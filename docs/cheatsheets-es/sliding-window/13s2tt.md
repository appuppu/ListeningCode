# Finding the Longest Substring Without Repeating Characters — Encontrar la longitud de la subcadena más larga sin caracteres repetidos

## Esencia del problema

Se recibe una cadena `s`. Se debe encontrar la subcadena contigua (substring) dentro de `s` en la que ningún carácter aparezca más de una vez, y devolver su **longitud máxima** como un entero.

## Idea central

El uso de una ventana deslizante permite examinar todas las subcadenas válidas en O(n). Cuando se encuentra un duplicado, el extremo izquierdo salta directamente a "la posición de la aparición anterior del carácter duplicado + 1", lo que elimina los desplazamientos innecesarios de uno en uno.

## Proceso de razonamiento

1. **Representar la búsqueda de subcadenas como una ventana**: Una "subcadena sin duplicados" se puede representar como un intervalo delimitado por dos punteros, el extremo izquierdo `left` y el extremo derecho `right`. Se avanza el extremo derecho de uno en uno para expandir la ventana, y cuando ocurre un duplicado, se mueve el extremo izquierdo para contraer la ventana
2. **Usar un HashMap para detectar duplicados**: Si se registra en un HashMap el "último índice en el que apareció cada carácter", se puede determinar en O(1) si un nuevo carácter ya existe dentro de la ventana
3. **Definir con precisión la condición de salto del extremo izquierdo**: No basta con que el carácter de `right` exista en el HashMap. Solo se considera duplicado cuando la posición de la aparición anterior es mayor o igual a `left` (es decir, está dentro de la ventana actual). Los registros antiguos fuera de la ventana se ignoran
4. **Determinar el destino del desplazamiento del extremo izquierdo**: Cuando se detecta un duplicado, se actualiza `left` a "la posición de la aparición anterior del carácter duplicado + 1". De esta forma, se excluye el carácter duplicado de la ventana y se mantienen los demás caracteres válidos dentro de ella
5. **Momento de actualización del HashMap**: Después de la verificación de duplicados, se registra (sobrescribe) el índice del carácter actual en el HashMap. Así, siempre se mantiene registrada la posición más reciente de cada carácter
6. **Actualización de la longitud máxima**: En cada paso se calcula `right - left + 1` (el ancho actual de la ventana) y se compara con el valor máximo obtenido hasta el momento para actualizarlo

## Conocimientos previos

### Qué es una ventana deslizante

Es una técnica que consiste en desplazar una "ventana" definida por dos punteros (`left`, `right`) sobre un arreglo o cadena, buscando las partes que cumplan una condición. Se avanza el extremo derecho para expandir la ventana y se avanza el extremo izquierdo para contraerla cuando se viola la condición. Como cada puntero solo se mueve hacia adelante, la complejidad total es O(n).

### Qué es un HashMap

Es una estructura de datos que almacena pares de clave y valor. Permite buscar y obtener un valor a partir de su clave en O(1). En este problema, la clave es un "carácter" y el valor es "el último índice en el que apareció ese carácter".

```java
HashMap<Character, Integer> map = new HashMap<>();  // Crear un HashMap vacío
map.put('a', 0);            // Almacenar el valor 0 con la clave 'a'
map.containsKey('a');       // Devolver un boolean indicando si la clave 'a' existe → true
map.get('a');               // Devolver el valor asociado a la clave 'a' → 0
```

### Qué es charAt

Es un método que obtiene el carácter en una posición específica de una cadena. `s.charAt(i)` devuelve el `char` en el índice `i` de la cadena `s`.

```java
String s = "abc";
char c = s.charAt(0);  // Devuelve 'a'
char d = s.charAt(2);  // Devuelve 'c'
```

### Qué es Math.max

Es un método que devuelve el mayor de dos valores. Se utiliza en situaciones donde se necesita actualizar continuamente un valor máximo.

```java
int result = Math.max(3, 7);  // Devuelve 7
maxLength = Math.max(maxLength, currentLength);  // Actualizar el valor máximo actual
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — `right` recorre la cadena una sola vez. `left` también se mueve solo hacia adelante, por lo que el total es O(n) |
| Space | O(n) — El HashMap almacena como máximo n pares de carácter e índice |

## Código

```java
// Entrada: cadena s
// Salida: devolver como int la longitud de la subcadena más larga sin caracteres duplicados
public int lengthOfLongestSubstring(String s) {
    // Puntero del extremo izquierdo de la ventana. La posición inicial es el inicio de la cadena
    int left = 0;
    // Variable que registra el ancho máximo de la ventana encontrado durante el recorrido
    int maxLength = 0;
    // HashMap que almacena clave=carácter, valor=último índice en el que apareció ese carácter
    // Se usa tanto para la verificación de duplicados como para calcular el destino del salto del extremo izquierdo
    HashMap<Character, Integer> hashMap = new HashMap<>();

    // right es el puntero del extremo derecho de la ventana. Se avanza de uno en uno para expandir la ventana
    for (int right = 0; right < s.length(); right++) {
        // Obtener el carácter que se va a agregar a la ventana
        char curChar = s.charAt(right);

        // containsKey: verificar si este carácter ha aparecido anteriormente
        // get(curChar) >= left: confirmar si esa posición de aparición está dentro de la ventana actual
        // Cuando ambas condiciones son verdaderas, existe un duplicado dentro de la ventana
        if (hashMap.containsKey(curChar) && hashMap.get(curChar) >= left) {
            // Saltar el extremo izquierdo a la posición de la aparición anterior del carácter duplicado + 1 para eliminar el duplicado
            // left solo se mueve hacia adelante, nunca retrocede
            left = hashMap.get(curChar) + 1;
        }

        // Registrar (sobrescribir) la posición del carácter actual con el índice más reciente
        // La próxima vez que aparezca este carácter, se usará el índice registrado aquí para calcular el destino del salto del extremo izquierdo
        hashMap.put(curChar, right);
        // right - left + 1 es el ancho actual de la ventana (longitud de la subcadena sin duplicados)
        // Se actualiza si supera el valor máximo anterior
        maxLength = Math.max(maxLength, right - left + 1);
    }
    // Este es la longitud de la subcadena más larga sin caracteres duplicados
    return maxLength;
}
```
