# Finding the Maximum in Each Sliding Window — Encontrar el valor máximo en cada ventana deslizante

## Esencia del problema

Se reciben un arreglo de enteros `nums` y un tamaño de ventana `k`. Se desliza una ventana de tamaño `k` una posición a la vez desde el extremo izquierdo hasta el extremo derecho del arreglo, y se obtiene el **valor máximo** dentro de la ventana en cada posición. Se devuelven todos los valores máximos en un arreglo.

## Idea central

Si se mantienen índices en un Deque (cola de doble extremo) de forma que los valores correspondientes estén en orden monótonamente decreciente, el frente del Deque siempre apunta al valor máximo dentro de la ventana. Cuando llega un nuevo elemento, se eliminan desde el final todos los elementos menores o iguales a él, y si el frente queda fuera de la ventana, se elimina. De esta manera, se obtiene el valor máximo en cada paso con un costo amortizado de O(1).

## Proceso de razonamiento

1. **Se necesita el valor máximo de cada ventana**: Cada vez que la ventana se desliza una posición, solo se agrega un elemento y se elimina uno. Si se recorre toda la ventana para obtener el máximo en O(k) cada vez, el costo total es O(nk), por lo que se necesita una estructura de datos que gestione el máximo de forma eficiente.
2. **Basta con conservar solo los candidatos a máximo**: Si dentro de la ventana hay elementos A y B, donde A está más a la izquierda que B y el valor de A es menor o igual al de B, entonces A nunca podrá ser el máximo en ninguna ventana futura. Como B está más a la derecha, B no saldrá de la ventana antes que A. Por lo tanto, se puede excluir a A de los candidatos.
3. **Se gestionan los candidatos con un Deque monótonamente decreciente**: Si se mantienen los candidatos en orden de mayor a menor, el frente siempre será el máximo. Al agregar un nuevo elemento, se eliminan desde el final todos los elementos menores o iguales a él, manteniendo así la propiedad de orden decreciente. Un Deque (cola de doble extremo) es la estructura adecuada para esta operación.
4. **Se almacenan índices en el Deque**: Para determinar si un elemento ha salido de la ventana, se necesita información de posición, por lo que se almacenan índices en lugar de valores en el Deque. Los valores se consultan mediante `nums[index]`.
5. **Verificación de fuera de ventana en el frente**: En cada paso, si el índice del frente del Deque es menor que el extremo izquierdo de la ventana actual `i - k + 1`, ese elemento ya salió de la ventana y se elimina del frente.
6. **Momento de registrar el resultado**: Cuando el índice `i` alcanza `k - 1` o más, la ventana está completa, por lo que se registra en el arreglo de resultados el valor al que apunta el frente del Deque.

## Conocimientos previos

### ¿Qué es un ArrayDeque (cola de doble extremo)?

Es una estructura de datos que permite agregar, consultar y eliminar elementos tanto por el frente como por el final en O(1). Combina las funcionalidades de pila y cola.

```java
ArrayDeque<Integer> deque = new ArrayDeque<>();  // Se crea un Deque vacío
deque.offerLast(5);       // Se agrega 5 al final
deque.offerLast(3);       // Se agrega 3 al final → Contenido del Deque: [5, 3]
deque.peekFirst();        // Se obtiene el elemento del frente (sin eliminarlo) → 5
deque.peekLast();         // Se obtiene el elemento del final (sin eliminarlo) → 3
deque.pollFirst();        // Se obtiene y elimina el elemento del frente → 5
deque.pollLast();         // Se obtiene y elimina el elemento del final → 3
deque.isEmpty();          // Se devuelve un boolean indicando si el Deque está vacío → true
```

### ¿Qué es un Deque monótonamente decreciente (Monotonic Deque)?

Es un Deque que mantiene sus elementos en orden siempre decreciente (sin igualdad) desde el frente hacia el final. Al agregar un nuevo elemento, se eliminan desde el final todos los elementos menores o iguales a él para mantener el orden decreciente.
Ejemplo: Deque=[7, 5, 3], se agrega 6 → se eliminan 5 y 3 → Deque=[7, 6]. El frente siempre apunta al valor máximo.

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Cada elemento se agrega al Deque como máximo una vez y se elimina como máximo una vez, por lo que el costo total es O(n) |
| Space | O(k) — El Deque mantiene como máximo k elementos, correspondientes al tamaño de la ventana |

## Código

```java
// Entrada: un arreglo de enteros nums y un entero k (tamaño de la ventana)
// Salida: se devuelve un int[] que contiene el valor máximo en cada posición de la ventana. El número de elementos es n - k + 1
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    // Arreglo de resultados que almacena el valor máximo de cada ventana. Existen n - k + 1 ventanas
    int[] result = new int[n - k + 1];
    // Deque que mantiene los índices de los candidatos a máximo en orden monótonamente decreciente
    // El Deque almacena los índices que pueden ser el máximo dentro de la ventana, de forma que los valores correspondientes estén en orden decreciente
    ArrayDeque<Integer> deque = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // Si el índice del frente es menor que el extremo izquierdo de la ventana i - k + 1, está fuera de la ventana y se elimina
        // Como la ventana se desliza de a una posición, a lo sumo un elemento queda fuera de la ventana en cada paso
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }

        // Se eliminan desde el final todos los candidatos menores o iguales al elemento actual nums[i] para mantener el orden decreciente
        // Estos elementos nunca podrán ser el máximo mientras nums[i] exista en la ventana, por lo que se pueden excluir de los candidatos
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }

        // Se agrega el índice actual al final del Deque
        // Como el bucle while anterior eliminó todos los elementos menores o iguales, el Deque permanece en orden decreciente tras la inserción
        deque.offerLast(i);

        // Cuando i >= k - 1, la ventana contiene k elementos completos
        // El frente del Deque apunta al índice del valor máximo dentro de la ventana actual
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    // Se devuelve result, que contiene los valores máximos de todas las ventanas
    return result;
}
```
