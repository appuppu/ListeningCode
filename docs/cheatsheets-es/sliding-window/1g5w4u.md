# Longest Substring After Replacing K Characters — Encontrar la subcadena más larga de caracteres idénticos obtenida mediante K reemplazos de caracteres

## Esencia del problema

Se da una cadena `s` de letras mayúsculas y un entero `k`. Se pueden reemplazar como máximo `k` caracteres de la cadena por cualquier carácter. El objetivo es devolver la longitud máxima de una subcadena en la que **todos los caracteres sean idénticos**.

## Idea central

Si se conoce la "frecuencia del carácter más repetido" dentro de la ventana, se puede calcular el "número de caracteres que necesitan reemplazo = tamaño de la ventana − frecuencia del carácter más repetido". Mientras este número de reemplazos sea menor o igual a `k`, se sigue expandiendo la ventana para obtener la subcadena más larga.

## Proceso de razonamiento

1. **Explorar todas las subcadenas es ineficiente**: Enumerar todas las subcadenas requiere O(n²). Como se trata de intervalos contiguos, el patrón Sliding Window es adecuado
2. **Se desea conocer el número de caracteres que necesitan reemplazo dentro de la ventana**: Para hacer que todos los caracteres de la ventana sean idénticos, basta con reemplazar todos los caracteres excepto el de mayor frecuencia. Por lo tanto, el número de caracteres que necesitan reemplazo se obtiene como `tamaño de la ventana − frecuencia del carácter más repetido`
3. **Medio para rastrear la frecuencia de cada carácter**: Como solo existen 26 tipos de letras mayúsculas, se puede gestionar la frecuencia de cada carácter con un arreglo `count` de tamaño 26. Se incrementa y decrementa conforme la ventana se expande y contrae
4. **Gestión eficiente de la frecuencia del carácter más repetido**: Cada vez que se avanza el puntero derecho, se compara la frecuencia del carácter añadido con el `maxFreq` actual y se toma el mayor como nuevo `maxFreq`. Aunque se avance el puntero izquierdo y se excluya un carácter, no se reduce `maxFreq`. Esto se debe a que, en un problema donde se busca la longitud máxima, actualizar `maxFreq` a un valor menor que el máximo alcanzado en el pasado no permite obtener un resultado más largo
5. **Condición para contraer la ventana**: Cuando `tamaño de la ventana − maxFreq > k`, el número de reemplazos supera `k`, por lo que se avanza el puntero izquierdo en una posición para contraer la ventana. Se repite hasta que esta condición deje de cumplirse
6. **Actualización de la longitud máxima**: Cada vez que la ventana es válida (número de reemplazos ≤ k), se compara `right − left + 1` con el `maxLen` actual y se registra el mayor como `maxLen`

## Conocimientos previos

### ¿Qué es Sliding Window (ventana deslizante)?

Es una técnica que gestiona un intervalo contiguo sobre un arreglo o cadena mediante dos punteros (left, right). Se avanza right para expandir la ventana y, cuando la condición deja de cumplirse, se avanza left para contraerla. Como cada elemento se procesa como máximo 2 veces (una al añadirlo y otra al eliminarlo), la técnica opera en O(n).

### Método para gestionar la frecuencia de caracteres con un arreglo

Las letras mayúsculas comprenden 26 caracteres de `'A'` a `'Z'`, por lo que se puede gestionar la frecuencia de cada carácter con un arreglo `int[26]`. La conversión de carácter a índice se realiza con `charAt() - 'A'`.

```java
int[] count = new int[26];           // Arreglo que almacena la frecuencia de los 26 caracteres
count[s.charAt(i) - 'A']++;         // Incrementa en 1 la frecuencia del carácter s.charAt(i)
count[s.charAt(i) - 'A']--;         // Decrementa en 1 la frecuencia del carácter s.charAt(i)
```

### Razón por la que no se reduce maxFreq

`maxFreq` es la frecuencia del carácter más repetido dentro de la ventana. No es necesario recalcular ni reducir `maxFreq` cuando se avanza el puntero izquierdo y se excluye un carácter. En un problema donde se busca la longitud máxima, aunque `maxFreq` se vuelva menor que su valor máximo anterior, el tamaño de ventana obtenido en ese estado no puede superar la longitud máxima alcanzada previamente. Por eso, gestionar `maxFreq` de forma monótonamente creciente produce resultados correctos.

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — El puntero derecho y el puntero izquierdo avanzan como máximo n veces cada uno |
| Space | O(1) — El tamaño del arreglo utilizado es fijo en 26 y no depende del tamaño de la entrada |

## Código

```java
// Entrada: una cadena s de letras mayúsculas y un entero k (número máximo de reemplazos)
// Salida: devuelve como int la longitud máxima de una subcadena en la que todos los caracteres pueden hacerse idénticos con como máximo k reemplazos
public int characterReplacement(String s, int k) {
    // Arreglo que gestiona la frecuencia de cada carácter (A a Z). El índice 0 corresponde a 'A' y el 25 a 'Z'
    int[] count = new int[26];
    // left: extremo izquierdo de la ventana
    int left = 0;
    // maxFreq: frecuencia del carácter más repetido dentro de la ventana (se gestiona de forma monótonamente creciente)
    int maxFreq = 0;
    // maxLen: longitud máxima de la subcadena que cumple la condición (se devuelve este valor al final)
    int maxLen = 0;

    // Se avanza el puntero derecho de uno en uno para expandir el extremo derecho de la ventana
    for (int right = 0; right < s.length(); right++) {
        // Se incrementa en 1 la frecuencia del carácter añadido al extremo derecho
        count[s.charAt(right) - 'A']++;

        // Se compara la frecuencia del carácter añadido con el maxFreq actual y se actualiza la frecuencia del carácter más repetido
        maxFreq = Math.max(maxFreq, count[s.charAt(right) - 'A']);

        // Tamaño de la ventana - maxFreq = número de caracteres que necesitan reemplazo. Mientras esto supere k, se contrae el extremo izquierdo
        // Nota: no se recalcula maxFreq aquí. Reducirlo no contribuye a actualizar la longitud máxima
        while (right - left + 1 - maxFreq > k) {
            // Se decrementa en 1 la frecuencia del carácter del extremo izquierdo para excluirlo de la ventana
            count[s.charAt(left) - 'A']--;
            left++;
        }

        // La ventana es válida (número de reemplazos ≤ k), por lo que se actualiza la longitud máxima con el tamaño actual de la ventana
        maxLen = Math.max(maxLen, right - left + 1);
    }
    // Tras finalizar el bucle for, se devuelve la longitud de la subcadena más larga de caracteres idénticos obtenida con como máximo k reemplazos
    return maxLen;
}
```
