# Checking if a String Contains a Permutation of Another — Determinar si una cadena contiene una permutación de otra

## Esencia del problema

Se dan dos cadenas `s1` y `s2`. Se debe determinar si dentro de `s2` existe un anagrama (reordenación de caracteres) de `s1` como una **subcadena contigua**, y devolver `true` si existe o `false` si no existe.

## Idea central

Que una permutación de `s1` esté contenida en `s2` significa que existe una subcadena dentro de `s2` con la misma longitud y la misma frecuencia de caracteres que `s1`. Al recorrer `s2` con una ventana deslizante de longitud fija y actualizar de forma incremental la cantidad de caracteres cuya frecuencia coincide entre las 26 letras, se puede evaluar cada desplazamiento en O(1).

## Proceso de razonamiento

1. **Reformular la condición de permutación**: Que una permutación de `s1` exista como subcadena de `s2` significa que dentro de `s2` existe una subcadena de longitud `m` (= longitud de `s1`) donde la frecuencia de aparición de cada carácter coincide exactamente con la de `s1`
2. **Recorrer con una ventana de longitud fija**: Como la longitud de la subcadena siempre es `m`, se coloca una ventana de tamaño fijo `m` sobre `s2` y se desliza carácter por carácter comparando las frecuencias de caracteres
3. **Gestionar las frecuencias de aparición con arreglos de frecuencia**: Como las letras minúsculas son 26 tipos, se utilizan dos arreglos de enteros de tamaño 26 (`s1F` y `winF`) para gestionar las frecuencias de caracteres de `s1` y de la ventana respectivamente. Cada índice del arreglo corresponde a cada letra
4. **Comparar 26 elementos cada vez es ineficiente**: Al deslizar la ventana, los caracteres que cambian son como máximo 2: "el carácter que entra" y "el carácter que sale". En lugar de comparar los 26 elementos cada vez, se rastrea con un contador `matches` "la cantidad de letras cuya frecuencia coincide entre las 26", y solo se actualiza la diferencia
5. **Regla de actualización del contador matches**: Al modificar la frecuencia de un carácter, si coincidía antes del cambio se resta 1 a `matches`, y si coincide después del cambio se suma 1 a `matches`. Se mantiene la consistencia del contador respetando el orden "evaluación antes del cambio → cambio del valor → evaluación después del cambio"
6. **Condición de evaluación**: En el momento en que `matches` llega a 26, las frecuencias de las 26 letras coinciden, por lo que se devuelve `true`. Si se desliza hasta el final de `s2` sin alcanzar 26, se devuelve `false`

## Conocimientos previos

### Qué es una ventana deslizante

Es una técnica que recorre subintervalos contiguos de un arreglo o cadena moviendo el extremo izquierdo y el extremo derecho. En el caso de una ventana de longitud fija, al avanzar el extremo derecho una posición, el extremo izquierdo también avanza una posición, manteniendo así el tamaño constante de la ventana.

```java
// Forma básica de deslizar una ventana fija de longitud m sobre s2
for (int i = m; i < n; i++) {
    char entering = s2.charAt(i);       // Carácter que entra en la ventana (extremo derecho)
    char leaving = s2.charAt(i - m);    // Carácter que sale de la ventana (extremo izquierdo)
}
```

### Qué es un arreglo de frecuencia

Es un arreglo de enteros de tamaño 26 que almacena la cantidad de apariciones de cada carácter. Se asocia `'a'` al índice 0 y `'z'` al índice 25. Se convierte un carácter a índice mediante `charAt(i) - 'a'`.

```java
int[] freq = new int[26];              // Se inicializa con todos los elementos en 0
freq[s.charAt(i) - 'a']++;            // Se incrementa en 1 la frecuencia del carácter
freq[s.charAt(i) - 'a']--;            // Se decrementa en 1 la frecuencia del carácter
```

### Qué es el contador matches

Es un contador que rastrea la cantidad de índices donde los valores coinciden entre dos arreglos de frecuencia. Si los 26 coinciden, entonces `matches == 26`, lo que significa que la composición de caracteres de ambas cadenas es idéntica.

```java
int matches = 0;
for (int i = 0; i < 26; i++) {
    if (s1F[i] == winF[i]) matches++;  // Se cuenta la cantidad de caracteres que coinciden
}
// Si matches == 26, las frecuencias de todos los caracteres coinciden
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Solo se necesita un recorrido de `s2` (cada desplazamiento es O(1)) |
| Space | O(1) — El tamaño de los arreglos de frecuencia siempre es 26 y no depende del tamaño de la entrada |

## Código

```java
// Entrada: cadena s1 (permutación a buscar) y cadena s2 (cadena donde se busca)
// Salida: true si s2 contiene una permutación de s1 como subcadena, false en caso contrario
boolean checkInclusion(String s1, String s2) {
    int m = s1.length();
    int n = s2.length();

    // Si s1 es más larga que s2, es imposible que contenga la permutación, así que se devuelve false inmediatamente
    if (m > n) return false;

    // Arreglos de tamaño 26 para almacenar la frecuencia de caracteres de s1 y de la ventana
    int[] s1F = new int[26];
    int[] winF = new int[26];

    // Se calcula la frecuencia de la primera ventana (los primeros m caracteres). Se cuentan simultáneamente los primeros m caracteres de s1 y s2
    for (int i = 0; i < m; i++) {
        s1F[s1.charAt(i) - 'a']++;
        winF[s2.charAt(i) - 'a']++;
    }

    // Se cuenta la cantidad de caracteres cuya frecuencia coincide entre las 26 letras (cálculo del matches inicial)
    int matches = 0;
    for (int i = 0; i < 26; i++) {
        if (s1F[i] == winF[i]) matches++;
    }

    // Si las frecuencias de las 26 letras coinciden en la primera ventana, se devuelve true
    if (matches == 26) return true;

    // Se desliza la ventana un carácter a la derecha (i es la posición siguiente al extremo derecho de la ventana)
    for (int i = m; i < n; i++) {
        // --- Procesamiento del carácter que entra en la ventana (extremo derecho) ---
        int idx = s2.charAt(i) - 'a';
        // Nota: se debe respetar siempre el orden "evaluación antes del cambio → cambio del valor → evaluación después del cambio"
        if (winF[idx] == s1F[idx]) matches--;   // Si coincidía antes del cambio, se decrementa matches
        winF[idx]++;                              // Se incrementa la frecuencia porque el carácter entra en la ventana
        if (winF[idx] == s1F[idx]) matches++;   // Si coincide después del cambio, se incrementa matches

        // --- Procesamiento del carácter que sale de la ventana (extremo izquierdo) ---
        idx = s2.charAt(i - m) - 'a';
        // Mismo procedimiento que para el carácter que entra: evaluación antes del cambio → cambio del valor → evaluación después del cambio
        if (winF[idx] == s1F[idx]) matches--;   // Si coincidía antes del cambio, se decrementa matches
        winF[idx]--;                              // Se decrementa la frecuencia porque el carácter sale de la ventana
        if (winF[idx] == s1F[idx]) matches++;   // Si coincide después del cambio, se incrementa matches

        // Si las frecuencias de las 26 letras coinciden, se encontró la permutación y se devuelve true
        if (matches == 26) return true;
    }

    // Se deslizó hasta el final de s2 sin alcanzar matches==26, así que se devuelve false
    return false;
}
```
