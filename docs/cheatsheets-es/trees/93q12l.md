# Validating a Binary Search Tree — Determinar si un árbol binario es un árbol binario de búsqueda válido

## Esencia del problema

Se da el nodo `root` de un árbol binario. Se debe determinar si el árbol es un árbol binario de búsqueda (BST) válido. Un BST válido significa que, para cada nodo, todos los valores del subárbol izquierdo son **estrictamente menores** que el valor del nodo, y todos los valores del subárbol derecho son **estrictamente mayores** que el valor del nodo.

## Idea central

Cada nodo tiene un "rango válido de valores posibles". Al descender recursivamente desde la raíz, se reduce el límite superior para el hijo izquierdo y el límite inferior para el hijo derecho, lo que permite determinar en un solo recorrido si todos los nodos cumplen las condiciones del BST.

## Proceso de razonamiento

1. **Verificar solo el padre y los hijos directos no es suficiente**: No basta con que cada nodo sea mayor que su hijo izquierdo directo y menor que su hijo derecho directo para cumplir las condiciones del BST. "Todos" los nodos del subárbol izquierdo deben ser menores que el nodo. Es decir, cada nodo tiene restricciones heredadas de sus ancestros
2. **Definir el rango válido de cada nodo**: La raíz puede tomar cualquier valor, por lo que el rango comienza en `(-∞, +∞)`. Al avanzar al hijo izquierdo, el límite superior se reduce al valor del padre, y al avanzar al hijo derecho, el límite inferior se reduce al valor del padre. Este rango se pasa como argumento en la recursión
3. **Determinar la condición de validación**: En cada nodo se verifica si `node.val` está dentro del rango `(lo, hi)`. Como el BST usa desigualdades estrictas, si `node.val <= lo` o `node.val >= hi`, el nodo se considera inválido
4. **Definir la estructura de la recursión**: El caso base es `node == null`, que retorna `true` (un árbol vacío es un BST válido). En cada nodo se valida su propio valor y se realiza una llamada recursiva a los hijos izquierdo y derecho con el rango reducido. Solo se retorna `true` si ambos hijos retornan `true`
5. **Usar el tipo long para el rango**: Cuando el valor de un nodo es `Integer.MIN_VALUE` o `Integer.MAX_VALUE`, el rango del tipo int no permite representar los valores iniciales. Al usar `Long.MIN_VALUE` y `Long.MAX_VALUE` como rango inicial, todos los valores int se pueden validar correctamente
6. **Valor de retorno final**: Se inicia la recursión desde la raíz. Si todos los nodos están dentro de su rango válido, se retorna `true`; si al menos uno viola la condición, se retorna `false`

## Conocimientos previos

### Qué es un árbol binario de búsqueda (BST)

Un árbol binario en el que, para cada nodo, todos los valores del subárbol izquierdo son menores que el valor del nodo, y todos los valores del subárbol derecho son mayores que el valor del nodo. Esta propiedad se aplica no solo a los hijos directos, sino a todo el subárbol.

```
      5
     / \
    3   7     ← BST válido: 3<5, 7>5, 1<3, 4>3 y 4<5, 6>5 y 6<7
   / \   \
  1   4   8
```

### Reducción del rango mediante recursión

El mecanismo por el cual el rango de valores válidos se reduce al avanzar del padre al hijo:

```
Nodo 5: rango(-∞, +∞)
├─ Hijo izq. 3: rango(-∞, 5)  ← El límite superior se reduce al valor 5 del padre
│  ├─ Hijo izq. 1: rango(-∞, 3)
│  └─ Hijo der. 4: rango(3, 5)  ← Límite inferior 3 y límite superior 5
└─ Hijo der. 7: rango(5, +∞)  ← El límite inferior se reduce al valor 5 del padre
```

### Razón de usar el tipo long

El rango de `int` en Java es `-2147483648` a `2147483647`. Para expresar como rango inicial "cualquier valor de tipo int es aceptable", se necesitan valores que excedan el rango de int. Al usar el tipo `long`, se puede establecer un rango inicial suficientemente amplio con `Long.MIN_VALUE` y `Long.MAX_VALUE`.

```java
long lo = Long.MIN_VALUE;  // Menor que cualquier valor de tipo int
long hi = Long.MAX_VALUE;  // Mayor que cualquier valor de tipo int
node.val <= lo;            // node.val es de tipo int, por lo que se garantiza que es mayor que Long.MIN_VALUE
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Se visita cada nodo exactamente una vez |
| Space | O(h) — La profundidad de la pila de llamadas recursivas es proporcional a la altura h del árbol (peor caso O(n), caso balanceado O(log n)) |

## Código

```java
// Entrada: nodo raíz root del árbol binario
// Salida: true si el árbol es un BST válido, false en caso contrario
public boolean isValidBST(TreeNode root) {
    // Se establece el rango inicial en Long.MIN_VALUE/MAX_VALUE para que el nodo raíz acepte cualquier valor de tipo int
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

// lo, hi son de tipo long. No se puede usar Integer.MIN_VALUE/MAX_VALUE como valores iniciales con el tipo int
boolean validate(TreeNode node, long lo, long hi) {
    // Caso base: un nodo vacío no viola las condiciones del BST
    if (node == null) return true;

    // Si el valor del nodo actual está fuera del rango válido (lo, hi), es inválido
    // En un BST los valores iguales tampoco son permitidos, por lo que se valida estrictamente con <= y >=
    if (node.val <= lo || node.val >= hi) return false;

    // Subárbol izquierdo: se reduce el límite superior a node.val (todos los valores izquierdos deben ser menores que node.val). El límite inferior lo mantiene la restricción del ancestro
    // Subárbol derecho: se reduce el límite inferior a node.val (todos los valores derechos deben ser mayores que node.val). El límite superior hi mantiene la restricción del ancestro
    // Solo si ambos subárboles retornan true, todo el subárbol es un BST válido
    return validate(node.left, lo, node.val)
        && validate(node.right, node.val, hi);
}
```
