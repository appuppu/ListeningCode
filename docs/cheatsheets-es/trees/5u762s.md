# Inverting a Binary Tree — Intercambiar los hijos izquierdo y derecho de todos los nodos de un árbol binario

## Esencia del problema

Se recibe el nodo raíz `root` de un árbol binario. Se deben intercambiar los hijos izquierdo y derecho en **todos los nodos** del árbol (invertirlos) y devolver el nodo raíz del árbol invertido.

## Idea central

La inversión de un árbol binario es una operación que intercambia los hijos izquierdo y derecho en todos los nodos. Si se visitan todos los nodos en orden por niveles mediante BFS y se realiza el swap de los hijos izquierdo y derecho en cada nodo, el árbol completo queda invertido.

## Proceso de razonamiento

1. **Comprender la definición de inversión**: La inversión de un árbol binario es una operación que intercambia los hijos izquierdo y derecho no solo en el nodo raíz, sino en todos los nodos. Es decir, basta con visitar todos los nodos del árbol una vez cada uno y realizar el proceso de swap en cada nodo
2. **Elegir el método para visitar todos los nodos**: Se utiliza BFS (búsqueda en anchura) como método para visitar todos los nodos del árbol. BFS procesa los nodos en orden por niveles utilizando una cola, lo que hace que la implementación sea intuitiva y fácil de entender
3. **Decidir la operación en cada nodo**: Para cada nodo extraído de la cola, se intercambian `left` y `right` utilizando una variable temporal. El orden del swap no importa, y el swap se puede realizar sin problemas incluso si algún hijo es null
4. **Agregar los nodos hijos a la cola**: Si los hijos izquierdo y derecho después del swap no son null, se agregan a la cola. De esta manera, los nodos de los niveles inferiores del árbol también se visitan secuencialmente y el swap se ejecuta en todos los nodos
5. **Qué devolver al final**: Después de completar el swap de todos los nodos, se devuelve directamente el nodo raíz original `root`. La estructura del árbol cambia, pero el nodo raíz en sí es el mismo objeto

## Conocimientos previos

### Qué es un árbol binario (Binary Tree)

Es una estructura de árbol en la que cada nodo tiene como máximo dos hijos (hijo izquierdo `left` e hijo derecho `right`). Los nodos se representan con la clase `TreeNode`, que tiene los campos `val` (valor), `left` (hijo izquierdo) y `right` (hijo derecho).

```java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

### Qué es una Queue (cola)

Es una estructura de datos de tipo primero en entrar, primero en salir (FIFO). El primer elemento agregado es el primero en ser extraído. En BFS se utiliza una cola para gestionar los nodos que deben ser visitados.

```java
Queue<TreeNode> queue = new LinkedList<>();  // Crear una cola vacía
queue.add(node);     // Agregar node al final de la cola
queue.poll();        // Extraer y devolver el elemento del frente de la cola
queue.isEmpty();     // Devolver un boolean indicando si la cola está vacía → true/false
```

### Qué es BFS (búsqueda en anchura)

Es un algoritmo que explora un árbol o grafo "en orden por niveles". Utilizando una cola, después de procesar el nodo actual se agregan sus nodos hijos a la cola, lo que permite visitar todos los nodos en orden desde los niveles más superficiales.

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Se visita cada nodo del árbol exactamente una vez |
| Space | O(n) — La cola almacena como máximo n nodos |

## Código

```java
// Entrada: nodo raíz root de un árbol binario
// Salida: devolver el nodo raíz root después de intercambiar los hijos izquierdo y derecho de todos los nodos
public TreeNode invertTree(TreeNode root) {
    // Si el árbol está vacío, devolver null. El árbol no existe, así que se termina directamente
    if (root == null) return null;

    // Crear una cola para BFS y agregar el nodo raíz
    // Esta cola gestiona los nodos a los que se les debe realizar el swap de izquierda y derecha
    Queue<TreeNode> queue = new LinkedList<>();
    queue.add(root);

    // Repetir hasta que la cola esté vacía (= hasta que se hayan procesado todos los nodos)
    while (!queue.isEmpty()) {
        // Extraer del frente de la cola el nodo objetivo del swap
        TreeNode curr = queue.poll();

        // Intercambiar los hijos izquierdo y derecho utilizando una variable temporal
        // Nota: si se asigna directamente sin usar una variable temporal, se pierde la referencia de uno de los hijos al ser sobrescrita
        TreeNode temp = curr.left;
        curr.left = curr.right;
        curr.right = temp;

        // Si los hijos después del swap no son null, agregarlos a la cola
        // Los nodos null no tienen más hijos que procesar, por lo que no es necesario agregarlos
        if (curr.left != null) queue.add(curr.left);
        if (curr.right != null) queue.add(curr.right);
    }

    // Devolver el nodo raíz con el swap de todos los nodos completado
    // La estructura del árbol cambia, pero el nodo raíz en sí es el mismo objeto
    return root;
}
```
