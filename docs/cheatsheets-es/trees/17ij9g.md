# Encontrar la profundidad máxima de un árbol binario — Obtener el número de nodos en la ruta más profunda de un árbol binario

## Esencia del problema

Se da el nodo `root` de un árbol binario. Se debe devolver como entero el **número de nodos** (profundidad máxima) contenidos en la ruta desde el nodo raíz hasta el nodo hoja más lejano. Si el árbol está vacío (root es null), se devuelve 0.

## Idea central

La profundidad máxima de un árbol es igual al mayor valor entre "la profundidad máxima del subárbol izquierdo" y "la profundidad máxima del subárbol derecho", más 1 (correspondiente al nodo actual). Esta definición recursiva se convierte directamente en la solución.

## Proceso de razonamiento

1. **La profundidad del árbol se puede definir recursivamente**: La profundidad de un nodo depende de la profundidad de los subárboles que tienen como raíz a sus hijos izquierdo y derecho. Es decir, el problema se puede descomponer en subproblemas más pequeños con la misma estructura
2. **Determinar el caso base**: Cuando el nodo es null, no hay nada allí, por lo que la profundidad es 0. Esta es la condición de terminación de la recursión
3. **Obtener la profundidad de cada subárbol izquierdo y derecho**: Desde el nodo actual se recurre al hijo izquierdo para obtener la profundidad máxima del subárbol izquierdo. De la misma manera, se recurre al hijo derecho para obtener la profundidad máxima del subárbol derecho
4. **Integrar los resultados izquierdo y derecho**: Como la profundidad máxima es la ruta más larga, se selecciona el mayor de los dos valores de profundidad. Se obtiene con `Math.max(left, right)`
5. **Sumar el nodo actual y devolver el resultado**: Al sumar 1 al valor máximo de las profundidades izquierda y derecha, se devuelve al padre la profundidad que incluye el nodo actual. Este 1 cuenta "el nodo actual en sí mismo"

## Conocimientos previos

### Qué es TreeNode (nodo de un árbol binario)

TreeNode es una clase que representa cada nodo de un árbol binario. Tiene tres campos: el valor `val`, el hijo izquierdo `left` y el hijo derecho `right`. Si un hijo no existe, su valor es null.

```java
public class TreeNode {
    int val;              // Valor que almacena el nodo
    TreeNode left;        // Nodo hijo izquierdo (null si no existe)
    TreeNode right;       // Nodo hijo derecho (null si no existe)
}
```

### Qué es la recursión (Recursion)

La recursión es una técnica en la que una función se llama a sí misma. En estructuras de árbol, se utiliza para aplicar el mismo procesamiento a los subárboles de cada nodo. Siempre se debe definir un caso base (condición para detener la recursión) para evitar bucles infinitos.

```java
// Estructura básica de la recursión
public int recursive(TreeNode node) {
    if (node == null) return 0;           // Caso base: condición de terminación de la recursión
    return recursive(node.left);          // Llamada recursiva: resolver el subproblema
}
```

### Qué es Math.max

Math.max es un método estándar de Java que devuelve el mayor de dos enteros.

```java
Math.max(3, 5);    // → 5
Math.max(0, 0);    // → 0
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Se visita cada nodo exactamente una vez |
| Space | O(h) — La pila de llamadas de la recursión se acumula según la altura del árbol. En el peor caso (árbol sesgado), es O(n) |

## Código

```java
// Entrada: nodo raíz root del árbol binario (tipo TreeNode, puede ser null)
// Salida: devuelve un entero que representa la profundidad máxima del árbol
public int maxDepth(TreeNode root) {
    // Caso base: si no hay nodo, la profundidad es 0
    // La recursión se detiene cuando se alcanza el hijo (null) de un nodo hoja
    if (root == null) return 0;

    // Obtener recursivamente la profundidad máxima del subárbol izquierdo
    // Se repite el mismo procesamiento para el subárbol con el hijo izquierdo como raíz, hasta alcanzar el caso base y devolver el valor
    int left = maxDepth(root.left);

    // Obtener recursivamente la profundidad máxima del subárbol derecho
    // De la misma manera que con el izquierdo, se obtiene la profundidad del subárbol con el hijo derecho como raíz
    int right = maxDepth(root.right);

    // Sumar 1 por el nodo actual al mayor de los dos valores y devolver el resultado
    // Math.max(left, right) selecciona el subárbol más profundo, cuyo número de nodos corresponde a la ruta más larga
    // El +1 cuenta el nodo actual root en sí mismo. El nodo padre recibe este valor de retorno y lo usa en su propio cálculo
    return 1 + Math.max(left, right);
}
```
