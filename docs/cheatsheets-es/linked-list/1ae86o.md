# Reordering a Linked List by Interleaving Ends — Reordenar una lista enlazada intercalando los extremos

## Esencia del problema

Se da una lista enlazada simple L0 → L1 → … → Ln-1 → Ln. Se debe reordenar esta lista en el orden L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → … **en el lugar (in-place)**. Se realiza manipulando únicamente los enlaces (punteros next) de los nodos, sin modificar los valores de los nodos.

## Idea central

Si se invierte la segunda mitad de la lista, basta con intercalar alternadamente los nodos "desde el inicio de la primera mitad" y "desde el inicio de la segunda mitad (que era el final original)" para obtener el orden deseado. Para invertir la segunda mitad, primero se encuentra el punto medio de la lista y se divide en dos partes.

## Proceso de razonamiento

1. **Observar la estructura después del reordenamiento**: El orden L0 → Ln → L1 → Ln-1 → … es el resultado de extraer alternadamente elementos desde el "inicio" y el "final" de la lista. Es decir, basta con fusionar alternadamente dos secuencias: la del lado del inicio y la del lado del final.
2. **Se necesita invertir para extraer elementos desde el final**: En una lista enlazada simple, acceder al final tiene un costo de O(n). Sin embargo, si se invierte la segunda mitad de la lista, el inicio de la segunda mitad se convierte en el final original, y se pueden obtener los elementos del lado del final simplemente recorriendo desde el inicio.
3. **Encontrar el punto medio de la lista**: Para invertir la segunda mitad, primero se necesita decidir en qué punto dividir la lista. Usando punteros slow/fast (tortuga y liebre), se puede encontrar el punto medio en un solo recorrido. slow avanza de uno en uno, fast avanza de dos en dos, y cuando fast llega al final de la lista, slow apunta al punto medio.
4. **Invertir la segunda mitad**: Comenzando desde el nodo siguiente al punto medio, se redirige el puntero next de cada nodo hacia el nodo anterior, invirtiendo así la segunda mitad de la lista. Se rastrea el nodo anterior con la variable prev, y al terminar el bucle, prev apunta al inicio de la lista invertida.
5. **Fusionar alternadamente la primera mitad y la segunda mitad invertida**: Se recorren ambas listas desde el inicio, insertando un nodo de la segunda mitad después de cada nodo de la primera mitad. En cada paso, se guardan los enlaces originales en variables temporales antes de reescribir los punteros next.
6. **La segunda mitad es más corta o de igual longitud**: En listas de longitud impar, la primera mitad es un nodo más larga, por lo que la condición del bucle de fusión es `second != null`. La fusión termina cuando se agotan los nodos de la segunda mitad.

## Conocimientos previos

### Qué son los punteros slow/fast (método de la tortuga y la liebre)

Es una técnica para encontrar el punto medio de una lista enlazada en un solo recorrido. slow avanza de un nodo a la vez, y fast avanza de dos nodos a la vez. Cuando fast llega al final de la lista, slow apunta al punto medio de la lista.

```java
ListNode slow = head, fast = head;
while (fast.next != null && fast.next.next != null) {
    slow = slow.next;        // slow avanza un paso
    fast = fast.next.next;   // fast avanza dos pasos
}
// Al terminar el bucle, slow apunta al nodo medio de la lista
```

### Qué es la inversión de una lista enlazada

Es la operación de redirigir el puntero next de cada nodo hacia el nodo anterior en lugar del siguiente. Se avanza de un nodo a la vez mientras se rastrea prev (nodo anterior), invirtiendo la dirección de los enlaces.

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode nxt = curr.next;  // Se guarda el siguiente nodo en una variable temporal
    curr.next = prev;          // Se redirige el enlace hacia el nodo anterior
    prev = curr;               // Se actualiza prev al nodo actual
    curr = nxt;                // Se avanza al siguiente nodo
}
// Al terminar el bucle, prev apunta al inicio de la lista invertida
```

### Qué es la fusión alternada de dos listas

Es la operación de extraer alternadamente un elemento de cada una de las dos listas y conectarlos en una sola lista. En cada paso, se guardan los enlaces originales en variables temporales antes de reescribir los punteros next.

```java
ListNode a = list1, b = list2;
while (b != null) {
    ListNode tmpA = a.next;   // Se guarda el siguiente original de a
    ListNode tmpB = b.next;   // Se guarda el siguiente original de b
    a.next = b;               // Se inserta b después de a
    b.next = tmpA;            // Se conecta el siguiente original de a después de b
    a = tmpA;                 // Se avanza a a la siguiente posición
    b = tmpB;                 // Se avanza b a la siguiente posición
}
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Cada paso de búsqueda del punto medio, inversión de la segunda mitad y fusión es O(n) |
| Space | O(1) — Solo se utilizan variables de punteros, sin crear estructuras de datos adicionales |

## Código

```java
// Entrada: nodo cabeza head de una lista enlazada simple
// Salida: ninguna (se reordena la lista en el lugar. El tipo de retorno es void)
void reorderList(ListNode head) {
    // No se necesita reordenar una lista vacía
    if (head == null) return;

    // Paso 1: Encontrar el punto medio de la lista con punteros slow/fast
    // fast avanza al doble de velocidad que slow, por lo que cuando fast llega al final, slow apunta al nodo medio
    ListNode slow = head, fast = head;
    while (fast.next != null
            && fast.next.next != null) {
        slow = slow.next;          // slow avanza un paso
        fast = fast.next.next;     // fast avanza dos pasos
    }

    // Paso 2: Separar la segunda mitad de la lista e invertirla
    ListNode second = slow.next;   // second es el nodo inicial de la segunda mitad de la lista
    slow.next = null;              // Se corta el final de la primera mitad, dividiendo la lista en dos partes
    ListNode prev = null;
    while (second != null) {
        ListNode nxt = second.next;  // Se guarda el siguiente nodo en una variable temporal
        second.next = prev;          // Se redirige el enlace hacia el nodo anterior
        prev = second;               // Se actualiza prev al nodo actual
        second = nxt;                // Se avanza al siguiente nodo
    }
    // Al terminar el bucle, prev apunta al inicio de la segunda mitad invertida (el final de la lista original)

    // Paso 3: Fusionar alternadamente la primera mitad y la segunda mitad invertida
    ListNode first = head;         // Inicio de la primera mitad de la lista
    second = prev;                 // Inicio de la segunda mitad invertida de la lista
    // En listas de longitud impar, la primera mitad es un nodo más larga, por lo que se termina cuando la segunda mitad (second) se agota
    while (second != null) {
        ListNode tmp1 = first.next;   // Se guarda el siguiente nodo de la primera mitad (si no se guarda, se pierde el enlace original al reescribir next)
        ListNode tmp2 = second.next;  // Se guarda el siguiente nodo de la segunda mitad
        first.next = second;          // Se inserta el nodo de la segunda mitad después del nodo de la primera mitad
        second.next = tmp1;           // Se conecta la continuación de la primera mitad después del nodo de la segunda mitad
        first = tmp1;                 // Se avanza el puntero de la primera mitad a la siguiente posición
        second = tmp2;                // Se avanza el puntero de la segunda mitad a la siguiente posición
    }
}
```
