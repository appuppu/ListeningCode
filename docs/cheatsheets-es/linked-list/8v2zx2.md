# Merging Two Sorted Linked Lists — Fusionar dos listas enlazadas ordenadas en una sola

## Esencia del problema

Se dan dos listas enlazadas ordenadas `list1` y `list2`. El objetivo es fusionarlas en una sola lista enlazada ordenada y devolver el **nodo cabeza** de la lista fusionada.

## Idea central

Se comparan los nodos cabeza de ambas listas y se elige el menor como cabeza del resultado fusionado. La parte restante consiste en fusionar "el siguiente nodo del menor" con "la otra lista", lo cual tiene la misma estructura que el problema original y se puede resolver con recursión.

## Proceso de razonamiento

1. **Cada paso de la fusión realiza la misma operación**: Se comparan los nodos cabeza de ambas listas y se elige el menor. Esta operación se repite hasta que una lista quede vacía. Como la decisión es siempre la misma, se puede expresar con recursión
2. **Considerar el caso base**: Si una de las listas está vacía (null), se devuelve la otra lista tal cual. Si ambas están vacías, se devuelve null (este caso está incluido en el caso de que una sea null)
3. **Considerar el paso recursivo**: Si `list1.val <= list2.val`, entonces `list1` se convierte en la cabeza. A `list1.next` se le conecta el resultado de fusionar "el resto de `list1`" con "todo `list2`". En el caso contrario, se coloca `list2` como cabeza y se procede de la misma forma
4. **Cada llamada recursiva reduce el tamaño del problema en uno**: En cada llamada se consume un nodo de una de las listas, por lo que todos los nodos se procesan en un total de n llamadas recursivas
5. **Lo que se devuelve finalmente**: Cada llamada recursiva devuelve el nodo elegido (`list1` o `list2`). El nodo devuelto por la primera llamada se convierte en la cabeza de la lista fusionada

## Conocimientos previos

### Qué es un ListNode (nodo de lista enlazada)

Es una clase que representa cada elemento de una lista enlazada. El campo `val` almacena el valor y el campo `next` almacena la referencia al siguiente nodo. El nodo cuyo `next` es null es el final de la lista.

```java
class ListNode {
    int val;          // Valor que almacena el nodo
    ListNode next;    // Referencia al siguiente nodo (null si es el último)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### Qué es la recursión (Recursion)

Es una técnica en la que una función se llama a sí misma para resolver un problema. Se descompone un problema grande en subproblemas más pequeños con la misma estructura, y cuando se alcanza el caso base (el subproblema más pequeño que no se puede descomponer más), se devuelve el resultado. Cada llamada apila un marco en la pila de llamadas, por lo que se consume espacio proporcional a la profundidad de la recursión.

```java
// Ejemplo: cálculo del factorial
int factorial(int n) {
    if (n <= 1) return 1;           // Caso base: no se descompone más
    return n * factorial(n - 1);    // Paso recursivo: se reduce el tamaño del problema en uno y se llama a sí misma
}
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Se procesan todos los nodos en n llamadas recursivas, donde n es el número total de nodos de ambas listas |
| Space | O(n) — Cada llamada recursiva apila un marco en la pila de llamadas, alcanzando una profundidad máxima de n |

## Código

```java
// Entrada: los nodos cabeza list1 y list2 de dos listas enlazadas ordenadas
// Salida: se devuelve el nodo cabeza de la lista enlazada ordenada fusionada como ListNode
ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    // Caso base: si list1 está vacía, se devuelve list2 tal cual (como list1 está vacía, list2 es directamente el resultado de la fusión)
    if (list1 == null) return list2;
    // Caso base: si list2 está vacía, se devuelve list1 tal cual (como list2 está vacía, list1 es directamente el resultado de la fusión)
    if (list2 == null) return list1;

    // Se comparan las cabezas de list1 y list2 para decidir cuál nodo se coloca como cabeza del resultado fusionado
    if (list1.val <= list2.val) {
        // Se elige list1 como cabeza y se conecta a list1.next el resultado de fusionar el resto de list1 (list1.next) con todo list2
        list1.next = mergeTwoLists(list1.next, list2);
        return list1; // list1 se convierte en el nodo cabeza del resultado fusionado
    } else {
        // Se elige list2 como cabeza y se conecta a list2.next el resultado de fusionar todo list1 con el resto de list2 (list2.next)
        list2.next = mergeTwoLists(list1, list2.next);
        return list2; // list2 se convierte en el nodo cabeza del resultado fusionado
    }
}
```
