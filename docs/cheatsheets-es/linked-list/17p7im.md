# Detecting a Cycle in a Linked List — Determinar si existe un ciclo en una lista enlazada

## Esencia del problema

Se recibe el nodo inicial `head` de una lista enlazada simple. Si el puntero `next` de algún nodo de la lista apunta a un nodo visitado anteriormente (existe un ciclo), se devuelve `true`; si no existe un ciclo, se devuelve `false`.

## Idea central

Si se avanzan simultáneamente dos punteros a velocidades distintas, cuando existe un ciclo estos se encuentran inevitablemente. Si no existe un ciclo, el puntero rápido alcanza el final primero. Esta propiedad permite detectar un ciclo sin utilizar estructuras de datos adicionales.

## Proceso de razonamiento

1. **Considerar la esencia de un ciclo**: Al recorrer una lista que contiene un ciclo, nunca se alcanza el final (null) y se entra en un bucle infinito. Por el contrario, si no existe un ciclo, siempre se alcanza null y el recorrido termina
2. **Utilizar punteros con diferencia de velocidad**: Se preparan un puntero que avanza de 1 en 1 paso (slow) y otro que avanza de 2 en 2 pasos (fast). Dentro del ciclo, fast reduce la distancia respecto a slow en 1 nodo por cada paso, por lo que inevitablemente se encuentran
3. **Razón por la que el encuentro demuestra la existencia de un ciclo**: Si no existe un ciclo, fast alcanza null antes, por lo que es imposible que slow y fast apunten al mismo nodo. Si se encuentran, significa que existe un ciclo
4. **Definir las condiciones de terminación**: Si fast o fast.next es null, el final de la lista existe y por lo tanto no hay ciclo. Si slow y fast apuntan al mismo nodo, existe un ciclo
5. **Establecer las posiciones iniciales**: Se coloca slow en head y fast en head.next. De esta forma, la condición del while `slow != fast` se cumple desde el inicio y se puede comenzar el recorrido dentro del bucle
6. **Valor de retorno final**: Si slow y fast se encuentran, se devuelve `true`; si fast alcanza null, se devuelve `false`

## Conocimientos previos

### Qué es un ListNode (nodo de una lista enlazada)

Es cada elemento individual que compone una lista enlazada. Cada nodo posee un "valor" y un "puntero al siguiente nodo". El next del último nodo apunta a null (cuando no existe un ciclo).

```java
class ListNode {
    int val;            // Valor que almacena el nodo
    ListNode next;      // Referencia al siguiente nodo (null si no existe)
}

ListNode node = head;       // Obtener el nodo inicial
node.next;                  // Obtener el siguiente nodo
node.next.next;             // Obtener el nodo dos posiciones adelante
```

### Qué es Floyd's Tortoise and Hare (algoritmo de detección de ciclos de Floyd)

Es un algoritmo que detecta ciclos utilizando dos punteros con velocidades distintas. El puntero slow avanza de 1 en 1 paso y el puntero fast avanza de 2 en 2 pasos. Dentro del ciclo, fast se acerca a slow en 1 nodo por cada paso, por lo que si existe un ciclo, ambos se encuentran inevitablemente en un número finito de pasos.

```java
ListNode slow = head;       // Puntero que avanza de 1 en 1 paso
ListNode fast = head.next;  // Puntero que avanza de 2 en 2 pasos
slow = slow.next;           // Avanzar slow en 1 posición
fast = fast.next.next;      // Avanzar fast en 2 posiciones
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Si no existe un ciclo, fast alcanza el final en n/2 pasos; si existe un ciclo, se encuentran dentro de la longitud del ciclo |
| Space | O(1) — Solo se utilizan dos variables de puntero y no se requieren estructuras de datos adicionales |

## Código

```java
// Entrada: nodo inicial head de una lista enlazada simple
// Salida: devuelve true si existe un ciclo, false si no existe
public boolean hasCycle(ListNode head) {
    // Si hay 0 o 1 nodo, no puede existir un ciclo. Se devuelve false y se termina
    if (head == null || head.next == null) {
        return false;
    }

    // Se coloca slow en head y fast en head.next
    // Al colocar fast una posición adelante, la condición del while slow != fast se cumple desde el inicio y se puede entrar al bucle
    ListNode slow = head;
    ListNode fast = head.next;

    // Se repite el bucle hasta que slow y fast se encuentren (al encontrarse, se termina)
    while (slow != fast) {
        // Si fast es null o fast.next es null, el final de la lista existe y por lo tanto no hay ciclo
        if (fast == null || fast.next == null) {
            return false;
        }
        // Se avanza slow en 1 paso y fast en 2 pasos
        // Debido a la diferencia de velocidad, dentro del ciclo fast se acerca a slow en 1 nodo por cada paso
        slow = slow.next;
        fast = fast.next.next;
    }

    // La condición del while slow != fast se volvió falsa = slow y fast se encontraron, por lo tanto existe un ciclo
    return true;
}
```
