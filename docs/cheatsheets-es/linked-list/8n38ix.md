# Removing the Nth Node From the End of a List — Eliminar el N-ésimo nodo desde el final de una lista

## Esencia del problema

Se reciben el nodo inicial `head` de una lista enlazada simple y un entero `n`. Se debe eliminar el **N-ésimo nodo desde el final** de la lista y devolver el nodo inicial de la lista modificada.

## Idea central

Si se avanzan dos punteros simultáneamente con un intervalo de N nodos entre ellos, cuando el puntero adelantado llega al final de la lista, el puntero trasero se encuentra justo antes del nodo que se debe eliminar. Esto permite completar la eliminación con un solo recorrido.

## Proceso de razonamiento

1. **Parece necesario conocer la longitud de la lista para identificar el N-ésimo nodo desde el final**: De forma intuitiva, primero se recorre toda la lista para obtener la longitud L, y luego se busca el nodo en la posición L-N, lo que requiere dos recorridos. Sin embargo, usando dos punteros se puede resolver con un solo recorrido
2. **Se utilizan dos punteros con un intervalo de N nodos**: Se adelanta el puntero fast N posiciones respecto al puntero slow. Al avanzar ambos simultáneamente de uno en uno, cuando fast llega al final de la lista, slow se encuentra exactamente en la posición N+1 desde el final. Es decir, slow apunta al nodo **justo antes** del nodo que se debe eliminar
3. **Razón para agregar un nodo ficticio al inicio**: Cuando el nodo a eliminar es el primer nodo de la lista (el propio head), no existe un "nodo anterior al nodo a eliminar". Al colocar un nodo ficticio antes de head, la eliminación del primer nodo se puede manejar con la misma lógica que la eliminación de cualquier otro nodo
4. **Se adelanta fast N posiciones**: Mediante un bucle for, se avanza fast N veces. En este punto, existen N nodos entre slow y fast
5. **Se avanzan ambos punteros simultáneamente**: Mientras `fast.next != null`, se avanzan slow y fast de uno en uno al mismo tiempo. Cuando el **siguiente** de fast es null, se sale del bucle. En ese momento, fast apunta al último nodo de la lista, y slow apunta al nodo N+1 desde el final (justo antes del nodo a eliminar)
6. **Eliminación del nodo y devolución de la lista**: El siguiente nodo de slow es el nodo a eliminar, por lo que se reasigna el enlace con `slow.next = slow.next.next` para eliminarlo. Finalmente se devuelve `dummy.next`. No se devuelve head directamente porque head podría haber sido el nodo eliminado

## Conocimientos previos

### Qué es un ListNode

Es una clase que representa un nodo de una lista enlazada simple. Cada nodo tiene un valor `val` y una referencia al siguiente nodo `next`. El nodo cuyo `next` es null es el último de la lista.

```java
ListNode node = new ListNode(5);  // Se crea un nodo con valor 5, next es null
node.next = new ListNode(10);     // La lista queda como node → 10 → null
```

### Qué es un nodo ficticio (Sentinel Node)

Es un nodo centinela sin valor que se agrega al inicio de la lista. Incluso cuando se elimina el primer nodo, siempre existe un "nodo anterior al nodo a eliminar", lo que elimina la necesidad de manejar el inicio como un caso especial.

```java
ListNode dummy = new ListNode(0);  // Se crea el nodo ficticio
dummy.next = head;                 // Se enlaza el siguiente del nodo ficticio al inicio original
// Después del procesamiento, dummy.next será el nuevo nodo inicial
```

### Qué es la técnica Two-Pointer (dos punteros)

Es una técnica que mueve dos punteros a diferentes velocidades o intervalos para encontrar eficientemente una posición específica en la lista. En este problema, se mueven dos punteros con un intervalo de N nodos a la misma velocidad para identificar la posición N-ésima desde el final.

```java
ListNode slow = head;
ListNode fast = head;
// Se adelanta fast N posiciones y luego se avanzan ambos simultáneamente
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Solo se necesita un recorrido de la lista |
| Space | O(1) — Solo se utilizan un nodo ficticio y dos punteros |

## Código

```java
// Entrada: el nodo inicial head de una lista enlazada simple y un entero n
// Salida: se devuelve el nodo inicial ListNode de la lista después de eliminar el N-ésimo nodo desde el final
public ListNode removeNthFromEnd(ListNode head, int n) {
    // Se agrega un nodo ficticio con valor 0 al inicio
    // Al colocar el nodo ficticio, incluso para la eliminación del primer nodo existe un "nodo justo antes del nodo a eliminar"
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // Ambos punteros se inician desde el nodo ficticio
    // Al iniciar desde el nodo ficticio, slow queda correctamente posicionado justo antes del nodo a eliminar
    ListNode slow = dummy;
    ListNode fast = dummy;

    // Se adelanta fast N posiciones para crear un intervalo de N nodos entre slow y fast
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }

    // Se avanzan ambos punteros simultáneamente y se detiene cuando fast llega al final de la lista
    // La condición es fast.next != null porque cuando fast llega al último nodo de la lista,
    // slow debe estar posicionado justo antes del nodo a eliminar
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // slow.next es el nodo a eliminar. Se reasigna el puntero siguiente de slow un nodo más adelante para desenlazar el nodo a eliminar de la lista
    slow.next = slow.next.next;

    // Se devuelve dummy.next en lugar de head porque si head era el nodo eliminado, se debe devolver correctamente el nuevo nodo inicial
    return dummy.next;
}
```
