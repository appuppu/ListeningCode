# Reversing Nodes in Groups of K — Invertir los nodos de una lista enlazada en grupos de K

## Esencia del problema

Se proporcionan el nodo inicial `head` de una lista enlazada simple y un entero `k`. Se divide la lista en grupos de `k` nodos desde el inicio y se invierte el orden de los nodos dentro de cada grupo. Si el último grupo tiene menos de `k` nodos, ese grupo se deja tal cual. Se retorna el nodo inicial de la lista modificada.

## Idea central

Se coloca un nodo ficticio al inicio y, utilizando como puntos de referencia el "nodo inmediatamente anterior al grupo" y el "k-ésimo nodo del grupo", se reasignan los punteros dentro de cada grupo uno por uno, logrando así la inversión en el lugar sin memoria adicional.

## Proceso de razonamiento

1. **Es necesario invertir en unidades de grupo**: No se invierte la lista completa, sino grupo por grupo de k nodos. Es decir, la estructura del bucle es: "identificar el rango del grupo actual" → "invertir ese grupo" → "avanzar al siguiente grupo"
2. **Para identificar el rango del grupo se busca el k-ésimo nodo**: Se prepara una función auxiliar `getKth` que busca el nodo que está k posiciones adelante desde la posición actual. Si el k-ésimo nodo no existe (`null`), significa que quedan menos de k nodos, por lo que se termina sin invertir
3. **Es necesario conectar correctamente los grupos después de la inversión**: Al invertir un grupo, el inicio y el final del grupo se intercambian. Es necesario reconectar para que el final del grupo anterior (`groupPrev`) apunte al nuevo inicio después de la inversión (el k-ésimo nodo original)
4. **El nodo ficticio permite manejar la inversión del primer grupo de forma uniforme**: Al invertir el primer grupo, el nodo inicial de la lista cambia. Al colocar un nodo ficticio al inicio, la operación de "el nodo anterior al grupo apunta al nuevo inicio" se puede procesar con la misma lógica tanto para el primer grupo como para los siguientes
5. **La inversión de cada grupo se realiza con la misma técnica estándar de inversión de listas**: Se utilizan dos punteros `prev` y `curr`, y se reasigna `curr.next` a `prev` mientras se avanza nodo por nodo. Sin embargo, al establecer el valor inicial de `prev` como el nodo siguiente al grupo (`groupNext`), el final del grupo invertido se conecta automáticamente con el siguiente grupo
6. **Después de la inversión se actualiza groupPrev y se avanza al siguiente grupo**: El nodo que era el inicio del grupo antes de la inversión (`groupPrev.next`) se convierte en el final del grupo después de la inversión. Este nodo se utiliza como `groupPrev` del siguiente grupo para avanzar a la siguiente iteración

## Conocimientos previos

### Qué es un ListNode

Es una clase que representa un nodo de una lista enlazada simple. Cada nodo tiene un "valor (val)" y un "puntero al siguiente nodo (next)". El nodo cuyo `next` es `null` es el final de la lista.

```java
class ListNode {
    int val;          // Valor almacenado en el nodo
    ListNode next;    // Referencia al siguiente nodo (null si es el final)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### Qué es un nodo ficticio (Dummy Node)

Es una técnica que consiste en agregar un nodo provisional al inicio de la lista. Cuando el nodo inicial puede cambiar, esta técnica elimina la necesidad de manejar casos especiales. `dummy.next` siempre apunta al inicio real de la lista.

```java
ListNode dummy = new ListNode(0);  // El valor puede ser cualquiera
dummy.next = head;                 // El siguiente del nodo ficticio es el inicio real
// ... Se manipula la lista ...
return dummy.next;                 // Se retorna el inicio real después de la manipulación
```

### Operación básica de inversión de una lista enlazada

Se utilizan dos punteros `prev` y `curr`, y se reasigna el `next` de cada nodo para que apunte al nodo anterior.

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode tmp = curr.next;  // Se guarda temporalmente el siguiente nodo
    curr.next = prev;          // Se cambia el siguiente del nodo actual al nodo anterior
    prev = curr;               // Se avanza prev al nodo actual
    curr = tmp;                // Se avanza curr al siguiente nodo
}
// prev es el nodo inicial de la lista invertida
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Se visita cada nodo un número constante de veces (una vez para buscar el k-ésimo y una vez para invertir) |
| Space | O(1) — Solo se utilizan variables de punteros, no se requieren estructuras de datos adicionales |

## Código

```java
// Entrada: nodo inicial head de la lista enlazada y un entero k
// Salida: se retorna el nodo inicial de la lista enlazada con los grupos de k nodos invertidos
public ListNode reverseKGroup(ListNode head, int k) {
    // Se crea un nodo ficticio y se conecta al inicio real de la lista con dummy.next = head
    // Al usar un nodo ficticio, el "nodo anterior al grupo" siempre existe incluso al invertir el primer grupo
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // groupPrev apunta al "nodo inmediatamente anterior al grupo que se va a invertir"
    // El valor inicial es el nodo ficticio
    ListNode groupPrev = dummy;

    // En un bucle infinito se invierte un grupo en cada iteración
    while (true) {
        // Se parte del nodo siguiente a groupPrev y se recorre next k-1 veces para encontrar el k-ésimo nodo
        // Si se alcanza null en el camino, significa que quedan menos de k nodos, por lo que se retorna null
        ListNode kth = getKth(groupPrev, k);

        // Si el k-ésimo nodo no existe, quedan menos de k nodos, por lo que se termina tal cual
        // Esta verificación cumple el requisito del problema de dejar los grupos con menos de k nodos sin modificar
        if (kth == null) break;

        // groupNext es el "nodo inmediatamente después del grupo actual" y se usa como marca de fin de la inversión
        ListNode groupNext = kth.next;

        // Se establece el valor inicial de prev como groupNext
        // De esta manera, el next del último nodo del grupo invertido apunta automáticamente al inicio del siguiente grupo
        ListNode prev = kth.next;
        // curr comienza desde el nodo inicial del grupo (que se convertirá en el último nodo del grupo después de la inversión)
        ListNode curr = groupPrev.next;

        // Se invierten los punteros next de cada nodo dentro del grupo hasta que curr sea igual a groupNext
        // Esta operación hace que el next de cada nodo apunte al nodo anterior
        while (curr != groupNext) {
            ListNode tmp = curr.next;  // Se guarda temporalmente el siguiente nodo
            curr.next = prev;          // Se cambia el siguiente del nodo actual al nodo anterior
            prev = curr;               // Se avanza prev al nodo actual
            curr = tmp;                // Se avanza curr al siguiente nodo
        }

        // Se guarda el nodo que era el inicio antes de la inversión (ahora es el final del grupo)
        ListNode tmp = groupPrev.next;
        // El nuevo inicio del grupo invertido es kth (el k-ésimo nodo original),
        // por lo que se reconecta para que el final del grupo anterior apunte correctamente al nuevo inicio
        groupPrev.next = kth;
        // El nodo que era el inicio del grupo antes de la inversión ahora es el final del grupo
        // Este nodo se usa como groupPrev para la siguiente iteración
        groupPrev = tmp;
    }

    // dummy.next apunta al nodo inicial de la lista completa después de la manipulación
    return dummy.next;
}

// Se retorna el k-ésimo nodo a partir del siguiente nodo de node. Si hay menos de k nodos, se retorna null
private ListNode getKth(ListNode node, int k) {
    // Se parte del nodo siguiente a node
    node = node.next;
    // Se recorre next k-1 veces para alcanzar el k-ésimo nodo
    // Si se alcanza null en el camino, significa que quedan menos de k nodos
    while (node != null && k > 1) {
        node = node.next;
        k--;
    }
    // Se retorna el k-ésimo nodo (null si había menos de k nodos)
    return node;
}
```
