# Finding the Subarray With Maximum Product — Encontrar el subarreglo contiguo con el producto máximo

## Esencia del problema

Se da un arreglo de enteros `nums`. Se debe seleccionar un **subarreglo contiguo** dentro del arreglo cuyo producto de elementos sea máximo, y devolver dicho **producto**. Un subarreglo se compone de uno o más elementos consecutivos.

## Idea central

Dado que el producto de dos números negativos resulta en un número positivo, el valor mínimo actual (el negativo de mayor magnitud) puede convertirse en el valor máximo al multiplicarse por el siguiente número negativo. Por esta razón, es necesario rastrear tanto el "producto máximo actual" como el "producto mínimo actual" en cada posición.

## Proceso de razonamiento

1. **Considerar las propiedades del producto de subarreglos**: En un problema que busca el producto de un subarreglo contiguo, cada vez que se agrega un elemento se puede calcular el nuevo producto como "producto del subarreglo anterior × elemento actual". Este enfoque es igual al de la programación dinámica (DP), donde se deriva el siguiente estado a partir del estado anterior
2. **Los números negativos complican el cálculo del producto máximo**: Si solo hubiera números positivos, bastaría con rastrear únicamente el producto máximo. Sin embargo, con números negativos puede ocurrir que "un producto negativo grande × un número negativo = un producto positivo grande". Es decir, si no se rastrea también el producto mínimo actual (el valor más grande en dirección negativa), se podría pasar por alto el producto máximo
3. **Los candidatos en cada posición se reducen a tres**: Los candidatos para el producto máximo en la posición `i` son: (a) `nums[i]` solo (cuando se inicia un nuevo subarreglo), (b) `curMax * nums[i]` (cuando se extiende el producto máximo positivo), y (c) `curMin * nums[i]` (cuando el producto mínimo negativo se invierte con un número negativo). El máximo de estos tres valores se convierte en el nuevo `curMax`
4. **El producto mínimo se elige de los mismos tres candidatos**: Los candidatos para el producto mínimo son los mismos tres valores, y el mínimo de ellos se convierte en el nuevo `curMin`. Al actualizar simultáneamente el máximo y el mínimo, se captura correctamente la inversión causada por los números negativos
5. **Guardar el valor anterior antes de actualizar**: Si se calcula `curMin` después de actualizar `curMax`, el valor previo de `curMax` ya no estaría disponible para el cálculo de `curMin`. Por eso, antes de actualizar `curMax`, se guarda su valor en una variable temporal `temp`, y se usa `temp` al calcular `curMin`
6. **Gestionar el máximo global en una variable separada**: `curMax` es el producto máximo en la posición actual, no el producto máximo de todo el arreglo. En cada posición se actualiza el máximo global con `result = Math.max(result, curMax)`, y finalmente se devuelve `result`

## Conocimientos previos

### Relación entre el producto de subarreglos y DP

El producto de un subarreglo se puede extender multiplicando el producto hasta la posición anterior por el elemento actual. Aprovechando esta propiedad, se puede calcular en O(1) el "producto máximo del subarreglo que termina aquí" a partir del resultado de la posición anterior. Este es un método que, al igual que la DP, retiene el estado anterior para derivar el siguiente estado.

### Qué son Math.max / Math.min

Son métodos de Java que obtienen el valor máximo o mínimo entre varios valores. Para comparar tres o más valores, se anidan las llamadas.

```java
Math.max(3, 7);                   // Devuelve el máximo de dos valores → 7
Math.min(3, 7);                   // Devuelve el mínimo de dos valores → 3
Math.max(a, Math.max(b, c));      // Devuelve el máximo de tres valores
Math.min(a, Math.min(b, c));      // Devuelve el mínimo de tres valores
```

### Por qué es necesario rastrear el valor mínimo

En arreglos que contienen números negativos, el signo del producto se invierte con cada elemento. Ejemplo: en `[-2, 3, -4]`, el producto mínimo en la posición 1 es `-2 × 3 = -6`, pero en la posición 2, `-6 × -4 = 24` se convierte en el producto máximo. Si solo se rastrea el producto máximo, se descartaría `-6` y se pasaría por alto `24`.

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Solo se requiere un recorrido del arreglo |
| Space | O(1) — Solo se utilizan un número fijo de variables, sin depender del tamaño de la entrada |

## Código

```java
// Entrada: arreglo de enteros nums (longitud 1 o más)
// Salida: devuelve como int el producto máximo de un subarreglo contiguo
public int maxProduct(int[] nums) {
    // result=producto máximo global, curMax=producto máximo del subarreglo que termina en la posición actual, curMin=producto mínimo del mismo
    // El estado inicial es el subarreglo que consiste únicamente en el primer elemento
    int result = nums[0];
    int curMax = nums[0];
    int curMin = nums[0];

    // i=0 ya se procesó en la inicialización, por lo que se comienza desde i=1
    for (int i = 1; i < nums.length; i++) {
        int n = nums[i];
        // Se guarda curMax antes de actualizarlo (porque el cálculo de curMin necesita el valor previo)
        int temp = curMax;

        // Se elige el máximo entre tres candidatos:
        // n solo → cuando se inicia un nuevo subarreglo
        // temp * n → cuando se extiende el producto máximo anterior
        // curMin * n → cuando el producto mínimo anterior (negativo) se invierte con un n negativo y se convierte en el máximo
        curMax = Math.max(n,
            Math.max(temp * n, curMin * n));

        // Se elige el mínimo entre los mismos tres candidatos (usando temp con el curMax previo a la actualización, se calcula correctamente sin verse afectado por la actualización anterior)
        curMin = Math.min(n,
            Math.min(temp * n, curMin * n));

        // curMax es el producto máximo en la posición actual, no el máximo global, por lo que se gestiona el máximo global en la variable separada result
        result = Math.max(result, curMax);
    }
    // result contiene el producto máximo de subarreglo a lo largo de todo el arreglo
    return result;
}
```
