# Counting Ways to Climb Stairs — Encontrar el número total de formas de subir una escalera de n escalones subiendo de 1 o 2 escalones a la vez

## Esencia del problema

Se recibe un entero `n` (el número de escalones). Si se puede subir 1 o 2 escalones a la vez, el programa debe devolver el **número total de formas distintas** de llegar a la cima (el escalón n).

## Idea central

Para llegar al escalón n, solo existen dos opciones: "subir 1 escalón desde el escalón n-1" o "subir 2 escalones desde el escalón n-2". Es decir, se cumple la recurrencia `ways(n) = ways(n-1) + ways(n-2)`, que es la misma que la de la secuencia de Fibonacci. Si solo se conservan los dos valores anteriores, se puede calcular el resultado en O(1) de espacio sin usar un arreglo.

## Proceso de razonamiento

1. **Razonar hacia atrás desde el último paso**: El estado inmediatamente anterior a llegar al escalón n es "estar en el escalón n-1" o "estar en el escalón n-2". Por lo tanto, el número total de formas de llegar al escalón n se expresa con la recurrencia `ways(n) = ways(n-1) + ways(n-2)`
2. **Definir los casos base**: Una escalera de 1 escalón tiene 1 forma (subir 1 escalón), y una escalera de 2 escalones tiene 2 formas (1+1 o 2). Estos dos valores son el punto de partida de la recurrencia
3. **Calcular de abajo hacia arriba (bottom-up)**: Si se calcula recursivamente desde arriba, se resuelven los mismos subproblemas múltiples veces. En cambio, si se adopta el enfoque bottom-up calculando desde los valores más pequeños, cada valor se calcula una sola vez
4. **Solo se necesitan 2 variables**: La recurrencia `ways(i) = ways(i-1) + ways(i-2)` solo hace referencia a los 2 valores anteriores. No es necesario conservar todo el arreglo; basta con 2 variables (`prev2` y `prev1`)
5. **Actualizar las variables en un bucle**: Desde `i = 3` hasta `n`, se calcula el valor actual con `curr = prev1 + prev2`, y luego se desplazan las variables asignando `prev2 = prev1` y `prev1 = curr` para preparar la siguiente iteración
6. **Qué devolver al final**: Al terminar el bucle, `prev1` contiene el número total de formas de subir al escalón n, por lo que se devuelve `prev1`

## Conocimientos previos

### ¿Qué es la Programación Dinámica (Dynamic Programming)?

Es una técnica que divide un problema grande en subproblemas más pequeños y los resuelve registrando el resultado de cada subproblema. Al no repetir los mismos cálculos, se logra mayor eficiencia. En el enfoque bottom-up, se resuelven los subproblemas desde el más pequeño en adelante.

```java
// Patrón básico de DP bottom-up (versión con arreglo)
int[] dp = new int[n + 1];   // Arreglo para almacenar los resultados de los subproblemas
dp[1] = 1;                    // Caso base 1
dp[2] = 2;                    // Caso base 2
for (int i = 3; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];  // Se calcula con la recurrencia
}
// dp[n] es la respuesta final
```

### ¿Qué son las variables deslizantes?

Es una técnica que conserva los valores anteriores usando solo 2 variables en lugar de un arreglo. Cuando la recurrencia hace referencia a una cantidad fija de valores pasados, no es necesario conservar el arreglo completo, y se puede reducir la complejidad espacial de O(n) a O(1).

```java
int prev2 = 1;  // Variable que conserva el valor de 2 posiciones atrás
int prev1 = 2;  // Variable que conserva el valor de 1 posición atrás
int curr = prev1 + prev2;  // Se calcula el valor actual
prev2 = prev1;  // Se desliza prev2 (hereda el valor de prev1)
prev1 = curr;   // Se desliza prev1 (hereda el valor de curr)
```

## Complejidad

| | Valor |
|---|---|
| Time | O(n) — Solo se necesita un bucle de 3 a n |
| Space | O(1) — Solo se usan 2 variables (prev2, prev1) |

## Código

```java
// Entrada: un entero n (el número de escalones)
// Salida: se devuelve como int el número total de formas distintas de llegar a la cima
public int climbStairs(int n) {
    // Caso base: si hay 1 escalón, solo existe 1 forma. Se procesa n=1 primero porque el bucle posterior comienza en i=3
    if (n == 1) return 1;

    // prev2 es el número total de formas del escalón 2 posiciones atrás. El valor inicial corresponde a las formas del escalón 1 (1 forma)
    int prev2 = 1;
    // prev1 es el número total de formas del escalón 1 posición atrás. El valor inicial corresponde a las formas del escalón 2 (2 formas: 1+1 o 2)
    int prev1 = 2;

    // i es el número del escalón que se está calculando actualmente. Los escalones 1 y 2 ya se establecieron como valores iniciales, por lo que se comienza desde el escalón 3
    for (int i = 3; i <= n; i++) {
        // Recurrencia: formas del escalón i = formas del escalón (i-1) + formas del escalón (i-2)
        int curr = prev1 + prev2;
        // Nota: se debe actualizar prev2 antes, para no perder el valor original de prev1
        prev2 = prev1;
        prev1 = curr;
    }

    // Al terminar el bucle, prev1 contiene el número total de formas de subir al escalón n
    return prev1;
}
```
