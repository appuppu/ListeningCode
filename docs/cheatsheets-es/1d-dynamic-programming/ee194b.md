# Maximizing Robbery Loot in a Circular Neighborhood — Robar la cantidad máxima de dinero de casas dispuestas en círculo sin elegir casas adyacentes

## Esencia del problema

Se proporciona un arreglo de enteros no negativos `nums`. Cada elemento representa la cantidad de dinero en una casa dispuesta en forma circular. No se pueden robar dos casas adyacentes de forma consecutiva. Se debe devolver la cantidad máxima de dinero que se puede robar, **considerando que la primera casa y la última casa también son adyacentes**.

## Idea central

La restricción circular se reduce a "no se pueden elegir la primera casa y la última casa al mismo tiempo". Por lo tanto, se resuelve la versión lineal de House Robber dos veces: una para "el rango que incluye la primera casa y excluye la última" y otra para "el rango que incluye la última casa y excluye la primera". Se toma el mayor de los dos resultados para satisfacer la restricción circular.

## Proceso de razonamiento

1. **Descomponer la restricción circular**: En un arreglo circular, `nums[0]` y `nums[n-1]` son adyacentes. Es decir, no se pueden elegir ambos al mismo tiempo. Esto se descompone en dos casos: "si se elige `nums[0]`, no se puede elegir `nums[n-1]`" y "si se elige `nums[n-1]`, no se puede elegir `nums[0]`"
2. **Reducir a dos problemas lineales**: El caso 1 resuelve House Robber lineal en el rango `nums[0..n-2]` (incluye la primera, excluye la última). El caso 2 lo resuelve en el rango `nums[1..n-1]` (excluye la primera, incluye la última). El mayor de los dos resultados es la respuesta
3. **Establecer la recurrencia de la versión lineal**: Para cada casa `i`, existen dos opciones: "robar la casa `i`" o "no robarla". Si se roba, el valor es `nums[i] + dp[i-2]` (se salta la anterior). Si no se roba, el valor es `dp[i-1]` (se hereda el máximo hasta la anterior). Por lo tanto, `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
4. **Reducir el espacio a constante**: La recurrencia solo hace referencia a `dp[i-1]` y `dp[i-2]`. No es necesario mantener todo el arreglo DP; basta con dos variables: `prev1` (máximo de la posición anterior) y `prev2` (máximo de dos posiciones atrás)
5. **Manejar los casos límite**: Si el arreglo está vacío, se devuelve 0. Si tiene un solo elemento, la restricción circular no aplica, por lo que se devuelve ese valor. Solo cuando hay dos o más elementos se ejecuta el procesamiento en dos pasadas
6. **Valor que se devuelve al final**: Se selecciona con `Math.max` la mayor de las cantidades máximas obtenidas en cada uno de los dos rangos

## Conocimientos previos

### Qué es House Robber (versión lineal)

Es un problema en el que se busca obtener la cantidad máxima de dinero de casas dispuestas en línea, sin elegir casas adyacentes de forma consecutiva. Es un problema básico de DP que se resuelve con la recurrencia `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`. La versión circular se resuelve aplicando la versión lineal dos veces.

### Optimización de espacio en DP mediante variables rodantes

Es una técnica que consiste en mantener como variables solo los últimos valores que la recurrencia necesita del arreglo DP. Al no necesitar mantener el arreglo completo, se reduce la complejidad espacial de O(n) a O(1).

```java
int prev2 = 0, prev1 = 0;        // Se inicializan las variables equivalentes a dp[i-2] y dp[i-1]
int curr = Math.max(prev1, prev2 + nums[i]);  // Se calcula dp[i]
prev2 = prev1;                    // Se avanza prev2 una posición (el antiguo prev1 se convierte en el nuevo prev2)
prev1 = curr;                     // Se avanza prev1 una posición (curr se convierte en el nuevo prev1)
```

### Qué es Math.max

Es un método estándar de Java que devuelve el mayor de dos valores. Se utiliza en la transición del DP para elegir el valor máximo entre "el caso de robar" y "el caso de no robar".

```java
Math.max(5, 3);   // → 5 (devuelve el mayor de los dos)
Math.max(prev1, prev2 + nums[i]);  // Se elige el máximo entre el caso de no robar y el caso de robar
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Se recorre el arreglo dos veces, pero cada recorrido es O(n), por lo que el total es O(n) |
| Space | O(1) — No se utiliza un arreglo DP; se calcula únicamente con dos variables rodantes |

## Código

```java
// Entrada: un arreglo de enteros no negativos nums (cantidad de dinero en cada casa dispuesta en círculo)
// Salida: se devuelve como int la cantidad máxima de dinero que se puede robar sin robar casas adyacentes de forma consecutiva

// Método auxiliar que resuelve la versión lineal de House Robber para un rango especificado (start a end)
private int robRange(int[] nums, int start, int end) {
    // Se inicializa en 0 porque la cantidad de dinero cuando no se roba ninguna casa es 0
    int prev2 = 0, prev1 = 0;  // Variables rodantes que almacenan la cantidad máxima de dos posiciones atrás y una posición atrás
    // Se recorre uno por uno desde el inicio hasta el final del rango especificado
    for (int i = start; i <= end; i++) {
        // prev1: opción de no robar la casa i, heredando el máximo hasta la posición anterior
        // prev2 + nums[i]: opción de robar la casa i, sumando la cantidad actual al máximo hasta dos posiciones atrás
        int curr = Math.max(prev1,
            prev2 + nums[i]);
        // Se avanzan las variables rodantes una posición (en la siguiente iteración, curr asume el rol de prev1 y prev1 asume el rol de prev2)
        prev2 = prev1;
        prev1 = curr;
    }
    // prev1 contiene la cantidad máxima considerando todo el rango especificado
    return prev1;
}

public int rob(int[] nums) {
    int n = nums.length;
    if (n == 0) return 0;        // Si no hay casas, se devuelve 0
    if (n == 1) return nums[0];  // Si hay una sola casa, la restricción de adyacencia no aplica, por lo que ese valor es directamente la respuesta

    // Se descompone la restricción circular en dos problemas lineales y se devuelve el mayor de los dos
    // Se garantiza que la primera y la última casa no se eligen al mismo tiempo, satisfaciendo así la restricción circular
    return Math.max(
        robRange(nums, 0, n - 2),   // Rango que incluye la primera casa y excluye la última (índices 0 a n-2)
        robRange(nums, 1, n - 1));  // Rango que excluye la primera casa e incluye la última (índices 1 a n-1)
}
```
