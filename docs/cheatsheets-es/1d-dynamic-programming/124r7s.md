# Partitioning an Array Into Two Equal Sum Subsets — Determinar si un arreglo se puede dividir en dos subconjuntos con sumas iguales

## Esencia del problema

Se recibe un arreglo de enteros `nums`. Se debe devolver un `boolean` que indique si es posible dividir este arreglo en dos subconjuntos de modo que la suma de los elementos de cada subconjunto sea igual. Cada elemento debe pertenecer exactamente a uno de los dos subconjuntos y no se puede usar de forma duplicada.

## Idea central

Si la suma total del arreglo es impar, se puede determinar inmediatamente que el resultado es false. Si la suma es par, el problema se reduce a un "problema de suma de subconjuntos": determinar si existe un subconjunto cuya suma sea exactamente la mitad del total, es decir, `target`. Utilizando un arreglo DP unidimensional de tipo boolean y procesando cada elemento en orden mientras se registran las sumas alcanzables, se puede determinar si se alcanza `target` en O(n × target).

## Proceso de razonamiento

1. **Considerar la condición para dividir en dos partes iguales**: Cuando la suma total del arreglo es `sum`, para que las sumas de los dos subconjuntos sean iguales, la suma de cada subconjunto debe ser `sum / 2`. Si `sum` es impar, no se puede dividir en dos enteros iguales, por lo que se devuelve false inmediatamente
2. **Convertir el problema en un "problema de suma de subconjuntos"**: Si la suma de uno de los subconjuntos es `target = sum / 2`, la suma del otro subconjunto también será automáticamente `target`. Es decir, el problema se reduce a determinar si existe un subconjunto de los elementos del arreglo cuya suma sea `target`
3. **Gestionar las sumas alcanzables con DP**: Se prepara un arreglo booleano `dp`, donde `dp[j]` indica si es posible obtener la suma `j` a partir de los elementos procesados hasta el momento. Como estado inicial, se establece `dp[0] = true` (si no se selecciona ningún elemento, la suma es 0)
4. **Actualizar las sumas alcanzables con cada elemento**: Para cada elemento `num` del arreglo, si una suma `j` ya es alcanzable, entonces `j + num` también se vuelve alcanzable. Esta operación consiste en establecer `dp[j + num]` como true si `dp[j]` es true
5. **Recorrer en orden inverso para evitar el uso duplicado**: El bucle interno se recorre en orden inverso desde `target` hasta `num`. Si se recorriera en orden directo, el arreglo `dp` se actualizaría con resultados que usan el mismo elemento varias veces. Al recorrer en orden inverso, cada elemento se usa como máximo una sola vez
6. **Devolver `dp[target]` como resultado final**: Después de procesar todos los elementos, si `dp[target]` es true, existe un subconjunto con suma `target`, por lo que se devuelve true; si es false, dicho subconjunto no existe

## Conocimientos previos

### ¿Qué es el problema de suma de subconjuntos (Subset Sum Problem)?

Es un problema que consiste en determinar si, dado un conjunto de enteros, es posible seleccionar algunos elementos cuya suma sea exactamente igual a un valor objetivo. Es un problema representativo que se resuelve eficientemente mediante DP (programación dinámica).

### ¿Qué es un arreglo DP unidimensional de tipo boolean?

Es un arreglo donde `dp[j]` indica con true/false si es posible obtener la suma `j`. Cada vez que se procesa un elemento, el conjunto de sumas alcanzables se expande.

```java
boolean[] dp = new boolean[target + 1];  // Crear un arreglo de tamaño target+1 (valor inicial: todo false)
dp[0] = true;                            // Si no se selecciona nada, la suma 0 siempre es alcanzable
dp[j - num] == true                      // Si se puede obtener la suma j-num, al sumar num también se puede obtener la suma j
```

### Razón para actualizar el arreglo DP en orden inverso

Si se actualiza en orden directo (de `j` pequeño a `j` grande), se propagan resultados que usan el mismo elemento `num` varias veces. Si se actualiza en orden inverso (de `j` grande a `j` pequeño), se garantiza que cada elemento se usa solo una vez.

```java
// Bucle en orden inverso: j disminuye de 1 en 1 desde target hasta num
for (int j = target; j >= num; j--) {
    if (dp[j - num]) dp[j] = true;
}
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n × target) — Para cada uno de los n elementos, se recorre el arreglo DP hasta un máximo de target |
| Space | O(target) — Se utiliza un solo arreglo DP de tipo boolean con tamaño target+1 |

## Código

```java
// Entrada: arreglo de enteros nums
// Salida: devuelve un boolean que indica si el arreglo se puede dividir en dos subconjuntos con sumas iguales
boolean canPartition(int[] nums) {
    // Calcular la suma total de todos los elementos del arreglo para obtener el valor de referencia que determina si la división en dos partes iguales es posible
    int sum = 0;
    for (int n : nums) sum += n;

    // Si la suma es impar, no se puede dividir en dos enteros iguales, por lo que se devuelve false
    if (sum % 2 != 0) return false;

    // Valor objetivo de suma que un subconjunto debe alcanzar. El otro subconjunto automáticamente también será target
    int target = sum / 2;

    // dp[j] = indica si es posible obtener la suma j a partir de los elementos procesados hasta el momento (arreglo DP del problema de suma de subconjuntos)
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;  // Si no se selecciona nada, la suma 0 siempre es alcanzable

    // Procesar cada elemento del arreglo uno por uno desde el inicio hasta el final, actualizando el conjunto de sumas alcanzables
    for (int num : nums) {
        // Recorrer en orden inverso para evitar el uso duplicado del mismo elemento (en orden directo se propagarían resultados que suman num varias veces)
        for (int j = target; j >= num; j--) {
            // Si se puede obtener la suma j-num, al sumar num también se puede obtener la suma j, por lo que se actualiza a true
            if (dp[j - num]) dp[j] = true;
        }
    }

    // Si dp[target] es true, existe un subconjunto con suma target, por lo que la división en dos partes iguales es posible
    return dp[target];
}
```
