# Maximizing Robbery Loot Without Adjacent Houses — Encontrar el monto máximo que se puede robar evitando casas adyacentes

## Esencia del problema

Se da un arreglo de enteros `nums`, donde cada elemento representa el monto de dinero en cada casa a lo largo de una calle. Bajo la restricción de que no se pueden robar dos casas adyacentes, se debe devolver el **monto máximo** que se puede robar en una noche. Si se roba la casa `i`, no se pueden robar las casas `i-1` ni `i+1`.

## Idea central

Para cada casa existen dos opciones: "robar o no robar". Si se roba, se suma el monto actual al máximo acumulado hasta dos casas antes. Si no se roba, se mantiene el máximo acumulado hasta la casa anterior. Dado que solo se necesitan los dos valores previos para tomar esta decisión, se puede calcular con solo dos variables sin necesidad de un arreglo.

## Proceso de razonamiento

1. **Se necesita una decisión óptima de "robar/no robar" en cada casa**: Si se roba la casa `i`, no se puede robar la casa `i-1`, por lo que se obtiene el valor de sumar `nums[i]` al máximo hasta la casa `i-2`. Si no se roba, se mantiene el máximo hasta la casa `i-1`. Es decir, el máximo en cada casa se expresa como `max(máximo hasta casa i-1, máximo hasta casa i-2 + nums[i])`
2. **Se establece una recurrencia**: Con la recurrencia `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`, se puede calcular el monto máximo hasta cada casa secuencialmente desde el inicio. Esta es una estructura típica de programación dinámica
3. **Solo se necesitan los dos valores previos**: Al observar la recurrencia, el cálculo de `dp[i]` solo utiliza `dp[i-1]` y `dp[i-2]`. No es necesario mantener el arreglo completo; dos variables (`prev1` y `prev2`) son suficientes
4. **Considerar el orden de actualización de las variables**: Después de calcular `curr`, en la siguiente iteración el `prev1` actual se convierte en el nuevo `prev2`, y `curr` se convierte en el nuevo `prev1`. Actualizando en este orden se evita sobrescribir los valores
5. **Establecer los valores iniciales**: Antes de iniciar el recorrido, se establece `prev1 = 0` (máximo de la casa anterior) y `prev2 = 0` (máximo de dos casas antes). Con 0 casas el resultado es 0, y para la primera casa se obtiene `max(0, 0 + nums[0]) = nums[0]`, lo cual es correcto
6. **Qué se devuelve al final**: Después de recorrer todas las casas, `prev1` contiene el monto máximo total

## Conocimientos previos

### ¿Qué es la programación dinámica (Dynamic Programming)?

Es una técnica que divide un problema grande en subproblemas más pequeños y reutiliza las soluciones de cada subproblema para construir la solución global. Cuando existen subproblemas superpuestos, se evita repetir los mismos cálculos. En este problema, "el monto máximo hasta la casa `i`" corresponde a un subproblema.

### ¿Qué es Math.max?

Es un método estándar de Java que devuelve el mayor de dos valores. Permite escribir una bifurcación condicional en una sola línea.

```java
Math.max(5, 3);    // → 5 (devuelve el mayor de los dos)
Math.max(prev1, prev2 + num);  // devuelve el mayor entre prev1 y prev2+num
```

### ¿Qué es el bucle for extendido (for-each)?

Es una estructura de bucle que extrae y procesa uno por uno todos los elementos de un arreglo desde el inicio hasta el final. Se accede directamente a los elementos sin utilizar índices.

```java
int[] nums = {2, 7, 9, 3};
for (int num : nums) {   // asigna cada elemento de nums a num y ejecuta el bucle
    System.out.println(num);  // se imprime 2, 7, 9, 3 en orden
}
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Solo se necesita un recorrido del arreglo |
| Space | O(1) — Solo se utilizan dos variables, sin depender del tamaño de la entrada |

## Código

```java
// Entrada: arreglo de enteros nums (monto de cada casa)
// Salida: devuelve como int el monto máximo que se puede robar bajo la restricción de no robar casas adyacentes
public int rob(int[] nums) {
    // prev2: monto máximo hasta dos casas antes. Es 0 antes de iniciar el recorrido porque no existen casas
    int prev2 = 0;
    // prev1: monto máximo hasta la casa anterior. Igualmente es 0 antes de iniciar el recorrido
    int prev1 = 0;

    // Se recorre el arreglo nums elemento por elemento desde el inicio hasta el final con un bucle for extendido
    for (int num : nums) {
        // Se elige el mayor entre "no robar la casa actual (prev1)" y "robar la casa actual (prev2+num)"
        // Se usa prev2 al robar la casa actual porque no se puede robar la casa adyacente representada por prev1
        int curr = Math.max(prev1,
            prev2 + num);
        // Se desplazan las variables para la siguiente iteración
        // El prev1 actual (máximo de la casa anterior) se convierte en el máximo de dos casas antes en la siguiente iteración
        prev2 = prev1;
        // El curr recién calculado (máximo hasta la casa actual) se convierte en el máximo de la casa anterior en la siguiente iteración
        // Nota: esta actualización se realiza después de prev2 = prev1. Si se actualiza prev1 primero, no se puede asignar el valor correcto a prev2
        prev1 = curr;
    }
    // Se devuelve el monto máximo considerando todas las casas. prev1 almacena el monto máximo considerando hasta la última casa
    return prev1;
}
```
