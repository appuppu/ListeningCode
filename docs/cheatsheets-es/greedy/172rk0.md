# Checking Validity of a Parenthesis String With Wildcards — Determinar la validez de una cadena de paréntesis con comodines

## Esencia del problema

Se recibe una cadena compuesta únicamente por tres tipos de caracteres: `(`, `)` y `*`. El carácter `*` puede tratarse como `(`, `)` o como una cadena vacía. El objetivo es determinar si la cadena puede convertirse en una **secuencia válida de paréntesis** y devolver un `boolean`.

## Idea central

Dado que la interpretación de `*` es indeterminada, se rastrea la cantidad de paréntesis abiertos no como un único valor, sino como un **rango de valores posibles (mínimo low ~ máximo high)**. Si este rango se mantiene válido durante todo el recorrido y al final contiene el valor 0, la cadena es válida.

## Proceso de razonamiento

1. **La validez de los paréntesis se determina contando los paréntesis abiertos**: Se recorre la cadena de izquierda a derecha, sumando +1 por cada `(` y -1 por cada `)`. Si el contador se vuelve negativo en algún momento, la cadena es inválida; si al final es 0, la cadena es válida. Este es el principio básico de la validación de paréntesis
2. **Con `*`, el contador no se fija en un único valor**: Como `*` admite tres interpretaciones, el contador no es un valor único sino un "rango". Si se interpreta `*` como `(`, el contador sube +1; si se interpreta como `)`, baja -1; si se interpreta como cadena vacía, no cambia. Es decir, cada vez que se encuentra un `*`, el rango se amplía
3. **Se rastrea el rango con dos variables**: `low` representa el valor mínimo del contador de paréntesis abiertos (cuando se interpretan los `*` como `)` o cadena vacía en la mayor medida posible), y `high` representa el valor máximo (cuando se interpretan los `*` como `(` en la mayor medida posible). Con solo estas dos variables se cubren todos los patrones posibles
4. **Si `high` se vuelve negativo durante el recorrido, la cadena es inmediatamente inválida**: Dado que `high` es el valor máximo del contador de paréntesis abiertos, que se vuelva negativo significa que, sin importar cómo se interpreten los `*`, hay un exceso de `)` y la cadena no puede ser una secuencia válida de paréntesis
5. **Si `low` se vuelve negativo, se ajusta a 0**: Que `low` sea negativo solo indica que se está incluyendo una interpretación donde sobran `)`, pero si se interpreta `*` como cadena vacía, el contador se puede mantener en 0 o más. Los valores negativos corresponden a interpretaciones que en la práctica no se eligen, por lo que se corrige `low` a 0
6. **Al final, se determina el resultado verificando si `low == 0`**: Si al completar el recorrido `low` es 0, significa que "existe una interpretación en la que todos los paréntesis abiertos se cierran", por lo que se devuelve `true`

## Conocimientos previos

### Principio básico de validación de secuencias de paréntesis

Se recorre la cadena de izquierda a derecha gestionando un contador de paréntesis abiertos. Se suma +1 por `(` y se resta -1 por `)`. Si el contador no se vuelve negativo en ningún momento y al final es 0, la secuencia de paréntesis es válida.

```java
int count = 0;
for (char c : s.toCharArray()) {
    if (c == '(') count++;
    else count--;
    if (count < 0) return false;  // Exceso de paréntesis de cierre
}
return count == 0;  // Todos los paréntesis abiertos se cerraron
```

### Qué es Math.max

Es un método que devuelve el mayor de dos valores. Se utiliza para corregir (clampear) un valor de modo que no caiga por debajo de un límite inferior determinado.

```java
Math.max(3, 0);    // → 3 (3 es mayor o igual a 0, se mantiene tal cual)
Math.max(-1, 0);   // → 0 (-1 es menor que 0, se corrige a 0)
```

### Qué es toCharArray

Es un método que convierte una cadena en un arreglo de `char`. Se utiliza para recorrer una cadena carácter por carácter mediante un bucle for-each.

```java
String s = "(*)";
char[] chars = s.toCharArray();  // → ['(', '*', ')']
for (char c : s.toCharArray()) {
    // Se asigna un carácter a c en cada iteración del bucle
}
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Solo se necesita un único recorrido de la cadena |
| Space | O(1) — Solo se utilizan las dos variables `low` y `high` |

## Código

```java
// Entrada: cadena s compuesta únicamente por '(', ')' y '*'
// Salida: devuelve un boolean indicando si la cadena puede ser una secuencia válida de paréntesis
public boolean checkValidString(String s) {
    // low: valor mínimo del contador de paréntesis abiertos, high: valor máximo
    // Con estas dos variables se rastrea el rango del contador para todas las interpretaciones de *
    int low = 0, high = 0;

    // Se recorre la cadena carácter por carácter desde el inicio
    for (char c : s.toCharArray()) {
        if (c == '(') {
            // Paréntesis de apertura: en cualquier interpretación el contador sube 1, así que se suma +1 a ambos extremos del rango
            low++;
            high++;
        } else if (c == ')') {
            // Paréntesis de cierre: en cualquier interpretación el contador baja 1, así que se resta -1 a ambos extremos del rango
            low--;
            high--;
        } else {
            // '*': si se interpreta como ), el mínimo baja; si se interpreta como (, el máximo sube
            // La interpretación como cadena vacía queda incluida dentro de este rango
            low--;
            high++;
        }

        // Si el máximo es negativo, sin importar cómo se interpreten los *, hay exceso de paréntesis de cierre, por lo que es inválida
        if (high < 0) return false;

        // Si low se vuelve negativo, significa que se interpretaron demasiados * como ),
        // pero basta con no elegir esa interpretación, así que se corrige el mínimo a 0
        low = Math.max(low, 0);
    }

    // Si low es 0, "existe una interpretación de * que cierra todos los paréntesis abiertos", por lo que se devuelve true
    // Si low es mayor que 0, en cualquier interpretación sobran paréntesis abiertos, por lo que se devuelve false
    return low == 0;
}
```
