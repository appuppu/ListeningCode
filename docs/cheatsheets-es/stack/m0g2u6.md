# Designing a Stack That Tracks the Minimum — Diseñar un stack que obtiene el valor mínimo en O(1) para todas las operaciones

## Esencia del problema

Se debe diseñar un stack que ejecute las cuatro operaciones `push`, `pop`, `top` y `getMin` (obtener el valor mínimo actual) en O(1). En un stack convencional, obtener el valor mínimo requiere O(n), por lo que se necesita una solución ingeniosa.

## Idea central

Si se almacena junto con cada elemento "el valor mínimo en ese momento", la información del mínimo no se pierde aunque se haga pop de un elemento. `getMin()` siempre obtiene la respuesta en O(1) simplemente consultando el tope del stack.

## Proceso de razonamiento

1. **Para lograr getMin en O(1), es necesario mantener el valor mínimo actualizado en todo momento**: Se considera un enfoque con una sola variable para gestionar el mínimo, pero cuando el mínimo se elimina con pop, no se puede conocer el siguiente valor mínimo. Es decir, se necesita un mecanismo que conserve el "historial" del mínimo
2. **El historial del mínimo está vinculado al estado del stack**: Cada vez que se apila un elemento, el mínimo puede cambiar. Inversamente, cuando se hace pop, el mínimo vuelve al valor anterior al push. Esta propiedad de "volver al estado previo al push" es la misma propiedad del stack
3. **Se almacena cada elemento junto con el valor mínimo en ese momento como un par**: Al hacer push, se compara el nuevo valor con el mínimo actual y se guarda el menor como "el mínimo en ese momento" junto con el nuevo valor. De esta forma, aunque se elimine un elemento con pop, el siguiente elemento en el tope contiene el mínimo correcto
4. **Se define la estructura del par**: Se utiliza un arreglo `int[]`, donde `[0]` almacena el valor y `[1]` almacena el mínimo en ese momento. El tipo del stack es `Stack<int[]>`
5. **Cálculo del mínimo en push**: Si el stack está vacío, el nuevo valor es directamente el mínimo. Si no está vacío, se compara el nuevo valor con el mínimo almacenado en el tope (`stack.peek()[1]`) y se adopta el menor
6. **Implementación de top, getMin y pop**: `top()` retorna `[0]` del par en el tope, `getMin()` retorna `[1]` del par en el tope, ambos en O(1). `pop()` simplemente elimina el tope como un stack convencional

## Conocimientos previos

### Qué es un Stack

Es una estructura de datos de tipo último en entrar, primero en salir (LIFO). El último elemento agregado es el primero en ser extraído. En Java se especifica el tipo a almacenar utilizando Generics.

```java
Stack<int[]> stack = new Stack<>();  // Crear un stack que almacena arreglos de int
stack.push(new int[]{1, 1});         // Agregar un elemento al tope
stack.peek();                         // Consultar el elemento del tope sin extraerlo → [1, 1]
stack.pop();                          // Extraer y retornar el elemento del tope → [1, 1]
stack.isEmpty();                      // Retornar un boolean indicando si el stack está vacío → true
```

### Qué es Math.min

Es un método que recibe dos enteros y retorna el menor. Se utiliza para comparar el nuevo valor con el mínimo actual en cada push.

```java
Math.min(3, 5);   // → 3
Math.min(-1, 0);  // → -1
```

## Complejidad

| | Valor |
|---|---|
| Time | O(1) — Todas las operaciones push, pop, top y getMin se completan en tiempo constante |
| Space | O(n) — Se almacenan como máximo n pares en el stack |

## Código

```java
// Entrada: secuencia de operaciones push(val), pop(), top(), getMin()
// Salida: top() retorna el valor del tope. getMin() retorna el valor mínimo actual en el stack
class MinStack {

    // Campo de tipo Stack<int[]>. Cada elemento es un arreglo de longitud 2, donde [0] almacena el valor y [1] almacena el valor mínimo de todo el stack en ese momento
    private Stack<int[]> stack;

    public MinStack() {
        stack = new Stack<>();
    }

    public void push(int val) {
        // Si el stack está vacío, val es el mínimo. Si no, se compara con el mínimo registrado en el tope y se adopta el menor
        int min = stack.isEmpty() ? val : Math.min(val, stack.peek()[1]);
        // Se hace push del par new int[]{val, min}. Mientras este elemento esté en el tope, min es el valor mínimo correcto
        stack.push(new int[]{val, min});
    }

    public void pop() {
        // Se elimina el par del tope. El [1] del par que queda en el tope almacena el mínimo correcto del momento en que ese elemento fue apilado, por lo que la consistencia del mínimo se mantiene automáticamente
        stack.pop();
    }

    public int top() {
        // En [0] del par se almacena el valor original
        return stack.peek()[0];
    }

    public int getMin() {
        // En [1] del par se almacena el valor mínimo en ese momento, por lo que no se necesita recorrer el stack
        return stack.peek()[1];
    }
}
```
