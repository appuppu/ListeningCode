# Checking if Parentheses Are Balanced — Determinar si los paréntesis de una cadena están correctamente balanceados

## Esencia del problema

Se recibe una cadena compuesta únicamente por los 6 tipos de paréntesis: `(`, `)`, `{`, `}`, `[`, `]`. El programa debe determinar si cada paréntesis de apertura tiene su correspondiente paréntesis de cierre en el **orden correcto**, y devolver `true` o `false`.

## Idea central

La correspondencia de paréntesis tiene una estructura de último en entrar, primero en salir (LIFO): "el último paréntesis abierto es el primero en cerrarse". Esta propiedad es exactamente la de una pila. El algoritmo apila los paréntesis de apertura y, cuando aparece un paréntesis de cierre, lo compara con el elemento en el tope de la pila para verificar la correspondencia correcta.

## Proceso de razonamiento

1. **La correspondencia de paréntesis tiene un orden**: `([)]` tiene el número correcto de cada tipo de paréntesis, pero el orden es inválido. Es decir, existe la regla de que "los paréntesis más internos se cierran primero". Esta es una estructura LIFO (último en entrar, primero en salir) que se representa naturalmente con una pila
2. **Los paréntesis de apertura se apilan**: El algoritmo recorre la cadena carácter por carácter desde el inicio y, cuando encuentra un paréntesis de apertura (`(`, `{`, `[`), lo inserta con push en la pila. El tope de la pila siempre contiene "el paréntesis abierto más reciente que aún no ha sido cerrado"
3. **Cuando aparece un paréntesis de cierre, se compara con el tope de la pila**: Cuando el algoritmo encuentra un paréntesis de cierre, extrae con pop el paréntesis de apertura de la pila y verifica que sean del mismo tipo. Si no coinciden, la cadena es inválida
4. **Si la pila está vacía cuando aparece un paréntesis de cierre, la cadena es inválida**: Si la pila está vacía antes de hacer pop, significa que no existe un paréntesis de apertura correspondiente, por lo que el programa devuelve `false`
5. **Si la pila está vacía al terminar el recorrido, la cadena es válida**: Después de procesar todos los caracteres, si quedan paréntesis de apertura en la pila, significa que existen paréntesis sin cerrar. Si la pila está vacía, todos los paréntesis están correctamente emparejados

## Conocimientos previos

### Qué es un Stack

Un Stack es una estructura de datos de tipo último en entrar, primero en salir (LIFO: Last In, First Out). El último elemento agregado es el primero en ser extraído. Se utiliza en situaciones donde se debe procesar en orden desde "el más reciente", como la verificación de correspondencia de paréntesis.

```java
Stack<Character> stack = new Stack<>();  // Crear una pila vacía
stack.push('(');      // Agregar '(' al tope de la pila
stack.peek();         // Consultar el elemento del tope de la pila sin extraerlo → '('
stack.pop();          // Extraer y devolver el elemento del tope de la pila → '('
stack.isEmpty();      // Devolver un boolean indicando si la pila está vacía → true
```

### Correspondencia de paréntesis

Existen 3 tipos de paréntesis, cada uno con su par de apertura y cierre. Cuando aparece un paréntesis de cierre, es necesario verificar que el tope de la pila contenga el paréntesis de apertura correspondiente.

```
El paréntesis de apertura correspondiente a ')' es '('
El paréntesis de apertura correspondiente a '}' es '{'
El paréntesis de apertura correspondiente a ']' es '['
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Solo se necesita un único recorrido de la cadena |
| Space | O(n) — La pila almacena como máximo n paréntesis de apertura |

## Código

```java
// Entrada: cadena s compuesta únicamente por paréntesis
// Salida: true si todos los paréntesis están correctamente emparejados, false en caso contrario
public boolean isValid(String s) {
    // Pila que almacena los paréntesis de apertura que aún no han sido cerrados
    // El tope de la pila contiene el paréntesis abierto más reciente
    Stack<Character> stack = new Stack<>();

    // Recorrer la cadena carácter por carácter desde el inicio. toCharArray() convierte la cadena en un arreglo de char
    for (char c : s.toCharArray()) {
        // Si es un paréntesis de apertura, se apila. Permanece en la pila hasta que aparezca su paréntesis de cierre correspondiente
        if (c == '(' || c == '{' || c == '[') {
            stack.push(c);
        } else {
            // Si es un paréntesis de cierre pero la pila está vacía, no existe un paréntesis de apertura correspondiente, por lo que es inválido
            if (stack.isEmpty()) return false;

            // Extraer del tope de la pila el paréntesis abierto más reciente que aún no ha sido cerrado
            char top = stack.pop();

            // Si el tipo del paréntesis de cierre no corresponde con el de apertura, es inválido
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
            if (c == ')' && top != '(') return false;
        }
    }

    // Si la pila está vacía, todos los paréntesis están correctamente emparejados
    // Si quedan elementos en la pila, existen paréntesis de apertura sin cerrar, por lo que se devuelve false
    return stack.isEmpty();
}
```
