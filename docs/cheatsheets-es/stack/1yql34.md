# Finding the Largest Rectangle in a Histogram — Encontrar el área del rectángulo más grande que se puede formar dentro de un histograma

## Esencia del problema

Se proporciona un arreglo de enteros no negativos `heights`. Cada elemento representa la altura de una barra del histograma, y todas las barras tienen un ancho de 1. El objetivo es encontrar y devolver el **área del rectángulo más grande** que se puede formar dentro de este histograma.

## Idea central

Si se adopta cada barra como "la altura del rectángulo", se puede calcular el área si se determina hasta dónde se puede extender esa barra hacia la izquierda y la derecha como la barra más baja. Utilizando un stack monótonamente creciente, en el momento en que la altura de una barra disminuye, se puede determinar en O(1) el ancho extensible de las barras dentro del stack.

## Proceso de razonamiento

1. **Considerar el rectángulo cuya altura es cada barra**: Cualquier rectángulo se puede interpretar como "compuesto por barras consecutivas hacia la izquierda y la derecha, con el límite superior definido por la altura de cierta barra". Es decir, si para cada barra `heights[i]` se conoce "el ancho del intervalo en el que esta barra es la más baja", se puede calcular el área como `heights[i] × ancho`
2. **Encontrar los límites izquierdo y derecho de forma eficiente**: Si para cada barra se conoce "la posición de la primera barra más baja a la izquierda" y "la posición de la primera barra más baja a la derecha", se determina el ancho extensible. Buscar estos dos límites de forma ingenua para todas las barras resulta en O(n²), por lo que se utiliza un stack para optimizar el proceso
3. **Usar un stack monótonamente creciente**: Se apilan los índices de las barras en el stack de manera que las alturas se mantengan en orden monótonamente creciente. Cuando la altura de la barra actual es menor que la de la cima del stack, se determina que el "límite derecho" de la barra en la cima es la posición actual `i`
4. **Calcular el ancho al hacer pop**: Cuando se extrae una barra `top` del stack, el límite derecho es la posición actual `i`, y el límite izquierdo es la posición siguiente a la cima del stack después del pop. Si el stack está vacío, la barra se puede extender hasta el extremo izquierdo (índice 0), por lo que el ancho es `i`. Si el stack no está vacío, el ancho es `i - stack.peek() - 1`
5. **Agregar una altura 0 al final como centinela**: Cuando se llega al final del arreglo, es necesario calcular el área de las barras que quedan en el stack. Al establecer el rango del bucle como `i <= heights.length` y colocar virtualmente una altura 0 cuando `i == heights.length`, se garantiza que todas las barras dentro del stack sean extraídas
6. **Rastrear el área máxima**: Cada vez que se extrae una barra, se calcula `heights[top] × ancho` y se compara con el valor máximo hasta el momento para actualizarlo. El valor máximo en el momento en que se completan todas las extracciones es la respuesta

## Conocimientos previos

### ¿Qué es un Stack?

Es una estructura de datos de tipo último en entrar, primero en salir (LIFO). El último elemento agregado es el primero en ser extraído. En el problema del histograma, se utiliza el stack para apilar los índices de las barras y mantener la monotonía de las alturas.

```java
Stack<Integer> stack = new Stack<>();  // Crear un stack vacío
stack.push(0);       // Agregar el valor 0 a la cima del stack
stack.peek();        // Consultar el valor de la cima del stack sin extraerlo → 0
stack.pop();         // Extraer y devolver el valor de la cima del stack → 0
stack.isEmpty();     // Devolver un boolean indicando si el stack está vacío → true
```

### ¿Qué es un Stack monótonamente creciente (Monotonic Stack)?

Es un stack que mantiene sus elementos siempre en orden creciente (o igual) de abajo hacia arriba. Al agregar un nuevo elemento, si el valor entrante es menor que la cima del stack, se extraen elementos hasta que la cima sea mayor o igual al nuevo valor. En el momento de la extracción, se puede interpretar que "el límite derecho de ese elemento extraído ha sido determinado".

```java
// Movimientos del stack monótonamente creciente para el arreglo [2, 1, 5, 6, 2, 3]
// i=0: push(0)         → Stack: [0]       (alturas: [2])
// i=1: 1 < 2 → pop     → Stack: []        (el límite derecho de la barra con altura 2 se determina como i=1)
//       push(1)         → Stack: [1]       (alturas: [1])
// i=2: push(2)         → Stack: [1,2]     (alturas: [1,5])
// i=3: push(3)         → Stack: [1,2,3]   (alturas: [1,5,6])
// i=4: 2 < 6 → pop     → Stack: [1,2]     (el límite derecho de la barra con altura 6 se determina como i=4)
//       2 < 5 → pop     → Stack: [1]       (el límite derecho de la barra con altura 5 se determina como i=4)
//       push(4)         → Stack: [1,4]     (alturas: [1,2])
```

### ¿Qué es un centinela (Sentinel)?

Es un valor que se agrega virtualmente para simplificar el procesamiento del final de un bucle. En este problema, al colocar virtualmente una barra con altura 0 al final del arreglo, se logra que todas las barras que quedan en el stack se extraigan de forma natural al finalizar el bucle.

```java
// Cuando i == heights.length, se usa virtualmente la altura 0 ya que está fuera del arreglo real
int h = (i == heights.length) ? 0 : heights[i];
// Como la altura 0 es menor que cualquier barra, todas las barras del stack son extraídas
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Cada barra se apila una vez y se extrae una vez del stack, por lo que el total de operaciones es O(n) |
| Space | O(n) — El stack almacena como máximo n índices |

## Código

```java
// Entrada: un arreglo de enteros no negativos heights (cada elemento es la altura de una barra del histograma)
// Salida: devolver como int el área del rectángulo más grande que se puede formar dentro del histograma
public int largestRectangleArea(int[] heights) {
    // Stack que mantiene los índices de las barras en orden monótonamente creciente
    Stack<Integer> stack = new Stack<>();
    // Variable que registra el área máxima encontrada hasta el momento
    int maxArea = 0;

    // Al usar i <= heights.length se incluye el procesamiento del centinela
    // Cuando i == heights.length, se usa como centinela (altura 0) para extraer todo el stack
    for (int i = 0; i <= heights.length; i++) {
        // Centinela: si se supera el final del arreglo, se usa la altura 0. Como la altura 0 es menor que cualquier barra, se garantiza que todas las barras del stack sean extraídas
        int h = (i == heights.length) ? 0 : heights[i];

        // Mientras la altura actual sea menor que la barra en la cima del stack, se calcula el área
        // Esta condición mantiene la propiedad de crecimiento monótono dentro del stack
        while (!stack.isEmpty() && h < heights[stack.peek()]) {
            // Se adopta la barra extraída como la altura del rectángulo. El límite derecho de esta barra es la posición actual i
            int top = stack.pop();

            // Calcular el ancho:
            // Si el stack está vacío → la barra top se puede extender hasta el extremo izquierdo (índice 0), por lo que el ancho es i
            // Si el stack no está vacío → stack.peek() es el índice de la barra más baja que top a su izquierda (límite izquierdo), por lo que el ancho es i - stack.peek() - 1
            int w = stack.isEmpty() ? i : i - stack.peek() - 1;

            // Calcular el área y actualizar el valor máximo
            maxArea = Math.max(maxArea, heights[top] * w);
        }

        // Apilar el índice actual en el stack para mantener el crecimiento monótono
        stack.push(i);
    }
    // El valor máximo en el momento en que se completan todas las extracciones es la respuesta
    return maxArea;
}
```
