# Implementing Regular Expression Matching — Determinar si una cadena coincide completamente con un patrón

## Esencia del problema

Se reciben una cadena de entrada `s` y un patrón `p`. En el patrón, `.` coincide con cualquier carácter individual, y `*` significa cero o más repeticiones del carácter inmediatamente anterior. El objetivo es devolver un `boolean` que indique si el patrón coincide con la cadena **completa**.

## Idea central

Se llena una tabla DP bidimensional desde el final de la cadena y el patrón hacia el inicio. `dp[i][j]` representa "si `s[i:]` coincide con `p[j:]`". Cuando hay un `*`, el problema se reduce a dos opciones: "usar el carácter anterior 0 veces (omitirlo)" o "usarlo 1 vez y avanzar un carácter en la cadena".

## Proceso de razonamiento

1. **Se puede descomponer en subproblemas**: Si se fija la posición `i` en la cadena y la posición `j` en el patrón, se obtiene el subproblema "si `s[i:]` coincide con `p[j:]`". Al almacenar la respuesta de este subproblema en `dp[i][j]`, se evitan cálculos redundantes
2. **Se determina si el carácter en la posición actual coincide**: Si `s[i]` y `p[j]` son el mismo carácter, o si `p[j]` es `.`, entonces el carácter en la posición actual coincide. Se almacena este resultado en la variable `match`
3. **Se consideran las dos opciones cuando hay `*`**: Cuando `p[j+1]` es `*`, el patrón `x*` se puede interpretar de dos maneras. La primera es "0 coincidencias (omitir)", donde se salta `x*` por completo y se consulta `dp[i][j+2]`. La segunda es "1 o más coincidencias", donde si el carácter actual coincide, se avanza un carácter en la cadena y se consulta `dp[i+1][j]` (no se avanza en el patrón, porque la repetición mediante `*` puede continuar en la siguiente posición)
4. **Sin `*`, simplemente se avanza un carácter a la vez**: Si el carácter actual coincide, la respuesta es directamente `dp[i+1][j+1]`, avanzando tanto la cadena como el patrón en una posición
5. **Se establece el caso base**: El estado `dp[n][m]`, donde tanto la cadena como el patrón han llegado al final, es `true`. Si queda cadena pero el patrón ha llegado al final, el resultado es `false`. Si queda patrón pero la cadena ha llegado al final, solo puede ser `true` mediante la omisión con `*`
6. **Se llena la tabla desde el final hacia el inicio**: El cálculo de `dp[i][j]` depende de `dp[i][j+2]`, `dp[i+1][j]` y `dp[i+1][j+1]`. Todos estos valores están en la dirección donde `i` o `j` son mayores, por lo que al recorrer `i` de `n` a `0` y `j` de `m-1` a `0` en orden inverso, los valores referenciados siempre estarán ya calculados
7. **Valor que se devuelve al final**: `dp[0][0]` en la tabla es la respuesta a "si la cadena completa coincide con el patrón completo"

## Conocimientos previos

### Qué es una tabla DP bidimensional

Es un arreglo bidimensional que almacena la respuesta de cada subproblema para cada combinación de dos variables (en este caso, la posición `i` en la cadena y la posición `j` en el patrón). Se crea con `boolean[][] dp = new boolean[n+1][m+1]`, y en `dp[i][j]` se almacena el resultado de la coincidencia entre `s[i:]` y `p[j:]`.

```java
boolean[][] dp = new boolean[n + 1][m + 1];  // Se crea una tabla de (n+1)×(m+1) inicializada con false
dp[n][m] = true;                              // Caso base: si ambos llegan al final, coinciden
dp[i][j] = dp[i][j + 2];                     // Se consulta el valor de otra celda para llenar la celda actual
```

### String.length() y String.charAt()

`length()` devuelve la longitud de la cadena. `charAt(i)` devuelve el carácter en el índice `i`. Los índices comienzan en 0, y un acceso fuera de rango lanza una excepción.

```java
String s = "abc";
s.length();     // → 3
s.charAt(0);    // → 'a'
s.charAt(2);    // → 'c'
```

### Significado de `*` (asterisco)

En expresiones regulares, `*` representa "cero o más repeticiones del carácter inmediatamente anterior". `a*` coincide con `""`, `"a"`, `"aa"`, `"aaa"`, etc. `.*` significa "cero o más repeticiones de cualquier carácter", por lo que coincide con cualquier cadena. `*` no se usa de forma independiente; siempre forma un par con el carácter anterior en la forma `x*`.

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n×m) — Se calcula cada celda de la tabla DP de n×m una sola vez |
| Space | O(n×m) — Se almacena la tabla DP de n×m |

## Código

```java
// Entrada: cadena s y patrón p
// Salida: devuelve un boolean que indica si s completa coincide con p
public boolean isMatch(String s, String p) {
    int n = s.length();  // Longitud de la cadena
    int m = p.length();  // Longitud del patrón

    // dp[i][j] = tabla bidimensional que almacena "si s[i:] coincide con p[j:]"
    // Los índices n y m representan la cadena vacía, por lo que el tamaño es +1
    boolean[][] dp = new boolean[n + 1][m + 1];

    // Caso base: si ambas cadenas han llegado al final, la coincidencia es exitosa
    dp[n][m] = true;

    // Se llena la tabla desde el final hacia el inicio
    // Este orden de recorrido garantiza que dp[i][j+2], dp[i+1][j] y dp[i+1][j+1] ya están calculados
    for (int i = n; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // Se determina si el carácter en la posición actual coincide
            // Se evalúa i < n primero para evitar un acceso fuera de rango con charAt cuando la cadena está al final
            boolean match = i < n
                && (s.charAt(i) == p.charAt(j)
                    || p.charAt(j) == '.');

            // Se verifica el rango con j+1 < m y se determina si la posición actual del patrón tiene la forma x*
            if (j + 1 < m && p.charAt(j + 1) == '*') {
                // Se toma el OR (disyunción lógica) de las dos opciones del patrón x*:
                // dp[i][j+2]: 0 coincidencias (se omite x* por completo)
                // match && dp[i+1][j]: 1 coincidencia y se avanza en la cadena (no se avanza en el patrón; j se mantiene porque la repetición mediante * puede continuar)
                dp[i][j] = dp[i][j + 2]
                    || (match && dp[i + 1][j]);
            } else {
                // Carácter normal: si coincide un carácter, se avanza tanto la cadena como el patrón en una posición
                dp[i][j] = match
                    && dp[i + 1][j + 1];
            }
        }
    }

    // dp[0][0] es la respuesta final a "si la cadena s completa coincide con el patrón p completo"
    return dp[0][0];
}
```
