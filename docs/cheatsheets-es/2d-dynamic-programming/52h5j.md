# Checking if a String is an Interleaving of Two Others — Determinar si una tercera cadena se puede formar intercalando dos cadenas

## Esencia del problema

Se dan tres cadenas `s1`, `s2` y `s3`. Se debe determinar si `s3` está compuesta por un **interleaving** (intercalación) de `s1` y `s2`. Un interleaving consiste en utilizar todos los caracteres de `s1` y `s2`, mezclándolos de manera que se preserve el orden relativo de aparición dentro de cada cadena original.

## Idea central

El problema se puede descomponer en subproblemas que preguntan si los primeros `i` caracteres de `s1` y los primeros `j` caracteres de `s2` pueden formar los primeros `i+j` caracteres de `s3`. En cada posición, la decisión de "tomar el siguiente carácter de `s1` o de `s2`" se resuelve eficientemente mediante una tabla de DP.

## Proceso de razonamiento

1. **Verificar la precondición de longitud**: Si `s3` es un interleaving de `s1` y `s2`, la longitud de `s3` debe ser igual a la longitud de `s1` más la longitud de `s2`. Si no coinciden, se puede devolver `false` de inmediato
2. **Definir el subproblema**: Se define `dp[i][j]` como "si los primeros `i` caracteres de `s1` y los primeros `j` caracteres de `s2` pueden formar los primeros `i+j` caracteres de `s3`". Con esta definición, `dp[m][n]` (donde `m` es la longitud de `s1` y `n` es la longitud de `s2`) es la respuesta final
3. **Derivar la relación de recurrencia**: `dp[i][j]` es `true` en uno de dos casos. Caso 1: `dp[i-1][j]` es `true` y el carácter `i`-ésimo de `s1` coincide con el carácter `(i+j)`-ésimo de `s3` (se toma un carácter de `s1`). Caso 2: `dp[i][j-1]` es `true` y el carácter `j`-ésimo de `s2` coincide con el carácter `(i+j)`-ésimo de `s3` (se toma un carácter de `s2`)
4. **Definir el caso base**: Cuando `i=0` y `j=0`, es el estado inicial en el que no se ha tomado ningún carácter de ninguna cadena, y coincide con los primeros 0 caracteres de `s3` (cadena vacía), por lo que se establece `dp[0][0] = true`
5. **Optimizar la complejidad espacial**: La tabla bidimensional `dp[i][j]` solo utiliza los valores de la fila `i-1` para calcular la fila `i`. Por lo tanto, un arreglo unidimensional `dp[j]` es suficiente: el valor de `dp[j]` antes de actualizarse corresponde a la fila anterior (`dp[i-1][j]`), y el valor de `dp[j-1]` después de actualizarse corresponde a la celda izquierda de la fila actual (`dp[i][j-1]`)
6. **Valor de retorno**: Después de que el bucle externo recorra `i` de `0` a `m` y el bucle interno recorra `j` de `0` a `n`, `dp[n]` contiene la respuesta sobre si toda la cadena `s3` se puede formar mediante interleaving

## Conocimientos previos

### Qué es la optimización espacial con arreglo unidimensional en DP (programación dinámica)

En una tabla de DP bidimensional `dp[i][j]`, cuando el cálculo de cada fila solo depende de la fila inmediatamente anterior, se puede sustituir por un arreglo unidimensional `dp[j]`. Al sobrescribir el arreglo fila por fila, se reduce la complejidad espacial de O(m×n) a O(n).

```java
// Caso bidimensional: dp[i][j] hace referencia a dp[i-1][j] y dp[i][j-1]
boolean[][] dp = new boolean[m + 1][n + 1];

// Optimización a una dimensión: se sobrescribe dp[j] fila por fila
boolean[] dp = new boolean[n + 1];
// El valor de dp[j] antes de actualizar → corresponde a dp[i-1][j] de la fila anterior
// El valor de dp[j-1] después de actualizar → corresponde a dp[i][j-1] de la fila actual
```

### Qué es String.charAt(index)

Es un método que devuelve el carácter en la posición especificada de una cadena. El índice comienza en 0.

```java
String s = "abc";
s.charAt(0);  // Devuelve 'a'
s.charAt(2);  // Devuelve 'c'
```

### Qué es el interleaving (intercalación)

Es la operación de mezclar los caracteres de dos cadenas para formar una sola cadena, preservando el orden relativo de cada cadena original.
Ejemplo: Si `s1 = "aab"` y `s2 = "axy"`, entonces `"aaxaby"` es un interleaving (el orden de a,a,b de `s1` y el orden de a,x,y de `s2` se preservan respectivamente). `"abaaxy"` no es un interleaving porque el orden de los caracteres de `s1` se altera.

## Complejidad

| | Valor |
|---|---|
| Time | O(m×n) — Se ejecuta un doble bucle una vez con la longitud `m` de `s1` y la longitud `n` de `s2` |
| Space | O(n) — Solo se utiliza un arreglo de DP unidimensional de tamaño igual a la longitud de `s2` más 1 |

## Código

```java
// Entrada: cadena s1 (longitud m), cadena s2 (longitud n), cadena s3
// Salida: devuelve un boolean indicando si s3 se puede formar con el interleaving de s1 y s2
public boolean isInterleave(String s1, String s2, String s3) {
    int m = s1.length();
    int n = s2.length();

    // Si m + n no coincide con la longitud de s3, el interleaving es imposible
    if (m + n != s3.length())
        return false;

    // dp[j] = si los primeros i caracteres de s1 y los primeros j caracteres de s2 pueden formar los primeros i+j caracteres de s3
    // Al sobrescribir el arreglo unidimensional fila por fila, se comprime el espacio de la tabla bidimensional a O(n)
    boolean[] dp = new boolean[n + 1];

    // Bucle externo: i representa la cantidad de caracteres tomados de s1 (0 a m)
    for (int i = 0; i <= m; i++) {
        // Bucle interno: j representa la cantidad de caracteres tomados de s2 (0 a n)
        for (int j = 0; j <= n; j++) {
            if (i == 0 && j == 0) {
                // Caso base: no se ha tomado ningún carácter de ninguna cadena, y coincide con la cadena vacía de s3
                dp[j] = true;
            } else {
                // Condición 1 (tomar de s1): el valor de dp[j] antes de actualizar (fila anterior = equivale a dp[i-1][j]) es true
                //   y el carácter i-ésimo de s1 coincide con el carácter (i+j)-ésimo de s3
                // Condición 2 (tomar de s2): el valor de dp[j-1] después de actualizar (celda izquierda de la fila actual = equivale a dp[i][j-1]) es true
                //   y el carácter j-ésimo de s2 coincide con el carácter (i+j)-ésimo de s3
                // Nota: como el bucle interno recorre j de izquierda a derecha, dp[j] aún no ha sido sobrescrito y conserva el valor de la fila anterior,
                //   mientras que dp[j-1] ya ha sido sobrescrito y contiene el valor de la fila actual
                dp[j] =
                    (dp[j] && i > 0
                    && s1.charAt(i - 1)
                    == s3.charAt(i + j - 1))
                    || (j > 0
                    && dp[j - 1]
                    && s2.charAt(j - 1)
                    == s3.charAt(i + j - 1));
            }
        }
    }

    // dp[n] es el resultado de si los m caracteres completos de s1 y los n caracteres completos de s2 pueden formar los m+n caracteres completos de s3
    return dp[n];
}
```
