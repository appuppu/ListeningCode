# Counting Distinct Subsequences — Contar cuántas subsecuencias de la cadena s coinciden con t

## Esencia del problema

Se dan dos cadenas `s` y `t`. Se debe contar y devolver de cuántas formas se puede formar una subsecuencia que coincida con `t` eliminando cero o más caracteres de `s` (sin cambiar el orden relativo de los caracteres restantes).

## Idea central

Para cada carácter de `s`, existe una elección binaria: "usarlo o no usarlo para el emparejamiento con `t`". La acumulación de estas elecciones se gestiona con un arreglo unidimensional, y al actualizarlo de atrás hacia adelante se logra realizar correctamente la suma de los casos "usar" y "no usar".

## Proceso de razonamiento

1. **El emparejamiento de subsecuencias es una acumulación de elecciones**: Cuando el i-ésimo carácter de `s` coincide con el j-ésimo carácter de `t`, existen dos opciones: "usar este carácter para emparejar con `t[j]`" o "omitirlo sin usarlo". La suma del número de casos de ambas opciones produce el total de todos los patrones
2. **Definir el estado del DP**: Se define `dp[j]` como "el número de subsecuencias de `s` que coinciden con los primeros j caracteres de `t`". Finalmente, `dp[n]` (donde n es la longitud de `t`) es la respuesta
3. **Considerar el caso base**: La subsecuencia que coincide con los primeros 0 caracteres de `t` (la cadena vacía) siempre tiene exactamente una forma para cualquier `s`: "no seleccionar nada". Por lo tanto, `dp[0] = 1`
4. **Derivar la fórmula de transición**: Cuando `s[i-1] == t[j-1]`, `dp[j]` recibe dos contribuciones. En el caso de "no usar `s[i-1]`", el valor existente de `dp[j]` se mantiene tal cual, y en el caso de "usar `s[i-1]`", se suma `dp[j-1]` (el número de emparejamientos completados hasta el carácter anterior). Por lo tanto, `dp[j] += dp[j-1]`. Cuando los caracteres no coinciden, `dp[j]` no cambia (la única opción es omitir)
5. **Razón para actualizar en orden inverso**: En `dp[j] += dp[j-1]` se necesita el valor de `dp[j-1]` antes de la actualización. Si se actualiza j desde el menor hacia el mayor, `dp[j-1]` se sobrescribe primero y se pierde el valor anterior. Al actualizar j en orden inverso, del mayor al menor, `dp[j-1]` aún conserva el valor anterior a la actualización, por lo que el cálculo se realiza correctamente
6. **Valor a devolver**: Después de recorrer todos los caracteres de `s`, `dp[n]` contiene la respuesta de cuántas subsecuencias de `s` coinciden con `t`

## Conocimientos previos

### Qué es una subsecuencia (Subsequence)

Es una cadena que se forma eliminando cero o más caracteres de la cadena original, manteniendo el orden relativo de los caracteres restantes. A diferencia de una subcadena (Substring), los caracteres no necesitan ser consecutivos.

```
s = "rabbbit", t = "rabbit"
Ejemplo de subsecuencia: seleccionar los caracteres 1,2,3,5,6,7 de s → "rabbit" ✓
Ejemplo de subsecuencia: seleccionar los caracteres 1,2,4,5,6,7 de s → "rabbit" ✓
Ejemplo de subsecuencia: seleccionar los caracteres 1,3,4,5,6,7 de s → "rabbit" ✓
→ 3 formas en total
```

### Qué es la actualización en orden inverso del DP unidimensional

Es una técnica que comprime la tabla de DP bidimensional `dp[i][j]` en un arreglo unidimensional `dp[j]`. Cuando el cálculo de la fila actual solo necesita los valores de la fila anterior, se puede reutilizar el arreglo unidimensional para reducir la complejidad espacial. Sin embargo, cuando la actualización de `dp[j]` necesita `dp[j-1]` (el valor de la fila anterior), si se actualiza j en orden ascendente, `dp[j-1]` se sobrescribe con el valor de la fila actual. Al actualizar j en orden descendente (de mayor a menor), se puede referenciar correctamente `dp[j-1]` de la fila anterior, que aún no ha sido sobrescrito.

```java
// DP bidimensional (forma original)
dp[i][j] = dp[i-1][j] + dp[i-1][j-1];

// Compresión a DP unidimensional (actualización en orden inverso)
for (int j = n; j >= 1; j--) {   // Se actualiza desde el mayor
    dp[j] += dp[j - 1];          // dp[j-1] aún conserva el valor de la fila anterior
}
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(m × n) — Para cada carácter de s (m caracteres), se recorren los caracteres de t (n caracteres) |
| Space | O(n) — Solo se utiliza un arreglo unidimensional de longitud n+1 |

## Código

```java
// Entrada: cadena s (longitud m) y cadena t (longitud n)
// Salida: devuelve como int el número de subsecuencias de s que coinciden con t
public int numDistinct(String s, String t) {
    int m = s.length();
    int n = t.length();

    // dp[j] = número de subsecuencias de s que coinciden con los primeros j caracteres de t
    // Se gestiona n+1 estados con índices de 0 a n, por lo que el tamaño es n+1
    int[] dp = new int[n + 1];

    // La subsecuencia que coincide con la cadena vacía siempre tiene exactamente 1 forma (no seleccionar nada)
    // Este caso base se cumple sin importar desde qué posición de s se comience
    dp[0] = 1;

    // Se considera cada carácter de s en orden (i representa cuántos caracteres de s se han considerado)
    for (int i = 1; i <= m; i++) {
        // Se recorre j en orden inverso (de mayor a menor)
        // Razón: en el cálculo dp[j] += dp[j-1] se necesita referenciar dp[j-1] antes de la actualización
        // Si se actualiza en orden ascendente, dp[j-1] se sobrescribe primero y se pierde el valor de la fila anterior
        for (int j = n; j >= 1; j--) {
            // i, j comienzan en 1, pero los índices de la cadena comienzan en 0, por lo que se accede con i-1, j-1
            if (s.charAt(i - 1) == t.charAt(j - 1))
                // Caso de coincidencia: se suma dp[j-1] (número de casos al usar) a dp[j] (número de casos al no usar)
                // Con esta suma, el total de ambas opciones "usar" y "no usar" se acumula en dp[j]
                dp[j] += dp[j - 1];
            // Caso de no coincidencia: no se hace nada (s[i-1] no puede usarse para emparejar con t[j-1], la única opción es omitir)
        }
    }

    // dp[n] contiene el número de subsecuencias en todo s que coinciden con todo t
    return dp[n];
}
```
