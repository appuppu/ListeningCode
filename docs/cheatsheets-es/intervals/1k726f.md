# Merging Overlapping Intervals — Fusionar todos los intervalos superpuestos

## Esencia del problema

Se recibe un arreglo `intervals` de intervalos (pares de valor inicial y valor final). Se deben fusionar (merge) todos los intervalos superpuestos y devolver una lista de intervalos sin superposiciones.

## Idea central

Si se ordenan los intervalos por su valor inicial, solo los intervalos adyacentes pueden superponerse. Después de ordenar, se recorren los intervalos en orden: si el intervalo actual se superpone con el anterior, se actualiza el valor final; si no se superpone, se agrega como un nuevo intervalo.

## Proceso de razonamiento

1. **Simplificar la determinación de superposición**: Si los intervalos no están ordenados, es necesario comparar todos los pares. Al ordenar en orden ascendente por valor inicial, la determinación de superposición se reduce a verificar si "el valor final del intervalo anterior ≥ el valor inicial del intervalo actual"
2. **Después de ordenar, se puede fusionar con un solo recorrido**: Se recorren los intervalos ordenados desde el principio. Se compara el último intervalo de la lista de resultados con el intervalo actual; si se superponen, se actualiza el valor final al mayor de los dos. Si no se superponen, se agrega el intervalo actual directamente a la lista de resultados
3. **Se necesita acceso al final de la lista de resultados**: En la determinación de fusión, siempre se hace referencia al valor final del "último intervalo agregado" en la lista de resultados. Usando LinkedList, se puede acceder al final en O(1) con `getLast()`
4. **Definir con precisión la condición de superposición**: Cuando el valor final del intervalo anterior es menor que el valor inicial del intervalo actual (`res.getLast()[1] < interval[0]`), los dos intervalos no se superponen. En cualquier otro caso (valor final ≥ valor inicial), los intervalos se superponen y se fusionan
5. **Al fusionar, solo se actualiza el valor final**: Como los valores iniciales ya están ordenados, el intervalo anterior siempre tiene un valor inicial menor o igual. Para el valor final, se adopta el mayor de los dos intervalos. Se usa `Math.max()` para comparar el valor final anterior con el valor final actual
6. **Qué se devuelve al final**: Se convierten todos los intervalos no superpuestos acumulados en la lista de resultados a un arreglo bidimensional `int[][]` y se devuelve

## Conocimientos previos

### Arrays.sort y Comparator personalizado

`Arrays.sort` es un método que ordena un arreglo. En el caso de arreglos bidimensionales, se especifica un Comparator mediante una expresión lambda para definir con qué elemento se ordena.

```java
int[][] intervals = {{3, 6}, {1, 3}, {2, 5}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // Ordenar en orden ascendente por el valor inicial (índice 0) de cada intervalo
// Resultado: {{1, 3}, {2, 5}, {3, 6}}
```

### Qué es LinkedList

Es una lista que permite agregar elementos al inicio y al final, y obtener el último elemento en O(1). A diferencia de ArrayList, permite acceder directamente al último elemento mediante el método `getLast()`.

```java
LinkedList<int[]> res = new LinkedList<>();  // Crear una LinkedList vacía
res.add(new int[]{1, 3});   // Agregar un elemento al final
res.getLast();               // Obtener el último elemento → {1, 3}
res.getLast()[1] = 5;        // Modificar directamente el valor final del último elemento → {1, 5}
res.isEmpty();               // Devolver un boolean indicando si la lista está vacía → false
res.size();                  // Devolver el número de elementos de la lista → 1
```

### Qué es Math.max

Es un método que devuelve el mayor de dos valores. En la fusión de intervalos, se usa para adoptar el mayor de los dos valores finales.

```java
Math.max(5, 8);   // → 8
Math.max(10, 3);  // → 10
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n log n) — La ordenación es O(n log n) y el recorrido es O(n), por lo que el total es O(n log n) |
| Space | O(n) — Se almacenan como máximo n intervalos en la lista de resultados |

## Código

```java
// Entrada: arreglo bidimensional de intervalos int[][] intervals (cada elemento es [valor inicial, valor final])
// Salida: devuelve un arreglo bidimensional int[][] después de fusionar los intervalos superpuestos
public int[][] merge(int[][] intervals) {
    // Al ordenar, la determinación de superposición se limita solo a la comparación de intervalos adyacentes
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // Lista de resultados que acumula los intervalos ya fusionados
    // Se usa LinkedList porque permite referenciar y actualizar el último elemento en O(1)
    LinkedList<int[]> res = new LinkedList<>();

    for (int[] interval : intervals) {
        // Si res está vacío, es el primer intervalo, así que se agrega incondicionalmente
        // Si res.getLast()[1] < interval[0], no se superpone con el intervalo anterior, así que se agrega directamente
        if (res.isEmpty() || res.getLast()[1] < interval[0]) {
            res.add(interval);
        } else {
            // Si se superponen, se actualiza el valor final al mayor de los dos para fusionarlos
            // No es necesario modificar el valor inicial porque, al estar ordenados, el intervalo anterior tiene un valor inicial menor o igual
            res.getLast()[1] = Math.max(res.getLast()[1], interval[1]);
        }
    }

    // Convertir la lista de resultados a un arreglo bidimensional y devolverlo
    return res.toArray(new int[res.size()][]);
}
```
