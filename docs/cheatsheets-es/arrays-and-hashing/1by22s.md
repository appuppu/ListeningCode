# Finding the Longest Consecutive Number Sequence — Encontrar la longitud de la secuencia consecutiva más larga de enteros en un arreglo no ordenado

## Esencia del problema

Se recibe un arreglo de enteros `nums` (no ordenado). El objetivo es encontrar la secuencia de enteros consecutivos (por ejemplo: 1, 2, 3, 4) dentro del arreglo y devolver la **longitud máxima** de dicha secuencia. El orden de los elementos en el arreglo no importa; solo importa que los valores sean consecutivos.

## Idea central

Si contamos la longitud únicamente desde el "punto de inicio" de cada secuencia consecutiva, podemos eliminar los cálculos redundantes. Si para un número `num` no existe `num - 1` en el HashSet, entonces ese número es el punto de inicio de una secuencia consecutiva. Al iniciar el conteo solo desde los puntos de inicio, logramos una complejidad total de O(n).

## Proceso de razonamiento

1. **Identificar el punto de inicio de la secuencia consecutiva**: Si comenzamos a contar desde un número que está en medio de una secuencia consecutiva, contaremos la misma secuencia varias veces. Solo los números para los cuales `num - 1` no existe son verdaderos puntos de inicio de una secuencia consecutiva. Al contar únicamente desde los puntos de inicio, cada elemento se cuenta como máximo una sola vez.
2. **Realizar la verificación de existencia de forma eficiente**: Para determinar en O(1) si un número está contenido en el arreglo, almacenamos todos los elementos en un HashSet. Ordenar el arreglo permitiría resolver el problema en O(n log n), pero usando un HashSet lo resolvemos en O(n).
3. **Contar los consecutivos desde el punto de inicio**: Una vez encontrado el punto de inicio `num`, verificamos en orden si `num + 1`, `num + 2`, ... existen en el HashSet, y contamos la longitud hasta que la secuencia se interrumpa.
4. **Rastrear la longitud máxima**: Comparamos la longitud de cada secuencia consecutiva con la variable `longest` y la actualizamos si es mayor. El valor de `longest` después de procesar todos los elementos es la respuesta.

## Conocimientos previos

### Qué es un HashSet

Un HashSet es una estructura de datos que almacena valores sin duplicados. La inserción y la verificación de existencia se realizan en O(1). A diferencia de un HashMap, solo almacena claves, y se utiliza cuando se necesita determinar rápidamente si un valor "existe o no".

```java
HashSet<Integer> set = new HashSet<>();  // Crear un HashSet vacío
set.add(4);              // Agregar el valor 4 al conjunto
set.add(4);              // Los duplicados se ignoran (el tamaño del conjunto no cambia)
set.contains(4);         // Devuelve un boolean indicando si el valor 4 existe → true
set.contains(5);         // Devuelve un boolean indicando si el valor 5 existe → false
```

### Qué es el punto de inicio de una secuencia consecutiva

Para un número `num`, si `num - 1` no existe en el conjunto, entonces `num` es el primer número (punto de inicio) de una secuencia consecutiva.
Ejemplo: En el conjunto {100, 4, 200, 1, 3, 2}, el número 1 es un punto de inicio (porque 0 no existe), pero el número 2 no es un punto de inicio (porque 1 sí existe).

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Cada elemento se accede como máximo 2 veces: una vez para la verificación del punto de inicio y una vez para el conteo |
| Space | O(n) — El HashSet almacena como máximo n elementos |

## Código

```java
// Entrada: arreglo de enteros nums (no ordenado, puede contener duplicados)
// Salida: devuelve la longitud de la secuencia consecutiva más larga como int
public int longestConsecutive(int[] nums) {
    // Almacenar todos los elementos en un HashSet para verificar existencia en O(1)
    // Los elementos duplicados se eliminan automáticamente
    Set<Integer> numSet = new HashSet<>();
    for (int num : nums) {
        numSet.add(num);
    }

    // Variable que mantiene la longitud máxima de la secuencia consecutiva encontrada hasta ahora
    int longest = 0;

    // Recorrer cada elemento del HashSet
    for (int num : numSet) {
        // Si num - 1 no existe, entonces num es el punto de inicio de una secuencia consecutiva
        // Si num - 1 existe, num está en medio de una secuencia consecutiva, así que lo omitimos
        // (Este número se contará cuando se cuente desde otro punto de inicio)
        if (!numSet.contains(num - 1)) {
            int currentNum = num;
            int length = 1;

            // Contar en orden los números consecutivos desde el punto de inicio (num+1, num+2, ...)
            // El bucle continúa hasta que la secuencia se interrumpa
            while (numSet.contains(currentNum + 1)) {
                currentNum++;
                length++;
            }

            // Actualizar si la longitud de la secuencia actual supera la longitud máxima encontrada hasta ahora
            longest = Math.max(longest, length);
        }
    }
    // Después de recorrer todos los elementos, devolver la longitud de la secuencia consecutiva más larga
    return longest;
}
```
