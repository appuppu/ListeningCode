# Grouping Words by Anagram Patterns — Agrupar palabras que son anagramas entre sí

## Esencia del problema

Se recibe un arreglo de cadenas `strs`. Se deben agrupar las cadenas que son anagramas entre sí y devolver el resultado como una lista de grupos. Dos cadenas son anagramas cuando contienen las mismas letras con la misma frecuencia, y solo difieren en el orden de los caracteres.

## Idea central

Las cadenas que son anagramas entre sí tienen exactamente la misma frecuencia de aparición de cada letra. Si se cuenta la frecuencia de cada una de las 26 letras y se convierte ese conteo en una cadena para usarla como clave, los anagramas siempre generarán la misma clave, lo que permite agruparlos de una sola vez mediante un HashMap.

## Proceso de razonamiento

1. **Encontrar la propiedad común de los anagramas**: Los anagramas solo difieren en el orden de las letras; la frecuencia de aparición de cada letra es exactamente igual. Se puede usar esta "coincidencia en las frecuencias" como criterio para agruparlos
2. **Cómo representar las frecuencias de aparición**: Como las letras minúsculas son 26 tipos, se prepara un arreglo de enteros `count` de tamaño 26 y se cuenta la frecuencia de cada letra. Si el contenido de este arreglo es igual entre dos palabras, esas palabras son anagramas
3. **Cómo usar el arreglo como clave de un HashMap**: En Java, no se puede usar un arreglo directamente como clave de un HashMap (porque la comparación se hace por referencia). Por eso, se concatenan los elementos del arreglo separados por `#` para formar una cadena (por ejemplo: `"1#0#0#...#"`) y se usa como clave. De esta forma, las palabras con la misma frecuencia generan la misma clave de tipo cadena
4. **Agrupar mediante un HashMap**: Las palabras con la misma clave se agregan a la misma lista. Al usar `computeIfAbsent`, si la clave no está registrada se genera automáticamente una nueva lista, y si ya está registrada se devuelve la lista existente, lo que permite agregar palabras sin necesidad de ramificaciones condicionales
5. **Qué se devuelve al final**: Se convierten todos los valores del HashMap (la lista de cada grupo) en un `ArrayList` y se devuelve

## Conocimientos previos

### Qué es un HashMap

Es una estructura de datos que almacena pares de clave y valor. Permite buscar y obtener valores especificando la clave en O(1). Funciona como un diccionario que permite acceder mediante cualquier clave a la misma velocidad que el acceso por índice en un arreglo.

```java
HashMap<String, List<String>> map = new HashMap<>();  // Crear un HashMap vacío
map.put("key", new ArrayList<>());  // Almacenar una lista vacía con la clave "key"
map.containsKey("key");             // Devolver un boolean indicando si la clave "key" existe → true
map.get("key");                     // Devolver el valor correspondiente a la clave "key" → []
map.values();                       // Devolver todos los valores como una Collection
```

### Qué es computeIfAbsent

Es un método de HashMap. Si la clave especificada no existe, genera un valor mediante la expresión lambda del segundo argumento, lo registra y lo devuelve. Si la clave ya existe, devuelve el valor existente tal cual. Permite escribir en una sola línea la ramificación condicional según la existencia de la clave.

```java
// Si la clave "abc" no está registrada, se crea un nuevo ArrayList, se registra y se devuelve esa lista
// Si la clave "abc" ya está registrada, se devuelve la lista existente tal cual
map.computeIfAbsent("abc", k -> new ArrayList<>()).add("cab");
```

### Conteo de frecuencia de caracteres

Al restar `'a'` de un carácter de tipo `char`, se obtiene un índice donde a=0, b=1, ..., z=25. Se prepara un arreglo de tamaño 26 y se incrementa la posición correspondiente a cada índice, registrando así la frecuencia de aparición de cada carácter.

```java
int[] count = new int[26];           // Crear un arreglo de conteo para 26 letras (valor inicial: todo 0)
for (char c : "eat".toCharArray())   // Recorrer la cadena carácter por carácter
    count[c - 'a']++;                // Incrementar la posición correspondiente al carácter
// Resultado: count[0]=1(a), count[4]=1(e), count[19]=1(t), el resto es 0
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n × k) — n es la cantidad de cadenas, k es la longitud promedio de las cadenas. Para cada cadena se realiza el conteo de caracteres y la generación de una clave de tamaño 26 |
| Space | O(n × k) — Se almacenan todas las cadenas en el HashMap; cada clave tiene longitud fija, pero las cadenas en sí ocupan memoria proporcional a k caracteres |

## Código

```java
// Entrada: arreglo de cadenas strs
// Salida: devuelve una List<List<String>> con las cadenas agrupadas por anagramas
public List<List<String>> groupAnagrams(String[] strs) {
    // HashMap que almacena clave=representación en cadena de las frecuencias, valor=lista de palabras que pertenecen a esa clave
    // Las palabras con la misma clave son anagramas entre sí
    Map<String, List<String>> map = new HashMap<>();

    // Recorrer cada cadena s del arreglo strs desde el inicio hasta el final, una por una
    for (String s : strs) {
        // Crear un arreglo de tamaño 26 para registrar la frecuencia de cada letra (a~z) (valor inicial: todo 0)
        // Se crea un nuevo arreglo para cada cadena para evitar que queden los resultados del conteo anterior
        int[] count = new int[26];
        // Convertir a un arreglo de caracteres con toCharArray() y contar la frecuencia de cada carácter c
        for (char c : s.toCharArray())
            // Mediante c - 'a', se convierte el carácter c a un índice de 0 a 25 y se incrementa
            count[c - 'a']++;

        // Convertir el arreglo de frecuencias a una clave de cadena con formato "1#0#0#..."
        // Esta clave representa de forma única las frecuencias de los caracteres; los anagramas siempre generan la misma clave
        // Se intercala el separador # entre cada elemento para evitar que conteos diferentes produzcan la misma cadena
        StringBuilder sb = new StringBuilder();
        for (int n : count)
            sb.append(n).append('#');
        String key = sb.toString();

        // Si la clave no está registrada, se crea una nueva lista y se agrega la cadena actual a la lista
        // De este modo, las palabras con la misma clave se acumulan en la misma lista
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }

    // Obtener la colección de todos los grupos y convertirla a List<List<String>> para devolverla
    return new ArrayList<>(map.values());
}
```
