# Checking if Two Strings Are Anagrams — Determinar si dos cadenas son anagramas entre sí

## Esencia del problema

Se dan dos cadenas `s` y `t`. Se debe determinar si `t` es un anagrama de `s` y devolver un **boolean**. Un anagrama es una relación en la que dos cadenas contienen exactamente los mismos caracteres con la misma frecuencia de aparición, diferenciándose únicamente en el orden.

## Idea central

Determinar si dos cadenas son anagramas se reduce a verificar si la frecuencia de aparición de cada carácter coincide exactamente. Dado que el alfabeto en minúsculas tiene solo 26 letras, se puede gestionar la frecuencia de todos los caracteres con un arreglo de longitud fija 26, lo que permite resolver el problema en tiempo O(n) y espacio O(1).

## Proceso de razonamiento

1. **Interpretar la definición de anagrama de forma matemática**: Que dos cadenas sean anagramas significa que la frecuencia de aparición de cada carácter coincide exactamente. Es decir, se puede ignorar el orden de los caracteres y comparar únicamente las frecuencias
2. **Devolver false inmediatamente si las longitudes son diferentes**: Un anagrama contiene los mismos caracteres la misma cantidad de veces, por lo que si las cadenas tienen longitudes diferentes, no pueden ser anagramas. Verificar esto primero permite evitar procesamiento innecesario
3. **Considerar cómo comparar las frecuencias**: El alfabeto en minúsculas está limitado a 26 tipos, de la 'a' a la 'z'. En lugar de usar un HashMap, se puede utilizar un arreglo de enteros de tamaño fijo 26 para gestionar la frecuencia de cada carácter mediante su índice
4. **Procesar ambas cadenas con un solo arreglo**: En lugar de crear dos arreglos y compararlos, se incrementa el arreglo con una cadena y se decrementa con la otra. Si al final todos los elementos son 0, las frecuencias coinciden exactamente
5. **Procesar ambas cadenas dentro del mismo bucle**: Dado que se ha verificado previamente que las cadenas tienen la misma longitud, se puede realizar el incremento de `s` y el decremento de `t` simultáneamente dentro de un solo bucle for
6. **Determinación final**: Después de terminar el bucle, se verifica si todos los elementos del arreglo son 0. Si existe al menos un elemento distinto de 0, la frecuencia de algún carácter no coincide, por lo que se devuelve false

## Conocimientos previos

### Conversión de carácter a índice de arreglo

Mediante la operación `char - 'a'`, se puede convertir una letra minúscula en un entero del 0 al 25. Esto permite usar el carácter directamente como índice del arreglo.

```java
char c = 'd';
int index = c - 'a';    // 'd' - 'a' = 3 ('a'=0, 'b'=1, 'c'=2, 'd'=3)
int[] count = new int[26];
count[c - 'a']++;       // count[3] se convierte en 1 (se registra la aparición de 'd')
```

### Conteo de frecuencias con un arreglo de longitud fija

Al preparar un arreglo de enteros de tamaño 26, cada índice funciona como una tabla de frecuencias que corresponde a un carácter. En Java, `new int[26]` inicializa todos los elementos en 0.

```java
int[] count = new int[26];  // Todos los elementos se inicializan en 0
count['b' - 'a']++;        // count[1] = 1 (se registra la aparición de 'b')
count['b' - 'a']--;        // count[1] = 0 (se cancela la aparición de 'b')
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Solo se necesita recorrer la cadena una vez (n es la longitud de la cadena) |
| Space | O(1) — El tamaño del arreglo utilizado es siempre 26, sin depender de la longitud de la entrada |

## Código

```java
// Entrada: dos cadenas s y t
// Salida: devuelve true si t es un anagrama de s, false en caso contrario
public boolean isAnagram(String s, String t) {
    // Un anagrama contiene los mismos caracteres la misma cantidad de veces, por lo que si las longitudes difieren, no es un anagrama
    if (s.length() != t.length())
        return false;

    // Arreglo que registra la "diferencia" en la frecuencia de aparición de cada letra (índice 0='a', 25='z')
    // El tamaño 26 corresponde a las 26 letras de la 'a' a la 'z'
    int[] count = new int[26];

    // Se procesan ambas cadenas simultáneamente en un solo bucle (se ha verificado previamente que las longitudes son iguales)
    for (int i = 0; i < s.length(); i++) {
        // Se incrementa con el carácter de s: se registra que "este carácter apareció 1 vez en s"
        count[s.charAt(i) - 'a']++;
        // Se decrementa con el carácter de t: se registra que "este carácter apareció 1 vez en t"
        // Si el incremento y el decremento se cancelan mutuamente, la frecuencia de ese carácter es igual en s y t
        count[t.charAt(i) - 'a']--;
    }

    // Se recorren los 26 elementos; si al menos uno no es 0, las frecuencias no coinciden
    for (int c : count) {
        if (c != 0) return false;
    }
    // Todos los elementos son 0 → las frecuencias de todos los caracteres coinciden → son anagramas
    return true;
}
```
