# Computing Products Without Self Inclusion — Calcular el producto de todos los elementos excluyéndose a sí mismo

## Esencia del problema

Se recibe un arreglo de enteros `nums`. Para cada índice `i`, se debe calcular el producto de todos los elementos **excepto** `nums[i]` y devolver un arreglo `result` que contenga dichos resultados. No se permite utilizar el operador de división.

## Idea central

El producto de todos los elementos excluyendo un elemento determinado se puede descomponer en "el producto de todos los elementos a la izquierda de ese elemento" × "el producto de todos los elementos a la derecha de ese elemento". Si se construyen estos productos acumulados izquierdo y derecho mediante dos recorridos (uno hacia adelante y otro hacia atrás), el problema se resuelve en O(n) sin necesidad de división.

## Proceso de razonamiento

1. **Pensar en una descomposición alternativa, ya que no se puede usar la división**: El método de obtener el producto total y dividir por cada elemento está prohibido. Por lo tanto, se descompone `result[i]` como "el producto de los elementos a la izquierda de `nums[i]`" × "el producto de los elementos a la derecha de `nums[i]`". Esta descomposición no requiere división
2. **El producto acumulado izquierdo se construye con un recorrido hacia adelante**: Se recorre el arreglo de izquierda a derecha y se calcula, para cada posición, "el producto de todos los elementos a su izquierda". Se cumple la relación de recurrencia `result[i] = result[i-1] * nums[i-1]`. Como no existen elementos a la izquierda del primer elemento, se inicializa con `result[0] = 1` (el elemento neutro del producto)
3. **El producto acumulado derecho se construye con un recorrido hacia atrás**: Se recorre el arreglo de derecha a izquierda y se acumula en la variable `record` "el producto de todos los elementos a su derecha". Como no existen elementos a la derecha del último elemento, se inicializa con `record = 1`
4. **Se multiplican ambos productos**: Durante el recorrido hacia atrás, se multiplica `result[i]` (el producto izquierdo) por `record` (el producto derecho) para obtener la respuesta final. Después de la multiplicación, se actualiza el producto derecho con `record = record * nums[i]`
5. **No se necesitan arreglos adicionales**: El producto izquierdo se escribe directamente en el arreglo `result` y el producto derecho se gestiona con una sola variable, por lo que la memoria adicional aparte del arreglo de salida es O(1)

## Conocimientos previos

### Producto acumulado (Prefix Product / Suffix Product)

Es una secuencia de productos que se obtiene multiplicando los elementos sucesivamente desde el inicio o el final del arreglo. Es la versión multiplicativa de la suma acumulada. Permite calcular eficientemente "el producto de todos los elementos hasta cada posición".

```java
int[] nums = {1, 2, 3, 4};

// Producto acumulado desde la izquierda (prefix product)
// prefix[0] = 1 (no hay elementos a la izquierda)
// prefix[1] = 1 (hasta nums[0])
// prefix[2] = 1*2 = 2 (hasta nums[1])
// prefix[3] = 1*2*3 = 6 (hasta nums[2])

// Producto acumulado desde la derecha (suffix product)
// suffix[3] = 1 (no hay elementos a la derecha)
// suffix[2] = 4 (hasta nums[3])
// suffix[1] = 4*3 = 12 (nums[3]*nums[2])
// suffix[0] = 4*3*2 = 24 (nums[3]*nums[2]*nums[1])
```

### Elemento neutro del producto

El valor de cualquier número no cambia al multiplicarlo por 1. Al usar 1 como valor inicial del producto acumulado, se puede aplicar la misma relación de recurrencia incluso para el primer elemento.

```java
int record = 1;              // El valor inicial del producto es 1 (elemento neutro)
record = record * nums[i];   // En la primera multiplicación, record se convierte en nums[i]
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Solo se necesita recorrer el arreglo una vez hacia adelante y una vez hacia atrás |
| Space | O(1) — Excluyendo el arreglo de salida `result`, la única memoria adicional utilizada es la variable `record` |

## Código

```java
// Entrada: arreglo de enteros nums
// Salida: devuelve un int[] que contiene el producto de todos los elementos excepto el propio para cada índice
public int[] productExceptSelf(int[] nums) {
    // Se crea un arreglo de la misma longitud que nums. Primero se almacena el producto acumulado izquierdo y luego se multiplica por el producto acumulado derecho
    int[] result = new int[nums.length];

    // Recorrido hacia adelante: se almacena en result el producto de todos los elementos a la izquierda de cada posición
    result[0] = 1;  // No existen elementos a la izquierda del primer elemento, por lo que se inicializa con 1, el elemento neutro del producto
    for (int i = 1; i < nums.length; i++) {
        // result[i-1] es el producto izquierdo hasta la posición i-1. Se multiplica por nums[i-1] (el elemento inmediatamente a la izquierda) para obtener el producto izquierdo de la posición i
        result[i] = result[i - 1] * nums[i - 1];
    }

    // Recorrido hacia atrás: se multiplica el producto acumulado derecho para completar el resultado final
    // record es una variable que acumula "el producto de todos los elementos a la derecha de la posición actual"
    int record = 1;  // No existen elementos a la derecha del último elemento, por lo que se inicializa con 1
    for (int i = nums.length - 1; i >= 0; i--) {
        // result[i] contiene el producto izquierdo. Se multiplica por record (el producto derecho) para completar "el producto de todos los elementos excepto el propio"
        result[i] = record * result[i];
        // Nota: la actualización de record se realiza después de determinar result[i]. Si se actualizara antes, nums[i] quedaría incluido en el producto
        record = record * nums[i];
    }

    // Se devuelve result, donde cada elemento contiene "el producto de todos los elementos excepto el propio"
    return result;
}
```
