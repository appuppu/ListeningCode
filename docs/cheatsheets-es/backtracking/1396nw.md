# Partitioning a String Into Palindrome Substrings — Encontrar todos los patrones de partición de una cadena en subcadenas palíndromas

## Esencia del problema

Se da una cadena `s`. Se debe particionar `s` de modo que todas las subcadenas resultantes sean palíndromas (cadenas que se leen igual de izquierda a derecha que de derecha a izquierda), enumerar **todos** los patrones de partición posibles y devolver el resultado como una lista de listas.

## Idea central

Se precalcula una tabla DP que permite determinar en O(1) si cualquier subcadena es palíndroma, y luego se utiliza backtracking para extraer secuencialmente desde el inicio las "partes que son palíndromas" y recurrir, enumerando así todos los patrones de partición de manera eficiente.

## Proceso de razonamiento

1. **El problema de partición se puede expresar como una recursión que extrae subcadenas secuencialmente desde el inicio**: Desde la posición inicial `start` hasta el final de la cadena, se extrae una subcadena desde `start` hasta `end`, y se procesa recursivamente el resto. Cuando `start` alcanza el final de la cadena, se completa una partición válida
2. **La condición para extraer es que "esa parte sea palíndroma"**: Como todas las subcadenas deben ser palíndromas, solo se extrae y se agrega al camino cuando `s[start..end]` es palíndroma, y se avanza con la recursión. Si no es palíndroma, se omite esa forma de extracción
3. **Realizar la verificación de palíndromo en O(n) cada vez genera mucho desperdicio**: En cada paso del backtracking se verifica si la subcadena es palíndroma, pero existe la posibilidad de verificar la misma subcadena múltiples veces. Si se precalcula con una tabla DP, se puede reducir la verificación de palíndromo de cualquier `s[l..r]` a O(1)
4. **Método de construcción de la tabla DP**: `dp[l][r]` es un boolean que indica "si la subcadena de `s` desde el índice `l` hasta `r` es palíndroma". La condición de palíndromo es que "los caracteres en ambos extremos sean iguales" y que "la subcadena interior también sea palíndroma". Para longitud 1 (`l == r`) siempre es palíndroma, para longitud 2 (`r - l == 1`) es palíndroma si ambos extremos son iguales, y para longitud 3 o mayor es palíndroma si `s[l] == s[r]` y `dp[l+1][r-1]` es true
5. **Estructura del backtracking**: Desde la posición actual `start`, se extiende `end` de `start` a `s.length()-1` uno a uno, y si `dp[start][end]` es true, se agrega la subcadena al camino y se recurre desde `end+1`. Al regresar de la recursión, se elimina el último elemento del camino y se prueba otra forma de extracción
6. **Lo que se devuelve al final**: Cada vez que `start` alcanza `s.length()`, se agrega una copia del camino actual a la lista de resultados. Cuando toda la recursión termina, se devuelve la lista de resultados

## Conocimientos previos

### Qué es un palíndromo (Palindrome)

Es una cadena que se lee igual de izquierda a derecha que de derecha a izquierda. Por ejemplo, `"aba"`, `"aa"`, `"a"` son palíndromas. `"ab"` no es palíndroma.

### Tabla DP de palíndromos con arreglo boolean bidimensional

Es una tabla que permite determinar en O(1) si "la subcadena desde el índice `l` hasta `r` es palíndroma" mediante `dp[l][r]`. Se construye fijando el extremo derecho `r` en el bucle externo y moviendo el extremo izquierdo `l` desde `0` hasta `r` en el bucle interno.

```java
boolean[][] dp = new boolean[n][n];
for (int r = 0; r < n; r++) {
    for (int l = 0; l <= r; l++) {
        // Si los caracteres en ambos extremos son iguales y el interior es palíndromo (o la longitud es 2 o menor), entonces es palíndromo
        if (s.charAt(l) == s.charAt(r) && (r - l < 2 || dp[l + 1][r - 1])) {
            dp[l][r] = true;
        }
    }
}
dp[0][2];  // Si la subcadena de s[0] a s[2] es palíndroma → true o false
```

### Qué es el backtracking

Es una técnica de búsqueda que selecciona una opción, avanza recursivamente y, si la condición no se cumple, deshace la última selección y prueba otra opción. Se compone de tres pasos: agregar al camino (seleccionar) → recurrir → eliminar del camino (deshacer).

```java
path.add(choice);                    // Seleccionar
backtrack(nextState, path, result);  // Avanzar recursivamente
path.remove(path.size() - 1);       // Deshacer la selección y probar otro camino
```

### Método substring

`String.substring(start, end)` devuelve la subcadena desde el índice `start` hasta `end - 1`. Se debe tener en cuenta que `end` no está incluido.

```java
String s = "aab";
s.substring(0, 1);  // "a"
s.substring(0, 2);  // "aa"
s.substring(0, 3);  // "aab"
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n × 2^n) — La construcción de la tabla DP toma O(n^2), el backtracking enumera hasta 2^(n-1) particiones posibles y cada partición requiere O(n) para copiar las subcadenas |
| Space | O(n^2) — Se utiliza un arreglo boolean de n×n para la tabla DP. La profundidad máxima de la pila de recursión es O(n) |

## Código

```java
// Entrada: cadena s
// Salida: List<List<String>> que contiene todos los patrones de partición palíndroma de s
List<List<String>> partition(String s) {
    int n = s.length();

    // dp[l][r] = tabla DP que indica si la subcadena de s[l] a s[r] es palíndroma
    boolean[][] dp = new boolean[n][n];
    // El bucle externo fija el extremo derecho r, y el bucle interno recorre el extremo izquierdo l de 0 a r para construir la tabla
    for (int r = 0; r < n; r++) {
        for (int l = 0; l <= r; l++) {
            // Si los caracteres en ambos extremos son iguales y el interior es palíndromo (o la longitud es 2 o menor), entonces es palíndromo
            // Condición r - l < 2: longitud 1 siempre es palíndroma, longitud 2 es palíndroma si ambos extremos son iguales
            if (s.charAt(l) == s.charAt(r)
                && (r - l < 2
                || dp[l + 1][r - 1])) {
                dp[l][r] = true;
            }
        }
    }

    // Lista de resultados que almacena todos los patrones de partición
    List<List<String>> res = new ArrayList<>();
    // Se inicia el backtracking desde la posición 0 con un camino vacío
    bt(s, 0, new ArrayList<>(), res, dp);
    return res;
}

void bt(String s, int start,
    List<String> path,
    List<List<String>> res,
    boolean[][] dp) {
    // Se alcanzó el final de la cadena → se particionó toda la cadena en subcadenas palíndromas
    if (start == s.length()) {
        // Se agrega una copia porque path se modificará después
        res.add(new ArrayList<>(path));
        return;
    }

    // Se prueban secuencialmente las subcadenas desde start hasta end
    for (int end = start; end < s.length();
        end++) {
        // Se verifica si es palíndroma en O(1) usando la tabla DP
        if (dp[start][end]) {
            // Se agrega la parte palíndroma al camino y se recurre
            // El segundo argumento de substring es exclusivo, por lo que se especifica end + 1
            path.add(
                s.substring(start, end + 1));
            // La siguiente posición de inicio es end + 1 (justo después de la parte extraída)
            bt(s, end + 1, path, res, dp);
            // Se deshace la selección y se prueba otra forma de extracción (backtrack)
            path.remove(path.size() - 1);
        }
    }
}
```
