# Finding Combinations That Sum to a Target — Encontrar todas las combinaciones de números que suman un objetivo

## Esencia del problema

Se recibe un arreglo de enteros positivos `candidates` (todos los elementos son distintos) y un entero positivo `target`. Se deben encontrar y devolver todas las combinaciones de elementos de `candidates` cuya suma sea igual a `target`. Se puede **reutilizar el mismo número cualquier cantidad de veces**. Las combinaciones que solo difieren en el orden se consideran duplicadas.

## Idea central

Si se ordenan los candidatos previamente, en cada etapa de la recursión se puede determinar que "si el candidato actual supera el objetivo restante, todos los candidatos siguientes también lo superarán", lo que permite descartar búsquedas innecesarias por completo. Esta poda permite enumerar todas las combinaciones de manera eficiente.

## Proceso de razonamiento

1. **El backtracking es adecuado para enumerar todas las combinaciones**: Los problemas del tipo "encontrar todos los patrones que cumplan una condición" se resuelven mediante exploración recursiva (backtracking), donde se selecciona un candidato a la vez, se prueba y, si no funciona, se retrocede
2. **Para evitar duplicados, se controla la posición inicial del índice**: Se puede usar el mismo número varias veces, pero no se debe contar `[2,3]` y `[3,2]` como combinaciones distintas. Si en cada etapa de la recursión se seleccionan "solo los candidatos desde la posición actual en adelante", solo se generan combinaciones en orden ascendente y se previenen los duplicados
3. **Se gestiona el progreso mediante el objetivo restante (remain)**: Se resta cada número seleccionado del `target`; si `remain` llega a 0, significa que la suma coincide con `target`. Si `remain` se vuelve negativo, significa que la suma ha excedido el objetivo
4. **El ordenamiento permite la poda**: Si se ordenan los candidatos en orden ascendente, en el momento en que un candidato `cands[i]` supera `remain`, todos los candidatos `cands[i+1]` en adelante son aún mayores, por lo que no es necesario probarlos. Se puede interrumpir el bucle for en ese punto
5. **Se gestiona la combinación actual con una lista, repitiendo selecciones y cancelaciones**: Se agrega un elemento al final, se realiza la recursión y, al regresar, se elimina el último elemento. Este patrón de "agregar → recurrir → eliminar" es la operación básica del backtracking
6. **Cuando remain llega a 0, se agrega una copia de la combinación actual al resultado**: Si se guarda la referencia en lugar de una copia, las operaciones posteriores modificarán su contenido

## Conocimientos previos

### Qué es el backtracking

Es una técnica de búsqueda que construye candidatos de solución paso a paso y, en cuanto se determina que no cumplen la condición, retrocede al estado anterior para probar otro candidato. Se implementa con funciones recursivas, y repite el ciclo de "seleccionar → recurrir → cancelar la selección" para enumerar todos los patrones.

### Qué es Arrays.sort

Es un método que ordena un arreglo en orden ascendente. En un arreglo ordenado, se puede aprovechar la propiedad de que "si el valor actual supera la condición, todos los valores siguientes también la superarán" para realizar la poda.

```java
int[] cands = {3, 1, 2};
Arrays.sort(cands);       // cands se convierte en {1, 2, 3}
```

### Operaciones de ArrayList

Es una lista de tamaño variable. Se utiliza para agregar, eliminar y copiar elementos. En el backtracking se usa para gestionar la combinación actual.

```java
List<Integer> curr = new ArrayList<>();
curr.add(2);                          // Agrega 2 al final → [2]
curr.add(3);                          // Agrega 3 al final → [2, 3]
curr.remove(curr.size() - 1);         // Elimina el último elemento → [2] (backtrack)
new ArrayList<>(curr);                // Crea una copia de curr (para guardar el resultado)
```

### Qué es List\<List\<Integer\>\>

Es un tipo que representa "una lista de listas de enteros". Se usa para almacenar múltiples combinaciones. Cada combinación es un `List<Integer>`, y el conjunto de todas ellas es un `List<List<Integer>>`.

```java
List<List<Integer>> res = new ArrayList<>();  // Crea una lista de resultados vacía
res.add(new ArrayList<>(curr));               // Agrega una copia de la combinación al resultado
```

## Complejidad computacional

| | Valor |
|---|---|
| Tiempo | O(n^(target/min)) — n es la cantidad de candidatos y min es el valor mínimo de los candidatos. En el peor caso, se genera una ramificación que selecciona el valor mínimo target/min veces para cada candidato |
| Espacio | O(target/min) — La profundidad máxima de la recursión es target/min. El número máximo de elementos en una combinación también es target/min |

## Código

```java
// Entrada: un arreglo de enteros positivos candidates (todos los elementos son distintos) y un entero positivo target
// Salida: todas las combinaciones cuya suma sea target, devueltas como List<List<Integer>>
public List<List<Integer>> combinationSum(int[] cands, int target) {
    // El ordenamiento ascendente permite usar la condición de poda "si cands[i] > remain, todos los siguientes también lo superan"
    Arrays.sort(cands);
    // Lista para almacenar los resultados
    List<List<Integer>> res = new ArrayList<>();
    // Inicia el backtracking (restante=target, posición inicial=0, combinación actual=vacía)
    backtrack(cands, target, 0, new ArrayList<>(), res);
    return res;
}

// remain: el valor restante después de restar los números seleccionados del target. Si llega a 0, la suma coincide con target
// start: posición inicial de la exploración. Al seleccionar solo desde la posición actual en adelante, se previenen duplicados (diferencias de orden)
// curr: la combinación en construcción. Se exploran todos los patrones repitiendo selecciones y cancelaciones
void backtrack(int[] cands, int remain, int start,
               List<Integer> curr, List<List<Integer>> res) {
    // Si remain es 0, la suma coincide con target → se agrega la combinación actual al resultado
    if (remain == 0) {
        // Se crea y guarda una copia. Si se guarda la referencia, las operaciones posteriores modificarán el contenido
        res.add(new ArrayList<>(curr));
        return;
    }
    // Se recorre desde start; si cands[i] > remain, como el arreglo está ordenado, todos los siguientes también lo superan → se interrumpe el bucle (poda)
    for (int i = start; i < cands.length && cands[i] <= remain; i++) {
        // Se agrega el candidato actual al final de la combinación
        curr.add(cands[i]);
        // Se pasa i (no i+1) como tercer argumento para permitir seleccionar el mismo número repetidamente
        backtrack(cands, remain - cands[i], i, curr, res);
        // Al regresar de la recursión, se cancela el elemento agregado (backtrack). Se prepara para probar el siguiente candidato
        curr.remove(curr.size() - 1);
    }
}
```
