# Searching for a Word in a Grid — Determinar si se puede formar una palabra recorriendo caracteres en un grid

## Esencia del problema

Se proporcionan un grid 2D de caracteres `board` y una cadena `word`. Se debe determinar si es posible formar `word` recorriendo secuencialmente celdas adyacentes (arriba, abajo, izquierda, derecha) en el grid, y devolver un `boolean`. Cada celda solo se puede usar una vez por camino.

## Idea central

Se realiza una DFS desde cada celda del grid como punto de partida, comparando los caracteres de la palabra uno por uno. En lugar de gestionar las celdas visitadas con un arreglo separado, se sobrescribe directamente la celda del tablero con un carácter especial y se restaura después de la exploración, lo que reduce la complejidad espacial únicamente a la profundidad de la pila de recursión.

## Proceso de razonamiento

1. **Cualquier celda puede ser el punto de partida**: La posición inicial de la palabra puede ser cualquier celda del grid, por lo que es necesario probar todas las celdas como candidatas de inicio
2. **Se comparan los caracteres uno por uno en orden**: Se verifica si el carácter de la celda actual coincide con el carácter en la posición actual de `word`, y si coincide, se explora recursivamente hacia las celdas adyacentes en las cuatro direcciones. Esta estructura es exactamente una DFS (búsqueda en profundidad)
3. **Se debe evitar la reutilización de la misma celda**: Como no se puede usar la misma celda dos veces en un mismo camino, es necesario gestionar las celdas visitadas. Se podría usar un arreglo de visitas `boolean[][]` separado, pero esto consume espacio adicional
4. **Se sobrescribe directamente el tablero para representar las celdas visitadas**: Al entrar en la exploración, se sobrescribe el carácter de la celda actual con un carácter especial como `'#'` que no existe en el tablero, de modo que la celda no pueda coincidir nuevamente en las llamadas recursivas. Esto elimina la necesidad de un arreglo de visitas, y la complejidad espacial se reduce únicamente a la profundidad de la pila de recursión O(L)
5. **Se restaura el carácter original después de la exploración**: Al retornar de la DFS, se restaura el `'#'` sobrescrito al carácter original (backtracking). Esto permite que la misma celda se use correctamente en exploraciones desde otros puntos de partida
6. **Se organizan las condiciones de terminación de la exploración**: Si el índice `idx` alcanza `word.length()`, se han coincidido todos los caracteres con éxito y se devuelve `true`. Si se sale del rango o el carácter no coincide, se devuelve `false`. Si alguna de las 4 direcciones devuelve `true`, se devuelve `true` en ese momento

## Conocimientos previos

### ¿Qué es la DFS (búsqueda en profundidad)?

Es una técnica de exploración de grafos y grids. Se avanza lo más lejos posible en una dirección, y al llegar a un callejón sin salida, se retrocede un paso y se prueba otra dirección. Se implementa de forma natural con llamadas recursivas.

```java
void dfs(int node) {
    // Se procesa el nodo
    for (int neighbor : getNeighbors(node)) {
        dfs(neighbor);  // Se avanza recursivamente al nodo adyacente
    }
}
```

### ¿Qué es el backtracking?

Es una técnica que revierte los cambios realizados durante la exploración al retornar de ella. Mediante el ciclo "probar → avanzar → revertir", se pueden explorar todos los candidatos sin omisiones.

```java
board[r][c] = '#';   // Se modifica (se marca como visitada)
dfs(...);            // Se explora recursivamente
board[r][c] = temp;  // Se restaura (se marca como no visitada)
```

### ¿Qué es charAt?

Es un método que devuelve el carácter en la posición especificada de un `String` como tipo `char`. El índice comienza en 0.

```java
String word = "ABCCED";
word.charAt(0);   // Devuelve 'A'
word.charAt(3);   // Devuelve 'C'
word.length();    // Devuelve 6 (devuelve el número de caracteres)
```

### Exploración en 4 direcciones en un grid 2D

Para explorar las celdas adyacentes arriba, abajo, izquierda y derecha en un grid 2D, se prueban 4 patrones sumando y restando 1 a la fila y la columna respectivamente.

```java
// Se explora en el orden: arriba, abajo, izquierda, derecha
dfs(board, word, r-1, c, idx+1);  // Arriba (fila -1)
dfs(board, word, r+1, c, idx+1);  // Abajo (fila +1)
dfs(board, word, r, c-1, idx+1);  // Izquierda (columna -1)
dfs(board, word, r, c+1, idx+1);  // Derecha (columna +1)
```

## Complejidad

| | Valor |
|---|---|
| Time | O(m × n × 4^L) — Se explora desde todas las celdas como punto de partida, y desde cada una se exploran hasta 4 direcciones por L caracteres (m×n es el tamaño del grid, L es la longitud de la palabra) |
| Space | O(L) — La profundidad máxima de la pila de recursión es L. No se necesita un arreglo de visitas porque se sobrescribe directamente el tablero |

## Código

```java
// Entrada: un arreglo 2D de caracteres board y una cadena word
// Salida: devuelve true si se puede formar word con celdas adyacentes en el grid, false en caso contrario

// DFS que intenta hacer coincidir word[idx] en adelante desde la posición actual (r,c)
boolean dfs(char[][] board, String word, int r, int c, int idx) {
    // Si idx es igual a word.length(), se han coincidido todos los caracteres, por lo que se devuelve true
    if (idx == word.length()) return true;

    // Si r o c están fuera del rango del grid, o board[r][c] no coincide con word.charAt(idx), se devuelve false
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length
        || board[r][c] != word.charAt(idx))
        return false;

    // Se guarda el carácter de la celda actual en la variable temp y se sobrescribe con '#' para evitar revisitas
    // Como '#' no coincide con ninguna letra, se evita que esta celda coincida nuevamente en las llamadas recursivas (en lugar de un arreglo de visitas)
    char temp = board[r][c];
    board[r][c] = '#';

    // Se explora recursivamente en las 4 direcciones (si alguna devuelve true, es éxito)
    // Gracias a la evaluación en cortocircuito de ||, cuando se encuentra true se omite la exploración de las direcciones restantes
    boolean found =
        dfs(board, word, r - 1, c, idx + 1)
     || dfs(board, word, r + 1, c, idx + 1)
     || dfs(board, word, r, c - 1, idx + 1)
     || dfs(board, word, r, c + 1, idx + 1);

    // Se restaura el carácter original independientemente del resultado de la exploración (backtracking)
    // Esto devuelve la celda a un estado utilizable para exploraciones desde otros puntos de partida u otros caminos
    board[r][c] = temp;
    return found;
}

boolean exist(char[][] board, String word) {
    int m = board.length;
    int n = board[0].length;

    // Se recorren todas las celdas (i,j) del grid con un doble bucle for, y se llama a DFS desde cada celda como punto de partida
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // Se devuelve true en el momento en que dfs devuelve true
            if (dfs(board, word, i, j, 0))
                return true;

    // Si no se encuentra después de probar todas las celdas, se devuelve false
    return false;
}
```
