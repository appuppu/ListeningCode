# Generating All Valid Parentheses Combinations — Generar todas las combinaciones válidas de n pares de paréntesis

## Esencia del problema

Se recibe un entero `n`. Se deben generar **todas** las cadenas de paréntesis correctamente anidadas utilizando `n` paréntesis de apertura `(` y `n` paréntesis de cierre `)`, y devolverlas en una lista. La longitud de cada cadena es `2 * n`, y en ninguna posición el total acumulado de paréntesis de cierre debe superar el total acumulado de paréntesis de apertura.

## Idea central

Al construir la cadena carácter por carácter, solo dos estados determinan qué carácter se puede colocar a continuación: "la cantidad restante de paréntesis de apertura" y "la cantidad restante de paréntesis de cierre". Se puede agregar un paréntesis de apertura si se han usado menos de `n`, y se puede agregar un paréntesis de cierre solo cuando su cantidad es menor que la de paréntesis de apertura. Si se podan las ramas con estas condiciones, se pueden enumerar todas las combinaciones válidas sin generar nunca una cadena inválida.

## Proceso de razonamiento

1. **Es necesario enumerar todas las combinaciones**: El problema pide "generar todas", por lo que se necesita un método que enumere todos los patrones de forma exploratoria. El backtracking, que construye la cadena carácter por carácter y ramifica en cada paso, es el enfoque adecuado
2. **En cada paso solo hay dos opciones**: Los únicos caracteres que se pueden colocar en cada posición de la cadena son `(` o `)`. Al repetir esta elección binaria de forma recursiva, se pueden explorar todos los candidatos
3. **Se desea podar las ramas inválidas de forma temprana**: Si se prueban todas las elecciones binarias, se obtienen `2^(2n)` combinaciones, pero la mayoría son inválidas. Las condiciones de validez son dos: no se pueden usar más de `n` paréntesis de apertura, y la cantidad de paréntesis de cierre no debe superar la cantidad de paréntesis de apertura en ningún momento. Con estas dos condiciones se podan las ramas
4. **El estado se puede gestionar con dos variables**: Se pasan `open` (cantidad de paréntesis de apertura usados) y `close` (cantidad de paréntesis de cierre usados) a la función recursiva. Si `open < n` se puede agregar `(`, y si `close < open` se puede agregar `)`
5. **La cadena está completa cuando su longitud alcanza `2 * n`**: Una cadena construida respetando las condiciones de `open` y `close` que alcanza `2 * n` caracteres es necesariamente válida. Se agrega a la lista de resultados
6. **El backtracking restaura el estado**: Después de agregar un carácter al `StringBuilder` y hacer la llamada recursiva, se elimina el último carácter con `deleteCharAt` para restaurar el estado original. De esta manera, una única instancia de `StringBuilder` se comparte en todas las rutas de exploración

## Conocimientos previos

### Qué es el backtracking

El backtracking es una técnica de exploración que repite el ciclo de seleccionar, recurrir y deshacer para enumerar todas las combinaciones válidas. En cada paso se elige una de las opciones disponibles y se avanza recursivamente al siguiente paso. Al regresar de la recursión, se deshace la selección (backtrack) y se prueba otra opción. Al agregar condiciones de poda, se pueden descartar las rutas inválidas de forma temprana.

```java
// Patrón básico de backtracking
void backtrack(estado) {
    if (condiciónDeTerminación) {
        agregarAlResultado;
        return;
    }
    for (cadaOpción) {
        aplicarSelección;        // Ejemplo: sb.append('(')
        backtrack(siguienteEstado);
        deshacerSelección;       // Ejemplo: sb.deleteCharAt(sb.length() - 1)
    }
}
```

### Qué es StringBuilder

StringBuilder es una clase para construir cadenas de forma eficiente. Como `String` es inmutable (immutable) y genera un nuevo objeto cada vez que se agrega un carácter, `StringBuilder` opera directamente sobre un búfer interno, lo que permite agregar y eliminar caracteres en O(1).

```java
StringBuilder sb = new StringBuilder();  // Crear un StringBuilder vacío
sb.append('(');          // Agregar un carácter al final → "("
sb.append(')');          // Agregar un carácter al final → "()"
sb.length();             // Devolver la cantidad actual de caracteres → 2
sb.deleteCharAt(1);      // Eliminar el carácter en el índice 1 → "("
sb.toString();           // Convertir a tipo String y devolver → "("
```

### Condiciones de validez de los paréntesis

Una cadena de paréntesis es "válida" cuando cumple las dos condiciones siguientes:
- **Condición 1**: La cantidad de paréntesis de apertura y la cantidad de paréntesis de cierre son iguales
- **Condición 2**: En cualquier posición de la cadena, la cantidad de paréntesis de cierre desde el inicio hasta esa posición no supera la cantidad de paréntesis de apertura

Ejemplo: cuando `n=2`, `(())` y `()()` son válidas. `)()(` viola la condición 2, y `((()` viola la condición 1.

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(4^n / √n) — La cantidad de cadenas de paréntesis válidas generadas es el número de Catalan C(n) = C(2n,n)/(n+1), que es asintóticamente O(4^n / (n√n)). Como la construcción de cada cadena toma O(n), el total es O(4^n / √n) |
| Space | O(n) — La profundidad máxima de la recursión es 2n, y la longitud máxima del StringBuilder también es 2n. Excluyendo la lista de resultados, el espacio utilizado es O(n) |

## Código

```java
// Entrada: entero n (cantidad de pares de paréntesis)
// Salida: devuelve una List<String> que contiene todas las cadenas de paréntesis válidas
private void backtrack(StringBuilder sb, int open, int close, int n, List<String> res) {
    // Cuando la longitud de la cadena alcanza 2n, se han usado exactamente n paréntesis de apertura y n de cierre, completando una cadena de paréntesis válida
    if (sb.length() == 2 * n) {
        res.add(sb.toString());
        return;
    }
    // Si ninguna de las condiciones se cumple, no se pueden agregar más caracteres, por lo que se retorna sin hacer nada y el backtracking avanza en el nivel superior

    // Si se han usado menos de n paréntesis de apertura, todavía se puede agregar uno
    if (open < n) {
        sb.append('(');
        backtrack(sb, open + 1, close, n, res);
        // Núcleo del backtracking: eliminar el '(' del final para restaurar el estado y probar la siguiente rama (agregar paréntesis de cierre) en el estado correcto
        sb.deleteCharAt(sb.length() - 1);
    }

    // Nota: es importante que la condición sea close < open y no close < n
    // Con close < n se permitirían casos donde los paréntesis de cierre superan a los de apertura (ejemplo: ")("),
    // pero con close < open la cantidad de paréntesis de cierre siempre se mantiene menor o igual a la de apertura, evitando la generación de cadenas inválidas
    if (close < open) {
        sb.append(')');
        backtrack(sb, open, close + 1, n, res);
        sb.deleteCharAt(sb.length() - 1);  // Restaurar el estado
    }
}

public List<String> generateParenthesis(int n) {
    // Lista para almacenar todas las cadenas de paréntesis válidas
    List<String> res = new ArrayList<>();
    // Iniciar la exploración con un StringBuilder vacío y open=0, close=0
    backtrack(new StringBuilder(), 0, 0, n, res);
    return res;
}
```
