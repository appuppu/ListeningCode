# Detecting Axis-Aligned Squares From Points — Contar cuadrados con lados paralelos a los ejes a partir de puntos almacenados

## Esencia del problema

Se diseña una estructura de datos que tiene una operación `add` para agregar puntos en un plano 2D, y una operación `count` que devuelve la cantidad de **cuadrados con lados paralelos a los ejes** (los 4 lados son paralelos al eje x o al eje y) que contienen un punto dado como uno de sus vértices. Los puntos agregados múltiples veces en la misma coordenada se tratan como puntos distintos.

## Idea central

En un cuadrado con lados paralelos a los ejes, si se determinan 2 puntos en la diagonal, los otros 2 puntos quedan definidos de forma única. Se enumeran los puntos que tienen la misma coordenada x que el punto de consulta como candidatos a compañero diagonal, y se verifica la existencia de los otros 2 vértices en O(1) mediante un HashMap, lo que permite contar los cuadrados de manera eficiente.

## Proceso de razonamiento

1. **Comprender las propiedades de un cuadrado con lados paralelos a los ejes**: Como los 4 lados son paralelos al eje x o al eje y, los 4 vértices tienen la forma `(x1,y1)`, `(x1,y2)`, `(x2,y1)`, `(x2,y2)`. Es decir, el cuadrado se compone de la combinación de 2 puntos con la misma coordenada x y 2 puntos con la misma coordenada y
2. **Determinar los 2 puntos restantes a partir de 2 puntos en la diagonal**: Si se elige el punto de consulta `(px, py)` y un punto `(px, pt_y)` con la misma coordenada x pero diferente coordenada y, la longitud del lado es `|py - pt_y|`. Los otros 2 vértices deben existir en las posiciones `(px ± side, py)` y `(px ± side, pt_y)`
3. **El cuadrado puede formarse en 2 direcciones, izquierda y derecha**: Una vez determinada la longitud del lado `side`, la otra coordenada x puede ser `px - side` o `px + side`. Es necesario verificar ambas direcciones
4. **Registrar la cantidad de puntos en cada coordenada**: Como se pueden agregar múltiples puntos en la misma coordenada, se gestiona la frecuencia de aparición de cada coordenada con un HashMap. El producto de las frecuencias de los 2 vértices restantes es la cantidad de cuadrados que se pueden formar con esa combinación
5. **Obtener rápidamente los puntos con la misma coordenada x**: Se gestiona en otro HashMap la lista de todos los puntos que tienen una coordenada x como clave. De esta manera, durante `count` se pueden enumerar eficientemente solo los puntos con la misma coordenada x
6. **Acumular y devolver el resultado**: Para cada candidato a compañero y cada dirección, se suma al resultado el producto de las frecuencias de los 2 vértices restantes

## Conocimientos previos

### Método para usar coordenadas como clave de un HashMap

Para usar una coordenada 2D `(x, y)` como clave de un HashMap, se puede convertir a la cadena `"x,y"`. Esto permite almacenar y obtener valores en O(1) para cualquier coordenada.

```java
Map<String, Integer> cnt = new HashMap<>();
String key = x + "," + y;               // Coordenada (3,5) → "3,5"
cnt.put(key, cnt.getOrDefault(key, 0) + 1);  // Incrementar en 1 la frecuencia de esa coordenada
cnt.getOrDefault(key, 0);               // Devolver 0 si la coordenada no existe
```

### Qué es computeIfAbsent

Es un método que genera y registra un nuevo valor solo cuando la clave especificada no existe en el Map. Si la clave ya existe, devuelve el valor existente tal cual. Es útil para construir un Map de listas.

```java
Map<Integer, List<int[]>> xMap = new HashMap<>();
// Si la clave 5 no existe, se crea un nuevo ArrayList; si existe, se devuelve esa lista
xMap.computeIfAbsent(5, k -> new ArrayList<>()).add(new int[]{5, 3});
```

### Cómo contar combinaciones (regla del producto)

Cuando hay `c1` opciones y `c2` opciones en dos elecciones independientes, el número total de combinaciones es `c1 * c2`. En este problema, si existen `c1` puntos y `c2` puntos en las coordenadas de los 2 vértices restantes, el número de formas de elegir esos 2 vértices es `c1 * c2`.

## Complejidad computacional

| | Valor |
|---|---|
| Time | add: O(1) — Solo registro en el HashMap. count: O(n) — Se recorren todos los puntos con la misma coordenada x |
| Space | O(n) — Se almacenan las coordenadas y frecuencias de todos los puntos en el HashMap |

## Código

```java
// add(int[] p): Agregar el punto p = [x, y] en el plano 2D
// count(int[] p): Devolver como int la cantidad de cuadrados con lados paralelos a los ejes que contienen el punto p = [x, y] como uno de sus vértices
class DetectSquares {
    // HashMap que gestiona la frecuencia de cada coordenada (clave: "x,y")
    // Se usa para obtener en O(1) cuántos puntos hay en cualquier coordenada durante count
    Map<String, Integer> cnt;
    // HashMap que gestiona la lista de puntos con la misma coordenada x (clave: coordenada x)
    // Se usa para enumerar eficientemente solo los puntos con la misma coordenada x durante count
    Map<Integer, List<int[]>> xMap;

    DetectSquares() {
        cnt = new HashMap<>();
        xMap = new HashMap<>();
    }

    void add(int[] p) {
        // Convertir la coordenada a la cadena "x,y" e incrementar la frecuencia en 1
        String key = p[0] + "," + p[1];
        cnt.put(key, cnt.getOrDefault(key, 0) + 1);

        // Agregar el punto a la lista por coordenada x (crear una nueva lista si es la primera vez para esa coordenada x)
        xMap.computeIfAbsent(p[0],
            k -> new ArrayList<>()).add(p);
    }

    int count(int[] p) {
        int res = 0;
        int px = p[0], py = p[1];

        // Obtener la lista de puntos con la misma coordenada x que el punto de consulta
        // Si la lista no existe, no se puede formar ningún cuadrado, por lo que se devuelve 0
        List<int[]> same = xMap.get(px);
        if (same == null) return 0;

        // Recorrer cada punto con la misma coordenada x como candidato a compañero
        for (int[] pt : same) {
            // Calcular la longitud del lado (valor absoluto de la diferencia de coordenadas y entre el punto de consulta y el punto compañero)
            int side = Math.abs(py - pt[1]);
            // Si tienen la misma coordenada y, la longitud del lado es 0 y no se puede formar un cuadrado, así que se omite
            if (side == 0) continue;

            // Como el cuadrado puede formarse en 2 direcciones (izquierda y derecha), se prueban ambas coordenadas x
            int[] dirs = {px - side, px + side};
            for (int nx : dirs) {
                // Obtener la frecuencia de las coordenadas de los 2 vértices restantes (nx, py) y (nx, pt[1])
                // Las coordenadas inexistentes dan 0, y el producto también es 0, por lo que no se suman automáticamente
                String k1 = nx + "," + py;
                String k2 = nx + "," + pt[1];
                int c1 = cnt.getOrDefault(k1, 0);
                int c2 = cnt.getOrDefault(k2, 0);

                // El producto de las frecuencias de los 2 vértices es la cantidad de cuadrados que se pueden formar con esta combinación (regla del producto)
                res += c1 * c2;
            }
        }
        return res;
    }
}
```
