# Finding a Valid Order to Complete All Courses — Encontrar un orden válido para completar todos los cursos

## Esencia del problema

Se recibe un conjunto de cursos etiquetados de 0 a `numCourses - 1` y un arreglo de pares de prerrequisitos `[a, b]` (el curso `b` debe completarse antes que el curso `a`). Se debe devolver un arreglo con un **orden válido de cursado** que permita completar todos los cursos. Si no existe un orden válido (es decir, si hay una dependencia circular), se devuelve un arreglo vacío.

## Idea central

Las dependencias de prerrequisitos se pueden representar como un grafo dirigido, y un orden válido de cursado corresponde a un ordenamiento topológico de dicho grafo. Si se procesan primero los nodos con grado de entrada 0 (cursos sin prerrequisitos) y se eliminan las dependencias de los nodos ya procesados, es posible ordenar correctamente todos los nodos siempre que no existan ciclos.

## Proceso de razonamiento

1. **Interpretar las dependencias como un grafo**: El prerrequisito `[a, b]` significa una arista dirigida `b → a`. Si se representan todos los prerrequisitos como aristas de un grafo dirigido, un orden válido de cursado corresponde al ordenamiento topológico de ese grafo.
2. **Determinar qué cursos se pueden tomar primero**: Los cursos sin ningún prerrequisito, es decir, aquellos cuyo grado de entrada (número de aristas que llegan al nodo) es 0, se pueden cursar de inmediato. Si se calcula el grado de entrada de cada nodo de antemano, se puede determinar en O(1) qué cursos están disponibles para iniciar.
3. **Reflejar el efecto de procesar los cursos disponibles**: Cuando un curso se marca como completado, el "número de prerrequisitos restantes" de los cursos que dependían de él disminuye en 1. Esto se expresa como un decremento del grado de entrada. Si, como resultado del decremento, el grado de entrada llega a 0, ese curso pasa a estar disponible para cursarse.
4. **Gestionar el orden de procesamiento con BFS**: Se insertan en una cola los cursos con grado de entrada 0, y cada vez que se extrae un curso de la cola, se agrega al arreglo de resultados y se decrementa el grado de entrada de sus nodos adyacentes. Los nodos cuyo grado de entrada llega a 0 tras el decremento se agregan a la cola. Esta repetición constituye el algoritmo de Kahn.
5. **Detección de dependencias circulares**: Si existe un ciclo, el grado de entrada de todos los nodos dentro del ciclo nunca llegará a 0. Por lo tanto, si el número de cursos procesados es menor que `numCourses`, se determina que existe un ciclo.
6. **Valor de retorno final**: Si el número de cursos procesados coincide con `numCourses`, se devuelve el arreglo de resultados; de lo contrario, se devuelve un arreglo vacío.

## Conocimientos previos

### ¿Qué es el ordenamiento topológico?

Es el proceso de disponer todos los nodos de un grafo acíclico dirigido (DAG) en una fila de modo que todas las aristas apunten de izquierda a derecha. Si existe una arista `u → v`, entonces `u` aparece necesariamente antes que `v` en el orden. Si el grafo contiene ciclos, el ordenamiento topológico no es posible.

### ¿Qué es el grado de entrada (in-degree)?

Es el número de aristas que llegan a un nodo determinado. Un nodo con grado de entrada 0 no depende de ningún otro nodo, por lo que se puede procesar primero.

```java
int[] indegree = new int[numCourses];  // Inicializar el grado de entrada de cada nodo en 0
indegree[a]++;  // Incrementar en 1 el grado de entrada del nodo a porque recibe una arista
--indegree[next];  // Decrementar en 1 el grado de entrada del nodo next (se resuelve un prerrequisito)
```

### ¿Qué es una lista de adyacencia (Adjacency List)?

Es una estructura de datos que, para cada nodo del grafo, mantiene una lista de los nodos a los que apuntan sus aristas salientes. Con `graph.get(u)` se obtienen todos los nodos alcanzables desde el nodo `u`.

```java
List<List<Integer>> graph = new ArrayList<>();       // Lista que almacena todo el grafo
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());  // Asignar una lista vacía a cada nodo
graph.get(u).add(v);   // Agregar una arista del nodo u al nodo v
graph.get(u);           // Obtener todos los nodos adyacentes al nodo u → [v, ...]
```

### ¿Qué es una Queue (cola)?

Es una estructura de datos de tipo primero en entrar, primero en salir (FIFO). En BFS, los nodos pendientes de procesar se gestionan mediante una cola.

```java
Queue<Integer> queue = new LinkedList<>();  // Crear una cola vacía
queue.offer(0);   // Agregar el elemento 0 al final de la cola
queue.poll();      // Extraer y devolver el elemento del frente de la cola → 0
queue.isEmpty();   // Devolver un booleano indicando si la cola está vacía → true
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(V + E) — Se procesa cada nodo (curso) y cada arista (prerrequisito) exactamente una vez |
| Space | O(V + E) — La lista de adyacencia almacena todas las aristas; el arreglo de grados de entrada, la cola y el arreglo de resultados almacenan todos los nodos |

## Código

```java
// Entrada: un entero numCourses (número total de cursos) y un arreglo bidimensional de enteros prerequisites (pares de prerrequisitos)
// Salida: devuelve un int[] con un orden válido de cursado de todos los cursos. Si no existe un orden válido, devuelve un int[] vacío
public int[] findOrder(int numCourses, int[][] prerequisites) {
    // Crear una lista de adyacencia y asignar una lista vacía a cada curso
    // Cada índice corresponde a un número de curso y contiene la lista de cursos que se pueden tomar tras completarlo
    List<List<Integer>> graph = new ArrayList<>();
    // Arreglo de grados de entrada: representa el número de prerrequisitos pendientes de cada curso
    int[] indegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++)
        graph.add(new ArrayList<>());

    // Crear aristas a partir de los prerrequisitos y calcular los grados de entrada
    // Para cada par [a, b], se crea la arista b → a, registrando que el curso a depende del curso b
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);  // Agregar la arista pre[1] → pre[0]
        indegree[pre[0]]++;  // Incrementar en 1 el grado de entrada del curso pre[0]
    }

    // Agregar a la cola los cursos con grado de entrada 0 (sin prerrequisitos)
    // Estos son los cursos que se pueden tomar primero
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    // Inicializar el arreglo de resultados y la posición de escritura
    int[] result = new int[numCourses];
    int idx = 0;

    while (!queue.isEmpty()) {
        // Extraer un curso de la cola y fijarlo en el orden de cursado
        int course = queue.poll();
        result[idx++] = course;

        // Decrementar en 1 el grado de entrada de cada nodo adyacente next de course
        // Esto refleja que course, uno de los prerrequisitos de next, ya fue completado
        for (int next : graph.get(course))
            // Si el grado de entrada llega a 0 tras el decremento, todos los prerrequisitos de next están completos, así que se agrega a la cola
            if (--indegree[next] == 0)
                queue.offer(next);
    }

    // Verificar si se procesaron todos los cursos
    // Si idx es menor que numCourses, existe una dependencia circular y se devuelve un arreglo vacío
    return idx == numCourses ? result : new int[0];
}
```
