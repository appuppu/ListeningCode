# Checking if a Graph Forms a Valid Tree — Determinar si un grafo forma un árbol válido

## Esencia del problema

Se proporcionan `n` nodos etiquetados de `0` a `n-1` y una lista de aristas no dirigidas `edges`. Se debe determinar si este grafo forma un **árbol válido (valid tree)** y devolver un `boolean`. Un árbol válido es un grafo en el que todos los nodos están conectados y no existe ningún ciclo.

## Idea central

Un árbol tiene exactamente `n-1` aristas para `n` nodos y no contiene ciclos. Si primero se verifica que el número de aristas es `n-1` y luego se utiliza Union-Find para unir cada arista detectando la presencia de ciclos, se puede determinar si el grafo es un árbol.

## Proceso de razonamiento

1. **Utilizar la condición necesaria de un árbol**: Un árbol válido siempre tiene exactamente `n-1` aristas. Si el número de aristas no es `n-1`, se puede determinar inmediatamente que no es un árbol. Esta verificación previa descarta tanto el caso de demasiadas aristas (donde seguramente existen ciclos) como el de muy pocas aristas (donde el grafo no está conectado)
2. **Considerar cómo detectar ciclos**: Incluso si el número de aristas es `n-1`, pueden existir ciclos (en cuyo caso el grafo no está conectado). Si al agregar cada arista se verifica si ambos extremos ya pertenecen al mismo componente conexo, se pueden detectar ciclos
3. **Gestionar los componentes conexos con Union-Find**: Utilizando Union-Find (estructura de conjuntos disjuntos), se puede verificar si dos nodos pertenecen al mismo componente conexo (find) y fusionar dos componentes conexos (union) en tiempo prácticamente O(1). Se inicializa el padre de cada nodo como sí mismo y se realiza union por cada arista
4. **Definir la condición de detección de ciclos**: Durante la operación union, si las raíces de los dos nodos son iguales, significa que ya están conectados. Agregar una arista adicional entre ellos crearía un ciclo, por lo que se devuelve `false`
5. **Devolver el resultado tras procesar todas las aristas**: Si después de procesar todas las aristas no se detectó ningún ciclo, combinado con el hecho de que el número de aristas es `n-1` (verificado en el paso 1), se determina que el grafo es un árbol válido y se devuelve `true`

## Conocimientos previos

### ¿Qué es Union-Find (estructura de conjuntos disjuntos)?

Es una estructura de datos que gestiona múltiples elementos dividiéndolos en grupos (conjuntos). Proporciona dos operaciones. `find` devuelve el representante (raíz) del grupo al que pertenece un elemento. `union` fusiona los grupos a los que pertenecen dos elementos en uno solo. Con la optimización de compresión de caminos y unión por rango, cada operación se ejecuta en tiempo prácticamente O(1).

```java
int[] parent = {0, 1, 2, 3, 4};  // Estado inicial: el padre de cada nodo es sí mismo
int[] rank = new int[5];          // Se inicializa el rango de cada nodo (límite superior de la altura del árbol) en 0

// find: devuelve la raíz del nodo x (con compresión de caminos)
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // Compresión de caminos: reasigna el padre directamente a la raíz
    return parent[x];
}
```

### ¿Qué es la compresión de caminos (Path Compression)?

Es una técnica de optimización que, cada vez que se llama a `find`, reasigna el padre de todos los nodos en el camino de búsqueda directamente a la raíz. Esto hace que las llamadas posteriores a `find` se aproximen a O(1). Se implementa mediante la asignación recursiva `parent[x] = find(parent[x])`.

### ¿Qué es la unión por rango (Union by Rank)?

Es una técnica que, al fusionar dos árboles, coloca el árbol con menor rango (límite superior de la altura) debajo del árbol con mayor rango. Esto suprime el aumento de la altura del árbol y mantiene corta la distancia de búsqueda de `find`. Solo cuando los rangos son iguales se incrementa el rango en 1 después de la fusión.

```java
// union: fusiona los grupos del nodo a y del nodo b. Devuelve false si ya pertenecen al mismo grupo
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // Se obtiene la raíz de cada nodo
    if (ra == rb) return false;       // Misma raíz → ya están en el mismo grupo → ciclo
    if (rank[ra] < rank[rb])
        parent[ra] = rb;             // Se coloca el de menor rango debajo del de mayor rango
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;             // Si los rangos son iguales, se coloca rb debajo de ra
        rank[ra]++;                   // Se incrementa el rango en 1
    }
    return true;
}
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n × α(n)) — Se ejecutan find y union por cada arista. α(n) es la función inversa de Ackermann, que en la práctica se considera constante |
| Space | O(n) — Se almacenan n elementos en cada una de las matrices parent y rank |

## Código

```java
// Entrada: entero n (número de nodos) y matriz bidimensional de enteros edges (cada elemento es una arista no dirigida [u, v])
// Salida: devuelve true si el grafo es un árbol válido, false en caso contrario

// Matriz parent: gestiona el padre de cada nodo
int[] parent, rank;

// Devuelve la raíz del componente conexo al que pertenece el nodo x (con compresión de caminos)
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // Compresión de caminos: reasigna el padre directamente a la raíz
    return parent[x];
}

// Fusiona los componentes conexos del nodo a y del nodo b. Devuelve false si se produciría un ciclo
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // Se obtiene la raíz de ambos extremos
    if (ra == rb) return false;       // Si tienen la misma raíz, se produciría un ciclo → agregar esta arista crearía un ciclo
    // Se coloca el de menor rango debajo del de mayor rango para suprimir la altura del árbol
    if (rank[ra] < rank[rb])
        parent[ra] = rb;
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;
        rank[ra]++;
    }
    return true;
}

public boolean validTree(int n, int[][] edges) {
    // El número de aristas de un árbol debe ser igual al número de nodos menos 1 (si hay más, existe un ciclo; si hay menos, no está conectado)
    if (edges.length != n - 1)
        return false;

    // Se inicializa el padre de cada nodo como sí mismo (cada nodo forma un componente conexo independiente)
    parent = new int[n];
    rank = new int[n];
    for (int i = 0; i < n; i++)
        parent[i] = i;

    // Se procesa cada arista; si ambos extremos ya pertenecen al mismo componente conexo, se produciría un ciclo, por lo que se devuelve false
    for (int[] e : edges)
        if (!union(e[0], e[1]))
            return false;

    // Se procesaron todas las aristas sin detectar ciclos y el número de aristas es n-1, por lo que el grafo es un árbol válido
    return true;
}
```
