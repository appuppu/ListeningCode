# Finding All Words From a Dictionary in a Grid — Buscar simultáneamente todas las palabras del diccionario en una cuadrícula

## Esencia del problema

Se proporcionan una cuadrícula 2D de caracteres `board` y una lista de palabras `words`. El objetivo es encontrar y devolver todas las palabras de `words` que se pueden formar recorriendo secuencialmente celdas adyacentes (arriba, abajo, izquierda, derecha) en la cuadrícula. Cada celda solo se puede usar una vez durante la formación de una palabra.

## Idea central

Se almacenan todas las palabras de la lista en un Trie y, al realizar DFS desde cada celda de la cuadrícula, se recorren los nodos del Trie para buscar todas las palabras simultáneamente. Como el DFS se interrumpe inmediatamente en las direcciones donde no existen ramas del Trie, se reduce drásticamente la exploración innecesaria.

## Proceso de razonamiento

1. **Se desea buscar múltiples palabras simultáneamente**: Si se ejecuta un DFS individual por cada palabra, la complejidad es número de palabras × total de celdas × longitud máxima de palabra. Cuando varias palabras comparten el mismo prefijo, es eficiente buscar múltiples palabras simultáneamente en un solo DFS
2. **El Trie es adecuado para gestionar prefijos comunes**: El Trie, también llamado árbol de prefijos, comparte los prefijos comunes de cadenas en un único camino. Si se insertan todas las palabras en el Trie, durante el DFS se puede determinar en O(1) si el camino actual corresponde al prefijo de alguna palabra
3. **Se almacena la palabra completa en el nodo del Trie**: Si se guarda la cadena completa de la palabra en el nodo terminal, cuando el DFS alcanza ese nodo se puede obtener inmediatamente qué palabra se encontró
4. **Se ejecuta DFS desde cada celda de la cuadrícula con la raíz del Trie como punto de partida**: Tomando cada celda como punto de inicio, se realiza DFS recorriendo los caracteres desde la raíz del Trie. Si no existe un nodo hijo en el Trie correspondiente al carácter actual, se interrumpe inmediatamente la exploración en esa dirección (poda)
5. **Marcado de celdas visitadas**: Para evitar revisitar la misma celda durante el DFS, se reemplaza temporalmente el carácter de la celda visitada por el carácter especial `'#'`. Tras finalizar el DFS, se restaura el carácter original (backtracking)
6. **Prevención de duplicados**: Es posible que la misma palabra se encuentre por múltiples caminos. Al agregar la palabra a la lista de resultados, se establece `word` del nodo del Trie en `null` para evitar agregar la misma palabra duplicadamente

## Conocimientos previos

### ¿Qué es un Trie (árbol de prefijos)?

Es una estructura de árbol para almacenar y buscar eficientemente un conjunto de cadenas. Cada nodo tiene hasta 26 nodos hijos (a–z), y el camino desde la raíz hasta una hoja representa una cadena. Las cadenas con prefijos comunes comparten el camino, por lo que la verificación de prefijos se realiza en O(longitud de la cadena).

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // Arreglo de 26 nodos hijos para las letras a–z
    String word = null;                       // Palabra completada en este nodo (null si no es terminal)
}

// Inserción de una palabra en el Trie
TrieNode root = new TrieNode();
TrieNode node = root;
for (char c : "cat".toCharArray()) {
    int i = c - 'a';                          // Convertir carácter a índice ('a'→0, 'b'→1, ...)
    if (node.children[i] == null)
        node.children[i] = new TrieNode();    // Crear nuevo nodo hijo si no existe
    node = node.children[i];                  // Avanzar al nodo hijo
}
node.word = "cat";                            // Almacenar la palabra en el nodo terminal
```

### ¿Qué es el backtracking?

Es una variante de DFS (búsqueda en profundidad) en la que se modifica el estado durante la exploración y se restaura al finalizar. Esto garantiza que los cambios de estado realizados en un camino de exploración no afecten a otros caminos.

```java
board[r][c] = '#';    // Marcar como visitado (evitar que otros caminos revisiten esta celda)
// ... Explorar arriba, abajo, izquierda y derecha con DFS ...
board[r][c] = ch;     // Restaurar el carácter original (permitir su reutilización en exploraciones desde otros puntos de inicio)
```

### Conversión entre char e int

En Java, el tipo `char` tiene un valor entero, por lo que se puede calcular la diferencia entre caracteres para convertirlo en un índice.

```java
char ch = 'c';
int index = ch - 'a';   // 'c' - 'a' = 2 (se usa como índice del arreglo)
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(M × N × 4^L) — M×N es el número de celdas de la cuadrícula y L es la longitud de la palabra más larga. Desde cada celda se recurre hasta 4 direcciones L veces |
| Space | O(suma total de caracteres de todas las palabras) — Espacio para almacenar todas las palabras en el Trie |

## Código

```java
// Entrada: arreglo 2D de caracteres board y arreglo de cadenas words
// Salida: devuelve una List<String> con todas las palabras que se pueden formar en board

class TrieNode {
    TrieNode[] children = new TrieNode[26];  // Nodos hijos para a–z
    String word = null;                       // Palabra completada en este nodo
}

// Insertar todas las palabras en el Trie y devolver el nodo raíz
TrieNode buildTrie(String[] words) {
    // Se crea un nodo raíz para construir un Trie vacío (punto de partida para la búsqueda de todas las palabras)
    TrieNode root = new TrieNode();
    // Se inserta cada palabra de words en el Trie
    for (String w : words) {
        TrieNode node = root;
        // Se recorren los nodos hijos carácter por carácter desde la raíz
        for (char c : w.toCharArray()) {
            int i = c - 'a';
            // Si el nodo hijo no existe, se crea uno nuevo
            if (node.children[i] == null)
                node.children[i] = new TrieNode();
            node = node.children[i];
        }
        // Se almacena la cadena de la palabra en el nodo terminal (permite obtener inmediatamente la palabra completada al alcanzar el nodo durante el DFS)
        node.word = w;
    }
    return root;
}

// Realizar DFS en la cuadrícula recorriendo los nodos del Trie
void dfs(char[][] board, int r, int c,
    TrieNode node, List<String> res) {
    // Verificación de límites: si la fila r o la columna c están fuera del rango de la cuadrícula, se retorna inmediatamente
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length)
        return;
    char ch = board[r][c];
    // Si la celda tiene la marca de visitado '#', se retorna inmediatamente (evitar revisitas dentro del mismo camino)
    if (ch == '#') return;
    // Se obtiene el nodo hijo del Trie correspondiente al carácter actual
    TrieNode next = node.children[ch - 'a'];
    // Si no existe nodo hijo, no hay ninguna palabra en el Trie que continúe en esta dirección (poda)
    if (next == null) return;
    // Si se completó una palabra, se agrega al resultado y se establece en null para prevenir duplicados
    // (ya que la misma palabra podría encontrarse por múltiples caminos)
    if (next.word != null) {
        res.add(next.word);
        next.word = null;
    }
    // Se reemplaza la celda actual por '#' para marcarla como visitada
    board[r][c] = '#';
    // Se realiza DFS recursivo en las 4 direcciones (arriba, abajo, izquierda, derecha) pasando el nodo next
    dfs(board, r + 1, c, next, res);
    dfs(board, r - 1, c, next, res);
    dfs(board, r, c + 1, next, res);
    dfs(board, r, c - 1, next, res);
    // Se restaura el carácter original ch en la celda (backtracking: permitir su reutilización en exploraciones desde otros puntos de inicio)
    board[r][c] = ch;
}

// Función principal: buscar todas las palabras del diccionario en la cuadrícula
List<String> findWords(char[][] board, String[] words) {
    // Insertar todas las palabras en el Trie
    TrieNode root = buildTrie(words);
    // Crear una lista vacía para almacenar los resultados
    List<String> res = new ArrayList<>();
    // Recorrer todas las celdas (i, j) con un doble bucle for y ejecutar DFS desde cada celda como punto de inicio
    // Se pasa el nodo raíz del Trie al DFS
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            dfs(board, i, j, root, res);
        }
    }
    // Después de completar el DFS desde todas las celdas, se devuelven los resultados
    return res;
}
```
