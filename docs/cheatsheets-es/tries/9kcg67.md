# Designing a Word Dictionary With Wildcard Search — Búsqueda de palabras en un diccionario con comodines

## Esencia del problema

Se diseña una estructura de datos que soporta dos operaciones: agregar palabras y buscar palabras. Durante la búsqueda, el punto `.` funciona como un comodín que coincide con cualquier carácter individual. Por ejemplo, si la palabra "bad" está registrada en el diccionario, `search("b.d")` devuelve `true` y `search("b.e")` devuelve `false`.

## Idea central

Las palabras se almacenan en un Trie. Para los caracteres normales, basta con seguir un único nodo hijo. Sin embargo, cuando se encuentra un punto, la búsqueda se ramifica hacia "todos los nodos hijos" y realiza una búsqueda en profundidad (DFS), lo que permite lograr la coincidencia con cualquier carácter individual.

## Proceso de razonamiento

1. **Se busca agregar palabras y realizar búsquedas por prefijo de manera eficiente**: El Trie es la estructura de datos adecuada, ya que permite almacenar cadenas compartiendo los caracteres uno a uno. Con un Trie, las palabras que comparten un prefijo común comparten nodos, logrando eficiencia tanto en memoria como en búsqueda
2. **La búsqueda de caracteres normales se resuelve con la operación básica del Trie**: Para un carácter `c`, basta con seguir `children[c - 'a']` del nodo actual. Si el nodo hijo es `null`, no hay coincidencia; si existe, se avanza al siguiente carácter
3. **El punto implica una ramificación hacia todos los nodos hijos**: Dado que el punto coincide con cualquier carácter individual, es necesario probar todos los nodos hijos no nulos entre los 26 hijos del nodo actual. Si al menos uno de ellos coincide con el resto de la cadena, se devuelve `true`
4. **Se utiliza la búsqueda en profundidad (DFS) para explorar las ramificaciones**: Cada ruta ramificada por un punto se recorre recursivamente. Cuando se alcanza el final de la palabra y el indicador `isEnd` es `true`, la búsqueda es exitosa. La DFS permite tratar de manera uniforme tanto el procesamiento de ramificaciones como el de caracteres normales
5. **Se define la condición de terminación de la recursión**: Cuando se han procesado todos los caracteres de la cadena (`idx == word.length()`), si `isEnd` del nodo actual es `true`, la palabra existe. Si un nodo hijo resulta `null` en algún punto intermedio, esa ruta no tiene coincidencia
6. **Valor de retorno final**: El método `search` inicia la DFS recursivamente desde el nodo raíz y devuelve `true` si existe al menos una ruta que coincida, o `false` en caso contrario

## Conocimientos previos

### ¿Qué es un Trie (árbol de prefijos)?

Es una estructura de árbol que almacena cadenas descomponiéndolas carácter por carácter en nodos. Cada nodo tiene un máximo de 26 nodos hijos (de la a a la z), y al recorrer desde la raíz hacia las hojas se forma una palabra. Las palabras que comparten un prefijo común comparten nodos, lo que lo hace adecuado para almacenar diccionarios.

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // 26 nodos hijos correspondientes a las letras de la a a la z
    boolean isEnd = false;                    // Indica si existe una palabra que termina en este punto
}
```

### ¿Qué es la búsqueda en profundidad (DFS)?

Es una técnica de exploración de árboles y grafos. Se avanza por una ruta hasta llegar al final, y al encontrar un callejón sin salida, se retrocede un paso para probar otra ruta. Se implementa de forma natural con recursión y es adecuada para la exploración ramificada de un Trie.

```java
}
```

### Conversión de char a entero

En Java, el tipo `char` tiene un valor entero. Con `c - 'a'` se obtiene la posición alfabética del carácter `c` (de 0 a 25). Este valor se utiliza como índice del arreglo `children` del Trie.

```java
char c = 'd';
int idx = c - 'a';  // idx = 3 ('a'=0, 'b'=1, 'c'=2, 'd'=3)
```

## Complejidad computacional

| | Valor |
|---|---|
| Time (addWord) | O(m) — Se recorren los nodos del Trie de forma proporcional a la longitud m de la palabra |
| Time (search) | O(26^d × m) — d es la cantidad de puntos y m es la longitud de la palabra. Sin puntos, es O(m) |
| Space | O(n × m) — Se almacenan n palabras (de longitud promedio m) en el Trie |

## Código

```java
// Entrada: addWord(word) recibe la cadena word y la agrega al diccionario. search(word) recibe la cadena word (que puede contener ".")
// Salida: search devuelve true si existe una palabra coincidente en el diccionario, o false en caso contrario

class TrieNode {
    TrieNode[] children;  // 26 nodos hijos correspondientes a las letras de la a a la z
    boolean isEnd;        // Indica si existe una palabra que termina en este punto

    TrieNode() {
        children = new TrieNode[26];
        isEnd = false;
    }
}

class WordDictionary {
    TrieNode root;  // Nodo raíz del Trie

    WordDictionary() {
        root = new TrieNode();
    }

    // Agrega una palabra al Trie
    void addWord(String word) {
        // Se inicializa el nodo actual con la raíz
        TrieNode node = root;
        // Se procesan los caracteres de la palabra en orden desde el inicio
        for (char c : word.toCharArray()) {
            // Se calcula la posición en el arreglo children que corresponde al carácter c mediante c - 'a'
            int idx = c - 'a';
            // Si el nodo hijo no existe, se crea uno nuevo
            if (node.children[idx] == null)
                node.children[idx] = new TrieNode();
            // Se avanza al nodo hijo
            node = node.children[idx];
        }
        // Se registra el final de la palabra. Esto indica que existe una palabra en el diccionario que termina en este punto
        node.isEnd = true;
    }

    // Se inicia la búsqueda con comodines desde la raíz
    boolean search(String word) {
        // Se inicia la DFS desde el nodo raíz en la posición 0
        return dfs(root, word, 0);
    }

    // Se explora el Trie recursivamente mediante DFS
    boolean dfs(TrieNode node, String word, int idx) {
        // Condición de terminación: si se han procesado todos los caracteres, se devuelve si el nodo actual es un final de palabra
        // Si es true, la palabra existe; si es false, solo existe una coincidencia parcial
        if (idx == word.length())
            return node.isEnd;

        char c = word.charAt(idx);

        if (c == '.') {
            // Caso del punto: se prueban los 26 nodos hijos (coincidencia con cualquier carácter individual)
            for (TrieNode child : node.children) {
                // Se exploran recursivamente los nodos hijos que no sean null
                if (child != null && dfs(child, word, idx + 1))
                    return true;  // Si alguna ruta coincide, se devuelve true inmediatamente
            }
            // Si ningún nodo hijo devuelve true, no hay coincidencia
            return false;
        } else {
            // Caso de carácter normal: se calcula el índice con c - 'a' y se sigue el nodo hijo correspondiente
            int i = c - 'a';
            // Si el nodo hijo no existe, no hay carácter correspondiente y no hay coincidencia
            if (node.children[i] == null)
                return false;
            // Si el nodo hijo existe, se recurre con la siguiente posición de carácter idx + 1
            return dfs(node.children[i], word, idx + 1);
        }
    }
}
```
