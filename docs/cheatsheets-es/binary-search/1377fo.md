# Finding the Minimum Eating Speed to Finish Bananas — Encontrar la velocidad mínima para comer todos los plátanos dentro del tiempo límite

## Esencia del problema

Se recibe un arreglo de montones de plátanos `piles` y un tiempo límite `h` (en horas). Si se comen `k` plátanos por hora, se debe devolver **la velocidad entera mínima `k`** que permite comer todos los plátanos en `h` horas o menos. Solo se puede comer de un montón por hora, y si un montón tiene menos de `k` plátanos, se termina ese montón pero se debe esperar el resto de la hora sin avanzar al siguiente.

## Idea central

La pregunta "¿Se pueden comer todos los plátanos a velocidad `k`?" tiene monotonía respecto a `k`. Si `k` es suficientemente grande, siempre se pueden comer todos; si es demasiado pequeño, no se puede. Gracias a esta monotonía, se puede aplicar búsqueda binaria sobre el rango de candidatos `[1, max(piles)]` para encontrar eficientemente el `k` mínimo que cumple la condición.

## Proceso de razonamiento

1. **Existe monotonía entre la velocidad y el resultado**: Al aumentar la velocidad `k`, el tiempo necesario disminuye; al disminuirla, aumenta. Si se pueden comer todos los plátanos a cierta velocidad, también se puede a cualquier velocidad mayor. Esta estructura de "encontrar el valor mínimo que cumple cierta condición" es un patrón típico de búsqueda binaria
2. **Definir el rango de búsqueda**: El valor mínimo de la velocidad es `1` (se come al menos 1 plátano por hora) y el valor máximo es `max(piles)` (velocidad suficiente para comer el montón más grande en 1 hora). Usar una velocidad mayor que `max(piles)` no cambia el resultado, ya que solo se puede comer de un montón por hora
3. **Diseñar la función de evaluación**: Dada una velocidad `mid`, comer cada montón `piles[i]` toma `ceil(piles[i] / mid)` horas. Si la suma total de horas es menor o igual a `h`, se determina que esa velocidad es suficiente
4. **Realizar la división con techo mediante aritmética entera**: `ceil(piles[i] / mid)` se calcula como `(piles[i] + mid - 1) / mid`. Esto evita la aritmética de punto flotante y permite un cálculo exacto usando solo enteros
5. **Reducir el rango con búsqueda binaria**: Si se puede terminar de comer con el valor medio `mid`, la respuesta está en `mid` o menos, así que se asigna `right = mid`. Si no se puede, la respuesta está en `mid + 1` o más, así que se asigna `left = mid + 1`. Cuando `left == right`, ese valor es la velocidad mínima buscada

## Conocimientos previos

### Patrón de búsqueda binaria para "el valor mínimo que cumple una condición"

Técnica para encontrar el valor mínimo (o máximo) que satisface cierta condición dentro de un rango de valores ordenados o enteros consecutivos. Como el rango de búsqueda se reduce a la mitad en cada iteración, la respuesta se encuentra en O(log n).

```java
int left = 1;               // Límite inferior del rango de búsqueda
int right = 1000;            // Límite superior del rango de búsqueda
while (left < right) {       // Cuando left == right, la respuesta está determinada
    int mid = left + (right - left) / 2;  // Cálculo del punto medio que evita desbordamiento
    if (condition(mid))       // Se evalúa si mid cumple la condición
        right = mid;          // Cumple la condición → la respuesta está en mid o menos
    else
        left = mid + 1;       // No cumple la condición → la respuesta está en mid+1 o más
}
// left es el valor mínimo que cumple la condición
```

### División con techo (Ceiling Division)

Operación entera que redondea hacia arriba el resultado de `a / b`. Se calcula como `(a + b - 1) / b` sin necesidad de usar `Math.ceil`.

```java
int a = 10, b = 3;
int result = (a + b - 1) / b;  // (10 + 2) / 3 = 4  (10÷3=3.33... → se redondea hacia arriba a 4)
```

En el problema de los plátanos, se divide el tamaño del montón `piles[i]` entre la velocidad `k` y se redondea hacia arriba para obtener el número de horas necesarias para comer ese montón.

### Qué es Math.max

Método que devuelve el mayor de dos valores. Se usa en combinación con un bucle para encontrar el valor máximo de un arreglo.

```java
Math.max(5, 3);   // → 5
Math.max(-1, 0);  // → 0
```

## Complejidad

| | Valor |
|---|---|
| Time | O(n × log(max(piles))) — Se realizan O(log(max(piles))) iteraciones de búsqueda binaria, y en cada iteración se recorre todo el arreglo en O(n) para calcular el tiempo total |
| Space | O(1) — No se utilizan estructuras de datos adicionales; el procesamiento se realiza solo con variables |

## Código

```java
// Entrada: arreglo de enteros piles (número de plátanos en cada montón) y entero h (tiempo límite)
// Salida: se devuelve como int la velocidad entera mínima k que permite comer todos los plátanos en h horas o menos
public int minEatingSpeed(int[] piles, int h) {
    // Se establece el límite inferior de la búsqueda binaria en 1. La velocidad mínima es de 1 plátano por hora
    int left = 1;
    // Se establece el límite superior de la búsqueda binaria en el valor máximo del arreglo
    // No tiene sentido usar una velocidad mayor que la necesaria para comer el montón más grande en 1 hora, por lo que este valor es el límite superior
    int right = 0;
    for (int p : piles) {
        right = Math.max(right, p);
    }

    // Se reduce el rango de búsqueda a la mitad hasta que left == right
    // Cuando left == right, ese valor es la respuesta
    while (left < right) {
        // Cálculo del punto medio que evita desbordamiento
        // Se usa left + (right - left) / 2 en lugar de (left + right) / 2 para prevenir desbordamiento de enteros
        int mid = left + (right - left) / 2;

        // Se calcula el tiempo total necesario para comer todos los plátanos a velocidad mid
        int totalHours = 0;
        for (int p : piles) {
            // División con techo: se obtiene el número de horas necesarias para comer cada montón
            totalHours += (p + mid - 1) / mid;
        }

        if (totalHours <= h) {
            // Se puede terminar → existe la posibilidad de terminar con una velocidad menor, así que se reduce el límite superior
            // Como mid mismo puede ser la respuesta, se asigna mid en lugar de mid - 1
            right = mid;
        } else {
            // No se puede terminar → la velocidad es insuficiente, así que se aumenta el límite inferior
            // Como mid no puede ser la respuesta, se asigna mid + 1
            left = mid + 1;
        }
    }

    // Al finalizar el bucle, left (= right) es la velocidad mínima que cumple la condición
    return left;
}
```
