# Finding the Missing Number in a Sequence — Encontrar el número faltante en una secuencia de 0 a n

## Esencia del problema

Se da un arreglo `nums` que contiene n números distintos del rango de 0 a n. Se debe encontrar y devolver **el único número faltante** que pertenece al rango pero no existe en el arreglo.

## Idea central

XOR cancela y se convierte en cero cuando se aplica dos veces al mismo valor. Si se aplica XOR a los índices del arreglo (0 a n-1), al valor n y a todos los elementos del arreglo, los números que forman pares se cancelan entre sí y solo queda el "número faltante" que no tiene par.

## Proceso de razonamiento

1. **Todos los números excepto el faltante forman pares**: Los índices del arreglo van de 0 a n-1, y los valores del arreglo son del rango 0 a n excluyendo el número faltante. Es decir, si se añade n como valor inicial en el lado de los índices, todos los enteros de 0 a n quedan cubiertos en el lado de los índices. Solo el número faltante no existe en el lado de los valores del arreglo, por lo que no forma par
2. **XOR es la operación óptima para cancelar pares**: XOR tiene las propiedades `a ^ a = 0` (los valores iguales se cancelan entre sí) y `a ^ 0 = a` (XOR con cero preserva el valor). Si se aplica XOR a todos los índices y valores, todos los números con par se convierten en 0 y solo queda el número faltante sin par
3. **Razón de establecer el valor inicial en n**: El índice del bucle for solo cubre el rango de 0 a n-1. Sin embargo, el número faltante podría ser n, por lo que se establece n como valor inicial del XOR para cubrir todo el rango de 0 a n
4. **Se completa en un solo recorrido**: Dentro del bucle se realizan simultáneamente `xor ^= i` (XOR del índice) y `xor ^= nums[i]` (XOR del valor), por lo que se obtiene el resultado con un solo recorrido del arreglo. No se necesitan estructuras de datos adicionales

## Conocimientos previos

### Qué es XOR (OR exclusivo)

Es una operación a nivel de bits que devuelve 1 cuando los dos bits son diferentes y 0 cuando son iguales. En Java se utiliza con el operador `^`. Se aplica bit a bit a los enteros.

```java
int a = 5;          // Binario: 101
int b = 3;          // Binario: 011
int result = a ^ b; // Binario: 110 → 6
```

### Propiedades importantes de XOR

Existen tres propiedades fundamentales para el algoritmo.

```java
// Propiedad 1: XOR de un valor consigo mismo es 0 (cancelación)
5 ^ 5;    // → 0

// Propiedad 2: XOR con 0 preserva el valor original
5 ^ 0;    // → 5

// Propiedad 3: El resultado es el mismo independientemente del orden (ley conmutativa y asociativa)
(2 ^ 5) ^ 2;  // → 5 (los dos 2 se cancelan entre sí y queda 5)
```

### Qué es el operador ^=

Es un operador de asignación compuesta que asigna el resultado de la operación XOR a la variable del lado izquierdo. `xor ^= i` tiene el mismo significado que `xor = xor ^ i`.

```java
int xor = 0;
xor ^= 3;   // xor = 0 ^ 3 → 3
xor ^= 3;   // xor = 3 ^ 3 → 0 (se cancela con el mismo valor)
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Solo se necesita un recorrido del arreglo |
| Space | O(1) — No se utilizan estructuras de datos adicionales, solo una variable |

## Código

```java
// Entrada: arreglo nums que contiene n enteros distintos del rango 0 a n
// Salida: devuelve el único entero del rango que no está en el arreglo
public int missingNumber(int[] nums) {
    // Al establecer el valor inicial en n, junto con los índices del bucle 0 a n-1, se cubre todo el rango de 0 a n
    // El índice del bucle for solo cubre de 0 a n-1, por eso se asigna n aquí como valor inicial
    int xor = nums.length;

    for (int i = 0; i < nums.length; i++) {
        // Se acumula el índice i en el valor XOR acumulado
        // Al finalizar el bucle, todos los índices de 0 a n-1 habrán sido aplicados con XOR (junto con el valor inicial n, se habrán aplicado XOR a todos los enteros de 0 a n)
        xor ^= i;
        // Se acumula el valor del arreglo en el valor XOR acumulado
        // Los números presentes en el arreglo aparecen tanto en el lado de los índices como en el lado de los valores, por lo que se cancelan entre sí por la propiedad a ^ a = 0
        xor ^= nums[i];
    }

    // Todos los números con par se cancelan y se convierten en 0, y solo queda el número faltante que no estaba en el arreglo porque no tiene par
    return xor;
}
```
