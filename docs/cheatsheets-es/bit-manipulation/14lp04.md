# Reversing the Digits of an Integer — Invertir cada dígito de un entero con signo de 32 bits

## Esencia del problema

Se recibe un entero con signo de 32 bits `x`. Se debe devolver el entero resultante de reordenar los dígitos de `x` en orden inverso. Si el valor invertido excede el rango de un entero con signo de 32 bits (de -2³¹ a 2³¹-1), se devuelve `0`.

## Idea central

El último dígito de un entero se puede extraer con `x % 10`, y se puede eliminar con `x / 10`. Al repetir esta operación de "extraer y acumular", los dígitos se invierten de forma natural. Verificando el desbordamiento antes de cada acumulación, se puede construir el resultado invertido de manera segura.

## Proceso de razonamiento

1. **Método para extraer los dígitos uno a uno**: El último dígito de un entero se obtiene con `x % 10` (el residuo de dividir entre 10). Después de obtenerlo, se elimina el último dígito con `x / 10`, lo que permite acceder al siguiente dígito. Al repetir esta operación hasta que `x` sea 0, se pueden extraer todos los dígitos en orden desde el final
2. **Método para ensamblar los dígitos extraídos en orden inverso**: Se repite `result = result * 10 + digit` sobre la variable de resultado `result`. Con `result * 10` se desplazan los dígitos existentes una posición a la izquierda, y con `+ digit` se agrega el nuevo dígito en la posición de las unidades. Como los dígitos extraídos desde el final se colocan en orden desde el inicio, el orden de los dígitos se invierte de forma natural
3. **Manejo del desbordamiento**: El resultado de `result * 10 + digit` puede exceder `Integer.MAX_VALUE` (2147483647) o ser menor que `Integer.MIN_VALUE` (-2147483648). Como ya es demasiado tarde **después** de ejecutar la multiplicación, es necesario verificar **antes** de la multiplicación
4. **Método de verificación previa del desbordamiento**: Se puede determinar si `result * 10` provocará un desbordamiento comparando `result` con `Integer.MAX_VALUE / 10` (= 214748364). Si `result > 214748364`, el desbordamiento es seguro. Si `result == 214748364`, el desbordamiento ocurre cuando `digit > 7` (el dígito de las unidades de MAX_VALUE). Para valores negativos, se compara de manera similar con `Integer.MIN_VALUE / 10`
5. **Manejo del signo**: En Java, `x % 10` y `x / 10` funcionan correctamente con números negativos (`-123 % 10 == -3`, `-123 / 10 == -12`). Por lo tanto, se puede procesar directamente sin separar el signo
6. **Valor de retorno final**: El `result` al finalizar el bucle es el entero invertido. Si se detecta un desbordamiento, se devuelve `0` inmediatamente dentro del bucle

## Conocimientos previos

### Operador % (operador de residuo)

Es un operador que devuelve el residuo de dividir un entero entre otro entero. `x % 10` extrae el dígito de las unidades de `x`. En Java, el signo se conserva incluso para números negativos.

```java
123 % 10;    // → 3 (se obtiene el dígito de las unidades)
-123 % 10;   // → -3 (el signo se conserva incluso con números negativos)
123 / 10;    // → 12 (se elimina el dígito de las unidades)
-123 / 10;   // → -12 (se trunca correctamente incluso con números negativos)
```

### Rango de un entero con signo de 32 bits

Es el rango de valores que puede representar el tipo `int` de Java. Si se excede este rango, ocurre un desbordamiento y el valor se vuelve incorrecto.

```java
Integer.MAX_VALUE;   // → 2147483647 (2³¹ - 1)
Integer.MIN_VALUE;   // → -2147483648 (-2³¹)
Integer.MAX_VALUE / 10;  // → 214748364 (umbral para la verificación de desbordamiento)
Integer.MAX_VALUE % 10;  // → 7 (dígito de las unidades de MAX_VALUE)
Integer.MIN_VALUE / 10;  // → -214748364
Integer.MIN_VALUE % 10;  // → -8 (dígito de las unidades de MIN_VALUE)
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — n es el número de dígitos de `x`. Cada dígito se procesa una vez |
| Space | O(1) — Solo se utilizan las variables `result` y `digit` |

## Código

```java
// Entrada: un entero con signo de 32 bits x
// Salida: se devuelve el entero con los dígitos de x invertidos. Si el valor invertido excede el rango de 32 bits, se devuelve 0
public int reverse(int x) {
    // Variable para almacenar el resultado invertido. Los dígitos se acumulan uno a uno
    int result = 0;

    // Se extraen los dígitos de x uno a uno desde el final. Cuando x es 0, se han procesado todos los dígitos
    while (x != 0) {
        // Se extrae el dígito de las unidades de x. No se requiere tratamiento especial ya que % conserva el signo con números negativos
        int digit = x % 10;

        // Verificación previa de desbordamiento positivo (se verifica antes de la multiplicación porque después ya es tarde)
        // Si result > 214748364, entonces result * 10 excede con certeza MAX_VALUE (2147483647)
        // Si result == 214748364 y digit > 7, entonces result * 10 + digit excede MAX_VALUE (cuyo último dígito es 7)
        if (result > Integer.MAX_VALUE / 10
                || (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return 0;
        }

        // Verificación previa de desbordamiento negativo
        // Si result < -214748364, entonces result * 10 es con certeza menor que MIN_VALUE (-2147483648)
        // Si result == -214748364 y digit < -8, entonces result * 10 + digit es menor que MIN_VALUE (cuyo último dígito es -8)
        if (result < Integer.MIN_VALUE / 10
                || (result == Integer.MIN_VALUE / 10 && digit < -8)) {
            return 0;
        }

        // Con result * 10 se desplazan los dígitos existentes una posición a la izquierda, y con + digit se agrega el dígito extraído en la posición de las unidades
        // De esta manera, los dígitos finales del número original se colocan secuencialmente al inicio del resultado
        result = result * 10 + digit;

        // Se elimina el dígito de las unidades de x, exponiendo el siguiente dígito en la posición final
        x = x / 10;
    }

    // Se devuelve el resultado con todos los dígitos invertidos. En caso de desbordamiento, ya se ha devuelto 0 dentro del bucle
    return result;
}
```
