# Encontrar dos números en un arreglo ordenado que sumen un objetivo — Finding Two Numbers in a Sorted Array That Add Up to a Target

## Esencia del problema

Se recibe un arreglo de enteros ordenado `nums` y un entero `target`. Se deben encontrar dos elementos en `nums` cuya suma sea igual a `target` y devolver sus **posiciones en base 1** en un arreglo. Se garantiza que existe exactamente una solución, y no se puede usar el mismo elemento dos veces.

## Idea central

Dado que el arreglo está ordenado, se pueden utilizar dos punteros que avanzan desde ambos extremos hacia el centro. Si la suma de los dos elementos es demasiado grande, se reduce el puntero derecho; si es demasiado pequeña, se avanza el puntero izquierdo. De este modo, se encuentra la respuesta en una sola pasada con tiempo O(n) y espacio O(1).

## Proceso de razonamiento

1. **Aprovechar la condición de que el arreglo está ordenado**: Como el arreglo está ordenado, el extremo izquierdo apunta al valor mínimo y el extremo derecho apunta al valor máximo. Al comenzar la búsqueda desde la suma de ambos extremos, se puede reducir el rango de búsqueda de forma segura según si la suma es mayor o menor que el objetivo
2. **Si la suma es demasiado grande, mover el puntero derecho hacia la izquierda**: El puntero derecho apunta al valor más grande dentro del rango de búsqueda actual. Si la suma es mayor que `target`, se mueve el puntero derecho una posición a la izquierda para cambiar a un valor más pequeño y así reducir la suma
3. **Si la suma es demasiado pequeña, mover el puntero izquierdo hacia la derecha**: El puntero izquierdo apunta al valor más pequeño dentro del rango de búsqueda actual. Si la suma es menor que `target`, se mueve el puntero izquierdo una posición a la derecha para cambiar a un valor más grande y así aumentar la suma
4. **Si la suma es exactamente igual a `target`, se ha encontrado la respuesta**: Cuando la suma de los valores a los que apuntan los dos punteros coincide con `target`, ese es el par buscado. Como el problema requiere índices en base 1, se suma 1 a la posición de cada puntero antes de devolver el resultado
5. **Condición de terminación del bucle**: El bucle se repite hasta que el puntero izquierdo alcance al puntero derecho. Según las restricciones del problema, siempre existe una solución, por lo que la respuesta se encuentra antes de que los punteros se crucen
6. **Valor de retorno final**: En el momento en que la suma coincide con `target`, se devuelven `left + 1` (posición en base 1 del elemento izquierdo) y `right + 1` (posición en base 1 del elemento derecho) en un `int[]`

## Conocimientos previos

### ¿Qué es Two Pointers (dos punteros)?

Es una técnica que utiliza dos variables de índice que apuntan a distintas posiciones de un arreglo y las mueve según una condición. En arreglos ordenados, el patrón típico consiste en reducir el rango de búsqueda avanzando desde ambos extremos hacia el centro.

```java
int left = 0;                    // Se coloca el puntero izquierdo al inicio del arreglo
int right = nums.length - 1;     // Se coloca el puntero derecho al final del arreglo
while (left < right) {           // Se repite el bucle hasta que los dos punteros se crucen
    // Se mueven left y right según la condición
    left++;   // Se avanza el puntero izquierdo una posición a la derecha
    right--;  // Se retrocede el puntero derecho una posición a la izquierda
}
```

### Propiedades de un arreglo ordenado

Cuando el arreglo está ordenado en orden ascendente, siempre se cumple que `nums[left] <= nums[right]`. Al mover el puntero izquierdo hacia la derecha, la suma aumenta; al mover el puntero derecho hacia la izquierda, la suma disminuye. Gracias a esta monotonía, se puede determinar la dirección de movimiento de cada puntero en función de si la suma es mayor o menor que el objetivo.

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n) — Los dos punteros se mueven un máximo de n veces en total |
| Space | O(1) — Solo se utilizan variables para los punteros, sin estructuras de datos adicionales |

## Código

```java
// Entrada: un arreglo de enteros ordenado nums y un entero target
// Salida: se devuelve un int[] que contiene las posiciones en base 1 de los dos elementos cuya suma es igual a target
public int[] twoSum(int[] nums, int target) {
    // Se coloca el puntero izquierdo al inicio del arreglo. Es el extremo izquierdo del rango de búsqueda y se encarga del lado de los valores mínimos
    int left = 0;
    // Se coloca el puntero derecho al final del arreglo. Es el extremo derecho del rango de búsqueda y se encarga del lado de los valores máximos
    int right = nums.length - 1;

    // Se repite el bucle hasta que los dos punteros se crucen
    while (left < right) {
        // Se calcula la suma de los dos elementos actuales y se almacena en una variable para reutilizarla en cada rama condicional
        int cursum = nums[left] + nums[right];

        if (cursum == target) {
            // La suma coincide con el objetivo, por lo que se ha encontrado el par. Como el problema requiere índices en base 1, se suma 1 a cada índice antes de devolver el resultado
            return new int[]{left + 1, right + 1};
        } else if (cursum > target) {
            // La suma es demasiado grande, por lo que se mueve el puntero derecho hacia la izquierda. El valor al que apunta el puntero derecho será más pequeño y la suma disminuirá en la siguiente iteración
            right--;
        } else {
            // La suma es demasiado pequeña, por lo que se mueve el puntero izquierdo hacia la derecha. El valor al que apunta el puntero izquierdo será más grande y la suma aumentará en la siguiente iteración
            left++;
        }
    }
    // Según las restricciones del problema, siempre existe una solución, por lo que este punto nunca se alcanza
    return new int[]{};
}
```
