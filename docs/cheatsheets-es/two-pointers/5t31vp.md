# Three Sum — Encontrar todos los tripletes cuya suma sea cero

## Esencia del problema

Se recibe un arreglo de enteros `nums`. Se deben encontrar todas las combinaciones de tres elementos (tripletes) dentro de `nums` cuya suma sea `0`, y devolverlas como `List<List<Integer>>`. Cada triplete debe estar compuesto por elementos en índices distintos, y el resultado no debe contener tripletes duplicados.

## Idea central

Si se ordena el arreglo, se puede fijar un elemento y buscar eficientemente los otros dos elementos restantes con Two Pointers. Además, aprovechando el orden, se pueden omitir valores duplicados para eliminar tripletes repetidos de forma natural.

## Proceso de razonamiento

1. **Reducir el problema de 3 elementos a uno de 2 elementos**: La ecuación `a + b + c = 0` se transforma, al fijar un elemento `a = nums[i]`, en el problema de búsqueda de dos elementos `b + c = -a`. Si se fija `a` con un bucle for externo y se buscan `b` y `c` en el interior, se puede aplicar el enfoque conocido de Two Sum
2. **Ordenar el arreglo para usar Two Pointers**: Para buscar eficientemente los dos elementos, se ordena el arreglo y se estrechan los punteros desde ambos extremos con Two Pointers. Si la suma es demasiado pequeña, se mueve el puntero izquierdo hacia la derecha; si es demasiado grande, se mueve el puntero derecho hacia la izquierda. De esta forma, se exploran todos los pares de manera eficiente
3. **Eliminar tripletes duplicados mediante el ordenamiento**: En un arreglo ordenado, los valores iguales quedan adyacentes. Si `nums[i]` en el bucle externo tiene el mismo valor que el elemento anterior, se omite. En el bucle interno, después de encontrar un par, también se omiten los valores repetidos de `left` y `right` mientras sean iguales, evitando así incluir tripletes duplicados en el resultado
4. **Definir el rango del bucle externo**: Como se necesitan tres elementos, `i` recorre desde `0` hasta `nums.length - 3`. `left` comienza en `i + 1` y `right` en `nums.length - 1`, y la búsqueda continúa mientras `left < right`
5. **Mover los punteros según el valor de la suma**: Si `sum == 0`, se agrega el triplete al resultado, se omiten los duplicados y se avanzan ambos punteros hacia el interior. Si `sum < 0`, se mueve `left` hacia la derecha para aumentar la suma. Si `sum > 0`, se mueve `right` hacia la izquierda para disminuir la suma
6. **Valor de retorno final**: Una vez exploradas todas las combinaciones de elementos fijos y punteros, se devuelve directamente la lista `result` acumulada

## Conocimientos previos

### Qué es Two Pointers

Es una técnica que coloca dos punteros (`left` y `right`) en ambos extremos de un arreglo ordenado y mueve uno u otro según la condición, permitiendo explorar todos los pares en O(n). Si la suma es menor que el objetivo, se mueve `left` hacia la derecha (para aumentar el valor); si es mayor, se mueve `right` hacia la izquierda (para disminuir el valor).

```java
int left = 0;
int right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) {
        // Par encontrado
    } else if (sum < target) {
        left++;    // Se mueve el puntero izquierdo a la derecha para aumentar la suma
    } else {
        right--;   // Se mueve el puntero derecho a la izquierda para disminuir la suma
    }
}
```

### Qué es Arrays.sort()

Es un método estándar de Java que ordena un arreglo en orden ascendente. Después de ordenar, los valores iguales quedan adyacentes, lo que facilita la detección de duplicados.

```java
int[] nums = {4, -1, 2, -1, 0};
Arrays.sort(nums);    // nums se convierte en {-4, -1, -1, 0, 2} (orden ascendente)
```

### Qué es Arrays.asList()

Es un método que genera una `List` de tamaño fijo a partir de argumentos variables. Se utiliza para agregar un triplete como `List<Integer>` a la lista de resultados.

```java
List<Integer> triplet = Arrays.asList(-1, 0, 1);  // Genera la lista [-1, 0, 1]
```

## Complejidad computacional

| | Valor |
|---|---|
| Time | O(n²) — El bucle externo es O(n) y el Two Pointers interno es O(n), lo que da un total de O(n²) |
| Space | O(1) — Excluyendo el ordenamiento, solo se utilizan variables de punteros sin espacio adicional |

## Código

```java
// Entrada: arreglo de enteros nums
// Salida: List<List<Integer>> que contiene todos los tripletes únicos cuya suma es 0
public List<List<Integer>> threeSum(int[] nums) {
    // Lista de resultados que acumula todos los tripletes encontrados
    List<List<Integer>> result = new ArrayList<>();
    // Se ordena el arreglo en orden ascendente (requisito para Two Pointers + omisión de duplicados)
    Arrays.sort(nums);

    // i recorre desde 0 hasta nums.length - 3. nums[i] es el elemento fijo del triplete
    for (int i = 0; i < nums.length - 2; i++) {
        // Si el elemento fijo tiene el mismo valor que el anterior, se omite para evitar generar el mismo triplete
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }
        // Se colocan los punteros izquierdo y derecho justo después del elemento fijo y al final del arreglo para buscar pares en este rango
        int left = i + 1;
        int right = nums.length - 1;

        while (left < right) {
            // Se calcula la suma de los tres elementos
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0) {
                // Se agrega el triplete con suma cero al resultado
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // Se omiten los valores duplicados del puntero izquierdo (se avanza a la derecha mientras el valor sea igual)
                while (left < right && nums[left] == nums[left + 1]) {
                    left++;
                }
                // Se omiten los valores duplicados del puntero derecho (se avanza a la izquierda mientras el valor sea igual)
                while (left < right && nums[right] == nums[right - 1]) {
                    right--;
                }
                // Después de omitir duplicados, se avanzan ambos punteros una posición hacia el interior para buscar el siguiente par
                left++;
                right--;
            } else if (sum < 0) {
                // La suma es negativa, así que se mueve el puntero izquierdo a la derecha para aumentar la suma
                left++;
            } else {
                // La suma es positiva, así que se mueve el puntero derecho a la izquierda para disminuir la suma
                right--;
            }
        }
    }

    // La exploración ha finalizado para todos los elementos fijos. Se han almacenado todos los tripletes sin duplicados
    return result;
}
```
