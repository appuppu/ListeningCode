# Finding the Minimum Time to Swim Across a Grid — Encontrar el tiempo mínimo para cruzar un grid nadando

## Esencia del problema

Se proporciona un grid de n×n donde cada celda contiene un valor de elevación único entre 0 y n²-1. Se puede nadar de una celda a una celda adyacente (arriba, abajo, izquierda, derecha) solo cuando el tiempo actual es **mayor o igual que la elevación de ambas celdas**. Se debe encontrar el **tiempo mínimo** necesario para llegar desde la esquina superior izquierda (0,0) hasta la esquina inferior derecha (n-1,n-1). El tiempo de inicio es el valor de grid[0][0].

## Idea central

El **valor máximo** de elevación entre las celdas recorridas en una ruta determina el tiempo necesario para esa ruta. Si se utiliza un min-heap para explorar en orden desde "la celda alcanzable con el menor tiempo requerido", el tiempo en el momento de alcanzar la meta por primera vez es la solución óptima.

## Proceso de razonamiento

1. **Reformular la condición de movimiento**: Para moverse de la celda A a la celda B se requiere que "tiempo ≥ max(A, B)". Es decir, el tiempo necesario para toda la ruta desde el inicio hasta la meta es igual al "valor máximo de elevación de todas las celdas en la ruta". Por lo tanto, el problema se reduce a "encontrar la ruta cuya elevación máxima sea mínima"
2. **Notar la similitud con el problema de caminos más cortos**: El Dijkstra estándar minimiza la **suma** de los pesos de las aristas en una ruta, pero en este problema se minimiza el **valor máximo** de elevación en la ruta. Al usar el máximo en lugar de la suma, se puede aplicar directamente el marco de Dijkstra
3. **Expandir desde la celda con el menor tiempo usando una cola de prioridad**: Se almacenan las celdas en un min-heap (PriorityQueue) con "el tiempo necesario para alcanzar cada celda". Al expandir siempre desde la celda con el menor tiempo requerido, se garantiza que el tiempo en el momento de alcanzar cada celda por primera vez es óptimo
4. **Calcular el tiempo necesario hacia las celdas adyacentes**: Cuando el tiempo necesario de la celda actual (r,c) es `time`, el tiempo necesario hacia la celda adyacente (nr,nc) se calcula como `Math.max(time, grid[nr][nc])`. Esto se debe a que el mayor entre "la elevación máxima de la ruta hasta aquí" y "la elevación de la siguiente celda" se convierte en el tiempo necesario de la nueva ruta
5. **Evitar duplicados con gestión de celdas visitadas**: Las celdas extraídas del min-heap tienen su tiempo óptimo confirmado en ese momento. Se marcan con el array de visitados `vis` para no procesar la misma celda nuevamente. Este es el mismo concepto que los nodos confirmados en Dijkstra
6. **Retornar inmediatamente al alcanzar la meta**: Si la celda extraída del heap es (n-1, n-1), el `time` en ese momento es el tiempo mínimo. Dado que se procesan en orden desde el menor tiempo gracias al min-heap, el primer momento en que se alcanza la meta es la solución óptima

## Conocimientos previos

### Qué es una PriorityQueue (min-heap)

Es una estructura de datos que permite extraer elementos en orden de prioridad. Por defecto, el valor mínimo se extrae con la mayor prioridad. Tanto la inserción como la extracción operan con una complejidad de O(log n). En el algoritmo de Dijkstra se utiliza para realizar eficientemente la operación de "seleccionar el nodo con el menor costo entre los nodos no confirmados".

```java
// Crear un min-heap que ordena en forma ascendente por el elemento 0 de int[]
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{5, 0, 0});   // Agregar un elemento (O(log n))
pq.offer(new int[]{3, 1, 0});   // Agregar un elemento
int[] min = pq.poll();          // Extraer y eliminar el elemento mínimo → {3, 1, 0}
boolean empty = pq.isEmpty();   // Verificar si la cola está vacía → false
```

### Qué es la variante del algoritmo de Dijkstra

El algoritmo de Dijkstra estándar minimiza la **suma** de los pesos de las aristas, pero en este problema se minimiza el **valor máximo** de las elevaciones en la ruta. Con solo cambiar la fórmula de actualización de la distancia de `dist[next] = dist[cur] + weight` a `dist[next] = max(dist[cur], grid[next])`, se mantiene la validez de Dijkstra (la propiedad de que el óptimo se confirma en el momento de la extracción del min-heap).

### Exploración de celdas adyacentes en 4 direcciones

Las celdas adyacentes arriba, abajo, izquierda y derecha de una celda (r,c) en el grid se enumeran sumando los vectores de dirección `{{0,1},{0,-1},{1,0},{-1,0}}`. Se verifica que estén dentro del rango (0 ≤ nr < n y 0 ≤ nc < n) y solo se procesan las celdas válidas.

```java
int[][] dir = {{0,1},{0,-1},{1,0},{-1,0}};  // 4 direcciones: derecha, izquierda, abajo, arriba
for (int[] d : dir) {
    int nr = r + d[0];  // Fila de la celda adyacente
    int nc = c + d[1];  // Columna de la celda adyacente
    if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
        // (nr, nc) es una celda adyacente válida
    }
}
```

## Complejidad computacional

| | Valor |
|---|---|
| Tiempo | O(n² log n) — Se inserta y extrae cada una de las n² celdas como máximo una vez en el heap. Cada operación del heap es O(log n²) = O(log n) |
| Espacio | O(n²) — El array de visitados y el heap almacenan como máximo n² celdas cada uno |

## Código

```java
// Entrada: array de enteros grid de n×n (cada celda contiene un valor de elevación único entre 0 y n²-1)
// Salida: retorna como int el tiempo mínimo necesario para llegar desde la esquina superior izquierda (0,0) hasta la esquina inferior derecha (n-1,n-1)
int swimInWater(int[][] grid) {
    int n = grid.length;
    // Array de visitados que gestiona si el tiempo óptimo de cada celda está confirmado (vis[r][c] = true significa confirmado)
    boolean[][] vis = new boolean[n][n];
    // Min-heap que extrae en orden ascendente de tiempo necesario (elemento: {tiempo, fila, columna})
    // La función de comparación (a,b)->a[0]-b[0] extrae en orden ascendente del elemento 0 (tiempo necesario)
    PriorityQueue<int[]> pq =
        new PriorityQueue<>(
            (a, b) -> a[0] - b[0]);
    // Agregar el punto de inicio al heap y marcarlo como visitado
    // El elemento 0 es el tiempo necesario, el elemento 1 es la fila, el elemento 2 es la columna
    pq.offer(new int[]
        {grid[0][0], 0, 0});
    vis[0][0] = true;
    // Vectores de dirección para las 4 direcciones: arriba, abajo, izquierda, derecha
    int[][] dir =
        {{0,1},{0,-1},{1,0},{-1,0}};
    while (!pq.isEmpty()) {
        // Extraer la celda con el menor tiempo necesario (por la propiedad del min-heap, el tiempo óptimo queda confirmado en este punto)
        int[] cur = pq.poll();
        int time = cur[0];
        int r = cur[1], c = cur[2];
        // Si se alcanzó la meta, ese tiempo es la solución óptima (la primera llegada es óptima porque se procesa en orden desde el menor tiempo)
        if (r == n-1 && c == n-1)
            return time;
        // Explorar las celdas adyacentes en las 4 direcciones
        for (int[] d : dir) {
            int nr = r+d[0];
            int nc = c+d[1];
            // Procesar solo las celdas dentro del rango y no visitadas
            if (nr >= 0 && nr < n
                && nc >= 0 && nc < n
                && !vis[nr][nc]) {
                // Nota: al marcar como visitado en el momento de agregar al heap, se evita que la misma celda se agregue al heap múltiples veces
                vis[nr][nc] = true;
                // La elevación máxima en la ruta determina el tiempo necesario (el mayor entre "la elevación máxima hasta aquí" y "la elevación de la siguiente celda")
                int nt = Math.max(
                    time,grid[nr][nc]);
                pq.offer(new int[]
                    {nt, nr, nc});
            }
        }
    }
    // Según las restricciones del problema, el grid es conexo, por lo que nunca se llega aquí
    return -1;
}
```
