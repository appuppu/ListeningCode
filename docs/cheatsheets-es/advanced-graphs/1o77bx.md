# Deriving the Order of an Alien Alphabet — Restaurar el orden de los caracteres de un idioma alienígena

## Esencia del problema

Se proporciona una lista de palabras `words` ordenadas en orden lexicográfico de un idioma alienígena. A partir de este orden, se debe deducir el orden del alfabeto en ese idioma y devolverlo como una cadena de texto. Si el orden contiene contradicciones (por ejemplo, si existe un ciclo o si una palabra más corta aparece después de una más larga), se devuelve una cadena vacía `""`.

## Idea central

Al comparar dos palabras adyacentes, se obtiene una relación de orden (arista dirigida) a partir del "primer carácter que difiere". Se construye un grafo dirigido con todas las relaciones de orden obtenidas de todos los pares, y se determina el orden total mediante un ordenamiento topológico con DFS. Si existe un ciclo, el orden es contradictorio.

## Proceso de razonamiento

1. **Extraer relaciones de orden comparando palabras adyacentes**: En una lista ordenada, se comparan dos palabras adyacentes `words[i]` y `words[i+1]` desde el inicio, y si se encuentra el primer par de caracteres distintos `(a, b)`, se establece la relación de orden "a precede a b". Esta relación se representa como una arista dirigida `a → b` en el grafo
2. **Detectar entradas inválidas**: Si `words[i]` es un prefijo de `words[i+1]` y `words[i]` es más larga (por ejemplo, `"abc"` aparece antes de `"ab"`), esto contradice el orden lexicográfico, por lo que se devuelve inmediatamente una cadena vacía
3. **Registrar todos los caracteres como nodos**: Dado que pueden existir caracteres sin relaciones de orden, se registran todos los caracteres de todas las palabras como nodos del grafo. De esta manera, los caracteres sin aristas también se incluyen en el resultado
4. **Determinar el orden total mediante ordenamiento topológico con DFS**: Se ejecuta DFS sobre el grafo dirigido y se agrega cada nodo a una lista al completar su exploración. Al invertir el orden posterior (post-order) del DFS, se obtiene el orden topológico (donde los orígenes de las dependencias aparecen primero)
5. **Detectar ciclos mediante marcado de 3 colores**: Durante el DFS, se gestiona cada nodo con 3 estados: "no visitado (0)", "en exploración (1)" y "explorado (2)". Si se alcanza de nuevo un nodo en estado "en exploración", se confirma la existencia de un ciclo y el orden no puede determinarse, por lo que se devuelve una cadena vacía
6. **Invertir el orden y construir la cadena**: Se invierte la lista en orden posterior del DFS para obtener el orden topológico. Se concatenan todos los caracteres de la lista y se devuelve la cadena resultante

## Conocimientos previos

### ¿Qué es el ordenamiento topológico?

Es una operación que ordena linealmente todos los nodos de un grafo acíclico dirigido (DAG) sin contradecir la dirección de las aristas. Si existe una arista `a → b`, en el resultado `a` siempre aparece antes que `b`. No existe un orden topológico para grafos que contienen ciclos.

### ¿Qué es el marcado de 3 colores en DFS?

Es una técnica que gestiona el estado de cada nodo en DFS mediante 3 colores. Blanco (0) indica no visitado, gris (1) indica que está en la ruta de exploración actual (presente en la pila de recursión), y negro (2) indica que la exploración se completó. Si se alcanza de nuevo un nodo gris, se confirma la existencia de un ciclo.

```java
Map<Character, Integer> color = new HashMap<>();
color.put('a', 0);  // Blanco: no visitado
color.put('a', 1);  // Gris: en exploración (presente en la pila de recursión)
color.put('a', 2);  // Negro: exploración completada (todos los descendientes procesados)
```

### Operaciones básicas de HashMap y HashSet

```java
// HashMap: almacena pares de clave y valor. La búsqueda y obtención son O(1)
Map<Character, Set<Character>> adj = new HashMap<>();
adj.putIfAbsent('a', new HashSet<>());  // Registra un Set vacío solo si la clave no está registrada
adj.get('a').add('b');                  // Agrega 'b' a la lista de adyacencia de la clave 'a'

// HashSet: conjunto sin duplicados. La adición y búsqueda son O(1)
Set<Character> set = new HashSet<>();
set.add('b');        // Agrega un elemento
set.contains('b');   // Verifica la existencia del elemento → true
```

### Método startsWith

Determina si una cadena comienza con el prefijo especificado.

```java
"abc".startsWith("ab");  // true — "abc" comienza con "ab"
"ab".startsWith("abc");  // false — "ab" no comienza con "abc"
```

## Complejidad computacional

| | Valor |
|---|---|
| Tiempo | O(C) — C es el número total de caracteres en todas las palabras. La construcción del grafo recorre todos los caracteres, y el DFS es proporcional al número de nodos más aristas, pero ninguno de estos supera C |
| Espacio | O(1) — El número de nodos es como máximo 26 caracteres (letras minúsculas del inglés), lo cual es constante. El número de aristas también es como máximo 26², que es constante. No depende del tamaño de la entrada |

## Código

```java
// Entrada: arreglo de cadenas words ordenado en orden lexicográfico del idioma alienígena
// Salida: cadena que representa el orden del alfabeto. Si hay contradicción, se devuelve una cadena vacía ""

// DFS: detecta ciclos mediante marcado de 3 colores y registra el orden posterior
boolean dfs(char c, Map<Character, Set<Character>> adj,
            Map<Character, Integer> color, List<Character> result) {
    // Se alcanza de nuevo un nodo gris (en exploración) → se detecta un ciclo
    if (color.get(c) == 1) return false;
    // Nodo negro (ya explorado) → la exploración ya se completó, se omite
    if (color.get(c) == 2) return true;

    // Se marca el nodo actual como gris (en exploración)
    color.put(c, 1);

    // Se ejecuta DFS recursivamente en todos los nodos adyacentes (caracteres que vienen después de este)
    for (char n : adj.get(c))
        if (!dfs(n, adj, color, result))
            return false;  // Se detectó un ciclo en un descendiente → se propaga inmediatamente

    // La exploración de todos los descendientes se completó, se marca como negro
    color.put(c, 2);
    // Se agrega a la lista en orden posterior (en DFS los destinos de las dependencias se agregan primero, por lo que al invertir se obtiene el orden topológico)
    result.add(c);
    return true;
}

public String alienOrder(String[] words) {
    // Lista de adyacencia: clave=carácter, valor=conjunto de caracteres que vienen después de ese carácter
    Map<Character, Set<Character>> adj = new HashMap<>();

    // Se registran todos los caracteres de todas las palabras como nodos del grafo
    // Es necesario registrar todos los caracteres en este punto para incluir en el resultado también los caracteres sin relaciones de orden (aristas)
    for (String w : words)
        for (char c : w.toCharArray())
            adj.putIfAbsent(c, new HashSet<>());

    // Se comparan dos palabras adyacentes para extraer relaciones de orden (aristas dirigidas)
    for (int i = 0; i < words.length - 1; i++) {
        String w1 = words[i];
        String w2 = words[i + 1];

        // Detección de entrada inválida: una palabra más larga aparece antes de su prefijo más corto (ejemplo: ["abc","ab"] es una contradicción)
        if (w1.length() > w2.length() && w1.startsWith(w2))
            return "";

        int len = Math.min(w1.length(), w2.length());
        for (int j = 0; j < len; j++) {
            if (w1.charAt(j) != w2.charAt(j)) {
                // Se obtiene una relación de orden a partir del primer carácter que difiere y se sale del bucle inmediatamente
                // Las diferencias a partir del segundo carácter solo tienen significado si los caracteres anteriores son iguales, por lo que se extrae solo una relación
                adj.get(w1.charAt(j)).add(w2.charAt(j));
                break;
            }
        }
    }

    // Se crea el mapa de gestión de 3 colores y se inicializan todos los nodos como blanco (0: no visitado)
    Map<Character, Integer> color = new HashMap<>();
    for (char c : adj.keySet())
        color.put(c, 0);

    // Lista para registrar el orden posterior del DFS
    List<Character> result = new ArrayList<>();

    // Se ejecuta DFS desde todos los nodos (se inicia desde todos los nodos para manejar grafos no conexos)
    for (char c : adj.keySet())
        if (!dfs(c, adj, color, result))
            return "";  // Se detectó un ciclo → el orden no puede determinarse

    // Se invierte el orden posterior para obtener el orden topológico
    Collections.reverse(result);

    // Se concatenan todos los caracteres para construir la cadena resultante
    StringBuilder sb = new StringBuilder();
    for (char c : result) sb.append(c);
    return sb.toString();
}
```
