# Three Sum — 합이 0이 되는 세 수의 조합을 모두 찾기

## 문제의 본질

정수 배열 `nums`가 주어진다. `nums`에서 합이 `0`이 되는 세 요소의 조합(트리플렛)을 모두 찾아 `List<List<Integer>>`로 반환한다. 각 트리플렛은 서로 다른 인덱스의 요소로 구성되며, 결과에 중복되는 트리플렛을 포함해서는 안 된다.

## 핵심 아이디어

배열을 정렬하면, 하나의 요소를 고정한 뒤 나머지 두 요소를 Two Pointers로 효율적으로 탐색할 수 있고, 정렬된 순서를 이용하여 중복되는 값을 건너뛰면 중복 트리플렛 제거도 자연스럽게 구현할 수 있다.

## 사고 과정

1. **3요소 문제를 2요소 문제로 귀결시킨다**: 세 수 `a + b + c = 0`은 하나의 요소 `a = nums[i]`를 고정하면 `b + c = -a`라는 2요소 탐색 문제가 된다. 바깥쪽 for 루프에서 `a`를 고정하고, 안쪽에서 `b`와 `c`를 찾는 구조로 만들면 기존의 Two Sum 개념을 응용할 수 있다
2. **Two Pointers를 사용하기 위해 정렬한다**: 2요소 탐색을 효율적으로 수행하려면, 배열을 정렬하고 양쪽 끝에서 포인터를 좁혀가는 Two Pointers가 유효하다. 합이 너무 작으면 왼쪽 포인터를 오른쪽으로, 너무 크면 오른쪽 포인터를 왼쪽으로 이동시킴으로써 모든 쌍을 효율적으로 탐색할 수 있다
3. **중복 트리플렛 제거를 정렬로 구현한다**: 정렬된 배열에서는 같은 값이 인접한다. 바깥쪽 루프의 `nums[i]`가 이전 요소와 같은 값이면 건너뛰고, 안쪽 루프에서도 쌍을 찾은 후 `left`와 `right`를 같은 값이 계속되는 한 건너뛰면, 중복 트리플렛을 결과에 포함하지 않을 수 있다
4. **바깥쪽 루프의 범위를 결정한다**: 세 요소가 필요하므로 `i`는 `0`부터 `nums.length - 3`까지 순회한다. `left`는 `i + 1`에서, `right`는 `nums.length - 1`에서 시작하며, `left < right`인 동안만 탐색을 계속한다
5. **합의 값에 따라 포인터를 이동시킨다**: `sum == 0`이면 트리플렛을 결과에 추가하고, 중복 건너뛰기 후 양쪽 포인터를 안쪽으로 진행시킨다. `sum < 0`이면 합을 크게 하기 위해 `left`를 오른쪽으로, `sum > 0`이면 합을 작게 하기 위해 `right`를 왼쪽으로 이동시킨다
6. **최종적으로 반환하는 것**: 모든 고정 요소와 포인터 조합의 탐색을 마치면, 축적한 `result` 리스트를 그대로 반환한다

## 전제 지식

### Two Pointers란

정렬된 배열의 양 끝에 두 개의 포인터(`left`와 `right`)를 놓고, 조건에 따라 어느 한쪽을 이동시킴으로써 모든 쌍의 탐색을 O(n)으로 수행하는 기법이다. 합이 목표보다 작으면 `left`를 오른쪽으로(값을 크게), 크면 `right`를 왼쪽으로(값을 작게) 이동시킨다.

```java
int left = 0;
int right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) {
        // 쌍 발견
    } else if (sum < target) {
        left++;    // 합을 크게 하기 위해 왼쪽 포인터를 오른쪽으로 이동시킨다
    } else {
        right--;   // 합을 작게 하기 위해 오른쪽 포인터를 왼쪽으로 이동시킨다
    }
}
```

### Arrays.sort()란

배열을 오름차순으로 정렬하는 Java의 표준 메서드이다. 정렬 후에는 같은 값이 인접하므로 중복 검출이 용이해진다.

```java
int[] nums = {4, -1, 2, -1, 0};
Arrays.sort(nums);    // nums는 {-4, -1, -1, 0, 2}가 된다(오름차순)
```

### Arrays.asList()란

가변 인자로부터 고정 크기의 `List`를 생성하는 메서드이다. 트리플렛을 `List<Integer>`로서 결과 리스트에 추가할 때 사용한다.

```java
List<Integer> triplet = Arrays.asList(-1, 0, 1);  // [-1, 0, 1] 리스트를 생성한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n²) — 바깥쪽 루프가 O(n), 안쪽 Two Pointers가 O(n)이므로 합계 O(n²) |
| Space | O(1) — 정렬을 제외하면, 포인터 변수만 사용하여 추가 공간을 사용하지 않는다 |

## 코드

```java
// 입력: 정수 배열 nums
// 출력: 합이 0이 되는 모든 유니크한 트리플렛을 저장한 List<List<Integer>>
public List<List<Integer>> threeSum(int[] nums) {
    // 발견한 모든 트리플렛을 축적하는 결과 리스트
    List<List<Integer>> result = new ArrayList<>();
    // 배열을 오름차순으로 정렬한다(Two Pointers의 전제조건 + 중복 건너뛰기를 위해)
    Arrays.sort(nums);

    // i는 0부터 nums.length - 3까지 순회한다. nums[i]가 트리플렛의 고정 요소가 된다
    for (int i = 0; i < nums.length - 2; i++) {
        // 고정 요소가 이전 요소와 같은 값이면, 같은 트리플렛이 다시 생성되므로 건너뛴다
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }
        // 고정 요소 바로 다음과 배열 끝에 좌우 포인터를 배치하고, 이 범위에서 쌍을 탐색한다
        int left = i + 1;
        int right = nums.length - 1;

        while (left < right) {
            // 세 요소의 합을 계산한다
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0) {
                // 합이 0인 트리플렛을 결과에 추가한다
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // 왼쪽 포인터 측의 중복 값을 건너뛴다(같은 값이 계속되는 한 오른쪽으로 진행시킨다)
                while (left < right && nums[left] == nums[left + 1]) {
                    left++;
                }
                // 오른쪽 포인터 측의 중복 값을 건너뛴다(같은 값이 계속되는 한 왼쪽으로 진행시킨다)
                while (left < right && nums[right] == nums[right - 1]) {
                    right--;
                }
                // 중복 건너뛰기 후, 양쪽 포인터를 안쪽으로 1칸 진행시켜 다음 쌍 탐색으로 넘어간다
                left++;
                right--;
            } else if (sum < 0) {
                // 합이 음수이므로, 왼쪽 포인터를 오른쪽으로 이동시켜 합을 크게 한다
                left++;
            } else {
                // 합이 양수이므로, 오른쪽 포인터를 왼쪽으로 이동시켜 합을 작게 한다
                right--;
            }
        }
    }

    // 모든 고정 요소에 대한 탐색이 완료되었다. 중복 없는 모든 트리플렛이 저장되어 있다
    return result;
}
```
