# Finding Two Numbers in a Sorted Array That Add Up to a Target — 정렬된 배열에서 합이 타겟이 되는 두 수를 찾기

## 문제의 본질

정렬된 정수 배열 `nums`와 정수 `target`이 주어진다. `nums`에서 합이 `target`이 되는 두 요소를 찾아, 그 **1-indexed 위치**를 배열로 반환한다. 해는 반드시 하나만 존재하며, 같은 요소를 두 번 사용할 수 없다.

## 핵심 아이디어

배열이 정렬되어 있으므로, 왼쪽 끝과 오른쪽 끝의 두 포인터로 양쪽에서 좁혀 나갈 수 있다. 두 수의 합이 너무 크면 오른쪽을 줄이고, 너무 작으면 왼쪽을 넓힘으로써, 한 번의 순회로 O(n) 시간·O(1) 공간에 답을 찾을 수 있다.

## 사고 프로세스

1. **정렬되어 있다는 조건을 활용한다**: 배열이 정렬되어 있으므로, 왼쪽 끝은 최솟값을, 오른쪽 끝은 최댓값을 가리킨다. 이 양쪽 끝의 합에서 탐색을 시작하면, 합의 크고 작음에 따라 탐색 범위를 확실히 좁힐 수 있다
2. **합이 너무 크면 오른쪽 포인터를 왼쪽으로 이동한다**: 오른쪽 포인터는 현재 탐색 범위에서 가장 큰 값을 가리키고 있다. 합이 `target`보다 큰 경우, 합을 줄이려면 오른쪽 포인터를 왼쪽으로 한 칸 이동하여 더 작은 값으로 전환한다
3. **합이 너무 작으면 왼쪽 포인터를 오른쪽으로 이동한다**: 왼쪽 포인터는 현재 탐색 범위에서 가장 작은 값을 가리키고 있다. 합이 `target`보다 작은 경우, 합을 늘리려면 왼쪽 포인터를 오른쪽으로 한 칸 이동하여 더 큰 값으로 전환한다
4. **합이 정확히 `target`이면 답을 찾은 것이다**: 두 포인터가 가리키는 값의 합이 `target`과 일치하면, 그것이 구하는 쌍이다. 문제에서 1-indexed를 요구하므로, 각 포인터의 위치에 1을 더하여 반환한다
5. **루프의 종료 조건**: 왼쪽 포인터가 오른쪽 포인터에 도달할 때까지 반복한다. 문제의 제약 조건상 해는 반드시 존재하므로, 포인터가 교차하기 전에 반드시 답을 찾을 수 있다
6. **최종적으로 반환하는 것**: 합이 `target`과 일치한 시점에서, `left + 1`(왼쪽 요소의 1-indexed 위치)과 `right + 1`(오른쪽 요소의 1-indexed 위치) 두 값을 `int[]`로 반환한다

## 전제 지식

### Two Pointers(투 포인터)란

배열의 서로 다른 위치를 가리키는 두 개의 인덱스 변수를 사용하여, 조건에 따라 각각을 이동시키는 기법이다. 정렬된 배열에서는 양쪽 끝에서 중앙을 향해 탐색 범위를 좁히는 패턴이 대표적이다.

```java
int left = 0;                    // 왼쪽 포인터를 배열의 맨 앞에 놓는다
int right = nums.length - 1;     // 오른쪽 포인터를 배열의 맨 뒤에 놓는다
while (left < right) {           // 두 포인터가 교차할 때까지 루프를 실행한다
    // left와 right를 조건에 따라 이동시킨다
    left++;   // 왼쪽 포인터를 오른쪽으로 한 칸 전진시킨다
    right--;  // 오른쪽 포인터를 왼쪽으로 한 칸 후퇴시킨다
}
```

### 정렬된 배열의 성질

배열이 오름차순으로 정렬되어 있는 경우, `nums[left] <= nums[right]`가 항상 성립한다. 왼쪽 포인터를 오른쪽으로 이동하면 합은 증가하고, 오른쪽 포인터를 왼쪽으로 이동하면 합은 감소한다. 이러한 단조성이 있기 때문에, 두 포인터의 이동 방향을 합의 크고 작음으로 결정할 수 있다.

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 두 포인터가 합쳐서 최대 n번 이동하는 것만으로 충분하다 |
| Space | O(1) — 포인터용 변수만 사용하며, 추가적인 데이터 구조는 불필요하다 |

## 코드

```java
// 입력: 정렬된 정수 배열 nums와 정수 target
// 출력: 합이 target이 되는 두 요소의 1-indexed 위치를 담은 int[]를 반환한다
public int[] twoSum(int[] nums, int target) {
    // 왼쪽 포인터를 배열의 맨 앞에 놓는다. 탐색 범위의 왼쪽 끝이며, 배열의 최솟값 쪽을 담당한다
    int left = 0;
    // 오른쪽 포인터를 배열의 맨 뒤에 놓는다. 탐색 범위의 오른쪽 끝이며, 배열의 최댓값 쪽을 담당한다
    int right = nums.length - 1;

    // 두 포인터가 교차할 때까지 루프를 실행한다
    while (left < right) {
        // 현재 두 요소의 합을 계산하고, 변수에 저장하여 각 분기에서 재사용한다
        int cursum = nums[left] + nums[right];

        if (cursum == target) {
            // 합이 타겟과 일치했으므로 쌍을 발견했다. 문제에서 1-indexed를 요구하므로 각 인덱스에 1을 더하여 반환한다
            return new int[]{left + 1, right + 1};
        } else if (cursum > target) {
            // 합이 너무 크므로 오른쪽 포인터를 왼쪽으로 이동한다. 오른쪽 포인터가 가리키는 값이 더 작아지며, 다음 반복에서 합이 감소한다
            right--;
        } else {
            // 합이 너무 작으므로 왼쪽 포인터를 오른쪽으로 이동한다. 왼쪽 포인터가 가리키는 값이 더 커지며, 다음 반복에서 합이 증가한다
            left++;
        }
    }
    // 문제의 제약 조건상 해는 반드시 존재하므로 여기에는 도달하지 않는다
    return new int[]{};
}
```
