# Maximizing Water Held Between Two Lines — 두 수직선 사이에 담을 수 있는 최대 물의 양을 구하기

## 문제의 본질

음이 아닌 정수 배열 `height`가 주어진다. 각 요소 `height[i]`는 x축 위의 위치 `i`에 세워진 수직선의 높이를 나타낸다. 이 중에서 두 선을 선택하여 x축과 함께 형성되는 용기에 담을 수 있는 **물의 최대량**을 반환한다. 용기의 물의 양은 "두 선 사이의 거리 × 두 선 중 짧은 쪽의 높이"로 결정된다.

## 핵심 아이디어

용기의 너비를 최대(양쪽 끝)에서 시작하여, 짧은 쪽의 포인터를 안쪽으로 이동시킴으로써 높이 증가에 의한 면적 개선의 가능성을 남기면서 모든 쌍을 효율적으로 탐색할 수 있다. 짧은 쪽을 이동시키는 이유는, 너비가 줄어드는 이상 높이가 증가하지 않으면 면적이 개선되지 않기 때문이다.

## 사고 프로세스

1. **면적 계산식을 정리한다**: 두 선 `i`와 `j`(i < j)가 만드는 용기의 면적은 `(j - i) × min(height[i], height[j])`이다. 면적을 최대화하려면 "너비"와 "높이의 최솟값"의 곱을 최대로 만들어야 한다
2. **너비가 최대인 상태에서 시작한다**: 너비를 최대로 하려면, 왼쪽 끝(인덱스 0)과 오른쪽 끝(인덱스 n-1)의 두 선을 선택하면 된다. 이 상태에서 탐색을 시작하면, 너비가 최대인 상태에서 출발할 수 있다
3. **어느 쪽 포인터를 이동할지 결정한다**: 너비는 안쪽으로 이동하면 반드시 1 줄어든다. 면적을 개선하려면 높이를 늘리는 수밖에 없다. 용기의 높이는 두 선 중 짧은 쪽에 의해 결정되므로, 짧은 쪽의 포인터를 안쪽으로 이동시키면 더 높은 선을 만날 가능성이 있다. 반대로, 긴 쪽을 이동시켜도 짧은 쪽이 병목으로 남아 있으므로 면적은 개선되지 않는다
4. **각 단계에서 면적을 기록한다**: 포인터를 이동할 때마다 새로운 면적을 계산하고, 지금까지의 최댓값과 비교하여 갱신한다. 이렇게 하면 완전 탐색과 동일한 결과를 얻을 수 있다
5. **종료 조건을 결정한다**: 왼쪽 포인터와 오른쪽 포인터가 만나는 시점에 모든 유망한 쌍을 조사 완료했으므로, 탐색을 종료한다
6. **최종적으로 반환하는 값**: 탐색 중에 기록한 면적의 최댓값 `maxarea`를 반환한다

## 사전 지식

### Two Pointers(투 포인터)란

배열의 양쪽 끝 또는 서로 다른 위치에 두 개의 포인터(인덱스)를 놓고, 조건에 따라 한쪽 또는 양쪽을 이동시키면서 탐색하는 기법이다. 모든 쌍을 조사하는 O(n²)의 탐색을, 조건을 활용하여 O(n)으로 줄일 수 있는 경우에 유효하다.

```java
int left = 0;                      // 왼쪽 포인터를 배열의 처음에 놓는다
int right = height.length - 1;     // 오른쪽 포인터를 배열의 끝에 놓는다
while (left < right) {             // 두 포인터가 만날 때까지 루프를 실행한다
    // left 또는 right를 이동시킨다
    left++;   // 왼쪽 포인터를 오른쪽으로 1칸 전진시킨다
    right--;  // 오른쪽 포인터를 왼쪽으로 1칸 전진시킨다
}
```

### Math.min / Math.max란

`Math.min(a, b)`는 두 값 중 작은 쪽을, `Math.max(a, b)`는 큰 쪽을 반환한다. 용기의 높이(짧은 쪽의 선)와 면적의 최댓값 갱신에 사용한다.

```java
Math.min(3, 7);          // 두 값 중 작은 쪽을 반환한다 → 3
Math.max(10, 25);        // 두 값 중 큰 쪽을 반환한다 → 25
```

### 용기의 면적 계산

두 선 `left`와 `right`가 만드는 용기의 면적은 너비 × 높이로 구한다. 높이는 두 선 중 짧은 쪽에 의해 결정된다.

```java
int width = right - left;                              // 너비 = 두 선 사이의 거리
int minHeight = Math.min(height[left], height[right]);  // 높이 = 짧은 쪽 선의 높이
int area = width * minHeight;                           // 면적 = 너비 × 높이
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 왼쪽과 오른쪽 포인터가 각각 한 번씩 안쪽으로 전진할 뿐이며, 배열을 한 번 순회한다 |
| Space | O(1) — 포인터와 최댓값을 저장하는 변수만 사용한다 |

## 코드

```java
// 입력: 음이 아닌 정수 배열 height (각 요소는 수직선의 높이)
// 출력: 두 선과 x축으로 형성되는 용기가 담을 수 있는 물의 최대량을 int로 반환한다
public int maxArea(int[] height) {
    // 탐색 중에 발견한 면적의 최댓값을 기록하는 변수. 0으로 초기화한다
    int maxarea = 0;
    // 왼쪽 포인터를 배열의 처음에 놓는다. 너비가 최대인 상태에서 탐색을 시작한다
    int left = 0;
    // 오른쪽 포인터를 배열의 끝에 놓는다
    int right = height.length - 1;

    // 두 포인터가 만날 때까지 루프를 실행한다. 만나는 시점에 모든 유망한 쌍의 조사를 완료한다
    while (left < right) {
        // 너비 = 두 선 사이의 거리
        int width = right - left;
        // 높이 = 짧은 쪽 선의 높이. 용기의 물의 양은 짧은 쪽의 선에 의해 결정된다
        int minHeight = Math.min(height[left], height[right]);
        // 면적 = 너비 × 높이
        int area = width * minHeight;

        // 지금까지의 최댓값과 비교하여 갱신한다
        maxarea = Math.max(area, maxarea);

        // 짧은 쪽의 포인터를 안쪽으로 이동시킨다. 너비가 줄어드는 이상, 높이가 증가하지 않으면 면적은 개선되지 않는다
        // 긴 쪽을 이동시켜도 짧은 쪽이 병목으로 남아 있으므로 면적은 개선되지 않는다
        if (height[left] <= height[right]) {
            // 왼쪽 선이 짧으므로(또는 같으므로), 왼쪽 포인터를 오른쪽으로 1칸 전진시켜 높이 개선을 노린다
            left++;
        } else {
            // 오른쪽 선이 짧으므로, 오른쪽 포인터를 왼쪽으로 1칸 전진시켜 높이 개선을 노린다
            right--;
        }
    }
    // 탐색 중에 기록한 면적의 최댓값을 반환한다
    return maxarea;
}
```
