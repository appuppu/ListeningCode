# Finding the Largest Rectangle in a Histogram — 히스토그램 내에서 형성할 수 있는 최대 직사각형의 면적을 구하기

## 문제의 본질

비음수 정수 배열 `heights`가 주어진다. 각 요소는 히스토그램 막대의 높이를 나타내며, 막대의 너비는 모두 1이다. 이 히스토그램 내에서 형성할 수 있는 **최대 직사각형의 면적**을 구하여 반환한다.

## 핵심 아이디어

각 막대를 "직사각형의 높이"로 채택했을 때, 해당 막대가 가장 낮은 막대로서 좌우로 어디까지 확장할 수 있는지를 알면 면적을 계산할 수 있다. 단조 증가 스택을 사용하면, 막대의 높이가 내려가는 순간에 스택 내 막대의 확장 가능한 너비를 O(1)로 확정할 수 있다.

## 사고 프로세스

1. **각 막대를 높이로 하는 직사각형을 생각한다**: 임의의 직사각형은 "어떤 막대의 높이를 상한으로 하여 좌우로 연속하는 막대로 구성된다"고 볼 수 있다. 즉, 각 막대 `heights[i]`에 대해 "이 막대가 가장 낮은 막대가 되는 구간의 너비"를 알면 `heights[i] × 너비`로 면적을 계산할 수 있다
2. **좌우 경계를 효율적으로 구하고 싶다**: 각 막대에 대해 "왼쪽에서 처음으로 자신보다 낮은 막대의 위치"와 "오른쪽에서 처음으로 자신보다 낮은 막대의 위치"를 알면 확장 가능한 너비가 확정된다. 모든 막대에 대해 이 두 경계를 단순하게 탐색하면 O(n²)이 되므로, 스택을 사용하여 효율화한다
3. **단조 증가 스택을 사용한다**: 스택에 막대의 인덱스를, 높이가 단조 증가하도록 쌓아간다. 현재 막대의 높이가 스택의 최상단보다 낮을 때, 스택 최상단의 막대에 대해 "오른쪽 경계"가 현재 위치 `i`라고 확정된다
4. **팝할 때 너비를 계산한다**: 스택에서 막대 `top`을 팝했을 때, 오른쪽 경계는 현재 위치 `i`이고 왼쪽 경계는 팝 후 스택 최상단의 다음 위치이다. 스택이 비어 있는 경우에는 왼쪽 끝(인덱스 0)까지 확장할 수 있으므로 너비는 `i`가 된다. 스택이 비어 있지 않은 경우에는 너비는 `i - stack.peek() - 1`이 된다
5. **센티널로 높이 0을 끝에 추가한다**: 배열의 끝에 도달했을 때, 스택에 남아 있는 막대의 면적도 계산해야 한다. 루프의 범위를 `i <= heights.length`로 설정하고, `i == heights.length`일 때 가상으로 높이 0을 놓음으로써, 스택 내의 모든 막대가 반드시 팝된다
6. **최대 면적을 추적한다**: 막대를 팝할 때마다 `heights[top] × 너비`를 계산하고, 지금까지의 최댓값과 비교하여 갱신한다. 모든 팝이 완료된 시점의 최댓값이 정답이다

## 사전 지식

### Stack(스택)이란

후입선출(LIFO) 데이터 구조이다. 마지막에 추가한 요소가 가장 먼저 꺼내진다. 히스토그램 문제에서는 막대의 인덱스를 스택에 쌓고, 높이의 단조성을 유지하기 위해 사용한다.

```java
Stack<Integer> stack = new Stack<>();  // 빈 스택을 생성한다
stack.push(0);       // 스택의 최상단에 값 0을 추가한다
stack.peek();        // 스택의 최상단 값을 꺼내지 않고 참조한다 → 0
stack.pop();         // 스택의 최상단 값을 꺼내어 반환한다 → 0
stack.isEmpty();     // 스택이 비어 있는지를 boolean으로 반환한다 → true
```

### 단조 증가 스택(Monotonic Stack)이란

스택 내의 요소가 항상 아래에서 위로 증가하는(또는 같은) 상태를 유지하는 스택이다. 새로운 요소를 추가할 때, 스택의 최상단보다 작은 값이 오면, 최상단이 새로운 값 이상이 될 때까지 팝한다. 팝하는 순간에 "팝된 요소의 오른쪽 경계가 확정되었다"고 해석할 수 있다.

```java
// 배열 [2, 1, 5, 6, 2, 3]에 대한 단조 증가 스택의 동작
// i=0: push(0)         → 스택: [0]       (높이: [2])
// i=1: 1 < 2 이므로 pop → 스택: []        (높이 2인 막대의 오른쪽 경계가 i=1로 확정됨)
//       push(1)         → 스택: [1]       (높이: [1])
// i=2: push(2)         → 스택: [1,2]     (높이: [1,5])
// i=3: push(3)         → 스택: [1,2,3]   (높이: [1,5,6])
// i=4: 2 < 6 이므로 pop → 스택: [1,2]     (높이 6인 막대의 오른쪽 경계가 i=4로 확정됨)
//       2 < 5 이므로 pop → 스택: [1]       (높이 5인 막대의 오른쪽 경계가 i=4로 확정됨)
//       push(4)         → 스택: [1,4]     (높이: [1,2])
```

### 센티널(Sentinel)이란

루프의 종단 처리를 간결하게 하기 위해 가상으로 추가하는 값이다. 이 문제에서는 배열의 끝에 높이 0인 막대를 가상으로 놓음으로써, 루프 종료 시 스택에 남아 있는 모든 막대를 자연스럽게 팝시킨다.

```java
// i == heights.length일 때, 실제 배열 범위 밖이므로 가상으로 높이 0을 사용한다
int h = (i == heights.length) ? 0 : heights[i];
// 높이 0은 어떤 막대보다도 낮으므로, 스택 내의 모든 막대가 팝된다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 각 막대는 스택에 1번 푸시되고 1번 팝되므로, 전체적으로 O(n)의 연산으로 완료된다 |
| Space | O(n) — 스택에 최대 n개의 인덱스를 저장한다 |

## 코드

```java
// 입력: 비음수 정수 배열 heights (각 요소는 히스토그램 막대의 높이)
// 출력: 히스토그램 내에서 형성할 수 있는 최대 직사각형의 면적을 int로 반환한다
public int largestRectangleArea(int[] heights) {
    // 막대의 인덱스를 단조 증가로 유지하는 스택
    Stack<Integer> stack = new Stack<>();
    // 지금까지 발견된 최대 면적을 기록하는 변수
    int maxArea = 0;

    // i <= heights.length로 설정하여 센티널 처리를 포함한다
    // i == heights.length일 때 센티널(높이 0)로서 스택을 모두 팝시킨다
    for (int i = 0; i <= heights.length; i++) {
        // 센티널: 배열 끝을 넘어서면 높이 0을 사용한다. 높이 0은 어떤 막대보다도 낮으므로, 스택 내의 모든 막대가 팝되는 것이 보장된다
        int h = (i == heights.length) ? 0 : heights[i];

        // 현재 높이가 스택 최상단의 막대보다 낮은 동안 면적을 계산한다
        // 이 조건에 의해 스택 내의 단조 증가성이 유지된다
        while (!stack.isEmpty() && h < heights[stack.peek()]) {
            // 팝한 막대를 직사각형의 높이로 채택한다. 이 막대의 오른쪽 경계는 현재 위치 i이다
            int top = stack.pop();

            // 너비를 계산한다:
            // 스택이 비어 있음 → top 막대는 왼쪽 끝(인덱스 0)까지 확장할 수 있으므로 너비는 i이다
            // 스택이 비어 있지 않음 → stack.peek()는 top보다 왼쪽에 있으면서 top보다 낮은 막대의 인덱스(왼쪽 경계)이므로, 너비는 i - stack.peek() - 1이다
            int w = stack.isEmpty() ? i : i - stack.peek() - 1;

            // 면적을 계산하고 최댓값을 갱신한다
            maxArea = Math.max(maxArea, heights[top] * w);
        }

        // 현재 인덱스를 스택에 푸시하여 단조 증가를 유지한다
        stack.push(i);
    }
    // 모든 팝이 완료된 시점의 최댓값이 정답이다
    return maxArea;
}
```
