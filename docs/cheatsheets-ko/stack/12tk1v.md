# Checking if Parentheses Are Balanced — 괄호 문자열이 올바르게 대응하는지 판정하기

## 문제의 본질

`(`、`)`、`{`、`}`、`[`、`]` 의 6종류 괄호로만 구성된 문자열이 주어진다. 모든 여는 괄호에 대응하는 닫는 괄호가 **올바른 순서**로 존재하는지를 판정하여 `true` 또는 `false`를 반환한다.

## 핵심 아이디어

괄호의 대응은 "마지막에 연 것을 가장 먼저 닫는다"라는 후입선출(LIFO) 구조를 가진다. 이 성질은 스택 그 자체이며, 여는 괄호를 스택에 쌓고 닫는 괄호가 오면 스택의 맨 위와 대조하여 올바른 대응을 검증할 수 있다.

## 사고 프로세스

1. **괄호의 대응에는 순서가 있다**: `([)]`는 각 괄호의 개수는 맞지만 순서가 올바르지 않다. 즉 "가장 안쪽의 괄호부터 먼저 닫는다"라는 규칙이 있다. 이것은 후입선출(LIFO) 구조이며, 스택으로 자연스럽게 표현할 수 있다
2. **여는 괄호는 스택에 쌓는다**: 문자열을 처음부터 한 문자씩 순회하며, 여는 괄호(`(`, `{`, `[`)를 만나면 스택에 push한다. 스택의 맨 위에는 "가장 최근에 열린, 아직 닫히지 않은 괄호"가 항상 위치한다
3. **닫는 괄호가 오면 스택의 맨 위와 대조한다**: 닫는 괄호를 만나면 스택에서 pop한 여는 괄호가 대응하는 종류인지를 확인한다. 대응하지 않으면 올바르지 않은 문자열이다
4. **스택이 비어 있을 때 닫는 괄호가 오면 올바르지 않다**: pop하기 전에 스택이 비어 있으면 대응하는 여는 괄호가 존재하지 않는다는 의미이므로 `false`를 반환한다
5. **순회 완료 후 스택이 비어 있으면 올바르다**: 모든 문자를 처리한 후 스택에 여는 괄호가 남아 있으면 닫히지 않은 괄호가 있다는 의미이다. 스택이 비어 있으면 모든 괄호가 올바르게 대응하고 있다

## 사전 지식

### Stack이란

후입선출(LIFO: Last In, First Out) 데이터 구조이다. 마지막에 추가한 요소가 가장 먼저 꺼내진다. 괄호의 대응 검사처럼 "가장 최근의 것"부터 순서대로 처리하는 상황에서 사용한다.

```java
Stack<Character> stack = new Stack<>();  // 빈 스택을 생성한다
stack.push('(');      // 스택의 맨 위에 '('를 추가한다
stack.peek();         // 스택의 맨 위 요소를 꺼내지 않고 참조한다 → '('
stack.pop();          // 스택의 맨 위 요소를 꺼내어 반환한다 → '('
stack.isEmpty();      // 스택이 비어 있는지를 boolean으로 반환한다 → true
```

### 괄호의 대응 관계

3종류의 괄호에는 각각 여는 괄호와 닫는 괄호의 쌍이 있다. 닫는 괄호가 왔을 때 스택의 맨 위가 대응하는 여는 괄호인지를 확인할 필요가 있다.

```
')'에 대응하는 여는 괄호는 '('이다
'}'에 대응하는 여는 괄호는 '{'이다
']'에 대응하는 여는 괄호는 '['이다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 문자열을 1회 순회하는 것만으로 충분하다 |
| Space | O(n) — 스택에 최대 n개의 여는 괄호를 저장한다 |

## 코드

```java
// 입력: 괄호로만 구성된 문자열 s
// 출력: 모든 괄호가 올바르게 대응하면 true, 그렇지 않으면 false
public boolean isValid(String s) {
    // "아직 닫히지 않은 여는 괄호"를 보관하는 스택
    // 스택의 맨 위에는 가장 최근에 열린 괄호가 위치한다
    Stack<Character> stack = new Stack<>();

    // 문자열을 처음부터 한 문자씩 순회한다. toCharArray()로 문자열을 char 배열로 변환한다
    for (char c : s.toCharArray()) {
        // 여는 괄호이면 스택에 쌓는다. 대응하는 닫는 괄호가 올 때까지 스택에 남아 있는다
        if (c == '(' || c == '{' || c == '[') {
            stack.push(c);
        } else {
            // 닫는 괄호인데 스택이 비어 있으면 대응하는 여는 괄호가 존재하지 않으므로 올바르지 않다
            if (stack.isEmpty()) return false;

            // 스택의 맨 위에서 "가장 최근에 열린, 아직 닫히지 않은 괄호"를 꺼낸다
            char top = stack.pop();

            // 닫는 괄호와 여는 괄호의 종류가 대응하지 않으면 올바르지 않다
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
            if (c == ')' && top != '(') return false;
        }
    }

    // 스택이 비어 있으면 모든 괄호가 올바르게 대응하고 있다
    // 스택에 요소가 남아 있으면 닫히지 않은 여는 괄호가 있으므로 false를 반환한다
    return stack.isEmpty();
}
```
