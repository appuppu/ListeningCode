# Counting Car Fleets Arriving at a Destination — 목적지에 도착하는 차량 대열 수를 구하기

## 문제의 본질

정수 `target`(목적지의 위치), 정수 배열 `position`(각 차량의 현재 위치), 정수 배열 `speed`(각 차량의 속도)가 주어진다. 모든 차량은 같은 목적지를 향해 주행하고 있다. 빠른 차량이 앞에 있는 느린 차량을 따라잡으면, 느린 차량의 속도에 맞추어 하나의 대열(fleet)로 주행한다. 최종적으로 목적지에 도착하는 **대열의 수**를 정수로 반환한다.

## 핵심 아이디어

목적지에 가까운 차량부터 순서대로 처리하고, 각 차량의 "목적지 도착 시간"을 스택으로 관리하면, 뒤에 있는 차량의 도착 시간이 앞 차량의 도착 시간 이하이면 합류하고, 더 크면 새로운 대열로 판정할 수 있으며, 최종적인 스택의 크기가 대열 수가 된다.

## 사고 프로세스

1. **대열의 성립 조건을 도착 시간으로 판정한다**: 뒤에 있는 차량이 앞 차량을 따라잡는지 여부는 목적지 도착 시간으로 결정된다. 뒤 차량의 도착 시간이 앞 차량의 도착 시간 이하이면, 도중에 따라잡으므로 같은 대열이 된다. 도착 시간은 `(target - position[i]) / speed[i]`로 계산할 수 있다
2. **목적지에 가까운 차량부터 순서대로 처리하고자 한다**: 대열의 합류 판정은 "앞 차량(목적지에 가까운 차량)이 벽이 되는지 여부"로 결정되므로, 목적지에 가까운 순서로 정렬하여 처리하면, 앞 차량의 도착 시간을 기준으로 뒤 차량을 순차적으로 판정할 수 있다
3. **정렬 대상은 인덱스로 한다**: position과 speed는 별도의 배열이므로, 인덱스 배열을 생성하고 `position`의 내림차순(목적지에 가까운 순)으로 정렬한다. 이렇게 하면 원래 배열을 변경하지 않고, 대응하는 position과 speed를 참조할 수 있다
4. **스택으로 대열을 관리한다**: 스택의 맨 위에는 직전 대열의 도착 시간(= 해당 대열의 선두 차량의 도착 시간)이 들어 있다. 새 차량의 도착 시간이 스택의 맨 위 이하이면, 해당 차량은 앞 대열에 합류하므로 스택에 추가하지 않는다. 도착 시간이 맨 위보다 크면, 새로운 대열이 형성되므로 스택에 push한다
5. **스택의 크기가 답이 된다**: 합류한 차량은 스택에 추가되지 않고, 새로운 대열을 형성하는 차량만 push되므로, 최종적인 스택의 요소 수가 그대로 대열의 수가 된다

## 전제 지식

### 도착 시간의 계산

차량의 현재 위치가 `pos`, 속도가 `speed`, 목적지가 `target`일 때, 도착 시간은 `(target - pos) / speed`로 구할 수 있다. 이 값이 작을수록 빨리 도착한다.

```
예시: target=12, pos=10, speed=2 일 때
도착 시간 = (12 - 10) / 2 = 1.0
```

### Integer[]의 커스텀 정렬

프리미티브 타입 `int[]`은 람다식으로 정렬할 수 없으므로, `Integer[]` 인덱스 배열을 생성하고 `Arrays.sort`에 Comparator를 전달하여 정렬한다.

```java
Integer[] idx = new Integer[n];
for (int i = 0; i < n; i++) idx[i] = i;
// pos의 내림차순(목적지에 가까운 순)으로 인덱스를 정렬한다
Arrays.sort(idx, (a, b) -> pos[b] - pos[a]);
```

### Stack이란

후입선출(LIFO) 데이터 구조이다. `push`로 요소를 쌓고, `peek`로 맨 위의 요소를 참조하며, `pop`으로 꺼낸다. 여기서는 스택의 맨 위에 "직전 대열의 도착 시간"을 유지하고, 합류 판정의 기준으로 사용한다.

```java
Stack<Double> stack = new Stack<>();  // 빈 스택을 생성한다
stack.push(3.0);    // 요소 3.0을 스택의 맨 위에 쌓는다
stack.peek();        // 맨 위의 요소를 꺼내지 않고 참조한다 → 3.0
stack.isEmpty();     // 스택이 비어 있는지 판정한다 → false
stack.size();        // 스택 내의 요소 수를 반환한다 → 1
```

## 계산량

| | 값 |
|---|---|
| Time | O(n log n) — 인덱스 배열의 정렬에 O(n log n), 이후의 순회에 O(n)이 소요된다 |
| Space | O(n) — 인덱스 배열과 스택에 각각 최대 n개의 요소를 저장한다 |

## 코드

```java
// 입력: 정수 target(목적지의 위치), 정수 배열 pos(각 차량의 위치), 정수 배열 speed(각 차량의 속도)
// 출력: 목적지에 도착하는 대열의 수를 정수로 반환한다
public int carFleet(int target, int[] pos, int[] speed) {
    // 차량의 대수를 가져온다
    int n = pos.length;

    // Integer[] 타입의 인덱스 배열을 생성하고, 0부터 n-1까지의 값으로 초기화한다
    // 인덱스 배열을 정렬함으로써, 원래 배열을 유지한 채로 순서를 변경할 수 있다
    Integer[] idx = new Integer[n];
    for (int i = 0; i < n; i++) {
        idx[i] = i;
    }

    // 인덱스 배열을 position의 내림차순(목적지에 가까운 순)으로 정렬한다
    // 목적지에 가까운 차량부터 처리함으로써, 앞 차량을 기준으로 한 합류 판정이 가능해진다
    Arrays.sort(idx, (a, b) -> pos[b] - pos[a]);

    // 각 대열의 도착 시간을 저장하는 스택
    // 스택의 맨 위는 "직전에 확정된 대열의 도착 시간"을 나타낸다
    Stack<Double> stack = new Stack<>();

    for (int i : idx) {
        // 이 차량의 목적지 도착 시간을 계산한다
        // double로 캐스팅하지 않으면 정수 나눗셈이 되어 소수 부분이 손실된다
        double time = (double) (target - pos[i]) / speed[i];

        // 도착 시간이 스택의 맨 위 이하이면, 이 차량은 앞 대열을 따라잡으므로 합류한다
        // continue로 스택에 추가하는 것을 건너뛰고, 다음 차량의 처리로 진행한다
        if (!stack.isEmpty() && time <= stack.peek()) {
            continue;
        }

        // 스택이 비어 있거나, time이 맨 위보다 큰 경우, 앞 대열을 따라잡을 수 없다
        // 새로운 대열을 형성하므로 스택에 도착 시간을 쌓는다
        stack.push(time);
    }

    // 스택에는 각 대열의 도착 시간이 하나씩 들어 있으므로, 크기가 대열의 수와 일치한다
    return stack.size();
}
```
