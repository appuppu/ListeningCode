# Evaluating an Expression in Reverse Polish Notation — 역폴란드 표기법의 산술식을 평가하기

## 문제의 본질

문자열 배열 `tokens`가 역폴란드 표기법(RPN)의 산술식으로 주어진다. 이 식을 평가하여 결과를 정수로 반환한다. 유효한 연산자는 `+`, `-`, `*`, `/`의 4가지이며, 각 피연산자는 정수 또는 다른 부분식이다. 나눗셈은 0 방향으로 버림한다. 예: `["2","1","+","3","*"]` → `((2+1)*3)` → `9`.

## 핵심 아이디어

역폴란드 표기법에서는 연산자의 우선순위나 괄호 처리가 필요 없으며, 토큰을 왼쪽에서 오른쪽으로 순회하면서 스택에 숫자를 쌓고, 연산자가 나타나면 상위 2개를 꺼내어 계산 결과를 다시 넣는 것만으로 식 전체를 올바르게 평가할 수 있다.

## 사고 프로세스

1. **RPN의 성질을 이해한다**: 역폴란드 표기법에서는 연산자가 바로 앞의 두 피연산자에 작용한다. 즉, 연산자가 출현하는 시점에서 대상이 되는 두 피연산자는 이미 확정되어 있다. 이 성질로 인해 "마지막에 추가한 것을 가장 먼저 꺼내는" LIFO 데이터 구조인 스택이 적합하다
2. **토큰이 숫자인지 연산자인지에 따라 처리를 분기한다**: 각 토큰을 순서대로 확인하여, 숫자이면 스택에 쌓고, 연산자이면 계산을 수행한다. 이 두 가지 연산만으로 식 전체를 평가할 수 있다
3. **연산자 처리 시 피연산자의 순서에 주의한다**: 스택에서 처음 pop한 값이 오른쪽 피연산자(`a`)이고, 다음에 pop한 값이 왼쪽 피연산자(`b`)가 된다. 계산은 `b 연산자 a` 순서로 수행한다. 이 순서를 잘못 적용하면 뺄셈과 나눗셈에서 잘못된 결과가 나온다
4. **계산 결과를 스택에 다시 넣는다**: 연산 결과를 스택에 push함으로써, 해당 결과가 이후 연산의 피연산자로 사용된다. 이를 통해 중첩된 부분식도 자연스럽게 처리된다
5. **최종 결과는 스택에 하나만 남는다**: 유효한 RPN 식이라면 모든 토큰을 처리한 후 스택에는 계산 결과가 하나만 남는다. 이 값을 pop하여 반환한다

## 전제 지식

### Stack이란

후입선출(LIFO) 데이터 구조이다. 마지막에 추가한 요소를 가장 먼저 꺼낼 수 있다. 요소의 추가(push)와 꺼내기(pop)는 모두 O(1)로 수행할 수 있다.

```java
Stack<Integer> stack = new Stack<>();  // 빈 스택을 생성한다
stack.push(5);     // 스택의 맨 위에 5를 쌓는다 → [5]
stack.push(3);     // 스택의 맨 위에 3을 쌓는다 → [5, 3]
stack.pop();       // 맨 위의 요소를 꺼내어 반환한다 → 3, 스택은 [5]
stack.pop();       // 맨 위의 요소를 꺼내어 반환한다 → 5, 스택은 []
```

### 역폴란드 표기법(RPN)이란

연산자를 피연산자 뒤에 놓는 표기법이다. 일반적인 중위 표기법 `(2 + 1) * 3`은 RPN에서는 `2 1 + 3 *`으로 표기한다. 괄호가 필요 없으며, 왼쪽에서 오른쪽으로 순서대로 처리하는 것만으로 올바르게 평가할 수 있다.

```
중위 표기법:  (2 + 1) * 3
RPN:         2 1 + 3 *
평가 과정:   2 1 + → 3, 다음에 3 3 * → 9
```

### Integer.parseInt란

문자열을 정수로 변환하는 Java의 정적 메서드이다. 음수를 나타내는 문자열(예: `"-3"`)도 올바르게 변환할 수 있다.

```java
Integer.parseInt("42");    // → 42
Integer.parseInt("-3");    // → -3
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열의 토큰을 한 번 순회하는 것만으로 충분하다 |
| Space | O(n) — 스택에 최대 n개의 요소를 저장한다 |

## 코드

```java
// 입력: 역폴란드 표기법의 산술식을 나타내는 문자열 배열 tokens
// 출력: 식의 평가 결과를 정수로 반환한다
public int evalRPN(String[] tokens) {
    // 숫자 피연산자와 중간 계산 결과를 일시적으로 보관하는 스택
    Stack<Integer> stack = new Stack<>();

    // 배열 tokens를 처음부터 끝까지 하나씩 순회한다
    for (String token : tokens) {
        // 현재 토큰이 연산자(+, -, *, / 중 하나)인지를 판정한다
        switch (token) {
            case "+": {
                int a = stack.pop();  // 첫 번째 pop → 오른쪽 피연산자
                int b = stack.pop();  // 두 번째 pop → 왼쪽 피연산자
                // 계산 결과를 push하여 이후 연산의 피연산자로 사용한다
                stack.push(b + a);
                break;
            }
            case "-": {
                int a = stack.pop();
                int b = stack.pop();
                // 주의: pop 순서가 반대이므로 반드시 b - a 순서로 계산한다. a - b로 하면 결과가 반전된다
                stack.push(b - a);
                break;
            }
            case "*": {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(b * a);
                break;
            }
            case "/": {
                int a = stack.pop();
                int b = stack.pop();
                // Java의 정수 나눗셈은 자동으로 0 방향으로 버림되므로 특별한 처리가 필요 없다
                // 주의: pop 순서가 반대이므로 반드시 b / a 순서로 계산한다. a / b로 하면 결과가 반전된다
                stack.push(b / a);
                break;
            }
            default: {
                // 숫자 토큰을 정수로 변환하여 스택에 쌓는다
                // 음수(예: "-3")도 parseInt가 올바르게 처리한다
                stack.push(Integer.parseInt(token));
            }
        }
    }

    // 유효한 RPN 식이라면 모든 토큰 처리 후 스택에는 결과가 하나만 남는다
    return stack.pop();
}
```
