# Designing a Stack That Tracks the Minimum — 모든 연산을 O(1)으로 수행하며 최솟값을 조회할 수 있는 스택을 설계한다

## 문제의 본질

`push`, `pop`, `top`, `getMin`(현재 최솟값 조회)의 4가지 연산을 모두 O(1)으로 수행할 수 있는 스택을 설계한다. 일반적인 스택에서는 최솟값을 조회하는 데 O(n)이 걸리므로, 별도의 설계가 필요하다.

## 핵심 아이디어

스택의 각 요소에 "해당 시점에서의 최솟값"을 함께 저장하면, 요소가 pop되더라도 최솟값 정보가 유실되지 않는다. `getMin()`은 항상 스택의 맨 위만 확인하면 되므로 O(1)으로 답을 얻을 수 있다.

## 사고 과정

1. **getMin을 O(1)으로 만들려면, 최솟값을 항상 파악하고 있어야 한다**: 변수 하나로 최솟값을 관리하는 방법을 생각해 볼 수 있지만, pop으로 최솟값이 제거되었을 때 그다음 최솟값을 알 수 없게 된다. 즉, 최솟값의 "이력"을 유지하는 구조가 필요하다
2. **최솟값의 이력은 스택의 상태와 연동된다**: 스택에 요소가 쌓일 때마다 최솟값이 바뀔 수 있다. 반대로 pop되면 push하기 전의 최솟값으로 되돌아간다. 이 "push하기 전 상태로 되돌아간다"는 성질은 스택 자체의 성질과 동일하다
3. **각 요소에 해당 시점의 최솟값을 쌍으로 저장한다**: push할 때, 새로운 값과 현재 최솟값을 비교하여 더 작은 쪽을 "해당 시점의 최솟값"으로 새로운 값과 함께 저장한다. 이렇게 하면 pop으로 요소가 제거되더라도 다음 맨 위 요소가 올바른 최솟값을 가지고 있다
4. **쌍의 구조를 결정한다**: `int[]` 배열을 사용하여, `[0]`에 값을, `[1]`에 해당 시점의 최솟값을 저장한다. 스택의 타입은 `Stack<int[]>`가 된다
5. **push에서 최솟값을 계산하는 방법**: 스택이 비어 있으면 새로운 값이 그대로 최솟값이 된다. 비어 있지 않으면 새로운 값과 스택 맨 위에 있는 최솟값(`stack.peek()[1]`)을 비교하여 더 작은 쪽을 채택한다
6. **top·getMin·pop의 구현**: `top()`은 맨 위 쌍의 `[0]`을, `getMin()`은 맨 위 쌍의 `[1]`을 반환하기만 하면 되므로 O(1)이다. `pop()`은 일반 스택과 마찬가지로 맨 위를 제거하기만 하면 된다

## 사전 지식

### Stack이란

후입선출(LIFO) 데이터 구조이다. 마지막에 추가한 요소가 가장 먼저 꺼내진다. Java에서는 Generics를 사용하여 저장할 타입을 지정한다.

```java
Stack<int[]> stack = new Stack<>();  // int 배열을 저장하는 스택을 생성한다
stack.push(new int[]{1, 1});         // 요소를 맨 위에 추가한다
stack.peek();                         // 맨 위 요소를 제거하지 않고 참조한다 → [1, 1]
stack.pop();                          // 맨 위 요소를 제거하고 반환한다 → [1, 1]
stack.isEmpty();                      // 스택이 비어 있는지를 boolean으로 반환한다 → true
```

### Math.min이란

두 정수를 받아서 더 작은 쪽을 반환하는 메서드이다. push할 때마다 새로운 값과 현재 최솟값을 비교하기 위해 사용한다.

```java
Math.min(3, 5);   // → 3
Math.min(-1, 0);  // → -1
```

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(1) — push, pop, top, getMin의 모든 연산이 상수 시간에 완료된다 |
| Space | O(n) — 스택에 최대 n개의 쌍을 저장한다 |

## 코드

```java
// 입력: push(val), pop(), top(), getMin() 의 연산 시퀀스
// 출력: top()은 맨 위의 값을 반환한다. getMin()은 현재 스택 내의 최솟값을 반환한다
class MinStack {

    // Stack<int[]> 타입의 필드. 각 요소는 길이 2의 배열이며, [0]에 값을, [1]에 해당 시점에서의 스택 전체 최솟값을 저장한다
    private Stack<int[]> stack;

    public MinStack() {
        stack = new Stack<>();
    }

    public void push(int val) {
        // 스택이 비어 있으면 val 자체가 최솟값이 된다. 비어 있지 않으면 맨 위에 기록된 최솟값과 비교하여 더 작은 쪽을 채택한다
        int min = stack.isEmpty() ? val : Math.min(val, stack.peek()[1]);
        // 값과 최솟값의 쌍 new int[]{val, min}을 push한다. 이 요소가 맨 위에 있는 동안 min이 올바른 최솟값이 된다
        stack.push(new int[]{val, min});
    }

    public void pop() {
        // 맨 위의 쌍을 제거한다. 제거된 후 맨 위 쌍의 [1]에는 해당 요소가 push된 시점의 올바른 최솟값이 저장되어 있으므로, 최솟값의 정합성은 자동으로 유지된다
        stack.pop();
    }

    public int top() {
        // 쌍의 [0]에는 값 자체가 저장되어 있다
        return stack.peek()[0];
    }

    public int getMin() {
        // 쌍의 [1]에는 해당 시점에서의 최솟값이 저장되어 있으므로, 순회가 불필요하다
        return stack.peek()[1];
    }
}
```
