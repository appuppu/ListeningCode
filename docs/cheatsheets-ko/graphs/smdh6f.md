# Filling Distances to the Nearest Gate — 그리드 내 각 빈 방에서 가장 가까운 게이트까지의 거리를 구하기

## 문제의 본질

m×n 그리드가 주어진다. 각 셀은 "벽(-1)", "게이트(0)", "빈 방(Integer.MAX_VALUE)" 중 하나이다. 각 빈 방의 셀에 가장 가까운 게이트까지의 거리를 기록한다. 어떤 게이트에도 도달할 수 없는 방은 Integer.MAX_VALUE 그대로 둔다.

## 핵심 아이디어

각 빈 방에서 가장 가까운 게이트를 찾는 것이 아니라, 모든 게이트에서 동시에 BFS를 시작한다. BFS의 각 단계가 거리 1, 2, 3…에 대응하므로, 처음 도달한 시점에서 해당 셀의 최단 거리가 확정된다.

## 사고 과정

1. **각 방에서 게이트를 찾으면 비효율적이다**: 빈 방마다 BFS를 수행하면, 방의 수만큼 BFS가 실행되어 계산량이 커진다. 발상을 뒤집어 게이트 쪽에서 방을 향해 탐색하면, 모든 게이트를 시작점으로 하여 1회의 BFS로 전체 방의 최단 거리를 구할 수 있다
2. **여러 게이트에서 동시에 출발한다(Multi-source BFS)**: 모든 게이트를 큐에 넣은 상태에서 BFS를 시작한다. 이렇게 하면 거리 1인 방이 모두 먼저 처리되고, 다음으로 거리 2인 방이 처리된다. BFS의 레벨 순서 탐색 특성에 의해 각 방에 처음 도달했을 때의 거리가 최단 거리가 된다
3. **방문 여부 판정을 값으로 할 수 있다**: 빈 방은 Integer.MAX_VALUE로 초기화되어 있다. BFS로 도달한 셀에는 거리를 기록하므로, 값이 Integer.MAX_VALUE인 셀만 미방문 셀이다. 별도의 visited 배열을 준비할 필요가 없다
4. **거리 계산은 부모 셀의 값+1이다**: 큐에서 꺼낸 셀(부모)의 값에 1을 더한 값이 인접 셀(자식)의 거리가 된다. 게이트의 값이 0이므로, 인접한 방은 1, 그 옆은 2로 올바르게 전파된다
5. **벽과 범위 밖은 단순히 건너뛴다**: 벽(-1)이나 게이트(0)는 Integer.MAX_VALUE가 아니므로, 미방문 판정에서 자연스럽게 제외된다. 범위 밖의 인덱스는 경계 검사로 걸러낸다

## 사전 지식

### BFS(너비 우선 탐색)란

그래프나 그리드를 "가까운 순서"로 탐색하는 알고리즘이다. 큐(선입선출)를 사용하여 시작점에서 거리 1인 노드를 모두 처리한 후 거리 2인 노드로 진행한다. 이 특성에 의해 각 노드까지의 최단 거리가 보장된다.

```java
Queue<int[]> queue = new LinkedList<>();  // BFS용 큐를 생성한다
queue.offer(new int[]{0, 0});             // 시작점의 좌표를 큐에 추가한다
int[] cell = queue.poll();                // 큐의 맨 앞에서 요소를 꺼낸다
queue.isEmpty();                          // 큐가 비어 있는지 판정한다 → true/false
```

### Multi-source BFS란

일반적인 BFS는 시작점이 1개이지만, Multi-source BFS는 여러 시작점을 큐에 넣은 상태에서 시작한다. 모든 시작점에서 동시에 파동이 퍼지듯 탐색이 진행되며, 각 셀에는 가장 가까운 시작점으로부터의 거리가 기록된다.

```java
// 모든 게이트(값이 0인 셀)를 시작점으로 큐에 추가한다
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        if (rooms[i][j] == 0)
            queue.offer(new int[]{i, j});
// 이 상태에서 BFS를 시작하면, 모든 게이트에서 동시에 탐색이 시작된다
```

### 4방향 인접 셀 탐색

그리드 위에서 상하좌우 4방향으로 이동할 때, 방향 벡터 배열을 사용하면 코드가 간결해진다. 각 방향 벡터를 현재 좌표에 더하여 인접 셀의 좌표를 구한다.

```java
int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};  // 상·하·좌·우 방향 벡터
for (int[] d : dirs) {
    int r = cell[0] + d[0];  // 인접 셀의 행 번호
    int c = cell[1] + d[1];  // 인접 셀의 열 번호
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(m × n) — 각 셀은 큐에 최대 1회만 추가되므로, 전체 셀을 1회씩 처리한다 |
| Space | O(m × n) — 큐에 최대 m×n개의 셀이 들어갈 수 있다 |

## 코드

```java
// 입력: m×n 정수 그리드 rooms(-1=벽, 0=게이트, Integer.MAX_VALUE=빈 방)
// 출력: 반환값 없음(void). rooms를 직접 수정하여, 각 빈 방의 셀에 가장 가까운 게이트까지의 거리를 저장한다
public void wallsAndGates(int[][] rooms) {
    // 그리드의 행 수를 가져온다
    int m = rooms.length;
    // 그리드가 비어 있으면 처리를 종료한다
    if (m == 0) return;
    // 그리드의 열 수를 가져온다
    int n = rooms[0].length;

    // BFS용 큐를 생성한다. 셀의 좌표 {행, 열}을 저장한다
    Queue<int[]> q = new LinkedList<>();

    // 그리드 전체를 순회하여, 모든 게이트(값이 0인 셀)를 큐에 추가한다
    // 이를 통해 모든 게이트가 BFS의 시작점으로 동시에 등록된다(Multi-source BFS)
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (rooms[i][j] == 0)
                q.offer(new int[]{i, j});

    // 상·하·좌·우 4방향을 나타내는 방향 벡터. 루프에서 인접 셀을 열거하기 위해 사용한다
    int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

    // 큐가 빌 때까지 BFS를 계속한다. BFS의 특성에 의해 거리가 작은 셀부터 순서대로 처리된다
    while (!q.isEmpty()) {
        // 큐의 맨 앞에서 셀을 꺼낸다. cell[0]이 행 번호, cell[1]이 열 번호이다
        int[] cell = q.poll();

        // 4방향의 인접 셀을 조사한다
        for (int[] d : dirs) {
            // 방향 벡터를 더하여 인접 셀의 좌표를 계산한다
            int r = cell[0] + d[0];
            int c = cell[1] + d[1];

            // 범위 밖이면 건너뛴다
            if (r < 0 || r >= m || c < 0 || c >= n) continue;

            // 값이 Integer.MAX_VALUE가 아니면 건너뛴다(벽·게이트·거리 확정된 방)
            // 이 판정을 통해 별도의 visited 배열 없이도 재방문을 방지할 수 있다
            if (rooms[r][c] != Integer.MAX_VALUE) continue;

            // 부모 셀의 거리+1을 기록한다. 게이트가 0이므로 인접은 1, 그 옆은 2로 올바르게 전파된다
            // BFS가 거리 순서로 셀을 처리하므로, 처음 도달한 거리가 최단 거리가 된다
            rooms[r][c] = rooms[cell[0]][cell[1]] + 1;
            // 거리를 기록한 셀을 큐에 추가하여, 그 너머의 방을 계속 탐색한다
            q.offer(new int[]{r, c});
        }
    }
}
```
