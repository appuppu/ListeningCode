# Counting Connected Components in an Undirected Graph — 무향 그래프의 연결 요소의 수를 세기

## 문제의 본질

`0`부터 `n-1`까지의 라벨이 붙은 `n`개의 노드와 무향 간선의 리스트 `edges`가 주어진다. 그래프 내의 **연결 요소(connected component)의 수**를 정수로 반환한다. 연결 요소란 간선을 따라 서로 도달할 수 있는 노드의 집합이다.

## 핵심 아이디어

처음에 각 노드를 독립된 연결 요소로 간주하고, 간선을 하나씩 처리하면서 양 끝 노드가 속하는 그룹을 통합해 나간다. 모든 간선을 처리한 후에 남아 있는 그룹의 수가 연결 요소의 수이다.

## 사고 프로세스

1. **간선으로 연결된 노드는 같은 그룹에 속한다**: 연결 요소란 "간선을 따라 도달할 수 있는 노드의 집합"이므로, 간선으로 연결된 두 노드는 반드시 같은 연결 요소에 속한다. 모든 간선에 대해 "양 끝 노드를 같은 그룹으로 묶는" 연산을 반복하면, 최종적으로 연결 요소를 구할 수 있다
2. **그룹 관리에는 Union-Find가 적합하다**: "두 요소를 같은 그룹으로 통합하는(union)" 연산과 "어떤 요소가 어느 그룹에 속하는지를 조회하는(find)" 연산을 고속으로 수행하는 자료 구조가 Union-Find이다. 각 노드에 "부모 노드"를 두고, 루트(root)가 같은 노드끼리를 동일 그룹으로 간주한다
3. **초기 상태에서 각 노드는 자기 자신을 부모로 가진다**: `parent[i] = i`로 초기화함으로써, 처음에는 n개의 노드가 각각 독립된 그룹(연결 요소)이 된다. 초기 연결 요소의 수는 `n`이다
4. **간선을 처리할 때마다 union을 수행하고, 통합이 일어나면 요소 수를 줄인다**: 각 간선 `[a, b]`에 대해 `a`의 루트와 `b`의 루트를 구한다. 루트가 다르면 두 노드는 서로 다른 그룹이므로, 한쪽 루트를 다른 쪽 루트의 자식으로 만들어 통합하고, 연결 요소의 수를 1 줄인다. 루트가 같으면 이미 같은 그룹이므로 아무 작업도 하지 않는다
5. **경로 압축과 랭크로 고속화한다**: find 수행 시 경로 압축(path compression)을 적용하여, 방문한 노드의 부모를 직접 루트로 교체한다. union 수행 시 랭크(트리 높이의 상한)를 비교하여, 낮은 트리를 높은 트리 아래에 붙인다(union by rank). 이를 통해 find의 시간 복잡도가 거의 O(1)(정확히는 O(α(V)))이 된다
6. **모든 간선을 처리한 후의 `components`가 정답이다**: 초기값 `n`에서 union이 성공할 때마다 1씩 줄인 결과가 최종적인 연결 요소의 수가 된다

## 전제 지식

### Union-Find(서로소 집합 자료 구조)란

요소를 그룹으로 나누어 관리하는 자료 구조이다. "두 요소를 같은 그룹으로 통합하는(union)" 연산과 "어떤 요소가 속하는 그룹의 대표(루트)를 구하는(find)" 연산, 이 두 가지 연산을 제공한다. `parent` 배열로 각 요소의 부모를 기록하고, 루트까지 부모를 따라감으로써 그룹의 대표를 특정한다.

```java
int[] parent = new int[n];   // parent[i]는 노드 i의 부모 노드를 저장한다
for (int i = 0; i < n; i++)
    parent[i] = i;            // 초기 상태: 각 노드가 자기 자신을 부모로 가진다(독립된 그룹)
```

### 경로 압축(Path Compression)이란

find의 재귀 과정에서 방문한 모든 노드의 부모를 직접 루트로 교체하는 최적화 기법이다. 이후의 find가 즉시 루트를 반환하게 되며, 트리가 평탄화됨으로써 시간 복잡도가 거의 O(1)로 개선된다.

```java
int find(int[] parent, int x) {
    if (parent[x] != x)
        parent[x] = find(parent, parent[x]);  // 재귀로 루트를 찾고, 부모를 루트로 교체한다
    return parent[x];                          // 루트를 반환한다
}
```

### 랭크(Rank)에 의한 union이란

union 수행 시 트리 높이의 상한(랭크)을 비교하여, 랭크가 낮은 트리를 랭크가 높은 트리 아래에 붙이는 기법이다. 트리 높이의 증가를 억제함으로써 find의 효율을 유지한다. 랭크가 같은 경우에만 통합 대상의 랭크를 1 증가시킨다.

```java
int[] rank = new int[n];     // rank[i]는 노드 i를 루트로 하는 트리 높이의 상한이다(초기값은 0)
// 랭크가 높은 쪽을 부모로 만든다 → 트리가 깊어지기 어렵다
if (rank[r1] > rank[r2])
    parent[r2] = r1;         // r2의 트리를 r1 아래에 붙인다
```

### α(아커만 함수의 역함수)란

Union-Find의 시간 복잡도에 나타나는 함수이다. 실용적인 입력 크기에서 α(V)는 항상 5 이하이며, 사실상 상수로 간주할 수 있다. 따라서 Union-Find의 각 연산은 거의 O(1)로 동작한다.

## 시간·공간 복잡도

| | 값 |
|---|---|
| Time | O(V + E · α(V)) — 초기화에 O(V), 각 간선에 대해 find와 union을 수행하지만 α(V)는 거의 상수이므로 실질적으로 O(V + E) |
| Space | O(V) — parent 배열과 rank 배열에 각각 V개의 요소를 저장한다 |

## 코드

```java
// 입력: 노드 수 n과 간선의 리스트 edges(각 간선은 2개의 요소로 구성된 배열 [a, b])
// 출력: 연결 요소의 수를 정수로 반환한다

// 경로 압축이 적용된 find 함수: 노드 x가 속하는 그룹의 루트를 반환한다
int find(int[] parent, int x) {
    if (parent[x] != x)
        // 재귀적으로 루트를 찾고, 부모를 직접 루트로 교체한다(경로 압축)
        // 이를 통해 이후의 find가 즉시 루트를 반환하게 된다
        parent[x] = find(parent, parent[x]);
    return parent[x];
}

int countComponents(int n, int[][] edges) {
    // 각 노드의 부모를 저장하는 배열. parent[i] = i로 초기화하여 각 노드를 독립된 그룹으로 만든다
    int[] parent = new int[n];
    // 각 노드를 루트로 하는 트리 높이의 상한을 저장하는 배열(union 시 어느 쪽 아래에 붙일지를 결정하는 데 사용한다)
    int[] rank = new int[n];
    for (int i = 0; i < n; i++)
        parent[i] = i;

    // 초기 상태에서 각 노드는 독립된 연결 요소이므로, 요소 수는 n이다
    int components = n;

    // 간선을 하나씩 순회하며, 양 끝 노드가 속하는 그룹을 통합해 나간다
    for (int[] e : edges) {
        // 간선의 양 끝 노드가 속하는 그룹의 루트를 구한다(경로 압축에 의해 방문 노드의 부모도 루트로 교체된다)
        int r1 = find(parent, e[0]);
        int r2 = find(parent, e[1]);

        // 루트가 다르면 서로 다른 그룹이므로 통합한다(루트가 같으면 이미 같은 그룹이므로 아무 작업도 하지 않는다)
        if (r1 != r2) {
            // 랭크를 비교하여, 낮은 쪽을 높은 쪽 아래에 붙인다(트리 높이의 증가를 억제한다)
            if (rank[r1] > rank[r2])
                parent[r2] = r1;
            else if (rank[r1] < rank[r2])
                parent[r1] = r2;
            else {
                // 랭크가 같은 경우, r2를 r1 아래에 붙이고 r1의 랭크를 1 증가시킨다
                parent[r2] = r1;
                rank[r1]++;
            }
            // 두 그룹이 하나로 통합되었으므로 요소 수를 1 줄인다
            components--;
        }
    }
    // 모든 간선을 처리한 후의 components가 연결 요소의 수이다
    return components;
}
```
