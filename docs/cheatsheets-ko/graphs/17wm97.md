# Checking if a Graph Forms a Valid Tree — 그래프가 유효한 트리를 형성하는지 판정하기

## 문제의 본질

`0`부터 `n-1`까지 라벨이 부여된 `n`개의 노드와 무향 간선 리스트 `edges`가 주어진다. 이 그래프가 **유효한 트리(valid tree)**를 형성하는지 판정하여 `boolean`으로 반환한다. 유효한 트리란 모든 노드가 연결되어 있고, 사이클(순환)이 존재하지 않는 그래프이다.

## 핵심 아이디어

트리는 노드 수 `n`에 대해 간선의 수가 정확히 `n-1`개이며, 사이클이 없다. 간선의 수가 `n-1`개인지를 먼저 확인하고, Union-Find로 각 간선을 결합해 나가는 과정에서 사이클의 유무를 검출하면 트리인지 여부를 판정할 수 있다.

## 사고 프로세스

1. **트리의 필요조건을 활용한다**: 유효한 트리는 반드시 `n-1`개의 간선을 가진다. 간선의 수가 `n-1`이 아니면, 그 시점에서 트리가 아니라고 즉시 판정할 수 있다. 이 사전 검사를 통해 간선이 너무 많은 경우(사이클이 확실히 존재)도 간선이 너무 적은 경우(비연결)도 배제할 수 있다
2. **사이클 검출 방법을 생각한다**: 간선의 수가 `n-1`개여도 사이클이 존재할 가능성이 있다(그 경우 비연결이 된다). 각 간선을 추가할 때마다 양 끝 노드가 이미 같은 연결 성분에 속하는지를 판정하면 사이클을 검출할 수 있다
3. **Union-Find로 연결 성분을 관리한다**: Union-Find(서로소 집합 자료구조)를 사용하면, 두 노드가 같은 연결 성분에 속하는지 판정(find)과 두 연결 성분의 통합(union)을 거의 O(1)로 실행할 수 있다. 각 노드의 부모를 자기 자신으로 초기화하고, 간선마다 union을 수행한다
4. **사이클 검출 조건을 정한다**: union 연산 시에 두 노드의 루트(근)가 같으면, 그들은 이미 연결되어 있다. 거기에 추가로 간선을 추가하면 사이클이 발생하므로 `false`를 반환한다
5. **모든 간선 처리 후 결과를 반환한다**: 모든 간선을 처리해도 사이클이 검출되지 않으면, 간선의 수가 `n-1`개인 것(1단계에서 확인 완료)과 합쳐서 그래프가 유효한 트리라고 판정하고 `true`를 반환한다

## 전제 지식

### Union-Find(서로소 집합 자료구조)란

여러 요소를 그룹(집합)으로 나누어 관리하는 자료구조이다. 두 가지 연산을 제공한다. `find`는 어떤 요소가 속하는 그룹의 대표 원소(루트)를 반환한다. `union`은 두 요소가 속하는 그룹을 하나로 통합한다. 경로 압축과 랭크에 의한 최적화를 수행하면 각 연산을 거의 O(1)로 실행할 수 있다.

```java
int[] parent = {0, 1, 2, 3, 4};  // 초기 상태: 각 노드의 부모는 자기 자신
int[] rank = new int[5];          // 각 노드의 랭크(트리 높이의 상한)를 0으로 초기화

// find: 노드 x의 루트를 반환한다 (경로 압축 포함)
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 경로 압축: 부모를 직접 루트로 교체한다
    return parent[x];
}
```

### 경로 압축(Path Compression)이란

`find`를 호출할 때마다 탐색 경로 상의 모든 노드의 부모를 직접 루트로 교체하는 최적화 기법이다. 이를 통해 이후의 `find`가 O(1)에 근접한다. `parent[x] = find(parent[x])`의 재귀 대입으로 구현한다.

### 랭크에 의한 통합(Union by Rank)이란

두 트리를 통합할 때, 랭크(트리 높이의 상한)가 낮은 쪽을 높은 쪽 아래에 붙이는 기법이다. 트리 높이의 증가를 억제하여 `find`의 탐색 거리를 짧게 유지한다. 랭크가 같은 경우에만 통합 후 랭크를 1 증가시킨다.

```java
// union: 노드 a와 노드 b의 그룹을 통합한다. 이미 같은 그룹이면 false를 반환한다
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // 각 노드의 루트를 가져온다
    if (ra == rb) return false;       // 같은 루트 → 이미 같은 그룹 → 사이클
    if (rank[ra] < rank[rb])
        parent[ra] = rb;             // 랭크가 낮은 쪽을 높은 쪽 아래에 붙인다
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;             // 랭크가 같은 경우 ra 아래에 rb를 붙인다
        rank[ra]++;                   // 랭크를 1 증가시킨다
    }
    return true;
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(n × α(n)) — 각 간선에 대해 find와 union을 실행한다. α(n)은 아커만 함수의 역함수이며, 실용상 상수로 간주할 수 있다 |
| Space | O(n) — parent 배열과 rank 배열에 각각 n개의 요소를 저장한다 |

## 코드

```java
// 입력: 정수 n(노드 수)과 이차원 정수 배열 edges(각 요소는 [u, v]의 무향 간선)
// 출력: 그래프가 유효한 트리이면 true, 그렇지 않으면 false를 반환한다

// parent 배열: 각 노드의 부모를 관리한다
int[] parent, rank;

// 노드 x가 속하는 연결 성분의 루트를 반환한다 (경로 압축 포함)
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 경로 압축: 부모를 직접 루트로 교체한다
    return parent[x];
}

// 노드 a와 노드 b의 연결 성분을 통합한다. 사이클이 발생하는 경우 false를 반환한다
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // 양 끝 노드의 루트를 가져온다
    if (ra == rb) return false;       // 같은 루트이면 사이클이 발생한다 → 이 간선을 추가하면 사이클이 된다
    // 랭크가 낮은 쪽을 높은 쪽 아래에 붙여서 트리의 높이를 억제한다
    if (rank[ra] < rank[rb])
        parent[ra] = rb;
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;
        rank[ra]++;
    }
    return true;
}

public boolean validTree(int n, int[][] edges) {
    // 트리의 간선 수는 노드 수-1이어야 한다 (너무 많으면 사이클 확정, 너무 적으면 비연결)
    if (edges.length != n - 1)
        return false;

    // 각 노드의 부모를 자기 자신으로 초기화한다 (각 노드가 독립된 연결 성분을 형성한다)
    parent = new int[n];
    rank = new int[n];
    for (int i = 0; i < n; i++)
        parent[i] = i;

    // 각 간선을 처리하고, 양 끝이 이미 같은 연결 성분이면 사이클이 발생하므로 false를 반환한다
    for (int[] e : edges)
        if (!union(e[0], e[1]))
            return false;

    // 모든 간선을 처리해도 사이클이 없고, 간선의 수가 n-1개이므로 유효한 트리이다
    return true;
}
```
