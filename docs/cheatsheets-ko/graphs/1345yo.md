# Finding a Valid Order to Complete All Courses — 모든 코스를 완료할 수 있는 유효한 수강 순서를 구하기

## 문제의 본질

0부터 `numCourses - 1`까지 라벨이 붙은 코스와, 선행 조건 쌍 `[a, b]`(코스 `b`를 코스 `a`보다 먼저 수강해야 함)의 배열이 주어진다. 모든 코스를 완료할 수 있는 **유효한 수강 순서**를 배열로 반환한다. 유효한 순서가 존재하지 않는 경우(순환 의존이 있는 경우)에는 빈 배열을 반환한다.

## 핵심 아이디어

선행 조건의 의존 관계는 유향 그래프로 표현할 수 있으며, 유효한 수강 순서는 그 그래프의 위상 정렬에 대응한다. 진입 차수가 0인 노드(선행 조건이 없는 코스)부터 순서대로 처리하고, 처리 완료된 노드의 의존을 제거해 나가면, 순환이 없는 한 모든 노드를 올바른 순서로 나열할 수 있다.

## 사고 과정

1. **의존 관계를 그래프로 파악한다**: 선행 조건 `[a, b]`는 "`b` → `a`"라는 유향 간선을 의미한다. 모든 선행 조건을 유향 그래프의 간선으로 표현하면, 유효한 수강 순서는 이 그래프의 위상 정렬이 된다
2. **어떤 코스부터 시작할 수 있는지 판정하고자 한다**: 선행 조건이 하나도 없는 코스, 즉 진입 차수(해당 노드로 들어오는 간선의 수)가 0인 코스는 바로 수강할 수 있다. 진입 차수를 각 노드에 대해 계산해 두면, 시작 가능한 코스를 O(1)로 판정할 수 있다
3. **시작 가능한 코스를 처리한 후의 영향을 반영한다**: 어떤 코스를 수강 완료하면, 그 코스를 선행 조건으로 갖고 있던 다른 코스의 "남은 선행 조건 수"가 1 줄어든다. 이것은 진입 차수의 감소로 표현할 수 있다. 감소 결과, 진입 차수가 0이 된 코스는 새롭게 수강 가능해진다
4. **BFS로 처리 순서를 관리한다**: 진입 차수가 0인 코스를 큐에 넣고, 큐에서 꺼낼 때마다 그 코스를 결과 배열에 추가하며, 인접 노드의 진입 차수를 감소시킨다. 감소 결과 0이 된 노드를 큐에 추가한다. 이 반복이 Kahn's 알고리즘이다
5. **순환 의존의 검출**: 순환이 있으면, 순환 내의 모든 노드의 진입 차수는 영원히 0이 되지 않는다. 따라서 처리한 코스 수가 `numCourses`에 미치지 못하면 순환이 존재한다고 판정할 수 있다
6. **최종적으로 반환하는 것**: 처리한 코스 수가 `numCourses`와 일치하면 결과 배열을 반환하고, 일치하지 않으면 빈 배열을 반환한다

## 사전 지식

### 위상 정렬이란

유향 비순환 그래프(DAG)의 모든 노드를, 모든 간선이 왼쪽에서 오른쪽으로 향하도록 한 줄로 나열하는 것이다. 간선 `u → v`가 있을 때, 나열 순서에서 `u`는 반드시 `v`보다 앞에 온다. 순환이 있는 경우에는 위상 정렬이 불가능하다.

### 진입 차수(in-degree)란

어떤 노드로 들어오는 간선의 수이다. 진입 차수가 0인 노드는 다른 어떤 노드에도 의존하지 않으므로 가장 먼저 처리할 수 있다.

```java
int[] indegree = new int[numCourses];  // 각 노드의 진입 차수를 0으로 초기화한다
indegree[a]++;  // 노드 a에 간선이 1개 들어오므로 진입 차수를 1 증가시킨다
--indegree[next];  // 노드 next의 진입 차수를 1 감소시킨다 (선행 조건을 1개 해소한다)
```

### 인접 리스트(Adjacency List)란

그래프의 각 노드에 대해, 해당 노드에서 간선이 나가는 목적지 노드를 리스트로 관리하는 자료 구조이다. `graph.get(u)`로 노드 `u`에서 도달 가능한 모든 노드를 가져올 수 있다.

```java
List<List<Integer>> graph = new ArrayList<>();       // 그래프 전체를 보관하는 리스트
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());  // 각 노드에 빈 리스트를 할당한다
graph.get(u).add(v);   // 노드 u에서 노드 v로의 간선을 추가한다
graph.get(u);           // 노드 u의 모든 인접 노드를 가져온다 → [v, ...]
```

### Queue(큐)란

선입선출(FIFO) 자료 구조이다. BFS에서는 처리 대기 중인 노드를 큐로 관리한다.

```java
Queue<Integer> queue = new LinkedList<>();  // 빈 큐를 생성한다
queue.offer(0);   // 큐의 끝에 요소 0을 추가한다
queue.poll();      // 큐의 앞에서 요소를 꺼내어 반환한다 → 0
queue.isEmpty();   // 큐가 비어 있는지를 boolean으로 반환한다 → true
```

## 계산량

| | 값 |
|---|---|
| Time | O(V + E) — 모든 노드(코스)와 모든 간선(선행 조건)을 각각 1회씩 처리한다 |
| Space | O(V + E) — 인접 리스트에 모든 간선을, 진입 차수 배열과 큐와 결과 배열에 모든 노드를 저장한다 |

## 코드

```java
// 입력: 정수 numCourses(코스의 총 수)와 이차원 정수 배열 prerequisites(선행 조건 쌍의 배열)
// 출력: 모든 코스의 유효한 수강 순서를 담은 int[]를 반환한다. 유효한 순서가 존재하지 않으면 빈 int[]를 반환한다
public int[] findOrder(int numCourses, int[][] prerequisites) {
    // 인접 리스트를 생성하고, 각 코스에 빈 리스트를 할당한다
    // 각 인덱스가 코스 번호에 대응하며, 해당 코스 수강 후에 수강 가능해지는 코스의 리스트를 보관한다
    List<List<Integer>> graph = new ArrayList<>();
    // 진입 차수 배열: 각 코스의 미수강 선행 조건의 수를 나타낸다
    int[] indegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++)
        graph.add(new ArrayList<>());

    // 선행 조건으로부터 간선을 생성하고, 진입 차수를 계산한다
    // 각 쌍 [a, b]에 대해 간선 b → a를 생성하여, 코스 a가 코스 b에 의존하고 있음을 기록한다
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);  // 간선 pre[1] → pre[0]을 추가한다
        indegree[pre[0]]++;  // 코스 pre[0]의 진입 차수를 1 증가시킨다
    }

    // 진입 차수가 0인 코스(선행 조건 없음)를 큐에 추가한다
    // 이들은 가장 먼저 수강할 수 있는 코스이다
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    // 결과 배열과 기록 위치를 초기화한다
    int[] result = new int[numCourses];
    int idx = 0;

    while (!queue.isEmpty()) {
        // 큐에서 코스를 꺼내어 수강 순서에 확정한다
        int course = queue.poll();
        result[idx++] = course;

        // course의 모든 인접 노드 next의 진입 차수를 1 감소시킨다
        // 이것은 next의 선행 조건 중 하나인 course가 수강 완료되었음을 반영한다
        for (int next : graph.get(course))
            // 감소 결과 0이 된 경우, next의 모든 선행 조건이 완료되었으므로 큐에 추가한다
            if (--indegree[next] == 0)
                queue.offer(next);
    }

    // 모든 코스를 처리할 수 있었는지 판정한다
    // idx가 numCourses에 미치지 못하면 순환 의존이 존재하므로 빈 배열을 반환한다
    return idx == numCourses ? result : new int[0];
}
```
