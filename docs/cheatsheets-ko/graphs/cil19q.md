# 모든 코스를 완료할 수 있는지 판정하기 — Determining if All Courses Can Be Completed

## 문제의 본질

`0`부터 `n-1`까지 라벨이 붙은 `numCourses`개의 코스와 선수 조건 쌍의 리스트 `prerequisites`가 주어진다. 각 쌍 `[a, b]`는 "코스 `b`를 먼저 이수하지 않으면 코스 `a`를 이수할 수 없다"는 것을 의미한다. 모든 코스를 이수할 수 있는지를 `boolean`으로 반환한다. 이것은 유향 그래프에 사이클(순환 의존)이 존재하는지를 검출하는 문제이다.

## 핵심 아이디어

코스의 의존 관계를 유향 그래프로 파악하면, 모든 코스를 이수할 수 있는지는 "그래프에 사이클이 없는가"와 동의어이다. 진입 차수(해당 노드로 들어오는 간선의 수)가 0인 노드부터 순서대로 처리하는 위상 정렬을 수행하여, 모든 노드를 처리할 수 있으면 사이클은 존재하지 않는다.

## 사고 프로세스

1. **문제를 그래프로 변환한다**: 각 코스를 노드로, 각 선수 조건 `[a, b]`를 "`b` → `a`"의 유향 간선으로 하여 인접 리스트를 구축한다. 이렇게 하면 의존 관계를 그래프 구조로 표현할 수 있다
2. **사이클이 있으면 전체 이수가 불가능하다**: 코스 A가 B에 의존하고, B가 A에 의존하는 순환이 있으면, 어느 쪽도 먼저 이수할 수 없다. 따라서 문제는 "유향 그래프에 사이클이 있는가"의 판정으로 귀결된다
3. **진입 차수에 주목한다**: 각 노드의 진입 차수(선수 조건의 수)를 센다. 진입 차수가 0인 노드는 선수 조건이 없으므로 바로 이수할 수 있다. 이들을 시작점으로 삼으면 된다
4. **진입 차수가 0인 노드를 큐에 넣고 처리를 시작한다**: BFS처럼 큐를 사용하여 진입 차수가 0인 노드를 순서대로 처리한다. 처리 완료된 노드에서 나가는 간선의 도착 노드의 진입 차수를 1 줄이고, 진입 차수가 0이 된 노드를 새로 큐에 추가한다
5. **처리 완료 노드 수로 판정한다**: 모든 노드를 처리할 수 있으면(처리 완료 카운트 == `numCourses`) 사이클은 존재하지 않으며, 전체 코스 이수가 가능하다. 사이클 내의 노드는 진입 차수가 영원히 0이 되지 않으므로 처리되지 않고 남는다

## 사전 지식

### 인접 리스트(Adjacency List)란

그래프를 표현하는 데이터 구조이다. 각 노드에 대해, 해당 노드에서 간선이 나가는 도착 노드의 리스트를 보유한다. `List<List<Integer>>`로 구현하며, `graph.get(i)`로 노드 `i`의 인접 노드 목록을 가져올 수 있다.

```java
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++)
    graph.add(new ArrayList<>());  // 각 노드에 빈 리스트를 생성
graph.get(0).add(1);               // 노드 0에서 노드 1로의 간선을 추가
graph.get(0);                       // 노드 0의 인접 노드 목록 → [1]
```

### 진입 차수(In-degree)란

유향 그래프에서 특정 노드로 들어오는 간선의 수이다. 진입 차수가 0인 노드는 어떤 노드에도 의존하지 않는다. 배열 `inDegree[i]`로 노드 `i`의 진입 차수를 관리한다.

```java
int[] inDegree = new int[n];   // 모든 노드의 진입 차수를 0으로 초기화
inDegree[0]++;                  // 노드 0의 진입 차수를 1 증가
```

### Queue(큐)란

선입선출(FIFO) 데이터 구조이다. BFS에서 처리 대기 중인 노드를 관리하기 위해 사용한다. `offer`로 끝에 추가하고, `poll`로 앞에서 꺼낸다.

```java
Queue<Integer> queue = new LinkedList<>();
queue.offer(0);       // 큐에 0을 추가한다
queue.poll();          // 큐의 맨 앞을 꺼내서 반환한다 → 0
queue.isEmpty();       // 큐가 비어 있는지를 boolean으로 반환한다 → true
```

## 계산량

| | 값 |
|---|---|
| Time | O(V + E) — 모든 노드(V개)와 모든 간선(E개)을 각각 1회씩 처리한다 |
| Space | O(V + E) — 인접 리스트에 모든 간선을, 진입 차수 배열과 큐에 모든 노드를 저장한다 |

## 코드

```java
// 입력: 코스 수 numCourses와 선수 조건 배열 prerequisites (각 요소는 [a, b]로 "b → a"의 의존을 나타낸다)
// 출력: 모든 코스를 이수할 수 있으면 true, 사이클이 있어 이수 불가능하면 false
boolean canFinish(int numCourses, int[][] prerequisites) {
    // 각 노드의 진입 차수(선수 조건의 수)를 저장하는 배열. 진입 차수는 "해당 코스의 선수 조건이 몇 개인지"를 나타낸다
    int[] inDegree = new int[numCourses];

    // 인접 리스트로 그래프를 구축한다. graph.get(i)는 노드 i에서 간선이 나가는 도착 노드의 리스트이다
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < numCourses; i++)
        graph.add(new ArrayList<>());

    // 각 선수 조건으로부터 간선을 추가하고 진입 차수를 갱신한다. 이를 통해 의존 관계 그래프와 각 노드의 진입 차수가 완성된다
    for (int[] p : prerequisites) {
        graph.get(p[1]).add(p[0]);  // p[1] → p[0]의 간선을 추가
        inDegree[p[0]]++;           // p[0]의 진입 차수를 1 증가
    }

    // 진입 차수가 0인 노드(선수 조건 없음)를 큐에 추가한다. 이들이 가장 먼저 이수할 수 있는 코스이다
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (inDegree[i] == 0)
            queue.offer(i);

    // BFS로 진입 차수가 0인 노드부터 순서대로 처리한다
    int count = 0;  // 처리 완료 코스 수를 추적하는 변수
    while (!queue.isEmpty()) {
        int course = queue.poll();
        count++;  // 이 노드는 이수 완료로 처리한다

        // 인접 노드의 진입 차수를 1 줄인다(선수 조건을 하나 소화했다는 의미). 0이 되면 모든 선수 조건이 충족되었으므로 큐에 추가한다
        for (int nei : graph.get(course))
            if (--inDegree[nei] == 0)
                queue.offer(nei);
    }

    // 모든 노드를 처리할 수 있으면 사이클 없음(전체 코스 이수 가능). 사이클 내의 노드는 진입 차수가 0이 되지 않아 처리되지 않고 남는다
    return count == numCourses;
}
```
