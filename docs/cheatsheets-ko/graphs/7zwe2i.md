# Capturing Surrounded Regions on a Board — 보드 위의 둘러싸인 영역을 캡처하기

## 문제의 본질

`'X'`와 `'O'`로 구성된 m×n 보드가 주어진다. `'X'`에 **완전히 둘러싸인** `'O'` 영역을 모두 `'X'`로 반전한다. 단, 보드의 **경계(보더)**에 접해 있는 `'O'` 및 거기서 연결된 `'O'`는 둘러싸이지 않았으므로 반전해서는 안 된다.

## 핵심 아이디어

"둘러싸인 O를 찾는" 것이 아니라, "둘러싸이지 않은 O(＝경계에서 도달 가능한 O)를 먼저 마킹하고, 남은 O가 모두 둘러싸여 있다"라는 역발상으로 접근한다. 경계의 O에서 DFS로 연결된 셀을 안전 마킹하고, 마지막에 보드를 일괄 스캔하면 판정과 반전을 분리할 수 있다.

## 사고 과정

1. **둘러싸이지 않은 O의 특징을 생각한다**: `'O'`가 캡처되지 않는 조건은, 해당 `'O'`가 보드의 경계에 있거나, 경계의 `'O'`와 상하좌우 연결로 이어져 있는 것이다. 역으로 말하면, 경계의 `'O'`에서 도달할 수 없는 `'O'`는 모두 둘러싸여 있다
2. **경계에서 탐색을 시작한다**: 보드의 4변(상변·하변·좌변·우변)을 순회하며, `'O'`가 발견될 때마다 그곳을 기점으로 DFS를 실행한다. DFS로 도달할 수 있는 모든 `'O'`는 "안전(캡처 불가)"이다
3. **안전한 셀을 마커로 구분한다**: DFS에서 방문한 `'O'`를 임시 마커 `'S'`(Safe)로 덮어쓴다. 이렇게 하면 DFS 종료 후 보드 위의 `'O'`는 "아직 마킹되지 않은＝둘러싸인" 셀만 남게 된다
4. **보드를 일괄 스캔하여 반전과 복원을 수행한다**: 모든 셀을 순회하며, `'O'`인 채로 남아 있는 셀은 둘러싸여 있으므로 `'X'`로 반전한다. `'S'`인 셀은 안전한 `'O'`이므로 원래의 `'O'`로 복원한다. `'X'`인 셀은 그대로 둔다
5. **DFS의 재귀 구조**: 각 셀에서 상하좌우 4방향으로 재귀적으로 탐색한다. 범위 밖 체크와 `'O'` 이외의 셀에서의 중단이 방문 여부 판정도 겸한다(`'S'`로 덮어쓴 셀은 `'O'`가 아니므로 재방문하지 않는다)

## 전제 지식

### DFS(깊이 우선 탐색)란

그래프나 그리드를 탐색하는 알고리즘이다. 특정 지점에서 출발하여, 갈 수 있는 곳까지 한 방향으로 깊이 진행하고, 막다른 곳에 도달하면 되돌아가서 다른 방향을 시도한다. 재귀 호출로 자연스럽게 구현할 수 있다. 그리드에서는 상하좌우 4방향을 재귀적으로 방문한다.

```java
// 그리드 위의 DFS 기본 패턴
void dfs(char[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length          // 범위 밖 체크
        || c < 0 || c >= grid[0].length
        || grid[r][c] != 'O')              // 대상 외 셀에서 중단
        return;
    grid[r][c] = 'S';                      // 방문 완료 마크(재방문 방지를 겸함)
    dfs(grid, r + 1, c);                   // 아래
    dfs(grid, r - 1, c);                   // 위
    dfs(grid, r, c + 1);                   // 오른쪽
    dfs(grid, r, c - 1);                   // 왼쪽
}
```

### 경계(보더) 셀의 순회 방법

m×n 보드에서 4변의 셀을 열거하려면 다음과 같이 한다. 상변과 하변은 열을, 좌변과 우변은 행을 루프한다.

```java
int m = board.length;    // 행 수
int n = board[0].length; // 열 수

// 상변(행 0)과 하변(행 m-1)의 모든 열을 순회
for (int j = 0; j < n; j++) {
    process(board[0][j]);      // 상변
    process(board[m - 1][j]);  // 하변
}
// 좌변(열 0)과 우변(열 n-1)의 모든 행을 순회
for (int i = 0; i < m; i++) {
    process(board[i][0]);      // 좌변
    process(board[i][n - 1]);  // 우변
}
```

### 마커 기법이란

보드의 셀을 임시로 다른 문자(여기서는 `'S'`)로 덮어쓰는 것으로 "방문 완료"와 "미방문"을 구분하는 기법이다. 별도의 `boolean[][]` 방문 배열을 준비하는 대신, 보드 자체를 상태 관리에 사용한다. 처리의 마지막에 마커를 원래 값으로 복원한다.

## 계산량

| | 값 |
|---|---|
| Time | O(m × n) — 경계에서의 DFS가 각 셀을 최대 1회 방문하고, 최종 스캔도 모든 셀을 1회 순회한다 |
| Space | O(m × n) — DFS의 재귀 호출 스택이 최악의 경우 모든 셀 수만큼의 깊이에 도달한다 |

## 코드

```java
// 입력: 'X'와 'O'로 구성된 m×n의 2차원 문자 배열 board
// 출력: board를 그 자리에서(in-place) 변경한다. 둘러싸인 'O'를 'X'로 반전하며, 반환값은 없다(void)

// 경계에서 도달 가능한 O를 마커 S로 덮어쓰는 DFS
void dfs(char[][] board, int r, int c, int m, int n) {
    // 범위 밖이거나 O가 아닌 셀이면 아무것도 하지 않는다(방문 완료 S도 걸러진다)
    // 'S'로 덮어쓴 셀은 'O'가 아니므로 재방문되지 않는다
    if (r < 0 || r >= m
        || c < 0 || c >= n
        || board[r][c] != 'O')
        return;

    // 안전 마커 S로 덮어쓴다(방문 완료를 겸한다)
    // 별도의 boolean[][]을 준비하지 않고, 보드 자체를 상태 관리에 사용한다
    board[r][c] = 'S';

    // 상하좌우 4방향으로 재귀 탐색한다
    dfs(board, r + 1, c, m, n);
    dfs(board, r - 1, c, m, n);
    dfs(board, r, c + 1, m, n);
    dfs(board, r, c - 1, m, n);
}

public void solve(char[][] board) {
    // 행 수와 열 수를 가져온다. 이후의 범위 체크와 경계 순회에 사용한다
    int m = board.length;     // 행 수
    int n = board[0].length;  // 열 수

    // 상변과 하변의 각 열에서 경계 DFS를 시작한다
    // dfs는 대상 셀이 'O'인 경우에만 처리를 수행하므로, 'X'인 셀에서는 아무것도 하지 않고 반환한다
    for (int j = 0; j < n; j++) {
        dfs(board, 0, j, m, n);       // 상변
        dfs(board, m - 1, j, m, n);   // 하변
    }

    // 좌변과 우변의 각 행에서 경계 DFS를 시작한다
    // 위의 루프와 합쳐서, 보드의 4변 전체를 기점으로 커버한다
    for (int i = 0; i < m; i++) {
        dfs(board, i, 0, m, n);       // 좌변
        dfs(board, i, n - 1, m, n);   // 우변
    }

    // 보드를 일괄 스캔하여 반전과 복원을 수행한다
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (board[i][j] == 'O')
                board[i][j] = 'X';        // 경계에서 도달할 수 없었던＝둘러싸인 O를 X로 반전한다
            else if (board[i][j] == 'S')
                board[i][j] = 'O';        // 경계에서 도달할 수 있었던＝안전 마커를 원래의 O로 복원한다
            // 'X'인 셀은 변경하지 않는다
        }
    }
}
```
