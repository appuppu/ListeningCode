# Finding the Redundant Edge in a Graph — 트리에 간선 하나를 추가한 그래프에서 여분의 간선을 찾기

## 문제의 본질

n개의 노드와 n-1개의 간선으로 이루어진 트리에 간선 하나가 추가되어 정확히 하나의 폐로(사이클)가 생긴 그래프가 주어진다. 추가된 여분의 간선을 찾아서 반환한다. 해당 간선을 제거하면 그래프가 다시 유효한 트리로 돌아간다.

## 핵심 아이디어

간선을 하나씩 처리해 나갈 때, "이미 같은 연결 성분에 속해 있는 두 노드"를 연결하는 간선이 나타나면, 그 간선이 바로 사이클을 만들어내는 여분의 간선이다. 이 판정에는 Union-Find가 최적이다.

## 사고 과정

1. **트리의 성질을 활용한다**: 트리는 n개의 노드를 n-1개의 간선으로 연결하는 구조이며, 사이클은 존재하지 않는다. 여기에 간선 하나를 추가하면 정확히 하나의 사이클이 생긴다. 즉, 간선을 순서대로 추가해 나가는 과정에서 "사이클을 만드는 간선"을 검출하면 된다
2. **사이클의 검출 조건을 생각한다**: 간선(u, v)을 추가할 때, u와 v가 이미 같은 연결 성분에 속해 있으면 해당 간선은 사이클을 형성한다. 반대로, u와 v가 다른 연결 성분에 속해 있으면 해당 간선은 두 성분을 통합할 뿐 사이클은 생기지 않는다
3. **연결 성분의 관리에는 Union-Find가 적합하다**: "두 노드가 같은 연결 성분에 속하는지"의 판정과 "두 연결 성분을 통합하는" 연산을 고속으로 수행하는 자료구조가 Union-Find이다. find 연산으로 루트를 비교하면 동일 성분인지를 판정할 수 있고, union 연산으로 성분을 통합할 수 있다
4. **Union-Find의 효율화**: 경로 압축(path compression)에 의해 find 연산을 수행할 때마다 노드를 루트에 직접 연결한다. 랭크(rank)에 의한 통합으로 트리의 높이를 억제한다. 이 두 가지 최적화에 의해 각 연산의 계산량은 α(n)(역 아커만 함수, 실질적으로 상수)이 된다
5. **간선을 순서대로 처리한다**: 주어진 간선 배열을 처음부터 순서대로 처리하며, 각 간선에 대해 union 연산을 시도한다. union이 실패한(= 이미 같은 성분에 속해 있었던) 간선이 여분의 간선이며, 그것을 반환한다
6. **최종적으로 반환하는 것**: union 연산이 실패한 간선을 `int[]`로 반환한다. 문제의 제약상 반드시 여분의 간선이 하나 존재하므로, 답을 찾지 못하는 경우는 없다

## 사전 지식

### Union-Find(서로소 집합 자료구조)란

여러 요소를 그룹(연결 성분)으로 나누어, "두 요소가 같은 그룹에 속하는지"의 판정과 "두 그룹을 통합하는" 연산을 고속으로 수행하는 자료구조이다. `parent` 배열로 그룹의 트리 구조를 표현하며, 각 요소의 루트(대표 원소)가 같으면 동일 그룹으로 판정한다.

```java
int[] parent = new int[n + 1];  // parent[i]는 노드 i의 부모를 저장한다
int[] rank = new int[n + 1];    // rank[i]는 노드 i를 루트로 하는 트리 높이의 상한이다
for (int i = 1; i <= n; i++)
    parent[i] = i;              // 초기 상태에서는 각 노드가 자기 자신을 부모로 한다(모두 독립된 그룹)
```

### find 연산(경로 압축 포함)

노드 x가 속하는 그룹의 루트(대표 원소)를 반환한다. 재귀적으로 부모를 따라가며, 경로상의 모든 노드를 루트에 직접 연결한다(경로 압축). 이를 통해 이후의 find가 고속화된다.

```java
int find(int[] parent, int x) {
    if (parent[x] != x)                    // x가 루트가 아니면
        parent[x] = find(parent, parent[x]); // 부모를 재귀적으로 따라가 루트에 직접 연결한다
    return parent[x];                       // x의 루트를 반환한다
}
```

### union 연산(랭크에 의한 통합)

두 노드가 속하는 그룹을 통합한다. 랭크(트리 높이의 상한)가 작은 쪽을 큰 쪽 아래에 연결함으로써 트리 높이의 증가를 억제한다. 두 노드가 이미 같은 그룹에 속하는 경우에는 통합하지 않고 `false`를 반환한다.

```java
boolean union(int[] parent, int[] rank, int x, int y) {
    int rx = find(parent, x);  // x의 루트를 구한다
    int ry = find(parent, y);  // y의 루트를 구한다
    if (rx == ry) return false; // 같은 그룹이면 통합 불필요 → false를 반환한다
    // 랭크가 작은 쪽을 큰 쪽 아래에 연결한다
    if (rank[rx] < rank[ry]) parent[rx] = ry;
    else if (rank[rx] > rank[ry]) parent[ry] = rx;
    else { parent[ry] = rx; rank[rx]++; }  // 랭크가 같으면 한쪽을 다른 쪽 아래에 연결하고, 랭크를 1 증가시킨다
    return true;  // 통합 성공 → true를 반환한다
}
```

### 역 아커만 함수 α(n)란

Union-Find의 연산 1회당 계산량을 나타내는 함수이다. α(n)은 매우 느리게 증가하며, 현실적인 입력 크기(n < 2^65536)에서는 α(n) ≤ 4가 되므로 실질적으로 상수로 간주할 수 있다.

## 계산량

| | 값 |
|---|---|
| Time | O(n × α(n)) ≈ O(n) — n개의 간선 각각에 대해 find와 union을 1회씩 수행한다. α(n)은 실질적으로 상수이므로 O(n)으로 간주할 수 있다 |
| Space | O(n) — parent 배열과 rank 배열에 각각 n+1개의 요소를 저장한다 |

## 코드

```java
// 입력: 간선 배열 edges(각 요소는 int[]{u, v}이며, 노드 u와 노드 v를 연결하는 간선을 나타낸다)
// 출력: 사이클을 형성하는 여분의 간선을 int[]로 반환한다

// 노드 x가 속하는 그룹의 루트를 반환한다(경로 압축 포함)
int find(int[] parent, int x) {
    if (parent[x] != x)
        // 부모를 재귀적으로 따라가 루트에 직접 연결한다(경로 압축)
        parent[x] = find(parent,
            parent[x]);
    return parent[x];
}

// 두 노드가 속하는 그룹을 통합한다. 이미 같은 그룹이면 false를 반환한다
boolean union(int[] parent,
        int[] rank, int x, int y) {
    int rx = find(parent, x); // x의 루트를 구한다
    int ry = find(parent, y); // y의 루트를 구한다
    if (rx == ry) return false; // 이미 같은 연결 성분 → 사이클이 생기므로 false를 반환한다
    // 랭크가 작은 쪽을 큰 쪽 아래에 연결하여 트리 높이의 증가를 억제한다
    if (rank[rx] < rank[ry])
        parent[rx] = ry;
    else if (rank[rx] > rank[ry])
        parent[ry] = rx;
    else {
        // 랭크가 같으면 한쪽을 다른 쪽 아래에 연결하고, 랭크를 1 증가시킨다
        parent[ry] = rx;
        rank[rx]++;
    }
    return true; // 통합 성공 → 사이클은 생기지 않았다
}

public int[] findRedundantConnection(
        int[][] edges) {
    // 간선의 수 = 노드의 수(트리의 n-1개 + 여분의 1개 = n개). 노드 번호는 1부터 n까지이다
    int n = edges.length;
    // 각 노드를 독립된 그룹으로 초기화한다(parent[i] = i로 자기 자신이 루트)
    int[] parent = new int[n + 1];
    int[] rank = new int[n + 1]; // rank 배열은 기본값 0 그대로 사용한다
    for (int i = 1; i <= n; i++)
        parent[i] = i;

    // 간선을 처음부터 순서대로 하나씩 처리하며 사이클을 형성하는 간선을 검출한다
    for (int[] e : edges) {
        // union이 false를 반환한 경우, e[0]과 e[1]은 이미 같은 연결 성분에 속해 있다
        // → 이 간선이 사이클을 형성하는 여분의 간선이므로 그대로 반환한다
        if (!union(parent, rank,
                e[0], e[1]))
            return e;
    }
    // 문제의 제약상 반드시 여분의 간선이 하나 존재하므로 이 지점에는 도달하지 않는다
    return new int[0];
}
```
