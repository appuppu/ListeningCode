# Simulating Rotting Oranges Spreading — 썩은 오렌지의 확산이 완료되기까지의 최소 시간을 구한다

## 문제의 본질

m×n 그리드가 주어지며, 각 셀은 0(빈 칸), 1(신선한 오렌지), 2(썩은 오렌지) 중 하나이다. 매분마다 썩은 오렌지는 상하좌우로 인접한 신선한 오렌지를 썩게 만든다. 모든 신선한 오렌지가 썩을 때까지의 **최소 분 수**를 반환한다. 모든 오렌지를 썩게 만드는 것이 불가능한 경우에는 -1을 반환한다.

## 핵심 아이디어

썩은 오렌지는 "동시에" 인접 셀로 확산된다. 이것은 여러 시작점에서 동시에 BFS를 시작하는 "Multi-Source BFS" 그 자체이며, BFS의 각 레벨(계층)이 1분에 대응한다.

## 사고 프로세스

1. **확산은 동시에 일어난다**: 썩은 오렌지가 여러 개일 때, 각각이 동시에 인접 셀을 썩게 만든다. 하나의 시작점에서 탐색하는 것이 아니라, 모든 썩은 오렌지를 동시에 출발점으로 설정해야 한다
2. **동시 출발에는 Multi-Source BFS를 사용한다**: 처음에 모든 썩은 오렌지를 큐에 넣어 두면, BFS의 1레벨(큐의 현재 크기만큼 처리하는 1라운드)이 1분간의 확산에 대응한다. DFS로는 "최소 시간"을 보장할 수 없으므로 BFS가 적합하다
3. **신선한 오렌지의 수를 추적한다**: 확산이 종료된 후에 신선한 오렌지가 남아 있으면 불가능한 케이스이다. 따라서 초기 상태에서 신선한 오렌지의 수를 세어 두고, 썩게 만들 때마다 감소시킨다
4. **경과 시간의 측정 방법**: BFS의 레벨마다 큐의 모든 요소를 처리하고, 1레벨이 완료될 때마다 경과 시간을 1분 가산한다. 신선한 오렌지가 0이 된 시점의 레벨 수가 답이다
5. **종료 조건과 불가능 판정**: BFS가 종료된 후에 `fresh > 0`이면 도달 불가능한 신선한 오렌지가 존재하므로 -1을 반환한다. `fresh == 0`이면 경과 시간을 반환한다

## 전제 지식

### BFS(너비 우선 탐색)란

그래프나 그리드를 "시작점으로부터의 거리가 가까운 순서"로 탐색하는 알고리즘이다. 큐(FIFO)를 사용하여 현재 레벨의 모든 노드를 처리한 후에 다음 레벨로 진행한다. 최단 거리·최소 시간을 구하는 문제에 적합하다.

### Multi-Source BFS란

일반적인 BFS는 시작점이 1개이지만, Multi-Source BFS는 여러 시작점을 큐에 넣은 상태에서 BFS를 시작한다. 모든 시작점에서 동시에 확산하는 시뮬레이션에 사용한다. 큐의 초기 상태가 여러 요소가 되는 것 외에는 일반적인 BFS와 동일하다.

### Queue(큐)란

선입선출(FIFO) 데이터 구조이다. BFS에서는 탐색 대상 노드를 순서대로 처리하기 위해 사용한다.

```java
Queue<int[]> queue = new LinkedList<>();  // int 배열을 요소로 하는 큐를 생성한다
queue.offer(new int[]{0, 1});  // 큐의 끝에 요소를 추가한다
int[] pos = queue.poll();       // 큐의 앞에서 요소를 꺼내고 삭제한다 → {0, 1}
queue.size();                   // 큐 내의 요소 수를 반환한다
queue.isEmpty();                // 큐가 비어 있는지를 boolean으로 반환한다
```

### 방향 배열이란

그리드 탐색에서 상하좌우의 인접 셀을 열거하기 위한 기법이다. 행과 열의 변위를 배열로 정의하고, 루프로 순회한다.

```java
int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};  // 오른쪽, 왼쪽, 아래, 위의 4방향
for (int[] d : dirs) {
    int nr = row + d[0];  // 인접 셀의 행 인덱스
    int nc = col + d[1];  // 인접 셀의 열 인덱스
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(m × n) — 그리드의 모든 셀을 초기 순회에서 1회, BFS에서 최대 1회씩 처리한다 |
| Space | O(m × n) — 큐에 최대 m×n개의 셀이 저장된다 |

## 코드

```java
// 입력: m×n의 정수 그리드 grid (각 셀은 0=빈 칸, 1=신선한 오렌지, 2=썩은 오렌지)
// 출력: 모든 신선한 오렌지가 썩을 때까지의 최소 분 수를 int로 반환한다. 불가능한 경우에는 -1을 반환한다
public int orangesRotting(int[][] grid) {
    int rows = grid.length;
    int cols = grid[0].length;
    // BFS용 큐. 탐색 대상이 되는 셀의 좌표를 보관한다
    Queue<int[]> queue = new LinkedList<>();
    // 남아 있는 신선한 오렌지의 수를 추적하는 변수
    int fresh = 0;

    // 그리드 전체를 순회하여, BFS의 여러 시작점과 목표까지의 잔여 수를 동시에 준비한다
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (grid[i][j] == 2) {
                // 썩은 오렌지를 큐에 추가한다 (Multi-Source BFS의 시작점)
                queue.offer(new int[]{i, j});
            } else if (grid[i][j] == 1) {
                // 신선한 오렌지의 수를 카운트한다
                fresh++;
            }
        }
    }

    // 상하좌우 4방향을 나타내는 방향 배열. 인접 셀 열거에 사용한다
    int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
    int minutes = 0;

    // 큐가 비어 있지 않을 뿐만 아니라 신선한 오렌지가 남아 있는 것도 조건에 포함하여, 모두 썩은 후의 불필요한 루프를 방지한다
    while (!queue.isEmpty() && fresh > 0) {
        // 이 레벨(1분간)에서 처리할 셀 수를 먼저 저장한다. 루프 중에 추가되는 다음 레벨의 요소와 구별하기 위함이다
        int size = queue.size();
        // 1레벨분의 처리를 시작하므로 경과 시간을 1분 가산한다
        minutes++;

        // size번만큼 큐에서 요소를 꺼내어, 이 레벨의 모든 셀을 처리한다
        for (int k = 0; k < size; k++) {
            int[] pos = queue.poll();

            // 방향 배열을 사용하여 상하좌우 4개의 인접 셀을 확인한다
            for (int[] d : dirs) {
                int nr = pos[0] + d[0];
                int nc = pos[1] + d[1];

                // 범위 내이면서 신선한 오렌지이면 썩게 만든다
                if (nr >= 0 && nr < rows
                    && nc >= 0 && nc < cols
                    && grid[nr][nc] == 1) {
                    // 셀을 2로 갱신하여 방문 완료로 표시한다 (visited 배열을 대신한다. 동일한 셀의 중복 처리를 방지한다)
                    grid[nr][nc] = 2;
                    fresh--;
                    queue.offer(new int[]{nr, nc});
                }
            }
        }
    }

    // 신선한 오렌지가 남아 있으면 도달 불가능하므로 -1을 반환한다. 그렇지 않으면 경과 시간을 반환한다
    return fresh > 0 ? -1 : minutes;
}
```
