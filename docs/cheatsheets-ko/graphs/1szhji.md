# Deep Copying a Graph — 연결 무향 그래프의 모든 노드를 깊은 복사로 복제하기

## 문제의 본질

연결 무향 그래프의 한 노드에 대한 참조가 주어진다. 그래프 전체의 **딥 카피(클론)**를 생성하고, 클론된 그래프의 대응하는 노드를 반환한다. 각 노드는 정수값 `val`과 인접 노드의 리스트 `neighbors`를 가진다. 원본 그래프의 노드를 일절 참조하지 않는, 완전히 독립된 새로운 그래프를 구축해야 한다.

## 핵심 아이디어

그래프에는 사이클이 있으므로, 같은 노드를 두 번 클론하지 않도록 HashMap으로 「원본 노드 → 클론 노드」의 대응을 기록한다. 미방문이면 클론을 생성하여 HashMap에 등록하고, 방문 완료이면 HashMap에서 클론을 반환함으로써, 무한 루프를 방지하면서 모든 노드를 정확하게 복제할 수 있다.

## 사고 프로세스

1. **그래프 순회가 필요하다**: 그래프 전체를 복사하려면, 시작 노드에서 도달 가능한 모든 노드를 방문해야 한다. 순회에는 DFS(깊이 우선 탐색)를 재귀로 수행하는 것이 자연스럽다
2. **사이클에 대한 대처가 필수이다**: 무향 그래프에서는 A→B→A와 같은 사이클이 반드시 존재한다. 방문 완료된 노드를 다시 클론하려고 하면 무한 루프에 빠지므로, 「이 노드가 이미 클론 완료인지」를 판정하는 구조가 필요하다
3. **HashMap으로 원본 노드와 클론의 대응을 관리한다**: `HashMap<Node, Node>`를 준비하고, 키에 「원본 노드」, 밸류에 「그 클론」을 저장한다. 이렇게 하면, 어떤 노드가 이미 클론 완료인지를 O(1)로 판정할 수 있고, 클론 완료라면 그 클론을 O(1)로 취득할 수 있다
4. **재귀의 각 단계에서 수행할 작업**: 현재 노드가 HashMap에 존재하면 그 클론을 반환한다(방문 완료). 존재하지 않으면, 새로운 Node를 생성하여 HashMap에 등록하고, 원본 노드의 모든 인접 노드에 대해 재귀적으로 클론을 호출하여, 반환된 클론을 자신의 neighbors에 추가한다
5. **등록은 재귀 전에 수행한다**: HashMap에의 등록을 인접 노드의 재귀 호출보다 **먼저** 수행한다. 먼저 등록하지 않으면, 사이클로 자기 자신에게 돌아왔을 때 HashMap에서 클론을 찾을 수 없어 무한 루프가 발생한다
6. **최종적으로 반환하는 것**: 시작 노드의 클론을 반환한다. 이 클론으로부터 모든 클론 노드가 인접 리스트로 연결되어 있다

## 전제 지식

### Node 클래스란

그래프의 각 정점을 나타내는 클래스이다. 정수값 `val`과 인접 노드의 리스트 `neighbors`를 가진다.

```java
class Node {
    public int val;
    public List<Node> neighbors;

    public Node(int val) {        // val을 지정하여 노드를 생성한다
        this.val = val;
        this.neighbors = new ArrayList<>();  // 인접 리스트는 빈 상태로 초기화된다
    }
}
```

### HashMap이란

키와 값의 쌍을 저장하는 데이터 구조이다. 키를 지정하여 값의 검색·취득을 O(1)로 수행할 수 있다. 이 문제에서는 키에 「원본 노드」, 밸류에 「그 클론 노드」를 저장하여, 방문 완료 판정과 클론 취득을 겸한다.

```java
HashMap<Node, Node> map = new HashMap<>();  // 빈 HashMap을 생성한다
map.put(original, clone);     // 원본 노드를 키, 클론을 밸류로 저장한다
map.containsKey(original);    // 원본 노드가 등록 완료인지를 boolean으로 반환한다 → true
map.get(original);            // 원본 노드에 대응하는 클론을 반환한다 → clone
```

### DFS(깊이 우선 탐색)란

그래프 순회 알고리즘 중 하나이다. 한 방향으로 가능한 한 깊이 진행하고, 막다른 곳에 도달하면 되돌아와서 다른 방향으로 진행한다. 재귀 호출로 자연스럽게 구현할 수 있다. 방문 완료 관리를 수행하지 않으면 사이클에서 무한 루프가 발생한다.

## 계산량

| | 값 |
|---|---|
| Time | O(V + E) — 각 노드를 1회씩 방문하고(V), 각 간선을 1회씩 처리한다(E) |
| Space | O(V) — HashMap에 V개의 노드 대응을 저장하고, 재귀 스택도 최대 V단이 된다 |

## 코드

```java
// 입력: 연결 무향 그래프의 한 노드 node(Node 타입). 그래프가 비어 있는 경우는 null
// 출력: 그래프 전체의 딥 카피에서 입력 노드에 대응하는 클론 노드(Node 타입)를 반환한다

// 키=원본 노드, 밸류=클론 노드를 저장하는 HashMap
// 모든 재귀 호출에서 공유하기 위해 클래스의 필드에 배치한다
Map<Node, Node> map = new HashMap<>();

public Node cloneGraph(Node node) {
    // 그래프가 비어 있으면(null) null을 반환하고 종료한다
    if (node == null) return null;

    // 현재 노드가 이미 클론 완료이면 그 클론을 반환한다
    // 이것이 사이클에 의한 무한 루프를 방지하는 구조이다
    if (map.containsKey(node))
        return map.get(node);

    // 현재 노드의 클론을 생성한다(이 시점에서는 neighbors는 비어 있다)
    Node clone = new Node(node.val);

    // 주의: 등록은 다음 for 루프의 재귀 호출보다 먼저 수행한다
    // 먼저 등록하지 않으면, 사이클로 자기 자신에게 돌아왔을 때 containsKey로 검출할 수 없어 무한 루프가 발생한다
    map.put(node, clone);

    // 원본 노드의 모든 인접 노드를 재귀적으로 클론하고, 클론의 인접 리스트에 추가한다
    // 이를 통해 원본 그래프와 동일한 인접 관계가 클론 측에도 구축된다
    for (Node nbr : node.neighbors) {
        clone.neighbors
            .add(cloneGraph(nbr));
    }

    // 최초 호출에 대해 반환되는 clone이, 클론된 그래프 전체의 시작 노드가 된다
    return clone;
}
```
