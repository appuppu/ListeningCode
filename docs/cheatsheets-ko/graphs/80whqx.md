# Finding the Largest Island by Area — 2D 그리드에서 최대 면적의 섬 찾기

## 문제의 본질

`1`(육지)과 `0`(물)으로 구성된 2D 바이너리 그리드가 주어진다. 섬이란, 상하좌우로 인접한 `1` 셀이 연결된 그룹이다. 그리드 내의 모든 섬 중에서 **최대 면적**(셀 수)을 구하여 반환한다. 섬이 존재하지 않는 경우에는 `0`을 반환한다.

## 핵심 아이디어

각 육지 셀에서 DFS로 연결된 육지를 세면 섬의 면적을 구할 수 있다. 방문한 셀을 별도의 배열로 관리하는 대신, 방문한 셀의 값을 `0`으로 덮어씀으로써, 추가 메모리 없이 중복 방문을 방지할 수 있다.

## 사고 과정

1. **섬의 면적은 연결 요소의 크기이다**: 그리드 위의 `1`이 상하좌우로 연결된 그룹이 하나의 섬을 구성한다. 섬의 면적이란, 해당 그룹에 포함된 셀의 개수이다. 따라서 각 연결 요소의 크기를 구하고, 그 최댓값을 반환하면 된다
2. **연결 요소의 탐색에는 DFS가 적합하다**: 어떤 셀 `(r, c)`가 `1`이면, 그 셀을 시작점으로 DFS를 통해 상하좌우의 인접 셀을 재귀적으로 탐색하고, 연결된 모든 `1`을 세어 올림으로써, 해당 섬의 면적을 구할 수 있다
3. **같은 셀을 여러 번 세지 않는 구조가 필요하다**: DFS로 방문한 셀을 다시 방문하면 면적을 이중으로 세게 된다. 일반적으로는 `boolean[][] visited` 배열을 준비하여 방문 여부를 기록하지만, 이 방법에는 O(m × n)의 추가 메모리가 필요하다
4. **방문한 셀을 `0`으로 덮어쓰면 추가 메모리가 불필요해진다**: DFS로 방문한 셀의 값을 `1`에서 `0`으로 변경하면, 해당 셀은 물로 취급되어, 이후의 탐색에서 재방문되지 않는다. `visited` 배열을 사용하지 않고도 중복을 방지할 수 있으며, 보조 메모리가 O(1)이 된다
5. **DFS의 반환값으로 면적을 집계한다**: DFS는 방문한 셀 자체의 `1`(카운트)에, 상하좌우 4방향의 재귀 호출 반환값을 더하여 반환한다. 기저 조건으로, 그리드 범위 밖이거나 값이 `0`인 셀은 `0`을 반환한다. 이를 통해, 한 번의 DFS 호출로 섬 전체의 면적이 재귀적으로 집계된다
6. **그리드 전체를 순회하여 최댓값을 구한다**: 이중 for 루프로 그리드의 모든 셀을 순회하며, 각 셀에 대해 DFS를 호출한다. DFS의 반환값(섬의 면적)과 현재의 최댓값을 비교하여, 더 큰 값을 유지한다. 값이 `0`인 셀에서는 DFS의 기저 조건에서 즉시 `0`이 반환되므로, 별도의 분기 처리는 불필요하다

## 사전 지식

### DFS(깊이 우선 탐색)란

그래프나 그리드의 탐색 알고리즘이다. 하나의 노드에서 출발하여, 갈 수 있는 곳까지 깊이 진행한 후 되돌아온다. 2D 그리드에서는, 특정 셀에서 상하좌우의 인접 셀로 재귀적으로 이동함으로써, 연결된 모든 셀을 방문할 수 있다.

```java
// 2D 그리드에서의 기본적인 DFS 구조
void dfs(int[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length)
        return;                    // 그리드 범위 밖이면 종료
    dfs(grid, r - 1, c);          // 위 방향으로 재귀
    dfs(grid, r + 1, c);          // 아래 방향으로 재귀
    dfs(grid, r, c - 1);          // 왼쪽 방향으로 재귀
    dfs(grid, r, c + 1);          // 오른쪽 방향으로 재귀
}
```

### In-place Modification(제자리 수정)이란

입력 데이터 자체를 변경함으로써, 추가 데이터 구조(배열이나 세트 등)를 사용하지 않고 상태를 기록하는 기법이다. 이 문제에서는, 방문한 육지 셀을 `0`으로 덮어씀으로써, `visited` 배열을 대체한다.

```java
grid[r][c] = 0;  // 방문한 육지(1)를 물(0)로 덮어쓴다
```

### Math.max란

두 값을 비교하여 더 큰 값을 반환하는 Java의 표준 메서드이다. 루프 내에서 최댓값을 계속 갱신하는 장면에서 사용한다.

```java
Math.max(3, 7);   // → 7(더 큰 값을 반환한다)
Math.max(10, 2);  // → 10
```

## 계산량

| | 값 |
|---|---|
| Time | O(m × n) — 그리드의 모든 셀을 최대 2회(루프에서 1회, DFS에서 1회) 방문한다 |
| Space | O(1) 보조 메모리 — visited 배열을 사용하지 않고 그리드를 직접 덮어쓴다. 단, 재귀 스택에 최대 O(m × n)을 사용한다 |

## 코드

```java
// 입력: 1(육지)과 0(물)으로 구성된 2D 정수 배열 grid
// 출력: 그리드 내의 최대 섬 면적을 int로 반환한다. 섬이 없으면 0을 반환한다

// DFS: 연결된 육지 셀을 세고, 방문한 셀을 0으로 덮어쓴다
int dfs(int[][] grid, int r, int c) {
    // 기저 조건: 범위 밖이거나 물(0)/방문 완료이면 세지 않는다
    if (r < 0 || r >= grid.length
        || c < 0 || c >= grid[0].length
        || grid[r][c] == 0)
        return 0;

    // 방문 완료로 육지(1)를 물(0)로 덮어쓴다 (in-place modification으로 visited 배열을 불필요하게 한다)
    grid[r][c] = 0;

    // 자기 자신의 1 + 상하좌우의 연결 셀 수를 합산하여 반환한다
    // 4방향 재귀의 반환값을 더함으로써, 섬 전체의 면적이 재귀적으로 집계된다
    return 1 + dfs(grid, r - 1, c)   // 위
             + dfs(grid, r + 1, c)   // 아래
             + dfs(grid, r, c - 1)   // 왼쪽
             + dfs(grid, r, c + 1);  // 오른쪽
}

int maxAreaOfIsland(int[][] grid) {
    // 그리드의 행 수와 열 수를 가져온다
    int m = grid.length;
    int n = grid[0].length;
    // 최대 면적을 기록하는 변수를 0으로 초기화한다 (섬이 없으면 이 값이 그대로 반환된다)
    int maxArea = 0;

    // 이중 for 루프로 모든 셀을 순회하며, 각 섬 면적의 최댓값을 구한다
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // 값이 0인 셀에서는 DFS의 기저 조건에서 즉시 0이 반환되므로, 별도의 분기 처리는 불필요하다
            maxArea = Math.max(maxArea,
                dfs(grid, i, j));

    return maxArea;
}
```
