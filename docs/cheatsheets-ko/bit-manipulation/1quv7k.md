# Adding Two Numbers Without the Plus Operator — 덧셈 연산자를 사용하지 않고 두 정수의 합을 구하기

## 문제의 본질

두 정수 `a`와 `b`가 주어진다. `+` 연산자나 `-` 연산자를 **사용하지 않고**, 비트 연산만으로 두 정수의 합계를 계산하여 반환한다.

## 핵심 아이디어

2진수의 덧셈은 「올림 없는 각 자릿수의 합(XOR)」과 「올림(AND를 왼쪽 시프트)」의 두 가지로 분해할 수 있다. 올림이 0이 될 때까지 이 분해를 반복하면 최종적인 합을 얻을 수 있다.

## 사고 프로세스

1. **덧셈의 본질을 비트 단위로 생각한다**: 2진수의 각 자릿수 덧셈은, 올림을 무시하면 「둘 중 하나만 1일 때 결과가 1」이 된다. 이것은 XOR 연산(`a ^ b`) 그 자체이다
2. **올림을 별도로 계산한다**: 올림은 「양쪽 자릿수가 모두 1일 때」 발생한다. 이것은 AND 연산(`a & b`)으로 구할 수 있다. 올림은 다음 자릿수에 영향을 주므로, 결과를 1비트 왼쪽으로 시프트한다(`(a & b) << 1`)
3. **올림을 합에 더해야 한다**: XOR의 결과와 올림을 더하면 최종적인 합이 되지만, `+`는 사용할 수 없다. 그러나 「두 수를 더한다」는 동일한 문제로 귀결되므로, 재귀적으로 같은 처리를 적용할 수 있다
4. **재귀의 종료 조건을 정한다**: 올림 `b`가 0이 되면, 더해야 할 값이 남아 있지 않으므로, 그때의 `a`가 최종적인 합이다. 이것을 기저 케이스로 한다
5. **정수의 비트 폭이 유한하므로 반드시 종료한다**: 왼쪽 시프트에 의해 올림 비트는 매번 상위로 이동하며, 32비트 정수의 범위에서는 최대 32회의 재귀로 올림이 반드시 0이 된다

## 사전 지식

### XOR 연산(배타적 논리합)이란

두 비트가 서로 다를 때 1, 같을 때 0을 반환하는 비트 연산이다. 올림을 무시한 덧셈과 동일한 결과를 얻을 수 있다.

```java
int result = 5 ^ 3;   // 0101 ^ 0011 = 0110 → 6
int result2 = 7 ^ 7;  // 0111 ^ 0111 = 0000 → 0（같은 값끼리의 XOR은 0）
```

### AND 연산이란

두 비트가 모두 1일 때만 1을 반환하는 비트 연산이다. 올림이 발생하는 자릿수를 특정하기 위해 사용한다.

```java
int result = 5 & 3;   // 0101 & 0011 = 0001 → 1
int result2 = 6 & 3;  // 0110 & 0011 = 0010 → 2
```

### 왼쪽 시프트 연산이란

비트열을 지정한 수만큼 왼쪽으로 이동시키고, 비어 있는 오른쪽 비트를 0으로 채우는 연산이다. 1비트 왼쪽 시프트는 값을 2배로 만드는 효과가 있다. 올림은 다음 자릿수에 영향을 주므로, 1비트 왼쪽 시프트로 올바른 자릿수 위치로 이동시킨다.

```java
int result = 1 << 1;  // 0001 → 0010 → 2
int result2 = 3 << 1; // 0011 → 0110 → 6
```

### 2진수 덧셈의 원리

10진수의 필산과 마찬가지로, 각 자릿수마다 덧셈을 하고, 올림을 윗자릿수로 보낸다.
예: `5 + 3`（`0101 + 0011`）의 경우:
- XOR（올림 없는 합）: `0101 ^ 0011 = 0110`（6）
- AND + 왼쪽 시프트（올림）: `(0101 & 0011) << 1 = 0001 << 1 = 0010`（2）
- 6과 2를 같은 방법으로 더한다 → `0110 ^ 0010 = 0100`（4）、`(0110 & 0010) << 1 = 0100`（4）
- 4와 4를 더한다 → `0100 ^ 0100 = 0000`（0）、`(0100 & 0100) << 1 = 1000`（8）
- 0과 8을 더한다 → `0000 ^ 1000 = 1000`（8）、올림은 0 → 종료. 결과는 **8**

## 계산량

| | 값 |
|---|---|
| Time | O(1) — 32비트 정수에서는 올림의 시프트가 최대 32회로 종료되므로, 상수 횟수의 재귀로 완료된다 |
| Space | O(1) — 재귀의 깊이도 최대 32회로 상수이며, 추가적인 데이터 구조를 사용하지 않는다 |

## 코드

```java
// 입력: 두 정수 a와 b
// 출력: a와 b의 합계값을 int로 반환한다
public int getSum(int a, int b) {
    // 기저 케이스: 올림(b)이 0이면 더해야 할 값이 남아 있지 않으므로, a가 최종적인 합이다
    if (b == 0) return a;

    // a ^ b: 올림을 무시한 각 자릿수의 합을 구한다（XOR은 「두 비트가 서로 다를 때 1」을 반환한다）
    // (a & b) << 1: 올림을 구한다（AND로 「양쪽 모두 1인 자릿수」를 특정하고, 왼쪽 시프트로 다음 자릿수 위치로 이동시킨다）
    // 재귀할 때마다 올림 비트는 상위로 이동하며, 32비트 정수에서는 최대 32회로 반드시 0이 된다
    return getSum(a ^ b, (a & b) << 1);
}
```
