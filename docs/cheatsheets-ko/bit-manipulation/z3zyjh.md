# Finding the Number That Appears Only Once — 배열에서 하나만 존재하는 요소를 찾기

## 문제의 본질

정수 배열 `nums`가 주어진다. 배열 내의 모든 요소는 정확히 2번씩 출현하지만, 하나의 요소만 1번만 출현한다. 그 **1번만 출현하는 요소**를 반환한다.

## 핵심 아이디어

XOR 연산은 "같은 값을 2번 XOR하면 0이 된다"라는 성질을 가진다. 배열의 모든 요소를 XOR하면, 2번 출현하는 요소는 모두 상쇄되어 0이 되고, 1번만 출현하는 요소만 남는다.

## 사고 과정

1. **중복 페어를 소거할 수 있으면 답이 남는다**: 배열에서 2번 출현하는 요소를 모두 제거하면, 1번만 출현하는 요소를 얻을 수 있다. 이 "페어의 소거"를 효율적으로 수행하는 연산을 찾는다
2. **XOR의 자기 역원 성질을 이용한다**: XOR 연산에는 `a ^ a = 0`이라는 성질이 있다. 같은 값을 2번 XOR하면 결과는 0이 된다. 즉, 2번 출현하는 요소는 자동으로 소거된다
3. **XOR의 항등원과 결합 법칙을 이용한다**: `a ^ 0 = a`(0과의 XOR는 값을 변경하지 않는다)이고, XOR는 결합 법칙과 교환 법칙이 성립한다. 따라서 요소의 출현 순서에 관계없이, 모든 요소를 XOR하면 페어는 사라지고, 유일한 요소만 남는다
4. **변수 하나로 누적 XOR을 계산한다**: 변수 `result`를 0으로 초기화하고, 배열을 순회하면서 각 요소를 XOR해 나간다. 순회가 끝난 시점에서 `result`에 남아 있는 값이 답이다
5. **추가 데이터 구조가 불필요하다**: HashSet이나 HashMap을 사용하지 않고, 정수 변수 하나만으로 풀 수 있으므로, 공간 복잡도는 O(1)이 된다

## 전제 지식

### XOR(배타적 논리합)란

두 비트가 서로 다르면 1을, 같으면 0을 반환하는 비트 연산이다. Java에서는 `^` 연산자로 표현한다. 정수에 대해 사용하면, 각 비트 위치마다 XOR가 적용된다.

```java
int a = 5;          // 이진수: 101
int b = 3;          // 이진수: 011
int c = a ^ b;      // 이진수: 110 → 6
```

### XOR의 중요한 성질

XOR 연산에는 다음 3가지 성질이 있으며, 이 문제를 풀기 위해 모든 성질이 필요하다.

```java
// 1. 자기 역원: 같은 값을 2번 XOR하면 0이 된다
a ^ a;    // → 0

// 2. 항등원: 0과의 XOR는 원래 값을 변경하지 않는다
a ^ 0;    // → a

// 3. 교환 법칙·결합 법칙: 순서를 바꾸어도 결과는 동일하다
a ^ b ^ a;    // → (a ^ a) ^ b → 0 ^ b → b
```

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(n) — 배열을 1번 순회하는 것만으로 충분하다 |
| Space | O(1) — 추가 데이터 구조를 사용하지 않고, 정수 변수 하나만으로 충분하다 |

## 코드

```java
// 입력: 정수 배열 nums (모든 요소가 2번 출현하고, 하나의 요소만 1번 출현한다)
// 출력: 1번만 출현하는 요소를 int로 반환한다
public int singleNumber(int[] nums) {
    // 누적 XOR의 초기값. 0은 XOR의 항등원이므로, 어떤 값과 XOR해도 상대 값을 변경하지 않는다
    int result = 0;

    // for-each 루프로 배열의 각 요소를 처음부터 끝까지 하나씩 순회한다
    for (int num : nums) {
        // 현재의 result와 num의 XOR를 계산하여 result에 대입한다
        // 2번 출현하는 요소는 a ^ a = 0에 의해 상쇄되고, 1번만 출현하는 요소만 축적된다
        result ^= num;
    }

    // 루프 종료 후, 모든 페어가 상쇄된 결과로서, 1번만 출현하는 요소의 값만 남아 있다
    return result;
}
```
