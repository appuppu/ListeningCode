# Reversing the Bits of an Integer — 32비트 부호 없는 정수의 비트를 반전하기

## 문제의 본질

32비트 부호 없는 정수가 주어진다. 그 비트열을 좌우 반전(역순)한 정수를 반환한다. 예를 들어, 입력 `00000000000000000000000000001011`은 `11010000000000000000000000000000`이 된다.

## 핵심 아이디어

결과를 왼쪽으로 1비트씩 시프트하면서, 입력의 최하위 비트를 하나씩 꺼내어 결과에 추가한다. 이것을 32회 반복하면, 입력의 비트열이 역순으로 결과에 쌓이게 된다.

## 사고 프로세스

1. **비트의 반전은 "끝에서 꺼내어 앞에 쌓는" 연산이다**: 입력의 최하위 비트(오른쪽 끝)를 꺼내어, 결과의 최하위 비트(오른쪽 끝)에 추가한 뒤 결과를 왼쪽으로 시프트하면, 처음에 꺼낸 비트가 최종적으로 최상위로 이동한다. 이것은 비트열의 역순 구축에 해당한다
2. **최하위 비트를 꺼내는 방법**: `n & 1`을 계산하면, `n`의 최하위 비트만을 얻을 수 있다. AND 연산으로 최하위 비트 이외를 모두 0으로 마스킹하는 구조이다
3. **꺼낸 비트를 결과에 추가하는 방법**: `result |= (n & 1)`로 OR 연산을 사용하면, result의 최하위 비트에 꺼낸 비트를 설정할 수 있다. result의 최하위 비트는 직전의 왼쪽 시프트로 0이 되어 있으므로, OR 연산으로 올바르게 설정된다
4. **다음 비트로 진행하는 방법**: 입력 `n`을 `n >>>= 1`로 오른쪽으로 1비트 시프트하면, 다음 비트가 최하위에 온다. `>>>`는 부호 없는 오른쪽 시프트로, 최상위에 항상 0을 채운다
5. **결과에 공간을 만드는 방법**: 새로운 비트를 추가하기 전에 `result <<= 1`로 결과를 왼쪽으로 1비트 시프트하면, 최하위 비트가 0이 되어 새로운 비트를 받아들일 공간이 생긴다
6. **32회 반복하면 완성된다**: 32비트 정수이므로, 위의 "왼쪽 시프트→비트 추가→오른쪽 시프트"를 32회 반복하면, 입력의 모든 비트가 역순으로 결과에 저장된다

## 전제 지식

### 비트 AND 연산(&)이란

두 정수의 각 비트를 비교하여, 양쪽 모두 1인 비트만 1이 되는 연산이다. 특정 비트를 꺼내는 "마스크"로 사용한다.

```java
int n = 0b1011;       // 2진수로 1011 (10진수로 11)
int bit = n & 1;      // 최하위 비트만을 얻음 → 1
int bit2 = 0b1010 & 1; // 최하위 비트가 0인 경우 → 0
```

### 비트 OR 연산(|=)이란

두 정수의 각 비트를 비교하여, 어느 한쪽이라도 1이면 그 비트가 1이 되는 연산이다. 특정 비트를 설정(1로 만들기)하기 위해 사용한다.

```java
int result = 0b0000;
result |= 1;          // 최하위 비트를 1로 설정 → 0b0001
result |= 0;          // 0과의 OR은 변화 없음 → 0b0001
```

### 왼쪽 시프트 연산(<<=)이란

비트열을 왼쪽으로 지정한 수만큼 이동시키는 연산이다. 오른쪽 끝에는 0이 채워진다. 1비트 왼쪽 시프트는 값을 2배로 만드는 효과가 있다.

```java
int result = 0b0011;   // 2진수로 11 (10진수로 3)
result <<= 1;          // 왼쪽으로 1비트 시프트 → 0b0110 (10진수로 6)
```

### 부호 없는 오른쪽 시프트 연산(>>>=)이란

비트열을 오른쪽으로 지정한 수만큼 이동시키는 연산이다. 왼쪽 끝에는 항상 0이 채워진다. `>>`와 달리, 부호 비트에 관계없이 0을 채우기 때문에, 부호 없는 정수의 연산에 적합하다.

```java
int n = 0b1011;        // 2진수로 1011
n >>>= 1;              // 오른쪽으로 1비트 시프트 → 0b0101 (최하위의 1이 사라지고, 오른쪽 끝에 다음 비트가 온다)
```

## 계산량

| | 값 |
|---|---|
| Time | O(1) — 루프는 항상 32회로 고정이며, 입력 값에 의존하지 않는다 |
| Space | O(1) — 추가 변수 `result`만을 사용하며, 입력 크기에 의존하지 않는다 |

## 코드

```java
// 입력: 32비트 부호 없는 정수 n
// 출력: 비트열을 역순으로 한 정수를 int로 반환한다
public int reverseBits(int n) {
    // 반전 후의 비트열을 저장하는 변수. 초기값 0은 모든 비트가 0인 상태를 의미한다
    int result = 0;

    // 32비트 정수의 모든 비트를 처리하기 위해 32회 루프한다
    for (int i = 0; i < 32; i++) {
        // result를 왼쪽으로 1비트 시프트하여, 최하위 비트를 0으로 만들고 새로운 비트를 받아들일 공간을 만든다
        // 주의: 왼쪽 시프트는 비트 추가 전에 수행한다. 후에 수행하면 마지막 비트 추가 후에 불필요한 시프트가 발생하여 결과가 2배가 되어 버린다
        result <<= 1;
        // n의 최하위 비트를 n & 1로 꺼내어, OR 연산으로 result의 최하위 비트에 설정한다
        // 직전의 왼쪽 시프트로 최하위 비트는 0이 되어 있으므로, OR 연산으로 올바르게 설정된다
        result |= (n & 1);
        // n을 부호 없는 오른쪽 시프트하여, 다음 비트를 최하위로 이동시킨다
        // >>>를 사용하는 이유는, 부호 비트에 관계없이 0을 채워야 하기 때문이다
        n >>>= 1;
    }
    // 32회 루프 완료 후, 입력의 비트 0이 result의 비트 31에, 비트 1이 비트 30에, 이런 식으로 모든 비트가 역순으로 저장되어 있다
    return result;
}
```
