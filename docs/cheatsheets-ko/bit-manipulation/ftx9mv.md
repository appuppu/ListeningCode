# Counting the Number of Set Bits — 정수의 2진수 표현에 포함된 1의 비트 수를 세기

## 문제의 본질

음이 아닌 정수 `n`이 주어진다. `n`의 2진수 표현에서 값이 1인 비트의 개수(해밍 가중치)를 반환한다.

## 핵심 아이디어

`n & (n - 1)` 연산은 `n`의 최하위 1 비트를 하나만 제거하는 연산이다. 이 연산을 `n`이 0이 될 때까지 반복하면, 반복 횟수가 곧 1의 비트 수가 된다.

## 사고 프로세스

1. **1의 비트만 효율적으로 세고 싶다**: 32비트 전체를 순회하는 것이 아니라, 1의 비트가 존재하는 위치만 처리할 수 있다면 1의 비트 수 `k`에 비례하는 시간으로 해결할 수 있다
2. **최하위 1 비트를 제거하는 방법을 생각한다**: `n - 1`을 계산하면 `n`의 최하위 1 비트가 0이 되고, 그보다 하위의 비트가 모두 1로 반전된다. 예를 들어 `n = 1100`일 때 `n - 1 = 1011`이 된다
3. **n AND (n - 1)로 최하위 1 비트만 제거된다**: `n`과 `n - 1`의 AND를 취하면, 최하위 1 비트 위치 이하가 모두 0이 되고, 그보다 상위의 비트는 그대로 남는다. `1100 & 1011 = 1000`이 되어 최하위 1 비트가 하나 제거되었다
4. **제거 연산을 반복하여 카운트한다**: `n &= (n - 1)`을 반복 적용하고, `n`이 0이 될 때까지의 횟수를 카운트하면, 그것이 원래 `n`에 포함된 1의 비트 수이다
5. **루프의 종료 조건**: 1의 비트가 모두 제거되면 `n`은 0이 된다. `n != 0`을 루프 조건으로 하면, 1의 비트 수만큼만 루프가 실행되어 자연스럽게 종료된다

## 전제 지식

### 비트 AND 연산(&)이란

두 정수의 각 비트를 비교하여, 양쪽 모두 1일 때만 결과가 1이 되는 연산이다. 그 외의 조합에서는 결과가 0이 된다.

```java
int a = 0b1100;       // 2진수로 1100
int b = 0b1010;       // 2진수로 1010
int result = a & b;   // 결과는 0b1000 (양쪽 모두 1인 위치만 1이 된다)
```

### n & (n - 1)의 동작

`n`에서 1을 빼면, 최하위 1 비트가 0이 되고 그보다 하위의 비트가 모두 1로 반전된다. `n`과의 AND를 취하면, 최하위 1 비트 이하가 모두 0이 된다.

```java
int n = 0b1100;       // n     = 1100 (1의 비트가 2개)
n &= (n - 1);        // n - 1 = 1011, n = 1100 & 1011 = 1000 (1의 비트가 1개로 줄었다)
n &= (n - 1);        // n - 1 = 0111, n = 1000 & 0111 = 0000 (1의 비트가 0개로 줄었다)
```

### 해밍 가중치(Hamming Weight)란

정수의 2진수 표현에 포함된 1의 비트 개수를 말한다. 예를 들어 `11`의 2진수는 `1011`이므로, 해밍 가중치는 3이다.

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(k) — k는 `n`에 포함된 1의 비트 수이다. 루프는 k번만 실행된다 |
| Space | O(1) — 카운터 변수 1개만 사용한다 |

## 코드

```java
// 입력: 음이 아닌 정수 n
// 출력: n의 2진수 표현에 포함된 1의 비트 수를 int로 반환한다
public int hammingWeight(int n) {
    // 1의 비트를 제거한 횟수를 기록하는 카운터. 제거한 총 횟수가 최종 답이 된다
    int count = 0;

    // n이 0이면 1의 비트가 남아 있지 않으므로 루프를 종료한다
    while (n != 0) {
        // 최하위 1 비트를 하나 제거한다 (Brian Kernighan's Trick)
        // n - 1에 의해 최하위 1 비트 이하가 반전되고, n과의 AND로 해당 위치 이하가 모두 0이 된다
        n &= (n - 1);
        // 1의 비트를 하나 제거했으므로 제거 횟수를 기록한다
        count++;
    }
    // count에는 1의 비트를 제거한 총 횟수, 즉 원래 n에 포함되어 있던 1의 비트 수가 저장되어 있다
    return count;
}
```
