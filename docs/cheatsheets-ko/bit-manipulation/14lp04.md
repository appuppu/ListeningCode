# Reversing the Digits of an Integer — 32비트 부호 있는 정수의 각 자릿수를 반전한다

## 문제의 본질

32비트 부호 있는 정수 `x`가 주어진다. `x`의 각 자릿수를 역순으로 재배열한 정수를 반환한다. 반전 후의 값이 32비트 부호 있는 정수의 범위(-2³¹ ~ 2³¹-1)를 초과하는 경우에는 `0`을 반환한다.

## 핵심 아이디어

정수의 마지막 자릿수는 `x % 10`으로 추출할 수 있고, `x / 10`으로 마지막 자릿수를 제거할 수 있다. 이 "추출하여 쌓아 올리는" 연산을 반복하면, 자연스럽게 자릿수가 역순이 된다. 쌓아 올릴 때마다 오버플로를 사전에 검사함으로써, 안전하게 반전 결과를 구축할 수 있다.

## 사고 프로세스

1. **자릿수를 하나씩 추출하는 방법**: 정수의 마지막 자릿수는 `x % 10`(10으로 나눈 나머지)으로 얻을 수 있다. 추출 후에 `x / 10`으로 마지막 자릿수를 제거하면, 다음 자릿수에 접근할 수 있다. 이 연산을 `x`가 0이 될 때까지 반복하면, 모든 자릿수를 끝에서부터 순서대로 추출할 수 있다
2. **추출한 자릿수를 역순으로 조립하는 방법**: 결과 변수 `result`에 대해 `result = result * 10 + digit`를 반복한다. `result * 10`으로 기존의 자릿수를 한 자리 왼쪽으로 이동시키고, `+ digit`로 새로운 자릿수를 1의 자리에 추가한다. 끝에서부터 추출한 자릿수를 앞에서부터 순서대로 배치하게 되므로, 자릿수의 배열이 자연스럽게 역전된다
3. **오버플로에 대한 대처**: `result * 10 + digit`의 계산 결과가 `Integer.MAX_VALUE`(2147483647)를 초과하거나, `Integer.MIN_VALUE`(-2147483648)를 하회할 가능성이 있다. 곱셈을 실행한 **후**에는 이미 늦으므로, 곱셈 **전**에 검사할 필요가 있다
4. **오버플로의 사전 검사 방법**: `result * 10`이 오버플로하는지 여부는, `result`를 `Integer.MAX_VALUE / 10`(= 214748364)과 비교하면 판정할 수 있다. `result > 214748364`이면 확실히 오버플로한다. `result == 214748364`인 경우에는, `digit > 7`(MAX_VALUE의 1의 자리)이면 오버플로한다. 음수의 경우에도 마찬가지로 `Integer.MIN_VALUE / 10`과 비교한다
5. **부호의 처리**: `x % 10`과 `x / 10`은 Java에서 음수에 대해서도 올바르게 동작한다(`-123 % 10 == -3`, `-123 / 10 == -12`). 따라서 부호를 분리하지 않고 그대로 처리할 수 있다
6. **최종적으로 반환하는 값**: 루프 종료 후의 `result`가 반전된 정수이다. 오버플로가 검출된 경우에는 루프 내에서 즉시 `0`을 반환한다

## 사전 지식

### % 연산자(나머지 연산자)란

정수를 다른 정수로 나눈 나머지를 반환하는 연산자이다. `x % 10`은 `x`의 1의 자리 숫자를 추출한다. Java에서는 음수에 대해서도 부호가 유지된다.

```java
123 % 10;    // → 3 (1의 자리를 추출한다)
-123 % 10;   // → -3 (음수에서도 부호가 유지된다)
123 / 10;    // → 12 (1의 자리를 제거한다)
-123 / 10;   // → -12 (음수에서도 올바르게 버림 처리된다)
```

### 32비트 부호 있는 정수의 범위

Java의 `int` 타입이 표현할 수 있는 값의 범위이다. 이 범위를 초과하면 오버플로가 발생하여 잘못된 값이 된다.

```java
Integer.MAX_VALUE;   // → 2147483647 (2³¹ - 1)
Integer.MIN_VALUE;   // → -2147483648 (-2³¹)
Integer.MAX_VALUE / 10;  // → 214748364 (오버플로 판정의 임계값)
Integer.MAX_VALUE % 10;  // → 7 (MAX_VALUE의 1의 자리)
Integer.MIN_VALUE / 10;  // → -214748364
Integer.MIN_VALUE % 10;  // → -8 (MIN_VALUE의 1의 자리)
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — n은 `x`의 자릿수이다. 각 자릿수를 1회씩 처리한다 |
| Space | O(1) — 변수 `result`와 `digit`만 사용한다 |

## 코드

```java
// 입력: 32비트 부호 있는 정수 x
// 출력: x의 각 자릿수를 반전한 정수를 반환한다. 반전 후의 값이 32비트 범위를 초과하는 경우에는 0을 반환한다
public int reverse(int x) {
    // 반전 결과를 저장하는 변수이다. 자릿수를 하나씩 쌓아 올린다
    int result = 0;

    // x의 자릿수를 끝에서부터 하나씩 추출하여 처리한다. x가 0이 되면 모든 자릿수의 처리가 완료된다
    while (x != 0) {
        // x의 1의 자리를 추출한다. 음수에서도 %는 부호를 유지하므로 특별한 처리가 필요 없다
        int digit = x % 10;

        // 양의 오버플로를 사전에 검사한다 (곱셈 후에는 이미 늦으므로 곱셈 전에 검사한다)
        // result > 214748364이면 result * 10은 확실히 MAX_VALUE(2147483647)를 초과한다
        // result == 214748364이고 digit > 7이면 result * 10 + digit가 MAX_VALUE(끝자리가 7)를 초과한다
        if (result > Integer.MAX_VALUE / 10
                || (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return 0;
        }

        // 음의 오버플로를 사전에 검사한다
        // result < -214748364이면 result * 10은 확실히 MIN_VALUE(-2147483648)를 하회한다
        // result == -214748364이고 digit < -8이면 result * 10 + digit가 MIN_VALUE(끝자리가 -8)를 하회한다
        if (result < Integer.MIN_VALUE / 10
                || (result == Integer.MIN_VALUE / 10 && digit < -8)) {
            return 0;
        }

        // result * 10으로 기존의 자릿수를 한 자리 왼쪽으로 이동시키고, + digit로 추출한 자릿수를 1의 자리에 추가한다
        // 이를 통해 원래 수의 마지막 자릿수가 결과의 앞쪽에 순차적으로 배치된다
        result = result * 10 + digit;

        // x의 1의 자리를 제거하고, 다음 자릿수를 끝에 노출시킨다
        x = x / 10;
    }

    // 모든 자릿수의 반전이 완료된 결과를 반환한다. 오버플로 발생 시에는 루프 내에서 이미 0을 반환하였다
    return result;
}
```
