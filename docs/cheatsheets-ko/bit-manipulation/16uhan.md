# Counting Bits for Every Number Up to N — 0부터 N까지 각 정수에 포함된 1의 비트 수를 배열로 반환한다

## 문제의 본질

비음수 정수 `n`이 주어진다. 길이 `n + 1`인 배열을 반환한다. 배열의 인덱스 `i`에 해당하는 요소에는 `i`를 2진수로 표현했을 때의 **1인 비트의 개수**를 저장한다. 예: n=5일 때, 0→0, 1→1, 2→1, 3→2, 4→1, 5→2이므로 `[0,1,1,2,1,2]`를 반환한다.

## 핵심 아이디어

임의의 정수 `i`의 1인 비트 수는 `i`를 1비트 오른쪽으로 시프트한 값 `i >> 1`의 1인 비트 수에 `i`의 최하위 비트(`i & 1`)를 더한 것과 같다. 이 재귀적 관계를 이용하면 작은 값의 결과를 재활용하여 모든 값을 O(1)씩 구할 수 있다.

## 사고 과정

1. **2진수의 구조에 주목한다**: 정수 `i`의 2진 표현을 오른쪽으로 1비트 시프트하면, 최하위 비트가 사라지고 나머지 비트열은 `i / 2`(내림)와 같아진다. 즉 `i`의 비트열은 「`i >> 1`의 비트열」＋「최하위 1비트」라는 구조를 가진다
2. **1인 비트 수를 분해할 수 있다**: 위의 구조로부터 `i`에 포함된 1의 개수는 「`i >> 1`에 포함된 1의 개수」＋「최하위 비트가 1인지 여부(0 또는 1)」로 분해할 수 있다. 이를 식으로 나타내면 `countBits(i) = countBits(i >> 1) + (i & 1)`이 된다
3. **작은 값부터 순서대로 계산하면 재활용할 수 있다**: `i >> 1`은 항상 `i`보다 작은 값이므로, `i = 0`부터 순서대로 계산해 나가면 `result[i >> 1]`은 반드시 계산이 완료된 상태이다. 이 성질 덕분에 재귀가 아닌 루프로 앞에서부터 순서대로 채울 수 있다
4. **결과 배열 자체가 DP 테이블이 된다**: 반환할 배열 `result`를 그대로 DP 테이블로 사용한다. `result[0] = 0`을 기저 케이스로 하고, `i = 1`부터 `n`까지 `result[i] = result[i >> 1] + (i & 1)`로 채워 나간다. 추가적인 데이터 구조는 필요하지 않다

## 전제 지식

### 오른쪽 시프트 연산(`>>`)이란

정수의 2진 표현을 오른쪽으로 지정한 비트 수만큼 이동하는 연산이다. 오른쪽으로 1비트 시프트하면 최하위 비트가 사라지고, 값은 2로 나눈 몫(내림)이 된다.

```java
int a = 6;      // 2진수: 110
int b = a >> 1;  // 2진수: 011 → 값은 3 (6 ÷ 2 = 3)

int c = 7;      // 2진수: 111
int d = c >> 1;  // 2진수: 011 → 값은 3 (7 ÷ 2 = 3, 나머지 버림)
```

### 비트 AND 연산(`&`)이란

두 정수의 각 비트를 비교하여 양쪽 모두 1인 비트만 1로 만드는 연산이다. `i & 1`은 `i`의 최하위 비트만을 추출하는 연산이며, `i`가 홀수이면 1을, 짝수이면 0을 반환한다.

```java
int a = 5;       // 2진수: 101
int b = a & 1;   // 2진수: 001 → 값은 1 (홀수이므로 최하위 비트는 1)

int c = 4;       // 2진수: 100
int d = c & 1;   // 2진수: 000 → 값은 0 (짝수이므로 최하위 비트는 0)
```

### 동적 계획법(DP)이란

큰 문제를 작은 부분 문제로 분할하고, 부분 문제의 결과를 배열에 기록하여 재활용하는 기법이다. 이 문제에서는 `result[i >> 1]`(이미 계산이 완료된 작은 값의 결과)을 이용하여 `result[i]`를 O(1)로 구한다.

```java
int[] result = new int[n + 1];  // DP 테이블 겸 결과 배열을 생성한다
result[0] = 0;                  // 기저 케이스: 0의 1인 비트 수는 0이다
result[i] = result[i >> 1] + (i & 1);  // 점화식: 이미 알고 있는 결과를 재활용한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 1부터 n까지의 각 값에 대해 비트 시프트와 AND 연산을 각각 1회씩 수행하는 것으로 충분하다 |
| Space | O(n) — 결과를 저장하는 길이 n+1의 배열을 사용한다 (출력 자체이므로 추가 공간은 O(1)로도 해석할 수 있다) |

## 코드

```java
// 입력: 비음수 정수 n
// 출력: 길이 n+1인 int[]. 각 result[i]에는 i의 2진 표현에 포함된 1인 비트 수를 저장한다
public int[] countBits(int n) {
    // DP 테이블 겸 결과 배열을 생성한다. new int[n+1]로 모든 요소가 0으로 초기화되므로,
    // result[0] = 0 (0의 1인 비트 수는 0)은 자동으로 충족된다
    int[] result = new int[n + 1];

    // i=0은 이미 0으로 올바르므로, i=1부터 순회를 시작한다
    for (int i = 1; i <= n; i++) {
        // result[i >> 1]: i를 1비트 오른쪽으로 시프트한 값의 1인 비트 수 (i >> 1은 항상 i보다 작으므로 계산이 완료된 상태이다)
        // i & 1: i의 최하위 비트 (홀수이면 1, 짝수이면 0)
        // 이 둘을 더하면 i의 2진 표현에 포함된 1의 총 개수를 구할 수 있다
        result[i] = result[i >> 1] + (i & 1);
    }
    // 배열의 각 요소 result[i]에 인덱스 i의 1인 비트 수가 저장된 상태로 반환한다
    return result;
}
```
