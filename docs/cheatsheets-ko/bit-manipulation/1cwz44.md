# Finding the Missing Number in a Sequence — 0~n의 연속된 수열에서 빠진 하나의 수를 찾는다

## 문제의 본질

0부터 n까지의 정수 중 n개의 서로 다른 수를 포함하는 배열 `nums`가 주어진다. 이 범위에 포함되지만 배열에는 존재하지 않는 **하나의 빠진 수**를 찾아서 반환한다.

## 핵심 아이디어

XOR는 같은 값을 2번 적용하면 상쇄되어 0이 된다. 배열의 인덱스(0~n-1)와 값 n, 그리고 배열의 모든 요소를 전부 XOR하면 쌍이 되는 수는 사라지고, 쌍이 없는 "빠진 수"만 남는다.

## 사고 프로세스

1. **빠진 수를 제외한 모든 수는 쌍이 된다**: 배열의 인덱스는 0~n-1이고, 배열의 값도 0~n 범위에서 빠진 수를 제외한 것이다. 즉 인덱스 측에 초기값으로 n을 더하면 0~n의 모든 정수가 인덱스 측에 갖춰진다. 빠진 수만이 배열의 값 측에 존재하지 않으므로 쌍이 되지 않는다
2. **쌍을 상쇄하는 연산에는 XOR가 최적이다**: XOR에는 `a ^ a = 0`(같은 값끼리 상쇄된다)과 `a ^ 0 = a`(0과의 XOR는 값을 유지한다)라는 성질이 있다. 모든 인덱스와 값을 XOR하면 쌍이 되는 수는 모두 0이 되고, 쌍이 없는 빠진 수만 남는다
3. **초기값을 n으로 설정하는 이유**: for 루프의 인덱스는 0~n-1 범위만 커버한다. 그러나 빠진 수가 n일 가능성도 있으므로, XOR의 초기값을 n으로 설정함으로써 0~n의 전체 범위를 커버한다
4. **한 번의 루프로 완결된다**: 루프 내에서 `xor ^= i`(인덱스의 XOR)와 `xor ^= nums[i]`(값의 XOR)를 동시에 수행하면, 배열을 한 번 순회하는 것만으로 결과를 얻을 수 있다. 추가 데이터 구조도 필요 없다

## 전제 지식

### XOR(배타적 논리합)란

두 비트가 서로 다를 때 1, 같을 때 0을 반환하는 비트 연산이다. Java에서는 `^` 연산자를 사용한다. 정수에 대해 비트 단위로 적용된다.

```java
int a = 5;          // 이진수: 101
int b = 3;          // 이진수: 011
int result = a ^ b; // 이진수: 110 → 6
```

### XOR의 중요한 성질

알고리즘의 핵심이 되는 3가지 성질이 있다.

```java
// 성질1: 같은 값의 XOR는 0이 된다 (상쇄)
5 ^ 5;    // → 0

// 성질2: 0과의 XOR는 원래 값을 유지한다
5 ^ 0;    // → 5

// 성질3: 순서를 바꿔도 결과는 같다 (교환법칙·결합법칙)
(2 ^ 5) ^ 2;  // → 5 (2끼리 상쇄되어 5가 남는다)
```

### ^= 연산자란

XOR 연산의 결과를 좌변의 변수에 대입하는 복합 대입 연산자이다. `xor ^= i`는 `xor = xor ^ i`와 같은 의미이다.

```java
int xor = 0;
xor ^= 3;   // xor = 0 ^ 3 → 3
xor ^= 3;   // xor = 3 ^ 3 → 0 (같은 값으로 상쇄된다)
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 한 번 순회하는 것만으로 충분하다 |
| Space | O(1) — 추가 데이터 구조를 사용하지 않고 변수 하나만으로 충분하다 |

## 코드

```java
// 입력: 0~n 범위에서 n개의 서로 다른 정수를 포함하는 배열 nums
// 출력: 범위 내에서 배열에 포함되지 않는 하나의 정수를 반환한다
public int missingNumber(int[] nums) {
    // 초기값을 n으로 설정함으로써 루프의 인덱스 0~n-1과 합쳐 0~n 전체를 커버한다
    // for 루프의 인덱스는 0~n-1만 커버하므로, n을 여기서 초기값으로 부여한다
    int xor = nums.length;

    for (int i = 0; i < nums.length; i++) {
        // 인덱스 i를 XOR 누적값에 접는다
        // 루프 종료 시에는 인덱스 0~n-1의 전부가 XOR된다 (초기값 n과 합쳐 0~n의 모든 정수가 XOR된다)
        xor ^= i;
        // 배열의 값을 XOR 누적값에 접는다
        // 배열에 존재하는 수는 인덱스 측과 값 측 양쪽에 나타나므로, a ^ a = 0의 성질에 의해 상쇄된다
        xor ^= nums[i];
    }

    // 쌍이 된 수는 모두 상쇄되어 0이 되고, 배열에 존재하지 않았던 빠진 수만이 쌍을 갖지 않으므로 남는다
    return xor;
}
```
