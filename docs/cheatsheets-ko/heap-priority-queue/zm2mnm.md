# Finding the Kth Largest Element in an Array — 정렬되지 않은 배열에서 K번째로 큰 요소를 찾기

## 문제의 본질

정수 배열 `nums`와 정수 `k`가 주어진다. 배열을 정렬했을 때 큰 쪽에서 세어 `k`번째에 해당하는 요소의 값을 반환한다. 중복되는 값도 각각 독립적으로 카운트한다(k번째로 큰 "서로 다른 값"이 아니다).

## 핵심 아이디어

배열 전체를 정렬하지 않아도, 피벗을 기준으로 배열을 분할하면 "피벗이 몇 번째로 큰지"를 즉시 알 수 있다. 피벗의 위치가 `k-1`이 될 때까지 탐색 범위를 한쪽으로 좁혀 나감으로써, 평균 O(n)으로 목적의 요소에 도달할 수 있다.

## 사고 프로세스

1. **K번째로 큰 요소는 정렬 후의 인덱스로 결정된다**: 배열을 내림차순으로 정렬하면, 인덱스 `k-1`의 요소가 답이 된다. 그러나 완전한 정렬은 O(n log n)이 소요되므로, 더 효율적인 방법을 생각한다
2. **필요한 것은 K번째 위치뿐이다**: 전체의 순서는 불필요하고, "K번째로 큰 요소가 어느 것인지"만 알면 된다. 피벗을 사용하여 배열을 "피벗보다 큰 그룹"과 "피벗 이하의 그룹"으로 분할하면, 피벗이 몇 번째로 큰지가 그 위치(인덱스)로 알 수 있다
3. **피벗의 위치로 탐색 범위를 좁힌다**: partition의 결과, 피벗이 인덱스 `p`에 놓였다고 하자. `p == k-1`이면 답을 찾은 것이다. `p < k-1`이면 목적의 요소는 피벗보다 오른쪽(더 작은 쪽)에 있으므로, 탐색 범위를 `p+1` 이후로 좁힌다. `p > k-1`이면 왼쪽으로 좁힌다
4. **내림차순으로 partition한다**: 일반적인 QuickSort의 partition은 오름차순이지만, "K번째로 큰" 것을 구하기 위해 내림차순으로 partition한다. 즉, 피벗보다 큰 요소를 왼쪽에 모은다. 이렇게 함으로써, 인덱스 `k-1`이 답의 위치에 대응한다
5. **루프로 한쪽만 반복 처리한다**: QuickSort는 양쪽을 재귀적으로 처리하지만, Quickselect에서는 답이 포함된 한쪽만 처리하면 된다. while 루프로 `l <= r`인 동안 partition을 반복하고, `p == k-1`이 된 시점에서 해당 요소를 반환한다

## 전제 지식

### Quickselect란

QuickSort와 동일한 partition 연산을 사용하여, 배열에서 K번째로 작은(또는 큰) 요소를 평균 O(n)으로 찾는 알고리즘이다. QuickSort가 양쪽을 재귀 처리하는 것에 비해, Quickselect는 한쪽만 처리하므로, 평균 계산량이 O(n)이 된다.

### partition(분할)이란

배열에서 하나의 피벗을 선택하고, 피벗보다 큰 요소를 왼쪽에, 피벗 이하의 요소를 오른쪽으로 이동시키는 연산이다. 연산 후, 피벗은 최종적인 올바른 위치에 놓인다. 이 위치(인덱스)가 피벗의 "순위"를 나타낸다.

```java
// 내림차순 partition: 피벗보다 큰 요소를 왼쪽에 모은다
// 반환값: 피벗이 놓인 인덱스
int pivot = nums[r];       // 오른쪽 끝의 요소를 피벗으로 선택한다
int store = l;             // 다음에 스왑할 위치를 가리키는 포인터
// nums[i] > pivot이면, nums[i]를 store 위치에 스왑하고 store를 전진시킨다
// 마지막에 pivot을 store 위치에 놓는다 → store가 피벗의 최종 위치
```

### swap(요소의 교환)이란

배열 내의 두 요소의 위치를 바꾸는 연산이다. 임시 변수 `temp`를 사용하여 값을 대피시킴으로써 덮어쓰기를 방지한다.

```java
int temp = nums[i];    // nums[i]의 값을 임시 변수에 대피시킨다
nums[i] = nums[store]; // nums[store]의 값을 nums[i]에 덮어쓴다
nums[store] = temp;    // 대피해 둔 원래의 nums[i] 값을 nums[store]에 쓴다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) 평균 — 매번 탐색 범위가 평균적으로 절반이 되므로, n + n/2 + n/4 + ... ≈ 2n = O(n) |
| Space | O(1) — 배열을 in-place로 조작하며, 추가 데이터 구조를 사용하지 않는다 |

## 코드

```java
// 입력: 정수 배열 nums와 정수 k
// 출력: 배열에서 K번째로 큰 요소의 값을 int로 반환한다

// 내림차순 partition: 피벗보다 큰 요소를 왼쪽에 모으고, 피벗의 최종 위치를 반환한다
private int partition(int[] nums, int l, int r) {
    // 탐색 범위의 오른쪽 끝 요소를 피벗으로 선택한다
    int pivot = nums[r];
    // store는 "다음에 피벗보다 큰 요소를 놓아야 할 위치"를 가리킨다
    int store = l;

    // l부터 r-1까지 순회하며, 피벗보다 큰 요소를 왼쪽에 모은다
    for (int i = l; i < r; i++) {
        // 현재 요소가 피벗보다 크면, store 위치에 스왑하여 왼쪽에 모은다
        if (nums[i] > pivot) {
            int temp = nums[i];
            nums[i] = nums[store];
            nums[store] = temp;
            // store를 전진시켜, 다음 큰 요소의 배치 위치를 갱신한다
            store++;
        }
    }

    // 피벗을 store 위치에 배치한다 (피벗의 최종적인 올바른 위치)
    // 이 시점에서, store보다 왼쪽에는 피벗보다 큰 요소가, 오른쪽에는 피벗 이하의 요소가 있다
    int temp = nums[store];
    nums[store] = nums[r];
    nums[r] = temp;
    // store가 피벗의 최종 위치 = 피벗의 "내림차순에서의 순위"를 나타낸다
    return store;
}

public int findKthLargest(int[] nums, int k) {
    // 탐색 범위를 배열 전체로 초기화한다
    int l = 0, r = nums.length - 1;

    // 탐색 범위가 유효한 동안 partition을 반복한다. 루프가 돌 때마다 탐색 범위가 좁아진다
    while (l <= r) {
        // 현재의 탐색 범위에서 partition을 실행하고, 피벗의 위치를 얻는다
        int p = partition(nums, l, r);

        if (p == k - 1) {
            // 피벗이 K번째로 큰 위치에 있으므로 답을 반환한다
            // 내림차순으로 왼쪽부터 세어 인덱스 k-1이 K번째로 큰 요소의 위치이다
            return nums[p];
        } else if (p < k - 1) {
            // K번째는 피벗보다 오른쪽(더 작은 쪽)에 있으므로, 탐색 범위의 왼쪽 끝을 줄인다
            l = p + 1;
        } else {
            // K번째는 피벗보다 왼쪽(더 큰 쪽)에 있으므로, 탐색 범위의 오른쪽 끝을 줄인다
            r = p - 1;
        }
    }
    // 문제의 제약상, 유효한 k가 주어지므로 여기에는 도달하지 않는다
    return -1;
}
```
