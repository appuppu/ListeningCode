# Scheduling Tasks With Cooldown Intervals — 쿨다운이 있는 태스크의 최소 실행 시간을 구하기

## 문제의 본질

태스크 배열(문자로 표현)과 음이 아닌 정수 `n`(쿨다운 간격)이 주어진다. 동일한 태스크는 최소 `n` 간격을 두어야 다시 실행할 수 있다. 쿨다운 중에는 CPU가 유휴 상태가 된다. 모든 태스크를 완료하는 데 필요한 **최소 시간 단위 수**를 반환한다.

## 핵심 아이디어

가장 빈도가 높은 태스크가 전체 스케줄의 골격을 결정한다. 최빈 태스크 사이에 생기는 쿨다운 빈틈을 다른 태스크로 채울 수 있는지에 따라, 전체 시간이 "수식에 의한 계산 결과"와 "태스크 총 개수" 중 큰 쪽으로 결정된다.

## 사고 프로세스

1. **최빈 태스크가 병목이 된다**: 쿨다운 제약이 가장 엄격한 것은 출현 횟수가 가장 많은 태스크이다. 이 태스크가 전체 스케줄의 길이를 지배한다
2. **최빈 태스크를 배치하면 빈틈이 생긴다**: 최빈 태스크의 출현 횟수를 `maxFreq`라 하면, 이 태스크를 `n` 간격을 두고 배치할 때, 태스크 사이에 `(maxFreq - 1)`개의 블록이 생긴다. 각 블록의 길이는 `(n + 1)`(태스크 1개 + 쿨다운 `n` 슬롯)이다
3. **빈틈을 다른 태스크로 채운다**: 각 블록 내의 쿨다운 슬롯에 다른 태스크를 배치하여 유휴 시간을 줄인다. 빈틈이 모두 채워지면 유휴는 발생하지 않는다
4. **마지막 블록은 특별 처리한다**: 마지막 실행에는 쿨다운이 필요 없으므로, 마지막 블록에는 최빈 태스크(및 동률인 태스크)만 들어간다. 최빈과 같은 횟수를 가진 태스크의 개수를 `maxCount`라 하면, 마지막 블록의 길이는 `maxCount`이다
5. **수식으로 전체 길이를 계산한다**: `(maxFreq - 1) * (n + 1) + maxCount`로 최빈 태스크를 축으로 한 스케줄의 길이를 구한다
6. **태스크 총 개수와 비교가 필요하다**: 빈틈이 모두 채워지고 태스크가 남는 경우, 유휴가 전혀 필요 없으며 태스크 총 개수가 그대로 답이 된다. 따라서 최종 답은 `Math.max(formulaResult, tasks.length)`이다

## 사전 지식

### 빈도 배열이란

고정 크기 배열을 사용하여 각 문자의 출현 횟수를 세는 기법이다. 영어 대문자만 있는 경우, 크기 26의 배열로 모든 문자를 커버할 수 있다. HashMap보다 빠르고 메모리 효율적이다.

```java
int[] freq = new int[26];            // A~Z에 대응하는 26개의 카운터를 0으로 초기화한다
freq['B' - 'A']++;                   // 'B'의 출현 횟수를 1 증가시킨다 (인덱스 1)
freq['B' - 'A'];                     // 'B'의 출현 횟수를 가져온다 → 1
```

### Math.max란

두 값 중 큰 쪽을 반환하는 메서드이다. 두 후보 중에서 답을 선택할 때 사용한다.

```java
Math.max(10, 7);    // → 10 (큰 쪽을 반환한다)
Math.max(5, 12);    // → 12
```

### 이 문제에서의 블록 구조란

최빈 태스크를 `A`(출현 횟수 3), `n = 2`라 하면, 스케줄은 다음과 같은 블록 구조가 된다:

```
[A _ _] [A _ _] [A]
 블록1    블록2   마지막
```

`_`는 쿨다운 슬롯으로, 다른 태스크 또는 유휴가 들어간다. 마지막 블록에는 쿨다운이 필요 없으므로 `A`만 들어간다.

## 계산량

| | 값 |
|---|---|
| Time | O(k) — 태스크 배열을 1회 순회하고, 고정 길이 26의 배열을 상수 회 순회한다 (k는 태스크 수) |
| Space | O(1) — 크기 26의 고정 길이 배열만 사용한다 |

## 코드

```java
// 입력: 문자 배열 tasks(각 태스크는 'A'~'Z'의 영어 대문자)와 음이 아닌 정수 n(쿨다운 간격)
// 출력: 모든 태스크를 완료하는 데 필요한 최소 시간 단위 수를 int로 반환한다
public int leastInterval(char[] tasks, int n) {
    // 크기 26의 빈도 배열을 생성한다. freq[0]이 'A'의 횟수, freq[1]이 'B'의 횟수에 대응한다
    int[] freq = new int[26];
    // tasks를 순회하며, t - 'A'로 문자를 0~25의 인덱스로 변환하여 카운트한다
    for (char t : tasks)
        freq[t - 'A']++;

    // freq 배열을 순회하여 최대 출현 횟수를 구한다. maxFreq는 스케줄의 블록 수를 결정한다
    int maxFreq = 0;
    for (int f : freq)
        maxFreq = Math.max(maxFreq, f);

    // 출현 횟수가 maxFreq와 같은 태스크의 개수를 센다. maxCount는 마지막 블록에 들어가는 태스크의 수이다
    int maxCount = 0;
    for (int f : freq)
        if (f == maxFreq) maxCount++;

    // (maxFreq - 1): 쿨다운이 필요한 블록의 수
    // (n + 1): 각 블록의 길이 (태스크 1개 + 쿨다운 n 슬롯)
    // maxCount: 마지막 블록의 길이 (최빈 태스크와 동률인 태스크만 들어간다)
    int formulaResult =
        (maxFreq - 1) * (n + 1)
        + maxCount;

    // formulaResult는 쿨다운에 의한 유휴가 발생하는 경우의 길이이다
    // tasks.length는 유휴가 전혀 필요 없는 경우(빈틈이 모두 채워지고 태스크가 남는 경우)의 길이이다
    // 둘 중 큰 쪽이 올바른 답이 된다
    return Math.max(formulaResult,
        tasks.length);
}
```
