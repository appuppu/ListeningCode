# Tracking the Kth Largest Element in a Stream — 스트림에서 K번째로 큰 요소를 항상 가져오기

## 문제의 본질

정수 `k`와 초기 숫자 리스트가 주어지는 클래스를 설계한다. `add` 메서드가 호출될 때마다 새로운 숫자를 스트림에 추가하고, 그 시점의 스트림 전체에서 **K번째로 큰 요소**를 반환한다.

## 핵심 아이디어

K번째로 큰 요소만 필요하므로, 상위 K개의 요소만 Min-Heap으로 유지하면 힙의 루트(최솟값)가 항상 K번째로 큰 요소가 된다.

## 사고 과정

1. **필요한 것은 K번째로 큰 요소뿐이다**: 스트림 전체를 정렬할 필요 없이, 상위 K개의 요소만 파악하고 있으면 K번째로 큰 요소를 확정할 수 있다
2. **상위 K개를 효율적으로 관리하고 싶다**: 요소의 추가와 최솟값의 추출을 O(log n)으로 수행할 수 있는 Min-Heap(최소 힙)이 적합하다. Min-Heap의 루트는 항상 힙 내의 최솟값을 유지하므로, 크기를 K로 유지하면 루트가 K번째로 큰 요소가 된다
3. **힙의 크기를 K로 제한하는 방법**: 새로운 요소를 추가한 후, 힙의 크기가 K를 초과하면 `poll()`로 루트(최솟값)를 제거한다. 이를 통해 K번째로 큰 요소보다 작은 값이 자동으로 제거되어, 항상 상위 K개만 남게 된다
4. **K번째로 큰 요소의 획득 방법**: 힙의 크기가 정확히 K일 때, 루트의 값이 K번째로 큰 요소이다. `peek()`으로 O(1)에 가져올 수 있다
5. **초기화 시에도 add를 재활용한다**: 생성자에서 초기 리스트의 각 요소에 대해 `add`를 호출하면, 같은 로직으로 힙을 구축할 수 있다. 초기화와 추가에서 코드를 공통화할 수 있다

## 전제 지식

### Min-Heap(최소 힙)이란

힙은 완전 이진 트리 구조를 가진 자료 구조이다. Min-Heap에서는 부모 노드의 값이 항상 자식 노드의 값 이하가 되도록 유지된다. 따라서 루트에는 항상 힙 내의 최솟값이 위치한다. 요소의 추가와 최솟값의 추출은 O(log n)으로 수행할 수 있다.

### PriorityQueue란

Java에서 Min-Heap을 구현한 클래스이다. 기본적으로 요소를 오름차순(작은 순서)으로 우선순위를 부여한다.

```java
PriorityQueue<Integer> heap = new PriorityQueue<>();  // 빈 Min-Heap을 생성한다
heap.offer(5);        // 요소 5를 힙에 추가한다
heap.offer(3);        // 요소 3을 힙에 추가한다
heap.offer(8);        // 요소 8을 힙에 추가한다
heap.peek();          // 힙의 루트(최솟값)를 삭제하지 않고 반환한다 → 3
heap.poll();          // 힙의 루트(최솟값)를 삭제하고 반환한다 → 3
heap.size();          // 힙 내의 요소 수를 반환한다 → 2
```

### 왜 Min-Heap으로 K번째로 큰 요소를 알 수 있는가

크기 K인 Min-Heap에는 상위 K개의 큰 요소가 들어 있다. 힙의 루트는 그중에서 가장 작은 값, 즉 "상위 K개 중의 최솟값" = "전체에서 K번째로 큰 요소"이다.
예: k=3, 힙의 내용이 [4, 5, 8]일 때, 루트는 4이다. 이것은 전체에서 3번째로 큰 요소이다.

## 계산량

| | 값 |
|---|---|
| Time | O(log k) — add 메서드 1회당, 크기 K인 힙에 대한 삽입과 삭제가 각각 O(log k)로 수행된다 |
| Space | O(k) — 힙에는 항상 최대 K개의 요소만 유지한다 |

## 코드

```java
// 입력: 정수 k, 초기 정수 배열 nums, 그리고 add 메서드에 전달되는 정수 val
// 출력: add 메서드는, 스트림 전체에서 K번째로 큰 요소를 int로 반환한다
class KthLargest {
    // K는 힙의 크기 상한으로 계속 사용하므로, 필드에 보관한다
    int k;
    // PriorityQueue는 기본적으로 Min-Heap(최솟값이 루트)으로 동작한다
    PriorityQueue<Integer> heap;

    // 생성자: k와 초기 배열을 받아서 힙을 구축한다
    KthLargest(int k, int[] nums) {
        this.k = k;
        heap = new PriorityQueue<>();
        // add 메서드 내에서 힙의 크기 제한이 수행되므로, 초기화 전용 로직은 불필요하다
        for (int n : nums) {
            add(n);
        }
    }

    // 새로운 값을 추가하고, K번째로 큰 요소를 반환한다
    int add(int val) {
        // 힙의 끝에 요소를 삽입하고, 힙의 성질을 유지하도록 부모 방향으로 이동한다 (O(log k))
        heap.offer(val);

        // 크기가 K를 초과한 경우, K번째보다 작은 요소가 하나 초과하여 존재한다
        if (heap.size() > k) {
            // Min-Heap의 루트는 항상 최솟값이므로, 삭제되는 것은 K번째보다 작은 값이다
            heap.poll();
        }

        // 힙의 크기가 정확히 K일 때, 루트는 힙 내의 최솟값 = 전체에서 K번째로 큰 요소이다
        return heap.peek();
    }
}
```
