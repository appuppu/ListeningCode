# Longest Substring After Replacing K Characters — K번의 문자 치환으로 얻을 수 있는 최장 동일 문자 부분 문자열을 구한다

## 문제의 본질

대문자 영문자로 이루어진 문자열 `s`와 정수 `k`가 주어진다. 문자열 중 최대 `k`개의 문자를 임의의 문자로 치환할 수 있을 때, **모든 문자가 동일한** 부분 문자열의 최대 길이를 반환한다.

## 핵심 아이디어

윈도우 내에서 "가장 많이 등장하는 문자의 출현 횟수"를 파악하면, "치환이 필요한 문자 수 = 윈도우 크기 − 최빈 문자의 출현 횟수"로 계산할 수 있다. 이 치환 횟수가 `k` 이하인 한 윈도우를 계속 확장하면, 최장 부분 문자열을 구할 수 있다.

## 사고 프로세스

1. **부분 문자열을 전수 탐색하는 것은 비효율적이다**: 모든 부분 문자열을 열거하면 O(n²)이 소요된다. 연속하는 구간을 다루므로, Sliding Window 패턴이 적합하다
2. **윈도우 내에서 치환이 필요한 문자 수를 구하고자 한다**: 윈도우 내의 모든 문자를 동일하게 만들려면, 가장 출현 횟수가 많은 문자 이외를 치환하면 된다. 따라서 치환이 필요한 문자 수는 `윈도우 크기 − 최빈 문자의 출현 횟수`로 구할 수 있다
3. **각 문자의 출현 횟수를 추적하는 수단**: 대문자 영문자는 26종류밖에 없으므로, 크기 26인 배열 `count`로 각 문자의 출현 횟수를 관리할 수 있다. 윈도우의 확장·축소에 맞춰 증가·감소시킨다
4. **최빈 문자의 출현 횟수를 효율적으로 관리한다**: 오른쪽 포인터를 진행시킬 때마다, 추가한 문자의 출현 횟수와 현재의 `maxFreq`를 비교하여 더 큰 쪽을 `maxFreq`로 설정한다. 왼쪽 포인터를 진행시켜 문자를 제외해도 `maxFreq`는 줄이지 않는다. 그 이유는, 최대 길이를 구하는 문제에서는 과거에 달성한 `maxFreq`보다 작은 값으로 갱신해도 더 긴 결과를 얻을 수 없기 때문이다
5. **윈도우의 축소 조건**: `윈도우 크기 − maxFreq > k`일 때, 치환 횟수가 `k`를 초과하고 있으므로 왼쪽 포인터를 1칸 진행시켜 윈도우를 축소한다. 이 조건이 충족되지 않을 때까지 반복한다
6. **최대 길이의 갱신**: 윈도우가 유효(치환 수 ≤ k)할 때마다, `right − left + 1`과 현재의 `maxLen`을 비교하여 더 큰 쪽을 `maxLen`으로 기록한다

## 전제 지식

### Sliding Window(슬라이딩 윈도우)란

배열이나 문자열 위의 연속하는 구간을 두 개의 포인터(left, right)로 관리하는 기법이다. right를 진행시켜 윈도우를 확장하고, 조건을 충족하지 못하게 되면 left를 진행시켜 윈도우를 축소한다. 각 요소를 최대 2번(추가와 삭제에서 각 1번)만 처리하므로, O(n)으로 동작한다.

### 문자의 출현 횟수를 배열로 관리하는 방법

대문자 영문자는 `'A'`〜`'Z'`의 26문자이므로, `int[26]` 배열로 각 문자의 출현 횟수를 관리할 수 있다. 문자에서 인덱스로의 변환은 `charAt() - 'A'`로 수행한다.

```java
int[] count = new int[26];           // 26문자분의 출현 횟수를 저장하는 배열
count[s.charAt(i) - 'A']++;         // 문자 s.charAt(i)의 출현 횟수를 1 증가시킨다
count[s.charAt(i) - 'A']--;         // 문자 s.charAt(i)의 출현 횟수를 1 감소시킨다
```

### maxFreq를 줄이지 않는 이유

`maxFreq`는 윈도우 내 최빈 문자의 출현 횟수이다. 왼쪽 포인터를 진행시켜 문자를 제외해도 `maxFreq`를 재계산하여 줄일 필요는 없다. 최대 길이를 구하는 문제에서는, `maxFreq`가 과거의 최댓값보다 작아지더라도 그 상태에서 얻을 수 있는 윈도우 크기는 과거의 최대 길이를 초과할 수 없다. 따라서 `maxFreq`를 단조 증가 상태로 관리해도 올바른 결과를 얻을 수 있다.

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 오른쪽 포인터와 왼쪽 포인터가 각각 최대 n번 진행하는 것으로 충분하다 |
| Space | O(1) — 사용하는 배열의 크기가 26으로 고정되어 있으며, 입력 크기에 의존하지 않는다 |

## 코드

```java
// 입력: 대문자 영문자로 이루어진 문자열 s와 정수 k(최대 치환 횟수)
// 출력: 최대 k번의 치환으로 모든 문자를 동일하게 만들 수 있는 부분 문자열의 최대 길이를 int로 반환한다
public int characterReplacement(String s, int k) {
    // 각 문자(A〜Z)의 출현 횟수를 관리하는 배열. 인덱스 0이 'A', 25가 'Z'에 대응한다
    int[] count = new int[26];
    // left: 윈도우의 왼쪽 끝
    int left = 0;
    // maxFreq: 윈도우 내에서 가장 많이 출현하는 문자의 횟수(단조 증가로 관리한다)
    int maxFreq = 0;
    // maxLen: 조건을 충족하는 부분 문자열의 최대 길이(최종적으로 이 값을 반환한다)
    int maxLen = 0;

    // 오른쪽 포인터를 1칸씩 진행시켜 윈도우의 오른쪽 끝을 확장한다
    for (int right = 0; right < s.length(); right++) {
        // 오른쪽 끝에 추가한 문자의 출현 횟수를 1 증가시킨다
        count[s.charAt(right) - 'A']++;

        // 추가한 문자의 출현 횟수와 현재의 maxFreq를 비교하여, 최빈 문자의 출현 횟수를 갱신한다
        maxFreq = Math.max(maxFreq, count[s.charAt(right) - 'A']);

        // 윈도우 크기 - maxFreq = 치환이 필요한 문자 수. 이 값이 k를 초과하는 동안, 왼쪽 끝을 축소한다
        // 주의: maxFreq는 여기서 재계산하지 않는다. 줄여도 최대 길이의 갱신에 기여하지 않기 때문이다
        while (right - left + 1 - maxFreq > k) {
            // 왼쪽 끝 문자의 출현 횟수를 1 감소시켜 윈도우에서 제외한다
            count[s.charAt(left) - 'A']--;
            left++;
        }

        // 윈도우가 유효(치환 수 ≤ k)하므로, 현재 윈도우 크기로 최대 길이를 갱신한다
        maxLen = Math.max(maxLen, right - left + 1);
    }
    // for 루프 종료 후, 최대 k번의 치환으로 얻을 수 있는 최장 동일 문자 부분 문자열의 길이를 반환한다
    return maxLen;
}
```
