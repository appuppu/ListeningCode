# Finding the Longest Substring Without Repeating Characters — 중복 문자를 포함하지 않는 최장 부분 문자열의 길이를 구하기

## 문제의 본질

문자열 `s`가 주어진다. `s` 안에서 같은 문자가 2번 이상 출현하지 않는 연속 부분 문자열(substring)을 찾아, 그 **최대 길이**를 정수로 반환한다.

## 핵심 아이디어

슬라이딩 윈도우를 사용하면 모든 유효한 부분 문자열을 O(n)으로 검사할 수 있다. 중복이 발견되었을 때, 왼쪽 끝을 "중복 문자의 이전 출현 위치+1"까지 한 번에 점프시킴으로써 불필요한 한 칸씩의 이동을 생략할 수 있다.

## 사고 프로세스

1. **부분 문자열 탐색을 윈도우로 표현한다**: "중복 없는 부분 문자열"은 왼쪽 끝 `left`와 오른쪽 끝 `right`의 두 포인터로 둘러싸인 구간으로 표현할 수 있다. 오른쪽 끝을 하나씩 전진시켜 윈도우를 넓히고, 중복이 발생하면 왼쪽 끝을 이동시켜 윈도우를 줄인다
2. **중복 검출에는 HashMap을 사용한다**: 각 문자의 "마지막으로 출현한 인덱스"를 HashMap에 기록해 두면, 새로운 문자가 윈도우 내에 이미 존재하는지를 O(1)으로 판정할 수 있다
3. **왼쪽 끝의 점프 조건을 정확히 정한다**: `right`의 문자가 HashMap에 존재하는 것만으로는 불충분하다. 그 문자의 이전 출현 위치가 `left` 이상(즉, 현재 윈도우 내)인 경우에만 중복으로 간주한다. 윈도우 밖의 오래된 기록은 무시한다
4. **왼쪽 끝의 이동 목적지를 결정한다**: 중복이 검출되면 `left`를 "중복 문자의 이전 출현 위치 + 1"로 갱신한다. 이렇게 함으로써 중복 문자를 윈도우에서 제거하면서도, 그 외의 유효한 문자는 윈도우 내에 남길 수 있다
5. **HashMap의 갱신 타이밍**: 중복 판정 후에 현재 문자의 인덱스를 HashMap에 등록(덮어쓰기)한다. 이를 통해 항상 각 문자의 최신 출현 위치가 기록된다
6. **최대 길이의 갱신**: 각 단계에서 `right - left + 1`(현재 윈도우 너비)을 계산하고, 지금까지의 최댓값과 비교하여 갱신한다

## 전제 지식

### 슬라이딩 윈도우란

배열이나 문자열 위에서 두 개의 포인터(`left`, `right`)가 정의하는 구간을 "창"으로 삼아 이동시키면서, 조건을 만족하는 부분을 탐색하는 기법이다. 오른쪽 끝을 전진시켜 창을 넓히고, 조건 위반 시에 왼쪽 끝을 전진시켜 창을 줄인다. 각 포인터는 앞쪽으로만 이동하므로 전체적으로 O(n)의 계산량이 된다.

### HashMap이란

키와 값의 쌍을 저장하는 데이터 구조이다. 키를 지정하여 값의 검색·취득을 O(1)으로 수행할 수 있다. 이 문제에서는 키에 "문자", 값에 "해당 문자가 마지막으로 출현한 인덱스"를 저장한다.

```java
HashMap<Character, Integer> map = new HashMap<>();  // 빈 HashMap을 생성한다
map.put('a', 0);            // 키 'a'에 값 0을 저장한다
map.containsKey('a');       // 키 'a'가 존재하는지를 boolean으로 반환한다 → true
map.get('a');               // 키 'a'에 대응하는 값을 반환한다 → 0
```

### charAt이란

문자열의 지정된 위치에 있는 문자를 취득하는 메서드이다. `s.charAt(i)`는 문자열 `s`의 인덱스 `i`에 있는 `char`를 반환한다.

```java
String s = "abc";
char c = s.charAt(0);  // 'a'를 반환한다
char d = s.charAt(2);  // 'c'를 반환한다
```

### Math.max란

두 값 중 더 큰 쪽을 반환하는 메서드이다. 최댓값을 계속 갱신하는 장면에서 사용한다.

```java
int result = Math.max(3, 7);  // 7을 반환한다
maxLength = Math.max(maxLength, currentLength);  // 현재의 최댓값을 갱신한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — `right`가 문자열을 1회 순회하는 것만으로 충분하다. `left`도 앞쪽으로만 이동하므로 전체적으로 O(n)이다 |
| Space | O(n) — HashMap에 최대 n개의 문자와 인덱스 쌍을 저장한다 |

## 코드

```java
// 입력: 문자열 s
// 출력: 중복 문자를 포함하지 않는 최장 부분 문자열의 길이를 int로 반환한다
public int lengthOfLongestSubstring(String s) {
    // 윈도우의 왼쪽 끝 포인터. 초기 위치는 문자열의 맨 앞이다
    int left = 0;
    // 순회 중에 발견한 최장 윈도우 너비를 기록하는 변수이다
    int maxLength = 0;
    // 키=문자, 값=해당 문자가 마지막으로 출현한 인덱스를 저장하는 HashMap이다
    // 중복 판정과 왼쪽 끝의 점프 목적지 계산 양쪽 모두에 사용한다
    HashMap<Character, Integer> hashMap = new HashMap<>();

    // right는 윈도우의 오른쪽 끝을 나타내는 포인터이다. 하나씩 전진시켜 윈도우를 넓힌다
    for (int right = 0; right < s.length(); right++) {
        // 지금 윈도우에 추가하려는 문자를 취득한다
        char curChar = s.charAt(right);

        // containsKey: 이 문자가 과거에 출현했는지를 판정한다
        // get(curChar) >= left: 그 출현 위치가 현재 윈도우 내인지를 확인한다
        // 양쪽 모두 참일 때, 윈도우 내에 중복이 존재한다
        if (hashMap.containsKey(curChar) && hashMap.get(curChar) >= left) {
            // 중복 문자의 이전 출현 위치+1로 왼쪽 끝을 점프시켜 중복을 해소한다
            // left는 항상 앞쪽으로만 이동하므로, 과거로 되돌아가는 일은 없다
            left = hashMap.get(curChar) + 1;
        }

        // 현재 문자의 출현 위치를 최신 인덱스로 덮어써서 등록한다
        // 다음에 이 문자가 출현했을 때, 여기서 기록한 인덱스로 왼쪽 끝의 점프 목적지를 계산한다
        hashMap.put(curChar, right);
        // right - left + 1은 현재 윈도우 너비(중복 없는 부분 문자열의 길이)이다
        // 과거의 최댓값을 초과하면 갱신한다
        maxLength = Math.max(maxLength, right - left + 1);
    }
    // 이것이 중복 문자를 포함하지 않는 최장 부분 문자열의 길이이다
    return maxLength;
}
```
