# Finding the Best Time to Buy and Sell a Stock — 주가 배열에서 1회 매매로 얻을 수 있는 최대 이익을 구한다

## 문제의 본질

정수 배열 `prices`가 주어진다. 각 요소 `prices[i]`는 `i`번째 날의 주가를 나타낸다. 1회만 "매수→매도"를 할 수 있는 조건에서, 얻을 수 있는 **최대 이익**을 반환한다. 이익이 발생하지 않는 경우에는 `0`을 반환한다. 매수는 매도보다 이전 날에 이루어져야 한다.

## 핵심 아이디어

배열을 왼쪽부터 순회하면서 "지금까지의 최저가"를 계속 기록하면, 각 날의 가격에서 최저가를 빼는 것만으로 그 날에 매도했을 때의 최대 이익을 O(1)로 구할 수 있다. 모든 날에 대해 이 이익의 최댓값을 취하면 답이 된다.

## 사고 과정

1. **이익은 "매도가 − 매수가"로 결정된다**: 어떤 날에 매도할 때, 이익을 최대화하려면 매수가를 최대한 낮추면 된다. 즉, 매도하는 날 이전의 모든 날 중 최저가에 매수하면 된다
2. **각 날에서 "그 이전의 최저가"를 효율적으로 구하고 싶다**: 배열을 왼쪽부터 순회하면서, 지금까지 본 가격의 최솟값을 변수 `minPrice`로 추적한다. 새로운 가격을 볼 때마다 `minPrice`를 갱신하기만 하면 되므로, 추가 배열이 불필요하고 O(1)의 공간으로 충분하다
3. **각 날의 "매도했을 때의 이익"을 계산한다**: 순회 중 각 날 `i`에 대해, `prices[i] - minPrice`가 그 날에 매도했을 때의 최대 이익이다. 이 값을 변수 `maxProfit`과 비교하여, 더 크면 `maxProfit`을 갱신한다
4. **minPrice 갱신과 이익 계산의 관계를 정리한다**: 현재 가격이 `minPrice`보다 작은 경우에는 `minPrice`를 갱신한다. 이 날에 매도해도 이익은 음수이므로 이익 계산은 불필요하다. 현재 가격이 `minPrice` 이상인 경우에는 이익을 계산하여 `maxProfit`을 갱신한다
5. **이익이 발생하지 않는 경우의 처리**: 주가가 단조 감소하는 경우, `maxProfit`은 초기값 `0`인 채로 갱신되지 않는다. 조건 분기 없이 자연스럽게 `0`이 반환된다
6. **최종적으로 반환하는 것**: 배열을 1회 순회한 시점의 `maxProfit` 값을 반환한다. 이것이 1회 매매로 얻을 수 있는 최대 이익이다

## 전제 지식

### Integer.MAX_VALUE란

Java의 `int` 타입이 가질 수 있는 최대 값(2,147,483,647)이다. 최솟값을 찾는 알고리즘에서 초기값으로 사용한다. 어떤 주가보다도 큰 것이 보장되므로, 첫 번째 비교에서 반드시 실제 주가로 대체된다.

```java
int minPrice = Integer.MAX_VALUE;  // 최솟값의 초기값으로 충분히 큰 값을 설정한다
// prices[0]이 예를 들어 7인 경우, 7 < Integer.MAX_VALUE이므로 minPrice는 7로 갱신된다
```

### Math.max란

2개의 `int` 값을 받아서 큰 쪽을 반환하는 정적 메서드이다. 최댓값 갱신 처리를 1줄로 작성할 수 있다.

```java
int a = 5;
int b = 3;
Math.max(a, b);  // → 5를 반환한다

// 최대 이익의 갱신에 사용한다
maxProfit = Math.max(maxProfit, profit);  // profit이 더 크면 maxProfit을 갱신한다
```

### Running Minimum(순회 중 최솟값 추적)이란

배열을 순회하면서, 그때까지 본 요소의 최솟값을 변수로 추적하는 기법이다. 각 단계에서 현재 요소와 변수를 비교하여, 작은 쪽으로 변수를 갱신한다. 이를 통해 임의의 위치에서 "해당 위치 이전의 최솟값"을 O(1)로 얻을 수 있다.

```java
int minPrice = Integer.MAX_VALUE;
for (int price : prices) {
    if (price < minPrice) {
        minPrice = price;  // 지금까지의 최저가를 갱신한다
    }
    // 이 시점에서 minPrice는 prices[0]~prices[현재]의 최솟값을 보유하고 있다
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 1회 순회하는 것만으로 충분하다 |
| Space | O(1) — 변수 2개(minPrice, maxProfit)만 사용한다 |

## 코드

```java
// 입력: 정수 배열 prices (각 요소는 날짜별 주가)
// 출력: 1회 매매로 얻을 수 있는 최대 이익을 int로 반환한다. 이익이 발생하지 않는 경우에는 0을 반환한다
public int maxProfit(int[] prices) {
    // 지금까지의 최저가를 추적하는 변수. Integer.MAX_VALUE로 초기화하여, 첫 번째 가격과의 비교에서 반드시 실제 주가로 갱신된다
    int minPrice = Integer.MAX_VALUE;
    // 지금까지의 최대 이익을 추적하는 변수. 0으로 초기화하여, 이익이 발생하지 않는 경우에는 자연스럽게 0이 반환된다
    int maxProfit = 0;

    // for-each 루프로 배열을 처음부터 끝까지 하나씩 순회한다
    for (int price : prices) {
        if (price < minPrice) {
            // 현재 가격이 최저가보다 작으면 최저가를 갱신한다
            // 이 날은 최저가 갱신일이므로, 이 날에 매도해도 이익이 발생하지 않는다 (이익이 음수가 된다). 따라서 이익 계산을 건너뛴다
            minPrice = price;
        } else {
            // 최저가인 날에 매수하고 오늘 매도했을 때의 이익을 계산한다
            int profit = price - minPrice;
            // 이익이 지금까지의 최대를 초과하면 최대 이익을 갱신한다
            maxProfit = Math.max(maxProfit, profit);
        }
    }
    // 루프 종료 시점의 maxProfit이 배열 전체에 걸친 최대 이익이다
    return maxProfit;
}
```
