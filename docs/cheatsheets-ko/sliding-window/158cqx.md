# Checking if a String Contains a Permutation of Another — 문자열이 다른 문자열의 순열을 포함하는지 판정하기

## 문제의 본질

2개의 문자열 `s1`과 `s2`가 주어진다. `s2` 안에 `s1`의 아나그램(문자의 재배열)이 **연속하는 부분 문자열**로 존재하는지를 판정하여, 존재하면 `true`를, 존재하지 않으면 `false`를 반환한다.

## 핵심 아이디어

`s1`의 순열이 `s2`에 포함된다는 것은, `s2` 내에 `s1`과 같은 길이이면서 같은 문자 빈도를 가지는 부분 문자열이 존재한다는 것이다. 고정 길이의 슬라이딩 윈도우로 `s2`를 탐색하고, 26개 문자의 빈도가 일치하는 수를 차분 갱신함으로써, 각 슬라이드를 O(1)로 판정할 수 있다.

## 사고 프로세스

1. **순열의 조건을 바꿔 말하기**: `s1`의 순열이 `s2`의 부분 문자열로 존재한다는 것은, `s2` 내에 길이 `m`(= `s1`의 길이)인 부분 문자열 중 각 문자의 출현 횟수가 `s1`과 완전히 일치하는 것이 존재한다는 것이다
2. **고정 길이 윈도우로 탐색하기**: 부분 문자열의 길이는 항상 `m`이므로, `s2` 위에 길이 `m`의 고정 크기 윈도우를 놓고 1문자씩 슬라이드하면서 문자 빈도를 비교하면 된다
3. **빈도 배열로 문자의 출현 횟수를 관리하기**: 영어 소문자는 26종류이므로, 크기 26의 정수 배열 2개(`s1F`와 `winF`)로 `s1`과 윈도우 내의 문자 빈도를 각각 관리한다. 배열의 각 인덱스가 각 문자에 대응한다
4. **매번 26개 요소를 비교하는 것은 비효율적이다**: 윈도우를 슬라이드하면 변화하는 문자는 "새로 들어오는 1문자"와 "나가는 1문자"의 최대 2개뿐이다. 26개 요소를 매번 비교하는 대신, "26문자 중 빈도가 일치하는 문자 수"를 `matches` 카운터로 추적하고, 차분만 갱신한다
5. **matches 카운터의 갱신 규칙**: 특정 문자의 빈도를 변경할 때, 변경 전에 일치했으면 `matches`를 1 줄이고, 변경 후에 일치하면 `matches`를 1 늘린다. 이 "변경 전 판정 → 값 변경 → 변경 후 판정"의 순서를 지킴으로써 카운터의 정합성을 유지한다
6. **판정 조건**: `matches`가 26이 된 시점에서 전체 26문자의 빈도가 일치하므로 `true`를 반환한다. `s2`의 끝까지 슬라이드해도 26이 되지 않으면 `false`를 반환한다

## 전제 지식

### 슬라이딩 윈도우란

배열이나 문자열 위의 연속하는 부분 구간을, 왼쪽 끝과 오른쪽 끝을 이동시키면서 탐색하는 기법이다. 고정 길이 윈도우의 경우, 오른쪽 끝을 1칸 전진시킴과 동시에 왼쪽 끝도 1칸 전진시켜 윈도우 크기를 일정하게 유지한다.

```java
// 길이 m의 고정 윈도우를 s2 위에서 슬라이드하는 기본 형태
for (int i = m; i < n; i++) {
    char entering = s2.charAt(i);       // 윈도우에 새로 들어오는 문자 (오른쪽 끝)
    char leaving = s2.charAt(i - m);    // 윈도우에서 나가는 문자 (왼쪽 끝)
}
```

### 빈도 배열이란

각 문자의 출현 횟수를 저장하는 크기 26의 정수 배열이다. `'a'`를 인덱스 0, `'z'`를 인덱스 25에 대응시킨다. `charAt(i) - 'a'`로 문자를 인덱스로 변환한다.

```java
int[] freq = new int[26];              // 모든 요소가 0으로 초기화된다
freq[s.charAt(i) - 'a']++;            // 문자의 출현 횟수를 1 증가시킨다
freq[s.charAt(i) - 'a']--;            // 문자의 출현 횟수를 1 감소시킨다
```

### matches 카운터란

2개의 빈도 배열 간에 같은 인덱스의 값이 일치하는 개수를 추적하는 카운터이다. 전체 26개가 일치하면 `matches == 26`이 되어, 두 문자열의 문자 구성이 동일하다는 것을 의미한다.

```java
int matches = 0;
for (int i = 0; i < 26; i++) {
    if (s1F[i] == winF[i]) matches++;  // 일치하는 문자 수를 센다
}
// matches == 26이면 모든 문자의 빈도가 일치한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — `s2`를 1회 탐색하는 것만으로 충분하다 (각 슬라이드는 O(1)) |
| Space | O(1) — 빈도 배열의 크기는 항상 26이며, 입력 크기에 의존하지 않는다 |

## 코드

```java
// 입력: 문자열 s1 (검색 대상의 순열)과 문자열 s2 (검색할 문자열)
// 출력: s2가 s1의 순열을 부분 문자열로 포함하면 true, 포함하지 않으면 false
boolean checkInclusion(String s1, String s2) {
    int m = s1.length();
    int n = s2.length();

    // s1이 s2보다 긴 경우, 순열이 포함될 수 없으므로 즉시 false를 반환한다
    if (m > n) return false;

    // s1의 문자 빈도와 윈도우의 문자 빈도를 저장하는 크기 26의 배열
    int[] s1F = new int[26];
    int[] winF = new int[26];

    // 첫 번째 윈도우 (처음 m개 문자)의 빈도를 계산한다. s1과 s2의 처음 m개 문자를 동시에 카운트한다
    for (int i = 0; i < m; i++) {
        s1F[s1.charAt(i) - 'a']++;
        winF[s2.charAt(i) - 'a']++;
    }

    // 26개 문자 중 빈도가 일치하는 문자 수를 센다 (초기 matches 계산)
    int matches = 0;
    for (int i = 0; i < 26; i++) {
        if (s1F[i] == winF[i]) matches++;
    }

    // 첫 번째 윈도우에서 전체 26개 문자의 빈도가 일치하면 true를 반환한다
    if (matches == 26) return true;

    // 윈도우를 1문자씩 오른쪽으로 슬라이드한다 (i는 윈도우 오른쪽 끝의 다음 위치)
    for (int i = m; i < n; i++) {
        // --- 새로 윈도우에 들어오는 문자 (오른쪽 끝) 처리 ---
        int idx = s2.charAt(i) - 'a';
        // 주의: "변경 전 판정 → 값 변경 → 변경 후 판정"의 순서를 반드시 지켜야 한다
        if (winF[idx] == s1F[idx]) matches--;   // 변경 전에 일치했으면 matches를 줄인다
        winF[idx]++;                              // 윈도우에 들어오므로 빈도를 1 증가시킨다
        if (winF[idx] == s1F[idx]) matches++;   // 변경 후에 일치하면 matches를 늘린다

        // --- 윈도우에서 나가는 문자 (왼쪽 끝) 처리 ---
        idx = s2.charAt(i - m) - 'a';
        // 들어오는 문자와 같은 절차: 변경 전 판정 → 값 변경 → 변경 후 판정
        if (winF[idx] == s1F[idx]) matches--;   // 변경 전에 일치했으면 matches를 줄인다
        winF[idx]--;                              // 윈도우에서 나가므로 빈도를 1 감소시킨다
        if (winF[idx] == s1F[idx]) matches++;   // 변경 후에 일치하면 matches를 늘린다

        // 전체 26개 문자의 빈도가 일치하면 순열을 찾은 것이므로 true를 반환한다
        if (matches == 26) return true;
    }

    // s2의 끝까지 슬라이드해도 matches==26이 되지 않았으므로 false를 반환한다
    return false;
}
```
