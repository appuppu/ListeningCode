# Finding the Maximum in Each Sliding Window — 슬라이딩 윈도우 내의 최댓값을 구하기

## 문제의 본질

정수 배열 `nums`와 윈도우 크기 `k`가 주어진다. 크기 `k`의 윈도우를 배열의 왼쪽 끝에서 오른쪽 끝까지 하나씩 슬라이드시키며, 각 위치에서 윈도우 내의 **최댓값**을 구한다. 모든 최댓값을 배열로 반환한다.

## 핵심 아이디어

Deque(양방향 큐)에 인덱스를 "값이 단조 감소가 되도록" 유지하면, Deque의 선두가 항상 윈도우 내의 최댓값을 가리킨다. 새로운 요소가 오면 끝에서부터 자신 이하의 요소를 제거하고, 선두가 윈도우 밖이면 제거함으로써, 각 단계에서 O(1)의 상각 비용으로 최댓값을 얻을 수 있다.

## 사고 프로세스

1. **각 윈도우의 최댓값이 필요하다**: 윈도우를 하나 슬라이드할 때마다, 추가되는 요소와 제거되는 요소는 각각 하나씩이다. 매번 윈도우 전체를 순회하여 O(k)로 최댓값을 구하면 전체적으로 O(nk)가 되므로, 최댓값을 효율적으로 관리하는 데이터 구조가 필요하다
2. **최댓값 후보만 유지하면 된다**: 윈도우 내에 요소 A와 B가 있고, A가 B보다 왼쪽에 있으며, A의 값이 B 이하라면, A는 앞으로 어떤 윈도우에서도 최댓값이 될 수 없다. B가 더 오른쪽에 있으므로 먼저 윈도우에서 나가는 일도 없다. 따라서 A는 후보에서 제외해도 된다
3. **단조 감소 Deque로 후보를 관리한다**: 후보를 값이 큰 순서로 유지하면, 선두가 항상 최댓값이 된다. 새로운 요소를 추가할 때, 끝에서부터 자신 이하의 요소를 모두 제거하면, 단조 감소 성질이 유지된다. 이 연산에는 Deque(양방향 큐)가 적합하다
4. **Deque에는 인덱스를 저장한다**: 요소가 윈도우 밖으로 나갔는지 판정하려면 위치 정보가 필요하므로, Deque에는 값이 아닌 인덱스를 저장한다. 값은 `nums[index]`로 참조할 수 있다
5. **선두의 윈도우 밖 체크**: 각 단계에서, Deque의 선두 인덱스가 현재 윈도우의 왼쪽 끝 `i - k + 1`보다 작은 경우, 해당 요소는 윈도우에서 나간 것이므로 선두에서 제거한다
6. **결과 기록 시점**: 인덱스 `i`가 `k - 1` 이상이 된 시점에서 윈도우가 완성되어 있으므로, Deque의 선두가 가리키는 값을 결과 배열에 기록한다

## 사전 지식

### ArrayDeque(양방향 큐)란

선두와 끝 양쪽에서 요소의 추가·조회·삭제가 O(1)로 가능한 데이터 구조이다. 스택과 큐 양쪽의 기능을 겸비하고 있다.

```java
ArrayDeque<Integer> deque = new ArrayDeque<>();  // 빈 Deque를 생성한다
deque.offerLast(5);       // 끝에 5를 추가한다
deque.offerLast(3);       // 끝에 3을 추가한다 → Deque의 내용: [5, 3]
deque.peekFirst();        // 선두의 요소를 조회한다 (삭제하지 않음) → 5
deque.peekLast();         // 끝의 요소를 조회한다 (삭제하지 않음) → 3
deque.pollFirst();        // 선두의 요소를 조회하고 삭제한다 → 5
deque.pollLast();         // 끝의 요소를 조회하고 삭제한다 → 3
deque.isEmpty();          // Deque가 비어 있는지를 boolean으로 반환한다 → true
```

### 단조 감소 Deque(Monotonic Deque)란

Deque 내의 요소가 선두에서 끝을 향해 항상 감소(또는 같지 않은) 상태를 유지하는 Deque이다. 새로운 요소를 추가할 때, 끝에서부터 자신 이하의 요소를 모두 제거함으로써 단조 감소를 유지한다.
예: Deque=[7, 5, 3]에 6을 추가 → 5와 3을 제거 → Deque=[7, 6]. 선두는 항상 최댓값을 가리킨다.

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 각 요소는 Deque에 최대 1번 추가되고, 최대 1번 제거되므로, 전체적으로 O(n)이 된다 |
| Space | O(k) — Deque에는 윈도우 크기 k 이하의 요소만 유지된다 |

## 코드

```java
// 입력: 정수 배열 nums와 정수 k (윈도우 크기)
// 출력: 각 윈도우 위치에서의 최댓값을 저장한 int[]를 반환한다. 요소 수는 n - k + 1개이다
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    // 각 윈도우의 최댓값을 저장하는 결과 배열. 윈도우는 n - k + 1개 존재한다
    int[] result = new int[n - k + 1];
    // 최댓값 후보의 인덱스를 단조 감소로 유지하는 Deque
    // Deque에는 "윈도우 내에서 최댓값이 될 가능성이 있는 인덱스"를, 대응하는 값이 단조 감소가 되도록 유지한다
    ArrayDeque<Integer> deque = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // 선두의 인덱스가 윈도우의 왼쪽 끝 i - k + 1보다 작으면 윈도우 밖이므로 제거한다
        // 윈도우는 하나씩 슬라이드하므로, 윈도우 밖이 되는 요소는 각 단계에서 최대 1개이다
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }

        // 끝에서부터 현재 요소 nums[i] 이하의 후보를 모두 제거하여 단조 감소를 유지한다
        // 이 요소들은 nums[i]가 존재하는 한 최댓값이 될 수 없으므로, 후보에서 제외해도 된다
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }

        // 현재 인덱스를 Deque의 끝에 추가한다
        // 위의 while에서 자신 이하의 요소를 제거했으므로, 추가 후에도 Deque는 단조 감소를 유지한다
        deque.offerLast(i);

        // i >= k - 1일 때, 윈도우에 k개의 요소가 갖추어져 있다
        // Deque의 선두가 현재 윈도우 내의 최댓값 인덱스를 가리키고 있다
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    // 모든 윈도우의 최댓값이 기록된 result를 반환한다
    return result;
}
```
