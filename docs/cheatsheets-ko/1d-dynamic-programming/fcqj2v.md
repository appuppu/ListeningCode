# Finding the Fewest Coins to Make a Target Amount — 최소 개수의 코인으로 목표 금액 만들기

## 문제의 본질

코인의 액면가가 담긴 배열 `coins`와 목표 금액 `amount`가 주어진다. `coins` 안의 코인을 몇 개든 사용하여 합계가 `amount`이 되는 조합 중에서 **최소 개수**를 반환한다. 어떻게 조합해도 `amount`를 만들 수 없는 경우에는 `-1`을 반환한다.

## 핵심 아이디어

금액 0부터 목표 금액까지 "각 금액을 만드는 데 필요한 최소 개수"를 보텀업으로 계산하면, 금액 `i`의 최소 개수는 "`i`에서 각 코인의 액면가를 뺀 금액의 최소 개수 + 1" 중의 최솟값으로 구할 수 있다.

## 사고 과정

1. **부분 문제로 분해할 수 있다**: 금액 `i`를 만드는 마지막 1개가 코인 `c`라고 하면, 나머지 금액 `i - c`를 만드는 최소 개수를 알고 있다면 `dp[i - c] + 1`로 금액 `i`의 최소 개수를 구할 수 있다. 이 구조는 동적 계획법에 적합하다
2. **어떤 코인이 마지막 1개인지는 사전에 알 수 없다**: 마지막 1개의 후보는 모든 코인 액면가이다. 따라서 모든 코인 `c`에 대해 `dp[i - c] + 1`을 계산하고, 그 최솟값을 `dp[i]`로 한다. 이것이 점화식 `dp[i] = min(dp[i - c] + 1)` for each coin `c`이다
3. **기저 케이스를 결정한다**: 금액 0을 만드는 데 필요한 코인은 0개이므로 `dp[0] = 0`으로 설정한다. 이것이 보텀업 계산의 출발점이 된다
4. **초기값에 "도달 불가"를 나타내는 값을 설정한다**: 각 금액을 만들 수 있는지 여부는 사전에 알 수 없으므로, `dp` 배열의 모든 요소를 `amount + 1`(있을 수 없는 큰 개수)로 초기화한다. 이 값이 갱신되지 않은 금액은 "만들 수 없음"을 의미한다
5. **금액 1부터 순서대로 채워 나간다**: `dp[0]`을 기점으로 금액 1, 2, ..., `amount` 순서로 테이블을 채운다. 금액 `i`를 계산하는 시점에서 `i`보다 작은 모든 금액의 최소 개수는 이미 확정되어 있으므로, `dp[i - c]`를 안전하게 참조할 수 있다
6. **최종적으로 반환하는 것**: `dp[amount]`가 `amount + 1` 그대로라면 목표 금액을 만들 수 없으므로 `-1`을 반환한다. 그렇지 않으면 `dp[amount]`가 최소 개수이다

## 사전 지식

### 동적 계획법(Dynamic Programming)이란

큰 문제를 작은 부분 문제로 분해하고, 각 부분 문제의 해를 테이블에 기록하면서 보텀업으로 해를 구축하는 기법이다. 동일한 부분 문제를 중복으로 푸는 것을 피하기 때문에 계산 효율이 좋다.

```java
// 보텀업 DP의 기본 패턴
int[] dp = new int[n + 1];     // 테이블을 생성한다
dp[0] = baseCase;              // 기저 케이스를 설정한다
for (int i = 1; i <= n; i++) { // 작은 부분 문제부터 순서대로 푼다
    dp[i] = /* dp[i-1] 등 과거의 결과를 사용하여 계산한다 */;
}
return dp[n];                  // 최종 답을 반환한다
```

### Arrays.fill이란

배열의 모든 요소를 지정한 값으로 채우는 Java의 표준 메서드이다. DP 배열의 초기화에 자주 사용된다.

```java
int[] dp = new int[5];       // [0, 0, 0, 0, 0]이 생성된다
Arrays.fill(dp, 100);        // 모든 요소를 100으로 채운다 → [100, 100, 100, 100, 100]
```

### Math.min이란

두 정수 중 작은 쪽을 반환하는 Java의 표준 메서드이다. 여러 후보 중에서 최솟값을 선택할 때 사용한다.

```java
Math.min(3, 7);    // → 3
Math.min(dp[i], dp[i - coin] + 1);  // 현재 값과 새로운 후보 중 작은 쪽을 선택한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(amount × n) — 각 금액마다 n종류의 코인을 순회한다 (n은 coins 배열의 길이) |
| Space | O(amount) — dp 배열에 amount+1개의 요소를 저장한다 |

## 코드

```java
// 입력: 코인의 액면가가 담긴 정수 배열 coins와 목표 금액의 정수 amount
// 출력: 합계가 amount가 되는 코인의 최소 개수를 int로 반환한다. 만들 수 없는 경우에는 -1을 반환한다
int coinChange(int[] coins, int amount) {
    // dp[i] = 금액 i를 만드는 데 필요한 최소 코인 개수
    // 인덱스 0부터 amount까지의 각 금액에 대응하기 위해 크기는 amount + 1이 된다
    int[] dp = new int[amount + 1];

    // 모든 요소를 "도달 불가"를 나타내는 파수꾼 값으로 초기화한다
    // 코인의 액면가는 최소 1이므로 amount개를 초과할 수는 없으며, 이 값이 남아 있으면 "만들 수 없음"으로 판정할 수 있다
    Arrays.fill(dp, amount + 1);

    // 기저 케이스: 금액 0을 만드는 데 필요한 코인은 0개이다. 보텀업 계산의 출발점이다
    dp[0] = 0;

    // 금액 1부터 amount까지 순서대로 테이블을 채운다
    // 작은 금액부터 순서대로 계산함으로써 dp[i - coin]이 이미 확정되어 있음을 보장한다
    for (int i = 1; i <= amount; i++) {
        // 각 코인을 "금액 i를 만드는 마지막 1개"의 후보로서, 모든 액면가에서 최적의 것을 찾는다
        for (int coin : coins) {
            // coin > i인 경우에는 해당 코인으로 금액 i를 만들 수 없으므로 건너뛴다
            if (coin <= i)
                // dp[i - coin] + 1은 "금액 i - coin의 최소 개수에 코인 1개를 추가한 개수"이다
                // 현재의 dp[i]와 비교하여 작은 쪽을 채택한다
                dp[i] = Math.min(dp[i],
                    dp[i - coin] + 1);
        }
    }

    // 파수꾼 값 그대로라면 초기값에서 갱신되지 않았다 = 목표 금액을 만들 수 없으므로 -1을 반환한다
    return dp[amount] > amount
        ? -1 : dp[amount];
}
```
