# Partitioning an Array Into Two Equal Sum Subsets — 배열을 합계가 같은 2개의 부분집합으로 분할할 수 있는지 판정한다

## 문제의 본질

정수 배열 `nums`가 주어진다. 이 배열을 2개의 부분집합으로 분할하여, 각 부분집합의 요소 합계가 같아지도록 만들 수 있는지를 `boolean`으로 반환한다. 요소는 반드시 어느 한쪽 부분집합에 속하며, 중복하여 사용할 수 없다.

## 핵심 아이디어

배열의 합계가 홀수이면 즉시 false로 판정할 수 있다. 합계가 짝수이면, 합계의 절반 `target`을 정확히 만들 수 있는 부분집합이 존재하는지를 묻는 「부분합 문제」로 귀착할 수 있다. 1차원 boolean형 DP 배열을 사용하여, 각 요소를 순서대로 처리하면서 도달 가능한 합계값을 기록해 나가면, `target`에 도달할 수 있는지를 O(n × target)으로 판정할 수 있다.

## 사고 과정

1. **2등분의 조건을 생각한다**: 배열 전체의 합계가 `sum`일 때, 2개의 부분집합의 합계가 각각 같아지려면, 각 부분집합의 합계가 `sum / 2`여야 한다. `sum`이 홀수이면 정수로 2등분할 수 없으므로, 즉시 false를 반환할 수 있다
2. **문제를 「부분합 문제」로 변환한다**: 한쪽 부분집합의 합계가 `target = sum / 2`가 되면, 다른 한쪽도 자동으로 `target`이 된다. 즉, 「배열의 요소에서 합계가 `target`이 되는 부분집합이 존재하는가」라는 부분합 문제로 귀착할 수 있다
3. **DP로 도달 가능한 합계값을 관리한다**: boolean형 배열 `dp`를 준비하고, `dp[j]`는 「지금까지 처리한 요소로 합계 `j`를 만들 수 있는가」를 나타낸다. 초기 상태로 `dp[0] = true`(아무것도 선택하지 않으면 합계는 0)로 설정한다
4. **각 요소로 도달 가능한 합계값을 갱신한다**: 배열의 각 요소 `num`에 대해, 이미 도달 가능한 합계값 `j`에 `num`을 더한 `j + num`도 도달 가능해진다. 이것은 `dp[j]`가 true이면 `dp[j + num]`도 true로 만드는 연산이다
5. **역순으로 순회하여 중복 사용을 방지한다**: 내부 루프를 `target`에서 `num`까지 역순으로 순회한다. 순방향으로 순회하면, 같은 요소를 여러 번 사용한 결과로 `dp`가 갱신되어 버린다. 역순이면 각 요소는 최대 1번만 사용된다
6. **최종적으로 `dp[target]`을 반환한다**: 모든 요소를 처리한 후, `dp[target]`이 true이면 합계가 `target`인 부분집합이 존재하므로 true를 반환하고, false이면 그러한 부분집합은 존재하지 않는다

## 전제 지식

### 부분합 문제(Subset Sum Problem)란

주어진 정수 집합에서, 몇 개의 요소를 선택하여 합계가 정확히 목표값이 되는지를 판정하는 문제이다. DP(동적 계획법)로 효율적으로 풀 수 있는 대표적인 문제이다.

### boolean형 1차원 DP 배열이란

`dp[j]`가 「합계 `j`를 만드는 것이 가능한가」를 true/false로 나타내는 배열이다. 요소를 하나씩 처리할 때마다, 도달 가능한 합계값의 집합이 확장되어 간다.

```java
boolean[] dp = new boolean[target + 1];  // 크기 target+1의 배열을 생성한다 (초기값은 모두 false)
dp[0] = true;                            // 아무것도 선택하지 않는 경우, 합계 0은 항상 도달 가능하다
dp[j - num] == true                      // 합계 j-num을 만들 수 있으면, num을 더하여 합계 j도 만들 수 있다
```

### DP 배열을 역순으로 갱신하는 이유

순방향(작은 `j`에서 큰 `j`)으로 갱신하면, 같은 요소 `num`을 여러 번 사용한 결과가 전파된다. 역방향(큰 `j`에서 작은 `j`)으로 갱신하면, 각 요소가 1번만 사용되는 것이 보장된다.

```java
// 역순 루프: j = target에서 num까지 1씩 감소
for (int j = target; j >= num; j--) {
    if (dp[j - num]) dp[j] = true;
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(n × target) — n개의 요소 각각에 대해, 최대 target까지의 DP 배열을 순회한다 |
| Space | O(target) — 크기 target+1의 boolean형 DP 배열을 1개 사용한다 |

## 코드

```java
// 입력: 정수 배열 nums
// 출력: 배열을 합계가 같은 2개의 부분집합으로 분할할 수 있는지를 boolean으로 반환한다
boolean canPartition(int[] nums) {
    // 배열의 모든 요소의 합계를 계산하여, 2등분이 가능한지를 판단하기 위한 기준값을 구한다
    int sum = 0;
    for (int n : nums) sum += n;

    // 합계가 홀수이면 정수로 2등분할 수 없으므로 false를 반환한다
    if (sum % 2 != 0) return false;

    // 한쪽 부분집합이 달성해야 할 목표 합계값. 다른 한쪽도 자동으로 target이 된다
    int target = sum / 2;

    // dp[j] = 지금까지 처리한 요소로 합계 j를 만들 수 있는가 (부분합 문제의 DP 배열)
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;  // 아무것도 선택하지 않으면 합계 0은 항상 도달 가능하다

    // 배열의 각 요소를 처음부터 끝까지 하나씩 처리하여, 도달 가능한 합계값의 집합을 갱신한다
    for (int num : nums) {
        // 역순으로 순회하여 같은 요소의 중복 사용을 방지한다 (순방향이면 num을 여러 번 더한 결과가 전파된다)
        for (int j = target; j >= num; j--) {
            // 합계 j-num을 만들 수 있으면, num을 더하여 합계 j도 만들 수 있으므로 true로 갱신한다
            if (dp[j - num]) dp[j] = true;
        }
    }

    // dp[target]이 true이면 합계가 target인 부분집합이 존재하므로 2등분이 가능하다
    return dp[target];
}
```
