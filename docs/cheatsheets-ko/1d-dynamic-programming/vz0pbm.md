# Finding the Minimum Cost to Climb Stairs — 계단 꼭대기에 도달하는 최소 비용을 구하기

## 문제의 본질

정수 배열 `cost`가 주어지며, `cost[i]`는 i번째 계단을 밟는 비용을 나타낸다. 스텝 0 또는 스텝 1에서 시작할 수 있고, 각 스텝에서 1칸 또는 2칸을 올라갈 수 있다. 계단의 **꼭대기**(배열의 끝에서 한 칸 앞)에 도달하기 위한 최소 총 비용을 반환한다.

## 핵심 아이디어

각 계단에 도달하는 최소 비용은 "1칸 전에서 오는 경우"와 "2칸 전에서 오는 경우" 중 작은 쪽으로 결정된다. 이 계산에는 직전 2개의 결과만 필요하므로, 배열을 유지하지 않고 2개의 변수만으로 최소 비용을 구할 수 있다.

## 사고 과정

1. **꼭대기에 도달하는 방법은 2가지이다**: 꼭대기(인덱스 n)에는 1칸 전의 계단(n-1)에서 1칸 올라가거나, 2칸 전의 계단(n-2)에서 2칸 올라가는 2가지 방법으로 도달할 수 있다. 각각의 비용 중 작은 쪽이 정답이 된다
2. **각 계단까지의 최소 비용은 재귀적으로 정의할 수 있다**: 계단 i에 도달하는 최소 비용을 `dp[i]`라 하면, `dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`라는 점화식이 성립한다. "1칸 전의 최소 비용 + 그 계단의 비용"과 "2칸 전의 최소 비용 + 그 계단의 비용" 중 작은 쪽이다
3. **초기 조건을 결정한다**: 스텝 0 또는 스텝 1에서 시작할 수 있으므로, 계단 0과 계단 1에 도달하는 비용은 모두 0이다. 즉 `dp[0] = 0`, `dp[1] = 0`이 된다
4. **배열 전체는 불필요하고, 직전 2개만 있으면 된다**: 점화식 `dp[i]`는 `dp[i-1]`과 `dp[i-2]`에만 의존한다. 따라서 배열 대신 2개의 변수 `prev1`(1칸 전)과 `prev2`(2칸 전)만 유지하면 계산할 수 있다
5. **변수를 갱신하면서 앞으로 진행한다**: 계단 2부터 계단 n까지 순서대로 루프하며, 매번 `curr`를 계산한 후 `prev2 = prev1`, `prev1 = curr`로 슬라이드시킨다. 루프 종료 시의 `prev1`이 꼭대기까지의 최소 비용이다

## 전제 지식

### 동적 계획법(Dynamic Programming)이란

큰 문제를 작은 부분 문제로 분할하고, 부분 문제의 결과를 재사용하여 효율적으로 해를 구하는 기법이다. 이 문제에서는 "계단 i까지의 최소 비용"을 부분 문제로 삼고, 작은 인덱스부터 순서대로 풀어나간다(바텀업 방식).

### Math.min이란

2개의 정수 중 작은 쪽을 반환하는 Java의 표준 메서드이다. 2가지 선택지에서 비용이 낮은 쪽을 선택하는 데 사용한다.

```java
Math.min(5, 3);    // 3을 반환한다 — 2개의 인수 중 작은 쪽을 반환한다
Math.min(10, 10);  // 10을 반환한다 — 같은 값인 경우 그 값을 반환한다
```

### 공간 최적화의 개념

DP 배열의 각 요소가 직전 몇 개의 요소에만 의존하는 경우, 배열 전체를 유지하는 대신 필요한 수만큼의 변수로 계산을 수행할 수 있다. 이 문제에서는 `dp[i-1]`과 `dp[i-2]` 2개만 필요하므로, 변수 2개로 충분하다.

```java
int prev2 = 0;  // dp[i-2]에 해당하는 변수
int prev1 = 0;  // dp[i-1]에 해당하는 변수
int curr;       // dp[i]에 해당하는 변수(매번 계산하여 갱신한다)
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 1회 순회하는 것만으로 충분하다 |
| Space | O(1) — 변수 2개만 사용하며, 배열 크기에 의존하지 않는다 |

## 코드

```java
// 입력: 정수 배열 cost(각 계단을 밟는 비용)
// 출력: 계단의 꼭대기(인덱스 n)에 도달하는 최소 총 비용을 int로 반환한다
public int minCostClimbingStairs(int[] cost) {
    // 배열의 길이를 가져온다. 꼭대기는 인덱스 n의 위치(배열의 끝에서 한 칸 앞)이다
    int n = cost.length;

    // prev2=2칸 전의 계단까지의 최소 비용, prev1=1칸 전의 계단까지의 최소 비용
    // 스텝 0과 1에서 시작할 수 있으므로 초기 비용은 0이다
    int prev2 = 0, prev1 = 0;

    // 계단 2부터 꼭대기(계단 n)까지 순서대로 최소 비용을 계산한다. i는 현재 도달하려는 계단이다
    for (int i = 2; i <= n; i++) {
        // prev1 + cost[i-1]: 1칸 전의 계단에서 1칸 올라오는 경우의 총 비용
        // prev2 + cost[i-2]: 2칸 전의 계단에서 2칸 올라오는 경우의 총 비용
        // 작은 쪽을 선택한다
        int curr = Math.min(
            prev1 + cost[i - 1],
            prev2 + cost[i - 2]);

        // 변수를 1칸씩 앞으로 슬라이드시킨다
        // 주의: prev2의 갱신을 먼저 수행하지 않으면 prev1의 원래 값이 소실된다
        prev2 = prev1;
        prev1 = curr;
    }

    // prev1에 루프 마지막 이터레이션(i = n)에서 계산된 꼭대기까지의 최소 비용이 저장되어 있다
    return prev1;
}
```
