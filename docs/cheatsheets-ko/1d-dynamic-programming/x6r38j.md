# Counting Ways to Climb Stairs — n개의 계단을 1칸 또는 2칸씩 올라가는 방법의 총 수를 구한다

## 문제의 본질

정수 `n`(계단의 단 수)이 주어진다. 한 번에 1칸 또는 2칸씩 올라갈 수 있을 때, 꼭대기(n번째 칸)에 도달하는 **서로 다른 올라가는 방법의 총 수**를 반환한다.

## 핵심 아이디어

n번째 칸에 도달하려면 "n-1번째 칸에서 1칸 올라가는 것"이거나 "n-2번째 칸에서 2칸 올라가는 것"밖에 없다. 즉, `ways(n) = ways(n-1) + ways(n-2)`라는 피보나치 수열과 동일한 점화식이 성립한다. 직전 2개의 값만 보유하면 배열을 사용하지 않고 O(1)의 공간으로 계산할 수 있다.

## 사고 과정

1. **마지막 한 걸음에서 역산한다**: n번째 칸에 도달하기 직전의 상태는 "n-1번째 칸에 있는 것"이거나 "n-2번째 칸에 있는 것" 둘 중 하나밖에 없다. 따라서 n번째 칸으로의 올라가는 방법의 총 수는 `ways(n) = ways(n-1) + ways(n-2)`라는 점화식으로 나타낼 수 있다
2. **기저 케이스를 정한다**: 1칸짜리 계단은 1가지(1칸 올라감), 2칸짜리 계단은 2가지(1+1 또는 2)이다. 이 두 가지가 점화식의 출발점이 된다
3. **바텀업으로 계산한다**: 재귀로 위에서부터 계산하면 같은 부분 문제를 여러 번 풀게 된다. 대신에 작은 값부터 순서대로 계산해 나가는 바텀업 방식을 채택하면 각 값을 한 번씩만 계산하면 된다
4. **필요한 변수는 2개뿐이다**: 점화식 `ways(i) = ways(i-1) + ways(i-2)`는 직전 2개의 값만 참조한다. 배열 전체를 보유할 필요가 없고 변수 2개(`prev2`와 `prev1`)만으로 충분하다
5. **루프로 변수를 갱신한다**: `i = 3`부터 `n`까지 순서대로 `curr = prev1 + prev2`로 현재의 값을 계산하고, `prev2 = prev1`, `prev1 = curr`로 슬라이드시켜 다음 이터레이션에 대비한다
6. **최종적으로 반환하는 것**: 루프 종료 후 `prev1`에 n번째 칸의 올라가는 방법의 총 수가 저장되어 있으므로 `prev1`을 반환한다

## 전제 지식

### 동적 계획법(Dynamic Programming)이란

큰 문제를 작은 부분 문제로 분할하여 각 부분 문제의 결과를 기록하면서 푸는 기법이다. 같은 계산을 반복하지 않음으로써 효율화한다. 바텀업 방식에서는 가장 작은 부분 문제부터 순서대로 풀어 나간다.

```java
// 바텀업 DP의 기본 패턴 (배열 버전)
int[] dp = new int[n + 1];   // 부분 문제의 결과를 저장하는 배열
dp[1] = 1;                    // 기저 케이스 1
dp[2] = 2;                    // 기저 케이스 2
for (int i = 3; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];  // 점화식으로 계산한다
}
// dp[n]이 최종 답이다
```

### 슬라이딩 변수란

배열 대신 변수 2개만으로 직전의 값을 보유하는 기법이다. 점화식이 참조하는 과거의 값이 일정 개수인 경우 배열 전체를 보유할 필요가 없어지며, 공간 계산량을 O(n)에서 O(1)으로 줄일 수 있다.

```java
int prev2 = 1;  // 2개 전의 값을 보유하는 변수
int prev1 = 2;  // 1개 전의 값을 보유하는 변수
int curr = prev1 + prev2;  // 현재의 값을 계산한다
prev2 = prev1;  // prev2를 슬라이드시킨다 (prev1의 값을 이어받는다)
prev1 = curr;   // prev1을 슬라이드시킨다 (curr의 값을 이어받는다)
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 3부터 n까지 한 번 루프하는 것만으로 충분하다 |
| Space | O(1) — 변수 2개(prev2, prev1)만 사용한다 |

## 코드

```java
// 입력: 정수 n (계단의 단 수)
// 출력: 꼭대기에 도달하는 서로 다른 올라가는 방법의 총 수를 int로 반환한다
public int climbStairs(int n) {
    // 기저 케이스: 1칸이면 1가지밖에 없다. 후속 루프가 i=3부터 시작하기 때문에 n=1을 먼저 처리한다
    if (n == 1) return 1;

    // prev2는 2칸 전의 올라가는 방법의 총 수이다. 초기값은 1번째 칸의 올라가는 방법(1가지)에 대응한다
    int prev2 = 1;
    // prev1은 1칸 전의 올라가는 방법의 총 수이다. 초기값은 2번째 칸의 올라가는 방법(2가지: 1+1 또는 2)에 대응한다
    int prev1 = 2;

    // i는 현재 계산하고 있는 칸 수이다. 1번째 칸과 2번째 칸은 초기값으로 설정 완료했으므로 3번째 칸부터 시작한다
    for (int i = 3; i <= n; i++) {
        // 점화식: i번째 칸의 올라가는 방법 = (i-1)번째 칸의 올라가는 방법 + (i-2)번째 칸의 올라가는 방법
        int curr = prev1 + prev2;
        // 주의: prev2를 먼저 갱신하면 prev1의 원래 값이 손실된다
        prev2 = prev1;
        prev1 = curr;
    }

    // 루프 종료 후 prev1에 n번째 칸의 올라가는 방법의 총 수가 저장되어 있다
    return prev1;
}
```
