# Maximizing Robbery Loot in a Circular Neighborhood — 원형으로 배열된 집에서 인접하지 않게 최대 금액을 훔치기

## 문제의 본질

비음수 정수 배열 `nums`가 주어진다. 각 요소는 원형으로 배열된 집에 있는 금액을 나타낸다. 인접한 2개의 집을 연속으로 훔칠 수 없다. **첫 번째 집과 마지막 집도 인접해 있다**는 제약 조건 하에서 훔칠 수 있는 금액의 최댓값을 반환한다.

## 핵심 아이디어

원형의 제약은 "첫 번째 집과 마지막 집을 동시에 선택할 수 없다"는 것으로 귀결된다. 따라서 "첫 번째 집을 포함하고 마지막 집을 제외하는 범위"와 "마지막 집을 포함하고 첫 번째 집을 제외하는 범위"로 2회 나누어 선형 버전의 House Robber를 풀고, 더 큰 쪽을 취하면 원형의 제약을 충족할 수 있다.

## 사고 과정

1. **원형의 제약을 분해한다**: 원형 배열에서는 `nums[0]`과 `nums[n-1]`이 인접한다. 즉, 양쪽을 동시에 선택할 수 없다. 이것은 "`nums[0]`을 선택하면 `nums[n-1]`은 선택할 수 없다", "`nums[n-1]`을 선택하면 `nums[0]`은 선택할 수 없다"라는 2가지 케이스로 분해할 수 있다
2. **2개의 선형 문제로 귀착시킨다**: 케이스 1은 `nums[0..n-2]`(첫 번째를 포함하고 마지막을 제외), 케이스 2는 `nums[1..n-1]`(첫 번째를 제외하고 마지막을 포함)의 범위에서 각각 선형 버전의 House Robber를 풀면 된다. 2개의 결과 중 더 큰 쪽이 답이 된다
3. **선형 버전의 점화식을 세운다**: 각 집 `i`에 대해 "집 `i`를 훔친다"와 "훔치지 않는다"의 2가지 선택지가 있다. 훔치는 경우는 `nums[i] + dp[i-2]`(바로 앞 집은 건너뛴다)이고, 훔치지 않는 경우는 `dp[i-1]`(바로 앞까지의 최댓값을 그대로 이어받는다)이다. 따라서 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`가 된다
4. **공간을 상수로 줄인다**: 점화식이 참조하는 것은 `dp[i-1]`과 `dp[i-2]` 2개뿐이다. DP 배열 전체를 유지할 필요 없이, 2개의 변수 `prev1`(바로 앞의 최댓값)과 `prev2`(2개 앞의 최댓값)만으로 계산할 수 있다
5. **엣지 케이스를 처리한다**: 배열이 비어 있으면 0을 반환한다. 요소가 1개뿐이면 원형의 제약은 관계없으므로 해당 값을 반환한다. 요소가 2개 이상인 경우에만 2패스 처리를 수행한다
6. **최종적으로 반환하는 것**: 2개의 범위에서 각각 얻은 최대 금액 중 더 큰 쪽을 `Math.max`로 선택하여 반환한다

## 전제 지식

### House Robber(선형 버전)란

일렬로 늘어선 집에서 인접한 집을 연속으로 선택하지 않고 최대 금액을 얻는 문제이다. DP의 기본 문제이며, 점화식 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`로 풀 수 있다. 이 원형 버전은 선형 버전을 2회 적용하여 푼다.

### 롤링 변수를 이용한 DP 공간 최적화

DP 배열 중 점화식이 참조하는 최근 몇 개만을 변수로 유지하는 기법이다. 배열 전체를 유지할 필요가 없어지며, 공간 복잡도를 O(n)에서 O(1)로 줄일 수 있다.

```java
int prev2 = 0, prev1 = 0;        // dp[i-2]와 dp[i-1]에 해당하는 변수를 초기화한다
int curr = Math.max(prev1, prev2 + nums[i]);  // dp[i]를 계산한다
prev2 = prev1;                    // prev2를 한 칸 전진시킨다 (기존 prev1이 새 prev2가 된다)
prev1 = curr;                     // prev1을 한 칸 전진시킨다 (curr이 새 prev1이 된다)
```

### Math.max란

2개의 값 중 더 큰 쪽을 반환하는 Java의 표준 메서드이다. DP의 전이에서 "훔치는 경우"와 "훔치지 않는 경우"의 최댓값을 선택하기 위해 사용한다.

```java
Math.max(5, 3);   // → 5 (더 큰 쪽을 반환한다)
Math.max(prev1, prev2 + nums[i]);  // 훔치지 않는 경우와 훔치는 경우의 최댓값을 선택한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 2회 순회하지만, 각 순회는 O(n)이므로 전체적으로 O(n)이다 |
| Space | O(1) — DP 배열을 사용하지 않고, 2개의 롤링 변수만으로 계산한다 |

## 코드

```java
// 입력: 비음수 정수 배열 nums (원형으로 배열된 각 집의 금액)
// 출력: 인접한 집을 연속으로 훔치지 않고 얻을 수 있는 최대 금액을 int로 반환한다

// 지정 범위(start~end)에 대해 선형 버전 House Robber를 푸는 헬퍼 메서드
private int robRange(int[] nums, int start, int end) {
    // 0으로 초기화하는 이유는 어떤 집도 훔치지 않은 상태에서의 금액이 0이기 때문이다
    int prev2 = 0, prev1 = 0;  // 2개 앞과 1개 앞의 최대 금액을 유지하는 롤링 변수
    // 지정된 범위의 처음부터 끝까지 하나씩 순회한다
    for (int i = start; i <= end; i++) {
        // prev1: 집 i를 훔치지 않고, 바로 앞까지의 최댓값을 이어받는 선택지
        // prev2 + nums[i]: 집 i를 훔치고, 2개 앞까지의 최댓값에 현재 금액을 더하는 선택지
        int curr = Math.max(prev1,
            prev2 + nums[i]);
        // 롤링 변수를 한 칸 전진시킨다 (다음 이터레이션에서는 curr이 prev1, prev1이 prev2의 역할을 한다)
        prev2 = prev1;
        prev1 = curr;
    }
    // prev1에는 지정 범위 전체를 고려한 최대 금액이 저장되어 있다
    return prev1;
}

public int rob(int[] nums) {
    int n = nums.length;
    if (n == 0) return 0;        // 집이 없으면 0을 반환한다
    if (n == 1) return nums[0];  // 집이 1개뿐이면 인접 제약이 발생하지 않으므로, 해당 값이 그대로 답이다

    // 원형의 제약을 2개의 선형 문제로 분해하고, 더 큰 쪽을 반환한다
    // 첫 번째와 마지막 집을 동시에 선택하지 않는 것이 보장되므로, 원형의 제약을 충족할 수 있다
    return Math.max(
        robRange(nums, 0, n - 2),   // 첫 번째 집을 포함하고 마지막을 제외하는 범위 (인덱스 0부터 n-2)
        robRange(nums, 1, n - 1));  // 첫 번째 집을 제외하고 마지막을 포함하는 범위 (인덱스 1부터 n-1)
}
```
