# Counting All Palindromic Substrings — 문자열 내 회문 부분 문자열의 총 개수를 구한다

## 문제의 본질

문자열 `s`가 주어진다. `s`의 모든 부분 문자열 중 회문(앞에서 읽어도 뒤에서 읽어도 동일한 문자열)인 것의 **총 개수**를 반환한다. 한 글자짜리 부분 문자열도 모두 회문으로 센다.

## 핵심 아이디어

모든 회문에는 「중심」이 존재한다. 중심을 고정하고 좌우로 확장하면 해당 중심에서 생성되는 모든 회문을 열거할 수 있다. 중심 후보는 각 문자(홀수 길이)와 인접한 두 문자 사이(짝수 길이)를 합쳐 총 2n-1개뿐이므로 전수 탐색이 가능하다.

## 사고 과정

1. **회문의 구조적 성질에 주목한다**: 모든 회문은 중심을 기준으로 좌우 대칭이다. 홀수 길이의 회문은 한 문자를 중심으로 가지며, 짝수 길이의 회문은 인접한 두 문자를 중심으로 가진다. 이 성질을 이용하면 중심을 기점으로 회문을 효율적으로 발견할 수 있다
2. **중심에서 바깥쪽으로 확장한다**: 특정 중심에 대해 좌우 포인터 `left`와 `right`를 설정하고, `s.charAt(left) == s.charAt(right)`인 한 바깥쪽으로 확장한다. 확장에 성공할 때마다 새로운 회문이 하나 발견되므로 카운트를 1 증가시킨다
3. **홀수 길이와 짝수 길이를 나누어 처리한다**: 각 인덱스 `i`에 대해 `expand(s, i, i)`로 홀수 길이의 회문을, `expand(s, i, i+1)`로 짝수 길이의 회문을 센다. 이 두 호출로 `i`를 중심으로 하는 모든 회문을 망라할 수 있다
4. **확장의 정지 조건을 정한다**: `left`가 0 미만이 되거나, `right`가 문자열 길이 이상이 되거나, 좌우 문자가 일치하지 않게 되면 확장을 정지한다. 이를 통해 범위 밖 접근을 방지하면서 최대한의 확장을 수행한다
5. **각 중심의 결과를 합산한다**: 모든 인덱스에 대해 홀수 길이·짝수 길이의 회문 수를 합산한 값이 문자열 전체의 회문 부분 문자열 총 개수가 된다
6. **최종적으로 반환하는 것**: 모든 중심에서 얻은 회문 수의 합계를 정수 `result`로 반환한다

## 전제 지식

### 회문(Palindrome)이란

앞에서 읽어도 뒤에서 읽어도 동일한 문자열이다. `"aba"`, `"abba"`, `"a"`는 모두 회문이다. 회문에는 홀수 길이(중심이 한 문자)와 짝수 길이(중심이 두 문자 사이)의 두 종류가 있다.

```
홀수 길이 예시: "aba"  → 중심은 'b'
짝수 길이 예시: "abba" → 중심은 'b'와 'b' 사이
```

### 중심 확장법(Expand Around Center)이란

회문의 중심을 고정하고, 좌우로 한 문자씩 넓혀 가며 회문인지 여부를 판정하는 기법이다. 중심에서 바깥쪽으로 향하여 문자가 일치하는 한 확장을 계속하고, 일치하지 않게 되면 정지한다.

```
문자열: "abacd"
중심 i=1 ('b')에서 확장:
  left=1, right=1 → 'b'=='b' → 회문 "b" 발견, count=1
  left=0, right=2 → 'a'=='a' → 회문 "aba" 발견, count=2
  left=-1 → 범위 밖이므로 정지
```

### String.charAt(int index)란

문자열의 지정된 인덱스에 있는 문자를 반환하는 메서드이다. 인덱스는 0부터 시작한다.

```java
String s = "abc";
s.charAt(0);    // 'a'를 반환한다
s.charAt(2);    // 'c'를 반환한다
s.length();     // 문자열의 길이를 반환한다 → 3
```

## 계산량

| | 값 |
|---|---|
| Time | O(n²) — 각 중심(n개)에 대해 최대 O(n)의 확장을 수행한다 |
| Space | O(1) — 포인터와 카운터만 사용하며, 추가적인 데이터 구조를 사용하지 않는다 |

## 코드

```java
// 입력: 문자열 s
// 출력: s의 회문 부분 문자열의 총 개수를 정수로 반환한다

// 지정된 중심에서 좌우로 확장하여, 발견된 회문의 개수를 반환한다
// left와 right가 같은 값이면 홀수 길이, 인접한 값이면 짝수 길이의 회문을 탐색한다
int expand(String s, int left, int right) {
    int count = 0;
    // 3가지 조건을 모두 만족하는 동안 확장한다: 왼쪽 끝이 범위 내, 오른쪽 끝이 범위 내, 좌우 문자가 일치
    while (left >= 0 && right < s.length()
            && s.charAt(left) == s.charAt(right)) {
        count++;   // s.substring(left, right+1)이 새로운 회문이므로 카운트한다
        left--;    // 왼쪽으로 1칸 확장한다
        right++;   // 오른쪽으로 1칸 확장한다
    }
    // 이 중심에서 발견된 회문의 총 개수를 반환한다
    return count;
}

int countSubstrings(String s) {
    // 모든 중심에서 발견된 회문의 개수를 누적하는 변수
    int result = 0;

    // 각 인덱스를 중심 후보로 삼아 순회한다
    for (int i = 0; i < s.length(); i++) {
        // 홀수 길이 회문: left=i, right=i로 한 문자의 중심에서 확장을 시작한다
        result += expand(s, i, i);
        // 짝수 길이 회문: left=i, right=i+1로 인접한 두 문자의 중심에서 확장을 시작한다
        result += expand(s, i, i + 1);
    }
    // 모든 중심에서 얻은 회문 수의 합계를 반환한다
    return result;
}
```
