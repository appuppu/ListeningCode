# Finding the Subarray With Maximum Product — 최대 곱을 가지는 연속 부분 배열 찾기

## 문제의 본질

정수 배열 `nums`가 주어진다. 배열에서 **연속하는 부분 배열**을 선택하여 그 요소들의 곱이 최대가 되는 것을 찾고, 그 **곱**을 반환한다. 부분 배열은 1개 이상의 연속된 요소로 구성된다.

## 핵심 아이디어

음수끼리의 곱셈은 양수가 되기 때문에, 현재의 최솟값(절댓값이 가장 큰 음수)이 다음 음수와 곱해져서 최댓값으로 바뀔 수 있다. 따라서 각 위치에서 「현재의 최대 곱」과 「현재의 최소 곱」을 모두 추적해야 한다.

## 사고 과정

1. **부분 배열의 곱의 특성을 생각한다**: 연속 부분 배열의 곱을 구하는 문제에서는 요소를 하나 추가할 때마다 「이전 부분 배열의 곱 × 현재 요소」로 새로운 곱을 계산할 수 있다. 이는 DP의 사고방식과 동일하며, 이전 상태에서 다음 상태를 도출할 수 있다
2. **음수가 최대 곱 계산을 복잡하게 만든다**: 양수만 있다면 최대 곱만 추적하면 되지만, 음수가 있으면 「큰 음의 곱 × 음수 = 큰 양의 곱」이 발생한다. 즉, 현재의 최소 곱(음의 방향으로 가장 큰 값)도 추적하지 않으면 최대 곱을 놓칠 가능성이 있다
3. **각 위치에서의 후보는 3가지로 좁혀진다**: 위치 `i`에서의 최대 곱 후보는, (a) `nums[i]` 단독(새로운 부분 배열을 시작하는 경우), (b) `curMax * nums[i]`(양의 최대 곱을 연장하는 경우), (c) `curMin * nums[i]`(음의 최소 곱이 음수로 반전되는 경우)의 3가지이다. 이 3가지의 최댓값이 새로운 `curMax`가 된다
4. **최소 곱도 같은 3가지 후보에서 선택한다**: 최소 곱의 후보도 같은 3가지 값이며, 그 최솟값이 새로운 `curMin`이 된다. 최대와 최소를 동시에 갱신함으로써 음수에 의한 반전을 올바르게 포착할 수 있다
5. **갱신 시 이전 값을 임시 저장한다**: `curMax`를 갱신한 후에 `curMin`을 계산하면 `curMin` 계산에 갱신 전의 `curMax`를 사용할 수 없게 된다. 따라서 `curMax` 갱신 전에 그 값을 임시 변수 `temp`에 저장하고, `curMin` 계산에서는 `temp`를 사용한다
6. **전체 최댓값을 별도의 변수로 관리한다**: `curMax`는 현재 위치에서의 최대 곱이며 전체의 최대 곱이 아니다. 각 위치에서 `result = Math.max(result, curMax)`로 전체의 최대 곱을 갱신하고, 최종적으로 `result`를 반환한다

## 전제 지식

### 부분 배열의 곱과 DP의 관계

부분 배열의 곱은 이전 위치까지의 곱에 현재 요소를 곱하여 연장할 수 있다. 이 성질을 이용하면 각 위치에서 「여기서 끝나는 부분 배열의 최대 곱」을 이전 위치의 결과로부터 O(1)로 계산할 수 있다. DP처럼 이전 상태를 유지하여 다음 상태를 도출하는 방법이다.

### Math.max / Math.min이란

여러 값에서 최댓값·최솟값을 구하는 Java 메서드이다. 3개 이상의 값을 비교하려면 중첩하여 호출한다.

```java
Math.max(3, 7);                   // 두 값의 최댓값을 반환한다 → 7
Math.min(3, 7);                   // 두 값의 최솟값을 반환한다 → 3
Math.max(a, Math.max(b, c));      // 세 값의 최댓값을 반환한다
Math.min(a, Math.min(b, c));      // 세 값의 최솟값을 반환한다
```

### 왜 최솟값 추적이 필요한가

음수를 포함하는 배열에서는 곱의 부호가 요소마다 반전된다. 예: `[-2, 3, -4]`의 경우, 위치 1에서의 최소 곱은 `-2 × 3 = -6`이지만, 위치 2에서 `-6 × -4 = 24`가 되어 최대 곱이 된다. 최대 곱만 추적하고 있으면 `-6`을 버리게 되어 `24`를 놓치게 된다.

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 한 번 순회하는 것만으로 충분하다 |
| Space | O(1) — 사용하는 변수는 고정 개수뿐이며, 입력 크기에 의존하지 않는다 |

## 코드

```java
// 입력: 정수 배열 nums(길이 1 이상)
// 출력: 연속 부분 배열의 곱의 최댓값을 int로 반환한다
public int maxProduct(int[] nums) {
    // result=전체의 최대 곱, curMax=현재 위치에서 끝나는 부분 배열의 최대 곱, curMin=동일한 최소 곱
    // 첫 번째 요소만으로 구성된 부분 배열이 초기 상태가 된다
    int result = nums[0];
    int curMax = nums[0];
    int curMin = nums[0];

    // i=0은 초기화에서 처리 완료했으므로 i=1부터 시작한다
    for (int i = 1; i < nums.length; i++) {
        int n = nums[i];
        // curMax를 갱신하기 전에 임시 저장한다(curMin 계산에 갱신 전의 값이 필요하기 때문이다)
        int temp = curMax;

        // 3가지 후보에서 최댓값을 선택한다:
        // n 단독 → 새로운 부분 배열을 시작하는 경우
        // temp * n → 이전의 최대 곱을 연장하는 경우
        // curMin * n → 이전의 최소 곱(음수)이 음수 n으로 반전되어 최대가 되는 경우
        curMax = Math.max(n,
            Math.max(temp * n, curMin * n));

        // 같은 3가지 후보에서 최솟값을 선택한다(temp로 갱신 전의 curMax를 사용하여 위의 갱신 영향을 받지 않고 올바르게 계산할 수 있다)
        curMin = Math.min(n,
            Math.min(temp * n, curMin * n));

        // curMax는 현재 위치에서의 최대 곱이며 전체의 최대 곱이 아니므로, 별도 변수 result로 전체의 최대 곱을 관리한다
        result = Math.max(result, curMax);
    }
    // result에는 배열 전체를 통틀어 최대인 부분 배열의 곱이 저장되어 있다
    return result;
}
```
