# Finding the Longest Palindromic Substring — 문자열에서 가장 긴 회문 부분 문자열을 찾기

## 문제의 본질

문자열 `s`가 주어진다. `s` 안에서 앞에서 읽어도 뒤에서 읽어도 같은 **가장 긴 부분 문자열(회문)**을 찾아서 반환한다. 같은 길이의 회문이 여러 개 있는 경우에는 그중 하나를 반환하면 된다.

## 핵심 아이디어

회문은 반드시 「중심」을 가진다. 문자열의 각 위치를 중심으로 좌우로 확장하며, 문자가 일치하는 한 회문을 넓혀 가면 모든 회문을 빠짐없이 발견할 수 있다. 중심은 「1문자(홀수 길이)」와 「인접한 2문자 사이(짝수 길이)」의 2가지를 시도해야 한다.

## 사고 과정

1. **회문은 중심으로부터 대칭으로 확장되는 구조를 가진다**: 회문 `"racecar"`는 중심인 `e`로부터 좌우로 `c→a→r`과 대칭으로 확장되어 있다. 이 성질을 이용하면, 중심을 고정하고 좌우로 확장함으로써 회문을 검출할 수 있다
2. **중심의 후보는 2가지가 있다**: 홀수 길이의 회문(예: `"aba"`)은 1문자가 중심이 되고, 짝수 길이의 회문(예: `"abba"`)은 인접한 2문자 사이가 중심이 된다. 모든 회문을 빠짐없이 검출하려면 양쪽 중심을 모두 시도해야 한다
3. **확장 절차를 정한다**: 중심에서 좌우로 포인터 `left`와 `right`를 놓고, `s.charAt(left) == s.charAt(right)`인 한 `left`를 왼쪽으로, `right`를 오른쪽으로 하나씩 넓힌다. 문자가 불일치하거나 문자열의 끝에 도달하면 확장을 종료한다
4. **확장 결과로부터 회문의 길이를 구한다**: 확장이 종료된 시점에서 `left`와 `right`는 회문 범위를 하나씩 벗어난 위치에 있다. 따라서 회문의 길이는 `right - left - 1`로 계산할 수 있다
5. **가장 긴 회문의 시작·종료 위치를 기록한다**: 각 중심에서 얻은 회문의 길이가 지금까지의 최장을 초과한 경우에 시작 위치 `start`와 종료 위치 `end`를 갱신한다. 중심 위치 `i`와 회문의 길이 `len`으로부터 `start = i - (len - 1) / 2`, `end = i + len / 2`로 계산할 수 있다
6. **최종적으로 부분 문자열을 반환한다**: 모든 중심을 시도한 후, `s.substring(start, end + 1)`로 가장 긴 회문 부분 문자열을 잘라내어 반환한다

## 사전 지식

### 회문(Palindrome)이란

앞에서 읽어도 뒤에서 읽어도 같은 문자열을 말한다. `"aba"`, `"abba"`, `"racecar"`는 회문이다. 1문자짜리 문자열도 회문이다.

### 중심 확장법(Expand Around Center)이란

회문의 중심을 고정하고, 좌우로 1문자씩 넓혀 가면서 회문인지 아닌지를 판정하는 기법이다. 중심에서 바깥쪽으로 문자를 비교하기 때문에 회문 검출을 효율적으로 수행할 수 있다.

```java
// left=right이면 홀수 길이의 회문(1문자 중심)을 검출한다
// left=i, right=i+1이면 짝수 길이의 회문(2문자 중심)을 검출한다
expand(s, 2, 2);    // 인덱스 2를 중심으로 한 홀수 길이의 회문을 찾는다
expand(s, 2, 3);    // 인덱스 2와 3 사이를 중심으로 한 짝수 길이의 회문을 찾는다
```

### String.substring(int, int)이란

문자열에서 부분 문자열을 잘라내는 메서드이다. 첫 번째 인수는 시작 인덱스(포함)이고, 두 번째 인수는 종료 인덱스(미포함)이다.

```java
String s = "babad";
s.substring(0, 3);   // "bab"를 반환한다 (인덱스 0, 1, 2의 문자)
s.substring(1, 4);   // "aba"를 반환한다 (인덱스 1, 2, 3의 문자)
```

### String.charAt(int)이란

문자열의 지정한 인덱스에 있는 문자를 반환하는 메서드이다.

```java
String s = "babad";
s.charAt(0);   // 'b'를 반환한다
s.charAt(2);   // 'b'를 반환한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n²) — 각 인덱스를 중심으로 최대 O(n)의 확장을 수행하며, 중심은 n개 있다 |
| Space | O(1) — 포인터와 길이를 기록하는 변수만 사용하며, 추가적인 데이터 구조는 불필요하다 |

## 코드

```java
// 입력: 문자열 s
// 출력: s에서 가장 긴 회문 부분 문자열을 String으로 반환한다

// 중심에서 좌우로 확장하여 회문의 길이를 반환하는 헬퍼 메서드
private int expand(String s, int left, int right) {
    // 좌우 문자가 일치하고, 문자열 범위 내에 있는 한 확장을 계속한다
    while (left >= 0
            && right < s.length()
            && s.charAt(left)
            == s.charAt(right)) {
        left--;  // 왼쪽으로 1칸 넓힌다
        right++; // 오른쪽으로 1칸 넓힌다
    }
    // 확장 종료 시, left와 right는 회문 범위를 하나씩 벗어난 위치에 있다
    // 따라서 회문의 길이는 right - left - 1로 구한다
    return right - left - 1;
}

public String longestPalindrome(String s) {
    // 가장 긴 회문의 시작·종료 인덱스를 기록하는 변수
    // 초기값 0은 최소한 첫 번째 문자 자체가 길이 1의 회문인 것에 대응한다
    int start = 0, end = 0;

    // 각 인덱스 i를 회문의 중심 후보로 순회한다
    for (int i = 0; i < s.length(); i++) {
        // 홀수 길이의 회문(1문자 중심)을 확장하여 길이를 구한다
        int odd = expand(s, i, i);
        // 짝수 길이의 회문(2문자 중심)을 확장하여 길이를 구한다
        int even = expand(s, i, i + 1);
        // 홀수 길이와 짝수 길이 중 큰 쪽을 채택한다
        int len = Math.max(odd, even);

        // 현재 가장 긴 회문의 길이 (end - start + 1)를 초과한 경우, 시작·종료 위치를 갱신한다
        if (len > end - start + 1) {
            // (len - 1) / 2는 중심에서 왼쪽으로의 거리이다
            start = i - (len - 1) / 2;
            // len / 2는 중심에서 오른쪽으로의 거리이다
            end = i + len / 2;
        }
    }
    // substring의 두 번째 인수는 「미포함」 사양이므로, end + 1을 지정하여 end의 문자까지 포함한다
    return s.substring(start, end + 1);
}
```
