# Maximizing Robbery Loot Without Adjacent Houses — 인접한 집을 피하면서 훔칠 수 있는 금액의 최댓값을 구하기

## 문제의 본질

정수 배열 `nums`가 주어지며, 각 요소는 거리에 늘어선 각 집에 있는 금액을 나타낸다. 인접한 2개의 집을 모두 털 수는 없다는 제약 조건 하에서, 하룻밤에 훔칠 수 있는 **금액의 최댓값**을 반환한다. 집 `i`를 털면, 집 `i-1`과 집 `i+1`은 털 수 없다.

## 핵심 아이디어

각 집에 대해 「털다 or 털지 않다」의 2가지 선택지가 있으며, 터는 경우에는 2칸 앞까지의 최댓값에 현재 금액을 더하고, 털지 않는 경우에는 1칸 앞의 최댓값을 그대로 이어받는다. 이 판단에 필요한 것은 직전 2개의 값뿐이므로, 배열을 유지하지 않고 변수 2개로 계산할 수 있다.

## 사고 과정

1. **각 집에서 「털다/털지 않다」의 최적 판단이 필요하다**: 집 `i`를 털면 집 `i-1`은 털 수 없으므로, 집 `i-2`까지의 최댓값에 `nums[i]`를 더한 값을 얻을 수 있다. 털지 않으면 집 `i-1`까지의 최댓값이 그대로 남는다. 즉, 각 집에서의 최댓값은 `max(집 i-1까지의 최댓값, 집 i-2까지의 최댓값 + nums[i])`로 표현할 수 있다
2. **점화식을 세울 수 있다**: `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`라는 점화식으로, 처음부터 순서대로 각 집까지의 최대 금액을 계산할 수 있다. 이것은 전형적인 동적 계획법의 구조이다
3. **필요한 정보는 직전 2개뿐이다**: 점화식을 보면, `dp[i]`의 계산에 사용하는 것은 `dp[i-1]`과 `dp[i-2]` 2개뿐이다. 배열 전체를 유지할 필요가 없으며, 변수 2개(`prev1`과 `prev2`)로 충분하다
4. **변수의 갱신 순서를 고려한다**: `curr`를 계산한 후, 다음 반복에서는 현재의 `prev1`이 새로운 `prev2`가 되고, `curr`가 새로운 `prev1`이 된다. 이 순서로 갱신하면 값이 덮어쓰이지 않는다
5. **초깃값을 설정한다**: 순회 시작 전에 `prev1 = 0`(1칸 앞의 최댓값), `prev2 = 0`(2칸 앞의 최댓값)으로 설정한다. 집이 0채인 경우에는 0이 되고, 1번째 집에서는 `max(0, 0 + nums[0]) = nums[0]`이 되어 올바르게 동작한다
6. **최종적으로 반환하는 것**: 모든 집을 순회한 후의 `prev1`이 전체를 통틀어 최대 금액이다

## 전제 지식

### 동적 계획법(Dynamic Programming)이란

큰 문제를 작은 부분 문제로 분할하고, 각 부분 문제의 해를 재활용하여 전체의 해를 구축하는 기법이다. 중복되는 부분 문제가 있는 경우, 같은 계산을 반복하지 않아도 된다. 이 문제에서는 「집 `i`까지의 최대 금액」이 부분 문제에 해당한다.

### Math.max란

2개의 값 중 큰 쪽을 반환하는 Java의 표준 메서드이다. 조건 분기를 한 줄로 작성할 수 있다.

```java
Math.max(5, 3);    // → 5 (큰 쪽을 반환한다)
Math.max(prev1, prev2 + num);  // prev1과 prev2+num 중 큰 쪽을 반환한다
```

### 확장 for 루프(for-each)란

배열의 전체 요소를 처음부터 순서대로 하나씩 꺼내어 처리하는 루프 구문이다. 인덱스를 사용하지 않고 요소에 직접 접근한다.

```java
int[] nums = {2, 7, 9, 3};
for (int num : nums) {   // nums의 각 요소를 순서대로 num에 대입하며 루프를 실행한다
    System.out.println(num);  // 2, 7, 9, 3이 순서대로 출력된다
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 1회 순회하는 것만으로 충분하다 |
| Space | O(1) — 변수 2개만 사용하며, 입력 크기에 의존하지 않는다 |

## 코드

```java
// 입력: 정수 배열 nums (각 집의 금액)
// 출력: 인접한 집을 털지 않는 제약 조건 하에서 훔칠 수 있는 금액의 최댓값을 int로 반환한다
public int rob(int[] nums) {
    // prev2: 2칸 앞의 집까지의 최대 금액. 순회 시작 전에는 집이 존재하지 않으므로 0이다
    int prev2 = 0;
    // prev1: 1칸 앞의 집까지의 최대 금액. 마찬가지로 순회 시작 전에는 0이다
    int prev1 = 0;

    // 확장 for 루프로 배열 nums를 처음부터 끝까지 1개 요소씩 순회한다
    for (int num : nums) {
        // 「현재 집을 털지 않는 경우(prev1)」와 「현재 집을 터는 경우(prev2+num)」 중 큰 쪽을 선택한다
        // 현재 집을 터는 경우에 prev2를 사용하는 이유는, 인접한 prev1의 집은 털 수 없기 때문이다
        int curr = Math.max(prev1,
            prev2 + num);
        // 다음 반복을 위해 변수를 슬라이드시킨다
        // 현재의 prev1(1칸 앞의 최댓값)이 다음 반복에서는 2칸 앞의 최댓값이 된다
        prev2 = prev1;
        // 방금 계산한 curr(현재 집까지의 최댓값)가 다음 반복에서는 1칸 앞의 최댓값이 된다
        // 주의: 이 갱신은 prev2 = prev1 이후에 수행해야 한다. prev1을 먼저 갱신하면 prev2에 올바른 값을 대입할 수 없게 된다
        prev1 = curr;
    }
    // 모든 집을 고려한 최대 금액을 반환한다. prev1에는 마지막 집까지 고려한 최대 금액이 저장되어 있다
    return prev1;
}
```
