# Counting Ways to Decode a Numeric String — 숫자 문자열을 알파벳으로 변환하는 방법의 총 수를 구하기

## 문제의 본질

숫자로만 구성된 문자열 `s`가 주어진다. A=1, B=2, ..., Z=26이라는 대응 관계에 따라 문자열을 알파벳 열로 디코딩하는 방법이 몇 가지인지를 반환한다. 예를 들어 "226"은 "BZ"(2,26), "VF"(22,6), "BBF"(2,2,6)의 3가지로 디코딩할 수 있다.

## 핵심 아이디어

각 위치에서의 디코딩 방법 수는 「1문자 디코딩(1자리)한 경우의 나머지 방법 수」와 「2문자 디코딩(2자리)한 경우의 나머지 방법 수」의 합으로 구할 수 있다. 이 의존 관계는 직전 2개의 결과에만 한정되므로, 변수 2개로 충분하다.

## 사고 과정

1. **각 위치에서의 선택지는 최대 2개이다**: 위치 `i`의 숫자를 볼 때, 1자리(1~9)로서 1문자로 디코딩하거나, 2자리(10~26)로서 1문자로 디코딩하는 최대 2가지 선택이 있다. 이 선택이 재귀적으로 발생하므로, 각 위치에서의 디코딩 방법 수를 체계적으로 구해야 한다
2. **'0'은 단독으로 디코딩할 수 없다**: '0'에 대응하는 알파벳은 존재하지 않는다. 위치 `i`의 숫자가 '0'인 경우, 그 위치에서 시작하는 1자리 디코딩은 불가능하므로 방법 수는 0이 된다. '0'은 앞의 숫자와 조합하여 10 또는 20으로만 디코딩할 수 있다
3. **DP의 점화식을 세운다**: `dp[i]`를 「위치 `i`에서 끝까지의 디코딩 방법 수」로 정의한다. 위치 `i`의 숫자가 '0'이 아니면, 1자리 디코딩한 경우의 나머지 `dp[i+1]`을 더한다. 또한 위치 `i`와 `i+1`의 2자리가 10~26 범위이면, 2자리 디코딩한 경우의 나머지 `dp[i+2]`도 더한다. 즉 `dp[i] = dp[i+1] + dp[i+2]`(조건부)이다
4. **의존 대상은 바로 뒤의 2개뿐이다**: `dp[i]`는 `dp[i+1]`과 `dp[i+2]`에만 의존한다. 따라서 배열 전체를 유지할 필요가 없으며, 변수 2개(`next1` = `dp[i+1]`, `next2` = `dp[i+2]`)만으로 계산할 수 있다. 이를 통해 Space O(1)을 실현한다
5. **끝에서 앞으로 순회한다**: `dp[i]`는 `dp[i+1]`과 `dp[i+2]`에 의존하므로, 끝쪽이 먼저 확정되어 있어야 한다. 따라서 문자열의 끝에서 앞으로 루프를 돌면서 각 위치의 방법 수를 계산한다
6. **최종적으로 반환하는 값**: 루프 완료 후, `next1`에는 `dp[0]`(문자열 전체의 디코딩 방법 수)이 저장되어 있다. 이 값을 반환한다

## 사전 지식

### 동적 계획법(DP)이란

큰 문제를 작은 부분 문제로 분할하고, 부분 문제의 결과를 재활용하여 전체의 답을 구하는 기법이다. 동일한 부분 문제를 여러 번 재계산하는 것을 피하기 위해, 한 번 계산한 결과를 저장(메모이제이션)하거나 순서대로 계산(바텀업)한다.

```java
// 바텀업 DP의 전형적인 패턴: 피보나치 수열
int prev2 = 0, prev1 = 1;
for (int i = 2; i <= n; i++) {
    int current = prev1 + prev2;  // 직전 2개의 결과만으로 현재 값을 계산한다
    prev2 = prev1;                // 변수를 슬라이드하여 다음 이터레이션에 대비한다
    prev1 = current;
}
// prev1에 최종 결과가 들어 있다
```

### Integer.parseInt란

문자열을 정수로 변환하는 메서드이다. 부분 문자열을 수치로 평가하기 위해 사용한다.

```java
Integer.parseInt("26");          // 문자열 "26"을 정수 26으로 변환한다 → 26
Integer.parseInt("09");          // 문자열 "09"를 정수 9로 변환한다 → 9
```

### String.substring이란

문자열에서 지정 범위의 부분 문자열을 가져오는 메서드이다. 인수는 시작 인덱스(포함)와 종료 인덱스(미포함)이다.

```java
String s = "226";
s.substring(0, 2);   // 인덱스 0부터 1까지의 부분 문자열을 반환한다 → "22"
s.substring(1, 3);   // 인덱스 1부터 2까지의 부분 문자열을 반환한다 → "26"
```

### String.charAt이란

문자열의 지정 위치에 있는 1문자를 반환하는 메서드이다. char 타입을 반환하므로, 문자 '0'과의 비교로 숫자를 판정할 수 있다.

```java
String s = "206";
s.charAt(0);          // 인덱스 0의 문자를 반환한다 → '2'
s.charAt(1);          // 인덱스 1의 문자를 반환한다 → '0'
s.charAt(1) == '0';   // 문자가 '0'인지를 판정한다 → true
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 문자열을 끝에서 앞으로 1회 순회하는 것만으로 충분하다 |
| Space | O(1) — 변수 2개(next1, next2)만으로 계산할 수 있으며, 배열을 사용하지 않는다 |

## 코드

```java
// 입력: 숫자로만 구성된 문자열 s
// 출력: 문자열 s를 알파벳 열로 디코딩하는 방법의 총 수를 int로 반환한다
public int numDecodings(String s) {
    // next1 = 1칸 오른쪽 위치부터의 방법 수(dp[i+1]), next2 = 2칸 오른쪽 위치부터의 방법 수(dp[i+2])
    // 문자열의 끝보다 오른쪽은 「빈 문자열을 디코딩하는 방법 = 1가지」로 정의하므로, 초기값은 1이다
    int next1 = 1, next2 = 1;

    // dp[i]는 dp[i+1]과 dp[i+2]에 의존하므로, 오른쪽을 먼저 확정하기 위해 끝에서 앞으로 순회한다
    for (int i = s.length() - 1; i >= 0; i--) {
        int current;

        if (s.charAt(i) == '0') {
            // '0'은 단독으로 어떤 알파벳에도 대응하지 않으므로, 이 위치에서 시작하는 디코딩 방법은 0가지이다
            // '0'은 앞의 숫자와 조합하여 10 또는 20으로만 디코딩할 수 있다
            current = 0;
        } else {
            // 1자리 디코딩: 위치 i의 숫자(1~9)를 1문자로 처리하고, 나머지 i+1 이후는 next1가지이다
            current = next1;

            // 2자리 디코딩이 가능한지 판정한다 (i+1이 문자열 범위 내이면 2자리를 취득할 수 있다)
            if (i + 1 < s.length()) {
                // s.substring(i, i+2)로 2자리의 부분 문자열을 취득하고, 정수로 변환한다
                int two = Integer.parseInt(
                    s.substring(i, i + 2));
                // 2자리가 10~26 범위이면, 2자리를 1문자로 디코딩하고 나머지 i+2 이후를 next2가지로 가산한다
                if (two >= 10 && two <= 26)
                    current += next2;
            }
        }

        // 변수를 1칸 왼쪽으로 슬라이드한다: 현재의 current가 다음 이터레이션에서는 next1(1칸 오른쪽)이 된다
        next2 = next1;
        next1 = current;
    }

    // 루프 완료 후, next1에는 마지막으로 계산한 current(= dp[0])가 저장되어 있다
    // 이것이 문자열 전체의 디코딩 방법의 총 수이다
    return next1;
}
```
