# Finding the Longest Increasing Subsequence — 최장 엄격 증가 부분 수열의 길이를 구하기

## 문제의 본질

정수 배열 `nums`가 주어진다. 원래 배열에서 요소를 삭제하여(순서는 바꾸지 않고) 만들 수 있는 **엄격하게 증가하는 부분 수열** 중에서 가장 긴 것의 길이를 반환한다. 부분 수열은 연속일 필요는 없지만, 원래 배열 내에서의 상대적인 순서는 유지해야 한다.

## 핵심 아이디어

"길이 `k`인 증가 부분 수열의 마지막 요소는 가능한 한 작을수록, 후속 요소로 확장할 수 있는 가능성이 높다". 각 길이에 대해 마지막 요소의 최솟값을 배열 `tails`로 관리하면, 새로운 요소의 삽입 위치를 이분 탐색으로 O(log n)에 결정할 수 있으며, 전체를 O(n log n)으로 풀 수 있다.

## 사고 과정

1. **증가 부분 수열을 확장하려면 마지막 값이 작을수록 유리하다**: 길이가 같은 증가 부분 수열이 여러 개 있을 때, 마지막 요소가 가장 작은 것이 "다음에 연결할 수 있는 값의 범위"가 가장 넓다. 따라서 각 길이마다 마지막 요소의 최솟값만 기록하면 충분하다
2. **tails 배열로 마지막 값의 최솟값을 관리한다**: `tails[i]`에 "길이 `i+1`인 증가 부분 수열이 가질 수 있는 마지막 요소의 최솟값"을 저장하는 배열 `tails`를 준비한다. 이 배열은 항상 정렬된 상태가 유지된다(길이가 긴 부분 수열일수록 마지막 값이 커지기 때문이다)
3. **새로운 요소의 처리는 2가지 패턴으로 나뉜다**: 배열의 각 요소 `num`에 대해, `tails` 안에서 `num` 이상인 최소 요소를 이분 탐색으로 찾는다. 찾은 위치가 `tails`의 끝을 넘으면, `num`은 기존 최장 부분 수열보다 크므로 `tails`의 끝에 추가한다. 끝을 넘지 않으면, 해당 위치의 값을 `num`으로 교체하여 마지막 값의 최솟값을 갱신한다
4. **이분 탐색을 사용할 수 있는 이유**: `tails` 배열은 항상 정렬된 상태이므로, `num`의 삽입 위치를 `Collections.binarySearch`로 O(log n)에 특정할 수 있다. 이를 통해 각 요소의 처리가 O(log n)이 되며, 전체적으로 O(n log n)을 달성한다
5. **tails 배열의 길이가 답이 된다**: 각 요소의 처리에서 `tails`는 추가 또는 교체 중 하나가 수행된다. 추가는 최장 부분 수열의 길이가 1 늘어났음을 의미한다. 모든 요소의 처리가 끝난 시점에서의 `tails.size()`가 최장 증가 부분 수열의 길이이다

## 사전 지식

### ArrayList란

가변 길이 배열이다. 요소의 추가·조회·갱신을 O(1)로 수행할 수 있다. 일반 배열과 달리 크기를 미리 정할 필요가 없다.

```java
List<Integer> list = new ArrayList<>();  // 빈 ArrayList를 생성한다
list.add(10);          // 끝에 10을 추가한다 → [10]
list.add(20);          // 끝에 20을 추가한다 → [10, 20]
list.get(0);           // 인덱스 0의 요소를 가져온다 → 10
list.set(0, 5);        // 인덱스 0의 요소를 5로 교체한다 → [5, 20]
list.size();           // 요소의 개수를 반환한다 → 2
```

### Collections.binarySearch란

정렬된 리스트에 대해 이분 탐색을 수행하여 지정한 값의 위치를 반환하는 메서드이다. 값이 발견되면 해당 인덱스를 반환한다. 발견되지 않으면 `-(삽입 위치) - 1`이라는 음수 값을 반환한다. 삽입 위치란, 해당 값을 리스트에 삽입해도 정렬 순서가 유지되는 위치를 말한다.

```java
List<Integer> list = Arrays.asList(2, 5, 8, 12);
Collections.binarySearch(list, 5);   // 5는 인덱스 1에 있다 → 1을 반환한다
Collections.binarySearch(list, 6);   // 6은 존재하지 않는다. 삽입 위치는 2 → -(2)-1 = -3을 반환한다
Collections.binarySearch(list, 1);   // 1은 존재하지 않는다. 삽입 위치는 0 → -(0)-1 = -1을 반환한다
Collections.binarySearch(list, 15);  // 15는 존재하지 않는다. 삽입 위치는 4 → -(4)-1 = -5를 반환한다
```

음수 반환값에서 삽입 위치를 복원하려면 `-(반환값 + 1)`을 계산한다. 예: 반환값이 -3이면, `-(-3 + 1) = 2`가 삽입 위치이다.

### tails 배열의 개념

`tails`는 "길이별 증가 부분 수열의 마지막 요소의 최솟값"을 기록하는 배열이다. `tails[i]`는 "길이 `i+1`인 증가 부분 수열이 가질 수 있는 마지막 값의 최솟값"을 의미한다. 이 배열은 항상 오름차순으로 정렬된 상태를 유지한다.

예: nums = [3, 1, 4, 1, 5]를 처리하는 과정:
- 3을 처리 → tails = [3] (길이 1인 부분 수열의 마지막 최솟값은 3이다)
- 1을 처리 → tails = [1] (길이 1의 마지막 최솟값을 1로 갱신한다. 3보다 1이 더 작아 유리하다)
- 4를 처리 → tails = [1, 4] (4는 1보다 크므로 끝에 추가한다. 길이 2인 부분 수열이 생겼다)
- 1을 처리 → tails = [1, 4] (1의 삽입 위치는 인덱스 0이며, 이미 1이므로 변화가 없다)
- 5를 처리 → tails = [1, 4, 5] (5는 4보다 크므로 끝에 추가한다. 길이 3인 부분 수열이 생겼다)

최종적인 `tails.size()` = 3이 답이다.

## 계산량

| | 값 |
|---|---|
| Time | O(n log n) — n개의 요소 각각에 대해 O(log n)의 이분 탐색을 수행한다 |
| Space | O(n) — tails 배열에 최대 n개의 요소를 저장한다 |

## 코드

```java
// 입력: 정수 배열 nums
// 출력: 최장 엄격 증가 부분 수열의 길이를 int로 반환한다
public int lengthOfLIS(int[] nums) {
    // 각 길이의 증가 부분 수열의 마지막 요소의 최솟값을 오름차순으로 유지하는 배열
    // tails[i]는 "길이 i+1인 증가 부분 수열이 가질 수 있는 마지막 요소의 최솟값"을 의미한다
    List<Integer> tails = new ArrayList<>();

    // 배열 nums의 각 요소를 처음부터 끝까지 하나씩 순회한다
    for (int num : nums) {
        // tails 배열 내에서 num이 들어갈 위치를 이분 탐색으로 구한다
        // tails는 항상 정렬된 상태이므로 이분 탐색을 사용할 수 있다
        int pos = Collections.binarySearch(tails, num);

        // 음수 값은 "찾지 못했음"을 의미하므로, 삽입 위치로 변환한다
        // pos가 0 이상인 경우는 num과 같은 값이 tails[pos]에 이미 존재하므로 그대로 사용한다
        if (pos < 0)
            pos = -(pos + 1);

        if (pos == tails.size()) {
            // num이 tails의 모든 요소보다 크므로 끝에 추가한다
            // 이것은 최장 증가 부분 수열의 길이가 1 늘어났음을 의미한다
            tails.add(num);
        } else {
            // 해당 위치의 마지막 최솟값을 num으로 교체하여 갱신한다
            // 이를 통해 길이 pos+1인 증가 부분 수열의 마지막 최솟값이 더 작아지며,
            // 향후 부분 수열을 확장할 수 있는 가능성이 넓어진다
            tails.set(pos, num);
        }
    }

    // tails의 요소 수는 처리 중에 끝에 추가가 수행된 횟수와 일치하며,
    // 이것이 최장 증가 부분 수열의 길이이다
    return tails.size();
}
```
