# Determining if a String Can Be Segmented Into Dictionary Words — 문자열을 사전의 단어로 분할할 수 있는지 판정하기

## 문제의 본질

문자열 `s`와 사전의 단어 리스트 `wordDict`가 주어진다. `s`를 사전에 포함된 단어의 연결로 분할할 수 있는지를 판정하여 **boolean**으로 반환한다. 각 사전의 단어는 몇 번이든 재사용할 수 있다.

## 핵심 아이디어

문자열의 처음부터 각 위치 `i`까지의 부분 문자열에 대해 「분할 가능한지 여부」를 기록해 나가면, 위치 `i`의 판정은 「어떤 분할점 `j`까지가 분할 가능」하고 「`j`에서 `i`까지의 부분 문자열이 사전에 존재하는지」의 여부로 귀결할 수 있다.

## 사고 프로세스

1. **부분 문제로 분해할 수 있다**: 문자열 `s`의 처음 `i`글자가 분할 가능한지를 판정하려면, 어떤 위치 `j`에서 둘로 나누어 「처음 `j`글자가 분할 가능」하고 「`j`에서 `i`까지가 사전의 단어」이면 된다. 이 구조는 동적 계획법에 적합하다
2. **DP의 정의를 결정한다**: `dp[i]`를 「문자열 `s`의 처음 `i`글자가 사전의 단어만으로 분할 가능한지 여부」를 나타내는 boolean으로 한다. 최종적으로 `dp[n]`（`n`은 문자열의 길이）이 답이 된다
3. **기저 조건을 설정한다**: 빈 문자열은 항상 분할 가능하므로 `dp[0] = true`로 한다. 이 기저 조건이 있기 때문에 문자열의 처음부터 시작하는 사전의 단어를 검출할 수 있다
4. **점화식을 생각한다**: `dp[i]`가 `true`가 되는 조건은, `0 ≤ j < i`의 어떤 `j`에 대해 「`dp[j]`가 `true`」이고 「`s.substring(j, i)`가 사전에 존재하는」 것이 성립하는 것이다. 모든 `j`를 시도하면 판정할 수 있다
5. **사전 검색을 고속화한다**: 단어 리스트를 HashSet으로 변환해 두면, 부분 문자열이 사전에 포함되는지를 `contains`로 O(1)에 판정할 수 있다. 리스트 그대로 선형 탐색하는 것보다 효율적이다
6. **조기 종료로 낭비를 줄인다**: 어떤 `j`에서 `dp[i] = true`가 확정되면, 그 이상의 `j`를 시도할 필요가 없다. `break`로 내부 루프를 빠져나와 다음 `i`로 진행한다

## 사전 지식

### HashSet이란

중복 없는 요소를 저장하는 데이터 구조이다. 요소가 포함되어 있는지의 판정을 O(1)로 수행할 수 있다. 사전의 단어 리스트를 고속으로 검색하기 위해 사용한다.

```java
Set<String> set = new HashSet<>();       // 빈 HashSet을 생성한다
set.add("apple");                        // 요소를 추가한다
set.contains("apple");                   // 요소가 존재하는지를 boolean으로 반환한다 → true
```

### 생성자를 이용한 List에서 Set으로의 변환

`HashSet`의 생성자에 List를 전달하면, List의 모든 요소를 Set으로 변환할 수 있다. 한 줄로 사전을 HashSet으로 변환하기 위해 사용한다.

```java
List<String> list = Arrays.asList("a", "b", "c");
Set<String> set = new HashSet<>(list);   // List의 모든 요소를 Set으로 변환한다
```

### substring이란

문자열의 일부를 잘라내는 메서드이다. `s.substring(j, i)`는 인덱스 `j`부터 `i - 1`까지의 문자를 반환한다. DP의 점화식에서 「위치 `j`부터 위치 `i`까지의 부분 문자열」을 가져오기 위해 사용한다.

```java
String s = "leetcode";
s.substring(0, 4);                       // "leet"를 반환한다（인덱스 0〜3）
s.substring(4, 8);                       // "code"를 반환한다（인덱스 4〜7）
```

### DP 배열（boolean 배열）이란

동적 계획법에서 부분 문제의 결과를 저장하는 배열이다. `boolean[] dp = new boolean[n + 1]`로 생성하면, 모든 요소가 `false`로 초기화된다. `dp[i]`에 `true`를 대입함으로써 「처음 `i`글자는 분할 가능하다」는 결과를 기록한다.

```java
boolean[] dp = new boolean[5];           // [false, false, false, false, false]로 초기화된다
dp[0] = true;                           // 기저 조건을 설정한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n^2) — 외부 루프가 n회, 내부 루프가 최대 n회이며, 각 단계에서 substring 생성에 O(n)이 걸리는 경우 엄밀히는 O(n^3)이지만, 평균적으로는 O(n^2)으로 취급한다 |
| Space | O(n) — 크기 n+1의 DP 배열과 HashSet에 사전의 단어를 저장한다 |

## 코드

```java
// 입력: 문자열 s와 사전의 단어 리스트 wordDict
// 출력: s를 사전의 단어만으로 분할할 수 있으면 true, 그렇지 않으면 false를 반환한다
public boolean wordBreak(String s, List<String> wordDict) {
    // 사전의 단어 리스트를 HashSet으로 변환하여 검색을 O(1)로 만든다
    Set<String> set = new HashSet<>(wordDict);
    // 문자열의 길이를 변수에 저장한다
    int n = s.length();

    // dp[i] = 처음 i글자가 사전의 단어만으로 분할 가능한지 여부
    // 크기가 n+1인 이유는 dp[n]이 문자열 전체의 분할 가능성을 나타내기 때문이다
    boolean[] dp = new boolean[n + 1];

    // 빈 문자열은 항상 분할 가능하다（기저 조건）
    // 이 설정이 없으면 문자열의 처음부터 시작하는 사전의 단어를 검출할 수 없다
    dp[0] = true;

    // 외부 루프: i는 「처음 몇 글자까지를 고려하는지」를 나타낸다
    for (int i = 1; i <= n; i++) {
        // 내부 루프: j는 분할점의 후보이다. 「처음 j글자」와 「j부터 i까지의 부분 문자열」로 나누는 위치이다
        for (int j = 0; j < i; j++) {
            // 처음 j글자가 분할 가능하고 j부터 i까지가 사전의 단어이면, 처음 i글자는 분할 가능하다
            // 두 조건이 동시에 성립한다 = 「분할 가능한 부분 + 사전의 단어」로 나눌 수 있다
            if (dp[j] && set.contains(s.substring(j, i))) {
                dp[i] = true;
                break;  // 분할 가능하다고 판명되었으므로 다른 j를 시도할 필요가 없다
            }
        }
    }

    // dp[n]은 문자열 s 전체가 분할 가능한지 여부를 나타낸다
    return dp[n];
}
```
