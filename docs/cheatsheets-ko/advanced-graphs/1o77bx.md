# Deriving the Order of an Alien Alphabet — 외계 언어의 문자 순서를 복원하기

## 문제의 본질

외계 언어의 사전순으로 정렬된 단어 리스트 `words`가 주어진다. 이 정렬 순서로부터 해당 언어에서의 알파벳 순서를 추정하여 문자열로 반환한다. 순서에 모순이 있는 경우(사이클이 존재하거나, 짧은 단어가 긴 단어 뒤에 오는 경우 등)에는 빈 문자열 `""`을 반환한다.

## 핵심 아이디어

인접한 두 단어를 비교하면 "처음으로 다른 문자"에서 하나의 순서 관계(유향 간선)를 얻을 수 있다. 모든 쌍에서 얻은 순서 관계를 유향 그래프로 구축하고, DFS 위상 정렬로 전체 순서를 결정한다. 사이클이 있으면 순서에 모순이 있는 것이다.

## 사고 과정

1. **인접 단어의 비교로 순서 관계를 추출한다**: 정렬된 리스트에서 인접한 두 단어 `words[i]`와 `words[i+1]`을 앞에서부터 비교하여, 처음으로 다른 문자 쌍 `(a, b)`를 찾으면 "a는 b보다 앞에 온다"는 순서 관계가 하나 확정된다. 이 관계는 유향 그래프의 간선 `a → b`로 표현할 수 있다
2. **무효한 입력을 검출한다**: `words[i]`가 `words[i+1]`의 접두사와 일치하면서 `words[i]`의 길이가 더 긴 경우(예: `"abc"`가 `"ab"` 앞에 오는 경우), 사전순으로 모순이므로 즉시 빈 문자열을 반환한다
3. **모든 문자를 노드로 등록한다**: 순서 관계를 얻을 수 없는 문자도 존재하므로, 모든 단어의 모든 문자를 그래프의 노드로 등록한다. 이를 통해 간선이 없는 문자도 결과에 포함된다
4. **DFS 위상 정렬로 전체 순서를 결정한다**: 유향 그래프에 대해 DFS를 실행하고, 각 노드의 탐색 완료 시점에 리스트에 추가한다. DFS의 후위 순서(post-order)를 역전하면 위상 정렬 순서(의존 원본이 먼저 오는 순서)를 얻을 수 있다
5. **3색 마킹으로 사이클을 검출한다**: DFS 중에 각 노드를 "미방문(0)", "탐색 중(1)", "탐색 완료(2)"의 3가지 상태로 관리한다. 탐색 중인 노드에 다시 도달한 경우 사이클이 존재하므로 순서를 결정할 수 없으며, 빈 문자열을 반환한다
6. **역순으로 문자열을 구성한다**: DFS의 후위 순서 리스트를 역전시켜 위상 정렬 순서를 얻는다. 리스트의 모든 문자를 연결하여 결과 문자열을 반환한다

## 전제 지식

### 위상 정렬이란

유향 비순환 그래프(DAG)의 모든 노드를 간선의 방향에 모순이 없는 순서로 한 줄로 나열하는 연산이다. 간선 `a → b`가 있으면 결과에서 반드시 `a`가 `b`보다 앞에 온다. 사이클이 있는 그래프에는 위상 정렬 순서가 존재하지 않는다.

### DFS의 3색 마킹이란

DFS에서 각 노드의 상태를 3가지 색으로 관리하는 기법이다. 흰색(0)은 미방문, 회색(1)은 현재 탐색 경로 위에 있음(재귀 스택에 존재), 검은색(2)은 탐색 완료를 나타낸다. 회색 노드에 다시 도달하면 사이클이 확정된다.

```java
Map<Character, Integer> color = new HashMap<>();
color.put('a', 0);  // 흰색: 미방문
color.put('a', 1);  // 회색: 탐색 중 (재귀 스택 위에 있음)
color.put('a', 2);  // 검은색: 탐색 완료 (모든 자손을 처리 완료)
```

### HashMap과 HashSet의 기본 연산

```java
// HashMap: 키와 값의 쌍을 저장한다. 검색 및 조회가 O(1)이다
Map<Character, Set<Character>> adj = new HashMap<>();
adj.putIfAbsent('a', new HashSet<>());  // 키가 미등록인 경우에만 빈 Set을 등록한다
adj.get('a').add('b');                  // 키 'a'의 인접 리스트에 'b'를 추가한다

// HashSet: 중복 없는 집합이다. 추가 및 검색이 O(1)이다
Set<Character> set = new HashSet<>();
set.add('b');        // 요소를 추가한다
set.contains('b');   // 요소의 존재 여부를 판정한다 → true
```

### startsWith 메서드

문자열이 지정된 접두사로 시작하는지를 판정한다.

```java
"abc".startsWith("ab");  // true — "abc"는 "ab"로 시작한다
"ab".startsWith("abc");  // false — "ab"는 "abc"로 시작하지 않는다
```

## 계산량

| | 값 |
|---|---|
| Time | O(C) — C는 모든 단어의 총 문자 수이다. 그래프 구축 시 모든 문자를 순회하며, DFS는 노드 수 + 간선 수에 비례하지만, 어느 것도 C를 초과하지 않는다 |
| Space | O(1) — 노드 수는 최대 26개 문자(영소문자)로 상수이다. 간선 수도 최대 26²으로 상수이다. 입력 크기에 의존하지 않는다 |

## 코드

```java
// 입력: 외계 언어의 사전순으로 정렬된 문자열 배열 words
// 출력: 알파벳 순서를 나타내는 문자열. 모순이 있는 경우 빈 문자열 ""을 반환한다

// DFS: 3색 마킹으로 사이클을 검출하면서 후위 순서를 기록한다
boolean dfs(char c, Map<Character, Set<Character>> adj,
            Map<Character, Integer> color, List<Character> result) {
    // 회색(탐색 중)에 다시 도달 → 사이클 검출
    if (color.get(c) == 1) return false;
    // 검은색(탐색 완료) → 이미 처리가 완료되었으므로 건너뛴다
    if (color.get(c) == 2) return true;

    // 현재 노드를 회색(탐색 중)으로 마킹한다
    color.put(c, 1);

    // 모든 인접 노드(이 문자보다 뒤에 오는 문자)에 대해 재귀적으로 DFS를 실행한다
    for (char n : adj.get(c))
        if (!dfs(n, adj, color, result))
            return false;  // 자손에서 사이클 검출 → 즉시 전파한다

    // 모든 자손의 탐색이 완료되었으므로 검은색으로 마킹한다
    color.put(c, 2);
    // 후위 순서로 리스트에 추가한다 (DFS에서는 의존 대상이 먼저 추가되므로, 역전 후에 위상 정렬 순서가 된다)
    result.add(c);
    return true;
}

public String alienOrder(String[] words) {
    // 인접 리스트: 키=문자, 값=해당 문자보다 뒤에 오는 문자의 집합
    Map<Character, Set<Character>> adj = new HashMap<>();

    // 모든 단어의 모든 문자를 그래프의 노드로 등록한다
    // 순서 관계(간선)가 없는 문자도 결과에 포함해야 하므로, 이 시점에서 모든 문자를 등록해 둔다
    for (String w : words)
        for (char c : w.toCharArray())
            adj.putIfAbsent(c, new HashSet<>());

    // 인접한 두 단어를 비교하여 순서 관계(유향 간선)를 추출한다
    for (int i = 0; i < words.length - 1; i++) {
        String w1 = words[i];
        String w2 = words[i + 1];

        // 무효 입력 검출: 긴 단어가 짧은 접두사보다 앞에 있는 경우 (예: ["abc","ab"]는 모순)
        if (w1.length() > w2.length() && w1.startsWith(w2))
            return "";

        int len = Math.min(w1.length(), w2.length());
        for (int j = 0; j < len; j++) {
            if (w1.charAt(j) != w2.charAt(j)) {
                // 처음으로 다른 문자에서 순서 관계를 하나 얻고, 즉시 루프를 빠져나간다
                // 두 번째 이후의 차이는 앞 문자가 같은 경우에만 의미를 가지므로, 하나만 추출한다
                adj.get(w1.charAt(j)).add(w2.charAt(j));
                break;
            }
        }
    }

    // 3색 관리 맵을 생성하고, 모든 노드를 흰색(0: 미방문)으로 초기화한다
    Map<Character, Integer> color = new HashMap<>();
    for (char c : adj.keySet())
        color.put(c, 0);

    // DFS의 후위 순서를 기록하는 리스트
    List<Character> result = new ArrayList<>();

    // 모든 노드에 대해 DFS를 실행한다 (연결되지 않은 그래프에도 대응하기 위해 모든 노드를 기점으로 한다)
    for (char c : adj.keySet())
        if (!dfs(c, adj, color, result))
            return "";  // 사이클 검출 → 순서를 결정할 수 없다

    // 후위 순서를 역전하여 위상 정렬 순서를 얻는다
    Collections.reverse(result);

    // 모든 문자를 연결하여 결과 문자열을 구성한다
    StringBuilder sb = new StringBuilder();
    for (char c : result) sb.append(c);
    return sb.toString();
}
```
