# Finding the Minimum Time to Swim Across a Grid — 그리드를 수영하여 건너는 최단 시간 구하기

## 문제의 본질

n×n 그리드가 주어지며, 각 셀에는 0부터 n²-1까지의 고유한 표고 값이 들어 있다. 어떤 셀에서 인접 셀(상하좌우)로 수영하여 이동할 수 있는 조건은, 현재 시각이 **양쪽 셀의 표고 이상**일 때뿐이다. 좌상단(0,0)에서 우하단(n-1,n-1)까지 도달하는 데 필요한 **최소 시각**을 구한다. 시작 시각은 grid[0][0]의 값이다.

## 핵심 아이디어

경로상에서 통과하는 셀의 표고의 **최댓값**이 해당 경로에 필요한 시각이 된다. 최소 힙을 사용하여 "현재 도달 가능한 셀 중 필요 시각이 가장 작은 셀"부터 순서대로 탐색하면, 처음으로 골에 도달한 시점의 시각이 최적해이다.

## 사고 프로세스

1. **이동 조건을 다시 표현한다**: 셀 A에서 셀 B로 이동하려면 "시각 ≥ max(A, B)"이 필요하다. 즉, 시작점에서 골까지의 경로 전체에서 필요한 시각은 "경로상의 모든 셀의 표고의 최댓값"과 같다. 따라서 문제는 "경로상의 최대 표고가 최소가 되는 경로를 찾는 것"으로 귀결된다
2. **최단 경로 문제와의 유사성을 파악한다**: 일반적인 Dijkstra는 "경로상의 간선 가중치의 합계"를 최소화하지만, 이 문제에서는 "경로상의 셀 표고의 최댓값"을 최소화한다. 합계 대신 최댓값을 사용함으로써 Dijkstra의 프레임워크를 그대로 적용할 수 있다
3. **우선순위 큐로 최소 시각의 셀부터 확장한다**: 최소 힙(PriorityQueue)에 셀을 "해당 셀에 도달하기 위해 필요한 시각"으로 저장한다. 항상 필요 시각이 가장 작은 셀부터 확장함으로써, 각 셀에 처음 도달한 시점의 시각이 최적임을 보장할 수 있다
4. **인접 셀로의 필요 시각을 계산한다**: 현재 셀(r,c)의 필요 시각이 `time`일 때, 인접 셀(nr,nc)로의 필요 시각은 `Math.max(time, grid[nr][nc])`로 계산한다. 이는 "여기까지의 경로상의 최대 표고"와 "다음 셀의 표고" 중 더 큰 쪽이 새로운 경로의 필요 시각이 되기 때문이다
5. **방문 완료 관리로 중복을 방지한다**: 최소 힙에서 꺼낸 셀은 해당 시점에서 최적 시각이 확정되어 있다. 방문 완료 배열 `vis`로 표시하여 같은 셀을 다시 처리하지 않도록 한다. 이는 Dijkstra의 확정 완료 노드와 동일한 개념이다
6. **골 도달 시 즉시 반환한다**: 힙에서 꺼낸 셀이 (n-1, n-1)이면 해당 시점의 `time`이 최소 시각이다. 최소 힙에 의해 최소 시각부터 순서대로 처리하고 있으므로, 처음으로 골에 도달한 시점이 최적해가 된다

## 사전 지식

### PriorityQueue(최소 힙)란

요소를 우선순위 순서대로 꺼낼 수 있는 데이터 구조이다. 기본적으로 최솟값이 최우선으로 꺼내진다. 삽입과 꺼내기 모두 O(log n)의 계산 복잡도로 동작한다. Dijkstra 알고리즘에서는 "미확정 노드 중 최소 비용인 것을 선택하는" 연산을 효율적으로 수행하기 위해 사용한다.

```java
// int[]의 제0요소를 기준으로 오름차순으로 정렬하는 최소 힙을 생성한다
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{5, 0, 0});   // 요소를 추가한다 (O(log n))
pq.offer(new int[]{3, 1, 0});   // 요소를 추가한다
int[] min = pq.poll();          // 최소 요소를 꺼내고 삭제한다 → {3, 1, 0}
boolean empty = pq.isEmpty();   // 큐가 비어 있는지 판정한다 → false
```

### Dijkstra 알고리즘의 변형이란

일반적인 Dijkstra 알고리즘은 간선 가중치의 **합계**를 최소화하지만, 이 문제에서는 경로상의 표고의 **최댓값**을 최소화한다. 거리 갱신 식을 `dist[next] = dist[cur] + weight`에서 `dist[next] = max(dist[cur], grid[next])`로 변경하는 것만으로, Dijkstra의 정당성(최소 힙에서 꺼낸 시점에 최적이 확정되는 성질)이 그대로 유지된다.

### 4방향 인접 셀 탐색

그리드 위의 셀(r,c)의 상하좌우 인접 셀은 방향 벡터 `{{0,1},{0,-1},{1,0},{-1,0}}`를 더하여 열거한다. 범위 밖 검사(0 ≤ nr < n 그리고 0 ≤ nc < n)를 수행하고, 유효한 셀만 처리한다.

```java
int[][] dir = {{0,1},{0,-1},{1,0},{-1,0}};  // 오른쪽·왼쪽·아래·위의 4방향
for (int[] d : dir) {
    int nr = r + d[0];  // 인접 셀의 행
    int nc = c + d[1];  // 인접 셀의 열
    if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
        // (nr, nc)는 유효한 인접 셀이다
    }
}
```

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(n² log n) — n²개의 셀을 각각 최대 1회 힙에 넣고 빼낸다. 힙 연산 1회당 O(log n²) = O(log n) |
| Space | O(n²) — 방문 완료 배열과 힙에 각각 최대 n²개의 셀을 보유한다 |

## 코드

```java
// 입력: n×n 정수 배열 grid (각 셀에 0부터 n²-1까지의 고유한 표고 값이 들어 있다)
// 출력: 좌상단(0,0)에서 우하단(n-1,n-1)까지 도달하기 위해 필요한 최소 시각을 int로 반환한다
int swimInWater(int[][] grid) {
    int n = grid.length;
    // 각 셀의 최적 시각이 확정되었는지를 관리하는 방문 완료 배열 (vis[r][c] = true이면 확정 완료)
    boolean[][] vis = new boolean[n][n];
    // 필요 시각이 작은 순서대로 꺼내는 최소 힙 (요소: {시각, 행, 열})
    // 비교 함수 (a,b)->a[0]-b[0]에 의해 제0요소(필요 시각)의 오름차순으로 꺼내진다
    PriorityQueue<int[]> pq =
        new PriorityQueue<>(
            (a, b) -> a[0] - b[0]);
    // 시작 지점을 힙에 추가하고 방문 완료로 표시한다
    // 제0요소가 필요 시각, 제1요소가 행, 제2요소가 열이다
    pq.offer(new int[]
        {grid[0][0], 0, 0});
    vis[0][0] = true;
    // 상하좌우 4방향 벡터
    int[][] dir =
        {{0,1},{0,-1},{1,0},{-1,0}};
    while (!pq.isEmpty()) {
        // 필요 시각이 최소인 셀을 꺼낸다 (최소 힙의 성질에 의해 이 시점에서 최적 시각이 확정된다)
        int[] cur = pq.poll();
        int time = cur[0];
        int r = cur[1], c = cur[2];
        // 골에 도달하면 해당 시각이 최적해이다 (최소 시각부터 순서대로 처리하므로 첫 번째 도달이 최적이다)
        if (r == n-1 && c == n-1)
            return time;
        // 4방향의 인접 셀을 탐색한다
        for (int[] d : dir) {
            int nr = r+d[0];
            int nc = c+d[1];
            // 범위 내이고 미방문인 셀만 처리한다
            if (nr >= 0 && nr < n
                && nc >= 0 && nc < n
                && !vis[nr][nc]) {
                // 주의: 힙에 추가하는 시점에서 방문 완료로 표시하여 같은 셀이 여러 번 힙에 추가되는 것을 방지한다
                vis[nr][nc] = true;
                // 경로상의 최대 표고가 필요 시각이 된다 ("여기까지의 최대 표고"와 "다음 셀의 표고" 중 더 큰 쪽)
                int nt = Math.max(
                    time,grid[nr][nc]);
                pq.offer(new int[]
                    {nt, nr, nc});
            }
        }
    }
    // 문제의 제약상 그리드는 연결되어 있으므로 여기에는 도달하지 않는다
    return -1;
}
```
