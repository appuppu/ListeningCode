# Reconstructing a Flight Itinerary — 항공 티켓으로 사전순 최소 여정을 재구성하기

## 문제의 본질

출발 공항과 도착 공항의 쌍으로 표현된 항공 티켓 리스트가 주어진다. JFK에서 출발하여 모든 티켓을 정확히 1번씩 사용하는 여정을 재구성한다. 유효한 여정이 여러 개 존재하는 경우에는 사전순으로 가장 작은 여정을 반환한다.

## 핵심 아이디어

모든 간선(티켓)을 정확히 1번씩 통과하는 오일러 경로 문제이다. 각 공항의 목적지를 PriorityQueue로 관리하면 사전순 최소가 자동으로 보장되며, Hierholzer 알고리즘으로 뒤에서부터 여정을 구성하면 막다른 길을 올바르게 처리할 수 있다.

## 사고 프로세스

1. **모든 티켓을 1번씩 사용 = 오일러 경로**: 각 티켓은 유향 그래프의 간선이며, 모든 간선을 정확히 1번 통과하는 경로를 구하는 문제는 오일러 경로(Eulerian Path) 문제로 귀결된다
2. **사전순 최소를 보장하려면 정렬이 필요하다**: 각 공항에서 여러 목적지가 있는 경우, 사전순으로 작은 쪽을 먼저 선택해야 한다. 각 공항의 목적지를 PriorityQueue(최소 힙)에 저장하면, `poll()`하는 것만으로 항상 사전순 최소의 목적지를 얻을 수 있다
3. **단순한 탐욕법으로는 막다른 길에 대처할 수 없다**: 사전순 최소를 항상 선택하면, 미사용 간선이 남아 있는데도 먼저 막다른 길에 도달해 버리는 경우가 있다. 예를 들어 JFK→A→JFK→B 티켓이 있을 때, JFK에서 A를 먼저 선택하면 A→JFK→B로 진행할 수 있지만, B를 먼저 선택하면 B에서 막다른 길이 된다
4. **Hierholzer 알고리즘으로 뒤에서부터 구성한다**: DFS에서 목적지가 없어진(막다른 길에 도달한) 노드를 결과 리스트의 **맨 앞**에 추가한다. 이렇게 하면 막다른 길은 여정의 끝부분에 배치되고, 나머지 간선은 재귀의 되감기 시에 올바른 순서로 맨 앞에 추가된다
5. **재귀 DFS의 동작**: 현재 노드에서 PriorityQueue로 사전순 최소의 목적지를 꺼내어 재귀적으로 DFS한다. 목적지가 없어지면 결과 리스트의 맨 앞에 현재 노드를 추가한다. LinkedList의 `addFirst`를 사용하면 O(1)로 맨 앞에 추가할 수 있다
6. **최종적으로 반환하는 것**: 모든 DFS가 완료된 후, 결과 리스트(LinkedList)를 그대로 반환한다. 리스트에는 JFK에서 시작하는 사전순 최소의 여정이 저장되어 있다

## 사전 지식

### PriorityQueue(우선순위 큐)란

요소를 추가하면 자동으로 정렬되어, 꺼낼 때 항상 최솟값을 얻을 수 있는 자료 구조이다. 내부는 힙으로 구현되어 있으며, 추가와 꺼내기 모두 O(log n)으로 동작한다.

```java
PriorityQueue<String> pq = new PriorityQueue<>();  // 문자열의 자연 순서(사전순)로 최소 힙을 생성한다
pq.offer("SFO");       // "SFO"를 추가한다
pq.offer("ATL");       // "ATL"을 추가한다
pq.poll();             // 최솟값 "ATL"을 꺼내어 삭제한다 → "ATL"
pq.isEmpty();          // 큐가 비어 있는지를 boolean으로 반환한다 → false ("SFO"가 남아 있다)
```

### computeIfAbsent란

HashMap의 키가 존재하지 않는 경우에만 지정한 함수로 값을 생성하여 등록하고, 그 값을 반환하는 메서드이다. 키가 이미 존재하는 경우에는 기존 값을 그대로 반환한다. `get`하고 `null` 체크하고 `put`하는 3단계를 1행으로 작성할 수 있다.

```java
Map<String, PriorityQueue<String>> graph = new HashMap<>();
// "JFK" 키가 존재하지 않으면 새로운 PriorityQueue를 생성하여 등록하고, 그 PriorityQueue를 반환한다
graph.computeIfAbsent("JFK", k -> new PriorityQueue<>()).offer("SFO");
// "JFK" 키가 이미 존재하므로, 기존 PriorityQueue를 반환한다 (새로 생성하지 않는다)
graph.computeIfAbsent("JFK", k -> new PriorityQueue<>()).offer("ATL");
```

### LinkedList의 addFirst란

리스트의 맨 앞에 요소를 O(1)로 추가하는 메서드이다. 일반적인 `add`(끝에 추가)와는 달리, 기존 요소를 뒤로 밀지 않고 맨 앞에 삽입할 수 있다. Hierholzer 알고리즘에서 역순으로 결과를 구성할 때 사용한다.

```java
LinkedList<String> result = new LinkedList<>();
result.addFirst("JFK");   // result: ["JFK"]
result.addFirst("ATL");   // result: ["ATL", "JFK"]
result.addFirst("SFO");   // result: ["SFO", "ATL", "JFK"]
```

### Hierholzer 알고리즘이란

오일러 경로(모든 간선을 정확히 1번 통과하는 경로)를 구하는 알고리즘이다. DFS로 간선을 소비하면서 진행하고, 막다른 길에 도달한 노드를 결과의 맨 앞에 추가한다. 모든 간선을 사용한 후, 결과 리스트에는 오일러 경로가 올바른 순서로 저장된다. 막다른 길을 여정의 끝부분에 자연스럽게 배치할 수 있다는 점이 이 문제에 적합하다.

## 계산량

| | 값 |
|---|---|
| Time | O(E log E) — 각 티켓(간선)을 PriorityQueue에 추가·꺼낼 때 log E의 비용이 발생한다 |
| Space | O(V + E) — 그래프의 인접 리스트에 모든 간선을 저장하고, 재귀 스택은 최대 간선 수만큼 깊어진다 |

## 코드

```java
// 입력: 항공 티켓 리스트 tickets (각 티켓은 [출발 공항, 도착 공항]의 문자열 쌍)
// 출력: JFK에서 시작하는 사전순 최소의 여정을 List<String>으로 반환한다
public List<String> findItinerary(List<List<String>> tickets) {
    // 키=출발 공항, 값=도착 공항을 사전순으로 관리하는 PriorityQueue
    // PriorityQueue를 사용하면 꺼낼 때 항상 사전순 최소의 목적지를 얻을 수 있다
    Map<String, PriorityQueue<String>> graph = new HashMap<>();

    // 모든 티켓으로 그래프를 구성한다
    // computeIfAbsent에 의해, src 키가 처음 등장하면 새로운 PriorityQueue를 생성하고, 이미 존재하면 그대로 가져온다
    for (List<String> t : tickets) {
        graph.computeIfAbsent(t.get(0), k -> new PriorityQueue<>())
             .offer(t.get(1));
    }

    // 결과를 저장하는 LinkedList (addFirst로 O(1)의 맨 앞 추가를 수행하기 위해)
    LinkedList<String> result = new LinkedList<>();

    // JFK에서 DFS를 시작한다
    dfs("JFK", graph, result);
    return result;
}

void dfs(String curr,
          Map<String, PriorityQueue<String>> graph,
          LinkedList<String> result) {
    // 현재 공항에서 갈 수 있는 목적지의 PriorityQueue를 가져온다
    PriorityQueue<String> dests = graph.get(curr);

    // 목적지가 존재하는 동안, 사전순 최소의 목적지를 꺼내어 DFS한다
    // 주의: poll()은 요소를 삭제하므로, 같은 간선(티켓)을 2번 통과하는 일은 없다
    while (dests != null && !dests.isEmpty()) {
        dfs(dests.poll(), graph, result);
    }

    // 막다른 길에 도달하면, 결과 리스트의 맨 앞에 현재 공항을 추가한다
    // 맨 앞에 추가함으로써, 막다른 길의 노드는 여정의 끝부분에 배치되고,
    // 나중에 추가되는 노드가 여정의 앞부분에 올바르게 배치된다
    result.addFirst(curr);
}
```
