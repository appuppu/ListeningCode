# 네트워크 신호 전파 시간 계산 — 네트워크 전체에 신호가 도달하는 최단 시간을 구한다

## 문제의 본질

`n` 개의 노드(1~n)와 가중치가 있는 유향 간선 리스트 `times`(각 간선은 `[송신원, 수신처, 소요 시간]`)가 주어진다. 지정된 소스 노드 `k`에서 신호를 송신했을 때, 모든 노드에 신호가 도달하는 최단 시간을 반환한다. 도달 불가능한 노드가 하나라도 있으면 `-1`을 반환한다.

## 핵심 아이디어

"모든 노드에 도달하는 최단 시간"은 "각 노드까지의 최단 거리 중 최댓값"과 같다. 다익스트라 알고리즘으로 모든 노드까지의 최단 거리를 구한 뒤, 그 최댓값을 취하면 된다.

## 사고 프로세스

1. **문제를 최단 경로 문제로 파악한다**: 신호는 소스 노드에서 각 간선을 따라 전파된다. 각 노드에 신호가 도달하는 시각은 소스에서 해당 노드까지의 최단 거리와 같다. 따라서 단일 시작점 최단 경로 문제를 풀면 된다
2. **모든 노드까지의 최단 거리를 효율적으로 구하고 싶다**: 간선의 가중치가 비음수이므로 다익스트라 알고리즘을 적용할 수 있다. 다익스트라 알고리즘은 우선순위 큐(min-heap)를 사용하여, 거리가 최소인 노드부터 탐욕적으로 확정해 나간다
3. **그래프의 표현 방법을 결정한다**: 인접 리스트를 사용한다. 각 노드에 대해 "인접 노드와 해당 간선의 가중치" 쌍을 리스트로 보유한다. 이를 통해 특정 노드에서 나가는 간선을 효율적으로 열거할 수 있다
4. **거리 배열을 초기화한다**: 모든 노드의 거리를 무한대(`Integer.MAX_VALUE`)로 초기화하고, 소스 노드 `k`의 거리를 0으로 설정한다. 소스에서 자기 자신까지의 거리는 0이기 때문이다
5. **우선순위 큐로 최단 거리의 노드를 처리한다**: 큐에서 거리가 최소인 노드를 꺼내고, 해당 노드의 인접 노드에 대해 거리를 갱신(완화)한다. 갱신이 발생하면 큐에 추가한다
6. **중복 처리를 건너뛴다**: 큐에서 꺼낸 노드의 거리가 현재의 최단 거리보다 크면, 이미 더 좋은 경로로 처리가 완료된 것이므로 건너뛴다. 이를 통해 불필요한 계산을 피한다
7. **모든 노드의 최단 거리로부터 답을 구한다**: 모든 노드의 거리 배열을 순회하여, 무한대인 채로 남아 있는 노드가 있으면 도달 불가능하므로 `-1`을 반환한다. 그렇지 않으면 거리의 최댓값이 답이다

## 전제 지식

### 인접 리스트(Adjacency List)란

그래프를 표현하는 데이터 구조이다. 각 노드마다 "해당 노드에서 나가는 간선의 목록"을 리스트로 보유한다. 노드 수 `n`에 대해 `List<List<int[]>>`로 표현하며, `graph.get(u)`로 노드 `u`에서 나가는 간선을 가져온다.

```java
List<List<int[]>> graph = new ArrayList<>();
for (int i = 0; i <= n; i++) {
    graph.add(new ArrayList<>());       // 각 노드에 빈 리스트를 준비한다
}
graph.get(1).add(new int[]{2, 5});      // 노드1→노드2, 가중치 5인 간선을 추가한다
graph.get(1).add(new int[]{3, 2});      // 노드1→노드3, 가중치 2인 간선을 추가한다
```

### PriorityQueue(우선순위 큐)란

요소를 추가하는 순서에 관계없이, 항상 최솟값(또는 최댓값)을 가진 요소를 선두에 유지하는 데이터 구조이다. 다익스트라 알고리즘에서는 "거리가 최소인 노드"를 효율적으로 꺼내기 위해 사용한다.

```java
// int[]의 첫 번째 요소(거리)를 기준으로 오름차순 정렬하는 min-heap
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{0, 1});   // {거리 0, 노드 1}을 큐에 추가한다
pq.offer(new int[]{5, 2});   // {거리 5, 노드 2}를 큐에 추가한다
int[] curr = pq.poll();       // 거리가 최소인 요소 {0, 1}을 꺼낸다
pq.isEmpty();                 // 큐가 비어 있는지를 boolean으로 반환한다
```

### 다익스트라 알고리즘의 완화(Relaxation)란

특정 노드 `u`를 경유하여 노드 `v`에 도달하는 거리 `dist[u] + w`가 현재의 `dist[v]`보다 작을 때, `dist[v]`를 더 짧은 값으로 갱신하는 연산이다. 이 갱신을 반복함으로써 최종적으로 모든 노드까지의 최단 거리가 확정된다.

```java
int newDist = dist[u] + w;      // u를 경유하여 v에 가는 거리를 계산한다
if (newDist < dist[v]) {        // 현재의 최단 거리보다 짧으면
    dist[v] = newDist;          // 최단 거리를 갱신한다
    pq.offer(new int[]{newDist, v});  // 갱신된 v를 큐에 추가한다
}
```

## 계산량

| | 값 |
|---|---|
| Time | O((V + E) log V) — 각 노드와 각 간선에 대해 우선순위 큐 연산(log V)을 수행한다 |
| Space | O(V + E) — 인접 리스트에 모든 간선을 저장하고, 거리 배열과 큐에 노드 수만큼을 사용한다 |

## 코드

```java
// 입력: 유향 간선 리스트 int[][] times(각 요소는 [시작점, 끝점, 가중치]), 노드 수 int n, 소스 노드 int k
// 출력: 소스에서 모든 노드에 신호가 도달하는 최단 시간을 int로 반환한다. 도달 불가능한 노드가 있으면 -1을 반환한다
public int networkDelayTime(int[][] times, int n, int k) {
    // 인접 리스트를 생성한다(노드 번호가 1부터 시작하므로, 크기 n+1로 만들어 인덱스 0은 미사용으로 둔다)
    List<List<int[]>> graph = new ArrayList<>();
    for (int i = 0; i <= n; i++) {
        graph.add(new ArrayList<>());
    }
    // 각 간선 [u, v, w]를 인접 리스트에 등록하여 유향 그래프의 인접 리스트 표현을 완성한다
    for (int[] t : times) {
        graph.get(t[0]).add(new int[]{t[1], t[2]});
    }

    // 거리 배열을 무한대로 초기화한다. dist[i]는 "소스에서 노드 i까지의 현재 최단 거리"를 나타낸다
    int[] dist = new int[n + 1];
    Arrays.fill(dist, Integer.MAX_VALUE);
    // 소스 노드에서 자기 자신까지의 거리는 0이다
    dist[k] = 0;

    // 거리(첫 번째 요소) 기준 오름차순으로 꺼내는 min-heap을 생성하고, 소스 노드 {거리 0, 노드 k}를 추가한다
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, k});

    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int d = curr[0];  // 소스에서 노드 u까지의 거리
        int u = curr[1];  // 현재 처리하는 노드

        // d > dist[u]이면, 이미 더 짧은 거리로 처리가 완료된 상태이다. 큐에 오래된(거리가 큰) 항목이 남아 있는 경우에 발생한다
        if (d > dist[u]) continue;

        // 인접 노드에 대해 완화를 시도한다
        for (int[] nei : graph.get(u)) {
            int v = nei[0];  // 인접 노드
            int w = nei[1];  // 간선의 가중치
            // u를 경유한 거리 d + w가 현재의 dist[v]보다 짧으면, 거리를 갱신하고 큐에 추가한다
            if (d + w < dist[v]) {
                dist[v] = d + w;
                pq.offer(new int[]{d + w, v});
            }
        }
    }

    // 모든 노드의 최단 거리 중 최댓값을 구한다. 이 최댓값이 "모든 노드에 신호가 도달하는 최단 시간"이다
    int max = 0;
    for (int i = 1; i <= n; i++) {
        // Integer.MAX_VALUE인 채로 남아 있으면 도달 불가능한 노드가 존재하므로 -1을 반환한다
        if (dist[i] == Integer.MAX_VALUE) return -1;
        max = Math.max(max, dist[i]);
    }
    return max;
}
```
