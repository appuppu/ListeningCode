# Finding the Cheapest Flight With Limited Stops — 최대 k번의 환승으로 최저가 항공편 찾기

## 문제의 본질

`n`개의 도시와 항공편 목록 `[from, to, price]`, 출발지 `src`, 목적지 `dst`, 최대 환승 횟수 `k`가 주어진다. 출발지에서 목적지까지 **최대 k번의 환승**(경유지가 k개 이하)으로 도달할 수 있는 최저 총 운임을 반환한다. 도달이 불가능한 경우에는 `-1`을 반환한다.

## 핵심 아이디어

일반적인 Dijkstra는 비용이 최소인 경로만을 추적하지만, 이 문제에서는 "비용이 높더라도 환승 횟수가 적은 경로"가 최종적으로 최저가 경로가 될 가능성이 있다. 따라서 각 도시에 도달한 "최소 환승 횟수"를 기록하고, 더 적은 환승으로 도달할 수 있는 경로만을 탐색 대상으로 남김으로써, 비용과 환승 횟수 양쪽을 모두 고려한 최적해를 구한다.

## 사고 과정

1. **최저가 경로 탐색에는 Dijkstra가 기본이다**: 가중치가 있는 그래프의 최단 경로 문제이므로, 우선순위 큐를 사용한 Dijkstra가 기본 방침이 된다. 비용이 작은 순서대로 노드를 꺼냄으로써, 목적지에 처음 도달한 시점에서 그것이 최저가가 된다
2. **환승 횟수 제약을 어떻게 처리할 것인가**: 일반적인 Dijkstra는 "최소 비용으로 도달한 도시는 재방문하지 않는다"는 원칙을 따르지만, 이 문제에서는 환승 횟수의 제약이 있다. 비용이 최소인 경로로 도달했더라도 환승 횟수가 k번을 초과하면 무효이며, 비용이 약간 높더라도 환승이 적은 경로가 유효할 수 있다
3. **각 도시에 대한 "최소 환승 횟수"를 기록한다**: 배열 `stops[]`를 준비하여 각 도시에 도달한 최소 환승 횟수를 기록한다. 어떤 도시에 이전보다 많은 환승 횟수로 도달한 경우, 그 경로는 비용에서도 환승 횟수에서도 개선이 없으므로 가지치기할 수 있다
4. **우선순위 큐에 무엇을 저장할 것인가**: 각 상태를 `[비용, 도시, 환승 횟수]`의 3개 값으로 관리한다. 비용 오름차순으로 꺼냄으로써, 목적지에 처음 도달한 시점의 해가 최저가가 된다
5. **가지치기 조건을 정리한다**: (a) 현재 환승 횟수가 해당 도시의 기록된 최소 환승 횟수 이상이면 탐색을 중단한다. (b) 환승 횟수가 k를 초과하면 그 이후의 인접 도시로의 확장을 수행하지 않는다
6. **인접 도시로의 확장**: 가지치기를 통과한 경우에만, 인접하는 각 도시에 대해 `[현재 비용 + 운임, 인접 도시, 환승 횟수 + 1]`을 큐에 추가한다

## 사전 지식

### 인접 리스트(Adjacency List)란

그래프의 각 정점에 대해, 그곳에서 직접 갈 수 있는 정점과 간선의 가중치를 리스트로 보유하는 자료 구조이다. `HashMap<Integer, List<int[]>>`로 표현하며, 키가 출발 도시, 값이 `[도착 도시, 운임]`의 리스트가 된다.

```java
Map<Integer, List<int[]>> adj = new HashMap<>();
// 도시 0에서 도시 1로 운임 100인 항공편을 추가
adj.computeIfAbsent(0, x -> new ArrayList<>()).add(new int[]{1, 100});
// 도시 0의 인접 리스트를 조회
List<int[]> neighbors = adj.get(0);  // → [[1, 100]]
```

### PriorityQueue(우선순위 큐)란

요소를 추가하면 내부에서 자동으로 정렬되어, 항상 최솟값(또는 최댓값)의 요소를 선두에서 꺼낼 수 있는 자료 구조이다. Dijkstra에서는 "비용이 최소인 상태"를 효율적으로 꺼내기 위해 사용한다.

```java
// int[]의 첫 번째 요소(비용)를 기준으로 오름차순 정렬하는 우선순위 큐
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{100, 1, 0});   // [비용=100, 도시=1, 환승=0]을 추가
pq.offer(new int[]{50, 2, 1});    // [비용=50, 도시=2, 환승=1]을 추가
int[] min = pq.poll();            // 비용이 최소인 [50, 2, 1]을 꺼냄
pq.isEmpty();                      // 큐가 비어 있는지 판정 → false
```

### stops 배열을 이용한 가지치기란

일반적인 Dijkstra에서는 `visited` 배열로 방문한 도시를 관리하지만, 이 문제에서는 같은 도시에 "서로 다른 환승 횟수"로 도달하는 경로를 구별할 필요가 있다. `stops[]` 배열에 각 도시에 대한 최소 환승 횟수를 기록하고, 그 이상의 환승 횟수로 도달한 경로를 중단함으로써 불필요한 탐색을 제거한다.

```java
int[] stops = new int[n];
Arrays.fill(stops, k + 2);  // k+2는 "아직 미도달"을 의미하는 충분히 큰 초기값
// 도시 2에 환승 1회로 도달한 경우
stops[2] = 1;
// 이후 도시 2에 환승 2회로 도달 → 2 >= stops[2]이므로 가지치기(스킵)
```

## 계산량

| | 값 |
|---|---|
| Time | O(E · log n) — 각 항공편(간선)에 대해 우선순위 큐로의 추가·꺼내기에 log n이 소요된다 |
| Space | O(n + E) — 인접 리스트에 O(E), stops 배열에 O(n), 큐에 최대 O(E)의 상태를 보유한다 |

## 코드

```java
// 입력: 도시 수 n, 항공편 배열 flights(각 요소는 [from, to, price]), 출발지 src, 목적지 dst, 최대 환승 횟수 k
// 출력: 최대 k번의 환승으로 출발지에서 목적지에 도달하는 최저 운임을 int로 반환한다. 도달이 불가능한 경우에는 -1을 반환한다
public int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
    // 인접 리스트를 구축한다. 키=출발 도시, 값=[도착 도시, 운임]의 리스트
    // 각 항공편 f에 대해, adj의 키 f[0]에 [f[1], f[2]]를 추가한다
    Map<Integer, List<int[]>> adj = new HashMap<>();
    for (int[] f : flights)
        adj.computeIfAbsent(f[0], x -> new ArrayList<>())
            .add(new int[]{f[1], f[2]});

    // 비용 오름차순의 우선순위 큐. 각 상태는 [비용, 도시, 환승 횟수]
    // 비용이 작은 상태를 우선적으로 꺼냄으로써, 목적지에 처음 도달한 시점이 최저가가 된다
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    // 초기 상태: 출발지에 비용 0, 환승 0회로 도달해 있다
    pq.offer(new int[]{0, src, 0});

    // 각 도시에 대한 최소 환승 횟수를 기록하는 배열
    // k+2는 환승 상한 k보다 충분히 큰 값으로 "아직 미도달"을 의미하는 초기값
    int[] stops = new int[n];
    Arrays.fill(stops, k + 2);

    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int cost = curr[0];
        int city = curr[1];
        int stop = curr[2];

        // 목적지에 도달하면, 비용 오름차순으로 꺼내고 있으므로 이것이 최저가이다
        if (city == dst) return cost;

        // 이 도시에 이전보다 많은(또는 같은) 환승으로 도달한 경우에는 가지치기한다
        // 비용 오름차순으로 꺼내고 있으므로, 이전 도달은 비용도 작다 → 탐색할 의미가 없다
        if (stop >= stops[city]) continue;
        // 이 도시에 도달한 최소 환승 횟수를 갱신한다
        stops[city] = stop;

        // 환승 횟수가 상한 k를 초과하면, 이 도시에서 더 이상 인접 도시로 확장할 수 없다
        if (stop > k) continue;

        // 이 도시에서 출발하는 항공편이 없으면 스킵한다
        if (!adj.containsKey(city)) continue;

        // 인접하는 각 도시에 대해 [누적 비용, 인접 도시, 환승 횟수+1]을 큐에 추가한다
        for (int[] next : adj.get(city)) {
            pq.offer(new int[]{cost + next[1], next[0], stop + 1});
        }
    }

    // 루프가 종료되어도 목적지에 도달하지 못한 경우에는 -1을 반환한다
    return -1;
}
```
