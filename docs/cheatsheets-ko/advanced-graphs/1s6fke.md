# Finding the Minimum Cost to Connect All Points — 모든 점을 최소 비용으로 연결하기

## 문제의 본질

2D 평면 위의 점 배열 `points`가 주어진다. 임의의 두 점 사이의 비용은 맨해튼 거리 `|xi - xj| + |yi - yj|`로 정의된다. 모든 점을 연결하기 위한 **최소 총 비용**을 반환한다. 이것은 최소 신장 트리(MST: Minimum Spanning Tree)를 구하는 문제이다.

## 핵심 아이디어

모든 점을 최소 비용으로 연결하려면, Prim의 알고리즘으로 "현재 MST에 가장 가까운 미방문 점"을 탐욕적으로 계속 선택하면 된다. 우선순위 큐를 사용하면 최소 비용의 간선을 효율적으로 꺼낼 수 있다.

## 사고 프로세스

1. **이것은 MST 문제이다**: 모든 점을 연결하면서 비용을 최소화한다. 이것은 최소 신장 트리의 정의 그 자체이다. 그래프의 간선 가중치는 맨해튼 거리로 계산할 수 있다
2. **완전 그래프이므로 Prim이 적합하다**: n개의 점이 있으면 간선의 수는 n(n-1)/2개가 된다. Kruskal에서는 모든 간선을 사전에 생성하고 정렬해야 하지만, Prim이라면 현재 MST에 인접한 간선만 순차적으로 처리할 수 있다
3. **최소 비용의 간선을 빠르게 꺼내고 싶다**: Prim의 알고리즘에서는 매번 "미방문 점으로의 최소 비용 간선"을 선택해야 한다. 우선순위 큐(최소 힙)를 사용하면 이 꺼내기를 O(log n)으로 수행할 수 있다
4. **임의의 점에서 시작할 수 있다**: MST의 총 비용은 어떤 점에서 시작해도 동일하므로, 점 0에서 시작한다. 초기 상태에서는 점 0으로의 비용 0을 큐에 넣는다
5. **방문 완료 플래그로 중복을 방지한다**: 큐에서 꺼낸 점이 이미 MST에 포함되어 있는 경우에는 건너뛴다. 이를 통해 같은 점을 이중으로 처리하는 것을 방지한다
6. **새로운 점을 MST에 추가할 때마다 인접 간선을 추가한다**: MST에 점 u를 추가하면, u에서 모든 미방문 점 v로의 맨해튼 거리를 계산하고 큐에 추가한다. 큐가 자동으로 최소 비용의 간선을 다음 후보로 관리한다

## 사전 지식

### 최소 신장 트리(MST)란

그래프의 모든 정점을 연결하는 부분 그래프 중에서 간선 가중치의 합이 최소인 것이다. n개의 정점에 대해 정확히 n-1개의 간선을 가지며, 사이클을 포함하지 않는다.

### Prim의 알고리즘이란

MST를 구축하는 탐욕 알고리즘이다. 임의의 정점에서 시작하여, "현재 MST와 미방문 정점을 잇는 간선 중 최소 가중치의 간선"을 반복적으로 선택하여 MST를 확장한다. 모든 정점이 MST에 포함되면 종료한다.

### 맨해튼 거리란

두 점 사이의 각 좌표 차이의 절댓값의 합이다. 2D 평면 위의 점 `(x1, y1)`과 `(x2, y2)`의 거리는 `|x1 - x2| + |y1 - y2|`로 계산한다. 격자 형태의 길을 걸을 때의 최단 거리에 해당한다.

```java
int dist = Math.abs(pts[u][0] - pts[v][0]) + Math.abs(pts[u][1] - pts[v][1]);
```

### PriorityQueue(우선순위 큐)란

요소를 우선순위 순서대로 꺼낼 수 있는 데이터 구조이다. 기본적으로 최솟값이 먼저 꺼내진다(최소 힙). `offer`로 추가하고, `poll`로 최소 요소를 꺼내며, 둘 다 O(log n)으로 동작한다.

```java
// int[]의 첫 번째 요소를 기준으로 오름차순으로 정렬하는 우선순위 큐를 생성한다
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{5, 0});   // [비용=5, 점의 인덱스=0]을 추가한다
pq.offer(new int[]{2, 1});   // [비용=2, 점의 인덱스=1]을 추가한다
int[] min = pq.poll();       // 비용이 최소인 요소 [2, 1]을 꺼낸다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n² log n) — 각 점을 MST에 추가할 때마다 최대 n개의 간선을 큐에 추가하며, 큐 연산에 log n이 소요된다 |
| Space | O(n²) — 큐에 최대 n²개의 간선이 저장된다. inMST 배열은 O(n)이다 |

## 코드

```java
// 입력: 2D 좌표의 배열 pts (각 요소는 [x, y])
// 출력: 모든 점을 연결하는 최소 비용을 int로 반환한다
int minCostConnectPoints(int[][] pts) {
    // 점의 개수를 가져온다
    int n = pts.length;
    // 각 점이 MST에 포함되어 있는지를 관리하는 플래그 배열 (모두 false로 초기화된다)
    boolean[] inMST = new boolean[n];
    // {비용, 점의 인덱스}를 저장하고, 비용 오름차순으로 꺼내는 우선순위 큐
    PriorityQueue<int[]> pq =
        new PriorityQueue<>((a, b) -> a[0] - b[0]);
    // 시작점(인덱스 0)을 비용 0으로 큐에 추가한다
    // 비용 0은 첫 번째 점을 MST에 추가하는 비용이 0임을 의미한다
    // MST의 총 비용은 어떤 점에서 시작해도 동일하므로, 임의로 점 0을 선택하고 있다
    pq.offer(new int[]{0, 0});
    // cost: MST의 총 비용, visited: MST에 추가된 점의 수
    int cost = 0, visited = 0;

    // 모든 점이 MST에 포함될 때까지 반복한다
    while (visited < n) {
        // 비용이 최소인 간선을 꺼낸다 (d: 연결 비용, u: 점의 인덱스)
        int[] curr = pq.poll();
        int d = curr[0], u = curr[1];

        // 이미 MST에 포함되어 있는 점은 건너뛴다
        // 같은 점이 다른 비용으로 큐에 여러 번 추가되어 있을 수 있으므로, 이 판정이 필요하다
        if (inMST[u]) continue;

        // 점 u를 MST에 추가하고, 비용을 가산한다
        inMST[u] = true;
        cost += d;
        visited++;

        // 점 u에서 모든 미방문 점으로의 간선을 큐에 추가한다
        // 다음 후보 간선이 큐에 등록되며, 큐가 자동으로 최소 비용의 간선을 관리한다
        for (int v = 0; v < n; v++) {
            if (!inMST[v]) {
                // 맨해튼 거리를 계산한다: |xu - xv| + |yu - yv|
                int nd =
                    Math.abs(pts[u][0] - pts[v][0])
                    + Math.abs(pts[u][1] - pts[v][1]);
                pq.offer(new int[]{nd, v});
            }
        }
    }
    // while 루프 종료 후, cost에 MST의 총 비용이 저장되어 있다
    return cost;
}
```
