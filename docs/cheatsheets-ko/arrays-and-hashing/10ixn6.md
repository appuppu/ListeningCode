# Computing Products Without Self Inclusion — 자기 자신을 제외한 모든 요소의 곱을 구하기

## 문제의 본질

정수 배열 `nums`가 주어진다. 각 인덱스 `i`에 대해 `nums[i]`를 **제외한** 모든 요소의 곱을 계산하고, 그 결과를 저장한 배열 `result`를 반환해야 한다. 나눗셈 연산자를 사용해서는 안 된다.

## 핵심 아이디어

어떤 요소를 제외한 전체의 곱은 「그 요소보다 왼쪽에 있는 모든 요소의 곱」×「그 요소보다 오른쪽에 있는 모든 요소의 곱」으로 분해할 수 있다. 이 좌우의 누적곱을 순방향·역방향의 2회 순회로 구축하면, 나눗셈 없이 O(n)으로 풀 수 있다.

## 사고 프로세스

1. **나눗셈을 사용할 수 없으므로 다른 분해 방법을 생각한다**: 전체의 곱을 구해 각 요소로 나누는 방법은 금지되어 있다. 따라서 `result[i]`를 「`nums[i]`의 왼쪽 곱」×「`nums[i]`의 오른쪽 곱」으로 분해한다. 이 분해 방식이라면 나눗셈은 불필요하다
2. **왼쪽 누적곱은 순방향 순회로 구축할 수 있다**: 배열을 왼쪽에서 오른쪽으로 순회하면서, 각 위치에서 「자신보다 왼쪽에 있는 모든 요소의 곱」을 계산한다. `result[i] = result[i-1] * nums[i-1]`이라는 점화식이 성립한다. 첫 번째 요소의 왼쪽에는 요소가 없으므로, `result[0] = 1`(곱의 항등원)으로 초기화한다
3. **오른쪽 누적곱은 역방향 순회로 구축할 수 있다**: 배열을 오른쪽에서 왼쪽으로 순회하면서, 변수 `record`에 「자신보다 오른쪽에 있는 모든 요소의 곱」을 축적한다. 마지막 요소의 오른쪽에는 요소가 없으므로, `record = 1`로 초기화한다
4. **두 곱을 곱한다**: 역방향 순회 중에 `result[i]`(왼쪽 곱)에 `record`(오른쪽 곱)를 곱함으로써 최종 답을 얻는다. 곱한 후에 `record = record * nums[i]`로 오른쪽 곱을 갱신한다
5. **추가 배열을 사용하지 않아도 된다**: 왼쪽 곱을 `result` 배열에 직접 기록하고, 오른쪽 곱을 변수 하나로 관리하므로, 출력 배열 외의 추가 메모리는 O(1)로 충분하다

## 전제 지식

### 누적곱(Prefix Product / Suffix Product)이란

배열의 처음 또는 끝부터 순서대로 요소를 곱해 나감으로써 얻어지는 곱의 열이다. 누적합의 곱셈 버전에 해당한다. 각 위치에서 「그때까지의 모든 요소의 곱」을 효율적으로 구할 수 있다.

```java
int[] nums = {1, 2, 3, 4};

// 왼쪽부터의 누적곱（prefix product）
// prefix[0] = 1（왼쪽에 요소가 없음）
// prefix[1] = 1（nums[0]까지）
// prefix[2] = 1*2 = 2（nums[1]까지）
// prefix[3] = 1*2*3 = 6（nums[2]까지）

// 오른쪽부터의 누적곱（suffix product）
// suffix[3] = 1（오른쪽에 요소가 없음）
// suffix[2] = 4（nums[3]까지）
// suffix[1] = 4*3 = 12（nums[3]*nums[2]）
// suffix[0] = 4*3*2 = 24（nums[3]*nums[2]*nums[1]）
```

### 곱의 항등원

임의의 수에 1을 곱해도 값은 변하지 않는다. 누적곱의 초기값으로 1을 사용함으로써, 첫 번째 요소에 대해서도 동일한 점화식을 적용할 수 있다.

```java
int record = 1;              // 곱의 초기값은 1（항등원）
record = record * nums[i];   // 첫 번째 곱셈에서는 record = nums[i]가 된다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 순방향과 역방향으로 각각 1회씩 순회하는 것만으로 충분하다 |
| Space | O(1) — 출력 배열 `result`를 제외하면, 추가로 사용하는 메모리는 변수 `record`뿐이다 |

## 코드

```java
// 입력: 정수 배열 nums
// 출력: 각 인덱스에 대해 자기 자신을 제외한 모든 요소의 곱을 저장한 int[]를 반환한다
public int[] productExceptSelf(int[] nums) {
    // nums와 동일한 길이의 배열을 생성한다. 먼저 왼쪽 누적곱을 저장하고, 이후 오른쪽 누적곱을 곱한다
    int[] result = new int[nums.length];

    // 순방향 순회: 각 위치의 왼쪽에 있는 모든 요소의 곱을 result에 저장한다
    result[0] = 1;  // 첫 번째 요소의 왼쪽에는 요소가 존재하지 않으므로, 곱의 항등원인 1로 초기화한다
    for (int i = 1; i < nums.length; i++) {
        // result[i-1]은 위치 i-1까지의 왼쪽 곱이다. 여기에 nums[i-1](하나 왼쪽의 요소)을 곱하여 위치 i의 왼쪽 곱을 구한다
        result[i] = result[i - 1] * nums[i - 1];
    }

    // 역방향 순회: 오른쪽 누적곱을 곱하여 최종 결과를 완성한다
    // record는 「현재 위치보다 오른쪽에 있는 모든 요소의 곱」을 축적하는 변수이다
    int record = 1;  // 마지막 요소의 오른쪽에는 요소가 존재하지 않으므로, 1로 초기화한다
    for (int i = nums.length - 1; i >= 0; i--) {
        // result[i]에는 왼쪽 곱이 들어 있다. record(오른쪽 곱)를 곱하여 「자기 자신을 제외한 모든 요소의 곱」을 완성한다
        result[i] = record * result[i];
        // 주의: record의 갱신은 result[i]를 확정한 후에 수행한다. 먼저 갱신하면 nums[i] 자체가 곱에 포함되어 버린다
        record = record * nums[i];
    }

    // 각 요소에 「자기 자신을 제외한 모든 요소의 곱」이 저장된 result를 반환한다
    return result;
}
```
