# Validating a Sudoku Board — 9×9 Sudoku 보드가 유효한지 판정하기

## 문제의 본질

9×9의 이차원 문자 배열로 표현된 Sudoku 보드가 주어진다. 각 행·각 열·각 3×3 서브그리드에 중복되는 숫자가 포함되어 있지 않으면 유효하다고 판정하고, `true`를 반환한다. 빈 셀은 점 `.`으로 표현된다. 보드가 완성되어 있을 필요는 없으며, 현재 배치가 규칙을 위반하고 있지 않은지만 확인한다.

## 핵심 아이디어

보드 전체를 1회 순회하면서, 각 셀의 숫자가 「해당 행」「해당 열」「해당 3×3 박스」 중 하나에서 이미 출현했으면 무효로 판정한다. 임의의 셀 `(i, j)`가 속하는 박스의 인덱스는 `(i/3) * 3 + j/3`이라는 식으로 0~8에 유일하게 매핑할 수 있다.

## 사고 프로세스

1. **검증해야 할 조건을 정리한다**: Sudoku의 유효성은 「각 행에 중복 없음」「각 열에 중복 없음」「각 3×3 박스에 중복 없음」이라는 3가지 조건으로 결정된다. 이 3가지 조건을 동시에 검증할 수 있으면 효율적이다
2. **중복 검출에는 HashSet이 적합하다**: 어떤 숫자가 이미 출현했는지를 O(1)로 판정하려면 HashSet이 최적이다. 행마다 9개, 열마다 9개, 박스마다 9개, 총 27개의 HashSet을 준비하면, 3가지 조건을 동시에 체크할 수 있다
3. **셀에서 박스로의 매핑이 필요하다**: 셀 `(i, j)`가 어느 박스에 속하는지를 계산해야 한다. 행 방향은 `i/3`(정수 나눗셈)으로 0,1,2의 3그룹, 열 방향은 `j/3`으로 0,1,2의 3그룹으로 나뉜다. 이것을 1차원 인덱스로 변환하려면 `(i/3) * 3 + j/3`으로 한다. 이를 통해 9개의 박스가 0~8의 번호에 대응된다
4. **1회 순회로 모든 조건을 검증한다**: 이중 for 루프로 보드 전체를 순회하며, 각 셀에 대해 행·열·박스의 3개 Set에 대해 중복 체크와 등록을 수행한다. 점은 숫자가 아니므로 건너뛴다
5. **중복이 발견된 시점에 즉시 false를 반환한다**: 3개의 Set 중 하나에 이미 같은 숫자가 포함되어 있으면, 해당 보드는 무효이므로 즉시 `false`를 반환한다
6. **모든 셀을 순회한 후에 true를 반환한다**: 중복이 한 번도 발견되지 않으면, 보드는 유효하다

## 전제 지식

### HashSet이란

중복되지 않는 요소의 집합을 관리하는 데이터 구조이다. 요소의 추가·존재 확인을 O(1)로 수행할 수 있다. 이번에는 「어떤 숫자가 이미 출현했는지」를 고속으로 판정하기 위해 사용한다.

```java
Set<Character> set = new HashSet<>();  // 빈 HashSet을 생성한다
set.add('5');            // 요소 '5'를 추가한다
set.contains('5');       // 요소 '5'가 존재하는지를 boolean으로 반환한다 → true
set.contains('3');       // 요소 '3'이 존재하는지를 boolean으로 반환한다 → false
```

### HashSet 배열을 생성하는 방법

9개의 HashSet을 배열로 묶어서 관리한다. 제네릭 배열은 직접 생성할 수 없으므로, `new HashSet[9]`로 raw 타입의 배열을 만들고, 각 요소를 루프로 초기화한다.

```java
Set<Character>[] sets = new HashSet[9];  // 9개분의 배열을 확보한다
for (int i = 0; i < 9; i++) {
    sets[i] = new HashSet<>();           // 각 요소를 빈 HashSet으로 초기화한다
}
```

### 박스 인덱스 계산식

`boxIdx = (i/3) * 3 + j/3`은 셀 `(i, j)`가 속하는 3×3 박스의 번호(0~8)를 반환한다. `i/3`은 행 방향의 박스 위치(0,1,2)를, `j/3`은 열 방향의 박스 위치(0,1,2)를 나타낸다. 행 방향의 위치에 3을 곱하고 열 방향의 위치를 더함으로써, 9개의 박스에 유일한 번호를 할당한다.

```
박스 번호 배치:
0 | 1 | 2
3 | 4 | 5
6 | 7 | 8

예: 셀(4, 7) → (4/3)*3 + 7/3 = 1*3 + 2 = 5 → 박스 5에 속한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n²) — 9×9 보드 전체를 1회 순회한다 (n=9로 고정이므로 O(81)=O(1)이라고도 할 수 있다) |
| Space | O(n²) — 27개의 HashSet에 최대 81개의 요소를 저장한다 |

## 코드

```java
// 입력: 9×9 이차원 문자 배열 board (숫자 '1'~'9' 또는 점 '.')
// 출력: 보드가 유효하면 true, 무효하면 false를 반환한다
public boolean isValidSudoku(char[][] board) {
    // 행·열·박스별로 출현한 숫자를 기록하는 HashSet 배열을 생성한다
    // rowset[i]는 i행, columnset[j]는 j열, boxset[k]는 k번째 박스에 출현한 숫자를 기록한다
    Set<Character>[] rowset = createSets();
    Set<Character>[] columnset = createSets();
    Set<Character>[] boxset = createSets();

    // 바깥쪽 루프에서 행을, 안쪽 루프에서 열을 순회하여 전체 81개 셀을 1회씩 방문한다
    for (int i = 0; i < 9; i++) {
        for (int j = 0; j < 9; j++) {
            // 현재 셀의 값을 가져온다
            char c = board[i][j];
            // 점은 빈 셀(숫자가 아님)이므로 건너뛴다
            if (c == '.') {
                continue;
            }

            // 셀(i, j)가 속하는 박스의 번호를 계산한다 (0~8에 유일하게 대응)
            int boxIdx = (i / 3) * 3 + j / 3;

            // 행·열·박스 중 하나에 이미 같은 숫자가 있으면 중복이므로 즉시 false를 반환한다
            if (rowset[i].contains(c) || columnset[j].contains(c) || boxset[boxIdx].contains(c)) {
                return false;
            }

            // 중복이 없으면 3개의 Set에 현재 숫자를 등록하여 이후의 중복 검출에 대비한다
            rowset[i].add(c);
            columnset[j].add(c);
            boxset[boxIdx].add(c);
        }
    }
    // 모든 셀을 순회하여 중복이 한 번도 발견되지 않았으면 보드는 유효하다
    return true;
}

// 9개의 빈 HashSet을 가진 배열을 생성하는 헬퍼 메서드
public Set<Character>[] createSets() {
    Set<Character>[] sets = new HashSet[9];
    for (int i = 0; i < 9; i++) {
        sets[i] = new HashSet<>();
    }
    return sets;
}
```
