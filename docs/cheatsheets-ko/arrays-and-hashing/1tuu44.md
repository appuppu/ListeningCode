# Checking if Two Strings Are Anagrams — 두 문자열이 같은 문자의 재배열인지 판정하기

## 문제의 본질

두 문자열 `s`와 `t`가 주어진다. `t`가 `s`의 애너그램인지를 판정하여 **boolean**으로 반환한다. 애너그램이란, 두 문자열이 완전히 같은 문자를 같은 출현 횟수만큼 포함하고, 순서만 다른 관계를 말한다.

## 핵심 아이디어

애너그램인지 여부는 "각 문자의 출현 횟수가 완전히 일치하는가"로 귀결된다. 소문자 알파벳은 26종류밖에 없으므로, 고정 길이 26의 배열로 모든 문자의 출현 횟수를 관리하면 O(1)의 공간으로 O(n)의 시간에 판정할 수 있다.

## 사고 프로세스

1. **애너그램의 정의를 수학적으로 파악한다**: 두 문자열이 애너그램이라 함은, 각 문자의 출현 빈도가 완전히 일치한다는 것을 의미한다. 즉, 문자의 순서는 무시하고 빈도만 비교하면 된다
2. **길이가 다르면 즉시 false를 반환한다**: 애너그램은 같은 문자를 같은 횟수만큼 포함하므로, 문자열의 길이가 다른 시점에서 애너그램일 수 없다. 이를 먼저 판정하면 불필요한 처리를 생략할 수 있다
3. **빈도의 비교 방법을 고려한다**: 소문자 알파벳은 'a'부터 'z'까지 26종류로 한정되어 있다. HashMap 대신 크기 26의 고정 길이 int 배열을 사용하면, 각 문자의 출현 횟수를 인덱스로 관리할 수 있다
4. **하나의 배열로 두 문자열을 처리한다**: 두 개의 배열을 만들어 비교하는 대신, 하나의 배열에 대해 한쪽 문자열로 증가시키고 다른 쪽으로 감소시킨다. 최종적으로 모든 요소가 0이면, 빈도가 완전히 일치했음을 의미한다
5. **같은 루프 안에서 양쪽을 처리한다**: 문자열의 길이가 같음을 사전에 확인했으므로, 하나의 for 루프 안에서 `s`의 증가와 `t`의 감소를 동시에 수행할 수 있다
6. **최종 판정**: 루프 종료 후, 배열의 모든 요소가 0인지를 확인한다. 하나라도 0이 아닌 요소가 있으면, 특정 문자의 출현 횟수가 일치하지 않으므로 false를 반환한다

## 전제 지식

### 문자에서 배열 인덱스로의 변환

`char - 'a'` 연산을 통해 소문자 알파벳을 0~25의 정수로 변환할 수 있다. 이를 통해 문자를 그대로 배열의 인덱스로 사용할 수 있다.

```java
char c = 'd';
int index = c - 'a';    // 'd' - 'a' = 3 ('a'=0, 'b'=1, 'c'=2, 'd'=3)
int[] count = new int[26];
count[c - 'a']++;       // count[3]이 1이 된다 ('d'의 출현 횟수를 기록)
```

### 고정 길이 배열을 이용한 빈도 카운트

크기 26의 int 배열을 준비하면, 각 인덱스가 하나의 문자에 대응하는 빈도 테이블로 기능한다. Java에서는 `new int[26]`으로 모든 요소가 0으로 초기화된다.

```java
int[] count = new int[26];  // 모든 요소가 0으로 초기화된다
count['b' - 'a']++;        // count[1] = 1 ('b'의 출현을 기록)
count['b' - 'a']--;        // count[1] = 0 ('b'의 출현을 상쇄)
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 문자열을 1회 순회하는 것만으로 충분하다 (n은 문자열의 길이) |
| Space | O(1) — 사용하는 배열의 크기는 항상 26이며, 입력의 길이에 의존하지 않는다 |

## 코드

```java
// 입력: 두 문자열 s와 t
// 출력: t가 s의 애너그램이면 true, 그렇지 않으면 false를 반환한다
public boolean isAnagram(String s, String t) {
    // 애너그램은 같은 문자를 같은 횟수만큼 포함하므로, 길이가 다른 시점에서 애너그램이 아니다
    if (s.length() != t.length())
        return false;

    // 각 알파벳의 출현 횟수의 "차이"를 기록하는 배열 (인덱스 0='a', 25='z')
    // 크기 26은 a~z의 26개 문자에 대응한다
    int[] count = new int[26];

    // 하나의 루프로 두 문자열을 동시에 처리한다 (길이가 같음을 사전에 확인 완료)
    for (int i = 0; i < s.length(); i++) {
        // s의 문자로 증가: "s에 이 문자가 1회 출현했음"을 기록한다
        count[s.charAt(i) - 'a']++;
        // t의 문자로 감소: "t에 이 문자가 1회 출현했음"을 기록한다
        // 증가와 감소가 상쇄되면, 해당 문자의 출현 횟수가 s와 t에서 같다는 것을 의미한다
        count[t.charAt(i) - 'a']--;
    }

    // 전체 26개 요소를 순회하여, 0이 아닌 요소가 하나라도 있으면 출현 횟수가 불일치한다
    for (int c : count) {
        if (c != 0) return false;
    }
    // 모든 요소가 0 → 모든 문자의 출현 횟수가 일치 → 애너그램이다
    return true;
}
```
