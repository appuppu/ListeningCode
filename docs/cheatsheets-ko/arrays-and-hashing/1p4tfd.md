# Finding Duplicates in an Array — 배열 내에 중복되는 값이 존재하는지를 판정한다

## 문제의 본질

정수 배열 `nums`가 주어진다. 배열 내에 같은 값이 2회 이상 출현하는 경우에는 `true`를, 모든 요소가 서로 다른 경우에는 `false`를 반환한다.

## 핵심 아이디어

배열을 순회하면서 지금까지 본 요소를 HashSet에 기록해 나가면, 각 요소가 이미 출현했는지를 O(1)로 판정할 수 있다. 중복을 발견한 시점에서 즉시 `true`를 반환할 수 있다.

## 사고 프로세스

1. **중복 판정 = "이전에 같은 값을 본 적이 있는가"의 판정**: 배열을 처음부터 순회할 때, 현재 요소가 과거에 이미 출현한 적이 있다면, 그것은 중복이다. 즉 "지금까지 본 요소의 집합"을 관리할 수 있으면, 중복을 검출할 수 있다
2. **과거에 본 요소를 고속으로 검색하고 싶다**: 각 요소에 대해 "이 값을 이미 본 적이 있는가?"를 O(1)로 판정하려면, HashSet이 적합하다. HashSet은 요소의 존재 확인을 O(1)로 수행할 수 있는 데이터 구조이다
3. **HashSet에 무엇을 저장할 것인가**: 문제는 인덱스가 아니라 참거짓 값을 반환하기만 하면 되므로, 값 자체만을 HashSet에 저장하면 충분하다
4. **순회하면서 HashSet을 구축한다**: 배열을 처음부터 순서대로 순회하며, 각 요소에 대해 "HashSet에 이미 포함되어 있는가"를 판정한다. 포함되어 있으면 중복 발견이고, 포함되어 있지 않으면 현재 요소를 HashSet에 추가하고 다음으로 진행한다
5. **조기 리턴으로 효율화한다**: 중복을 발견한 시점에서 즉시 `true`를 반환한다. 배열 전체를 순회한 후에도 중복이 발견되지 않으면 `false`를 반환한다

## 전제 지식

### HashSet이란

중복이 없는 요소의 집합을 관리하는 데이터 구조이다. 요소의 추가와 존재 확인을 O(1)로 수행할 수 있다. HashMap과 달리, 키와 값의 쌍이 아니라 값만을 저장한다. 중복을 자동으로 배제하는 성질을 갖는다.

```java
HashSet<Integer> set = new HashSet<>();  // 빈 HashSet을 생성한다
set.add(10);              // 요소 10을 추가한다
set.contains(10);         // 요소 10이 존재하는지를 boolean으로 반환한다 → true
set.contains(5);          // 요소 5가 존재하는지를 boolean으로 반환한다 → false
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 1회 순회하는 것만으로 충분하다 |
| Space | O(n) — HashSet에 최대 n개의 요소를 저장한다 |

## 코드

```java
// 입력: 정수 배열 nums
// 출력: 중복되는 값이 존재하면 true, 모두 다르면 false
public boolean containsDuplicate(int[] nums) {
    // 지금까지 순회한 요소를 기록하는 HashSet
    // 문제가 요구하는 것은 참거짓 값뿐이므로, 값만을 저장하면 충분하다
    HashSet<Integer> seen = new HashSet<>();

    for (int num : nums) {
        // 현재 요소가 이미 HashSet에 존재하면, 같은 값이 2회 출현한 것이므로 중복이 확정된다
        if (seen.contains(num)) {
            return true;  // 중복을 발견한 시점에서 즉시 반환한다 (조기 리턴)
        }

        // 현재 요소를 HashSet에 추가하고 다음으로 진행한다
        // 이 요소는 이후의 순회에서 "과거에 본 요소"로서 참조된다
        seen.add(num);
    }
    // 루프가 종료되어도 중복이 발견되지 않으면, 모든 요소가 서로 다르다는 것이 확정된다
    return false;
}
```
