# Grouping Words by Anagram Patterns — 애너그램 관계인 단어를 그룹으로 묶기

## 문제의 본질

문자열 배열 `strs`가 주어진다. 서로 애너그램인 문자열끼리 그룹으로 묶어서 그룹의 리스트로 반환한다. 두 문자열이 애너그램이라 함은, 같은 문자를 같은 횟수만큼 포함하되 배열 순서만 다른 것을 의미한다.

## 핵심 아이디어

애너그램끼리는 "각 문자의 출현 횟수"가 완전히 동일하다. 26개 문자 각각의 출현 횟수를 세어 문자열로 변환한 것을 키로 사용하면, 애너그램끼리는 반드시 같은 키가 되므로 HashMap으로 일괄 그룹화할 수 있다.

## 사고 과정

1. **애너그램의 공통 성질을 찾는다**: 애너그램끼리는 문자의 배열 순서만 다르고, 각 문자의 출현 횟수는 완전히 일치한다. 이 "출현 횟수의 일치"를 그룹화의 판정 기준으로 사용할 수 있다
2. **출현 횟수를 어떻게 표현할 것인가**: 영문 소문자는 26종류이므로, 크기 26의 정수 배열 `count`를 준비하고 각 문자의 출현 횟수를 카운트한다. 이 배열의 내용이 동일하면 해당 단어끼리는 애너그램이다
3. **배열을 HashMap의 키로 사용하는 방법**: Java에서는 배열을 그대로 HashMap의 키로 사용할 수 없다(참조 비교가 되기 때문이다). 따라서 배열의 각 요소를 `#`으로 구분하여 연결한 문자열(예: `"1#0#0#...#"`)을 키로 사용한다. 이렇게 하면 동일한 출현 횟수를 가진 단어는 같은 문자열 키를 생성한다
4. **HashMap으로 그룹화한다**: 키가 같은 단어는 같은 리스트에 넣으면 된다. `computeIfAbsent`를 사용하면 키가 미등록일 때는 새로운 리스트를 자동 생성하고, 이미 등록되어 있을 때는 해당 리스트를 반환하므로 조건 분기 없이 단어를 추가할 수 있다
5. **최종적으로 반환하는 것**: HashMap의 모든 밸류(각 그룹의 리스트)를 `ArrayList`로 변환하여 반환한다

## 전제 지식

### HashMap이란

키와 값의 쌍을 저장하는 데이터 구조이다. 키를 지정하여 값의 검색 및 취득을 O(1)로 수행할 수 있다. 배열의 인덱스 접근과 같은 속도로 임의의 키를 통해 접근할 수 있는 사전과 같은 것이다.

```java
HashMap<String, List<String>> map = new HashMap<>();  // 빈 HashMap을 생성한다
map.put("key", new ArrayList<>());  // 키 "key"에 빈 리스트를 저장한다
map.containsKey("key");             // 키 "key"가 존재하는지를 boolean으로 반환한다 → true
map.get("key");                     // 키 "key"에 대응하는 값을 반환한다 → []
map.values();                       // 모든 값을 Collection으로 반환한다
```

### computeIfAbsent란

HashMap의 메서드이다. 지정한 키가 존재하지 않으면 두 번째 인수의 람다식으로 값을 생성하여 등록하고, 그 값을 반환한다. 키가 이미 존재하면 기존의 값을 그대로 반환한다. 키의 유무에 따른 조건 분기를 한 줄로 작성할 수 있다.

```java
// 키 "abc"가 미등록이면 새로운 ArrayList를 생성하여 등록하고, 그 리스트를 반환한다
// 키 "abc"가 등록 완료 상태이면, 기존 리스트를 그대로 반환한다
map.computeIfAbsent("abc", k -> new ArrayList<>()).add("cab");
```

### 문자의 출현 횟수 카운트

`char` 타입의 문자에서 `'a'`를 빼면 a=0, b=1, ..., z=25의 인덱스로 변환할 수 있다. 크기 26의 배열을 준비하고, 이 인덱스 위치를 증가시킴으로써 각 문자의 출현 횟수를 기록한다.

```java
int[] count = new int[26];           // 26개 문자에 대한 카운트 배열을 생성한다(초기값은 모두 0)
for (char c : "eat".toCharArray())   // 문자열을 한 문자씩 순회한다
    count[c - 'a']++;                // 해당 문자의 위치를 증가시킨다
// 결과: count[0]=1(a), count[4]=1(e), count[19]=1(t), 나머지는 0
```

## 계산량

| | 값 |
|---|---|
| Time | O(n × k) — n은 문자열의 개수, k는 문자열의 평균 길이이다. 각 문자열에 대해 문자 수만큼의 카운트와 크기 26의 키 생성을 수행한다 |
| Space | O(n × k) — HashMap에 모든 문자열을 저장하며, 각 키는 고정 길이이지만 문자열 자체가 k개 문자 분량의 메모리를 차지한다 |

## 코드

```java
// 입력: 문자열 배열 strs
// 출력: 애너그램끼리 그룹화한 List<List<String>>을 반환한다
public List<List<String>> groupAnagrams(String[] strs) {
    // 키=출현 횟수의 문자열 표현, 밸류=해당 키에 속하는 단어의 리스트를 저장하는 HashMap
    // 같은 키를 가진 단어끼리가 애너그램이다
    Map<String, List<String>> map = new HashMap<>();

    // 배열 strs의 각 문자열 s를 처음부터 끝까지 하나씩 순회한다
    for (String s : strs) {
        // 각 문자(a~z)의 출현 횟수를 기록하는 크기 26의 배열을 생성한다(초기값은 모두 0)
        // 문자열마다 새로운 배열을 생성하는 이유는, 이전 문자열의 카운트 결과가 남지 않도록 하기 위해서이다
        int[] count = new int[26];
        // toCharArray()로 문자 배열로 변환하고, 각 문자 c에 대해 출현 횟수를 카운트한다
        for (char c : s.toCharArray())
            // c - 'a'를 통해 문자 c를 인덱스 0~25로 변환하여 증가시킨다
            count[c - 'a']++;

        // 출현 횟수 배열을 "1#0#0#..." 형식의 문자열 키로 변환한다
        // 이 키는 문자의 출현 횟수를 고유하게 표현하며, 애너그램끼리는 반드시 같은 키가 된다
        // 각 요소 사이에 구분 문자 #을 삽입하여 서로 다른 카운트가 같은 문자열이 되지 않도록 한다
        StringBuilder sb = new StringBuilder();
        for (int n : count)
            sb.append(n).append('#');
        String key = sb.toString();

        // 키가 미등록이면 새로운 리스트를 생성하고, 현재 문자열을 리스트에 추가한다
        // 이를 통해 같은 키를 가진 단어가 같은 리스트에 축적된다
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }

    // 모든 그룹의 컬렉션을 취득하고, List<List<String>>으로 변환하여 반환한다
    return new ArrayList<>(map.values());
}
```
