# Finding the Longest Consecutive Number Sequence — 정렬되지 않은 배열에서 최장 연속 정수열의 길이를 구한다

## 문제의 본질

정수 배열 `nums`(정렬되지 않음)가 주어진다. 배열에서 연속하는 정수의 열(예: 1,2,3,4)을 찾아 그 **최장 길이**를 반환한다. 요소의 나열 순서는 관계없으며, 값으로서 연속하기만 하면 된다.

## 핵심 아이디어

연속열의 "시작점"에서만 길이를 세면 불필요한 중복 계산을 제거할 수 있다. 어떤 수 `num`에 대해 `num - 1`이 HashSet에 존재하지 않으면, 그 수는 연속열의 시작점이다. 시작점에서만 카운트를 시작함으로써 전체적으로 O(n)을 달성한다.

## 사고 프로세스

1. **연속열의 시작점을 특정한다**: 연속열의 중간 수부터 카운트를 시작하면 같은 열을 여러 번 세게 된다. `num - 1`이 존재하지 않는 수만이 연속열의 진정한 시작점이다. 시작점에서만 카운트하면 각 요소는 최대 1회만 카운트 대상이 된다
2. **존재 판정을 고속으로 수행한다**: 어떤 수가 배열에 포함되어 있는지를 O(1)로 판정하기 위해 전체 요소를 HashSet에 저장한다. 정렬하면 O(n log n)으로 풀 수 있지만, HashSet을 사용하면 O(n)으로 해결할 수 있다
3. **시작점에서 연속을 세어 나간다**: 시작점 `num`을 찾으면, `num + 1`, `num + 2`, ... 순서로 HashSet에 존재하는지 확인하며 연속이 끊어질 때까지의 길이를 센다
4. **최장을 추적한다**: 각 연속열의 길이를 변수 `longest`와 비교하여 더 길면 갱신한다. 모든 요소를 처리한 후의 `longest`가 답이다

## 전제 지식

### HashSet이란

중복 없이 값을 저장하는 데이터 구조이다. 값의 추가와 존재 판정을 O(1)로 수행할 수 있다. HashMap과 달리 키만 저장하며, 어떤 값이 "존재하는지 여부"를 고속으로 판정하고 싶을 때 사용한다.

```java
HashSet<Integer> set = new HashSet<>();  // 빈 HashSet을 생성한다
set.add(4);              // 값 4를 세트에 추가한다
set.add(4);              // 중복은 무시된다 (세트의 요소 수는 변하지 않는다)
set.contains(4);         // 값 4가 존재하는지를 boolean으로 반환한다 → true
set.contains(5);         // 값 5가 존재하는지를 boolean으로 반환한다 → false
```

### 연속열의 시작점이란

어떤 수 `num`에 대해 `num - 1`이 세트에 존재하지 않을 때, `num`은 연속열의 첫 번째 수(시작점)이다.
예: 세트={100, 4, 200, 1, 3, 2}일 때, 1은 시작점이다(0이 존재하지 않는다). 2는 시작점이 아니다(1이 존재한다).

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 각 요소는 시작점 판정에서 1회, 카운트에서 최대 1회, 총 2회만 접근된다 |
| Space | O(n) — HashSet에 최대 n개의 요소를 저장한다 |

## 코드

```java
// 입력: 정수 배열 nums (정렬되지 않음, 중복이 있을 수 있음)
// 출력: 최장 연속 정수열의 길이를 int로 반환한다
public int longestConsecutive(int[] nums) {
    // 전체 요소를 HashSet에 저장하여 O(1)로 존재 판정을 할 수 있도록 한다
    // 중복 요소는 자동으로 제거된다
    Set<Integer> numSet = new HashSet<>();
    for (int num : nums) {
        numSet.add(num);
    }

    // 지금까지 발견한 연속열의 최장 길이를 보유하는 변수
    int longest = 0;

    // HashSet의 각 요소를 순회한다
    for (int num : numSet) {
        // num - 1이 존재하지 않으면, num은 연속열의 시작점이다
        // num - 1이 존재하면, num은 연속열의 중간 수이므로 건너뛴다
        // (이 수는 다른 시작점에서의 카운트 시에 세어진다)
        if (!numSet.contains(num - 1)) {
            int currentNum = num;
            int length = 1;

            // 시작점에서 연속하는 수(num+1, num+2, ...)를 순서대로 세어 나간다
            // 연속이 끊어질 때까지 루프를 계속한다
            while (numSet.contains(currentNum + 1)) {
                currentNum++;
                length++;
            }

            // 현재 연속열의 길이가 지금까지의 최장을 초과하면 갱신한다
            longest = Math.max(longest, length);
        }
    }
    // 전체 요소의 순회가 완료되면, 최장 연속 정수열의 길이를 반환한다
    return longest;
}
```
