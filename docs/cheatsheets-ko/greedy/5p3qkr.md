# Partitioning a String Into Maximum Parts — 각 문자가 하나의 파트에만 포함되도록 문자열을 최대 개수로 분할하기

## 문제의 본질

소문자 영문자로 이루어진 문자열 `s`가 주어진다. 각 문자가 최대 하나의 파트에만 포함되도록 문자열을 가능한 한 많은 파트로 분할한다. 각 파트의 **길이**를 리스트로 반환한다.

## 핵심 아이디어

어떤 문자가 현재 파트에 포함되어 있다면, 그 문자의 마지막 출현 위치까지 파트를 연장해야 한다. 각 문자의 최종 출현 위치를 사전에 계산해 두면, 한 번의 순회로 탐욕적으로 파트의 경계를 확정할 수 있다.

## 사고 과정

1. **분할의 제약 조건을 이해한다**: 같은 문자가 두 개의 파트에 걸쳐서는 안 된다. 즉, 어떤 문자를 포함하는 파트는 그 문자의 마지막 출현 위치까지를 적어도 포함해야 한다
2. **각 문자의 최종 출현 위치를 사전에 구한다**: 문자열을 한 번 순회하며, 각 문자가 마지막으로 나타나는 인덱스를 배열에 기록한다. 영소문자는 26종류밖에 없으므로 크기 26의 배열이면 충분하다
3. **파트의 끝을 탐욕적으로 확장한다**: 문자열을 처음부터 순회하며, 현재 파트에 포함된 모든 문자의 최종 출현 위치의 최댓값을 `end`로 추적한다. 새로운 문자를 만날 때마다, `end`를 그 문자의 최종 출현 위치와 비교하여 갱신한다
4. **파트의 확정 조건을 파악한다**: 현재 인덱스 `i`가 `end`에 도달했을 때, 현재 파트 내의 모든 문자가 이 파트의 범위 안에 수용되어 있음이 보장된다. 이 시점에서 파트를 확정하고, 다음 파트를 시작한다
5. **파트의 길이를 계산한다**: 파트가 확정될 때마다, `end - start + 1`로 파트의 길이를 구하여 결과 리스트에 추가한다. 다음 파트의 시작 위치 `start`를 `i + 1`로 갱신한다

## 사전 지식

### 문자의 인덱스 변환

Java에서 `char` 타입은 정수로 취급할 수 있다. `s.charAt(i) - 'a'`를 통해 소문자 `'a'`를 `0`, `'b'`를 `1`, ..., `'z'`를 `25`로 변환할 수 있다. 이를 통해 크기 26의 배열로 모든 소문자를 관리할 수 있다.

```java
char c = 'c';
int index = c - 'a';    // 2 ('c'는 'a'로부터 2번째)
int[] arr = new int[26]; // 26개 문자를 위한 배열
arr[c - 'a'] = 5;       // 'c'에 해당하는 위치에 값 5를 저장
```

### Math.max란

두 값 중 더 큰 값을 반환하는 메서드이다. 파트의 끝을 확장할 때, 현재의 `end`와 새로운 문자의 최종 출현 위치를 비교하여 더 먼 쪽을 채택하기 위해 사용한다.

```java
Math.max(3, 7);   // 7을 반환
Math.max(10, 2);  // 10을 반환
```

### ArrayList란

가변 길이의 리스트이다. 파트 수를 사전에 알 수 없기 때문에, 파트의 길이를 하나씩 추가해 나가는 데 적합하다.

```java
List<Integer> res = new ArrayList<>();  // 빈 리스트를 생성
res.add(9);    // 끝에 9를 추가 → [9]
res.add(7);    // 끝에 7을 추가 → [9, 7]
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 문자열을 2번 순회하는 것만으로 충분하다 (최종 위치 기록에 1번, 파트 분할에 1번) |
| Space | O(1) — 크기 26의 고정 배열만 사용하며, 입력 크기에 의존하지 않는다 |

## 코드

```java
// 입력: 소문자 영문자로 이루어진 문자열 s
// 출력: 각 파트의 길이를 저장한 List<Integer>를 반환한다
List<Integer> partitionLabels(String s) {
    // 크기 26의 정수 배열로, 각 문자('a'~'z')의 최종 출현 인덱스를 저장한다
    // 영소문자는 26종류밖에 없으므로 크기 26으로 고정한다
    int[] last = new int[26];

    // 1번째 순회: 각 문자의 최종 출현 위치를 기록한다
    // 같은 문자가 여러 번 출현하는 경우, 뒤의 인덱스로 덮어쓰이므로 마지막 위치가 남는다
    for (int i = 0; i < s.length(); i++) {
        last[s.charAt(i) - 'a'] = i;
    }

    // 파트 수를 사전에 알 수 없으므로 가변 길이 리스트를 사용한다
    List<Integer> res = new ArrayList<>();
    // start: 현재 파트의 시작 위치, end: 현재 파트의 끝 위치
    int start = 0, end = 0;

    // 2번째 순회: 파트를 탐욕적으로 확정해 나간다
    for (int i = 0; i < s.length(); i++) {
        // 현재 문자의 최종 출현 위치가 end보다 멀면, 파트의 끝을 그곳까지 확장한다
        // 이를 통해, 파트 내 모든 문자의 최종 출현 위치의 최댓값이 end에 항상 유지된다
        end = Math.max(end,
            last[s.charAt(i) - 'a']);

        // i가 end에 도달 → 파트 내의 모든 문자가 이 범위에 수용되어 있음이 보장된다
        // 왜냐하면, 파트 내의 어떤 문자도 end 이후에는 출현하지 않기 때문이다
        if (i == end) {
            // end - start + 1로 파트의 길이를 계산하여 결과 리스트에 추가한다
            res.add(end - start + 1);
            // 다음 파트의 시작 위치를 갱신한다
            start = i + 1;
        }
    }
    // 모든 파트의 길이가 저장된 리스트를 반환한다
    return res;
}
```
