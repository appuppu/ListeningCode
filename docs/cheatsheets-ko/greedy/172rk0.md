# Checking Validity of a Parenthesis String With Wildcards — 와일드카드가 포함된 괄호 문자열의 유효성을 판정한다

## 문제의 본질

`(`、`)`、`*` 의 3종류 문자로만 이루어진 문자열이 주어진다. `*` 는 `(`、`)`、또는 빈 문자 중 하나로 취급할 수 있다. 이 문자열이 **유효한 괄호열**이 될 수 있는지를 판정하여 `boolean` 으로 반환한다.

## 핵심 아이디어

`*` 의 취급이 불확정이므로, 여는 괄호의 수를 하나의 값이 아닌 "취할 수 있는 범위(최솟값 low ~ 최댓값 high)"로 추적한다. 이 범위가 순회 중 항상 유효하고, 최종적으로 0을 포함하고 있으면 문자열은 유효하다.

## 사고 프로세스

1. **괄호의 유효성은 여는 괄호의 카운트로 판정할 수 있다**: 문자열을 왼쪽부터 순회하며, `(` 에서 +1, `)` 에서 -1한다. 도중에 카운트가 음수가 되면 무효이고, 최종적으로 0이면 유효하다. 이것이 괄호 판정의 기본 원리이다
2. **`*` 가 있으면 카운트가 하나의 값으로 정해지지 않는다**: `*` 는 3가지로 해석할 수 있으므로, 카운트는 단일 값이 아닌 "범위"가 된다. `*` 를 `(` 로 해석하면 카운트는 +1, `)` 로 해석하면 -1, 빈 문자로 해석하면 ±0이다. 즉 `*` 를 만날 때마다 범위가 넓어진다
3. **범위를 2개의 변수로 추적한다**: `low` 는 여는 괄호 카운트의 최솟값(`*` 를 가능한 한 `)` 나 빈 문자로 취급한 경우)을, `high` 는 최댓값(`*` 를 가능한 한 `(` 로 취급한 경우)을 나타낸다. 이 2개의 변수만으로 모든 패턴을 망라할 수 있다
4. **순회 중 `high` 가 음수가 되면 즉시 무효로 판정한다**: `high` 는 여는 괄호 카운트의 최댓값이므로, 이것이 음수가 된다는 것은 어떤 `*` 의 해석을 선택해도 `)` 가 과잉이라는 의미이며, 유효한 괄호열이 될 수 없다
5. **`low` 가 음수가 되면 0으로 클램프한다**: `low` 가 음수가 되는 것은 "`)` 를 남기는 해석"을 포함하고 있을 뿐이며, `*` 를 빈 문자로 취급하면 카운트 0 이상을 유지할 수 있다. 음수 값은 실제로는 선택하지 않는 해석이므로, `low` 를 0으로 보정한다
6. **최종적으로 `low == 0` 인지로 판정한다**: 순회가 완료된 시점에서, `low` 가 0이면 "여는 괄호를 모두 닫을 수 있는 해석이 존재한다"는 것을 의미하므로 `true` 를 반환한다

## 전제 지식

### 괄호열 유효성 판정의 기본 원리

문자열을 왼쪽부터 순회하며, 여는 괄호의 카운트를 관리한다. `(` 에서 +1, `)` 에서 -1하고, 도중에 음수가 되지 않으며 최종적으로 0이면 유효한 괄호열이다.

```java
int count = 0;
for (char c : s.toCharArray()) {
    if (c == '(') count++;
    else count--;
    if (count < 0) return false;  // 닫는 괄호가 과잉이다
}
return count == 0;  // 여는 괄호가 모두 닫혔는지를 확인한다
```

### Math.max 란

2개의 값 중 큰 쪽을 반환하는 메서드이다. 값이 특정 하한을 밑돌지 않도록 보정(클램프)하는 용도로 사용할 수 있다.

```java
Math.max(3, 0);    // → 3（3은 0 이상이므로 그대로 반환된다）
Math.max(-1, 0);   // → 0（-1은 0 미만이므로 0으로 보정된다）
```

### toCharArray 란

문자열을 `char` 배열로 변환하는 메서드이다. for-each 루프로 문자열을 한 글자씩 순회할 때 사용한다.

```java
String s = "(*)"；
char[] chars = s.toCharArray();  // → ['(', '*', ')']
for (char c : s.toCharArray()) {
    // c 에 한 글자씩 대입되면서 루프가 실행된다
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 문자열을 1회 순회하는 것만으로 충분하다 |
| Space | O(1) — 변수 `low` 와 `high` 2개만 사용한다 |

## 코드

```java
// 입력: '('、')'、'*' 로만 이루어진 문자열 s
// 출력: 문자열이 유효한 괄호열이 될 수 있는지를 boolean 으로 반환한다
public boolean checkValidString(String s) {
    // low: 여는 괄호 카운트의 최솟값, high: 최댓값
    // 이 2개의 변수로 * 의 모든 해석 패턴에서의 카운트 범위를 추적한다
    int low = 0, high = 0;

    // 문자열을 처음부터 한 글자씩 순회한다
    for (char c : s.toCharArray()) {
        if (c == '(') {
            // 여는 괄호: 어떤 해석에서도 카운트를 1 증가시키므로, 범위의 양 끝을 +1한다
            low++;
            high++;
        } else if (c == ')') {
            // 닫는 괄호: 어떤 해석에서도 카운트를 1 감소시키므로, 범위의 양 끝을 -1한다
            low--;
            high--;
        } else {
            // '*': ) 로 해석하면 최솟값이 내려가고, ( 로 해석하면 최댓값이 올라간다
            // 빈 문자 해석은 이 범위 안에 포함된다
            low--;
            high++;
        }

        // 최댓값이 음수이면, 어떤 * 의 해석을 선택해도 닫는 괄호가 과잉이므로 무효이다
        if (high < 0) return false;

        // low 가 음수가 되는 것은 ) 로 해석을 과도하게 한 경우이며,
        // 실제로는 그 해석을 선택하지 않으면 되므로, 최솟값을 0으로 보정한다
        low = Math.max(low, 0);
    }

    // low 가 0이면 "모든 여는 괄호를 닫을 수 있는 * 의 해석이 존재한다"는 의미이므로 true 를 반환한다
    // low 가 0보다 크면, 어떻게 해석해도 여는 괄호가 남으므로 false 를 반환한다
    return low == 0;
}
```
