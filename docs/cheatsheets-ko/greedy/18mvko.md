# Finding the Starting Gas Station for a Circular Route — 원형 경로를 한 바퀴 돌 수 있는 시작 주유소를 찾기

## 문제의 본질

길이 `n`의 정수 배열 `gas`와 `cost`가 주어진다. `gas[i]`는 스테이션 `i`에서 얻을 수 있는 연료이고, `cost[i]`는 스테이션 `i`에서 다음 스테이션으로 이동하는 데 필요한 연료이다. 원형 경로를 한 바퀴 돌 수 있는 시작 스테이션의 인덱스를 반환한다. 한 바퀴를 돌 수 있는 스테이션이 존재하지 않는 경우에는 `-1`을 반환한다. 해는 최대 1개만 존재한다.

## 핵심 아이디어

모든 스테이션의 연료 수지 합계가 음이 아니면 반드시 해가 존재한다. 현재 연료 잔량이 음수가 된 지점까지의 스테이션은 시작 지점이 될 수 없으므로, 다음 스테이션을 새로운 시작 후보로 리셋하면 1회 탐색으로 답을 찾을 수 있다.

## 사고 과정

1. **각 스테이션의 연료 수지를 생각한다**: 스테이션 `i`에서는 `gas[i]`의 연료를 얻고 `cost[i]`의 연료를 소비하므로, 순 연료 변화는 `net = gas[i] - cost[i]`로 나타낼 수 있다. 이 `net`이 양수이면 해당 스테이션은 연료 잉여를 만들고, 음수이면 연료 부족을 만든다
2. **한 바퀴를 돌 수 있는 조건을 판정한다**: 모든 스테이션의 `net` 합계(`totalBalance`)가 음이 아니면, 경로 전체에서 얻는 연료가 소비하는 연료 이상이므로 반드시 어딘가의 시작 지점에서 한 바퀴를 돌 수 있다. 반대로 `totalBalance`가 음수이면, 어디에서 출발하더라도 연료가 부족하므로 해는 존재하지 않는다
3. **시작 후보를 효율적으로 좁힌다**: 스테이션 `start`에서 출발하여 탐색을 진행하다가, 어떤 지점 `i`에서 누적 연료 잔량(`currentBalance`)이 음수가 되었다고 하자. 이때 `start`부터 `i`까지의 어떤 스테이션에서 출발하더라도 `i`를 넘을 수 없다. 왜냐하면 `start`부터 중간 스테이션 `j`까지의 누적은 음이 아니었으므로, `j`에서 출발하면 연료가 더 적은 상태로 `i`에 도달하기 때문이다. 따라서 `start`부터 `i`까지의 모든 스테이션을 일괄 제외하고, `i + 1`을 새로운 시작 후보로 설정한다
4. **currentBalance를 리셋하고 탐색을 계속한다**: 새로운 시작 후보 `i + 1`부터 다시 연료 잔량을 추적하기 위해 `currentBalance`를 `0`으로 리셋하고, `start`를 `i + 1`로 갱신한다. 탐색 자체는 처음부터 끝까지 1회만 수행하면 된다
5. **탐색 종료 후 totalBalance로 최종 판정한다**: 탐색이 끝난 시점에서 `totalBalance >= 0`이면 해가 존재하므로 `start`를 반환한다. `totalBalance < 0`이면 한 바퀴를 돌 수 없으므로 `-1`을 반환한다

## 전제 지식

### net(순 연료 변화)이란

각 스테이션에서의 연료 수지이다. `net = gas[i] - cost[i]`로 계산한다. 양수이면 연료가 남고, 음수이면 연료가 부족함을 의미한다.

```java
int net = gas[i] - cost[i];  // 스테이션 i에서의 연료 수지를 계산한다
// 예: gas[i]=3, cost[i]=5 일 때 net=-2 (연료가 2 부족하다)
// 예: gas[i]=4, cost[i]=1 일 때 net=3 (연료가 3 남는다)
```

### totalBalance와 currentBalance의 역할

`totalBalance`는 경로 전체의 연료 수지 합계로, 한 바퀴를 돌 수 있는지 판정하는 데 사용한다. `currentBalance`는 현재 시작 후보에서 탐색 중인 스테이션까지의 누적 연료 잔량으로, 시작 후보의 갱신 판정에 사용한다.

```java
int totalBalance = 0;    // 경로 전체의 연료 수지 합계 (한 바퀴 가능 여부 판정용)
int currentBalance = 0;  // 현재 시작 후보로부터의 누적 연료 잔량 (후보 갱신 판정용)
totalBalance += net;     // 모든 스테이션에 대해 항상 계속 더한다
currentBalance += net;   // 시작 후보를 리셋할 때마다 0으로 되돌린다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 1회 탐색하는 것만으로 충분하다 |
| Space | O(1) — 사용하는 변수는 3개뿐이며, 입력 크기에 의존하지 않는다 |

## 코드

```java
// 입력: 정수 배열 gas (각 스테이션에서 얻을 수 있는 연료)와 정수 배열 cost (각 스테이션에서 다음으로 이동하는 데 필요한 연료)
// 출력: 원형 경로를 한 바퀴 돌 수 있는 시작 스테이션의 인덱스를 int로 반환한다. 한 바퀴를 돌 수 없는 경우에는 -1을 반환한다
public int canCompleteCircuit(int[] gas, int[] cost) {
    // 경로 전체의 연료 수지 합계 (한 바퀴 가능 여부의 최종 판정에 사용한다)
    int totalBalance = 0;
    // 현재 시작 후보로부터의 누적 연료 잔량 (후보 리셋 판정에 사용한다)
    int currentBalance = 0;
    // 시작 후보의 인덱스 (0부터 시작하며, 리셋할 때마다 갱신한다)
    int start = 0;

    // 배열을 인덱스 0부터 끝까지 하나씩 탐색한다
    for (int i = 0; i < gas.length; i++) {
        // 스테이션 i에서의 순 연료 변화를 계산한다
        int net = gas[i] - cost[i];
        // 경로 전체의 연료 수지에 항상 더한다 (최종적으로 한 바퀴 가능 여부 판정에 사용한다)
        totalBalance += net;
        // 현재 시작 후보로부터의 누적 연료 잔량에 더한다 (스테이션 i 도착 시점의 연료 잔량에 해당한다)
        currentBalance += net;

        // 누적 연료 잔량이 음수가 되면, start부터 i까지의 어떤 스테이션도 시작 지점이 될 수 없다
        if (currentBalance < 0) {
            // 누적 연료 잔량을 리셋하고 다음 스테이션을 새로운 시작 후보로 설정한다
            currentBalance = 0;
            start = i + 1;
        }
    }
    // 경로 전체의 연료 수지가 음이 아니면 한 바퀴를 돌 수 있으므로 start를 반환하고, 음수이면 불가능하므로 -1을 반환한다
    return totalBalance >= 0 ? start : -1;
}
```
