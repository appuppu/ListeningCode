# Finding the Subarray With Maximum Sum — 최대 합을 가지는 연속 부분 배열을 찾기

## 문제의 본질

정수 배열 `nums`가 주어진다. 배열에는 양수와 음수가 모두 포함될 수 있다. 연속하는 부분 배열(subarray) 중에서 요소의 합이 최대가 되는 것을 찾아 그 **합계 값**을 반환한다.

## 핵심 아이디어

각 요소에 도달했을 때, "지금까지의 부분 배열을 연장한다"와 "이 요소에서 새로운 부분 배열을 시작한다" 두 가지 선택지밖에 없다. 지금까지의 누적 합이 음수라면, 그것을 끌고 가는 것보다 버리고 새로 시작하는 것이 반드시 이득이 된다.

## 사고 과정

1. **각 요소에서의 선택은 두 가지뿐이다**: 요소 `nums[i]`에 도달했을 때, 취할 수 있는 행동은 "직전까지의 부분 배열에 `nums[i]`를 추가하여 연장한다"와 "`nums[i]`를 선두로 하여 새로운 부분 배열을 시작한다" 두 가지뿐이다. 연속 부분 배열이라는 제약상, 중간 요소를 건너뛸 수 없다
2. **연장할 것인지 새로 시작할 것인지의 판단 기준**: 직전까지의 누적 합 `currentSum`이 양수이면, `nums[i]`에 더하는 것이 `nums[i]` 단독보다 커지므로 연장한다. `currentSum`이 음수이면, 더하면 `nums[i]` 단독보다 작아지므로 버리고 새로 시작한다. 즉 `currentSum + nums[i]`와 `nums[i]` 중 큰 쪽을 선택하면 된다
3. **이 판단을 `Math.max`로 표현한다**: `currentSum = Math.max(currentSum + nums[i], nums[i])` 한 줄로 연장과 새로 시작의 판단이 완료된다. `currentSum + nums[i]`가 연장에, `nums[i]`가 새로 시작에 대응한다
4. **전체의 최대값을 별도로 추적한다**: `currentSum`은 "현재 부분 배열의 합"이며, 탐색 도중에 값이 오르내린다. 문제가 요구하는 것은 "전체를 통틀어서의 최대 합"이므로, 별도의 변수 `maxSum`으로 탐색 중에 출현한 `currentSum`의 최대값을 계속 기록한다
5. **`maxSum`의 초기값은 `Integer.MIN_VALUE`로 설정한다**: 배열의 모든 요소가 음수인 경우에도 올바르게 동작하도록, `maxSum`의 초기값을 정수의 최소값으로 설정한다. 0으로 초기화하면, 모든 요소가 음수일 때 "빈 부분 배열(합계 0)"이 최대라고 잘못 판정하게 된다
6. **최종적으로 `maxSum`을 반환한다**: 배열의 탐색이 종료된 시점에서, `maxSum`에는 모든 연속 부분 배열 중 최대 합이 기록되어 있다. 이 값을 반환한다

## 전제 지식

### Math.max란

두 값을 받아서 큰 쪽을 반환하는 Java의 표준 메서드이다. 조건 분기를 한 줄로 표현할 수 있다.

```java
Math.max(5, 3);       // 두 값 중 큰 쪽을 반환한다 → 5
Math.max(-2, -7);     // 음수끼리도 큰 쪽을 반환한다 → -2
Math.max(a + b, b);   // 식의 결과끼리를 비교할 수도 있다
```

### Integer.MIN_VALUE란

Java에서 `int` 타입의 최소값(-2,147,483,648)을 나타내는 상수이다. "아직 아무것도 비교하지 않은" 상태의 초기값으로 사용한다. 어떤 정수와 비교해도 `Math.max`에서 반드시 상대편이 선택된다.

```java
int maxSum = Integer.MIN_VALUE;   // int 타입의 최소값으로 초기화한다
maxSum = Math.max(maxSum, -5);    // 어떤 값이든 maxSum보다 크다 → -5
```

### 연속 부분 배열(subarray)이란

배열에서 인접한 요소를 끊김 없이 추출한 부분을 말한다. 요소를 건너뛰어 선택할 수 없다.
예: `nums = [-2, 1, -3, 4, -1, 2]`일 때, `[4, -1, 2]`는 연속 부분 배열이다(합계 5). `[1, 4, 2]`는 요소가 인접하지 않으므로 연속 부분 배열이 아니다.

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 한 번 탐색하는 것만으로 충분하다 |
| Space | O(1) — 사용하는 변수는 `maxSum`과 `currentSum` 두 개뿐이다 |

## 코드

```java
// 입력: 양수와 음수를 포함할 수 있는 정수 배열 nums
// 출력: 연속 부분 배열의 합계 값의 최대값을 int로 반환한다
public int maxSubArray(int[] nums) {
    // 탐색 전체를 통해 출현한 부분 배열 합의 최대값을 기록하는 변수
    // 모든 요소가 음수인 경우에도 올바르게 최대값을 선택할 수 있도록 Integer.MIN_VALUE로 초기화한다
    // 주의: 0으로 초기화하면, 모든 요소가 음수일 때 "빈 부분 배열(합계 0)"이 최대라고 잘못 판정하게 된다
    int maxSum = Integer.MIN_VALUE;
    // 현재 구축 중인 부분 배열의 합을 유지하는 변수. 탐색 시작 시점에서는 아직 어떤 요소도 포함하지 않으므로 0이다
    int currentSum = 0;

    // 배열을 처음부터 끝까지 하나씩 탐색한다
    for (int num : nums) {
        // currentSum + num은 "직전까지의 부분 배열을 연장한 경우의 합"이다
        // num은 "이 요소에서 새로운 부분 배열을 시작한 경우의 합"이다
        // 큰 쪽을 선택함으로써 항상 최적의 판단을 할 수 있다
        currentSum = Math.max(currentSum + num, num);
        // 현재 부분 배열의 합이 지금까지의 최대값을 초과하면 갱신하고, 초과하지 않으면 유지한다
        maxSum = Math.max(maxSum, currentSum);
    }
    // 탐색이 종료된 시점에서, maxSum에는 모든 연속 부분 배열 중 최대 합계 값이 기록되어 있다
    return maxSum;
}
```
