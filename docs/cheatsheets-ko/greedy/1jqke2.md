# Determining if You Can Reach the End of an Array — 배열의 끝에 도달할 수 있는지를 판정하기

## 문제의 본질

정수 배열 `nums`가 주어진다. 각 요소 `nums[i]`는 해당 인덱스에서 앞으로 점프할 수 있는 **최대 길이**를 나타낸다. 인덱스 `0`에서 시작하여 배열의 **마지막 인덱스**에 도달할 수 있는지를 `boolean`으로 반환한다.

## 핵심 아이디어

각 위치에서 "여기서 도달할 수 있는 최원점"을 계속 갱신하면, 그 최원점이 현재 위치보다 앞쪽으로 떨어지는 순간에 도달 불가능하다고 판정할 수 있다. 개별 점프 경로를 추적할 필요 없이, "지금까지 도달 가능한 최원 인덱스"라는 하나의 값만으로 충분하다.

## 사고 프로세스

1. **도달 가능성은 최원점으로 결정된다**: 인덱스 `i`에 도달할 수 있는지 여부는, 그 이전의 모든 요소로부터 계산되는 "도달 가능한 최원 인덱스"가 `i` 이상인지로 판정할 수 있다. 중간 경로의 세부 사항은 불필요하며, 최원점만이 중요하다
2. **최원점은 하나의 변수로 관리할 수 있다**: 각 인덱스 `i`에서 `i + nums[i]`가 해당 위치에서의 최원 도달 지점이다. 지금까지의 최원점과 비교하여 더 큰 쪽을 유지하면, 변수 하나로 전체 도달 가능 범위를 추적할 수 있다
3. **도달 불가능의 판정 조건**: 배열을 왼쪽부터 순서대로 탐색할 때, 현재 인덱스 `i`가 최원점 `maxReach`를 초과하고 있다면, 인덱스 `i`에는 애초에 도달할 수 없다. 즉, `i > maxReach`가 도달 불가능의 조건이다
4. **조기 종료 조건**: `maxReach`가 배열의 마지막 인덱스 `nums.length - 1` 이상이 된 시점에서, 끝에 도달 가능하다고 확정되므로, 나머지 탐색을 건너뛰고 `true`를 반환할 수 있다
5. **탐색이 끝까지 완료된 경우**: 도중에 `false`도 `true`도 되지 않고 루프가 종료된 경우, 모든 인덱스가 도달 가능했다는 것을 의미하므로 `true`를 반환한다

## 사전 지식

### Math.max란

두 개의 정수를 받아 더 큰 쪽의 값을 반환하는 정적 메서드이다. 최원점 갱신 시 "현재의 최원점"과 "새로 계산한 도달 지점"을 비교하기 위해 사용한다.

```java
Math.max(3, 5);    // 5를 반환한다 — 두 인수 중 더 큰 쪽
Math.max(7, 2);    // 7을 반환한다
Math.max(4, 4);    // 4를 반환한다 — 같은 경우 해당 값을 반환한다
```

### maxReach(최원 도달 인덱스)란

배열의 처음부터 현재 위치까지의 모든 요소를 고려했을 때, 도달 가능한 가장 먼 인덱스를 나타내는 변수이다. 인덱스 `i`에 있을 때, `i + nums[i]`가 해당 위치에서 도달할 수 있는 최원점이며, `maxReach = Math.max(maxReach, i + nums[i])`로 항상 최댓값을 유지한다.
예: `nums = [2, 3, 1, 1, 4]`일 때, `i=0`에서 `maxReach = 0 + 2 = 2`, `i=1`에서 `maxReach = max(2, 1 + 3) = 4`가 되어, 마지막 인덱스 `4`에 도달 가능하다고 판정할 수 있다.

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 한 번 탐색하는 것만으로 충분하다 |
| Space | O(1) — 추가 변수는 `maxReach` 하나뿐이다 |

## 코드

```java
// 입력: 정수 배열 nums (각 요소는 해당 인덱스에서의 최대 점프 길이)
// 출력: 마지막 인덱스에 도달할 수 있으면 true, 도달할 수 없으면 false를 반환한다
boolean canJump(int[] nums) {
    // 지금까지 도달 가능한 최원 인덱스를 추적하는 변수
    // 시작 지점은 인덱스 0이므로, 초기값은 0이다
    int maxReach = 0;

    // 배열을 처음부터 끝까지 하나씩 탐색한다
    for (int i = 0; i < nums.length; i++) {
        // 현재 인덱스가 최원 도달 지점을 초과하면, 여기에는 도달할 수 없다
        if (i > maxReach) return false;

        // i + nums[i]는 현재 위치에서 도달할 수 있는 최원 인덱스이다
        // 지금까지의 maxReach와 비교하여 더 큰 쪽을 유지한다
        maxReach = Math.max(maxReach,
            i + nums[i]);

        // 최원 도달 지점이 배열의 마지막 인덱스 이상이면, 끝에 도달 가능하다고 확정된다
        if (maxReach >= nums.length - 1)
            return true;
    }
    // 루프가 끝까지 완료된 경우, 모든 인덱스가 도달 가능했으므로 true를 반환한다
    return true;
}
```
