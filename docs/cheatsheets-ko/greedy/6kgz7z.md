# Finding the Minimum Jumps to Reach the End — 배열의 끝에 도달하기 위한 최소 점프 횟수를 구하기

## 문제의 본질

정수 배열 `nums`가 주어지며, 각 요소 `nums[i]`는 해당 위치에서 최대 몇 칸 앞으로 점프할 수 있는지를 나타낸다. 인덱스 0에서 시작하여 마지막 인덱스에 도달하기 위해 필요한 **최소 점프 횟수**를 반환한다. 끝에는 반드시 도달할 수 있다는 것이 보장되어 있다.

## 핵심 아이디어

각 점프를 "한 번의 점프로 도달할 수 있는 범위(윈도우)"로 파악하고, 윈도우의 경계에 도달할 때마다 점프 횟수를 1 증가시킨다. 윈도우 내를 순회하면서 다음 윈도우의 최원 도달점을 기록함으로써, BFS의 레벨 탐색과 동일한 효과를 O(1) 공간에서 실현할 수 있다.

## 사고 과정

1. **최소 횟수를 구하는 문제는 BFS로 풀 수 있다**: 각 위치를 노드로, 점프 가능한 범위를 에지로 간주하면, 인덱스 0에서 끝까지의 최단 경로 문제가 된다. BFS는 레벨별로 탐색하므로, 처음으로 끝에 도달한 레벨이 최소 점프 횟수가 된다
2. **BFS의 레벨을 윈도우로 표현한다**: 일반적인 BFS는 큐를 사용하여 O(n)의 공간을 소비한다. 그러나 배열 위의 점프에서는 각 레벨에서 도달 가능한 범위가 연속 구간이 되므로, 구간의 끝점 `currentEnd`만으로 현재 레벨을 표현할 수 있다
3. **윈도우 내에서 다음 최원 도달점을 추적한다**: 현재 윈도우 내(이전 `currentEnd`부터 현재 `currentEnd`까지)를 순회하면서, 각 위치 `i`에서 도달할 수 있는 최원점 `i + nums[i]`의 최댓값을 변수 `farthest`에 기록한다. 이것이 다음 윈도우의 끝점이 된다
4. **윈도우의 경계에서 점프를 확정한다**: 인덱스 `i`가 `currentEnd`에 도달했을 때, 현재 윈도우를 모두 사용했음을 의미한다. 이 시점에서 점프 횟수를 1 증가시키고, `currentEnd`를 `farthest`로 갱신하여 다음 윈도우로 이행한다
5. **루프 범위는 끝의 한 칸 앞까지이다**: 루프를 `i < nums.length - 1`로 돌림으로써, 마지막 인덱스에 도달한 시점에서 불필요한 점프를 세는 것을 방지한다. 끝에 도달할 수 있다는 것이 보장되어 있으므로, 도달 판정은 불필요하다
6. **최종적으로 반환하는 것**: 루프 종료 후, 변수 `jumps`에 누적된 최소 점프 횟수를 반환한다

## 전제 지식

### Greedy BFS(탐욕 너비 우선 탐색)란

BFS(너비 우선 탐색)는 그래프의 시작점에서 각 노드까지의 최단 경로를 구하는 알고리즘이다. 일반적으로는 큐를 사용하지만, 배열 위의 점프 문제에서는 도달 가능 범위가 연속 구간이 되므로, 구간의 경계만을 관리하는 탐욕법으로 동일한 결과를 얻을 수 있다. 각 레벨(점프 1회분)에서 도달 가능한 최원점을 탐욕적으로 선택함으로써 최소 점프 횟수를 구할 수 있다.

### Math.max란

두 정수 중 큰 쪽을 반환하는 Java의 표준 메서드이다. 현재의 최원 도달점과 새로 계산한 도달점을 비교하여, 더 먼 쪽을 유지하기 위해 사용한다.

```java
Math.max(3, 7);       // 두 값 중 큰 쪽을 반환한다 → 7
Math.max(farthest, i + nums[i]);  // 현재의 최원점과 새로운 도달점을 비교한다
```

### 윈도우(점프 범위)란

한 번의 점프로 도달할 수 있는 인덱스의 연속 구간을 말한다. 변수 `currentEnd`가 윈도우의 오른쪽 끝을 나타낸다. `i`가 `currentEnd`에 도달하면, 현재 윈도우를 모두 사용했음을 의미하며, 다음 점프가 필요하게 된다.
예: `nums = [2,3,1,1,4]`의 경우, 첫 번째 윈도우는 `[1,2]`(인덱스 0에서 최대 2칸 앞)이고, 다음 윈도우는 `[3,4]`(윈도우 내의 최원 도달점 4까지)이다.

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 배열을 한 번 순회하는 것만으로 충분하다 |
| Space | O(1) — 3개의 변수만 사용하며, 추가 데이터 구조를 필요로 하지 않는다 |

## 코드

```java
// 입력: 정수 배열 nums (각 요소는 해당 위치에서의 최대 점프 길이)
// 출력: 마지막 인덱스에 도달하기 위한 최소 점프 횟수를 int로 반환한다
public int jump(int[] nums) {
    // 점프 횟수를 기록하는 변수. 윈도우의 경계에 도달할 때마다 1을 증가시킨다
    int jumps = 0;
    // 현재 점프 윈도우의 오른쪽 끝. 처음에는 인덱스 0에 있으므로 0으로 초기화한다
    int currentEnd = 0;
    // 윈도우 내에서 도달할 수 있는 가장 먼 인덱스. 다음 윈도우의 오른쪽 끝을 결정하기 위해 사용한다
    int farthest = 0;

    // 끝의 한 칸 앞까지 순회한다. 끝에 도달한 시점에서 목적을 달성하였으므로, 거기서 더 점프할 필요가 없다
    for (int i = 0; i < nums.length - 1; i++) {
        // i + nums[i]는 현재 위치 i에서 최대 점프했을 때의 도달 인덱스이다
        // 지금까지의 farthest보다 멀면 갱신한다
        farthest = Math.max(farthest, i + nums[i]);

        // 현재 윈도우의 오른쪽 끝에 도달하면, 다음 점프가 필요하다
        if (i == currentEnd) {
            // 점프 횟수를 1 증가시킨다
            jumps++;
            // 다음 윈도우의 오른쪽 끝을 farthest로 설정한다. 다음 윈도우의 범위는 currentEnd+1부터 새로운 currentEnd까지이다
            currentEnd = farthest;
        }
    }
    // 누적된 최소 점프 횟수를 반환한다
    return jumps;
}
```
