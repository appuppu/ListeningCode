# Traversing a Matrix in Spiral Order — 행렬의 모든 요소를 나선 순서로 가져오기

## 문제의 본질

m행 n열의 행렬 `matrix`가 주어진다. 왼쪽 상단 모서리에서 시작하여 오른쪽→아래→왼쪽→위 순서로 외곽을 따라가며, 안쪽으로 반복하여 모든 요소를 **나선(스파이럴) 순서**로 나열한 배열을 반환한다.

## 핵심 아이디어

행렬의 외곽을 하나의 "층"으로 간주하고, 상변·우변·하변·좌변의 4변을 순서대로 순회한다. 한 층의 순회가 끝나면 4개의 경계 포인터를 안쪽으로 줄임으로써 다음 층으로 자연스럽게 이행할 수 있다.

## 사고 과정

1. **스파이럴 순회는 4방향의 반복이다**: 오른쪽→아래→왼쪽→위의 4방향을 외곽에서 안쪽으로 반복하는 구조이므로, 현재 순회 범위의 "상단·하단·좌단·우단"을 관리하면 각 방향의 순회 범위가 유일하게 결정된다
2. **4개의 경계 포인터로 순회 범위를 표현한다**: `top`(상단 행), `bottom`(하단 행), `left`(좌단 열), `right`(우단 열)의 4개 변수를 준비한다. 이 변수들이 현재 층의 4변의 위치를 나타낸다
3. **각 변의 순회 순서를 결정한다**: 상변은 왼쪽에서 오른쪽으로(열을 증가), 우변은 위에서 아래로(행을 증가), 하변은 오른쪽에서 왼쪽으로(열을 감소), 좌변은 아래에서 위로(행을 감소). 이 4개의 for 루프로 한 층의 순회가 완료된다
4. **한 변의 순회 후에 경계를 줄인다**: 상변을 순회하면 `top++`(상단을 1행 아래로), 우변을 순회하면 `right--`(우단을 1열 왼쪽으로), 하변을 순회하면 `bottom--`, 좌변을 순회하면 `left++`. 이를 통해 다음 루프에서는 한 겹 안쪽 층을 순회한다
5. **하변과 좌변의 순회에는 추가 조건이 필요하다**: 상변 순회 후에 `top`을 증가시키고, 우변 순회 후에 `right`를 감소시키므로, 하변 순회 시점에서 `top <= bottom`이 깨져 있을 가능성이 있다. 마찬가지로 좌변 순회 시점에서 `left <= right`가 깨져 있을 가능성이 있다. 이러한 조건을 만족하지 않으면 이미 순회한 행이나 열을 중복하여 읽게 되므로 조건 검사가 필요하다
6. **종료 조건은 경계의 교차이다**: `top > bottom` 또는 `left > right`가 된 시점에서 모든 층의 순회가 완료된 것이다. while 루프의 조건에 `top <= bottom && left <= right`를 지정하면 자연스럽게 종료된다

## 사전 지식

### ArrayList란

가변 길이의 배열이다. 요소를 끝에 추가하는 `add`가 O(1)로 수행된다. 결과의 스파이럴 순서 배열을 구축하기 위해 사용한다.

```java
List<Integer> res = new ArrayList<>();  // 빈 ArrayList를 생성한다
res.add(5);                             // 끝에 5를 추가한다 → [5]
res.add(3);                             // 끝에 3을 추가한다 → [5, 3]
res.size();                             // 요소 수를 반환한다 → 2
```

### 경계 포인터(Boundary Pointers)란

행렬의 순회 범위를 나타내는 4개의 정수 변수이다. `top`과 `bottom`이 행의 범위를, `left`와 `right`가 열의 범위를 나타낸다. 순회할 때마다 값을 변경하여 범위를 안쪽으로 축소한다.

```java
int top = 0;                    // 상단 행 인덱스 (초기값: 0)
int bottom = matrix.length - 1; // 하단 행 인덱스 (초기값: 마지막 행)
int left = 0;                   // 좌단 열 인덱스 (초기값: 0)
int right = matrix[0].length - 1; // 우단 열 인덱스 (초기값: 마지막 열)
top++;    // 상단을 1행 아래로 줄인다
right--;  // 우단을 1열 왼쪽으로 줄인다
```

## 계산량

| | 값 |
|---|---|
| Time | O(m × n) — 행렬의 모든 요소를 정확히 1번씩 순회한다 |
| Space | O(1) — 출력용 리스트를 제외하고, 경계 포인터 4개만을 사용한다 |

## 코드

```java
// 입력: m행 n열의 정수 행렬 matrix
// 출력: 모든 요소를 스파이럴 순서로 저장한 List<Integer>를 반환한다
List<Integer> spiralOrder(int[][] matrix) {
    // 결과를 저장할 가변 길이 리스트를 생성한다
    List<Integer> res = new ArrayList<>();
    // 행렬이 비어 있으면(행 수가 0이면) 빈 리스트를 그대로 반환한다
    if (matrix.length == 0) return res;

    // 4개의 경계 포인터를 초기화한다. 이 포인터들이 현재 순회해야 할 층의 4변 위치를 나타낸다
    int top = 0;                      // 상단 행 (최상단 행)
    int bottom = matrix.length - 1;   // 하단 행 (최하단 행)
    int left = 0;                     // 좌단 열 (최좌측 열)
    int right = matrix[0].length - 1; // 우단 열 (최우측 열)

    // 순회 범위가 존재하는 동안 층별로 반복한다. 경계가 교차하면 모든 요소의 순회가 완료된 것이다
    while (top <= bottom && left <= right) {
        // 상변: 왼쪽에서 오른쪽으로 순회한다
        for (int c = left; c <= right; c++)
            res.add(matrix[top][c]);
        // 상변 순회를 완료했다. 상단을 1행 아래로 줄여서 다음 우변 순회에서 모서리 요소를 중복 읽지 않도록 한다
        top++;

        // 우변: 위에서 아래로 순회한다 (top은 이미 갱신되었으므로 모서리 중복이 없다)
        for (int r = top; r <= bottom; r++)
            res.add(matrix[r][right]);
        // 우변 순회를 완료했다. 우단을 1열 왼쪽으로 줄인다
        right--;

        // 하변: 오른쪽에서 왼쪽으로 순회한다
        // 조건 검사: top++ 결과 top > bottom이 된 경우(남은 행이 1행이었던 경우),
        // 하변은 상변과 같은 행이며 이미 순회를 완료했으므로 건너뛴다
        if (top <= bottom) {
            for (int c = right; c >= left; c--)
                res.add(matrix[bottom][c]);
            // 하단을 1행 위로 줄인다
            bottom--;
        }

        // 좌변: 아래에서 위로 순회한다
        // 조건 검사: right-- 결과 left > right가 된 경우(남은 열이 1열이었던 경우),
        // 좌변은 우변과 같은 열이며 이미 순회를 완료했으므로 건너뛴다
        if (left <= right) {
            for (int r = bottom; r >= top; r--)
                res.add(matrix[r][left]);
            // 좌단을 1열 오른쪽으로 줄인다
            left++;
        }
    }
    // 전체 m×n개의 요소가 스파이럴 순서로 저장된 리스트를 반환한다
    return res;
}
```
