# Determining if a Number is a Happy Number — 각 자릿수의 제곱합을 반복하여 1에 도달하는지 판정한다

## 문제의 본질

양의 정수 `n`이 주어진다. `n`의 각 자릿수를 제곱하여 합산하는 연산을 반복하고, 결과가 **1**에 도달하면 "해피 넘버"로서 `true`를 반환한다. 1에 도달하지 못하고 무한 루프에 빠지는 경우에는 `false`를 반환한다.

## 핵심 아이디어

각 자릿수의 제곱합을 반복하는 연산은 반드시 유한 개의 값 안에서 순환한다. 이것은 연결 리스트의 사이클 검출과 동일한 구조이며, Floyd의 슬로 포인터와 패스트 포인터를 사용하면 추가 메모리 없이 사이클의 유무와 도달 지점을 판정할 수 있다.

## 사고 프로세스

1. **연산을 반복하면 반드시 루프가 발생한다**: 각 자릿수의 제곱합을 계산하는 연산을 반복하면, 값은 유한한 범위에 수렴하므로 결국 과거에 나온 값에 다시 도달한다. 즉, 수열은 반드시 "1에서 멈추는 루프" 또는 "1을 포함하지 않는 루프" 중 하나에 진입한다
2. **루프 검출은 사이클 검출 문제로 귀착할 수 있다**: 각 값에서 다음 값으로의 전이를 "노드에서 노드로의 링크"로 간주하면, 이 문제는 연결 리스트에 사이클이 있는지를 검출하는 문제와 동일한 구조가 된다
3. **Floyd의 투 포인터 기법으로 O(1) 공간에서 검출한다**: 슬로 포인터는 1스텝씩, 패스트 포인터는 2스텝씩 전진한다. 사이클이 존재하면, 두 포인터는 반드시 사이클 내의 어딘가에서 합류한다
4. **합류 지점의 값으로 결과를 판정한다**: 두 포인터가 합류했을 때, 그 값이 1이면 해피 넘버이다(1의 각 자릿수의 제곱합은 1이므로, 1 자체가 사이클을 형성한다). 1 이외의 값에서 합류한 경우에는, 1을 포함하지 않는 사이클에 진입한 것이므로 해피 넘버가 아니다
5. **초기값 설정**: 슬로 포인터를 `n`으로, 패스트 포인터를 `getNext(n)`으로 설정하여 시작한다. 이렇게 하면 `while (slow != fast)` 루프에 자연스럽게 진입할 수 있다

## 전제 지식

### 각 자릿수의 제곱합 계산

정수 `n`의 각 자릿수를 추출하려면, `n % 10`으로 최하위 자릿수를 얻고, `n /= 10`으로 최하위 자릿수를 제거하는 연산을 `n`이 0이 될 때까지 반복한다.

```java
int n = 19;
int digit = n % 10;   // 최하위 자릿수를 취득 → 9
n /= 10;              // 최하위 자릿수를 제거 → n은 1이 된다
digit = n % 10;       // 다음 자릿수를 취득 → 1
// 19 → 1² + 9² = 1 + 81 = 82
```

### Floyd의 사이클 검출법(투 포인터 기법)이란

연결 리스트나 수열에 사이클(루프)이 있는지를 검출하는 알고리즘이다. 슬로 포인터는 1스텝씩, 패스트 포인터는 2스텝씩 전진한다. 사이클이 존재하는 경우, 패스트 포인터가 슬로 포인터를 따라잡아 반드시 합류한다. 추가적인 데이터 구조를 사용하지 않으므로 공간 복잡도는 O(1)이다.

```java
int slow = start;                // 슬로 포인터는 1스텝씩 전진한다
int fast = getNext(start);       // 패스트 포인터는 초기 위치를 1칸 앞으로 설정한다
while (slow != fast) {
    slow = getNext(slow);        // 1스텝 전진한다
    fast = getNext(getNext(fast)); // 2스텝 전진한다
}
// 루프 종료 시, slow == fast가 합류 지점의 값이다
```

## 계산량

| | 값 |
|---|---|
| Time | O(log n) — 각 자릿수의 제곱합 계산에 O(log n)이 소요되며, 사이클에 도달하기까지의 반복 횟수는 상수 범위에 수렴한다 |
| Space | O(1) — 슬로 포인터와 패스트 포인터의 두 변수만을 사용한다 |

## 코드

```java
// 입력: 양의 정수 n
// 출력: n이 해피 넘버이면 true, 그렇지 않으면 false를 반환한다

// 정수 n의 각 자릿수의 제곱합을 계산하여 반환하는 헬퍼 함수
// n % 10으로 최하위 자릿수를 추출하고, 제곱을 누적하며, n /= 10으로 자릿수를 제거하는 연산을 반복한다
private int getNext(int n) {
    int sum = 0;
    while (n > 0) {
        int digit = n % 10;   // 최하위 자릿수를 추출한다
        sum += digit * digit;  // 자릿수의 제곱을 sum에 가산한다
        n /= 10;               // 최하위 자릿수를 제거한다
    }
    return sum;
}

public boolean isHappy(int n) {
    // 슬로 포인터는 n에서, 패스트 포인터는 1스텝 앞인 getNext(n)에서 시작한다
    // fast를 1칸 앞으로 설정함으로써 while (slow != fast) 루프에 자연스럽게 진입할 수 있다
    int slow = n;
    int fast = getNext(n);

    // 두 포인터가 합류할 때까지 루프를 실행한다
    // 슬로와 패스트의 속도 차이로 인해, 사이클이 존재하면 반드시 합류한다
    while (slow != fast) {
        slow = getNext(slow);           // 슬로 포인터는 1스텝 전진한다
        fast = getNext(getNext(fast));   // 패스트 포인터는 2스텝 전진한다
    }

    // 합류 지점이 1이면 해피 넘버이다(1의 각 자릿수의 제곱합은 1이므로, 1 자체가 사이클을 형성한다)
    // 1 이외의 값에서 합류한 경우에는, 1을 포함하지 않는 사이클에 진입한 것이므로 해피 넘버가 아니다
    return fast == 1;
}
```
