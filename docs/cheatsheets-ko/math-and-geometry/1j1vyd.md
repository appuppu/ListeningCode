# Multiplying Two Numbers Represented as Strings — 문자열로 표현된 두 수를 곱셈하기

## 문제의 본질

음이 아닌 정수를 나타내는 두 문자열 `num1`과 `num2`가 주어진다. 두 수의 **곱**을 문자열로 반환한다. 내장 큰 정수 라이브러리를 사용하거나, 입력을 직접 정수로 변환하는 것은 금지되어 있다.

## 핵심 아이디어

초등학교에서 배우는 필산 곱셈을 그대로 시뮬레이션한다. `num1`의 i번째 자릿수와 `num2`의 j번째 자릿수의 곱은 결과의 `i + j`번째 자릿수와 `i + j + 1`번째 자릿수에 가산된다는 위치 관계가 핵심이다.

## 사고 과정

1. **필산 곱셈을 재현한다**: 정수로 변환할 수 없으므로, 한 자릿수씩 곱셈하여 결과를 누적하는 필산 알고리즘을 그대로 구현한다
2. **곱의 최대 자릿수를 추정한다**: n자리 수와 m자리 수의 곱은 최대 `n + m`자리가 된다(예: 99 × 99 = 9801, 2자리 × 2자리 = 4자리). 따라서 크기 `n + m`의 배열 `pos`를 준비하고, 각 자릿수의 값을 저장한다
3. **각 자릿수의 곱이 결과의 어느 위치에 대응하는지를 특정한다**: `num1`의 오른쪽에서 세어 i번째 자릿수와 `num2`의 오른쪽에서 세어 j번째 자릿수의 곱은 결과의 오른쪽에서 `i + j`번째와 `i + j + 1`번째 위치에 영향을 준다. 문자열 인덱스에서는 `num1[i] * num2[j]`의 곱이 `pos[i + j + 1]`(아래 자릿수)과 `pos[i + j]`(위 자릿수)에 가산된다
4. **올림을 그 자리에서 처리한다**: 각 자릿수 쌍의 곱을 계산한 후, `pos[p2]`에 이미 누적되어 있는 값과 합산하고, 10으로 나눈 나머지를 해당 자릿수에 남기고, 10으로 나눈 몫을 위 자릿수 `pos[p1]`에 가산한다. 이를 통해 올림이 즉시 처리된다
5. **선행 0을 제거하고 문자열을 구축한다**: 배열 `pos`의 선두에는 0이 포함될 수 있다(예: 3자리 × 2자리의 곱이 4자리일 때, 5자리 분량의 배열 선두가 0이 된다). 선행 0을 건너뛰면서 `StringBuilder`로 문자열을 구축한다
6. **0의 특별 처리**: 입력 중 하나가 `"0"`인 경우, 곱은 반드시 `"0"`이므로 조기에 `"0"`을 반환한다

## 사전 지식

### charAt와 문자에서 숫자로의 변환

`String.charAt(i)`는 문자열의 i번째 문자를 `char` 타입으로 반환한다. `char` 타입의 `'0'`~`'9'`를 정수 0~9로 변환하려면, `'0'`의 문자 코드를 뺀다.

```java
String s = "123";
char c = s.charAt(0);       // '1' (char 타입)
int digit = c - '0';        // 1 (int 타입). '1'의 코드 49에서 '0'의 코드 48을 뺀다
```

### 필산의 위치 관계

n자리 × m자리의 필산에서, `num1[i]`와 `num2[j]`의 곱(최대 81)은 2자리가 될 수 있다. 이 2자리는 결과의 `pos[i + j]`(위 자릿수)와 `pos[i + j + 1]`(아래 자릿수)에 대응한다.

```
예: "12" × "34"
  num1[0]=1, num2[0]=3 → 곱3  → pos[0], pos[1]에 가산
  num1[0]=1, num2[1]=4 → 곱4  → pos[1], pos[2]에 가산
  num1[1]=2, num2[0]=3 → 곱6  → pos[1], pos[2]에 가산
  num1[1]=2, num2[1]=4 → 곱8  → pos[2], pos[3]에 가산
```

### StringBuilder

가변 길이의 문자열을 효율적으로 구축하는 클래스이다. `append`로 끝에 문자를 추가하고, 마지막에 `toString`으로 `String`으로 변환한다.

```java
StringBuilder sb = new StringBuilder();  // 빈 StringBuilder를 생성한다
sb.append(4);                            // "4"를 끝에 추가한다
sb.append(0);                            // "40"이 된다
sb.append(8);                            // "408"이 된다
sb.toString();                           // String 타입 "408"을 반환한다
sb.length();                             // 현재 문자 수를 반환한다 → 3
```

## 계산량

| | 값 |
|---|---|
| Time | O(n × m) — num1의 각 자릿수와 num2의 각 자릿수의 모든 쌍을 한 번씩 곱셈한다 |
| Space | O(n + m) — 곱의 각 자릿수를 저장하는 배열의 크기가 n + m이다 |

## 코드

```java
// 입력: 음이 아닌 정수를 나타내는 문자열 num1과 num2
// 출력: 두 수의 곱을 나타내는 문자열을 반환한다
String multiply(String num1, String num2) {
    // 둘 중 하나가 "0"이면 곱은 반드시 0이므로, 조기에 "0"을 반환하고 종료한다
    if (num1.equals("0") || num2.equals("0"))
        return "0";

    int n = num1.length();
    int m = num2.length();
    // 곱의 각 자릿수를 저장하는 배열. n자리×m자리의 곱은 최대 n+m자리이므로, 이 크기로 충분하다
    int[] pos = new int[n + m];

    // 필산과 마찬가지로 아래 자릿수(끝)에서 선두를 향해 순서대로 곱셈한다
    for (int i = n - 1; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // charAt로 취득한 문자에서 '0'을 빼서, 문자를 대응하는 정수로 변환하여 곱셈한다
            int mul = (num1.charAt(i) - '0')
                * (num2.charAt(j) - '0');
            // 곱이 가산되는 위치: p1이 위 자릿수, p2가 아래 자릿수. 이 위치 관계는 필산에서의 자릿수 대응에 기반한다
            int p1 = i + j;
            int p2 = i + j + 1;
            // 이전 루프에서 같은 위치에 가산된 값을 고려하여, 이미 누적되어 있는 값과 합산한다
            int sum = mul + pos[p2];
            // 아래 자릿수에 1자리분만 남기고(10으로 나눈 나머지), 올림을 위 자릿수에 가산한다(10으로 나눈 몫)
            pos[p2] = sum % 10;
            pos[p1] += sum / 10;
        }
    }

    // 선행 0을 건너뛰면서 문자열을 구축한다 (예: 5자리 분량의 배열 선두가 0인 경우)
    StringBuilder sb = new StringBuilder();
    for (int p : pos) {
        // StringBuilder가 아직 비어 있고, 현재 값이 0인 경우는 선행 0이므로 건너뛴다
        if (sb.length() == 0 && p == 0)
            continue;
        sb.append(p);
    }
    // StringBuilder를 String 타입으로 변환하여 반환한다
    return sb.toString();
}
```
