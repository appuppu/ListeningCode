# Detecting Axis-Aligned Squares From Points — 저장된 점들로부터 축에 평행한 정사각형을 세기

## 문제의 본질

2D 평면 위에 점을 추가하는 `add` 연산과, 주어진 점을 하나의 꼭짓점으로 포함하는 **축에 평행한 정사각형**(4변이 모두 x축 또는 y축에 평행)의 개수를 반환하는 `count` 연산을 가진 데이터 구조를 설계한다. 같은 좌표에 여러 번 추가된 점은 각각 별개의 점으로 취급한다.

## 핵심 아이디어

축에 평행한 정사각형은 대각선 위의 2점이 결정되면 나머지 2점이 유일하게 결정된다. 쿼리 점과 같은 x좌표를 가진 점을 대각선의 파트너 후보로 열거하고, 나머지 2개의 꼭짓점의 존재를 HashMap으로 O(1)에 확인하면 효율적으로 정사각형을 셀 수 있다.

## 사고 과정

1. **축에 평행한 정사각형의 성질을 이해한다**: 4변이 x축·y축에 평행하므로 4개의 꼭짓점은 `(x1,y1)`, `(x1,y2)`, `(x2,y1)`, `(x2,y2)` 형태가 된다. 즉, x좌표가 같은 2점과 y좌표가 같은 2점의 조합으로 구성된다
2. **대각선 위의 2점으로부터 나머지 2점을 특정한다**: 쿼리 점 `(px, py)`와 같은 x좌표에서 다른 y좌표를 가진 점 `(px, pt_y)`를 선택하면, 변의 길이는 `|py - pt_y|`가 된다. 나머지 2개의 꼭짓점은 `(px ± side, py)`와 `(px ± side, pt_y)` 위치에 존재해야 한다
3. **정사각형은 좌우 2방향으로 만들 수 있다**: 변의 길이 `side`가 결정되면 나머지 x좌표는 `px - side` 또는 `px + side`의 2가지가 있다. 양쪽 방향을 모두 확인해야 한다
4. **각 좌표의 점의 개수를 기록한다**: 같은 좌표에 여러 개의 점이 추가될 수 있으므로 HashMap으로 각 좌표의 점의 출현 횟수를 관리한다. 나머지 2개 꼭짓점의 출현 횟수의 곱이 해당 조합으로 만들 수 있는 정사각형의 수가 된다
5. **같은 x좌표의 점을 빠르게 가져온다**: x좌표를 키로 하여 해당 좌표를 가진 모든 점의 리스트를 별도의 HashMap으로 관리한다. 이렇게 하면 `count` 시에 같은 x좌표의 점만 효율적으로 열거할 수 있다
6. **결과를 누적하여 반환한다**: 각 파트너 후보와 각 방향에 대해 나머지 2개 꼭짓점의 출현 횟수의 곱을 결과에 더해 나간다

## 전제 지식

### HashMap의 키에 좌표를 사용하는 방법

2차원 좌표 `(x, y)`를 HashMap의 키로 사용하려면 문자열 `"x,y"`로 변환하는 방법이 있다. 이를 통해 임의의 좌표에 대해 O(1)로 값을 저장·조회할 수 있다.

```java
Map<String, Integer> cnt = new HashMap<>();
String key = x + "," + y;               // 좌표(3,5) → "3,5"
cnt.put(key, cnt.getOrDefault(key, 0) + 1);  // 해당 좌표의 출현 횟수를 1 증가시킨다
cnt.getOrDefault(key, 0);               // 존재하지 않으면 0을 반환한다
```

### computeIfAbsent란

지정한 키가 Map에 존재하지 않는 경우에만 새로운 값을 생성하여 등록하는 메서드이다. 키가 이미 존재하는 경우에는 기존 값을 그대로 반환한다. 리스트의 Map을 구축할 때 유용하다.

```java
Map<Integer, List<int[]>> xMap = new HashMap<>();
// 키 5가 존재하지 않으면 새로운 ArrayList를 생성하고, 존재하면 해당 리스트를 반환한다
xMap.computeIfAbsent(5, k -> new ArrayList<>()).add(new int[]{5, 3});
```

### 조합의 수를 세는 방법 (곱의 법칙)

2개의 독립적인 선택지가 각각 `c1`가지와 `c2`가지인 경우, 조합의 총 수는 `c1 * c2`가 된다. 이 문제에서는 나머지 2개 꼭짓점의 좌표에 각각 `c1`개와 `c2`개의 점이 존재할 때, 그 2개 꼭짓점의 선택 방법은 `c1 * c2`가지가 된다.

## 계산량

| | 값 |
|---|---|
| Time | add: O(1) — HashMap에 등록만 수행한다. count: O(n) — 같은 x좌표의 점을 모두 순회한다 |
| Space | O(n) — 모든 점의 좌표와 출현 횟수를 HashMap에 저장한다 |

## 코드

```java
// add(int[] p): 2D 평면 위에 점 p = [x, y]를 추가한다
// count(int[] p): 점 p = [x, y]를 하나의 꼭짓점으로 포함하는 축에 평행한 정사각형의 개수를 int로 반환한다
class DetectSquares {
    // 각 좌표의 출현 횟수를 관리하는 HashMap (키: "x,y")
    // count 시에 임의의 좌표에 몇 개의 점이 있는지를 O(1)로 조회하기 위해 사용한다
    Map<String, Integer> cnt;
    // 같은 x좌표를 가진 점의 리스트를 관리하는 HashMap (키: x좌표)
    // count 시에 같은 x좌표의 점만 효율적으로 열거하기 위해 사용한다
    Map<Integer, List<int[]>> xMap;

    DetectSquares() {
        cnt = new HashMap<>();
        xMap = new HashMap<>();
    }

    void add(int[] p) {
        // 좌표를 문자열 "x,y"로 변환하여 출현 횟수를 1 증가시킨다
        String key = p[0] + "," + p[1];
        cnt.put(key, cnt.getOrDefault(key, 0) + 1);

        // x좌표별 리스트에 점을 추가한다 (처음 등장하는 x좌표이면 새로운 리스트를 생성한다)
        xMap.computeIfAbsent(p[0],
            k -> new ArrayList<>()).add(p);
    }

    int count(int[] p) {
        int res = 0;
        int px = p[0], py = p[1];

        // 쿼리 점과 같은 x좌표를 가진 점의 리스트를 가져온다
        // 리스트가 존재하지 않으면 정사각형을 구성할 수 없으므로 0을 반환한다
        List<int[]> same = xMap.get(px);
        if (same == null) return 0;

        // 같은 x좌표의 각 점을 파트너 후보로 순회한다
        for (int[] pt : same) {
            // 변의 길이를 계산한다 (쿼리 점과 파트너 점의 y좌표 차이의 절댓값)
            int side = Math.abs(py - pt[1]);
            // 같은 y좌표의 점은 변의 길이가 0이 되어 정사각형을 구성할 수 없으므로 건너뛴다
            if (side == 0) continue;

            // 정사각형은 좌우 2방향으로 만들 수 있으므로 양쪽 x좌표를 모두 시도한다
            int[] dirs = {px - side, px + side};
            for (int nx : dirs) {
                // 나머지 2개 꼭짓점의 좌표 (nx, py)와 (nx, pt[1])의 출현 횟수를 가져온다
                // 존재하지 않는 좌표는 0이 되며, 곱도 0이 되므로 자동적으로 가산되지 않는다
                String k1 = nx + "," + py;
                String k2 = nx + "," + pt[1];
                int c1 = cnt.getOrDefault(k1, 0);
                int c2 = cnt.getOrDefault(k2, 0);

                // 2개 꼭짓점의 출현 횟수의 곱이 이 조합으로 만들 수 있는 정사각형의 수이다 (곱의 법칙)
                res += c1 * c2;
            }
        }
        return res;
    }
}
```
