# Adding One to a Number Represented as an Array — 배열로 표현된 숫자에 1을 더하기

## 문제의 본질

음이 아닌 정수를 한 자릿수씩 저장한 배열 `digits`가 주어진다. 배열의 첫 번째 요소가 최상위 자릿수이고, 마지막 요소가 최하위 자릿수이다. 이 숫자에 1을 더한 결과를 같은 형식의 배열로 반환한다. 각 요소는 0부터 9까지의 한 자릿수 숫자이다.

## 핵심 아이디어

마지막 자릿수부터 1을 더하고, 올림이 발생하지 않는 시점에서 즉시 반환할 수 있다. 올림이 발생하는 경우는 해당 자릿수가 9일 때뿐이며, 모든 자릿수가 9인 경우에만 배열의 길이가 1 증가한다.

## 사고 과정

1. **덧셈은 최하위 자릿수부터 수행한다**: 숫자의 덧셈은 일의 자리부터 시작하는 것이 자연스러우므로, 배열의 끝에서 처음으로 역순으로 순회한다
2. **올림이 멈추는 조건을 생각한다**: 현재 자릿수가 9 미만이면, 1을 더해도 올림이 발생하지 않는다. 그 시점에서 덧셈이 완료되므로 즉시 배열을 반환할 수 있다
3. **자릿수가 9인 경우의 처리를 생각한다**: 현재 자릿수가 9일 때, 1을 더하면 10이 되어 올림이 발생한다. 이 자릿수를 0으로 설정하고, 다음 상위 자릿수로 올림을 전파한다. 루프의 다음 반복에서 상위 자릿수에 1을 더하는 처리가 자연스럽게 수행된다
4. **모든 자릿수가 9인 경우를 생각한다**: 999처럼 모든 자릿수가 9인 경우, 루프가 끝까지 돌아도 올림이 멈추지 않는다. 결과는 1000처럼 자릿수가 1 증가한다. 이 경우에만 새로운 배열을 생성하고 첫 번째 요소에 1을 설정한다. Java의 `new int[]`는 모든 요소가 0으로 초기화되므로, 나머지 자릿수에 0을 대입할 필요가 없다
5. **올림을 변수로 관리할 필요가 없다**: 올림의 값은 항상 1이며, 루프가 계속되는 시점에서 올림이 존재하는 것이 확정되어 있으므로, carry 변수를 준비하지 않고 루프의 계속 자체가 올림의 존재를 의미하는 구조로 만들 수 있다

## 사전 지식

### 배열의 역순 순회

배열의 끝에서 처음으로 루프를 수행한다. `i = n - 1`에서 시작하여 `i >= 0`인 동안 `i--`로 감소시킨다.

```java
int[] digits = {1, 2, 3};
int n = digits.length;                  // 배열의 길이를 가져옴 → 3
for (int i = n - 1; i >= 0; i--) {      // i=2, 1, 0 순서로 루프
    System.out.println(digits[i]);      // 3, 2, 1 순서로 출력됨
}
```

### Java의 배열 초기화

`new int[n]`으로 길이 n의 정수 배열을 생성하면, 모든 요소가 자동으로 0으로 초기화된다. 명시적으로 0을 대입할 필요가 없다.

```java
int[] result = new int[4];   // {0, 0, 0, 0}으로 초기화됨
result[0] = 1;               // {1, 0, 0, 0}이 됨
```

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(n) — 배열을 끝에서 처음까지 최대 1회 순회한다 |
| Space | O(1) — 모든 자릿수가 9인 경우를 제외하면, 입력 배열을 제자리에서 수정하므로 추가 메모리가 필요하지 않다 |

## 코드

```java
// 입력: 음이 아닌 정수의 각 자릿수를 저장한 정수 배열 digits
// 출력: digits가 나타내는 숫자에 1을 더한 결과를 저장한 int[]를 반환한다
public int[] plusOne(int[] digits) {
    // 배열의 길이를 저장한다. 역순 순회의 루프 상한과, 모든 자릿수가 9인 경우의 새 배열 길이에 사용한다
    int n = digits.length;

    // 끝에서 처음으로 순회한다. 루프가 계속되는 것 자체가 "올림이 존재한다"는 것을 의미한다
    for (int i = n - 1; i >= 0; i--) {
        // 현재 자릿수가 9 미만이면 올림이 발생하지 않는다. 1을 더하고 즉시 반환할 수 있다
        if (digits[i] < 9) {
            digits[i]++;
            return digits;  // 올림 없음. 수정된 배열을 그대로 반환하고 종료한다
        }
        // 현재 자릿수가 9이므로 0으로 설정하고 올림을 상위 자릿수로 전파한다
        digits[i] = 0;
    }

    // 모든 자릿수가 9인 경우 (예: [9,9,9] → [0,0,0]), 자릿수가 1 증가한다
    // new int[]는 모든 요소를 0으로 초기화하므로, 나머지 자릿수에 0을 대입할 필요가 없다
    int[] result = new int[n + 1];
    result[0] = 1;  // 첫 번째 요소에 1을 설정한다 (예: 999 + 1 = 1000 → [1, 0, 0, 0])
    return result;
}
```
