# Computing Power of a Number Efficiently — 부동소수점 수의 거듭제곱을 효율적으로 계산하기

## 문제의 본질

부동소수점 수 `x`와 정수 `n`이 주어진다. `x`의 `n` 제곱을 계산하여 반환한다. `n`은 음수 값을 가질 수 있으므로 음의 지수에도 대응해야 하며, `n`의 절댓값이 매우 큰 경우에도 효율적으로 계산해야 한다.

## 핵심 아이디어

지수 `n`을 2진수로 표현하면, 거듭제곱 계산은 "x를 반복적으로 제곱하면서, n의 각 비트가 1일 때만 결과에 곱하는" 연산으로 분해할 수 있다. 이를 통해 n번의 곱셈이 log(n)번으로 줄어든다.

## 사고 과정

1. **음의 지수를 양의 지수로 변환한다**: `x^(-n)`은 `(1/x)^n`과 같으므로, `n`이 음수인 경우 `x`를 `1/x`로 치환하고 `n`의 부호를 반전시키면 양의 지수 문제로 통일할 수 있다
2. **n번의 곱셈은 너무 느리다**: 단순하게 `x`를 `n`번 곱하면 O(n)이 걸린다. `n`이 수십억인 경우 이 방법으로는 시간 내에 처리할 수 없다. 지수를 절반씩 줄이는 방법이 필요하다
3. **거듭제곱은 제곱의 반복으로 분해할 수 있다**: `x^10 = x^8 × x^2`처럼, 임의의 거듭제곱은 2의 거듭제곱의 곱으로 분해할 수 있다. 이것은 지수 `n`의 2진수 표현에 대응한다. `10`은 2진수로 `1010`이므로, 비트가 1인 자릿수에 대응하는 `x^8`과 `x^2`만 곱하면 된다
4. **비트 연산으로 각 자릿수를 판정한다**: `n`의 최하위 비트가 1인지 여부는 `(n & 1) == 1`로 판정할 수 있다. 1이면 그때의 `x`(현재 자릿수에 대응하는 2의 거듭제곱만큼 누적 제곱된 값)를 결과에 곱한다
5. **x의 제곱을 반복하여 자릿수를 올린다**: 각 루프에서 `x`를 `x * x`로 갱신하면, `x`는 원래 값의 2제곱, 4제곱, 8제곱…으로 2의 거듭제곱만큼의 누적 제곱이 된다. 동시에 `n`을 1비트 오른쪽으로 시프트하여 다음 자릿수로 진행한다
6. **루프의 종료 조건**: `n`을 오른쪽으로 시프트를 계속하면 최종적으로 0이 된다. `n > 0`인 동안 루프를 돌리면 모든 비트를 처리할 수 있다

## 전제 지식

### 비트 연산(& 와 >>)이란

정수를 2진수로 취급하여 비트 단위로 조작하는 연산이다. `&`(AND)는 두 비트가 모두 1일 때만 1이 된다. `>>`(오른쪽 시프트)는 비트열을 오른쪽으로 밀어내고 최하위 비트를 버린다(2로 나누는 연산에 해당한다).

```java
int n = 10;           // 2진수: 1010
n & 1;                // 최하위 비트를 취득 → 0(짝수)
n >>= 1;              // 1비트 오른쪽 시프트 → n은 5(2진수: 101)
n & 1;                // 최하위 비트를 취득 → 1(홀수)
```

### 반복 제곱법(Fast Exponentiation)이란

지수의 2진수 표현을 이용하여 거듭제곱을 O(log n)번의 곱셈으로 계산하는 기법이다. `x^13`을 예로 들면, `13`은 2진수로 `1101`이므로 `x^13 = x^8 × x^4 × x^1`로 분해할 수 있다. 루프에서 `x`를 반복적으로 제곱하면서(`x → x^2 → x^4 → x^8`), 대응하는 비트가 1일 때만 결과에 곱한다.

```java
// x^13의 계산 과정 (13 = 1101 in binary)
// 비트0: 1 → result *= x    (result = x^1),   x = x^2
// 비트1: 0 → 건너뜀,                            x = x^4
// 비트2: 1 → result *= x^4  (result = x^5),   x = x^8
// 비트3: 1 → result *= x^8  (result = x^13),  x = x^16
```

### long 타입으로의 캐스팅이 필요한 이유

Java의 `int` 타입의 범위는 `-2^31`부터 `2^31 - 1`까지이다. `n = -2^31`일 때 `-n`은 `2^31`이 되어 `int`의 범위를 초과하여 오버플로가 발생한다. `long` 타입으로 캐스팅한 후 부호를 반전시키면 이 문제를 회피할 수 있다.

```java
int n = Integer.MIN_VALUE;   // -2147483648
long power = (long) n;       // -2147483648L (long 타입으로 변환)
power = -power;              // 2147483648L (int 타입으로는 표현 불가하지만 long 타입이면 안전)
```

## 계산량

| | 값 |
|---|---|
| Time | O(log n) — 지수 n의 비트 수만큼 루프를 돌기 때문 |
| Space | O(1) — 사용하는 변수는 result, x, power 3개뿐이며 재귀 스택도 불필요 |

## 코드

```java
// 입력: 부동소수점 수 x와 정수 n
// 출력: x의 n 제곱 값을 double로 반환한다
double myPow(double x, int n) {
    // int 타입 그대로면 n = -2^31일 때 부호 반전에서 오버플로가 발생하므로 long 타입으로 변환한다
    long power = (long) n;

    // 음의 지수를 양으로 변환한다: x^(-n) = (1/x)^n
    // 이 변환을 통해 이후의 처리를 양의 지수만으로 통일할 수 있다
    if (power < 0) {
        x = 1 / x;
        power = -power;
    }

    // 결과를 누적하는 변수를 1.0으로 초기화한다
    // 비트가 1인 자릿수에 대응하는 x의 누적 제곱을 곱하여 최종 결과를 누적해 나간다
    double result = 1.0;

    // power의 모든 비트를 하위부터 순서대로 처리한다
    // power를 오른쪽으로 시프트를 계속하면 최종적으로 0이 되어 모든 자릿수의 처리가 완료된다
    while (power > 0) {
        // power & 1로 최하위 비트(현재 처리 중인 자릿수)가 1인지 여부를 판정한다
        if ((power & 1) == 1) {
            // 비트가 1인 경우: 이 시점의 x는 원래의 x를 처리 완료된 자릿수만큼 제곱한 값(원래 x의 2^k 제곱)이다
            // 이 자릿수의 기여분을 result에 곱하여 반영한다
            result *= x;
        }
        // x를 제곱하여 다음 자릿수에 대응하는 누적 제곱 값(2배 지수의 거듭제곱)으로 갱신한다
        x *= x;
        // power를 1비트 오른쪽으로 시프트하여 다음 자릿수로 진행한다(최하위 비트가 버려진다)
        power >>= 1;
    }
    // 모든 비트의 기여분이 곱해진 최종 결과를 반환한다
    return result;
}
```
