# Rotating a Matrix 90 Degrees — n×n 행렬을 추가 메모리 없이 시계 방향으로 90도 회전시키기

## 문제의 본질

n×n 정방 행렬이 주어진다. 이 행렬을 시계 방향으로 90도 회전시킨다. 새로운 행렬을 할당하지 않고 **in-place(제자리에서)** 변환을 수행한다. 회전 후, 원래 행렬의 각 요소 `matrix[i][j]`는 `matrix[j][n-1-i]` 위치로 이동한다.

## 핵심 아이디어

90도 회전은 「전치(행과 열을 교환)」+「각 행을 좌우 반전」이라는 2가지 단순한 연산으로 분해할 수 있다. 이 분해를 통해 추가 메모리 없이 각 요소를 올바른 위치로 이동시킬 수 있다.

## 사고 과정

1. **회전의 이동 위치를 관찰한다**: 요소 `matrix[i][j]`는 90도 시계 방향 회전으로 `matrix[j][n-1-i]`로 이동한다. 이 변환을 직접 한 요소씩 수행하면 4개 요소의 순환 치환이 필요해져 복잡해진다
2. **회전을 기존의 알려진 연산으로 분해할 수 있는지 생각한다**: 전치 연산은 `matrix[i][j]`를 `matrix[j][i]`로 이동시킨다. 전치 후 각 행을 좌우 반전하면, `matrix[j][i]`가 `matrix[j][n-1-i]`로 이동한다. 이것은 원래의 `matrix[i][j]` → `matrix[j][n-1-i]`라는 90도 회전과 일치한다
3. **전치를 in-place로 구현하는 방법**: 대각선(`i == j`)을 기준으로 상삼각과 하삼각의 요소를 교환한다. `j > i` 범위에서 `matrix[i][j]`와 `matrix[j][i]`를 swap하면, 각 쌍을 한 번만 교환할 수 있다
4. **각 행의 반전을 in-place로 구현하는 방법**: 각 행에 대해 왼쪽 끝과 오른쪽 끝의 포인터를 준비하고, 중앙을 향해 요소를 교환해 나간다. 이 연산은 추가 메모리를 필요로 하지 않는다
5. **2가지 연산을 순서대로 적용한다**: 먼저 행렬 전체를 전치하고, 다음으로 각 행을 반전한다. 둘 다 in-place로 수행할 수 있으므로, 전체적으로 O(1)의 추가 메모리로 90도 회전이 완성된다

## 사전 지식

### 전치(Transpose)란

행렬의 행과 열을 교환하는 연산이다. 요소 `matrix[i][j]`와 `matrix[j][i]`의 위치를 교환한다. 정방 행렬의 경우, 대각선 위의 요소는 이동하지 않으며, 대각선을 사이에 두고 대칭 위치의 요소끼리 교환한다.

```java
// 3×3 행렬의 전치 예시
// 전치 전:        전치 후:
// [1, 2, 3]     [1, 4, 7]
// [4, 5, 6]  →  [2, 5, 8]
// [7, 8, 9]     [3, 6, 9]

// matrix[0][1]=2 와 matrix[1][0]=4 가 교환된다
int temp = matrix[i][j];
matrix[i][j] = matrix[j][i];
matrix[j][i] = temp;
```

### 배열의 반전(Reverse)이란

배열의 요소를 좌우 대칭으로 교환하는 연산이다. 왼쪽 끝과 오른쪽 끝에서 중앙을 향해 포인터를 이동시키면서 교환한다.

```java
// [1, 4, 7] → [7, 4, 1]
int left = 0, right = n - 1;
while (left < right) {
    int temp = array[left];
    array[left] = array[right];
    array[right] = temp;
    left++;
    right--;
}
```

### in-place(제자리에서) 연산이란

새로운 데이터 구조를 할당하지 않고, 입력 데이터 자체를 직접 변경하는 연산이다. 임시 변수(`temp`)의 사용은 O(1)이므로 허용된다. 문제가 「새로운 행렬을 할당하지 말라」고 지시하고 있으므로, in-place로 풀어야 한다.

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(n²) — 전치에서 n²/2회, 반전에서 n²/2회의 교환을 수행한다 |
| Space | O(1) — 임시 변수만 사용하며, 새로운 행렬을 할당하지 않는다 |

## 코드

```java
// 입력: n×n 정수 행렬 matrix(2차원 배열 int[][]). 정방 행렬이므로 행 수와 열 수가 동일하다
// 출력: 없음(void). 인수인 matrix 자체를 90도 시계 방향으로 회전시킨 상태로 변경한다
public void rotate(int[][] matrix) {
    // matrix.length 로 행렬의 크기 n을 가져온다
    int n = matrix.length;

    // 단계 1: 전치(대각선을 기준으로 요소를 교환하여 행과 열을 바꾼다)
    for (int i = 0; i < n; i++) {
        // j를 i+1부터 시작하는 이유: 대각선 위(i==j)는 교환 불필요, j<i 범위는 이미 교환 완료
        for (int j = i + 1; j < n; j++) {
            // matrix[i][j]와 matrix[j][i]를 임시 변수를 사용하여 교환하고, 행과 열을 바꾼다
            int temp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = temp;
        }
    }

    // 단계 2: 각 행을 좌우 반전한다
    for (int i = 0; i < n; i++) {
        // 왼쪽 끝과 오른쪽 끝의 2개의 포인터를 준비하고, 중앙을 향해 교환해 나간다
        int left = 0, right = n - 1;
        while (left < right) {
            // matrix[i][left]와 matrix[i][right]를 교환하여 행을 좌우 반전한다
            int temp = matrix[i][left];
            matrix[i][left] = matrix[i][right];
            matrix[i][right] = temp;
            left++;
            right--;
        }
    }
    // 모든 행의 반전이 완료된 시점에서, 행렬 전체가 90도 시계 방향으로 회전한 상태가 되어 있다
}
```
