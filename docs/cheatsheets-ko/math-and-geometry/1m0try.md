# Setting Entire Rows and Columns to Zero — 0을 포함하는 행과 열을 전부 0으로 만들기

## 문제의 본질

m×n 행렬이 주어진다. 요소가 0인 위치를 찾으면, 해당 요소가 속하는 **행 전체**와 **열 전체**를 모두 0으로 설정한다. 이 변환을 in-place(추가 행렬을 사용하지 않고)로 수행한다.

## 핵심 아이디어

행렬의 제0행과 제0열을 "어떤 행·열을 0으로 만들어야 하는지" 기록하는 플래그 영역으로 재활용하면, 추가 공간 O(1)으로 0으로 만들어야 할 행·열을 관리할 수 있다.

## 사고 과정

1. **0으로 만들어야 할 행·열을 기록할 필요가 있다**: 탐색 중에 0을 발견한 순간 해당 행·열을 바로 덮어쓰면, 이후 탐색에서 원래 값이 0이었는지 덮어쓰기로 인한 0인지 구별할 수 없게 된다. 따라서 먼저 "어떤 행·열을 0으로 만들 것인지"를 기록한 뒤, 일괄적으로 덮어쓰는 2패스 방식이 필요하다
2. **기록용으로 별도 배열을 사용하면 O(m+n) 공간이 필요하다**: 행용으로 크기 m인 배열, 열용으로 크기 n인 배열을 사용하면 기록할 수 있지만, O(1) 공간을 목표로 하고 싶다
3. **행렬 자체의 제0행·제0열을 플래그로 사용한다**: `matrix[i][0]`이 0이면 "i번째 행을 0으로 만든다", `matrix[0][j]`가 0이면 "j번째 열을 0으로 만든다"라는 의미를 부여한다. 이렇게 하면 추가 배열이 불필요해진다
4. **제0열의 플래그만은 독립된 변수가 필요하다**: `matrix[i][0]`은 "i번째 행의 플래그"와 "제0열의 원래 값"이라는 두 가지 의미를 갖게 된다. 제0열 자체를 0으로 만들어야 하는지 여부는 별도의 변수 `firstCol`로 관리한다
5. **플래그 마킹**: 행렬을 탐색하여 `matrix[i][j] == 0`을 발견하면 `matrix[i][0] = 0`과 `matrix[0][j] = 0`을 설정하여 플래그를 세운다
6. **역순으로 0을 채운다**: 플래그에 기반하여 0을 기록할 때, 제0행·제0열을 먼저 덮어쓰면 플래그가 파괴된다. 따라서 끝에서부터 역순으로 처리하고, 제0행·제0열은 마지막에 처리한다

## 사전 지식

### in-place 연산이란

추가적인 데이터 구조(별도의 행렬이나 큰 배열)를 사용하지 않고, 입력 데이터 자체를 덮어써서 결과를 얻는 연산이다. 상수 개의 변수만 추가로 사용하는 것이 허용된다.

```java
// in-place 연산의 예: 배열의 요소를 직접 덮어쓴다
matrix[i][j] = 0;  // 별도의 배열에 복사하지 않고, 원래 행렬을 직접 변경한다
```

### boolean형 플래그란

true/false의 2가지 값으로 "어떤 조건이 성립했는지"를 기록하는 변수이다. 루프 중에 조건이 한 번이라도 성립하면 true로 설정하고, 이후 처리에서 참조한다.

```java
boolean firstCol = false;       // 초기값은 false(조건 미성립)
if (matrix[i][0] == 0)
    firstCol = true;            // 조건 성립을 기록한다
// 나중에 참조한다
if (firstCol)
    matrix[i][0] = 0;          // 플래그가 true이면 처리를 실행한다
```

### 역순 루프란

배열이나 행렬을 끝에서 처음을 향해 탐색하는 루프이다. 처음의 요소가 이후 처리에 사용되는 플래그를 겸하는 경우, 처음을 마지막에 처리하기 위해 역순을 사용한다.

```java
for (int i = m - 1; i >= 0; i--)    // i를 끝(m-1)에서 0까지 1씩 감소시킨다
    for (int j = n - 1; j >= 1; j--)  // j를 끝(n-1)에서 1까지 1씩 감소시킨다
```

## 계산량

| | 값 |
|---|---|
| Time | O(m × n) — 행렬 전체를 2번 탐색한다 (플래그 설정에 1번, 0 채우기에 1번) |
| Space | O(1) — 추가 변수는 `firstCol`뿐이다. 행렬 자체를 플래그 영역으로 재활용한다 |

## 코드

```java
// 입력: m×n 정수 행렬 matrix (2차원 배열)
// 출력: 없음 (matrix를 직접 덮어쓴다. 반환값은 void)
public void setZeroes(int[][] matrix) {
    // 행 수 m과 열 수 n을 가져온다
    int m = matrix.length;
    int n = matrix[0].length;
    // 제0열을 0으로 만들어야 하는지를 기록하는 플래그
    // matrix[i][0]은 행 플래그와 겸용되므로, 제0열의 플래그만은 독립된 변수로 관리한다
    boolean firstCol = false;

    // 제1패스: 플래그 마킹
    for (int i = 0; i < m; i++) {
        // 제0열에 원래 0이 있는지 확인하고, 있으면 firstCol을 true로 설정한다
        if (matrix[i][0] == 0)
            firstCol = true;
        // j=1부터 탐색한다 (j=0은 행 플래그 겸용이므로 열 1 이후만 확인한다)
        for (int j = 1; j < n; j++)
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;  // i번째 행을 0으로 만드는 플래그
                matrix[0][j] = 0;  // j번째 열을 0으로 만드는 플래그
            }
    }

    // 제2패스: 역순으로 0을 기록한다
    // 역순으로 하는 이유: 제0행의 플래그(matrix[0][j])를 다른 행의 처리에 사용하므로, 제0행을 마지막에 처리한다
    for (int i = m - 1; i >= 0; i--) {
        // j=1부터 역순으로 탐색하여, 행 플래그 또는 열 플래그가 설정되어 있으면 0으로 만든다
        for (int j = n - 1; j >= 1; j--)
            if (matrix[i][0] == 0 || matrix[0][j] == 0)
                matrix[i][j] = 0;
        // 제0열의 0 채우기는 내부 루프 이후에 수행한다
        // 주의: 먼저 matrix[i][0]을 덮어쓰면, 위의 행 플래그 판정이 파괴된다
        if (firstCol)
            matrix[i][0] = 0;
    }
}
```
