# Finding the Minimum Eating Speed to Finish Bananas — 제한 시간 내에 모든 바나나를 먹어치우는 최소 속도를 구하기

## 문제의 본질

바나나 더미의 배열 `piles`와 제한 시간 `h`(시간)가 주어진다. 매시간 `k`개의 바나나를 먹을 때, `h` 시간 이내에 모든 바나나를 먹어치울 수 있는 **최소 정수 속도 `k`**를 반환한다. 1시간에 하나의 더미만 먹을 수 있으며, 더미의 바나나가 `k`개 미만이면 그 더미를 다 먹어도 남은 시간에 다음 더미로 넘어가지 못하고 대기한다.

## 핵심 아이디어

"속도 `k`로 전부 먹어치울 수 있는가?"는 `k`에 대해 단조성을 가진다. `k`가 크면 반드시 먹어치울 수 있고, 너무 작으면 먹어치울 수 없다. 이 단조성이 있으므로 답의 후보 범위 `[1, max(piles)]`에 대해 이분 탐색을 적용하여 조건을 만족하는 최소 `k`를 효율적으로 찾을 수 있다.

## 사고 과정

1. **속도와 결과의 관계에 단조성이 있다**: 속도 `k`를 올리면 필요 시간은 줄어들고, 내리면 늘어난다. 어떤 속도에서 먹어치울 수 있다면 그 이상의 속도에서도 반드시 먹어치울 수 있다. 이러한 "어떤 조건을 만족하는 최솟값을 구하는" 구조는 이분 탐색의 전형적인 패턴이다
2. **탐색 범위를 정한다**: 속도의 최솟값은 `1`(매시간 1개는 먹는다)이고, 최댓값은 `max(piles)`(가장 큰 더미를 1시간에 먹어치울 수 있는 속도)이다. `max(piles)`보다 큰 속도로 해도 1시간에 하나의 더미만 먹을 수 있으므로 결과는 변하지 않는다
3. **판정 함수를 설계한다**: 속도 `mid`가 주어졌을 때, 각 더미 `piles[i]`를 먹는 데 `ceil(piles[i] / mid)` 시간이 걸린다. 모든 더미의 합계 시간이 `h` 이하이면 그 속도로 먹어치울 수 있다고 판정할 수 있다
4. **올림 나눗셈을 정수 연산으로 수행한다**: `ceil(piles[i] / mid)`는 `(piles[i] + mid - 1) / mid`로 계산할 수 있다. 이를 통해 부동소수점 연산을 피하고 정수만으로 정확하게 계산할 수 있다
5. **이분 탐색으로 범위를 좁힌다**: 중간값 `mid`로 먹어치울 수 있다면 답은 `mid` 이하에 있으므로 `right = mid`로 설정한다. 먹어치울 수 없다면 답은 `mid + 1` 이상에 있으므로 `left = mid + 1`로 설정한다. `left == right`가 되었을 때 그 값이 구하는 최소 속도이다

## 전제 지식

### 이분 탐색(Binary Search)의 "조건을 만족하는 최솟값" 패턴

정렬된 값이나 연속하는 정수 범위에 대해 어떤 조건을 만족하는 최솟값(또는 최댓값)을 찾는 기법이다. 탐색 범위를 매번 절반으로 줄이기 때문에 O(log n)으로 답을 찾을 수 있다.

```java
int left = 1;               // 탐색 범위의 하한
int right = 1000;            // 탐색 범위의 상한
while (left < right) {       // left == right가 되면 답이 확정된다
    int mid = left + (right - left) / 2;  // 오버플로를 방지하는 중간값 계산
    if (condition(mid))       // mid가 조건을 만족하는지 판정한다
        right = mid;          // 조건을 만족한다 → 답은 mid 이하에 있다
    else
        left = mid + 1;       // 조건을 만족하지 않는다 → 답은 mid+1 이상에 있다
}
// left가 조건을 만족하는 최솟값이다
```

### 올림 나눗셈(Ceiling Division)

`a / b`의 결과를 올림하는 정수 연산이다. `Math.ceil`을 사용하지 않고 `(a + b - 1) / b`로 계산할 수 있다.

```java
int a = 10, b = 3;
int result = (a + b - 1) / b;  // (10 + 2) / 3 = 4  (10÷3=3.33... → 올림하여 4)
```

바나나 문제에서는 더미의 크기 `piles[i]`를 속도 `k`로 나누어 올림함으로써 그 더미를 먹어치우는 데 필요한 시간 수를 구한다.

### Math.max란

두 값 중 큰 쪽을 반환하는 메서드이다. 배열의 최댓값을 구할 때 루프와 조합하여 사용한다.

```java
Math.max(5, 3);   // → 5
Math.max(-1, 0);  // → 0
```

## 계산량

| | 값 |
|---|---|
| Time | O(n × log(max(piles))) — 이분 탐색으로 O(log(max(piles)))번의 반복을 수행하고, 각 반복에서 배열 전체를 O(n)으로 순회하여 합계 시간을 계산한다 |
| Space | O(1) — 추가 데이터 구조를 사용하지 않고 변수만으로 처리한다 |

## 코드

```java
// 입력: 정수 배열 piles(각 더미의 바나나 개수)와 정수 h(제한 시간)
// 출력: h 시간 이내에 모든 바나나를 먹어치울 수 있는 최소 정수 속도 k를 int로 반환한다
public int minEatingSpeed(int[] piles, int h) {
    // 이분 탐색의 하한을 1로 설정한다. 속도는 최소한 매시간 1개이다
    int left = 1;
    // 이분 탐색의 상한을 배열의 최댓값으로 설정한다
    // 가장 큰 더미를 1시간에 먹어치울 수 있는 속도보다 크게 해도 의미가 없으므로 이 값이 상한이 된다
    int right = 0;
    for (int p : piles) {
        right = Math.max(right, p);
    }

    // left == right가 될 때까지 탐색 범위를 절반으로 줄여나간다
    // left == right가 되었을 때 그 값이 답이다
    while (left < right) {
        // 오버플로를 방지하는 중간값 계산
        // (left + right) / 2가 아니라 left + (right - left) / 2를 사용하여 정수 오버플로를 방지한다
        int mid = left + (right - left) / 2;

        // 속도 mid로 모든 바나나를 먹는 데 필요한 합계 시간을 계산한다
        int totalHours = 0;
        for (int p : piles) {
            // 올림 나눗셈: 각 더미를 먹어치우는 데 필요한 시간 수를 구한다
            totalHours += (p + mid - 1) / mid;
        }

        if (totalHours <= h) {
            // 먹어치울 수 있다 → 더 느린 속도로도 먹어치울 가능성이 있으므로 상한을 줄인다
            // mid 자체가 답일 가능성이 있으므로 mid - 1이 아니라 mid를 대입한다
            right = mid;
        } else {
            // 먹어치울 수 없다 → 속도가 부족하므로 하한을 올린다
            // mid는 답이 될 수 없으므로 mid + 1을 대입한다
            left = mid + 1;
        }
    }

    // 루프 종료 후 left(= right)가 조건을 만족하는 최소 속도이다
    return left;
}
```
