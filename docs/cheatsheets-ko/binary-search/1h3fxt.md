# Searching for a Value in a Sorted Matrix — 정렬된 행렬에서 목표값을 찾는 방법

## 문제의 본질

m×n 행렬이 주어진다. 각 행은 오름차순으로 정렬되어 있으며, 각 행의 첫 번째 요소는 이전 행의 마지막 요소보다 크다. 주어진 `target`이 이 행렬 내에 존재하는지를 판정하여 `boolean`으로 반환한다.

## 핵심 아이디어

행렬 전체를 왼쪽 위에서 오른쪽 아래로 일렬로 나열하면 하나의 정렬된 배열로 간주할 수 있다. 1차원 인덱스 `mid`에서 행렬 좌표 `[mid / n][mid % n]`으로의 변환을 사용하면, 행렬을 평탄화하지 않고도 한 번의 이진 탐색으로 O(log(m * n))에 탐색할 수 있다.

## 사고 과정

1. **행렬 전체가 하나의 정렬된 배열이다**: 각 행이 오름차순이고 다음 행의 첫 번째 요소가 이전 행의 마지막 요소보다 크므로, 행렬의 요소를 왼쪽 위에서 오른쪽 아래로 순서대로 읽으면 전체가 하나의 오름차순 정렬된 배열이 된다
2. **정렬된 배열에는 이진 탐색을 사용할 수 있다**: 전체 요소 수는 `m * n`개이므로, 0부터 `m * n - 1`까지의 범위에서 이진 탐색을 수행하면 된다. 탐색 범위의 하한 `lo = 0`, 상한 `hi = m * n - 1`로 설정한다
3. **1차원 인덱스에서 2차원 좌표로의 변환이 필요하다**: 이진 탐색의 중간점 `mid`는 1차원 인덱스이다. 행렬에서 값을 가져오려면 2차원 좌표가 필요하므로, 행 인덱스를 `mid / n`(열 수로 나눈 몫), 열 인덱스를 `mid % n`(열 수로 나눈 나머지)으로 변환한다
4. **표준적인 이진 탐색 로직을 적용한다**: `matrix[mid / n][mid % n]`으로 가져온 값이 `target`과 같으면 `true`를 반환한다. 작으면 `lo = mid + 1`로 탐색 범위를 오른쪽 절반으로 좁히고, 크면 `hi = mid - 1`로 왼쪽 절반으로 좁힌다
5. **탐색 범위가 없어지면 target은 존재하지 않는다**: `lo > hi`가 될 때까지 일치하지 않으면, 행렬 내에 `target`은 존재하지 않으므로 `false`를 반환한다

## 사전 지식

### 이진 탐색(Binary Search)이란

정렬된 배열에 대해 탐색 범위를 매번 절반으로 줄여 나감으로써 목적 값을 고속으로 찾는 알고리즘이다. 요소 수 n에 대해 최대 log₂(n)번의 비교로 결과를 얻을 수 있다.

```java
int lo = 0, hi = array.length - 1;  // 탐색 범위의 하한과 상한을 설정한다
while (lo <= hi) {                    // 탐색 범위가 존재하는 동안 반복한다
    int mid = lo + (hi - lo) / 2;    // 오버플로를 방지하면서 중간점을 계산한다
    if (array[mid] == target)         // 중간점의 값이 target과 일치하는지 판정한다
        return true;
    else if (array[mid] < target)
        lo = mid + 1;                // target은 오른쪽 절반에 있으므로 하한을 올린다
    else
        hi = mid - 1;                // target은 왼쪽 절반에 있으므로 상한을 내린다
}
return false;                         // 찾지 못한 경우
```

### 1차원 인덱스와 2차원 좌표의 변환

열 수 `n`인 행렬에서 1차원 인덱스 `idx`를 2차원 좌표로 변환하는 것은 나눗셈과 나머지 연산으로 수행한다. 이 변환을 통해 행렬을 가상의 1차원 배열로 다룰 수 있다.

```java
int n = matrix[0].length;        // 열 수를 가져온다
int row = idx / n;               // 몫이 행 인덱스가 된다 (예: idx=7, n=4 → row=1)
int col = idx % n;               // 나머지가 열 인덱스가 된다 (예: idx=7, n=4 → col=3)
int val = matrix[row][col];      // 2차원 좌표로 행렬의 값을 가져온다
```

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(log(m * n)) — 전체 요소 수 m * n에 대해 이진 탐색을 1회 수행한다 |
| Space | O(1) — 포인터 변수만 사용하며, 추가적인 데이터 구조는 필요하지 않다 |

## 코드

```java
// 입력: m×n 정수 행렬 matrix와 정수 target
// 출력: target이 행렬 내에 존재하면 true, 존재하지 않으면 false를 반환한다
public boolean searchMatrix(int[][] matrix, int target) {
    // 행렬의 행 수와 열 수를 가져온다. 전체 요소 수 계산과 1차원→2차원 변환에 사용한다
    int m = matrix.length;
    int n = matrix[0].length;

    // 이진 탐색의 탐색 범위를 행렬 전체로 설정한다
    // lo=0은 행렬의 왼쪽 위, hi=m*n-1은 행렬의 오른쪽 아래에 대응한다
    int lo = 0, hi = m * n - 1;

    // lo > hi가 된 시점에서 탐색 범위가 없어지며, target은 존재하지 않는다고 판정할 수 있다
    while (lo <= hi) {
        // (lo + hi) / 2 대신 이 형식을 사용하여 lo + hi의 정수 오버플로를 방지한다
        int mid = lo + (hi - lo) / 2;

        // 1차원 인덱스를 2차원 좌표로 변환하여 값을 가져온다
        // 행 인덱스 = mid / n(몫), 열 인덱스 = mid % n(나머지)
        int val = matrix[mid / n][mid % n];

        if (val == target)
            return true;           // 목표값을 찾았으므로 true를 반환한다
        else if (val < target)
            lo = mid + 1;          // target은 오른쪽 절반(큰 쪽)에 있으므로 하한을 올린다
        else
            hi = mid - 1;          // target은 왼쪽 절반(작은 쪽)에 있으므로 상한을 내린다
    }

    // 루프가 종료되어도 true를 반환하지 않았으므로, target은 행렬 내에 존재하지 않는다
    return false;
}
```
