# Searching for a Target in a Rotated Sorted Array — 회전된 정렬 배열에서 타겟을 찾기

## 문제의 본질

오름차순으로 정렬된 정수 배열이 알 수 없는 피벗에서 회전되어 있다. 이 배열에서 주어진 `target` 값을 찾아 해당 인덱스를 반환한다. `target`이 존재하지 않으면 `-1`을 반환한다. 모든 요소는 고유하다.

## 핵심 아이디어

회전된 정렬 배열을 중앙에서 분할하면, 왼쪽 절반과 오른쪽 절반 중 반드시 한쪽은 정렬되어 있다. 정렬된 쪽에 `target`이 포함되는지를 범위 검사로 판정하고, 포함되지 않으면 나머지 쪽을 탐색함으로써, 매번 탐색 범위를 절반으로 줄일 수 있다.

## 사고 과정

1. **정렬된 배열이므로 Binary Search를 사용하고 싶다**: 일반적인 정렬 배열이라면 Binary Search로 O(log n)에 탐색할 수 있다. 회전이 있더라도 이 효율을 유지하는 방법을 생각한다
2. **회전된 배열을 중앙에서 분할하면, 한쪽은 반드시 정렬되어 있다**: 배열 `[4,5,6,7,0,1,2]`를 `mid=3`(값 7)에서 분할하면, 왼쪽 절반 `[4,5,6,7]`은 정렬되어 있고, 오른쪽 절반 `[0,1,2]`도 정렬되어 있다. 회전의 피벗은 한쪽에만 포함되므로, 나머지 한쪽은 반드시 오름차순이 유지된다
3. **어느 쪽이 정렬되어 있는지 판정하는 방법**: `nums[left] <= nums[mid]`가 성립하면 왼쪽 절반이 정렬되어 있다. 성립하지 않으면 오른쪽 절반이 정렬되어 있다. 등호를 포함하는 이유는, `left == mid`가 되는 경우(요소가 2개 이하일 때)를 올바르게 처리하기 위해서이다
4. **정렬된 쪽에 target이 포함되는지 판정한다**: 정렬된 쪽은 최솟값과 최댓값을 알 수 있으므로, `target`이 그 범위 안에 있는지를 부등식으로 판정할 수 있다. 예를 들어 왼쪽 절반이 정렬되어 있다면, `target >= nums[left] && target < nums[mid]`로 판정한다
5. **포함되는 쪽을 탐색한다**: `target`이 정렬된 쪽의 범위 안에 있으면, 그쪽으로 범위를 좁힌다. 범위 밖이면, 나머지 쪽에 `target`이 존재할 것이므로 그쪽을 탐색한다
6. **루프 종료 시 처리**: `left > right`가 될 때까지 탐색해도 `target`을 찾지 못하면, 배열에 `target`이 존재하지 않으므로 `-1`을 반환한다

## 사전 지식

### Binary Search(이진 탐색)란

정렬된 배열에서, 탐색 범위의 중앙 요소를 확인하여 탐색 범위를 절반으로 줄이는 작업을 반복하는 탐색 기법이다. 매번 범위가 절반이 되므로, O(log n)의 시간 복잡도로 탐색할 수 있다.

```java
int left = 0;
int right = nums.length - 1;
while (left <= right) {                    // 탐색 범위가 유효한 동안 루프한다
    int mid = left + (right - left) / 2;   // 오버플로를 방지하는 중앙 계산
    // nums[mid]와 target을 비교하여 left 또는 right를 갱신한다
}
```

### 회전된 정렬 배열이란

오름차순 정렬된 배열을 특정 위치에서 잘라, 뒷부분을 앞으로 이동시킨 배열이다. 예를 들어 `[0,1,2,4,5,6,7]`을 인덱스 4에서 회전하면 `[4,5,6,7,0,1,2]`가 된다. 배열 전체는 정렬되어 있지 않지만, 피벗의 좌우 각각은 정렬되어 있다.

```
원래 배열:   [0, 1, 2, 4, 5, 6, 7]
회전 후:     [4, 5, 6, 7, 0, 1, 2]
             정렬됨↑    ↑정렬됨
```

## 계산량

| | 값 |
|---|---|
| Time | O(log n) — 매번 탐색 범위를 절반으로 줄이므로, 최대 log n 번의 비교로 충분하다 |
| Space | O(1) — left, right, mid 3개의 변수만 사용하며, 추가 데이터 구조는 필요 없다 |

## 코드

```java
// 입력: 회전된 정렬 정수 배열 nums와 정수 target
// 출력: target의 인덱스를 int로 반환한다. 존재하지 않으면 -1을 반환한다
public int search(int[] nums, int target) {
    // 탐색 범위의 양 끝을 초기화한다. 이 두 변수가 탐색 범위의 양 끝을 나타낸다
    int left = 0;
    int right = nums.length - 1;

    // left > right가 되면 탐색 범위가 비었음을 의미한다
    while (left <= right) {
        // (left + right) / 2 대신 이 식을 사용하는 이유는, left + right의 정수 오버플로를 방지하기 위해서이다
        int mid = left + (right - left) / 2;

        // 중앙 요소가 target과 일치하면 인덱스를 반환한다
        if (nums[mid] == target) {
            return mid;
        }

        // 왼쪽 절반이 정렬되어 있는지 판정한다
        // 등호를 포함하는 이유는, left == mid(탐색 범위가 2개 이하)일 때 왼쪽 절반을 올바르게 정렬됨으로 판정하기 위해서이다
        if (nums[left] <= nums[mid]) {
            // target이 왼쪽 절반의 범위 안에 있는지 판정한다
            if (target >= nums[left] && target < nums[mid]) {
                right = mid - 1;  // target이 왼쪽 절반의 범위 안에 있으므로 왼쪽 절반으로 좁힌다
            } else {
                left = mid + 1;   // target이 왼쪽 절반의 범위 밖이므로 오른쪽 절반으로 좁힌다
            }
        // 오른쪽 절반이 정렬되어 있는 경우
        } else {
            // target이 오른쪽 절반의 범위 안에 있는지 판정한다
            if (target > nums[mid] && target <= nums[right]) {
                left = mid + 1;   // target이 오른쪽 절반의 범위 안에 있으므로 오른쪽 절반으로 좁힌다
            } else {
                right = mid - 1;  // target이 오른쪽 절반의 범위 밖이므로 왼쪽 절반으로 좁힌다
            }
        }
    }

    // 탐색 범위가 비었으므로 target은 배열에 존재하지 않는다
    return -1;
}
```
