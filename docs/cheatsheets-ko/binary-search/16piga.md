# Finding the Median of Two Sorted Arrays — 정렬된 두 배열을 병합했을 때의 중앙값을 구하기

## 문제의 본질

정렬된 두 정수 배열 `n1`과 `n2`가 주어진다. 두 배열을 병합했을 때의 **중앙값**을 구한다. 해법은 전체 요소 수에 대해 로그 시간으로 동작해야 한다.

## 핵심 아이디어

정렬된 두 배열의 중앙값을 구하는 것은 "왼쪽 절반"과 "오른쪽 절반"으로 올바르게 분할하는 경계를 찾는 것과 같다. 짧은 쪽 배열에 대해 이분 탐색을 수행하여 분할 위치를 정하면, 나머지 배열의 분할 위치도 자동으로 결정된다.

## 사고 프로세스

1. **중앙값은 "왼쪽 절반의 최댓값"과 "오른쪽 절반의 최솟값"으로 결정된다**: 병합 후 배열을 정렬된 상태로 좌우 이등분할 수 있으면, 중앙값은 왼쪽 절반의 최댓값(홀수 개일 때) 또는 왼쪽 절반의 최댓값과 오른쪽 절반의 최솟값의 평균(짝수 개일 때)으로 구할 수 있다. 즉, 전체 요소를 정렬하지 않아도 올바른 분할 위치만 찾으면 된다
2. **분할 위치는 한쪽 배열에서 정하면 나머지는 자동으로 결정된다**: 왼쪽 절반에 합계 `half = (m + n + 1) / 2`개의 요소를 넣기로 하면, 배열 `n1`에서 `cut1`개를 취하면 배열 `n2`에서는 `cut2 = half - cut1`개를 취해야 한다. 즉, `cut1`만 탐색하면 된다
3. **올바른 분할 조건은 "교차 비교"로 판정할 수 있다**: 올바른 분할이란 왼쪽 절반의 모든 요소가 오른쪽 절반의 모든 요소 이하인 것을 의미한다. 각 배열 내부는 정렬되어 있으므로, 교차하는 부분만 확인하면 된다. 구체적으로 `n1`의 왼쪽 끝 마지막 `l1` ≤ `n2`의 오른쪽 끝 첫 번째 `r2`, 그리고 `n2`의 왼쪽 끝 마지막 `l2` ≤ `n1`의 오른쪽 끝 첫 번째 `r1`이 성립하면 올바른 분할이다
4. **이분 탐색으로 `cut1`을 효율적으로 찾는다**: `cut1`의 범위는 `0`부터 `m`까지이다. `l1 > r2`이면 `n1`에서 너무 많이 취한 것이므로 `cut1`을 줄이고, `l2 > r1`이면 `n1`에서 너무 적게 취한 것이므로 `cut1`을 늘린다. 이 판정에 의해 이분 탐색이 성립한다
5. **짧은 쪽 배열에서 탐색하는 이유**: 이분 탐색의 범위는 `0`부터 `m`(배열의 길이)까지이므로, 짧은 쪽 배열을 선택하면 탐색 범위가 줄어들어 계산량이 `O(log(min(m, n)))`이 된다
6. **경계 처리에는 센티널 값을 사용한다**: `cut1 = 0`(`n1`에서 하나도 취하지 않음)이나 `cut1 = m`(`n1`을 전부 취함)일 때, 존재하지 않는 요소에 접근하게 된다. `Integer.MIN_VALUE`와 `Integer.MAX_VALUE`를 센티널 값으로 사용하면 비교 조건이 항상 올바르게 동작한다

## 전제 지식

### 중앙값(Median)이란

정렬된 수열에서 중앙에 위치하는 값이다. 요소 수가 홀수이면 중앙의 1개, 짝수이면 중앙 2개의 평균값을 취한다.

```java
// 홀수 개: [1, 3, 5] → 중앙값은 3
// 짝수 개: [1, 3, 5, 7] → 중앙값은 (3 + 5) / 2.0 = 4.0
```

### 이분 탐색(Binary Search)이란

정렬된 데이터에 대해 탐색 범위를 매번 절반으로 줄여 O(log n)으로 목표 값을 찾는 기법이다. `lo`와 `hi`로 탐색 범위를 관리하고, 중앙 값을 기준으로 범위를 좁혀 나간다.

```java
int lo = 0, hi = n;
while (lo <= hi) {
    int mid = (lo + hi) / 2;       // 탐색 범위의 중앙을 계산한다
    if (조건을 만족) { /* 답 */ }
    else if (mid가 너무 크다) { hi = mid - 1; }  // 왼쪽 절반으로 좁힌다
    else { lo = mid + 1; }                        // 오른쪽 절반으로 좁힌다
}
```

### 센티널 값(Sentinel Value)이란

배열의 경계 밖 접근을 방지하기 위해 사용하는 특별한 값이다. `Integer.MIN_VALUE`(정수의 최솟값)와 `Integer.MAX_VALUE`(정수의 최댓값)를 사용하여 비교 조건이 경계 케이스에서도 올바르게 작동하도록 한다.

```java
Integer.MIN_VALUE;  // -2147483648 — 어떤 요소보다도 작은 값으로 사용한다
Integer.MAX_VALUE;  //  2147483647 — 어떤 요소보다도 큰 값으로 사용한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(log(min(m, n))) — 짧은 쪽 배열에 대해 이분 탐색을 수행한다 |
| Space | O(1) — 변수만 사용하며, 추가 데이터 구조를 생성하지 않는다 |

## 코드

```java
// 입력: 정렬된 두 정수 배열 n1과 n2
// 출력: 두 배열을 병합했을 때의 중앙값을 double로 반환한다
public double findMedian(int[] n1, int[] n2) {
    // 짧은 쪽 배열에서 이분 탐색을 수행하기 위해, n1이 더 길면 교환하여 재귀 호출한다
    // 이렇게 하면 탐색 범위를 최소화하여 O(log(min(m, n)))을 실현한다
    if (n1.length > n2.length)
        return findMedian(n2, n1);

    int m = n1.length, n = n2.length;
    // 왼쪽 절반에 넣을 요소 수. +1을 하면 홀수일 때 왼쪽 절반이 1개 더 많아져서,
    // 왼쪽 절반의 최댓값이 그대로 중앙값이 된다
    int half = (m + n + 1) / 2;
    // cut1의 탐색 범위: 0(n1에서 하나도 취하지 않음) ~ m(n1을 전부 취함)
    int lo = 0, hi = m;

    while (lo <= hi) {
        // n1에서 왼쪽 절반에 넣을 개수를 이분 탐색의 중앙값으로 정한다
        int cut1 = (lo + hi) / 2;
        // n2에서 왼쪽 절반에 넣을 개수(왼쪽 절반의 합계가 half가 되도록 자동 결정)
        int cut2 = half - cut1;

        // n1의 왼쪽 절반의 마지막 값(cut1=0이면 왼쪽 절반이 비어 있으므로,
        // 어떤 요소보다도 작은 센티널 값을 사용하여 비교 조건을 항상 성립시킨다)
        int l1 = cut1 == 0 ?
            Integer.MIN_VALUE :
            n1[cut1 - 1];
        // n2의 왼쪽 절반의 마지막 값(cut2=0이면 왼쪽 절반이 비어 있으므로 센티널 값을 사용한다)
        int l2 = cut2 == 0 ?
            Integer.MIN_VALUE :
            n2[cut2 - 1];
        // n1의 오른쪽 절반의 첫 번째 값(cut1=m이면 오른쪽 절반이 비어 있으므로,
        // 어떤 요소보다도 큰 센티널 값을 사용하여 비교 조건을 항상 성립시킨다)
        int r1 = cut1 == m ?
            Integer.MAX_VALUE :
            n1[cut1];
        // n2의 오른쪽 절반의 첫 번째 값(cut2=n이면 오른쪽 절반이 비어 있으므로 센티널 값을 사용한다)
        int r2 = cut2 == n ?
            Integer.MAX_VALUE :
            n2[cut2];

        // 교차 비교: 왼쪽 절반의 모든 요소 ≤ 오른쪽 절반의 모든 요소이면 올바른 분할이다
        if (l1 <= r2 && l2 <= r1) {
            // 올바른 분할을 찾았다
            if ((m + n) % 2 == 1)
                // 홀수 개: 왼쪽 절반의 최댓값이 그대로 중앙값이다
                return Math.max(l1, l2);
            // 짝수 개: 왼쪽 절반의 최댓값과 오른쪽 절반의 최솟값의 평균이 중앙값이다
            return (Math.max(l1, l2)
                + Math.min(r1, r2))
                / 2.0;
        } else if (l1 > r2) {
            // n1의 왼쪽 절반 마지막 값이 n2의 오른쪽 절반 첫 번째 값을 초과한다 → n1에서 너무 많이 취했다 → cut1을 줄인다
            hi = cut1 - 1;
        } else {
            // l2 > r1: n1에서 너무 적게 취했다 → cut1을 늘린다
            lo = cut1 + 1;
        }
    }
    // 문제의 제약 조건상 올바른 분할은 반드시 존재하므로 여기에는 도달하지 않는다
    return -1;
}
```
