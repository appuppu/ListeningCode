# Removing the Nth Node From the End of a List — 리스트의 끝에서 N번째 노드를 삭제하기

## 문제의 본질

단방향 연결 리스트의 헤드 노드 `head`와 정수 `n`이 주어진다. 리스트의 **끝에서 N번째** 노드를 삭제하고, 변경된 리스트의 헤드 노드를 반환한다.

## 핵심 아이디어

두 개의 포인터를 N개 간격으로 벌려 놓고 동시에 전진시키면, 선행 포인터가 리스트 끝에 도달한 시점에 후행 포인터는 삭제 대상 노드의 바로 앞에 위치한다. 이를 통해 한 번의 순회로 삭제를 완료할 수 있다.

## 사고 과정

1. **끝에서 N번째를 특정하려면 리스트의 길이가 필요해 보인다**: 단순하게 생각하면, 먼저 리스트 전체를 순회하여 길이 L을 구하고, 다음으로 L-N번째 노드를 찾는 2회 순회가 필요하다. 하지만 두 개의 포인터를 사용하면 1회 순회로 해결할 수 있다
2. **N개 간격을 벌린 두 개의 포인터를 사용한다**: fast 포인터를 slow 포인터보다 N개 앞으로 전진시켜 둔다. 이 상태에서 둘을 동시에 하나씩 전진시키면, fast가 리스트 끝에 도달했을 때 slow는 끝에서 정확히 N+1번째 위치에 있다. 즉, slow는 삭제 대상의 **바로 앞** 노드를 가리키고 있다
3. **더미 노드를 선두에 추가하는 이유**: 삭제 대상이 리스트의 헤드 노드(head 자체)인 경우, "삭제 대상의 바로 앞 노드"가 존재하지 않는다. 더미 노드를 head 앞에 배치함으로써, 헤드 노드의 삭제도 다른 노드의 삭제와 동일한 로직으로 처리할 수 있다
4. **fast를 N개 앞으로 전진시킨다**: for 루프로 fast를 N번 전진시킨다. 이 시점에서 slow와 fast 사이에는 N개의 노드가 존재한다
5. **두 포인터를 동시에 전진시킨다**: `fast.next != null`인 동안, slow와 fast를 동시에 하나씩 전진시킨다. fast의 **다음**이 null이 된 시점에 루프를 빠져나온다. 이때 fast는 리스트의 마지막 노드를 가리키고, slow는 끝에서 N+1번째(삭제 대상의 바로 앞)를 가리키고 있다
6. **노드의 삭제와 리스트의 반환**: slow의 다음 노드가 삭제 대상이므로, `slow.next = slow.next.next`로 링크를 변경하여 삭제한다. 마지막으로 `dummy.next`를 반환한다. head를 직접 반환하지 않는 이유는, head가 삭제된 경우에 대응하기 위해서이다

## 사전 지식

### ListNode란

단방향 연결 리스트의 하나의 노드를 나타내는 클래스이다. 각 노드는 값 `val`과 다음 노드에 대한 참조 `next`를 갖는다. `next`가 null인 노드가 리스트의 끝이다.

```java
ListNode node = new ListNode(5);  // 값이 5인 노드를 생성하고, next는 null이다
node.next = new ListNode(10);     // node → 10 → null 리스트가 된다
```

### 더미 노드(Sentinel Node)란

리스트의 선두에 추가하는, 값을 갖지 않는 보초 노드이다. 헤드 노드를 삭제하는 경우에도 "삭제 대상 앞의 노드"가 반드시 존재하게 되어, 선두에 대한 특별 처리가 불필요해진다.

```java
ListNode dummy = new ListNode(0);  // 더미 노드를 생성한다
dummy.next = head;                 // 더미의 다음을 본래의 헤드로 설정한다
// 처리 후, dummy.next가 새로운 헤드 노드가 된다
```

### Two-Pointer(투 포인터) 기법이란

두 개의 포인터를 서로 다른 속도나 간격으로 이동시켜, 리스트의 특정 위치를 효율적으로 찾는 기법이다. 이 문제에서는 N개 간격을 벌린 두 개의 포인터를 같은 속도로 이동시켜, 끝에서 N번째 위치를 특정한다.

```java
ListNode slow = head;
ListNode fast = head;
// fast를 N개 앞으로 전진시킨 후, 둘을 동시에 전진시킨다
```

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(n) — 리스트를 한 번만 순회하면 된다 |
| Space | O(1) — 더미 노드와 두 개의 포인터만 사용한다 |

## 코드

```java
// 입력: 단방향 연결 리스트의 헤드 노드 head와 정수 n
// 출력: 끝에서 N번째 노드를 삭제한 후의 리스트의 헤드 노드 ListNode를 반환한다
public ListNode removeNthFromEnd(ListNode head, int n) {
    // 값이 0인 더미 노드를 선두에 추가한다
    // 더미 노드를 배치함으로써, 헤드 노드를 삭제할 때도 "삭제 대상의 바로 앞 노드"가 존재하게 된다
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // 두 포인터를 모두 더미 노드에서 시작한다
    // 더미 노드에서 시작함으로써, 최종적으로 slow가 삭제 대상의 바로 앞에 정확히 위치하게 된다
    ListNode slow = dummy;
    ListNode fast = dummy;

    // fast를 N개 앞으로 전진시켜, slow와의 사이에 N개 간격을 만든다
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }

    // 두 포인터를 동시에 전진시키고, fast가 리스트 끝에 도달하면 멈춘다
    // fast.next != null을 조건으로 하는 이유는, fast가 리스트의 마지막 노드에 도달한 시점에
    // slow가 삭제 대상의 바로 앞에 위치하도록 하기 위해서이다
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // slow.next가 삭제 대상 노드이다. slow의 다음 포인터를 한 칸 앞으로 변경하여, 삭제 대상을 리스트에서 분리한다
    slow.next = slow.next.next;

    // head가 아닌 dummy.next를 반환하는 이유는, head가 삭제 대상이었을 경우 새로운 헤드 노드를 정확히 반환하기 위해서이다
    return dummy.next;
}
```
