# Adding Two Numbers Represented as Linked Lists — 역순 연결 리스트로 표현된 두 수를 더하기

## 문제의 본질

두 개의 비어 있지 않은 연결 리스트가 주어진다. 각 연결 리스트는 비음수 정수를 **역순**(일의 자리가 맨 앞)으로 표현하며, 각 노드에는 한 자릿수의 숫자가 저장되어 있다. 두 수를 더하고, 그 합계를 마찬가지로 **역순 연결 리스트**로 반환한다.

## 핵심 아이디어

연결 리스트가 역순(일의 자리가 맨 앞)으로 저장되어 있으므로, 첫 번째 노드부터 순서대로 더하면 그대로 일의 자리→십의 자리→백의 자리… 순으로 필산과 같은 순서로 덧셈할 수 있다. 올림(carry)을 변수로 이월하면서, 각 자릿수의 결과를 새로운 노드로 연결해 나가면 된다.

## 사고 과정

1. **역순이라는 점이 장점이 된다**: 수의 덧셈은 일의 자리부터 수행한다. 연결 리스트가 역순이므로, 첫 번째 노드부터 순서대로 처리하면 자연스럽게 일의 자리부터 덧셈할 수 있다. 자릿수의 순서를 반전할 필요가 없다
2. **각 자릿수의 덧셈과 올림을 관리한다**: 각 자릿수에서 `l1의 값 + l2의 값 + carry`를 계산한다. 합계가 10 이상이면 올림이 발생한다. `sum % 10`이 해당 자릿수의 결과이고, `sum / 10`이 다음 자릿수로의 올림이 된다. 이것은 필산의 규칙 그 자체이다
3. **두 리스트의 길이가 다른 경우를 처리한다**: 한쪽 리스트가 먼저 끝나더라도, 나머지 리스트나 carry가 남아 있는 한 처리를 계속해야 한다. while 루프의 조건을 `l1 != null || l2 != null || carry != 0`으로 설정하면, 모든 경우를 통일적으로 처리할 수 있다
4. **더미 헤드로 결과 리스트의 구축을 간결하게 한다**: 결과 리스트의 첫 번째 노드를 특별 처리하지 않기 위해, 값이 0인 더미 노드를 맨 앞에 놓는다. 모든 자릿수의 결과를 `curr.next`에 추가해 나가고, 마지막에 `dummy.next`를 반환하면 올바른 결과 리스트를 얻을 수 있다
5. **루프 내의 처리를 통일한다**: 각 반복에서 `l1`과 `l2`가 null이 아니면 각각의 값을 sum에 더하고, 포인터를 다음으로 이동시킨다. null인 경우에는 아무것도 하지 않는다. 이 조건 분기를 통해, 리스트 길이의 차이를 자연스럽게 흡수할 수 있다
6. **최종적으로 반환하는 것**: 더미 헤드의 다음 노드 `dummy.next`가 결과 리스트의 맨 앞이다. 이것을 반환한다

## 사전 지식

### ListNode란

단방향 연결 리스트의 노드를 나타내는 클래스이다. 각 노드는 정수값 `val`과 다음 노드에 대한 참조 `next`를 가진다. `next`가 `null`인 노드가 리스트의 끝이다.

```java
public class ListNode {
    int val;              // 이 노드가 보유하는 한 자릿수의 숫자
    ListNode next;        // 다음 노드에 대한 참조 (끝이면 null)
    ListNode(int val) {   // 생성자: 값을 지정하여 노드를 생성한다
        this.val = val;
    }
}
```

### 더미 헤드(Dummy Head)란

리스트의 맨 앞에 놓는 값을 가지지 않는 더미 노드이다. 결과 리스트를 구축할 때, 첫 번째 노드를 특별 처리하지 않아도 되는 기법이다. 모든 노드를 `curr.next = new ListNode(...)`로 통일적으로 추가할 수 있으며, 마지막에 `dummy.next`를 반환함으로써 실제 첫 번째 노드를 얻을 수 있다.

```java
ListNode dummy = new ListNode(0);  // 더미 헤드를 생성한다
ListNode curr = dummy;             // curr는 리스트의 끝을 추적하는 포인터이다
curr.next = new ListNode(5);       // 더미 다음에 값 5의 노드를 추가한다
curr = curr.next;                  // curr를 끝으로 이동시킨다
// dummy.next가 실제 리스트의 맨 앞(값 5의 노드)을 가리킨다
```

### 올림(Carry)이란

한 자릿수끼리의 덧셈에서 합계가 10 이상이 되었을 때, 다음 자릿수로 이월하는 값이다. `sum / 10`으로 계산한다(정수 나눗셈이므로 0 또는 1이 된다). 현재 자릿수에 남는 값은 `sum % 10`으로 구한다.
예: 7 + 8 = 15일 때, carry = 15 / 10 = 1, 현재 자릿수의 값 = 15 % 10 = 5.

## 계산량

| | 값 |
|---|---|
| Time | O(max(n, m)) — 두 리스트 중 긴 쪽의 길이만큼 순회한다 |
| Space | O(max(n, m)) — 결과 리스트의 노드 수는 최대 max(n, m) + 1개가 된다 |

## 코드

```java
// 입력: 역순 연결 리스트 l1과 l2 (각 노드는 한 자릿수의 비음수 정수)
// 출력: 두 수의 합계를 역순 연결 리스트로 반환한다
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    // 더미 헤드를 생성한다. 결과 리스트의 첫 번째 노드를 특별 처리하지 않아도 된다
    // 최종 결과에는 포함되지 않으며, dummy.next가 실제 맨 앞이 된다
    ListNode dummy = new ListNode(0);
    // curr는 결과 리스트의 끝을 추적하는 포인터이다
    ListNode curr = dummy;
    // 올림을 보유하는 변수이다. 각 자릿수의 덧셈 결과가 10 이상일 때, 다음 자릿수로 이월하는 값(0 또는 1)이다
    int carry = 0;

    // 어느 쪽이든 리스트가 남아 있거나, 올림이 있는 한 루프를 계속한다
    // carry != 0 조건에 의해, 999 + 1 = 1000처럼 자릿수가 늘어나는 경우에도 대응한다
    while (l1 != null || l2 != null || carry != 0) {
        // 이전 자릿수에서의 올림을 초기값으로 하여 sum을 계산한다
        int sum = carry;

        // l1이 남아 있으면 값을 더하고, 포인터를 다음으로 이동시킨다
        // null인 경우에는 아무것도 하지 않는다. 이로써 l1이 먼저 끝나더라도 처리가 계속된다
        if (l1 != null) {
            sum += l1.val;
            l1 = l1.next;
        }

        // l2가 남아 있으면 값을 더하고, 포인터를 다음으로 이동시킨다
        // null인 경우에는 아무것도 하지 않는다. 이로써 l2가 먼저 끝나더라도 처리가 계속된다
        if (l2 != null) {
            sum += l2.val;
            l2 = l2.next;
        }

        // 올림을 계산한다. sum이 10 이상이면 1, 10 미만이면 0이 된다
        carry = sum / 10;
        // 현재 자릿수의 값(sum % 10)으로 새로운 노드를 생성하고, 결과 리스트의 끝에 연결한다
        curr.next = new ListNode(sum % 10);
        // curr를 끝으로 이동시켜, 다음 반복에서 새로운 노드를 추가할 수 있도록 한다
        curr = curr.next;
    }

    // 더미 헤드의 다음이 결과 리스트의 맨 앞이다
    return dummy.next;
}
```
