# Detecting a Cycle in a Linked List — 연결 리스트에 사이클이 존재하는지 판정하기

## 문제의 본질

단방향 연결 리스트의 첫 번째 노드 `head`가 주어진다. 리스트 내 어떤 노드의 `next` 포인터가 이전에 방문한 노드를 가리키고 있으면(사이클이 존재하면) `true`를 반환하고, 사이클이 존재하지 않으면 `false`를 반환한다.

## 핵심 아이디어

속도가 다른 두 개의 포인터를 동시에 이동시키면, 사이클이 있을 경우 반드시 따라잡아 합류하게 된다. 사이클이 없으면 빠른 포인터가 먼저 끝에 도달한다. 이 성질을 이용하면 추가 데이터 구조 없이 사이클을 검출할 수 있다.

## 사고 프로세스

1. **사이클의 본질을 생각한다**: 사이클이 있는 리스트를 순회하면 끝(null)에 도달하지 못하고 영원히 루프를 반복한다. 반대로 사이클이 없으면 반드시 null에 도달하여 순회가 종료된다
2. **속도 차이가 있는 포인터를 사용한다**: 1스텝씩 진행하는 포인터(slow)와 2스텝씩 진행하는 포인터(fast)를 준비한다. 사이클 내에서 fast는 slow에 대해 매 스텝마다 1노드씩 거리를 줄이므로 반드시 합류한다
3. **합류가 사이클의 증거가 되는 이유**: 사이클이 없으면 fast가 먼저 null에 도달하므로 slow와 fast가 같은 노드를 가리키는 일은 발생할 수 없다. 합류가 발생했다 = 사이클이 존재한다
4. **종료 조건을 정한다**: fast 또는 fast.next가 null이 되면 리스트에 끝이 존재하므로 사이클이 없다. slow와 fast가 같은 노드를 가리키면 사이클이 존재한다
5. **초기 위치를 설정한다**: slow를 head에, fast를 head.next에 배치한다. 이렇게 하면 while 루프의 조건 `slow != fast`가 처음부터 성립하여 루프 안에서 순회를 시작할 수 있다
6. **최종적으로 반환할 값**: slow와 fast가 합류하면 `true`를, fast가 null에 도달하면 `false`를 반환한다

## 사전 지식

### ListNode(연결 리스트의 노드)란

연결 리스트를 구성하는 개별 요소이다. 각 노드는 "값"과 "다음 노드를 가리키는 포인터"를 가진다. 마지막 노드의 next는 null을 가리킨다(사이클이 없는 경우).

```java
class ListNode {
    int val;            // 노드가 보유하는 값
    ListNode next;      // 다음 노드에 대한 참조 (없으면 null)
}

ListNode node = head;       // 첫 번째 노드를 가져온다
node.next;                  // 다음 노드를 가져온다
node.next.next;             // 두 칸 뒤의 노드를 가져온다
```

### Floyd's Tortoise and Hare(플로이드의 순환 검출법)란

속도가 다른 두 개의 포인터를 사용하여 사이클을 검출하는 알고리즘이다. slow 포인터는 1스텝씩, fast 포인터는 2스텝씩 진행한다. 사이클 내에서 fast는 slow에 매 스텝마다 1노드씩 가까워지므로, 사이클이 존재하면 유한 스텝 안에 반드시 합류한다.

```java
ListNode slow = head;       // 1스텝씩 진행하는 포인터
ListNode fast = head.next;  // 2스텝씩 진행하는 포인터
slow = slow.next;           // slow를 1칸 진행시킨다
fast = fast.next.next;      // fast를 2칸 진행시킨다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 사이클이 없는 경우 fast가 n/2스텝만에 끝에 도달하고, 사이클이 있는 경우에도 사이클 길이 이내에 합류한다 |
| Space | O(1) — 두 개의 포인터 변수만 사용하며, 추가 데이터 구조를 필요로 하지 않는다 |

## 코드

```java
// 입력: 단방향 연결 리스트의 첫 번째 노드 head
// 출력: 사이클이 존재하면 true, 존재하지 않으면 false를 반환한다
public boolean hasCycle(ListNode head) {
    // 노드가 0개 또는 1개이면 사이클은 존재할 수 없다. false를 반환하고 종료한다
    if (head == null || head.next == null) {
        return false;
    }

    // slow를 head에, fast를 head.next에 배치한다
    // fast를 1칸 앞에 두어 while의 조건 slow != fast가 처음부터 성립하여 루프에 진입할 수 있도록 한다
    ListNode slow = head;
    ListNode fast = head.next;

    // slow와 fast가 합류할 때까지 루프를 반복한다 (합류하면 종료)
    while (slow != fast) {
        // fast가 null이거나 fast.next가 null이면 리스트에 끝이 존재하므로 사이클이 없다
        if (fast == null || fast.next == null) {
            return false;
        }
        // slow를 1스텝, fast를 2스텝 진행시킨다
        // 속도 차이로 인해 사이클 내에서 fast는 slow에 매 스텝마다 1노드씩 가까워진다
        slow = slow.next;
        fast = fast.next.next;
    }

    // while의 조건 slow != fast가 거짓이 되었다 = slow와 fast가 합류했으므로 사이클이 존재한다
    return true;
}
```
