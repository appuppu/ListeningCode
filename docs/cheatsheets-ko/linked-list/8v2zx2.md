# Merging Two Sorted Linked Lists — 정렬된 두 연결 리스트를 하나로 병합하기

## 문제의 본질

정렬된 두 연결 리스트 `list1`과 `list2`가 주어진다. 이 두 리스트를 하나의 정렬된 연결 리스트로 병합하고, 병합된 리스트의 **첫 번째 노드**를 반환한다.

## 핵심 아이디어

두 리스트의 첫 번째 노드를 비교하여 더 작은 쪽을 병합 결과의 첫 번째 노드로 선택한다. 나머지 부분은 "더 작은 쪽의 다음 노드"와 "다른 쪽 리스트"를 병합한 결과이며, 이는 원래 문제와 동일한 구조이므로 재귀로 풀 수 있다.

## 사고 과정

1. **병합의 각 단계에서 수행하는 작업은 동일하다**: 두 리스트의 첫 번째 노드를 비교하여 더 작은 쪽을 선택한다. 이 연산은 리스트가 비워질 때까지 반복된다. 매번 동일한 판단을 수행하므로 재귀로 표현할 수 있다
2. **베이스 케이스를 생각한다**: 한쪽 리스트가 비어 있으면(null) 다른 쪽 리스트를 그대로 반환하면 된다. 양쪽 모두 비어 있으면 null을 반환한다(한쪽이 null인 케이스에 포함된다)
3. **재귀 단계를 생각한다**: `list1.val <= list2.val`이면 `list1`이 첫 번째 노드가 된다. `list1.next`에는 "`list1`의 나머지"와 "`list2` 전체"를 병합한 결과를 연결한다. 반대의 경우에는 `list2`를 첫 번째 노드로 선택하여 동일하게 처리한다
4. **각 재귀 호출에서 문제 크기가 1씩 줄어든다**: 매번 어느 한쪽 리스트에서 노드 1개를 소비하므로, 총 n번의 재귀로 모든 노드가 처리된다
5. **최종적으로 반환하는 것**: 각 재귀 호출은 선택한 노드(`list1` 또는 `list2`)를 반환한다. 첫 번째 호출이 반환하는 노드가 병합된 리스트의 첫 번째 노드가 된다

## 사전 지식

### ListNode(연결 리스트의 노드)란

연결 리스트의 각 요소를 나타내는 클래스이다. `val` 필드에 값을, `next` 필드에 다음 노드에 대한 참조를 저장한다. `next`가 null인 노드가 리스트의 마지막 노드이다.

```java
class ListNode {
    int val;          // 노드가 저장하는 값
    ListNode next;    // 다음 노드에 대한 참조 (마지막 노드이면 null)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### 재귀(Recursion)란

함수가 자기 자신을 호출하여 문제를 푸는 기법이다. 큰 문제를 동일한 구조의 작은 문제로 분해하고, 베이스 케이스(더 이상 분해할 수 없는 가장 작은 문제)에 도달하면 결과를 반환한다. 호출할 때마다 콜 스택에 프레임이 쌓이므로, 재귀 깊이만큼의 공간을 소비한다.

```java
// 예: 팩토리얼 계산
int factorial(int n) {
    if (n <= 1) return 1;           // 베이스 케이스: 더 이상 분해하지 않는다
    return n * factorial(n - 1);    // 재귀 단계: 문제 크기를 1 줄여 자기 자신을 호출한다
}
```

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(n) — 두 리스트의 총 노드 수 n번의 재귀 호출로 모든 노드를 처리한다 |
| Space | O(n) — 재귀 호출할 때마다 콜 스택에 프레임이 쌓이며, 최대 n단의 깊이가 된다 |

## 코드

```java
// 입력: 정렬된 두 연결 리스트의 첫 번째 노드 list1과 list2
// 출력: 병합된 정렬 연결 리스트의 첫 번째 노드를 ListNode로 반환한다
ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    // 베이스 케이스: list1이 비어 있으면 나머지 list2를 그대로 반환한다 (list1이 비어 있으므로 list2가 그대로 병합 결과가 된다)
    if (list1 == null) return list2;
    // 베이스 케이스: list2가 비어 있으면 나머지 list1을 그대로 반환한다 (list2가 비어 있으므로 list1이 그대로 병합 결과가 된다)
    if (list2 == null) return list1;

    // list1의 첫 번째 노드와 list2의 첫 번째 노드를 비교하여 병합 결과의 첫 번째 노드로 어느 쪽을 선택할지 결정한다
    if (list1.val <= list2.val) {
        // list1을 첫 번째 노드로 선택하고, list1의 나머지(list1.next)와 list2 전체를 병합한 결과를 list1의 다음에 연결한다
        list1.next = mergeTwoLists(list1.next, list2);
        return list1; // list1이 병합 결과의 첫 번째 노드가 된다
    } else {
        // list2를 첫 번째 노드로 선택하고, list1 전체와 list2의 나머지(list2.next)를 병합한 결과를 list2의 다음에 연결한다
        list2.next = mergeTwoLists(list1, list2.next);
        return list2; // list2가 병합 결과의 첫 번째 노드가 된다
    }
}
```
