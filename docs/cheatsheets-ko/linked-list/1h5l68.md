# Reversing Nodes in Groups of K — 연결 리스트를 K개씩 그룹으로 나누어 각 그룹을 반전하기

## 문제의 본질

단방향 연결 리스트의 헤드 노드 `head`와 정수 `k`가 주어진다. 리스트를 처음부터 `k`개씩 그룹으로 나누고, 각 그룹 내 노드의 순서를 반전한다. 마지막 그룹이 `k`개 미만인 경우에는 해당 그룹을 그대로 유지한다. 변경된 리스트의 헤드 노드를 반환한다.

## 핵심 아이디어

더미 노드를 맨 앞에 배치하고, 「그룹 직전 노드」와 「그룹의 k번째 노드」를 기준점으로 삼아 각 그룹 내의 포인터를 하나씩 교체함으로써 추가 메모리 없이 제자리에서 반전할 수 있다.

## 사고 과정

1. **그룹 단위로 반전해야 한다**: 리스트 전체가 아니라 k개씩 그룹별로 반전한다. 즉, 「현재 그룹의 범위를 특정한다」→「해당 그룹을 반전한다」→「다음 그룹으로 진행한다」라는 루프 구조가 된다
2. **그룹의 범위를 특정하려면 k번째 노드를 찾아야 한다**: 현재 위치에서 k개 앞의 노드를 찾는 보조 함수 `getKth`를 준비한다. k번째 노드가 존재하지 않으면(`null`), 나머지가 k개 미만이므로 반전하지 않고 종료한다
3. **반전 후 그룹끼리 올바르게 연결해야 한다**: 그룹을 반전하면 그룹의 앞과 뒤가 바뀐다. 이전 그룹의 끝(`groupPrev`)이 반전 후의 새로운 앞(원래의 k번째 노드)을 가리키도록 다시 연결해야 한다
4. **더미 노드로 첫 번째 그룹의 반전을 통일적으로 처리한다**: 첫 번째 그룹을 반전하면 리스트의 헤드 노드 자체가 바뀐다. 더미 노드를 맨 앞에 배치함으로써 「그룹 직전 노드가 새로운 앞을 가리킨다」라는 연산을 첫 번째 그룹에서도 이후 그룹에서도 동일한 로직으로 처리할 수 있다
5. **각 그룹의 반전은 표준적인 리스트 반전과 동일한 기법으로 수행한다**: `prev`와 `curr` 두 개의 포인터를 사용하여 `curr.next`를 `prev`로 교체하면서 노드를 하나씩 진행한다. 단, `prev`의 초기값을 그룹의 다음 노드(`groupNext`)로 설정함으로써 반전 후의 끝이 다음 그룹과 자동으로 연결된다
6. **반전 후 groupPrev를 갱신하고 다음 그룹으로 진행한다**: 반전 전 그룹의 첫 번째 노드(`groupPrev.next`)는 반전 후에 그룹의 끝이 된다. 이 노드를 다음 그룹의 `groupPrev`로 사용하여 다음 이터레이션으로 진행한다

## 전제 지식

### ListNode란

단방향 연결 리스트의 하나의 노드를 나타내는 클래스이다. 각 노드는 「값(val)」과 「다음 노드를 가리키는 포인터(next)」를 가진다. `next`가 `null`인 노드가 리스트의 끝이다.

```java
class ListNode {
    int val;          // 노드가 보유하는 값
    ListNode next;    // 다음 노드에 대한 참조 (끝이면 null)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### 더미 노드(Dummy Node)란

리스트의 맨 앞에 가상의 노드를 추가하는 기법이다. 헤드 노드가 변경되는 경우에 조건 분기를 불필요하게 만든다. `dummy.next`가 항상 리스트의 실제 헤드를 가리킨다.

```java
ListNode dummy = new ListNode(0);  // 값은 아무 것이나 상관없다
dummy.next = head;                 // 더미의 다음이 실제 헤드이다
// ... 리스트를 조작한다 ...
return dummy.next;                 // 조작 후의 실제 헤드를 반환한다
```

### 연결 리스트 반전의 기본 연산

`prev`와 `curr` 두 개의 포인터를 사용하여 각 노드의 `next`를 이전 노드로 교체해 나간다.

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode tmp = curr.next;  // 다음 노드를 임시 저장한다
    curr.next = prev;          // 현재 노드의 다음을 이전 노드로 변경한다
    prev = curr;               // prev를 현재 노드로 진행시킨다
    curr = tmp;                // curr를 다음 노드로 진행시킨다
}
// prev가 반전 후의 헤드 노드가 된다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 각 노드를 상수 회만 방문한다 (k번째 탐색에서 1회, 반전에서 1회) |
| Space | O(1) — 포인터 변수만 사용하며, 추가적인 데이터 구조는 불필요하다 |

## 코드

```java
// 입력: 연결 리스트의 헤드 노드 head와 정수 k
// 출력: k개씩 그룹을 반전한 연결 리스트의 헤드 노드를 반환한다
public ListNode reverseKGroup(ListNode head, int k) {
    // 더미 노드를 생성하고, dummy.next = head로 실제 리스트의 헤드에 연결한다
    // 더미 노드를 사용함으로써 첫 번째 그룹의 반전에서도 「그룹 직전 노드」가 항상 존재한다
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // groupPrev는 「지금부터 반전할 그룹의 직전 노드」를 가리킨다
    // 초기값은 더미 노드이다
    ListNode groupPrev = dummy;

    // 무한 루프로 각 이터레이션마다 하나의 그룹을 반전한다
    while (true) {
        // groupPrev의 한 칸 다음 노드에서 출발하여 k-1회 next를 따라가 k번째 노드를 찾는다
        // 도중에 null에 도달한 경우 나머지가 k개 미만이므로 null을 반환한다
        ListNode kth = getKth(groupPrev, k);

        // k번째가 존재하지 않으면 나머지가 k개 미만이므로 그대로 종료한다
        // k개 미만의 그룹은 그대로 유지한다는 문제의 요건을 이 판정으로 충족한다
        if (kth == null) break;

        // groupNext는 「현재 그룹 직후의 노드」로, 반전의 종단 표지로 사용한다
        ListNode groupNext = kth.next;

        // prev의 초기값을 groupNext로 설정한다
        // 이렇게 하면 반전 후 그룹 끝 노드의 next가 자동으로 다음 그룹의 앞을 가리킨다
        ListNode prev = kth.next;
        // curr는 그룹의 첫 번째 노드에서 시작한다 (반전 후에는 그룹의 끝이 되는 노드이다)
        ListNode curr = groupPrev.next;

        // curr가 groupNext와 같아질 때까지 그룹 내 각 노드의 next 포인터를 반전한다
        // 이 연산에 의해 각 노드의 next가 하나 앞의 노드를 가리키도록 변경된다
        while (curr != groupNext) {
            ListNode tmp = curr.next;  // 다음 노드를 임시 저장한다
            curr.next = prev;          // 현재 노드의 다음을 이전 노드로 변경한다
            prev = curr;               // prev를 현재 노드로 진행시킨다
            curr = tmp;                // curr를 다음 노드로 진행시킨다
        }

        // 반전 전의 첫 번째 노드를 저장한다 (반전 후에는 그룹의 끝이 되어 있다)
        ListNode tmp = groupPrev.next;
        // 반전 후의 그룹 앞은 kth(원래의 k번째 노드)이므로,
        // 이전 그룹의 끝이 반전 후의 새로운 앞을 올바르게 가리키도록 연결한다
        groupPrev.next = kth;
        // 반전 전에 그룹의 앞이었던 노드는 반전 후에 그룹의 끝이 되어 있다
        // 이 노드를 다음 이터레이션의 groupPrev로 사용한다
        groupPrev = tmp;
    }

    // dummy.next는 조작 후 리스트 전체의 헤드 노드를 가리키고 있다
    return dummy.next;
}

// node의 다음 노드부터 k번째 노드를 반환한다. k개 미만이면 null을 반환한다
private ListNode getKth(ListNode node, int k) {
    // node의 한 칸 다음에서 출발한다
    node = node.next;
    // k-1회 next를 따라가 k번째에 도달한다
    // 도중에 null에 도달한 경우 나머지 노드가 k개 미만이다
    while (node != null && k > 1) {
        node = node.next;
        k--;
    }
    // k번째 노드를 반환한다 (k개 미만이었을 경우 null)
    return node;
}
```
