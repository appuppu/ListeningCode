# Reversing a Linked List — 단방향 연결 리스트를 역순으로 만들기

## 문제의 본질

단방향 연결 리스트(singly linked list)의 첫 번째 노드 `head`가 주어진다. 리스트 내의 모든 링크(포인터)의 방향을 반전시켜, 원래의 마지막 노드가 새로운 첫 번째 노드가 되도록 한 뒤, 그 새로운 첫 번째 노드를 반환한다.

## 핵심 아이디어

각 노드의 `next` 포인터를 "다음 노드"에서 "이전 노드"로 교체하면, 리스트 전체가 역순이 된다. 3개의 포인터(prev, curr, next)를 사용하여 링크를 하나씩 안전하게 교체하면서 1회 순회하는 것만으로 완료된다.

## 사고 프로세스

1. **역순이란 링크의 방향을 반전시키는 것이다**: 연결 리스트의 순서는 노드의 `next` 포인터가 결정한다. 모든 노드의 `next`를 "다음 노드"에서 "이전 노드"로 변경하면, 리스트 전체가 역순이 된다
2. **링크를 교체하면 다음 노드에 대한 참조가 사라진다**: `curr.next = prev`로 덮어쓰는 순간, 원래의 다음 노드에 대한 참조가 사라진다. 따라서 덮어쓰기 전에 `curr.next`를 별도의 변수 `next`에 백업해 두어야 한다
3. **3개의 포인터로 상태를 관리한다**: `prev`(교체 대상이 되는 이전 노드), `curr`(현재 처리 중인 노드), `next`(원래의 다음 노드 백업)의 3개가 있으면, 링크 교체와 순회를 동시에 수행할 수 있다
4. **초기 상태를 결정한다**: 역순 후의 마지막 노드(원래의 첫 번째 노드)의 `next`는 `null`이 되어야 하므로, `prev`의 초기값은 `null`로 설정한다. `curr`의 초기값은 `head`(첫 번째 노드)로 설정한다
5. **루프의 종료 조건과 반환값**: `curr`이 `null`이 되었을 때, 모든 노드의 처리가 완료된 것이다. 이때 `prev`는 마지막으로 처리한 노드(원래의 마지막 노드)를 가리키고 있으므로, `prev`를 새로운 첫 번째 노드로 반환한다

## 사전 지식

### ListNode(연결 리스트의 노드)란

연결 리스트를 구성하는 요소이다. 각 노드는 "값(val)"과 "다음 노드에 대한 포인터(next)"를 가진다. 마지막 노드의 `next`는 `null`이다.

```java
class ListNode {
    int val;          // 노드가 보유하는 값
    ListNode next;    // 다음 노드에 대한 참조 (마지막이면 null)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### 포인터 교체란

노드의 `next` 필드에 다른 노드를 대입함으로써, 링크의 방향을 변경하는 것이다.

```java
// 원래 상태: A → B → C
// A.next는 B를 가리키고 있다

A.next = null;   // A → null (A와 B 사이의 링크가 끊어진다)
B.next = A;      // B → A (B에서 A로의 역방향 링크가 생성된다)
// 결과: C → null, B → A → null
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 리스트를 1회 순회하는 것만으로 충분하다 |
| Space | O(1) — 3개의 포인터 변수만 사용하며, 추가적인 데이터 구조는 불필요하다 |

## 코드

```java
// 입력: 단방향 연결 리스트의 첫 번째 노드 head
// 출력: 역순으로 만든 리스트의 새로운 첫 번째 노드(ListNode)를 반환한다
ListNode reverseList(ListNode head) {
    // prev: 링크 교체 대상 (역순 후의 "이전 노드")
    // 첫 번째 노드(원래의 첫 번째)는 역순 후에 마지막이 되므로, 그 next는 null이어야 한다. 따라서 초기값은 null이다
    ListNode prev = null;
    // curr: 지금부터 링크를 교체할 노드. 첫 번째 노드부터 처리를 시작한다
    ListNode curr = head;

    // curr이 null이 되었을 때, 모든 노드의 처리가 완료된 것이다
    while (curr != null) {
        // 원래의 다음 노드를 백업한다 (다음 단계에서 curr.next를 덮어쓰므로, 참조를 잃지 않도록 저장한다)
        ListNode next = curr.next;

        // 링크를 반전시킨다: 다음 노드가 아닌 이전 노드를 가리키도록 한다. 이것이 반전 연산의 핵심이다
        curr.next = prev;

        // prev를 현재 노드로 전진시킨다 (다음 반복에서, 다음 노드의 링크 교체 대상으로 사용한다)
        prev = curr;
        // curr을 백업해 둔 원래의 다음 노드로 전진시킨다 (이를 통해 리스트의 순회가 계속된다)
        curr = next;
    }

    // 루프의 마지막 반복에서 prev에는 마지막으로 처리한 노드(원래의 마지막 노드)가 대입되어 있다
    // 이것이 역순 리스트의 새로운 첫 번째 노드이다
    return prev;
}
```
