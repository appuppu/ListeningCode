# Reordering a Linked List by Interleaving Ends — 연결 리스트의 양쪽 끝을 교대로 재배치하기

## 문제의 본질

단방향 연결 리스트 L0 → L1 → … → Ln-1 → Ln이 주어진다. 이 리스트를 L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → … 순서로 **제자리에서(in-place)** 재배치한다. 노드의 값을 변경하지 않고, 노드의 링크(next 포인터)만을 조작하여 구현한다.

## 핵심 아이디어

리스트의 후반부를 역순으로 뒤집으면, "전반부의 처음부터"와 "후반부의 처음(원래의 끝)부터"를 교대로 연결하는 것만으로 목적하는 순서가 된다. 후반부를 역순으로 뒤집기 위해, 먼저 리스트의 중간점을 찾아 전반부와 후반부로 분할한다.

## 사고 과정

1. **재배치 후의 구조를 관찰한다**: L0 → Ln → L1 → Ln-1 → … 라는 순서는 리스트의 "앞쪽"과 "뒤쪽"에서 교대로 요소를 꺼낸 결과이다. 즉, 앞쪽과 뒤쪽의 두 열을 교대로 병합하면 된다
2. **뒤쪽에서 요소를 꺼내려면 역순이 필요하다**: 단방향 연결 리스트에서는 끝에 접근하는 데 O(n)이 걸린다. 그러나 리스트의 후반부를 뒤집으면, 후반부의 처음이 원래의 끝이 되어, 처음부터 순서대로 따라가는 것만으로 뒤쪽의 요소를 가져올 수 있다
3. **리스트의 중간점을 찾는다**: 후반부를 뒤집기 위해서는, 먼저 리스트를 어디에서 분할할지 결정해야 한다. slow/fast 포인터(거북이와 토끼)를 사용하면, 한 번의 순회로 중간점을 찾을 수 있다. slow는 한 칸씩, fast는 두 칸씩 전진하며, fast가 리스트 끝에 도달한 시점에서 slow가 중간점을 가리키고 있다
4. **후반부를 뒤집는다**: 중간점의 다음 노드부터 시작하여, 각 노드의 next 포인터를 이전 노드를 향하도록 변경함으로써, 후반부 리스트를 역순으로 만든다. prev 변수로 직전 노드를 추적하며, 루프 완료 후의 prev가 뒤집힌 후의 처음이 된다
5. **전반부와 뒤집힌 후반부를 교대로 병합한다**: 전반부 리스트와 후반부 리스트를 각각 처음부터 순회하며, 전반부 노드의 다음에 후반부 노드를 삽입한다. 각 단계에서 next 포인터를 교체하므로, 원래의 링크를 임시 변수에 저장한 후 덮어쓴다
6. **후반부는 전반부보다 짧거나 같은 길이이다**: 홀수 길이의 리스트에서는 전반부가 1개 더 길어지므로, 병합의 루프 조건은 `second != null`로 한다. 후반부의 노드가 없어진 시점에서 병합이 완료된다

## 전제 지식

### slow/fast 포인터(거북이와 토끼 기법)란

연결 리스트의 중간점을 한 번의 순회로 찾는 기법이다. slow는 한 노드씩, fast는 두 노드씩 전진한다. fast가 리스트 끝에 도달한 시점에서, slow는 리스트의 중간점을 가리키고 있다.

```java
ListNode slow = head, fast = head;
while (fast.next != null && fast.next.next != null) {
    slow = slow.next;        // slow는 한 칸 전진한다
    fast = fast.next.next;   // fast는 두 칸 전진한다
}
// 루프 종료 시, slow가 리스트의 중간 노드를 가리킨다
```

### 연결 리스트의 뒤집기란

각 노드의 next 포인터를, 다음 노드가 아닌 이전 노드를 향하도록 변경하는 조작이다. prev(직전 노드)를 추적하면서 한 노드씩 전진하며, 링크의 방향을 반전시킨다.

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode nxt = curr.next;  // 다음 노드를 저장한다
    curr.next = prev;          // 링크를 이전 노드를 향하도록 변경한다
    prev = curr;               // prev를 현재 노드로 갱신한다
    curr = nxt;                // 다음 노드로 전진한다
}
// 루프 종료 시, prev가 뒤집힌 리스트의 처음을 가리킨다
```

### 두 리스트의 교대 병합이란

두 리스트의 요소를 교대로 하나씩 꺼내어, 하나의 리스트로 연결하는 조작이다. 각 단계에서 next 포인터를 교체하므로, 원래의 링크를 임시 변수에 저장한 후 덮어쓴다.

```java
ListNode a = list1, b = list2;
while (b != null) {
    ListNode tmpA = a.next;   // a의 원래 다음을 저장한다
    ListNode tmpB = b.next;   // b의 원래 다음을 저장한다
    a.next = b;               // a의 다음에 b를 삽입한다
    b.next = tmpA;            // b의 다음에 a의 원래 다음을 연결한다
    a = tmpA;                 // a를 다음 위치로 전진시킨다
    b = tmpB;                 // b를 다음 위치로 전진시킨다
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 중간점 탐색, 후반부 뒤집기, 병합의 각 단계가 각각 O(n)이다 |
| Space | O(1) — 포인터 변수만을 사용하며, 추가적인 데이터 구조를 생성하지 않는다 |

## 코드

```java
// 입력: 단방향 연결 리스트의 처음 노드 head
// 출력: 없음 (리스트를 제자리에서 재배치한다. 반환값은 void이다)
void reorderList(ListNode head) {
    // 빈 리스트에는 재배치가 필요하지 않다
    if (head == null) return;

    // 단계 1: slow/fast 포인터로 리스트의 중간점을 찾는다
    // fast는 slow의 2배 속도로 전진하므로, fast가 끝에 도달한 시점에서 slow가 중간 노드를 가리킨다
    ListNode slow = head, fast = head;
    while (fast.next != null
            && fast.next.next != null) {
        slow = slow.next;          // slow는 한 칸 전진한다
        fast = fast.next.next;     // fast는 두 칸 전진한다
    }

    // 단계 2: 후반부 리스트를 분리하여 뒤집는다
    ListNode second = slow.next;   // second는 후반부 리스트의 처음 노드이다
    slow.next = null;              // 전반부 리스트의 끝을 잘라내어, 전반부와 후반부 두 개로 분할한다
    ListNode prev = null;
    while (second != null) {
        ListNode nxt = second.next;  // 다음 노드를 저장한다
        second.next = prev;          // 링크를 이전 노드를 향하도록 변경한다
        prev = second;               // prev를 현재 노드로 갱신한다
        second = nxt;                // 다음 노드로 전진한다
    }
    // 루프 종료 시, prev가 뒤집힌 후반부 리스트의 처음(원래 리스트의 끝)을 가리킨다

    // 단계 3: 전반부와 뒤집힌 후반부를 교대로 병합한다
    ListNode first = head;         // 전반부 리스트의 처음
    second = prev;                 // 뒤집힌 후반부 리스트의 처음
    // 홀수 길이의 리스트에서는 전반부가 1개 더 길어지므로, 후반부(second)가 없어지면 종료한다
    while (second != null) {
        ListNode tmp1 = first.next;   // 전반부의 다음 노드를 저장한다 (저장하지 않으면 next 덮어쓰기로 원래의 링크 대상이 사라진다)
        ListNode tmp2 = second.next;  // 후반부의 다음 노드를 저장한다
        first.next = second;          // 전반부의 다음에 후반부의 노드를 삽입한다
        second.next = tmp1;           // 후반부 노드의 다음에 전반부의 나머지를 연결한다
        first = tmp1;                 // 전반부의 포인터를 다음 위치로 전진시킨다
        second = tmp2;                // 후반부의 포인터를 다음 위치로 전진시킨다
    }
}
```
