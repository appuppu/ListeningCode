# Finding the Duplicate in an Array of N Plus One Integers — N+1개의 정수 배열에서 중복되는 하나의 수를 찾기

## 문제의 본질

길이 n+1인 정수 배열 `nums`가 주어진다. 각 요소는 1부터 n 범위 내에 있으며, 반드시 하나의 중복되는 수가 존재한다. 배열을 변경하지 않고, 상수 크기의 추가 공간만 사용하여 그 중복되는 수를 찾아서 반환한다.

## 핵심 아이디어

배열의 각 인덱스 `i`에서 `nums[i]`로 이동하는 관계를 "연결 리스트"로 간주하면, 중복되는 수가 존재하는 지점에서 링크가 합류하여 사이클(순환)이 발생한다. Floyd's Cycle Detection(거북이와 토끼 알고리즘)을 사용하면, 그 사이클의 입구 = 중복되는 수를 O(1) 공간으로 특정할 수 있다.

## 사고 프로세스

1. **배열을 암묵적인 연결 리스트로 파악한다**: 인덱스 `i`에 있는 값 `nums[i]`를 "다음 노드로의 포인터"로 간주한다. 인덱스 0에서 출발하여 `nums[0]` → `nums[nums[0]]` → … 로 순회하면, 연결 리스트의 탐색과 동일한 동작이 된다. 값의 범위가 1~n이므로 인덱스 0으로 돌아가는 일은 없으며, 항상 유효한 인덱스를 가리킨다
2. **중복이 사이클을 만드는 이유를 이해한다**: 서로 다른 두 인덱스가 동일한 값을 가질 때, 그 값의 인덱스를 향하는 화살표가 2개 존재한다. 이것은 연결 리스트에서 두 노드가 같은 노드를 가리키는 상태이며, 합류 지점에서 사이클이 시작된다. 사이클의 입구가 바로 중복되는 수이다
3. **사이클의 존재를 검출한다**: slow 포인터는 1스텝씩(`slow = nums[slow]`), fast 포인터는 2스텝씩(`fast = nums[nums[fast]]`) 전진한다. 사이클이 존재하면 slow와 fast는 반드시 사이클 내 어딘가에서 만난다
4. **사이클의 입구를 특정한다**: 만난 후, slow를 시작 지점(`nums[0]`)으로 되돌리고, fast는 그 위치에 그대로 둔다. 양쪽을 1스텝씩 전진시키면, 두 포인터는 사이클의 입구에서 다시 만난다. 이 입구의 인덱스에 대응하는 값이 중복되는 수이다
5. **왜 입구에서 만나는가**: 시작 지점에서 사이클 입구까지의 거리와, 만남 지점에서 사이클 입구까지의 거리가 같다는 것이 수학적으로 증명되어 있다. 따라서 양쪽을 같은 속도로 전진시키면 입구에서 일치한다

## 사전 지식

### 암묵적 연결 리스트(Implicit Linked List)란

실제로 노드 객체를 생성하지 않더라도, 배열의 값을 "다음 인덱스로의 포인터"로 해석함으로써 연결 리스트와 동일한 구조를 표현할 수 있다. 인덱스 `i`인 노드의 "다음 노드"는, 인덱스 `nums[i]`인 노드이다.

```java
// 배열 nums = [1, 3, 4, 2, 2]인 경우의 연결 리스트 순회
int current = nums[0];       // 인덱스 0의 값 → 1 (다음은 인덱스 1로)
current = nums[current];     // 인덱스 1의 값 → 3 (다음은 인덱스 3으로)
current = nums[current];     // 인덱스 3의 값 → 2 (다음은 인덱스 2로)
current = nums[current];     // 인덱스 2의 값 → 4 (다음은 인덱스 4로)
current = nums[current];     // 인덱스 4의 값 → 2 (인덱스 2로 돌아감 → 사이클)
```

### Floyd's Cycle Detection(플로이드의 사이클 검출)이란

연결 리스트 내의 사이클을 검출하고, 그 입구를 특정하는 알고리즘이다. 두 개의 포인터(slow: 1칸씩, fast: 2칸씩)를 사용한다. 사이클이 있으면 두 포인터는 반드시 만나며, 그 이후의 절차를 통해 사이클의 입구를 특정할 수 있다.

```java
// 페이즈 1: 사이클 내에서의 만남
slow = nums[slow];           // slow는 1스텝 전진한다
fast = nums[nums[fast]];     // fast는 2스텝 전진한다

// 페이즈 2: 사이클 입구의 특정
slow = nums[slow];           // 양쪽 모두 1스텝씩 전진한다
fast = nums[fast];           // 만나는 지점이 사이클의 입구이다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 각 포인터는 연결 리스트의 순회를 최대 2바퀴만 수행하면 된다 |
| Space | O(1) — slow와 fast 두 개의 변수만 사용한다 |

## 코드

```java
// 입력: 길이 n+1인 정수 배열 nums (각 요소는 1 이상 n 이하, 중복은 1개만 존재)
// 출력: 중복되는 수를 int로 반환한다
public int findDuplicate(int[] nums) {
    // slow와 fast를 연결 리스트의 시작점(nums[0])으로 초기화한다
    // 인덱스 0 자체는 값의 범위(1~n)에 포함되지 않으므로, 사이클의 일부가 되지 않는 안전한 시작 지점이다
    int slow = nums[0];
    int fast = nums[0];

    // 페이즈 1: slow는 1칸, fast는 2칸씩 전진하여 사이클 내에서 만날 때까지 반복한다
    // do-while을 사용하는 이유: 초기값이 같으므로 첫 번째 비교를 건너뛸 필요가 있다
    do {
        slow = nums[slow];           // slow를 1스텝 전진시킨다
        fast = nums[nums[fast]];     // fast를 2스텝 전진시킨다 (사이클이 있으면 반드시 따라잡는다)
    } while (slow != fast);

    // 페이즈 2: slow를 시작 지점으로 되돌리고, 양쪽 모두 1칸씩 전진시킨다
    // 시작 지점에서 입구까지의 거리 = 만남 지점에서 입구까지의 거리라는 성질을 이용한다
    slow = nums[0];
    while (slow != fast) {
        slow = nums[slow];           // 양쪽 모두 1스텝씩 전진시킨다
        fast = nums[fast];           // 사이클의 입구에서 반드시 일치한다
    }

    // 사이클의 입구 = 서로 다른 두 인덱스에서 가리키고 있는 수 = 중복되는 수를 반환한다
    return slow;
}
```
