# Traversing a Binary Tree Level by Level — 이진 트리의 노드를 레벨별로 나누어 리스트로 만들기

## 문제의 본질

이진 트리의 `root`가 주어진다. 트리의 노드를 **레벨(깊이)별로** 그룹화하고, 각 레벨의 노드 값을 왼쪽에서 오른쪽 순서로 저장한 `List<Integer>`를 위쪽 레벨부터 순서대로 나열한 `List<List<Integer>>`로 반환한다.

## 핵심 아이디어

큐(Queue)를 사용하면 노드를 "너비 우선"으로 왼쪽에서 오른쪽으로 처리할 수 있다. 각 레벨의 시작 시점에 큐의 크기를 기록하고, 그 크기만큼 노드를 꺼내면 레벨의 구분을 정확하게 관리할 수 있다.

## 사고 프로세스

1. **레벨별로 처리하려면 너비 우선 탐색(BFS)이 적합하다**: 깊이 우선 탐색(DFS)은 하나의 가지를 깊게 따라가므로 레벨 단위의 그룹화가 어렵다. BFS는 노드를 얕은 순서대로 처리하므로 레벨별 순회에 자연스럽게 대응한다
2. **BFS의 구현에는 큐를 사용한다**: 큐는 FIFO(선입선출) 데이터 구조이며, "먼저 추가한(얕은) 노드부터 순서대로 처리한다"는 BFS의 동작을 구현할 수 있다
3. **레벨의 구분을 어떻게 판정하는가**: 각 레벨의 처리를 시작하는 시점에 큐에 들어 있는 노드는 모두 같은 레벨에 속해 있다. 이 타이밍에 `queue.size()`를 변수 `size`에 기록하고, `size`번만큼 노드를 꺼내면 정확히 1레벨 분의 노드를 처리할 수 있다
4. **꺼낸 노드의 자식을 다음 레벨로서 큐에 추가한다**: 각 노드를 꺼낼 때 그 왼쪽과 오른쪽 자식 노드를 큐에 추가한다. 이 자식 노드들은 현재 레벨의 처리 중에는 꺼내지지 않는다(`size`로 횟수를 제한하고 있기 때문이다). 다음 while 루프의 반복에서 다음 레벨로서 처리된다
5. **각 레벨의 결과를 리스트에 모아서 반환한다**: 레벨마다 `List<Integer>`를 생성하고, 해당 레벨의 노드 값을 저장한다. 1레벨 분의 처리가 끝나면 이 리스트를 최종 결과인 `List<List<Integer>>`에 추가한다
6. **큐가 비면 모든 레벨의 처리가 완료된다**: 모든 노드를 꺼내면 큐가 비게 되고, while 루프가 종료된다. 이 시점에서 결과 리스트에는 위쪽 레벨부터 순서대로 모든 레벨의 노드 값이 저장되어 있다

## 전제 지식

### Queue(큐)란

선입선출(FIFO) 데이터 구조이다. 가장 먼저 추가한 요소가 가장 먼저 꺼내진다. Java에서는 인터페이스 Queue의 구현으로 LinkedList를 사용한다.

```java
Queue<TreeNode> queue = new LinkedList<>();  // 빈 큐를 생성한다
queue.offer(node);   // 큐의 끝에 node를 추가한다
queue.poll();        // 큐의 맨 앞에서 요소를 꺼내서 반환한다(큐에서 삭제된다)
queue.size();        // 큐에 들어 있는 요소의 수를 반환한다 → int
queue.isEmpty();     // 큐가 비어 있는지 여부를 boolean으로 반환한다
```

### BFS(너비 우선 탐색)란

그래프나 트리를 "너비" 방향으로 탐색하는 알고리즘이다. 시작점에 가까운 노드부터 순서대로 처리한다. 큐를 사용하여 구현한다. 트리에 적용하면 레벨0→레벨1→레벨2… 순서로 노드를 방문한다.

### TreeNode의 구조

이진 트리의 각 노드를 나타내는 클래스이다. 값 `val`, 왼쪽 자식 `left`, 오른쪽 자식 `right`의 3개 필드를 가진다.

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 트리의 모든 노드를 1번씩 처리한다 |
| Space | O(n) — 큐에 최대로 트리에서 가장 너비가 넓은 레벨의 노드 수만큼 저장된다(최악의 경우 n/2) |

## 코드

```java
// 입력: 이진 트리의 루트 노드 root
// 출력: 각 레벨의 노드 값을 리스트로 모은 List<List<Integer>>를 반환한다
List<List<Integer>> levelOrder(TreeNode root) {
    // 각 레벨의 노드 값 리스트를 저장하는 최종 결과
    List<List<Integer>> result = new ArrayList<>();

    // root가 null인 경우 트리가 비어 있으므로, 빈 result를 그대로 반환한다
    if (root == null) return result;

    // BFS용 큐를 생성하고, 루트 노드를 추가한다
    // 이 시점에서 큐에는 레벨0의 노드가 1개만 들어 있다
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    // 큐가 빌 때까지 레벨별로 처리를 반복한다
    // 큐가 비었을 때, 모든 노드의 처리가 완료되어 있다
    while (!queue.isEmpty()) {
        // 주의: 이 값을 루프 전에 변수에 저장해 두어야 한다
        // for 루프 내에서 큐에 자식 노드를 추가하면 큐의 크기가 변하므로,
        // queue.size()를 직접 for 루프의 조건에 사용하면 올바른 레벨 구분이 되지 않는다
        int size = queue.size();
        // 현재 레벨의 노드 값을 저장하는 리스트
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < size; i++) {
            // 큐의 맨 앞에서 노드를 꺼낸다
            TreeNode node = queue.poll();
            // 노드의 값을 현재 레벨의 리스트에 추가한다
            level.add(node.val);

            // 왼쪽 자식이 존재하면 큐에 추가한다(다음 레벨에서 처리된다)
            if (node.left != null)
                queue.offer(node.left);
            // 오른쪽 자식이 존재하면 큐에 추가한다
            // 자식 노드의 추가 순서를 왼쪽→오른쪽으로 하여, 다음 레벨에서도 노드가 왼쪽에서 오른쪽 순서로 처리된다
            if (node.right != null)
                queue.offer(node.right);
        }

        // 1레벨 분의 처리가 완료되었으므로 결과에 추가한다
        result.add(level);
    }
    // 모든 레벨의 노드 값이 위에서부터 순서대로 저장된 result를 반환한다
    return result;
}
```
