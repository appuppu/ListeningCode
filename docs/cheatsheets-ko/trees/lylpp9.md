# Finding the Kth Smallest Element in a BST — BST에서 k번째로 작은 요소를 찾기

## 문제의 본질

이진 탐색 트리(BST)의 루트 노드 `root`와 정수 `k`가 주어진다. BST 내 모든 노드의 값 중에서 **k번째로 작은 값**을 반환한다. 트리에는 최소 k개의 노드가 존재하는 것이 보장되어 있다.

## 핵심 아이디어

BST를 중위 순회(in-order traversal)하면 노드의 값이 오름차순으로 나열된다. 따라서 중위 순회에서 k번째로 방문한 노드의 값이 그대로 정답이 된다. 모든 노드를 순회할 필요 없이, k번째에 도달한 시점에서 즉시 종료할 수 있다.

## 사고 과정

1. **BST의 성질을 활용한다**: BST에서는 임의의 노드에 대해 「왼쪽 서브트리의 모든 노드 < 자기 자신 < 오른쪽 서브트리의 모든 노드」가 성립한다. 이 성질에 의해 중위 순회(왼쪽→자기 자신→오른쪽)를 수행하면 노드의 값이 오름차순으로 얻어진다
2. **k번째로 작은 값은 중위 순회의 k번째이다**: 중위 순회로 얻어지는 오름차순 수열의 k번째 요소가 정답이므로, 순회하면서 카운트하면 된다
3. **재귀가 아닌 스택을 이용한 반복적 순회를 선택한다**: 재귀의 경우 k번째에 도달해도 즉시 return할 수 없다(콜 스택의 되감기가 필요하다). 스택을 사용한 반복적 순회라면 k번째를 찾은 순간 return으로 빠져나올 수 있다
4. **스택으로 중위 순회를 구현하는 방법**: 현재 노드에서 왼쪽 자식을 계속 따라가면서 스택에 쌓는다. 왼쪽 끝에 도달하면 스택에서 pop하고, 해당 노드를 「방문」한다. 다음으로 오른쪽 자식으로 이동하여 같은 처리를 반복한다
5. **카운터로 k번째를 감지한다**: 노드를 pop하여 방문할 때마다 k를 감소시킨다. k가 0이 된 시점에서 해당 노드의 값이 정답이다
6. **최종적으로 반환하는 것**: k가 0이 된 시점의 노드 값 `curr.val`을 반환한다

## 사전 지식

### BST(이진 탐색 트리)의 중위 순회란

이진 탐색 트리를 「왼쪽 서브트리→자기 자신→오른쪽 서브트리」의 순서로 방문하는 순회 방법이다. BST에 대해 중위 순회를 수행하면 노드의 값이 오름차순(작은 순서)으로 얻어진다.

```
예시:     5
       / \
      3   7
     / \
    2   4

중위 순회의 결과: 2, 3, 4, 5, 7 (오름차순)
```

### Stack이란

후입선출(LIFO) 데이터 구조이다. 마지막에 추가한 요소가 가장 먼저 꺼내진다. 중위 순회에서는 왼쪽 자식을 따라가는 과정에서 통과한 부모 노드를 기억해 두기 위해 사용한다.

```java
Stack<TreeNode> stack = new Stack<>();  // 빈 스택을 생성한다
stack.push(node);      // node를 스택의 맨 위에 추가한다
stack.pop();           // 스택의 맨 위 요소를 꺼내서 반환한다
stack.isEmpty();       // 스택이 비어 있는지 여부를 boolean으로 반환한다
```

### 반복적 중위 순회의 패턴

스택을 사용한 중위 순회는 「왼쪽 끝까지 내려간다→pop하여 방문한다→오른쪽 자식으로 이동한다」를 반복한다. 루프의 계속 조건은 「현재 노드가 null이 아니거나, 스택이 비어 있지 않은 경우」 중 하나라도 참인 한 계속 수행한다.

```java
TreeNode curr = root;
while (curr != null || !stack.isEmpty()) {
    while (curr != null) {       // 왼쪽 끝까지 내려간다
        stack.push(curr);
        curr = curr.left;
    }
    curr = stack.pop();          // 방문한다 (여기서 오름차순으로 노드가 얻어진다)
    curr = curr.right;           // 오른쪽 자식으로 이동한다
}
```

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(h + k) — 왼쪽 끝까지 h번 하강하고, k개의 노드를 pop한다 |
| Space | O(h) — 스택에 최대 트리의 높이 h개의 노드가 쌓인다 |

## 코드

```java
// 입력: 이진 탐색 트리의 루트 노드 root와 정수 k
// 출력: BST 내에서 k번째로 작은 노드의 값을 int로 반환한다
public int kthSmallest(TreeNode root, int k) {
    // 왼쪽 자식을 따라가는 과정에서 통과한 부모 노드를 임시로 저장하고, 나중에 되돌아오기 위한 스택
    Stack<TreeNode> stack = new Stack<>();
    // 현재 주목하고 있는 노드를 가리키는 포인터
    TreeNode curr = root;

    // curr가 null이어도 스택에 노드가 남아 있으면 미방문 노드가 있으므로 계속한다
    while (curr != null || !stack.isEmpty()) {
        // 왼쪽 끝까지 내려가면서 통과하는 노드를 스택에 쌓는다 (현재 서브트리의 최솟값에 도달한다)
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }

        // pop한 노드가 중위 순회에서 다음으로 방문해야 할 노드이다 (미방문 중 가장 작은 값을 가진다)
        curr = stack.pop();
        // pop은 중위 순회에서 하나를 방문한 것에 해당하므로, 남은 방문 횟수를 1 줄인다
        k--;

        // k가 0이 된 노드가 k번째로 작은 요소이므로, 즉시 값을 반환하고 종료한다
        if (k == 0)
            return curr.val;

        // 오른쪽 서브트리가 있으면 다음 반복에서 그 왼쪽 끝까지 내려간다. 없으면 curr가 null이 되어 스택에서 부모를 pop한다
        curr = curr.right;
    }
    // 문제의 제약 조건상, 트리에는 최소 k개의 노드가 존재하므로 여기에는 도달하지 않는다
    return -1;
}
```
