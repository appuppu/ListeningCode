# Validating a Binary Search Tree — 이진 트리가 유효한 이진 탐색 트리인지 판정한다

## 문제의 본질

이진 트리의 `root`가 주어진다. 해당 트리가 유효한 이진 탐색 트리(BST)인지를 판정한다. 유효한 BST란, 모든 노드에서 왼쪽 부분 트리의 모든 값이 해당 노드의 값보다 **엄격하게 작고**, 오른쪽 부분 트리의 모든 값이 해당 노드의 값보다 **엄격하게 큰** 것을 의미한다.

## 핵심 아이디어

각 노드는 "취할 수 있는 값의 유효 범위"를 가진다. 루트에서 재귀적으로 내려가면서, 왼쪽 자식에는 상한을, 오른쪽 자식에는 하한을 좁혀 나가면, 모든 노드가 BST의 조건을 만족하는지를 한 번의 순회로 판정할 수 있다.

## 사고 프로세스

1. **직접적인 부모-자식 관계만으로는 불충분하다**: 각 노드가 직접적인 왼쪽 자식보다 크고 오른쪽 자식보다 작은 것만으로는 BST의 조건을 만족하지 않는다. 왼쪽 부분 트리의 "모든" 노드가 해당 노드보다 작아야 한다. 즉, 각 노드에는 조상으로부터 물려받은 제약이 존재한다
2. **각 노드의 유효 범위를 정의한다**: 루트는 임의의 값을 취할 수 있으므로, 범위는 `(-∞, +∞)`에서 시작한다. 왼쪽 자식으로 진행할 때 상한이 부모의 값으로 좁아지고, 오른쪽 자식으로 진행할 때 하한이 부모의 값으로 좁아진다. 이 범위를 재귀의 인수로 전달하면 된다
3. **판정 조건을 결정한다**: 각 노드에서 `node.val`이 `(lo, hi)` 범위 내에 있는지를 확인한다. BST는 엄격한 부등호를 사용하므로, `node.val <= lo` 또는 `node.val >= hi`이면 유효하지 않다고 판정한다
4. **재귀의 구조를 결정한다**: 베이스 케이스는 `node == null`이며 `true`를 반환한다(빈 트리는 유효한 BST이다). 각 노드에서 자신의 값을 판정하고, 왼쪽과 오른쪽 자식에 대해 범위를 좁혀서 재귀 호출한다. 왼쪽과 오른쪽 모두 `true`를 반환한 경우에만 `true`로 한다
5. **범위의 타입을 long으로 한다**: 노드의 값이 `Integer.MIN_VALUE`나 `Integer.MAX_VALUE`일 때, int 타입의 범위로는 초기값을 표현할 수 없다. `Long.MIN_VALUE`와 `Long.MAX_VALUE`를 초기 범위로 사용함으로써 모든 int 값을 올바르게 판정할 수 있다
6. **최종적으로 반환하는 것**: 루트에서 재귀를 시작하여, 모든 노드가 유효 범위 내에 있으면 `true`를, 하나라도 위반이 있으면 `false`를 반환한다

## 사전 지식

### 이진 탐색 트리(BST)란

각 노드에 대해, 왼쪽 부분 트리의 모든 값이 해당 노드의 값보다 작고, 오른쪽 부분 트리의 모든 값이 해당 노드의 값보다 큰 성질을 가지는 이진 트리이다. 이 성질은 직접적인 자식뿐만 아니라 부분 트리 전체에 적용된다.

```
      5
     / \
    3   7     ← 유효한 BST: 3<5, 7>5, 1<3, 4>3이면서 4<5, 6>5이면서 6<7
   / \   \
  1   4   8
```

### 재귀를 통한 범위의 축소

부모에서 자식으로 진행할 때, 유효한 값의 범위가 좁아지는 구조:

```
노드5: 범위(-∞, +∞)
├─ 왼쪽 자식3: 범위(-∞, 5)  ← 상한이 부모의 값 5로 좁아진다
│  ├─ 왼쪽 자식1: 범위(-∞, 3)
│  └─ 오른쪽 자식4: 범위(3, 5)  ← 하한 3이면서 상한 5
└─ 오른쪽 자식7: 범위(5, +∞)  ← 하한이 부모의 값 5로 좁아진다
```

### long 타입을 사용하는 이유

Java의 `int` 범위는 `-2147483648` ~ `2147483647`이다. 초기 범위로서 "int 타입의 어떤 값이든 허용한다"를 표현하려면, int 타입의 범위를 초과하는 값이 필요하다. `long` 타입을 사용하면 `Long.MIN_VALUE`와 `Long.MAX_VALUE`로 충분히 넓은 초기 범위를 설정할 수 있다.

```java
long lo = Long.MIN_VALUE;  // int의 어떤 값보다도 작다
long hi = Long.MAX_VALUE;  // int의 어떤 값보다도 크다
node.val <= lo;            // node.val은 int 타입이므로, Long.MIN_VALUE보다 큰 것이 보장된다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 각 노드를 한 번씩 방문한다 |
| Space | O(h) — 재귀의 콜 스택 깊이는 트리의 높이 h에 비례한다 (최악 O(n), 균형 시 O(log n)) |

## 코드

```java
// 입력: 이진 트리의 루트 노드 root
// 출력: 트리가 유효한 BST이면 true, 그렇지 않으면 false
public boolean isValidBST(TreeNode root) {
    // 초기 범위를 Long.MIN_VALUE/MAX_VALUE로 설정하여, 루트 노드가 int 타입의 어떤 값이든 허용되도록 한다
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

// lo, hi는 long 타입이다. int 타입이면 Integer.MIN_VALUE/MAX_VALUE를 초기값으로 사용할 수 없기 때문이다
boolean validate(TreeNode node, long lo, long hi) {
    // 베이스 케이스: 빈 노드는 BST 조건을 위반하지 않는다
    if (node == null) return true;

    // 현재 노드의 값이 유효 범위(lo, hi) 밖에 있으면 유효하지 않다
    // BST에서는 같은 값도 허용되지 않으므로, <=와 >=로 엄격하게 판정한다
    if (node.val <= lo || node.val >= hi) return false;

    // 왼쪽 부분 트리: 상한을 node.val로 좁힌다 (왼쪽의 값은 모두 node.val보다 작아야 한다). 하한 lo는 조상의 제약을 유지한다
    // 오른쪽 부분 트리: 하한을 node.val로 좁힌다 (오른쪽의 값은 모두 node.val보다 커야 한다). 상한 hi는 조상의 제약을 유지한다
    // 왼쪽과 오른쪽 모두 true인 경우에만, 이 부분 트리 전체가 유효한 BST이다
    return validate(node.left, lo, node.val)
        && validate(node.right, node.val, hi);
}
```
