# Checking if a Binary Tree is Height-Balanced — 이진 트리가 높이 균형인지 판정하기

## 문제의 본질

이진 트리의 루트 노드 `root`가 주어진다. 해당 트리가 **높이 균형(height-balanced)**인지를 판정한다. 높이 균형이란, 모든 노드에서 왼쪽 서브트리의 높이와 오른쪽 서브트리의 높이의 차이가 1 이하인 것을 의미한다. 결과를 `boolean`으로 반환한다.

## 핵심 아이디어

각 노드의 높이를 구하는 재귀 처리 중에, 불균형을 감지한 순간 `-1`을 반환하여 전파시킨다. 높이 계산과 균형 판정을 1회의 후위 순회(post-order traversal)로 동시에 수행함으로써, 모든 노드를 1번만 방문하면 답을 구할 수 있다.

## 사고 프로세스

1. **균형의 정의를 재귀적으로 파악한다**: 트리가 균형이라 함은, 모든 노드에서 좌우 서브트리의 높이 차이가 1 이하인 것이다. 즉, 어떤 노드의 균형 판정에는 좌우 서브트리의 「높이」가 필요하다
2. **높이 계산 자체가 재귀적이다**: 어떤 노드의 높이는 `1 + max(왼쪽 높이, 오른쪽 높이)`로 구할 수 있다. 이 재귀로 트리를 아래에서 위로(post-order로) 순회하면, 각 노드의 높이가 자연스럽게 구해진다
3. **높이 계산과 균형 판정을 통합한다**: 높이를 반환하는 재귀 함수 안에서, 좌우 높이의 차이가 1을 초과한 시점에 「불균형」을 나타내는 특별한 값 `-1`을 반환한다. 이렇게 하면 높이 계산과 균형 판정을 하나의 함수로 동시에 수행할 수 있다
4. **조기 종료로 불필요한 탐색을 생략한다**: 왼쪽 서브트리의 결과가 `-1`이면, 오른쪽 서브트리를 조사할 필요 없이 트리 전체가 불균형이다. 재귀의 반환값이 `-1`인지를 매번 확인하고, 불균형이 발견된 시점에 즉시 `-1`을 반환하여 재귀를 중단한다
5. **반환값의 이중 의미를 활용한다**: 반환값이 `0 이상`이면 정상적인 높이를, `-1`이면 불균형을 의미한다. 호출 측의 `isBalanced` 메서드는 최종 반환값이 `-1`이 아닌지를 확인하는 것만으로 답을 얻을 수 있다

## 전제 지식

### 이진 트리의 높이(height)란

어떤 노드에서 가장 먼 리프 노드까지의 간선 수이다. 리프 노드의 높이는 1(노드 수로 세는 경우)이고, `null`의 높이는 0으로 한다. 재귀적으로는 `height(node) = 1 + max(height(node.left), height(node.right))`로 구할 수 있다.

```
        1           노드 1의 높이: 3
       / \          노드 2의 높이: 2
      2   3         노드 4의 높이: 1
     /              노드 3의 높이: 1
    4
```

### 후위 순회(Post-Order Traversal)란

왼쪽 서브트리 → 오른쪽 서브트리 → 자기 자신 의 순서로 노드를 처리하는 순회 방법이다. 자식의 정보를 먼저 확정한 후에 부모의 처리를 수행하므로, 「자식의 높이를 사용하여 부모의 높이를 계산하는」 것과 같은 아래에서 위로의 집계 처리에 적합하다.

```java
void postOrder(TreeNode node) {
    if (node == null) return;
    postOrder(node.left);   // 왼쪽 서브트리를 먼저 처리한다
    postOrder(node.right);  // 오른쪽 서브트리를 다음에 처리한다
    // 여기서 node 자신의 처리를 수행한다 (좌우의 결과가 이미 확정되어 있다)
}
```

### Math.abs란

정수의 절댓값을 반환하는 Java의 표준 메서드이다. 좌우 높이의 차이가 양수이든 음수이든 1 이하인지를 판정하기 위해 사용한다.

```java
Math.abs(3 - 1);    // → 2
Math.abs(1 - 3);    // → 2
Math.abs(2 - 3);    // → 1
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 각 노드를 1번씩 방문한다 |
| Space | O(n) — 재귀 호출의 콜 스택이 최대 n단이다 (트리가 편향된 경우) |

## 코드

```java
// 입력: 이진 트리의 루트 노드 root
// 출력: 트리가 높이 균형이면 true, 그렇지 않으면 false를 반환한다

// 노드의 높이를 반환하는 재귀 함수. 불균형을 감지하면 센티널 값 -1을 반환한다
// 반환값이 0 이상이면 정상적인 높이, -1이면 「어딘가의 서브트리가 불균형」임을 의미한다
private int checkHeight(TreeNode node) {
    // 베이스 케이스: null은 빈 서브트리를 나타내며, 높이는 0이다
    if (node == null) return 0;

    // 왼쪽 서브트리의 높이를 재귀적으로 구한다 (후위 순회의 「왼쪽을 먼저」 부분)
    int left = checkHeight(node.left);
    // 왼쪽 서브트리가 불균형이면, 오른쪽 서브트리를 조사하지 않고 즉시 -1을 전파한다 (조기 종료)
    if (left == -1) return -1;

    // 오른쪽 서브트리의 높이를 재귀적으로 구한다 (후위 순회의 「오른쪽을 다음에」 부분)
    int right = checkHeight(node.right);
    // 오른쪽 서브트리가 불균형이면 즉시 -1을 전파한다
    if (right == -1) return -1;

    // 현재 노드에서 좌우 높이의 차이가 1을 초과하면 불균형이다 (후위 순회의 「자기 자신의 처리」)
    // Math.abs를 사용하여, 좌우 어느 쪽이 높더라도 올바르게 차이를 판정한다
    if (Math.abs(left - right) > 1)
        return -1;

    // 균형이면 현재 노드의 높이를 반환한다. 부모 노드의 계산에 사용된다
    return 1 + Math.max(left, right);
}

public boolean isBalanced(TreeNode root) {
    // checkHeight가 -1이 아니면 트리 전체가 균형이다
    // -1은 「어딘가의 서브트리가 불균형」임을 나타내는 센티널 값이다
    return checkHeight(root) != -1;
}
```
