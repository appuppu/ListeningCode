# Finding the Lowest Common Ancestor in a BST — BST 내 두 노드의 가장 깊은 공통 조상을 찾기

## 문제의 본질

이진 탐색 트리(BST)와 트리에 존재하는 두 노드 `p`, `q`가 주어진다. 두 노드를 모두 자손으로 가지는 가장 깊은 노드(최소 공통 조상: LCA)를 반환한다. 노드 자신도 자기 자신의 자손으로 간주한다.

## 핵심 아이디어

BST에서는 왼쪽 자손이 모두 현재 노드보다 작고, 오른쪽 자손이 모두 크다. `p`와 `q`가 현재 노드를 기준으로 좌우로 나뉘는 순간, 그 노드가 LCA이다.

## 사고 과정

1. **BST의 성질을 활용할 수 있다**: BST에서는 임의의 노드에 대해 왼쪽 부분 트리의 모든 값 < 노드의 값 < 오른쪽 부분 트리의 모든 값이라는 순서가 보장된다. 이 성질을 통해 `p`와 `q`가 어느 부분 트리에 있는지를 노드 값의 비교만으로 판정할 수 있다
2. **둘 다 왼쪽에 있으면 왼쪽으로 진행한다**: `p.val`과 `q.val`이 모두 현재 노드의 값보다 작은 경우, `p`와 `q`는 둘 다 왼쪽 부분 트리에 존재한다. LCA도 그 왼쪽 부분 트리 안에 있으므로 왼쪽 자식으로 이동한다
3. **둘 다 오른쪽에 있으면 오른쪽으로 진행한다**: `p.val`과 `q.val`이 모두 현재 노드의 값보다 큰 경우, `p`와 `q`는 둘 다 오른쪽 부분 트리에 존재한다. LCA도 그 오른쪽 부분 트리 안에 있으므로 오른쪽 자식으로 이동한다
4. **좌우로 나뉘면 그 노드가 LCA이다**: `p`와 `q`가 현재 노드의 좌우로 나뉜 경우(한쪽이 작고 다른 쪽이 큰 경우), 이보다 더 깊은 단일 부분 트리에 둘 다 포함될 수 없다. 따라서 현재 노드가 LCA이다. `p` 또는 `q`가 현재 노드와 같은 경우에도 자기 자신이 자손으로 간주되므로 LCA가 된다
5. **재귀를 사용하지 않고 반복으로 구현할 수 있다**: 각 단계에서 왼쪽 또는 오른쪽 한 방향으로만 진행하므로 재귀의 콜 스택이 필요하지 않다. while 루프로 현재 노드를 갱신해 나가기만 하면 되며, 공간 복잡도를 O(1)로 만들 수 있다

## 사전 지식

### 이진 탐색 트리(BST)란

각 노드가 "왼쪽 자손 < 자신 < 오른쪽 자손"이라는 순서를 만족하는 이진 트리이다. 이 성질을 통해 값의 대소 비교만으로 노드가 어느 부분 트리에 속하는지를 판정할 수 있다.

```
        6
       / \
      2    8
     / \  / \
    0   4 7   9
```

이 트리에서 노드 2와 노드 8의 LCA는 6이다. 노드 2와 노드 4의 LCA는 2이다(노드 2는 자기 자신의 자손이기도 하다).

### 최소 공통 조상(LCA)이란

두 노드 `p`, `q`의 공통 조상 중 가장 깊은(루트에서 가장 먼) 노드이다. `p` 또는 `q` 자신이 다른 한쪽의 조상인 경우, 그 노드 자신이 LCA가 된다.

### TreeNode의 구조

BST의 각 노드를 나타내는 클래스이다. 값 `val`, 왼쪽 자식 `left`, 오른쪽 자식 `right`를 가진다.

```java
TreeNode node = new TreeNode(6);   // 값이 6인 노드를 생성한다
node.val;                           // 노드의 값을 가져온다 → 6
node.left;                          // 왼쪽 자식 노드를 가져온다
node.right;                         // 오른쪽 자식 노드를 가져온다
```

## 복잡도

| | 값 |
|---|---|
| Time | O(h) — 트리의 높이만큼 탐색한다. 균형 BST라면 O(log n) |
| Space | O(1) — 반복 처리이므로 추가 메모리를 사용하지 않는다 |

## 코드

```java
// 입력: BST의 루트 노드 root, 트리에 존재하는 두 노드 p와 q
// 출력: p와 q의 최소 공통 조상(LCA)에 해당하는 TreeNode를 반환한다
TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    // 현재 탐색 위치를 루트로 초기화한다. while 루프로 갱신해 나간다
    TreeNode node = root;

    // node가 null이 아닌 동안 탐색을 반복한다
    while (node != null) {
        // p와 q가 모두 현재 노드보다 작은지 판정한다
        if (p.val < node.val && q.val < node.val) {
            // 둘 다 왼쪽 부분 트리에 존재하므로 LCA도 왼쪽 부분 트리 안에 있다
            node = node.left;
        // p와 q가 모두 현재 노드보다 큰지 판정한다
        } else if (p.val > node.val && q.val > node.val) {
            // 둘 다 오른쪽 부분 트리에 존재하므로 LCA도 오른쪽 부분 트리 안에 있다
            node = node.right;
        } else {
            // p와 q가 좌우로 나뉘었다(또는 한쪽이 현재 노드와 같다)
            // 이보다 더 깊은 단일 부분 트리에는 두 노드가 모두 들어갈 수 없으므로 LCA가 확정된다
            return node;
        }
    }
    // 문제의 제약 조건상 p와 q는 트리에 존재하므로 반드시 위의 return에서 종료되며 여기에는 도달하지 않는다
    return null;
}
```
