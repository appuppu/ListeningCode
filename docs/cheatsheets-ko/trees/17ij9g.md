# Finding the Maximum Depth of a Binary Tree — 이진 트리의 가장 깊은 경로의 노드 수를 구하기

## 문제의 본질

이진 트리의 `root` 노드가 주어진다. 루트 노드에서 가장 먼 리프 노드까지의 경로에 포함되는 **노드의 수**(최대 깊이)를 정수로 반환한다. 빈 트리(root가 null)인 경우에는 0을 반환한다.

## 핵심 아이디어

트리의 최대 깊이는 "왼쪽 서브트리의 최대 깊이"와 "오른쪽 서브트리의 최대 깊이" 중 큰 쪽에 1(현재 노드 분)을 더한 것이다. 이 재귀적 정의가 그대로 풀이 방법이 된다.

## 사고 프로세스

1. **트리의 깊이는 재귀적으로 정의할 수 있다**: 어떤 노드의 깊이는 그 좌우 자식을 루트로 하는 서브트리의 깊이에 의존한다. 즉, 문제를 작은 동일한 구조의 부분 문제로 분해할 수 있다
2. **베이스 케이스를 결정한다**: 노드가 null일 때, 거기에는 아무것도 없으므로 깊이는 0이다. 이것이 재귀의 종료 조건이 된다
3. **좌우 서브트리 각각의 깊이를 구한다**: 현재 노드에서 왼쪽 자식으로 재귀하여 왼쪽 서브트리의 최대 깊이를 얻는다. 마찬가지로 오른쪽 자식으로도 재귀하여 오른쪽 서브트리의 최대 깊이를 얻는다
4. **좌우의 결과를 통합한다**: 최대 깊이란 가장 긴 경로이므로, 좌우 깊이 중 큰 쪽을 선택한다. `Math.max(left, right)`로 취득한다
5. **현재 노드를 가산하여 반환한다**: 좌우 깊이의 최댓값에 1을 더함으로써 현재 노드를 포함한 깊이를 부모에게 반환한다. 이 1은 "현재 노드 자신"을 세는 것이다

## 전제 지식

### TreeNode(이진 트리의 노드)란

이진 트리의 각 노드를 나타내는 클래스이다. 값 `val`, 왼쪽 자식 `left`, 오른쪽 자식 `right`의 3개 필드를 가진다. 자식이 존재하지 않는 경우에는 null이 들어간다.

```java
public class TreeNode {
    int val;              // 노드가 보유하는 값
    TreeNode left;        // 왼쪽 자식 노드(없으면 null)
    TreeNode right;       // 오른쪽 자식 노드(없으면 null)
}
```

### 재귀(Recursion)란

함수가 자기 자신을 호출하는 기법이다. 트리 구조에서는 각 노드에 대해 동일한 처리를 서브트리에 적용할 때 사용한다. 반드시 베이스 케이스(재귀를 멈추는 조건)를 정의하여 무한 루프를 방지한다.

```java
// 재귀의 기본 구조
public int recursive(TreeNode node) {
    if (node == null) return 0;           // 베이스 케이스: 재귀의 종료 조건
    return recursive(node.left);          // 재귀 호출: 부분 문제를 풀기
}
```

### Math.max란

2개의 정수 중 큰 쪽을 반환하는 Java의 표준 메서드이다.

```java
Math.max(3, 5);    // → 5
Math.max(0, 0);    // → 0
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 모든 노드를 1회씩 방문한다 |
| Space | O(h) — 재귀의 콜 스택이 트리의 높이만큼 쌓인다. 최악의 경우(편향된 트리)에서는 O(n)이 된다 |

## 코드

```java
// 입력: 이진 트리의 루트 노드 root(TreeNode 타입, null인 경우도 있음)
// 출력: 트리의 최대 깊이를 나타내는 정수를 반환한다
public int maxDepth(TreeNode root) {
    // 베이스 케이스: 노드가 없으면 깊이는 0이다
    // 리프 노드의 자식(null)에 도달했을 때 재귀가 멈춘다
    if (root == null) return 0;

    // 왼쪽 서브트리의 최대 깊이를 재귀적으로 구한다
    // 왼쪽 자식을 루트로 하는 서브트리에 대해 동일한 처리를 반복하며, 최종적으로 베이스 케이스에 도달하여 값이 반환된다
    int left = maxDepth(root.left);

    // 오른쪽 서브트리의 최대 깊이를 재귀적으로 구한다
    // 왼쪽과 마찬가지로, 오른쪽 자식을 루트로 하는 서브트리의 깊이를 구한다
    int right = maxDepth(root.right);

    // 좌우 중 깊은 쪽에 현재 노드 분의 1을 더하여 반환한다
    // Math.max(left, right)로 가장 긴 경로의 노드 수가 되는 깊은 쪽의 서브트리를 선택한다
    // +1은 현재 노드 root 자신을 세는 것이다. 부모 노드는 이 반환값을 받아 자신의 계산에 사용한다
    return 1 + Math.max(left, right);
}
```
