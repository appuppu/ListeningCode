# Checking if Two Binary Trees Are Identical — 두 이진 트리가 구조와 값 모두 동일한지 판정하기

## 문제의 본질

두 이진 트리 `p`와 `q`가 주어진다. 두 트리가 "동일"하다는 것은 구조가 완전히 일치하고, 대응하는 모든 노드의 값이 같다는 것을 의미한다. 동일하면 `true`를, 그렇지 않으면 `false`를 반환한다.

## 핵심 아이디어

두 트리의 대응하는 노드를 "쌍"으로 큐에 넣고, 레벨 순서대로 한 쌍씩 꺼내어 비교한다. 모든 쌍에서 구조와 값이 일치하면 동일하고, 하나라도 불일치가 있으면 동일하지 않다고 즉시 판정할 수 있다.

## 사고 프로세스

1. **대응하는 노드끼리 비교하면 된다**: 두 트리가 동일한지 판정하려면, 트리의 같은 위치에 있는 노드끼리 한 쌍씩 비교하면 된다. 모든 쌍에서 값이 일치하고 구조(자식의 유무)도 일치하면, 두 트리는 동일하다
2. **쌍을 어떻게 관리할 것인가**: 비교해야 할 노드의 쌍을 순서대로 관리할 필요가 있다. 큐(FIFO)를 사용하면 너비 우선으로 레벨별로 쌍을 꺼내어 비교할 수 있다. 큐에는 `TreeNode[]` 배열(요소 수 2)을 저장하며, `pair[0]`은 트리 p의 노드를, `pair[1]`은 트리 q의 노드를 나타낸다
3. **쌍을 꺼냈을 때 무엇을 판정하는가**: 꺼낸 쌍에 대해 3가지 경우를 순서대로 판정한다. (a) 둘 다 null이면 구조가 일치하므로 다음 쌍으로 진행한다, (b) 한쪽만 null이면 구조가 다르므로 `false`를 반환한다, (c) 둘 다 null이 아니지만 값이 다르면 `false`를 반환한다
4. **판정을 통과하면 자식 노드의 쌍을 큐에 추가한다**: 현재 쌍이 일치한 경우, 다음으로 비교해야 할 것은 왼쪽 자식끼리와 오른쪽 자식끼리이다. `{n1.left, n2.left}`와 `{n1.right, n2.right}` 두 쌍을 큐에 추가한다. 자식이 null이더라도 추가해도 된다(3단계의 null 판정에서 올바르게 처리된다)
5. **큐가 비면 모든 쌍이 일치한 것이다**: 모든 쌍을 비교한 후 불일치가 발견되지 않았다면, 두 트리는 동일하므로 `true`를 반환한다

## 사전 지식

### Queue(큐)란

선입선출(FIFO) 데이터 구조이다. 가장 먼저 추가한 요소가 가장 먼저 꺼내진다. 너비 우선 탐색에서 노드를 레벨 순서대로 처리하기 위해 사용한다. Java에서는 `Queue` 인터페이스를 `LinkedList`로 구현한다.

```java
Queue<TreeNode[]> queue = new LinkedList<>();  // TreeNode 배열을 저장하는 큐를 생성한다
queue.add(new TreeNode[]{p, q});               // 쌍(요소 2개의 배열)을 큐의 끝에 추가한다
TreeNode[] pair = queue.poll();                 // 큐의 맨 앞에서 쌍을 꺼내어 반환한다(큐가 비어 있으면 null을 반환한다)
queue.isEmpty();                               // 큐가 비어 있는지를 boolean으로 반환한다 → true/false
```

### TreeNode(이진 트리의 노드)란

이진 트리의 각 노드를 나타내는 클래스이다. `val` 필드에 노드의 값을, `left`와 `right` 필드에 각각 왼쪽 자식 노드와 오른쪽 자식 노드에 대한 참조를 가진다. 자식이 존재하지 않는 경우 `null`이 된다.

```java
TreeNode node = new TreeNode(5);   // 값이 5인 노드를 생성한다
node.val;                          // 노드의 값을 가져온다 → 5
node.left;                         // 왼쪽 자식 노드를 가져온다(없으면 null)
node.right;                        // 오른쪽 자식 노드를 가져온다(없으면 null)
```

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(n) — 두 트리의 노드를 최대 n개씩 1회 비교한다 |
| Space | O(n) — 큐에 최대 노드 수에 비례하는 쌍을 보유한다 |

## 코드

```java
// 입력: 두 이진 트리의 루트 노드 p와 q
// 출력: 두 트리가 구조와 값 모두 동일하면 true를, 그렇지 않으면 false를 반환한다
public boolean isSameTree(TreeNode p, TreeNode q) {
    // 비교해야 할 노드의 쌍을 관리하는 큐를 생성한다
    // 쌍은 요소 수 2의 TreeNode[] 배열로 저장하며, pair[0]은 트리 p의 노드를, pair[1]은 트리 q의 노드를 나타낸다
    Queue<TreeNode[]> queue = new LinkedList<>();
    // 초기 상태로, 두 트리의 루트 노드 쌍을 큐에 추가한다(가장 먼저 비교해야 할 쌍)
    queue.add(new TreeNode[]{p, q});

    // 큐가 비어 있지 않은 동안, 쌍을 한 쌍씩 꺼내어 비교한다
    while (!queue.isEmpty()) {
        // 큐의 맨 앞에서 쌍을 꺼낸다
        TreeNode[] pair = queue.poll();
        TreeNode n1 = pair[0];
        TreeNode n2 = pair[1];

        // 둘 다 null이면, 이 위치에서 두 트리 모두 자식이 존재하지 않으므로 구조가 일치한다. 다음 쌍으로 진행한다
        if (n1 == null && n2 == null)
            continue;
        // 한쪽만 null이면, 한 트리에는 노드가 존재하고 다른 트리에는 존재하지 않으므로 구조가 다르다
        if (n1 == null || n2 == null)
            return false;
        // 값이 다르면 대응하는 노드의 값이 일치하지 않으므로 false를 반환한다
        if (n1.val != n2.val)
            return false;

        // 현재 쌍이 일치했으므로, 다음으로 비교해야 할 자식 노드의 쌍을 큐에 추가한다
        // 자식이 null이더라도 그대로 추가한다(위의 null 판정에서 올바르게 처리된다)
        queue.add(new TreeNode[]{n1.left, n2.left});
        queue.add(new TreeNode[]{n1.right, n2.right});
    }
    // 모든 쌍에서 구조와 값이 일치했으므로 true를 반환한다
    return true;
}
```
