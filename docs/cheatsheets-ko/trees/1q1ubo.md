# Constructing a Binary Tree From Traversal Orders — 전위 순회와 중위 순회로 원래의 이진 트리를 복원하기

## 문제의 본질

정수 배열 `preorder`(전위 순회)와 `inorder`(중위 순회)가 주어진다. 이 2개의 순회 결과로부터 원래의 이진 트리를 구축하여 반환한다. 전위 순회는 「루트→왼쪽→오른쪽」의 순서, 중위 순회는 「왼쪽→루트→오른쪽」의 순서로 요소가 나열되어 있다.

## 핵심 아이디어

전위 순회의 첫 번째 요소는 반드시 현재 부분 트리의 루트이며, 그 루트의 값이 중위 순회의 어디에 위치하는지를 확인하면 중위 순회를 「왼쪽 부분 트리의 요소」와 「오른쪽 부분 트리의 요소」로 분할할 수 있다. 이 분할을 재귀적으로 반복하면 트리 전체를 복원할 수 있다.

## 사고 프로세스

1. **전위 순회의 첫 번째 요소는 루트이다**: 전위 순회는 「루트→왼쪽→오른쪽」의 순서로 요소를 나열하므로, 배열의 첫 번째 요소는 반드시 트리 전체의 루트 노드이다. 이 성질은 부분 트리에도 재귀적으로 성립한다
2. **중위 순회에서 루트의 위치를 알면 좌우를 분할할 수 있다**: 중위 순회는 「왼쪽→루트→오른쪽」의 순서이므로, 루트의 값이 중위 순회의 위치 `mid`에 있을 때, `mid`보다 왼쪽의 요소는 모두 왼쪽 부분 트리에 속하고, `mid`보다 오른쪽의 요소는 모두 오른쪽 부분 트리에 속한다
3. **루트의 위치를 빠르게 구하고 싶다**: 매번 중위 순회를 선형 탐색하면 전체적으로 O(n²)이 걸린다. 사전에 HashMap으로 「값→중위 순회에서의 인덱스」를 기록해 두면 루트의 위치를 O(1)로 취득할 수 있다
4. **배열 복사가 아닌 인덱스 경계로 부분 트리의 범위를 표현한다**: 재귀할 때마다 배열을 복사하면 O(n²)의 공간이 필요해진다. 중위 순회의 범위를 `inLeft`와 `inRight`의 2개의 인덱스로 표현하면, 배열 복사 없이 부분 트리의 범위를 지정할 수 있다
5. **전위 순회의 포인터를 전역으로 진행시킨다**: 전위 순회는 「루트→왼쪽 부분 트리 전체→오른쪽 부분 트리 전체」의 순서로 나열되어 있으므로, 전역 포인터 `preIdx`를 준비하여 루트를 하나 꺼낼 때마다 인크리먼트하면, 왼쪽 부분 트리의 재귀가 끝난 시점에서 포인터는 자연스럽게 오른쪽 부분 트리의 루트를 가리킨다
6. **왼쪽 부분 트리를 먼저 구축한다**: 전위 순회의 순서는 「루트→왼쪽→오른쪽」이므로, 루트를 꺼낸 후에는 반드시 왼쪽 부분 트리를 먼저 재귀적으로 구축하고, 그 다음에 오른쪽 부분 트리를 구축한다. 이 순서를 지키면 `preIdx`가 올바르게 진행된다

## 전제 지식

### 전위 순회(Preorder Traversal)란

이진 트리를 「루트→왼쪽 부분 트리→오른쪽 부분 트리」의 순서로 방문하는 순회 방법이다. 배열의 첫 번째 요소가 반드시 루트 노드의 값이 된다.

```
        3
       / \
      9   20
         / \
        15   7

전위 순회: [3, 9, 20, 15, 7]  ← 첫 번째 요소 3이 루트
```

### 중위 순회(Inorder Traversal)란

이진 트리를 「왼쪽 부분 트리→루트→오른쪽 부분 트리」의 순서로 방문하는 순회 방법이다. 루트의 값을 기준으로, 왼쪽의 요소가 왼쪽 부분 트리, 오른쪽의 요소가 오른쪽 부분 트리에 속한다.

```
중위 순회: [9, 3, 15, 20, 7]  ← 3의 왼쪽에 있는 [9]가 왼쪽 부분 트리, 오른쪽에 있는 [15,20,7]가 오른쪽 부분 트리
```

### HashMap이란

키와 값의 쌍을 저장하는 데이터 구조이다. 키를 지정하여 값의 검색 및 취득을 O(1)로 수행할 수 있다.

```java
HashMap<Integer, Integer> map = new HashMap<>();  // 빈 HashMap을 생성한다
map.put(3, 1);           // 키 3에 값 1을 저장한다
map.get(3);              // 키 3에 대응하는 값을 반환한다 → 1
```

### TreeNode란

이진 트리의 하나의 노드를 나타내는 클래스이다. 값 `val`, 왼쪽 자식 `left`, 오른쪽 자식 `right`를 가진다.

```java
TreeNode root = new TreeNode(3);    // 값 3의 노드를 생성한다
root.left = new TreeNode(9);        // 왼쪽 자식에 값 9의 노드를 설정한다
root.right = new TreeNode(20);      // 오른쪽 자식에 값 20의 노드를 설정한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 각 노드를 1회씩 처리하며, HashMap에 의한 검색은 O(1)로 완료된다 |
| Space | O(n) — HashMap에 n개의 요소를 저장하며, 재귀 스택은 최악의 경우 O(n)이다 (편향된 트리의 경우) |

## 코드

```java
// 입력: 정수 배열 preorder(전위 순회)와 정수 배열 inorder(중위 순회)
// 출력: 복원한 이진 트리의 루트 노드 TreeNode를 반환한다

// 키=중위 순회의 값, 밸류=그 값의 중위 순회에서의 인덱스를 저장하는 HashMap
// 루트의 값으로부터 중위 순회에서의 위치를 O(1)로 취득하기 위해 사용한다
Map<Integer, Integer> map = new HashMap<>();
// 전위 순회 배열에서 「다음에 꺼내야 할 루트의 위치」를 가리키는 전역 포인터
// 재귀 호출할 때마다 인크리먼트하여 진행시킨다
int preIdx = 0;

public TreeNode buildTree(int[] preorder, int[] inorder) {
    // 중위 순회의 각 값과 인덱스를 HashMap에 등록한다
    // 이를 통해 임의의 값이 중위 순회의 어느 위치에 있는지를 즉시 조회할 수 있게 된다
    for (int i = 0; i < inorder.length; i++)
        map.put(inorder[i], i);

    // 배열 전체의 범위(inLeft=0, inRight=끝)를 지정하여 재귀를 시작한다
    return helper(preorder, 0, inorder.length - 1);
}

// inLeft, inRight는 중위 순회 배열에서 현재 부분 트리의 범위를 나타낸다
TreeNode helper(int[] preorder, int inLeft, int inRight) {
    // 부분 트리의 범위가 비어 있으면(inLeft > inRight) 자식 노드는 존재하지 않는다
    if (inLeft > inRight) return null;

    // 전위 순회의 현재 위치에서 루트의 값을 꺼내고, 포인터를 진행시킨다
    int rootVal = preorder[preIdx++];
    TreeNode root = new TreeNode(rootVal);

    // 루트의 값이 중위 순회의 어디에 있는지를 HashMap으로 취득한다
    // mid는 중위 순회에서 왼쪽 부분 트리와 오른쪽 부분 트리의 경계를 나타낸다
    int mid = map.get(rootVal);

    // 주의: 전위 순회는 「루트→왼쪽→오른쪽」의 순서로 나열되어 있으므로, 왼쪽 부분 트리를 반드시 먼저 구축한다
    // 이 순서에 의해 preIdx가 올바르게 오른쪽 부분 트리의 루트를 가리키게 된다
    // 중위 순회의 inLeft부터 mid-1까지가 왼쪽 부분 트리의 범위이다
    root.left = helper(preorder, inLeft, mid - 1);
    // 중위 순회의 mid+1부터 inRight까지가 오른쪽 부분 트리의 범위이다
    root.right = helper(preorder, mid + 1, inRight);

    // 구축한 root 노드를 반환한다. 재귀가 모두 완료되면 트리 전체의 루트 노드가 반환된다
    return root;
}
```
