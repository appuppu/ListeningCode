# Finding the Maximum Path Sum in a Binary Tree — 이진 트리에서 임의의 경로의 최대 합계값을 구하기

## 문제의 본질

이진 트리가 주어진다. 각 노드는 정수값(음수도 가능)을 가진다. 노드끼리 엣지로 연결된 임의의 경로(각 노드는 최대 1회만 사용 가능) 중에서, 노드 값의 합계가 최대가 되는 경로를 찾아 그 **합계값**을 반환한다. 경로는 루트를 지날 필요가 없으며, 임의의 노드에서 임의의 노드로의 경로이면 된다.

## 핵심 아이디어

각 노드에서 "왼쪽 자손으로부터 얻을 수 있는 최대 이득"과 "오른쪽 자손으로부터 얻을 수 있는 최대 이득"을 계산하고, 해당 노드를 꼭짓점으로 하여 좌우를 잇는 경로의 합계를 글로벌 최대값의 후보로 삼는다. 한편, 부모에게 반환하는 값은 좌우 중 한쪽 가지만 선택한다(경로는 분기할 수 없기 때문이다).

## 사고 과정

1. **경로의 구조를 생각한다**: 임의의 경로에는 반드시 "가장 높은 위치에 있는 노드(꼭짓점)"가 하나 존재한다. 해당 노드에서 보면, 경로는 "왼쪽 자손으로 내려가는 부분", "자기 자신", "오른쪽 자손으로 내려가는 부분"의 3가지로 구성된다. 모든 노드를 꼭짓점으로 시도하여 최대 경로 합계를 구하면 된다
2. **각 노드에서의 이득(gain)을 정의한다**: 어떤 노드를 루트로 하는 서브트리에서, 부모 방향으로 가져갈 수 있는 최대 합계값을 "이득"이라고 부른다. 이득은 "자신의 값 + 좌우 중 더 큰 쪽 자식의 이득"으로 계산한다. 경로는 분기할 수 없기 때문에, 좌우 양쪽을 동시에 부모에게 반환할 수 없다
3. **음수 이득은 0으로 처리한다**: 자식의 이득이 음수인 경우, 해당 가지를 포함하면 경로의 합계가 줄어든다. 따라서 `Math.max(0, gain)`을 사용하여, 음수 이득을 0(해당 가지를 사용하지 않음)으로 올림한다. 이를 통해 노드 단독 경로나 한쪽 가지만 사용하는 경로도 자연스럽게 표현할 수 있다
4. **글로벌 최대값을 별도로 관리한다**: 각 노드를 꼭짓점으로 한 "왼쪽 이득 + 자신의 값 + 오른쪽 이득"이 해당 노드를 지나는 최대 경로의 합계이다. 이 값을 글로벌 변수 `maxSum`과 비교하여 갱신한다. 부모에게 반환하는 이득과는 별개의 계산이므로, 독립적으로 관리해야 한다
5. **후위 순회 DFS(postorder DFS)로 계산한다**: 자식의 이득을 알아야 자신의 계산을 할 수 있으므로, 왼쪽→오른쪽→자신 순서로 처리하는 후위 순회 DFS가 적합하다. 이를 통해 한 번의 순회로 모든 노드를 꼭짓점으로 시도할 수 있다
6. **최종적으로 반환하는 것**: DFS 완료 후, `maxSum`에는 모든 노드를 꼭짓점으로 시도한 것 중 최대 경로 합계가 저장되어 있다. 이 값을 반환한다

## 사전 지식

### 이진 트리의 후위 순회 DFS(Postorder DFS)란

이진 트리를 "왼쪽 자식→오른쪽 자식→자기 자신" 순서로 재귀적으로 방문하는 순회 방법이다. 자식의 계산 결과를 사용하여 부모의 계산을 수행하는 경우에 적합하다.

```java
void postorder(TreeNode node) {
    if (node == null) return;     // 베이스 케이스: null이면 아무것도 하지 않는다
    postorder(node.left);         // 왼쪽 서브트리를 먼저 처리한다
    postorder(node.right);        // 오른쪽 서브트리를 다음으로 처리한다
    // 여기서 node 자체의 처리를 수행한다(자식의 결과가 이미 확정되어 있다)
}
```

### Math.max란

두 값 중 더 큰 쪽을 반환하는 Java의 표준 메서드이다. 음수 이득을 0으로 올림하는 처리나, 좌우 이득의 비교에 사용한다.

```java
Math.max(0, -5);    // → 0(음수 값을 0으로 올림한다)
Math.max(3, 7);     // → 7(더 큰 쪽을 반환한다)
Math.max(0, gain(node.left));  // 왼쪽 자식의 이득이 음수이면 0으로 만든다
```

### Integer.MIN_VALUE란

Java의 `int` 타입이 가질 수 있는 최솟값(-2,147,483,648)이다. 최대값을 구하는 알고리즘에서 초기값으로 사용한다. 어떤 값과 비교해도 반드시 갱신되는 것이 보장된다.

```java
int maxSum = Integer.MIN_VALUE;  // 어떤 경로 합계보다도 작은 초기값
maxSum = Math.max(maxSum, 10);   // → 10(첫 번째 비교에서 반드시 갱신된다)
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 각 노드를 1회씩 방문하는 DFS를 수행한다 |
| Space | O(n) — 재귀 호출의 콜 스택이 최악의 경우(편향된 트리) n단이 된다 |

## 코드

```java
// 입력: 이진 트리의 루트 노드 root(각 노드는 정수값 val, 왼쪽 자식 left, 오른쪽 자식 right를 가진다)
// 출력: 이진 트리 내 임의의 경로에서의 최대 합계값을 int로 반환한다
class Solution {
    // 모든 노드를 꼭짓점으로 시도한 것 중 최대 경로 합계를 기록한다
    // Integer.MIN_VALUE로 초기화하여, 어떤 음수 값의 경로보다도 작게 함으로써 첫 번째 비교에서 반드시 갱신되도록 한다
    int maxSum = Integer.MIN_VALUE;

    // 노드에서 부모 방향으로 가져갈 수 있는 최대 이득을 반환하는 재귀 함수(후위 순회 DFS로 자식→부모 순서로 계산한다)
    int gain(TreeNode node) {
        // 베이스 케이스: null 노드의 이득은 0이다(존재하지 않는 자식으로부터는 아무것도 얻을 수 없다)
        if (node == null) return 0;

        // 왼쪽 자식의 이득을 취득하고, 음수이면 0으로 올림한다(음수 가지를 사용하면 경로 합계가 줄어들므로 사용하지 않는 선택을 한다)
        int leftGain = Math.max(0, gain(node.left));
        // 오른쪽 자식의 이득을 취득하고, 마찬가지로 음수이면 0으로 올림한다
        int rightGain = Math.max(0, gain(node.right));

        // 현재 노드를 꼭짓점으로 하여 좌우를 잇는 경로의 합계로 글로벌 최대값을 갱신한다
        // 이 값은 "왼쪽 자손→현재 노드→오른쪽 자손" 경로의 합계를 나타낸다
        // leftGain이나 rightGain이 0인 경우는 한쪽 가지만, 또는 노드 단독 경로를 의미한다
        maxSum = Math.max(maxSum, node.val + leftGain + rightGain);

        // 부모에게 반환하는 이득은 좌우 중 더 큰 쪽의 가지만 선택한다
        // 경로는 한붓그리기처럼 연속되어야 하며, 하나의 노드에서 분기할 수 없으므로 양쪽을 반환할 수 없다
        return node.val + Math.max(leftGain, rightGain);
    }

    int maxPathSum(TreeNode root) {
        // 루트에서 재귀적으로 DFS를 시작하여, 모든 노드를 꼭짓점으로 시도한다
        gain(root);
        // DFS 완료 후, maxSum에는 모든 노드를 꼭짓점으로 시도한 경로 중 최대 합계값이 저장되어 있다
        return maxSum;
    }
}
```
