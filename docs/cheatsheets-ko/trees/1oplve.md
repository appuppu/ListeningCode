# Finding the Diameter of a Binary Tree — 이진 트리에서 가장 긴 경로(간선의 수)를 구하기

## 문제의 본질

이진 트리의 `root`가 주어진다. 트리에서 임의의 두 노드 사이의 경로 중 가장 긴 경로의 길이(간선의 수)를 반환한다. 이 경로는 루트를 지날 필요가 없다.

## 핵심 아이디어

임의의 노드에서 「왼쪽 서브트리의 높이 + 오른쪽 서브트리의 높이 + 2」가 해당 노드를 경유하는 최장 경로의 간선 수가 된다. DFS로 각 노드의 높이를 구하면서 이 값의 최댓값을 추적하면, 한 번의 순회로 지름을 구할 수 있다.

## 사고 프로세스

1. **지름은 어떤 노드를 「꼭짓점」으로 통과한다**: 최장 경로는 반드시 하나의 노드를 가장 높은 위치(꺾이는 지점)로 삼아, 해당 노드의 왼쪽 서브트리 어딘가에서 오른쪽 서브트리 어딘가로 향하는 형태가 된다. 따라서 각 노드에 대해 「해당 노드를 꼭짓점으로 하는 경로의 길이」를 구하고, 그 최댓값이 지름이 된다
2. **꼭짓점을 지나는 경로의 길이는 좌우 높이로 결정된다**: 어떤 노드를 꼭짓점으로 하는 경로의 간선 수는 「왼쪽 서브트리의 높이 + 오른쪽 서브트리의 높이 + 2」로 계산할 수 있다. 왼쪽 높이는 가장 깊은 왼쪽 노드까지의 간선 수이고, 오른쪽 높이는 가장 깊은 오른쪽 노드까지의 간선 수이며, 꼭짓점에서 좌우로 각각 1개의 간선이 추가되므로 +2가 된다
3. **높이의 정의를 「간선의 수」에 맞춘다**: 노드의 높이를 「해당 노드에서 가장 먼 리프까지의 간선 수」로 정의하면, 리프 노드의 높이는 0, null 노드의 높이는 -1이 된다. null을 -1로 설정함으로써 리프 노드의 높이가 `1 + max(-1, -1) = 0`으로 자연스럽게 계산된다
4. **DFS로 높이를 반환하면서 지름을 갱신한다**: 후위 순회(포스트오더) DFS를 사용하여, 각 노드에서 좌우 자식의 높이를 재귀적으로 가져온다. 가져온 좌우 높이로부터 「해당 노드를 꼭짓점으로 하는 경로의 길이」를 계산하여 전역 변수 `maxDiameter`를 갱신하고, 반환값으로는 해당 노드 자신의 높이 `1 + max(left, right)`를 반환한다
5. **전역 변수로 최댓값을 추적한다**: DFS의 반환값은 「높이」이지 「지름」이 아니므로, 지름의 최댓값은 전역 변수 `maxDiameter`에 기록한다. 각 노드에서 `left + right + 2`와 현재의 `maxDiameter`를 비교하여 더 큰 값을 유지한다
6. **최종적으로 반환하는 값**: DFS가 모든 노드를 순회한 후, `maxDiameter`에 저장된 값이 트리 전체의 지름이다

## 전제 지식

### 이진 트리의 높이(height)란

어떤 노드에서 가장 먼 리프 노드까지의 경로에 포함된 간선의 수이다. 리프 노드의 높이는 0, null 노드의 높이는 -1로 정의한다. 부모 노드의 높이는 `1 + max(왼쪽 자식의 높이, 오른쪽 자식의 높이)`로 구한다.

```
      1          노드 1의 높이: 2 (1→2→4의 간선 수)
     / \         노드 2의 높이: 1 (2→4의 간선 수)
    2   3        노드 3의 높이: 0 (리프 노드)
   /             노드 4의 높이: 0 (리프 노드)
  4
```

### 재귀를 이용한 DFS(깊이 우선 탐색)란

트리의 각 노드를 재귀적으로 방문하는 기법이다. 후위 순회(포스트오더)에서는 왼쪽 자식 → 오른쪽 자식 → 자기 자신의 순서로 처리한다. 자식의 결과를 사용하여 부모의 값을 계산하는 경우에 적합하다.

```java
int dfs(TreeNode node) {
    if (node == null) return -1;   // 기저 조건: null 노드의 높이는 -1이다
    int left = dfs(node.left);     // 왼쪽 서브트리를 재귀적으로 처리한다
    int right = dfs(node.right);   // 오른쪽 서브트리를 재귀적으로 처리한다
    return 1 + Math.max(left, right);  // 자신의 높이를 계산하여 반환한다
}
```

### Math.max란

두 값 중 더 큰 값을 반환하는 Java의 표준 메서드이다.

```java
Math.max(3, 5);    // → 5
Math.max(-1, -1);  // → -1
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 모든 노드를 한 번씩 방문하는 DFS를 1회 수행하는 것만으로 충분하다 |
| Space | O(n) — 재귀 호출의 콜 스택이 최대 n단(편향된 트리의 경우)이 된다 |

## 코드

```java
// 입력: 이진 트리의 루트 노드 root
// 출력: 트리의 지름(임의의 두 노드 사이의 최장 경로의 간선 수)을 int로 반환한다

// DFS 순회 중에 발견된 최대 지름을 보관하는 전역 변수
// 초깃값이 0인 이유는 노드가 하나뿐인 트리의 지름이 0이기 때문이다
int maxDiameter = 0;

// 각 노드의 높이를 반환하면서 부수 효과로 maxDiameter를 갱신하는 재귀 함수
int dfs(TreeNode node) {
    // null 노드의 높이는 -1이다(간선이 존재하지 않음을 나타낸다)
    // -1을 반환함으로써 부모(리프 노드)의 높이가 1 + max(-1, -1) = 0으로 올바르게 구해진다
    if (node == null) return -1;

    // 왼쪽 서브트리의 높이를 재귀적으로 가져온다
    int left = dfs(node.left);
    // 오른쪽 서브트리의 높이를 재귀적으로 가져온다
    int right = dfs(node.right);

    // 현재 노드를 꼭짓점으로 하는 경로의 간선 수(left + right + 2)로 지름의 최댓값을 갱신한다
    // +2는 현재 노드에서 좌우 자식으로의 2개의 간선을 더하기 위함이다
    maxDiameter = Math.max(
        maxDiameter,
        left + right + 2);

    // 현재 노드의 높이를 부모에게 반환한다(이것은 지름이 아니라 높이임에 주의한다)
    // 부모 노드가 자신의 경로 길이를 계산하기 위해 사용하는 값이다
    return 1 + Math.max(left, right);
}

public int diameterOfBinaryTree(TreeNode root) {
    // DFS로 모든 노드를 순회하여 각 노드를 꼭짓점으로 하는 경로의 길이로부터 maxDiameter를 갱신한다
    dfs(root);
    // 순회 완료 후의 maxDiameter가 트리 전체의 지름이다
    return maxDiameter;
}
```
