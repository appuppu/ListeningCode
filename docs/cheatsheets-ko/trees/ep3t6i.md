# Viewing a Binary Tree From the Right Side — 이진 트리를 오른쪽에서 보았을 때 보이는 노드의 값을 반환하기

## 문제의 본질

이진 트리의 `root`가 주어진다. 트리를 오른쪽에서 바라보았을 때, 각 깊이에서 가장 오른쪽에 있는 노드만 보인다. 해당 노드의 값을 위(root)에서 아래로 순서대로 나열한 `List<Integer>`를 반환한다.

## 핵심 아이디어

DFS로 오른쪽 자식을 먼저 방문하면, 각 깊이에서 처음으로 도달하는 노드가 반드시 "오른쪽에서 보이는 노드"가 된다. 깊이와 결과 리스트의 크기를 비교하는 것만으로, 해당 노드가 각 깊이에서 최초 방문인지 여부를 판정할 수 있다.

## 사고 과정

1. **오른쪽에서 보이는 노드란 무엇인가**: 각 깊이에서 가장 오른쪽에 위치하는 노드가 "오른쪽에서 보이는 노드"이다. 즉, 깊이마다 하나씩 노드를 선택하는 문제로 귀결할 수 있다
2. **오른쪽 자식을 먼저 방문하는 DFS를 생각한다**: DFS로 트리를 순회할 때, 오른쪽 자식을 왼쪽 자식보다 먼저 재귀 호출하면, 각 깊이에서 가장 오른쪽 노드에 최초로 도달한다. 이 성질을 이용하면, 각 깊이에서 처음 방문한 노드만 기록하면 된다
3. **"각 깊이에서 최초 방문"을 어떻게 판정하는가**: 결과 리스트 `result`의 크기는 "지금까지 기록한 깊이의 수"를 나타낸다. 현재의 `depth`가 `result.size()`와 같으면, 해당 깊이의 노드가 아직 기록되지 않았음을 의미한다. 이 조건이 성립할 때만 `result.add(node.val)`을 수행한다
4. **재귀의 구조**: 각 노드에서 "깊이가 새로우면 값을 기록" → "오른쪽 자식을 재귀" → "왼쪽 자식을 재귀" 순서로 처리한다. 오른쪽 자식을 먼저 방문하므로, 오른쪽 노드가 각 깊이에서 우선적으로 기록된다
5. **베이스 케이스**: 노드가 `null`일 때, 아무 작업도 하지 않고 `return`한다. 이를 통해 리프 노드를 넘어선 재귀가 자연스럽게 종료된다
6. **최종적으로 반환하는 것**: DFS 완료 후, `result` 리스트에는 깊이 0부터 순서대로 오른쪽에서 보이는 노드의 값이 저장되어 있다. 이 리스트를 그대로 반환한다

## 사전 지식

### DFS(깊이 우선 탐색)란

트리나 그래프를 순회하는 알고리즘 중 하나이다. 특정 노드에서 출발하여, 갈 수 있는 곳까지 깊이 진행한 뒤 되돌아온다(백트래킹한다). 재귀를 사용하면 자연스럽게 구현할 수 있다.

```java
void dfs(TreeNode node) {
    if (node == null) return;  // 베이스 케이스: null이면 아무 작업도 하지 않는다
    // node에 대한 처리를 여기서 수행한다
    dfs(node.left);   // 왼쪽 자식을 재귀적으로 순회한다
    dfs(node.right);  // 오른쪽 자식을 재귀적으로 순회한다
}
```

### List의 size()와 add()

`List`는 가변 길이 배열이다. `size()`는 현재 요소 수를 반환하고, `add()`는 끝에 요소를 추가한다. 요소는 추가된 순서대로 인덱스 0, 1, 2...로 나열된다.

```java
List<Integer> list = new ArrayList<>();  // 빈 리스트를 생성한다
list.size();      // 현재 요소 수를 반환한다 → 0
list.add(5);      // 끝에 5를 추가한다 → [5]
list.add(3);      // 끝에 3을 추가한다 → [5, 3]
list.size();      // → 2
```

### depth(깊이)란

트리의 루트에서 해당 노드까지의 간선 수이다. 루트의 깊이는 0, 루트의 자식 깊이는 1, 손자의 깊이는 2이다. 재귀 호출 시 `depth + 1`을 전달함으로써 각 노드의 깊이를 추적할 수 있다.

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 모든 노드를 한 번씩 방문한다 |
| Space | O(h) — 재귀 콜 스택이 트리의 높이만큼 필요하다 (h는 트리의 높이) |

## 코드

```java
// 입력: 이진 트리의 루트 노드 root
// 출력: 오른쪽에서 보이는 노드의 값을 위에서 아래로 순서대로 저장한 List<Integer>
List<Integer> rightSideView(TreeNode root) {
    // 각 깊이의 가장 오른쪽 노드 값을 저장하는 리스트
    // 리스트의 인덱스가 깊이에 대응한다 (index 0 = depth 0)
    List<Integer> result = new ArrayList<>();
    dfs(root, 0, result);
    // DFS 완료 후, result에는 깊이 0부터 순서대로 오른쪽에서 보이는 노드의 값이 저장되어 있다
    return result;
}

void dfs(TreeNode node, int depth,
         List<Integer> result) {
    // 베이스 케이스: null이면 아무 작업도 하지 않는다 (리프 노드 너머의 존재하지 않는 자식에 대한 재귀가 종료된다)
    if (node == null) return;

    // depth == result.size()이면, 이 깊이의 노드는 아직 미기록 상태이다
    // result.size()는 "지금까지 기록된 깊이의 수"를 나타낸다
    if (depth == result.size()) {
        // 오른쪽 자식을 먼저 방문하는 DFS이므로, 각 깊이에서 최초로 도달하는 노드는 반드시 가장 오른쪽 노드이다
        result.add(node.val);
    }

    // 오른쪽 자식을 먼저 방문함으로써, 각 깊이의 가장 오른쪽 노드가 최초로 기록된다
    // 이것이 이 알고리즘의 핵심이다: 오른쪽 → 왼쪽 순서로 방문한다
    dfs(node.right, depth + 1, result);
    // 오른쪽 자식이 존재하지 않는 깊이에서는, 왼쪽 자식이 "해당 깊이에서 최초로 방문되는 노드"가 되어 올바르게 기록된다
    dfs(node.left, depth + 1, result);
}
```
