# Counting Good Nodes in a Binary Tree — 이진 트리에서 "좋은 노드"의 개수를 세기

## 문제의 본질

이진 트리가 주어진다. 루트에서 해당 노드까지의 경로 상에 있는 모든 값 중에서, 해당 노드의 값이 최댓값 이상이면 "좋은 노드(good node)"로 간주한다. 트리 전체에서 좋은 노드가 몇 개인지를 반환한다.

## 핵심 아이디어

루트에서 각 노드로 향하는 도중에 "지금까지의 최댓값"을 전달하면, 각 노드가 좋은 노드인지 여부를 O(1)로 판정할 수 있다. DFS로 트리를 순회하면서 최댓값을 자식 노드에 전파하면, 모든 노드를 한 번씩만 방문하는 것으로 답을 구할 수 있다.

## 사고 과정

1. **판정 조건을 정리한다**: 어떤 노드가 좋은 노드인지는, 루트에서 해당 노드까지의 경로 상의 최댓값과 비교하는 것만으로 결정된다. 즉, 경로 상의 최댓값만 알면 판정할 수 있다
2. **경로 상의 최댓값을 어떻게 관리할 것인가**: DFS로 트리를 순회하면, 재귀 호출 스택이 루트에서 현재 노드까지의 경로에 대응한다. 재귀의 인자로 "지금까지의 최댓값"을 전달하면, 각 노드에서 판정에 필요한 정보를 얻을 수 있다
3. **각 노드에서의 처리를 결정한다**: 현재 노드의 값이 최댓값 이상이면 좋은 노드이므로 1을, 그렇지 않으면 0을 결과에 가산한다. 이렇게 하면 판정과 계수를 동시에 수행할 수 있다
4. **자식 노드에 전달할 최댓값을 갱신한다**: 자식 노드에 전달할 최댓값은, 현재의 최댓값과 현재 노드의 값 중 큰 쪽으로 설정한다. 이를 통해 경로가 길어짐에 따라 최댓값이 단조 비감소로 갱신된다
5. **왼쪽과 오른쪽 서브트리를 재귀적으로 처리한다**: 왼쪽 서브트리의 좋은 노드 수와 오른쪽 서브트리의 좋은 노드 수를 재귀로 구하고, 현재 노드의 결과와 합산하여 반환한다
6. **초기 호출의 최댓값**: 루트 노드는 항상 좋은 노드이다(경로 상에 자기 자신만 존재한다). 초기값을 `Integer.MIN_VALUE`로 설정하면, 루트의 값은 반드시 그 이상이 되므로 올바르게 판정된다

## 사전 지식

### 재귀적 DFS(깊이 우선 탐색)란

트리나 그래프를 깊은 방향으로 우선하여 순회하는 알고리즘이다. 이진 트리에서는, 재귀 함수가 자기 자신을 왼쪽 자식과 오른쪽 자식에 대해 호출함으로써 구현한다. 재귀 호출 스택이 루트에서 현재 노드까지의 경로를 암묵적으로 유지한다.

```java
void dfs(TreeNode node) {
    if (node == null) return;  // 베이스 케이스: null 노드에 도달하면 반환한다
    // 현재 노드에 대한 처리
    dfs(node.left);            // 왼쪽 서브트리를 재귀적으로 순회한다
    dfs(node.right);           // 오른쪽 서브트리를 재귀적으로 순회한다
}
```

### Math.max란

두 값 중 큰 쪽을 반환하는 메서드이다. 경로 상의 최댓값을 갱신할 때 사용한다.

```java
Math.max(5, 3);    // → 5 (5와 3 중 큰 쪽을 반환한다)
Math.max(-1, 4);   // → 4
```

### Integer.MIN_VALUE란

Java의 `int` 타입이 가질 수 있는 최솟값(-2,147,483,648)이다. 어떤 노드의 값이든 이 값 이상이 되므로, 초기 최댓값으로 사용하면 루트 노드가 반드시 좋은 노드로 판정된다.

```java
Integer.MIN_VALUE;  // → -2147483648 (int 타입의 최솟값)
```

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 모든 노드를 한 번씩 방문한다 |
| Space | O(h) — 재귀 호출 스택이 트리의 높이만큼 사용된다 |

## 코드

```java
// 입력: 이진 트리의 루트 노드 root
// 출력: 좋은 노드의 총 개수를 int로 반환한다

// 헬퍼 함수: node를 루트로 하는 서브트리의 좋은 노드 수를 반환한다
// maxSoFar는 루트에서 현재 노드까지의 경로 상의 최댓값을 나타낸다
private int dfs(TreeNode node, int maxSoFar) {
    // 베이스 케이스: null에 도달하면 좋은 노드는 0개이다 (리프 노드의 끝이므로 셀 노드가 없다)
    if (node == null) return 0;

    // 현재 노드가 좋은 노드인지 판정한다 (경로 상의 최댓값 이상이면 좋은 노드이다)
    int result = node.val >= maxSoFar ? 1 : 0;

    // 자식 노드에 전달할 최댓값을 갱신한다 (현재 노드의 값이 크면 갱신하고, 그렇지 않으면 기존 최댓값을 그대로 사용한다)
    int newMax = Math.max(maxSoFar, node.val);

    // 왼쪽 서브트리의 좋은 노드 수를 재귀적으로 구하여 가산한다
    result += dfs(node.left, newMax);
    // 오른쪽 서브트리의 좋은 노드 수를 재귀적으로 구하여 가산한다
    result += dfs(node.right, newMax);

    // 현재 노드를 루트로 하는 서브트리 전체의 좋은 노드 수를 반환한다
    return result;
}

public int goodNodes(TreeNode root) {
    // 초기 최댓값을 int 최솟값으로 설정하여, 루트 노드가 반드시 좋은 노드로 판정되도록 한다
    return dfs(root, Integer.MIN_VALUE);
}
```
