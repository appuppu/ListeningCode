# Inverting a Binary Tree — 이진 트리의 모든 노드에서 왼쪽과 오른쪽 자식을 교환하기

## 문제의 본질

이진 트리의 루트 노드 `root`가 주어진다. 트리의 **모든 노드**에서 왼쪽 자식과 오른쪽 자식을 교환(반전)하고, 반전된 트리의 루트 노드를 반환한다.

## 핵심 아이디어

이진 트리의 반전이란, 모든 노드에서 왼쪽과 오른쪽 자식을 교환하는 연산이다. BFS로 레벨 순서대로 모든 노드를 방문하고, 각 노드에서 왼쪽과 오른쪽 자식을 swap하면 트리 전체가 반전된다.

## 사고 프로세스

1. **반전의 정의를 이해한다**: 이진 트리의 반전이란, 루트 노드뿐만 아니라 모든 노드에서 왼쪽 자식과 오른쪽 자식을 교환하는 연산이다. 즉, 트리의 모든 노드를 한 번씩 방문하여 각 노드에서 swap 처리를 수행하면 된다
2. **모든 노드를 방문하는 방법을 선택한다**: 트리의 모든 노드를 방문하는 방법으로 BFS(너비 우선 탐색)를 사용한다. BFS는 큐를 사용하여 레벨 순서대로 노드를 처리하므로, 구현이 직관적이고 이해하기 쉽다
3. **각 노드에서의 연산을 결정한다**: 큐에서 꺼낸 각 노드에 대해, `left`와 `right`를 임시 변수를 사용하여 swap한다. swap의 순서는 상관없으며, 자식이 null이어도 swap 자체는 문제없이 수행할 수 있다
4. **자식 노드를 큐에 추가한다**: swap한 후의 왼쪽과 오른쪽 자식이 null이 아니면 큐에 추가한다. 이렇게 하면 트리의 하위 레벨 노드도 순차적으로 방문되어, 모든 노드에서 swap이 실행된다
5. **최종적으로 반환하는 것**: 모든 노드의 swap이 완료된 후, 원래의 루트 노드 `root`를 그대로 반환한다. 트리의 구조는 변경되지만, 루트 노드 자체는 동일한 객체이다

## 전제 지식

### 이진 트리(Binary Tree)란

각 노드가 최대 2개의 자식(왼쪽 자식 `left`와 오른쪽 자식 `right`)을 가지는 트리 구조이다. 노드는 `TreeNode` 클래스로 표현되며, `val`(값), `left`(왼쪽 자식), `right`(오른쪽 자식) 필드를 가진다.

```java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

### Queue(큐)란

선입선출(FIFO) 데이터 구조이다. 가장 먼저 추가한 요소가 가장 먼저 꺼내진다. BFS에서는 큐를 사용하여 방문해야 할 노드를 관리한다.

```java
Queue<TreeNode> queue = new LinkedList<>();  // 빈 큐를 생성한다
queue.add(node);     // 큐의 끝에 node를 추가한다
queue.poll();        // 큐의 맨 앞 요소를 꺼내서 반환한다
queue.isEmpty();     // 큐가 비어 있는지 boolean으로 반환한다 → true/false
```

### BFS(너비 우선 탐색)란

트리나 그래프를 "레벨 순서"로 탐색하는 알고리즘이다. 큐를 사용하여, 현재 노드를 처리한 후 그 자식 노드를 큐에 추가함으로써, 얕은 레벨부터 순서대로 모든 노드를 방문한다.

## 계산량

| | 값 |
|---|---|
| Time | O(n) — 트리의 모든 노드를 한 번씩 방문한다 |
| Space | O(n) — 큐에 최대 n개의 노드가 저장된다 |

## 코드

```java
// 입력: 이진 트리의 루트 노드 root
// 출력: 모든 노드의 왼쪽과 오른쪽 자식을 교환한 후의 루트 노드 root를 반환한다
public TreeNode invertTree(TreeNode root) {
    // 트리가 비어 있으면 null을 반환한다. 트리가 존재하지 않으므로 그대로 종료한다
    if (root == null) return null;

    // BFS용 큐를 생성하고, 루트 노드를 추가한다
    // 이 큐는 앞으로 왼쪽과 오른쪽의 swap을 수행해야 할 노드를 관리한다
    Queue<TreeNode> queue = new LinkedList<>();
    queue.add(root);

    // 큐가 빌 때까지(= 모든 노드를 처리할 때까지) 반복한다
    while (!queue.isEmpty()) {
        // 큐의 맨 앞에서 swap 대상 노드를 꺼낸다
        TreeNode curr = queue.poll();

        // 임시 변수를 사용하여 왼쪽과 오른쪽 자식을 교환한다
        // 주의: 임시 변수를 사용하지 않고 직접 대입하면, 한쪽 참조가 덮어씌워져 사라진다
        TreeNode temp = curr.left;
        curr.left = curr.right;
        curr.right = temp;

        // swap한 후의 자식이 null이 아니면 큐에 추가한다
        // null인 노드는 더 이상 처리할 자식을 가지지 않으므로 추가할 필요가 없다
        if (curr.left != null) queue.add(curr.left);
        if (curr.right != null) queue.add(curr.right);
    }

    // 모든 노드의 swap이 완료된 루트 노드를 반환한다
    // 트리의 구조는 변경되지만, 루트 노드 자체는 동일한 객체이다
    return root;
}
```
