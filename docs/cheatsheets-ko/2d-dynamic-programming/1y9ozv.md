# Maximizing Coins From Bursting Balloons — 풍선을 터뜨리는 순서를 최적화하여 코인을 최대화하기

## 문제의 본질

정수 배열 `nums`(각 풍선의 값)가 주어진다. 풍선 `i`를 터뜨리면 `nums[left] * nums[i] * nums[right]`(left와 right는 인접한 나머지 풍선)만큼의 코인을 획득한다. 모든 풍선을 터뜨렸을 때 얻을 수 있는 코인의 최댓값을 반환한다. 배열의 경계 밖은 값 `1`로 취급한다.

## 핵심 아이디어

풍선을 "어떤 순서로 터뜨릴 것인가"가 아니라, 구간 `[left, right]` 안에서 "어떤 풍선을 **마지막으로** 터뜨릴 것인가"로 역발상하여 생각한다. 마지막으로 터뜨리는 풍선 `k`를 고정하면, 좌우의 부분 구간은 서로 독립적이 되며, 구간 DP로 최적해를 합성할 수 있다.

## 사고 과정

1. **터뜨리는 순서의 의존 관계를 해소하고 싶다**: 풍선을 터뜨리면 인접 관계가 바뀌기 때문에, 터뜨리는 순서에 따라 획득하는 코인이 달라진다. 순서를 전수 탐색하면 `n!`가지가 되어 현실적이지 않다. 이 의존 관계를 끊어내는 관점이 필요하다
2. **"마지막으로 터뜨린다"고 생각하면 구간이 독립적이 된다**: 구간 `[left, right]` 안에서 풍선 `k`를 마지막으로 터뜨린다고 결정하면, `k`를 터뜨리는 시점에서 `[left, k-1]`과 `[k+1, right]`의 풍선은 모두 사라져 있다. 즉 `k`의 인접 풍선은 구간 바깥에 있는 `arr[left-1]`과 `arr[right+1]`로 고정된다. 좌우의 부분 문제가 독립적이 되므로, DP로 합성할 수 있다
3. **경계 처리를 간결하게 한다**: 원래 배열의 양 끝에 값 `1`의 가상 풍선을 추가한 새로운 배열 `arr`을 만든다. `arr[0] = 1`, `arr[n+1] = 1`로 설정함으로써, 경계 조건을 특별 처리하지 않고 `arr[left-1] * arr[k] * arr[right+1]` 수식을 통일적으로 사용할 수 있다
4. **DP 테이블의 정의**: `dp[left][right]`를 "구간 `[left, right]`의 모든 풍선을 터뜨려서 얻을 수 있는 코인의 최댓값"으로 정의한다. 최종 답은 `dp[1][n]`(원래 배열 전체에 대응하는 구간)이다
5. **구간의 길이가 짧은 것부터 채운다**: 길이 1의 구간(풍선 1개)부터 시작하여, 길이 `n`의 구간까지 순서대로 DP 테이블을 채운다. 긴 구간의 값은 짧은 구간의 값에 의존하므로, 짧은 것부터 계산하면 참조 대상은 항상 계산이 완료된 상태이다
6. **각 구간에서 마지막으로 터뜨리는 풍선을 전수 탐색한다**: 구간 `[left, right]`에 대해, 마지막으로 터뜨리는 풍선 `k`를 `left`부터 `right`까지 시도한다. `k`를 마지막으로 터뜨렸을 때의 코인은 `arr[left-1] * arr[k] * arr[right+1] + dp[left][k-1] + dp[k+1][right]`이며, 이 최댓값을 `dp[left][right]`에 기록한다

## 전제 지식

### 구간 DP(Interval DP)란

구간 `[left, right]`를 단위로 DP 테이블을 구축하는 기법이다. 구간을 분할하고, 부분 구간의 최적해를 조합하여 전체의 최적해를 구한다. 짧은 구간에서 긴 구간으로 바텀업 방식으로 계산한다.

```java
// 구간 DP의 기본 구조: 구간의 길이가 짧은 것부터 순서대로 계산한다
for (int len = 1; len <= n; len++) {        // 구간의 길이
    for (int left = 1; left <= n - len + 1; left++) {  // 구간의 왼쪽 끝
        int right = left + len - 1;          // 구간의 오른쪽 끝
        // dp[left][right]를 계산한다
    }
}
```

### 센티널(Sentinel)이란

배열의 양 끝에 가상의 요소를 추가하여, 경계 조건의 특별 처리를 불필요하게 만드는 기법이다. 이 문제에서는 값 `1`의 풍선을 양 끝에 배치한다.

```java
int[] arr = new int[n + 2];   // 원래 배열보다 2개 큰 배열을 생성한다
arr[0] = 1;                   // 왼쪽 끝의 센티널(값 1)
arr[n + 1] = 1;               // 오른쪽 끝의 센티널(값 1)
for (int i = 0; i < n; i++)
    arr[i + 1] = nums[i];     // 원래 요소를 인덱스 1~n에 복사한다
```

### 2차원 배열의 DP 테이블

`dp[i][j]`로 구간 `[i, j]`의 최적해를 기록한다. Java에서는 `new int[n+2][n+2]`로 생성하면 모든 요소가 `0`으로 초기화된다. 빈 구간(`left > right`)은 `0`인 채로 두면 되므로, 초기화를 위한 추가 처리는 불필요하다.

```java
int[][] dp = new int[n + 2][n + 2];  // 모든 요소가 0으로 초기화된다
dp[left][right];                      // 구간 [left, right]의 최대 코인을 저장한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n³) — 구간의 왼쪽 끝·오른쪽 끝·마지막으로 터뜨리는 위치의 3중 루프 |
| Space | O(n²) — DP 테이블 `dp[n+2][n+2]`를 사용한다 |

## 코드

```java
// 입력: 정수 배열 nums(각 풍선의 값)
// 출력: 모든 풍선을 터뜨려서 얻을 수 있는 코인의 최댓값을 int로 반환한다
public int maxCoins(int[] nums) {
    int n = nums.length;

    // 양 끝에 센티널(값 1)을 추가한 배열을 생성한다
    // 이 센티널에 의해, 구간 바깥을 참조할 때 경계 조건을 특별 처리할 필요가 없어진다
    int[] arr = new int[n + 2];
    arr[0] = arr[n + 1] = 1;
    for (int i = 0; i < n; i++)
        arr[i + 1] = nums[i];

    // dp[left][right] = 구간 [left, right]의 풍선을 모두 터뜨려서 얻을 수 있는 코인의 최댓값
    // 크기를 n+2로 하는 이유는 센티널의 인덱스(0과 n+1)를 포함하기 위해서이다
    // 빈 구간(left > right)의 값은 0인 채로 두면 된다
    int[][] dp = new int[n + 2][n + 2];

    // 구간의 길이가 짧은 것부터 순서대로 계산한다
    // 짧은 구간부터 계산함으로써, 긴 구간을 계산할 때 필요한 부분 구간의 값이 항상 계산 완료된 상태임을 보장한다
    for (int len = 1; len <= n; len++) {
        // 길이 len인 모든 구간을 순회한다
        for (int left = 1; left <= n - len + 1; left++) {
            int right = left + len - 1;

            // 구간 [left, right]에서 마지막으로 터뜨리는 풍선 k를 전수 탐색한다
            for (int k = left; k <= right; k++) {
                // k를 마지막으로 터뜨린다고 결정했을 때, k의 인접 풍선은 구간 바깥의 arr[left-1]과 arr[right+1]로 고정된다
                int coins = arr[left - 1] * arr[k] * arr[right + 1];
                // 좌우의 부분 구간의 코인을 더하여 합계를 구한다
                int total = coins + dp[left][k - 1] + dp[k + 1][right];
                // dp[left][right]를 최댓값으로 갱신한다
                dp[left][right] = Math.max(dp[left][right], total);
            }
        }
    }

    // 원래 배열 전체(인덱스 1~n)에 대응하는 최대 코인을 반환한다
    return dp[1][n];
}
```
