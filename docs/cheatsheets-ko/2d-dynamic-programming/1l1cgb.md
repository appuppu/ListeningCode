# Finding the Longest Common Subsequence — 두 문자열에 공통되는 최장 부분 수열의 길이를 구한다

## 문제의 본질

두 문자열 `text1`과 `text2`가 주어진다. 두 문자열에 공통되는 **부분 수열(subsequence)** 중 가장 긴 것의 **길이**를 반환한다. 부분 수열이란 원래 문자열에서 문자를 선택하여 상대적인 순서를 유지한 채 추출한 수열이며, 연속할 필요는 없다.

## 핵심 아이디어

두 문자열의 마지막 문자가 일치하면 해당 문자는 LCS에 포함되고, 나머지 부분 문제는 두 문자열을 각각 1문자씩 줄인 것이 된다. 일치하지 않으면 어느 한쪽을 1문자 줄인 두 부분 문제 중 더 긴 쪽을 채택한다. 이 재귀 구조를 2차원 테이블로 바텀업 방식으로 채우면 중복 계산 없이 최적해를 구할 수 있다.

## 사고 과정

1. **부분 문제의 정의**: `text1`의 앞 `i`개 문자와 `text2`의 앞 `j`개 문자에 대한 LCS의 길이를 `dp[i][j]`로 정의한다. 최종적으로 구하고자 하는 답은 `dp[m][n]`이다(`m` = text1의 길이, `n` = text2의 길이)
2. **마지막 문자가 일치하는 경우의 전이**: `text1[i-1] == text2[j-1]`일 때, 이 문자는 LCS의 일부가 된다. 따라서 `dp[i][j] = dp[i-1][j-1] + 1`이 된다. 두 문자열을 각각 1문자씩 줄인 부분 문제의 답에 1을 더한다
3. **마지막 문자가 일치하지 않는 경우의 전이**: `text1[i-1] != text2[j-1]`일 때, 적어도 한쪽의 마지막 문자는 LCS에 포함되지 않는다. `text1`을 1문자 줄인 경우(`dp[i-1][j]`)와 `text2`를 1문자 줄인 경우(`dp[i][j-1]`) 중 큰 쪽을 채택한다. 즉, `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`이 된다
4. **기저 조건**: 어느 한쪽 문자열이 비어 있으면(길이 0) 공통 부분 수열이 존재하지 않으므로 `dp[0][j] = 0` 및 `dp[i][0] = 0`이 된다. Java에서 `int[][]`를 생성하면 모든 요소가 0으로 초기화되므로 명시적인 설정은 불필요하다
5. **테이블 채우는 방법**: `dp[i][j]`는 `dp[i-1][j-1]`, `dp[i-1][j]`, `dp[i][j-1]`에 의존한다. 따라서 `i`를 1부터 m까지, `j`를 1부터 n까지 오름차순으로 채우면 참조 대상은 항상 이미 계산된 상태이다
6. **최종적으로 반환하는 것**: 테이블을 모두 채운 후, `dp[m][n]`이 두 문자열 전체의 LCS 길이이며, 이 값을 반환한다

## 사전 지식

### 부분 수열(Subsequence)이란

문자열에서 0개 이상의 문자를 삭제하고, 남은 문자의 상대적인 순서를 바꾸지 않고 추출한 수열이다. 부분 문자열(substring)과 달리 연속할 필요는 없다.

```
문자열: "abcde"
부분 수열의 예: "ace" (a, c, e를 선택. b, d를 삭제)
부분 수열이 아닌 예: "aec" (원래 문자열에서의 순서 a→c→e에 어긋남)
```

### 2차원 배열의 생성과 초기화

Java에서 `new int[m+1][n+1]`을 선언하면 크기 `(m+1) × (n+1)`의 2차원 배열이 생성되고, 모든 요소가 0으로 초기화된다.

```java
int[][] dp = new int[m + 1][n + 1];  // (m+1)행×(n+1)열의 배열을 생성하고, 모든 요소를 0으로 초기화한다
dp[i][j] = 5;                         // i행 j열에 값 5를 대입한다
int val = dp[i][j];                    // i행 j열의 값을 가져온다 → 5
```

### Math.max란

두 정수 중 큰 쪽을 반환하는 메서드이다. 두 부분 문제의 해를 비교하여 더 나은 쪽을 선택하기 위해 사용한다.

```java
Math.max(3, 7);    // 두 값 중 큰 쪽을 반환한다 → 7
Math.max(dp[i-1][j], dp[i][j-1]);  // 두 셀의 값을 비교하여 큰 쪽을 반환한다
```

### charAt이란

문자열에서 지정한 위치의 문자를 반환하는 메서드이다. 인덱스는 0부터 시작한다.

```java
String s = "abc";
s.charAt(0);    // 인덱스 0의 문자를 반환한다 → 'a'
s.charAt(2);    // 인덱스 2의 문자를 반환한다 → 'c'
```

## 계산량

| | 값 |
|---|---|
| Time | O(m × n) — m×n 테이블의 각 셀을 1회씩 채운다 |
| Space | O(m × n) — 크기 (m+1)×(n+1)의 2차원 배열을 사용한다 |

## 코드

```java
// 입력: 두 문자열 text1과 text2
// 출력: 두 문자열의 최장 공통 부분 수열의 길이를 int로 반환한다
public int longestCommonSubsequence(String text1, String text2) {
    // text1의 길이를 m에, text2의 길이를 n에 대입한다. 테이블 크기와 루프 상한에 사용한다
    int m = text1.length();
    int n = text2.length();

    // dp[i][j] = text1의 앞 i개 문자와 text2의 앞 j개 문자의 LCS 길이
    // 크기를 (m+1)×(n+1)로 하는 이유는 어느 한쪽이 빈 문자열인 경우(기저 조건)를 표현하기 위함이다
    // Java에서는 int[][]의 모든 요소가 0으로 초기화되므로 기저 조건 dp[0][j]=0, dp[i][0]=0은 자동으로 충족된다
    int[][] dp = new int[m + 1][n + 1];

    // i는 text1의 앞 몇 개 문자를 고려하고 있는지를 나타낸다
    for (int i = 1; i <= m; i++) {
        // j는 text2의 앞 몇 개 문자를 고려하고 있는지를 나타낸다
        for (int j = 1; j <= n; j++) {
            // dp의 인덱스는 1부터 시작하지만, 문자열의 인덱스는 0부터 시작하므로 i-1, j-1로 접근한다
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                // 문자가 일치하는 경우, 일치한 문자가 LCS에 추가되므로 양쪽을 1문자씩 줄인 부분 문제의 답에 1을 더한다
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // 문자가 일치하지 않는 경우, text1을 1문자 줄인 경우와 text2를 1문자 줄인 경우 중 LCS가 긴 쪽을 채택한다
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    // 테이블 오른쪽 아래가 text1 전체와 text2 전체의 LCS 길이이다
    return dp[m][n];
}
```
