# Counting Distinct Subsequences — 문자열 s 안에서 t와 일치하는 부분 수열이 몇 개인지 세기

## 문제의 본질

두 문자열 `s`와 `t`가 주어진다. `s`에서 0개 이상의 문자를 삭제하여(남은 문자의 상대적 순서는 바꾸지 않고) `t`와 일치하는 부분 수열을 만드는 방법이 몇 가지인지 세어 반환한다.

## 핵심 아이디어

`s`의 각 문자에 대해 "`t`의 매칭에 사용할지 사용하지 않을지"의 2가지 선택지가 있다. 이 선택의 누적을 1차원 배열로 관리하고, 뒤에서부터 갱신하면 "사용하는 경우"와 "사용하지 않는 경우"의 덧셈을 올바르게 수행할 수 있다.

## 사고 과정

1. **부분 수열의 매칭은 선택의 누적이다**: `s`의 i번째 문자가 `t`의 j번째 문자와 일치할 때, "이 문자를 `t[j]`의 매칭에 사용한다"와 "사용하지 않고 건너뛴다"라는 2가지 선택지가 있다. 두 경우의 수를 합산하면 모든 패턴을 구할 수 있다
2. **DP의 상태를 정의한다**: `dp[j]`를 "`t`의 앞쪽 j개 문자와 일치하는 `s`의 부분 수열의 개수"로 정의한다. 최종적으로 `dp[n]`(n은 `t`의 길이)이 답이 된다
3. **베이스 케이스를 생각한다**: `t`의 앞쪽 0개 문자(빈 문자열)와 일치하는 부분 수열은 어떤 `s`에 대해서든 "아무것도 선택하지 않는다"라는 1가지가 존재한다. 따라서 `dp[0] = 1`이다
4. **점화식을 도출한다**: `s[i-1] == t[j-1]`일 때, `dp[j]`에는 2가지 기여가 있다. "`s[i-1]`을 사용하지 않는 경우"는 기존의 `dp[j]`가 그대로 유지되고, "`s[i-1]`을 사용하는 경우"는 `dp[j-1]`(한 문자 앞까지 매칭 완료된 개수)이 더해진다. 따라서 `dp[j] += dp[j-1]`이 된다. 문자가 일치하지 않을 때는 `dp[j]`가 변하지 않는다(건너뛰기만 가능)
5. **갱신 순서를 역순으로 하는 이유**: `dp[j] += dp[j-1]`에서는 갱신 전의 `dp[j-1]`이 필요하다. 만약 j를 작은 쪽부터 갱신하면 `dp[j-1]`이 먼저 덮어쓰여 이전 값이 사라진다. j를 큰 쪽에서 작은 쪽으로 역순으로 갱신하면 `dp[j-1]`은 아직 갱신 전의 값을 유지하고 있으므로 올바르게 계산할 수 있다
6. **최종적으로 반환하는 것**: `s`의 모든 문자를 순회한 후의 `dp[n]`이 `s` 안에서 `t`와 일치하는 부분 수열이 몇 개인지에 대한 답이다

## 사전 지식

### 부분 수열(Subsequence)이란

원래 문자열에서 0개 이상의 문자를 삭제하고, 남은 문자의 상대적 순서를 유지한 채 구성되는 문자열이다. 부분 문자열(Substring)과는 달리 연속할 필요가 없다.

```
s = "rabbbit", t = "rabbit"
부분 수열의 예: s의 1,2,3,5,6,7번째 문자를 선택 → "rabbit" ✓
부분 수열의 예: s의 1,2,4,5,6,7번째 문자를 선택 → "rabbit" ✓
부분 수열의 예: s의 1,3,4,5,6,7번째 문자를 선택 → "rabbit" ✓
→ 총 3가지
```

### 1차원 DP의 역순 갱신이란

2차원 DP 테이블 `dp[i][j]`를 1차원 배열 `dp[j]`로 압축하는 기법이다. 현재 행의 계산에 이전 행의 값만 필요한 경우, 1차원 배열을 재사용하여 공간 복잡도를 줄일 수 있다. 다만 `dp[j]`의 갱신에서 `dp[j-1]`(이전 행의 값)이 필요할 때, j를 오름차순으로 갱신하면 `dp[j-1]`이 현재 행의 값으로 덮어쓰여 버린다. j를 내림차순(큰 값→작은 값)으로 갱신하면 아직 덮어쓰이지 않은 이전 행의 `dp[j-1]`을 올바르게 참조할 수 있다.

```java
// 2차원 DP (원래 형태)
dp[i][j] = dp[i-1][j] + dp[i-1][j-1];

// 1차원 DP로 압축 (역순 갱신)
for (int j = n; j >= 1; j--) {   // 큰 쪽부터 갱신한다
    dp[j] += dp[j - 1];          // dp[j-1]은 아직 이전 행의 값을 유지하고 있다
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(m × n) — s의 각 문자(m개)에 대해 t의 각 문자(n개)를 순회한다 |
| Space | O(n) — 길이 n+1의 1차원 배열만 사용한다 |

## 코드

```java
// 입력: 문자열 s(길이 m)와 문자열 t(길이 n)
// 출력: s의 부분 수열 중 t와 일치하는 것의 개수를 int로 반환한다
public int numDistinct(String s, String t) {
    int m = s.length();
    int n = t.length();

    // dp[j] = t의 앞쪽 j개 문자와 일치하는 s의 부분 수열의 개수
    // 인덱스 0〜n의 n+1개의 상태를 관리하기 위해 크기를 n+1로 설정한다
    int[] dp = new int[n + 1];

    // 빈 문자열과 일치하는 부분 수열은 항상 1가지이다(아무것도 선택하지 않음)
    // 이 베이스 케이스는 s의 어느 위치에서 시작하더라도 성립한다
    dp[0] = 1;

    // s의 각 문자를 순서대로 고려한다(i는 s의 몇 번째 문자까지 고려했는지를 나타낸다)
    for (int i = 1; i <= m; i++) {
        // j를 역순(큰 값→작은 값)으로 순회한다
        // 이유: dp[j] += dp[j-1] 계산에서 갱신 전의 dp[j-1]을 참조해야 하기 때문이다
        // 오름차순으로 갱신하면 dp[j-1]이 먼저 덮어쓰여 이전 행의 값이 사라진다
        for (int j = n; j >= 1; j--) {
            // i, j는 1부터 시작하지만, 문자열의 인덱스는 0부터 시작하므로 i-1, j-1로 접근한다
            if (s.charAt(i - 1) == t.charAt(j - 1))
                // 일치하는 경우: dp[j](사용하지 않는 경우의 수)에 dp[j-1](사용하는 경우의 수)을 더한다
                // 이 덧셈으로 "사용한다"와 "사용하지 않는다" 두 선택지의 합계가 dp[j]에 축적된다
                dp[j] += dp[j - 1];
            // 일치하지 않는 경우: 아무것도 하지 않는다(s[i-1]은 t[j-1]의 매칭에 사용할 수 없으므로 건너뛰기만 가능하다)
        }
    }

    // dp[n]은 s 전체에서 t 전체와 일치하는 부분 수열의 개수를 보유하고 있다
    return dp[n];
}
```
