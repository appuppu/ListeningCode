# Counting Combinations to Make a Target Amount — 코인 조합으로 목표 금액을 만드는 방법의 수를 세기

## 문제의 본질

코인의 액면가가 담긴 배열 `coins`와 정수 `amount`가 주어진다. `coins` 안의 코인을 몇 개든 반복해서 사용하여 합계가 정확히 `amount`이 되는 **조합의 수**를 반환한다. 조합이 다르다는 것은 적어도 하나의 액면가의 사용 매수가 다르다는 것을 의미한다. 순서만 다른 것은 같은 조합으로 취급한다.

## 핵심 아이디어

코인을 한 종류씩 순서대로 처리하며, 각 코인에 대해 「해당 코인을 0개 이상 사용하는 경우의 조합 수」를 DP 배열에 누적해 나간다. 코인의 종류별로 바깥쪽 루프를 돌림으로써, 같은 코인 집합을 다른 순서로 세는 중복(순열)을 자연스럽게 배제할 수 있다.

## 사고 과정

1. **조합과 순열의 차이를 인식한다**: 이 문제는 「조합의 수」를 구하는 것이므로, [1,2]와 [2,1]은 같은 것으로 세야 한다. 금액을 바깥쪽 루프로 하고 코인을 안쪽에서 선택하면 순열을 세게 되므로, 코인의 종류를 바깥쪽 루프로 하여 처리 순서를 고정할 필요가 있다
2. **DP의 상태를 정의한다**: `dp[a]`를 「금액 `a`를 정확히 만드는 조합의 수」로 정의한다. 최종적으로 `dp[amount]`가 답이 된다
3. **기저 조건을 결정한다**: 금액 0을 만드는 방법은 「어떤 코인도 사용하지 않는다」라는 1가지이므로, `dp[0] = 1`로 설정한다. 이 기저가 없으면, 어떤 코인을 사용해도 조합 수가 0인 채로 더해져서 답이 항상 0이 되어 버린다
4. **전이식을 도출한다**: 어떤 코인 `coin`을 적어도 1개 사용하여 금액 `a`를 만들려면, 나머지 금액 `a - coin`의 조합 수를 더하면 된다. 즉, `dp[a] += dp[a - coin]`이 전이식이 된다. `dp[a - coin]`에는 이미 같은 코인을 0개 이상 사용한 조합 수가 포함되어 있으므로, 이 덧셈으로 「coin을 1개, 2개, …」 사용하는 경우가 자동으로 포괄된다
5. **루프의 순서를 결정한다**: 바깥쪽 루프에서 코인의 종류를 하나씩 처리하고, 안쪽 루프에서 금액 `a`를 `coin`부터 `amount`까지 오름차순으로 순회한다. 이렇게 하면, 각 코인은 「이전 코인 종류까지의 조합 수」에 자신의 기여를 더하는 형태가 되어, 순열의 중복 카운트가 발생하지 않는다
6. **최종적으로 반환하는 것**: 모든 코인의 처리를 마친 후의 `dp[amount]`가 목표 금액을 만드는 조합의 총 수이다

## 전제 지식

### DP 배열(동적 계획법의 1차원 배열)이란

부분 문제의 답을 배열에 저장하고, 그것을 재활용하여 큰 문제의 답을 효율적으로 구하는 기법이다. 이 문제에서는 `dp[a]`가 「금액 `a`를 만드는 조합의 수」를 나타낸다.

```java
int[] dp = new int[amount + 1];  // 인덱스 0~amount의 배열을 생성 (초기값은 모두 0)
dp[0] = 1;                       // 기저 조건: 금액 0을 만드는 방법은 1가지
dp[a] += dp[a - coin];           // 전이: 금액 a의 조합 수에, coin을 1개 사용한 나머지의 조합 수를 더한다
```

### 바깥쪽 루프를 코인으로 하는 이유

금액을 바깥쪽, 코인을 안쪽으로 하면, 금액 5를 만들 때 [1,2,2]와 [2,1,2]와 [2,2,1]을 각각 별도로 세게 된다(순열). 코인을 바깥쪽으로 하면, 코인 1의 처리가 완료된 후에 코인 2를 처리하므로, 「코인 1→코인 2」의 순서가 고정되어 조합만을 셀 수 있다.

```java
// 조합을 세는 경우 (올바른 순서)
for (int coin : coins) {          // 바깥쪽: 코인의 종류별로 처리
    for (int a = coin; a <= amount; a++) {  // 안쪽: 금액을 순회
        dp[a] += dp[a - coin];
    }
}

// 순열을 세게 되는 경우 (잘못된 순서)
for (int a = 1; a <= amount; a++) {         // 바깥쪽: 금액별로 처리
    for (int coin : coins) {                // 안쪽: 모든 코인을 시도
        if (a >= coin) dp[a] += dp[a - coin];
    }
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(n × amount) — n종류의 코인 각각에 대해 금액 0~amount를 순회한다 |
| Space | O(amount) — 크기 amount+1의 DP 배열을 하나만 사용한다 |

## 코드

```java
// 입력: 코인의 액면가를 저장한 정수 배열 coins와 목표 금액의 정수 amount
// 출력: 합계가 정확히 amount가 되는 코인 조합의 수를 int로 반환한다
public int change(int amount, int[] coins) {
    // dp[a] = 금액 a를 정확히 만드는 조합의 수
    // 크기는 amount + 1 (인덱스 0부터 amount까지의 각 금액에 대응하기 위함)
    int[] dp = new int[amount + 1];

    // 기저 조건: 금액 0을 만드는 방법은 「아무것도 선택하지 않는다」의 1가지
    // 이 기저가 없으면 전이에서 더하는 원래 값이 항상 0이 되어, 모든 결과가 0이 된다
    dp[0] = 1;

    // 코인의 종류별로 처리한다 (바깥쪽 루프로 순서를 고정하여 조합만을 센다)
    // 코인의 종류를 바깥쪽 루프로 함으로써, 같은 코인 집합을 다른 순서로 세는 중복(순열)을 방지한다
    for (int coin : coins) {
        // 금액 coin부터 amount까지 오름차순으로 순회한다
        // coin부터 시작하는 이유는 a - coin이 0 이상이어야 하기 때문이다
        // 오름차순으로 순회함으로써, 같은 코인을 여러 개 사용하는 경우가 자연스럽게 반영된다
        for (int a = coin; a <= amount; a++) {
            // coin을 1개 사용하고, 나머지 a-coin의 조합 수를 더한다
            // dp[a - coin]에는 같은 코인을 0개 이상 사용한 조합 수가 이미 포함되어 있으므로,
            // 이 한 줄로 「coin을 1개, 2개, 3개… 사용하는」 모든 경우가 포괄된다
            dp[a] += dp[a - coin];
        }
    }

    // 목표 금액을 만드는 조합의 총 수를 반환한다
    return dp[amount];
}
```
