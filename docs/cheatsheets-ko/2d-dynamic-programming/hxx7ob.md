# Counting Unique Paths in a Grid — 그리드의 왼쪽 상단에서 오른쪽 하단까지의 고유 경로 수를 구하기

## 문제의 본질

`m × n` 그리드가 주어진다. 왼쪽 상단 칸 `(0, 0)`에서 오른쪽 하단 칸 `(m-1, n-1)`까지, 각 단계에서 **오른쪽 또는 아래로만** 이동할 수 있을 때, 고유 경로의 총 수를 반환한다.

## 핵심 아이디어

특정 칸까지의 경로 수는 "위쪽 칸까지의 경로 수"와 "왼쪽 칸까지의 경로 수"의 합이다. 이 점화식을 바텀업 방식으로 채워나가면 답을 구할 수 있으며, 각 행의 계산은 바로 이전 행과 현재 행에만 의존하므로, 1행 분량의 배열만으로 공간을 절약할 수 있다.

## 사고 과정

1. **각 칸까지의 경로 수는 부분 문제로 분해할 수 있다**: 칸 `(i, j)`에 도달하려면, 반드시 위쪽 `(i-1, j)` 또는 왼쪽 `(i, j-1)`에서 와야 한다. 따라서 `dp[i][j] = dp[i-1][j] + dp[i][j-1]`이라는 점화식이 성립한다
2. **기저 조건을 결정한다**: 최상단 행의 칸에는 왼쪽에서만 도달할 수 있고, 최좌측 열의 칸에는 위에서만 도달할 수 있다. 두 경우 모두 경로 수는 1이므로, `dp[0][j] = 1`, `dp[i][0] = 1`로 초기화한다
3. **행별로 왼쪽에서 오른쪽으로 채워나간다**: 점화식이 의존하는 것은 "하나 위의 칸"과 "하나 왼쪽의 칸"이므로, 행을 위에서 아래로, 각 행 내를 왼쪽에서 오른쪽으로 순회하면, 필요한 값은 항상 이미 계산되어 있다
4. **공간을 1행 분량으로 압축할 수 있다**: `dp[i][j]`가 의존하는 것은 같은 행의 왼쪽 이웃 `dp[i][j-1]`과 이전 행의 같은 열 `dp[i-1][j]`뿐이다. 1차원 배열 `dp[j]`를 사용하면, 갱신 전의 `dp[j]`가 "위쪽 칸의 값"에 해당하고, 갱신 완료된 `dp[j-1]`이 "왼쪽 칸의 값"에 해당하므로, `dp[j] += dp[j-1]`로 점화식을 표현할 수 있다
5. **초기화는 모든 요소를 1로 설정한다**: 1차원 배열을 모두 1로 초기화하면, 최상단 행(모든 칸의 경로 수가 1)의 상태를 나타낸다. 최좌측 열에 해당하는 `dp[0]`은 내부 루프에서 갱신되지 않으므로 항상 1인 채로 유지되어, 최좌측 열의 기저 조건도 자연스럽게 보존된다
6. **최종적으로 반환할 값**: 모든 행의 처리가 끝난 후, `dp[n-1]`이 오른쪽 하단 칸까지의 경로 수를 보유하고 있으므로, 이 값을 반환한다

## 전제 지식

### Arrays.fill이란

배열의 모든 요소를 지정한 값으로 일괄 초기화하는 유틸리티 메서드이다. 루프를 작성하지 않고도 배열을 균일한 값으로 채울 수 있다.

```java
int[] dp = new int[5];       // 길이 5의 배열을 생성한다 (초기값은 모두 0)
Arrays.fill(dp, 1);          // 모든 요소를 1로 설정한다 → [1, 1, 1, 1, 1]
```

### 1차원 DP를 활용한 공간 압축이란

2차원 DP 테이블에서, 각 셀의 계산이 "현재 행"과 "하나 이전 행"에만 의존하는 경우, 2차원 배열을 1차원 배열로 대체할 수 있는 기법이다. 배열을 행별로 덮어쓰기 갱신함으로써, Space O(m×n)을 O(n)으로 줄인다.

```java
// 2차원의 경우: dp[i][j] = dp[i-1][j] + dp[i][j-1]
// 1차원으로 압축: dp[j] += dp[j-1]
//   dp[j] (갱신 전) = 이전 행의 같은 열 값 (= dp[i-1][j]에 해당)
//   dp[j-1] (갱신 완료) = 현재 행의 왼쪽 이웃 값 (= dp[i][j-1]에 해당)
```

## 계산량

| | 값 |
|---|---|
| Time | O(m × n) — 그리드의 모든 칸을 한 번씩 순회한다 |
| Space | O(n) — 1행 분량의 배열만을 유지한다 |

## 코드

```java
// 입력: 정수 m (행 수)과 정수 n (열 수)
// 출력: 왼쪽 상단에서 오른쪽 하단까지의 고유 경로 수를 정수로 반환한다
public int uniquePaths(int m, int n) {
    // 길이 n의 1행 분량 DP 배열을 생성하고, 모든 요소를 1로 초기화한다
    // 모두 1로 설정함으로써, 최상단 행의 기저 조건(각 칸까지의 경로 수가 1)을 설정한다
    int[] dp = new int[n];
    Arrays.fill(dp, 1);

    // i=0(최상단 행)은 초기화로 설정이 완료되었으므로 i=1부터 시작한다
    for (int i = 1; i < m; i++) {
        // j=0(최좌측 열)은 항상 1로 유지되어야 하므로 j=1부터 시작한다
        for (int j = 1; j < n; j++) {
            // dp[j] (갱신 전) = 이전 행의 같은 열 값 (위에서 오는 경로 수)
            // dp[j-1] (갱신 완료) = 현재 행의 왼쪽 이웃 값 (왼쪽에서 오는 경로 수)
            // 이 덧셈으로 점화식 dp[i][j] = dp[i-1][j] + dp[i][j-1]을 1차원 배열 위에서 구현한다
            dp[j] += dp[j - 1];
        }
    }

    // dp[n-1]은 그리드의 오른쪽 하단 칸 (m-1, n-1)까지의 고유 경로 수를 보유하고 있다
    return dp[n - 1];
}
```
