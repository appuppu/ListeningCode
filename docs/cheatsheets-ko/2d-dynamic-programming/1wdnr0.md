# Finding the Minimum Edits to Transform One String Into Another — 두 문자열 간의 최소 편집 거리를 구하기

## 문제의 본질

두 문자열 `word1`과 `word2`가 주어진다. `word1`을 `word2`로 변환하기 위해 필요한 **최소 연산 횟수**를 반환한다. 사용할 수 있는 연산은 「삽입」「삭제」「치환」의 3가지이며, 각각 1회의 연산으로 카운트한다.

## 핵심 아이디어

두 문자열의 끝에서부터 비교할 때, 현재 문자가 일치하면 연산 없이 양쪽 모두 진행하고, 불일치하면 「삽입·삭제·치환」의 3가지 연산 중 최소 비용인 것을 선택한다. 이 부분 문제의 중복을 DP 테이블로 해소하고, 또한 각 셀은 현재 행과 이전 행에만 의존하므로 1행 분량의 배열만으로 공간을 최적화할 수 있다.

## 사고 프로세스

1. **각 위치에서의 선택지는 3가지로 제한된다**: `word1[i]`와 `word2[j]`를 비교할 때, 문자가 일치하면 연산 없이 `(i+1, j+1)`로 진행한다. 불일치하면 「삽입(j를 진행)」「삭제(i를 진행)」「치환(양쪽 모두 진행)」의 3가지에서 최소 비용을 선택한다. 이 재귀적인 구조가 DP 적용을 시사한다
2. **DP 테이블의 정의**: `dp[i][j]`를 「`word1[i:]`를 `word2[j:]`로 변환하기 위한 최소 연산 횟수」로 정의한다. 최종적인 답은 `dp[0][0]`이 된다
3. **베이스 케이스를 결정한다**: `word1`의 나머지가 비어 있으면(`i == m`) `word2[j:]`의 남은 문자 수만큼 삽입이 필요하므로 `dp[m][j] = n - j`이다. `word2`의 나머지가 비어 있으면(`j == n`) `word1[i:]`의 남은 문자 수만큼 삭제가 필요하므로 `dp[i][n] = m - i`이다
4. **바텀업으로 채우는 방향을 결정한다**: `dp[i][j]`는 `dp[i+1][j+1]`, `dp[i][j+1]`, `dp[i+1][j]`에 의존하므로, `i`를 `m-1`에서 `0`으로, `j`를 `n-1`에서 `0`으로 역순으로 채운다
5. **공간을 최적화한다**: 각 행 `i`의 계산에 필요한 것은 「이전 행(`i+1`)」과 「현재 행(`i`)」의 2행뿐이다. 따라서 2차원 배열을 유지할 필요 없이, 1차원 배열 `prev`(이전 행)와 `curr`(현재 행)의 2개만으로 충분하다. 각 행의 계산이 끝나면 `prev = curr`로 교체한다
6. **최종적으로 반환하는 값**: 모든 행을 처리한 후, `prev[0]`이 `dp[0][0]`에 해당하는 값이며, 이것이 `word1` 전체를 `word2` 전체로 변환하는 최소 연산 횟수이다

## 사전 지식

### Edit Distance(편집 거리)란

두 문자열 간의 「유사도」를 나타내는 지표로, 한쪽을 다른 쪽으로 변환하기 위해 필요한 최소 연산 횟수를 의미한다. Levenshtein 거리라고도 불린다. 허용되는 연산은 다음 3가지이며, 각각 비용은 1이다.

- **삽입(Insert)**: 문자열에 1문자를 추가한다
- **삭제(Delete)**: 문자열에서 1문자를 제거한다
- **치환(Replace)**: 문자열의 1문자를 다른 문자로 변경한다

### 바텀업 DP(동적 계획법)란

재귀적인 부분 문제를 작은 문제부터 순서대로 테이블에 기록하면서 푸는 기법이다. 메모이제이션 재귀(탑다운)와 달리 재귀 호출의 오버헤드가 없고, 공간 최적화도 적용하기 쉽다.

```java
// 1차원 DP의 예: 피보나치 수열을 2개의 변수로 계산한다
int a = 0, b = 1;
for (int i = 2; i <= n; i++) {
    int temp = a + b;  // 현재 값은 이전 2개에만 의존한다
    a = b;             // 오래된 값을 버리고 갱신한다
    b = temp;
}
```

### Math.min()이란

두 정수 중 작은 쪽을 반환하는 Java의 표준 메서드이다. 3개 이상의 값을 비교할 경우 중첩하여 사용한다.

```java
Math.min(3, 5);                    // → 3
Math.min(3, Math.min(5, 1));       // → 1 (3개 값의 최솟값)
```

### String.charAt(int index)란

문자열의 지정 위치에 있는 문자를 반환하는 메서드이다. 인덱스는 0부터 시작한다.

```java
String s = "abc";
s.charAt(0);  // → 'a'
s.charAt(2);  // → 'c'
```

## 계산량

| | 값 |
|---|---|
| Time | O(m × n) — `word1`의 각 위치에 대해 `word2`의 모든 위치를 순회한다 |
| Space | O(n) — 2차원 테이블 대신 1행 분량의 배열만을 유지한다 |

## 코드

```java
// 입력: 두 문자열 word1(길이 m)과 word2(길이 n)
// 출력: word1을 word2로 변환하기 위한 최소 연산 횟수를 int로 반환한다
public int minDistance(String w1, String w2) {
    int m = w1.length();  // word1의 길이를 가져온다
    int n = w2.length();  // word2의 길이를 가져온다

    // prev 배열: DP 테이블의 한 칸 아래 행(i+1)에 해당한다
    // prev[j] = n - j로 초기화: word1이 비어 있을 때, word2[j:]의 나머지 n-j 문자를 모두 삽입하는 연산 횟수
    int[] prev = new int[n + 1];
    for (int j = 0; j <= n; j++)
        prev[j] = n - j;

    // word1의 끝에서 처음으로 역순 순회한다 (i는 word1의 현재 위치)
    for (int i = m - 1; i >= 0; i--) {
        // curr 배열: DP 테이블의 현재 행(i)에 해당한다
        int[] curr = new int[n + 1];
        // word2가 비어 있을 때, word1[i:]의 나머지 m-i 문자를 모두 삭제하는 연산 횟수
        curr[n] = m - i;

        // word2의 끝에서 처음으로 역순 순회한다 (j는 word2의 현재 위치)
        for (int j = n - 1; j >= 0; j--) {
            if (w1.charAt(i) == w2.charAt(j)) {
                // 문자가 일치하면 연산이 불필요하다. prev[j+1]은 양쪽 모두 1문자 진행한 부분 문제 dp[i+1][j+1]의 답이다
                curr[j] = prev[j + 1];
            } else {
                // 불일치하면 3가지 연산 중 최소 비용을 선택하고, 이번 연산 1회분(+1)을 더한다
                curr[j] = 1 + Math.min(
                    curr[j + 1],           // 삽입: word2 쪽에서 1문자 진행한다 (dp[i][j+1])
                    Math.min(prev[j],      // 삭제: word1 쪽에서 1문자 진행한다 (dp[i+1][j])
                        prev[j + 1]));     // 치환: 양쪽 모두에서 1문자 진행한다 (dp[i+1][j+1])
            }
        }
        // 현재 행을 이전 행으로 저장하고, 다음 이터레이션(i-1)에 대비한다
        prev = curr;
    }

    // prev[0]이 dp[0][0]에 해당하며, word1 전체를 word2 전체로 변환하는 최소 연산 횟수이다
    return prev[0];
}
```
