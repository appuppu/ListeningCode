# Finding the Longest Increasing Path in a Matrix — 행렬에서 값이 엄밀하게 증가하는 최장 경로의 길이를 구한다

## 문제의 본질

m×n 정수 행렬 `matrix`가 주어진다. 상하좌우 4방향으로 이동할 수 있으며, 이동할 셀의 값이 현재 셀의 값보다 **엄밀하게 큰** 경우에만 이동할 수 있다. 이 조건을 만족하는 **최장 경로의 길이**(셀 수)를 반환한다.

## 핵심 아이디어

행렬을 "작은 값에서 큰 값으로 간선이 향하는 DAG(유향 비순환 그래프)"로 파악한다. 진입 차수가 0인 셀(주위에 자신보다 작은 값이 없는 셀)에서 BFS를 층별로 진행하면, 층의 수가 그대로 최장 경로의 길이가 된다.

## 사고 과정

1. **이동 조건은 DAG의 간선이 된다**: 값이 엄밀하게 증가하는 방향으로만 이동할 수 있으므로 사이클이 존재하지 않는다. 즉, 행렬의 인접 관계를 그래프로 보면, 작은 값→큰 값 방향으로 간선을 갖는 DAG(유향 비순환 그래프)가 된다
2. **DAG의 최장 경로는 위상 정렬로 구할 수 있다**: DAG의 최장 경로 문제는 위상 정렬 순서에 따라 처리하면 효율적으로 풀 수 있다. BFS(칸의 알고리즘)를 사용하면 층별로 처리할 수 있으며, 층의 수가 최장 경로의 길이에 대응한다
3. **진입 차수의 의미를 정의한다**: 각 셀의 진입 차수는 "인접한 4방향 중 자신보다 값이 작은 셀의 수"이다. 진입 차수가 0인 셀은 경로의 시작점 후보이며, 주위에 자신보다 작은 값을 가진 인접 셀이 존재하지 않는다
4. **BFS를 층별로 처리한다**: 진입 차수가 0인 셀을 모두 큐에 넣고 BFS를 시작한다. 한 층의 셀을 일괄 처리하며, 각 셀에서 "자신보다 큰 인접 셀"의 진입 차수를 1 줄인다. 진입 차수가 0이 된 셀을 다음 층으로 큐에 추가한다
5. **층의 수가 답이 되는 이유**: BFS의 각 층은 DAG 상에서 같은 거리에 있는 셀의 집합이다. 마지막 층이 처리될 때까지의 층 수가, 시작점에서 가장 먼 셀까지의 거리, 즉 최장 경로의 길이가 된다

## 사전 지식

### DAG(유향 비순환 그래프)란

정점과 유향 간선으로 이루어진 그래프로, 사이클(순환)이 존재하지 않는 것이다. 값이 엄밀하게 증가하는 방향으로만 간선을 연결하면, 같은 값으로 돌아올 수 없으므로 사이클이 발생하지 않아 DAG가 구성된다.

### 진입 차수(in-degree)란

어떤 정점에 **들어오는 간선의 수**이다. 본 문제에서 셀 `(i, j)`의 진입 차수는 "상하좌우 인접 셀 중 `matrix[i][j]`보다 작은 값을 가진 셀의 수"이다. 진입 차수가 0인 셀은, 어떤 셀에서도 도달되지 않는 경로의 시작점을 의미한다.

```java
// 셀(i,j)의 진입 차수를 계산하는 예
int indegree = 0;
for (int[] d : dirs) {
    int ni = i + d[0], nj = j + d[1];
    if (ni >= 0 && ni < m && nj >= 0 && nj < n
        && matrix[ni][nj] < matrix[i][j])  // 이웃이 자신보다 작으면 간선이 들어온다
        indegree++;
}
```

### 위상 정렬(BFS / 칸의 알고리즘)이란

DAG의 정점을, 모든 간선이 "선→후" 순서가 되도록 나열하는 기법이다. 칸의 알고리즘에서는, 진입 차수가 0인 정점을 큐에 넣고, 꺼낼 때마다 인접 정점의 진입 차수를 1 줄이며, 진입 차수가 0이 된 정점을 큐에 추가한다. 이를 반복하면 위상 정렬 순서를 얻을 수 있다.

```java
Queue<int[]> q = new LinkedList<>();   // BFS용 큐를 생성한다
q.offer(new int[]{0, 1});             // 셀 좌표를 큐에 추가한다
q.isEmpty();                           // 큐가 비어 있는지를 boolean으로 반환한다 → false
q.size();                              // 큐 내의 요소 수를 반환한다 → 1
int[] cell = q.poll();                 // 큐의 선두 요소를 꺼내서 반환한다 → {0, 1}
```

### 4방향 이동을 배열로 표현한다

상하좌우 4방향을 `{행의 변화량, 열의 변화량}`의 2차원 배열로 정의하고, 루프로 각 방향을 처리한다.

```java
int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};  // 오른쪽, 왼쪽, 아래, 위
for (int[] d : dirs) {
    int ni = i + d[0];  // 이동할 행
    int nj = j + d[1];  // 이동할 열
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(m\*n) — 각 셀의 진입 차수 계산에 O(m\*n), BFS에서 각 셀을 정확히 1회 처리하는 데 O(m\*n) |
| Space | O(m\*n) — 진입 차수를 저장하는 2차원 배열과 BFS 큐에 각각 최대 m\*n개의 셀을 저장한다 |

## 코드

```java
// 입력: m×n 정수 행렬 matrix
// 출력: 값이 엄밀하게 증가하는 최장 경로의 길이(셀 수)를 int로 반환한다
int longestIncreasingPath(int[][] matrix) {
    // 행 수 m과 열 수 n을 가져온다
    int m = matrix.length;
    int n = matrix[0].length;
    // 상하좌우 4방향의 이동량을 정의한다(오른쪽, 왼쪽, 아래, 위)
    int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};

    // 각 셀의 진입 차수를 계산한다(인접 셀 중 자신보다 작은 값의 수)
    // 진입 차수 = 해당 셀에 들어오는 간선의 수 = 인접한 자신보다 작은 값의 셀 수
    int[][] indeg = new int[m][n];
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            for (int[] d : dirs) {
                int ni = i + d[0];
                int nj = j + d[1];
                // 인접 셀이 범위 내이고 자신보다 작으면, 거기서 간선이 들어온다
                if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && matrix[ni][nj] < matrix[i][j])
                    indeg[i][j]++;
            }
        }
    }

    // 진입 차수가 0인 셀(경로의 시작점)을 모두 큐에 추가한다
    // 진입 차수 0 = 주위에 자신보다 작은 값이 없음 = DAG 상에서 어떤 셀에서도 도달되지 않는 시작점
    Queue<int[]> q = new LinkedList<>();
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (indeg[i][j] == 0)
                q.offer(new int[]{i, j});

    // BFS를 층별로 처리하고, 층의 수를 카운트한다
    // 각 층은 DAG 상에서 시작점으로부터 같은 거리에 있는 셀의 집합이다
    int pathLen = 0;
    while (!q.isEmpty()) {
        // 현재 층에 속하는 셀의 수를 가져온다
        int size = q.size();
        // 새로운 층으로 진행할 때마다 경로 길이를 1 늘린다(총 층 수 = 최장 경로의 길이)
        pathLen++;
        for (int k = 0; k < size; k++) {
            int[] cell = q.poll();
            // 꺼낸 셀의 4방향 인접 셀을 조사한다
            for (int[] d : dirs) {
                int ni = cell[0] + d[0];
                int nj = cell[1] + d[1];
                // 인접 셀이 범위 내이고 자신보다 큰 경우, 해당 간선을 처리한다
                if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && matrix[ni][nj] > matrix[cell[0]][cell[1]]) {
                    // 진입 차수를 1 줄인다(이 셀로부터의 입력 간선을 처리 완료로 표시한다)
                    indeg[ni][nj]--;
                    // 진입 차수가 0이 됨 = 모든 입력 간선이 처리 완료 → 다음 층으로 큐에 추가한다
                    if (indeg[ni][nj] == 0)
                        q.offer(new int[]{ni, nj});
                }
            }
        }
    }
    // BFS의 층 수가 최장 증가 경로의 길이이다
    // 문제의 제약상 행렬은 비어 있지 않으므로 pathLen >= 1이 보장된다
    return pathLen;
}
```
