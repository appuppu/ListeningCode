# Implementing Regular Expression Matching — 문자열이 패턴에 완전히 일치하는지 판정한다

## 문제의 본질

입력 문자열 `s`와 패턴 `p`가 주어진다. 패턴 중의 `.`은 임의의 1문자에 매치되고, `*`는 직전 문자의 0회 이상 반복을 의미한다. 패턴이 문자열 **전체**에 일치하는지를 `boolean`으로 반환한다.

## 핵심 아이디어

문자열과 패턴의 끝에서 앞쪽으로 향하여 2차원 DP 테이블을 채워 나간다. `dp[i][j]`는 「`s[i:]`가 `p[j:]`에 매치되는가」를 나타내며, `*`가 있는 경우에는 「직전 문자를 0회 사용한다(스킵)」거나 「1회 사용하고 문자열을 1칸 진행한다」는 2가지 선택으로 귀결된다.

## 사고 프로세스

1. **부분 문제로 분해할 수 있다**: 문자열의 위치 `i`와 패턴의 위치 `j`를 정하면, 「`s[i:]`가 `p[j:]`에 매치되는가」라는 부분 문제가 된다. 이 부분 문제의 답을 `dp[i][j]`에 저장하면, 중복 계산을 피할 수 있다
2. **현재 위치의 문자 매치를 판정한다**: `s[i]`와 `p[j]`가 같은 문자이거나, 또는 `p[j]`가 `.`이면, 현재 위치의 1문자는 매치된다. 이 판정 결과를 변수 `match`에 저장해 둔다
3. **`*`가 있는 경우의 2가지 선택지를 생각한다**: `p[j+1]`이 `*`일 때, 「`x*`」라는 패턴은 2가지로 해석할 수 있다. 첫 번째는 「0회 매치(스킵)」로, `x*`를 통째로 건너뛰고 `dp[i][j+2]`를 참조한다. 두 번째는 「1회 이상 매치」로, 현재 문자가 매치되면 문자열을 1칸 진행하여 `dp[i+1][j]`를 참조한다(패턴 쪽은 진행하지 않는다. 다음 위치에서도 `*`에 의한 반복이 계속될 가능성이 있기 때문이다)
4. **`*`가 없는 경우에는 단순히 1문자씩 진행한다**: 현재 문자가 매치되면, 문자열과 패턴을 모두 1칸 진행한 `dp[i+1][j+1]`이 그대로 답이 된다
5. **베이스 케이스를 설정한다**: 문자열과 패턴 모두 끝에 도달한 상태 `dp[n][m]`은 `true`이다. 문자열이 남아 있지만 패턴이 끝인 경우는 `false`이고, 패턴이 남아 있지만 문자열이 끝인 경우는 `*`에 의한 스킵으로만 `true`가 될 수 있다
6. **끝에서 앞쪽으로 향하여 테이블을 채운다**: `dp[i][j]`의 계산은 `dp[i][j+2]`, `dp[i+1][j]`, `dp[i+1][j+1]`에 의존한다. 이들은 모두 `i` 또는 `j`가 큰 방향의 값이므로, `i`를 `n`에서 `0`으로, `j`를 `m-1`에서 `0`으로 역순으로 순회하면, 참조 대상은 항상 계산이 완료된 상태이다
7. **최종적으로 반환하는 것**: 테이블의 `dp[0][0]`이 「문자열 전체가 패턴 전체에 매치되는가」의 답이다

## 전제 지식

### 2차원 DP 테이블이란

2개의 변수(여기서는 문자열의 위치 `i`와 패턴의 위치 `j`)의 조합마다 부분 문제의 답을 저장하는 2차원 배열이다. `boolean[][] dp = new boolean[n+1][m+1]`로 생성하고, `dp[i][j]`에 `s[i:]`와 `p[j:]`의 매치 결과를 저장한다.

```java
boolean[][] dp = new boolean[n + 1][m + 1];  // (n+1)×(m+1)의 false로 초기화된 표를 생성한다
dp[n][m] = true;                              // 베이스 케이스: 양쪽 모두 끝이면 일치한다
dp[i][j] = dp[i][j + 2];                     // 다른 셀의 값을 참조하여 현재 셀을 채운다
```

### String.length()와 String.charAt()

`length()`는 문자열의 길이를 반환한다. `charAt(i)`는 인덱스 `i`의 문자를 반환한다. 인덱스는 0부터 시작하며, 범위 밖 접근은 예외를 던진다.

```java
String s = "abc";
s.length();     // → 3
s.charAt(0);    // → 'a'
s.charAt(2);    // → 'c'
```

### `*`(스타)의 의미

정규 표현식에서 `*`는 「직전 1문자의 0회 이상 반복」을 나타낸다. `a*`는 `""`, `"a"`, `"aa"`, `"aaa"`, ... 중 어느 것에도 매치된다. `.*`는 「임의의 문자의 0회 이상 반복」이므로, 모든 문자열에 매치된다. `*`는 단독으로 사용되지 않으며, 반드시 직전 문자와 세트로 `x*`의 형태를 취한다.

## 계산량

| | 값 |
|---|---|
| Time | O(n×m) — n×m의 DP 테이블의 각 셀을 1회씩 계산한다 |
| Space | O(n×m) — n×m의 DP 테이블을 저장한다 |

## 코드

```java
// 입력: 문자열 s와 패턴 p
// 출력: s 전체가 p에 매치되는지를 boolean으로 반환한다
public boolean isMatch(String s, String p) {
    int n = s.length();  // 문자열의 길이
    int m = p.length();  // 패턴의 길이

    // dp[i][j] = 「s[i:]가 p[j:]에 매치되는가」를 저장하는 2차원 테이블
    // 인덱스 n과 m은 빈 문자열을 나타내므로, 크기는 +1 한다
    boolean[][] dp = new boolean[n + 1][m + 1];

    // 베이스 케이스: 양쪽 문자열 모두 끝에 도달했으면 매치 성공이다
    dp[n][m] = true;

    // 끝에서 앞쪽으로 향하여 테이블을 채운다
    // 이 순회 순서에 의해, 참조 대상인 dp[i][j+2], dp[i+1][j], dp[i+1][j+1]은 모두 계산이 완료된 상태이다
    for (int i = n; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // 현재 위치의 1문자가 매치되는지를 판정한다
            // i < n을 먼저 판정하여, 문자열이 끝일 때 charAt로 범위 밖 접근하는 것을 방지한다
            boolean match = i < n
                && (s.charAt(i) == p.charAt(j)
                    || p.charAt(j) == '.');

            // j+1 < m으로 범위 검사를 하고, 패턴의 현재 위치가 x* 형태인지를 판정한다
            if (j + 1 < m && p.charAt(j + 1) == '*') {
                // x* 패턴의 2가지 선택지의 OR(논리합)을 취한다:
                // dp[i][j+2]: 0회 매치(x*를 통째로 건너뛴다)
                // match && dp[i+1][j]: 1회 매치하고 문자열을 진행한다(패턴 쪽은 진행하지 않는다. *에 의한 반복이 계속될 가능성이 있으므로 j는 그대로 유지한다)
                dp[i][j] = dp[i][j + 2]
                    || (match && dp[i + 1][j]);
            } else {
                // 일반 문자: 1문자 매치이면 문자열과 패턴 양쪽을 1칸 진행한다
                dp[i][j] = match
                    && dp[i + 1][j + 1];
            }
        }
    }

    // dp[0][0]이 「문자열 s 전체가 패턴 p 전체에 매치되는가」의 최종 답이다
    return dp[0][0];
}
```
