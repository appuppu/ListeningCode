# Checking if a String is an Interleaving of Two Others — 두 문자열을 교차로 섞어서 세 번째 문자열을 만들 수 있는지 판정하기

## 문제의 본질

세 문자열 `s1`, `s2`, `s3`가 주어진다. `s3`가 `s1`과 `s2`의 **인터리빙**(교차 혼합)으로 구성되어 있는지를 판정한다. 인터리빙이란, `s1`과 `s2`의 모든 문자를 빠짐없이 사용하면서 각 문자열 내에서의 상대적인 출현 순서를 유지한 채 섞는 것이다.

## 핵심 아이디어

`s1`의 앞 `i`개 문자와 `s2`의 앞 `j`개 문자로 `s3`의 앞 `i+j`개 문자를 구성할 수 있는지라는 부분 문제로 분해할 수 있다. 각 위치에서 "다음 1문자를 `s1`에서 가져올지 `s2`에서 가져올지"의 2가지 선택을 DP 테이블로 효율적으로 판정한다.

## 사고 과정

1. **길이의 전제 조건을 확인한다**: `s3`가 `s1`과 `s2`의 인터리빙이라면, `s3`의 길이는 `s1`의 길이 + `s2`의 길이와 일치해야 한다. 일치하지 않으면 즉시 `false`를 반환할 수 있다
2. **부분 문제를 정의한다**: `dp[i][j]`를 "`s1`의 앞 `i`개 문자와 `s2`의 앞 `j`개 문자로 `s3`의 앞 `i+j`개 문자를 구성할 수 있는지"로 정의한다. 이 정의에 따라 `dp[m][n]`(`m`은 `s1`의 길이, `n`은 `s2`의 길이)이 최종 답이 된다
3. **점화식을 도출한다**: `dp[i][j]`가 `true`가 되는 경우는 두 가지 케이스 중 하나이다. 케이스 1: `dp[i-1][j]`가 `true`이고 `s1`의 `i`번째 문자가 `s3`의 `i+j`번째 문자와 일치하는 경우(`s1`에서 1문자를 가져옴). 케이스 2: `dp[i][j-1]`가 `true`이고 `s2`의 `j`번째 문자가 `s3`의 `i+j`번째 문자와 일치하는 경우(`s2`에서 1문자를 가져옴)
4. **기저 사례를 정의한다**: `i=0`이고 `j=0`일 때, 어느 문자열에서도 문자를 가져오지 않은 초기 상태이며 `s3`의 앞 0개 문자(빈 문자열)와 일치하므로 `dp[0][0] = true`로 설정한다
5. **공간 복잡도를 최적화한다**: 2차원 `dp[i][j]`는 `i`행의 계산에 `i-1`행의 값만 사용한다. 따라서 1차원 배열 `dp[j]`로 충분하며, `dp[j]`의 갱신 전 값이 이전 행(`dp[i-1][j]`)에 해당하고, `dp[j-1]`의 갱신 후 값이 현재 행의 왼쪽 이웃(`dp[i][j-1]`)에 해당한다
6. **최종적으로 반환하는 것**: 바깥쪽 루프가 `i = 0`부터 `m`까지, 안쪽 루프가 `j = 0`부터 `n`까지 순회한 후, `dp[n]`이 `s3` 전체를 인터리빙으로 구성할 수 있는지의 답이다

## 전제 지식

### DP(동적 계획법)의 1차원 배열을 이용한 공간 최적화란

2차원 DP 테이블 `dp[i][j]`에서 각 행의 계산이 직전 행에만 의존하는 경우, 1차원 배열 `dp[j]`로 대체할 수 있는 기법이다. 배열을 행마다 덮어쓰면서 갱신함으로써 공간 복잡도를 O(m×n)에서 O(n)으로 줄인다.

```java
// 2차원의 경우: dp[i][j]는 dp[i-1][j]과 dp[i][j-1]을 참조한다
boolean[][] dp = new boolean[m + 1][n + 1];

// 1차원으로 최적화: dp[j]를 행마다 덮어쓴다
boolean[] dp = new boolean[n + 1];
// dp[j]의 갱신 전 값 → 이전 행의 dp[i-1][j]에 해당
// dp[j-1]의 갱신 후 값 → 현재 행의 dp[i][j-1]에 해당
```

### String.charAt(index)란

문자열의 지정된 위치의 문자를 반환하는 메서드이다. 인덱스는 0부터 시작한다.

```java
String s = "abc";
s.charAt(0);  // 'a'를 반환한다
s.charAt(2);  // 'c'를 반환한다
```

### 인터리빙(Interleaving)이란

두 문자열의 문자를 각각의 상대적 순서를 유지하면서 섞어서 하나의 문자열을 만드는 것이다.
예: `s1 = "aab"`, `s2 = "axy"`일 때, `"aaxaby"`는 인터리빙이다(`s1`에서 a,a,b, `s2`에서 a,x,y의 순서가 각각 유지되고 있다). `"abaaxy"`는 `s1`의 문자 순서가 깨지므로 인터리빙이 아니다.

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(m×n) — `s1`의 길이 `m`과 `s2`의 길이 `n`의 이중 루프를 1회 실행한다 |
| Space | O(n) — `s2`의 길이+1 크기의 1차원 DP 배열만 사용한다 |

## 코드

```java
// 입력: 문자열 s1(길이 m), 문자열 s2(길이 n), 문자열 s3
// 출력: s3가 s1과 s2의 인터리빙으로 구성될 수 있는지를 boolean으로 반환한다
public boolean isInterleave(String s1, String s2, String s3) {
    int m = s1.length();
    int n = s2.length();

    // m + n이 s3의 길이와 일치하지 않는 경우, 인터리빙은 불가능하다
    if (m + n != s3.length())
        return false;

    // dp[j] = s1의 앞 i개 문자와 s2의 앞 j개 문자로 s3의 앞 i+j개 문자를 구성할 수 있는지
    // 1차원 배열을 행마다 덮어씀으로써, 2차원 테이블의 공간을 O(n)으로 압축한다
    boolean[] dp = new boolean[n + 1];

    // 바깥쪽 루프: i는 s1에서 가져오는 문자 수를 나타낸다 (0〜m)
    for (int i = 0; i <= m; i++) {
        // 안쪽 루프: j는 s2에서 가져오는 문자 수를 나타낸다 (0〜n)
        for (int j = 0; j <= n; j++) {
            if (i == 0 && j == 0) {
                // 기저 사례: 어느 쪽에서도 문자를 가져오지 않은 상태에서, s3의 빈 문자열과 일치한다
                dp[j] = true;
            } else {
                // 조건 1(s1에서 가져오기): dp[j]의 갱신 전 값(이전 행 = dp[i-1][j]에 해당)이 true
                //   이고 s1의 i번째 문자가 s3의 i+j번째 문자와 일치하는 경우
                // 조건 2(s2에서 가져오기): dp[j-1]의 갱신 후 값(현재 행의 왼쪽 이웃 = dp[i][j-1]에 해당)이 true
                //   이고 s2의 j번째 문자가 s3의 i+j번째 문자와 일치하는 경우
                // 주의: 안쪽 루프가 j를 왼쪽에서 오른쪽으로 순회하므로, dp[j]는 아직 덮어쓰이지 않아 이전 행의 값을 유지하고 있고,
                //   dp[j-1]은 이미 덮어쓰여 현재 행의 값을 유지하고 있다
                dp[j] =
                    (dp[j] && i > 0
                    && s1.charAt(i - 1)
                    == s3.charAt(i + j - 1))
                    || (j > 0
                    && dp[j - 1]
                    && s2.charAt(j - 1)
                    == s3.charAt(i + j - 1));
            }
        }
    }

    // dp[n]은 s1의 전체 m개 문자와 s2의 전체 n개 문자로 s3의 전체 m+n개 문자를 구성할 수 있는지의 결과이다
    return dp[n];
}
```
