# Merging Overlapping Intervals — 겹치는 구간을 모두 통합하기

## 문제의 본질

구간(시작값과 종료값의 쌍)의 배열 `intervals`가 주어진다. 겹치는 구간을 모두 통합(머지)하여 겹침이 없는 구간의 리스트를 반환한다.

## 핵심 아이디어

구간을 시작값으로 정렬하면, 겹칠 가능성이 있는 것은 인접한 구간뿐이다. 정렬 후 앞에서부터 순서대로 탐색하면서, 현재 구간이 직전 구간과 겹치면 종료값을 갱신하고, 겹치지 않으면 새로운 구간으로 추가한다.

## 사고 과정

1. **겹침 판정을 단순화하고 싶다**: 구간이 정렬되어 있지 않으면 모든 쌍을 비교해야 한다. 시작값으로 오름차순 정렬하면, 겹침 판정은 「직전 구간의 종료값 ≥ 현재 구간의 시작값」만으로 충분하다
2. **정렬 후에는 한 번의 탐색으로 통합할 수 있다**: 정렬된 구간을 처음부터 순서대로 확인한다. 결과 리스트의 마지막 구간과 현재 구간을 비교하여, 겹치면 종료값을 큰 쪽으로 갱신한다. 겹치지 않으면 현재 구간을 그대로 결과 리스트에 추가한다
3. **결과 리스트의 마지막 요소에 접근해야 한다**: 통합 판정에서는 항상 결과 리스트의 「마지막으로 추가한 구간」의 종료값을 참조한다. LinkedList를 사용하면 `getLast()`로 O(1)에 마지막 요소에 접근할 수 있다
4. **겹침 조건을 정확하게 정의한다**: 직전 구간의 종료값이 현재 구간의 시작값보다 작으면(`res.getLast()[1] < interval[0]`), 두 구간은 겹치지 않는다. 그 외의 경우(종료값 ≥ 시작값)에는 겹치므로 통합한다
5. **통합 시에는 종료값만 갱신한다**: 시작값은 정렬되어 있으므로 직전 구간의 시작값이 반드시 작거나 같다. 종료값은 두 구간 중 큰 쪽을 채택한다. `Math.max()`로 직전 종료값과 현재 종료값을 비교한다
6. **최종적으로 반환하는 것**: 결과 리스트에 축적된 겹치지 않는 구간을 모두 `int[][]` 이차원 배열로 변환하여 반환한다

## 사전 지식

### Arrays.sort와 커스텀 Comparator

`Arrays.sort`는 배열을 정렬하는 메서드이다. 이차원 배열의 경우, 람다식으로 Comparator를 지정하여 어떤 요소를 기준으로 정렬할지를 정의한다.

```java
int[][] intervals = {{3, 6}, {1, 3}, {2, 5}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 각 구간의 시작값(index 0)으로 오름차순 정렬
// 결과: {{1, 3}, {2, 5}, {3, 6}}
```

### LinkedList란

선두·끝에 요소를 추가하거나 끝의 요소를 가져오는 작업이 O(1)로 가능한 리스트이다. ArrayList와 달리, `getLast()` 메서드로 마지막 요소에 직접 접근할 수 있다.

```java
LinkedList<int[]> res = new LinkedList<>();  // 빈 LinkedList를 생성한다
res.add(new int[]{1, 3});   // 끝에 요소를 추가한다
res.getLast();               // 마지막 요소를 가져온다 → {1, 3}
res.getLast()[1] = 5;        // 마지막 요소의 종료값을 직접 수정한다 → {1, 5}
res.isEmpty();               // 리스트가 비어 있는지를 boolean으로 반환한다 → false
res.size();                  // 리스트의 요소 수를 반환한다 → 1
```

### Math.max란

두 값 중 큰 쪽을 반환하는 메서드이다. 구간 통합에서는 두 종료값 중 큰 쪽을 채택하기 위해 사용한다.

```java
Math.max(5, 8);   // → 8
Math.max(10, 3);  // → 10
```

## 계산량

| | 값 |
|---|---|
| Time | O(n log n) — 정렬이 O(n log n), 탐색이 O(n)이므로 전체는 O(n log n) |
| Space | O(n) — 결과 리스트에 최대 n개의 구간을 저장한다 |

## 코드

```java
// 입력: 구간의 이차원 배열 int[][] intervals (각 요소는 [시작값, 종료값])
// 출력: 겹치는 구간을 통합한 후의 이차원 배열 int[][]를 반환한다
public int[][] merge(int[][] intervals) {
    // 정렬하여 겹침 판정을 인접한 구간의 비교만으로 한정할 수 있다
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // 통합 완료된 구간을 축적하는 결과 리스트
    // LinkedList를 사용하는 이유는 마지막 요소의 참조와 갱신을 O(1)로 수행하기 위함이다
    LinkedList<int[]> res = new LinkedList<>();

    for (int[] interval : intervals) {
        // res가 비어 있으면 첫 번째 구간이므로 무조건 추가한다
        // res.getLast()[1] < interval[0]이면 직전 구간과 겹치지 않으므로 그대로 추가한다
        if (res.isEmpty() || res.getLast()[1] < interval[0]) {
            res.add(interval);
        } else {
            // 겹치는 경우, 종료값을 큰 쪽으로 갱신하여 통합한다
            // 시작값은 정렬되어 있으므로 직전 구간의 시작값이 작거나 같아 변경할 필요가 없다
            res.getLast()[1] = Math.max(res.getLast()[1], interval[1]);
        }
    }

    // 결과 리스트를 이차원 배열로 변환하여 반환한다
    return res.toArray(new int[res.size()][]);
}
```
