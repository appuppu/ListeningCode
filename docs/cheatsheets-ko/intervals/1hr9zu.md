# Finding the Smallest Interval Containing Each Query — 각 쿼리를 포함하는 최소 구간 찾기

## 문제의 본질

2D 정수 배열 `intervals`(각 요소는 `[left, right]`)와 정수 배열 `queries`가 주어진다. 각 쿼리 값을 포함하는 구간 중에서 **크기가 가장 작은 것**을 찾는다. 구간의 크기는 `right - left + 1`로 정의한다. 쿼리를 포함하는 구간이 존재하지 않으면 `-1`을 반환한다.

## 핵심 아이디어

쿼리와 구간을 모두 정렬하고, 쿼리 값이 작은 순서대로 처리하면, 각 쿼리에 대해 "왼쪽 끝이 쿼리 이하인 구간"을 순차적으로 Min-Heap에 추가할 수 있다. Min-Heap에서 크기가 가장 작고 오른쪽 끝이 쿼리 이상인 구간을 꺼내면, 그것이 답이 된다.

## 사고 과정

1. **각 쿼리에 대해 모든 구간을 조사하는 것은 비효율적이다**: 각 쿼리마다 모든 구간을 순회하면 O(n×q)가 걸린다. 쿼리와 구간을 모두 정렬하면, 구간 추가 처리를 모든 쿼리에서 공유할 수 있어 중복 순회를 제거할 수 있다
2. **쿼리를 오름차순으로 처리하면 구간 추가가 단조적이 된다**: 구간을 왼쪽 끝으로 정렬하고, 쿼리를 값의 오름차순으로 정렬하면, 쿼리 값이 증가할 때마다 "왼쪽 끝이 쿼리 이하"인 조건을 만족하는 구간이 늘어나기만 하고 줄어들지 않는다. 즉, 구간 추가는 포인터를 앞으로 이동시키는 단조 연산이 된다
3. **추가한 구간 중에서 최소 크기를 빠르게 가져오고 싶다**: 후보 구간 중에서 크기가 가장 작은 것을 꺼내는 연산에는 Min-Heap(최소 힙)이 적합하다. 힙의 키를 구간 크기로 설정하면, peek 연산으로 O(1)에 최소 크기의 구간을 가져올 수 있다
4. **오른쪽 끝이 쿼리 값보다 작은 구간은 무효이다**: 힙에 남아 있는 구간 중에서, 오른쪽 끝이 쿼리 값보다 작은 것은 해당 쿼리를 포함하지 않는다. 이러한 구간은 힙의 맨 위부터 순서대로 poll하여 제거한다. 한 번 제거한 구간은 이후 쿼리에서도 무효이므로(쿼리 값이 증가하기 때문에) 다시 추가할 필요가 없다
5. **쿼리의 원래 순서를 유지해야 한다**: 쿼리를 정렬하여 처리하지만, 결과는 원래 순서대로 반환해야 한다. 따라서 정렬 전에 각 쿼리의 원래 인덱스를 쌍으로 보관하고, 결과 배열의 해당 위치에 답을 기록한다
6. **힙이 비어 있으면 해당 쿼리를 포함하는 구간이 존재하지 않는다**: 무효 구간을 제거한 후에 힙이 비어 있으면, 해당 쿼리를 포함하는 구간이 존재하지 않으므로 `-1`을 결과에 저장한다

## 사전 지식

### PriorityQueue(Min-Heap)란

요소를 우선순위 순서로 관리하는 자료 구조이다. 기본적으로 최솟값이 맨 앞에 온다(Min-Heap). 요소의 추가와 꺼내기가 O(log n), 맨 앞 요소의 참조가 O(1)에 가능하다.

```java
// int[]를 저장하고, 배열의 0번째 요소(크기)로 오름차순 정렬하는 Min-Heap
PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
heap.offer(new int[]{5, 10});  // 요소를 추가한다
heap.peek();                    // 맨 앞 요소를 꺼내지 않고 참조한다 → {5, 10}
heap.poll();                    // 맨 앞 요소를 꺼내고 삭제한다 → {5, 10}
heap.isEmpty();                 // 힙이 비어 있는지 판정한다 → true
```

### 오프라인 쿼리란

쿼리를 도착 순서가 아니라, 처리에 유리한 순서로 재배열한 후에 처리하는 기법이다. 결과는 원래 인덱스를 사용하여 올바른 위치에 다시 기록한다. 쿼리 간에 의존 관계가 없는 경우에 유효하다.

```java
int q = queries.length;
int[][] sortedQ = new int[q][2];
for (int i = 0; i < q; i++) {
    sortedQ[i] = new int[]{queries[i], i};  // {쿼리 값, 원래 인덱스} 쌍을 만든다
}
Arrays.sort(sortedQ, (a, b) -> a[0] - b[0]);  // 쿼리 값의 오름차순으로 정렬한다
```

### Arrays.sort의 커스텀 비교자

2D 배열이나 객체 배열을 임의의 기준으로 정렬한다. 람다식 `(a, b) -> a[0] - b[0]`은 각 요소의 0번째 값으로 오름차순 정렬하는 것을 의미한다.

```java
int[][] intervals = {{3, 6}, {1, 4}, {2, 8}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 왼쪽 끝의 오름차순으로 정렬한다 → {{1,4}, {2,8}, {3,6}}
```

## 계산량

| | 값 |
|---|---|
| Time | O(n log n + q log q) — 구간 정렬에 O(n log n), 쿼리 정렬에 O(q log q), 힙 연산은 각 구간이 최대 1회 추가·1회 삭제되므로 O(n log n) |
| Space | O(n + q) — 힙에 최대 n개의 구간, 정렬된 쿼리 배열에 q개의 요소를 저장한다 |

## 코드

```java
// 입력: 2D 정수 배열 intervals(각 요소는 [left, right])와 정수 배열 queries
// 출력: 각 쿼리를 포함하는 최소 크기 구간의 크기를 저장한 int[]를 반환한다. 포함하는 구간이 없으면 -1을 저장한다
public int[] minInterval(int[][] intervals, int[] queries) {
    // 구간을 왼쪽 끝의 오름차순으로 정렬한다. 이렇게 하면 포인터 j를 앞으로 진행시키는 것만으로 "왼쪽 끝이 쿼리 값 이하인 구간"을 빠짐없이 추가할 수 있다
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    int q = queries.length;
    // 각 쿼리에 원래 인덱스를 부여하여 쌍으로 만든다. 정렬 후에도 결과를 올바른 위치에 다시 기록하기 위해 필요하다
    int[][] sortedQ = new int[q][2];
    for (int i = 0; i < q; i++) {
        sortedQ[i] = new int[]{queries[i], i};
    }
    // 쿼리 값의 오름차순으로 정렬한다. 오름차순으로 처리하면 구간 추가가 단조 연산이 된다
    Arrays.sort(sortedQ, (a, b) -> a[0] - b[0]);

    // {구간 크기, 오른쪽 끝}을 보관하고, 크기의 오름차순으로 꺼내는 Min-Heap. 크기를 키로 설정하면 최소 크기의 구간을 O(1)에 참조할 수 있다
    PriorityQueue<int[]> heap =
        new PriorityQueue<>((a, b) -> a[0] - b[0]);

    int[] res = new int[q];
    int j = 0;  // 구간 배열을 순회하는 포인터. 모든 쿼리를 통틀어 앞으로만 진행하므로, 구간 추가의 합계는 O(n)이다

    for (int[] sq : sortedQ) {
        int val = sq[0], idx = sq[1];  // val=쿼리 값, idx=원래 인덱스

        // 왼쪽 끝이 쿼리 값 이하인 구간을 모두 힙에 추가한다. j는 되돌아가지 않으므로 전체적으로 O(n)이다
        while (j < intervals.length && intervals[j][0] <= val) {
            int sz = intervals[j][1] - intervals[j][0] + 1;  // 구간 크기 = right - left + 1
            heap.offer(new int[]{sz, intervals[j][1]});  // {크기, 오른쪽 끝}을 힙에 추가한다
            j++;
        }

        // 오른쪽 끝이 쿼리 값보다 작은(쿼리를 포함하지 않는) 구간을 제거한다. 쿼리 값은 오름차순으로 증가하므로, 한 번 제거한 구간은 이후에도 무효이다
        while (!heap.isEmpty() && heap.peek()[1] < val) {
            heap.poll();
        }

        // 힙이 비어 있으면 포함하는 구간이 없고, 그렇지 않으면 맨 앞의 구간 크기가 답이다(무효 구간은 이미 제거했으므로 맨 앞이 최소이면서 유효하다)
        res[idx] = heap.isEmpty() ? -1 : heap.peek()[0];
    }
    return res;
}
```
