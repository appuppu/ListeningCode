# 모든 회의에 참석할 수 있는지 판정하기 — Determining if All Meetings Can Be Attended

## 문제의 본질

회의 시간대를 나타내는 구간(시작 시각과 종료 시각의 쌍)의 배열 `intervals`가 주어진다. 한 사람이 **모든 회의에 참석할 수 있는지**를 판정하여 `boolean`으로 반환한다. 어떤 회의가 다른 회의의 종료 전에 시작되는 경우, 두 회의는 충돌(중복)하고 있으며, 모든 회의에는 참석할 수 없다.

## 핵심 아이디어

구간을 시작 시각으로 정렬하면, 중복이 발생할 수 있는 것은 인접한 구간끼리뿐이다. 인접한 쌍을 순서대로 비교하여, 다음 구간의 시작 시각이 이전 구간의 종료 시각보다 앞인지를 확인하는 것만으로 전체의 중복 판정을 할 수 있다.

## 사고 프로세스

1. **중복 조건을 정리한다**: 두 구간이 중복한다는 것은, 한쪽의 시작 시각이 다른 쪽의 종료 시각보다 앞이라는 것을 의미한다. 그러나 구간이 뒤섞인 순서라면 모든 쌍을 비교해야 하므로 O(n²)이 된다
2. **정렬로 비교 대상을 한정한다**: 구간을 시작 시각의 오름차순으로 정렬하면, 중복이 발생하는 것은 인접한 구간끼리로 한정된다. 왜냐하면 `intervals[i]`와 `intervals[i+2]`가 중복한다면, 반드시 `intervals[i]`와 `intervals[i+1]`도 중복하기 때문이다
3. **인접 쌍의 중복 판정**: 정렬 후, `intervals[i]`의 시작 시각이 `intervals[i-1]`의 종료 시각보다 앞이면 두 회의는 중복하고 있다. 이 조건은 `intervals[i][0] < intervals[i-1][1]`로 표현할 수 있다
4. **중복이 하나라도 있으면 즉시 결과가 결정된다**: 중복이 1쌍이라도 발견되면 모든 회의에는 참석할 수 없으므로 `false`를 반환한다. 모든 인접 쌍을 확인하여 중복이 없으면 `true`를 반환한다

## 사전 지식

### Arrays.sort와 커스텀 Comparator

`Arrays.sort`는 배열을 정렬하는 메서드이다. 2차원 배열의 경우, 람다식으로 Comparator(비교 함수)를 지정하여 어떤 요소를 기준으로 정렬할지를 제어할 수 있다.

```java
int[][] intervals = {{7, 10}, {2, 4}, {5, 8}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 각 구간의 시작 시각([0])으로 오름차순 정렬
// 결과: {{2, 4}, {5, 8}, {7, 10}}
```

`(a, b) -> a[0] - b[0]`은 두 구간 `a`와 `b`를 받아서 시작 시각의 차이를 반환한다. 차이가 음수이면 `a`가 먼저, 양수이면 `b`가 먼저 배치된다.

### 구간의 중복 판정

두 구간이 시작 시각으로 정렬된 상태일 때, 뒤 구간의 시작이 앞 구간의 종료보다 앞이면 중복하고 있다.

```java
int[] prev = {2, 4};   // 2시~4시 회의
int[] curr = {3, 6};   // 3시~6시 회의
curr[0] < prev[1];     // 3 < 4 → true → 중복하고 있음
```

## 계산량

| | 값 |
|---|---|
| Time | O(n log n) — 정렬이 O(n log n), 인접 쌍의 순회가 O(n)이며, 정렬이 지배적이다 |
| Space | O(1) — 정렬은 입력 배열을 직접 재배치하므로 추가 배열을 사용하지 않는다 |

## 코드

```java
// 입력: 회의 시간대를 나타내는 2차원 정수 배열 intervals (각 요소는 [시작 시각, 종료 시각])
// 출력: 모든 회의에 참석할 수 있으면 true, 중복하는 회의가 있으면 false
public boolean canAttendMeetings(int[][] intervals) {
    // 시작 시각의 오름차순으로 구간을 정렬한다
    // 람다식 (a, b) -> a[0] - b[0]을 Comparator로 전달한다
    // 이를 통해, 시간순으로 정렬된 구간에 대해 인접 쌍만 비교하면 충분하게 된다
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // i = 0이 아닌 i = 1부터 시작한다. 각 단계에서 intervals[i]와 intervals[i-1]의 인접 쌍을 비교하기 때문이다
    for (int i = 1; i < intervals.length; i++) {
        // 현재 회의의 시작 시각이 직전 회의의 종료 시각보다 앞이면 중복이다
        if (intervals[i][0] < intervals[i - 1][1]) {
            // 1쌍이라도 중복이 있으면 모든 회의에는 참석할 수 없으므로 즉시 false를 반환한다
            return false;
        }
        // 중복이 없으면 다음 인접 쌍으로 진행한다
    }
    // 루프가 끝까지 완료된 경우, 어떤 인접 쌍에도 중복이 없었으므로 true를 반환한다
    return true;
}
```
