# Finding the Minimum Meeting Rooms Required — 모든 회의를 충돌 없이 개최하기 위해 필요한 최소 회의실 수를 구하기

## 문제의 본질

회의 시간대(시작 시각과 종료 시각)의 배열이 주어진다. 모든 회의를 충돌 없이 개최하기 위해 필요한 **최소 회의실 수**를 반환한다. 같은 시간대에 겹치는 회의는 각각 별도의 회의실을 사용해야 한다.

## 핵심 아이디어

회의의 시작과 종료를 별개의 이벤트로 시계열 순서대로 처리하면, 특정 순간에 동시에 진행되고 있는 회의의 최대 수를 구할 수 있다. 그 최대 수가 필요한 회의실 수이다.

## 사고 프로세스

1. **동시 진행 회의 수가 답이 된다**: 특정 순간에 동시에 진행되고 있는 회의의 최대 수 = 필요한 회의실 수이다. 문제는 "동시 진행 수의 최대값"을 효율적으로 구하는 것으로 귀결된다
2. **시작과 종료를 별개의 이벤트로 취급한다**: 회의가 시작될 때 방이 1개 필요하고, 종료될 때 방이 1개 비게 된다. 시작과 종료를 분리하여 각각 정렬하면, 시계열 순서대로 이벤트를 처리할 수 있다
3. **2개의 정렬된 배열을 스윕한다**: starts 배열과 ends 배열을 각각 정렬하고, starts를 처음부터 순회한다. 각 시작 시각에 대해 "가장 빠른 종료 시각보다 이전인지"를 판정하면, 방이 필요한지 비는지를 알 수 있다
4. **투 포인터로 동시 진행 수를 추적한다**: starts 배열의 포인터 `i`와 ends 배열의 포인터 `endPtr`를 준비한다. `starts[i] < ends[endPtr]`이면 새로운 회의가 기존 회의와 겹치므로 방을 추가한다. 그렇지 않으면 하나의 회의가 종료되어 방이 비므로 `endPtr`를 전진시킨다
5. **최대값을 기록한다**: 순회 과정에서 `rooms`의 최대값을 `maxRooms`에 계속 기록한다. 순회 완료 후 `maxRooms`를 반환한다

## 사전 지식

### Arrays.sort란

배열을 오름차순으로 정렬하는 Java의 표준 메서드이다. 기본형 배열에 대해서는 듀얼 피벗 퀵소트(O(n log n))를 사용한다.

```java
int[] arr = {5, 2, 8, 1};
Arrays.sort(arr);        // arr는 {1, 2, 5, 8}이 된다
```

### 투 포인터(Two Pointer)란

2개의 인덱스 변수를 사용하여 각각 독립적으로 배열을 순회하는 기법이다. 정렬된 배열에 대해 사용하면, 2개의 배열 요소를 효율적으로 비교하고 병합할 수 있다.

```java
int i = 0;          // 첫 번째 배열용 포인터
int endPtr = 0;     // 두 번째 배열용 포인터
// 조건에 따라 어느 쪽 포인터를 전진시킬지 결정한다
```

### 이벤트 스윕(Event Sweep)이란

시간축 위의 이벤트(시작·종료)를 시계열 순서대로 처리하여, 특정 시점의 상태(동시 진행 수 등)를 추적하는 기법이다. 시작 이벤트에서 카운터를 증가시키고, 종료 이벤트에서 카운터를 감소시킴으로써, 임의의 순간의 동시 진행 수를 알 수 있다.

## 계산 복잡도

| | 값 |
|---|---|
| Time | O(n log n) — 2개의 배열 정렬이 지배적이다 |
| Space | O(n) — 시작 시각과 종료 시각을 저장하는 2개의 배열을 생성한다 |

## 코드

```java
// 입력: 회의 시간대를 나타내는 2차원 정수 배열 intervals (각 요소는 [start, end])
// 출력: 모든 회의를 충돌 없이 개최하기 위해 필요한 최소 회의실 수를 int로 반환한다
public int minMeetingRooms(int[][] intervals) {
    // 입력이 null이거나 비어 있는 경우, 회의가 존재하지 않으므로 0을 반환한다
    if (intervals == null || intervals.length == 0)
        return 0;

    int n = intervals.length;
    // 시작과 종료를 분리함으로써, 각각 독립적으로 정렬할 수 있게 된다
    int[] starts = new int[n];  // 시작 시각을 저장하는 배열
    int[] ends = new int[n];    // 종료 시각을 저장하는 배열

    // intervals를 순회하며, 시작 시각과 종료 시각을 별도의 배열에 저장한다
    for (int i = 0; i < n; i++) {
        starts[i] = intervals[i][0];
        ends[i] = intervals[i][1];
    }

    // 두 배열을 오름차순으로 정렬하여, 시계열 순서대로 이벤트를 처리할 준비를 갖춘다
    Arrays.sort(starts);
    Arrays.sort(ends);

    int rooms = 0, maxRooms = 0;
    // ends 배열의 포인터. 가장 빨리 끝나는 회의를 가리킨다
    int endPtr = 0;

    // starts 배열을 처음부터 순회한다. 각 이터레이션은 "새로운 회의가 시작된다"는 이벤트를 나타낸다
    for (int i = 0; i < n; i++) {
        if (starts[i] < ends[endPtr]) {
            // 현재 시작되는 회의의 시작 시각이 가장 빨리 끝나는 회의의 종료 시각보다 이전이다 → 겹침이 발생하므로 새로운 방을 할당한다
            rooms++;
        } else {
            // 가장 빨리 끝나는 회의가 이미 종료되었으므로, 그 방을 재사용할 수 있다. 방 수는 늘리지 않고 endPtr를 전진시켜 다음으로 빨리 끝나는 회의를 가리킨다
            endPtr++;
        }
        // 동시 사용 최대 방 수를 갱신한다
        maxRooms = Math.max(maxRooms, rooms);
    }
    // maxRooms가 동시에 사용된 방 수의 최대값이며, 필요한 최소 회의실 수이다
    return maxRooms;
}
```
