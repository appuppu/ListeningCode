# Finding the Minimum Removals for Non-Overlapping Intervals — 겹치지 않는 구간으로 만들기 위해 제거할 구간의 최소 수를 구하기

## 문제의 본질

구간의 배열 `intervals`(각 구간은 `[start, end]` 쌍)가 주어진다. 남은 구간끼리 겹치지 않도록 하기 위해 **제거할 구간의 최소 수**를 반환한다.

## 핵심 아이디어

구간을 종료 시각으로 정렬하고, 종료가 빠른 구간을 우선적으로 남기면 후속 구간과 겹칠 가능성이 최소가 된다. 겹침이 발생하면 종료가 늦은 쪽(＝현재 구간)을 제거함으로써 제거 수를 최소화할 수 있다.

## 사고 과정

1. **겹침을 줄이려면 "자리를 적게 차지하는" 구간을 우선적으로 남긴다**: 종료 시각이 빠른 구간일수록 뒤에 빈 공간이 많이 남아 후속 구간과 겹치기 어렵다. 따라서 구간을 종료 시각의 오름차순으로 정렬하고, 종료가 빠른 순서대로 탐욕적으로 선택하는 것이 최적이다
2. **정렬 후, 직전에 남긴 구간의 종료 시각만 추적하면 된다**: 종료 시각으로 정렬했기 때문에, 남긴 구간 중 마지막 하나의 종료 시각 `lastEnd`만 기억하면 다음 구간이 겹치는지를 판정할 수 있다. 다음 구간의 시작 시각이 `lastEnd`보다 작으면 겹치고 있는 것이다
3. **겹친 경우에는 현재 구간을 제거한다**: 겹침이 발생했을 때, 직전에 남긴 구간과 현재 구간 중 어느 쪽을 제거해야 하는가. 종료 시각으로 정렬했으므로 현재 구간의 종료 시각은 직전 구간의 종료 시각 이상이다. 종료가 늦은 현재 구간을 제거하는 편이 후속에 대한 영향이 작다. 따라서 `removals`를 증가시키고, `lastEnd`는 갱신하지 않는다
4. **겹치지 않는 경우에는 현재 구간을 남긴다**: 현재 구간의 시작 시각이 `lastEnd` 이상이면 겹치지 않으므로 이 구간을 남긴다. `lastEnd`를 현재 구간의 종료 시각으로 갱신한다
5. **최종적으로 반환하는 것**: 루프 종료 후, `removals`(제거한 구간의 수)를 반환한다

## 사전 지식

### Arrays.sort의 커스텀 비교자

`Arrays.sort`의 두 번째 인자에 람다식을 전달하면 정렬 기준을 커스터마이즈할 수 있다. `(a, b) -> a[1] - b[1]`은 각 구간의 종료 시각(인덱스 1의 요소)을 기준으로 오름차순 정렬한다.

```java
int[][] intervals = {{1,3}, {2,4}, {0,2}};
Arrays.sort(intervals, (a, b) -> a[1] - b[1]);
// 결과: {{0,2}, {1,3}, {2,4}} — 종료 시각이 빠른 순서로 정렬된다
```

### 탐욕법(Greedy)이란

각 단계에서 "그 시점에서 가장 좋은 선택"을 수행하여 전체의 최적해를 도출하는 기법이다. 이 문제에서는 "종료 시각이 가장 빠른 구간을 우선적으로 남긴다"라는 국소적인 선택이 전체적으로 제거 수의 최소화로 이어진다.

```java
// 탐욕법의 전형적인 패턴: 정렬한 후 앞에서부터 순서대로 최적의 선택을 수행한다
Arrays.sort(data, comparator);  // 기준으로 정렬
for (int i = 0; i < data.length; i++) {
    // 조건을 만족하면 선택하고, 만족하지 않으면 건너뛴다
}
```

## 계산량

| | 값 |
|---|---|
| Time | O(n log n) — 정렬에 O(n log n), 순회에 O(n)이 소요되며, 정렬이 지배적이다 |
| Space | O(1) — 정렬의 내부 영역을 제외하고 추가 데이터 구조를 사용하지 않는다 |

## 코드

```java
// 입력: 구간의 배열 int[][] intervals (각 요소는 [start, end])
// 출력: 겹침을 없애기 위해 제거할 구간의 최소 수를 int로 반환한다
int eraseOverlapIntervals(int[][] intervals) {
    // 구간이 0개이면 제거할 필요가 없다
    if (intervals.length == 0)
        return 0;

    // 종료 시각의 오름차순으로 정렬한다 (종료가 빠른 구간을 우선적으로 남기기 위해)
    // 탐욕법: 종료가 빠른 구간일수록 후속과 겹치기 어려우므로 먼저 남기는 것이 최적이다
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);

    // 제거한 구간의 수를 기록하는 변수
    int removals = 0;
    // 정렬 후 첫 번째 구간은 항상 남긴다 (종료가 가장 빠르기 때문). 그 종료 시각을 기록한다
    int lastEnd = intervals[0][1];

    // 인덱스 1부터 순회한다 (0번째는 이미 남길 구간으로 확정됨)
    for (int i = 1; i < intervals.length; i++) {
        // 현재 구간의 시작 시각이 lastEnd보다 작으면, 직전에 남긴 구간과 겹치고 있다
        if (intervals[i][0] < lastEnd) {
            // 현재 구간을 제거한다. 종료 시각으로 정렬했으므로 현재 구간의 종료는 lastEnd 이상이며,
            // 종료가 늦은 현재 구간을 제거하는 편이 후속과의 겹침을 줄일 수 있다. lastEnd는 갱신하지 않는다
            removals++;
        } else {
            // 겹치지 않으므로 현재 구간을 남기고, lastEnd를 현재 구간의 종료 시각으로 갱신한다
            // 다음 구간과의 겹침 판정은 이 새로운 lastEnd를 기준으로 수행한다
            lastEnd = intervals[i][1];
        }
    }
    // removals가 겹침을 없애기 위해 제거해야 하는 구간의 최소 수이다
    return removals;
}
```
