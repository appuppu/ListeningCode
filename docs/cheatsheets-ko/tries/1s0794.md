# Finding All Words From a Dictionary in a Grid — 그리드에서 사전의 모든 단어를 동시에 탐색하기

## 문제의 본질

문자의 2D 그리드 `board`와 단어 리스트 `words`가 주어진다. 그리드에서 인접한 셀(상하좌우)을 순서대로 따라가며 구성할 수 있는 단어를 `words` 중에서 모두 찾아 반환한다. 각 셀은 하나의 단어를 구성하는 과정에서 한 번만 사용할 수 있다.

## 핵심 아이디어

단어 리스트의 모든 단어를 Trie에 저장하고, 그리드의 각 셀에서 DFS를 수행할 때 Trie 노드를 따라감으로써 모든 단어를 동시에 탐색한다. Trie의 가지가 존재하지 않는 방향으로의 DFS를 즉시 중단할 수 있으므로, 불필요한 탐색을 대폭 줄일 수 있다.

## 사고 프로세스

1. **여러 단어를 동시에 탐색하고 싶다**: 단어마다 개별적으로 DFS를 수행하면, 단어 수 × 그리드 전체 셀 수 × 최대 단어 길이의 계산량이 된다. 여러 단어가 같은 접두사를 공유하는 경우, 한 번의 DFS로 여러 단어를 동시에 탐색할 수 있으면 효율적이다
2. **공통 접두사 관리에는 Trie가 적합하다**: Trie는 접두사 트리라고도 불리며, 문자열의 공통 접두사를 하나의 경로로 공유한다. 모든 단어를 Trie에 삽입하면, DFS 중에 현재 경로가 어떤 단어의 접두사에 해당하는지를 O(1)로 판정할 수 있다
3. **Trie 노드에 단어 자체를 저장한다**: 단어의 마지막 노드에 완성된 단어 문자열을 저장해 두면, DFS가 해당 노드에 도달한 시점에서 "어떤 단어를 찾았는지"를 즉시 얻을 수 있다
4. **그리드의 각 셀에서 Trie의 루트를 기점으로 DFS를 수행한다**: 각 셀을 시작점으로 하여 Trie의 루트에서 문자를 따라가며 DFS를 수행한다. 현재 문자에 대응하는 자식 노드가 Trie에 존재하지 않으면, 해당 방향의 탐색을 즉시 중단한다(가지치기)
5. **방문한 셀의 마킹**: DFS 중에 같은 셀을 다시 방문하지 않도록, 현재 방문 중인 셀의 문자를 특수 문자 `'#'`로 일시적으로 교체한다. DFS 종료 후에 원래 문자로 복원한다(백트래킹)
6. **중복 방지**: 같은 단어가 여러 경로에서 발견될 가능성이 있다. 단어를 결과 리스트에 추가한 시점에서 해당 Trie 노드의 `word`를 `null`로 설정함으로써, 같은 단어의 중복 추가를 방지한다

## 사전 지식

### Trie(트라이)란

문자열의 집합을 효율적으로 저장하고 검색하기 위한 트리 구조이다. 각 노드는 최대 26개의 자식 노드(a~z)를 가지며, 루트에서 리프까지의 경로가 하나의 문자열을 나타낸다. 공통 접두사를 가진 문자열은 경로를 공유하므로, 접두사 판정을 O(문자열 길이)로 수행할 수 있다.

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a~z 26글자에 대한 자식 노드 배열
    String word = null;                       // 이 노드에서 완성되는 단어 (끝이 아니면 null)
}

// Trie에 단어 삽입
TrieNode root = new TrieNode();
TrieNode node = root;
for (char c : "cat".toCharArray()) {
    int i = c - 'a';                          // 문자를 인덱스로 변환 ('a'→0, 'b'→1, ...)
    if (node.children[i] == null)
        node.children[i] = new TrieNode();    // 자식 노드가 없으면 새로 생성
    node = node.children[i];                  // 자식 노드로 이동
}
node.word = "cat";                            // 마지막 노드에 단어를 저장
```

### 백트래킹이란

DFS(깊이 우선 탐색)의 일종으로, 탐색 중에 상태를 변경하고 탐색 종료 후에 상태를 원래대로 되돌리는 기법이다. 이를 통해 하나의 탐색 경로에서 사용한 상태 변경이 다른 경로에 영향을 주지 않음을 보장한다.

```java
board[r][c] = '#';    // 방문 중 마크를 붙인다 (다른 경로가 이 셀을 다시 방문하지 않도록 한다)
// ... DFS로 상하좌우를 탐색 ...
board[r][c] = ch;     // 원래 문자로 복원한다 (다른 시작점에서의 탐색에서 재사용 가능하게 한다)
```

### char와 int의 변환

Java에서 `char` 타입은 정수값을 가지므로, 문자의 차이를 계산하여 인덱스로 변환할 수 있다.

```java
char ch = 'c';
int index = ch - 'a';   // 'c' - 'a' = 2 (배열의 인덱스로 사용)
```

## 계산량

| | 값 |
|---|---|
| Time | O(M × N × 4^L) — M×N은 그리드의 셀 수, L은 최장 단어의 길이이다. 각 셀에서 최대 4방향으로 L번 재귀한다 |
| Space | O(모든 단어의 문자 수 합계) — Trie에 모든 단어를 저장하는 공간이다 |

## 코드

```java
// 입력: 문자의 2D 배열 board와 문자열 배열 words
// 출력: board 위에서 구성 가능한 모든 단어를 담은 List<String>을 반환한다

class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a~z의 자식 노드
    String word = null;                       // 이 노드에서 완성되는 단어
}

// 모든 단어를 Trie에 삽입하고 루트 노드를 반환한다
TrieNode buildTrie(String[] words) {
    // 빈 Trie를 구축하기 위해 루트 노드를 하나 생성한다 (모든 단어 탐색의 기점)
    TrieNode root = new TrieNode();
    // words의 각 단어를 Trie에 삽입한다
    for (String w : words) {
        TrieNode node = root;
        // 루트에서 한 글자씩 자식 노드를 따라간다
        for (char c : w.toCharArray()) {
            int i = c - 'a';
            // 자식 노드가 존재하지 않으면 새로 생성한다
            if (node.children[i] == null)
                node.children[i] = new TrieNode();
            node = node.children[i];
        }
        // 단어의 마지막 노드에 단어 문자열을 저장한다 (DFS 중에 노드 도달 시 완성된 단어를 즉시 얻을 수 있다)
        node.word = w;
    }
    return root;
}

// Trie 노드를 따라가며 그리드 위에서 DFS를 수행한다
void dfs(char[][] board, int r, int c,
    TrieNode node, List<String> res) {
    // 경계 검사: 행 r 또는 열 c가 그리드의 범위를 벗어나면 즉시 리턴한다
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length)
        return;
    char ch = board[r][c];
    // 방문 중 마크 '#'인 셀이면 즉시 리턴한다 (같은 경로 내에서의 재방문을 방지한다)
    if (ch == '#') return;
    // 현재 문자에 대응하는 Trie의 자식 노드를 가져온다
    TrieNode next = node.children[ch - 'a'];
    // 자식 노드가 없으면 이 방향으로 이어지는 단어가 Trie에 존재하지 않는다 (가지치기)
    if (next == null) return;
    // 단어가 완성되었으면 결과에 추가하고, 중복 방지를 위해 null로 설정한다
    // (같은 단어가 여러 경로에서 발견될 가능성이 있기 때문이다)
    if (next.word != null) {
        res.add(next.word);
        next.word = null;
    }
    // 현재 셀을 '#'로 교체하여 방문 중으로 마킹한다
    board[r][c] = '#';
    // 상하좌우 4방향에 대해 next 노드를 전달하여 재귀적으로 DFS를 수행한다
    dfs(board, r + 1, c, next, res);
    dfs(board, r - 1, c, next, res);
    dfs(board, r, c + 1, next, res);
    dfs(board, r, c - 1, next, res);
    // 셀의 문자를 원래의 ch로 복원한다 (백트래킹: 다른 시작점에서의 탐색에서 재사용 가능하게 한다)
    board[r][c] = ch;
}

// 메인 함수: 그리드에서 사전의 모든 단어를 탐색한다
List<String> findWords(char[][] board, String[] words) {
    // 모든 단어를 Trie에 삽입한다
    TrieNode root = buildTrie(words);
    // 결과를 저장할 빈 리스트를 생성한다
    List<String> res = new ArrayList<>();
    // 이중 for 루프로 모든 셀 (i, j)을 순회하고, 각 셀을 시작점으로 DFS를 실행한다
    // DFS에는 Trie의 루트 노드를 전달한다
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            dfs(board, i, j, root, res);
        }
    }
    // 모든 셀에서의 DFS가 완료된 후 결과를 반환한다
    return res;
}
```
