# Designing a Word Dictionary With Wildcard Search — 와일드카드 포함 사전 단어 검색

## 문제의 본질

단어의 추가와 검색이라는 두 가지 연산을 지원하는 데이터 구조를 설계한다. 검색 시 점 `.`은 임의의 한 문자에 매칭되는 와일드카드로 기능한다. 예를 들어, 사전에 "bad"가 등록되어 있을 때, `search("b.d")`는 `true`를 반환하고, `search("b.e")`는 `false`를 반환한다.

## 핵심 아이디어

Trie에 단어를 저장하고, 일반 문자는 해당 자식 노드를 하나만 따라가면 되지만, 점을 만나면 "모든 자식 노드"로 분기하여 깊이 우선 탐색을 수행하면 임의의 한 문자에 매칭되는 검색을 구현할 수 있다.

## 사고 프로세스

1. **단어의 추가와 전방 일치 검색을 효율적으로 수행하고 싶다**: 문자열을 한 문자씩 공유하면서 저장할 수 있는 데이터 구조로 Trie가 적합하다. Trie를 사용하면 공통 접두사를 가진 단어끼리 노드를 공유할 수 있어 메모리 효율과 검색 효율을 모두 달성할 수 있다
2. **일반 문자의 검색은 Trie의 기본 연산으로 대응할 수 있다**: 문자 `c`에 대해서는 현재 노드의 `children[c - 'a']`를 따라가기만 하면 된다. 자식 노드가 `null`이면 불일치이고, 존재하면 다음 문자로 진행한다
3. **점은 모든 자식 노드로의 분기를 의미한다**: 점은 임의의 한 문자에 매칭되므로, 현재 노드의 26개 자식 노드 중 `null`이 아닌 것을 모두 시도해야 한다. 어느 하나라도 나머지 문자열과 매칭되면 `true`를 반환하면 된다
4. **분기의 탐색에는 깊이 우선 탐색(DFS)을 사용한다**: 점에서 분기한 각 경로를 재귀적으로 따라가며, 단어의 끝에 도달했을 때 `isEnd` 플래그가 `true`이면 검색 성공으로 판정한다. DFS를 사용하면 분기 처리와 일반 문자 처리를 통일적으로 다룰 수 있다
5. **재귀의 종료 조건을 정한다**: 문자열의 모든 문자를 처리한 시점(`idx == word.length()`)에서 현재 노드의 `isEnd`가 `true`이면 단어가 존재한다. 도중에 자식 노드가 `null`이 된 경우 해당 경로에서는 불일치로 판정한다
6. **최종적으로 반환하는 값**: `search` 메서드는 루트 노드에서 재귀적으로 DFS를 시작하여, 매칭되는 경로가 하나라도 있으면 `true`를, 없으면 `false`를 반환한다

## 사전 지식

### Trie(트라이)란

문자열을 한 문자씩 노드로 분해하여 저장하는 트리 구조이다. 각 노드는 최대 26개의 자식 노드(a~z)를 가지며, 루트에서 리프를 향해 따라가면 하나의 단어가 된다. 공통 접두사를 가진 단어는 노드를 공유하므로 사전 저장에 적합하다.

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a~z에 대응하는 26개의 자식 노드
    boolean isEnd = false;                    // 이 지점에서 끝나는 단어가 존재하는지 여부
}
```

### 깊이 우선 탐색(DFS)이란

트리나 그래프의 탐색 기법 중 하나이다. 하나의 경로를 끝까지 진행한 후, 막다른 곳에 도달하면 하나 되돌아가서 다른 경로를 시도한다. 재귀로 구현하는 것이 자연스러우며, Trie의 분기 탐색에 적합하다.

```java
boolean dfs(TrieNode node, String word, int idx) {
    // idx는 현재 처리 중인 문자 위치
    // 재귀적으로 자식 노드를 따라가며 조건을 만족하는 경로를 탐색한다
}
```

### char의 정수 변환

Java에서 `char` 타입은 정수 값을 가진다. `c - 'a'`로 문자 `c`의 알파벳 상 위치(0~25)를 얻을 수 있다. 이 값을 Trie의 `children` 배열 인덱스로 사용한다.

```java
char c = 'd';
int idx = c - 'a';  // idx = 3 ('a'=0, 'b'=1, 'c'=2, 'd'=3)
```

## 계산량

| | 값 |
|---|---|
| Time (addWord) | O(m) — 단어의 길이 m에 비례하여 Trie 노드를 따라간다 |
| Time (search) | O(26^d × m) — d는 점의 개수, m은 단어의 길이이다. 점이 없으면 O(m)이다 |
| Space | O(n × m) — n개의 단어(평균 길이 m)를 Trie에 저장한다 |

## 코드

```java
// 입력: addWord(word)는 문자열 word를 받아 사전에 추가한다. search(word)는 문자열 word("."를 포함할 수 있음)를 받는다
// 출력: search는 사전에 일치하는 단어가 존재하면 true를, 존재하지 않으면 false를 반환한다

class TrieNode {
    TrieNode[] children;  // a~z에 대응하는 26개의 자식 노드
    boolean isEnd;        // 이 지점에서 끝나는 단어가 존재하는지 여부

    TrieNode() {
        children = new TrieNode[26];
        isEnd = false;
    }
}

class WordDictionary {
    TrieNode root;  // Trie의 루트 노드

    WordDictionary() {
        root = new TrieNode();
    }

    // 단어를 Trie에 추가한다
    void addWord(String word) {
        // 현재 노드를 루트로 초기화한다
        TrieNode node = root;
        // 단어의 각 문자를 처음부터 순서대로 처리한다
        for (char c : word.toCharArray()) {
            // c - 'a'로 children 배열에서 문자 c가 대응하는 위치를 구한다
            int idx = c - 'a';
            // 자식 노드가 존재하지 않으면 새로 생성한다
            if (node.children[idx] == null)
                node.children[idx] = new TrieNode();
            // 자식 노드로 이동한다
            node = node.children[idx];
        }
        // 단어의 끝을 기록한다. 이 지점에서 끝나는 단어가 사전에 존재함을 나타낸다
        node.isEnd = true;
    }

    // 와일드카드 포함 검색을 루트에서 시작한다
    boolean search(String word) {
        // 루트 노드에서 위치 0으로 DFS를 시작한다
        return dfs(root, word, 0);
    }

    // DFS로 재귀적으로 Trie를 탐색한다
    boolean dfs(TrieNode node, String word, int idx) {
        // 종료 조건: 모든 문자를 처리했으면 현재 노드가 단어의 끝인지를 반환한다
        // true이면 단어가 존재하고, false이면 도중까지만 일치하는 단어가 있다
        if (idx == word.length())
            return node.isEnd;

        char c = word.charAt(idx);

        if (c == '.') {
            // 점인 경우: 26개의 자식 노드를 모두 시도한다 (임의의 한 문자에 매칭)
            for (TrieNode child : node.children) {
                // null이 아닌 자식 노드에 대해 재귀적으로 탐색한다
                if (child != null && dfs(child, word, idx + 1))
                    return true;  // 어느 경로에서든 매칭되면 즉시 true를 반환한다
            }
            // 모든 자식 노드를 시도해도 true가 반환되지 않으면 불일치이다
            return false;
        } else {
            // 일반 문자인 경우: c - 'a'로 인덱스를 구하고 대응하는 자식 노드를 따라간다
            int i = c - 'a';
            // 자식 노드가 존재하지 않으면 대응하는 문자가 없으므로 불일치이다
            if (node.children[i] == null)
                return false;
            // 자식 노드가 존재하면 다음 문자 위치 idx + 1로 재귀한다
            return dfs(node.children[i], word, idx + 1);
        }
    }
}
```
