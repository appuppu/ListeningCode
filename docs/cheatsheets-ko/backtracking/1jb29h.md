# Generating All Valid Parentheses Combinations — n쌍의 괄호로 유효한 조합을 모두 생성하기

## 문제의 본질

정수 `n`이 주어진다. `n`개의 여는 괄호 `(`와 `n`개의 닫는 괄호 `)`를 사용하여, 올바르게 중첩된 괄호 문자열을 **모두** 생성하고 리스트로 반환한다. 각 문자열의 길이는 `2 * n`이며, 어떤 위치에서도 닫는 괄호의 누적 수가 여는 괄호의 누적 수를 초과해서는 안 된다.

## 핵심 아이디어

문자열을 한 문자씩 구축할 때, "여는 괄호의 남은 수"와 "닫는 괄호의 남은 수"라는 2가지 상태만으로 다음에 놓을 수 있는 문자가 결정된다. 여는 괄호는 `n`개 미만이면 추가할 수 있고, 닫는 괄호는 여는 괄호보다 적을 때만 추가할 수 있다. 이 조건으로 분기를 가지치기하면, 무효한 문자열을 한 번도 생성하지 않고 모든 유효한 조합을 열거할 수 있다.

## 사고 프로세스

1. **모든 조합을 열거해야 한다**: 문제는 "모두 생성하라"고 요구하고 있으므로, 탐색적으로 모든 패턴을 열거하는 기법이 필요하다. 문자열을 한 문자씩 구축하면서 분기하는 백트래킹이 적합하다
2. **각 단계에서 선택지는 2가지뿐이다**: 문자열의 각 위치에 놓을 수 있는 문자는 `(` 또는 `)` 2가지뿐이다. 이 2가지 선택을 재귀적으로 반복함으로써 모든 후보를 탐색할 수 있다
3. **무효한 분기를 조기에 차단하고 싶다**: 모든 2가지 선택을 시도하면 `2^(2n)`가지가 되지만, 대부분은 무효하다. 유효성 조건은 2가지이다. 여는 괄호를 `n`개보다 많이 사용할 수 없다는 것과, 닫는 괄호의 수가 해당 시점의 여는 괄호의 수를 초과해서는 안 된다는 것이다. 이 2가지 조건으로 분기를 가지치기한다
4. **상태는 2개의 변수로 관리할 수 있다**: `open`(사용한 여는 괄호의 수)과 `close`(사용한 닫는 괄호의 수)를 재귀 함수에 전달한다. `open < n`이면 `(`를 추가할 수 있고, `close < open`이면 `)`를 추가할 수 있다
5. **문자열의 길이가 `2 * n`에 도달하면 완성이다**: `open`과 `close`의 조건을 지키면서 구축한 문자열이 `2 * n`자에 도달한 시점에서, 그 문자열은 반드시 유효하다. 결과 리스트에 추가한다
6. **백트래킹으로 상태를 복원한다**: `StringBuilder`에 문자를 추가하고 재귀한 후, `deleteCharAt`으로 마지막 문자를 삭제하여 원래 상태로 되돌린다. 이렇게 함으로써 하나의 `StringBuilder` 인스턴스를 모든 탐색 경로에서 공유할 수 있다

## 사전 지식

### 백트래킹이란

선택→재귀→취소를 반복하여 모든 유효한 조합을 열거하는 탐색 기법이다. 각 단계에서 선택지 중 하나를 선택하고, 재귀적으로 다음 단계로 진행한다. 재귀에서 돌아오면 선택을 취소(백트래킹)하고, 다른 선택지를 시도한다. 가지치기 조건을 추가함으로써 무효한 경로를 조기에 차단할 수 있다.

```java
// 백트래킹의 기본 패턴
void backtrack(상태) {
    if (종료조건) {
        결과에 추가;
        return;
    }
    for (각 선택지) {
        선택을 적용;        // 예: sb.append('(')
        backtrack(다음 상태);
        선택을 취소;        // 예: sb.deleteCharAt(sb.length() - 1)
    }
}
```

### StringBuilder란

문자열을 효율적으로 조립하기 위한 클래스이다. `String`은 불변(immutable)이므로 문자를 추가할 때마다 새로운 객체가 생성되지만, `StringBuilder`는 내부 버퍼를 직접 조작하므로 추가·삭제를 O(1)로 수행할 수 있다.

```java
StringBuilder sb = new StringBuilder();  // 빈 StringBuilder를 생성
sb.append('(');          // 끝에 문자를 추가 → "("
sb.append(')');          // 끝에 문자를 추가 → "()"
sb.length();             // 현재 문자 수를 반환 → 2
sb.deleteCharAt(1);      // 인덱스 1의 문자를 삭제 → "("
sb.toString();           // String 타입으로 변환하여 반환 → "("
```

### 괄호의 유효성 조건

괄호 문자열이 "유효"하다는 것은 다음 2가지 조건을 만족하는 것이다.
- **조건1**: 여는 괄호와 닫는 괄호의 수가 같다
- **조건2**: 문자열의 임의의 위치에서, 처음부터 해당 위치까지의 닫는 괄호의 수가 여는 괄호의 수를 초과하지 않는다

예: `n=2`일 때, `(())`와 `()()`는 유효하다. `)()(` 는 조건2를 위반하고, `((()` 는 조건1을 위반한다.

## 계산량

| | 값 |
|---|---|
| Time | O(4^n / √n) — 생성되는 유효한 괄호 문자열의 수는 카탈란 수 C(n) = C(2n,n)/(n+1)이며, 이는 O(4^n / (n√n))에 점근한다. 각 문자열의 구축에 O(n)이 걸리므로, 전체적으로 O(4^n / √n)이 된다 |
| Space | O(n) — 재귀의 깊이는 최대 2n이며, StringBuilder의 길이도 최대 2n이다. 결과 리스트를 제외하면 사용하는 공간은 O(n)이다 |

## 코드

```java
// 입력: 정수 n (괄호의 쌍 수)
// 출력: 유효한 괄호 문자열을 모두 담은 List<String>을 반환
private void backtrack(StringBuilder sb, int open, int close, int n, List<String> res) {
    // 문자열의 길이가 2n에 도달하면, 여는 괄호와 닫는 괄호를 정확히 n개씩 사용했으므로 유효한 괄호 문자열이 완성됨
    if (sb.length() == 2 * n) {
        res.add(sb.toString());
        return;
    }
    // 어떤 조건도 만족하지 않는 경우, 더 이상 문자를 추가할 수 없으므로 아무것도 하지 않고 return하며, 호출원에서 백트래킹이 진행됨

    // 여는 괄호가 n개 미만이면, 아직 여는 괄호를 추가할 수 있음
    if (open < n) {
        sb.append('(');
        backtrack(sb, open + 1, close, n, res);
        // 백트래킹의 핵심: 끝의 '('를 삭제하여 상태를 복원하고, 다음 분기(닫는 괄호 추가)를 올바른 상태에서 시도함
        sb.deleteCharAt(sb.length() - 1);
    }

    // 주의: 조건이 close < n이 아니라 close < open인 점이 중요
    // close < n으로 하면 닫는 괄호가 여는 괄호를 초과하는 경우(예: ")(")를 허용하게 되지만,
    // close < open으로 하면 항상 닫는 괄호의 수가 여는 괄호의 수 이하로 유지되어 무효한 문자열의 생성을 방지할 수 있음
    if (close < open) {
        sb.append(')');
        backtrack(sb, open, close + 1, n, res);
        sb.deleteCharAt(sb.length() - 1);  // 상태를 복원함
    }
}

public List<String> generateParenthesis(int n) {
    // 모든 유효한 괄호 문자열을 저장할 리스트
    List<String> res = new ArrayList<>();
    // 빈 StringBuilder와 open=0, close=0에서 탐색을 시작함
    backtrack(new StringBuilder(), 0, 0, n, res);
    return res;
}
```
