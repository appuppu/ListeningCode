# Searching for a Word in a Grid — 그리드 내의 문자를 따라가며 단어를 구성할 수 있는지 판정한다

## 문제의 본질

2D 문자 그리드 `board`와 문자열 `word`가 주어진다. 그리드 내의 인접한 셀(상하좌우)을 순서대로 따라가며 `word`를 구성할 수 있는지를 판정하고, `boolean`으로 반환한다. 각 셀은 하나의 경로에서 1회만 사용할 수 있다.

## 핵심 아이디어

그리드의 각 셀을 시작점으로 DFS를 수행하며, 단어의 문자를 한 글자씩 매칭시킨다. 방문한 셀을 별도의 배열로 관리하는 대신, 보드의 셀을 직접 특수 문자로 덮어쓰고 탐색 후에 원래대로 복원함으로써, 공간 계산량을 재귀 스택의 깊이만큼으로 억제한다.

## 사고 프로세스

1. **각 셀이 시작점이 될 수 있다**: 단어의 시작 위치는 그리드의 어떤 셀이든 가능하므로, 모든 셀을 시작점 후보로 시도해야 한다
2. **한 글자씩 순서대로 매칭시킨다**: 현재 셀의 문자가 `word`의 현재 위치 문자와 일치하는지를 확인하고, 일치하면 상하좌우의 인접 셀로 재귀적으로 탐색을 진행한다. 이 구조는 DFS(깊이 우선 탐색) 그 자체이다
3. **같은 셀의 재사용을 방지한다**: 하나의 경로에서 같은 셀을 2회 사용할 수 없으므로, 방문 여부 관리가 필요하다. 별도의 `boolean[][]` 방문 배열을 두는 방법도 있지만, 공간을 소비한다
4. **보드를 직접 덮어써서 방문 여부를 표현한다**: 탐색에 진입할 때 현재 셀의 문자를 `'#'` 등 보드에 존재하지 않는 특수 문자로 덮어쓰면, 재귀 호출에서 같은 셀에 매칭되는 일이 없어진다. 이를 통해 방문 배열이 불필요해지고, 공간 계산량이 재귀 스택의 깊이 O(L)만으로 충분해진다
5. **탐색 후에 원래 문자를 복원한다**: DFS의 돌아오는 과정에서 덮어쓴 `'#'`을 원래 문자로 되돌린다(백트래킹). 이를 통해 다른 시작점에서의 탐색에서 같은 셀을 올바르게 사용할 수 있다
6. **탐색의 종료 조건을 정리한다**: 인덱스 `idx`가 `word.length()`에 도달하면 모든 문자 매칭이 성공한 것이므로 `true`를 반환한다. 범위 밖이거나 문자가 불일치하는 경우에는 `false`를 반환한다. 4방향 중 하나라도 `true`를 반환하면 그 시점에서 `true`를 반환한다

## 전제 지식

### DFS(깊이 우선 탐색)란

그래프나 그리드의 탐색 기법이다. 하나의 방향으로 갈 수 있는 곳까지 진행하고, 막다른 곳에 도달하면 하나 되돌아가서 다른 방향을 시도한다. 재귀 호출로 자연스럽게 구현할 수 있다.

```java
void dfs(int node) {
    // node를 처리한다
    for (int neighbor : getNeighbors(node)) {
        dfs(neighbor);  // 인접 노드로 재귀적으로 진행한다
    }
}
```

### 백트래킹이란

탐색 중에 수행한 변경을 탐색에서 되돌아올 때 원래대로 복원하는 기법이다. "시도한다 → 진행한다 → 되돌린다"의 사이클을 통해 모든 후보를 빠짐없이 탐색할 수 있다.

```java
board[r][c] = '#';   // 변경한다 (방문 완료로 표시한다)
dfs(...);            // 재귀적으로 탐색을 진행한다
board[r][c] = temp;  // 원래대로 되돌린다 (미방문 상태로 복원한다)
```

### charAt란

`String`의 지정 위치의 문자를 `char` 타입으로 반환하는 메서드이다. 인덱스는 0부터 시작한다.

```java
String word = "ABCCED";
word.charAt(0);   // 'A'를 반환한다
word.charAt(3);   // 'C'를 반환한다
word.length();    // 6을 반환한다 (문자 수를 반환한다)
```

### 2D 그리드의 4방향 탐색

2D 그리드에서 상하좌우의 인접 셀을 탐색하려면, 행과 열 각각에 ±1하는 4가지 패턴을 시도한다.

```java
// 상·하·좌·우 순서로 탐색한다
dfs(board, word, r-1, c, idx+1);  // 상 (행을 -1)
dfs(board, word, r+1, c, idx+1);  // 하 (행을 +1)
dfs(board, word, r, c-1, idx+1);  // 좌 (열을 -1)
dfs(board, word, r, c+1, idx+1);  // 우 (열을 +1)
```

## 계산량

| | 값 |
|---|---|
| Time | O(m × n × 4^L) — 모든 셀을 시작점으로, 각 시작점에서 최대 4방향을 L문자분 탐색한다 (m×n은 그리드 크기, L은 단어의 길이) |
| Space | O(L) — 재귀 스택의 깊이가 최대 L이다. 보드를 직접 덮어쓰므로 방문 배열은 불필요하다 |

## 코드

```java
// 입력: 2D 문자 배열 board와 문자열 word
// 출력: word를 그리드 내의 인접 셀로 구성할 수 있으면 true, 구성할 수 없으면 false를 반환한다

// 현재 위치(r,c)에서 word[idx] 이후를 매칭시키는 DFS
boolean dfs(char[][] board, String word, int r, int c, int idx) {
    // idx가 word.length()와 같으면 모든 문자의 매칭이 완료된 것이므로 true를 반환한다
    if (idx == word.length()) return true;

    // r 또는 c가 그리드의 범위 밖이거나, board[r][c]가 word.charAt(idx)와 일치하지 않으면 false를 반환한다
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length
        || board[r][c] != word.charAt(idx))
        return false;

    // 현재 셀의 문자를 변수 temp에 대피시키고, '#'으로 덮어써서 재방문을 방지한다
    // '#'은 영문자와 일치하지 않으므로, 재귀 호출에서 이 셀이 다시 매칭되는 것을 방지한다 (방문 배열의 대체)
    char temp = board[r][c];
    board[r][c] = '#';

    // 상하좌우 4방향으로 재귀 탐색한다 (어느 하나라도 true이면 성공)
    // ||의 단락 평가에 의해, true가 발견된 시점에서 나머지 방향의 탐색은 생략된다
    boolean found =
        dfs(board, word, r - 1, c, idx + 1)
     || dfs(board, word, r + 1, c, idx + 1)
     || dfs(board, word, r, c - 1, idx + 1)
     || dfs(board, word, r, c + 1, idx + 1);

    // 탐색 결과에 관계없이 원래 문자를 복원한다 (백트래킹)
    // 이를 통해 다른 시작점이나 다른 경로에서의 탐색에서 같은 셀을 올바르게 사용할 수 있는 상태로 되돌린다
    board[r][c] = temp;
    return found;
}

boolean exist(char[][] board, String word) {
    int m = board.length;
    int n = board[0].length;

    // 그리드의 모든 셀(i,j)을 이중 for 루프로 순회하며, 각 셀을 시작점으로 DFS를 호출한다
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // dfs가 true를 반환한 시점에서 true를 반환한다
            if (dfs(board, word, i, j, 0))
                return true;

    // 모든 셀을 시도해도 찾지 못하면 false를 반환한다
    return false;
}
```
