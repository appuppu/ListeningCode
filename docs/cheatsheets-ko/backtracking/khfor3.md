# Placing N Queens on a Board Without Conflicts — N개의 퀸을 충돌 없이 배치하기

## 문제의 본질

정수 `n`이 주어진다. n×n 체스보드 위에 n개의 퀸을, 어떤 두 퀸도 같은 행·같은 열·같은 대각선 위에 존재하지 않도록 배치한다. 조건을 만족하는 모든 보드 구성을 문자열의 리스트로 반환한다.

## 핵심 아이디어

행마다 하나씩 퀸을 배치하면 행의 충돌은 자동으로 제거할 수 있다. 나머지 열·정대각선·역대각선의 충돌 판정을 비트마스크의 각 비트로 관리하면, O(1)의 상수 시간으로 충돌 검사와 상태 갱신을 할 수 있다.

## 사고 과정

1. **행의 충돌을 구조적으로 제거한다**: n개의 퀸을 n행에 배치하므로, 각 행에 반드시 하나만 퀸을 놓으면 행의 충돌은 발생하지 않는다. 따라서 문제는 "각 행에서 어느 열에 퀸을 놓을 것인가"를 결정하는 탐색으로 귀결된다
2. **열과 대각선의 충돌을 검출해야 한다**: 열의 충돌은 "이미 사용한 열의 집합"으로 관리할 수 있다. 대각선의 충돌은, 정대각선(오른쪽 위 방향, row + col이 같음)과 역대각선(왼쪽 위 방향, row - col이 같음)의 2종류가 있다. 이 3가지 집합을 관리하면 모든 충돌을 검출할 수 있다
3. **비트마스크로 집합을 표현한다**: 열·정대각선·역대각선의 사용 상황을 정수의 비트로 표현한다. 제c비트가 1이면 "해당 열(또는 대각선)은 사용 완료"를 의미한다. 비트 연산의 AND로 충돌 판정, OR로 등록을 할 수 있으며, HashSet보다 빠르게 동작한다
4. **대각선의 비트마스크를 행마다 시프트한다**: 정대각선은 행이 하나 내려가면 영향 범위가 왼쪽으로 한 칸 이동하므로 왼쪽 시프트(`<< 1`), 역대각선은 오른쪽으로 한 칸 이동하므로 오른쪽 시프트(`>> 1`)로 갱신한다. 이렇게 하면 대각선의 충돌 판정을 열 번호의 비트 위치만으로 수행할 수 있다
5. **백트래킹으로 모든 해를 탐색한다**: 행 0부터 행 n-1까지 순서대로, 각 행에서 충돌하지 않는 열을 시도한다. 충돌하지 않는 열을 찾으면 퀸을 배치하고 다음 행으로 재귀하며, 행 n에 도달하면 해를 하나 기록한다. 재귀에서 돌아오면 자동으로 배치가 취소되어 다른 열을 시도할 수 있다
6. **해의 총 수를 반환한다**: 모든 행에 퀸을 배치할 수 있었던(row == n에 도달한) 횟수를 합산하여 반환한다

## 전제 지식

### 백트래킹이란

선택지를 하나 시도하고, 막다른 길에 이르면 직전의 선택으로 돌아가 다른 선택지를 시도하는 탐색 기법이다. 재귀 호출로 "시도→전진→복귀"를 자연스럽게 구현할 수 있다. 모든 유효한 조합을 열거하는 문제에 적합하다.

```java
void backtrack(int step) {
    if (step == goal) {       // 목표에 도달하면 해를 기록한다
        recordSolution();
        return;
    }
    for (int choice : choices) {
        if (isValid(choice)) {    // 선택이 유효하면 시도한다
            apply(choice);        // 선택을 적용한다
            backtrack(step + 1);  // 다음 단계로 재귀한다
            undo(choice);         // 선택을 취소하고 다른 선택지를 시도한다
        }
    }
}
```

### 비트마스크란

정수의 각 비트를 "집합의 원소가 있는지 없는지"의 플래그로 사용하는 기법이다. 집합 연산을 비트 연산으로 고속으로 수행할 수 있다.

```java
int mask = 0;             // 빈 집합 (모든 비트가 0)
int bit = 1 << c;         // 제c비트만 1인 값을 만든다 (원소 c를 나타낸다)
mask |= bit;              // 원소 c를 집합에 추가한다 (제c비트를 1로 설정한다)
(mask & bit) != 0;        // 원소 c가 집합에 포함되는지를 판정한다 → true/false
```

### 비트 시프트를 이용한 대각선 추적

체스보드에서 행이 하나 내려가면, 정대각선(오른쪽 위 ↗ 방향)의 영향은 열 번호가 하나 작은 쪽으로 이동하고, 역대각선(왼쪽 위 ↖ 방향)의 영향은 열 번호가 하나 큰 쪽으로 이동한다. 비트마스크를 시프트하여 이 이동을 표현한다.

```java
int posDiag = 0;          // 정대각선의 사용 상황을 관리하는 비트마스크
posDiag |= (1 << c);      // 열 c에 놓은 퀸의 정대각선을 등록한다
posDiag << 1;              // 다음 행에서는 영향이 왼쪽으로 1열 이동한다 (왼쪽 시프트)

int negDiag = 0;          // 역대각선의 사용 상황을 관리하는 비트마스크
negDiag |= (1 << c);      // 열 c에 놓은 퀸의 역대각선을 등록한다
negDiag >> 1;              // 다음 행에서는 영향이 오른쪽으로 1열 이동한다 (오른쪽 시프트)
```

## 계산량

| | 값 |
|---|---|
| Time | O(n!) — 각 행에서 선택할 수 있는 열의 수가 최대 n, n-1, n-2, ...로 감소한다 |
| Space | O(n) — 재귀의 깊이가 n단이며, 각 단의 비트마스크는 상수 개의 정수뿐이다 |

## 코드

```java
// 입력: 정수 n (체스보드의 크기이자 배치할 퀸의 수)
// 출력: n개의 퀸을 충돌 없이 배치할 수 있는 보드의 총 수를 int로 반환한다
int totalNQueens(int n) {
    // 행 0부터 탐색을 시작하고, 열·정대각선·역대각선의 비트마스크를 모두 빈 상태(0)로 초기화한다
    return backtrack(0, n, 0, 0, 0);
}

int backtrack(int row, int n,
    int cols, int posDiag,
    int negDiag) {
    // 모든 행에 퀸을 배치했으므로, 해를 하나 찾았다
    if (row == n) return 1;

    // 이 행 이후에서 찾은 해의 수를 누적하는 변수
    int count = 0;

    // 열 0부터 n-1까지 순회하며, 각 열에 퀸을 놓을 수 있는지를 판정한다
    for (int c = 0; c < n; c++) {
        // 열 c에 대응하는 비트를 만든다. 이 bit를 사용하여 3개의 비트마스크와의 충돌 판정을 수행한다
        int bit = 1 << c;

        // 열·정대각선·역대각선 중 하나라도 충돌하면 건너뛰고 다음 열을 시도한다
        if ((cols & bit) != 0 ||
            (posDiag & bit) != 0 ||
            (negDiag & bit) != 0)
            continue;

        // 열 c에 퀸을 배치하고, 3개의 비트마스크를 갱신하여 다음 행으로 재귀한다
        // cols | bit: 열 c를 사용 완료로 등록한다
        // (posDiag | bit) << 1: 정대각선을 등록하고, 다음 행으로의 이동을 왼쪽 시프트로 반영한다
        // (negDiag | bit) >> 1: 역대각선을 등록하고, 다음 행으로의 이동을 오른쪽 시프트로 반영한다
        // 비트마스크는 값 전달이므로, 재귀에서 돌아오면 자동으로 등록 전 상태로 복원되어 명시적인 취소 처리가 불필요하다
        count += backtrack(row + 1, n,
            cols | bit,
            (posDiag | bit) << 1,
            (negDiag | bit) >> 1);
    }
    // 모든 열을 시도한 결과의 해의 총 수를 반환한다
    return count;
}
```
