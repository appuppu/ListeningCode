# Generating All Unique Subsets With Duplicates — 중복 요소를 포함하는 배열에서 모든 유니크한 부분집합을 생성하기

## 문제의 본질

중복되는 값을 포함할 수 있는 정수 배열 `nums`가 주어진다. 모든 가능한 유니크한 부분집합을 반환해야 한다. 결과에 중복되는 부분집합을 포함해서는 안 되며, 각 부분집합의 요소 순서는 임의로 해도 된다.

## 핵심 아이디어

배열을 정렬해 두면, 같은 재귀 레벨에서 이전 요소와 같은 값을 선택하려 할 때 건너뛰기만 하면 중복 부분집합의 생성을 근본적으로 방지할 수 있다.

## 사고 프로세스

1. **부분집합 생성은 백트래킹의 전형적인 문제이다**: 각 요소에 대해 「선택할지 선택하지 않을지」를 재귀적으로 결정해 나가면 모든 부분집합을 열거할 수 있다. 재귀의 각 단계에서 현재의 부분집합을 그대로 결과에 추가하면 모든 부분집합을 얻을 수 있다
2. **중복의 원인을 특정한다**: 배열에 같은 값이 여러 개 있으면, 예를 들어 `[1,2,2]`에서 첫 번째 2를 선택하는 경우와 두 번째 2를 선택하는 경우에 같은 부분집합이 생성된다. 중복은 「같은 재귀 레벨에서 같은 값을 여러 번 선택할 때」 발생한다
3. **정렬로 중복 요소를 인접시킨다**: 배열을 정렬하면 같은 값의 요소가 이웃하게 된다. 이로써 「이전 요소와 같은 값인지」를 단순한 비교로 판정할 수 있게 된다
4. **같은 재귀 레벨에서의 중복을 건너뛴다**: for 루프 내에서 `i > start && nums[i] == nums[i-1]` 조건을 만족할 때, 해당 요소를 건너뛴다. `i > start` 조건은 「같은 재귀 레벨의 두 번째 이후의 선택지」를 의미하며, 이로 인해 다른 재귀 레벨에서는 같은 값을 선택할 수 있다 (부분집합에 같은 값을 여러 개 포함하는 것은 허용된다)
5. **재귀의 각 단계에서 결과에 추가한다**: 재귀 함수의 맨 앞에서 현재의 부분집합 `curr`을 결과 리스트에 추가한다. 이로써 빈 집합부터 모든 요소를 포함하는 집합까지, 모든 부분집합이 결과에 포함된다
6. **백트래킹으로 원래 상태로 되돌린다**: 재귀 호출 후에 `curr`의 마지막 요소를 삭제하여 원래로 되돌림으로써, 다음 선택지를 올바르게 탐색할 수 있다

## 사전 지식

### 백트래킹이란

해의 후보를 재귀적으로 구축하고, 조건을 만족하지 않는 경우 직전의 선택을 취소하여 다른 선택을 시도하는 탐색 기법이다. 부분집합·순열·조합의 열거에 사용된다.

```java
// 백트래킹의 기본 구조
void backtrack(상태, 선택지리스트) {
    결과에 현재 상태를 추가;
    for (각 선택지) {
        선택을 적용;
        backtrack(다음 상태, 나머지 선택지);
        선택을 취소;  // ← 백트래킹
    }
}
```

### Arrays.sort란

배열을 오름차순으로 정렬하는 메서드이다. 중복 요소를 인접시킴으로써 중복 판정을 용이하게 한다.

```java
int[] nums = {4, 1, 4, 2};
Arrays.sort(nums);  // nums = {1, 2, 4, 4}가 된다
```

### ArrayList의 복사에 대해

`new ArrayList<>(list)`는 기존 리스트의 얕은 복사를 생성한다. 결과에 부분집합을 추가할 때, 참조가 아닌 복사를 추가하지 않으면 이후의 백트래킹에서 내용이 덮어씌워진다.

```java
List<Integer> curr = new ArrayList<>();
curr.add(1);
curr.add(2);
List<Integer> copy = new ArrayList<>(curr);  // [1, 2]의 복사를 생성
curr.remove(curr.size() - 1);               // curr는 [1]로 돌아가지만, copy는 [1, 2] 그대로이다
```

### List의 마지막 요소 삭제

`list.remove(list.size() - 1)`는 리스트의 마지막 요소를 삭제한다. 백트래킹에서 직전에 추가한 요소를 취소하기 위해 사용한다.

```java
List<Integer> curr = new ArrayList<>();
curr.add(5);        // curr = [5]
curr.add(3);        // curr = [5, 3]
curr.remove(curr.size() - 1);  // curr = [5]로 돌아간다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n × 2^n) — 최대 2^n개의 부분집합이 존재하며, 각 부분집합의 복사에 최대 O(n)이 소요된다 |
| Space | O(n) — 재귀의 깊이가 최대 n이며, 작업 리스트 `curr`의 길이도 최대 n이다 (결과 리스트를 제외) |

## 코드

```java
// 입력: 중복을 포함할 수 있는 정수 배열 nums
// 출력: 모든 유니크한 부분집합을 저장한 List<List<Integer>>를 반환한다
void backtrack(int[] nums, int start, List<Integer> curr, List<List<Integer>> result) {
    // 현재 부분집합의 복사를 결과에 추가한다
    // new ArrayList<>(curr)로 복사를 만드는 이유: curr는 이후의 재귀에서 내용이 변화하므로, 참조가 아닌 그 시점의 상태를 저장할 필요가 있다
    result.add(new ArrayList<>(curr));

    // start부터 탐색함으로써, 자신보다 앞의 요소를 선택하지 않고 부분집합의 요소 순서를 유지한다
    for (int i = start; i < nums.length; i++) {
        // 같은 재귀 레벨에서 이전 요소와 같은 값이면 건너뛰어 중복을 방지한다
        // i > start: 이 레벨의 첫 번째 선택지가 아니다 (다른 레벨에서는 같은 값을 선택해도 된다)
        // nums[i] == nums[i-1]: 이전 요소와 같은 값이다
        // 이 두 조건이 동시에 성립하면, 같은 레벨에서 같은 값을 2번 선택하게 되어 중복 부분집합이 발생한다
        if (i > start && nums[i] == nums[i - 1]) continue;

        // 현재 요소를 부분집합에 추가하고 다음 레벨로 진행한다
        curr.add(nums[i]);
        // i + 1을 전달함으로써, 다음 재귀 레벨에서는 현재 요소보다 뒤의 요소만을 선택 대상으로 한다
        backtrack(nums, i + 1, curr, result);

        // 백트래킹: 마지막 요소를 삭제하여 원래 상태로 되돌리고, 다음 이터레이션에서 다른 요소를 선택할 수 있도록 한다
        curr.remove(curr.size() - 1);
    }
}

public List<List<Integer>> subsetsWithDup(int[] nums) {
    // 정렬하여 같은 값의 요소를 인접시킨다. 이로써 nums[i] == nums[i-1]의 단순 비교로 중복 판정이 가능해진다
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    // 0은 「배열의 맨 앞부터 탐색을 시작한다」는 것을 의미한다
    backtrack(nums, 0, new ArrayList<>(), result);
    // 모든 재귀가 완료되었으며, result에는 모든 유니크한 부분집합이 저장되어 있다
    return result;
}
```
