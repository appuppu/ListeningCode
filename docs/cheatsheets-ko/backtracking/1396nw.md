# Partitioning a String Into Palindrome Substrings — 문자열을 회문 부분 문자열로 분할하는 모든 패턴을 구하기

## 문제의 본질

문자열 `s`가 주어진다. `s`를 분할하여 모든 부분 문자열이 회문(앞에서 읽어도 뒤에서 읽어도 같은 문자열)이 되는 분할 방법을 **모두** 열거하여 리스트의 리스트로 반환한다.

## 핵심 아이디어

임의의 부분 문자열이 회문인지 여부를 DP 테이블로 사전에 O(1) 판정할 수 있도록 준비해 두고, 백트래킹으로 앞에서부터 순서대로 「회문인 부분」을 잘라내며 재귀함으로써 모든 분할 패턴을 효율적으로 열거할 수 있다.

## 사고 과정

1. **분할 문제는 앞에서부터 순서대로 잘라내는 재귀로 표현할 수 있다**: 문자열의 시작 위치 `start`에서 끝까지의 범위에서, `start`부터 `end`까지의 부분 문자열을 하나 잘라내고, 나머지 부분을 재귀적으로 처리한다. `start`가 문자열의 끝에 도달하면 하나의 유효한 분할이 완성된다
2. **잘라내는 조건은 「해당 부분이 회문인 것」이다**: 모든 부분 문자열이 회문이어야 하므로, `s[start..end]`가 회문일 때만 잘라내어 경로에 추가하고 재귀를 진행한다. 회문이 아니면 해당 잘라내기 방법은 건너뛴다
3. **회문 판정을 매번 O(n)으로 수행하면 낭비가 많다**: 백트래킹의 각 단계에서 부분 문자열의 회문 판정을 수행하지만, 같은 부분 문자열을 여러 번 판정할 가능성이 있다. DP 테이블로 사전 계산하면 임의의 `s[l..r]`에 대한 회문 판정을 O(1)으로 단축할 수 있다
4. **DP 테이블의 구축 방법**: `dp[l][r]`은 「`s`의 인덱스 `l`부터 `r`까지의 부분 문자열이 회문인지 여부」를 나타내는 boolean이다. 회문의 조건은 「양 끝 문자가 같고」 「안쪽 부분 문자열도 회문」인 것이다. 길이 1(`l == r`)은 항상 회문이고, 길이 2(`r - l == 1`)는 양 끝이 같으면 회문이며, 길이 3 이상은 `s[l] == s[r]`이고 `dp[l+1][r-1]`이 true이면 회문이다
5. **백트래킹의 구조**: 현재 위치 `start`에서 `end`를 `start`부터 `s.length()-1`까지 하나씩 늘려가며, `dp[start][end]`가 true이면 부분 문자열을 경로에 추가하고 `end+1`부터 재귀한다. 재귀에서 돌아오면 경로의 마지막 요소를 삭제하고 다른 잘라내기 방법을 시도한다
6. **최종적으로 반환하는 것**: `start`가 `s.length()`에 도달할 때마다 현재 경로의 복사본을 결과 리스트에 추가한다. 모든 재귀가 종료되면 결과 리스트를 반환한다

## 전제 지식

### 회문(Palindrome)이란

앞에서 읽어도 뒤에서 읽어도 같은 문자열을 말한다. 예를 들어 `"aba"`, `"aa"`, `"a"`는 회문이다. `"ab"`는 회문이 아니다.

### 2차원 boolean 배열을 이용한 회문 DP 테이블

`dp[l][r]`로 「인덱스 `l`부터 `r`까지의 부분 문자열이 회문인지」를 O(1)으로 판정할 수 있는 테이블이다. 바깥쪽 루프에서 오른쪽 끝 `r`을 고정하고, 안쪽 루프에서 왼쪽 끝 `l`을 `0`부터 `r`까지 이동하며 구축한다.

```java
boolean[][] dp = new boolean[n][n];
for (int r = 0; r < n; r++) {
    for (int l = 0; l <= r; l++) {
        // 양 끝이 같은 문자이고, 안쪽이 회문(또는 길이 2 이하)이면 회문
        if (s.charAt(l) == s.charAt(r) && (r - l < 2 || dp[l + 1][r - 1])) {
            dp[l][r] = true;
        }
    }
}
dp[0][2];  // s[0]부터 s[2]까지가 회문인지 여부 → true or false
```

### 백트래킹이란

선택지를 하나 선택하여 재귀적으로 진행하고, 조건을 만족하지 못하면 직전의 선택을 취소하고 다른 선택지를 시도하는 탐색 기법이다. 경로에 추가(선택) → 재귀 → 경로에서 삭제(취소)의 3단계로 구성된다.

```java
path.add(choice);                    // 선택한다
backtrack(nextState, path, result);  // 재귀로 앞으로 진행한다
path.remove(path.size() - 1);       // 선택을 취소하고 다른 경로를 시도한다
```

### substring 메서드

`String.substring(start, end)`는 인덱스 `start`부터 `end - 1`까지의 부분 문자열을 반환한다. `end`는 포함되지 않는다는 점에 주의한다.

```java
String s = "aab";
s.substring(0, 1);  // "a"
s.substring(0, 2);  // "aa"
s.substring(0, 3);  // "aab"
```

## 계산량

| | 값 |
|---|---|
| Time | O(n × 2^n) — DP 테이블 구축에 O(n^2), 백트래킹에서 최대 2^(n-1)가지 분할을 열거하며 각 분할에서 부분 문자열 복사에 O(n)이 소요된다 |
| Space | O(n^2) — DP 테이블에 n×n의 boolean 배열을 사용한다. 재귀 스택의 깊이는 최대 O(n)이다 |

## 코드

```java
// 입력: 문자열 s
// 출력: s의 모든 회문 분할 패턴을 저장한 List<List<String>>
List<List<String>> partition(String s) {
    int n = s.length();

    // dp[l][r] = s[l]부터 s[r]까지의 부분 문자열이 회문인지를 나타내는 DP 테이블
    boolean[][] dp = new boolean[n][n];
    // 바깥쪽 루프에서 오른쪽 끝 r을 고정하고, 안쪽 루프에서 왼쪽 끝 l을 0부터 r까지 순회하며 구축한다
    for (int r = 0; r < n; r++) {
        for (int l = 0; l <= r; l++) {
            // 양 끝 문자가 같고, 안쪽이 회문(또는 길이 2 이하)이면 회문
            // r - l < 2 조건: 길이 1은 항상 회문, 길이 2는 양 끝이 같으면 회문
            if (s.charAt(l) == s.charAt(r)
                && (r - l < 2
                || dp[l + 1][r - 1])) {
                dp[l][r] = true;
            }
        }
    }

    // 모든 분할 패턴을 저장하는 결과 리스트
    List<List<String>> res = new ArrayList<>();
    // 시작 위치 0, 빈 경로로 백트래킹을 시작한다
    bt(s, 0, new ArrayList<>(), res, dp);
    return res;
}

void bt(String s, int start,
    List<String> path,
    List<List<String>> res,
    boolean[][] dp) {
    // 문자열의 끝에 도달 → 문자열 전체를 회문 부분 문자열로 분할 완료
    if (start == s.length()) {
        // path는 이후에 변경되므로 복사본을 추가한다
        res.add(new ArrayList<>(path));
        return;
    }

    // start부터 end까지의 부분 문자열을 순서대로 시도한다
    for (int end = start; end < s.length();
        end++) {
        // DP 테이블로 회문 판정을 O(1)으로 수행한다
        if (dp[start][end]) {
            // 회문 부분을 경로에 추가하고 재귀한다
            // substring의 두 번째 인수는 배타적이므로 end + 1을 지정한다
            path.add(
                s.substring(start, end + 1));
            // 다음 시작 위치는 end + 1(잘라낸 부분의 바로 다음)
            bt(s, end + 1, path, res, dp);
            // 선택을 취소하고 다른 잘라내기 방법을 시도한다(백트래킹)
            path.remove(path.size() - 1);
        }
    }
}
```
