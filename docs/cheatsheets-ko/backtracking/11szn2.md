# Finding Combinations That Sum to a Target — 합계가 타겟이 되는 숫자 조합을 모두 찾기

## 문제의 본질

양의 정수 배열 `candidates`(모든 요소가 서로 다름)와 양의 정수 `target`이 주어진다. `candidates` 중에서 합계가 `target`이 되는 조합을 모두 찾아 반환한다. 같은 숫자를 **몇 번이든 반복해서 사용할 수 있다**. 조합의 순서만 다른 것은 중복으로 간주한다.

## 핵심 아이디어

후보를 정렬해 두면, 재귀의 각 단계에서 "현재 후보가 남은 타겟을 초과하면, 그 이후의 후보도 모두 초과한다"고 판단할 수 있어 불필요한 탐색을 통째로 중단할 수 있다. 이 가지치기를 통해 모든 조합을 효율적으로 열거할 수 있다.

## 사고 과정

1. **조합의 전체 열거에는 백트래킹이 적합하다**: "조건을 만족하는 모든 패턴을 찾아라"라는 문제는, 후보를 하나씩 선택하여 시도하고, 안 되면 되돌아오는 재귀적 탐색(백트래킹)으로 풀 수 있다
2. **중복을 피하려면 인덱스의 시작 위치를 제어한다**: 같은 숫자를 몇 번이든 사용할 수 있지만, `[2,3]`과 `[3,2]`를 서로 다른 조합으로 세어서는 안 된다. 재귀의 각 단계에서 "자신과 같은 위치 이후의 후보만 선택한다"고 하면, 항상 오름차순 조합만 생성되어 중복을 방지할 수 있다
3. **남은 타겟(remain)으로 진행 상황을 관리한다**: `target`에서 선택한 숫자를 빼 나가며, `remain`이 0이 되면 합계가 `target`과 일치했음을 의미한다. `remain`이 음수가 되면 합계가 초과했음을 의미한다
4. **정렬하면 가지치기가 가능하다**: 후보를 오름차순으로 정렬해 두면, 어떤 후보 `cands[i]`가 `remain`을 초과한 시점에서 `cands[i+1]` 이후는 모두 더 크므로 시도할 필요가 없다. for 루프를 그 자리에서 중단할 수 있다
5. **현재 조합을 리스트로 관리하며, 선택과 취소를 반복한다**: 요소를 끝에 추가하고 재귀한 후, 돌아오면 끝을 삭제한다. 이 "추가→재귀→삭제" 패턴이 백트래킹의 기본 연산이다
6. **remain이 0이 되면 현재 조합의 복사본을 결과에 추가한다**: 참조가 아닌 복사본을 저장하지 않으면, 후속 연산에서 내용이 변경되어 버린다

## 사전 지식

### 백트래킹이란

해의 후보를 단계적으로 구축하고, 조건을 만족하지 않는다고 판단된 시점에서 직전 상태로 되돌아가 다른 후보를 시도하는 탐색 기법이다. 재귀 함수로 구현하며, "선택→재귀→선택 취소"를 반복함으로써 모든 패턴을 열거한다.

### Arrays.sort란

배열을 오름차순으로 정렬하는 메서드이다. 정렬된 배열에서는 "현재 값이 조건을 초과하면, 이후의 값도 모두 초과한다"는 성질을 이용하여 가지치기를 할 수 있다.

```java
int[] cands = {3, 1, 2};
Arrays.sort(cands);       // cands는 {1, 2, 3}이 된다
```

### ArrayList의 연산

가변 길이 리스트이다. 요소의 추가·삭제·복사를 수행한다. 백트래킹에서는 현재 조합을 관리하기 위해 사용한다.

```java
List<Integer> curr = new ArrayList<>();
curr.add(2);                          // 끝에 2를 추가 → [2]
curr.add(3);                          // 끝에 3을 추가 → [2, 3]
curr.remove(curr.size() - 1);         // 끝을 삭제 → [2] (백트래킹)
new ArrayList<>(curr);                // curr의 복사본을 생성한다 (결과 저장용)
```

### List\<List\<Integer\>\>란

"정수 리스트의 리스트"를 나타내는 타입이다. 여러 조합을 저장하기 위해 사용한다. 각 조합이 하나의 `List<Integer>`이며, 이들을 묶은 것이 `List<List<Integer>>`이다.

```java
List<List<Integer>> res = new ArrayList<>();  // 빈 결과 리스트를 생성한다
res.add(new ArrayList<>(curr));               // 조합의 복사본을 결과에 추가한다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n^(target/min)) — n은 후보의 수, min은 최솟값인 후보의 값이다. 최악의 경우, 최솟값을 target/min번 선택하는 분기가 각 후보에 대해 발생한다 |
| Space | O(target/min) — 재귀의 깊이는 최대 target/min이다. 하나의 조합에 포함되는 요소의 수도 최대 target/min개이다 |

## 코드

```java
// 입력: 양의 정수 배열 candidates(모든 요소가 서로 다름)와 양의 정수 target
// 출력: 합계가 target이 되는 모든 조합을 List<List<Integer>>로 반환한다
public List<List<Integer>> combinationSum(int[] cands, int target) {
    // 오름차순 정렬로 "cands[i] > remain이면 이후도 모두 초과한다"는 가지치기 조건을 사용할 수 있다
    Arrays.sort(cands);
    // 결과를 저장하는 리스트
    List<List<Integer>> res = new ArrayList<>();
    // 백트래킹을 시작한다 (나머지=target, 시작 위치=0, 현재 조합=빈 리스트)
    backtrack(cands, target, 0, new ArrayList<>(), res);
    return res;
}

// remain: target에서 지금까지 선택한 숫자를 뺀 나머지이다. 0이 되면 합계가 target과 일치한다
// start: 탐색 시작 위치이다. 자신과 같은 위치 이후만 선택함으로써 중복(순서 차이)을 방지한다
// curr: 현재 구축 중인 조합이다. 선택과 취소를 반복하여 모든 패턴을 탐색한다
void backtrack(int[] cands, int remain, int start,
               List<Integer> curr, List<List<Integer>> res) {
    // remain이 0이면 합계가 target과 일치 → 현재 조합을 결과에 추가한다
    if (remain == 0) {
        // 복사본을 생성하여 저장한다. 참조 그대로 저장하면 후속 연산에서 내용이 변경된다
        res.add(new ArrayList<>(curr));
        return;
    }
    // start부터 순회하며, cands[i] > remain이면 정렬되어 있으므로 이후도 모두 초과한다 → 루프 중단 (가지치기)
    for (int i = start; i < cands.length && cands[i] <= remain; i++) {
        // 현재 후보를 조합의 끝에 추가한다
        curr.add(cands[i]);
        // 세 번째 인수에 i(i+1이 아닌 i)를 전달하여, 같은 숫자를 반복 선택하는 것을 허용한다
        backtrack(cands, remain - cands[i], i, curr, res);
        // 재귀에서 돌아오면 추가한 요소를 취소한다 (백트래킹). 다음 후보를 시도할 준비를 한다
        curr.remove(curr.size() - 1);
    }
}
```
