# Generating All Subsets of a Set — 집합의 모든 부분집합을 생성하기

## 문제의 본질

서로 다른 정수의 배열 `nums`가 주어진다. `nums`의 모든 부분집합(멱집합)을 리스트로 반환한다. 부분집합에 중복이 있어서는 안 되며, 반환 순서는 상관없다.

## 핵심 아이디어

원소 수가 `n`인 집합에는 `2^n`개의 부분집합이 존재한다. `n` 비트의 정수를 `0`부터 `2^n - 1`까지 열거하면, 각 비트가 "해당 원소를 포함하는지 포함하지 않는지"를 나타내므로, 모든 부분집합을 빠짐없이 중복 없이 생성할 수 있다.

## 사고 과정

1. **부분집합의 수는 2^n으로 결정된다**: 각 원소에 대해 "포함한다" 또는 "포함하지 않는다"의 2가지 선택이 있으므로, 원소 수가 `n`인 집합에는 `2^n`개의 부분집합이 존재한다. 모든 부분집합을 열거하려면, 이 `2^n`가지의 선택 패턴을 전부 표현할 수 있는 구조가 필요하다
2. **2가지 선택의 열거는 비트로 표현할 수 있다**: "포함=1, 포함하지 않음=0"으로 대응시키면, `n`개 원소의 선택 패턴을 `n` 비트의 정수로 표현할 수 있다. 예를 들어 `nums = [a, b, c]`일 때, 비트열 `101`은 "a를 포함, b를 포함하지 않음, c를 포함"을 의미하며, 즉 부분집합 `[a, c]`를 나타낸다
3. **0부터 2^n-1까지의 정수가 모든 패턴을 포괄한다**: `n` 비트로 표현할 수 있는 정수는 `0`(모든 비트가 0 = 공집합)부터 `2^n - 1`(모든 비트가 1 = 전체 원소를 포함하는 집합)까지 `2^n`개이다. 이들을 순서대로 열거하면, 모든 부분집합을 빠짐없이 중복 없이 생성할 수 있다
4. **각 정수로부터 부분집합을 구성하는 방법**: 정수 `mask`의 제 `i` 비트가 `1`인지 여부를 `(mask & (1 << i)) != 0`으로 판정할 수 있다. `1`이면 `nums[i]`를 부분집합에 추가한다. `i`를 `0`부터 `n-1`까지 순회하면, `mask`에 대응하는 부분집합이 완성된다
5. **1 << n으로 2^n을 계산한다**: Java에서는 비트 시프트 연산자 `<<`를 사용하여 `1 << n`으로 `2^n`을 계산할 수 있다. 루프의 상한값으로 `mask < (1 << n)`을 조건으로 설정하면, `0`부터 `2^n - 1`까지 빠짐없이 열거할 수 있다
6. **최종적으로 반환하는 것**: 각 `mask`에 대응하는 부분집합을 리스트에 추가해 나가고, 모든 `mask`를 처리한 후에 부분집합의 리스트 `result`를 반환한다

## 전제 지식

### 비트마스크란

정수의 각 비트(0 또는 1)를 "플래그"로 활용하는 기법이다. `n`개의 원소에 대한 "포함/포함하지 않음"의 조합을 하나의 정수로 표현할 수 있다.

```java
int mask = 5;            // 2진수로 101
// 제0비트: 1(포함), 제1비트: 0(포함하지 않음), 제2비트: 1(포함)
```

### 비트 연산자

`&`(AND)와 `<<`(왼쪽 시프트)를 조합하여 특정 비트가 설정되어 있는지를 판정한다.

```java
1 << 0;                  // 1(2진수: 001) — 제0비트만 1인 마스크를 만든다
1 << 1;                  // 2(2진수: 010) — 제1비트만 1인 마스크를 만든다
1 << 2;                  // 4(2진수: 100) — 제2비트만 1인 마스크를 만든다

int mask = 5;            // 2진수: 101
(mask & (1 << 0)) != 0;  // true  — 제0비트는 1이다
(mask & (1 << 1)) != 0;  // false — 제1비트는 0이다
(mask & (1 << 2)) != 0;  // true  — 제2비트는 1이다
```

### 1 << n으로 2^n을 계산하기

비트 시프트 `1 << n`은 `1`을 왼쪽으로 `n` 비트 이동시키는 연산이며, 결과는 `2^n`이 된다. 부분집합의 총 개수를 구하는 데 사용한다.

```java
1 << 3;                  // 8(= 2^3) — 원소가 3개이면 부분집합은 8개이다
```

## 계산량

| | 값 |
|---|---|
| Time | O(n × 2^n) — 2^n개의 마스크 각각에 대해 n 비트를 순회한다 |
| Space | O(n × 2^n) — 2^n개의 부분집합을 저장하며, 각 부분집합의 평균 원소 수는 n/2이다 |

## 코드

```java
// 입력: 서로 다른 정수의 배열 nums
// 출력: 모든 부분집합을 담은 List<List<Integer>>를 반환한다
List<List<Integer>> subsets(int[] nums) {
    // nums의 원소 수. 비트마스크의 비트 수와 배열 순회 범위 양쪽에서 사용한다
    int n = nums.length;
    // 모든 부분집합을 저장하는 리스트. 각 mask로부터 생성한 부분집합을 여기에 추가해 나간다
    List<List<Integer>> result = new ArrayList<>();

    // mask를 0부터 2^n-1까지 열거하며, 각 값이 하나의 부분집합에 대응한다
    // 1 << n으로 2^n을 계산하고, 루프 조건으로 설정하여 2^n개의 패턴을 전부 열거한다
    for (int mask = 0; mask < (1 << n); mask++) {
        // 현재 mask에 대응하는 원소를 추가해 나갈 빈 부분집합을 생성한다
        List<Integer> subset = new ArrayList<>();

        // i는 nums의 인덱스이며, 동시에 mask의 몇 번째 비트를 확인할지를 결정한다
        for (int i = 0; i < n; i++) {
            // 1 << i로 제 i 비트만 1인 마스크를 만들고, mask와 AND 연산하여 제 i 비트의 값을 추출한다
            // 비트가 1이면 "이 원소를 포함한다", 0이면 "포함하지 않는다"이므로 다음 i로 진행한다
            if ((mask & (1 << i)) != 0) {
                subset.add(nums[i]);
            }
        }

        // 안쪽 루프가 종료된 후, 완성된 부분집합을 결과 리스트에 추가한다
        result.add(subset);
    }
    // 모든 mask를 처리한 후, 2^n개의 부분집합이 저장된 result를 반환한다
    return result;
}
```
