# Adding Two Numbers Without the Plus Operator — 不使用加法运算符求两个整数的和

## 问题的本质

给定两个整数 `a` 和 `b`。要求**不使用** `+` 运算符和 `-` 运算符，仅通过位运算计算并返回两个整数的和。

## 核心思路

二进制加法可以分解为"不考虑进位的各位之和（XOR）"和"进位（AND 后左移）"两个部分。反复执行这一分解直到进位变为零，就能得到最终的和。

## 思考过程

1. **从位的层面思考加法的本质**: 二进制各位的加法，如果忽略进位，则"仅当其中一位为1时结果为1"。这正是XOR运算（`a ^ b`）本身
2. **单独计算进位**: 进位在"两位都为1时"产生。这可以通过AND运算（`a & b`）求得。由于进位影响的是下一位，因此需要将结果左移1位（`(a & b) << 1`）
3. **需要将进位加到和上**: 将XOR的结果与进位相加即可得到最终的和，但不能使用 `+`。然而这归结为"将两个数相加"这同一个问题，因此可以递归地应用相同的处理
4. **确定递归的终止条件**: 当进位 `b` 变为零时，没有剩余需要相加的值，此时的 `a` 就是最终的和。将此作为基准情况
5. **整数位宽有限，因此必定终止**: 由于左移操作，进位的位每次都向高位移动，在32位整数的范围内，最多经过32次递归进位必定变为零

## 前置知识

### 什么是XOR运算（异或运算）

XOR是一种位运算，当两个位不同时返回1，相同时返回0。其结果与忽略进位的加法相同。

```java
int result = 5 ^ 3;   // 0101 ^ 0011 = 0110 → 6
int result2 = 7 ^ 7;  // 0111 ^ 0111 = 0000 → 0（相同值的XOR结果为0）
```

### 什么是AND运算

AND是一种位运算，仅当两个位都为1时才返回1。AND运算用于确定产生进位的位。

```java
int result = 5 & 3;   // 0101 & 0011 = 0001 → 1
int result2 = 6 & 3;  // 0110 & 0011 = 0010 → 2
```

### 什么是左移运算

左移运算将位序列向左移动指定的位数，右侧空出的位用0填充。左移1位相当于将值乘以2。由于进位影响的是下一位，因此通过左移1位将其移动到正确的位位置。

```java
int result = 1 << 1;  // 0001 → 0010 → 2
int result2 = 3 << 1; // 0011 → 0110 → 6
```

### 二进制加法的原理

与十进制竖式计算相同，逐位相加并将进位传递到高位。
例: `5 + 3`（`0101 + 0011`）的情况：
- XOR（不含进位的和）: `0101 ^ 0011 = 0110`（6）
- AND + 左移（进位）: `(0101 & 0011) << 1 = 0001 << 1 = 0010`（2）
- 再用同样的方法将6和2相加 → `0110 ^ 0010 = 0100`（4），`(0110 & 0010) << 1 = 0100`（4）
- 再将4和4相加 → `0100 ^ 0100 = 0000`（0），`(0100 & 0100) << 1 = 1000`（8）
- 将0和8相加 → `0000 ^ 1000 = 1000`（8），进位为0 → 结束。结果为 **8**

## 复杂度

| | 值 |
|---|---|
| Time | O(1) — 对于32位整数，进位的移位最多执行32次即结束，因此在常数次递归内完成 |
| Space | O(1) — 递归深度最多也为32次，属于常数级别，且不使用额外的数据结构 |

## 代码

```java
// 输入: 两个整数 a 和 b
// 输出: 以 int 类型返回 a 和 b 的和
public int getSum(int a, int b) {
    // 基准情况: 当进位(b)为零时，没有剩余需要相加的值，此时a即为最终的和
    if (b == 0) return a;

    // a ^ b: 求不考虑进位的各位之和（XOR在"两个位不同时"返回1）
    // (a & b) << 1: 求进位（通过AND确定"两位都为1的位"，再通过左移将其移动到下一位位置）
    // 每次递归进位的位都向高位移动，对于32位整数最多经过32次必定变为零
    return getSum(a ^ b, (a & b) << 1);
}
```
