# Reversing the Digits of an Integer — 反转32位有符号整数的各位数字

## 问题的本质

给定一个32位有符号整数 `x`。返回将 `x` 的各位数字逆序排列后的整数。如果反转后的值超出32位有符号整数的范围（-2³¹ ～ 2³¹-1），则返回 `0`。

## 核心思路

整数末尾的数字可以通过 `x % 10` 取出，通过 `x / 10` 去除末尾数字。反复执行"取出并累积"的操作，数字的各位自然会变为逆序。在每次累积时提前检查是否溢出，就能安全地构建反转结果。

## 思考过程

1. **逐位取出数字的方法**: 整数末尾的数字可以通过 `x % 10`（除以10的余数）获取。获取后通过 `x / 10` 去除末尾数字，就能访问下一位数字。将此操作重复执行直到 `x` 变为0，就能从末尾开始依次取出所有数字
2. **将取出的数字逆序组装的方法**: 对结果变量 `result` 反复执行 `result = result * 10 + digit`。`result * 10` 将已有数字左移一位，`+ digit` 将新数字添加到个位。由于从末尾取出的数字从高位开始依次放置，数字的排列自然会反转
3. **溢出的处理**: `result * 10 + digit` 的计算结果可能超过 `Integer.MAX_VALUE`（2147483647）或低于 `Integer.MIN_VALUE`（-2147483648）。在执行乘法**之后**就来不及了，所以需要在乘法**之前**进行检查
4. **溢出的预检查方法**: `result * 10` 是否会溢出，可以通过将 `result` 与 `Integer.MAX_VALUE / 10`（= 214748364）进行比较来判定。如果 `result > 214748364`，则必定溢出。如果 `result == 214748364`，则当 `digit > 7`（MAX_VALUE的个位数）时会溢出。负数的情况同样与 `Integer.MIN_VALUE / 10` 进行比较
5. **符号的处理**: `x % 10` 和 `x / 10` 在Java中对负数也能正确运算（`-123 % 10 == -3`、`-123 / 10 == -12`）。因此无需分离符号，可以直接处理
6. **最终返回的值**: 循环结束后的 `result` 就是反转后的整数。如果检测到溢出，则在循环内立即返回 `0`

## 前置知识

### % 运算符（取余运算符）

将一个整数除以另一个整数并返回余数的运算符。`x % 10` 用于取出 `x` 的个位数字。在Java中，对负数也会保留符号。

```java
123 % 10;    // → 3（获取个位数字）
-123 % 10;   // → -3（负数也会保留符号）
123 / 10;    // → 12（去除个位数字）
-123 / 10;   // → -12（负数也能正确截断）
```

### 32位有符号整数的范围

Java的 `int` 类型能表示的值的范围。超出此范围会发生溢出，产生错误的值。

```java
Integer.MAX_VALUE;   // → 2147483647（2³¹ - 1）
Integer.MIN_VALUE;   // → -2147483648（-2³¹）
Integer.MAX_VALUE / 10;  // → 214748364（溢出判定的阈值）
Integer.MAX_VALUE % 10;  // → 7（MAX_VALUE的个位数字）
Integer.MIN_VALUE / 10;  // → -214748364
Integer.MIN_VALUE % 10;  // → -8（MIN_VALUE的个位数字）
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — n为 `x` 的位数。每一位处理一次 |
| Space | O(1) — 仅使用变量 `result` 和 `digit` |

## 代码

```java
// 输入: 32位有符号整数 x
// 输出: 返回将 x 的各位数字反转后的整数。如果反转后的值超出32位范围，则返回 0
public int reverse(int x) {
    // 存储反转结果的变量。逐位累积构建
    int result = 0;

    // 从末尾开始逐位取出 x 的数字并处理。当 x 变为 0 时，所有位数处理完毕
    while (x != 0) {
        // 取出 x 的个位数字。负数的 % 运算也会保留符号，因此无需特殊处理
        int digit = x % 10;

        // 预检查正数溢出（乘法之后就来不及了，所以在乘法之前检查）
        // 如果 result > 214748364，则 result * 10 必定超过 MAX_VALUE(2147483647)
        // 如果 result == 214748364 且 digit > 7，则 result * 10 + digit 超过 MAX_VALUE（末位为7）
        if (result > Integer.MAX_VALUE / 10
                || (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return 0;
        }

        // 预检查负数溢出
        // 如果 result < -214748364，则 result * 10 必定低于 MIN_VALUE(-2147483648)
        // 如果 result == -214748364 且 digit < -8，则 result * 10 + digit 低于 MIN_VALUE（末位为-8）
        if (result < Integer.MIN_VALUE / 10
                || (result == Integer.MIN_VALUE / 10 && digit < -8)) {
            return 0;
        }

        // result * 10 将已有数字左移一位，+ digit 将取出的数字添加到个位
        // 这样，原数末尾的数字会依次放置到结果的高位
        result = result * 10 + digit;

        // 去除 x 的个位数字，使下一位数字暴露在末尾
        x = x / 10;
    }

    // 返回所有位数反转完成的结果。溢出时已在循环内返回 0
    return result;
}
```
