# Finding the Number That Appears Only Once — 找出数组中只出现一次的元素

## 问题的本质

给定一个整数数组 `nums`。数组中所有元素都恰好出现2次，但只有1个元素只出现1次。返回那个**只出现1次的元素**。

## 核心思路

XOR运算具有"将同一个值XOR两次结果为0"的性质。对数组的所有元素执行XOR运算后，出现2次的元素全部相互抵消变为0，最终只剩下出现1次的元素。

## 思考过程

1. **如果能消除重复的配对，答案就会留下来**: 如果能将数组中出现2次的元素全部去除，就能得到只出现1次的元素。我们需要找到一种能高效执行"配对消除"的运算
2. **利用XOR的自逆性质**: XOR运算具有 `a ^ a = 0` 的性质。将同一个值XOR两次，结果为0。也就是说，出现2次的元素会被自动消除
3. **利用XOR的单位元和结合律**: `a ^ 0 = a`（与0进行XOR不会改变原值），并且XOR满足结合律和交换律。因此，无论元素出现的顺序如何，对所有元素执行XOR后，配对都会消失，只留下唯一的元素
4. **用一个变量计算累积XOR**: 将变量 `result` 初始化为0，在遍历数组的过程中对每个元素执行XOR运算。遍历结束后，`result` 中保留的值就是答案
5. **不需要额外的数据结构**: 无需使用HashSet或HashMap，只用一个整数变量就能求解，因此空间复杂度为O(1)

## 前置知识

### 什么是XOR（异或运算）

XOR是一种位运算，当两个比特不同时返回1，相同时返回0。在Java中用 `^` 运算符表示。对整数使用时，会对每个比特位分别执行XOR运算。

```java
int a = 5;          // 二进制: 101
int b = 3;          // 二进制: 011
int c = a ^ b;      // 二进制: 110 → 6
```

### XOR的重要性质

XOR运算具有以下3个性质，解决这道题需要用到全部这些性质。

```java
// 1. 自逆性: 将同一个值XOR两次结果为0
a ^ a;    // → 0

// 2. 单位元: 与0进行XOR不会改变原值
a ^ 0;    // → a

// 3. 交换律与结合律: 即使交换顺序，结果也相同
a ^ b ^ a;    // → (a ^ a) ^ b → 0 ^ b → b
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历数组一次 |
| Space | O(1) — 不使用额外的数据结构，只需要一个整数变量 |

## 代码

```java
// 输入: 整数数组 nums（所有元素出现2次，只有1个元素出现1次）
// 输出: 以 int 形式返回只出现1次的元素
public int singleNumber(int[] nums) {
    // 累积XOR的初始值。0是XOR的单位元，与任何值进行XOR都不会改变对方的值
    int result = 0;

    // 使用for-each循环从头到尾逐个遍历数组的每个元素
    for (int num : nums) {
        // 计算当前 result 与 num 的XOR，并将结果赋值给 result
        // 出现2次的元素通过 a ^ a = 0 相互抵消，只有出现1次的元素会被累积保留
        result ^= num;
    }

    // 循环结束后，所有配对都已相互抵消，只剩下出现1次的元素的值
    return result;
}
```
