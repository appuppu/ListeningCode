# Finding the Missing Number in a Sequence — 从0〜n的连续数列中找出缺失的1个数

## 问题的本质

给定一个包含n个不同整数的数组 `nums`，其中整数的范围是0到n。找出并返回该范围内存在但数组中不存在的**1个缺失的数**。

## 核心思路

XOR对同一个值应用两次会相互抵消变为零。将数组的索引（0〜n-1）、值n以及数组的所有元素全部进行XOR运算，成对的数会被抵消，只剩下没有配对的"缺失的数"。

## 思考过程

1. **除缺失的数以外，所有数都能配对**: 数组的索引范围是0〜n-1，数组的值也是从0〜n的范围中去掉缺失的数后的结果。也就是说，如果在索引一侧加上初始值n，那么0〜n的所有整数都会在索引一侧齐全。只有缺失的数不存在于数组的值一侧，因此无法配对
2. **XOR是抵消配对的最佳操作**: XOR具有 `a ^ a = 0`（相同的值相互抵消）和 `a ^ 0 = a`（与零进行XOR会保留原值）的性质。将所有索引和值进行XOR运算，成对的数全部变为0，只剩下没有配对的缺失的数
3. **初始值设为n的原因**: for循环的索引只覆盖0〜n-1的范围。但缺失的数也可能是n，因此将XOR的初始值设为n，从而覆盖0〜n的完整范围
4. **一次循环即可完成**: 在循环内同时执行 `xor ^= i`（索引的XOR）和 `xor ^= nums[i]`（值的XOR），只需遍历数组一次即可得到结果。无需额外的数据结构

## 前置知识

### XOR（异或运算）是什么

当两个比特不同时返回1、相同时返回0的位运算。在Java中使用 `^` 运算符。对整数逐位进行运算。

```java
int a = 5;          // 二进制: 101
int b = 3;          // 二进制: 011
int result = a ^ b; // 二进制: 110 → 6
```

### XOR的重要性质

算法的核心依赖于以下3个性质。

```java
// 性质1: 相同值的XOR结果为0（相互抵消）
5 ^ 5;    // → 0

// 性质2: 与0进行XOR保留原值
5 ^ 0;    // → 5

// 性质3: 改变运算顺序结果不变（交换律和结合律）
(2 ^ 5) ^ 2;  // → 5（两个2相互抵消，剩下5）
```

### ^= 运算符是什么

将XOR运算的结果赋值给左侧变量的复合赋值运算符。`xor ^= i` 等同于 `xor = xor ^ i`。

```java
int xor = 0;
xor ^= 3;   // xor = 0 ^ 3 → 3
xor ^= 3;   // xor = 3 ^ 3 → 0（相同值相互抵消）
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历数组一次 |
| Space | O(1) — 不使用额外的数据结构，只需1个变量 |

## 代码

```java
// 输入: 包含0〜n范围内n个不同整数的数组 nums
// 输出: 返回范围内不存在于数组中的1个整数
public int missingNumber(int[] nums) {
    // 将初始值设为n，与循环索引0〜n-1配合，覆盖0〜n的完整范围
    // 由于for循环的索引只覆盖0〜n-1，因此在此处将n作为初始值
    int xor = nums.length;

    for (int i = 0; i < nums.length; i++) {
        // 将索引i累积到XOR值中
        // 循环结束时，索引0〜n-1全部完成XOR运算（加上初始值n，0〜n的所有整数均完成XOR运算）
        xor ^= i;
        // 将数组的值累积到XOR值中
        // 数组中存在的数同时出现在索引侧和值侧，根据 a ^ a = 0 的性质相互抵消
        xor ^= nums[i];
    }

    // 所有成对的数相互抵消变为0，只有不存在于数组中的缺失的数因没有配对而保留下来
    return xor;
}
```
