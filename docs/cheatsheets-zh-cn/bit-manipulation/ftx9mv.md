# Counting the Number of Set Bits — 计算整数二进制表示中1的位数

## 问题的本质

给定一个非负整数 `n`。返回 `n` 的二进制表示中值为1的位的个数（汉明权重）。

## 核心思路

`n & (n - 1)` 这个运算是将 `n` 的最低位的1消除一个的操作。将这个操作重复执行直到 `n` 变为0，重复的次数就是1的位数。

## 思考过程

1. **希望只高效地计数值为1的位**: 不是遍历全部32位，而是只处理存在1的位的位置，这样就能在与1的位数 `k` 成正比的时间内完成
2. **思考如何消除最低位的1**: 计算 `n - 1` 时，`n` 的最低位的1变为0，比它更低位的位全部反转为1。例如 `n = 1100` 时 `n - 1 = 1011`
3. **n AND (n - 1) 只消除最低位的1**: 对 `n` 和 `n - 1` 取AND，最低位的1及其以下的位全部变为0，比它更高位的位保持不变。`1100 & 1011 = 1000`，最低位的1被消除了一个
4. **重复消除操作并计数**: 反复执行 `n &= (n - 1)`，计数直到 `n` 变为0的次数，该次数就是原始 `n` 中包含的1的位数
5. **循环的终止条件**: 当所有值为1的位都被消除后，`n` 变为0。将 `n != 0` 作为循环条件，循环只执行1的位数次后自然终止

## 前置知识

### 位AND运算（&）是什么

比较两个整数的各个位，只有当两个位都为1时结果才为1的运算。其他组合的结果都为0。

```java
int a = 0b1100;       // 二进制 1100
int b = 0b1010;       // 二进制 1010
int result = a & b;   // 结果为 0b1000（只有两者都为1的位置结果才为1）
```

### n & (n - 1) 的工作原理

从 `n` 减去1时，最低位的1变为0，比它更低位的位全部反转为1。与 `n` 取AND后，最低位的1及其以下的位全部变为0。

```java
int n = 0b1100;       // n     = 1100（有2个值为1的位）
n &= (n - 1);        // n - 1 = 1011, n = 1100 & 1011 = 1000（值为1的位减少到1个）
n &= (n - 1);        // n - 1 = 0111, n = 1000 & 0111 = 0000（值为1的位减少到0个）
```

### 汉明权重（Hamming Weight）是什么

指整数的二进制表示中包含的1的位的个数。例如 `11` 的二进制是 `1011`，所以汉明权重为3。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(k) — k为 `n` 中包含的1的位数。循环只执行k次 |
| Space | O(1) — 只使用一个计数器变量 |

## 代码

```java
// 输入: 非负整数 n
// 输出: 以 int 返回 n 的二进制表示中包含的1的位数
public int hammingWeight(int n) {
    // 记录消除1的位的次数的计数器。消除的总次数就是最终的答案
    int count = 0;

    // 如果n为0，则不存在值为1的位，终止循环
    while (n != 0) {
        // 消除最低位的一个1（Brian Kernighan's Trick）
        // n - 1 使最低位的1及其以下的位反转，与n取AND后该位置及其以下全部变为0
        n &= (n - 1);
        // 消除了一个值为1的位，记录消除的次数
        count++;
    }
    // count中存储的是消除1的位的总次数，即原始n中包含的1的位数
    return count;
}
```
