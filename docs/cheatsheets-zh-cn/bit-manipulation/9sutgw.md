# Reversing the Bits of an Integer — 反转32位无符号整数的比特位

## 问题的本质

给定一个32位无符号整数，将其比特序列左右反转（逆序）后返回对应的整数。例如，输入 `00000000000000000000000000001011` 将变为 `11010000000000000000000000000000`。

## 核心思路

将结果逐位左移的同时，逐个取出输入的最低位比特并追加到结果中。重复此操作32次后，输入的比特序列将以逆序累积到结果中。

## 思考过程

1. **比特反转是"从末尾取出并堆积到开头"的操作**：取出输入的最低位比特（右端），将其追加到结果的最低位（右端），然后将结果左移。这样，最先取出的比特最终会移动到最高位。这就是比特序列的逆序构建过程
2. **如何取出最低位比特**：计算 `n & 1` 即可获取 `n` 的最低位比特。AND运算会将最低位以外的所有比特掩码为0
3. **如何将取出的比特追加到结果中**：使用 `result |= (n & 1)` 的OR运算，可以将取出的比特设置到result的最低位。由于result的最低位在之前的左移操作中已变为0，OR运算可以正确地设置该比特
4. **如何移动到下一个比特**：对输入 `n` 执行 `n >>>= 1` 右移1位，下一个比特就会移动到最低位。`>>>` 是无符号右移，始终在最高位填充0
5. **如何为结果腾出空间**：在追加新比特之前，执行 `result <<= 1` 将结果左移1位，最低位变为0，从而为新比特腾出接收空间
6. **重复32次即可完成**：由于是32位整数，将上述"左移→追加比特→右移"操作重复32次，输入的所有比特就会以逆序存储到结果中

## 前置知识

### 比特AND运算（&）

比较两个整数的每一位，只有两位都为1时结果才为1的运算。用作提取特定比特的"掩码"。

```java
int n = 0b1011;       // 二进制1011（十进制11）
int bit = n & 1;      // 仅获取最低位比特 → 1
int bit2 = 0b1010 & 1; // 最低位为0的情况 → 0
```

### 比特OR运算（|=）

比较两个整数的每一位，只要其中一位为1则该位结果为1的运算。用于将特定比特设置为1。

```java
int result = 0b0000;
result |= 1;          // 将最低位设置为1 → 0b0001
result |= 0;          // 与0进行OR运算不产生变化 → 0b0001
```

### 左移运算（<<=）

将比特序列向左移动指定位数的运算。右端用0填充。左移1位相当于将值乘以2。

```java
int result = 0b0011;   // 二进制11（十进制3）
result <<= 1;          // 向左移动1位 → 0b0110（十进制6）
```

### 无符号右移运算（>>>=）

将比特序列向右移动指定位数的运算。左端始终用0填充。与 `>>` 不同，无论符号位如何都填充0，因此适用于无符号整数的操作。

```java
int n = 0b1011;        // 二进制1011
n >>>= 1;              // 向右移动1位 → 0b0101（最低位的1被移除，下一个比特移动到右端）
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(1) — 循环固定执行32次，不依赖于输入的值 |
| Space | O(1) — 仅使用额外变量 `result`，不依赖于输入规模 |

## 代码

```java
// 输入: 32位无符号整数 n
// 输出: 以int形式返回比特序列逆序后的整数
public int reverseBits(int n) {
    // 用于存储反转后比特序列的变量。初始值0表示所有比特均为0的状态
    int result = 0;

    // 为处理32位整数的所有比特，循环执行32次
    for (int i = 0; i < 32; i++) {
        // 将result左移1位，使最低位变为0，为接收新比特腾出空间
        // 注意: 左移必须在追加比特之前执行。若在之后执行，最后一次追加比特后会产生多余的移位，导致结果变为2倍
        result <<= 1;
        // 通过 n & 1 取出n的最低位比特，使用OR运算将其设置到result的最低位
        // 由于之前的左移操作使最低位已为0，OR运算可以正确地设置该比特
        result |= (n & 1);
        // 对n执行无符号右移，将下一个比特移动到最低位
        // 使用 >>> 是因为需要无论符号位如何都填充0
        n >>>= 1;
    }
    // 32次循环完成后，输入的第0位存储在result的第31位，第1位存储在第30位，所有比特均以逆序存储
    return result;
}
```
