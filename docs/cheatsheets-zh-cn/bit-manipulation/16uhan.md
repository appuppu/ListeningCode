# Counting Bits for Every Number Up to N — 以数组形式返回0到N每个整数的二进制表示中1的位数

## 问题的本质

给定一个非负整数 `n`。返回一个长度为 `n + 1` 的数组。数组中索引 `i` 处的元素存储将 `i` 转换为二进制时 **1的位数**。例：当 n=5 时，0→0, 1→1, 2→1, 3→2, 4→1, 5→2，因此返回 `[0,1,1,2,1,2]`。

## 核心思路

任意整数 `i` 的1的位数等于将 `i` 右移1位后的值 `i >> 1` 的1的位数加上 `i` 的最低位（`i & 1`）。利用这一递推关系，可以复用较小值的结果，以 O(1) 的时间求出每个值的结果。

## 思考过程

1. **关注二进制的结构**：将整数 `i` 的二进制表示右移1位后，最低位被丢弃，剩余的位序列与 `i / 2`（向下取整）相同。也就是说，`i` 的位序列具有「`i >> 1` 的位序列」+「最低1位」的结构
2. **可以分解1的位数**：根据上述结构，`i` 中包含的1的个数可以分解为「`i >> 1` 中包含的1的个数」+「最低位是否为1（0或1）」。将其写成公式为 `countBits(i) = countBits(i >> 1) + (i & 1)`
3. **从小值开始依次计算即可复用**：`i >> 1` 的值始终小于 `i`，因此从 `i = 0` 开始依次计算，`result[i >> 1]` 必定已经计算完毕。利用这一性质，可以用循环从前往后依次填充，而无需递归
4. **结果数组本身就是DP表**：将返回的数组 `result` 直接用作DP表。以 `result[0] = 0` 为基础情况，从 `i = 1` 到 `n` 依次用 `result[i] = result[i >> 1] + (i & 1)` 填充。不需要额外的数据结构

## 前置知识

### 什么是右移运算（`>>`）

右移运算将整数的二进制表示向右移动指定的位数。右移1位后，最低位被丢弃，值变为除以2的商（向下取整）。

```java
int a = 6;      // 二进制: 110
int b = a >> 1;  // 二进制: 011 → 值为3（6 ÷ 2 = 3）

int c = 7;      // 二进制: 111
int d = c >> 1;  // 二进制: 011 → 值为3（7 ÷ 2 = 3，舍去小数部分）
```

### 什么是位与运算（`&`）

位与运算比较两个整数的每一位，仅当两位都为1时结果位才为1。`i & 1` 是提取 `i` 的最低位的操作，当 `i` 为奇数时返回1，为偶数时返回0。

```java
int a = 5;       // 二进制: 101
int b = a & 1;   // 二进制: 001 → 值为1（奇数，因此最低位为1）

int c = 4;       // 二进制: 100
int d = c & 1;   // 二进制: 000 → 值为0（偶数，因此最低位为0）
```

### 什么是动态规划（DP）

动态规划是一种将大问题分解为小的子问题，并将子问题的结果记录在数组中以供复用的方法。在本问题中，利用 `result[i >> 1]`（已计算完毕的较小值的结果）以 O(1) 的时间求出 `result[i]`。

```java
int[] result = new int[n + 1];  // 创建兼作DP表的结果数组
result[0] = 0;                  // 基础情况: 0的1的位数为0
result[i] = result[i >> 1] + (i & 1);  // 状态转移方程: 复用已知结果
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 对1到n的每个值只需分别执行一次位移运算和一次与运算 |
| Space | O(n) — 使用一个长度为n+1的数组存储结果（由于该数组本身就是输出，也可以认为额外空间为O(1)） |

## 代码

```java
// 输入: 非负整数 n
// 输出: 长度为 n+1 的 int[]。每个 result[i] 存储 i 的二进制表示中包含的1的位数
public int[] countBits(int n) {
    // 创建兼作DP表的结果数组。new int[n+1] 会将所有元素初始化为0，
    // 因此 result[0] = 0（0的1的位数为0）自动满足
    int[] result = new int[n + 1];

    // i=0 已经正确为0，因此从 i=1 开始遍历
    for (int i = 1; i <= n; i++) {
        // result[i >> 1]: 将 i 右移1位后的值的1的位数（i >> 1 始终小于 i，因此已计算完毕）
        // i & 1: i 的最低位（奇数为1，偶数为0）
        // 将这两者相加即可得到 i 的二进制表示中1的总数
        result[i] = result[i >> 1] + (i & 1);
    }
    // 数组中每个元素 result[i] 已存储索引 i 的1的位数，直接返回
    return result;
}
```
