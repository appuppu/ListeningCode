# Finding the Maximum in Each Sliding Window — 求滑动窗口内的最大值

## 问题的本质

给定一个整数数组 `nums` 和一个窗口大小 `k`。将大小为 `k` 的窗口从数组的左端向右端逐个滑动，求每个位置窗口内的**最大值**。将所有最大值以数组形式返回。

## 核心思路

在 Deque（双端队列）中按照"值单调递减"的方式保持索引，这样 Deque 的头部始终指向窗口内的最大值。当新元素到来时，从尾部移除所有不大于该元素的元素；当头部元素在窗口外时，将其移除。通过这种方式，每一步以 O(1) 的均摊代价获取最大值。

## 思考过程

1. **需要求每个窗口的最大值**：每次窗口滑动一步时，新增和移除的元素各为一个。如果每次都遍历整个窗口以 O(k) 求最大值，则总时间复杂度为 O(nk)，因此需要一种能高效管理最大值的数据结构
2. **只需保留最大值的候选元素**：如果窗口内存在元素 A 和 B，A 在 B 的左侧且 A 的值不大于 B，那么 A 在之后的任何窗口中都不可能成为最大值。因为 B 在 A 的右侧，所以 B 不会比 A 先离开窗口。因此可以将 A 从候选中排除
3. **使用单调递减的 Deque 管理候选元素**：按照值从大到小的顺序保持候选元素，头部始终为最大值。添加新元素时，从尾部移除所有不大于该元素的元素，即可维持单调递减的性质。Deque（双端队列）非常适合执行这种操作
4. **在 Deque 中保存索引**：为了判断元素是否已移出窗口，需要位置信息，因此在 Deque 中保存的是索引而非值。值可以通过 `nums[index]` 获取
5. **检查头部是否在窗口外**：在每一步中，如果 Deque 头部的索引小于当前窗口的左端 `i - k + 1`，则该元素已移出窗口，需要从头部移除
6. **记录结果的时机**：当索引 `i` 大于等于 `k - 1` 时，窗口已经完整形成，此时将 Deque 头部指向的值记录到结果数组中

## 前置知识

### ArrayDeque（双端队列）

一种可以在头部和尾部以 O(1) 时间复杂度进行添加、获取和删除操作的数据结构。它同时具备栈和队列的功能。

```java
ArrayDeque<Integer> deque = new ArrayDeque<>();  // 创建一个空的 Deque
deque.offerLast(5);       // 在尾部添加 5
deque.offerLast(3);       // 在尾部添加 3 → Deque 内容: [5, 3]
deque.peekFirst();        // 获取头部元素（不删除） → 5
deque.peekLast();         // 获取尾部元素（不删除） → 3
deque.pollFirst();        // 获取并删除头部元素 → 5
deque.pollLast();         // 获取并删除尾部元素 → 3
deque.isEmpty();          // 返回 Deque 是否为空的布尔值 → true
```

### 单调递减 Deque（Monotonic Deque）

一种保持 Deque 内的元素从头部到尾部始终递减（不允许相等）的 Deque。添加新元素时，从尾部移除所有不大于该元素的元素，以维持单调递减。
例如：Deque=[7, 5, 3] 中添加 6 → 移除 5 和 3 → Deque=[7, 6]。头部始终指向最大值。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 每个元素最多被加入 Deque 一次，最多被移除一次，因此总时间复杂度为 O(n) |
| Space | O(k) — Deque 中最多保持不超过窗口大小 k 个元素 |

## 代码

```java
// 输入：整数数组 nums 和整数 k（窗口大小）
// 输出：返回包含每个窗口位置最大值的 int[]，元素个数为 n - k + 1
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    // 存储每个窗口最大值的结果数组。共有 n - k + 1 个窗口
    int[] result = new int[n - k + 1];
    // 以单调递减方式保持最大值候选索引的 Deque
    // Deque 中保持"可能成为窗口内最大值的索引"，对应的值按单调递减排列
    ArrayDeque<Integer> deque = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // 如果头部索引小于窗口左端 i - k + 1，则该元素已移出窗口，将其移除
        // 窗口每次滑动一步，因此每步最多只有一个元素移出窗口
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }

        // 从尾部移除所有不大于当前元素 nums[i] 的候选元素，以维持单调递减
        // 这些元素在 nums[i] 存在的情况下不可能成为最大值，因此可以从候选中排除
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }

        // 将当前索引添加到 Deque 的尾部
        // 上面的 while 已经移除了所有不大于当前元素的元素，因此添加后 Deque 仍保持单调递减
        deque.offerLast(i);

        // 当 i >= k - 1 时，窗口中已有 k 个元素
        // Deque 的头部指向当前窗口内最大值的索引
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    // 返回记录了所有窗口最大值的 result
    return result;
}
```
