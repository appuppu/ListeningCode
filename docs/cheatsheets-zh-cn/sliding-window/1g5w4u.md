# Longest Substring After Replacing K Characters — 求在K次字符替换后能得到的最长相同字符子串

## 问题的本质

给定一个大写英文字母组成的字符串 `s` 和一个整数 `k`。在字符串中最多可以将 `k` 个字符替换为任意字符，返回**所有字符都相同**的子串的最大长度。

## 核心思路

只要掌握窗口内"出现次数最多的字符的出现次数"，就可以计算出"需要替换的字符数 = 窗口大小 − 最高频字符的出现次数"。只要该替换数不超过 `k`，就持续扩大窗口，从而求出最长的子串。

## 思考过程

1. **暴力枚举所有子串效率低下**: 枚举所有子串需要O(n²)的时间。由于处理的是连续区间，适合使用Sliding Window模式
2. **需要求出窗口内需要替换的字符数**: 要将窗口内所有字符变为相同字符，只需替换出现次数最多的字符以外的字符即可。因此，需要替换的字符数为 `窗口大小 − 最高频字符的出现次数`
3. **追踪各字符出现次数的方法**: 大写英文字母只有26种，因此可以用大小为26的数组 `count` 来管理各字符的出现次数。随着窗口的扩大和缩小，对数组进行递增和递减操作
4. **高效管理最高频字符的出现次数**: 每当右指针前进时，将新增字符的出现次数与当前的 `maxFreq` 比较，取较大值作为 `maxFreq`。即使左指针前进排除了某个字符，也不减小 `maxFreq`。因为在求最大长度的问题中，将 `maxFreq` 更新为比过去最大值更小的值，不会得到更长的结果
5. **窗口缩小的条件**: 当 `窗口大小 − maxFreq > k` 时，替换次数超过了 `k`，因此将左指针前进1步来缩小窗口。重复此操作直到该条件不再满足
6. **更新最大长度**: 每当窗口有效（替换数 ≤ k）时，将 `right − left + 1` 与当前的 `maxLen` 比较，取较大值记录为 `maxLen`

## 前置知识

### Sliding Window（滑动窗口）

滑动窗口是一种使用两个指针（left, right）来管理数组或字符串上连续区间的方法。通过前移right来扩大窗口，当不满足条件时前移left来缩小窗口。由于每个元素最多只被处理2次（添加和移除各1次），因此时间复杂度为O(n)。

### 使用数组管理字符出现次数的方法

大写英文字母为 `'A'`〜`'Z'` 共26个字符，因此可以用 `int[26]` 的数组来管理各字符的出现次数。将字符转换为索引的方法是 `charAt() - 'A'`。

```java
int[] count = new int[26];           // 保存26个字母出现次数的数组
count[s.charAt(i) - 'A']++;         // 将字符s.charAt(i)的出现次数加1
count[s.charAt(i) - 'A']--;         // 将字符s.charAt(i)的出现次数减1
```

### 不减小maxFreq的原因

`maxFreq` 是窗口内最高频字符的出现次数。即使左指针前进排除了某个字符，也不需要重新计算并减小 `maxFreq`。在求最大长度的问题中，即使 `maxFreq` 变得比过去的最大值更小，在该状态下获得的窗口大小也不会超过过去的最大长度。因此，将 `maxFreq` 保持单调递增来管理也能得到正确的结果。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 右指针和左指针各自最多前进n次即可完成 |
| Space | O(1) — 使用的数组大小固定为26，不依赖于输入大小 |

## 代码

```java
// 输入: 大写英文字母组成的字符串 s 和整数 k（最大替换次数）
// 输出: 以int形式返回最多替换k次后能使所有字符相同的子串的最大长度
public int characterReplacement(String s, int k) {
    // 管理各字符（A〜Z）出现次数的数组。索引0对应'A'，25对应'Z'
    int[] count = new int[26];
    // left: 窗口的左端
    int left = 0;
    // maxFreq: 窗口内出现次数最多的字符的次数（以单调递增方式管理）
    int maxFreq = 0;
    // maxLen: 满足条件的子串的最大长度（最终返回此值）
    int maxLen = 0;

    // 将右指针逐步前进，扩大窗口的右端
    for (int right = 0; right < s.length(); right++) {
        // 将右端新增字符的出现次数加1
        count[s.charAt(right) - 'A']++;

        // 将新增字符的出现次数与当前maxFreq比较，更新最高频字符的出现次数
        maxFreq = Math.max(maxFreq, count[s.charAt(right) - 'A']);

        // 窗口大小 - maxFreq = 需要替换的字符数。当该值超过k时，缩小左端
        // 注意: 此处不重新计算maxFreq。因为减小它对更新最大长度没有贡献
        while (right - left + 1 - maxFreq > k) {
            // 将左端字符的出现次数减1，从窗口中移除该字符
            count[s.charAt(left) - 'A']--;
            left++;
        }

        // 窗口有效（替换数 ≤ k），用当前窗口大小更新最大长度
        maxLen = Math.max(maxLen, right - left + 1);
    }
    // for循环结束后，返回最多替换k次能得到的最长相同字符子串的长度
    return maxLen;
}
```
