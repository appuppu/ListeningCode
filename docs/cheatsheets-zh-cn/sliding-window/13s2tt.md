# Finding the Longest Substring Without Repeating Characters — 求不含重复字符的最长子串长度

## 问题的本质

给定一个字符串 `s`。从 `s` 中找到不包含重复字符的连续子串（substring），并返回其**最大长度**（整数）。

## 核心思路

使用滑动窗口可以在O(n)时间内检查所有有效子串。当发现重复字符时，将左端直接跳转到"重复字符上次出现位置+1"，从而省去逐个移动的无效操作。

## 思考过程

1. **用窗口表示子串的搜索范围**: "无重复子串"可以表示为由左端 `left` 和右端 `right` 两个指针围成的区间。右端逐步前移来扩展窗口，当出现重复时移动左端来收缩窗口
2. **使用HashMap检测重复**: 将每个字符的"最后出现索引"记录在HashMap中，即可在O(1)时间内判断新字符是否已存在于窗口内
3. **精确确定左端跳转条件**: 仅凭字符存在于HashMap中是不够的。只有当该字符上次出现的位置大于等于 `left`（即在当前窗口内）时，才视为重复。窗口外的旧记录应被忽略
4. **确定左端的移动目标**: 检测到重复后，将 `left` 更新为"重复字符上次出现位置 + 1"。这样既能将重复字符排除出窗口，又能保留其他有效字符在窗口内
5. **HashMap的更新时机**: 在完成重复判定之后，将当前字符的索引注册（覆盖）到HashMap中。这样可以始终记录每个字符的最新出现位置
6. **更新最大长度**: 在每一步中计算 `right - left + 1`（当前窗口宽度），并与之前的最大值进行比较更新

## 前置知识

### 什么是滑动窗口

滑动窗口是一种在数组或字符串上，通过两个指针（`left`, `right`）定义的区间作为"窗口"进行移动，从而搜索满足条件的部分的技巧。右端前移来扩展窗口，当条件被违反时左端前移来收缩窗口。由于每个指针只向前移动，整体时间复杂度为O(n)。

### 什么是HashMap

HashMap是一种保存键值对的数据结构。通过指定键可以在O(1)时间内搜索和获取值。在本题中，键为"字符"，值为"该字符最后出现的索引"。

```java
HashMap<Character, Integer> map = new HashMap<>();  // 创建空的HashMap
map.put('a', 0);            // 将值0存入键'a'
map.containsKey('a');       // 返回键'a'是否存在的boolean值 → true
map.get('a');               // 返回键'a'对应的值 → 0
```

### 什么是charAt

charAt是获取字符串指定位置字符的方法。`s.charAt(i)` 返回字符串 `s` 中索引 `i` 处的 `char`。

```java
String s = "abc";
char c = s.charAt(0);  // 返回 'a'
char d = s.charAt(2);  // 返回 'c'
```

### 什么是Math.max

Math.max是返回两个值中较大值的方法。用于持续更新最大值的场景。

```java
int result = Math.max(3, 7);  // 返回 7
maxLength = Math.max(maxLength, currentLength);  // 更新当前最大值
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — `right` 只需遍历字符串一次。`left` 也只向前移动，因此整体为O(n) |
| Space | O(n) — HashMap最多保存n个字符与索引的键值对 |

## 代码

```java
// 输入: 字符串 s
// 输出: 以 int 形式返回不含重复字符的最长子串长度
public int lengthOfLongestSubstring(String s) {
    // 窗口的左端指针。初始位置为字符串开头
    int left = 0;
    // 记录遍历过程中找到的最长窗口宽度的变量
    int maxLength = 0;
    // 键=字符，值=该字符最后出现的索引 的HashMap
    // 同时用于重复判定和左端跳转目标的计算
    HashMap<Character, Integer> hashMap = new HashMap<>();

    // right 是表示窗口右端的指针。逐步前移来扩展窗口
    for (int right = 0; right < s.length(); right++) {
        // 获取即将添加到窗口中的字符
        char curChar = s.charAt(right);

        // containsKey: 判断该字符是否曾经出现过
        // get(curChar) >= left: 确认该出现位置是否在当前窗口内
        // 当两者都为真时，窗口内存在重复
        if (hashMap.containsKey(curChar) && hashMap.get(curChar) >= left) {
            // 将左端跳转到重复字符上次出现位置+1，以消除重复
            // left 始终只向前移动，不会回退
            left = hashMap.get(curChar) + 1;
        }

        // 用最新索引覆盖注册当前字符的出现位置
        // 下次该字符出现时，将使用此处记录的索引来计算左端的跳转目标
        hashMap.put(curChar, right);
        // right - left + 1 为当前窗口宽度（无重复子串的长度）
        // 如果超过之前的最大值则进行更新
        maxLength = Math.max(maxLength, right - left + 1);
    }
    // 这就是不含重复字符的最长子串长度
    return maxLength;
}
```
