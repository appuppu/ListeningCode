# Checking if a String Contains a Permutation of Another — 判断字符串是否包含另一个字符串的排列

## 问题的本质

给定两个字符串 `s1` 和 `s2`。判断 `s2` 中是否存在 `s1` 的字谜（字符重新排列）作为**连续子字符串**，如果存在则返回 `true`，不存在则返回 `false`。

## 核心思路

`s1` 的排列包含在 `s2` 中，意味着 `s2` 内存在一个与 `s1` 长度相同且字符频率相同的子字符串。使用固定长度的滑动窗口扫描 `s2`，通过差分更新26个字符的频率匹配数，可以在O(1)时间内完成每次滑动的判断。

## 思考过程

1. **换一种方式表述排列的条件**: `s1` 的排列作为 `s2` 的子字符串存在，意味着 `s2` 中存在长度为 `m`（= `s1` 的长度）的子字符串，且该子字符串中每个字符的出现次数与 `s1` 完全一致
2. **使用固定长度的窗口进行扫描**: 子字符串的长度始终为 `m`，因此在 `s2` 上放置一个长度为 `m` 的固定大小窗口，每次滑动一个字符并比较字符频率即可
3. **使用频率数组管理字符的出现次数**: 英文小写字母共有26种，因此使用两个大小为26的整数数组（`s1F` 和 `winF`）分别管理 `s1` 和窗口内的字符频率。数组的每个索引对应一个字符
4. **每次比较26个元素是浪费的**: 滑动窗口时发生变化的字符最多只有"新进入的1个字符"和"离开的1个字符"两个。与其每次比较26个元素，不如使用 `matches` 计数器追踪"26个字符中频率一致的字符数"，只更新差分部分
5. **matches计数器的更新规则**: 修改某个字符的频率时，如果修改前频率一致则将 `matches` 减1，如果修改后频率一致则将 `matches` 加1。遵守"修改前判断→修改值→修改后判断"的顺序，可以保持计数器的一致性
6. **判断条件**: 当 `matches` 达到26时，表示全部26个字符的频率都一致，返回 `true`。如果滑动到 `s2` 的末尾仍未达到26，则返回 `false`

## 前置知识

### 什么是滑动窗口

滑动窗口是一种在数组或字符串上，通过移动左端和右端来扫描连续子区间的方法。对于固定长度的窗口，右端向前移动一个位置的同时左端也向前移动一个位置，从而保持窗口大小不变。

```java
// 在s2上滑动长度为m的固定窗口的基本形式
for (int i = m; i < n; i++) {
    char entering = s2.charAt(i);       // 新进入窗口的字符（右端）
    char leaving = s2.charAt(i - m);    // 离开窗口的字符（左端）
}
```

### 什么是频率数组

频率数组是一个大小为26的整数数组，用于存储每个字符的出现次数。将 `'a'` 对应索引0，`'z'` 对应索引25。通过 `charAt(i) - 'a'` 将字符转换为索引。

```java
int[] freq = new int[26];              // 所有元素初始化为0
freq[s.charAt(i) - 'a']++;            // 将字符的出现次数加1
freq[s.charAt(i) - 'a']--;            // 将字符的出现次数减1
```

### 什么是matches计数器

matches计数器用于追踪两个频率数组中相同索引的值一致的个数。当全部26个都一致时，`matches == 26`，表示两个字符串的字符组成完全相同。

```java
int matches = 0;
for (int i = 0; i < 26; i++) {
    if (s1F[i] == winF[i]) matches++;  // 统计频率一致的字符数
}
// matches == 26 表示所有字符的频率都一致
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需扫描 `s2` 一次（每次滑动为O(1)） |
| Space | O(1) — 频率数组的大小始终为26，不依赖于输入大小 |

## 代码

```java
// 输入: 字符串 s1（要搜索的排列）和字符串 s2（被搜索的字符串）
// 输出: 如果 s2 包含 s1 的排列作为子字符串则返回 true，否则返回 false
boolean checkInclusion(String s1, String s2) {
    int m = s1.length();
    int n = s2.length();

    // 如果s1比s2长，则不可能包含排列，立即返回false
    if (m > n) return false;

    // 大小为26的数组，分别存储s1的字符频率和窗口的字符频率
    int[] s1F = new int[26];
    int[] winF = new int[26];

    // 计算第一个窗口（前m个字符）的频率。同时统计s1和s2前m个字符
    for (int i = 0; i < m; i++) {
        s1F[s1.charAt(i) - 'a']++;
        winF[s2.charAt(i) - 'a']++;
    }

    // 统计26个字符中频率一致的字符数（计算初始matches）
    int matches = 0;
    for (int i = 0; i < 26; i++) {
        if (s1F[i] == winF[i]) matches++;
    }

    // 如果第一个窗口中全部26个字符的频率都一致则返回true
    if (matches == 26) return true;

    // 将窗口每次向右滑动一个字符（i是窗口右端的下一个位置）
    for (int i = m; i < n; i++) {
        // --- 处理新进入窗口的字符（右端） ---
        int idx = s2.charAt(i) - 'a';
        // 注意: 必须遵守"修改前判断→修改值→修改后判断"的顺序
        if (winF[idx] == s1F[idx]) matches--;   // 如果修改前一致则减少matches
        winF[idx]++;                              // 进入窗口，频率加1
        if (winF[idx] == s1F[idx]) matches++;   // 如果修改后一致则增加matches

        // --- 处理离开窗口的字符（左端） ---
        idx = s2.charAt(i - m) - 'a';
        // 与进入字符相同的步骤: 修改前判断→修改值→修改后判断
        if (winF[idx] == s1F[idx]) matches--;   // 如果修改前一致则减少matches
        winF[idx]--;                              // 离开窗口，频率减1
        if (winF[idx] == s1F[idx]) matches++;   // 如果修改后一致则增加matches

        // 如果全部26个字符的频率都一致则找到了排列，返回true
        if (matches == 26) return true;
    }

    // 滑动到s2末尾仍未达到matches==26，返回false
    return false;
}
```
