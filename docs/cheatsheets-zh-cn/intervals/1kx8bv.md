# Finding the Minimum Meeting Rooms Required — 求所有会议无冲突召开所需的最少会议室数量

## 问题的本质

给定一个会议时间段（开始时间和结束时间）的数组。返回所有会议无冲突召开所需的**最少会议室数量**。在同一时间段内重叠的会议需要分别使用不同的会议室。

## 核心思路

将会议的开始和结束作为独立的事件按时间顺序处理，就能求出某一时刻同时进行的会议的最大数量。该最大数量即为所需的会议室数量。

## 思考过程

1. **同时进行的会议数量即为答案**: 某一时刻同时进行的会议的最大数量 = 所需的会议室数量。问题归结为高效地求出"同时进行数量的最大值"
2. **将开始和结束作为独立的事件处理**: 会议开始时需要一间会议室，结束时释放一间会议室。将开始和结束分离并分别排序，就能按时间顺序处理事件
3. **对两个已排序数组进行扫描**: 将starts数组和ends数组分别排序，从头开始遍历starts。对每个开始时间判断"是否早于最早的结束时间"，即可确定是需要新增会议室还是释放会议室
4. **用双指针追踪同时进行的数量**: 准备starts数组的指针 `i` 和ends数组的指针 `endPtr`。若 `starts[i] < ends[endPtr]`，则新会议与现有会议重叠，需要增加会议室。否则，一场会议已结束，会议室被释放，将 `endPtr` 向前推进
5. **记录最大值**: 在遍历过程中持续将 `rooms` 的最大值记录到 `maxRooms` 中。遍历完成后返回 `maxRooms`

## 前置知识

### 什么是 Arrays.sort

Arrays.sort 是Java的标准方法，用于将数组按升序排序。对于基本类型数组，使用双轴快速排序（O(n log n)）。

```java
int[] arr = {5, 2, 8, 1};
Arrays.sort(arr);        // arr 变为 {1, 2, 5, 8}
```

### 什么是双指针（Two Pointer）

双指针是一种使用两个索引变量分别独立遍历数组的技巧。对已排序的数组使用该技巧，可以高效地比较和合并两个数组的元素。

```java
int i = 0;          // 第一个数组的指针
int endPtr = 0;     // 第二个数组的指针
// 根据条件决定推进哪个指针
```

### 什么是事件扫描（Event Sweep）

事件扫描是一种按时间顺序处理时间轴上的事件（开始和结束），并追踪某一时刻状态（如同时进行数量）的方法。通过在开始事件时增加计数器、在结束事件时减少计数器，可以得知任意时刻的同时进行数量。

## 复杂度

| | 值 |
|---|---|
| Time | O(n log n) — 两个数组的排序占主导地位 |
| Space | O(n) — 创建两个数组分别存储开始时间和结束时间 |

## 代码

```java
// 输入: 表示会议时间段的二维整数数组 intervals（每个元素为 [start, end]）
// 输出: 以 int 形式返回所有会议无冲突召开所需的最少会议室数量
public int minMeetingRooms(int[][] intervals) {
    // 若输入为 null 或为空，则不存在会议，返回 0
    if (intervals == null || intervals.length == 0)
        return 0;

    int n = intervals.length;
    // 将开始和结束分离，使其可以分别独立排序
    int[] starts = new int[n];  // 存储开始时间的数组
    int[] ends = new int[n];    // 存储结束时间的数组

    // 遍历 intervals，将开始时间和结束时间分别存入不同的数组
    for (int i = 0; i < n; i++) {
        starts[i] = intervals[i][0];
        ends[i] = intervals[i][1];
    }

    // 将两个数组按升序排序，为按时间顺序处理事件做准备
    Arrays.sort(starts);
    Arrays.sort(ends);

    int rooms = 0, maxRooms = 0;
    // ends数组的指针，指向最早结束的会议
    int endPtr = 0;

    // 从头遍历 starts 数组。每次迭代表示"一场新会议开始"的事件
    for (int i = 0; i < n; i++) {
        if (starts[i] < ends[endPtr]) {
            // 当前开始的会议的开始时间早于最早结束的会议的结束时间 → 发生重叠，分配新的会议室
            rooms++;
        } else {
            // 最早结束的会议已经结束，可以复用该会议室。不增加会议室数量，将 endPtr 向前推进以指向下一个最早结束的会议
            endPtr++;
        }
        // 更新同时使用的最大会议室数量
        maxRooms = Math.max(maxRooms, rooms);
    }
    // maxRooms 是同时使用的会议室数量的最大值，即所需的最少会议室数量
    return maxRooms;
}
```
