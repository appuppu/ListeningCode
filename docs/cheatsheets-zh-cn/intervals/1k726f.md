# Merging Overlapping Intervals — 合并所有重叠区间

## 问题本质

给定一个区间（起始值和结束值的配对）数组 `intervals`。将所有重叠的区间进行合并，返回一个不重叠的区间列表。

## 核心思路

如果按起始值对区间进行排序，那么可能重叠的只有相邻的区间。排序后从前往后依次遍历，如果当前区间与前一个区间重叠，则更新结束值；如果不重叠，则将当前区间作为新区间添加到结果中。

## 思考过程

1. **简化重叠判定**: 如果区间未排序，则需要比较所有的区间对。按起始值升序排序后，重叠判定只需检查「前一个区间的结束值 ≥ 当前区间的起始值」即可
2. **排序后只需一次遍历即可完成合并**: 从头开始依次遍历排序后的区间。将结果列表末尾的区间与当前区间进行比较，如果重叠则将结束值更新为较大的值。如果不重叠则将当前区间直接添加到结果列表中
3. **需要访问结果列表的末尾元素**: 合并判定时始终需要引用结果列表中「最后添加的区间」的结束值。使用LinkedList可以通过 `getLast()` 以O(1)的时间复杂度访问末尾元素
4. **准确定义重叠条件**: 当前一个区间的结束值小于当前区间的起始值（`res.getLast()[1] < interval[0]`）时，两个区间不重叠。除此之外（结束值 ≥ 起始值）的情况均为重叠，需要进行合并
5. **合并时只需更新结束值**: 由于起始值已排序，前一个区间的起始值必定小于或等于当前区间的起始值。结束值取两个区间中较大的值。使用 `Math.max()` 比较前一个结束值和当前结束值
6. **最终返回结果**: 将结果列表中积累的所有非重叠区间转换为 `int[][]` 二维数组并返回

## 前置知识

### Arrays.sort 与自定义Comparator

`Arrays.sort` 是对数组进行排序的方法。对于二维数组，通过lambda表达式指定Comparator，定义以哪个元素为基准进行排序。

```java
int[][] intervals = {{3, 6}, {1, 3}, {2, 5}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 按每个区间的起始值（index 0）升序排序
// 结果: {{1, 3}, {2, 5}, {3, 6}}
```

### 什么是LinkedList

LinkedList是一种在头部、尾部添加元素以及获取尾部元素均为O(1)时间复杂度的列表。与ArrayList不同，它可以通过 `getLast()` 方法直接访问尾部元素。

```java
LinkedList<int[]> res = new LinkedList<>();  // 创建一个空的LinkedList
res.add(new int[]{1, 3});   // 在尾部添加元素
res.getLast();               // 获取尾部元素 → {1, 3}
res.getLast()[1] = 5;        // 直接修改尾部元素的结束值 → {1, 5}
res.isEmpty();               // 返回列表是否为空的布尔值 → false
res.size();                  // 返回列表的元素个数 → 1
```

### 什么是Math.max

Math.max是返回两个值中较大值的方法。在区间合并中，用于取两个结束值中较大的值。

```java
Math.max(5, 8);   // → 8
Math.max(10, 3);  // → 10
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n log n) — 排序为O(n log n)，遍历为O(n)，因此整体为O(n log n) |
| Space | O(n) — 结果列表中最多保存n个区间 |

## 代码

```java
// 输入: 区间的二维数组 int[][] intervals（每个元素为 [起始值, 结束值]）
// 输出: 返回合并重叠区间后的二维数组 int[][]
public int[][] merge(int[][] intervals) {
    // 通过排序，将重叠判定限定为仅比较相邻区间
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // 用于积累合并后区间的结果列表
    // 使用LinkedList的原因是可以以O(1)的时间复杂度引用和更新尾部元素
    LinkedList<int[]> res = new LinkedList<>();

    for (int[] interval : intervals) {
        // 如果res为空则是第一个区间，无条件添加
        // 如果 res.getLast()[1] < interval[0] 则与前一个区间不重叠，直接添加
        if (res.isEmpty() || res.getLast()[1] < interval[0]) {
            res.add(interval);
        } else {
            // 如果重叠，则将结束值更新为较大值进行合并
            // 由于起始值已排序，前一个区间的起始值必定小于或等于当前值，无需修改
            res.getLast()[1] = Math.max(res.getLast()[1], interval[1]);
        }
    }

    // 将结果列表转换为二维数组并返回
    return res.toArray(new int[res.size()][]);
}
```
