# Finding the Minimum Removals for Non-Overlapping Intervals — 求使区间不重叠所需移除的最少区间数

## 问题的本质

给定一个区间数组 `intervals`（每个区间是 `[start, end]` 的配对）。返回为使剩余区间互不重叠所需**移除的最少区间数**。

## 核心思路

将区间按结束时间排序，优先保留结束时间早的区间，这样与后续区间重叠的可能性最小。当发生重叠时，移除结束时间较晚的一方（即当前区间），从而将移除数量最小化。

## 思考过程

1. **要减少重叠，应优先保留"占用空间少"的区间**: 结束时间越早的区间，后方剩余的空闲空间越多，越不容易与后续区间重叠。因此，将区间按结束时间升序排序，按结束时间从早到晚贪心地选择是最优策略
2. **排序后，只需追踪上一个保留区间的结束时间**: 由于已按结束时间排序，只需记住已保留区间中最后一个的结束时间 `lastEnd`，就能判断下一个区间是否重叠。如果下一个区间的开始时间小于 `lastEnd`，则存在重叠
3. **发生重叠时，移除当前区间**: 当发生重叠时，应该移除上一个保留的区间还是当前区间？由于已按结束时间排序，当前区间的结束时间大于等于上一个区间的结束时间。移除结束时间较晚的当前区间对后续的影响更小。因此将 `removals` 加一，不更新 `lastEnd`
4. **不重叠时，保留当前区间**: 如果当前区间的开始时间大于等于 `lastEnd`，则不存在重叠，保留该区间。将 `lastEnd` 更新为当前区间的结束时间
5. **最终返回值**: 循环结束后，返回 `removals`（已移除的区间数量）

## 前置知识

### Arrays.sort 的自定义比较器

通过向 `Arrays.sort` 的第二个参数传入 Lambda 表达式，可以自定义排序规则。`(a, b) -> a[1] - b[1]` 表示以每个区间的结束时间（索引为1的元素）为基准进行升序排序。

```java
int[][] intervals = {{1,3}, {2,4}, {0,2}};
Arrays.sort(intervals, (a, b) -> a[1] - b[1]);
// 结果: {{0,2}, {1,3}, {2,4}} — 按结束时间从早到晚排列
```

### 什么是贪心算法（Greedy）

贪心算法是在每一步都做出"当前最优选择"，从而得到全局最优解的方法。在本题中，"优先保留结束时间最早的区间"这一局部选择，能够使整体移除数量最小化。

```java
// 贪心算法的典型模式: 先排序，再从头开始依次做出最优选择
Arrays.sort(data, comparator);  // 按基准排序
for (int i = 0; i < data.length; i++) {
    // 满足条件则选择，不满足则跳过
}
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n log n) — 排序需要 O(n log n)，遍历需要 O(n)，排序为主导项 |
| Space | O(1) — 除排序的内部空间外，不使用额外的数据结构 |

## 代码

```java
// 输入: 区间数组 int[][] intervals（每个元素为 [start, end]）
// 输出: 返回为消除重叠所需移除的最少区间数，类型为 int
int eraseOverlapIntervals(int[][] intervals) {
    // 如果区间数量为0，则无需移除
    if (intervals.length == 0)
        return 0;

    // 按结束时间升序排序（为了优先保留结束时间早的区间）
    // 贪心策略: 结束时间越早的区间越不容易与后续区间重叠，因此优先保留是最优的
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);

    // 记录已移除区间数量的变量
    int removals = 0;
    // 排序后的第一个区间始终保留（因为其结束时间最早）。记录其结束时间
    int lastEnd = intervals[0][1];

    // 从索引1开始遍历（第0个区间已确定为保留）
    for (int i = 1; i < intervals.length; i++) {
        // 如果当前区间的开始时间小于 lastEnd，则与上一个保留的区间重叠
        if (intervals[i][0] < lastEnd) {
            // 移除当前区间。由于已按结束时间排序，当前区间的结束时间大于等于 lastEnd，
            // 移除结束时间较晚的当前区间能减少与后续区间的重叠。不更新 lastEnd
            removals++;
        } else {
            // 不重叠，保留当前区间，将 lastEnd 更新为当前区间的结束时间
            // 与下一个区间的重叠判断将以这个新的 lastEnd 为基准
            lastEnd = intervals[i][1];
        }
    }
    // removals 即为消除重叠所需移除的最少区间数
    return removals;
}
```
