# 判断是否能参加所有会议 — Determining if All Meetings Can Be Attended

## 问题的本质

给定一个表示会议时间段的区间数组 `intervals`（每个元素是开始时间和结束时间的配对）。判断一个人是否**能参加所有会议**，返回 `boolean`。如果某个会议在另一个会议结束之前就开始了，则这两个会议存在冲突（重叠），无法全部参加。

## 核心思路

将区间按开始时间排序后，重叠只可能发生在相邻的区间之间。只需依次比较相邻的区间对，检查下一个区间的开始时间是否早于上一个区间的结束时间，即可完成整体的重叠判断。

## 思考过程

1. **整理重叠的条件**：两个区间重叠，意味着一个区间的开始时间早于另一个区间的结束时间。但如果区间的顺序是无序的，就需要比较所有的区间对，时间复杂度为O(n²)
2. **通过排序限定比较对象**：将区间按开始时间升序排序后，重叠只可能发生在相邻的区间之间。因为如果 `intervals[i]` 和 `intervals[i+2]` 重叠，那么 `intervals[i]` 和 `intervals[i+1]` 也必然重叠
3. **相邻区间对的重叠判断**：排序后，如果 `intervals[i]` 的开始时间早于 `intervals[i-1]` 的结束时间，则这两个会议存在重叠。该条件可以表示为 `intervals[i][0] < intervals[i-1][1]`
4. **只要存在一组重叠即可立即得出结论**：只要发现一组重叠，就无法参加所有会议，返回 `false`。如果检查完所有相邻区间对都没有重叠，则返回 `true`

## 前置知识

### Arrays.sort 与自定义Comparator

`Arrays.sort` 是对数组进行排序的方法。对于二维数组，可以通过Lambda表达式指定Comparator（比较函数），控制以哪个元素为基准进行排序。

```java
int[][] intervals = {{7, 10}, {2, 4}, {5, 8}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 按每个区间的开始时间（[0]）升序排序
// 结果: {{2, 4}, {5, 8}, {7, 10}}
```

`(a, b) -> a[0] - b[0]` 接收两个区间 `a` 和 `b`，返回开始时间的差值。差值为负则 `a` 排在前面，为正则 `b` 排在前面。

### 区间的重叠判断

当两个区间已按开始时间排序时，如果后一个区间的开始时间早于前一个区间的结束时间，则存在重叠。

```java
int[] prev = {2, 4};   // 2点到4点的会议
int[] curr = {3, 6};   // 3点到6点的会议
curr[0] < prev[1];     // 3 < 4 → true → 存在重叠
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n log n) — 排序为O(n log n)，遍历相邻区间对为O(n)，排序占主导地位 |
| Space | O(1) — 排序直接在输入数组上进行，不使用额外的数组 |

## 代码

```java
// 输入: 表示会议时间段的二维整数数组 intervals（每个元素为 [开始时间, 结束时间]）
// 输出: 如果能参加所有会议则返回 true，如果存在重叠的会议则返回 false
public boolean canAttendMeetings(int[][] intervals) {
    // 按开始时间升序对区间进行排序
    // 将Lambda表达式 (a, b) -> a[0] - b[0] 作为Comparator传入
    // 这样，对于按时间顺序排列的区间，只需比较相邻的区间对即可
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // 从 i = 1 而不是 i = 0 开始。因为每一步都要比较 intervals[i] 和 intervals[i-1] 这对相邻区间
    for (int i = 1; i < intervals.length; i++) {
        // 如果当前会议的开始时间早于上一个会议的结束时间，则存在重叠
        if (intervals[i][0] < intervals[i - 1][1]) {
            // 只要存在一组重叠就无法参加所有会议，立即返回 false
            return false;
        }
        // 如果没有重叠，则继续检查下一对相邻区间
    }
    // 如果循环完整执行完毕，说明所有相邻区间对都没有重叠，返回 true
    return true;
}
```
