# Scheduling Tasks With Cooldown Intervals — 求解带冷却间隔的任务最小执行时间

## 问题的本质

给定一个任务数组（用字符表示）和一个非负整数 `n`（冷却间隔）。相同的任务必须间隔至少 `n` 个时间单位才能再次执行。在冷却期间CPU处于空闲状态。返回完成所有任务所需的**最小时间单位数**。

## 核心思路

出现频率最高的任务决定了整个调度的骨架。最高频任务之间产生的冷却间隙能否被其他任务填满，决定了总时间是取「公式计算结果」还是「任务总数」中的较大值。

## 思考过程

1. **最高频任务成为瓶颈**: 冷却约束最严格的是出现次数最多的任务。该任务支配了整个调度的长度
2. **排列最高频任务后会产生间隙**: 设最高频任务的出现次数为 `maxFreq`，将该任务按间隔 `n` 排列时，任务之间会产生 `(maxFreq - 1)` 个块。每个块的长度为 `(n + 1)`（1个任务 + `n` 个冷却槽位）
3. **用其他任务填充间隙**: 在每个块内的冷却槽位中放置其他任务，以减少空闲时间。如果间隙全部被填满，则不会产生空闲
4. **最后一个块需要特殊处理**: 最后一次执行不需要冷却，因此最后一个块只包含最高频任务（以及频率相同的任务）。设与最高频次相同的任务个数为 `maxCount`，则最后一个块的长度为 `maxCount`
5. **用公式计算整体长度**: `(maxFreq - 1) * (n + 1) + maxCount` 可以求出以最高频任务为轴的调度长度
6. **需要与任务总数进行比较**: 如果间隙全部被填满且还有剩余任务，则完全不需要空闲，任务总数直接就是答案。因此最终答案为 `Math.max(formulaResult, tasks.length)`

## 前置知识

### 什么是频率数组

使用固定大小的数组来统计每个字符出现次数的技巧。如果只有英文大写字母，大小为26的数组即可覆盖所有字符。比HashMap更快且更省内存。

```java
int[] freq = new int[26];            // 初始化26个计数器（对应A〜Z），值为0
freq['B' - 'A']++;                   // 将'B'的出现次数加1（索引为1）
freq['B' - 'A'];                     // 获取'B'的出现次数 → 1
```

### 什么是 Math.max

返回两个值中较大值的方法。用于从两个候选值中选择答案。

```java
Math.max(10, 7);    // → 10（返回较大的值）
Math.max(5, 12);    // → 12
```

### 本题中的块结构是什么

假设最高频任务为 `A`（出现3次），`n = 2`，则调度呈以下块结构：

```
[A _ _] [A _ _] [A]
  块1      块2    最后
```

`_` 是冷却槽位，可以放入其他任务或保持空闲。最后一个块不需要冷却，因此只包含 `A`。

## 复杂度

| | 值 |
|---|---|
| Time | O(k) — 遍历任务数组一次，并对固定长度为26的数组进行常数次遍历（k为任务数） |
| Space | O(1) — 仅使用大小为26的固定长度数组 |

## 代码

```java
// 输入: 字符数组 tasks（每个字符表示一个任务）和非负整数 n（冷却间隔）
// 输出: 以 int 形式返回完成所有任务所需的最小时间单位数
public int leastInterval(char[] tasks, int n) {
    // 统计每个任务（A〜Z）出现次数的频率数组。freq[0]对应'A'，freq[1]对应'B'
    int[] freq = new int[26];
    // 遍历tasks数组，通过 t - 'A' 将字符转换为0〜25的索引并计数
    for (char t : tasks)
        freq[t - 'A']++;

    // 求最大出现次数。该值决定了调度的块数
    int maxFreq = 0;
    for (int f : freq)
        maxFreq = Math.max(maxFreq, f);

    // 统计与最大出现次数相同的任务个数。该值为最后一个块中包含的任务数
    int maxCount = 0;
    for (int f : freq)
        if (f == maxFreq) maxCount++;

    // 基于块结构的公式进行计算
    // (maxFreq - 1): 需要冷却的块的数量
    // (n + 1): 每个块的长度（1个任务 + n 个冷却槽位）
    // maxCount: 最后一个块的长度（仅包含与最高频次相同的任务）
    int formulaResult =
        (maxFreq - 1) * (n + 1)
        + maxCount;

    // formulaResult: 因冷却产生空闲时的长度
    // tasks.length: 完全不需要空闲时的长度（间隙全部填满且有剩余任务的情况）
    // 两者中较大的值即为正确答案
    return Math.max(formulaResult,
        tasks.length);
}
```
