# Generating All Valid Parentheses Combinations — 生成n组括号的所有有效组合

## 问题的本质

给定一个整数 `n`。使用 `n` 个左括号 `(` 和 `n` 个右括号 `)`，生成**所有**正确嵌套的括号字符串，并以列表形式返回。每个字符串的长度为 `2 * n`，且在任意位置，右括号的累计数量都不能超过左括号的累计数量。

## 核心思路

逐字符构建字符串时，仅通过"剩余左括号数量"和"剩余右括号数量"这两个状态，就可以确定下一个能放置的字符。如果左括号使用不足 `n` 个，则可以添加左括号；只有当右括号数量少于左括号数量时，才可以添加右括号。通过此条件进行分支剪枝，就能在不生成任何无效字符串的情况下，枚举出所有有效的组合。

## 思考过程

1. **需要枚举所有组合**: 问题要求"生成所有组合"，因此需要一种能够探索性地枚举所有模式的方法。逐字符构建字符串并进行分支的回溯法非常适合此类问题
2. **每一步只有两个选择**: 字符串的每个位置只能放置 `(` 或 `)` 两种字符。通过递归地重复这两个选择，可以探索所有候选方案
3. **需要尽早剪掉无效分支**: 如果尝试所有的两种选择，将产生 `2^(2n)` 种情况，但其中大部分是无效的。有效性的条件有两个：左括号的使用数量不能超过 `n` 个；右括号的数量在任何时刻都不能超过左括号的数量。通过这两个条件进行分支剪枝
4. **状态可以用两个变量管理**: 将 `open`（已使用的左括号数量）和 `close`（已使用的右括号数量）传递给递归函数。如果 `open < n`，则可以添加 `(`；如果 `close < open`，则可以添加 `)`
5. **字符串长度达到 `2 * n` 时即完成**: 在遵守 `open` 和 `close` 条件的前提下构建的字符串，一旦达到 `2 * n` 个字符，该字符串必定是有效的。将其添加到结果列表中
6. **通过回溯恢复状态**: 向 `StringBuilder` 添加字符并递归后，使用 `deleteCharAt` 删除末尾字符以恢复原始状态。这样就可以让所有探索路径共享同一个 `StringBuilder` 实例

## 前置知识

### 什么是回溯法

回溯法是一种通过反复执行"选择→递归→撤销"来枚举所有有效组合的搜索方法。在每一步中，从选项中选择一个，然后递归地进入下一步。从递归返回后，撤销选择（回溯），然后尝试其他选项。通过添加剪枝条件，可以尽早终止无效路径的探索。

```java
// 回溯法的基本模式
void backtrack(状态) {
    if (终止条件) {
        添加到结果;
        return;
    }
    for (每个选项) {
        应用选择;        // 例: sb.append('(')
        backtrack(下一个状态);
        撤销选择;        // 例: sb.deleteCharAt(sb.length() - 1)
    }
}
```

### 什么是 StringBuilder

StringBuilder 是一个用于高效构建字符串的类。由于 `String` 是不可变的（immutable），每次添加字符都会生成新的对象，而 `StringBuilder` 直接操作内部缓冲区，因此添加和删除操作的时间复杂度为O(1)。

```java
StringBuilder sb = new StringBuilder();  // 创建空的StringBuilder
sb.append('(');          // 在末尾添加字符 → "("
sb.append(')');          // 在末尾添加字符 → "()"
sb.length();             // 返回当前字符数 → 2
sb.deleteCharAt(1);      // 删除索引1处的字符 → "("
sb.toString();           // 转换为String类型并返回 → "("
```

### 括号有效性的条件

括号字符串"有效"是指满足以下两个条件。
- **条件1**: 左括号和右括号的数量相等
- **条件2**: 在字符串的任意位置，从开头到该位置的右括号数量都不超过左括号的数量

例如：当 `n=2` 时，`(())` 和 `()()` 是有效的。`)()(` 违反条件2，`((()` 违反条件1。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(4^n / √n) — 生成的有效括号字符串数量为卡塔兰数 C(n) = C(2n,n)/(n+1)，其渐近值为 O(4^n / (n√n))。由于构建每个字符串需要O(n)的时间，因此总体时间复杂度为O(4^n / √n) |
| Space | O(n) — 递归深度最大为 2n，StringBuilder 的长度也最大为 2n。除去结果列表，使用的空间为O(n) |

## 代码

```java
// 输入: 整数 n（括号的对数）
// 输出: 返回包含所有有效括号字符串的 List<String>
private void backtrack(StringBuilder sb, int open, int close, int n, List<String> res) {
    // 当字符串长度达到2n时，说明恰好使用了n个左括号和n个右括号，有效的括号字符串构建完成
    if (sb.length() == 2 * n) {
        res.add(sb.toString());
        return;
    }
    // 如果两个条件都不满足，则无法再添加任何字符，因此直接return，由调用方继续回溯

    // 如果左括号不足n个，则仍可以添加左括号
    if (open < n) {
        sb.append('(');
        backtrack(sb, open + 1, close, n, res);
        // 回溯的核心: 删除末尾的 '(' 以恢复状态，从而在正确的状态下尝试下一个分支（添加右括号）
        sb.deleteCharAt(sb.length() - 1);
    }

    // 注意: 条件是 close < open 而不是 close < n，这一点非常重要
    // 如果使用 close < n，则会允许右括号数量超过左括号的情况（例如: ")(")，
    // 而 close < open 能始终保证右括号数量不超过左括号数量，从而防止生成无效字符串
    if (close < open) {
        sb.append(')');
        backtrack(sb, open, close + 1, n, res);
        sb.deleteCharAt(sb.length() - 1);  // 恢复状态
    }
}

public List<String> generateParenthesis(int n) {
    // 用于存储所有有效括号字符串的列表
    List<String> res = new ArrayList<>();
    // 从空的StringBuilder和open=0, close=0开始探索
    backtrack(new StringBuilder(), 0, 0, n, res);
    return res;
}
```
