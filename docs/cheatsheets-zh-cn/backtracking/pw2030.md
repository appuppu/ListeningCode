# 在网格中搜索单词 — 判断能否通过遍历网格中的字符来构成指定单词

## 问题的本质

给定一个二维字符网格 `board` 和一个字符串 `word`。判断能否通过依次遍历网格中相邻的单元格（上下左右）来构成 `word`，并返回 `boolean` 值。每个单元格在一条路径中只能使用一次。

## 核心思路

以网格的每个单元格为起点执行DFS，逐个字符匹配单词中的字符。不使用额外数组来管理已访问的单元格，而是直接用特殊字符覆盖棋盘上的单元格，探索结束后再恢复原值，从而将空间复杂度控制在仅为递归栈深度的水平。

## 思考过程

1. **每个单元格都可能作为起点**：单词的起始位置可以是网格中的任意单元格，因此需要尝试以所有单元格作为起点候选
2. **逐个字符依次匹配**：检查当前单元格的字符是否与 `word` 当前位置的字符一致，如果一致，则向上下左右相邻的单元格递归地推进探索。这种结构本质上就是DFS（深度优先搜索）
3. **防止同一单元格被重复使用**：由于一条路径中不能两次使用同一个单元格，因此需要管理已访问状态。虽然可以使用额外的 `boolean[][]` 访问数组，但这会消耗额外空间
4. **通过直接修改棋盘来表示已访问状态**：进入探索时，将当前单元格的字符覆盖为 `'#'` 等棋盘中不存在的特殊字符，这样在递归过程中就不会再匹配到同一个单元格。由此省去了访问数组，空间复杂度仅为递归栈深度 O(L)
5. **探索结束后恢复原始字符**：在DFS回溯时，将被覆盖的 `'#'` 恢复为原始字符（回溯）。这样，从其他起点出发的探索可以正确地使用同一个单元格
6. **整理探索的终止条件**：当索引 `idx` 达到 `word.length()` 时，表示所有字符匹配成功，返回 `true`。超出范围或字符不匹配时返回 `false`。四个方向中只要有一个返回 `true`，就立即返回 `true`

## 前置知识

### 什么是DFS（深度优先搜索）

DFS是一种图或网格的探索方法。沿一个方向尽可能深入地前进，到达死胡同后回退一步，再尝试其他方向。可以通过递归调用自然地实现。

```java
void dfs(int node) {
    // 处理当前节点
    for (int neighbor : getNeighbors(node)) {
        dfs(neighbor);  // 递归地前进到相邻节点
    }
}
```

### 什么是回溯法

回溯法是一种在探索过程中所做的修改，在从探索返回时恢复原状的方法。通过"尝试 → 前进 → 恢复"的循环，可以不遗漏地探索所有候选方案。

```java
board[r][c] = '#';   // 修改（标记为已访问）
dfs(...);            // 递归地推进探索
board[r][c] = temp;  // 恢复原状（标记为未访问）
```

### 什么是charAt

`charAt` 是一个以 `char` 类型返回 `String` 中指定位置字符的方法。索引从0开始。

```java
String word = "ABCCED";
word.charAt(0);   // 返回 'A'
word.charAt(3);   // 返回 'C'
word.length();    // 返回 6（返回字符数）
```

### 二维网格的四方向探索

在二维网格中探索上下左右的相邻单元格时，需要对行和列分别进行±1的四种模式尝试。

```java
// 按上、下、左、右的顺序进行探索
dfs(board, word, r-1, c, idx+1);  // 上（行-1）
dfs(board, word, r+1, c, idx+1);  // 下（行+1）
dfs(board, word, r, c-1, idx+1);  // 左（列-1）
dfs(board, word, r, c+1, idx+1);  // 右（列+1）
```

## 复杂度

| | 值 |
|---|---|
| Time | O(m × n × 4^L) — 以所有单元格为起点，从每个起点出发最多沿4个方向探索L个字符（m×n为网格大小，L为单词长度） |
| Space | O(L) — 递归栈的最大深度为L。由于直接修改棋盘，因此不需要访问数组 |

## 代码

```java
// 输入：二维字符数组 board 和字符串 word
// 输出：如果能通过网格中的相邻单元格构成 word 则返回 true，否则返回 false

// 从当前位置(r,c)开始匹配word[idx]及之后字符的DFS
boolean dfs(char[][] board, String word, int r, int c, int idx) {
    // 如果 idx 等于 word.length()，则所有字符匹配完成，返回 true
    if (idx == word.length()) return true;

    // 如果 r 或 c 超出网格范围，或者 board[r][c] 与 word.charAt(idx) 不一致，则返回 false
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length
        || board[r][c] != word.charAt(idx))
        return false;

    // 将当前单元格的字符保存到变量 temp 中，然后用 '#' 覆盖以防止重复访问
    // '#' 不会与英文字母匹配，因此可以防止递归过程中再次匹配到该单元格（替代访问数组）
    char temp = board[r][c];
    board[r][c] = '#';

    // 向上下左右四个方向递归探索（任一方向返回true即为成功）
    // 由于 || 的短路求值特性，一旦找到 true，就会跳过剩余方向的探索
    boolean found =
        dfs(board, word, r - 1, c, idx + 1)
     || dfs(board, word, r + 1, c, idx + 1)
     || dfs(board, word, r, c - 1, idx + 1)
     || dfs(board, word, r, c + 1, idx + 1);

    // 无论探索结果如何，都恢复原始字符（回溯）
    // 这样可以确保从其他起点或其他路径出发的探索能够正确使用该单元格
    board[r][c] = temp;
    return found;
}

boolean exist(char[][] board, String word) {
    int m = board.length;
    int n = board[0].length;

    // 用双重for循环遍历网格的所有单元格(i,j)，以每个单元格为起点调用DFS
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // 一旦 dfs 返回 true，立即返回 true
            if (dfs(board, word, i, j, 0))
                return true;

    // 尝试所有单元格后仍未找到，则返回 false
    return false;
}
```
