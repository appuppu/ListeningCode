# Finding Combinations That Sum to a Target — 找出所有和为目标值的数字组合

## 问题的本质

给定一个正整数数组 `candidates`（所有元素互不相同）和一个正整数 `target`。从 `candidates` 中找出所有和为 `target` 的组合并返回。同一个数可以**被重复使用任意次**。仅顺序不同的组合视为重复。

## 核心思路

如果事先对候选数排序，则在递归的每一步中可以判断"当前候选数超过剩余目标值时，其后的所有候选数也一定超过"，从而整体剪去不必要的搜索。通过这种剪枝，可以高效地枚举所有组合。

## 思考过程

1. **枚举所有组合适合使用回溯法**: "找出满足条件的所有模式"这类问题，可以通过逐一选择候选数进行尝试、不行就回退的递归搜索（回溯法）来求解
2. **通过控制索引的起始位置来避免重复**: 虽然同一个数可以使用任意次，但不能将 `[2,3]` 和 `[3,2]` 视为不同的组合。在递归的每一步中"只选择当前位置及之后的候选数"，就只会生成升序的组合，从而避免重复
3. **用剩余目标值（remain）管理进度**: 从 `target` 中逐步减去所选的数，当 `remain` 变为0时表示和恰好等于 `target`。当 `remain` 变为负数时表示和已超过目标值
4. **排序后可以进行剪枝**: 将候选数按升序排序后，当某个候选数 `cands[i]` 超过 `remain` 时，`cands[i+1]` 及之后的数都更大，因此无需再尝试。可以立即终止for循环
5. **用列表管理当前组合，反复执行选择和撤销**: 将元素添加到末尾后进行递归，返回时删除末尾元素。这种"添加→递归→删除"的模式是回溯法的基本操作
6. **当 remain 为0时，将当前组合的副本添加到结果中**: 必须保存副本而非引用，否则后续操作会改变其内容

## 前置知识

### 什么是回溯法

回溯法是一种逐步构建解的候选，一旦发现不满足条件就回退到上一步状态并尝试其他候选的搜索方法。通过递归函数实现，反复执行"选择→递归→撤销选择"来枚举所有模式。

### 什么是 Arrays.sort

Arrays.sort 是将数组按升序排序的方法。在已排序的数组中，可以利用"当前值超过条件时，之后的值也一定全部超过"这一性质进行剪枝。

```java
int[] cands = {3, 1, 2};
Arrays.sort(cands);       // cands 变为 {1, 2, 3}
```

### ArrayList 的操作

ArrayList 是可变长度的列表。可以进行元素的添加、删除和复制。在回溯法中用于管理当前的组合。

```java
List<Integer> curr = new ArrayList<>();
curr.add(2);                          // 在末尾添加2 → [2]
curr.add(3);                          // 在末尾添加3 → [2, 3]
curr.remove(curr.size() - 1);         // 删除末尾元素 → [2]（回溯）
new ArrayList<>(curr);                // 创建 curr 的副本（用于保存结果）
```

### 什么是 List\<List\<Integer\>\>

List\<List\<Integer\>\> 是表示"整数列表的列表"的类型。用于存储多个组合。每个组合是一个 `List<Integer>`，将它们汇总在一起就是 `List<List<Integer>>`。

```java
List<List<Integer>> res = new ArrayList<>();  // 创建空的结果列表
res.add(new ArrayList<>(curr));               // 将组合的副本添加到结果中
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n^(target/min)) — n为候选数的个数，min为最小的候选值。最坏情况下，对每个候选数都会产生选择最小值 target/min 次的分支 |
| Space | O(target/min) — 递归深度最大为 target/min。一个组合中包含的元素个数最多也为 target/min 个 |

## 代码

```java
// 输入: 正整数数组 candidates（所有元素互不相同）和正整数 target
// 输出: 以 List<List<Integer>> 形式返回所有和为 target 的组合
public List<List<Integer>> combinationSum(int[] cands, int target) {
    // 升序排序使得"cands[i] > remain 则其后也全部超过"的剪枝条件可用
    Arrays.sort(cands);
    // 存储结果的列表
    List<List<Integer>> res = new ArrayList<>();
    // 开始回溯（剩余值=target，起始位置=0，当前组合=空）
    backtrack(cands, target, 0, new ArrayList<>(), res);
    return res;
}

// remain: 从 target 中减去已选数后的剩余值。为0则表示和等于 target
// start: 搜索起始位置。只选择当前位置及之后的候选数，从而防止重复（顺序不同）
// curr: 当前正在构建的组合。通过反复执行选择和撤销来搜索所有模式
void backtrack(int[] cands, int remain, int start,
               List<Integer> curr, List<List<Integer>> res) {
    // 若 remain 为0则和等于 target → 将当前组合添加到结果中
    if (remain == 0) {
        // 创建副本并保存。若直接保存引用，后续操作会改变其内容
        res.add(new ArrayList<>(curr));
        return;
    }
    // 从 start 开始遍历，若 cands[i] > remain，由于已排序，其后也全部超过 → 终止循环（剪枝）
    for (int i = start; i < cands.length && cands[i] <= remain; i++) {
        // 将当前候选数添加到组合的末尾
        curr.add(cands[i]);
        // 第3个参数传入 i（而非 i+1），从而允许重复选择同一个数
        backtrack(cands, remain - cands[i], i, curr, res);
        // 从递归返回后撤销添加的元素（回溯）。为尝试下一个候选数做准备
        curr.remove(curr.size() - 1);
    }
}
```
