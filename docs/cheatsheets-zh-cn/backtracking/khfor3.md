# Placing N Queens on a Board Without Conflicts — 在棋盘上无冲突地放置N个皇后

## 问题的本质

给定一个整数 `n`。在 n×n 的棋盘上放置 n 个皇后，使得任意两个皇后都不在同一行、同一列或同一对角线上。以字符串列表的形式返回所有满足条件的棋盘布局。

## 核心思路

如果逐行放置一个皇后，就能自动排除行冲突。对于剩余的列冲突、正对角线冲突和负对角线冲突，用位掩码的各个位来管理，就能在 O(1) 常数时间内完成冲突检测和状态更新。

## 思考过程

1. **从结构上排除行冲突**: 将 n 个皇后放置在 n 行中，每行恰好放置一个皇后，就不会发生行冲突。因此问题归结为一个搜索问题：决定每行将皇后放在哪一列
2. **需要检测列冲突和对角线冲突**: 列冲突可以通过"已使用列的集合"来管理。对角线冲突分为正对角线（右上方向，row + col 相同）和负对角线（左上方向，row - col 相同）两种。管理这三个集合就能检测所有冲突
3. **用位掩码表示集合**: 用整数的各个位来表示列、正对角线和负对角线的使用状态。如果第 c 位为 1，则表示"该列（或对角线）已被使用"。用位运算的 AND 进行冲突判定，用 OR 进行注册，比 HashSet 运行更快
4. **逐行移位对角线的位掩码**: 正对角线在行下移一行时影响范围向左偏移一列，因此用左移（`<< 1`）更新；负对角线向右偏移一列，因此用右移（`>> 1`）更新。这样就能仅通过列号的位位置来进行对角线冲突判定
5. **用回溯法搜索所有解**: 从第 0 行到第 n-1 行依次尝试每行中不冲突的列。如果找到不冲突的列，就放置皇后并递归到下一行；到达第 n 行时记录一个解。从递归返回时配置自动撤销，可以尝试其他列
6. **返回解的总数**: 将所有行都成功放置皇后（到达 row == n）的次数累加后返回

## 前置知识

### 什么是回溯法

回溯法是一种搜索方法：尝试一个选项，遇到死路时回退到上一个选择并尝试其他选项。通过递归调用可以自然地实现"尝试→前进→回退"的过程。适用于枚举所有有效组合的问题。

```java
void backtrack(int step) {
    if (step == goal) {       // 到达目标时记录解
        recordSolution();
        return;
    }
    for (int choice : choices) {
        if (isValid(choice)) {    // 如果选择有效则尝试
            apply(choice);        // 应用选择
            backtrack(step + 1);  // 递归到下一步
            undo(choice);         // 撤销选择并尝试其他选项
        }
    }
}
```

### 什么是位掩码

位掩码是一种将整数的各个位用作"集合中是否存在某元素"的标志的技巧。可以通过位运算高效地执行集合操作。

```java
int mask = 0;             // 空集合（所有位均为0）
int bit = 1 << c;         // 创建仅第c位为1的值（表示元素c）
mask |= bit;              // 将元素c添加到集合中（将第c位设为1）
(mask & bit) != 0;        // 判断元素c是否包含在集合中 → true/false
```

### 通过位移追踪对角线

在棋盘上行下移一行时，正对角线（右上↗方向）的影响向列号较小的方向偏移一列，负对角线（左上↖方向）的影响向列号较大的方向偏移一列。通过对位掩码进行移位来表示这种偏移。

```java
int posDiag = 0;          // 管理正对角线使用状态的位掩码
posDiag |= (1 << c);      // 注册放置在第c列的皇后的正对角线
posDiag << 1;              // 下一行中影响向左偏移一列（左移）

int negDiag = 0;          // 管理负对角线使用状态的位掩码
negDiag |= (1 << c);      // 注册放置在第c列的皇后的负对角线
negDiag >> 1;              // 下一行中影响向右偏移一列（右移）
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n!) — 每行可选的列数最多依次递减为 n, n-1, n-2, ... |
| Space | O(n) — 递归深度为 n 层，每层的位掩码仅为常数个整数 |

## 代码

```java
// 输入: 整数 n（棋盘大小，同时也是要放置的皇后数量）
// 输出: 以 int 形式返回能无冲突地放置 n 个皇后的棋盘布局总数
int totalNQueens(int n) {
    // 从第0行开始搜索，将列、正对角线、负对角线的位掩码全部初始化为空（0）
    return backtrack(0, n, 0, 0, 0);
}

int backtrack(int row, int n,
    int cols, int posDiag,
    int negDiag) {
    // 所有行都已放置皇后，找到了一个解
    if (row == n) return 1;

    // 用于累计从当前行开始找到的解的数量的变量
    int count = 0;

    // 遍历第0列到第n-1列，判断每列是否可以放置皇后
    for (int c = 0; c < n; c++) {
        // 创建对应第c列的位。使用该bit与三个位掩码进行冲突判定
        int bit = 1 << c;

        // 如果与列、正对角线、负对角线中的任意一个冲突，则跳过并尝试下一列
        if ((cols & bit) != 0 ||
            (posDiag & bit) != 0 ||
            (negDiag & bit) != 0)
            continue;

        // 在第c列放置皇后，更新三个位掩码后递归到下一行
        // cols | bit: 将第c列注册为已使用
        // (posDiag | bit) << 1: 注册正对角线，并通过左移反映到下一行的偏移
        // (negDiag | bit) >> 1: 注册负对角线，并通过右移反映到下一行的偏移
        // 位掩码是值传递，因此从递归返回时自动恢复到注册前的状态，无需显式的撤销处理
        count += backtrack(row + 1, n,
            cols | bit,
            (posDiag | bit) << 1,
            (negDiag | bit) >> 1);
    }
    // 返回尝试所有列后得到的解的总数
    return count;
}
```
