# Partitioning a String Into Palindrome Substrings — 求字符串的所有回文子串分割方案

## 问题的本质

给定一个字符串 `s`。将 `s` 进行分割，使得每个子串都是回文串（正读和反读相同的字符串），列举出**所有**满足条件的分割方案，并以列表的列表形式返回。

## 核心思路

通过DP表预先计算任意子串是否为回文串，使判定时间降为 O(1)，然后利用回溯法从头开始依次切出"回文部分"并递归处理，从而高效地列举出所有分割方案。

## 思考过程

1. **分割问题可以用从头依次切出的递归方式来表达**：在字符串从起始位置 `start` 到末尾的范围内，切出从 `start` 到 `end` 的子串，然后对剩余部分进行递归处理。当 `start` 到达字符串末尾时，一个有效的分割方案就完成了
2. **切出的条件是"该部分是回文串"**：因为所有子串都必须是回文串，所以只有当 `s[start..end]` 是回文串时才将其切出并添加到路径中，然后继续递归。如果不是回文串，则跳过该切出方式
3. **每次都用 O(n) 进行回文判定会造成大量浪费**：在回溯的每一步中都需要对子串进行回文判定，但可能会多次判定相同的子串。通过DP表预先计算，可以将任意 `s[l..r]` 的回文判定时间缩短为 O(1)
4. **DP表的构建方法**：`dp[l][r]` 表示"`s` 中从索引 `l` 到 `r` 的子串是否为回文串"的boolean值。回文的条件是"两端字符相同"且"内部子串也是回文串"。长度为1（`l == r`）时始终是回文串，长度为2（`r - l == 1`）时两端字符相同则是回文串，长度为3及以上时，若 `s[l] == s[r]` 且 `dp[l+1][r-1]` 为 true 则是回文串
5. **回溯的结构**：从当前位置 `start` 开始，将 `end` 从 `start` 逐一扩展到 `s.length()-1`，若 `dp[start][end]` 为 true，则将子串添加到路径中并从 `end+1` 开始递归。从递归返回后删除路径末尾元素，尝试其他切出方式
6. **最终返回的内容**：每当 `start` 到达 `s.length()` 时，将当前路径的副本添加到结果列表中。所有递归结束后，返回结果列表

## 前置知识

### 什么是回文串（Palindrome）

正读和反读都相同的字符串。例如 `"aba"`、`"aa"`、`"a"` 是回文串，`"ab"` 不是回文串。

### 基于二维boolean数组的回文DP表

通过 `dp[l][r]` 可以在 O(1) 时间内判定"从索引 `l` 到 `r` 的子串是否为回文串"的表。外层循环固定右端 `r`，内层循环将左端 `l` 从 `0` 遍历到 `r` 来构建该表。

```java
boolean[][] dp = new boolean[n][n];
for (int r = 0; r < n; r++) {
    for (int l = 0; l <= r; l++) {
        // 两端字符相同，且内部是回文串（或长度不超过2）则为回文串
        if (s.charAt(l) == s.charAt(r) && (r - l < 2 || dp[l + 1][r - 1])) {
            dp[l][r] = true;
        }
    }
}
dp[0][2];  // s[0]到s[2]是否为回文串 → true or false
```

### 什么是回溯法

回溯法是一种搜索方法：选择一个选项并递归前进，当不满足条件时撤销上一步的选择并尝试其他选项。由添加到路径（选择）→ 递归 → 从路径中删除（撤销）这三个步骤组成。

```java
path.add(choice);                    // 进行选择
backtrack(nextState, path, result);  // 递归继续前进
path.remove(path.size() - 1);       // 撤销选择，尝试其他路径
```

### substring 方法

`String.substring(start, end)` 返回从索引 `start` 到 `end - 1` 的子串。需要注意 `end` 不包含在内。

```java
String s = "aab";
s.substring(0, 1);  // "a"
s.substring(0, 2);  // "aa"
s.substring(0, 3);  // "aab"
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n × 2^n) — 构建DP表需要 O(n^2)，回溯最多列举 2^(n-1) 种分割方案，每种分割方案中子串的复制需要 O(n) |
| Space | O(n^2) — DP表使用 n×n 的boolean数组。递归栈的最大深度为 O(n) |

## 代码

```java
// 输入: 字符串 s
// 输出: 存储 s 的所有回文分割方案的 List<List<String>>
List<List<String>> partition(String s) {
    int n = s.length();

    // dp[l][r] = 表示 s[l] 到 s[r] 的子串是否为回文串的DP表
    boolean[][] dp = new boolean[n][n];
    // 外层循环固定右端 r，内层循环将左端 l 从 0 遍历到 r 来构建
    for (int r = 0; r < n; r++) {
        for (int l = 0; l <= r; l++) {
            // 两端字符相同，且内部是回文串（或长度不超过2）则为回文串
            // r - l < 2 的条件: 长度为1时始终是回文串，长度为2时两端字符相同则是回文串
            if (s.charAt(l) == s.charAt(r)
                && (r - l < 2
                || dp[l + 1][r - 1])) {
                dp[l][r] = true;
            }
        }
    }

    // 存储所有分割方案的结果列表
    List<List<String>> res = new ArrayList<>();
    // 从起始位置 0 和空路径开始回溯
    bt(s, 0, new ArrayList<>(), res, dp);
    return res;
}

void bt(String s, int start,
    List<String> path,
    List<List<String>> res,
    boolean[][] dp) {
    // 到达字符串末尾 → 整个字符串已被完全分割为回文子串
    if (start == s.length()) {
        // 因为 path 之后会被修改，所以添加其副本
        res.add(new ArrayList<>(path));
        return;
    }

    // 依次尝试从 start 到 end 的子串
    for (int end = start; end < s.length();
        end++) {
        // 使用DP表在 O(1) 时间内进行回文判定
        if (dp[start][end]) {
            // 将回文部分添加到路径中并递归
            // substring 的第二个参数是排他性的，所以指定 end + 1
            path.add(
                s.substring(start, end + 1));
            // 下一个起始位置是 end + 1（切出部分的紧接之后）
            bt(s, end + 1, path, res, dp);
            // 撤销选择，尝试其他切出方式（回溯）
            path.remove(path.size() - 1);
        }
    }
}
```
