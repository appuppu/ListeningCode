# Generating All Subsets of a Set — 生成集合的所有子集

## 问题的本质

给定一个包含不同整数的数组 `nums`。以列表形式返回 `nums` 的所有子集（幂集）。子集不能有重复，返回顺序不限。

## 核心思路

元素数为 `n` 的集合有 `2^n` 个子集。将 `n` 位整数从 `0` 枚举到 `2^n - 1`，每个位表示"是否包含对应元素"，就能不遗漏、不重复地生成所有子集。

## 思考过程

1. **子集的数量由2^n决定**: 每个元素有"包含"或"不包含"两种选择，因此元素数为 `n` 的集合存在 `2^n` 个子集。要枚举所有子集，需要一种能表达这 `2^n` 种选择模式的机制
2. **两种选择的枚举可以用位来表示**: 将"包含=1、不包含=0"进行对应，`n` 个元素的选择模式就可以用 `n` 位整数来表示。例如当 `nums = [a, b, c]` 时，位序列 `101` 表示"包含 a、不包含 b、包含 c"，即子集 `[a, c]`
3. **0到2^n-1的整数涵盖了所有模式**: `n` 位能表示的整数从 `0`（所有位为0 = 空集）到 `2^n - 1`（所有位为1 = 包含全部元素的集合），共 `2^n` 个。依次枚举这些整数，就能不遗漏、不重复地生成所有子集
4. **从每个整数构建子集的方法**: 可以通过 `(mask & (1 << i)) != 0` 来判断整数 `mask` 的第 `i` 位是否为 `1`。如果为 `1`，则将 `nums[i]` 添加到子集中。让 `i` 从 `0` 遍历到 `n-1`，就能完成 `mask` 对应的子集
5. **用1 << n计算2^n**: 在Java中使用位移运算符 `<<`，通过 `1 << n` 计算 `2^n`。将 `mask < (1 << n)` 作为循环上限条件，就能不遗漏地枚举从 `0` 到 `2^n - 1` 的所有值
6. **最终返回的结果**: 将每个 `mask` 对应的子集添加到列表中，处理完所有 `mask` 后，返回子集列表 `result`

## 前置知识

### 什么是位掩码

位掩码是一种将整数的每个位（0 或 1）用作"标志"的技巧。它可以用一个整数表示 `n` 个元素的"包含/不包含"的所有组合。

```java
int mask = 5;            // 二进制为 101
// 第0位: 1（包含）、第1位: 0（不包含）、第2位: 1（包含）
```

### 位运算符

组合使用 `&`（AND）和 `<<`（左移）来判断特定位是否被置位。

```java
1 << 0;                  // 1（二进制: 001）— 创建仅第0位为1的掩码
1 << 1;                  // 2（二进制: 010）— 创建仅第1位为1的掩码
1 << 2;                  // 4（二进制: 100）— 创建仅第2位为1的掩码

int mask = 5;            // 二进制: 101
(mask & (1 << 0)) != 0;  // true  — 第0位为1
(mask & (1 << 1)) != 0;  // false — 第1位为0
(mask & (1 << 2)) != 0;  // true  — 第2位为1
```

### 用1 << n计算2^n

位移操作 `1 << n` 将 `1` 向左移动 `n` 位，结果为 `2^n`。该操作用于求子集的总数。

```java
1 << 3;                  // 8（= 2^3）— 3个元素则有8个子集
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n × 2^n) — 对 2^n 个掩码中的每一个遍历 n 个位 |
| Space | O(n × 2^n) — 保存 2^n 个子集，每个子集的平均元素数为 n/2 |

## 代码

```java
// 输入: 包含不同整数的数组 nums
// 输出: 返回包含所有子集的 List<List<Integer>>
List<List<Integer>> subsets(int[] nums) {
    // nums 的元素数。同时用于位掩码的位数和数组的遍历范围
    int n = nums.length;
    // 存储所有子集的列表。将从每个 mask 生成的子集添加到此列表中
    List<List<Integer>> result = new ArrayList<>();

    // 将 mask 从 0 枚举到 2^n-1，每个值对应一个子集
    // 用 1 << n 计算 2^n 作为循环条件，从而枚举所有 2^n 种模式
    for (int mask = 0; mask < (1 << n); mask++) {
        // 创建一个空子集，用于添加当前 mask 对应的元素
        List<Integer> subset = new ArrayList<>();

        // i 是 nums 的索引，同时决定查看 mask 的第几位
        for (int i = 0; i < n; i++) {
            // 用 1 << i 创建仅第 i 位为 1 的掩码，与 mask 进行 AND 运算取出第 i 位的值
            // 如果该位为 1 则表示"包含该元素"，为 0 则表示"不包含"，继续处理下一个 i
            if ((mask & (1 << i)) != 0) {
                subset.add(nums[i]);
            }
        }

        // 内层循环结束后，将完成的子集添加到结果列表中
        result.add(subset);
    }
    // 处理完所有 mask 后，返回包含 2^n 个子集的 result
    return result;
}
```
