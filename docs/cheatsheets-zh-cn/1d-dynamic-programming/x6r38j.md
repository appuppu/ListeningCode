# Counting Ways to Climb Stairs — 求解以每次1阶或2阶的方式爬n阶楼梯的总方法数

## 问题的本质

给定一个整数 `n`（楼梯的阶数）。每次可以爬1阶或2阶，返回到达顶部（第n阶）的**不同爬法的总数**。

## 核心思路

要到达第n阶，只能从「第n-1阶爬1阶」或「第n-2阶爬2阶」到达。也就是说，`ways(n) = ways(n-1) + ways(n-2)` 这一递推关系与斐波那契数列相同。只需保留前两个值，就可以不使用数组，以O(1)的空间完成计算。

## 思考过程

1. **从最后一步倒推**: 到达第n阶之前的状态只有「在第n-1阶」或「在第n-2阶」两种情况。因此，到达第n阶的爬法总数可以用递推公式 `ways(n) = ways(n-1) + ways(n-2)` 来表示
2. **确定基础情况**: 1阶楼梯有1种方式（爬1阶），2阶楼梯有2种方式（1+1 或 2）。这两个值是递推公式的起点
3. **自底向上计算**: 如果用递归从上往下计算，会重复求解相同的子问题。相反，采用从小到大依次计算的自底向上方式，每个值只需计算一次即可
4. **只需要2个变量**: 递推公式 `ways(i) = ways(i-1) + ways(i-2)` 只引用前两个值。不需要保留整个数组，只用2个变量（`prev2` 和 `prev1`）就足够了
5. **在循环中更新变量**: 从 `i = 3` 到 `n`，依次用 `curr = prev1 + prev2` 计算当前值，然后将 `prev2 = prev1`、`prev1 = curr` 进行滑动，为下一次迭代做准备
6. **最终返回值**: 循环结束后，`prev1` 中存储着第n阶的爬法总数，因此返回 `prev1`

## 前置知识

### 什么是动态规划（Dynamic Programming）

动态规划是一种将大问题分解为小的子问题，并在记录每个子问题结果的同时进行求解的方法。通过避免重复计算来提高效率。自底向上方式从最小的子问题开始依次求解。

```java
// 自底向上DP的基本模式（数组版）
int[] dp = new int[n + 1];   // 保存子问题结果的数组
dp[1] = 1;                    // 基础情况1
dp[2] = 2;                    // 基础情况2
for (int i = 3; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];  // 用递推公式计算
}
// dp[n] 就是最终答案
```

### 什么是滑动变量

滑动变量是一种只用2个变量代替数组来保留前值的技巧。当递推公式引用的历史值数量固定时，就不需要保留整个数组，可以将空间复杂度从O(n)降低到O(1)。

```java
int prev2 = 1;  // 保存前第2个值的变量
int prev1 = 2;  // 保存前第1个值的变量
int curr = prev1 + prev2;  // 计算当前值
prev2 = prev1;  // 滑动prev2（继承prev1的值）
prev1 = curr;   // 滑动prev1（继承curr的值）
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需从3到n循环一次即可 |
| Space | O(1) — 只使用2个变量（prev2, prev1） |

## 代码

```java
// 输入: 整数 n（楼梯的阶数）
// 输出: 以 int 形式返回到达顶部的不同爬法总数
public int climbStairs(int n) {
    // 基础情况: 1阶时只有1种方式。因为后续循环从 i=3 开始，所以先处理 n=1 的情况
    if (n == 1) return 1;

    // prev2是前第2阶的爬法总数。初始值对应第1阶的爬法（1种）
    int prev2 = 1;
    // prev1是前第1阶的爬法总数。初始值对应第2阶的爬法（2种: 1+1 或 2）
    int prev1 = 2;

    // i 是当前正在计算的阶数。第1阶和第2阶已作为初始值设定，所以从第3阶开始
    for (int i = 3; i <= n; i++) {
        // 递推公式: 第i阶的爬法 = 第(i-1)阶的爬法 + 第(i-2)阶的爬法
        int curr = prev1 + prev2;
        // 注意: 必须先更新prev2，否则prev1的原始值会丢失
        prev2 = prev1;
        prev1 = curr;
    }

    // 循环结束后，prev1 中存储着第n阶的爬法总数
    return prev1;
}
```
