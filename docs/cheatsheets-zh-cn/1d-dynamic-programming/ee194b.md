# Maximizing Robbery Loot in a Circular Neighborhood — 从环形排列的房屋中不相邻地偷取最大金额

## 问题的本质

给定一个非负整数数组 `nums`。每个元素表示环形排列的房屋中的金额。不能连续偷取相邻的两栋房屋。在**第一栋房屋与最后一栋房屋也相邻**的约束下，返回能偷取的最大金额。

## 核心思路

环形约束可以归结为"不能同时选择第一栋房屋和最后一栋房屋"。因此，将问题分为"包含第一栋房屋但排除最后一栋的范围"和"包含最后一栋房屋但排除第一栋的范围"两次求解线性版 House Robber，取较大值即可满足环形约束。

## 思考过程

1. **分解环形约束**: 在环形数组中，`nums[0]` 和 `nums[n-1]` 相邻。也就是说不能同时选择两者。这可以分解为两种情况："如果选择 `nums[0]`，则不能选择 `nums[n-1]`"和"如果选择 `nums[n-1]`，则不能选择 `nums[0]`"
2. **归结为两个线性问题**: 情况1在 `nums[0..n-2]`（包含第一栋，排除最后一栋）范围内求解，情况2在 `nums[1..n-1]`（排除第一栋，包含最后一栋）范围内求解，分别用线性版 House Robber 求解即可。两个结果中较大的一个就是答案
3. **建立线性版的递推公式**: 对于每栋房屋 `i`，有"偷取房屋 `i`"和"不偷取"两种选择。偷取时为 `nums[i] + dp[i-2]`（跳过前一栋），不偷取时为 `dp[i-1]`（直接继承前一栋为止的最大值）。因此 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
4. **将空间缩减为常数**: 递推公式只引用 `dp[i-1]` 和 `dp[i-2]` 两个值。无需保留整个DP数组，只需两个变量 `prev1`（前一个最大值）和 `prev2`（前两个最大值）即可完成计算
5. **处理边界情况**: 如果数组为空则返回0。如果只有一个元素，则环形约束不影响结果，直接返回该值。只有在元素数量为2个以上时才进行两趟处理
6. **最终返回值**: 对两个范围分别得到的最大金额，用 `Math.max` 选择较大的一个返回

## 前置知识

### 什么是 House Robber（线性版）

从一排房屋中，在不连续选择相邻房屋的条件下获取最大金额的问题。这是DP的基础问题，可以用递推公式 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` 求解。本环形版通过两次应用线性版来求解。

### 通过滚动变量优化DP空间

只将递推公式引用的最近几个值作为变量保留的方法。无需保留整个数组，可以将空间复杂度从O(n)缩减到O(1)。

```java
int prev2 = 0, prev1 = 0;        // 初始化相当于dp[i-2]和dp[i-1]的变量
int curr = Math.max(prev1, prev2 + nums[i]);  // 计算dp[i]
prev2 = prev1;                    // 将prev2前移一步（旧的prev1变为新的prev2）
prev1 = curr;                     // 将prev1前移一步（curr变为新的prev1）
```

### 什么是 Math.max

返回两个值中较大值的Java标准方法。在DP转移中用于选择"偷取的情况"和"不偷取的情况"的最大值。

```java
Math.max(5, 3);   // → 5（返回较大的值）
Math.max(prev1, prev2 + nums[i]);  // 选择不偷取和偷取两种情况的最大值
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 虽然遍历数组两次，但每次遍历都是O(n)，因此总体为O(n) |
| Space | O(1) — 不使用DP数组，仅用两个滚动变量进行计算 |

## 代码

```java
// 输入: 非负整数数组 nums（环形排列的每栋房屋的金额）
// 输出: 以 int 形式返回在不连续偷取相邻房屋的条件下能获得的最大金额

// 对指定范围（start～end）求解线性版House Robber的辅助方法
private int robRange(int[] nums, int start, int end) {
    // 初始化为0，因为不偷取任何房屋时的金额为0
    int prev2 = 0, prev1 = 0;  // 保存前两个和前一个最大金额的滚动变量
    // 从指定范围的起始位置到末尾逐个遍历
    for (int i = start; i <= end; i++) {
        // prev1: 不偷取房屋i，继承前一栋为止的最大值的选项
        // prev2 + nums[i]: 偷取房屋i，将当前金额加到前两栋为止的最大值上的选项
        int curr = Math.max(prev1,
            prev2 + nums[i]);
        // 将滚动变量前移一步（在下一次迭代中，curr充当prev1，prev1充当prev2）
        prev2 = prev1;
        prev1 = curr;
    }
    // prev1 中存储了考虑整个指定范围后的最大金额
    return prev1;
}

public int rob(int[] nums) {
    int n = nums.length;
    if (n == 0) return 0;        // 如果没有房屋则返回0
    if (n == 1) return nums[0];  // 如果只有一栋房屋，则不存在相邻约束，该值即为答案

    // 将环形约束分解为两个线性问题，返回较大的一个
    // 由于保证了不会同时选择第一栋和最后一栋房屋，因此满足环形约束
    return Math.max(
        robRange(nums, 0, n - 2),   // 包含第一栋房屋但排除最后一栋的范围（索引0到n-2）
        robRange(nums, 1, n - 1));  // 排除第一栋房屋但包含最后一栋的范围（索引1到n-1）
}
```
