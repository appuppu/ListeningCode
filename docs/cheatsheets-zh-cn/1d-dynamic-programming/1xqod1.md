# Counting All Palindromic Substrings — 计算字符串中所有回文子串的总数

## 问题的本质

给定一个字符串 `s`。在 `s` 的所有子串中，返回属于回文（正读和反读相同的字符串）的子串的**总数**。每个单字符子串也计为回文。

## 核心思路

每个回文都存在一个「中心」。固定中心并向左右两侧扩展，就能枚举出从该中心产生的所有回文。中心的候选仅有每个字符（奇数长度）和相邻两个字符之间（偶数长度）共 2n-1 个，因此可以进行全量搜索。

## 思考过程

1. **关注回文的结构性质**: 所有回文关于中心左右对称。奇数长度的回文以1个字符为中心，偶数长度的回文以相邻的2个字符为中心。利用这一性质，可以从中心出发高效地发现回文
2. **从中心向外侧扩展**: 对于某个中心，设置左右指针 `left` 和 `right`，只要 `s.charAt(left) == s.charAt(right)` 就向外侧扩展。每次扩展成功就发现了一个新的回文，因此将计数加1
3. **分别处理奇数长度和偶数长度**: 对于每个索引 `i`，用 `expand(s, i, i)` 计算奇数长度的回文数量，用 `expand(s, i, i+1)` 计算偶数长度的回文数量。通过这两次调用，可以覆盖以 `i` 为中心的所有回文
4. **确定扩展的停止条件**: 当 `left` 小于0、`right` 大于等于字符串长度、或左右字符不一致时，停止扩展。这样既能防止越界访问，又能实现最大限度的扩展
5. **汇总每个中心的结果**: 将所有索引的奇数长度和偶数长度回文数量相加，所得之和即为整个字符串中回文子串的总数
6. **最终返回值**: 将从所有中心获得的回文数量之和作为整数 `result` 返回

## 前置知识

### 回文（Palindrome）

正读和反读相同的字符串。`"aba"`、`"abba"`、`"a"` 都是回文。回文分为奇数长度（中心为1个字符）和偶数长度（中心在2个字符之间）两种类型。

```
奇数长度示例: "aba"  → 中心是 'b'
偶数长度示例: "abba" → 中心在 'b' 和 'b' 之间
```

### 中心扩展法（Expand Around Center）

固定回文的中心，逐次向左右各扩展一个字符来判断是否为回文的方法。从中心向外侧扩展，只要字符一致就继续扩展，一旦不一致就停止。

```
字符串: "abacd"
从中心 i=1 ('b') 开始扩展:
  left=1, right=1 → 'b'=='b' → 发现回文 "b"，count=1
  left=0, right=2 → 'a'=='a' → 发现回文 "aba"，count=2
  left=-1 → 超出范围，停止
```

### String.charAt(int index)

返回字符串中指定索引位置的字符的方法。索引从0开始。

```java
String s = "abc";
s.charAt(0);    // 返回 'a'
s.charAt(2);    // 返回 'c'
s.length();     // 返回字符串的长度 → 3
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n²) — 对每个中心（n个）最多执行 O(n) 的扩展 |
| Space | O(1) — 仅使用指针和计数器，不使用额外的数据结构 |

## 代码

```java
// 输入: 字符串 s
// 输出: 以整数形式返回 s 中回文子串的总数

// 从指定的中心向左右扩展，返回发现的回文数量
// left 和 right 相同时探索奇数长度的回文，相邻时探索偶数长度的回文
int expand(String s, int left, int right) {
    int count = 0;
    // 同时满足3个条件时继续扩展: 左端在范围内、右端在范围内、左右字符一致
    while (left >= 0 && right < s.length()
            && s.charAt(left) == s.charAt(right)) {
        count++;   // s.substring(left, right+1) 是新的回文，计数加1
        left--;    // 向左扩展1位
        right++;   // 向右扩展1位
    }
    // 返回从该中心发现的回文总数
    return count;
}

int countSubstrings(String s) {
    // 累计从所有中心发现的回文数量的变量
    int result = 0;

    // 将每个索引作为中心候选进行遍历
    for (int i = 0; i < s.length(); i++) {
        // 奇数长度的回文: left=i, right=i，从1个字符的中心开始扩展
        result += expand(s, i, i);
        // 偶数长度的回文: left=i, right=i+1，从相邻2个字符的中心开始扩展
        result += expand(s, i, i + 1);
    }
    // 返回从所有中心获得的回文数量之和
    return result;
}
```
