# Counting Ways to Decode a Numeric String — 求解将数字字符串转换为字母的总方法数

## 问题的本质

给定一个仅由数字组成的字符串 `s`。根据 A=1, B=2, ..., Z=26 的对应关系，返回将字符串解码为字母序列的方法总数。例如 "226" 可以解码为 "BZ"(2,26)、"VF"(22,6)、"BBF"(2,2,6) 共3种方式。

## 核心思路

每个位置的解码方法数等于"解码1个字符（1位数）后剩余部分的方法数"与"解码1个字符（2位数）后剩余部分的方法数"之和。由于这种依赖关系仅限于前两个结果，因此只需2个变量即可。

## 思考过程

1. **每个位置最多有2种选择**: 查看位置 `i` 的数字时，最多有两种选择：将其作为1位数（1〜9）解码为1个字母，或将其作为2位数（10〜26）解码为1个字母。由于这种选择会递归发生，因此需要系统地求解每个位置的解码方法数
2. **'0' 无法单独解码**: 不存在与 '0' 对应的字母。如果位置 `i` 的数字是 '0'，则从该位置开始的1位数解码不可能，方法数为0。'0' 只能与前一个数字组合，作为10或20来解码
3. **建立DP递推公式**: 将 `dp[i]` 定义为"从位置 `i` 到末尾的解码方法数"。如果位置 `i` 的数字不是 '0'，则加上1位数解码后剩余部分的 `dp[i+1]`。此外，如果位置 `i` 和 `i+1` 组成的2位数在10〜26的范围内，则还要加上2位数解码后剩余部分的 `dp[i+2]`。即 `dp[i] = dp[i+1] + dp[i+2]`（有条件）
4. **依赖项仅为紧随其后的2个**: `dp[i]` 仅依赖于 `dp[i+1]` 和 `dp[i+2]`。因此不需要维护整个数组，只需2个变量（`next1` = `dp[i+1]`、`next2` = `dp[i+2]`）即可完成计算。由此实现 Space O(1)
5. **从末尾向开头遍历**: 由于 `dp[i]` 依赖于 `dp[i+1]` 和 `dp[i+2]`，末尾侧需要先确定。因此从字符串的末尾向开头循环，计算每个位置的方法数
6. **最终返回值**: 循环完成后，`next1` 中存储的是 `dp[0]`（整个字符串的解码方法数）。返回该值

## 前置知识

### 什么是动态规划（DP）

动态规划是一种将大问题分解为小的子问题，并重用子问题的结果来求解整体答案的方法。为了避免对相同的子问题进行重复计算，将已计算的结果进行保存（记忆化）或按顺序计算（自底向上）。

```java
// 自底向上DP的典型模式：斐波那契数列
int prev2 = 0, prev1 = 1;
for (int i = 2; i <= n; i++) {
    int current = prev1 + prev2;  // 仅用前两个结果计算当前值
    prev2 = prev1;                // 滑动变量以准备下一次迭代
    prev1 = current;
}
// prev1 中存储着最终结果
```

### 什么是 Integer.parseInt

Integer.parseInt 是将字符串转换为整数的方法。用于将子字符串作为数值进行评估。

```java
Integer.parseInt("26");          // 将字符串"26"转换为整数26 → 26
Integer.parseInt("09");          // 将字符串"09"转换为整数9 → 9
```

### 什么是 String.substring

String.substring 是从字符串中获取指定范围子字符串的方法。参数为起始索引（包含）和结束索引（不包含）。

```java
String s = "226";
s.substring(0, 2);   // 返回从索引0到1的子字符串 → "22"
s.substring(1, 3);   // 返回从索引1到2的子字符串 → "26"
```

### 什么是 String.charAt

String.charAt 是返回字符串中指定位置的单个字符的方法。由于返回 char 类型，可以通过与字符 '0' 比较来判断数字。

```java
String s = "206";
s.charAt(0);          // 返回索引0处的字符 → '2'
s.charAt(1);          // 返回索引1处的字符 → '0'
s.charAt(1) == '0';   // 判断字符是否为'0' → true
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需从末尾到开头遍历字符串一次 |
| Space | O(1) — 仅用2个变量（next1, next2）即可计算，无需使用数组 |

## 代码

```java
// 输入: 仅由数字组成的字符串 s
// 输出: 以 int 返回将字符串 s 解码为字母序列的方法总数
public int numDecodings(String s) {
    // next1 = 右侧1个位置开始的方法数（dp[i+1]），next2 = 右侧2个位置开始的方法数（dp[i+2]）
    // 字符串末尾的右侧定义为"解码空字符串的方法 = 1种"，因此初始值为1
    int next1 = 1, next2 = 1;

    // 由于dp[i]依赖于dp[i+1]和dp[i+2]，为了先确定右侧的值，从末尾向开头遍历
    for (int i = s.length() - 1; i >= 0; i--) {
        int current;

        if (s.charAt(i) == '0') {
            // '0'不对应任何字母，因此从该位置开始的解码方法数为0
            // '0'只能与前一个数字组合，作为10或20来解码
            current = 0;
        } else {
            // 1位数解码: 将位置i的数字（1〜9）作为1个字母，剩余i+1之后有next1种方法
            current = next1;

            // 判断是否可以进行2位数解码（如果i+1在字符串范围内，则可以获取2位数）
            if (i + 1 < s.length()) {
                // 用s.substring(i, i+2)获取2位数的子字符串，并转换为整数
                int two = Integer.parseInt(
                    s.substring(i, i + 2));
                // 如果2位数在10〜26的范围内，则将其作为1个字母解码，加上i+2之后的next2种方法
                if (two >= 10 && two <= 26)
                    current += next2;
            }
        }

        // 将变量向左滑动1位: 当前的current在下一次迭代中成为next1（右侧1个位置）
        next2 = next1;
        next1 = current;
    }

    // 循环完成后，next1中存储的是最后计算的current（= dp[0]）
    // 这就是整个字符串的解码方法总数
    return next1;
}
```
