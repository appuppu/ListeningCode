# Maximizing Robbery Loot Without Adjacent Houses — 求在不盗窃相邻房屋的条件下可盗取的最大金额

## 问题的本质

给定一个整数数组 `nums`，每个元素表示沿街每栋房屋中的金额。在不能同时盗窃相邻两栋房屋的约束下，返回一晚能盗取的**最大金额**。如果盗窃了房屋 `i`，则不能盗窃房屋 `i-1` 和房屋 `i+1`。

## 核心思路

对于每栋房屋，存在"盗窃或不盗窃"两种选择。如果选择盗窃，则将当前金额加上前两栋房屋为止的最大值；如果选择不盗窃，则直接继承前一栋房屋为止的最大值。由于做出此判断只需要前两个值，因此无需使用数组，仅用两个变量即可完成计算。

## 思考过程

1. **需要对每栋房屋做出"盗窃/不盗窃"的最优判断**：如果盗窃房屋 `i`，则不能盗窃房屋 `i-1`，因此可以获得房屋 `i-2` 为止的最大值加上 `nums[i]` 的值。如果不盗窃，则房屋 `i-1` 为止的最大值保持不变。也就是说，每栋房屋的最大值可以表示为 `max(房屋i-1为止的最大值, 房屋i-2为止的最大值 + nums[i])`
2. **可以建立递推公式**：通过递推公式 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，可以从头开始依次计算到每栋房屋为止的最大金额。这是典型的动态规划结构
3. **所需信息仅为前两个值**：观察递推公式可知，计算 `dp[i]` 只用到 `dp[i-1]` 和 `dp[i-2]` 两个值。无需保存整个数组，两个变量（`prev1` 和 `prev2`）就足够了
4. **考虑变量的更新顺序**：计算出 `curr` 之后，在下一次迭代中，当前的 `prev1` 变为新的 `prev2`，`curr` 变为新的 `prev1`。按此顺序更新可以避免值被覆盖
5. **设置初始值**：在遍历开始前，将 `prev1 = 0`（前一栋房屋为止的最大值）和 `prev2 = 0`（前两栋房屋为止的最大值）。当房屋数为0时结果为0，处理第1栋房屋时 `max(0, 0 + nums[0]) = nums[0]`，结果正确
6. **最终返回值**：遍历完所有房屋后的 `prev1` 即为整体的最大金额

## 前置知识

### 什么是动态规划（Dynamic Programming）

动态规划是一种将大问题分解为小的子问题，并通过复用各子问题的解来构建整体解的方法。当存在重叠子问题时，可以避免重复计算。在本问题中，"到房屋 `i` 为止的最大金额"就是子问题。

### 什么是 Math.max

Math.max 是 Java 的标准方法，用于返回两个值中较大的一个。可以用一行代码替代条件分支。

```java
Math.max(5, 3);    // → 5（返回较大的值）
Math.max(prev1, prev2 + num);  // 返回 prev1 和 prev2+num 中较大的值
```

### 什么是增强for循环（for-each）

增强for循环是一种从数组的第一个元素开始，依次逐个取出并处理的循环语法。它不使用索引，而是直接访问元素。

```java
int[] nums = {2, 7, 9, 3};
for (int num : nums) {   // 将 nums 的每个元素依次赋值给 num 并循环
    System.out.println(num);  // 依次输出 2, 7, 9, 3
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历数组一次 |
| Space | O(1) — 仅使用两个变量，不依赖于输入规模 |

## 代码

```java
// 输入：整数数组 nums（每栋房屋的金额）
// 输出：在不盗窃相邻房屋的约束下，以 int 类型返回可盗取的最大金额
public int rob(int[] nums) {
    // prev2：到前两栋房屋为止的最大金额。遍历开始前不存在房屋，因此为0
    int prev2 = 0;
    // prev1：到前一栋房屋为止的最大金额。同样，遍历开始前为0
    int prev1 = 0;

    // 使用增强for循环从头到尾逐个遍历数组 nums 的每个元素
    for (int num : nums) {
        // 选择"不盗窃当前房屋的情况(prev1)"和"盗窃当前房屋的情况(prev2+num)"中较大的值
        // 盗窃当前房屋时使用 prev2，是因为不能盗窃相邻的 prev1 对应的房屋
        int curr = Math.max(prev1,
            prev2 + num);
        // 为下一次迭代滑动变量
        // 当前的 prev1（前一栋房屋的最大值）在下一次迭代中变为前两栋房屋的最大值
        prev2 = prev1;
        // 刚计算出的 curr（到当前房屋为止的最大值）在下一次迭代中变为前一栋房屋的最大值
        // 注意：此更新必须在 prev2 = prev1 之后执行。如果先更新 prev1，则无法将正确的值赋给 prev2
        prev1 = curr;
    }
    // 返回考虑了所有房屋后的最大金额。prev1 中存储着考虑到最后一栋房屋为止的最大金额
    return prev1;
}
```
