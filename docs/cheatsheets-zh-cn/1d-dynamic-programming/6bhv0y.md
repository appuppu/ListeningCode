# Finding the Longest Palindromic Substring — 查找字符串中最长的回文子串

## 问题的本质

给定一个字符串 `s`。从 `s` 中找出正读和反读都相同的**最长子串（回文）**并返回。如果存在多个长度相同的回文，返回其中任意一个即可。

## 核心思路

回文必定拥有一个"中心"。以字符串的每个位置为中心向左右两侧展开，只要字符匹配就继续扩展回文，这样可以不遗漏地发现所有回文。中心需要尝试"1个字符（奇数长度）"和"相邻2个字符之间（偶数长度）"两种类型。

## 思考过程

1. **回文具有从中心对称展开的结构**: 回文 `"racecar"` 从中心的 `e` 向左右对称地展开为 `c→a→r`。利用这个性质，可以固定中心并向左右展开来检测回文
2. **中心的候选有2种类型**: 奇数长度的回文（例: `"aba"`）以1个字符为中心，偶数长度的回文（例: `"abba"`）以相邻2个字符之间为中心。要不遗漏地检测所有回文，需要尝试两种中心
3. **确定展开的步骤**: 从中心分别放置左指针 `left` 和右指针 `right`，只要 `s.charAt(left) == s.charAt(right)` 成立，就将 `left` 向左、`right` 向右各移动一位。当字符不匹配或到达字符串边界时，停止展开
4. **根据展开结果计算回文的长度**: 展开结束时，`left` 和 `right` 分别超出了回文范围一个位置。因此，回文的长度可以用 `right - left - 1` 来计算
5. **记录最长回文的起始和结束位置**: 当从某个中心得到的回文长度超过当前最长记录时，更新起始位置 `start` 和结束位置 `end`。根据中心位置 `i` 和回文长度 `len`，可以用 `start = i - (len - 1) / 2`、`end = i + len / 2` 来计算
6. **最终返回子串**: 尝试完所有中心后，用 `s.substring(start, end + 1)` 截取最长回文子串并返回

## 前置知识

### 什么是回文（Palindrome）

回文是指正读和反读都相同的字符串。`"aba"`、`"abba"`、`"racecar"` 都是回文。单个字符的字符串也是回文。

### 什么是中心展开法（Expand Around Center）

中心展开法是一种固定回文的中心，逐步向左右各扩展一个字符来判断是否为回文的方法。由于是从中心向外侧比较字符，因此可以高效地检测回文。

```java
// left=right 时检测奇数长度的回文（1个字符为中心）
// left=i, right=i+1 时检测偶数长度的回文（2个字符为中心）
expand(s, 2, 2);    // 查找以索引2为中心的奇数长度回文
expand(s, 2, 3);    // 查找以索引2和3之间为中心的偶数长度回文
```

### 什么是 String.substring(int, int)

该方法用于从字符串中截取子串。第1个参数是起始索引（包含），第2个参数是结束索引（不包含）。

```java
String s = "babad";
s.substring(0, 3);   // 返回 "bab"（索引0, 1, 2处的字符）
s.substring(1, 4);   // 返回 "aba"（索引1, 2, 3处的字符）
```

### 什么是 String.charAt(int)

该方法返回字符串中指定索引处的字符。

```java
String s = "babad";
s.charAt(0);   // 返回 'b'
s.charAt(2);   // 返回 'b'
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n²) — 以每个索引为中心进行最多O(n)的展开，共有n个中心 |
| Space | O(1) — 仅使用记录指针和长度的变量，不需要额外的数据结构 |

## 代码

```java
// 输入: 字符串 s
// 输出: 以 String 形式返回 s 中最长的回文子串

// 从中心向左右展开并返回回文长度的辅助方法
private int expand(String s, int left, int right) {
    // 只要左右字符一致且在字符串范围内，就继续展开
    while (left >= 0
            && right < s.length()
            && s.charAt(left)
            == s.charAt(right)) {
        left--;  // 向左扩展一位
        right++; // 向右扩展一位
    }
    // 展开结束时，left和right分别超出了回文范围一个位置
    // 因此回文的长度为 right - left - 1
    return right - left - 1;
}

public String longestPalindrome(String s) {
    // 记录最长回文的起始和结束索引的变量
    // 初始值0对应于至少第1个字符本身就是长度为1的回文
    int start = 0, end = 0;

    // 以每个索引 i 作为回文的中心候选进行遍历
    for (int i = 0; i < s.length(); i++) {
        // 展开奇数长度的回文（1个字符为中心）并获取长度
        int odd = expand(s, i, i);
        // 展开偶数长度的回文（2个字符为中心）并获取长度
        int even = expand(s, i, i + 1);
        // 取奇数长度和偶数长度中较大的值
        int len = Math.max(odd, even);

        // 如果超过当前最长回文的长度 (end - start + 1)，则更新起始和结束位置
        if (len > end - start + 1) {
            // (len - 1) / 2 是从中心到左侧的距离
            start = i - (len - 1) / 2;
            // len / 2 是从中心到右侧的距离
            end = i + len / 2;
        }
    }
    // substring的第2个参数是"不包含"的规范，因此指定 end + 1 以包含 end 处的字符
    return s.substring(start, end + 1);
}
```
