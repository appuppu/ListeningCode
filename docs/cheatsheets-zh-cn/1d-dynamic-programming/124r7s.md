# Partitioning an Array Into Two Equal Sum Subsets — 判定能否将数组分割为两个元素之和相等的子集

## 问题的本质

给定一个整数数组 `nums`。判定能否将该数组分割为两个子集，使得两个子集的元素之和相等，并以 `boolean` 返回结果。每个元素必须且只能属于其中一个子集，不能重复使用。

## 核心思路

如果数组的总和为奇数，则可以立即判定为false。如果总和为偶数，则问题可以归约为"子集和问题"：是否存在一个子集，其元素之和恰好等于总和的一半 `target`。使用一维boolean型DP数组，依次处理每个元素并记录可达的总和值，即可在O(n × target)的时间内判定能否达到 `target`。

## 思考过程

1. **思考二等分的条件**：当数组所有元素的总和为 `sum` 时，要使两个子集的元素之和相等，每个子集的元素之和必须为 `sum / 2`。如果 `sum` 为奇数，则无法整除为二等分，因此可以立即返回false
2. **将问题转化为"子集和问题"**：只要其中一个子集的元素之和等于 `target = sum / 2`，另一个子集的元素之和也自动等于 `target`。也就是说，问题可以归约为"是否存在数组元素的一个子集，使其元素之和等于 `target`"这一子集和问题
3. **用DP管理可达的总和值**：准备一个boolean型数组 `dp`，其中 `dp[j]` 表示"用已处理的元素能否构成总和 `j`"。初始状态设为 `dp[0] = true`（不选任何元素时总和为0）
4. **用每个元素更新可达的总和值**：对于数组中的每个元素 `num`，如果已经可以达到总和 `j`，则加上 `num` 后的 `j + num` 也变为可达。即当 `dp[j]` 为true时，将 `dp[j + num]` 也设为true
5. **逆序遍历以防止重复使用同一元素**：内层循环从 `target` 到 `num` 进行逆序遍历。如果正序遍历，`dp` 会被同一元素多次使用的结果所更新。逆序遍历可以保证每个元素最多只被使用一次
6. **最终返回 `dp[target]`**：处理完所有元素后，如果 `dp[target]` 为true，则存在总和为 `target` 的子集，因此返回true；否则不存在这样的子集，返回false

## 前置知识

### 什么是子集和问题（Subset Sum Problem）

子集和问题是指：从给定的整数集合中选取若干元素，判定其总和能否恰好等于目标值。这是一个可以用DP（动态规划）高效求解的经典问题。

### 什么是boolean型一维DP数组

`dp[j]` 用true/false表示"能否构成总和 `j`"的数组。每处理一个元素，可达的总和值集合就会相应扩展。

```java
boolean[] dp = new boolean[target + 1];  // 创建大小为 target+1 的数组（初始值全部为false）
dp[0] = true;                            // 不选任何元素时，总和0始终可达
dp[j - num] == true                      // 如果能构成总和 j-num，则加上 num 后也能构成总和 j
```

### 逆序更新DP数组的原因

如果正序（从小的 `j` 到大的 `j`）更新，同一元素 `num` 被多次使用的结果会发生传播。如果逆序（从大的 `j` 到小的 `j`）更新，则可以保证每个元素只被使用一次。

```java
// 逆序循环: j 从 target 到 num 每次递减1
for (int j = target; j >= num; j--) {
    if (dp[j - num]) dp[j] = true;
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n × target) — 对n个元素中的每一个，遍历最大到target的DP数组 |
| Space | O(target) — 使用一个大小为 target+1 的boolean型DP数组 |

## 代码

```java
// 输入: 整数数组 nums
// 输出: 以 boolean 返回能否将数组分割为两个元素之和相等的子集
boolean canPartition(int[] nums) {
    // 计算数组所有元素的总和，作为判断能否二等分的基准值
    int sum = 0;
    for (int n : nums) sum += n;

    // 如果总和为奇数，则无法整除为二等分，返回false
    if (sum % 2 != 0) return false;

    // 其中一个子集需要达到的目标总和值。另一个子集的总和也自动等于target
    int target = sum / 2;

    // dp[j] = 用已处理的元素能否构成总和j（子集和问题的DP数组）
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;  // 不选任何元素时，总和0始终可达

    // 从头到尾依次处理数组中的每个元素，更新可达的总和值集合
    for (int num : nums) {
        // 逆序遍历以防止同一元素被重复使用（正序遍历会导致num被多次累加的结果发生传播）
        for (int j = target; j >= num; j--) {
            // 如果能构成总和 j-num，则加上 num 后也能构成总和 j，因此更新为true
            if (dp[j - num]) dp[j] = true;
        }
    }

    // 如果 dp[target] 为true，则存在总和为target的子集，因此可以二等分
    return dp[target];
}
```
