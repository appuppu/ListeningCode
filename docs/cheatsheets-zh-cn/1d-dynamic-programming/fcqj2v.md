# Finding the Fewest Coins to Make a Target Amount — 用最少硬币凑出目标金额

## 问题的本质

给定一个包含硬币面额的数组 `coins` 和一个目标金额 `amount`。可以无限次使用 `coins` 中的硬币，在所有使总和等于 `amount` 的组合中，返回所需的**最少硬币数**。如果无论如何组合都无法凑出 `amount`，则返回 `-1`。

## 核心思路

从金额0到目标金额，自底向上计算"凑出每个金额所需的最少硬币数"。金额 `i` 的最少硬币数等于"从 `i` 中减去各硬币面额后对应金额的最少硬币数 + 1"中的最小值。

## 思考过程

1. **可以分解为子问题**：假设凑出金额 `i` 时最后使用的一枚硬币是 `c`，如果已知凑出剩余金额 `i - c` 的最少硬币数，就可以通过 `dp[i - c] + 1` 求出金额 `i` 的最少硬币数。这种结构适合使用动态规划来解决
2. **事先无法确定最后一枚硬币是哪个**：最后一枚硬币的候选是所有硬币面额。因此，对所有硬币 `c` 计算 `dp[i - c] + 1`，并取其最小值作为 `dp[i]`。这就是状态转移方程 `dp[i] = min(dp[i - c] + 1)` for each coin `c`
3. **确定基础情况**：凑出金额0所需的硬币数为0枚，因此设 `dp[0] = 0`。这是自底向上计算的起点
4. **将初始值设为表示"不可达"的值**：由于事先无法知道每个金额是否能够凑出，所以将 `dp` 数组的所有元素初始化为 `amount + 1`（一个不可能达到的大数）。未被更新的金额意味着"无法凑出"
5. **从金额1开始依次填表**：以 `dp[0]` 为起点，按金额1, 2, ..., `amount` 的顺序填写表格。在计算金额 `i` 时，所有小于 `i` 的金额的最少硬币数已经确定，因此可以安全地引用 `dp[i - c]`
6. **最终返回值**：如果 `dp[amount]` 仍为 `amount + 1`，说明无法凑出目标金额，返回 `-1`。否则 `dp[amount]` 即为最少硬币数

## 前置知识

### 什么是动态规划（Dynamic Programming）

动态规划是一种将大问题分解为小的子问题，并将每个子问题的解记录在表格中，自底向上构建最终解的方法。由于避免了重复求解相同的子问题，因此计算效率很高。

```java
// 自底向上DP的基本模式
int[] dp = new int[n + 1];     // 创建表格
dp[0] = baseCase;              // 设置基础情况
for (int i = 1; i <= n; i++) { // 从小的子问题开始依次求解
    dp[i] = /* 利用 dp[i-1] 等已有结果进行计算 */;
}
return dp[n];                  // 返回最终答案
```

### 什么是 Arrays.fill

Arrays.fill 是Java的标准方法，用于将数组的所有元素填充为指定值。常用于DP数组的初始化。

```java
int[] dp = new int[5];       // 创建 [0, 0, 0, 0, 0]
Arrays.fill(dp, 100);        // 将所有元素填充为100 → [100, 100, 100, 100, 100]
```

### 什么是 Math.min

Math.min 是Java的标准方法，用于返回两个整数中较小的一个。在从多个候选值中选取最小值时使用。

```java
Math.min(3, 7);    // → 3
Math.min(dp[i], dp[i - coin] + 1);  // 在当前值和新候选值中选取较小的一个
```

## 复杂度

| | 值 |
|---|---|
| Time | O(amount × n) — 对每个金额遍历n种硬币（n为coins数组的长度） |
| Space | O(amount) — dp数组存储amount+1个元素 |

## 代码

```java
// 输入：包含硬币面额的整数数组 coins 和目标金额的整数 amount
// 输出：返回凑出总和为 amount 的最少硬币数（int类型）。无法凑出时返回 -1
int coinChange(int[] coins, int amount) {
    // dp[i] = 凑出金额i所需的最少硬币数
    // 为了对应从索引0到amount的每个金额，数组大小为 amount + 1
    int[] dp = new int[amount + 1];

    // 将所有元素初始化为表示"不可达"的哨兵值
    // 由于硬币面额最小为1，所以硬币数不可能超过 amount 枚，若该值未被更新则可判定为"无法凑出"
    Arrays.fill(dp, amount + 1);

    // 基础情况：凑出金额0所需的硬币数为0枚。这是自底向上计算的起点
    dp[0] = 0;

    // 从金额1到amount依次填写表格
    // 通过从小金额开始计算，保证 dp[i - coin] 已经确定
    for (int i = 1; i <= amount; i++) {
        // 将每枚硬币作为"凑出金额i的最后一枚"的候选，从所有面额中寻找最优选择
        for (int coin : coins) {
            // 如果 coin > i，则该硬币无法用于凑出金额i，跳过
            if (coin <= i)
                // dp[i - coin] + 1 表示"金额 i - coin 的最少硬币数再加上1枚硬币"
                // 与当前的 dp[i] 比较，取较小值
                dp[i] = Math.min(dp[i],
                    dp[i - coin] + 1);
        }
    }

    // 如果仍为哨兵值，说明初始值未被更新＝无法凑出目标金额，返回 -1
    return dp[amount] > amount
        ? -1 : dp[amount];
}
```
