# Finding the Longest Increasing Subsequence — 求最长严格递增子序列的长度

## 问题本质

给定一个整数数组 `nums`。从原数组中删除若干元素（不改变顺序）所能构成的**严格递增子序列**中，返回最长子序列的长度。子序列不需要连续，但必须保持元素在原数组中的相对顺序。

## 核心思路

"长度为 `k` 的递增子序列的末尾元素越小，后续元素能够延伸该子序列的可能性就越大"。用数组 `tails` 管理每种长度对应的末尾元素最小值，就可以通过二分查找在 O(log n) 内确定新元素的插入位置，从而在整体 O(n log n) 内求解。

## 思考过程

1. **末尾越小越有利于延伸递增子序列**：当存在多个长度相同的递增子序列时，末尾元素最小的那个"能够衔接的值的范围"最广。因此，只记录每种长度对应的末尾元素最小值就足够了
2. **用 tails 数组管理末尾最小值**：准备一个数组 `tails`，在 `tails[i]` 中保存"长度为 `i+1` 的递增子序列所能拥有的末尾元素最小值"。该数组始终保持有序状态（因为子序列越长，末尾元素越大）
3. **新元素的处理分为两种情况**：对于数组中的每个元素 `num`，通过二分查找在 `tails` 中找到大于等于 `num` 的最小元素。如果找到的位置超出 `tails` 的末尾，说明 `num` 大于现有最长子序列的末尾，将 `num` 追加到 `tails` 末尾。如果没有超出末尾，则用 `num` 替换该位置的值以更新末尾最小值
4. **可以使用二分查找的原因**：由于 `tails` 数组始终保持有序，可以用 `Collections.binarySearch` 在 O(log n) 内确定 `num` 的插入位置。这使得每个元素的处理为 O(log n)，整体达到 O(n log n)
5. **tails 数组的长度即为答案**：在处理每个元素时，`tails` 只会发生追加或替换操作。追加意味着最长子序列的长度增加了 1。当所有元素处理完毕时，`tails.size()` 就是最长递增子序列的长度

## 前置知识

### 什么是 ArrayList

ArrayList 是可变长度的数组。元素的添加、获取和更新均为 O(1)。与普通数组不同，ArrayList 不需要事先确定大小。

```java
List<Integer> list = new ArrayList<>();  // 创建一个空的 ArrayList
list.add(10);          // 在末尾添加 10 → [10]
list.add(20);          // 在末尾添加 20 → [10, 20]
list.get(0);           // 获取索引 0 处的元素 → 10
list.set(0, 5);        // 将索引 0 处的元素替换为 5 → [5, 20]
list.size();           // 返回元素个数 → 2
```

### 什么是 Collections.binarySearch

Collections.binarySearch 是对有序列表执行二分查找并返回指定值位置的方法。如果找到该值，则返回其索引。如果未找到，则返回 `-(插入位置) - 1` 这样的负值。插入位置是指将该值插入列表后仍能保持排序顺序的位置。

```java
List<Integer> list = Arrays.asList(2, 5, 8, 12);
Collections.binarySearch(list, 5);   // 5 位于索引 1 → 返回 1
Collections.binarySearch(list, 6);   // 6 不存在。插入位置为 2 → -(2)-1 = -3，返回 -3
Collections.binarySearch(list, 1);   // 1 不存在。插入位置为 0 → -(0)-1 = -1，返回 -1
Collections.binarySearch(list, 15);  // 15 不存在。插入位置为 4 → -(4)-1 = -5，返回 -5
```

从负返回值恢复插入位置的方法是计算 `-(返回值 + 1)`。例如：返回值为 -3 时，`-(-3 + 1) = 2` 即为插入位置。

### tails 数组的概念

`tails` 是记录"每种长度的递增子序列的末尾元素最小值"的数组。`tails[i]` 表示"长度为 `i+1` 的递增子序列所能取到的末尾最小值"。该数组始终维持升序排列的状态。

例如：处理 nums = [3, 1, 4, 1, 5] 的过程：
- 处理 3 → tails = [3]（长度为 1 的子序列的末尾最小值为 3）
- 处理 1 → tails = [1]（将长度为 1 的末尾最小值更新为 1。1 比 3 小，更有利）
- 处理 4 → tails = [1, 4]（4 大于 1，追加到末尾。形成了长度为 2 的子序列）
- 处理 1 → tails = [1, 4]（1 的插入位置为索引 0，已经是 1，所以无变化）
- 处理 5 → tails = [1, 4, 5]（5 大于 4，追加到末尾。形成了长度为 3 的子序列）

最终 `tails.size()` = 3 即为答案。

## 复杂度

| | 值 |
|---|---|
| Time | O(n log n) — 对 n 个元素分别执行 O(log n) 的二分查找 |
| Space | O(n) — tails 数组最多保存 n 个元素 |

## 代码

```java
// 输入：整数数组 nums
// 输出：以 int 类型返回最长严格递增子序列的长度
public int lengthOfLIS(int[] nums) {
    // 按升序保存各长度递增子序列的末尾元素最小值的数组
    // tails[i] 表示"长度为 i+1 的递增子序列所能拥有的末尾元素最小值"
    List<Integer> tails = new ArrayList<>();

    // 从头到尾逐一遍历数组 nums 的每个元素
    for (int num : nums) {
        // 通过二分查找确定 num 在 tails 数组中应插入的位置
        // 由于 tails 始终保持有序，因此可以使用二分查找
        int pos = Collections.binarySearch(tails, num);

        // 负值表示"未找到"，需要将其转换为插入位置
        // 如果 pos 大于等于 0，说明 tails[pos] 中已存在与 num 相同的值，直接使用该位置
        if (pos < 0)
            pos = -(pos + 1);

        if (pos == tails.size()) {
            // num 大于 tails 的所有元素，追加到末尾
            // 这意味着最长递增子序列的长度增加了 1
            tails.add(num);
        } else {
            // 用 num 替换该位置的末尾最小值进行更新
            // 这样长度为 pos+1 的递增子序列的末尾最小值变得更小，
            // 从而增加了将来延伸子序列的可能性
            tails.set(pos, num);
        }
    }

    // tails 的元素个数等于处理过程中追加到末尾的次数，
    // 即为最长递增子序列的长度
    return tails.size();
}
```
