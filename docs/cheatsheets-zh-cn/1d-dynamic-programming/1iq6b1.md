# Finding the Subarray With Maximum Product — 查找具有最大乘积的连续子数组

## 问题的本质

给定一个整数数组 `nums`。从数组中选择一个**连续子数组**，找到元素乘积最大的子数组，并返回该**乘积**。子数组由一个或多个连续元素组成。

## 核心思路

两个负数相乘会得到正数，因此当前最小值（绝对值最大的负数）与下一个负数相乘时可能变为最大值。因此，需要在每个位置同时追踪"当前最大乘积"和"当前最小乘积"。

## 思考过程

1. **考虑子数组乘积的特性**: 在求连续子数组乘积的问题中，每添加一个元素，都可以通过"前一个子数组的乘积 × 当前元素"来计算新的乘积。这与 DP 的思想相同，可以从前一个状态推导出下一个状态
2. **负数使最大乘积的计算变得复杂**: 如果只有正数，只需追踪最大乘积即可，但存在负数时会出现"较大的负乘积 × 负数 = 较大的正乘积"的情况。也就是说，如果不同时追踪当前最小乘积（负方向上绝对值最大的值），就可能遗漏最大乘积
3. **每个位置的候选值缩减为3个**: 位置 `i` 处最大乘积的候选值为：(a) `nums[i]` 本身（开始一个新的子数组）、(b) `curMax * nums[i]`（延长正的最大乘积）、(c) `curMin * nums[i]`（负的最小乘积因负数而翻转）。这三者的最大值即为新的 `curMax`
4. **最小乘积也从相同的3个候选值中选择**: 最小乘积的候选值也是相同的3个值，其中的最小值即为新的 `curMin`。通过同时更新最大值和最小值，可以正确捕捉负数引起的翻转
5. **更新时需要保存之前的值**: 如果在更新 `curMax` 之后再计算 `curMin`，则 `curMin` 的计算将无法使用更新前的 `curMax`。因此，在更新 `curMax` 之前，需要将其值保存到临时变量 `temp` 中，在计算 `curMin` 时使用 `temp`
6. **用单独的变量管理全局最大值**: `curMax` 是当前位置的最大乘积，而不是整体的最大乘积。在每个位置通过 `result = Math.max(result, curMax)` 更新整体的最大乘积，最终返回 `result`

## 前置知识

### 子数组乘积与 DP 的关系

子数组的乘积可以通过将前一个位置的乘积乘以当前元素来延长。利用这一性质，可以在每个位置以 O(1) 的时间从前一个位置的结果计算"以当前位置结尾的子数组的最大乘积"。这是一种保留前一个状态并推导下一个状态的方法，与 DP 相同。

### Math.max / Math.min 是什么

这是从多个值中获取最大值和最小值的 Java 方法。要比较3个或更多的值，需要嵌套调用。

```java
Math.max(3, 7);                   // 返回两个值中的最大值 → 7
Math.min(3, 7);                   // 返回两个值中的最小值 → 3
Math.max(a, Math.max(b, c));      // 返回三个值中的最大值
Math.min(a, Math.min(b, c));      // 返回三个值中的最小值
```

### 为什么需要追踪最小值

在包含负数的数组中，乘积的符号会随每个元素翻转。例如：对于 `[-2, 3, -4]`，位置1处的最小乘积为 `-2 × 3 = -6`，但在位置2处 `-6 × -4 = 24` 变为最大乘积。如果只追踪最大乘积，就会丢弃 `-6`，从而遗漏 `24`。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历数组一次 |
| Space | O(1) — 使用的变量数量固定，不依赖于输入规模 |

## 代码

```java
// 输入: 整数数组 nums（长度为1以上）
// 输出: 以 int 形式返回连续子数组乘积的最大值
public int maxProduct(int[] nums) {
    // result=整体的最大乘积，curMax=以当前位置结尾的子数组的最大乘积，curMin=同最小乘积
    // 仅由第一个元素组成的子数组作为初始状态
    int result = nums[0];
    int curMax = nums[0];
    int curMin = nums[0];

    // i=0 已在初始化中处理，因此从 i=1 开始
    for (int i = 1; i < nums.length; i++) {
        int n = nums[i];
        // 在更新 curMax 之前将其保存（因为计算 curMin 时需要更新前的值）
        int temp = curMax;

        // 从3个候选值中选择最大值:
        // n 本身 → 开始一个新的子数组的情况
        // temp * n → 延长前一个最大乘积的情况
        // curMin * n → 前一个最小乘积（负数）因负数 n 翻转而变为最大的情况
        curMax = Math.max(n,
            Math.max(temp * n, curMin * n));

        // 从相同的3个候选值中选择最小值（通过使用 temp 中更新前的 curMax，可以不受上面更新的影响进行正确计算）
        curMin = Math.min(n,
            Math.min(temp * n, curMin * n));

        // curMax 是当前位置的最大乘积而非整体的最大乘积，因此用单独的变量 result 管理整体的最大乘积
        result = Math.max(result, curMax);
    }
    // result 中存储了整个数组中最大的子数组乘积
    return result;
}
```
