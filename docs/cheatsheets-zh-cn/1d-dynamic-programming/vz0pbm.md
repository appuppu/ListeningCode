# Finding the Minimum Cost to Climb Stairs — 求解到达楼梯顶部的最小花费

## 问题的本质

给定一个整数数组 `cost`，其中 `cost[i]` 表示踏上第 i 级台阶的花费。可以从第0级或第1级台阶开始，每一步可以向上爬1级或2级台阶。请返回到达楼梯**顶部**（数组末尾的下一个位置）所需的最小总花费。

## 核心思路

到达每一级台阶的最小花费，由「从前1级台阶过来的情况」和「从前2级台阶过来的情况」中较小的一方决定。由于该计算只需要前2个结果，因此无需使用数组，仅用2个变量即可求出最小花费。

## 思考过程

1. **到达顶部有2种方式**：到达顶部（索引 n）可以从前1级台阶（n-1）向上爬1级，或者从前2级台阶（n-2）向上爬2级。两者花费中较小的一方即为答案
2. **到达每一级台阶的最小花费可以递归定义**：将到达第 i 级台阶的最小花费设为 `dp[i]`，则递推公式为 `dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`。即取「前1级的最小花费＋该级的花费」与「前2级的最小花费＋该级的花费」中较小的一方
3. **确定初始条件**：由于可以从第0级或第1级台阶开始，因此到达第0级和第1级台阶的花费均为0。即 `dp[0] = 0`，`dp[1] = 0`
4. **无需整个数组，只需保留前2个值**：递推公式 `dp[i]` 仅依赖于 `dp[i-1]` 和 `dp[i-2]`。因此，可以用2个变量 `prev1`（前1级）和 `prev2`（前2级）代替数组来完成计算
5. **一边更新变量一边向前推进**：从第2级台阶到第 n 级台阶依次循环，每次计算出 `curr` 后，将 `prev2 = prev1`，`prev1 = curr` 依次滑动更新。循环结束时 `prev1` 即为到达顶部的最小花费

## 前置知识

### 什么是动态规划（Dynamic Programming）

动态规划是一种将大问题分解为小的子问题，并通过复用子问题的结果来高效求解的方法。在本题中，将「到达第 i 级台阶的最小花费」作为子问题，从小索引开始依次求解（自底向上方式）。

### 什么是 Math.min

Math.min 是Java的标准方法，用于返回两个整数中较小的一方。在本题中用于从两个选择中选出花费较低的一方。

```java
Math.min(5, 3);    // 返回3 — 返回两个参数中较小的一方
Math.min(10, 10);  // 返回10 — 两个值相同时返回该值
```

### 空间优化的思路

当DP数组的每个元素仅依赖于前面若干个元素时，可以不保留整个数组，而仅用所需数量的变量来完成计算。在本题中，由于只需要 `dp[i-1]` 和 `dp[i-2]` 两个值，因此2个变量就足够了。

```java
int prev2 = 0;  // 相当于 dp[i-2] 的变量
int prev1 = 0;  // 相当于 dp[i-1] 的变量
int curr;       // 相当于 dp[i] 的变量（每次计算后更新）
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历数组一次 |
| Space | O(1) — 仅使用2个变量，不依赖于数组大小 |

## 代码

```java
// 输入：整数数组 cost（每一级台阶的踏上花费）
// 输出：以 int 类型返回到达楼梯顶部（索引 n）的最小总花费
public int minCostClimbingStairs(int[] cost) {
    // 获取数组长度。顶部位于索引 n 的位置（数组末尾的下一个位置）
    int n = cost.length;

    // prev2=到达前2级台阶的最小花费，prev1=到达前1级台阶的最小花费
    // 由于可以从第0级和第1级开始，因此初始花费为0
    int prev2 = 0, prev1 = 0;

    // 从第2级台阶到顶部（第 n 级）依次计算最小花费。i 表示当前要到达的台阶
    for (int i = 2; i <= n; i++) {
        // prev1 + cost[i-1]：从前1级台阶向上爬1级到达时的总花费
        // prev2 + cost[i-2]：从前2级台阶向上爬2级到达时的总花费
        // 选择较小的一方
        int curr = Math.min(
            prev1 + cost[i - 1],
            prev2 + cost[i - 2]);

        // 将变量依次向前滑动一位
        // 注意：必须先更新 prev2，否则 prev1 的原始值会丢失
        prev2 = prev1;
        prev1 = curr;
    }

    // prev1 中存储着循环最后一次迭代（i = n）计算出的到达顶部的最小花费
    return prev1;
}
```
