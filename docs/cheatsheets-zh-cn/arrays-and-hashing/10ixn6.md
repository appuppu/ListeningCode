# Computing Products Without Self Inclusion — 求不包含自身的所有元素之积

## 问题的本质

给定一个整数数组 `nums`。对于每个索引 `i`，计算除 `nums[i]` **以外**所有元素的乘积，并返回存储结果的数组 `result`。不允许使用除法运算符。

## 核心思路

不包含某个元素的所有元素之积，可以分解为「该元素左侧所有元素之积」×「该元素右侧所有元素之积」。通过正向和反向两次遍历来构建左右两侧的累积积，就能在不使用除法的情况下以 O(n) 的时间复杂度求解。

## 思考过程

1. **由于不能使用除法，需要考虑其他分解方式**: 先求所有元素之积再除以各元素的方法是被禁止的。因此，将 `result[i]` 分解为「`nums[i]` 左侧之积」×「`nums[i]` 右侧之积」。这种分解方式不需要除法
2. **左侧的累积积可以通过正向遍历来构建**: 从左到右遍历数组，计算每个位置「其左侧所有元素之积」。递推公式为 `result[i] = result[i-1] * nums[i-1]`。由于首元素左侧没有元素，因此用 `result[0] = 1`（乘法单位元）进行初始化
3. **右侧的累积积可以通过反向遍历来构建**: 从右到左遍历数组，用变量 `record` 累积「其右侧所有元素之积」。由于末尾元素右侧没有元素，因此用 `record = 1` 进行初始化
4. **将两个积相乘**: 在反向遍历过程中，将 `result[i]`（左侧之积）乘以 `record`（右侧之积），即可得到最终答案。相乘之后，通过 `record = record * nums[i]` 来更新右侧之积
5. **无需使用额外数组**: 左侧之积直接写入 `result` 数组，右侧之积仅用一个变量来维护，因此除输出数组外，额外的内存开销为 O(1)

## 前置知识

### 累积积（Prefix Product / Suffix Product）

从数组的头部或尾部开始依次将元素相乘所得到的积的序列，相当于累积和的乘法版本。可以高效地求出每个位置「之前所有元素之积」。

```java
int[] nums = {1, 2, 3, 4};

// 从左到右的累积积（prefix product）
// prefix[0] = 1（左侧没有元素）
// prefix[1] = 1（截至 nums[0]）
// prefix[2] = 1*2 = 2（截至 nums[1]）
// prefix[3] = 1*2*3 = 6（截至 nums[2]）

// 从右到左的累积积（suffix product）
// suffix[3] = 1（右侧没有元素）
// suffix[2] = 4（截至 nums[3]）
// suffix[1] = 4*3 = 12（nums[3]*nums[2]）
// suffix[0] = 4*3*2 = 24（nums[3]*nums[2]*nums[1]）
```

### 乘法单位元

任何数乘以1，其值不变。将1作为累积积的初始值，可以对第一个元素也适用相同的递推公式。

```java
int record = 1;              // 积的初始值为1（单位元）
record = record * nums[i];   // 第一次乘法运算时 record = nums[i]
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需对数组进行一次正向遍历和一次反向遍历 |
| Space | O(1) — 除输出数组 `result` 外，额外使用的内存仅有变量 `record` |

## 代码

```java
// 输入: 整数数组 nums
// 输出: 返回一个 int[]，其中每个索引存储除自身以外所有元素之积
public int[] productExceptSelf(int[] nums) {
    // 创建与 nums 等长的数组。先存储左侧的累积积，之后再乘以右侧的累积积
    int[] result = new int[nums.length];

    // 正向遍历：将每个位置左侧所有元素之积存入 result
    result[0] = 1;  // 首元素左侧没有元素，因此用乘法单位元1进行初始化
    for (int i = 1; i < nums.length; i++) {
        // result[i-1] 是位置 i-1 的左侧之积。将其乘以 nums[i-1]（左边一个元素）即得到位置 i 的左侧之积
        result[i] = result[i - 1] * nums[i - 1];
    }

    // 反向遍历：乘以右侧的累积积以得到最终结果
    // record 是用于累积「当前位置右侧所有元素之积」的变量
    int record = 1;  // 末尾元素右侧没有元素，因此用1进行初始化
    for (int i = nums.length - 1; i >= 0; i--) {
        // result[i] 中存储的是左侧之积。将其乘以 record（右侧之积）即得到「除自身以外所有元素之积」
        result[i] = record * result[i];
        // 注意: record 的更新必须在 result[i] 确定之后进行。若先更新，nums[i] 自身会被包含在积中
        record = record * nums[i];
    }

    // 返回每个元素都存储了「除自身以外所有元素之积」的 result
    return result;
}
```
