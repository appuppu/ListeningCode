# Checking if Two Strings Are Anagrams — 判断两个字符串是否为字母重排

## 问题的本质

给定两个字符串 `s` 和 `t`。判断 `t` 是否为 `s` 的字母重排（Anagram），并返回 **boolean** 值。字母重排是指两个字符串包含完全相同的字符且每个字符的出现次数也相同，只是排列顺序不同的关系。

## 核心思路

判断是否为字母重排，可以归结为"每个字符的出现次数是否完全一致"。由于小写字母只有26种，使用固定长度为26的数组来管理所有字符的出现次数，就可以在 O(1) 的空间和 O(n) 的时间内完成判断。

## 思考过程

1. **从数学角度理解字母重排的定义**：两个字符串互为字母重排，意味着每个字符的出现频率完全一致。也就是说，可以忽略字符的顺序，只需比较频率即可
2. **长度不同则立即返回false**：字母重排要求包含相同的字符且出现次数相同，因此当两个字符串长度不同时，它们不可能互为字母重排。在最开始进行此判断可以避免不必要的处理
3. **考虑频率的比较方法**：小写字母限定为从'a'到'z'的26种。不使用HashMap，而是使用大小为26的固定长度int数组，就可以通过索引来管理每个字符的出现次数
4. **用一个数组处理两个字符串**：不需要创建两个数组再进行比较，而是对一个数组，针对一个字符串进行递增操作，针对另一个字符串进行递减操作。最终如果所有元素都为0，则表示频率完全一致
5. **在同一个循环中处理两个字符串**：由于已经事先确认了两个字符串长度相等，因此可以在一个for循环中同时对 `s` 进行递增和对 `t` 进行递减操作
6. **最终判断**：循环结束后，检查数组中所有元素是否都为0。如果存在任何一个不为0的元素，则说明某个字符的出现次数不一致，返回false

## 前置知识

### 从字符到数组索引的转换

通过 `char - 'a'` 运算，可以将小写字母转换为0到25的整数。这样就可以直接将字符用作数组的索引。

```java
char c = 'd';
int index = c - 'a';    // 'd' - 'a' = 3（'a'=0, 'b'=1, 'c'=2, 'd'=3）
int[] count = new int[26];
count[c - 'a']++;       // count[3] 变为1（记录'd'的出现次数）
```

### 使用固定长度数组进行频率计数

准备一个大小为26的int数组，每个索引对应一个字符，从而构成一个频率表。在Java中，`new int[26]` 会将所有元素初始化为0。

```java
int[] count = new int[26];  // 所有元素初始化为0
count['b' - 'a']++;        // count[1] = 1（记录'b'的出现）
count['b' - 'a']--;        // count[1] = 0（抵消'b'的出现）
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历字符串一次即可完成判断（n为字符串的长度） |
| Space | O(1) — 使用的数组大小始终为26，不依赖于输入的长度 |

## 代码

```java
// 输入：两个字符串 s 和 t
// 输出：如果 t 是 s 的字母重排则返回 true，否则返回 false
public boolean isAnagram(String s, String t) {
    // 字母重排要求包含相同字符且出现次数相同，因此长度不同时不可能是字母重排
    if (s.length() != t.length())
        return false;

    // 记录每个字母出现次数"差值"的数组（索引0='a', 25='z'）
    // 大小26对应a到z的26个字母
    int[] count = new int[26];

    // 在一个循环中同时处理两个字符串（已事先确认长度相等）
    for (int i = 0; i < s.length(); i++) {
        // 对s的字符进行递增：记录"s中该字符出现了1次"
        count[s.charAt(i) - 'a']++;
        // 对t的字符进行递减：记录"t中该字符出现了1次"
        // 如果递增和递减相互抵消，则说明该字符在s和t中的出现次数相等
        count[t.charAt(i) - 'a']--;
    }

    // 遍历全部26个元素，如果存在任何一个不为0的元素，则说明出现次数不一致
    for (int c : count) {
        if (c != 0) return false;
    }
    // 所有元素都为0 → 所有字符的出现次数一致 → 互为字母重排
    return true;
}
```
