# Finding the Longest Consecutive Number Sequence — 从未排序的数组中求最长连续整数序列的长度

## 问题的本质

给定一个整数数组 `nums`（未排序）。从数组中找出连续整数序列（例：1,2,3,4），并返回其**最长长度**。元素的排列顺序无关紧要，只要值是连续的即可。

## 核心思路

只从连续序列的"起点"开始计数，就能消除多余的重复计算。对于某个数 `num`，如果 `num - 1` 不存在于HashSet中，则该数就是连续序列的起点。仅从起点开始计数，整体可以达到O(n)的时间复杂度。

## 思考过程

1. **确定连续序列的起点**：如果从连续序列中间的数开始计数，会导致同一个序列被重复计算多次。只有 `num - 1` 不存在的数才是连续序列的真正起点。仅从起点开始计数，每个元素最多只会被计数一次
2. **快速进行存在性判定**：为了以O(1)的时间复杂度判定某个数是否存在于数组中，将所有元素存入HashSet。虽然排序可以用O(n log n)解决问题，但使用HashSet只需O(n)
3. **从起点开始逐个计数**：找到起点 `num` 后，依次检查 `num + 1`、`num + 2`、... 是否存在于HashSet中，计算连续序列的长度直到中断为止
4. **追踪最长长度**：将每个连续序列的长度与变量 `longest` 进行比较，如果更长则更新该变量。处理完所有元素后，`longest` 即为答案

## 前置知识

### 什么是 HashSet

HashSet是一种不允许重复值的数据结构。添加值和判定值是否存在的操作均为O(1)。与HashMap不同，HashSet只保存键，适用于需要快速判定某个值"是否存在"的场景。

```java
HashSet<Integer> set = new HashSet<>();  // 创建一个空的HashSet
set.add(4);              // 将值4添加到集合中
set.add(4);              // 重复值会被忽略（集合的元素数量不变）
set.contains(4);         // 判定值4是否存在，返回boolean → true
set.contains(5);         // 判定值5是否存在，返回boolean → false
```

### 什么是连续序列的起点

对于某个数 `num`，当 `num - 1` 不存在于集合中时，`num` 就是连续序列的第一个数（起点）。
例：集合={100, 4, 200, 1, 3, 2} 时，1是起点（0不存在），2不是起点（1存在）。

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 每个元素在起点判定时被访问一次，在计数时最多被访问一次，总共最多被访问两次 |
| Space | O(n) — HashSet中最多保存n个元素 |

## 代码

```java
// 输入：整数数组 nums（未排序，可能包含重复元素）
// 输出：以 int 类型返回最长连续整数序列的长度
public int longestConsecutive(int[] nums) {
    // 将所有元素存入HashSet，使存在性判定可以在O(1)时间内完成
    // 重复元素会被自动去除
    Set<Integer> numSet = new HashSet<>();
    for (int num : nums) {
        numSet.add(num);
    }

    // 保存目前为止找到的最长连续序列长度的变量
    int longest = 0;

    // 遍历HashSet中的每个元素
    for (int num : numSet) {
        // 如果 num - 1 不存在，则 num 是连续序列的起点
        // 如果 num - 1 存在，则 num 是连续序列中间的数，跳过该数
        //（该数会在从其他起点开始计数时被统计）
        if (!numSet.contains(num - 1)) {
            int currentNum = num;
            int length = 1;

            // 从起点开始依次计数连续的数（num+1, num+2, ...）
            // 循环持续进行直到连续中断为止
            while (numSet.contains(currentNum + 1)) {
                currentNum++;
                length++;
            }

            // 如果当前连续序列的长度超过了目前的最长记录，则更新该记录
            longest = Math.max(longest, length);
        }
    }
    // 遍历完所有元素后，返回最长连续整数序列的长度
    return longest;
}
```
