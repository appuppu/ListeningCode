# Grouping Words by Anagram Patterns — 将互为字谜的单词分组归类

## 问题的本质

给定一个字符串数组 `strs`。将互为字谜的字符串分为一组，并以组的列表形式返回。两个字符串互为字谜是指，它们包含相同的字符且每个字符的出现次数相同，仅排列顺序不同。

## 核心思路

互为字谜的字符串具有完全相同的"各字符出现次数"。将26个字母各自的出现次数统计后转换为字符串作为键，互为字谜的字符串必定生成相同的键，因此可以用HashMap进行统一分组。

## 思考过程

1. **找出字谜的共同性质**: 互为字谜的字符串仅排列顺序不同，各字符的出现次数完全一致。可以利用这个"出现次数一致"作为分组的判定标准
2. **如何表示出现次数**: 英文小写字母共26种，因此准备一个大小为26的整数数组 `count`，统计每个字符的出现次数。如果两个单词的数组内容相同，则它们互为字谜
3. **将数组作为HashMap键的方法**: 在Java中不能直接将数组作为HashMap的键（因为会进行引用比较）。因此，将数组的各元素用 `#` 分隔后拼接成字符串（例如: `"1#0#0#...#"`）作为键使用。这样，出现次数相同的单词就会生成相同的字符串键
4. **用HashMap进行分组**: 将键相同的单词放入同一个列表即可。使用 `computeIfAbsent`，当键未注册时会自动生成新列表，当键已注册时则返回该列表，无需条件分支即可添加单词
5. **最终返回的结果**: 将HashMap的所有值（各组的列表）转换为 `ArrayList` 后返回

## 前置知识

### HashMap 是什么

HashMap是一种保存键值对的数据结构。通过指定键，可以在O(1)时间内完成值的搜索和获取。它类似于一本字典，可以用任意键进行访问，速度与数组的索引访问相同。

```java
HashMap<String, List<String>> map = new HashMap<>();  // 创建一个空的HashMap
map.put("key", new ArrayList<>());  // 将空列表存入键"key"
map.containsKey("key");             // 返回键"key"是否存在的boolean值 → true
map.get("key");                     // 返回键"key"对应的值 → []
map.values();                       // 以Collection形式返回所有的值
```

### computeIfAbsent 是什么

computeIfAbsent是HashMap的方法。如果指定的键不存在，则通过第二个参数的Lambda表达式生成值并注册，然后返回该值。如果键已存在，则直接返回现有的值。它可以用一行代码实现基于键是否存在的条件分支。

```java
// 如果键"abc"未注册，则创建新的ArrayList并注册，然后返回该列表
// 如果键"abc"已注册，则直接返回现有的列表
map.computeIfAbsent("abc", k -> new ArrayList<>()).add("cab");
```

### 字符出现次数的统计

将 `char` 类型的字符减去 `'a'`，可以将其转换为 a=0, b=1, ..., z=25 的索引。准备一个大小为26的数组，在对应索引的位置进行自增，即可记录每个字符的出现次数。

```java
int[] count = new int[26];           // 创建一个26个字母的计数数组（初始值全部为0）
for (char c : "eat".toCharArray())   // 逐字符遍历字符串
    count[c - 'a']++;                // 将对应字符位置的计数自增
// 结果: count[0]=1(a), count[4]=1(e), count[19]=1(t), 其余为0
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n × k) — n为字符串的个数，k为字符串的平均长度。对每个字符串进行字符数量的统计和大小为26的键生成 |
| Space | O(n × k) — HashMap中保存所有字符串，每个键为固定长度，但字符串本身占用k个字符的内存 |

## 代码

```java
// 输入: 字符串数组 strs
// 输出: 返回将互为字谜的字符串分组后的 List<List<String>>
public List<List<String>> groupAnagrams(String[] strs) {
    // 键=出现次数的字符串表示，值=属于该键的单词列表，保存在HashMap中
    // 拥有相同键的单词互为字谜
    Map<String, List<String>> map = new HashMap<>();

    // 从头到尾逐个遍历数组 strs 中的每个字符串 s
    for (String s : strs) {
        // 创建一个大小为26的数组，用于记录每个字符（a〜z）的出现次数（初始值全部为0）
        // 每个字符串都创建新数组，是为了防止前一个字符串的统计结果残留
        int[] count = new int[26];
        // 通过 toCharArray() 转换为字符数组，对每个字符 c 统计出现次数
        for (char c : s.toCharArray())
            // 通过 c - 'a' 将字符 c 转换为索引0〜25并自增
            count[c - 'a']++;

        // 将出现次数数组转换为"1#0#0#..."格式的字符串键
        // 该键唯一地表示字符的出现次数，互为字谜的字符串必定生成相同的键
        // 在每个元素之间插入分隔符 #，以防止不同的计数生成相同的字符串
        StringBuilder sb = new StringBuilder();
        for (int n : count)
            sb.append(n).append('#');
        String key = sb.toString();

        // 如果键未注册则创建新列表，然后将当前字符串添加到列表中
        // 这样，拥有相同键的单词就会被累积到同一个列表中
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }

    // 获取所有组的集合，转换为 List<List<String>> 后返回
    return new ArrayList<>(map.values());
}
```
