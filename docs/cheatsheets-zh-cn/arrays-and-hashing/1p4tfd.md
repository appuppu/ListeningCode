# Finding Duplicates in an Array — 判定数组中是否存在重复值

## 问题的本质

给定一个整数数组 `nums`。如果数组中存在某个值出现2次以上，则返回 `true`；如果所有元素都不相同，则返回 `false`。

## 核心思路

在遍历数组的过程中，将已经遇到的元素记录到HashSet中，就可以以O(1)的时间复杂度判定每个元素是否已经出现过。一旦发现重复，立即返回 `true`。

## 思考过程

1. **判定重复 = 判定"之前是否见过相同的值"**: 从头开始遍历数组时，如果当前元素在之前已经出现过，那么它就是重复的。也就是说，只要能够管理"到目前为止见过的元素的集合"，就可以检测到重复
2. **需要高速检索之前见过的元素**: 对于每个元素，要以O(1)的时间复杂度判定"这个值是否已经见过"，HashSet是最合适的数据结构。HashSet可以以O(1)的时间复杂度进行元素的存在性确认
3. **HashSet中保存什么**: 问题只需要返回布尔值而不是索引，因此只保存值本身到HashSet中就足够了
4. **在遍历的同时构建HashSet**: 从头开始依次遍历数组，对每个元素判定"是否已经包含在HashSet中"。如果已包含则发现了重复，如果未包含则将当前元素添加到HashSet中并继续处理下一个元素
5. **通过提前返回提高效率**: 一旦发现重复，立即返回 `true`。如果遍历完整个数组都没有发现重复，则返回 `false`

## 前置知识

### 什么是HashSet

HashSet是一种管理不含重复元素的集合的数据结构。添加元素和确认元素是否存在的操作都可以在O(1)时间内完成。与HashMap不同，HashSet不保存键值对，而只保存值。它具有自动排除重复元素的特性。

```java
HashSet<Integer> set = new HashSet<>();  // 创建一个空的HashSet
set.add(10);              // 添加元素10
set.contains(10);         // 判定元素10是否存在，返回boolean → true
set.contains(5);          // 判定元素5是否存在，返回boolean → false
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历数组一次 |
| Space | O(n) — HashSet中最多保存n个元素 |

## 代码

```java
// 输入: 整数数组 nums
// 输出: 如果存在重复值则返回 true，如果所有元素都不相同则返回 false
public boolean containsDuplicate(int[] nums) {
    // 用于记录到目前为止已遍历过的元素的HashSet
    // 因为问题只需要返回布尔值，所以只保存值就足够了
    HashSet<Integer> seen = new HashSet<>();

    for (int num : nums) {
        // 如果当前元素已经存在于HashSet中，说明同一个值出现了2次，确认存在重复
        if (seen.contains(num)) {
            return true;  // 一旦发现重复立即返回（提前返回）
        }

        // 将当前元素添加到HashSet中并继续处理下一个元素
        // 该元素在后续遍历中将作为"之前见过的元素"被引用
        seen.add(num);
    }
    // 如果循环结束后仍未发现重复，则确认所有元素都不相同
    return false;
}
```
