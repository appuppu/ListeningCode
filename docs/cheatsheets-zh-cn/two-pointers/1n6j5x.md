# 在排序数组中查找两个数使其和等于目标值 — ソート済み配列から合計がターゲットになる2つの数を見つける

## 问题的本质

给定一个已排序的整数数组 `nums` 和一个整数 `target`。需要在 `nums` 中找到两个元素，使它们的和等于 `target`，并以数组形式返回这两个元素的**1-indexed 位置**。解恰好只有一个，且不能重复使用同一个元素。

## 核心思路

由于数组已经排序，可以从左端和右端分别设置两个指针进行夹逼。如果两个元素的和太大，就将右指针向左移动；如果和太小，就将左指针向右移动。这样只需一次遍历，就能在 O(n) 时间和 O(1) 空间内找到答案。

## 思考过程

1. **利用数组已排序这一条件**: 由于数组已排序，左端指向最小值，右端指向最大值。从这两端的和开始搜索，就能根据和的大小关系确定地缩小搜索范围
2. **如果和太大，就将右指针向左移动**: 右指针指向当前搜索范围中的最大值。当和大于 `target` 时，为了减小和，需要将右指针向左移动一位，切换到更小的值
3. **如果和太小，就将左指针向右移动**: 左指针指向当前搜索范围中的最小值。当和小于 `target` 时，为了增大和，需要将左指针向右移动一位，切换到更大的值
4. **如果和恰好等于 `target`，就找到了答案**: 当两个指针所指的值之和与 `target` 一致时，这就是所求的配对。由于题目要求 1-indexed，因此需要将每个指针的位置加 1 后返回
5. **循环的终止条件**: 循环持续进行，直到左指针到达右指针的位置。根据题目的约束条件，解一定存在，因此在两个指针交叉之前一定能找到答案
6. **最终返回的内容**: 当和与 `target` 一致时，以 `int[]` 的形式返回 `left + 1`（左侧元素的 1-indexed 位置）和 `right + 1`（右侧元素的 1-indexed 位置）

## 前置知识

### Two Pointers（双指针）是什么

双指针是一种使用两个指向数组不同位置的索引变量，并根据条件分别移动它们的方法。对于已排序的数组，从两端向中间缩小搜索范围是最典型的模式。

```java
int left = 0;                    // 将左指针放在数组的开头
int right = nums.length - 1;     // 将右指针放在数组的末尾
while (left < right) {           // 循环直到两个指针交叉
    // 根据条件移动 left 和 right
    left++;   // 将左指针向右移动一位
    right--;  // 将右指针向左移动一位
}
```

### 排序数组的性质

当数组按升序排列时，`nums[left] <= nums[right]` 始终成立。将左指针向右移动会使和增大，将右指针向左移动会使和减小。正是由于这种单调性，才能根据和的大小来决定两个指针的移动方向。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 两个指针总共最多移动 n 次即可完成 |
| Space | O(1) — 仅使用指针变量，不需要额外的数据结构 |

## 代码

```java
// 输入: 已排序的整数数组 nums 和整数 target
// 输出: 返回一个 int[]，其中存储和等于 target 的两个元素的 1-indexed 位置
public int[] twoSum(int[] nums, int target) {
    // 将左指针放在数组的开头。它是搜索范围的左端，负责数组的最小值一侧
    int left = 0;
    // 将右指针放在数组的末尾。它是搜索范围的右端，负责数组的最大值一侧
    int right = nums.length - 1;

    // 循环直到两个指针交叉
    while (left < right) {
        // 计算当前两个元素的和，并存入变量以便在各分支中复用
        int cursum = nums[left] + nums[right];

        if (cursum == target) {
            // 和与目标值一致，找到了配对。由于题目要求 1-indexed，因此将每个索引加 1 后返回
            return new int[]{left + 1, right + 1};
        } else if (cursum > target) {
            // 和太大，所以将右指针向左移动。右指针指向的值变小，下一次迭代中和会减小
            right--;
        } else {
            // 和太小，所以将左指针向右移动。左指针指向的值变大，下一次迭代中和会增大
            left++;
        }
    }
    // 根据题目的约束条件，解一定存在，因此程序不会执行到这里
    return new int[]{};
}
```
