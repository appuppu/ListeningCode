# Three Sum — 找出所有三个数之和为零的三元组

## 问题的本质

给定一个整数数组 `nums`。从 `nums` 中找出所有三个元素之和为 `0` 的组合（三元组），以 `List<List<Integer>>` 的形式返回。每个三元组由不同索引的元素组成，结果中不能包含重复的三元组。

## 核心思路

对数组进行排序后，固定一个元素，利用 Two Pointers 高效地搜索剩余的两个元素。同时利用排序后的顺序跳过重复值，从而自然地实现重复三元组的去除。

## 思考过程

1. **将三元素问题归约为两元素问题**：三个数 `a + b + c = 0`，固定一个元素 `a = nums[i]` 后，问题就变成了 `b + c = -a` 的两元素搜索问题。在外层 for 循环中固定 `a`，在内层搜索 `b` 和 `c`，这样就可以应用已知的 Two Sum 思路
2. **为使用 Two Pointers 而进行排序**：为了高效地搜索两个元素，对数组进行排序后从两端收缩指针的 Two Pointers 方法非常有效。如果总和太小则将左指针右移，如果总和太大则将右指针左移，从而高效地搜索所有配对
3. **利用排序实现重复三元组的去除**：在排序后的数组中，相同的值会相邻排列。如果外层循环的 `nums[i]` 与前一个元素值相同则跳过；在内层循环中，找到配对后也将 `left` 和 `right` 在相同值持续出现时跳过，从而避免将重复三元组加入结果
4. **确定外层循环的范围**：由于需要三个元素，`i` 从 `0` 遍历到 `nums.length - 3`。`left` 从 `i + 1` 开始，`right` 从 `nums.length - 1` 开始，仅在 `left < right` 时继续搜索
5. **根据总和值移动指针**：如果 `sum == 0`，则将三元组添加到结果中，跳过重复值后将两个指针向内移动。如果 `sum < 0`，为了增大总和将 `left` 右移；如果 `sum > 0`，为了减小总和将 `right` 左移
6. **最终返回的内容**：遍历完所有固定元素和指针的组合后，直接返回累积的 `result` 列表

## 前置知识

### 什么是 Two Pointers

在排序后的数组两端放置两个指针（`left` 和 `right`），根据条件移动其中一个，从而以 O(n) 的时间复杂度搜索所有配对的方法。如果总和小于目标值则将 `left` 右移（增大值），如果总和大于目标值则将 `right` 左移（减小值）。

```java
int left = 0;
int right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) {
        // 找到配对
    } else if (sum < target) {
        left++;    // 为了增大总和，将左指针右移
    } else {
        right--;   // 为了减小总和，将右指针左移
    }
}
```

### 什么是 Arrays.sort()

Arrays.sort() 是 Java 的标准方法，用于将数组按升序排序。排序后相同的值会相邻排列，因此便于检测重复值。

```java
int[] nums = {4, -1, 2, -1, 0};
Arrays.sort(nums);    // nums 变为 {-4, -1, -1, 0, 2}（升序）
```

### 什么是 Arrays.asList()

Arrays.asList() 是一个从可变参数生成固定大小 `List` 的方法。在将三元组作为 `List<Integer>` 添加到结果列表时使用。

```java
List<Integer> triplet = Arrays.asList(-1, 0, 1);  // 生成 [-1, 0, 1] 的列表
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n²) — 外层循环为 O(n)，内层 Two Pointers 为 O(n)，总计 O(n²) |
| Space | O(1) — 除排序外，仅使用指针变量，不占用额外空间 |

## 代码

```java
// 输入：整数数组 nums
// 输出：存储所有和为 0 的唯一三元组的 List<List<Integer>>
public List<List<Integer>> threeSum(int[] nums) {
    // 用于累积所有已找到三元组的结果列表
    List<List<Integer>> result = new ArrayList<>();
    // 将数组按升序排序（Two Pointers 的前提条件 + 用于跳过重复值）
    Arrays.sort(nums);

    // i 从 0 遍历到 nums.length - 3。nums[i] 作为三元组的固定元素
    for (int i = 0; i < nums.length - 2; i++) {
        // 如果固定元素与前一个元素值相同，会生成相同的三元组，因此跳过
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }
        // 将左右指针分别放置在固定元素之后和数组末尾，在此范围内搜索配对
        int left = i + 1;
        int right = nums.length - 1;

        while (left < right) {
            // 计算三个元素的总和
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0) {
                // 将总和为零的三元组添加到结果中
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // 跳过左指针侧的重复值（相同值持续出现时向右移动）
                while (left < right && nums[left] == nums[left + 1]) {
                    left++;
                }
                // 跳过右指针侧的重复值（相同值持续出现时向左移动）
                while (left < right && nums[right] == nums[right - 1]) {
                    right--;
                }
                // 跳过重复值后，将两个指针各向内移动一步，继续搜索下一个配对
                left++;
                right--;
            } else if (sum < 0) {
                // 总和为负，将左指针右移以增大总和
                left++;
            } else {
                // 总和为正，将右指针左移以减小总和
                right--;
            }
        }
    }

    // 所有固定元素的搜索已完成。结果中存储了所有无重复的三元组
    return result;
}
```
