# Maximizing Water Held Between Two Lines — 求两条垂直线之间容器的最大盛水量

## 问题的本质

给定一个非负整数数组 `height`。每个元素 `height[i]` 表示x轴上位置 `i` 处垂直线的高度。从中选择两条线，返回这两条线与x轴所形成的容器能够容纳的**最大水量**。容器的水量由"两条线之间的距离 × 两条线中较短一条的高度"决定。

## 核心思路

从容器宽度最大的状态（两端）开始，将较短一侧的指针向内移动，这样既保留了通过增加高度来改善面积的可能性，又能高效地探索所有配对。移动较短一侧的原因是：既然宽度在缩小，如果高度不增加，面积就不会改善。

## 思考过程

1. **整理面积的计算公式**：两条线 `i` 和 `j`（i < j）所形成的容器面积为 `(j - i) × min(height[i], height[j])`。要使面积最大化，需要使"宽度"与"高度的最小值"的乘积最大
2. **从宽度最大的状态开始**：要使宽度最大，选择左端（索引0）和右端（索引 n-1）两条线即可。从这个状态开始探索，就能从宽度最大的状态出发
3. **决定移动哪个指针**：向内移动时宽度必定减少1。要改善面积只能增加高度。容器的高度由两条线中较短的一条决定，因此移动较短一侧的指针，就有可能遇到更高的线。相反，移动较长一侧的指针，由于较短一侧仍然是瓶颈，面积不会改善
4. **每一步记录面积**：每次移动指针后计算新的面积，与当前最大值进行比较并更新。这样就能得到与全量搜索相同的结果
5. **确定终止条件**：当左指针与右指针相遇时，所有有希望的配对已经检查完毕，因此结束探索
6. **最终返回值**：返回探索过程中记录的面积最大值 `maxarea`

## 前置知识

### Two Pointers（双指针）

在数组的两端或不同位置放置两个指针（索引），根据条件移动其中一个或两个指针来进行探索的方法。当可以利用条件将检查所有配对的O(n²)探索降低为O(n)时，该方法非常有效。

```java
int left = 0;                      // 将左指针放在数组的开头
int right = height.length - 1;     // 将右指针放在数组的末尾
while (left < right) {             // 循环直到两个指针相遇
    // 移动 left 或 right
    left++;   // 将左指针向右移动一位
    right--;  // 将右指针向左移动一位
}
```

### Math.min / Math.max

`Math.min(a, b)` 返回两个值中较小的一个，`Math.max(a, b)` 返回较大的一个。用于获取容器的高度（较短的线）以及更新面积的最大值。

```java
Math.min(3, 7);          // 返回两者中较小的一个 → 3
Math.max(10, 25);        // 返回两者中较大的一个 → 25
```

### 容器面积的计算

两条线 `left` 和 `right` 所形成的容器面积由宽度 × 高度求得。高度由两条线中较短的一条决定。

```java
int width = right - left;                              // 宽度 = 两条线之间的距离
int minHeight = Math.min(height[left], height[right]);  // 高度 = 较短一条线的高度
int area = width * minHeight;                           // 面积 = 宽度 × 高度
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 左右指针各向内移动一次，仅遍历数组一遍 |
| Space | O(1) — 仅使用保存指针和最大值的变量 |

## 代码

```java
// 输入：非负整数数组 height（每个元素表示垂直线的高度）
// 输出：返回两条线与x轴所形成的容器能够容纳的最大水量（int 类型）
public int maxArea(int[] height) {
    // 记录探索过程中找到的面积最大值的变量。初始化为0
    int maxarea = 0;
    // 将左指针放在数组的开头。从宽度最大的状态开始探索
    int left = 0;
    // 将右指针放在数组的末尾
    int right = height.length - 1;

    // 循环直到两个指针相遇。相遇时所有有希望的配对已经检查完毕
    while (left < right) {
        // 宽度 = 两条线之间的距离
        int width = right - left;
        // 高度 = 较短一条线的高度。容器的水量由较短的线决定
        int minHeight = Math.min(height[left], height[right]);
        // 面积 = 宽度 × 高度
        int area = width * minHeight;

        // 与当前最大值进行比较并更新
        maxarea = Math.max(area, maxarea);

        // 将较短一侧的指针向内移动。既然宽度在缩小，如果高度不增加，面积就不会改善
        // 移动较长一侧的指针，由于较短一侧仍然是瓶颈，面积不会改善
        if (height[left] <= height[right]) {
            // 左边的线较短（或相等），将左指针向右移动一位以寻求高度的改善
            left++;
        } else {
            // 右边的线较短，将右指针向左移动一位以寻求高度的改善
            right--;
        }
    }
    // 返回探索过程中记录的面积最大值
    return maxarea;
}
```
