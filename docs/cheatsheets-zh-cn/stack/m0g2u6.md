# Designing a Stack That Tracks the Minimum — 设计一个所有操作均为O(1)且能获取最小值的栈

## 问题的本质

设计一个栈，使其能够以O(1)的时间复杂度执行`push`、`pop`、`top`、`getMin`（获取当前最小值）这四种操作。普通栈获取最小值需要O(n)的时间复杂度，因此需要进行特殊设计。

## 核心思路

如果在栈的每个元素中同时保存"该时刻的最小值"，那么即使元素被pop出栈，最小值的信息也不会丢失。`getMin()`只需查看栈顶元素即可在O(1)时间内得到答案。

## 思考过程

1. **要使getMin达到O(1)，就必须始终掌握最小值**: 可以考虑用一个变量来管理最小值，但当pop操作移除了最小值时，就无法得知下一个最小值是什么。也就是说，需要一种机制来保存最小值的"历史记录"
2. **最小值的历史记录与栈的状态是联动的**: 每当栈中压入一个元素，最小值都可能发生变化。反之，当元素被pop出栈时，最小值会恢复到push之前的值。这种"恢复到push之前状态"的性质与栈本身的性质一致
3. **将每个元素与该时刻的最小值配对保存**: 在push时，将新值与当前最小值进行比较，将较小的一方作为"该时刻的最小值"与新值一起保存。这样即使元素被pop移除，下一个栈顶元素仍然持有正确的最小值
4. **确定配对的数据结构**: 使用`int[]`数组，`[0]`保存值，`[1]`保存该时刻的最小值。栈的类型为`Stack<int[]>`
5. **push时最小值的计算方法**: 如果栈为空，则新值本身即为最小值。如果栈不为空，则将新值与栈顶保存的最小值（`stack.peek()[1]`）进行比较，取较小的一方
6. **top、getMin、pop的实现**: `top()`返回栈顶配对的`[0]`，`getMin()`返回栈顶配对的`[1]`，均为O(1)。`pop()`与普通栈一样，只需移除栈顶元素即可

## 前置知识

### 什么是Stack

后进先出（LIFO）的数据结构。最后添加的元素最先被取出。在Java中使用泛型来指定存储的数据类型。

```java
Stack<int[]> stack = new Stack<>();  // 创建一个存储int数组的栈
stack.push(new int[]{1, 1});         // 将元素压入栈顶
stack.peek();                         // 查看栈顶元素但不移除 → [1, 1]
stack.pop();                          // 移除并返回栈顶元素 → [1, 1]
stack.isEmpty();                      // 返回boolean值表示栈是否为空 → true
```

### 什么是Math.min

接收两个整数并返回较小值的方法。每次push时用于比较新值与当前最小值。

```java
Math.min(3, 5);   // → 3
Math.min(-1, 0);  // → -1
```

## 复杂度

| | 值 |
|---|---|
| Time | O(1) — push、pop、top、getMin所有操作均在常数时间内完成 |
| Space | O(n) — 栈中最多保存n个配对 |

## 代码

```java
// 输入: push(val)、pop()、top()、getMin() 的操作序列
// 输出: top() 返回栈顶的值。getMin() 返回当前栈中的最小值
class MinStack {

    // Stack<int[]> 类型的字段。每个元素是长度为2的数组，[0] 保存值，[1] 保存该时刻整个栈的最小值
    private Stack<int[]> stack;

    public MinStack() {
        stack = new Stack<>();
    }

    public void push(int val) {
        // 如果栈为空，则 val 本身即为最小值。如果栈不为空，则与栈顶记录的最小值进行比较，取较小的一方
        int min = stack.isEmpty() ? val : Math.min(val, stack.peek()[1]);
        // 将值与最小值的配对 new int[]{val, min} 压入栈中。只要该元素位于栈顶，min 就是正确的最小值
        stack.push(new int[]{val, min});
    }

    public void pop() {
        // 移除栈顶的配对。移除后新的栈顶配对的 [1] 中保存着该元素被push时的正确最小值，因此最小值的一致性会自动维持
        stack.pop();
    }

    public int top() {
        // 配对的 [0] 中保存着值本身
        return stack.peek()[0];
    }

    public int getMin() {
        // 配对的 [1] 中保存着该时刻的最小值，因此无需遍历
        return stack.peek()[1];
    }
}
```
