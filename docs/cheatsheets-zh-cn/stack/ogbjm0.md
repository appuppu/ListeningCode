# Counting Car Fleets Arriving at a Destination — 求解到达目的地的车队数量

## 问题的本质

给定整数 `target`（目的地的位置）、整数数组 `position`（每辆车的当前位置）、整数数组 `speed`（每辆车的速度）。所有车都朝同一个目的地行驶。当快车追上前方的慢车时，快车会降速与慢车保持一致，作为一个车队（fleet）行驶。返回最终到达目的地的**车队数量**（整数）。

## 核心思路

从距离目的地最近的车开始依次处理，用栈管理每辆车的"到达目的地的时间"。如果后方车辆的到达时间小于等于前方车辆的到达时间，则合并为同一车队；如果大于前方车辆的到达时间，则判定为新的车队。最终栈的大小即为车队数量。

## 思考过程

1. **用到达时间判断车队是否合并**: 后方车辆是否能追上前方车辆，取决于它们到达目的地的时间。如果后方车辆的到达时间小于等于前方车辆的到达时间，则说明途中会追上，从而合并为同一车队。到达时间可以通过 `(target - position[i]) / speed[i]` 计算
2. **希望从距离目的地最近的车开始处理**: 车队的合并判断取决于"前方的车（距离目的地更近的车）是否构成障碍"，因此按照距离目的地从近到远排序后处理，就可以以前方车辆的到达时间为基准，依次判断后方车辆
3. **排序对象为索引数组**: 由于 position 和 speed 是两个独立的数组，因此创建一个索引数组，按 `position` 降序（距离目的地从近到远）排序。这样既不破坏原始数组，又能通过索引访问对应的 position 和 speed
4. **用栈管理车队**: 栈顶存储的是上一个车队的到达时间（即该车队最前方车辆的到达时间）。如果新车辆的到达时间小于等于栈顶值，则该车辆并入前方车队，不压入栈中。如果到达时间大于栈顶值，则形成新的车队，将其压入栈中
5. **栈的大小即为答案**: 合并的车辆不会被压入栈中，只有形成新车队的车辆才会被压入栈中，因此最终栈中的元素个数就是车队的数量

## 前置知识

### 到达时间的计算

当车辆当前位置为 `pos`、速度为 `speed`、目的地为 `target` 时，到达时间为 `(target - pos) / speed`。该值越小，表示越早到达。

```
例: target=12, pos=10, speed=2 时
到达时间 = (12 - 10) / 2 = 1.0
```

### Integer[] 的自定义排序

基本类型 `int[]` 无法使用 Lambda 表达式排序，因此需要创建 `Integer[]` 类型的索引数组，并向 `Arrays.sort` 传入 Comparator 进行排序。

```java
Integer[] idx = new Integer[n];
for (int i = 0; i < n; i++) idx[i] = i;
// 按pos降序（距离目的地从近到远）对索引进行排序
Arrays.sort(idx, (a, b) -> pos[b] - pos[a]);
```

### 什么是 Stack

Stack 是一种后进先出（LIFO）的数据结构。使用 `push` 压入元素，使用 `peek` 查看栈顶元素，使用 `pop` 弹出栈顶元素。在本题中，栈顶保存的是"上一个车队的到达时间"，作为合并判断的基准。

```java
Stack<Double> stack = new Stack<>();  // 创建一个空栈
stack.push(3.0);    // 将元素3.0压入栈顶
stack.peek();        // 查看栈顶元素但不弹出 → 3.0
stack.isEmpty();     // 判断栈是否为空 → false
stack.size();        // 返回栈中的元素个数 → 1
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n log n) — 索引数组排序需要O(n log n)，之后的遍历需要O(n) |
| Space | O(n) — 索引数组和栈各最多存储n个元素 |

## 代码

```java
// 输入: 整数 target（目的地的位置）、整数数组 pos（每辆车的位置）、整数数组 speed（每辆车的速度）
// 输出: 返回到达目的地的车队数量（整数）
public int carFleet(int target, int[] pos, int[] speed) {
    // 获取车辆数量
    int n = pos.length;

    // 创建 Integer[] 类型的索引数组，并用0到n-1的值进行初始化
    // 通过对索引数组排序，可以在保留原始数组的同时改变处理顺序
    Integer[] idx = new Integer[n];
    for (int i = 0; i < n; i++) {
        idx[i] = i;
    }

    // 按position降序（距离目的地从近到远）对索引数组进行排序
    // 从距离目的地最近的车开始处理，以便以前方车辆为基准进行合并判断
    Arrays.sort(idx, (a, b) -> pos[b] - pos[a]);

    // 用于保存每个车队到达时间的栈
    // 栈顶表示"上一个已确定车队的到达时间"
    Stack<Double> stack = new Stack<>();

    for (int i : idx) {
        // 计算该车辆到达目的地的时间
        // 如果不强制转换为double，整数除法会丢失小数部分
        double time = (double) (target - pos[i]) / speed[i];

        // 如果到达时间小于等于栈顶值，说明该车辆会追上前方车队，因此合并
        // 使用continue跳过压栈操作，继续处理下一辆车
        if (!stack.isEmpty() && time <= stack.peek()) {
            continue;
        }

        // 如果栈为空，或者time大于栈顶值，说明无法追上前方车队
        // 形成新的车队，将到达时间压入栈中
        stack.push(time);
    }

    // 栈中每个元素对应一个车队的到达时间，因此栈的大小就是车队的数量
    return stack.size();
}
```
