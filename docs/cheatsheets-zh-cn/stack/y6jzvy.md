# Finding How Many Days Until a Warmer Temperature — 求每天距离下一个更高气温的天数

## 问题的本质

给定一个整数数组 `temperatures`。对于每一天，计算在未来第几天会出现比当天更高的气温，并将结果以数组形式返回。如果未来不存在气温更高的天，则该天的答案为 `0`。

## 核心思路

将索引依次压入单调递减栈，栈中只保留"尚未找到比自身更暖天数的日子"。当新一天的气温高于栈顶所对应天的气温时，两者的索引之差就是"等待天数"。

## 思考过程

1. **需要为每一天找到"下一个气温更高的天"**：朴素的做法是从每一天向右线性搜索，但这样时间复杂度为 O(n²)。因此需要一种高效管理每天"未解决状态"的机制
2. **希望追踪"尚未确定答案的天"**：从左到右扫描数组时，将尚未找到比其气温更高的未来天数的日子作为"未解决的天"保留下来，这样当新的一天到来时就可以批量解决
3. **用栈来管理未解决的天**：将索引依次压入栈中。当新一天的气温高于栈顶所对应天的气温时，该未解决天的答案就确定了。栈始终保持气温从底到顶单调递减的顺序（较低的气温在栈顶）
4. **答案通过索引之差求得**：当未解决的天 `j` 被当前天 `i` 解决时，等待天数为 `i - j`。将该差值存入结果数组的第 `j` 个位置
5. **每个元素最多各执行一次 push 和 pop**：每个元素入栈一次，出栈也最多一次，因此包含 while 循环在内的整体处理次数为 O(n)

## 前置知识

### 什么是 Stack（栈）

后进先出（LIFO）的数据结构。最后添加的元素最先被取出。在 Java 中使用 `Stack<Integer>` 类。

```java
Stack<Integer> stack = new Stack<>();  // 创建一个空栈
stack.push(5);          // 将5压入栈顶
stack.peek();           // 返回栈顶元素但不移除 → 5
stack.pop();            // 移除并返回栈顶元素 → 5
stack.isEmpty();        // 返回栈是否为空的boolean值 → true
```

### 什么是单调栈（Monotonic Stack）

一种保证栈内元素始终保持单调递增或单调递减顺序的栈。本题使用**单调递减栈**。在添加新元素之前，将所有破坏栈内顺序的元素全部弹出，从而维持单调性。该模式适用于"查找下一个更大（更小）元素"的问题。

```java
// 单调递减栈的基本模式
// 栈内的气温从底到顶递减
// 例: 栈底[75, 71, 69]栈顶 ← 气温递减
// 当72到来时，弹出69和71并解决它们，栈变为[75, 72]
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 每个元素最多各执行一次 push 和 pop，因此整体为 O(n) |
| Space | O(n) — 栈中最多存储 n 个索引 |

## 代码

```java
// 输入: 整数数组 temperatures（每天的气温）
// 输出: 返回一个 int[]，存储每天距离下一个更高气温的天数
public int[] dailyTemperatures(int[] temperatures) {
    // 创建结果数组（Java 中 int[] 的初始值为0，因此未来没有更暖天数时答案默认为0）
    int[] result = new int[temperatures.length];
    // 用于存储尚未找到更暖天数的日子的索引的栈
    // 存储索引而非气温值的原因: 计算等待天数需要索引之差，且通过 temperatures[index] 即可获取气温值
    Stack<Integer> indexStack = new Stack<>();

    // 从索引 i = 0 到数组末尾逐一扫描
    for (int i = 0; i < temperatures.length; i++) {
        // 当前气温高于栈顶所对应天的气温时，解决未解决的天
        // 条件: 栈不为空 且 当前气温 > 栈顶索引所对应的气温
        while (!indexStack.isEmpty() && temperatures[i] > temperatures[indexStack.peek()]) {
            // 弹出栈顶的索引
            int stackTopIndex = indexStack.pop();
            // 等待天数 = 当前索引 - 等待中的天的索引
            result[stackTopIndex] = i - stackTopIndex;
        }
        // while 循环结束后（栈为空，或栈顶气温大于等于当前气温），将当前索引压入栈
        // 此时栈内保持单调递减的顺序
        indexStack.push(i);
    }

    // 栈中剩余的索引是"未来不存在更暖天数的日子"
    // 这些天的结果保持初始值0，因此无需额外处理
    return result;
}
```
