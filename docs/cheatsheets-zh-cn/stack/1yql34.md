# Finding the Largest Rectangle in a Histogram — 求直方图中能形成的最大矩形面积

## 问题的本质

给定一个非负整数数组 `heights`。每个元素表示直方图中柱子的高度，所有柱子的宽度均为1。求该直方图中能形成的**最大矩形面积**并返回。

## 核心思路

当将每根柱子作为"矩形的高度"时，如果能知道该柱子作为最矮柱子能向左右扩展到什么位置，就可以计算面积。使用单调递增栈，在柱子高度下降的瞬间，可以用O(1)的时间确定栈内柱子的可扩展宽度。

## 思考过程

1. **考虑以每根柱子为高度的矩形**: 任意矩形都可以视为"以某根柱子的高度为上限，由左右连续的柱子构成"。也就是说，对于每根柱子 `heights[i]`，如果知道"以该柱子为最矮柱子的区间宽度"，就可以用 `heights[i] × 宽度` 计算面积
2. **希望高效地求左右边界**: 对于每根柱子，如果知道"左侧第一根比自己矮的柱子的位置"和"右侧第一根比自己矮的柱子的位置"，就可以确定可扩展的宽度。对所有柱子暴力搜索这两个边界需要O(n²)，因此使用栈来优化
3. **使用单调递增栈**: 将柱子的索引按高度单调递增的方式压入栈中。当当前柱子的高度低于栈顶时，确定栈顶柱子的"右侧边界"为当前位置 `i`
4. **弹出时计算宽度**: 从栈中弹出柱子 `top` 时，右侧边界为当前位置 `i`，左侧边界为弹出后栈顶的下一个位置。如果栈为空，则可以扩展到左端（索引0），宽度为 `i`。如果栈不为空，宽度为 `i - stack.peek() - 1`
5. **在末尾添加高度0作为哨兵**: 到达数组末尾时，仍需计算栈中剩余柱子的面积。将循环范围设为 `i <= heights.length`，当 `i == heights.length` 时虚拟放置高度为0的柱子，从而保证栈内所有柱子都会被弹出
6. **追踪最大面积**: 每次弹出柱子时计算 `heights[top] × 宽度`，与当前最大值比较并更新。所有弹出操作完成时的最大值即为答案

## 前置知识

### Stack（栈）是什么

后进先出（LIFO）的数据结构。最后添加的元素最先被取出。在直方图问题中，将柱子的索引压入栈中，用于维护高度的单调性。

```java
Stack<Integer> stack = new Stack<>();  // 创建一个空栈
stack.push(0);       // 将值0添加到栈顶
stack.peek();        // 查看栈顶的值但不取出 → 0
stack.pop();         // 取出并返回栈顶的值 → 0
stack.isEmpty();     // 返回栈是否为空的boolean值 → true
```

### 单调递增栈（Monotonic Stack）是什么

栈内元素始终保持从底到顶递增（或相等）状态的栈。添加新元素时，如果新值小于栈顶，则持续弹出栈顶直到栈顶小于等于新值。弹出的瞬间可以解释为"该弹出元素的右侧边界已确定"。

```java
// 对数组 [2, 1, 5, 6, 2, 3] 的单调递增栈操作过程
// i=0: push(0)         → 栈: [0]       （高度: [2]）
// i=1: 1 < 2 所以pop   → 栈: []        （高度为2的柱子的右边界确定为i=1）
//       push(1)         → 栈: [1]       （高度: [1]）
// i=2: push(2)         → 栈: [1,2]     （高度: [1,5]）
// i=3: push(3)         → 栈: [1,2,3]   （高度: [1,5,6]）
// i=4: 2 < 6 所以pop   → 栈: [1,2]     （高度为6的柱子的右边界确定为i=4）
//       2 < 5 所以pop   → 栈: [1]       （高度为5的柱子的右边界确定为i=4）
//       push(4)         → 栈: [1,4]     （高度: [1,2]）
```

### 哨兵（Sentinel）是什么

为了简化循环终端处理而虚拟添加的值。在本问题中，在数组末尾虚拟放置高度为0的柱子，使循环结束时栈中剩余的所有柱子自然地被弹出。

```java
// 当 i == heights.length 时，超出实际数组范围，因此虚拟使用高度0
int h = (i == heights.length) ? 0 : heights[i];
// 高度0比任何柱子都矮，因此栈内所有柱子都会被弹出
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 每根柱子被压入栈一次、弹出栈一次，因此总共只需O(n)次操作 |
| Space | O(n) — 栈中最多存储n个索引 |

## 代码

```java
// 输入: 非负整数数组 heights（每个元素表示直方图中柱子的高度）
// 输出: 以 int 返回直方图中能形成的最大矩形面积
public int largestRectangleArea(int[] heights) {
    // 以单调递增方式保存柱子索引的栈
    Stack<Integer> stack = new Stack<>();
    // 记录目前为止找到的最大面积的变量
    int maxArea = 0;

    // 令 i <= heights.length 以包含哨兵的处理
    // 当 i == heights.length 时作为哨兵（高度0）将栈全部弹出
    for (int i = 0; i <= heights.length; i++) {
        // 哨兵: 超出数组末尾时使用高度0。高度0比任何柱子都矮，因此保证栈内所有柱子都会被弹出
        int h = (i == heights.length) ? 0 : heights[i];

        // 当当前高度低于栈顶柱子时，计算面积
        // 此条件维护了栈内的单调递增性
        while (!stack.isEmpty() && h < heights[stack.peek()]) {
            // 将弹出的柱子作为矩形的高度。该柱子的右侧边界为当前位置 i
            int top = stack.pop();

            // 计算宽度:
            // 栈为空 → top 柱子可以扩展到左端（索引0），因此宽度为 i
            // 栈不为空 → stack.peek() 是 top 左侧比 top 矮的柱子的索引（左侧边界），因此宽度为 i - stack.peek() - 1
            int w = stack.isEmpty() ? i : i - stack.peek() - 1;

            // 计算面积并更新最大值
            maxArea = Math.max(maxArea, heights[top] * w);
        }

        // 将当前索引压入栈以维护单调递增性
        stack.push(i);
    }
    // 所有弹出操作完成时的最大值即为答案
    return maxArea;
}
```
