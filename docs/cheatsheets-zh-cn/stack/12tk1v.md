# Checking if Parentheses Are Balanced — 判断括号字符串是否正确匹配

## 问题的本质

给定一个仅由 `(`、`)`、`{`、`}`、`[`、`]` 这6种括号构成的字符串。判断所有的开括号是否存在**正确顺序**对应的闭括号，返回 `true` 或 `false`。

## 核心思路

括号的匹配具有"最后打开的括号最先关闭"这一后进先出（LIFO）的结构。这一性质正是栈的本质，将开括号压入栈中，当遇到闭括号时与栈顶元素进行比对，即可验证括号是否正确匹配。

## 思考过程

1. **括号的匹配存在顺序要求**: `([)]` 中各括号的数量虽然相等，但顺序不正确。也就是说，存在"最内层的括号必须最先关闭"的规则。这是后进先出（LIFO）的结构，可以用栈自然地表达
2. **将开括号压入栈中**: 从字符串的开头逐字符扫描，遇到开括号（`(`、`{`、`[`）时将其 push 到栈中。栈顶始终是"最近打开的、尚未关闭的括号"
3. **遇到闭括号时与栈顶元素比对**: 遇到闭括号时，从栈中 pop 出开括号，确认其是否为对应的类型。如果不对应，则该字符串不合法
4. **栈为空时遇到闭括号则不合法**: 如果在 pop 之前栈已为空，说明不存在对应的开括号，因此返回 `false`
5. **扫描结束后栈为空则合法**: 处理完所有字符后，如果栈中仍残留开括号，说明存在未关闭的括号。栈为空则表示所有括号均已正确匹配

## 前置知识

### 什么是 Stack

后进先出（LIFO: Last In, First Out）的数据结构。最后添加的元素最先被取出。适用于像括号匹配检查这样需要从"最近的元素"开始依次处理的场景。

```java
Stack<Character> stack = new Stack<>();  // 创建一个空栈
stack.push('(');      // 将 '(' 添加到栈顶
stack.peek();         // 查看栈顶元素但不取出 → '('
stack.pop();          // 取出并返回栈顶元素 → '('
stack.isEmpty();      // 返回栈是否为空的 boolean 值 → true
```

### 括号的对应关系

3种括号各有开和闭的配对。当遇到闭括号时，需要确认栈顶是否为其对应的开括号。

```
')' 对应的开括号是 '('
'}' 对应的开括号是 '{'
']' 对应的开括号是 '['
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需对字符串进行一次扫描 |
| Space | O(n) — 栈中最多保存 n 个开括号 |

## 代码

```java
// 输入: 仅由括号构成的字符串 s
// 输出: 如果所有括号都正确匹配则返回 true，否则返回 false
public boolean isValid(String s) {
    // 保存"尚未关闭的开括号"的栈
    // 栈顶始终是最近打开的括号
    Stack<Character> stack = new Stack<>();

    // 从字符串开头逐字符扫描。toCharArray() 将字符串转换为 char 数组
    for (char c : s.toCharArray()) {
        // 如果是开括号则压入栈中。在对应的闭括号出现之前，它将一直留在栈中
        if (c == '(' || c == '{' || c == '[') {
            stack.push(c);
        } else {
            // 遇到闭括号但栈为空，说明不存在对应的开括号，因此不合法
            if (stack.isEmpty()) return false;

            // 从栈顶取出"最近打开的、尚未关闭的括号"
            char top = stack.pop();

            // 如果闭括号与开括号的类型不对应则不合法
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
            if (c == ')' && top != '(') return false;
        }
    }

    // 如果栈为空，说明所有括号都已正确匹配
    // 如果栈中仍有元素，说明存在未关闭的开括号，返回 false
    return stack.isEmpty();
}
```
