# Finding the Lowest Common Ancestor in a BST — 在BST中找到两个节点的最深公共祖先

## 问题的本质

给定一棵二叉搜索树（BST）以及树中存在的两个节点 `p` 和 `q`。返回同时将这两个节点作为子孙的最深节点（最近公共祖先：LCA）。节点本身也被视为自己的子孙。

## 核心思路

在BST中，左子孙全部小于当前节点，右子孙全部大于当前节点。当 `p` 和 `q` 相对于当前节点分别位于左右两侧时，该节点就是LCA。

## 思考过程

1. **可以利用BST的性质**：在BST中，对于任意节点，左子树的所有值 < 节点的值 < 右子树的所有值，这一顺序是有保证的。利用这一性质，仅通过比较节点的值就能判定 `p` 和 `q` 位于哪棵子树中
2. **如果两者都在左侧，则向左移动**：当 `p.val` 和 `q.val` 都小于当前节点的值时，`p` 和 `q` 都存在于左子树中。LCA也在该左子树中，因此移动到左子节点
3. **如果两者都在右侧，则向右移动**：当 `p.val` 和 `q.val` 都大于当前节点的值时，`p` 和 `q` 都存在于右子树中。LCA也在该右子树中，因此移动到右子节点
4. **如果分别位于左右两侧，则当前节点就是LCA**：当 `p` 和 `q` 分别位于当前节点的左右两侧时（一个较小，另一个较大），不可能有更深的单一子树同时包含两者。因此当前节点就是LCA。当 `p` 或 `q` 等于当前节点时，由于节点本身被视为自己的子孙，该节点也是LCA
5. **可以用迭代代替递归来实现**：由于每一步只朝左或右一个方向前进，因此不需要递归的调用栈。只需用while循环不断更新当前节点即可，空间复杂度可以降为O(1)

## 前置知识

### 什么是二叉搜索树（BST）

一种每个节点都满足"左子孙 < 自身 < 右子孙"这一顺序的二叉树。利用这一性质，仅通过值的大小比较就能判定节点属于哪棵子树。

```
        6
       / \
      2    8
     / \  / \
    0   4 7   9
```

在这棵树中，节点2和节点8的LCA是6。节点2和节点4的LCA是2（节点2也是自身的子孙）。

### 什么是最近公共祖先（LCA）

两个节点 `p` 和 `q` 的公共祖先中最深的（离根最远的）节点。当 `p` 或 `q` 本身是另一个节点的祖先时，该节点本身就是LCA。

### TreeNode 的结构

表示BST中每个节点的类。具有值 `val`、左子节点 `left`、右子节点 `right`。

```java
TreeNode node = new TreeNode(6);   // 创建值为6的节点
node.val;                           // 获取节点的值 → 6
node.left;                          // 获取左子节点
node.right;                         // 获取右子节点
```

## 复杂度

| | 值 |
|---|---|
| Time | O(h) — 搜索树的高度次。若为平衡BST则为O(log n) |
| Space | O(1) — 由于使用迭代处理，不使用额外的内存 |

## 代码

```java
// 输入：BST的根节点 root、树中存在的两个节点 p 和 q
// 输出：返回 p 和 q 的最近公共祖先（LCA）对应的 TreeNode
TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    // 将当前搜索位置初始化为根节点。通过while循环进行更新
    TreeNode node = root;

    // 当node不为null时，重复搜索
    while (node != null) {
        // 判断p和q是否都小于当前节点
        if (p.val < node.val && q.val < node.val) {
            // 两者都存在于左子树中，因此LCA也在左子树中
            node = node.left;
        // 判断p和q是否都大于当前节点
        } else if (p.val > node.val && q.val > node.val) {
            // 两者都存在于右子树中，因此LCA也在右子树中
            node = node.right;
        } else {
            // p和q分别位于左右两侧（或其中一个等于当前节点）
            // 不可能有更深的单一子树同时包含两个节点，因此确定LCA
            return node;
        }
    }
    // 根据问题的约束条件，p和q存在于树中，因此必定在上面的return处结束，不会到达此处
    return null;
}
```
