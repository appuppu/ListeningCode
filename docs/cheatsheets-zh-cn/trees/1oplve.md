# Finding the Diameter of a Binary Tree — 求二叉树中最长路径的边数

## 问题本质

给定一棵二叉树的 `root`。返回树中任意两个节点之间最长路径的长度（边数）。该路径不一定经过根节点。

## 核心思路

在任意节点处，"左子树的高度 ＋ 右子树的高度 ＋ 2"即为经过该节点的最长路径的边数。在 DFS 中求每个节点的高度的同时，追踪该值的最大值，就能在一次遍历中求出直径。

## 思考过程

1. **直径必定经过某个节点作为"顶点"**: 最长路径一定以某个节点作为最高位置（折返点），从该节点的左子树中的某个节点延伸到右子树中的某个节点。因此，对每个节点求"以该节点为顶点的路径长度"，取其最大值即为直径
2. **经过顶点的路径长度由左右子树的高度决定**: 以某个节点为顶点的路径边数可以用"左子树的高度 ＋ 右子树的高度 ＋ 2"来计算。左子树的高度表示到最深左侧节点的边数，右子树的高度表示到最深右侧节点的边数，由于从顶点到左右子节点各需加 1 条边，所以要加 2
3. **将高度的定义统一为"边数"**: 将节点的高度定义为"从该节点到最远叶子节点的边数"，则叶子节点的高度为 0，null 节点的高度为 -1。将 null 定义为 -1，叶子节点的高度就可以自然地计算为 `1 + max(-1, -1) = 0`
4. **在 DFS 中返回高度的同时更新直径**: 使用后序遍历（Post-order）的 DFS，在每个节点递归获取左右子节点的高度。根据获取的左右高度计算"以该节点为顶点的路径长度"，更新全局变量 `maxDiameter`，返回值则为该节点自身的高度 `1 + max(left, right)`
5. **用全局变量追踪最大值**: DFS 的返回值是"高度"而非"直径"，因此直径的最大值记录在全局变量 `maxDiameter` 中。在每个节点处比较 `left + right + 2` 和当前的 `maxDiameter`，保留较大的值
6. **最终返回的结果**: DFS 遍历完所有节点后，`maxDiameter` 中存储的值就是整棵树的直径

## 前置知识

### 二叉树的高度（height）

从某个节点到最远叶子节点的路径中包含的边数。叶子节点的高度定义为 0，null 节点的高度定义为 -1。父节点的高度通过 `1 + max(左子节点的高度, 右子节点的高度)` 求得。

```
      1          节点1的高度: 2（1→2→4 的边数）
     / \         节点2的高度: 1（2→4 的边数）
    2   3        节点3的高度: 0（叶子节点）
   /             节点4的高度: 0（叶子节点）
  4
```

### 基于递归的 DFS（深度优先搜索）

递归访问树中每个节点的方法。后序遍历（Post-order）按照左子节点→右子节点→自身的顺序进行处理。适用于需要利用子节点的结果来计算父节点的值的情况。

```java
int dfs(TreeNode node) {
    if (node == null) return -1;   // 基本情况: null节点的高度为-1
    int left = dfs(node.left);     // 递归处理左子树
    int right = dfs(node.right);   // 递归处理右子树
    return 1 + Math.max(left, right);  // 计算并返回自身的高度
}
```

### Math.max

返回两个值中较大值的 Java 标准方法。

```java
Math.max(3, 5);    // → 5
Math.max(-1, -1);  // → -1
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需进行一次访问所有节点各一次的 DFS |
| Space | O(n) — 递归调用的调用栈最大为 n 层（在树退化为链表的情况下） |

## 代码

```java
// 输入: 二叉树的根节点 root
// 输出: 以 int 形式返回树的直径（任意两个节点之间最长路径的边数）

// 在 DFS 遍历过程中保存已发现的最大直径的全局变量
// 初始值为0，因为只有一个节点的树的直径为0
int maxDiameter = 0;

// 返回每个节点的高度，同时作为副作用更新 maxDiameter 的递归函数
int dfs(TreeNode node) {
    // null节点的高度为-1（表示不存在边）
    // 返回-1使得父节点（叶子节点）的高度能正确计算为 1 + max(-1, -1) = 0
    if (node == null) return -1;

    // 递归获取左子树的高度
    int left = dfs(node.left);
    // 递归获取右子树的高度
    int right = dfs(node.right);

    // 用以当前节点为顶点的路径边数（left + right + 2）更新直径的最大值
    // +2 是因为要加上从当前节点到左右子节点的2条边
    maxDiameter = Math.max(
        maxDiameter,
        left + right + 2);

    // 将当前节点的高度返回给父节点（注意这是高度而非直径）
    // 该值用于父节点计算其自身的路径长度
    return 1 + Math.max(left, right);
}

public int diameterOfBinaryTree(TreeNode root) {
    // 通过 DFS 遍历所有节点，根据以每个节点为顶点的路径长度更新 maxDiameter
    dfs(root);
    // 遍历完成后的 maxDiameter 即为整棵树的直径
    return maxDiameter;
}
```
