# 求二叉树的最大深度 — 求从根节点到最远叶子节点路径上的节点数

## 问题的本质

给定一棵二叉树的 `root` 节点。返回从根节点到最远叶子节点的路径上包含的**节点数**（最大深度），以整数形式返回。如果树为空（root 为 null），则返回 0。

## 核心思想

树的最大深度等于「左子树的最大深度」和「右子树的最大深度」中较大的一方加上 1（当前节点）。这个递归定义本身就是解法。

## 思考过程

1. **树的深度可以递归定义**：某个节点的深度取决于以其左右子节点为根的子树的深度。也就是说，问题可以分解为结构相同的更小的子问题
2. **确定基准情形**：当节点为 null 时，该处不存在任何节点，因此深度为 0。这就是递归的终止条件
3. **分别求左右子树的深度**：从当前节点递归到左子节点，获得左子树的最大深度。同样递归到右子节点，获得右子树的最大深度
4. **合并左右的结果**：最大深度即最长路径，因此选择左右深度中较大的一方。通过 `Math.max(left, right)` 获取
5. **加上当前节点后返回**：在左右深度的最大值上加 1，将包含当前节点的深度返回给父节点。这个 1 代表的是「当前节点本身」

## 前置知识

### TreeNode（二叉树节点）

表示二叉树中每个节点的类。包含三个字段：值 `val`、左子节点 `left`、右子节点 `right`。当子节点不存在时，其值为 null。

```java
public class TreeNode {
    int val;              // 节点存储的值
    TreeNode left;        // 左子节点（不存在时为null）
    TreeNode right;       // 右子节点（不存在时为null）
}
```

### 递归（Recursion）

函数调用自身的技术。在树结构中，用于对每个节点的子树执行相同的处理。必须定义基准情形（终止递归的条件），以防止无限循环。

```java
// 递归的基本结构
public int recursive(TreeNode node) {
    if (node == null) return 0;           // 基准情形：递归的终止条件
    return recursive(node.left);          // 递归调用：求解子问题
}
```

### Math.max

返回两个整数中较大值的 Java 标准方法。

```java
Math.max(3, 5);    // → 5
Math.max(0, 0);    // → 0
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 每个节点恰好访问一次 |
| Space | O(h) — 递归调用栈的深度等于树的高度。最坏情况（退化树）下为 O(n) |

## 代码

```java
// 输入：二叉树的根节点 root（TreeNode 类型，可能为 null）
// 输出：返回表示树的最大深度的整数
public int maxDepth(TreeNode root) {
    // 基准情形：如果节点不存在，则深度为0
    // 当到达叶子节点的子节点（null）时，递归终止
    if (root == null) return 0;

    // 递归求左子树的最大深度
    // 对以左子节点为根的子树重复执行相同处理，最终到达基准情形并返回值
    int left = maxDepth(root.left);

    // 递归求右子树的最大深度
    // 与左子树同理，求以右子节点为根的子树的深度
    int right = maxDepth(root.right);

    // 取左右中较深的一方，加上当前节点的1后返回
    // Math.max(left, right) 选择路径上节点数更多的较深子树
    // +1 表示计入当前节点 root 本身。父节点接收此返回值，用于自身的计算
    return 1 + Math.max(left, right);
}
```
