# Counting Good Nodes in a Binary Tree — 计算二叉树中"好节点"的数量

## 问题的本质

给定一棵二叉树。从根节点到某个节点的路径上，如果该节点的值大于或等于路径上所有节点的最大值，则该节点被视为"好节点（good node）"。要求返回整棵树中好节点的数量。

## 核心思路

在从根节点向各个节点遍历的过程中，只要携带"到目前为止的最大值"，就能以O(1)的时间复杂度判定每个节点是否为好节点。通过DFS遍历整棵树，并将最大值传播给子节点，只需访问每个节点一次即可求得答案。

## 思考过程

1. **整理判定条件**: 判定某个节点是否为好节点，只需将其与从根节点到该节点的路径上的最大值进行比较。也就是说，只要知道路径上的最大值就能完成判定
2. **如何管理路径上的最大值**: 使用DFS遍历树时，递归调用栈对应从根节点到当前节点的路径。将"到目前为止的最大值"作为递归参数传递，就能在每个节点获取判定所需的信息
3. **确定每个节点的处理方式**: 如果当前节点的值大于或等于最大值，则该节点是好节点，将1加入结果；否则加入0。这样就能同时完成判定和计数
4. **更新传递给子节点的最大值**: 传递给子节点的最大值取当前最大值与当前节点值中的较大者。这样随着路径的延伸，最大值将以单调非递减的方式更新
5. **递归处理左右子树**: 通过递归分别求出左子树和右子树的好节点数量，再与当前节点的结果相加后返回
6. **初始调用的最大值**: 根节点始终是好节点（路径上只有自身）。将初始值设为 `Integer.MIN_VALUE`，根节点的值必然大于或等于该值，因此能够正确判定

## 前置知识

### 什么是递归DFS（深度优先搜索）

DFS是一种优先向深处方向遍历树或图的算法。在二叉树中，递归函数对左子节点和右子节点分别调用自身来实现遍历。递归调用栈隐式地保存了从根节点到当前节点的路径。

```java
void dfs(TreeNode node) {
    if (node == null) return;  // 基本情况: 到达null节点时返回
    // 对当前节点进行处理
    dfs(node.left);            // 递归遍历左子树
    dfs(node.right);           // 递归遍历右子树
}
```

### 什么是 Math.max

Math.max 是一个返回两个值中较大值的方法。在更新路径上的最大值时使用。

```java
Math.max(5, 3);    // → 5（返回5和3中的较大值）
Math.max(-1, 4);   // → 4
```

### 什么是 Integer.MIN_VALUE

Integer.MIN_VALUE 是Java中 `int` 类型能表示的最小值（-2,147,483,648）。由于任何节点的值都大于或等于该值，因此将其作为初始最大值可以确保根节点始终被判定为好节点。

```java
Integer.MIN_VALUE;  // → -2147483648（int类型的最小值）
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 每个节点恰好访问一次 |
| Space | O(h) — 递归调用栈占用与树的高度相当的空间 |

## 代码

```java
// 输入: 二叉树的根节点 root
// 输出: 以 int 类型返回好节点的总数

// 辅助函数: 返回以 node 为根的子树中好节点的数量
// maxSoFar 表示从根节点到当前节点的路径上的最大值
private int dfs(TreeNode node, int maxSoFar) {
    // 基本情况: 到达null时好节点数量为0（已超出叶节点，没有需要计数的节点）
    if (node == null) return 0;

    // 判定当前节点是否为好节点（如果大于或等于路径上的最大值，则为好节点）
    int result = node.val >= maxSoFar ? 1 : 0;

    // 更新传递给子节点的最大值（如果当前节点的值更大则更新，否则沿用之前的最大值）
    int newMax = Math.max(maxSoFar, node.val);

    // 递归求出左子树的好节点数量并累加
    result += dfs(node.left, newMax);
    // 递归求出右子树的好节点数量并累加
    result += dfs(node.right, newMax);

    // 返回以当前节点为根的整棵子树的好节点数量
    return result;
}

public int goodNodes(TreeNode root) {
    // 将初始最大值设为int最小值，以确保根节点始终被判定为好节点
    return dfs(root, Integer.MIN_VALUE);
}
```
