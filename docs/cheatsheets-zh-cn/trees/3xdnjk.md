# Checking if a Binary Tree is Height-Balanced — 判断二叉树是否高度平衡

## 问题的本质

给定二叉树的根节点 `root`，判断该树是否为**高度平衡（height-balanced）**二叉树。高度平衡是指对于所有节点，其左子树的高度与右子树的高度之差不超过1。返回 `boolean` 类型的结果。

## 核心思路

在递归计算每个节点高度的过程中，一旦检测到不平衡，立即返回 `-1` 并向上传播。将高度计算与平衡判断合并到一次后序遍历（post-order traversal）中同时完成，这样只需访问每个节点一次即可得出答案。

## 思考过程

1. **递归地理解平衡的定义**：树是平衡的，意味着对于所有节点，其左右子树的高度差不超过1。也就是说，判断某个节点是否平衡，需要知道其左右子树的「高度」
2. **高度的计算本身就是递归的**：某个节点的高度为 `1 + max(左子树高度, 右子树高度)`。通过这个递归从下往上（以 post-order 方式）遍历树，可以自然地求出每个节点的高度
3. **将高度计算与平衡判断整合在一起**：在返回高度的递归函数中，当左右子树的高度差超过1时，返回表示「不平衡」的特殊值 `-1`。这样就可以在一个函数中同时完成高度计算和平衡判断
4. **通过提前终止避免不必要的搜索**：如果左子树的结果为 `-1`，则无需检查右子树，整棵树已经不平衡。每次检查递归的返回值是否为 `-1`，一旦发现不平衡就立即返回 `-1`，终止递归
5. **利用返回值的双重含义**：返回值为 `0以上` 表示正常的高度，为 `-1` 表示不平衡。调用方的 `isBalanced` 方法只需确认最终返回值是否不为 `-1`，即可得出答案

## 前置知识

### 二叉树的高度（height）

从某个节点到最远叶子节点的边数。叶子节点的高度为1（按节点数计算），`null` 的高度为0。递归定义为 `height(node) = 1 + max(height(node.left), height(node.right))`。

```
        1           节点1的高度: 3
       / \          节点2的高度: 2
      2   3         节点4的高度: 1
     /              节点3的高度: 1
    4
```

### 后序遍历（Post-Order Traversal）

按照左子树 → 右子树 → 当前节点的顺序处理节点的遍历方法。由于先确定子节点的信息再处理父节点，因此适合「利用子节点的高度来计算父节点的高度」这类自下而上的聚合处理。

```java
void postOrder(TreeNode node) {
    if (node == null) return;
    postOrder(node.left);   // 先处理左子树
    postOrder(node.right);  // 再处理右子树
    // 在这里处理当前节点（左右子树的结果已经确定）
}
```

### Math.abs

返回整数绝对值的Java标准方法。用于判断左右子树的高度差无论正负是否不超过1。

```java
Math.abs(3 - 1);    // → 2
Math.abs(1 - 3);    // → 2
Math.abs(2 - 3);    // → 1
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 每个节点访问一次 |
| Space | O(n) — 递归调用的调用栈最大为n层（树退化为链表的情况） |

## 代码

```java
// 输入: 二叉树的根节点 root
// 输出: 如果树是高度平衡的返回 true，否则返回 false

// 返回节点高度的递归函数。检测到不平衡时返回哨兵值 -1
// 返回值为 0以上 表示正常高度，-1 表示「某个子树不平衡」
private int checkHeight(TreeNode node) {
    // 基本情况: null 表示空子树，高度为0
    if (node == null) return 0;

    // 递归求左子树的高度（后序遍历中「先处理左子树」的部分）
    int left = checkHeight(node.left);
    // 如果左子树不平衡，不再检查右子树，立即传播 -1（提前终止）
    if (left == -1) return -1;

    // 递归求右子树的高度（后序遍历中「再处理右子树」的部分）
    int right = checkHeight(node.right);
    // 如果右子树不平衡，立即传播 -1
    if (right == -1) return -1;

    // 当前节点的左右子树高度差超过1则不平衡（后序遍历中「处理当前节点」的部分）
    // 使用 Math.abs，无论左右哪边更高都能正确判断高度差
    if (Math.abs(left - right) > 1)
        return -1;

    // 如果平衡，返回当前节点的高度，供父节点的计算使用
    return 1 + Math.max(left, right);
}

public boolean isBalanced(TreeNode root) {
    // 如果 checkHeight 的返回值不为 -1，则整棵树是平衡的
    // -1 是表示「某个子树不平衡」的哨兵值
    return checkHeight(root) != -1;
}
```
