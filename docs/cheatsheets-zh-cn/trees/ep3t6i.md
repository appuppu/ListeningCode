# 从右侧观察二叉树 — 返回从右侧观察二叉树时可见的节点值

## 问题的本质

给定一棵二叉树的 `root`。从右侧观察这棵树时，每个深度只能看到最右边的节点。要求按照从上（root）到下的顺序，返回这些节点值组成的 `List<Integer>`。

## 核心思路

如果在DFS中优先访问右子节点，那么在每个深度最先到达的节点一定是"从右侧可见的节点"。只需比较深度与结果列表的大小，就能判断该节点是否是该深度的首次访问。

## 思考过程

1. **什么是从右侧可见的节点**: 在每个深度中位于最右边的节点就是"从右侧可见的节点"。也就是说，问题可以归结为在每个深度各选择一个节点
2. **考虑优先访问右子节点的DFS**: 在用DFS遍历树时，如果将右子节点的递归调用放在左子节点之前，就能在每个深度最先到达最右边的节点。利用这个性质，只需记录每个深度首次访问的节点即可
3. **如何判断"某深度的首次访问"**: 结果列表 `result` 的大小表示"迄今为止已记录的深度数量"。如果当前的 `depth` 等于 `result.size()`，则意味着该深度的节点尚未被记录。仅在满足此条件时执行 `result.add(node.val)`
4. **递归的结构**: 在每个节点处按照"如果是新深度则记录值"→"递归访问右子节点"→"递归访问左子节点"的顺序进行处理。由于优先访问右子节点，右侧的节点会在每个深度被优先记录
5. **基本情况**: 当节点为 `null` 时，直接 `return` 不做任何操作。这样超过叶节点的递归会自然终止
6. **最终返回值**: DFS完成后，`result` 列表中按照深度0开始的顺序存储了从右侧可见的节点值。直接返回该列表即可

## 前置知识

### 什么是DFS（深度优先搜索）

DFS是遍历树或图的算法之一。从某个节点出发，尽可能深入地前进，然后回溯（backtrack）。使用递归可以自然地实现DFS。

```java
void dfs(TreeNode node) {
    if (node == null) return;  // 基本情况：如果为null则不做任何操作
    // 在此处对node执行处理
    dfs(node.left);   // 递归遍历左子节点
    dfs(node.right);  // 递归遍历右子节点
}
```

### List 的 size() 和 add()

`List` 是可变长度的数组。`size()` 返回当前的元素个数，`add()` 在末尾追加元素。元素按照添加顺序依次排列在索引0, 1, 2...的位置。

```java
List<Integer> list = new ArrayList<>();  // 创建空列表
list.size();      // 返回当前元素个数 → 0
list.add(5);      // 在末尾追加5 → [5]
list.add(3);      // 在末尾追加3 → [5, 3]
list.size();      // → 2
```

### 什么是depth（深度）

深度是指从树的根节点到该节点的边数。根节点的深度为0，根节点的子节点深度为1，孙节点的深度为2。在递归调用时传递 `depth + 1`，即可追踪每个节点的深度。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 每个节点恰好访问一次 |
| Space | O(h) — 递归调用栈需要与树的高度相同的空间（h为树的高度） |

## 代码

```java
// 输入: 二叉树的根节点 root
// 输出: 按从上到下的顺序存储从右侧可见的节点值的 List<Integer>
List<Integer> rightSideView(TreeNode root) {
    // 存储每个深度最右节点值的列表
    // 列表的索引对应深度（index 0 = depth 0）
    List<Integer> result = new ArrayList<>();
    dfs(root, 0, result);
    // DFS完成后，result中按照深度0开始的顺序存储了从右侧可见的节点值
    return result;
}

void dfs(TreeNode node, int depth,
         List<Integer> result) {
    // 基本情况：如果为null则不做任何操作（超过叶节点的不存在的子节点的递归在此终止）
    if (node == null) return;

    // 如果 depth == result.size()，则该深度的节点尚未被记录
    // result.size() 表示"迄今为止已记录的深度数量"
    if (depth == result.size()) {
        // 由于DFS优先访问右子节点，每个深度最先到达的节点一定是最右边的节点
        result.add(node.val);
    }

    // 通过优先访问右子节点，每个深度的最右节点会被最先记录
    // 这是本算法的核心：按照右→左的顺序访问
    dfs(node.right, depth + 1, result);
    // 在右子节点不存在的深度，左子节点将成为"该深度首次被访问的节点"，从而被正确记录
    dfs(node.left, depth + 1, result);
}
```
