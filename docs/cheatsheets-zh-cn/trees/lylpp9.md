# Finding the Kth Smallest Element in a BST — 在BST中查找第k小的元素

## 问题的本质

给定一棵二分搜索树（BST）的根节点 `root` 和一个整数 `k`。要求返回BST中所有节点值中**第k小的值**。题目保证树中至少存在k个节点。

## 核心思路

对BST进行中序遍历（in-order traversal）时，节点的值会按升序排列。因此，中序遍历中第k个被访问的节点的值就是答案。不需要遍历所有节点，到达第k个节点时即可立即终止。

## 思考过程

1. **利用BST的性质**: 在BST中，对于任意节点，「左子树的所有节点 < 自身 < 右子树的所有节点」成立。根据这一性质，进行中序遍历（左→自身→右）可以按升序获取节点的值
2. **第k小的值就是中序遍历的第k个元素**: 中序遍历得到的升序序列中第k个元素就是答案，因此在遍历过程中进行计数即可
3. **选择使用栈的迭代遍历而非递归**: 使用递归时，即使到达第k个节点也无法立即return（需要回溯调用栈）。使用栈的迭代遍历则可以在找到第k个节点的瞬间通过return退出
4. **使用栈实现中序遍历的方法**: 从当前节点不断沿左子节点向下并压入栈中。到达最左端后从栈中pop，将该节点视为「已访问」。然后移动到右子节点并重复相同的处理
5. **使用计数器检测第k个节点**: 每次pop并访问一个节点时将k递减。当k变为0时，该节点的值就是答案
6. **最终返回值**: 返回k变为0时的节点值 `curr.val`

## 前置知识

### BST（二分搜索树）的中序遍历

中序遍历是按「左子树→自身→右子树」的顺序访问二分搜索树的遍历方法。对BST进行中序遍历时，节点的值会按升序（从小到大）排列。

```
例:     5
       / \
      3   7
     / \
    2   4

中序遍历的结果: 2, 3, 4, 5, 7（升序）
```

### Stack（栈）

栈是一种后进先出（LIFO）的数据结构。最后添加的元素会最先被取出。在中序遍历中，栈用于记录沿左子节点向下过程中经过的父节点。

```java
Stack<TreeNode> stack = new Stack<>();  // 创建一个空栈
stack.push(node);      // 将node添加到栈顶
stack.pop();           // 取出并返回栈顶元素
stack.isEmpty();       // 返回boolean值，表示栈是否为空
```

### 迭代式中序遍历的模式

使用栈的中序遍历重复执行「向左端深入→pop并访问→移动到右子节点」。循环的继续条件是「当前节点不为null」或「栈不为空」，只要其中之一为真就继续执行。

```java
TreeNode curr = root;
while (curr != null || !stack.isEmpty()) {
    while (curr != null) {       // 向左端深入
        stack.push(curr);
        curr = curr.left;
    }
    curr = stack.pop();          // 访问（此处按升序获取节点）
    curr = curr.right;           // 移动到右子节点
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(h + k) — 向左端下降h次，pop k个节点 |
| Space | O(h) — 栈中最多存储树的高度h个节点 |

## 代码

```java
// 输入: 二分搜索树的根节点 root 和整数 k
// 输出: 返回BST中第k小的节点值，类型为 int
public int kthSmallest(TreeNode root, int k) {
    // 用于临时保存沿左子节点向下过程中经过的父节点，以便之后返回的栈
    Stack<TreeNode> stack = new Stack<>();
    // 指向当前关注节点的指针
    TreeNode curr = root;

    // 即使curr为null，只要栈中还有节点就说明存在未访问的节点，继续执行
    while (curr != null || !stack.isEmpty()) {
        // 向左端深入，将经过的节点压入栈中（到达当前子树的最小值）
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }

        // pop出的节点是中序遍历中下一个应该访问的节点（未访问节点中持有最小值的节点）
        curr = stack.pop();
        // pop相当于在中序遍历中访问了一个节点，因此将剩余访问次数减1
        k--;

        // 当k变为0时，该节点就是第k小的元素，立即返回其值并终止
        if (k == 0)
            return curr.val;

        // 如果存在右子树，下一次迭代将向其左端深入。如果不存在，curr变为null，从栈中pop父节点
        curr = curr.right;
    }
    // 根据题目约束，树中至少存在k个节点，因此不会到达此处
    return -1;
}
```
