# Inverting a Binary Tree — 交换二叉树所有节点的左右子节点

## 问题的本质

给定二叉树的根节点 `root`。需要将树的**所有节点**的左子节点和右子节点进行交换（反转），并返回反转后的树的根节点。

## 核心思路

二叉树的反转是指对所有节点交换其左右子节点的操作。使用BFS按层级顺序访问所有节点，并对每个节点交换其左右子节点，即可完成整棵树的反转。

## 思考过程

1. **理解反转的定义**: 二叉树的反转不仅仅是交换根节点的左右子节点，而是要对所有节点都执行左右子节点的交换操作。也就是说，只需逐一访问树的所有节点，并对每个节点执行交换处理即可
2. **选择访问所有节点的方法**: 选择BFS（广度优先搜索）来访问树的所有节点。BFS使用队列按层级顺序处理节点，实现方式直观且易于理解
3. **确定每个节点的操作**: 对从队列中取出的每个节点，使用临时变量交换其 `left` 和 `right`。交换的顺序无关紧要，即使子节点为null，交换操作本身也不会产生问题
4. **将子节点添加到队列中**: 交换后的左右子节点如果不为null，则将其添加到队列中。这样可以依次访问树的下层节点，确保所有节点都执行交换操作
5. **最终返回值**: 所有节点的交换完成后，直接返回原来的根节点 `root`。虽然树的结构发生了变化，但根节点本身仍然是同一个对象

## 前置知识

### 二叉树（Binary Tree）

每个节点最多拥有两个子节点（左子节点 `left` 和右子节点 `right`）的树结构。节点使用 `TreeNode` 类表示，包含 `val`（值）、`left`（左子节点）、`right`（右子节点）三个字段。

```java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

### Queue（队列）

先进先出（FIFO）的数据结构。最先添加的元素最先被取出。在BFS中使用队列来管理待访问的节点。

```java
Queue<TreeNode> queue = new LinkedList<>();  // 创建空队列
queue.add(node);     // 将node添加到队列末尾
queue.poll();        // 取出并返回队列头部的元素
queue.isEmpty();     // 返回队列是否为空的boolean值 → true/false
```

### BFS（广度优先搜索）

按"层级顺序"搜索树或图的算法。使用队列，在处理当前节点后将其子节点添加到队列中，从而按从浅层到深层的顺序依次访问所有节点。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 访问树的所有节点各一次 |
| Space | O(n) — 队列中最多存储n个节点 |

## 代码

```java
// 输入: 二叉树的根节点 root
// 输出: 返回所有节点的左右子节点交换后的根节点 root
public TreeNode invertTree(TreeNode root) {
    // 如果树为空则返回null。因为树不存在，直接结束
    if (root == null) return null;

    // 创建BFS用的队列，并将根节点添加到队列中
    // 该队列用于管理接下来需要执行左右交换的节点
    Queue<TreeNode> queue = new LinkedList<>();
    queue.add(root);

    // 循环直到队列为空（即所有节点都已处理完毕）
    while (!queue.isEmpty()) {
        // 从队列头部取出待交换的节点
        TreeNode curr = queue.poll();

        // 使用临时变量交换左右子节点
        // 注意: 如果不使用临时变量而直接赋值，会导致其中一个引用被覆盖而丢失
        TreeNode temp = curr.left;
        curr.left = curr.right;
        curr.right = temp;

        // 如果交换后的子节点不为null，则将其添加到队列中
        // 值为null的节点没有需要进一步处理的子节点，因此无需添加
        if (curr.left != null) queue.add(curr.left);
        if (curr.right != null) queue.add(curr.right);
    }

    // 返回所有节点交换完成后的根节点
    // 虽然树的结构发生了变化，但根节点本身仍然是同一个对象
    return root;
}
```
