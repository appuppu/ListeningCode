# Finding the Maximum Path Sum in a Binary Tree — 求二叉树中任意路径的最大总和

## 问题的本质

给定一棵二叉树。每个节点持有一个整数值（可能为负值）。在由边连接的任意路径（每个节点最多使用一次）中，找到节点值总和最大的路径，并返回该**总和值**。路径不必经过根节点，可以是从任意节点到任意节点的路径。

## 核心思路

在每个节点处计算"从左子孙获得的最大收益"和"从右子孙获得的最大收益"，将以该节点为顶点、连接左右两侧的路径总和作为全局最大值的候选。另一方面，返回给父节点的值只能选择左右其中一条分支（因为路径不能分叉）。

## 思考过程

1. **考虑路径的结构**：任意路径中必然存在一个"位于最高位置的节点（顶点）"。从该节点来看，路径由"向左子孙延伸的部分"、"自身"、"向右子孙延伸的部分"三部分组成。尝试将所有节点作为顶点，求出最大的路径总和即可
2. **定义每个节点的收益（gain）**：将以某个节点为根的子树中，能够向父方向带回的最大总和值称为"收益"。收益的计算方式为"自身的值 + 左右子节点中较大一方的收益"。由于路径不能分叉，因此不能同时将左右两方的收益返回给父节点
3. **将负收益视为0**：当子节点的收益为负时，包含该分支会导致路径总和减少。因此使用 `Math.max(0, gain)` 将负收益截断为0（即不使用该分支）。这样可以自然地表示仅包含单个节点的路径或只使用一侧分支的路径
4. **单独管理全局最大值**：以每个节点为顶点的"左收益 + 自身的值 + 右收益"即为经过该节点的最大路径总和。将该值与全局变量 `maxSum` 进行比较并更新。由于这与返回给父节点的收益是不同的计算，因此需要独立管理
5. **使用后序DFS（postorder DFS）进行计算**：由于需要在子节点的收益确定之后才能进行自身的计算，因此按照左→右→自身的顺序处理的后序DFS最为合适。这样只需一次遍历即可尝试将所有节点作为顶点
6. **最终返回的结果**：DFS完成后，`maxSum` 中存储了以所有节点为顶点尝试后的最大路径总和。返回该值即可

## 前置知识

### 什么是二叉树的后序DFS（Postorder DFS）

后序DFS是按照"左子节点→右子节点→自身"的顺序递归访问二叉树的遍历方法。适用于需要利用子节点的计算结果来进行父节点计算的场景。

```java
void postorder(TreeNode node) {
    if (node == null) return;     // 基本情况：如果为null则不做任何处理
    postorder(node.left);         // 先处理左子树
    postorder(node.right);        // 再处理右子树
    // 在此处对 node 自身进行处理（子节点的结果已经确定）
}
```

### 什么是 Math.max

Math.max 是Java的标准方法，返回两个值中较大的一个。用于将负收益截断为0以及比较左右收益。

```java
Math.max(0, -5);    // → 0（将负值截断为0）
Math.max(3, 7);     // → 7（返回较大的值）
Math.max(0, gain(node.left));  // 如果左子节点的收益为负则置为0
```

### 什么是 Integer.MIN_VALUE

Integer.MIN_VALUE 是Java `int` 类型可取的最小值（-2,147,483,648）。在求最大值的算法中用作初始值。可以保证无论与什么值比较都会被更新。

```java
int maxSum = Integer.MIN_VALUE;  // 比任何路径总和都小的初始值
maxSum = Math.max(maxSum, 10);   // → 10（首次比较时必定会被更新）
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 执行对每个节点访问一次的DFS |
| Space | O(n) — 递归调用的调用栈在最坏情况下（倾斜的树）达到n层 |

## 代码

```java
// 输入：二叉树的根节点 root（每个节点持有整数值 val、左子节点 left、右子节点 right）
// 输出：以 int 形式返回二叉树中任意路径的最大总和值
class Solution {
    // 记录以所有节点为顶点尝试后的最大路径总和
    // 使用 Integer.MIN_VALUE 初始化，使其比任何负值路径都小，确保首次比较时必定会被更新
    int maxSum = Integer.MIN_VALUE;

    // 返回从节点向父方向能带回的最大收益的递归函数（通过后序DFS按子→父的顺序计算）
    int gain(TreeNode node) {
        // 基本情况：null节点的收益为0（从不存在的子节点无法获得任何收益）
        if (node == null) return 0;

        // 获取左子节点的收益，如果为负则截断为0（因为使用负收益的分支会导致路径总和减少，所以选择不使用）
        int leftGain = Math.max(0, gain(node.left));
        // 获取右子节点的收益，同样如果为负则截断为0
        int rightGain = Math.max(0, gain(node.right));

        // 以当前节点为顶点，用连接左右两侧的路径总和更新全局最大值
        // 该值表示"左子孙→当前节点→右子孙"的路径总和
        // 当 leftGain 或 rightGain 为0时，表示只使用一侧分支或仅包含单个节点的路径
        maxSum = Math.max(maxSum, node.val + leftGain + rightGain);

        // 返回给父节点的收益只取左右中较大一方的分支
        // 路径必须像一笔画一样连续，不能在一个节点处分叉，因此不能同时返回两侧
        return node.val + Math.max(leftGain, rightGain);
    }

    int maxPathSum(TreeNode root) {
        // 从根节点开始递归DFS，尝试将所有节点作为顶点
        gain(root);
        // DFS完成后，maxSum 中存储了以所有节点为顶点尝试的路径中的最大总和值
        return maxSum;
    }
}
```
