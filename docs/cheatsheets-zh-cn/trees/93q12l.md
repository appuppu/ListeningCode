# Validating a Binary Search Tree — 判定二叉树是否为有效的二叉搜索树

## 问题的本质

给定一棵二叉树的 `root`。判定该树是否为有效的二叉搜索树（BST）。有效的BST是指，对于所有节点，其左子树中的所有值**严格小于**该节点的值，其右子树中的所有值**严格大于**该节点的值。

## 核心思路

每个节点都有一个"可取值的有效范围"。从根节点开始递归向下遍历，对左子节点缩小上界，对右子节点缩小下界，这样就可以在一次遍历中判定所有节点是否满足BST的条件。

## 思考过程

1. **仅检查直接父子关系是不够的**: 仅仅每个节点大于其直接左子节点且小于其直接右子节点，并不能满足BST的条件。左子树中"所有"节点都必须小于该节点。也就是说，每个节点都有从祖先节点继承下来的约束
2. **定义每个节点的有效范围**: 根节点可以取任意值，因此范围从 `(-∞, +∞)` 开始。向左子节点前进时，上界缩小为其父节点的值；向右子节点前进时，下界缩小为其父节点的值。将该范围作为递归的参数传递即可
3. **确定判定条件**: 在每个节点处检查 `node.val` 是否在 `(lo, hi)` 范围内。BST使用严格不等号，因此当 `node.val <= lo` 或 `node.val >= hi` 时判定为无效
4. **确定递归结构**: 基本情况是 `node == null` 时返回 `true`（空树是有效的BST）。在每个节点处判定自身的值，并对左右子节点缩小范围进行递归调用。仅当左右两侧都返回 `true` 时才返回 `true`
5. **将范围的类型设为long**: 当节点的值为 `Integer.MIN_VALUE` 或 `Integer.MAX_VALUE` 时，int类型的范围无法表示初始值。使用 `Long.MIN_VALUE` 和 `Long.MAX_VALUE` 作为初始范围，可以正确判定所有int值
6. **最终返回值**: 从根节点开始递归，如果所有节点都在有效范围内则返回 `true`，只要有一个违反则返回 `false`

## 前置知识

### 什么是二叉搜索树（BST）

二叉搜索树是一种二叉树，对于每个节点，其左子树中的所有值小于该节点的值，其右子树中的所有值大于该节点的值。该性质不仅适用于直接子节点，还适用于整个子树。

```
      5
     / \
    3   7     ← 有效的BST: 3<5, 7>5, 1<3, 4>3且4<5, 6>5且6<7
   / \   \
  1   4   8
```

### 通过递归缩小范围

从父节点向子节点前进时，有效值的范围逐渐缩小的机制:

```
节点5: 范围(-∞, +∞)
├─ 左子节点3: 范围(-∞, 5)  ← 上界缩小为父节点的值5
│  ├─ 左子节点1: 范围(-∞, 3)
│  └─ 右子节点4: 范围(3, 5)  ← 下界3且上界5
└─ 右子节点7: 范围(5, +∞)  ← 下界缩小为父节点的值5
```

### 使用long类型的原因

Java中 `int` 的范围是 `-2147483648` ～ `2147483647`。要将"允许int类型的任意值"表示为初始范围，需要超出int类型范围的值。使用 `long` 类型，可以通过 `Long.MIN_VALUE` 和 `Long.MAX_VALUE` 设置足够宽的初始范围。

```java
long lo = Long.MIN_VALUE;  // 小于int类型的任意值
long hi = Long.MAX_VALUE;  // 大于int类型的任意值
node.val <= lo;            // node.val是int类型，因此保证大于Long.MIN_VALUE
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 每个节点访问一次 |
| Space | O(h) — 递归调用栈的深度与树的高度h成正比（最坏情况O(n)，平衡时O(log n)） |

## 代码

```java
// 输入: 二叉树的根节点 root
// 输出: 如果树是有效的BST则返回 true，否则返回 false
public boolean isValidBST(TreeNode root) {
    // 将初始范围设为Long.MIN_VALUE/MAX_VALUE，使根节点可以接受int类型的任意值
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

// lo, hi 为long类型。因为int类型无法将Integer.MIN_VALUE/MAX_VALUE用作初始值
boolean validate(TreeNode node, long lo, long hi) {
    // 基本情况: 空节点不违反BST的条件
    if (node == null) return true;

    // 如果当前节点的值在有效范围(lo, hi)之外则无效
    // BST中不允许相等的值，因此使用 <= 和 >= 进行严格判定
    if (node.val <= lo || node.val >= hi) return false;

    // 左子树: 将上界缩小为node.val（左侧的所有值必须小于node.val）。下界lo保持祖先的约束
    // 右子树: 将下界缩小为node.val（右侧的所有值必须大于node.val）。上界hi保持祖先的约束
    // 仅当左右两侧都为true时，该子树整体才是有效的BST
    return validate(node.left, lo, node.val)
        && validate(node.right, node.val, hi);
}
```
