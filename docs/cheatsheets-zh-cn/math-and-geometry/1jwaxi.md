# Adding One to a Number Represented as an Array — 将数组表示的数值加1

## 问题的本质

给定一个非负整数的数组 `digits`，其中每个元素存储一位数字。数组的第一个元素是最高位，最后一个元素是最低位。将该数值加1，并以相同格式的数组返回结果。每个元素是0到9的一位数字。

## 核心思路

从末尾的数字开始加1，在不再产生进位的时刻立即返回结果。只有当该位数字为9时才会产生进位，只有当所有位都为9时数组的长度才会增加1。

## 思考过程

1. **从最低位开始加法运算**: 数值的加法从个位开始是自然的，因此从数组的末尾向开头进行逆序遍历
2. **考虑进位停止的条件**: 如果当前位小于9，则加1后不会产生进位。此时加法运算已完成，可以立即返回数组
3. **考虑当前位为9时的处理**: 当前位为9时，加1后变为10，产生进位。将该位设为0，并将进位传播到上一位。在循环的下一次迭代中，对上一位加1的处理会自然地执行
4. **考虑所有位都为9的情况**: 如999这样所有位都为9时，即使循环执行到最后进位也不会停止。结果如1000一样位数增加1。仅在这种情况下创建新数组，并将首位设为1。Java的 `new int[]` 会将所有元素初始化为0，因此无需对其余位赋值为0
5. **无需用变量管理进位**: 进位的值始终为1，且循环继续执行这一事实本身就确定了进位的存在，因此无需准备carry变量，可以将循环的继续本身作为表示进位存在的结构

## 前置知识

### 数组的逆序遍历

从数组的末尾向开头进行循环。从 `i = n - 1` 开始，在 `i >= 0` 的范围内通过 `i--` 进行递减。

```java
int[] digits = {1, 2, 3};
int n = digits.length;                  // 获取数组的长度 → 3
for (int i = n - 1; i >= 0; i--) {      // 按 i=2, 1, 0 的顺序循环
    System.out.println(digits[i]);      // 按 3, 2, 1 的顺序输出
}
```

### Java的数组初始化

使用 `new int[n]` 创建长度为n的整数数组时，所有元素会自动初始化为0。无需显式地将元素赋值为0。

```java
int[] result = new int[4];   // 初始化为 {0, 0, 0, 0}
result[0] = 1;               // 变为 {1, 0, 0, 0}
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 从数组末尾到开头最多遍历一次 |
| Space | O(1) — 除所有位都为9的情况外，直接在输入数组上进行修改，无需额外内存 |

## 代码

```java
// 输入: 存储非负整数各位数字的整数数组 digits
// 输出: 返回将 digits 表示的数值加1后的结果 int[]
public int[] plusOne(int[] digits) {
    // 保存数组的长度。用于逆序遍历的循环上限，以及所有位都为9时新数组的长度
    int n = digits.length;

    // 从末尾向开头遍历。循环继续执行这一事实本身意味着"存在进位"
    for (int i = n - 1; i >= 0; i--) {
        // 如果当前位小于9，则不会产生进位。加1后立即返回
        if (digits[i] < 9) {
            digits[i]++;
            return digits;  // 无进位。直接返回修改后的数组并结束
        }
        // 当前位为9，将其设为0并将进位传播到上一位
        digits[i] = 0;
    }

    // 所有位都为9的情况（例: [9,9,9] → [0,0,0]），位数增加1
    // new int[] 会将所有元素初始化为0，因此无需对其余位赋值为0
    int[] result = new int[n + 1];
    result[0] = 1;  // 将首位设为1（例: 999 + 1 = 1000 → [1, 0, 0, 0]）
    return result;
}
```
