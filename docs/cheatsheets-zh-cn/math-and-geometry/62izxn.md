# Computing Power of a Number Efficiently — 高效计算浮点数的幂

## 问题的本质

给定一个浮点数 `x` 和一个整数 `n`，要求计算并返回 `x` 的 `n` 次幂。由于 `n` 可以取负值，因此需要处理负指数的情况；同时当 `n` 的绝对值非常大时，也必须高效地完成计算。

## 核心思想

将指数 `n` 用二进制表示后，幂运算可以分解为"反复对 x 进行平方，仅在 n 的对应位为 1 时才将结果乘入"的操作。这样就能将 n 次乘法减少为 log(n) 次。

## 思考过程

1. **将负指数转换为正指数**：`x^(-n)` 等于 `(1/x)^n`，因此当 `n` 为负数时，将 `x` 替换为 `1/x` 并翻转 `n` 的符号，即可将问题统一为正指数的情况
2. **进行 n 次乘法太慢**：朴素地将 `x` 乘以自身 `n` 次，时间复杂度为 O(n)。当 `n` 达到数十亿时，这种方法无法满足要求。因此需要一种每次将指数减半的方法
3. **幂运算可以通过反复平方来分解**：例如 `x^10 = x^8 × x^2`，任意幂次都可以分解为若干个 2 的幂次之积。这与指数 `n` 的二进制表示相对应。`10` 的二进制为 `1010`，所以只需将位为 1 的对应项 `x^8` 和 `x^2` 相乘即可
4. **利用位运算判断每一位**：通过 `(n & 1) == 1` 可以判断 `n` 的最低位是否为 1。如果为 1，则将当前的 `x`（即已经累积平方到对应位数的值）乘入结果中
5. **反复平方 x 以推进到更高位**：每次循环中将 `x` 更新为 `x * x`，则 `x` 依次变为原始值的 2 次方、4 次方、8 次方……即 2 的幂次对应的累乘值。同时将 `n` 右移 1 位，推进到下一位
6. **循环的终止条件**：持续对 `n` 进行右移操作后，`n` 最终会变为 0。只要在 `n > 0` 的条件下循环，就能处理所有的位

## 前置知识

### 位运算（& 和 >>）

位运算将整数视为二进制，在位级别上进行操作。`&`（AND）仅当两个位都为 1 时结果才为 1。`>>`（右移）将位序列向右移动，丢弃最低位（相当于除以 2 的操作）。

```java
int n = 10;           // 二进制: 1010
n & 1;                // 获取最低位 → 0（偶数）
n >>= 1;              // 右移1位 → n 变为 5（二进制: 101）
n & 1;                // 获取最低位 → 1（奇数）
```

### 快速幂算法（Fast Exponentiation）

快速幂算法利用指数的二进制表示，通过 O(log n) 次乘法完成幂运算。以 `x^13` 为例，`13` 的二进制为 `1101`，因此 `x^13 = x^8 × x^4 × x^1`。在循环中反复对 `x` 进行平方（`x → x^2 → x^4 → x^8`），仅在对应位为 1 时将其乘入结果。

```java
// x^13 的计算过程（13 = 1101 in binary）
// 第0位: 1 → result *= x    (result = x^1)，  x = x^2
// 第1位: 0 → 跳过，                             x = x^4
// 第2位: 1 → result *= x^4  (result = x^5)，  x = x^8
// 第3位: 1 → result *= x^8  (result = x^13)， x = x^16
```

### 需要强制转换为 long 类型的原因

Java 中 `int` 类型的范围是 `-2^31` 到 `2^31 - 1`。当 `n = -2^31` 时，`-n` 的值为 `2^31`，超出了 `int` 的范围，会导致溢出。先将 `n` 强制转换为 `long` 类型再进行符号翻转，即可避免该问题。

```java
int n = Integer.MIN_VALUE;   // -2147483648
long power = (long) n;       // -2147483648L（转换为long类型）
power = -power;              // 2147483648L（int类型无法表示，但long类型可以安全处理）
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(log n) — 循环次数等于指数 n 的二进制位数 |
| Space | O(1) — 仅使用 result、x、power 三个变量，不需要递归栈 |

## 代码

```java
// 输入: 浮点数 x 和整数 n
// 输出: 以 double 类型返回 x 的 n 次幂
double myPow(double x, int n) {
    // 如果保持int类型，当n = -2^31时符号翻转会溢出，因此转换为long类型
    long power = (long) n;

    // 将负指数转换为正指数: x^(-n) = (1/x)^n
    // 通过此转换，后续处理可以统一为仅处理正指数的情况
    if (power < 0) {
        x = 1 / x;
        power = -power;
    }

    // 用1.0初始化用于累积结果的变量
    // 将位为1的对应位数的x的累乘值逐步乘入，以累积最终结果
    double result = 1.0;

    // 从低位到高位依次处理power的所有位
    // 持续右移power后其最终变为0，表示所有位的处理已完成
    while (power > 0) {
        // 通过 power & 1 判断最低位（当前处理的位）是否为1
        if ((power & 1) == 1) {
            // 如果该位为1: 此时的x是原始x经过已处理位数次平方后的值（即原始x的2^k次幂）
            // 将该位的贡献乘入result中
            result *= x;
        }
        // 对x进行平方，更新为下一位对应的累乘值（指数翻倍的幂）
        x *= x;
        // 将power右移1位，推进到下一位（最低位被丢弃）
        power >>= 1;
    }
    // 返回所有位的贡献相乘后得到的最终结果
    return result;
}
```
