# Setting Entire Rows and Columns to Zero — 将包含零的行和列全部置零

## 问题本质

给定一个 m×n 的矩阵。找到值为0的元素后，将该元素所在的**整行**和**整列**全部设置为0。要求在in-place（不使用额外矩阵）的条件下完成此变换。

## 核心思路

将矩阵的第0行和第0列作为"记录哪些行和列需要置零"的标志区域来复用，就能以O(1)的额外空间管理需要置零的行和列。

## 思考过程

1. **需要记录哪些行和列应被置零**: 在遍历过程中一旦发现零就立即改写该行和列，会导致后续遍历时无法区分某个零是原始值还是改写后的结果。因此需要先记录"哪些行和列需要置零"，然后统一改写的两趟扫描方式
2. **使用额外数组记录需要O(m+n)的空间**: 可以用大小为m的数组记录行、大小为n的数组记录列，但目标是实现O(1)空间
3. **将矩阵自身的第0行和第0列用作标志**: 令 `matrix[i][0]` 为0表示"第i行需要置零"，`matrix[0][j]` 为0表示"第j列需要置零"。这样就不需要额外数组
4. **第0列的标志需要使用独立变量**: `matrix[i][0]` 同时承担了"第i行的标志"和"第0列的原始值"两重含义。第0列本身是否需要置零，需要用另一个变量 `firstCol` 来管理
5. **标记标志**: 遍历矩阵，发现 `matrix[i][j] == 0` 时，设置 `matrix[i][0] = 0` 和 `matrix[0][j] = 0` 来标记标志
6. **按逆序执行置零操作**: 根据标志写入零时，如果先改写第0行和第0列，标志就会被破坏。因此需要从末尾开始逆序处理，将第0行和第0列留到最后处理

## 前置知识

### 什么是in-place操作

不使用额外的数据结构（如另一个矩阵或大型数组），直接改写输入数据本身来得到结果的操作。仅允许使用常数个额外变量。

```java
// in-place操作示例: 直接改写数组中的元素
matrix[i][j] = 0;  // 不复制到另一个数组，而是直接修改原矩阵
```

### 什么是boolean型标志

用true/false两个值来记录"某个条件是否成立"的变量。在循环中一旦条件成立就设为true，在后续处理中引用该标志。

```java
boolean firstCol = false;       // 初始值为false（条件未成立）
if (matrix[i][0] == 0)
    firstCol = true;            // 记录条件已成立
// 后续引用该标志
if (firstCol)
    matrix[i][0] = 0;          // 如果标志为true则执行处理
```

### 什么是逆序循环

从数组或矩阵的末尾向开头方向遍历的循环。当开头的元素兼作后续处理所用的标志时，为了将开头留到最后处理而使用逆序。

```java
for (int i = m - 1; i >= 0; i--)    // i 从末尾(m-1)递减到0
    for (int j = n - 1; j >= 1; j--)  // j 从末尾(n-1)递减到1
```

## 复杂度

| | 值 |
|---|---|
| Time | O(m × n) — 对整个矩阵遍历两次（标志设置一次，置零一次） |
| Space | O(1) — 额外变量仅有 `firstCol`。将矩阵自身作为标志区域复用 |

## 代码

```java
// 输入: m×n 的整数矩阵 matrix（二维数组）
// 输出: 无（直接改写 matrix。返回值为 void）
public void setZeroes(int[][] matrix) {
    // 获取行数m和列数n
    int m = matrix.length;
    int n = matrix[0].length;
    // 记录第0列是否需要置零的标志
    // 由于 matrix[i][0] 兼作行标志，所以第0列的标志需要用独立变量管理
    boolean firstCol = false;

    // 第1趟: 标记标志
    for (int i = 0; i < m; i++) {
        // 检查第0列中是否原本存在零，如果有则将 firstCol 设为 true
        if (matrix[i][0] == 0)
            firstCol = true;
        // 从j=1开始遍历（j=0 兼作行标志，所以只查看第1列及之后的列）
        for (int j = 1; j < n; j++)
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;  // 标记第i行需要置零
                matrix[0][j] = 0;  // 标记第j列需要置零
            }
    }

    // 第2趟: 按逆序写入零
    // 使用逆序的原因: 由于第0行的标志（matrix[0][j]）被其他行的处理所引用，需要将第0行留到最后处理
    for (int i = m - 1; i >= 0; i--) {
        // 从j=1开始逆序遍历，如果行标志或列标志被标记则置零
        for (int j = n - 1; j >= 1; j--)
            if (matrix[i][0] == 0 || matrix[0][j] == 0)
                matrix[i][j] = 0;
        // 第0列的置零在内层循环之后执行
        // 注意: 如果先改写 matrix[i][0]，上面的行标志判定就会被破坏
        if (firstCol)
            matrix[i][0] = 0;
    }
}
```
