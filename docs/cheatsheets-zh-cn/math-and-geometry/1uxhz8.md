# Determining if a Number is a Happy Number — 反复计算各位数字的平方和，判断是否能到达1

## 问题的本质

给定一个正整数 `n`。反复将 `n` 的各位数字平方后求和，如果结果最终到达 **1**，则该数为"快乐数"，返回 `true`。如果无法到达1而陷入无限循环，则返回 `false`。

## 核心思路

反复计算各位数字平方和的操作，必定在有限个值之间循环。这与链表的环检测具有相同的结构，使用 Floyd 的慢指针和快指针，可以在不使用额外内存的情况下判断是否存在环以及环的到达点。

## 思考过程

1. **反复操作必定形成循环**: 反复计算各位数字的平方和时，值会被限制在有限范围内，因此必定会再次到达之前出现过的值。也就是说，数列必定进入"在1处停止的循环"或"不包含1的循环"中的某一个
2. **循环检测可以归结为环检测问题**: 将每个值到下一个值的转换视为"从一个节点到另一个节点的链接"，这个问题就与检测链表中是否存在环的问题具有相同的结构
3. **使用 Floyd 双指针法以O(1)空间进行检测**: 慢指针每次前进1步，快指针每次前进2步。如果存在环，两个指针必定会在环内的某个位置相遇
4. **根据相遇点的值判断结果**: 当两个指针相遇时，如果该值为1，则该数是快乐数（因为1的各位数字平方和仍为1，所以1自身构成一个环）。如果在1以外的值相遇，则说明进入了不包含1的环，因此该数不是快乐数
5. **初始值的设置**: 将慢指针设为 `n`，快指针设为 `getNext(n)` 后开始。这样可以自然地进入 `while (slow != fast)` 的循环

## 前置知识

### 各位数字平方和的计算

要取出整数 `n` 的各位数字，通过 `n % 10` 获取最低位数字，再通过 `n /= 10` 去除最低位数字，重复此操作直到 `n` 变为0。

```java
int n = 19;
int digit = n % 10;   // 获取最低位数字 → 9
n /= 10;              // 去除最低位数字 → n变为1
digit = n % 10;       // 获取下一位数字 → 1
// 19 → 1² + 9² = 1 + 81 = 82
```

### Floyd 环检测法（双指针法）

一种检测链表或数列中是否存在环（循环）的算法。慢指针每次前进1步，快指针每次前进2步。如果存在环，快指针会追上慢指针，两者必定相遇。由于不使用额外的数据结构，空间复杂度为O(1)。

```java
int slow = start;                // 慢指针每次前进1步
int fast = getNext(start);       // 快指针的初始位置设为前方1步处
while (slow != fast) {
    slow = getNext(slow);        // 前进1步
    fast = getNext(getNext(fast)); // 前进2步
}
// 循环结束时，slow == fast 为相遇点的值
```

## 复杂度

| | 值 |
|---|---|
| Time | O(log n) — 计算各位数字平方和需要O(log n)，到达环之前的迭代次数为常数级别 |
| Space | O(1) — 仅使用慢指针和快指针两个变量 |

## 代码

```java
// 输入: 正整数 n
// 输出: 如果 n 是快乐数则返回 true，否则返回 false

// 计算并返回整数n各位数字平方和的辅助函数
// 通过 n % 10 取出最低位数字，将其平方累加，再通过 n /= 10 去除该位数字，反复执行此操作
private int getNext(int n) {
    int sum = 0;
    while (n > 0) {
        int digit = n % 10;   // 取出最低位数字
        sum += digit * digit;  // 将该位数字的平方加到sum上
        n /= 10;               // 去除最低位数字
    }
    return sum;
}

public boolean isHappy(int n) {
    // 慢指针从n开始，快指针从领先1步的getNext(n)开始
    // 将fast设为领先1步，可以自然地进入 while (slow != fast) 的循环
    int slow = n;
    int fast = getNext(n);

    // 循环直到两个指针相遇
    // 由于慢指针和快指针的速度差，如果存在环则必定相遇
    while (slow != fast) {
        slow = getNext(slow);           // 慢指针前进1步
        fast = getNext(getNext(fast));   // 快指针前进2步
    }

    // 如果相遇点为1则是快乐数（因为1的各位数字平方和为1，所以1自身构成环）
    // 如果在1以外的值相遇，则说明进入了不包含1的环，因此不是快乐数
    return fast == 1;
}
```
