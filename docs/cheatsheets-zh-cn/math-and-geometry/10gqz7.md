# Detecting Axis-Aligned Squares From Points — 从存储的点中计算与坐标轴平行的正方形数量

## 问题的本质

设计一个数据结构，支持 `add` 操作（在2D平面上添加点）和 `count` 操作（返回以给定点为一个顶点的**与坐标轴平行的正方形**（四条边均平行于x轴或y轴）的数量）。同一坐标被多次添加的点，每次视为不同的点。

## 核心思路

与坐标轴平行的正方形，一旦确定对角线上的两个点，其余两个点就唯一确定。将与查询点具有相同x坐标的点作为对角线的候选伙伴逐一枚举，然后通过HashMap以O(1)的时间复杂度确认其余两个角是否存在，即可高效地计算正方形的数量。

## 思考过程

1. **理解与坐标轴平行的正方形的性质**：由于四条边平行于x轴和y轴，四个顶点的形式为 `(x1,y1)`、`(x1,y2)`、`(x2,y1)`、`(x2,y2)`。也就是说，正方形由x坐标相同的两个点和y坐标相同的两个点的组合构成
2. **从对角线上的两个点确定其余两个点**：选择查询点 `(px, py)` 和具有相同x坐标但不同y坐标的点 `(px, pt_y)`，边长为 `|py - pt_y|`。其余两个顶点必须位于 `(px ± side, py)` 和 `(px ± side, pt_y)` 的位置
3. **正方形可以向左右两个方向构成**：当边长 `side` 确定后，另一侧的x坐标有 `px - side` 和 `px + side` 两种可能。需要检查两个方向
4. **记录每个坐标的点的数量**：由于同一坐标可能被多次添加点，因此使用HashMap管理每个坐标的点的出现次数。其余两个顶点的出现次数之积，即为该组合能构成的正方形数量
5. **快速获取具有相同x坐标的点**：以x坐标为键，用另一个HashMap管理具有该坐标的所有点的列表。这样在执行 `count` 时，可以高效地仅枚举具有相同x坐标的点
6. **累积结果并返回**：对于每个候选伙伴和每个方向，将其余两个顶点的出现次数之积累加到结果中

## 前置知识

### 将坐标作为HashMap键的方法

要将二维坐标 `(x, y)` 用作HashMap的键，可以将其转换为字符串 `"x,y"`。这样可以对任意坐标以O(1)的时间复杂度进行值的存储和获取。

```java
Map<String, Integer> cnt = new HashMap<>();
String key = x + "," + y;               // 坐标(3,5) → "3,5"
cnt.put(key, cnt.getOrDefault(key, 0) + 1);  // 将该坐标的出现次数加1
cnt.getOrDefault(key, 0);               // 如果不存在则返回0
```

### computeIfAbsent 的含义

该方法仅在指定键不存在于Map中时，生成新值并注册。如果键已经存在，则直接返回现有的值。在构建值为列表的Map时非常方便。

```java
Map<Integer, List<int[]>> xMap = new HashMap<>();
// 如果键5不存在则创建新的ArrayList，如果存在则返回该列表
xMap.computeIfAbsent(5, k -> new ArrayList<>()).add(new int[]{5, 3});
```

### 组合数的计算方法（乘法原理）

当两个独立的选择分别有 `c1` 种和 `c2` 种时，组合总数为 `c1 * c2`。在本题中，当其余两个顶点的坐标分别存在 `c1` 个和 `c2` 个点时，这两个顶点的选择方式共有 `c1 * c2` 种。

## 计算复杂度

| | 值 |
|---|---|
| Time | add: O(1) — 仅进行HashMap的注册。count: O(n) — 遍历所有具有相同x坐标的点 |
| Space | O(n) — 将所有点的坐标和出现次数保存在HashMap中 |

## 代码

```java
// add(int[] p): 在2D平面上添加点 p = [x, y]
// count(int[] p): 返回以点 p = [x, y] 为一个顶点的与坐标轴平行的正方形的数量（int类型）
class DetectSquares {
    // 管理每个坐标出现次数的HashMap（键: "x,y"）
    // 用于在count时以O(1)获取任意坐标上有多少个点
    Map<String, Integer> cnt;
    // 管理具有相同x坐标的点的列表的HashMap（键: x坐标）
    // 用于在count时高效地仅枚举具有相同x坐标的点
    Map<Integer, List<int[]>> xMap;

    DetectSquares() {
        cnt = new HashMap<>();
        xMap = new HashMap<>();
    }

    void add(int[] p) {
        // 将坐标转换为字符串 "x,y" 并将出现次数加1
        String key = p[0] + "," + p[1];
        cnt.put(key, cnt.getOrDefault(key, 0) + 1);

        // 将点添加到按x坐标分组的列表中（如果是首次出现的x坐标则创建新列表）
        xMap.computeIfAbsent(p[0],
            k -> new ArrayList<>()).add(p);
    }

    int count(int[] p) {
        int res = 0;
        int px = p[0], py = p[1];

        // 获取与查询点具有相同x坐标的点的列表
        // 如果列表不存在则无法构成正方形，返回0
        List<int[]> same = xMap.get(px);
        if (same == null) return 0;

        // 遍历具有相同x坐标的每个点作为候选伙伴
        for (int[] pt : same) {
            // 计算边长（查询点与候选伙伴点的y坐标之差的绝对值）
            int side = Math.abs(py - pt[1]);
            // 如果y坐标相同则边长为0，无法构成正方形，跳过
            if (side == 0) continue;

            // 正方形可以向左右两个方向构成，因此尝试两个x坐标
            int[] dirs = {px - side, px + side};
            for (int nx : dirs) {
                // 获取其余两个顶点坐标 (nx, py) 和 (nx, pt[1]) 的出现次数
                // 不存在的坐标返回0，乘积也为0，因此不会被累加
                String k1 = nx + "," + py;
                String k2 = nx + "," + pt[1];
                int c1 = cnt.getOrDefault(k1, 0);
                int c2 = cnt.getOrDefault(k2, 0);

                // 两个顶点出现次数的乘积即为该组合能构成的正方形数量（乘法原理）
                res += c1 * c2;
            }
        }
        return res;
    }
}
```
