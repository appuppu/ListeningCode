# Finding the Minimum Eating Speed to Finish Bananas — 求在限定时间内吃完所有香蕉的最小速度

## 问题的本质

给定一个香蕉堆数组 `piles` 和限定时间 `h`（小时）。当每小时吃 `k` 根香蕉时，返回能在 `h` 小时内吃完所有香蕉的**最小整数速度 `k`**。每小时只能吃一堆香蕉，如果某堆香蕉不足 `k` 根，吃完该堆后剩余时间需要等待，不能继续吃下一堆。

## 核心思路

"以速度 `k` 能否吃完全部香蕉？"对 `k` 具有单调性。`k` 越大必定能吃完，`k` 太小则吃不完。由于存在这种单调性，可以对答案的候选范围 `[1, max(piles)]` 应用二分查找，从而高效地找到满足条件的最小 `k`。

## 思考过程

1. **速度与结果的关系具有单调性**：速度 `k` 越大，所需时间越少；速度越小，所需时间越多。如果某个速度能吃完，那么大于该速度的任何速度也一定能吃完。这种"求满足某个条件的最小值"的结构是二分查找的典型模式
2. **确定搜索范围**：速度的最小值为 `1`（每小时至少吃1根），最大值为 `max(piles)`（能在1小时内吃完最大堆的速度）。即使速度大于 `max(piles)`，由于每小时只能吃一堆，结果也不会改变
3. **设计判定函数**：给定速度 `mid` 时，吃完每堆 `piles[i]` 需要 `ceil(piles[i] / mid)` 小时。如果所有堆的总时间不超过 `h`，则判定该速度可以吃完
4. **用整数运算实现向上取整**：`ceil(piles[i] / mid)` 可以用 `(piles[i] + mid - 1) / mid` 来计算。这样可以避免浮点运算，仅用整数就能精确计算
5. **用二分查找缩小范围**：如果中间值 `mid` 能吃完，则答案在 `mid` 以下，令 `right = mid`。如果吃不完，则答案在 `mid + 1` 以上，令 `left = mid + 1`。当 `left == right` 时，该值即为所求的最小速度

## 前置知识

### 二分查找（Binary Search）的"求满足条件的最小值"模式

对有序的值或连续整数范围，找到满足某个条件的最小值（或最大值）的方法。由于每次将搜索范围缩小一半，因此可以在 O(log n) 内找到答案。

```java
int left = 1;               // 搜索范围的下限
int right = 1000;            // 搜索范围的上限
while (left < right) {       // 当 left == right 时答案确定
    int mid = left + (right - left) / 2;  // 防止溢出的中间值计算
    if (condition(mid))       // 判断 mid 是否满足条件
        right = mid;          // 满足条件 → 答案在 mid 以下
    else
        left = mid + 1;       // 不满足条件 → 答案在 mid+1 以上
}
// left 即为满足条件的最小值
```

### 向上取整除法（Ceiling Division）

将 `a / b` 的结果向上取整的整数运算。不使用 `Math.ceil`，而是通过 `(a + b - 1) / b` 来计算。

```java
int a = 10, b = 3;
int result = (a + b - 1) / b;  // (10 + 2) / 3 = 4  （10÷3=3.33... → 向上取整为4）
```

在香蕉问题中，将堆的大小 `piles[i]` 除以速度 `k` 并向上取整，即可求出吃完该堆所需的小时数。

### Math.max 是什么

返回两个值中较大值的方法。与循环结合使用可以求数组的最大值。

```java
Math.max(5, 3);   // → 5
Math.max(-1, 0);  // → 0
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n × log(max(piles))) — 二分查找进行 O(log(max(piles))) 次迭代，每次迭代以 O(n) 遍历整个数组来计算总时间 |
| Space | O(1) — 不使用额外的数据结构，仅用变量进行处理 |

## 代码

```java
// 输入：整数数组 piles（每堆香蕉的数量）和整数 h（限定时间）
// 输出：以 int 返回能在 h 小时内吃完所有香蕉的最小整数速度 k
public int minEatingSpeed(int[] piles, int h) {
    // 将二分查找的下限设为1。速度最低为每小时1根
    int left = 1;
    // 将二分查找的上限设为数组的最大值
    // 因为速度大于能在1小时内吃完最大堆的值没有意义，所以该值为上限
    int right = 0;
    for (int p : piles) {
        right = Math.max(right, p);
    }

    // 持续将搜索范围缩小一半，直到 left == right
    // 当 left == right 时，该值即为答案
    while (left < right) {
        // 防止溢出的中间值计算
        // 使用 left + (right - left) / 2 而非 (left + right) / 2 来防止整数溢出
        int mid = left + (right - left) / 2;

        // 计算以速度 mid 吃完所有香蕉所需的总时间
        int totalHours = 0;
        for (int p : piles) {
            // 向上取整除法：求吃完每堆所需的小时数
            totalHours += (p + mid - 1) / mid;
        }

        if (totalHours <= h) {
            // 能吃完 → 更慢的速度也可能吃完，因此缩小上限
            // 由于 mid 本身可能是答案，所以赋值 mid 而非 mid - 1
            right = mid;
        } else {
            // 吃不完 → 速度不够，因此提高下限
            // 由于 mid 不可能是答案，所以赋值 mid + 1
            left = mid + 1;
        }
    }

    // 循环结束后，left（= right）即为满足条件的最小速度
    return left;
}
```
