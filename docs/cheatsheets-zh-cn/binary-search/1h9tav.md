# Finding the Minimum in a Rotated Sorted Array — 在旋转排序数组中查找最小值

## 问题的本质

一个由唯一整数组成的升序排序数组，被旋转了1次以上n次以下。需要在这个旋转后的数组中找到并返回**最小的元素**。旋转是指将数组末尾的元素移动到开头的操作，因此原始排序顺序中存在一个"折断"的枢轴点。

## 核心思路

在旋转排序数组中，最小值位于排序顺序被打破的"枢轴"位置。通过将中间元素与最右端元素进行比较，就能在一次比较中判断最小值位于左半部分还是右半部分，从而通过二分查找在 O(log n) 内找到最小值。

## 思考过程

1. **最小值位于枢轴位置**: 旋转排序数组被分为"较大的子序列"和"较小的子序列"两个有序部分。最小值位于"较小的子序列"的开头，即枢轴位置。找到这个枢轴就是问题的本质
2. **希望使用二分查找而非线性查找**: 虽然数组并非完全有序，但它具有被分为两个有序部分的结构。利用这个结构，可以应用每次丢弃一半的二分查找
3. **将中间元素与最右端元素进行比较**: 当 `nums[mid] > nums[right]` 成立时，mid到right之间存在枢轴（排序顺序的断裂），因此最小值在右半部分。反之，当 `nums[mid] <= nums[right]` 时，mid到right是有序的，最小值在mid及其左侧（包含mid本身）
4. **与右端而非左端比较的原因**: 如果与左端比较，当数组未被旋转（整体有序）时无法正确判断。而与右端比较，无论是否发生了旋转，都能正确地缩小最小值的范围
5. **搜索范围的更新方式**: 当 `nums[mid] > nums[right]` 时，可以确定mid不是最小值，因此令 `left = mid + 1`。否则，mid有可能是最小值，因此令 `right = mid`（不排除mid）
6. **循环的终止条件**: 在 `left < right` 期间持续循环，当 `left == right` 时搜索范围缩小到1个元素。该元素 `nums[left]` 就是最小值

## 前置知识

### 什么是旋转排序数组

将升序排序数组 `[1, 2, 3, 4, 5]` 向右旋转2次后变为 `[4, 5, 1, 2, 3]`。数组被分为两个有序子序列 `[4, 5]` 和 `[1, 2, 3]`，它们的边界就是枢轴。

```
原始数组:      [1, 2, 3, 4, 5]
旋转2次后:     [4, 5, 1, 2, 3]
                     ↑ 枢轴（最小值）
```

### 二分查找的基本结构

通过每次将搜索范围缩小一半，以 O(log n) 的时间复杂度找到目标元素的方法。使用left和right两个指针管理搜索范围，以中间元素为基准更新范围。

```java
int left = 0;
int right = nums.length - 1;
int mid = left + (right - left) / 2;  // 防止溢出的中间值计算
```

### 什么是 `left + (right - left) / 2`

计算中间索引的表达式。虽然 `(left + right) / 2` 也能得到相同结果，但当left和right的值较大时，相加可能超过int的最大值。这个表达式是**防止溢出**的安全写法。

## 复杂度

| | 值 |
|---|---|
| Time | O(log n) — 由于每次将搜索范围缩小一半，最多经过log n次比较即可找到最小值 |
| Space | O(1) — 仅使用left、right、mid三个变量，不需要额外的数据结构 |

## 代码

```java
// 输入: 旋转排序后的唯一整数数组 nums
// 输出: 以 int 形式返回数组中的最小值
public int findMin(int[] nums) {
    // 初始化搜索范围的两端。这两个变量表示搜索范围的两端
    int left = 0;
    int right = nums.length - 1;

    // 当 left == right 时搜索范围缩小到1个元素，该元素就是最小值
    while (left < right) {
        // 使用此表达式而非 (left + right) / 2，是为了防止整数溢出
        int mid = left + (right - left) / 2;

        // 当中间元素大于右端元素时，mid和right之间存在枢轴（排序顺序的断裂）
        if (nums[mid] > nums[right]) {
            // 最小值在mid的右侧。mid大于右端元素，因此mid不是最小值，可以排除
            left = mid + 1;
        } else {
            // 从mid到right是有序的。最小值在mid及其左侧（包含mid本身）
            // 由于mid本身可能是最小值，因此不将mid从搜索范围中排除
            right = mid;
        }
    }

    // 此时 left == right，搜索范围缩小到1个元素，该元素就是最小值
    return nums[left];
}
```
