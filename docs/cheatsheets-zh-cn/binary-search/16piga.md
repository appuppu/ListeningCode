# Finding the Median of Two Sorted Arrays — 求两个有序数组合并后的中位数

## 问题的本质

给定两个有序整数数组 `n1` 和 `n2`。求将两个数组合并后的**中位数**。解法必须在总元素数的对数时间内运行。

## 核心思想

求两个有序数组的中位数，等价于找到将数组正确划分为"左半部分"和"右半部分"的边界。对较短的数组进行二分查找来确定划分位置，另一个数组的划分位置也随之自动确定。

## 思考过程

1. **中位数由"左半部分的最大值"和"右半部分的最小值"决定**：如果能将合并后的数组在保持有序的情况下等分为左右两半，那么中位数就是左半部分的最大值（元素总数为奇数时），或者左半部分的最大值与右半部分的最小值的平均值（元素总数为偶数时）。也就是说，无需对全部元素排序，只要找到正确的划分位置即可
2. **确定一个数组的划分位置后，另一个数组的划分位置自动确定**：如果规定左半部分共包含 `half = (m + n + 1) / 2` 个元素，那么从数组 `n1` 中取 `cut1` 个元素后，从数组 `n2` 中需要取 `cut2 = half - cut1` 个元素。也就是说，只需搜索 `cut1` 的值即可
3. **通过"交叉比较"判断划分是否正确**：正确的划分意味着左半部分的所有元素都小于等于右半部分的所有元素。由于每个数组内部已经有序，只需检查交叉的部分。具体来说，当 `n1` 的左半部分末尾 `l1` ≤ `n2` 的右半部分开头 `r2`，且 `n2` 的左半部分末尾 `l2` ≤ `n1` 的右半部分开头 `r1` 时，划分就是正确的
4. **通过二分查找高效搜索 `cut1`**：`cut1` 的范围是 `0` 到 `m`。如果 `l1 > r2`，说明从 `n1` 中取的元素过多，需要减小 `cut1`；如果 `l2 > r1`，说明从 `n1` 中取的元素过少，需要增大 `cut1`。基于这个判断条件，二分查找成立
5. **选择较短数组进行搜索的原因**：二分查找的范围是 `0` 到 `m`（数组的长度），因此选择较短的数组可以缩小搜索范围，使时间复杂度达到 `O(log(min(m, n)))`
6. **使用哨兵值处理边界情况**：当 `cut1 = 0`（不从 `n1` 中取任何元素）或 `cut1 = m`（取 `n1` 的全部元素）时，会访问到不存在的元素。使用 `Integer.MIN_VALUE` 和 `Integer.MAX_VALUE` 作为哨兵值，可以保证比较条件在任何情况下都能正确运行

## 前置知识

### 什么是中位数（Median）

在有序数列中位于中央位置的值。如果元素个数为奇数，取中央的那一个值；如果元素个数为偶数，取中央两个值的平均值。

```java
// 奇数个: [1, 3, 5] → 中位数为 3
// 偶数个: [1, 3, 5, 7] → 中位数为 (3 + 5) / 2.0 = 4.0
```

### 什么是二分查找（Binary Search）

对有序数据每次将搜索范围缩小一半，从而以 O(log n) 的时间复杂度找到目标值的方法。使用 `lo` 和 `hi` 管理搜索范围，以中间值为基准逐步缩小范围。

```java
int lo = 0, hi = n;
while (lo <= hi) {
    int mid = (lo + hi) / 2;       // 计算搜索范围的中间位置
    if (条件满足) { /* 答案 */ }
    else if (mid过大) { hi = mid - 1; }  // 缩小到左半部分
    else { lo = mid + 1; }                // 缩小到右半部分
}
```

### 什么是哨兵值（Sentinel Value）

为避免数组越界访问而使用的特殊值。通过使用 `Integer.MIN_VALUE`（整数最小值）和 `Integer.MAX_VALUE`（整数最大值），可以确保比较条件在边界情况下也不会出错。

```java
Integer.MIN_VALUE;  // -2147483648 — 用作比任何元素都小的值
Integer.MAX_VALUE;  //  2147483647 — 用作比任何元素都大的值
```

## 复杂度

| | 值 |
|---|---|
| Time | O(log(min(m, n))) — 对较短的数组进行二分查找 |
| Space | O(1) — 仅使用变量，不创建额外的数据结构 |

## 代码

```java
// 输入: 两个有序整数数组 n1 和 n2
// 输出: 以 double 类型返回两个数组合并后的中位数
public double findMedian(int[] n1, int[] n2) {
    // 为了对较短的数组进行二分查找，如果 n1 较长则交换后递归调用
    // 这样可以最小化搜索范围，实现 O(log(min(m, n)))
    if (n1.length > n2.length)
        return findMedian(n2, n1);

    int m = n1.length, n = n2.length;
    // 左半部分包含的元素数。通过 +1 使奇数时左半部分多一个元素，
    // 这样左半部分的最大值就直接是中位数
    int half = (m + n + 1) / 2;
    // cut1 的搜索范围: 0（不从 n1 中取任何元素）到 m（取 n1 的全部元素）
    int lo = 0, hi = m;

    while (lo <= hi) {
        // 通过二分查找的中间值决定从 n1 放入左半部分的元素个数
        int cut1 = (lo + hi) / 2;
        // 从 n2 放入左半部分的元素个数（自动确定，使左半部分总数等于 half）
        int cut2 = half - cut1;

        // n1 左半部分的末尾（cut1=0 时左半部分为空，
        // 使用比任何元素都小的哨兵值，确保比较条件始终成立）
        int l1 = cut1 == 0 ?
            Integer.MIN_VALUE :
            n1[cut1 - 1];
        // n2 左半部分的末尾（cut2=0 时左半部分为空，使用哨兵值）
        int l2 = cut2 == 0 ?
            Integer.MIN_VALUE :
            n2[cut2 - 1];
        // n1 右半部分的开头（cut1=m 时右半部分为空，
        // 使用比任何元素都大的哨兵值，确保比较条件始终成立）
        int r1 = cut1 == m ?
            Integer.MAX_VALUE :
            n1[cut1];
        // n2 右半部分的开头（cut2=n 时右半部分为空，使用哨兵值）
        int r2 = cut2 == n ?
            Integer.MAX_VALUE :
            n2[cut2];

        // 交叉比较: 左半部分的所有元素 ≤ 右半部分的所有元素，则为正确划分
        if (l1 <= r2 && l2 <= r1) {
            // 找到了正确的划分
            if ((m + n) % 2 == 1)
                // 奇数个: 左半部分的最大值即为中位数
                return Math.max(l1, l2);
            // 偶数个: 左半部分的最大值与右半部分的最小值的平均值即为中位数
            return (Math.max(l1, l2)
                + Math.min(r1, r2))
                / 2.0;
        } else if (l1 > r2) {
            // n1 左半部分末尾超过了 n2 右半部分开头 → 从 n1 中取的元素过多 → 减小 cut1
            hi = cut1 - 1;
        } else {
            // l2 > r1: 从 n1 中取的元素过少 → 增大 cut1
            lo = cut1 + 1;
        }
    }
    // 根据问题的约束条件，一定能找到正确的划分，因此不会到达这里
    return -1;
}
```
