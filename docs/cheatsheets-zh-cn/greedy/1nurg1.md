# Finding the Subarray With Maximum Sum — 查找具有最大总和的连续子数组

## 问题的本质

给定一个整数数组 `nums`。该数组可能同时包含正数和负数。需要在所有连续子数组（subarray）中，找到元素总和最大的子数组，并返回该**总和值**。

## 核心思想

当到达每个元素时，只有两种选择："延续之前的子数组"或"从当前元素开始一个新的子数组"。如果之前的累积和为负数，则丢弃它并重新开始一定比继续延续更优。

## 思考过程

1. **每个元素只有两种选择**: 当到达元素 `nums[i]` 时，可以采取的操作只有两种："将 `nums[i]` 追加到之前的子数组中进行延续"或"以 `nums[i]` 为起点开始一个新的子数组"。由于连续子数组的约束，不能跳过中间的元素
2. **判断延续还是重新开始的标准**: 如果之前的累积和 `currentSum` 为正数，将其加到 `nums[i]` 上会使结果大于 `nums[i]` 本身，因此选择延续。如果 `currentSum` 为负数，加上它会使结果小于 `nums[i]` 本身，因此丢弃它并重新开始。也就是说，只需选择 `currentSum + nums[i]` 和 `nums[i]` 中较大的一个即可
3. **用 `Math.max` 表达这个判断**: `currentSum = Math.max(currentSum + nums[i], nums[i])` 这一行代码就完成了延续和重新开始的判断。`currentSum + nums[i]` 对应延续，`nums[i]` 对应重新开始
4. **另外跟踪全局最大值**: `currentSum` 是"当前子数组的总和"，在遍历过程中值会上下波动。题目要求的是"整个遍历过程中的最大总和"，因此需要用另一个变量 `maxSum` 持续记录遍历过程中出现的 `currentSum` 的最大值
5. **将 `maxSum` 的初始值设为 `Integer.MIN_VALUE`**: 为了在数组所有元素均为负数时也能正确工作，将 `maxSum` 的初始值设为整数的最小值。如果初始化为0，当所有元素均为负数时，会错误地将"空子数组（总和为0）"判断为最大值
6. **最终返回 `maxSum`**: 当数组遍历结束时，`maxSum` 中已记录了所有连续子数组中的最大总和。返回该值即可

## 前置知识

### 什么是 Math.max

Math.max 是 Java 的标准方法，接收两个值并返回较大的一个。它可以用一行代码表达条件分支。

```java
Math.max(5, 3);       // 返回两个值中较大的一个 → 5
Math.max(-2, -7);     // 即使是负数之间也返回较大的一个 → -2
Math.max(a + b, b);   // 也可以比较表达式的结果
```

### 什么是 Integer.MIN_VALUE

Integer.MIN_VALUE 是表示 Java 中 `int` 类型最小值（-2,147,483,648）的常量。它被用作"尚未进行任何比较"状态的初始值。与任何整数比较时，`Math.max` 一定会选择对方的值。

```java
int maxSum = Integer.MIN_VALUE;   // 用int类型的最小值进行初始化
maxSum = Math.max(maxSum, -5);    // 任何值都比maxSum大 → -5
```

### 什么是连续子数组（subarray）

连续子数组是从数组中取出的相邻且不间断的元素序列。不能跳过元素进行选取。
例如：当 `nums = [-2, 1, -3, 4, -1, 2]` 时，`[4, -1, 2]` 是连续子数组（总和为5）。`[1, 4, 2]` 因为元素不相邻，所以不是连续子数组。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历数组一次即可完成 |
| Space | O(1) — 只使用 `maxSum` 和 `currentSum` 两个变量 |

## 代码

```java
// 输入: 可能包含正数和负数的整数数组 nums
// 输出: 以 int 形式返回连续子数组的最大总和
public int maxSubArray(int[] nums) {
    // 记录整个遍历过程中出现的子数组总和的最大值的变量
    // 用 Integer.MIN_VALUE 初始化，以便在所有元素均为负数时也能正确选出最大值
    // 注意: 如果用0初始化，当所有元素均为负数时，会错误地将"空子数组（总和为0）"判断为最大值
    int maxSum = Integer.MIN_VALUE;
    // 保存当前正在构建的子数组总和的变量。遍历开始时尚未包含任何元素，因此为0
    int currentSum = 0;

    // 从头到尾逐个遍历数组
    for (int num : nums) {
        // currentSum + num 是"延续之前子数组时的总和"
        // num 是"从当前元素开始新子数组时的总和"
        // 选择较大的一个，就能始终做出最优判断
        currentSum = Math.max(currentSum + num, num);
        // 如果当前子数组的总和超过了之前的最大值则更新，否则保持不变
        maxSum = Math.max(maxSum, currentSum);
    }
    // 遍历结束时，maxSum 中已记录了所有连续子数组中的最大总和
    return maxSum;
}
```
