# Finding the Minimum Jumps to Reach the End — 求解到达数组末尾的最小跳跃次数

## 问题的本质

给定一个整数数组 `nums`，每个元素 `nums[i]` 表示从该位置最多可以向前跳跃多少格。从索引0开始出发，返回到达最后一个索引所需的**最小跳跃次数**。题目保证一定能够到达末尾。

## 核心思路

将每次跳跃视为"一次跳跃所能到达的范围（窗口）"，每当到达窗口的边界时，将跳跃次数加1。在遍历窗口内元素的同时，记录下一个窗口的最远到达点，从而以O(1)的空间复杂度实现与BFS层级搜索相同的效果。

## 思考过程

1. **求最小次数的问题可以用BFS来解决**：将每个位置视为节点，将可跳跃的范围视为边，问题就转化为从索引0到末尾的最短路径问题。由于BFS按层级进行搜索，因此最先到达末尾的层级就是最小跳跃次数
2. **用窗口来表示BFS的层级**：普通的BFS使用队列，需要O(n)的空间。然而，在数组跳跃问题中，每个层级可到达的范围是一个连续区间，因此只需用区间的终点 `currentEnd` 就能表示当前层级
3. **在窗口内追踪下一个最远到达点**：遍历当前窗口内的元素（从上一个 `currentEnd` 到当前 `currentEnd`），将每个位置 `i` 能到达的最远点 `i + nums[i]` 的最大值记录在变量 `farthest` 中。该值即为下一个窗口的终点
4. **在窗口边界处确定跳跃**：当索引 `i` 到达 `currentEnd` 时，意味着当前窗口已经遍历完毕。此时将跳跃次数加1，并将 `currentEnd` 更新为 `farthest`，从而转移到下一个窗口
5. **循环范围到末尾的前一个位置为止**：将循环条件设为 `i < nums.length - 1`，可以避免在到达最后一个索引时多计算一次跳跃。由于题目保证一定能到达末尾，因此不需要进行到达判定
6. **最终返回的结果**：循环结束后，返回变量 `jumps` 中累积的最小跳跃次数

## 前置知识

### 什么是贪心BFS（贪心广度优先搜索）

BFS（广度优先搜索）是一种用于求解从图的起点到各节点最短路径的算法。通常使用队列来实现，但在数组跳跃问题中，由于可到达的范围是连续区间，因此可以通过只管理区间边界的贪心法获得相同的结果。在每个层级（对应一次跳跃）中贪心地选择可到达的最远点，就能求出最小跳跃次数。

### 什么是 Math.max

Math.max 是Java的标准方法，用于返回两个整数中较大的那个。该方法用于比较当前的最远到达点和新计算出的到达点，并保留距离更远的那个。

```java
Math.max(3, 7);       // 返回两个值中较大的那个 → 7
Math.max(farthest, i + nums[i]);  // 比较当前最远点和新的到达点
```

### 什么是窗口（跳跃范围）

窗口是指一次跳跃所能到达的连续索引区间。变量 `currentEnd` 表示窗口的右端。当 `i` 到达 `currentEnd` 时，意味着当前窗口已经遍历完毕，需要进行下一次跳跃。
例如：对于 `nums = [2,3,1,1,4]`，第一个窗口是 `[1,2]`（从索引0最多跳2格），下一个窗口是 `[3,4]`（窗口内的最远到达点为4）。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历数组一次 |
| Space | O(1) — 仅使用3个变量，不需要额外的数据结构 |

## 代码

```java
// 输入：整数数组 nums（每个元素表示从该位置的最大跳跃长度）
// 输出：以 int 形式返回到达最后一个索引所需的最小跳跃次数
public int jump(int[] nums) {
    // 记录跳跃次数的变量。每当到达窗口边界时加1
    int jumps = 0;
    // 当前跳跃窗口的右端。由于初始位于索引0，因此初始化为0
    int currentEnd = 0;
    // 从窗口内能够到达的最远索引。用于确定下一个窗口的右端
    int farthest = 0;

    // 遍历到末尾的前一个位置为止。到达末尾即完成目标，无需从该位置再进行跳跃
    for (int i = 0; i < nums.length - 1; i++) {
        // i + nums[i] 是从当前位置i进行最大跳跃后的目标索引
        // 如果该值比当前的farthest更远，则进行更新
        farthest = Math.max(farthest, i + nums[i]);

        // 到达当前窗口的右端时，需要进行下一次跳跃
        if (i == currentEnd) {
            // 将跳跃次数加1
            jumps++;
            // 将下一个窗口的右端设置为farthest。下一个窗口的范围是从 currentEnd+1 到新的 currentEnd
            currentEnd = farthest;
        }
    }
    // 返回累积的最小跳跃次数
    return jumps;
}
```
