# 寻找环形路线中可完成一圈的起始加油站 — Finding the Starting Gas Station for a Circular Route

## 问题的本质

给定长度为 `n` 的整数数组 `gas` 和 `cost`。`gas[i]` 表示在加油站 `i` 获得的燃料量，`cost[i]` 表示从加油站 `i` 移动到下一个加油站所需的燃料量。返回能够沿环形路线完成一圈的起始加油站的索引。如果不存在能完成一圈的加油站，则返回 `-1`。解最多只有一个。

## 核心思想

如果所有加油站的燃料收支总和为非负数，则必定存在解。由于累计燃料余量变为负数之前的所有加油站都不可能作为起始点，因此将下一个加油站设为新的起始候选并重置，即可通过一次遍历找到答案。

## 思考过程

1. **考虑每个加油站的燃料收支**: 在加油站 `i` 获得 `gas[i]` 的燃料并消耗 `cost[i]` 的燃料，因此净燃料变化为 `net = gas[i] - cost[i]`。如果 `net` 为正，则该加油站产生燃料盈余；如果为负，则产生燃料亏缺
2. **判断能否完成一圈**: 如果所有加油站的 `net` 之和（`totalBalance`）为非负数，则整条路线获得的燃料不少于消耗的燃料，因此必定存在某个起始点可以完成一圈。反之，如果 `totalBalance` 为负数，则无论从哪里出发燃料都不够，解不存在
3. **高效地筛选起始候选**: 假设从加油站 `start` 出发进行遍历，在某个位置 `i` 累计燃料余量（`currentBalance`）变为负数。此时，从 `start` 到 `i` 之间的任何加油站出发都无法越过 `i`。因为从 `start` 到中间某个加油站 `j` 的累计值是非负的，所以从 `j` 出发到达 `i` 时燃料会更少。因此，可以一次性排除 `start` 到 `i` 的所有加油站，将 `i + 1` 设为新的起始候选
4. **重置 currentBalance 并继续遍历**: 为了从新的起始候选 `i + 1` 重新追踪燃料余量，将 `currentBalance` 重置为 `0`，并将 `start` 更新为 `i + 1`。遍历本身从头到尾只需进行一次
5. **遍历结束后用 totalBalance 进行最终判断**: 遍历结束时，如果 `totalBalance >= 0`，则解存在，返回 `start`。如果 `totalBalance < 0`，则无法完成一圈，返回 `-1`

## 前置知识

### net（净燃料变化）的含义

每个加油站的燃料收支。通过 `net = gas[i] - cost[i]` 计算。为正表示燃料有盈余，为负表示燃料有亏缺。

```java
int net = gas[i] - cost[i];  // 计算加油站i的燃料收支
// 例: gas[i]=3, cost[i]=5 时 net=-2（燃料不足2）
// 例: gas[i]=4, cost[i]=1 时 net=3（燃料盈余3）
```

### totalBalance 和 currentBalance 的作用

`totalBalance` 是整条路线燃料收支的总和，用于判断能否完成一圈。`currentBalance` 是从当前起始候选到正在遍历的加油站的累计燃料余量，用于判断是否需要更新起始候选。

```java
int totalBalance = 0;    // 整条路线的燃料收支总和（用于判断能否完成一圈）
int currentBalance = 0;  // 从当前起始候选开始的累计燃料余量（用于判断是否更新候选）
totalBalance += net;     // 对所有加油站始终累加
currentBalance += net;   // 每次重置起始候选时归零
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历数组一次 |
| Space | O(1) — 仅使用3个变量，不依赖于输入规模 |

## 代码

```java
// 输入: 整数数组 gas（每个加油站获得的燃料量）和整数数组 cost（从每个加油站移动到下一个加油站所需的燃料量）
// 输出: 返回能够沿环形路线完成一圈的起始加油站索引（int 类型）。无法完成一圈时返回 -1
public int canCompleteCircuit(int[] gas, int[] cost) {
    // 整条路线的燃料收支总和（用于最终判断能否完成一圈）
    int totalBalance = 0;
    // 从当前起始候选开始的累计燃料余量（用于判断是否重置候选）
    int currentBalance = 0;
    // 起始候选的索引（从0开始，每次重置时更新）
    int start = 0;

    // 从索引0到数组末尾逐个遍历
    for (int i = 0; i < gas.length; i++) {
        // 计算加油站i的净燃料变化
        int net = gas[i] - cost[i];
        // 始终累加到整条路线的燃料收支总和中（最终用于判断能否完成一圈）
        totalBalance += net;
        // 累加到从当前起始候选开始的累计燃料余量中（相当于到达加油站i时的燃料余量）
        currentBalance += net;

        // 如果累计燃料余量变为负数，则从start到i的所有加油站都不可能作为起始点
        if (currentBalance < 0) {
            // 重置累计燃料余量，将下一个加油站设为新的起始候选
            currentBalance = 0;
            start = i + 1;
        }
    }
    // 如果整条路线的燃料收支总和为非负数，则可以完成一圈，返回start；否则返回-1
    return totalBalance >= 0 ? start : -1;
}
```
