# Determining if You Can Reach the End of an Array — 判断是否能到达数组末尾

## 问题的本质

给定一个整数数组 `nums`。每个元素 `nums[i]` 表示从该索引向前跳跃的**最大长度**。从索引 `0` 开始，返回一个 `boolean` 值，表示是否能到达数组的**最后一个索引**。

## 核心思路

持续更新每个位置"从这里能到达的最远点"，当最远点落后于当前位置时，就可以判定为无法到达。不需要追踪每条跳跃路径，只需维护"到目前为止能到达的最远索引"这一个值就足够了。

## 思考过程

1. **可达性由最远点决定**：判断索引 `i` 是否可达，取决于之前所有元素计算出的"可达最远索引"是否大于等于 `i`。不需要路径的具体细节，只有最远点是重要的
2. **最远点可以用一个变量管理**：在每个索引 `i` 处，`i + nums[i]` 是从该位置出发的最远到达点。将其与之前的最远点比较并保留较大值，就能用一个变量追踪整体的可达范围
3. **无法到达的判定条件**：从左到右遍历数组时，如果当前索引 `i` 超过了最远点 `maxReach`，说明索引 `i` 本身就不可达。即 `i > maxReach` 是无法到达的条件
4. **提前终止的条件**：当 `maxReach` 大于等于数组最后一个索引 `nums.length - 1` 时，可以确定能到达末尾，因此可以跳过剩余的遍历直接返回 `true`
5. **遍历完成的情况**：如果循环结束时既没有返回 `false` 也没有返回 `true`，说明所有索引都是可达的，因此返回 `true`

## 前置知识

### 什么是 Math.max

Math.max 是一个静态方法，接收两个整数并返回较大的值。在更新最远点时，用于比较"当前最远点"和"新计算的到达点"。

```java
Math.max(3, 5);    // 返回 5 — 两个参数中较大的一个
Math.max(7, 2);    // 返回 7
Math.max(4, 4);    // 返回 4 — 相等时返回该值
```

### 什么是 maxReach（最远到达索引）

maxReach 是一个变量，表示从数组开头到当前位置考虑所有元素后能到达的最远索引。在索引 `i` 处，`i + nums[i]` 是从该位置能到达的最远点，通过 `maxReach = Math.max(maxReach, i + nums[i])` 始终保持最大值。
例如：当 `nums = [2, 3, 1, 1, 4]` 时，`i=0` 时 `maxReach = 0 + 2 = 2`，`i=1` 时 `maxReach = max(2, 1 + 3) = 4`，因此可以判定能到达末尾索引 `4`。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历数组一次 |
| Space | O(1) — 额外变量只有 `maxReach` 一个 |

## 代码

```java
// 输入：整数数组 nums（每个元素表示从该索引出发的最大跳跃长度）
// 输出：如果能到达最后一个索引则返回 true，否则返回 false
boolean canJump(int[] nums) {
    // 追踪到目前为止能到达的最远索引的变量
    // 起始点是索引 0，因此初始值为 0
    int maxReach = 0;

    // 从数组开头到末尾逐个遍历
    for (int i = 0; i < nums.length; i++) {
        // 如果当前索引超过了最远到达点，说明无法到达这里
        if (i > maxReach) return false;

        // i + nums[i] 是从当前位置能到达的最远索引
        // 与之前的 maxReach 比较并保留较大值
        maxReach = Math.max(maxReach,
            i + nums[i]);

        // 如果最远到达点大于等于数组最后一个索引，则确定能到达末尾
        if (maxReach >= nums.length - 1)
            return true;
    }
    // 循环完成时，说明所有索引都是可达的，因此返回 true
    return true;
}
```
