# Checking Validity of a Parenthesis String With Wildcards — 判定带通配符的括号字符串是否有效

## 问题的本质

给定一个仅由 `(`、`)`、`*` 三种字符组成的字符串。`*` 可以被视为 `(`、`)` 或空字符中的任意一种。需要判定该字符串是否**能够成为有效的括号序列**，并以 `boolean` 形式返回结果。

## 核心思路

由于 `*` 的处理方式不确定，因此不将开括号的数量作为单一值来追踪，而是作为"可能的范围（最小值 low ～ 最大值 high）"来追踪。如果该范围在遍历过程中始终有效，并且最终包含0，则该字符串是有效的。

## 思考过程

1. **可以通过开括号的计数来判定括号的有效性**：从左到右遍历字符串，遇到 `(` 时计数+1，遇到 `)` 时计数-1。如果中途计数变为负数则无效，最终为0则有效。这是括号判定的基本原理
2. **存在 `*` 时计数无法确定为单一值**：`*` 有3种解释方式，因此计数不是单一值而是"范围"。将 `*` 解释为 `(` 时计数+1，解释为 `)` 时计数-1，解释为空字符时计数±0。也就是说，每遇到一个 `*`，范围就会扩大
3. **使用两个变量追踪范围**：`low` 表示开括号计数的最小值（尽可能将 `*` 视为 `)` 或空字符的情况），`high` 表示最大值（尽可能将 `*` 视为 `(` 的情况）。仅用这两个变量就能覆盖所有模式
4. **遍历过程中如果 `high` 变为负数，则立即判定为无效**：`high` 是开括号计数的最大值，如果它变为负数，说明无论如何解释 `*`，`)` 都是过多的，不可能构成有效的括号序列
5. **如果 `low` 变为负数，则将其钳制为0**：`low` 变为负数只是因为包含了"让 `)` 多余的解释"，实际上只要将 `*` 视为空字符就能维持计数在0以上。负值对应的是实际不会选择的解释，因此将 `low` 修正为0
6. **最终通过 `low == 0` 来判定结果**：遍历完成时，如果 `low` 为0，则意味着"存在一种使所有开括号都能被关闭的解释"，因此返回 `true`

## 前置知识

### 括号序列有效性判定的基本原理

从左到右遍历字符串，管理开括号的计数。遇到 `(` 时+1，遇到 `)` 时-1，如果中途没有变为负数且最终为0，则是有效的括号序列。

```java
int count = 0;
for (char c : s.toCharArray()) {
    if (c == '(') count++;
    else count--;
    if (count < 0) return false;  // 闭括号过多
}
return count == 0;  // 所有开括号是否都已被关闭
```

### Math.max 是什么

该方法返回两个值中较大的一个。可用于将值修正（钳制）为不低于特定下限的用途。

```java
Math.max(3, 0);    // → 3（3大于等于0，因此保持不变）
Math.max(-1, 0);   // → 0（-1小于0，因此被修正为0）
```

### toCharArray 是什么

该方法将字符串转换为 `char` 数组。在使用 for-each 循环逐字符遍历字符串时使用。

```java
String s = "(*)";
char[] chars = s.toCharArray();  // → ['(', '*', ')']
for (char c : s.toCharArray()) {
    // 每次循环将一个字符赋值给 c
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历字符串一次 |
| Space | O(1) — 仅使用 `low` 和 `high` 两个变量 |

## 代码

```java
// 输入: 仅由 '('、')'、'*' 组成的字符串 s
// 输出: 以 boolean 形式返回该字符串是否能成为有效的括号序列
public boolean checkValidString(String s) {
    // low: 开括号计数的最小值，high: 最大值
    // 用这两个变量追踪 * 的所有解释模式下计数的范围
    int low = 0, high = 0;

    // 从头开始逐字符遍历字符串
    for (char c : s.toCharArray()) {
        if (c == '(') {
            // 开括号: 无论哪种解释都将计数加1，因此范围的两端都+1
            low++;
            high++;
        } else if (c == ')') {
            // 闭括号: 无论哪种解释都将计数减1，因此范围的两端都-1
            low--;
            high--;
        } else {
            // '*': 解释为 ) 时最小值下降，解释为 ( 时最大值上升
            // 空字符的解释包含在该范围之内
            low--;
            high++;
        }

        // 如果最大值为负，则无论如何解释 * 闭括号都过多，因此无效
        if (high < 0) return false;

        // low 变为负数是因为过多地将 * 解释为了 )，
        // 实际上只要不选择该解释即可，因此将最小值修正为0
        low = Math.max(low, 0);
    }

    // 如果 low 为0，则"存在一种使所有开括号都被关闭的 * 的解释"，返回 true
    // 如果 low 大于0，则无论如何解释开括号都会多余，返回 false
    return low == 0;
}
```
