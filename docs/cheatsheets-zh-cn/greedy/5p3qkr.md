# Partitioning a String Into Maximum Parts — 将字符串分割为最多的部分，使每个字符只出现在一个部分中

## 问题的本质

给定一个由小写英文字母组成的字符串 `s`。要求将字符串分割为尽可能多的部分，使得每个字符最多只出现在一个部分中。返回一个包含每个部分**长度**的列表。

## 核心思路

如果某个字符包含在当前部分中，则必须将该部分延伸到该字符的最后出现位置。只要预先计算每个字符的最后出现位置，就可以通过一次遍历贪心地确定各部分的边界。

## 思考过程

1. **理解分割的约束条件**: 同一个字符不能跨越两个部分。也就是说，包含某个字符的部分至少需要延伸到该字符的最后出现位置
2. **预先求出每个字符的最后出现位置**: 遍历字符串一次，将每个字符最后出现的索引记录到数组中。由于英文小写字母只有26种，因此大小为26的数组就足够了
3. **贪心地扩展部分的终点**: 从字符串开头进行遍历，将当前部分中所有字符的最后出现位置的最大值作为 `end` 进行追踪。每遇到一个新字符，就将 `end` 与该字符的最后出现位置进行比较并更新
4. **判断部分的确定条件**: 当当前索引 `i` 到达 `end` 时，可以保证当前部分内的所有字符都包含在该部分的范围内。此时确定当前部分，并开始下一个部分
5. **计算部分的长度**: 每当确定一个部分时，通过 `end - start + 1` 计算该部分的长度，并将其添加到结果列表中。然后将下一个部分的起始位置 `start` 更新为 `i + 1`

## 前置知识

### 字符的索引转换

在Java中，`char` 类型可以作为整数处理。通过 `s.charAt(i) - 'a'`，可以将小写字母 `'a'` 转换为 `0`、`'b'` 转换为 `1`、...、`'z'` 转换为 `25`。这样就可以用大小为26的数组来管理所有小写字母。

```java
char c = 'c';
int index = c - 'a';    // 2（'c'是从'a'开始的第2个字母）
int[] arr = new int[26]; // 存储26个字母的数组
arr[c - 'a'] = 5;       // 在'c'对应的位置存储值5
```

### Math.max 是什么

Math.max 是一个返回两个值中较大值的方法。在扩展部分终点时，用于比较当前的 `end` 和新字符的最后出现位置，从而采用更远的那个位置。

```java
Math.max(3, 7);   // 返回7
Math.max(10, 2);  // 返回10
```

### ArrayList 是什么

ArrayList 是一种可变长度的列表。由于部分的数量事先未知，因此适合逐个添加每个部分的长度。

```java
List<Integer> res = new ArrayList<>();  // 创建空列表
res.add(9);    // 在末尾添加9 → [9]
res.add(7);    // 在末尾添加7 → [9, 7]
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历字符串两次（一次记录最后出现位置，一次进行部分分割） |
| Space | O(1) — 仅使用大小为26的固定数组，不依赖于输入规模 |

## 代码

```java
// 输入: 由小写英文字母组成的字符串 s
// 输出: 返回包含每个部分长度的 List<Integer>
List<Integer> partitionLabels(String s) {
    // 使用大小为26的整数数组，保存每个字符('a'~'z')的最后出现索引
    // 由于英文小写字母只有26种，因此数组大小固定为26
    int[] last = new int[26];

    // 第一次遍历: 记录每个字符的最后出现位置
    // 如果同一个字符出现多次，后面的索引会覆盖前面的，因此最终保留的是最后的位置
    for (int i = 0; i < s.length(); i++) {
        last[s.charAt(i) - 'a'] = i;
    }

    // 由于部分数量事先未知，因此使用可变长度列表
    List<Integer> res = new ArrayList<>();
    // start: 当前部分的起始位置，end: 当前部分的终点位置
    int start = 0, end = 0;

    // 第二次遍历: 贪心地确定每个部分
    for (int i = 0; i < s.length(); i++) {
        // 如果当前字符的最后出现位置比 end 更远，则将部分的终点扩展到该位置
        // 这样可以确保 end 始终保持为当前部分内所有字符的最后出现位置的最大值
        end = Math.max(end,
            last[s.charAt(i) - 'a']);

        // 当 i 到达 end 时 → 保证当前部分内的所有字符都包含在该范围内
        // 因为部分内的任何字符都不会在 end 之后再次出现
        if (i == end) {
            // 通过 end - start + 1 计算部分的长度，并添加到结果列表中
            res.add(end - start + 1);
            // 更新下一个部分的起始位置
            start = i + 1;
        }
    }
    // 返回包含所有部分长度的列表
    return res;
}
```
