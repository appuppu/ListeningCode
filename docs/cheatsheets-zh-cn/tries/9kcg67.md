# Designing a Word Dictionary With Wildcard Search — 带通配符的字典单词搜索

## 问题的本质

设计一个数据结构，支持单词的添加和搜索两种操作。搜索时，点号 `.` 作为通配符，可以匹配任意一个字符。例如，当字典中已注册 "bad" 时，`search("b.d")` 返回 `true`，`search("b.e")` 返回 `false`。

## 核心思路

将单词存储在Trie中，普通字符只需沿着对应的子节点向下遍历即可，但遇到点号时，则向"所有子节点"分支并进行深度优先搜索，从而实现匹配任意一个字符的搜索功能。

## 思考过程

1. **希望高效地实现单词的添加和前缀匹配搜索**: Trie适合作为逐字符共享存储字符串的数据结构。使用Trie，具有相同前缀的单词可以共享节点，从而兼顾内存效率和搜索效率
2. **普通字符的搜索可以通过Trie的基本操作来完成**: 对于字符 `c`，只需沿着当前节点的 `children[c - 'a']` 向下遍历即可。如果子节点为 `null` 则不匹配，如果存在则继续处理下一个字符
3. **点号意味着向所有子节点分支**: 点号可以匹配任意一个字符，因此需要尝试当前节点的26个子节点中所有不为 `null` 的节点。只要其中任意一个与剩余字符串匹配，就可以返回 `true`
4. **使用深度优先搜索（DFS）来探索分支**: 对点号分支出的每条路径进行递归遍历，当到达单词末尾时，如果 `isEnd` 标志为 `true`，则搜索成功。使用DFS可以统一处理分支逻辑和普通字符的处理逻辑
5. **确定递归的终止条件**: 当处理完字符串的所有字符时（`idx == word.length()`），如果当前节点的 `isEnd` 为 `true`，则该单词存在。如果在中途子节点变为 `null`，则该路径不匹配
6. **最终返回的结果**: `search` 方法从根节点开始递归地执行DFS，只要存在一条匹配的路径就返回 `true`，否则返回 `false`

## 前置知识

### 什么是Trie（字典树）

Trie是一种将字符串逐字符分解并存储在节点中的树结构。每个节点最多有26个子节点（a〜z），从根节点到叶节点的路径构成一个单词。具有相同前缀的单词共享节点，因此Trie适合用于存储字典。

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // 对应a〜z的26个子节点
    boolean isEnd = false;                    // 是否存在以该节点结尾的单词
}
```

### 什么是深度优先搜索（DFS）

深度优先搜索是一种树或图的遍历方法。沿着一条路径一直走到末端，到达死胡同后回退一步尝试另一条路径。使用递归实现最为自然，适合用于Trie的分支搜索。

```java
boolean dfs(TrieNode node, String word, int idx) {
    // idx是当前正在处理的字符位置
    // 递归地遍历子节点，寻找满足条件的路径
}
```

### char的整数转换

在Java中，`char` 类型具有整数值。通过 `c - 'a'` 可以获得字符 `c` 在字母表中的位置（0〜25）。该值用作Trie的 `children` 数组的索引。

```java
char c = 'd';
int idx = c - 'a';  // idx = 3（'a'=0, 'b'=1, 'c'=2, 'd'=3）
```

## 计算复杂度

| | 值 |
|---|---|
| Time (addWord) | O(m) — 与单词长度m成正比地遍历Trie节点 |
| Time (search) | O(26^d × m) — d是点号的个数，m是单词的长度。如果没有点号则为O(m) |
| Space | O(n × m) — 将n个单词（平均长度m）存储在Trie中 |

## 代码

```java
// 输入: addWord(word) 接收字符串 word 并将其添加到字典中。search(word) 接收字符串 word（可能包含 "."）
// 输出: search 如果字典中存在匹配的单词则返回 true，不存在则返回 false

class TrieNode {
    TrieNode[] children;  // 对应a〜z的26个子节点
    boolean isEnd;        // 是否存在以该节点结尾的单词

    TrieNode() {
        children = new TrieNode[26];
        isEnd = false;
    }
}

class WordDictionary {
    TrieNode root;  // Trie的根节点

    WordDictionary() {
        root = new TrieNode();
    }

    // 将单词添加到Trie中
    void addWord(String word) {
        // 将当前节点初始化为根节点
        TrieNode node = root;
        // 从头开始依次处理单词的每个字符
        for (char c : word.toCharArray()) {
            // 通过 c - 'a' 求出字符 c 在 children 数组中对应的位置
            int idx = c - 'a';
            // 如果子节点不存在则新建一个
            if (node.children[idx] == null)
                node.children[idx] = new TrieNode();
            // 移动到子节点
            node = node.children[idx];
        }
        // 记录单词的终端。表示字典中存在以该节点结尾的单词
        node.isEnd = true;
    }

    // 从根节点开始执行带通配符的搜索
    boolean search(String word) {
        // 从根节点的位置0开始执行DFS
        return dfs(root, word, 0);
    }

    // 使用DFS递归地搜索Trie
    boolean dfs(TrieNode node, String word, int idx) {
        // 终止条件：处理完所有字符后，返回当前节点是否为单词的终端
        // 如果为 true 则单词存在，如果为 false 则只有部分匹配的单词
        if (idx == word.length())
            return node.isEnd;

        char c = word.charAt(idx);

        if (c == '.') {
            // 点号的情况：尝试所有26个子节点（匹配任意一个字符）
            for (TrieNode child : node.children) {
                // 对不为 null 的子节点进行递归搜索
                if (child != null && dfs(child, word, idx + 1))
                    return true;  // 只要任意一条路径匹配就立即返回 true
            }
            // 尝试完所有子节点仍未返回 true 则不匹配
            return false;
        } else {
            // 普通字符的情况：通过 c - 'a' 求出索引，沿着对应的子节点遍历
            int i = c - 'a';
            // 如果子节点不存在则没有对应的字符，不匹配
            if (node.children[i] == null)
                return false;
            // 如果子节点存在则在下一个字符位置 idx + 1 处递归
            return dfs(node.children[i], word, idx + 1);
        }
    }
}
```
