# Finding All Words From a Dictionary in a Grid — 在网格上同时搜索字典中的所有单词

## 问题的本质

给定一个字符的二维网格 `board` 和一个单词列表 `words`。在网格上依次经过相邻的单元格（上下左右）来构成单词，从 `words` 中找出所有可以构成的单词并返回。每个单元格在构成一个单词的过程中只能使用一次。

## 核心思路

将单词列表中的所有单词存入Trie，在从网格的每个单元格进行DFS时沿着Trie节点遍历，从而同时搜索所有单词。由于可以在Trie中不存在分支的方向上立即终止DFS，因此能大幅减少无效搜索。

## 思考过程

1. **希望同时搜索多个单词**: 如果对每个单词单独进行DFS，计算量将达到单词数×网格全部单元格数×最大单词长度。当多个单词共享相同的前缀时，如果能在一次DFS中同时搜索多个单词，效率会更高
2. **Trie适合管理公共前缀**: Trie也被称为前缀树，它将字符串的公共前缀共享为一条路径。将所有单词插入Trie后，在DFS过程中可以以O(1)的时间判断当前路径是否为某个单词的前缀
3. **在Trie节点中保存单词本身**: 如果在单词的末尾节点中保存完整的单词字符串，那么当DFS到达该节点时，就可以立即获取"找到了哪个单词"
4. **从网格的每个单元格以Trie的根节点为起点进行DFS**: 以每个单元格为起点，从Trie的根节点开始沿着字符进行DFS。如果当前字符对应的子节点在Trie中不存在，则立即终止该方向的搜索（剪枝）
5. **已访问单元格的标记**: 为了在DFS过程中不重复访问同一个单元格，将当前正在访问的单元格的字符临时替换为特殊字符 `'#'`。DFS结束后恢复为原来的字符（回溯）
6. **防止重复**: 同一个单词可能通过多条路径被找到。在将单词添加到结果列表时，将该Trie节点的 `word` 设置为 `null`，从而防止同一个单词被重复添加

## 前置知识

### 什么是Trie（字典树）

Trie是一种用于高效存储和检索字符串集合的树结构。每个节点最多有26个子节点（a～z），从根节点到叶节点的路径表示一个字符串。具有公共前缀的字符串会共享路径，因此前缀判断可以在O(字符串长度)内完成。

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a～z共26个字符的子节点数组
    String word = null;                       // 在该节点处完成的单词（若非末尾则为null）
}

// 向Trie中插入单词
TrieNode root = new TrieNode();
TrieNode node = root;
for (char c : "cat".toCharArray()) {
    int i = c - 'a';                          // 将字符转换为索引（'a'→0, 'b'→1, ...）
    if (node.children[i] == null)
        node.children[i] = new TrieNode();    // 若子节点不存在则新建
    node = node.children[i];                  // 移动到子节点
}
node.word = "cat";                            // 在末尾节点保存单词
```

### 什么是回溯

回溯是DFS（深度优先搜索）的一种，在搜索过程中修改状态，搜索结束后将状态恢复原样。这样可以保证一条搜索路径中的状态修改不会影响其他路径。

```java
board[r][c] = '#';    // 标记为正在访问（防止其他路径重新访问该单元格）
// ... 通过DFS搜索上下左右 ...
board[r][c] = ch;     // 恢复为原来的字符（使其可在从其他起点开始的搜索中重新使用）
```

### char与int的转换

在Java中，`char` 类型具有整数值，因此可以通过计算字符的差值来转换为索引。

```java
char ch = 'c';
int index = ch - 'a';   // 'c' - 'a' = 2（用作数组的索引）
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(M × N × 4^L) — M×N为网格的单元格数，L为最长单词的长度。从每个单元格最多向4个方向递归L次 |
| Space | O(所有单词的字符总数) — 在Trie中存储所有单词所需的空间 |

## 代码

```java
// 输入: 字符的二维数组 board 和字符串数组 words
// 输出: 返回包含 board 上所有可构成单词的 List<String>

class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a～z的子节点
    String word = null;                       // 在该节点处完成的单词
}

// 将所有单词插入Trie并返回根节点
TrieNode buildTrie(String[] words) {
    // 创建一个根节点来构建空的Trie（作为所有单词搜索的起点）
    TrieNode root = new TrieNode();
    // 将 words 中的每个单词插入Trie
    for (String w : words) {
        TrieNode node = root;
        // 从根节点开始逐字符遍历子节点
        for (char c : w.toCharArray()) {
            int i = c - 'a';
            // 若子节点不存在则新建
            if (node.children[i] == null)
                node.children[i] = new TrieNode();
            node = node.children[i];
        }
        // 在单词的末尾节点保存单词字符串（DFS中到达该节点时可立即获取完成的单词）
        node.word = w;
    }
    return root;
}

// 沿着Trie节点在网格上进行DFS
void dfs(char[][] board, int r, int c,
    TrieNode node, List<String> res) {
    // 边界检查: 若行 r 或列 c 超出网格范围则立即返回
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length)
        return;
    char ch = board[r][c];
    // 若单元格为访问中标记 '#' 则立即返回（防止在同一路径内重复访问）
    if (ch == '#') return;
    // 获取当前字符对应的Trie子节点
    TrieNode next = node.children[ch - 'a'];
    // 若子节点不存在则Trie中没有沿此方向继续的单词（剪枝）
    if (next == null) return;
    // 若单词已完成则添加到结果中，并设置为null以防止重复
    //（因为同一个单词可能通过多条路径被找到）
    if (next.word != null) {
        res.add(next.word);
        next.word = null;
    }
    // 将当前单元格替换为 '#' 标记为正在访问
    board[r][c] = '#';
    // 向上下左右4个方向传递next节点并递归执行DFS
    dfs(board, r + 1, c, next, res);
    dfs(board, r - 1, c, next, res);
    dfs(board, r, c + 1, next, res);
    dfs(board, r, c - 1, next, res);
    // 将单元格的字符恢复为原来的 ch（回溯: 使其可在从其他起点开始的搜索中重新使用）
    board[r][c] = ch;
}

// 主函数: 在网格上搜索字典中的所有单词
List<String> findWords(char[][] board, String[] words) {
    // 将所有单词插入Trie
    TrieNode root = buildTrie(words);
    // 创建一个空列表来存储结果
    List<String> res = new ArrayList<>();
    // 通过双重for循环遍历所有单元格 (i, j)，以每个单元格为起点执行DFS
    // 向DFS传递Trie的根节点
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            dfs(board, i, j, root, res);
        }
    }
    // 所有单元格的DFS完成后，返回结果
    return res;
}
```
