# 按面积查找最大岛屿 — 在2D网格上查找面积最大的岛屿

## 问题的本质

给定一个由 `1`（陆地）和 `0`（水）组成的2D二进制网格。岛屿是由上下左右相邻的 `1` 的单元格连通而成的组。在网格中所有岛屿中，求出**最大的面积**（单元格数）并返回。如果不存在岛屿，则返回 `0`。

## 核心思路

从每个陆地单元格出发，通过DFS计算连通的陆地数量，即可求出岛屿的面积。与其使用单独的数组来管理已访问的单元格，不如将已访问单元格的值改写为 `0`，这样无需额外内存即可防止重复访问。

## 思考过程

1. **岛屿的面积就是连通分量的大小**：网格上的 `1` 通过上下左右连通形成的组构成一个岛屿。岛屿的面积就是该组中包含的单元格个数。因此，只需求出每个连通分量的大小，并返回其最大值即可
2. **DFS适合用于连通分量的搜索**：如果某个单元格 `(r, c)` 的值为 `1`，则以该单元格为起点，通过DFS递归地搜索上下左右的相邻单元格，计算所有连通的 `1` 的数量，从而求出该岛屿的面积
3. **需要一种机制来避免对同一单元格进行多次计数**：如果DFS重复访问已访问过的单元格，就会导致面积被重复计数。通常的做法是准备一个 `boolean[][] visited` 数组来记录已访问状态，但这需要O(m × n)的额外内存
4. **将已访问单元格改写为 `0` 即可省去额外内存**：在DFS中将已访问单元格的值从 `1` 改为 `0`，该单元格就会被视为水，在后续搜索中不会被再次访问。这样无需使用 `visited` 数组即可防止重复，辅助内存降为O(1)
5. **通过DFS的返回值来汇总面积**：DFS将已访问单元格自身的 `1`（计数）加上上下左右4个方向递归调用的返回值后返回。基准条件是：超出网格范围或值为 `0` 的单元格返回 `0`。由此，一次DFS调用即可递归地汇总整个岛屿的面积
6. **遍历整个网格以求最大值**：使用双重for循环遍历网格的所有单元格，对每个单元格调用DFS。将DFS的返回值（岛屿面积）与当前最大值进行比较，保留较大的值。对于值为 `0` 的单元格，DFS的基准条件会立即返回 `0`，因此无需特殊的分支处理

## 前置知识

### 什么是DFS（深度优先搜索）

DFS是一种用于图或网格的搜索算法。从一个节点出发，尽可能深入地前进，然后再回溯。在2D网格中，从某个单元格递归地向上下左右的相邻单元格移动，即可访问所有连通的单元格。

```java
// 2D网格中DFS的基本结构
void dfs(int[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length)
        return;                    // 超出网格范围则返回
    dfs(grid, r - 1, c);          // 向上递归
    dfs(grid, r + 1, c);          // 向下递归
    dfs(grid, r, c - 1);          // 向左递归
    dfs(grid, r, c + 1);          // 向右递归
}
```

### 什么是In-place Modification（原地修改）

原地修改是一种通过直接修改输入数据本身来记录状态的手法，无需使用额外的数据结构（如数组或集合等）。在本题中，通过将已访问的陆地单元格改写为 `0`，来替代 `visited` 数组的功能。

```java
grid[r][c] = 0;  // 将已访问的陆地(1)改写为水(0)
```

### 什么是Math.max

Math.max是Java的标准方法，用于比较两个值并返回较大的那个。常用于在循环中持续更新最大值的场景。

```java
Math.max(3, 7);   // → 7（返回较大的值）
Math.max(10, 2);  // → 10
```

## 复杂度

| | 值 |
|---|---|
| Time | O(m × n) — 每个单元格最多被访问2次（循环中1次，DFS中1次） |
| Space | O(1) 辅助内存 — 不使用visited数组而是直接修改网格。但递归栈最多使用O(m × n)的空间 |

## 代码

```java
// 输入: 由1（陆地）和0（水）组成的2D整数数组 grid
// 输出: 以int形式返回网格中最大岛屿的面积。如果没有岛屿则返回0

// DFS: 计算连通的陆地单元格数量，并将已访问的单元格改写为0
int dfs(int[][] grid, int r, int c) {
    // 基准条件: 超出范围或为水(0)/已访问则不计数
    if (r < 0 || r >= grid.length
        || c < 0 || c >= grid[0].length
        || grid[r][c] == 0)
        return 0;

    // 将陆地(1)改写为水(0)以标记为已访问（通过in-place modification省去visited数组）
    grid[r][c] = 0;

    // 返回自身的1 + 上下左右连通单元格数的总和
    // 通过累加4个方向递归的返回值，递归地汇总整个岛屿的面积
    return 1 + dfs(grid, r - 1, c)   // 上
             + dfs(grid, r + 1, c)   // 下
             + dfs(grid, r, c - 1)   // 左
             + dfs(grid, r, c + 1);  // 右
}

int maxAreaOfIsland(int[][] grid) {
    // 获取网格的行数和列数
    int m = grid.length;
    int n = grid[0].length;
    // 将最大面积变量初始化为0（如果没有岛屿则直接返回该值）
    int maxArea = 0;

    // 使用双重for循环遍历所有单元格，求各岛屿面积的最大值
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // 对于值为0的单元格，DFS的基准条件会立即返回0，因此无需特殊分支处理
            maxArea = Math.max(maxArea,
                dfs(grid, i, j));

    return maxArea;
}
```
