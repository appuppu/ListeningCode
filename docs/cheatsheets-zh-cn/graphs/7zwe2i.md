# Capturing Surrounded Regions on a Board — 捕获棋盘上被包围的区域

## 问题的本质

给定一个由 `'X'` 和 `'O'` 组成的 m×n 棋盘。将所有被 `'X'` **完全包围**的 `'O'` 区域全部翻转为 `'X'`。但是，与棋盘**边界（边框）**相邻的 `'O'` 以及从该处连通的 `'O'` 不属于被包围的区域，因此不能翻转。

## 核心思路

不是"寻找被包围的 O"，而是用逆向思维来思考："先标记未被包围的 O（即从边界可达的 O），剩下的 O 就全部是被包围的"。从边界的 O 出发，通过 DFS 将连通的单元格标记为安全，最后对棋盘进行一次扫描，就可以将判定和翻转分离开来。

## 思考过程

1. **思考未被包围的 O 的特征**：`'O'` 不被捕获的条件是，该 `'O'` 位于棋盘边界上，或者通过上下左右的连通与边界上的 `'O'` 相连。换言之，从边界的 `'O'` 无法到达的 `'O'` 全部是被包围的
2. **从边界开始探索**：扫描棋盘的四条边（上边、下边、左边、右边），每当发现 `'O'` 时，以该位置为起点执行 DFS。通过 DFS 能到达的所有 `'O'` 都是"安全的（不可捕获的）"
3. **用标记区分安全的单元格**：将 DFS 访问过的 `'O'` 临时替换为标记 `'S'`（Safe）。这样在 DFS 结束后，棋盘上剩余的 `'O'` 就只有"尚未标记的＝被包围的"单元格
4. **对棋盘进行一次扫描完成翻转和还原**：扫描所有单元格，仍为 `'O'` 的单元格是被包围的，将其翻转为 `'X'`。`'S'` 的单元格是安全的 `'O'`，将其还原为原来的 `'O'`。`'X'` 的单元格保持不变
5. **DFS 的递归结构**：从每个单元格向上下左右四个方向递归探索。越界检查和非 `'O'` 单元格的剪枝同时兼作已访问判定（已替换为 `'S'` 的单元格不是 `'O'`，因此不会被重复访问）

## 前置知识

### 什么是 DFS（深度优先搜索）

DFS 是一种用于探索图或网格的算法。从某个节点出发，沿一个方向尽可能深入地前进，遇到死路后回退并尝试其他方向。可以通过递归调用自然地实现。在网格上，递归地访问上下左右四个方向。

```java
// 网格上 DFS 的基本模式
void dfs(char[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length          // 越界检查
        || c < 0 || c >= grid[0].length
        || grid[r][c] != 'O')              // 非目标单元格则剪枝
        return;
    grid[r][c] = 'S';                      // 标记为已访问（同时防止重复访问）
    dfs(grid, r + 1, c);                   // 下
    dfs(grid, r - 1, c);                   // 上
    dfs(grid, r, c + 1);                   // 右
    dfs(grid, r, c - 1);                   // 左
}
```

### 边界（边框）单元格的遍历方法

在 m×n 的棋盘上，要枚举四条边上的单元格，可以按如下方式操作。上边和下边遍历列，左边和右边遍历行。

```java
int m = board.length;    // 行数
int n = board[0].length; // 列数

// 遍历上边（第0行）和下边（第m-1行）的所有列
for (int j = 0; j < n; j++) {
    process(board[0][j]);      // 上边
    process(board[m - 1][j]);  // 下边
}
// 遍历左边（第0列）和右边（第n-1列）的所有行
for (int i = 0; i < m; i++) {
    process(board[i][0]);      // 左边
    process(board[i][n - 1]);  // 右边
}
```

### 什么是标记技法

标记技法是将棋盘上的单元格临时替换为另一个字符（此处为 `'S'`），以此区分"已访问"和"未访问"的方法。它不需要另外准备 `boolean[][]` 的访问数组，而是利用棋盘本身来进行状态管理。在处理结束后将标记还原为原始值。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(m × n) — 从边界出发的 DFS 最多访问每个单元格一次，最终扫描也只遍历所有单元格一次 |
| Space | O(m × n) — DFS 的递归调用栈在最坏情况下深度可达所有单元格的数量 |

## 代码

```java
// 输入：由 'X' 和 'O' 组成的 m×n 二维字符数组 board
// 输出：就地（in-place）修改 board。将被包围的 'O' 翻转为 'X'，无返回值（void）

// 通过 DFS 将从边界可达的 O 替换为标记 S
void dfs(char[][] board, int r, int c, int m, int n) {
    // 如果越界或单元格不是 O 则不做任何操作（已替换为 S 的单元格也会被排除）
    // 已替换为 'S' 的单元格不是 'O'，因此不会被重复访问
    if (r < 0 || r >= m
        || c < 0 || c >= n
        || board[r][c] != 'O')
        return;

    // 替换为安全标记 S（同时兼作已访问标记）
    // 不需要另外准备 boolean[][]，利用棋盘本身进行状态管理
    board[r][c] = 'S';

    // 向上下左右四个方向递归探索
    dfs(board, r + 1, c, m, n);
    dfs(board, r - 1, c, m, n);
    dfs(board, r, c + 1, m, n);
    dfs(board, r, c - 1, m, n);
}

public void solve(char[][] board) {
    // 获取行数和列数。用于后续的越界检查和边界遍历
    int m = board.length;     // 行数
    int n = board[0].length;  // 列数

    // 从上边和下边的每一列开始执行边界 DFS
    // dfs 仅在目标单元格为 'O' 时才执行处理，对于 'X' 的单元格不做任何操作直接返回
    for (int j = 0; j < n; j++) {
        dfs(board, 0, j, m, n);       // 上边
        dfs(board, m - 1, j, m, n);   // 下边
    }

    // 从左边和右边的每一行开始执行边界 DFS
    // 与上面的循环合在一起，覆盖棋盘四条边的所有起点
    for (int i = 0; i < m; i++) {
        dfs(board, i, 0, m, n);       // 左边
        dfs(board, i, n - 1, m, n);   // 右边
    }

    // 对棋盘进行一次扫描完成翻转和还原
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (board[i][j] == 'O')
                board[i][j] = 'X';        // 从边界无法到达＝被包围的 O 翻转为 X
            else if (board[i][j] == 'S')
                board[i][j] = 'O';        // 从边界可以到达＝将安全标记还原为原来的 O
            // 'X' 的单元格不做修改
        }
    }
}
```
