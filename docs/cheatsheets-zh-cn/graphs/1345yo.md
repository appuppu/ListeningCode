# Finding a Valid Order to Complete All Courses — 求解完成全部课程的有效修课顺序

## 问题的本质

给定标签从 0 到 `numCourses - 1` 的课程，以及前置条件对的数组 `[a, b]`（表示必须在课程 `a` 之前修完课程 `b`）。返回一个能够完成全部课程的**有效修课顺序**的数组。如果不存在有效顺序（即存在循环依赖），则返回空数组。

## 核心思路

前置条件的依赖关系可以用有向图来表示，有效的修课顺序对应于该图的拓扑排序。从入度为 0 的节点（没有前置条件的课程）开始依次处理，逐步移除已处理节点的依赖关系，只要不存在循环，就能将所有节点按正确顺序排列。

## 思考过程

1. **将依赖关系视为图**：前置条件 `[a, b]` 表示一条从 `b` 到 `a` 的有向边。将所有前置条件表示为有向图的边后，有效的修课顺序就是该图的拓扑排序
2. **判断哪些课程可以最先开始**：没有任何前置条件的课程，即入度（指向该节点的边的数量）为 0 的课程，可以立即修读。预先计算每个节点的入度，就能以 O(1) 的时间判断哪些课程可以开始
3. **反映处理可开始课程后的影响**：当某门课程标记为已修完后，以该课程为前置条件的其他课程的"剩余前置条件数"减少 1。这可以表示为入度的递减。递减后入度变为 0 的课程成为新的可修读课程
4. **用 BFS 管理处理顺序**：将入度为 0 的课程加入队列，每次从队列中取出一门课程并添加到结果数组中，同时递减其相邻节点的入度。递减后入度变为 0 的节点加入队列。这一重复过程就是 Kahn 算法
5. **检测循环依赖**：如果存在循环，循环内所有节点的入度永远不会变为 0。因此，如果已处理的课程数不足 `numCourses`，则可以判定存在循环
6. **最终返回结果**：如果已处理的课程数等于 `numCourses`，则返回结果数组；否则返回空数组

## 前置知识

### 什么是拓扑排序

将有向无环图（DAG）的所有节点排成一列，使得所有边都从左指向右。如果存在边 `u → v`，则在排列顺序中 `u` 一定在 `v` 之前。如果存在循环，则无法进行拓扑排序。

### 什么是入度（in-degree）

指向某个节点的边的数量。入度为 0 的节点不依赖于任何其他节点，因此可以最先处理。

```java
int[] indegree = new int[numCourses];  // 将每个节点的入度初始化为0
indegree[a]++;  // 节点a有一条入边，将入度加1
--indegree[next];  // 将节点next的入度减1（解除一个前置条件）
```

### 什么是邻接表（Adjacency List）

一种数据结构，为图中的每个节点维护一个列表，记录从该节点出发的边所指向的节点。通过 `graph.get(u)` 可以获取从节点 `u` 可达的所有节点。

```java
List<List<Integer>> graph = new ArrayList<>();       // 保存整个图的列表
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());  // 为每个节点分配一个空列表
graph.get(u).add(v);   // 添加从节点u到节点v的边
graph.get(u);           // 获取节点u的所有相邻节点 → [v, ...]
```

### 什么是 Queue（队列）

先进先出（FIFO）的数据结构。在 BFS 中用队列来管理待处理的节点。

```java
Queue<Integer> queue = new LinkedList<>();  // 创建一个空队列
queue.offer(0);   // 将元素0添加到队列末尾
queue.poll();      // 从队列头部取出并返回元素 → 0
queue.isEmpty();   // 返回队列是否为空的布尔值 → true
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(V + E) — 对所有节点（课程）和所有边（前置条件）各处理一次 |
| Space | O(V + E) — 邻接表存储所有边，入度数组、队列和结果数组存储所有节点 |

## 代码

```java
// 输入：整数 numCourses（课程总数）和二维整数数组 prerequisites（前置条件对的数组）
// 输出：返回包含全部课程有效修课顺序的 int[]。如果不存在有效顺序，则返回空的 int[]
public int[] findOrder(int numCourses, int[][] prerequisites) {
    // 创建邻接表，为每门课程分配一个空列表
    // 每个索引对应一个课程编号，保存修完该课程后可以修读的课程列表
    List<List<Integer>> graph = new ArrayList<>();
    // 入度数组：表示每门课程尚未修完的前置条件数量
    int[] indegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++)
        graph.add(new ArrayList<>());

    // 根据前置条件创建边并计算入度
    // 对于每个对 [a, b]，创建边 b → a，记录课程 a 依赖于课程 b
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);  // 添加边 pre[1] → pre[0]
        indegree[pre[0]]++;  // 将课程 pre[0] 的入度加1
    }

    // 将入度为0的课程（无前置条件）加入队列
    // 这些是可以最先修读的课程
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    // 初始化结果数组和写入位置
    int[] result = new int[numCourses];
    int idx = 0;

    while (!queue.isEmpty()) {
        // 从队列中取出课程，确定其在修课顺序中的位置
        int course = queue.poll();
        result[idx++] = course;

        // 将 course 的所有相邻节点 next 的入度减1
        // 这反映了 next 的前置条件之一 course 已经修完
        for (int next : graph.get(course))
            // 如果递减后入度变为0，说明 next 的所有前置条件已完成，将其加入队列
            if (--indegree[next] == 0)
                queue.offer(next);
    }

    // 判断是否处理了全部课程
    // 如果 idx 小于 numCourses，则存在循环依赖，返回空数组
    return idx == numCourses ? result : new int[0];
}
```
