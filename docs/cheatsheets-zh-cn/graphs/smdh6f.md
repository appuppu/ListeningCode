# Filling Distances to the Nearest Gate — 求网格中每个空房间到最近门的距离

## 问题的本质

给定一个 m×n 的网格。每个单元格为"墙（-1）""门（0）""空房间（Integer.MAX_VALUE）"中的一种。将每个空房间单元格的值更新为到最近的门的距离。无法到达任何门的房间保持 Integer.MAX_VALUE 不变。

## 核心思路

不是从每个空房间出发寻找最近的门，而是从所有门同时开始BFS。由于BFS的每一步对应距离1, 2, 3…，因此首次到达某个单元格时，该单元格的最短距离就已确定。

## 思考过程

1. **从每个房间搜索门效率低下**: 如果对每个空房间分别执行BFS，则需要运行与房间数量相同次数的BFS，计算量会急剧增大。反转思路，从门向房间方向探索，就可以以所有门为起点，通过一次BFS求出所有房间的最短距离
2. **从多个门同时出发（Multi-source BFS）**: 将所有门放入队列后开始BFS。这样，距离为1的房间全部先被处理，然后距离为2的房间被处理。利用BFS按层次顺序探索的性质，每个房间首次被到达时的距离就是最短距离
3. **可以通过值来判断是否已访问**: 空房间初始化为 Integer.MAX_VALUE。BFS到达的单元格会被写入距离值，因此只有值为 Integer.MAX_VALUE 的单元格是未访问的。无需另外准备 visited 数组
4. **距离的计算为父单元格的值+1**: 从队列中取出的单元格（父）的值加1，就是相邻单元格（子）的距离。由于门的值为0，相邻房间为1，再下一个为2，距离正确地传播
5. **墙和越界直接跳过**: 墙（-1）和门（0）的值不是 Integer.MAX_VALUE，因此在未访问判断中自然被排除。越界的索引通过边界检查来过滤

## 前置知识

### BFS（广度优先搜索）

BFS是按"从近到远"的顺序探索图或网格的算法。使用队列（先进先出），先处理所有距起点距离为1的节点，然后再处理距离为2的节点。这一性质保证了到每个节点的最短距离。

```java
Queue<int[]> queue = new LinkedList<>();  // 创建BFS用的队列
queue.offer(new int[]{0, 0});             // 将起点坐标添加到队列中
int[] cell = queue.poll();                // 从队列头部取出元素
queue.isEmpty();                          // 判断队列是否为空 → true/false
```

### Multi-source BFS

普通BFS只有一个起点，而Multi-source BFS在将多个起点放入队列的状态下开始。探索像从所有起点同时扩散波一样进行，每个单元格记录的是到最近起点的距离。

```java
// 将所有门（值为0的单元格）作为起点添加到队列中
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        if (rooms[i][j] == 0)
            queue.offer(new int[]{i, j});
// 在此状态下开始BFS，即从所有门同时开始探索
```

### 4方向相邻单元格探索

在网格上向上下左右4个方向移动时，使用方向向量数组可以使代码更简洁。将每个方向向量与当前坐标相加，即可求得相邻单元格的坐标。

```java
int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};  // 上、下、左、右的方向向量
for (int[] d : dirs) {
    int r = cell[0] + d[0];  // 相邻单元格的行号
    int c = cell[1] + d[1];  // 相邻单元格的列号
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(m × n) — 每个单元格最多只被添加到队列一次，因此所有单元格各处理一次 |
| Space | O(m × n) — 队列中最多可能存入 m×n 个单元格 |

## 代码

```java
// 输入: m×n 的整数网格 rooms（-1=墙、0=门、Integer.MAX_VALUE=空房间）
// 输出: 无返回值（void）。直接修改 rooms，将每个空房间单元格的值更新为到最近门的距离
public void wallsAndGates(int[][] rooms) {
    // 获取网格的行数
    int m = rooms.length;
    // 如果网格为空则结束处理
    if (m == 0) return;
    // 获取网格的列数
    int n = rooms[0].length;

    // 创建BFS用的队列。存储单元格坐标 {行, 列}
    Queue<int[]> q = new LinkedList<>();

    // 遍历整个网格，将所有门（值为0的单元格）添加到队列中
    // 这样所有门作为BFS的起点被同时注册（Multi-source BFS）
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (rooms[i][j] == 0)
                q.offer(new int[]{i, j});

    // 表示上、下、左、右4个方向的方向向量。用于在循环中枚举相邻单元格
    int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

    // 持续执行BFS直到队列为空。利用BFS的性质，距离小的单元格优先被处理
    while (!q.isEmpty()) {
        // 从队列头部取出单元格。cell[0]为行号，cell[1]为列号
        int[] cell = q.poll();

        // 检查4个方向的相邻单元格
        for (int[] d : dirs) {
            // 将方向向量与当前坐标相加，计算相邻单元格的坐标
            int r = cell[0] + d[0];
            int c = cell[1] + d[1];

            // 如果越界则跳过
            if (r < 0 || r >= m || c < 0 || c >= n) continue;

            // 如果值不是Integer.MAX_VALUE则跳过（墙、门、或距离已确定的房间）
            // 通过此判断，无需另外准备visited数组即可防止重复访问
            if (rooms[r][c] != Integer.MAX_VALUE) continue;

            // 写入父单元格的距离+1。由于门为0，相邻为1，再下一个为2，距离正确传播
            // 由于BFS按距离顺序处理单元格，首次到达的距离就是最短距离
            rooms[r][c] = rooms[cell[0]][cell[1]] + 1;
            // 将写入距离的单元格添加到队列中，继续探索更远的房间
            q.offer(new int[]{r, c});
        }
    }
}
```
