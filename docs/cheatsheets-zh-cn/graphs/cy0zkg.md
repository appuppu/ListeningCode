# Simulating Rotting Oranges Spreading — 求解腐烂橙子扩散完成所需的最短时间

## 问题的本质

给定一个 m×n 的网格，每个单元格的值为 0（空）、1（新鲜橙子）或 2（腐烂橙子）之一。每过一分钟，腐烂的橙子会使其上下左右相邻的新鲜橙子腐烂。返回使所有新鲜橙子都腐烂所需的**最少分钟数**。如果无法使所有橙子腐烂，则返回 -1。

## 核心思路

腐烂的橙子"同时"向相邻单元格扩散。这正是从多个起点同时开始 BFS 的"Multi-Source BFS"，BFS 的每一层（层级）对应一分钟。

## 思考过程

1. **扩散是同时发生的**：当存在多个腐烂橙子时，每个腐烂橙子同时使相邻单元格腐烂。不能从单个起点进行搜索，而是需要将所有腐烂橙子同时作为出发点
2. **同时出发需要使用 Multi-Source BFS**：如果一开始就将所有腐烂橙子放入队列，那么 BFS 的一层（处理当前队列大小数量元素的一轮）就对应一分钟的扩散。DFS 无法保证"最短时间"，因此 BFS 更为合适
3. **追踪新鲜橙子的数量**：如果扩散结束后仍有新鲜橙子剩余，则说明这是不可能的情况。因此，需要在初始状态下统计新鲜橙子的数量，每腐烂一个就将计数减一
4. **经过时间的计算方法**：在 BFS 的每一层中处理队列中的所有元素，每完成一层就将经过时间加一分钟。当新鲜橙子数量变为 0 时的层数即为答案
5. **终止条件与不可能判定**：BFS 结束后，如果 `fresh > 0`，则表示存在无法到达的新鲜橙子，返回 -1。如果 `fresh == 0`，则返回经过时间

## 前置知识

### 什么是 BFS（广度优先搜索）

BFS 是一种按"距起点从近到远的顺序"探索图或网格的算法。它使用队列（FIFO），先处理当前层的所有节点，然后再进入下一层。适用于求解最短距离和最短时间的问题。

### 什么是 Multi-Source BFS

普通的 BFS 只有一个起点，而 Multi-Source BFS 是将多个起点放入队列后开始 BFS。它用于模拟从所有起点同时扩散的场景。除了队列的初始状态包含多个元素之外，其余与普通 BFS 相同。

### 什么是 Queue（队列）

队列是一种先进先出（FIFO）的数据结构。在 BFS 中，它用于按顺序处理待探索的节点。

```java
Queue<int[]> queue = new LinkedList<>();  // 创建一个以 int 数组为元素的队列
queue.offer(new int[]{0, 1});  // 将元素添加到队列末尾
int[] pos = queue.poll();       // 从队列头部取出并删除元素 → {0, 1}
queue.size();                   // 返回队列中的元素数量
queue.isEmpty();                // 返回队列是否为空的布尔值
```

### 什么是方向数组

方向数组是在网格搜索中枚举上下左右相邻单元格的技巧。通过数组定义行和列的偏移量，然后用循环遍历。

```java
int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};  // 右、左、下、上 4 个方向
for (int[] d : dirs) {
    int nr = row + d[0];  // 相邻单元格的行索引
    int nc = col + d[1];  // 相邻单元格的列索引
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(m × n) — 初始扫描遍历网格的所有单元格一次，BFS 中每个单元格最多处理一次 |
| Space | O(m × n) — 队列中最多存储 m×n 个单元格 |

## 代码

```java
// 输入：m×n 的整数网格 grid（每个单元格的值为 0=空、1=新鲜橙子、2=腐烂橙子）
// 输出：以 int 返回使所有新鲜橙子腐烂所需的最少分钟数。如果不可能则返回 -1
public int orangesRotting(int[][] grid) {
    int rows = grid.length;
    int cols = grid[0].length;
    // 用于 BFS 的队列。保存待探索单元格的坐标
    Queue<int[]> queue = new LinkedList<>();
    // 用于追踪剩余新鲜橙子数量的变量
    int fresh = 0;

    // 扫描整个网格，同时准备 BFS 的多个起点和到达目标的剩余数量
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (grid[i][j] == 2) {
                // 将腐烂橙子添加到队列（Multi-Source BFS 的起点）
                queue.offer(new int[]{i, j});
            } else if (grid[i][j] == 1) {
                // 统计新鲜橙子的数量
                fresh++;
            }
        }
    }

    // 表示上下左右 4 个方向的方向数组。用于枚举相邻单元格
    int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
    int minutes = 0;

    // 不仅要求队列非空，还要求仍有新鲜橙子剩余，以避免所有橙子腐烂后的无效循环
    while (!queue.isEmpty() && fresh > 0) {
        // 预先保存本层（一分钟内）需要处理的单元格数量。用于与循环中添加的下一层元素区分开
        int size = queue.size();
        // 开始处理一层，因此经过时间加一分钟
        minutes++;

        // 从队列中取出 size 个元素，处理本层的所有单元格
        for (int k = 0; k < size; k++) {
            int[] pos = queue.poll();

            // 使用方向数组检查上下左右 4 个相邻单元格
            for (int[] d : dirs) {
                int nr = pos[0] + d[0];
                int nc = pos[1] + d[1];

                // 如果在范围内且为新鲜橙子，则使其腐烂
                if (nr >= 0 && nr < rows
                    && nc >= 0 && nc < cols
                    && grid[nr][nc] == 1) {
                    // 将单元格更新为 2 以标记为已访问（代替 visited 数组。防止对同一单元格的重复处理）
                    grid[nr][nc] = 2;
                    fresh--;
                    queue.offer(new int[]{nr, nc});
                }
            }
        }
    }

    // 如果仍有新鲜橙子剩余，则说明无法到达，返回 -1。否则返回经过时间
    return fresh > 0 ? -1 : minutes;
}
```
