# Checking if a Graph Forms a Valid Tree — 判定图是否构成有效树

## 问题的本质

给定 `n` 个标记为 `0` 到 `n-1` 的节点和一个无向边列表 `edges`。判定该图是否构成**有效树（valid tree）**，并返回 `boolean`。有效树是指所有节点连通且不存在环（回路）的图。

## 核心思路

树的边数恰好为节点数 `n` 减 1，且不存在环。先确认边数为 `n-1`，再通过 Union-Find 逐条合并边，在合并过程中检测是否存在环，即可判定图是否为树。

## 思考过程

1. **利用树的必要条件**: 有效树必定有 `n-1` 条边。如果边数不等于 `n-1`，可以立即判定该图不是树。通过这一前置检查，可以排除边过多的情况（必定存在环）以及边过少的情况（不连通）
2. **考虑环的检测方法**: 即使边数为 `n-1`，仍然可能存在环（此时图不连通）。每添加一条边时，判定该边的两个端点是否已经属于同一个连通分量，即可检测环的存在
3. **用 Union-Find 管理连通分量**: 使用 Union-Find（不相交集合数据结构），可以以接近 O(1) 的时间复杂度执行判定两个节点是否属于同一连通分量（find）以及合并两个连通分量（union）的操作。将每个节点的父节点初始化为自身，然后对每条边执行 union 操作
4. **确定环的检测条件**: 执行 union 操作时，如果两个节点的根（root）相同，说明它们已经连通。此时再添加一条边会产生环，因此返回 `false`
5. **处理完所有边后返回结果**: 如果处理完所有边都未检测到环，结合边数为 `n-1`（已在步骤 1 中确认），可以判定该图是有效树，返回 `true`

## 前置知识

### 什么是 Union-Find（不相交集合数据结构）

一种将多个元素分组（集合）管理的数据结构，提供两种操作。`find` 返回某个元素所属组的代表元素（根）。`union` 将两个元素所属的组合并为一个。通过路径压缩和按秩合并优化后，每次操作的时间复杂度接近 O(1)。

```java
int[] parent = {0, 1, 2, 3, 4};  // 初始状态：每个节点的父节点是自身
int[] rank = new int[5];          // 将每个节点的秩（树高度的上界）初始化为0

// find: 返回节点x的根（带路径压缩）
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 路径压缩：将父节点直接指向根
    return parent[x];
}
```

### 什么是路径压缩（Path Compression）

每次调用 `find` 时，将搜索路径上的所有节点的父节点直接指向根的优化方法。这使得后续的 `find` 操作接近 O(1)。通过 `parent[x] = find(parent[x])` 的递归赋值实现。

### 什么是按秩合并（Union by Rank）

合并两棵树时，将秩（树高度的上界）较低的树挂在秩较高的树下方的方法。这可以抑制树高度的增长，保持 `find` 的搜索距离较短。仅当两棵树的秩相等时，合并后将秩加 1。

```java
// union: 合并节点a和节点b所属的组。如果已在同一组则返回false
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // 获取每个节点的根
    if (ra == rb) return false;       // 根相同 → 已在同一组 → 存在环
    if (rank[ra] < rank[rb])
        parent[ra] = rb;             // 将秩较低的树挂在秩较高的树下方
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;             // 秩相等时将rb挂在ra下方
        rank[ra]++;                   // 将秩加1
    }
    return true;
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n × α(n)) — 对每条边执行 find 和 union 操作。α(n) 是阿克曼函数的反函数，在实际应用中可视为常数 |
| Space | O(n) — parent 数组和 rank 数组各存储 n 个元素 |

## 代码

```java
// 输入: 整数 n（节点数）和二维整数数组 edges（每个元素是 [u, v] 的无向边）
// 输出: 如果图是有效树则返回 true，否则返回 false

// parent数组：管理每个节点的父节点
int[] parent, rank;

// 返回节点x所属连通分量的根（带路径压缩）
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 路径压缩：将父节点直接指向根
    return parent[x];
}

// 合并节点a和节点b的连通分量。如果会产生环则返回false
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // 获取两个端点的根
    if (ra == rb) return false;       // 根相同则会产生环 → 添加该边会形成环
    // 将秩较低的树挂在秩较高的树下方以抑制树的高度
    if (rank[ra] < rank[rb])
        parent[ra] = rb;
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;
        rank[ra]++;
    }
    return true;
}

public boolean validTree(int n, int[][] edges) {
    // 树的边数必须等于节点数减1（过多则必定有环，过少则不连通）
    if (edges.length != n - 1)
        return false;

    // 将每个节点的父节点初始化为自身（每个节点构成一个独立的连通分量）
    parent = new int[n];
    rank = new int[n];
    for (int i = 0; i < n; i++)
        parent[i] = i;

    // 处理每条边，如果两个端点已属于同一连通分量则会产生环，返回false
    for (int[] e : edges)
        if (!union(e[0], e[1]))
            return false;

    // 处理完所有边均未检测到环，且边数为n-1，因此该图是有效树
    return true;
}
```
