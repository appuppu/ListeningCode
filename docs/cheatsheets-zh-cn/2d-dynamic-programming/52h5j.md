# Checking if a String is an Interleaving of Two Others — 判定两个字符串交错混合后能否组成第三个字符串

## 问题的本质

给定三个字符串 `s1`、`s2`、`s3`。判定 `s3` 是否由 `s1` 和 `s2` 的**交错混合**（Interleaving）组成。交错混合是指使用 `s1` 和 `s2` 的全部字符，并且保持各自字符串内的相对出现顺序不变，将它们混合在一起。

## 核心思路

可以将问题分解为如下子问题：`s1` 的前 `i` 个字符和 `s2` 的前 `j` 个字符能否组成 `s3` 的前 `i+j` 个字符。在每个位置上，"下一个字符从 `s1` 取还是从 `s2` 取"这一二选一的判断，可以通过DP表高效地完成。

## 思考过程

1. **检查长度的前提条件**：如果 `s3` 是 `s1` 和 `s2` 的交错混合，那么 `s3` 的长度必须等于 `s1` 的长度 + `s2` 的长度。如果不相等，可以立即返回 `false`
2. **定义子问题**：将 `dp[i][j]` 定义为"`s1` 的前 `i` 个字符和 `s2` 的前 `j` 个字符能否组成 `s3` 的前 `i+j` 个字符"。根据这个定义，`dp[m][n]`（`m` 是 `s1` 的长度，`n` 是 `s2` 的长度）就是最终答案
3. **推导状态转移方程**：`dp[i][j]` 为 `true` 的情况有以下两种之一。情况1：`dp[i-1][j]` 为 `true`，并且 `s1` 的第 `i` 个字符与 `s3` 的第 `i+j` 个字符一致（从 `s1` 取一个字符）。情况2：`dp[i][j-1]` 为 `true`，并且 `s2` 的第 `j` 个字符与 `s3` 的第 `i+j` 个字符一致（从 `s2` 取一个字符）
4. **定义基本情况**：当 `i=0` 且 `j=0` 时，表示尚未从任何一个字符串中取出字符的初始状态，与 `s3` 的前0个字符（空字符串）一致，因此设 `dp[0][0] = true`
5. **优化空间复杂度**：二维的 `dp[i][j]` 在计算第 `i` 行时只使用第 `i-1` 行的值。因此使用一维数组 `dp[j]` 即可。`dp[j]` 更新前的值相当于上一行的值（`dp[i-1][j]`），`dp[j-1]` 更新后的值相当于当前行左邻的值（`dp[i][j-1]`）
6. **最终返回值**：外层循环从 `i = 0` 到 `m`，内层循环从 `j = 0` 到 `n` 遍历完成后，`dp[n]` 就是整个 `s3` 能否通过交错混合组成的答案

## 前置知识

### 什么是DP（动态规划）的一维数组空间优化

在二维DP表 `dp[i][j]` 中，如果每行的计算只依赖于上一行的值，就可以用一维数组 `dp[j]` 代替。通过逐行覆盖更新数组，将空间复杂度从 O(m×n) 降低到 O(n)。

```java
// 二维情况: dp[i][j] 引用 dp[i-1][j] 和 dp[i][j-1]
boolean[][] dp = new boolean[m + 1][n + 1];

// 优化为一维: 逐行覆盖更新 dp[j]
boolean[] dp = new boolean[n + 1];
// dp[j] 更新前的值 → 相当于上一行的 dp[i-1][j]
// dp[j-1] 更新后的值 → 相当于当前行的 dp[i][j-1]
```

### 什么是 String.charAt(index)

返回字符串指定位置字符的方法。索引从0开始。

```java
String s = "abc";
s.charAt(0);  // 返回 'a'
s.charAt(2);  // 返回 'c'
```

### 什么是交错混合（Interleaving）

将两个字符串的字符在保持各自相对顺序的前提下混合在一起，组成一个新的字符串。
例如：`s1 = "aab"`，`s2 = "axy"` 时，`"aaxaby"` 是交错混合（`s1` 中 a,a,b 和 `s2` 中 a,x,y 的顺序分别得到了保持）。`"abaaxy"` 由于 `s1` 的字符顺序被打乱，因此不是交错混合。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(m×n) — 对 `s1` 的长度 `m` 和 `s2` 的长度 `n` 执行一次双重循环 |
| Space | O(n) — 仅使用大小为 `s2` 的长度+1 的一维DP数组 |

## 代码

```java
// 输入: 字符串 s1（长度 m）、字符串 s2（长度 n）、字符串 s3
// 输出: 以 boolean 返回 s3 能否由 s1 和 s2 的交错混合组成
public boolean isInterleave(String s1, String s2, String s3) {
    int m = s1.length();
    int n = s2.length();

    // 当 m + n 与 s3 的长度不一致时，交错混合不可能实现
    if (m + n != s3.length())
        return false;

    // dp[j] = s1的前i个字符和s2的前j个字符能否组成s3的前i+j个字符
    // 通过逐行覆盖更新一维数组，将二维表的空间压缩到 O(n)
    boolean[] dp = new boolean[n + 1];

    // 外层循环: i 表示从 s1 中取出的字符数（0〜m）
    for (int i = 0; i <= m; i++) {
        // 内层循环: j 表示从 s2 中取出的字符数（0〜n）
        for (int j = 0; j <= n; j++) {
            if (i == 0 && j == 0) {
                // 基本情况: 尚未从任何一方取出字符的状态，与 s3 的空字符串一致
                dp[j] = true;
            } else {
                // 条件1（从s1取）: dp[j] 更新前的值（上一行 = 相当于 dp[i-1][j]）为 true
                //   并且 s1 的第 i 个字符与 s3 的第 i+j 个字符一致
                // 条件2（从s2取）: dp[j-1] 更新后的值（当前行的左邻 = 相当于 dp[i][j-1]）为 true
                //   并且 s2 的第 j 个字符与 s3 的第 i+j 个字符一致
                // 注意: 由于内层循环从左到右遍历 j，dp[j] 尚未被覆盖因此保持上一行的值，
                //   而 dp[j-1] 已经被覆盖因此保持当前行的值
                dp[j] =
                    (dp[j] && i > 0
                    && s1.charAt(i - 1)
                    == s3.charAt(i + j - 1))
                    || (j > 0
                    && dp[j - 1]
                    && s2.charAt(j - 1)
                    == s3.charAt(i + j - 1));
            }
        }
    }

    // dp[n] 是 s1 的全部 m 个字符和 s2 的全部 n 个字符能否组成 s3 的全部 m+n 个字符的结果
    return dp[n];
}
```
