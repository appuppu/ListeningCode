# Counting Unique Paths in a Grid — 计算从网格左上角到右下角的唯一路径数

## 问题本质

给定一个 `m × n` 的网格。从左上角格子 `(0, 0)` 到右下角格子 `(m-1, n-1)`，每一步只能**向右或向下**移动，返回唯一路径的总数。

## 核心思想

到达某个格子的路径数等于「到达上方格子的路径数」与「到达左方格子的路径数」之和。通过自底向上填充该递推公式即可求得答案，而每一行的计算仅依赖于前一行和当前行，因此只需一行大小的数组即可节省空间。

## 思考过程

1. **到达每个格子的路径数可以分解为子问题**：要到达格子 `(i, j)`，必定从上方 `(i-1, j)` 或左方 `(i, j-1)` 而来。因此递推公式 `dp[i][j] = dp[i-1][j] + dp[i][j-1]` 成立
2. **确定基准情况**：最上行的格子只能从左方到达，最左列的格子只能从上方到达。两者的路径数均为1，因此用 `dp[0][j] = 1`、`dp[i][0] = 1` 进行初始化
3. **逐行从左到右填充**：递推公式依赖的是「正上方的格子」和「左侧的格子」，因此从上到下逐行、每行内从左到右扫描，所需的值始终已经计算完毕
4. **可以将空间压缩为一行**：`dp[i][j]` 仅依赖于同一行左侧的 `dp[i][j-1]` 和前一行同一列的 `dp[i-1][j]`。使用一维数组 `dp[j]` 时，更新前的 `dp[j]` 对应「上方格子的值」，已更新的 `dp[j-1]` 对应「左方格子的值」，因此可以用 `dp[j] += dp[j-1]` 来表达递推公式
5. **初始化所有元素为1**：将一维数组全部初始化为1，即表示最上行（每个格子的路径数均为1）的状态。对应最左列的 `dp[0]` 在内层循环中不会被更新，因此始终保持为1，最左列的基准情况也自然得以维持
6. **最终返回值**：所有行处理完毕后，`dp[n-1]` 保存着到达右下角格子的路径数，将其返回

## 前置知识

### 什么是 Arrays.fill

Arrays.fill 是一个将数组的所有元素一次性初始化为指定值的工具方法。无需编写循环即可将数组填充为统一的值。

```java
int[] dp = new int[5];       // 创建长度为5的数组（初始值全部为0）
Arrays.fill(dp, 1);          // 将所有元素设置为1 → [1, 1, 1, 1, 1]
```

### 什么是一维DP空间压缩

当二维DP表中每个单元格的计算仅依赖于「当前行」和「前一行」时，可以将二维数组替换为一维数组的技巧。通过逐行覆盖更新数组，将 Space O(m×n) 降低为 O(n)。

```java
// 二维情况: dp[i][j] = dp[i-1][j] + dp[i][j-1]
// 压缩为一维: dp[j] += dp[j-1]
//   dp[j]（更新前）= 前一行同一列的值（相当于 dp[i-1][j]）
//   dp[j-1]（已更新）= 当前行左侧邻居的值（相当于 dp[i][j-1]）
```

## 复杂度

| | 值 |
|---|---|
| Time | O(m × n) — 遍历网格的每个格子一次 |
| Space | O(n) — 仅保存一行大小的数组 |

## 代码

```java
// 输入: 整数 m（行数）和整数 n（列数）
// 输出: 以整数形式返回从左上角到右下角的唯一路径数
public int uniquePaths(int m, int n) {
    // 创建长度为 n 的一行DP数组，并将所有元素初始化为1
    // 全部设为1，即设定了最上行的基准情况（到达每个格子的路径数为1）
    int[] dp = new int[n];
    Arrays.fill(dp, 1);

    // i=0（最上行）已通过初始化设定完毕，因此从 i=1 开始
    for (int i = 1; i < m; i++) {
        // j=0（最左列）应始终保持为1，因此从 j=1 开始
        for (int j = 1; j < n; j++) {
            // dp[j]（更新前）= 前一行同一列的值（来自上方的路径数）
            // dp[j-1]（已更新）= 当前行左侧邻居的值（来自左方的路径数）
            // 通过该加法在一维数组上实现递推公式 dp[i][j] = dp[i-1][j] + dp[i][j-1]
            dp[j] += dp[j - 1];
        }
    }

    // dp[n-1] 保存着到达网格右下角格子 (m-1, n-1) 的唯一路径数
    return dp[n - 1];
}
```
