# Finding the Longest Increasing Path in a Matrix — 求矩阵中值严格递增的最长路径的长度

## 问题的本质

给定一个 m×n 的整数矩阵 `matrix`。可以向上下左右4个方向移动，仅当移动目标单元格的值**严格大于**当前单元格的值时才能移动。返回满足该条件的**最长路径的长度**（单元格数）。

## 核心思路

将矩阵视为"从小值指向大值的DAG（有向无环图）"。从入度为0的单元格（周围没有比自身值更小的单元格）开始，逐层进行BFS，层数即为最长路径的长度。

## 思考过程

1. **移动条件构成DAG的边**: 由于只能沿值严格递增的方向移动，因此不存在环。也就是说，将矩阵的相邻关系视为图时，会形成以小→大方向为边的DAG（有向无环图）
2. **DAG的最长路径可通过拓扑排序求得**: DAG的最长路径问题，沿拓扑顺序处理即可高效求解。使用BFS（Kahn算法），可以逐层处理，层数对应最长路径的长度
3. **定义入度的含义**: 每个单元格的入度是"相邻4个方向中，值比自身小的单元格数量"。入度为0的单元格是路径的起点候选，即周围不存在值比自身小的相邻单元格
4. **逐层执行BFS**: 将所有入度为0的单元格放入队列并开始BFS。批量处理一层中的所有单元格，对每个单元格的"值比自身大的相邻单元格"的入度减1。入度变为0的单元格作为下一层加入队列
5. **层数即为答案的原因**: BFS的每一层是DAG上距起点相同距离的单元格集合。直到最后一层处理完毕的层数，就是从起点到最远单元格的距离，即最长路径的长度

## 前置知识

### 什么是DAG（有向无环图）

由顶点和有向边组成的图，其中不存在环（循环）。仅沿值严格递增的方向连边时，由于不可能回到相同的值，因此不会产生环，从而构成DAG。

### 什么是入度（in-degree）

**进入某个顶点的边的数量**。在本问题中，单元格 `(i, j)` 的入度是"上下左右相邻单元格中，值小于 `matrix[i][j]` 的单元格数量"。入度为0的单元格表示没有任何单元格可以到达该单元格的路径起点。

```java
// 计算单元格(i,j)的入度的示例
int indegree = 0;
for (int[] d : dirs) {
    int ni = i + d[0], nj = j + d[1];
    if (ni >= 0 && ni < m && nj >= 0 && nj < n
        && matrix[ni][nj] < matrix[i][j])  // 如果相邻单元格的值比自身小，则有边进入
        indegree++;
}
```

### 什么是拓扑排序（BFS / Kahn算法）

将DAG的顶点按照所有边均为"先→后"的顺序进行排列的方法。在Kahn算法中，将入度为0的顶点放入队列，每次取出时将相邻顶点的入度减1，入度变为0的顶点加入队列。重复此过程即可得到拓扑顺序。

```java
Queue<int[]> q = new LinkedList<>();   // 创建BFS用的队列
q.offer(new int[]{0, 1});             // 将单元格坐标添加到队列中
q.isEmpty();                           // 返回队列是否为空的boolean值 → false
q.size();                              // 返回队列中的元素数量 → 1
int[] cell = q.poll();                 // 取出并返回队列的头部元素 → {0, 1}
```

### 用数组表示4个方向的移动

将上下左右4个方向定义为 `{行变化量, 列变化量}` 的二维数组，通过循环处理各个方向。

```java
int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};  // 右、左、下、上
for (int[] d : dirs) {
    int ni = i + d[0];  // 移动目标的行
    int nj = j + d[1];  // 移动目标的列
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(m\*n) — 计算每个单元格的入度需要O(m\*n)，BFS中每个单元格恰好处理一次需要O(m\*n) |
| Space | O(m\*n) — 存储入度的二维数组和BFS队列各最多保存m\*n个单元格 |

## 代码

```java
// 输入: m×n 的整数矩阵 matrix
// 输出: 以 int 返回值严格递增的最长路径的长度（单元格数）
int longestIncreasingPath(int[][] matrix) {
    // 获取行数m和列数n
    int m = matrix.length;
    int n = matrix[0].length;
    // 定义上下左右4个方向的移动量（右、左、下、上）
    int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};

    // 计算每个单元格的入度（相邻单元格中值比自身小的数量）
    // 入度 = 进入该单元格的边数 = 相邻的值比自身小的单元格数量
    int[][] indeg = new int[m][n];
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            for (int[] d : dirs) {
                int ni = i + d[0];
                int nj = j + d[1];
                // 如果相邻单元格在范围内且值比自身小，则有边从该单元格进入
                if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && matrix[ni][nj] < matrix[i][j])
                    indeg[i][j]++;
            }
        }
    }

    // 将所有入度为0的单元格（路径起点）添加到队列中
    // 入度为0 = 周围没有比自身值更小的单元格 = DAG上没有任何单元格可以到达的起点
    Queue<int[]> q = new LinkedList<>();
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (indeg[i][j] == 0)
                q.offer(new int[]{i, j});

    // 逐层执行BFS，并计算层数
    // 每一层是DAG上距起点相同距离的单元格集合
    int pathLen = 0;
    while (!q.isEmpty()) {
        // 获取当前层包含的单元格数量
        int size = q.size();
        // 每进入新的一层，路径长度加1（总层数 = 最长路径的长度）
        pathLen++;
        for (int k = 0; k < size; k++) {
            int[] cell = q.poll();
            // 检查取出的单元格的4个方向的相邻单元格
            for (int[] d : dirs) {
                int ni = cell[0] + d[0];
                int nj = cell[1] + d[1];
                // 如果相邻单元格在范围内且值比自身大，则处理该边
                if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && matrix[ni][nj] > matrix[cell[0]][cell[1]]) {
                    // 将入度减1（将来自该单元格的入边标记为已处理）
                    indeg[ni][nj]--;
                    // 入度变为0 = 所有入边均已处理 → 作为下一层添加到队列中
                    if (indeg[ni][nj] == 0)
                        q.offer(new int[]{ni, nj});
                }
            }
        }
    }
    // BFS的层数即为最长递增路径的长度
    // 根据问题约束，矩阵非空，因此 pathLen >= 1 是有保证的
    return pathLen;
}
```
