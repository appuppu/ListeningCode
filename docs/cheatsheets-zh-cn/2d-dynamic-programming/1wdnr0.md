# Finding the Minimum Edits to Transform One String Into Another — 求解两个字符串之间的最小编辑距离

## 问题的本质

给定两个字符串 `word1` 和 `word2`。返回将 `word1` 转换为 `word2` 所需的**最小操作次数**。可用的操作有"插入""删除""替换"三种，每种操作计为一次。

## 核心思路

从两个字符串的末尾开始比较时，如果当前字符匹配，则无需操作，同时推进两个指针；如果不匹配，则从"插入、删除、替换"三种操作中选择最小代价的操作。利用DP表消除子问题的重叠计算，并且由于每个单元格仅依赖当前行和前一行，因此只需一行数组即可优化空间。

## 思考过程

1. **每个位置的选择仅限三种**: 比较 `word1[i]` 和 `word2[j]` 时，如果字符匹配，则无需操作，直接推进到 `(i+1, j+1)`。如果不匹配，则从"插入（推进j）""删除（推进i）""替换（同时推进两者）"三种操作中选择最小代价的操作。这种递归结构提示我们可以使用DP来求解
2. **DP表的定义**: 将 `dp[i][j]` 定义为"将 `word1[i:]` 转换为 `word2[j:]` 所需的最小操作次数"。最终答案为 `dp[0][0]`
3. **确定基本情况**: 如果 `word1` 的剩余部分为空（`i == m`），则需要插入 `word2[j:]` 的剩余字符数，因此 `dp[m][j] = n - j`。如果 `word2` 的剩余部分为空（`j == n`），则需要删除 `word1[i:]` 的剩余字符数，因此 `dp[i][n] = m - i`
4. **确定自底向上的填表方向**: 由于 `dp[i][j]` 依赖于 `dp[i+1][j+1]`、`dp[i][j+1]`、`dp[i+1][j]`，因此 `i` 从 `m-1` 到 `0` 逆序填充，`j` 从 `n-1` 到 `0` 逆序填充
5. **优化空间**: 计算每一行 `i` 时，只需要"前一行（`i+1`）"和"当前行（`i`）"这两行。因此无需维护二维数组，只需一维数组 `prev`（前一行）和 `curr`（当前行）两个数组即可。每行计算完成后，通过 `prev = curr` 进行交换
6. **最终返回值**: 处理完所有行后，`prev[0]` 对应 `dp[0][0]` 的值，即将整个 `word1` 转换为整个 `word2` 的最小操作次数

## 前置知识

### Edit Distance（编辑距离）是什么

编辑距离是衡量两个字符串"相似度"的指标，表示将一个字符串转换为另一个字符串所需的最小操作次数。也称为Levenshtein距离。允许的操作有以下三种，每种操作的代价为1。

- **插入（Insert）**: 向字符串中添加一个字符
- **删除（Delete）**: 从字符串中移除一个字符
- **替换（Replace）**: 将字符串中的一个字符更改为另一个字符

### 自底向上DP（动态规划）是什么

自底向上DP是一种从小规模子问题开始，逐步将结果记录在表中进行求解的方法。与记忆化递归（自顶向下）不同，它没有递归调用的开销，并且更容易应用空间优化。

```java
// 一维DP示例: 使用两个变量计算斐波那契数列
int a = 0, b = 1;
for (int i = 2; i <= n; i++) {
    int temp = a + b;  // 当前值仅依赖于前两个值
    a = b;             // 丢弃旧值并更新
    b = temp;
}
```

### Math.min() 是什么

Math.min() 是Java的标准方法，返回两个整数中较小的一个。比较三个或更多值时，可以嵌套使用。

```java
Math.min(3, 5);                    // → 3
Math.min(3, Math.min(5, 1));       // → 1（三个值中的最小值）
```

### String.charAt(int index) 是什么

charAt() 是返回字符串中指定位置字符的方法。索引从0开始。

```java
String s = "abc";
s.charAt(0);  // → 'a'
s.charAt(2);  // → 'c'
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(m × n) — 对 `word1` 的每个位置遍历 `word2` 的所有位置 |
| Space | O(n) — 用一行数组代替二维表 |

## 代码

```java
// 输入: 两个字符串 word1（长度 m）和 word2（长度 n）
// 输出: 以 int 形式返回将 word1 转换为 word2 的最小操作次数
public int minDistance(String w1, String w2) {
    int m = w1.length();  // 获取 word1 的长度
    int n = w2.length();  // 获取 word2 的长度

    // prev数组: 对应DP表中下一行（i+1）
    // 以 prev[j] = n - j 初始化: 当 word1 为空时，需要插入 word2[j:] 剩余的 n-j 个字符的操作次数
    int[] prev = new int[n + 1];
    for (int j = 0; j <= n; j++)
        prev[j] = n - j;

    // 从 word1 的末尾到开头逆序遍历（i 是 word1 的当前位置）
    for (int i = m - 1; i >= 0; i--) {
        // curr数组: 对应DP表中当前行（i）
        int[] curr = new int[n + 1];
        // 当 word2 为空时，需要删除 word1[i:] 剩余的 m-i 个字符的操作次数
        curr[n] = m - i;

        // 从 word2 的末尾到开头逆序遍历（j 是 word2 的当前位置）
        for (int j = n - 1; j >= 0; j--) {
            if (w1.charAt(i) == w2.charAt(j)) {
                // 字符匹配则无需操作。prev[j+1] 是同时推进一个字符的子问题 dp[i+1][j+1] 的答案
                curr[j] = prev[j + 1];
            } else {
                // 不匹配则从三种操作中选择最小代价，并加上本次操作的1次（+1）
                curr[j] = 1 + Math.min(
                    curr[j + 1],           // 插入: 在 word2 侧推进一个字符（dp[i][j+1]）
                    Math.min(prev[j],      // 删除: 在 word1 侧推进一个字符（dp[i+1][j]）
                        prev[j + 1]));     // 替换: 在两侧各推进一个字符（dp[i+1][j+1]）
            }
        }
        // 将当前行保存为前一行，为下一次迭代（i-1）做准备
        prev = curr;
    }

    // prev[0] 对应 dp[0][0]，即将整个 word1 转换为整个 word2 的最小操作次数
    return prev[0];
}
```
