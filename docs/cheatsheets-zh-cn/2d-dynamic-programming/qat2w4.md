# Counting Combinations to Make a Target Amount — 计算凑出目标金额的硬币组合数

## 问题本质

给定一个包含硬币面额的数组 `coins` 和一个整数 `amount`。可以无限次重复使用 `coins` 中的硬币，返回总和恰好为 `amount` 的**组合数**。所谓不同的组合，是指至少有一种面额的使用枚数不同。仅顺序不同的视为相同组合。

## 核心思路

按种类逐一处理硬币，对每种硬币将「使用该硬币 0 枚以上时的组合数」累加到 DP 数组中。通过将硬币种类作为外层循环，可以自然地消除因相同硬币集合以不同顺序被计数而产生的重复（排列）。

## 思考过程

1. **区分组合与排列**: 本题求的是「组合数」，因此需要将 [1,2] 和 [2,1] 视为同一种。如果将金额作为外层循环、在内层选择硬币，就会计算排列数，因此需要将硬币种类作为外层循环来固定处理顺序
2. **定义 DP 状态**: 将 `dp[a]` 定义为「恰好凑出金额 `a` 的组合数」。最终 `dp[amount]` 就是答案
3. **确定基础条件**: 凑出金额 0 的方法只有「不使用任何硬币」这一种，因此设 `dp[0] = 1`。如果没有这个基础条件，无论使用哪种硬币，组合数都会一直以 0 累加，答案将始终为 0
4. **推导转移方程**: 要使用至少 1 枚硬币 `coin` 凑出金额 `a`，只需加上剩余金额 `a - coin` 的组合数即可。即转移方程为 `dp[a] += dp[a - coin]`。由于 `dp[a - coin]` 中已经包含了使用同种硬币 0 枚以上的组合数，这一累加会自动涵盖「使用 coin 1 枚、2 枚、……」的所有情况
5. **确定循环顺序**: 外层循环逐一处理硬币种类，内层循环将金额 `a` 从 `coin` 到 `amount` 升序遍历。这样每种硬币都是在「前面各种硬币的组合数」基础上累加自身的贡献，不会出现排列的重复计数
6. **最终返回值**: 处理完所有硬币后的 `dp[amount]` 即为凑出目标金额的组合总数

## 前置知识

### 什么是 DP 数组（动态规划的一维数组）

将子问题的答案保存在数组中，通过复用这些答案来高效求解更大问题的方法。在本题中，`dp[a]` 表示「凑出金额 `a` 的组合数」。

```java
int[] dp = new int[amount + 1];  // 创建索引 0 到 amount 的数组（初始值全为 0）
dp[0] = 1;                       // 基础条件：凑出金额 0 的方法有 1 种
dp[a] += dp[a - coin];           // 转移：将使用 1 枚 coin 后剩余金额的组合数累加到金额 a 的组合数中
```

### 将硬币作为外层循环的原因

如果将金额作为外层、硬币作为内层，在凑出金额 5 时会将 [1,2,2]、[2,1,2] 和 [2,2,1] 分别计数（排列）。将硬币作为外层后，硬币 1 处理完毕才会处理硬币 2，因此「硬币 1 → 硬币 2」的顺序被固定，只会计数组合。

```java
// 计算组合数（正确的顺序）
for (int coin : coins) {          // 外层：按硬币种类逐一处理
    for (int a = coin; a <= amount; a++) {  // 内层：遍历金额
        dp[a] += dp[a - coin];
    }
}

// 会计算排列数（错误的顺序）
for (int a = 1; a <= amount; a++) {         // 外层：按金额逐一处理
    for (int coin : coins) {                // 内层：尝试所有硬币
        if (a >= coin) dp[a] += dp[a - coin];
    }
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n × amount) — 对 n 种硬币分别遍历金额 0 到 amount |
| Space | O(amount) — 仅使用一个大小为 amount+1 的 DP 数组 |

## 代码

```java
// 输入：存储硬币面额的整数数组 coins 和目标金额的整数 amount
// 输出：以 int 返回总和恰好为 amount 的硬币组合数
public int change(int amount, int[] coins) {
    // dp[a] = 恰好凑出金额 a 的组合数
    // 大小为 amount + 1（对应索引 0 到 amount 的每个金额）
    int[] dp = new int[amount + 1];

    // 基础条件：凑出金额 0 的方法只有「什么都不选」这 1 种
    // 如果没有这个基础条件，转移时累加的源值始终为 0，所有结果都会变成 0
    dp[0] = 1;

    // 按硬币种类逐一处理（通过外层循环固定顺序，只计算组合数）
    // 将硬币种类作为外层循环，可以防止同一硬币集合因不同排列顺序而被重复计数（排列）
    for (int coin : coins) {
        // 从金额 coin 到 amount 升序遍历
        // 从 coin 开始是因为 a - coin 必须大于等于 0
        // 升序遍历使得同一种硬币被多次使用的情况能自然地被反映
        for (int a = coin; a <= amount; a++) {
            // 使用 1 枚 coin，将剩余金额 a-coin 的组合数累加
            // 由于 dp[a - coin] 中已经包含了使用同种硬币 0 枚以上的组合数，
            // 仅凭这一行就能涵盖「使用 coin 1 枚、2 枚、3 枚……」的所有情况
            dp[a] += dp[a - coin];
        }
    }

    // 返回凑出目标金额的组合总数
    return dp[amount];
}
```
