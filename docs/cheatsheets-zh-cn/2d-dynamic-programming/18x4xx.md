# Implementing Regular Expression Matching — 判断字符串是否与模式完全匹配

## 问题的本质

给定输入字符串 `s` 和模式 `p`。模式中的 `.` 匹配任意一个字符，`*` 表示将前一个字符重复零次或多次。要求以 `boolean` 返回模式是否与字符串**整体**匹配。

## 核心思路

从字符串和模式的末尾向开头填充二维DP表。`dp[i][j]` 表示"`s[i:]` 是否与 `p[j:]` 匹配"，当存在 `*` 时，问题归结为两种选择："将前一个字符使用0次（跳过）"或"使用1次并将字符串向前推进1位"。

## 思考过程

1. **可以分解为子问题**: 确定字符串的位置 `i` 和模式的位置 `j` 后，就形成了"`s[i:]` 是否与 `p[j:]` 匹配"这一子问题。将该子问题的答案保存到 `dp[i][j]` 中，就可以避免重复计算
2. **判断当前位置的字符是否匹配**: 如果 `s[i]` 与 `p[j]` 是相同字符，或者 `p[j]` 是 `.`，则当前位置的一个字符匹配。将该判断结果保存到变量 `match` 中
3. **考虑存在 `*` 时的两种选择**: 当 `p[j+1]` 为 `*` 时，模式 `x*` 可以有两种解释。第一种是"匹配0次（跳过）"，即整体跳过 `x*`，引用 `dp[i][j+2]`。第二种是"匹配1次以上"，如果当前字符匹配，则将字符串向前推进1位，引用 `dp[i+1][j]`（模式侧不推进，因为下一个位置可能仍然继续 `*` 的重复）
4. **不存在 `*` 时简单地逐字符推进**: 如果当前字符匹配，则将字符串和模式都向前推进1位的 `dp[i+1][j+1]` 直接作为答案
5. **设置基准情况**: 字符串和模式都到达末尾的状态 `dp[n][m]` 为 `true`。如果字符串还有剩余但模式已到末尾，则为 `false`；如果模式还有剩余但字符串已到末尾，则只有通过 `*` 跳过才可能为 `true`
6. **从末尾向开头填充表**: `dp[i][j]` 的计算依赖于 `dp[i][j+2]`、`dp[i+1][j]`、`dp[i+1][j+1]`。这些值都位于 `i` 或 `j` 较大的方向，因此将 `i` 从 `n` 到 `0`、`j` 从 `m-1` 到 `0` 逆序遍历，引用的值就始终是已计算好的
7. **最终返回的结果**: 表中的 `dp[0][0]` 就是"整个字符串是否与整个模式匹配"的答案

## 前置知识

### 什么是二维DP表

针对两个变量（这里是字符串的位置 `i` 和模式的位置 `j`）的每种组合，保存子问题答案的二维数组。通过 `boolean[][] dp = new boolean[n+1][m+1]` 创建，在 `dp[i][j]` 中存储 `s[i:]` 与 `p[j:]` 的匹配结果。

```java
boolean[][] dp = new boolean[n + 1][m + 1];  // 创建初始化为false的(n+1)×(m+1)的表
dp[n][m] = true;                              // 基准情况: 两者都到达末尾则匹配
dp[i][j] = dp[i][j + 2];                     // 引用其他单元格的值来填充当前单元格
```

### String.length() 和 String.charAt()

`length()` 返回字符串的长度。`charAt(i)` 返回索引 `i` 处的字符。索引从0开始，越界访问会抛出异常。

```java
String s = "abc";
s.length();     // → 3
s.charAt(0);    // → 'a'
s.charAt(2);    // → 'c'
```

### `*`（星号）的含义

正则表达式中的 `*` 表示"将前一个字符重复零次或多次"。`a*` 可以匹配 `""`、`"a"`、`"aa"`、`"aaa"` 等任意情况。`.*` 表示"将任意字符重复零次或多次"，因此可以匹配任何字符串。`*` 不会单独使用，必须与前一个字符组合成 `x*` 的形式。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n×m) — 对n×m的DP表中每个单元格计算一次 |
| Space | O(n×m) — 保存n×m的DP表 |

## 代码

```java
// 输入: 字符串 s 和模式 p
// 输出: 以 boolean 返回 s 整体是否与 p 匹配
public boolean isMatch(String s, String p) {
    int n = s.length();  // 字符串的长度
    int m = p.length();  // 模式的长度

    // dp[i][j] = 保存"s[i:]是否与p[j:]匹配"的二维表
    // 索引 n 和 m 表示空字符串，因此大小需要 +1
    boolean[][] dp = new boolean[n + 1][m + 1];

    // 基准情况: 两个字符串都到达末尾则匹配成功
    dp[n][m] = true;

    // 从末尾向开头填充表
    // 通过这种遍历顺序，引用的 dp[i][j+2]、dp[i+1][j]、dp[i+1][j+1] 都已经计算完毕
    for (int i = n; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // 判断当前位置的一个字符是否匹配
            // 先判断 i < n，以防止字符串到达末尾时 charAt 越界访问
            boolean match = i < n
                && (s.charAt(i) == p.charAt(j)
                    || p.charAt(j) == '.');

            // 通过 j+1 < m 进行范围检查，判断模式的当前位置是否为 x* 的形式
            if (j + 1 < m && p.charAt(j + 1) == '*') {
                // 对 x* 模式的两种选择取OR（逻辑或）:
                // dp[i][j+2]: 匹配0次（整体跳过 x*）
                // match && dp[i+1][j]: 匹配1次并推进字符串（模式侧不推进。因为 * 的重复可能继续，所以 j 保持不变）
                dp[i][j] = dp[i][j + 2]
                    || (match && dp[i + 1][j]);
            } else {
                // 普通字符: 如果一个字符匹配，则将字符串和模式都向前推进1位
                dp[i][j] = match
                    && dp[i + 1][j + 1];
            }
        }
    }

    // dp[0][0] 是"字符串 s 整体是否与模式 p 整体匹配"的最终答案
    return dp[0][0];
}
```
