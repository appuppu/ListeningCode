# Counting Distinct Subsequences — 计算字符串s中与t匹配的子序列有多少个

## 问题的本质

给定两个字符串 `s` 和 `t`。从 `s` 中删除0个或多个字符（保持剩余字符的相对顺序不变），计算能构成与 `t` 匹配的子序列的方法有多少种并返回。

## 核心思想

对于 `s` 的每个字符，存在"是否用于匹配 `t`"的两种选择。通过一维数组管理这些选择的累积结果，并从后向前更新，可以正确地将"使用该字符"和"不使用该字符"两种情况的计数相加。

## 思考过程

1. **子序列的匹配是选择的累积**：当 `s` 的第 i 个字符与 `t` 的第 j 个字符匹配时，存在两种选择："将该字符用于匹配 `t[j]`"或"跳过该字符不使用"。将两种情况的计数相加即可得到所有模式的总数
2. **定义DP的状态**：将 `dp[j]` 定义为"与 `t` 的前 j 个字符匹配的 `s` 的子序列数量"。最终 `dp[n]`（n 为 `t` 的长度）即为答案
3. **考虑基准情况**：与 `t` 的前0个字符（空字符串）匹配的子序列，对于任何 `s` 都存在"不选择任何字符"这1种方式。因此 `dp[0] = 1`
4. **推导转移方程**：当 `s[i-1] == t[j-1]` 时，`dp[j]` 有两个贡献来源。"不使用 `s[i-1]`"的情况下，已有的 `dp[j]` 保持不变；"使用 `s[i-1]`"的情况下，需要加上 `dp[j-1]`（已匹配到前一个字符的数量）。因此 `dp[j] += dp[j-1]`。当字符不匹配时，`dp[j]` 不变（只能选择跳过）
5. **更新顺序需要逆序的原因**：`dp[j] += dp[j-1]` 需要使用更新前的 `dp[j-1]`。如果从小到大更新 j，`dp[j-1]` 会先被覆盖，旧值就会丢失。从大到小逆序更新 j，`dp[j-1]` 仍然保持更新前的值，因此可以正确计算
6. **最终返回的值**：遍历完 `s` 的所有字符后，`dp[n]` 就是 `s` 中与 `t` 匹配的子序列的数量

## 前置知识

### 什么是子序列（Subsequence）

从原始字符串中删除0个或多个字符，保持剩余字符的相对顺序不变而构成的字符串。与子串（Substring）不同，子序列中的字符不需要是连续的。

```
s = "rabbbit", t = "rabbit"
子序列示例: 选择 s 的第 1,2,3,5,6,7 个字符 → "rabbit" ✓
子序列示例: 选择 s 的第 1,2,4,5,6,7 个字符 → "rabbit" ✓
子序列示例: 选择 s 的第 1,3,4,5,6,7 个字符 → "rabbit" ✓
→ 共3种方式
```

### 什么是一维DP的逆序更新

将二维DP表 `dp[i][j]` 压缩为一维数组 `dp[j]` 的技巧。当计算当前行只需要前一行的值时，可以复用一维数组来减少空间复杂度。但是，当更新 `dp[j]` 需要使用 `dp[j-1]`（前一行的值）时，如果按升序更新 j，`dp[j-1]` 会被当前行的值覆盖。通过按降序（大→小）更新 j，可以正确引用尚未被覆盖的前一行的 `dp[j-1]`。

```java
// 二维DP（原始形式）
dp[i][j] = dp[i-1][j] + dp[i-1][j-1];

// 压缩为一维DP（逆序更新）
for (int j = n; j >= 1; j--) {   // 从大到小更新
    dp[j] += dp[j - 1];          // dp[j-1] 仍然保持前一行的值
}
```

## 复杂度

| | 值 |
|---|---|
| Time | O(m × n) — 对s的每个字符（m个）遍历t的每个字符（n个） |
| Space | O(n) — 仅使用长度为 n+1 的一维数组 |

## 代码

```java
// 输入: 字符串 s（长度 m）和字符串 t（长度 n）
// 输出: 以 int 返回 s 的子序列中与 t 匹配的个数
public int numDistinct(String s, String t) {
    int m = s.length();
    int n = t.length();

    // dp[j] = 与t的前j个字符匹配的s的子序列数量
    // 需要管理索引 0〜n 共 n+1 个状态，因此数组大小设为 n+1
    int[] dp = new int[n + 1];

    // 与空字符串匹配的子序列始终只有1种（不选择任何字符）
    // 无论从 s 的哪个位置开始，这个基准情况都成立
    dp[0] = 1;

    // 依次考虑 s 的每个字符（i 表示已考虑到 s 的第几个字符）
    for (int i = 1; i <= m; i++) {
        // 逆序（大→小）遍历 j
        // 原因: 计算 dp[j] += dp[j-1] 时需要引用更新前的 dp[j-1]
        // 如果按升序更新，dp[j-1] 会先被覆盖，前一行的值就会丢失
        for (int j = n; j >= 1; j--) {
            // i, j 从1开始，但字符串索引从0开始，因此用 i-1, j-1 访问
            if (s.charAt(i - 1) == t.charAt(j - 1))
                // 匹配时: 在 dp[j]（不使用的情况数）上加上 dp[j-1]（使用的情况数）
                // 通过这个加法，"使用"和"不使用"两种选择的总数累积到 dp[j] 中
                dp[j] += dp[j - 1];
            // 不匹配时: 不做任何操作（s[i-1] 无法用于匹配 t[j-1]，只能选择跳过）
        }
    }

    // dp[n] 保存的是整个 s 中与整个 t 匹配的子序列个数
    return dp[n];
}
```
