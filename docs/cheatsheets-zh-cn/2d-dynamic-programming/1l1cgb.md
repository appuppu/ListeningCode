# Finding the Longest Common Subsequence — 求两个字符串的最长公共子序列的长度

## 问题的本质

给定两个字符串 `text1` 和 `text2`。要求返回两个字符串共有的**子序列（subsequence）**中最长的那个的**长度**。子序列是从原字符串中选取若干字符并保持其相对顺序所构成的序列，不要求连续。

## 核心思路

如果两个字符串的末尾字符相同，则该字符属于LCS的一部分，剩余的子问题是将两个字符串各缩短一个字符后的问题。如果末尾字符不同，则从将其中一个字符串缩短一个字符所得到的两个子问题中，选择结果更长的那个。通过在二维表格中自底向上地填充这一递归结构，可以在不重复计算的情况下求得最优解。

## 思考过程

1. **子问题的定义**: 将 `text1` 的前 `i` 个字符与 `text2` 的前 `j` 个字符的LCS长度定义为 `dp[i][j]`。最终要求的答案是 `dp[m][n]`（`m` = text1的长度，`n` = text2的长度）
2. **末尾字符相同时的转移**: 当 `text1[i-1] == text2[j-1]` 时，该字符成为LCS的一部分。因此 `dp[i][j] = dp[i-1][j-1] + 1`。即在将两个字符串各缩短一个字符后的子问题的答案上加1
3. **末尾字符不同时的转移**: 当 `text1[i-1] != text2[j-1]` 时，至少有一个末尾字符不属于LCS。取将 `text1` 缩短一个字符的情况（`dp[i-1][j]`）与将 `text2` 缩短一个字符的情况（`dp[i][j-1]`）中较大的那个。即 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
4. **基础条件**: 当任一字符串为空（长度为0）时，不存在公共子序列，因此 `dp[0][j] = 0` 且 `dp[i][0] = 0`。在Java中生成 `int[][]` 时所有元素会被初始化为0，因此无需显式设置
5. **表格的填充方式**: `dp[i][j]` 依赖于 `dp[i-1][j-1]`、`dp[i-1][j]`、`dp[i][j-1]`。因此将 `i` 从1到m、`j` 从1到n按升序填充，即可保证所引用的值始终已经计算完毕
6. **最终返回值**: 填充完整个表格后，`dp[m][n]` 即为两个完整字符串的LCS长度，将其返回

## 前置知识

### 什么是子序列（Subsequence）

从字符串中删除零个或多个字符，并保持剩余字符的相对顺序不变所得到的序列。与子串（substring）不同，子序列不要求连续。

```
字符串: "abcde"
子序列示例: "ace"（选取 a, c, e，删除 b, d）
非子序列示例: "aec"（违反了原字符串中 a→c→e 的顺序）
```

### 二维数组的创建与初始化

在Java中声明 `new int[m+1][n+1]` 会创建一个大小为 `(m+1) × (n+1)` 的二维数组，所有元素被初始化为0。

```java
int[][] dp = new int[m + 1][n + 1];  // 创建(m+1)行×(n+1)列的数组，所有元素为0
dp[i][j] = 5;                         // 将值5赋给第i行第j列
int val = dp[i][j];                    // 获取第i行第j列的值 → 5
```

### 什么是 Math.max

返回两个整数中较大值的方法。用于比较两个子问题的解，从中选择更优的那个。

```java
Math.max(3, 7);    // 返回两个值中较大的那个 → 7
Math.max(dp[i-1][j], dp[i][j-1]);  // 比较两个单元格的值并返回较大的那个
```

### 什么是 charAt

返回字符串中指定位置的字符的方法。索引从0开始。

```java
String s = "abc";
s.charAt(0);    // 返回索引0处的字符 → 'a'
s.charAt(2);    // 返回索引2处的字符 → 'c'
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(m × n) — 对m×n的表格中的每个单元格填充一次 |
| Space | O(m × n) — 使用大小为(m+1)×(n+1)的二维数组 |

## 代码

```java
// 输入: 两个字符串 text1 和 text2
// 输出: 以 int 形式返回两个字符串的最长公共子序列的长度
public int longestCommonSubsequence(String text1, String text2) {
    // 将text1的长度赋给m，将text2的长度赋给n。用于确定表格大小和循环上限
    int m = text1.length();
    int n = text2.length();

    // dp[i][j] = text1的前i个字符与text2的前j个字符的LCS长度
    // 大小设为(m+1)×(n+1)是为了表示其中一个为空字符串的情况（基础条件）
    // 在Java中int[][]的所有元素被初始化为0，因此基础条件 dp[0][j]=0, dp[i][0]=0 自动满足
    int[][] dp = new int[m + 1][n + 1];

    // i表示当前考虑text1的前多少个字符
    for (int i = 1; i <= m; i++) {
        // j表示当前考虑text2的前多少个字符
        for (int j = 1; j <= n; j++) {
            // dp的索引从1开始，但字符串的索引从0开始，因此用 i-1, j-1 访问
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                // 字符相同时，匹配的字符加入LCS，因此在将两个字符串各缩短一个字符后的子问题的答案上加1
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // 字符不同时，取将text1缩短一个字符的情况与将text2缩短一个字符的情况中LCS较长的那个
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    // 表格右下角的值即为text1整体与text2整体的LCS长度
    return dp[m][n];
}
```
