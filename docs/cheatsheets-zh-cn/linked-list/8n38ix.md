# Removing the Nth Node From the End of a List — 删除链表的倒数第N个节点

## 问题的本质

给定单向链表的头节点 `head` 和整数 `n`。删除链表**倒数第N个**节点，并返回修改后的链表头节点。

## 核心思路

让两个指针保持N个节点的间隔同时前进，当前方指针到达链表末尾时，后方指针正好位于待删除节点的前一个位置。这样只需一次遍历即可完成删除。

## 思考过程

1. **要定位倒数第N个节点，看似需要知道链表的长度**: 直觉上，需要先遍历整个链表求出长度L，再找到第L-N个节点，共需两次遍历。但使用两个指针可以仅用一次遍历完成
2. **使用间隔N个节点的两个指针**: 将fast指针提前移动到比slow指针超前N个节点的位置。在此状态下，两者同时每次前进一步，当fast到达链表末尾时，slow正好位于倒数第N+1个位置。也就是说，slow指向待删除节点的**前一个**节点
3. **在头部添加虚拟节点的原因**: 当待删除节点是链表的头节点（head本身）时，"待删除节点的前一个节点"不存在。在head前放置虚拟节点，可以使头节点的删除与其他节点的删除使用相同的逻辑处理
4. **将fast提前移动N步**: 通过for循环将fast前进N次。此时slow和fast之间存在N个节点
5. **同时移动两个指针**: 在 `fast.next != null` 的条件下，slow和fast同时每次前进一步。当fast的**下一个**节点为null时退出循环。此时，fast指向链表的最后一个节点，slow指向倒数第N+1个节点（即待删除节点的前一个节点）
6. **删除节点并返回链表**: slow的下一个节点就是待删除节点，通过 `slow.next = slow.next.next` 重新链接指针来删除该节点。最后返回 `dummy.next`。不直接返回head的原因是，当head被删除时需要正确返回新的头节点

## 前置知识

### 什么是 ListNode

ListNode是表示单向链表中一个节点的类。每个节点持有值 `val` 和指向下一个节点的引用 `next`。`next` 为null的节点即为链表的末尾。

```java
ListNode node = new ListNode(5);  // 创建值为5的节点，next为null
node.next = new ListNode(10);     // 链表变为 node → 10 → null
```

### 什么是虚拟节点（Sentinel Node）

虚拟节点是添加在链表头部的一个不持有有效值的哨兵节点。即使删除头节点，也能保证"待删除节点的前一个节点"始终存在，从而无需对头节点进行特殊处理。

```java
ListNode dummy = new ListNode(0);  // 创建虚拟节点
dummy.next = head;                 // 将虚拟节点的next指向原来的头节点
// 处理完成后，dummy.next即为新的头节点
```

### 什么是 Two-Pointer（双指针）技巧

双指针技巧是通过以不同速度或间隔移动两个指针，来高效定位链表中特定位置的方法。在本题中，两个保持N个间隔的指针以相同速度移动，从而定位倒数第N个位置。

```java
ListNode slow = head;
ListNode fast = head;
// 先将fast提前移动N步，然后两者同时前进
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历链表一次 |
| Space | O(1) — 仅使用虚拟节点和两个指针 |

## 代码

```java
// 输入: 单向链表的头节点 head 和整数 n
// 输出: 返回删除倒数第N个节点后的链表头节点 ListNode
public ListNode removeNthFromEnd(ListNode head, int n) {
    // 在头部添加值为0的虚拟节点
    // 放置虚拟节点后，即使删除头节点也能保证"待删除节点的前一个节点"存在
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // 两个指针均从虚拟节点开始
    // 从虚拟节点开始，可以确保最终slow正确地位于待删除节点的前一个位置
    ListNode slow = dummy;
    ListNode fast = dummy;

    // 将fast提前移动N步，在slow和fast之间创建N个节点的间隔
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }

    // 同时移动两个指针，当fast到达链表末尾时停止
    // 条件设为 fast.next != null，是为了在fast到达链表最后一个节点时
    // slow正好位于待删除节点的前一个位置
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // slow.next 即为待删除节点。将slow的next指针重新链接到下一个节点，从而将待删除节点从链表中移除
    slow.next = slow.next.next;

    // 返回 dummy.next 而非 head，是因为当head为待删除节点时需要正确返回新的头节点
    return dummy.next;
}
```
