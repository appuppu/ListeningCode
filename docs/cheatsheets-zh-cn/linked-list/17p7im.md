# Detecting a Cycle in a Linked List — 判定链表中是否存在环

## 问题的本质

给定一个单向链表的头节点 `head`。如果链表中某个节点的 `next` 指针指向了之前已访问过的节点（即存在环），则返回 `true`；如果不存在环，则返回 `false`。

## 核心思路

同时移动两个速度不同的指针，如果存在环，快指针必然会追上慢指针并相遇。如果不存在环，快指针会先到达链表末尾。利用这一性质，无需额外的数据结构即可检测环。

## 思考过程

1. **思考环的本质**：遍历存在环的链表时，永远无法到达末尾（null），会一直循环下去。反之，如果不存在环，遍历必然会到达 null 并终止
2. **使用速度不同的指针**：准备一个每次前进1步的指针（slow）和一个每次前进2步的指针（fast）。在环内，fast 每步缩短与 slow 之间1个节点的距离，因此两者必然会相遇
3. **相遇能证明环存在的原因**：如果不存在环，fast 会先到达 null，因此 slow 和 fast 不可能指向同一个节点。发生相遇 ＝ 环存在
4. **确定终止条件**：当 fast 或 fast.next 为 null 时，说明链表存在末尾，因此没有环。当 slow 和 fast 指向同一个节点时，说明环存在
5. **设置初始位置**：将 slow 放在 head，将 fast 放在 head.next。这样 while 循环的条件 `slow != fast` 从一开始就成立，可以进入循环开始遍历
6. **最终返回值**：当 slow 和 fast 相遇时返回 `true`，当 fast 到达 null 时返回 `false`

## 前置知识

### ListNode（链表节点）

链表由一个个节点构成。每个节点包含"值"和"指向下一个节点的指针"。最后一个节点的 next 指向 null（在不存在环的情况下）。

```java
class ListNode {
    int val;            // 节点存储的值
    ListNode next;      // 指向下一个节点的引用（没有则为 null）
}

ListNode node = head;       // 获取头节点
node.next;                  // 获取下一个节点
node.next.next;             // 获取下下一个节点
```

### Floyd's Tortoise and Hare（Floyd 循环检测算法）

使用两个速度不同的指针来检测环的算法。slow 指针每次前进1步，fast 指针每次前进2步。在环内，fast 每步向 slow 靠近1个节点，因此如果存在环，两者必然会在有限步数内相遇。

```java
ListNode slow = head;       // 每次前进1步的指针
ListNode fast = head.next;  // 每次前进2步的指针
slow = slow.next;           // 将 slow 前进1步
fast = fast.next.next;      // 将 fast 前进2步
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 不存在环时，fast 在 n/2 步内到达末尾；存在环时，也会在环长度以内相遇 |
| Space | O(1) — 仅使用两个指针变量，不需要额外的数据结构 |

## 代码

```java
// 输入：单向链表的头节点 head
// 输出：如果存在环则返回 true，不存在则返回 false
public boolean hasCycle(ListNode head) {
    // 如果节点数为0个或1个，则不可能存在环。返回 false 并终止
    if (head == null || head.next == null) {
        return false;
    }

    // 将 slow 放在 head，将 fast 放在 head.next
    // 将 fast 放在前一个位置，使 while 条件 slow != fast 从一开始就成立，从而进入循环
    ListNode slow = head;
    ListNode fast = head.next;

    // 重复循环直到 slow 和 fast 相遇（相遇则终止）
    while (slow != fast) {
        // 如果 fast 为 null 或 fast.next 为 null，说明链表存在末尾，因此没有环
        if (fast == null || fast.next == null) {
            return false;
        }
        // 将 slow 前进1步，将 fast 前进2步
        // 由于速度差，在环内 fast 每步向 slow 靠近1个节点
        slow = slow.next;
        fast = fast.next.next;
    }

    // while 条件 slow != fast 为假 ＝ slow 和 fast 相遇，因此环存在
    return true;
}
```
