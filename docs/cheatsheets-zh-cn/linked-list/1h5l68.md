# Reversing Nodes in Groups of K — 将链表按每K个节点为一组进行反转

## 问题的本质

给定单向链表的头节点 `head` 和整数 `k`。从链表头部开始，将链表按每 `k` 个节点为一组进行划分，并反转每组内节点的顺序。如果末尾的组不足 `k` 个节点，则保持该组不变。返回修改后链表的头节点。

## 核心思路

在链表头部放置一个虚拟节点，以"当前组的前一个节点"和"当前组的第k个节点"作为基准点，逐一修改每组内的指针指向，从而在不使用额外内存的情况下原地完成反转。

## 思考过程

1. **需要按组进行反转**：不是反转整个链表，而是每 `k` 个节点为一组进行反转。即形成"确定当前组的范围"→"反转该组"→"移动到下一组"的循环结构
2. **确定组的范围需要找到第k个节点**：准备一个辅助函数 `getKth`，从当前位置开始查找第 `k` 个节点。如果第 `k` 个节点不存在（为 `null`），说明剩余节点不足 `k` 个，不进行反转并结束
3. **反转后需要正确连接各组**：反转一个组后，该组的头节点和尾节点会互换。需要将前一组的尾节点（`groupPrev`）重新指向反转后的新头节点（即原来的第 `k` 个节点）
4. **使用虚拟节点统一处理首组的反转**：反转第一组时，链表的头节点本身会发生变化。在头部放置虚拟节点后，"组的前一个节点指向新的头节点"这一操作，无论对第一组还是后续的组都可以使用相同的逻辑来处理
5. **每组的反转使用与标准链表反转相同的方法**：使用 `prev` 和 `curr` 两个指针，逐个将 `curr.next` 修改为指向 `prev`，同时逐节点向前推进。不过，将 `prev` 的初始值设为当前组的下一个节点（`groupNext`），这样反转后的尾节点会自动与下一组相连接
6. **反转后更新 groupPrev 并移动到下一组**：反转前的组头节点（`groupPrev.next`）在反转后变成了组的尾节点。将该节点作为下一组的 `groupPrev`，进入下一次迭代

## 前置知识

### 什么是 ListNode

ListNode 是表示单向链表中一个节点的类。每个节点持有"值（val）"和"指向下一个节点的指针（next）"。`next` 为 `null` 的节点即为链表的末尾。

```java
class ListNode {
    int val;          // 节点保存的值
    ListNode next;    // 指向下一个节点的引用（末尾节点为null）

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### 什么是虚拟节点（Dummy Node）

虚拟节点是在链表头部添加一个临时节点的技巧。当头节点可能发生变化时，可以避免额外的条件判断。`dummy.next` 始终指向链表的实际头节点。

```java
ListNode dummy = new ListNode(0);  // 值可以是任意值
dummy.next = head;                 // 虚拟节点的next指向实际的头节点
// ... 对链表进行操作 ...
return dummy.next;                 // 返回操作后的实际头节点
```

### 链表反转的基本操作

使用 `prev` 和 `curr` 两个指针，将每个节点的 `next` 逐一修改为指向前一个节点。

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode tmp = curr.next;  // 临时保存下一个节点
    curr.next = prev;          // 将当前节点的next修改为指向前一个节点
    prev = curr;               // 将prev移动到当前节点
    curr = tmp;                // 将curr移动到下一个节点
}
// prev即为反转后的头节点
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 每个节点只被访问常数次（查找第k个节点时一次，反转时一次） |
| Space | O(1) — 仅使用指针变量，不需要额外的数据结构 |

## 代码

```java
// 输入: 链表的头节点 head 和整数 k
// 输出: 返回按每k个节点为一组进行反转后的链表头节点
public ListNode reverseKGroup(ListNode head, int k) {
    // 创建虚拟节点，通过 dummy.next = head 连接到实际链表的头部
    // 使用虚拟节点可以确保即使反转第一组时，"当前组的前一个节点"也始终存在
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // groupPrev 指向"即将反转的组的前一个节点"
    // 初始值为虚拟节点
    ListNode groupPrev = dummy;

    // 通过无限循环，每次迭代反转一个组
    while (true) {
        // 从 groupPrev 的下一个节点出发，沿next移动k-1次以找到第k个节点
        // 如果中途遇到null，说明剩余节点不足k个，返回null
        ListNode kth = getKth(groupPrev, k);

        // 如果第k个节点不存在，说明剩余节点不足k个，直接结束
        // 通过这个判断满足了"不足k个节点的组保持不变"的题目要求
        if (kth == null) break;

        // groupNext 是"当前组的下一个节点"，用作反转的终止标记
        ListNode groupNext = kth.next;

        // 将 prev 的初始值设为 groupNext
        // 这样反转后组的尾节点的next会自动指向下一组的头节点
        ListNode prev = kth.next;
        // curr 从当前组的头节点开始（反转后该节点将变为组的尾节点）
        ListNode curr = groupPrev.next;

        // 在 curr 不等于 groupNext 的范围内，反转组内每个节点的next指针
        // 通过此操作，每个节点的next将改为指向前一个节点
        while (curr != groupNext) {
            ListNode tmp = curr.next;  // 临时保存下一个节点
            curr.next = prev;          // 将当前节点的next修改为指向前一个节点
            prev = curr;               // 将prev移动到当前节点
            curr = tmp;                // 将curr移动到下一个节点
        }

        // 保存反转前的头节点（反转后该节点已变为组的尾节点）
        ListNode tmp = groupPrev.next;
        // 反转后的组头节点是 kth（即原来的第k个节点），
        // 将前一组的尾节点正确地指向反转后的新头节点
        groupPrev.next = kth;
        // 反转前的组头节点在反转后变成了组的尾节点
        // 将该节点作为下一次迭代的 groupPrev
        groupPrev = tmp;
    }

    // dummy.next 指向操作后整个链表的头节点
    return dummy.next;
}

// 从 node 的下一个节点开始，返回第k个节点。如果不足k个则返回null
private ListNode getKth(ListNode node, int k) {
    // 从 node 的下一个节点出发
    node = node.next;
    // 沿next移动k-1次到达第k个节点
    // 如果中途遇到null，说明剩余节点不足k个
    while (node != null && k > 1) {
        node = node.next;
        k--;
    }
    // 返回第k个节点（如果不足k个则返回null）
    return node;
}
```
