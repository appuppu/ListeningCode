# Reordering a Linked List by Interleaving Ends — 通过交替连接两端来重排链表

## 问题的本质

给定一个单向链表 L0 → L1 → … → Ln-1 → Ln。要求将该链表**原地（in-place）**重排为 L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → … 的顺序。不能修改节点的值，只能通过操作节点的链接（next 指针）来实现。

## 核心思路

如果将链表的后半部分反转，那么只需从"前半部分的头部"和"后半部分的头部（即原来的尾部）"交替连接，就能得到目标顺序。为了反转后半部分，首先需要找到链表的中间点，将链表分成前半部分和后半部分。

## 思考过程

1. **观察重排后的结构**: L0 → Ln → L1 → Ln-1 → … 这个顺序是从链表的"头部"和"尾部"交替取出元素的结果。也就是说，只需要将头部侧和尾部侧两个序列交替合并即可
2. **从尾部取出元素需要反转**: 在单向链表中，访问尾部需要 O(n) 的时间。但是，如果将链表的后半部分反转，后半部分的头部就变成了原来的尾部，只需从头部依次遍历就能获取尾部侧的元素
3. **找到链表的中间点**: 为了反转后半部分，首先需要确定在哪里分割链表。使用 slow/fast 指针（龟兔赛跑法），只需一次遍历就能找到中间点。slow 每次走1步，fast 每次走2步，当 fast 到达链表末尾时，slow 正好指向中间点
4. **反转后半部分**: 从中间点的下一个节点开始，将每个节点的 next 指针指向前一个节点，从而将后半部分链表反转。使用 prev 变量追踪前一个节点，循环结束后 prev 即为反转后的头节点
5. **将前半部分和反转后的后半部分交替合并**: 分别从前半部分链表和后半部分链表的头部开始遍历，将后半部分的节点插入到前半部分节点的后面。由于每一步都要修改 next 指针，需要先将原始链接保存到临时变量中再进行修改
6. **后半部分的长度小于或等于前半部分**: 当链表长度为奇数时，前半部分会多一个节点，因此合并的循环条件为 `second != null`。当后半部分的节点用完时，合并即完成

## 前置知识

### 什么是 slow/fast 指针（龟兔赛跑法）

这是一种通过一次遍历找到链表中间点的技巧。slow 每次移动1个节点，fast 每次移动2个节点。当 fast 到达链表末尾时，slow 正好指向链表的中间点。

```java
ListNode slow = head, fast = head;
while (fast.next != null && fast.next.next != null) {
    slow = slow.next;        // slow前进1步
    fast = fast.next.next;   // fast前进2步
}
// 循环结束时，slow指向链表的中间节点
```

### 什么是链表反转

将每个节点的 next 指针从指向下一个节点改为指向前一个节点的操作。在遍历过程中使用 prev（前一个节点）进行追踪，逐个节点地反转链接方向。

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode nxt = curr.next;  // 保存下一个节点
    curr.next = prev;          // 将链接指向前一个节点
    prev = curr;               // 将prev更新为当前节点
    curr = nxt;                // 移动到下一个节点
}
// 循环结束时，prev指向反转后链表的头节点
```

### 什么是两个链表的交替合并

从两个链表中交替逐个取出元素，连接成一个链表的操作。由于每一步都要修改 next 指针，需要先将原始链接保存到临时变量中再进行修改。

```java
ListNode a = list1, b = list2;
while (b != null) {
    ListNode tmpA = a.next;   // 保存a的原始下一个节点
    ListNode tmpB = b.next;   // 保存b的原始下一个节点
    a.next = b;               // 将b插入到a的后面
    b.next = tmpA;            // 将a的原始下一个节点连接到b的后面
    a = tmpA;                 // 将a移动到下一个位置
    b = tmpB;                 // 将b移动到下一个位置
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 中间点查找、后半部分反转、合并这三个步骤各为 O(n) |
| Space | O(1) — 仅使用指针变量，不创建额外的数据结构 |

## 代码

```java
// 输入: 单向链表的头节点 head
// 输出: 无（原地重排链表，返回值为 void）
void reorderList(ListNode head) {
    // 空链表不需要重排
    if (head == null) return;

    // 步骤1: 使用slow/fast指针找到链表的中间点
    // fast以slow两倍的速度前进，因此当fast到达末尾时，slow指向中间节点
    ListNode slow = head, fast = head;
    while (fast.next != null
            && fast.next.next != null) {
        slow = slow.next;          // slow前进1步
        fast = fast.next.next;     // fast前进2步
    }

    // 步骤2: 分离后半部分链表并将其反转
    ListNode second = slow.next;   // second是后半部分链表的头节点
    slow.next = null;              // 切断前半部分链表的末尾，将链表分成前后两部分
    ListNode prev = null;
    while (second != null) {
        ListNode nxt = second.next;  // 保存下一个节点
        second.next = prev;          // 将链接指向前一个节点
        prev = second;               // 将prev更新为当前节点
        second = nxt;                // 移动到下一个节点
    }
    // 循环结束时，prev指向反转后的后半部分链表的头节点（即原链表的尾节点）

    // 步骤3: 将前半部分和反转后的后半部分交替合并
    ListNode first = head;         // 前半部分链表的头节点
    second = prev;                 // 反转后的后半部分链表的头节点
    // 当链表长度为奇数时，前半部分会多一个节点，因此当后半部分(second)用完时结束
    while (second != null) {
        ListNode tmp1 = first.next;   // 保存前半部分的下一个节点（不保存的话修改next时会丢失原始链接目标）
        ListNode tmp2 = second.next;  // 保存后半部分的下一个节点
        first.next = second;          // 将后半部分的节点插入到前半部分节点的后面
        second.next = tmp1;           // 将前半部分的后续节点连接到后半部分节点的后面
        first = tmp1;                 // 将前半部分的指针移动到下一个位置
        second = tmp2;                // 将后半部分的指针移动到下一个位置
    }
}
```
