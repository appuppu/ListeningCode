# Finding the Duplicate in an Array of N Plus One Integers — 从N+1个整数数组中找出唯一重复的数

## 问题的本质

给定一个长度为 n+1 的整数数组 `nums`。每个元素都在 1 到 n 的范围内，且必定存在唯一一个重复的数。要求在不修改数组、且仅使用常数额外空间的条件下，找出并返回该重复的数。

## 核心思路

将数组中每个索引 `i` 到 `nums[i]` 的移动关系视为"链表"，则重复数存在的位置会导致链接汇合，从而产生环（循环）。使用 Floyd's Cycle Detection（龟兔赛跑算法），可以在 O(1) 空间内确定该环的入口＝重复的数。

## 思考过程

1. **将数组视为隐式链表**：将索引 `i` 处的值 `nums[i]` 视为"指向下一个节点的指针"。从索引 0 出发，沿 `nums[0]` → `nums[nums[0]]` → … 遍历，其行为与链表遍历完全相同。由于值的范围是 1〜n，因此永远不会回到索引 0，始终指向有效索引
2. **理解重复为何产生环**：当两个不同的索引拥有相同的值时，指向该值对应索引的箭头就有两条。这在链表中意味着两个节点指向同一个节点，从汇合点开始形成环。环的入口正是重复的数
3. **检测环的存在**：slow 指针每次前进 1 步（`slow = nums[slow]`），fast 指针每次前进 2 步（`fast = nums[nums[fast]]`）。如果存在环，slow 和 fast 必定在环内的某处相遇
4. **确定环的入口**：相遇后，将 slow 重置回起点（`nums[0]`），fast 保持在当前位置。两者都以 1 步的速度前进，它们将在环的入口再次相遇。该入口对应的值就是重复的数
5. **为何会在入口相遇**：从起点到环入口的距离与从相遇点到环入口的距离相等，这一点已被数学证明。因此，两者以相同速度前进时必定在入口处重合

## 前提知识

### 什么是隐式链表（Implicit Linked List）

即使不实际创建节点对象，也可以将数组的值解释为"指向下一个索引的指针"，从而表达与链表相同的结构。索引 `i` 的节点的"下一个节点"就是索引 `nums[i]` 的节点。

```java
// 数组 nums = [1, 3, 4, 2, 2] 的链表遍历过程
int current = nums[0];       // 索引0的值 → 1（下一步前往索引1）
current = nums[current];     // 索引1的值 → 3（下一步前往索引3）
current = nums[current];     // 索引3的值 → 2（下一步前往索引2）
current = nums[current];     // 索引2的值 → 4（下一步前往索引4）
current = nums[current];     // 索引4的值 → 2（回到索引2 → 产生环）
```

### 什么是 Floyd's Cycle Detection（弗洛伊德环检测）

该算法用于检测链表中的环并确定环的入口。使用两个指针（slow：每次 1 步，fast：每次 2 步）。如果存在环，两者必定相遇，之后通过后续步骤即可确定环的入口。

```java
// 阶段1：在环内相遇
slow = nums[slow];           // slow前进1步
fast = nums[nums[fast]];     // fast前进2步

// 阶段2：确定环的入口
slow = nums[slow];           // 两者都每次前进1步
fast = nums[fast];           // 相遇的地点就是环的入口
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 每个指针最多只需遍历链表约2圈 |
| Space | O(1) — 仅使用 slow 和 fast 两个变量 |

## 代码

```java
// 输入：长度为 n+1 的整数数组 nums（每个元素在 1 到 n 之间，仅有一个重复）
// 输出：以 int 形式返回重复的数
public int findDuplicate(int[] nums) {
    // 将 slow 和 fast 都初始化为链表的头部（nums[0]）
    // 索引0本身不在值的范围（1〜n）内，因此不会成为环的一部分，是安全的起始点
    int slow = nums[0];
    int fast = nums[0];

    // 阶段1：slow每次前进1步，fast每次前进2步，重复直到在环内相遇
    // 使用do-while的原因：初始值相同，需要跳过第一次比较
    do {
        slow = nums[slow];           // slow前进1步
        fast = nums[nums[fast]];     // fast前进2步（如果存在环则必定追上）
    } while (slow != fast);

    // 阶段2：将slow重置回起点，两者都每次前进1步
    // 利用"起点到入口的距离 = 相遇点到入口的距离"这一性质
    slow = nums[0];
    while (slow != fast) {
        slow = nums[slow];           // 两者都每次前进1步
        fast = nums[fast];           // 必定在环的入口处重合
    }

    // 环的入口 = 被两个不同索引指向的数 = 重复的数，将其返回
    return slow;
}
```
