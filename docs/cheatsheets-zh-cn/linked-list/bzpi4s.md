# Adding Two Numbers Represented as Linked Lists — 将逆序链表表示的两个数相加

## 问题的本质

给定两个非空链表。每个链表以**逆序**（个位在头部）表示一个非负整数，每个节点存储一位数字。将两个数相加，并以同样的**逆序链表**形式返回其和。

## 核心思路

由于链表以逆序（个位在头部）存储数字，从头节点开始依次相加，就能按照个位→十位→百位……的顺序进行加法，与竖式计算的顺序完全一致。只需用一个变量保存进位（carry），并将每一位的计算结果作为新节点依次连接即可。

## 思考过程

1. **逆序存储是一个优势**：数值加法从个位开始计算。链表是逆序存储的，因此从头节点开始处理就能自然地从个位开始相加，无需反转数位顺序
2. **管理每一位的加法和进位**：每一位计算 `l1的值 + l2的值 + carry`。如果总和大于等于10，则产生进位。`sum % 10` 是该位的结果，`sum / 10` 是向下一位的进位。这与竖式计算的规则完全相同
3. **处理两个链表长度不同的情况**：即使其中一个链表先结束，只要另一个链表或carry仍有剩余，就需要继续处理。将while循环的条件设为 `l1 != null || l2 != null || carry != 0`，就能统一处理所有情况
4. **使用哑节点简化结果链表的构建**：为了避免对结果链表的头节点进行特殊处理，在头部放置一个值为0的哑节点。将每一位的结果都追加到 `curr.next`，最后返回 `dummy.next` 即可获得正确的结果链表
5. **统一循环内的处理逻辑**：在每次迭代中，如果 `l1` 和 `l2` 不为null，则将各自的值加到sum中，并将指针前移。如果为null则不做任何操作。通过这种条件分支，可以自然地处理链表长度不同的情况
6. **最终返回的内容**：哑节点的下一个节点 `dummy.next` 就是结果链表的头节点。返回该节点即可

## 前置知识

### 什么是 ListNode

ListNode 是表示单向链表节点的类。每个节点持有一个整数值 `val` 和指向下一个节点的引用 `next`。`next` 为 `null` 的节点是链表的末尾。

```java
public class ListNode {
    int val;              // 该节点保存的一位数值
    ListNode next;        // 指向下一个节点的引用（末尾节点为null）
    ListNode(int val) {   // 构造函数：指定值来创建节点
        this.val = val;
    }
}
```

### 什么是哑节点（Dummy Head）

哑节点是放置在链表头部的、不持有实际值的虚拟节点。在构建结果链表时，使用哑节点可以避免对第一个节点进行特殊处理。所有节点都可以通过 `curr.next = new ListNode(...)` 统一追加，最后返回 `dummy.next` 即可获取实际的头节点。

```java
ListNode dummy = new ListNode(0);  // 创建哑节点
ListNode curr = dummy;             // curr是追踪链表末尾的指针
curr.next = new ListNode(5);       // 在哑节点后面追加值为5的节点
curr = curr.next;                  // 将curr前移到末尾
// dummy.next 指向实际链表的头节点（值为5的节点）
```

### 什么是进位（Carry）

当两个一位数相加的总和大于等于10时，需要向下一位传递的值。通过 `sum / 10` 计算（由于是整数除法，结果为0或1）。当前位保留的值通过 `sum % 10` 求得。
例如：7 + 8 = 15 时，carry = 15 / 10 = 1，当前位的值 = 15 % 10 = 5。

## 计算复杂度

| | 值 |
|---|---|
| Time | O(max(n, m)) — 遍历两个链表中较长的那个链表的长度 |
| Space | O(max(n, m)) — 结果链表的节点数最多为 max(n, m) + 1 个 |

## 代码

```java
// 输入：逆序链表 l1 和 l2（每个节点为一位非负整数）
// 输出：将两个数的和以逆序链表形式返回
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    // 创建哑节点。这样无需对结果链表的头节点进行特殊处理
    // 哑节点不包含在最终结果中，dummy.next 才是实际的头节点
    ListNode dummy = new ListNode(0);
    // curr是追踪结果链表末尾的指针
    ListNode curr = dummy;
    // 保存进位的变量。当每一位的加法结果大于等于10时，向下一位传递的值（0或1）
    int carry = 0;

    // 只要任一链表还有剩余节点，或者还有进位，就继续循环
    // carry != 0 这个条件可以处理 999 + 1 = 1000 这样位数增加的情况
    while (l1 != null || l2 != null || carry != 0) {
        // 将上一位的进位作为sum的初始值
        int sum = carry;

        // 如果l1还有剩余节点，则将其值加到sum中，并将指针前移
        // 如果为null则不做任何操作。这样即使l1先结束，处理也能继续
        if (l1 != null) {
            sum += l1.val;
            l1 = l1.next;
        }

        // 如果l2还有剩余节点，则将其值加到sum中，并将指针前移
        // 如果为null则不做任何操作。这样即使l2先结束，处理也能继续
        if (l2 != null) {
            sum += l2.val;
            l2 = l2.next;
        }

        // 计算进位。如果sum大于等于10则为1，小于10则为0
        carry = sum / 10;
        // 用当前位的值（sum % 10）创建新节点，并连接到结果链表的末尾
        curr.next = new ListNode(sum % 10);
        // 将curr前移到末尾，以便在下一次迭代中追加新节点
        curr = curr.next;
    }

    // 哑节点的下一个节点就是结果链表的头节点
    return dummy.next;
}
```
