# Reversing a Linked List — 反转单向链表

## 问题的本质

给定一个单向链表（singly linked list）的头节点 `head`。将链表中所有链接（指针）的方向反转，使原来的尾节点成为新的头节点，并返回该新的头节点。

## 核心思路

将每个节点的 `next` 指针从"指向下一个节点"改为"指向前一个节点"，即可将整个链表反转。只需使用三个指针（prev、curr、next），逐一安全地重新连接链接，仅需遍历一次即可完成。

## 思考过程

1. **反转即是改变链接的方向**：链表的顺序由节点的 `next` 指针决定。将所有节点的 `next` 从"指向下一个节点"改为"指向前一个节点"，整个链表就会被反转
2. **重新连接链接时会丢失对下一个节点的引用**：在执行 `curr.next = prev` 的瞬间，对原来下一个节点的引用就会丢失。因此，在重新连接之前，需要将 `curr.next` 保存到另一个变量 `next` 中
3. **使用三个指针管理状态**：`prev`（重新连接的目标，即前一个节点）、`curr`（当前正在处理的节点）、`next`（保存原来下一个节点的变量），有了这三个指针，就可以同时进行链接的重新连接和遍历
4. **确定初始状态**：反转后的尾节点（即原来的头节点）的 `next` 应该为 `null`，因此 `prev` 的初始值设为 `null`。`curr` 的初始值设为 `head`（头节点）
5. **循环的终止条件和返回值**：当 `curr` 变为 `null` 时，所有节点的处理已完成。此时 `prev` 指向最后处理的节点（即原来的尾节点），因此将 `prev` 作为新的头节点返回

## 前置知识

### ListNode（链表节点）是什么

ListNode 是构成链表的元素。每个节点包含"值（val）"和"指向下一个节点的指针（next）"。最后一个节点的 `next` 为 `null`。

```java
class ListNode {
    int val;          // 节点存储的值
    ListNode next;    // 指向下一个节点的引用（若为尾节点则为 null）

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### 什么是指针的重新连接

通过将另一个节点赋值给节点的 `next` 字段，来改变链接的方向。

```java
// 原始状态: A → B → C
// A.next 指向 B

A.next = null;   // A → null（A 和 B 之间的链接断开）
B.next = A;      // B → A（建立了从 B 到 A 的反向链接）
// 结果: C → null, B → A → null
```

## 复杂度

| | 值 |
|---|---|
| Time | O(n) — 只需遍历链表一次 |
| Space | O(1) — 仅使用三个指针变量，不需要额外的数据结构 |

## 代码

```java
// 输入: 单向链表的头节点 head
// 输出: 返回反转后链表的新头节点（ListNode）
ListNode reverseList(ListNode head) {
    // prev: 重新连接的目标（反转后的"前一个节点"）
    // 第一个节点（原来的头节点）在反转后会成为尾节点，因此其 next 应为 null。所以初始值设为 null
    ListNode prev = null;
    // curr: 即将进行链接重新连接的节点。从头节点开始处理
    ListNode curr = head;

    // 当 curr 变为 null 时，所有节点的处理已完成
    while (curr != null) {
        // 保存原来的下一个节点（因为下一步要修改 curr.next，所以先保存引用以免丢失）
        ListNode next = curr.next;

        // 反转链接：将指针从指向下一个节点改为指向前一个节点。这是反转操作的核心
        curr.next = prev;

        // 将 prev 前移到当前节点（在下一次迭代中，作为下一个节点的链接重新连接目标）
        prev = curr;
        // 将 curr 前移到之前保存的原来的下一个节点（这样链表的遍历得以继续）
        curr = next;
    }

    // 在循环的最后一次迭代中，prev 被赋值为最后处理的节点（即原来的尾节点）
    // 该节点就是反转后链表的新头节点
    return prev;
}
```
