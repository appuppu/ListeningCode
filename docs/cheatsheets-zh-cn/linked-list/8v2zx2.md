# Merging Two Sorted Linked Lists — 将两个已排序链表合并为一个链表

## 问题的本质

给定两个已排序链表 `list1` 和 `list2`。将它们合并为一个已排序链表，并返回合并后链表的**头节点**。

## 核心思路

比较两个链表的头节点，选择较小的一方作为合并结果的头节点。剩余部分是"较小一方的下一个节点"与"另一个链表"的合并结果，这与原问题具有相同的结构，因此可以用递归来求解。

## 思考过程

1. **合并的每一步执行的操作相同**：比较两个链表的头节点，选择较小的一方。该操作重复执行直到链表为空。由于每次都做相同的判断，所以可以用递归来表达
2. **考虑基准情形**：如果其中一个链表为空（null），则直接返回另一个链表。如果两个都为空，则返回 null（该情形包含在其中一方为 null 的情形中）
3. **考虑递归步骤**：如果 `list1.val <= list2.val`，则 `list1` 成为头节点。将"`list1` 的剩余部分"与"`list2` 的全部"合并的结果连接到 `list1.next`。反之则将 `list2` 作为头节点并进行相同的处理
4. **每次递归调用使问题规模减少1**：每次从其中一个链表消耗1个节点，因此共经过 n 次递归即可处理完所有节点
5. **最终返回的内容**：每次递归调用返回所选的节点（`list1` 或 `list2`）。第一次调用返回的节点即为合并后链表的头节点

## 前置知识

### ListNode（链表节点）是什么

ListNode 是表示链表中各元素的类。`val` 字段存储值，`next` 字段存储对下一个节点的引用。`next` 为 null 的节点即为链表的末尾。

```java
class ListNode {
    int val;          // 节点存储的值
    ListNode next;    // 对下一个节点的引用（末尾时为 null）

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### 递归（Recursion）是什么

递归是一种通过函数调用自身来求解问题的方法。它将大问题分解为具有相同结构的小问题，当到达基准情形（无法再分解的最小问题）时返回结果。每次调用都会在调用栈上压入一个栈帧，因此会消耗与递归深度相当的空间。

```java
// 示例：计算阶乘
int factorial(int n) {
    if (n <= 1) return 1;           // 基准情形：不再进一步分解
    return n * factorial(n - 1);    // 递归步骤：将问题规模减少1并调用自身
}
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(n) — 通过两个链表的总节点数 n 次递归调用来处理所有节点 |
| Space | O(n) — 每次递归调用都会在调用栈上压入一个栈帧，最大深度为 n 层 |

## 代码

```java
// 输入：两个已排序链表的头节点 list1 和 list2
// 输出：以 ListNode 形式返回合并后的已排序链表的头节点
ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    // 基准情形：如果 list1 为空，则直接返回剩余的 list2（因为 list1 为空，所以 list2 本身就是合并结果）
    if (list1 == null) return list2;
    // 基准情形：如果 list2 为空，则直接返回剩余的 list1（因为 list2 为空，所以 list1 本身就是合并结果）
    if (list2 == null) return list1;

    // 比较 list1 的头节点和 list2 的头节点，决定将哪个节点放在合并结果的头部
    if (list1.val <= list2.val) {
        // 选择 list1 作为头节点，将 list1 的剩余部分（list1.next）与 list2 的全部合并的结果连接到 list1 的下一个位置
        list1.next = mergeTwoLists(list1.next, list2);
        return list1; // list1 成为合并结果的头节点
    } else {
        // 选择 list2 作为头节点，将 list1 的全部与 list2 的剩余部分（list2.next）合并的结果连接到 list2 的下一个位置
        list2.next = mergeTwoLists(list1, list2.next);
        return list2; // list2 成为合并结果的头节点
    }
}
```
