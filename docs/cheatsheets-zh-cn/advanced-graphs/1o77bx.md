# Deriving the Order of an Alien Alphabet — 还原外星语言的字母顺序

## 问题的本质

给定一个按外星语言的字典序排列的单词列表 `words`。根据这个排列顺序，推断该语言中字母的顺序，并以字符串形式返回。如果顺序存在矛盾（例如存在环，或者短单词排在长单词之后），则返回空字符串 `""`。

## 核心思路

比较相邻的两个单词，可以从"第一个不同的字符"中获得一个顺序关系（有向边）。将所有相邻单词对得到的顺序关系构建为有向图，然后通过 DFS 拓扑排序确定整体顺序。如果存在环，则说明顺序存在矛盾。

## 思考过程

1. **通过比较相邻单词提取顺序关系**：在已排序的列表中，将相邻的两个单词 `words[i]` 和 `words[i+1]` 从头开始比较，找到第一个不同字符的组合 `(a, b)` 后，就可以确定"a 排在 b 之前"这一顺序关系。该关系可以表示为有向图中的边 `a → b`
2. **检测无效输入**：如果 `words[i]` 是 `words[i+1]` 的前缀匹配且 `words[i]` 更长（例如：`"abc"` 排在 `"ab"` 之前），则违反字典序规则，应立即返回空字符串
3. **将所有字符注册为图的节点**：由于存在无法获得顺序关系的字符，因此需要将所有单词中的所有字符注册为图的节点。这样，即使没有边的字符也能包含在结果中
4. **通过 DFS 拓扑排序确定整体顺序**：对有向图执行 DFS，在每个节点的探索完成时将其添加到列表中。将 DFS 的后序遍历（post-order）结果反转后，即可得到拓扑顺序（依赖源排在前面的顺序）
5. **通过三色标记检测环**：在 DFS 过程中，将每个节点管理为"未访问(0)"、"探索中(1)"、"已探索(2)"三种状态。如果再次到达处于探索中状态的节点，则说明存在环，顺序无法确定，返回空字符串
6. **反转后构建字符串**：将 DFS 的后序遍历列表反转以获得拓扑顺序。将列表中的所有字符连接起来，返回结果字符串

## 前置知识

### 什么是拓扑排序

将有向无环图（DAG）的所有节点按照不违反边方向的顺序排成一列的操作。如果存在边 `a → b`，则在结果中 `a` 一定排在 `b` 之前。存在环的图不存在拓扑顺序。

### 什么是 DFS 的三色标记

用三种颜色管理 DFS 中每个节点状态的方法。白色(0)表示未访问，灰色(1)表示在当前探索路径上（存在于递归栈中），黑色(2)表示探索完成。如果再次到达灰色节点，则确认存在环。

```java
Map<Character, Integer> color = new HashMap<>();
color.put('a', 0);  // 白色: 未访问
color.put('a', 1);  // 灰色: 探索中（在递归栈上）
color.put('a', 2);  // 黑色: 探索完成（所有后代已处理）
```

### HashMap 和 HashSet 的基本操作

```java
// HashMap: 保存键值对。查找和获取的时间复杂度为 O(1)
Map<Character, Set<Character>> adj = new HashMap<>();
adj.putIfAbsent('a', new HashSet<>());  // 仅当键未注册时才注册空的 Set
adj.get('a').add('b');                  // 将 'b' 添加到键 'a' 的邻接列表中

// HashSet: 不含重复元素的集合。添加和查找的时间复杂度为 O(1)
Set<Character> set = new HashSet<>();
set.add('b');        // 添加元素
set.contains('b');   // 判断元素是否存在 → true
```

### startsWith 方法

判断字符串是否以指定的前缀开头。

```java
"abc".startsWith("ab");  // true — "abc" 以 "ab" 开头
"ab".startsWith("abc");  // false — "ab" 不以 "abc" 开头
```

## 计算复杂度

| | 值 |
|---|---|
| Time | O(C) — C 为所有单词的总字符数。构建图需要遍历所有字符，DFS 与节点数加边数成正比，但两者均不超过 C |
| Space | O(1) — 节点数最多为 26 个字符（英文小写字母），为常数。边数最多为 26²，也为常数。不依赖于输入规模 |

## 代码

```java
// 输入: 按外星语言字典序排列的字符串数组 words
// 输出: 表示字母顺序的字符串。如果存在矛盾则返回空字符串 ""

// DFS: 通过三色标记检测环，同时记录后序遍历顺序
boolean dfs(char c, Map<Character, Set<Character>> adj,
            Map<Character, Integer> color, List<Character> result) {
    // 再次到达灰色（探索中）节点 → 检测到环
    if (color.get(c) == 1) return false;
    // 黑色（已探索）→ 已处理完成，跳过
    if (color.get(c) == 2) return true;

    // 将当前节点标记为灰色（探索中）
    color.put(c, 1);

    // 对所有邻接节点（排在该字符之后的字符）递归执行 DFS
    for (char n : adj.get(c))
        if (!dfs(n, adj, color, result))
            return false;  // 在后代中检测到环 → 立即传播

    // 所有后代的探索已完成，标记为黑色
    color.put(c, 2);
    // 按后序遍历顺序添加到列表中（在 DFS 中依赖目标先被添加，因此反转后即为拓扑顺序）
    result.add(c);
    return true;
}

public String alienOrder(String[] words) {
    // 邻接列表: 键=字符，值=排在该字符之后的字符集合
    Map<Character, Set<Character>> adj = new HashMap<>();

    // 将所有单词中的所有字符注册为图的节点
    // 由于没有顺序关系（边）的字符也需要包含在结果中，因此在此时注册所有字符
    for (String w : words)
        for (char c : w.toCharArray())
            adj.putIfAbsent(c, new HashSet<>());

    // 比较相邻的两个单词，提取顺序关系（有向边）
    for (int i = 0; i < words.length - 1; i++) {
        String w1 = words[i];
        String w2 = words[i + 1];

        // 无效输入检测: 较长的单词排在较短前缀之前的情况（例如: ["abc","ab"] 存在矛盾）
        if (w1.length() > w2.length() && w1.startsWith(w2))
            return "";

        int len = Math.min(w1.length(), w2.length());
        for (int j = 0; j < len; j++) {
            if (w1.charAt(j) != w2.charAt(j)) {
                // 从第一个不同的字符获得一个顺序关系，然后立即跳出循环
                // 第二个及之后的差异只有在前面的字符相同时才有意义，因此只提取一个
                adj.get(w1.charAt(j)).add(w2.charAt(j));
                break;
            }
        }
    }

    // 创建三色管理映射，将所有节点初始化为白色(0: 未访问)
    Map<Character, Integer> color = new HashMap<>();
    for (char c : adj.keySet())
        color.put(c, 0);

    // 记录 DFS 后序遍历顺序的列表
    List<Character> result = new ArrayList<>();

    // 对所有节点执行 DFS（为了处理非连通图，以所有节点为起点）
    for (char c : adj.keySet())
        if (!dfs(c, adj, color, result))
            return "";  // 检测到环 → 顺序无法确定

    // 反转后序遍历顺序以获得拓扑顺序
    Collections.reverse(result);

    // 连接所有字符，构建结果字符串
    StringBuilder sb = new StringBuilder();
    for (char c : result) sb.append(c);
    return sb.toString();
}
```
