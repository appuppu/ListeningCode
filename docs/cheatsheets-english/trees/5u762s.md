# Inverting a Binary Tree — Swap the Left and Right Children of Every Node in a Binary Tree

## Problem

You are given the root node `root` of a binary tree. Swap (invert) the left child and right child of **every node** in the tree, and return the root node of the inverted tree.

## Key Insight

Inverting a binary tree is an operation that swaps the left and right children of every node. If you visit every node in level order using BFS and swap the left and right children at each node, the entire tree becomes inverted.

## Thought Process

1. **Understand the definition of inversion**: Inverting a binary tree is an operation that swaps the left child and right child not only at the root node but at every node. In other words, you visit every node in the tree exactly once and perform a swap operation at each node
2. **Choose a method to visit every node**: Use BFS (Breadth-First Search) to visit every node in the tree. BFS processes nodes in level order using a queue, making the implementation intuitive and straightforward
3. **Determine the operation at each node**: For each node dequeued from the queue, swap `left` and `right` using a temporary variable. The order of the swap does not matter, and the swap works correctly even when a child is null
4. **Add child nodes to the queue**: After the swap, add the left and right children to the queue if they are not null. This ensures that the algorithm progressively visits nodes in the lower levels of the tree and executes the swap on every node
5. **Determine what to return**: After all nodes have been swapped, return the original root node `root` as-is. The structure of the tree changes, but the root node itself remains the same object

## Prerequisites

### Binary Tree

A tree structure in which each node has at most two children: a left child `left` and a right child `right`. Each node is represented by a `TreeNode` class, which has the fields `val` (value), `left` (left child), and `right` (right child).

```java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

### Queue

A first-in, first-out (FIFO) data structure. The element added first is the element removed first. In BFS, a queue manages the nodes that need to be visited.

```java
Queue<TreeNode> queue = new LinkedList<>();  // Create an empty queue
queue.add(node);     // Add node to the end of the queue
queue.poll();        // Remove and return the element at the front of the queue
queue.isEmpty();     // Return a boolean indicating whether the queue is empty → true/false
```

### BFS (Breadth-First Search)

An algorithm that traverses a tree or graph in level order. It uses a queue: after processing the current node, it adds the node's children to the queue, thereby visiting all nodes from the shallowest level to the deepest.

## Complexity

| | Value |
|---|---|
| Time | O(n) — The algorithm visits every node in the tree exactly once |
| Space | O(n) — The queue stores at most n nodes |

## Code

```java
// Input: the root node root of a binary tree
// Output: return the root node root after swapping the left and right children of every node
public TreeNode invertTree(TreeNode root) {
    // If the tree is empty, return null. There is no tree to process, so terminate immediately
    if (root == null) return null;

    // Create a queue for BFS and add the root node
    // This queue manages the nodes whose left and right children need to be swapped
    Queue<TreeNode> queue = new LinkedList<>();
    queue.add(root);

    // Repeat until the queue is empty (i.e., until every node has been processed)
    while (!queue.isEmpty()) {
        // Dequeue the node at the front of the queue as the swap target
        TreeNode curr = queue.poll();

        // Swap the left and right children using a temporary variable
        // Note: assigning directly without a temporary variable would overwrite and lose one reference
        TreeNode temp = curr.left;
        curr.left = curr.right;
        curr.right = temp;

        // Add the children to the queue if they are not null after the swap
        // Null nodes have no children to process, so there is no need to add them
        if (curr.left != null) queue.add(curr.left);
        if (curr.right != null) queue.add(curr.right);
    }

    // Return the root node after all nodes have been swapped
    // The structure of the tree has changed, but the root node itself is the same object
    return root;
}
```
