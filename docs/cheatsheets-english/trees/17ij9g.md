# Finding the Maximum Depth of a Binary Tree — Find the Number of Nodes on the Deepest Path in a Binary Tree

## Problem

The system gives you the `root` node of a binary tree. You return the **number of nodes** (maximum depth) on the path from the root node to the farthest leaf node as an integer. You return 0 for an empty tree (root is null).

## Key Insight

The maximum depth of a tree equals the larger of the "maximum depth of the left subtree" and the "maximum depth of the right subtree" plus 1 (for the current node). This recursive definition directly becomes the solution.

## Thought Process

1. **You can define tree depth recursively**: The depth of a given node depends on the depth of the subtrees rooted at its left and right children. This means you can decompose the problem into smaller subproblems of the same structure.
2. **You determine the base case**: When a node is null, nothing exists there, so the depth is 0. This condition serves as the termination condition for the recursion.
3. **You find the depth of each subtree**: You recurse from the current node to its left child and obtain the maximum depth of the left subtree. Similarly, you recurse to the right child and obtain the maximum depth of the right subtree.
4. **You combine the results from both subtrees**: Since the maximum depth represents the longest path, you select the larger of the left and right depths. You obtain this value using `Math.max(left, right)`.
5. **You add the current node and return**: You add 1 to the maximum of the left and right depths and return the depth including the current node to its parent. This 1 counts the current node itself.

## Prerequisites

### TreeNode (Binary Tree Node)

A TreeNode is a class that represents each node in a binary tree. It has three fields: a value `val`, a left child `left`, and a right child `right`. A field contains null when the corresponding child does not exist.

```java
public class TreeNode {
    int val;              // Value held by the node
    TreeNode left;        // Left child node (null if absent)
    TreeNode right;       // Right child node (null if absent)
}
```

### Recursion

Recursion is a technique where a function calls itself. In tree structures, you use recursion to apply the same operation to subtrees for each node. You must always define a base case (a condition that stops the recursion) to prevent infinite loops.

```java
// Basic structure of recursion
public int recursive(TreeNode node) {
    if (node == null) return 0;           // Base case: termination condition for recursion
    return recursive(node.left);          // Recursive call: solve the subproblem
}
```

### Math.max

Math.max is a standard Java method that returns the larger of two integers.

```java
Math.max(3, 5);    // → 5
Math.max(0, 0);    // → 0
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — The algorithm visits every node exactly once |
| Space | O(h) — The recursion call stack grows to the height of the tree. In the worst case (a skewed tree), the space complexity becomes O(n) |

## Code

```java
// Input: root node of a binary tree (TreeNode type, may be null)
// Output: returns an integer representing the maximum depth of the tree
public int maxDepth(TreeNode root) {
    // Base case: if the node does not exist, the depth is 0
    // The recursion stops when it reaches a child of a leaf node (null)
    if (root == null) return 0;

    // Recursively find the maximum depth of the left subtree
    // The method repeats the same operation on the subtree rooted at the left child until it reaches the base case and returns a value
    int left = maxDepth(root.left);

    // Recursively find the maximum depth of the right subtree
    // Same as the left side, the method finds the depth of the subtree rooted at the right child
    int right = maxDepth(root.right);

    // Add 1 for the current node to the deeper subtree and return the result
    // Math.max(left, right) selects the deeper subtree, which represents the number of nodes on the longest path
    // +1 counts the current node root itself. The parent node receives this return value and uses it in its own calculation
    return 1 + Math.max(left, right);
}
```
