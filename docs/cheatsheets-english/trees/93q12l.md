# Validating a Binary Search Tree — Determine Whether a Binary Tree Is a Valid BST

## Problem

You are given the `root` of a binary tree. Determine whether the tree is a valid binary search tree (BST). A valid BST means that for every node, all values in its left subtree are **strictly less than** the node's value, and all values in its right subtree are **strictly greater than** the node's value.

## Key Insight

Each node has a valid range of values it can take. By recursively traversing from the root and narrowing the upper bound for left children and the lower bound for right children, you can determine whether all nodes satisfy the BST property in a single traversal.

## Thought Process

1. **Checking only direct parent-child relationships is insufficient**: A node being greater than its left child and less than its right child does not guarantee the BST property. All nodes in the left subtree must be less than that node. This means each node inherits constraints from its ancestors.
2. **Define a valid range for each node**: The root can take any value, so the range starts at `(-∞, +∞)`. When moving to a left child, the upper bound narrows to the parent's value. When moving to a right child, the lower bound narrows to the parent's value. You pass this range as arguments to the recursive function.
3. **Determine the validation condition**: At each node, check whether `node.val` falls within the range `(lo, hi)`. Since a BST uses strict inequalities, the node is invalid if `node.val <= lo` or `node.val >= hi`.
4. **Define the recursive structure**: The base case returns `true` when `node == null` (an empty tree is a valid BST). At each node, validate its own value, then recursively call on the left and right children with narrowed ranges. Return `true` only when both left and right subtrees return `true`.
5. **Use long for the range type**: When a node's value equals `Integer.MIN_VALUE` or `Integer.MAX_VALUE`, the int type cannot represent the initial bounds. Using `Long.MIN_VALUE` and `Long.MAX_VALUE` as initial bounds allows correct validation of all int values.
6. **Determine the final return value**: Start the recursion from the root. Return `true` if all nodes fall within their valid ranges, and return `false` if any node violates its range.

## Prerequisites

### Binary Search Tree (BST)

A binary search tree is a binary tree where, for each node, all values in the left subtree are less than the node's value, and all values in the right subtree are greater than the node's value. This property applies to the entire subtree, not just the direct children.

```
      5
     / \
    3   7     ← Valid BST: 3<5, 7>5, 1<3, 4>3 and 4<5, 6>5 and 6<7
   / \   \
  1   4   8
```

### Narrowing the Range Through Recursion

When traversing from a parent to a child, the valid range of values narrows:

```
Node 5: range(-∞, +∞)
├─ Left child 3: range(-∞, 5)  ← Upper bound narrows to parent's value 5
│  ├─ Left child 1: range(-∞, 3)
│  └─ Right child 4: range(3, 5)  ← Lower bound 3 and upper bound 5
└─ Right child 7: range(5, +∞)  ← Lower bound narrows to parent's value 5
```

### Why Use long Type

Java's `int` ranges from `-2147483648` to `2147483647`. To express an initial range that "permits any int value," you need values that exceed the int range. Using `long` type allows you to set a sufficiently wide initial range with `Long.MIN_VALUE` and `Long.MAX_VALUE`.

```java
long lo = Long.MIN_VALUE;  // Smaller than any int value
long hi = Long.MAX_VALUE;  // Larger than any int value
node.val <= lo;            // node.val is int, so it is guaranteed to be greater than Long.MIN_VALUE
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — The algorithm visits each node exactly once |
| Space | O(h) — The recursion call stack depth is proportional to the tree height h (worst case O(n), balanced case O(log n)) |

## Code

```java
// Input: root node of a binary tree
// Output: true if the tree is a valid BST, false otherwise
public boolean isValidBST(TreeNode root) {
    // Set initial range to Long.MIN_VALUE/MAX_VALUE so that the root node accepts any int value
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

// lo and hi are long type because int type cannot use Integer.MIN_VALUE/MAX_VALUE as initial bounds
boolean validate(TreeNode node, long lo, long hi) {
    // Base case: a null node does not violate BST properties
    if (node == null) return true;

    // If the current node's value is outside the valid range (lo, hi), it is invalid
    // BST does not allow equal values, so use <= and >= for strict comparison
    if (node.val <= lo || node.val >= hi) return false;

    // Left subtree: narrow upper bound to node.val (all left values must be less than node.val). Maintain lo from ancestor constraints
    // Right subtree: narrow lower bound to node.val (all right values must be greater than node.val). Maintain hi from ancestor constraints
    // The entire subtree is a valid BST only when both left and right return true
    return validate(node.left, lo, node.val)
        && validate(node.right, node.val, hi);
}
```
