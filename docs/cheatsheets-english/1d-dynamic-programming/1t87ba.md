# Maximizing Robbery Loot Without Adjacent Houses — Find the Maximum Amount You Can Rob Without Robbing Adjacent Houses

## Problem

You are given an integer array `nums`, where each element represents the amount of money in each house along a street. You must return the **maximum amount of money** you can rob in one night, subject to the constraint that you cannot rob two adjacent houses. If you rob house `i`, you cannot rob house `i-1` or house `i+1`.

## Key Insight

For each house, you have two choices: "rob" or "skip." If you rob the current house, you add the current amount to the maximum value up to two houses before. If you skip the current house, you carry forward the maximum value up to the previous house. Since this decision requires only the two most recent values, you can compute the result using just two variables instead of maintaining an array.

## Thought Process

1. **You need to make an optimal "rob or skip" decision at each house**: If you rob house `i`, you cannot rob house `i-1`, so you gain the maximum value up to house `i-2` plus `nums[i]`. If you skip house `i`, the maximum value up to house `i-1` carries over as is. This means the maximum value at each house can be expressed as `max(max value up to house i-1, max value up to house i-2 + nums[i])`.
2. **You can formulate a recurrence relation**: The recurrence `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` computes the maximum amount up to each house from left to right. This is a classic dynamic programming structure.
3. **You only need the two most recent values**: Looking at the recurrence, computing `dp[i]` requires only `dp[i-1]` and `dp[i-2]`. You do not need to maintain the entire array; two variables (`prev1` and `prev2`) are sufficient.
4. **You must consider the update order of the variables**: After computing `curr`, the current `prev1` becomes the new `prev2` in the next iteration, and `curr` becomes the new `prev1`. Updating in this order prevents values from being overwritten prematurely.
5. **You initialize the variables to zero**: Before the traversal begins, you set `prev1 = 0` (maximum value up to the previous house) and `prev2 = 0` (maximum value up to two houses before). When there are zero houses the result is 0, and for the first house the computation yields `max(0, 0 + nums[0]) = nums[0]`, which is correct.
6. **You return the final result**: After traversing all houses, `prev1` holds the maximum amount across all houses.

## Prerequisites

### Dynamic Programming

Dynamic programming is a technique that breaks a large problem into smaller subproblems and reuses the solutions to those subproblems to build the overall solution. When overlapping subproblems exist, this technique avoids redundant computation. In this problem, "the maximum amount up to house `i`" constitutes each subproblem.

### Math.max

`Math.max` is a standard Java method that returns the larger of two values. It expresses a conditional branch in a single line.

```java
Math.max(5, 3);    // → 5 (returns the larger value)
Math.max(prev1, prev2 + num);  // returns the larger of prev1 and prev2 + num
```

### Enhanced for Loop (for-each)

The enhanced for loop is a loop construct that retrieves each element of an array one by one from beginning to end. It accesses elements directly without using an index.

```java
int[] nums = {2, 7, 9, 3};
for (int num : nums) {   // assigns each element of nums to num in order
    System.out.println(num);  // outputs 2, 7, 9, 3 in order
}
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — You only need to traverse the array once |
| Space | O(1) — You use only two variables, independent of the input size |

## Code

```java
// Input: integer array nums (amount of money in each house)
// Output: returns the maximum amount you can rob as an int, subject to the constraint of not robbing adjacent houses
public int rob(int[] nums) {
    // prev2: maximum amount up to two houses before. It is 0 before traversal because no houses exist yet
    int prev2 = 0;
    // prev1: maximum amount up to the previous house. Similarly 0 before traversal
    int prev1 = 0;

    // Traverse the array nums from beginning to end, one element at a time, using an enhanced for loop
    for (int num : nums) {
        // Choose the larger of "skip the current house (prev1)" and "rob the current house (prev2 + num)"
        // When robbing the current house, you use prev2 because you cannot rob the adjacent house at prev1
        int curr = Math.max(prev1,
            prev2 + num);
        // Slide the variables forward for the next iteration
        // The current prev1 (previous max) becomes the two-houses-before max in the next iteration
        prev2 = prev1;
        // The just-computed curr (max up to the current house) becomes the previous max in the next iteration
        // Note: this update must happen after prev2 = prev1. Updating prev1 first would prevent assigning the correct value to prev2
        prev1 = curr;
    }
    // Return the maximum amount considering all houses. prev1 holds the maximum amount up to the last house
    return prev1;
}
```
