# Partitioning an Array Into Two Equal Sum Subsets — Determine Whether an Array Can Be Partitioned Into Two Subsets With Equal Sums

## Problem

You are given an integer array `nums`. You must determine whether you can partition the array into two subsets such that the sum of elements in each subset is equal, and return the result as a `boolean`. Each element must belong to exactly one of the two subsets and cannot be used more than once.

## Key Insight

If the total sum of the array is odd, you can immediately return false. If the total sum is even, the problem reduces to a "subset sum problem": determining whether a subset exists whose elements sum to exactly half of the total, called `target`. By using a one-dimensional boolean DP array and processing each element in sequence while recording all reachable sums, you can determine whether `target` is reachable in O(n × target) time.

## Thought Process

1. **Consider the condition for equal partitioning**: When the total sum of the array is `sum`, each subset must have a sum of `sum / 2` for the two subsets to be equal. If `sum` is odd, you cannot divide it into two equal integers, so you can immediately return false.
2. **Convert the problem into a subset sum problem**: If one subset sums to `target = sum / 2`, the other subset automatically sums to `target` as well. This means the problem reduces to "does a subset of the array exist whose elements sum to `target`?"
3. **Use DP to track reachable sums**: Prepare a boolean array `dp` where `dp[j]` represents "whether you can form the sum `j` from the elements processed so far." Set the initial state as `dp[0] = true` (selecting nothing yields a sum of 0).
4. **Update reachable sums for each element**: For each element `num` in the array, if a sum `j` is already reachable, then `j + num` also becomes reachable. This operation sets `dp[j + num]` to true whenever `dp[j]` is true.
5. **Iterate in reverse order to prevent reusing elements**: Iterate the inner loop in reverse from `target` down to `num`. If you iterate forward, the DP array gets updated using results that already counted the same element multiple times. Iterating in reverse guarantees that each element is used at most once.
6. **Return `dp[target]` as the final answer**: After processing all elements, if `dp[target]` is true, a subset with sum `target` exists, so you return true. If it is false, no such subset exists.

## Prerequisites

### What Is the Subset Sum Problem?

The subset sum problem asks whether you can select some elements from a given set of integers such that their sum equals exactly a target value. It is a classic problem that can be solved efficiently using DP (dynamic programming).

### What Is a One-Dimensional Boolean DP Array?

A one-dimensional boolean DP array is an array where `dp[j]` represents whether it is possible to form the sum `j`, using true or false. As you process elements one by one, the set of reachable sums expands.

```java
boolean[] dp = new boolean[target + 1];  // Create an array of size target+1 (all values initialized to false)
dp[0] = true;                            // Selecting nothing means a sum of 0 is always reachable
dp[j - num] == true                      // If you can form the sum j-num, then adding num makes the sum j also reachable
```

### Why You Must Update the DP Array in Reverse Order

If you update in the forward direction (from small `j` to large `j`), the result of using the same element `num` multiple times propagates through the array. Updating in the reverse direction (from large `j` to small `j`) guarantees that each element is used exactly once.

```java
// Reverse loop: j decreases by 1 from target down to num
for (int j = target; j >= num; j--) {
    if (dp[j - num]) dp[j] = true;
}
```

## Complexity

| | Value |
|---|---|
| Time | O(n × target) — For each of the n elements, the algorithm scans the DP array up to index target |
| Space | O(target) — The algorithm uses a single boolean DP array of size target+1 |

## Code

```java
// Input: integer array nums
// Output: boolean indicating whether the array can be partitioned into two subsets with equal sums
boolean canPartition(int[] nums) {
    // Calculate the total sum of all elements to determine whether equal partitioning is possible
    int sum = 0;
    for (int n : nums) sum += n;

    // If the total sum is odd, it cannot be divided into two equal integers, so return false
    if (sum % 2 != 0) return false;

    // The target sum that one subset must achieve; the other subset will automatically equal target
    int target = sum / 2;

    // dp[j] = whether the sum j can be formed from elements processed so far (subset sum DP array)
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;  // Selecting nothing means a sum of 0 is always reachable

    // Process each element in the array from first to last, updating the set of reachable sums
    for (int num : nums) {
        // Iterate in reverse to prevent reusing the same element (forward iteration would propagate multiple additions of num)
        for (int j = target; j >= num; j--) {
            // If the sum j-num is reachable, then adding num makes the sum j also reachable, so set it to true
            if (dp[j - num]) dp[j] = true;
        }
    }

    // If dp[target] is true, a subset with sum target exists, so the array can be partitioned into two equal halves
    return dp[target];
}
```
