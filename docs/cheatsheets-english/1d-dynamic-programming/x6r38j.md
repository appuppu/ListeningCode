# Counting Ways to Climb Stairs — Find the total number of ways to climb n stairs by taking 1 or 2 steps at a time

## Problem

You are given an integer `n` (the number of stairs). You can climb either 1 or 2 steps at a time. Return the **total number of distinct ways** to reach the top (the nth stair).

## Key Insight

To reach the nth stair, you can only come from "the (n-1)th stair by climbing 1 step" or "the (n-2)th stair by climbing 2 steps." This means the recurrence `ways(n) = ways(n-1) + ways(n-2)` holds, which is the same as the Fibonacci sequence. By keeping only the two most recent values, you can compute the result in O(1) space without using an array.

## Thought Process

1. **Work backwards from the last step**: The state right before reaching the nth stair is either "being on the (n-1)th stair" or "being on the (n-2)th stair." Therefore, the total number of ways to reach the nth stair can be expressed by the recurrence `ways(n) = ways(n-1) + ways(n-2)`
2. **Define the base cases**: A staircase with 1 stair has 1 way (climb 1 step), and a staircase with 2 stairs has 2 ways (1+1 or 2). These two values serve as the starting point for the recurrence
3. **Compute bottom-up**: Computing top-down with recursion solves the same subproblems multiple times. Instead, adopting a bottom-up approach that computes from smaller values in order requires calculating each value only once
4. **You only need two variables**: The recurrence `ways(i) = ways(i-1) + ways(i-2)` references only the two preceding values. You do not need to maintain an entire array — two variables (`prev2` and `prev1`) are sufficient
5. **Update the variables in a loop**: From `i = 3` to `n`, compute the current value as `curr = prev1 + prev2`, then slide the variables by setting `prev2 = prev1` and `prev1 = curr` to prepare for the next iteration
6. **Return the final result**: After the loop finishes, `prev1` holds the total number of ways to reach the nth stair, so you return `prev1`

## Prerequisites

### Dynamic Programming

Dynamic programming is a technique that breaks a large problem into smaller subproblems and solves them while recording the result of each subproblem. It achieves efficiency by never repeating the same computation. In the bottom-up approach, you solve subproblems starting from the smallest one.

```java
// Basic pattern of bottom-up DP (array version)
int[] dp = new int[n + 1];   // Array to store subproblem results
dp[1] = 1;                    // Base case 1
dp[2] = 2;                    // Base case 2
for (int i = 3; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];  // Compute using the recurrence
}
// dp[n] is the final answer
```

### Sliding Variables

Sliding variables is a technique that keeps only the two most recent values using variables instead of an array. When the recurrence references a fixed number of past values, you do not need to maintain the entire array, and you can reduce the space complexity from O(n) to O(1).

```java
int prev2 = 1;  // Variable holding the value from 2 steps back
int prev1 = 2;  // Variable holding the value from 1 step back
int curr = prev1 + prev2;  // Compute the current value
prev2 = prev1;  // Slide prev2 forward (inherit the value of prev1)
prev1 = curr;   // Slide prev1 forward (inherit the value of curr)
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — You only need a single loop from 3 to n |
| Space | O(1) — You use only two variables (prev2, prev1) |

## Code

```java
// Input: integer n (the number of stairs)
// Output: return the total number of distinct ways to reach the top as an int
public int climbStairs(int n) {
    // Base case: if there is only 1 stair, there is only 1 way. Handle n=1 first since the loop starts at i=3
    if (n == 1) return 1;

    // prev2 is the total number of ways for the stair 2 steps back. The initial value corresponds to the 1st stair (1 way)
    int prev2 = 1;
    // prev1 is the total number of ways for the stair 1 step back. The initial value corresponds to the 2nd stair (2 ways: 1+1 or 2)
    int prev1 = 2;

    // i is the stair number currently being computed. Since the 1st and 2nd stairs are already initialized, start from the 3rd stair
    for (int i = 3; i <= n; i++) {
        // Recurrence: ways to reach stair i = ways to reach stair (i-1) + ways to reach stair (i-2)
        int curr = prev1 + prev2;
        // Note: update prev2 before prev1, otherwise the original value of prev1 is lost
        prev2 = prev1;
        prev1 = curr;
    }

    // After the loop finishes, prev1 holds the total number of ways to reach the nth stair
    return prev1;
}
```
