# Maximizing Robbery Loot in a Circular Neighborhood — Steal the Maximum Amount from Circularly Arranged Houses Without Robbing Adjacent Ones

## Problem

The system gives you an array `nums` of non-negative integers. Each element represents the amount of money in a house arranged in a circle. You cannot rob two adjacent houses consecutively. You must return the maximum amount you can rob under the constraint that **the first house and the last house are also adjacent**.

## Key Insight

The circular constraint reduces to "you cannot select both the first house and the last house simultaneously." You split the problem into two ranges — "include the first house and exclude the last" and "include the last house and exclude the first" — solve the linear House Robber for each range, and take the larger result to satisfy the circular constraint.

## Thought Process

1. **Decompose the circular constraint**: In a circular array, `nums[0]` and `nums[n-1]` are adjacent. This means you cannot select both simultaneously. You can decompose this into two cases: "if you select `nums[0]`, you cannot select `nums[n-1]`" and "if you select `nums[n-1]`, you cannot select `nums[0]`"
2. **Reduce to two linear problems**: Case 1 solves the linear House Robber on `nums[0..n-2]` (include first, exclude last). Case 2 solves it on `nums[1..n-1]` (exclude first, include last). The larger of the two results is the answer
3. **Formulate the linear recurrence**: For each house `i`, you have two choices: "rob house `i`" or "skip house `i`." If you rob it, the value is `nums[i] + dp[i-2]` (skip the previous one). If you skip it, the value is `dp[i-1]` (carry forward the maximum up to the previous house). Therefore `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
4. **Reduce space to constant**: The recurrence references only `dp[i-1]` and `dp[i-2]`. You do not need to maintain the entire DP array — two variables `prev1` (maximum at one step back) and `prev2` (maximum at two steps back) suffice
5. **Handle edge cases**: If the array is empty, return 0. If the array has only one element, the circular constraint does not apply, so return that value. Perform the two-pass processing only when the array has two or more elements
6. **Return the final answer**: Select the larger of the two maximum amounts obtained from each range using `Math.max`

## Prerequisites

### What Is House Robber (Linear Version)

The linear House Robber problem asks you to select houses from a line without choosing adjacent ones and maximize the total amount. It is a fundamental DP problem that you solve with the recurrence `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`. The circular version solves the linear version twice.

### DP Space Optimization with Rolling Variables

This technique keeps only the few most recent values that the recurrence references as variables instead of maintaining the entire DP array. This eliminates the need to store the full array and reduces space complexity from O(n) to O(1).

```java
int prev2 = 0, prev1 = 0;        // Initialize variables corresponding to dp[i-2] and dp[i-1]
int curr = Math.max(prev1, prev2 + nums[i]);  // Compute dp[i]
prev2 = prev1;                    // Advance prev2 by one step (old prev1 becomes new prev2)
prev1 = curr;                     // Advance prev1 by one step (curr becomes new prev1)
```

### What Is Math.max

`Math.max` is a standard Java method that returns the larger of two values. You use it in the DP transition to select the maximum between "rob the current house" and "skip the current house."

```java
Math.max(5, 3);   // → 5 (returns the larger value)
Math.max(prev1, prev2 + nums[i]);  // Select the maximum between skipping and robbing
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — The algorithm scans the array twice, but each scan is O(n), so the total is O(n) |
| Space | O(1) — The algorithm uses no DP array and computes with only two rolling variables |

## Code

```java
// Input: an array nums of non-negative integers (amount in each circularly arranged house)
// Output: return the maximum amount you can rob as int without robbing adjacent houses

// Helper method that solves the linear House Robber for the specified range (start to end)
private int robRange(int[] nums, int start, int end) {
    // Initialize to 0 because the amount when robbing no house is 0
    int prev2 = 0, prev1 = 0;  // Rolling variables holding the max amount from two steps back and one step back
    // Iterate from the start to the end of the specified range one by one
    for (int i = start; i <= end; i++) {
        // prev1: the option to skip house i and carry forward the max up to the previous house
        // prev2 + nums[i]: the option to rob house i and add current amount to the max from two steps back
        int curr = Math.max(prev1,
            prev2 + nums[i]);
        // Advance rolling variables by one step (in the next iteration, curr serves as prev1 and prev1 serves as prev2)
        prev2 = prev1;
        prev1 = curr;
    }
    // prev1 holds the maximum amount considering the entire specified range
    return prev1;
}

public int rob(int[] nums) {
    int n = nums.length;
    if (n == 0) return 0;        // If there are no houses, return 0
    if (n == 1) return nums[0];  // If there is only one house, the adjacency constraint does not apply, so its value is the answer

    // Decompose the circular constraint into two linear problems and return the larger result
    // This guarantees that the first and last houses are never selected simultaneously, satisfying the circular constraint
    return Math.max(
        robRange(nums, 0, n - 2),   // Range including the first house and excluding the last (index 0 to n-2)
        robRange(nums, 1, n - 1));  // Range excluding the first house and including the last (index 1 to n-1)
}
```
