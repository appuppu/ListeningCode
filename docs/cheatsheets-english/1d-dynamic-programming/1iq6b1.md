# Finding the Subarray With Maximum Product

## Problem

You are given an integer array `nums`. Find a **contiguous subarray** within the array whose product of elements is the largest, and return that **product**. A subarray consists of one or more consecutive elements.

## Key Insight

Multiplying two negative numbers produces a positive number, so the current minimum product (the largest negative number) can become the maximum product when multiplied by the next negative number. Therefore, you need to track both the "current maximum product" and the "current minimum product" at each position.

## Thought Process

1. **Consider the properties of subarray products**: In a problem that asks for the product of a contiguous subarray, each time you add one element, you can compute the new product as "previous subarray's product × current element." This follows the same idea as DP, where you derive the next state from the previous state.
2. **Negative numbers complicate the maximum product calculation**: If there were only positive numbers, you would only need to track the maximum product. However, with negative numbers, "a large negative product × a negative number = a large positive product" can occur. This means if you do not also track the current minimum product (the value most negative), you may miss the true maximum product.
3. **There are exactly three candidates at each position**: The candidates for the maximum product at position `i` are: (a) `nums[i]` alone (starting a new subarray), (b) `curMax * nums[i]` (extending the positive maximum product), and (c) `curMin * nums[i]` (the negative minimum product flipping sign with a negative number). The largest of these three values becomes the new `curMax`.
4. **The minimum product is chosen from the same three candidates**: The candidates for the minimum product are the same three values, and the smallest among them becomes the new `curMin`. By updating both the maximum and minimum simultaneously, you correctly capture sign flips caused by negative numbers.
5. **Save the previous value before updating**: If you update `curMax` first and then compute `curMin`, the pre-update value of `curMax` is no longer available for the `curMin` calculation. Therefore, you save `curMax` to a temporary variable `temp` before updating it, and use `temp` when computing `curMin`.
6. **Track the global maximum in a separate variable**: `curMax` represents the maximum product ending at the current position, not the overall maximum product. At each position, you update the overall maximum with `result = Math.max(result, curMax)`, and return `result` at the end.

## Prerequisites

### Relationship Between Subarray Products and DP

You can extend the product of a subarray by multiplying the product up to the previous position by the current element. Using this property, you can compute the "maximum product of a subarray ending here" in O(1) from the result at the previous position. This technique retains the previous state and derives the next state, just like DP.

### What Are Math.max / Math.min

These are Java methods that return the maximum or minimum value among multiple values. To compare three or more values, you nest the calls.

```java
Math.max(3, 7);                   // Returns the maximum of two values → 7
Math.min(3, 7);                   // Returns the minimum of two values → 3
Math.max(a, Math.max(b, c));      // Returns the maximum of three values
Math.min(a, Math.min(b, c));      // Returns the minimum of three values
```

### Why Tracking the Minimum Value Is Necessary

In an array containing negative numbers, the sign of the product flips with each such element. Example: for `[-2, 3, -4]`, the minimum product at position 1 is `-2 × 3 = -6`, but at position 2 it becomes `-6 × -4 = 24`, which is the maximum product. If you track only the maximum product, you discard `-6` and miss `24`.

## Complexity

| | Value |
|---|---|
| Time | O(n) — You only need a single pass through the array |
| Space | O(1) — You use only a fixed number of variables, independent of the input size |

## Code

```java
// Input: integer array nums (length >= 1)
// Output: return the maximum product of a contiguous subarray as an int
public int maxProduct(int[] nums) {
    // result = global maximum product, curMax = maximum product of subarray ending at current position, curMin = same for minimum
    // The initial state is the subarray consisting of only the first element
    int result = nums[0];
    int curMax = nums[0];
    int curMin = nums[0];

    // i=0 is already handled by initialization, so start from i=1
    for (int i = 1; i < nums.length; i++) {
        int n = nums[i];
        // Save curMax before updating (the pre-update value is needed for computing curMin)
        int temp = curMax;

        // Choose the maximum from three candidates:
        // n alone → start a new subarray
        // temp * n → extend the previous maximum product
        // curMin * n → the previous minimum product (negative) flips sign with a negative n to become the maximum
        curMax = Math.max(n,
            Math.max(temp * n, curMin * n));

        // Choose the minimum from the same three candidates (using temp for the pre-update curMax ensures this calculation is unaffected by the update above)
        curMin = Math.min(n,
            Math.min(temp * n, curMin * n));

        // curMax is the maximum product at the current position, not the overall maximum, so track the overall maximum in a separate variable result
        result = Math.max(result, curMax);
    }
    // result now holds the maximum subarray product across the entire array
    return result;
}
```
