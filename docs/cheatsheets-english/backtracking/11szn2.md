# Finding Combinations That Sum to a Target

## Problem

You are given an array of distinct positive integers `candidates` and a positive integer `target`. Find and return all unique combinations from `candidates` that sum to `target`. You may reuse the same number **unlimited times**. Two combinations that differ only in order are considered duplicates.

## Key Insight

If you sort the candidates, then at each level of recursion, once the current candidate exceeds the remaining target, all subsequent candidates also exceed it. This allows you to prune entire branches of the search tree at once. This pruning makes it possible to enumerate all valid combinations efficiently.

## Thought Process

1. **Backtracking is well suited for enumerating all combinations**: Problems that ask "find all patterns satisfying a condition" can be solved with a recursive exploration (backtracking) that picks candidates one by one and backtracks when a choice fails.
2. **Controlling the start index prevents duplicates**: You may reuse the same number any number of times, but you must not count `[2,3]` and `[3,2]` as separate combinations. By only choosing candidates at or after the current index at each recursion level, you generate only non-decreasing combinations, which eliminates duplicates.
3. **Tracking the remaining target (`remain`) manages progress**: You subtract each chosen number from `target`. When `remain` reaches 0, the current combination sums to `target`. When `remain` becomes negative, the sum has exceeded `target`.
4. **Sorting enables pruning**: When the candidates are sorted in ascending order, if a candidate `cands[i]` exceeds `remain`, then every candidate from `cands[i+1]` onward is even larger and does not need to be tried. You can break out of the for-loop immediately.
5. **A list manages the current combination through repeated add and remove operations**: You append an element to the end of the list, recurse, and then remove the last element upon return. This "add → recurse → remove" pattern is the fundamental operation of backtracking.
6. **When `remain` reaches 0, add a copy of the current combination to the result**: You must save a copy rather than a reference; otherwise, subsequent operations will modify the contents.

## Prerequisites

### Backtracking

Backtracking is a search technique that builds solution candidates incrementally and reverts to the previous state to try a different candidate as soon as it determines that the current path cannot satisfy the constraints. It is implemented with a recursive function that repeats the cycle of "choose → recurse → undo the choice" to enumerate all possible patterns.

### Arrays.sort

`Arrays.sort` is a method that sorts an array in ascending order. In a sorted array, you can apply pruning based on the property that "if the current value exceeds the condition, all subsequent values also exceed it."

```java
int[] cands = {3, 1, 2};
Arrays.sort(cands);       // cands becomes {1, 2, 3}
```

### ArrayList Operations

An `ArrayList` is a variable-length list. It supports adding, removing, and copying elements. In backtracking, it is used to manage the current combination being built.

```java
List<Integer> curr = new ArrayList<>();
curr.add(2);                          // Append 2 to the end → [2]
curr.add(3);                          // Append 3 to the end → [2, 3]
curr.remove(curr.size() - 1);         // Remove the last element → [2] (backtrack)
new ArrayList<>(curr);                // Create a copy of curr (for saving to results)
```

### List\<List\<Integer\>\>

`List<List<Integer>>` is a type representing "a list of integer lists." It is used to store multiple combinations. Each combination is a single `List<Integer>`, and the collection of all combinations is a `List<List<Integer>>`.

```java
List<List<Integer>> res = new ArrayList<>();  // Create an empty result list
res.add(new ArrayList<>(curr));               // Add a copy of the combination to the result
```

## Complexity

| | Value |
|---|---|
| Time | O(n^(target/min)) — n is the number of candidates and min is the smallest candidate value. In the worst case, branching occurs for each candidate up to target/min times for the smallest value. |
| Space | O(target/min) — The maximum recursion depth is target/min. The maximum number of elements in a single combination is also target/min. |

## Code

```java
// Input: an array of distinct positive integers candidates and a positive integer target
// Output: all combinations that sum to target, returned as List<List<Integer>>
public List<List<Integer>> combinationSum(int[] cands, int target) {
    // Sorting in ascending order enables the pruning condition: "if cands[i] > remain, all subsequent values also exceed it"
    Arrays.sort(cands);
    // List to store the results
    List<List<Integer>> res = new ArrayList<>();
    // Start backtracking (remain=target, start index=0, current combination=empty)
    backtrack(cands, target, 0, new ArrayList<>(), res);
    return res;
}

// remain: the value left after subtracting all chosen numbers from target. When it reaches 0, the sum matches target
// start: the starting index for exploration. Only choosing candidates at or after this index prevents duplicates (different orderings)
// curr: the combination currently being built. The algorithm explores all patterns by repeatedly choosing and undoing choices
void backtrack(int[] cands, int remain, int start,
               List<Integer> curr, List<List<Integer>> res) {
    // If remain is 0, the sum matches target → add the current combination to the result
    if (remain == 0) {
        // Create and save a copy. Saving the reference directly would cause its contents to change in subsequent operations
        res.add(new ArrayList<>(curr));
        return;
    }
    // Scan from start. If cands[i] > remain, the array is sorted so all subsequent values also exceed it → break the loop (pruning)
    for (int i = start; i < cands.length && cands[i] <= remain; i++) {
        // Append the current candidate to the end of the combination
        curr.add(cands[i]);
        // Pass i (not i+1) as the third argument to allow the same number to be chosen repeatedly
        backtrack(cands, remain - cands[i], i, curr, res);
        // After returning from recursion, remove the added element (backtrack). This prepares to try the next candidate
        curr.remove(curr.size() - 1);
    }
}
```
