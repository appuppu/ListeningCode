# Partitioning a String Into Palindrome Substrings — Find All Ways to Partition a String Into Palindrome Substrings

## Problem

The algorithm receives a string `s` as input. It partitions `s` such that every substring in the partition is a palindrome (a string that reads the same forwards and backwards), enumerates **all** such partitioning patterns, and returns the result as a list of lists.

## Key Insight

The algorithm precomputes a DP table so that it can determine whether any substring is a palindrome in O(1) time. It then uses backtracking to extract palindromic substrings from left to right and recurse on the remainder, efficiently enumerating all partitioning patterns.

## Thought Process

1. **A partitioning problem can be expressed as recursion that extracts substrings from the beginning**: Starting from position `start` through the end of the string, the algorithm extracts one substring from `start` to `end` and recursively processes the remaining portion. When `start` reaches the end of the string, one valid partition is complete
2. **The extraction condition is "the substring must be a palindrome"**: Since every substring in the partition must be a palindrome, the algorithm extracts `s[start..end]` and adds it to the path only when it is a palindrome. The algorithm skips the extraction when the substring is not a palindrome
3. **Performing O(n) palindrome checks at every step is wasteful**: The backtracking process checks whether substrings are palindromes at each step, but it may check the same substring multiple times. Precomputing a DP table reduces the palindrome check for any `s[l..r]` to O(1)
4. **How to build the DP table**: `dp[l][r]` is a boolean representing whether the substring of `s` from index `l` to index `r` is a palindrome. A substring is a palindrome when both end characters are the same and the inner substring is also a palindrome. A substring of length 1 (`l == r`) is always a palindrome. A substring of length 2 (`r - l == 1`) is a palindrome when both characters are the same. A substring of length 3 or more is a palindrome when `s[l] == s[r]` and `dp[l+1][r-1]` is true
5. **Structure of the backtracking**: The algorithm extends `end` one position at a time from `start` to `s.length()-1`. When `dp[start][end]` is true, the algorithm adds the substring to the path and recurses from `end+1`. After returning from the recursion, the algorithm removes the last element from the path and tries a different extraction
6. **What the algorithm returns**: Each time `start` reaches `s.length()`, the algorithm adds a copy of the current path to the result list. After all recursions complete, the algorithm returns the result list

## Prerequisites

### Palindrome

A palindrome is a string that reads the same forwards and backwards. For example, `"aba"`, `"aa"`, and `"a"` are palindromes. `"ab"` is not a palindrome.

### Palindrome DP Table Using a 2D Boolean Array

The table `dp[l][r]` enables O(1) lookup of whether the substring from index `l` to index `r` is a palindrome. The algorithm fixes the right endpoint `r` in the outer loop and moves the left endpoint `l` from `0` to `r` in the inner loop to build the table.

```java
boolean[][] dp = new boolean[n][n];
for (int r = 0; r < n; r++) {
    for (int l = 0; l <= r; l++) {
        // Palindrome if both ends match and the inner part is a palindrome (or length <= 2)
        if (s.charAt(l) == s.charAt(r) && (r - l < 2 || dp[l + 1][r - 1])) {
            dp[l][r] = true;
        }
    }
}
dp[0][2];  // Whether s[0] through s[2] is a palindrome → true or false
```

### Backtracking

Backtracking is a search technique that makes one choice, recurses forward, and undoes the choice to try a different option when the current path fails to satisfy the conditions. It consists of three steps: add to path (choose) → recurse → remove from path (undo).

```java
path.add(choice);                    // Make a choice
backtrack(nextState, path, result);  // Recurse forward
path.remove(path.size() - 1);       // Undo the choice and try another path
```

### The substring Method

`String.substring(start, end)` returns the substring from index `start` to index `end - 1`. Note that the `end` index is exclusive.

```java
String s = "aab";
s.substring(0, 1);  // "a"
s.substring(0, 2);  // "aa"
s.substring(0, 3);  // "aab"
```

## Complexity

| | Value |
|---|---|
| Time | O(n × 2^n) — Building the DP table takes O(n^2). The backtracking enumerates up to 2^(n-1) partitions, and each partition requires O(n) to copy the substrings |
| Space | O(n^2) — The DP table uses an n×n boolean array. The maximum recursion stack depth is O(n) |

## Code

```java
// Input: string s
// Output: List<List<String>> containing all palindrome partitions of s
List<List<String>> partition(String s) {
    int n = s.length();

    // dp[l][r] = DP table indicating whether the substring s[l] through s[r] is a palindrome
    boolean[][] dp = new boolean[n][n];
    // Fix the right endpoint r in the outer loop and scan l from 0 to r in the inner loop
    for (int r = 0; r < n; r++) {
        for (int l = 0; l <= r; l++) {
            // Palindrome if both end characters match and the inner part is a palindrome (or length <= 2)
            // r - l < 2 condition: length 1 is always a palindrome, length 2 is a palindrome if both characters match
            if (s.charAt(l) == s.charAt(r)
                && (r - l < 2
                || dp[l + 1][r - 1])) {
                dp[l][r] = true;
            }
        }
    }

    // Result list to store all partitioning patterns
    List<List<String>> res = new ArrayList<>();
    // Start backtracking from position 0 with an empty path
    bt(s, 0, new ArrayList<>(), res, dp);
    return res;
}

void bt(String s, int start,
    List<String> path,
    List<List<String>> res,
    boolean[][] dp) {
    // Reached the end of the string → successfully partitioned the entire string into palindrome substrings
    if (start == s.length()) {
        // Add a copy of path because path will be modified later
        res.add(new ArrayList<>(path));
        return;
    }

    // Try substrings from start to end one by one
    for (int end = start; end < s.length();
        end++) {
        // Check palindrome in O(1) using the DP table
        if (dp[start][end]) {
            // Add the palindrome substring to the path and recurse
            // The second argument of substring is exclusive, so specify end + 1
            path.add(
                s.substring(start, end + 1));
            // The next start position is end + 1 (immediately after the extracted part)
            bt(s, end + 1, path, res, dp);
            // Undo the choice and try a different extraction (backtrack)
            path.remove(path.size() - 1);
        }
    }
}
```
