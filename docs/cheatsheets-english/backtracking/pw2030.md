# Searching for a Word in a Grid — Determine whether a word can be formed by tracing characters in a grid

## Problem

You are given a 2D character grid `board` and a string `word`. You must determine whether you can construct `word` by sequentially tracing adjacent cells (up, down, left, right) in the grid, and return a `boolean`. Each cell can be used only once per path.

## Key Insight

You perform DFS starting from each cell in the grid, matching one character of the word at a time. Instead of managing visited cells with a separate array, you overwrite each cell directly with a special character and restore it after exploration. This approach reduces space complexity to only the depth of the recursion stack.

## Thought Process

1. **Any cell can serve as a starting point**: The word can begin at any cell in the grid, so you must try every cell as a potential starting point.
2. **You match characters one at a time in order**: You check whether the current cell's character matches the character at the current position in `word`. If it matches, you recursively explore the adjacent cells in all four directions. This structure is DFS (Depth-First Search) itself.
3. **You must prevent reusing the same cell**: Since a single path cannot use the same cell twice, you need to track visited cells. You could maintain a separate `boolean[][]` visited array, but that consumes additional space.
4. **You mark cells as visited by modifying the board directly**: When you enter exploration, you overwrite the current cell's character with `'#'` or another special character that does not appear in the board. This prevents recursive calls from matching the same cell again. This eliminates the need for a visited array and reduces space complexity to O(L), the depth of the recursion stack.
5. **You restore the original character after exploration**: On the way back from DFS, you restore the overwritten `'#'` to the original character (backtracking). This allows other starting points to use the same cell correctly in their explorations.
6. **You organize the termination conditions**: When the index `idx` reaches `word.length()`, all characters have been matched and you return `true`. When the position is out of bounds or the character does not match, you return `false`. If any of the four directions returns `true`, you return `true` at that point.

## Prerequisites

### DFS (Depth-First Search)

DFS is an exploration technique for graphs and grids. It advances as far as possible in one direction, and when it reaches a dead end, it backtracks one step and tries a different direction. Recursive calls implement this behavior naturally.

```java
void dfs(int node) {
    // Process the node
    for (int neighbor : getNeighbors(node)) {
        dfs(neighbor);  // Recursively advance to the neighboring node
    }
}
```

### Backtracking

Backtracking is a technique that undoes changes made during exploration when returning from that exploration. The cycle of "try → advance → undo" allows you to explore all candidates without missing any.

```java
board[r][c] = '#';   // Modify the cell (mark it as visited)
dfs(...);            // Recursively continue the exploration
board[r][c] = temp;  // Restore the cell (mark it as unvisited)
```

### charAt

`charAt` is a method that returns the character at a specified position in a `String` as a `char` type. The index is zero-based.

```java
String word = "ABCCED";
word.charAt(0);   // Returns 'A'
word.charAt(3);   // Returns 'C'
word.length();    // Returns 6 (returns the number of characters)
```

### Four-Direction Exploration in a 2D Grid

To explore adjacent cells (up, down, left, right) in a 2D grid, you try four patterns by adding or subtracting 1 from the row and column respectively.

```java
// Explore in the order: up, down, left, right
dfs(board, word, r-1, c, idx+1);  // Up (row - 1)
dfs(board, word, r+1, c, idx+1);  // Down (row + 1)
dfs(board, word, r, c-1, idx+1);  // Left (column - 1)
dfs(board, word, r, c+1, idx+1);  // Right (column + 1)
```

## Complexity

| | Value |
|---|---|
| Time | O(m × n × 4^L) — You start DFS from every cell, and from each starting point you explore up to 4 directions for L characters (m×n is the grid size, L is the length of the word) |
| Space | O(L) — The maximum depth of the recursion stack is L. No visited array is needed because you modify the board directly |

## Code

```java
// Input: a 2D character array board and a string word
// Output: return true if word can be formed by tracing adjacent cells in the grid, false otherwise

// DFS that matches word[idx] onward from the current position (r, c)
boolean dfs(char[][] board, String word, int r, int c, int idx) {
    // If idx equals word.length(), all characters have been matched, so return true
    if (idx == word.length()) return true;

    // If r or c is out of the grid bounds, or board[r][c] does not match word.charAt(idx), return false
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length
        || board[r][c] != word.charAt(idx))
        return false;

    // Save the current cell's character in a variable temp and overwrite it with '#' to prevent revisiting
    // '#' does not match any letter, so it prevents this cell from being matched again in recursive calls (substitute for a visited array)
    char temp = board[r][c];
    board[r][c] = '#';

    // Recursively explore all four directions (succeed if any direction returns true)
    // Short-circuit evaluation of || skips the remaining directions once true is found
    boolean found =
        dfs(board, word, r - 1, c, idx + 1)
     || dfs(board, word, r + 1, c, idx + 1)
     || dfs(board, word, r, c - 1, idx + 1)
     || dfs(board, word, r, c + 1, idx + 1);

    // Restore the original character regardless of the exploration result (backtrack)
    // This returns the cell to a usable state for explorations from other starting points or other paths
    board[r][c] = temp;
    return found;
}

boolean exist(char[][] board, String word) {
    int m = board.length;
    int n = board[0].length;

    // Iterate over all cells (i, j) in the grid with a nested for loop and call DFS from each cell as a starting point
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // Return true as soon as dfs returns true
            if (dfs(board, word, i, j, 0))
                return true;

    // Return false if no starting cell produces a match
    return false;
}
```
