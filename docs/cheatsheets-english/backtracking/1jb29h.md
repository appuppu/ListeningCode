# Generating All Valid Parentheses Combinations — Generate All Valid Combinations from n Pairs of Parentheses

## Problem

You are given an integer `n`. You must generate **all** correctly nested parentheses strings using `n` opening parentheses `(` and `n` closing parentheses `)`, and return them as a list. Each string has a length of `2 * n`, and the cumulative count of closing parentheses must never exceed the cumulative count of opening parentheses at any position.

## Key Insight

When you build a string one character at a time, only two pieces of state determine which character you can place next: the remaining count of opening parentheses and the remaining count of closing parentheses. You can add an opening parenthesis as long as you have used fewer than `n` of them, and you can add a closing parenthesis only when its count is less than the count of opening parentheses used so far. By pruning branches with these conditions, you can enumerate all valid combinations without ever generating an invalid string.

## Thought Process

1. **The problem requires enumerating all combinations**: The problem asks you to "generate all," so you need an exploratory approach that enumerates every valid pattern. Backtracking, which builds the string one character at a time and branches at each step, is well suited for this task.
2. **Each step has only two choices**: The only characters you can place at each position are `(` or `)`. By repeating this binary choice recursively, you can explore all candidates.
3. **You want to prune invalid branches early**: Trying all binary choices yields `2^(2n)` possibilities, but the vast majority are invalid. Two validity conditions exist: you cannot use more than `n` opening parentheses, and the count of closing parentheses must never exceed the count of opening parentheses at any point. These two conditions prune invalid branches.
4. **Two variables are sufficient to manage the state**: You pass `open` (the number of opening parentheses used) and `close` (the number of closing parentheses used) to the recursive function. If `open < n`, you can add `(`. If `close < open`, you can add `)`.
5. **The string is complete when its length reaches `2 * n`**: A string built while respecting the `open` and `close` conditions is guaranteed to be valid once it reaches `2 * n` characters. At that point, you add the string to the result list.
6. **Backtracking restores the state**: After appending a character to the `StringBuilder` and recursing, you call `deleteCharAt` to remove the last character and restore the previous state. This approach allows all exploration paths to share a single `StringBuilder` instance.

## Prerequisites

### What Is Backtracking

Backtracking is a search technique that repeats the cycle of choose → recurse → undo to enumerate all valid combinations. At each step, you pick one option from the available choices and proceed recursively to the next step. When the recursion returns, you undo the choice (backtrack) and try a different option. By adding pruning conditions, you can terminate invalid paths early.

```java
// Basic backtracking pattern
void backtrack(state) {
    if (termination condition) {
        add to results;
        return;
    }
    for (each choice) {
        apply choice;        // e.g., sb.append('(')
        backtrack(next state);
        undo choice;         // e.g., sb.deleteCharAt(sb.length() - 1)
    }
}
```

### What Is StringBuilder

`StringBuilder` is a class for building strings efficiently. Because `String` is immutable and creates a new object every time you append a character, `StringBuilder` manipulates an internal buffer directly, allowing O(1) append and delete operations.

```java
StringBuilder sb = new StringBuilder();  // Create an empty StringBuilder
sb.append('(');          // Append a character to the end → "("
sb.append(')');          // Append a character to the end → "()"
sb.length();             // Return the current character count → 2
sb.deleteCharAt(1);      // Delete the character at index 1 → "("
sb.toString();           // Convert to a String and return → "("
```

### Validity Conditions for Parentheses

A parentheses string is "valid" when it satisfies the following two conditions:
- **Condition 1**: The number of opening parentheses equals the number of closing parentheses.
- **Condition 2**: At every position in the string, the count of closing parentheses from the beginning up to that position does not exceed the count of opening parentheses.

Example: When `n=2`, `(())` and `()()` are valid. `)()(` violates Condition 2, and `((()` violates Condition 1.

## Complexity

| | Value |
|---|---|
| Time | O(4^n / √n) — The number of valid parentheses strings generated equals the Catalan number C(n) = C(2n,n)/(n+1), which is asymptotically O(4^n / (n√n)). Since building each string takes O(n), the overall complexity is O(4^n / √n). |
| Space | O(n) — The maximum recursion depth is 2n, and the maximum length of the StringBuilder is also 2n. Excluding the result list, the space usage is O(n). |

## Code

```java
// Input: an integer n (the number of parenthesis pairs)
// Output: return a List<String> containing all valid parentheses strings
private void backtrack(StringBuilder sb, int open, int close, int n, List<String> res) {
    // When the string length reaches 2n, we have used exactly n opening and n closing parentheses, so a valid parentheses string is complete
    if (sb.length() == 2 * n) {
        res.add(sb.toString());
        return;
    }
    // If neither condition below is met, no more characters can be added, so the method returns and backtracking continues at the caller

    // If fewer than n opening parentheses have been used, we can still add an opening parenthesis
    if (open < n) {
        sb.append('(');
        backtrack(sb, open + 1, close, n, res);
        // Core of backtracking: remove the trailing '(' to restore the state, so the next branch (adding a closing parenthesis) starts from the correct state
        sb.deleteCharAt(sb.length() - 1);
    }

    // Important: the condition is close < open, NOT close < n
    // close < n would allow closing parentheses to exceed opening parentheses (e.g., ")("),
    // but close < open ensures the count of closing parentheses never exceeds the count of opening parentheses, preventing the generation of invalid strings
    if (close < open) {
        sb.append(')');
        backtrack(sb, open, close + 1, n, res);
        sb.deleteCharAt(sb.length() - 1);  // Restore the state
    }
}

public List<String> generateParenthesis(int n) {
    // List to store all valid parentheses strings
    List<String> res = new ArrayList<>();
    // Start the search with an empty StringBuilder and open=0, close=0
    backtrack(new StringBuilder(), 0, 0, n, res);
    return res;
}
```
