# Detecting Axis-Aligned Squares From Points — Counting Axis-Aligned Squares From Stored Points

## Problem

Design a data structure that supports an `add` operation to add a point on a 2D plane, and a `count` operation that returns the number of **axis-aligned squares** (all four sides are parallel to either the x-axis or y-axis) that include a given point as one vertex. The system treats points added multiple times to the same coordinates as separate individual points.

## Key Insight

An axis-aligned square is uniquely determined by two diagonal points — once you fix those two points, the remaining two vertices are uniquely determined. You enumerate candidate diagonal partners that share the same x-coordinate as the query point, and then verify the existence of the remaining two corners in O(1) using a HashMap. This approach enables efficient square counting.

## Thought Process

1. **Understand the properties of axis-aligned squares**: Because all four sides are parallel to the x-axis or y-axis, the four vertices take the form `(x1,y1)`, `(x1,y2)`, `(x2,y1)`, `(x2,y2)`. In other words, a square consists of a combination of two points sharing the same x-coordinate and two points sharing the same y-coordinate.
2. **Identify the remaining two points from two diagonal points**: If you select the query point `(px, py)` and a point `(px, pt_y)` that shares the same x-coordinate but has a different y-coordinate, the side length becomes `|py - pt_y|`. The remaining two vertices must exist at positions `(px ± side, py)` and `(px ± side, pt_y)`.
3. **A square can extend in two directions (left and right)**: Once the side length `side` is determined, the other x-coordinate is either `px - side` or `px + side`. You need to check both directions.
4. **Record the count of points at each coordinate**: Because the system can add multiple points to the same coordinates, you manage the occurrence count of each coordinate using a HashMap. The product of the occurrence counts of the remaining two vertices gives the number of squares that can be formed from that combination.
5. **Retrieve points with the same x-coordinate efficiently**: You maintain a separate HashMap keyed by x-coordinate that stores a list of all points with that coordinate. This enables efficient enumeration of only the points sharing the same x-coordinate during the `count` operation.
6. **Accumulate and return the result**: For each partner candidate and each direction, you add the product of the occurrence counts of the remaining two vertices to the result.

## Prerequisites

### Using Coordinates as HashMap Keys

To use a 2D coordinate `(x, y)` as a HashMap key, you can convert it to the string `"x,y"`. This allows you to store and retrieve values for any coordinate in O(1).

```java
Map<String, Integer> cnt = new HashMap<>();
String key = x + "," + y;               // Coordinate (3,5) → "3,5"
cnt.put(key, cnt.getOrDefault(key, 0) + 1);  // Increment the occurrence count for this coordinate by 1
cnt.getOrDefault(key, 0);               // Return 0 if the coordinate does not exist
```

### What computeIfAbsent Does

This method generates and registers a new value only when the specified key does not exist in the Map. If the key already exists, it returns the existing value as-is. This is convenient when building a Map of Lists.

```java
Map<Integer, List<int[]>> xMap = new HashMap<>();
// Create a new ArrayList if key 5 does not exist; return the existing list if it does
xMap.computeIfAbsent(5, k -> new ArrayList<>()).add(new int[]{5, 3});
```

### Counting Combinations (Multiplication Principle)

When two independent choices have `c1` and `c2` options respectively, the total number of combinations is `c1 * c2`. In this problem, when `c1` points exist at one remaining vertex coordinate and `c2` points exist at the other, the number of ways to choose those two vertices is `c1 * c2`.

## Complexity

| | Value |
|---|---|
| Time | add: O(1) — Only registers entries in the HashMap. count: O(n) — Scans all points that share the same x-coordinate. |
| Space | O(n) — Stores the coordinates and occurrence counts of all points in the HashMap. |

## Code

```java
// add(int[] p): Add point p = [x, y] to the 2D plane
// count(int[] p): Return the number of axis-aligned squares that include point p = [x, y] as one vertex
class DetectSquares {
    // HashMap that manages the occurrence count of each coordinate (key: "x,y")
    // Used to retrieve in O(1) how many points exist at any coordinate during count
    Map<String, Integer> cnt;
    // HashMap that manages the list of points sharing the same x-coordinate (key: x-coordinate)
    // Used to efficiently enumerate only points with the same x-coordinate during count
    Map<Integer, List<int[]>> xMap;

    DetectSquares() {
        cnt = new HashMap<>();
        xMap = new HashMap<>();
    }

    void add(int[] p) {
        // Convert the coordinate to the string "x,y" and increment its occurrence count by 1
        String key = p[0] + "," + p[1];
        cnt.put(key, cnt.getOrDefault(key, 0) + 1);

        // Add the point to the list for its x-coordinate (create a new list if this x-coordinate appears for the first time)
        xMap.computeIfAbsent(p[0],
            k -> new ArrayList<>()).add(p);
    }

    int count(int[] p) {
        int res = 0;
        int px = p[0], py = p[1];

        // Retrieve the list of points sharing the same x-coordinate as the query point
        // Return 0 if the list does not exist, since no square can be formed
        List<int[]> same = xMap.get(px);
        if (same == null) return 0;

        // Scan each point with the same x-coordinate as a partner candidate
        for (int[] pt : same) {
            // Calculate the side length (absolute difference of y-coordinates between the query point and the partner point)
            int side = Math.abs(py - pt[1]);
            // Skip points with the same y-coordinate, since the side length would be 0 and cannot form a square
            if (side == 0) continue;

            // A square can extend in two directions (left and right), so try both x-coordinates
            int[] dirs = {px - side, px + side};
            for (int nx : dirs) {
                // Retrieve the occurrence counts of the remaining two vertices at (nx, py) and (nx, pt[1])
                // Non-existent coordinates return 0, making the product 0, so they are automatically excluded
                String k1 = nx + "," + py;
                String k2 = nx + "," + pt[1];
                int c1 = cnt.getOrDefault(k1, 0);
                int c2 = cnt.getOrDefault(k2, 0);

                // The product of the two vertex occurrence counts gives the number of squares for this combination (multiplication principle)
                res += c1 * c2;
            }
        }
        return res;
    }
}
```
