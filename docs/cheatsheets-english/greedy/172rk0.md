# Checking Validity of a Parenthesis String With Wildcards

## Problem

You are given a string consisting of only three types of characters: `(`, `)`, and `*`. The `*` can be treated as `(`, `)`, or an empty string. You need to determine whether this string can be a **valid parenthesis string** and return a `boolean`.

## Key Insight

Since the interpretation of `*` is uncertain, you track the count of open parentheses not as a single value but as a "possible range (minimum `low` to maximum `high`)." If this range remains valid throughout the scan and includes 0 at the end, the string is valid.

## Thought Process

1. **You can determine parenthesis validity by counting open parentheses**: Scan the string from left to right, incrementing by 1 for `(` and decrementing by 1 for `)`. If the count becomes negative at any point, the string is invalid. If the count is 0 at the end, the string is valid. This is the fundamental principle of parenthesis validation.
2. **The `*` character prevents the count from being a single value**: Since `*` has three possible interpretations, the count becomes a "range" rather than a single value. Interpreting `*` as `(` increments the count by 1, interpreting it as `)` decrements the count by 1, and interpreting it as an empty string leaves the count unchanged. Each `*` encountered widens the range.
3. **You track the range with two variables**: `low` represents the minimum open-parenthesis count (when `*` is treated as `)` or an empty string as much as possible), and `high` represents the maximum (when `*` is treated as `(` as much as possible). These two variables alone cover all possible patterns.
4. **If `high` becomes negative during the scan, you immediately determine the string is invalid**: Since `high` is the maximum open-parenthesis count, a negative value means that no matter how you interpret the `*` characters, there is an excess of `)`, and the string cannot be a valid parenthesis string.
5. **If `low` becomes negative, you clamp it to 0**: A negative `low` simply means the range includes interpretations that would produce an excess of `)`. Since you can choose to interpret `*` as an empty string to keep the count at 0 or above, you correct `low` to 0 because a negative value represents an interpretation you would never actually choose.
6. **You determine the result by checking whether `low == 0` at the end**: When the scan is complete, if `low` is 0, it means there exists an interpretation where all open parentheses are closed, so you return `true`.

## Prerequisites

### Fundamental Principle of Parenthesis Validation

You scan the string from left to right and manage the count of open parentheses. You increment by 1 for `(` and decrement by 1 for `)`. If the count never becomes negative and is 0 at the end, the string is a valid parenthesis string.

```java
int count = 0;
for (char c : s.toCharArray()) {
    if (c == '(') count++;
    else count--;
    if (count < 0) return false;  // Excess closing parentheses
}
return count == 0;  // Whether all open parentheses have been closed
```

### What Math.max Is

`Math.max` is a method that returns the larger of two values. You can use it to clamp a value so that it does not fall below a certain lower bound.

```java
Math.max(3, 0);    // → 3 (3 is already >= 0, so it remains unchanged)
Math.max(-1, 0);   // → 0 (-1 is < 0, so it is corrected to 0)
```

### What toCharArray Is

`toCharArray` is a method that converts a string into an array of `char`. You use it to iterate through a string character by character in a for-each loop.

```java
String s = "(*)";
char[] chars = s.toCharArray();  // → ['(', '*', ')']
for (char c : s.toCharArray()) {
    // Each character is assigned to c one at a time as the loop iterates
}
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — You only need to scan the string once |
| Space | O(1) — You use only two variables: `low` and `high` |

## Code

```java
// Input: a string s consisting of only '(', ')', and '*'
// Output: a boolean indicating whether the string can be a valid parenthesis string
public boolean checkValidString(String s) {
    // low: minimum open-parenthesis count, high: maximum open-parenthesis count
    // These two variables track the range of counts across all interpretation patterns of *
    int low = 0, high = 0;

    // Scan the string one character at a time from the beginning
    for (char c : s.toCharArray()) {
        if (c == '(') {
            // Open parenthesis: every interpretation increments the count by 1, so shift both ends of the range by +1
            low++;
            high++;
        } else if (c == ')') {
            // Close parenthesis: every interpretation decrements the count by 1, so shift both ends of the range by -1
            low--;
            high--;
        } else {
            // '*': interpreting as ) lowers the minimum, interpreting as ( raises the maximum
            // The empty-string interpretation is included within this range
            low--;
            high++;
        }

        // If the maximum is negative, closing parentheses are in excess no matter how you interpret *, so the string is invalid
        if (high < 0) return false;

        // A negative low means too many * characters were interpreted as ),
        // but you can simply choose not to use that interpretation, so clamp the minimum to 0
        low = Math.max(low, 0);
    }

    // If low is 0, there exists an interpretation of * where all open parentheses are closed, so return true
    // If low is greater than 0, open parentheses remain regardless of interpretation, so return false
    return low == 0;
}
```
