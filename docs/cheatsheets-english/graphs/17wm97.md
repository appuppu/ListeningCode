# Checking if a Graph Forms a Valid Tree

## Problem

The input consists of `n` nodes labeled from `0` to `n-1` and a list of undirected edges `edges`. The task is to determine whether this graph forms a **valid tree** and return a `boolean`. A valid tree is a graph in which all nodes are connected and no cycle exists.

## Key Insight

A tree with `n` nodes has exactly `n-1` edges and contains no cycle. By first verifying that the number of edges equals `n-1`, and then using Union-Find to merge each edge while detecting cycles during the process, the algorithm can determine whether the graph is a valid tree.

## Thought Process

1. **Use the necessary condition of a tree**: A valid tree must have exactly `n-1` edges. If the number of edges is not `n-1`, the algorithm can immediately determine that the graph is not a tree. This preliminary check eliminates both the case where too many edges exist (a cycle definitely exists) and the case where too few edges exist (the graph is not connected).
2. **Consider how to detect cycles**: Even when the number of edges is `n-1`, a cycle may still exist (in which case the graph is disconnected). By checking whether both endpoints of each added edge already belong to the same connected component, the algorithm can detect a cycle.
3. **Manage connected components with Union-Find**: Union-Find (disjoint set data structure) can determine whether two nodes belong to the same connected component (find) and merge two connected components (union) in nearly O(1) time. The algorithm initializes each node's parent to itself and performs union for each edge.
4. **Define the cycle detection condition**: During a union operation, if two nodes share the same root, they are already connected. Adding another edge between them would create a cycle, so the algorithm returns `false`.
5. **Return the result after processing all edges**: If no cycle is detected after processing all edges, the algorithm combines this result with the fact that the number of edges is `n-1` (verified in step 1) to determine that the graph is a valid tree and returns `true`.

## Prerequisites

### What is Union-Find (Disjoint Set Data Structure)?

Union-Find is a data structure that manages multiple elements by dividing them into groups (sets). It provides two operations. `find` returns the representative element (root) of the group to which a given element belongs. `union` merges the groups of two elements into one. When optimized with path compression and union by rank, each operation runs in nearly O(1) time.

```java
int[] parent = {0, 1, 2, 3, 4};  // Initial state: each node's parent is itself
int[] rank = new int[5];          // Initialize each node's rank (upper bound of tree height) to 0

// find: returns the root of node x (with path compression)
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // Path compression: reattach the parent directly to the root
    return parent[x];
}
```

### What is Path Compression?

Path compression is an optimization technique that reattaches the parent of every node along the search path directly to the root each time `find` is called. This causes subsequent `find` calls to approach O(1). The technique is implemented by the recursive assignment `parent[x] = find(parent[x])`.

### What is Union by Rank?

Union by rank is a technique that attaches the tree with the lower rank (upper bound of tree height) under the tree with the higher rank when merging two trees. This suppresses the increase in tree height and keeps the search distance of `find` short. The rank increases by 1 only when the two ranks are equal.

```java
// union: merges the groups of node a and node b. Returns false if they already belong to the same group
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // Get the root of each node
    if (ra == rb) return false;       // Same root → already in the same group → cycle
    if (rank[ra] < rank[rb])
        parent[ra] = rb;             // Attach the lower-rank tree under the higher-rank tree
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;             // If ranks are equal, attach rb under ra
        rank[ra]++;                   // Increment the rank by 1
    }
    return true;
}
```

## Complexity

| | Value |
|---|---|
| Time | O(n × α(n)) — The algorithm executes find and union for each edge. α(n) is the inverse Ackermann function, which is effectively constant in practice |
| Space | O(n) — The parent array and rank array each store n elements |

## Code

```java
// Input: integer n (number of nodes) and 2D integer array edges (each element is an undirected edge [u, v])
// Output: returns true if the graph is a valid tree, false otherwise

// parent array: manages the parent of each node
int[] parent, rank;

// Returns the root of the connected component to which node x belongs (with path compression)
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // Path compression: reattach the parent directly to the root
    return parent[x];
}

// Merges the connected components of node a and node b. Returns false if a cycle would be created
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // Get the roots of both endpoint nodes
    if (ra == rb) return false;       // Same root means a cycle would be created → adding this edge forms a cycle
    // Attach the lower-rank tree under the higher-rank tree to suppress tree height
    if (rank[ra] < rank[rb])
        parent[ra] = rb;
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;
        rank[ra]++;
    }
    return true;
}

public boolean validTree(int n, int[][] edges) {
    // The number of edges in a tree must be n-1 (too many means a cycle exists, too few means disconnected)
    if (edges.length != n - 1)
        return false;

    // Initialize each node's parent to itself (each node forms an independent connected component)
    parent = new int[n];
    rank = new int[n];
    for (int i = 0; i < n; i++)
        parent[i] = i;

    // Process each edge and return false if both endpoints already belong to the same connected component
    for (int[] e : edges)
        if (!union(e[0], e[1]))
            return false;

    // No cycle was detected after processing all edges, and the edge count is n-1, so the graph is a valid tree
    return true;
}
```
