# Finding a Valid Order to Complete All Courses

## Problem

You are given courses labeled from 0 to `numCourses - 1` and an array of prerequisite pairs `[a, b]`, where you must complete course `b` before course `a`. Return an array representing a **valid order** to complete all courses. If no valid order exists (i.e., a circular dependency exists), return an empty array.

## Key Insight

You can represent prerequisite dependencies as a directed graph, and a valid course order corresponds to a topological sort of that graph. By processing nodes with an in-degree of 0 (courses with no prerequisites) first and removing their dependencies from the graph, you can arrange all nodes in the correct order as long as no cycle exists.

## Thought Process

1. **Model the dependencies as a graph**: A prerequisite `[a, b]` represents a directed edge `b → a`. By expressing all prerequisites as edges in a directed graph, a valid course order becomes a topological sort of this graph.
2. **Determine which courses can be taken first**: Courses with no prerequisites — that is, courses whose in-degree (the number of incoming edges) is 0 — can be taken immediately. By precomputing the in-degree for each node, you can identify startable courses in O(1) time.
3. **Propagate the effect of completing a course**: When you mark a course as completed, every other course that lists it as a prerequisite has its "remaining prerequisite count" reduced by one. This reduction corresponds to decrementing the in-degree. If a decrement causes a course's in-degree to reach 0, that course becomes newly available.
4. **Use BFS to manage processing order**: Enqueue all courses with an in-degree of 0. Each time you dequeue a course, append it to the result array and decrement the in-degree of its neighbors. If any neighbor's in-degree reaches 0, enqueue it. This repeated process is Kahn's algorithm.
5. **Detect circular dependencies**: If a cycle exists, every node in the cycle will never reach an in-degree of 0. Therefore, if the number of processed courses is less than `numCourses`, you can conclude that a cycle exists.
6. **Determine the return value**: If the number of processed courses equals `numCourses`, return the result array. Otherwise, return an empty array.

## Prerequisites

### What Is Topological Sort?

Topological sort arranges all nodes of a directed acyclic graph (DAG) in a linear order such that every edge points from left to right. For an edge `u → v`, node `u` always appears before node `v` in the ordering. Topological sort is impossible if the graph contains a cycle.

### What Is In-Degree?

In-degree is the number of edges coming into a node. A node with an in-degree of 0 does not depend on any other node, so you can process it first.

```java
int[] indegree = new int[numCourses];  // Initialize in-degree of each node to 0
indegree[a]++;  // Increment in-degree of node a because one edge enters it
--indegree[next];  // Decrement in-degree of node next (one prerequisite is resolved)
```

### What Is an Adjacency List?

An adjacency list is a data structure that maintains, for each node in the graph, a list of nodes to which it has outgoing edges. Calling `graph.get(u)` retrieves all nodes reachable from node `u`.

```java
List<List<Integer>> graph = new ArrayList<>();       // List that holds the entire graph
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());  // Assign an empty list to each node
graph.get(u).add(v);   // Add an edge from node u to node v
graph.get(u);           // Get all neighbors of node u → [v, ...]
```

### What Is a Queue?

A queue is a first-in, first-out (FIFO) data structure. In BFS, a queue manages nodes that are waiting to be processed.

```java
Queue<Integer> queue = new LinkedList<>();  // Create an empty queue
queue.offer(0);   // Add element 0 to the end of the queue
queue.poll();      // Remove and return the element at the front of the queue → 0
queue.isEmpty();   // Return whether the queue is empty as a boolean → true
```

## Complexity

| | Value |
|---|---|
| Time | O(V + E) — The algorithm processes each node (course) and each edge (prerequisite) exactly once |
| Space | O(V + E) — The adjacency list stores all edges, and the in-degree array, queue, and result array store all nodes |

## Code

```java
// Input: int numCourses (total number of courses) and int[][] prerequisites (array of prerequisite pairs)
// Output: Return an int[] containing a valid course order. If no valid order exists, return an empty int[]
public int[] findOrder(int numCourses, int[][] prerequisites) {
    // Create an adjacency list and assign an empty list to each course
    // Each index corresponds to a course number and holds a list of courses that become available after completing it
    List<List<Integer>> graph = new ArrayList<>();
    // In-degree array: represents the number of uncompleted prerequisites for each course
    int[] indegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++)
        graph.add(new ArrayList<>());

    // Build edges from prerequisites and compute in-degrees
    // For each pair [a, b], create an edge b → a, recording that course a depends on course b
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);  // Add edge pre[1] → pre[0]
        indegree[pre[0]]++;  // Increment the in-degree of course pre[0]
    }

    // Enqueue courses with an in-degree of 0 (no prerequisites)
    // These are the courses that can be taken first
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    // Initialize the result array and write index
    int[] result = new int[numCourses];
    int idx = 0;

    while (!queue.isEmpty()) {
        // Dequeue a course and finalize its position in the course order
        int course = queue.poll();
        result[idx++] = course;

        // Decrement the in-degree of each neighbor next of course
        // This reflects that course, which is a prerequisite of next, has been completed
        for (int next : graph.get(course))
            // If the decrement causes the in-degree to reach 0, all prerequisites of next are fulfilled, so enqueue it
            if (--indegree[next] == 0)
                queue.offer(next);
    }

    // Check whether all courses have been processed
    // If idx is less than numCourses, a circular dependency exists, so return an empty array
    return idx == numCourses ? result : new int[0];
}
```
