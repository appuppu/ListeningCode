# Checking if a String is an Interleaving of Two Others

## Problem

The problem gives three strings `s1`, `s2`, and `s3`. You must determine whether `s3` is an **interleaving** of `s1` and `s2`. An interleaving uses all characters from `s1` and `s2`, and it preserves the relative order of characters within each original string while merging them together.

## Key Insight

You can decompose this problem into the subproblem of whether the first `i` characters of `s1` and the first `j` characters of `s2` can form the first `i+j` characters of `s3`. At each position, you face a binary choice — take the next character from `s1` or from `s2` — and a DP table efficiently resolves this choice at every position.

## Thought Process

1. **Check the length precondition**: If `s3` is an interleaving of `s1` and `s2`, the length of `s3` must equal the length of `s1` plus the length of `s2`. If the lengths do not match, you can immediately return `false`.
2. **Define the subproblem**: Define `dp[i][j]` as "whether the first `i` characters of `s1` and the first `j` characters of `s2` can form the first `i+j` characters of `s3`." Under this definition, `dp[m][n]` (where `m` is the length of `s1` and `n` is the length of `s2`) gives the final answer.
3. **Derive the transition formula**: `dp[i][j]` becomes `true` in either of two cases. Case 1: `dp[i-1][j]` is `true` and the `i`-th character of `s1` matches the `(i+j)`-th character of `s3` (taking one character from `s1`). Case 2: `dp[i][j-1]` is `true` and the `j`-th character of `s2` matches the `(i+j)`-th character of `s3` (taking one character from `s2`).
4. **Define the base case**: When `i=0` and `j=0`, no characters have been taken from either string, which matches the first 0 characters (the empty string) of `s3`, so you set `dp[0][0] = true`.
5. **Optimize the space complexity**: The 2D `dp[i][j]` only uses row `i-1` to compute row `i`. Therefore, a 1D array `dp[j]` suffices: the value of `dp[j]` before the update corresponds to the previous row (`dp[i-1][j]`), and the value of `dp[j-1]` after the update corresponds to the left neighbor in the current row (`dp[i][j-1]`).
6. **Return the final result**: After the outer loop runs `i` from `0` to `m` and the inner loop runs `j` from `0` to `n`, `dp[n]` holds the answer for whether you can form all of `s3` as an interleaving.

## Prerequisites

### Space Optimization of DP Using a 1D Array

When each row of a 2D DP table `dp[i][j]` depends only on the immediately preceding row, you can replace the table with a 1D array `dp[j]`. By overwriting the array row by row, this technique reduces the space complexity from O(m×n) to O(n).

```java
// 2D case: dp[i][j] references dp[i-1][j] and dp[i][j-1]
boolean[][] dp = new boolean[m + 1][n + 1];

// Optimized to 1D: overwrite dp[j] row by row
boolean[] dp = new boolean[n + 1];
// The value of dp[j] before the update corresponds to dp[i-1][j] from the previous row
// The value of dp[j-1] after the update corresponds to dp[i][j-1] from the current row
```

### String.charAt(index)

This method returns the character at the specified position in a string. The index is zero-based.

```java
String s = "abc";
s.charAt(0);  // returns 'a'
s.charAt(2);  // returns 'c'
```

### Interleaving

Interleaving merges two strings into one string while preserving the relative order of characters in each original string.
Example: Given `s1 = "aab"` and `s2 = "axy"`, the string `"aaxaby"` is a valid interleaving (the order a, a, b from `s1` and the order a, x, y from `s2` are both preserved). The string `"abaaxy"` is not a valid interleaving because it breaks the character order of `s1`.

## Complexity

| | Value |
|---|---|
| Time | O(m×n) — The algorithm executes one pass through a double loop over the length `m` of `s1` and the length `n` of `s2` |
| Space | O(n) — The algorithm uses only a 1D DP array of size `n+1` (the length of `s2` plus one) |

## Code

```java
// Input: string s1 (length m), string s2 (length n), string s3
// Output: returns a boolean indicating whether s3 can be formed as an interleaving of s1 and s2
public boolean isInterleave(String s1, String s2, String s3) {
    int m = s1.length();
    int n = s2.length();

    // If m + n does not equal the length of s3, interleaving is impossible
    if (m + n != s3.length())
        return false;

    // dp[j] = whether the first i characters of s1 and the first j characters of s2 can form the first i+j characters of s3
    // Overwriting a 1D array row by row compresses the 2D table space to O(n)
    boolean[] dp = new boolean[n + 1];

    // Outer loop: i represents the number of characters taken from s1 (0 to m)
    for (int i = 0; i <= m; i++) {
        // Inner loop: j represents the number of characters taken from s2 (0 to n)
        for (int j = 0; j <= n; j++) {
            if (i == 0 && j == 0) {
                // Base case: no characters have been taken from either string, matching the empty string of s3
                dp[j] = true;
            } else {
                // Condition 1 (take from s1): the value of dp[j] before the update (previous row = dp[i-1][j]) is true
                //   AND the i-th character of s1 matches the (i+j)-th character of s3
                // Condition 2 (take from s2): the value of dp[j-1] after the update (left neighbor in current row = dp[i][j-1]) is true
                //   AND the j-th character of s2 matches the (i+j)-th character of s3
                // Note: because the inner loop scans j from left to right, dp[j] has not yet been overwritten and retains the previous row's value,
                //   while dp[j-1] has already been overwritten and holds the current row's value
                dp[j] =
                    (dp[j] && i > 0
                    && s1.charAt(i - 1)
                    == s3.charAt(i + j - 1))
                    || (j > 0
                    && dp[j - 1]
                    && s2.charAt(j - 1)
                    == s3.charAt(i + j - 1));
            }
        }
    }

    // dp[n] holds the result of whether all m characters of s1 and all n characters of s2 can form all m+n characters of s3
    return dp[n];
}
```
