# Counting Distinct Subsequences — Count how many subsequences in string s match string t

## Problem

Given two strings `s` and `t`, count and return the number of ways to form a subsequence that matches `t` by deleting zero or more characters from `s` while preserving the relative order of the remaining characters.

## Key Insight

For each character in `s`, there are two choices: "use it for matching `t`" or "don't use it." A 1D array tracks the accumulation of these choices, and updating from right to left correctly handles the addition of "use" and "skip" cases.

## Thought Process

1. **Subsequence matching is an accumulation of choices**: When the i-th character of `s` matches the j-th character of `t`, there are two options: "use this character to match `t[j]`" or "skip it without using it." Summing the counts from both cases yields the total number of patterns
2. **Define the DP state**: Define `dp[j]` as "the number of subsequences of `s` that match the first j characters of `t`." The final answer is `dp[n]` where n is the length of `t`
3. **Consider the base case**: A subsequence matching the first 0 characters of `t` (the empty string) always has exactly one way for any `s`: "select nothing." Therefore `dp[0] = 1`
4. **Derive the transition formula**: When `s[i-1] == t[j-1]`, `dp[j]` receives two contributions. The "don't use `s[i-1]`" case keeps the existing `dp[j]` unchanged, and the "use `s[i-1]`" case adds `dp[j-1]` (the count of matches up to the previous character). Thus `dp[j] += dp[j-1]`. When the characters do not match, `dp[j]` remains unchanged (skipping is the only option)
5. **Reason for reverse-order updates**: The formula `dp[j] += dp[j-1]` requires the pre-update value of `dp[j-1]`. If j is updated from small to large, `dp[j-1]` gets overwritten first, and the old value is lost. Updating j from large to small ensures that `dp[j-1]` still holds its pre-update value, enabling correct computation
6. **What to return**: After iterating through all characters of `s`, `dp[n]` holds the answer — the number of subsequences in `s` that match `t`

## Prerequisites

### Subsequence

A subsequence is a string formed by deleting zero or more characters from the original string while preserving the relative order of the remaining characters. Unlike a substring, the characters do not need to be contiguous.

```
s = "rabbbit", t = "rabbit"
Subsequence example: select characters at positions 1,2,3,5,6,7 of s → "rabbit" ✓
Subsequence example: select characters at positions 1,2,4,5,6,7 of s → "rabbit" ✓
Subsequence example: select characters at positions 1,3,4,5,6,7 of s → "rabbit" ✓
→ 3 ways in total
```

### Reverse-Order Update in 1D DP

This is a technique that compresses a 2D DP table `dp[i][j]` into a 1D array `dp[j]`. When the current row's computation only requires values from the previous row, reusing a 1D array reduces space complexity. However, when updating `dp[j]` requires `dp[j-1]` (the previous row's value), updating j in ascending order causes `dp[j-1]` to be overwritten with the current row's value. Updating j in descending order (large → small) ensures that the previous row's `dp[j-1]` has not yet been overwritten and can be correctly referenced.

```java
// 2D DP (original form)
dp[i][j] = dp[i-1][j] + dp[i-1][j-1];

// Compressed to 1D DP (reverse-order update)
for (int j = n; j >= 1; j--) {   // Update from large to small
    dp[j] += dp[j - 1];          // dp[j-1] still holds the previous row's value
}
```

## Complexity

| | Value |
|---|---|
| Time | O(m × n) — For each character in s (m characters), iterate through each character in t (n characters) |
| Space | O(n) — Only a 1D array of length n+1 is used |

## Code

```java
// Input: string s (length m) and string t (length n)
// Output: return the number of subsequences of s that match t as an int
public int numDistinct(String s, String t) {
    int m = s.length();
    int n = t.length();

    // dp[j] = number of subsequences of s that match the first j characters of t
    // Size is n+1 to manage n+1 states for indices 0 through n
    int[] dp = new int[n + 1];

    // A subsequence matching the empty string always has exactly 1 way (select nothing)
    // This base case holds regardless of which position in s we start from
    dp[0] = 1;

    // Consider each character of s in order (i represents how many characters of s have been considered)
    for (int i = 1; i <= m; i++) {
        // Iterate j in reverse order (large → small)
        // Reason: the computation dp[j] += dp[j-1] requires the pre-update value of dp[j-1]
        // Updating in ascending order would overwrite dp[j-1] first, losing the previous row's value
        for (int j = n; j >= 1; j--) {
            // i and j are 1-based, but string indices are 0-based, so access using i-1 and j-1
            if (s.charAt(i - 1) == t.charAt(j - 1))
                // Match case: add dp[j-1] (count for "use" case) to dp[j] (count for "skip" case)
                // This addition accumulates the total of both "use" and "skip" choices into dp[j]
                dp[j] += dp[j - 1];
            // No match case: do nothing (s[i-1] cannot be used to match t[j-1], so skipping is the only option)
        }
    }

    // dp[n] holds the number of subsequences in all of s that match all of t
    return dp[n];
}
```
