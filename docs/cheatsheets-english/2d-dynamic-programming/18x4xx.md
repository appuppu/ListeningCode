# Implementing Regular Expression Matching — Determine whether a string fully matches a pattern

## Problem

The system receives an input string `s` and a pattern `p`. In the pattern, `.` matches any single character, and `*` means zero or more repetitions of the preceding character. The function returns a `boolean` indicating whether the pattern matches the **entire** string.

## Key Insight

The algorithm fills a 2D DP table from the end of the string and pattern toward the beginning. `dp[i][j]` represents whether `s[i:]` matches `p[j:]`. When the algorithm encounters `*`, the problem reduces to two choices: "use the preceding character zero times (skip)" or "use it once and advance the string by one position."

## Thought Process

1. **The problem decomposes into subproblems**: Once the algorithm fixes a position `i` in the string and a position `j` in the pattern, the question becomes a subproblem: "does `s[i:]` match `p[j:]`?" Storing the answer to each subproblem in `dp[i][j]` eliminates redundant computation
2. **The algorithm checks whether the current characters match**: If `s[i]` and `p[j]` are the same character, or if `p[j]` is `.`, the single character at the current position matches. The algorithm stores this result in a variable `match`
3. **The algorithm considers two choices when `*` is present**: When `p[j+1]` is `*`, the pattern `x*` has two possible interpretations. The first interpretation is "zero matches (skip)," where the algorithm skips `x*` entirely and refers to `dp[i][j+2]`. The second interpretation is "one or more matches," where, if the current character matches, the algorithm advances the string by one and refers to `dp[i+1][j]` (the algorithm does not advance the pattern side because the `*` repetition may continue at the next position)
4. **Without `*`, the algorithm simply advances one character at a time**: If the current characters match, `dp[i+1][j+1]` directly becomes the answer
5. **The algorithm sets the base case**: The state `dp[n][m]`, where both the string and the pattern have reached the end, is `true`. If the string has remaining characters but the pattern has reached the end, the result is `false`. If the pattern has remaining characters but the string has reached the end, the result can only be `true` through skipping via `*`
6. **The algorithm fills the table from the end toward the beginning**: Computing `dp[i][j]` depends on `dp[i][j+2]`, `dp[i+1][j]`, and `dp[i+1][j+1]`. All of these are values in the direction of larger `i` or `j`, so iterating `i` from `n` to `0` and `j` from `m-1` to `0` in reverse order ensures that every referenced cell is already computed
7. **The function returns the final answer**: `dp[0][0]` in the table represents the answer to "does the entire string match the entire pattern"

## Prerequisites

### 2D DP Table

A 2D DP table is a two-dimensional array that stores the answer to a subproblem for each combination of two variables (here, position `i` in the string and position `j` in the pattern). The code creates it with `boolean[][] dp = new boolean[n+1][m+1]` and stores the match result of `s[i:]` and `p[j:]` in `dp[i][j]`.

```java
boolean[][] dp = new boolean[n + 1][m + 1];  // Create a table of size (n+1)×(m+1) initialized to false
dp[n][m] = true;                              // Base case: both ends reached means a match
dp[i][j] = dp[i][j + 2];                     // Fill the current cell by referencing another cell's value
```

### String.length() and String.charAt()

`length()` returns the length of the string. `charAt(i)` returns the character at index `i`. Indices are zero-based, and an out-of-bounds access throws an exception.

```java
String s = "abc";
s.length();     // → 3
s.charAt(0);    // → 'a'
s.charAt(2);    // → 'c'
```

### The meaning of `*` (star)

In regular expressions, `*` means "zero or more repetitions of the immediately preceding character." `a*` matches any of `""`, `"a"`, `"aa"`, `"aaa"`, and so on. `.*` means "zero or more repetitions of any character," so it matches any string. `*` never appears alone; it always forms a pair with the preceding character as `x*`.

## Complexity

| | Value |
|---|---|
| Time | O(n×m) — The algorithm computes each cell of the n×m DP table exactly once |
| Space | O(n×m) — The algorithm stores the n×m DP table |

## Code

```java
// Input: string s and pattern p
// Output: returns a boolean indicating whether the entire s matches p
public boolean isMatch(String s, String p) {
    int n = s.length();  // Length of the string
    int m = p.length();  // Length of the pattern

    // dp[i][j] = a 2D table storing whether s[i:] matches p[j:]
    // Indices n and m represent empty strings, so the size is +1
    boolean[][] dp = new boolean[n + 1][m + 1];

    // Base case: match succeeds when both strings have reached the end
    dp[n][m] = true;

    // Fill the table from the end toward the beginning
    // This traversal order ensures that dp[i][j+2], dp[i+1][j], and dp[i+1][j+1] are all already computed
    for (int i = n; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // Check whether the single character at the current position matches
            // Checking i < n first prevents an out-of-bounds charAt access when the string has reached the end
            boolean match = i < n
                && (s.charAt(i) == p.charAt(j)
                    || p.charAt(j) == '.');

            // Check bounds with j+1 < m and determine whether the current pattern position has the form x*
            if (j + 1 < m && p.charAt(j + 1) == '*') {
                // Take the OR (logical disjunction) of the two choices for the x* pattern:
                // dp[i][j+2]: zero matches (skip x* entirely)
                // match && dp[i+1][j]: one match and advance the string (do not advance the pattern side; j stays in place because the * repetition may continue)
                dp[i][j] = dp[i][j + 2]
                    || (match && dp[i + 1][j]);
            } else {
                // Normal character: if the single character matches, advance both the string and the pattern by one
                dp[i][j] = match
                    && dp[i + 1][j + 1];
            }
        }
    }

    // dp[0][0] is the final answer to "does the entire string s match the entire pattern p"
    return dp[0][0];
}
```
