# Designing a Simplified Twitter Feed — Design a system that efficiently retrieves the 10 most recent tweets from multiple users

## Problem

You implement four operations for a simplified Twitter system. `postTweet` posts a tweet, `getNewsFeed` retrieves the **10 most recent tweets** from that user and the users they follow, `follow` follows a user, and `unfollow` unfollows a user. The core challenge is to **merge tweet lists from multiple users in chronological order and efficiently extract only the top 10 tweets**.

## Key Insight

Each user's tweet list is already sorted in chronological order (by posting time). To extract the top K items from multiple sorted lists, rather than re-sorting all lists together, you can use a **K-way merge with a heap** that compares only the head of each list and extracts one item at a time, solving the problem with the minimum number of comparisons.

## Thought Process

1. **Decide how to store the data**: You need to manage each user's posted tweets in chronological order. A HashMap with user IDs as keys and tweet lists as values allows you to retrieve any user's tweet list in O(1). You assign a global timestamp to each tweet to record the posting order.
2. **Decide how to manage follow relationships**: Following and unfollowing correspond to adding and removing user IDs from a set. A HashMap with user IDs as keys and Sets of followed user IDs as values allows you to add, remove, and list follows all in O(1).
3. **Identify the essence of news feed retrieval**: `getNewsFeed` returns the 10 most recent tweets from the user and all users they follow. Since each user's tweet list is already sorted by posting time, this problem **reduces to extracting the top K items from multiple sorted lists (K-way merge)**.
4. **Use a heap for K-way merge**: You insert the tail (most recent tweet) of each user's tweet list into a Max-Heap. You extract the element with the largest timestamp from the heap and add that user's next most recent tweet to the heap. You repeat this process 10 times to obtain the 10 most recent tweets.
5. **Decide what information each heap element holds**: To add the next tweet from the same user after extraction, each entry holds four values: "timestamp," "tweet ID," "user ID," and "index within the list." You decrement the index by one to access that user's next most recent tweet.
6. **Terminate early after retrieving 10 items**: You exit the loop when the heap becomes empty or the result list reaches 10 items. You do not need to process all tweets.

## Prerequisites

### PriorityQueue (Priority Queue / Heap)

A PriorityQueue is a data structure that automatically reorders elements by priority each time you add an element. It extracts the highest-priority element in O(log N). Java's PriorityQueue defaults to a Min-Heap (smallest value at the head), but you can specify a Comparator to change it to a Max-Heap (largest value at the head).

```java
// Create a Max-Heap where the largest timestamp (most recent) comes first
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[0] - a[0]);
pq.offer(new int[]{5, 101});   // Add [timestamp, tweetId]
pq.offer(new int[]{3, 102});   // After adding, the heap internally orders by timestamp descending
int[] top = pq.poll();         // Extract the element with the largest timestamp → [5, 101]
pq.isEmpty();                  // Return whether the heap is empty as a boolean → false
```

### computeIfAbsent

`computeIfAbsent` is a method that generates and registers a value using the specified function only when the key does not exist in the HashMap, and returns that value. When the key already exists, it returns the existing value as-is. This method condenses the three steps of calling `get`, checking for `null`, and calling `put` into a single line.

```java
Map<Integer, List<int[]>> tweets = new HashMap<>();
// If key 1 does not exist, create a new ArrayList, register it, and return that list
tweets.computeIfAbsent(1, k -> new ArrayList<>()).add(new int[]{0, 101});
// Key 1 already exists, so return the existing list and add to it
tweets.computeIfAbsent(1, k -> new ArrayList<>()).add(new int[]{1, 102});
```

### K-way Merge

K-way merge is a technique that combines K sorted lists into a single sorted sequence. You insert only the head element of each list into a heap, and each time you extract the minimum (or maximum), you add the next element from the list to which the extracted element belonged into the heap. This technique merges in O(N log K), which is more efficient than sorting all elements together in O(N log N).

## Complexity

| | Value |
|---|---|
| Time | O(K log K) — K is the number of followed users. The initial insertion into the heap takes O(K log K), and up to 10 poll/offer operations take O(10 log K). |
| Space | O(K) — The heap stores at most K elements simultaneously. |

## Code

```java
// Input: operation calls for postTweet(userId, tweetId), follow(followerId, followeeId), unfollow(followerId, followeeId), getNewsFeed(userId)
// Output: getNewsFeed returns the 10 most recent tweet IDs from the user and their followees as a List<Integer>
class Twitter {
    // Global timestamp that uniquely identifies posting order across all users' tweets (monotonically increasing)
    int time = 0;
    // Key = user ID, Value = that user's tweet list (each element is [timestamp, tweetId])
    // The list appends to the tail in posting order, so the tail is the most recent
    Map<Integer, List<int[]>> tweets;
    // Key = follower's user ID, Value = Set of followee user IDs
    // Using a Set enables O(1) follow addition, removal, and deduplication
    Map<Integer, Set<Integer>> follows;

    Twitter() {
        tweets = new HashMap<>();
        follows = new HashMap<>();
    }

    void postTweet(int userId, int tweetId) {
        // Retrieve the user's tweet list (create one if it doesn't exist) and append [timestamp, tweetId] to the tail
        // Since time++ increases monotonically across all users, you can correctly compare posting order across users
        tweets.computeIfAbsent(userId, k -> new ArrayList<>())
            .add(new int[]{time++, tweetId});
    }

    void follow(int followerId, int followeeId) {
        // Add followeeId to the followee Set (the Set prevents duplicates even if the same user is followed twice)
        follows.computeIfAbsent(followerId, k -> new HashSet<>())
            .add(followeeId);
    }

    void unfollow(int followerId, int followeeId) {
        // Remove followeeId from the Set only if the follow relationship exists. Do nothing if it doesn't exist
        if (follows.containsKey(followerId))
            follows.get(followerId).remove(followeeId);
    }

    List<Integer> getNewsFeed(int userId) {
        // Max-Heap: specify a Comparator so that the largest (most recent) timestamp comes first
        PriorityQueue<int[]> pq =
            new PriorityQueue<>((a, b) -> b[0] - a[0]);

        // Target users for the feed = self + all followed users
        // You must include yourself because your own tweets should appear in the feed
        Set<Integer> users = new HashSet<>();
        users.add(userId);
        if (follows.containsKey(userId))
            users.addAll(follows.get(userId));

        // Add each user's most recent tweet (tail of the list) to the heap
        // Include the user ID and index so you can traverse to that user's next tweet after extraction
        for (int uid : users) {
            if (!tweets.containsKey(uid)) continue;
            List<int[]> t = tweets.get(uid);
            int idx = t.size() - 1;
            int[] tw = t.get(idx);
            // 4-element array: [timestamp, tweetId, userId, index within the list]
            pq.offer(new int[]{tw[0], tw[1], uid, idx});
        }

        // Extract up to 10 items from the heap (terminate early if the heap is empty or 10 items are reached)
        List<Integer> res = new ArrayList<>();
        while (!pq.isEmpty() && res.size() < 10) {
            // Extract the element with the largest timestamp
            int[] top = pq.poll();
            // Add the extracted tweet ID to the result
            res.add(top[1]);
            int uid = top[2];
            // Decrement the index by one to point to that user's next most recent tweet
            int idx = top[3] - 1;
            // If the user has more tweets, add the next one to the heap (a negative index means all tweets are processed)
            if (idx >= 0) {
                int[] tw = tweets.get(uid).get(idx);
                pq.offer(new int[]{tw[0], tw[1], uid, idx});
            }
        }
        // The result contains the 10 most recent tweet IDs (or all tweets if fewer than 10) in descending timestamp order
        return res;
    }
}
```
