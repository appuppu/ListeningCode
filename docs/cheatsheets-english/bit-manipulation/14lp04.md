# Reversing the Digits of an Integer — Reverse each digit of a 32-bit signed integer

## Problem

The function receives a 32-bit signed integer `x`. It returns the integer formed by reversing the digits of `x`. If the reversed value exceeds the 32-bit signed integer range (−2³¹ to 2³¹−1), the function returns `0`.

## Key Insight

The operator `x % 10` extracts the last digit of the integer, and `x / 10` removes that last digit. Repeating this "extract and stack" operation naturally reverses the order of the digits. Checking for overflow before each multiplication ensures that the function builds the reversed result safely.

## Thought Process

1. **How to extract digits one by one**: The operator `x % 10` (remainder when divided by 10) retrieves the last digit of the integer. After extraction, `x / 10` removes the last digit, exposing the next digit. Repeating this operation until `x` becomes 0 extracts every digit from last to first.
2. **How to assemble the extracted digits in reverse order**: The loop applies `result = result * 10 + digit` repeatedly. The expression `result * 10` shifts all existing digits one place to the left, and `+ digit` places the new digit in the ones place. Because the loop extracts digits from the tail and places them from the head, the digit order naturally reverses.
3. **How to handle overflow**: The expression `result * 10 + digit` may exceed `Integer.MAX_VALUE` (2147483647) or fall below `Integer.MIN_VALUE` (−2147483648). Checking **after** the multiplication is too late, so the function must check **before** the multiplication.
4. **How to check for overflow in advance**: The function determines whether `result * 10` will overflow by comparing `result` with `Integer.MAX_VALUE / 10` (= 214748364). If `result > 214748364`, the multiplication will definitely overflow. If `result == 214748364`, the multiplication overflows when `digit > 7` (the ones digit of MAX_VALUE). The function applies the same logic for negative values using `Integer.MIN_VALUE / 10`.
5. **How the function handles sign**: In Java, `x % 10` and `x / 10` work correctly for negative numbers (`-123 % 10 == -3`, `-123 / 10 == -12`). Therefore, the function processes negative numbers directly without separating the sign.
6. **What the function returns**: After the loop ends, `result` holds the reversed integer. If the function detects overflow inside the loop, it immediately returns `0`.

## Prerequisites

### The % Operator (Modulo Operator)

The modulo operator returns the remainder when one integer is divided by another. The expression `x % 10` extracts the ones digit of `x`. In Java, the operator preserves the sign for negative numbers.

```java
123 % 10;    // → 3 (extracts the ones digit)
-123 % 10;   // → -3 (preserves the sign for negative numbers)
123 / 10;    // → 12 (removes the ones digit)
-123 / 10;   // → -12 (truncates correctly for negative numbers)
```

### The Range of a 32-bit Signed Integer

This range defines the values that Java's `int` type can represent. Exceeding this range causes overflow, which produces an incorrect value.

```java
Integer.MAX_VALUE;   // → 2147483647 (2³¹ - 1)
Integer.MIN_VALUE;   // → -2147483648 (-2³¹)
Integer.MAX_VALUE / 10;  // → 214748364 (threshold for overflow detection)
Integer.MAX_VALUE % 10;  // → 7 (the ones digit of MAX_VALUE)
Integer.MIN_VALUE / 10;  // → -214748364
Integer.MIN_VALUE % 10;  // → -8 (the ones digit of MIN_VALUE)
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — n is the number of digits in `x`. The function processes each digit exactly once. |
| Space | O(1) — The function uses only the variables `result` and `digit`. |

## Code

```java
// Input: a 32-bit signed integer x
// Output: the integer with the digits of x reversed. Returns 0 if the reversed value exceeds the 32-bit range.
public int reverse(int x) {
    // Variable to store the reversed result. The loop builds it by stacking one digit at a time.
    int result = 0;

    // Extract digits from x one by one starting from the last. The loop ends when x becomes 0.
    while (x != 0) {
        // Extract the ones digit of x. The % operator preserves the sign for negative numbers, so no special handling is needed.
        int digit = x % 10;

        // Check for positive overflow before the multiplication (checking afterward would be too late).
        // If result > 214748364, then result * 10 will definitely exceed MAX_VALUE (2147483647).
        // If result == 214748364 and digit > 7, then result * 10 + digit will exceed MAX_VALUE (whose last digit is 7).
        if (result > Integer.MAX_VALUE / 10
                || (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return 0;
        }

        // Check for negative overflow before the multiplication.
        // If result < -214748364, then result * 10 will definitely fall below MIN_VALUE (-2147483648).
        // If result == -214748364 and digit < -8, then result * 10 + digit will fall below MIN_VALUE (whose last digit is -8).
        if (result < Integer.MIN_VALUE / 10
                || (result == Integer.MIN_VALUE / 10 && digit < -8)) {
            return 0;
        }

        // result * 10 shifts the existing digits one place to the left, and + digit places the extracted digit in the ones place.
        // This positions each tail digit of the original number at the head side of the result in sequence.
        result = result * 10 + digit;

        // Remove the ones digit of x to expose the next digit at the tail.
        x = x / 10;
    }

    // Return the fully reversed result. If overflow was detected, the function already returned 0 inside the loop.
    return result;
}
```
