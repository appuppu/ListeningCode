# Finding the Missing Number in a Sequence — Find the one missing number from a consecutive sequence of 0 to n

## Problem

You are given an array `nums` containing n distinct integers from 0 to n. Find and return the **one missing number** that is within this range but does not exist in the array.

## Key Insight

XOR cancels out to zero when the same value is applied twice. If you XOR all array indices (0 to n-1), the value n, and all elements of the array together, paired numbers cancel each other out, and only the unpaired "missing number" remains.

## Thought Process

1. **Every number except the missing one forms a pair**: The array indices range from 0 to n-1, and the array values cover the range 0 to n minus the missing number. If you add n as an initial value on the index side, all integers from 0 to n are represented on the index side. Only the missing number has no counterpart on the array value side, so it remains unpaired.
2. **XOR is the optimal operation for canceling pairs**: XOR has the properties `a ^ a = 0` (identical values cancel each other out) and `a ^ 0 = a` (XOR with zero preserves the value). If you XOR all indices and values together, every paired number becomes 0, and only the unpaired missing number remains.
3. **The initial value is set to n for a reason**: The for loop index only covers the range 0 to n-1. However, the missing number could be n itself, so setting the initial XOR value to n ensures coverage of the entire range 0 to n.
4. **The algorithm completes in a single loop**: By performing `xor ^= i` (XOR of the index) and `xor ^= nums[i]` (XOR of the value) simultaneously within the loop, you obtain the result with just one pass through the array. No additional data structures are needed.

## Prerequisites

### What Is XOR (Exclusive OR)?

XOR is a bitwise operation that returns 1 when two bits are different and 0 when they are the same. In Java, you use the `^` operator. The operation is applied bit by bit to integers.

```java
int a = 5;          // Binary: 101
int b = 3;          // Binary: 011
int result = a ^ b; // Binary: 110 → 6
```

### Important Properties of XOR

There are three properties that form the foundation of this algorithm.

```java
// Property 1: XOR of the same value is 0 (cancellation)
5 ^ 5;    // → 0

// Property 2: XOR with 0 preserves the original value
5 ^ 0;    // → 5

// Property 3: The result is the same regardless of order (commutative and associative laws)
(2 ^ 5) ^ 2;  // → 5 (the two 2s cancel each other out, leaving 5)
```

### What Is the ^= Operator?

The `^=` operator is a compound assignment operator that assigns the result of a XOR operation to the variable on the left side. `xor ^= i` means the same thing as `xor = xor ^ i`.

```java
int xor = 0;
xor ^= 3;   // xor = 0 ^ 3 → 3
xor ^= 3;   // xor = 3 ^ 3 → 0 (canceled out by the same value)
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — Only a single pass through the array is needed |
| Space | O(1) — No additional data structures are used; only a single variable is needed |

## Code

```java
// Input: an array nums containing n distinct integers from the range 0 to n
// Output: return the one integer in the range that is not in the array
public int missingNumber(int[] nums) {
    // Setting the initial value to n ensures coverage of the entire range 0 to n,
    // combined with the loop indices 0 to n-1.
    // The for loop index only covers 0 to n-1, so n is provided here as the initial value.
    int xor = nums.length;

    for (int i = 0; i < nums.length; i++) {
        // Fold index i into the XOR accumulator.
        // By the end of the loop, all indices 0 to n-1 have been XORed (combined with the initial value n, all integers 0 to n are XORed).
        xor ^= i;
        // Fold the array value into the XOR accumulator.
        // Numbers that exist in the array appear on both the index side and the value side, so they cancel out by the property a ^ a = 0.
        xor ^= nums[i];
    }

    // All paired numbers have been canceled out to 0, and only the missing number remains because it had no pair.
    return xor;
}
```
