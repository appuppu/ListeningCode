# Merging Two Sorted Linked Lists — Merge two sorted linked lists into one

## Problem

You are given two sorted linked lists `list1` and `list2`. Merge them into a single sorted linked list and return the **head node** of the merged list.

## Key Insight

You compare the head nodes of the two lists and select the smaller one as the head of the merged result. The remaining part is the result of merging "the next node of the smaller one" with "the other list," which has the same structure as the original problem, so you can solve it with recursion.

## Thought Process

1. **Each step of the merge does the same thing**: You compare the head nodes of the two lists and select the smaller one. This operation repeats until one list becomes empty. Because you make the same decision every time, you can express it with recursion.
2. **Consider the base case**: If one list is empty (null), you simply return the other list. If both are empty, you return null (this is covered by the case where one is null).
3. **Consider the recursive step**: If `list1.val <= list2.val`, then `list1` becomes the head. You connect the result of merging "the rest of `list1`" and "all of `list2`" to `list1.next`. In the opposite case, you make `list2` the head and process it similarly.
4. **Each recursive call reduces the problem size by one**: Each call consumes one node from either list, so a total of n recursive calls process all nodes.
5. **What you ultimately return**: Each recursive call returns the chosen node (`list1` or `list2`). The node returned by the first call becomes the head of the merged list.

## Prerequisites

### What is a ListNode (linked list node)?

A ListNode is a class that represents each element of a linked list. The `val` field holds the value, and the `next` field holds a reference to the next node. A node whose `next` is null is the tail of the list.

```java
class ListNode {
    int val;          // The value held by this node
    ListNode next;    // Reference to the next node (null if this is the tail)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### What is Recursion?

Recursion is a technique where a function solves a problem by calling itself. It decomposes a large problem into smaller problems with the same structure and returns a result when it reaches a base case (the smallest problem that cannot be decomposed further). Each call pushes a frame onto the call stack, so recursion consumes space proportional to its depth.

```java
// Example: computing factorial
int factorial(int n) {
    if (n <= 1) return 1;           // Base case: do not decompose further
    return n * factorial(n - 1);    // Recursive step: reduce the problem size by one and call itself
}
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — The algorithm processes all nodes in n recursive calls, where n is the total number of nodes in the two lists |
| Space | O(n) — Each recursive call pushes a frame onto the call stack, reaching a maximum depth of n |

## Code

```java
// Input: head nodes list1 and list2 of two sorted linked lists
// Output: return the head node of the merged sorted linked list as a ListNode
ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    // Base case: if list1 is empty, return the remaining list2 as-is (since list1 is empty, list2 itself becomes the merge result)
    if (list1 == null) return list2;
    // Base case: if list2 is empty, return the remaining list1 as-is (since list2 is empty, list1 itself becomes the merge result)
    if (list2 == null) return list1;

    // Compare the heads of list1 and list2 to decide which node to place at the head of the merge result
    if (list1.val <= list2.val) {
        // Select list1 as the head, and connect the result of merging list1's remainder (list1.next) with all of list2 to list1's next
        list1.next = mergeTwoLists(list1.next, list2);
        return list1; // list1 becomes the head node of the merge result
    } else {
        // Select list2 as the head, and connect the result of merging all of list1 with list2's remainder (list2.next) to list2's next
        list2.next = mergeTwoLists(list1, list2.next);
        return list2; // list2 becomes the head node of the merge result
    }
}
```
