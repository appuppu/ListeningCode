# Detecting a Cycle in a Linked List — Determine whether a cycle exists in a linked list

## Problem

You are given the head node `head` of a singly linked list. Return `true` if any node's `next` pointer points to a previously visited node (a cycle exists), and return `false` if no cycle exists.

## Key Insight

When you run two pointers at different speeds simultaneously, they will always catch up and meet if a cycle exists. If no cycle exists, the faster pointer will reach the end first. This property allows you to detect a cycle without using any additional data structures.

## Thought Process

1. **Consider the nature of a cycle**: When you traverse a list that contains a cycle, the traversal never reaches the end (null) and loops forever. Conversely, if no cycle exists, the traversal always reaches null and terminates
2. **Use pointers with different speeds**: Prepare a pointer that advances 1 step at a time (slow) and a pointer that advances 2 steps at a time (fast). Inside a cycle, fast closes the distance to slow by 1 node per step, so the two pointers will always meet
3. **Why meeting proves a cycle exists**: If no cycle exists, fast reaches null first, so slow and fast can never point to the same node. If the two pointers meet, a cycle exists
4. **Define the termination conditions**: If fast or fast.next becomes null, the list has an end, so no cycle exists. If slow and fast point to the same node, a cycle exists
5. **Set the initial positions**: Place slow at head and fast at head.next. This ensures that the while loop condition `slow != fast` holds from the start, allowing the traversal to begin inside the loop
6. **Determine the return value**: Return `true` if slow and fast meet, and return `false` if fast reaches null

## Prerequisites

### ListNode (a node in a linked list)

A ListNode is an individual element that makes up a linked list. Each node holds a "value" and a "pointer to the next node." The last node's next points to null (when no cycle exists).

```java
class ListNode {
    int val;            // The value the node holds
    ListNode next;      // A reference to the next node (null if none)
}

ListNode node = head;       // Get the head node
node.next;                  // Get the next node
node.next.next;             // Get the node two positions ahead
```

### Floyd's Tortoise and Hare (Floyd's cycle detection algorithm)

Floyd's Tortoise and Hare is an algorithm that detects a cycle using two pointers moving at different speeds. The slow pointer advances 1 step at a time, and the fast pointer advances 2 steps at a time. Inside a cycle, fast approaches slow by 1 node per step, so the two pointers are guaranteed to meet within a finite number of steps if a cycle exists.

```java
ListNode slow = head;       // A pointer that advances 1 step at a time
ListNode fast = head.next;  // A pointer that advances 2 steps at a time
slow = slow.next;           // Advance slow by 1
fast = fast.next.next;      // Advance fast by 2
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — If no cycle exists, fast reaches the end in n/2 steps. If a cycle exists, the two pointers meet within at most the length of the cycle |
| Space | O(1) — The algorithm uses only two pointer variables and requires no additional data structures |

## Code

```java
// Input: the head node head of a singly linked list
// Output: return true if a cycle exists, false otherwise
public boolean hasCycle(ListNode head) {
    // If the list has 0 or 1 nodes, no cycle can exist. Return false
    if (head == null || head.next == null) {
        return false;
    }

    // Place slow at head and fast at head.next
    // Placing fast one position ahead ensures the while condition slow != fast holds from the start
    ListNode slow = head;
    ListNode fast = head.next;

    // Repeat the loop until slow and fast meet (exit when they meet)
    while (slow != fast) {
        // If fast is null or fast.next is null, the list has an end, so no cycle exists
        if (fast == null || fast.next == null) {
            return false;
        }
        // Advance slow by 1 step and fast by 2 steps
        // Due to the speed difference, fast approaches slow by 1 node per step inside a cycle
        slow = slow.next;
        fast = fast.next.next;
    }

    // The while condition slow != fast became false, meaning slow and fast met, so a cycle exists
    return true;
}
```
