# Reversing Nodes in Groups of K — Reverse Each Group of K Nodes in a Singly Linked List

## Problem

You are given the head node `head` of a singly linked list and an integer `k`. You divide the list into groups of `k` nodes from the beginning and reverse the order of nodes within each group. If the last group contains fewer than `k` nodes, you leave that group as is. You return the head node of the modified list.

## Key Insight

You place a dummy node at the beginning and use "the node immediately before the group" and "the k-th node of the group" as reference points. You reassign the pointers one by one within each group, which allows you to reverse the group in place without additional memory.

## Thought Process

1. **You need to reverse the list in groups of k**: You reverse not the entire list but each group of k nodes. This means the loop structure follows the pattern: "identify the range of the current group" → "reverse that group" → "move to the next group."
2. **You find the k-th node to identify the group's range**: You prepare a helper function `getKth` that finds the node k positions ahead from the current position. If the k-th node does not exist (`null`), the remaining nodes number fewer than k, so you stop without reversing.
3. **You need to connect groups correctly after reversal**: Reversing a group swaps its head and tail. You must reconnect `groupPrev` (the tail of the previous group) so that it points to the new head of the reversed group (the original k-th node).
4. **A dummy node lets you handle the first group's reversal uniformly**: Reversing the first group changes the head of the entire list. By placing a dummy node at the beginning, you can apply the same logic — "the node before the group points to the new head" — to both the first group and all subsequent groups.
5. **You reverse each group using the standard list reversal technique**: You use two pointers, `prev` and `curr`, and reassign `curr.next` to `prev` while advancing one node at a time. By initializing `prev` to the node after the group (`groupNext`), the tail of the reversed group automatically connects to the next group.
6. **You update groupPrev after reversal and move to the next group**: The node that was the head of the group before reversal (`groupPrev.next`) becomes the tail of the group after reversal. You use this node as `groupPrev` for the next iteration.

## Prerequisites

### What Is a ListNode

A ListNode is a class that represents one node of a singly linked list. Each node holds a "value (val)" and a "pointer to the next node (next)." The node whose `next` is `null` is the tail of the list.

```java
class ListNode {
    int val;          // The value the node holds
    ListNode next;    // Reference to the next node (null if this is the tail)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### What Is a Dummy Node

A dummy node is a technique where you add a temporary node at the beginning of the list. When the head node may change, a dummy node eliminates the need for special-case handling. `dummy.next` always points to the actual head of the list.

```java
ListNode dummy = new ListNode(0);  // The value can be anything
dummy.next = head;                 // The dummy's next points to the actual head
// ... manipulate the list ...
return dummy.next;                 // Return the actual head after manipulation
```

### Basic Operation for Reversing a Linked List

You use two pointers, `prev` and `curr`, and reassign each node's `next` to point to the previous node.

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode tmp = curr.next;  // Temporarily save the next node
    curr.next = prev;          // Change the current node's next to the previous node
    prev = curr;               // Advance prev to the current node
    curr = tmp;                // Advance curr to the next node
}
// prev is now the head node of the reversed list
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — You visit each node a constant number of times (once for finding the k-th node and once for reversal) |
| Space | O(1) — You use only pointer variables and require no additional data structures |

## Code

```java
// Input: the head node of a linked list head and an integer k
// Output: return the head node of the linked list with each group of k nodes reversed
public ListNode reverseKGroup(ListNode head, int k) {
    // Create a dummy node and connect it to the actual head of the list with dummy.next = head
    // The dummy node ensures that "the node immediately before the group" always exists, even for the first group
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // groupPrev points to "the node immediately before the group about to be reversed"
    // Its initial value is the dummy node
    ListNode groupPrev = dummy;

    // An infinite loop reverses one group per iteration
    while (true) {
        // Starting from the node after groupPrev, follow next k-1 times to find the k-th node
        // If null is reached along the way, the remaining nodes number fewer than k, so return null
        ListNode kth = getKth(groupPrev, k);

        // If the k-th node does not exist, the remaining nodes number fewer than k, so stop
        // This check satisfies the problem's requirement to leave groups of fewer than k nodes as is
        if (kth == null) break;

        // groupNext is "the node immediately after the current group" and serves as the end marker for reversal
        ListNode groupNext = kth.next;

        // Set the initial value of prev to groupNext
        // This way, the next pointer of the group's tail node after reversal automatically points to the head of the next group
        ListNode prev = kth.next;
        // curr starts at the head node of the group (this node will become the tail of the group after reversal)
        ListNode curr = groupPrev.next;

        // Reverse the next pointer of each node within the group until curr equals groupNext
        // This operation changes each node's next to point to the preceding node
        while (curr != groupNext) {
            ListNode tmp = curr.next;  // Temporarily save the next node
            curr.next = prev;          // Change the current node's next to the previous node
            prev = curr;               // Advance prev to the current node
            curr = tmp;                // Advance curr to the next node
        }

        // Save the node that was the head before reversal (it is now the tail of the group after reversal)
        ListNode tmp = groupPrev.next;
        // The head of the reversed group is kth (the original k-th node),
        // so connect the tail of the previous group to correctly point to the new head after reversal
        groupPrev.next = kth;
        // The node that was the head of the group before reversal is now the tail after reversal
        // Use this node as groupPrev for the next iteration
        groupPrev = tmp;
    }

    // dummy.next points to the head node of the entire list after all operations
    return dummy.next;
}

// Return the k-th node starting from the node after the given node. Return null if fewer than k nodes remain
private ListNode getKth(ListNode node, int k) {
    // Start from the node after the given node
    node = node.next;
    // Follow next k-1 times to reach the k-th node
    // If null is reached along the way, the remaining nodes number fewer than k
    while (node != null && k > 1) {
        node = node.next;
        k--;
    }
    // Return the k-th node (null if fewer than k nodes remained)
    return node;
}
```
