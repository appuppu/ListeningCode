# Reordering a Linked List by Interleaving Ends

## Problem

You are given a singly linked list L0 → L1 → … → Ln-1 → Ln. You must reorder this list **in-place** into the order L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → …. You must achieve this by manipulating only the node links (next pointers), without changing any node values.

## Key Insight

If you reverse the second half of the list, you can produce the target order by simply alternating nodes from "the beginning of the first half" and "the beginning of the second half (which was originally the tail)." To reverse the second half, you first find the midpoint of the list and split it into two halves.

## Thought Process

1. **Observe the structure after reordering**: The order L0 → Ln → L1 → Ln-1 → … is the result of alternately taking elements from the "head" and "tail" of the list. This means you need to alternately merge two sequences: one from the head side and one from the tail side.
2. **Extracting elements from the tail requires reversal**: In a singly linked list, accessing the tail costs O(n). However, if you reverse the second half of the list, the head of the reversed half becomes the original tail, and you can retrieve tail-side elements simply by traversing forward from the head.
3. **Find the midpoint of the list**: To reverse the second half, you first need to determine where to split the list. Using slow/fast pointers (the tortoise and hare technique), you can find the midpoint in a single pass. The slow pointer advances one step at a time, the fast pointer advances two steps at a time, and when the fast pointer reaches the end of the list, the slow pointer points to the midpoint.
4. **Reverse the second half**: Starting from the node after the midpoint, you redirect each node's next pointer to point to the previous node, thereby reversing the second half of the list. A prev variable tracks the preceding node, and after the loop completes, prev becomes the head of the reversed portion.
5. **Alternately merge the first half and the reversed second half**: You traverse both the first-half list and the second-half list from their respective heads, inserting each second-half node after the corresponding first-half node. Because each step reassigns next pointers, you must save the original links in temporary variables before overwriting them.
6. **The second half is shorter than or equal in length to the first half**: For odd-length lists, the first half is one node longer, so the merge loop condition uses `second != null`. The merge is complete when the second half runs out of nodes.

## Prerequisites

### What Is the Slow/Fast Pointer (Tortoise and Hare) Technique?

The slow/fast pointer technique finds the midpoint of a linked list in a single pass. The slow pointer advances one node at a time, and the fast pointer advances two nodes at a time. When the fast pointer reaches the end of the list, the slow pointer points to the midpoint.

```java
ListNode slow = head, fast = head;
while (fast.next != null && fast.next.next != null) {
    slow = slow.next;        // slow advances one step
    fast = fast.next.next;   // fast advances two steps
}
// After the loop, slow points to the middle node of the list
```

### What Is Linked List Reversal?

Linked list reversal is the operation of redirecting each node's next pointer to point to the previous node instead of the next node. You traverse one node at a time while tracking prev (the preceding node), and reverse the direction of each link.

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode nxt = curr.next;  // Save the next node
    curr.next = prev;          // Point the link to the previous node
    prev = curr;               // Update prev to the current node
    curr = nxt;                // Advance to the next node
}
// After the loop, prev points to the head of the reversed list
```

### What Is Alternating Merge of Two Lists?

Alternating merge is the operation of taking one element at a time from each of two lists in alternation and connecting them into a single list. Because each step reassigns next pointers, you must save the original links in temporary variables before overwriting them.

```java
ListNode a = list1, b = list2;
while (b != null) {
    ListNode tmpA = a.next;   // Save a's original next
    ListNode tmpB = b.next;   // Save b's original next
    a.next = b;               // Insert b after a
    b.next = tmpA;            // Connect a's original next after b
    a = tmpA;                 // Advance a to the next position
    b = tmpB;                 // Advance b to the next position
}
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — Each step (finding the midpoint, reversing the second half, and merging) takes O(n) |
| Space | O(1) — The algorithm uses only pointer variables and creates no additional data structures |

## Code

```java
// Input: head, the head node of a singly linked list
// Output: none (the list is reordered in-place; the return type is void)
void reorderList(ListNode head) {
    // An empty list does not need reordering
    if (head == null) return;

    // Step 1: Find the midpoint of the list using slow/fast pointers
    // fast advances at twice the speed of slow, so when fast reaches the end, slow points to the middle node
    ListNode slow = head, fast = head;
    while (fast.next != null
            && fast.next.next != null) {
        slow = slow.next;          // slow advances one step
        fast = fast.next.next;     // fast advances two steps
    }

    // Step 2: Detach and reverse the second half of the list
    ListNode second = slow.next;   // second is the head node of the second half
    slow.next = null;              // Cut the tail of the first half to split the list into two halves
    ListNode prev = null;
    while (second != null) {
        ListNode nxt = second.next;  // Save the next node
        second.next = prev;          // Point the link to the previous node
        prev = second;               // Update prev to the current node
        second = nxt;                // Advance to the next node
    }
    // After the loop, prev points to the head of the reversed second half (the original tail of the list)

    // Step 3: Alternately merge the first half and the reversed second half
    ListNode first = head;         // Head of the first half
    second = prev;                 // Head of the reversed second half
    // For odd-length lists, the first half is one node longer, so the loop ends when the second half (second) is exhausted
    while (second != null) {
        ListNode tmp1 = first.next;   // Save the next node of the first half (without saving, overwriting next would lose the original link target)
        ListNode tmp2 = second.next;  // Save the next node of the second half
        first.next = second;          // Insert the second-half node after the first-half node
        second.next = tmp1;           // Connect the continuation of the first half after the second-half node
        first = tmp1;                 // Advance the first-half pointer to the next position
        second = tmp2;                // Advance the second-half pointer to the next position
    }
}
```
