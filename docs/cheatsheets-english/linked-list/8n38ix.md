# Removing the Nth Node From the End of a List

## Problem

You are given the head node `head` of a singly linked list and an integer `n`. You must remove the **Nth node from the end** of the list and return the head node of the modified list.

## Key Insight

If you advance two pointers simultaneously with a gap of N nodes between them, the trailing pointer will be positioned just before the target node when the leading pointer reaches the end of the list. This approach completes the removal in a single pass.

## Thought Process

1. **Finding the Nth node from the end seems to require the list length**: A naive approach would traverse the entire list once to determine the length L, then traverse again to find the (L-N)th node, requiring two passes. However, using two pointers reduces this to a single pass.
2. **Use two pointers with a gap of N nodes**: You advance the fast pointer N nodes ahead of the slow pointer. Then you move both pointers forward one node at a time simultaneously. When fast reaches the end of the list, slow is at exactly the (N+1)th position from the end — meaning slow points to the node **immediately before** the target node.
3. **Why you add a dummy node at the head**: When the target node is the head node itself, no "node immediately before the target" exists. Placing a dummy node before head allows the removal of the head node to use the same logic as removing any other node.
4. **Advance fast by N nodes**: A for loop advances fast N times. At this point, N nodes exist between slow and fast.
5. **Advance both pointers simultaneously**: While `fast.next != null`, you advance both slow and fast by one node at a time. The loop exits when fast's **next** becomes null. At that point, fast points to the last node in the list, and slow points to the (N+1)th node from the end (the node immediately before the target).
6. **Remove the node and return the list**: The node after slow is the target, so `slow.next = slow.next.next` rewires the link to remove it. Finally, you return `dummy.next` instead of head, because head itself may have been the removed node.

## Prerequisites

### What is a ListNode?

A ListNode is a class that represents a single node in a singly linked list. Each node holds a value `val` and a reference `next` to the next node. A node whose `next` is null is the tail of the list.

```java
ListNode node = new ListNode(5);  // Create a node with value 5; next is null
node.next = new ListNode(10);     // The list becomes node → 10 → null
```

### What is a Dummy Node (Sentinel Node)?

A dummy node is a valueless sentinel node added at the head of the list. It ensures that a "node before the target" always exists even when you remove the head node, eliminating the need for special-case handling of the head.

```java
ListNode dummy = new ListNode(0);  // Create a dummy node
dummy.next = head;                 // Point the dummy's next to the original head
// After processing, dummy.next becomes the new head node
```

### What is the Two-Pointer Technique?

The two-pointer technique moves two pointers at different speeds or with a fixed gap to efficiently locate a specific position in a list. In this problem, you move two pointers at the same speed with a gap of N nodes to identify the Nth position from the end.

```java
ListNode slow = head;
ListNode fast = head;
// Advance fast N nodes ahead, then move both forward simultaneously
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — The algorithm requires only a single pass through the list |
| Space | O(1) — The algorithm uses only a dummy node and two pointers |

## Code

```java
// Input: the head node of a singly linked list head and an integer n
// Output: return the head ListNode of the list after removing the Nth node from the end
public ListNode removeNthFromEnd(ListNode head, int n) {
    // Add a dummy node with value 0 at the head of the list
    // The dummy node ensures that a "node immediately before the target" exists even when removing the head node
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // Start both pointers from the dummy node
    // Starting from the dummy node ensures that slow ends up correctly positioned just before the target
    ListNode slow = dummy;
    ListNode fast = dummy;

    // Advance fast by N nodes to create a gap of N nodes between slow and fast
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }

    // Advance both pointers simultaneously and stop when fast reaches the end of the list
    // The condition fast.next != null ensures that when fast reaches the last node,
    // slow is positioned just before the target node
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // slow.next is the target node. Rewire slow's next pointer to skip one node ahead, removing the target from the list
    slow.next = slow.next.next;

    // Return dummy.next instead of head because head may have been the removed node, and dummy.next correctly points to the new head
    return dummy.next;
}
```
