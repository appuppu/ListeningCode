# Finding the Largest Rectangle in a Histogram — Find the area of the largest rectangle that can be formed within a histogram

## Problem

You are given an array of non-negative integers `heights`. Each element represents the height of a bar in a histogram, and every bar has a width of 1. Find and return the **area of the largest rectangle** that can be formed within this histogram.

## Key Insight

If you treat each bar as the height of a rectangle, you can compute the area once you know how far that bar can extend left and right as the shortest bar in the range. By using a monotonically increasing stack, you can determine the extendable width of each bar in O(1) time at the moment the bar height decreases.

## Thought Process

1. **Consider a rectangle with each bar as its height**: You can view any rectangle as "bounded by the height of some bar and composed of consecutive bars extending left and right." In other words, if you know "the width of the interval where `heights[i]` is the shortest bar" for each bar `heights[i]`, you can compute the area as `heights[i] × width`.
2. **Find the left and right boundaries efficiently**: If you know "the position of the first bar shorter than the current bar on the left" and "the position of the first bar shorter than the current bar on the right" for each bar, you can determine the extendable width. Searching these two boundaries naively for every bar takes O(n²), so you use a stack to optimize the process.
3. **Use a monotonically increasing stack**: You push bar indices onto the stack so that the heights remain in monotonically increasing order. When the current bar's height is lower than the height of the bar at the top of the stack, you determine that the "right boundary" for the bar at the top of the stack is the current position `i`.
4. **Calculate the width upon popping**: When you pop bar `top` from the stack, the right boundary is the current position `i`, and the left boundary is the position right after the new top of the stack. If the stack is empty, the bar can extend all the way to the left edge (index 0), so the width is `i`. If the stack is not empty, the width is `i - stack.peek() - 1`.
5. **Add a sentinel of height 0 at the end**: When you reach the end of the array, you still need to compute the area for the bars remaining in the stack. By setting the loop range to `i <= heights.length` and virtually placing a bar of height 0 when `i == heights.length`, you guarantee that every bar in the stack gets popped.
6. **Track the maximum area**: Each time you pop a bar, you calculate `heights[top] × width` and update the maximum value. The maximum value after all pops are complete is the answer.

## Prerequisites

### Stack

A stack is a last-in, first-out (LIFO) data structure. The element added last is the first one to be removed. In the histogram problem, you use a stack to store bar indices and maintain monotonicity of heights.

```java
Stack<Integer> stack = new Stack<>();  // Create an empty stack
stack.push(0);       // Push the value 0 onto the top of the stack
stack.peek();        // Read the value at the top of the stack without removing it → 0
stack.pop();         // Remove and return the value at the top of the stack → 0
stack.isEmpty();     // Return a boolean indicating whether the stack is empty → true
```

### Monotonic Stack

A monotonic stack maintains the invariant that elements always increase (or remain equal) from bottom to top. When you add a new element, if it is smaller than the top of the stack, you pop the top until the top is no longer greater than the new value. At the moment of each pop, you can interpret it as "the right boundary of the popped element has been determined."

```java
// Monotonic increasing stack behavior for the array [2, 1, 5, 6, 2, 3]
// i=0: push(0)             → stack: [0]       (heights: [2])
// i=1: 1 < 2, so pop       → stack: []        (right boundary of height-2 bar is determined as i=1)
//       push(1)             → stack: [1]       (heights: [1])
// i=2: push(2)             → stack: [1,2]     (heights: [1,5])
// i=3: push(3)             → stack: [1,2,3]   (heights: [1,5,6])
// i=4: 2 < 6, so pop       → stack: [1,2]     (right boundary of height-6 bar is determined as i=4)
//       2 < 5, so pop       → stack: [1]       (right boundary of height-5 bar is determined as i=4)
//       push(4)             → stack: [1,4]     (heights: [1,2])
```

### Sentinel

A sentinel is a virtual value added to simplify end-of-loop processing. In this problem, you virtually place a bar of height 0 at the end of the array, which forces every bar remaining in the stack to be popped naturally when the loop finishes.

```java
// When i == heights.length, use a virtual height of 0 since i is outside the actual array
int h = (i == heights.length) ? 0 : heights[i];
// Height 0 is lower than any bar, so every bar in the stack gets popped
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — Each bar is pushed onto the stack once and popped once, so the total number of operations is O(n) |
| Space | O(n) — The stack stores at most n indices |

## Code

```java
// Input: an array of non-negative integers heights (each element represents the height of a histogram bar)
// Output: return the area of the largest rectangle that can be formed within the histogram as an int
public int largestRectangleArea(int[] heights) {
    // Stack to hold bar indices in monotonically increasing order of height
    Stack<Integer> stack = new Stack<>();
    // Variable to track the largest area found so far
    int maxArea = 0;

    // Use i <= heights.length to include sentinel processing
    // When i == heights.length, the sentinel (height 0) forces all remaining bars to be popped
    for (int i = 0; i <= heights.length; i++) {
        // Sentinel: use height 0 when past the end of the array. Height 0 is lower than any bar, guaranteeing that every bar in the stack gets popped
        int h = (i == heights.length) ? 0 : heights[i];

        // While the current height is lower than the bar at the top of the stack, calculate the area
        // This condition maintains the monotonically increasing invariant of the stack
        while (!stack.isEmpty() && h < heights[stack.peek()]) {
            // Pop the bar and use it as the height of the rectangle. The right boundary of this bar is the current position i
            int top = stack.pop();

            // Calculate the width:
            // If the stack is empty → the bar at top can extend to the left edge (index 0), so the width is i
            // If the stack is not empty → stack.peek() is the index of a bar to the left of top that is shorter than top (the left boundary), so the width is i - stack.peek() - 1
            int w = stack.isEmpty() ? i : i - stack.peek() - 1;

            // Calculate the area and update the maximum
            maxArea = Math.max(maxArea, heights[top] * w);
        }

        // Push the current index onto the stack to maintain the monotonically increasing order
        stack.push(i);
    }
    // The maximum value after all pops are complete is the answer
    return maxArea;
}
```
