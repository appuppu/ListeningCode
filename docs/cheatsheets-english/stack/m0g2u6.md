# Designing a Stack That Tracks the Minimum — Design a Stack That Retrieves the Minimum Value in O(1) for All Operations

## Problem

Design a stack that executes all four operations — `push`, `pop`, `top`, and `getMin` (retrieve the current minimum value) — in O(1) time. A standard stack requires O(n) to retrieve the minimum value, so the design needs a special approach.

## Key Insight

If you store "the minimum value at that point in time" alongside each element in the stack, the minimum value information is never lost even when elements are popped. `getMin()` always returns the answer in O(1) by simply looking at the top of the stack.

## Thought Process

1. **To make getMin O(1), the system must always know the minimum value**: You might consider tracking the minimum value with a single variable, but when a pop removes the minimum value, the system cannot determine the next minimum value. This means the system needs a mechanism to retain the "history" of minimum values.
2. **The history of minimum values is linked to the state of the stack**: The minimum value can change each time an element is pushed onto the stack. Conversely, when an element is popped, the minimum value reverts to what it was before that push. This "reverting to the state before the push" property is the same property that a stack itself has.
3. **Store the minimum value at that point in time as a pair with each element**: When pushing, the system compares the new value with the current minimum value and stores the smaller one as "the minimum value at that point in time" together with the new value. This way, even when an element is popped, the next top element holds the correct minimum value.
4. **Decide the structure of the pair**: Use an `int[]` array, storing the value at index `[0]` and the minimum value at that point in time at index `[1]`. The stack type becomes `Stack<int[]>`.
5. **How to calculate the minimum value on push**: If the stack is empty, the new value itself becomes the minimum value. If the stack is not empty, the system compares the new value with the minimum value at the top of the stack (`stack.peek()[1]`) and adopts the smaller one.
6. **Implementation of top, getMin, and pop**: `top()` returns `[0]` of the top pair, and `getMin()` returns `[1]` of the top pair — both in O(1). `pop()` simply removes the top element, just like a standard stack.

## Prerequisites

### Stack

A stack is a Last-In-First-Out (LIFO) data structure. The element added last is the first one to be removed. In Java, you use Generics to specify the type of elements the stack stores.

```java
Stack<int[]> stack = new Stack<>();  // Create a stack that stores int arrays
stack.push(new int[]{1, 1});         // Add an element to the top
stack.peek();                         // Read the top element without removing it → [1, 1]
stack.pop();                          // Remove and return the top element → [1, 1]
stack.isEmpty();                      // Return a boolean indicating whether the stack is empty → true
```

### Math.min

A method that takes two integers and returns the smaller one. The system uses this method to compare the new value with the current minimum value on each push.

```java
Math.min(3, 5);   // → 3
Math.min(-1, 0);  // → -1
```

## Complexity

| | Value |
|---|---|
| Time | O(1) — All operations (push, pop, top, getMin) complete in constant time |
| Space | O(n) — The stack stores up to n pairs |

## Code

```java
// Input: a sequence of operations — push(val), pop(), top(), getMin()
// Output: top() returns the value at the top. getMin() returns the minimum value currently in the stack
class MinStack {

    // A field of type Stack<int[]>. Each element is an array of length 2, where [0] stores the value and [1] stores the minimum value of the entire stack at that point in time
    private Stack<int[]> stack;

    public MinStack() {
        stack = new Stack<>();
    }

    public void push(int val) {
        // If the stack is empty, val itself is the minimum value. Otherwise, compare val with the minimum value recorded at the top and adopt the smaller one
        int min = stack.isEmpty() ? val : Math.min(val, stack.peek()[1]);
        // Push the pair new int[]{val, min}. While this element is at the top, min is the correct minimum value
        stack.push(new int[]{val, min});
    }

    public void pop() {
        // Remove the top pair. The [1] of the new top pair stores the correct minimum value from when that element was pushed, so the minimum value consistency is maintained automatically
        stack.pop();
    }

    public int top() {
        // The value itself is stored at [0] of the pair
        return stack.peek()[0];
    }

    public int getMin() {
        // The minimum value at that point in time is stored at [1] of the pair, so no traversal is needed
        return stack.peek()[1];
    }
}
```
