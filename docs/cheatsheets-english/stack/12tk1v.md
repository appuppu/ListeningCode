# Checking if Parentheses Are Balanced

## Problem

The input is a string composed only of six types of parentheses: `(`, `)`, `{`, `}`, `[`, `]`. The task requires determining whether every opening parenthesis has a corresponding closing parenthesis in the **correct order**, and returning `true` or `false`.

## Key Insight

Parenthesis matching has a Last-In-First-Out (LIFO) structure where the most recently opened parenthesis must be closed first. This property maps directly to a stack: the algorithm pushes opening parentheses onto the stack and checks each closing parenthesis against the top of the stack to verify correct matching.

## Thought Process

1. **Parenthesis matching requires correct ordering**: `([)]` has the correct count for each type of parenthesis, but the order is invalid. The rule is "the innermost parenthesis must be closed first." This is a Last-In-First-Out (LIFO) structure, which a stack naturally represents.
2. **Push opening parentheses onto the stack**: The algorithm scans the string one character at a time from left to right, and pushes each opening parenthesis (`(`, `{`, `[`) onto the stack. The top of the stack always holds the most recently opened parenthesis that has not yet been closed.
3. **Match each closing parenthesis against the top of the stack**: When the algorithm encounters a closing parenthesis, it pops the top element from the stack and checks whether the popped opening parenthesis matches the closing parenthesis's type. If the types do not match, the string is invalid.
4. **A closing parenthesis with an empty stack is invalid**: If the stack is empty before a pop operation, no corresponding opening parenthesis exists, so the algorithm returns `false`.
5. **An empty stack after full traversal means the string is valid**: After processing all characters, any opening parentheses remaining on the stack indicate unclosed parentheses. If the stack is empty, all parentheses are correctly matched.

## Prerequisites

### Stack

A stack is a Last-In-First-Out (LIFO) data structure where the last element added is the first element removed. Stacks are useful in scenarios that require processing items in reverse order of arrival, such as parenthesis matching.

```java
Stack<Character> stack = new Stack<>();  // Create an empty stack
stack.push('(');      // Push '(' onto the top of the stack
stack.peek();         // Return the top element without removing it → '('
stack.pop();          // Remove and return the top element → '('
stack.isEmpty();      // Return true if the stack is empty → true
```

### Parenthesis Pairing Rules

Three types of parentheses each have an opening and closing pair. When a closing parenthesis appears, the algorithm must verify that the top of the stack holds the corresponding opening parenthesis.

```
The matching opening parenthesis for ')' is '('
The matching opening parenthesis for '}' is '{'
The matching opening parenthesis for ']' is '['
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — The algorithm scans the string only once |
| Space | O(n) — The stack stores at most n opening parentheses |

## Code

```java
// Input: a string s composed only of parentheses
// Output: true if all parentheses are correctly matched, false otherwise
public boolean isValid(String s) {
    // A stack that holds opening parentheses that have not yet been closed
    // The top of the stack always holds the most recently opened parenthesis
    Stack<Character> stack = new Stack<>();

    // Scan the string one character at a time from left to right. toCharArray() converts the string to a char array
    for (char c : s.toCharArray()) {
        // If the character is an opening parenthesis, push it onto the stack. It remains on the stack until the matching closing parenthesis appears
        if (c == '(' || c == '{' || c == '[') {
            stack.push(c);
        } else {
            // If the character is a closing parenthesis but the stack is empty, no matching opening parenthesis exists, so the string is invalid
            if (stack.isEmpty()) return false;

            // Pop the most recently opened, unclosed parenthesis from the top of the stack
            char top = stack.pop();

            // If the closing parenthesis does not match the type of the opening parenthesis, the string is invalid
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
            if (c == ')' && top != '(') return false;
        }
    }

    // If the stack is empty, all parentheses are correctly matched
    // If elements remain on the stack, unclosed opening parentheses exist, so return false
    return stack.isEmpty();
}
```
