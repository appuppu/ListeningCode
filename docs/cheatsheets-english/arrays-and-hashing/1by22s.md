# Finding the Longest Consecutive Number Sequence — Find the length of the longest consecutive integer sequence from an unsorted array

## Problem

The system receives an unsorted integer array `nums`. The algorithm finds a sequence of consecutive integers (e.g., 1, 2, 3, 4) within the array and returns the **longest length** of such a sequence. The order of elements in the array does not matter; the values only need to be numerically consecutive.

## Key Insight

Counting the length only from the "starting point" of each consecutive sequence eliminates redundant computation. If `num - 1` does not exist in the HashSet for a given number `num`, that number is the starting point of a consecutive sequence. Starting the count only from these starting points achieves O(n) overall time complexity.

## Thought Process

1. **Identify the starting point of each consecutive sequence**: If the algorithm starts counting from a number in the middle of a sequence, it will count the same sequence multiple times. Only a number where `num - 1` does not exist is the true starting point of a consecutive sequence. By counting only from starting points, each element becomes a counting target at most once.
2. **Perform existence checks efficiently**: The algorithm stores all elements in a HashSet to determine whether a given number exists in the array in O(1) time. Sorting could solve the problem in O(n log n), but using a HashSet reduces the time complexity to O(n).
3. **Count consecutive numbers from each starting point**: Once the algorithm finds a starting point `num`, it sequentially checks whether `num + 1`, `num + 2`, ... exist in the HashSet and counts the length until the consecutive sequence breaks.
4. **Track the longest sequence**: The algorithm compares each consecutive sequence's length against a variable `longest` and updates it if the current sequence is longer. The value of `longest` after processing all elements is the answer.

## Prerequisites

### What is a HashSet?

A HashSet is a data structure that stores values without duplicates. It performs both insertion and existence checks in O(1) time. Unlike a HashMap, a HashSet stores only keys, making it ideal for scenarios where the program needs to quickly determine whether a value exists.

```java
HashSet<Integer> set = new HashSet<>();  // Create an empty HashSet
set.add(4);              // Add value 4 to the set
set.add(4);              // The set ignores duplicates (the size remains unchanged)
set.contains(4);         // Check whether value 4 exists and return a boolean → true
set.contains(5);         // Check whether value 5 exists and return a boolean → false
```

### What is the starting point of a consecutive sequence?

For a given number `num`, if `num - 1` does not exist in the set, then `num` is the first number (starting point) of a consecutive sequence.
Example: Given the set {100, 4, 200, 1, 3, 2}, the number 1 is a starting point (because 0 does not exist), but the number 2 is not a starting point (because 1 exists).

## Complexity

| | Value |
|---|---|
| Time | O(n) — Each element is accessed at most twice: once for the starting point check and once during counting |
| Space | O(n) — The HashSet stores up to n elements |

## Code

```java
// Input: an unsorted integer array nums (may contain duplicates)
// Output: return the length of the longest consecutive integer sequence as an int
public int longestConsecutive(int[] nums) {
    // Store all elements in a HashSet to enable O(1) existence checks
    // The HashSet automatically removes duplicate elements
    Set<Integer> numSet = new HashSet<>();
    for (int num : nums) {
        numSet.add(num);
    }

    // Variable to hold the longest consecutive sequence length found so far
    int longest = 0;

    // Iterate through each element in the HashSet
    for (int num : numSet) {
        // If num - 1 does not exist, num is the starting point of a consecutive sequence
        // If num - 1 exists, num is in the middle of a sequence, so skip it
        // (This number will be counted when processing starts from another starting point)
        if (!numSet.contains(num - 1)) {
            int currentNum = num;
            int length = 1;

            // Count consecutive numbers (num+1, num+2, ...) starting from this point
            // Continue the loop until the consecutive sequence breaks
            while (numSet.contains(currentNum + 1)) {
                currentNum++;
                length++;
            }

            // Update the longest length if the current sequence exceeds the previous maximum
            longest = Math.max(longest, length);
        }
    }
    // After iterating through all elements, return the length of the longest consecutive sequence
    return longest;
}
```
