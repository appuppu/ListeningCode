# Computing Products Without Self Inclusion

## Problem

You are given an integer array `nums`. For each index `i`, you must calculate the product of all elements except `nums[i]` and return the resulting array `result`. You must not use the division operator.

## Key Insight

You can decompose the product of all elements except a given element into "the product of all elements to its left" × "the product of all elements to its right." You can build these left and right cumulative products in two passes — one forward and one backward — to solve the problem in O(n) without division.

## Thought Process

1. **Consider an alternative decomposition because division is not allowed**: The approach of computing the total product and dividing by each element is prohibited. Instead, you decompose `result[i]` as "the product of elements to the left of `nums[i]`" × "the product of elements to the right of `nums[i]`." This decomposition does not require division.
2. **You can build the left cumulative product with a forward pass**: You scan the array from left to right and compute "the product of all elements to the left of the current position." The recurrence `result[i] = result[i-1] * nums[i-1]` holds. Since no elements exist to the left of the first element, you initialize `result[0] = 1` (the multiplicative identity).
3. **You can build the right cumulative product with a backward pass**: You scan the array from right to left and accumulate "the product of all elements to the right of the current position" in a variable `record`. Since no elements exist to the right of the last element, you initialize `record = 1`.
4. **You multiply the two products together**: During the backward pass, you multiply `result[i]` (the left product) by `record` (the right product) to obtain the final answer. After the multiplication, you update the right product with `record = record * nums[i]`.
5. **You avoid using any additional arrays**: You write the left product directly into the `result` array and manage the right product with a single variable, so the additional memory beyond the output array is O(1).

## Prerequisites

### Cumulative Product (Prefix Product / Suffix Product)

A cumulative product is a sequence of products obtained by multiplying elements sequentially from the beginning or end of an array. It is the multiplication counterpart of a cumulative sum. It allows you to efficiently compute "the product of all elements up to each position."

```java
int[] nums = {1, 2, 3, 4};

// Prefix product (cumulative product from the left)
// prefix[0] = 1 (no elements to the left)
// prefix[1] = 1 (up to nums[0])
// prefix[2] = 1*2 = 2 (up to nums[1])
// prefix[3] = 1*2*3 = 6 (up to nums[2])

// Suffix product (cumulative product from the right)
// suffix[3] = 1 (no elements to the right)
// suffix[2] = 4 (up to nums[3])
// suffix[1] = 4*3 = 12 (nums[3]*nums[2])
// suffix[0] = 4*3*2 = 24 (nums[3]*nums[2]*nums[1])
```

### Multiplicative Identity

Multiplying any number by 1 does not change its value. By using 1 as the initial value of the cumulative product, you can apply the same recurrence to the first element without special-casing it.

```java
int record = 1;              // Initialize the product to 1 (multiplicative identity)
record = record * nums[i];   // On the first multiplication, record becomes nums[i]
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — You only need one forward pass and one backward pass through the array |
| Space | O(1) — Excluding the output array `result`, the only additional memory used is the variable `record` |

## Code

```java
// Input: integer array nums
// Output: returns an int[] where each index holds the product of all elements except itself
public int[] productExceptSelf(int[] nums) {
    // Create an array of the same length as nums. First store the left cumulative product, then multiply by the right cumulative product later
    int[] result = new int[nums.length];

    // Forward pass: store the product of all elements to the left of each position in result
    result[0] = 1;  // No elements exist to the left of the first element, so initialize with 1 (multiplicative identity)
    for (int i = 1; i < nums.length; i++) {
        // result[i-1] holds the left product up to position i-1. Multiply it by nums[i-1] (the element one position to the left) to get the left product at position i
        result[i] = result[i - 1] * nums[i - 1];
    }

    // Backward pass: multiply by the right cumulative product to complete the final result
    // record accumulates the product of all elements to the right of the current position
    int record = 1;  // No elements exist to the right of the last element, so initialize with 1
    for (int i = nums.length - 1; i >= 0; i--) {
        // result[i] currently holds the left product. Multiply it by record (the right product) to complete "the product of all elements except itself"
        result[i] = record * result[i];
        // Note: you must update record after finalizing result[i]. Updating it beforehand would include nums[i] itself in the product
        record = record * nums[i];
    }

    // Return result, where each element holds the product of all elements except itself
    return result;
}
```
