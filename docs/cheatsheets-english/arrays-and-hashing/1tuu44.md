# Checking if Two Strings Are Anagrams

## Problem

The problem gives you two strings `s` and `t`. You must determine whether `t` is an anagram of `s` and return a **boolean**. An anagram is a relationship where two strings contain exactly the same characters with the same frequency, differing only in their order.

## Key Insight

Checking whether two strings are anagrams reduces to verifying that the frequency of each character matches exactly. Since lowercase alphabets consist of only 26 characters, you can manage the frequency of every character using a fixed-length array of size 26, which allows O(n) time with O(1) space.

## Thought Process

1. **Capture the definition of an anagram mathematically**: Two strings being anagrams means that the frequency of each character matches exactly. This means you can ignore the order of characters and compare only the frequencies.
2. **Return false immediately if the lengths differ**: An anagram contains the same characters the same number of times, so strings of different lengths cannot be anagrams. Checking this condition first eliminates unnecessary processing.
3. **Consider how to compare frequencies**: Lowercase alphabets are limited to 26 characters from 'a' to 'z'. Instead of using a HashMap, you can use a fixed-length int array of size 26 to manage the frequency of each character by index.
4. **Process both strings with a single array**: Instead of creating two arrays and comparing them, you increment the array for one string and decrement it for the other. If all elements are 0 at the end, the frequencies match exactly.
5. **Process both strings within the same loop**: Since you have already confirmed that the string lengths are equal, you can perform the increment for `s` and the decrement for `t` simultaneously within a single for loop.
6. **Make the final decision**: After the loop completes, you check whether all elements in the array are 0. If even one element is not 0, the frequency of some character does not match, so you return false.

## Prerequisites

### Converting a Character to an Array Index

The expression `char - 'a'` converts a lowercase alphabet character into an integer from 0 to 25. This conversion allows you to use the character directly as an array index.

```java
char c = 'd';
int index = c - 'a';    // 'd' - 'a' = 3 ('a'=0, 'b'=1, 'c'=2, 'd'=3)
int[] count = new int[26];
count[c - 'a']++;       // count[3] becomes 1 (records the occurrence of 'd')
```

### Frequency Counting with a Fixed-Length Array

Preparing an int array of size 26 creates a frequency table where each index corresponds to one character. In Java, `new int[26]` initializes all elements to 0.

```java
int[] count = new int[26];  // All elements are initialized to 0
count['b' - 'a']++;        // count[1] = 1 (records the occurrence of 'b')
count['b' - 'a']--;        // count[1] = 0 (cancels out the occurrence of 'b')
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — The algorithm only needs to scan the strings once (n is the length of the string) |
| Space | O(1) — The array size is always 26, regardless of the input length |

## Code

```java
// Input: two strings s and t
// Output: returns true if t is an anagram of s, false otherwise
public boolean isAnagram(String s, String t) {
    // An anagram contains the same characters the same number of times, so different lengths mean it is not an anagram
    if (s.length() != t.length())
        return false;

    // An array that records the difference in frequency of each alphabet character (index 0='a', 25='z')
    // The size 26 corresponds to the 26 characters from 'a' to 'z'
    int[] count = new int[26];

    // Process both strings simultaneously in a single loop (lengths are already confirmed to be equal)
    for (int i = 0; i < s.length(); i++) {
        // Increment for each character in s: records that this character appeared once in s
        count[s.charAt(i) - 'a']++;
        // Decrement for each character in t: records that this character appeared once in t
        // If the increment and decrement cancel each other out, the frequency of that character is equal in s and t
        count[t.charAt(i) - 'a']--;
    }

    // Scan all 26 elements; if even one element is not 0, the frequencies do not match
    for (int c : count) {
        if (c != 0) return false;
    }
    // All elements are 0 → the frequency of every character matches → the strings are anagrams
    return true;
}
```
