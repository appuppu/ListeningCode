# Grouping Words by Anagram Patterns

## Problem

You are given an array of strings `strs`. You must group the strings that are anagrams of each other and return the result as a list of groups. Two strings are anagrams if they contain the same characters with the same frequency, differing only in their arrangement.

## Key Insight

Anagrams share exactly the same character frequency count. If you convert the frequency count of each of the 26 lowercase letters into a string and use it as a key, anagrams will always produce the same key, allowing you to group them all at once using a HashMap.

## Thought Process

1. **Find the common property of anagrams**: Anagrams differ only in character order; the frequency of each character is exactly the same. You can use this "matching frequency" as the criterion for grouping.
2. **How to represent the frequency**: Since there are 26 lowercase English letters, you prepare an integer array `count` of size 26 and count the occurrences of each character. If two words produce the same array contents, they are anagrams.
3. **How to use the array as a HashMap key**: In Java, you cannot use an array directly as a HashMap key (because it uses reference comparison). Instead, you concatenate each element of the array separated by `#` into a string (e.g., `"1#0#0#...#"`) and use that as the key. This way, words with the same frequency produce the same string key.
4. **Group using a HashMap**: Words with the same key go into the same list. By using `computeIfAbsent`, the map automatically creates a new list when a key is not yet registered and returns the existing list when it is, so you can add words without any conditional branching.
5. **What to return**: Convert all values (the list of each group) from the HashMap into an `ArrayList` and return it.

## Prerequisites

### What is a HashMap

A HashMap is a data structure that stores key-value pairs. It can search and retrieve values by key in O(1) time. It works like a dictionary that allows access by any key at the same speed as array index access.

```java
HashMap<String, List<String>> map = new HashMap<>();  // Create an empty HashMap
map.put("key", new ArrayList<>());  // Store an empty list under the key "key"
map.containsKey("key");             // Return whether the key "key" exists as a boolean → true
map.get("key");                     // Return the value associated with the key "key" → []
map.values();                       // Return all values as a Collection
```

### What is computeIfAbsent

`computeIfAbsent` is a HashMap method. If the specified key does not exist, it generates a value using the lambda expression in the second argument, registers it, and returns that value. If the key already exists, it returns the existing value as-is. This method lets you handle the presence or absence of a key in a single line without conditional branching.

```java
// If the key "abc" is not registered, create a new ArrayList, register it, and return that list
// If the key "abc" is already registered, return the existing list as-is
map.computeIfAbsent("abc", k -> new ArrayList<>()).add("cab");
```

### Counting Character Frequencies

Subtracting `'a'` from a `char` value converts it to an index where a=0, b=1, ..., z=25. By preparing an array of size 26 and incrementing the position at this index, you can record the frequency of each character.

```java
int[] count = new int[26];           // Create a count array for 26 characters (all initialized to 0)
for (char c : "eat".toCharArray())   // Iterate through the string one character at a time
    count[c - 'a']++;                // Increment the position corresponding to the character
// Result: count[0]=1(a), count[4]=1(e), count[19]=1(t), others are 0
```

## Complexity

| | Value |
|---|---|
| Time | O(n × k) — n is the number of strings, k is the average length of a string. For each string, the algorithm counts characters and generates a key of size 26 |
| Space | O(n × k) — The HashMap stores all strings; each key has a fixed length, but the strings themselves occupy k characters of memory |

## Code

```java
// Input: string array strs
// Output: return a List<List<String>> grouping anagrams together
public List<List<String>> groupAnagrams(String[] strs) {
    // HashMap where key = string representation of frequency count, value = list of words belonging to that key
    // Words sharing the same key are anagrams of each other
    Map<String, List<String>> map = new HashMap<>();

    // Iterate through each string s in the array strs from start to end
    for (String s : strs) {
        // Create an array of size 26 to record the frequency of each character (a-z), initialized to 0
        // A new array is created for each string to prevent leftover counts from the previous string
        int[] count = new int[26];
        // Convert to a char array with toCharArray() and count the frequency of each character c
        for (char c : s.toCharArray())
            // Convert character c to an index 0-25 using c - 'a' and increment that position
            count[c - 'a']++;

        // Convert the frequency array into a string key in the format "1#0#0#..."
        // This key uniquely represents the character frequencies, and anagrams always produce the same key
        // The delimiter # between elements ensures different counts do not produce the same string
        StringBuilder sb = new StringBuilder();
        for (int n : count)
            sb.append(n).append('#');
        String key = sb.toString();

        // If the key is not registered, create a new list, then add the current string to the list
        // This causes words with the same key to accumulate in the same list
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }

    // Retrieve the collection of all groups and convert it to a List<List<String>> to return
    return new ArrayList<>(map.values());
}
```
