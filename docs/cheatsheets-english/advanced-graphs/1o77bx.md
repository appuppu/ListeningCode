# Deriving the Order of an Alien Alphabet

## Problem

You are given a list of words `words` sorted in lexicographic order of an alien language. You must infer the order of the alphabet in that language from this ordering and return it as a string. If the ordering contains a contradiction (e.g., a cycle exists or a shorter word appears after a longer word it prefixes), you must return an empty string `""`.

## Key Insight

Comparing two adjacent words reveals one ordering relation (a directed edge) from the first differing character. You construct a directed graph from all such relations across every adjacent pair, then determine the full ordering via DFS topological sort. If a cycle exists, the ordering is contradictory.

## Thought Process

1. **Extract ordering relations by comparing adjacent words**: In a sorted list, you compare two adjacent words `words[i]` and `words[i+1]` character by character from the beginning. When you find the first differing character pair `(a, b)`, you establish one ordering relation: "a comes before b." You represent this relation as a directed edge `a → b` in a graph.
2. **Detect invalid input**: If `words[i]` is a prefix of `words[i+1]` and `words[i]` is longer (e.g., `"abc"` appears before `"ab"`), this contradicts lexicographic order, so you immediately return an empty string.
3. **Register all characters as nodes**: Some characters may not appear in any ordering relation, so you register every character from every word as a node in the graph. This ensures that characters with no edges are still included in the result.
4. **Determine the full ordering via DFS topological sort**: You perform DFS on the directed graph and add each node to a list upon completion of its exploration. Reversing this post-order traversal yields a topological ordering where dependencies appear first.
5. **Detect cycles using three-color marking**: During DFS, you manage each node in one of three states: "unvisited (0)," "in progress (1)," and "completed (2)." If you reach a node that is currently in progress, a cycle exists, making the ordering impossible to determine, so you return an empty string.
6. **Build the result string by reversing the post-order list**: You reverse the DFS post-order list to obtain the topological ordering. You concatenate all characters in the list to produce the result string.

## Prerequisites

### What Is Topological Sort

Topological sort is an operation that arranges all nodes of a directed acyclic graph (DAG) in a linear order consistent with the direction of edges. If an edge `a → b` exists, then `a` always appears before `b` in the result. A graph containing a cycle has no valid topological ordering.

### What Is Three-Color Marking in DFS

Three-color marking is a technique that manages each node's state using three colors during DFS. White (0) represents an unvisited node, gray (1) represents a node on the current exploration path (present on the recursion stack), and black (2) represents a fully explored node. Reaching a gray node again confirms the existence of a cycle.

```java
Map<Character, Integer> color = new HashMap<>();
color.put('a', 0);  // White: unvisited
color.put('a', 1);  // Gray: in progress (on the recursion stack)
color.put('a', 2);  // Black: completed (all descendants processed)
```

### Basic Operations of HashMap and HashSet

```java
// HashMap: stores key-value pairs. Lookup and retrieval run in O(1)
Map<Character, Set<Character>> adj = new HashMap<>();
adj.putIfAbsent('a', new HashSet<>());  // Register an empty Set only if the key is not already present
adj.get('a').add('b');                  // Add 'b' to the adjacency list of key 'a'

// HashSet: a collection with no duplicates. Addition and lookup run in O(1)
Set<Character> set = new HashSet<>();
set.add('b');        // Add an element
set.contains('b');   // Check whether an element exists → true
```

### The startsWith Method

This method checks whether a string begins with a specified prefix.

```java
"abc".startsWith("ab");  // true — "abc" starts with "ab"
"ab".startsWith("abc");  // false — "ab" does not start with "abc"
```

## Complexity

| | Value |
|---|---|
| Time | O(C) — C is the total number of characters across all words. Graph construction scans all characters, and DFS runs proportional to the number of nodes plus edges, neither of which exceeds C |
| Space | O(1) — The number of nodes is at most 26 lowercase letters, which is constant. The number of edges is at most 26², which is also constant. The space does not depend on the input size |

## Code

```java
// Input: a string array words sorted in lexicographic order of an alien language
// Output: a string representing the alphabet order. Return an empty string "" if a contradiction exists

// DFS: record post-order while detecting cycles using three-color marking
boolean dfs(char c, Map<Character, Set<Character>> adj,
            Map<Character, Integer> color, List<Character> result) {
    // Reached a gray (in-progress) node again → cycle detected
    if (color.get(c) == 1) return false;
    // Black (completed) → already processed, so skip this node
    if (color.get(c) == 2) return true;

    // Mark the current node as gray (in progress)
    color.put(c, 1);

    // Recursively perform DFS on all adjacent nodes (characters that come after this character)
    for (char n : adj.get(c))
        if (!dfs(n, adj, color, result))
            return false;  // Cycle detected in a descendant → propagate immediately

    // All descendants have been explored, so mark this node as black
    color.put(c, 2);
    // Add to the list in post-order (DFS adds dependencies first, so reversing yields topological order)
    result.add(c);
    return true;
}

public String alienOrder(String[] words) {
    // Adjacency list: key = character, value = set of characters that come after the key
    Map<Character, Set<Character>> adj = new HashMap<>();

    // Register every character from every word as a node in the graph
    // Characters without any ordering relation (edge) must also appear in the result, so register all characters here
    for (String w : words)
        for (char c : w.toCharArray())
            adj.putIfAbsent(c, new HashSet<>());

    // Compare adjacent words to extract ordering relations (directed edges)
    for (int i = 0; i < words.length - 1; i++) {
        String w1 = words[i];
        String w2 = words[i + 1];

        // Detect invalid input: a longer word appears before a shorter word it prefixes (e.g., ["abc","ab"] is contradictory)
        if (w1.length() > w2.length() && w1.startsWith(w2))
            return "";

        int len = Math.min(w1.length(), w2.length());
        for (int j = 0; j < len; j++) {
            if (w1.charAt(j) != w2.charAt(j)) {
                // Obtain one ordering relation from the first differing character and break immediately
                // Differences beyond the first pair are only meaningful when preceding characters are identical, so extract only one relation
                adj.get(w1.charAt(j)).add(w2.charAt(j));
                break;
            }
        }
    }

    // Create a three-color map and initialize all nodes to white (0: unvisited)
    Map<Character, Integer> color = new HashMap<>();
    for (char c : adj.keySet())
        color.put(c, 0);

    // List to record the DFS post-order traversal
    List<Character> result = new ArrayList<>();

    // Perform DFS from every node (to handle disconnected components in the graph)
    for (char c : adj.keySet())
        if (!dfs(c, adj, color, result))
            return "";  // Cycle detected → the ordering is impossible to determine

    // Reverse the post-order list to obtain the topological ordering
    Collections.reverse(result);

    // Concatenate all characters to build the result string
    StringBuilder sb = new StringBuilder();
    for (char c : result) sb.append(c);
    return sb.toString();
}
```
