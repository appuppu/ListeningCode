# Finding the Minimum Time to Swim Across a Grid

## Problem

You are given an n×n grid where each cell contains a unique elevation value from 0 to n²-1. You can swim from a cell to an adjacent cell (up, down, left, right) only when the current time is **greater than or equal to the elevations of both cells**. Find the **minimum time** required to reach the bottom-right corner (n-1, n-1) from the top-left corner (0, 0). The starting time equals the value of grid[0][0].

## Key Insight

The **maximum elevation** among all cells on a path determines the required time for that path. By using a min-heap to explore cells in order of smallest required time among currently reachable cells, the time at which you first reach the goal is the optimal answer.

## Thought Process

1. **Restate the movement condition**: Moving from cell A to cell B requires "time ≥ max(A, B)". This means the required time for an entire path from start to goal equals the maximum elevation among all cells on that path. Therefore, the problem reduces to finding the path that minimizes the maximum elevation along it.
2. **Recognize the similarity to shortest path problems**: Standard Dijkstra minimizes the **sum** of edge weights along a path, but this problem minimizes the **maximum** of cell elevations along a path. By replacing summation with maximum, you can apply Dijkstra's framework directly.
3. **Expand from the cell with minimum required time using a priority queue**: Store cells in a min-heap (PriorityQueue) keyed by the time required to reach them. By always expanding the cell with the smallest required time, the algorithm guarantees that the time at which each cell is first reached is optimal.
4. **Calculate the required time for adjacent cells**: When the current cell (r, c) has required time `time`, the required time for an adjacent cell (nr, nc) is `Math.max(time, grid[nr][nc])`. This is because the new path's required time is the larger of "the maximum elevation along the path so far" and "the elevation of the next cell".
5. **Prevent redundant processing with a visited array**: A cell removed from the min-heap has its optimal time finalized at that point. Mark it as visited in the array `vis` so that the algorithm does not process the same cell again. This follows the same logic as finalized nodes in Dijkstra's algorithm.
6. **Return immediately upon reaching the goal**: If the cell removed from the heap is (n-1, n-1), then `time` at that moment is the minimum time. Since the min-heap processes cells in order of increasing time, the first arrival at the goal is guaranteed to be optimal.

## Prerequisites

### PriorityQueue (Min-Heap)

A PriorityQueue is a data structure that retrieves elements in priority order. By default, it retrieves the smallest value first. Both insertion and removal operate in O(log n) time. In Dijkstra's algorithm, it efficiently performs the operation of "selecting the node with the minimum cost among unfinalized nodes".

```java
// Create a min-heap that orders int[] elements by their 0th element in ascending order
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{5, 0, 0});   // Add an element (O(log n))
pq.offer(new int[]{3, 1, 0});   // Add an element
int[] min = pq.poll();          // Remove and return the minimum element → {3, 1, 0}
boolean empty = pq.isEmpty();   // Check whether the queue is empty → false
```

### Modified Dijkstra's Algorithm

Standard Dijkstra's algorithm minimizes the **sum** of edge weights, but this problem minimizes the **maximum** of elevations along a path. By changing the distance update formula from `dist[next] = dist[cur] + weight` to `dist[next] = max(dist[cur], grid[next])`, Dijkstra's correctness guarantee (the property that optimality is finalized when a node is removed from the min-heap) is preserved.

### Four-Directional Adjacent Cell Exploration

You enumerate the up, down, left, and right neighbors of a cell (r, c) on a grid by adding direction vectors `{{0,1},{0,-1},{1,0},{-1,0}}`. Perform bounds checking (0 ≤ nr < n and 0 ≤ nc < n) and process only valid cells.

```java
int[][] dir = {{0,1},{0,-1},{1,0},{-1,0}};  // Four directions: right, left, down, up
for (int[] d : dir) {
    int nr = r + d[0];  // Row of the adjacent cell
    int nc = c + d[1];  // Column of the adjacent cell
    if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
        // (nr, nc) is a valid adjacent cell
    }
}
```

## Complexity

| | Value |
|---|---|
| Time | O(n² log n) — Each of the n² cells is inserted into and removed from the heap at most once. Each heap operation costs O(log n²) = O(log n). |
| Space | O(n²) — The visited array and the heap each hold at most n² cells. |

## Code

```java
// Input: an n×n integer array grid (each cell contains a unique elevation value from 0 to n²-1)
// Output: return the minimum time required to reach (n-1, n-1) from (0, 0) as an int
int swimInWater(int[][] grid) {
    int n = grid.length;
    // Visited array to track whether each cell's optimal time has been finalized (vis[r][c] = true means finalized)
    boolean[][] vis = new boolean[n][n];
    // Min-heap that retrieves cells in order of smallest required time (element: {time, row, col})
    // The comparator (a,b)->a[0]-b[0] orders elements by their 0th element (required time) in ascending order
    PriorityQueue<int[]> pq =
        new PriorityQueue<>(
            (a, b) -> a[0] - b[0]);
    // Add the starting cell to the heap and mark it as visited
    // The 0th element is the required time, the 1st element is the row, and the 2nd element is the column
    pq.offer(new int[]
        {grid[0][0], 0, 0});
    vis[0][0] = true;
    // Four-directional vectors for up, down, left, right
    int[][] dir =
        {{0,1},{0,-1},{1,0},{-1,0}};
    while (!pq.isEmpty()) {
        // Remove the cell with the minimum required time (by the min-heap property, its optimal time is finalized at this point)
        int[] cur = pq.poll();
        int time = cur[0];
        int r = cur[1], c = cur[2];
        // If the goal is reached, this time is the optimal answer (since cells are processed in order of increasing time, the first arrival is optimal)
        if (r == n-1 && c == n-1)
            return time;
        // Explore adjacent cells in four directions
        for (int[] d : dir) {
            int nr = r+d[0];
            int nc = c+d[1];
            // Process only cells that are within bounds and not yet visited
            if (nr >= 0 && nr < n
                && nc >= 0 && nc < n
                && !vis[nr][nc]) {
                // Note: marking as visited at the time of heap insertion prevents the same cell from being added to the heap multiple times
                vis[nr][nc] = true;
                // The maximum elevation along the path becomes the required time (the larger of "maximum elevation so far" and "elevation of the next cell")
                int nt = Math.max(
                    time,grid[nr][nc]);
                pq.offer(new int[]
                    {nt, nr, nc});
            }
        }
    }
    // This point is unreachable because the grid is connected by the problem's constraints
    return -1;
}
```
