# Reconstructing a Flight Itinerary — Reconstruct the Lexicographically Smallest Itinerary from Flight Tickets

## Problem

You are given a list of flight tickets, where each ticket is represented as a pair of a departure airport and an arrival airport. You must reconstruct an itinerary that starts from JFK and uses every ticket exactly once. If multiple valid itineraries exist, you must return the lexicographically smallest one.

## Key Insight

This problem is an Eulerian path problem, where you must traverse every edge (ticket) exactly once. Managing each airport's destinations with a PriorityQueue automatically guarantees the lexicographically smallest order, and Hierholzer's algorithm constructs the itinerary from the back, correctly handling dead ends.

## Thought Process

1. **Using every ticket exactly once = Eulerian path**: Each ticket is an edge in a directed graph, and finding a path that traverses every edge exactly once reduces to the Eulerian path problem
2. **Sorting is required to guarantee the lexicographically smallest order**: When an airport has multiple destinations, you want to choose the lexicographically smaller one first. Storing each airport's destinations in a PriorityQueue (min-heap) ensures that each `poll()` always returns the lexicographically smallest destination
3. **A simple greedy approach cannot handle dead ends**: Always choosing the lexicographically smallest destination may lead to a dead end while unused edges still remain. For example, given tickets JFK→A, A→JFK, and JFK→B, choosing A first from JFK lets you proceed A→JFK→B, but choosing B first leads to a dead end at B
4. **Hierholzer's algorithm constructs the itinerary from the back**: You add each node to the **front** of the result list when DFS reaches a dead end (a node with no remaining destinations). This places dead ends at the tail of the itinerary, and the remaining edges are added to the front in the correct order as the recursion unwinds
5. **How the recursive DFS works**: From the current node, you extract the lexicographically smallest destination using the PriorityQueue and recursively perform DFS. When no destinations remain, you add the current node to the front of the result list. Using LinkedList's `addFirst` achieves O(1) front insertion
6. **What to return**: After all DFS calls complete, you return the result list (LinkedList) as is. The list contains the lexicographically smallest itinerary starting from JFK

## Prerequisites

### PriorityQueue

A PriorityQueue is a data structure that automatically sorts elements upon insertion and always returns the smallest element upon extraction. It is internally implemented as a heap, and both insertion and extraction operate in O(log n) time.

```java
PriorityQueue<String> pq = new PriorityQueue<>();  // Create a min-heap using natural ordering (lexicographic) for strings
pq.offer("SFO");       // Add "SFO"
pq.offer("ATL");       // Add "ATL"
pq.poll();             // Extract and remove the smallest element "ATL" → "ATL"
pq.isEmpty();          // Return whether the queue is empty as a boolean → false ("SFO" remains)
```

### computeIfAbsent

`computeIfAbsent` is a HashMap method that generates and registers a value using a specified function only if the key does not exist, and returns that value. If the key already exists, it returns the existing value as is. This method replaces the three-step pattern of `get`, null check, and `put` with a single line.

```java
Map<String, PriorityQueue<String>> graph = new HashMap<>();
// If the key "JFK" does not exist, create a new PriorityQueue, register it, and return it
graph.computeIfAbsent("JFK", k -> new PriorityQueue<>()).offer("SFO");
// The key "JFK" already exists, so return the existing PriorityQueue (no new creation)
graph.computeIfAbsent("JFK", k -> new PriorityQueue<>()).offer("ATL");
```

### LinkedList's addFirst

`addFirst` is a method that adds an element to the front of a list in O(1) time. Unlike the regular `add` (which appends to the end), it inserts at the front without shifting existing elements. It is used in Hierholzer's algorithm to construct the result in reverse order.

```java
LinkedList<String> result = new LinkedList<>();
result.addFirst("JFK");   // result: ["JFK"]
result.addFirst("ATL");   // result: ["ATL", "JFK"]
result.addFirst("SFO");   // result: ["SFO", "ATL", "JFK"]
```

### Hierholzer's Algorithm

Hierholzer's algorithm finds an Eulerian path (a path that traverses every edge exactly once). It consumes edges via DFS and adds each node to the front of the result when it reaches a dead end. After all edges are consumed, the result list contains the Eulerian path in the correct order. The algorithm is well suited to this problem because it naturally places dead ends at the tail of the itinerary.

## Complexity

| | Value |
|---|---|
| Time | O(E log E) — Each ticket (edge) incurs a log E cost when being added to and extracted from the PriorityQueue |
| Space | O(V + E) — The adjacency list stores all edges, and the recursion stack can grow as deep as the number of edges |

## Code

```java
// Input: a list of flight tickets (each ticket is a string pair [departure airport, arrival airport])
// Output: the lexicographically smallest itinerary starting from JFK, returned as List<String>
public List<String> findItinerary(List<List<String>> tickets) {
    // Key = departure airport, Value = PriorityQueue managing arrival airports in lexicographic order
    // Using a PriorityQueue ensures that extraction always yields the lexicographically smallest destination
    Map<String, PriorityQueue<String>> graph = new HashMap<>();

    // Build the graph from all tickets
    // computeIfAbsent creates a new PriorityQueue if the src key appears for the first time, or retrieves the existing one
    for (List<String> t : tickets) {
        graph.computeIfAbsent(t.get(0), k -> new PriorityQueue<>())
             .offer(t.get(1));
    }

    // LinkedList to store the result (using addFirst for O(1) front insertion)
    LinkedList<String> result = new LinkedList<>();

    // Start DFS from JFK
    dfs("JFK", graph, result);
    return result;
}

void dfs(String curr,
          Map<String, PriorityQueue<String>> graph,
          LinkedList<String> result) {
    // Get the PriorityQueue of destinations reachable from the current airport
    PriorityQueue<String> dests = graph.get(curr);

    // While destinations exist, extract the lexicographically smallest destination and perform DFS
    // Note: poll() removes the element, so the same edge (ticket) is never traversed twice
    while (dests != null && !dests.isEmpty()) {
        dfs(dests.poll(), graph, result);
    }

    // When a dead end is reached, add the current airport to the front of the result list
    // By adding to the front, dead-end nodes are placed toward the tail of the itinerary,
    // and nodes added later are correctly placed toward the front of the itinerary
    result.addFirst(curr);
}
```
