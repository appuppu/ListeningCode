# Finding Two Numbers in a Sorted Array That Add Up to a Target

## Problem

You are given a sorted integer array `nums` and an integer `target`. You need to find two elements in `nums` that add up to `target` and return their **1-indexed positions** as an array. Exactly one solution exists, and you cannot use the same element twice.

## Key Insight

Because the array is sorted, you can use two pointers starting from both ends to close in on the answer. If the sum is too large, you move the right pointer inward; if too small, you move the left pointer inward. This approach finds the answer in O(n) time and O(1) space with a single pass.

## Thought Process

1. **Leverage the sorted property**: The array is sorted, so the left end points to the minimum value and the right end points to the maximum value. By starting the search from both ends, you can reliably narrow the search range based on whether the current sum is too large or too small.
2. **Move the right pointer left if the sum is too large**: The right pointer points to the largest value in the current search range. If the sum exceeds `target`, you move the right pointer one step to the left to switch to a smaller value.
3. **Move the left pointer right if the sum is too small**: The left pointer points to the smallest value in the current search range. If the sum is less than `target`, you move the left pointer one step to the right to switch to a larger value.
4. **The answer is found when the sum equals `target`**: When the sum of the values at the two pointers equals `target`, that pair is the answer. Since the problem requires 1-indexed positions, you add 1 to each pointer's position before returning.
5. **Loop termination condition**: The loop repeats until the left pointer reaches the right pointer. The problem guarantees that a solution always exists, so the algorithm always finds the answer before the pointers cross.
6. **Return value**: When the sum matches `target`, you return an `int[]` containing `left + 1` (the 1-indexed position of the left element) and `right + 1` (the 1-indexed position of the right element).

## Prerequisites

### Two Pointers

The two pointers technique uses two index variables pointing to different positions in an array, moving each one according to specific conditions. In sorted arrays, the typical pattern narrows the search range from both ends toward the center.

```java
int left = 0;                    // Place the left pointer at the start of the array
int right = nums.length - 1;     // Place the right pointer at the end of the array
while (left < right) {           // Loop until the two pointers cross
    // Move left and right according to the condition
    left++;   // Advance the left pointer one step to the right
    right--;  // Move the right pointer one step to the left
}
```

### Properties of a Sorted Array

When the array is sorted in ascending order, `nums[left] <= nums[right]` always holds. Moving the left pointer to the right increases the sum, and moving the right pointer to the left decreases the sum. This monotonic property is what allows you to determine the direction of each pointer movement based on the sum comparison.

## Complexity

| | Value |
|---|---|
| Time | O(n) — The two pointers move at most n times in total |
| Space | O(1) — The algorithm uses only pointer variables and requires no additional data structures |

## Code

```java
// Input: a sorted integer array nums and an integer target
// Output: an int[] containing the 1-indexed positions of two elements that add up to target
public int[] twoSum(int[] nums, int target) {
    // Place the left pointer at the start of the array. It marks the left boundary of the search range and covers the minimum-value side
    int left = 0;
    // Place the right pointer at the end of the array. It marks the right boundary of the search range and covers the maximum-value side
    int right = nums.length - 1;

    // Loop until the two pointers cross
    while (left < right) {
        // Calculate the sum of the current two elements and store it in a variable for reuse in each branch
        int cursum = nums[left] + nums[right];

        if (cursum == target) {
            // The sum matches the target, so the pair is found. Add 1 to each index to convert to 1-indexed positions as the problem requires
            return new int[]{left + 1, right + 1};
        } else if (cursum > target) {
            // The sum is too large, so move the right pointer to the left. The right pointer will point to a smaller value, decreasing the sum in the next iteration
            right--;
        } else {
            // The sum is too small, so move the left pointer to the right. The left pointer will point to a larger value, increasing the sum in the next iteration
            left++;
        }
    }
    // The problem guarantees a solution always exists, so this line is never reached
    return new int[]{};
}
```
