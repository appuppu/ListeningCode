# Three Sum — Find All Triplets That Sum to Zero

## Problem

The system receives an integer array `nums` as input. The algorithm finds all combinations of three elements (triplets) in `nums` that sum to `0` and returns them as a `List<List<Integer>>`. Each triplet consists of elements at distinct indices, and the result must not contain duplicate triplets.

## Key Insight

Sorting the array allows the algorithm to fix one element and efficiently search for the remaining two elements using Two Pointers. The sorted order also enables the algorithm to skip duplicate values naturally, which eliminates duplicate triplets from the result.

## Thought Process

1. **Reduce the 3-element problem to a 2-element problem**: The equation `a + b + c = 0` becomes `b + c = -a` when the algorithm fixes one element `a = nums[i]`. An outer for-loop fixes `a`, and the inner loop searches for `b` and `c`. This structure applies the well-known Two Sum approach
2. **Sort the array to enable Two Pointers**: The Two Pointers technique efficiently searches for two elements by narrowing pointers from both ends of a sorted array. If the sum is too small, the algorithm moves the left pointer right. If the sum is too large, the algorithm moves the right pointer left. This approach explores all pairs efficiently
3. **Eliminate duplicate triplets using the sorted order**: In a sorted array, identical values sit adjacent to each other. The outer loop skips `nums[i]` when it equals the previous element. The inner loop skips `left` and `right` past consecutive duplicate values after finding a valid pair. This approach prevents the result from containing duplicate triplets
4. **Determine the outer loop range**: The algorithm needs three elements, so `i` iterates from `0` to `nums.length - 3`. The algorithm initializes `left` at `i + 1` and `right` at `nums.length - 1`, and the search continues while `left < right`
5. **Move pointers based on the sum**: If `sum == 0`, the algorithm adds the triplet to the result, skips duplicates, and advances both pointers inward. If `sum < 0`, the algorithm moves `left` right to increase the sum. If `sum > 0`, the algorithm moves `right` left to decrease the sum
6. **Return the final result**: After the algorithm has explored all combinations of fixed elements and pointer positions, it returns the accumulated `result` list

## Prerequisites

### Two Pointers

Two Pointers is a technique that places two pointers (`left` and `right`) at both ends of a sorted array and moves one of them based on a condition. This technique searches all pairs in O(n) time. If the sum is smaller than the target, the algorithm moves `left` right (to increase the value). If the sum is larger, the algorithm moves `right` left (to decrease the value).

```java
int left = 0;
int right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) {
        // Pair found
    } else if (sum < target) {
        left++;    // Move the left pointer right to increase the sum
    } else {
        right--;   // Move the right pointer left to decrease the sum
    }
}
```

### Arrays.sort()

`Arrays.sort()` is a standard Java method that sorts an array in ascending order. After sorting, identical values sit adjacent to each other, which makes duplicate detection straightforward.

```java
int[] nums = {4, -1, 2, -1, 0};
Arrays.sort(nums);    // nums becomes {-4, -1, -1, 0, 2} (ascending order)
```

### Arrays.asList()

`Arrays.asList()` is a method that creates a fixed-size `List` from varargs. The algorithm uses this method to add each triplet as a `List<Integer>` to the result list.

```java
List<Integer> triplet = Arrays.asList(-1, 0, 1);  // Creates a list [-1, 0, 1]
```

## Complexity

| | Value |
|---|---|
| Time | O(n²) — The outer loop runs in O(n), and the inner Two Pointers runs in O(n), giving O(n²) in total |
| Space | O(1) — Excluding the sort, the algorithm uses only pointer variables and no additional space |

## Code

```java
// Input: integer array nums
// Output: List<List<Integer>> containing all unique triplets that sum to 0
public List<List<Integer>> threeSum(int[] nums) {
    // Result list that accumulates all discovered triplets
    List<List<Integer>> result = new ArrayList<>();
    // Sort the array in ascending order (prerequisite for Two Pointers + duplicate skipping)
    Arrays.sort(nums);

    // i iterates from 0 to nums.length - 3. nums[i] serves as the fixed element of the triplet
    for (int i = 0; i < nums.length - 2; i++) {
        // Skip if the fixed element equals the previous element to avoid generating the same triplet again
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }
        // Place left and right pointers just after the fixed element and at the end of the array to search for pairs in this range
        int left = i + 1;
        int right = nums.length - 1;

        while (left < right) {
            // Calculate the sum of the three elements
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0) {
                // Add the triplet that sums to zero to the result
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // Skip duplicate values on the left pointer side (advance right while the same value continues)
                while (left < right && nums[left] == nums[left + 1]) {
                    left++;
                }
                // Skip duplicate values on the right pointer side (advance left while the same value continues)
                while (left < right && nums[right] == nums[right - 1]) {
                    right--;
                }
                // After skipping duplicates, advance both pointers inward by one to search for the next pair
                left++;
                right--;
            } else if (sum < 0) {
                // The sum is negative, so move the left pointer right to increase the sum
                left++;
            } else {
                // The sum is positive, so move the right pointer left to decrease the sum
                right--;
            }
        }
    }

    // Exploration is complete for all fixed elements. The result contains all unique triplets
    return result;
}
```
