# Finding the Minimum Eating Speed to Finish Bananas — Find the minimum speed to eat all bananas within the time limit

## Problem

You are given an array of banana piles `piles` and a time limit `h` (hours). When you eat `k` bananas per hour, return the **minimum integer speed `k`** that allows you to eat all bananas within `h` hours. You can only eat from one pile per hour, and if a pile has fewer than `k` bananas, you finish that pile but must wait for the remaining time instead of moving to the next pile.

## Key Insight

The question "Can you eat all bananas at speed `k`?" has monotonicity with respect to `k`. A large enough `k` always allows you to finish, while a too-small `k` does not. Because of this monotonicity, you can apply binary search over the candidate range `[1, max(piles)]` to efficiently find the minimum `k` that satisfies the condition.

## Thought Process

1. **The relationship between speed and result is monotonic**: Increasing speed `k` decreases the required time, and decreasing speed increases it. If you can finish at a certain speed, you can always finish at any higher speed. This "find the minimum value satisfying a condition" structure is a classic binary search pattern.
2. **Determine the search range**: The minimum speed is `1` (you eat at least one banana per hour), and the maximum speed is `max(piles)` (the speed at which you can finish the largest pile in one hour). Any speed greater than `max(piles)` produces the same result because you can only eat from one pile per hour.
3. **Design the feasibility function**: Given a speed `mid`, eating each pile `piles[i]` takes `ceil(piles[i] / mid)` hours. If the total hours across all piles is at most `h`, you can finish at that speed.
4. **Perform ceiling division using integer arithmetic**: You can compute `ceil(piles[i] / mid)` as `(piles[i] + mid - 1) / mid`. This approach avoids floating-point arithmetic and computes the result exactly using only integers.
5. **Narrow the range with binary search**: If you can finish at the midpoint `mid`, the answer is at most `mid`, so you set `right = mid`. If you cannot finish, the answer is at least `mid + 1`, so you set `left = mid + 1`. When `left == right`, that value is the minimum speed.

## Prerequisites

### Binary Search — "Find the Minimum Value Satisfying a Condition" Pattern

This technique finds the minimum (or maximum) value satisfying a given condition over a sorted range of values or a contiguous range of integers. Because the search range is halved each time, the answer is found in O(log n).

```java
int left = 1;               // Lower bound of the search range
int right = 1000;            // Upper bound of the search range
while (left < right) {       // The answer is determined when left == right
    int mid = left + (right - left) / 2;  // Compute midpoint to prevent overflow
    if (condition(mid))       // Check whether mid satisfies the condition
        right = mid;          // Condition satisfied → the answer is at most mid
    else
        left = mid + 1;       // Condition not satisfied → the answer is at least mid + 1
}
// left is the minimum value satisfying the condition
```

### Ceiling Division

An integer operation that rounds up the result of `a / b`. You can compute it as `(a + b - 1) / b` without using `Math.ceil`.

```java
int a = 10, b = 3;
int result = (a + b - 1) / b;  // (10 + 2) / 3 = 4  (10 ÷ 3 = 3.33... → rounded up to 4)
```

In the banana problem, you divide the pile size `piles[i]` by the speed `k` and round up to get the number of hours needed to finish that pile.

### What is Math.max

A method that returns the larger of two values. You combine it with a loop to find the maximum value in an array.

```java
Math.max(5, 3);   // → 5
Math.max(-1, 0);  // → 0
```

## Complexity

| | Value |
|---|---|
| Time | O(n × log(max(piles))) — Binary search performs O(log(max(piles))) iterations, and each iteration scans the entire array in O(n) to compute the total time |
| Space | O(1) — The algorithm uses no additional data structures and processes everything with only variables |

## Code

```java
// Input: integer array piles (number of bananas in each pile) and integer h (time limit)
// Output: return the minimum integer speed k that allows eating all bananas within h hours as an int
public int minEatingSpeed(int[] piles, int h) {
    // Set the lower bound of binary search to 1. The minimum speed is at least 1 banana per hour
    int left = 1;
    // Set the upper bound of binary search to the maximum value in the array
    // Any speed greater than the largest pile eaten in one hour adds no benefit, so this value is the upper bound
    int right = 0;
    for (int p : piles) {
        right = Math.max(right, p);
    }

    // Keep halving the search range until left == right
    // When left == right, that value is the answer
    while (left < right) {
        // Compute the midpoint in a way that prevents overflow
        // Use left + (right - left) / 2 instead of (left + right) / 2 to prevent integer overflow
        int mid = left + (right - left) / 2;

        // Compute the total hours needed to eat all bananas at speed mid
        int totalHours = 0;
        for (int p : piles) {
            // Ceiling division: compute the number of hours needed to finish each pile
            totalHours += (p + mid - 1) / mid;
        }

        if (totalHours <= h) {
            // Can finish → a slower speed might also work, so shrink the upper bound
            // mid itself could be the answer, so assign mid instead of mid - 1
            right = mid;
        } else {
            // Cannot finish → the speed is insufficient, so raise the lower bound
            // mid cannot be the answer, so assign mid + 1
            left = mid + 1;
        }
    }

    // After the loop, left (== right) is the minimum speed satisfying the condition
    return left;
}
```
