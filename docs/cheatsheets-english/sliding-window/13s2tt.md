# Finding the Longest Substring Without Repeating Characters

## Problem

You are given a string `s`. You need to find a contiguous substring in `s` where no character appears more than once, and return the **maximum length** of such a substring as an integer.

## Key Insight

A sliding window allows you to examine all valid substrings in O(n) time. When you detect a duplicate, you jump the left pointer directly to "the previous occurrence index of the duplicate character + 1," eliminating unnecessary one-by-one movements.

## Thought Process

1. **Represent the substring search as a window**: You can represent a "substring without duplicates" as a range bounded by two pointers, `left` and `right`. You advance `right` one step at a time to expand the window, and move `left` forward to shrink the window when a duplicate occurs.
2. **Use a HashMap to detect duplicates**: You record the "last seen index" of each character in a HashMap, which allows you to determine in O(1) whether a new character already exists within the current window.
3. **Define the exact jump condition for the left pointer**: The mere existence of a character in the HashMap is insufficient. You treat it as a duplicate only when the character's previous occurrence index is greater than or equal to `left` (i.e., it falls within the current window). You ignore stale records that lie outside the window.
4. **Determine the destination of the left pointer**: When you detect a duplicate, you update `left` to "the previous occurrence index of the duplicate character + 1." This removes the duplicate character from the window while retaining all other valid characters inside it.
5. **Time the HashMap update correctly**: After performing the duplicate check, you register (overwrite) the current character's index in the HashMap. This ensures the HashMap always records the most recent occurrence position of each character.
6. **Update the maximum length**: At each step, you compute `right - left + 1` (the current window width) and update the running maximum if this value exceeds it.

## Prerequisites

### Sliding Window

A sliding window is a technique that moves a "window" defined by two pointers (`left`, `right`) across an array or string to find segments that satisfy a given condition. You advance `right` to expand the window and advance `left` to shrink the window when a condition violation occurs. Because each pointer moves only forward, the overall time complexity is O(n).

### HashMap

A HashMap is a data structure that stores key-value pairs. It allows you to look up and retrieve a value by its key in O(1) time. In this problem, you store each "character" as the key and "the index where that character last appeared" as the value.

```java
HashMap<Character, Integer> map = new HashMap<>();  // Create an empty HashMap
map.put('a', 0);            // Store value 0 for key 'a'
map.containsKey('a');       // Return whether key 'a' exists as a boolean → true
map.get('a');               // Return the value associated with key 'a' → 0
```

### charAt

The `charAt` method retrieves the character at a specified position in a string. `s.charAt(i)` returns the `char` at index `i` of string `s`.

```java
String s = "abc";
char c = s.charAt(0);  // Returns 'a'
char d = s.charAt(2);  // Returns 'c'
```

### Math.max

The `Math.max` method returns the larger of two values. You use it in situations where you need to continuously update a maximum value.

```java
int result = Math.max(3, 7);  // Returns 7
maxLength = Math.max(maxLength, currentLength);  // Update the current maximum
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — `right` traverses the string only once. `left` also moves only forward, so the overall complexity is O(n). |
| Space | O(n) — The HashMap stores at most n character-index pairs. |

## Code

```java
// Input: String s
// Output: Return the length of the longest substring without repeating characters as an int
public int lengthOfLongestSubstring(String s) {
    // Left pointer of the window. Initial position is the start of the string
    int left = 0;
    // Variable to record the longest window width found during traversal
    int maxLength = 0;
    // HashMap where key = character, value = the index where that character last appeared
    // Used for both duplicate detection and calculating the left pointer's jump destination
    HashMap<Character, Integer> hashMap = new HashMap<>();

    // right is the pointer representing the right end of the window. It advances one step at a time to expand the window
    for (int right = 0; right < s.length(); right++) {
        // Retrieve the character about to be added to the window
        char curChar = s.charAt(right);

        // containsKey: Determine whether this character has appeared before
        // get(curChar) >= left: Verify whether that occurrence falls within the current window
        // When both conditions are true, a duplicate exists within the window
        if (hashMap.containsKey(curChar) && hashMap.get(curChar) >= left) {
            // Jump the left pointer to the previous occurrence index + 1 to resolve the duplicate
            // left only moves forward, so it never moves backward
            left = hashMap.get(curChar) + 1;
        }

        // Register the current character's position by overwriting it with the latest index
        // The next time this character appears, the system uses the index recorded here to calculate the left pointer's jump destination
        hashMap.put(curChar, right);
        // right - left + 1 is the current window width (the length of the duplicate-free substring)
        // Update the maximum if this value exceeds the previous maximum
        maxLength = Math.max(maxLength, right - left + 1);
    }
    // This is the length of the longest substring without repeating characters
    return maxLength;
}
```
