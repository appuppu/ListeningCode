# Finding the Maximum in Each Sliding Window

## Problem

You are given an integer array `nums` and a window size `k`. You slide a window of size `k` one position at a time from the left end to the right end of the array, and you find the **maximum value** within the window at each position. You return all the maximum values as an array.

## Key Insight

If you maintain indices in a Deque (double-ended queue) such that their corresponding values are in monotonically decreasing order, the front of the Deque always points to the maximum value within the window. When a new element arrives, you remove all elements from the back that are less than or equal to the new element, and if the front element is outside the window, you remove it from the front. This approach achieves an amortized O(1) cost per step for obtaining the maximum value.

## Thought Process

1. **You need the maximum value for each window**: Each time the window slides by one position, the system adds one element and removes one element. If you scan the entire window at O(k) to find the maximum each time, the total cost becomes O(nk), so you need a data structure that manages the maximum value efficiently.
2. **You only need to keep candidates for the maximum**: If elements A and B are both in the window, A is to the left of B, and A's value is less than or equal to B's value, then A can never be the maximum in any future window. Because B is to the right, B will never leave the window before A does. Therefore, you can safely exclude A from the candidates.
3. **You manage candidates with a monotonically decreasing Deque**: If you keep candidates in decreasing order of value, the front always holds the maximum. When you add a new element, you remove all elements from the back that are less than or equal to the new element, which maintains the monotonically decreasing property. A Deque (double-ended queue) is well suited for this operation.
4. **You store indices in the Deque**: You need positional information to determine whether an element has left the window, so you store indices rather than values in the Deque. You can retrieve the value by referencing `nums[index]`.
5. **You check whether the front is outside the window**: At each step, if the index at the front of the Deque is less than the current window's left boundary `i - k + 1`, that element has left the window, so you remove it from the front.
6. **You record the result at the right timing**: Once the index `i` reaches `k - 1` or greater, the window is fully formed, so you record the value pointed to by the front of the Deque into the result array.

## Prerequisites

### ArrayDeque (Double-Ended Queue)

An ArrayDeque is a data structure that supports adding, retrieving, and removing elements from both the front and the back in O(1) time. It combines the functionality of both a stack and a queue.

```java
ArrayDeque<Integer> deque = new ArrayDeque<>();  // Create an empty Deque
deque.offerLast(5);       // Add 5 to the back
deque.offerLast(3);       // Add 3 to the back → Deque contents: [5, 3]
deque.peekFirst();        // Retrieve the front element without removing it → 5
deque.peekLast();         // Retrieve the back element without removing it → 3
deque.pollFirst();        // Retrieve and remove the front element → 5
deque.pollLast();         // Retrieve and remove the back element → 3
deque.isEmpty();          // Return whether the Deque is empty as a boolean → true
```

### Monotonic Deque

A Monotonic Deque is a Deque that maintains its elements in strictly decreasing order from front to back. When you add a new element, you remove all elements from the back that are less than or equal to the new element to maintain the monotonically decreasing property.
Example: Deque=[7, 5, 3], add 6 → remove 5 and 3 → Deque=[7, 6]. The front always points to the maximum value.

## Complexity

| | Value |
|---|---|
| Time | O(n) — Each element is added to the Deque at most once and removed at most once, so the total cost is O(n) |
| Space | O(k) — The Deque holds at most k elements, which is the window size |

## Code

```java
// Input: integer array nums and integer k (window size)
// Output: return an int[] containing the maximum value at each window position. The array contains n - k + 1 elements
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    // Result array to store the maximum value of each window. There are n - k + 1 windows
    int[] result = new int[n - k + 1];
    // Deque that holds indices of maximum value candidates in monotonically decreasing order
    // The Deque holds indices that could be the maximum within the window, with corresponding values in decreasing order
    ArrayDeque<Integer> deque = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // If the front index is less than the window's left boundary i - k + 1, remove it because it is outside the window
        // The window slides by one position at a time, so at most one element leaves the window per step
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }

        // Remove all candidates from the back that are less than or equal to the current element nums[i] to maintain monotonic decrease
        // These elements can never be the maximum as long as nums[i] exists, so you can safely exclude them from the candidates
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }

        // Add the current index to the back of the Deque
        // The while loop above already removed all elements less than or equal to the current one, so the Deque remains monotonically decreasing after the addition
        deque.offerLast(i);

        // When i >= k - 1, the window contains k elements
        // The front of the Deque points to the index of the maximum value in the current window
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    // Return result, which contains the maximum values for all windows
    return result;
}
```
