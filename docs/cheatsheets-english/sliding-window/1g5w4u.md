# Longest Substring After Replacing K Characters — Find the longest substring of identical characters obtainable by replacing at most K characters

## Problem

You are given a string `s` consisting of uppercase English letters and an integer `k`. You can replace at most `k` characters in the string with any character. Return the maximum length of a substring in which **all characters are identical**.

## Key Insight

If you track the frequency of the most common character within the window, you can calculate the number of characters that need replacement as `window size − frequency of the most common character`. As long as this replacement count remains at most `k`, you keep expanding the window, which yields the longest valid substring.

## Thought Process

1. **Brute-force enumeration of all substrings is inefficient**: Enumerating every substring costs O(n²). Since the problem deals with contiguous ranges, the Sliding Window pattern is a good fit.
2. **Determine how many characters need replacement within the window**: To make all characters in the window identical, you only need to replace every character except the most frequent one. Therefore, the number of characters that need replacement equals `window size − frequency of the most frequent character`.
3. **Track the frequency of each character**: Since there are only 26 uppercase English letters, you can manage the frequency of each character using an array `count` of size 26. You increment and decrement the counts as the window expands and shrinks.
4. **Maintain the maximum character frequency efficiently**: Each time you advance the right pointer, you compare the frequency of the newly added character with the current `maxFreq` and take the larger value. When you advance the left pointer to remove a character, you do not decrease `maxFreq`. This is because, in a problem that seeks the maximum length, updating `maxFreq` to a value smaller than the historical maximum can never produce a longer result.
5. **Window shrink condition**: When `window size − maxFreq > k`, the number of replacements exceeds `k`, so you advance the left pointer by one to shrink the window. You repeat this until the condition is no longer met.
6. **Update the maximum length**: Each time the window is valid (replacement count ≤ k), you compare `right − left + 1` with the current `maxLen` and record the larger value as `maxLen`.

## Prerequisites

### Sliding Window

The Sliding Window technique manages a contiguous range over an array or string using two pointers (left, right). You advance `right` to expand the window and advance `left` to shrink it when the condition is violated. Since each element is processed at most twice (once for addition and once for removal), the technique runs in O(n) time.

### Managing Character Frequencies with an Array

Uppercase English letters range from `'A'` to `'Z'` (26 characters), so you can manage the frequency of each character using an `int[26]` array. You convert a character to an array index with `charAt() - 'A'`.

```java
int[] count = new int[26];           // Array that holds the frequency of each of the 26 characters
count[s.charAt(i) - 'A']++;         // Increment the frequency of the character s.charAt(i)
count[s.charAt(i) - 'A']--;         // Decrement the frequency of the character s.charAt(i)
```

### Why maxFreq Is Never Decreased

`maxFreq` represents the frequency of the most common character within the window. Even when you advance the left pointer to remove a character, you do not need to recalculate and decrease `maxFreq`. In a problem that seeks the maximum length, even if `maxFreq` drops below its historical maximum, the resulting window size in that state can never exceed the previously recorded maximum length. Therefore, managing `maxFreq` as a monotonically increasing value still produces the correct result.

## Complexity

| | Value |
|---|---|
| Time | O(n) — The right pointer and the left pointer each advance at most n times |
| Space | O(1) — The array size is fixed at 26 and does not depend on the input size |

## Code

```java
// Input: a string s of uppercase English letters and an integer k (maximum number of replacements)
// Output: return the maximum length of a substring where all characters can be made identical with at most k replacements
public int characterReplacement(String s, int k) {
    // Array that manages the frequency of each character (A–Z). Index 0 corresponds to 'A' and index 25 corresponds to 'Z'
    int[] count = new int[26];
    // left: the left boundary of the window
    int left = 0;
    // maxFreq: the frequency of the most common character in the window (managed as monotonically increasing)
    int maxFreq = 0;
    // maxLen: the maximum length of a valid substring (this value is returned at the end)
    int maxLen = 0;

    // Advance the right pointer one step at a time to expand the right boundary of the window
    for (int right = 0; right < s.length(); right++) {
        // Increment the frequency of the character added at the right boundary
        count[s.charAt(right) - 'A']++;

        // Compare the frequency of the added character with the current maxFreq and update the most frequent character count
        maxFreq = Math.max(maxFreq, count[s.charAt(right) - 'A']);

        // window size - maxFreq = number of characters that need replacement. Shrink from the left while this exceeds k
        // Note: maxFreq is not recalculated here because decreasing it would not contribute to updating the maximum length
        while (right - left + 1 - maxFreq > k) {
            // Decrement the frequency of the left boundary character and remove it from the window
            count[s.charAt(left) - 'A']--;
            left++;
        }

        // The window is valid (replacement count ≤ k), so update the maximum length with the current window size
        maxLen = Math.max(maxLen, right - left + 1);
    }
    // After the for loop ends, return the length of the longest substring of identical characters obtainable with at most k replacements
    return maxLen;
}
```
