# Checking if a String Contains a Permutation of Another

## Problem

The algorithm receives two strings `s1` and `s2`. It determines whether an anagram (a rearrangement of characters) of `s1` exists as a **contiguous substring** within `s2`, and returns `true` if such a substring exists or `false` if it does not.

## Key Insight

The statement "a permutation of `s1` is contained in `s2`" means that a substring exists within `s2` that has the same length and the same character frequency as `s1`. The algorithm scans `s2` with a fixed-length sliding window and incrementally updates the count of matching character frequencies across all 26 letters, which enables O(1) evaluation at each slide.

## Thought Process

1. **Restate the permutation condition**: A permutation of `s1` exists as a substring of `s2` if and only if `s2` contains a substring of length `m` (the length of `s1`) whose character frequency matches that of `s1` exactly
2. **Scan with a fixed-length window**: The substring length is always `m`, so the algorithm places a fixed-size window of length `m` on `s2` and slides it one character at a time while comparing character frequencies
3. **Manage character counts with frequency arrays**: Lowercase English letters have 26 varieties, so two integer arrays of size 26 (`s1F` and `winF`) track the character frequencies of `s1` and the current window respectively. Each index in the array corresponds to a specific letter
4. **Avoid comparing all 26 elements every time**: When the window slides, at most two characters change: one entering character and one leaving character. Instead of comparing all 26 elements each time, the algorithm tracks the number of characters whose frequencies match between the two arrays using a `matches` counter, and updates only the difference
5. **Update rule for the matches counter**: When the algorithm modifies a character's frequency, it decrements `matches` by 1 if that character matched before the change, and increments `matches` by 1 if that character matches after the change. Following this strict order of "check before change → apply change → check after change" maintains the counter's consistency
6. **Termination condition**: The algorithm returns `true` the moment `matches` reaches 26, because all 26 character frequencies match at that point. If `matches` never reaches 26 after sliding to the end of `s2`, the algorithm returns `false`

## Prerequisites

### Sliding Window

A sliding window is a technique that scans a contiguous subrange of an array or string by moving the left and right endpoints. For a fixed-length window, the algorithm advances the right endpoint by one position and simultaneously advances the left endpoint by one position, which keeps the window size constant.

```java
// Basic pattern for sliding a fixed-length window of size m over s2
for (int i = m; i < n; i++) {
    char entering = s2.charAt(i);       // Character entering the window (right end)
    char leaving = s2.charAt(i - m);    // Character leaving the window (left end)
}
```

### Frequency Array

A frequency array is an integer array of size 26 that stores the occurrence count of each character. It maps `'a'` to index 0 and `'z'` to index 25. The expression `charAt(i) - 'a'` converts a character to its corresponding index.

```java
int[] freq = new int[26];              // All elements are initialized to 0
freq[s.charAt(i) - 'a']++;            // Increment the occurrence count of the character by 1
freq[s.charAt(i) - 'a']--;            // Decrement the occurrence count of the character by 1
```

### Matches Counter

A matches counter tracks how many indices have equal values between two frequency arrays. When all 26 indices match, `matches == 26`, which means the two strings have identical character compositions.

```java
int matches = 0;
for (int i = 0; i < 26; i++) {
    if (s1F[i] == winF[i]) matches++;  // Count the number of matching character frequencies
}
// If matches == 26, all character frequencies are identical
```

## Complexity

| | Value |
|---|---|
| Time | O(n) — The algorithm scans `s2` only once, and each slide takes O(1) |
| Space | O(1) — The frequency arrays always have size 26, independent of input size |

## Code

```java
// Input: String s1 (the string whose permutation to search for) and String s2 (the string to search within)
// Output: true if s2 contains a permutation of s1 as a substring, false otherwise
boolean checkInclusion(String s1, String s2) {
    int m = s1.length();
    int n = s2.length();

    // If s1 is longer than s2, no permutation can be contained, so return false immediately
    if (m > n) return false;

    // Size-26 arrays to store character frequencies of s1 and the current window
    int[] s1F = new int[26];
    int[] winF = new int[26];

    // Compute frequencies for the first window (the leading m characters). Count both s1 and the first m characters of s2
    for (int i = 0; i < m; i++) {
        s1F[s1.charAt(i) - 'a']++;
        winF[s2.charAt(i) - 'a']++;
    }

    // Count how many of the 26 characters have matching frequencies (initial matches computation)
    int matches = 0;
    for (int i = 0; i < 26; i++) {
        if (s1F[i] == winF[i]) matches++;
    }

    // If all 26 character frequencies match in the first window, return true
    if (matches == 26) return true;

    // Slide the window one character to the right at a time (i is the position just past the window's right end)
    for (int i = m; i < n; i++) {
        // --- Process the character entering the window (right end) ---
        int idx = s2.charAt(i) - 'a';
        // Note: Always follow the order "check before change → apply change → check after change"
        if (winF[idx] == s1F[idx]) matches--;   // If it matched before the change, decrement matches
        winF[idx]++;                              // Increment frequency because the character enters the window
        if (winF[idx] == s1F[idx]) matches++;   // If it matches after the change, increment matches

        // --- Process the character leaving the window (left end) ---
        idx = s2.charAt(i - m) - 'a';
        // Same procedure as the entering character: check before change → apply change → check after change
        if (winF[idx] == s1F[idx]) matches--;   // If it matched before the change, decrement matches
        winF[idx]--;                              // Decrement frequency because the character leaves the window
        if (winF[idx] == s1F[idx]) matches++;   // If it matches after the change, increment matches

        // If all 26 character frequencies match, a permutation has been found, so return true
        if (matches == 26) return true;
    }

    // The window slid to the end of s2 without matches reaching 26, so return false
    return false;
}
```
