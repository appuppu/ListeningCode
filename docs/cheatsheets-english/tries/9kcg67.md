# Designing a Word Dictionary With Wildcard Search

## Problem

Design a data structure that supports two operations: adding a word and searching for a word. During search, the dot `.` functions as a wildcard that matches any single character. For example, if the dictionary contains "bad", `search("b.d")` returns `true`, and `search("b.e")` returns `false`.

## Key Insight

The system stores words in a Trie. For a regular character, the search follows a single child node. When the search encounters a dot, it branches into all child nodes and performs a depth-first search, thereby achieving matching against any single character.

## Thought Process

1. **We want to perform word addition and prefix-based search efficiently**: A Trie is suitable as a data structure that stores strings by sharing characters one at a time. A Trie allows words with common prefixes to share nodes, achieving both memory efficiency and search efficiency.
2. **Regular character search uses basic Trie operations**: For a character `c`, the search simply follows `children[c - 'a']` of the current node. If the child node is `null`, the search finds no match; if the child node exists, the search proceeds to the next character.
3. **A dot means branching into all child nodes**: Since a dot matches any single character, the search must try all non-`null` children among the 26 child nodes of the current node. If any one of them matches the remaining string, the search returns `true`.
4. **The search uses depth-first search (DFS) to explore branches**: The search recursively follows each path branched by a dot. When the search reaches the end of the word and the `isEnd` flag is `true`, the search succeeds. DFS allows the system to handle branch processing and regular character processing in a unified manner.
5. **Define the base case for recursion**: When the search has processed all characters in the string (`idx == word.length()`), the word exists if the current node's `isEnd` is `true`. If a child node becomes `null` along the way, that path yields no match.
6. **Determine what to return**: The `search` method starts a recursive DFS from the root node and returns `true` if at least one matching path exists, or `false` otherwise.

## Prerequisites

### Trie

A Trie is a tree structure that stores strings by decomposing them into individual characters at each node. Each node has up to 26 child nodes (a–z), and traversing from the root to a leaf spells out a single word. Words with common prefixes share nodes, making a Trie well-suited for storing a dictionary.

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // 26 child nodes corresponding to a–z
    boolean isEnd = false;                    // Whether a word ends at this node
}
```

### Depth-First Search (DFS)

DFS is a traversal technique for trees and graphs. It advances along one path to the very end, and when it reaches a dead end, it backtracks one step and tries another path. Recursion is a natural way to implement DFS, and it is well-suited for branching search in a Trie.


### Integer Conversion of char

In Java, the `char` type holds an integer value. The expression `c - 'a'` yields the alphabetical position (0–25) of the character `c`. The system uses this value as an index into the Trie's `children` array.

```java
char c = 'd';
int idx = c - 'a';  // idx = 3 ('a'=0, 'b'=1, 'c'=2, 'd'=3)
```

## Complexity

| | Value |
|---|---|
| Time (addWord) | O(m) — The operation traverses Trie nodes proportionally to the word length m |
| Time (search) | O(26^d × m) — d is the number of dots, m is the word length. Without dots, it is O(m) |
| Space | O(n × m) — The Trie stores n words with an average length of m |

## Code

```java
// Input: addWord(word) receives a string word and adds it to the dictionary. search(word) receives a string word (which may contain ".").
// Output: search returns true if a matching word exists in the dictionary, or false if no matching word exists.

class TrieNode {
    TrieNode[] children;  // 26 child nodes corresponding to a–z
    boolean isEnd;        // Whether a word ends at this node

    TrieNode() {
        children = new TrieNode[26];
        isEnd = false;
    }
}

class WordDictionary {
    TrieNode root;  // Root node of the Trie

    WordDictionary() {
        root = new TrieNode();
    }

    // Add a word to the Trie
    void addWord(String word) {
        // Initialize the current node to the root
        TrieNode node = root;
        // Process each character of the word from the beginning
        for (char c : word.toCharArray()) {
            // c - 'a' determines which position in the children array corresponds to the character c
            int idx = c - 'a';
            // Create a new child node if one does not exist
            if (node.children[idx] == null)
                node.children[idx] = new TrieNode();
            // Move to the child node
            node = node.children[idx];
        }
        // Mark the end of the word, indicating that a word ending at this node exists in the dictionary
        node.isEnd = true;
    }

    // Start the wildcard search from the root
    boolean search(String word) {
        // Start DFS from the root node at position 0
        return dfs(root, word, 0);
    }

    // Recursively explore the Trie using DFS
    boolean dfs(TrieNode node, String word, int idx) {
        // Base case: if all characters have been processed, return whether the current node is the end of a word
        // true means the word exists; false means only a partial match exists
        if (idx == word.length())
            return node.isEnd;

        char c = word.charAt(idx);

        if (c == '.') {
            // Dot case: try all 26 child nodes (matching any single character)
            for (TrieNode child : node.children) {
                // Recursively search each non-null child node
                if (child != null && dfs(child, word, idx + 1))
                    return true;  // Return true immediately if any path matches
            }
            // No match found after trying all child nodes
            return false;
        } else {
            // Regular character case: compute the index using c - 'a' and follow the corresponding child node
            int i = c - 'a';
            // No match if the child node does not exist, meaning the corresponding character is absent
            if (node.children[i] == null)
                return false;
            // If the child node exists, recurse with the next character position idx + 1
            return dfs(node.children[i], word, idx + 1);
        }
    }
}
```
