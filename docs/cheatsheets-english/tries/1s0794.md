# Finding All Words From a Dictionary in a Grid — Searching for All Dictionary Words in a Grid Simultaneously

## Problem

The system receives a 2D grid of characters `board` and a word list `words`. The algorithm finds and returns all words from `words` that can be formed by sequentially tracing adjacent cells (up, down, left, right) on the grid. Each cell can only be used once during the construction of a single word.

## Key Insight

The algorithm stores all words from the word list in a Trie and traverses Trie nodes during DFS from each grid cell, enabling simultaneous searching of all words. The Trie immediately prunes DFS in directions where no branch exists, significantly reducing unnecessary exploration.

## Thought Process

1. **Searching for multiple words simultaneously**: Performing individual DFS for each word results in a complexity of word count × total grid cells × maximum word length. When multiple words share a common prefix, performing a single DFS that searches for multiple words simultaneously is more efficient.
2. **A Trie is ideal for managing common prefixes**: A Trie, also known as a prefix tree, shares common prefixes of strings as a single path. After inserting all words into the Trie, the algorithm can determine in O(1) whether the current path matches any word's prefix during DFS.
3. **Storing the complete word at the Trie node**: By storing the complete word string at the terminal node of each word, the algorithm can immediately retrieve which word was found when DFS reaches that node.
4. **Performing DFS from each grid cell starting at the Trie root**: The algorithm starts DFS from each cell, following characters from the Trie root. If the Trie has no child node corresponding to the current character, the algorithm immediately prunes that direction.
5. **Marking visited cells**: To prevent revisiting the same cell during DFS, the algorithm temporarily replaces the current cell's character with a special character `'#'`. After the DFS completes, it restores the original character (backtracking).
6. **Preventing duplicates**: The same word may be found via multiple paths. When the algorithm adds a word to the result list, it sets the Trie node's `word` to `null` to prevent adding the same word again.

## Prerequisites

### What is a Trie?

A Trie is a tree data structure that efficiently stores and searches a set of strings. Each node has up to 26 child nodes (a–z), and a path from the root to a leaf represents one string. Strings that share a common prefix share a path, so the algorithm can determine prefix matches in O(string length).

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // Array of 26 child nodes for a–z
    String word = null;                       // The word completed at this node (null if not a terminal)
}

// Inserting a word into the Trie
TrieNode root = new TrieNode();
TrieNode node = root;
for (char c : "cat".toCharArray()) {
    int i = c - 'a';                          // Convert character to index ('a'→0, 'b'→1, ...)
    if (node.children[i] == null)
        node.children[i] = new TrieNode();    // Create a new child node if it does not exist
    node = node.children[i];                  // Move to the child node
}
node.word = "cat";                            // Store the word at the terminal node
```

### What is Backtracking?

Backtracking is a variant of DFS (Depth-First Search) that modifies state during exploration and restores the state after exploration completes. This technique guarantees that state changes made during one exploration path do not affect other paths.

```java
board[r][c] = '#';    // Mark the cell as visited (prevents other paths from revisiting this cell)
// ... DFS explores up, down, left, and right ...
board[r][c] = ch;     // Restore the original character (makes the cell available for exploration from other starting points)
```

### Conversion Between char and int

In Java, the `char` type holds an integer value, so the algorithm can compute character differences to convert characters into indices.

```java
char ch = 'c';
int index = ch - 'a';   // 'c' - 'a' = 2 (used as an array index)
```

## Complexity

| | Value |
|---|---|
| Time | O(M × N × 4^L) — M×N is the number of grid cells, and L is the length of the longest word. The algorithm recurses up to 4 directions L times from each cell. |
| Space | O(total number of characters across all words) — Space required to store all words in the Trie. |

## Code

```java
// Input: 2D character array board and string array words
// Output: Returns a List<String> containing all words that can be formed on the board

class TrieNode {
    TrieNode[] children = new TrieNode[26];  // Child nodes for a–z
    String word = null;                       // The word completed at this node
}

// Insert all words into the Trie and return the root node
TrieNode buildTrie(String[] words) {
    // Create a single root node to build an empty Trie (serves as the starting point for all word searches)
    TrieNode root = new TrieNode();
    // Insert each word from words into the Trie
    for (String w : words) {
        TrieNode node = root;
        // Traverse child nodes one character at a time from the root
        for (char c : w.toCharArray()) {
            int i = c - 'a';
            // Create a new child node if it does not exist
            if (node.children[i] == null)
                node.children[i] = new TrieNode();
            node = node.children[i];
        }
        // Store the word string at the terminal node (allows immediate retrieval of the completed word when DFS reaches this node)
        node.word = w;
    }
    return root;
}

// Perform DFS on the grid while traversing Trie nodes
void dfs(char[][] board, int r, int c,
    TrieNode node, List<String> res) {
    // Boundary check: return immediately if row r or column c is outside the grid
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length)
        return;
    char ch = board[r][c];
    // Return immediately if the cell is marked '#' as visited (prevents revisiting within the same path)
    if (ch == '#') return;
    // Get the Trie child node corresponding to the current character
    TrieNode next = node.children[ch - 'a'];
    // If no child node exists, no word in the Trie continues in this direction (pruning)
    if (next == null) return;
    // If a word is complete, add it to the result and set it to null to prevent duplicates
    // (the same word may be found via multiple paths)
    if (next.word != null) {
        res.add(next.word);
        next.word = null;
    }
    // Replace the current cell with '#' to mark it as visited
    board[r][c] = '#';
    // Recursively perform DFS in all 4 directions, passing the next node
    dfs(board, r + 1, c, next, res);
    dfs(board, r - 1, c, next, res);
    dfs(board, r, c + 1, next, res);
    dfs(board, r, c - 1, next, res);
    // Restore the cell's original character ch (backtracking: makes the cell available for exploration from other starting points)
    board[r][c] = ch;
}

// Main function: search for all dictionary words on the grid
List<String> findWords(char[][] board, String[] words) {
    // Insert all words into the Trie
    TrieNode root = buildTrie(words);
    // Create an empty list to store the results
    List<String> res = new ArrayList<>();
    // Iterate over all cells (i, j) with a nested for loop and perform DFS from each cell as the starting point
    // Pass the Trie root node to the DFS
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            dfs(board, i, j, root, res);
        }
    }
    // Return the results after DFS from all cells is complete
    return res;
}
```
