# Merging Overlapping Intervals — Merge All Overlapping Intervals

## Problem

The system gives you an array `intervals` of intervals (pairs of start and end values). You merge all overlapping intervals and return a list of non-overlapping intervals.

## Key Insight

Sorting the intervals by their start values ensures that only adjacent intervals can overlap. After sorting, you scan from left to right: if the current interval overlaps with the previous one, you update the end value; otherwise, you add the current interval as a new entry.

## Thought Process

1. **Simplify the overlap check**: Without sorting, you would need to compare every pair of intervals. Sorting in ascending order by start value reduces the overlap check to a single condition: "the end value of the previous interval ≥ the start value of the current interval."
2. **A single pass merges all intervals after sorting**: You iterate through the sorted intervals from the beginning. You compare the last interval in the result list with the current interval — if they overlap, you update the end value to the larger one. If they do not overlap, you append the current interval to the result list as-is.
3. **You need access to the tail of the result list**: The merge check always references the end value of the most recently added interval in the result list. Using a LinkedList provides O(1) tail access via `getLast()`.
4. **Define the overlap condition precisely**: When the end value of the previous interval is less than the start value of the current interval (`res.getLast()[1] < interval[0]`), the two intervals do not overlap. In all other cases (end value ≥ start value), the intervals overlap and you merge them.
5. **Merging only updates the end value**: Because the intervals are sorted, the start value of the previous interval is always less than or equal to that of the current one. You take the larger of the two end values using `Math.max()` to compare the previous end value with the current end value.
6. **Return the final result**: You convert all non-overlapping intervals accumulated in the result list into a two-dimensional `int[][]` array and return it.

## Prerequisites

### Arrays.sort with a Custom Comparator

`Arrays.sort` is a method that sorts an array. For a two-dimensional array, you specify a Comparator using a lambda expression to define which element serves as the sort key.

```java
int[][] intervals = {{3, 6}, {1, 3}, {2, 5}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // Sort in ascending order by each interval's start value (index 0)
// Result: {{1, 3}, {2, 5}, {3, 6}}
```

### What Is a LinkedList

A LinkedList is a list that supports O(1) addition to the head/tail and O(1) retrieval of the tail element. Unlike ArrayList, it provides direct access to the tail element via the `getLast()` method.

```java
LinkedList<int[]> res = new LinkedList<>();  // Create an empty LinkedList
res.add(new int[]{1, 3});   // Append an element to the tail
res.getLast();               // Retrieve the tail element → {1, 3}
res.getLast()[1] = 5;        // Directly update the end value of the tail element → {1, 5}
res.isEmpty();               // Return a boolean indicating whether the list is empty → false
res.size();                  // Return the number of elements in the list → 1
```

### What Is Math.max

`Math.max` is a method that returns the larger of two values. In interval merging, you use it to select the larger of the two end values.

```java
Math.max(5, 8);   // → 8
Math.max(10, 3);  // → 10
```

## Complexity

| | Value |
|---|---|
| Time | O(n log n) — Sorting takes O(n log n) and the scan takes O(n), so the overall complexity is O(n log n) |
| Space | O(n) — The result list stores at most n intervals |

## Code

```java
// Input: a two-dimensional array of intervals int[][] intervals (each element is [start, end])
// Output: return a two-dimensional array int[][] after merging all overlapping intervals
public int[][] merge(int[][] intervals) {
    // Sorting limits the overlap check to only adjacent interval comparisons
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // Result list that accumulates merged intervals
    // Using LinkedList because it provides O(1) reference and update of the tail element
    LinkedList<int[]> res = new LinkedList<>();

    for (int[] interval : intervals) {
        // If res is empty, this is the first interval so add it unconditionally
        // If res.getLast()[1] < interval[0], the current interval does not overlap with the previous one so add it as-is
        if (res.isEmpty() || res.getLast()[1] < interval[0]) {
            res.add(interval);
        } else {
            // If they overlap, update the end value to the larger one to merge them
            // The start value needs no change because sorting guarantees the previous interval's start is less than or equal
            res.getLast()[1] = Math.max(res.getLast()[1], interval[1]);
        }
    }

    // Convert the result list to a two-dimensional array and return it
    return res.toArray(new int[res.size()][]);
}
```
