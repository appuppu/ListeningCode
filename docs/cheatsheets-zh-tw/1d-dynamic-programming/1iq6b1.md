# Finding the Subarray With Maximum Product — 尋找具有最大乘積的連續子陣列

## 問題的本質

給定一個整數陣列 `nums`。從陣列中選出一個**連續子陣列**，找到元素乘積最大的子陣列，並返回該**乘積**。子陣列由一個或多個連續元素組成。

## 核心思路

負數相乘會變成正數，因此當前的最小值（絕對值最大的負數）與下一個負數相乘時，可能會變成最大值。因此，需要在每個位置同時追蹤「當前最大乘積」和「當前最小乘積」。

## 思考過程

1. **考慮子陣列乘積的特性**：在求連續子陣列乘積的問題中，每增加一個元素，就可以用「前一個子陣列的乘積 × 當前元素」來計算新的乘積。這與 DP 的思路相同，可以從前一個狀態推導出下一個狀態
2. **負數使最大乘積的計算變得複雜**：如果只有正數，只需追蹤最大乘積即可，但當存在負數時，會發生「較大的負乘積 × 負數 = 較大的正乘積」的情況。也就是說，如果不同時追蹤當前最小乘積（負方向上絕對值最大的值），就可能遺漏最大乘積
3. **每個位置的候選值縮減為三個**：位置 `i` 的最大乘積候選值為：(a) `nums[i]` 本身（開始一個新的子陣列）、(b) `curMax * nums[i]`（延長正的最大乘積）、(c) `curMin * nums[i]`（負的最小乘積因負數而翻轉）。這三者的最大值即為新的 `curMax`
4. **最小乘積也從相同的三個候選值中選取**：最小乘積的候選值也是相同的三個值，其最小值即為新的 `curMin`。透過同時更新最大值和最小值，可以正確捕捉負數導致的翻轉
5. **更新時需要保存先前的值**：如果在更新 `curMax` 之後再計算 `curMin`，則 `curMin` 的計算將無法使用更新前的 `curMax`。因此，在更新 `curMax` 之前，需要將其值保存到臨時變數 `temp` 中，並在計算 `curMin` 時使用 `temp`
6. **用另一個變數管理全域最大值**：`curMax` 是當前位置的最大乘積，而非整體的最大乘積。在每個位置透過 `result = Math.max(result, curMax)` 來更新整體最大乘積，最終返回 `result`

## 前置知識

### 子陣列乘積與 DP 的關係

子陣列的乘積可以透過將前一個位置的乘積乘以當前元素來延長。利用這個性質，可以在每個位置以 O(1) 的時間從前一個位置的結果計算「以此位置結尾的子陣列的最大乘積」。這是一種保持前一個狀態並推導下一個狀態的方法，與 DP 相同。

### 什麼是 Math.max / Math.min

這是 Java 中從多個值取得最大值和最小值的方法。若要比較三個以上的值，可以透過巢狀呼叫來實現。

```java
Math.max(3, 7);                   // 返回兩個值的最大值 → 7
Math.min(3, 7);                   // 返回兩個值的最小值 → 3
Math.max(a, Math.max(b, c));      // 返回三個值的最大值
Math.min(a, Math.min(b, c));      // 返回三個值的最小值
```

### 為什麼需要追蹤最小值

在包含負數的陣列中，乘積的正負號會隨每個元素翻轉。例如：對於 `[-2, 3, -4]`，位置 1 的最小乘積為 `-2 × 3 = -6`，但在位置 2 時 `-6 × -4 = 24` 變成了最大乘積。如果只追蹤最大乘積，就會丟棄 `-6`，從而遺漏 `24`。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需遍歷陣列一次 |
| Space | O(1) — 使用的變數數量固定，不依賴於輸入大小 |

## 程式碼

```java
// 輸入：整數陣列 nums（長度至少為 1）
// 輸出：以 int 返回連續子陣列乘積的最大值
public int maxProduct(int[] nums) {
    // result=整體最大乘積、curMax=以當前位置結尾的子陣列最大乘積、curMin=同最小乘積
    // 初始狀態為僅包含第一個元素的子陣列
    int result = nums[0];
    int curMax = nums[0];
    int curMin = nums[0];

    // i=0 已在初始化中處理完畢，因此從 i=1 開始
    for (int i = 1; i < nums.length; i++) {
        int n = nums[i];
        // 在更新 curMax 之前先保存其值（因為計算 curMin 時需要更新前的值）
        int temp = curMax;

        // 從三個候選值中選取最大值：
        // n 本身 → 開始一個新的子陣列
        // temp * n → 延長前一個最大乘積
        // curMin * n → 前一個最小乘積（負數）因負數 n 翻轉而變成最大值
        curMax = Math.max(n,
            Math.max(temp * n, curMin * n));

        // 從相同的三個候選值中選取最小值（使用 temp 中更新前的 curMax，避免受到上方更新的影響，確保計算正確）
        curMin = Math.min(n,
            Math.min(temp * n, curMin * n));

        // curMax 是當前位置的最大乘積，而非整體最大乘積，因此用另一個變數 result 來管理整體最大乘積
        result = Math.max(result, curMax);
    }
    // result 中儲存了遍歷整個陣列後的最大子陣列乘積
    return result;
}
```
