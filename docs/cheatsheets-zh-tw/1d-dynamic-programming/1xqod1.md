# Counting All Palindromic Substrings — 計算字串中所有回文子字串的總數

## 問題的本質

給定一個字串 `s`。在 `s` 的所有子字串中，返回屬於回文（從前往後讀和從後往前讀相同的字串）的子字串**總數**。每個單一字元的子字串也計為回文。

## 核心思路

所有回文都存在一個「中心」。固定中心並向左右兩側擴展，就能列舉從該中心產生的所有回文。中心的候選位置只有每個字元（奇數長度）和相鄰兩個字元之間（偶數長度），總共 2n-1 個，因此可以進行全面搜尋。

## 思考過程

1. **關注回文的結構性質**：所有回文都相對於中心呈左右對稱。奇數長度的回文以1個字元為中心，偶數長度的回文以相鄰的2個字元為中心。利用這個性質，可以從中心出發高效地發現回文
2. **從中心向外側擴展**：對於某個中心，設定左右指標 `left` 和 `right`，只要 `s.charAt(left) == s.charAt(right)` 就繼續向外側擴展。每次擴展成功就找到一個新的回文，因此將計數加1
3. **分別處理奇數長度和偶數長度**：對於每個索引 `i`，用 `expand(s, i, i)` 計算奇數長度的回文，用 `expand(s, i, i+1)` 計算偶數長度的回文。透過這兩次呼叫，可以涵蓋以 `i` 為中心的所有回文
4. **確定擴展的停止條件**：當 `left` 小於0、`right` 大於等於字串長度、或左右字元不一致時，停止擴展。這樣既能防止越界存取，又能進行最大限度的擴展
5. **合計各中心的結果**：將所有索引的奇數長度和偶數長度回文數相加，即為整個字串的回文子字串總數
6. **最終返回值**：將從所有中心獲得的回文數合計作為整數 `result` 返回

## 前置知識

### 回文（Palindrome）

從前往後讀和從後往前讀都相同的字串。`"aba"`、`"abba"`、`"a"` 都是回文。回文分為奇數長度（中心為1個字元）和偶數長度（中心在2個字元之間）兩種。

```
奇數長度的例子: "aba"  → 中心是 'b'
偶數長度的例子: "abba" → 中心在 'b' 和 'b' 之間
```

### 中心擴展法（Expand Around Center）

固定回文的中心，逐次向左右各擴展1個字元，判斷是否為回文的方法。從中心向外側擴展，只要字元一致就繼續擴展，當字元不一致時停止。

```
字串: "abacd"
從中心 i=1 ('b') 開始擴展:
  left=1, right=1 → 'b'=='b' → 發現回文 "b"，count=1
  left=0, right=2 → 'a'=='a' → 發現回文 "aba"，count=2
  left=-1 → 超出範圍，停止
```

### String.charAt(int index)

返回字串中指定索引位置的字元的方法。索引從0開始。

```java
String s = "abc";
s.charAt(0);    // 返回 'a'
s.charAt(2);    // 返回 'c'
s.length();     // 返回字串的長度 → 3
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n²) — 對每個中心（n個）進行最多 O(n) 的擴展 |
| Space | O(1) — 僅使用指標和計數器，不使用額外的資料結構 |

## 程式碼

```java
// 輸入: 字串 s
// 輸出: 以整數返回 s 的回文子字串總數

// 從指定的中心向左右擴展，返回找到的回文數量
// left 和 right 相同時探索奇數長度的回文，相鄰時探索偶數長度的回文
int expand(String s, int left, int right) {
    int count = 0;
    // 滿足以下3個條件時持續擴展: 左端在範圍內、右端在範圍內、左右字元一致
    while (left >= 0 && right < s.length()
            && s.charAt(left) == s.charAt(right)) {
        count++;   // s.substring(left, right+1) 是新的回文，計數加1
        left--;    // 向左擴展1格
        right++;   // 向右擴展1格
    }
    // 返回從此中心找到的回文總數
    return count;
}

int countSubstrings(String s) {
    // 累積從所有中心找到的回文數量的變數
    int result = 0;

    // 將每個索引作為中心候選進行遍歷
    for (int i = 0; i < s.length(); i++) {
        // 奇數長度的回文: left=i, right=i，從1個字元的中心開始擴展
        result += expand(s, i, i);
        // 偶數長度的回文: left=i, right=i+1，從相鄰2個字元的中心開始擴展
        result += expand(s, i, i + 1);
    }
    // 返回從所有中心獲得的回文數合計
    return result;
}
```
