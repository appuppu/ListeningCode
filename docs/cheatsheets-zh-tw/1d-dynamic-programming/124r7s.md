# Partitioning an Array Into Two Equal Sum Subsets — 判斷能否將陣列分割為總和相等的兩個子集

## 問題的本質

給定一個整數陣列 `nums`。判斷能否將此陣列分割為兩個子集，使兩個子集的元素總和相等，並以 `boolean` 回傳結果。每個元素必須恰好屬於其中一個子集，不可重複使用。

## 核心思路

若陣列總和為奇數，可立即判定為 false。若總和為偶數，則可將問題歸結為「是否存在一個子集，其總和恰好等於總和的一半 `target`」的「子集和問題」。使用一維 boolean 型 DP 陣列，依序處理每個元素並記錄可達成的總和值，即可在 O(n × target) 內判斷是否能達成 `target`。

## 思考過程

1. **思考二等分的條件**：當陣列全體總和為 `sum` 時，要使兩個子集的總和各自相等，每個子集的總和必須為 `sum / 2`。若 `sum` 為奇數，則無法以整數進行二等分，因此可立即回傳 false
2. **將問題轉換為「子集和問題」**：只要其中一個子集的總和為 `target = sum / 2`，另一個子集的總和也自動為 `target`。亦即可將問題歸結為「從陣列元素中是否存在總和為 `target` 的子集」這一子集和問題
3. **以 DP 管理可達成的總和值**：準備一個 boolean 型陣列 `dp`，`dp[j]` 表示「從目前已處理的元素中，能否組成總和 `j`」。初始狀態設為 `dp[0] = true`（不選任何元素時總和為 0）
4. **以每個元素更新可達成的總和值**：對於陣列中的每個元素 `num`，若已可達成的總和值 `j` 加上 `num` 得到的 `j + num` 也變為可達成。此操作即為：若 `dp[j]` 為 true，則將 `dp[j + num]` 也設為 true
5. **以逆序遍歷防止重複使用**：內層迴圈從 `target` 到 `num` 進行逆序遍歷。若以正序遍歷，`dp` 會因同一元素被多次使用的結果而被更新。以逆序遍歷則可保證每個元素最多只被使用一次
6. **最終回傳 `dp[target]`**：處理完所有元素後，若 `dp[target]` 為 true，表示存在總和為 `target` 的子集，因此回傳 true；若為 false，則表示不存在這樣的子集

## 前提知識

### 何謂子集和問題（Subset Sum Problem）

從給定的整數集合中，選取若干元素使其總和恰好等於目標值，判斷是否可行的問題。這是可用 DP（動態規劃法）高效求解的代表性問題。

### 何謂 boolean 型一維 DP 陣列

`dp[j]` 以 true/false 表示「能否組成總和 `j`」的陣列。每處理一個元素，可達成的總和值集合就會逐步擴展。

```java
boolean[] dp = new boolean[target + 1];  // 建立大小為 target+1 的陣列（初始值全部為 false）
dp[0] = true;                            // 不選任何元素時，總和 0 始終可達成
dp[j - num] == true                      // 若能組成總和 j-num，則加上 num 後也能組成總和 j
```

### 以逆序更新 DP 陣列的原因

若以正序（從小的 `j` 到大的 `j`）更新，同一元素 `num` 被多次使用的結果會產生傳播。若以逆序（從大的 `j` 到小的 `j`）更新，則可保證每個元素僅被使用一次。

```java
// 逆序迴圈：j 從 target 到 num 每次遞減 1
for (int j = target; j >= num; j--) {
    if (dp[j - num]) dp[j] = true;
}
```

## 計算量

| | 值 |
|---|---|
| Time | O(n × target) — 對 n 個元素分別遍歷最多到 target 的 DP 陣列 |
| Space | O(target) — 使用一個大小為 target+1 的 boolean 型 DP 陣列 |

## 程式碼

```java
// 輸入：整數陣列 nums
// 輸出：以 boolean 回傳能否將陣列分割為總和相等的兩個子集
boolean canPartition(int[] nums) {
    // 計算陣列所有元素的總和，求出判斷能否二等分的基準值
    int sum = 0;
    for (int n : nums) sum += n;

    // 若總和為奇數，無法以整數二等分，因此回傳 false
    if (sum % 2 != 0) return false;

    // 其中一個子集應達成的目標總和值。另一個子集的總和也自動為 target
    int target = sum / 2;

    // dp[j] = 從目前已處理的元素中能否組成總和 j（子集和問題的 DP 陣列）
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;  // 不選任何元素時，總和 0 始終可達成

    // 從頭到尾依序處理陣列的每個元素，更新可達成的總和值集合
    for (int num : nums) {
        // 以逆序遍歷防止同一元素被重複使用（正序遍歷會導致 num 被多次加算的結果產生傳播）
        for (int j = target; j >= num; j--) {
            // 若能組成總和 j-num，則加上 num 後也能組成總和 j，因此更新為 true
            if (dp[j - num]) dp[j] = true;
        }
    }

    // 若 dp[target] 為 true，表示存在總和為 target 的子集，因此可進行二等分
    return dp[target];
}
```
