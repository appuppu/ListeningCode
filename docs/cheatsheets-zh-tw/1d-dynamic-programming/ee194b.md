# Maximizing Robbery Loot in a Circular Neighborhood — 從環形排列的房屋中不相鄰地偷取最大金額

## 問題的本質

系統給定一個非負整數陣列 `nums`。每個元素代表環形排列的房屋中的金額。小偷不能連續偷取相鄰的兩棟房屋。在**第一棟房屋與最後一棟房屋也相鄰**的限制條件下，求小偷能偷取的最大金額。

## 核心思路

環形的限制條件可以歸結為「不能同時選擇第一棟房屋和最後一棟房屋」。因此，將問題分成「包含第一棟房屋但排除最後一棟的範圍」和「包含最後一棟房屋但排除第一棟的範圍」兩次，分別求解線性版的 House Robber，取較大值即可滿足環形的限制條件。

## 思考過程

1. **分解環形的限制條件**：在環形陣列中，`nums[0]` 與 `nums[n-1]` 相鄰。也就是說，小偷不能同時選擇兩者。這可以分解為「若選擇 `nums[0]`，則不能選擇 `nums[n-1]`」和「若選擇 `nums[n-1]`，則不能選擇 `nums[0]`」兩個情況
2. **歸結為兩個線性問題**：情況一是在 `nums[0..n-2]`（包含第一棟，排除最後一棟）的範圍內求解線性版 House Robber；情況二是在 `nums[1..n-1]`（排除第一棟，包含最後一棟）的範圍內求解。兩個結果中較大者即為答案
3. **建立線性版的遞推公式**：對於每棟房屋 `i`，有「偷取房屋 `i`」或「不偷取」兩種選擇。若偷取，金額為 `nums[i] + dp[i-2]`（跳過前一棟）；若不偷取，金額為 `dp[i-1]`（直接繼承到前一棟為止的最大值）。因此 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
4. **將空間壓縮為常數**：遞推公式只參考 `dp[i-1]` 和 `dp[i-2]` 兩個值。不需要保留整個 DP 陣列，只需兩個變數 `prev1`（前一棟的最大值）和 `prev2`（前兩棟的最大值）即可完成計算
5. **處理邊界情況**：若陣列為空，則回傳 0。若只有一個元素，則環形限制不影響結果，直接回傳該值。只有在元素為兩個以上時，才執行兩次掃描的處理
6. **最終回傳值**：對兩個範圍分別求得的最大金額，使用 `Math.max` 選出較大者並回傳

## 前置知識

### House Robber（線性版）是什麼

House Robber 是從一列排列的房屋中，不連續選擇相鄰房屋以取得最大金額的問題。這是 DP 的基礎問題，可用遞推公式 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` 求解。此環形版透過將線性版套用兩次來求解。

### 使用滾動變數的 DP 空間最佳化

這是一種只保留遞推公式所參考的最近幾個值作為變數的技巧。由於不需要保留整個陣列，空間複雜度可從 O(n) 降低至 O(1)。

```java
int prev2 = 0, prev1 = 0;        // 初始化對應 dp[i-2] 和 dp[i-1] 的變數
int curr = Math.max(prev1, prev2 + nums[i]);  // 計算 dp[i]
prev2 = prev1;                    // 將 prev2 向前推進一步（舊的 prev1 成為新的 prev2）
prev1 = curr;                     // 將 prev1 向前推進一步（curr 成為新的 prev1）
```

### Math.max 是什麼

Math.max 是 Java 的標準方法，用於回傳兩個值中較大的一個。在 DP 轉移中，用來選擇「偷取的情況」和「不偷取的情況」的最大值。

```java
Math.max(5, 3);   // → 5（回傳較大的值）
Math.max(prev1, prev2 + nums[i]);  // 選擇不偷取的情況與偷取的情況中的最大值
```

## 複雜度

| | 值 |
|---|---|
| Time | O(n) — 雖然掃描陣列兩次，但每次掃描為 O(n)，因此整體為 O(n) |
| Space | O(1) — 不使用 DP 陣列，僅用兩個滾動變數進行計算 |

## 程式碼

```java
// 輸入：非負整數陣列 nums（環形排列的各房屋金額）
// 輸出：在不連續偷取相鄰房屋的條件下，能取得的最大金額，以 int 回傳

// 對指定範圍（start 到 end）求解線性版 House Robber 的輔助方法
private int robRange(int[] nums, int start, int end) {
    // 初始化為 0，因為在不偷取任何房屋的狀態下金額為 0
    int prev2 = 0, prev1 = 0;  // 保存前兩棟和前一棟最大金額的滾動變數
    // 從指定範圍的起始到末尾逐一掃描
    for (int i = start; i <= end; i++) {
        // prev1：不偷取房屋 i，繼承到前一棟為止的最大值的選項
        // prev2 + nums[i]：偷取房屋 i，將當前金額加上到前兩棟為止的最大值的選項
        int curr = Math.max(prev1,
            prev2 + nums[i]);
        // 將滾動變數向前推進一步（在下一次迭代中，curr 充當 prev1，prev1 充當 prev2 的角色）
        prev2 = prev1;
        prev1 = curr;
    }
    // prev1 中儲存了考慮整個指定範圍後的最大金額
    return prev1;
}

public int rob(int[] nums) {
    int n = nums.length;
    if (n == 0) return 0;        // 若沒有房屋，則回傳 0
    if (n == 1) return nums[0];  // 若只有一棟房屋，則不會產生相鄰限制，該值即為答案

    // 將環形限制分解為兩個線性問題，回傳較大者
    // 由於保證不會同時選擇第一棟和最後一棟房屋，因此能滿足環形的限制條件
    return Math.max(
        robRange(nums, 0, n - 2),   // 包含第一棟房屋但排除最後一棟的範圍（索引 0 到 n-2）
        robRange(nums, 1, n - 1));  // 排除第一棟房屋但包含最後一棟的範圍（索引 1 到 n-1）
}
```
