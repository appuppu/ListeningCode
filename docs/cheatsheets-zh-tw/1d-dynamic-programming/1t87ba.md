# Maximizing Robbery Loot Without Adjacent Houses — 求在不搶劫相鄰房屋的條件下可盜取的最大金額

## 問題的本質

給定一個整數陣列 `nums`，每個元素代表街道上每棟房屋中的金額。在不能同時搶劫相鄰兩棟房屋的約束下，返回一晚能盜取的**最大金額**。若搶劫了房屋 `i`，則不能搶劫房屋 `i-1` 和房屋 `i+1`。

## 核心思路

對於每棟房屋都有「搶劫或不搶劫」兩種選擇。若選擇搶劫，則將當前金額加上前兩棟房屋為止的最大值；若選擇不搶劫，則直接繼承前一棟房屋為止的最大值。由於這個判斷只需要前兩個值，因此不需要陣列，僅用兩個變數即可完成計算。

## 思考過程

1. **每棟房屋都需要做出「搶劫/不搶劫」的最佳判斷**：若搶劫房屋 `i`，則不能搶劫房屋 `i-1`，因此可獲得房屋 `i-2` 為止的最大值加上 `nums[i]`。若不搶劫，則房屋 `i-1` 為止的最大值直接保留。也就是說，每棟房屋的最大值可表示為 `max(房屋i-1為止的最大值, 房屋i-2為止的最大值 + nums[i])`
2. **建立遞推公式**：透過遞推公式 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`，可以從頭開始依序計算到每棟房屋為止的最大金額。這是典型的動態規劃結構
3. **所需資訊僅為前兩個值**：觀察遞推公式可知，計算 `dp[i]` 只需要 `dp[i-1]` 和 `dp[i-2]` 兩個值。不需要保存整個陣列，兩個變數（`prev1` 和 `prev2`）就足夠了
4. **考慮變數的更新順序**：計算出 `curr` 之後，在下一次迭代中，當前的 `prev1` 會成為新的 `prev2`，而 `curr` 會成為新的 `prev1`。按此順序更新可避免值被覆蓋
5. **設定初始值**：在開始遍歷之前，將 `prev1 = 0`（前一棟的最大值）和 `prev2 = 0`（前兩棟的最大值）。當房屋數為0時結果為0，第一棟房屋時 `max(0, 0 + nums[0]) = nums[0]`，運作正確
6. **最終返回值**：遍歷完所有房屋後的 `prev1` 即為整體的最大金額

## 前提知識

### 什麼是動態規劃（Dynamic Programming）

動態規劃是一種將大問題分解為小的子問題，並重複利用各子問題的解來構建整體解的方法。當存在重疊的子問題時，可以避免重複計算。在此問題中，「到房屋 `i` 為止的最大金額」即為子問題。

### 什麼是 Math.max

Math.max 是 Java 的標準方法，返回兩個值中較大的那個。可以用一行程式碼取代條件分支。

```java
Math.max(5, 3);    // → 5（返回較大的值）
Math.max(prev1, prev2 + num);  // 返回 prev1 和 prev2+num 中較大的值
```

### 什麼是增強型 for 迴圈（for-each）

增強型 for 迴圈是一種從陣列的開頭依序逐一取出所有元素進行處理的迴圈語法。不使用索引，而是直接存取元素。

```java
int[] nums = {2, 7, 9, 3};
for (int num : nums) {   // 將 nums 的每個元素依序賦值給 num 並執行迴圈
    System.out.println(num);  // 依序輸出 2, 7, 9, 3
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需遍歷陣列一次 |
| Space | O(1) — 僅使用兩個變數，不依賴輸入大小 |

## 程式碼

```java
// 輸入：整數陣列 nums（每棟房屋的金額）
// 輸出：在不搶劫相鄰房屋的約束下，可盜取的最大金額，以 int 返回
public int rob(int[] nums) {
    // prev2：到前兩棟房屋為止的最大金額。遍歷開始前不存在房屋，因此為0
    int prev2 = 0;
    // prev1：到前一棟房屋為止的最大金額。同樣在遍歷開始前為0
    int prev1 = 0;

    // 使用增強型 for 迴圈從頭到尾逐一遍歷陣列 nums 的每個元素
    for (int num : nums) {
        // 選擇「不搶劫當前房屋(prev1)」和「搶劫當前房屋(prev2+num)」中較大的值
        // 搶劫當前房屋時使用 prev2，是因為不能搶劫相鄰的 prev1 所對應的房屋
        int curr = Math.max(prev1,
            prev2 + num);
        // 為下一次迭代滑動變數
        // 當前的 prev1（前一棟的最大值）在下一次迭代中成為前兩棟的最大值
        prev2 = prev1;
        // 剛計算出的 curr（到當前房屋為止的最大值）在下一次迭代中成為前一棟的最大值
        // 注意：此更新必須在 prev2 = prev1 之後執行。若先更新 prev1，則無法將正確的值賦給 prev2
        prev1 = curr;
    }
    // 返回考慮所有房屋後的最大金額。prev1 中儲存了考慮到最後一棟房屋為止的最大金額
    return prev1;
}
```
