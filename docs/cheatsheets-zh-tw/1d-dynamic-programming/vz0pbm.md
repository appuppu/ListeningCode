# Finding the Minimum Cost to Climb Stairs — 求解到達階梯頂端的最小成本

## 問題的本質

給定一個整數陣列 `cost`，其中 `cost[i]` 表示踏上第 i 階的成本。可以從第 0 階或第 1 階開始，每一步可以往上爬 1 階或 2 階。請返回到達階梯**頂端**（陣列末尾的下一個位置）所需的最小總成本。

## 核心思路

到達每一階的最小成本，取決於「從前 1 階過來」和「從前 2 階過來」兩者中較小的那個。由於這個計算只需要前 2 個結果，因此不需要陣列，只用 2 個變數就能求出最小成本。

## 思考過程

1. **到達頂端有 2 種方式**：到達頂端（索引 n）可以從前 1 階（n-1）爬 1 階，或從前 2 階（n-2）爬 2 階。兩者成本中較小的那個就是答案
2. **到達每一階的最小成本可以用遞迴方式定義**：將到達第 i 階的最小成本記為 `dp[i]`，則遞推式為 `dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])`。也就是「前 1 階的最小成本＋該階的成本」與「前 2 階的最小成本＋該階的成本」中較小的那個
3. **決定初始條件**：由於可以從第 0 階或第 1 階開始，到達第 0 階和第 1 階的成本都是 0。也就是 `dp[0] = 0`、`dp[1] = 0`
4. **不需要整個陣列，只需前 2 個值**：遞推式 `dp[i]` 只依賴 `dp[i-1]` 和 `dp[i-2]`。因此，可以不使用陣列，只保留 2 個變數 `prev1`（前 1 階）和 `prev2`（前 2 階）即可完成計算
5. **一邊更新變數一邊向前推進**：從第 2 階到第 n 階依序迴圈，每次計算出 `curr` 後，將 `prev2 = prev1`、`prev1 = curr` 進行滑動。迴圈結束時的 `prev1` 就是到達頂端的最小成本

## 前置知識

### 什麼是動態規劃（Dynamic Programming）

動態規劃是一種將大問題分解為小的子問題，並重複利用子問題的結果來高效求解的方法。在這道題中，將「到達第 i 階的最小成本」作為子問題，從小的索引開始依序求解（自底向上方式）。

### 什麼是 Math.min

Math.min 是 Java 的標準方法，用於返回兩個整數中較小的那個。在這道題中用來從兩個選項中選擇成本較低的那個。

```java
Math.min(5, 3);    // 返回 3 — 返回兩個引數中較小的那個
Math.min(10, 10);  // 返回 10 — 當兩個值相同時返回該值
```

### 空間最佳化的概念

當 DP 陣列的每個元素只依賴前幾個元素時，可以不保留整個陣列，而只用所需數量的變數來進行計算。在這道題中只需要 `dp[i-1]` 和 `dp[i-2]` 兩個值，因此 2 個變數就足夠了。

```java
int prev2 = 0;  // 相當於 dp[i-2] 的變數
int prev1 = 0;  // 相當於 dp[i-1] 的變數
int curr;       // 相當於 dp[i] 的變數（每次計算後更新）
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需遍歷陣列一次 |
| Space | O(1) — 只使用 2 個變數，不依賴陣列大小 |

## 程式碼

```java
// 輸入：整數陣列 cost（每一階的踏上成本）
// 輸出：以 int 返回到達階梯頂端（索引 n）的最小總成本
public int minCostClimbingStairs(int[] cost) {
    // 取得陣列長度。頂端位於索引 n 的位置（陣列末尾的下一個位置）
    int n = cost.length;

    // prev2=到達前 2 階的最小成本，prev1=到達前 1 階的最小成本
    // 由於可以從第 0 階和第 1 階開始，初始成本為 0
    int prev2 = 0, prev1 = 0;

    // 從第 2 階到頂端（第 n 階）依序計算最小成本。i 是目前嘗試到達的階數
    for (int i = 2; i <= n; i++) {
        // prev1 + cost[i-1]：從前 1 階爬 1 階過來的總成本
        // prev2 + cost[i-2]：從前 2 階爬 2 階過來的總成本
        // 選擇較小的那個
        int curr = Math.min(
            prev1 + cost[i - 1],
            prev2 + cost[i - 2]);

        // 將變數往前滑動一個位置
        // 注意：必須先更新 prev2，否則 prev1 的原始值會遺失
        prev2 = prev1;
        prev1 = curr;
    }

    // prev1 儲存了迴圈最後一次迭代（i = n）計算出的到達頂端的最小成本
    return prev1;
}
```
