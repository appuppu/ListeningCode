# Counting Ways to Climb Stairs — 求解以每次1階或2階的方式爬n階樓梯的總方法數

## 問題的本質

給定整數 `n`（樓梯的階數）。每次可以爬1階或2階，請回傳到達頂端（第n階）的**不同爬法總數**。

## 核心思路

要到達第n階，只能「從第n-1階爬1階」或「從第n-2階爬2階」。也就是說，`ways(n) = ways(n-1) + ways(n-2)` 這個遞推關係式與費波那契數列相同。只需保留前兩個值，就能不使用陣列，以O(1)的空間完成計算。

## 思考過程

1. **從最後一步反推**: 到達第n階的前一個狀態，只可能是「在第n-1階」或「在第n-2階」。因此，到達第n階的爬法總數可以用遞推關係式 `ways(n) = ways(n-1) + ways(n-2)` 來表示
2. **確定基底情況**: 1階樓梯有1種方式（爬1階），2階樓梯有2種方式（1+1 或 2）。這兩個值作為遞推關係式的起始點
3. **由下而上計算**: 如果用遞迴從上往下計算，會重複求解相同的子問題。改為採用從小值開始依序計算的由下而上方式，每個值只需計算一次即可
4. **只需要兩個變數**: 遞推關係式 `ways(i) = ways(i-1) + ways(i-2)` 只參照前兩個值。不需要保留整個陣列，只需兩個變數（`prev2` 和 `prev1`）就足夠了
5. **用迴圈更新變數**: 從 `i = 3` 到 `n`，依序用 `curr = prev1 + prev2` 計算當前值，然後將 `prev2 = prev1`、`prev1 = curr` 向前滑動，為下一次迭代做準備
6. **最終回傳的值**: 迴圈結束後，`prev1` 中儲存了第n階的爬法總數，因此回傳 `prev1`

## 前置知識

### 動態規劃（Dynamic Programming）是什麼

動態規劃是一種將大問題分解為小的子問題，並記錄每個子問題的結果來求解的方法。透過避免重複計算來提升效率。由下而上方式是從最小的子問題開始依序求解。

```java
// 由下而上DP的基本模式（陣列版）
int[] dp = new int[n + 1];   // 儲存子問題結果的陣列
dp[1] = 1;                    // 基底情況1
dp[2] = 2;                    // 基底情況2
for (int i = 3; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];  // 用遞推關係式計算
}
// dp[n] 為最終答案
```

### 滑動變數是什麼

滑動變數是一種用兩個變數代替陣列來保留前面的值的技巧。當遞推關係式參照的過去值為固定個數時，就不需要保留整個陣列，可以將空間複雜度從O(n)降低到O(1)。

```java
int prev2 = 1;  // 保留前兩個值的變數
int prev1 = 2;  // 保留前一個值的變數
int curr = prev1 + prev2;  // 計算當前值
prev2 = prev1;  // 滑動prev2（繼承prev1的值）
prev1 = curr;   // 滑動prev1（繼承curr的值）
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需從3到n執行一次迴圈 |
| Space | O(1) — 只使用兩個變數（prev2, prev1） |

## 程式碼

```java
// 輸入: 整數 n（樓梯的階數）
// 輸出: 以 int 回傳到達頂端的不同爬法總數
public int climbStairs(int n) {
    // 基底情況: 1階只有1種方式。由於後續迴圈從 i=3 開始，需先處理 n=1 的情況
    if (n == 1) return 1;

    // prev2是前兩階的爬法總數。初始值對應第1階的爬法（1種）
    int prev2 = 1;
    // prev1是前一階的爬法總數。初始值對應第2階的爬法（2種: 1+1 或 2）
    int prev1 = 2;

    // i 是目前正在計算的階數。第1階和第2階已設為初始值，因此從第3階開始
    for (int i = 3; i <= n; i++) {
        // 遞推關係式: 第i階的爬法 = 第(i-1)階的爬法 + 第(i-2)階的爬法
        int curr = prev1 + prev2;
        // 注意: 必須先更新prev2，否則會丟失prev1的原始值
        prev2 = prev1;
        prev1 = curr;
    }

    // 迴圈結束後，prev1 中儲存了第n階的爬法總數
    return prev1;
}
```
