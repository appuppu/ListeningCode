# Finding the Longest Increasing Subsequence — 求最長嚴格遞增子序列的長度

## 問題的本質

給定一個整數陣列 `nums`。從原始陣列中刪除若干元素（不改變順序）所能構成的**嚴格遞增子序列**中，返回最長者的長度。子序列不需要是連續的，但必須保持在原始陣列中的相對順序。

## 核心思路

「長度為 `k` 的遞增子序列，其末尾元素越小，後續元素能將其延伸的可能性就越高」。若用陣列 `tails` 來管理每個長度對應的末尾元素最小值，便可透過二分搜尋以 O(log n) 決定新元素的插入位置，從而以 O(n log n) 解決整個問題。

## 思考過程

1. **末尾越小，越有利於延伸遞增子序列**：當存在多個長度相同的遞增子序列時，末尾元素最小的那個「可接續的值的範圍」最廣。因此，只需記錄每個長度對應的末尾元素最小值即可
2. **用 tails 陣列管理末尾最小值**：準備一個陣列 `tails`，在 `tails[i]` 中儲存「長度為 `i+1` 的遞增子序列所能擁有的末尾元素最小值」。此陣列始終維持已排序的狀態（因為子序列越長，末尾必然越大）
3. **新元素的處理分為兩種情況**：對於陣列中的每個元素 `num`，透過二分搜尋在 `tails` 中找到大於等於 `num` 的最小元素。若找到的位置超出 `tails` 的末尾，表示 `num` 比現有最長子序列的末尾還大，因此將 `num` 追加到 `tails` 的末尾。若未超出末尾，則將該位置的值替換為 `num`，以更新末尾最小值
4. **可以使用二分搜尋的原因**：由於 `tails` 陣列始終維持已排序的狀態，因此可以用 `Collections.binarySearch` 以 O(log n) 確定 `num` 的插入位置。這使得每個元素的處理為 O(log n)，整體達到 O(n log n)
5. **tails 陣列的長度即為答案**：在處理每個元素時，`tails` 只會發生追加或替換其中一種操作。追加代表最長子序列的長度增加了 1。當所有元素處理完畢後，`tails.size()` 就是最長遞增子序列的長度

## 前置知識

### 什麼是 ArrayList

ArrayList 是可變長度的陣列。元素的新增、取得、更新均為 O(1)。與一般陣列不同，不需要事先決定大小。

```java
List<Integer> list = new ArrayList<>();  // 建立空的 ArrayList
list.add(10);          // 在末尾新增 10 → [10]
list.add(20);          // 在末尾新增 20 → [10, 20]
list.get(0);           // 取得索引 0 的元素 → 10
list.set(0, 5);        // 將索引 0 的元素替換為 5 → [5, 20]
list.size();           // 返回元素數量 → 2
```

### 什麼是 Collections.binarySearch

Collections.binarySearch 是對已排序的列表執行二分搜尋，並返回指定值位置的方法。若找到該值，則返回其索引。若未找到，則返回 `-(插入位置) - 1` 的負值。插入位置是指將該值插入列表後仍能維持排序順序的位置。

```java
List<Integer> list = Arrays.asList(2, 5, 8, 12);
Collections.binarySearch(list, 5);   // 5 位於索引 1 → 返回 1
Collections.binarySearch(list, 6);   // 6 不存在。插入位置為 2 → 返回 -(2)-1 = -3
Collections.binarySearch(list, 1);   // 1 不存在。插入位置為 0 → 返回 -(0)-1 = -1
Collections.binarySearch(list, 15);  // 15 不存在。插入位置為 4 → 返回 -(4)-1 = -5
```

從負的返回值還原插入位置的方法是計算 `-(返回值 + 1)`。例如：返回值為 -3 時，`-(-3 + 1) = 2` 即為插入位置。

### tails 陣列的概念

`tails` 是記錄「每個長度的遞增子序列末尾元素最小值」的陣列。`tails[i]` 表示「長度為 `i+1` 的遞增子序列所能取得的末尾最小值」。此陣列始終維持升序排列的狀態。

例如：處理 nums = [3, 1, 4, 1, 5] 的過程：
- 處理 3 → tails = [3]（長度 1 的子序列末尾最小值為 3）
- 處理 1 → tails = [1]（將長度 1 的末尾最小值更新為 1。因為 1 比 3 小，更為有利）
- 處理 4 → tails = [1, 4]（4 大於 1，因此追加到末尾。形成了長度 2 的子序列）
- 處理 1 → tails = [1, 4]（1 的插入位置為索引 0，已經是 1，因此沒有變化）
- 處理 5 → tails = [1, 4, 5]（5 大於 4，因此追加到末尾。形成了長度 3 的子序列）

最終的 `tails.size()` = 3 即為答案。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n log n) — 對 n 個元素各執行一次 O(log n) 的二分搜尋 |
| Space | O(n) — tails 陣列最多儲存 n 個元素 |

## 程式碼

```java
// 輸入：整數陣列 nums
// 輸出：以 int 返回最長嚴格遞增子序列的長度
public int lengthOfLIS(int[] nums) {
    // 以升序保存每個長度的遞增子序列末尾元素最小值的陣列
    // tails[i] 表示「長度為 i+1 的遞增子序列所能擁有的末尾元素最小值」
    List<Integer> tails = new ArrayList<>();

    // 從頭到尾逐一走訪陣列 nums 的每個元素
    for (int num : nums) {
        // 透過二分搜尋求出 num 在 tails 陣列中應插入的位置
        // 由於 tails 始終維持已排序狀態，因此可以使用二分搜尋
        int pos = Collections.binarySearch(tails, num);

        // 負值表示「未找到」，因此將其轉換為插入位置
        // 若 pos 為 0 以上，表示 tails[pos] 中已存在與 num 相同的值，直接使用該位置
        if (pos < 0)
            pos = -(pos + 1);

        if (pos == tails.size()) {
            // num 大於 tails 的所有元素，因此追加到末尾
            // 這代表最長遞增子序列的長度增加了 1
            tails.add(num);
        } else {
            // 將該位置的末尾最小值替換為 num 進行更新
            // 這使得長度為 pos+1 的遞增子序列末尾最小值變得更小，
            // 未來延伸子序列的可能性因此擴大
            tails.set(pos, num);
        }
    }

    // tails 的元素數量等於處理過程中追加到末尾的次數，
    // 這就是最長遞增子序列的長度
    return tails.size();
}
```
