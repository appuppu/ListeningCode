# Counting Ways to Decode a Numeric String — 求數字字串轉換為字母的總方法數

## 問題的本質

給定一個僅由數字組成的字串 `s`。根據 A=1, B=2, ..., Z=26 的對應關係，返回將字串解碼為字母序列的方法總數。例如 "226" 可以解碼為 "BZ"(2,26)、"VF"(22,6)、"BBF"(2,2,6) 共3種方式。

## 核心思路

每個位置的解碼方法數等於「解碼1個字元（1位數）後剩餘部分的方法數」與「解碼2個字元（2位數）後剩餘部分的方法數」的總和。這種依賴關係僅限於前兩個結果，因此只需2個變數即可。

## 思考過程

1. **每個位置最多有2種選擇**: 查看位置 `i` 的數字時，最多有兩種選擇：將其作為1位數（1～9）解碼為1個字母，或將其作為2位數（10～26）解碼為1個字母。由於這種選擇會遞迴發生，因此需要系統性地求出每個位置的解碼方法數
2. **'0' 無法單獨解碼**: 沒有對應 '0' 的字母。當位置 `i` 的數字為 '0' 時，從該位置開始的1位數解碼不可能，因此方法數為0。'0' 只能與前一個數字組合，作為10或20來解碼
3. **建立DP遞推公式**: 將 `dp[i]` 定義為「從位置 `i` 到末尾的解碼方法數」。若位置 `i` 的數字不是 '0'，則加上1位數解碼後的剩餘部分 `dp[i+1]`。若位置 `i` 和 `i+1` 組成的2位數在10～26的範圍內，則也加上2位數解碼後的剩餘部分 `dp[i+2]`。即 `dp[i] = dp[i+1] + dp[i+2]`（附帶條件）
4. **依賴對象僅為緊接其後的2個**: `dp[i]` 僅依賴於 `dp[i+1]` 和 `dp[i+2]`。因此不需要維護整個陣列，只需2個變數（`next1` = `dp[i+1]`、`next2` = `dp[i+2]`）即可完成計算。這樣可實現 Space O(1)
5. **從末尾向開頭遍歷**: 由於 `dp[i]` 依賴於 `dp[i+1]` 和 `dp[i+2]`，末尾側需要先確定。因此從字串的末尾向開頭進行迴圈，計算每個位置的方法數
6. **最終返回的值**: 迴圈完成後，`next1` 中儲存了 `dp[0]`（整個字串的解碼方法數）。返回該值

## 前提知識

### 何謂動態規劃（DP）

動態規劃是一種將大問題分解為小的子問題，並重複利用子問題的結果來求出整體答案的方法。為了避免多次重複計算相同的子問題，會將計算過的結果儲存（記憶化）或按順序計算（自底向上）。

```java
// 自底向上DP的典型模式：費波那契數列
int prev2 = 0, prev1 = 1;
for (int i = 2; i <= n; i++) {
    int current = prev1 + prev2;  // 僅用前兩個結果計算當前值
    prev2 = prev1;                // 滑動變數以準備下一次迭代
    prev1 = current;
}
// prev1 中儲存了最終結果
```

### 何謂 Integer.parseInt

Integer.parseInt 是將字串轉換為整數的方法。用於將子字串作為數值進行評估。

```java
Integer.parseInt("26");          // 將字串"26"轉換為整數26 → 26
Integer.parseInt("09");          // 將字串"09"轉換為整數9 → 9
```

### 何謂 String.substring

String.substring 是從字串中取得指定範圍子字串的方法。參數為起始索引（包含）和結束索引（不包含）。

```java
String s = "226";
s.substring(0, 2);   // 返回索引0到1的子字串 → "22"
s.substring(1, 3);   // 返回索引1到2的子字串 → "26"
```

### 何謂 String.charAt

String.charAt 是返回字串中指定位置的單一字元的方法。由於返回 char 類型，可以透過與字元 '0' 的比較來判定數字。

```java
String s = "206";
s.charAt(0);          // 返回索引0的字元 → '2'
s.charAt(1);          // 返回索引1的字元 → '0'
s.charAt(1) == '0';   // 判定字元是否為'0' → true
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需從末尾到開頭遍歷字串一次 |
| Space | O(1) — 僅用2個變數（next1, next2）即可完成計算，不使用陣列 |

## 程式碼

```java
// 輸入: 僅由數字組成的字串 s
// 輸出: 以 int 返回將字串 s 解碼為字母序列的方法總數
public int numDecodings(String s) {
    // next1 = 右側1個位置開始的方法數（dp[i+1]）、next2 = 右側2個位置開始的方法數（dp[i+2]）
    // 字串末尾右側定義為「解碼空字串的方法 = 1種」，因此初始值為1
    int next1 = 1, next2 = 1;

    // dp[i]依賴於dp[i+1]和dp[i+2]，因此為了先確定右側，從末尾向開頭遍歷
    for (int i = s.length() - 1; i >= 0; i--) {
        int current;

        if (s.charAt(i) == '0') {
            // '0'無法單獨對應任何字母，因此從此位置開始的解碼方法數為0
            // '0'只能與前一個數字組合，作為10或20來解碼
            current = 0;
        } else {
            // 1位數解碼: 將位置i的數字（1～9）作為1個字母，剩餘i+1以後有next1種方法
            current = next1;

            // 判定是否可以進行2位數解碼（若i+1在字串範圍內，則可取得2位數）
            if (i + 1 < s.length()) {
                // 用s.substring(i, i+2)取得2位數的子字串，並轉換為整數
                int two = Integer.parseInt(
                    s.substring(i, i + 2));
                // 若2位數在10～26的範圍內，則將2位數作為1個字母解碼，加上剩餘i+2以後的next2種方法
                if (two >= 10 && two <= 26)
                    current += next2;
            }
        }

        // 將變數向左滑動1位: 當前的current在下一次迭代中成為next1（右側1個位置）
        next2 = next1;
        next1 = current;
    }

    // 迴圈完成後，next1中儲存了最後計算的current（= dp[0]）
    // 這就是整個字串的解碼方法總數
    return next1;
}
```
