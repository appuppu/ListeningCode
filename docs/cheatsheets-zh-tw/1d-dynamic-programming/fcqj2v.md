# Finding the Fewest Coins to Make a Target Amount — 用最少硬幣湊出目標金額

## 問題的本質

給定一個包含硬幣面額的陣列 `coins` 和目標金額 `amount`。可以無限次使用 `coins` 中的硬幣，在所有總和等於 `amount` 的組合中，返回所需的**最少硬幣數量**。如果無論如何組合都無法湊出 `amount`，則返回 `-1`。

## 核心思路

從金額0到目標金額，自底向上計算「湊出每個金額所需的最少硬幣數量」，則金額 `i` 的最少硬幣數量可以表示為「從 `i` 減去每個硬幣面額後的金額的最少硬幣數量 + 1」中的最小值。

## 思考過程

1. **可以分解為子問題**：假設湊出金額 `i` 的最後一枚硬幣是 `c`，如果已經知道湊出剩餘金額 `i - c` 的最少硬幣數量，就可以用 `dp[i - c] + 1` 求出金額 `i` 的最少硬幣數量。這種結構適合使用動態規劃來解決
2. **事先無法得知哪枚硬幣是最後一枚**：最後一枚硬幣的候選是所有硬幣面額。因此，對所有硬幣 `c` 計算 `dp[i - c] + 1`，取其最小值作為 `dp[i]`。這就是轉移方程 `dp[i] = min(dp[i - c] + 1)` for each coin `c`
3. **確定基底情況**：湊出金額0所需的硬幣數量為0枚，因此設 `dp[0] = 0`。這是自底向上計算的起始點
4. **將初始值設為代表「不可達」的值**：由於事先無法得知每個金額是否能湊出，所以將 `dp` 陣列的所有元素初始化為 `amount + 1`（一個不可能出現的大數值）。未被更新的金額代表「無法湊出」
5. **從金額1開始依序填表**：以 `dp[0]` 為起點，按金額1, 2, ..., `amount` 的順序填表。計算金額 `i` 時，所有小於 `i` 的金額的最少硬幣數量已經確定，因此可以安全地參照 `dp[i - c]`
6. **最終返回值**：如果 `dp[amount]` 仍為 `amount + 1`，表示無法湊出目標金額，返回 `-1`。否則 `dp[amount]` 即為最少硬幣數量

## 前置知識

### 什麼是動態規劃（Dynamic Programming）

將大問題分解為小的子問題，一邊將每個子問題的解記錄在表格中，一邊自底向上構築解的方法。由於避免了重複求解相同的子問題，因此計算效率很高。

```java
// 自底向上DP的基本模式
int[] dp = new int[n + 1];     // 建立表格
dp[0] = baseCase;              // 設定基底情況
for (int i = 1; i <= n; i++) { // 從小的子問題開始依序求解
    dp[i] = /* 使用 dp[i-1] 等過去的結果來計算 */;
}
return dp[n];                  // 返回最終答案
```

### 什麼是 Arrays.fill

將陣列的所有元素填入指定值的Java標準方法。常用於DP陣列的初始化。

```java
int[] dp = new int[5];       // 建立 [0, 0, 0, 0, 0]
Arrays.fill(dp, 100);        // 將所有元素填入100 → [100, 100, 100, 100, 100]
```

### 什麼是 Math.min

返回兩個整數中較小值的Java標準方法。用於從多個候選值中選出最小值。

```java
Math.min(3, 7);    // → 3
Math.min(dp[i], dp[i - coin] + 1);  // 從當前值和新候選值中選擇較小的一方
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(amount × n) — 對每個金額遍歷n種硬幣（n為coins陣列的長度） |
| Space | O(amount) — dp陣列儲存amount+1個元素 |

## 程式碼

```java
// 輸入：包含硬幣面額的整數陣列 coins 和目標金額的整數 amount
// 輸出：返回總和等於 amount 的最少硬幣數量（int）。無法湊出時返回 -1
int coinChange(int[] coins, int amount) {
    // dp[i] = 湊出金額i所需的最少硬幣數量
    // 為了對應索引0到amount的每個金額，大小為 amount + 1
    int[] dp = new int[amount + 1];

    // 將所有元素初始化為代表「不可達」的哨兵值
    // 硬幣面額最小為1，因此不可能超過 amount 枚，若此值未被更新即可判定為「無法湊出」
    Arrays.fill(dp, amount + 1);

    // 基底情況：湊出金額0所需的硬幣數量為0枚。這是自底向上計算的起始點
    dp[0] = 0;

    // 從金額1到amount依序填表
    // 從小金額開始計算，保證 dp[i - coin] 已經確定
    for (int i = 1; i <= amount; i++) {
        // 將每枚硬幣作為「湊出金額i的最後一枚」的候選，從所有面額中尋找最佳選擇
        for (int coin : coins) {
            // 若 coin > i，則該硬幣無法用於湊出金額i，因此跳過
            if (coin <= i)
                // dp[i - coin] + 1 表示「金額 i - coin 的最少硬幣數量再加上1枚硬幣」
                // 與當前的 dp[i] 比較，採用較小的值
                dp[i] = Math.min(dp[i],
                    dp[i - coin] + 1);
        }
    }

    // 若仍為哨兵值，表示初始值未被更新＝無法湊出目標金額，返回 -1
    return dp[amount] > amount
        ? -1 : dp[amount];
}
```
