# Computing Power of a Number Efficiently — 高效計算浮點數的冪次方

## 問題的本質

給定一個浮點數 `x` 和一個整數 `n`，計算並返回 `x` 的 `n` 次方。由於 `n` 可能為負值，因此必須處理負指數的情況；此外，即使 `n` 的絕對值非常大，也必須高效地完成計算。

## 核心概念

將指數 `n` 以二進位表示後，冪次計算可以分解為「反覆對 x 進行平方，並僅在 n 的各位元為 1 時將其乘入結果」的操作。藉此，原本需要 n 次的乘法運算可以削減為 log(n) 次。

## 思考過程

1. **將負指數轉換為正指數**：`x^(-n)` 等於 `(1/x)^n`，因此當 `n` 為負數時，將 `x` 替換為 `1/x` 並反轉 `n` 的符號，即可將問題統一為正指數的情況
2. **n 次乘法太慢**：單純地將 `x` 乘以 `n` 次需要 O(n) 的時間複雜度。當 `n` 達到數十億時，這種方法無法在時限內完成。我們需要一種能將指數逐步減半的方法
3. **冪次可以透過反覆平方來分解**：如 `x^10 = x^8 × x^2`，任意冪次都可以分解為 2 的冪次之積。這對應於指數 `n` 的二進位表示。`10` 的二進位為 `1010`，因此只需將位元為 1 的位數所對應的 `x^8` 和 `x^2` 相乘即可
4. **使用位元運算判定各位數**：透過 `(n & 1) == 1` 可以判定 `n` 的最低位元是否為 1。若為 1，則將當時的 `x`（已累乘至對應位數的 2 的冪次方的值）乘入結果
5. **反覆對 x 平方以提升位數**：每次迴圈將 `x` 更新為 `x * x`，使 `x` 依序成為原始值的 2 次方、4 次方、8 次方……即 2 的冪次方的累乘值。同時將 `n` 右移 1 位元以進入下一位數
6. **迴圈的終止條件**：持續對 `n` 進行右移後，`n` 最終會變為 0。只要在 `n > 0` 的期間持續迴圈，即可處理所有位元

## 前置知識

### 位元運算（& 和 >>）

位元運算是將整數視為二進位並逐位操作的運算。`&`（AND）僅在兩個位元皆為 1 時結果才為 1。`>>`（右移）將位元列向右移動，並丟棄最低位元（相當於除以 2 的操作）。

```java
int n = 10;           // 二進位: 1010
n & 1;                // 取得最低位元 → 0（偶數）
n >>= 1;              // 右移 1 位元 → n 為 5（二進位: 101）
n & 1;                // 取得最低位元 → 1（奇數）
```

### 反覆平方法（Fast Exponentiation）

利用指數的二進位表示，以 O(log n) 次乘法計算冪次的方法。以 `x^13` 為例，`13` 的二進位為 `1101`，因此 `x^13 = x^8 × x^4 × x^1`。在迴圈中反覆對 `x` 進行平方（`x → x^2 → x^4 → x^8`），並僅在對應位元為 1 時將其乘入結果。

```java
// x^13 的計算過程（13 = 1101 in binary）
// 位元0: 1 → result *= x    (result = x^1)，  x = x^2
// 位元1: 0 → 跳過，                             x = x^4
// 位元2: 1 → result *= x^4  (result = x^5)，  x = x^8
// 位元3: 1 → result *= x^8  (result = x^13)， x = x^16
```

### 需要轉型為 long 的原因

Java 的 `int` 型別範圍為 `-2^31` 到 `2^31 - 1`。當 `n = -2^31` 時，`-n` 為 `2^31`，超出 `int` 的範圍而發生溢位。先轉型為 `long` 再反轉符號，即可避免此問題。

```java
int n = Integer.MIN_VALUE;   // -2147483648
long power = (long) n;       // -2147483648L（轉換為 long 型別）
power = -power;              // 2147483648L（int 型別無法表示，但 long 型別可安全處理）
```

## 複雜度

| | 值 |
|---|---|
| Time | O(log n) — 因為迴圈次數等於指數 n 的位元數 |
| Space | O(1) — 僅使用 result、x、power 三個變數，無需遞迴堆疊 |

## 程式碼

```java
// 輸入: 浮點數 x 與整數 n
// 輸出: 以 double 返回 x 的 n 次方的值
double myPow(double x, int n) {
    // 若維持 int 型別，當 n = -2^31 時符號反轉會發生溢位，因此轉換為 long 型別
    long power = (long) n;

    // 將負指數轉換為正指數: x^(-n) = (1/x)^n
    // 透過此轉換，後續處理可統一為僅處理正指數
    if (power < 0) {
        x = 1 / x;
        power = -power;
    }

    // 以 1.0 初始化用於累積結果的變數
    // 將位元為 1 的位數所對應的 x 的累乘值相乘，逐步累積最終結果
    double result = 1.0;

    // 從低位到高位依序處理 power 的所有位元
    // 持續右移 power 後最終會變為 0，代表所有位數的處理已完成
    while (power > 0) {
        // 透過 power & 1 判定最低位元（當前處理中的位數）是否為 1
        if ((power & 1) == 1) {
            // 位元為 1 的情況: 此時的 x 是原始 x 經過已處理位數次平方後的值（原始 x 的 2^k 次方）
            // 將此位數的貢獻量乘入 result 以反映至結果中
            result *= x;
        }
        // 對 x 進行平方，更新為對應下一位數的累乘值（指數加倍的冪次）
        x *= x;
        // 將 power 右移 1 位元以進入下一位數（最低位元被丟棄）
        power >>= 1;
    }
    // 返回所有位元的貢獻量相乘後的最終結果
    return result;
}
```
