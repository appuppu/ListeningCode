# Adding One to a Number Represented as an Array — 將以陣列表示的數值加1

## 問題的本質

給定一個非負整數的陣列 `digits`，其中每個元素儲存一位數字。陣列的第一個元素是最高位數字，最後一個元素是最低位數字。將這個數值加1，並以相同格式的陣列返回結果。每個元素是0到9的一位數字。

## 核心思路

從末尾的數字開始加1，當不再產生進位時立即返回結果。只有當該位數字為9時才會產生進位，只有當所有位數字都是9時，陣列的長度才會增加1。

## 思考過程

1. **從最低位開始加算**: 數值的加法自然從個位數開始，因此從陣列的末尾向前逆序遍歷
2. **考慮進位停止的條件**: 如果當前位數字小於9，加1後不會產生進位。此時加算已完成，可以立即返回陣列
3. **考慮數字為9時的處理**: 當前位數字為9時，加1後變為10，產生進位。將該位設為0，並將進位傳播到上一位。在迴圈的下一次迭代中，自然會對上一位執行加1的處理
4. **考慮所有位數字都是9的情況**: 如999這樣所有位數字都是9時，迴圈執行到最後進位仍未停止。結果如1000一樣，位數增加1。僅在這種情況下建立新陣列，並將第一個元素設為1。由於Java的 `new int[]` 會將所有元素初始化為0，因此不需要對其餘位數字賦值0
5. **不需要使用變數來管理進位**: 進位的值始終為1，且迴圈持續執行本身就確定了進位的存在，因此不需要準備carry變數，迴圈的持續本身就代表進位存在的結構

## 前置知識

### 陣列的逆序遍歷

從陣列的末尾向前遍歷。從 `i = n - 1` 開始，在 `i >= 0` 的條件下以 `i--` 遞減。

```java
int[] digits = {1, 2, 3};
int n = digits.length;                  // 取得陣列的長度 → 3
for (int i = n - 1; i >= 0; i--) {      // 以 i=2, 1, 0 的順序迴圈
    System.out.println(digits[i]);      // 以 3, 2, 1 的順序輸出
}
```

### Java的陣列初始化

使用 `new int[n]` 建立長度為n的整數陣列時，所有元素會自動初始化為0。不需要明確地賦值0。

```java
int[] result = new int[4];   // 初始化為 {0, 0, 0, 0}
result[0] = 1;               // 變為 {1, 0, 0, 0}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 從陣列末尾到開頭最多遍歷一次 |
| Space | O(1) — 除了所有位數字都是9的情況外，直接在原陣列上修改，不需要額外記憶體 |

## 程式碼

```java
// 輸入: 儲存非負整數各位數字的整數陣列 digits
// 輸出: 返回將 digits 所表示的數值加1後的結果 int[]
public int[] plusOne(int[] digits) {
    // 儲存陣列的長度。用於逆序遍歷的迴圈上限，以及所有位數字都是9時新陣列的長度
    int n = digits.length;

    // 從末尾向開頭遍歷。迴圈持續執行本身就代表「存在進位」
    for (int i = n - 1; i >= 0; i--) {
        // 如果當前位數字小於9，則不會產生進位。加1後立即返回
        if (digits[i] < 9) {
            digits[i]++;
            return digits;  // 無進位。直接返回已修改的陣列並結束
        }
        // 當前位數字為9，將其設為0並將進位傳播到上一位
        digits[i] = 0;
    }

    // 所有位數字都是9的情況（例: [9,9,9] → [0,0,0]），位數增加1
    // new int[] 會將所有元素初始化為0，因此不需要對其餘位數字賦值0
    int[] result = new int[n + 1];
    result[0] = 1;  // 將第一個元素設為1（例: 999 + 1 = 1000 → [1, 0, 0, 0]）
    return result;
}
```
