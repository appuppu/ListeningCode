# Determining if a Number is a Happy Number — 重複計算各位數字的平方和，判斷是否能到達1

## 問題的本質

給定一個正整數 `n`。重複執行將 `n` 的每一位數字平方後求和的操作，若結果最終到達 **1**，則該數為「快樂數」，返回 `true`。若無法到達1而陷入無限循環，則返回 `false`。

## 核心思路

重複計算各位數字平方和的操作，必定在有限個數值之間循環。這與鏈結串列的循環檢測具有相同結構，使用 Floyd 的慢指標與快指標，即可在不使用額外記憶體的情況下判定是否存在循環以及循環的到達點。

## 思考過程

1. **重複操作必定形成循環**：重複計算各位數字的平方和時，數值會收斂在有限範圍內，因此必定會再次到達先前出現過的值。也就是說，數列必定進入「停留在1的循環」或「不包含1的循環」其中之一
2. **循環檢測可歸結為環檢測問題**：若將每個值到下一個值的轉移視為「從一個節點到另一個節點的連結」，則此問題與檢測鏈結串列中是否存在環的問題具有相同結構
3. **使用 Floyd 雙指標法以 O(1) 空間進行檢測**：慢指標每次前進1步，快指標每次前進2步。若存在循環，兩個指標必定在循環中的某處會合
4. **根據會合點的值判定結果**：兩個指標會合時，若該值為1，則為快樂數（因為1的各位數字平方和為1，所以1本身形成一個循環）。若在1以外的值會合，則表示進入了不包含1的循環，因此不是快樂數
5. **初始值的設定**：將慢指標設為 `n`，快指標設為 `getNext(n)` 來開始。這樣可以自然地進入 `while (slow != fast)` 的迴圈

## 前置知識

### 各位數字平方和的計算

要取出整數 `n` 的每一位數字，使用 `n % 10` 取得最低位的數字，再用 `n /= 10` 移除最低位的數字，重複此操作直到 `n` 變為0。

```java
int n = 19;
int digit = n % 10;   // 取得最低位的數字 → 9
n /= 10;              // 移除最低位的數字 → n 變為1
digit = n % 10;       // 取得下一位數字 → 1
// 19 → 1² + 9² = 1 + 81 = 82
```

### Floyd 的循環檢測法（雙指標法）

這是一種檢測鏈結串列或數列中是否存在循環（迴圈）的演算法。慢指標每次前進1步，快指標每次前進2步。若存在循環，快指標會追上慢指標，兩者必定會合。由於不使用額外的資料結構，空間複雜度為 O(1)。

```java
int slow = start;                // 慢指標每次前進1步
int fast = getNext(start);       // 快指標的初始位置設為前方1步
while (slow != fast) {
    slow = getNext(slow);        // 前進1步
    fast = getNext(getNext(fast)); // 前進2步
}
// 迴圈結束時，slow == fast 為會合點的值
```

## 複雜度

| | 值 |
|---|---|
| Time | O(log n) — 計算各位數字的平方和需要 O(log n)，到達循環為止的迭代次數收斂為常數 |
| Space | O(1) — 僅使用慢指標和快指標兩個變數 |

## 程式碼

```java
// 輸入：正整數 n
// 輸出：若 n 為快樂數則返回 true，否則返回 false

// 計算並返回整數 n 的各位數字平方和的輔助函式
// 使用 n % 10 取出最低位的數字，將其平方累加，再用 n /= 10 移除該位數字，重複此操作
private int getNext(int n) {
    int sum = 0;
    while (n > 0) {
        int digit = n % 10;   // 取出最低位的數字
        sum += digit * digit;  // 將該位數字的平方加到 sum
        n /= 10;               // 移除最低位的數字
    }
    return sum;
}

public boolean isHappy(int n) {
    // 慢指標從 n 開始，快指標從前方1步的 getNext(n) 開始
    // 將 fast 設為前方1步，可以自然地進入 while (slow != fast) 的迴圈
    int slow = n;
    int fast = getNext(n);

    // 持續迴圈直到兩個指標會合
    // 由於慢指標與快指標的速度差，若存在循環則必定會合
    while (slow != fast) {
        slow = getNext(slow);           // 慢指標前進1步
        fast = getNext(getNext(fast));   // 快指標前進2步
    }

    // 若會合點為1則為快樂數（因為1的各位數字平方和為1，所以1本身形成循環）
    // 若在1以外的值會合，則表示進入了不包含1的循環，因此不是快樂數
    return fast == 1;
}
```
