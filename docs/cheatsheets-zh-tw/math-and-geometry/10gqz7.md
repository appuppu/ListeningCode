# Detecting Axis-Aligned Squares From Points — 從儲存的點中計算與軸平行的正方形數量

## 問題的本質

設計一個資料結構，具備在2D平面上新增點的 `add` 操作，以及以給定的點作為一個頂點、回傳**與軸平行的正方形**（四邊皆平行於x軸或y軸）個數的 `count` 操作。同一座標被多次新增的點，每個都視為獨立的點。

## 核心思路

與軸平行的正方形，只要確定對角線上的兩個點，其餘兩個點就能唯一確定。列舉與查詢點具有相同x座標的點作為對角線配對候選，再透過HashMap以O(1)確認其餘兩個角是否存在，即可高效地計算正方形的數量。

## 思考過程

1. **理解與軸平行的正方形的性質**：由於四邊平行於x軸和y軸，四個頂點的形式為 `(x1,y1)`、`(x1,y2)`、`(x2,y1)`、`(x2,y2)`。也就是說，正方形由x座標相同的兩個點與y座標相同的兩個點的組合所構成
2. **從對角線上的兩個點確定其餘兩個點**：選擇查詢點 `(px, py)` 和具有相同x座標但不同y座標的點 `(px, pt_y)` 後，邊長為 `|py - pt_y|`。其餘兩個頂點必須存在於 `(px ± side, py)` 和 `(px ± side, pt_y)` 的位置
3. **正方形可以在左右兩個方向形成**：當邊長 `side` 確定後，另一側的x座標有 `px - side` 或 `px + side` 兩種可能。需要檢查兩個方向
4. **記錄每個座標的點的個數**：由於同一座標可能被多次新增點，因此使用HashMap管理每個座標的點的出現次數。其餘兩個頂點的出現次數之積，即為該組合能構成的正方形數量
5. **快速取得相同x座標的點**：以x座標為鍵，用另一個HashMap管理具有該座標的所有點的列表。如此一來，在 `count` 時可以高效地列舉僅具有相同x座標的點
6. **累加結果並回傳**：針對每個配對候選和每個方向，將其餘兩個頂點的出現次數之積加入結果中

## 前置知識

### 將座標作為 HashMap 鍵的方法

要將二維座標 `(x, y)` 作為HashMap的鍵，可以將其轉換為字串 `"x,y"`。這樣就能對任意座標以O(1)儲存和取得值。

```java
Map<String, Integer> cnt = new HashMap<>();
String key = x + "," + y;               // 座標(3,5) → "3,5"
cnt.put(key, cnt.getOrDefault(key, 0) + 1);  // 將該座標的出現次數加1
cnt.getOrDefault(key, 0);               // 若不存在則回傳0
```

### 什麼是 computeIfAbsent

這是一個僅在指定的鍵不存在於Map中時，才生成新值並註冊的方法。若鍵已存在，則直接回傳現有的值。在建構以列表為值的Map時非常方便。

```java
Map<Integer, List<int[]>> xMap = new HashMap<>();
// 若鍵5不存在則建立新的ArrayList，若存在則回傳該列表
xMap.computeIfAbsent(5, k -> new ArrayList<>()).add(new int[]{5, 3});
```

### 組合的計算方法（乘法原理）

當兩個獨立的選擇分別有 `c1` 種和 `c2` 種時，組合的總數為 `c1 * c2`。在本問題中，當其餘兩個頂點的座標分別存在 `c1` 個和 `c2` 個點時，選擇這兩個頂點的方式有 `c1 * c2` 種。

## 計算複雜度

| | 值 |
|---|---|
| Time | add: O(1) — 僅進行HashMap的註冊。count: O(n) — 遍歷所有具有相同x座標的點 |
| Space | O(n) — 將所有點的座標和出現次數儲存在HashMap中 |

## 程式碼

```java
// add(int[] p): 在2D平面上新增點 p = [x, y]
// count(int[] p): 回傳以點 p = [x, y] 作為一個頂點且與軸平行的正方形個數（int）
class DetectSquares {
    // 管理每個座標出現次數的HashMap（鍵: "x,y"）
    // 用於在count時以O(1)取得任意座標上有多少個點
    Map<String, Integer> cnt;
    // 管理具有相同x座標的點的列表的HashMap（鍵: x座標）
    // 用於在count時高效地列舉僅具有相同x座標的點
    Map<Integer, List<int[]>> xMap;

    DetectSquares() {
        cnt = new HashMap<>();
        xMap = new HashMap<>();
    }

    void add(int[] p) {
        // 將座標轉換為字串 "x,y" 並將出現次數加1
        String key = p[0] + "," + p[1];
        cnt.put(key, cnt.getOrDefault(key, 0) + 1);

        // 將點新增至該x座標的列表中（若為首次出現的x座標則建立新列表）
        xMap.computeIfAbsent(p[0],
            k -> new ArrayList<>()).add(p);
    }

    int count(int[] p) {
        int res = 0;
        int px = p[0], py = p[1];

        // 取得與查詢點具有相同x座標的點的列表
        // 若列表不存在則無法構成正方形，因此回傳0
        List<int[]> same = xMap.get(px);
        if (same == null) return 0;

        // 遍歷相同x座標的每個點作為配對候選
        for (int[] pt : same) {
            // 計算邊長（查詢點與配對點的y座標差的絕對值）
            int side = Math.abs(py - pt[1]);
            // y座標相同的點邊長為0，無法構成正方形，因此跳過
            if (side == 0) continue;

            // 正方形可以在左右兩個方向形成，因此嘗試兩個x座標
            int[] dirs = {px - side, px + side};
            for (int nx : dirs) {
                // 取得其餘兩個頂點座標 (nx, py) 和 (nx, pt[1]) 的出現次數
                // 不存在的座標會得到0，乘積也為0，因此不會被加入結果
                String k1 = nx + "," + py;
                String k2 = nx + "," + pt[1];
                int c1 = cnt.getOrDefault(k1, 0);
                int c2 = cnt.getOrDefault(k2, 0);

                // 兩個頂點的出現次數之積即為該組合能構成的正方形數量（乘法原理）
                res += c1 * c2;
            }
        }
        return res;
    }
}
```
