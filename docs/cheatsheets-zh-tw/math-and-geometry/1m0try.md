# Setting Entire Rows and Columns to Zero — 將包含零的行與列全部設為零

## 問題的本質

給定一個 m×n 的矩陣。找到值為 0 的元素後，將該元素所屬的**整行**和**整列**全部設為 0。此轉換需要 in-place（不使用額外的矩陣）完成。

## 核心思路

將矩陣的第 0 行和第 0 列重新用作「記錄哪些行和列應該被設為零」的標記區域，就能以 O(1) 的額外空間管理需要設為零的行與列。

## 思考過程

1. **需要記錄哪些行和列應該設為零**：在遍歷過程中一發現零就立即改寫該行和列，會導致後續遍歷時無法區分該零是原始值還是改寫產生的。因此，需要先記錄「哪些行和列要設為零」，然後再統一改寫的兩次遍歷方式
2. **使用額外陣列記錄需要 O(m+n) 的空間**：可以用大小為 m 的陣列記錄行、大小為 n 的陣列記錄列，但我們的目標是 O(1) 空間
3. **將矩陣自身的第 0 行和第 0 列用作標記**：讓 `matrix[i][0]` 為 0 表示「第 i 行需要設為零」，`matrix[0][j]` 為 0 表示「第 j 列需要設為零」。這樣就不需要額外的陣列
4. **第 0 列的標記需要獨立的變數**：`matrix[i][0]` 同時承載了「第 i 行的標記」和「第 0 列的原始值」兩種含義。第 0 列本身是否需要設為零，要用另一個變數 `firstCol` 來管理
5. **標記的設置**：遍歷矩陣，發現 `matrix[i][j] == 0` 時，設置 `matrix[i][0] = 0` 和 `matrix[0][j] = 0` 來建立標記
6. **逆序設為零**：根據標記寫入零時，如果先改寫第 0 行和第 0 列，標記就會被破壞。因此，從末尾逆序處理，第 0 行和第 0 列留到最後處理

## 前提知識

### 什麼是 in-place 操作

不使用額外的資料結構（其他矩陣或大型陣列），直接改寫輸入資料本身來得到結果的操作。僅允許使用常數個額外變數。

```java
// in-place 操作的範例：直接改寫陣列的元素
matrix[i][j] = 0;  // 不複製到其他陣列，直接修改原始矩陣
```

### 什麼是 boolean 型標記

用 true/false 兩個值來記錄「某個條件是否成立」的變數。在迴圈中一旦條件成立就設為 true，供後續處理參照。

```java
boolean firstCol = false;       // 初始值為 false（條件尚未成立）
if (matrix[i][0] == 0)
    firstCol = true;            // 記錄條件已成立
// 稍後進行參照
if (firstCol)
    matrix[i][0] = 0;          // 若標記為 true 則執行處理
```

### 什麼是逆序迴圈

從陣列或矩陣的末尾向開頭進行遍歷的迴圈。當開頭的元素同時兼作後續處理所需的標記時，使用逆序將開頭留到最後處理。

```java
for (int i = m - 1; i >= 0; i--)    // i 從末尾(m-1)遞減到 0
    for (int j = n - 1; j >= 1; j--)  // j 從末尾(n-1)遞減到 1
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(m × n) — 遍歷整個矩陣兩次（標記設置一次，設為零一次） |
| Space | O(1) — 額外變數僅有 `firstCol`。將矩陣本身重新用作標記區域 |

## 程式碼

```java
// 輸入：m×n 的整數矩陣 matrix（二維陣列）
// 輸出：無（直接改寫 matrix。回傳值為 void）
public void setZeroes(int[][] matrix) {
    // 取得行數 m 和列數 n
    int m = matrix.length;
    int n = matrix[0].length;
    // 記錄第 0 列是否需要設為零的標記
    // 因為 matrix[i][0] 同時兼作行標記，所以第 0 列的標記需要用獨立的變數管理
    boolean firstCol = false;

    // 第一次遍歷：設置標記
    for (int i = 0; i < m; i++) {
        // 確認第 0 列是否原本就包含零，若有則將 firstCol 設為 true
        if (matrix[i][0] == 0)
            firstCol = true;
        // 從 j=1 開始遍歷（j=0 兼作行標記，所以只檢查第 1 列之後）
        for (int j = 1; j < n; j++)
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;  // 設置第 i 行需要設為零的標記
                matrix[0][j] = 0;  // 設置第 j 列需要設為零的標記
            }
    }

    // 第二次遍歷：逆序寫入零
    // 使用逆序的原因：第 0 行的標記（matrix[0][j]）在處理其他行時會用到，所以第 0 行必須最後處理
    for (int i = m - 1; i >= 0; i--) {
        // 從 j=1 逆序遍歷，若行標記或列標記已設置則設為零
        for (int j = n - 1; j >= 1; j--)
            if (matrix[i][0] == 0 || matrix[0][j] == 0)
                matrix[i][j] = 0;
        // 第 0 列的零化在內層迴圈之後進行
        // 注意：若先改寫 matrix[i][0]，上方的行標記判定就會被破壞
        if (firstCol)
            matrix[i][0] = 0;
    }
}
```
