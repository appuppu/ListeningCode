# Reversing the Digits of an Integer — 反轉 32 位元有號整數的各位數

## 問題的本質

給定一個 32 位元有號整數 `x`。將 `x` 的各位數以逆序排列後回傳該整數。若反轉後的值超出 32 位元有號整數的範圍（-2³¹ ～ 2³¹-1），則回傳 `0`。

## 核心概念

整數的末位數可透過 `x % 10` 取出，並透過 `x / 10` 移除末位。重複執行這個「取出並堆疊」的操作，位數自然會變成逆序。在每次堆疊時事先檢查溢位，就能安全地建構反轉結果。

## 思考過程

1. **逐位取出的方法**：整數的末位數可透過 `x % 10`（除以 10 的餘數）取得。取得後透過 `x / 10` 移除末位數，即可存取下一位數。重複此操作直到 `x` 變為 0，就能從末位開始依序取出所有位數
2. **將取出的位數以逆序組合的方法**：對結果變數 `result` 重複執行 `result = result * 10 + digit`。`result * 10` 將現有位數向左移動一位，`+ digit` 將新的位數加到個位。由於從末位取出的位數會從開頭依序排列，因此位數的順序自然會反轉
3. **溢位的處理**：`result * 10 + digit` 的計算結果可能超過 `Integer.MAX_VALUE`（2147483647）或低於 `Integer.MIN_VALUE`（-2147483648）。在執行乘法**之後**就來不及了，因此必須在乘法**之前**進行檢查
4. **溢位的事前檢查方法**：`result * 10` 是否會溢位，可透過將 `result` 與 `Integer.MAX_VALUE / 10`（= 214748364）進行比較來判定。若 `result > 214748364`，則必定會溢位。若 `result == 214748364`，則當 `digit > 7`（MAX_VALUE 的個位數）時會溢位。負數的情況也同樣與 `Integer.MIN_VALUE / 10` 進行比較
5. **符號的處理**：`x % 10` 和 `x / 10` 在 Java 中對負數也能正確運作（`-123 % 10 == -3`、`-123 / 10 == -12`）。因此不需要分離符號，可以直接處理
6. **最終回傳的值**：迴圈結束後的 `result` 就是反轉後的整數。若檢測到溢位，則在迴圈內立即回傳 `0`

## 前置知識

### % 運算子（餘數運算子）是什麼

此運算子回傳一個整數除以另一個整數的餘數。`x % 10` 可取出 `x` 的個位數。在 Java 中，對負數也會保留符號。

```java
123 % 10;    // → 3（取得個位數）
-123 % 10;   // → -3（負數也會保留符號）
123 / 10;    // → 12（移除個位數）
-123 / 10;   // → -12（負數也會正確地截斷）
```

### 32 位元有號整數的範圍

Java 的 `int` 型別所能表示的值的範圍。超出此範圍會發生溢位，導致產生不正確的值。

```java
Integer.MAX_VALUE;   // → 2147483647（2³¹ - 1）
Integer.MIN_VALUE;   // → -2147483648（-2³¹）
Integer.MAX_VALUE / 10;  // → 214748364（溢位判定的閾值）
Integer.MAX_VALUE % 10;  // → 7（MAX_VALUE 的個位數）
Integer.MIN_VALUE / 10;  // → -214748364
Integer.MIN_VALUE % 10;  // → -8（MIN_VALUE 的個位數）
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — n 為 `x` 的位數。每一位數處理一次 |
| Space | O(1) — 僅使用變數 `result` 和 `digit` |

## 程式碼

```java
// 輸入：32 位元有號整數 x
// 輸出：回傳將 x 的各位數反轉後的整數。若反轉後的值超出 32 位元範圍，則回傳 0
public int reverse(int x) {
    // 儲存反轉結果的變數。逐位堆疊上去
    int result = 0;

    // 從 x 的末位開始逐位取出並處理。當 x 變為 0 時，表示所有位數處理完成
    while (x != 0) {
        // 取出 x 的個位數。即使是負數，% 也會保留符號，因此不需要特別處理
        int digit = x % 10;

        // 事先檢查正數溢位（乘法之後就來不及了，所以要在之前檢查）
        // 若 result > 214748364，則 result * 10 必定超過 MAX_VALUE(2147483647)
        // 若 result == 214748364 且 digit > 7，則 result * 10 + digit 會超過 MAX_VALUE（末位為 7）
        if (result > Integer.MAX_VALUE / 10
                || (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return 0;
        }

        // 事先檢查負數溢位
        // 若 result < -214748364，則 result * 10 必定低於 MIN_VALUE(-2147483648)
        // 若 result == -214748364 且 digit < -8，則 result * 10 + digit 會低於 MIN_VALUE（末位為 -8）
        if (result < Integer.MIN_VALUE / 10
                || (result == Integer.MIN_VALUE / 10 && digit < -8)) {
            return 0;
        }

        // result * 10 將現有位數向左移動一位，+ digit 將取出的位數加到個位
        // 藉此，原始數字的末位數會依序被放置到結果的開頭側
        result = result * 10 + digit;

        // 移除 x 的個位數，使下一位數暴露在末位
        x = x / 10;
    }

    // 回傳所有位數反轉完成的結果。若發生溢位，已在迴圈內回傳 0
    return result;
}
```
