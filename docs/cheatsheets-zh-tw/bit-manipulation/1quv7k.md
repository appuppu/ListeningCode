# Adding Two Numbers Without the Plus Operator — 不使用加法運算子求兩個整數的和

## 問題的本質

給定兩個整數 `a` 和 `b`。在**不使用** `+` 運算子或 `-` 運算子的情況下，僅用位元運算計算並返回兩個整數的總和。

## 核心思路

二進位加法可以分解為「不含進位的各位數之和（XOR）」與「進位（AND 左移）」兩個部分。重複執行此分解直到進位變為零，即可得到最終的和。

## 思考過程

1. **從位元層面思考加法的本質**：二進位各位數的加法，若忽略進位，則「只有其中一方為1時結果才為1」。這正是 XOR 運算（`a ^ b`）本身
2. **另外計算進位**：進位在「兩個位數都為1時」發生。這可以用 AND 運算（`a & b`）求得。由於進位會影響下一位數，因此需要將結果左移1位元（`(a & b) << 1`）
3. **需要將進位加到和上**：將 XOR 的結果與進位相加即可得到最終的和，但不能使用 `+`。然而這歸結為「將兩個數相加」的相同問題，因此可以遞迴地套用相同的處理
4. **確定遞迴的終止條件**：當進位 `b` 變為零時，代表沒有剩餘需要加的值，此時的 `a` 就是最終的和。這作為基底情況
5. **由於整數的位元寬度有限，必定會終止**：透過左移，進位的位元每次都會向高位移動，在32位元整數的範圍內，最多經過32次遞迴進位必定會變為零

## 前提知識

### XOR 運算（互斥或）是什麼

當兩個位元不同時返回1、相同時返回0的位元運算。其結果與忽略進位的加法相同。

```java
int result = 5 ^ 3;   // 0101 ^ 0011 = 0110 → 6
int result2 = 7 ^ 7;  // 0111 ^ 0111 = 0000 → 0（相同值的 XOR 為0）
```

### AND 運算是什麼

只有當兩個位元都為1時才返回1的位元運算。用於確定發生進位的位數。

```java
int result = 5 & 3;   // 0101 & 0011 = 0001 → 1
int result2 = 6 & 3;  // 0110 & 0011 = 0010 → 2
```

### 左移運算是什麼

將位元列向左移動指定的位數，並用0填充右側空出的位元。左移1位元具有將值乘以2的效果。由於進位會影響下一位數，因此透過左移1位元將其移動到正確的位數位置。

```java
int result = 1 << 1;  // 0001 → 0010 → 2
int result2 = 3 << 1; // 0011 → 0110 → 6
```

### 二進位加法的原理

與十進位的直式計算相同，逐位相加並將進位送往上一位。
例：`5 + 3`（`0101 + 0011`）的情況：
- XOR（不含進位的和）：`0101 ^ 0011 = 0110`（6）
- AND + 左移（進位）：`(0101 & 0011) << 1 = 0001 << 1 = 0010`（2）
- 再用相同方法將6和2相加 → `0110 ^ 0010 = 0100`（4）、`(0110 & 0010) << 1 = 0100`（4）
- 再將4和4相加 → `0100 ^ 0100 = 0000`（0）、`(0100 & 0100) << 1 = 1000`（8）
- 將0和8相加 → `0000 ^ 1000 = 1000`（8）、進位為0 → 結束。結果為 **8**

## 計算複雜度

| | 值 |
|---|---|
| Time | O(1) — 在32位元整數中，進位的移位最多進行32次即結束，因此以常數次遞迴完成 |
| Space | O(1) — 遞迴深度也最多為32次屬於常數，且不使用額外的資料結構 |

## 程式碼

```java
// 輸入：兩個整數 a 和 b
// 輸出：以 int 返回 a 和 b 的總和
public int getSum(int a, int b) {
    // 基底情況：若進位(b)為零，則沒有剩餘需要加的值，a 即為最終的和
    if (b == 0) return a;

    // a ^ b：求不含進位的各位數之和（XOR 在「兩個位元不同時」返回1）
    // (a & b) << 1：求進位（用 AND 確定「兩者都為1的位數」，再用左移移動到下一位數位置）
    // 每次遞迴進位的位元都會向高位移動，在32位元整數中最多32次必定變為零
    return getSum(a ^ b, (a & b) << 1);
}
```
