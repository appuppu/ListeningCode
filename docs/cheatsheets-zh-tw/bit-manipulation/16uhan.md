# Counting Bits for Every Number Up to N — 以陣列返回從0到N每個整數中包含的1的位元數

## 問題的本質

給定一個非負整數 `n`。返回一個長度為 `n + 1` 的陣列。陣列中索引 `i` 的元素儲存將 `i` 以二進位表示時 **1的位元個數**。例如：當 n=5 時，0→0, 1→1, 2→1, 3→2, 4→1, 5→2，因此返回 `[0,1,1,2,1,2]`。

## 核心思路

任意整數 `i` 的1的位元數，等於將 `i` 右移1位後的值 `i >> 1` 的1的位元數，加上 `i` 的最低位元（`i & 1`）。透過這個遞迴關係，可以重複利用較小值的結果，以 O(1) 的時間逐一求出所有值。

## 思考過程

1. **關注二進位的結構**：將整數 `i` 的二進位表示右移1位後，最低位元會消失，剩餘的位元列與 `i / 2`（無條件捨去）相同。也就是說，`i` 的位元列具有「`i >> 1` 的位元列」＋「最低的1位元」這樣的結構
2. **可以分解1的位元數**：根據上述結構，`i` 中包含的1的個數可以分解為「`i >> 1` 中包含的1的個數」＋「最低位元是否為1（0或1）」。將此寫成公式為 `countBits(i) = countBits(i >> 1) + (i & 1)`
3. **從較小的值開始計算即可重複利用**：`i >> 1` 的值始終小於 `i`，因此只要從 `i = 0` 開始依序計算，`result[i >> 1]` 一定已經計算完畢。藉由這個性質，不需要遞迴，而是用迴圈從前往後依序填入即可
4. **結果陣列本身就是DP表**：直接將要返回的陣列 `result` 當作DP表使用。以 `result[0] = 0` 作為基底情況，從 `i = 1` 到 `n` 依序以 `result[i] = result[i >> 1] + (i & 1)` 填入。不需要額外的資料結構

## 前置知識

### 右移運算（`>>`）是什麼

將整數的二進位表示向右移動指定位元數的運算。右移1位元後，最低位元會消失，值會變成除以2的商（無條件捨去）。

```java
int a = 6;      // 二進位: 110
int b = a >> 1;  // 二進位: 011 → 值為3（6 ÷ 2 = 3）

int c = 7;      // 二進位: 111
int d = c >> 1;  // 二進位: 011 → 值為3（7 ÷ 2 = 3，捨去小數）
```

### 位元AND運算（`&`）是什麼

比較兩個整數的各個位元，僅在兩者都為1的位元上設為1的運算。`i & 1` 是取出 `i` 的最低位元的操作，若 `i` 為奇數則返回1，若為偶數則返回0。

```java
int a = 5;       // 二進位: 101
int b = a & 1;   // 二進位: 001 → 值為1（因為是奇數，最低位元為1）

int c = 4;       // 二進位: 100
int d = c & 1;   // 二進位: 000 → 值為0（因為是偶數，最低位元為0）
```

### 動態規劃（DP）是什麼

將大問題分割為小的子問題，並將子問題的結果記錄在陣列中以便重複利用的方法。在這個問題中，利用 `result[i >> 1]`（已經計算完畢的較小值的結果）以 O(1) 求出 `result[i]`。

```java
int[] result = new int[n + 1];  // 建立DP表兼結果陣列
result[0] = 0;                  // 基底情況: 0的1的位元數為0
result[i] = result[i >> 1] + (i & 1);  // 轉移方程式: 重複利用已知結果
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 對從1到n的每個值僅需各執行一次位元移位和AND運算即可 |
| Space | O(n) — 使用長度為n+1的陣列來儲存結果（因為這就是輸出本身，也可以解釋為額外空間為O(1)） |

## 程式碼

```java
// 輸入: 非負整數 n
// 輸出: 長度為 n+1 的 int[]。每個 result[i] 儲存 i 的二進位表示中包含的1的位元數
public int[] countBits(int n) {
    // 建立DP表兼結果陣列。new int[n+1] 會將所有元素初始化為0，
    // 因此 result[0] = 0（0的1的位元數為0）會自動滿足
    int[] result = new int[n + 1];

    // i=0 已經是正確的0，因此從 i=1 開始遍歷
    for (int i = 1; i <= n; i++) {
        // result[i >> 1]: 將 i 右移1位元後的值的1的位元數（i >> 1 始終小於 i，因此已計算完畢）
        // i & 1: i 的最低位元（奇數為1，偶數為0）
        // 將這兩者相加，即可求得 i 的二進位表示中包含的1的總數
        result[i] = result[i >> 1] + (i & 1);
    }
    // 在陣列的每個元素 result[i] 中已儲存索引 i 的1的位元數的狀態下返回
    return result;
}
```
