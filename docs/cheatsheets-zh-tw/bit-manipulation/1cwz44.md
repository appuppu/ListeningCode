# Finding the Missing Number in a Sequence — 從0〜n的連續數列中找出缺少的一個數

## 問題的本質

給定一個包含從0到n的整數中n個不同數的陣列 `nums`。找出並返回在此範圍內存在但在陣列中不存在的**一個缺少的數**。

## 核心思路

XOR對同一個值套用兩次後會互相抵消變為零。將陣列的索引（0〜n-1）、值n以及陣列的所有元素全部進行XOR運算，成對的數會被消除，只剩下沒有配對的「缺少的數」。

## 思考過程

1. **除了缺少的數以外，所有數都能配對**: 陣列的索引為0〜n-1，陣列的值也是從0〜n的範圍中去除缺少的數後的結果。也就是說，只要在索引側加入初始值n，索引側就能湊齊0〜n的所有整數。只有缺少的數不存在於陣列的值側，因此無法配對
2. **XOR是抵消配對的最佳運算**: XOR具有 `a ^ a = 0`（相同的值互相抵消）和 `a ^ 0 = a`（與零進行XOR會保持原值）的性質。將所有索引和值進行XOR運算後，成對的數全部變為0，只剩下沒有配對的缺少的數
3. **初始值設為n的原因**: for迴圈的索引只涵蓋0〜n-1的範圍。但缺少的數也可能是n，因此將XOR的初始值設為n，以涵蓋0〜n的完整範圍
4. **只需一次迴圈即可完成**: 在迴圈內同時執行 `xor ^= i`（索引的XOR）和 `xor ^= nums[i]`（值的XOR），只需走訪陣列一次即可得到結果。也不需要額外的資料結構

## 前提知識

### XOR（互斥或運算）是什麼

當兩個位元不同時返回1、相同時返回0的位元運算。在Java中使用 `^` 運算子。對整數逐位元進行運算。

```java
int a = 5;          // 二進位: 101
int b = 3;          // 二進位: 011
int result = a ^ b; // 二進位: 110 → 6
```

### XOR 的重要性質

以下是構成演算法核心的三個性質。

```java
// 性質1: 相同值的XOR結果為0（互相抵消）
5 ^ 5;    // → 0

// 性質2: 與0進行XOR會保持原值
5 ^ 0;    // → 5

// 性質3: 改變順序結果不變（交換律・結合律）
(2 ^ 5) ^ 2;  // → 5（兩個2互相抵消，剩下5）
```

### ^= 運算子是什麼

將XOR運算的結果賦值給左側變數的複合賦值運算子。`xor ^= i` 等同於 `xor = xor ^ i`。

```java
int xor = 0;
xor ^= 3;   // xor = 0 ^ 3 → 3
xor ^= 3;   // xor = 3 ^ 3 → 0（相同值互相抵消）
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需走訪陣列一次即可完成 |
| Space | O(1) — 不使用額外的資料結構，只需一個變數即可完成 |

## 程式碼

```java
// 輸入: 包含從0〜n的範圍中n個不同整數的陣列 nums
// 輸出: 返回範圍內不包含在陣列中的一個整數
public int missingNumber(int[] nums) {
    // 將初始值設為n，配合迴圈的索引0〜n-1，涵蓋0〜n的完整範圍
    // 因為for迴圈的索引只涵蓋0〜n-1，所以在此將n作為初始值
    int xor = nums.length;

    for (int i = 0; i < nums.length; i++) {
        // 將索引i累積到XOR累積值中
        // 迴圈結束時，索引0〜n-1的所有值都已進行XOR運算（配合初始值n，0〜n的所有整數都已進行XOR運算）
        xor ^= i;
        // 將陣列的值累積到XOR累積值中
        // 陣列中存在的數同時出現在索引側和值側，因此根據 a ^ a = 0 的性質互相抵消
        xor ^= nums[i];
    }

    // 所有成對的數都被抵消變為0，只有不存在於陣列中的缺少的數因為沒有配對而留下
    return xor;
}
```
