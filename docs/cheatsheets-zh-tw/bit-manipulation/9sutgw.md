# Reversing the Bits of an Integer — 反轉32位元無號整數的位元

## 問題的本質

給定一個32位元的無號整數，將其位元列從左到右反轉（逆序），並回傳反轉後的整數。例如，輸入 `00000000000000000000000000001011` 會變成 `11010000000000000000000000000000`。

## 核心思路

將結果向左逐位元移位，同時從輸入中逐一取出最低位元並追加到結果中。重複此操作32次後，輸入的位元列便會以逆序堆疊在結果中。

## 思考過程

1. **位元反轉是「從末尾取出並堆疊到開頭」的操作**：從輸入的最低位元（右端）取出，追加到結果的最低位元（右端），然後將結果向左移位。如此一來，最先取出的位元最終會移動到最高位。這就是位元列的逆序建構
2. **如何取出最低位元**：計算 `n & 1` 即可取得 `n` 的最低位元。AND運算會將最低位元以外的所有位元遮罩為0
3. **如何將取出的位元追加到結果中**：使用 `result |= (n & 1)` 的OR運算，即可將取出的位元設定到result的最低位元。由於result的最低位元在前一次左移後已變為0，因此OR運算能正確地設定該位元
4. **如何前進到下一個位元**：將輸入 `n` 以 `n >>>= 1` 向右移位1個位元，下一個位元便會移到最低位。`>>>` 是無號右移，最高位始終補填0
5. **如何在結果中騰出空間**：在追加新位元之前，以 `result <<= 1` 將結果向左移位1個位元，最低位元便會變為0，為新位元騰出接收空間
6. **重複32次即完成**：由於是32位元整數，將上述「左移→追加位元→右移」重複32次，輸入的所有位元便會以逆序儲存在結果中

## 前提知識

### 何謂位元AND運算（&）

比較兩個整數的各個位元，只有兩者皆為1的位元才會成為1的運算。用作取出特定位元的「遮罩」。

```java
int n = 0b1011;       // 二進位為1011（十進位為11）
int bit = n & 1;      // 僅取得最低位元 → 1
int bit2 = 0b1010 & 1; // 最低位元為0的情況 → 0
```

### 何謂位元OR運算（|=）

比較兩個整數的各個位元，只要其中一方為1，該位元就會成為1的運算。用於將特定位元設定（設為1）。

```java
int result = 0b0000;
result |= 1;          // 將最低位元設為1 → 0b0001
result |= 0;          // 與0進行OR不會改變 → 0b0001
```

### 何謂左移運算（<<=）

將位元列向左移動指定數量的運算。右端會補填0。向左移1個位元等同於將值乘以2。

```java
int result = 0b0011;   // 二進位為11（十進位為3）
result <<= 1;          // 向左移1個位元 → 0b0110（十進位為6）
```

### 何謂無號右移運算（>>>=）

將位元列向右移動指定數量的運算。左端始終補填0。與 `>>` 不同，無論符號位元為何都補填0，因此適合用於無號整數的操作。

```java
int n = 0b1011;        // 二進位為1011
n >>>= 1;              // 向右移1個位元 → 0b0101（最低位的1消失，下一個位元移到右端）
```

## 計算量

| | 值 |
|---|---|
| Time | O(1) — 迴圈固定執行32次，不依賴輸入的值 |
| Space | O(1) — 僅使用額外變數 `result`，不依賴輸入大小 |

## 程式碼

```java
// 輸入: 32位元無號整數 n
// 輸出: 以 int 回傳位元列逆序後的整數
public int reverseBits(int n) {
    // 儲存反轉後位元列的變數。初始值0表示所有位元皆為0的狀態
    int result = 0;

    // 為了處理32位元整數的所有位元，迴圈執行32次
    for (int i = 0; i < 32; i++) {
        // 將result向左移1個位元，使最低位元變為0，騰出接收新位元的空間
        // 注意: 左移必須在追加位元之前執行。若在之後執行，最後一次追加位元後會產生多餘的移位，導致結果變為2倍
        result <<= 1;
        // 以 n & 1 取出n的最低位元，再以OR運算將其設定到result的最低位元
        // 由於前一次左移已使最低位元變為0，OR運算能正確地設定該位元
        result |= (n & 1);
        // 將n進行無號右移，使下一個位元移到最低位
        // 使用 >>> 是因為無論符號位元為何都需要補填0
        n >>>= 1;
    }
    // 32次迴圈完成後，輸入的位元0儲存在result的位元31，位元1儲存在位元30，所有位元皆以逆序儲存
    return result;
}
```
