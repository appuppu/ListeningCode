# Counting the Number of Set Bits — 計算整數的二進位表示中值為 1 的位元數量

## 問題的本質

給定一個非負整數 `n`。返回 `n` 的二進位表示中，值為 1 的位元個數（漢明權重）。

## 核心思路

`n & (n - 1)` 這個運算是一種僅消除 `n` 最低位的 1 位元的操作。重複執行此操作直到 `n` 變為 0，則重複次數就等於 1 的位元數量。

## 思考過程

1. **希望僅高效地計算值為 1 的位元數量**：不需要遍歷全部 32 個位元，只要能夠僅處理存在 1 的位元的位置，就能以與 1 的位元數量 `k` 成正比的時間完成
2. **思考如何消除最低位的 1 位元**：計算 `n - 1` 時，`n` 的最低位的 1 位元會變為 0，而比它更低位的位元會全部反轉為 1。例如當 `n = 1100` 時，`n - 1 = 1011`
3. **n AND (n - 1) 僅消除最低位的 1 位元**：對 `n` 和 `n - 1` 取 AND 運算後，最低位的 1 位元及其以下的位置會全部變為 0，而比它更高位的位元則保持不變。`1100 & 1011 = 1000`，最低位的 1 位元被消除了一個
4. **重複消除操作並計數**：重複執行 `n &= (n - 1)`，計算直到 `n` 變為 0 的次數，該次數就是原始 `n` 中包含的 1 的位元數量
5. **迴圈的終止條件**：當所有值為 1 的位元都被消除後，`n` 會變為 0。將 `n != 0` 作為迴圈條件，迴圈就會僅執行 1 的位元數量次後自然結束

## 前置知識

### 位元 AND 運算（&）是什麼

比較兩個整數的各個位元，只有當兩者都為 1 時結果才為 1 的運算。其他組合的結果均為 0。

```java
int a = 0b1100;       // 二進位為 1100
int b = 0b1010;       // 二進位為 1010
int result = a & b;   // 結果為 0b1000（只有兩者都為 1 的位置結果才為 1）
```

### n & (n - 1) 的運作方式

將 `n` 減去 1 後，最低位的 1 位元會變為 0，而比它更低位的位元會全部反轉為 1。與 `n` 取 AND 運算後，最低位的 1 位元及其以下的位置會全部變為 0。

```java
int n = 0b1100;       // n     = 1100（有 2 個值為 1 的位元）
n &= (n - 1);        // n - 1 = 1011, n = 1100 & 1011 = 1000（值為 1 的位元減少為 1 個）
n &= (n - 1);        // n - 1 = 0111, n = 1000 & 0111 = 0000（值為 1 的位元減少為 0 個）
```

### 漢明權重（Hamming Weight）是什麼

指整數的二進位表示中所包含的值為 1 的位元個數。例如 `11` 的二進位為 `1011`，因此漢明權重為 3。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(k) — k 為 `n` 中包含的 1 的位元數量。迴圈僅執行 k 次 |
| Space | O(1) — 僅使用一個計數器變數 |

## 程式碼

```java
// 輸入：非負整數 n
// 輸出：以 int 返回 n 的二進位表示中值為 1 的位元數量
public int hammingWeight(int n) {
    // 記錄消除 1 位元次數的計數器。消除的總次數即為最終答案
    int count = 0;

    // 若 n 為 0，則表示已無剩餘的 1 位元，結束迴圈
    while (n != 0) {
        // 消除最低位的 1 位元（Brian Kernighan's Trick）
        // n - 1 使最低位的 1 位元及其以下的位元反轉，與 n 取 AND 後該位置及其以下全部變為 0
        n &= (n - 1);
        // 已消除一個值為 1 的位元，記錄消除次數
        count++;
    }
    // count 中儲存了消除 1 位元的總次數，即原始 n 中所包含的 1 的位元數量
    return count;
}
```
