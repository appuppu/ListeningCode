# Finding the Number That Appears Only Once — 在陣列中找出只出現一次的元素

## 問題的本質

給定一個整數陣列 `nums`。陣列中所有元素都恰好出現2次，但只有一個元素只出現1次。請返回那個**只出現一次的元素**。

## 核心思路

XOR運算具有「對同一個值進行兩次XOR會變成0」的性質。將陣列中所有元素進行XOR運算後，出現2次的元素會全部互相抵消變成0，最終只剩下出現1次的元素。

## 思考過程

1. **只要能消除重複的配對，答案就會留下來**: 如果能把陣列中出現2次的元素全部移除，就能得到只出現1次的元素。我們需要尋找一個能高效執行「配對消除」的運算
2. **利用XOR的自反性質**: XOR運算具有 `a ^ a = 0` 的性質。對同一個值進行兩次XOR，結果會變成0。也就是說，出現2次的元素會被自動消除
3. **利用XOR的單位元和結合律**: `a ^ 0 = a`（與0進行XOR不會改變原值），而且XOR滿足結合律和交換律。因此，無論元素的出現順序如何，只要對所有元素進行XOR，配對就會被消除，只留下唯一的元素
4. **用一個變數計算累積XOR**: 將變數 `result` 初始化為0，在遍歷陣列的過程中對每個元素進行XOR運算。遍歷結束時，`result` 中殘留的值就是答案
5. **不需要額外的資料結構**: 不使用HashSet或HashMap，只用一個整數變數就能解題，因此空間複雜度為O(1)

## 前置知識

### XOR（互斥或）是什麼

當兩個位元不同時返回1、相同時返回0的位元運算。在Java中用 `^` 運算子表示。對整數使用時，會對每個位元位置分別進行XOR運算。

```java
int a = 5;          // 二進位: 101
int b = 3;          // 二進位: 011
int c = a ^ b;      // 二進位: 110 → 6
```

### XOR 的重要性質

XOR運算具有以下3個性質，解這道題時三者缺一不可。

```java
// 1. 自反性: 對同一個值進行兩次XOR會變成0
a ^ a;    // → 0

// 2. 單位元: 與0進行XOR不會改變原值
a ^ 0;    // → a

// 3. 交換律・結合律: 即使交換順序，結果也相同
a ^ b ^ a;    // → (a ^ a) ^ b → 0 ^ b → b
```

## 複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需遍歷陣列一次 |
| Space | O(1) — 不使用額外的資料結構，只需要一個整數變數 |

## 程式碼

```java
// 輸入: 整數陣列 nums（所有元素出現2次，只有一個元素出現1次）
// 輸出: 以 int 返回只出現一次的元素
public int singleNumber(int[] nums) {
    // 累積XOR的初始值。0是XOR的單位元，與任何值進行XOR都不會改變對方的值
    int result = 0;

    // 使用for-each迴圈從頭到尾逐一遍歷陣列中的每個元素
    for (int num : nums) {
        // 計算當前 result 與 num 的XOR並賦值給 result
        // 出現2次的元素會因為 a ^ a = 0 而互相抵消，只有出現1次的元素會被累積
        result ^= num;
    }

    // 迴圈結束後，所有配對都已被抵消，只剩下出現一次的元素的值
    return result;
}
```
