# Filling Distances to the Nearest Gate — 求網格中每個空房間到最近閘門的距離

## 問題的本質

給定一個 m×n 的網格。每個儲存格為「牆壁（-1）」「閘門（0）」「空房間（Integer.MAX_VALUE）」其中之一。將每個空房間的儲存格寫入到最近閘門的距離。無法到達任何閘門的房間保持 Integer.MAX_VALUE 不變。

## 核心思路

不是從每個空房間尋找最近的閘門，而是從所有閘門同時開始 BFS。由於 BFS 的每一步對應距離 1、2、3…，因此首次到達某儲存格時，該儲存格的最短距離即已確定。

## 思考過程

1. **從每個房間尋找閘門效率低下**：若對每個空房間分別執行 BFS，則 BFS 的執行次數等於房間數量，計算量會急劇增加。反轉思路，從閘門側向房間方向探索，便能以所有閘門為起點，僅執行一次 BFS 即可求得所有房間的最短距離
2. **從多個閘門同時出發（Multi-source BFS）**：將所有閘門加入佇列後開始 BFS。如此一來，距離為 1 的房間全部先被處理，接著處理距離為 2 的房間。藉由 BFS 逐層探索的特性，首次到達每個房間時的距離即為最短距離
3. **可透過數值判斷是否已訪問**：空房間以 Integer.MAX_VALUE 初始化。BFS 到達的儲存格會被寫入距離值，因此只有值為 Integer.MAX_VALUE 的儲存格才是未訪問的。無需另外準備 visited 陣列
4. **距離的計算為父儲存格的值 +1**：從佇列中取出的儲存格（父）的值加 1，即為相鄰儲存格（子）的距離。由於閘門的值為 0，相鄰房間為 1，再下一個為 2，距離會正確傳播
5. **牆壁與範圍外直接跳過**：牆壁（-1）和閘門（0）的值不是 Integer.MAX_VALUE，因此在未訪問判斷中會自然被排除。超出範圍的索引則透過邊界檢查來過濾

## 前置知識

### BFS（廣度優先搜尋）

BFS 是一種按「由近到遠」的順序探索圖或網格的演算法。使用佇列（先進先出），先處理所有距離起點為 1 的節點，再處理距離為 2 的節點。藉由此特性，可保證求得到各節點的最短距離。

```java
Queue<int[]> queue = new LinkedList<>();  // 建立 BFS 用的佇列
queue.offer(new int[]{0, 0});             // 將起點座標加入佇列
int[] cell = queue.poll();                // 從佇列前端取出元素
queue.isEmpty();                          // 判斷佇列是否為空 → true/false
```

### Multi-source BFS

一般的 BFS 只有一個起點，而 Multi-source BFS 是將多個起點加入佇列後開始執行。探索過程如同從所有起點同時擴散波紋，每個儲存格會記錄距離最近起點的距離。

```java
// 將所有閘門（值為 0 的儲存格）作為起點加入佇列
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        if (rooms[i][j] == 0)
            queue.offer(new int[]{i, j});
// 在此狀態下開始 BFS，即可從所有閘門同時開始探索
```

### 四方向相鄰儲存格探索

在網格上向上下左右四個方向移動時，使用方向向量陣列可使程式碼更簡潔。將各方向向量加到當前座標上，即可求得相鄰儲存格的座標。

```java
int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};  // 上、下、左、右的方向向量
for (int[] d : dirs) {
    int r = cell[0] + d[0];  // 相鄰儲存格的列號
    int c = cell[1] + d[1];  // 相鄰儲存格的行號
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(m × n) — 每個儲存格最多只會被加入佇列一次，因此所有儲存格僅處理一次 |
| Space | O(m × n) — 佇列中最多可能存放 m×n 個儲存格 |

## 程式碼

```java
// 輸入：m×n 的整數網格 rooms（-1=牆壁、0=閘門、Integer.MAX_VALUE=空房間）
// 輸出：無回傳值（void）。直接修改 rooms，將每個空房間的儲存格寫入到最近閘門的距離
public void wallsAndGates(int[][] rooms) {
    // 取得網格的列數
    int m = rooms.length;
    // 若網格為空則結束處理
    if (m == 0) return;
    // 取得網格的行數
    int n = rooms[0].length;

    // 建立 BFS 用的佇列。儲存儲存格的座標 {列, 行}
    Queue<int[]> q = new LinkedList<>();

    // 遍歷整個網格，將所有閘門（值為 0 的儲存格）加入佇列
    // 藉此，所有閘門同時被註冊為 BFS 的起點（Multi-source BFS）
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (rooms[i][j] == 0)
                q.offer(new int[]{i, j});

    // 表示上、下、左、右四個方向的方向向量。用於在迴圈中列舉相鄰儲存格
    int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

    // 持續執行 BFS 直到佇列為空。藉由 BFS 的特性，距離較小的儲存格會優先被處理
    while (!q.isEmpty()) {
        // 從佇列前端取出儲存格。cell[0] 為列號，cell[1] 為行號
        int[] cell = q.poll();

        // 檢查四個方向的相鄰儲存格
        for (int[] d : dirs) {
            // 將方向向量加到當前座標上，計算相鄰儲存格的座標
            int r = cell[0] + d[0];
            int c = cell[1] + d[1];

            // 若超出範圍則跳過
            if (r < 0 || r >= m || c < 0 || c >= n) continue;

            // 若值不是 Integer.MAX_VALUE 則跳過（牆壁、閘門、距離已確定的房間）
            // 透過此判斷，無需另外準備 visited 陣列即可防止重複訪問
            if (rooms[r][c] != Integer.MAX_VALUE) continue;

            // 寫入父儲存格的距離 +1。由於閘門為 0，相鄰為 1，再下一個為 2，距離會正確傳播
            // 由於 BFS 按距離順序處理儲存格，首次到達的距離即為最短距離
            rooms[r][c] = rooms[cell[0]][cell[1]] + 1;
            // 將已寫入距離的儲存格加入佇列，繼續探索更遠的房間
            q.offer(new int[]{r, c});
        }
    }
}
```
