# Deep Copying a Graph — 將連通無向圖的所有節點透過深拷貝進行複製

## 問題的本質

給定一個連通無向圖中某個節點的參照。需要建立整個圖的**深拷貝（克隆）**，並回傳克隆圖中對應的節點。每個節點擁有一個整數值 `val` 和一個鄰接節點列表 `neighbors`。必須構建一個完全獨立的新圖，不得參照原始圖中的任何節點。

## 核心思路

由於圖中可能存在環，為了避免同一個節點被克隆兩次，使用 HashMap 記錄「原始節點→克隆節點」的對應關係。若節點尚未被訪問，則建立克隆並註冊到 HashMap 中；若節點已被訪問，則直接從 HashMap 回傳克隆節點。藉此在防止無限迴圈的同時，準確地複製所有節點。

## 思考過程

1. **需要遍歷圖**：要複製整個圖，必須從起始節點出發，訪問所有可到達的節點。使用 DFS（深度優先搜尋）的遞迴方式進行遍歷是最自然的做法
2. **必須處理環**：在無向圖中，必定存在如 A→B→A 這樣的環。若嘗試重複克隆已訪問的節點，將會陷入無限迴圈，因此需要一個機制來判定「該節點是否已經被克隆」
3. **使用 HashMap 管理原始節點與克隆節點的對應關係**：準備一個 `HashMap<Node, Node>`，以「原始節點」作為鍵，「其克隆節點」作為值。如此一來，可以在 O(1) 時間內判定某個節點是否已被克隆，若已被克隆則可在 O(1) 時間內取得該克隆節點
4. **遞迴的每一步所做的事**：若當前節點已存在於 HashMap 中，則回傳其克隆節點（表示已訪問）。若不存在，則建立新的 Node 並註冊到 HashMap 中，接著對原始節點的所有鄰接節點遞迴呼叫克隆函式，並將回傳的克隆節點加入自身的 neighbors 列表中
5. **註冊必須在遞迴之前進行**：將節點註冊到 HashMap 的操作必須在對鄰接節點進行遞迴呼叫**之前**完成。若不先行註冊，當遇到環而回到自身時，將因在 HashMap 中找不到克隆節點而導致無限迴圈
6. **最終回傳的內容**：回傳起始節點的克隆節點。從該克隆節點出發，所有克隆節點皆透過鄰接列表相互連接

## 前提知識

### Node 類別

表示圖中各頂點的類別。擁有整數值 `val` 和鄰接節點列表 `neighbors`。

```java
class Node {
    public int val;
    public List<Node> neighbors;

    public Node(int val) {        // 指定 val 來建立節點
        this.val = val;
        this.neighbors = new ArrayList<>();  // 鄰接列表以空列表進行初始化
    }
}
```

### HashMap

儲存鍵值對的資料結構。可以透過指定鍵在 O(1) 時間內搜尋和取得對應的值。在此問題中，以「原始節點」作為鍵、「其克隆節點」作為值進行儲存，同時兼具已訪問判定和克隆節點取得的功能。

```java
HashMap<Node, Node> map = new HashMap<>();  // 建立空的 HashMap
map.put(original, clone);     // 將原始節點作為鍵、克隆節點作為值進行儲存
map.containsKey(original);    // 回傳原始節點是否已註冊的布林值 → true
map.get(original);            // 回傳原始節點對應的克隆節點 → clone
```

### DFS（深度優先搜尋）

圖的遍歷演算法之一。沿著一個方向盡可能深入探索，遇到死路後回退並轉向其他方向繼續探索。可以透過遞迴呼叫自然地實作。若不進行已訪問管理，在遇到環時將會陷入無限迴圈。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(V + E) — 每個節點訪問一次（V），每條邊處理一次（E） |
| Space | O(V) — HashMap 中儲存 V 個節點的對應關係，遞迴堆疊最深也為 V 層 |

## 程式碼

```java
// 輸入: 連通無向圖中的一個節點 node（Node 型別）。若圖為空則為 null
// 輸出: 回傳整個圖的深拷貝中，與輸入節點對應的克隆節點（Node 型別）

// 儲存 鍵=原始節點、值=克隆節點 的 HashMap
// 為了在所有遞迴呼叫中共享，將其設為類別的欄位
Map<Node, Node> map = new HashMap<>();

public Node cloneGraph(Node node) {
    // 若圖為空（null），則回傳 null 並結束
    if (node == null) return null;

    // 若當前節點已被克隆，則回傳其克隆節點
    // 這是防止因環而產生無限迴圈的機制
    if (map.containsKey(node))
        return map.get(node);

    // 建立當前節點的克隆（此時 neighbors 為空）
    Node clone = new Node(node.val);

    // 注意: 註冊必須在下方 for 迴圈的遞迴呼叫之前進行
    // 若不先行註冊，當遇到環而回到自身時，containsKey 將無法檢測到，從而導致無限迴圈
    map.put(node, clone);

    // 對原始節點的所有鄰接節點進行遞迴克隆，並加入克隆節點的鄰接列表中
    // 藉此在克隆側構建與原始圖相同的鄰接關係
    for (Node nbr : node.neighbors) {
        clone.neighbors
            .add(cloneGraph(nbr));
    }

    // 對於最初的呼叫所回傳的 clone，即為克隆圖整體的起始節點
    return clone;
}
```
