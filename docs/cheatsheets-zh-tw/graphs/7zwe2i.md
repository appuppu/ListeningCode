# Capturing Surrounded Regions on a Board — 捕獲棋盤上被包圍的區域

## 問題的本質

給定一個由 `'X'` 和 `'O'` 組成的 m×n 棋盤。將所有被 `'X'` **完全包圍**的 `'O'` 區域全部翻轉為 `'X'`。但是，與棋盤**邊界（Border）**相鄰的 `'O'` 以及從該處連結的 `'O'` 並未被包圍，因此不可翻轉。

## 核心思路

不是「尋找被包圍的 O」，而是以逆向思維來思考：「先標記未被包圍的 O（＝從邊界可到達的 O），剩餘的 O 全部都是被包圍的」。從邊界的 O 開始透過 DFS 將連結的儲存格標記為安全，最後一次掃描整個棋盤，就能將判定與翻轉分離處理。

## 思考過程

1. **思考未被包圍的 O 的特徵**：`'O'` 不被捕獲的條件是，該 `'O'` 位於棋盤的邊界上，或者與邊界的 `'O'` 透過上下左右的連結相連。反過來說，從邊界的 `'O'` 無法到達的 `'O'` 全部都是被包圍的
2. **從邊界開始探索**：掃描棋盤的四邊（上邊、下邊、左邊、右邊），每當找到 `'O'` 時，就以該處為起點執行 DFS。透過 DFS 能到達的所有 `'O'` 都是「安全的（不可捕獲）」
3. **用標記區分安全的儲存格**：將 DFS 訪問過的 `'O'` 暫時改寫為標記 `'S'`（Safe）。這樣一來，DFS 結束後棋盤上的 `'O'` 就只剩下「尚未被標記＝被包圍」的儲存格
4. **一次掃描棋盤進行翻轉與還原**：掃描所有儲存格，仍為 `'O'` 的儲存格是被包圍的，因此翻轉為 `'X'`。`'S'` 的儲存格是安全的 `'O'`，因此還原為原本的 `'O'`。`'X'` 的儲存格則保持不變
5. **DFS 的遞迴結構**：從每個儲存格向上下左右4個方向遞迴探索。範圍外檢查與非 `'O'` 儲存格的截斷同時兼作已訪問判定（已改寫為 `'S'` 的儲存格不是 `'O'`，因此不會被重複訪問）

## 前提知識

### 什麼是 DFS（深度優先搜尋）

這是一種探索圖或網格的演算法。從某個點出發，沿著一個方向盡可能深入前進，遇到死路後回退並嘗試其他方向。可以透過遞迴呼叫自然地實作。在網格上會遞迴訪問上下左右4個方向。

```java
// 網格上 DFS 的基本模式
void dfs(char[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length          // 範圍外檢查
        || c < 0 || c >= grid[0].length
        || grid[r][c] != 'O')              // 非目標儲存格則截斷
        return;
    grid[r][c] = 'S';                      // 已訪問標記（兼作防止重複訪問）
    dfs(grid, r + 1, c);                   // 下
    dfs(grid, r - 1, c);                   // 上
    dfs(grid, r, c + 1);                   // 右
    dfs(grid, r, c - 1);                   // 左
}
```

### 邊界（Border）儲存格的掃描方法

在 m×n 的棋盤中，要列舉四邊的儲存格，可以按以下方式進行。上邊和下邊遍歷列，左邊和右邊遍歷行。

```java
int m = board.length;    // 行數
int n = board[0].length; // 列數

// 掃描上邊（第0行）和下邊（第m-1行）的所有列
for (int j = 0; j < n; j++) {
    process(board[0][j]);      // 上邊
    process(board[m - 1][j]);  // 下邊
}
// 掃描左邊（第0列）和右邊（第n-1列）的所有行
for (int i = 0; i < m; i++) {
    process(board[i][0]);      // 左邊
    process(board[i][n - 1]);  // 右邊
}
```

### 什麼是標記技法

透過將棋盤的儲存格暫時改寫為其他字元（此處為 `'S'`），來區分「已訪問」和「未訪問」的手法。不另外準備 `boolean[][]` 的訪問陣列，而是將棋盤本身用於狀態管理。在處理結束時將標記還原為原本的值。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(m × n) — 從邊界開始的 DFS 最多訪問每個儲存格1次，最終掃描也遍歷所有儲存格1次 |
| Space | O(m × n) — DFS 的遞迴呼叫堆疊在最壞情況下會達到所有儲存格數量的深度 |

## 程式碼

```java
// 輸入：由 'X' 和 'O' 組成的 m×n 二維字元陣列 board
// 輸出：就地（in-place）修改 board。將被包圍的 'O' 翻轉為 'X'，無回傳值（void）

// 透過 DFS 將從邊界可到達的 O 改寫為標記 S
void dfs(char[][] board, int r, int c, int m, int n) {
    // 若為範圍外或非 O 的儲存格則不做任何處理（已改寫為 S 的儲存格也會被排除）
    // 已改寫為 'S' 的儲存格不是 'O'，因此不會被重複訪問
    if (r < 0 || r >= m
        || c < 0 || c >= n
        || board[r][c] != 'O')
        return;

    // 改寫為安全標記 S（兼作已訪問標記）
    // 不另外準備 boolean[][]，而是將棋盤本身用於狀態管理
    board[r][c] = 'S';

    // 向上下左右4個方向遞迴探索
    dfs(board, r + 1, c, m, n);
    dfs(board, r - 1, c, m, n);
    dfs(board, r, c + 1, m, n);
    dfs(board, r, c - 1, m, n);
}

public void solve(char[][] board) {
    // 取得行數和列數。用於後續的範圍檢查和邊界掃描
    int m = board.length;     // 行數
    int n = board[0].length;  // 列數

    // 從上邊和下邊的各列開始邊界 DFS
    // dfs 僅在目標儲存格為 'O' 時才進行處理，'X' 的儲存格會直接返回不做任何處理
    for (int j = 0; j < n; j++) {
        dfs(board, 0, j, m, n);       // 上邊
        dfs(board, m - 1, j, m, n);   // 下邊
    }

    // 從左邊和右邊的各行開始邊界 DFS
    // 與上面的迴圈合在一起，覆蓋棋盤四邊所有的起點
    for (int i = 0; i < m; i++) {
        dfs(board, i, 0, m, n);       // 左邊
        dfs(board, i, n - 1, m, n);   // 右邊
    }

    // 一次掃描棋盤進行翻轉與還原
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (board[i][j] == 'O')
                board[i][j] = 'X';        // 從邊界無法到達＝被包圍的 O 翻轉為 X
            else if (board[i][j] == 'S')
                board[i][j] = 'O';        // 從邊界可到達＝將安全標記還原為原本的 O
            // 'X' 的儲存格不做變更
        }
    }
}
```
