# Checking if a Graph Forms a Valid Tree — 判定圖是否構成有效的樹

## 問題的本質

給定標記為 `0` 到 `n-1` 的 `n` 個節點和一個無向邊列表 `edges`。判定該圖是否構成**有效的樹（valid tree）**，並以 `boolean` 回傳結果。有效的樹是指所有節點皆為連通，且不存在環（迴路）的圖。

## 核心思路

樹的邊數恰好為節點數 `n` 減 1，即 `n-1` 條，且不存在環。先確認邊數是否為 `n-1` 條，再透過 Union-Find 逐一合併各邊的過程中偵測是否存在環，即可判定是否為樹。

## 思考過程

1. **利用樹的必要條件**：有效的樹必定具有 `n-1` 條邊。若邊數不為 `n-1`，則可立即判定該圖不是樹。透過此前置檢查，可排除邊數過多（必定存在環）和邊數過少（不連通）的情況
2. **思考環的偵測方法**：即使邊數為 `n-1` 條，仍可能存在環（此時圖為不連通）。每新增一條邊時，若兩端節點已屬於同一連通分量，即可偵測到環
3. **以 Union-Find 管理連通分量**：使用 Union-Find（不相交集合資料結構），可以近乎 O(1) 的時間複雜度執行判定兩個節點是否屬於同一連通分量（find）以及合併兩個連通分量（union）。將每個節點的父節點初始化為自身，再對每條邊執行 union 操作
4. **定義環的偵測條件**：在執行 union 操作時，若兩個節點的根（root）相同，表示它們已經連通。此時再新增一條邊將會產生環，因此回傳 `false`
5. **處理完所有邊後回傳結果**：若處理完所有邊後都未偵測到環，加上邊數為 `n-1` 條（已在步驟 1 確認），即可判定該圖為有效的樹，回傳 `true`

## 前提知識

### 什麼是 Union-Find（不相交集合資料結構）

一種將多個元素分組（集合）管理的資料結構，提供兩種操作。`find` 回傳某元素所屬群組的代表元素（根）。`union` 將兩個元素所屬的群組合併為一個。透過路徑壓縮和依秩合併的最佳化，各操作可近乎 O(1) 的時間複雜度執行。

```java
int[] parent = {0, 1, 2, 3, 4};  // 初始狀態：每個節點的父節點為自身
int[] rank = new int[5];          // 將每個節點的秩（樹高度的上限）初始化為 0

// find：回傳節點 x 的根（附帶路徑壓縮）
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 路徑壓縮：將父節點直接指向根
    return parent[x];
}
```

### 什麼是路徑壓縮（Path Compression）

每次呼叫 `find` 時，將搜尋路徑上所有節點的父節點直接指向根的最佳化技術。藉此使後續的 `find` 操作接近 O(1)。透過 `parent[x] = find(parent[x])` 的遞迴賦值來實現。

### 什麼是依秩合併（Union by Rank）

合併兩棵樹時，將秩（樹高度的上限）較低的樹接到秩較高的樹下方的技術。此方法可抑制樹高度的增長，使 `find` 的搜尋距離保持較短。僅當兩者秩相等時，合併後才將秩加 1。

```java
// union：合併節點 a 和節點 b 所屬的群組。若已屬同一群組則回傳 false
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // 取得各節點的根
    if (ra == rb) return false;       // 根相同 → 已屬同一群組 → 環
    if (rank[ra] < rank[rb])
        parent[ra] = rb;             // 將秩較低的一方接到秩較高的一方下方
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;             // 秩相等時將 rb 接到 ra 下方
        rank[ra]++;                   // 將秩加 1
    }
    return true;
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n × α(n)) — 對每條邊執行 find 和 union。α(n) 為阿克曼函數的反函數，實際應用中可視為常數 |
| Space | O(n) — parent 陣列和 rank 陣列各儲存 n 個元素 |

## 程式碼

```java
// 輸入：整數 n（節點數）和二維整數陣列 edges（每個元素為 [u, v] 的無向邊）
// 輸出：若圖為有效的樹則回傳 true，否則回傳 false

// parent 陣列：管理每個節點的父節點
int[] parent, rank;

// 回傳節點 x 所屬連通分量的根（附帶路徑壓縮）
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 路徑壓縮：將父節點直接指向根
    return parent[x];
}

// 合併節點 a 和節點 b 的連通分量。若會產生環則回傳 false
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // 取得兩端節點的根
    if (ra == rb) return false;       // 根相同表示會產生環 → 新增此邊將形成環
    // 將秩較低的一方接到秩較高的一方下方，以抑制樹的高度
    if (rank[ra] < rank[rb])
        parent[ra] = rb;
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;
        rank[ra]++;
    }
    return true;
}

public boolean validTree(int n, int[][] edges) {
    // 樹的邊數必須為節點數減 1（過多則必定有環，過少則不連通）
    if (edges.length != n - 1)
        return false;

    // 將每個節點的父節點初始化為自身（每個節點各自構成獨立的連通分量）
    parent = new int[n];
    rank = new int[n];
    for (int i = 0; i < n; i++)
        parent[i] = i;

    // 處理每條邊，若兩端已屬同一連通分量則會產生環，回傳 false
    for (int[] e : edges)
        if (!union(e[0], e[1]))
            return false;

    // 處理完所有邊後未偵測到環，且邊數為 n-1 條，因此為有效的樹
    return true;
}
```
