# Finding a Valid Order to Complete All Courses — 求出完成所有課程的有效修課順序

## 問題的本質

給定標記為 0 到 `numCourses - 1` 的課程，以及先修條件配對 `[a, b]`（表示必須在課程 `a` 之前修完課程 `b`）的陣列。請以陣列形式返回完成所有課程的**有效修課順序**。若不存在有效順序（存在循環依賴），則返回空陣列。

## 核心思路

先修條件的依賴關係可以用有向圖來表示，有效的修課順序對應該圖的拓撲排序。從入度為 0 的節點（沒有先修條件的課程）開始依序處理，逐步移除已處理節點的依賴關係，只要不存在循環，就能將所有節點按正確順序排列。

## 思考過程

1. **將依賴關係視為圖**：先修條件 `[a, b]` 表示一條「`b` → `a`」的有向邊。將所有先修條件表示為有向圖的邊，有效的修課順序就是該圖的拓撲排序
2. **判斷哪些課程可以作為起點**：沒有任何先修條件的課程，即入度（指向該節點的邊數）為 0 的課程，可以立即修習。預先計算各節點的入度，就能以 O(1) 判斷哪些課程可以作為起點
3. **反映處理起始課程後的影響**：將某課程標記為已修習後，以該課程為先修條件的其他課程的「剩餘先修條件數」會減少 1。這可以用入度遞減來表示。遞減後入度變為 0 的課程，即成為新的可修習課程
4. **用 BFS 管理處理順序**：將入度為 0 的課程加入佇列，每次從佇列取出課程時將其加入結果陣列，並對相鄰節點的入度進行遞減。遞減後變為 0 的節點加入佇列。這個反覆過程即為 Kahn's 演算法
5. **循環依賴的偵測**：若存在循環，循環內所有節點的入度永遠不會變為 0。因此，若已處理的課程數未達 `numCourses`，即可判定存在循環
6. **最終返回的結果**：若已處理的課程數等於 `numCourses`，則返回結果陣列；若不相等，則返回空陣列

## 前置知識

### 什麼是拓撲排序

將有向無環圖（DAG）的所有節點排成一列，使所有邊都從左指向右。若存在邊 `u → v`，則在排列順序中 `u` 必定在 `v` 之前。若存在循環，則無法進行拓撲排序。

### 什麼是入度（in-degree）

指向某節點的邊的數量。入度為 0 的節點不依賴於任何其他節點，因此可以最先處理。

```java
int[] indegree = new int[numCourses];  // 將各節點的入度初始化為 0
indegree[a]++;  // 節點 a 有一條邊進入，因此將入度加 1
--indegree[next];  // 將節點 next 的入度減 1（解除一個先修條件）
```

### 什麼是鄰接串列（Adjacency List）

一種資料結構，用串列管理圖中各節點的出邊所指向的節點。透過 `graph.get(u)` 可以取得從節點 `u` 可到達的所有節點。

```java
List<List<Integer>> graph = new ArrayList<>();       // 保存整個圖的串列
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());  // 為每個節點分配空串列
graph.get(u).add(v);   // 新增從節點 u 到節點 v 的邊
graph.get(u);           // 取得節點 u 的所有相鄰節點 → [v, ...]
```

### 什麼是 Queue（佇列）

先進先出（FIFO）的資料結構。在 BFS 中用佇列管理等待處理的節點。

```java
Queue<Integer> queue = new LinkedList<>();  // 建立空佇列
queue.offer(0);   // 將元素 0 加入佇列尾端
queue.poll();      // 從佇列前端取出並返回元素 → 0
queue.isEmpty();   // 以 boolean 返回佇列是否為空 → true
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(V + E) — 所有節點（課程）和所有邊（先修條件）各處理一次 |
| Space | O(V + E) — 鄰接串列儲存所有邊，入度陣列、佇列和結果陣列儲存所有節點 |

## 程式碼

```java
// 輸入：整數 numCourses（課程總數）和二維整數陣列 prerequisites（先修條件配對的陣列）
// 輸出：返回包含所有課程有效修課順序的 int[]。若不存在有效順序，則返回空的 int[]
public int[] findOrder(int numCourses, int[][] prerequisites) {
    // 建立鄰接串列，為每門課程分配空串列
    // 每個索引對應一個課程編號，保存修完該課程後可以修習的課程串列
    List<List<Integer>> graph = new ArrayList<>();
    // 入度陣列：表示各課程尚未修習的先修條件數量
    int[] indegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++)
        graph.add(new ArrayList<>());

    // 根據先修條件建立邊並計算入度
    // 對於每個配對 [a, b]，建立邊 b → a，記錄課程 a 依賴於課程 b
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);  // 新增邊 pre[1] → pre[0]
        indegree[pre[0]]++;  // 將課程 pre[0] 的入度加 1
    }

    // 將入度為 0 的課程（無先修條件）加入佇列
    // 這些是最先可以修習的課程
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    // 初始化結果陣列和寫入位置
    int[] result = new int[numCourses];
    int idx = 0;

    while (!queue.isEmpty()) {
        // 從佇列取出課程，確定其修課順序
        int course = queue.poll();
        result[idx++] = course;

        // 將 course 的所有相鄰節點 next 的入度減 1
        // 這反映了 next 的先修條件之一 course 已經修習完成
        for (int next : graph.get(course))
            // 若遞減後結果為 0，表示 next 的所有先修條件已完成，將其加入佇列
            if (--indegree[next] == 0)
                queue.offer(next);
    }

    // 判斷是否已處理所有課程
    // 若 idx 未達 numCourses，表示存在循環依賴，返回空陣列
    return idx == numCourses ? result : new int[0];
}
```
