# Finding the Largest Island by Area — 在2D網格上找出面積最大的島嶼

## 問題的本質

給定一個由 `1`（陸地）和 `0`（水域）組成的2D二元網格。島嶼是指上下左右相鄰的 `1` 的格子所連結形成的群組。要求從網格中所有島嶼中找出**最大的面積**（格子數）並返回。如果不存在任何島嶼，則返回 `0`。

## 核心思路

從每個陸地格子出發，透過DFS計算相連的陸地數量，即可求得島嶼的面積。不使用額外的陣列來管理已訪問的格子，而是將已訪問的格子值改寫為 `0`，從而在不使用額外記憶體的情況下防止重複訪問。

## 思考過程

1. **島嶼的面積等於連通分量的大小**：網格上的 `1` 透過上下左右相鄰連結形成的群組構成一個島嶼。島嶼的面積是該群組所包含的格子數量。因此，只需求出每個連通分量的大小，並返回其中的最大值即可
2. **DFS適合用於連通分量的探索**：如果某個格子 `(r, c)` 的值為 `1`，則以該格子為起點，透過DFS向上下左右的相鄰格子進行遞迴探索，計算所有相連的 `1` 的數量，即可求得該島嶼的面積
3. **需要一個機制來防止同一格子被重複計算**：如果DFS重新訪問已訪問過的格子，面積就會被重複計算。通常會準備一個 `boolean[][] visited` 陣列來記錄已訪問狀態，但這需要O(m × n)的額外記憶體
4. **將已訪問的格子改寫為 `0` 即可省去額外記憶體**：將DFS訪問過的格子值從 `1` 改為 `0`，該格子就會被視為水域，後續的探索不會再次訪問它。無需使用 `visited` 陣列即可防止重複訪問，輔助記憶體降為O(1)
5. **透過DFS的返回值來累計面積**：DFS將訪問的格子本身計為 `1`（計數），再加上上下左右4個方向遞迴呼叫的返回值後返回。基底條件是：超出網格範圍或格子值為 `0` 時返回 `0`。藉此，一次DFS呼叫即可遞迴地累計整個島嶼的面積
6. **遍歷整個網格以求取最大值**：使用雙重for迴圈遍歷網格的所有格子，對每個格子呼叫DFS。將DFS的返回值（島嶼面積）與當前最大值進行比較，保留較大的值。對於值為 `0` 的格子，DFS的基底條件會立即返回 `0`，因此不需要特別的分支判斷

## 前置知識

### 什麼是DFS（深度優先搜尋）

DFS是一種用於圖或網格的探索演算法。從一個節點出發，盡可能深入地前進，然後再回溯。在2D網格中，從某個格子出發，遞迴地移動到上下左右的相鄰格子，即可訪問所有相連的格子。

```java
// 2D網格中基本的DFS結構
void dfs(int[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length)
        return;                    // 超出網格範圍則結束
    dfs(grid, r - 1, c);          // 向上遞迴
    dfs(grid, r + 1, c);          // 向下遞迴
    dfs(grid, r, c - 1);          // 向左遞迴
    dfs(grid, r, c + 1);          // 向右遞迴
}
```

### 什麼是In-place Modification（原地修改）

In-place Modification是一種透過直接修改輸入資料本身來記錄狀態的手法，無需使用額外的資料結構（如陣列或集合等）。在這道問題中，將已訪問的陸地格子改寫為 `0`，以此取代 `visited` 陣列。

```java
grid[r][c] = 0;  // 將已訪問的陸地(1)改寫為水域(0)
```

### 什麼是Math.max

Math.max是Java的標準方法，用於比較兩個值並返回較大的那個。常用於在迴圈中持續更新最大值的場景。

```java
Math.max(3, 7);   // → 7（返回較大的值）
Math.max(10, 2);  // → 10
```

## 複雜度

| | 值 |
|---|---|
| Time | O(m × n) — 網格的每個格子最多被訪問2次（迴圈中1次，DFS中1次） |
| Space | O(1) 輔助記憶體 — 不使用visited陣列，直接改寫網格。但遞迴堆疊最多使用O(m × n) |

## 程式碼

```java
// 輸入：由 1（陸地）和 0（水域）組成的2D整數陣列 grid
// 輸出：以 int 返回網格中最大島嶼的面積。如果沒有島嶼則返回 0

// DFS：計算相連的陸地格子數量，並將已訪問的格子改寫為0
int dfs(int[][] grid, int r, int c) {
    // 基底條件：超出範圍或為水域(0)/已訪問則不計算
    if (r < 0 || r >= grid.length
        || c < 0 || c >= grid[0].length
        || grid[r][c] == 0)
        return 0;

    // 將陸地(1)改寫為水域(0)以標記為已訪問（透過 in-place modification 省去 visited 陣列）
    grid[r][c] = 0;

    // 將自身的1加上上下左右相連格子的數量後返回
    // 透過累加4個方向遞迴的返回值，遞迴地累計整個島嶼的面積
    return 1 + dfs(grid, r - 1, c)   // 上
             + dfs(grid, r + 1, c)   // 下
             + dfs(grid, r, c - 1)   // 左
             + dfs(grid, r, c + 1);  // 右
}

int maxAreaOfIsland(int[][] grid) {
    // 取得網格的行數和列數
    int m = grid.length;
    int n = grid[0].length;
    // 將記錄最大面積的變數初始化為 0（如果沒有島嶼，則直接返回此值）
    int maxArea = 0;

    // 使用雙重for迴圈遍歷所有格子，求取各島嶼面積的最大值
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // 值為 0 的格子在DFS的基底條件中會立即返回 0，因此不需要特別的分支判斷
            maxArea = Math.max(maxArea,
                dfs(grid, i, j));

    return maxArea;
}
```
