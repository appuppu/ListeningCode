# Simulating Rotting Oranges Spreading — 求解腐爛橘子擴散完成所需的最短時間

## 問題的本質

給定一個 m×n 的網格，每個格子為 0（空）、1（新鮮橘子）、2（腐爛橘子）之一。每分鐘，腐爛的橘子會使上下左右相鄰的新鮮橘子腐爛。返回所有新鮮橘子腐爛所需的**最少分鐘數**。如果無法使所有橘子腐爛，則返回 -1。

## 核心思路

腐爛的橘子「同時」向相鄰格子擴散。這正是從多個起點同時開始 BFS 的「Multi-Source BFS」，BFS 的每一層（階層）對應 1 分鐘。

## 思考過程

1. **擴散是同時發生的**：當存在多個腐爛橘子時，每個腐爛橘子同時使相鄰格子腐爛。不是從單一起點進行探索，而是需要將所有腐爛橘子同時作為出發點
2. **同時出發使用 Multi-Source BFS**：一開始將所有腐爛橘子放入佇列，BFS 的 1 層（處理佇列當前大小數量的 1 輪）就對應 1 分鐘的擴散。DFS 無法保證「最短時間」，因此 BFS 更為適合
3. **追蹤新鮮橘子的數量**：如果擴散結束後仍有新鮮橘子殘留，則為不可能的情況。因此，在初始狀態下計算新鮮橘子的數量，每次使橘子腐爛時遞減
4. **經過時間的計算方法**：每一 BFS 層處理佇列中的所有元素，每完成 1 層就將經過時間加 1 分鐘。新鮮橘子數量變為 0 時的層數即為答案
5. **終止條件與不可能判定**：BFS 結束後若 `fresh > 0`，表示存在無法到達的新鮮橘子，返回 -1。若 `fresh == 0`，則返回經過時間

## 前置知識

### BFS（廣度優先搜尋）是什麼

BFS 是一種按照「距離起點由近到遠的順序」來探索圖或網格的演算法。使用佇列（FIFO），先處理當前層的所有節點後再進入下一層。適用於求解最短距離、最短時間的問題。

### Multi-Source BFS 是什麼

一般的 BFS 只有 1 個起點，而 Multi-Source BFS 是將多個起點放入佇列後開始 BFS。用於模擬從所有起點同時擴散的情境。除了佇列的初始狀態包含多個元素之外，與一般的 BFS 相同。

### Queue（佇列）是什麼

佇列是一種先進先出（FIFO）的資料結構。在 BFS 中用於按順序處理待探索的節點。

```java
Queue<int[]> queue = new LinkedList<>();  // 建立以 int 陣列為元素的佇列
queue.offer(new int[]{0, 1});  // 將元素新增到佇列末端
int[] pos = queue.poll();       // 從佇列前端取出並移除元素 → {0, 1}
queue.size();                   // 返回佇列中的元素數量
queue.isEmpty();                // 返回佇列是否為空的布林值
```

### 方向陣列是什麼

方向陣列是在網格探索中列舉上下左右相鄰格子的技巧。將行和列的位移定義為陣列，並用迴圈遍歷。

```java
int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};  // 右、左、下、上的 4 個方向
for (int[] d : dirs) {
    int nr = row + d[0];  // 相鄰格子的行索引
    int nc = col + d[1];  // 相鄰格子的列索引
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(m × n) — 初始掃描遍歷網格所有格子 1 次，BFS 最多再處理每個格子 1 次 |
| Space | O(m × n) — 佇列最多儲存 m×n 個格子 |

## 程式碼

```java
// 輸入：m×n 的整數網格 grid（每個格子為 0=空、1=新鮮橘子、2=腐爛橘子）
// 輸出：以 int 返回所有新鮮橘子腐爛所需的最少分鐘數。不可能時返回 -1
public int orangesRotting(int[][] grid) {
    int rows = grid.length;
    int cols = grid[0].length;
    // BFS 用的佇列。保存待探索格子的座標
    Queue<int[]> queue = new LinkedList<>();
    // 追蹤剩餘新鮮橘子數量的變數
    int fresh = 0;

    // 掃描整個網格，同時準備 BFS 的多個起點和到達目標的剩餘數量
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (grid[i][j] == 2) {
                // 將腐爛橘子加入佇列（Multi-Source BFS 的起點）
                queue.offer(new int[]{i, j});
            } else if (grid[i][j] == 1) {
                // 計算新鮮橘子的數量
                fresh++;
            }
        }
    }

    // 表示上下左右 4 個方向的方向陣列。用於列舉相鄰格子
    int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
    int minutes = 0;

    // 條件不僅是佇列非空，還包括仍有新鮮橘子殘留，以避免所有橘子腐爛後的多餘迴圈
    while (!queue.isEmpty() && fresh > 0) {
        // 先保存這一層（1 分鐘）要處理的格子數。用於區分迴圈中新增的下一層元素
        int size = queue.size();
        // 開始處理 1 層，因此將經過時間加 1 分鐘
        minutes++;

        // 從佇列中取出 size 次元素，處理這一層的所有格子
        for (int k = 0; k < size; k++) {
            int[] pos = queue.poll();

            // 使用方向陣列確認上下左右 4 個相鄰格子
            for (int[] d : dirs) {
                int nr = pos[0] + d[0];
                int nc = pos[1] + d[1];

                // 若在範圍內且為新鮮橘子，則使其腐爛
                if (nr >= 0 && nr < rows
                    && nc >= 0 && nc < cols
                    && grid[nr][nc] == 1) {
                    // 將格子更新為 2 作為已訪問標記（取代 visited 陣列。防止對同一格子重複處理）
                    grid[nr][nc] = 2;
                    fresh--;
                    queue.offer(new int[]{nr, nc});
                }
            }
        }
    }

    // 若仍有新鮮橘子殘留，表示無法到達，返回 -1。否則返回經過時間
    return fresh > 0 ? -1 : minutes;
}
```
