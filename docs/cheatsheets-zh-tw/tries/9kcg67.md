# Designing a Word Dictionary With Wildcard Search — 含萬用字元的字典單字搜尋

## 問題的本質

設計一個資料結構，支援新增單字和搜尋單字兩種操作。搜尋時，點號 `.` 作為萬用字元，可以匹配任意一個字元。例如，當字典中已註冊 "bad" 時，`search("b.d")` 回傳 `true`，`search("b.e")` 回傳 `false`。

## 核心思路

將單字儲存在 Trie 中，一般字元只需沿著對應的子節點往下走一步即可，但遇到點號時，則對「所有子節點」進行分支，執行深度優先搜尋，從而實現匹配任意一個字元的搜尋功能。

## 思考過程

1. **希望高效地執行單字新增與前綴搜尋**: Trie 是一種能將字串逐字元共享儲存的資料結構，非常適合此場景。使用 Trie 可以讓具有相同前綴的單字共享節點，同時兼顧記憶體效率和搜尋效率
2. **一般字元的搜尋可透過 Trie 的基本操作來處理**: 對於字元 `c`，只需沿著當前節點的 `children[c - 'a']` 往下走即可。若子節點為 `null` 則表示不匹配，若存在則繼續處理下一個字元
3. **點號代表對所有子節點進行分支**: 點號可匹配任意一個字元，因此需要嘗試當前節點的 26 個子節點中所有不為 `null` 的節點。只要其中任何一個能與剩餘字串匹配，就回傳 `true`
4. **使用深度優先搜尋（DFS）來探索分支**: 對於點號產生的每條分支路徑，以遞迴方式逐一探索。當到達單字末尾時，若 `isEnd` 旗標為 `true` 則搜尋成功。使用 DFS 可以統一處理分支邏輯和一般字元的邏輯
5. **確定遞迴的終止條件**: 當所有字元都處理完畢（`idx == word.length()`）時，若當前節點的 `isEnd` 為 `true`，則表示該單字存在。若途中子節點為 `null`，則該路徑不匹配
6. **最終回傳的結果**: `search` 方法從根節點開始遞迴執行 DFS，只要存在任何一條匹配的路徑就回傳 `true`，否則回傳 `false`

## 前置知識

### Trie（字典樹）是什麼

Trie 是一種將字串逐字元分解並儲存在節點中的樹狀結構。每個節點最多擁有 26 個子節點（a～z），從根節點往葉節點方向走就能組成一個單字。具有相同前綴的單字會共享節點，因此非常適合用來儲存字典。

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // 對應 a～z 的 26 個子節點
    boolean isEnd = false;                    // 是否存在以此節點結尾的單字
}
```

### 深度優先搜尋（DFS）是什麼

深度優先搜尋是一種樹或圖的探索方法。它會沿著一條路徑一直走到底，遇到死路時回退一步再嘗試另一條路徑。使用遞迴來實作是最自然的方式，非常適合用於 Trie 的分支探索。

```java
boolean dfs(TrieNode node, String word, int idx) {
    // idx 是目前正在處理的字元位置
    // 遞迴地沿著子節點往下走，尋找滿足條件的路徑
}
```

### char 的整數轉換

在 Java 中，`char` 型別具有整數值。透過 `c - 'a'` 可以取得字元 `c` 在字母表中的位置（0～25）。此值可作為 Trie 的 `children` 陣列的索引使用。

```java
char c = 'd';
int idx = c - 'a';  // idx = 3（'a'=0, 'b'=1, 'c'=2, 'd'=3）
```

## 計算複雜度

| | 值 |
|---|---|
| Time (addWord) | O(m) — 與單字長度 m 成正比，逐一走訪 Trie 節點 |
| Time (search) | O(26^d × m) — d 為點號的個數，m 為單字的長度。若沒有點號則為 O(m) |
| Space | O(n × m) — 將 n 個單字（平均長度 m）儲存在 Trie 中 |

## 程式碼

```java
// 輸入: addWord(word) 接收字串 word 並將其新增至字典。search(word) 接收字串 word（可能包含 "."）
// 輸出: search 若字典中存在匹配的單字則回傳 true，不存在則回傳 false

class TrieNode {
    TrieNode[] children;  // 對應 a～z 的 26 個子節點
    boolean isEnd;        // 是否存在以此節點結尾的單字

    TrieNode() {
        children = new TrieNode[26];
        isEnd = false;
    }
}

class WordDictionary {
    TrieNode root;  // Trie 的根節點

    WordDictionary() {
        root = new TrieNode();
    }

    // 將單字新增至 Trie
    void addWord(String word) {
        // 將當前節點初始化為根節點
        TrieNode node = root;
        // 從頭開始依序處理單字的每個字元
        for (char c : word.toCharArray()) {
            // 透過 c - 'a' 求出字元 c 在 children 陣列中對應的位置
            int idx = c - 'a';
            // 若子節點不存在則新建一個
            if (node.children[idx] == null)
                node.children[idx] = new TrieNode();
            // 移動至子節點
            node = node.children[idx];
        }
        // 記錄單字的結尾。表示字典中存在以此節點結尾的單字
        node.isEnd = true;
    }

    // 從根節點開始執行含萬用字元的搜尋
    boolean search(String word) {
        // 從根節點、位置 0 開始執行 DFS
        return dfs(root, word, 0);
    }

    // 使用 DFS 遞迴探索 Trie
    boolean dfs(TrieNode node, String word, int idx) {
        // 終止條件：當所有字元都處理完畢時，回傳當前節點是否為單字的結尾
        // 若為 true 則表示單字存在，若為 false 則表示只有部分匹配的單字
        if (idx == word.length())
            return node.isEnd;

        char c = word.charAt(idx);

        if (c == '.') {
            // 點號的情況：嘗試所有 26 個子節點（匹配任意一個字元）
            for (TrieNode child : node.children) {
                // 對不為 null 的子節點遞迴進行探索
                if (child != null && dfs(child, word, idx + 1))
                    return true;  // 任何一條路徑匹配成功就立即回傳 true
            }
            // 嘗試所有子節點後仍未回傳 true 則表示不匹配
            return false;
        } else {
            // 一般字元的情況：透過 c - 'a' 求出索引，沿著對應的子節點往下走
            int i = c - 'a';
            // 若子節點不存在則表示沒有對應的字元，不匹配
            if (node.children[i] == null)
                return false;
            // 若子節點存在則以下一個字元位置 idx + 1 進行遞迴
            return dfs(node.children[i], word, idx + 1);
        }
    }
}
```
