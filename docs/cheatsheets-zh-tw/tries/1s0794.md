# Finding All Words From a Dictionary in a Grid — 在網格上同時搜尋字典中的所有單詞

## 問題的本質

給定一個字元的2D網格 `board` 和一個單詞列表 `words`。在網格上依序經過相鄰的格子（上下左右），找出所有能夠組成的單詞，並從 `words` 中返回這些單詞。每個格子在組成一個單詞的過程中只能使用一次。

## 核心思路

將單詞列表中的所有單詞存入Trie，在從網格的每個格子進行DFS時沿著Trie節點遍歷，從而同時搜尋所有單詞。由於能夠立即剪掉Trie中不存在分支的方向的DFS，因此可以大幅減少無效的搜尋。

## 思考過程

1. **希望同時搜尋多個單詞**：如果對每個單詞分別進行DFS，計算量將達到單詞數×網格全部格子數×最大單詞長度。當多個單詞共享相同的前綴時，如果能在一次DFS中同時搜尋多個單詞，效率會更高
2. **Trie適合管理共同前綴**：Trie也稱為前綴樹，它將字串的共同前綴作為一條路徑共享。將所有單詞插入Trie後，在DFS過程中可以用O(1)判定當前路徑屬於哪個單詞的前綴
3. **在Trie節點中保存單詞本身**：在單詞的末尾節點保存完整的單詞字串，當DFS到達該節點時，就能立即獲取「找到了哪個單詞」
4. **從網格的每個格子以Trie的根節點為起點進行DFS**：以每個格子作為起點，從Trie的根節點開始沿著字元進行DFS。如果當前字元對應的子節點在Trie中不存在，就立即剪掉該方向的搜尋（剪枝）
5. **已訪問格子的標記**：為了在DFS過程中不重複訪問同一個格子，將當前訪問中的格子的字元暫時替換為特殊字元 `'#'`。DFS結束後恢復為原來的字元（回溯）
6. **防止重複**：同一個單詞可能通過多條路徑被找到。在將單詞添加到結果列表時，將該Trie節點的 `word` 設為 `null`，以防止重複添加同一個單詞

## 前置知識

### 什麼是Trie（字典樹）

Trie是一種用於高效地儲存和搜尋字串集合的樹狀結構。每個節點最多有26個子節點（a〜z），從根到葉的路徑表示一個字串。具有共同前綴的字串會共享路徑，因此前綴的判定可以在O(字串長度)內完成。

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a〜z共26個字元的子節點陣列
    String word = null;                       // 在此節點完成的單詞（若非末尾則為null）
}

// 將單詞插入Trie
TrieNode root = new TrieNode();
TrieNode node = root;
for (char c : "cat".toCharArray()) {
    int i = c - 'a';                          // 將字元轉換為索引（'a'→0, 'b'→1, ...）
    if (node.children[i] == null)
        node.children[i] = new TrieNode();    // 若子節點不存在則新建
    node = node.children[i];                  // 移動到子節點
}
node.word = "cat";                            // 在末尾節點保存單詞
```

### 什麼是回溯

回溯是DFS（深度優先搜尋）的一種，在搜尋過程中修改狀態，並在搜尋結束後將狀態恢復原樣。這樣可以保證一條搜尋路徑中的狀態修改不會影響其他路徑。

```java
board[r][c] = '#';    // 標記為訪問中（防止其他路徑重複訪問此格子）
// ... 用DFS探索上下左右 ...
board[r][c] = ch;     // 恢復為原來的字元（使其可在從其他起點開始的搜尋中重新使用）
```

### char 與 int 的轉換

在Java中，`char` 類型具有整數值，因此可以通過計算字元之間的差值來將字元轉換為索引。

```java
char ch = 'c';
int index = ch - 'a';   // 'c' - 'a' = 2（用作陣列的索引）
```

## 計算量

| | 值 |
|---|---|
| Time | O(M × N × 4^L) — M×N為網格的格子數，L為最長單詞的長度。從每個格子最多向4個方向遞迴L次 |
| Space | O(所有單詞的字元數總和) — 在Trie中儲存所有單詞所需的空間 |

## 程式碼

```java
// 輸入: 字元的2D陣列 board 和字串陣列 words
// 輸出: 返回包含 board 上所有可組成單詞的 List<String>

class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a〜z的子節點
    String word = null;                       // 在此節點完成的單詞
}

// 將所有單詞插入Trie並返回根節點
TrieNode buildTrie(String[] words) {
    // 為了構建空的Trie，建立一個根節點（作為所有單詞搜尋的起點）
    TrieNode root = new TrieNode();
    // 將 words 中的每個單詞插入Trie
    for (String w : words) {
        TrieNode node = root;
        // 從根節點開始逐字元遍歷子節點
        for (char c : w.toCharArray()) {
            int i = c - 'a';
            // 若子節點不存在則新建
            if (node.children[i] == null)
                node.children[i] = new TrieNode();
            node = node.children[i];
        }
        // 在單詞的末尾節點保存單詞字串（DFS中到達該節點時可立即獲取完成的單詞）
        node.word = w;
    }
    return root;
}

// 沿著Trie節點在網格上進行DFS
void dfs(char[][] board, int r, int c,
    TrieNode node, List<String> res) {
    // 邊界檢查: 若行 r 或列 c 超出網格範圍則立即返回
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length)
        return;
    char ch = board[r][c];
    // 若格子為訪問中標記 '#' 則立即返回（防止在同一路徑內重複訪問）
    if (ch == '#') return;
    // 取得當前字元對應的Trie子節點
    TrieNode next = node.children[ch - 'a'];
    // 若子節點不存在，則Trie中不存在沿此方向延續的單詞（剪枝）
    if (next == null) return;
    // 若單詞已完成則添加到結果中，並設為null以防止重複
    // （因為同一個單詞可能通過多條路徑被找到）
    if (next.word != null) {
        res.add(next.word);
        next.word = null;
    }
    // 將當前格子替換為 '#' 以標記為訪問中
    board[r][c] = '#';
    // 對上下左右4個方向，傳入next節點進行遞迴DFS
    dfs(board, r + 1, c, next, res);
    dfs(board, r - 1, c, next, res);
    dfs(board, r, c + 1, next, res);
    dfs(board, r, c - 1, next, res);
    // 將格子的字元恢復為原來的 ch（回溯: 使其可在從其他起點開始的搜尋中重新使用）
    board[r][c] = ch;
}

// 主函式: 在網格上搜尋字典中的所有單詞
List<String> findWords(char[][] board, String[] words) {
    // 將所有單詞插入Trie
    TrieNode root = buildTrie(words);
    // 建立一個空的列表來儲存結果
    List<String> res = new ArrayList<>();
    // 用雙重for迴圈遍歷所有格子 (i, j)，以每個格子為起點執行DFS
    // 將Trie的根節點傳入DFS
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            dfs(board, i, j, root, res);
        }
    }
    // 所有格子的DFS完成後，返回結果
    return res;
}
```
