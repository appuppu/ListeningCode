# Searching for a Word in a Grid — 判定能否在網格中沿相鄰格子拼出指定單詞

## 問題的本質

給定一個二維字元網格 `board` 和一個字串 `word`。判定能否在網格中沿相鄰格子（上下左右）依序走訪來構成 `word`，並以 `boolean` 回傳結果。每個格子在同一條路徑中只能使用一次。

## 核心思路

以網格的每個格子作為起點執行 DFS，逐一比對單詞的每個字元。不另外使用陣列來管理已訪問的格子，而是直接將盤面上的格子覆寫為特殊字元，探索結束後再還原，藉此將空間複雜度壓縮到僅有遞迴堆疊的深度。

## 思考過程

1. **每個格子都可能是起點**：單詞的起始位置可以是網格中的任何格子，因此必須將所有格子都作為起點候選來嘗試
2. **逐一依序比對字元**：確認當前格子的字元是否與 `word` 中當前位置的字元一致，若一致則遞迴地向上下左右的相鄰格子繼續探索。這個結構正是 DFS（深度優先搜尋）本身
3. **防止重複使用同一格子**：同一條路徑中不能使用同一個格子兩次，因此需要管理已訪問狀態。雖然可以另外準備一個 `boolean[][]` 的訪問陣列，但會消耗額外空間
4. **直接改寫盤面來表示已訪問**：進入探索時，將當前格子的字元覆寫為 `'#'` 等盤面上不存在的特殊字元，這樣在遞迴過程中就不會再次匹配到同一格子。如此便不需要訪問陣列，空間複雜度僅為遞迴堆疊的深度 O(L)
5. **探索後還原原始字元**：在 DFS 回溯時，將覆寫的 `'#'` 還原為原始字元（回溯）。這樣從其他起點進行探索時，才能正確地使用同一格子
6. **整理探索的終止條件**：當索引 `idx` 達到 `word.length()` 時，表示所有字元比對成功，回傳 `true`。超出範圍或字元不匹配時回傳 `false`。四個方向中只要有任一方向回傳 `true`，就立即回傳 `true`

## 前置知識

### 什麼是 DFS（深度優先搜尋）

DFS 是一種圖或網格的搜尋方法。沿著一個方向盡可能深入，遇到死路後回退一步再嘗試其他方向。可以透過遞迴呼叫自然地實現。

```java
void dfs(int node) {
    // 處理 node
    for (int neighbor : getNeighbors(node)) {
        dfs(neighbor);  // 遞迴地前進到相鄰節點
    }
}
```

### 什麼是回溯法

回溯法是一種在探索過程中所做的變更，於從探索返回時還原的方法。透過「嘗試 → 前進 → 還原」的循環，可以不遺漏地探索所有候選方案。

```java
board[r][c] = '#';   // 進行變更（標記為已訪問）
dfs(...);            // 遞迴地繼續探索
board[r][c] = temp;  // 還原（恢復為未訪問）
```

### 什麼是 charAt

`charAt` 是回傳 `String` 中指定位置字元的方法，回傳型別為 `char`。索引從 0 開始。

```java
String word = "ABCCED";
word.charAt(0);   // 回傳 'A'
word.charAt(3);   // 回傳 'C'
word.length();    // 回傳 6（回傳字元數）
```

### 二維網格的四方向探索

在二維網格中探索上下左右的相鄰格子時，分別對行和列進行 ±1 的四種嘗試。

```java
// 依序探索上、下、左、右
dfs(board, word, r-1, c, idx+1);  // 上（行 -1）
dfs(board, word, r+1, c, idx+1);  // 下（行 +1）
dfs(board, word, r, c-1, idx+1);  // 左（列 -1）
dfs(board, word, r, c+1, idx+1);  // 右（列 +1）
```

## 複雜度

| | 值 |
|---|---|
| Time | O(m × n × 4^L) — 以所有格子為起點，從每個起點最多向 4 個方向探索 L 個字元（m×n 為網格大小，L 為單詞長度） |
| Space | O(L) — 遞迴堆疊的最大深度為 L。因為直接改寫盤面，所以不需要訪問陣列 |

## 程式碼

```java
// 輸入：二維字元陣列 board 和字串 word
// 輸出：若能在網格中沿相鄰格子構成 word 則回傳 true，否則回傳 false

// 從當前位置 (r,c) 開始比對 word[idx] 之後字元的 DFS
boolean dfs(char[][] board, String word, int r, int c, int idx) {
    // 若 idx 等於 word.length()，表示所有字元已比對完成，回傳 true
    if (idx == word.length()) return true;

    // 若 r 或 c 超出網格範圍，或 board[r][c] 與 word.charAt(idx) 不一致，則回傳 false
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length
        || board[r][c] != word.charAt(idx))
        return false;

    // 將當前格子的字元暫存到變數 temp，並以 '#' 覆寫以防止重複訪問
    // '#' 不會與英文字母匹配，因此能防止在遞迴過程中再次匹配到此格子（取代訪問陣列的作用）
    char temp = board[r][c];
    board[r][c] = '#';

    // 向上下左右四個方向遞迴探索（任一方向回傳 true 即表示成功）
    // 由於 || 的短路求值特性，一旦找到 true，就會省略剩餘方向的探索
    boolean found =
        dfs(board, word, r - 1, c, idx + 1)
     || dfs(board, word, r + 1, c, idx + 1)
     || dfs(board, word, r, c - 1, idx + 1)
     || dfs(board, word, r, c + 1, idx + 1);

    // 無論探索結果如何，都還原原始字元（回溯）
    // 這樣可以確保從其他起點或其他路徑探索時，能正確地使用同一格子
    board[r][c] = temp;
    return found;
}

boolean exist(char[][] board, String word) {
    int m = board.length;
    int n = board[0].length;

    // 使用雙重 for 迴圈遍歷網格的所有格子 (i,j)，以每個格子為起點呼叫 DFS
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // 當 dfs 回傳 true 時，立即回傳 true
            if (dfs(board, word, i, j, 0))
                return true;

    // 若嘗試所有格子後仍未找到，則回傳 false
    return false;
}
```
