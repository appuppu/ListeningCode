# Partitioning a String Into Palindrome Substrings — 求出將字串分割為回文子字串的所有模式

## 問題的本質

給定一個字串 `s`。將 `s` 進行分割，使得所有子字串都是回文（從前往後讀和從後往前讀相同的字串），並將**所有**分割方式以列表的列表形式返回。

## 核心思路

預先使用 DP 表格將任意子字串是否為回文的判定優化為 O(1)，再透過回溯法從開頭依序切出「為回文的部分」並遞迴處理，從而高效地列舉所有分割模式。

## 思考過程

1. **分割問題可以用從開頭依序切出的遞迴來表達**：在字串的起始位置 `start` 到末尾的範圍內，切出從 `start` 到 `end` 的子字串，然後對剩餘部分進行遞迴處理。當 `start` 到達字串末尾時，一個有效的分割就完成了
2. **切出的條件是「該部分是回文」**：因為所有子字串都必須是回文，所以只有當 `s[start..end]` 是回文時才切出並加入路徑，繼續遞迴。若不是回文則跳過該切法
3. **每次以 O(n) 進行回文判定會造成大量浪費**：回溯的每個步驟都會進行子字串的回文判定，但可能會多次判定相同的子字串。若使用 DP 表格預先計算，就能將任意 `s[l..r]` 的回文判定縮短為 O(1)
4. **DP 表格的建構方法**：`dp[l][r]` 是一個 boolean 值，表示「`s` 中從索引 `l` 到 `r` 的子字串是否為回文」。回文的條件是「兩端字元相同」且「內側的子字串也是回文」。長度為 1（`l == r`）時必定是回文，長度為 2（`r - l == 1`）時兩端相同則為回文，長度 3 以上時需要 `s[l] == s[r]` 且 `dp[l+1][r-1]` 為 true 才是回文
5. **回溯的結構**：從當前位置 `start` 開始，將 `end` 從 `start` 逐一延伸到 `s.length()-1`，若 `dp[start][end]` 為 true 則將子字串加入路徑，並從 `end+1` 開始遞迴。從遞迴返回後刪除路徑末尾的元素，嘗試其他切法
6. **最終返回的內容**：每當 `start` 到達 `s.length()` 時，將當前路徑的副本加入結果列表。所有遞迴結束後，返回結果列表

## 前置知識

### 回文（Palindrome）是什麼

回文是指從前往後讀和從後往前讀都相同的字串。例如 `"aba"`、`"aa"`、`"a"` 是回文。`"ab"` 不是回文。

### 使用二維 boolean 陣列的回文 DP 表格

`dp[l][r]` 是一個能以 O(1) 判定「從索引 `l` 到 `r` 的子字串是否為回文」的表格。外層迴圈固定右端 `r`，內層迴圈將左端 `l` 從 `0` 移動到 `r` 來建構。

```java
boolean[][] dp = new boolean[n][n];
for (int r = 0; r < n; r++) {
    for (int l = 0; l <= r; l++) {
        // 兩端字元相同，且內側為回文（或長度為 2 以下）則為回文
        if (s.charAt(l) == s.charAt(r) && (r - l < 2 || dp[l + 1][r - 1])) {
            dp[l][r] = true;
        }
    }
}
dp[0][2];  // s[0] 到 s[2] 是否為回文 → true or false
```

### 回溯法是什麼

回溯法是一種探索手法：選擇一個選項並遞迴前進，當不滿足條件時撤銷上一個選擇並嘗試其他選項。由加入路徑（選擇）→ 遞迴 → 從路徑刪除（撤銷）三個步驟構成。

```java
path.add(choice);                    // 進行選擇
backtrack(nextState, path, result);  // 透過遞迴繼續前進
path.remove(path.size() - 1);       // 撤銷選擇以嘗試其他路徑
```

### substring 方法

`String.substring(start, end)` 返回從索引 `start` 到 `end - 1` 的子字串。請注意 `end` 不包含在內。

```java
String s = "aab";
s.substring(0, 1);  // "a"
s.substring(0, 2);  // "aa"
s.substring(0, 3);  // "aab"
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n × 2^n) — 建構 DP 表格需要 O(n^2)，回溯最多列舉 2^(n-1) 種分割方式，每種分割複製子字串需要 O(n) |
| Space | O(n^2) — DP 表格使用 n×n 的 boolean 陣列。遞迴堆疊的最大深度為 O(n) |

## 程式碼

```java
// 輸入：字串 s
// 輸出：儲存 s 的所有回文分割模式的 List<List<String>>
List<List<String>> partition(String s) {
    int n = s.length();

    // dp[l][r] = 表示 s[l] 到 s[r] 的子字串是否為回文的 DP 表格
    boolean[][] dp = new boolean[n][n];
    // 外層迴圈固定右端 r，內層迴圈將左端 l 從 0 掃描到 r 來建構
    for (int r = 0; r < n; r++) {
        for (int l = 0; l <= r; l++) {
            // 兩端字元相同，且內側為回文（或長度為 2 以下）則為回文
            // r - l < 2 的條件：長度 1 必定是回文，長度 2 兩端相同則為回文
            if (s.charAt(l) == s.charAt(r)
                && (r - l < 2
                || dp[l + 1][r - 1])) {
                dp[l][r] = true;
            }
        }
    }

    // 儲存所有分割模式的結果列表
    List<List<String>> res = new ArrayList<>();
    // 從起始位置 0、空路徑開始進行回溯
    bt(s, 0, new ArrayList<>(), res, dp);
    return res;
}

void bt(String s, int start,
    List<String> path,
    List<List<String>> res,
    boolean[][] dp) {
    // 到達字串末尾 → 已將整個字串完整分割為回文子字串
    if (start == s.length()) {
        // 因為 path 之後會被修改，所以加入副本
        res.add(new ArrayList<>(path));
        return;
    }

    // 依序嘗試從 start 到 end 的子字串
    for (int end = start; end < s.length();
        end++) {
        // 使用 DP 表格以 O(1) 進行回文判定
        if (dp[start][end]) {
            // 將回文部分加入路徑並遞迴
            // substring 的第二個參數是排他的，所以指定 end + 1
            path.add(
                s.substring(start, end + 1));
            // 下一個起始位置是 end + 1（切出部分的緊接之後）
            bt(s, end + 1, path, res, dp);
            // 撤銷選擇以嘗試其他切法（回溯）
            path.remove(path.size() - 1);
        }
    }
}
```
