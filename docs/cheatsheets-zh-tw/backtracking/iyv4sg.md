# Generating All Subsets of a Set — 生成集合的所有子集

## 問題的本質

給定一個包含不同整數的陣列 `nums`。請以列表形式回傳 `nums` 的所有子集（冪集合）。子集不得重複，回傳順序不限。

## 核心思路

元素數量為 `n` 的集合有 `2^n` 個子集。將 `n` 位元的整數從 `0` 列舉到 `2^n - 1`，每個位元代表「是否包含對應的元素」，因此可以不遺漏且不重複地生成所有子集。

## 思考過程

1. **子集的數量由 2^n 決定**：對於每個元素都有「包含」或「不包含」兩種選擇，因此元素數量為 `n` 的集合存在 `2^n` 個子集。要列舉所有子集，需要一種能夠表達這 `2^n` 種選擇模式的機制
2. **兩種選擇的列舉可以用位元表示**：將「包含=1、不包含=0」進行對應後，`n` 個元素的選擇模式可以用 `n` 位元的整數來表示。例如，當 `nums = [a, b, c]` 時，位元串 `101` 代表「包含 a、不包含 b、包含 c」，即子集 `[a, c]`
3. **從 0 到 2^n-1 的整數涵蓋所有模式**：`n` 位元能表示的整數從 `0`（所有位元為 0 = 空集合）到 `2^n - 1`（所有位元為 1 = 包含全部元素的集合），共有 `2^n` 個。依序列舉這些整數，即可不遺漏且不重複地生成所有子集
4. **從每個整數建構子集的方法**：可以用 `(mask & (1 << i)) != 0` 來判斷整數 `mask` 的第 `i` 個位元是否為 `1`。若為 `1`，則將 `nums[i]` 加入子集。將 `i` 從 `0` 遍歷到 `n-1`，即可完成 `mask` 對應的子集
5. **使用 1 << n 計算 2^n**：在 Java 中可以使用位元左移運算子 `<<`，透過 `1 << n` 計算 `2^n`。將迴圈的上限條件設為 `mask < (1 << n)`，即可不遺漏地從 `0` 列舉到 `2^n - 1`
6. **最終回傳的結果**：將每個 `mask` 對應的子集加入列表中，處理完所有 `mask` 後，回傳子集列表 `result`

## 前置知識

### 什麼是位元遮罩

位元遮罩是一種利用整數的每個位元（0 或 1）作為「旗標」的技巧。可以用一個整數來表示 `n` 個元素「包含/不包含」的所有組合。

```java
int mask = 5;            // 二進位為 101
// 第 0 位元: 1（包含）、第 1 位元: 0（不包含）、第 2 位元: 1（包含）
```

### 位元運算子

將 `&`（AND）與 `<<`（左移）組合使用，可以判斷特定位元是否被設為 1。

```java
1 << 0;                  // 1（二進位: 001）— 建立只有第 0 位元為 1 的遮罩
1 << 1;                  // 2（二進位: 010）— 建立只有第 1 位元為 1 的遮罩
1 << 2;                  // 4（二進位: 100）— 建立只有第 2 位元為 1 的遮罩

int mask = 5;            // 二進位: 101
(mask & (1 << 0)) != 0;  // true  — 第 0 位元為 1
(mask & (1 << 1)) != 0;  // false — 第 1 位元為 0
(mask & (1 << 2)) != 0;  // true  — 第 2 位元為 1
```

### 使用 1 << n 計算 2^n

位元左移 `1 << n` 是將 `1` 向左移動 `n` 個位元的操作，結果為 `2^n`。此操作用於計算子集的總數。

```java
1 << 3;                  // 8（= 2^3）— 若有 3 個元素，則子集共有 8 個
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n × 2^n) — 對 2^n 個遮罩各遍歷 n 個位元 |
| Space | O(n × 2^n) — 儲存 2^n 個子集，每個子集的平均元素數量為 n/2 |

## 程式碼

```java
// 輸入: 包含不同整數的陣列 nums
// 輸出: 回傳包含所有子集的 List<List<Integer>>
List<List<Integer>> subsets(int[] nums) {
    // nums 的元素數量。同時用於位元遮罩的位元數和陣列的遍歷範圍
    int n = nums.length;
    // 儲存所有子集的列表。將從每個 mask 生成的子集加入此列表
    List<List<Integer>> result = new ArrayList<>();

    // 將 mask 從 0 列舉到 2^n-1，每個值對應一個子集
    // 使用 1 << n 計算 2^n 作為迴圈條件，列舉所有 2^n 個模式
    for (int mask = 0; mask < (1 << n); mask++) {
        // 建立一個空的子集，用於加入當前 mask 對應的元素
        List<Integer> subset = new ArrayList<>();

        // i 是 nums 的索引，同時決定要檢查 mask 的第幾個位元
        for (int i = 0; i < n; i++) {
            // 使用 1 << i 建立只有第 i 位元為 1 的遮罩，再與 mask 進行 AND 運算以取得第 i 位元的值
            // 若位元為 1 則代表「包含該元素」，若為 0 則代表「不包含」，繼續處理下一個 i
            if ((mask & (1 << i)) != 0) {
                subset.add(nums[i]);
            }
        }

        // 內層迴圈結束後，將完成的子集加入結果列表
        result.add(subset);
    }
    // 處理完所有 mask 後，回傳包含 2^n 個子集的 result
    return result;
}
```
