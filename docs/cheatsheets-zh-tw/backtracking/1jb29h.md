# Generating All Valid Parentheses Combinations — 從 n 組括號生成所有有效的組合

## 問題的本質

給定一個整數 `n`。使用 `n` 個左括號 `(` 和 `n` 個右括號 `)`，生成**所有**正確嵌套的括號字串，並以列表形式返回。每個字串的長度為 `2 * n`，且在任何位置上，右括號的累計數量都不得超過左括號的累計數量。

## 核心思路

逐字構建字串時，僅需「剩餘的左括號數量」和「剩餘的右括號數量」這兩個狀態，即可決定下一個可放置的字元。左括號在使用數量少於 `n` 個時可以追加，右括號僅在其數量少於左括號時才能追加。透過此條件進行分支剪枝，便能在不生成任何無效字串的情況下，列舉出所有有效的組合。

## 思考過程

1. **需要列舉所有組合**: 問題要求「生成所有組合」，因此需要一種能探索性地列舉所有模式的方法。逐字構建字串並進行分支的回溯法非常適合此場景
2. **每一步只有兩個選擇**: 字串的每個位置只能放置 `(` 或 `)` 兩個字元。透過遞迴地重複這兩個選擇，即可探索所有候選方案
3. **希望盡早剪除無效的分支**: 如果嘗試所有的兩種選擇，將產生 `2^(2n)` 種組合，但其中大部分是無效的。有效性的條件有兩個：左括號的使用數量不能超過 `n` 個，以及右括號的數量在任何時刻都不能超過左括號的數量。利用這兩個條件進行分支剪枝
4. **狀態可以用兩個變數管理**: 將 `open`（已使用的左括號數量）和 `close`（已使用的右括號數量）傳遞給遞迴函數。若 `open < n` 則可以追加 `(`，若 `close < open` 則可以追加 `)`
5. **字串長度達到 `2 * n` 時即完成**: 在遵守 `open` 和 `close` 的條件下構建的字串，一旦達到 `2 * n` 個字元，該字串必定是有效的。將其加入結果列表
6. **透過回溯法恢復狀態**: 向 `StringBuilder` 追加字元並進行遞迴後，使用 `deleteCharAt` 刪除末尾的字元以恢復原始狀態。如此一來，所有探索路徑可以共用同一個 `StringBuilder` 實例

## 前置知識

### 什麼是回溯法

回溯法是一種透過反覆執行「選擇→遞迴→撤銷」來列舉所有有效組合的搜索方法。在每一步中，從選項中選擇一個，然後遞迴地進入下一步。從遞迴返回後，撤銷該選擇（回溯），再嘗試其他選項。加入剪枝條件後，可以盡早中斷無效的路徑。

```java
// 回溯法的基本模式
void backtrack(狀態) {
    if (終止條件) {
        加入結果;
        return;
    }
    for (每個選項) {
        套用選擇;        // 例: sb.append('(')
        backtrack(下一個狀態);
        撤銷選擇;        // 例: sb.deleteCharAt(sb.length() - 1)
    }
}
```

### 什麼是 StringBuilder

StringBuilder 是一個用於高效組建字串的類別。由於 `String` 是不可變的（immutable），每次追加字元都會生成新的物件，而 `StringBuilder` 直接操作內部緩衝區，因此追加和刪除操作的時間複雜度為 O(1)。

```java
StringBuilder sb = new StringBuilder();  // 建立空的 StringBuilder
sb.append('(');          // 在末尾追加字元 → "("
sb.append(')');          // 在末尾追加字元 → "()"
sb.length();             // 返回目前的字元數 → 2
sb.deleteCharAt(1);      // 刪除索引 1 的字元 → "("
sb.toString();           // 轉換為 String 型別並返回 → "("
```

### 括號有效性的條件

括號字串「有效」意味著滿足以下兩個條件：
- **條件 1**: 左括號和右括號的數量相等
- **條件 2**: 在字串的任意位置上，從開頭到該位置為止，右括號的數量不超過左括號的數量

例如：當 `n=2` 時，`(())` 和 `()()` 是有效的。`)()(` 違反條件 2，`((()` 違反條件 1。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(4^n / √n) — 生成的有效括號字串數量為卡塔蘭數 C(n) = C(2n,n)/(n+1)，其漸近值為 O(4^n / (n√n))。由於每個字串的構建需要 O(n) 的時間，因此整體為 O(4^n / √n) |
| Space | O(n) — 遞迴深度最大為 2n，StringBuilder 的長度也最大為 2n。排除結果列表後，使用的空間為 O(n) |

## 程式碼

```java
// 輸入: 整數 n（括號的配對數）
// 輸出: 返回包含所有有效括號字串的 List<String>
private void backtrack(StringBuilder sb, int open, int close, int n, List<String> res) {
    // 當字串長度達到 2n 時，表示已恰好使用了 n 個左括號和 n 個右括號，有效的括號字串構建完成
    if (sb.length() == 2 * n) {
        res.add(sb.toString());
        return;
    }
    // 若兩個條件都不滿足，則無法再追加字元，因此直接 return，由呼叫端繼續進行回溯

    // 若左括號的使用數量少於 n 個，則仍可追加左括號
    if (open < n) {
        sb.append('(');
        backtrack(sb, open + 1, close, n, res);
        // 回溯法的核心: 刪除末尾的 '(' 以恢復狀態，確保在正確的狀態下嘗試下一個分支（追加右括號）
        sb.deleteCharAt(sb.length() - 1);
    }

    // 注意: 條件是 close < open 而非 close < n，這一點非常重要
    // 若使用 close < n，則會允許右括號數量超過左括號的情況（例如: ")(")，
    // 而 close < open 可以確保右括號的數量始終不超過左括號的數量，從而防止生成無效的字串
    if (close < open) {
        sb.append(')');
        backtrack(sb, open, close + 1, n, res);
        sb.deleteCharAt(sb.length() - 1);  // 恢復狀態
    }
}

public List<String> generateParenthesis(int n) {
    // 用於儲存所有有效括號字串的列表
    List<String> res = new ArrayList<>();
    // 從空的 StringBuilder 以及 open=0, close=0 開始探索
    backtrack(new StringBuilder(), 0, 0, n, res);
    return res;
}
```
