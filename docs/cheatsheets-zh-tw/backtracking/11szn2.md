# Finding Combinations That Sum to a Target — 找出所有總和等於目標值的數字組合

## 問題的本質

給定一個正整數陣列 `candidates`（所有元素皆不同）和一個正整數 `target`。從 `candidates` 中找出所有總和等於 `target` 的組合並返回。同一個數字**可以重複使用任意次**。僅順序不同的組合視為重複。

## 核心思路

若事先將候選數字排序，則在遞迴的每個階段中，當「目前的候選數字超過剩餘目標值時，其後的所有候選數字也必定超過」，因此可以將不必要的搜尋整段剪除。透過這種剪枝，能夠高效地列舉所有組合。

## 思考過程

1. **列舉所有組合適合使用回溯法**：「找出所有滿足條件的模式」這類問題，可以透過逐一選擇候選數字嘗試、不符合則回退的遞迴搜尋（回溯法）來解決
2. **透過控制索引的起始位置來避免重複**：雖然同一個數字可以使用任意次，但不能將 `[2,3]` 和 `[3,2]` 視為不同的組合。在遞迴的每個階段中，只從「自身位置及之後的候選數字」中選取，就只會產生升序的組合，從而防止重複
3. **用剩餘目標值（remain）來管理進度**：從 `target` 中逐步減去已選的數字，當 `remain` 變為 0 時，表示總和與 `target` 一致。當 `remain` 變為負數時，表示總和已超過目標值
4. **排序後即可進行剪枝**：將候選數字按升序排序後，當某個候選數字 `cands[i]` 超過 `remain` 時，`cands[i+1]` 及之後的數字全部更大，因此無需嘗試。可以在該處直接中斷 for 迴圈
5. **用列表管理當前組合，反覆執行選擇與撤銷**：將元素加入末尾後進行遞迴，返回後再刪除末尾元素。這種「加入→遞迴→刪除」的模式是回溯法的基本操作
6. **當 remain 等於 0 時，將當前組合的副本加入結果中**：若儲存的是參照而非副本，後續操作會改變其內容

## 前提知識

### 何謂回溯法

一種逐步構建候選解，並在確定不滿足條件時回退到上一個狀態、嘗試其他候選的搜尋方法。透過遞迴函式實現，反覆執行「選擇→遞迴→撤銷選擇」來列舉所有模式。

### 何謂 Arrays.sort

將陣列按升序排序的方法。在已排序的陣列中，可以利用「當前值超過條件時，之後的值也全部超過」這一性質來進行剪枝。

```java
int[] cands = {3, 1, 2};
Arrays.sort(cands);       // cands 變為 {1, 2, 3}
```

### ArrayList 的操作

可變長度的列表。用於執行元素的新增、刪除和複製。在回溯法中用來管理當前的組合。

```java
List<Integer> curr = new ArrayList<>();
curr.add(2);                          // 在末尾新增 2 → [2]
curr.add(3);                          // 在末尾新增 3 → [2, 3]
curr.remove(curr.size() - 1);         // 刪除末尾元素 → [2]（回溯）
new ArrayList<>(curr);                // 建立 curr 的副本（用於儲存結果）
```

### 何謂 List\<List\<Integer\>\>

表示「整數列表的列表」的型別。用於存放多個組合。每個組合是一個 `List<Integer>`，而將它們彙集在一起的就是 `List<List<Integer>>`。

```java
List<List<Integer>> res = new ArrayList<>();  // 建立空的結果列表
res.add(new ArrayList<>(curr));               // 將組合的副本加入結果中
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n^(target/min)) — n 為候選數字的個數，min 為最小的候選值。最壞情況下，對每個候選數字都會產生選取最小值 target/min 次的分支 |
| Space | O(target/min) — 遞迴深度最大為 target/min。一個組合中包含的元素數量最多也是 target/min 個 |

## 程式碼

```java
// 輸入：正整數陣列 candidates（所有元素皆不同）和正整數 target
// 輸出：以 List<List<Integer>> 返回所有總和等於 target 的組合
public List<List<Integer>> combinationSum(int[] cands, int target) {
    // 升序排序後可使用「cands[i] > remain 則之後也全部超過」的剪枝條件
    Arrays.sort(cands);
    // 用於存放結果的列表
    List<List<Integer>> res = new ArrayList<>();
    // 開始回溯（剩餘值=target、起始位置=0、當前組合=空）
    backtrack(cands, target, 0, new ArrayList<>(), res);
    return res;
}

// remain：從 target 中減去已選數字後的剩餘值。當其為 0 時表示總和與 target 一致
// start：搜尋起始位置。只從自身位置及之後選取，以防止重複（順序不同的情況）
// curr：當前正在構建的組合。透過反覆選擇與撤銷來搜尋所有模式
void backtrack(int[] cands, int remain, int start,
               List<Integer> curr, List<List<Integer>> res) {
    // 若 remain 為 0，則總和與 target 一致 → 將當前組合加入結果
    if (remain == 0) {
        // 建立副本並儲存。若直接儲存參照，後續操作會改變其內容
        res.add(new ArrayList<>(curr));
        return;
    }
    // 從 start 開始掃描，若 cands[i] > remain，因為已排序所以之後也全部超過 → 中斷迴圈（剪枝）
    for (int i = start; i < cands.length && cands[i] <= remain; i++) {
        // 將當前候選數字加入組合的末尾
        curr.add(cands[i]);
        // 第三個參數傳入 i（而非 i+1），以允許重複選取同一個數字
        backtrack(cands, remain - cands[i], i, curr, res);
        // 從遞迴返回後撤銷所加入的元素（回溯）。準備嘗試下一個候選數字
        curr.remove(curr.size() - 1);
    }
}
```
