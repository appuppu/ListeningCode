# Placing N Queens on a Board Without Conflicts — 在棋盤上放置N個皇后且互不衝突

## 問題的本質

給定一個整數 `n`。在 n×n 的棋盤上放置 n 個皇后，使得任意兩個皇后都不在同一行、同一列或同一對角線上。以字串列表的形式返回所有滿足條件的棋盤配置。

## 核心思路

逐行放置一個皇后，就能自動排除行的衝突。對於剩餘的列、正對角線、負對角線的衝突判定，使用位元遮罩的各個位元來管理，就能在 O(1) 常數時間內完成衝突檢查和狀態更新。

## 思考過程

1. **從結構上排除行的衝突**: 將 n 個皇后放置在 n 行上，每行恰好放置一個皇后，行的衝突就不會發生。因此問題歸結為「決定每行將皇后放在哪一列」的搜索問題
2. **需要檢測列和對角線的衝突**: 列的衝突可以用「已使用的列的集合」來管理。對角線的衝突分為正對角線（右上方向，row + col 相同）和負對角線（左上方向，row - col 相同）兩種。管理這三個集合就能檢測所有衝突
3. **用位元遮罩表示集合**: 用整數的位元來表示列、正對角線、負對角線的使用狀態。第 c 位元為 1 表示「該列（或對角線）已被使用」。用位元 AND 運算進行衝突判定，用 OR 運算進行登記，比 HashSet 更快速
4. **逐行移位對角線的位元遮罩**: 正對角線在行數增加一行時，影響範圍向左偏移一列，因此用左移（`<< 1`）更新；負對角線向右偏移一列，因此用右移（`>> 1`）更新。這樣就能僅通過列號的位元位置來進行對角線的衝突判定
5. **用回溯法搜索所有解**: 從第 0 行到第 n-1 行依序，在每行嘗試不衝突的列。找到不衝突的列後放置皇后並遞迴到下一行，到達第 n 行時記錄一個解。從遞迴返回時配置自動撤銷，可以嘗試其他列
6. **返回解的總數**: 將所有行都成功放置皇后（到達 row == n）的次數加總後返回

## 前置知識

### 什麼是回溯法

回溯法是一種搜索技術：嘗試一個選項，遇到死路時回到上一個選擇並嘗試其他選項。通過遞迴呼叫可以自然地實現「嘗試→前進→回退」的過程。適用於列舉所有有效組合的問題。

```java
void backtrack(int step) {
    if (step == goal) {       // 到達目標時記錄解
        recordSolution();
        return;
    }
    for (int choice : choices) {
        if (isValid(choice)) {    // 如果選擇有效則嘗試
            apply(choice);        // 套用選擇
            backtrack(step + 1);  // 遞迴到下一步
            undo(choice);         // 撤銷選擇並嘗試其他選項
        }
    }
}
```

### 什麼是位元遮罩

位元遮罩是一種將整數的每個位元用作「集合中是否存在該元素」的旗標的技術。可以通過位元運算高速執行集合操作。

```java
int mask = 0;             // 空集合（所有位元為 0）
int bit = 1 << c;         // 建立只有第 c 位元為 1 的值（表示元素 c）
mask |= bit;              // 將元素 c 加入集合（將第 c 位元設為 1）
(mask & bit) != 0;        // 判定元素 c 是否包含在集合中 → true/false
```

### 通過位元移位追蹤對角線

在棋盤上行數增加一行時，正對角線（右上 ↗ 方向）的影響向列號較小的方向偏移，負對角線（左上 ↖ 方向）的影響向列號較大的方向偏移。通過移位位元遮罩來表示這種偏移。

```java
int posDiag = 0;          // 管理正對角線使用狀態的位元遮罩
posDiag |= (1 << c);      // 登記放置在第 c 列的皇后的正對角線
posDiag << 1;              // 下一行中影響向左偏移一列（左移）

int negDiag = 0;          // 管理負對角線使用狀態的位元遮罩
negDiag |= (1 << c);      // 登記放置在第 c 列的皇后的負對角線
negDiag >> 1;              // 下一行中影響向右偏移一列（右移）
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n!) — 每行可選的列數最多依序為 n, n-1, n-2, ... 遞減 |
| Space | O(n) — 遞迴深度為 n 層，每層的位元遮罩僅為常數個整數 |

## 程式碼

```java
// 輸入：整數 n（棋盤的大小，同時也是要放置的皇后數量）
// 輸出：以 int 返回 n 個皇后互不衝突的棋盤配置總數
int totalNQueens(int n) {
    // 從第 0 行開始搜索，將列、正對角線、負對角線的位元遮罩全部初始化為空（0）
    return backtrack(0, n, 0, 0, 0);
}

int backtrack(int row, int n,
    int cols, int posDiag,
    int negDiag) {
    // 所有行都已放置皇后，找到一個解
    if (row == n) return 1;

    // 累計從本行開始找到的解的數量的變數
    int count = 0;

    // 遍歷第 0 列到第 n-1 列，判定每列是否可以放置皇后
    for (int c = 0; c < n; c++) {
        // 建立對應第 c 列的位元。使用此 bit 與三個位元遮罩進行衝突判定
        int bit = 1 << c;

        // 如果與列、正對角線、負對角線中的任何一個衝突，則跳過並嘗試下一列
        if ((cols & bit) != 0 ||
            (posDiag & bit) != 0 ||
            (negDiag & bit) != 0)
            continue;

        // 在第 c 列放置皇后，更新三個位元遮罩後遞迴到下一行
        // cols | bit：將第 c 列登記為已使用
        // (posDiag | bit) << 1：登記正對角線，並通過左移反映到下一行的偏移
        // (negDiag | bit) >> 1：登記負對角線，並通過右移反映到下一行的偏移
        // 位元遮罩是值傳遞，從遞迴返回時會自動恢復到登記前的狀態，不需要明確的撤銷處理
        count += backtrack(row + 1, n,
            cols | bit,
            (posDiag | bit) << 1,
            (negDiag | bit) >> 1);
    }
    // 返回嘗試所有列後找到的解的總數
    return count;
}
```
