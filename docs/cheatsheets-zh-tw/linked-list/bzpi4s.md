# Adding Two Numbers Represented as Linked Lists — 將逆序鏈結串列表示的兩個數字相加

## 問題的本質

給定兩個非空鏈結串列。每個鏈結串列以**逆序**（個位數在開頭）表示一個非負整數，每個節點儲存一位數字。將兩個數字相加，並將總和以同樣的**逆序鏈結串列**形式返回。

## 核心思路

由於鏈結串列以逆序（個位數在開頭）儲存，從頭節點依序相加就能按照個位→十位→百位…的順序進行加法，與直式運算的順序完全相同。只需用一個變數來保存進位（carry），並將每一位的結果作為新節點串接起來即可。

## 思考過程

1. **逆序儲存成為優勢**：數值加法從個位數開始。由於鏈結串列是逆序的，從頭節點依序處理就能自然地從個位數開始相加，不需要反轉位數順序
2. **管理每一位的加法與進位**：每一位計算 `l1的值 + l2的值 + carry`。如果總和達到10以上，就會產生進位。`sum % 10` 是該位的結果，`sum / 10` 是傳給下一位的進位。這就是直式運算的規則本身
3. **處理兩個串列長度不同的情況**：即使其中一個串列先結束，只要另一個串列或carry還有剩餘，就需要繼續處理。將while迴圈的條件設為 `l1 != null || l2 != null || carry != 0`，就能統一處理所有情況
4. **使用虛擬頭節點簡化結果串列的建構**：為了不需要特別處理結果串列的第一個節點，在開頭放置一個值為0的虛擬節點。將所有位數的結果追加到 `curr.next`，最後返回 `dummy.next` 就能得到正確的結果串列
5. **統一迴圈內的處理**：每次迭代中，如果 `l1` 和 `l2` 不為null，就將各自的值加到sum中，並將指標移到下一個節點。如果為null則不做任何操作。這個條件分支能自然地吸收串列長度的差異
6. **最終返回的內容**：虛擬頭節點的下一個節點 `dummy.next` 就是結果串列的開頭。返回這個節點

## 前置知識

### 什麼是 ListNode

ListNode 是表示單向鏈結串列節點的類別。每個節點持有整數值 `val` 和指向下一個節點的參考 `next`。`next` 為 `null` 的節點是串列的末尾。

```java
public class ListNode {
    int val;              // 此節點儲存的一位數值
    ListNode next;        // 指向下一個節點的參考（若為末尾則為null）
    ListNode(int val) {   // 建構子：指定值來建立節點
        this.val = val;
    }
}
```

### 什麼是虛擬頭節點（Dummy Head）

虛擬頭節點是放在串列開頭、不持有實際值的虛擬節點。這是在建構結果串列時，不需要特別處理第一個節點的技巧。所有節點都能以 `curr.next = new ListNode(...)` 的方式統一追加，最後返回 `dummy.next` 就能取得實際的頭節點。

```java
ListNode dummy = new ListNode(0);  // 建立虛擬頭節點
ListNode curr = dummy;             // curr是追蹤串列末尾的指標
curr.next = new ListNode(5);       // 在虛擬節點之後追加值為5的節點
curr = curr.next;                  // 將curr移到末尾
// dummy.next 指向實際串列的開頭（值為5的節點）
```

### 什麼是進位（Carry）

當一位數的加法結果達到10以上時，傳遞到下一位的值。使用 `sum / 10` 計算（因為是整數除法，結果為0或1）。留在當前位的值使用 `sum % 10` 求得。
例：7 + 8 = 15 時，carry = 15 / 10 = 1，當前位的值 = 15 % 10 = 5。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(max(n, m)) — 遍歷兩個串列中較長者的長度 |
| Space | O(max(n, m)) — 結果串列的節點數最多為 max(n, m) + 1 個 |

## 程式碼

```java
// 輸入：逆序鏈結串列 l1 和 l2（每個節點為一位非負整數）
// 輸出：將兩個數字的總和以逆序鏈結串列返回
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    // 建立虛擬頭節點。不需要特別處理結果串列的第一個節點
    // 最終結果不包含此節點，dummy.next 才是實際的開頭
    ListNode dummy = new ListNode(0);
    // curr是追蹤結果串列末尾的指標
    ListNode curr = dummy;
    // 保存進位的變數。當每一位的加法結果達到10以上時，傳遞到下一位的值（0或1）
    int carry = 0;

    // 只要任一串列還有剩餘，或進位不為零，就繼續迴圈
    // carry != 0 的條件使其能處理 999 + 1 = 1000 這種位數增加的情況
    while (l1 != null || l2 != null || carry != 0) {
        // 將前一位的進位作為sum的初始值進行計算
        int sum = carry;

        // 如果l1還有剩餘，將其值加到sum中，並將指標移到下一個節點
        // 若為null則不做任何操作。這使得即使l1先結束，處理也能繼續
        if (l1 != null) {
            sum += l1.val;
            l1 = l1.next;
        }

        // 如果l2還有剩餘，將其值加到sum中，並將指標移到下一個節點
        // 若為null則不做任何操作。這使得即使l2先結束，處理也能繼續
        if (l2 != null) {
            sum += l2.val;
            l2 = l2.next;
        }

        // 計算進位。如果sum達到10以上則為1，未滿10則為0
        carry = sum / 10;
        // 以當前位的值（sum % 10）建立新節點，並連接到結果串列的末尾
        curr.next = new ListNode(sum % 10);
        // 將curr移到末尾，使下一次迭代能追加新節點
        curr = curr.next;
    }

    // 虛擬頭節點的下一個節點就是結果串列的開頭
    return dummy.next;
}
```
