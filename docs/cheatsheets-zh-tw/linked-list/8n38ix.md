# Removing the Nth Node From the End of a List — 從末尾刪除第N個節點

## 問題的本質

給定一個單向鏈結串列的頭節點 `head` 和一個整數 `n`。刪除串列中**從末尾數第N個**節點，並回傳修改後串列的頭節點。

## 核心思路

讓兩個指標保持N個節點的間隔同時前進，當前方指標到達串列末尾時，後方指標正好位於待刪除節點的前一個位置。如此只需一次遍歷即可完成刪除。

## 思考過程

1. **要找出從末尾數第N個節點，看似需要知道串列的長度**：直覺上，需要先遍歷整個串列求出長度L，再找到第L-N個節點，需要兩次遍歷。但若使用兩個指標，只需一次遍歷即可完成
2. **使用間隔N個節點的兩個指標**：將fast指標預先移動到比slow指標前方N個位置。在此狀態下，讓兩者同時逐一前進，當fast到達串列末尾時，slow正好位於從末尾數第N+1個位置。也就是說slow指向待刪除節點的**前一個**節點
3. **在串列前端加入虛擬節點的原因**：當待刪除的節點是串列的頭節點（head本身）時，「待刪除節點的前一個節點」並不存在。在head前面放置虛擬節點，即可用相同的邏輯處理頭節點的刪除和其他節點的刪除
4. **將fast向前移動N個位置**：透過for迴圈將fast前進N次。此時slow和fast之間存在N個節點
5. **同時移動兩個指標**：在 `fast.next != null` 的期間，同時將slow和fast逐一前進。當fast的**下一個**為null時跳出迴圈。此時fast指向串列的最後一個節點，slow指向從末尾數第N+1個節點（即待刪除節點的前一個）
6. **刪除節點並回傳串列**：slow的下一個節點即為待刪除的節點，透過 `slow.next = slow.next.next` 重新連結指標來完成刪除。最後回傳 `dummy.next`。不直接回傳head，是因為head可能已被刪除

## 前提知識

### 什麼是 ListNode

ListNode是表示單向鏈結串列中一個節點的類別。每個節點擁有一個值 `val` 和指向下一個節點的參考 `next`。`next` 為null的節點即為串列的末尾。

```java
ListNode node = new ListNode(5);  // 建立值為5的節點，next為null
node.next = new ListNode(10);     // 形成 node → 10 → null 的串列
```

### 什麼是虛擬節點（Sentinel Node）

虛擬節點是加在串列前端、不帶實際值的哨兵節點。即使在刪除頭節點的情況下，也能確保「待刪除節點的前一個節點」一定存在，不需要對頭節點進行特殊處理。

```java
ListNode dummy = new ListNode(0);  // 建立虛擬節點
dummy.next = head;                 // 將虛擬節點的next指向原本的頭節點
// 處理完成後，dummy.next即為新的頭節點
```

### 什麼是 Two-Pointer（雙指標）技巧

雙指標技巧是透過以不同速度或間隔移動兩個指標，來高效找到串列中特定位置的方法。在本題中，讓間隔N個節點的兩個指標以相同速度移動，藉此找出從末尾數第N個位置。

```java
ListNode slow = head;
ListNode fast = head;
// 先將fast向前移動N個位置，再讓兩者同時前進
```

## 計算量

| | 值 |
|---|---|
| Time | O(n) — 只需遍歷串列一次即可完成 |
| Space | O(1) — 只使用虛擬節點和兩個指標 |

## 程式碼

```java
// 輸入：單向鏈結串列的頭節點 head 和整數 n
// 輸出：回傳刪除從末尾數第N個節點後的串列頭節點 ListNode
public ListNode removeNthFromEnd(ListNode head, int n) {
    // 在串列前端加入值為0的虛擬節點
    // 放置虛擬節點後，即使刪除頭節點也能確保「待刪除節點的前一個節點」存在
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // 兩個指標都從虛擬節點開始
    // 從虛擬節點開始，才能讓slow最終正確地停在待刪除節點的前一個位置
    ListNode slow = dummy;
    ListNode fast = dummy;

    // 將fast向前移動N個位置，在slow和fast之間建立N個節點的間隔
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }

    // 同時移動兩個指標，當fast到達串列末尾時停止
    // 條件設為 fast.next != null，是為了讓fast到達串列最後一個節點時
    // slow正好位於待刪除節點的前一個位置
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // slow.next 即為待刪除的節點。將slow的next指標重新連結到下一個節點，將待刪除節點從串列中移除
    slow.next = slow.next.next;

    // 回傳 dummy.next 而非 head，是因為當head本身被刪除時，才能正確回傳新的頭節點
    return dummy.next;
}
```
