# Reordering a Linked List by Interleaving Ends — 將連結串列的兩端交替重新排列

## 問題的本質

給定一個單向連結串列 L0 → L1 → … → Ln-1 → Ln。將此串列**就地（in-place）**重新排列為 L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → … 的順序。不改變節點的值，僅透過操作節點的連結（next 指標）來實現。

## 核心思路

若將串列的後半部分反轉，則只需從「前半部分的開頭」和「後半部分的開頭（即原本的末尾）」交替連接，即可得到目標順序。為了反轉後半部分，首先需要找到串列的中間點，將串列分割為前半和後半兩部分。

## 思考過程

1. **觀察重新排列後的結構**: L0 → Ln → L1 → Ln-1 → … 這個順序，是從串列的「開頭」和「末尾」交替取出元素的結果。也就是說，只需將開頭側和末尾側這兩個序列交替合併即可
2. **從末尾取出元素需要反轉**: 在單向連結串列中，存取末尾需要 O(n) 的時間。然而，若將串列的後半部分反轉，後半部分的開頭就變成了原本的末尾，只需從開頭依序遍歷即可取得末尾側的元素
3. **找到串列的中間點**: 為了反轉後半部分，首先需要決定在哪裡分割串列。使用 slow/fast 指標（龜兔賽跑法），只需一次遍歷即可找到中間點。slow 每次前進1步，fast 每次前進2步，當 fast 到達串列末尾時，slow 就指向中間點
4. **反轉後半部分**: 從中間點的下一個節點開始，將每個節點的 next 指標重新指向前一個節點，藉此將後半串列反轉。使用 prev 變數追蹤前一個節點，迴圈結束後的 prev 即為反轉後的開頭
5. **將前半和反轉後的後半交替合併**: 分別從前半串列和後半串列的開頭遍歷，將後半的節點插入到前半節點的後面。由於每一步都需要改寫 next 指標，因此在改寫前需先將原本的連結儲存到臨時變數中
6. **後半部分的長度小於或等於前半部分**: 對於奇數長度的串列，前半部分會多一個節點，因此合併的迴圈條件為 `second != null`。當後半的節點用完時，合併即完成

## 前置知識

### 什麼是 slow/fast 指標（龜兔賽跑法）

這是一種透過一次遍歷即可找到連結串列中間點的技巧。slow 每次前進1個節點，fast 每次前進2個節點。當 fast 到達串列末尾時，slow 就指向串列的中間點。

```java
ListNode slow = head, fast = head;
while (fast.next != null && fast.next.next != null) {
    slow = slow.next;        // slow前進1步
    fast = fast.next.next;   // fast前進2步
}
// 迴圈結束時，slow指向串列的中間節點
```

### 什麼是連結串列的反轉

將每個節點的 next 指標從指向下一個節點改為指向前一個節點的操作。一邊追蹤 prev（前一個節點），一邊逐一前進，反轉連結的方向。

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode nxt = curr.next;  // 將下一個節點儲存到臨時變數
    curr.next = prev;          // 將連結指向前一個節點
    prev = curr;               // 將prev更新為當前節點
    curr = nxt;                // 前進到下一個節點
}
// 迴圈結束時，prev指向反轉後的串列開頭
```

### 什麼是兩個串列的交替合併

從兩個串列中交替逐一取出元素，連接成一個串列的操作。由於每一步都需要改寫 next 指標，因此在改寫前需先將原本的連結儲存到臨時變數中。

```java
ListNode a = list1, b = list2;
while (b != null) {
    ListNode tmpA = a.next;   // 將a的原始下一個節點儲存到臨時變數
    ListNode tmpB = b.next;   // 將b的原始下一個節點儲存到臨時變數
    a.next = b;               // 在a的後面插入b
    b.next = tmpA;            // 將b的下一個連接到a的原始下一個節點
    a = tmpA;                 // 將a前進到下一個位置
    b = tmpB;                 // 將b前進到下一個位置
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 中間點的搜尋、後半部分的反轉、合併的每個步驟各為 O(n) |
| Space | O(1) — 僅使用指標變數，不建立額外的資料結構 |

## 程式碼

```java
// 輸入: 單向連結串列的頭節點 head
// 輸出: 無（就地重新排列串列。回傳值為 void）
void reorderList(ListNode head) {
    // 空串列不需要重新排列
    if (head == null) return;

    // 步驟1: 使用slow/fast指標找到串列的中間點
    // fast以slow兩倍的速度前進，因此當fast到達末尾時，slow指向中間節點
    ListNode slow = head, fast = head;
    while (fast.next != null
            && fast.next.next != null) {
        slow = slow.next;          // slow前進1步
        fast = fast.next.next;     // fast前進2步
    }

    // 步驟2: 將後半串列切離並反轉
    ListNode second = slow.next;   // second是後半串列的頭節點
    slow.next = null;              // 切斷前半串列的末尾，將串列分割為前半和後半兩部分
    ListNode prev = null;
    while (second != null) {
        ListNode nxt = second.next;  // 將下一個節點儲存到臨時變數
        second.next = prev;          // 將連結指向前一個節點
        prev = second;               // 將prev更新為當前節點
        second = nxt;                // 前進到下一個節點
    }
    // 迴圈結束時，prev指向反轉後的後半串列開頭（即原始串列的末尾）

    // 步驟3: 將前半和反轉後的後半交替合併
    ListNode first = head;         // 前半串列的開頭
    second = prev;                 // 反轉後的後半串列的開頭
    // 對於奇數長度的串列，前半部分會多一個節點，因此當後半(second)用完時即結束
    while (second != null) {
        ListNode tmp1 = first.next;   // 將前半的下一個節點儲存到臨時變數（若不儲存，改寫next後將遺失原本的連結目標）
        ListNode tmp2 = second.next;  // 將後半的下一個節點儲存到臨時變數
        first.next = second;          // 在前半的後面插入後半的節點
        second.next = tmp1;           // 將後半節點的下一個連接到前半的後續部分
        first = tmp1;                 // 將前半的指標前進到下一個位置
        second = tmp2;                // 將後半的指標前進到下一個位置
    }
}
```
