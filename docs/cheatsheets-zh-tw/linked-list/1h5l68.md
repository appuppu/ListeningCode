# Reversing Nodes in Groups of K — 將連結串列按每K個節點為一組進行反轉

## 問題的本質

給定一個單向連結串列的頭節點 `head` 和一個整數 `k`。從串列的開頭開始，將串列分成每 `k` 個節點為一組，並反轉每組內節點的順序。若末尾的組不足 `k` 個節點，則保持該組不變。返回修改後串列的頭節點。

## 核心思路

在串列開頭放置一個虛擬節點，以「該組的前一個節點」和「該組的第k個節點」作為基準點，逐一改接每組內的指標，即可在不使用額外記憶體的情況下原地完成反轉。

## 思考過程

1. **需要以組為單位進行反轉**：不是反轉整個串列，而是每 `k` 個節點為一組分別反轉。也就是形成「確定當前組的範圍」→「反轉該組」→「前進到下一組」的迴圈結構
2. **要確定組的範圍，需要找到第k個節點**：準備一個輔助函式 `getKth`，從當前位置開始尋找第 `k` 個節點。若第 `k` 個節點不存在（為 `null`），表示剩餘節點不足 `k` 個，不需反轉即可結束
3. **反轉後需要正確連接各組之間的關係**：反轉一個組後，該組的頭和尾會互換。需要將前一組的末尾（`groupPrev`）重新指向反轉後的新頭（即原本的第 `k` 個節點）
4. **使用虛擬節點來統一處理第一組的反轉**：反轉第一組時，串列的頭節點本身會改變。在開頭放置虛擬節點後，「該組的前一個節點指向新的頭」這個操作，無論是第一組還是之後的組，都可以用相同的邏輯來處理
5. **每組的反轉使用與標準串列反轉相同的手法**：使用 `prev` 和 `curr` 兩個指標，逐一將 `curr.next` 改接到 `prev`，每次前進一個節點。不過，將 `prev` 的初始值設為該組的下一個節點（`groupNext`），這樣反轉後的末尾就會自動與下一組連接
6. **反轉後更新 groupPrev 並前進到下一組**：反轉前的組頭節點（`groupPrev.next`）在反轉後會變成該組的末尾。將此節點作為下一組的 `groupPrev`，然後進入下一次迭代

## 前置知識

### 什麼是 ListNode

表示單向連結串列中一個節點的類別。每個節點持有「值（val）」和「指向下一個節點的指標（next）」。`next` 為 `null` 的節點即為串列的末尾。

```java
class ListNode {
    int val;          // 節點持有的值
    ListNode next;    // 指向下一個節點的參考（若為末尾則為null）

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### 什麼是虛擬節點（Dummy Node）

在串列開頭新增一個假節點的技巧。當頭節點可能發生變更時，可以省去條件分支的判斷。`dummy.next` 始終指向串列實際的頭節點。

```java
ListNode dummy = new ListNode(0);  // 值可以是任意值
dummy.next = head;                 // 虛擬節點的下一個即為實際的頭節點
// ... 對串列進行操作 ...
return dummy.next;                 // 返回操作後實際的頭節點
```

### 連結串列反轉的基本操作

使用 `prev` 和 `curr` 兩個指標，逐一將每個節點的 `next` 改接到前一個節點。

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode tmp = curr.next;  // 暫時保存下一個節點
    curr.next = prev;          // 將當前節點的next改為指向前一個節點
    prev = curr;               // 將prev前進到當前節點
    curr = tmp;                // 將curr前進到下一個節點
}
// prev即為反轉後的頭節點
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 每個節點僅被訪問常數次（尋找第k個節點時一次，反轉時一次） |
| Space | O(1) — 僅使用指標變數，不需要額外的資料結構 |

## 程式碼

```java
// 輸入：連結串列的頭節點 head 和整數 k
// 輸出：返回將每k個節點為一組反轉後的連結串列的頭節點
public ListNode reverseKGroup(ListNode head, int k) {
    // 建立虛擬節點，透過 dummy.next = head 連接到實際串列的頭節點
    // 使用虛擬節點可以確保即使反轉第一組，「該組的前一個節點」也始終存在
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // groupPrev 指向「即將反轉的組的前一個節點」
    // 初始值為虛擬節點
    ListNode groupPrev = dummy;

    // 以無限迴圈在每次迭代中反轉一個組
    while (true) {
        // 從 groupPrev 的下一個節點出發，沿著 next 走 k-1 次以找到第k個節點
        // 若途中到達 null，表示剩餘節點不足k個，返回 null
        ListNode kth = getKth(groupPrev, k);

        // 若第k個節點不存在，表示剩餘不足k個，直接結束
        // 透過此判斷滿足「不足k個的組保持不變」的問題要求
        if (kth == null) break;

        // groupNext 是「當前組的下一個節點」，作為反轉的終點標記
        ListNode groupNext = kth.next;

        // 將 prev 的初始值設為 groupNext
        // 這樣反轉後的組末尾節點的 next 會自動指向下一組的頭節點
        ListNode prev = kth.next;
        // curr 從組的頭節點開始（反轉後此節點會變成組的末尾）
        ListNode curr = groupPrev.next;

        // 在 curr 不等於 groupNext 的期間，反轉組內每個節點的 next 指標
        // 透過此操作，每個節點的 next 會改為指向前一個節點
        while (curr != groupNext) {
            ListNode tmp = curr.next;  // 暫時保存下一個節點
            curr.next = prev;          // 將當前節點的next改為指向前一個節點
            prev = curr;               // 將prev前進到當前節點
            curr = tmp;                // 將curr前進到下一個節點
        }

        // 保存反轉前的頭節點（反轉後此節點已變成組的末尾）
        ListNode tmp = groupPrev.next;
        // 反轉後的組頭節點為 kth（即原本的第k個節點），
        // 將前一組的末尾正確地指向反轉後的新頭節點
        groupPrev.next = kth;
        // 反轉前為組頭的節點在反轉後已變成組的末尾
        // 將此節點作為下一次迭代的 groupPrev 使用
        groupPrev = tmp;
    }

    // dummy.next 指向操作後整個串列的頭節點
    return dummy.next;
}

// 從 node 的下一個節點開始，返回第k個節點。若不足k個則返回 null
private ListNode getKth(ListNode node, int k) {
    // 從 node 的下一個節點出發
    node = node.next;
    // 沿著 next 走 k-1 次以到達第k個節點
    // 若途中到達 null，表示剩餘節點不足k個
    while (node != null && k > 1) {
        node = node.next;
        k--;
    }
    // 返回第k個節點（若不足k個則為 null）
    return node;
}
```
