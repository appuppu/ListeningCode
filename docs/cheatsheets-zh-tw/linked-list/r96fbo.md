# Reversing a Linked List — 反轉單向鏈結串列

## 問題的本質

給定一個單向鏈結串列（singly linked list）的頭節點 `head`。將串列中所有鏈結（指標）的方向反轉，使原本的尾節點成為新的頭節點，並回傳該新的頭節點。

## 核心思路

將每個節點的 `next` 指標從「指向下一個節點」改為「指向前一個節點」，整個串列就會變成逆序。只需使用三個指標（prev、curr、next），逐一安全地重新指向鏈結，僅需遍歷一次即可完成。

## 思考過程

1. **反轉就是將鏈結的方向反轉**：鏈結串列的順序由節點的 `next` 指標決定。將所有節點的 `next` 從「指向下一個節點」改為「指向前一個節點」，整個串列就會變成逆序
2. **重新指向鏈結會遺失對下一個節點的參照**：在寫入 `curr.next = prev` 的瞬間，對原本下一個節點的參照就會消失。因此，在重新指向之前，需要先將 `curr.next` 暫存到另一個變數 `next` 中
3. **使用三個指標管理狀態**：`prev`（作為重新指向目標的前一個節點）、`curr`（目前正在處理的節點）、`next`（暫存原本下一個節點的變數），有了這三個指標就能同時進行鏈結的重新指向與遍歷
4. **決定初始狀態**：反轉後的尾節點（原本的頭節點）的 `next` 應該是 `null`，因此 `prev` 的初始值設為 `null`。`curr` 的初始值設為 `head`（頭節點）
5. **迴圈的結束條件與回傳值**：當 `curr` 變成 `null` 時，所有節點的處理已經完成。此時 `prev` 指向最後處理的節點（原本的尾節點），因此將 `prev` 作為新的頭節點回傳

## 前置知識

### ListNode（鏈結串列的節點）是什麼

鏈結串列的組成元素。每個節點擁有「值（val）」和「指向下一個節點的指標（next）」。最後一個節點的 `next` 為 `null`。

```java
class ListNode {
    int val;          // 節點儲存的值
    ListNode next;    // 指向下一個節點的參照（若為尾節點則為 null）

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### 什麼是重新指向指標

透過將另一個節點賦值給節點的 `next` 欄位，來改變鏈結的方向。

```java
// 原始狀態: A → B → C
// A.next 指向 B

A.next = null;   // A → null（A 與 B 之間的鏈結斷開）
B.next = A;      // B → A（建立從 B 到 A 的反向鏈結）
// 結果: C → null, B → A → null
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需遍歷串列一次 |
| Space | O(1) — 僅使用三個指標變數，不需要額外的資料結構 |

## 程式碼

```java
// 輸入: 單向鏈結串列的頭節點 head
// 輸出: 回傳反轉後串列的新頭節點（ListNode）
ListNode reverseList(ListNode head) {
    // prev: 重新指向的目標（反轉後的「前一個節點」）
    // 第一個節點（原本的頭節點）在反轉後會變成尾節點，所以它的 next 應該是 null。因此初始值設為 null
    ListNode prev = null;
    // curr: 即將重新指向鏈結的節點。從頭節點開始處理
    ListNode curr = head;

    // 當 curr 變成 null 時，所有節點的處理已經完成
    while (curr != null) {
        // 暫存原本的下一個節點（因為下一步會覆寫 curr.next，為了不遺失參照而先保存）
        ListNode next = curr.next;

        // 反轉鏈結：讓指標指向前一個節點而非下一個節點。這就是反轉操作的核心
        curr.next = prev;

        // 將 prev 推進到目前的節點（在下一次迭代中，作為下一個節點重新指向的目標）
        prev = curr;
        // 將 curr 推進到先前暫存的原本下一個節點（藉此繼續遍歷串列）
        curr = next;
    }

    // 在迴圈的最後一次迭代中，prev 被賦值為最後處理的節點（原本的尾節點）
    // 這就是反轉後串列的新頭節點
    return prev;
}
```
