# Detecting a Cycle in a Linked List — 判定連結串列中是否存在環

## 問題的本質

給定一個單向連結串列的頭節點 `head`。如果串列中任一節點的 `next` 指標指向先前已訪問過的節點（即存在環），則回傳 `true`；如果不存在環，則回傳 `false`。

## 核心思路

同時移動兩個速度不同的指標，若存在環，兩者必定會相遇。若不存在環，較快的指標會先到達終點。利用這個性質，無需額外的資料結構即可偵測環。

## 思考過程

1. **思考環的本質**：遍歷含有環的串列時，永遠無法到達終點（null），會無限循環下去。反之，若不存在環，必定會到達 null 而結束遍歷
2. **使用速度差異的指標**：準備一個每次前進 1 步的指標（slow）和一個每次前進 2 步的指標（fast）。在環內，fast 每一步都會縮短與 slow 之間 1 個節點的距離，因此兩者必定會相遇
3. **相遇能作為環的證據的原因**：若不存在環，fast 會先到達 null，因此 slow 和 fast 不可能指向同一個節點。發生相遇 ＝ 環存在
4. **確定終止條件**：若 fast 或 fast.next 為 null，代表串列有終點，因此不存在環。若 slow 和 fast 指向同一個節點，則環存在
5. **設定初始位置**：將 slow 放在 head，fast 放在 head.next。如此一來，while 迴圈的條件 `slow != fast` 從一開始就成立，可以進入迴圈開始遍歷
6. **最終回傳值**：slow 和 fast 相遇時回傳 `true`，fast 到達 null 時回傳 `false`

## 前置知識

### ListNode（連結串列的節點）是什麼

連結串列中的個別元素。每個節點持有「值」和「指向下一個節點的指標」。最後一個節點的 next 指向 null（在不存在環的情況下）。

```java
class ListNode {
    int val;            // 節點持有的值
    ListNode next;      // 指向下一個節點的參照（若無則為 null）
}

ListNode node = head;       // 取得頭節點
node.next;                  // 取得下一個節點
node.next.next;             // 取得後兩個的節點
```

### Floyd's Tortoise and Hare（Floyd 循環偵測演算法）是什麼

使用兩個速度不同的指標來偵測環的演算法。slow 指標每次前進 1 步，fast 指標每次前進 2 步。在環內，fast 每一步都會靠近 slow 1 個節點，因此若存在環，必定會在有限步數內相遇。

```java
ListNode slow = head;       // 每次前進 1 步的指標
ListNode fast = head.next;  // 每次前進 2 步的指標
slow = slow.next;           // 將 slow 前進 1 步
fast = fast.next.next;      // 將 fast 前進 2 步
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 若不存在環，fast 在 n/2 步內到達終點；若存在環，也會在環長度以內相遇 |
| Space | O(1) — 僅使用 2 個指標變數，不需要額外的資料結構 |

## 程式碼

```java
// 輸入：單向連結串列的頭節點 head
// 輸出：若存在環則回傳 true，不存在則回傳 false
public boolean hasCycle(ListNode head) {
    // 若節點數為 0 或 1，則不可能存在環。回傳 false 並結束
    if (head == null || head.next == null) {
        return false;
    }

    // 將 slow 放在 head，fast 放在 head.next
    // 將 fast 放在前一個位置，使 while 條件 slow != fast 從初次即成立，得以進入迴圈
    ListNode slow = head;
    ListNode fast = head.next;

    // 重複迴圈直到 slow 和 fast 相遇（相遇後結束）
    while (slow != fast) {
        // 若 fast 為 null 或 fast.next 為 null，代表串列有終點，因此不存在環
        if (fast == null || fast.next == null) {
            return false;
        }
        // 將 slow 前進 1 步，fast 前進 2 步
        // 由於速度差異，在環內 fast 每一步都會靠近 slow 1 個節點
        slow = slow.next;
        fast = fast.next.next;
    }

    // while 條件 slow != fast 變為假 ＝ slow 和 fast 已相遇，因此環存在
    return true;
}
```
