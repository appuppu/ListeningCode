# Finding the Duplicate in an Array of N Plus One Integers — 從 N+1 個整數陣列中找出重複的數

## 問題的本質

給定一個長度為 n+1 的整數陣列 `nums`。每個元素都在 1 到 n 的範圍內，且必定存在恰好一個重複的數。在不修改陣列且僅使用常數額外空間的條件下，找出並返回該重複的數。

## 核心概念

將陣列中每個索引 `i` 到 `nums[i]` 的移動關係視為「鏈結串列」，在重複數存在的位置，鏈結會匯合，從而產生環（循環）。使用 Floyd's Cycle Detection（龜兔演算法），即可以 O(1) 空間找出環的入口＝重複的數。

## 思考過程

1. **將陣列視為隱含的鏈結串列**：將索引 `i` 處的值 `nums[i]` 視為「指向下一個節點的指標」。從索引 0 出發，沿著 `nums[0]` → `nums[nums[0]]` → … 的方向遍歷，其動作與鏈結串列的遍歷相同。由於值的範圍是 1〜n，因此不會回到索引 0，且始終指向有效的索引
2. **理解重複為何產生環**：當兩個不同的索引擁有相同的值時，指向該值索引的箭頭會有兩條。這等同於鏈結串列中兩個節點指向同一個節點的狀態，環從匯合點開始。環的入口正是重複的數
3. **偵測環的存在**：slow 指標每次前進 1 步（`slow = nums[slow]`），fast 指標每次前進 2 步（`fast = nums[nums[fast]]`）。若環存在，slow 與 fast 必定會在環內的某處相遇
4. **確定環的入口**：相遇後，將 slow 重設回起始點（`nums[0]`），fast 保持在原位。兩者都以每次 1 步的速度前進，它們會在環的入口再次相遇。該入口對應的值就是重複的數
5. **為何會在入口相遇**：從起點到環入口的距離與從相遇點到環入口的距離相等，這已被數學證明。因此，以相同速度前進的兩個指標必定會在入口一致

## 前置知識

### 什麼是隱含鏈結串列（Implicit Linked List）

即使不實際建立節點物件，只要將陣列的值解讀為「指向下一個索引的指標」，就能表達與鏈結串列相同的結構。索引 `i` 的節點的「下一個節點」就是索引 `nums[i]` 的節點。

```java
// 陣列 nums = [1, 3, 4, 2, 2] 的鏈結串列遍歷
int current = nums[0];       // 索引 0 的值 → 1（下一步前往索引 1）
current = nums[current];     // 索引 1 的值 → 3（下一步前往索引 3）
current = nums[current];     // 索引 3 的值 → 2（下一步前往索引 2）
current = nums[current];     // 索引 2 的值 → 4（下一步前往索引 4）
current = nums[current];     // 索引 4 的值 → 2（回到索引 2 → 產生環）
```

### 什麼是 Floyd's Cycle Detection（Floyd 環偵測演算法）

這是一種偵測鏈結串列中環的存在並確定其入口的演算法。使用兩個指標（slow：每次 1 步、fast：每次 2 步）。若環存在，兩者必定會相遇，之後透過後續步驟即可確定環的入口。

```java
// 階段 1：在環內相遇
slow = nums[slow];           // slow 前進 1 步
fast = nums[nums[fast]];     // fast 前進 2 步

// 階段 2：確定環的入口
slow = nums[slow];           // 兩者都每次前進 1 步
fast = nums[fast];           // 相遇的地點就是環的入口
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 每個指標最多只需遍歷鏈結串列約兩圈 |
| Space | O(1) — 僅使用 slow 和 fast 兩個變數 |

## 程式碼

```java
// 輸入：長度為 n+1 的整數陣列 nums（每個元素介於 1 到 n 之間，僅有一個重複）
// 輸出：以 int 返回重複的數
public int findDuplicate(int[] nums) {
    // 將 slow 和 fast 都初始化為鏈結串列的起點（nums[0]）
    // 索引 0 本身不在值的範圍（1〜n）內，因此不會成為環的一部分，是安全的起始點
    int slow = nums[0];
    int fast = nums[0];

    // 階段 1：slow 每次走 1 步、fast 每次走 2 步，重複直到它們在環內相遇
    // 使用 do-while 的原因：因為初始值相同，需要跳過第一次的比較
    do {
        slow = nums[slow];           // 將 slow 前進 1 步
        fast = nums[nums[fast]];     // 將 fast 前進 2 步（若環存在，必定會追上）
    } while (slow != fast);

    // 階段 2：將 slow 重設回起始點，兩者都每次走 1 步
    // 利用「起點到入口的距離 = 相遇點到入口的距離」這一性質
    slow = nums[0];
    while (slow != fast) {
        slow = nums[slow];           // 兩者都每次前進 1 步
        fast = nums[fast];           // 它們必定在環的入口一致
    }

    // 環的入口 = 被兩個不同索引指向的數 = 重複的數，將其返回
    return slow;
}
```
