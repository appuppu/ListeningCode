# Merging Two Sorted Linked Lists — 將兩個已排序的連結串列合併為一個

## 問題的本質

給定兩個已排序的連結串列 `list1` 和 `list2`。將它們合併為一個已排序的連結串列，並返回合併後串列的**頭節點**。

## 核心思路

比較兩個串列的頭節點，選擇較小的一方作為合併結果的頭節點。剩餘的部分是「較小方的下一個節點」與「另一個串列」的合併結果，這與原問題具有相同的結構，因此可以用遞迴來求解。

## 思考過程

1. **合併的每一步所做的事情都相同**：比較兩個串列的頭節點，選擇較小的一方。這個操作會重複執行直到串列為空。由於每次都做相同的判斷，因此可以用遞迴來表達
2. **考慮基礎情況**：如果其中一個串列為空（null），則直接返回另一個串列。如果兩個串列都為空，則返回 null（這已包含在其中一方為 null 的情況中）
3. **考慮遞迴步驟**：如果 `list1.val <= list2.val`，則 `list1` 成為頭節點。將「`list1` 的剩餘部分」與「整個 `list2`」的合併結果連接到 `list1.next`。反之，則以 `list2` 作為頭節點並進行相同的處理
4. **每次遞迴呼叫都使問題規模減少1**：每次都從其中一個串列中消耗1個節點，因此總共經過 n 次遞迴即可處理所有節點
5. **最終返回的內容**：每次遞迴呼叫都返回所選擇的節點（`list1` 或 `list2`）。第一次呼叫所返回的節點即為合併後串列的頭節點

## 前置知識

### ListNode（連結串列的節點）是什麼

ListNode 是表示連結串列中各元素的類別。`val` 欄位儲存值，`next` 欄位儲存對下一個節點的參照。`next` 為 null 的節點即為串列的末尾。

```java
class ListNode {
    int val;          // 節點所儲存的值
    ListNode next;    // 對下一個節點的參照（若為末尾則為 null）

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### 遞迴（Recursion）是什麼

遞迴是一種函式呼叫自身來求解問題的方法。它將大問題分解為具有相同結構的小問題，當到達基礎情況（無法再繼續分解的最小問題）時返回結果。每次呼叫都會在呼叫堆疊中推入一個框架，因此會消耗與遞迴深度相等的空間。

```java
// 範例：計算階乘
int factorial(int n) {
    if (n <= 1) return 1;           // 基礎情況：不再繼續分解
    return n * factorial(n - 1);    // 遞迴步驟：將問題規模減少1並呼叫自身
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 對兩個串列的總節點數進行 n 次遞迴呼叫以處理所有節點 |
| Space | O(n) — 每次遞迴呼叫都會在呼叫堆疊中推入一個框架，最大深度為 n 層 |

## 程式碼

```java
// 輸入：兩個已排序連結串列的頭節點 list1 和 list2
// 輸出：以 ListNode 形式返回合併後已排序連結串列的頭節點
ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    // 基礎情況：如果 list1 為空，則直接返回剩餘的 list2（因為 list1 為空，所以 list2 本身即為合併結果）
    if (list1 == null) return list2;
    // 基礎情況：如果 list2 為空，則直接返回剩餘的 list1（因為 list2 為空，所以 list1 本身即為合併結果）
    if (list2 == null) return list1;

    // 比較 list1 的頭節點與 list2 的頭節點，決定將哪個節點放在合併結果的頭部
    if (list1.val <= list2.val) {
        // 選擇 list1 作為頭節點，將 list1 的剩餘部分（list1.next）與整個 list2 的合併結果連接到 list1 的下一個節點
        list1.next = mergeTwoLists(list1.next, list2);
        return list1; // list1 成為合併結果的頭節點
    } else {
        // 選擇 list2 作為頭節點，將整個 list1 與 list2 的剩餘部分（list2.next）的合併結果連接到 list2 的下一個節點
        list2.next = mergeTwoLists(list1, list2.next);
        return list2; // list2 成為合併結果的頭節點
    }
}
```
