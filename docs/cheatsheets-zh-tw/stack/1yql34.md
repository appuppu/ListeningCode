# Finding the Largest Rectangle in a Histogram — 求直方圖中能形成的最大矩形面積

## 問題的本質

給定一個非負整數陣列 `heights`。每個元素代表直方圖中柱子的高度，所有柱子的寬度均為1。求此直方圖中能形成的**最大矩形面積**並返回。

## 核心思路

當將每根柱子作為「矩形的高度」時，若能知道該柱子作為最矮柱子能向左右擴展到哪裡，就能計算面積。使用單調遞增堆疊，在柱子高度下降的瞬間，就能以 O(1) 確定堆疊中柱子可擴展的寬度。

## 思考過程

1. **考慮以每根柱子為高度的矩形**：任意矩形都可視為「以某根柱子的高度為上限，由左右連續的柱子所構成」。也就是說，對於每根柱子 `heights[i]`，若能知道「以該柱子為最矮柱子的區間寬度」，就能以 `heights[i] × 寬度` 計算面積
2. **希望高效地求出左右邊界**：對於每根柱子，若能知道「左側第一根比自己矮的柱子的位置」和「右側第一根比自己矮的柱子的位置」，就能確定可擴展的寬度。對所有柱子暴力搜尋這兩個邊界需要 O(n²)，因此使用堆疊來提升效率
3. **使用單調遞增堆疊**：將柱子的索引以高度單調遞增的方式壓入堆疊。當目前柱子的高度低於堆疊頂端時，可確定堆疊頂端柱子的「右側邊界」為目前位置 `i`
4. **彈出時計算寬度**：從堆疊彈出柱子 `top` 時，右側邊界為目前位置 `i`，左側邊界為彈出後堆疊頂端的下一個位置。若堆疊為空，則可擴展到最左端（索引 0），寬度為 `i`。若堆疊不為空，寬度為 `i - stack.peek() - 1`
5. **在末尾添加高度 0 作為哨兵**：到達陣列末尾時，仍需計算堆疊中剩餘柱子的面積。將迴圈範圍設為 `i <= heights.length`，當 `i == heights.length` 時虛擬地放置高度 0，確保堆疊中所有柱子都會被彈出
6. **追蹤最大面積**：每次彈出柱子時計算 `heights[top] × 寬度`，並與目前的最大值比較後更新。所有彈出操作完成時的最大值即為答案

## 前置知識

### Stack（堆疊）是什麼

後進先出（LIFO）的資料結構。最後添加的元素最先被取出。在直方圖問題中，將柱子的索引壓入堆疊，用於維持高度的單調性。

```java
Stack<Integer> stack = new Stack<>();  // 建立空的堆疊
stack.push(0);       // 將值 0 添加到堆疊頂端
stack.peek();        // 不取出地參照堆疊頂端的值 → 0
stack.pop();         // 取出並返回堆疊頂端的值 → 0
stack.isEmpty();     // 以 boolean 返回堆疊是否為空 → true
```

### 單調遞增堆疊（Monotonic Stack）是什麼

堆疊內的元素始終維持從底部到頂部遞增（或相等）狀態的堆疊。添加新元素時，若新值小於堆疊頂端，則持續彈出頂端直到頂端值不大於新值為止。在彈出的瞬間，可解釋為「被彈出元素的右側邊界已確定」。

```java
// 對陣列 [2, 1, 5, 6, 2, 3] 的單調遞增堆疊運作過程
// i=0: push(0)         → 堆疊: [0]       （高度: [2]）
// i=1: 1 < 2 所以 pop  → 堆疊: []        （高度 2 的柱子的右邊界確定為 i=1）
//       push(1)         → 堆疊: [1]       （高度: [1]）
// i=2: push(2)         → 堆疊: [1,2]     （高度: [1,5]）
// i=3: push(3)         → 堆疊: [1,2,3]   （高度: [1,5,6]）
// i=4: 2 < 6 所以 pop  → 堆疊: [1,2]     （高度 6 的柱子的右邊界確定為 i=4）
//       2 < 5 所以 pop  → 堆疊: [1]       （高度 5 的柱子的右邊界確定為 i=4）
//       push(4)         → 堆疊: [1,4]     （高度: [1,2]）
```

### 哨兵（Sentinel）是什麼

為了簡化迴圈的終端處理而虛擬添加的值。在此問題中，於陣列末尾虛擬放置高度 0 的柱子，使迴圈結束時堆疊中剩餘的所有柱子自然地被彈出。

```java
// 當 i == heights.length 時，已超出實際陣列範圍，因此虛擬地使用高度 0
int h = (i == heights.length) ? 0 : heights[i];
// 高度 0 比任何柱子都矮，因此堆疊中的所有柱子都會被彈出
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 每根柱子被壓入堆疊一次、彈出一次，因此整體只需 O(n) 次操作 |
| Space | O(n) — 堆疊最多儲存 n 個索引 |

## 程式碼

```java
// 輸入：非負整數陣列 heights（每個元素為直方圖中柱子的高度）
// 輸出：以 int 返回直方圖中能形成的最大矩形面積
public int largestRectangleArea(int[] heights) {
    // 以單調遞增方式保存柱子索引的堆疊
    Stack<Integer> stack = new Stack<>();
    // 記錄目前為止找到的最大面積的變數
    int maxArea = 0;

    // 將 i <= heights.length 以包含哨兵的處理
    // 當 i == heights.length 時作為哨兵（高度 0）將堆疊全部彈出
    for (int i = 0; i <= heights.length; i++) {
        // 哨兵：超過陣列末尾時使用高度 0。高度 0 比任何柱子都矮，因此保證堆疊中的所有柱子都會被彈出
        int h = (i == heights.length) ? 0 : heights[i];

        // 當目前高度低於堆疊頂端的柱子時，計算面積
        // 此條件維持堆疊內的單調遞增性
        while (!stack.isEmpty() && h < heights[stack.peek()]) {
            // 將彈出的柱子作為矩形的高度。此柱子的右側邊界為目前位置 i
            int top = stack.pop();

            // 計算寬度：
            // 堆疊為空 → top 的柱子可擴展到最左端（索引 0），寬度為 i
            // 堆疊不為空 → stack.peek() 是位於 top 左側且比 top 矮的柱子的索引（左側邊界），寬度為 i - stack.peek() - 1
            int w = stack.isEmpty() ? i : i - stack.peek() - 1;

            // 計算面積並更新最大值
            maxArea = Math.max(maxArea, heights[top] * w);
        }

        // 將目前索引壓入堆疊以維持單調遞增
        stack.push(i);
    }
    // 所有彈出操作完成時的最大值即為答案
    return maxArea;
}
```
