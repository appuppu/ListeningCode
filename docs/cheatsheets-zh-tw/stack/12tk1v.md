# Checking if Parentheses Are Balanced — 判斷括號字串是否正確配對

## 問題的本質

給定一個僅由 `(`、`)`、`{`、`}`、`[`、`]` 這6種括號組成的字串。判斷所有的開括號是否都有對應的閉括號以**正確的順序**存在，並返回 `true` 或 `false`。

## 核心思路

括號的配對具有「最後開啟的括號最先關閉」的後進先出（LIFO）結構。這個性質正是堆疊的特性，將開括號推入堆疊，當遇到閉括號時與堆疊頂端進行比對，即可驗證括號是否正確配對。

## 思考過程

1. **括號的配對具有順序性**: `([)]` 雖然每種括號的數量相符，但順序不正確。也就是說存在「必須從最內層的括號開始關閉」的規則。這是後進先出（LIFO）的結構，可以用堆疊自然地表達
2. **將開括號推入堆疊**: 從字串的開頭逐字掃描，遇到開括號（`(`、`{`、`[`）時將其 push 到堆疊中。堆疊的頂端始終存放「最近開啟的、尚未關閉的括號」
3. **遇到閉括號時與堆疊頂端進行比對**: 遇到閉括號時，從堆疊 pop 出開括號，確認其是否為對應的種類。若不對應則該字串不合法
4. **堆疊為空時遇到閉括號則不合法**: 在 pop 之前若堆疊為空，表示不存在對應的開括號，因此返回 `false`
5. **掃描完成後堆疊為空則合法**: 處理完所有字元後，若堆疊中仍殘留開括號，表示存在未關閉的括號。若堆疊為空，則所有括號皆正確配對

## 前置知識

### Stack 是什麼

後進先出（LIFO: Last In, First Out）的資料結構。最後添加的元素會最先被取出。適用於像括號配對檢查這樣需要從「最近的元素」開始依序處理的場景。

```java
Stack<Character> stack = new Stack<>();  // 建立空的堆疊
stack.push('(');      // 將 '(' 添加到堆疊頂端
stack.peek();         // 不取出地參照堆疊頂端的元素 → '('
stack.pop();          // 取出並返回堆疊頂端的元素 → '('
stack.isEmpty();      // 以 boolean 返回堆疊是否為空 → true
```

### 括號的對應關係

3種括號各自有開與閉的配對。當遇到閉括號時，需要確認堆疊頂端是否為對應的開括號。

```
')' 對應的開括號是 '('
'}' 對應的開括號是 '{'
']' 對應的開括號是 '['
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需掃描字串一次 |
| Space | O(n) — 堆疊最多儲存 n 個開括號 |

## 程式碼

```java
// 輸入：僅由括號組成的字串 s
// 輸出：若所有括號皆正確配對則返回 true，否則返回 false
public boolean isValid(String s) {
    // 保存「尚未關閉的開括號」的堆疊
    // 堆疊頂端始終存放最近開啟的括號
    Stack<Character> stack = new Stack<>();

    // 從字串開頭逐字掃描。toCharArray() 將字串轉換為 char 陣列
    for (char c : s.toCharArray()) {
        // 若為開括號則推入堆疊。該括號會一直留在堆疊中直到遇到對應的閉括號
        if (c == '(' || c == '{' || c == '[') {
            stack.push(c);
        } else {
            // 遇到閉括號但堆疊為空，表示不存在對應的開括號，因此不合法
            if (stack.isEmpty()) return false;

            // 從堆疊頂端取出「最近開啟的、尚未關閉的括號」
            char top = stack.pop();

            // 若閉括號與開括號的種類不對應則不合法
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
            if (c == ')' && top != '(') return false;
        }
    }

    // 若堆疊為空則所有括號皆正確配對
    // 若堆疊中仍有殘留元素，表示存在未關閉的開括號，因此返回 false
    return stack.isEmpty();
}
```
