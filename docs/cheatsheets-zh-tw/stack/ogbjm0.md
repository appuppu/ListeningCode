# Counting Car Fleets Arriving at a Destination — 求解到達目的地的車隊數量

## 問題的本質

給定整數 `target`（目的地的位置）、整數陣列 `position`（每輛車的目前位置）、整數陣列 `speed`（每輛車的速度）。所有車輛都朝著同一個目的地行駛。當較快的車追上前方較慢的車時，會以較慢車的速度合併為一個車隊（fleet）繼續行駛。請以整數回傳最終到達目的地的**車隊數量**。

## 核心思路

從距離目的地最近的車開始依序處理，用堆疊管理每輛車的「到達目的地所需時間」。若後方車輛的到達時間小於或等於前方車輛，則判定為合併；若大於前方車輛，則判定為新的車隊。最終堆疊的大小即為車隊數量。

## 思考過程

1. **用到達時間判定車隊的成立條件**：後方車輛是否能追上前方車輛，取決於到達目的地的時間。若後方車輛的到達時間小於或等於前方車輛的到達時間，代表途中會追上，因此歸入同一車隊。到達時間可用 `(target - position[i]) / speed[i]` 計算
2. **希望從距離目的地最近的車開始處理**：車隊的合併判定取決於「前方的車（距離目的地較近的車）是否成為阻擋」，因此按照距離目的地由近到遠排序後處理，即可以前方車輛的到達時間為基準，依序判定後方車輛
3. **排序對象為索引**：由於 position 和 speed 是兩個獨立的陣列，因此建立索引陣列，按照 `position` 的降序（距離目的地由近到遠）排序。這樣既不會破壞原始陣列，又能參照對應的 position 和 speed
4. **用堆疊管理車隊**：堆疊頂端存放的是前一個車隊的到達時間（＝該車隊最前方車輛的到達時間）。若新車輛的到達時間小於或等於堆疊頂端，代表該車輛會合併到前方車隊，因此不加入堆疊。若到達時間大於堆疊頂端，代表形成新的車隊，因此將其 push 到堆疊中
5. **堆疊的大小即為答案**：已合併的車輛不會被加入堆疊，只有形成新車隊的車輛才會被 push，因此最終堆疊的元素數量即為車隊數量

## 前置知識

### 到達時間的計算

當車輛的目前位置為 `pos`、速度為 `speed`、目的地為 `target` 時，到達時間為 `(target - pos) / speed`。此值越小代表越早到達。

```
例：target=12, pos=10, speed=2 時
到達時間 = (12 - 10) / 2 = 1.0
```

### Integer[] 的自訂排序

基本型別 `int[]` 無法使用 Lambda 表達式排序，因此建立 `Integer[]` 的索引陣列，並將 Comparator 傳入 `Arrays.sort` 進行排序。

```java
Integer[] idx = new Integer[n];
for (int i = 0; i < n; i++) idx[i] = i;
// 將索引按照 pos 的降序（距離目的地由近到遠）排序
Arrays.sort(idx, (a, b) -> pos[b] - pos[a]);
```

### 什麼是 Stack

Stack 是後進先出（LIFO）的資料結構。使用 `push` 將元素壓入，使用 `peek` 參照最頂端的元素，使用 `pop` 取出元素。在此處，堆疊頂端保存「前一個車隊的到達時間」，作為合併判定的基準。

```java
Stack<Double> stack = new Stack<>();  // 建立空的堆疊
stack.push(3.0);    // 將元素 3.0 壓入堆疊頂端
stack.peek();        // 不取出地參照最頂端的元素 → 3.0
stack.isEmpty();     // 判定堆疊是否為空 → false
stack.size();        // 回傳堆疊中的元素數量 → 1
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n log n) — 索引陣列的排序需要 O(n log n)，之後的遍歷需要 O(n) |
| Space | O(n) — 索引陣列和堆疊各需儲存最多 n 個元素 |

## 程式碼

```java
// 輸入：整數 target（目的地的位置）、整數陣列 pos（每輛車的位置）、整數陣列 speed（每輛車的速度）
// 輸出：以整數回傳到達目的地的車隊數量
public int carFleet(int target, int[] pos, int[] speed) {
    // 取得車輛數量
    int n = pos.length;

    // 建立 Integer[] 型別的索引陣列，以 0 到 n-1 的值初始化
    // 透過排序索引陣列，可以在保留原始陣列的同時改變處理順序
    Integer[] idx = new Integer[n];
    for (int i = 0; i < n; i++) {
        idx[i] = i;
    }

    // 將索引陣列按照 position 的降序（距離目的地由近到遠）排序
    // 從距離目的地最近的車開始處理，使得以前方車輛為基準的合併判定成為可能
    Arrays.sort(idx, (a, b) -> pos[b] - pos[a]);

    // 用於儲存每個車隊到達時間的堆疊
    // 堆疊頂端代表「上一個已確定車隊的到達時間」
    Stack<Double> stack = new Stack<>();

    for (int i : idx) {
        // 計算此車輛到達目的地的時間
        // 若不轉型為 double，會執行整數除法而丟失小數部分
        double time = (double) (target - pos[i]) / speed[i];

        // 若到達時間小於或等於堆疊頂端，代表此車輛會追上前方車隊並合併
        // 使用 continue 跳過加入堆疊的步驟，繼續處理下一輛車
        if (!stack.isEmpty() && time <= stack.peek()) {
            continue;
        }

        // 若堆疊為空，或 time 大於堆疊頂端，代表無法追上前方車隊
        // 形成新的車隊，因此將到達時間壓入堆疊
        stack.push(time);
    }

    // 堆疊中每個車隊的到達時間各佔一個元素，因此堆疊大小等於車隊數量
    return stack.size();
}
```
