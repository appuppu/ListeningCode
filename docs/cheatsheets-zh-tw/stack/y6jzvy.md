# Finding How Many Days Until a Warmer Temperature — 求每日到下一個氣溫上升日的天數

## 問題的本質

給定一個整數陣列 `temperatures`。對於每一天，計算未來第幾天的氣溫會比當天高，並將結果以陣列形式返回。如果未來不存在氣溫更高的日子，則該天的答案為 `0`。

## 核心思路

將索引逐一推入單調遞減堆疊中，堆疊中只會保留「尚未找到比自己更暖日子」的天數。當新的一天的氣溫高於堆疊頂部那天的氣溫時，兩者的索引差即為「等待天數」。

## 思考過程

1. **需要為每一天尋找「下一個氣溫上升的日子」**：直觀的做法是從每一天向右進行線性搜尋，但這樣時間複雜度為 O(n²)。需要一種能高效管理每天「未解決狀態」的機制
2. **想要追蹤「尚未確定答案的日子」**：從左到右掃描陣列時，將尚未找到氣溫更高之未來日子的天數作為「未解決的日子」保留下來，當新的一天到來時即可一次性解決
3. **使用堆疊管理未解決的日子**：將索引推入堆疊中。當新的一天的氣溫高於堆疊頂部那天的氣溫時，該未解決日子的答案即確定。堆疊始終保持氣溫從頂部到底部單調遞減的狀態（較低的氣溫堆在上方）
4. **答案由索引差求得**：當未解決的日子 `j` 被當前的日子 `i` 解決時，等待天數為 `i - j`。將此差值存入結果陣列的第 `j` 個位置
5. **每個元素最多各執行一次 push 和 pop**：每個元素推入堆疊一次，彈出也最多一次，因此包含 while 迴圈在內的整體處理次數為 O(n)

## 前置知識

### Stack（堆疊）是什麼

後進先出（LIFO）的資料結構。最後加入的元素最先被取出。在 Java 中使用 `Stack<Integer>` 類別。

```java
Stack<Integer> stack = new Stack<>();  // 建立空的堆疊
stack.push(5);          // 將 5 推入堆疊頂部
stack.peek();           // 不取出地返回堆疊頂部的元素 → 5
stack.pop();            // 取出並返回堆疊頂部的元素 → 5
stack.isEmpty();        // 以 boolean 返回堆疊是否為空 → true
```

### 單調堆疊（Monotonic Stack）是什麼

一種維持堆疊內元素始終保持單調遞增或單調遞減順序的堆疊。本題使用**單調遞減堆疊**。在加入新元素之前，將所有破壞堆疊順序的元素全部彈出，以此維持單調性。適用於「尋找下一個更大（更小）元素」的模式。

```java
// 單調遞減堆疊的基本模式
// 堆疊內的氣溫從底部到頂部遞減
// 例：堆疊底[75, 71, 69]頂 ← 氣溫遞減
// 當 72 進來時，彈出 69 和 71 並解決，堆疊變為 [75, 72]
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 每個元素最多各執行一次 push 和 pop，因此整體為 O(n) |
| Space | O(n) — 堆疊最多儲存 n 個索引 |

## 程式碼

```java
// 輸入：整數陣列 temperatures（每日的氣溫）
// 輸出：返回儲存每日到下一個氣溫上升日天數的 int[]
public int[] dailyTemperatures(int[] temperatures) {
    // 建立結果陣列（在 Java 中 int[] 的初始值為 0，因此未來沒有更暖日子時的答案 0 已預設設定）
    int[] result = new int[temperatures.length];
    // 儲存尚未找到更暖日子之索引的堆疊
    // 儲存索引而非氣溫值的原因：計算等待天數需要索引差，且可透過 temperatures[index] 從索引查詢氣溫
    Stack<Integer> indexStack = new Stack<>();

    // 從索引 i = 0 到陣列末尾逐一掃描
    for (int i = 0; i < temperatures.length; i++) {
        // 當目前氣溫高於堆疊頂部那天的氣溫時，解決未解決的日子
        // 條件：堆疊不為空 且 目前氣溫 > 堆疊頂部索引所指向的氣溫
        while (!indexStack.isEmpty() && temperatures[i] > temperatures[indexStack.peek()]) {
            // 取出堆疊頂部的索引
            int stackTopIndex = indexStack.pop();
            // 等待天數 = 目前索引 - 等待中日子的索引
            result[stackTopIndex] = i - stackTopIndex;
        }
        // while 迴圈結束後（堆疊為空，或堆疊頂部的氣溫大於等於目前氣溫），將目前索引推入堆疊
        // 此時堆疊內維持著單調遞減的順序
        indexStack.push(i);
    }

    // 堆疊中剩餘的索引是「未來不存在更暖日子的天數」
    // 這些日子的結果維持初始值 0，因此不需要額外處理
    return result;
}
```
