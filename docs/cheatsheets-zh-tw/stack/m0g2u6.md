# Designing a Stack That Tracks the Minimum — 設計一個所有操作皆為O(1)且能取得最小值的堆疊

## 問題的本質

設計一個堆疊，使其能以O(1)執行`push`、`pop`、`top`、`getMin`（取得當前最小值）這四種操作。一般的堆疊取得最小值需要O(n)的時間，因此需要特別的設計。

## 核心思路

若將「該時間點的最小值」與堆疊的每個元素一起保存，即使元素被pop移除，最小值的資訊也不會遺失。`getMin()`只需查看堆疊頂端的元素，即可在O(1)內得到答案。

## 思考過程

1. **要使getMin達到O(1)，必須隨時掌握最小值**：考慮用一個變數來管理最小值，但當pop移除了最小值時，便無法得知下一個最小值。也就是說，需要一個保持最小值「歷史紀錄」的機制
2. **最小值的歷史紀錄與堆疊的狀態是連動的**：每當堆疊中加入元素，最小值可能會改變。反之，當元素被pop移除時，最小值會恢復為push之前的值。這種「恢復到push之前狀態」的性質，與堆疊本身的性質相同
3. **將每個元素與該時間點的最小值配對保存**：push時，將新值與當前最小值進行比較，將較小的一方作為「該時間點的最小值」，與新值一起保存。這樣即使pop移除了元素，下一個頂端元素仍持有正確的最小值
4. **決定配對的結構**：使用`int[]`陣列，`[0]`保存值，`[1]`保存該時間點的最小值。堆疊的型別為`Stack<int[]>`
5. **push時最小值的計算方法**：若堆疊為空，則新值直接作為最小值。若不為空，則將新值與堆疊頂端的最小值（`stack.peek()[1]`）進行比較，採用較小的一方
6. **top、getMin、pop的實作**：`top()`回傳頂端配對的`[0]`，`getMin()`回傳頂端配對的`[1]`，皆為O(1)。`pop()`只需如同一般堆疊移除頂端元素即可

## 前備知識

### Stack 是什麼

後進先出（LIFO）的資料結構。最後加入的元素會最先被取出。在Java中使用Generics來指定儲存的型別。

```java
Stack<int[]> stack = new Stack<>();  // 建立一個儲存int陣列的堆疊
stack.push(new int[]{1, 1});         // 將元素加入頂端
stack.peek();                         // 不移除地參照頂端元素 → [1, 1]
stack.pop();                          // 取出並回傳頂端元素 → [1, 1]
stack.isEmpty();                      // 以boolean回傳堆疊是否為空 → true
```

### Math.min 是什麼

接收兩個整數並回傳較小值的方法。每次push時用來比較新值與當前最小值。

```java
Math.min(3, 5);   // → 3
Math.min(-1, 0);  // → -1
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(1) — push、pop、top、getMin的所有操作皆在常數時間內完成 |
| Space | O(n) — 堆疊中最多保存n個配對 |

## 程式碼

```java
// 輸入：push(val)、pop()、top()、getMin() 的操作序列
// 輸出：top() 回傳頂端的值。getMin() 回傳當前堆疊中的最小值
class MinStack {

    // Stack<int[]> 型別的欄位。每個元素是長度為2的陣列，[0] 保存值，[1] 保存該時間點整個堆疊的最小值
    private Stack<int[]> stack;

    public MinStack() {
        stack = new Stack<>();
    }

    public void push(int val) {
        // 若堆疊為空，則val本身即為最小值。若不為空，則與頂端記錄的最小值進行比較，採用較小的一方
        int min = stack.isEmpty() ? val : Math.min(val, stack.peek()[1]);
        // push值與最小值的配對 new int[]{val, min}。只要該元素位於頂端，min就是正確的最小值
        stack.push(new int[]{val, min});
    }

    public void pop() {
        // 移除頂端的配對。移除後新的頂端配對的 [1] 保存著該元素被push時的正確最小值，因此最小值的一致性會自動維持
        stack.pop();
    }

    public int top() {
        // 配對的 [0] 保存著值本身
        return stack.peek()[0];
    }

    public int getMin() {
        // 配對的 [1] 保存著該時間點的最小值，因此不需要遍歷
        return stack.peek()[1];
    }
}
```
