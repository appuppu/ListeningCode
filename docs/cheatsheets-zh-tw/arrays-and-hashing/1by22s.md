# Finding the Longest Consecutive Number Sequence — 從未排序的陣列中求出最長連續整數序列的長度

## 問題的本質

系統給定一個整數陣列 `nums`（未排序）。你需要從陣列中找出連續的整數序列（例如：1,2,3,4），並返回其**最長的長度**。元素的排列順序無關緊要，只要數值上是連續的即可。

## 核心思路

只從連續序列的「起點」開始計算長度，就能排除多餘的重複計算。對於某個數 `num`，如果 `num - 1` 不存在於 HashSet 中，則該數就是連續序列的起點。僅從起點開始計數，整體即可達到 O(n) 的時間複雜度。

## 思考過程

1. **找出連續序列的起點**：如果從連續序列中間的數開始計數，同一個序列會被重複計算多次。只有 `num - 1` 不存在的數才是連續序列的真正起點。僅從起點開始計數，每個元素最多只會被計算一次
2. **快速進行存在性判定**：為了以 O(1) 的時間判定某個數是否存在於陣列中，將所有元素存入 HashSet。雖然排序可以用 O(n log n) 解決問題，但使用 HashSet 只需 O(n)
3. **從起點開始逐一計算連續數**：找到起點 `num` 後，依序確認 `num + 1`、`num + 2`、... 是否存在於 HashSet 中，計算直到連續中斷為止的長度
4. **追蹤最長長度**：將每個連續序列的長度與變數 `longest` 進行比較，如果更長則更新。處理完所有元素後的 `longest` 即為答案

## 前置知識

### 什麼是 HashSet

HashSet 是一種不允許重複值的資料結構。它能以 O(1) 的時間完成值的新增和存在性判定。與 HashMap 不同，HashSet 只儲存鍵，適用於需要快速判定某個值「是否存在」的場景。

```java
HashSet<Integer> set = new HashSet<>();  // 建立一個空的 HashSet
set.add(4);              // 將值 4 加入集合中
set.add(4);              // 重複值會被忽略（集合的元素數量不會改變）
set.contains(4);         // 判定值 4 是否存在，返回 boolean → true
set.contains(5);         // 判定值 5 是否存在，返回 boolean → false
```

### 什麼是連續序列的起點

對於某個數 `num`，當 `num - 1` 不存在於集合中時，`num` 就是連續序列的第一個數（起點）。
例如：集合={100, 4, 200, 1, 3, 2} 時，1 是起點（0 不存在），2 不是起點（1 存在）。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 每個元素在起點判定時被存取一次，在計數時最多被存取一次，共計最多兩次 |
| Space | O(n) — HashSet 最多儲存 n 個元素 |

## 程式碼

```java
// 輸入：整數陣列 nums（未排序，可能包含重複值）
// 輸出：以 int 返回最長連續整數序列的長度
public int longestConsecutive(int[] nums) {
    // 將所有元素存入 HashSet，使存在性判定可在 O(1) 內完成
    // 重複元素會被自動排除
    Set<Integer> numSet = new HashSet<>();
    for (int num : nums) {
        numSet.add(num);
    }

    // 用於保存目前找到的最長連續序列長度的變數
    int longest = 0;

    // 遍歷 HashSet 中的每個元素
    for (int num : numSet) {
        // 如果 num - 1 不存在，則 num 是連續序列的起點
        // 如果 num - 1 存在，則 num 是連續序列中間的數，予以跳過
        //（該數會在從其他起點開始計數時被計算到）
        if (!numSet.contains(num - 1)) {
            int currentNum = num;
            int length = 1;

            // 從起點開始依序計算連續的數（num+1, num+2, ...）
            // 持續迴圈直到連續中斷為止
            while (numSet.contains(currentNum + 1)) {
                currentNum++;
                length++;
            }

            // 如果當前連續序列的長度超過目前的最長紀錄，則進行更新
            longest = Math.max(longest, length);
        }
    }
    // 遍歷所有元素完成後，返回最長連續整數序列的長度
    return longest;
}
```
