# Checking if Two Strings Are Anagrams — 判斷兩個字串是否為彼此的字母重排

## 問題的本質

給定兩個字串 `s` 和 `t`。判斷 `t` 是否為 `s` 的 Anagram，並以 **boolean** 回傳結果。所謂 Anagram，是指兩個字串包含完全相同的字元且每個字元的出現次數也相同，僅排列順序不同的關係。

## 核心思路

判斷是否為 Anagram，可以歸結為「每個字元的出現次數是否完全一致」。由於小寫英文字母只有 26 種，使用固定長度為 26 的陣列來管理所有字元的出現次數，即可在 O(1) 的空間和 O(n) 的時間內完成判斷。

## 思考過程

1. **以數學方式理解 Anagram 的定義**：兩個字串互為 Anagram，意味著每個字元的出現頻率完全一致。換言之，只需忽略字元的順序，僅比較頻率即可
2. **長度不同則立即回傳 false**：Anagram 包含相同的字元且出現次數相同，因此當字串長度不同時，不可能是 Anagram。先行判斷此條件可以避免不必要的處理
3. **思考頻率的比較方法**：小寫英文字母限定為 'a' 到 'z' 共 26 種。不使用 HashMap，而是使用大小為 26 的固定長度 int 陣列，即可透過索引管理每個字元的出現次數
4. **用一個陣列處理兩個字串**：不必建立兩個陣列再進行比較，而是對一個陣列，針對一個字串進行遞增、另一個字串進行遞減。最終若所有元素皆為 0，則表示頻率完全一致
5. **在同一個迴圈內處理兩個字串**：由於已事先確認字串長度相等，因此可以在一個 for 迴圈內同時對 `s` 進行遞增和對 `t` 進行遞減
6. **最終判斷**：迴圈結束後，確認陣列的所有元素是否皆為 0。只要有一個元素不為 0，就表示某個字元的出現次數不一致，回傳 false

## 前提知識

### 將字元轉換為陣列索引

透過 `char - 'a'` 運算，可以將小寫英文字母轉換為 0 到 25 的整數。藉此可以直接將字元作為陣列的索引使用。

```java
char c = 'd';
int index = c - 'a';    // 'd' - 'a' = 3（'a'=0, 'b'=1, 'c'=2, 'd'=3）
int[] count = new int[26];
count[c - 'a']++;       // count[3] 變為 1（記錄 'd' 的出現次數）
```

### 使用固定長度陣列進行頻率計數

準備一個大小為 26 的 int 陣列，每個索引對應一個字元，即可作為頻率表使用。在 Java 中，`new int[26]` 會將所有元素初始化為 0。

```java
int[] count = new int[26];  // 所有元素初始化為 0
count['b' - 'a']++;        // count[1] = 1（記錄 'b' 的出現）
count['b' - 'a']--;        // count[1] = 0（抵消 'b' 的出現）
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需遍歷字串一次即可完成（n 為字串的長度） |
| Space | O(1) — 使用的陣列大小固定為 26，不隨輸入長度而變化 |

## 程式碼

```java
// 輸入：兩個字串 s 和 t
// 輸出：若 t 是 s 的 Anagram 則回傳 true，否則回傳 false
public boolean isAnagram(String s, String t) {
    // Anagram 包含相同字元且出現次數相同，因此長度不同時不可能是 Anagram
    if (s.length() != t.length())
        return false;

    // 記錄每個字母出現次數「差值」的陣列（索引 0='a', 25='z'）
    // 大小 26 對應 a～z 的 26 個字母
    int[] count = new int[26];

    // 在一個迴圈內同時處理兩個字串（已事先確認長度相等）
    for (int i = 0; i < s.length(); i++) {
        // 對 s 的字元進行遞增：記錄「s 中該字元出現了 1 次」
        count[s.charAt(i) - 'a']++;
        // 對 t 的字元進行遞減：記錄「t 中該字元出現了 1 次」
        // 若遞增和遞減互相抵消，則表示該字元在 s 和 t 中的出現次數相等
        count[t.charAt(i) - 'a']--;
    }

    // 遍歷全部 26 個元素，只要有一個元素不為 0，則表示出現次數不一致
    for (int c : count) {
        if (c != 0) return false;
    }
    // 所有元素皆為 0 → 所有字元的出現次數一致 → 是 Anagram
    return true;
}
```
