# Computing Products Without Self Inclusion — 計算排除自身的所有元素之積

## 問題的本質

給定一個整數陣列 `nums`。對於每個索引 `i`，計算除了 `nums[i]` **以外**所有元素的積，並返回儲存結果的陣列 `result`。不得使用除法運算子。

## 核心思路

排除某個元素後的所有元素之積，可以分解為「該元素左側所有元素的積」×「該元素右側所有元素的積」。透過正向和反向兩次遍歷來構建左右兩側的累積積，即可在不使用除法的情況下以 O(n) 求解。

## 思考過程

1. **由於不能使用除法，需要思考其他分解方式**: 先求所有元素的積再除以各元素的方法是被禁止的。因此，將 `result[i]` 分解為「`nums[i]` 左側的積」×「`nums[i]` 右側的積」。這種分解方式不需要除法
2. **左側的累積積可以透過正向遍歷來構建**: 從左到右遍歷陣列，計算每個位置「自身左側所有元素的積」。遞推公式為 `result[i] = result[i-1] * nums[i-1]`。由於第一個元素的左側沒有任何元素，因此以 `result[0] = 1`（積的單位元）進行初始化
3. **右側的累積積可以透過反向遍歷來構建**: 從右到左遍歷陣列，將「自身右側所有元素的積」累積到變數 `record` 中。由於最後一個元素的右側沒有任何元素，因此以 `record = 1` 進行初始化
4. **將兩側的積相乘**: 在反向遍歷過程中，將 `result[i]`（左側的積）乘以 `record`（右側的積），即可得到最終答案。相乘之後，透過 `record = record * nums[i]` 更新右側的積
5. **不需要使用額外的陣列**: 由於左側的積直接寫入 `result` 陣列，右側的積僅用一個變數來管理，因此除了輸出陣列之外，額外的記憶體開銷為 O(1)

## 前置知識

### 累積積（Prefix Product / Suffix Product）

從陣列的開頭或末尾依序將元素相乘所得到的積的序列。它相當於累積和的乘法版本。可以高效地求出每個位置「到該位置為止所有元素的積」。

```java
int[] nums = {1, 2, 3, 4};

// 從左側開始的累積積（prefix product）
// prefix[0] = 1（左側沒有元素）
// prefix[1] = 1（到 nums[0] 為止）
// prefix[2] = 1*2 = 2（到 nums[1] 為止）
// prefix[3] = 1*2*3 = 6（到 nums[2] 為止）

// 從右側開始的累積積（suffix product）
// suffix[3] = 1（右側沒有元素）
// suffix[2] = 4（到 nums[3] 為止）
// suffix[1] = 4*3 = 12（nums[3]*nums[2]）
// suffix[0] = 4*3*2 = 24（nums[3]*nums[2]*nums[1]）
```

### 積的單位元

任何數乘以 1，其值都不會改變。將 1 作為累積積的初始值，即可對第一個元素也套用相同的遞推公式。

```java
int record = 1;              // 積的初始值為 1（單位元）
record = record * nums[i];   // 第一次相乘時 record = nums[i]
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需對陣列進行正向和反向各一次遍歷 |
| Space | O(1) — 除了輸出陣列 `result` 之外，額外使用的記憶體僅有變數 `record` |

## 程式碼

```java
// 輸入: 整數陣列 nums
// 輸出: 返回一個 int[]，其中每個索引儲存除自身以外所有元素的積
public int[] productExceptSelf(int[] nums) {
    // 建立與 nums 相同長度的陣列。先儲存左側的累積積，之後再乘以右側的累積積
    int[] result = new int[nums.length];

    // 正向遍歷：將每個位置左側所有元素的積儲存到 result 中
    result[0] = 1;  // 第一個元素的左側沒有任何元素，因此以積的單位元 1 進行初始化
    for (int i = 1; i < nums.length; i++) {
        // result[i-1] 是位置 i-1 的左側積。將其乘以 nums[i-1]（左邊一個元素）即可得到位置 i 的左側積
        result[i] = result[i - 1] * nums[i - 1];
    }

    // 反向遍歷：乘以右側的累積積以完成最終結果
    // record 是用來累積「當前位置右側所有元素的積」的變數
    int record = 1;  // 最後一個元素的右側沒有任何元素，因此以 1 進行初始化
    for (int i = nums.length - 1; i >= 0; i--) {
        // result[i] 中已儲存左側的積。將其乘以 record（右側的積）即可完成「除自身以外所有元素的積」
        result[i] = record * result[i];
        // 注意: record 的更新必須在 result[i] 確定之後進行。若先更新，nums[i] 本身將被包含在積中
        record = record * nums[i];
    }

    // 返回每個元素都儲存了「除自身以外所有元素的積」的 result
    return result;
}
```
