# Grouping Words by Anagram Patterns — 將互為字母重組的單詞分組歸類

## 問題的本質

給定一個字串陣列 `strs`。將互為字母重組（Anagram）的字串歸為同一組，並以群組列表的形式返回。兩個字串互為字母重組，是指它們包含相同的字母且每個字母出現的次數相同，僅排列順序不同。

## 核心思路

互為字母重組的字串，其「每個字母的出現次數」完全相同。將26個字母各自的出現次數計算後轉換為字串作為鍵，互為字母重組的字串必定產生相同的鍵，因此可以用 HashMap 一次性完成分組。

## 思考過程

1. **找出字母重組的共同性質**：互為字母重組的字串僅排列順序不同，各字母的出現次數完全一致。可以利用這個「出現次數一致」的特性作為分組的判斷標準
2. **如何表示出現次數**：英文小寫字母共26種，因此準備一個大小為26的整數陣列 `count`，統計每個字母的出現次數。若兩個陣列的內容相同，則對應的單詞互為字母重組
3. **將陣列作為 HashMap 鍵的方法**：在 Java 中無法直接將陣列作為 HashMap 的鍵（因為會進行參照比較）。因此，將陣列的每個元素用 `#` 分隔並串接成字串（例如：`"1#0#0#...#"`）作為鍵。這樣一來，出現次數相同的單詞會產生相同的字串鍵
4. **使用 HashMap 進行分組**：鍵相同的單詞放入同一個列表即可。使用 `computeIfAbsent` 方法，當鍵尚未註冊時自動建立新列表，當鍵已註冊時直接返回該列表，無需條件分支即可新增單詞
5. **最終返回的結果**：將 HashMap 的所有值（各群組的列表）轉換為 `ArrayList` 後返回

## 前置知識

### HashMap 是什麼

HashMap 是一種儲存鍵值對的資料結構。透過指定鍵即可以 O(1) 的時間複雜度進行搜尋和取得值。如同以陣列索引存取的速度，使用任意鍵進行存取的字典。

```java
HashMap<String, List<String>> map = new HashMap<>();  // 建立空的 HashMap
map.put("key", new ArrayList<>());  // 在鍵 "key" 中儲存空列表
map.containsKey("key");             // 檢查鍵 "key" 是否存在，返回 boolean → true
map.get("key");                     // 返回鍵 "key" 對應的值 → []
map.values();                       // 以 Collection 的形式返回所有的值
```

### computeIfAbsent 是什麼

computeIfAbsent 是 HashMap 的方法。若指定的鍵不存在，則透過第二個參數的 Lambda 表達式生成值並註冊，然後返回該值。若鍵已存在，則直接返回現有的值。可以用一行程式碼完成依據鍵是否存在的條件分支。

```java
// 若鍵 "abc" 尚未註冊，則建立新的 ArrayList 並註冊，然後返回該列表
// 若鍵 "abc" 已註冊，則直接返回現有的列表
map.computeIfAbsent("abc", k -> new ArrayList<>()).add("cab");
```

### 字母出現次數的計數方式

將 `char` 型別的字母減去 `'a'`，即可轉換為 a=0, b=1, ..., z=25 的索引。準備一個大小為26的陣列，在對應索引的位置進行遞增，即可記錄每個字母的出現次數。

```java
int[] count = new int[26];           // 建立26個字母的計數陣列（初始值全部為0）
for (char c : "eat".toCharArray())   // 逐字走訪字串
    count[c - 'a']++;                // 將對應字母位置的計數遞增
// 結果: count[0]=1(a), count[4]=1(e), count[19]=1(t), 其餘為0
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n × k) — n 為字串的個數，k 為字串的平均長度。對每個字串進行字母計數及大小為26的鍵生成 |
| Space | O(n × k) — HashMap 中儲存所有字串，每個鍵為固定長度，但字串本身佔用 k 個字元的記憶體 |

## 程式碼

```java
// 輸入：字串陣列 strs
// 輸出：返回將互為字母重組的字串分組後的 List<List<String>>
public List<List<String>> groupAnagrams(String[] strs) {
    // 鍵=出現次數的字串表示，值=屬於該鍵的單詞列表，儲存於 HashMap 中
    // 擁有相同鍵的單詞互為字母重組
    Map<String, List<String>> map = new HashMap<>();

    // 從頭到尾逐一走訪陣列 strs 中的每個字串 s
    for (String s : strs) {
        // 建立大小為26的陣列，用於記錄每個字母（a〜z）的出現次數（初始值全部為0）
        // 每個字串都建立新的陣列，是為了避免前一個字串的計數結果殘留
        int[] count = new int[26];
        // 使用 toCharArray() 轉換為字元陣列，對每個字元 c 統計出現次數
        for (char c : s.toCharArray())
            // 透過 c - 'a' 將字元 c 轉換為索引 0〜25 並遞增
            count[c - 'a']++;

        // 將出現次數陣列轉換為 "1#0#0#..." 格式的字串鍵
        // 此鍵唯一地表示字母的出現次數，互為字母重組的字串必定產生相同的鍵
        // 在每個元素之間插入分隔符 #，以避免不同的計數產生相同的字串
        StringBuilder sb = new StringBuilder();
        for (int n : count)
            sb.append(n).append('#');
        String key = sb.toString();

        // 若鍵尚未註冊則建立新列表，並將當前字串新增至列表中
        // 如此一來，擁有相同鍵的單詞會被累積到同一個列表中
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }

    // 取得所有群組的集合，轉換為 List<List<String>> 後返回
    return new ArrayList<>(map.values());
}
```
