# Finding the Minimum Removals for Non-Overlapping Intervals — 求使區間不重疊所需移除的最少區間數

## 問題的本質

給定一個區間陣列 `intervals`（每個區間為 `[start, end]` 的配對）。請返回**需要移除的最少區間數**，使得剩餘的區間彼此不重疊。

## 核心思路

將區間按結束時間排序，優先保留結束時間較早的區間，這樣與後續區間重疊的可能性最小。當發生重疊時，移除結束時間較晚的一方（即當前區間），即可將移除數量最小化。

## 思考過程

1. **要減少重疊，應優先保留「佔用空間較少」的區間**：結束時間越早的區間，後方剩餘的空閒空間越多，越不容易與後續區間重疊。因此，將區間按結束時間升序排序，並按結束時間由早到晚貪心地選取，是最優策略
2. **排序後，只需追蹤上一個保留區間的結束時間**：由於已按結束時間排序，只需記住已保留區間中最後一個的結束時間 `lastEnd`，即可判斷下一個區間是否重疊。若下一個區間的開始時間小於 `lastEnd`，則存在重疊
3. **發生重疊時，移除當前區間**：當發生重疊時，應移除上一個保留的區間還是當前區間？由於已按結束時間排序，當前區間的結束時間必定大於或等於上一個區間的結束時間。移除結束時間較晚的當前區間，對後續的影響較小。因此將 `removals` 遞增，且不更新 `lastEnd`
4. **未發生重疊時，保留當前區間**：若當前區間的開始時間大於或等於 `lastEnd`，則不存在重疊，因此保留該區間，並將 `lastEnd` 更新為當前區間的結束時間
5. **最終返回值**：迴圈結束後，返回 `removals`（被移除的區間數量）

## 前置知識

### Arrays.sort 的自訂比較器

透過在 `Arrays.sort` 的第二個參數傳入 Lambda 表達式，可以自訂排序基準。`(a, b) -> a[1] - b[1]` 表示以每個區間的結束時間（索引 1 的元素）為基準進行升序排序。

```java
int[][] intervals = {{1,3}, {2,4}, {0,2}};
Arrays.sort(intervals, (a, b) -> a[1] - b[1]);
// 結果: {{0,2}, {1,3}, {2,4}} — 按結束時間由早到晚排列
```

### 貪心法（Greedy）

在每一步選擇「當前最優的選項」，從而推導出整體最優解的方法。在本題中，「優先保留結束時間最早的區間」這一局部選擇，能使整體移除數量達到最小化。

```java
// 貪心法的典型模式：先排序，再從頭開始依序做最優選擇
Arrays.sort(data, comparator);  // 按基準排序
for (int i = 0; i < data.length; i++) {
    // 若滿足條件則選擇，不滿足則跳過
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n log n) — 排序需要 O(n log n)，遍歷需要 O(n)，排序為主導項 |
| Space | O(1) — 除排序的內部空間外，不使用額外的資料結構 |

## 程式碼

```java
// 輸入：區間陣列 int[][] intervals（每個元素為 [start, end]）
// 輸出：以 int 返回使區間不重疊所需移除的最少區間數
int eraseOverlapIntervals(int[][] intervals) {
    // 若區間數量為 0，則無需移除
    if (intervals.length == 0)
        return 0;

    // 按結束時間升序排序（為了優先保留結束時間較早的區間）
    // 貪心法：結束時間越早的區間越不容易與後續重疊，因此先保留是最優策略
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);

    // 記錄已移除區間數量的變數
    int removals = 0;
    // 排序後的第一個區間一定保留（因為其結束時間最早）。記錄其結束時間
    int lastEnd = intervals[0][1];

    // 從索引 1 開始遍歷（第 0 個已確定為保留的區間）
    for (int i = 1; i < intervals.length; i++) {
        // 若當前區間的開始時間小於 lastEnd，則與上一個保留的區間重疊
        if (intervals[i][0] < lastEnd) {
            // 移除當前區間。由於已按結束時間排序，當前區間的結束時間必定大於或等於 lastEnd，
            // 移除結束時間較晚的當前區間能減少與後續區間的重疊。不更新 lastEnd
            removals++;
        } else {
            // 不重疊，因此保留當前區間，並將 lastEnd 更新為當前區間的結束時間
            // 與下一個區間的重疊判斷將以這個新的 lastEnd 為基準
            lastEnd = intervals[i][1];
        }
    }
    // removals 即為使區間不重疊所需移除的最少區間數
    return removals;
}
```
