# 判斷是否能出席所有會議 — Determining if All Meetings Can Be Attended

## 問題的本質

給定一個表示會議時間段的區間陣列 `intervals`（每個元素為開始時間與結束時間的配對）。需要判斷一個人是否能**出席所有會議**，並以 `boolean` 回傳結果。若某場會議在另一場會議結束前就開始，則這兩場會議互相衝突（重疊），因此無法全部出席。

## 核心思路

將區間按開始時間排序後，重疊只可能發生在相鄰的區間之間。依序比較相鄰的配對，只需確認下一個區間的開始時間是否早於前一個區間的結束時間，即可完成整體的重疊判定。

## 思考過程

1. **整理重疊的條件**：兩個區間重疊，意味著其中一個區間的開始時間早於另一個區間的結束時間。然而，若區間的順序是雜亂的，則需要比較所有配對，時間複雜度為 O(n²)
2. **透過排序限定比較對象**：將區間按開始時間升序排序後，重疊只會發生在相鄰的區間之間。原因在於，若 `intervals[i]` 與 `intervals[i+2]` 重疊，則 `intervals[i]` 與 `intervals[i+1]` 必定也重疊
3. **相鄰配對的重疊判定**：排序後，若 `intervals[i]` 的開始時間早於 `intervals[i-1]` 的結束時間，則這兩場會議重疊。此條件可表示為 `intervals[i][0] < intervals[i-1][1]`
4. **只要存在一組重疊即可立即得出結果**：只要找到一組重疊，就代表無法出席所有會議，因此回傳 `false`。若確認所有相鄰配對都沒有重疊，則回傳 `true`

## 前置知識

### Arrays.sort 與自訂 Comparator

`Arrays.sort` 是用於排序陣列的方法。對於二維陣列，可以透過 Lambda 運算式指定 Comparator（比較函式），控制以哪個元素作為排序基準。

```java
int[][] intervals = {{7, 10}, {2, 4}, {5, 8}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 按各區間的開始時間（[0]）升序排序
// 結果: {{2, 4}, {5, 8}, {7, 10}}
```

`(a, b) -> a[0] - b[0]` 接收兩個區間 `a` 和 `b`，回傳開始時間的差值。差值為負則 `a` 排在前面，為正則 `b` 排在前面。

### 區間的重疊判定

當兩個區間已按開始時間排序時，若後一個區間的開始時間早於前一個區間的結束時間，則兩者重疊。

```java
int[] prev = {2, 4};   // 2點～4點的會議
int[] curr = {3, 6};   // 3點～6點的會議
curr[0] < prev[1];     // 3 < 4 → true → 存在重疊
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n log n) — 排序為 O(n log n)，相鄰配對的遍歷為 O(n)，排序為主導項 |
| Space | O(1) — 排序直接在輸入陣列上進行，不使用額外的陣列 |

## 程式碼

```java
// 輸入：表示會議時間段的二維整數陣列 intervals（每個元素為 [開始時間, 結束時間]）
// 輸出：若能出席所有會議則回傳 true，若存在重疊的會議則回傳 false
public boolean canAttendMeetings(int[][] intervals) {
    // 按開始時間升序排序區間
    // 將 Lambda 運算式 (a, b) -> a[0] - b[0] 作為 Comparator 傳入
    // 如此一來，對於按時間順序排列的區間，只需比較相鄰配對即可
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // 從 i = 1 而非 i = 0 開始。因為每一步都要比較 intervals[i] 與 intervals[i-1] 的相鄰配對
    for (int i = 1; i < intervals.length; i++) {
        // 若當前會議的開始時間早於前一場會議的結束時間，則存在重疊
        if (intervals[i][0] < intervals[i - 1][1]) {
            // 只要存在一組重疊，就無法出席所有會議，因此立即回傳 false
            return false;
        }
        // 若無重疊，則繼續檢查下一組相鄰配對
    }
    // 若迴圈完整執行完畢，代表所有相鄰配對都沒有重疊，因此回傳 true
    return true;
}
```
