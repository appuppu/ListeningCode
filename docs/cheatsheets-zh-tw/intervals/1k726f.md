# Merging Overlapping Intervals — 合併所有重疊的區間

## 問題的本質

給定一個區間（起始值與結束值的配對）陣列 `intervals`。將所有重疊的區間進行合併（merge），並返回一個不重疊的區間列表。

## 核心思路

將區間按起始值排序後，可能重疊的區間僅限於相鄰的區間。排序後從前往後依序掃描，若當前區間與前一個區間重疊，則更新結束值；若未重疊，則將其作為新的區間添加。

## 思考過程

1. **簡化重疊的判定**：若區間未經排序，則需要比較所有配對。按起始值升序排序後，重疊的判定條件僅需「前一個區間的結束值 ≥ 當前區間的起始值」即可
2. **排序後只需一次掃描即可完成合併**：從頭開始依序檢視排序後的區間。將結果列表末尾的區間與當前區間進行比較，若重疊則將結束值更新為較大的一方。若未重疊，則直接將當前區間添加到結果列表中
3. **需要存取結果列表的末尾元素**：合併的判定始終需要參考結果列表中「最後添加的區間」的結束值。使用 LinkedList 可透過 `getLast()` 以 O(1) 存取末尾元素
4. **精確定義重疊的條件**：當前一個區間的結束值小於當前區間的起始值（`res.getLast()[1] < interval[0]`）時，兩個區間不重疊。其餘情況（結束值 ≥ 起始值）表示重疊，需要進行合併
5. **合併時只需更新結束值**：由於起始值已排序，前一個區間的起始值必定小於或等於當前區間的起始值。結束值則取兩個區間中較大的一方。使用 `Math.max()` 比較前一個結束值與當前結束值
6. **最終返回的結果**：將結果列表中累積的所有非重疊區間轉換為 `int[][]` 二維陣列後返回

## 前置知識

### Arrays.sort 與自訂 Comparator

`Arrays.sort` 是對陣列進行排序的方法。對於二維陣列，可透過 Lambda 表達式指定 Comparator，定義以哪個元素作為排序基準。

```java
int[][] intervals = {{3, 6}, {1, 3}, {2, 5}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 按各區間的起始值（index 0）升序排序
// 結果: {{1, 3}, {2, 5}, {3, 6}}
```

### 什麼是 LinkedList

LinkedList 是一種可以在 O(1) 時間內對首尾進行添加及取得末尾元素的列表。與 ArrayList 不同，LinkedList 可透過 `getLast()` 方法直接存取末尾元素。

```java
LinkedList<int[]> res = new LinkedList<>();  // 建立空的 LinkedList
res.add(new int[]{1, 3});   // 在末尾添加元素
res.getLast();               // 取得末尾元素 → {1, 3}
res.getLast()[1] = 5;        // 直接修改末尾元素的結束值 → {1, 5}
res.isEmpty();               // 返回列表是否為空的布林值 → false
res.size();                  // 返回列表的元素數量 → 1
```

### 什麼是 Math.max

Math.max 是返回兩個值中較大者的方法。在區間合併中，用於取兩個結束值中較大的一方。

```java
Math.max(5, 8);   // → 8
Math.max(10, 3);  // → 10
```

## 複雜度

| | 值 |
|---|---|
| Time | O(n log n) — 排序為 O(n log n)，掃描為 O(n)，因此整體為 O(n log n) |
| Space | O(n) — 結果列表最多儲存 n 個區間 |

## 程式碼

```java
// 輸入：區間的二維陣列 int[][] intervals（每個元素為 [起始值, 結束值]）
// 輸出：返回合併重疊區間後的二維陣列 int[][]
public int[][] merge(int[][] intervals) {
    // 透過排序，將重疊的判定限制為僅比較相鄰的區間
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // 用於累積已合併區間的結果列表
    // 使用 LinkedList 的原因是可以以 O(1) 參考及更新末尾元素
    LinkedList<int[]> res = new LinkedList<>();

    for (int[] interval : intervals) {
        // 若 res 為空，則為第一個區間，無條件添加
        // 若 res.getLast()[1] < interval[0]，則與前一個區間不重疊，直接添加
        if (res.isEmpty() || res.getLast()[1] < interval[0]) {
            res.add(interval);
        } else {
            // 若重疊，則將結束值更新為較大的一方以完成合併
            // 由於起始值已排序，前一個區間的起始值必定小於或等於當前區間，因此無需變更
            res.getLast()[1] = Math.max(res.getLast()[1], interval[1]);
        }
    }

    // 將結果列表轉換為二維陣列後返回
    return res.toArray(new int[res.size()][]);
}
```
