# Finding the Minimum Meeting Rooms Required — 求出所有會議在不衝突的情況下所需的最少會議室數量

## 問題的本質

給定一個會議時間段（開始時刻與結束時刻）的陣列。請回傳為了讓所有會議在不衝突的情況下順利召開所需的**最少會議室數量**。在相同時間段內重疊的會議必須各自使用不同的會議室。

## 核心思路

若將會議的開始與結束作為獨立的事件，按時間順序進行處理，就能求出某一瞬間同時進行的會議的最大數量。該最大數量即為所需的會議室數量。

## 思考過程

1. **同時進行的會議數量即為答案**：某一瞬間同時進行的會議的最大數量 = 所需的會議室數量。問題可歸結為如何有效率地求出「同時進行數量的最大值」
2. **將開始與結束作為獨立的事件來處理**：會議開始時需要一間會議室，結束時會空出一間會議室。將開始與結束分離並分別排序後，就能按時間順序處理事件
3. **對兩個已排序的陣列進行掃描**：分別對 starts 陣列與 ends 陣列進行排序，然後從 starts 的開頭開始遍歷。針對每個開始時刻判斷「是否早於最早的結束時刻」，就能知道是需要新的會議室還是有會議室空出來
4. **使用雙指標追蹤同時進行的數量**：準備 starts 陣列的指標 `i` 和 ends 陣列的指標 `endPtr`。若 `starts[i] < ends[endPtr]`，表示新的會議與現有會議重疊，因此需要增加會議室。否則表示有一場會議已結束而空出會議室，因此將 `endPtr` 向前推進
5. **記錄最大值**：在遍歷過程中持續將 `rooms` 的最大值記錄到 `maxRooms` 中。遍歷完成後回傳 `maxRooms`

## 前置知識

### 什麼是 Arrays.sort

Arrays.sort 是 Java 的標準方法，用於將陣列按升序排序。對於原始型別陣列，它使用雙軸快速排序（O(n log n)）。

```java
int[] arr = {5, 2, 8, 1};
Arrays.sort(arr);        // arr 變為 {1, 2, 5, 8}
```

### 什麼是雙指標（Two Pointer）

雙指標是一種使用兩個索引變數，分別獨立地遍歷陣列的技巧。對已排序的陣列使用此技巧，可以有效率地比較與合併兩個陣列的元素。

```java
int i = 0;          // 第一個陣列用的指標
int endPtr = 0;     // 第二個陣列用的指標
// 根據條件決定要推進哪一個指標
```

### 什麼是事件掃描（Event Sweep）

事件掃描是一種按時間順序處理時間軸上的事件（開始、結束），並追蹤某一時刻的狀態（例如同時進行的數量）的方法。透過在開始事件時增加計數器、在結束事件時減少計數器，就能得知任意瞬間的同時進行數量。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n log n) — 兩個陣列的排序為主要開銷 |
| Space | O(n) — 建立兩個陣列分別儲存開始時刻與結束時刻 |

## 程式碼

```java
// 輸入：表示會議時間段的二維整數陣列 intervals（每個元素為 [start, end]）
// 輸出：回傳所有會議在不衝突的情況下所需的最少會議室數量（int）
public int minMeetingRooms(int[][] intervals) {
    // 若輸入為 null 或為空，表示不存在任何會議，因此回傳 0
    if (intervals == null || intervals.length == 0)
        return 0;

    int n = intervals.length;
    // 將開始與結束分離，使其能夠分別獨立排序
    int[] starts = new int[n];  // 儲存開始時刻的陣列
    int[] ends = new int[n];    // 儲存結束時刻的陣列

    // 遍歷 intervals，將開始時刻與結束時刻分別儲存到各自的陣列中
    for (int i = 0; i < n; i++) {
        starts[i] = intervals[i][0];
        ends[i] = intervals[i][1];
    }

    // 將兩個陣列按升序排序，為按時間順序處理事件做好準備
    Arrays.sort(starts);
    Arrays.sort(ends);

    int rooms = 0, maxRooms = 0;
    // ends 陣列的指標，指向最早結束的會議
    int endPtr = 0;

    // 從 starts 陣列的開頭開始遍歷。每次迭代代表「一場新會議開始」的事件
    for (int i = 0; i < n; i++) {
        if (starts[i] < ends[endPtr]) {
            // 當前開始的會議的開始時刻早於最早結束的會議的結束時刻 → 發生重疊，因此分配一間新的會議室
            rooms++;
        } else {
            // 最早結束的會議已經結束，因此可以重複使用該會議室。不增加會議室數量，將 endPtr 向前推進以指向下一個最早結束的會議
            endPtr++;
        }
        // 更新同時使用的最大會議室數量
        maxRooms = Math.max(maxRooms, rooms);
    }
    // maxRooms 是同時使用的會議室數量的最大值，即所需的最少會議室數量
    return maxRooms;
}
```
