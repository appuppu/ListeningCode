# Finding the Minimum Jumps to Reach the End — 求出到達陣列末尾的最少跳躍次數

## 問題的本質

給定一個整數陣列 `nums`，每個元素 `nums[i]` 表示從該位置最多可以向前跳躍多少格。從索引 0 開始出發，返回到達最後一個索引所需的**最少跳躍次數**。題目保證一定能到達末尾。

## 核心思路

將每次跳躍視為「一次跳躍可到達的範圍（窗口）」，每當到達窗口的邊界時，就將跳躍次數加 1。在遍歷窗口內的元素時，同時記錄下一個窗口的最遠到達點，藉此以 O(1) 的空間實現與 BFS 層級搜索相同的效果。

## 思考過程

1. **求最少次數的問題可以用 BFS 來解決**：將每個位置視為節點、可跳躍的範圍視為邊，問題就轉化為從索引 0 到末尾的最短路徑問題。BFS 按層級進行搜索，因此第一次到達末尾的層級即為最少跳躍次數
2. **用窗口來表示 BFS 的層級**：一般的 BFS 使用佇列，需要 O(n) 的空間。然而，在陣列上的跳躍問題中，每個層級可到達的範圍是連續區間，因此只需用區間的終點 `currentEnd` 就能表示當前的層級
3. **在窗口內追蹤下一個最遠到達點**：遍歷當前窗口內的元素（從上一次的 `currentEnd` 到本次的 `currentEnd`），將每個位置 `i` 能到達的最遠點 `i + nums[i]` 的最大值記錄在變數 `farthest` 中。這個值就是下一個窗口的終點
4. **在窗口邊界處確定跳躍**：當索引 `i` 到達 `currentEnd` 時，表示當前窗口已經用完。此時將跳躍次數加 1，並將 `currentEnd` 更新為 `farthest`，進入下一個窗口
5. **迴圈範圍到末尾的前一個元素為止**：迴圈條件設為 `i < nums.length - 1`，可以避免在到達最後一個索引時多算一次跳躍。由於題目保證一定能到達末尾，因此不需要進行到達判定
6. **最終返回的結果**：迴圈結束後，返回變數 `jumps` 中累積的最少跳躍次數

## 前置知識

### 什麼是 Greedy BFS（貪心廣度優先搜索）

BFS（廣度優先搜索）是一種從圖的起點求出到各節點最短路徑的演算法。通常使用佇列來實現，但在陣列上的跳躍問題中，可到達範圍是連續區間，因此只需管理區間的邊界，就能用貪心法得到相同的結果。在每個層級（一次跳躍的範圍）中貪心地選擇可到達的最遠點，即可求出最少跳躍次數。

### 什麼是 Math.max

Math.max 是 Java 的標準方法，用於返回兩個整數中較大的那一個。用途是比較當前的最遠到達點和新計算的到達點，保留較遠的那一個。

```java
Math.max(3, 7);       // 返回兩個值中較大的一個 → 7
Math.max(farthest, i + nums[i]);  // 比較當前最遠點和新的到達點
```

### 什麼是窗口（跳躍範圍）

窗口是指一次跳躍可以到達的連續索引區間。變數 `currentEnd` 表示窗口的右端。當 `i` 到達 `currentEnd` 時，表示當前窗口已用完，需要進行下一次跳躍。
例如：`nums = [2,3,1,1,4]` 的情況下，第一個窗口是 `[1,2]`（從索引 0 最多跳 2 格），下一個窗口是 `[3,4]`（窗口內的最遠到達點為 4）。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需遍歷陣列一次 |
| Space | O(1) — 只使用 3 個變數，不需要額外的資料結構 |

## 程式碼

```java
// 輸入：整數陣列 nums（每個元素表示從該位置的最大跳躍長度）
// 輸出：以 int 返回到達最後一個索引所需的最少跳躍次數
public int jump(int[] nums) {
    // 記錄跳躍次數的變數。每當到達窗口的邊界時加 1
    int jumps = 0;
    // 當前跳躍窗口的右端。初始位於索引 0，因此初始化為 0
    int currentEnd = 0;
    // 從窗口內可以到達的最遠索引。用於決定下一個窗口的右端
    int farthest = 0;

    // 遍歷到末尾的前一個元素為止。到達末尾即達成目標，不需要再進行額外的跳躍
    for (int i = 0; i < nums.length - 1; i++) {
        // i + nums[i] 是從當前位置 i 進行最大跳躍後的到達索引
        // 如果比目前的 farthest 更遠，則更新該值
        farthest = Math.max(farthest, i + nums[i]);

        // 到達當前窗口的右端時，需要進行下一次跳躍
        if (i == currentEnd) {
            // 將跳躍次數加 1
            jumps++;
            // 將下一個窗口的右端設定為 farthest。下一個窗口的範圍是從 currentEnd+1 到新的 currentEnd
            currentEnd = farthest;
        }
    }
    // 返回累積的最少跳躍次數
    return jumps;
}
```
