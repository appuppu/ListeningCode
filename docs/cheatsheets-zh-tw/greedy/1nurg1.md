# Finding the Subarray With Maximum Sum — 找出具有最大總和的連續子陣列

## 問題的本質

系統給定一個整數陣列 `nums`。該陣列可能同時包含正數和負數。我們需要在所有連續子陣列（subarray）中，找出元素總和最大的那一個，並返回該**總和值**。

## 核心概念

當我們到達每個元素時，只有兩種選擇：「延長目前的子陣列」或「從該元素開始一個新的子陣列」。如果目前的累積總和為負數，那麼捨棄它並重新開始一定比繼續拖著負數更有利。

## 思考過程

1. **每個元素只有兩種選擇**：當我們到達元素 `nums[i]` 時，可以採取的行動只有「將 `nums[i]` 加入先前的子陣列來延長它」或「以 `nums[i]` 為起點開始一個新的子陣列」這兩種。由於連續子陣列的限制，我們不能跳過中間的元素
2. **判斷延長還是重新開始的標準**：如果先前的累積總和 `currentSum` 為正數，將它加上 `nums[i]` 會得到比 `nums[i]` 單獨更大的值，因此選擇延長。如果 `currentSum` 為負數，加上它反而會使結果比 `nums[i]` 單獨更小，因此捨棄它並重新開始。也就是說，我們只需選擇 `currentSum + nums[i]` 和 `nums[i]` 之中較大的那一個
3. **用 `Math.max` 來表達這個判斷**：`currentSum = Math.max(currentSum + nums[i], nums[i])` 這一行就能完成延長與重新開始的判斷。其中 `currentSum + nums[i]` 對應延長，`nums[i]` 對應重新開始
4. **另外追蹤整體的最大值**：`currentSum` 代表「目前子陣列的總和」，它在走訪過程中會上下波動。由於題目要求的是「整個走訪過程中的最大總和」，因此我們需要用另一個變數 `maxSum` 持續記錄走訪中出現過的 `currentSum` 的最大值
5. **將 `maxSum` 的初始值設為 `Integer.MIN_VALUE`**：為了在陣列所有元素都是負數的情況下仍能正確運作，我們將 `maxSum` 的初始值設為整數的最小值。如果用 0 來初始化，當所有元素都是負數時，程式會錯誤地判定「空的子陣列（總和為0）」為最大值
6. **最終返回 `maxSum`**：當陣列的走訪結束時，`maxSum` 中已記錄了所有連續子陣列中的最大總和。我們返回這個值

## 前置知識

### 什麼是 Math.max

Math.max 是 Java 的標準方法，它接收兩個值並返回較大的那一個。它可以將條件分支用一行來表達。

```java
Math.max(5, 3);       // 返回兩個值中較大的那一個 → 5
Math.max(-2, -7);     // 即使是負數之間也返回較大的那一個 → -2
Math.max(a + b, b);   // 也可以比較運算式的結果
```

### 什麼是 Integer.MIN_VALUE

Integer.MIN_VALUE 是表示 Java 中 `int` 型別最小值（-2,147,483,648）的常數。它被用作「尚未進行任何比較」狀態的初始值。無論與任何整數比較，`Math.max` 都一定會選擇對方的值。

```java
int maxSum = Integer.MIN_VALUE;   // 用 int 型別的最小值來初始化
maxSum = Math.max(maxSum, -5);    // 任何值都比 maxSum 大 → -5
```

### 什麼是連續子陣列（subarray）

連續子陣列是指從陣列中取出相鄰且不間斷的元素所組成的部分。我們不能跳過元素來選取。
例如：當 `nums = [-2, 1, -3, 4, -1, 2]` 時，`[4, -1, 2]` 是連續子陣列（總和為5）。`[1, 4, 2]` 因為元素不相鄰，所以不是連續子陣列。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需走訪陣列一次即可完成 |
| Space | O(1) — 只使用 `maxSum` 和 `currentSum` 這兩個變數 |

## 程式碼

```java
// 輸入：可能包含正數和負數的整數陣列 nums
// 輸出：以 int 返回連續子陣列的最大總和值
public int maxSubArray(int[] nums) {
    // 記錄整個走訪過程中出現過的子陣列總和的最大值的變數
    // 用 Integer.MIN_VALUE 初始化，以便在所有元素都是負數時也能正確選出最大值
    // 注意：如果用 0 初始化，當所有元素都是負數時，程式會錯誤地判定「空的子陣列（總和為0）」為最大值
    int maxSum = Integer.MIN_VALUE;
    // 保存目前正在構建的子陣列總和的變數。走訪開始時尚未包含任何元素，因此初始值為 0
    int currentSum = 0;

    // 從陣列的開頭到末尾逐一走訪
    for (int num : nums) {
        // currentSum + num 是「延長先前子陣列時的總和」
        // num 是「從該元素開始一個新子陣列時的總和」
        // 選擇較大的那一個，就能始終做出最佳判斷
        currentSum = Math.max(currentSum + num, num);
        // 如果目前子陣列的總和超過了先前的最大值就更新，未超過則維持不變
        maxSum = Math.max(maxSum, currentSum);
    }
    // 走訪結束時，maxSum 中已記錄了所有連續子陣列中的最大總和值
    return maxSum;
}
```
