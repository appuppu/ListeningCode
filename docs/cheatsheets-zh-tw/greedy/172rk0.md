# Checking Validity of a Parenthesis String With Wildcards — 判定含萬用字元的括號字串是否有效

## 問題的本質

給定一個僅由 `(`、`)`、`*` 三種字元組成的字串。`*` 可以被視為 `(`、`)` 或空字元中的任何一種。判定該字串是否**能成為有效的括號序列**，並以 `boolean` 回傳結果。

## 核心思路

由於 `*` 的解釋方式不確定，因此不將開括號的數量追蹤為單一值，而是追蹤為「可能的範圍（最小值 low ～ 最大值 high）」。只要在掃描過程中該範圍始終有效，且最終範圍包含 0，則該字串為有效。

## 思考過程

1. **括號的有效性可以透過開括號的計數來判定**：從左到右掃描字串，遇到 `(` 則 +1，遇到 `)` 則 -1。若中途計數變為負數則無效，最終為 0 則有效。這是括號判定的基本原理
2. **存在 `*` 時，計數無法確定為單一值**：`*` 有三種解釋方式，因此計數不是單一值，而是一個「範圍」。若將 `*` 解釋為 `(` 則計數 +1，解釋為 `)` 則 -1，解釋為空字元則 ±0。也就是說，每遇到一個 `*`，範圍就會擴大
3. **使用兩個變數追蹤範圍**：`low` 代表開括號計數的最小值（盡可能將 `*` 視為 `)` 或空字元的情況），`high` 代表最大值（盡可能將 `*` 視為 `(` 的情況）。僅靠這兩個變數就能涵蓋所有模式
4. **掃描過程中若 `high` 變為負數，則立即判定為無效**：`high` 是開括號計數的最大值，若其變為負數，代表無論如何解釋 `*`，`)` 都過多，不可能成為有效的括號序列
5. **若 `low` 變為負數，則將其鉗位為 0**：`low` 變為負數只是因為包含了「讓 `)` 多餘的解釋」，只要將 `*` 視為空字元，就能維持計數在 0 以上。負值代表實際上不會選擇的解釋，因此將 `low` 修正為 0
6. **最終根據 `low == 0` 來判定**：掃描完成時，若 `low` 為 0，代表「存在一種能讓所有開括號都被關閉的解釋」，因此回傳 `true`

## 前置知識

### 括號序列有效性判定的基本原理

從左到右掃描字串，管理開括號的計數。遇到 `(` 則 +1，遇到 `)` 則 -1，若中途不變為負數且最終為 0，則為有效的括號序列。

```java
int count = 0;
for (char c : s.toCharArray()) {
    if (c == '(') count++;
    else count--;
    if (count < 0) return false;  // 閉括號過多
}
return count == 0;  // 所有開括號是否都已被關閉
```

### Math.max 是什麼

回傳兩個值中較大者的方法。可用於將值修正（鉗位）為不低於特定下限。

```java
Math.max(3, 0);    // → 3（3 >= 0，因此維持原值）
Math.max(-1, 0);   // → 0（-1 < 0，因此被修正為 0）
```

### toCharArray 是什麼

將字串轉換為 `char` 陣列的方法。用於在 for-each 迴圈中逐字元掃描字串。

```java
String s = "(*)"；
char[] chars = s.toCharArray();  // → ['(', '*', ')']
for (char c : s.toCharArray()) {
    // c 被逐一賦值為每個字元，迴圈依次執行
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需掃描字串一次 |
| Space | O(1) — 僅使用 `low` 和 `high` 兩個變數 |

## 程式碼

```java
// 輸入：僅由 '('、')'、'*' 組成的字串 s
// 輸出：以 boolean 回傳該字串是否能成為有效的括號序列
public boolean checkValidString(String s) {
    // low：開括號計數的最小值，high：最大值
    // 透過這兩個變數追蹤 * 的所有解釋模式下計數的範圍
    int low = 0, high = 0;

    // 從字串開頭逐字元掃描
    for (char c : s.toCharArray()) {
        if (c == '(') {
            // 開括號：無論哪種解釋都將計數加 1，因此範圍的兩端都 +1
            low++;
            high++;
        } else if (c == ')') {
            // 閉括號：無論哪種解釋都將計數減 1，因此範圍的兩端都 -1
            low--;
            high--;
        } else {
            // '*'：若解釋為 ) 則最小值下降，若解釋為 ( 則最大值上升
            // 空字元的解釋包含在此範圍之內
            low--;
            high++;
        }

        // 若最大值為負，則無論如何解釋 *，閉括號都過多，因此無效
        if (high < 0) return false;

        // low 變為負數是因為過度將 * 解釋為 )，
        // 實際上只要不選擇該解釋即可，因此將最小值修正為 0
        low = Math.max(low, 0);
    }

    // 若 low 為 0，代表「存在一種讓所有開括號都被關閉的 * 解釋」，因此為 true
    // 若 low 大於 0，代表無論如何解釋，開括號都會多餘，因此為 false
    return low == 0;
}
```
