# Determining if You Can Reach the End of an Array — 判斷是否能到達陣列的末尾

## 問題的本質

給定一個整數陣列 `nums`。每個元素 `nums[i]` 表示從該索引向前跳躍的**最大長度**。從索引 `0` 開始，以 `boolean` 回傳是否能到達陣列的**最後一個索引**。

## 核心思路

持續更新每個位置「從此處能到達的最遠點」，當最遠點落在當前位置之前的瞬間，即可判定為無法到達。不需要追蹤個別的跳躍路徑，只需「到目前為止可到達的最遠索引」這一個值就足夠了。

## 思考過程

1. **可達性由最遠點決定**：索引 `i` 是否可達，可透過之前所有元素計算出的「可到達的最遠索引」是否大於等於 `i` 來判定。不需要中間路徑的細節，只有最遠點是重要的
2. **最遠點可用一個變數管理**：在每個索引 `i`，`i + nums[i]` 是從該位置的最遠到達點。與目前的最遠點比較並保留較大的值，就能用一個變數追蹤整體的可到達範圍
3. **無法到達的判定條件**：從左到右掃描陣列時，如果當前索引 `i` 超過了最遠點 `maxReach`，則表示根本無法到達索引 `i`。也就是說 `i > maxReach` 就是無法到達的條件
4. **提前終止的條件**：當 `maxReach` 大於等於陣列的最後一個索引 `nums.length - 1` 時，即可確定能到達末尾，因此可以跳過剩餘的掃描並回傳 `true`
5. **掃描完成到最後的情況**：如果迴圈結束時既沒有回傳 `false` 也沒有回傳 `true`，表示所有索引都是可到達的，因此回傳 `true`

## 前置知識

### 什麼是 Math.max

這是一個接收兩個整數並回傳較大值的靜態方法。在更新最遠點時，用於比較「當前的最遠點」和「新計算的到達點」。

```java
Math.max(3, 5);    // 回傳 5 — 兩個引數中較大的一個
Math.max(7, 2);    // 回傳 7
Math.max(4, 4);    // 回傳 4 — 相等時回傳該值
```

### 什麼是 maxReach（最遠到達索引）

這是一個變數，表示從陣列開頭到當前位置考慮所有元素後，可到達的最遠索引。在索引 `i` 時，`i + nums[i]` 是從該位置能到達的最遠點，透過 `maxReach = Math.max(maxReach, i + nums[i])` 始終保持最大值。
例如：當 `nums = [2, 3, 1, 1, 4]` 時，在 `i=0` 時 `maxReach = 0 + 2 = 2`，在 `i=1` 時 `maxReach = max(2, 1 + 3) = 4`，因此可判定能到達末尾索引 `4`。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需掃描陣列一次即可完成 |
| Space | O(1) — 額外的變數只有 `maxReach` 一個 |

## 程式碼

```java
// 輸入：整數陣列 nums（每個元素為從該索引的最大跳躍長度）
// 輸出：如果能到達最後一個索引則回傳 true，否則回傳 false
boolean canJump(int[] nums) {
    // 追蹤到目前為止可到達的最遠索引的變數
    // 起始點為索引 0，因此初始值為 0
    int maxReach = 0;

    // 從陣列開頭到末尾逐一掃描
    for (int i = 0; i < nums.length; i++) {
        // 如果當前索引超過了最遠到達點，則無法到達此處
        if (i > maxReach) return false;

        // i + nums[i] 是從當前位置能到達的最遠索引
        // 與目前的 maxReach 比較並保留較大的值
        maxReach = Math.max(maxReach,
            i + nums[i]);

        // 如果最遠到達點大於等於陣列的最後一個索引，則確定能到達末尾
        if (maxReach >= nums.length - 1)
            return true;
    }
    // 迴圈完成到最後的情況，表示所有索引都是可到達的，因此回傳 true
    return true;
}
```
