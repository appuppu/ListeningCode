# Partitioning a String Into Maximum Parts — 將字串分割為最大數量的部分，使每個字元僅包含在一個部分中

## 問題的本質

給定一個由小寫英文字母組成的字串 `s`。將字串分割為盡可能多的部分，使每個字元最多只包含在一個部分中。以列表形式返回每個部分的**長度**。

## 核心思路

如果某個字元包含在當前部分中，則必須將該部分延伸到該字元的最後出現位置。只要事先計算出每個字元的最終出現位置，就能透過一次遍歷以貪心策略確定部分的邊界。

## 思考過程

1. **理解分割的限制條件**: 同一個字元不能跨越兩個部分。也就是說，包含某個字元的部分至少需要涵蓋到該字元的最後出現位置
2. **事先求出每個字元的最終出現位置**: 遍歷字串一次，將每個字元最後出現的索引記錄在陣列中。由於英文小寫字母只有26種，大小為26的陣列即足夠
3. **以貪心策略擴展部分的終點**: 從字串開頭開始遍歷，追蹤當前部分中所有字元的最終出現位置的最大值作為 `end`。每遇到一個新字元，就將 `end` 與該字元的最終出現位置進行比較並更新
4. **判斷部分的確定條件**: 當前索引 `i` 到達 `end` 時，可以保證當前部分內的所有字元都收容在該部分的範圍內。此時確定該部分，並開始下一個部分
5. **計算部分的長度**: 每當確定一個部分時，用 `end - start + 1` 求出部分的長度，並加入結果列表中。將下一個部分的起始位置 `start` 更新為 `i + 1`

## 前置知識

### 字元的索引轉換

在Java中，`char` 型別可以作為整數處理。透過 `s.charAt(i) - 'a'`，可以將小寫字母 `'a'` 轉換為 `0`、`'b'` 轉換為 `1`、...、`'z'` 轉換為 `25`。藉此，可以用大小為26的陣列管理所有小寫字母。

```java
char c = 'c';
int index = c - 'a';    // 2（'c'是從'a'起算第2個）
int[] arr = new int[26]; // 存放26個字母的陣列
arr[c - 'a'] = 5;       // 在對應'c'的位置儲存值5
```

### 什麼是 Math.max

這是一個返回兩個值中較大值的方法。在擴展部分終點時，用於比較當前的 `end` 與新字元的最終出現位置，並採用較遠的那個。

```java
Math.max(3, 7);   // 返回7
Math.max(10, 2);  // 返回10
```

### 什麼是 ArrayList

這是一個可變長度的列表。由於部分的數量事先未知，適合用來逐一添加每個部分的長度。

```java
List<Integer> res = new ArrayList<>();  // 建立空列表
res.add(9);    // 在末尾添加9 → [9]
res.add(7);    // 在末尾添加7 → [9, 7]
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需遍歷字串兩次即可完成（記錄最終位置一次，分割部分一次） |
| Space | O(1) — 僅使用大小為26的固定陣列，不依賴於輸入大小 |

## 程式碼

```java
// 輸入: 由小寫英文字母組成的字串 s
// 輸出: 返回儲存每個部分長度的 List<Integer>
List<Integer> partitionLabels(String s) {
    // 用大小為26的整數陣列，儲存每個字元（'a'～'z'）的最終出現索引
    // 由於英文小寫字母只有26種，所以大小固定為26
    int[] last = new int[26];

    // 第一次遍歷: 記錄每個字元的最終出現位置
    // 當同一個字元出現多次時，後面的索引會覆寫前面的，因此最終保留的是最後的位置
    for (int i = 0; i < s.length(); i++) {
        last[s.charAt(i) - 'a'] = i;
    }

    // 由於部分數量事先未知，所以使用可變長度列表
    List<Integer> res = new ArrayList<>();
    // start: 當前部分的起始位置，end: 當前部分的終點位置
    int start = 0, end = 0;

    // 第二次遍歷: 以貪心策略逐步確定各個部分
    for (int i = 0; i < s.length(); i++) {
        // 如果當前字元的最終出現位置比 end 更遠，則將部分的終點擴展到該位置
        // 藉此，end 始終保持為部分內所有字元的最終出現位置的最大值
        end = Math.max(end,
            last[s.charAt(i) - 'a']);

        // i 到達 end → 保證部分內的所有字元都收容在此範圍內
        // 因為部分內的任何字元都不會出現在 end 之後
        if (i == end) {
            // 用 end - start + 1 計算部分的長度，並加入結果列表
            res.add(end - start + 1);
            // 更新下一個部分的起始位置
            start = i + 1;
        }
    }
    // 返回儲存所有部分長度的列表
    return res;
}
```
