# Finding the Median of Two Sorted Arrays — 求兩個已排序陣列合併後的中位數

## 問題的本質

給定兩個已排序的整數陣列 `n1` 和 `n2`。求將兩個陣列合併後的**中位數**。解法必須在相對於總元素數的對數時間內完成。

## 核心思路

求兩個已排序陣列的中位數，等同於找到將陣列正確分割為「左半部」和「右半部」的邊界。對較短的陣列進行二分搜尋來決定分割位置，另一個陣列的分割位置就會自動確定。

## 思考過程

1. **中位數由「左半部的最大值」和「右半部的最小值」決定**：如果能將合併後的陣列在保持排序的狀態下平分為左右兩半，中位數就是左半部的最大值（元素總數為奇數時），或者左半部最大值與右半部最小值的平均（元素總數為偶數時）。也就是說，不需要對所有元素排序，只要找到正確的分割位置即可
2. **只要決定一個陣列的分割位置，另一個陣列的分割位置就自動確定**：假設左半部共放入 `half = (m + n + 1) / 2` 個元素，若從陣列 `n1` 取 `cut1` 個，則從陣列 `n2` 需要取 `cut2 = half - cut1` 個。也就是說，只需搜尋 `cut1` 即可
3. **正確分割的條件可以透過「交叉比較」來判定**：正確的分割意味著左半部的所有元素都小於等於右半部的所有元素。由於各陣列內部已排序，只需確認交叉的部分即可。具體來說，`n1` 的左端末尾 `l1` ≤ `n2` 的右端開頭 `r2`，且 `n2` 的左端末尾 `l2` ≤ `n1` 的右端開頭 `r1` 成立，就是正確的分割
4. **使用二分搜尋高效地搜尋 `cut1`**：`cut1` 的範圍是 `0` 到 `m`。若 `l1 > r2` 表示從 `n1` 取太多，需要減少 `cut1`；若 `l2 > r1` 表示從 `n1` 取太少，需要增加 `cut1`。這個判定使二分搜尋成立
5. **選擇較短陣列進行搜尋的原因**：二分搜尋的範圍是 `0` 到 `m`（陣列的長度），選擇較短的陣列可以縮小搜尋範圍，使計算複雜度達到 `O(log(min(m, n)))`
6. **邊界處理使用哨兵值**：當 `cut1 = 0`（不從 `n1` 取任何元素）或 `cut1 = m`（取 `n1` 的全部元素）時，會存取不存在的元素。使用 `Integer.MIN_VALUE` 和 `Integer.MAX_VALUE` 作為哨兵值，可以確保比較條件在任何情況下都能正確運作

## 前置知識

### 中位數（Median）

在已排序的數列中位於中央位置的值。元素數為奇數時取中央的一個值，偶數時取中央兩個值的平均。

```java
// 奇數個: [1, 3, 5] → 中位數為 3
// 偶數個: [1, 3, 5, 7] → 中位數為 (3 + 5) / 2.0 = 4.0
```

### 二分搜尋（Binary Search）

對已排序的資料，每次將搜尋範圍縮小一半，從而以 O(log n) 的時間找到目標值的方法。使用 `lo` 和 `hi` 管理搜尋範圍，以中央的值為基準逐步縮小範圍。

```java
int lo = 0, hi = n;
while (lo <= hi) {
    int mid = (lo + hi) / 2;       // 計算搜尋範圍的中央位置
    if (條件成立) { /* 答案 */ }
    else if (mid太大) { hi = mid - 1; }  // 縮小到左半部
    else { lo = mid + 1; }               // 縮小到右半部
}
```

### 哨兵值（Sentinel Value）

為了避免存取陣列邊界外而使用的特殊值。使用 `Integer.MIN_VALUE`（整數最小值）和 `Integer.MAX_VALUE`（整數最大值），確保比較條件在邊界情況下也不會出錯。

```java
Integer.MIN_VALUE;  // -2147483648 — 作為比任何元素都小的值使用
Integer.MAX_VALUE;  //  2147483647 — 作為比任何元素都大的值使用
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(log(min(m, n))) — 對較短的陣列進行二分搜尋 |
| Space | O(1) — 僅使用變數，不建立額外的資料結構 |

## 程式碼

```java
// 輸入: 兩個已排序的整數陣列 n1 和 n2
// 輸出: 將兩個陣列合併後的中位數，以 double 回傳
public double findMedian(int[] n1, int[] n2) {
    // 為了對較短的陣列進行二分搜尋，若 n1 較長則交換後遞迴呼叫
    // 這樣可以最小化搜尋範圍，實現 O(log(min(m, n)))
    if (n1.length > n2.length)
        return findMedian(n2, n1);

    int m = n1.length, n = n2.length;
    // 放入左半部的元素數。加 1 使得元素總數為奇數時左半部多一個，
    // 左半部的最大值就直接是中位數
    int half = (m + n + 1) / 2;
    // cut1 的搜尋範圍: 0（不從 n1 取任何元素）～ m（取 n1 的全部元素）
    int lo = 0, hi = m;

    while (lo <= hi) {
        // 以二分搜尋的中間值決定從 n1 放入左半部的個數
        int cut1 = (lo + hi) / 2;
        // 從 n2 放入左半部的個數（自動決定使左半部合計為 half）
        int cut2 = half - cut1;

        // n1 左半部的末尾（cut1=0 表示左半部為空，
        // 使用比任何元素都小的哨兵值，確保比較條件始終成立）
        int l1 = cut1 == 0 ?
            Integer.MIN_VALUE :
            n1[cut1 - 1];
        // n2 左半部的末尾（cut2=0 表示左半部為空，使用哨兵值）
        int l2 = cut2 == 0 ?
            Integer.MIN_VALUE :
            n2[cut2 - 1];
        // n1 右半部的開頭（cut1=m 表示右半部為空，
        // 使用比任何元素都大的哨兵值，確保比較條件始終成立）
        int r1 = cut1 == m ?
            Integer.MAX_VALUE :
            n1[cut1];
        // n2 右半部的開頭（cut2=n 表示右半部為空，使用哨兵值）
        int r2 = cut2 == n ?
            Integer.MAX_VALUE :
            n2[cut2];

        // 交叉比較: 左半部的所有元素 ≤ 右半部的所有元素，則為正確的分割
        if (l1 <= r2 && l2 <= r1) {
            // 找到正確的分割
            if ((m + n) % 2 == 1)
                // 奇數個: 左半部的最大值就是中位數
                return Math.max(l1, l2);
            // 偶數個: 左半部最大值與右半部最小值的平均就是中位數
            return (Math.max(l1, l2)
                + Math.min(r1, r2))
                / 2.0;
        } else if (l1 > r2) {
            // n1 左半部末尾超過 n2 右半部開頭 → 從 n1 取太多 → 減少 cut1
            hi = cut1 - 1;
        } else {
            // l2 > r1: 從 n1 取太少 → 增加 cut1
            lo = cut1 + 1;
        }
    }
    // 根據問題的約束條件，一定能找到正確的分割，因此不會到達這裡
    return -1;
}
```
