# Finding the Minimum Eating Speed to Finish Bananas — 求在限制時間內吃完所有香蕉的最小速度

## 問題的本質

給定一個香蕉堆的陣列 `piles` 和限制時間 `h`（小時）。每小時吃 `k` 根香蕉時，返回能在 `h` 小時內吃完所有香蕉的**最小整數速度 `k`**。每小時只能吃一堆，若該堆的香蕉少於 `k` 根，吃完該堆後剩餘時間無法開始吃下一堆，必須等待。

## 核心思路

「以速度 `k` 能否吃完全部？」對 `k` 具有單調性。`k` 越大必定能吃完，太小則吃不完。由於存在此單調性，可對答案的候選範圍 `[1, max(piles)]` 應用二分搜尋，高效地找到滿足條件的最小 `k`。

## 思考過程

1. **速度與結果的關係具有單調性**：提高速度 `k` 則所需時間減少，降低則增加。若某速度能吃完，則大於該速度的任何值也必定能吃完。這種「求滿足某條件的最小值」的結構，是二分搜尋的典型模式
2. **確定搜尋範圍**：速度的最小值為 `1`（每小時至少吃1根），最大值為 `max(piles)`（能在1小時內吃完最大堆的速度）。即使速度大於 `max(piles)`，由於每小時只能吃一堆，結果不會改變
3. **設計判定函數**：給定速度 `mid` 時，吃完每堆 `piles[i]` 需要 `ceil(piles[i] / mid)` 小時。若所有堆的總時間不超過 `h`，則判定該速度能吃完
4. **用整數運算實現天花板除法**：`ceil(piles[i] / mid)` 可用 `(piles[i] + mid - 1) / mid` 計算。這樣可以避免浮點數運算，僅用整數進行精確計算
5. **用二分搜尋縮小範圍**：若中間值 `mid` 能吃完，則答案在 `mid` 以下，故令 `right = mid`。若吃不完，則答案在 `mid + 1` 以上，故令 `left = mid + 1`。當 `left == right` 時，該值即為所求的最小速度

## 前置知識

### 二分搜尋（Binary Search）的「求滿足條件的最小值」模式

對已排序的值或連續整數的範圍，找出滿足某條件的最小值（或最大值）的方法。每次將搜尋範圍縮小一半，因此能在 O(log n) 內找到答案。

```java
int left = 1;               // 搜尋範圍的下限
int right = 1000;            // 搜尋範圍的上限
while (left < right) {       // 當 left == right 時答案確定
    int mid = left + (right - left) / 2;  // 防止溢位的中間值計算
    if (condition(mid))       // 判定 mid 是否滿足條件
        right = mid;          // 滿足條件 → 答案在 mid 以下
    else
        left = mid + 1;       // 不滿足條件 → 答案在 mid+1 以上
}
// left 即為滿足條件的最小值
```

### 天花板除法（Ceiling Division）

將 `a / b` 的結果向上取整的整數運算。不使用 `Math.ceil`，而用 `(a + b - 1) / b` 來計算。

```java
int a = 10, b = 3;
int result = (a + b - 1) / b;  // (10 + 2) / 3 = 4  （10÷3=3.33... → 向上取整為4）
```

在香蕉問題中，將堆的大小 `piles[i]` 除以速度 `k` 並向上取整，即可求出吃完該堆所需的小時數。

### Math.max 是什麼

返回兩個值中較大者的方法。求陣列最大值時，與迴圈搭配使用。

```java
Math.max(5, 3);   // → 5
Math.max(-1, 0);  // → 0
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n × log(max(piles))) — 二分搜尋進行 O(log(max(piles))) 次迭代，每次迭代以 O(n) 遍歷整個陣列計算總時間 |
| Space | O(1) — 不使用額外的資料結構，僅用變數進行處理 |

## 程式碼

```java
// 輸入：整數陣列 piles（每堆的香蕉數量）和整數 h（限制時間）
// 輸出：以 int 返回能在 h 小時內吃完所有香蕉的最小整數速度 k
public int minEatingSpeed(int[] piles, int h) {
    // 將二分搜尋的下限設為1。速度最少為每小時1根
    int left = 1;
    // 將二分搜尋的上限設為陣列的最大值
    // 因為速度大於能在1小時內吃完最大堆的值沒有意義，所以此值為上限
    int right = 0;
    for (int p : piles) {
        right = Math.max(right, p);
    }

    // 持續將搜尋範圍縮小一半，直到 left == right
    // 當 left == right 時，該值即為答案
    while (left < right) {
        // 防止溢位的中間值計算
        // 使用 left + (right - left) / 2 而非 (left + right) / 2 來防止整數溢位
        int mid = left + (right - left) / 2;

        // 計算以速度 mid 吃完所有香蕉所需的總時間
        int totalHours = 0;
        for (int p : piles) {
            // 天花板除法：求出吃完每堆所需的小時數
            totalHours += (p + mid - 1) / mid;
        }

        if (totalHours <= h) {
            // 能吃完 → 可能以更慢的速度也能吃完，因此縮小上限
            // 因為 mid 本身可能是答案，所以賦值 mid 而非 mid - 1
            right = mid;
        } else {
            // 吃不完 → 速度不足，因此提高下限
            // 因為 mid 不可能是答案，所以賦值 mid + 1
            left = mid + 1;
        }
    }

    // 迴圈結束後，left（= right）即為滿足條件的最小速度
    return left;
}
```
