# Finding the Minimum in a Rotated Sorted Array — 從旋轉過的已排序陣列中找出最小值

## 問題的本質

一個由唯一整數組成的升序已排序陣列，被旋轉了 1 次以上 n 次以下。需要從這個旋轉過的陣列中找出並回傳**最小的元素**。旋轉是指將陣列末尾的元素移動到開頭的操作，原本的排序順序會在某處「折斷」，該位置稱為樞軸（pivot）。

## 核心思路

在旋轉過的已排序陣列中，最小值位於排序順序崩壞的「樞軸」位置。只要將中間元素與最右端元素進行比較，就能透過一次比較判定最小值存在於左半部還是右半部，並以二分搜尋在 O(log n) 的時間內找到最小值。

## 思考過程

1. **最小值位於樞軸的位置**：旋轉過的已排序陣列會分成「較大的子序列」和「較小的子序列」兩個已排序的部分。最小值位於「較小的子序列」的開頭，也就是樞軸的位置。找到這個樞軸就是問題的本質
2. **希望使用二分搜尋而非線性搜尋**：雖然陣列並非完全排序，但它具有分成兩個已排序部分的結構。利用這個結構，就能套用每次丟棄一半的二分搜尋
3. **將中間元素與最右端元素進行比較**：當 `nums[mid] > nums[right]` 成立時，mid 到 right 之間存在樞軸（排序順序的崩壞），因此最小值在右半部。反之，當 `nums[mid] <= nums[right]` 時，mid 到 right 是已排序的，最小值在 mid 以左（包含 mid 本身）
4. **與右端而非左端比較的原因**：若與左端比較，在陣列未被旋轉的情況下（整體為已排序）會無法正確判定。與右端比較的話，無論是否經過旋轉，都能正確縮小最小值的範圍
5. **搜尋範圍的更新方式**：當 `nums[mid] > nums[right]` 時，可以確定 mid 不是最小值，因此設定 `left = mid + 1`。否則，mid 有可能是最小值，因此設定 `right = mid`（不排除 mid）
6. **迴圈的終止條件**：在 `left < right` 期間持續迴圈，當 `left == right` 時搜尋範圍縮小至 1 個元素。該元素 `nums[left]` 即為最小值

## 前提知識

### 什麼是旋轉過的已排序陣列

將升序已排序陣列 `[1, 2, 3, 4, 5]` 向右旋轉 2 次後，會變成 `[4, 5, 1, 2, 3]`。陣列被分成兩個已排序子序列 `[4, 5]` 和 `[1, 2, 3]`，其邊界就是樞軸。

```
原始陣列：    [1, 2, 3, 4, 5]
旋轉 2 次後： [4, 5, 1, 2, 3]
                   ↑ 樞軸（最小值）
```

### 二分搜尋的基本結構

透過每次將搜尋範圍縮小一半，以 O(log n) 找到目標元素的方法。使用 left 和 right 兩個指標管理搜尋範圍，並以中間元素為基準更新範圍。

```java
int left = 0;
int right = nums.length - 1;
int mid = left + (right - left) / 2;  // 防止溢位的中間值計算
```

### 什麼是 `left + (right - left) / 2`

這是計算中間索引的公式。雖然 `(left + right) / 2` 也能得到相同結果，但當 left 和 right 為較大值時，相加可能會超過 int 的最大值。這個公式是**防止溢位**的安全寫法。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(log n) — 由於每次將搜尋範圍縮小一半，最多經過 log n 次比較即可找到最小值 |
| Space | O(1) — 僅使用 left、right、mid 三個變數，不需要額外的資料結構 |

## 程式碼

```java
// 輸入：旋轉過的已排序唯一整數陣列 nums
// 輸出：以 int 回傳陣列中的最小值
public int findMin(int[] nums) {
    // 初始化搜尋範圍的兩端。這兩個變數代表搜尋範圍的兩端
    int left = 0;
    int right = nums.length - 1;

    // 當 left == right 時，搜尋範圍縮小至 1 個元素，該元素即為最小值
    while (left < right) {
        // 使用這個公式而非 (left + right) / 2，是為了防止整數溢位
        int mid = left + (right - left) / 2;

        // 當中間元素大於右端時，mid 和 right 之間存在樞軸（排序順序的崩壞）
        if (nums[mid] > nums[right]) {
            // 最小值在 mid 的右側。因為 mid 大於右端，所以 mid 不是最小值，可以排除
            left = mid + 1;
        } else {
            // 從 mid 到 right 是已排序的。最小值在 mid 以左（包含 mid 本身）
            // 因為 mid 本身可能是最小值，所以不將 mid 排除在搜尋範圍外
            right = mid;
        }
    }

    // 此時 left == right，搜尋範圍已縮小至 1 個元素，該元素即為最小值
    return nums[left];
}
```
