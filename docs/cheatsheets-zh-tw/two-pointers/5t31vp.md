# Three Sum — 找出所有三個數字之和為零的三元組

## 問題的本質

給定一個整數陣列 `nums`。從 `nums` 中找出所有三個元素之和為 `0` 的組合（三元組），並以 `List<List<Integer>>` 的形式返回。每個三元組必須由不同索引的元素組成，且結果中不得包含重複的三元組。

## 核心思路

將陣列排序後，固定其中一個元素，再利用 Two Pointers 高效地搜尋剩餘的兩個元素。同時，利用排序後的順序跳過重複的值，便能自然地排除重複的三元組。

## 思考過程

1. **將三元素問題歸約為二元素問題**：三個數 `a + b + c = 0`，只要固定一個元素 `a = nums[i]`，就變成 `b + c = -a` 的二元素搜尋問題。用外層 for 迴圈固定 `a`，在內層搜尋 `b` 和 `c`，就能應用已知的 Two Sum 思路
2. **為了使用 Two Pointers 而進行排序**：為了高效地搜尋兩個元素，將陣列排序後從兩端用指標向內收縮的 Two Pointers 方法非常有效。如果總和太小，就將左指標右移；如果總和太大，就將右指標左移，這樣就能高效地搜尋所有配對
3. **利用排序實現重複三元組的排除**：在排序後的陣列中，相同的值會相鄰排列。如果外層迴圈的 `nums[i]` 與前一個元素值相同就跳過，在內層迴圈中找到配對後也將 `left` 和 `right` 在相同值持續出現的範圍內跳過，這樣就能避免將重複的三元組加入結果中
4. **決定外層迴圈的範圍**：由於需要三個元素，`i` 從 `0` 遍歷到 `nums.length - 3`。`left` 從 `i + 1` 開始，`right` 從 `nums.length - 1` 開始，僅在 `left < right` 的條件下繼續搜尋
5. **根據總和值移動指標**：若 `sum == 0`，則將三元組加入結果中，跳過重複值後將兩個指標向內推進。若 `sum < 0`，為了增大總和將 `left` 右移；若 `sum > 0`，為了減小總和將 `right` 左移
6. **最終返回的內容**：在搜尋完所有固定元素與指標的組合後，直接返回累積的 `result` 列表

## 前提知識

### 什麼是 Two Pointers

在排序後的陣列兩端放置兩個指標（`left` 和 `right`），根據條件移動其中一個，從而在 O(n) 時間內搜尋所有配對的方法。如果總和小於目標值，就將 `left` 右移（使值增大）；如果總和大於目標值，就將 `right` 左移（使值減小）。

```java
int left = 0;
int right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) {
        // 發現配對
    } else if (sum < target) {
        left++;    // 為了增大總和，將左指標右移
    } else {
        right--;   // 為了減小總和，將右指標左移
    }
}
```

### 什麼是 Arrays.sort()

Arrays.sort() 是 Java 的標準方法，用於將陣列按升序排序。排序後相同的值會相鄰排列，因此更容易偵測重複值。

```java
int[] nums = {4, -1, 2, -1, 0};
Arrays.sort(nums);    // nums 變為 {-4, -1, -1, 0, 2}（升序）
```

### 什麼是 Arrays.asList()

Arrays.asList() 是從可變長度引數生成固定大小 `List` 的方法。在將三元組作為 `List<Integer>` 加入結果列表時使用。

```java
List<Integer> triplet = Arrays.asList(-1, 0, 1);  // 生成 [-1, 0, 1] 的列表
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n²) — 外層迴圈為 O(n)，內層的 Two Pointers 為 O(n)，合計為 O(n²) |
| Space | O(1) — 除排序外，僅使用指標變數，不佔用額外空間 |

## 程式碼

```java
// 輸入：整數陣列 nums
// 輸出：儲存所有總和為 0 的唯一三元組的 List<List<Integer>>
public List<List<Integer>> threeSum(int[] nums) {
    // 用於累積所有已發現三元組的結果列表
    List<List<Integer>> result = new ArrayList<>();
    // 將陣列按升序排序（Two Pointers 的前提條件 + 用於跳過重複值）
    Arrays.sort(nums);

    // i 從 0 遍歷到 nums.length - 3。nums[i] 作為三元組的固定元素
    for (int i = 0; i < nums.length - 2; i++) {
        // 若固定元素與前一個元素值相同，會產生相同的三元組，因此跳過
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }
        // 將左右指標分別放置在固定元素之後和陣列末尾，在此範圍內搜尋配對
        int left = i + 1;
        int right = nums.length - 1;

        while (left < right) {
            // 計算三個元素的總和
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0) {
                // 將總和為零的三元組加入結果中
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // 跳過左指標側的重複值（在相同值持續出現時向右推進）
                while (left < right && nums[left] == nums[left + 1]) {
                    left++;
                }
                // 跳過右指標側的重複值（在相同值持續出現時向左推進）
                while (left < right && nums[right] == nums[right - 1]) {
                    right--;
                }
                // 跳過重複值後，將兩個指標各向內推進一步，繼續搜尋下一個配對
                left++;
                right--;
            } else if (sum < 0) {
                // 總和為負，將左指標右移以增大總和
                left++;
            } else {
                // 總和為正，將右指標左移以減小總和
                right--;
            }
        }
    }

    // 所有固定元素的搜尋已完成。結果中儲存了所有不重複的三元組
    return result;
}
```
