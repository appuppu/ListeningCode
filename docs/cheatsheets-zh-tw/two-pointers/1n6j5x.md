# Finding Two Numbers in a Sorted Array That Add Up to a Target — 從已排序陣列中找出兩個數字之和等於目標值

## 問題的本質

給定一個已排序的整數陣列 `nums` 和一個整數 `target`。從 `nums` 中找出兩個元素，使其和等於 `target`，並以陣列形式回傳這兩個元素的 **1-indexed 位置**。解保證唯一存在，且不能重複使用同一個元素。

## 核心思路

由於陣列已排序，可以從左端和右端使用兩個指標進行夾擊。若兩數之和太大則縮小右端，若太小則擴大左端，透過一次掃描即可在 O(n) 時間、O(1) 空間內找到答案。

## 思考過程

1. **利用已排序的條件**：陣列已排序，因此左端指向最小值，右端指向最大值。從兩端的和開始搜尋，就能根據和的大小確實地縮小搜尋範圍
2. **若和太大，則將右指標向左移動**：右指標指向當前搜尋範圍中的最大值。當和大於 `target` 時，為了減小和，將右指標向左移動一格，切換到較小的值
3. **若和太小，則將左指標向右移動**：左指標指向當前搜尋範圍中的最小值。當和小於 `target` 時，為了增大和，將左指標向右移動一格，切換到較大的值
4. **若和恰好等於 `target`，則找到答案**：當兩個指標所指的值之和與 `target` 一致時，即為所求的配對。由於問題要求 1-indexed，因此將每個指標的位置加 1 後回傳
5. **迴圈的終止條件**：重複執行直到左指標到達右指標為止。根據問題的限制條件，解保證存在，因此在指標交叉之前一定能找到答案
6. **最終回傳的內容**：在和與 `target` 一致的時刻，以 `int[]` 回傳 `left + 1`（左元素的 1-indexed 位置）和 `right + 1`（右元素的 1-indexed 位置）

## 前置知識

### Two Pointers（雙指標）是什麼

雙指標是一種使用兩個指向陣列不同位置的索引變數，根據條件分別移動它們的技巧。在已排序的陣列中，從兩端向中央縮小搜尋範圍是典型的模式。

```java
int left = 0;                    // 將左指標放在陣列的開頭
int right = nums.length - 1;     // 將右指標放在陣列的末尾
while (left < right) {           // 持續迴圈直到兩個指標交叉為止
    // 根據條件移動 left 和 right
    left++;   // 將左指標向右移動一格
    right--;  // 將右指標向左移動一格
}
```

### 已排序陣列的性質

當陣列以升序排列時，`nums[left] <= nums[right]` 始終成立。將左指標向右移動會使和增大，將右指標向左移動會使和減小。正是因為具有這種單調性，才能根據和的大小來決定兩個指標的移動方向。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 兩個指標總共最多移動 n 次即可完成 |
| Space | O(1) — 僅使用指標用的變數，不需要額外的資料結構 |

## 程式碼

```java
// 輸入：已排序的整數陣列 nums 和整數 target
// 輸出：回傳包含兩個元素之和等於 target 的 1-indexed 位置的 int[]
public int[] twoSum(int[] nums, int target) {
    // 將左指標放在陣列的開頭。它是搜尋範圍的左端，負責陣列的最小值側
    int left = 0;
    // 將右指標放在陣列的末尾。它是搜尋範圍的右端，負責陣列的最大值側
    int right = nums.length - 1;

    // 持續迴圈直到兩個指標交叉為止
    while (left < right) {
        // 計算當前兩個元素的和，存入變數以便在各分支中重複使用
        int cursum = nums[left] + nums[right];

        if (cursum == target) {
            // 和與目標值一致，找到配對。由於問題要求 1-indexed，因此將每個索引加 1 後回傳
            return new int[]{left + 1, right + 1};
        } else if (cursum > target) {
            // 和太大，因此將右指標向左移動。右指標所指的值變得更小，下一次迭代的和將會減小
            right--;
        } else {
            // 和太小，因此將左指標向右移動。左指標所指的值變得更大，下一次迭代的和將會增大
            left++;
        }
    }
    // 根據問題的限制條件，解保證存在，因此不會到達此處
    return new int[]{};
}
```
