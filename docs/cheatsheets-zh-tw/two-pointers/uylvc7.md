# Maximizing Water Held Between Two Lines — 求兩條垂直線之間容器的最大盛水量

## 問題的本質

給定一個非負整數陣列 `height`。每個元素 `height[i]` 表示在x軸上位置 `i` 處的垂直線高度。從中選擇兩條線，求與x軸共同形成的容器所能盛裝的**最大水量**。容器的水量由「兩條線之間的距離 × 兩條線中較短者的高度」決定。

## 核心思路

從容器寬度最大的狀態（兩端）開始，將較短一方的指標向內移動，如此既保留了因高度增加而改善面積的可能性，又能高效地探索所有配對。移動較短一方的原因是：寬度必然縮小，若高度不增加，面積就不會改善。

## 思考過程

1. **整理面積的計算公式**：兩條線 `i` 和 `j`（i < j）所形成的容器面積為 `(j - i) × min(height[i], height[j])`。要最大化面積，需要使「寬度」與「高度最小值」的乘積最大化
2. **從寬度最大的狀態開始**：要使寬度最大，選擇左端（索引0）和右端（索引 n-1）兩條線即可。從這個狀態開始探索，就能從最大寬度出發
3. **決定移動哪個指標**：寬度向內移動時必定減少1。要改善面積只能增加高度。容器的高度由兩條線中較短者決定，因此移動較短一方的指標，就有機會遇到更高的線。相反，移動較長一方，較短一方仍然是瓶頸，面積不會改善
4. **在每一步記錄面積**：每次移動指標後計算新的面積，與目前的最大值進行比較並更新。如此便能得到與全域搜索相同的結果
5. **決定終止條件**：當左指標與右指標相遇時，所有有希望的配對都已檢查完畢，因此結束探索
6. **最終返回的值**：返回探索過程中記錄的面積最大值 `maxarea`

## 前置知識

### Two Pointers（雙指標）

在陣列的兩端或不同位置放置兩個指標（索引），根據條件移動其中一方或雙方來進行探索的技巧。在能夠利用條件將檢查所有配對的O(n²)探索降低為O(n)時，此方法特別有效。

```java
int left = 0;                      // 將左指標放在陣列的開頭
int right = height.length - 1;     // 將右指標放在陣列的末尾
while (left < right) {             // 持續迴圈直到兩個指標相遇
    // 移動 left 或 right
    left++;   // 將左指標向右移動一步
    right--;  // 將右指標向左移動一步
}
```

### Math.min / Math.max

`Math.min(a, b)` 返回兩個值中較小者，`Math.max(a, b)` 返回較大者。用於取得容器的高度（較短的線）以及更新面積的最大值。

```java
Math.min(3, 7);          // 返回兩者中較小者 → 3
Math.max(10, 25);        // 返回兩者中較大者 → 25
```

### 容器面積的計算

兩條線 `left` 和 `right` 所形成的容器面積，由寬度 × 高度求得。高度由兩條線中較短者決定。

```java
int width = right - left;                              // 寬度 = 兩條線之間的距離
int minHeight = Math.min(height[left], height[right]);  // 高度 = 較短的線的高度
int area = width * minHeight;                           // 面積 = 寬度 × 高度
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 左右指標各向內移動一次，僅走訪陣列一遍 |
| Space | O(1) — 僅使用指標和儲存最大值的變數 |

## 程式碼

```java
// 輸入：非負整數陣列 height（每個元素為垂直線的高度）
// 輸出：以 int 返回兩條線與x軸所形成的容器能盛裝的最大水量
public int maxArea(int[] height) {
    // 記錄探索過程中找到的面積最大值的變數，以0初始化
    int maxarea = 0;
    // 將左指標放在陣列的開頭，從寬度最大的狀態開始探索
    int left = 0;
    // 將右指標放在陣列的末尾
    int right = height.length - 1;

    // 持續迴圈直到兩個指標相遇。相遇時所有有希望的配對都已檢查完畢
    while (left < right) {
        // 寬度 = 兩條線之間的距離
        int width = right - left;
        // 高度 = 較短的線的高度。容器的水量由較短的線決定
        int minHeight = Math.min(height[left], height[right]);
        // 面積 = 寬度 × 高度
        int area = width * minHeight;

        // 與目前的最大值進行比較並更新
        maxarea = Math.max(area, maxarea);

        // 將較短一方的指標向內移動。寬度必然縮小，若高度不增加，面積就不會改善
        // 移動較長一方，較短一方仍然是瓶頸，面積不會改善
        if (height[left] <= height[right]) {
            // 左邊的線較短（或相同），因此將左指標向右移動一步以期改善高度
            left++;
        } else {
            // 右邊的線較短，因此將右指標向左移動一步以期改善高度
            right--;
        }
    }
    // 返回探索過程中記錄的面積最大值
    return maxarea;
}
```
