# Designing a Simplified Twitter Feed — 設計一個從多個用戶的推文中高效獲取最新10條的系統

## 問題的本質

實作一個簡化版 Twitter 系統的四種操作。使用 `postTweet` 發布推文，使用 `getNewsFeed` 從該用戶及其關注用戶的推文中獲取**最新10條**，使用 `follow` 進行關注，使用 `unfollow` 取消關注。核心課題在於，將多個用戶的推文列表**按時間順序合併，並高效地提取前10條**。

## 核心思路

每個用戶的推文列表已經按發布順序（時間順序）排序。從多個已排序列表中取出前 K 條的問題，不需要對所有列表重新排序，而是使用**堆積進行 K-way 合併**，僅比較各列表的頭部元素，逐一取出，即可以最少的比較次數解決。

## 思考過程

1. **決定資料的儲存方式**：需要按時間順序管理每個用戶發布的推文。使用以用戶 ID 為鍵、推文列表為值的 HashMap，即可以 O(1) 獲取任意用戶的推文列表。為每條推文賦予全域時間戳以記錄發布順序
2. **決定關注關係的管理方式**：關注與取消關注對應於用戶 ID 集合的新增與刪除。使用以用戶 ID 為鍵、關注對象 ID 的 Set 為值的 HashMap，即可以 O(1) 完成關注新增、刪除及列表獲取
3. **看透新聞動態獲取的本質**：`getNewsFeed` 是從自己及所有關注用戶的推文中返回最新10條的操作。由於每個用戶的推文列表已按發布順序排序，因此這可以歸結為**從多個已排序列表中取出前 K 條的問題（K-way 合併）**
4. **使用堆積進行 K-way 合併**：將每個用戶推文列表的末尾（最新推文）放入 Max-Heap。從堆積中取出時間戳最大的元素，然後將該用戶的下一條較新推文加入堆積。重複此操作10次即可獲得最新10條
5. **決定堆積中每個元素需要攜帶的資訊**：為了在從堆積取出後能夠添加同一用戶的下一條推文，每個條目需要攜帶「時間戳」「推文 ID」「用戶 ID」「列表中的索引」這四項資訊。將索引減1即可存取該用戶的下一條較新推文
6. **取得10條後提前終止**：當堆積為空或結果列表達到10條時，終止迴圈。不需要處理所有推文

## 前置知識

### PriorityQueue（優先佇列／堆積）是什麼

一種每次添加元素時會自動按優先順序排列的資料結構。可以用 O(log N) 取出優先度最高的元素。Java 的 PriorityQueue 預設為 Min-Heap（最小值在頂部），但可以透過指定 Comparator 變更為 Max-Heap（最大值在頂部）。

```java
// 建立 Max-Heap（時間戳越大＝越新的排在頂部）
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[0] - a[0]);
pq.offer(new int[]{5, 101});   // 添加 [時間戳, 推文ID]
pq.offer(new int[]{3, 102});   // 添加後，內部按時間戳降序排列
int[] top = pq.poll();         // 取出具有最大時間戳的元素 → [5, 101]
pq.isEmpty();                  // 以 boolean 返回堆積是否為空 → false
```

### computeIfAbsent 是什麼

當 HashMap 的鍵不存在時，才使用指定的函式生成值並註冊，然後返回該值的方法。當鍵已存在時，直接返回現有的值。可以將 `get`、`null` 檢查、`put` 這三個步驟合併為一行。

```java
Map<Integer, List<int[]>> tweets = new HashMap<>();
// 若鍵1不存在，則建立新的 ArrayList 並註冊，然後返回該列表
tweets.computeIfAbsent(1, k -> new ArrayList<>()).add(new int[]{0, 101});
// 鍵1已存在，因此返回現有的列表，並向其中添加元素
tweets.computeIfAbsent(1, k -> new ArrayList<>()).add(new int[]{1, 102});
```

### K-way 合併是什麼

將 K 個已排序列表整合為一個已排序序列的手法。僅將各列表的頭部元素放入堆積，每次取出最小（或最大）元素時，將該元素所屬列表的下一個元素加入堆積。相比將所有元素一起排序的 O(N log N)，可以更高效地以 O(N log K) 完成整合。

## 計算量

| | 值 |
|---|---|
| Time | O(K log K) — K 為關注中的用戶數。堆積的初始插入需要 O(K log K)，最多10次的 poll/offer 需要 O(10 log K) |
| Space | O(K) — 堆積中最多同時儲存 K 個元素 |

## 程式碼

```java
// 輸入：postTweet(userId, tweetId)、follow(followerId, followeeId)、unfollow(followerId, followeeId)、getNewsFeed(userId) 的各操作呼叫
// 輸出：getNewsFeed 從用戶及其關注對象的推文中，以 List<Integer> 返回最新10條推文 ID
class Twitter {
    // 全域時間戳。在所有用戶的推文之間唯一識別發布順序（單調遞增）
    int time = 0;
    // 鍵=用戶 ID，值=該用戶的推文列表（每個元素為 [時間戳, 推文ID]）
    // 列表按發布順序追加到末尾，因此末尾為最新
    Map<Integer, List<int[]>> tweets;
    // 鍵=關注方的用戶 ID，值=關注對象用戶 ID 的 Set
    // 使用 Set 可以讓關注新增、刪除、去重都在 O(1) 內完成
    Map<Integer, Set<Integer>> follows;

    Twitter() {
        tweets = new HashMap<>();
        follows = new HashMap<>();
    }

    void postTweet(int userId, int tweetId) {
        // 獲取用戶的推文列表（若不存在則建立），並在末尾添加 [時間戳, 推文ID]
        // 由於 time++ 全域單調遞增，因此可以在所有用戶之間正確比較發布順序
        tweets.computeIfAbsent(userId, k -> new ArrayList<>())
            .add(new int[]{time++, tweetId});
    }

    void follow(int followerId, int followeeId) {
        // 將 followeeId 添加到關注對象 Set 中（由於是 Set，重複關注同一用戶也不會產生重複）
        follows.computeIfAbsent(followerId, k -> new HashSet<>())
            .add(followeeId);
    }

    void unfollow(int followerId, int followeeId) {
        // 僅在關注關係存在時，從 Set 中刪除 followeeId。若不存在則不做任何操作
        if (follows.containsKey(followerId))
            follows.get(followerId).remove(followeeId);
    }

    List<Integer> getNewsFeed(int userId) {
        // Max-Heap：指定 Comparator 使時間戳較大（較新）的排在頂部
        PriorityQueue<int[]> pq =
            new PriorityQueue<>((a, b) -> b[0] - a[0]);

        // 動態消息的目標用戶 = 自己 + 所有關注中的用戶
        // 由於自己的推文也需要包含在動態消息中，因此不要忘記添加自己
        Set<Integer> users = new HashSet<>();
        users.add(userId);
        if (follows.containsKey(userId))
            users.addAll(follows.get(userId));

        // 將每個用戶的最新推文（列表末尾）添加到堆積中
        // 包含用戶 ID 和索引是為了在取出後能追溯該用戶的下一條推文
        for (int uid : users) {
            if (!tweets.containsKey(uid)) continue;
            List<int[]> t = tweets.get(uid);
            int idx = t.size() - 1;
            int[] tw = t.get(idx);
            // 包含 [時間戳, 推文ID, 用戶ID, 列表內索引] 的4元素陣列
            pq.offer(new int[]{tw[0], tw[1], uid, idx});
        }

        // 從堆積中取出最多10條（堆積為空或達到10條時提前終止）
        List<Integer> res = new ArrayList<>();
        while (!pq.isEmpty() && res.size() < 10) {
            // 取出時間戳最大的元素
            int[] top = pq.poll();
            // 將取出的推文 ID 添加到結果中
            res.add(top[1]);
            int uid = top[2];
            // 將索引減1，指向該用戶的下一條較新推文
            int idx = top[3] - 1;
            // 若該用戶還有推文則添加到堆積中（索引為負表示已全部處理完畢）
            if (idx >= 0) {
                int[] tw = tweets.get(uid).get(idx);
                pq.offer(new int[]{tw[0], tw[1], uid, idx});
            }
        }
        // 最新10條（或推文總數少於10條時為全部）的推文 ID 按時間戳降序儲存
        return res;
    }
}
```
