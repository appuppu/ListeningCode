# Deriving the Order of an Alien Alphabet — 還原外星語言的字母順序

## 問題的本質

給定一個按照外星語言的字典序排列的單詞列表 `words`。根據這個排列順序，推斷該語言中字母的順序，並以字串形式返回。如果順序存在矛盾（存在循環，或較短的單詞排在較長單詞之後等），則返回空字串 `""`。

## 核心思路

比較相鄰的兩個單詞，可以從「第一個不同的字母」中獲得一個順序關係（有向邊）。將所有相鄰對中獲得的順序關係構建為有向圖，再透過 DFS 拓撲排序來決定整體順序。如果存在循環，則表示順序存在矛盾。

## 思考過程

1. **從相鄰單詞的比較中提取順序關係**：在已排序的列表中，比較相鄰的兩個單詞 `words[i]` 和 `words[i+1]`，從頭開始逐字比較，找到第一對不同的字母 `(a, b)` 時，就能確定「a 排在 b 之前」這一順序關係。這個關係可以表示為有向圖的邊 `a → b`
2. **檢測無效輸入**：如果 `words[i]` 是 `words[i+1]` 的前綴匹配且 `words[i]` 更長（例如：`"abc"` 排在 `"ab"` 之前），則違反字典序規則，應立即返回空字串
3. **將所有字母註冊為節點**：因為有些字母可能沒有順序關係，所以需要將所有單詞中的所有字母都註冊為圖的節點。這樣可以確保沒有邊的字母也能包含在結果中
4. **透過 DFS 拓撲排序決定整體順序**：對有向圖執行 DFS，在每個節點探索完成時將其加入列表。將 DFS 的後序（post-order）反轉後，即可獲得拓撲順序（依賴來源排在前面的順序）
5. **透過三色標記檢測循環**：在 DFS 過程中，將每個節點管理為「未訪問(0)」「探索中(1)」「已探索(2)」三種狀態。如果再次到達處於探索中的節點，則表示存在循環，順序無法確定，返回空字串
6. **反轉後構建字串**：將 DFS 的後序列表反轉以獲得拓撲順序。將列表中的所有字母連接起來，返回結果字串

## 前提知識

### 什麼是拓撲排序

將有向無環圖（DAG）的所有節點按照不違反邊的方向的順序排列成一列的操作。如果存在邊 `a → b`，則在結果中 `a` 一定排在 `b` 之前。存在循環的圖不存在拓撲順序。

### 什麼是 DFS 的三色標記

在 DFS 中用三種顏色管理每個節點狀態的方法。白色(0)表示未訪問，灰色(1)表示位於當前探索路徑上（存在於遞迴堆疊中），黑色(2)表示探索完成。當再次到達灰色節點時，即可確定存在循環。

```java
Map<Character, Integer> color = new HashMap<>();
color.put('a', 0);  // 白色: 未訪問
color.put('a', 1);  // 灰色: 探索中（位於遞迴堆疊上）
color.put('a', 2);  // 黑色: 探索完成（所有子孫已處理完畢）
```

### HashMap 和 HashSet 的基本操作

```java
// HashMap: 儲存鍵值對。搜尋與取得的時間複雜度為 O(1)
Map<Character, Set<Character>> adj = new HashMap<>();
adj.putIfAbsent('a', new HashSet<>());  // 僅在鍵未註冊時才註冊空的 Set
adj.get('a').add('b');                  // 將 'b' 加入鍵 'a' 的鄰接列表中

// HashSet: 不含重複元素的集合。新增與搜尋的時間複雜度為 O(1)
Set<Character> set = new HashSet<>();
set.add('b');        // 新增元素
set.contains('b');   // 判斷元素是否存在 → true
```

### startsWith 方法

判斷字串是否以指定的前綴開頭。

```java
"abc".startsWith("ab");  // true — "abc" 以 "ab" 開頭
"ab".startsWith("abc");  // false — "ab" 不以 "abc" 開頭
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(C) — C 為所有單詞的總字元數。構建圖需要遍歷所有字元，DFS 與節點數加邊數成正比，但兩者都不超過 C |
| Space | O(1) — 節點數最多為 26 個字母（英文小寫），為常數。邊數最多為 26²，也是常數。不依賴於輸入大小 |

## 程式碼

```java
// 輸入: 按照外星語言字典序排列的字串陣列 words
// 輸出: 表示字母順序的字串。如果存在矛盾則返回空字串 ""

// DFS: 透過三色標記檢測循環，同時記錄後序
boolean dfs(char c, Map<Character, Set<Character>> adj,
            Map<Character, Integer> color, List<Character> result) {
    // 再次到達灰色（探索中）節點 → 檢測到循環
    if (color.get(c) == 1) return false;
    // 黑色（已探索）→ 已處理完成，跳過該節點
    if (color.get(c) == 2) return true;

    // 將當前節點標記為灰色（探索中）
    color.put(c, 1);

    // 對所有鄰接節點（排在該字母之後的字母）遞迴執行 DFS
    for (char n : adj.get(c))
        if (!dfs(n, adj, color, result))
            return false;  // 在子孫中檢測到循環 → 立即傳播

    // 所有子孫的探索已完成，將該節點標記為黑色
    color.put(c, 2);
    // 按後序加入列表（在 DFS 中依賴目標會先被加入，因此反轉後即為拓撲順序）
    result.add(c);
    return true;
}

public String alienOrder(String[] words) {
    // 鄰接列表: 鍵=字母，值=排在該字母之後的字母集合
    Map<Character, Set<Character>> adj = new HashMap<>();

    // 將所有單詞中的所有字母註冊為圖的節點
    // 因為沒有順序關係（邊）的字母也需要包含在結果中，所以在此時註冊所有字母
    for (String w : words)
        for (char c : w.toCharArray())
            adj.putIfAbsent(c, new HashSet<>());

    // 比較相鄰的兩個單詞，提取順序關係（有向邊）
    for (int i = 0; i < words.length - 1; i++) {
        String w1 = words[i];
        String w2 = words[i + 1];

        // 檢測無效輸入: 較長的單詞排在較短前綴之前的情況（例如: ["abc","ab"] 存在矛盾）
        if (w1.length() > w2.length() && w1.startsWith(w2))
            return "";

        int len = Math.min(w1.length(), w2.length());
        for (int j = 0; j < len; j++) {
            if (w1.charAt(j) != w2.charAt(j)) {
                // 從第一個不同的字母中獲得一個順序關係，並立即跳出迴圈
                // 第二個及之後的差異僅在前面的字母相同時才有意義，因此只提取一個
                adj.get(w1.charAt(j)).add(w2.charAt(j));
                break;
            }
        }
    }

    // 建立三色管理映射，將所有節點初始化為白色(0: 未訪問)
    Map<Character, Integer> color = new HashMap<>();
    for (char c : adj.keySet())
        color.put(c, 0);

    // 記錄 DFS 後序的列表
    List<Character> result = new ArrayList<>();

    // 對所有節點執行 DFS（為了處理非連通圖，以所有節點為起點）
    for (char c : adj.keySet())
        if (!dfs(c, adj, color, result))
            return "";  // 檢測到循環 → 順序無法確定

    // 反轉後序以獲得拓撲順序
    Collections.reverse(result);

    // 連接所有字母以構建結果字串
    StringBuilder sb = new StringBuilder();
    for (char c : result) sb.append(c);
    return sb.toString();
}
```
