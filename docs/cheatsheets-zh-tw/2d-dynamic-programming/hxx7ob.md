# Counting Unique Paths in a Grid — 計算網格從左上角到右下角的唯一路徑數

## 問題的本質

給定一個 `m × n` 的網格。從左上角的格子 `(0, 0)` 到右下角的格子 `(m-1, n-1)`，每一步只能**向右或向下**移動，求唯一路徑的總數。

## 核心思路

到達某個格子的路徑數等於「到達上方格子的路徑數」與「到達左方格子的路徑數」之和。利用這個遞推公式從底部向上填充即可求得答案，而且每一行的計算僅依賴前一行與當前行，因此只需一行大小的陣列即可節省空間。

## 思考過程

1. **到達每個格子的路徑數可以分解為子問題**：要到達格子 `(i, j)`，必定從上方 `(i-1, j)` 或左方 `(i, j-1)` 而來。因此遞推公式 `dp[i][j] = dp[i-1][j] + dp[i][j-1]` 成立
2. **確定基底情況**：最上行的格子只能從左方到達，最左列的格子只能從上方到達。兩者的路徑數都是 1，因此以 `dp[0][j] = 1`、`dp[i][0] = 1` 進行初始化
3. **逐行從左到右填充**：遞推公式依賴的是「上方一格」和「左方一格」，所以從上到下逐行、每行內從左到右掃描，所需的值必定已經計算完成
4. **空間可壓縮為一行**：`dp[i][j]` 僅依賴同一行的左鄰 `dp[i][j-1]` 和前一行的同一列 `dp[i-1][j]`。使用一維陣列 `dp[j]` 時，更新前的 `dp[j]` 相當於「上方格子的值」，已更新的 `dp[j-1]` 相當於「左方格子的值」，因此可用 `dp[j] += dp[j-1]` 來表達遞推公式
5. **初始化所有元素為 1**：將一維陣列全部初始化為 1，即表示最上行（每個格子的路徑數為 1）的狀態。對應最左列的 `dp[0]` 在內層迴圈中不會被更新，因此始終保持為 1，最左列的基底情況也自然維持
6. **最終回傳值**：處理完所有行之後，`dp[n-1]` 保存的就是到達右下角格子的路徑數，將其回傳即可

## 前置知識

### 什麼是 Arrays.fill

這是一個將陣列的所有元素一次性初始化為指定值的工具方法。無需撰寫迴圈即可將陣列填充為統一的值。

```java
int[] dp = new int[5];       // 建立長度為 5 的陣列（初始值全部為 0）
Arrays.fill(dp, 1);          // 將所有元素設為 1 → [1, 1, 1, 1, 1]
```

### 什麼是一維 DP 空間壓縮

在二維 DP 表格中，當每個格子的計算僅依賴「當前行」和「前一行」時，可以將二維陣列替換為一維陣列的技巧。透過逐行覆寫更新陣列，將空間從 O(m×n) 降低至 O(n)。

```java
// 二維情況: dp[i][j] = dp[i-1][j] + dp[i][j-1]
// 壓縮為一維: dp[j] += dp[j-1]
//   dp[j]（更新前）= 前一行同一列的值（相當於 dp[i-1][j]）
//   dp[j-1]（已更新）= 當前行左鄰的值（相當於 dp[i][j-1]）
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(m × n) — 對網格的每個格子掃描一次 |
| Space | O(n) — 僅保存一行大小的陣列 |

## 程式碼

```java
// 輸入: 整數 m（行數）與整數 n（列數）
// 輸出: 以整數回傳從左上角到右下角的唯一路徑數
public int uniquePaths(int m, int n) {
    // 建立長度為 n 的一行 DP 陣列，並將所有元素初始化為 1
    // 全部設為 1，藉此設定最上行的基底情況（每個格子的路徑數為 1）
    int[] dp = new int[n];
    Arrays.fill(dp, 1);

    // i=0（最上行）已透過初始化設定完成，因此從 i=1 開始
    for (int i = 1; i < m; i++) {
        // j=0（最左列）應始終保持為 1，因此從 j=1 開始
        for (int j = 1; j < n; j++) {
            // dp[j]（更新前）= 前一行同一列的值（從上方來的路徑數）
            // dp[j-1]（已更新）= 當前行左鄰的值（從左方來的路徑數）
            // 透過這個加法，在一維陣列上實現遞推公式 dp[i][j] = dp[i-1][j] + dp[i][j-1]
            dp[j] += dp[j - 1];
        }
    }

    // dp[n-1] 保存的是到達網格右下角格子 (m-1, n-1) 的唯一路徑數
    return dp[n - 1];
}
```
