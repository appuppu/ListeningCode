# Implementing Regular Expression Matching — 判定字串是否與模式完全匹配

## 問題的本質

給定輸入字串 `s` 和模式 `p`。模式中的 `.` 匹配任意一個字元，`*` 表示前一個字元重複零次或多次。以 `boolean` 回傳模式是否與字串**整體**匹配。

## 核心思路

從字串和模式的末尾向開頭填充二維 DP 表。`dp[i][j]` 表示「`s[i:]` 是否與 `p[j:]` 匹配」，當存在 `*` 時，問題歸結為兩種選擇：「前一個字元使用 0 次（跳過）」或「使用 1 次並將字串前進一位」。

## 思考過程

1. **可以分解為子問題**：確定字串的位置 `i` 和模式的位置 `j` 後，就形成「`s[i:]` 是否與 `p[j:]` 匹配」這個子問題。將該子問題的答案儲存在 `dp[i][j]` 中，即可避免重複計算
2. **判定當前位置的字元是否匹配**：如果 `s[i]` 與 `p[j]` 是相同字元，或者 `p[j]` 是 `.`，則當前位置的一個字元匹配。將此判定結果儲存在變數 `match` 中
3. **考慮存在 `*` 時的兩種選擇**：當 `p[j+1]` 是 `*` 時，「`x*`」模式有兩種解釋方式。第一種是「匹配 0 次（跳過）」，整個跳過 `x*` 並參照 `dp[i][j+2]`。第二種是「匹配 1 次以上」，如果當前字元匹配，則將字串前進一位並參照 `dp[i+1][j]`（模式側不前進，因為下一個位置可能繼續透過 `*` 重複）
4. **沒有 `*` 時單純逐字元前進**：如果當前字元匹配，則將字串和模式都前進一位的 `dp[i+1][j+1]` 即為答案
5. **設定基底情況**：字串和模式都到達末尾的狀態 `dp[n][m]` 為 `true`。字串尚有剩餘但模式已到末尾時為 `false`，模式尚有剩餘但字串已到末尾時，只有透過 `*` 跳過才可能為 `true`
6. **從末尾向開頭填充表格**：`dp[i][j]` 的計算依賴於 `dp[i][j+2]`、`dp[i+1][j]`、`dp[i+1][j+1]`。這些值都位於 `i` 或 `j` 較大的方向，因此將 `i` 從 `n` 到 `0`、`j` 從 `m-1` 到 `0` 逆序遍歷，參照的值一定已經計算完畢
7. **最終回傳的值**：表格的 `dp[0][0]` 就是「字串整體是否與模式整體匹配」的答案

## 前置知識

### 何謂二維 DP 表

針對兩個變數（此處為字串的位置 `i` 和模式的位置 `j`）的每種組合，儲存子問題答案的二維陣列。以 `boolean[][] dp = new boolean[n+1][m+1]` 建立，在 `dp[i][j]` 中存放 `s[i:]` 與 `p[j:]` 的匹配結果。

```java
boolean[][] dp = new boolean[n + 1][m + 1];  // 建立以 false 初始化的 (n+1)×(m+1) 表格
dp[n][m] = true;                              // 基底情況：兩者都到達末尾則匹配
dp[i][j] = dp[i][j + 2];                     // 參照其他儲存格的值來填充當前儲存格
```

### String.length() 與 String.charAt()

`length()` 回傳字串的長度。`charAt(i)` 回傳索引 `i` 處的字元。索引從 0 開始，存取超出範圍時會拋出例外。

```java
String s = "abc";
s.length();     // → 3
s.charAt(0);    // → 'a'
s.charAt(2);    // → 'c'
```

### `*`（星號）的意義

正規表達式中的 `*` 表示「前一個字元重複零次或多次」。`a*` 可匹配 `""`、`"a"`、`"aa"`、`"aaa"` 等任意情況。`.*` 表示「任意字元重複零次或多次」，因此可匹配任何字串。`*` 不會單獨使用，必定與前一個字元組成 `x*` 的形式。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n×m) — 對 n×m 的 DP 表中每個儲存格各計算一次 |
| Space | O(n×m) — 儲存 n×m 的 DP 表 |

## 程式碼

```java
// 輸入：字串 s 和模式 p
// 輸出：以 boolean 回傳 s 整體是否與 p 匹配
public boolean isMatch(String s, String p) {
    int n = s.length();  // 字串的長度
    int m = p.length();  // 模式的長度

    // dp[i][j] = 儲存「s[i:] 是否與 p[j:] 匹配」的二維表格
    // 索引 n 和 m 表示空字串，因此大小需要 +1
    boolean[][] dp = new boolean[n + 1][m + 1];

    // 基底情況：兩個字串都到達末尾時匹配成功
    dp[n][m] = true;

    // 從末尾向開頭填充表格
    // 此遍歷順序確保參照的 dp[i][j+2]、dp[i+1][j]、dp[i+1][j+1] 皆已計算完畢
    for (int i = n; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // 判定當前位置的一個字元是否匹配
            // 先判定 i < n，以防止字串到達末尾時 charAt 存取超出範圍
            boolean match = i < n
                && (s.charAt(i) == p.charAt(j)
                    || p.charAt(j) == '.');

            // 以 j+1 < m 進行範圍檢查，判定模式的當前位置是否為 x* 的形式
            if (j + 1 < m && p.charAt(j + 1) == '*') {
                // 取 x* 模式兩種選擇的 OR（邏輯或）：
                // dp[i][j+2]：匹配 0 次（整個跳過 x*）
                // match && dp[i+1][j]：匹配 1 次並將字串前進（模式側不前進，因為可能透過 * 繼續重複，所以 j 保持不變）
                dp[i][j] = dp[i][j + 2]
                    || (match && dp[i + 1][j]);
            } else {
                // 一般字元：如果一個字元匹配，則將字串和模式都前進一位
                dp[i][j] = match
                    && dp[i + 1][j + 1];
            }
        }
    }

    // dp[0][0] 是「字串 s 整體是否與模式 p 整體匹配」的最終答案
    return dp[0][0];
}
```
