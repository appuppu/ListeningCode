# Checking if a String is an Interleaving of Two Others — 判斷兩個字串交錯混合後能否組成第三個字串

## 問題的本質

給定三個字串 `s1`、`s2`、`s3`。判斷 `s3` 是否由 `s1` 和 `s2` 的**交錯混合（Interleaving）**所組成。交錯混合是指用盡 `s1` 和 `s2` 的所有字元，並且保持各自字串內字元的相對出現順序不變，將它們混合在一起。

## 核心思路

可以將問題分解為以下子問題：`s1` 的前 `i` 個字元與 `s2` 的前 `j` 個字元，能否組成 `s3` 的前 `i+j` 個字元。在每個位置上，「下一個字元從 `s1` 取還是從 `s2` 取」這兩種選擇，可以透過 DP 表格來高效判定。

## 思考過程

1. **確認長度的前提條件**：若 `s3` 是 `s1` 和 `s2` 的交錯混合，則 `s3` 的長度必須等於 `s1` 的長度 + `s2` 的長度。若不相等，可以立即回傳 `false`
2. **定義子問題**：將 `dp[i][j]` 定義為「`s1` 的前 `i` 個字元與 `s2` 的前 `j` 個字元，能否組成 `s3` 的前 `i+j` 個字元」。根據此定義，`dp[m][n]`（`m` 為 `s1` 的長度，`n` 為 `s2` 的長度）即為最終答案
3. **推導轉移方程式**：`dp[i][j]` 為 `true` 的情況有以下兩種。情況一：`dp[i-1][j]` 為 `true` 且 `s1` 的第 `i` 個字元與 `s3` 的第 `i+j` 個字元相同（從 `s1` 取一個字元）。情況二：`dp[i][j-1]` 為 `true` 且 `s2` 的第 `j` 個字元與 `s3` 的第 `i+j` 個字元相同（從 `s2` 取一個字元）
4. **定義基礎情況**：當 `i=0` 且 `j=0` 時，尚未從任一字串取出字元，此為初始狀態，與 `s3` 的前 0 個字元（空字串）一致，因此設定 `dp[0][0] = true`
5. **最佳化空間複雜度**：二維的 `dp[i][j]` 在計算第 `i` 行時只使用第 `i-1` 行的值。因此一維陣列 `dp[j]` 即已足夠，`dp[j]` 更新前的值相當於前一行（`dp[i-1][j]`），`dp[j-1]` 更新後的值相當於當前行的左鄰（`dp[i][j-1]`）
6. **最終回傳值**：外層迴圈從 `i = 0` 到 `m`，內層迴圈從 `j = 0` 到 `n` 執行完畢後，`dp[n]` 即為 `s3` 整體能否由交錯混合組成的答案

## 前置知識

### 什麼是 DP（動態規劃）的一維陣列空間最佳化

在二維 DP 表格 `dp[i][j]` 中，若每一行的計算僅依賴前一行，則可以用一維陣列 `dp[j]` 來替代。透過逐行覆寫更新陣列，將空間複雜度從 O(m×n) 降低至 O(n)。

```java
// 二維的情況: dp[i][j] 參照 dp[i-1][j] 和 dp[i][j-1]
boolean[][] dp = new boolean[m + 1][n + 1];

// 最佳化為一維: 逐行覆寫 dp[j]
boolean[] dp = new boolean[n + 1];
// dp[j] 更新前的值 → 相當於前一行的 dp[i-1][j]
// dp[j-1] 更新後的值 → 相當於當前行的 dp[i][j-1]
```

### 什麼是 String.charAt(index)

此方法回傳字串中指定位置的字元。索引從 0 開始。

```java
String s = "abc";
s.charAt(0);  // 回傳 'a'
s.charAt(2);  // 回傳 'c'
```

### 什麼是交錯混合（Interleaving）

交錯混合是指將兩個字串的字元在保持各自相對順序的前提下混合，組成一個新的字串。
例如：`s1 = "aab"`、`s2 = "axy"` 時，`"aaxaby"` 是交錯混合（`s1` 的 a,a,b 和 `s2` 的 a,x,y 各自的順序都被保持）。`"abaaxy"` 因為 `s1` 的字元順序被打亂，所以不是交錯混合。

## 複雜度

| | 值 |
|---|---|
| Time | O(m×n) — 對 `s1` 的長度 `m` 和 `s2` 的長度 `n` 執行一次雙重迴圈 |
| Space | O(n) — 僅使用大小為 `s2` 的長度+1 的一維 DP 陣列 |

## 程式碼

```java
// 輸入: 字串 s1（長度 m）、字串 s2（長度 n）、字串 s3
// 輸出: 以 boolean 回傳 s3 是否能由 s1 和 s2 的交錯混合組成
public boolean isInterleave(String s1, String s2, String s3) {
    int m = s1.length();
    int n = s2.length();

    // 若 m + n 與 s3 的長度不一致，則交錯混合不可能成立
    if (m + n != s3.length())
        return false;

    // dp[j] = s1 的前 i 個字元與 s2 的前 j 個字元能否組成 s3 的前 i+j 個字元
    // 透過逐行覆寫一維陣列，將二維表格的空間壓縮至 O(n)
    boolean[] dp = new boolean[n + 1];

    // 外層迴圈: i 表示從 s1 取出的字元數（0〜m）
    for (int i = 0; i <= m; i++) {
        // 內層迴圈: j 表示從 s2 取出的字元數（0〜n）
        for (int j = 0; j <= n; j++) {
            if (i == 0 && j == 0) {
                // 基礎情況: 尚未從任一字串取出字元，與 s3 的空字串一致
                dp[j] = true;
            } else {
                // 條件一（從 s1 取）: dp[j] 更新前的值（前一行 = 相當於 dp[i-1][j]）為 true
                //   且 s1 的第 i 個字元與 s3 的第 i+j 個字元相同
                // 條件二（從 s2 取）: dp[j-1] 更新後的值（當前行的左鄰 = 相當於 dp[i][j-1]）為 true
                //   且 s2 的第 j 個字元與 s3 的第 i+j 個字元相同
                // 注意: 內層迴圈的 j 從左向右遍歷，因此 dp[j] 尚未被覆寫，仍保持前一行的值，
                //   而 dp[j-1] 已被覆寫，保持的是當前行的值
                dp[j] =
                    (dp[j] && i > 0
                    && s1.charAt(i - 1)
                    == s3.charAt(i + j - 1))
                    || (j > 0
                    && dp[j - 1]
                    && s2.charAt(j - 1)
                    == s3.charAt(i + j - 1));
            }
        }
    }

    // dp[n] 為 s1 的全部 m 個字元與 s2 的全部 n 個字元能否組成 s3 的全部 m+n 個字元的結果
    return dp[n];
}
```
