# Finding the Longest Common Subsequence — 求兩個字串的最長公共子序列長度

## 問題的本質

給定兩個字串 `text1` 和 `text2`。返回兩個字串共有的**子序列（subsequence）**中最長的**長度**。子序列是從原始字串中選取字元並保持相對順序所形成的序列，不需要連續。

## 核心思路

如果兩個字串的末尾字元相同，則該字元包含在LCS中，剩餘的子問題是將兩個字串各縮短一個字元。如果不相同，則從將其中一方縮短一個字元的兩個子問題中，採用較長的結果。透過在二維表格中自底向上填寫此遞迴結構，可以在不重複計算的情況下求得最佳解。

## 思考過程

1. **子問題的定義**：將 `text1` 的前 `i` 個字元與 `text2` 的前 `j` 個字元的LCS長度定義為 `dp[i][j]`。最終要求的答案是 `dp[m][n]`（`m` = text1的長度、`n` = text2的長度）
2. **末尾字元相同時的轉移**：當 `text1[i-1] == text2[j-1]` 時，該字元成為LCS的一部分。因此 `dp[i][j] = dp[i-1][j-1] + 1`。將兩個字串各縮短一個字元的子問題答案加1
3. **末尾字元不同時的轉移**：當 `text1[i-1] != text2[j-1]` 時，至少有一方的末尾字元不包含在LCS中。採用將 `text1` 縮短一個字元的情況（`dp[i-1][j]`）與將 `text2` 縮短一個字元的情況（`dp[i][j-1]`）中較大的值。即 `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
4. **基底條件**：當任一字串為空（長度為0）時，不存在公共子序列，因此 `dp[0][j] = 0` 及 `dp[i][0] = 0`。在Java中生成 `int[][]` 時所有元素會初始化為0，因此不需要明確設定
5. **表格的填寫方式**：`dp[i][j]` 依賴於 `dp[i-1][j-1]`、`dp[i-1][j]`、`dp[i][j-1]`。因此將 `i` 從1到m、`j` 從1到n按升序填寫，則參照的值總是已計算完成的
6. **最終返回的值**：填完整個表格後，`dp[m][n]` 即為兩個完整字串的LCS長度，將其返回

## 前提知識

### 子序列（Subsequence）是什麼

從字串中刪除零個或多個字元，並保持剩餘字元的相對順序所取出的序列。與子字串（substring）不同，不需要連續。

```
字串: "abcde"
子序列的範例: "ace"（選取 a, c, e。刪除 b, d）
非子序列的範例: "aec"（違反原始字串中 a→c→e 的順序）
```

### 二維陣列的生成與初始化

在Java中宣告 `new int[m+1][n+1]` 時，會建立大小為 `(m+1) × (n+1)` 的二維陣列，所有元素初始化為0。

```java
int[][] dp = new int[m + 1][n + 1];  // 建立(m+1)行×(n+1)列的陣列，所有元素為0
dp[i][j] = 5;                         // 將值5賦值給第i行第j列
int val = dp[i][j];                    // 取得第i行第j列的值 → 5
```

### Math.max 是什麼

返回兩個整數中較大值的方法。用於比較兩個子問題的解，選擇較好的一方。

```java
Math.max(3, 7);    // 返回兩個值中較大的一方 → 7
Math.max(dp[i-1][j], dp[i][j-1]);  // 比較兩個儲存格的值並返回較大的一方
```

### charAt 是什麼

返回字串中指定位置字元的方法。索引從0開始。

```java
String s = "abc";
s.charAt(0);    // 返回索引0的字元 → 'a'
s.charAt(2);    // 返回索引2的字元 → 'c'
```

## 計算量

| | 值 |
|---|---|
| Time | O(m × n) — 將m×n表格的每個儲存格各填寫一次 |
| Space | O(m × n) — 使用大小為(m+1)×(n+1)的二維陣列 |

## 程式碼

```java
// 輸入：兩個字串 text1 和 text2
// 輸出：以 int 返回兩個字串的最長公共子序列長度
public int longestCommonSubsequence(String text1, String text2) {
    // 將text1的長度賦值給m、text2的長度賦值給n。用於表格大小和迴圈上限
    int m = text1.length();
    int n = text2.length();

    // dp[i][j] = text1的前i個字元與text2的前j個字元的LCS長度
    // 大小設為(m+1)×(n+1)是為了表示任一方為空字串的情況（基底條件）
    // 在Java中int[][]的所有元素初始化為0，因此基底條件 dp[0][j]=0, dp[i][0]=0 自動滿足
    int[][] dp = new int[m + 1][n + 1];

    // i表示正在考慮text1的前幾個字元
    for (int i = 1; i <= m; i++) {
        // j表示正在考慮text2的前幾個字元
        for (int j = 1; j <= n; j++) {
            // dp的索引從1開始，但字串的索引從0開始，因此用 i-1, j-1 來存取
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                // 字元相同時，相同的字元加入LCS，因此將兩方各縮短一個字元的子問題答案加1
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // 字元不同時，從將text1縮短一個字元的情況與將text2縮短一個字元的情況中，採用LCS較長的一方
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    // 表格右下角即為text1全體與text2全體的LCS長度
    return dp[m][n];
}
```
