# Counting Combinations to Make a Target Amount — 計算湊成目標金額的硬幣組合數量

## 問題的本質

給定一個包含硬幣面額的陣列 `coins` 和一個整數 `amount`。可以無限次重複使用 `coins` 中的硬幣，返回總和恰好為 `amount` 的**組合數量**。所謂不同的組合，是指至少有一種面額的使用枚數不同。僅順序不同的視為相同的組合。

## 核心思路

按順序逐一處理每種硬幣，對於每種硬幣，將「使用該硬幣 0 枚以上的組合數」累加到 DP 陣列中。透過將硬幣種類作為外層迴圈，可以自然地排除因不同順序而重複計算同一組硬幣的情況（排列）。

## 思考過程

1. **意識到組合與排列的區別**: 這道題要求的是「組合的數量」，因此 [1,2] 和 [2,1] 需要視為相同的組合來計數。如果將金額作為外層迴圈、在內層選擇硬幣，就會計算出排列數，因此需要將硬幣種類作為外層迴圈來固定處理順序
2. **定義 DP 的狀態**: 將 `dp[a]` 定義為「恰好湊成金額 `a` 的組合數量」。最終 `dp[amount]` 即為答案
3. **確定基底條件**: 湊成金額 0 的方法只有「不使用任何硬幣」這一種，因此設定 `dp[0] = 1`。如果沒有這個基底條件，無論使用哪種硬幣，組合數都會一直以 0 累加，答案將始終為 0
4. **推導轉移方程**: 要使用至少 1 枚硬幣 `coin` 來湊成金額 `a`，只需加上剩餘金額 `a - coin` 的組合數即可。即轉移方程為 `dp[a] += dp[a - coin]`。由於 `dp[a - coin]` 中已經包含了使用同一種硬幣 0 枚以上的組合數，因此這個加法會自動涵蓋「使用 coin 1 枚、2 枚、……」的所有情況
5. **決定迴圈順序**: 外層迴圈逐一處理每種硬幣，內層迴圈將金額 `a` 從 `coin` 到 `amount` 按升序遍歷。這樣一來，每種硬幣都是在「前面幾種硬幣的組合數」基礎上加上自己的貢獻，不會產生排列的重複計數
6. **最終返回的結果**: 處理完所有硬幣後的 `dp[amount]` 即為湊成目標金額的組合總數

## 前置知識

### DP 陣列（動態規劃的一維陣列）

將子問題的答案儲存在陣列中，並重複利用這些答案來高效地求解更大問題的方法。在這道題中，`dp[a]` 表示「湊成金額 `a` 的組合數量」。

```java
int[] dp = new int[amount + 1];  // 建立索引 0 到 amount 的陣列（初始值全部為 0）
dp[0] = 1;                       // 基底條件: 湊成金額 0 的方法有 1 種
dp[a] += dp[a - coin];           // 轉移: 將使用 1 枚 coin 後剩餘金額的組合數加到金額 a 的組合數上
```

### 將硬幣作為外層迴圈的原因

如果將金額作為外層、硬幣作為內層，在湊成金額 5 時會將 [1,2,2] 和 [2,1,2] 和 [2,2,1] 分別計數（排列）。將硬幣作為外層時，由於處理完硬幣 1 後才處理硬幣 2，「硬幣 1 → 硬幣 2」的順序被固定，因此只會計算組合。

```java
// 計算組合（正確的順序）
for (int coin : coins) {          // 外層: 逐一處理每種硬幣
    for (int a = coin; a <= amount; a++) {  // 內層: 遍歷金額
        dp[a] += dp[a - coin];
    }
}

// 會計算成排列（錯誤的順序）
for (int a = 1; a <= amount; a++) {         // 外層: 逐一處理每個金額
    for (int coin : coins) {                // 內層: 嘗試所有硬幣
        if (a >= coin) dp[a] += dp[a - coin];
    }
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n × amount) — 對 n 種硬幣的每一種，遍歷金額 0 到 amount |
| Space | O(amount) — 僅使用一個大小為 amount+1 的 DP 陣列 |

## 程式碼

```java
// 輸入: 儲存硬幣面額的整數陣列 coins 和目標金額的整數 amount
// 輸出: 以 int 返回總和恰好為 amount 的硬幣組合數量
public int change(int amount, int[] coins) {
    // dp[a] = 恰好湊成金額 a 的組合數量
    // 大小為 amount + 1（對應索引 0 到 amount 的每個金額）
    int[] dp = new int[amount + 1];

    // 基底條件: 湊成金額 0 的方法只有「什麼都不選」這 1 種
    // 如果沒有這個基底條件，轉移時累加的來源值始終為 0，所有結果都會變成 0
    dp[0] = 1;

    // 逐一處理每種硬幣（透過外層迴圈固定順序，只計算組合）
    // 將硬幣種類作為外層迴圈，防止將同一組硬幣以不同順序重複計數（排列）
    for (int coin : coins) {
        // 從金額 coin 到 amount 按升序遍歷
        // 從 coin 開始是因為 a - coin 必須大於等於 0
        // 按升序遍歷使得使用同一種硬幣多枚的情況能自然地被反映
        for (int a = coin; a <= amount; a++) {
            // 使用 1 枚 coin，加上剩餘金額 a-coin 的組合數
            // 由於 dp[a - coin] 中已包含使用同一種硬幣 0 枚以上的組合數，
            // 這一行就涵蓋了「使用 coin 1 枚、2 枚、3 枚……」的所有情況
            dp[a] += dp[a - coin];
        }
    }

    // 返回湊成目標金額的組合總數
    return dp[amount];
}
```
