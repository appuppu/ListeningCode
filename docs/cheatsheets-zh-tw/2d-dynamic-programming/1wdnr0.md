# Finding the Minimum Edits to Transform One String Into Another — 求兩個字串之間的最小編輯距離

## 問題的本質

給定兩個字串 `word1` 和 `word2`。請回傳將 `word1` 轉換為 `word2` 所需的**最少操作次數**。可使用的操作有「插入」「刪除」「替換」三種，每種操作各計為一次。

## 核心思路

從兩個字串的末尾開始比較時，若當前字元相同則不需操作，同時推進兩邊；若不同則從「插入、刪除、替換」三種操作中選擇成本最小的一個。利用 DP 表格消除這些重疊子問題，再加上每個儲存格只依賴當前行和前一行，因此只需一行陣列即可進行空間最佳化。

## 思考過程

1. **每個位置的選擇僅限三種**：比較 `word1[i]` 和 `word2[j]` 時，若字元相同則不需操作，直接前進到 `(i+1, j+1)`。若不同則從「插入（推進 j）」「刪除（推進 i）」「替換（同時推進兩邊）」三者中選擇成本最小的。這種遞迴結構暗示了 DP 的適用性
2. **DP 表格的定義**：將 `dp[i][j]` 定義為「將 `word1[i:]` 轉換為 `word2[j:]` 所需的最少操作次數」。最終答案為 `dp[0][0]`
3. **決定基底情況**：若 `word1` 的剩餘部分為空（`i == m`），則需要插入 `word2[j:]` 的剩餘字元數，因此 `dp[m][j] = n - j`。若 `word2` 的剩餘部分為空（`j == n`），則需要刪除 `word1[i:]` 的剩餘字元數，因此 `dp[i][n] = m - i`
4. **決定自底向上的填充方向**：`dp[i][j]` 依賴於 `dp[i+1][j+1]`、`dp[i][j+1]`、`dp[i+1][j]`，因此 `i` 從 `m-1` 到 `0`、`j` 從 `n-1` 到 `0` 以逆序填充
5. **進行空間最佳化**：計算每一行 `i` 時只需要「前一行（`i+1`）」和「當前行（`i`）」這兩行。因此不需要持有二維陣列，只需 `prev`（前一行）和 `curr`（當前行）兩個一維陣列即可。每行計算完畢後透過 `prev = curr` 進行交換
6. **最終回傳值**：處理完所有行之後，`prev[0]` 相當於 `dp[0][0]` 的值，即將整個 `word1` 轉換為整個 `word2` 的最少操作次數

## 先備知識

### 什麼是 Edit Distance（編輯距離）

編輯距離是衡量兩個字串「相似度」的指標，表示將一個字串轉換為另一個字串所需的最少操作次數。也稱為 Levenshtein 距離。允許的操作有以下三種，每種成本為 1。

- **插入（Insert）**：在字串中新增一個字元
- **刪除（Delete）**：從字串中移除一個字元
- **替換（Replace）**：將字串中的一個字元更改為另一個字元

### 什麼是自底向上 DP（動態規劃法）

自底向上 DP 是一種從較小的子問題開始，逐步將結果記錄到表格中來求解遞迴子問題的方法。與記憶化遞迴（自頂向下）不同，它沒有遞迴呼叫的開銷，且更容易進行空間最佳化。

```java
// 一維 DP 範例：用兩個變數計算費波那契數列
int a = 0, b = 1;
for (int i = 2; i <= n; i++) {
    int temp = a + b;  // 當前值只依賴前兩個值
    a = b;             // 捨棄舊值並更新
    b = temp;
}
```

### 什麼是 Math.min()

Math.min() 是 Java 的標準方法，回傳兩個整數中較小的一個。比較三個以上的值時，需要巢狀使用。

```java
Math.min(3, 5);                    // → 3
Math.min(3, Math.min(5, 1));       // → 1（三個值中的最小值）
```

### 什麼是 String.charAt(int index)

String.charAt() 是回傳字串中指定位置字元的方法。索引從 0 開始。

```java
String s = "abc";
s.charAt(0);  // → 'a'
s.charAt(2);  // → 'c'
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(m × n) — 對 `word1` 的每個位置掃描 `word2` 的所有位置 |
| Space | O(n) — 以一行陣列取代二維表格來保存資料 |

## 程式碼

```java
// 輸入：兩個字串 word1（長度 m）和 word2（長度 n）
// 輸出：以 int 回傳將 word1 轉換為 word2 的最少操作次數
public int minDistance(String w1, String w2) {
    int m = w1.length();  // 取得 word1 的長度
    int n = w2.length();  // 取得 word2 的長度

    // prev 陣列：對應 DP 表格中下一行（i+1）
    // 以 prev[j] = n - j 進行初始化：當 word1 為空時，需要插入 word2[j:] 剩餘的 n-j 個字元的操作次數
    int[] prev = new int[n + 1];
    for (int j = 0; j <= n; j++)
        prev[j] = n - j;

    // 從 word1 的末尾向開頭逆序掃描（i 為 word1 的當前位置）
    for (int i = m - 1; i >= 0; i--) {
        // curr 陣列：對應 DP 表格中的當前行（i）
        int[] curr = new int[n + 1];
        // 當 word2 為空時，需要刪除 word1[i:] 剩餘的 m-i 個字元的操作次數
        curr[n] = m - i;

        // 從 word2 的末尾向開頭逆序掃描（j 為 word2 的當前位置）
        for (int j = n - 1; j >= 0; j--) {
            if (w1.charAt(i) == w2.charAt(j)) {
                // 字元相同則不需操作。prev[j+1] 為同時推進一個字元的子問題 dp[i+1][j+1] 的答案
                curr[j] = prev[j + 1];
            } else {
                // 字元不同則從三種操作中選擇成本最小的，並加上本次操作的 1 次（+1）
                curr[j] = 1 + Math.min(
                    curr[j + 1],           // 插入：在 word2 側推進一個字元（dp[i][j+1]）
                    Math.min(prev[j],      // 刪除：在 word1 側推進一個字元（dp[i+1][j]）
                        prev[j + 1]));     // 替換：在兩側同時推進一個字元（dp[i+1][j+1]）
            }
        }
        // 將當前行儲存為前一行，為下一次迭代（i-1）做準備
        prev = curr;
    }

    // prev[0] 對應 dp[0][0]，即將整個 word1 轉換為整個 word2 的最少操作次數
    return prev[0];
}
```
