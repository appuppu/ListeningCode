# Finding the Longest Increasing Path in a Matrix — 求矩陣中值嚴格遞增的最長路徑長度

## 問題本質

給定一個 m×n 的整數矩陣 `matrix`。可以向上下左右四個方向移動，但只有當移動目標格的值**嚴格大於**當前格的值時才能移動。返回滿足此條件的**最長路徑長度**（格數）。

## 核心思路

將矩陣視為「邊從小值指向大值的 DAG（有向無環圖）」。從入度為 0 的格（周圍沒有比自己更小的值的格）開始，逐層進行 BFS，層數即為最長路徑的長度。

## 思考過程

1. **移動條件構成 DAG 的邊**：由於只能沿值嚴格遞增的方向移動，因此不存在環。也就是說，將矩陣的相鄰關係視為圖時，會形成邊從小值指向大值的 DAG（有向無環圖）
2. **DAG 的最長路徑可用拓撲排序求解**：DAG 的最長路徑問題可以沿拓撲順序高效求解。使用 BFS（Kahn 演算法）可以逐層處理，層數對應最長路徑的長度
3. **定義入度的含義**：每個格的入度為「相鄰四個方向中，值比自己小的格的數量」。入度為 0 的格是路徑的起點候選，表示周圍不存在值比自己小的相鄰格
4. **逐層進行 BFS 處理**：將所有入度為 0 的格加入佇列，開始 BFS。每次處理一整層的格，對每個格的「值比自己大的相鄰格」將其入度減 1。當入度變為 0 時，將該格作為下一層加入佇列
5. **層數即為答案的原因**：BFS 的每一層是 DAG 上距離起點相同距離的格的集合。直到最後一層處理完畢的層數，就是從起點到最遠格的距離，即最長路徑的長度

## 前置知識

### 什麼是 DAG（有向無環圖）

由頂點和有向邊組成的圖，且不存在環（循環）。由於只沿值嚴格遞增的方向建立邊，因此不可能回到相同的值，不會產生環，從而構成 DAG。

### 什麼是入度（in-degree）

指向某頂點的**入邊數量**。在本問題中，格 `(i, j)` 的入度為「上下左右相鄰格中，值小於 `matrix[i][j]` 的格的數量」。入度為 0 的格表示沒有任何格能到達該格，即路徑的起點。

```java
// 計算格(i,j)的入度的範例
int indegree = 0;
for (int[] d : dirs) {
    int ni = i + d[0], nj = j + d[1];
    if (ni >= 0 && ni < m && nj >= 0 && nj < n
        && matrix[ni][nj] < matrix[i][j])  // 若相鄰格的值比自己小，則有一條邊進入
        indegree++;
}
```

### 什麼是拓撲排序（BFS / Kahn 演算法）

將 DAG 的頂點排列成所有邊都從「前」指向「後」的順序的方法。Kahn 演算法將入度為 0 的頂點加入佇列，每次取出時將相鄰頂點的入度減 1，當入度變為 0 時將該頂點加入佇列。重複此過程即可得到拓撲順序。

```java
Queue<int[]> q = new LinkedList<>();   // 建立 BFS 用的佇列
q.offer(new int[]{0, 1});             // 將格座標加入佇列
q.isEmpty();                           // 以 boolean 回傳佇列是否為空 → false
q.size();                              // 回傳佇列中的元素數量 → 1
int[] cell = q.poll();                 // 取出並回傳佇列的首元素 → {0, 1}
```

### 用陣列表示四個方向的移動

將上下左右四個方向定義為 `{列變化量, 行變化量}` 的二維陣列，用迴圈處理各方向。

```java
int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};  // 右、左、下、上
for (int[] d : dirs) {
    int ni = i + d[0];  // 移動目標的列
    int nj = j + d[1];  // 移動目標的行
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(m\*n) — 計算每個格的入度需要 O(m\*n)，BFS 中每個格恰好處理一次需要 O(m\*n) |
| Space | O(m\*n) — 儲存入度的二維陣列和 BFS 佇列各最多儲存 m\*n 個格 |

## 程式碼

```java
// 輸入：m×n 的整數矩陣 matrix
// 輸出：以 int 回傳值嚴格遞增的最長路徑長度（格數）
int longestIncreasingPath(int[][] matrix) {
    // 取得列數 m 和行數 n
    int m = matrix.length;
    int n = matrix[0].length;
    // 定義上下左右四個方向的移動量（右、左、下、上）
    int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};

    // 計算每個格的入度（相鄰格中值比自己小的數量）
    // 入度 = 進入該格的邊數 = 相鄰且值比自己小的格數
    int[][] indeg = new int[m][n];
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            for (int[] d : dirs) {
                int ni = i + d[0];
                int nj = j + d[1];
                // 若相鄰格在範圍內且值比自己小，則有一條邊從該格進入
                if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && matrix[ni][nj] < matrix[i][j])
                    indeg[i][j]++;
            }
        }
    }

    // 將所有入度為 0 的格（路徑的起點）加入佇列
    // 入度為 0 = 周圍沒有值比自己小的格 = DAG 上沒有任何格能到達的起點
    Queue<int[]> q = new LinkedList<>();
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (indeg[i][j] == 0)
                q.offer(new int[]{i, j});

    // 逐層進行 BFS 處理，並計算層數
    // 每一層是 DAG 上距離起點相同距離的格的集合
    int pathLen = 0;
    while (!q.isEmpty()) {
        // 取得當前層所包含的格數
        int size = q.size();
        // 每進入新的一層，路徑長度加 1（層的總數 = 最長路徑的長度）
        pathLen++;
        for (int k = 0; k < size; k++) {
            int[] cell = q.poll();
            // 檢查取出的格的四個方向的相鄰格
            for (int[] d : dirs) {
                int ni = cell[0] + d[0];
                int nj = cell[1] + d[1];
                // 若相鄰格在範圍內且值比自己大，則處理該邊
                if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && matrix[ni][nj] > matrix[cell[0]][cell[1]]) {
                    // 將入度減 1（標記來自此格的入邊已處理完畢）
                    indeg[ni][nj]--;
                    // 入度變為 0 = 所有入邊已處理完畢 → 作為下一層加入佇列
                    if (indeg[ni][nj] == 0)
                        q.offer(new int[]{ni, nj});
                }
            }
        }
    }
    // BFS 的層數即為最長遞增路徑的長度
    // 根據問題約束，矩陣不為空，因此保證 pathLen >= 1
    return pathLen;
}
```
