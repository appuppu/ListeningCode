# Counting Distinct Subsequences — 計算字串s中與t匹配的子序列有多少個

## 問題的本質

給定兩個字串 `s` 和 `t`。從 `s` 中刪除零個或多個字元（保持剩餘字元的相對順序不變），計算能夠構成與 `t` 匹配的子序列的方法有多少種並返回結果。

## 核心思路

對於 `s` 的每個字元，存在「用於 `t` 的匹配」或「不用於匹配」這兩種選擇。用一維陣列管理這些選擇的累積結果，並從後往前更新，就能正確地執行「使用的情況」與「不使用的情況」的加總。

## 思考過程

1. **子序列的匹配是選擇的累積**：當 `s` 的第 i 個字元與 `t` 的第 j 個字元匹配時，存在「將該字元用於 `t[j]` 的匹配」或「跳過不使用」這兩種選項。將兩種情況的數量加總即可求得所有模式
2. **定義DP的狀態**：將 `dp[j]` 定義為「與 `t` 的前 j 個字元匹配的 `s` 的子序列數量」。最終 `dp[n]`（n 為 `t` 的長度）即為答案
3. **考慮基礎情況**：與 `t` 的前 0 個字元（空字串）匹配的子序列，對於任何 `s` 都存在「什麼都不選」這唯一的一種方式。因此 `dp[0] = 1`
4. **推導轉移方程**：當 `s[i-1] == t[j-1]` 時，`dp[j]` 有兩個貢獻來源。「不使用 `s[i-1]` 的情況」保留既有的 `dp[j]`，「使用 `s[i-1]` 的情況」則加上 `dp[j-1]`（已匹配到前一個字元的數量）。因此 `dp[j] += dp[j-1]`。當字元不匹配時，`dp[j]` 不變（只能選擇跳過）
5. **更新順序需要反向的原因**：`dp[j] += dp[j-1]` 需要更新前的 `dp[j-1]`。如果從小到大更新 j，`dp[j-1]` 會先被覆寫，導致舊值丟失。從大到小反向更新 j，`dp[j-1]` 仍保持更新前的值，因此能正確計算
6. **最終返回的結果**：遍歷完 `s` 的所有字元後，`dp[n]` 就是 `s` 中與 `t` 匹配的子序列數量的答案

## 前置知識

### 什麼是子序列（Subsequence）

從原始字串中刪除零個或多個字元，保持剩餘字元的相對順序所構成的字串。與子字串（Substring）不同，子序列不需要是連續的。

```
s = "rabbbit", t = "rabbit"
子序列範例: 選擇 s 的第 1,2,3,5,6,7 個字元 → "rabbit" ✓
子序列範例: 選擇 s 的第 1,2,4,5,6,7 個字元 → "rabbit" ✓
子序列範例: 選擇 s 的第 1,3,4,5,6,7 個字元 → "rabbit" ✓
→ 共計3種
```

### 什麼是一維DP的反向更新

將二維DP表格 `dp[i][j]` 壓縮為一維陣列 `dp[j]` 的技巧。當計算當前行只需要前一行的值時，可以重複使用一維陣列來減少空間複雜度。但是，當更新 `dp[j]` 時需要 `dp[j-1]`（前一行的值），如果按 j 的升序更新，`dp[j-1]` 會被當前行的值覆寫。按 j 的降序（大→小）更新，就能正確引用尚未被覆寫的前一行的 `dp[j-1]`。

```java
// 二維DP（原始形式）
dp[i][j] = dp[i-1][j] + dp[i-1][j-1];

// 壓縮為一維DP（反向更新）
for (int j = n; j >= 1; j--) {   // 從大到小更新
    dp[j] += dp[j - 1];          // dp[j-1] 仍保持前一行的值
}
```

## 複雜度

| | 值 |
|---|---|
| Time | O(m × n) — 對s的每個字元（m個）遍歷t的每個字元（n個） |
| Space | O(n) — 僅使用長度為 n+1 的一維陣列 |

## 程式碼

```java
// 輸入: 字串 s（長度 m）和字串 t（長度 n）
// 輸出: 以 int 返回 s 的子序列中與 t 匹配的個數
public int numDistinct(String s, String t) {
    int m = s.length();
    int n = t.length();

    // dp[j] = 與t的前j個字元匹配的s的子序列數量
    // 管理索引 0〜n 共 n+1 個狀態，因此大小設為 n+1
    int[] dp = new int[n + 1];

    // 與空字串匹配的子序列始終為1種（什麼都不選）
    // 無論從 s 的哪個位置開始，此基礎情況都成立
    dp[0] = 1;

    // 依序考慮 s 的每個字元（i 表示已考慮到 s 的第幾個字元）
    for (int i = 1; i <= m; i++) {
        // 按 j 的反向（大→小）遍歷
        // 原因: 計算 dp[j] += dp[j-1] 時需要引用更新前的 dp[j-1]
        // 若按升序更新，dp[j-1] 會先被覆寫，導致前一行的值丟失
        for (int j = n; j >= 1; j--) {
            // i, j 從1開始，但字串索引從0開始，因此用 i-1, j-1 存取
            if (s.charAt(i - 1) == t.charAt(j - 1))
                // 匹配的情況: 將 dp[j-1]（使用的情況數量）加到 dp[j]（不使用的情況數量）上
                // 透過此加法，「使用」和「不使用」兩種選項的合計累積到 dp[j] 中
                dp[j] += dp[j - 1];
            // 不匹配的情況: 不做任何操作（s[i-1] 無法用於 t[j-1] 的匹配，只能選擇跳過）
        }
    }

    // dp[n] 保存了 s 整體中與 t 整體匹配的子序列個數
    return dp[n];
}
```
