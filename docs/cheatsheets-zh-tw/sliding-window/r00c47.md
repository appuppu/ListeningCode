# Finding the Maximum in Each Sliding Window — 求滑動視窗內的最大值

## 問題的本質

給定一個整數陣列 `nums` 和視窗大小 `k`。將大小為 `k` 的視窗從陣列的左端向右端逐一滑動，求每個位置視窗內的**最大值**。將所有最大值以陣列形式返回。

## 核心思路

在 Deque（雙端佇列）中以「值保持單調遞減」的方式保存索引，則 Deque 的頭部始終指向視窗內的最大值。當新元素加入時，從尾部移除所有小於等於自身的元素；當頭部超出視窗範圍時將其移除。透過這種方式，每一步以均攤 O(1) 的成本取得最大值。

## 思考過程

1. **需要每個視窗的最大值**：每次視窗滑動一格時，新增和移除的元素各只有一個。若每次都遍歷整個視窗以 O(k) 求最大值，則整體複雜度為 O(nk)，因此需要一個能高效管理最大值的資料結構
2. **只需保留最大值的候選者**：若視窗內有元素 A 和 B，A 在 B 的左邊且 A 的值小於等於 B，則 A 在之後的任何視窗中都不可能成為最大值。因為 B 在更右邊，所以 B 不會比 A 先離開視窗。因此可以將 A 從候選者中排除
3. **使用單調遞減的 Deque 管理候選者**：將候選者按值從大到小保持，則頭部始終為最大值。加入新元素時，從尾部移除所有小於等於自身的元素，即可維持單調遞減的性質。這個操作適合使用 Deque（雙端佇列）來實現
4. **在 Deque 中儲存索引**：要判斷元素是否已超出視窗範圍，需要位置資訊，因此 Deque 中儲存的是索引而非值。值可以透過 `nums[index]` 來參照
5. **頭部的視窗外檢查**：在每一步中，若 Deque 頭部的索引小於當前視窗的左端 `i - k + 1`，則該元素已離開視窗，需從頭部移除
6. **記錄結果的時機**：當索引 `i` 大於等於 `k - 1` 時，視窗已完整形成，此時將 Deque 頭部所指的值記錄到結果陣列中

## 前置知識

### ArrayDeque（雙端佇列）是什麼

ArrayDeque 是一種能在頭部和尾部以 O(1) 進行元素新增、取得和刪除的資料結構。它同時兼具堆疊和佇列的功能。

```java
ArrayDeque<Integer> deque = new ArrayDeque<>();  // 建立空的 Deque
deque.offerLast(5);       // 在尾部加入 5
deque.offerLast(3);       // 在尾部加入 3 → Deque 內容: [5, 3]
deque.peekFirst();        // 取得頭部元素（不刪除） → 5
deque.peekLast();         // 取得尾部元素（不刪除） → 3
deque.pollFirst();        // 取得並刪除頭部元素 → 5
deque.pollLast();         // 取得並刪除尾部元素 → 3
deque.isEmpty();          // 以 boolean 返回 Deque 是否為空 → true
```

### 單調遞減 Deque（Monotonic Deque）是什麼

單調遞減 Deque 是一種保持 Deque 內元素從頭部到尾部始終遞減（且不相等）的 Deque。加入新元素時，從尾部移除所有小於等於自身的元素，以維持單調遞減性質。
例如：Deque=[7, 5, 3] 加入 6 → 移除 5 和 3 → Deque=[7, 6]。頭部始終指向最大值。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 每個元素最多被加入 Deque 一次並被移除一次，因此整體為 O(n) |
| Space | O(k) — Deque 中最多只保持視窗大小 k 以下的元素 |

## 程式碼

```java
// 輸入：整數陣列 nums 和整數 k（視窗大小）
// 輸出：返回包含每個視窗位置最大值的 int[]，元素個數為 n - k + 1
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    // 儲存每個視窗最大值的結果陣列。視窗共有 n - k + 1 個
    int[] result = new int[n - k + 1];
    // 以單調遞減方式保存最大值候選索引的 Deque
    // Deque 中保存「視窗內有可能成為最大值的索引」，對應的值保持單調遞減
    ArrayDeque<Integer> deque = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // 若頭部索引小於視窗左端 i - k + 1，則該元素已在視窗外，將其移除
        // 視窗每次滑動一格，因此每步最多只有一個元素超出視窗範圍
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }

        // 從尾部移除所有小於等於當前元素 nums[i] 的候選者，以維持單調遞減
        // 只要 nums[i] 存在，這些元素就不可能成為最大值，因此可以從候選者中排除
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }

        // 將當前索引加入 Deque 的尾部
        // 上方的 while 已移除所有小於等於自身的元素，因此加入後 Deque 仍保持單調遞減
        deque.offerLast(i);

        // 當 i >= k - 1 時，視窗已包含 k 個元素
        // Deque 的頭部指向當前視窗內最大值的索引
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    // 返回記錄了所有視窗最大值的 result
    return result;
}
```
