# Checking if a String Contains a Permutation of Another — 判斷字串是否包含另一個字串的排列

## 問題的本質

給定兩個字串 `s1` 和 `s2`。判斷 `s2` 中是否存在 `s1` 的字謎（字元重新排列）作為**連續子字串**，若存在則回傳 `true`，若不存在則回傳 `false`。

## 核心思路

`s1` 的排列包含在 `s2` 中，意味著 `s2` 內存在一個與 `s1` 長度相同且字元頻率相同的子字串。使用固定長度的滑動窗口掃描 `s2`，透過差分更新 26 個字元的頻率匹配數，即可在每次滑動時以 O(1) 完成判斷。

## 思考過程

1. **將排列的條件換一種方式表達**：`s1` 的排列作為 `s2` 的子字串存在，等同於 `s2` 中存在一個長度為 `m`（= `s1` 的長度）的子字串，其每個字元的出現次數與 `s1` 完全一致
2. **使用固定長度的窗口進行掃描**：子字串的長度始終為 `m`，因此在 `s2` 上放置一個長度為 `m` 的固定大小窗口，每次滑動一個字元並比較字元頻率即可
3. **使用頻率陣列管理字元的出現次數**：英文小寫字母共有 26 種，因此使用兩個大小為 26 的整數陣列（`s1F` 和 `winF`）分別管理 `s1` 和窗口內的字元頻率。陣列的每個索引對應一個字元
4. **每次比較 26 個元素太浪費**：滑動窗口時，發生變化的字元最多只有「新進入的 1 個字元」和「離開的 1 個字元」。與其每次比較 26 個元素，不如使用 `matches` 計數器追蹤「26 個字元中頻率一致的字元數」，僅更新差分部分
5. **matches 計數器的更新規則**：在變更某個字元的頻率時，若變更前頻率一致則將 `matches` 減 1，若變更後頻率一致則將 `matches` 加 1。遵守「變更前判定→數值變更→變更後判定」的順序，即可維持計數器的一致性
6. **判斷條件**：當 `matches` 達到 26 時，表示全部 26 個字元的頻率都一致，因此回傳 `true`。若滑動至 `s2` 的末尾仍未達到 26，則回傳 `false`

## 前置知識

### 什麼是滑動窗口

滑動窗口是一種在陣列或字串上，透過移動左端和右端來掃描連續子區間的技巧。在固定長度窗口的情況下，右端前進 1 個位置的同時左端也前進 1 個位置，藉此維持窗口大小不變。

```java
// 在 s2 上滑動長度為 m 的固定窗口的基本形式
for (int i = m; i < n; i++) {
    char entering = s2.charAt(i);       // 新進入窗口的字元（右端）
    char leaving = s2.charAt(i - m);    // 離開窗口的字元（左端）
}
```

### 什麼是頻率陣列

頻率陣列是一個大小為 26 的整數陣列，用於儲存每個字元的出現次數。將 `'a'` 對應到索引 0，`'z'` 對應到索引 25。使用 `charAt(i) - 'a'` 將字元轉換為索引。

```java
int[] freq = new int[26];              // 所有元素初始化為 0
freq[s.charAt(i) - 'a']++;            // 將該字元的出現次數加 1
freq[s.charAt(i) - 'a']--;            // 將該字元的出現次數減 1
```

### 什麼是 matches 計數器

matches 計數器用於追蹤兩個頻率陣列中，相同索引的值一致的個數。若全部 26 個都一致，則 `matches == 26`，表示兩個字串的字元組成完全相同。

```java
int matches = 0;
for (int i = 0; i < 26; i++) {
    if (s1F[i] == winF[i]) matches++;  // 計算頻率一致的字元數
}
// matches == 26 表示所有字元的頻率都一致
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需掃描 `s2` 一次（每次滑動為 O(1)） |
| Space | O(1) — 頻率陣列的大小始終為 26，不依賴於輸入大小 |

## 程式碼

```java
// 輸入：字串 s1（要搜尋其排列的字串）和字串 s2（被搜尋的字串）
// 輸出：若 s2 包含 s1 的排列作為子字串則回傳 true，否則回傳 false
boolean checkInclusion(String s1, String s2) {
    int m = s1.length();
    int n = s2.length();

    // 若 s1 比 s2 長，則不可能包含其排列，因此立即回傳 false
    if (m > n) return false;

    // 用於儲存 s1 的字元頻率和窗口的字元頻率的大小為 26 的陣列
    int[] s1F = new int[26];
    int[] winF = new int[26];

    // 計算第一個窗口（開頭 m 個字元）的頻率。同時計算 s1 和 s2 開頭 m 個字元的頻率
    for (int i = 0; i < m; i++) {
        s1F[s1.charAt(i) - 'a']++;
        winF[s2.charAt(i) - 'a']++;
    }

    // 計算 26 個字元中頻率一致的字元數（初始 matches 的計算）
    int matches = 0;
    for (int i = 0; i < 26; i++) {
        if (s1F[i] == winF[i]) matches++;
    }

    // 若第一個窗口中全部 26 個字元的頻率都一致，則回傳 true
    if (matches == 26) return true;

    // 將窗口每次向右滑動一個字元（i 為窗口右端的下一個位置）
    for (int i = m; i < n; i++) {
        // --- 處理新進入窗口的字元（右端）---
        int idx = s2.charAt(i) - 'a';
        // 注意：必須遵守「變更前判定→數值變更→變更後判定」的順序
        if (winF[idx] == s1F[idx]) matches--;   // 若變更前頻率一致，則將 matches 減 1
        winF[idx]++;                              // 因為進入窗口，所以將頻率加 1
        if (winF[idx] == s1F[idx]) matches++;   // 若變更後頻率一致，則將 matches 加 1

        // --- 處理離開窗口的字元（左端）---
        idx = s2.charAt(i - m) - 'a';
        // 與進入字元相同的步驟：變更前判定→數值變更→變更後判定
        if (winF[idx] == s1F[idx]) matches--;   // 若變更前頻率一致，則將 matches 減 1
        winF[idx]--;                              // 因為離開窗口，所以將頻率減 1
        if (winF[idx] == s1F[idx]) matches++;   // 若變更後頻率一致，則將 matches 加 1

        // 若全部 26 個字元的頻率都一致，表示找到了排列，因此回傳 true
        if (matches == 26) return true;
    }

    // 滑動至 s2 的末尾仍未達到 matches==26，因此回傳 false
    return false;
}
```
