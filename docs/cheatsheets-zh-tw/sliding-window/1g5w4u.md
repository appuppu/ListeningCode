# Longest Substring After Replacing K Characters — 求在 K 次字元替換後能得到的最長相同字元子字串

## 問題的本質

給定一個大寫英文字母的字串 `s` 和一個整數 `k`。在字串中最多可以將 `k` 個字元替換為任意字元的情況下，返回**所有字元都相同**的子字串的最大長度。

## 核心思路

只要掌握視窗內「出現次數最多的字元的出現次數」，就可以計算出「需要替換的字元數 = 視窗大小 − 最頻字元的出現次數」。只要這個替換數不超過 `k`，就持續擴大視窗，即可求出最長的子字串。

## 思考過程

1. **暴力搜尋所有子字串效率太低**：列舉所有子字串需要 O(n²) 的時間。由於處理的是連續區間，適合使用 Sliding Window 模式
2. **想求出視窗內需要替換的字元數**：要將視窗內的所有字元變成相同字元，只需替換出現次數最多的字元以外的字元。因此，需要替換的字元數為 `視窗大小 − 最頻字元的出現次數`
3. **追蹤各字元出現次數的方法**：大寫英文字母只有 26 種，因此可以用大小為 26 的陣列 `count` 來管理各字元的出現次數。隨著視窗的擴大和縮小進行遞增和遞減操作
4. **高效管理最頻字元的出現次數**：每次右指標前進時，將新增字元的出現次數與目前的 `maxFreq` 進行比較，取較大值作為 `maxFreq`。即使左指標前進而移除字元，也不減少 `maxFreq`。因為在求最大長度的問題中，將 `maxFreq` 更新為比過去達成的值更小的值，不可能得到更長的結果
5. **視窗縮小的條件**：當 `視窗大小 − maxFreq > k` 時，表示替換次數超過了 `k`，因此將左指標前進 1 步來縮小視窗。重複此操作直到條件不再成立
6. **更新最大長度**：每當視窗有效（替換數 ≤ k）時，比較 `right − left + 1` 和目前的 `maxLen`，將較大值記錄為 `maxLen`

## 前提知識

### Sliding Window（滑動視窗）是什麼

Sliding Window 是一種在陣列或字串上以兩個指標（left、right）管理連續區間的方法。透過前進 right 來擴大視窗，當不再滿足條件時前進 left 來縮小視窗。由於每個元素最多只處理 2 次（新增和移除各 1 次），因此時間複雜度為 O(n)。

### 用陣列管理字元出現次數的方法

大寫英文字母為 `'A'` 到 `'Z'` 共 26 個字元，因此可以用 `int[26]` 的陣列來管理各字元的出現次數。字元轉換為索引的方式為 `charAt() - 'A'`。

```java
int[] count = new int[26];           // 保存 26 個字元出現次數的陣列
count[s.charAt(i) - 'A']++;         // 將字元 s.charAt(i) 的出現次數加 1
count[s.charAt(i) - 'A']--;         // 將字元 s.charAt(i) 的出現次數減 1
```

### 不減少 maxFreq 的原因

`maxFreq` 是視窗內最頻字元的出現次數。即使左指標前進而移除字元，也不需要重新計算並減少 `maxFreq`。在求最大長度的問題中，即使 `maxFreq` 變得比過去的最大值更小，在該狀態下能得到的視窗大小也不會超過過去的最大長度。因此，將 `maxFreq` 以單調遞增的方式管理也能得到正確的結果。

## 計算量

| | 值 |
|---|---|
| Time | O(n) — 右指標和左指標各自最多前進 n 次即可完成 |
| Space | O(1) — 使用的陣列大小固定為 26，不依賴輸入大小 |

## 程式碼

```java
// 輸入：大寫英文字母的字串 s 和整數 k（最大替換次數）
// 輸出：以 int 返回最多 k 次替換後能使所有字元相同的子字串的最大長度
public int characterReplacement(String s, int k) {
    // 管理各字元（A～Z）出現次數的陣列。索引 0 對應 'A'，25 對應 'Z'
    int[] count = new int[26];
    // left：視窗的左端
    int left = 0;
    // maxFreq：視窗內出現次數最多的字元的次數（以單調遞增方式管理）
    int maxFreq = 0;
    // maxLen：滿足條件的子字串的最大長度（最終返回此值）
    int maxLen = 0;

    // 逐步前進右指標以擴大視窗的右端
    for (int right = 0; right < s.length(); right++) {
        // 將右端新增字元的出現次數加 1
        count[s.charAt(right) - 'A']++;

        // 比較新增字元的出現次數和目前的 maxFreq，更新最頻字元的出現次數
        maxFreq = Math.max(maxFreq, count[s.charAt(right) - 'A']);

        // 視窗大小 - maxFreq = 需要替換的字元數。當此值超過 k 時，縮小左端
        // 注意：此處不重新計算 maxFreq。因為即使減少也不會對最大長度的更新有所貢獻
        while (right - left + 1 - maxFreq > k) {
            // 將左端字元的出現次數減 1，從視窗中移除
            count[s.charAt(left) - 'A']--;
            left++;
        }

        // 視窗有效（替換數 ≤ k），因此以目前的視窗大小更新最大長度
        maxLen = Math.max(maxLen, right - left + 1);
    }
    // for 迴圈結束後，返回最多 k 次替換後能得到的最長相同字元子字串的長度
    return maxLen;
}
```
