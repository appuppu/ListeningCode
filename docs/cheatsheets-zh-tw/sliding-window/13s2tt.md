# Finding the Longest Substring Without Repeating Characters — 求不含重複字元的最長子字串長度

## 問題的本質

給定一個字串 `s`。從 `s` 中找出不包含任何重複字元的連續子字串（substring），並以整數形式回傳該子字串的**最大長度**。

## 核心思路

使用滑動視窗可以在 O(n) 時間內檢查所有有效的子字串。當發現重複字元時，將左端直接跳躍到「重複字元上次出現位置 + 1」，藉此省略逐一移動的多餘操作。

## 思考過程

1. **用視窗表達子字串的搜尋**: 「不含重複的子字串」可以表示為由左端 `left` 和右端 `right` 兩個指標所圍成的區間。將右端逐一向前推進以擴展視窗，當發生重複時移動左端以縮小視窗
2. **使用 HashMap 來偵測重複**: 將每個字元「最後出現的索引」記錄在 HashMap 中，就能以 O(1) 判斷新字元是否已存在於視窗內
3. **精確定義左端的跳躍條件**: 僅憑 `right` 的字元存在於 HashMap 中是不夠的。只有當該字元的上次出現位置大於等於 `left`（即位於當前視窗內）時，才視為重複。視窗外的舊記錄應予以忽略
4. **決定左端的移動目標**: 當偵測到重複時，將 `left` 更新為「重複字元的上次出現位置 + 1」。如此一來，既能將重複字元排除在視窗之外，又能將其餘有效字元保留在視窗內
5. **HashMap 的更新時機**: 在完成重複判定之後，將當前字元的索引註冊（覆寫）到 HashMap 中。這樣就能始終記錄每個字元的最新出現位置
6. **更新最大長度**: 在每一步計算 `right - left + 1`（當前視窗寬度），並與目前的最大值進行比較後更新

## 前提知識

### 什麼是滑動視窗

滑動視窗是一種在陣列或字串上，以兩個指標（`left`、`right`）所定義的區間作為「窗口」進行移動，同時搜尋滿足條件的部分的技巧。將右端向前推進以擴展窗口，當違反條件時將左端向前推進以縮小窗口。由於每個指標只會向前移動，因此整體的時間複雜度為 O(n)。

### 什麼是 HashMap

HashMap 是一種儲存鍵值對的資料結構。透過指定鍵，可以在 O(1) 時間內搜尋和取得對應的值。在這道題目中，鍵儲存「字元」，值儲存「該字元最後出現的索引」。

```java
HashMap<Character, Integer> map = new HashMap<>();  // 建立空的 HashMap
map.put('a', 0);            // 將值 0 儲存到鍵 'a'
map.containsKey('a');       // 回傳鍵 'a' 是否存在的 boolean 值 → true
map.get('a');               // 回傳鍵 'a' 對應的值 → 0
```

### 什麼是 charAt

charAt 是取得字串中指定位置字元的方法。`s.charAt(i)` 會回傳字串 `s` 中索引 `i` 處的 `char`。

```java
String s = "abc";
char c = s.charAt(0);  // 回傳 'a'
char d = s.charAt(2);  // 回傳 'c'
```

### 什麼是 Math.max

Math.max 是回傳兩個值中較大者的方法。適用於需要持續更新最大值的場景。

```java
int result = Math.max(3, 7);  // 回傳 7
maxLength = Math.max(maxLength, currentLength);  // 更新當前的最大值
```

## 複雜度

| | 值 |
|---|---|
| Time | O(n) — `right` 只需遍歷字串一次。`left` 也只會向前移動，因此整體為 O(n) |
| Space | O(n) — HashMap 最多儲存 n 個字元與索引的鍵值對 |

## 程式碼

```java
// 輸入: 字串 s
// 輸出: 以 int 回傳不含重複字元的最長子字串長度
public int lengthOfLongestSubstring(String s) {
    // 視窗的左端指標。初始位置為字串的開頭
    int left = 0;
    // 記錄遍歷過程中找到的最長視窗寬度的變數
    int maxLength = 0;
    // 鍵=字元、值=該字元最後出現的索引，儲存於 HashMap 中
    // 同時用於重複判定和計算左端的跳躍目標
    HashMap<Character, Integer> hashMap = new HashMap<>();

    // right 是代表視窗右端的指標。逐一向前推進以擴展視窗
    for (int right = 0; right < s.length(); right++) {
        // 取得即將加入視窗的字元
        char curChar = s.charAt(right);

        // containsKey: 判斷該字元是否曾經出現過
        // get(curChar) >= left: 確認該出現位置是否在當前視窗內
        // 當兩個條件皆為真時，代表視窗內存在重複字元
        if (hashMap.containsKey(curChar) && hashMap.get(curChar) >= left) {
            // 將左端跳躍到重複字元的上次出現位置 + 1，以消除重複
            // left 始終只會向前移動，不會回退
            left = hashMap.get(curChar) + 1;
        }

        // 將當前字元的出現位置以最新的索引覆寫註冊
        // 下次該字元出現時，將使用此處記錄的索引來計算左端的跳躍目標
        hashMap.put(curChar, right);
        // right - left + 1 為當前的視窗寬度（不含重複字元的子字串長度）
        // 若超過過去的最大值則進行更新
        maxLength = Math.max(maxLength, right - left + 1);
    }
    // 這就是不含重複字元的最長子字串的長度
    return maxLength;
}
```
