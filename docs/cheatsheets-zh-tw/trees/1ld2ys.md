# Finding the Lowest Common Ancestor in a BST — 在BST中找出兩個節點的最深共同祖先

## 問題的本質

給定一棵二元搜尋樹（BST）以及樹中存在的兩個節點 `p` 和 `q`。請返回同時以這兩個節點作為子孫的最深節點（最低共同祖先：LCA）。節點本身也視為自己的子孫。

## 核心思路

在BST中，左子孫的值全部小於當前節點，右子孫的值全部大於當前節點。當 `p` 和 `q` 相對於當前節點分別位於左右兩側的瞬間，該節點就是LCA。

## 思考過程

1. **可以利用BST的性質**：在BST中，對於任意節點，左子樹的所有值 < 節點的值 < 右子樹的所有值，這個順序是有保證的。利用這個性質，只需比較節點的值就能判定 `p` 和 `q` 位於哪一側的子樹中
2. **兩者都在左側則向左前進**：當 `p.val` 和 `q.val` 都小於當前節點的值時，`p` 和 `q` 都存在於左子樹中。LCA也在該左子樹內，因此移動到左子節點
3. **兩者都在右側則向右前進**：當 `p.val` 和 `q.val` 都大於當前節點的值時，`p` 和 `q` 都存在於右子樹中。LCA也在該右子樹內，因此移動到右子節點
4. **分處左右兩側時該節點即為LCA**：當 `p` 和 `q` 分別位於當前節點的左右兩側（一方較小、另一方較大）時，不可能有更深的單一子樹同時包含兩者。因此當前節點就是LCA。當 `p` 或 `q` 等於當前節點時，由於自身也視為子孫，所以該節點也是LCA
5. **不需要遞迴，可用迭代實現**：每一步只朝左或右其中一個方向前進，因此不需要遞迴的呼叫堆疊。只需在while迴圈中更新當前節點即可，空間複雜度可達到O(1)

## 前備知識

### 什麼是二元搜尋樹（BST）

每個節點都滿足「左子孫 < 自身 < 右子孫」順序的二元樹。利用這個性質，僅透過值的大小比較就能判定節點屬於哪一側的子樹。

```
        6
       / \
      2    8
     / \  / \
    0   4 7   9
```

在這棵樹中，節點2和節點8的LCA是6。節點2和節點4的LCA是2（節點2也是自身的子孫）。

### 什麼是最低共同祖先（LCA）

在兩個節點 `p` 和 `q` 的所有共同祖先中，最深的（距離根最遠的）節點。當 `p` 或 `q` 本身是另一方的祖先時，該節點本身就是LCA。

### TreeNode 的結構

表示BST中每個節點的類別。具有值 `val`、左子節點 `left`、右子節點 `right`。

```java
TreeNode node = new TreeNode(6);   // 建立值為6的節點
node.val;                           // 取得節點的值 → 6
node.left;                          // 取得左子節點
node.right;                         // 取得右子節點
```

## 複雜度

| | 值 |
|---|---|
| Time | O(h) — 搜尋的次數等於樹的高度。若為平衡BST則為O(log n) |
| Space | O(1) — 由於使用迭代處理，不需要額外的記憶體 |

## 程式碼

```java
// 輸入：BST的根節點 root、樹中存在的兩個節點 p 和 q
// 輸出：返回 p 和 q 的最低共同祖先（LCA）對應的 TreeNode
TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    // 將當前搜尋位置初始化為根節點。透過while迴圈進行更新
    TreeNode node = root;

    // 當node不為null時，重複進行搜尋
    while (node != null) {
        // 判定p和q是否都小於當前節點
        if (p.val < node.val && q.val < node.val) {
            // 兩者都存在於左子樹中，所以LCA也在左子樹內
            node = node.left;
        // 判定p和q是否都大於當前節點
        } else if (p.val > node.val && q.val > node.val) {
            // 兩者都存在於右子樹中，所以LCA也在右子樹內
            node = node.right;
        } else {
            // p和q分處左右兩側（或其中一方等於當前節點）
            // 不可能有更深的單一子樹能同時容納兩個節點，因此確定為LCA
            return node;
        }
    }
    // 根據問題的約束條件，p和q都存在於樹中，因此必定會在上方的return結束，不會到達此處
    return null;
}
```
