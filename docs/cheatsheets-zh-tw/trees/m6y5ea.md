# Finding the Maximum Path Sum in a Binary Tree — 求二元樹中任意路徑的最大總和

## 問題的本質

給定一棵二元樹。每個節點持有一個整數值（可能為負數）。在由邊連接的所有路徑中（每個節點最多使用一次），找出節點值總和最大的路徑，並返回該**總和值**。路徑不必經過根節點，可以是從任意節點到任意節點的路徑。

## 核心思路

在每個節點計算「從左子孫獲得的最大收益」與「從右子孫獲得的最大收益」，將以該節點為頂點、連接左右的路徑總和作為全域最大值的候選。另一方面，返回給父節點的值只能選擇左右其中一條分支（因為路徑不能分岔）。

## 思考過程

1. **考慮路徑的結構**：任意路徑中必定存在一個「位置最高的節點（頂點）」。從該節點的角度來看，路徑由「向左子孫延伸的部分」、「節點本身」、「向右子孫延伸的部分」三部分組成。只要嘗試以每個節點作為頂點，即可求出最大路徑總和
2. **定義每個節點的收益（gain）**：將以某個節點為根的子樹中，能帶回父節點方向的最大總和值稱為「收益」。收益的計算方式為「自身的值 + 左右子節點中收益較大者」。由於路徑不能分岔，因此不能同時將左右兩邊的收益返回給父節點
3. **將負收益視為 0**：當子節點的收益為負時，包含該分支會使路徑總和減少。因此使用 `Math.max(0, gain)` 將負收益提升為 0（即不使用該分支）。這樣就能自然地表達單一節點的路徑或只使用一側分支的路徑
4. **另外管理全域最大值**：以每個節點為頂點時，「左收益 + 自身的值 + 右收益」即為經過該節點的最大路徑總和。將此值與全域變數 `maxSum` 比較並更新。由於這與返回給父節點的收益是不同的計算，因此需要獨立管理
5. **使用後序 DFS（postorder DFS）進行計算**：由於需要先知道子節點的收益才能計算自身，因此按照左→右→自身的順序處理的後序 DFS 最為適合。這樣只需一次遍歷就能嘗試以所有節點作為頂點
6. **最終返回的內容**：DFS 完成後，`maxSum` 中儲存了嘗試以所有節點為頂點後的最大路徑總和。返回此值即可

## 前置知識

### 什麼是二元樹的後序 DFS（Postorder DFS）

以「左子節點→右子節點→自身」的順序遞迴訪問二元樹的遍歷方法。適用於需要利用子節點的計算結果來進行父節點計算的情況。

```java
void postorder(TreeNode node) {
    if (node == null) return;     // 基本情況：若為 null 則不執行任何操作
    postorder(node.left);         // 先處理左子樹
    postorder(node.right);        // 接著處理右子樹
    // 在此處理 node 本身（子節點的結果已經確定）
}
```

### 什麼是 Math.max

返回兩個值中較大者的 Java 標準方法。用於將負收益提升為 0 的處理，以及左右收益的比較。

```java
Math.max(0, -5);    // → 0（將負值提升為 0）
Math.max(3, 7);     // → 7（返回較大的值）
Math.max(0, gain(node.left));  // 若左子節點的收益為負則設為 0
```

### 什麼是 Integer.MIN_VALUE

Java 中 `int` 型別可取的最小值（-2,147,483,648）。在求最大值的演算法中用作初始值。保證與任何值比較時都會被更新。

```java
int maxSum = Integer.MIN_VALUE;  // 比任何路徑總和都小的初始值
maxSum = Math.max(maxSum, 10);   // → 10（首次比較時必定會被更新）
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 執行一次 DFS，每個節點訪問一次 |
| Space | O(n) — 遞迴呼叫的呼叫堆疊在最壞情況下（偏斜樹）達到 n 層 |

## 程式碼

```java
// 輸入：二元樹的根節點 root（每個節點持有整數值 val、左子節點 left、右子節點 right）
// 輸出：以 int 返回二元樹中任意路徑的最大總和值
class Solution {
    // 記錄嘗試以所有節點為頂點後的最大路徑總和
    // 以 Integer.MIN_VALUE 初始化，使其比任何負值路徑都小，確保首次比較時必定更新
    int maxSum = Integer.MIN_VALUE;

    // 返回從節點帶回父節點方向的最大收益的遞迴函式（以後序 DFS 按子→父的順序計算）
    int gain(TreeNode node) {
        // 基本情況：null 節點的收益為 0（從不存在的子節點無法獲得任何收益）
        if (node == null) return 0;

        // 取得左子節點的收益，若為負則提升為 0（使用負的分支會減少路徑總和，因此選擇不使用）
        int leftGain = Math.max(0, gain(node.left));
        // 取得右子節點的收益，同樣若為負則提升為 0
        int rightGain = Math.max(0, gain(node.right));

        // 以當前節點為頂點，用連接左右的路徑總和更新全域最大值
        // 此值表示「左子孫→當前節點→右子孫」的路徑總和
        // 當 leftGain 或 rightGain 為 0 時，表示只使用一側分支或單一節點的路徑
        maxSum = Math.max(maxSum, node.val + leftGain + rightGain);

        // 返回給父節點的收益只取左右中較大的一條分支
        // 路徑必須像一筆畫般連續，不能在一個節點處分岔，因此不能同時返回兩邊
        return node.val + Math.max(leftGain, rightGain);
    }

    int maxPathSum(TreeNode root) {
        // 從根節點開始遞迴 DFS，嘗試以所有節點作為頂點
        gain(root);
        // DFS 完成後，maxSum 中儲存了嘗試以所有節點為頂點的路徑中最大的總和值
        return maxSum;
    }
}
```
