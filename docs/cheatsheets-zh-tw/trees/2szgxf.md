# Counting Good Nodes in a Binary Tree — 計算二元樹中「良好節點」的數量

## 問題的本質

給定一棵二元樹。從根節點到某個節點的路徑上，如果該節點的值大於或等於路徑上所有值的最大值，則該節點被視為「良好節點（good node）」。返回整棵樹中良好節點的數量。

## 核心思路

在從根節點走向各個節點的過程中，只要攜帶「目前為止的最大值」，就能以 O(1) 判定每個節點是否為良好節點。透過 DFS 遍歷樹並將最大值傳播給子節點，只需訪問所有節點各一次即可求得答案。

## 思考過程

1. **整理判定條件**：某個節點是否為良好節點，只需與從根節點到該節點的路徑上的最大值進行比較即可判定。也就是說，只要知道路徑上的最大值就能做出判定
2. **如何管理路徑上的最大值**：透過 DFS 遍歷樹時，遞迴的呼叫堆疊對應從根節點到當前節點的路徑。將「目前為止的最大值」作為遞迴的參數傳遞，即可在每個節點取得判定所需的資訊
3. **決定每個節點的處理方式**：如果當前節點的值大於或等於最大值，則為良好節點，將 1 加入結果；否則加入 0。這樣就能同時完成判定和計數
4. **更新傳遞給子節點的最大值**：傳遞給子節點的最大值取當前最大值與當前節點值中較大的一方。這樣隨著路徑延伸，最大值會以單調非遞減的方式更新
5. **遞迴處理左右子樹**：透過遞迴分別求出左子樹和右子樹的良好節點數，再與當前節點的結果合計後返回
6. **初始呼叫的最大值**：根節點始終是良好節點（路徑上只有自己）。將初始值設為 `Integer.MIN_VALUE`，根節點的值必定大於或等於它，因此能正確判定

## 前置知識

### 遞迴 DFS（深度優先搜尋）

以深度方向優先遍歷樹或圖的演算法。在二元樹中，透過遞迴函式對左子節點和右子節點分別呼叫自身來實現。遞迴的呼叫堆疊會隱含地保持從根節點到當前節點的路徑。

```java
void dfs(TreeNode node) {
    if (node == null) return;  // 基本情況：到達 null 節點時返回
    // 對當前節點進行處理
    dfs(node.left);            // 遞迴遍歷左子樹
    dfs(node.right);           // 遞迴遍歷右子樹
}
```

### Math.max

返回兩個值中較大者的方法。用於更新路徑上的最大值。

```java
Math.max(5, 3);    // → 5（返回 5 和 3 中較大的一方）
Math.max(-1, 4);   // → 4
```

### Integer.MIN_VALUE

Java 中 `int` 型別可取的最小值（-2,147,483,648）。由於任何節點的值都大於或等於此值，將其作為初始最大值可確保根節點必定被判定為良好節點。

```java
Integer.MIN_VALUE;  // → -2147483648（int 型別的最小值）
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 訪問所有節點各一次 |
| Space | O(h) — 遞迴的呼叫堆疊使用與樹的高度相當的空間 |

## 程式碼

```java
// 輸入：二元樹的根節點 root
// 輸出：以 int 返回良好節點的總數

// 輔助函式：返回以 node 為根的子樹中良好節點的數量
// maxSoFar 表示從根節點到當前節點的路徑上的最大值
private int dfs(TreeNode node, int maxSoFar) {
    // 基本情況：到達 null 時良好節點為 0 個（已超過葉節點，沒有需要計數的節點）
    if (node == null) return 0;

    // 判定當前節點是否為良好節點（大於或等於路徑上的最大值則為良好節點）
    int result = node.val >= maxSoFar ? 1 : 0;

    // 更新傳遞給子節點的最大值（如果當前節點的值較大則更新，否則沿用原本的最大值）
    int newMax = Math.max(maxSoFar, node.val);

    // 遞迴求出左子樹的良好節點數並加總
    result += dfs(node.left, newMax);
    // 遞迴求出右子樹的良好節點數並加總
    result += dfs(node.right, newMax);

    // 返回以當前節點為根的整棵子樹的良好節點數
    return result;
}

public int goodNodes(TreeNode root) {
    // 將初始最大值設為 int 最小值，確保根節點必定被判定為良好節點
    return dfs(root, Integer.MIN_VALUE);
}
```
