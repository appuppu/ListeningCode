# Inverting a Binary Tree — 將二分樹的所有節點的左右子節點進行交換

## 問題的本質

給定一棵二分樹的根節點 `root`。將樹的**所有節點**的左子節點和右子節點進行交換（反轉），並返回反轉後的樹的根節點。

## 核心思路

二分樹的反轉是指在所有節點上交換左右子節點的操作。使用 BFS 按層序訪問所有節點，並在每個節點上交換左右子節點，即可完成整棵樹的反轉。

## 思考過程

1. **理解反轉的定義**: 二分樹的反轉不僅是在根節點上，而是在所有節點上交換左子節點和右子節點的操作。也就是說，只需逐一訪問樹的所有節點，並在每個節點上執行交換處理即可
2. **選擇訪問所有節點的方法**: 使用 BFS（廣度優先搜尋）來訪問樹的所有節點。BFS 使用佇列按層序處理節點，實作方式直觀且易於理解
3. **決定在每個節點上的操作**: 對從佇列中取出的每個節點，使用臨時變數交換 `left` 和 `right`。交換的順序無關緊要，即使子節點為 null，交換操作本身也不會產生問題
4. **將子節點加入佇列**: 交換後的左右子節點如果不為 null，則將其加入佇列。這樣可以依次訪問樹的下層節點，確保所有節點都執行交換操作
5. **最終返回的內容**: 所有節點的交換完成後，直接返回原本的根節點 `root`。樹的結構雖然改變了，但根節點本身仍是同一個物件

## 前置知識

### 二分樹（Binary Tree）

每個節點最多擁有兩個子節點（左子節點 `left` 和右子節點 `right`）的樹狀結構。節點以 `TreeNode` 類別表示，包含 `val`（值）、`left`（左子節點）、`right`（右子節點）三個欄位。

```java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

### Queue（佇列）

先進先出（FIFO）的資料結構。最先加入的元素會最先被取出。在 BFS 中使用佇列來管理待訪問的節點。

```java
Queue<TreeNode> queue = new LinkedList<>();  // 建立空的佇列
queue.add(node);     // 將 node 加入佇列的末尾
queue.poll();        // 取出並返回佇列最前端的元素
queue.isEmpty();     // 以 boolean 值返回佇列是否為空 → true/false
```

### BFS（廣度優先搜尋）

按「層序」搜尋樹或圖的演算法。使用佇列，在處理當前節點後將其子節點加入佇列，從而從較淺的層次開始依序訪問所有節點。

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 逐一訪問樹的所有節點各一次 |
| Space | O(n) — 佇列中最多儲存 n 個節點 |

## 程式碼

```java
// 輸入: 二分樹的根節點 root
// 輸出: 返回所有節點的左右子節點交換完成後的根節點 root
public TreeNode invertTree(TreeNode root) {
    // 若樹為空則返回 null。因為樹不存在，所以直接結束
    if (root == null) return null;

    // 建立 BFS 用的佇列，並將根節點加入
    // 此佇列用於管理接下來需要執行左右交換的節點
    Queue<TreeNode> queue = new LinkedList<>();
    queue.add(root);

    // 重複執行直到佇列為空（即所有節點都處理完畢）
    while (!queue.isEmpty()) {
        // 從佇列最前端取出待交換的節點
        TreeNode curr = queue.poll();

        // 使用臨時變數交換左右子節點
        // 注意: 若不使用臨時變數而直接賦值，會導致其中一方的參照被覆蓋而遺失
        TreeNode temp = curr.left;
        curr.left = curr.right;
        curr.right = temp;

        // 若交換後的子節點不為 null，則將其加入佇列
        // null 的節點不再擁有需要處理的子節點，因此無需加入
        if (curr.left != null) queue.add(curr.left);
        if (curr.right != null) queue.add(curr.right);
    }

    // 返回所有節點交換完成後的根節點
    // 樹的結構雖然改變了，但根節點本身仍是同一個物件
    return root;
}
```
