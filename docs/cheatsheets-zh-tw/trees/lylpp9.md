# Finding the Kth Smallest Element in a BST — 在BST中找出第k小的元素

## 問題本質

給定一棵二元搜尋樹（BST）的根節點 `root` 和一個整數 `k`。請從BST中所有節點的值裡，返回**第k小的值**。題目保證樹中至少存在k個節點。

## 核心思路

對BST進行中序走訪（in-order traversal）時，節點的值會按升序排列。因此，中序走訪中第k個被訪問的節點的值就是答案。不需要走訪所有節點，到達第k個時即可立即結束。

## 思考過程

1. **利用BST的性質**: 在BST中，對於任意節點，「左子樹的所有節點 < 自身 < 右子樹的所有節點」成立。根據這個性質，進行中序走訪（左→自身→右）可以按升序獲得節點的值
2. **第k小的值就是中序走訪的第k個元素**: 中序走訪得到的升序序列中第k個元素就是答案，因此只需在走訪過程中進行計數即可
3. **選擇使用堆疊的迭代式走訪而非遞迴**: 使用遞迴時，即使到達第k個元素也無法立即return（需要回溯呼叫堆疊）。使用堆疊的迭代式走訪，在找到第k個元素的瞬間就能直接return跳出
4. **使用堆疊實現中序走訪的方法**: 從當前節點沿著左子節點不斷往下走並壓入堆疊。到達最左端後從堆疊pop，該節點即為「訪問」的節點。接著移動到右子節點，重複相同的處理
5. **使用計數器檢測第k個元素**: 每次pop並訪問一個節點時，將k遞減。當k變為0時，該節點的值就是答案
6. **最終返回的內容**: 返回k變為0時的節點值 `curr.val`

## 前置知識

### BST（二元搜尋樹）的中序走訪

以「左子樹→自身→右子樹」的順序訪問二元搜尋樹的走訪方法。對BST進行中序走訪時，節點的值會按升序（從小到大）排列。

```
例:     5
       / \
      3   7
     / \
    2   4

中序走訪結果: 2, 3, 4, 5, 7（升序）
```

### Stack（堆疊）

後進先出（LIFO）的資料結構。最後加入的元素會最先被取出。在中序走訪中，堆疊用於記住沿左子節點往下走過程中經過的父節點。

```java
Stack<TreeNode> stack = new Stack<>();  // 建立空的堆疊
stack.push(node);      // 將node加入堆疊頂部
stack.pop();           // 取出並返回堆疊頂部的元素
stack.isEmpty();       // 以boolean返回堆疊是否為空
```

### 迭代式中序走訪的模式

使用堆疊的中序走訪是重複「深入到最左端→pop並訪問→移動到右子節點」的過程。迴圈的持續條件是「當前節點不為null，或堆疊不為空」，只要其中之一為真就繼續執行。

```java
TreeNode curr = root;
while (curr != null || !stack.isEmpty()) {
    while (curr != null) {       // 深入到最左端
        stack.push(curr);
        curr = curr.left;
    }
    curr = stack.pop();          // 訪問（此處按升序獲得節點）
    curr = curr.right;           // 移動到右子節點
}
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(h + k) — 向下走到最左端需h次，pop k個節點 |
| Space | O(h) — 堆疊中最多存放樹的高度h個節點 |

## 程式碼

```java
// 輸入: 二元搜尋樹的根節點 root 和整數 k
// 輸出: 以 int 返回BST中第k小的節點值
public int kthSmallest(TreeNode root, int k) {
    // 用於暫存沿左子節點往下走過程中經過的父節點，以便之後返回的堆疊
    Stack<TreeNode> stack = new Stack<>();
    // 指向當前關注節點的指標
    TreeNode curr = root;

    // 即使curr為null，只要堆疊中還有節點就表示仍有未訪問的節點，繼續執行
    while (curr != null || !stack.isEmpty()) {
        // 深入到最左端，將經過的節點壓入堆疊（到達當前子樹的最小值）
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }

        // pop出的節點是中序走訪中下一個應訪問的節點（未訪問節點中持有最小值的節點）
        curr = stack.pop();
        // pop相當於在中序走訪中訪問了一個節點，因此將剩餘訪問次數減1
        k--;

        // 當k變為0時，該節點就是第k小的元素，立即返回其值並結束
        if (k == 0)
            return curr.val;

        // 若存在右子樹，下一次迭代會深入到其最左端。若不存在，curr變為null，從堆疊pop父節點
        curr = curr.right;
    }
    // 根據題目約束，樹中至少存在k個節點，因此不會到達這裡
    return -1;
}
```
