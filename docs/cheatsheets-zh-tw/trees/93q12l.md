# Validating a Binary Search Tree — 判定二元樹是否為有效的二元搜尋樹

## 問題的本質

給定一棵二元樹的 `root`。判定該樹是否為有效的二元搜尋樹（BST）。有效的 BST 意味著，對於所有節點，左子樹的所有值**嚴格小於**該節點的值，右子樹的所有值**嚴格大於**該節點的值。

## 核心思路

每個節點都擁有「可取值的有效範圍」。從根節點開始遞迴向下遍歷，對左子節點縮小上限，對右子節點縮小下限，就能在一次遍歷中判定所有節點是否滿足 BST 的條件。

## 思考過程

1. **僅檢查直接的父子關係是不夠的**：僅確認每個節點大於直接的左子節點且小於右子節點，並不能滿足 BST 的條件。左子樹的「所有」節點都必須小於該節點。也就是說，每個節點都有從祖先繼承而來的約束條件
2. **定義每個節點的有效範圍**：根節點可以取任意值，因此範圍從 `(-∞, +∞)` 開始。當進入左子節點時，上限縮小為父節點的值；當進入右子節點時，下限縮小為父節點的值。只需將此範圍作為遞迴的參數傳遞即可
3. **決定判定條件**：在每個節點確認 `node.val` 是否在 `(lo, hi)` 的範圍內。由於 BST 使用嚴格不等號，若 `node.val <= lo` 或 `node.val >= hi`，則判定為無效
4. **決定遞迴的結構**：基本情況是 `node == null` 時返回 `true`（空樹是有效的 BST）。在每個節點判定自身的值，並對左右子節點縮小範圍後進行遞迴呼叫。只有當左右兩邊都返回 `true` 時，才返回 `true`
5. **將範圍的型別設為 long**：當節點的值為 `Integer.MIN_VALUE` 或 `Integer.MAX_VALUE` 時，int 型別的範圍無法表示初始值。使用 `Long.MIN_VALUE` 和 `Long.MAX_VALUE` 作為初始範圍，就能正確判定所有 int 值
6. **最終返回的結果**：從根節點開始遞迴，若所有節點都在有效範圍內則返回 `true`，只要有一個違反則返回 `false`

## 前置知識

### 什麼是二元搜尋樹（BST）

一種二元樹，對於每個節點，左子樹的所有值小於該節點的值，右子樹的所有值大於該節點的值。此性質不僅適用於直接的子節點，而是適用於整個子樹。

```
      5
     / \
    3   7     ← 有效的 BST：3<5, 7>5, 1<3, 4>3 且 4<5, 6>5 且 6<7
   / \   \
  1   4   8
```

### 透過遞迴縮小範圍

從父節點進入子節點時，有效值的範圍會縮小的機制：

```
節點5：範圍(-∞, +∞)
├─ 左子3：範圍(-∞, 5)  ← 上限縮小為父節點的值 5
│  ├─ 左子1：範圍(-∞, 3)
│  └─ 右子4：範圍(3, 5)  ← 下限 3 且上限 5
└─ 右子7：範圍(5, +∞)  ← 下限縮小為父節點的值 5
```

### 使用 long 型別的原因

Java 的 `int` 範圍為 `-2147483648` 至 `2147483647`。要將初始範圍表示為「允許 int 型別的任何值」，就需要超出 int 型別範圍的值。使用 `long` 型別，就能以 `Long.MIN_VALUE` 和 `Long.MAX_VALUE` 設定足夠寬廣的初始範圍。

```java
long lo = Long.MIN_VALUE;  // 小於 int 的任何值
long hi = Long.MAX_VALUE;  // 大於 int 的任何值
node.val <= lo;            // node.val 為 int 型別，因此保證大於 Long.MIN_VALUE
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 每個節點恰好訪問一次 |
| Space | O(h) — 遞迴呼叫堆疊的深度與樹的高度 h 成正比（最差 O(n)，平衡時 O(log n)） |

## 程式碼

```java
// 輸入：二元樹的根節點 root
// 輸出：若樹為有效的 BST 則返回 true，否則返回 false
public boolean isValidBST(TreeNode root) {
    // 將初始範圍設為 Long.MIN_VALUE/MAX_VALUE，使根節點允許 int 型別的任何值
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

// lo、hi 為 long 型別。因為 int 型別無法使用 Integer.MIN_VALUE/MAX_VALUE 作為初始值
boolean validate(TreeNode node, long lo, long hi) {
    // 基本情況：空節點不違反 BST 的條件
    if (node == null) return true;

    // 若當前節點的值在有效範圍 (lo, hi) 之外，則為無效
    // BST 中不允許相等的值，因此使用 <= 和 >= 進行嚴格判定
    if (node.val <= lo || node.val >= hi) return false;

    // 左子樹：將上限縮小為 node.val（左邊的所有值必須小於 node.val）。下限 lo 維持祖先的約束
    // 右子樹：將下限縮小為 node.val（右邊的所有值必須大於 node.val）。上限 hi 維持祖先的約束
    // 只有當左右兩邊都為 true 時，整個子樹才是有效的 BST
    return validate(node.left, lo, node.val)
        && validate(node.right, node.val, hi);
}
```
