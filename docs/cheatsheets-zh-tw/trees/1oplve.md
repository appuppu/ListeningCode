# Finding the Diameter of a Binary Tree — 求二元樹中最長路徑的邊數

## 問題的本質

給定一棵二元樹的 `root`。在樹中任意兩個節點之間的路徑中，返回最長路徑的長度（邊數）。該路徑不一定需要經過根節點。

## 核心思路

在任意節點上，「左子樹的高度＋右子樹的高度＋2」即為經過該節點的最長路徑邊數。透過 DFS 計算每個節點的高度，同時追蹤該值的最大值，即可在一次遍歷中求出直徑。

## 思考過程

1. **直徑會經過某個節點作為「頂點」**: 最長路徑必定以某一個節點作為最高位置（折返點），從該節點的左子樹某處延伸到右子樹某處。因此，對每個節點求出「以該節點為頂點的路徑長度」，其最大值即為直徑
2. **經過頂點的路徑長度由左右高度決定**: 以某個節點為頂點的路徑邊數可透過「左子樹的高度＋右子樹的高度＋2」來計算。左高度為到最深左側節點的邊數，右高度為到最深右側節點的邊數，因為從頂點到左右各加一條邊，所以＋2
3. **將高度的定義對齊「邊數」**: 將節點的高度定義為「從該節點到最遠葉節點的邊數」，則葉節點的高度為 0，null 節點的高度為 -1。將 null 設為 -1，葉節點的高度就能自然地計算為 `1 + max(-1, -1) = 0`
4. **在 DFS 中返回高度並同時更新直徑**: 使用後序（Post-order）DFS，在每個節點遞迴取得左右子節點的高度。根據取得的左右高度計算「以該節點為頂點的路徑長度」，更新全域變數 `maxDiameter`，並將該節點自身的高度 `1 + max(left, right)` 作為返回值
5. **使用全域變數追蹤最大值**: DFS 的返回值是「高度」而非「直徑」，因此直徑的最大值記錄在全域變數 `maxDiameter` 中。在每個節點比較 `left + right + 2` 與當前的 `maxDiameter`，保留較大的值
6. **最終返回的結果**: DFS 遍歷完所有節點後，儲存在 `maxDiameter` 中的值即為整棵樹的直徑

## 前提知識

### 二元樹的高度（height）

從某個節點到最遠葉節點的路徑中包含的邊數。葉節點的高度定義為 0，null 節點的高度定義為 -1。父節點的高度透過 `1 + max(左子節點的高度, 右子節點的高度)` 求得。

```
      1          節點 1 的高度: 2（1→2→4 的邊數）
     / \         節點 2 的高度: 1（2→4 的邊數）
    2   3        節點 3 的高度: 0（葉節點）
   /             節點 4 的高度: 0（葉節點）
  4
```

### 透過遞迴實現的 DFS（深度優先搜尋）

以遞迴方式訪問樹中每個節點的方法。在後序（Post-order）中，按照左子節點→右子節點→自身的順序處理。適用於需要利用子節點的結果來計算父節點值的情況。

```java
int dfs(TreeNode node) {
    if (node == null) return -1;   // 基本情況: null 節點的高度為 -1
    int left = dfs(node.left);     // 遞迴處理左子樹
    int right = dfs(node.right);   // 遞迴處理右子樹
    return 1 + Math.max(left, right);  // 計算並返回自身的高度
}
```

### Math.max

返回兩個值中較大者的 Java 標準方法。

```java
Math.max(3, 5);    // → 5
Math.max(-1, -1);  // → -1
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 只需執行一次遍歷所有節點各一次的 DFS |
| Space | O(n) — 遞迴呼叫的呼叫堆疊最多為 n 層（在傾斜樹的情況下） |

## 程式碼

```java
// 輸入: 二元樹的根節點 root
// 輸出: 以 int 返回樹的直徑（任意兩個節點之間最長路徑的邊數）

// 在 DFS 遍歷過程中保存已發現的最大直徑的全域變數
// 初始值為 0，因為只有一個節點的樹其直徑為 0
int maxDiameter = 0;

// 返回每個節點的高度，同時作為副作用更新 maxDiameter 的遞迴函數
int dfs(TreeNode node) {
    // null 節點的高度為 -1（表示不存在邊）
    // 返回 -1 使得父節點（葉節點）的高度能正確計算為 1 + max(-1, -1) = 0
    if (node == null) return -1;

    // 遞迴取得左子樹的高度
    int left = dfs(node.left);
    // 遞迴取得右子樹的高度
    int right = dfs(node.right);

    // 以當前節點為頂點的路徑邊數（left + right + 2）來更新直徑的最大值
    // +2 是因為要加上從當前節點到左右子節點的兩條邊
    maxDiameter = Math.max(
        maxDiameter,
        left + right + 2);

    // 將當前節點的高度返回給父節點（注意這是高度而非直徑）
    // 這是父節點用來計算自身路徑長度所需的值
    return 1 + Math.max(left, right);
}

public int diameterOfBinaryTree(TreeNode root) {
    // 透過 DFS 遍歷所有節點，根據以每個節點為頂點的路徑長度來更新 maxDiameter
    dfs(root);
    // 遍歷完成後的 maxDiameter 即為整棵樹的直徑
    return maxDiameter;
}
```
