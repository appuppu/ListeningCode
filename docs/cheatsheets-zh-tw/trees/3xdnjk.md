# Checking if a Binary Tree is Height-Balanced — 判定二元樹是否為高度平衡

## 問題的本質

給定一棵二元樹的根節點 `root`，判定該樹是否為**高度平衡（height-balanced）**。高度平衡是指在所有節點中，左子樹的高度與右子樹的高度之差不超過1。將結果以 `boolean` 返回。

## 核心思路

在遞迴計算各節點高度的過程中，一旦偵測到不平衡就立即返回 `-1` 並向上傳播。將高度計算與平衡判定合併在一次後序走訪（post-order traversal）中同時進行，只需訪問每個節點一次即可得出答案。

## 思考過程

1. **以遞迴方式理解平衡的定義**：樹是平衡的，意味著在所有節點中，左右子樹的高度之差不超過1。也就是說，要判定某個節點是否平衡，需要知道左右子樹的「高度」
2. **高度的計算本身就是遞迴的**：某個節點的高度可由 `1 + max(左子樹高度, 右子樹高度)` 求得。利用這個遞迴從下往上（以 post-order）遍歷樹，就能自然地求出各節點的高度
3. **將高度計算與平衡判定整合**：在返回高度的遞迴函式中，當左右高度之差超過1時，返回表示「不平衡」的特殊值 `-1`。如此一來，就能在一個函式中同時完成高度計算與平衡判定
4. **透過提前終止來避免無謂的探索**：若左子樹的結果為 `-1`，則無需再檢查右子樹，整棵樹就已經是不平衡的。每次都檢查遞迴的返回值是否為 `-1`，一旦發現不平衡就立即返回 `-1` 以中斷遞迴
5. **靈活運用返回值的雙重含義**：返回值為 `0以上` 表示正常的高度，`-1` 表示不平衡。呼叫端的 `isBalanced` 方法只需確認最終返回值是否不為 `-1`，即可得出答案

## 前提知識

### 二元樹的高度（height）

從某個節點到最遠的葉節點之間的邊數。葉節點的高度為1（以節點數計算），`null` 的高度為0。以遞迴方式表示為 `height(node) = 1 + max(height(node.left), height(node.right))`。

```
        1           節點1的高度: 3
       / \          節點2的高度: 2
      2   3         節點4的高度: 1
     /              節點3的高度: 1
    4
```

### 後序走訪（Post-Order Traversal）

以左子樹 → 右子樹 → 自身的順序處理節點的走訪方法。由於先確定子節點的資訊後再處理父節點，因此適合「使用子節點的高度來計算父節點的高度」這類由下而上的彙總處理。

```java
void postOrder(TreeNode node) {
    if (node == null) return;
    postOrder(node.left);   // 先處理左子樹
    postOrder(node.right);  // 接著處理右子樹
    // 在此處理 node 自身（左右的結果已經確定）
}
```

### Math.abs

返回整數絕對值的 Java 標準方法。用於判定左右高度之差無論正負是否不超過1。

```java
Math.abs(3 - 1);    // → 2
Math.abs(1 - 3);    // → 2
Math.abs(2 - 3);    // → 1
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 每個節點訪問一次 |
| Space | O(n) — 遞迴呼叫的呼叫堆疊最多為 n 層（當樹傾斜時） |

## 程式碼

```java
// 輸入: 二元樹的根節點 root
// 輸出: 若樹為高度平衡則返回 true，否則返回 false

// 返回節點高度的遞迴函式。偵測到不平衡時返回哨兵值 -1
// 返回值為 0以上 表示正常的高度，-1 表示「某個子樹不平衡」
private int checkHeight(TreeNode node) {
    // 基底情況: null 表示空的子樹，高度為0
    if (node == null) return 0;

    // 遞迴求取左子樹的高度（後序走訪中「先處理左子樹」的部分）
    int left = checkHeight(node.left);
    // 若左子樹不平衡，則不檢查右子樹，立即傳播 -1（提前終止）
    if (left == -1) return -1;

    // 遞迴求取右子樹的高度（後序走訪中「接著處理右子樹」的部分）
    int right = checkHeight(node.right);
    // 若右子樹不平衡，則立即傳播 -1
    if (right == -1) return -1;

    // 在當前節點，若左右高度之差超過1則為不平衡（後序走訪中「處理自身」的部分）
    // 使用 Math.abs，無論左右哪邊較高都能正確判定差值
    if (Math.abs(left - right) > 1)
        return -1;

    // 若為平衡，則返回當前節點的高度。該值將用於父節點的計算
    return 1 + Math.max(left, right);
}

public boolean isBalanced(TreeNode root) {
    // 若 checkHeight 的返回值不為 -1，則整棵樹為平衡
    // -1 是表示「某個子樹不平衡」的哨兵值
    return checkHeight(root) != -1;
}
```
