# Finding the Maximum Depth of a Binary Tree — 求二元樹最深路徑的節點數

## 問題的本質

給定一棵二元樹的 `root` 節點。要求返回從根節點到最遠葉節點的路徑中包含的**節點數**（最大深度）作為整數。若為空樹（root 為 null），則返回 0。

## 核心思路

樹的最大深度等於「左子樹的最大深度」與「右子樹的最大深度」中較大者加上 1（代表當前節點）。這個遞迴定義本身就是解法。

## 思考過程

1. **樹的深度可以遞迴定義**：某個節點的深度取決於以其左右子節點為根的子樹深度。也就是說，問題可以分解為結構相同的較小子問題
2. **決定基礎情況**：當節點為 null 時，該處不存在任何節點，因此深度為 0。這就是遞迴的終止條件
3. **分別求左右子樹的深度**：從當前節點遞迴進入左子節點，取得左子樹的最大深度。同樣地，遞迴進入右子節點，取得右子樹的最大深度
4. **整合左右的結果**：最大深度代表最長路徑，因此選擇左右深度中較大的一方。使用 `Math.max(left, right)` 來取得
5. **加上當前節點後返回**：將左右深度的最大值加 1，即可將包含當前節點的深度返回給父節點。這個 1 代表「當前節點本身」

## 前提知識

### TreeNode（二元樹的節點）是什麼

表示二元樹各節點的類別。擁有值 `val`、左子節點 `left`、右子節點 `right` 三個欄位。若子節點不存在，則為 null。

```java
public class TreeNode {
    int val;              // 節點儲存的值
    TreeNode left;        // 左子節點（若無則為null）
    TreeNode right;       // 右子節點（若無則為null）
}
```

### 遞迴（Recursion）是什麼

函式呼叫自身的技巧。在樹結構中，用於對每個節點的子樹套用相同的處理。必須定義基礎情況（停止遞迴的條件），以防止無限迴圈。

```java
// 遞迴的基本結構
public int recursive(TreeNode node) {
    if (node == null) return 0;           // 基礎情況：遞迴的終止條件
    return recursive(node.left);          // 遞迴呼叫：解決子問題
}
```

### Math.max 是什麼

返回兩個整數中較大者的 Java 標準方法。

```java
Math.max(3, 5);    // → 5
Math.max(0, 0);    // → 0
```

## 計算複雜度

| | 值 |
|---|---|
| Time | O(n) — 每個節點恰好訪問一次 |
| Space | O(h) — 遞迴的呼叫堆疊會累積至樹的高度。最壞情況（傾斜的樹）為 O(n) |

## 程式碼

```java
// 輸入：二元樹的根節點 root（TreeNode 型別，可能為 null）
// 輸出：返回表示樹的最大深度的整數
public int maxDepth(TreeNode root) {
    // 基礎情況：若節點不存在，則深度為0
    // 當到達葉節點的子節點（null）時，遞迴停止
    if (root == null) return 0;

    // 遞迴求取左子樹的最大深度
    // 對以左子節點為根的子樹重複相同處理，最終到達基礎情況並返回值
    int left = maxDepth(root.left);

    // 遞迴求取右子樹的最大深度
    // 與左側相同，求取以右子節點為根的子樹深度
    int right = maxDepth(root.right);

    // 取左右中較深的一方，加上當前節點的1後返回
    // Math.max(left, right) 選擇具有最長路徑節點數的較深子樹
    // +1 代表計入當前節點 root 本身。父節點接收此返回值並用於自身的計算
    return 1 + Math.max(left, right);
}
```
