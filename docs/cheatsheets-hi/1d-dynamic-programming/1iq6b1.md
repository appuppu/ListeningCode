# Finding the Subarray With Maximum Product — अधिकतम गुणनफल वाला सन्निहित उपसरणी खोजना

## समस्या का सार

पूर्णांकों की एक सरणी `nums` दी गई है। सरणी में से **सन्निहित उपसरणी** चुनें जिसके तत्वों का गुणनफल अधिकतम हो, और वह **गुणनफल** लौटाएँ। उपसरणी एक या अधिक सन्निहित तत्वों से बनी होती है।

## मूल विचार

ऋणात्मक संख्याओं का आपस में गुणा करने पर धनात्मक संख्या प्राप्त होती है, इसलिए वर्तमान न्यूनतम मान (सबसे बड़ी ऋणात्मक संख्या) अगली ऋणात्मक संख्या से गुणा होकर अधिकतम मान बन सकता है। इसलिए, प्रत्येक स्थिति पर "वर्तमान अधिकतम गुणनफल" और "वर्तमान न्यूनतम गुणनफल" दोनों को ट्रैक करना आवश्यक है।

## विचार प्रक्रिया

1. **उपसरणी के गुणनफल की विशेषताओं पर विचार करें**: सन्निहित उपसरणी का गुणनफल निकालने की समस्या में, प्रत्येक नया तत्व जोड़ने पर "पिछली उपसरणी का गुणनफल × वर्तमान तत्व" से नया गुणनफल प्राप्त होता है। यह DP की अवधारणा के समान है, जहाँ पिछली अवस्था से अगली अवस्था निकाली जा सकती है
2. **ऋणात्मक संख्याएँ अधिकतम गुणनफल की गणना को जटिल बनाती हैं**: यदि केवल धनात्मक संख्याएँ हों तो केवल अधिकतम गुणनफल ट्रैक करना पर्याप्त है, लेकिन ऋणात्मक संख्याओं की उपस्थिति में "बड़ा ऋणात्मक गुणनफल × ऋणात्मक संख्या = बड़ा धनात्मक गुणनफल" की स्थिति उत्पन्न होती है। अर्थात, वर्तमान न्यूनतम गुणनफल (ऋणात्मक दिशा में सबसे बड़ा मान) भी ट्रैक करना अनिवार्य है, अन्यथा अधिकतम गुणनफल छूट सकता है
3. **प्रत्येक स्थिति पर उम्मीदवार तीन तक सीमित होते हैं**: स्थिति `i` पर अधिकतम गुणनफल के उम्मीदवार हैं: (a) `nums[i]` अकेला (नई उपसरणी शुरू करने की स्थिति में), (b) `curMax * nums[i]` (धनात्मक अधिकतम गुणनफल को विस्तारित करने की स्थिति में), (c) `curMin * nums[i]` (ऋणात्मक न्यूनतम गुणनफल का ऋणात्मक संख्या से उलटने की स्थिति में)। इन तीनों का अधिकतम मान नया `curMax` बनता है
4. **न्यूनतम गुणनफल भी उन्हीं तीन उम्मीदवारों से चुना जाता है**: न्यूनतम गुणनफल के उम्मीदवार भी वही तीन मान हैं, और उनका न्यूनतम मान नया `curMin` बनता है। अधिकतम और न्यूनतम को एक साथ अपडेट करने से ऋणात्मक संख्या द्वारा उलटाव को सही ढंग से पकड़ा जा सकता है
5. **अपडेट करते समय पिछले मान को सुरक्षित रखें**: `curMax` अपडेट करने के बाद `curMin` की गणना करने पर, `curMin` की गणना में अपडेट से पहले के `curMax` का उपयोग नहीं हो पाएगा। इसलिए, `curMax` अपडेट करने से पहले उसके मान को अस्थायी चर `temp` में सुरक्षित करें, और `curMin` की गणना में `temp` का उपयोग करें
6. **समग्र अधिकतम मान को अलग चर में प्रबंधित करें**: `curMax` वर्तमान स्थिति पर अधिकतम गुणनफल है, संपूर्ण सरणी का अधिकतम गुणनफल नहीं। प्रत्येक स्थिति पर `result = Math.max(result, curMax)` के रूप में समग्र अधिकतम गुणनफल अपडेट करें, और अंत में `result` लौटाएँ

## पूर्वापेक्षित ज्ञान

### उपसरणी के गुणनफल और DP का संबंध

उपसरणी के गुणनफल को पिछली स्थिति तक के गुणनफल में वर्तमान तत्व से गुणा करके विस्तारित किया जा सकता है। इस गुण का उपयोग करते हुए, प्रत्येक स्थिति पर "यहाँ समाप्त होने वाली उपसरणी का अधिकतम गुणनफल" को पिछली स्थिति के परिणाम से O(1) में गणना किया जा सकता है। यह DP की भाँति पिछली अवस्था को बनाए रखकर अगली अवस्था निकालने की विधि है।

### Math.max / Math.min क्या हैं

अनेक मानों में से अधिकतम और न्यूनतम मान प्राप्त करने के लिए Java के मेथड हैं। तीन या अधिक मानों की तुलना करने के लिए, इन्हें नेस्ट करके कॉल किया जाता है।

```java
Math.max(3, 7);                   // दो मानों का अधिकतम लौटाता है → 7
Math.min(3, 7);                   // दो मानों का न्यूनतम लौटाता है → 3
Math.max(a, Math.max(b, c));      // तीन मानों का अधिकतम लौटाता है
Math.min(a, Math.min(b, c));      // तीन मानों का न्यूनतम लौटाता है
```

### न्यूनतम मान को ट्रैक करना क्यों आवश्यक है

ऋणात्मक संख्याओं वाली सरणी में, गुणनफल का चिह्न प्रत्येक तत्व पर उलट सकता है। उदाहरण: `[-2, 3, -4]` की स्थिति में, स्थिति 1 पर न्यूनतम गुणनफल `-2 × 3 = -6` है, लेकिन स्थिति 2 पर `-6 × -4 = 24` बनकर अधिकतम गुणनफल बन जाता है। यदि केवल अधिकतम गुणनफल ट्रैक किया जाए, तो `-6` त्याग दिया जाएगा और `24` छूट जाएगा।

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(1) — उपयोग किए गए चर की संख्या निश्चित है और इनपुट आकार पर निर्भर नहीं है |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums (लंबाई 1 या अधिक)
// आउटपुट: सन्निहित उपसरणी के गुणनफल का अधिकतम मान int के रूप में लौटाएँ
public int maxProduct(int[] nums) {
    // result=समग्र अधिकतम गुणनफल, curMax=वर्तमान स्थिति पर समाप्त होने वाली उपसरणी का अधिकतम गुणनफल, curMin=वही न्यूनतम गुणनफल
    // पहले तत्व से बनी उपसरणी प्रारंभिक अवस्था है
    int result = nums[0];
    int curMax = nums[0];
    int curMin = nums[0];

    // i=0 प्रारंभीकरण में संसाधित हो चुका है इसलिए i=1 से शुरू करें
    for (int i = 1; i < nums.length; i++) {
        int n = nums[i];
        // curMax को अपडेट करने से पहले सुरक्षित करें (curMin की गणना में अपडेट से पहले का मान आवश्यक है)
        int temp = curMax;

        // तीन उम्मीदवारों में से अधिकतम चुनें:
        // n अकेला → नई उपसरणी शुरू करने की स्थिति
        // temp * n → पिछले अधिकतम गुणनफल को विस्तारित करने की स्थिति
        // curMin * n → पिछला न्यूनतम गुणनफल (ऋणात्मक) ऋणात्मक n से उलटकर अधिकतम बनने की स्थिति
        curMax = Math.max(n,
            Math.max(temp * n, curMin * n));

        // उन्हीं तीन उम्मीदवारों में से न्यूनतम चुनें (temp द्वारा अपडेट से पहले का curMax उपयोग करने से, ऊपर के अपडेट का प्रभाव पड़े बिना सही गणना होती है)
        curMin = Math.min(n,
            Math.min(temp * n, curMin * n));

        // curMax वर्तमान स्थिति का अधिकतम गुणनफल है, संपूर्ण सरणी का नहीं, इसलिए अलग चर result में समग्र अधिकतम गुणनफल प्रबंधित करें
        result = Math.max(result, curMax);
    }
    // result में संपूर्ण सरणी का अधिकतम उपसरणी गुणनफल संग्रहित है
    return result;
}
```
