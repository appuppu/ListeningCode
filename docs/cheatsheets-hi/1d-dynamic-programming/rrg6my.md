# Counting Ways to Decode a Numeric String — संख्यात्मक स्ट्रिंग को अल्फाबेट में बदलने के कुल तरीकों की संख्या ज्ञात करना

## समस्या का सार

केवल अंकों से बनी एक स्ट्रिंग `s` दी गई है। A=1, B=2, ..., Z=26 इस संबंध के आधार पर, स्ट्रिंग को अल्फाबेट अनुक्रम में डिकोड करने के कितने तरीके हैं, वह संख्या लौटानी है। उदाहरण के लिए "226" को "BZ"(2,26), "VF"(22,6), "BBF"(2,2,6) — इन 3 तरीकों से डिकोड किया जा सकता है।

## मूल विचार

प्रत्येक स्थिति पर डिकोड तरीकों की संख्या "1 अक्षर डिकोड (1 अंक) करने पर शेष तरीकों की संख्या" और "2 अक्षर डिकोड (2 अंक) करने पर शेष तरीकों की संख्या" के योग से प्राप्त होती है। यह निर्भरता केवल पिछले 2 परिणामों तक सीमित है, इसलिए 2 वेरिएबल पर्याप्त हैं।

## विचार प्रक्रिया

1. **प्रत्येक स्थिति पर अधिकतम 2 विकल्प हैं**: स्थिति `i` का अंक देखते समय, 1 अंक (1〜9) के रूप में 1 अक्षर में डिकोड करना या 2 अंक (10〜26) के रूप में 1 अक्षर में डिकोड करना — अधिकतम 2 विकल्प होते हैं। यह चुनाव पुनरावर्ती रूप से होता है, इसलिए प्रत्येक स्थिति पर डिकोड तरीकों की संख्या को व्यवस्थित रूप से ज्ञात करना आवश्यक है
2. **'0' को अकेले डिकोड नहीं किया जा सकता**: '0' से संबंधित कोई अल्फाबेट नहीं है। यदि स्थिति `i` का अंक '0' है, तो उस स्थिति से शुरू होने वाला 1 अंक का डिकोड असंभव है, इसलिए तरीकों की संख्या 0 होती है। '0' को केवल पिछले अंक के साथ मिलाकर 10 या 20 के रूप में ही डिकोड किया जा सकता है
3. **DP की पुनरावृत्ति सूत्र बनाना**: `dp[i]` को "स्थिति `i` से अंत तक डिकोड तरीकों की संख्या" के रूप में परिभाषित करते हैं। यदि स्थिति `i` का अंक '0' नहीं है, तो 1 अंक डिकोड करने पर शेष `dp[i+1]` जोड़ते हैं। इसके अतिरिक्त यदि स्थिति `i` और `i+1` के 2 अंक 10〜26 की सीमा में हैं, तो 2 अंक डिकोड करने पर शेष `dp[i+2]` भी जोड़ते हैं। अर्थात `dp[i] = dp[i+1] + dp[i+2]` (शर्तों के अधीन)
4. **निर्भरता केवल अगले 2 पर है**: `dp[i]` केवल `dp[i+1]` और `dp[i+2]` पर निर्भर करता है। इसलिए पूरी array रखने की आवश्यकता नहीं है, केवल 2 वेरिएबल (`next1` = `dp[i+1]`, `next2` = `dp[i+2]`) से गणना की जा सकती है। इससे Space O(1) प्राप्त होता है
5. **अंत से शुरुआत की ओर स्कैन करना**: `dp[i]` `dp[i+1]` और `dp[i+2]` पर निर्भर करता है, इसलिए अंत वाला भाग पहले निश्चित होना चाहिए। इसलिए स्ट्रिंग के अंत से शुरुआत की ओर लूप चलाकर प्रत्येक स्थिति पर तरीकों की संख्या की गणना करते हैं
6. **अंत में लौटाने वाला मान**: लूप पूरा होने के बाद, `next1` में `dp[0]` (पूरी स्ट्रिंग के डिकोड तरीकों की संख्या) संग्रहित होती है। इस मान को लौटाते हैं

## पूर्वापेक्षित ज्ञान

### डायनामिक प्रोग्रामिंग (DP) क्या है

बड़ी समस्या को छोटी उप-समस्याओं में विभाजित करके, उप-समस्याओं के परिणामों का पुन: उपयोग करके संपूर्ण उत्तर ज्ञात करने की विधि है। एक ही उप-समस्या की बार-बार पुनर्गणना से बचने के लिए, एक बार गणना किए गए परिणाम को संग्रहित (मेमोइज़ेशन) करते हैं या क्रम से गणना (बॉटम-अप) करते हैं।

```java
// बॉटम-अप DP का विशिष्ट पैटर्न: फिबोनाची अनुक्रम
int prev2 = 0, prev1 = 1;
for (int i = 2; i <= n; i++) {
    int current = prev1 + prev2;  // केवल पिछले 2 परिणामों से वर्तमान मान की गणना करना
    prev2 = prev1;                // अगले इटरेशन की तैयारी के लिए वेरिएबल को स्लाइड करना
    prev1 = current;
}
// prev1 में अंतिम परिणाम संग्रहित है
```

### Integer.parseInt क्या है

स्ट्रिंग को पूर्णांक में बदलने वाला मेथड है। उप-स्ट्रिंग को संख्यात्मक मान के रूप में मूल्यांकन करने के लिए उपयोग किया जाता है।

```java
Integer.parseInt("26");          // स्ट्रिंग "26" को पूर्णांक 26 में बदलता है → 26
Integer.parseInt("09");          // स्ट्रिंग "09" को पूर्णांक 9 में बदलता है → 9
```

### String.substring क्या है

स्ट्रिंग से निर्दिष्ट सीमा की उप-स्ट्रिंग प्राप्त करने वाला मेथड है। आर्गुमेंट प्रारंभ इंडेक्स (सम्मिलित) और अंत इंडेक्स (सम्मिलित नहीं) हैं।

```java
String s = "226";
s.substring(0, 2);   // इंडेक्स 0 से 1 तक की उप-स्ट्रिंग लौटाता है → "22"
s.substring(1, 3);   // इंडेक्स 1 से 2 तक की उप-स्ट्रिंग लौटाता है → "26"
```

### String.charAt क्या है

स्ट्रिंग में निर्दिष्ट स्थिति पर 1 अक्षर लौटाने वाला मेथड है। char प्रकार लौटाता है, इसलिए अक्षर '0' से तुलना करके अंक की पहचान की जा सकती है।

```java
String s = "206";
s.charAt(0);          // इंडेक्स 0 का अक्षर लौटाता है → '2'
s.charAt(1);          // इंडेक्स 1 का अक्षर लौटाता है → '0'
s.charAt(1) == '0';   // अक्षर '0' है या नहीं इसकी जाँच करता है → true
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n) — स्ट्रिंग को अंत से शुरुआत तक केवल 1 बार स्कैन करना पर्याप्त है |
| Space | O(1) — केवल 2 वेरिएबल (next1, next2) से गणना होती है, array का उपयोग नहीं होता |

## कोड

```java
// इनपुट: केवल अंकों से बनी स्ट्रिंग s
// आउटपुट: स्ट्रिंग s को अल्फाबेट अनुक्रम में डिकोड करने के कुल तरीकों की संख्या int के रूप में लौटाना
public int numDecodings(String s) {
    // next1 = 1 दाईं स्थिति से तरीकों की संख्या (dp[i+1]), next2 = 2 दाईं स्थिति से तरीकों की संख्या (dp[i+2])
    // स्ट्रिंग के अंत से दाईं ओर "खाली स्ट्रिंग को डिकोड करने का तरीका = 1" के रूप में परिभाषित है, इसलिए प्रारंभिक मान 1 है
    int next1 = 1, next2 = 1;

    // dp[i] dp[i+1] और dp[i+2] पर निर्भर करता है, इसलिए दाईं ओर को पहले निश्चित करने के लिए अंत से शुरुआत की ओर स्कैन करते हैं
    for (int i = s.length() - 1; i >= 0; i--) {
        int current;

        if (s.charAt(i) == '0') {
            // '0' अकेले किसी भी अल्फाबेट से संबंधित नहीं है, इसलिए इस स्थिति से शुरू होने वाले डिकोड तरीके 0 हैं
            // '0' को केवल पिछले अंक के साथ मिलाकर 10 या 20 के रूप में ही डिकोड किया जा सकता है
            current = 0;
        } else {
            // 1 अंक डिकोड: स्थिति i का अंक (1〜9) को 1 अक्षर के रूप में, शेष i+1 आगे next1 तरीके
            current = next1;

            // 2 अंक डिकोड संभव है या नहीं इसकी जाँच करना (i+1 स्ट्रिंग की सीमा में हो तो 2 अंक प्राप्त कर सकते हैं)
            if (i + 1 < s.length()) {
                // s.substring(i, i+2) से 2 अंकों की उप-स्ट्रिंग प्राप्त करके पूर्णांक में बदलना
                int two = Integer.parseInt(
                    s.substring(i, i + 2));
                // यदि 2 अंक 10〜26 की सीमा में हैं, तो 2 अंकों को 1 अक्षर के रूप में डिकोड करके शेष i+2 आगे next2 तरीके जोड़ना
                if (two >= 10 && two <= 26)
                    current += next2;
            }
        }

        // वेरिएबल को 1 बाईं ओर स्लाइड करना: वर्तमान current अगले इटरेशन में next1 (1 दाईं ओर) बन जाता है
        next2 = next1;
        next1 = current;
    }

    // लूप पूरा होने के बाद, next1 में अंतिम गणना किया गया current (= dp[0]) संग्रहित है
    // यह पूरी स्ट्रिंग के डिकोड तरीकों की कुल संख्या है
    return next1;
}
```
