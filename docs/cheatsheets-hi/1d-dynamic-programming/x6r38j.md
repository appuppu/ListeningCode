# Counting Ways to Climb Stairs — n सीढ़ियों को 1 या 2 सीढ़ी एक बार में चढ़कर कुल तरीकों की संख्या ज्ञात करना

## समस्या का सार

एक पूर्णांक `n` (सीढ़ियों की संख्या) दिया गया है। एक बार में 1 सीढ़ी या 2 सीढ़ी चढ़ सकते हैं, तब शीर्ष (nवीं सीढ़ी) तक पहुँचने के **कुल भिन्न तरीकों की संख्या** लौटानी है।

## मूल विचार

nवीं सीढ़ी तक पहुँचने के लिए या तो "n-1वीं सीढ़ी से 1 सीढ़ी चढ़ना" या "n-2वीं सीढ़ी से 2 सीढ़ी चढ़ना" — केवल ये दो ही विकल्प हैं। अर्थात `ways(n) = ways(n-1) + ways(n-2)` — यह फिबोनाची अनुक्रम के समान पुनरावृत्ति संबंध है। केवल पिछले 2 मानों को रखने से, बिना सरणी के O(1) स्थान में गणना की जा सकती है।

## विचार प्रक्रिया

1. **अंतिम कदम से पीछे की ओर सोचना**: nवीं सीढ़ी तक पहुँचने से ठीक पहले की स्थिति या तो "n-1वीं सीढ़ी पर होना" या "n-2वीं सीढ़ी पर होना" — केवल ये दो ही संभव हैं। इसलिए, nवीं सीढ़ी तक पहुँचने के कुल तरीके `ways(n) = ways(n-1) + ways(n-2)` पुनरावृत्ति संबंध से व्यक्त किए जा सकते हैं
2. **आधार स्थितियाँ निर्धारित करना**: 1 सीढ़ी के लिए 1 तरीका (1 सीढ़ी चढ़ना), 2 सीढ़ियों के लिए 2 तरीके (1+1 या 2)। ये दोनों पुनरावृत्ति संबंध के प्रारंभिक बिंदु हैं
3. **बॉटम-अप गणना करना**: यदि ऊपर से पुनरावर्तन (recursion) से गणना करें तो एक ही उप-समस्या को कई बार हल करना पड़ता है। इसके बजाय, छोटे मानों से क्रमशः गणना करने वाली बॉटम-अप विधि अपनाने से प्रत्येक मान की गणना केवल एक बार करनी पड़ती है
4. **केवल 2 चर की आवश्यकता है**: पुनरावृत्ति संबंध `ways(i) = ways(i-1) + ways(i-2)` केवल पिछले 2 मानों को संदर्भित करता है। पूरी सरणी रखने की आवश्यकता नहीं है, केवल 2 चर (`prev2` और `prev1`) पर्याप्त हैं
5. **लूप में चरों को अपडेट करना**: `i = 3` से `n` तक क्रमशः, `curr = prev1 + prev2` से वर्तमान मान की गणना करते हैं, फिर `prev2 = prev1`, `prev1 = curr` से स्लाइड करके अगले पुनरावृत्ति के लिए तैयार करते हैं
6. **अंतिम रूप से क्या लौटाना है**: लूप समाप्त होने के बाद, `prev1` में nवीं सीढ़ी तक पहुँचने के कुल तरीकों की संख्या संग्रहीत होती है, इसलिए `prev1` लौटाते हैं

## पूर्वापेक्षित ज्ञान

### डायनामिक प्रोग्रामिंग (Dynamic Programming) क्या है

बड़ी समस्या को छोटी उप-समस्याओं में विभाजित करके, प्रत्येक उप-समस्या के परिणाम को रिकॉर्ड करते हुए हल करने की विधि है। एक ही गणना को दोहराने से बचकर दक्षता प्राप्त की जाती है। बॉटम-अप विधि में सबसे छोटी उप-समस्या से क्रमशः हल किया जाता है।

```java
// बॉटम-अप DP का मूल पैटर्न (सरणी संस्करण)
int[] dp = new int[n + 1];   // उप-समस्याओं के परिणाम सहेजने वाली सरणी
dp[1] = 1;                    // आधार स्थिति 1
dp[2] = 2;                    // आधार स्थिति 2
for (int i = 3; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];  // पुनरावृत्ति संबंध से गणना करना
}
// dp[n] अंतिम उत्तर है
```

### स्लाइडिंग वेरिएबल क्या है

सरणी के बजाय केवल 2 चरों से पिछले मानों को रखने की तकनीक है। जब पुनरावृत्ति संबंध एक निश्चित संख्या में पिछले मानों को संदर्भित करता है, तो पूरी सरणी रखने की आवश्यकता नहीं रहती और स्थान जटिलता O(n) से O(1) तक कम हो जाती है।

```java
int prev2 = 1;  // 2 पीछे के मान को रखने वाला चर
int prev1 = 2;  // 1 पीछे के मान को रखने वाला चर
int curr = prev1 + prev2;  // वर्तमान मान की गणना करना
prev2 = prev1;  // prev2 को स्लाइड करना (prev1 का मान लेना)
prev1 = curr;   // prev1 को स्लाइड करना (curr का मान लेना)
```

## जटिलता विश्लेषण

| | मान |
|---|---|
| Time | O(n) — 3 से n तक केवल एक बार लूप चलता है |
| Space | O(1) — केवल 2 चर (prev2, prev1) का उपयोग होता है |

## कोड

```java
// इनपुट: पूर्णांक n (सीढ़ियों की संख्या)
// आउटपुट: शीर्ष तक पहुँचने के कुल भिन्न तरीकों की संख्या int के रूप में लौटाना
public int climbStairs(int n) {
    // आधार स्थिति: 1 सीढ़ी हो तो केवल 1 तरीका है। आगे का लूप i=3 से शुरू होता है, इसलिए n=1 को पहले संभालना है
    if (n == 1) return 1;

    // prev2 दो सीढ़ी पहले के चढ़ने के तरीकों की संख्या है। प्रारंभिक मान 1वीं सीढ़ी के तरीके (1 तरीका) के अनुरूप है
    int prev2 = 1;
    // prev1 एक सीढ़ी पहले के चढ़ने के तरीकों की संख्या है। प्रारंभिक मान 2वीं सीढ़ी के तरीके (2 तरीके: 1+1 या 2) के अनुरूप है
    int prev1 = 2;

    // i वर्तमान में गणना की जा रही सीढ़ी की संख्या है। 1वीं और 2वीं सीढ़ी प्रारंभिक मानों के रूप में सेट हैं इसलिए 3वीं सीढ़ी से शुरू करते हैं
    for (int i = 3; i <= n; i++) {
        // पुनरावृत्ति संबंध: iवीं सीढ़ी के तरीके = (i-1)वीं सीढ़ी के तरीके + (i-2)वीं सीढ़ी के तरीके
        int curr = prev1 + prev2;
        // सावधानी: prev2 को पहले अपडेट करना आवश्यक है अन्यथा prev1 का मूल मान खो जाएगा
        prev2 = prev1;
        prev1 = curr;
    }

    // लूप समाप्त होने के बाद, prev1 में nवीं सीढ़ी तक पहुँचने के कुल तरीकों की संख्या संग्रहीत है
    return prev1;
}
```
