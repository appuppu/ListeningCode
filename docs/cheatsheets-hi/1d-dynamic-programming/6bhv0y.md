# Finding the Longest Palindromic Substring — स्ट्रिंग में सबसे लंबी पैलिंड्रोम सबस्ट्रिंग खोजना

## समस्या का सार

एक स्ट्रिंग `s` दी गई है। `s` में से, आगे से पढ़ने पर और पीछे से पढ़ने पर समान रहने वाली **सबसे लंबी सबस्ट्रिंग (पैलिंड्रोम)** को खोजकर लौटाना है। यदि समान लंबाई के कई पैलिंड्रोम हों, तो उनमें से कोई भी एक लौटाना पर्याप्त है।

## मूल विचार

पैलिंड्रोम में अवश्य एक "केंद्र" होता है। स्ट्रिंग की प्रत्येक स्थिति को केंद्र मानकर बाएँ और दाएँ विस्तार करने पर, जब तक अक्षर मेल खाते हैं तब तक पैलिंड्रोम को बढ़ाने से सभी पैलिंड्रोम बिना चूके खोजे जा सकते हैं। केंद्र के लिए "1 अक्षर (विषम लंबाई)" और "दो आसन्न अक्षरों के बीच (सम लंबाई)" दोनों प्रकारों को आज़माना आवश्यक है।

## विचार प्रक्रिया

1. **पैलिंड्रोम केंद्र से सममित रूप में फैलता है**: पैलिंड्रोम `"racecar"` केंद्र `e` से बाएँ-दाएँ `c→a→r` के रूप में सममित रूप से फैलता है। इस गुण का उपयोग करके, केंद्र को स्थिर रखकर बाएँ-दाएँ विस्तार करने से पैलिंड्रोम का पता लगाया जा सकता है
2. **केंद्र के उम्मीदवार 2 प्रकार के होते हैं**: विषम लंबाई के पैलिंड्रोम (उदाहरण: `"aba"`) में 1 अक्षर केंद्र बनता है, और सम लंबाई के पैलिंड्रोम (उदाहरण: `"abba"`) में दो आसन्न अक्षरों के बीच केंद्र बनता है। सभी पैलिंड्रोम बिना चूके खोजने के लिए दोनों प्रकार के केंद्रों को आज़माना आवश्यक है
3. **विस्तार की प्रक्रिया निर्धारित करना**: केंद्र से बाएँ और दाएँ पॉइंटर `left` और `right` रखें, और जब तक `s.charAt(left) == s.charAt(right)` है तब तक `left` को बाएँ और `right` को दाएँ एक-एक स्थान बढ़ाएँ। अक्षर मेल न खाने पर या स्ट्रिंग के किनारे पर पहुँचने पर विस्तार समाप्त करें
4. **विस्तार के परिणाम से पैलिंड्रोम की लंबाई निकालना**: विस्तार समाप्त होने पर `left` और `right` पैलिंड्रोम की सीमा से एक-एक स्थान बाहर होते हैं। इसलिए पैलिंड्रोम की लंबाई `right - left - 1` से गणना की जा सकती है
5. **सबसे लंबे पैलिंड्रोम की आरंभ और समाप्ति स्थिति रिकॉर्ड करना**: प्रत्येक केंद्र से प्राप्त पैलिंड्रोम की लंबाई यदि अब तक की सबसे लंबी से अधिक हो, तो आरंभ स्थिति `start` और समाप्ति स्थिति `end` को अपडेट करें। केंद्र स्थिति `i` और पैलिंड्रोम की लंबाई `len` से, `start = i - (len - 1) / 2`, `end = i + len / 2` द्वारा गणना की जा सकती है
6. **अंत में सबस्ट्रिंग लौटाना**: सभी केंद्रों को आज़माने के बाद, `s.substring(start, end + 1)` से सबसे लंबी पैलिंड्रोम सबस्ट्रिंग निकालकर लौटाएँ

## पूर्व ज्ञान

### पैलिंड्रोम (Palindrome) क्या है

आगे से पढ़ने पर और पीछे से पढ़ने पर समान रहने वाली स्ट्रिंग को पैलिंड्रोम कहते हैं। `"aba"`, `"abba"`, `"racecar"` पैलिंड्रोम हैं। एक अक्षर वाली स्ट्रिंग भी पैलिंड्रोम होती है।

### केंद्र विस्तार विधि (Expand Around Center) क्या है

पैलिंड्रोम के केंद्र को स्थिर करके, बाएँ और दाएँ एक-एक अक्षर बढ़ाते हुए पैलिंड्रोम होने की जाँच करने की विधि है। केंद्र से बाहर की ओर अक्षरों की तुलना करने के कारण, पैलिंड्रोम का पता कुशलतापूर्वक लगाया जा सकता है।

```java
// left=right होने पर विषम लंबाई का पैलिंड्रोम (1 अक्षर केंद्र) खोजा जाता है
// left=i, right=i+1 होने पर सम लंबाई का पैलिंड्रोम (2 अक्षर केंद्र) खोजा जाता है
expand(s, 2, 2);    // इंडेक्स 2 को केंद्र मानकर विषम लंबाई का पैलिंड्रोम खोजना
expand(s, 2, 3);    // इंडेक्स 2 और 3 के बीच को केंद्र मानकर सम लंबाई का पैलिंड्रोम खोजना
```

### String.substring(int, int) क्या है

स्ट्रिंग से सबस्ट्रिंग निकालने की विधि है। पहला आर्गुमेंट आरंभ इंडेक्स (शामिल) है, दूसरा आर्गुमेंट समाप्ति इंडेक्स (शामिल नहीं) है।

```java
String s = "babad";
s.substring(0, 3);   // "bab" लौटाता है (इंडेक्स 0, 1, 2 के अक्षर)
s.substring(1, 4);   // "aba" लौटाता है (इंडेक्स 1, 2, 3 के अक्षर)
```

### String.charAt(int) क्या है

स्ट्रिंग के निर्दिष्ट इंडेक्स पर स्थित अक्षर लौटाने की विधि है।

```java
String s = "babad";
s.charAt(0);   // 'b' लौटाता है
s.charAt(2);   // 'b' लौटाता है
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n²) — प्रत्येक इंडेक्स को केंद्र मानकर अधिकतम O(n) का विस्तार किया जाता है, और केंद्र n होते हैं |
| Space | O(1) — केवल पॉइंटर और लंबाई रिकॉर्ड करने वाले चर का उपयोग होता है, अतिरिक्त डेटा संरचना की आवश्यकता नहीं |

## कोड

```java
// इनपुट: स्ट्रिंग s
// आउटपुट: s में सबसे लंबी पैलिंड्रोम सबस्ट्रिंग को String के रूप में लौटाना

// केंद्र से बाएँ-दाएँ विस्तार करके पैलिंड्रोम की लंबाई लौटाने वाली सहायक विधि
private int expand(String s, int left, int right) {
    // बाएँ और दाएँ अक्षर मेल खाते हैं और स्ट्रिंग की सीमा के अंदर हैं तब तक विस्तार जारी रखना
    while (left >= 0
            && right < s.length()
            && s.charAt(left)
            == s.charAt(right)) {
        left--;  // बाएँ एक स्थान बढ़ाना
        right++; // दाएँ एक स्थान बढ़ाना
    }
    // विस्तार समाप्त होने पर, left और right पैलिंड्रोम की सीमा से एक-एक स्थान बाहर होते हैं
    // इसलिए पैलिंड्रोम की लंबाई right - left - 1 से प्राप्त होती है
    return right - left - 1;
}

public String longestPalindrome(String s) {
    // सबसे लंबे पैलिंड्रोम के आरंभ और समाप्ति इंडेक्स रिकॉर्ड करने वाले चर
    // प्रारंभिक मान 0 है, जो कम से कम पहले अक्षर के स्वयं लंबाई 1 के पैलिंड्रोम होने को दर्शाता है
    int start = 0, end = 0;

    // प्रत्येक इंडेक्स i को पैलिंड्रोम के केंद्र उम्मीदवार के रूप में स्कैन करना
    for (int i = 0; i < s.length(); i++) {
        // विषम लंबाई के पैलिंड्रोम (1 अक्षर केंद्र) का विस्तार करके लंबाई प्राप्त करना
        int odd = expand(s, i, i);
        // सम लंबाई के पैलिंड्रोम (2 अक्षर केंद्र) का विस्तार करके लंबाई प्राप्त करना
        int even = expand(s, i, i + 1);
        // विषम लंबाई और सम लंबाई में से बड़ी वाली को अपनाना
        int len = Math.max(odd, even);

        // वर्तमान सबसे लंबे पैलिंड्रोम की लंबाई (end - start + 1) से अधिक होने पर आरंभ और समाप्ति स्थिति अपडेट करना
        if (len > end - start + 1) {
            // (len - 1) / 2 केंद्र से बाईं ओर की दूरी है
            start = i - (len - 1) / 2;
            // len / 2 केंद्र से दाईं ओर की दूरी है
            end = i + len / 2;
        }
    }
    // substring का दूसरा आर्गुमेंट "शामिल नहीं" होता है, इसलिए end + 1 निर्दिष्ट करके end के अक्षर तक शामिल करना
    return s.substring(start, end + 1);
}
```
