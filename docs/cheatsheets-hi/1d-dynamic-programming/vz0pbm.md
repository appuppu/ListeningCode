# Finding the Minimum Cost to Climb Stairs — सीढ़ी के शीर्ष तक पहुँचने की न्यूनतम लागत ज्ञात करना

## समस्या का सार

एक पूर्णांक सरणी `cost` दी गई है, जहाँ `cost[i]` i-वीं सीढ़ी पर कदम रखने की लागत को दर्शाता है। आप स्टेप 0 या स्टेप 1 से शुरू कर सकते हैं, और प्रत्येक स्टेप पर 1 सीढ़ी या 2 सीढ़ियाँ चढ़ सकते हैं। सीढ़ी के **शीर्ष** (सरणी के अंत से एक स्थान आगे) तक पहुँचने की न्यूनतम कुल लागत लौटाएँ।

## मूल विचार

प्रत्येक सीढ़ी तक पहुँचने की न्यूनतम लागत "1 सीढ़ी पहले से आने की स्थिति" और "2 सीढ़ी पहले से आने की स्थिति" में से छोटे मान से निर्धारित होती है। इस गणना के लिए केवल पिछले 2 परिणामों की आवश्यकता होती है, इसलिए सरणी रखे बिना केवल 2 चरों से न्यूनतम लागत ज्ञात की जा सकती है।

## विचार प्रक्रिया

1. **शीर्ष तक पहुँचने के 2 तरीके हैं**: शीर्ष (इंडेक्स n) तक, एक पिछली सीढ़ी (n-1) से 1 सीढ़ी चढ़कर या दो पिछली सीढ़ी (n-2) से 2 सीढ़ियाँ चढ़कर पहुँचा जा सकता है। दोनों लागतों में से छोटी वाली उत्तर होगी
2. **प्रत्येक सीढ़ी की न्यूनतम लागत को पुनरावर्ती रूप से परिभाषित किया जा सकता है**: सीढ़ी i तक पहुँचने की न्यूनतम लागत को `dp[i]` मानें तो, `dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])` यह पुनरावृत्ति संबंध बनता है। यह "1 सीढ़ी पहले की न्यूनतम लागत + उस सीढ़ी की लागत" और "2 सीढ़ी पहले की न्यूनतम लागत + उस सीढ़ी की लागत" में से छोटा मान है
3. **प्रारंभिक शर्तें निर्धारित करें**: स्टेप 0 या स्टेप 1 से शुरू किया जा सकता है, इसलिए सीढ़ी 0 और सीढ़ी 1 तक पहुँचने की लागत दोनों 0 है। अर्थात `dp[0] = 0`, `dp[1] = 0` होगा
4. **पूरी सरणी की आवश्यकता नहीं है, केवल पिछले 2 मान पर्याप्त हैं**: पुनरावृत्ति संबंध `dp[i]` केवल `dp[i-1]` और `dp[i-2]` पर निर्भर करता है। इसलिए, सरणी के बजाय केवल 2 चर `prev1` (1 पिछला) और `prev2` (2 पिछला) रखकर गणना की जा सकती है
5. **चरों को अपडेट करते हुए आगे बढ़ें**: सीढ़ी 2 से सीढ़ी n तक क्रम में लूप चलाएँ, हर बार `curr` की गणना करने के बाद, `prev2 = prev1`, `prev1 = curr` के रूप में स्लाइड करें। लूप समाप्त होने पर `prev1` शीर्ष तक पहुँचने की न्यूनतम लागत होगी

## पूर्वापेक्षित ज्ञान

### गतिशील प्रोग्रामिंग (Dynamic Programming) क्या है

एक बड़ी समस्या को छोटी उप-समस्याओं में विभाजित करके, उप-समस्याओं के परिणामों का पुन: उपयोग करके कुशलतापूर्वक हल ज्ञात करने की विधि है। इस समस्या में "सीढ़ी i तक की न्यूनतम लागत" को उप-समस्या मानकर, छोटे इंडेक्स से क्रम में हल किया जाता है (बॉटम-अप विधि)।

### Math.min क्या है

दो पूर्णांकों में से छोटा मान लौटाने वाली Java की मानक विधि है। दो विकल्पों में से कम लागत वाला चुनने के लिए इसका उपयोग किया जाता है।

```java
Math.min(5, 3);    // 3 लौटाता है — दो तर्कों में से छोटा मान लौटाता है
Math.min(10, 10);  // 10 लौटाता है — समान मान होने पर वही मान लौटाता है
```

### स्थान अनुकूलन की अवधारणा

जब DP सरणी का प्रत्येक तत्व केवल पिछले कुछ तत्वों पर निर्भर करता है, तो पूरी सरणी रखने के बजाय, केवल आवश्यक संख्या में चरों से गणना की जा सकती है। इस समस्या में केवल `dp[i-1]` और `dp[i-2]` की आवश्यकता है, इसलिए 2 चर पर्याप्त हैं।

```java
int prev2 = 0;  // dp[i-2] के समतुल्य चर
int prev1 = 0;  // dp[i-1] के समतुल्य चर
int curr;       // dp[i] के समतुल्य चर (हर बार गणना करके अपडेट किया जाता है)
```

## जटिलता विश्लेषण

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(1) — केवल 2 चरों का उपयोग करता है, सरणी के आकार पर निर्भर नहीं करता |

## कोड

```java
// इनपुट: पूर्णांक सरणी cost (प्रत्येक सीढ़ी पर कदम रखने की लागत)
// आउटपुट: सीढ़ी के शीर्ष (इंडेक्स n) तक पहुँचने की न्यूनतम कुल लागत int के रूप में लौटाएँ
public int minCostClimbingStairs(int[] cost) {
    // सरणी की लंबाई प्राप्त करें। शीर्ष इंडेक्स n की स्थिति पर है (सरणी के अंत से एक आगे)
    int n = cost.length;

    // prev2=2 सीढ़ी पहले तक की न्यूनतम लागत, prev1=1 सीढ़ी पहले तक की न्यूनतम लागत
    // स्टेप 0 और 1 से शुरू किया जा सकता है इसलिए प्रारंभिक लागत 0 है
    int prev2 = 0, prev1 = 0;

    // सीढ़ी 2 से शीर्ष (सीढ़ी n) तक क्रम में न्यूनतम लागत की गणना करें। i वह सीढ़ी है जिस तक वर्तमान में पहुँचने का प्रयास किया जा रहा है
    for (int i = 2; i <= n; i++) {
        // prev1 + cost[i-1]: 1 पिछली सीढ़ी से 1 सीढ़ी चढ़कर आने की कुल लागत
        // prev2 + cost[i-2]: 2 पिछली सीढ़ी से 2 सीढ़ियाँ चढ़कर आने की कुल लागत
        // छोटे मान को चुनें
        int curr = Math.min(
            prev1 + cost[i - 1],
            prev2 + cost[i - 2]);

        // चरों को एक स्थान आगे स्लाइड करें
        // ध्यान दें: prev2 को पहले अपडेट करना आवश्यक है अन्यथा prev1 का मूल मान खो जाएगा
        prev2 = prev1;
        prev1 = curr;
    }

    // prev1 में लूप के अंतिम इटरेशन (i = n) में गणना की गई शीर्ष तक की न्यूनतम लागत संग्रहित है
    return prev1;
}
```
