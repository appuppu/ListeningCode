# Determining if a String Can Be Segmented Into Dictionary Words — यह निर्धारित करना कि किसी स्ट्रिंग को शब्दकोश के शब्दों में विभाजित किया जा सकता है या नहीं

## समस्या का सार

एक स्ट्रिंग `s` और शब्दकोश की शब्द सूची `wordDict` दी गई है। यह निर्धारित करना है कि `s` को शब्दकोश में मौजूद शब्दों के संयोजन के रूप में विभाजित किया जा सकता है या नहीं, और परिणाम **boolean** के रूप में लौटाना है। शब्दकोश के प्रत्येक शब्द का कितनी भी बार पुनः उपयोग किया जा सकता है।

## मूल विचार

यदि स्ट्रिंग की शुरुआत से प्रत्येक स्थिति `i` तक की उप-स्ट्रिंग के लिए "विभाजित किया जा सकता है या नहीं" यह दर्ज किया जाए, तो स्थिति `i` का निर्धारण इस बात पर निर्भर करता है कि "किसी विभाजन बिंदु `j` तक विभाजन संभव है" और "`j` से `i` तक की उप-स्ट्रिंग शब्दकोश में मौजूद है"।

## विचार प्रक्रिया

1. **उप-समस्याओं में विभाजित किया जा सकता है**: स्ट्रिंग `s` के पहले `i` अक्षर विभाजन योग्य हैं या नहीं, यह निर्धारित करने के लिए किसी स्थिति `j` पर दो भागों में विभाजित करें — "पहले `j` अक्षर विभाजन योग्य हैं" और "`j` से `i` तक शब्दकोश का शब्द है" — यदि दोनों शर्तें पूरी हों तो विभाजन संभव है। यह संरचना डायनैमिक प्रोग्रामिंग के लिए उपयुक्त है
2. **DP की परिभाषा तय करें**: `dp[i]` को "स्ट्रिंग `s` के पहले `i` अक्षर केवल शब्दकोश के शब्दों से विभाजित किए जा सकते हैं या नहीं" दर्शाने वाला boolean मानें। अंतिम उत्तर `dp[n]` (`n` स्ट्रिंग की लंबाई है) होगा
3. **आधार शर्त निर्धारित करें**: रिक्त स्ट्रिंग को हमेशा विभाजित किया जा सकता है, इसलिए `dp[0] = true` रखें। इस आधार शर्त के कारण स्ट्रिंग की शुरुआत से आरंभ होने वाले शब्दकोश के शब्दों का पता लगाया जा सकता है
4. **संक्रमण सूत्र पर विचार करें**: `dp[i]` के `true` होने की शर्त यह है कि `0 ≤ j < i` में किसी `j` के लिए "`dp[j]` `true` है" और "`s.substring(j, i)` शब्दकोश में मौजूद है" — ये दोनों शर्तें एक साथ पूरी होनी चाहिए। सभी `j` की जाँच करके निर्धारण किया जा सकता है
5. **शब्दकोश की खोज को तेज़ करें**: शब्द सूची को HashSet में बदल देने पर, उप-स्ट्रिंग शब्दकोश में है या नहीं यह `contains` द्वारा O(1) में निर्धारित किया जा सकता है। सूची में रैखिक खोज करने से यह अधिक कुशल है
6. **शीघ्र समाप्ति से अनावश्यक कार्य हटाएं**: यदि किसी `j` पर `dp[i] = true` निश्चित हो जाए, तो आगे के `j` की जाँच आवश्यक नहीं है। `break` द्वारा आंतरिक लूप से बाहर निकलकर अगले `i` पर आगे बढ़ें

## पूर्वापेक्षित ज्ञान

### HashSet क्या है

यह एक डेटा संरचना है जो बिना दोहराव वाले तत्वों को संग्रहीत करती है। किसी तत्व के मौजूद होने का निर्धारण O(1) में किया जा सकता है। शब्दकोश की शब्द सूची में तेज़ी से खोज करने के लिए इसका उपयोग किया जाता है।

```java
Set<String> set = new HashSet<>();       // रिक्त HashSet बनाएं
set.add("apple");                        // तत्व जोड़ें
set.contains("apple");                   // तत्व मौजूद है या नहीं boolean में लौटाता है → true
```

### कंस्ट्रक्टर द्वारा List से Set में रूपांतरण

`HashSet` के कंस्ट्रक्टर में List पास करने पर, List के सभी तत्वों को Set में बदला जा सकता है। एक ही पंक्ति में शब्दकोश को HashSet में बदलने के लिए इसका उपयोग किया जाता है।

```java
List<String> list = Arrays.asList("a", "b", "c");
Set<String> set = new HashSet<>(list);   // List के सभी तत्वों को Set में बदलें
```

### substring क्या है

यह स्ट्रिंग के एक भाग को निकालने वाला मेथड है। `s.substring(j, i)` इंडेक्स `j` से `i - 1` तक के अक्षर लौटाता है। DP के संक्रमण में "स्थिति `j` से स्थिति `i` तक की उप-स्ट्रिंग" प्राप्त करने के लिए इसका उपयोग किया जाता है।

```java
String s = "leetcode";
s.substring(0, 4);                       // "leet" लौटाता है (इंडेक्स 0 से 3)
s.substring(4, 8);                       // "code" लौटाता है (इंडेक्स 4 से 7)
```

### DP ऐरे (boolean ऐरे) क्या है

डायनैमिक प्रोग्रामिंग में उप-समस्याओं के परिणामों को संग्रहीत करने वाला ऐरे। `boolean[] dp = new boolean[n + 1]` से बनाने पर सभी तत्व `false` से आरंभ होते हैं। `dp[i]` में `true` असाइन करके "पहले `i` अक्षर विभाजन योग्य हैं" यह परिणाम दर्ज किया जाता है।

```java
boolean[] dp = new boolean[5];           // [false, false, false, false, false] से आरंभ होता है
dp[0] = true;                           // आधार शर्त निर्धारित करें
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n^2) — बाहरी लूप n बार चलता है, आंतरिक लूप अधिकतम n बार चलता है, और यदि प्रत्येक चरण में substring उत्पन्न करने में O(n) लगता है तो सटीक रूप से O(n^3) है, लेकिन औसतन O(n^2) माना जाता है |
| Space | O(n) — आकार n+1 का DP ऐरे और HashSet में शब्दकोश के शब्द संग्रहीत किए जाते हैं |

## कोड

```java
// इनपुट: स्ट्रिंग s और शब्दकोश की शब्द सूची wordDict
// आउटपुट: यदि s को केवल शब्दकोश के शब्दों से विभाजित किया जा सकता है तो true, अन्यथा false लौटाएं
public boolean wordBreak(String s, List<String> wordDict) {
    // शब्दकोश की शब्द सूची को HashSet में बदलकर खोज को O(1) करें
    Set<String> set = new HashSet<>(wordDict);
    // स्ट्रिंग की लंबाई को वेरिएबल में सहेजें
    int n = s.length();

    // dp[i] = पहले i अक्षर केवल शब्दकोश के शब्दों से विभाजित किए जा सकते हैं या नहीं
    // आकार n+1 है क्योंकि dp[n] पूरी स्ट्रिंग की विभाजन संभावना को दर्शाता है
    boolean[] dp = new boolean[n + 1];

    // रिक्त स्ट्रिंग को हमेशा विभाजित किया जा सकता है (आधार शर्त)
    // यह सेटिंग न होने पर स्ट्रिंग की शुरुआत से आरंभ होने वाले शब्दकोश के शब्दों का पता नहीं लगाया जा सकता
    dp[0] = true;

    // बाहरी लूप: i "पहले कितने अक्षरों तक विचार करना है" यह दर्शाता है
    for (int i = 1; i <= n; i++) {
        // आंतरिक लूप: j विभाजन बिंदु का उम्मीदवार है। "पहले j अक्षर" और "j से i तक की उप-स्ट्रिंग" में विभाजित करने की स्थिति
        for (int j = 0; j < i; j++) {
            // यदि पहले j अक्षर विभाजन योग्य हैं और j से i तक शब्दकोश का शब्द है, तो पहले i अक्षर विभाजन योग्य हैं
            // दोनों शर्तें एक साथ पूरी होना = "विभाजन योग्य भाग + शब्दकोश का शब्द" में विभाजित किया जा सकता है
            if (dp[j] && set.contains(s.substring(j, i))) {
                dp[i] = true;
                break;  // विभाजन संभव पाया गया इसलिए अन्य j की जाँच आवश्यक नहीं है
            }
        }
    }

    // dp[n] दर्शाता है कि पूरी स्ट्रिंग s विभाजन योग्य है या नहीं
    return dp[n];
}
```
