# Partitioning an Array Into Two Equal Sum Subsets — सरणी को समान योग वाले दो उपसमुच्चयों में विभाजित किया जा सकता है या नहीं, यह निर्धारित करना

## समस्या का सार

पूर्णांकों की एक सरणी `nums` दी गई है। इस सरणी को दो उपसमुच्चयों में विभाजित करना है जिससे दोनों उपसमुच्चयों के तत्वों का योग समान हो, और यह संभव है या नहीं इसे `boolean` के रूप में लौटाना है। प्रत्येक तत्व अनिवार्य रूप से किसी एक उपसमुच्चय में होना चाहिए, और किसी तत्व को दोहराकर उपयोग नहीं किया जा सकता।

## मूल विचार

यदि सरणी का कुल योग विषम है तो तुरंत false लौटाया जा सकता है। यदि योग सम है तो यह समस्या "क्या योग के आधे `target` को ठीक-ठीक बनाने वाला कोई उपसमुच्चय मौजूद है" इस "उपसमुच्चय योग समस्या" में परिवर्तित हो जाती है। एक-आयामी boolean प्रकार की DP सरणी का उपयोग करके, प्रत्येक तत्व को क्रमशः संसाधित करते हुए पहुँच योग्य योग मानों को दर्ज करते जाएँ, तो O(n × target) में `target` तक पहुँचा जा सकता है या नहीं यह निर्धारित किया जा सकता है।

## विचार प्रक्रिया

1. **दो बराबर भागों की शर्त पर विचार करना**: जब सरणी का कुल योग `sum` हो, तो दोनों उपसमुच्चयों का योग समान होने के लिए प्रत्येक उपसमुच्चय का योग `sum / 2` होना चाहिए। यदि `sum` विषम है तो पूर्णांक में दो बराबर भागों में विभाजित नहीं किया जा सकता, इसलिए तुरंत false लौटाया जा सकता है
2. **समस्या को "उपसमुच्चय योग समस्या" में बदलना**: यदि एक उपसमुच्चय का योग `target = sum / 2` हो जाता है, तो दूसरा उपसमुच्चय स्वतः ही `target` हो जाता है। अर्थात यह "क्या सरणी के तत्वों से योग `target` बनने वाला कोई उपसमुच्चय मौजूद है" इस उपसमुच्चय योग समस्या में परिवर्तित हो जाती है
3. **DP से पहुँच योग्य योग मानों का प्रबंधन करना**: boolean प्रकार की सरणी `dp` तैयार करें, जहाँ `dp[j]` यह दर्शाता है कि "अब तक संसाधित तत्वों से योग `j` बनाया जा सकता है या नहीं"। प्रारंभिक अवस्था के रूप में `dp[0] = true` (कुछ भी न चुनने पर योग 0 होता है) सेट करें
4. **प्रत्येक तत्व से पहुँच योग्य योग मानों को अद्यतन करना**: सरणी के प्रत्येक तत्व `num` के लिए, पहले से पहुँच योग्य योग `j` में `num` जोड़कर `j + num` भी पहुँच योग्य हो जाता है। यह ऐसा संचालन है जिसमें यदि `dp[j]` true है तो `dp[j + num]` को भी true कर दिया जाता है
5. **उल्टे क्रम में पुनरावृत्ति करके दोहराव रोकना**: भीतरी लूप को `target` से `num` तक उल्टे क्रम में चलाएँ। यदि सीधे क्रम में चलाएँ तो उसी तत्व को कई बार उपयोग करने का परिणाम `dp` को अद्यतन कर देगा। उल्टे क्रम में चलाने पर प्रत्येक तत्व अधिकतम एक बार ही उपयोग होता है
6. **अंत में `dp[target]` लौटाना**: सभी तत्वों को संसाधित करने के बाद, यदि `dp[target]` true है तो योग `target` वाला उपसमुच्चय मौजूद है इसलिए true लौटाएँ, और यदि false है तो ऐसा कोई उपसमुच्चय मौजूद नहीं है

## पूर्वापेक्षित ज्ञान

### उपसमुच्चय योग समस्या (Subset Sum Problem) क्या है

दिए गए पूर्णांकों के समुच्चय में से कुछ तत्वों को चुनकर उनका योग ठीक-ठीक लक्ष्य मान बनता है या नहीं, यह निर्धारित करने वाली समस्या है। यह DP (गतिशील प्रोग्रामिंग) से कुशलतापूर्वक हल की जा सकने वाली एक प्रतिनिधि समस्या है।

### boolean प्रकार की एक-आयामी DP सरणी क्या है

`dp[j]` यह दर्शाती है कि "योग `j` बनाना संभव है या नहीं" जिसे true/false से व्यक्त किया जाता है। प्रत्येक तत्व को एक-एक करके संसाधित करने पर, पहुँच योग्य योग मानों का समुच्चय बढ़ता जाता है।

```java
boolean[] dp = new boolean[target + 1];  // आकार target+1 की सरणी बनाएँ (प्रारंभिक मान सभी false)
dp[0] = true;                            // कुछ भी न चुनने पर, योग 0 सदैव पहुँच योग्य है
dp[j - num] == true                      // यदि योग j-num बनाया जा सकता है, तो num जोड़कर योग j भी बनाया जा सकता है
```

### DP सरणी को उल्टे क्रम में अद्यतन करने का कारण

सीधे क्रम (छोटे `j` से बड़े `j`) में अद्यतन करने पर, उसी तत्व `num` को कई बार उपयोग करने का परिणाम प्रसारित हो जाता है। उल्टे क्रम (बड़े `j` से छोटे `j`) में अद्यतन करने पर, प्रत्येक तत्व केवल एक बार उपयोग होने की गारंटी होती है।

```java
// उल्टा क्रम लूप: j = target से num तक 1 कम करते हुए
for (int j = target; j >= num; j--) {
    if (dp[j - num]) dp[j] = true;
}
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n × target) — n तत्वों में से प्रत्येक के लिए, अधिकतम target तक की DP सरणी को पुनरावृत्त किया जाता है |
| Space | O(target) — आकार target+1 की boolean प्रकार की एक DP सरणी का उपयोग किया जाता है |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums
// आउटपुट: सरणी को समान योग वाले दो उपसमुच्चयों में विभाजित किया जा सकता है या नहीं, boolean के रूप में लौटाएँ
boolean canPartition(int[] nums) {
    // सरणी के सभी तत्वों का कुल योग गणना करें, और दो बराबर भागों में विभाजन संभव है या नहीं इसके लिए आधार मान प्राप्त करें
    int sum = 0;
    for (int n : nums) sum += n;

    // यदि योग विषम है तो पूर्णांक में दो बराबर भागों में विभाजित नहीं किया जा सकता इसलिए false लौटाएँ
    if (sum % 2 != 0) return false;

    // एक उपसमुच्चय को प्राप्त करने योग्य लक्ष्य योग मान। दूसरा उपसमुच्चय भी स्वतः target हो जाता है
    int target = sum / 2;

    // dp[j] = अब तक संसाधित तत्वों से योग j बनाया जा सकता है या नहीं (उपसमुच्चय योग समस्या की DP सरणी)
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;  // कुछ भी न चुनने पर योग 0 सदैव पहुँच योग्य है

    // सरणी के प्रत्येक तत्व को आरंभ से अंत तक एक-एक करके संसाधित करें, और पहुँच योग्य योग मानों के समुच्चय को अद्यतन करें
    for (int num : nums) {
        // उल्टे क्रम में पुनरावृत्ति करके उसी तत्व के दोहराव उपयोग को रोकें (सीधे क्रम में num को कई बार जोड़ने का परिणाम प्रसारित हो जाता है)
        for (int j = target; j >= num; j--) {
            // यदि योग j-num बनाया जा सकता है, तो num जोड़कर योग j भी बनाया जा सकता है इसलिए true में अद्यतन करें
            if (dp[j - num]) dp[j] = true;
        }
    }

    // यदि dp[target] true है तो योग target वाला उपसमुच्चय मौजूद है इसलिए दो बराबर भागों में विभाजन संभव है
    return dp[target];
}
```
