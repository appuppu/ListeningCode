# Maximizing Robbery Loot Without Adjacent Houses — आसपास के घरों को छोड़कर लूटी जा सकने वाली अधिकतम राशि ज्ञात करना

## समस्या का सार

एक पूर्णांक सरणी `nums` दी गई है, जिसमें प्रत्येक तत्व सड़क के किनारे प्रत्येक घर में रखी राशि को दर्शाता है। आसपास के दो घरों को एक साथ नहीं लूटा जा सकता, इस प्रतिबंध के अंतर्गत एक रात में लूटी जा सकने वाली **अधिकतम राशि** लौटानी है। यदि घर `i` को लूटा जाता है, तो घर `i-1` और घर `i+1` को नहीं लूटा जा सकता।

## मूल विचार

प्रत्येक घर के लिए "लूटना या नहीं लूटना" के दो विकल्प हैं। लूटने की स्थिति में दो पहले तक की अधिकतम राशि में वर्तमान राशि जोड़ी जाती है, और नहीं लूटने की स्थिति में एक पहले की अधिकतम राशि को वैसे ही आगे बढ़ाया जाता है। इस निर्णय के लिए केवल पिछले दो मान आवश्यक हैं, इसलिए सरणी रखे बिना केवल दो चरों से गणना की जा सकती है।

## विचार प्रक्रिया

1. **प्रत्येक घर पर "लूटना/नहीं लूटना" का इष्टतम निर्णय आवश्यक है**: यदि घर `i` को लूटा जाता है तो घर `i-1` को नहीं लूटा जा सकता, इसलिए घर `i-2` तक की अधिकतम राशि में `nums[i]` जोड़कर प्राप्त मान मिलता है। यदि नहीं लूटा जाता है तो घर `i-1` तक की अधिकतम राशि वैसी ही रहती है। अर्थात प्रत्येक घर पर अधिकतम राशि `max(घर i-1 तक की अधिकतम राशि, घर i-2 तक की अधिकतम राशि + nums[i])` से व्यक्त की जा सकती है
2. **पुनरावृत्ति संबंध बनता है**: `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` इस पुनरावृत्ति संबंध से, आरंभ से क्रम में प्रत्येक घर तक की अधिकतम राशि की गणना की जा सकती है। यह गतिशील प्रोग्रामिंग की एक विशिष्ट संरचना है
3. **केवल पिछले दो मान आवश्यक हैं**: पुनरावृत्ति संबंध को देखने पर, `dp[i]` की गणना में केवल `dp[i-1]` और `dp[i-2]` दो मानों का उपयोग होता है। पूरी सरणी रखने की आवश्यकता नहीं है, केवल दो चर (`prev1` और `prev2`) पर्याप्त हैं
4. **चरों के अद्यतन क्रम पर विचार करना**: `curr` की गणना के बाद, अगले पुनरावृत्ति में वर्तमान `prev1` नया `prev2` बनता है, और `curr` नया `prev1` बनता है। इस क्रम में अद्यतन करने पर मान अधिलेखित नहीं होते
5. **प्रारंभिक मान की स्थापना**: पुनरावलोकन शुरू होने से पहले `prev1 = 0` (एक पहले की अधिकतम राशि) और `prev2 = 0` (दो पहले की अधिकतम राशि) रखा जाता है। यदि 0 घर हैं तो 0 प्राप्त होता है, पहले घर पर `max(0, 0 + nums[0]) = nums[0]` प्राप्त होता है जो सही ढंग से कार्य करता है
6. **अंत में क्या लौटाना है**: सभी घरों का पुनरावलोकन समाप्त होने के बाद `prev1` ही संपूर्ण अधिकतम राशि है

## पूर्वापेक्षित ज्ञान

### गतिशील प्रोग्रामिंग (Dynamic Programming) क्या है

बड़ी समस्या को छोटी उपसमस्याओं में विभाजित करके, प्रत्येक उपसमस्या के हल का पुन: उपयोग करते हुए संपूर्ण हल का निर्माण करने की विधि है। जब अतिव्यापी उपसमस्याएँ होती हैं, तो एक ही गणना को बार-बार करने से बचा जा सकता है। इस समस्या में "घर `i` तक की अधिकतम राशि" उपसमस्या है।

### Math.max क्या है

दो मानों में से बड़ा मान लौटाने वाली Java की मानक विधि है। सशर्त शाखा को एक पंक्ति में लिखा जा सकता है।

```java
Math.max(5, 3);    // → 5（बड़ा मान लौटाता है）
Math.max(prev1, prev2 + num);  // prev1 और prev2+num में से बड़ा मान लौटाता है
```

### विस्तारित for लूप (for-each) क्या है

सरणी के सभी तत्वों को आरंभ से क्रम में एक-एक करके निकालकर संसाधित करने वाला लूप प्रारूप है। अनुक्रमणिका का उपयोग किए बिना तत्वों को सीधे प्राप्त किया जाता है।

```java
int[] nums = {2, 7, 9, 3};
for (int num : nums) {   // nums के प्रत्येक तत्व को क्रम से num में निर्दिष्ट करके लूप चलाता है
    System.out.println(num);  // 2, 7, 9, 3 क्रम से प्रदर्शित होते हैं
}
```

## संगणनात्मक जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार पुनरावलोकित करना पर्याप्त है |
| Space | O(1) — केवल दो चरों का उपयोग होता है, और यह इनपुट के आकार पर निर्भर नहीं करता |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums（प्रत्येक घर की राशि）
// आउटपुट: आसपास के घरों को नहीं लूटने के प्रतिबंध के अंतर्गत लूटी जा सकने वाली अधिकतम राशि int के रूप में लौटाता है
public int rob(int[] nums) {
    // prev2: दो पहले के घर तक की अधिकतम राशि। पुनरावलोकन शुरू होने से पहले कोई घर नहीं है इसलिए 0
    int prev2 = 0;
    // prev1: एक पहले के घर तक की अधिकतम राशि। इसी प्रकार पुनरावलोकन शुरू होने से पहले 0
    int prev1 = 0;

    // विस्तारित for लूप से सरणी nums को आरंभ से अंत तक एक-एक तत्व पुनरावलोकित करता है
    for (int num : nums) {
        // "वर्तमान घर को नहीं लूटने की स्थिति(prev1)" और "वर्तमान घर को लूटने की स्थिति(prev2+num)" में से बड़ा मान चुनता है
        // वर्तमान घर को लूटने की स्थिति में prev2 का उपयोग इसलिए होता है क्योंकि आसपास का prev1 वाला घर नहीं लूटा जा सकता
        int curr = Math.max(prev1,
            prev2 + num);
        // अगले पुनरावृत्ति के लिए चरों को स्लाइड करता है
        // वर्तमान prev1（एक पहले की अधिकतम राशि）अगले पुनरावृत्ति में दो पहले की अधिकतम राशि बनती है
        prev2 = prev1;
        // अभी गणना किया गया curr（वर्तमान घर तक की अधिकतम राशि）अगले पुनरावृत्ति में एक पहले की अधिकतम राशि बनता है
        // ध्यान दें: यह अद्यतन prev2 = prev1 के बाद किया जाता है। यदि पहले prev1 को अद्यतन किया जाए तो prev2 में सही मान निर्दिष्ट नहीं हो पाएगा
        prev1 = curr;
    }
    // सभी घरों पर विचार करने के बाद की अधिकतम राशि लौटाता है। prev1 में अंतिम घर तक विचार की गई अधिकतम राशि संग्रहीत है
    return prev1;
}
```
