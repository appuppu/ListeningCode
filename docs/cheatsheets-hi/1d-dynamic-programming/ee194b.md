# Maximizing Robbery Loot in a Circular Neighborhood — वृत्ताकार पड़ोस में आसन्न घरों को छोड़कर अधिकतम राशि चुराना

## समस्या का सार

गैर-ऋणात्मक पूर्णांकों की एक सरणी `nums` दी गई है। प्रत्येक तत्व वृत्ताकार रूप से व्यवस्थित घरों में रखी राशि को दर्शाता है। दो आसन्न घरों से लगातार चोरी नहीं की जा सकती। **पहला घर और अंतिम घर भी आसन्न हैं** — इस प्रतिबंध के अंतर्गत चुराई जा सकने वाली अधिकतम राशि लौटानी है।

## मूल विचार

वृत्ताकार प्रतिबंध का अर्थ है "पहले घर और अंतिम घर को एक साथ नहीं चुन सकते"। इसलिए "पहले घर को शामिल करें और अंतिम को बाहर रखें" तथा "अंतिम घर को शामिल करें और पहले को बाहर रखें" — इन दो परिसरों में रैखिक संस्करण House Robber को हल करें और बड़े मान को चुनें, तो वृत्ताकार प्रतिबंध संतुष्ट हो जाता है।

## विचार प्रक्रिया

1. **वृत्ताकार प्रतिबंध को विभाजित करना**: वृत्ताकार सरणी में `nums[0]` और `nums[n-1]` आसन्न हैं। अर्थात दोनों को एक साथ नहीं चुन सकते। इसे "यदि `nums[0]` चुनें तो `nums[n-1]` नहीं चुन सकते" और "यदि `nums[n-1]` चुनें तो `nums[0]` नहीं चुन सकते" — इन दो स्थितियों में विभाजित किया जा सकता है
2. **दो रैखिक समस्याओं में परिवर्तित करना**: स्थिति 1 में `nums[0..n-2]` (पहले को शामिल करें, अंतिम को बाहर रखें), स्थिति 2 में `nums[1..n-1]` (पहले को बाहर रखें, अंतिम को शामिल करें) — प्रत्येक परिसर में रैखिक संस्करण House Robber हल करना है। दोनों परिणामों में बड़ा मान उत्तर होगा
3. **रैखिक संस्करण की पुनरावृत्ति संबंध बनाना**: प्रत्येक घर `i` के लिए, "घर `i` से चोरी करें" या "न करें" — दो विकल्प हैं। चोरी करने पर `nums[i] + dp[i-2]` (एक पहले वाले को छोड़ दें), न करने पर `dp[i-1]` (एक पहले तक की अधिकतम राशि यथावत रखें)। अतः `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` बनता है
4. **स्थान को स्थिरांक तक घटाना**: पुनरावृत्ति संबंध केवल `dp[i-1]` और `dp[i-2]` को संदर्भित करता है। पूरी DP सरणी रखने की आवश्यकता नहीं है — केवल दो चर `prev1` (एक पहले की अधिकतम राशि) और `prev2` (दो पहले की अधिकतम राशि) से गणना की जा सकती है
5. **सीमांत स्थितियों को संभालना**: यदि सरणी खाली है तो 0 लौटाएँ। यदि केवल एक तत्व है तो वृत्ताकार प्रतिबंध लागू नहीं होता, इसलिए वह मान लौटाएँ। दो या अधिक तत्व होने पर ही दो-पास प्रक्रिया करें
6. **अंतिम उत्तर**: दोनों परिसरों से प्राप्त अधिकतम राशियों में से बड़ी राशि को `Math.max` से चुनकर लौटाएँ

## पूर्वापेक्षित ज्ञान

### House Robber (रैखिक संस्करण) क्या है

एक पंक्ति में व्यवस्थित घरों से, आसन्न घरों को लगातार न चुनते हुए अधिकतम राशि प्राप्त करने की समस्या है। यह DP की मूलभूत समस्या है और पुनरावृत्ति संबंध `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` से हल होती है। यह वृत्ताकार संस्करण रैखिक संस्करण को दो बार लागू करके हल किया जाता है।

### रोलिंग चर द्वारा DP स्थान अनुकूलन

DP सरणी में से, पुनरावृत्ति संबंध जिन निकटतम कुछ मानों को संदर्भित करता है, केवल उन्हें चर के रूप में रखने की विधि है। पूरी सरणी रखने की आवश्यकता समाप्त हो जाती है और स्थान जटिलता O(n) से O(1) तक घट जाती है।

```java
int prev2 = 0, prev1 = 0;        // dp[i-2] और dp[i-1] के समकक्ष चर आरंभ करें
int curr = Math.max(prev1, prev2 + nums[i]);  // dp[i] की गणना करें
prev2 = prev1;                    // prev2 को एक आगे बढ़ाएँ (पुराना prev1 नया prev2 बनता है)
prev1 = curr;                     // prev1 को एक आगे बढ़ाएँ (curr नया prev1 बनता है)
```

### Math.max क्या है

दो मानों में से बड़ा मान लौटाने वाली Java की मानक विधि है। DP संक्रमण में "चोरी करने की स्थिति" और "न करने की स्थिति" में से अधिकतम चुनने के लिए इसका उपयोग होता है।

```java
Math.max(5, 3);   // → 5 (बड़ा मान लौटाता है)
Math.max(prev1, prev2 + nums[i]);  // न चुराने और चुराने की स्थिति में अधिकतम चुनें
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को दो बार स्कैन करते हैं, परंतु प्रत्येक स्कैन O(n) है इसलिए कुल O(n) है |
| Space | O(1) — DP सरणी का उपयोग नहीं करते, केवल दो रोलिंग चर से गणना करते हैं |

## कोड

```java
// इनपुट: गैर-ऋणात्मक पूर्णांकों की सरणी nums (वृत्ताकार रूप से व्यवस्थित प्रत्येक घर की राशि)
// आउटपुट: आसन्न घरों से लगातार चोरी न करते हुए प्राप्त अधिकतम राशि int के रूप में लौटाएँ

// निर्दिष्ट परिसर (start से end) पर रैखिक संस्करण House Robber हल करने वाली सहायक विधि
private int robRange(int[] nums, int start, int end) {
    // 0 से आरंभ करते हैं क्योंकि किसी भी घर से चोरी न करने पर राशि 0 होती है
    int prev2 = 0, prev1 = 0;  // दो पहले और एक पहले की अधिकतम राशि रखने वाले रोलिंग चर
    // निर्दिष्ट परिसर के आरंभ से अंत तक एक-एक करके स्कैन करें
    for (int i = start; i <= end; i++) {
        // prev1: घर i से चोरी न करें, एक पहले तक की अधिकतम राशि यथावत रखने का विकल्प
        // prev2 + nums[i]: घर i से चोरी करें, दो पहले तक की अधिकतम राशि में वर्तमान राशि जोड़ने का विकल्प
        int curr = Math.max(prev1,
            prev2 + nums[i]);
        // रोलिंग चर को एक आगे बढ़ाएँ (अगले पुनरावृत्ति में curr prev1 की और prev1 prev2 की भूमिका निभाएगा)
        prev2 = prev1;
        prev1 = curr;
    }
    // prev1 में निर्दिष्ट परिसर को ध्यान में रखते हुए अधिकतम राशि संग्रहित है
    return prev1;
}

public int rob(int[] nums) {
    int n = nums.length;
    if (n == 0) return 0;        // कोई घर नहीं है तो 0 लौटाएँ
    if (n == 1) return nums[0];  // केवल एक घर है तो आसन्नता का प्रतिबंध लागू नहीं होता, वह मान ही उत्तर है

    // वृत्ताकार प्रतिबंध को दो रैखिक समस्याओं में विभाजित करें और बड़ा मान लौटाएँ
    // पहले और अंतिम घर को एक साथ न चुनने की गारंटी होती है, इसलिए वृत्ताकार प्रतिबंध संतुष्ट होता है
    return Math.max(
        robRange(nums, 0, n - 2),   // पहले घर को शामिल करें और अंतिम को बाहर रखें (इंडेक्स 0 से n-2)
        robRange(nums, 1, n - 1));  // पहले घर को बाहर रखें और अंतिम को शामिल करें (इंडेक्स 1 से n-1)
}
```
