# Finding the Longest Increasing Subsequence — सबसे लंबी सख्त बढ़ती उपअनुक्रम की लंबाई ज्ञात करना

## समस्या का सार

पूर्णांकों की एक सरणी `nums` दी गई है। मूल सरणी से तत्वों को हटाकर (क्रम बदले बिना) बनाई जा सकने वाली **सख्त रूप से बढ़ती उपअनुक्रम** में से सबसे लंबी उपअनुक्रम की लंबाई लौटानी है। उपअनुक्रम का सतत होना आवश्यक नहीं है, लेकिन मूल सरणी में तत्वों का सापेक्ष क्रम बनाए रखना अनिवार्य है।

## मूल विचार

"लंबाई `k` की बढ़ती उपअनुक्रम का अंतिम तत्व जितना छोटा हो, उतनी अधिक संभावना है कि बाद के तत्वों से उसे आगे बढ़ाया जा सके"। प्रत्येक लंबाई के लिए अंतिम तत्व के न्यूनतम मान को `tails` सरणी में प्रबंधित करने पर, नए तत्व की सम्मिलन स्थिति को बाइनरी सर्च द्वारा O(log n) में निर्धारित किया जा सकता है, और संपूर्ण समस्या को O(n log n) में हल किया जा सकता है।

## विचार प्रक्रिया

1. **बढ़ती उपअनुक्रम को आगे बढ़ाने के लिए अंतिम तत्व छोटा होना लाभदायक है**: जब समान लंबाई की कई बढ़ती उपअनुक्रमें हों, तो जिसका अंतिम तत्व सबसे छोटा है, उसमें "आगे जोड़े जा सकने वाले मानों की सीमा" सबसे विस्तृत होती है। इसलिए, प्रत्येक लंबाई के लिए केवल अंतिम तत्व का न्यूनतम मान दर्ज करना पर्याप्त है
2. **tails सरणी द्वारा अंतिम तत्व के न्यूनतम मान का प्रबंधन करना**: `tails[i]` में "लंबाई `i+1` की बढ़ती उपअनुक्रम का संभावित न्यूनतम अंतिम तत्व" संग्रहीत करने के लिए `tails` सरणी तैयार करनी है। यह सरणी सदैव क्रमबद्ध अवस्था में बनी रहती है (क्योंकि लंबी उपअनुक्रम का अंतिम तत्व बड़ा होता है)
3. **नए तत्व का प्रसंस्करण दो प्रकार से होता है**: सरणी के प्रत्येक तत्व `num` के लिए, `tails` में `num` के बराबर या उससे बड़े सबसे छोटे तत्व को बाइनरी सर्च से ढूँढना है। यदि मिली स्थिति `tails` के अंत से आगे है, तो `num` मौजूदा सबसे लंबी उपअनुक्रम से बड़ा है, इसलिए `tails` के अंत में जोड़ना है। यदि अंत से आगे नहीं है, तो उस स्थिति के मान को `num` से बदलकर न्यूनतम अंतिम मान को अद्यतन करना है
4. **बाइनरी सर्च का उपयोग संभव होने का कारण**: `tails` सरणी सदैव क्रमबद्ध रहती है, इसलिए `num` की सम्मिलन स्थिति को `Collections.binarySearch` द्वारा O(log n) में पहचाना जा सकता है। इससे प्रत्येक तत्व का प्रसंस्करण O(log n) में होता है, और संपूर्ण प्रक्रिया O(n log n) में पूर्ण होती है
5. **tails सरणी की लंबाई ही उत्तर है**: प्रत्येक तत्व के प्रसंस्करण में `tails` में या तो जोड़ना या प्रतिस्थापन होता है। जोड़ना इस बात को दर्शाता है कि सबसे लंबी उपअनुक्रम की लंबाई 1 बढ़ गई है। सभी तत्वों का प्रसंस्करण पूर्ण होने पर `tails.size()` का मान ही सबसे लंबी बढ़ती उपअनुक्रम की लंबाई है

## पूर्वापेक्षित ज्ञान

### ArrayList क्या है

यह एक परिवर्तनीय लंबाई वाली सरणी है। तत्वों को जोड़ना, प्राप्त करना और अद्यतन करना O(1) में किया जा सकता है। सामान्य सरणी के विपरीत, इसमें आकार पहले से निर्धारित करने की आवश्यकता नहीं होती।

```java
List<Integer> list = new ArrayList<>();  // खाली ArrayList बनाना
list.add(10);          // अंत में 10 जोड़ना → [10]
list.add(20);          // अंत में 20 जोड़ना → [10, 20]
list.get(0);           // इंडेक्स 0 का तत्व प्राप्त करना → 10
list.set(0, 5);        // इंडेक्स 0 के तत्व को 5 से बदलना → [5, 20]
list.size();           // तत्वों की संख्या लौटाना → 2
```

### Collections.binarySearch क्या है

यह क्रमबद्ध सूची पर बाइनरी सर्च करके निर्दिष्ट मान की स्थिति लौटाने वाली विधि है। यदि मान मिल जाता है तो उसका इंडेक्स लौटाती है। यदि नहीं मिलता तो `-(सम्मिलन स्थिति) - 1` के रूप में ऋणात्मक मान लौटाती है। सम्मिलन स्थिति वह स्थान है जहाँ उस मान को सूची में डालने पर क्रमबद्ध क्रम बना रहे।

```java
List<Integer> list = Arrays.asList(2, 5, 8, 12);
Collections.binarySearch(list, 5);   // 5 इंडेक्स 1 पर है → 1 लौटाता है
Collections.binarySearch(list, 6);   // 6 मौजूद नहीं है। सम्मिलन स्थिति 2 है → -(2)-1 = -3 लौटाता है
Collections.binarySearch(list, 1);   // 1 मौजूद नहीं है। सम्मिलन स्थिति 0 है → -(0)-1 = -1 लौटाता है
Collections.binarySearch(list, 15);  // 15 मौजूद नहीं है। सम्मिलन स्थिति 4 है → -(4)-1 = -5 लौटाता है
```

ऋणात्मक लौटाए गए मान से सम्मिलन स्थिति पुनः प्राप्त करने के लिए `-(लौटाया गया मान + 1)` की गणना करनी होती है। उदाहरण: यदि लौटाया गया मान -3 है, तो `-(-3 + 1) = 2` सम्मिलन स्थिति है।

### tails सरणी की अवधारणा

`tails` एक ऐसी सरणी है जो "प्रत्येक लंबाई की बढ़ती उपअनुक्रम के अंतिम तत्व का न्यूनतम मान" दर्ज करती है। `tails[i]` का अर्थ है "लंबाई `i+1` की बढ़ती उपअनुक्रम का संभावित न्यूनतम अंतिम मान"। यह सरणी सदैव आरोही क्रम में क्रमबद्ध अवस्था बनाए रखती है।

उदाहरण: nums = [3, 1, 4, 1, 5] को प्रसंस्कृत करने की प्रक्रिया:
- 3 का प्रसंस्करण → tails = [3] (लंबाई 1 की उपअनुक्रम का न्यूनतम अंतिम मान 3 है)
- 1 का प्रसंस्करण → tails = [1] (लंबाई 1 के न्यूनतम अंतिम मान को 1 में अद्यतन किया। 3 से 1 छोटा होने के कारण अधिक लाभदायक है)
- 4 का प्रसंस्करण → tails = [1, 4] (4, 1 से बड़ा है इसलिए अंत में जोड़ा गया। लंबाई 2 की उपअनुक्रम बन गई)
- 1 का प्रसंस्करण → tails = [1, 4] (1 की सम्मिलन स्थिति इंडेक्स 0 है और वहाँ पहले से 1 है, इसलिए कोई परिवर्तन नहीं हुआ)
- 5 का प्रसंस्करण → tails = [1, 4, 5] (5, 4 से बड़ा है इसलिए अंत में जोड़ा गया। लंबाई 3 की उपअनुक्रम बन गई)

अंतिम `tails.size()` = 3 ही उत्तर है।

## जटिलता

| | मान |
|---|---|
| Time | O(n log n) — n तत्वों में से प्रत्येक पर O(log n) की बाइनरी सर्च की जाती है |
| Space | O(n) — tails सरणी में अधिकतम n तत्व संग्रहीत किए जाते हैं |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums
// आउटपुट: सबसे लंबी सख्त बढ़ती उपअनुक्रम की लंबाई int के रूप में लौटाना
public int lengthOfLIS(int[] nums) {
    // प्रत्येक लंबाई की बढ़ती उपअनुक्रम के अंतिम तत्व का न्यूनतम मान आरोही क्रम में रखने वाली सरणी
    // tails[i] का अर्थ है "लंबाई i+1 की बढ़ती उपअनुक्रम का संभावित न्यूनतम अंतिम तत्व"
    List<Integer> tails = new ArrayList<>();

    // सरणी nums के प्रत्येक तत्व को आरंभ से अंत तक एक-एक करके जाँचना
    for (int num : nums) {
        // tails सरणी में num की उचित स्थिति बाइनरी सर्च से ज्ञात करना
        // tails सदैव क्रमबद्ध रहती है इसलिए बाइनरी सर्च का उपयोग किया जा सकता है
        int pos = Collections.binarySearch(tails, num);

        // ऋणात्मक मान का अर्थ "नहीं मिला" है, इसलिए सम्मिलन स्थिति में परिवर्तित करना
        // यदि pos 0 या उससे अधिक है तो num के समान मान tails[pos] में पहले से मौजूद है, इसलिए उसे वैसे ही उपयोग करना
        if (pos < 0)
            pos = -(pos + 1);

        if (pos == tails.size()) {
            // num, tails के सभी तत्वों से बड़ा है इसलिए अंत में जोड़ना
            // इसका अर्थ है कि सबसे लंबी बढ़ती उपअनुक्रम की लंबाई 1 बढ़ गई है
            tails.add(num);
        } else {
            // संबंधित स्थिति के न्यूनतम अंतिम मान को num से बदलकर अद्यतन करना
            // इससे लंबाई pos+1 की बढ़ती उपअनुक्रम का न्यूनतम अंतिम मान और छोटा हो जाता है,
            // जिससे भविष्य में उपअनुक्रम को आगे बढ़ाने की संभावना बढ़ जाती है
            tails.set(pos, num);
        }
    }

    // tails के तत्वों की संख्या प्रसंस्करण के दौरान अंत में जोड़ने की बार की संख्या के बराबर है,
    // और यही सबसे लंबी बढ़ती उपअनुक्रम की लंबाई है
    return tails.size();
}
```
