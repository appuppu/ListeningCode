# Finding the Fewest Coins to Make a Target Amount — न्यूनतम सिक्कों से लक्ष्य राशि बनाना

## समस्या का सार

सिक्कों के मूल्य वाली एक array `coins` और लक्ष्य राशि `amount` दी गई है। `coins` में से किसी भी सिक्के को कितनी भी बार उपयोग करके कुल योग `amount` बनाने वाले संयोजनों में से **न्यूनतम सिक्कों की संख्या** लौटानी है। यदि किसी भी संयोजन से `amount` नहीं बनाया जा सकता तो `-1` लौटाना है।

## मूल विचार

राशि 0 से लक्ष्य राशि तक "प्रत्येक राशि बनाने के लिए आवश्यक न्यूनतम सिक्कों की संख्या" को बॉटम-अप ढंग से गणना करने पर, राशि `i` की न्यूनतम संख्या "`i` में से प्रत्येक सिक्के का मूल्य घटाने पर प्राप्त राशि की न्यूनतम संख्या + 1" में से न्यूनतम मान के रूप में प्राप्त होती है।

## विचार प्रक्रिया

1. **उप-समस्याओं में विभाजित किया जा सकता है**: यदि राशि `i` बनाने का अंतिम सिक्का `c` है, तो शेष राशि `i - c` बनाने की न्यूनतम संख्या ज्ञात हो तो `dp[i - c] + 1` से राशि `i` की न्यूनतम संख्या प्राप्त होती है। यह संरचना dynamic programming के लिए उपयुक्त है
2. **कौन सा सिक्का अंतिम होगा यह पहले से ज्ञात नहीं है**: अंतिम सिक्के के उम्मीदवार सभी सिक्के के मूल्य हैं। इसलिए, सभी सिक्कों `c` के लिए `dp[i - c] + 1` की गणना करके उनमें से न्यूनतम मान को `dp[i]` बनाते हैं। यही संक्रमण सूत्र `dp[i] = min(dp[i - c] + 1)` for each coin `c` है
3. **आधार स्थिति निर्धारित करना**: राशि 0 बनाने के लिए आवश्यक सिक्कों की संख्या 0 है, इसलिए `dp[0] = 0` रखते हैं। यह बॉटम-अप गणना का प्रारंभ बिंदु है
4. **प्रारंभिक मान में "अप्राप्य" दर्शाने वाला मान सेट करना**: प्रत्येक राशि बनाई जा सकती है या नहीं यह पहले से ज्ञात नहीं है, इसलिए `dp` array के सभी तत्वों को `amount + 1` (असंभव रूप से बड़ी संख्या) से आरंभ करते हैं। जिस राशि का यह मान अद्यतन नहीं हुआ उसका अर्थ है "बनाई नहीं जा सकती"
5. **राशि 1 से क्रमशः भरना**: `dp[0]` को प्रारंभ बिंदु मानकर, राशि 1, 2, ..., `amount` के क्रम में तालिका भरते हैं। राशि `i` की गणना के समय, `i` से छोटी सभी राशियों की न्यूनतम संख्या पहले से निश्चित हो चुकी होती है, इसलिए `dp[i - c]` को सुरक्षित रूप से संदर्भित किया जा सकता है
6. **अंतिम रूप से क्या लौटाना है**: यदि `dp[amount]` अभी भी `amount + 1` है तो लक्ष्य राशि नहीं बनाई जा सकती इसलिए `-1` लौटाते हैं। अन्यथा `dp[amount]` ही न्यूनतम सिक्कों की संख्या है

## पूर्वापेक्षित ज्ञान

### Dynamic Programming (गतिशील प्रोग्रामिंग) क्या है

बड़ी समस्या को छोटी उप-समस्याओं में विभाजित करके, प्रत्येक उप-समस्या के हल को तालिका में दर्ज करते हुए बॉटम-अप ढंग से हल निर्मित करने की विधि। एक ही उप-समस्या को दोबारा हल करने से बचने के कारण, गणना कुशलता अच्छी होती है।

```java
// बॉटम-अप DP का मूल पैटर्न
int[] dp = new int[n + 1];     // तालिका बनाना
dp[0] = baseCase;              // आधार स्थिति सेट करना
for (int i = 1; i <= n; i++) { // छोटी उप-समस्या से क्रमशः हल करना
    dp[i] = /* dp[i-1] आदि पिछले परिणामों का उपयोग करके गणना करना */;
}
return dp[n];                  // अंतिम उत्तर लौटाना
```

### Arrays.fill क्या है

Array के सभी तत्वों को निर्दिष्ट मान से भरने वाला Java का मानक method। DP array को आरंभ करने में अक्सर उपयोग किया जाता है।

```java
int[] dp = new int[5];       // [0, 0, 0, 0, 0] बनाया जाता है
Arrays.fill(dp, 100);        // सभी तत्वों को 100 से भरना → [100, 100, 100, 100, 100]
```

### Math.min क्या है

दो पूर्णांकों में से छोटा लौटाने वाला Java का मानक method। अनेक उम्मीदवारों में से न्यूनतम मान चुनने के लिए उपयोग करते हैं।

```java
Math.min(3, 7);    // → 3
Math.min(dp[i], dp[i - coin] + 1);  // वर्तमान मान और नए उम्मीदवार में से छोटा चुनना
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(amount × n) — प्रत्येक राशि के लिए n प्रकार के सिक्कों को स्कैन करना (n coins array की लंबाई है) |
| Space | O(amount) — dp array में amount+1 तत्व संग्रहीत करना |

## कोड

```java
// इनपुट: सिक्कों के मूल्य वाली पूर्णांक array coins और लक्ष्य राशि पूर्णांक amount
// आउटपुट: कुल योग amount बनाने वाले सिक्कों की न्यूनतम संख्या int में लौटाना। नहीं बना सकते तो -1 लौटाना
int coinChange(int[] coins, int amount) {
    // dp[i] = राशि i बनाने के लिए आवश्यक न्यूनतम सिक्कों की संख्या
    // इंडेक्स 0 से amount तक प्रत्येक राशि के लिए, आकार amount + 1 होता है
    int[] dp = new int[amount + 1];

    // सभी तत्वों को "अप्राप्य" दर्शाने वाले प्रहरी मान से आरंभ करना
    // सिक्के का न्यूनतम मूल्य 1 है इसलिए amount से अधिक सिक्के कभी नहीं लगेंगे, यह मान शेष रहे तो "नहीं बना सकते" निर्धारित होता है
    Arrays.fill(dp, amount + 1);

    // आधार स्थिति: राशि 0 बनाने के लिए आवश्यक सिक्कों की संख्या 0 है। बॉटम-अप गणना का प्रारंभ बिंदु
    dp[0] = 0;

    // राशि 1 से amount तक क्रमशः तालिका भरना
    // छोटी राशि से क्रमशः गणना करके, dp[i - coin] पहले से निश्चित होने की गारंटी देना
    for (int i = 1; i <= amount; i++) {
        // प्रत्येक सिक्के को "राशि i बनाने का अंतिम सिक्का" उम्मीदवार मानकर, सभी मूल्यों में से इष्टतम खोजना
        for (int coin : coins) {
            // coin > i होने पर उस सिक्के से राशि i नहीं बना सकते इसलिए छोड़ना
            if (coin <= i)
                // dp[i - coin] + 1 का अर्थ है "राशि i - coin की न्यूनतम संख्या में एक सिक्का जोड़ने पर प्राप्त संख्या"
                // वर्तमान dp[i] से तुलना करके छोटा मान अपनाना
                dp[i] = Math.min(dp[i],
                    dp[i - coin] + 1);
        }
    }

    // प्रहरी मान अभी भी है तो प्रारंभिक मान से अद्यतन नहीं हुआ = लक्ष्य राशि नहीं बना सकते इसलिए -1 लौटाना
    return dp[amount] > amount
        ? -1 : dp[amount];
}
```
