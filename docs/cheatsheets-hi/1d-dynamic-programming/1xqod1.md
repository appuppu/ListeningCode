# Counting All Palindromic Substrings — स्ट्रिंग में सभी पैलिंड्रोमिक सबस्ट्रिंग्स की कुल संख्या गिनना

## समस्या का सार

एक स्ट्रिंग `s` दी गई है। `s` की सभी सबस्ट्रिंग्स में से, जो पैलिंड्रोम (आगे से पढ़ने और पीछे से पढ़ने पर समान स्ट्रिंग) हैं, उनकी **कुल संख्या** लौटानी है। एक अक्षर वाली सबस्ट्रिंग्स को भी पैलिंड्रोम के रूप में गिना जाता है।

## मूल विचार

हर पैलिंड्रोम का एक "केंद्र" होता है। केंद्र को स्थिर करके बाएँ और दाएँ विस्तार करने पर, उस केंद्र से उत्पन्न होने वाले सभी पैलिंड्रोम सूचीबद्ध किए जा सकते हैं। केंद्र के उम्मीदवार प्रत्येक अक्षर (विषम लंबाई) और आसन्न दो अक्षरों के बीच (सम लंबाई) मिलाकर कुल 2n-1 ही होते हैं, इसलिए संपूर्ण खोज संभव है।

## विचार प्रक्रिया

1. **पैलिंड्रोम के संरचनात्मक गुणों पर ध्यान देना**: हर पैलिंड्रोम अपने केंद्र के सापेक्ष बाएँ-दाएँ सममित होता है। विषम लंबाई वाले पैलिंड्रोम का केंद्र एक अक्षर होता है, और सम लंबाई वाले पैलिंड्रोम का केंद्र दो आसन्न अक्षर होते हैं। इस गुण का उपयोग करके केंद्र को प्रारंभ बिंदु मानकर पैलिंड्रोम को कुशलतापूर्वक खोजा जा सकता है
2. **केंद्र से बाहर की ओर विस्तार करना**: किसी केंद्र के लिए, बाएँ और दाएँ पॉइंटर `left` और `right` सेट किए जाते हैं, और जब तक `s.charAt(left) == s.charAt(right)` रहता है तब तक बाहर की ओर विस्तार किया जाता है। हर सफल विस्तार पर एक नया पैलिंड्रोम मिलता है, इसलिए गिनती 1 बढ़ाई जाती है
3. **विषम लंबाई और सम लंबाई को अलग-अलग संसाधित करना**: प्रत्येक इंडेक्स `i` के लिए, `expand(s, i, i)` से विषम लंबाई के पैलिंड्रोम और `expand(s, i, i+1)` से सम लंबाई के पैलिंड्रोम गिने जाते हैं। इन दो कॉल से `i` को केंद्र मानने वाले सभी पैलिंड्रोम कवर हो जाते हैं
4. **विस्तार की रोक शर्त निर्धारित करना**: जब `left` 0 से कम हो जाए, या `right` स्ट्रिंग की लंबाई के बराबर या अधिक हो जाए, या बाएँ और दाएँ के अक्षर मेल न खाएँ, तब विस्तार रोका जाता है। इससे सीमा से बाहर पहुँच को रोकते हुए अधिकतम विस्तार किया जाता है
5. **प्रत्येक केंद्र के परिणामों को जोड़ना**: सभी इंडेक्स के लिए विषम लंबाई और सम लंबाई के पैलिंड्रोम की संख्या का योग, संपूर्ण स्ट्रिंग में पैलिंड्रोमिक सबस्ट्रिंग्स की कुल संख्या होती है
6. **अंतिम रूप में क्या लौटाना है**: सभी केंद्रों से प्राप्त पैलिंड्रोम संख्या का योग एक पूर्णांक `result` के रूप में लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### पैलिंड्रोम (Palindrome) क्या है

आगे से पढ़ने और पीछे से पढ़ने पर समान रहने वाली स्ट्रिंग को पैलिंड्रोम कहते हैं। `"aba"`, `"abba"`, `"a"` सभी पैलिंड्रोम हैं। पैलिंड्रोम दो प्रकार के होते हैं: विषम लंबाई (केंद्र एक अक्षर) और सम लंबाई (केंद्र दो अक्षरों के बीच)।

```
विषम लंबाई का उदाहरण: "aba"  → केंद्र 'b' है
सम लंबाई का उदाहरण: "abba" → केंद्र 'b' और 'b' के बीच है
```

### केंद्र विस्तार विधि (Expand Around Center) क्या है

पैलिंड्रोम के केंद्र को स्थिर करके, बाएँ और दाएँ एक-एक अक्षर बढ़ाते हुए पैलिंड्रोम होने या न होने की जाँच करने वाली विधि है। केंद्र से बाहर की ओर जब तक अक्षर मेल खाते हैं तब तक विस्तार जारी रहता है, और मेल न खाने पर रुक जाता है।

```
स्ट्रिंग: "abacd"
केंद्र i=1 ('b') से विस्तार:
  left=1, right=1 → 'b'=='b' → पैलिंड्रोम "b" मिला, count=1
  left=0, right=2 → 'a'=='a' → पैलिंड्रोम "aba" मिला, count=2
  left=-1 → सीमा से बाहर इसलिए रुकना
```

### String.charAt(int index) क्या है

यह मेथड स्ट्रिंग में निर्दिष्ट इंडेक्स पर स्थित अक्षर लौटाता है। इंडेक्स 0 से शुरू होता है।

```java
String s = "abc";
s.charAt(0);    // 'a' लौटाता है
s.charAt(2);    // 'c' लौटाता है
s.length();     // स्ट्रिंग की लंबाई लौटाता है → 3
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n²) — प्रत्येक केंद्र (n व्यक्तिगत) के लिए अधिकतम O(n) विस्तार किया जाता है |
| Space | O(1) — केवल पॉइंटर और काउंटर का उपयोग होता है, कोई अतिरिक्त डेटा संरचना उपयोग नहीं होती |

## कोड

```java
// इनपुट: स्ट्रिंग s
// आउटपुट: s की पैलिंड्रोमिक सबस्ट्रिंग्स की कुल संख्या पूर्णांक में लौटाना

// निर्दिष्ट केंद्र से बाएँ और दाएँ विस्तार करके, मिले पैलिंड्रोम की संख्या लौटाना
// left और right समान मान हों तो विषम लंबाई, आसन्न मान हों तो सम लंबाई के पैलिंड्रोम खोजे जाते हैं
int expand(String s, int left, int right) {
    int count = 0;
    // तीनों शर्तें पूरी होने तक विस्तार: बायाँ सिरा सीमा में, दायाँ सिरा सीमा में, बाएँ-दाएँ अक्षर मेल
    while (left >= 0 && right < s.length()
            && s.charAt(left) == s.charAt(right)) {
        count++;   // s.substring(left, right+1) एक नया पैलिंड्रोम है इसलिए गिनती बढ़ाना
        left--;    // बाएँ 1 स्थान विस्तार करना
        right++;   // दाएँ 1 स्थान विस्तार करना
    }
    // इस केंद्र से मिले पैलिंड्रोम की कुल संख्या लौटाना
    return count;
}

int countSubstrings(String s) {
    // सभी केंद्रों से मिले पैलिंड्रोम की संख्या संचित करने वाला चर
    int result = 0;

    // प्रत्येक इंडेक्स को केंद्र उम्मीदवार के रूप में जाँचना
    for (int i = 0; i < s.length(); i++) {
        // विषम लंबाई का पैलिंड्रोम: left=i, right=i से एक अक्षर के केंद्र से विस्तार शुरू
        result += expand(s, i, i);
        // सम लंबाई का पैलिंड्रोम: left=i, right=i+1 से आसन्न दो अक्षरों के केंद्र से विस्तार शुरू
        result += expand(s, i, i + 1);
    }
    // सभी केंद्रों से प्राप्त पैलिंड्रोम संख्या का योग लौटाना
    return result;
}
```
