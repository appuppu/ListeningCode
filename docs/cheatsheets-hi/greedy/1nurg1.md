# Finding the Subarray With Maximum Sum — अधिकतम योग वाला सन्निहित उपसरणी खोजना

## समस्या का सार

पूर्णांकों की एक सरणी `nums` दी गई है। सरणी में धनात्मक और ऋणात्मक दोनों प्रकार की संख्याएँ हो सकती हैं। सन्निहित उपसरणी (subarray) में से, जिसके तत्वों का योग अधिकतम हो उसे खोजना है और उस **योग का मान** लौटाना है।

## मूल विचार

प्रत्येक तत्व पर पहुँचने पर केवल दो विकल्प होते हैं: "अब तक की उपसरणी को आगे बढ़ाना" या "इस तत्व से नई उपसरणी शुरू करना"। यदि अब तक का संचयी योग ऋणात्मक है, तो उसे ढोते रहने की बजाय छोड़कर नई शुरुआत करना हमेशा लाभदायक होता है।

## विचार प्रक्रिया

1. **प्रत्येक तत्व पर केवल दो विकल्प होते हैं**: जब हम तत्व `nums[i]` पर पहुँचते हैं, तो संभावित क्रियाएँ केवल दो हैं — "पिछली उपसरणी में `nums[i]` जोड़कर उसे आगे बढ़ाना" या "`nums[i]` को प्रारंभ बिंदु बनाकर नई उपसरणी शुरू करना"। सन्निहित उपसरणी की शर्त के कारण, बीच के तत्वों को छोड़ना संभव नहीं है
2. **आगे बढ़ाना या नई शुरुआत करना — निर्णय का आधार**: यदि पिछला संचयी योग `currentSum` धनात्मक है, तो `nums[i]` में जोड़ने पर मान `nums[i]` अकेले से बड़ा होगा, इसलिए आगे बढ़ाना उचित है। यदि `currentSum` ऋणात्मक है, तो जोड़ने पर मान `nums[i]` अकेले से छोटा हो जाएगा, इसलिए छोड़कर नई शुरुआत करनी चाहिए। अर्थात `currentSum + nums[i]` और `nums[i]` में से बड़े को चुनना पर्याप्त है
3. **इस निर्णय को `Math.max` से व्यक्त करना**: `currentSum = Math.max(currentSum + nums[i], nums[i])` — इस एक पंक्ति से आगे बढ़ाने और नई शुरुआत करने का निर्णय पूरा हो जाता है। `currentSum + nums[i]` आगे बढ़ाने को दर्शाता है, और `nums[i]` नई शुरुआत को दर्शाता है
4. **समग्र अधिकतम मान को अलग से ट्रैक करना**: `currentSum` "वर्तमान उपसरणी का योग" है, और यह स्कैनिंग के दौरान घटता-बढ़ता रहता है। समस्या "संपूर्ण सरणी में अधिकतम योग" माँगती है, इसलिए एक अलग चर `maxSum` में स्कैनिंग के दौरान आए `currentSum` के अधिकतम मान को लगातार दर्ज करना आवश्यक है
5. **`maxSum` का प्रारंभिक मान `Integer.MIN_VALUE` रखना**: सरणी के सभी तत्व ऋणात्मक होने पर भी सही परिणाम मिले, इसके लिए `maxSum` का प्रारंभिक मान पूर्णांक का न्यूनतम मान रखना चाहिए। यदि 0 से आरंभ करें, तो सभी तत्व ऋणात्मक होने पर "रिक्त उपसरणी (योग 0)" को अधिकतम मानने की गलती हो जाएगी
6. **अंत में `maxSum` लौटाना**: सरणी की स्कैनिंग समाप्त होने पर, `maxSum` में सभी सन्निहित उपसरणियों का अधिकतम योग दर्ज हो चुका होता है। इस मान को लौटाना है

## पूर्वापेक्षित ज्ञान

### Math.max क्या है

यह Java का एक मानक मेथड है जो दो मान लेता है और बड़ा मान लौटाता है। यह सशर्त शाखाओं को एक पंक्ति में व्यक्त कर सकता है।

```java
Math.max(5, 3);       // दो मानों में से बड़ा मान लौटाता है → 5
Math.max(-2, -7);     // ऋणात्मक संख्याओं में भी बड़ा मान लौटाता है → -2
Math.max(a + b, b);   // व्यंजकों के परिणामों की भी तुलना कर सकता है
```

### Integer.MIN_VALUE क्या है

यह Java में `int` प्रकार का न्यूनतम मान (-2,147,483,648) दर्शाने वाला स्थिरांक है। इसे "अभी तक कोई तुलना नहीं हुई" अवस्था के प्रारंभिक मान के रूप में उपयोग किया जाता है। किसी भी पूर्णांक से तुलना करने पर `Math.max` हमेशा दूसरे पक्ष को चुनता है।

```java
int maxSum = Integer.MIN_VALUE;   // int प्रकार के न्यूनतम मान से आरंभ करना
maxSum = Math.max(maxSum, -5);    // कोई भी मान maxSum से बड़ा होता है → -5
```

### सन्निहित उपसरणी (subarray) क्या है

सरणी में, निकटवर्ती तत्वों को बिना रुकावट के क्रमशः निकाला गया भाग सन्निहित उपसरणी कहलाता है। तत्वों को छोड़कर चुनना संभव नहीं है।
उदाहरण: `nums = [-2, 1, -3, 4, -1, 2]` के लिए, `[4, -1, 2]` एक सन्निहित उपसरणी है (योग 5)। `[1, 4, 2]` सन्निहित उपसरणी नहीं है क्योंकि तत्व निकटवर्ती नहीं हैं।

## संगणना जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(1) — उपयोग किए जाने वाले चर केवल `maxSum` और `currentSum` दो हैं |

## कोड

```java
// इनपुट: धनात्मक और ऋणात्मक संख्याएँ सम्मिलित हो सकने वाली पूर्णांक सरणी nums
// आउटपुट: सन्निहित उपसरणी के योग का अधिकतम मान int के रूप में लौटाना
public int maxSubArray(int[] nums) {
    // संपूर्ण स्कैनिंग के दौरान आई उपसरणी के योग का अधिकतम मान दर्ज करने वाला चर
    // सभी तत्व ऋणात्मक होने पर भी सही अधिकतम मान चुन सके, इसलिए Integer.MIN_VALUE से आरंभ करना
    // सावधानी: 0 से आरंभ करने पर, सभी तत्व ऋणात्मक होने पर "रिक्त उपसरणी (योग 0)" को अधिकतम मान लिया जाएगा
    int maxSum = Integer.MIN_VALUE;
    // वर्तमान में निर्माणाधीन उपसरणी का योग रखने वाला चर। स्कैनिंग के आरंभ में कोई तत्व शामिल नहीं है इसलिए 0
    int currentSum = 0;

    // सरणी को आरंभ से अंत तक एक-एक करके स्कैन करना
    for (int num : nums) {
        // currentSum + num "पिछली उपसरणी को आगे बढ़ाने पर प्राप्त योग" है
        // num "इस तत्व से नई उपसरणी शुरू करने पर प्राप्त योग" है
        // बड़े मान को चुनने से हमेशा इष्टतम निर्णय होता है
        currentSum = Math.max(currentSum + num, num);
        // वर्तमान उपसरणी का योग अब तक के अधिकतम मान से बड़ा हो तो अद्यतन करना, नहीं तो यथावत रखना
        maxSum = Math.max(maxSum, currentSum);
    }
    // स्कैनिंग समाप्त होने पर, maxSum में सभी सन्निहित उपसरणियों का अधिकतम योग दर्ज हो चुका है
    return maxSum;
}
```
