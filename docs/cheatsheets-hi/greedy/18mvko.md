# Finding the Starting Gas Station for a Circular Route — वृत्ताकार मार्ग पर एक चक्कर पूरा करने वाला प्रारंभिक गैस स्टेशन खोजना

## समस्या का सार

लंबाई `n` की पूर्णांक सरणी `gas` और `cost` दी गई है। `gas[i]` स्टेशन `i` पर प्राप्त होने वाला ईंधन है, और `cost[i]` स्टेशन `i` से अगले स्टेशन तक जाने के लिए आवश्यक ईंधन है। वृत्ताकार मार्ग पर एक चक्कर पूरा करने वाले प्रारंभिक स्टेशन का इंडेक्स लौटाना है। यदि एक चक्कर पूरा करने वाला कोई स्टेशन मौजूद नहीं है, तो `-1` लौटाना है। समाधान अधिकतम एक ही होता है।

## मूल विचार

यदि सभी स्टेशनों के ईंधन शेष का कुल योग अऋणात्मक है, तो समाधान अवश्य मौजूद होता है। जिस बिंदु पर वर्तमान ईंधन शेष ऋणात्मक हो जाता है, उस बिंदु तक के स्टेशन प्रारंभिक बिंदु नहीं बन सकते, इसलिए अगले स्टेशन को नया प्रारंभिक उम्मीदवार मानकर रीसेट करने से एक ही स्कैन में उत्तर मिल जाता है।

## विचार प्रक्रिया

1. **प्रत्येक स्टेशन के ईंधन शेष पर विचार करना**: स्टेशन `i` पर `gas[i]` ईंधन प्राप्त होता है और `cost[i]` ईंधन खर्च होता है, इसलिए शुद्ध ईंधन परिवर्तन `net = gas[i] - cost[i]` से व्यक्त होता है। यदि `net` धनात्मक है तो उस स्टेशन पर ईंधन अधिशेष उत्पन्न होता है, और यदि ऋणात्मक है तो ईंधन की कमी होती है
2. **एक चक्कर पूरा करने की शर्त निर्धारित करना**: सभी स्टेशनों के `net` का कुल योग (`totalBalance`) यदि अऋणात्मक है, तो पूरे मार्ग पर प्राप्त ईंधन खर्च होने वाले ईंधन से अधिक या बराबर है, इसलिए किसी न किसी प्रारंभिक बिंदु से अवश्य एक चक्कर पूरा किया जा सकता है। इसके विपरीत, यदि `totalBalance` ऋणात्मक है, तो कहीं से भी प्रारंभ करने पर ईंधन अपर्याप्त रहता है, इसलिए समाधान मौजूद नहीं है
3. **प्रारंभिक उम्मीदवार को कुशलतापूर्वक सीमित करना**: स्टेशन `start` से प्रारंभ करके स्कैन करते समय, किसी बिंदु `i` पर संचित ईंधन शेष (`currentBalance`) ऋणात्मक हो जाता है। इस स्थिति में, `start` से `i` तक के किसी भी स्टेशन से प्रारंभ करने पर `i` को पार करना संभव नहीं है। इसका कारण यह है कि `start` से बीच के किसी स्टेशन `j` तक का संचित मान अऋणात्मक था, इसलिए `j` से प्रारंभ करने पर और भी कम ईंधन के साथ `i` पर पहुँचा जाएगा। अतः `start` से `i` तक के सभी स्टेशनों को एक साथ बाहर करके `i + 1` को नया प्रारंभिक उम्मीदवार बनाना है
4. **currentBalance को रीसेट करके स्कैन जारी रखना**: नए प्रारंभिक उम्मीदवार `i + 1` से पुनः ईंधन शेष को ट्रैक करने के लिए `currentBalance` को `0` पर रीसेट करना है और `start` को `i + 1` पर अपडेट करना है। स्कैन स्वयं शुरू से अंत तक केवल एक बार करना पर्याप्त है
5. **स्कैन समाप्ति के बाद totalBalance से अंतिम निर्णय लेना**: स्कैन समाप्त होने पर, यदि `totalBalance >= 0` है तो समाधान मौजूद है इसलिए `start` लौटाना है। यदि `totalBalance < 0` है तो एक चक्कर पूरा करना असंभव है इसलिए `-1` लौटाना है

## पूर्वापेक्षित ज्ञान

### net (शुद्ध ईंधन परिवर्तन) क्या है

प्रत्येक स्टेशन पर ईंधन का शेष। `net = gas[i] - cost[i]` से गणना की जाती है। धनात्मक होने पर ईंधन अधिशेष होता है, और ऋणात्मक होने पर ईंधन की कमी होती है।

```java
int net = gas[i] - cost[i];  // स्टेशन i पर ईंधन शेष की गणना करना
// उदाहरण: gas[i]=3, cost[i]=5 के समय net=-2 (ईंधन 2 कम है)
// उदाहरण: gas[i]=4, cost[i]=1 के समय net=3 (ईंधन 3 अधिशेष है)
```

### totalBalance और currentBalance की भूमिका

`totalBalance` पूरे मार्ग के ईंधन शेष का कुल योग है, जिसका उपयोग एक चक्कर पूरा करना संभव है या नहीं यह निर्धारित करने में होता है। `currentBalance` वर्तमान प्रारंभिक उम्मीदवार से स्कैन किए जा रहे स्टेशन तक का संचित ईंधन शेष है, जिसका उपयोग प्रारंभिक उम्मीदवार को अपडेट करने के निर्णय में होता है।

```java
int totalBalance = 0;    // पूरे मार्ग के ईंधन शेष का कुल योग (एक चक्कर संभव है या नहीं इसके निर्णय हेतु)
int currentBalance = 0;  // वर्तमान प्रारंभिक उम्मीदवार से संचित ईंधन शेष (उम्मीदवार अपडेट के निर्णय हेतु)
totalBalance += net;     // सभी स्टेशनों के लिए हमेशा जोड़ते रहना है
currentBalance += net;   // प्रारंभिक उम्मीदवार रीसेट करते समय 0 पर वापस लाना है
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार स्कैन करने से उत्तर मिल जाता है |
| Space | O(1) — केवल 3 चर का उपयोग होता है, जो इनपुट आकार पर निर्भर नहीं करते |

## कोड

```java
// इनपुट: पूर्णांक सरणी gas (प्रत्येक स्टेशन पर प्राप्त ईंधन) और पूर्णांक सरणी cost (प्रत्येक स्टेशन से अगले तक जाने के लिए आवश्यक ईंधन)
// आउटपुट: वृत्ताकार मार्ग पर एक चक्कर पूरा करने वाले प्रारंभिक स्टेशन का इंडेक्स int में लौटाना है। एक चक्कर पूरा न कर सकने की स्थिति में -1 लौटाना है
public int canCompleteCircuit(int[] gas, int[] cost) {
    // पूरे मार्ग के ईंधन शेष का कुल योग (एक चक्कर संभव है या नहीं इसके अंतिम निर्णय में उपयोग होता है)
    int totalBalance = 0;
    // वर्तमान प्रारंभिक उम्मीदवार से संचित ईंधन शेष (उम्मीदवार रीसेट के निर्णय में उपयोग होता है)
    int currentBalance = 0;
    // प्रारंभिक उम्मीदवार का इंडेक्स (0 से शुरू होता है, प्रत्येक रीसेट पर अपडेट होता है)
    int start = 0;

    // सरणी को इंडेक्स 0 से अंत तक एक-एक करके स्कैन करना
    for (int i = 0; i < gas.length; i++) {
        // स्टेशन i पर शुद्ध ईंधन परिवर्तन की गणना करना
        int net = gas[i] - cost[i];
        // पूरे मार्ग के ईंधन शेष में हमेशा जोड़ना (अंत में एक चक्कर संभव है या नहीं इसके निर्णय में उपयोग होता है)
        totalBalance += net;
        // वर्तमान प्रारंभिक उम्मीदवार से संचित ईंधन शेष में जोड़ना (स्टेशन i पर पहुँचने के समय ईंधन शेष के बराबर है)
        currentBalance += net;

        // संचित ईंधन शेष ऋणात्मक होने पर, start से i तक का कोई भी स्टेशन प्रारंभिक बिंदु नहीं बन सकता
        if (currentBalance < 0) {
            // संचित ईंधन शेष को रीसेट करके अगले स्टेशन को नया प्रारंभिक उम्मीदवार बनाना
            currentBalance = 0;
            start = i + 1;
        }
    }
    // पूरे मार्ग का ईंधन शेष अऋणात्मक होने पर एक चक्कर संभव है इसलिए start लौटाना है, ऋणात्मक होने पर असंभव है इसलिए -1 लौटाना है
    return totalBalance >= 0 ? start : -1;
}
```
