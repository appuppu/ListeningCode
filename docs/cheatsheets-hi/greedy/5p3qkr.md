# Partitioning a String Into Maximum Parts — प्रत्येक अक्षर केवल एक ही भाग में शामिल हो, इस प्रकार स्ट्रिंग को अधिकतम भागों में विभाजित करना

## समस्या का सार

छोटे अंग्रेज़ी अक्षरों से बनी एक स्ट्रिंग `s` दी गई है। प्रत्येक अक्षर अधिकतम एक ही भाग में शामिल हो, इस शर्त के साथ स्ट्रिंग को अधिकतम संभव भागों में विभाजित करें। प्रत्येक भाग की **लंबाई** को एक सूची में लौटाएँ।

## मूल विचार

यदि कोई अक्षर वर्तमान भाग में शामिल है, तो उस अक्षर की अंतिम उपस्थिति स्थान तक भाग को विस्तारित करना आवश्यक है। प्रत्येक अक्षर की अंतिम उपस्थिति स्थान को पहले से गणना कर लें, तो एक ही बार स्कैन करके लालची (greedy) तरीके से भाग की सीमा निर्धारित की जा सकती है।

## विचार प्रक्रिया

1. **विभाजन की शर्त को समझें**: एक ही अक्षर दो भागों में नहीं आ सकता। अर्थात्, किसी अक्षर को शामिल करने वाले भाग में उस अक्षर की अंतिम उपस्थिति स्थान तक कम से कम शामिल होना आवश्यक है
2. **प्रत्येक अक्षर की अंतिम उपस्थिति स्थान पहले से ज्ञात करें**: स्ट्रिंग को एक बार स्कैन करके प्रत्येक अक्षर की अंतिम उपस्थिति का इंडेक्स एक सरणी में दर्ज करें। अंग्रेज़ी छोटे अक्षर केवल 26 प्रकार के होते हैं, इसलिए आकार 26 की सरणी पर्याप्त है
3. **भाग की समाप्ति को लालची तरीके से विस्तारित करें**: स्ट्रिंग को आरंभ से स्कैन करें और वर्तमान भाग में शामिल सभी अक्षरों की अंतिम उपस्थिति स्थान का अधिकतम मान `end` के रूप में ट्रैक करें। प्रत्येक नए अक्षर पर `end` को उस अक्षर की अंतिम उपस्थिति स्थान से तुलना करके अद्यतन करें
4. **भाग निर्धारित होने की शर्त पहचानें**: जब वर्तमान इंडेक्स `i`, `end` तक पहुँच जाता है, तब वर्तमान भाग के सभी अक्षर इस भाग की सीमा के भीतर होने की गारंटी मिलती है। इस समय भाग को निर्धारित करें और अगला भाग शुरू करें
5. **भाग की लंबाई की गणना करें**: प्रत्येक बार भाग निर्धारित होने पर `end - start + 1` से भाग की लंबाई ज्ञात करें और परिणाम सूची में जोड़ें। अगले भाग की आरंभ स्थिति `start` को `i + 1` पर अद्यतन करें

## पूर्वापेक्षित ज्ञान

### अक्षर का इंडेक्स रूपांतरण

Java में `char` प्रकार को पूर्णांक के रूप में उपयोग किया जा सकता है। `s.charAt(i) - 'a'` के द्वारा छोटे अक्षर `'a'` को `0`, `'b'` को `1`, ..., `'z'` को `25` में रूपांतरित किया जा सकता है। इससे आकार 26 की सरणी में सभी छोटे अक्षरों को प्रबंधित किया जा सकता है।

```java
char c = 'c';
int index = c - 'a';    // 2 ('c', 'a' से 2 स्थान आगे है)
int[] arr = new int[26]; // 26 अक्षरों के लिए सरणी
arr[c - 'a'] = 5;       // 'c' के संगत स्थान पर मान 5 संग्रहित करें
```

### Math.max क्या है

दो मानों में से बड़े मान को लौटाने वाली विधि है। भाग की समाप्ति को विस्तारित करते समय, वर्तमान `end` और नए अक्षर की अंतिम उपस्थिति स्थान की तुलना करके अधिक दूर वाले को अपनाने के लिए इसका उपयोग किया जाता है।

```java
Math.max(3, 7);   // 7 लौटाता है
Math.max(10, 2);  // 10 लौटाता है
```

### ArrayList क्या है

परिवर्तनीय लंबाई वाली सूची है। भागों की संख्या पहले से ज्ञात नहीं होती, इसलिए भाग की लंबाई को एक-एक करके जोड़ने के लिए यह उपयुक्त है।

```java
List<Integer> res = new ArrayList<>();  // खाली सूची बनाएँ
res.add(9);    // अंत में 9 जोड़ें → [9]
res.add(7);    // अंत में 7 जोड़ें → [9, 7]
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — स्ट्रिंग को केवल 2 बार स्कैन करना पड़ता है (अंतिम स्थान दर्ज करने में 1 बार, भाग विभाजन में 1 बार) |
| Space | O(1) — केवल आकार 26 की निश्चित सरणी का उपयोग होता है, जो इनपुट आकार पर निर्भर नहीं करती |

## कोड

```java
// इनपुट: छोटे अंग्रेज़ी अक्षरों से बनी स्ट्रिंग s
// आउटपुट: प्रत्येक भाग की लंबाई संग्रहित List<Integer> लौटाएँ
List<Integer> partitionLabels(String s) {
    // आकार 26 की पूर्णांक सरणी, जिसमें प्रत्येक अक्षर ('a'〜'z') की अंतिम उपस्थिति इंडेक्स संग्रहित है
    // अंग्रेज़ी छोटे अक्षर केवल 26 प्रकार के हैं इसलिए आकार 26 निश्चित है
    int[] last = new int[26];

    // पहला स्कैन: प्रत्येक अक्षर की अंतिम उपस्थिति स्थान दर्ज करें
    // यदि एक ही अक्षर कई बार आता है, तो बाद वाले इंडेक्स से अधिलेखित हो जाता है इसलिए अंतिम स्थान शेष रहता है
    for (int i = 0; i < s.length(); i++) {
        last[s.charAt(i) - 'a'] = i;
    }

    // भागों की संख्या पहले से ज्ञात नहीं है इसलिए परिवर्तनीय लंबाई वाली सूची का उपयोग करें
    List<Integer> res = new ArrayList<>();
    // start: वर्तमान भाग की आरंभ स्थिति, end: वर्तमान भाग की समाप्ति स्थिति
    int start = 0, end = 0;

    // दूसरा स्कैन: भागों को लालची तरीके से निर्धारित करें
    for (int i = 0; i < s.length(); i++) {
        // वर्तमान अक्षर की अंतिम उपस्थिति स्थान यदि end से अधिक दूर है, तो भाग की समाप्ति को वहाँ तक विस्तारित करें
        // इससे भाग के सभी अक्षरों की अंतिम उपस्थिति स्थान का अधिकतम मान सदैव end में बना रहता है
        end = Math.max(end,
            last[s.charAt(i) - 'a']);

        // i जब end तक पहुँचता है → भाग के सभी अक्षर इस सीमा में होने की गारंटी मिलती है
        // क्योंकि भाग का कोई भी अक्षर end के बाद उपस्थित नहीं होता
        if (i == end) {
            // end - start + 1 से भाग की लंबाई की गणना करके परिणाम सूची में जोड़ें
            res.add(end - start + 1);
            // अगले भाग की आरंभ स्थिति अद्यतन करें
            start = i + 1;
        }
    }
    // सभी भागों की लंबाई संग्रहित सूची लौटाएँ
    return res;
}
```
