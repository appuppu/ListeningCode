# Finding the Minimum Jumps to Reach the End — सरणी के अंत तक पहुँचने के लिए न्यूनतम जम्प संख्या ज्ञात करना

## समस्या का सार

एक पूर्णांक सरणी `nums` दी गई है, जहाँ प्रत्येक तत्व `nums[i]` उस स्थिति से अधिकतम कितने खाने आगे जम्प किया जा सकता है, यह दर्शाता है। इंडेक्स 0 से शुरू करके, अंतिम इंडेक्स तक पहुँचने के लिए आवश्यक **न्यूनतम जम्प संख्या** लौटानी है। यह गारंटी दी गई है कि अंत तक अवश्य पहुँचा जा सकता है।

## मूल विचार

प्रत्येक जम्प को "एक जम्प से पहुँच सकने वाली सीमा (विंडो)" के रूप में समझें, और विंडो की सीमा तक पहुँचने पर जम्प संख्या 1 बढ़ाएँ। विंडो के भीतर स्कैन करते हुए अगली विंडो की सबसे दूर पहुँच बिंदु को रिकॉर्ड करने से, BFS के लेवल-वार खोज के समान प्रभाव O(1) स्पेस में प्राप्त होता है।

## विचार प्रक्रिया

1. **न्यूनतम संख्या ज्ञात करने की समस्या BFS से हल होती है**: प्रत्येक स्थिति को नोड और जम्प सीमा को एज मानें, तो यह इंडेक्स 0 से अंत तक की सबसे छोटी पथ समस्या बन जाती है। BFS लेवल दर लेवल खोज करता है, इसलिए जो लेवल सबसे पहले अंत तक पहुँचता है, वही न्यूनतम जम्प संख्या होती है
2. **BFS के लेवल को विंडो से व्यक्त करना**: सामान्य BFS कतार (queue) का उपयोग करके O(n) स्पेस लेता है। लेकिन सरणी पर जम्प में, प्रत्येक लेवल पर पहुँच योग्य सीमा एक सतत अंतराल होती है, इसलिए अंतराल का अंतिम बिंदु `currentEnd` ही वर्तमान लेवल को दर्शा सकता है
3. **विंडो के भीतर अगले सबसे दूर पहुँच बिंदु को ट्रैक करना**: वर्तमान विंडो (पिछले `currentEnd` से इस बार के `currentEnd` तक) को स्कैन करते हुए, प्रत्येक स्थिति `i` से पहुँच सकने वाले सबसे दूर बिंदु `i + nums[i]` का अधिकतम मान `farthest` चर में रिकॉर्ड करें। यह अगली विंडो का अंतिम बिंदु बनता है
4. **विंडो की सीमा पर जम्प निश्चित करना**: जब इंडेक्स `i`, `currentEnd` तक पहुँचता है, तो इसका अर्थ है कि वर्तमान विंडो पूरी तरह उपयोग हो चुकी है। इस समय जम्प संख्या 1 बढ़ाएँ, `currentEnd` को `farthest` में अपडेट करें और अगली विंडो में जाएँ
5. **लूप सीमा अंत से एक पहले तक है**: लूप को `i < nums.length - 1` तक चलाने से, अंतिम इंडेक्स पर पहुँचने पर अतिरिक्त जम्प गिनने से बचा जाता है। अंत तक पहुँचने की गारंटी है, इसलिए पहुँच जाँच की आवश्यकता नहीं है
6. **अंत में क्या लौटाना है**: लूप समाप्त होने के बाद, `jumps` चर में संचित न्यूनतम जम्प संख्या लौटाएँ

## पूर्व-ज्ञान

### Greedy BFS (लालची चौड़ाई-पहले खोज) क्या है

BFS (चौड़ाई-पहले खोज) एक एल्गोरिदम है जो ग्राफ के प्रारंभ बिंदु से प्रत्येक नोड तक की सबसे छोटी पथ ज्ञात करता है। सामान्यतः कतार (queue) का उपयोग होता है, लेकिन सरणी पर जम्प समस्या में पहुँच योग्य सीमा सतत अंतराल होती है, इसलिए केवल अंतराल की सीमाओं को प्रबंधित करने वाली लालची विधि से समान परिणाम प्राप्त होता है। प्रत्येक लेवल (एक जम्प के बराबर) पर पहुँच योग्य सबसे दूर बिंदु को लालचपूर्वक चुनने से न्यूनतम जम्प संख्या प्राप्त होती है।

### Math.max क्या है

यह Java का मानक मेथड है जो दो पूर्णांकों में से बड़ा वाला लौटाता है। वर्तमान सबसे दूर पहुँच बिंदु और नए गणना किए गए पहुँच बिंदु की तुलना करके, जो अधिक दूर है उसे रखने के लिए इसका उपयोग होता है।

```java
Math.max(3, 7);       // दो मानों में से बड़ा मान लौटाता है → 7
Math.max(farthest, i + nums[i]);  // वर्तमान सबसे दूर बिंदु और नए पहुँच बिंदु की तुलना करता है
```

### विंडो (जम्प सीमा) क्या है

एक जम्प से पहुँच सकने वाले इंडेक्स का सतत अंतराल। चर `currentEnd` विंडो के दाएँ छोर को दर्शाता है। जब `i`, `currentEnd` तक पहुँचता है, तो इसका अर्थ है कि वर्तमान विंडो पूरी तरह उपयोग हो चुकी है और अगला जम्प आवश्यक है।
उदाहरण: `nums = [2,3,1,1,4]` के लिए, पहली विंडो `[1,2]` है (इंडेक्स 0 से अधिकतम 2 खाने आगे), अगली विंडो `[3,4]` है (विंडो के भीतर सबसे दूर पहुँच बिंदु 4 तक)।

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(1) — केवल 3 चरों का उपयोग होता है, किसी अतिरिक्त डेटा संरचना की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums (प्रत्येक तत्व उस स्थिति से अधिकतम जम्प लंबाई है)
// आउटपुट: अंतिम इंडेक्स तक पहुँचने के लिए न्यूनतम जम्प संख्या int में लौटाता है
public int jump(int[] nums) {
    // जम्प संख्या रिकॉर्ड करने वाला चर। विंडो की सीमा तक पहुँचने पर 1 बढ़ाता है
    int jumps = 0;
    // वर्तमान जम्प विंडो का दायाँ छोर। शुरू में इंडेक्स 0 पर होने के कारण 0 से आरंभ करता है
    int currentEnd = 0;
    // विंडो के भीतर से पहुँच सकने वाला सबसे दूर इंडेक्स। अगली विंडो का दायाँ छोर निर्धारित करने के लिए उपयोग होता है
    int farthest = 0;

    // अंत से एक पहले तक स्कैन करता है। अंत तक पहुँचने पर लक्ष्य प्राप्त हो जाता है, इसलिए वहाँ से आगे जम्प की आवश्यकता नहीं है
    for (int i = 0; i < nums.length - 1; i++) {
        // i + nums[i] वर्तमान स्थिति i से अधिकतम जम्प करने पर पहुँचने वाला इंडेक्स है
        // यदि यह अब तक के farthest से अधिक दूर है तो अपडेट करता है
        farthest = Math.max(farthest, i + nums[i]);

        // वर्तमान विंडो के दाएँ छोर तक पहुँचने पर, अगला जम्प आवश्यक है
        if (i == currentEnd) {
            // जम्प संख्या 1 बढ़ाता है
            jumps++;
            // अगली विंडो का दायाँ छोर farthest पर सेट करता है। अगली विंडो की सीमा currentEnd+1 से नए currentEnd तक है
            currentEnd = farthest;
        }
    }
    // संचित न्यूनतम जम्प संख्या लौटाता है
    return jumps;
}
```
