# Merging Triplets to Form a Target Triplet — ट्रिपलेट के प्रत्येक तत्व का अधिकतम मान लेकर लक्ष्य बनाया जा सकता है या नहीं इसका निर्धारण करना

## समस्या का सार

तीन पूर्णांकों वाले ट्रिपलेट की द्विआयामी सरणी `triplets` और एक लक्ष्य ट्रिपलेट `target` दिया गया है। `triplets` से कोई भी उपसमुच्चय चुनकर, तत्व-वार अधिकतम मान (element-wise maximum) लेने पर प्राप्त परिणाम `target` से पूरी तरह मेल खाता है या नहीं, इसका निर्धारण करें और **boolean** में लौटाएं।

## मूल विचार

लक्ष्य के किसी भी तत्व से अधिक मान रखने वाले ट्रिपलेट को मर्ज में उपयोग करने पर उस स्थान का मान लक्ष्य से अधिक हो जाएगा, इसलिए ऐसे ट्रिपलेट का उपयोग कभी नहीं किया जा सकता। इसके विपरीत, केवल उन ट्रिपलेट को मर्ज करें जिनके सभी तत्व लक्ष्य से कम या बराबर हैं, तो लक्ष्य से अधिक होने की चिंता के बिना अधिकतम मान संचित किए जा सकते हैं, और अंत में केवल यह जांचना होगा कि परिणाम लक्ष्य से मेल खाता है या नहीं।

## विचार प्रक्रिया

1. **अनुपयोगी ट्रिपलेट की पहचान करना**: यदि ट्रिपलेट `t` का कोई भी तत्व `target` के संबंधित तत्व से अधिक है, तो `t` को मर्ज में शामिल करने पर अधिकतम मान लक्ष्य से अधिक हो जाएगा। अधिकतम मान एक बार बढ़ने के बाद घटाया नहीं जा सकता, इसलिए ऐसे ट्रिपलेट को कभी नहीं चुना जा सकता
2. **उपयोग योग्य ट्रिपलेट सभी का उपयोग किया जा सकता है**: जिन ट्रिपलेट के सभी तत्व `target` से कम या बराबर हैं, उन्हें मर्ज करने पर भी लक्ष्य से अधिक नहीं होगा। उनका उपयोग करने से कोई हानि नहीं है, इसलिए लालची दृष्टिकोण से सभी को अपनाया जा सकता है
3. **मर्ज परिणाम कैसे संचित करें**: परिणाम संग्रहित करने के लिए सरणी `result` को `[0, 0, 0]` से आरंभ करें, और उपयोग योग्य ट्रिपलेट के प्रत्येक तत्व तथा `result` के प्रत्येक तत्व का अधिकतम मान लेकर अपडेट करें। `Math.max` से तत्व-वार अपडेट करने पर चुने गए सभी ट्रिपलेट का element-wise maximum प्राप्त होता है
4. **अंतिम निर्धारण**: सभी ट्रिपलेट को संसाधित करने के बाद, यदि `result` `target` से पूरी तरह मेल खाता है तो `true` लौटाएं, अन्यथा `false` लौटाएं। `Arrays.equals` से सरणी के सभी तत्वों की तुलना की जा सकती है

## पूर्वापेक्षित ज्ञान

### element-wise maximum (तत्व-वार अधिकतम मान) क्या है

दो या अधिक सरणियों के समान स्थान के तत्वों की तुलना करके, प्रत्येक स्थान पर अधिकतम मान लेने की क्रिया। उदाहरण के लिए `[2, 5, 3]` और `[5, 1, 6]` का element-wise maximum `[5, 5, 6]` होता है।

```java
int[] a = {2, 5, 3};
int[] b = {5, 1, 6};
int[] merged = new int[3];
merged[0] = Math.max(a[0], b[0]);  // max(2, 5) → 5
merged[1] = Math.max(a[1], b[1]);  // max(5, 1) → 5
merged[2] = Math.max(a[2], b[2]);  // max(3, 6) → 6
// merged = [5, 5, 6]
```

### Math.max क्या है

दो मानों में से बड़ा मान लौटाने वाली विधि। मर्ज परिणाम को संचित करने में इसका उपयोग किया जाता है।

```java
Math.max(3, 7);   // → 7
Math.max(5, 5);   // → 5
Math.max(0, 4);   // → 4（प्रारंभिक मान 0 से तुलना करके अपडेट करने के लिए）
```

### Arrays.equals क्या है

दो सरणियों की लंबाई और सभी तत्वों का मेल खाता है या नहीं इसका निर्धारण करके boolean में लौटाने वाली विधि। `==` ऑपरेटर संदर्भ की तुलना करता है, इसलिए सरणी की सामग्री की तुलना करने के लिए इस विधि का उपयोग करना चाहिए।

```java
int[] a = {2, 5, 3};
int[] b = {2, 5, 3};
a == b;              // → false（संदर्भ भिन्न होने के कारण）
Arrays.equals(a, b); // → true（सभी तत्व मेल खाने के कारण）
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n) — ट्रिपलेट सरणी को केवल एक बार स्कैन करना पर्याप्त है (प्रत्येक ट्रिपलेट का संसाधन O(1) है) |
| Space | O(1) — केवल लंबाई 3 की निश्चित आकार सरणी `result` का उपयोग किया जाता है |

## कोड

```java
// इनपुट: द्विआयामी पूर्णांक सरणी triplets (प्रत्येक तत्व लंबाई 3 का ट्रिपलेट है) और लंबाई 3 की पूर्णांक सरणी target
// आउटपुट: यदि ट्रिपलेट के उपसमुच्चय के element-wise maximum से target बनाया जा सकता है तो true, अन्यथा false
public boolean mergeTriplets(int[][] triplets, int[] target) {
    // उपयोग योग्य ट्रिपलेट के element-wise maximum को संचित करने वाली सरणी को [0, 0, 0] से आरंभ करें
    int[] result = new int[3];

    // triplets के प्रत्येक ट्रिपलेट t को आरंभ से अंत तक एक-एक करके स्कैन करें
    for (int[] t : triplets) {
        // यदि कोई भी तत्व लक्ष्य से अधिक है तो उस ट्रिपलेट को मर्ज में शामिल करने पर अधिकतम मान लक्ष्य से अधिक हो जाएगा और सुधारा नहीं जा सकता, इसलिए स्किप करें
        if (t[0] > target[0] ||
            t[1] > target[1] ||
            t[2] > target[2])
            continue;

        // सभी तत्व लक्ष्य से कम या बराबर हैं, इसलिए इस अपडेट से result लक्ष्य से अधिक नहीं होगा
        // प्रत्येक तत्व के अधिकतम मान से परिणाम को अपडेट करें
        result[0] = Math.max(result[0], t[0]);
        result[1] = Math.max(result[1], t[1]);
        result[2] = Math.max(result[2], t[2]);
    }

    // संचित परिणाम लक्ष्य से पूरी तरह मेल खाता है या नहीं इसका निर्धारण करके लौटाएं
    return Arrays.equals(result, target);
}
```
