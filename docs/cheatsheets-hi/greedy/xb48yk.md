# Dividing Cards Into Consecutive Groups — कार्डों को निर्दिष्ट आकार के लगातार समूहों में विभाजित किया जा सकता है या नहीं, यह निर्धारित करना

## समस्या का सार

पूर्णांक सरणी `hand` (कार्डों के मान) और पूर्णांक `groupSize` दिया गया है। सभी कार्डों को ऐसे समूहों में विभाजित किया जा सकता है या नहीं जहाँ प्रत्येक समूह `groupSize` **लगातार मानों** से बना हो, यह `boolean` के रूप में लौटाना है। सभी कार्डों का बिना किसी अतिरिक्त या कमी के पूर्ण उपयोग होना आवश्यक है।

## मूल विचार

यदि कार्डों को छोटे मान से लालची (greedy) तरीके से संसाधित किया जाए, तो प्रत्येक कार्ड किस समूह में आएगा यह एकमात्र रूप से निर्धारित होता है। सबसे छोटे कार्ड से लगातार समूह बनाकर, उपयोग किए गए कार्डों को हटाते हुए यह प्रक्रिया दोहराई जाती है, और यदि सभी कार्डों का उपयोग हो जाए तो विभाजन संभव है।

## विचार प्रक्रिया

1. **पूर्व शर्त की जाँच करना**: कार्डों को `groupSize` के समूहों में बाँटना है, इसलिए यदि कार्डों की कुल संख्या `groupSize` से विभाज्य नहीं है, तो विभाजन असंभव है। यह जाँच पहले करने से अनावश्यक प्रसंस्करण से बचा जा सकता है
2. **सबसे छोटे कार्ड से संसाधित करने का कारण**: सबसे छोटा कार्ड केवल अपने आप को शीर्ष मानकर बनने वाले लगातार समूह में ही आ सकता है। उदाहरण के लिए, यदि न्यूनतम मान 3 है और `groupSize` 3 है, तो वह कार्ड अवश्य [3, 4, 5] समूह में आएगा। इसलिए न्यूनतम मान से लालची तरीके से संसाधित करने की रणनीति सही है
3. **प्रत्येक कार्ड की उपस्थिति संख्या का प्रबंधन आवश्यक है**: समान मान के कई कार्ड हो सकते हैं, इसलिए प्रत्येक मान की उपस्थिति संख्या (आवृत्ति) दर्ज करने के लिए एक डेटा संरचना आवश्यक है। साथ ही, न्यूनतम मान को कुशलतापूर्वक प्राप्त करने के लिए, कुंजियों के क्रम में TreeMap उपयुक्त है
4. **समूह निर्माण की प्रक्रिया**: TreeMap से न्यूनतम कुंजी `first` प्राप्त करें, और `first` से `first + groupSize - 1` तक की लगातार सभी मान TreeMap में मौजूद हैं या नहीं जाँचें। यदि मौजूद हैं तो प्रत्येक मान की आवृत्ति 1 घटाएँ, और आवृत्ति 0 होने पर उस मान को TreeMap से हटाएँ
5. **लगातार मान अपर्याप्त होने पर**: समूह निर्माण के दौरान यदि आवश्यक मान TreeMap में मौजूद नहीं है, तो उस बिंदु पर विभाजन असंभव घोषित करें और `false` लौटाएँ
6. **सभी कार्डों का संसाधन पूर्ण होने पर सफलता**: TreeMap खाली होने तक समूह निर्माण दोहराएँ, और यदि सभी सफल हों तो `true` लौटाएँ

## पूर्व ज्ञान

### TreeMap क्या है

यह एक Map डेटा संरचना है जिसमें कुंजियाँ हमेशा क्रमबद्ध (sorted) रहती हैं। HashMap की तरह कुंजी-मान जोड़े संग्रहित किए जा सकते हैं, लेकिन कुंजी के क्रम पर आधारित संक्रियाएँ (जैसे न्यूनतम कुंजी प्राप्त करना) O(log n) में संभव हैं। आंतरिक रूप से यह लाल-काले वृक्ष (self-balancing binary search tree) द्वारा कार्यान्वित है।

```java
TreeMap<Integer, Integer> tm = new TreeMap<>();  // खाली TreeMap बनाएँ
tm.put(5, 2);           // कुंजी 5 में मान 2 संग्रहित करें
tm.put(3, 1);           // कुंजी 3 में मान 1 संग्रहित करें
tm.firstKey();           // न्यूनतम कुंजी लौटाता है → 3
tm.containsKey(5);       // कुंजी 5 मौजूद है या नहीं boolean में लौटाता है → true
tm.get(5);               // कुंजी 5 का संबंधित मान लौटाता है → 2
tm.remove(3);            // कुंजी 3 और उसका मान हटाता है
```

### getOrDefault क्या है

Map से मान प्राप्त करते समय, यदि कुंजी मौजूद नहीं है तो निर्दिष्ट डिफ़ॉल्ट मान लौटाने वाला मेथड। आवृत्ति गणना में `null` जाँच को छोड़ा जा सकता है।

```java
TreeMap<Integer, Integer> tm = new TreeMap<>();
tm.getOrDefault(10, 0);  // कुंजी 10 मौजूद नहीं है इसलिए डिफ़ॉल्ट मान 0 लौटाता है → 0
tm.put(10, 3);
tm.getOrDefault(10, 0);  // कुंजी 10 मौजूद है इसलिए उसका मान लौटाता है → 3
```

### लालची विधि (Greedy) क्या है

प्रत्येक चरण में स्थानीय रूप से इष्टतम चुनाव करके, समग्र इष्टतम समाधान प्राप्त करने की विधि। इस समस्या में "सबसे छोटे कार्ड से क्रमशः समूह बनाना" यह लालची चुनाव, समग्र रूप से सही विभाजन की ओर ले जाता है। सबसे छोटा कार्ड किसी अन्य समूह के बीच में नहीं आ सकता, इसलिए लालची चुनाव इष्टतम समाधान से मेल खाता है।

## जटिलता

| | मान |
|---|---|
| Time | O(n log n) — TreeMap में प्रविष्टि और विलोपन प्रत्येक O(log n) है, और कुल n कार्डों को संसाधित किया जाता है |
| Space | O(n) — TreeMap में अधिकतम n प्रविष्टियाँ संग्रहित होती हैं |

## कोड

```java
// इनपुट: पूर्णांक सरणी hand (कार्डों के मान) और पूर्णांक groupSize (प्रत्येक समूह का आकार)
// आउटपुट: यदि सभी कार्डों को लगातार मानों के समूहों में विभाजित कर सकते हैं तो true, अन्यथा false लौटाएँ
public boolean isNStraightHand(int[] hand, int groupSize) {
    // यदि कार्डों की कुल संख्या groupSize से विभाज्य नहीं है तो समान समूह बनाना असंभव है
    if (hand.length % groupSize != 0)
        return false;

    // कुंजी=कार्ड का मान, मान=शेष संख्या (आवृत्ति) संग्रहित करने वाला TreeMap
    // TreeMap उपयोग का कारण: न्यूनतम कार्ड मान O(log n) में प्राप्त किया जा सकता है
    TreeMap<Integer, Integer> tm = new TreeMap<>();
    // प्रत्येक कार्ड की उपस्थिति संख्या गिनें, getOrDefault से मौजूदा आवृत्ति में 1 जोड़ें
    for (int card : hand) {
        tm.put(card, tm.getOrDefault(card, 0) + 1);
    }

    // TreeMap खाली होने तक समूह बनाएँ (खाली होने का अर्थ है सभी कार्डों का विभाजन हो गया)
    while (!tm.isEmpty()) {
        // वर्तमान न्यूनतम कार्ड मान प्राप्त करें और समूह का शीर्ष बनाएँ
        // न्यूनतम मान किसी अन्य समूह के बीच में नहीं आ सकता, इसलिए यह अवश्य नए समूह का शीर्ष बनता है
        int first = tm.firstKey();

        // first से groupSize लगातार मानों का समूह बनाएँ
        for (int i = 0; i < groupSize; i++) {
            int cur = first + i;

            // यदि लगातार मान मौजूद नहीं है तो समूह नहीं बन सकता, अतः विभाजन असंभव है
            if (!tm.containsKey(cur))
                return false;

            // यदि आवृत्ति 1 है तो वह अंतिम कार्ड है इसलिए हटाएँ, 2 या अधिक हो तो आवृत्ति 1 घटाएँ
            if (tm.get(cur) == 1) {
                tm.remove(cur);
            } else {
                tm.put(cur, tm.get(cur) - 1);
            }
        }
    }

    // सभी कार्डों को लगातार समूहों में सफलतापूर्वक विभाजित किया गया
    return true;
}
```
