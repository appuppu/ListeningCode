# Determining if You Can Reach the End of an Array — यह निर्धारित करना कि आप सरणी के अंत तक पहुँच सकते हैं या नहीं

## समस्या का सार

पूर्णांकों की एक सरणी `nums` दी गई है। प्रत्येक तत्व `nums[i]` उस इंडेक्स से आगे की ओर कूदने की **अधिकतम लंबाई** को दर्शाता है। इंडेक्स `0` से शुरू करके, सरणी के **अंतिम इंडेक्स** तक पहुँचा जा सकता है या नहीं, यह `boolean` के रूप में लौटाना है।

## मूल विचार

प्रत्येक स्थिति पर "यहाँ से पहुँच सकने वाले सबसे दूर के बिंदु" को अपडेट करते रहने पर, जिस क्षण वह सबसे दूर का बिंदु वर्तमान स्थिति से पीछे रह जाए, उसे पहुँच-अयोग्य निर्धारित किया जा सकता है। व्यक्तिगत कूद पथों को ट्रैक करने की आवश्यकता नहीं है, केवल "अब तक पहुँच योग्य सबसे दूर का इंडेक्स" — यह एक मान ही पर्याप्त है।

## विचार प्रक्रिया

1. **पहुँच-योग्यता सबसे दूर के बिंदु से निर्धारित होती है**: इंडेक्स `i` तक पहुँचा जा सकता है या नहीं, यह इस बात से निर्धारित किया जा सकता है कि उससे पहले के सभी तत्वों से गणना किया गया "पहुँच योग्य सबसे दूर का इंडेक्स" `i` के बराबर या उससे अधिक है। बीच के पथ का विवरण अनावश्यक है, केवल सबसे दूर का बिंदु महत्वपूर्ण है
2. **सबसे दूर के बिंदु को एक ही चर से प्रबंधित किया जा सकता है**: प्रत्येक इंडेक्स `i` पर `i + nums[i]` वहाँ से सबसे दूर का पहुँच बिंदु है। अब तक के सबसे दूर के बिंदु से तुलना करके बड़े मान को रखने पर, एक ही चर से संपूर्ण पहुँच योग्य सीमा को ट्रैक किया जा सकता है
3. **पहुँच-अयोग्यता की निर्धारण शर्त**: सरणी को बाएँ से दाएँ स्कैन करते समय, यदि वर्तमान इंडेक्स `i` सबसे दूर के बिंदु `maxReach` से अधिक हो जाए, तो इंडेक्स `i` तक पहुँचना संभव ही नहीं है। अर्थात `i > maxReach` पहुँच-अयोग्यता की शर्त है
4. **शीघ्र समाप्ति की शर्त**: जब `maxReach` सरणी के अंतिम इंडेक्स `nums.length - 1` के बराबर या उससे अधिक हो जाए, तो अंत तक पहुँच योग्य होना निश्चित हो जाता है, इसलिए शेष स्कैन को छोड़कर `true` लौटाया जा सकता है
5. **जब स्कैन अंत तक पूरा हो जाए**: यदि बीच में न तो `false` और न ही `true` हुआ और लूप समाप्त हो गया, तो इसका अर्थ है कि सभी इंडेक्स पहुँच योग्य थे, इसलिए `true` लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### Math.max क्या है

यह एक स्थैतिक मेथड है जो दो पूर्णांक लेकर उनमें से बड़ा मान लौटाता है। सबसे दूर के बिंदु को अपडेट करते समय "वर्तमान सबसे दूर का बिंदु" और "नवगणित पहुँच बिंदु" की तुलना करने के लिए इसका उपयोग किया जाता है।

```java
Math.max(3, 5);    // 5 लौटाता है — दोनों आर्गुमेंट में से बड़ा मान
Math.max(7, 2);    // 7 लौटाता है
Math.max(4, 4);    // 4 लौटाता है — बराबर होने पर वही मान लौटाता है
```

### maxReach (सबसे दूर का पहुँच योग्य इंडेक्स) क्या है

सरणी के आरंभ से वर्तमान स्थिति तक के सभी तत्वों को ध्यान में रखते हुए, पहुँच योग्य सबसे दूर के इंडेक्स को दर्शाने वाला चर है। इंडेक्स `i` पर होने पर, `i + nums[i]` उस स्थिति से पहुँच सकने वाला सबसे दूर का बिंदु है, और `maxReach = Math.max(maxReach, i + nums[i])` द्वारा हमेशा अधिकतम मान रखा जाता है।
उदाहरण: `nums = [2, 3, 1, 1, 4]` के लिए, `i=0` पर `maxReach = 0 + 2 = 2`, `i=1` पर `maxReach = max(2, 1 + 3) = 4` होता है, और अंतिम इंडेक्स `4` तक पहुँच योग्य होना निर्धारित किया जा सकता है।

## जटिलता विश्लेषण

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(1) — अतिरिक्त चर केवल `maxReach` एक ही है |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums (प्रत्येक तत्व उस इंडेक्स से अधिकतम कूद लंबाई है)
// आउटपुट: अंतिम इंडेक्स तक पहुँच सकें तो true, नहीं तो false लौटाता है
boolean canJump(int[] nums) {
    // अब तक पहुँच योग्य सबसे दूर के इंडेक्स को ट्रैक करने वाला चर
    // प्रारंभ बिंदु इंडेक्स 0 है, इसलिए प्रारंभिक मान 0 है
    int maxReach = 0;

    // सरणी को आरंभ से अंत तक एक-एक करके स्कैन करता है
    for (int i = 0; i < nums.length; i++) {
        // यदि वर्तमान इंडेक्स सबसे दूर के पहुँच बिंदु से अधिक है, तो यहाँ पहुँचना संभव नहीं है
        if (i > maxReach) return false;

        // i + nums[i] वर्तमान स्थिति से पहुँच सकने वाला सबसे दूर का इंडेक्स है
        // अब तक के maxReach से तुलना करके बड़े मान को रखता है
        maxReach = Math.max(maxReach,
            i + nums[i]);

        // यदि सबसे दूर का पहुँच बिंदु सरणी के अंतिम इंडेक्स के बराबर या अधिक है, तो अंत तक पहुँच योग्य निश्चित है
        if (maxReach >= nums.length - 1)
            return true;
    }
    // यदि लूप अंत तक पूरा हुआ, तो सभी इंडेक्स पहुँच योग्य थे इसलिए true लौटाता है
    return true;
}
```
