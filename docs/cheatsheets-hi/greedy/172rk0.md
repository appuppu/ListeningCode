# Checking Validity of a Parenthesis String With Wildcards — वाइल्डकार्ड सहित कोष्ठक स्ट्रिंग की वैधता जाँचना

## समस्या का सार

`(`、`)`、`*` — केवल इन 3 प्रकार के वर्णों से बनी एक स्ट्रिंग दी गई है। `*` को `(`、`)` या खाली स्ट्रिंग में से किसी भी रूप में माना जा सकता है। यह निर्धारित करना है कि क्या यह स्ट्रिंग **वैध कोष्ठक अनुक्रम** बन सकती है, और परिणाम `boolean` के रूप में लौटाना है।

## मूल विचार

`*` की व्याख्या अनिश्चित होने के कारण, खुले कोष्ठकों की संख्या को एक मान के बजाय "संभावित सीमा (न्यूनतम low ~ अधिकतम high)" के रूप में ट्रैक किया जाता है। यदि यह सीमा स्कैन के दौरान सदैव वैध रहती है और अंत में 0 को सम्मिलित करती है, तो स्ट्रिंग वैध है।

## विचार प्रक्रिया

1. **कोष्ठकों की वैधता खुले कोष्ठकों की गिनती से निर्धारित की जा सकती है**: स्ट्रिंग को बाएँ से स्कैन करें, `(` पर +1 और `)` पर -1 करें। यदि बीच में गिनती ऋणात्मक हो जाए तो अमान्य है, और अंत में 0 हो तो वैध है। यह कोष्ठक जाँच का मूल सिद्धांत है
2. **`*` होने पर गिनती एक मान पर निश्चित नहीं रहती**: `*` की 3 व्याख्याएँ संभव हैं, इसलिए गिनती एकल मान नहीं बल्कि "सीमा" बन जाती है। `*` को `(` मानने पर गिनती +1 होती है, `)` मानने पर -1, और खाली स्ट्रिंग मानने पर ±0। अर्थात प्रत्येक `*` पर सीमा विस्तृत होती है
3. **सीमा को 2 चरों से ट्रैक किया जाता है**: `low` खुले कोष्ठकों की गिनती का न्यूनतम मान दर्शाता है (`*` को यथासंभव `)` या खाली स्ट्रिंग मानने पर), और `high` अधिकतम मान दर्शाता है (`*` को यथासंभव `(` मानने पर)। केवल इन 2 चरों से सभी पैटर्न कवर हो जाते हैं
4. **स्कैन के दौरान यदि `high` ऋणात्मक हो जाए तो तुरंत अमान्य घोषित किया जाता है**: `high` खुले कोष्ठकों की गिनती का अधिकतम मान है, इसलिए इसका ऋणात्मक होना अर्थात `*` की कोई भी व्याख्या चुनने पर भी `)` अधिक हैं, और वैध कोष्ठक अनुक्रम संभव नहीं है
5. **`low` ऋणात्मक होने पर उसे 0 पर क्लैंप किया जाता है**: `low` का ऋणात्मक होना केवल "`)` को अतिरिक्त रखने वाली व्याख्या" को सम्मिलित करता है, परंतु `*` को खाली स्ट्रिंग मानकर गिनती 0 या उससे अधिक बनाए रखी जा सकती है। ऋणात्मक मान वास्तव में न चुनी जाने वाली व्याख्या है, इसलिए `low` को 0 पर सही किया जाता है
6. **अंत में `low == 0` है या नहीं इससे निर्णय लिया जाता है**: स्कैन पूर्ण होने पर, यदि `low` 0 है तो इसका अर्थ है कि "सभी खुले कोष्ठकों को बंद करने वाली व्याख्या मौजूद है", इसलिए `true` लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### कोष्ठक अनुक्रम की वैधता जाँच का मूल सिद्धांत

स्ट्रिंग को बाएँ से स्कैन करके खुले कोष्ठकों की गिनती प्रबंधित की जाती है। `(` पर +1, `)` पर -1 किया जाता है, बीच में ऋणात्मक न हो और अंत में 0 हो तो वैध कोष्ठक अनुक्रम है।

```java
int count = 0;
for (char c : s.toCharArray()) {
    if (c == '(') count++;
    else count--;
    if (count < 0) return false;  // बंद कोष्ठक अधिक हैं
}
return count == 0;  // सभी खुले कोष्ठक बंद हो गए या नहीं
```

### Math.max क्या है

दो मानों में से बड़ा मान लौटाने वाला मेथड है। किसी मान को निश्चित निचली सीमा से नीचे न जाने देने (क्लैंप करने) के लिए इसका उपयोग किया जा सकता है।

```java
Math.max(3, 0);    // → 3（3, 0 या उससे अधिक है इसलिए वही रहता है）
Math.max(-1, 0);   // → 0（-1, 0 से कम है इसलिए 0 पर सही किया जाता है）
```

### toCharArray क्या है

स्ट्रिंग को `char` की array में बदलने वाला मेथड है। for-each लूप से स्ट्रिंग को एक-एक वर्ण करके स्कैन करने के लिए इसका उपयोग किया जाता है।

```java
String s = "(*)"；
char[] chars = s.toCharArray();  // → ['(', '*', ')']
for (char c : s.toCharArray()) {
    // c में एक-एक वर्ण असाइन होकर लूप चलता है
}
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n) — स्ट्रिंग को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(1) — केवल `low` और `high` दो चरों का उपयोग किया जाता है |

## कोड

```java
// इनपुट: केवल '('、')'、'*' से बनी स्ट्रिंग s
// आउटपुट: स्ट्रिंग वैध कोष्ठक अनुक्रम बन सकती है या नहीं, boolean में लौटाना है
public boolean checkValidString(String s) {
    // low: खुले कोष्ठक गिनती का न्यूनतम मान, high: अधिकतम मान
    // इन 2 चरों से * की सभी व्याख्याओं में गिनती की सीमा ट्रैक की जाती है
    int low = 0, high = 0;

    // स्ट्रिंग को आरंभ से एक-एक वर्ण स्कैन किया जाता है
    for (char c : s.toCharArray()) {
        if (c == '(') {
            // खुला कोष्ठक: किसी भी व्याख्या में गिनती 1 बढ़ती है, इसलिए सीमा के दोनों सिरों को +1 किया जाता है
            low++;
            high++;
        } else if (c == ')') {
            // बंद कोष्ठक: किसी भी व्याख्या में गिनती 1 घटती है, इसलिए सीमा के दोनों सिरों को -1 किया जाता है
            low--;
            high--;
        } else {
            // '*': ) मानने पर न्यूनतम मान घटता है, ( मानने पर अधिकतम मान बढ़ता है
            // खाली स्ट्रिंग की व्याख्या इस सीमा में सम्मिलित है
            low--;
            high++;
        }

        // यदि अधिकतम मान ऋणात्मक है, तो * की कोई भी व्याख्या चुनने पर बंद कोष्ठक अधिक हैं अतः अमान्य है
        if (high < 0) return false;

        // low का ऋणात्मक होना ) के रूप में अत्यधिक व्याख्या करने के कारण है,
        // वास्तव में वह व्याख्या न चुनना पर्याप्त है, इसलिए न्यूनतम मान को 0 पर सही किया जाता है
        low = Math.max(low, 0);
    }

    // यदि low 0 है तो "सभी खुले कोष्ठकों को बंद करने वाली * की व्याख्या मौजूद है" अतः true
    // यदि low 0 से बड़ा है, तो कोई भी व्याख्या चुनने पर खुले कोष्ठक शेष रहते हैं अतः false
    return low == 0;
}
```
