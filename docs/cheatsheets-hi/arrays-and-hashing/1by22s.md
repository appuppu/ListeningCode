# Finding the Longest Consecutive Number Sequence — बिना सॉर्ट किए गए ऐरे से सबसे लंबी लगातार पूर्णांक अनुक्रम की लंबाई ज्ञात करना

## समस्या का सार

पूर्णांकों की एक ऐरे `nums` (बिना सॉर्ट किए गए) दी गई है। ऐरे में से लगातार पूर्णांकों की श्रृंखला (उदाहरण: 1,2,3,4) खोजनी है और उसकी **सबसे अधिक लंबाई** लौटानी है। तत्वों का क्रम महत्वपूर्ण नहीं है, केवल मान के रूप में लगातार होना आवश्यक है।

## मूल विचार

केवल लगातार अनुक्रम के "प्रारंभ बिंदु" से लंबाई गिनने पर अनावश्यक दोहरी गणना को समाप्त किया जा सकता है। किसी संख्या `num` के लिए यदि `num - 1` HashSet में मौजूद नहीं है, तो वह संख्या लगातार अनुक्रम का प्रारंभ बिंदु है। केवल प्रारंभ बिंदु से गिनती शुरू करने पर समग्र रूप से O(n) प्राप्त होता है।

## विचार प्रक्रिया

1. **लगातार अनुक्रम के प्रारंभ बिंदु को पहचानना**: यदि लगातार अनुक्रम के बीच की संख्या से गिनती शुरू करें तो एक ही श्रृंखला को कई बार गिना जाएगा। केवल वह संख्या जिसके लिए `num - 1` मौजूद नहीं है, वही लगातार अनुक्रम का वास्तविक प्रारंभ बिंदु है। केवल प्रारंभ बिंदु से गिनने पर प्रत्येक तत्व अधिकतम 1 बार ही गिनती का विषय बनता है
2. **अस्तित्व जांच को तेज़ बनाना**: किसी संख्या का ऐरे में होना O(1) में जांचने के लिए सभी तत्वों को HashSet में संग्रहित करना है। सॉर्ट करने पर O(n log n) में हल होता है, लेकिन HashSet का उपयोग करने पर O(n) में पूरा होता है
3. **प्रारंभ बिंदु से लगातार संख्याओं को गिनना**: प्रारंभ बिंदु `num` मिलने पर, `num + 1`, `num + 2`, ... क्रमशः HashSet में मौजूद हैं या नहीं यह जांचना है और लगातार क्रम टूटने तक लंबाई गिननी है
4. **सबसे लंबी श्रृंखला को ट्रैक करना**: प्रत्येक लगातार अनुक्रम की लंबाई को चर `longest` से तुलना करनी है और यदि अधिक लंबी हो तो अपडेट करना है। सभी तत्वों की प्रोसेसिंग के बाद `longest` ही उत्तर है

## पूर्वापेक्षित ज्ञान

### HashSet क्या है

यह एक डेटा संरचना है जो बिना दोहराव के मान संग्रहित करती है। मान जोड़ना और अस्तित्व जांच O(1) में संभव है। HashMap के विपरीत यह केवल key संग्रहित करता है और किसी मान का "मौजूद है या नहीं" तेज़ी से जांचने के लिए उपयोग होता है।

```java
HashSet<Integer> set = new HashSet<>();  // खाली HashSet बनाना
set.add(4);              // मान 4 को सेट में जोड़ना
set.add(4);              // दोहराव को अनदेखा किया जाता है (सेट के तत्वों की संख्या नहीं बदलती)
set.contains(4);         // मान 4 मौजूद है या नहीं boolean में लौटाता है → true
set.contains(5);         // मान 5 मौजूद है या नहीं boolean में लौटाता है → false
```

### लगातार अनुक्रम का प्रारंभ बिंदु क्या है

किसी संख्या `num` के लिए, जब `num - 1` सेट में मौजूद नहीं होता, तब `num` लगातार अनुक्रम की पहली संख्या (प्रारंभ बिंदु) है।
उदाहरण: सेट={100, 4, 200, 1, 3, 2} में, 1 प्रारंभ बिंदु है (0 मौजूद नहीं है), 2 प्रारंभ बिंदु नहीं है (1 मौजूद है)।

## जटिलता

| | मान |
|---|---|
| Time | O(n) — प्रत्येक तत्व को प्रारंभ बिंदु जांच में 1 बार और गिनती में अधिकतम 1 बार, कुल 2 बार ही एक्सेस किया जाता है |
| Space | O(n) — HashSet में अधिकतम n तत्व संग्रहित होते हैं |

## कोड

```java
// इनपुट: पूर्णांक ऐरे nums (बिना सॉर्ट किए गए, दोहराव संभव)
// आउटपुट: सबसे लंबी लगातार पूर्णांक अनुक्रम की लंबाई int में लौटाना
public int longestConsecutive(int[] nums) {
    // सभी तत्वों को HashSet में संग्रहित करना ताकि O(1) में अस्तित्व जांच हो सके
    // दोहराए गए तत्व स्वचालित रूप से हटा दिए जाते हैं
    Set<Integer> numSet = new HashSet<>();
    for (int num : nums) {
        numSet.add(num);
    }

    // अब तक मिली सबसे लंबी लगातार अनुक्रम की लंबाई रखने वाला चर
    int longest = 0;

    // HashSet के प्रत्येक तत्व को स्कैन करना
    for (int num : numSet) {
        // यदि num - 1 मौजूद नहीं है, तो num लगातार अनुक्रम का प्रारंभ बिंदु है
        // यदि num - 1 मौजूद है, तो num लगातार अनुक्रम के बीच की संख्या है इसलिए स्किप करना है
        // (इस संख्या को किसी अन्य प्रारंभ बिंदु से गिनती के समय गिना जाएगा)
        if (!numSet.contains(num - 1)) {
            int currentNum = num;
            int length = 1;

            // प्रारंभ बिंदु से लगातार संख्याओं (num+1, num+2, ...) को क्रमशः गिनना
            // लगातार क्रम टूटने तक लूप जारी रखना
            while (numSet.contains(currentNum + 1)) {
                currentNum++;
                length++;
            }

            // यदि वर्तमान लगातार अनुक्रम की लंबाई अब तक की सबसे लंबी से अधिक है तो अपडेट करना
            longest = Math.max(longest, length);
        }
    }
    // सभी तत्वों की स्कैनिंग पूरी होने पर सबसे लंबी लगातार पूर्णांक अनुक्रम की लंबाई लौटाना
    return longest;
}
```
