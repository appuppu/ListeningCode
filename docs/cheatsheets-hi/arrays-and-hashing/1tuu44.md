# Checking if Two Strings Are Anagrams — दो स्ट्रिंग्स एक दूसरे के अक्षर पुनर्व्यवस्थापन हैं या नहीं, यह जाँचना

## समस्या का सार

दो स्ट्रिंग्स `s` और `t` दी गई हैं। यह निर्धारित करना है कि `t`, `s` का एनाग्राम है या नहीं, और परिणाम **boolean** के रूप में लौटाना है। एनाग्राम का अर्थ है कि दो स्ट्रिंग्स में बिल्कुल समान अक्षर समान बार आते हैं, केवल उनका क्रम भिन्न होता है।

## मूल विचार

एनाग्राम है या नहीं, यह "प्रत्येक अक्षर की उपस्थिति संख्या पूर्णतः मेल खाती है या नहीं" इस प्रश्न पर निर्भर करता है। लोअरकेस अल्फाबेट केवल 26 प्रकार के होते हैं, इसलिए 26 की निश्चित लंबाई वाली एक array से सभी अक्षरों की उपस्थिति संख्या को प्रबंधित करने पर O(1) स्पेस में O(n) समय में निर्णय लिया जा सकता है।

## विचार प्रक्रिया

1. **एनाग्राम की परिभाषा को गणितीय रूप से समझना**: दो स्ट्रिंग्स एनाग्राम होने का अर्थ है कि प्रत्येक अक्षर की उपस्थिति आवृत्ति पूर्णतः मेल खाती है। अर्थात, अक्षरों के क्रम को अनदेखा करके केवल आवृत्ति की तुलना करनी है
2. **यदि लंबाई भिन्न है तो तुरंत false लौटाना**: एनाग्राम में समान अक्षर समान बार होते हैं, इसलिए स्ट्रिंग्स की लंबाई भिन्न होने पर वे एनाग्राम नहीं हो सकतीं। इसे पहले जाँचने से अनावश्यक प्रोसेसिंग से बचा जा सकता है
3. **आवृत्ति तुलना की विधि पर विचार करना**: लोअरकेस अल्फाबेट 'a' से 'z' तक 26 प्रकारों तक सीमित है। HashMap की बजाय, साइज़ 26 की निश्चित लंबाई वाली int array का उपयोग करने से प्रत्येक अक्षर की उपस्थिति संख्या को इंडेक्स से प्रबंधित किया जा सकता है
4. **एक ही array से दोनों स्ट्रिंग्स को प्रोसेस करना**: दो array बनाकर तुलना करने की बजाय, एक array में एक स्ट्रिंग से इंक्रीमेंट और दूसरी से डिक्रीमेंट करना है। अंत में सभी तत्व 0 होने पर आवृत्ति पूर्णतः मेल खाती है
5. **एक ही लूप में दोनों को प्रोसेस करना**: स्ट्रिंग्स की लंबाई समान होने की पुष्टि पहले ही हो चुकी है, इसलिए एक for लूप में `s` का इंक्रीमेंट और `t` का डिक्रीमेंट एक साथ किया जा सकता है
6. **अंतिम निर्णय**: लूप समाप्त होने के बाद, array के सभी तत्व 0 हैं या नहीं, यह जाँचना है। यदि एक भी तत्व 0 नहीं है, तो किसी अक्षर की उपस्थिति संख्या मेल नहीं खाती, इसलिए false लौटाना है

## पूर्वापेक्षित ज्ञान

### अक्षर से array इंडेक्स में रूपांतरण

`char - 'a'` संक्रिया द्वारा लोअरकेस अल्फाबेट को 0 से 25 तक के पूर्णांक में बदला जा सकता है। इससे अक्षर को सीधे array के इंडेक्स के रूप में उपयोग किया जा सकता है।

```java
char c = 'd';
int index = c - 'a';    // 'd' - 'a' = 3（'a'=0, 'b'=1, 'c'=2, 'd'=3）
int[] count = new int[26];
count[c - 'a']++;       // count[3] 1 हो जाता है（'d' की उपस्थिति संख्या दर्ज होती है）
```

### निश्चित लंबाई array द्वारा आवृत्ति गणना

साइज़ 26 की int array तैयार करने पर प्रत्येक इंडेक्स एक अक्षर के अनुरूप आवृत्ति तालिका के रूप में कार्य करता है। Java में `new int[26]` से सभी तत्व 0 से प्रारंभ होते हैं।

```java
int[] count = new int[26];  // सभी तत्व 0 से प्रारंभ होते हैं
count['b' - 'a']++;        // count[1] = 1（'b' की उपस्थिति दर्ज होती है）
count['b' - 'a']--;        // count[1] = 0（'b' की उपस्थिति रद्द होती है）
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n) — स्ट्रिंग को केवल एक बार स्कैन करना पर्याप्त है（n स्ट्रिंग की लंबाई है） |
| Space | O(1) — उपयोग की जाने वाली array का साइज़ सदैव 26 है, जो इनपुट की लंबाई पर निर्भर नहीं करता |

## कोड

```java
// इनपुट: दो स्ट्रिंग्स s और t
// आउटपुट: यदि t, s का एनाग्राम है तो true, अन्यथा false लौटाना है
public boolean isAnagram(String s, String t) {
    // एनाग्राम में समान अक्षर समान बार होते हैं, इसलिए लंबाई भिन्न होने पर एनाग्राम नहीं है
    if (s.length() != t.length())
        return false;

    // प्रत्येक अल्फाबेट की उपस्थिति संख्या का "अंतर" दर्ज करने वाली array（इंडेक्स 0='a', 25='z'）
    // साइज़ 26, a से z तक 26 अक्षरों के अनुरूप है
    int[] count = new int[26];

    // एक लूप में दोनों स्ट्रिंग्स को एक साथ प्रोसेस करना（लंबाई समान होने की पुष्टि पहले ही हो चुकी है）
    for (int i = 0; i < s.length(); i++) {
        // s के अक्षर से इंक्रीमेंट: "s में यह अक्षर 1 बार आया" यह दर्ज करना
        count[s.charAt(i) - 'a']++;
        // t के अक्षर से डिक्रीमेंट: "t में यह अक्षर 1 बार आया" यह दर्ज करना
        // इंक्रीमेंट और डिक्रीमेंट एक दूसरे को रद्द कर दें तो उस अक्षर की उपस्थिति संख्या s और t में समान है
        count[t.charAt(i) - 'a']--;
    }

    // सभी 26 तत्वों को स्कैन करना, यदि एक भी तत्व 0 नहीं है तो उपस्थिति संख्या मेल नहीं खाती
    for (int c : count) {
        if (c != 0) return false;
    }
    // सभी तत्व 0 → सभी अक्षरों की उपस्थिति संख्या मेल खाती है → यह एनाग्राम है
    return true;
}
```
