# Grouping Words by Anagram Patterns — एनाग्राम पैटर्न के अनुसार शब्दों को समूहित करना

## समस्या का सार

एक स्ट्रिंग ऐरे `strs` दिया गया है। जो स्ट्रिंग्स आपस में एनाग्राम हैं, उन्हें एक समूह में रखना है और समूहों की सूची के रूप में वापस करना है। दो स्ट्रिंग्स एनाग्राम होती हैं जब दोनों में समान अक्षर समान संख्या में होते हैं और केवल क्रम भिन्न होता है।

## मुख्य विचार

एनाग्राम शब्दों में "प्रत्येक अक्षर की उपस्थिति संख्या" बिल्कुल समान होती है। 26 अक्षरों में से प्रत्येक की उपस्थिति संख्या गिनकर उसे स्ट्रिंग में बदलकर कुंजी बना लें, तो एनाग्राम शब्द हमेशा समान कुंजी उत्पन्न करते हैं, इसलिए HashMap से एक साथ समूहीकरण किया जा सकता है।

## विचार प्रक्रिया

1. **एनाग्राम की सामान्य विशेषता खोजना**: एनाग्राम शब्दों में केवल अक्षरों का क्रम भिन्न होता है, प्रत्येक अक्षर की उपस्थिति संख्या पूर्णतः समान होती है। इस "उपस्थिति संख्या की समानता" को समूहीकरण के निर्णय मानदंड के रूप में उपयोग किया जा सकता है
2. **उपस्थिति संख्या को कैसे प्रदर्शित करें**: अंग्रेज़ी के छोटे अक्षर 26 प्रकार के होते हैं, इसलिए आकार 26 का पूर्णांक ऐरे `count` तैयार करें और प्रत्येक अक्षर की उपस्थिति संख्या गिनें। यदि इस ऐरे की सामग्री समान है, तो वे शब्द एनाग्राम हैं
3. **ऐरे को HashMap की कुंजी बनाने की विधि**: Java में ऐरे को सीधे HashMap की कुंजी नहीं बनाया जा सकता (क्योंकि संदर्भ तुलना होती है)। इसलिए, ऐरे के प्रत्येक तत्व को `#` से अलग करके जोड़ी गई स्ट्रिंग (उदाहरण: `"1#0#0#...#"`) को कुंजी के रूप में उपयोग करें। इस प्रकार समान उपस्थिति संख्या वाले शब्द समान स्ट्रिंग कुंजी उत्पन्न करते हैं
4. **HashMap से समूहीकरण करना**: समान कुंजी वाले शब्दों को एक ही सूची में डालना है। `computeIfAbsent` का उपयोग करने पर, यदि कुंजी अपंजीकृत है तो स्वचालित रूप से नई सूची बनती है, और यदि पहले से पंजीकृत है तो वही सूची वापस आती है, इसलिए बिना शर्त जाँच के शब्द जोड़ा जा सकता है
5. **अंतिम परिणाम**: HashMap के सभी मान (प्रत्येक समूह की सूची) को `ArrayList` में बदलकर वापस करना है

## पूर्व ज्ञान

### HashMap क्या है

कुंजी और मान के जोड़े को संग्रहीत करने वाली डेटा संरचना है। कुंजी निर्दिष्ट करके मान की खोज और प्राप्ति O(1) में की जा सकती है। यह ऐरे के इंडेक्स एक्सेस जैसी गति से किसी भी कुंजी द्वारा एक्सेस करने योग्य शब्दकोश की तरह है।

```java
HashMap<String, List<String>> map = new HashMap<>();  // खाली HashMap बनाना
map.put("key", new ArrayList<>());  // कुंजी "key" पर खाली सूची संग्रहीत करना
map.containsKey("key");             // कुंजी "key" मौजूद है या नहीं boolean में लौटाना → true
map.get("key");                     // कुंजी "key" से संबंधित मान लौटाना → []
map.values();                       // सभी मानों को Collection के रूप में लौटाना
```

### computeIfAbsent क्या है

HashMap की एक विधि है। यदि निर्दिष्ट कुंजी मौजूद नहीं है, तो दूसरे आर्गुमेंट के lambda expression से मान उत्पन्न करके पंजीकृत करती है और वह मान लौटाती है। यदि कुंजी पहले से मौजूद है, तो मौजूदा मान को वैसे ही लौटाती है। कुंजी की उपस्थिति-अनुपस्थिति की शर्त जाँच को एक पंक्ति में लिखा जा सकता है।

```java
// यदि कुंजी "abc" अपंजीकृत है तो नई ArrayList बनाकर पंजीकृत करना और वह सूची लौटाना
// यदि कुंजी "abc" पहले से पंजीकृत है तो मौजूदा सूची वैसे ही लौटाना
map.computeIfAbsent("abc", k -> new ArrayList<>()).add("cab");
```

### अक्षरों की उपस्थिति संख्या गणना

`char` प्रकार के अक्षर से `'a'` घटाने पर, a=0, b=1, ..., z=25 के इंडेक्स में बदला जा सकता है। आकार 26 का ऐरे तैयार करके इस इंडेक्स की स्थिति को इंक्रीमेंट करने से प्रत्येक अक्षर की उपस्थिति संख्या दर्ज होती है।

```java
int[] count = new int[26];           // 26 अक्षरों के लिए काउंट ऐरे बनाना (प्रारंभिक मान सभी 0)
for (char c : "eat".toCharArray())   // स्ट्रिंग को एक-एक अक्षर करके पढ़ना
    count[c - 'a']++;                // संबंधित अक्षर की स्थिति को इंक्रीमेंट करना
// परिणाम: count[0]=1(a), count[4]=1(e), count[19]=1(t), शेष 0
```

## जटिलता

| | मान |
|---|---|
| Time | O(n × k) — n स्ट्रिंग्स की संख्या है, k स्ट्रिंग की औसत लंबाई है। प्रत्येक स्ट्रिंग के लिए अक्षर गणना और आकार 26 की कुंजी निर्माण किया जाता है |
| Space | O(n × k) — HashMap में सभी स्ट्रिंग्स संग्रहीत होती हैं, प्रत्येक कुंजी निश्चित लंबाई की होती है परंतु स्ट्रिंग स्वयं k अक्षरों की मेमोरी लेती है |

## कोड

```java
// इनपुट: स्ट्रिंग ऐरे strs
// आउटपुट: एनाग्राम शब्दों को समूहित करके List<List<String>> लौटाना
public List<List<String>> groupAnagrams(String[] strs) {
    // कुंजी=उपस्थिति संख्या की स्ट्रिंग अभिव्यक्ति, मान=उस कुंजी से संबंधित शब्दों की सूची संग्रहीत करने वाला HashMap
    // समान कुंजी वाले शब्द आपस में एनाग्राम हैं
    Map<String, List<String>> map = new HashMap<>();

    // ऐरे strs की प्रत्येक स्ट्रिंग s को आरंभ से अंत तक एक-एक करके पढ़ना
    for (String s : strs) {
        // प्रत्येक अक्षर (a से z) की उपस्थिति संख्या दर्ज करने के लिए आकार 26 का ऐरे बनाना (प्रारंभिक मान सभी 0)
        // प्रत्येक स्ट्रिंग के लिए नया ऐरे बनाना इसलिए आवश्यक है ताकि पिछली स्ट्रिंग की गणना शेष न रहे
        int[] count = new int[26];
        // toCharArray() से अक्षर ऐरे में बदलकर, प्रत्येक अक्षर c की उपस्थिति संख्या गिनना
        for (char c : s.toCharArray())
            // c - 'a' द्वारा अक्षर c को इंडेक्स 0 से 25 में बदलकर इंक्रीमेंट करना
            count[c - 'a']++;

        // उपस्थिति संख्या के ऐरे को "1#0#0#..." प्रारूप की स्ट्रिंग कुंजी में बदलना
        // यह कुंजी अक्षरों की उपस्थिति संख्या को अद्वितीय रूप से प्रदर्शित करती है, एनाग्राम शब्द हमेशा समान कुंजी उत्पन्न करते हैं
        // प्रत्येक तत्व के बीच विभाजक # लगाने से भिन्न गणनाएँ समान स्ट्रिंग नहीं बनतीं
        StringBuilder sb = new StringBuilder();
        for (int n : count)
            sb.append(n).append('#');
        String key = sb.toString();

        // यदि कुंजी अपंजीकृत है तो नई सूची बनाना, और वर्तमान स्ट्रिंग को सूची में जोड़ना
        // इससे समान कुंजी वाले शब्द एक ही सूची में एकत्रित होते हैं
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }

    // सभी समूहों का Collection प्राप्त करके List<List<String>> में बदलकर लौटाना
    return new ArrayList<>(map.values());
}
```
