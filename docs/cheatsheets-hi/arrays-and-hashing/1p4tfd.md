# Finding Duplicates in an Array — सरणी में डुप्लिकेट मान मौजूद हैं या नहीं, यह निर्धारित करना

## समस्या का सार

पूर्णांकों की एक सरणी `nums` दी गई है। यदि सरणी में कोई मान 2 बार या उससे अधिक बार आता है तो `true` लौटाएँ, और यदि सभी तत्व अलग-अलग हैं तो `false` लौटाएँ।

## मूल विचार

सरणी को ट्रैवर्स करते हुए, अब तक देखे गए तत्वों को HashSet में रिकॉर्ड करते जाएँ, तो प्रत्येक तत्व पहले से मौजूद है या नहीं, यह O(1) में निर्धारित किया जा सकता है। डुप्लिकेट मिलने पर तुरंत `true` लौटाया जा सकता है।

## विचार प्रक्रिया

1. **डुप्लिकेट का निर्धारण = "पहले भी यही मान देखा था क्या" का निर्धारण**: सरणी को शुरू से ट्रैवर्स करते समय, यदि वर्तमान तत्व पहले भी आ चुका है, तो वह डुप्लिकेट है। अर्थात, यदि "अब तक देखे गए तत्वों के समूह" को प्रबंधित किया जा सके, तो डुप्लिकेट का पता लगाया जा सकता है
2. **पहले देखे गए तत्वों को तेज़ी से खोजना**: प्रत्येक तत्व के लिए "क्या यह मान पहले देखा जा चुका है?" को O(1) में निर्धारित करने के लिए HashSet उपयुक्त है। HashSet एक ऐसी डेटा संरचना है जो तत्व की मौजूदगी की जाँच O(1) में कर सकती है
3. **HashSet में क्या सहेजना है**: समस्या में इंडेक्स नहीं बल्कि केवल बूलियन मान लौटाना है, इसलिए केवल मान को ही HashSet में सहेजना पर्याप्त है
4. **ट्रैवर्स करते हुए HashSet बनाना**: सरणी को शुरू से क्रमशः ट्रैवर्स करें और प्रत्येक तत्व के लिए "क्या यह HashSet में पहले से मौजूद है" निर्धारित करें। यदि मौजूद है तो डुप्लिकेट मिल गया, यदि नहीं है तो वर्तमान तत्व को HashSet में जोड़कर आगे बढ़ें
5. **अर्ली रिटर्न से दक्षता बढ़ाना**: डुप्लिकेट मिलने पर तुरंत `true` लौटाएँ। पूरी सरणी ट्रैवर्स करने के बाद भी यदि डुप्लिकेट नहीं मिलता, तो `false` लौटाएँ

## पूर्वापेक्षित ज्ञान

### HashSet क्या है

HashSet एक ऐसी डेटा संरचना है जो बिना डुप्लिकेट के तत्वों के समूह को प्रबंधित करती है। तत्व जोड़ना और मौजूदगी की जाँच करना O(1) में किया जा सकता है। HashMap के विपरीत, यह कुंजी-मान के जोड़े नहीं बल्कि केवल मान सहेजती है। यह स्वचालित रूप से डुप्लिकेट को हटा देती है।

```java
HashSet<Integer> set = new HashSet<>();  // एक खाली HashSet बनाएँ
set.add(10);              // तत्व 10 को जोड़ें
set.contains(10);         // तत्व 10 मौजूद है या नहीं, boolean लौटाता है → true
set.contains(5);          // तत्व 5 मौजूद है या नहीं, boolean लौटाता है → false
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार ट्रैवर्स करना पर्याप्त है |
| Space | O(n) — HashSet में अधिकतम n तत्व सहेजे जाते हैं |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums
// आउटपुट: डुप्लिकेट मान मौजूद हो तो true, सभी अलग-अलग हों तो false
public boolean containsDuplicate(int[] nums) {
    // अब तक ट्रैवर्स किए गए तत्वों को रिकॉर्ड करने के लिए HashSet
    // समस्या में केवल बूलियन मान चाहिए, इसलिए केवल मान सहेजना पर्याप्त है
    HashSet<Integer> seen = new HashSet<>();

    for (int num : nums) {
        // यदि वर्तमान तत्व पहले से HashSet में मौजूद है, तो एक ही मान दो बार आया है और डुप्लिकेट निश्चित है
        if (seen.contains(num)) {
            return true;  // डुप्लिकेट मिलने पर तुरंत लौटाएँ (अर्ली रिटर्न)
        }

        // वर्तमान तत्व को HashSet में जोड़कर आगे बढ़ें
        // यह तत्व आगे के ट्रैवर्सल में "पहले देखा गया तत्व" के रूप में संदर्भित होगा
        seen.add(num);
    }
    // लूप समाप्त होने पर भी यदि डुप्लिकेट नहीं मिला, तो सभी तत्व अलग-अलग हैं यह निश्चित है
    return false;
}
```
