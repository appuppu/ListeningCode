# Two Sum — दो संख्याओं का योग target के बराबर होने वाली जोड़ी खोजें

## समस्या का सार

एक पूर्णांक सरणी `nums` और एक पूर्णांक `target` दिया गया है। `nums` में से ऐसे दो तत्व खोजें जिनका योग `target` के बराबर हो, और उनके **इंडेक्स** को सरणी के रूप में लौटाएं। हल हमेशा केवल एक ही होता है, और एक ही तत्व को दो बार उपयोग नहीं किया जा सकता।

## मूल विचार

सरणी को स्कैन करते समय, प्रत्येक तत्व `nums[i]` के लिए "जोड़ी का साथी (target - nums[i])" एक ही मान होता है। पहले देखे गए तत्वों को HashMap में दर्ज कर लें, तो साथी मौजूद है या नहीं यह O(1) में जांचा जा सकता है, और एक ही स्कैन में उत्तर मिल जाता है।

## विचार प्रक्रिया

1. **जोड़ी का साथी गणना से निकलता है**: योग `target` होने वाली जोड़ी खोजनी है, इसलिए वर्तमान तत्व `nums[i]` के लिए दूसरा मान `complement = target - nums[i]` से एक ही मान निकलता है
2. **साथी पहले दिखा था या नहीं यह तेज़ी से जांचना है**: सरणी को स्कैन करते हुए, अब तक देखी गई संख्याओं को दर्ज करें, तो complement दर्ज है या नहीं यह O(1) में जांचा जा सकता है। इस रिकॉर्ड के लिए HashMap उपयुक्त है
3. **HashMap में क्या सहेजना है**: समस्या में इंडेक्स लौटाने की आवश्यकता है, इसलिए HashMap की key में "संख्या" और value में "उस संख्या का इंडेक्स" सहेजें। इस प्रकार साथी की मौजूदगी की जांच और इंडेक्स प्राप्ति एक साथ हो सकती है
4. **स्कैन करते हुए HashMap बनाना**: सरणी को शुरू से क्रम में स्कैन करें, और प्रत्येक तत्व के लिए "complement HashMap में है या नहीं" जांचें। यदि है तो जोड़ी मिल गई, नहीं तो वर्तमान तत्व को HashMap में दर्ज करके आगे बढ़ें
5. **दर्ज करना जांच के बाद करें**: यदि HashMap में दर्ज करना जांच से पहले किया जाए, तो `nums[i]` स्वयं complement के रूप में मैच हो जाएगा। इसलिए, जांच → दर्ज करना इस क्रम का पालन करें
6. **अंत में क्या लौटाना है**: complement HashMap में मिलने पर, `map.get(complement)` (साथी का इंडेक्स) और `i` (वर्तमान इंडेक्स) दोनों को `int[]` में लौटाएं

## पूर्वापेक्षित ज्ञान

### HashMap क्या है

key और value की जोड़ी सहेजने वाली डेटा संरचना है। key निर्दिष्ट करके value की खोज और प्राप्ति O(1) में हो सकती है। सरणी के इंडेक्स एक्सेस जैसी गति से, किसी भी key से एक्सेस कर सकने वाले शब्दकोश जैसी चीज़ है।

```java
HashMap<Integer, Integer> map = new HashMap<>();  // खाली HashMap बनाएं
map.put(10, 0);           // key 10 में value 0 सहेजें
map.containsKey(10);      // key 10 मौजूद है या नहीं boolean में लौटाता है → true
map.get(10);              // key 10 से संबंधित value लौटाता है → 0
```

### complement (पूरक) क्या है

`target` में से वर्तमान तत्व को घटाने पर मिलने वाला मान है। यह जोड़ी के साथी की संख्या है। `complement = target - nums[i]` से गणना करें।
उदाहरण: target=9, nums[i]=2 के समय, complement=7। यदि सरणी में 7 मौजूद है तो जोड़ी बन जाती है।

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार स्कैन करने से हल मिल जाता है |
| Space | O(n) — HashMap में अधिकतम n तत्व सहेजे जाते हैं |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums और पूर्णांक target
// आउटपुट: योग target होने वाले 2 तत्वों के इंडेक्स int[] में लौटाएं
public int[] twoSum(int[] nums, int target) {
    // key=संख्या, value=उस संख्या का इंडेक्स सहेजने वाला HashMap
    // समस्या में मान नहीं बल्कि इंडेक्स चाहिए, इसलिए value में इंडेक्स सहेजते हैं
    HashMap<Integer, Integer> map = new HashMap<>();

    for (int i = 0; i < nums.length; i++) {
        // जोड़ी के साथी की गणना करें, और containsKey तथा get में पुनः उपयोग के लिए चर में रखें
        int complement = target - nums[i];

        // यदि complement पहले से HashMap में दर्ज है तो जोड़ी मिल गई
        if (map.containsKey(complement)) {
            // map.get(complement) साथी का इंडेक्स है, i वर्तमान इंडेक्स है
            return new int[]{map.get(complement), i};
        }

        // ध्यान दें: दर्ज करना जांच के बाद करें। पहले दर्ज करने पर nums[i] स्वयं मैच हो जाएगा
        map.put(nums[i], i);
    }
    // समस्या की शर्तों के अनुसार, हल हमेशा मौजूद होता है इसलिए यहां नहीं पहुंचेगा
    return new int[]{};
}
```
