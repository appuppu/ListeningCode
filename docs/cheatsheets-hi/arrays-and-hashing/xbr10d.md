# Finding the K Most Frequent Elements — सरणी से सबसे अधिक बार आने वाले K तत्वों को लौटाना

## समस्या का सार

पूर्णांकों की एक सरणी `nums` और एक पूर्णांक `k` दिया गया है। `nums` में से सबसे अधिक बार आने वाले शीर्ष `k` तत्वों को चुनकर सरणी के रूप में लौटाना है। लौटाने का क्रम कोई भी हो सकता है। यह गारंटी दी गई है कि उत्तर अद्वितीय है।

## मूल विचार

प्रत्येक तत्व की आवृत्ति गिनने के बाद, आवृत्ति को इंडेक्स के रूप में उपयोग करते हुए एक बकेट सरणी बनाई जाए, तो सॉर्ट (O(n log n)) का उपयोग किए बिना O(n) में आवृत्ति क्रम के अनुसार तत्वों को निकाला जा सकता है। आवृत्ति का अधिकतम मान सरणी की लंबाई `n` से अधिक नहीं हो सकता, इसलिए बकेट सरणी का आकार सीमित है।

## विचार प्रक्रिया

1. **सबसे पहले प्रत्येक तत्व की आवृत्ति गिनना आवश्यक है**: शीर्ष K आवृत्ति वाले तत्वों को खोजने के लिए, प्रत्येक तत्व कितनी बार आया है यह जानना आवश्यक है। HashMap का उपयोग करके, कुंजी में "संख्या" और मान में "आवृत्ति" संग्रहीत करके, O(n) में सभी तत्वों की आवृत्ति एकत्र की जा सकती है
2. **आवृत्ति क्रम में व्यवस्थित करना है, लेकिन सॉर्ट में O(n log n) लगता है**: आवृत्ति मैप तैयार होने के बाद, उच्च आवृत्ति क्रम में K तत्व निकालने हैं। आवृत्ति के अनुसार सॉर्ट करने में O(n log n) लगता है, लेकिन एक तेज़ विधि मौजूद है
3. **आवृत्ति को इंडेक्स के रूप में उपयोग करते हुए बकेट सरणी बनाना**: जब सरणी की लंबाई `n` है, तो किसी भी तत्व की आवृत्ति अधिकतम `n` होती है। इसलिए, आकार `n+1` की एक सरणी तैयार करके, इंडेक्स `i` की स्थिति पर "आवृत्ति `i` बार वाले तत्वों की सूची" संग्रहीत की जाती है। यह बकेट सॉर्ट की अवधारणा है
4. **बकेट सरणी को अंत से स्कैन करके K तत्व एकत्र करना**: बकेट सरणी में जितना बड़ा इंडेक्स होगा, उतनी अधिक आवृत्ति होगी। अंत (इंडेक्स `n`) से शुरुआत की ओर स्कैन करते हुए, यदि बकेट खाली नहीं है तो उसमें मौजूद तत्वों को परिणाम सूची में जोड़ा जाता है। परिणाम सूची का आकार `k` तक पहुंचने पर, उस सूची को सरणी में बदलकर लौटाया जाता है

## पूर्व-ज्ञान

### HashMap क्या है

कुंजी और मान के जोड़े को संग्रहीत करने वाली डेटा संरचना है। कुंजी निर्दिष्ट करके मान की खोज और प्राप्ति O(1) में की जा सकती है। इस समस्या में, प्रत्येक संख्या की आवृत्ति गिनने के लिए काउंटर के रूप में इसका उपयोग किया जाता है।

```java
HashMap<Integer, Integer> map = new HashMap<>();  // खाली HashMap बनाना
map.merge(1, 1, Integer::sum);  // कुंजी 1 के मान में 1 जोड़ना (यदि कुंजी मौजूद नहीं है तो 1 से आरंभ करना)
map.entrySet();                 // सभी कुंजी-मान जोड़ों को Set के रूप में लौटाना
entry.getKey();                 // जोड़े से कुंजी प्राप्त करना
entry.getValue();               // जोड़े से मान प्राप्त करना
```

### merge मेथड क्या है

`map.merge(key, value, remappingFunction)` यह विधि, यदि कुंजी मौजूद नहीं है तो `value` को सीधे संग्रहीत करती है, और यदि कुंजी पहले से मौजूद है तो `remappingFunction` द्वारा मौजूदा मान और `value` को संयोजित करती है। `Integer::sum` पास करने पर, मौजूदा मान में `value` जोड़ा जाता है। यह `put` + `getOrDefault` के संयोजन को एक पंक्ति में लिखने वाली सुविधाजनक विधि है।

```java
map.merge(5, 1, Integer::sum);  // यदि कुंजी 5 नहीं है तो 1 संग्रहीत करना, है तो मौजूदा मान+1 संग्रहीत करना
// उपरोक्त का अर्थ निम्नलिखित के समान है
map.put(5, map.getOrDefault(5, 0) + 1);
```

### बकेट सॉर्ट क्या है

तत्व के मान को ही इंडेक्स के रूप में उपयोग करके सरणी में वितरित करने वाली सॉर्ट विधि है। तुलना-आधारित सॉर्ट (O(n log n)) के विपरीत, यदि मानों की सीमा सीमित है तो O(n) में प्रसंस्करण किया जा सकता है। इस समस्या में, आवृत्ति (अधिकतम `n`) को इंडेक्स के रूप में उपयोग किया जाता है।

```java
List<Integer>[] buckets = new ArrayList[4];  // इंडेक्स 0 से 3 तक की बकेट सरणी बनाना
buckets[2] = new ArrayList<>();              // इंडेक्स 2 के बकेट को आरंभ करना
buckets[2].add(7);                           // "आवृत्ति 2 वाले तत्व" के रूप में 7 संग्रहीत करना
// buckets = [null, null, [7], null]
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n) — आवृत्ति मैप के निर्माण में O(n), बकेट सरणी के निर्माण में O(n), परिणाम संग्रह में O(n), कुल मिलाकर O(n) |
| Space | O(n) — आवृत्ति मैप में अधिकतम n प्रविष्टियाँ, बकेट सरणी का आकार n+1, कुल मिलाकर O(n) |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums और पूर्णांक k
// आउटपुट: सबसे अधिक आवृत्ति वाले शीर्ष k तत्वों को संग्रहीत int[] लौटाना
public int[] topKFrequent(int[] nums, int k) {
    // चरण 1: प्रत्येक तत्व की आवृत्ति HashMap से एकत्र करना
    Map<Integer, Integer> freqMap = buildFrequencyMap(nums);
    // चरण 2: आवृत्ति को इंडेक्स के रूप में उपयोग करते हुए बकेट सरणी बनाना
    List<Integer>[] buckets = buildBuckets(freqMap, nums.length);
    // चरण 3: बकेट सरणी को अंत से स्कैन करके शीर्ष K तत्व एकत्र करना
    return collectTopK(buckets, k);
}

// प्रत्येक तत्व की आवृत्ति HashMap से एकत्र करके लौटाना
// कुंजी=संख्या, मान=उस संख्या की आवृत्ति
public Map<Integer, Integer> buildFrequencyMap(int[] nums) {
    Map<Integer, Integer> freqMap = new HashMap<>();
    for (int num : nums) {
        // merge द्वारा, यदि कुंजी नहीं है तो 1 से आरंभ करना, है तो मौजूदा मान में 1 जोड़ना
        freqMap.merge(num, 1, Integer::sum);
    }
    // स्कैन पूर्ण होने के बाद, HashMap में सभी तत्वों की आवृत्ति संग्रहीत है
    return freqMap;
}

// आवृत्ति को इंडेक्स के रूप में उपयोग करते हुए बकेट सरणी बनाकर लौटाना
// buckets[i] में आवृत्ति i बार वाले तत्वों की सूची होती है
public List<Integer>[] buildBuckets(Map<Integer, Integer> freqMap, int n) {
    // आकार n+1 इसलिए है क्योंकि कोई तत्व अधिकतम n बार आ सकता है, और इंडेक्स 0 से n तक उपयोग होता है
    List<Integer>[] buckets = new ArrayList[n + 1];
    for (var entry : freqMap.entrySet()) {
        int num = entry.getKey();
        int freq = entry.getValue();
        // यदि बकेट null है तो नया ArrayList बनाकर जोड़ना
        if (buckets[freq] == null) {
            buckets[freq] = new ArrayList<>();
        }
        // आवृत्ति freq को इंडेक्स के रूप में उपयोग करके, उस बकेट में संख्या num जोड़ना
        buckets[freq].add(num);
    }
    return buckets;
}

// बकेट सरणी को अंत से स्कैन करके, उच्च आवृत्ति क्रम में K तत्व एकत्र करके लौटाना
// इंडेक्स जितना बड़ा होगा आवृत्ति उतनी अधिक होगी, इसलिए उल्टे क्रम में स्कैन करने से उच्च आवृत्ति वाले तत्व पहले निकलते हैं
public int[] collectTopK(List<Integer>[] buckets, int k) {
    List<Integer> result = new ArrayList<>();
    // अंत (इंडेक्स n) से शुरुआत की ओर स्कैन करना। इंडेक्स 0 "आवृत्ति 0 बार" है इसलिए इसे छोड़ा जाता है
    for (int i = buckets.length - 1; i > 0; i--) {
        if (buckets[i] != null) {
            for (int num : buckets[i]) {
                result.add(num);
                // K तत्व एकत्र होने पर सरणी में बदलकर लौटाना
                if (result.size() == k) {
                    return result.stream().mapToInt(Integer::intValue).toArray();
                }
            }
        }
    }
    // समस्या की शर्तों के अनुसार, उत्तर अवश्य मौजूद होता है इसलिए यहाँ कभी नहीं पहुँचा जाता
    return new int[0];
}
```
