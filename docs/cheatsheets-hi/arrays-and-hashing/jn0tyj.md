# Encoding and Decoding a List of Strings — स्ट्रिंग्स की सूची को एक स्ट्रिंग में एनकोड और डिकोड करना

## समस्या का सार

स्ट्रिंग्स की एक सूची `strs` दी गई है। `encode` मेथड सूची को एक स्ट्रिंग में बदलता है, और `decode` मेथड उस स्ट्रिंग को मूल सूची में पुनर्स्थापित करता है। एनकोडिंग और डिकोडिंग स्टेटलेस (अवस्था-रहित) होनी चाहिए, और खाली स्ट्रिंग, विशेष अक्षर, तथा विभाजक अक्षर स्वयं को शामिल करने वाली स्ट्रिंग्स सहित सभी प्रकार के इनपुट को सही ढंग से संभालना आवश्यक है।

## मूल विचार

प्रत्येक स्ट्रिंग के आगे "उस स्ट्रिंग की लंबाई" जोड़ दी जाए, तो स्ट्रिंग के अंदर चाहे कुछ भी हो, उसे सटीक रूप से निकाला जा सकता है। जब लंबाई पहले से ज्ञात हो, तो विभाजक अक्षर के साथ टकराव की समस्या सैद्धांतिक रूप से उत्पन्न ही नहीं होती।

## विचार प्रक्रिया

1. **साधारण विभाजक विधि की समस्याओं को पहचानना**: यदि कॉमा या न्यूलाइन जैसे विभाजक से सूची को जोड़ा जाए, तो जब स्ट्रिंग में स्वयं वह विभाजक अक्षर हो, तब सही ढंग से डिकोड नहीं किया जा सकता। एस्केप प्रोसेसिंग लागू करने पर भी एस्केप अक्षर को स्वयं एस्केप करने की आवश्यकता होती है, जिससे जटिलता बढ़ती है
2. **स्ट्रिंग की लंबाई पहले बताने से टकराव नहीं होता**: प्रत्येक स्ट्रिंग के आगे उसकी लंबाई (बाइट्स नहीं बल्कि अक्षरों की संख्या) दर्ज करने पर, डिकोड करते समय "कितने अक्षर पढ़ने हैं" यह पहले से ज्ञात होता है। स्ट्रिंग की सामग्री की कोई व्याख्या किए बिना उसे निकाला जा सकता है, इसलिए कोई भी अक्षर हो तो भी समस्या नहीं होती
3. **लंबाई और स्ट्रिंग मुख्य भाग के बीच विभाजक के रूप में `#` का उपयोग करना**: लंबाई एक चर-अंकीय पूर्णांक होती है, इसलिए लंबाई भाग के अंत को दर्शाने वाले चिह्न की आवश्यकता होती है। `#` को विभाजक के रूप में उपयोग करके `लंबाई#स्ट्रिंग मुख्य भाग` का प्रारूप बनाया जाता है। डिकोड करते समय पहले `#` की स्थिति से लंबाई भाग पढ़ा जाता है, और उसके बाद से निर्दिष्ट अक्षर संख्या निकाली जाती है
4. **एनकोडिंग**: प्रत्येक स्ट्रिंग के लिए `स्ट्रिंग की लंबाई + "#" + स्ट्रिंग मुख्य भाग` को जोड़कर एक स्ट्रिंग बनाई जाती है। उदाहरण के लिए `["hello", "a#b"]` `5#hello3#a#b` बन जाता है
5. **डिकोडिंग**: शुरुआत से `#` खोजकर लंबाई पढ़ी जाती है, `#` के ठीक बाद से लंबाई के बराबर अक्षर निकाले जाते हैं। निकालने की समाप्ति स्थिति को अगली प्रारंभ स्थिति के रूप में उपयोग करके प्रक्रिया दोहराई जाती है। स्ट्रिंग मुख्य भाग में `#` होने पर भी, लंबाई से सटीक सीमा ज्ञात होने के कारण गलत पहचान नहीं होती
6. **अंतिम रिटर्न**: `encode` एक संयुक्त `String` लौटाता है, और `decode` उस `String` से पुनर्स्थापित `List<String>` लौटाता है

## पूर्वापेक्षित ज्ञान

### StringBuilder क्या है

स्ट्रिंग्स को कुशलतापूर्वक जोड़ने के लिए एक क्लास है। `String` के `+` ऑपरेटर से जोड़ने पर हर बार एक नया `String` ऑब्जेक्ट बनता है, लेकिन `StringBuilder` आंतरिक बफर में जोड़ता है इसलिए O(1) में जोड़ सकता है।

```java
StringBuilder sb = new StringBuilder();  // एक खाली StringBuilder बनाना
sb.append("hello");                      // अंत में "hello" जोड़ना
sb.append(5);                            // अंत में पूर्णांक 5 को स्ट्रिंग के रूप में जोड़ना
sb.toString();                           // परिणाम स्ट्रिंग "hello5" लौटाना
```

### String.indexOf(char, int) क्या है

निर्दिष्ट अक्षर को, निर्दिष्ट प्रारंभ स्थिति से आगे की ओर खोजकर, पहली बार मिलने वाली स्थिति (इंडेक्स) लौटाने वाला मेथड है। न मिलने पर -1 लौटाता है।

```java
String str = "12#hello";
str.indexOf('#', 0);    // स्थिति 0 से '#' खोजना → 2 लौटाता है
str.indexOf('#', 3);    // स्थिति 3 से '#' खोजना → न मिलने पर -1
```

### String.substring(int, int) क्या है

स्ट्रिंग की निर्दिष्ट सीमा को निकालने वाला मेथड है। पहला आर्गुमेंट प्रारंभ स्थिति (सम्मिलित) है, दूसरा आर्गुमेंट समाप्ति स्थिति (सम्मिलित नहीं) है।

```java
String str = "5#hello";
str.substring(0, 1);    // स्थिति 0 से स्थिति 1 के ठीक पहले तक → "5"
str.substring(2, 7);    // स्थिति 2 से स्थिति 7 के ठीक पहले तक → "hello"
```

### Integer.parseInt(String) क्या है

स्ट्रिंग को पूर्णांक में बदलने वाला स्टैटिक मेथड है। लंबाई प्रीफ़िक्स के संख्यात्मक भाग को पूर्णांक के रूप में पढ़ने के लिए इसका उपयोग किया जाता है।

```java
Integer.parseInt("5");    // स्ट्रिंग "5" को पूर्णांक 5 में बदलना
Integer.parseInt("123");  // स्ट्रिंग "123" को पूर्णांक 123 में बदलना
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n × k) — n स्ट्रिंग्स की संख्या है, k स्ट्रिंग्स की औसत लंबाई है। सभी स्ट्रिंग्स को एक-एक बार प्रोसेस किया जाता है |
| Space | O(n × k) — एनकोड परिणाम या डिकोड परिणाम के रूप में सभी स्ट्रिंग्स के बराबर स्थान उपयोग किया जाता है |

## कोड

```java
// === encode ===
// इनपुट: स्ट्रिंग्स की सूची strs (List<String>)
// आउटपुट: सभी स्ट्रिंग्स को एक में मिलाकर String लौटाता है
public String encode(List<String> strs) {
    // लूप में स्ट्रिंग जोड़ने को कुशलतापूर्वक करने के लिए StringBuilder का उपयोग करना
    StringBuilder sb = new StringBuilder();
    // सूची की प्रत्येक स्ट्रिंग को शुरुआत से क्रमानुसार पढ़ना
    for (String str : strs) {
        // प्रत्येक स्ट्रिंग के आगे "लंबाई#" जोड़कर संयोजित करना
        // लंबाई पहले दर्ज करने से, डिकोड करते समय स्ट्रिंग मुख्य भाग की सटीक सीमा ज्ञात होती है
        sb.append(str.length() + "#" + str);
    }
    // StringBuilder की सामग्री को String के रूप में लौटाना
    return sb.toString();
}

// === decode ===
// इनपुट: एनकोड की गई एक स्ट्रिंग str (String)
// आउटपुट: पुनर्स्थापित स्ट्रिंग्स की सूची List<String> लौटाता है
public List<String> decode(String str) {
    List<String> result = new ArrayList<>();
    // वर्तमान पढ़ने की स्थिति को दर्शाने वाला वेरिएबल। शुरुआत से आरंभ होता है
    int i = 0;
    while (i < str.length()) {
        // वर्तमान स्थिति i से पहले '#' को खोजकर, लंबाई भाग और स्ट्रिंग मुख्य भाग के बीच विभाजक स्थिति को पहचानना
        int separatorIndex = str.indexOf('#', i);
        // '#' के ठीक पहले तक को पूर्णांक के रूप में पढ़कर, स्ट्रिंग मुख्य भाग की लंबाई प्राप्त करना
        int textLength = Integer.parseInt(str.substring(i, separatorIndex));
        // '#' के ठीक बाद स्ट्रिंग मुख्य भाग की प्रारंभ स्थिति होती है
        int textStart = separatorIndex + 1;
        // प्रारंभ स्थिति से लंबाई के बराबर आगे समाप्ति स्थिति होती है। लंबाई से सीमा निर्धारित होने के कारण, स्ट्रिंग मुख्य भाग में '#' होने पर भी सही ढंग से निकाला जा सकता है
        int textEnd = textStart + textLength;
        // स्ट्रिंग मुख्य भाग को निकालकर परिणाम सूची में जोड़ना
        result.add(str.substring(textStart, textEnd));
        // पढ़ने की स्थिति को अगली स्ट्रिंग के लंबाई भाग की शुरुआत पर ले जाना
        i = textEnd;
    }
    return result;
}
```
