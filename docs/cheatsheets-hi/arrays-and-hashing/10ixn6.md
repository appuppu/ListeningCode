# Computing Products Without Self Inclusion — स्वयं को छोड़कर सभी तत्वों का गुणनफल ज्ञात करना

## समस्या का सार

एक पूर्णांक सरणी `nums` दी गई है। प्रत्येक इंडेक्स `i` के लिए, `nums[i]` **को छोड़कर** सभी तत्वों का गुणनफल की गणना करें और उस परिणाम को संग्रहीत करने वाली सरणी `result` लौटाएँ। विभाजन संकारक का उपयोग नहीं करना है।

## मूल विचार

किसी तत्व को छोड़कर समस्त तत्वों का गुणनफल, "उस तत्व के बाईं ओर के सभी तत्वों का गुणनफल" × "उस तत्व के दाईं ओर के सभी तत्वों का गुणनफल" में विभाजित किया जा सकता है। इन बाएँ और दाएँ संचयी गुणनफलों को आगे की दिशा और पीछे की दिशा में दो बार ट्रैवर्स करके निर्मित करें, तो बिना विभाजन के O(n) में हल मिल जाता है।

## विचार प्रक्रिया

1. **विभाजन का उपयोग नहीं कर सकते, इसलिए वैकल्पिक विभाजन विधि सोचें**: समस्त तत्वों का गुणनफल निकालकर प्रत्येक तत्व से भाग देने की विधि वर्जित है। अतः, `result[i]` को "`nums[i]` के बाईं ओर का गुणनफल" × "`nums[i]` के दाईं ओर का गुणनफल" के रूप में विभाजित करें। इस विभाजन में भाग देने की आवश्यकता नहीं है
2. **बाईं ओर का संचयी गुणनफल आगे की दिशा में ट्रैवर्स करके बनाया जा सकता है**: सरणी को बाएँ से दाएँ ट्रैवर्स करते हुए, प्रत्येक स्थिति पर "स्वयं से बाईं ओर के सभी तत्वों का गुणनफल" की गणना करें। `result[i] = result[i-1] * nums[i-1]` पुनरावृत्ति सूत्र लागू होता है। पहले तत्व के बाईं ओर कोई तत्व नहीं है, इसलिए `result[0] = 1` (गुणनफल का तत्समक) से आरंभ करें
3. **दाईं ओर का संचयी गुणनफल पीछे की दिशा में ट्रैवर्स करके बनाया जा सकता है**: सरणी को दाएँ से बाएँ ट्रैवर्स करते हुए, चर `record` में "स्वयं से दाईं ओर के सभी तत्वों का गुणनफल" संचित करें। अंतिम तत्व के दाईं ओर कोई तत्व नहीं है, इसलिए `record = 1` से आरंभ करें
4. **दोनों गुणनफलों को गुणा करें**: पीछे की दिशा में ट्रैवर्स करते समय, `result[i]` (बाईं ओर का गुणनफल) में `record` (दाईं ओर का गुणनफल) को गुणा करने से अंतिम उत्तर प्राप्त होता है। गुणा करने के बाद `record = record * nums[i]` से दाईं ओर के गुणनफल को अद्यतन करें
5. **अतिरिक्त सरणी की आवश्यकता नहीं है**: बाईं ओर का गुणनफल सीधे `result` सरणी में लिखा जाता है, और दाईं ओर का गुणनफल एक ही चर से प्रबंधित होता है, इसलिए आउटपुट सरणी के अतिरिक्त O(1) मेमोरी पर्याप्त है

## पूर्वापेक्षित ज्ञान

### संचयी गुणनफल (Prefix Product / Suffix Product) क्या है

सरणी के आरंभ या अंत से क्रमशः तत्वों को गुणा करते हुए प्राप्त गुणनफलों की श्रृंखला। यह संचयी योग का गुणन संस्करण है। प्रत्येक स्थिति पर "उस तक के सभी तत्वों का गुणनफल" कुशलतापूर्वक ज्ञात किया जा सकता है।

```java
int[] nums = {1, 2, 3, 4};

// बाएँ से संचयी गुणनफल (prefix product)
// prefix[0] = 1 (बाईं ओर कोई तत्व नहीं)
// prefix[1] = 1 (nums[0] तक)
// prefix[2] = 1*2 = 2 (nums[1] तक)
// prefix[3] = 1*2*3 = 6 (nums[2] तक)

// दाएँ से संचयी गुणनफल (suffix product)
// suffix[3] = 1 (दाईं ओर कोई तत्व नहीं)
// suffix[2] = 4 (nums[3] तक)
// suffix[1] = 4*3 = 12 (nums[3]*nums[2])
// suffix[0] = 4*3*2 = 24 (nums[3]*nums[2]*nums[1])
```

### गुणनफल का तत्समक

किसी भी संख्या में 1 का गुणा करने पर मान नहीं बदलता। संचयी गुणनफल के प्रारंभिक मान के रूप में 1 का उपयोग करने से, पहले तत्व पर भी वही पुनरावृत्ति सूत्र लागू किया जा सकता है।

```java
int record = 1;              // गुणनफल का प्रारंभिक मान 1 है (तत्समक)
record = record * nums[i];   // पहले गुणन में record = nums[i] हो जाता है
```

## जटिलता विश्लेषण

| | मान |
|---|---|
| Time | O(n) — सरणी को आगे की दिशा और पीछे की दिशा में एक-एक बार ट्रैवर्स करना पर्याप्त है |
| Space | O(1) — आउटपुट सरणी `result` को छोड़कर, अतिरिक्त उपयोग की जाने वाली मेमोरी केवल चर `record` है |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums
// आउटपुट: प्रत्येक इंडेक्स के लिए स्वयं को छोड़कर सभी तत्वों का गुणनफल संग्रहीत int[] लौटाएँ
public int[] productExceptSelf(int[] nums) {
    // nums के समान लंबाई की सरणी बनाएँ। पहले बाईं ओर का संचयी गुणनफल संग्रहीत करें, बाद में दाईं ओर का संचयी गुणनफल गुणा करें
    int[] result = new int[nums.length];

    // आगे की दिशा में ट्रैवर्स: प्रत्येक स्थिति के बाईं ओर के सभी तत्वों का गुणनफल result में संग्रहीत करें
    result[0] = 1;  // पहले तत्व के बाईं ओर कोई तत्व नहीं है, इसलिए गुणनफल के तत्समक 1 से आरंभ करें
    for (int i = 1; i < nums.length; i++) {
        // result[i-1] स्थिति i-1 तक का बाईं ओर का गुणनफल है। उसमें nums[i-1] (एक बाएँ का तत्व) गुणा करके स्थिति i का बाईं ओर का गुणनफल प्राप्त करें
        result[i] = result[i - 1] * nums[i - 1];
    }

    // पीछे की दिशा में ट्रैवर्स: दाईं ओर का संचयी गुणनफल गुणा करके अंतिम परिणाम पूर्ण करें
    // record "वर्तमान स्थिति से दाईं ओर के सभी तत्वों का गुणनफल" संचित करने वाला चर है
    int record = 1;  // अंतिम तत्व के दाईं ओर कोई तत्व नहीं है, इसलिए 1 से आरंभ करें
    for (int i = nums.length - 1; i >= 0; i--) {
        // result[i] में बाईं ओर का गुणनफल संग्रहीत है। record (दाईं ओर का गुणनफल) गुणा करके "स्वयं को छोड़कर सभी तत्वों का गुणनफल" पूर्ण करें
        result[i] = record * result[i];
        // ध्यान दें: record का अद्यतन result[i] निश्चित करने के बाद करें। पहले अद्यतन करने पर nums[i] स्वयं गुणनफल में शामिल हो जाएगा
        record = record * nums[i];
    }

    // प्रत्येक तत्व में "स्वयं को छोड़कर सभी तत्वों का गुणनफल" संग्रहीत result लौटाएँ
    return result;
}
```
