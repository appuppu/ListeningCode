# Validating a Sudoku Board — 9×9 के Sudoku बोर्ड की वैधता की जाँच करना

## समस्या का सार

9×9 की द्विआयामी वर्ण सरणी (character array) के रूप में एक Sudoku बोर्ड दिया गया है। प्रत्येक पंक्ति, प्रत्येक स्तंभ, और प्रत्येक 3×3 के उप-ग्रिड में कोई दोहराई गई संख्या नहीं है तो बोर्ड को वैध माना जाता है और `true` लौटाया जाता है। खाली सेल को डॉट `.` से दर्शाया जाता है। बोर्ड का पूर्ण होना आवश्यक नहीं है — केवल यह जाँचना है कि वर्तमान व्यवस्था नियमों का उल्लंघन तो नहीं करती।

## मूल विचार

पूरे बोर्ड को एक बार स्कैन करते हुए, यदि किसी सेल की संख्या "उसकी पंक्ति", "उसके स्तंभ", या "उसके 3×3 बॉक्स" में पहले से मौजूद है, तो बोर्ड को अवैध माना जाता है। किसी भी सेल `(i, j)` का बॉक्स इंडेक्स `(i/3) * 3 + j/3` सूत्र से 0 से 8 में विशिष्ट रूप से मैप किया जा सकता है।

## विचार प्रक्रिया

1. **सत्यापन की शर्तों को व्यवस्थित करना**: Sudoku की वैधता "प्रत्येक पंक्ति में कोई दोहराव नहीं", "प्रत्येक स्तंभ में कोई दोहराव नहीं", और "प्रत्येक 3×3 बॉक्स में कोई दोहराव नहीं" — इन तीन शर्तों से निर्धारित होती है। यदि इन तीनों शर्तों को एक साथ सत्यापित किया जा सके तो यह कुशल होगा
2. **दोहराव पहचानने के लिए HashSet उपयुक्त है**: किसी संख्या के पहले आ चुकने की जाँच O(1) में करने के लिए HashSet सर्वोत्तम है। प्रत्येक पंक्ति के लिए 9, प्रत्येक स्तंभ के लिए 9, और प्रत्येक बॉक्स के लिए 9 — कुल 27 HashSet तैयार करने से तीनों शर्तों की एक साथ जाँच की जा सकती है
3. **सेल से बॉक्स में मैपिंग आवश्यक है**: सेल `(i, j)` किस बॉक्स से संबंधित है, इसकी गणना करनी होगी। पंक्ति दिशा में `i/3` (पूर्णांक विभाजन) से 0, 1, 2 के तीन समूह बनते हैं, और स्तंभ दिशा में `j/3` से 0, 1, 2 के तीन समूह बनते हैं। इसे एकआयामी इंडेक्स में बदलने के लिए `(i/3) * 3 + j/3` का उपयोग किया जाता है। इससे 9 बॉक्सों को 0 से 8 तक की संख्या प्राप्त होती है
4. **एक ही स्कैन में सभी शर्तों की जाँच करना**: दोहरे for लूप से पूरे बोर्ड को स्कैन किया जाता है, और प्रत्येक सेल के लिए पंक्ति, स्तंभ, और बॉक्स के तीन Set में दोहराव की जाँच और पंजीकरण किया जाता है। डॉट संख्या नहीं है इसलिए उसे छोड़ दिया जाता है
5. **दोहराव मिलने पर तुरंत false लौटाना**: यदि तीन Set में से किसी में भी वही संख्या पहले से मौजूद है, तो वह बोर्ड अवैध है और तुरंत `false` लौटाया जाता है
6. **सभी सेल स्कैन होने के बाद true लौटाना**: यदि कोई भी दोहराव नहीं मिलता, तो बोर्ड वैध है

## पूर्व-ज्ञान

### HashSet क्या है

HashSet एक ऐसी डेटा संरचना है जो बिना दोहराव वाले तत्वों के समूह का प्रबंधन करती है। तत्व जोड़ना और उसकी उपस्थिति की जाँच करना O(1) में किया जा सकता है। यहाँ इसका उपयोग "कोई संख्या पहले आ चुकी है या नहीं" की तेज़ जाँच के लिए किया जाता है।

```java
Set<Character> set = new HashSet<>();  // खाली HashSet बनाना
set.add('5');            // तत्व '5' को जोड़ना
set.contains('5');       // तत्व '5' मौजूद है या नहीं boolean में लौटाना → true
set.contains('3');       // तत्व '3' मौजूद है या नहीं boolean में लौटाना → false
```

### HashSet की सरणी बनाने की विधि

9 HashSet को एक सरणी के रूप में एक साथ प्रबंधित किया जाता है। जेनेरिक्स सरणी सीधे नहीं बनाई जा सकती, इसलिए `new HashSet[9]` से रॉ टाइप की सरणी बनाई जाती है और प्रत्येक तत्व को लूप से प्रारंभ किया जाता है।

```java
Set<Character>[] sets = new HashSet[9];  // 9 तत्वों की सरणी आवंटित करना
for (int i = 0; i < 9; i++) {
    sets[i] = new HashSet<>();           // प्रत्येक तत्व को खाली HashSet से प्रारंभ करना
}
```

### बॉक्स इंडेक्स की गणना का सूत्र

`boxIdx = (i/3) * 3 + j/3` सेल `(i, j)` जिस 3×3 बॉक्स से संबंधित है उसकी संख्या (0 से 8) लौटाता है। `i/3` पंक्ति दिशा में बॉक्स की स्थिति (0, 1, 2) दर्शाता है और `j/3` स्तंभ दिशा में बॉक्स की स्थिति (0, 1, 2) दर्शाता है। पंक्ति दिशा की स्थिति में 3 गुणा करके स्तंभ दिशा की स्थिति जोड़ने से 9 बॉक्सों को एक विशिष्ट संख्या दी जाती है।

```
बॉक्स संख्या की व्यवस्था:
0 | 1 | 2
3 | 4 | 5
6 | 7 | 8

उदाहरण: सेल(4, 7) → (4/3)*3 + 7/3 = 1*3 + 2 = 5 → बॉक्स 5 से संबंधित है
```

## जटिलता विश्लेषण

| | मान |
|---|---|
| Time | O(n²) — 9×9 के पूरे बोर्ड को एक बार स्कैन किया जाता है (n=9 स्थिर है इसलिए O(81)=O(1) भी कहा जा सकता है) |
| Space | O(n²) — 27 HashSet में अधिकतम 81 तत्व संग्रहीत किए जाते हैं |

## कोड

```java
// इनपुट: 9×9 की द्विआयामी वर्ण सरणी board (संख्या '1'〜'9' या डॉट '.')
// आउटपुट: बोर्ड वैध है तो true, अवैध है तो false लौटाना
public boolean isValidSudoku(char[][] board) {
    // पंक्ति, स्तंभ, और बॉक्स के लिए आई हुई संख्याओं को रिकॉर्ड करने वाली HashSet सरणी बनाना
    // rowset[i] i-वीं पंक्ति, columnset[j] j-वें स्तंभ, boxset[k] k-वें बॉक्स में आई संख्याओं को रिकॉर्ड करता है
    Set<Character>[] rowset = createSets();
    Set<Character>[] columnset = createSets();
    Set<Character>[] boxset = createSets();

    // बाहरी लूप पंक्ति और आंतरिक लूप स्तंभ को स्कैन करता है, सभी 81 सेल एक-एक बार देखे जाते हैं
    for (int i = 0; i < 9; i++) {
        for (int j = 0; j < 9; j++) {
            // वर्तमान सेल का मान प्राप्त करना
            char c = board[i][j];
            // डॉट खाली सेल (संख्या नहीं) है इसलिए छोड़ देना
            if (c == '.') {
                continue;
            }

            // सेल(i, j) जिस बॉक्स से संबंधित है उसकी संख्या की गणना करना (0 से 8 में विशिष्ट रूप से मैप होता है)
            int boxIdx = (i / 3) * 3 + j / 3;

            // पंक्ति, स्तंभ, या बॉक्स में से किसी में भी वही संख्या पहले से है तो दोहराव है इसलिए तुरंत false लौटाना
            if (rowset[i].contains(c) || columnset[j].contains(c) || boxset[boxIdx].contains(c)) {
                return false;
            }

            // दोहराव नहीं है तो तीनों Set में वर्तमान संख्या पंजीकृत करना, आगे दोहराव पहचानने के लिए
            rowset[i].add(c);
            columnset[j].add(c);
            boxset[boxIdx].add(c);
        }
    }
    // सभी सेल स्कैन करने पर कोई दोहराव नहीं मिला, तो बोर्ड वैध है
    return true;
}

// 9 खाली HashSet की सरणी बनाने वाला सहायक मेथड
public Set<Character>[] createSets() {
    Set<Character>[] sets = new HashSet[9];
    for (int i = 0; i < 9; i++) {
        sets[i] = new HashSet<>();
    }
    return sets;
}
```
