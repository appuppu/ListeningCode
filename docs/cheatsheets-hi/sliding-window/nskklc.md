# Finding the Smallest Window Containing All Characters — सभी अक्षरों को शामिल करने वाली सबसे छोटी उप-स्ट्रिंग ढूँढना

## समस्या का सार

दो स्ट्रिंग `s` और `t` दी गई हैं। `s` में से `t` के सभी अक्षरों (डुप्लिकेट सहित) को शामिल करने वाली **सबसे छोटी उप-स्ट्रिंग** ढूँढकर लौटानी है। यदि ऐसी कोई उप-स्ट्रिंग मौजूद नहीं है तो खाली स्ट्रिंग लौटानी है।

## मूल विचार

दायाँ पॉइंटर बढ़ाकर शर्त पूरी करने वाली विंडो बनाना है, और बायाँ पॉइंटर सिकोड़कर उसे न्यूनतम करना है। "शर्त पूरी करने वाले अक्षर प्रकारों की संख्या" को एक वेरिएबल से प्रबंधित करके, विंडो की वैधता O(1) में जाँची जा सकती है।

## विचार प्रक्रिया

1. **आवश्यक अक्षरों की उपस्थिति संख्या पहले से गिनना**: `t` में शामिल प्रत्येक अक्षर की उपस्थिति संख्या HashMap में दर्ज करना है। यही वह शर्त है जो विंडो को पूरी करनी होगी। उदाहरण के लिए `t = "ABC"` हो तो `{A:1, B:1, C:1}` बनेगा
2. **विंडो को दाईं ओर बढ़ाकर शर्त पूरी करना**: दायाँ पॉइंटर `r` एक-एक करके आगे बढ़ाकर विंडो में अक्षर जोड़ना है, और विंडो के अंदर अक्षरों की उपस्थिति संख्या एक अलग HashMap से प्रबंधित करनी है। जब विंडो के अंदर किसी अक्षर प्रकार की उपस्थिति संख्या आवश्यक संख्या तक पहुँचती है, तो काउंटर `have` को इंक्रीमेंट करना है
3. **शर्त की पूर्ति O(1) में जाँचना**: `need` का आकार (आवश्यक अक्षर प्रकारों की संख्या) को `required` मानकर, `have == required` सत्य हो तो विंडो में `t` के सभी अक्षर शामिल हैं। अक्षर प्रकार के स्तर पर प्रबंधन करने से, हर बार सभी अक्षरों की तुलना करने की आवश्यकता नहीं रहती
4. **विंडो को बाईं ओर से सिकोड़कर न्यूनतम करना**: `have == required` होने तक, बायाँ पॉइंटर `left` दाईं ओर बढ़ाकर विंडो को छोटा करना है। हर बार सिकोड़ने पर विंडो की लंबाई वर्तमान न्यूनतम मान से तुलना करनी है, और यदि छोटी हो तो अपडेट करना है
5. **बाएँ छोर का अक्षर हटाने पर की जाने वाली प्रक्रिया**: बाएँ छोर का अक्षर `s.charAt(left)` विंडो से हटाते समय, यदि वह अक्षर `need` में शामिल है और विंडो के अंदर उसकी उपस्थिति संख्या आवश्यक संख्या से कम हो जाती है, तो `have` को डिक्रीमेंट करना है। इससे `while` लूप समाप्त होता है और दाएँ पॉइंटर के विस्तार पर वापस लौटता है
6. **अंत में क्या लौटाना है**: स्कैन पूरा होने के बाद, यदि न्यूनतम विंडो मिली है तो `s.substring(resStart, resStart + resLen)` लौटाना है। यदि नहीं मिली तो खाली स्ट्रिंग लौटानी है

## पूर्व-ज्ञान

### HashMap क्या है

HashMap एक डेटा संरचना है जो कुंजी और मान के जोड़े संग्रहीत करती है। कुंजी निर्दिष्ट करके मान की खोज और प्राप्ति O(1) में की जा सकती है। इस समस्या में इसका उपयोग अक्षरों की उपस्थिति संख्या प्रबंधित करने के लिए किया जाता है।

```java
HashMap<Character, Integer> map = new HashMap<>();  // खाली HashMap बनाना
map.put('A', 1);                    // कुंजी 'A' में मान 1 संग्रहीत करना
map.getOrDefault('A', 0);           // कुंजी 'A' का मान लौटाना। मौजूद न हो तो 0 लौटाना → 1
map.containsKey('A');               // कुंजी 'A' मौजूद है या नहीं boolean में लौटाना → true
map.get('A').equals(map.get('B'));  // Integer ऑब्जेक्ट्स की तुलना के लिए equals का उपयोग करना
```

### Sliding Window (स्लाइडिंग विंडो) क्या है

Sliding Window एक तकनीक है जो ऐरे या स्ट्रिंग पर एक सतत सीमा (विंडो) को दो पॉइंटर `left` और `right` से प्रबंधित करती है। दाएँ पॉइंटर से विंडो बढ़ाकर और बाएँ पॉइंटर से विंडो सिकोड़कर, सभी उप-स्ट्रिंग जाँचने की O(n²) प्रक्रिया को O(n) में अनुकूलित किया जा सकता है।

```java
int left = 0;
for (int r = 0; r < s.length(); r++) {
    // दाएँ पॉइंटर से विंडो बढ़ाने की प्रक्रिया
    while (शर्त पूरी हो रही है) {
        // बाएँ पॉइंटर से विंडो सिकोड़ने की प्रक्रिया
        left++;
    }
}
```

### have / required पैटर्न क्या है

यह एक तकनीक है जो O(1) में जाँचती है कि विंडो शर्त पूरी कर रही है या नहीं। `required` पूरी करने योग्य अक्षर प्रकारों की कुल संख्या है, और `have` वर्तमान में आवश्यक संख्या तक पहुँचे अक्षर प्रकारों की संख्या है। जब `have == required` हो तब विंडो सभी शर्तें पूरी कर रही है।

```java
int required = need.size();  // आवश्यक अक्षर प्रकारों की संख्या (उदा: need={A:1,B:1,C:1} → 3)
int have = 0;                // शर्त पूरी करने वाले अक्षर प्रकारों की संख्या (प्रारंभिक मान 0)
// विंडो में 'A' की संख्या need के 'A' की संख्या तक पहुँचे तो have++ → have==required पर सभी शर्तें पूरी
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — दायाँ पॉइंटर और बायाँ पॉइंटर प्रत्येक `s` को अधिकतम एक बार स्कैन करते हैं |
| Space | O(n) — HashMap `need` और `window` में अधिकतम `s` और `t` के अक्षर प्रकारों की संख्या जितने तत्व संग्रहीत होते हैं |

## कोड

```java
// इनपुट: स्ट्रिंग s और स्ट्रिंग t
// आउटपुट: s में से t के सभी अक्षरों को शामिल करने वाली सबसे छोटी उप-स्ट्रिंग String में लौटाना। मौजूद न हो तो खाली स्ट्रिंग लौटाना
String minWindow(String s, String t) {
    // यदि s, t से छोटा है तो सभी अक्षरों को शामिल करने वाली विंडो मौजूद नहीं है
    if (s.length() < t.length())
        return "";

    // t के प्रत्येक अक्षर की आवश्यक उपस्थिति संख्या दर्ज करने वाला HashMap। यह विंडो की शर्त को परिभाषित करता है
    Map<Character, Integer> need = new HashMap<>();
    for (char c : t.toCharArray()) {
        need.put(c, need.getOrDefault(c, 0) + 1);
    }

    // विंडो के अंदर प्रत्येक अक्षर की उपस्थिति संख्या प्रबंधित करने वाला HashMap
    Map<Character, Integer> window = new HashMap<>();
    int have = 0;              // शर्त पूरी करने वाले अक्षर प्रकारों की संख्या
    int required = need.size(); // पूरी करने योग्य अक्षर प्रकारों की कुल संख्या (need की कुंजियों की संख्या)
    int resLen = Integer.MAX_VALUE; // न्यूनतम विंडो की लंबाई (न मिलने की स्थिति दर्शाने वाला प्रारंभिक मान)
    int resStart = 0;          // न्यूनतम विंडो की प्रारंभ स्थिति
    int left = 0;              // बायाँ पॉइंटर

    // दाएँ पॉइंटर से विंडो को दाईं ओर बढ़ाते जाना
    for (int r = 0; r < s.length(); r++) {
        char c = s.charAt(r);
        // विंडो के अंदर अक्षर c की उपस्थिति संख्या 1 बढ़ाना (विंडो दाईं ओर 1 अक्षर बढ़ती है)
        window.put(c, window.getOrDefault(c, 0) + 1);

        // यदि अक्षर c, t में आवश्यक अक्षर है और विंडो में उसकी उपस्थिति संख्या आवश्यक संख्या तक ठीक पहुँची है तो have बढ़ाना
        // ध्यान दें: Integer ऑब्जेक्ट्स की तुलना के लिए == नहीं बल्कि equals का उपयोग करना
        if (need.containsKey(c)
            && window.get(c).equals(need.get(c))) {
            have++;
        }

        // जब तक विंडो सभी शर्तें पूरी कर रही है (have == required), बाईं ओर से सिकोड़कर न्यूनतम करना
        while (have == required) {
            int wLen = r - left + 1;
            // यदि अधिक छोटी विंडो मिली तो परिणाम अपडेट करना
            if (wLen < resLen) {
                resLen = wLen;
                resStart = left;
            }
            // बाएँ छोर का अक्षर विंडो से हटाना
            char lc = s.charAt(left);
            window.put(lc, window.get(lc) - 1);
            // हटाने से विंडो में उपस्थिति संख्या आवश्यक संख्या से कम हो जाए तो शर्त टूटी है इसलिए have घटाना
            if (need.containsKey(lc)
                && window.get(lc) < need.get(lc)) {
                have--;
            }
            // बाएँ पॉइंटर को दाईं ओर बढ़ाकर विंडो सिकोड़ना
            left++;
        }
    }

    // यदि resLen प्रारंभिक मान पर ही है तो शर्त पूरी करने वाली विंडो नहीं मिली इसलिए खाली स्ट्रिंग लौटाना
    if (resLen == Integer.MAX_VALUE)
        return "";
    // न्यूनतम विंडो की प्रारंभ स्थिति से न्यूनतम विंडो की लंबाई जितना भाग निकालकर लौटाना
    return s.substring(resStart, resStart + resLen);
}
```
