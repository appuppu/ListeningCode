# Finding the Longest Substring Without Repeating Characters — दोहराए जाने वाले वर्णों को शामिल न करने वाली सबसे लंबी सबस्ट्रिंग की लंबाई ज्ञात करना

## समस्या का सार

एक स्ट्रिंग `s` दी गई है। `s` में से ऐसी सबसे लंबी निरंतर सबस्ट्रिंग (substring) खोजनी है जिसमें कोई भी वर्ण 2 बार या उससे अधिक बार न आए, और उसकी **अधिकतम लंबाई** को पूर्णांक के रूप में लौटाना है।

## मूल विचार

स्लाइडिंग विंडो का उपयोग करने से सभी मान्य सबस्ट्रिंग्स को O(n) में जाँचा जा सकता है। जब दोहराव पाया जाता है, तो बाएँ सिरे को "दोहराए गए वर्ण की पिछली स्थिति + 1" तक एक साथ कूदाकर, एक-एक करके आगे बढ़ने की अनावश्यक प्रक्रिया को छोड़ा जा सकता है।

## विचार प्रक्रिया

1. **सबस्ट्रिंग की खोज को विंडो के रूप में प्रस्तुत करना**: "दोहराव-रहित सबस्ट्रिंग" को बाएँ सिरे `left` और दाएँ सिरे `right` के दो पॉइंटरों से घिरे अंतराल के रूप में प्रस्तुत किया जा सकता है। दाएँ सिरे को एक-एक करके आगे बढ़ाकर विंडो को फैलाया जाता है, और दोहराव होने पर बाएँ सिरे को आगे बढ़ाकर विंडो को सिकोड़ा जाता है
2. **दोहराव की पहचान के लिए HashMap का उपयोग करना**: प्रत्येक वर्ण का "अंतिम बार प्रकट हुआ इंडेक्स" HashMap में दर्ज करने से, नया वर्ण विंडो में पहले से मौजूद है या नहीं यह O(1) में निर्धारित किया जा सकता है
3. **बाएँ सिरे की कूद शर्त को सटीक रूप से निर्धारित करना**: `right` का वर्ण HashMap में मौजूद होना ही पर्याप्त नहीं है। उस वर्ण की पिछली स्थिति `left` के बराबर या उससे अधिक (अर्थात वर्तमान विंडो के अंदर) होने पर ही इसे दोहराव माना जाता है। विंडो के बाहर के पुराने रिकॉर्ड को अनदेखा किया जाता है
4. **बाएँ सिरे के गंतव्य को निर्धारित करना**: दोहराव पाए जाने पर, `left` को "दोहराए गए वर्ण की पिछली स्थिति + 1" पर अपडेट किया जाता है। इससे दोहराए गए वर्ण को विंडो से बाहर करते हुए, अन्य मान्य वर्णों को विंडो में बनाए रखा जा सकता है
5. **HashMap को अपडेट करने का समय**: दोहराव की जाँच के बाद, वर्तमान वर्ण के इंडेक्स को HashMap में दर्ज (ओवरराइट) किया जाता है। इससे प्रत्येक वर्ण की नवीनतम स्थिति हमेशा दर्ज रहती है
6. **अधिकतम लंबाई को अपडेट करना**: प्रत्येक चरण में `right - left + 1` (वर्तमान विंडो की चौड़ाई) की गणना की जाती है, और अब तक के अधिकतम मान से तुलना करके अपडेट किया जाता है

## पूर्वापेक्षित ज्ञान

### स्लाइडिंग विंडो क्या है

यह एक तकनीक है जिसमें ऐरे या स्ट्रिंग पर दो पॉइंटर (`left`, `right`) द्वारा परिभाषित अंतराल को एक "विंडो" के रूप में आगे बढ़ाते हुए, शर्त को पूरा करने वाले भाग की खोज की जाती है। दाएँ सिरे को आगे बढ़ाकर विंडो को फैलाया जाता है, और शर्त का उल्लंघन होने पर बाएँ सिरे को आगे बढ़ाकर विंडो को सिकोड़ा जाता है। प्रत्येक पॉइंटर केवल आगे की दिशा में चलता है, इसलिए कुल मिलाकर O(n) की जटिलता होती है।

### HashMap क्या है

यह एक डेटा संरचना है जो कुंजी और मान के जोड़ों को संग्रहीत करती है। कुंजी निर्दिष्ट करके मान की खोज और प्राप्ति O(1) में की जा सकती है। इस समस्या में, कुंजी के रूप में "वर्ण" और मान के रूप में "उस वर्ण का अंतिम बार प्रकट हुआ इंडेक्स" संग्रहीत किया जाता है।

```java
HashMap<Character, Integer> map = new HashMap<>();  // एक खाली HashMap बनाना
map.put('a', 0);            // कुंजी 'a' में मान 0 संग्रहीत करना
map.containsKey('a');       // कुंजी 'a' मौजूद है या नहीं यह boolean के रूप में लौटाना → true
map.get('a');               // कुंजी 'a' से संबंधित मान लौटाना → 0
```

### charAt क्या है

यह एक मेथड है जो स्ट्रिंग में निर्दिष्ट स्थान पर मौजूद वर्ण को प्राप्त करता है। `s.charAt(i)` स्ट्रिंग `s` के इंडेक्स `i` पर मौजूद `char` को लौटाता है।

```java
String s = "abc";
char c = s.charAt(0);  // 'a' लौटाता है
char d = s.charAt(2);  // 'c' लौटाता है
```

### Math.max क्या है

यह एक मेथड है जो दो मानों में से बड़े मान को लौटाता है। इसका उपयोग अधिकतम मान को लगातार अपडेट करने के लिए किया जाता है।

```java
int result = Math.max(3, 7);  // 7 लौटाता है
maxLength = Math.max(maxLength, currentLength);  // वर्तमान अधिकतम मान को अपडेट करना
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — `right` स्ट्रिंग को केवल एक बार स्कैन करता है। `left` भी केवल आगे की दिशा में चलता है इसलिए कुल मिलाकर O(n) होता है |
| Space | O(n) — HashMap में अधिकतम n वर्णों और इंडेक्स के जोड़ों को संग्रहीत किया जाता है |

## कोड

```java
// इनपुट: स्ट्रिंग s
// आउटपुट: दोहराए जाने वाले वर्णों को शामिल न करने वाली सबसे लंबी सबस्ट्रिंग की लंबाई int के रूप में लौटाना
public int lengthOfLongestSubstring(String s) {
    // विंडो का बायाँ सिरा पॉइंटर। प्रारंभिक स्थिति स्ट्रिंग की शुरुआत है
    int left = 0;
    // स्कैनिंग के दौरान पाई गई सबसे लंबी विंडो चौड़ाई को दर्ज करने वाला वेरिएबल
    int maxLength = 0;
    // कुंजी=वर्ण, मान=उस वर्ण का अंतिम बार प्रकट हुआ इंडेक्स संग्रहीत करने वाला HashMap
    // दोहराव की जाँच और बाएँ सिरे के कूद गंतव्य की गणना दोनों के लिए उपयोग किया जाता है
    HashMap<Character, Integer> hashMap = new HashMap<>();

    // right विंडो के दाएँ सिरे का पॉइंटर है। इसे एक-एक करके आगे बढ़ाकर विंडो को फैलाया जाता है
    for (int right = 0; right < s.length(); right++) {
        // विंडो में जोड़े जाने वाले वर्ण को प्राप्त करना
        char curChar = s.charAt(right);

        // containsKey: यह वर्ण पहले प्रकट हुआ है या नहीं इसकी जाँच करना
        // get(curChar) >= left: वह स्थिति वर्तमान विंडो के अंदर है या नहीं इसकी पुष्टि करना
        // दोनों सत्य होने पर, विंडो में दोहराव मौजूद है
        if (hashMap.containsKey(curChar) && hashMap.get(curChar) >= left) {
            // दोहराए गए वर्ण की पिछली स्थिति+1 पर बाएँ सिरे को कूदाकर, दोहराव को समाप्त करना
            // left हमेशा केवल आगे की दिशा में चलता है, इसलिए यह कभी पीछे नहीं जाता
            left = hashMap.get(curChar) + 1;
        }

        // वर्तमान वर्ण की स्थिति को नवीनतम इंडेक्स से ओवरराइट करके दर्ज करना
        // अगली बार यह वर्ण प्रकट होने पर, यहाँ दर्ज किए गए इंडेक्स से बाएँ सिरे के कूद गंतव्य की गणना की जाएगी
        hashMap.put(curChar, right);
        // right - left + 1 वर्तमान विंडो की चौड़ाई (दोहराव-रहित सबस्ट्रिंग की लंबाई) है
        // पिछले अधिकतम मान से अधिक होने पर अपडेट करना
        maxLength = Math.max(maxLength, right - left + 1);
    }
    // यह दोहराए जाने वाले वर्णों को शामिल न करने वाली सबसे लंबी सबस्ट्रिंग की लंबाई है
    return maxLength;
}
```
