# Longest Substring After Replacing K Characters — K बार अक्षर बदलकर प्राप्त होने वाली सबसे लंबी समान-अक्षर उपस्ट्रिंग ज्ञात करें

## समस्या का सार

बड़े अक्षरों (uppercase) की एक स्ट्रिंग `s` और एक पूर्णांक `k` दिया गया है। स्ट्रिंग में अधिकतम `k` अक्षरों को किसी भी अक्षर से बदला जा सकता है, तब **सभी अक्षर समान** होने वाली उपस्ट्रिंग की अधिकतम लंबाई लौटाएँ।

## मूल विचार

विंडो के भीतर "सबसे अधिक बार आने वाले अक्षर की गिनती" को ट्रैक करने पर, "बदलने की आवश्यकता वाले अक्षरों की संख्या = विंडो का आकार − सबसे अधिक बार आने वाले अक्षर की गिनती" की गणना की जा सकती है। जब तक यह बदलाव संख्या `k` से कम या बराबर रहे, विंडो का विस्तार जारी रखने पर सबसे लंबी उपस्ट्रिंग प्राप्त होती है।

## विचार प्रक्रिया

1. **सभी उपस्ट्रिंग की ब्रूट-फोर्स खोज अक्षम है**: सभी उपस्ट्रिंग की गणना करने में O(n²) लगता है। चूँकि हम सतत अंतराल को संभाल रहे हैं, Sliding Window पैटर्न उपयुक्त है
2. **विंडो के भीतर बदलने की आवश्यकता वाले अक्षरों की संख्या ज्ञात करनी है**: विंडो के सभी अक्षरों को समान बनाने के लिए, सबसे अधिक बार आने वाले अक्षर के अलावा बाकी सभी को बदलना होगा। इसलिए, बदलने की आवश्यकता वाले अक्षरों की संख्या `विंडो का आकार − सबसे अधिक बार आने वाले अक्षर की गिनती` से प्राप्त होती है
3. **प्रत्येक अक्षर की गिनती को ट्रैक करने का तरीका**: बड़े अक्षर केवल 26 प्रकार के होते हैं, इसलिए आकार 26 की सरणी `count` से प्रत्येक अक्षर की गिनती प्रबंधित की जा सकती है। विंडो के विस्तार और संकुचन के अनुसार इंक्रीमेंट और डिक्रीमेंट किया जाता है
4. **सबसे अधिक बार आने वाले अक्षर की गिनती को कुशलतापूर्वक प्रबंधित करना**: दायाँ पॉइंटर आगे बढ़ाने पर, जोड़े गए अक्षर की गिनती और वर्तमान `maxFreq` की तुलना करके बड़े मान को `maxFreq` बनाया जाता है। बायाँ पॉइंटर आगे बढ़ाकर अक्षर हटाने पर भी `maxFreq` को कम नहीं किया जाता। इसका कारण यह है कि अधिकतम लंबाई ज्ञात करने की समस्या में, पहले प्राप्त `maxFreq` से छोटे मान में अपडेट करने पर भी अधिक लंबा परिणाम नहीं मिलता
5. **विंडो संकुचन की शर्त**: जब `विंडो का आकार − maxFreq > k` हो, तो बदलाव की संख्या `k` से अधिक है, इसलिए बायाँ पॉइंटर 1 आगे बढ़ाकर विंडो को संकुचित किया जाता है। यह शर्त पूरी न हो जाने तक यह प्रक्रिया दोहराई जाती है
6. **अधिकतम लंबाई का अपडेट**: जब भी विंडो मान्य (बदलाव संख्या ≤ k) हो, `right − left + 1` और वर्तमान `maxLen` की तुलना करके बड़े मान को `maxLen` के रूप में दर्ज किया जाता है

## पूर्वापेक्षित ज्ञान

### Sliding Window (स्लाइडिंग विंडो) क्या है

सरणी या स्ट्रिंग पर सतत अंतराल को दो पॉइंटर (left, right) से प्रबंधित करने की तकनीक है। right को आगे बढ़ाकर विंडो का विस्तार किया जाता है, और शर्त पूरी न होने पर left को आगे बढ़ाकर विंडो को संकुचित किया जाता है। प्रत्येक तत्व को अधिकतम 2 बार (जोड़ने और हटाने में 1-1 बार) ही प्रोसेस किया जाता है, इसलिए यह O(n) में कार्य करता है।

### अक्षरों की गिनती को सरणी से प्रबंधित करने की विधि

बड़े अक्षर `'A'` से `'Z'` तक 26 अक्षर होते हैं, इसलिए `int[26]` की सरणी से प्रत्येक अक्षर की गिनती प्रबंधित की जा सकती है। अक्षर से इंडेक्स में रूपांतरण `charAt() - 'A'` से किया जाता है।

```java
int[] count = new int[26];           // 26 अक्षरों की गिनती रखने वाली सरणी
count[s.charAt(i) - 'A']++;         // अक्षर s.charAt(i) की गिनती 1 बढ़ाएँ
count[s.charAt(i) - 'A']--;         // अक्षर s.charAt(i) की गिनती 1 घटाएँ
```

### maxFreq को कम न करने का कारण

`maxFreq` विंडो के भीतर सबसे अधिक बार आने वाले अक्षर की गिनती है। बायाँ पॉइंटर आगे बढ़ाकर अक्षर हटाने पर भी `maxFreq` की पुनर्गणना करके कम करने की आवश्यकता नहीं है। अधिकतम लंबाई ज्ञात करने की समस्या में, भले ही `maxFreq` पिछले अधिकतम मान से छोटा हो जाए, उस स्थिति में प्राप्त विंडो का आकार पिछली अधिकतम लंबाई से अधिक नहीं हो सकता। इसलिए, `maxFreq` को केवल बढ़ते क्रम (monotonically increasing) में प्रबंधित करने पर भी सही परिणाम प्राप्त होता है।

## जटिलता

| | मान |
|---|---|
| Time | O(n) — दायाँ पॉइंटर और बायाँ पॉइंटर प्रत्येक अधिकतम n बार ही आगे बढ़ते हैं |
| Space | O(1) — उपयोग की गई सरणी का आकार 26 पर निश्चित है और यह इनपुट के आकार पर निर्भर नहीं करता |

## कोड

```java
// इनपुट: बड़े अक्षरों की स्ट्रिंग s और पूर्णांक k (अधिकतम बदलाव संख्या)
// आउटपुट: अधिकतम k बार बदलाव से सभी अक्षरों को समान बना सकने वाली उपस्ट्रिंग की अधिकतम लंबाई int के रूप में लौटाएँ
public int characterReplacement(String s, int k) {
    // प्रत्येक अक्षर (A से Z) की गिनती प्रबंधित करने वाली सरणी। इंडेक्स 0 'A' और 25 'Z' के अनुरूप है
    int[] count = new int[26];
    // left: विंडो का बायाँ सिरा
    int left = 0;
    // maxFreq: विंडो के भीतर सबसे अधिक बार आने वाले अक्षर की गिनती (केवल बढ़ते क्रम में प्रबंधित)
    int maxFreq = 0;
    // maxLen: शर्त पूरी करने वाली उपस्ट्रिंग की अधिकतम लंबाई (अंत में यह मान लौटाया जाएगा)
    int maxLen = 0;

    // दायाँ पॉइंटर 1-1 करके आगे बढ़ाकर विंडो के दाएँ सिरे का विस्तार करें
    for (int right = 0; right < s.length(); right++) {
        // दाएँ सिरे पर जोड़े गए अक्षर की गिनती 1 बढ़ाएँ
        count[s.charAt(right) - 'A']++;

        // जोड़े गए अक्षर की गिनती और वर्तमान maxFreq की तुलना करके सबसे अधिक बार आने वाले अक्षर की गिनती अपडेट करें
        maxFreq = Math.max(maxFreq, count[s.charAt(right) - 'A']);

        // विंडो का आकार - maxFreq = बदलने की आवश्यकता वाले अक्षरों की संख्या। जब तक यह k से अधिक हो, बाएँ सिरे को संकुचित करें
        // ध्यान दें: यहाँ maxFreq की पुनर्गणना नहीं की जाती। कम करने पर भी अधिकतम लंबाई के अपडेट में कोई योगदान नहीं होता
        while (right - left + 1 - maxFreq > k) {
            // बाएँ सिरे के अक्षर की गिनती 1 घटाकर उसे विंडो से हटाएँ
            count[s.charAt(left) - 'A']--;
            left++;
        }

        // विंडो मान्य है (बदलाव संख्या ≤ k), इसलिए वर्तमान विंडो के आकार से अधिकतम लंबाई अपडेट करें
        maxLen = Math.max(maxLen, right - left + 1);
    }
    // for लूप समाप्त होने के बाद, अधिकतम k बार बदलाव से प्राप्त सबसे लंबी समान-अक्षर उपस्ट्रिंग की लंबाई लौटाएँ
    return maxLen;
}
```
