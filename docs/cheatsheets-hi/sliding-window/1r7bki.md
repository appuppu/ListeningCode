# Finding the Best Time to Buy and Sell a Stock — मूल्य सरणी से एक बार के लेन-देन में अधिकतम लाभ ज्ञात करना

## समस्या का सार

पूर्णांकों की एक सरणी `prices` दी गई है। प्रत्येक तत्व `prices[i]` दिन `i` के शेयर मूल्य को दर्शाता है। केवल एक बार "खरीदो → बेचो" की शर्त पर, प्राप्त होने वाला **अधिकतम लाभ** लौटाना है। यदि कोई लाभ नहीं होता तो `0` लौटाना है। खरीदने का दिन बेचने के दिन से पहले होना चाहिए।

## मूल विचार

सरणी को बाएँ से स्कैन करते हुए "अब तक का न्यूनतम मूल्य" दर्ज करते रहने पर, प्रत्येक दिन के मूल्य से न्यूनतम मूल्य घटाने मात्र से, उस दिन बेचने पर मिलने वाला अधिकतम लाभ O(1) में प्राप्त होता है। सभी दिनों में इस लाभ का अधिकतम मान ही उत्तर है।

## विचार प्रक्रिया

1. **लाभ "विक्रय मूल्य − क्रय मूल्य" से निर्धारित होता है**: किसी दिन बेचते समय लाभ अधिकतम करने के लिए क्रय मूल्य यथासंभव कम रखना चाहिए। अर्थात, बेचने के दिन से पहले के सभी दिनों में से न्यूनतम मूल्य पर खरीदना चाहिए
2. **प्रत्येक दिन के लिए "उससे पहले का न्यूनतम मूल्य" कुशलतापूर्वक ज्ञात करना है**: सरणी को बाएँ से स्कैन करते हुए, अब तक देखे गए मूल्यों का न्यूनतम मान एक चर `minPrice` में ट्रैक करना है। नया मूल्य देखने पर केवल `minPrice` अपडेट करना होता है, इसलिए अतिरिक्त सरणी की आवश्यकता नहीं है और O(1) स्थान पर्याप्त है
3. **प्रत्येक दिन का "बेचने पर मिलने वाला लाभ" गणना करना है**: स्कैन के दौरान प्रत्येक दिन `i` के लिए, `prices[i] - minPrice` उस दिन बेचने पर मिलने वाला अधिकतम लाभ है। इस मान की तुलना चर `maxProfit` से करके, यदि यह अधिक हो तो `maxProfit` अपडेट करना है
4. **minPrice के अपडेट और लाभ गणना के संबंध को व्यवस्थित करना**: यदि वर्तमान मूल्य `minPrice` से कम है, तो `minPrice` अपडेट करना है। उस दिन बेचने पर लाभ ऋणात्मक होगा इसलिए लाभ गणना आवश्यक नहीं है। यदि वर्तमान मूल्य `minPrice` के बराबर या अधिक है, तो लाभ गणना करके `maxProfit` अपडेट करना है
5. **लाभ न होने की स्थिति का प्रबंधन**: यदि शेयर मूल्य एकदिशीय घटता रहे, तो `maxProfit` प्रारंभिक मान `0` पर ही रहता है। बिना किसी शर्त जाँच के स्वाभाविक रूप से `0` लौटता है
6. **अंतिम रूप से क्या लौटाना है**: सरणी का एक बार स्कैन पूरा होने पर `maxProfit` का मान लौटाना है। यही एक बार के लेन-देन से प्राप्त अधिकतम लाभ है

## पूर्वापेक्षित ज्ञान

### Integer.MAX_VALUE क्या है

Java के `int` प्रकार का अधिकतम संभव मान (2,147,483,647)। न्यूनतम मान खोजने वाले एल्गोरिदम में प्रारंभिक मान के रूप में उपयोग किया जाता है। यह किसी भी शेयर मूल्य से बड़ा होने की गारंटी रखता है, इसलिए पहली तुलना में यह अवश्य वास्तविक शेयर मूल्य से प्रतिस्थापित हो जाता है।

```java
int minPrice = Integer.MAX_VALUE;  // न्यूनतम मान के प्रारंभिक मान के रूप में पर्याप्त बड़ा मान सेट करना
// यदि prices[0] उदाहरणस्वरूप 7 है, तो 7 < Integer.MAX_VALUE होने से minPrice 7 में अपडेट होता है
```

### Math.max क्या है

दो `int` मान लेकर बड़ा मान लौटाने वाली स्थैतिक विधि। अधिकतम मान की अपडेट प्रक्रिया को एक पंक्ति में लिखा जा सकता है।

```java
int a = 5;
int b = 3;
Math.max(a, b);  // → 5 लौटाता है

// अधिकतम लाभ अपडेट करने में उपयोग करना
maxProfit = Math.max(maxProfit, profit);  // यदि profit अधिक है तो maxProfit अपडेट होता है
```

### Running Minimum (स्कैन के दौरान न्यूनतम मान ट्रैकिंग) क्या है

सरणी को स्कैन करते हुए, अब तक देखे गए तत्वों का न्यूनतम मान एक चर में ट्रैक करने की तकनीक। प्रत्येक चरण में वर्तमान तत्व और चर की तुलना करके, छोटे मान से चर को अपडेट किया जाता है। इससे किसी भी स्थिति पर "उस स्थिति तक का न्यूनतम मान" O(1) में प्राप्त होता है।

```java
int minPrice = Integer.MAX_VALUE;
for (int price : prices) {
    if (price < minPrice) {
        minPrice = price;  // अब तक का न्यूनतम मूल्य अपडेट करना
    }
    // इस बिंदु पर minPrice, prices[0] से prices[वर्तमान] तक का न्यूनतम मान रखता है
}
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(1) — केवल 2 चर (minPrice, maxProfit) का उपयोग होता है |

## कोड

```java
// इनपुट: पूर्णांक सरणी prices (प्रत्येक तत्व प्रतिदिन का शेयर मूल्य है)
// आउटपुट: एक बार के लेन-देन से प्राप्त अधिकतम लाभ int के रूप में लौटाना है। लाभ न होने पर 0 लौटाना है
public int maxProfit(int[] prices) {
    // अब तक के न्यूनतम मूल्य को ट्रैक करने वाला चर। Integer.MAX_VALUE से आरंभ करने पर, पहले मूल्य की तुलना में अवश्य वास्तविक शेयर मूल्य में अपडेट होता है
    int minPrice = Integer.MAX_VALUE;
    // अब तक के अधिकतम लाभ को ट्रैक करने वाला चर। 0 से आरंभ करने पर, लाभ न होने की स्थिति में स्वाभाविक रूप से 0 लौटता है
    int maxProfit = 0;

    // for-each लूप से सरणी को आरंभ से अंत तक एक-एक करके स्कैन करना
    for (int price : prices) {
        if (price < minPrice) {
            // यदि वर्तमान मूल्य न्यूनतम मूल्य से कम है तो न्यूनतम मूल्य अपडेट करना
            // यह दिन न्यूनतम मूल्य का अपडेट दिन है, इसलिए इस दिन बेचने पर लाभ नहीं होता (लाभ ऋणात्मक होगा)। अतः लाभ गणना छोड़ी जाती है
            minPrice = price;
        } else {
            // न्यूनतम मूल्य वाले दिन खरीदकर आज बेचने पर मिलने वाले लाभ की गणना करना
            int profit = price - minPrice;
            // यदि लाभ अब तक के अधिकतम से अधिक है तो अधिकतम लाभ अपडेट करना
            maxProfit = Math.max(maxProfit, profit);
        }
    }
    // लूप समाप्ति पर maxProfit संपूर्ण सरणी में अधिकतम लाभ है
    return maxProfit;
}
```
