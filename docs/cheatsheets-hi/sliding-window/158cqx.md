# Checking if a String Contains a Permutation of Another — जाँचना कि एक स्ट्रिंग में दूसरी स्ट्रिंग का क्रमपरिवर्तन है या नहीं

## समस्या का सार

दो स्ट्रिंग `s1` और `s2` दी गई हैं। हमें यह जाँचना है कि `s2` के अंदर `s1` का एनाग्राम (अक्षरों का पुनर्व्यवस्थापन) **सतत उपस्ट्रिंग** के रूप में मौजूद है या नहीं। यदि मौजूद है तो `true` लौटाना है, अन्यथा `false` लौटाना है।

## मूल विचार

`s1` का क्रमपरिवर्तन `s2` में शामिल होने का अर्थ यह है कि `s2` के अंदर `s1` के समान लंबाई और समान अक्षर आवृत्ति वाली एक उपस्ट्रिंग मौजूद है। निश्चित लंबाई के स्लाइडिंग विंडो से `s2` को स्कैन करके और 26 अक्षरों की आवृत्ति मिलान संख्या को अंतर-अद्यतन (差分更新) करके, प्रत्येक स्लाइड को O(1) में जाँचा जा सकता है।

## विचार प्रक्रिया

1. **क्रमपरिवर्तन की शर्त को पुनर्व्याख्यायित करना**: `s1` का क्रमपरिवर्तन `s2` की उपस्ट्रिंग के रूप में मौजूद होने का अर्थ यह है कि `s2` के अंदर लंबाई `m` (= `s1` की लंबाई) की एक ऐसी उपस्ट्रिंग मौजूद है जिसमें प्रत्येक अक्षर की उपस्थिति संख्या `s1` से पूरी तरह मेल खाती है
2. **निश्चित लंबाई की विंडो से स्कैन करना**: उपस्ट्रिंग की लंबाई हमेशा `m` होती है, इसलिए `s2` पर लंबाई `m` की निश्चित आकार की विंडो रखकर, एक-एक अक्षर स्लाइड करते हुए अक्षर आवृत्ति की तुलना करनी होगी
3. **आवृत्ति सरणी से अक्षरों की उपस्थिति संख्या प्रबंधित करना**: अंग्रेज़ी के छोटे अक्षर 26 प्रकार के होते हैं, इसलिए आकार 26 की दो पूर्णांक सरणियों (`s1F` और `winF`) से `s1` और विंडो के अंदर की अक्षर आवृत्ति को क्रमशः प्रबंधित किया जाता है। सरणी का प्रत्येक इंडेक्स प्रत्येक अक्षर से संबंधित होता है
4. **हर बार 26 तत्वों की तुलना करना अनावश्यक है**: विंडो स्लाइड करने पर जो अक्षर बदलते हैं वे अधिकतम दो ही होते हैं — "नया प्रवेश करने वाला 1 अक्षर" और "बाहर जाने वाला 1 अक्षर"। हर बार 26 तत्वों की तुलना करने के बजाय, "26 अक्षरों में से कितने अक्षरों की आवृत्ति मेल खाती है" इसे `matches` काउंटर से ट्रैक करके, केवल अंतर को अद्यतन किया जाता है
5. **matches काउंटर का अद्यतन नियम**: किसी अक्षर की आवृत्ति बदलते समय, यदि परिवर्तन से पहले आवृत्ति मेल खाती थी तो `matches` को 1 घटाया जाता है, और यदि परिवर्तन के बाद आवृत्ति मेल खाती है तो `matches` को 1 बढ़ाया जाता है। "परिवर्तन-पूर्व जाँच → मान परिवर्तन → परिवर्तन-पश्चात जाँच" इस क्रम का पालन करने से काउंटर की संगतता बनी रहती है
6. **निर्णय शर्त**: जैसे ही `matches` 26 हो जाता है, इसका अर्थ है कि सभी 26 अक्षरों की आवृत्ति मेल खा रही है, इसलिए `true` लौटाया जाता है। यदि `s2` के अंत तक स्लाइड करने पर भी 26 नहीं होता, तो `false` लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### स्लाइडिंग विंडो क्या है

यह सरणी या स्ट्रिंग पर सतत उपखंड को, बाएँ और दाएँ सिरे को आगे बढ़ाते हुए स्कैन करने की विधि है। निश्चित लंबाई की विंडो के मामले में, दाएँ सिरे को 1 आगे बढ़ाने के साथ-साथ बाएँ सिरे को भी 1 आगे बढ़ाकर, विंडो का आकार स्थिर रखा जाता है।

```java
// s2 पर लंबाई m की निश्चित विंडो को स्लाइड करने का मूल रूप
for (int i = m; i < n; i++) {
    char entering = s2.charAt(i);       // विंडो में नया प्रवेश करने वाला अक्षर (दायाँ सिरा)
    char leaving = s2.charAt(i - m);    // विंडो से बाहर जाने वाला अक्षर (बायाँ सिरा)
}
```

### आवृत्ति सरणी क्या है

प्रत्येक अक्षर की उपस्थिति संख्या को संग्रहीत करने वाली आकार 26 की पूर्णांक सरणी है। `'a'` को इंडेक्स 0 और `'z'` को इंडेक्स 25 से संबद्ध किया जाता है। `charAt(i) - 'a'` से अक्षर को इंडेक्स में बदला जाता है।

```java
int[] freq = new int[26];              // सभी तत्व 0 से आरंभ होते हैं
freq[s.charAt(i) - 'a']++;            // अक्षर की उपस्थिति संख्या 1 बढ़ाना
freq[s.charAt(i) - 'a']--;            // अक्षर की उपस्थिति संख्या 1 घटाना
```

### matches काउंटर क्या है

यह एक काउंटर है जो दो आवृत्ति सरणियों के बीच, समान इंडेक्स पर मान मेल खाने की संख्या को ट्रैक करता है। यदि सभी 26 मेल खाते हैं तो `matches == 26` होता है, जिसका अर्थ है कि दोनों स्ट्रिंग की अक्षर संरचना समान है।

```java
int matches = 0;
for (int i = 0; i < 26; i++) {
    if (s1F[i] == winF[i]) matches++;  // मेल खाने वाले अक्षरों की संख्या गिनना
}
// matches == 26 होने पर सभी अक्षरों की आवृत्ति मेल खाती है
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n) — `s2` को केवल एक बार स्कैन करना पड़ता है (प्रत्येक स्लाइड O(1) है) |
| Space | O(1) — आवृत्ति सरणी का आकार हमेशा 26 होता है, जो इनपुट आकार पर निर्भर नहीं करता |

## कोड

```java
// इनपुट: स्ट्रिंग s1 (खोजे जाने वाला क्रमपरिवर्तन) और स्ट्रिंग s2 (जिसमें खोजना है)
// आउटपुट: यदि s2 में s1 का क्रमपरिवर्तन उपस्ट्रिंग के रूप में है तो true, अन्यथा false
boolean checkInclusion(String s1, String s2) {
    int m = s1.length();
    int n = s2.length();

    // यदि s1 की लंबाई s2 से अधिक है, तो क्रमपरिवर्तन शामिल नहीं हो सकता इसलिए तुरंत false लौटाना
    if (m > n) return false;

    // s1 की अक्षर आवृत्ति और विंडो की अक्षर आवृत्ति संग्रहीत करने के लिए आकार 26 की सरणी
    int[] s1F = new int[26];
    int[] winF = new int[26];

    // पहली विंडो (आरंभिक m अक्षर) की आवृत्ति की गणना करना। s1 और s2 के पहले m अक्षरों को एक साथ गिनना
    for (int i = 0; i < m; i++) {
        s1F[s1.charAt(i) - 'a']++;
        winF[s2.charAt(i) - 'a']++;
    }

    // 26 अक्षरों में से आवृत्ति मेल खाने वाले अक्षरों की संख्या गिनना (आरंभिक matches की गणना)
    int matches = 0;
    for (int i = 0; i < 26; i++) {
        if (s1F[i] == winF[i]) matches++;
    }

    // यदि पहली विंडो में ही सभी 26 अक्षरों की आवृत्ति मेल खाती है तो true लौटाना
    if (matches == 26) return true;

    // विंडो को एक-एक अक्षर दाईं ओर स्लाइड करना (i विंडो के दाएँ सिरे की अगली स्थिति है)
    for (int i = m; i < n; i++) {
        // --- विंडो में नया प्रवेश करने वाले अक्षर (दायाँ सिरा) की प्रक्रिया ---
        int idx = s2.charAt(i) - 'a';
        // ध्यान दें: "परिवर्तन-पूर्व जाँच → मान परिवर्तन → परिवर्तन-पश्चात जाँच" के क्रम का पालन अवश्य करें
        if (winF[idx] == s1F[idx]) matches--;   // यदि परिवर्तन से पहले मेल खाता था तो matches घटाना
        winF[idx]++;                              // विंडो में प्रवेश करने से आवृत्ति 1 बढ़ाना
        if (winF[idx] == s1F[idx]) matches++;   // यदि परिवर्तन के बाद मेल खाता है तो matches बढ़ाना

        // --- विंडो से बाहर जाने वाले अक्षर (बायाँ सिरा) की प्रक्रिया ---
        idx = s2.charAt(i - m) - 'a';
        // प्रवेश करने वाले अक्षर के समान प्रक्रिया: परिवर्तन-पूर्व जाँच → मान परिवर्तन → परिवर्तन-पश्चात जाँच
        if (winF[idx] == s1F[idx]) matches--;   // यदि परिवर्तन से पहले मेल खाता था तो matches घटाना
        winF[idx]--;                              // विंडो से बाहर जाने से आवृत्ति 1 घटाना
        if (winF[idx] == s1F[idx]) matches++;   // यदि परिवर्तन के बाद मेल खाता है तो matches बढ़ाना

        // यदि सभी 26 अक्षरों की आवृत्ति मेल खाती है तो क्रमपरिवर्तन मिल गया इसलिए true लौटाना
        if (matches == 26) return true;
    }

    // s2 के अंत तक स्लाइड करने पर भी matches==26 नहीं हुआ इसलिए false लौटाना
    return false;
}
```
