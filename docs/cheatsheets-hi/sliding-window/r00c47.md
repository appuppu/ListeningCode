# Finding the Maximum in Each Sliding Window — स्लाइडिंग विंडो में अधिकतम मान ज्ञात करना

## समस्या का सार

पूर्णांकों की एक सरणी `nums` और विंडो का आकार `k` दिया गया है। आकार `k` की विंडो को सरणी के बाएँ छोर से दाएँ छोर तक एक-एक करके स्लाइड करना है, और प्रत्येक स्थिति पर विंडो के भीतर **अधिकतम मान** ज्ञात करना है। सभी अधिकतम मानों को एक सरणी में लौटाना है।

## मूल विचार

Deque (डबल-एंडेड कतार) में इंडेक्स को "मान एकदिशीय घटते क्रम में" रखा जाए, तो Deque का अग्र भाग सदैव विंडो के भीतर अधिकतम मान को इंगित करता है। जब कोई नया तत्व आता है तो पिछले छोर से अपने से छोटे या बराबर तत्वों को हटाया जाता है, और यदि अग्र भाग विंडो से बाहर हो गया हो तो उसे हटाया जाता है। इस प्रकार प्रत्येक चरण में O(1) की परिशोधित लागत में अधिकतम मान प्राप्त किया जा सकता है।

## विचार प्रक्रिया

1. **प्रत्येक विंडो का अधिकतम मान आवश्यक है**: विंडो को एक स्थान स्लाइड करने पर, जोड़ा जाने वाला तत्व और हटाया जाने वाला तत्व एक-एक होता है। यदि हर बार पूरी विंडो को स्कैन करके O(k) में अधिकतम मान ज्ञात किया जाए तो कुल O(nk) समय लगेगा, इसलिए अधिकतम मान को कुशलतापूर्वक प्रबंधित करने वाली डेटा संरचना की आवश्यकता है
2. **केवल अधिकतम मान के उम्मीदवारों को रखना पर्याप्त है**: यदि विंडो में तत्व A और B हैं, A, B से बाईं ओर है, और A का मान B के बराबर या उससे कम है, तो A भविष्य में किसी भी विंडो में अधिकतम मान नहीं बन सकता। B दाईं ओर है इसलिए वह A से पहले विंडो से बाहर नहीं जाएगा। अतः A को उम्मीदवारों से हटाया जा सकता है
3. **एकदिशीय घटते Deque से उम्मीदवारों का प्रबंधन करना**: यदि उम्मीदवारों को मान के घटते क्रम में रखा जाए, तो अग्र भाग सदैव अधिकतम मान होगा। नया तत्व जोड़ते समय, पिछले छोर से अपने से छोटे या बराबर सभी तत्वों को हटाने पर एकदिशीय घटते क्रम का गुण बना रहता है। इस संक्रिया के लिए Deque (डबल-एंडेड कतार) उपयुक्त है
4. **Deque में इंडेक्स संग्रहित करना**: किसी तत्व के विंडो से बाहर होने का निर्धारण करने के लिए स्थिति की जानकारी आवश्यक है, इसलिए Deque में मान नहीं बल्कि इंडेक्स संग्रहित किया जाता है। मान को `nums[index]` से प्राप्त किया जा सकता है
5. **अग्र भाग का विंडो-बाहर जाँच**: प्रत्येक चरण में, यदि Deque के अग्र भाग का इंडेक्स वर्तमान विंडो के बाएँ छोर `i - k + 1` से छोटा है, तो वह तत्व विंडो से बाहर हो चुका है इसलिए उसे अग्र भाग से हटाया जाता है
6. **परिणाम दर्ज करने का समय**: जब इंडेक्स `i`, `k - 1` या उससे अधिक हो जाता है, तब विंडो पूर्ण होती है, इसलिए Deque के अग्र भाग द्वारा इंगित मान को परिणाम सरणी में दर्ज किया जाता है

## पूर्वापेक्षित ज्ञान

### ArrayDeque (डबल-एंडेड कतार) क्या है

यह एक ऐसी डेटा संरचना है जिसमें अग्र भाग और पिछले छोर दोनों से O(1) में तत्व जोड़ना, प्राप्त करना और हटाना संभव है। यह स्टैक और कतार दोनों की कार्यक्षमता रखती है।

```java
ArrayDeque<Integer> deque = new ArrayDeque<>();  // खाली Deque बनाना
deque.offerLast(5);       // पिछले छोर पर 5 जोड़ना
deque.offerLast(3);       // पिछले छोर पर 3 जोड़ना → Deque की सामग्री: [5, 3]
deque.peekFirst();        // अग्र भाग का तत्व प्राप्त करना (हटाना नहीं) → 5
deque.peekLast();         // पिछले छोर का तत्व प्राप्त करना (हटाना नहीं) → 3
deque.pollFirst();        // अग्र भाग का तत्व प्राप्त करके हटाना → 5
deque.pollLast();         // पिछले छोर का तत्व प्राप्त करके हटाना → 3
deque.isEmpty();          // Deque खाली है या नहीं boolean में लौटाना → true
```

### एकदिशीय घटता Deque (Monotonic Deque) क्या है

यह वह Deque है जिसमें तत्व अग्र भाग से पिछले छोर की ओर सदैव घटते क्रम में (या बराबर नहीं) रहते हैं। नया तत्व जोड़ते समय, पिछले छोर से अपने से छोटे या बराबर सभी तत्वों को हटाकर एकदिशीय घटते क्रम को बनाए रखा जाता है।
उदाहरण: Deque=[7, 5, 3] में 6 जोड़ना → 5 और 3 को हटाना → Deque=[7, 6]। अग्र भाग सदैव अधिकतम मान को इंगित करता है।

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n) — प्रत्येक तत्व Deque में अधिकतम 1 बार जोड़ा जाता है और अधिकतम 1 बार हटाया जाता है, इसलिए कुल O(n) होता है |
| Space | O(k) — Deque में विंडो आकार k से अधिक तत्व नहीं रखे जाते |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums और पूर्णांक k (विंडो का आकार)
// आउटपुट: प्रत्येक विंडो स्थिति पर अधिकतम मान संग्रहित int[] लौटाना। तत्वों की संख्या n - k + 1 होती है
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    // प्रत्येक विंडो का अधिकतम मान संग्रहित करने वाली परिणाम सरणी। विंडो n - k + 1 होती हैं
    int[] result = new int[n - k + 1];
    // अधिकतम मान उम्मीदवारों के इंडेक्स को एकदिशीय घटते क्रम में रखने वाला Deque
    // Deque में "विंडो के भीतर अधिकतम मान बनने की संभावना वाले इंडेक्स" को, संबंधित मान एकदिशीय घटते क्रम में रखा जाता है
    ArrayDeque<Integer> deque = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // अग्र भाग का इंडेक्स विंडो के बाएँ छोर i - k + 1 से छोटा है तो वह विंडो से बाहर है इसलिए हटाना
        // विंडो एक-एक करके स्लाइड होती है, इसलिए विंडो से बाहर होने वाला तत्व प्रत्येक चरण में अधिकतम 1 होता है
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }

        // पिछले छोर से वर्तमान तत्व nums[i] से छोटे या बराबर सभी उम्मीदवारों को हटाकर एकदिशीय घटता क्रम बनाए रखना
        // ये तत्व nums[i] के रहते अधिकतम मान नहीं बन सकते, इसलिए उम्मीदवारों से हटाया जा सकता है
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }

        // वर्तमान इंडेक्स को Deque के पिछले छोर पर जोड़ना
        // ऊपर के while में अपने से छोटे या बराबर तत्व हटाए जा चुके हैं, इसलिए जोड़ने के बाद भी Deque एकदिशीय घटता रहता है
        deque.offerLast(i);

        // जब i >= k - 1 हो, तब विंडो में k तत्व पूर्ण हो चुके हैं
        // Deque का अग्र भाग वर्तमान विंडो के भीतर अधिकतम मान का इंडेक्स इंगित करता है
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    // सभी विंडो के अधिकतम मान दर्ज हो चुके result को लौटाना
    return result;
}
```
