# Finding the Median of Two Sorted Arrays — दो सॉर्ट की गई सरणियों को मिलाने पर मध्यिका ज्ञात करना

## समस्या का सार

दो सॉर्ट की गई पूर्णांक सरणियाँ `n1` और `n2` दी गई हैं। दोनों सरणियों को मिलाने पर प्राप्त **मध्यिका** ज्ञात करनी है। समाधान को कुल तत्वों की संख्या के सापेक्ष लघुगणकीय समय में कार्य करना आवश्यक है।

## मूल विचार

दो सॉर्ट की गई सरणियों की मध्यिका ज्ञात करना, "बाएँ आधे भाग" और "दाएँ आधे भाग" में सही ढंग से विभाजित करने वाली सीमा खोजने के बराबर है। छोटी सरणी पर बाइनरी सर्च करके विभाजन स्थिति निर्धारित करने पर, दूसरी सरणी की विभाजन स्थिति स्वतः निर्धारित हो जाती है।

## विचार प्रक्रिया

1. **मध्यिका "बाएँ भाग के अधिकतम मान" और "दाएँ भाग के न्यूनतम मान" से निर्धारित होती है**: मिली हुई सरणी को सॉर्ट क्रम बनाए रखते हुए बाएँ और दाएँ दो बराबर भागों में विभाजित कर सकें, तो मध्यिका बाएँ भाग का अधिकतम मान है (विषम संख्या में), या बाएँ भाग के अधिकतम मान और दाएँ भाग के न्यूनतम मान का औसत है (सम संख्या में)। अर्थात, सभी तत्वों को सॉर्ट किए बिना भी, केवल सही विभाजन स्थिति ढूँढनी होती है
2. **विभाजन स्थिति एक सरणी में निर्धारित करने पर दूसरी स्वतः निर्धारित हो जाती है**: बाएँ भाग में कुल `half = (m + n + 1) / 2` तत्व रखने का निर्णय लेने पर, यदि सरणी `n1` से `cut1` तत्व लिए जाएँ, तो सरणी `n2` से `cut2 = half - cut1` तत्व लेने आवश्यक हैं। अर्थात, केवल `cut1` खोजना पर्याप्त है
3. **सही विभाजन की शर्त "क्रॉस तुलना" से जाँची जा सकती है**: सही विभाजन का अर्थ है कि बाएँ भाग के सभी तत्व दाएँ भाग के सभी तत्वों से छोटे या बराबर हैं। प्रत्येक सरणी स्वयं सॉर्ट है, इसलिए केवल क्रॉस करने वाले भाग की जाँच करनी होती है। विशेष रूप से, `n1` के बाएँ भाग का अंतिम तत्व `l1` ≤ `n2` के दाएँ भाग का पहला तत्व `r2`, और `n2` के बाएँ भाग का अंतिम तत्व `l2` ≤ `n1` के दाएँ भाग का पहला तत्व `r1` — यह सत्य हो तो विभाजन सही है
4. **बाइनरी सर्च से `cut1` को कुशलतापूर्वक खोजना**: `cut1` की सीमा `0` से `m` तक है। यदि `l1 > r2` है तो `n1` से अधिक तत्व लिए गए हैं, इसलिए `cut1` घटाना है; यदि `l2 > r1` है तो `n1` से कम तत्व लिए गए हैं, इसलिए `cut1` बढ़ाना है। इस निर्णय से बाइनरी सर्च सिद्ध होती है
5. **छोटी सरणी पर खोज करने का कारण**: बाइनरी सर्च की सीमा `0` से `m` (सरणी की लंबाई) तक है, इसलिए छोटी सरणी चुनने पर खोज सीमा छोटी हो जाती है और समय जटिलता `O(log(min(m, n)))` होती है
6. **सीमा के प्रबंधन में प्रहरी मानों का उपयोग**: `cut1 = 0` (n1 से एक भी तत्व न लेना) या `cut1 = m` (n1 के सभी तत्व लेना) के समय, अस्तित्वहीन तत्व तक पहुँच होगी। `Integer.MIN_VALUE` और `Integer.MAX_VALUE` को प्रहरी मानों के रूप में उपयोग करने पर, तुलना शर्तें सीमा स्थितियों में भी सही ढंग से कार्य करती हैं

## पूर्वापेक्षित ज्ञान

### मध्यिका (Median) क्या है

सॉर्ट की गई संख्या श्रृंखला में मध्य स्थान पर स्थित मान। यदि तत्वों की संख्या विषम है तो मध्य का एक मान, सम है तो मध्य के दो मानों का औसत लिया जाता है।

```java
// विषम संख्या: [1, 3, 5] → मध्यिका 3 है
// सम संख्या: [1, 3, 5, 7] → मध्यिका (3 + 5) / 2.0 = 4.0 है
```

### बाइनरी सर्च (Binary Search) क्या है

सॉर्ट किए गए डेटा पर, खोज सीमा को प्रत्येक बार आधा करके O(log n) में लक्ष्य मान ढूँढने की विधि। `lo` और `hi` से खोज सीमा का प्रबंधन किया जाता है और मध्य मान के आधार पर सीमा संकुचित की जाती है।

```java
int lo = 0, hi = n;
while (lo <= hi) {
    int mid = (lo + hi) / 2;       // खोज सीमा का मध्य बिंदु गणना करना
    if (条件を満たす) { /* उत्तर */ }
    else if (mid बहुत बड़ा है) { hi = mid - 1; }  // बाएँ आधे भाग में संकुचित करना
    else { lo = mid + 1; }                         // दाएँ आधे भाग में संकुचित करना
}
```

### प्रहरी मान (Sentinel Value) क्या है

सरणी की सीमा से बाहर पहुँच से बचने के लिए उपयोग किया जाने वाला विशेष मान। `Integer.MIN_VALUE` (पूर्णांक का न्यूनतम मान) और `Integer.MAX_VALUE` (पूर्णांक का अधिकतम मान) का उपयोग करके, सीमा स्थितियों में भी तुलना शर्तें विफल नहीं होतीं।

```java
Integer.MIN_VALUE;  // -2147483648 — किसी भी तत्व से छोटे मान के रूप में उपयोग किया जाता है
Integer.MAX_VALUE;  //  2147483647 — किसी भी तत्व से बड़े मान के रूप में उपयोग किया जाता है
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(log(min(m, n))) — छोटी सरणी पर बाइनरी सर्च किया जाता है |
| Space | O(1) — केवल चरों का उपयोग किया जाता है, कोई अतिरिक्त डेटा संरचना नहीं बनाई जाती |

## कोड

```java
// इनपुट: दो सॉर्ट की गई पूर्णांक सरणियाँ n1 और n2
// आउटपुट: दोनों सरणियों को मिलाने पर प्राप्त मध्यिका double के रूप में लौटाना
public double findMedian(int[] n1, int[] n2) {
    // छोटी सरणी पर बाइनरी सर्च करने के लिए, यदि n1 लंबी है तो अदला-बदली करके पुनरावर्ती कॉल करना
    // इससे खोज सीमा न्यूनतम होती है और O(log(min(m, n))) प्राप्त होता है
    if (n1.length > n2.length)
        return findMedian(n2, n1);

    int m = n1.length, n = n2.length;
    // बाएँ भाग में रखे जाने वाले तत्वों की संख्या। +1 करने से विषम संख्या में बायाँ भाग 1 अधिक होता है,
    // जिससे बाएँ भाग का अधिकतम मान सीधे मध्यिका बन जाता है
    int half = (m + n + 1) / 2;
    // cut1 की खोज सीमा: 0 (n1 से एक भी न लेना) से m (n1 के सभी तत्व लेना) तक
    int lo = 0, hi = m;

    while (lo <= hi) {
        // n1 से बाएँ भाग में रखने वाले तत्वों की संख्या बाइनरी सर्च के मध्य बिंदु से निर्धारित करना
        int cut1 = (lo + hi) / 2;
        // n2 से बाएँ भाग में रखने वाले तत्वों की संख्या (बाएँ भाग का कुल half होने के लिए स्वतः निर्धारित)
        int cut2 = half - cut1;

        // n1 के बाएँ भाग का अंतिम तत्व (cut1=0 होने पर बायाँ भाग खाली है,
        // इसलिए किसी भी तत्व से छोटा प्रहरी मान उपयोग करके तुलना शर्त सदैव सत्य रखना)
        int l1 = cut1 == 0 ?
            Integer.MIN_VALUE :
            n1[cut1 - 1];
        // n2 के बाएँ भाग का अंतिम तत्व (cut2=0 होने पर प्रहरी मान उपयोग करना)
        int l2 = cut2 == 0 ?
            Integer.MIN_VALUE :
            n2[cut2 - 1];
        // n1 के दाएँ भाग का पहला तत्व (cut1=m होने पर दायाँ भाग खाली है,
        // इसलिए किसी भी तत्व से बड़ा प्रहरी मान उपयोग करके तुलना शर्त सदैव सत्य रखना)
        int r1 = cut1 == m ?
            Integer.MAX_VALUE :
            n1[cut1];
        // n2 के दाएँ भाग का पहला तत्व (cut2=n होने पर प्रहरी मान उपयोग करना)
        int r2 = cut2 == n ?
            Integer.MAX_VALUE :
            n2[cut2];

        // क्रॉस तुलना: बाएँ भाग के सभी तत्व ≤ दाएँ भाग के सभी तत्व हों तो सही विभाजन है
        if (l1 <= r2 && l2 <= r1) {
            // सही विभाजन मिल गया
            if ((m + n) % 2 == 1)
                // विषम संख्या: बाएँ भाग का अधिकतम मान सीधे मध्यिका है
                return Math.max(l1, l2);
            // सम संख्या: बाएँ भाग के अधिकतम मान और दाएँ भाग के न्यूनतम मान का औसत मध्यिका है
            return (Math.max(l1, l2)
                + Math.min(r1, r2))
                / 2.0;
        } else if (l1 > r2) {
            // n1 के बाएँ भाग का अंतिम तत्व n2 के दाएँ भाग के पहले तत्व से बड़ा है → n1 से अधिक लिए गए → cut1 घटाना
            hi = cut1 - 1;
        } else {
            // l2 > r1: n1 से कम लिए गए → cut1 बढ़ाना
            lo = cut1 + 1;
        }
    }
    // समस्या की बाधाओं के अनुसार सही विभाजन अवश्य मिलता है, इसलिए यहाँ कभी नहीं पहुँचा जाता
    return -1;
}
```
