# Designing a Time-Based Key-Value Store — टाइमस्टैम्प-युक्त की-वैल्यू स्टोर डिज़ाइन करना

## समस्या का सार

`set(key, value, timestamp)` से की और वैल्यू को टाइमस्टैम्प के साथ सेव करना है, और `get(key, timestamp)` से निर्दिष्ट टाइमस्टैम्प **के बराबर या उससे छोटे** सबसे बड़े टाइमस्टैम्प से जुड़ी वैल्यू को लौटाने वाला डेटा स्ट्रक्चर डिज़ाइन करना है। यदि कोई उपयुक्त टाइमस्टैम्प मौजूद नहीं है, तो खाली स्ट्रिंग लौटाना है।

## मूल विचार

यदि प्रत्येक की के लिए टाइमस्टैम्प को क्रमबद्ध (sorted) रूप में रखा जाए, तो "निर्दिष्ट मान के बराबर या उससे छोटा सबसे बड़ा मान" लघुगणकीय समय में खोजा जा सकता है। Java का TreeMap इस ऑपरेशन को `floorEntry` मेथड के रूप में बिल्ट-इन प्रदान करता है।

## विचार प्रक्रिया

1. **ऑपरेशन को समझना**: `set` एक ऐसा ऑपरेशन है जो की में टाइमस्टैम्प और वैल्यू का पेयर जोड़ता है, और `get` एक ऐसा ऑपरेशन है जो "निर्दिष्ट टाइमस्टैम्प के बराबर या उससे छोटे सबसे बड़े टाइमस्टैम्प" से जुड़ी वैल्यू लौटाता है। `get` का सार "किसी मान के बराबर या उससे छोटा सबसे बड़ा मान खोजना" एक सर्च समस्या है
2. **प्रत्येक की के लिए टाइमस्टैम्प प्रबंधित करना**: अलग-अलग कीज़ एक-दूसरे से स्वतंत्र हैं, इसलिए बाहरी HashMap से प्रत्येक की को अलग करना है, और प्रत्येक की के लिए टाइमस्टैम्प→वैल्यू का मैपिंग रखने वाला स्ट्रक्चर बनाना है
3. **"बराबर या छोटे में सबसे बड़ा" कुशलता से निकालने के लिए डेटा स्ट्रक्चर चुनना**: क्रमबद्ध डेटा में "किसी मान के बराबर या उससे छोटा सबसे बड़ा" निकालने के लिए बाइनरी सर्च आवश्यक है। TreeMap (रेड-ब्लैक ट्री आधारित बैलेंस्ड बाइनरी सर्च ट्री) कीज़ को क्रमबद्ध रूप में रखता है, और `floorEntry(key)` "निर्दिष्ट की के बराबर या उससे छोटी सबसे बड़ी एंट्री" को O(log n) में लौटाता है
4. **set का कार्यान्वयन तय करना**: यदि बाहरी HashMap में की पंजीकृत नहीं है तो नया TreeMap बनाना है, और TreeMap में टाइमस्टैम्प को की और वैल्यू को बैल्यू के रूप में `put` करना है। `computeIfAbsent` का उपयोग करने से अस्तित्व की जाँच और निर्माण एक ही पंक्ति में लिखा जा सकता है
5. **get का कार्यान्वयन तय करना**: पहले HashMap में की मौजूद है या नहीं यह जाँचना है, और यदि मौजूद नहीं है तो खाली स्ट्रिंग लौटाना है। यदि मौजूद है तो TreeMap के `floorEntry(timestamp)` को कॉल करना है, और यदि परिणाम null नहीं है तो उसकी वैल्यू लौटानी है, अन्यथा खाली स्ट्रिंग लौटानी है
6. **एज केस को संभालना**: दो स्थितियों में खाली स्ट्रिंग लौटानी है — जब की स्वयं पंजीकृत नहीं है, और जब की मौजूद है लेकिन सभी टाइमस्टैम्प निर्दिष्ट मान से बड़े हैं

## पूर्वापेक्षित ज्ञान

### HashMap क्या है

HashMap एक डेटा स्ट्रक्चर है जो की और वैल्यू के पेयर को सेव करता है। की निर्दिष्ट करके वैल्यू की खोज और प्राप्ति O(1) में की जा सकती है।

```java
HashMap<String, TreeMap<Integer, String>> map = new HashMap<>();  // खाली HashMap बनाना
map.containsKey("foo");    // की "foo" मौजूद है या नहीं, boolean में लौटाना
map.get("foo");            // की "foo" से जुड़ी वैल्यू को लौटाना
```

### computeIfAbsent क्या है

computeIfAbsent HashMap का एक मेथड है। यदि की पंजीकृत नहीं है तो ही लैम्ब्डा एक्सप्रेशन से वैल्यू बनाकर पंजीकृत करता है, और उस वैल्यू को लौटाता है। यदि की पहले से मौजूद है तो मौजूदा वैल्यू को लौटाता है। अस्तित्व की जाँच→निर्माण→पंजीकरण को एक ही पंक्ति में लिखा जा सकता है।

```java
map.computeIfAbsent("foo", k -> new TreeMap<>());
// "foo" पंजीकृत नहीं है → नया TreeMap बनाकर पंजीकृत करता है, और उस TreeMap को लौटाता है
// "foo" पहले से पंजीकृत है → मौजूदा TreeMap को लौटाता है
```

### TreeMap क्या है

TreeMap एक बैलेंस्ड बाइनरी सर्च ट्री आधारित Map है जो कीज़ को क्रमबद्ध (आरोही) क्रम में रखता है। सामान्य HashMap से भिन्न, यह कीज़ के बड़े-छोटे संबंध पर आधारित सर्च ऑपरेशन प्रदान करता है। `put` और `get` O(log n) में काम करते हैं।

```java
TreeMap<Integer, String> tree = new TreeMap<>();  // खाली TreeMap बनाना
tree.put(1, "one");        // टाइमस्टैम्प 1 पर "one" को स्टोर करना
tree.put(3, "three");      // टाइमस्टैम्प 3 पर "three" को स्टोर करना
tree.put(5, "five");       // टाइमस्टैम्प 5 पर "five" को स्टोर करना
```

### floorEntry क्या है

floorEntry TreeMap का एक मेथड है। यह निर्दिष्ट की **के बराबर या उससे छोटी** सबसे बड़ी की से जुड़ी एंट्री (की और वैल्यू का पेयर) लौटाता है। यदि कोई उपयुक्त एंट्री मौजूद नहीं है तो null लौटाता है। यह आंतरिक रूप से बाइनरी सर्च करता है इसलिए O(log n) में काम करता है।

```java
tree.floorEntry(4);   // की 4 के बराबर या उससे छोटी सबसे बड़ी → की 3 की एंट्री {3="three"} लौटाता है
tree.floorEntry(5);   // की 5 के बराबर या उससे छोटी सबसे बड़ी → की 5 की एंट्री {5="five"} लौटाता है
tree.floorEntry(0);   // की 0 के बराबर या उससे छोटी कोई एंट्री नहीं है → null लौटाता है

Map.Entry<Integer, String> entry = tree.floorEntry(4);
entry.getValue();     // एंट्री से वैल्यू प्राप्त करना → "three"
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(log n) — set और get दोनों में TreeMap का ऑपरेशन O(log n) है (n उस की में सेव किए गए टाइमस्टैम्प की संख्या है) |
| Space | O(n) — सभी set कॉल द्वारा सेव की गई एंट्रीज़ को स्टोर करता है (n कुल एंट्रीज़ की संख्या है) |

## कोड

```java
// इनपुट: set(key, value, timestamp) — स्ट्रिंग की, स्ट्रिंग वैल्यू, इंटीजर टाइमस्टैम्प / get(key, timestamp) — स्ट्रिंग की, इंटीजर टाइमस्टैम्प
// आउटपुट: set कोई मान नहीं लौटाता / get उपयुक्त वैल्यू की स्ट्रिंग लौटाता है (उपयुक्त न होने पर खाली स्ट्रिंग)
class TimeMap {
    // की → (टाइमस्टैम्प → वैल्यू) का TreeMap रखने वाला HashMap
    // बाहरी HashMap प्रत्येक की को अलग करता है, और आंतरिक TreeMap टाइमस्टैम्प को क्रमबद्ध रूप में रखता है
    Map<String, TreeMap<Integer, String>> map;

    public TimeMap() {
        // बाहरी डेटा स्ट्रक्चर के रूप में HashMap बनाना
        map = new HashMap<>();
    }

    public void set(String key, String val, int ts) {
        // computeIfAbsent से यदि की पंजीकृत नहीं है तो नया TreeMap स्वचालित रूप से बनाकर पंजीकृत करता है, मौजूद होने पर मौजूदा TreeMap लौटाता है
        // TreeMap इंसर्शन के समय की को क्रमबद्ध रूप में रखता है, इसलिए अलग से सॉर्ट ऑपरेशन की आवश्यकता नहीं है
        map.computeIfAbsent(key, k -> new TreeMap<>())
            .put(ts, val);
    }

    public String get(String key, int ts) {
        // यदि की स्वयं मौजूद नहीं है, तो set कभी कॉल नहीं हुआ है इसलिए खाली स्ट्रिंग लौटाना
        if (!map.containsKey(key))
            return "";

        // उस की का TreeMap प्राप्त करना
        TreeMap<Integer, String> tree = map.get(key);

        // निर्दिष्ट टाइमस्टैम्प के बराबर या उससे छोटी सबसे बड़ी एंट्री खोजना (TreeMap आंतरिक बाइनरी सर्च ट्री को O(log n) में खोजता है)
        Map.Entry<Integer, String> entry = tree.floorEntry(ts);

        // यदि एंट्री मिल जाती है तो वैल्यू लौटाना। null का अर्थ है कि सभी टाइमस्टैम्प निर्दिष्ट मान से बड़े हैं, इसलिए खाली स्ट्रिंग लौटाना
        return entry != null ? entry.getValue() : "";
    }
}
```
