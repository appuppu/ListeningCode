# Searching for a Value in a Sorted Matrix — क्रमबद्ध मैट्रिक्स में लक्ष्य मान खोजना

## समस्या का सार

m×n की मैट्रिक्स दी गई है। प्रत्येक पंक्ति आरोही क्रम में क्रमबद्ध है, और प्रत्येक पंक्ति का पहला तत्व उसकी पिछली पंक्ति के अंतिम तत्व से बड़ा है। दिए गए `target` का इस मैट्रिक्स में अस्तित्व है या नहीं, इसका निर्णय करके `boolean` लौटाना है।

## मूल विचार

यदि संपूर्ण मैट्रिक्स को ऊपर-बाएँ से नीचे-दाएँ तक एक पंक्ति में रखा जाए, तो इसे एक क्रमबद्ध सरणी माना जा सकता है। 1-आयामी इंडेक्स `mid` से मैट्रिक्स के निर्देशांक `[mid / n][mid % n]` में रूपांतरण का उपयोग करके, मैट्रिक्स को समतल किए बिना एक ही बाइनरी सर्च से O(log(m * n)) में खोज की जा सकती है।

## विचार प्रक्रिया

1. **संपूर्ण मैट्रिक्स एक क्रमबद्ध सरणी है**: प्रत्येक पंक्ति आरोही क्रम में है और अगली पंक्ति का पहला तत्व पिछली पंक्ति के अंतिम तत्व से बड़ा है, इसलिए मैट्रिक्स के तत्वों को ऊपर-बाएँ से नीचे-दाएँ तक क्रम में पढ़ने पर, संपूर्ण मैट्रिक्स एक आरोही क्रमबद्ध सरणी बन जाती है
2. **क्रमबद्ध सरणी पर बाइनरी सर्च लागू किया जा सकता है**: कुल तत्वों की संख्या `m * n` है, इसलिए 0 से `m * n - 1` की सीमा में बाइनरी सर्च करना होगा। खोज सीमा की निचली सीमा `lo = 0`, ऊपरी सीमा `hi = m * n - 1` निर्धारित करें
3. **1-आयामी इंडेक्स से 2-आयामी निर्देशांक में रूपांतरण आवश्यक है**: बाइनरी सर्च का मध्य बिंदु `mid` एक 1-आयामी इंडेक्स है। मैट्रिक्स से मान प्राप्त करने के लिए 2-आयामी निर्देशांक चाहिए, इसलिए पंक्ति इंडेक्स को `mid / n` (स्तंभ संख्या से भाग का भागफल) और स्तंभ इंडेक्स को `mid % n` (स्तंभ संख्या से भाग का शेषफल) के रूप में रूपांतरित करें
4. **मानक बाइनरी सर्च का तर्क लागू करें**: `matrix[mid / n][mid % n]` से प्राप्त मान यदि `target` के बराबर है तो `true` लौटाएँ। यदि छोटा है तो `lo = mid + 1` से खोज सीमा को दाएँ आधे भाग तक सीमित करें, यदि बड़ा है तो `hi = mid - 1` से बाएँ आधे भाग तक सीमित करें
5. **खोज सीमा समाप्त होने पर target मौजूद नहीं है**: `lo > hi` होने तक कोई मिलान नहीं मिला तो मैट्रिक्स में `target` मौजूद नहीं है, इसलिए `false` लौटाएँ

## पूर्व ज्ञान

### बाइनरी सर्च (Binary Search) क्या है

क्रमबद्ध सरणी पर, खोज सीमा को हर बार आधा करके लक्ष्य मान को तेज़ी से खोजने वाला एल्गोरिदम है। n तत्वों के लिए अधिकतम log₂(n) बार तुलना से परिणाम प्राप्त होता है।

```java
int lo = 0, hi = array.length - 1;  // खोज सीमा की निचली और ऊपरी सीमा निर्धारित करें
while (lo <= hi) {                    // जब तक खोज सीमा मौजूद है तब तक लूप चलाएँ
    int mid = lo + (hi - lo) / 2;    // ओवरफ्लो रोकते हुए मध्य बिंदु की गणना करें
    if (array[mid] == target)         // मध्य बिंदु का मान target से मेल खाता है या नहीं जाँचें
        return true;
    else if (array[mid] < target)
        lo = mid + 1;                // target दाएँ आधे भाग में है इसलिए निचली सीमा बढ़ाएँ
    else
        hi = mid - 1;                // target बाएँ आधे भाग में है इसलिए ऊपरी सीमा घटाएँ
}
return false;                         // नहीं मिलने की स्थिति में
```

### 1-आयामी इंडेक्स और 2-आयामी निर्देशांक का रूपांतरण

स्तंभ संख्या `n` वाली मैट्रिक्स में, 1-आयामी इंडेक्स `idx` से 2-आयामी निर्देशांक में रूपांतरण भागफल और शेषफल से किया जाता है। इस रूपांतरण द्वारा मैट्रिक्स को एक आभासी 1-आयामी सरणी के रूप में उपयोग किया जा सकता है।

```java
int n = matrix[0].length;        // स्तंभ संख्या प्राप्त करें
int row = idx / n;               // भागफल पंक्ति इंडेक्स बनता है (उदाहरण: idx=7, n=4 → row=1)
int col = idx % n;               // शेषफल स्तंभ इंडेक्स बनता है (उदाहरण: idx=7, n=4 → col=3)
int val = matrix[row][col];      // 2-आयामी निर्देशांक से मैट्रिक्स का मान प्राप्त करें
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(log(m * n)) — कुल तत्व संख्या m * n पर एक बार बाइनरी सर्च करता है |
| Space | O(1) — केवल पॉइंटर चर का उपयोग करता है, अतिरिक्त डेटा संरचना की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: m×n की पूर्णांक मैट्रिक्स matrix और पूर्णांक target
// आउटपुट: target मैट्रिक्स में मौजूद है तो true, नहीं है तो false लौटाएँ
public boolean searchMatrix(int[][] matrix, int target) {
    // मैट्रिक्स की पंक्ति संख्या और स्तंभ संख्या प्राप्त करें। कुल तत्व संख्या की गणना और 1-आयामी→2-आयामी रूपांतरण में उपयोग होता है
    int m = matrix.length;
    int n = matrix[0].length;

    // बाइनरी सर्च की खोज सीमा को संपूर्ण मैट्रिक्स पर निर्धारित करें
    // lo=0 मैट्रिक्स के ऊपर-बाएँ से, hi=m*n-1 मैट्रिक्स के नीचे-दाएँ से मेल खाता है
    int lo = 0, hi = m * n - 1;

    // lo > hi होने पर खोज सीमा समाप्त हो जाती है, और target मौजूद नहीं है ऐसा निर्णय किया जा सकता है
    while (lo <= hi) {
        // (lo + hi) / 2 के बजाय इस रूप का उपयोग करें, lo + hi के पूर्णांक ओवरफ्लो को रोकने के लिए
        int mid = lo + (hi - lo) / 2;

        // 1-आयामी इंडेक्स को 2-आयामी निर्देशांक में रूपांतरित करके मान प्राप्त करें
        // पंक्ति इंडेक्स = mid / n (भागफल), स्तंभ इंडेक्स = mid % n (शेषफल)
        int val = matrix[mid / n][mid % n];

        if (val == target)
            return true;           // लक्ष्य मान मिल गया इसलिए true लौटाएँ
        else if (val < target)
            lo = mid + 1;          // target दाएँ आधे भाग (बड़ी तरफ) में है इसलिए निचली सीमा बढ़ाएँ
        else
            hi = mid - 1;          // target बाएँ आधे भाग (छोटी तरफ) में है इसलिए ऊपरी सीमा घटाएँ
    }

    // लूप समाप्त होने पर भी true नहीं लौटा, इसलिए target मैट्रिक्स में मौजूद नहीं है
    return false;
}
```
