# Searching for a Target in a Sorted Array — क्रमबद्ध सरणी में लक्ष्य की स्थिति खोजना

## समस्या का सार

क्रमबद्ध पूर्णांक सरणी `nums` और एक पूर्णांक `target` दिया गया है। सरणी में `target` से मेल खाने वाला तत्व खोजें और उसका **इंडेक्स** लौटाएँ। यदि `target` सरणी में मौजूद नहीं है, तो `-1` लौटाएँ।

## मूल विचार

सरणी क्रमबद्ध होने के कारण, केवल मध्य तत्व और लक्ष्य की तुलना करके, खोज सीमा को हर बार आधा किया जा सकता है। इससे सभी तत्वों की जाँच करने वाले O(n) के बजाय, O(log n) में खोज पूरी होती है।

## विचार प्रक्रिया

1. **क्रमबद्ध होने की शर्त का लाभ उठाएँ**: सरणी क्रमबद्ध है, इसलिए किसी भी स्थिति के तत्व को देखकर यह निर्धारित किया जा सकता है कि लक्ष्य उसके बाईं ओर है या दाईं ओर। इस गुण का उपयोग करके खोज सीमा को हर बार आधा किया जा सकता है
2. **खोज सीमा को दो पॉइंटरों से प्रबंधित करें**: सरणी के बाएँ छोर को `left` और दाएँ छोर को `right` मानकर दो पॉइंटरों से खोज सीमा को व्यक्त करें। प्रारंभिक स्थिति में पूरी सरणी खोज सीमा होती है
3. **मध्य तत्व और लक्ष्य की तुलना करें**: खोज सीमा का मध्य इंडेक्स `mid` की गणना करें और `nums[mid]` की `target` से तुलना करें। यदि दोनों मेल खाते हैं, तो `mid` ही उत्तर है
4. **तुलना परिणाम के अनुसार खोज सीमा को आधा करें**: यदि `nums[mid] < target` है, तो लक्ष्य मध्य से दाईं ओर है, इसलिए `left = mid + 1` से बाएँ छोर को सिकोड़ें। यदि `nums[mid] > target` है, तो लक्ष्य मध्य से बाईं ओर है, इसलिए `right = mid - 1` से दाएँ छोर को सिकोड़ें
5. **खोज सीमा समाप्त होने तक दोहराएँ**: जब तक `left <= right` है, तब तक खोज जारी रखें। जब `left > right` हो जाए, तो इसका अर्थ है कि खोज सीमा खाली हो गई है और लक्ष्य सरणी में मौजूद नहीं है, इसलिए `-1` लौटाएँ
6. **मध्य इंडेक्स की गणना में ओवरफ़्लो से बचें**: `mid = (left + right) / 2` में `left + right` का योग पूर्णांक की अधिकतम सीमा पार कर सकता है। `mid = left + (right - left) / 2` लिखकर ओवरफ़्लो से बचा जा सकता है

## पूर्वापेक्षित ज्ञान

### Binary Search (बाइनरी सर्च) क्या है

क्रमबद्ध सरणी में खोज सीमा को हर बार आधा करके लक्ष्य तत्व को कुशलतापूर्वक खोजने वाला एल्गोरिदम है। खोज सीमा के मध्य तत्व की लक्ष्य से तुलना करें, और यदि मेल नहीं खाता तो बाएँ आधे या दाएँ आधे में से एक को त्याग दें। इसे दोहराने से खोज की संख्या O(log n) हो जाती है।

```java
// जब सरणी की लंबाई 8 हो तो खोज की संख्या
// पहली बार: 8 → 4 (आधा करें)
// दूसरी बार: 4 → 2 (आधा करें)
// तीसरी बार: 2 → 1 (आधा करें)
// अधिकतम 3 बार = log₂(8) = 3
```

### मध्य इंडेक्स की गणना

दो पॉइंटरों `left` और `right` की मध्य स्थिति ज्ञात करें। `(left + right) / 2` के बजाय `left + (right - left) / 2` का उपयोग करके, `left + right` के जोड़ से होने वाले पूर्णांक ओवरफ़्लो को रोकें।

```java
int left = 0;
int right = 10;
int mid = left + (right - left) / 2;  // mid = 0 + (10 - 0) / 2 = 5
```

### while लूप की शर्त `left <= right`

`left <= right` का अर्थ है कि खोज सीमा में एक या अधिक तत्व शेष हैं। जब `left == right` हो, तो खोज सीमा में केवल एक तत्व शेष है, और इस तत्व की भी जाँच करनी आवश्यक है, इसलिए `<` के बजाय `<=` का उपयोग करें।

```java
// जब left=3, right=3 हो, तो nums[3] अभी अनजाँचा है
// left <= right true है, इसलिए nums[3] की जाँच हो सकती है
// left < right होने पर false हो जाएगा, और nums[3] की जाँच किए बिना समाप्त हो जाएगा
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(log n) — खोज सीमा को हर बार आधा करने के कारण, अधिकतम log₂(n) बार तुलना पर्याप्त है |
| Space | O(1) — केवल पॉइंटर चरों का उपयोग होता है, अतिरिक्त डेटा संरचना की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: क्रमबद्ध पूर्णांक सरणी nums और पूर्णांक target
// आउटपुट: target से मेल खाने वाले तत्व का इंडेक्स int में लौटाएँ। मौजूद न होने पर -1 लौटाएँ
public int binarySearch(int[] nums, int target) {
    // खोज सीमा के बाएँ छोर और दाएँ छोर को आरंभ करें। ये दो चर खोज सीमा को प्रबंधित करते हैं
    int left = 0;
    int right = nums.length - 1;

    // left <= right: जब तक खोज सीमा में एक या अधिक तत्व शेष हैं, तब तक दोहराएँ
    // जब left > right हो जाए, तो खोज सीमा खाली है इसलिए लूप से बाहर निकलें
    while (left <= right) {
        // सावधानी: (left + right) / 2 में left + right के जोड़ से पूर्णांक ओवरफ़्लो हो सकता है
        // left + (right - left) / 2 लिखकर ओवरफ़्लो से बचें
        int mid = left
            + (right - left) / 2;

        // यदि मध्य तत्व लक्ष्य से मेल खाता है, तो इंडेक्स लौटाएँ
        if (nums[mid] == target) {
            return mid;
        }

        // यदि लक्ष्य मध्य से बड़ा है, तो खोज सीमा को दाएँ आधे तक सीमित करें
        // mid स्वयं पहले से जाँचा जा चुका है, इसलिए mid + 1 करें
        if (nums[mid] < target) {
            left = mid + 1;
        }
        // यदि लक्ष्य मध्य से छोटा है, तो खोज सीमा को बाएँ आधे तक सीमित करें
        // mid स्वयं पहले से जाँचा जा चुका है, इसलिए mid - 1 करें
        else {
            right = mid - 1;
        }
    }

    // खोज सीमा खाली हो गई है, इसलिए लक्ष्य सरणी में मौजूद नहीं है
    return -1;
}
```
