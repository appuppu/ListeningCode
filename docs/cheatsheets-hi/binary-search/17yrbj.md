# Searching for a Target in a Rotated Sorted Array — घुमाए गए क्रमबद्ध सरणी में लक्ष्य की खोज

## समस्या का सार

आरोही क्रम में क्रमबद्ध एक पूर्णांक सरणी को किसी अज्ञात pivot पर घुमाया गया है। इस सरणी में दिए गए `target` का मान खोजकर उसका इंडेक्स लौटाना है। यदि `target` मौजूद नहीं है तो `-1` लौटाना है। सभी तत्व अद्वितीय हैं।

## मूल विचार

घुमाई गई क्रमबद्ध सरणी को मध्य से विभाजित करने पर, बाएं और दाएं भाग में से कम से कम एक भाग अवश्य क्रमबद्ध होता है। क्रमबद्ध भाग में `target` शामिल है या नहीं यह सीमा जाँच से निर्धारित किया जाता है, और यदि शामिल नहीं है तो दूसरे भाग में खोज की जाती है, जिससे हर बार खोज सीमा आधी हो जाती है।

## विचार प्रक्रिया

1. **क्रमबद्ध सरणी होने के कारण Binary Search का उपयोग करना है**: सामान्य क्रमबद्ध सरणी में Binary Search से O(log n) में खोज की जा सकती है। घुमाव होने पर भी इस दक्षता को बनाए रखने की विधि पर विचार करना है
2. **घुमाई गई सरणी को मध्य से विभाजित करने पर एक भाग अवश्य क्रमबद्ध होता है**: सरणी `[4,5,6,7,0,1,2]` को `mid=3`（मान 7）पर विभाजित करने पर, बायाँ भाग `[4,5,6,7]` क्रमबद्ध है, और दायाँ भाग `[0,1,2]` भी क्रमबद्ध है। घुमाव का pivot केवल एक भाग में होता है, इसलिए दूसरा भाग अवश्य आरोही क्रम में रहता है
3. **कौन सा भाग क्रमबद्ध है यह निर्धारित करने की विधि**: यदि `nums[left] <= nums[mid]` सत्य है तो बायाँ भाग क्रमबद्ध है। यदि सत्य नहीं है तो दायाँ भाग क्रमबद्ध है। समान चिह्न इसलिए शामिल किया गया है क्योंकि `left == mid` होने की स्थिति（जब तत्वों की संख्या 2 या उससे कम हो）को सही ढंग से संसाधित करने के लिए यह आवश्यक है
4. **क्रमबद्ध भाग में target शामिल है या नहीं यह निर्धारित करना**: क्रमबद्ध भाग का न्यूनतम और अधिकतम मान ज्ञात होता है, इसलिए `target` उस सीमा में है या नहीं यह असमिका से निर्धारित किया जा सकता है। उदाहरण के लिए यदि बायाँ भाग क्रमबद्ध है, तो `target >= nums[left] && target < nums[mid]` से निर्धारित किया जाता है
5. **जिस भाग में शामिल है उसमें खोज करना**: यदि `target` क्रमबद्ध भाग की सीमा में है, तो उसी भाग तक सीमित किया जाता है। यदि सीमा से बाहर है, तो `target` दूसरे भाग में होना चाहिए, इसलिए उस भाग में खोज की जाती है
6. **लूप समाप्ति पर प्रक्रिया**: `left > right` होने तक खोज करने पर भी यदि `target` नहीं मिलता, तो सरणी में `target` मौजूद नहीं है इसलिए `-1` लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### Binary Search（द्विआधारी खोज）क्या है

क्रमबद्ध सरणी में, खोज सीमा के मध्य तत्व की जाँच करके खोज सीमा को आधा करने की क्रिया को बार-बार दोहराने वाली खोज विधि। हर बार सीमा आधी होने के कारण, O(log n) की समय जटिलता में खोज की जा सकती है।

```java
int left = 0;
int right = nums.length - 1;
while (left <= right) {                    // जब तक खोज सीमा मान्य है तब तक लूप चलाना
    int mid = left + (right - left) / 2;   // ओवरफ्लो रोकने के लिए मध्य की गणना
    // nums[mid] और target की तुलना करके left या right को अपडेट करना
}
```

### घुमाई गई क्रमबद्ध सरणी क्या है

आरोही क्रम में क्रमबद्ध सरणी को किसी स्थान पर काटकर, पिछले भाग को आगे स्थानांतरित की गई सरणी। उदाहरण के लिए `[0,1,2,4,5,6,7]` को इंडेक्स 4 पर घुमाने पर `[4,5,6,7,0,1,2]` बनती है। संपूर्ण सरणी क्रमबद्ध नहीं है, लेकिन pivot के बाएं और दाएं प्रत्येक भाग क्रमबद्ध है।

```
मूल सरणी:     [0, 1, 2, 4, 5, 6, 7]
घुमाव के बाद:  [4, 5, 6, 7, 0, 1, 2]
               क्रमबद्ध↑  ↑क्रमबद्ध
```

## जटिलता

| | मान |
|---|---|
| Time | O(log n) — हर बार खोज सीमा आधी होने के कारण, अधिकतम log n बार तुलना से कार्य पूर्ण होता है |
| Space | O(1) — केवल left, right, mid की 3 चर का उपयोग होता है, अतिरिक्त डेटा संरचना की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: घुमाई गई क्रमबद्ध पूर्णांक सरणी nums और पूर्णांक target
// आउटपुट: target का इंडेक्स int के रूप में लौटाना। मौजूद न होने पर -1 लौटाना
public int search(int[] nums, int target) {
    // खोज सीमा के दोनों छोरों को आरंभ करना। ये 2 चर खोज सीमा के दोनों छोरों को दर्शाते हैं
    int left = 0;
    int right = nums.length - 1;

    // left > right होने पर खोज सीमा रिक्त हो गई है
    while (left <= right) {
        // (left + right) / 2 के बजाय इस सूत्र का उपयोग left + right के पूर्णांक ओवरफ्लो को रोकने के लिए किया गया है
        int mid = left + (right - left) / 2;

        // मध्य तत्व target के बराबर है तो इंडेक्स लौटाना
        if (nums[mid] == target) {
            return mid;
        }

        // बायाँ भाग क्रमबद्ध है या नहीं यह निर्धारित करना
        // समान चिह्न इसलिए शामिल है क्योंकि left == mid（खोज सीमा में 2 या उससे कम तत्व）होने पर बाएं भाग को सही ढंग से क्रमबद्ध निर्धारित करने के लिए
        if (nums[left] <= nums[mid]) {
            // target बाएं भाग की सीमा में है या नहीं यह निर्धारित करना
            if (target >= nums[left] && target < nums[mid]) {
                right = mid - 1;  // target बाएं भाग की सीमा में है इसलिए बाएं भाग तक सीमित करना
            } else {
                left = mid + 1;   // target बाएं भाग की सीमा से बाहर है इसलिए दाएं भाग तक सीमित करना
            }
        // दायाँ भाग क्रमबद्ध होने की स्थिति में
        } else {
            // target दाएं भाग की सीमा में है या नहीं यह निर्धारित करना
            if (target > nums[mid] && target <= nums[right]) {
                left = mid + 1;   // target दाएं भाग की सीमा में है इसलिए दाएं भाग तक सीमित करना
            } else {
                right = mid - 1;  // target दाएं भाग की सीमा से बाहर है इसलिए बाएं भाग तक सीमित करना
            }
        }
    }

    // खोज सीमा रिक्त हो गई इसलिए target सरणी में मौजूद नहीं है
    return -1;
}
```
