# Finding the Minimum in a Rotated Sorted Array — घुमाए गए क्रमबद्ध सरणी में न्यूनतम मान खोजना

## समस्या का सार

आरोही क्रम में क्रमबद्ध अद्वितीय पूर्णांकों की एक सरणी को 1 बार से n बार तक घुमाया गया है। इस घुमाई गई सरणी में से **न्यूनतम तत्व** को खोजकर लौटाना है। घुमाव (rotation) का अर्थ है सरणी के अंतिम तत्व को आरंभ में स्थानांतरित करना, जिससे मूल क्रमबद्ध क्रम बीच में "मुड़ जाता है" और एक पिवट उत्पन्न होता है।

## मूल विचार

घुमाई गई क्रमबद्ध सरणी में, न्यूनतम मान उस स्थान पर होता है जहाँ क्रमबद्ध क्रम टूटता है, अर्थात "पिवट" की स्थिति पर। मध्य तत्व और दाएँ छोर के तत्व की तुलना करने से यह एक ही तुलना में निर्धारित किया जा सकता है कि न्यूनतम मान बाएँ आधे भाग में है या दाएँ आधे भाग में, और बाइनरी सर्च द्वारा O(log n) में इसे खोजा जा सकता है।

## विचार प्रक्रिया

1. **न्यूनतम मान पिवट की स्थिति पर होता है**: घुमाई गई क्रमबद्ध सरणी "बड़ी उप-अनुक्रम" और "छोटी उप-अनुक्रम" नामक दो क्रमबद्ध भागों में विभाजित होती है। न्यूनतम मान "छोटी उप-अनुक्रम" के आरंभ में, अर्थात पिवट की स्थिति पर होता है। इस पिवट को खोजना ही समस्या का सार है
2. **रैखिक खोज की बजाय बाइनरी सर्च का उपयोग करना है**: सरणी पूर्णतः क्रमबद्ध नहीं है, लेकिन दो क्रमबद्ध भागों में विभाजित होने की संरचना विद्यमान है। इस संरचना का उपयोग करके, प्रत्येक बार आधा भाग हटाकर बाइनरी सर्च लागू किया जा सकता है
3. **मध्य तत्व और दाएँ छोर के तत्व की तुलना करना**: यदि `nums[mid] > nums[right]` सत्य है, तो mid से right के बीच पिवट (क्रमबद्ध क्रम का टूटना) विद्यमान है, इसलिए न्यूनतम मान दाएँ आधे भाग में है। इसके विपरीत, यदि `nums[mid] <= nums[right]` है, तो mid से right तक क्रमबद्ध है, और न्यूनतम मान mid के बाईं ओर (mid स्वयं सहित) है
4. **बाएँ छोर की बजाय दाएँ छोर से तुलना करने का कारण**: बाएँ छोर से तुलना करने पर, जब सरणी घुमाई नहीं गई हो (संपूर्ण सरणी क्रमबद्ध हो), तब सही निर्णय नहीं लिया जा सकता। दाएँ छोर से तुलना करने पर, घुमाव हो या न हो, न्यूनतम मान की स्थिति को सही ढंग से सीमित किया जा सकता है
5. **खोज सीमा को अपडेट करने की विधि**: जब `nums[mid] > nums[right]` हो, तो mid न्यूनतम मान नहीं है यह निश्चित हो जाता है, इसलिए `left = mid + 1` किया जाता है। अन्यथा, mid न्यूनतम मान हो सकता है, इसलिए `right = mid` किया जाता है (mid को बाहर नहीं किया जाता)
6. **लूप की समाप्ति शर्त**: `left < right` तक लूप चलता है, और जब `left == right` हो जाता है तो खोज सीमा एक तत्व तक सिमट जाती है। वह तत्व `nums[left]` ही न्यूनतम मान है

## पूर्वापेक्षित ज्ञान

### घुमाई गई क्रमबद्ध सरणी क्या है

आरोही क्रमबद्ध सरणी `[1, 2, 3, 4, 5]` को दाईं ओर 2 बार घुमाने पर `[4, 5, 1, 2, 3]` बनती है। सरणी दो क्रमबद्ध उप-अनुक्रमों `[4, 5]` और `[1, 2, 3]` में विभाजित होती है, और उनकी सीमा पिवट होती है।

```
मूल सरणी:       [1, 2, 3, 4, 5]
2 बार घुमाने के बाद: [4, 5, 1, 2, 3]
                        ↑ पिवट (न्यूनतम मान)
```

### बाइनरी सर्च की मूल संरचना

खोज सीमा को प्रत्येक बार आधा करके, O(log n) में लक्षित तत्व खोजने की विधि। left और right दो पॉइंटरों द्वारा खोज सीमा का प्रबंधन किया जाता है, और मध्य तत्व के आधार पर सीमा को अपडेट किया जाता है।

```java
int left = 0;
int right = nums.length - 1;
int mid = left + (right - left) / 2;  // ओवरफ़्लो रोकने के लिए मध्य मान की गणना
```

### `left + (right - left) / 2` क्या है

मध्य इंडेक्स की गणना करने का सूत्र। `(left + right) / 2` से भी समान परिणाम मिलता है, लेकिन जब left और right बड़े मान हों तो जोड़ने पर int की अधिकतम सीमा पार हो सकती है। यह सूत्र उस **ओवरफ़्लो को रोकने** का सुरक्षित तरीका है।

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(log n) — प्रत्येक बार खोज सीमा को आधा करने के कारण, अधिकतम log n तुलनाओं में न्यूनतम मान मिल जाता है |
| Space | O(1) — केवल left, right, mid तीन चरों का उपयोग होता है, अतिरिक्त डेटा संरचना की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: घुमाई गई क्रमबद्ध अद्वितीय पूर्णांक सरणी nums
// आउटपुट: सरणी में न्यूनतम मान int के रूप में लौटाना
public int findMin(int[] nums) {
    // खोज सीमा के दोनों छोरों को आरंभ करना। ये दो चर खोज सीमा के दोनों छोरों को दर्शाते हैं
    int left = 0;
    int right = nums.length - 1;

    // जब left == right हो जाता है तो खोज सीमा एक तत्व तक सिमट जाती है, और वह तत्व न्यूनतम मान होता है
    while (left < right) {
        // (left + right) / 2 की बजाय इस सूत्र का उपयोग पूर्णांक ओवरफ़्लो को रोकने के लिए किया जाता है
        int mid = left + (right - left) / 2;

        // यदि मध्य तत्व दाएँ छोर से बड़ा है, तो mid और right के बीच पिवट (क्रमबद्ध क्रम का टूटना) विद्यमान है
        if (nums[mid] > nums[right]) {
            // न्यूनतम मान mid के दाईं ओर है। mid दाएँ छोर से बड़ा है इसलिए यह न्यूनतम मान नहीं है, इसे बाहर किया जा सकता है
            left = mid + 1;
        } else {
            // mid से right तक क्रमबद्ध है। न्यूनतम मान mid के बाईं ओर (mid स्वयं सहित) है
            // mid स्वयं न्यूनतम मान हो सकता है, इसलिए mid को खोज सीमा से बाहर नहीं किया जाता
            right = mid;
        }
    }

    // left == right हो गया है, खोज सीमा एक तत्व तक सिमट गई है, इसलिए वह तत्व न्यूनतम मान है
    return nums[left];
}
```
