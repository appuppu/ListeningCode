# Finding the Minimum Eating Speed to Finish Bananas — समय सीमा के भीतर सभी केले खा लेने की न्यूनतम गति ज्ञात करना

## समस्या का सार

केलों के ढेर की एक सरणी `piles` और समय सीमा `h` (घंटे) दी गई है। प्रति घंटे `k` केले खाने पर, `h` घंटे के भीतर सभी केले खा लेने की **न्यूनतम पूर्णांक गति `k`** लौटानी है। एक घंटे में केवल एक ढेर से खाया जा सकता है, और यदि ढेर में `k` से कम केले हैं, तो उस ढेर को खत्म करने के बाद शेष समय में अगले ढेर पर नहीं जाया जा सकता और प्रतीक्षा करनी होती है।

## मूल विचार

"क्या गति `k` से सभी केले खाए जा सकते हैं?" यह प्रश्न `k` के संबंध में एकदिष्ट (monotonic) है। यदि `k` बड़ा है तो निश्चित रूप से सभी केले खाए जा सकते हैं, और यदि बहुत छोटा है तो नहीं खाए जा सकते। इस एकदिष्टता के कारण, उत्तर की उम्मीदवार सीमा `[1, max(piles)]` पर बाइनरी सर्च लागू करके, शर्त को पूरा करने वाला न्यूनतम `k` कुशलतापूर्वक ज्ञात किया जा सकता है।

## विचार प्रक्रिया

1. **गति और परिणाम के बीच एकदिष्ट संबंध है**: गति `k` बढ़ाने पर आवश्यक समय घटता है, और घटाने पर बढ़ता है। यदि किसी गति पर सभी केले खाए जा सकते हैं, तो उससे अधिक किसी भी गति पर भी निश्चित रूप से खाए जा सकते हैं। यह "किसी शर्त को पूरा करने वाला न्यूनतम मान ज्ञात करना" संरचना बाइनरी सर्च का एक विशिष्ट पैटर्न है
2. **खोज सीमा निर्धारित करना**: गति का न्यूनतम मान `1` है (प्रति घंटे कम से कम 1 केला खाया जाता है), और अधिकतम मान `max(piles)` है (सबसे बड़े ढेर को 1 घंटे में खत्म कर सकने वाली गति)। `max(piles)` से बड़ी गति रखने पर भी एक घंटे में केवल एक ढेर ही खाया जा सकता है, इसलिए परिणाम नहीं बदलता
3. **निर्णय फ़ंक्शन डिज़ाइन करना**: जब गति `mid` दी जाए, तब प्रत्येक ढेर `piles[i]` को खाने में `ceil(piles[i] / mid)` घंटे लगते हैं। सभी ढेरों का कुल समय यदि `h` से कम या बराबर हो, तो उस गति पर सभी केले खाए जा सकते हैं
4. **ऊपरी पूर्णांकन भाग (ceiling division) को पूर्णांक संक्रिया से करना**: `ceil(piles[i] / mid)` को `(piles[i] + mid - 1) / mid` से परिकलित किया जा सकता है। इससे फ़्लोटिंग-पॉइंट संक्रिया से बचा जाता है और केवल पूर्णांकों से सटीक गणना होती है
5. **बाइनरी सर्च से सीमा को संकुचित करना**: यदि मध्य मान `mid` पर सभी केले खाए जा सकते हैं, तो उत्तर `mid` या उससे कम है, इसलिए `right = mid` रखा जाता है। यदि नहीं खाए जा सकते, तो उत्तर `mid + 1` या उससे अधिक है, इसलिए `left = mid + 1` रखा जाता है। जब `left == right` हो जाए, तब वह मान अभीष्ट न्यूनतम गति है

## पूर्वापेक्षित ज्ञान

### बाइनरी सर्च (Binary Search) का "शर्त को पूरा करने वाला न्यूनतम मान" पैटर्न

क्रमबद्ध मानों या क्रमागत पूर्णांकों की सीमा पर, किसी शर्त को पूरा करने वाला न्यूनतम मान (या अधिकतम मान) ज्ञात करने की विधि। प्रत्येक बार खोज सीमा को आधा करने के कारण, O(log n) में उत्तर मिल जाता है।

```java
int left = 1;               // खोज सीमा की निचली सीमा
int right = 1000;            // खोज सीमा की ऊपरी सीमा
while (left < right) {       // left == right होने पर उत्तर निश्चित होता है
    int mid = left + (right - left) / 2;  // ओवरफ़्लो रोकने वाली मध्य मान गणना
    if (condition(mid))       // mid शर्त को पूरा करता है या नहीं यह जाँचना
        right = mid;          // शर्त पूरी होती है → उत्तर mid या उससे कम में है
    else
        left = mid + 1;       // शर्त पूरी नहीं होती → उत्तर mid+1 या उससे अधिक में है
}
// left शर्त को पूरा करने वाला न्यूनतम मान है
```

### ऊपरी पूर्णांकन भाग (Ceiling Division)

`a / b` के परिणाम को ऊपर की ओर पूर्णांकित करने वाली पूर्णांक संक्रिया। `Math.ceil` का उपयोग किए बिना `(a + b - 1) / b` से परिकलित किया जा सकता है।

```java
int a = 10, b = 3;
int result = (a + b - 1) / b;  // (10 + 2) / 3 = 4  (10÷3=3.33... → ऊपर पूर्णांकित करके 4)
```

केले की समस्या में, ढेर का आकार `piles[i]` को गति `k` से भाग देकर ऊपर पूर्णांकित करने से, उस ढेर को खत्म करने में लगने वाले घंटों की संख्या ज्ञात होती है।

### Math.max क्या है

दो मानों में से बड़ा मान लौटाने वाली विधि। सरणी का अधिकतम मान ज्ञात करते समय लूप के साथ संयोजन में उपयोग किया जाता है।

```java
Math.max(5, 3);   // → 5
Math.max(-1, 0);  // → 0
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n × log(max(piles))) — बाइनरी सर्च में O(log(max(piles))) बार पुनरावृत्ति होती है, और प्रत्येक पुनरावृत्ति में पूरी सरणी को O(n) में स्कैन करके कुल समय की गणना की जाती है |
| Space | O(1) — किसी अतिरिक्त डेटा संरचना का उपयोग नहीं होता, केवल चरों से प्रसंस्करण किया जाता है |

## कोड

```java
// इनपुट: पूर्णांक सरणी piles (प्रत्येक ढेर में केलों की संख्या) और पूर्णांक h (समय सीमा)
// आउटपुट: h घंटे के भीतर सभी केले खा लेने की न्यूनतम पूर्णांक गति k को int के रूप में लौटाना
public int minEatingSpeed(int[] piles, int h) {
    // बाइनरी सर्च की निचली सीमा 1 पर सेट करना। गति कम से कम प्रति घंटे 1 केला है
    int left = 1;
    // बाइनरी सर्च की ऊपरी सीमा सरणी के अधिकतम मान पर सेट करना
    // सबसे बड़े ढेर को 1 घंटे में खा सकने वाली गति से अधिक रखने का कोई अर्थ नहीं है, इसलिए यह मान ऊपरी सीमा है
    int right = 0;
    for (int p : piles) {
        right = Math.max(right, p);
    }

    // left == right होने तक खोज सीमा को आधा करते रहना
    // left == right होने पर वह मान उत्तर है
    while (left < right) {
        // ओवरफ़्लो रोकने वाली मध्य मान गणना
        // (left + right) / 2 के बजाय left + (right - left) / 2 का उपयोग करके पूर्णांक ओवरफ़्लो रोका जाता है
        int mid = left + (right - left) / 2;

        // गति mid पर सभी केले खाने में लगने वाले कुल समय की गणना करना
        int totalHours = 0;
        for (int p : piles) {
            // ऊपरी पूर्णांकन भाग: प्रत्येक ढेर को खत्म करने में लगने वाले घंटों की संख्या ज्ञात करना
            totalHours += (p + mid - 1) / mid;
        }

        if (totalHours <= h) {
            // खा सकते हैं → और धीमी गति पर भी खा सकने की संभावना है इसलिए ऊपरी सीमा को संकुचित करना
            // mid स्वयं उत्तर हो सकता है, इसलिए mid - 1 नहीं बल्कि mid असाइन किया जाता है
            right = mid;
        } else {
            // नहीं खा सकते → गति अपर्याप्त है इसलिए निचली सीमा को बढ़ाना
            // mid उत्तर नहीं हो सकता, इसलिए mid + 1 असाइन किया जाता है
            left = mid + 1;
        }
    }

    // लूप समाप्त होने पर, left (= right) शर्त को पूरा करने वाली न्यूनतम गति है
    return left;
}
```
