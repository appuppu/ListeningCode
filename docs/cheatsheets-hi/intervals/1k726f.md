# Merging Overlapping Intervals — सभी ओवरलैपिंग अंतरालों को मर्ज करना

## समस्या का सार

अंतरालों (शुरुआती और अंतिम मान के जोड़े) की एक सरणी `intervals` दी गई है। सभी ओवरलैपिंग अंतरालों को मर्ज करें और गैर-ओवरलैपिंग अंतरालों की सूची लौटाएँ।

## मुख्य विचार

यदि अंतरालों को शुरुआती मान के अनुसार सॉर्ट किया जाए, तो ओवरलैप होने की संभावना केवल आसपास के अंतरालों में ही होती है। सॉर्ट करने के बाद आगे से क्रमशः स्कैन करें — यदि वर्तमान अंतराल पिछले अंतराल से ओवरलैप करता है तो अंतिम मान को अपडेट करें, और यदि ओवरलैप नहीं करता है तो उसे नए अंतराल के रूप में जोड़ें।

## विचार प्रक्रिया

1. **ओवरलैप की जाँच को सरल बनाना**: यदि अंतराल सॉर्ट नहीं हैं, तो सभी जोड़ों की तुलना करनी पड़ती है। शुरुआती मान के अनुसार आरोही क्रम में सॉर्ट करने पर, ओवरलैप की जाँच केवल "पिछले अंतराल का अंतिम मान ≥ वर्तमान अंतराल का शुरुआती मान" से हो जाती है
2. **सॉर्ट के बाद एक ही स्कैन में मर्ज संभव है**: सॉर्ट किए गए अंतरालों को शुरू से क्रमशः देखें। परिणाम सूची के अंतिम अंतराल और वर्तमान अंतराल की तुलना करें — यदि ओवरलैप है तो अंतिम मान को बड़े मान से अपडेट करें। यदि ओवरलैप नहीं है तो वर्तमान अंतराल को सीधे परिणाम सूची में जोड़ दें
3. **परिणाम सूची के अंतिम तत्व तक पहुँच आवश्यक है**: मर्ज की जाँच में हमेशा परिणाम सूची में "अंतिम जोड़े गए अंतराल" के अंतिम मान को संदर्भित किया जाता है। LinkedList का उपयोग करने पर `getLast()` से O(1) में अंतिम तत्व तक पहुँचा जा सकता है
4. **ओवरलैप की शर्त को सटीक रूप से परिभाषित करना**: जब पिछले अंतराल का अंतिम मान वर्तमान अंतराल के शुरुआती मान से छोटा हो (`res.getLast()[1] < interval[0]`), तो दोनों अंतराल ओवरलैप नहीं करते। अन्य स्थिति में (अंतिम मान ≥ शुरुआती मान) वे ओवरलैप करते हैं और उन्हें मर्ज किया जाता है
5. **मर्ज करते समय केवल अंतिम मान को अपडेट करना**: शुरुआती मान सॉर्ट के कारण पिछले अंतराल का हमेशा छोटा या बराबर होता है। अंतिम मान के लिए दोनों अंतरालों में से बड़ा मान अपनाया जाता है। `Math.max()` से पिछले अंतिम मान और वर्तमान अंतिम मान की तुलना की जाती है
6. **अंतिम रूप से क्या लौटाना है**: परिणाम सूची में संचित सभी गैर-ओवरलैपिंग अंतरालों को `int[][]` द्विमितीय सरणी में बदलकर लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### Arrays.sort और कस्टम Comparator

`Arrays.sort` सरणी को सॉर्ट करने की विधि है। द्विमितीय सरणी के लिए, लैम्ब्डा एक्सप्रेशन से Comparator निर्दिष्ट करके यह परिभाषित किया जाता है कि किस तत्व के आधार पर सॉर्ट करना है।

```java
int[][] intervals = {{3, 6}, {1, 3}, {2, 5}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // प्रत्येक अंतराल के शुरुआती मान (index 0) के अनुसार आरोही क्रम में सॉर्ट करें
// परिणाम: {{1, 3}, {2, 5}, {3, 6}}
```

### LinkedList क्या है

यह एक ऐसी सूची है जिसमें शुरू और अंत में जोड़ना तथा अंतिम तत्व प्राप्त करना O(1) में संभव है। ArrayList के विपरीत, `getLast()` विधि से अंतिम तत्व को सीधे एक्सेस किया जा सकता है।

```java
LinkedList<int[]> res = new LinkedList<>();  // खाली LinkedList बनाएँ
res.add(new int[]{1, 3});   // अंत में तत्व जोड़ें
res.getLast();               // अंतिम तत्व प्राप्त करें → {1, 3}
res.getLast()[1] = 5;        // अंतिम तत्व के अंतिम मान को सीधे बदलें → {1, 5}
res.isEmpty();               // सूची खाली है या नहीं boolean में लौटाएँ → false
res.size();                  // सूची में तत्वों की संख्या लौटाएँ → 1
```

### Math.max क्या है

यह दो मानों में से बड़ा मान लौटाने वाली विधि है। अंतरालों को मर्ज करते समय, दो अंतिम मानों में से बड़ा मान अपनाने के लिए इसका उपयोग किया जाता है।

```java
Math.max(5, 8);   // → 8
Math.max(10, 3);  // → 10
```

## जटिलता

| | मान |
|---|---|
| Time | O(n log n) — सॉर्ट O(n log n) है और स्कैन O(n) है, इसलिए कुल जटिलता O(n log n) है |
| Space | O(n) — परिणाम सूची में अधिकतम n अंतराल संग्रहीत होते हैं |

## कोड

```java
// इनपुट: अंतरालों की द्विमितीय सरणी int[][] intervals (प्रत्येक तत्व [शुरुआती मान, अंतिम मान] है)
// आउटपुट: ओवरलैपिंग अंतरालों को मर्ज करने के बाद की द्विमितीय सरणी int[][] लौटाएँ
public int[][] merge(int[][] intervals) {
    // सॉर्ट करने से ओवरलैप की जाँच केवल आसपास के अंतरालों की तुलना तक सीमित हो जाती है
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // मर्ज किए गए अंतरालों को संचित करने के लिए परिणाम सूची
    // LinkedList का उपयोग इसलिए किया गया है क्योंकि अंतिम तत्व का संदर्भ और अपडेट O(1) में होता है
    LinkedList<int[]> res = new LinkedList<>();

    for (int[] interval : intervals) {
        // यदि res खाली है तो यह पहला अंतराल है इसलिए बिना शर्त जोड़ें
        // यदि res.getLast()[1] < interval[0] है तो पिछले अंतराल से ओवरलैप नहीं है इसलिए सीधे जोड़ें
        if (res.isEmpty() || res.getLast()[1] < interval[0]) {
            res.add(interval);
        } else {
            // ओवरलैप होने पर, अंतिम मान को बड़े मान से अपडेट करके मर्ज करें
            // शुरुआती मान सॉर्ट के कारण पिछले अंतराल का छोटा या बराबर है इसलिए बदलने की आवश्यकता नहीं है
            res.getLast()[1] = Math.max(res.getLast()[1], interval[1]);
        }
    }

    // परिणाम सूची को द्विमितीय सरणी में बदलकर लौटाएँ
    return res.toArray(new int[res.size()][]);
}
```
