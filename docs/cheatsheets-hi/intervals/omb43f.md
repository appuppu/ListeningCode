# Determining if All Meetings Can Be Attended — यह निर्धारित करना कि सभी बैठकों में भाग लिया जा सकता है या नहीं

## समस्या का सार

बैठकों के समय अंतराल (प्रारंभ समय और समाप्ति समय की जोड़ी) की एक सरणी `intervals` दी गई है। यह निर्धारित करना है कि एक व्यक्ति **सभी बैठकों में भाग ले सकता है या नहीं**, और परिणाम `boolean` के रूप में लौटाना है। यदि कोई बैठक किसी अन्य बैठक की समाप्ति से पहले शुरू होती है, तो वे दो बैठकें परस्पर विरोधी (अतिव्यापी) हैं, और सभी बैठकों में भाग लेना संभव नहीं है।

## मूल विचार

यदि अंतरालों को प्रारंभ समय के अनुसार क्रमबद्ध किया जाए, तो अतिव्यापन केवल आसन्न अंतरालों के बीच ही हो सकता है। आसन्न जोड़ियों की क्रमशः तुलना करके, यह जाँचना पर्याप्त है कि अगले अंतराल का प्रारंभ समय पिछले अंतराल के समाप्ति समय से पहले है या नहीं — इससे संपूर्ण अतिव्यापन की जाँच हो जाती है।

## विचार प्रक्रिया

1. **अतिव्यापन की शर्त को समझना**: दो अंतरालों का अतिव्यापन होने का अर्थ है कि एक का प्रारंभ समय दूसरे के समाप्ति समय से पहले है। लेकिन यदि अंतराल अव्यवस्थित क्रम में हों, तो सभी जोड़ियों की तुलना करनी पड़ेगी, जिससे समय जटिलता O(n²) हो जाएगी
2. **क्रमबद्ध करके तुलना का दायरा सीमित करना**: यदि अंतरालों को प्रारंभ समय के आरोही क्रम में क्रमबद्ध किया जाए, तो अतिव्यापन केवल आसन्न अंतरालों के बीच ही हो सकता है। इसका कारण यह है कि यदि `intervals[i]` और `intervals[i+2]` अतिव्यापी हैं, तो `intervals[i]` और `intervals[i+1]` भी अवश्य अतिव्यापी होंगे
3. **आसन्न जोड़ियों का अतिव्यापन परीक्षण**: क्रमबद्ध करने के बाद, यदि `intervals[i]` का प्रारंभ समय `intervals[i-1]` के समाप्ति समय से पहले है, तो वे दो बैठकें अतिव्यापी हैं। इस शर्त को `intervals[i][0] < intervals[i-1][1]` के रूप में व्यक्त किया जा सकता है
4. **एक भी अतिव्यापन मिलने पर परिणाम तुरंत निश्चित हो जाता है**: यदि एक भी अतिव्यापी जोड़ी मिल जाए, तो सभी बैठकों में भाग लेना संभव नहीं है, इसलिए `false` लौटाना है। यदि सभी आसन्न जोड़ियों की जाँच के बाद कोई अतिव्यापन न मिले, तो `true` लौटाना है

## पूर्वापेक्षित ज्ञान

### Arrays.sort और कस्टम Comparator

`Arrays.sort` सरणी को क्रमबद्ध करने की विधि है। द्विआयामी सरणी के मामले में, लैम्ब्डा व्यंजक से Comparator (तुलना फ़ंक्शन) निर्दिष्ट करके, यह नियंत्रित किया जा सकता है कि किस तत्व के आधार पर क्रमबद्ध करना है।

```java
int[][] intervals = {{7, 10}, {2, 4}, {5, 8}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // प्रत्येक अंतराल के प्रारंभ समय ([0]) के अनुसार आरोही क्रम में क्रमबद्ध करना
// परिणाम: {{2, 4}, {5, 8}, {7, 10}}
```

`(a, b) -> a[0] - b[0]` दो अंतराल `a` और `b` को लेता है और प्रारंभ समय का अंतर लौटाता है। यदि अंतर ऋणात्मक हो तो `a` पहले आता है, और यदि धनात्मक हो तो `b` पहले आता है।

### अंतरालों का अतिव्यापन परीक्षण

जब दो अंतराल प्रारंभ समय के अनुसार क्रमबद्ध हों, तो यदि बाद वाले अंतराल का प्रारंभ पहले वाले अंतराल की समाप्ति से पहले हो, तो वे अतिव्यापी हैं।

```java
int[] prev = {2, 4};   // 2 बजे से 4 बजे तक की बैठक
int[] curr = {3, 6};   // 3 बजे से 6 बजे तक की बैठक
curr[0] < prev[1];     // 3 < 4 → true → अतिव्यापन है
```

## जटिलता

| | मान |
|---|---|
| Time | O(n log n) — क्रमबद्ध करना O(n log n) है, आसन्न जोड़ियों की जाँच O(n) है, और क्रमबद्ध करना प्रमुख है |
| Space | O(1) — क्रमबद्ध करना इनपुट सरणी को सीधे पुनर्व्यवस्थित करता है, इसलिए अतिरिक्त सरणी का उपयोग नहीं होता |

## कोड

```java
// इनपुट: बैठकों के समय अंतराल को दर्शाने वाली द्विआयामी पूर्णांक सरणी intervals (प्रत्येक तत्व [प्रारंभ समय, समाप्ति समय] है)
// आउटपुट: यदि सभी बैठकों में भाग लिया जा सकता है तो true, यदि अतिव्यापी बैठकें हैं तो false
public boolean canAttendMeetings(int[][] intervals) {
    // प्रारंभ समय के आरोही क्रम में अंतरालों को क्रमबद्ध करना
    // लैम्ब्डा व्यंजक (a, b) -> a[0] - b[0] को Comparator के रूप में पास करना
    // इससे समय क्रम में व्यवस्थित अंतरालों में केवल आसन्न जोड़ियों की तुलना करना पर्याप्त हो जाता है
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // i = 0 के बजाय i = 1 से शुरू करना। प्रत्येक चरण में intervals[i] और intervals[i-1] की आसन्न जोड़ी की तुलना करने के लिए
    for (int i = 1; i < intervals.length; i++) {
        // यदि वर्तमान बैठक का प्रारंभ समय पिछली बैठक के समाप्ति समय से पहले है, तो अतिव्यापन है
        if (intervals[i][0] < intervals[i - 1][1]) {
            // यदि एक भी अतिव्यापन हो, तो सभी बैठकों में भाग लेना संभव नहीं है, इसलिए तुरंत false लौटाना है
            return false;
        }
        // यदि अतिव्यापन नहीं है, तो अगली आसन्न जोड़ी की जाँच करना
    }
    // यदि लूप अंत तक पूर्ण हो गया, तो किसी भी आसन्न जोड़ी में अतिव्यापन नहीं था, इसलिए true लौटाना है
    return true;
}
```
