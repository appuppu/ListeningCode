# Finding the Smallest Interval Containing Each Query — प्रत्येक क्वेरी को शामिल करने वाला सबसे छोटा अंतराल खोजना

## समस्या का सार

2D पूर्णांक सरणी `intervals` (प्रत्येक तत्व `[left, right]` है) और पूर्णांक सरणी `queries` दी गई है। प्रत्येक क्वेरी मान को शामिल करने वाले अंतरालों में से **सबसे छोटे आकार वाला** अंतराल खोजना है। अंतराल का आकार `right - left + 1` से परिभाषित होता है। यदि क्वेरी को शामिल करने वाला कोई अंतराल मौजूद नहीं है तो `-1` लौटाना है।

## मुख्य विचार

क्वेरी और अंतराल दोनों को सॉर्ट करके, क्वेरी मान के छोटे क्रम में प्रसंस्करण करने से, प्रत्येक क्वेरी के लिए "बाएँ सिरे का मान क्वेरी से कम या बराबर वाले अंतराल" को क्रमशः Min-Heap में जोड़ा जा सकता है। Min-Heap से सबसे छोटे आकार वाला और दाएँ सिरे का मान क्वेरी से अधिक या बराबर वाला अंतराल निकालने पर वही उत्तर बनता है।

## विचार प्रक्रिया

1. **प्रत्येक क्वेरी के लिए सभी अंतरालों की जाँच करना अक्षम है**: प्रत्येक क्वेरी के लिए सभी अंतरालों को स्कैन करने पर O(n×q) समय लगता है। क्वेरी और अंतराल दोनों को सॉर्ट करने से, अंतराल जोड़ने की प्रक्रिया को सभी क्वेरी में साझा किया जा सकता है और दोहराव वाली स्कैनिंग को हटाया जा सकता है
2. **क्वेरी को आरोही क्रम में प्रसंस्करण करने से अंतराल जोड़ना एकदिशीय (monotone) हो जाता है**: अंतरालों को बाएँ सिरे से सॉर्ट करके और क्वेरी को मान के आरोही क्रम में सॉर्ट करने पर, क्वेरी मान बढ़ने के साथ "बाएँ सिरे का मान क्वेरी से कम या बराबर" की शर्त पूरी करने वाले अंतराल केवल बढ़ते हैं, कभी घटते नहीं। अर्थात अंतराल जोड़ना केवल पॉइंटर आगे बढ़ाने जैसी एकदिशीय क्रिया है
3. **जोड़े गए अंतरालों में से सबसे छोटा आकार तेज़ी से प्राप्त करना है**: उम्मीदवार अंतरालों में से सबसे छोटे आकार वाला निकालने के लिए Min-Heap (न्यूनतम हीप) उपयुक्त है। हीप की कुंजी को अंतराल आकार रखने पर, peek ऑपरेशन से O(1) में सबसे छोटे आकार का अंतराल प्राप्त किया जा सकता है
4. **दाएँ सिरे का मान क्वेरी मान से छोटा वाले अंतराल अमान्य हैं**: हीप में शेष अंतरालों में से, जिनका दायाँ सिरा क्वेरी मान से छोटा है, वे उस क्वेरी को शामिल नहीं करते। इन अंतरालों को हीप के शीर्ष से क्रमशः poll करके हटाया जाता है। एक बार हटाए गए अंतराल बाद की क्वेरी के लिए भी अमान्य रहते हैं (क्योंकि क्वेरी मान बढ़ता जाता है), इसलिए पुनः जोड़ने की आवश्यकता नहीं है
5. **क्वेरी के मूल क्रम को संरक्षित करना आवश्यक है**: क्वेरी को सॉर्ट करके प्रसंस्करण किया जाता है, लेकिन परिणाम मूल क्रम में लौटाना होता है। इसलिए सॉर्ट करने से पहले प्रत्येक क्वेरी के मूल इंडेक्स को जोड़ी के रूप में रखा जाता है, और परिणाम सरणी की संबंधित स्थिति पर उत्तर लिखा जाता है
6. **यदि हीप खाली है तो उस क्वेरी को शामिल करने वाला कोई अंतराल मौजूद नहीं है**: अमान्य अंतरालों को हटाने के बाद यदि हीप खाली है, तो उस क्वेरी को शामिल करने वाला कोई अंतराल नहीं है, इसलिए परिणाम में `-1` संग्रहित किया जाता है

## पूर्वापेक्षित ज्ञान

### PriorityQueue (Min-Heap) क्या है

यह एक डेटा संरचना है जो तत्वों को प्राथमिकता क्रम में प्रबंधित करती है। डिफ़ॉल्ट रूप से सबसे छोटा मान शीर्ष पर आता है (Min-Heap)। तत्व जोड़ना और निकालना O(log n) में होता है, और शीर्ष का संदर्भ O(1) में प्राप्त किया जा सकता है।

```java
// int[] को संग्रहित करने वाला Min-Heap जो सरणी के 0वें तत्व (आकार) के आरोही क्रम में व्यवस्थित करता है
PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
heap.offer(new int[]{5, 10});  // तत्व जोड़ता है
heap.peek();                    // शीर्ष तत्व को बिना निकाले संदर्भित करता है → {5, 10}
heap.poll();                    // शीर्ष तत्व को निकालकर हटाता है → {5, 10}
heap.isEmpty();                 // हीप खाली है या नहीं जाँचता है → true
```

### ऑफ़लाइन क्वेरी क्या है

यह एक तकनीक है जिसमें क्वेरी को आगमन क्रम के बजाय प्रसंस्करण के लिए सुविधाजनक क्रम में पुनर्व्यवस्थित करके प्रसंस्करण किया जाता है। परिणाम मूल इंडेक्स का उपयोग करके सही स्थिति पर वापस लिखे जाते हैं। यह तब प्रभावी होता है जब क्वेरी के बीच कोई निर्भरता नहीं होती।

```java
int q = queries.length;
int[][] sortedQ = new int[q][2];
for (int i = 0; i < q; i++) {
    sortedQ[i] = new int[]{queries[i], i};  // {क्वेरी मान, मूल इंडेक्स} की जोड़ी बनाता है
}
Arrays.sort(sortedQ, (a, b) -> a[0] - b[0]);  // क्वेरी मान के आरोही क्रम में सॉर्ट करता है
```

### Arrays.sort का कस्टम कंपैरेटर

2D सरणी या ऑब्जेक्ट सरणी को किसी भी मानदंड से सॉर्ट करता है। लैम्ब्डा एक्सप्रेशन `(a, b) -> a[0] - b[0]` का अर्थ है कि प्रत्येक तत्व के 0वें मान के आरोही क्रम में सॉर्ट करना।

```java
int[][] intervals = {{3, 6}, {1, 4}, {2, 8}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // बाएँ सिरे के आरोही क्रम में सॉर्ट करता है → {{1,4}, {2,8}, {3,6}}
```

## जटिलता

| | मान |
|---|---|
| Time | O(n log n + q log q) — अंतरालों को सॉर्ट करने में O(n log n), क्वेरी को सॉर्ट करने में O(q log q), हीप ऑपरेशन में प्रत्येक अंतराल अधिकतम 1 बार जोड़ा और 1 बार हटाया जाता है इसलिए O(n log n) |
| Space | O(n + q) — हीप में अधिकतम n अंतराल, सॉर्ट की गई क्वेरी सरणी में q तत्व संग्रहित होते हैं |

## कोड

```java
// इनपुट: 2D पूर्णांक सरणी intervals (प्रत्येक तत्व [left, right] है) और पूर्णांक सरणी queries
// आउटपुट: प्रत्येक क्वेरी को शामिल करने वाले सबसे छोटे आकार के अंतराल का आकार संग्रहित करने वाला int[] लौटाता है। यदि शामिल करने वाला कोई अंतराल नहीं है तो -1 संग्रहित करता है
public int[] minInterval(int[][] intervals, int[] queries) {
    // अंतरालों को बाएँ सिरे के आरोही क्रम में सॉर्ट करता है। ऐसा करने से पॉइंटर j को आगे बढ़ाने मात्र से "बाएँ सिरे का मान क्वेरी मान से कम या बराबर वाले अंतराल" बिना छूटे जोड़े जा सकते हैं
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    int q = queries.length;
    // प्रत्येक क्वेरी को मूल इंडेक्स के साथ जोड़ी बनाता है। सॉर्ट के बाद भी परिणाम को सही स्थिति पर लिखने के लिए आवश्यक है
    int[][] sortedQ = new int[q][2];
    for (int i = 0; i < q; i++) {
        sortedQ[i] = new int[]{queries[i], i};
    }
    // क्वेरी मान के आरोही क्रम में सॉर्ट करता है। आरोही क्रम में प्रसंस्करण करने से अंतराल जोड़ना एकदिशीय क्रिया बन जाती है
    Arrays.sort(sortedQ, (a, b) -> a[0] - b[0]);

    // {अंतराल आकार, दायाँ सिरा} रखने वाला Min-Heap जो आकार के आरोही क्रम में निकालता है। आकार को कुंजी रखने से सबसे छोटे आकार का अंतराल O(1) में संदर्भित किया जा सकता है
    PriorityQueue<int[]> heap =
        new PriorityQueue<>((a, b) -> a[0] - b[0]);

    int[] res = new int[q];
    int j = 0;  // अंतराल सरणी को स्कैन करने वाला पॉइंटर। सभी क्वेरी में यह केवल आगे बढ़ता है इसलिए अंतराल जोड़ने का कुल O(n) है

    for (int[] sq : sortedQ) {
        int val = sq[0], idx = sq[1];  // val=क्वेरी मान, idx=मूल इंडेक्स

        // बाएँ सिरे का मान क्वेरी मान से कम या बराबर वाले सभी अंतरालों को हीप में जोड़ता है। j पीछे नहीं जाता इसलिए कुल O(n) है
        while (j < intervals.length && intervals[j][0] <= val) {
            int sz = intervals[j][1] - intervals[j][0] + 1;  // अंतराल आकार = right - left + 1
            heap.offer(new int[]{sz, intervals[j][1]});  // {आकार, दायाँ सिरा} को हीप में जोड़ता है
            j++;
        }

        // दाएँ सिरे का मान क्वेरी मान से छोटा (क्वेरी को शामिल नहीं करने वाले) अंतरालों को हटाता है। क्वेरी मान आरोही क्रम में बढ़ता है इसलिए एक बार हटाया गया अंतराल बाद में भी अमान्य रहता है
        while (!heap.isEmpty() && heap.peek()[1] < val) {
            heap.poll();
        }

        // यदि हीप खाली है तो शामिल करने वाला कोई अंतराल नहीं है, अन्यथा शीर्ष का अंतराल आकार उत्तर है (अमान्य अंतराल हटाए जा चुके हैं इसलिए शीर्ष सबसे छोटा और मान्य है)
        res[idx] = heap.isEmpty() ? -1 : heap.peek()[0];
    }
    return res;
}
```
