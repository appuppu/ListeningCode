# Finding the Minimum Removals for Non-Overlapping Intervals — गैर-अतिव्यापी अंतरालों के लिए हटाने की न्यूनतम संख्या ज्ञात करना

## समस्या का सार

अंतरालों की एक सरणी `intervals` (प्रत्येक अंतराल `[start, end]` का जोड़ा है) दी गई है। शेष अंतराल एक-दूसरे से अतिव्यापी न हों, इसके लिए **हटाए जाने वाले अंतरालों की न्यूनतम संख्या** लौटानी है।

## मूल विचार

अंतरालों को समाप्ति समय के अनुसार क्रमबद्ध करें और पहले समाप्त होने वाले अंतराल को प्राथमिकता से बनाए रखें, तो बाद के अंतरालों से अतिव्यापन की संभावना न्यूनतम होती है। जब अतिव्यापन होता है, तो देर से समाप्त होने वाले अंतराल (= वर्तमान अंतराल) को हटाने से, हटाने की संख्या न्यूनतम की जा सकती है।

## विचार प्रक्रिया

1. **अतिव्यापन कम करने के लिए "कम स्थान घेरने वाले" अंतराल को प्राथमिकता से बनाए रखें**: जिस अंतराल का समाप्ति समय जितना पहले होता है, उसके बाद उतना अधिक खाली स्थान बचता है और बाद के अंतरालों से अतिव्यापन की संभावना कम होती है। इसलिए, अंतरालों को समाप्ति समय के आरोही क्रम में क्रमबद्ध करके, पहले समाप्त होने वाले अंतराल को लालची (greedy) विधि से चुनना इष्टतम है
2. **क्रमबद्ध करने के बाद, केवल अंतिम बनाए गए अंतराल के समाप्ति समय को ट्रैक करना पर्याप्त है**: समाप्ति समय से क्रमबद्ध होने के कारण, बनाए गए अंतरालों में से केवल अंतिम अंतराल का समाप्ति समय `lastEnd` याद रखने से, अगला अंतराल अतिव्यापी है या नहीं यह निर्धारित किया जा सकता है। यदि अगले अंतराल का प्रारंभ समय `lastEnd` से कम है, तो अतिव्यापन है
3. **अतिव्यापन होने पर वर्तमान अंतराल को हटाएं**: जब अतिव्यापन होता है, तो पिछले बनाए गए अंतराल और वर्तमान अंतराल में से किसे हटाना चाहिए। समाप्ति समय से क्रमबद्ध होने के कारण, वर्तमान अंतराल का समाप्ति समय पिछले अंतराल के समाप्ति समय के बराबर या अधिक है। देर से समाप्त होने वाले वर्तमान अंतराल को हटाने से बाद के अंतरालों पर प्रभाव कम होता है। इसलिए `removals` को बढ़ाएं और `lastEnd` को अपडेट न करें
4. **अतिव्यापन न होने पर वर्तमान अंतराल को बनाए रखें**: यदि वर्तमान अंतराल का प्रारंभ समय `lastEnd` के बराबर या अधिक है, तो अतिव्यापन नहीं है, इसलिए इस अंतराल को बनाए रखें। `lastEnd` को वर्तमान अंतराल के समाप्ति समय से अपडेट करें
5. **अंतिम रूप से लौटाया जाने वाला मान**: लूप समाप्त होने के बाद, `removals` (हटाए गए अंतरालों की संख्या) लौटाएं

## पूर्व-ज्ञान

### Arrays.sort का कस्टम कम्पेरेटर

`Arrays.sort` के दूसरे तर्क में लैम्ब्डा एक्सप्रेशन देकर, क्रमबद्ध करने का मानदंड अनुकूलित किया जा सकता है। `(a, b) -> a[1] - b[1]` प्रत्येक अंतराल के समाप्ति समय (इंडेक्स 1 का तत्व) के आधार पर आरोही क्रम में क्रमबद्ध करता है।

```java
int[][] intervals = {{1,3}, {2,4}, {0,2}};
Arrays.sort(intervals, (a, b) -> a[1] - b[1]);
// परिणाम: {{0,2}, {1,3}, {2,4}} — समाप्ति समय के आरोही क्रम में व्यवस्थित
```

### लालची विधि (Greedy) क्या है

प्रत्येक चरण में "उस समय सबसे अच्छा विकल्प" चुनकर, संपूर्ण इष्टतम समाधान प्राप्त करने की विधि। इस समस्या में "सबसे पहले समाप्त होने वाले अंतराल को प्राथमिकता से बनाए रखना" यह स्थानीय चयन, समग्र रूप से हटाने की संख्या को न्यूनतम करने में सहायक होता है।

```java
// लालची विधि का सामान्य पैटर्न: क्रमबद्ध करके शुरुआत से क्रमशः इष्टतम चयन करना
Arrays.sort(data, comparator);  // मानदंड से क्रमबद्ध करें
for (int i = 0; i < data.length; i++) {
    // शर्त पूरी हो तो चयन करें, न हो तो छोड़ें
}
```

## जटिलता

| | मान |
|---|---|
| Time | O(n log n) — क्रमबद्ध करने में O(n log n) और स्कैनिंग में O(n) लगता है, क्रमबद्ध करना प्रमुख है |
| Space | O(1) — क्रमबद्ध करने के आंतरिक स्थान को छोड़कर, कोई अतिरिक्त डेटा संरचना उपयोग नहीं होती |

## कोड

```java
// इनपुट: अंतरालों की सरणी int[][] intervals (प्रत्येक तत्व [start, end] है)
// आउटपुट: अतिव्यापन हटाने के लिए हटाए जाने वाले अंतरालों की न्यूनतम संख्या int के रूप में लौटाएं
int eraseOverlapIntervals(int[][] intervals) {
    // यदि अंतरालों की संख्या 0 है तो हटाने की आवश्यकता नहीं
    if (intervals.length == 0)
        return 0;

    // समाप्ति समय के आरोही क्रम में क्रमबद्ध करें (पहले समाप्त होने वाले अंतराल को प्राथमिकता से बनाए रखने के लिए)
    // लालची विधि: पहले समाप्त होने वाला अंतराल बाद के अंतरालों से कम अतिव्यापी होता है, इसलिए पहले बनाए रखना इष्टतम है
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);

    // हटाए गए अंतरालों की संख्या दर्ज करने वाला चर
    int removals = 0;
    // क्रमबद्ध करने के बाद पहला अंतराल हमेशा बनाए रखें (सबसे पहले समाप्त होने के कारण)। उसका समाप्ति समय दर्ज करें
    int lastEnd = intervals[0][1];

    // इंडेक्स 1 से स्कैन करें (0वां अंतराल पहले से बनाए रखने के लिए निश्चित है)
    for (int i = 1; i < intervals.length; i++) {
        // यदि वर्तमान अंतराल का प्रारंभ समय lastEnd से कम है, तो पिछले बनाए गए अंतराल से अतिव्यापन है
        if (intervals[i][0] < lastEnd) {
            // वर्तमान अंतराल को हटाएं। समाप्ति समय से क्रमबद्ध होने के कारण वर्तमान अंतराल का समाप्ति lastEnd के बराबर या अधिक है,
            // देर से समाप्त होने वाले वर्तमान अंतराल को हटाने से बाद के अतिव्यापन कम होते हैं। lastEnd अपडेट न करें
            removals++;
        } else {
            // अतिव्यापन नहीं है इसलिए वर्तमान अंतराल को बनाए रखें, lastEnd को वर्तमान अंतराल के समाप्ति समय से अपडेट करें
            // अगले अंतराल से अतिव्यापन की जांच इस नए lastEnd के आधार पर होगी
            lastEnd = intervals[i][1];
        }
    }
    // removals अतिव्यापन हटाने के लिए हटाए जाने वाले अंतरालों की न्यूनतम संख्या है
    return removals;
}
```
