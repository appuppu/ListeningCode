# Finding the Minimum Meeting Rooms Required — सभी बैठकों को बिना टकराव के आयोजित करने के लिए आवश्यक न्यूनतम बैठक कक्षों की संख्या ज्ञात करना

## समस्या का सार

बैठकों के समय अंतराल (प्रारंभ समय और समाप्ति समय) की एक सरणी दी गई है। सभी बैठकों को बिना टकराव के आयोजित करने के लिए आवश्यक **न्यूनतम बैठक कक्षों की संख्या** लौटानी है। एक ही समय अंतराल में ओवरलैप होने वाली बैठकों को अलग-अलग बैठक कक्षों का उपयोग करना आवश्यक है।

## मूल विचार

बैठकों के प्रारंभ और समाप्ति को अलग-अलग घटनाओं के रूप में समय क्रम में संसाधित करने पर, किसी भी क्षण में एक साथ चल रही बैठकों की अधिकतम संख्या ज्ञात हो जाती है। वह अधिकतम संख्या ही आवश्यक बैठक कक्षों की संख्या है।

## विचार प्रक्रिया

1. **एक साथ चल रही बैठकों की संख्या ही उत्तर है**: किसी भी क्षण में एक साथ चल रही बैठकों की अधिकतम संख्या = आवश्यक बैठक कक्षों की संख्या। समस्या "एक साथ चल रही बैठकों की अधिकतम संख्या" को कुशलतापूर्वक ज्ञात करने में सिमट जाती है
2. **प्रारंभ और समाप्ति को अलग-अलग घटनाओं के रूप में मानना**: बैठक प्रारंभ होने पर एक कक्ष आवश्यक होता है, और समाप्ति पर एक कक्ष खाली होता है। प्रारंभ और समाप्ति को अलग करके प्रत्येक को सॉर्ट करने पर, समय क्रम में घटनाओं को संसाधित किया जा सकता है
3. **दो सॉर्ट की गई सरणियों को स्वीप करना**: starts सरणी और ends सरणी को अलग-अलग सॉर्ट करके, starts को शुरू से स्कैन करना है। प्रत्येक प्रारंभ समय के लिए "क्या यह सबसे पहले समाप्त होने वाली बैठक से पहले है" का निर्णय करने पर, कक्ष की आवश्यकता या उपलब्धता ज्ञात होती है
4. **2 पॉइंटर से एक साथ चल रही बैठकों की संख्या को ट्रैक करना**: starts सरणी के लिए पॉइंटर `i` और ends सरणी के लिए पॉइंटर `endPtr` तैयार करना है। यदि `starts[i] < ends[endPtr]` है तो नई बैठक मौजूदा बैठक के साथ ओवरलैप होती है इसलिए कक्ष जोड़ना है। अन्यथा एक बैठक समाप्त हो चुकी है और कक्ष खाली हो गया है इसलिए `endPtr` को आगे बढ़ाना है
5. **अधिकतम मान को रिकॉर्ड करना**: स्कैन की प्रक्रिया में `rooms` के अधिकतम मान को `maxRooms` में रिकॉर्ड करते रहना है। स्कैन पूर्ण होने पर `maxRooms` लौटाना है

## पूर्व ज्ञान

### Arrays.sort क्या है

सरणी को आरोही क्रम में सॉर्ट करने वाली Java की मानक विधि है। प्रिमिटिव प्रकार की सरणी के लिए ड्यूअल-पिवट क्विकसॉर्ट (O(n log n)) का उपयोग करती है।

```java
int[] arr = {5, 2, 8, 1};
Arrays.sort(arr);        // arr {1, 2, 5, 8} बन जाता है
```

### 2 पॉइंटर (Two Pointer) क्या है

दो इंडेक्स चरों का उपयोग करके, प्रत्येक को स्वतंत्र रूप से सरणी में स्कैन करने की तकनीक है। सॉर्ट की गई सरणी पर उपयोग करने से, दो सरणियों के तत्वों की कुशलतापूर्वक तुलना और मर्ज की जा सकती है।

```java
int i = 0;          // पहली सरणी के लिए पॉइंटर
int endPtr = 0;     // दूसरी सरणी के लिए पॉइंटर
// शर्त के अनुसार किस पॉइंटर को आगे बढ़ाना है यह निर्णय करना है
```

### इवेंट स्वीप (Event Sweep) क्या है

समय अक्ष पर घटनाओं (प्रारंभ और समाप्ति) को समय क्रम में संसाधित करके, किसी समय बिंदु पर स्थिति (एक साथ चल रही संख्या आदि) को ट्रैक करने की विधि है। प्रारंभ घटना पर काउंटर बढ़ाना और समाप्ति घटना पर काउंटर घटाने से, किसी भी क्षण में एक साथ चल रही संख्या ज्ञात होती है।

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n log n) — दो सरणियों का सॉर्ट प्रमुख है |
| Space | O(n) — प्रारंभ समय और समाप्ति समय को संग्रहित करने वाली दो सरणियाँ बनाई जाती हैं |

## कोड

```java
// इनपुट: बैठकों के समय अंतराल को दर्शाने वाली 2D पूर्णांक सरणी intervals (प्रत्येक तत्व [start, end] है)
// आउटपुट: सभी बैठकों को बिना टकराव के आयोजित करने के लिए आवश्यक न्यूनतम बैठक कक्षों की संख्या int के रूप में लौटाना है
public int minMeetingRooms(int[][] intervals) {
    // यदि इनपुट null या खाली है, तो कोई बैठक नहीं है इसलिए 0 लौटाना है
    if (intervals == null || intervals.length == 0)
        return 0;

    int n = intervals.length;
    // प्रारंभ और समाप्ति को अलग करने से, प्रत्येक को स्वतंत्र रूप से सॉर्ट किया जा सकता है
    int[] starts = new int[n];  // प्रारंभ समय संग्रहित करने वाली सरणी
    int[] ends = new int[n];    // समाप्ति समय संग्रहित करने वाली सरणी

    // intervals को स्कैन करके, प्रारंभ समय और समाप्ति समय को अलग-अलग सरणियों में संग्रहित करना है
    for (int i = 0; i < n; i++) {
        starts[i] = intervals[i][0];
        ends[i] = intervals[i][1];
    }

    // दोनों सरणियों को आरोही क्रम में सॉर्ट करके, समय क्रम में घटनाओं को संसाधित करने की तैयारी करना है
    Arrays.sort(starts);
    Arrays.sort(ends);

    int rooms = 0, maxRooms = 0;
    // ends सरणी का पॉइंटर। सबसे पहले समाप्त होने वाली बैठक को इंगित करता है
    int endPtr = 0;

    // starts सरणी को शुरू से स्कैन करना है। प्रत्येक इटरेशन "एक नई बैठक प्रारंभ होती है" घटना को दर्शाता है
    for (int i = 0; i < n; i++) {
        if (starts[i] < ends[endPtr]) {
            // वर्तमान में शुरू होने वाली बैठक का प्रारंभ समय, सबसे पहले समाप्त होने वाली बैठक के समाप्ति समय से पहले है → ओवरलैप होता है इसलिए एक नया कक्ष आवंटित करना है
            rooms++;
        } else {
            // सबसे पहले समाप्त होने वाली बैठक पहले ही समाप्त हो चुकी है, इसलिए उस कक्ष का पुन: उपयोग किया जा सकता है। कक्ष संख्या नहीं बढ़ानी है और endPtr को आगे बढ़ाकर अगली जल्दी समाप्त होने वाली बैठक को इंगित करना है
            endPtr++;
        }
        // एक साथ उपयोग किए जा रहे अधिकतम कक्षों की संख्या को अपडेट करना है
        maxRooms = Math.max(maxRooms, rooms);
    }
    // maxRooms एक साथ उपयोग किए गए कक्षों की अधिकतम संख्या है, और यही आवश्यक न्यूनतम बैठक कक्षों की संख्या है
    return maxRooms;
}
```
