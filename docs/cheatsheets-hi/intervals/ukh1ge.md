# Inserting a New Interval Into a Sorted List — क्रमबद्ध गैर-अतिव्यापी अंतरालों की सूची में एक नया अंतराल सम्मिलित करना और मर्ज करना

## समस्या का सार

क्रमबद्ध और परस्पर गैर-अतिव्यापी अंतरालों की एक सूची `intervals` और एक नया अंतराल `newInterval` दिया गया है। `newInterval` को सही स्थान पर सम्मिलित करें, यदि कोई अतिव्यापी अंतराल हो तो उन सभी को मर्ज करें, और परिणामस्वरूप एक गैर-अतिव्यापी अंतरालों की सूची लौटाएँ।

## मूल विचार

क्रमबद्ध अंतराल सूची को बाएँ से स्कैन करने पर, प्रत्येक अंतराल तीन समूहों में विभाजित होता है: "नए अंतराल से पूरी तरह पहले", "नए अंतराल से अतिव्यापी", और "नए अंतराल से पूरी तरह बाद में"। इन तीन चरणों को क्रम से संसाधित करने पर, एक ही स्कैन में सम्मिलन और मर्ज पूरा हो जाता है।

## विचार प्रक्रिया

1. **अंतरालों की स्थिति के केवल 3 पैटर्न होते हैं**: क्रमबद्ध सूची के प्रत्येक अंतराल को newInterval से तुलना करने पर "पूरी तरह पहले", "अतिव्यापी", या "पूरी तरह बाद में" में वर्गीकृत किया जा सकता है। इस वर्गीकरण का उपयोग करके, सूची को केवल एक बार स्कैन करके संसाधित किया जा सकता है
2. **"पूरी तरह पहले" की निर्णय शर्त**: यदि मौजूदा अंतराल का अंतिम बिंदु `intervals[i][1]` newInterval के प्रारंभ बिंदु `newInterval[0]` से छोटा है, तो वह अंतराल newInterval से अतिव्यापी नहीं है। इस शर्त को पूरा करने वाले अंतरालों को सीधे परिणाम में जोड़ा जाता है
3. **"अतिव्यापी" की निर्णय शर्त**: यदि मौजूदा अंतराल का प्रारंभ बिंदु `intervals[i][0]` newInterval के अंतिम बिंदु `newInterval[1]` से कम या बराबर है, तो वह अंतराल newInterval से अतिव्यापी है। अतिव्यापी अंतराल मिलने पर हर बार, newInterval के प्रारंभ और अंतिम बिंदुओं को अपडेट करके मर्ज सीमा को विस्तारित किया जाता है
4. **मर्ज की विधि**: अतिव्यापी अंतराल के प्रारंभ बिंदु और newInterval के प्रारंभ बिंदु में से छोटे को नया प्रारंभ बिंदु बनाया जाता है, और अतिव्यापी अंतराल के अंतिम बिंदु और newInterval के अंतिम बिंदु में से बड़े को नया अंतिम बिंदु बनाया जाता है। इससे कई अतिव्यापी अंतरालों को एक अंतराल में समेकित किया जा सकता है
5. **मर्ज परिणाम जोड़ने का समय**: जब अतिव्यापी अंतराल समाप्त हो जाएँ, तब मर्ज किए गए newInterval को परिणाम में जोड़ा जाता है। उसके बाद के सभी अंतराल newInterval से बाद में होते हैं, इसलिए उन्हें सीधे परिणाम में जोड़ा जाता है
6. **अंतिम रूप से लौटाई जाने वाली चीज़**: तीन चरणों में निर्मित परिणाम सूची को `int[][]` में बदलकर लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### ArrayList क्या है

यह एक परिवर्तनीय लंबाई वाली सरणी है। `add()` से O(1) (परिशोधित) में तत्व जोड़े जा सकते हैं, और अंत में इसे निश्चित लंबाई वाली सरणी में बदला जा सकता है। इसका उपयोग तब किया जाता है जब परिणाम का आकार पहले से ज्ञात न हो।

```java
List<int[]> res = new ArrayList<>();   // खाली ArrayList बनाएँ
res.add(new int[]{1, 3});              // तत्व को अंत में जोड़ें
res.toArray(new int[0][]);             // int[][] प्रकार की सरणी में बदलें
```

### Math.min / Math.max क्या है

ये दो मानों में से छोटा या बड़ा मान लौटाने वाली विधियाँ हैं। अंतरालों को मर्ज करते समय प्रारंभ और अंतिम बिंदु निर्धारित करने के लिए इनका उपयोग किया जाता है।

```java
Math.min(1, 3);   // → 1（छोटा मान लौटाता है）
Math.max(1, 3);   // → 3（बड़ा मान लौटाता है）
```

### अंतरालों की अतिव्यापन जाँच

दो अंतराल `[a, b]` और `[c, d]` अतिव्यापी हैं या नहीं, यह `a <= d && c <= b` से जाँचा जा सकता है। इस समस्या में सूची क्रमबद्ध होने के कारण, केवल एक शर्त से ही पर्याप्त रूप से निर्णय लिया जा सकता है।

```java
// मौजूदा अंतराल newInterval से पूरी तरह पहले है (अतिव्यापी नहीं)
intervals[i][1] < newInterval[0]   // मौजूदा अंतराल का अंतिम बिंदु < नए अंतराल का प्रारंभ बिंदु

// मौजूदा अंतराल newInterval से अतिव्यापी है
intervals[i][0] <= newInterval[1]  // मौजूदा अंतराल का प्रारंभ बिंदु <= नए अंतराल का अंतिम बिंदु
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n) — अंतराल सूची को केवल एक बार स्कैन करना पड़ता है |
| Space | O(n) — परिणाम सूची में अधिकतम n+1 अंतराल संग्रहीत होते हैं |

## कोड

```java
// इनपुट: क्रमबद्ध गैर-अतिव्यापी अंतराल सूची intervals (int[][]) और नया अंतराल newInterval (int[])
// आउटपुट: newInterval को सम्मिलित और मर्ज करने के बाद गैर-अतिव्यापी अंतराल सूची int[][] के रूप में लौटाएँ
public int[][] insert(int[][] intervals, int[] newInterval) {
    // परिणाम संग्रहीत करने वाली सूची। आकार पहले से ज्ञात नहीं है इसलिए ArrayList का उपयोग करें
    List<int[]> res = new ArrayList<>();
    // स्कैन स्थिति को ट्रैक करने वाला चर
    int i = 0;
    // अंतरालों की कुल संख्या को चर में रखें ताकि लूप शर्त में हर बार .length संदर्भित न करना पड़े
    int n = intervals.length;

    // चरण 1: newInterval से पूरी तरह पहले वाले अंतरालों को सीधे जोड़ें
    // निर्णय शर्त: मौजूदा अंतराल का अंतिम बिंदु < newInterval का प्रारंभ बिंदु तो अतिव्यापी नहीं
    while (i < n && intervals[i][1] < newInterval[0]) {
        res.add(intervals[i]);
        i++;
    }

    // चरण 2: newInterval से अतिव्यापी सभी अंतरालों को मर्ज करें
    // निर्णय शर्त: मौजूदा अंतराल का प्रारंभ बिंदु <= newInterval का अंतिम बिंदु तो अतिव्यापी है
    while (i < n && intervals[i][0] <= newInterval[1]) {
        // प्रारंभ बिंदु में छोटा मान लें (newInterval की बाईं सीमा को अतिव्यापी अंतराल की बाईं सीमा तक विस्तारित करें)
        newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
        // अंतिम बिंदु में बड़ा मान लें (newInterval की दाईं सीमा को अतिव्यापी अंतराल की दाईं सीमा तक विस्तारित करें)
        newInterval[1] = Math.max(newInterval[1], intervals[i][1]);
        i++;
    }
    // मर्ज किए गए newInterval को परिणाम में जोड़ें (भले ही अतिव्यापी अंतराल 0 हों, इसे सीधे जोड़ा जाता है)
    res.add(newInterval);

    // चरण 3: newInterval से पूरी तरह बाद वाले अंतरालों को सीधे जोड़ें (मर्ज अनावश्यक)
    while (i < n) {
        res.add(intervals[i]);
        i++;
    }

    // ArrayList को int[][] में बदलकर लौटाएँ। new int[0][] प्रकार जानकारी देने के लिए एक खाली सरणी है
    return res.toArray(new int[0][]);
}
```
