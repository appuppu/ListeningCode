# Inserting a New Interval Into a Sorted List — क्रमबद्ध गैर-अतिव्यापी अंतराल सूची में नया अंतराल सम्मिलित करना और मर्ज करना

## समस्या का सार

क्रमबद्ध और परस्पर गैर-अतिव्यापी अंतरालों की सूची `intervals` और एक नया अंतराल `newInterval` दिया गया है। `newInterval` को सही स्थान पर सम्मिलित करें, यदि कोई अतिव्यापी अंतराल हो तो उन सभी को मर्ज करें, और परिणामस्वरूप गैर-अतिव्यापी अंतरालों की सूची लौटाएं।

## मूल विचार

क्रमबद्ध अंतराल सूची को बाएं से स्कैन करने पर, प्रत्येक अंतराल तीन समूहों में बंटता है: "नए अंतराल से पूर्णतः पहले", "नए अंतराल से अतिव्यापी", और "नए अंतराल से पूर्णतः बाद"। इन तीन चरणों को क्रम से संसाधित करने पर, एक ही स्कैन में सम्मिलन और मर्ज पूरा हो जाता है।

## विचार प्रक्रिया

1. **अंतरालों की स्थिति संबंध केवल 3 प्रकार के होते हैं**: क्रमबद्ध सूची के प्रत्येक अंतराल को newInterval से तुलना करने पर "पूर्णतः पहले", "अतिव्यापी", या "पूर्णतः बाद" में वर्गीकृत किया जा सकता है। इस वर्गीकरण का उपयोग करने पर, सूची को केवल एक बार स्कैन करके संसाधित किया जा सकता है
2. **"पूर्णतः पहले" की निर्णय शर्त**: यदि मौजूदा अंतराल का अंतिम बिंदु `intervals[i][1]` newInterval के प्रारंभ बिंदु `newInterval[0]` से छोटा है, तो वह अंतराल newInterval से अतिव्यापी नहीं है। इस शर्त को पूरा करने वाले अंतरालों को सीधे परिणाम में जोड़ा जाता है
3. **"अतिव्यापी" की निर्णय शर्त**: यदि मौजूदा अंतराल का प्रारंभ बिंदु `intervals[i][0]` newInterval के अंतिम बिंदु `newInterval[1]` से कम या बराबर है, तो वह अंतराल newInterval से अतिव्यापी है। अतिव्यापी अंतराल मिलने पर हर बार newInterval के प्रारंभ और अंतिम बिंदु को अपडेट करके मर्ज सीमा का विस्तार किया जाता है
4. **मर्ज की विधि**: अतिव्यापी अंतराल के प्रारंभ बिंदु और newInterval के प्रारंभ बिंदु में से छोटा मान नया प्रारंभ बिंदु बनता है, और अतिव्यापी अंतराल के अंतिम बिंदु और newInterval के अंतिम बिंदु में से बड़ा मान नया अंतिम बिंदु बनता है। इससे कई अतिव्यापी अंतरालों को एक अंतराल में समेकित किया जा सकता है
5. **मर्ज परिणाम जोड़ने का समय**: जब अतिव्यापी अंतराल समाप्त हो जाएं, उस समय मर्ज किए गए newInterval को परिणाम में जोड़ा जाता है। उसके बाद के सभी अंतराल newInterval से बाद में होते हैं, इसलिए उन्हें सीधे परिणाम में जोड़ा जाता है
6. **अंतिम रूप से लौटाया जाने वाला परिणाम**: तीन चरणों में निर्मित परिणाम सूची को `int[][]` में रूपांतरित करके लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### ArrayList क्या है

परिवर्तनीय लंबाई की सरणी है। `add()` से O(1) (परिशोधित) में तत्व जोड़े जा सकते हैं, और अंत में निश्चित लंबाई की सरणी में रूपांतरित किया जा सकता है। जब परिणाम का आकार पहले से ज्ञात न हो, तब इसका उपयोग किया जाता है।

```java
List<int[]> res = new ArrayList<>();   // खाली ArrayList बनाएं
res.add(new int[]{1, 3});              // तत्व को अंत में जोड़ें
res.toArray(new int[0][]);             // int[][] प्रकार की सरणी में रूपांतरित करें
```

### Math.min / Math.max क्या है

दो मानों में से छोटा या बड़ा मान लौटाने वाली विधि है। अंतरालों को मर्ज करते समय प्रारंभ और अंतिम बिंदु निर्धारित करने में इसका उपयोग किया जाता है।

```java
Math.min(1, 3);   // → 1（छोटा मान लौटाता है）
Math.max(1, 3);   // → 3（बड़ा मान लौटाता है）
```

### अंतराल की अतिव्यापन जांच

दो अंतरालों `[a, b]` और `[c, d]` के अतिव्यापी होने की जांच `a <= d && c <= b` से की जा सकती है। इस समस्या में सूची क्रमबद्ध होने के कारण, केवल एक शर्त से ही पर्याप्त रूप से जांच की जा सकती है।

```java
// मौजूदा अंतराल newInterval से पूर्णतः पहले है (अतिव्यापी नहीं)
intervals[i][1] < newInterval[0]   // मौजूदा अंतराल का अंतिम बिंदु < नए अंतराल का प्रारंभ बिंदु

// मौजूदा अंतराल newInterval से अतिव्यापी है
intervals[i][0] <= newInterval[1]  // मौजूदा अंतराल का प्रारंभ बिंदु <= नए अंतराल का अंतिम बिंदु
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n) — अंतराल सूची को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(n) — परिणाम सूची में अधिकतम n+1 अंतराल संग्रहीत होते हैं |

## कोड

```java
// इनपुट: क्रमबद्ध गैर-अतिव्यापी अंतराल सूची intervals (int[][]) और नया अंतराल newInterval (int[])
// आउटपुट: newInterval को सम्मिलित और मर्ज करने के बाद गैर-अतिव्यापी अंतराल सूची int[][] में लौटाएं
public int[][] insert(int[][] intervals, int[] newInterval) {
    // परिणाम संग्रहीत करने के लिए परिवर्तनीय लंबाई की सूची। आकार पहले से अज्ञात होने के कारण ArrayList का उपयोग किया जाता है
    List<int[]> res = new ArrayList<>();
    // स्कैन स्थिति को ट्रैक करने वाला चर
    int i = 0;
    // अंतरालों की कुल संख्या को चर में संग्रहीत करें ताकि लूप शर्त में बार-बार संदर्भित किया जा सके
    int n = intervals.length;

    // चरण 1: newInterval से पूर्णतः पहले वाले अंतरालों को सीधे जोड़ें
    // शर्त: मौजूदा अंतराल का अंतिम बिंदु < newInterval का प्रारंभ बिंदु → अतिव्यापी नहीं
    while (i < n && intervals[i][1] < newInterval[0]) {
        res.add(intervals[i]);
        i++;
    }

    // चरण 2: newInterval से अतिव्यापी सभी अंतरालों को मर्ज करें
    // शर्त: मौजूदा अंतराल का प्रारंभ बिंदु <= newInterval का अंतिम बिंदु → अतिव्यापी है
    while (i < n && intervals[i][0] <= newInterval[1]) {
        // प्रारंभ बिंदु में छोटा मान लें (मर्ज सीमा बाईं ओर विस्तारित हो सकती है)
        newInterval[0] = Math.min(newInterval[0], intervals[i][0]);
        // अंतिम बिंदु में बड़ा मान लें (मर्ज सीमा दाईं ओर विस्तारित हो सकती है)
        newInterval[1] = Math.max(newInterval[1], intervals[i][1]);
        i++;
    }
    // मर्ज किए गए newInterval को परिणाम में जोड़ें (यदि अतिव्यापी अंतराल 0 हों तो भी सीधे जोड़ा जाता है)
    res.add(newInterval);

    // चरण 3: newInterval से पूर्णतः बाद वाले अंतरालों को सीधे जोड़ें (मर्ज आवश्यक नहीं)
    while (i < n) {
        res.add(intervals[i]);
        i++;
    }

    // ArrayList को int[][] में रूपांतरित करके लौटाएं। new int[0][] toArray के लिए प्रकार संकेत है
    return res.toArray(new int[0][]);
}
```
