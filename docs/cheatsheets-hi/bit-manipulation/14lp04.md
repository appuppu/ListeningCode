# Reversing the Digits of an Integer — 32-बिट साइन्ड पूर्णांक के प्रत्येक अंक को उलटना

## समस्या का सार

32-बिट साइन्ड पूर्णांक `x` दिया गया है। `x` के प्रत्येक अंक को उलटे क्रम में पुनर्व्यवस्थित करके प्राप्त पूर्णांक लौटाएँ। यदि उलटने के बाद का मान 32-बिट साइन्ड पूर्णांक की सीमा (-2³¹ से 2³¹-1) से बाहर हो, तो `0` लौटाएँ।

## मूल विचार

पूर्णांक के अंतिम अंक को `x % 10` द्वारा निकाला जा सकता है, और `x / 10` द्वारा अंतिम अंक को हटाया जा सकता है। इस "निकालकर जमा करने" की क्रिया को दोहराने पर अंक स्वाभाविक रूप से उलटे क्रम में आ जाते हैं। जमा करते समय हर बार ओवरफ़्लो की पूर्व-जाँच करने से उलटा परिणाम सुरक्षित रूप से बनाया जा सकता है।

## विचार प्रक्रिया

1. **अंकों को एक-एक करके निकालने की विधि**: पूर्णांक का अंतिम अंक `x % 10` (10 से भाग देने पर शेषफल) द्वारा प्राप्त किया जा सकता है। प्राप्त करने के बाद `x / 10` द्वारा अंतिम अंक को हटा दें, जिससे अगले अंक तक पहुँचा जा सके। इस क्रिया को `x` शून्य होने तक दोहराने पर सभी अंक अंतिम से क्रमशः निकाले जा सकते हैं
2. **निकाले गए अंकों को उलटे क्रम में जोड़ने की विधि**: परिणाम चर `result` पर `result = result * 10 + digit` को दोहराएँ। `result * 10` मौजूदा अंकों को एक स्थान बाईं ओर खिसकाता है, और `+ digit` नए अंक को इकाई स्थान पर जोड़ता है। अंतिम से निकाले गए अंकों को आरंभ से क्रमशः रखा जाता है, इसलिए अंकों का क्रम स्वाभाविक रूप से उलट जाता है
3. **ओवरफ़्लो से निपटना**: `result * 10 + digit` का गणना परिणाम `Integer.MAX_VALUE` (2147483647) से अधिक हो सकता है, या `Integer.MIN_VALUE` (-2147483648) से कम हो सकता है। गुणन करने के **बाद** जाँच करना बहुत देर हो जाती है, इसलिए गुणन से **पहले** जाँच करना आवश्यक है
4. **ओवरफ़्लो की पूर्व-जाँच विधि**: `result * 10` ओवरफ़्लो होगा या नहीं, यह `result` की `Integer.MAX_VALUE / 10` (= 214748364) से तुलना करके निर्धारित किया जा सकता है। यदि `result > 214748364` है तो निश्चित रूप से ओवरफ़्लो होगा। यदि `result == 214748364` है, तो `digit > 7` (MAX_VALUE का इकाई अंक) होने पर ओवरफ़्लो होगा। ऋणात्मक स्थिति में भी इसी प्रकार `Integer.MIN_VALUE / 10` से तुलना की जाती है
5. **चिह्न (साइन) का प्रबंधन**: Java में `x % 10` और `x / 10` ऋणात्मक संख्याओं पर भी सही ढंग से कार्य करते हैं (`-123 % 10 == -3`, `-123 / 10 == -12`)। इसलिए चिह्न को अलग किए बिना सीधे प्रसंस्करण किया जा सकता है
6. **अंत में क्या लौटाना है**: लूप समाप्त होने के बाद `result` उलटा किया हुआ पूर्णांक है। यदि ओवरफ़्लो का पता चलता है तो लूप के अंदर तुरंत `0` लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### % ऑपरेटर (शेषफल ऑपरेटर) क्या है

यह ऑपरेटर एक पूर्णांक को दूसरे पूर्णांक से भाग देने पर शेषफल लौटाता है। `x % 10` `x` के इकाई स्थान का अंक निकालता है। Java में ऋणात्मक संख्याओं पर भी चिह्न संरक्षित रहता है।

```java
123 % 10;    // → 3 (इकाई स्थान का अंक प्राप्त करें)
-123 % 10;   // → -3 (ऋणात्मक संख्या में भी चिह्न संरक्षित रहता है)
123 / 10;    // → 12 (इकाई स्थान का अंक हटाएँ)
-123 / 10;   // → -12 (ऋणात्मक संख्या में भी सही ढंग से छोटा किया जाता है)
```

### 32-बिट साइन्ड पूर्णांक की सीमा

Java के `int` प्रकार द्वारा प्रदर्शित की जा सकने वाली मानों की सीमा। इस सीमा से बाहर जाने पर ओवरफ़्लो होता है और अमान्य मान उत्पन्न होता है।

```java
Integer.MAX_VALUE;   // → 2147483647 (2³¹ - 1)
Integer.MIN_VALUE;   // → -2147483648 (-2³¹)
Integer.MAX_VALUE / 10;  // → 214748364 (ओवरफ़्लो निर्धारण की सीमा)
Integer.MAX_VALUE % 10;  // → 7 (MAX_VALUE का इकाई अंक)
Integer.MIN_VALUE / 10;  // → -214748364
Integer.MIN_VALUE % 10;  // → -8 (MIN_VALUE का इकाई अंक)
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n) — n `x` के अंकों की संख्या है। प्रत्येक अंक को एक बार प्रसंस्कृत किया जाता है |
| Space | O(1) — केवल `result` और `digit` चरों का उपयोग किया जाता है |

## कोड

```java
// इनपुट: 32-बिट साइन्ड पूर्णांक x
// आउटपुट: x के प्रत्येक अंक को उलटा किया हुआ पूर्णांक लौटाएँ। यदि उलटने के बाद का मान 32-बिट सीमा से बाहर हो तो 0 लौटाएँ
public int reverse(int x) {
    // उलटे परिणाम को संग्रहीत करने वाला चर। अंकों को एक-एक करके जमा किया जाता है
    int result = 0;

    // x के अंकों को अंतिम से एक-एक करके निकालकर प्रसंस्कृत करें। x शून्य होने पर सभी अंकों का प्रसंस्करण पूर्ण होता है
    while (x != 0) {
        // x का इकाई अंक निकालें। ऋणात्मक संख्या में भी % चिह्न संरक्षित करता है इसलिए विशेष प्रसंस्करण अनावश्यक है
        int digit = x % 10;

        // धनात्मक ओवरफ़्लो की पूर्व-जाँच करें (गुणन के बाद बहुत देर हो जाती है इसलिए पहले जाँचें)
        // यदि result > 214748364 तो result * 10 निश्चित रूप से MAX_VALUE(2147483647) से अधिक होगा
        // यदि result == 214748364 और digit > 7 तो result * 10 + digit MAX_VALUE(अंतिम अंक 7) से अधिक होगा
        if (result > Integer.MAX_VALUE / 10
                || (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return 0;
        }

        // ऋणात्मक ओवरफ़्लो की पूर्व-जाँच करें
        // यदि result < -214748364 तो result * 10 निश्चित रूप से MIN_VALUE(-2147483648) से कम होगा
        // यदि result == -214748364 और digit < -8 तो result * 10 + digit MIN_VALUE(अंतिम अंक -8) से कम होगा
        if (result < Integer.MIN_VALUE / 10
                || (result == Integer.MIN_VALUE / 10 && digit < -8)) {
            return 0;
        }

        // result * 10 मौजूदा अंकों को एक स्थान बाईं ओर खिसकाता है, और + digit निकाले गए अंक को इकाई स्थान पर जोड़ता है
        // इससे मूल संख्या के अंतिम अंक परिणाम के आरंभिक पक्ष में क्रमशः रखे जाते हैं
        result = result * 10 + digit;

        // x का इकाई अंक हटाएँ और अगले अंक को अंतिम स्थान पर लाएँ
        x = x / 10;
    }

    // सभी अंकों को उलटने का परिणाम लौटाएँ। ओवरफ़्लो की स्थिति में लूप के अंदर पहले ही 0 लौटाया जा चुका है
    return result;
}
```
