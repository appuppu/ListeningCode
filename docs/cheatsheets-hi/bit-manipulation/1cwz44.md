# Finding the Missing Number in a Sequence — 0 से n तक की क्रमिक संख्या श्रृंखला में एक लुप्त संख्या को खोजना

## समस्या का सार

0 से n तक के पूर्णांकों में से n अलग-अलग संख्याओं वाली एक सरणी `nums` दी गई है। इस सीमा में शामिल लेकिन सरणी में मौजूद न होने वाली **एक लुप्त संख्या** को खोजकर लौटाना है।

## मूल विचार

XOR को एक ही मान पर दो बार लागू करने पर वह शून्य हो जाता है। सरणी के इंडेक्स (0 से n-1) और मान n, तथा सरणी के सभी तत्वों पर XOR लागू करने पर, जोड़ी बनाने वाली संख्याएँ मिट जाती हैं और केवल जोड़ी न बनाने वाली "लुप्त संख्या" शेष रहती है।

## विचार प्रक्रिया

1. **लुप्त संख्या को छोड़कर सभी संख्याएँ जोड़ी बनाती हैं**: सरणी के इंडेक्स 0 से n-1 हैं, और सरणी के मान भी 0 से n की सीमा में से लुप्त संख्या को छोड़कर हैं। अर्थात इंडेक्स पक्ष में प्रारंभिक मान के रूप में n जोड़ने पर, 0 से n तक के सभी पूर्णांक इंडेक्स पक्ष में आ जाते हैं। केवल लुप्त संख्या सरणी के मान पक्ष में मौजूद नहीं होती, इसलिए वह जोड़ी नहीं बनाती
2. **जोड़ियों को मिटाने के लिए XOR सबसे उपयुक्त है**: XOR में `a ^ a = 0` (समान मान एक-दूसरे को मिटा देते हैं) और `a ^ 0 = a` (शून्य के साथ XOR मान को बनाए रखता है) गुण हैं। सभी इंडेक्स और मानों पर XOR लागू करने पर, जोड़ी बनाने वाली सभी संख्याएँ 0 हो जाती हैं और केवल जोड़ी न बनाने वाली लुप्त संख्या शेष रहती है
3. **प्रारंभिक मान n रखने का कारण**: for लूप का इंडेक्स केवल 0 से n-1 की सीमा को कवर करता है। लेकिन लुप्त संख्या n भी हो सकती है, इसलिए XOR का प्रारंभिक मान n रखने से 0 से n की पूरी सीमा कवर हो जाती है
4. **एक ही लूप में पूरा हो जाता है**: लूप के अंदर `xor ^= i` (इंडेक्स का XOR) और `xor ^= nums[i]` (मान का XOR) एक साथ करने पर, सरणी को केवल एक बार स्कैन करके परिणाम प्राप्त हो जाता है। किसी अतिरिक्त डेटा संरचना की आवश्यकता नहीं होती

## पूर्वापेक्षित ज्ञान

### XOR (एक्सक्लूसिव OR) क्या है

दो बिट भिन्न होने पर 1 और समान होने पर 0 लौटाने वाला बिट संक्रिया। Java में `^` ऑपरेटर से उपयोग किया जाता है। पूर्णांकों पर बिट-दर-बिट लागू होता है।

```java
int a = 5;          // बाइनरी: 101
int b = 3;          // बाइनरी: 011
int result = a ^ b; // बाइनरी: 110 → 6
```

### XOR के महत्वपूर्ण गुण

एल्गोरिदम की नींव बनाने वाले 3 गुण हैं।

```java
// गुण 1: समान मान का XOR 0 होता है (मिटाना)
5 ^ 5;    // → 0

// गुण 2: 0 के साथ XOR मूल मान को बनाए रखता है
5 ^ 0;    // → 5

// गुण 3: क्रम बदलने पर भी परिणाम समान रहता है (क्रमविनिमय नियम और साहचर्य नियम)
(2 ^ 5) ^ 2;  // → 5 (दोनों 2 एक-दूसरे को मिटा देते हैं, 5 शेष रहता है)
```

### ^= ऑपरेटर क्या है

XOR संक्रिया का परिणाम बाईं ओर के चर में संग्रहित करने वाला संयुक्त असाइनमेंट ऑपरेटर। `xor ^= i` का अर्थ `xor = xor ^ i` के समान है।

```java
int xor = 0;
xor ^= 3;   // xor = 0 ^ 3 → 3
xor ^= 3;   // xor = 3 ^ 3 → 0 (समान मान से मिट जाता है)
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(1) — कोई अतिरिक्त डेटा संरचना उपयोग नहीं होती, केवल एक चर पर्याप्त है |

## कोड

```java
// इनपुट: 0 से n की सीमा में n अलग-अलग पूर्णांकों वाली सरणी nums
// आउटपुट: सीमा में वह एक पूर्णांक लौटाना जो सरणी में मौजूद नहीं है
public int missingNumber(int[] nums) {
    // प्रारंभिक मान n रखने से, लूप इंडेक्स 0 से n-1 के साथ मिलकर 0 से n की पूरी सीमा कवर हो जाती है
    // for लूप का इंडेक्स केवल 0 से n-1 कवर करता है, इसलिए n को यहाँ प्रारंभिक मान के रूप में दिया गया है
    int xor = nums.length;

    for (int i = 0; i < nums.length; i++) {
        // इंडेक्स i को XOR संचित मान में समाहित करना
        // लूप समाप्त होने पर इंडेक्स 0 से n-1 तक सभी XOR हो चुके होते हैं (प्रारंभिक मान n के साथ मिलकर 0 से n के सभी पूर्णांक XOR हो जाते हैं)
        xor ^= i;
        // सरणी के मान को XOR संचित मान में समाहित करना
        // सरणी में मौजूद संख्याएँ इंडेक्स पक्ष और मान पक्ष दोनों में आती हैं, इसलिए a ^ a = 0 के गुण से वे मिट जाती हैं
        xor ^= nums[i];
    }

    // जोड़ी बनाने वाली सभी संख्याएँ मिटकर 0 हो जाती हैं, और सरणी में अनुपस्थित लुप्त संख्या का कोई जोड़ा नहीं होता इसलिए वह शेष रहती है
    return xor;
}
```
