# Counting the Number of Set Bits — किसी पूर्णांक के बाइनरी प्रतिनिधित्व में 1 के बिट्स की संख्या गिनना

## समस्या का सार

एक गैर-ऋणात्मक पूर्णांक `n` दिया गया है। `n` के बाइनरी प्रतिनिधित्व में, जिन बिट्स का मान 1 है उनकी संख्या (हैमिंग वेट) लौटानी है।

## मूल विचार

`n & (n - 1)` यह संक्रिया `n` के सबसे निचले 1 बिट को केवल एक ही मिटाने की क्रिया है। इस संक्रिया को `n` के 0 होने तक दोहराने पर, दोहराव की संख्या ही 1 के बिट्स की संख्या बन जाती है।

## विचार प्रक्रिया

1. **केवल 1 के बिट्स को कुशलतापूर्वक गिनना है**: सभी 32 बिट्स को स्कैन करने के बजाय, केवल उन स्थानों को संसाधित किया जाए जहाँ 1 का बिट मौजूद है, तो 1 के बिट्स की संख्या `k` के अनुपात में समय लगेगा
2. **सबसे निचले 1 बिट को मिटाने की विधि सोचना**: `n - 1` की गणना करने पर, `n` का सबसे निचला 1 बिट 0 हो जाता है, और उससे नीचे के सभी बिट 1 में पलट जाते हैं। उदाहरण के लिए `n = 1100` होने पर `n - 1 = 1011` होता है
3. **n AND (n - 1) से केवल सबसे निचला 1 बिट मिटता है**: `n` और `n - 1` का AND लेने पर, सबसे निचले 1 बिट की स्थिति और उससे नीचे सब 0 हो जाते हैं, और उससे ऊपर के बिट यथावत रहते हैं। `1100 & 1011 = 1000` होता है, जिससे सबसे निचला 1 बिट एक मिट गया
4. **मिटाने की संक्रिया दोहराकर गिनती करना**: `n &= (n - 1)` को बार-बार लागू करके, `n` के 0 होने तक की संख्या गिनने पर, वही मूल `n` में मौजूद 1 के बिट्स की संख्या होती है
5. **लूप की समाप्ति शर्त**: सभी 1 के बिट मिट जाने पर `n` 0 हो जाता है। `n != 0` को लूप शर्त बनाने पर, लूप केवल 1 के बिट्स की संख्या जितनी बार चलता है और स्वाभाविक रूप से समाप्त हो जाता है

## पूर्वापेक्षित ज्ञान

### बिट AND संक्रिया (&) क्या है

दो पूर्णांकों के प्रत्येक बिट की तुलना करके, केवल जहाँ दोनों 1 हों वहीं परिणाम 1 होने वाली संक्रिया है। अन्य सभी संयोजनों में परिणाम 0 होता है।

```java
int a = 0b1100;       // बाइनरी में 1100
int b = 0b1010;       // बाइनरी में 1010
int result = a & b;   // परिणाम 0b1000 है (केवल वे स्थान 1 होते हैं जहाँ दोनों 1 हैं)
```

### n & (n - 1) की कार्यप्रणाली

`n` से 1 घटाने पर, सबसे निचला 1 बिट 0 हो जाता है, और उससे नीचे के सभी बिट 1 में पलट जाते हैं। `n` के साथ AND लेने पर, सबसे निचले 1 बिट और उससे नीचे सब 0 हो जाते हैं।

```java
int n = 0b1100;       // n     = 1100 (1 के बिट 2 हैं)
n &= (n - 1);        // n - 1 = 1011, n = 1100 & 1011 = 1000 (1 के बिट घटकर 1 हो गया)
n &= (n - 1);        // n - 1 = 0111, n = 1000 & 0111 = 0000 (1 के बिट घटकर 0 हो गया)
```

### हैमिंग वेट (Hamming Weight) क्या है

किसी पूर्णांक के बाइनरी प्रतिनिधित्व में मौजूद 1 के बिट्स की संख्या को हैमिंग वेट कहते हैं। उदाहरण के लिए `11` का बाइनरी `1011` है, इसलिए हैमिंग वेट 3 है।

## गणनात्मक जटिलता

| | मान |
|---|---|
| Time | O(k) — k, `n` में मौजूद 1 के बिट्स की संख्या है। लूप केवल k बार चलता है |
| Space | O(1) — केवल एक काउंटर चर का उपयोग होता है |

## कोड

```java
// इनपुट: गैर-ऋणात्मक पूर्णांक n
// आउटपुट: n के बाइनरी प्रतिनिधित्व में 1 के बिट्स की संख्या int में लौटाना
public int hammingWeight(int n) {
    // 1 के बिट मिटाने की संख्या दर्ज करने वाला काउंटर। मिटाने की कुल संख्या ही अंतिम उत्तर होती है
    int count = 0;

    // यदि n 0 है तो कोई 1 का बिट शेष नहीं है, इसलिए लूप समाप्त करना है
    while (n != 0) {
        // सबसे निचले 1 बिट को एक मिटाना (Brian Kernighan's Trick)
        // n - 1 से सबसे निचले 1 बिट और उससे नीचे पलट जाते हैं, n के साथ AND से वह स्थिति और नीचे सब 0 हो जाता है
        n &= (n - 1);
        // 1 का एक बिट मिटाया गया, इसलिए मिटाने की संख्या दर्ज करना है
        count++;
    }
    // count में 1 के बिट मिटाने की कुल संख्या है, अर्थात मूल n में मौजूद 1 के बिट्स की संख्या संग्रहित है
    return count;
}
```
