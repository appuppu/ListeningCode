# Reversing the Bits of an Integer — 32-बिट अनसाइन्ड इंटीजर के बिट्स को उलटना

## समस्या का सार

एक 32-बिट अनसाइन्ड इंटीजर दिया गया है। उसकी बिट श्रृंखला को बाएं-दाएं उलटकर (विपरीत क्रम में) प्राप्त इंटीजर को लौटाना है। उदाहरण के लिए, इनपुट `00000000000000000000000000001011` का परिणाम `11010000000000000000000000000000` होगा।

## मूल विचार

परिणाम को बाएं 1 बिट शिफ्ट करते हुए, इनपुट के सबसे निचले बिट को एक-एक करके निकालकर परिणाम में जोड़ना है। यह प्रक्रिया 32 बार दोहराने पर, इनपुट की बिट श्रृंखला उलटे क्रम में परिणाम में संग्रहित हो जाती है।

## विचार प्रक्रिया

1. **बिट उलटना "अंत से निकालकर शुरुआत में रखने" की क्रिया है**: इनपुट के सबसे निचले बिट (दाएं छोर) को निकालकर, परिणाम के सबसे निचले बिट (दाएं छोर) में जोड़ने के बाद परिणाम को बाएं शिफ्ट करने पर, पहले निकाला गया बिट अंततः सबसे ऊपरी स्थान पर पहुंच जाता है। यह बिट श्रृंखला का विपरीत क्रम में निर्माण है
2. **सबसे निचले बिट को निकालने का तरीका**: `n & 1` की गणना करने पर, `n` का केवल सबसे निचला बिट प्राप्त होता है। AND ऑपरेशन सबसे निचले बिट के अलावा सभी बिट्स को 0 से मास्क कर देता है
3. **निकाले गए बिट को परिणाम में जोड़ने का तरीका**: `result |= (n & 1)` में OR ऑपरेशन का उपयोग करने पर, result के सबसे निचले बिट में निकाला गया बिट सेट हो जाता है। result का सबसे निचला बिट पिछले बाएं शिफ्ट से 0 हो चुका होता है, इसलिए OR ऑपरेशन सही ढंग से सेट करता है
4. **अगले बिट पर जाने का तरीका**: इनपुट `n` को `n >>>= 1` से दाएं 1 बिट शिफ्ट करने पर, अगला बिट सबसे निचले स्थान पर आ जाता है। `>>>` अनसाइन्ड राइट शिफ्ट है, जो सबसे ऊपरी स्थान पर हमेशा 0 भरता है
5. **परिणाम में स्थान बनाने का तरीका**: नया बिट जोड़ने से पहले `result <<= 1` से परिणाम को बाएं 1 बिट शिफ्ट करने पर, सबसे निचला बिट 0 हो जाता है और नए बिट को स्वीकार करने के लिए स्थान बन जाता है
6. **32 बार दोहराने पर पूर्ण हो जाता है**: 32-बिट इंटीजर होने के कारण, उपरोक्त "बायां शिफ्ट → बिट जोड़ना → दायां शिफ्ट" को 32 बार दोहराने पर, इनपुट के सभी बिट्स उलटे क्रम में परिणाम में संग्रहित हो जाते हैं

## पूर्व ज्ञान

### बिट AND ऑपरेशन (&) क्या है

दो इंटीजर के प्रत्येक बिट की तुलना करके, दोनों में 1 होने पर ही 1 बनने वाला ऑपरेशन है। विशिष्ट बिट को निकालने के लिए "मास्क" के रूप में उपयोग किया जाता है।

```java
int n = 0b1011;       // बाइनरी में 1011 (दशमलव में 11)
int bit = n & 1;      // केवल सबसे निचला बिट प्राप्त करता है → 1
int bit2 = 0b1010 & 1; // सबसे निचला बिट 0 होने पर → 0
```

### बिट OR ऑपरेशन (|=) क्या है

दो इंटीजर के प्रत्येक बिट की तुलना करके, किसी एक में 1 होने पर उस बिट को 1 बनाने वाला ऑपरेशन है। विशिष्ट बिट को सेट (1 बनाने) के लिए उपयोग किया जाता है।

```java
int result = 0b0000;
result |= 1;          // सबसे निचले बिट को 1 पर सेट करता है → 0b0001
result |= 0;          // 0 के साथ OR करने पर कोई परिवर्तन नहीं होता → 0b0001
```

### लेफ्ट शिफ्ट ऑपरेशन (<<=) क्या है

बिट श्रृंखला को बाएं निर्दिष्ट संख्या तक सरकाने वाला ऑपरेशन है। दाएं छोर पर 0 भरा जाता है। 1 बिट बायां शिफ्ट मान को 2 गुना करने का प्रभाव रखता है।

```java
int result = 0b0011;   // बाइनरी में 11 (दशमलव में 3)
result <<= 1;          // बाएं 1 बिट शिफ्ट करता है → 0b0110 (दशमलव में 6)
```

### अनसाइन्ड राइट शिफ्ट ऑपरेशन (>>>=) क्या है

बिट श्रृंखला को दाएं निर्दिष्ट संख्या तक सरकाने वाला ऑपरेशन है। बाएं छोर पर हमेशा 0 भरा जाता है। `>>` के विपरीत, साइन बिट की परवाह किए बिना 0 भरता है, इसलिए यह अनसाइन्ड इंटीजर की ऑपरेशन के लिए उपयुक्त है।

```java
int n = 0b1011;        // बाइनरी में 1011
n >>>= 1;              // दाएं 1 बिट शिफ्ट करता है → 0b0101 (सबसे निचला 1 हटता है, दाएं छोर पर अगला बिट आता है)
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(1) — लूप हमेशा 32 बार निश्चित रूप से चलता है और इनपुट के मान पर निर्भर नहीं करता |
| Space | O(1) — केवल अतिरिक्त वेरिएबल `result` का उपयोग करता है और इनपुट के आकार पर निर्भर नहीं करता |

## कोड

```java
// इनपुट: 32-बिट अनसाइन्ड इंटीजर n
// आउटपुट: बिट श्रृंखला को उलटे क्रम में बदला हुआ इंटीजर int के रूप में लौटाता है
public int reverseBits(int n) {
    // उलटी बिट श्रृंखला को संग्रहित करने वाला वेरिएबल। प्रारंभिक मान 0 का अर्थ है कि सभी बिट्स 0 की स्थिति में हैं
    int result = 0;

    // 32-बिट इंटीजर के सभी बिट्स को प्रोसेस करने के लिए 32 बार लूप चलाता है
    for (int i = 0; i < 32; i++) {
        // result को बाएं 1 बिट शिफ्ट करके, सबसे निचले बिट को 0 बनाकर नए बिट के लिए स्थान बनाता है
        // ध्यान दें: बायां शिफ्ट बिट जोड़ने से पहले किया जाता है। बाद में करने पर अंतिम बिट जोड़ने के बाद अतिरिक्त शिफ्ट होगा और परिणाम 2 गुना हो जाएगा
        result <<= 1;
        // n के सबसे निचले बिट को n & 1 से निकालकर, OR ऑपरेशन से result के सबसे निचले बिट में सेट करता है
        // पिछले बाएं शिफ्ट से सबसे निचला बिट 0 हो चुका है, इसलिए OR ऑपरेशन सही ढंग से सेट करता है
        result |= (n & 1);
        // n को अनसाइन्ड राइट शिफ्ट करके, अगले बिट को सबसे निचले स्थान पर लाता है
        // >>> का उपयोग इसलिए किया जाता है क्योंकि साइन बिट की परवाह किए बिना 0 भरना आवश्यक है
        n >>>= 1;
    }
    // 32 बार लूप पूर्ण होने पर, इनपुट का बिट 0 result के बिट 31 में, बिट 1 बिट 30 में, इस प्रकार सभी बिट्स उलटे क्रम में संग्रहित हो जाते हैं
    return result;
}
```
