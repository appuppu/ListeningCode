# Counting Bits for Every Number Up to N — 0 से N तक प्रत्येक पूर्णांक में शामिल 1 के बिट्स की संख्या को सरणी में लौटाना

## समस्या का सार

एक अऋणात्मक पूर्णांक `n` दिया गया है। लंबाई `n + 1` की एक सरणी लौटानी है। सरणी के इंडेक्स `i` वाले तत्व में, `i` को बाइनरी में दर्शाने पर **1 के बिट्स की संख्या** संग्रहीत करनी है। उदाहरण: n=5 के लिए, 0→0, 1→1, 2→1, 3→2, 4→1, 5→2 इसलिए `[0,1,1,2,1,2]` लौटाना है।

## मूल विचार

किसी भी पूर्णांक `i` में 1 के बिट्स की संख्या, `i` को 1 बिट दाईं ओर शिफ्ट किए गए मान `i >> 1` में 1 के बिट्स की संख्या में, `i` का सबसे निचला बिट (`i & 1`) जोड़ने के बराबर होती है। इस पुनरावर्ती संबंध के कारण, छोटे मानों के परिणामों का पुन: उपयोग करके सभी मानों को O(1) में प्राप्त किया जा सकता है।

## विचार प्रक्रिया

1. **बाइनरी की संरचना पर ध्यान दें**: पूर्णांक `i` की बाइनरी अभिव्यक्ति को दाईं ओर 1 बिट शिफ्ट करने पर, सबसे निचला बिट हट जाता है और शेष बिट अनुक्रम `i / 2` (पूर्णांक भाग) के समान होता है। अर्थात `i` का बिट अनुक्रम "`i >> 1` का बिट अनुक्रम" + "सबसे निचला 1 बिट" की संरचना रखता है
2. **1 के बिट्स की संख्या को विभाजित किया जा सकता है**: उपरोक्त संरचना से, `i` में शामिल 1 की संख्या = "`i >> 1` में शामिल 1 की संख्या" + "सबसे निचला बिट 1 है या नहीं (0 या 1)" में विभाजित की जा सकती है। इसे सूत्र में लिखें तो `countBits(i) = countBits(i >> 1) + (i & 1)` होता है
3. **छोटे मानों से क्रम में गणना करने पर पुन: उपयोग संभव है**: `i >> 1` हमेशा `i` से छोटा मान होता है, इसलिए `i = 0` से क्रम में गणना करने पर `result[i >> 1]` निश्चित रूप से पहले से गणना किया हुआ होता है। इस गुण के कारण पुनरावर्तन के बजाय लूप से आगे की ओर क्रम में भरा जा सकता है
4. **परिणाम सरणी स्वयं DP तालिका बन जाती है**: लौटाई जाने वाली सरणी `result` को उसी रूप में DP तालिका के रूप में उपयोग किया जाता है। `result[0] = 0` को आधार स्थिति मानकर, `i = 1` से `n` तक `result[i] = result[i >> 1] + (i & 1)` से भरा जाता है। किसी अतिरिक्त डेटा संरचना की आवश्यकता नहीं है

## पूर्वापेक्षित ज्ञान

### दायाँ शिफ्ट संक्रिया (`>>`) क्या है

यह संक्रिया पूर्णांक की बाइनरी अभिव्यक्ति को दाईं ओर निर्दिष्ट बिट संख्या तक खिसकाती है। 1 बिट दाईं ओर शिफ्ट करने पर, सबसे निचला बिट हट जाता है और मान 2 से भाग देने का भागफल (पूर्णांक भाग) बन जाता है।

```java
int a = 6;      // बाइनरी: 110
int b = a >> 1;  // बाइनरी: 011 → मान 3 है (6 ÷ 2 = 3)

int c = 7;      // बाइनरी: 111
int d = c >> 1;  // बाइनरी: 011 → मान 3 है (7 ÷ 2 = 3, शेष छोड़ा गया)
```

### बिट AND संक्रिया (`&`) क्या है

यह संक्रिया दो पूर्णांकों के प्रत्येक बिट की तुलना करती है और केवल उन बिट्स को 1 करती है जहाँ दोनों 1 हों। `i & 1` केवल `i` का सबसे निचला बिट निकालने की क्रिया है, जो `i` विषम होने पर 1 और सम होने पर 0 लौटाती है।

```java
int a = 5;       // बाइनरी: 101
int b = a & 1;   // बाइनरी: 001 → मान 1 है (विषम होने के कारण सबसे निचला बिट 1 है)

int c = 4;       // बाइनरी: 100
int d = c & 1;   // बाइनरी: 000 → मान 0 है (सम होने के कारण सबसे निचला बिट 0 है)
```

### गतिशील प्रोग्रामिंग (DP) क्या है

यह एक तकनीक है जो बड़ी समस्या को छोटी उप-समस्याओं में विभाजित करती है और उप-समस्याओं के परिणामों को सरणी में दर्ज करके पुन: उपयोग करती है। इस समस्या में, `result[i >> 1]` (पहले से गणना किए गए छोटे मान का परिणाम) का उपयोग करके `result[i]` को O(1) में प्राप्त किया जाता है।

```java
int[] result = new int[n + 1];  // DP तालिका एवं परिणाम सरणी बनाएँ
result[0] = 0;                  // आधार स्थिति: 0 में 1 के बिट्स की संख्या 0 है
result[i] = result[i >> 1] + (i & 1);  // संक्रमण सूत्र: ज्ञात परिणाम का पुन: उपयोग
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n) — 1 से n तक प्रत्येक मान के लिए केवल एक बार बिट शिफ्ट और AND संक्रिया करनी होती है |
| Space | O(n) — परिणाम संग्रहीत करने के लिए लंबाई n+1 की सरणी का उपयोग किया जाता है (यह आउटपुट स्वयं है इसलिए अतिरिक्त स्थान O(1) भी माना जा सकता है) |

## कोड

```java
// इनपुट: अऋणात्मक पूर्णांक n
// आउटपुट: लंबाई n+1 का int[]। प्रत्येक result[i] में i की बाइनरी अभिव्यक्ति में शामिल 1 के बिट्स की संख्या संग्रहीत होती है
public int[] countBits(int n) {
    // DP तालिका एवं परिणाम सरणी बनाएँ। new int[n+1] से सभी तत्व 0 से आरंभ होते हैं,
    // इसलिए result[0] = 0 (0 में 1 के बिट्स की संख्या 0 है) स्वतः पूर्ण हो जाता है
    int[] result = new int[n + 1];

    // i=0 पहले से 0 के साथ सही है, इसलिए i=1 से स्कैन आरंभ करें
    for (int i = 1; i <= n; i++) {
        // result[i >> 1]: i को 1 बिट दाईं ओर शिफ्ट किए गए मान में 1 के बिट्स की संख्या (i >> 1 हमेशा i से छोटा होता है इसलिए पहले से गणना किया हुआ है)
        // i & 1: i का सबसे निचला बिट (विषम होने पर 1, सम होने पर 0)
        // इन दोनों को जोड़ने पर, i की बाइनरी अभिव्यक्ति में शामिल 1 की कुल संख्या प्राप्त होती है
        result[i] = result[i >> 1] + (i & 1);
    }
    // सरणी के प्रत्येक तत्व result[i] में इंडेक्स i के 1 के बिट्स की संख्या संग्रहीत होने की स्थिति में लौटाएँ
    return result;
}
```
