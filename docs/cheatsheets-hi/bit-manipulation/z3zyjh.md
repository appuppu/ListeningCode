# Finding the Number That Appears Only Once — सरणी में केवल एक बार मौजूद तत्व को खोजना

## समस्या का सार

पूर्णांकों की एक सरणी `nums` दी गई है। सरणी में सभी तत्व ठीक 2 बार आते हैं, लेकिन केवल एक तत्व 1 बार आता है। उस **केवल 1 बार आने वाले तत्व** को लौटाएँ।

## मूल विचार

XOR संक्रिया में "एक ही मान को 2 बार XOR करने पर 0 मिलता है" यह गुण होता है। सरणी के सभी तत्वों को XOR करने पर, 2 बार आने वाले सभी तत्व एक-दूसरे को निरस्त करके 0 हो जाते हैं, और केवल 1 बार आने वाला तत्व शेष रहता है।

## विचार प्रक्रिया

1. **यदि दोहरे जोड़ों को हटा दिया जाए तो उत्तर शेष रहता है**: सरणी में 2 बार आने वाले सभी तत्वों को हटा दिया जाए, तो केवल 1 बार आने वाला तत्व प्राप्त होता है। इस "जोड़ों को हटाने" की क्रिया को कुशलतापूर्वक करने वाली संक्रिया खोजें
2. **XOR के स्व-प्रतिलोम गुण का उपयोग करें**: XOR संक्रिया में `a ^ a = 0` गुण होता है। एक ही मान को 2 बार XOR करने पर परिणाम 0 होता है। अर्थात, 2 बार आने वाले तत्व स्वतः निरस्त हो जाते हैं
3. **XOR के तत्समक तत्व और साहचर्य नियम का उपयोग करें**: `a ^ 0 = a` (0 के साथ XOR मान को नहीं बदलता) और XOR में साहचर्य नियम तथा क्रमविनिमय नियम लागू होते हैं। इसलिए, तत्वों के आने के क्रम से कोई फ़र्क नहीं पड़ता, सभी तत्वों को XOR करने पर जोड़े निरस्त हो जाते हैं और केवल अद्वितीय तत्व शेष रहता है
4. **एक चर से संचयी XOR की गणना करें**: चर `result` को 0 से आरंभ करें और सरणी को पार करते हुए प्रत्येक तत्व को XOR करते जाएँ। पार करना समाप्त होने पर `result` में शेष मान ही उत्तर है
5. **अतिरिक्त डेटा संरचना की आवश्यकता नहीं है**: HashSet या HashMap का उपयोग किए बिना, केवल एक पूर्णांक चर से हल निकाला जा सकता है, इसलिए स्थान जटिलता O(1) होती है

## पूर्वापेक्षित ज्ञान

### XOR (अनन्य विभक्त योग) क्या है

जब दो बिट अलग-अलग हों तब 1, और समान हों तब 0 लौटाने वाली बिट संक्रिया है। Java में इसे `^` संकारक द्वारा दर्शाया जाता है। पूर्णांक पर उपयोग करने पर, प्रत्येक बिट स्थान पर XOR लागू होता है।

```java
int a = 5;          // द्विआधारी: 101
int b = 3;          // द्विआधारी: 011
int c = a ^ b;      // द्विआधारी: 110 → 6
```

### XOR के महत्वपूर्ण गुण

XOR संक्रिया में निम्नलिखित 3 गुण होते हैं, और इस समस्या को हल करने के लिए तीनों आवश्यक हैं।

```java
// 1. स्व-प्रतिलोम: एक ही मान को 2 बार XOR करने पर 0 मिलता है
a ^ a;    // → 0

// 2. तत्समक तत्व: 0 के साथ XOR मूल मान को नहीं बदलता
a ^ 0;    // → a

// 3. क्रमविनिमय नियम और साहचर्य नियम: क्रम बदलने पर भी परिणाम समान रहता है
a ^ b ^ a;    // → (a ^ a) ^ b → 0 ^ b → b
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को केवल एक बार पार करना पर्याप्त है |
| Space | O(1) — अतिरिक्त डेटा संरचना का उपयोग नहीं होता, केवल एक पूर्णांक चर पर्याप्त है |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums (सभी तत्व 2 बार आते हैं, केवल एक तत्व 1 बार आता है)
// आउटपुट: केवल 1 बार आने वाले तत्व को int के रूप में लौटाएँ
public int singleNumber(int[] nums) {
    // संचयी XOR का प्रारंभिक मान। 0 XOR का तत्समक तत्व है, इसलिए किसी भी मान के साथ XOR करने पर वह मान नहीं बदलता
    int result = 0;

    // for-each लूप से सरणी के प्रत्येक तत्व को आरंभ से अंत तक एक-एक करके पार करें
    for (int num : nums) {
        // वर्तमान result और num का XOR गणना करके result में संग्रहित करें
        // 2 बार आने वाले तत्व a ^ a = 0 द्वारा निरस्त हो जाते हैं, केवल 1 बार आने वाला तत्व संचित होता है
        result ^= num;
    }

    // लूप समाप्त होने पर, सभी जोड़ों के निरस्त होने के परिणामस्वरूप, केवल 1 बार आने वाले तत्व का मान शेष रहता है
    return result;
}
```
