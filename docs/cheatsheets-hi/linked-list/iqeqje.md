# Finding the Duplicate in an Array of N Plus One Integers — N+1 पूर्णांकों की सरणी में डुप्लिकेट संख्या ढूँढना

## समस्या का सार

लंबाई n+1 की एक पूर्णांक सरणी `nums` दी गई है। प्रत्येक तत्व 1 से n की सीमा में है, और ठीक एक डुप्लिकेट संख्या अवश्य मौजूद है। सरणी को संशोधित किए बिना और केवल स्थिर अतिरिक्त स्थान का उपयोग करके, उस डुप्लिकेट संख्या को ढूँढकर लौटाना है।

## मूल विचार

यदि हम सरणी के प्रत्येक इंडेक्स `i` से `nums[i]` तक जाने के संबंध को एक "लिंक्ड लिस्ट" के रूप में देखें, तो जहाँ डुप्लिकेट संख्या मौजूद होती है वहाँ लिंक मिलते हैं और एक साइकल (चक्र) बनता है। Floyd's Cycle Detection (कछुआ और खरगोश एल्गोरिदम) का उपयोग करके, उस साइकल का प्रवेश बिंदु = डुप्लिकेट संख्या को O(1) स्थान में पहचाना जा सकता है।

## विचार प्रक्रिया

1. **सरणी को एक अंतर्निहित लिंक्ड लिस्ट के रूप में समझना**: इंडेक्स `i` पर मौजूद मान `nums[i]` को "अगले नोड का पॉइंटर" मानें। इंडेक्स 0 से शुरू करके `nums[0]` → `nums[nums[0]]` → … का अनुसरण करने पर, यह लिंक्ड लिस्ट ट्रैवर्सल जैसा ही व्यवहार करता है। चूँकि मानों की सीमा 1 से n है, इसलिए इंडेक्स 0 पर कभी वापसी नहीं होती और यह हमेशा एक वैध इंडेक्स को इंगित करता है
2. **डुप्लिकेट से साइकल क्यों बनता है यह समझना**: जब दो अलग-अलग इंडेक्स एक ही मान रखते हैं, तो उस मान के इंडेक्स की ओर दो तीर मौजूद होते हैं। यह लिंक्ड लिस्ट में दो नोड्स का एक ही नोड को इंगित करने की स्थिति है, और संगम बिंदु से साइकल शुरू होता है। साइकल का प्रवेश बिंदु ही डुप्लिकेट संख्या है
3. **साइकल की उपस्थिति का पता लगाना**: slow पॉइंटर 1 स्टेप (`slow = nums[slow]`) और fast पॉइंटर 2 स्टेप (`fast = nums[nums[fast]]`) आगे बढ़ता है। यदि साइकल मौजूद है, तो slow और fast अवश्य साइकल के अंदर किसी बिंदु पर मिलते हैं
4. **साइकल के प्रवेश बिंदु की पहचान करना**: मिलने के बाद, slow को प्रारंभ बिंदु (`nums[0]`) पर वापस लाएँ और fast को उसी स्थान पर रखें। दोनों को 1 स्टेप ずつ आगे बढ़ाने पर, दोनों साइकल के प्रवेश बिंदु पर फिर से मिलते हैं। इस प्रवेश बिंदु के इंडेक्स से संबंधित मान ही डुप्लिकेट संख्या है
5. **प्रवेश बिंदु पर क्यों मिलते हैं**: प्रारंभ से साइकल प्रवेश बिंदु तक की दूरी और मिलन बिंदु से साइकल प्रवेश बिंदु तक की दूरी बराबर होती है, यह गणितीय रूप से सिद्ध है। इसलिए, दोनों को समान गति से आगे बढ़ाने पर वे प्रवेश बिंदु पर मिलते हैं

## पूर्व-ज्ञान

### अंतर्निहित लिंक्ड लिस्ट (Implicit Linked List) क्या है

वास्तव में नोड ऑब्जेक्ट बनाए बिना भी, सरणी के मान को "अगले इंडेक्स का पॉइंटर" के रूप में व्याख्या करके, लिंक्ड लिस्ट के समान संरचना को व्यक्त किया जा सकता है। इंडेक्स `i` के नोड का "अगला नोड" इंडेक्स `nums[i]` का नोड होता है।

```java
// सरणी nums = [1, 3, 4, 2, 2] के लिए लिंक्ड लिस्ट ट्रैवर्सल
int current = nums[0];       // इंडेक्स 0 का मान → 1 (अगला इंडेक्स 1 पर जाता है)
current = nums[current];     // इंडेक्स 1 का मान → 3 (अगला इंडेक्स 3 पर जाता है)
current = nums[current];     // इंडेक्स 3 का मान → 2 (अगला इंडेक्स 2 पर जाता है)
current = nums[current];     // इंडेक्स 2 का मान → 4 (अगला इंडेक्स 4 पर जाता है)
current = nums[current];     // इंडेक्स 4 का मान → 2 (इंडेक्स 2 पर वापस → साइकल)
```

### Floyd's Cycle Detection (फ्लॉयड का साइकल डिटेक्शन) क्या है

लिंक्ड लिस्ट में साइकल का पता लगाने और उसके प्रवेश बिंदु की पहचान करने का एल्गोरिदम। दो पॉइंटर्स (slow: 1 कदम, fast: 2 कदम) का उपयोग करता है। यदि साइकल मौजूद है तो दोनों अवश्य मिलते हैं, और उसके बाद की प्रक्रिया से साइकल के प्रवेश बिंदु की पहचान हो सकती है।

```java
// फेज 1: साइकल के अंदर मिलन
slow = nums[slow];           // slow 1 स्टेप आगे बढ़ता है
fast = nums[nums[fast]];     // fast 2 स्टेप आगे बढ़ता है

// फेज 2: साइकल प्रवेश बिंदु की पहचान
slow = nums[slow];           // दोनों 1-1 स्टेप आगे बढ़ते हैं
fast = nums[fast];           // जहाँ मिलते हैं वह साइकल का प्रवेश बिंदु है
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n) — प्रत्येक पॉइंटर लिंक्ड लिस्ट का अधिकतम 2 बार ट्रैवर्सल करता है |
| Space | O(1) — केवल slow और fast दो चर का उपयोग होता है |

## कोड

```java
// इनपुट: लंबाई n+1 की पूर्णांक सरणी nums (प्रत्येक तत्व 1 से n तक, केवल एक डुप्लिकेट)
// आउटपुट: डुप्लिकेट संख्या को int के रूप में लौटाना
public int findDuplicate(int[] nums) {
    // slow और fast दोनों को लिंक्ड लिस्ट के शीर्ष (nums[0]) पर आरंभ करें
    // इंडेक्स 0 स्वयं मानों की सीमा (1〜n) में शामिल नहीं है, इसलिए यह साइकल का हिस्सा नहीं बनता और सुरक्षित प्रारंभ बिंदु है
    int slow = nums[0];
    int fast = nums[0];

    // फेज 1: slow को 1 कदम और fast को 2 कदम आगे बढ़ाएँ, जब तक वे साइकल के अंदर नहीं मिलते
    // do-while का उपयोग इसलिए: प्रारंभिक मान समान हैं, इसलिए पहली तुलना को छोड़ना आवश्यक है
    do {
        slow = nums[slow];           // slow को 1 स्टेप आगे बढ़ाएँ
        fast = nums[nums[fast]];     // fast को 2 स्टेप आगे बढ़ाएँ (साइकल होने पर अवश्य पकड़ लेगा)
    } while (slow != fast);

    // फेज 2: slow को प्रारंभ बिंदु पर वापस लाएँ, दोनों को 1-1 कदम आगे बढ़ाएँ
    // प्रारंभ से प्रवेश बिंदु तक की दूरी = मिलन बिंदु से प्रवेश बिंदु तक की दूरी, इस गुण का उपयोग करें
    slow = nums[0];
    while (slow != fast) {
        slow = nums[slow];           // दोनों को 1-1 स्टेप आगे बढ़ाएँ
        fast = nums[fast];           // साइकल के प्रवेश बिंदु पर अवश्य मिलते हैं
    }

    // साइकल का प्रवेश बिंदु = दो अलग-अलग इंडेक्स से इंगित की गई संख्या = डुप्लिकेट संख्या लौटाएँ
    return slow;
}
```
