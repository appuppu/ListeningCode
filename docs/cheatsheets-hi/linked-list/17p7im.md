# Detecting a Cycle in a Linked List — लिंक्ड लिस्ट में साइकल मौजूद है या नहीं यह जाँचना

## समस्या का सार

एकदिशीय लिंक्ड लिस्ट का हेड नोड `head` दिया गया है। यदि लिस्ट में किसी नोड का `next` पॉइंटर पहले से विज़िट किए गए नोड को इंगित करता है (साइकल मौजूद है), तो `true` लौटाएँ, और यदि साइकल मौजूद नहीं है तो `false` लौटाएँ।

## मूल विचार

अलग-अलग गति वाले दो पॉइंटर को एक साथ चलाने पर, यदि साइकल है तो वे अवश्य एक-दूसरे से मिलेंगे। यदि साइकल नहीं है तो तेज़ पॉइंटर पहले अंत तक पहुँच जाएगा। इस गुण के कारण, बिना किसी अतिरिक्त डेटा संरचना के साइकल का पता लगाया जा सकता है।

## विचार प्रक्रिया

1. **साइकल के सार को समझें**: यदि साइकल वाली लिस्ट को ट्रैवर्स किया जाए, तो अंत (null) तक नहीं पहुँचा जा सकता और लूप अनंत काल तक चलता रहता है। इसके विपरीत, यदि साइकल नहीं है, तो ट्रैवर्सल अवश्य null पर पहुँचकर समाप्त होता है
2. **अलग-अलग गति वाले पॉइंटर का उपयोग करें**: एक-एक स्टेप आगे बढ़ने वाला पॉइंटर (slow) और दो-दो स्टेप आगे बढ़ने वाला पॉइंटर (fast) तैयार करें। साइकल के अंदर, fast हर स्टेप पर slow के साथ 1 नोड की दूरी कम करता है, इसलिए वे अवश्य मिलते हैं
3. **मिलन साइकल का प्रमाण क्यों है**: यदि साइकल नहीं है तो fast पहले null तक पहुँच जाता है, इसलिए slow और fast का एक ही नोड को इंगित करना संभव नहीं है। मिलन हुआ = साइकल मौजूद है
4. **समाप्ति शर्त निर्धारित करें**: यदि fast या fast.next null हो जाए, तो लिस्ट में अंत मौजूद है इसलिए साइकल नहीं है। यदि slow और fast एक ही नोड को इंगित करें, तो साइकल मौजूद है
5. **प्रारंभिक स्थिति सेट करें**: slow को head पर और fast को head.next पर रखें। ऐसा करने से while लूप की शर्त `slow != fast` शुरू से ही सत्य रहती है और लूप के अंदर ट्रैवर्सल शुरू हो सकता है
6. **अंतिम रूप से क्या लौटाएँ**: यदि slow और fast मिलें तो `true` लौटाएँ, यदि fast null तक पहुँचे तो `false` लौटाएँ

## पूर्वापेक्षित ज्ञान

### ListNode (लिंक्ड लिस्ट का नोड) क्या है

लिंक्ड लिस्ट को बनाने वाला प्रत्येक तत्व। हर नोड में एक "मान" और "अगले नोड का पॉइंटर" होता है। अंतिम नोड का next, null को इंगित करता है (जब साइकल नहीं होता)।

```java
class ListNode {
    int val;            // नोड में संग्रहीत मान
    ListNode next;      // अगले नोड का संदर्भ (नहीं है तो null)
}

ListNode node = head;       // हेड नोड प्राप्त करें
node.next;                  // अगला नोड प्राप्त करें
node.next.next;             // दो आगे का नोड प्राप्त करें
```

### Floyd's Tortoise and Hare (फ्लॉइड की साइकल डिटेक्शन विधि) क्या है

अलग-अलग गति वाले दो पॉइंटर का उपयोग करके साइकल का पता लगाने वाला एल्गोरिद्म। slow पॉइंटर 1 स्टेप और fast पॉइंटर 2 स्टेप आगे बढ़ता है। साइकल के अंदर fast हर स्टेप पर slow के 1 नोड करीब आता है, इसलिए यदि साइकल मौजूद है तो वे सीमित स्टेप में अवश्य मिलते हैं।

```java
ListNode slow = head;       // 1 स्टेप आगे बढ़ने वाला पॉइंटर
ListNode fast = head.next;  // 2 स्टेप आगे बढ़ने वाला पॉइंटर
slow = slow.next;           // slow को 1 आगे बढ़ाएँ
fast = fast.next.next;      // fast को 2 आगे बढ़ाएँ
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — यदि साइकल नहीं है तो fast, n/2 स्टेप में अंत तक पहुँचता है, और यदि साइकल है तो भी साइकल की लंबाई के भीतर मिलन होता है |
| Space | O(1) — केवल 2 पॉइंटर वेरिएबल का उपयोग होता है, किसी अतिरिक्त डेटा संरचना की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: एकदिशीय लिंक्ड लिस्ट का हेड नोड head
// आउटपुट: यदि साइकल मौजूद है तो true, नहीं है तो false लौटाएँ
public boolean hasCycle(ListNode head) {
    // यदि नोड 0 या 1 है तो साइकल संभव नहीं है। false लौटाकर समाप्त करें
    if (head == null || head.next == null) {
        return false;
    }

    // slow को head पर और fast को head.next पर रखें
    // fast को 1 आगे रखने से while की शर्त slow != fast पहली बार से सत्य रहती है और लूप में प्रवेश होता है
    ListNode slow = head;
    ListNode fast = head.next;

    // slow और fast के मिलने तक लूप दोहराएँ (मिलन होने पर समाप्त करें)
    while (slow != fast) {
        // यदि fast null है या fast.next null है तो लिस्ट में अंत मौजूद है, इसलिए साइकल नहीं है
        if (fast == null || fast.next == null) {
            return false;
        }
        // slow को 1 स्टेप और fast को 2 स्टेप आगे बढ़ाएँ
        // गति के अंतर के कारण, साइकल के अंदर fast हर स्टेप पर slow के 1 नोड करीब आता है
        slow = slow.next;
        fast = fast.next.next;
    }

    // while की शर्त slow != fast असत्य हुई = slow और fast मिले, इसलिए साइकल मौजूद है
    return true;
}
```
