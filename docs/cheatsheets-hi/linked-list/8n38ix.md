# Removing the Nth Node From the End of a List — सूची के अंत से N-वें नोड को हटाना

## समस्या का सार

एकदिशीय लिंक्ड लिस्ट का प्रारंभिक नोड `head` और एक पूर्णांक `n` दिया गया है। सूची के **अंत से N-वें** नोड को हटाकर, संशोधित सूची का प्रारंभिक नोड लौटाना है।

## मूल विचार

दो पॉइंटरों को N नोड्स की दूरी पर रखकर एक साथ आगे बढ़ाने पर, जब अग्रणी पॉइंटर सूची के अंत तक पहुँचता है, तब अनुगामी पॉइंटर हटाए जाने वाले नोड के ठीक पहले स्थित होता है। इससे एक ही बार की ट्रैवर्सल में नोड को हटाया जा सकता है।

## विचार प्रक्रिया

1. **अंत से N-वें नोड को पहचानने के लिए सूची की लंबाई आवश्यक प्रतीत होती है**: सरल दृष्टिकोण में, पहले पूरी सूची को ट्रैवर्स करके लंबाई L ज्ञात करना होगा, फिर L-N वें नोड तक पहुँचने के लिए दूसरी ट्रैवर्सल करनी होगी। लेकिन दो पॉइंटरों का उपयोग करने से एक ही ट्रैवर्सल में कार्य पूरा हो जाता है
2. **N नोड्स की दूरी पर रखे दो पॉइंटरों का उपयोग करना**: fast पॉइंटर को slow पॉइंटर से N नोड आगे बढ़ा दिया जाता है। इस स्थिति में दोनों को एक-एक नोड आगे बढ़ाने पर, जब fast सूची के अंत तक पहुँचता है, तब slow अंत से ठीक N+1 वीं स्थिति पर होता है। अर्थात slow हटाए जाने वाले नोड के **ठीक पहले** के नोड को इंगित करता है
3. **प्रारंभ में डमी नोड जोड़ने का कारण**: जब हटाया जाने वाला नोड सूची का प्रारंभिक नोड (स्वयं head) हो, तो "हटाए जाने वाले नोड के ठीक पहले का नोड" अस्तित्व में नहीं होता। head के पहले एक डमी नोड रखने से, प्रारंभिक नोड को हटाने का कार्य भी अन्य नोड्स को हटाने के समान तर्क से संभाला जा सकता है
4. **fast को N नोड आगे बढ़ाना**: for लूप से fast को N बार आगे बढ़ाया जाता है। इस बिंदु पर slow और fast के बीच N नोड्स विद्यमान होते हैं
5. **दोनों पॉइंटरों को एक साथ आगे बढ़ाना**: `fast.next != null` होने तक slow और fast को एक साथ एक-एक नोड आगे बढ़ाया जाता है। जब fast का **अगला** null हो जाता है तब लूप समाप्त होता है। इस समय fast सूची के अंतिम नोड को इंगित करता है, और slow अंत से N+1 वें (हटाए जाने वाले नोड के ठीक पहले के) नोड को इंगित करता है
6. **नोड को हटाना और सूची लौटाना**: slow का अगला नोड हटाए जाने वाला नोड है, इसलिए `slow.next = slow.next.next` द्वारा लिंक बदलकर उसे हटाया जाता है। अंत में `dummy.next` लौटाया जाता है। head को सीधे न लौटाने का कारण यह है कि यदि head ही हटाया गया हो तो सही प्रारंभिक नोड लौटाया जा सके

## पूर्वापेक्षित ज्ञान

### ListNode क्या है

ListNode एकदिशीय लिंक्ड लिस्ट के एक नोड को दर्शाने वाला क्लास है। प्रत्येक नोड में एक मान `val` और अगले नोड का संदर्भ `next` होता है। जिस नोड का `next` null है, वह सूची का अंतिम नोड है।

```java
ListNode node = new ListNode(5);  // मान 5 वाला नोड बनाता है, next null है
node.next = new ListNode(10);     // node → 10 → null की सूची बनती है
```

### डमी नोड (Sentinel Node) क्या है

डमी नोड सूची के प्रारंभ में जोड़ा जाने वाला एक संतरी नोड है जिसमें कोई सार्थक मान नहीं होता। प्रारंभिक नोड को हटाने की स्थिति में भी "हटाए जाने वाले नोड के पहले का नोड" सदैव उपलब्ध रहता है, जिससे प्रारंभिक नोड के लिए विशेष उपचार की आवश्यकता नहीं रहती।

```java
ListNode dummy = new ListNode(0);  // डमी नोड बनाता है
dummy.next = head;                 // डमी के अगले को वास्तविक प्रारंभिक नोड से जोड़ता है
// प्रसंस्करण के बाद, dummy.next नया प्रारंभिक नोड होगा
```

### Two-Pointer (2 पॉइंटर) तकनीक क्या है

Two-Pointer तकनीक में दो पॉइंटरों को भिन्न गति या अंतराल पर चलाकर सूची में किसी विशिष्ट स्थिति को कुशलतापूर्वक खोजा जाता है। इस समस्या में N नोड्स की दूरी पर रखे दो पॉइंटरों को समान गति से आगे बढ़ाकर अंत से N-वीं स्थिति निर्धारित की जाती है।

```java
ListNode slow = head;
ListNode fast = head;
// fast को N नोड आगे बढ़ाने के बाद, दोनों को एक साथ आगे बढ़ाया जाता है
```

## गणनात्मक जटिलता

| | मान |
|---|---|
| Time | O(n) — सूची को केवल एक बार ट्रैवर्स करना पर्याप्त है |
| Space | O(1) — केवल डमी नोड और दो पॉइंटरों का उपयोग होता है |

## कोड

```java
// इनपुट: एकदिशीय लिंक्ड लिस्ट का प्रारंभिक नोड head और पूर्णांक n
// आउटपुट: अंत से N-वें नोड को हटाने के बाद सूची का प्रारंभिक नोड ListNode लौटाता है
public ListNode removeNthFromEnd(ListNode head, int n) {
    // मान 0 वाला डमी नोड प्रारंभ में जोड़ता है
    // डमी नोड रखने से, प्रारंभिक नोड हटाने पर भी "हटाए जाने वाले नोड के ठीक पहले का नोड" उपलब्ध रहता है
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // दोनों पॉइंटरों को डमी नोड से प्रारंभ करता है
    // डमी नोड से प्रारंभ करने से, अंत में slow हटाए जाने वाले नोड के ठीक पहले सही स्थिति पर होता है
    ListNode slow = dummy;
    ListNode fast = dummy;

    // fast को N नोड आगे बढ़ाकर slow और fast के बीच N नोड्स का अंतर बनाता है
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }

    // दोनों पॉइंटरों को एक साथ आगे बढ़ाता है और fast के सूची के अंत तक पहुँचने पर रुकता है
    // fast.next != null को शर्त रखने का कारण यह है कि जब fast सूची के अंतिम नोड पर पहुँचे,
    // तब slow हटाए जाने वाले नोड के ठीक पहले स्थित हो
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // slow.next हटाए जाने वाला नोड है। slow के next पॉइंटर को एक नोड आगे जोड़कर, हटाए जाने वाले नोड को सूची से अलग करता है
    slow.next = slow.next.next;

    // head के बजाय dummy.next लौटाता है क्योंकि यदि head ही हटाया गया हो तो नया प्रारंभिक नोड सही ढंग से लौटाया जा सके
    return dummy.next;
}
```
