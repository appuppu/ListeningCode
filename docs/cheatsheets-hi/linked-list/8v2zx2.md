# Merging Two Sorted Linked Lists — दो सॉर्ट की गई लिंक्ड लिस्ट को एक में मर्ज करना

## समस्या का सार

दो सॉर्ट की गई लिंक्ड लिस्ट `list1` और `list2` दी गई हैं। इन दोनों को एक सॉर्ट की गई लिंक्ड लिस्ट में मर्ज करना है और मर्ज के बाद की लिस्ट का **पहला नोड** लौटाना है।

## मूल विचार

दोनों लिस्ट के पहले नोड की तुलना करें और छोटे वाले को चुनकर मर्ज परिणाम का पहला नोड बनाएं। शेष भाग "छोटे वाले का अगला नोड" और "दूसरी लिस्ट" को मर्ज करने का परिणाम है, और यह मूल समस्या के समान संरचना है इसलिए इसे रिकर्शन से हल किया जा सकता है।

## विचार प्रक्रिया

1. **मर्ज के हर चरण में एक ही काम होता है**: दोनों लिस्ट के पहले नोड की तुलना करें और छोटे वाले को चुनें। यह ऑपरेशन तब तक दोहराया जाता है जब तक लिस्ट खाली न हो जाए। हर बार एक ही निर्णय लिया जाता है, इसलिए इसे रिकर्शन से व्यक्त किया जा सकता है
2. **बेस केस पर विचार करें**: यदि एक लिस्ट खाली (null) है, तो दूसरी लिस्ट को वैसे ही लौटा दें। यदि दोनों खाली हैं तो null लौटाएं (यह एक लिस्ट के null होने के केस में शामिल है)
3. **रिकर्सिव स्टेप पर विचार करें**: यदि `list1.val <= list2.val` है तो `list1` पहला नोड बनेगा। `list1.next` में "`list1` के शेष भाग" और "पूरी `list2`" को मर्ज करने का परिणाम जोड़ें। विपरीत स्थिति में `list2` को पहला नोड बनाकर उसी प्रकार प्रोसेस करें
4. **हर रिकर्सिव कॉल में समस्या का आकार 1 कम होता है**: हर बार किसी एक लिस्ट से 1 नोड उपयोग होता है, इसलिए कुल n रिकर्सिव कॉल में सभी नोड प्रोसेस हो जाते हैं
5. **अंत में क्या लौटाना है**: हर रिकर्सिव कॉल चुने गए नोड (`list1` या `list2`) को लौटाती है। पहली कॉल जो नोड लौटाती है वह मर्ज के बाद की लिस्ट का पहला नोड बनता है

## पूर्वापेक्षित ज्ञान

### ListNode (लिंक्ड लिस्ट का नोड) क्या है

यह लिंक्ड लिस्ट के प्रत्येक तत्व को दर्शाने वाला क्लास है। `val` फ़ील्ड में मान होता है और `next` फ़ील्ड में अगले नोड का संदर्भ होता है। जिस नोड का `next` null है वह लिस्ट का अंतिम नोड है।

```java
class ListNode {
    int val;          // नोड में संग्रहीत मान
    ListNode next;    // अगले नोड का संदर्भ (अंतिम नोड के लिए null)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### रिकर्शन (Recursion) क्या है

यह एक ऐसी विधि है जिसमें फ़ंक्शन स्वयं को कॉल करके समस्या हल करता है। बड़ी समस्या को समान संरचना वाली छोटी समस्याओं में विभाजित किया जाता है, और बेस केस (जिसे और विभाजित नहीं किया जा सकता, सबसे छोटी समस्या) तक पहुंचने पर परिणाम लौटाया जाता है। हर कॉल पर कॉल स्टैक में एक फ्रेम जुड़ता है, इसलिए रिकर्शन की गहराई के बराबर स्पेस की खपत होती है।

```java
// उदाहरण: फ़ैक्टोरियल की गणना
int factorial(int n) {
    if (n <= 1) return 1;           // बेस केस: इसे और विभाजित नहीं करना है
    return n * factorial(n - 1);    // रिकर्सिव स्टेप: समस्या का आकार 1 कम करके स्वयं को कॉल करना
}
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — दोनों लिस्ट के कुल नोड की संख्या n बार रिकर्सिव कॉल करके सभी नोड को प्रोसेस किया जाता है |
| Space | O(n) — हर रिकर्सिव कॉल पर कॉल स्टैक में एक फ्रेम जुड़ता है और अधिकतम n स्तर की गहराई तक पहुंचता है |

## कोड

```java
// इनपुट: दो सॉर्ट की गई लिंक्ड लिस्ट के पहले नोड list1 और list2
// आउटपुट: मर्ज के बाद की सॉर्ट की गई लिंक्ड लिस्ट के पहले नोड को ListNode के रूप में लौटाना
ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    // बेस केस: यदि list1 खाली है, तो शेष list2 को वैसे ही लौटाएं (list1 खाली है इसलिए list2 ही मर्ज परिणाम बनता है)
    if (list1 == null) return list2;
    // बेस केस: यदि list2 खाली है, तो शेष list1 को वैसे ही लौटाएं (list2 खाली है इसलिए list1 ही मर्ज परिणाम बनता है)
    if (list2 == null) return list1;

    // list1 के पहले नोड और list2 के पहले नोड की तुलना करके निर्धारित करें कि मर्ज परिणाम का पहला नोड कौन सा होगा
    if (list1.val <= list2.val) {
        // list1 को पहले नोड के रूप में चुनें और list1 के शेष (list1.next) तथा पूरी list2 को मर्ज करने का परिणाम list1 के अगले नोड से जोड़ें
        list1.next = mergeTwoLists(list1.next, list2);
        return list1; // list1 मर्ज परिणाम का पहला नोड बनता है
    } else {
        // list2 को पहले नोड के रूप में चुनें और पूरी list1 तथा list2 के शेष (list2.next) को मर्ज करने का परिणाम list2 के अगले नोड से जोड़ें
        list2.next = mergeTwoLists(list1, list2.next);
        return list2; // list2 मर्ज परिणाम का पहला नोड बनता है
    }
}
```
