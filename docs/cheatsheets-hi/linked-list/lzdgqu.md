# Deep Copying a Linked List With Random Pointers — रैंडम पॉइंटर वाली लिंक्ड लिस्ट की पूर्ण प्रतिलिपि बनाना

## समस्या का सार

प्रत्येक नोड में `next` पॉइंटर के अलावा, लिस्ट के किसी भी नोड (या null) की ओर इशारा करने वाला एक `random` पॉइंटर होता है। इस लिंक्ड लिस्ट का **डीप कॉपी** (पूरी तरह स्वतंत्र प्रतिलिपि) बनाकर लौटाना है। कॉपी किए गए नोड का `random` मूल लिस्ट की ओर नहीं, बल्कि कॉपी लिस्ट के संबंधित नोड की ओर इशारा करना चाहिए।

## मूल विचार

कॉपी किए गए नोड को मूल नोड के ठीक बाद सम्मिलित (इंटरलीव) करने पर, मूल नोड के `random` का "अगला नोड" कॉपी पक्ष का संबंधित नोड बन जाता है। इस संरचनात्मक संबंध का उपयोग करके, HashMap के बिना O(1) स्पेस में रैंडम पॉइंटर को सही ढंग से सेट किया जा सकता है।

## विचार प्रक्रिया

1. **कठिन हिस्सा random पॉइंटर की मैपिंग है**: केवल `next` पॉइंटर हो तो क्रम से कॉपी करना सरल है, लेकिन `random` किसी भी नोड की ओर इशारा करता है, इसलिए मूल नोड और कॉपी नोड के बीच संबंध जानने का कोई साधन आवश्यक है
2. **HashMap से O(n) स्पेस में हल हो सकता है, लेकिन क्या O(1) संभव है**: मूल नोड→कॉपी नोड की मैपिंग HashMap में संग्रहीत करके हल किया जा सकता है, लेकिन अतिरिक्त डेटा संरचना का उपयोग किए बिना लिस्ट की संरचना में ही संबंध व्यक्त किया जा सकता है या नहीं, इस पर विचार करें
3. **कॉपी नोड को मूल नोड के ठीक बाद सम्मिलित करना**: मूल नोड A के ठीक बाद कॉपी A' सम्मिलित करने पर `A → A' → B → B' → C → C'` जैसी इंटरलीव संरचना बनती है। इससे किसी भी मूल नोड `X` के लिए `X.next` हमेशा उसकी कॉपी `X'` होती है — यह संबंध लिस्ट की संरचना में ही समाहित हो जाता है
4. **इंटरलीव संरचना द्वारा random पॉइंटर सेट करना**: जब मूल नोड `curr` का `random` किसी अन्य मूल नोड `R` की ओर इशारा करता है, तो कॉपी नोड `curr.next` का `random` `R` की कॉपी यानी `R.next` पर सेट करना होगा। अर्थात `curr.next.random = curr.random.next` सूत्र से एक साथ सेट किया जा सकता है
5. **दोनों लिस्ट को अलग करना**: random पॉइंटर सेट करने के बाद, इंटरलीव की गई लिस्ट से मूल लिस्ट और कॉपी लिस्ट को बारी-बारी निकालकर अलग करना है। मूल लिस्ट को भी वापस पूर्व स्थिति में लाना आवश्यक है
6. **तीन पास में पूरा होता है**: पहले पास में कॉपी नोड सम्मिलित करना, दूसरे पास में random पॉइंटर सेट करना, तीसरे पास में लिस्ट को अलग करना। प्रत्येक पास O(n) है, और कोई अतिरिक्त डेटा संरचना उपयोग नहीं होती इसलिए Space O(1) होता है

## पूर्वापेक्षित ज्ञान

### लिंक्ड लिस्ट की नोड संरचना (random सहित)

सामान्य लिंक्ड लिस्ट के `next` के अलावा, लिस्ट के किसी भी नोड की ओर इशारा करने वाला `random` पॉइंटर रखने वाला विशेष नोड। `random` `null` भी हो सकता है।

```java
class Node {
    int val;
    Node next;      // अगले नोड की ओर इशारा करता है (सामान्य लिंक्ड लिस्ट)
    Node random;    // लिस्ट के किसी भी नोड या null की ओर इशारा करता है

    Node(int val) {
        this.val = val;
        this.next = null;
        this.random = null;
    }
}
```

### डीप कॉपी क्या है

मूल ऑब्जेक्ट से पूरी तरह स्वतंत्र प्रतिलिपि बनाना। कॉपी किए गए नोड को मूल लिस्ट के नोड का संदर्भ नहीं रखना चाहिए। सभी पॉइंटर (`next` और `random`) को केवल कॉपी लिस्ट के नोड की ओर इशारा करना चाहिए।

```java
// शैलो कॉपी (गलत): copy.random मूल लिस्ट के नोड की ओर इशारा कर देता है
copy.random = original.random;

// डीप कॉपी (सही): copy.random कॉपी लिस्ट के संबंधित नोड की ओर इशारा करता है
copy.random = originalToCopyMapping(original.random);
```

### इंटरलीव (बारी-बारी व्यवस्था) क्या है

दो श्रृंखलाओं के तत्वों को बारी-बारी रखना। इस समस्या में, मूल लिस्ट के नोड के बीच कॉपी नोड सम्मिलित करके `A → A' → B → B' → C → C'` संरचना बनाई जाती है। इससे मूल नोड `X` की कॉपी हमेशा `X.next` से प्राप्त की जा सकती है।

```java
// मूल लिस्ट:        A → B → C → null
// इंटरलीव के बाद:   A → A' → B → B' → C → C' → null
// A की कॉपी A.next से, B की कॉपी B.next से प्राप्त की जा सकती है
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — लिस्ट को 3 बार ट्रैवर्स किया जाता है। प्रत्येक पास O(n) है इसलिए कुल O(3n) = O(n) |
| Space | O(1) — आउटपुट के कॉपी नोड के अलावा कोई अतिरिक्त डेटा संरचना उपयोग नहीं होती |

## कोड

```java
// इनपुट: random पॉइंटर वाली लिंक्ड लिस्ट का हेड नोड head
// आउटपुट: इनपुट लिस्ट की डीप कॉपी का हेड नोड लौटाता है
public Node copyRandomList(Node head) {
    // खाली लिस्ट में कॉपी करने के लिए कुछ नहीं है
    if (head == null) return null;

    // === पहला पास: प्रत्येक मूल नोड के ठीक बाद कॉपी नोड सम्मिलित करना ===
    // इस पास के बाद A → A' → B → B' → C → C' जैसी इंटरलीव संरचना बनती है
    Node curr = head;
    while (curr != null) {
        // मूल नोड के समान मान वाला नया कॉपी नोड बनाना
        Node copy = new Node(curr.val);
        copy.next = curr.next;       // कॉपी के next को मूल के next पर सेट करना
        curr.next = copy;            // मूल के next को कॉपी पर सेट करके, curr के ठीक बाद सम्मिलित करना
        curr = copy.next;            // copy.next मूल का अगला नोड है। अगले मूल नोड पर जाना
    }

    // === दूसरा पास: इंटरलीव संरचना का उपयोग करके random पॉइंटर सेट करना ===
    curr = head;
    while (curr != null) {
        // curr.next कॉपी नोड है, curr.random.next random गंतव्य का कॉपी नोड है
        // यदि curr.random null है तो कॉपी का random भी null रहेगा
        curr.next.random =
            curr.random != null
            ? curr.random.next : null;
        curr = curr.next.next;       // कॉपी नोड को छोड़कर अगले मूल नोड पर जाना
    }

    // === तीसरा पास: इंटरलीव की गई लिस्ट को मूल लिस्ट और कॉपी लिस्ट में अलग करना ===
    // मूल लिस्ट को भी वापस पूर्व स्थिति में लाना आवश्यक है
    curr = head;
    Node copyHead = head.next;       // कॉपी लिस्ट का हेड सहेजना। यही अंतिम रिटर्न वैल्यू होगी
    while (curr != null) {
        Node copy = curr.next;       // कॉपी नोड प्राप्त करना
        curr.next = copy.next;       // मूल लिस्ट के next को पुनर्स्थापित करना (कॉपी को छोड़कर मूल के अगले नोड पर)
        copy.next = copy.next != null
            ? copy.next.next : null;  // कॉपी लिस्ट के next को जोड़ना (मूल नोड को छोड़कर अगली कॉपी पर)
        curr = curr.next;            // पुनर्स्थापित मूल के अगले नोड पर जाना
    }

    // copyHead डीप कॉपी की गई लिस्ट का हेड है
    return copyHead;
}
```
