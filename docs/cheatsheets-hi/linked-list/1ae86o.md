# Reordering a Linked List by Interleaving Ends — लिंक्ड लिस्ट के दोनों सिरों को बारी-बारी से पुनर्व्यवस्थित करना

## समस्या का सार

एक एकदिशीय लिंक्ड लिस्ट L0 → L1 → … → Ln-1 → Ln दी गई है। इस लिस्ट को L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → … के क्रम में **इन-प्लेस (in-place)** पुनर्व्यवस्थित करना है। नोड्स के मान बदले बिना, केवल नोड्स के लिंक (next पॉइंटर) को बदलकर यह कार्य करना है।

## मुख्य विचार

लिस्ट के उत्तरार्ध को उलटा कर दें, तो "पूर्वार्ध के आरंभ से" और "उत्तरार्ध के आरंभ (मूल अंत) से" बारी-बारी जोड़ने मात्र से वांछित क्रम प्राप्त होता है। उत्तरार्ध को उलटा करने के लिए, पहले लिस्ट का मध्य बिंदु ढूँढकर पूर्वार्ध और उत्तरार्ध में विभाजित करना होता है।

## विचार प्रक्रिया

1. **पुनर्व्यवस्था के बाद की संरचना का अवलोकन करें**: L0 → Ln → L1 → Ln-1 → … यह क्रम, लिस्ट के "आरंभ" और "अंत" से बारी-बारी तत्वों को निकालने का परिणाम है। अर्थात, आरंभ पक्ष और अंत पक्ष की दो श्रेणियों को बारी-बारी मर्ज करना होगा
2. **अंत से तत्व निकालने के लिए उलटा क्रम आवश्यक है**: एकदिशीय लिंक्ड लिस्ट में अंतिम तत्व तक पहुँचने में O(n) लगता है। परंतु, लिस्ट के उत्तरार्ध को उलटा कर दें तो उत्तरार्ध का आरंभ मूल अंत बन जाता है, और आरंभ से क्रमशः आगे बढ़ने मात्र से अंत पक्ष के तत्व प्राप्त हो जाते हैं
3. **लिस्ट का मध्य बिंदु ढूँढें**: उत्तरार्ध को उलटा करने के लिए, पहले यह तय करना होगा कि लिस्ट को कहाँ विभाजित करें। slow/fast पॉइंटर (कछुआ और खरगोश विधि) का उपयोग करें तो एक ही बार ट्रैवर्स करके मध्य बिंदु मिल जाता है। slow एक कदम और fast दो कदम आगे बढ़ता है, और जब fast लिस्ट के अंत तक पहुँचता है तब slow मध्य बिंदु पर होता है
4. **उत्तरार्ध को उलटाएँ**: मध्य बिंदु के अगले नोड से शुरू करके, प्रत्येक नोड के next पॉइंटर को पिछले नोड की ओर मोड़कर उत्तरार्ध लिस्ट को उलटा करें। prev चर से ठीक पिछले नोड को ट्रैक करें, और लूप समाप्त होने पर prev उलटी लिस्ट का आरंभ होगा
5. **पूर्वार्ध और उलटे उत्तरार्ध को बारी-बारी मर्ज करें**: पूर्वार्ध लिस्ट और उत्तरार्ध लिस्ट को उनके आरंभ से ट्रैवर्स करें, और पूर्वार्ध के नोड के बाद उत्तरार्ध का नोड डालें। प्रत्येक चरण में next पॉइंटर बदलना होता है, इसलिए मूल लिंक को अस्थायी चर में सुरक्षित करके फिर बदलें
6. **उत्तरार्ध छोटा या समान लंबाई का होता है**: विषम लंबाई की लिस्ट में पूर्वार्ध एक तत्व अधिक होता है, इसलिए मर्ज लूप की शर्त `second != null` रखें। उत्तरार्ध के नोड समाप्त होने पर मर्ज पूरा हो जाता है

## पूर्वापेक्षित ज्ञान

### slow/fast पॉइंटर (कछुआ और खरगोश विधि) क्या है

लिंक्ड लिस्ट का मध्य बिंदु एक ही बार ट्रैवर्स करके ढूँढने की तकनीक है। slow एक-एक नोड आगे बढ़ता है, fast दो-दो नोड आगे बढ़ता है। जब fast लिस्ट के अंत तक पहुँचता है, तब slow लिस्ट के मध्य बिंदु पर होता है।

```java
ListNode slow = head, fast = head;
while (fast.next != null && fast.next.next != null) {
    slow = slow.next;        // slow एक कदम आगे बढ़ता है
    fast = fast.next.next;   // fast दो कदम आगे बढ़ता है
}
// लूप समाप्त होने पर, slow लिस्ट के मध्य नोड को इंगित करता है
```

### लिंक्ड लिस्ट को उलटाना क्या है

प्रत्येक नोड के next पॉइंटर को, अगले नोड के बजाय पिछले नोड की ओर मोड़ने की क्रिया है। prev (ठीक पिछला नोड) को ट्रैक करते हुए एक-एक नोड आगे बढ़ें और लिंक की दिशा उलट दें।

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode nxt = curr.next;  // अगले नोड को सुरक्षित करें
    curr.next = prev;          // लिंक को पिछले नोड की ओर मोड़ें
    prev = curr;               // prev को वर्तमान नोड से अपडेट करें
    curr = nxt;                // अगले नोड पर आगे बढ़ें
}
// लूप समाप्त होने पर, prev उलटी लिस्ट के आरंभ को इंगित करता है
```

### दो लिस्टों का बारी-बारी मर्ज क्या है

दो लिस्टों के तत्वों को बारी-बारी एक-एक निकालकर एक लिस्ट में जोड़ने की क्रिया है। प्रत्येक चरण में next पॉइंटर बदलना होता है, इसलिए मूल लिंक को अस्थायी चर में सुरक्षित करके फिर बदलें।

```java
ListNode a = list1, b = list2;
while (b != null) {
    ListNode tmpA = a.next;   // a के मूल अगले नोड को सुरक्षित करें
    ListNode tmpB = b.next;   // b के मूल अगले नोड को सुरक्षित करें
    a.next = b;               // a के बाद b को डालें
    b.next = tmpA;            // b के बाद a के मूल अगले नोड को जोड़ें
    a = tmpA;                 // a को अगली स्थिति पर ले जाएँ
    b = tmpB;                 // b को अगली स्थिति पर ले जाएँ
}
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — मध्य बिंदु की खोज, उत्तरार्ध को उलटाना, और मर्ज — प्रत्येक चरण O(n) है |
| Space | O(1) — केवल पॉइंटर चरों का उपयोग होता है, कोई अतिरिक्त डेटा संरचना नहीं बनती |

## कोड

```java
// इनपुट: एकदिशीय लिंक्ड लिस्ट का आरंभ नोड head
// आउटपुट: कुछ नहीं (लिस्ट को इन-प्लेस पुनर्व्यवस्थित करता है। रिटर्न टाइप void है)
void reorderList(ListNode head) {
    // खाली लिस्ट के लिए पुनर्व्यवस्था की आवश्यकता नहीं
    if (head == null) return;

    // चरण 1: slow/fast पॉइंटर से लिस्ट का मध्य बिंदु ढूँढें
    // fast, slow की दोगुनी गति से आगे बढ़ता है, इसलिए fast के अंत तक पहुँचने पर slow मध्य नोड पर होता है
    ListNode slow = head, fast = head;
    while (fast.next != null
            && fast.next.next != null) {
        slow = slow.next;          // slow एक कदम आगे बढ़ता है
        fast = fast.next.next;     // fast दो कदम आगे बढ़ता है
    }

    // चरण 2: उत्तरार्ध लिस्ट को अलग करके उलटाएँ
    ListNode second = slow.next;   // second उत्तरार्ध लिस्ट का आरंभ नोड है
    slow.next = null;              // पूर्वार्ध लिस्ट के अंत को काटकर, पूर्वार्ध और उत्तरार्ध दो भागों में विभाजित करें
    ListNode prev = null;
    while (second != null) {
        ListNode nxt = second.next;  // अगले नोड को सुरक्षित करें
        second.next = prev;          // लिंक को पिछले नोड की ओर मोड़ें
        prev = second;               // prev को वर्तमान नोड से अपडेट करें
        second = nxt;                // अगले नोड पर आगे बढ़ें
    }
    // लूप समाप्त होने पर, prev उलटी उत्तरार्ध लिस्ट के आरंभ (मूल लिस्ट का अंत) को इंगित करता है

    // चरण 3: पूर्वार्ध और उलटे उत्तरार्ध को बारी-बारी मर्ज करें
    ListNode first = head;         // पूर्वार्ध लिस्ट का आरंभ
    second = prev;                 // उलटी उत्तरार्ध लिस्ट का आरंभ
    // विषम लंबाई की लिस्ट में पूर्वार्ध एक तत्व अधिक होता है, इसलिए उत्तरार्ध (second) समाप्त होने पर रुकें
    while (second != null) {
        ListNode tmp1 = first.next;   // पूर्वार्ध के अगले नोड को सुरक्षित करें (सुरक्षित न करें तो next बदलने पर मूल लिंक खो जाएगा)
        ListNode tmp2 = second.next;  // उत्तरार्ध के अगले नोड को सुरक्षित करें
        first.next = second;          // पूर्वार्ध के बाद उत्तरार्ध का नोड डालें
        second.next = tmp1;           // उत्तरार्ध के नोड के बाद पूर्वार्ध की शेष लिस्ट जोड़ें
        first = tmp1;                 // पूर्वार्ध के पॉइंटर को अगली स्थिति पर ले जाएँ
        second = tmp2;                // उत्तरार्ध के पॉइंटर को अगली स्थिति पर ले जाएँ
    }
}
```
