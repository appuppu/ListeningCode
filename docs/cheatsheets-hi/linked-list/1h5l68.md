# Reversing Nodes in Groups of K — लिंक्ड लिस्ट को K आकार के समूहों में विभाजित करके प्रत्येक समूह को उलटना

## समस्या का सार

एकदिशीय लिंक्ड लिस्ट का पहला नोड `head` और एक पूर्णांक `k` दिया गया है। लिस्ट को शुरू से `k` नोड्स के समूहों में विभाजित करें और प्रत्येक समूह के भीतर नोड्स के क्रम को उलटें। यदि अंतिम समूह में `k` से कम नोड्स हैं, तो उस समूह को जैसा है वैसा ही छोड़ दें। परिवर्तित लिस्ट का पहला नोड लौटाएँ।

## मुख्य विचार

शुरुआत में एक डमी नोड रखें और "समूह के ठीक पहले वाले नोड" तथा "समूह के k-वें नोड" को आधार बिंदु के रूप में उपयोग करते हुए, प्रत्येक समूह के भीतर पॉइंटर्स को एक-एक करके पुनर्निर्देशित करें। इससे बिना अतिरिक्त मेमोरी के इन-प्लेस उलटना संभव होता है।

## विचार प्रक्रिया

1. **समूह इकाई में उलटने की आवश्यकता है**: पूरी लिस्ट को नहीं, बल्कि k नोड्स के प्रत्येक समूह को उलटना है। अर्थात "वर्तमान समूह की सीमा निर्धारित करें" → "उस समूह को उलटें" → "अगले समूह पर जाएँ" — यह एक लूप संरचना बनती है
2. **समूह की सीमा निर्धारित करने के लिए k-वाँ नोड खोजना होगा**: वर्तमान स्थिति से k नोड आगे का नोड खोजने के लिए एक सहायक फ़ंक्शन `getKth` बनाएँ। यदि k-वाँ नोड मौजूद नहीं है (`null`), तो शेष नोड्स k से कम हैं, इसलिए बिना उलटे समाप्त करें
3. **उलटने के बाद समूहों को सही ढंग से जोड़ना आवश्यक है**: समूह को उलटने पर समूह का पहला और अंतिम नोड आपस में बदल जाते हैं। पिछले समूह का अंतिम नोड (`groupPrev`) उलटने के बाद के नए पहले नोड (मूल k-वें नोड) की ओर इंगित करे — इसके लिए पुनः जोड़ना आवश्यक है
4. **डमी नोड से पहले समूह के उलटने को एकरूप तरीके से संभालना**: पहले समूह को उलटने पर लिस्ट का पहला नोड स्वयं बदल जाता है। शुरुआत में डमी नोड रखने से "समूह के ठीक पहले वाला नोड नए पहले नोड की ओर इंगित करता है" — यह ऑपरेशन पहले समूह और बाद के सभी समूहों के लिए एक ही लॉजिक से संभव हो जाता है
5. **प्रत्येक समूह का उलटना मानक लिस्ट उलटने की तकनीक से किया जाता है**: `prev` और `curr` दो पॉइंटर्स का उपयोग करें और `curr.next` को `prev` की ओर पुनर्निर्देशित करते हुए एक-एक नोड आगे बढ़ें। हालाँकि, `prev` का प्रारंभिक मान समूह के अगले नोड (`groupNext`) रखने से, उलटने के बाद का अंतिम नोड स्वतः अगले समूह से जुड़ जाता है
6. **उलटने के बाद groupPrev को अपडेट करके अगले समूह पर जाएँ**: उलटने से पहले समूह का पहला नोड (`groupPrev.next`) उलटने के बाद समूह का अंतिम नोड बन जाता है। इस नोड को अगले समूह के `groupPrev` के रूप में उपयोग करें और अगले इटरेशन पर जाएँ

## पूर्वापेक्षित ज्ञान

### ListNode क्या है

ListNode एकदिशीय लिंक्ड लिस्ट के एक नोड को दर्शाने वाला क्लास है। प्रत्येक नोड में "मान (val)" और "अगले नोड का पॉइंटर (next)" होता है। जिस नोड का `next` `null` है, वह लिस्ट का अंतिम नोड है।

```java
class ListNode {
    int val;          // नोड में संग्रहीत मान
    ListNode next;    // अगले नोड का संदर्भ (अंतिम नोड के लिए null)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### डमी नोड (Dummy Node) क्या है

डमी नोड लिस्ट की शुरुआत में एक अस्थायी नोड जोड़ने की तकनीक है। जब पहले नोड में परिवर्तन होता है, तो यह तकनीक शर्त-विभाजन को अनावश्यक बना देती है। `dummy.next` हमेशा लिस्ट के वास्तविक पहले नोड की ओर इंगित करता है।

```java
ListNode dummy = new ListNode(0);  // मान कुछ भी हो सकता है
dummy.next = head;                 // डमी का अगला नोड वास्तविक पहला नोड है
// ... लिस्ट पर ऑपरेशन करें ...
return dummy.next;                 // ऑपरेशन के बाद वास्तविक पहला नोड लौटाएँ
```

### लिंक्ड लिस्ट उलटने का मूल ऑपरेशन

`prev` और `curr` दो पॉइंटर्स का उपयोग करें और प्रत्येक नोड के `next` को पिछले नोड की ओर पुनर्निर्देशित करें।

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode tmp = curr.next;  // अगले नोड को अस्थायी रूप से सहेजें
    curr.next = prev;          // वर्तमान नोड के next को पिछले नोड में बदलें
    prev = curr;               // prev को वर्तमान नोड पर आगे बढ़ाएँ
    curr = tmp;                // curr को अगले नोड पर आगे बढ़ाएँ
}
// prev उलटने के बाद का पहला नोड बन जाता है
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n) — प्रत्येक नोड को केवल स्थिर संख्या में विज़िट किया जाता है (k-वें नोड की खोज में 1 बार, उलटने में 1 बार) |
| Space | O(1) — केवल पॉइंटर वेरिएबल्स का उपयोग होता है, किसी अतिरिक्त डेटा संरचना की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: लिंक्ड लिस्ट का पहला नोड head और पूर्णांक k
// आउटपुट: k नोड्स के समूहों को उलटकर प्राप्त लिंक्ड लिस्ट का पहला नोड लौटाता है
public ListNode reverseKGroup(ListNode head, int k) {
    // डमी नोड बनाएँ और dummy.next = head से वास्तविक लिस्ट के पहले नोड से जोड़ें
    // डमी नोड का उपयोग करने से पहले समूह को उलटते समय भी "समूह के ठीक पहले वाला नोड" हमेशा मौजूद रहता है
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // groupPrev "अभी उलटे जाने वाले समूह के ठीक पहले के नोड" की ओर इंगित करता है
    // प्रारंभिक मान डमी नोड है
    ListNode groupPrev = dummy;

    // अनंत लूप में प्रत्येक इटरेशन में एक समूह को उलटा जाता है
    while (true) {
        // groupPrev के एक आगे के नोड से शुरू करके k-1 बार next का अनुसरण करके k-वाँ नोड खोजें
        // यदि बीच में null आ जाए तो शेष नोड्स k से कम हैं, इसलिए null लौटाएँ
        ListNode kth = getKth(groupPrev, k);

        // यदि k-वाँ नोड मौजूद नहीं है तो शेष k से कम हैं, इसलिए जैसा है वैसा ही छोड़कर समाप्त करें
        // k से कम नोड्स वाले समूह को जैसा है वैसा रखने की समस्या की शर्त को यह जाँच पूरा करती है
        if (kth == null) break;

        // groupNext "वर्तमान समूह के ठीक बाद का नोड" है, जो उलटने की समाप्ति सीमा के रूप में उपयोग होता है
        ListNode groupNext = kth.next;

        // prev का प्रारंभिक मान groupNext पर सेट करें
        // ऐसा करने से उलटने के बाद समूह के अंतिम नोड का next स्वतः अगले समूह के पहले नोड की ओर इंगित करता है
        ListNode prev = kth.next;
        // curr समूह के पहले नोड से शुरू होता है (उलटने के बाद यह समूह का अंतिम नोड बन जाएगा)
        ListNode curr = groupPrev.next;

        // जब तक curr groupNext के बराबर न हो जाए, समूह के प्रत्येक नोड के next पॉइंटर को उलटें
        // इस ऑपरेशन से प्रत्येक नोड का next अपने पिछले नोड की ओर इंगित करने लगता है
        while (curr != groupNext) {
            ListNode tmp = curr.next;  // अगले नोड को अस्थायी रूप से सहेजें
            curr.next = prev;          // वर्तमान नोड के next को पिछले नोड में बदलें
            prev = curr;               // prev को वर्तमान नोड पर आगे बढ़ाएँ
            curr = tmp;                // curr को अगले नोड पर आगे बढ़ाएँ
        }

        // उलटने से पहले के पहले नोड को सहेजें (उलटने के बाद यह समूह का अंतिम नोड बन चुका है)
        ListNode tmp = groupPrev.next;
        // उलटने के बाद समूह का पहला नोड kth (मूल k-वाँ नोड) है,
        // इसलिए पिछले समूह का अंतिम नोड उलटने के बाद के नए पहले नोड की ओर सही ढंग से इंगित करे — ऐसे जोड़ें
        groupPrev.next = kth;
        // उलटने से पहले जो समूह का पहला नोड था, वह उलटने के बाद समूह का अंतिम नोड बन गया है
        // इस नोड को अगले इटरेशन के groupPrev के रूप में उपयोग करें
        groupPrev = tmp;
    }

    // dummy.next ऑपरेशन के बाद पूरी लिस्ट के पहले नोड की ओर इंगित करता है
    return dummy.next;
}

// node के अगले नोड से k-वाँ नोड लौटाता है। यदि k से कम नोड्स हैं तो null लौटाता है
private ListNode getKth(ListNode node, int k) {
    // node के एक आगे के नोड से शुरू करें
    node = node.next;
    // k-1 बार next का अनुसरण करके k-वें नोड तक पहुँचें
    // यदि बीच में null आ जाए तो शेष नोड्स k से कम हैं
    while (node != null && k > 1) {
        node = node.next;
        k--;
    }
    // k-वाँ नोड लौटाएँ (यदि k से कम नोड्स थे तो null)
    return node;
}
```
