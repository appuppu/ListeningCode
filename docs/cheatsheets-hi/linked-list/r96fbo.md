# Reversing a Linked List — एकदिशीय लिंक्ड लिस्ट को उलटना

## समस्या का सार

एकदिशीय लिंक्ड लिस्ट (singly linked list) का प्रारंभिक नोड `head` दिया गया है। लिस्ट में सभी लिंक (पॉइंटर) की दिशा को उलटना है, ताकि मूल अंतिम नोड नया प्रारंभिक नोड बन जाए, और उस नए प्रारंभिक नोड को लौटाना है।

## मूल विचार

प्रत्येक नोड के `next` पॉइंटर को "अगले नोड" से "पिछले नोड" की ओर बदल देने से पूरी लिस्ट उलट जाती है। तीन पॉइंटर (prev, curr, next) का उपयोग करके, लिंक को एक-एक करके सुरक्षित रूप से बदलते हुए केवल एक बार पूरी लिस्ट को ट्रैवर्स करने से कार्य पूरा हो जाता है।

## विचार प्रक्रिया

1. **उलटने का अर्थ है लिंक की दिशा को उलटना**: लिंक्ड लिस्ट का क्रम नोड के `next` पॉइंटर द्वारा निर्धारित होता है। सभी नोड के `next` को "अगले नोड" से "पिछले नोड" में बदल देने से पूरी लिस्ट उलट जाती है
2. **लिंक बदलने पर अगले नोड का संदर्भ खो जाता है**: `curr.next = prev` लिखने के क्षण, मूल अगले नोड का संदर्भ नष्ट हो जाता है। इसलिए, बदलने से पहले `curr.next` को एक अलग चर `next` में सुरक्षित रखना आवश्यक है
3. **तीन पॉइंटर से स्थिति का प्रबंधन करना**: `prev` (लिंक बदलने का लक्ष्य, अर्थात पिछला नोड), `curr` (वर्तमान में संसाधित हो रहा नोड), `next` (मूल अगले नोड का बैकअप) — ये तीन पॉइंटर होने से लिंक बदलना और ट्रैवर्सल दोनों एक साथ किए जा सकते हैं
4. **प्रारंभिक स्थिति निर्धारित करना**: उलटने के बाद अंतिम नोड (मूल प्रारंभिक नोड) का `next` `null` होना चाहिए, इसलिए `prev` का प्रारंभिक मान `null` रखा जाता है। `curr` का प्रारंभिक मान `head` (प्रारंभिक नोड) रखा जाता है
5. **लूप की समाप्ति शर्त और रिटर्न मान**: जब `curr` `null` हो जाता है, तब सभी नोड का संसाधन पूरा हो चुका होता है। इस समय `prev` अंतिम संसाधित नोड (मूल अंतिम नोड) को इंगित कर रहा होता है, इसलिए `prev` को नए प्रारंभिक नोड के रूप में लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### ListNode (लिंक्ड लिस्ट का नोड) क्या है

लिंक्ड लिस्ट को बनाने वाला तत्व। प्रत्येक नोड में "मान (val)" और "अगले नोड का पॉइंटर (next)" होता है। अंतिम नोड का `next` `null` होता है।

```java
class ListNode {
    int val;          // नोड में संग्रहीत मान
    ListNode next;    // अगले नोड का संदर्भ (अंतिम नोड के लिए null)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### पॉइंटर बदलना क्या है

नोड के `next` फ़ील्ड में किसी अन्य नोड को असाइन करके लिंक की दिशा बदलना।

```java
// मूल स्थिति: A → B → C
// A.next, B को इंगित कर रहा है

A.next = null;   // A → null (A और B के बीच का लिंक टूट जाता है)
B.next = A;      // B → A (B से A की ओर उलटा लिंक बन जाता है)
// परिणाम: C → null, B → A → null
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n) — लिस्ट को केवल एक बार ट्रैवर्स करना पर्याप्त है |
| Space | O(1) — केवल तीन पॉइंटर चर का उपयोग होता है, किसी अतिरिक्त डेटा संरचना की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: एकदिशीय लिंक्ड लिस्ट का प्रारंभिक नोड head
// आउटपुट: उलटी हुई लिस्ट का नया प्रारंभिक नोड (ListNode) लौटाता है
ListNode reverseList(ListNode head) {
    // prev: लिंक बदलने का लक्ष्य (उलटने के बाद का "पिछला नोड")
    // पहला नोड (मूल प्रारंभिक नोड) उलटने के बाद अंतिम नोड बनता है, इसलिए उसका next null होना चाहिए। अतः प्रारंभिक मान null है
    ListNode prev = null;
    // curr: जिस नोड का लिंक अभी बदला जाएगा। प्रारंभिक नोड से संसाधन शुरू होता है
    ListNode curr = head;

    // जब curr null हो जाता है, तब सभी नोड का संसाधन पूरा हो चुका होता है
    while (curr != null) {
        // मूल अगले नोड को सुरक्षित रखना (अगले चरण में curr.next को बदला जाएगा, इसलिए संदर्भ खोने से बचाने के लिए सहेजना)
        ListNode next = curr.next;

        // लिंक को उलटना: अगले नोड के बजाय पिछले नोड को इंगित करना। यही उलटने की मुख्य क्रिया है
        curr.next = prev;

        // prev को वर्तमान नोड पर आगे बढ़ाना (अगले इटरेशन में, अगले नोड का लिंक बदलने के लक्ष्य के रूप में उपयोग होगा)
        prev = curr;
        // curr को सुरक्षित रखे गए मूल अगले नोड पर आगे बढ़ाना (इससे लिस्ट का ट्रैवर्सल जारी रहता है)
        curr = next;
    }

    // लूप के अंतिम इटरेशन में prev में अंतिम संसाधित नोड (मूल अंतिम नोड) असाइन हो चुका होता है
    // यही उलटी हुई लिस्ट का नया प्रारंभिक नोड है
    return prev;
}
```
