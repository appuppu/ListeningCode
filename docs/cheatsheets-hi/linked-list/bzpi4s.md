# Adding Two Numbers Represented as Linked Lists — उलटे क्रम की लिंक्ड लिस्ट में दर्शाई गई दो संख्याओं को जोड़ना

## समस्या का सार

दो गैर-रिक्त लिंक्ड लिस्ट दी गई हैं। प्रत्येक लिंक्ड लिस्ट एक गैर-ऋणात्मक पूर्णांक को **उलटे क्रम** (इकाई का अंक सबसे पहले) में दर्शाती है, और प्रत्येक नोड में एक अंक संग्रहीत है। दोनों संख्याओं को जोड़कर, उनके योग को उसी प्रकार **उलटे क्रम की लिंक्ड लिस्ट** के रूप में लौटाना है।

## मूल विचार

लिंक्ड लिस्ट उलटे क्रम (इकाई का अंक सबसे पहले) में संग्रहीत है, इसलिए पहले नोड से क्रमशः जोड़ने पर स्वतः ही इकाई → दहाई → सैकड़ा… के क्रम में जोड़ा जा सकता है, ठीक हाथ से गणना करने जैसा। हासिल (carry) को एक चर में आगे ले जाते हुए, प्रत्येक अंक का परिणाम एक नए नोड के रूप में जोड़ते जाना है।

## विचार प्रक्रिया

1. **उलटा क्रम लाभदायक है**: संख्याओं का जोड़ इकाई के अंक से शुरू होता है। लिंक्ड लिस्ट उलटे क्रम में है, इसलिए पहले नोड से क्रमशः प्रोसेस करने पर स्वाभाविक रूप से इकाई के अंक से जोड़ा जा सकता है। अंकों का क्रम उलटने की आवश्यकता नहीं है
2. **प्रत्येक अंक का जोड़ और हासिल का प्रबंधन**: प्रत्येक अंक पर `l1 का मान + l2 का मान + carry` की गणना करनी है। यदि योग 10 या अधिक हो तो हासिल उत्पन्न होता है। `sum % 10` उस अंक का परिणाम है, और `sum / 10` अगले अंक के लिए हासिल है। यह हाथ से गणना का नियम ही है
3. **दोनों लिस्ट की लंबाई भिन्न होने की स्थिति**: एक लिस्ट पहले समाप्त हो जाए तब भी, दूसरी लिस्ट या carry शेष रहने तक प्रोसेसिंग जारी रखनी होगी। while लूप की शर्त को `l1 != null || l2 != null || carry != 0` रखने से सभी स्थितियों को एकसमान रूप से संभाला जा सकता है
4. **डमी हेड से परिणाम लिस्ट का निर्माण सरल बनाना**: परिणाम लिस्ट के पहले नोड को विशेष रूप से न संभालने के लिए, मान 0 वाला एक डमी नोड शुरू में रखा जाता है। सभी अंकों का परिणाम `curr.next` में जोड़ते जाएं, और अंत में `dummy.next` लौटाने से सही परिणाम लिस्ट प्राप्त होती है
5. **लूप के अंदर की प्रोसेसिंग को एकसमान रखना**: प्रत्येक पुनरावृत्ति में, `l1` और `l2` यदि null नहीं हैं तो उनके मान को sum में जोड़ा जाता है और पॉइंटर को आगे बढ़ाया जाता है। null होने पर कुछ नहीं किया जाता। इस सशर्त शाखा से लिस्ट की लंबाई के अंतर को स्वाभाविक रूप से समायोजित किया जा सकता है
6. **अंत में क्या लौटाना है**: डमी हेड के अगले नोड `dummy.next` को परिणाम लिस्ट का प्रारंभ माना जाता है। इसे लौटाना है

## पूर्वापेक्षित ज्ञान

### ListNode क्या है

एकदिशीय लिंक्ड लिस्ट के नोड को दर्शाने वाला क्लास। प्रत्येक नोड में एक पूर्णांक मान `val` और अगले नोड का संदर्भ `next` होता है। जिस नोड का `next` `null` हो, वह लिस्ट का अंतिम नोड है।

```java
public class ListNode {
    int val;              // इस नोड में संग्रहीत एक अंक का मान
    ListNode next;        // अगले नोड का संदर्भ (अंतिम हो तो null)
    ListNode(int val) {   // कंस्ट्रक्टर: मान निर्दिष्ट करके नोड बनाता है
        this.val = val;
    }
}
```

### डमी हेड (Dummy Head) क्या है

लिस्ट के प्रारंभ में रखा गया एक मान-रहित डमी नोड। परिणाम लिस्ट बनाते समय, पहले नोड को विशेष रूप से संभालने की आवश्यकता नहीं रहती। सभी नोड्स को `curr.next = new ListNode(...)` से एकसमान रूप से जोड़ा जा सकता है, और अंत में `dummy.next` लौटाकर वास्तविक प्रारंभिक नोड प्राप्त किया जाता है।

```java
ListNode dummy = new ListNode(0);  // डमी हेड बनाता है
ListNode curr = dummy;             // curr लिस्ट के अंत को ट्रैक करने वाला पॉइंटर है
curr.next = new ListNode(5);       // डमी के बाद मान 5 वाला नोड जोड़ता है
curr = curr.next;                  // curr को अंत तक आगे बढ़ाता है
// dummy.next वास्तविक लिस्ट के प्रारंभ (मान 5 वाले नोड) को इंगित करता है
```

### हासिल (Carry) क्या है

एक अंक के जोड़ में योग 10 या अधिक होने पर, अगले अंक में ले जाया जाने वाला मान। `sum / 10` से इसकी गणना होती है (पूर्णांक विभाजन होने से 0 या 1 प्राप्त होता है)। वर्तमान अंक में शेष मान `sum % 10` से प्राप्त होता है।
उदाहरण: 7 + 8 = 15 के लिए, carry = 15 / 10 = 1, वर्तमान अंक का मान = 15 % 10 = 5।

## गणना जटिलता

| | मान |
|---|---|
| Time | O(max(n, m)) — दोनों लिस्ट में से लंबी वाली की लंबाई तक स्कैन करता है |
| Space | O(max(n, m)) — परिणाम लिस्ट के नोड्स की संख्या अधिकतम max(n, m) + 1 होती है |

## कोड

```java
// इनपुट: उलटे क्रम की लिंक्ड लिस्ट l1 और l2 (प्रत्येक नोड एक अंक का गैर-ऋणात्मक पूर्णांक)
// आउटपुट: दोनों संख्याओं के योग को उलटे क्रम की लिंक्ड लिस्ट के रूप में लौटाता है
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    // डमी हेड बनाता है। परिणाम लिस्ट के पहले नोड को विशेष रूप से संभालने की आवश्यकता नहीं रहती
    // अंतिम परिणाम में यह शामिल नहीं होता, dummy.next वास्तविक प्रारंभ होता है
    ListNode dummy = new ListNode(0);
    // curr परिणाम लिस्ट के अंत को ट्रैक करने वाला पॉइंटर है
    ListNode curr = dummy;
    // हासिल को संग्रहीत करने वाला चर। प्रत्येक अंक के जोड़ का परिणाम 10 या अधिक होने पर अगले अंक में ले जाया जाने वाला मान (0 या 1)
    int carry = 0;

    // जब तक किसी भी लिस्ट में नोड शेष हों या हासिल बचा हो, लूप जारी रखता है
    // carry != 0 की शर्त से, 999 + 1 = 1000 जैसे अंकों की संख्या बढ़ने वाले मामलों को भी संभाला जाता है
    while (l1 != null || l2 != null || carry != 0) {
        // पिछले अंक से आए हासिल को प्रारंभिक मान के रूप में sum की गणना करता है
        int sum = carry;

        // l1 शेष हो तो मान जोड़ता है और पॉइंटर को आगे बढ़ाता है
        // null होने पर कुछ नहीं करता। इससे l1 पहले समाप्त हो जाए तब भी प्रोसेसिंग जारी रहती है
        if (l1 != null) {
            sum += l1.val;
            l1 = l1.next;
        }

        // l2 शेष हो तो मान जोड़ता है और पॉइंटर को आगे बढ़ाता है
        // null होने पर कुछ नहीं करता। इससे l2 पहले समाप्त हो जाए तब भी प्रोसेसिंग जारी रहती है
        if (l2 != null) {
            sum += l2.val;
            l2 = l2.next;
        }

        // हासिल की गणना करता है। sum 10 या अधिक हो तो 1, 10 से कम हो तो 0 होता है
        carry = sum / 10;
        // वर्तमान अंक का मान (sum % 10) से नया नोड बनाकर परिणाम लिस्ट के अंत में जोड़ता है
        curr.next = new ListNode(sum % 10);
        // curr को अंत तक आगे बढ़ाता है ताकि अगली पुनरावृत्ति में नया नोड जोड़ा जा सके
        curr = curr.next;
    }

    // डमी हेड का अगला नोड परिणाम लिस्ट का प्रारंभ है
    return dummy.next;
}
```
