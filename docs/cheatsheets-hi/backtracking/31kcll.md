# Mapping Phone Number Digits to Letter Combinations — फ़ोन नंबर के अंकों से अक्षरों के सभी संयोजन उत्पन्न करना

## समस्या का सार

अंक 2 से 9 से बनी एक स्ट्रिंग `digits` दी गई है। प्रत्येक अंक फ़ोन के कीपैड पर संबंधित अक्षरों (उदाहरण: 2→"abc", 3→"def") से मैप होता है। `digits` के प्रत्येक अंक से एक-एक अक्षर चुनकर क्रम में जोड़ने पर बनने वाले **सभी संभव अक्षर संयोजनों** को एक सूची में लौटाना है।

## मूल विचार

प्रत्येक अंक की स्थिति पर 3 से 4 अक्षर चुने जा सकते हैं, और सभी संयोजनों को सूचीबद्ध करना आवश्यक है। एक-एक अक्षर चुनकर अंत में जोड़ना है, सभी अंकों के लिए चुनाव पूरा होने पर परिणाम में दर्ज करना है, और पिछले चुनाव को रद्द करके दूसरा अक्षर आज़माना है — इस "बैकट्रैकिंग" विधि से सभी पैटर्न की बिना छूट के खोज की जा सकती है।

## विचार प्रक्रिया

1. **प्रत्येक अंक की स्थिति पर विकल्प होते हैं**: प्रत्येक अंक के लिए 3 से 4 संबंधित अक्षर होते हैं, और प्रत्येक स्थिति पर एक अक्षर चुनना होता है। सभी स्थितियों के चुनावों का संयोजन उत्तर बनता है, इसलिए सभी पैटर्न को व्यवस्थित रूप से सूचीबद्ध करना आवश्यक है
2. **रिकर्शन से एक-एक अंक को संसाधित करना है**: पहले अंक से क्रम में एक अक्षर चुनना है, और अगले अंक की प्रोसेसिंग रिकर्सिव कॉल पर छोड़नी है। इस तरह, रिकर्शन की प्रत्येक गहराई एक अंक की स्थिति से संबंधित होती है, और संरचना सरल बनी रहती है
3. **समाप्ति शर्त सभी अंकों की प्रोसेसिंग पूरी होने पर है**: जब रिकर्शन की गहराई `digits` की लंबाई तक पहुँच जाती है, तो वर्तमान में निर्माणाधीन स्ट्रिंग एक पूर्ण संयोजन बन जाती है। इसे परिणाम सूची में जोड़ना है
4. **बैकट्रैकिंग से अन्य विकल्प आज़माने हैं**: रिकर्शन से लौटने पर, पिछले जोड़े गए अक्षर को `StringBuilder` के अंत से हटाना है। इससे उसी स्थिति पर दूसरा अक्षर आज़माने की तैयारी हो जाती है
5. **अंक से अक्षर में रूपांतरण के लिए मैपिंग ऐरे का उपयोग करना है**: इंडेक्स 0 से 9 वाली एक स्ट्रिंग ऐरे तैयार करनी है, और `digits.charAt(idx) - '0'` से अंक को पूर्णांक में बदलकर इंडेक्स एक्सेस करने पर संबंधित अक्षर समूह O(1) में प्राप्त होता है
6. **खाली स्ट्रिंग इनपुट को संभालना है**: यदि `digits` खाली है तो कोई संयोजन संभव नहीं है, इसलिए खाली सूची को वैसे ही लौटाना है

## पूर्वापेक्षित ज्ञान

### बैकट्रैकिंग क्या है

यह एक खोज विधि है जिसमें हल के उम्मीदवार को एक-एक करके बनाया जाता है, पूरा होने पर दर्ज किया जाता है, और पिछले चुनाव को रद्द करके दूसरा विकल्प आज़माया जाता है। सभी संयोजनों और क्रमचयों को सूचीबद्ध करने वाली समस्याओं में इसका उपयोग होता है। "चुनना → आगे बढ़ना → वापस लौटना → दूसरा आज़माना" के चक्र को रिकर्शन से साकार किया जाता है।

```java
// बैकट्रैकिंग का मूल पैटर्न
void backtrack(स्थिति, परिणाम_सूची) {
    if (समाप्ति_शर्त) {
        परिणाम_सूची.add(वर्तमान_स्थिति);
        return;
    }
    for (विकल्प : वर्तमान_विकल्प_सूची) {
        स्थिति_में_विकल्प_जोड़ना;       // चुनना
        backtrack(अगली_स्थिति, परिणाम_सूची); // आगे बढ़ना
        स्थिति_से_विकल्प_हटाना;     // वापस लौटना (बैकट्रैक)
    }
}
```

### StringBuilder क्या है

यह स्ट्रिंग को कुशलता से बनाने के लिए एक क्लास है। `String` अपरिवर्तनीय है (हर बदलाव पर नया ऑब्जेक्ट बनता है), लेकिन `StringBuilder` आंतरिक बफ़र को सीधे संशोधित करता है, इसलिए अक्षर जोड़ना और हटाना O(1) में होता है। बैकट्रैकिंग में स्ट्रिंग बनाते समय यह उपयुक्त है।

```java
StringBuilder sb = new StringBuilder();  // खाली StringBuilder बनाना
sb.append('a');           // अंत में अक्षर 'a' जोड़ना → "a"
sb.append('b');           // अंत में अक्षर 'b' जोड़ना → "ab"
sb.deleteCharAt(sb.length() - 1);  // अंतिम अक्षर हटाना → "a"
sb.toString();            // String प्रकार में बदलकर लौटाना → "a"
```

### फ़ोन कीपैड मैपिंग

अंक और अक्षरों के संबंध को ऐरे से व्यक्त किया जाता है। ऐरे का इंडेक्स अंक से संबंधित होता है, और मान उस अंक को आवंटित अक्षर समूह होता है।

```java
String[] phone = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
// phone[2] → "abc",  phone[7] → "pqrs",  phone[9] → "wxyz"
// अक्षर '3' से पूर्णांक 3 में रूपांतरण: '3' - '0' → 3
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(4^n) — प्रत्येक अंक में अधिकतम 4 अक्षरों के विकल्प होते हैं, और n अंकों के सभी संयोजनों को सूचीबद्ध किया जाता है |
| Space | O(n) — रिकर्शन की अधिकतम गहराई n होती है, StringBuilder की लंबाई भी अधिकतम n होती है (परिणाम सूची को छोड़कर) |

## कोड

```java
// इनपुट: अंक 2 से 9 से बनी स्ट्रिंग digits
// आउटपुट: सभी अक्षर संयोजनों को संग्रहीत करने वाली List<String> लौटाना

// बैकट्रैक से एक-एक अंक के लिए अक्षर चुनकर सभी संयोजनों को सूचीबद्ध करना
void backtrack(String digits, String[] phone, int idx, StringBuilder path, List<String> result) {
    // समाप्ति शर्त: यदि idx, digits की लंबाई के बराबर है तो सभी अंकों के अक्षर चुने जा चुके हैं
    // StringBuilder की सामग्री को String में बदलकर परिणाम में जोड़ना है
    if (idx == digits.length()) {
        result.add(path.toString());
        return;
    }

    // digits.charAt(idx) - '0' से अक्षर के अंक को पूर्णांक में बदलकर phone ऐरे से संबंधित अक्षर समूह प्राप्त करना है
    String letters = phone[digits.charAt(idx) - '0'];

    // वर्तमान अंक से संबंधित प्रत्येक अक्षर को एक-एक करके आज़माना है
    for (char c : letters.toCharArray()) {
        path.append(c);                            // चयन: अक्षर चुनकर अंत में जोड़ना
        backtrack(digits, phone, idx + 1, path, result);  // रिकर्शन: अगले अंक की प्रोसेसिंग पर आगे बढ़ना
        path.deleteCharAt(path.length() - 1);      // पुनर्स्थापन: अंतिम अक्षर हटाकर मूल स्थिति में लौटना (बैकट्रैक)
    }
}

List<String> letterCombinations(String digits) {
    // परिणाम संग्रहीत करने के लिए खाली सूची बनाना
    List<String> result = new ArrayList<>();

    // यदि खाली स्ट्रिंग है तो कोई संयोजन संभव नहीं है इसलिए खाली सूची लौटाना है
    if (digits.isEmpty()) return result;

    // इंडेक्स अंक से संबंधित मैपिंग ऐरे को परिभाषित करना
    // इंडेक्स 0 और 1 पर फ़ोन कीपैड में कोई अक्षर आवंटित नहीं है इसलिए खाली स्ट्रिंग रखना है
    String[] phone = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};

    // स्थिति 0 से खाली StringBuilder के साथ बैकट्रैक शुरू करना
    backtrack(digits, phone, 0, new StringBuilder(), result);

    // सभी रिकर्शन पूर्ण होने पर सभी संयोजनों से भरी result सूची लौटाना
    return result;
}
```
