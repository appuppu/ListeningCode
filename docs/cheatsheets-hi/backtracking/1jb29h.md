# Generating All Valid Parentheses Combinations — n जोड़ी कोष्ठकों से सभी वैध संयोजन उत्पन्न करना

## समस्या का सार

एक पूर्णांक `n` दिया गया है। `n` खुले कोष्ठक `(` और `n` बंद कोष्ठक `)` का उपयोग करके, सही ढंग से नेस्ट की गई सभी कोष्ठक स्ट्रिंग उत्पन्न करें और उन्हें एक सूची में लौटाएँ। प्रत्येक स्ट्रिंग की लंबाई `2 * n` होती है, और किसी भी स्थान पर बंद कोष्ठकों की संचयी संख्या खुले कोष्ठकों की संचयी संख्या से अधिक नहीं होनी चाहिए।

## मूल विचार

जब स्ट्रिंग को एक-एक अक्षर करके बनाया जाता है, तो "शेष खुले कोष्ठकों की संख्या" और "शेष बंद कोष्ठकों की संख्या" — इन दो स्थितियों से ही अगला रखा जाने वाला अक्षर निर्धारित होता है। खुला कोष्ठक तब जोड़ा जा सकता है जब `n` से कम उपयोग हुए हों, और बंद कोष्ठक तब जोड़ा जा सकता है जब वह खुले कोष्ठकों से कम हो। इस शर्त से शाखाओं की छँटाई करने पर, एक भी अवैध स्ट्रिंग उत्पन्न किए बिना सभी वैध संयोजनों की गणना की जा सकती है।

## विचार प्रक्रिया

1. **सभी संयोजनों की गणना करनी होगी**: समस्या "सभी उत्पन्न करो" कहती है, इसलिए सभी पैटर्न की खोजपूर्ण गणना करने वाली विधि आवश्यक है। स्ट्रिंग को एक-एक अक्षर करके बनाते हुए शाखाओं में विभाजित करने वाला बैकट्रैकिंग उपयुक्त है
2. **प्रत्येक चरण में केवल दो विकल्प हैं**: स्ट्रिंग की प्रत्येक स्थिति पर रखा जाने वाला अक्षर केवल `(` या `)` है। इन दो विकल्पों को पुनरावर्ती रूप से दोहराकर सभी उम्मीदवारों की खोज की जा सकती है
3. **अवैध शाखाओं को जल्दी समाप्त करना चाहिए**: सभी दो विकल्पों को आज़माने पर `2^(2n)` संयोजन बनते हैं, लेकिन अधिकांश अवैध होते हैं। वैधता की शर्तें दो हैं: खुले कोष्ठक `n` से अधिक उपयोग नहीं किए जा सकते, और बंद कोष्ठकों की संख्या उस समय तक के खुले कोष्ठकों की संख्या से अधिक नहीं हो सकती। इन दो शर्तों से शाखाओं की छँटाई की जाती है
4. **स्थिति को दो चरों से प्रबंधित किया जा सकता है**: `open` (उपयोग किए गए खुले कोष्ठकों की संख्या) और `close` (उपयोग किए गए बंद कोष्ठकों की संख्या) को पुनरावर्ती फ़ंक्शन में पास किया जाता है। `open < n` हो तो `(` जोड़ा जा सकता है, `close < open` हो तो `)` जोड़ा जा सकता है
5. **स्ट्रिंग की लंबाई `2 * n` तक पहुँचने पर वह पूर्ण होती है**: `open` और `close` की शर्तों का पालन करते हुए बनाई गई स्ट्रिंग जब `2 * n` अक्षरों तक पहुँचती है, तो वह स्ट्रिंग अवश्य वैध होती है। उसे परिणाम सूची में जोड़ा जाता है
6. **बैकट्रैकिंग से स्थिति को पुनर्स्थापित किया जाता है**: `StringBuilder` में अक्षर जोड़कर पुनरावर्ती कॉल करने के बाद, `deleteCharAt` से अंतिम अक्षर हटाकर मूल स्थिति में लौटा जाता है। इस प्रकार एक ही `StringBuilder` इंस्टेंस को सभी खोज पथों में साझा किया जा सकता है

## पूर्वापेक्षित ज्ञान

### बैकट्रैकिंग क्या है

चयन → पुनरावर्तन → रद्द करना — इसे दोहराकर सभी वैध संयोजनों की गणना करने वाली खोज विधि है। प्रत्येक चरण में विकल्पों में से एक को चुना जाता है और पुनरावर्ती रूप से अगले चरण में बढ़ा जाता है। पुनरावर्तन से लौटने पर चयन को रद्द किया जाता है (बैकट्रैक) और दूसरा विकल्प आज़माया जाता है। छँटाई शर्त जोड़कर अवैध पथों को जल्दी समाप्त किया जा सकता है।

```java
// बैकट्रैकिंग का मूल पैटर्न
void backtrack(स्थिति) {
    if (समाप्ति शर्त) {
        परिणाम में जोड़ें;
        return;
    }
    for (प्रत्येक विकल्प) {
        चयन लागू करें;        // उदाहरण: sb.append('(')
        backtrack(अगली स्थिति);
        चयन रद्द करें;    // उदाहरण: sb.deleteCharAt(sb.length() - 1)
    }
}
```

### StringBuilder क्या है

स्ट्रिंग को कुशलतापूर्वक बनाने के लिए एक क्लास है। `String` अपरिवर्तनीय (immutable) होती है इसलिए अक्षर जोड़ने पर हर बार नया ऑब्जेक्ट बनता है, लेकिन `StringBuilder` आंतरिक बफ़र को सीधे संचालित करता है, जिससे जोड़ना और हटाना O(1) में होता है।

```java
StringBuilder sb = new StringBuilder();  // खाली StringBuilder बनाएँ
sb.append('(');          // अंत में अक्षर जोड़ें → "("
sb.append(')');          // अंत में अक्षर जोड़ें → "()"
sb.length();             // वर्तमान अक्षर संख्या लौटाएँ → 2
sb.deleteCharAt(1);      // इंडेक्स 1 का अक्षर हटाएँ → "("
sb.toString();           // String प्रकार में बदलकर लौटाएँ → "("
```

### कोष्ठकों की वैधता की शर्तें

कोष्ठक स्ट्रिंग "वैध" तब होती है जब निम्नलिखित दो शर्तें पूरी हों:
- **शर्त 1**: खुले कोष्ठकों और बंद कोष्ठकों की संख्या बराबर हो
- **शर्त 2**: स्ट्रिंग की किसी भी स्थिति पर, शुरू से उस स्थिति तक बंद कोष्ठकों की संख्या खुले कोष्ठकों की संख्या से अधिक न हो

उदाहरण: `n=2` के लिए, `(())` और `()()` वैध हैं। `)()(` शर्त 2 का उल्लंघन करती है, `((()` शर्त 1 का उल्लंघन करती है।

## जटिलता

| | मान |
|---|---|
| Time | O(4^n / √n) — उत्पन्न होने वाली वैध कोष्ठक स्ट्रिंग की संख्या कैटलन संख्या C(n) = C(2n,n)/(n+1) है, जो O(4^n / (n√n)) के अनुमानित है। प्रत्येक स्ट्रिंग के निर्माण में O(n) लगता है, इसलिए कुल मिलाकर O(4^n / √n) होता है |
| Space | O(n) — पुनरावर्तन की अधिकतम गहराई 2n है, और StringBuilder की अधिकतम लंबाई भी 2n है। परिणाम सूची को छोड़कर उपयोग किया जाने वाला स्थान O(n) है |

## कोड

```java
// इनपुट: पूर्णांक n (कोष्ठक जोड़ियों की संख्या)
// आउटपुट: सभी वैध कोष्ठक स्ट्रिंग को संग्रहीत करने वाली List<String> लौटाएँ
private void backtrack(StringBuilder sb, int open, int close, int n, List<String> res) {
    // स्ट्रिंग की लंबाई 2n तक पहुँचने पर, खुले और बंद कोष्ठक ठीक n-n उपयोग हो चुके हैं इसलिए वैध कोष्ठक स्ट्रिंग पूर्ण हुई
    if (sb.length() == 2 * n) {
        res.add(sb.toString());
        return;
    }
    // यदि कोई भी शर्त पूरी नहीं होती, तो और अक्षर नहीं जोड़े जा सकते इसलिए बिना कुछ किए return होता है, और कॉलर में बैकट्रैकिंग आगे बढ़ती है

    // यदि खुले कोष्ठक n से कम हैं, तो अभी और खुले कोष्ठक जोड़े जा सकते हैं
    if (open < n) {
        sb.append('(');
        backtrack(sb, open + 1, close, n, res);
        // बैकट्रैकिंग का मूल: अंतिम '(' हटाकर स्थिति पुनर्स्थापित करें, ताकि अगली शाखा (बंद कोष्ठक जोड़ना) सही स्थिति से आज़माई जा सके
        sb.deleteCharAt(sb.length() - 1);
    }

    // ध्यान दें: शर्त close < n नहीं बल्कि close < open है — यह महत्वपूर्ण है
    // close < n से बंद कोष्ठक खुले कोष्ठकों से अधिक हो सकते हैं (उदाहरण: ")("), लेकिन
    // close < open से बंद कोष्ठकों की संख्या हमेशा खुले कोष्ठकों की संख्या से कम या बराबर रहती है, जिससे अवैध स्ट्रिंग का निर्माण रुकता है
    if (close < open) {
        sb.append(')');
        backtrack(sb, open, close + 1, n, res);
        sb.deleteCharAt(sb.length() - 1);  // स्थिति पुनर्स्थापित करें
    }
}

public List<String> generateParenthesis(int n) {
    // सभी वैध कोष्ठक स्ट्रिंग संग्रहीत करने वाली सूची
    List<String> res = new ArrayList<>();
    // खाली StringBuilder और open=0, close=0 से खोज शुरू करें
    backtrack(new StringBuilder(), 0, 0, n, res);
    return res;
}
```
