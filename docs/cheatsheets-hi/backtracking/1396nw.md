# Partitioning a String Into Palindrome Substrings — एक स्ट्रिंग को palindrome सबस्ट्रिंग्स में विभाजित करने के सभी पैटर्न ज्ञात करना

## समस्या का सार

एक स्ट्रिंग `s` दी गई है। `s` को इस प्रकार विभाजित करना है कि सभी सबस्ट्रिंग्स palindrome (आगे से पढ़ने और पीछे से पढ़ने पर समान स्ट्रिंग) हों, ऐसे **सभी** विभाजन पैटर्न को सूचियों की सूची के रूप में लौटाना है।

## मूल विचार

किसी भी सबस्ट्रिंग के palindrome होने या न होने का निर्णय DP टेबल से पूर्व-गणना करके O(1) में करना संभव बनाते हैं, और बैकट्रैकिंग द्वारा आरंभ से क्रमशः "palindrome वाले भाग" को काटकर पुनरावर्तन करते हुए, सभी विभाजन पैटर्न को कुशलतापूर्वक सूचीबद्ध किया जा सकता है।

## विचार प्रक्रिया

1. **विभाजन समस्या को आरंभ से क्रमशः काटने वाले पुनरावर्तन द्वारा व्यक्त किया जा सकता है**: स्ट्रिंग की आरंभ स्थिति `start` से अंत तक की सीमा में, `start` से `end` तक की सबस्ट्रिंग को एक काटकर, शेष भाग को पुनरावर्ती रूप से संसाधित करना है। जब `start` स्ट्रिंग के अंत तक पहुँच जाता है, तब एक मान्य विभाजन पूरा होता है
2. **काटने की शर्त "वह भाग palindrome हो" है**: सभी सबस्ट्रिंग्स का palindrome होना आवश्यक है, इसलिए `s[start..end]` palindrome होने पर ही उसे काटकर पथ में जोड़ा जाता है और पुनरावर्तन आगे बढ़ता है। palindrome न होने पर उस कटाव को छोड़ दिया जाता है
3. **हर बार palindrome जाँच O(n) में करना अकुशल है**: बैकट्रैकिंग के प्रत्येक चरण में सबस्ट्रिंग की palindrome जाँच होती है, लेकिन एक ही सबस्ट्रिंग की कई बार जाँच हो सकती है। DP टेबल से पूर्व-गणना करने पर, किसी भी `s[l..r]` की palindrome जाँच O(1) में की जा सकती है
4. **DP टेबल की निर्माण विधि**: `dp[l][r]` यह दर्शाता है कि "`s` के इंडेक्स `l` से `r` तक की सबस्ट्रिंग palindrome है या नहीं" — यह एक boolean है। palindrome की शर्त "दोनों सिरों के अक्षर समान हों" और "आंतरिक सबस्ट्रिंग भी palindrome हो" है। लंबाई 1 (`l == r`) सदैव palindrome होती है, लंबाई 2 (`r - l == 1`) दोनों सिरे समान होने पर palindrome होती है, लंबाई 3 या अधिक में `s[l] == s[r]` और `dp[l+1][r-1]` true होने पर palindrome होती है
5. **बैकट्रैकिंग की संरचना**: वर्तमान स्थिति `start` से `end` को `start` से `s.length()-1` तक एक-एक करके बढ़ाया जाता है, `dp[start][end]` true होने पर सबस्ट्रिंग को पथ में जोड़कर `end+1` से पुनरावर्तन किया जाता है। पुनरावर्तन से लौटने पर पथ के अंतिम तत्व को हटाकर अन्य कटाव का प्रयास किया जाता है
6. **अंतिम रूप से लौटाया जाने वाला परिणाम**: जब भी `start` `s.length()` तक पहुँचता है, वर्तमान पथ की प्रतिलिपि परिणाम सूची में जोड़ी जाती है। सभी पुनरावर्तन समाप्त होने पर, परिणाम सूची लौटाई जाती है

## पूर्वापेक्षित ज्ञान

### Palindrome (पैलिंड्रोम) क्या है

आगे से पढ़ने और पीछे से पढ़ने पर समान रहने वाली स्ट्रिंग को palindrome कहते हैं। उदाहरण के लिए `"aba"`, `"aa"`, `"a"` palindrome हैं। `"ab"` palindrome नहीं है।

### 2-आयामी boolean सरणी द्वारा palindrome DP टेबल

`dp[l][r]` से "इंडेक्स `l` से `r` तक की सबस्ट्रिंग palindrome है या नहीं" O(1) में निर्धारित करने वाली टेबल। बाहरी लूप में दायाँ सिरा `r` स्थिर किया जाता है, और आंतरिक लूप में बायाँ सिरा `l` को `0` से `r` तक चलाकर निर्माण किया जाता है।

```java
boolean[][] dp = new boolean[n][n];
for (int r = 0; r < n; r++) {
    for (int l = 0; l <= r; l++) {
        // दोनों सिरों के अक्षर समान हों, और आंतरिक भाग palindrome हो (या लंबाई 2 या कम हो) तो palindrome है
        if (s.charAt(l) == s.charAt(r) && (r - l < 2 || dp[l + 1][r - 1])) {
            dp[l][r] = true;
        }
    }
}
dp[0][2];  // s[0] से s[2] तक palindrome है या नहीं → true or false
```

### बैकट्रैकिंग क्या है

एक विकल्प चुनकर पुनरावर्ती रूप से आगे बढ़ना, शर्त पूरी न होने पर पिछले चयन को रद्द करके अन्य विकल्प आज़माने की खोज तकनीक है। पथ में जोड़ना (चयन) → पुनरावर्तन → पथ से हटाना (रद्द करना) — इन 3 चरणों से बना होता है।

```java
path.add(choice);                    // चयन करना
backtrack(nextState, path, result);  // पुनरावर्तन द्वारा आगे बढ़ना
path.remove(path.size() - 1);       // चयन रद्द करके अन्य मार्ग आज़माना
```

### substring मेथड

`String.substring(start, end)` इंडेक्स `start` से `end - 1` तक की सबस्ट्रिंग लौटाता है। `end` शामिल नहीं होता, इस बात पर ध्यान देना चाहिए।

```java
String s = "aab";
s.substring(0, 1);  // "a"
s.substring(0, 2);  // "aa"
s.substring(0, 3);  // "aab"
```

## जटिलता

| | मान |
|---|---|
| Time | O(n × 2^n) — DP टेबल निर्माण में O(n^2), बैकट्रैकिंग में अधिकतम 2^(n-1) विभाजन सूचीबद्ध होते हैं और प्रत्येक विभाजन में सबस्ट्रिंग की प्रतिलिपि में O(n) लगता है |
| Space | O(n^2) — DP टेबल में n×n की boolean सरणी का उपयोग होता है। पुनरावर्तन स्टैक की अधिकतम गहराई O(n) है |

## कोड

```java
// इनपुट: स्ट्रिंग s
// आउटपुट: s के सभी palindrome विभाजन पैटर्न को संग्रहीत करने वाला List<List<String>>
List<List<String>> partition(String s) {
    int n = s.length();

    // dp[l][r] = s[l] से s[r] तक की सबस्ट्रिंग palindrome है या नहीं दर्शाने वाली DP टेबल
    boolean[][] dp = new boolean[n][n];
    // बाहरी लूप में दायाँ सिरा r स्थिर करके, आंतरिक लूप में बायाँ सिरा l को 0 से r तक चलाकर निर्माण करना
    for (int r = 0; r < n; r++) {
        for (int l = 0; l <= r; l++) {
            // दोनों सिरों के अक्षर समान हों, और आंतरिक भाग palindrome हो (या लंबाई 2 या कम हो) तो palindrome है
            // r - l < 2 की शर्त: लंबाई 1 सदैव palindrome, लंबाई 2 दोनों सिरे समान होने पर palindrome
            if (s.charAt(l) == s.charAt(r)
                && (r - l < 2
                || dp[l + 1][r - 1])) {
                dp[l][r] = true;
            }
        }
    }

    // सभी विभाजन पैटर्न को संग्रहीत करने वाली परिणाम सूची
    List<List<String>> res = new ArrayList<>();
    // आरंभ स्थिति 0, रिक्त पथ के साथ बैकट्रैकिंग प्रारंभ करना
    bt(s, 0, new ArrayList<>(), res, dp);
    return res;
}

void bt(String s, int start,
    List<String> path,
    List<List<String>> res,
    boolean[][] dp) {
    // स्ट्रिंग के अंत तक पहुँचना → संपूर्ण स्ट्रिंग palindrome सबस्ट्रिंग्स में पूरी तरह विभाजित हो गई
    if (start == s.length()) {
        // path इसके बाद परिवर्तित होगा, इसलिए प्रतिलिपि जोड़ी जाती है
        res.add(new ArrayList<>(path));
        return;
    }

    // start से end तक की सबस्ट्रिंग को क्रमशः आज़माना
    for (int end = start; end < s.length();
        end++) {
        // DP टेबल द्वारा palindrome जाँच O(1) में करना
        if (dp[start][end]) {
            // palindrome भाग को पथ में जोड़कर पुनरावर्तन करना
            // substring का दूसरा तर्क अनन्य (exclusive) है इसलिए end + 1 निर्दिष्ट करना
            path.add(
                s.substring(start, end + 1));
            // अगली आरंभ स्थिति end + 1 है (काटे गए भाग के ठीक बाद)
            bt(s, end + 1, path, res, dp);
            // चयन रद्द करके अन्य कटाव आज़माना (बैकट्रैक)
            path.remove(path.size() - 1);
        }
    }
}
```
