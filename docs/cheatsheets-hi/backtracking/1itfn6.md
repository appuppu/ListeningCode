# Generating All Unique Subsets With Duplicates — डुप्लिकेट तत्वों वाले ऐरे से सभी यूनिक सबसेट जनरेट करना

## समस्या का सार

डुप्लिकेट मान वाले संभावित पूर्णांक ऐरे `nums` दिया गया है। सभी संभव यूनिक सबसेट लौटाने हैं। परिणाम में डुप्लिकेट सबसेट शामिल नहीं होने चाहिए, और प्रत्येक सबसेट में तत्वों का क्रम कोई भी हो सकता है।

## मूल विचार

यदि ऐरे को सॉर्ट कर दिया जाए, तो उसी रिकर्शन लेवल पर पिछले तत्व के समान मान चुनने की कोशिश होने पर उसे स्किप करने मात्र से डुप्लिकेट सबसेट का जनरेशन मूल रूप से रोका जा सकता है।

## विचार प्रक्रिया

1. **सबसेट जनरेशन बैकट्रैकिंग की क्लासिक समस्या है**: प्रत्येक तत्व के लिए "चुनना है या नहीं" को रिकर्सिव रूप से तय करके सभी सबसेट की गणना की जा सकती है। रिकर्शन के प्रत्येक चरण में वर्तमान सबसेट को परिणाम में जोड़ने से सभी सबसेट प्राप्त होते हैं
2. **डुप्लिकेट का कारण पहचानना**: ऐरे में एक ही मान कई बार होने पर, उदाहरण के लिए `[1,2,2]` में पहले 2 को चुनने और दूसरे 2 को चुनने पर एक ही सबसेट बनता है। डुप्लिकेट तब उत्पन्न होता है जब "उसी रिकर्शन लेवल पर एक ही मान को कई बार चुना जाता है"
3. **सॉर्ट करके डुप्लिकेट तत्वों को पास-पास लाना**: ऐरे को सॉर्ट करने से समान मान वाले तत्व एक-दूसरे के बगल में आ जाते हैं। इससे "पिछले तत्व के समान मान है या नहीं" को साधारण तुलना से जांचा जा सकता है
4. **उसी रिकर्शन लेवल पर डुप्लिकेट को स्किप करना**: for लूप में जब `i > start && nums[i] == nums[i-1]` शर्त पूरी होती है, तब उस तत्व को स्किप किया जाता है। `i > start` शर्त का अर्थ है "उसी रिकर्शन लेवल का दूसरा या उसके बाद का विकल्प", जिससे अलग-अलग रिकर्शन लेवल पर समान मान चुना जा सकता है (सबसेट में एक ही मान कई बार शामिल करना अनुमत है)
5. **रिकर्शन के प्रत्येक चरण में परिणाम में जोड़ना**: रिकर्सिव फंक्शन की शुरुआत में वर्तमान सबसेट `curr` को परिणाम सूची में जोड़ा जाता है। इससे खाली सेट से लेकर सभी तत्वों वाले सेट तक, सभी सबसेट परिणाम में शामिल होते हैं
6. **बैकट्रैकिंग से मूल स्थिति में लौटना**: रिकर्सिव कॉल के बाद `curr` के अंतिम तत्व को हटाकर मूल स्थिति में लौटने से, अगले विकल्प की सही तरह से खोज की जा सकती है

## पूर्वापेक्षित ज्ञान

### बैकट्रैकिंग क्या है

समाधान के उम्मीदवारों को रिकर्सिव रूप से बनाने और शर्त पूरी न होने पर पिछले चुनाव को रद्द करके दूसरा चुनाव आज़माने की खोज विधि है। इसका उपयोग सबसेट, परमुटेशन और कॉम्बिनेशन की गणना में किया जाता है।

```java
// बैकट्रैकिंग की मूल संरचना
void backtrack(स्थिति, विकल्पसूची) {
    परिणाम में वर्तमान स्थिति जोड़ें;
    for (प्रत्येक विकल्प) {
        चुनाव लागू करें;
        backtrack(अगली स्थिति, शेष विकल्प);
        चुनाव रद्द करें;  // ← बैकट्रैक
    }
}
```

### Arrays.sort क्या है

ऐरे को आरोही क्रम में सॉर्ट करने वाला मेथड है। डुप्लिकेट तत्वों को पास-पास रखकर डुप्लिकेट की पहचान को आसान बनाता है।

```java
int[] nums = {4, 1, 4, 2};
Arrays.sort(nums);  // nums = {1, 2, 4, 4} बन जाता है
```

### ArrayList की कॉपी के बारे में

`new ArrayList<>(list)` मौजूदा लिस्ट की शैलो कॉपी बनाता है। परिणाम में सबसेट जोड़ते समय, रेफरेंस के बजाय कॉपी जोड़नी चाहिए, अन्यथा बाद की बैकट्रैकिंग में सामग्री बदल जाती है।

```java
List<Integer> curr = new ArrayList<>();
curr.add(1);
curr.add(2);
List<Integer> copy = new ArrayList<>(curr);  // [1, 2] की कॉपी बनाई गई
curr.remove(curr.size() - 1);               // curr [1] पर वापस आ जाता है, लेकिन copy [1, 2] ही रहता है
```

### List के अंतिम तत्व को हटाना

`list.remove(list.size() - 1)` लिस्ट के अंतिम तत्व को हटाता है। बैकट्रैकिंग में पिछले चरण में जोड़े गए तत्व को रद्द करने के लिए इसका उपयोग किया जाता है।

```java
List<Integer> curr = new ArrayList<>();
curr.add(5);        // curr = [5]
curr.add(3);        // curr = [5, 3]
curr.remove(curr.size() - 1);  // curr = [5] पर वापस आ जाता है
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n × 2^n) — अधिकतम 2^n सबसेट मौजूद होते हैं, और प्रत्येक सबसेट की कॉपी में अधिकतम O(n) लगता है |
| Space | O(n) — रिकर्शन की गहराई अधिकतम n होती है, और कार्यकारी सूची `curr` की लंबाई भी अधिकतम n होती है (परिणाम सूची को छोड़कर) |

## कोड

```java
// इनपुट: डुप्लिकेट हो सकने वाला पूर्णांक ऐरे nums
// आउटपुट: सभी यूनिक सबसेट को संग्रहित करने वाली List<List<Integer>> लौटाता है
void backtrack(int[] nums, int start, List<Integer> curr, List<List<Integer>> result) {
    // वर्तमान सबसेट की कॉपी को परिणाम में जोड़ें
    // new ArrayList<>(curr) से कॉपी बनाने का कारण: curr बाद की रिकर्शन में बदलता है, इसलिए रेफरेंस नहीं बल्कि उस समय की स्थिति को सहेजना आवश्यक है
    result.add(new ArrayList<>(curr));

    // start से स्कैन करने से अपने से पहले के तत्व नहीं चुने जाते और सबसेट में तत्वों का क्रम बना रहता है
    for (int i = start; i < nums.length; i++) {
        // उसी रिकर्शन लेवल पर पिछले तत्व के समान मान होने पर डुप्लिकेट रोकने के लिए स्किप करें
        // i > start: यह इस लेवल का पहला विकल्प नहीं है (अलग लेवल पर समान मान चुना जा सकता है)
        // nums[i] == nums[i-1]: पिछले तत्व के समान मान है
        // ये दोनों शर्तें एक साथ पूरी होने पर, उसी लेवल पर समान मान दो बार चुना जाएगा जिससे डुप्लिकेट सबसेट बनेगा
        if (i > start && nums[i] == nums[i - 1]) continue;

        // वर्तमान तत्व को सबसेट में जोड़कर अगले लेवल पर आगे बढ़ें
        curr.add(nums[i]);
        // i + 1 पास करने से अगले रिकर्शन लेवल में केवल वर्तमान तत्व के बाद के तत्व ही चयन योग्य होते हैं
        backtrack(nums, i + 1, curr, result);

        // बैकट्रैक: अंतिम तत्व हटाकर मूल स्थिति में लौटें, ताकि अगले इटरेशन में दूसरा तत्व चुना जा सके
        curr.remove(curr.size() - 1);
    }
}

public List<List<Integer>> subsetsWithDup(int[] nums) {
    // सॉर्ट करके समान मान वाले तत्वों को पास-पास लाएं। इससे nums[i] == nums[i-1] की साधारण तुलना से डुप्लिकेट पहचान संभव होती है
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    // 0 का अर्थ है "ऐरे की शुरुआत से खोज आरंभ करें"
    backtrack(nums, 0, new ArrayList<>(), result);
    // सभी रिकर्शन पूर्ण होने पर, result में सभी यूनिक सबसेट संग्रहित हो चुके हैं
    return result;
}
```
