# Generating All Subsets of a Set — किसी समुच्चय के सभी उपसमुच्चय उत्पन्न करना

## समस्या का सार

विभिन्न पूर्णांकों की एक सरणी `nums` दी गई है। `nums` के सभी उपसमुच्चयों (घात समुच्चय) की सूची लौटानी है। उपसमुच्चयों में कोई दोहराव नहीं होना चाहिए, और लौटाने का क्रम कोई भी हो सकता है।

## मूल विचार

`n` तत्वों वाले समुच्चय में `2^n` उपसमुच्चय होते हैं। `n` बिट के पूर्णांक को `0` से `2^n - 1` तक गिनने पर, प्रत्येक बिट "संबंधित तत्व को शामिल करना या न करना" दर्शाता है, इसलिए सभी उपसमुच्चय बिना किसी छूट या दोहराव के उत्पन्न किए जा सकते हैं।

## विचार प्रक्रिया

1. **उपसमुच्चयों की संख्या 2^n से निर्धारित होती है**: प्रत्येक तत्व के लिए "शामिल करना" या "शामिल न करना" के दो विकल्प होते हैं, इसलिए `n` तत्वों वाले समुच्चय में `2^n` उपसमुच्चय मौजूद होते हैं। सभी को गिनने के लिए, इन `2^n` चयन पैटर्नों को व्यक्त करने की एक विधि आवश्यक है
2. **दो विकल्पों की गणना बिट से की जा सकती है**: "शामिल करना=1, शामिल न करना=0" का संगत बनाने पर, `n` तत्वों का चयन पैटर्न `n` बिट के पूर्णांक से व्यक्त किया जा सकता है। उदाहरण के लिए `nums = [a, b, c]` के लिए, बिट श्रृंखला `101` का अर्थ है "a को शामिल करना, b को शामिल न करना, c को शामिल करना" अर्थात उपसमुच्चय `[a, c]`
3. **0 से 2^n-1 तक के पूर्णांक सभी पैटर्नों को समाहित करते हैं**: `n` बिट से व्यक्त किए जा सकने वाले पूर्णांक `0` (सभी बिट 0 = रिक्त समुच्चय) से `2^n - 1` (सभी बिट 1 = सभी तत्वों वाला समुच्चय) तक `2^n` होते हैं। इन्हें क्रमशः गिनने पर सभी उपसमुच्चय बिना छूट या दोहराव के उत्पन्न किए जा सकते हैं
4. **प्रत्येक पूर्णांक से उपसमुच्चय बनाने की विधि**: पूर्णांक `mask` का `i`-वाँ बिट `1` है या नहीं, यह `(mask & (1 << i)) != 0` से जाँचा जा सकता है। यदि `1` है तो `nums[i]` को उपसमुच्चय में जोड़ा जाता है। `i` को `0` से `n-1` तक चलाने पर `mask` के अनुरूप उपसमुच्चय पूरा हो जाता है
5. **1 << n से 2^n की गणना करना**: Java में बिट शिफ्ट संकारक `<<` का उपयोग करके `1 << n` से `2^n` की गणना की जा सकती है। लूप की ऊपरी सीमा के रूप में `mask < (1 << n)` को शर्त रखने पर `0` से `2^n - 1` तक बिना छूट के गणना की जा सकती है
6. **अंतिम रूप से क्या लौटाना है**: प्रत्येक `mask` के अनुरूप उपसमुच्चय को सूची में जोड़ते जाना है, और सभी `mask` का प्रसंस्करण पूरा होने के बाद उपसमुच्चयों की सूची `result` लौटानी है

## पूर्वापेक्षित ज्ञान

### बिटमास्क क्या है

पूर्णांक के प्रत्येक बिट (0 या 1) को "फ़्लैग" के रूप में उपयोग करने की तकनीक है। `n` तत्वों के लिए "शामिल करना/शामिल न करना" के संयोजन को एक पूर्णांक से व्यक्त किया जा सकता है।

```java
int mask = 5;            // बाइनरी में 101
// बिट 0: 1 (शामिल), बिट 1: 0 (शामिल नहीं), बिट 2: 1 (शामिल)
```

### बिट संकारक

`&` (AND) और `<<` (बायाँ शिफ्ट) को मिलाकर, किसी विशिष्ट बिट का सेट होना जाँचा जाता है।

```java
1 << 0;                  // 1 (बाइनरी: 001) — केवल बिट 0 पर 1 वाला मास्क बनाता है
1 << 1;                  // 2 (बाइनरी: 010) — केवल बिट 1 पर 1 वाला मास्क बनाता है
1 << 2;                  // 4 (बाइनरी: 100) — केवल बिट 2 पर 1 वाला मास्क बनाता है

int mask = 5;            // बाइनरी: 101
(mask & (1 << 0)) != 0;  // true  — बिट 0 का मान 1 है
(mask & (1 << 1)) != 0;  // false — बिट 1 का मान 0 है
(mask & (1 << 2)) != 0;  // true  — बिट 2 का मान 1 है
```

### 1 << n से 2^n की गणना करना

बिट शिफ्ट `1 << n`, `1` को बाईं ओर `n` बिट खिसकाने की क्रिया है, और परिणाम `2^n` होता है। इसका उपयोग उपसमुच्चयों की कुल संख्या ज्ञात करने में किया जाता है।

```java
1 << 3;                  // 8 (= 2^3) — 3 तत्व होने पर उपसमुच्चयों की संख्या 8 है
```

## जटिलता

| | मान |
|---|---|
| Time | O(n × 2^n) — 2^n मास्कों में से प्रत्येक के लिए n बिटों की जाँच की जाती है |
| Space | O(n × 2^n) — 2^n उपसमुच्चय संग्रहीत किए जाते हैं, और प्रत्येक उपसमुच्चय में औसतन n/2 तत्व होते हैं |

## कोड

```java
// इनपुट: विभिन्न पूर्णांकों की सरणी nums
// आउटपुट: सभी उपसमुच्चयों को संग्रहीत करने वाली List<List<Integer>> लौटाता है
List<List<Integer>> subsets(int[] nums) {
    // nums के तत्वों की संख्या। बिटमास्क के बिट संख्या और सरणी की जाँच सीमा दोनों में उपयोग होती है
    int n = nums.length;
    // सभी उपसमुच्चयों को संग्रहीत करने वाली सूची। प्रत्येक mask से उत्पन्न उपसमुच्चय यहाँ जोड़ा जाता है
    List<List<Integer>> result = new ArrayList<>();

    // mask को 0 से 2^n-1 तक गिनता है, प्रत्येक मान एक उपसमुच्चय के अनुरूप होता है
    // 1 << n से 2^n की गणना करके लूप शर्त बनाने पर 2^n पैटर्नों की पूर्ण गणना होती है
    for (int mask = 0; mask < (1 << n); mask++) {
        // वर्तमान mask के अनुरूप तत्वों को जोड़ने के लिए एक रिक्त उपसमुच्चय बनाता है
        List<Integer> subset = new ArrayList<>();

        // i, nums का अनुक्रमणिका है और साथ ही mask के किस बिट को देखना है यह निर्धारित करता है
        for (int i = 0; i < n; i++) {
            // 1 << i से केवल i-वें बिट पर 1 वाला मास्क बनाता है, mask के साथ AND करके i-वें बिट का मान निकालता है
            // बिट 1 होने पर "इस तत्व को शामिल करना है", 0 होने पर "शामिल नहीं करना है" इसलिए अगले i पर जाता है
            if ((mask & (1 << i)) != 0) {
                subset.add(nums[i]);
            }
        }

        // आंतरिक लूप समाप्त होने पर, पूर्ण उपसमुच्चय को परिणाम सूची में जोड़ता है
        result.add(subset);
    }
    // सभी mask का प्रसंस्करण पूरा होने पर, 2^n उपसमुच्चय संग्रहीत result लौटाता है
    return result;
}
```
