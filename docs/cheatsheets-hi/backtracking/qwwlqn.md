# Finding Combinations That Sum to a Target Without Reuse — डुप्लिकेट तत्वों वाले ऐरे से टारगेट का योग बनाने वाले सभी यूनिक कॉम्बिनेशन खोजना

## समस्या का सार

पूर्णांकों का एक ऐरे `candidates` (जिसमें डुप्लिकेट तत्व हो सकते हैं) और एक पूर्णांक `target` दिया गया है। ऐरे में से उन संख्याओं के सभी कॉम्बिनेशन खोजने हैं जिनका योग `target` के बराबर हो। प्रत्येक संख्या को कॉम्बिनेशन में **केवल एक बार** उपयोग किया जा सकता है, और परिणाम में **डुप्लिकेट कॉम्बिनेशन शामिल नहीं होने चाहिए**।

## मूल विचार

ऐरे को सॉर्ट करने से समान मान वाले तत्व एक-दूसरे के बगल में आ जाते हैं, और रिकर्शन के समान स्तर पर डुप्लिकेट तत्वों को स्किप करने की शर्त `i > start && cands[i] == cands[i-1]` लागू होती है। इससे डुप्लिकेट कॉम्बिनेशन का उत्पन्न होना मूल रूप से रुक जाता है, और साथ ही सभी यूनिक कॉम्बिनेशन बिना किसी चूक के खोजे जा सकते हैं।

## विचार प्रक्रिया

1. **सभी कॉम्बिनेशन की गणना करना आवश्यक है**: समस्या "शर्त पूरी करने वाले सभी कॉम्बिनेशन" माँगती है, इसलिए किसी एक इष्टतम हल के बजाय पूरे सॉल्यूशन स्पेस को खोजना आवश्यक है। इस प्रकार की "पूर्ण गणना" समस्याओं के लिए बैकट्रैकिंग उपयुक्त है
2. **प्रत्येक तत्व को "शामिल करना/न करना" के आधार पर ब्रांच करना**: ऐरे के प्रत्येक तत्व के लिए "वर्तमान कॉम्बिनेशन में शामिल करना है या नहीं" का रिकर्सिव रूप से चयन करना है। तत्व को केवल एक बार उपयोग करने के लिए, रिकर्सिव कॉल में स्टार्ट इंडेक्स को `i + 1` पर आगे बढ़ाना है
3. **डुप्लिकेट कॉम्बिनेशन को हटाना आवश्यक है**: यदि ऐरे में डुप्लिकेट तत्व हैं, तो अलग-अलग इंडेक्स पर समान मान चुनने से एक ही कॉम्बिनेशन बन जाता है। उदाहरण के लिए, `[1,1,2]` में target=3 के लिए, पहले 1 और 2 का कॉम्बिनेशन तथा दूसरे 1 और 2 का कॉम्बिनेशन दोनों एक ही `[1,2]` बनते हैं
4. **सॉर्ट करके डुप्लिकेट को स्किप करना**: ऐरे को सॉर्ट करने से समान मान एक-दूसरे के बगल में आ जाते हैं। रिकर्शन के समान स्तर (एक ही for लूप के अंदर) पर, ठीक पहले वाले तत्व के समान मान वाले तत्व को स्किप करने से डुप्लिकेट कॉम्बिनेशन का उत्पन्न होना रुक जाता है। स्किप की शर्त `i > start && cands[i] == cands[i-1]` है। `i > start` शर्त के कारण, पहले तत्व का उपयोग अनुमत रहता है जबकि दूसरे और उसके बाद के समान मान वाले तत्व स्किप हो जाते हैं
5. **प्रूनिंग से खोज को कुशल बनाना**: ऐरे सॉर्ट होने के कारण, जब वर्तमान तत्व शेष योग `remain` से अधिक हो जाता है, तो उसके बाद के सभी तत्व भी अधिक होंगे। `if (cands[i] > remain) break` से लूप को समाप्त करके अनावश्यक खोज को छोड़ा जा सकता है
6. **बेस केस की जाँच**: जब `remain` 0 हो जाता है, तो इसका अर्थ है कि वर्तमान `path` में शामिल तत्वों का योग ठीक `target` के बराबर है, इसलिए `path` की कॉपी को परिणाम लिस्ट में जोड़ा जाता है

## पूर्व-आवश्यक ज्ञान

### बैकट्रैकिंग क्या है

बैकट्रैकिंग एक ऐसी खोज तकनीक है जो हल के उम्मीदवारों को चरणबद्ध रूप से बनाती है, और जब यह स्पष्ट हो जाता है कि शर्त पूरी नहीं होगी, तो पिछली स्थिति में लौटकर (बैकट्रैक) अन्य उम्मीदवारों को आज़माती है। इसे "चयन → रिकर्शन → चयन रद्द करना" पैटर्न से लागू किया जाता है।

```java
path.add(element);          // चयन: तत्व को कॉम्बिनेशन में जोड़ना
backtrack(next_state);      // रिकर्शन: अगले तत्व के लिए खोज जारी रखना
path.remove(path.size()-1); // रद्द करना: तत्व को कॉम्बिनेशन से हटाकर पिछली स्थिति में लौटना
```

### Arrays.sort क्या है

यह ऐरे को आरोही क्रम में सॉर्ट करने वाला Java का मानक मेथड है। सॉर्ट करने से समान मान वाले तत्व एक-दूसरे के बगल में आ जाते हैं, जिससे डुप्लिकेट का पता लगाना और स्किप करना आसान हो जाता है।

```java
int[] arr = {2, 1, 2, 3};
Arrays.sort(arr);           // arr {1, 2, 2, 3} में बदल जाता है
```

### ArrayList का कॉपी कंस्ट्रक्टर

`new ArrayList<>(path)` एक नई लिस्ट बनाता है जिसमें `path` की सामग्री की कॉपी होती है। बैकट्रैकिंग में `path` रिकर्शन के दौरान लगातार बदलता रहता है, इसलिए परिणाम में जोड़ते समय कॉपी लेना आवश्यक है।

```java
List<Integer> path = new ArrayList<>(Arrays.asList(1, 2));
List<Integer> copy = new ArrayList<>(path);  // [1, 2] की कॉपी बनाना
path.add(3);        // path [1, 2, 3] में बदल जाता है
// copy [1, 2] ही रहता है और नहीं बदलता
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(2^n) — प्रत्येक तत्व के लिए "शामिल करना/न करना" के 2 विकल्प होने के कारण, सबसे खराब स्थिति में 2^n कॉम्बिनेशन की खोज होती है |
| Space | O(n) — रिकर्शन की अधिकतम गहराई n है, और path भी अधिकतम n तत्वों को रखता है |

## कोड

```java
// इनपुट: पूर्णांक ऐरे candidates (जिसमें डुप्लिकेट तत्व हो सकते हैं) और पूर्णांक target
// आउटपुट: योग target के बराबर होने वाले सभी यूनिक कॉम्बिनेशन को संग्रहीत करने वाला List<List<Integer>> लौटाना
private void backtrack(int[] cands, int start, int remain,
        List<Integer> path, List<List<Integer>> result) {
    // यदि remain 0 है तो path का योग ठीक target के बराबर होने वाला कॉम्बिनेशन मिल गया है
    if (remain == 0) {
        // path आगे के रिकर्शन में बदलता रहता है, इसलिए कॉपी बनाकर परिणाम में जोड़ना है
        result.add(new ArrayList<>(path));
        return;
    }

    // start से शुरू करने से पहले से उपयोग किए गए तत्वों (start से पहले) को दोबारा चुनना रुक जाता है
    for (int i = start; i < cands.length; i++) {
        // समान रिकर्शन स्तर पर दूसरे या उसके बाद का तत्व और ठीक पहले वाले के समान मान हो तो स्किप करके डुप्लिकेट कॉम्बिनेशन रोकना
        // i > start का अर्थ है "समान रिकर्शन स्तर पर पहला तत्व नहीं है"
        if (i > start && cands[i] == cands[i - 1]) continue;

        // सॉर्ट होने के कारण यदि वर्तमान मान remain से अधिक है तो आगे के सभी तत्व भी अधिक होंगे (प्रूनिंग)
        if (cands[i] > remain) break;

        path.add(cands[i]);                  // चयन: तत्व को कॉम्बिनेशन में जोड़ना
        backtrack(cands, i + 1,              // रिकर्शन: i+1 करके समान तत्व को दो बार उपयोग करना रोकना
            remain - cands[i], path, result); // remain से वर्तमान तत्व घटाकर शेष योग को अपडेट करना
        path.remove(path.size() - 1);        // रद्द करना: तत्व हटाकर अन्य तत्व आज़माने के लिए स्थिति पुनर्स्थापित करना
    }
}

public List<List<Integer>> combinationSum2(
        int[] candidates, int target) {
    // सॉर्ट करके समान मान वाले डुप्लिकेट तत्वों को बगल में लाना और स्किप शर्त की जाँच संभव बनाना
    Arrays.sort(candidates);
    // परिणाम संग्रहीत करने के लिए लिस्ट और वर्तमान कॉम्बिनेशन रिकॉर्ड करने के लिए path को खाली बनाना
    List<List<Integer>> result = new ArrayList<>();
    // इंडेक्स 0 और शेष योग target से रिकर्सिव खोज शुरू करना
    backtrack(candidates, 0, target, new ArrayList<>(), result);
    // सभी रिकर्शन पूर्ण होने के बाद, संग्रहीत सभी यूनिक कॉम्बिनेशन लौटाना
    return result;
}
```
