# Placing N Queens on a Board Without Conflicts — बोर्ड पर N क्वीन को बिना टकराव के रखना

## समस्या का सार

एक पूर्णांक `n` दिया गया है। n×n के चेसबोर्ड पर n क्वीन को इस प्रकार रखना है कि कोई भी दो क्वीन एक ही पंक्ति, एक ही स्तंभ, या एक ही विकर्ण पर न हों। शर्तों को पूरा करने वाली सभी बोर्ड संरचनाओं को स्ट्रिंग की सूची के रूप में लौटाना है।

## मूल विचार

प्रत्येक पंक्ति में एक-एक करके क्वीन रखने से पंक्ति का टकराव स्वतः समाप्त हो जाता है। शेष स्तंभ, धनात्मक विकर्ण और ऋणात्मक विकर्ण के टकराव की जाँच को बिटमास्क के प्रत्येक बिट से प्रबंधित करने पर O(1) स्थिर समय में टकराव जाँच और स्थिति अद्यतन किया जा सकता है।

## विचार प्रक्रिया

1. **पंक्ति के टकराव को संरचनात्मक रूप से समाप्त करना**: n क्वीन को n पंक्तियों में रखना है, इसलिए प्रत्येक पंक्ति में ठीक एक क्वीन रखने पर पंक्ति का टकराव नहीं होता। अतः समस्या "प्रत्येक पंक्ति में किस स्तंभ पर क्वीन रखना है" यह निर्धारित करने की खोज में बदल जाती है
2. **स्तंभ और विकर्ण के टकराव का पता लगाना आवश्यक है**: स्तंभ के टकराव को "पहले से उपयोग किए गए स्तंभों के समूह" से प्रबंधित किया जा सकता है। विकर्ण के टकराव दो प्रकार के होते हैं: धनात्मक विकर्ण (दाएँ ऊपर की दिशा, row + col समान) और ऋणात्मक विकर्ण (बाएँ ऊपर की दिशा, row - col समान)। इन तीन समूहों को प्रबंधित करने से सभी टकरावों का पता लगाया जा सकता है
3. **बिटमास्क से समूह को व्यक्त करना**: स्तंभ, धनात्मक विकर्ण और ऋणात्मक विकर्ण की उपयोग स्थिति को पूर्णांक के बिट से व्यक्त किया जाता है। यदि cवाँ बिट 1 है तो इसका अर्थ है "वह स्तंभ (या विकर्ण) उपयोग में है"। बिट AND संक्रिया से टकराव जाँच और OR संक्रिया से पंजीकरण किया जा सकता है, जो HashSet से तेज़ कार्य करता है
4. **विकर्ण के बिटमास्क को प्रत्येक पंक्ति पर शिफ्ट करना**: धनात्मक विकर्ण में जब पंक्ति एक नीचे जाती है तो प्रभाव क्षेत्र एक स्तंभ बाएँ खिसकता है, इसलिए बायाँ शिफ्ट (`<< 1`) किया जाता है; ऋणात्मक विकर्ण एक स्तंभ दाएँ खिसकता है, इसलिए दायाँ शिफ्ट (`>> 1`) किया जाता है। ऐसा करने से विकर्ण टकराव जाँच केवल स्तंभ संख्या की बिट स्थिति से की जा सकती है
5. **बैकट्रैकिंग से सभी हल खोजना**: पंक्ति 0 से पंक्ति n-1 तक क्रमशः, प्रत्येक पंक्ति में टकराव न होने वाले स्तंभ को आज़माया जाता है। यदि टकराव न होने वाला स्तंभ मिलता है तो क्वीन रखकर अगली पंक्ति में रिकर्सन किया जाता है, और पंक्ति n पर पहुँचने पर एक हल दर्ज किया जाता है। रिकर्सन से लौटने पर स्वतः ही रखा गया क्वीन हट जाता है और दूसरे स्तंभ को आज़माया जा सकता है
6. **हलों की कुल संख्या लौटाना**: सभी पंक्तियों में क्वीन रख पाने (row == n पर पहुँचने) की कुल बार की गिनती लौटाई जाती है

## पूर्वापेक्षित ज्ञान

### बैकट्रैकिंग क्या है

एक विकल्प को आज़माकर, यदि रास्ता बंद हो जाए तो पिछले चयन पर लौटकर दूसरे विकल्प को आज़माने की खोज विधि है। रिकर्सिव कॉल से "आज़माना → आगे बढ़ना → पीछे लौटना" को स्वाभाविक रूप से कार्यान्वित किया जा सकता है। यह विधि सभी मान्य संयोजनों को सूचीबद्ध करने वाली समस्याओं के लिए उपयुक्त है।

```java
void backtrack(int step) {
    if (step == goal) {       // लक्ष्य पर पहुँचने पर हल दर्ज करना
        recordSolution();
        return;
    }
    for (int choice : choices) {
        if (isValid(choice)) {    // यदि चयन मान्य है तो आज़माना
            apply(choice);        // चयन को लागू करना
            backtrack(step + 1);  // अगले चरण में रिकर्सन करना
            undo(choice);         // चयन को रद्द करके दूसरे विकल्प को आज़माना
        }
    }
}
```

### बिटमास्क क्या है

पूर्णांक के प्रत्येक बिट को "समूह में तत्व है या नहीं" के फ्लैग के रूप में उपयोग करने की तकनीक है। समूह संक्रियाओं को बिट संक्रियाओं से तेज़ी से किया जा सकता है।

```java
int mask = 0;             // खाली समूह (सभी बिट 0 हैं)
int bit = 1 << c;         // केवल cवाँ बिट 1 वाला मान बनाना (तत्व c को दर्शाता है)
mask |= bit;              // तत्व c को समूह में जोड़ना (cवें बिट को 1 करना)
(mask & bit) != 0;        // तत्व c समूह में शामिल है या नहीं यह जाँचना → true/false
```

### बिट शिफ्ट द्वारा विकर्ण की ट्रैकिंग

चेसबोर्ड पर जब पंक्ति एक नीचे जाती है, तो धनात्मक विकर्ण (दाएँ ऊपर ↗ दिशा) का प्रभाव स्तंभ संख्या में एक छोटी ओर खिसकता है, और ऋणात्मक विकर्ण (बाएँ ऊपर ↖ दिशा) का प्रभाव स्तंभ संख्या में एक बड़ी ओर खिसकता है। बिटमास्क को शिफ्ट करके इस खिसकाव को व्यक्त किया जाता है।

```java
int posDiag = 0;          // धनात्मक विकर्ण की उपयोग स्थिति प्रबंधित करने वाला बिटमास्क
posDiag |= (1 << c);      // स्तंभ c पर रखी गई क्वीन के धनात्मक विकर्ण को पंजीकृत करना
posDiag << 1;              // अगली पंक्ति में प्रभाव एक स्तंभ बाएँ खिसकता है (बायाँ शिफ्ट)

int negDiag = 0;          // ऋणात्मक विकर्ण की उपयोग स्थिति प्रबंधित करने वाला बिटमास्क
negDiag |= (1 << c);      // स्तंभ c पर रखी गई क्वीन के ऋणात्मक विकर्ण को पंजीकृत करना
negDiag >> 1;              // अगली पंक्ति में प्रभाव एक स्तंभ दाएँ खिसकता है (दायाँ शिफ्ट)
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n!) — प्रत्येक पंक्ति में चुने जा सकने वाले स्तंभों की संख्या अधिकतम n, n-1, n-2, ... के क्रम में घटती है |
| Space | O(n) — रिकर्सन की गहराई n स्तर है, और प्रत्येक स्तर पर बिटमास्क केवल स्थिर संख्या में पूर्णांक हैं |

## कोड

```java
// इनपुट: पूर्णांक n (चेसबोर्ड का आकार, और रखी जाने वाली क्वीन की संख्या)
// आउटपुट: n क्वीन को बिना टकराव के रखने योग्य बोर्ड संरचनाओं की कुल संख्या int में लौटाना
int totalNQueens(int n) {
    // पंक्ति 0 से खोज आरंभ करना, और स्तंभ, धनात्मक विकर्ण, ऋणात्मक विकर्ण के बिटमास्क को सभी खाली (0) से आरंभ करना
    return backtrack(0, n, 0, 0, 0);
}

int backtrack(int row, int n,
    int cols, int posDiag,
    int negDiag) {
    // सभी पंक्तियों में क्वीन रख दी गई, अतः एक हल मिल गया
    if (row == n) return 1;

    // इस पंक्ति के बाद मिलने वाले हलों की संख्या संचित करने वाला चर
    int count = 0;

    // स्तंभ 0 से n-1 तक स्कैन करके, प्रत्येक स्तंभ पर क्वीन रखी जा सकती है या नहीं यह जाँचना
    for (int c = 0; c < n; c++) {
        // स्तंभ c के अनुरूप बिट बनाना। इस bit का उपयोग तीन बिटमास्क के साथ टकराव जाँच के लिए किया जाता है
        int bit = 1 << c;

        // स्तंभ, धनात्मक विकर्ण, या ऋणात्मक विकर्ण में से किसी से टकराव होने पर छोड़कर अगले स्तंभ को आज़माना
        if ((cols & bit) != 0 ||
            (posDiag & bit) != 0 ||
            (negDiag & bit) != 0)
            continue;

        // स्तंभ c पर क्वीन रखकर, तीन बिटमास्क को अद्यतन करके अगली पंक्ति में रिकर्सन करना
        // cols | bit: स्तंभ c को उपयोग में पंजीकृत करना
        // (posDiag | bit) << 1: धनात्मक विकर्ण को पंजीकृत करके, अगली पंक्ति की ओर खिसकाव को बाएँ शिफ्ट से दर्शाना
        // (negDiag | bit) >> 1: ऋणात्मक विकर्ण को पंजीकृत करके, अगली पंक्ति की ओर खिसकाव को दाएँ शिफ्ट से दर्शाना
        // बिटमास्क मान द्वारा पास होते हैं, इसलिए रिकर्सन से लौटने पर स्वतः पंजीकरण पूर्व की स्थिति में आ जाते हैं, और स्पष्ट रद्दीकरण प्रक्रिया की आवश्यकता नहीं होती
        count += backtrack(row + 1, n,
            cols | bit,
            (posDiag | bit) << 1,
            (negDiag | bit) >> 1);
    }
    // सभी स्तंभों को आज़माने के बाद हलों की कुल संख्या लौटाना
    return count;
}
```
