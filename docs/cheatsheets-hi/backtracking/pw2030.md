# Searching for a Word in a Grid — ग्रिड में अक्षरों को जोड़कर शब्द बनाया जा सकता है या नहीं इसका निर्णय करना

## समस्या का सार

2D कैरेक्टर ग्रिड `board` और स्ट्रिंग `word` दिया गया है। ग्रिड में आसन्न सेल (ऊपर, नीचे, बाएँ, दाएँ) को क्रम से जोड़कर `word` बनाया जा सकता है या नहीं इसका निर्णय करना है, और `boolean` लौटाना है। प्रत्येक सेल को एक पथ में केवल एक बार उपयोग किया जा सकता है।

## मुख्य विचार

ग्रिड के प्रत्येक सेल को प्रारंभ बिंदु के रूप में DFS करना है, और शब्द के अक्षरों को एक-एक करके मिलाना है। विज़िट किए गए सेल को अलग ऐरे में प्रबंधित करने के बजाय, बोर्ड के सेल को सीधे विशेष कैरेक्टर से ओवरराइट करना है, और खोज के बाद मूल मान वापस रखना है, जिससे स्पेस कॉम्प्लेक्सिटी केवल रिकर्सन स्टैक की गहराई तक सीमित रहती है।

## विचार प्रक्रिया

1. **प्रत्येक सेल प्रारंभ बिंदु बन सकता है**: शब्द का प्रारंभ स्थान ग्रिड का कोई भी सेल हो सकता है, इसलिए सभी सेल को प्रारंभ बिंदु के रूप में आज़माना आवश्यक है
2. **एक-एक अक्षर क्रम में मिलाना है**: वर्तमान सेल का अक्षर `word` की वर्तमान स्थिति के अक्षर से मेल खाता है या नहीं यह जाँचना है, और मेल खाने पर ऊपर-नीचे-बाएँ-दाएँ के आसन्न सेल में रिकर्सिव रूप से खोज आगे बढ़ाना है। यह संरचना DFS (डेप्थ फर्स्ट सर्च) ही है
3. **एक ही सेल के पुनः उपयोग को रोकना है**: एक पथ में एक ही सेल को दो बार उपयोग नहीं किया जा सकता, इसलिए विज़िट किए गए सेल का प्रबंधन आवश्यक है। अलग से `boolean[][]` विज़िट ऐरे रखने की विधि भी है, लेकिन वह स्पेस खर्च करती है
4. **बोर्ड को सीधे बदलकर विज़िट को दर्शाना है**: खोज में प्रवेश करते समय, वर्तमान सेल के अक्षर को `'#'` जैसे विशेष कैरेक्टर से ओवरराइट करने पर, रिकर्सन में उसी सेल से मिलान नहीं होगा। इससे विज़िट ऐरे अनावश्यक हो जाता है, और स्पेस कॉम्प्लेक्सिटी केवल रिकर्सन स्टैक की गहराई O(L) तक रहती है
5. **खोज के बाद मूल अक्षर को पुनर्स्थापित करना है**: DFS से वापस लौटते समय, ओवरराइट किए गए `'#'` को मूल अक्षर में वापस रखना है (बैकट्रैक)। इससे अन्य प्रारंभ बिंदुओं से की जाने वाली खोज में उसी सेल को सही ढंग से उपयोग किया जा सकता है
6. **खोज की समाप्ति शर्तों को व्यवस्थित करना है**: इंडेक्स `idx` जब `word.length()` तक पहुँच जाए तो सभी अक्षर मिलान सफल है और `true` लौटाना है। सीमा से बाहर या अक्षर बेमेल होने पर `false` लौटाना है। 4 दिशाओं में से किसी एक में `true` मिलने पर, उसी समय `true` लौटाना है

## पूर्वापेक्षित ज्ञान

### DFS (डेप्थ फर्स्ट सर्च) क्या है

ग्राफ या ग्रिड की खोज विधि है। एक दिशा में जहाँ तक जा सकते हैं वहाँ तक जाना है, और अंतिम सीमा पर पहुँचने पर एक कदम पीछे लौटकर दूसरी दिशा आज़माना है। रिकर्सिव कॉल से यह स्वाभाविक रूप से लागू होता है।

```java
void dfs(int node) {
    // node को प्रोसेस करना है
    for (int neighbor : getNeighbors(node)) {
        dfs(neighbor);  // आसन्न नोड में रिकर्सिव रूप से आगे बढ़ना है
    }
}
```

### बैकट्रैकिंग क्या है

खोज के दौरान किए गए परिवर्तनों को, खोज से लौटते समय मूल स्थिति में वापस रखने की विधि है। "आज़माना → आगे बढ़ना → वापस रखना" के चक्र द्वारा, सभी उम्मीदवारों की बिना चूक खोज की जा सकती है।

```java
board[r][c] = '#';   // बदलना है (विज़िट किया हुआ चिह्नित करना है)
dfs(...);            // रिकर्सिव रूप से खोज आगे बढ़ाना है
board[r][c] = temp;  // वापस रखना है (अनविज़िट स्थिति में लौटाना है)
```

### charAt क्या है

`String` की निर्दिष्ट स्थिति का कैरेक्टर `char` प्रकार में लौटाने वाला मेथड है। इंडेक्स 0 से शुरू होता है।

```java
String word = "ABCCED";
word.charAt(0);   // 'A' लौटाता है
word.charAt(3);   // 'C' लौटाता है
word.length();    // 6 लौटाता है (अक्षरों की संख्या लौटाता है)
```

### 2D ग्रिड में 4 दिशाओं की खोज

2D ग्रिड में ऊपर-नीचे-बाएँ-दाएँ के आसन्न सेल की खोज करने के लिए, पंक्ति और स्तंभ में क्रमशः ±1 करने वाले 4 पैटर्न आज़माने हैं।

```java
// ऊपर・नीचे・बाएँ・दाएँ के क्रम में खोज करना है
dfs(board, word, r-1, c, idx+1);  // ऊपर (पंक्ति -1)
dfs(board, word, r+1, c, idx+1);  // नीचे (पंक्ति +1)
dfs(board, word, r, c-1, idx+1);  // बाएँ (स्तंभ -1)
dfs(board, word, r, c+1, idx+1);  // दाएँ (स्तंभ +1)
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(m × n × 4^L) — सभी सेल को प्रारंभ बिंदु के रूप में, प्रत्येक प्रारंभ बिंदु से अधिकतम 4 दिशाओं में L अक्षरों तक खोज करना है (m×n ग्रिड का आकार है, L शब्द की लंबाई है) |
| Space | O(L) — रिकर्सन स्टैक की अधिकतम गहराई L है। बोर्ड को सीधे बदलने के कारण विज़िट ऐरे अनावश्यक है |

## कोड

```java
// इनपुट: 2D कैरेक्टर ऐरे board और स्ट्रिंग word
// आउटपुट: word को ग्रिड के आसन्न सेल से बनाया जा सकता है तो true, नहीं तो false लौटाना है

// वर्तमान स्थिति (r,c) से word[idx] के बाद के अक्षरों का मिलान करने वाला DFS
boolean dfs(char[][] board, String word, int r, int c, int idx) {
    // idx जब word.length() के बराबर हो, तो सभी अक्षरों का मिलान पूर्ण है इसलिए true लौटाना है
    if (idx == word.length()) return true;

    // r या c ग्रिड की सीमा से बाहर है, या board[r][c] word.charAt(idx) से मेल नहीं खाता तो false लौटाना है
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length
        || board[r][c] != word.charAt(idx))
        return false;

    // वर्तमान सेल के अक्षर को वेरिएबल temp में सहेजना है, और '#' से ओवरराइट करके पुनः विज़िट रोकना है
    // '#' अंग्रेज़ी अक्षरों से मेल नहीं खाता, इसलिए रिकर्सन में इस सेल का पुनः मिलान रुक जाता है (विज़िट ऐरे के विकल्प के रूप में)
    char temp = board[r][c];
    board[r][c] = '#';

    // ऊपर-नीचे-बाएँ-दाएँ 4 दिशाओं में रिकर्सिव खोज करना है (कोई भी true हो तो सफल)
    // || के शॉर्ट-सर्किट इवैल्यूएशन द्वारा, true मिलने पर शेष दिशाओं की खोज छोड़ दी जाती है
    boolean found =
        dfs(board, word, r - 1, c, idx + 1)
     || dfs(board, word, r + 1, c, idx + 1)
     || dfs(board, word, r, c - 1, idx + 1)
     || dfs(board, word, r, c + 1, idx + 1);

    // खोज परिणाम चाहे जो भी हो, मूल अक्षर को पुनर्स्थापित करना है (बैकट्रैक)
    // इससे अन्य प्रारंभ बिंदु या अन्य पथ से की जाने वाली खोज में उसी सेल को सही ढंग से उपयोग करने योग्य स्थिति में वापस रखना है
    board[r][c] = temp;
    return found;
}

boolean exist(char[][] board, String word) {
    int m = board.length;
    int n = board[0].length;

    // ग्रिड के सभी सेल (i,j) को डबल for लूप से स्कैन करना है, और प्रत्येक सेल को प्रारंभ बिंदु के रूप में DFS कॉल करना है
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // dfs जब true लौटाए उसी समय true लौटाना है
            if (dfs(board, word, i, j, 0))
                return true;

    // सभी सेल आज़माने के बाद भी नहीं मिला तो false लौटाना है
    return false;
}
```
