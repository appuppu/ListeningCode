# Finding Combinations That Sum to a Target — लक्ष्य के बराबर योग बनाने वाले संख्याओं के सभी संयोजन खोजना

## समस्या का सार

धनात्मक पूर्णांकों की एक सरणी `candidates` (सभी तत्व अलग-अलग हैं) और एक धनात्मक पूर्णांक `target` दिया गया है। `candidates` में से उन सभी संयोजनों को खोजकर लौटाना है जिनका योग `target` के बराबर हो। एक ही संख्या को **कितनी भी बार दोबारा उपयोग किया जा सकता है**। केवल क्रम में भिन्न संयोजनों को डुप्लिकेट माना जाता है।

## मूल विचार

यदि उम्मीदवारों को पहले से सॉर्ट कर लिया जाए, तो रिकर्शन के प्रत्येक चरण में यह निर्णय लिया जा सकता है कि "यदि वर्तमान उम्मीदवार शेष लक्ष्य से अधिक है, तो उसके बाद के सभी उम्मीदवार भी अधिक होंगे", और अनावश्यक खोज को पूरी तरह से काटा जा सकता है। इस प्रूनिंग से सभी संयोजनों को कुशलतापूर्वक सूचीबद्ध किया जा सकता है।

## विचार प्रक्रिया

1. **सभी संयोजनों की सूची बनाने के लिए बैकट्रैकिंग उपयुक्त है**: "सभी ऐसे पैटर्न खोजो जो शर्त पूरी करते हैं" जैसी समस्या को, उम्मीदवारों को एक-एक करके चुनकर आज़माने और असफल होने पर वापस लौटने वाली रिकर्सिव खोज (बैकट्रैकिंग) से हल किया जा सकता है
2. **डुप्लिकेट से बचने के लिए इंडेक्स की प्रारंभ स्थिति को नियंत्रित करना होगा**: एक ही संख्या को कितनी भी बार उपयोग किया जा सकता है, लेकिन `[2,3]` और `[3,2]` को अलग-अलग संयोजन के रूप में नहीं गिनना चाहिए। रिकर्शन के प्रत्येक चरण में "अपनी स्थिति और उसके बाद के उम्मीदवारों में से ही चुनना" सुनिश्चित करने पर, हमेशा आरोही क्रम के संयोजन ही बनते हैं और डुप्लिकेट से बचा जा सकता है
3. **शेष लक्ष्य (remain) से प्रगति को ट्रैक करना**: `target` में से चुनी गई संख्याओं को घटाते जाना है, और `remain` के 0 होने का अर्थ है कि योग `target` के बराबर हो गया है। `remain` के ऋणात्मक होने का अर्थ है कि योग सीमा से अधिक हो गया है
4. **सॉर्ट करने से प्रूनिंग संभव होती है**: उम्मीदवारों को आरोही क्रम में सॉर्ट करने पर, जब कोई उम्मीदवार `cands[i]` `remain` से अधिक हो जाता है, तो `cands[i+1]` के बाद के सभी उम्मीदवार और भी बड़े होते हैं इसलिए उन्हें आज़माने की आवश्यकता नहीं है। for लूप को उसी स्थान पर समाप्त किया जा सकता है
5. **वर्तमान संयोजन को एक लिस्ट में प्रबंधित करना और चयन व रद्दीकरण दोहराना**: तत्व को अंत में जोड़कर रिकर्स करना है, और लौटने पर अंतिम तत्व को हटाना है। यह "जोड़ना→रिकर्स→हटाना" पैटर्न बैकट्रैकिंग का मूल ऑपरेशन है
6. **remain के 0 होने पर वर्तमान संयोजन की प्रतिलिपि को परिणाम में जोड़ना**: संदर्भ के बजाय प्रतिलिपि सहेजनी होगी, अन्यथा बाद के ऑपरेशनों से सामग्री बदल जाएगी

## पूर्वापेक्षित ज्ञान

### बैकट्रैकिंग क्या है

यह एक खोज तकनीक है जो समाधान के उम्मीदवारों को चरणबद्ध रूप से बनाती है, और जब पता चलता है कि शर्त पूरी नहीं होगी, तो तुरंत पिछली स्थिति में लौटकर अन्य उम्मीदवार आज़माती है। इसे रिकर्सिव फ़ंक्शन से लागू किया जाता है, और "चयन→रिकर्शन→चयन रद्द" को दोहराकर सभी पैटर्न सूचीबद्ध किए जाते हैं।

### Arrays.sort क्या है

यह एक मेथड है जो सरणी को आरोही क्रम में सॉर्ट करता है। सॉर्ट की गई सरणी में "यदि वर्तमान मान शर्त से अधिक है, तो उसके बाद के सभी मान भी अधिक होंगे" इस गुण का उपयोग करके प्रूनिंग की जा सकती है।

```java
int[] cands = {3, 1, 2};
Arrays.sort(cands);       // cands {1, 2, 3} बन जाता है
```

### ArrayList के ऑपरेशन

यह एक परिवर्तनशील लंबाई वाली लिस्ट है। इसमें तत्वों को जोड़ना, हटाना और प्रतिलिपि बनाना किया जाता है। बैकट्रैकिंग में वर्तमान संयोजन को प्रबंधित करने के लिए इसका उपयोग किया जाता है।

```java
List<Integer> curr = new ArrayList<>();
curr.add(2);                          // अंत में 2 जोड़ना → [2]
curr.add(3);                          // अंत में 3 जोड़ना → [2, 3]
curr.remove(curr.size() - 1);         // अंतिम तत्व हटाना → [2] (बैकट्रैक)
new ArrayList<>(curr);                // curr की प्रतिलिपि बनाना (परिणाम सहेजने के लिए)
```

### List\<List\<Integer\>\> क्या है

यह "पूर्णांक लिस्ट की लिस्ट" को दर्शाने वाला टाइप है। कई संयोजनों को संग्रहीत करने के लिए इसका उपयोग किया जाता है। प्रत्येक संयोजन एक `List<Integer>` है, और उन सभी को एक साथ रखने वाला `List<List<Integer>>` है।

```java
List<List<Integer>> res = new ArrayList<>();  // एक खाली परिणाम लिस्ट बनाना
res.add(new ArrayList<>(curr));               // संयोजन की प्रतिलिपि को परिणाम में जोड़ना
```

## जटिलता

| | मान |
|---|---|
| Time | O(n^(target/min)) — n उम्मीदवारों की संख्या है, min सबसे छोटा उम्मीदवार मान है। सबसे खराब स्थिति में, प्रत्येक उम्मीदवार के लिए सबसे छोटे मान को target/min बार चुनने की शाखाएँ बनती हैं |
| Space | O(target/min) — रिकर्शन की अधिकतम गहराई target/min है। एक संयोजन में शामिल तत्वों की अधिकतम संख्या भी target/min है |

## कोड

```java
// इनपुट: धनात्मक पूर्णांकों की सरणी candidates (सभी तत्व अलग-अलग हैं) और एक धनात्मक पूर्णांक target
// आउटपुट: योग target के बराबर होने वाले सभी संयोजनों को List<List<Integer>> में लौटाना
public List<List<Integer>> combinationSum(int[] cands, int target) {
    // आरोही क्रम में सॉर्ट करने से "cands[i] > remain तो उसके बाद भी सभी अधिक होंगे" प्रूनिंग शर्त उपयोग हो सकती है
    Arrays.sort(cands);
    // परिणाम संग्रहीत करने के लिए लिस्ट
    List<List<Integer>> res = new ArrayList<>();
    // बैकट्रैकिंग शुरू करना (शेष=target, प्रारंभ स्थिति=0, वर्तमान संयोजन=खाली)
    backtrack(cands, target, 0, new ArrayList<>(), res);
    return res;
}

// remain: target में से अब तक चुनी गई संख्याओं को घटाने के बाद का शेष। 0 होने पर योग target के बराबर होता है
// start: खोज प्रारंभ स्थिति। अपनी स्थिति और उसके बाद से ही चुनकर डुप्लिकेट (क्रम भिन्नता) रोकना
// curr: वर्तमान में निर्माणाधीन संयोजन। चयन और रद्दीकरण दोहराकर सभी पैटर्न खोजना
void backtrack(int[] cands, int remain, int start,
               List<Integer> curr, List<List<Integer>> res) {
    // remain 0 है तो योग target के बराबर है → वर्तमान संयोजन को परिणाम में जोड़ना
    if (remain == 0) {
        // प्रतिलिपि बनाकर सहेजना। संदर्भ के रूप में सहेजने पर बाद के ऑपरेशनों से सामग्री बदल जाती है
        res.add(new ArrayList<>(curr));
        return;
    }
    // start से स्कैन करना, cands[i] > remain तो सॉर्ट होने के कारण उसके बाद भी सभी अधिक होंगे → लूप समाप्त (प्रूनिंग)
    for (int i = start; i < cands.length && cands[i] <= remain; i++) {
        // वर्तमान उम्मीदवार को संयोजन के अंत में जोड़ना
        curr.add(cands[i]);
        // तीसरे आर्गुमेंट में i (i+1 नहीं बल्कि i) पास करके, एक ही संख्या को दोबारा चुनने की अनुमति देना
        backtrack(cands, remain - cands[i], i, curr, res);
        // रिकर्शन से लौटने पर जोड़े गए तत्व को रद्द करना (बैकट्रैक)। अगले उम्मीदवार को आज़माने की तैयारी
        curr.remove(curr.size() - 1);
    }
}
```
