# Finding the Longest Increasing Path in a Matrix — मैट्रिक्स में मानों के सख्ती से बढ़ते हुए सबसे लंबे पथ की लंबाई ज्ञात करना

## समस्या का सार

m×n का एक पूर्णांक मैट्रिक्स `matrix` दिया गया है। आप ऊपर, नीचे, बाएँ और दाएँ — चारों दिशाओं में चल सकते हैं, लेकिन केवल तभी जब गंतव्य सेल का मान वर्तमान सेल के मान से **सख्ती से बड़ा** हो। इस शर्त को पूरा करने वाले **सबसे लंबे पथ की लंबाई** (सेलों की संख्या) लौटाएँ।

## मूल विचार

मैट्रिक्स को "छोटे मान से बड़े मान की ओर जाने वाले किनारों वाले DAG (निर्देशित अचक्रीय ग्राफ)" के रूप में देखें। इन-डिग्री 0 वाले सेलों (जिनके आसपास उनसे छोटा कोई मान नहीं है) से BFS को परत-दर-परत आगे बढ़ाएँ, और परतों की संख्या ही सबसे लंबे पथ की लंबाई होती है।

## विचार प्रक्रिया

1. **चलने की शर्त DAG के किनारे बनाती है**: क्योंकि केवल सख्ती से बढ़ते मान की दिशा में ही चला जा सकता है, इसलिए कोई चक्र नहीं होता। अर्थात मैट्रिक्स की आसन्नता संबंध को ग्राफ के रूप में देखें तो यह छोटे→बड़े की दिशा में किनारे रखने वाला DAG (निर्देशित अचक्रीय ग्राफ) बनता है
2. **DAG का सबसे लंबा पथ टोपोलॉजिकल सॉर्ट से ज्ञात होता है**: DAG की सबसे लंबे पथ की समस्या को टोपोलॉजिकल क्रम में संसाधित करके कुशलता से हल किया जा सकता है। BFS (कान का एल्गोरिदम) का उपयोग करने पर परत-दर-परत संसाधन होता है, और परतों की संख्या सबसे लंबे पथ की लंबाई के बराबर होती है
3. **इन-डिग्री का अर्थ परिभाषित करें**: प्रत्येक सेल की इन-डिग्री "आसपास की 4 दिशाओं में से उन सेलों की संख्या है जिनका मान स्वयं से छोटा है"। इन-डिग्री 0 वाले सेल पथ के आरंभ बिंदु के उम्मीदवार हैं, जिनके आसपास स्वयं से छोटे मान वाला कोई आसन्न सेल नहीं है
4. **BFS को परत-दर-परत संसाधित करें**: इन-डिग्री 0 वाले सभी सेलों को कतार में डालकर BFS शुरू करें। एक परत के सभी सेलों को एक साथ संसाधित करें, और प्रत्येक सेल से "स्वयं से बड़े आसन्न सेल" की इन-डिग्री 1 घटाएँ। इन-डिग्री 0 हो जाने वाले सेलों को अगली परत के रूप में कतार में जोड़ें
5. **परतों की संख्या उत्तर क्यों होती है**: BFS की प्रत्येक परत DAG पर समान दूरी पर स्थित सेलों का समूह है। अंतिम परत तक संसाधित होने तक की परतों की संख्या, आरंभ बिंदु से सबसे दूर के सेल तक की दूरी अर्थात सबसे लंबे पथ की लंबाई होती है

## पूर्वापेक्षित ज्ञान

### DAG (निर्देशित अचक्रीय ग्राफ) क्या है

यह शीर्षों और निर्देशित किनारों से बना ग्राफ है जिसमें कोई चक्र नहीं होता। केवल सख्ती से बढ़ते मान की दिशा में किनारे लगाने पर, समान मान पर लौटना असंभव होने के कारण चक्र नहीं बनता, और DAG का निर्माण होता है।

### इन-डिग्री (in-degree) क्या है

किसी शीर्ष में **आने वाले किनारों की संख्या**। इस समस्या में, सेल `(i, j)` की इन-डिग्री "ऊपर, नीचे, बाएँ, दाएँ के आसन्न सेलों में से `matrix[i][j]` से छोटे मान वाले सेलों की संख्या" है। इन-डिग्री 0 वाला सेल ऐसे पथ का आरंभ बिंदु होता है जहाँ कोई अन्य सेल पहुँच नहीं सकता।

```java
// सेल (i,j) की इन-डिग्री की गणना करने का उदाहरण
int indegree = 0;
for (int[] d : dirs) {
    int ni = i + d[0], nj = j + d[1];
    if (ni >= 0 && ni < m && nj >= 0 && nj < n
        && matrix[ni][nj] < matrix[i][j])  // यदि पड़ोसी का मान स्वयं से छोटा है तो किनारा अंदर आता है
        indegree++;
}
```

### टोपोलॉजिकल सॉर्ट (BFS / कान का एल्गोरिदम) क्या है

DAG के शीर्षों को इस प्रकार क्रमबद्ध करने की विधि कि सभी किनारे "पहले→बाद" के क्रम में हों। कान के एल्गोरिदम में, इन-डिग्री 0 वाले शीर्षों को कतार में डालते हैं, निकालते समय आसन्न शीर्षों की इन-डिग्री 1 घटाते हैं, और इन-डिग्री 0 हो जाने वाले शीर्षों को कतार में जोड़ते हैं। इसे दोहराने पर टोपोलॉजिकल क्रम प्राप्त होता है।

```java
Queue<int[]> q = new LinkedList<>();   // BFS के लिए कतार बनाएँ
q.offer(new int[]{0, 1});             // सेल निर्देशांक को कतार में जोड़ें
q.isEmpty();                           // कतार खाली है या नहीं boolean में लौटाता है → false
q.size();                              // कतार में तत्वों की संख्या लौटाता है → 1
int[] cell = q.poll();                 // कतार के पहले तत्व को निकालकर लौटाता है → {0, 1}
```

### 4 दिशाओं में चलने को ऐरे से व्यक्त करना

ऊपर, नीचे, बाएँ, दाएँ की 4 दिशाओं को `{पंक्ति का परिवर्तन, स्तंभ का परिवर्तन}` के 2D ऐरे के रूप में परिभाषित करते हैं और लूप से प्रत्येक दिशा को संसाधित करते हैं।

```java
int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};  // दाएँ, बाएँ, नीचे, ऊपर
for (int[] d : dirs) {
    int ni = i + d[0];  // गंतव्य पंक्ति
    int nj = j + d[1];  // गंतव्य स्तंभ
}
```

## जटिलता

| | मान |
|---|---|
| Time | O(m\*n) — प्रत्येक सेल की इन-डिग्री गणना में O(m\*n), BFS में प्रत्येक सेल को ठीक 1 बार संसाधित करने में O(m\*n) |
| Space | O(m\*n) — इन-डिग्री संग्रहित करने वाले 2D ऐरे और BFS कतार में प्रत्येक में अधिकतम m\*n सेल संग्रहित होते हैं |

## कोड

```java
// इनपुट: m×n का पूर्णांक मैट्रिक्स matrix
// आउटपुट: सख्ती से बढ़ते हुए सबसे लंबे पथ की लंबाई (सेलों की संख्या) int में लौटाएँ
int longestIncreasingPath(int[][] matrix) {
    // पंक्तियों की संख्या m और स्तंभों की संख्या n प्राप्त करें
    int m = matrix.length;
    int n = matrix[0].length;
    // ऊपर, नीचे, बाएँ, दाएँ की 4 दिशाओं की चाल परिभाषित करें (दाएँ, बाएँ, नीचे, ऊपर)
    int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};

    // प्रत्येक सेल की इन-डिग्री की गणना करें (आसन्न सेलों में स्वयं से छोटे मान वाले सेलों की संख्या)
    // इन-डिग्री = उस सेल में आने वाले किनारों की संख्या = आसन्न स्वयं से छोटे मान वाले सेलों की संख्या
    int[][] indeg = new int[m][n];
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            for (int[] d : dirs) {
                int ni = i + d[0];
                int nj = j + d[1];
                // यदि आसन्न सेल सीमा में है और स्वयं से छोटा है, तो वहाँ से किनारा अंदर आता है
                if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && matrix[ni][nj] < matrix[i][j])
                    indeg[i][j]++;
            }
        }
    }

    // इन-डिग्री 0 वाले सभी सेलों (पथ के आरंभ बिंदु) को कतार में जोड़ें
    // इन-डिग्री 0 = आसपास में स्वयं से छोटा कोई मान नहीं = DAG पर कोई भी सेल इस तक नहीं पहुँचता अर्थात आरंभ बिंदु
    Queue<int[]> q = new LinkedList<>();
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (indeg[i][j] == 0)
                q.offer(new int[]{i, j});

    // BFS को परत-दर-परत संसाधित करें और परतों की संख्या गिनें
    // प्रत्येक परत DAG पर आरंभ बिंदु से समान दूरी पर स्थित सेलों का समूह है
    int pathLen = 0;
    while (!q.isEmpty()) {
        // वर्तमान परत में सेलों की संख्या प्राप्त करें
        int size = q.size();
        // नई परत में जाने पर पथ की लंबाई 1 बढ़ाएँ (कुल परतों की संख्या = सबसे लंबे पथ की लंबाई)
        pathLen++;
        for (int k = 0; k < size; k++) {
            int[] cell = q.poll();
            // निकाले गए सेल की 4 दिशाओं के आसन्न सेलों की जाँच करें
            for (int[] d : dirs) {
                int ni = cell[0] + d[0];
                int nj = cell[1] + d[1];
                // यदि आसन्न सेल सीमा में है और स्वयं से बड़ा है, तो उस किनारे को संसाधित करें
                if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && matrix[ni][nj] > matrix[cell[0]][cell[1]]) {
                    // इन-डिग्री 1 घटाएँ (इस सेल से आने वाले इनपुट किनारे को संसाधित-चिह्नित करें)
                    indeg[ni][nj]--;
                    // इन-डिग्री 0 हो गई = सभी इनपुट किनारे संसाधित हो चुके → अगली परत के रूप में कतार में जोड़ें
                    if (indeg[ni][nj] == 0)
                        q.offer(new int[]{ni, nj});
                }
            }
        }
    }
    // BFS की परतों की संख्या ही सबसे लंबे बढ़ते पथ की लंबाई है
    // समस्या की बाधाओं के अनुसार मैट्रिक्स खाली नहीं होता इसलिए pathLen >= 1 की गारंटी है
    return pathLen;
}
```
