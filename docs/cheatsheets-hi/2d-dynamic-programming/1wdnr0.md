# Finding the Minimum Edits to Transform One String Into Another — दो स्ट्रिंग्स के बीच न्यूनतम संपादन दूरी ज्ञात करना

## समस्या का सार

दो स्ट्रिंग्स `word1` और `word2` दी गई हैं। `word1` को `word2` में बदलने के लिए आवश्यक **न्यूनतम ऑपरेशनों की संख्या** लौटानी है। उपलब्ध ऑपरेशन "इन्सर्ट", "डिलीट" और "रिप्लेस" तीन हैं, और प्रत्येक को 1 ऑपरेशन के रूप में गिना जाता है।

## मूल विचार

दो स्ट्रिंग्स की तुलना अंत से करते समय, यदि वर्तमान अक्षर मेल खाते हैं तो किसी ऑपरेशन की आवश्यकता नहीं होती और दोनों आगे बढ़ते हैं; यदि मेल नहीं खाते तो "इन्सर्ट, डिलीट, रिप्लेस" तीन ऑपरेशनों में से न्यूनतम लागत वाला चुना जाता है। इन दोहराई जाने वाली उप-समस्याओं को DP टेबल से हल किया जाता है, और चूँकि प्रत्येक सेल केवल वर्तमान पंक्ति और पिछली पंक्ति पर निर्भर करता है, इसलिए केवल एक पंक्ति के ऐरे से स्पेस को अनुकूलित किया जा सकता है।

## विचार प्रक्रिया

1. **प्रत्येक स्थिति पर विकल्प केवल 3 हैं**: `word1[i]` और `word2[j]` की तुलना करते समय, यदि अक्षर मेल खाते हैं तो बिना किसी ऑपरेशन के `(i+1, j+1)` पर आगे बढ़ते हैं। यदि मेल नहीं खाते तो "इन्सर्ट (j को आगे बढ़ाना)", "डिलीट (i को आगे बढ़ाना)", "रिप्लेस (दोनों को आगे बढ़ाना)" तीनों में से न्यूनतम लागत चुनी जाती है। यह पुनरावर्ती संरचना DP के प्रयोग का संकेत देती है
2. **DP टेबल की परिभाषा**: `dp[i][j]` को "`word1[i:]` को `word2[j:]` में बदलने के लिए न्यूनतम ऑपरेशनों की संख्या" के रूप में परिभाषित किया जाता है। अंतिम उत्तर `dp[0][0]` होता है
3. **बेस केस निर्धारित करना**: यदि `word1` का शेष भाग खाली है (`i == m`) तो `word2[j:]` के शेष अक्षरों की संख्या जितने इन्सर्ट आवश्यक हैं, इसलिए `dp[m][j] = n - j`। यदि `word2` का शेष भाग खाली है (`j == n`) तो `word1[i:]` के शेष अक्षरों की संख्या जितने डिलीट आवश्यक हैं, इसलिए `dp[i][n] = m - i`
4. **बॉटम-अप भरने की दिशा तय करना**: `dp[i][j]` `dp[i+1][j+1]`, `dp[i][j+1]`, `dp[i+1][j]` पर निर्भर करता है, इसलिए `i` को `m-1` से `0` तक और `j` को `n-1` से `0` तक उल्टे क्रम में भरा जाता है
5. **स्पेस को अनुकूलित करना**: प्रत्येक पंक्ति `i` की गणना के लिए केवल "पिछली पंक्ति (`i+1`)" और "वर्तमान पंक्ति (`i`)" दो पंक्तियों की आवश्यकता होती है। इसलिए 2D ऐरे रखने की आवश्यकता नहीं है, और 1D ऐरे `prev` (पिछली पंक्ति) तथा `curr` (वर्तमान पंक्ति) दो ऐरे पर्याप्त हैं। प्रत्येक पंक्ति की गणना पूरी होने पर `prev = curr` से अदला-बदली की जाती है
6. **अंतिम लौटाया जाने वाला मान**: सभी पंक्तियों को प्रोसेस करने के बाद, `prev[0]` `dp[0][0]` के समतुल्य मान होता है, और यह `word1` संपूर्ण को `word2` संपूर्ण में बदलने के लिए न्यूनतम ऑपरेशनों की संख्या होती है

## पूर्वापेक्षित ज्ञान

### Edit Distance (संपादन दूरी) क्या है

दो स्ट्रिंग्स के बीच "समानता" को दर्शाने वाला एक माप है, जो एक स्ट्रिंग को दूसरी में बदलने के लिए आवश्यक न्यूनतम ऑपरेशनों की संख्या होती है। इसे Levenshtein दूरी भी कहा जाता है। अनुमत ऑपरेशन निम्नलिखित 3 हैं, और प्रत्येक की लागत 1 है।

- **इन्सर्ट (Insert)**: स्ट्रिंग में 1 अक्षर जोड़ना
- **डिलीट (Delete)**: स्ट्रिंग से 1 अक्षर हटाना
- **रिप्लेस (Replace)**: स्ट्रिंग के 1 अक्षर को दूसरे अक्षर में बदलना

### बॉटम-अप DP (डायनामिक प्रोग्रामिंग) क्या है

पुनरावर्ती उप-समस्याओं को छोटी समस्या से क्रमशः टेबल में रिकॉर्ड करते हुए हल करने की विधि है। मेमोइज़ेशन रिकर्शन (टॉप-डाउन) के विपरीत, इसमें रिकर्सिव कॉल का ओवरहेड नहीं होता और स्पेस अनुकूलन भी आसानी से लागू किया जा सकता है।

```java
// 1D DP का उदाहरण: फ़िबोनाची अनुक्रम को 2 वेरिएबल से गणना करना
int a = 0, b = 1;
for (int i = 2; i <= n; i++) {
    int temp = a + b;  // वर्तमान मान केवल पिछले 2 मानों पर निर्भर करता है
    a = b;             // पुराने मान को हटाकर अपडेट करना
    b = temp;
}
```

### Math.min() क्या है

दो पूर्णांकों में से छोटा मान लौटाने वाला Java का मानक मेथड है। 3 या अधिक मानों की तुलना करने के लिए नेस्ट करके उपयोग किया जाता है।

```java
Math.min(3, 5);                    // → 3
Math.min(3, Math.min(5, 1));       // → 1 (3 मानों का न्यूनतम)
```

### String.charAt(int index) क्या है

स्ट्रिंग में निर्दिष्ट स्थिति पर स्थित अक्षर लौटाने वाला मेथड है। इंडेक्स 0 से शुरू होता है।

```java
String s = "abc";
s.charAt(0);  // → 'a'
s.charAt(2);  // → 'c'
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(m × n) — `word1` की प्रत्येक स्थिति के लिए `word2` की सभी स्थितियों को स्कैन किया जाता है |
| Space | O(n) — 2D टेबल के बजाय केवल 1 पंक्ति का ऐरे रखा जाता है |

## कोड

```java
// इनपुट: दो स्ट्रिंग्स word1 (लंबाई m) और word2 (लंबाई n)
// आउटपुट: word1 को word2 में बदलने के लिए न्यूनतम ऑपरेशनों की संख्या int में लौटाना
public int minDistance(String w1, String w2) {
    int m = w1.length();  // word1 की लंबाई प्राप्त करना
    int n = w2.length();  // word2 की लंबाई प्राप्त करना

    // prev ऐरे: DP टेबल की एक नीचे वाली पंक्ति (i+1) के समतुल्य है
    // prev[j] = n - j से आरंभ करना: जब word1 खाली हो, तब word2[j:] के शेष n-j अक्षरों को इन्सर्ट करने के ऑपरेशनों की संख्या
    int[] prev = new int[n + 1];
    for (int j = 0; j <= n; j++)
        prev[j] = n - j;

    // word1 के अंत से शुरुआत तक उल्टे क्रम में स्कैन करना (i word1 की वर्तमान स्थिति है)
    for (int i = m - 1; i >= 0; i--) {
        // curr ऐरे: DP टेबल की वर्तमान पंक्ति (i) के समतुल्य है
        int[] curr = new int[n + 1];
        // जब word2 खाली हो, तब word1[i:] के शेष m-i अक्षरों को डिलीट करने के ऑपरेशनों की संख्या
        curr[n] = m - i;

        // word2 के अंत से शुरुआत तक उल्टे क्रम में स्कैन करना (j word2 की वर्तमान स्थिति है)
        for (int j = n - 1; j >= 0; j--) {
            if (w1.charAt(i) == w2.charAt(j)) {
                // अक्षर मेल खाते हैं तो ऑपरेशन अनावश्यक है। prev[j+1] दोनों को 1 अक्षर आगे बढ़ाने वाली उप-समस्या dp[i+1][j+1] का उत्तर है
                curr[j] = prev[j + 1];
            } else {
                // मेल नहीं खाते तो 3 ऑपरेशनों में से न्यूनतम लागत चुनकर इस बार के ऑपरेशन की 1 (+1) जोड़ना
                curr[j] = 1 + Math.min(
                    curr[j + 1],           // इन्सर्ट: word2 में 1 अक्षर आगे बढ़ाना (dp[i][j+1])
                    Math.min(prev[j],      // डिलीट: word1 में 1 अक्षर आगे बढ़ाना (dp[i+1][j])
                        prev[j + 1]));     // रिप्लेस: दोनों में 1 अक्षर आगे बढ़ाना (dp[i+1][j+1])
            }
        }
        // वर्तमान पंक्ति को पिछली पंक्ति के रूप में सहेजना और अगले इटरेशन (i-1) के लिए तैयार करना
        prev = curr;
    }

    // prev[0] dp[0][0] के समतुल्य है, जो word1 संपूर्ण को word2 संपूर्ण में बदलने के लिए न्यूनतम ऑपरेशनों की संख्या है
    return prev[0];
}
```
