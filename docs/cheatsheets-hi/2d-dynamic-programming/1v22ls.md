# Counting Distinct Subsequences — स्ट्रिंग s में t से मेल खाने वाली उपअनुक्रमों की संख्या गिनना

## समस्या का सार

दो स्ट्रिंग `s` और `t` दी गई हैं। `s` से 0 या अधिक अक्षरों को हटाकर (शेष अक्षरों का सापेक्ष क्रम बदले बिना) `t` से मेल खाने वाली उपअनुक्रम बनाने के कितने तरीके हैं, उनकी संख्या गिनकर लौटानी है।

## मूल विचार

`s` के प्रत्येक अक्षर के लिए "`t` के मिलान में उपयोग करना या नहीं करना" के 2 विकल्प होते हैं। इस चयन के संचय को 1-आयामी सरणी में प्रबंधित किया जाता है, और पीछे से अपडेट करने पर "उपयोग करने की स्थिति" और "उपयोग न करने की स्थिति" का योग सही ढंग से किया जा सकता है।

## विचार प्रक्रिया

1. **उपअनुक्रम का मिलान चयनों का संचय है**: जब `s` का i-वाँ अक्षर `t` के j-वें अक्षर से मेल खाता है, तो "इस अक्षर को `t[j]` के मिलान में उपयोग करना" या "उपयोग न करके छोड़ देना" के दो विकल्प होते हैं। दोनों स्थितियों की संख्याओं को जोड़ने पर सभी पैटर्न प्राप्त होते हैं
2. **DP की स्थिति परिभाषित करना**: `dp[j]` को "`t` के पहले j अक्षरों से मेल खाने वाली `s` की उपअनुक्रमों की संख्या" के रूप में परिभाषित किया जाता है। अंततः `dp[n]` (n, `t` की लंबाई है) उत्तर होता है
3. **आधार स्थिति पर विचार करना**: `t` के पहले 0 अक्षरों (रिक्त स्ट्रिंग) से मेल खाने वाली उपअनुक्रम, किसी भी `s` के लिए "कुछ भी न चुनना" की 1 विधि होती है। इसलिए `dp[0] = 1` है
4. **संक्रमण सूत्र निकालना**: जब `s[i-1] == t[j-1]` होता है, तो `dp[j]` में दो योगदान होते हैं। "`s[i-1]` का उपयोग न करने की स्थिति" में मौजूदा `dp[j]` वैसा ही रहता है, और "`s[i-1]` का उपयोग करने की स्थिति" में `dp[j-1]` (एक पिछले अक्षर तक मिलान हो चुकी संख्या) जोड़ी जाती है। इसलिए `dp[j] += dp[j-1]` होता है। जब अक्षर मेल नहीं खाते, तो `dp[j]` नहीं बदलता (केवल छोड़ने का विकल्प)
5. **अपडेट क्रम को उलटा रखने का कारण**: `dp[j] += dp[j-1]` में अपडेट से पहले के `dp[j-1]` की आवश्यकता होती है। यदि j को छोटे से बड़े की ओर अपडेट किया जाए, तो `dp[j-1]` पहले ही बदल जाता है और पुराना मान खो जाता है। j को बड़े से छोटे की ओर उलटे क्रम में अपडेट करने पर, `dp[j-1]` अभी भी अपडेट से पहले का मान रखता है, जिससे गणना सही होती है
6. **अंत में लौटाया जाने वाला मान**: `s` के सभी अक्षरों को स्कैन करने के बाद `dp[n]` वह उत्तर है जो बताता है कि `s` में `t` से मेल खाने वाली उपअनुक्रमें कितनी हैं

## पूर्वापेक्षित ज्ञान

### उपअनुक्रम (Subsequence) क्या है

मूल स्ट्रिंग से 0 या अधिक अक्षरों को हटाकर, शेष अक्षरों का सापेक्ष क्रम बनाए रखते हुए बनाई गई स्ट्रिंग। उप-स्ट्रिंग (Substring) के विपरीत, इसमें अक्षरों का लगातार होना आवश्यक नहीं है।

```
s = "rabbbit", t = "rabbit"
उपअनुक्रम का उदाहरण: s के 1,2,3,5,6,7 वें अक्षर चुनना → "rabbit" ✓
उपअनुक्रम का उदाहरण: s के 1,2,4,5,6,7 वें अक्षर चुनना → "rabbit" ✓
उपअनुक्रम का उदाहरण: s के 1,3,4,5,6,7 वें अक्षर चुनना → "rabbit" ✓
→ कुल 3 तरीके
```

### 1-आयामी DP का उलटा क्रम अपडेट क्या है

2-आयामी DP तालिका `dp[i][j]` को 1-आयामी सरणी `dp[j]` में संपीड़ित करने की विधि। जब वर्तमान पंक्ति की गणना में केवल पिछली पंक्ति के मान की आवश्यकता होती है, तो 1-आयामी सरणी का पुन: उपयोग करके स्थान जटिलता को कम किया जा सकता है। हालांकि, जब `dp[j]` के अपडेट में `dp[j-1]` (पिछली पंक्ति का मान) की आवश्यकता होती है और j को आरोही क्रम में अपडेट किया जाता है, तो `dp[j-1]` वर्तमान पंक्ति के मान से अधिलेखित हो जाता है। j को अवरोही क्रम (बड़े→छोटे) में अपडेट करने से, अभी तक अधिलेखित न हुए पिछली पंक्ति के `dp[j-1]` को सही ढंग से संदर्भित किया जा सकता है।

```java
// 2-आयामी DP (मूल रूप)
dp[i][j] = dp[i-1][j] + dp[i-1][j-1];

// 1-आयामी DP में संपीड़ित (उलटा क्रम अपडेट)
for (int j = n; j >= 1; j--) {   // बड़े से छोटे की ओर अपडेट करना
    dp[j] += dp[j - 1];          // dp[j-1] अभी भी पिछली पंक्ति का मान रखता है
}
```

## जटिलता

| | मान |
|---|---|
| Time | O(m × n) — s के प्रत्येक अक्षर (m) के लिए t के प्रत्येक अक्षर (n) को स्कैन किया जाता है |
| Space | O(n) — केवल लंबाई n+1 की 1-आयामी सरणी का उपयोग किया जाता है |

## कोड

```java
// इनपुट: स्ट्रिंग s (लंबाई m) और स्ट्रिंग t (लंबाई n)
// आउटपुट: s की उपअनुक्रमों में t से मेल खाने वालों की संख्या int के रूप में लौटाना
public int numDistinct(String s, String t) {
    int m = s.length();
    int n = t.length();

    // dp[j] = t के पहले j अक्षरों से मेल खाने वाली s की उपअनुक्रमों की संख्या
    // इंडेक्स 0 से n तक n+1 स्थितियों को प्रबंधित करने के लिए, आकार n+1 रखा गया है
    int[] dp = new int[n + 1];

    // रिक्त स्ट्रिंग से मेल खाने वाली उपअनुक्रम हमेशा 1 तरीका होती है (कुछ भी न चुनना)
    // यह आधार स्थिति s की किसी भी स्थिति से शुरू करने पर लागू होती है
    dp[0] = 1;

    // s के प्रत्येक अक्षर पर क्रम से विचार करना (i दर्शाता है कि s के कितने अक्षरों पर विचार हो चुका है)
    for (int i = 1; i <= m; i++) {
        // j को उलटे क्रम (बड़े→छोटे) में स्कैन करना
        // कारण: dp[j] += dp[j-1] की गणना में अपडेट से पहले के dp[j-1] को संदर्भित करना आवश्यक है
        // आरोही क्रम में अपडेट करने पर dp[j-1] पहले बदल जाता है और पिछली पंक्ति का मान खो जाता है
        for (int j = n; j >= 1; j--) {
            // i, j 1 से शुरू होते हैं, लेकिन स्ट्रिंग का इंडेक्स 0 से शुरू होता है इसलिए i-1, j-1 से एक्सेस करना
            if (s.charAt(i - 1) == t.charAt(j - 1))
                // मेल खाने की स्थिति: dp[j] (उपयोग न करने की संख्या) में dp[j-1] (उपयोग करने की संख्या) जोड़ना
                // इस योग से "उपयोग करना" और "उपयोग न करना" दोनों विकल्पों का कुल dp[j] में संचित होता है
                dp[j] += dp[j - 1];
            // मेल न खाने की स्थिति: कुछ नहीं करना (s[i-1] को t[j-1] के मिलान में उपयोग नहीं किया जा सकता इसलिए केवल छोड़ना)
        }
    }

    // dp[n] में s की संपूर्णता में t की संपूर्णता से मेल खाने वाली उपअनुक्रमों की संख्या संग्रहित है
    return dp[n];
}
```
