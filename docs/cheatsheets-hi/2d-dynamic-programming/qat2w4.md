# Counting Combinations to Make a Target Amount — सिक्कों के संयोजन से लक्ष्य राशि बनाने के तरीकों की संख्या गिनना

## समस्या का सार

सिक्कों के मूल्य वाली एक सरणी `coins` और एक पूर्णांक `amount` दिया गया है। `coins` में से सिक्कों को कितनी भी बार दोहराकर उपयोग करते हुए, कुल योग ठीक `amount` बनाने वाले **संयोजनों की संख्या** लौटानी है। दो संयोजन भिन्न तभी होते हैं जब कम से कम एक मूल्य के सिक्कों की उपयोग संख्या भिन्न हो। केवल क्रम भिन्न होने पर उन्हें एक ही संयोजन माना जाता है।

## मूल विचार

सिक्कों को एक-एक प्रकार करके क्रम से संसाधित किया जाता है, और प्रत्येक सिक्के के लिए "उस सिक्के को 0 या अधिक बार उपयोग करने पर बनने वाले संयोजनों की संख्या" को DP सरणी में संचित किया जाता है। सिक्के के प्रकार को बाहरी लूप में रखने से, एक ही सिक्कों के समूह को भिन्न क्रम में गिनने वाली दोहराव (क्रमचय) स्वाभाविक रूप से समाप्त हो जाती है।

## विचार प्रक्रिया

1. **संयोजन और क्रमचय के अंतर को समझना**: यह समस्या "संयोजनों की संख्या" पूछती है, इसलिए [1,2] और [2,1] को एक ही के रूप में गिनना आवश्यक है। यदि राशि को बाहरी लूप और सिक्कों को भीतरी लूप में रखा जाए तो क्रमचय गिने जाते हैं, इसलिए सिक्के के प्रकार को बाहरी लूप में रखकर संसाधन क्रम को स्थिर करना आवश्यक है
2. **DP की अवस्था परिभाषित करना**: `dp[a]` को "ठीक राशि `a` बनाने वाले संयोजनों की संख्या" के रूप में परिभाषित किया जाता है। अंतिम उत्तर `dp[amount]` होता है
3. **आधार स्थिति निर्धारित करना**: राशि 0 बनाने का तरीका "किसी भी सिक्के का उपयोग न करना" यानी 1 तरीका है, इसलिए `dp[0] = 1` रखा जाता है। यह आधार स्थिति न हो तो किसी भी सिक्के का उपयोग करने पर संयोजन संख्या 0 में ही जोड़ी जाएगी, और उत्तर सदैव 0 ही रहेगा
4. **संक्रमण सूत्र निकालना**: किसी सिक्के `coin` को कम से कम 1 बार उपयोग करके राशि `a` बनाने के लिए, शेष राशि `a - coin` के संयोजनों की संख्या जोड़नी होती है। अर्थात `dp[a] += dp[a - coin]` संक्रमण सूत्र है। `dp[a - coin]` में पहले से उसी सिक्के को 0 या अधिक बार उपयोग करने वाले संयोजनों की संख्या शामिल होती है, इसलिए इस जोड़ से "coin को 1 बार, 2 बार, …" उपयोग करने के सभी मामले स्वचालित रूप से समाहित हो जाते हैं
5. **लूप का क्रम निर्धारित करना**: बाहरी लूप में सिक्कों के प्रकार को एक-एक करके संसाधित किया जाता है, और भीतरी लूप में राशि `a` को `coin` से `amount` तक आरोही क्रम में चलाया जाता है। इससे प्रत्येक सिक्का "पिछले सिक्के के प्रकारों तक के संयोजनों की संख्या" में अपना योगदान जोड़ता है, और क्रमचय की दोहरी गणना नहीं होती
6. **अंतिम लौटाया जाने वाला मान**: सभी सिक्कों का संसाधन पूरा होने के बाद `dp[amount]` लक्ष्य राशि बनाने वाले संयोजनों की कुल संख्या होती है

## पूर्वापेक्षित ज्ञान

### DP सरणी (गतिक प्रोग्रामिंग की एकविमीय सरणी) क्या है

उप-समस्याओं के उत्तरों को सरणी में संग्रहीत करके, उनका पुनः उपयोग करते हुए बड़ी समस्या का उत्तर कुशलतापूर्वक प्राप्त करने की विधि है। इस समस्या में `dp[a]` "राशि `a` बनाने वाले संयोजनों की संख्या" को दर्शाता है।

```java
int[] dp = new int[amount + 1];  // इंडेक्स 0 से amount तक की सरणी बनाना (प्रारंभिक मान सभी 0)
dp[0] = 1;                       // आधार स्थिति: राशि 0 बनाने का तरीका 1 है
dp[a] += dp[a - coin];           // संक्रमण: राशि a के संयोजनों की संख्या में, coin को 1 बार उपयोग करने पर शेष के संयोजनों की संख्या जोड़ना
```

### बाहरी लूप में सिक्कों को रखने का कारण

यदि राशि को बाहरी और सिक्कों को भीतरी लूप में रखा जाए तो राशि 5 बनाते समय [1,2,2] और [2,1,2] और [2,2,1] को अलग-अलग गिना जाता है (क्रमचय)। सिक्कों को बाहरी लूप में रखने पर, सिक्का 1 का संसाधन पूरा होने के बाद ही सिक्का 2 का संसाधन होता है, इसलिए "सिक्का 1→सिक्का 2" का क्रम स्थिर हो जाता है और केवल संयोजन गिने जाते हैं।

```java
// संयोजन गिनना (सही क्रम)
for (int coin : coins) {          // बाहरी: सिक्के के प्रकार के अनुसार संसाधन
    for (int a = coin; a <= amount; a++) {  // भीतरी: राशि का अवलोकन
        dp[a] += dp[a - coin];
    }
}

// क्रमचय गिना जाता है (गलत क्रम)
for (int a = 1; a <= amount; a++) {         // बाहरी: राशि के अनुसार संसाधन
    for (int coin : coins) {                // भीतरी: सभी सिक्कों को आज़माना
        if (a >= coin) dp[a] += dp[a - coin];
    }
}
```

## जटिलता

| | मान |
|---|---|
| Time | O(n × amount) — n प्रकार के सिक्कों में से प्रत्येक के लिए राशि 0 से amount तक का अवलोकन किया जाता है |
| Space | O(amount) — आकार amount+1 की केवल एक DP सरणी का उपयोग होता है |

## कोड

```java
// इनपुट: सिक्कों के मूल्य संग्रहीत पूर्णांक सरणी coins और लक्ष्य राशि का पूर्णांक amount
// आउटपुट: कुल योग ठीक amount बनाने वाले सिक्कों के संयोजनों की संख्या int में लौटाना
public int change(int amount, int[] coins) {
    // dp[a] = ठीक राशि a बनाने वाले संयोजनों की संख्या
    // आकार amount + 1 है (इंडेक्स 0 से amount तक प्रत्येक राशि के लिए)
    int[] dp = new int[amount + 1];

    // आधार स्थिति: राशि 0 बनाने का तरीका "कुछ भी न चुनना" यानी 1 तरीका है
    // यह आधार स्थिति न हो तो संक्रमण में जोड़ा जाने वाला मूल मान सदैव 0 रहेगा, और सभी परिणाम 0 होंगे
    dp[0] = 1;

    // सिक्के के प्रकार के अनुसार संसाधन (बाहरी लूप से क्रम स्थिर करके केवल संयोजन गिनना)
    // सिक्के के प्रकार को बाहरी लूप में रखने से, एक ही सिक्कों के समूह को भिन्न क्रम में गिनने वाली दोहराव (क्रमचय) रोकी जाती है
    for (int coin : coins) {
        // राशि coin से amount तक आरोही क्रम में अवलोकन करना
        // coin से आरंभ करने का कारण यह है कि a - coin का मान 0 या उससे अधिक होना आवश्यक है
        // आरोही क्रम में अवलोकन करने से एक ही सिक्के को कई बार उपयोग करने के मामले स्वाभाविक रूप से प्रतिबिंबित होते हैं
        for (int a = coin; a <= amount; a++) {
            // coin को 1 बार उपयोग करके, शेष a-coin के संयोजनों की संख्या जोड़ना
            // dp[a - coin] में उसी सिक्के को 0 या अधिक बार उपयोग करने वाले संयोजनों की संख्या पहले से शामिल होती है,
            // इसलिए इस एक पंक्ति से "coin को 1 बार, 2 बार, 3 बार… उपयोग करना" सभी मामले समाहित हो जाते हैं
            dp[a] += dp[a - coin];
        }
    }

    // लक्ष्य राशि बनाने वाले संयोजनों की कुल संख्या लौटाना
    return dp[amount];
}
```
