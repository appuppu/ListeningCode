# Implementing Regular Expression Matching — यह निर्धारित करना कि स्ट्रिंग पैटर्न से पूरी तरह मेल खाती है या नहीं

## समस्या का सार

इनपुट स्ट्रिंग `s` और पैटर्न `p` दिए गए हैं। पैटर्न में `.` किसी भी एक वर्ण से मेल खाता है, और `*` का अर्थ है कि उसके ठीक पहले का वर्ण 0 या अधिक बार दोहराया जा सकता है। यह `boolean` में लौटाना है कि पैटर्न स्ट्रिंग की **संपूर्णता** से मेल खाता है या नहीं।

## मूल विचार

स्ट्रिंग और पैटर्न के अंत से शुरुआत की ओर जाते हुए एक 2D DP टेबल भरी जाती है। `dp[i][j]` यह दर्शाता है कि "`s[i:]` पैटर्न `p[j:]` से मेल खाती है या नहीं"। जब `*` मौजूद हो, तो यह दो विकल्पों में सिमट जाता है: "पिछले वर्ण को 0 बार उपयोग करना (स्किप करना)" या "1 बार उपयोग करके स्ट्रिंग में एक आगे बढ़ना"।

## विचार प्रक्रिया

1. **उप-समस्याओं में विभाजित किया जा सकता है**: स्ट्रिंग की स्थिति `i` और पैटर्न की स्थिति `j` तय करने पर, "`s[i:]` पैटर्न `p[j:]` से मेल खाती है या नहीं" यह एक उप-समस्या बन जाती है। इस उप-समस्या का उत्तर `dp[i][j]` में सहेजने से दोहरी गणना से बचा जा सकता है
2. **वर्तमान स्थिति पर वर्ण मिलान का निर्णय करना**: यदि `s[i]` और `p[j]` एक ही वर्ण हैं, या `p[j]` `.` है, तो वर्तमान स्थिति का एक वर्ण मेल खाता है। इस निर्णय के परिणाम को `match` चर में सहेजा जाता है
3. **`*` होने पर दो विकल्पों पर विचार करना**: जब `p[j+1]` `*` हो, तो `x*` पैटर्न की दो व्याख्याएँ संभव हैं। पहली है "0 बार मिलान (स्किप)" — `x*` को पूरी तरह छोड़कर `dp[i][j+2]` को संदर्भित करना। दूसरी है "1 या अधिक बार मिलान" — यदि वर्तमान वर्ण मेल खाता है तो स्ट्रिंग में एक आगे बढ़कर `dp[i+1][j]` को संदर्भित करना (पैटर्न आगे नहीं बढ़ाया जाता, क्योंकि अगली स्थिति पर भी `*` द्वारा दोहराव जारी रह सकता है)
4. **`*` न होने पर एक-एक वर्ण आगे बढ़ना**: यदि वर्तमान वर्ण मेल खाता है, तो स्ट्रिंग और पैटर्न दोनों को एक आगे बढ़ाकर `dp[i+1][j+1]` सीधे उत्तर बन जाता है
5. **बेस केस सेट करना**: स्ट्रिंग और पैटर्न दोनों अंत तक पहुँच चुकी हों — वह स्थिति `dp[n][m]` `true` होती है। यदि स्ट्रिंग शेष है लेकिन पैटर्न अंत पर है तो `false` होता है। यदि पैटर्न शेष है लेकिन स्ट्रिंग अंत पर है, तो केवल `*` द्वारा स्किप करने पर ही `true` हो सकता है
6. **अंत से शुरुआत की ओर टेबल भरना**: `dp[i][j]` की गणना `dp[i][j+2]`, `dp[i+1][j]`, `dp[i+1][j+1]` पर निर्भर करती है। ये सभी `i` या `j` के बड़े दिशा के मान हैं, इसलिए `i` को `n` से `0` तक और `j` को `m-1` से `0` तक उल्टे क्रम में चलाने पर संदर्भित मान सदैव पहले से गणित होते हैं
7. **अंतिम रूप से लौटाया जाने वाला मान**: टेबल का `dp[0][0]` "संपूर्ण स्ट्रिंग संपूर्ण पैटर्न से मेल खाती है या नहीं" का उत्तर है

## पूर्व-आवश्यक ज्ञान

### 2D DP टेबल क्या है

दो चरों (यहाँ स्ट्रिंग की स्थिति `i` और पैटर्न की स्थिति `j`) के प्रत्येक संयोजन के लिए उप-समस्या का उत्तर सहेजने वाली दो-आयामी सरणी। `boolean[][] dp = new boolean[n+1][m+1]` से बनाई जाती है, और `dp[i][j]` में `s[i:]` और `p[j:]` के मिलान परिणाम को संग्रहित किया जाता है।

```java
boolean[][] dp = new boolean[n + 1][m + 1];  // (n+1)×(m+1) आकार की false से आरंभित तालिका बनाना
dp[n][m] = true;                              // बेस केस: दोनों अंत पर हों तो मिलान सफल
dp[i][j] = dp[i][j + 2];                     // किसी अन्य सेल के मान को संदर्भित करके वर्तमान सेल भरना
```

### String.length() और String.charAt()

`length()` स्ट्रिंग की लंबाई लौटाता है। `charAt(i)` इंडेक्स `i` पर स्थित वर्ण लौटाता है। इंडेक्स 0 से शुरू होता है, और सीमा से बाहर एक्सेस करने पर अपवाद फेंका जाता है।

```java
String s = "abc";
s.length();     // → 3
s.charAt(0);    // → 'a'
s.charAt(2);    // → 'c'
```

### `*` (स्टार) का अर्थ

रेगुलर एक्सप्रेशन में `*` का अर्थ है "ठीक पहले के एक वर्ण का 0 या अधिक बार दोहराव"। `a*` `""`, `"a"`, `"aa"`, `"aaa"`, ... इनमें से किसी से भी मेल खाता है। `.*` का अर्थ है "किसी भी वर्ण का 0 या अधिक बार दोहराव", इसलिए यह हर स्ट्रिंग से मेल खाता है। `*` अकेले उपयोग नहीं होता, यह हमेशा पिछले वर्ण के साथ `x*` के रूप में आता है।

## जटिलता

| | मान |
|---|---|
| Time | O(n×m) — n×m DP टेबल के प्रत्येक सेल की गणना एक बार की जाती है |
| Space | O(n×m) — n×m DP टेबल को सहेजा जाता है |

## कोड

```java
// इनपुट: स्ट्रिंग s और पैटर्न p
// आउटपुट: s की संपूर्णता p से मेल खाती है या नहीं, boolean में लौटाना
public boolean isMatch(String s, String p) {
    int n = s.length();  // स्ट्रिंग की लंबाई
    int m = p.length();  // पैटर्न की लंबाई

    // dp[i][j] = "s[i:] पैटर्न p[j:] से मेल खाती है या नहीं" सहेजने वाली दो-आयामी तालिका
    // इंडेक्स n और m खाली स्ट्रिंग को दर्शाते हैं, इसलिए आकार +1 किया जाता है
    boolean[][] dp = new boolean[n + 1][m + 1];

    // बेस केस: दोनों स्ट्रिंग अंत तक पहुँच चुकी हों तो मिलान सफल है
    dp[n][m] = true;

    // अंत से शुरुआत की ओर टेबल भरना
    // इस क्रम से, संदर्भित dp[i][j+2], dp[i+1][j], dp[i+1][j+1] सभी पहले से गणित होते हैं
    for (int i = n; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // वर्तमान स्थिति का एक वर्ण मेल खाता है या नहीं, इसका निर्णय करना
            // i < n की जाँच पहले करने से, स्ट्रिंग अंत पर होने पर charAt द्वारा सीमा से बाहर एक्सेस रोका जाता है
            boolean match = i < n
                && (s.charAt(i) == p.charAt(j)
                    || p.charAt(j) == '.');

            // j+1 < m से सीमा जाँच करना, और पैटर्न की वर्तमान स्थिति x* के रूप में है या नहीं निर्धारित करना
            if (j + 1 < m && p.charAt(j + 1) == '*') {
                // x* पैटर्न के दो विकल्पों का OR (तार्किक योग) लेना:
                // dp[i][j+2]: 0 बार मिलान (x* को पूरी तरह छोड़ना)
                // match && dp[i+1][j]: 1 बार मिलान करके स्ट्रिंग आगे बढ़ाना (पैटर्न आगे नहीं बढ़ाया जाता। * द्वारा दोहराव जारी रह सकता है इसलिए j यथावत रखा जाता है)
                dp[i][j] = dp[i][j + 2]
                    || (match && dp[i + 1][j]);
            } else {
                // सामान्य वर्ण: 1 वर्ण मेल खाने पर स्ट्रिंग और पैटर्न दोनों को एक आगे बढ़ाना
                dp[i][j] = match
                    && dp[i + 1][j + 1];
            }
        }
    }

    // dp[0][0] "संपूर्ण स्ट्रिंग s संपूर्ण पैटर्न p से मेल खाती है या नहीं" का अंतिम उत्तर है
    return dp[0][0];
}
```
