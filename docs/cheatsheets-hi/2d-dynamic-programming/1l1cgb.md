# Finding the Longest Common Subsequence — 2 स्ट्रिंग्स में सबसे लंबी कॉमन सबसीक्वेंस की लंबाई ज्ञात करना

## समस्या का सार

2 स्ट्रिंग्स `text1` और `text2` दी गई हैं। दोनों स्ट्रिंग्स में कॉमन **सबसीक्वेंस (subsequence)** में से सबसे लंबी सबसीक्वेंस की **लंबाई** को रिटर्न करना है। सबसीक्वेंस वह अनुक्रम है जो मूल स्ट्रिंग से अक्षरों को चुनकर उनके सापेक्ष क्रम को बनाए रखते हुए निकाला जाता है, और इनका सन्निकट (continuous) होना आवश्यक नहीं है।

## मूल विचार

यदि 2 स्ट्रिंग्स के अंतिम अक्षर मेल खाते हैं, तो वह अक्षर LCS में शामिल होता है, और शेष उप-समस्या दोनों स्ट्रिंग्स को 1-1 अक्षर छोटा करने पर बनती है। यदि अक्षर मेल नहीं खाते, तो किसी एक स्ट्रिंग को 1 अक्षर छोटा करने पर बनने वाली 2 उप-समस्याओं में से जो लंबी हो उसे अपनाया जाता है। इस पुनरावर्ती संरचना को 2-आयामी टेबल में बॉटम-अप भरकर, दोहरी गणना के बिना इष्टतम हल प्राप्त होता है।

## विचार प्रक्रिया

1. **उप-समस्या की परिभाषा**: `text1` के पहले `i` अक्षरों और `text2` के पहले `j` अक्षरों के LCS की लंबाई को `dp[i][j]` के रूप में परिभाषित करते हैं। अंतिम उत्तर `dp[m][n]` है (`m` = text1 की लंबाई, `n` = text2 की लंबाई)
2. **अंतिम अक्षर मेल खाने पर संक्रमण**: जब `text1[i-1] == text2[j-1]` होता है, तो यह अक्षर LCS का हिस्सा बनता है। इसलिए `dp[i][j] = dp[i-1][j-1] + 1` होता है। दोनों स्ट्रिंग्स को 1-1 अक्षर छोटा करने पर बनी उप-समस्या के उत्तर में 1 जोड़ा जाता है
3. **अंतिम अक्षर मेल न खाने पर संक्रमण**: जब `text1[i-1] != text2[j-1]` होता है, तो कम से कम एक स्ट्रिंग का अंतिम अक्षर LCS में शामिल नहीं होता। `text1` को 1 अक्षर छोटा करने पर (`dp[i-1][j]`) और `text2` को 1 अक्षर छोटा करने पर (`dp[i][j-1]`) — इन दोनों में से बड़े वाले को अपनाया जाता है। अर्थात `dp[i][j] = max(dp[i-1][j], dp[i][j-1])` होता है
4. **आधार शर्त**: जब किसी एक स्ट्रिंग की लंबाई 0 (खाली) होती है, तो कोई कॉमन सबसीक्वेंस नहीं होती, इसलिए `dp[0][j] = 0` और `dp[i][0] = 0` होता है। Java में `int[][]` बनाने पर सभी तत्व 0 से इनिशियलाइज़ होते हैं, इसलिए स्पष्ट सेटिंग की आवश्यकता नहीं है
5. **टेबल भरने का तरीका**: `dp[i][j]` की गणना `dp[i-1][j-1]`, `dp[i-1][j]`, `dp[i][j-1]` पर निर्भर करती है। इसलिए `i` को 1 से m तक और `j` को 1 से n तक बढ़ते क्रम में भरने पर, संदर्भित मान हमेशा पहले से गणना किए हुए होते हैं
6. **अंतिम रिटर्न वैल्यू**: पूरी टेबल भरने के बाद, `dp[m][n]` दोनों स्ट्रिंग्स के संपूर्ण LCS की लंबाई होती है, और इसे रिटर्न किया जाता है

## पूर्व-ज्ञान

### सबसीक्वेंस (Subsequence) क्या है

सबसीक्वेंस वह अनुक्रम है जो किसी स्ट्रिंग से 0 या अधिक अक्षर हटाकर, शेष अक्षरों के सापेक्ष क्रम को बदले बिना प्राप्त होता है। सबस्ट्रिंग (substring) के विपरीत, इसमें अक्षरों का सन्निकट होना आवश्यक नहीं है।

```
स्ट्रिंग: "abcde"
सबसीक्वेंस का उदाहरण: "ace" (a, c, e को चुना गया। b, d को हटाया गया)
सबसीक्वेंस नहीं है: "aec" (मूल स्ट्रिंग में क्रम a→c→e का उल्लंघन हो रहा है)
```

### 2-आयामी ऐरे का निर्माण और इनिशियलाइज़ेशन

Java में `new int[m+1][n+1]` लिखने पर, `(m+1) × (n+1)` आकार का 2-आयामी ऐरे बनता है और सभी तत्व 0 से इनिशियलाइज़ होते हैं।

```java
int[][] dp = new int[m + 1][n + 1];  // (m+1) पंक्तियों × (n+1) स्तंभों का ऐरे बनाना, सभी तत्व 0
dp[i][j] = 5;                         // i-वीं पंक्ति j-वें स्तंभ में मान 5 असाइन करना
int val = dp[i][j];                    // i-वीं पंक्ति j-वें स्तंभ का मान प्राप्त करना → 5
```

### Math.max क्या है

Math.max एक मेथड है जो 2 पूर्णांकों में से बड़ा वाला रिटर्न करता है। 2 उप-समस्याओं के हल की तुलना करके बेहतर विकल्प चुनने के लिए इसका उपयोग किया जाता है।

```java
Math.max(3, 7);    // 2 मानों में से बड़ा वाला रिटर्न करता है → 7
Math.max(dp[i-1][j], dp[i][j-1]);  // 2 सेल के मानों की तुलना करके बड़ा वाला रिटर्न करता है
```

### charAt क्या है

charAt एक मेथड है जो स्ट्रिंग में निर्दिष्ट स्थान का अक्षर रिटर्न करता है। इंडेक्स 0 से शुरू होता है।

```java
String s = "abc";
s.charAt(0);    // इंडेक्स 0 का अक्षर रिटर्न करता है → 'a'
s.charAt(2);    // इंडेक्स 2 का अक्षर रिटर्न करता है → 'c'
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(m × n) — m×n टेबल के प्रत्येक सेल को 1 बार भरा जाता है |
| Space | O(m × n) — (m+1)×(n+1) आकार के 2-आयामी ऐरे का उपयोग किया जाता है |

## कोड

```java
// इनपुट: 2 स्ट्रिंग्स text1 और text2
// आउटपुट: 2 स्ट्रिंग्स की सबसे लंबी कॉमन सबसीक्वेंस की लंबाई int के रूप में रिटर्न करना
public int longestCommonSubsequence(String text1, String text2) {
    // text1 की लंबाई को m में और text2 की लंबाई को n में असाइन करना। टेबल आकार और लूप सीमा के लिए उपयोग किया जाता है
    int m = text1.length();
    int n = text2.length();

    // dp[i][j] = text1 के पहले i अक्षरों और text2 के पहले j अक्षरों के LCS की लंबाई
    // आकार (m+1)×(n+1) रखने का कारण यह है कि किसी एक स्ट्रिंग के खाली होने की स्थिति (आधार शर्त) को दर्शाया जा सके
    // Java में int[][] के सभी तत्व 0 से इनिशियलाइज़ होते हैं, इसलिए आधार शर्त dp[0][j]=0, dp[i][0]=0 स्वचालित रूप से पूरी होती है
    int[][] dp = new int[m + 1][n + 1];

    // i दर्शाता है कि text1 के पहले कितने अक्षरों पर विचार किया जा रहा है
    for (int i = 1; i <= m; i++) {
        // j दर्शाता है कि text2 के पहले कितने अक्षरों पर विचार किया जा रहा है
        for (int j = 1; j <= n; j++) {
            // dp का इंडेक्स 1 से शुरू होता है, लेकिन स्ट्रिंग का इंडेक्स 0 से शुरू होता है, इसलिए i-1, j-1 से एक्सेस किया जाता है
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                // अक्षर मेल खाने पर, मेल खाया अक्षर LCS में जुड़ता है, इसलिए दोनों को 1-1 अक्षर छोटा करने पर बनी उप-समस्या के उत्तर में 1 जोड़ा जाता है
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // अक्षर मेल न खाने पर, text1 को 1 अक्षर छोटा करने और text2 को 1 अक्षर छोटा करने में से, जिसमें LCS लंबी हो उसे अपनाया जाता है
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    // टेबल का दायाँ निचला कोना text1 संपूर्ण और text2 संपूर्ण के LCS की लंबाई है
    return dp[m][n];
}
```
