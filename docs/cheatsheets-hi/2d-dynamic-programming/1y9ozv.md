# Maximizing Coins From Bursting Balloons — गुब्बारे फोड़ने के क्रम को अनुकूलित करके सिक्कों को अधिकतम करना

## समस्या का सार

एक पूर्णांक सरणी `nums` (प्रत्येक गुब्बारे का मान) दी गई है। जब आप गुब्बारा `i` फोड़ते हैं, तो आपको `nums[left] * nums[i] * nums[right]` (left और right शेष आसन्न गुब्बारे हैं) सिक्के प्राप्त होते हैं। सभी गुब्बारे फोड़ने पर प्राप्त होने वाले सिक्कों का अधिकतम मान लौटाएँ। सरणी की सीमा से बाहर के मान को `1` माना जाता है।

## मूल विचार

गुब्बारों को "किस क्रम में फोड़ना है" के बजाय, अंतराल `[left, right]` में "किस गुब्बारे को **सबसे अंत में** फोड़ना है" — इस उलटे दृष्टिकोण से सोचें। यदि अंत में फोड़ने वाले गुब्बारे `k` को निश्चित कर दें, तो बाएँ और दाएँ उप-अंतराल एक-दूसरे से स्वतंत्र हो जाते हैं, और अंतराल DP से इष्टतम हल को संयोजित किया जा सकता है।

## विचार प्रक्रिया

1. **फोड़ने के क्रम की निर्भरता को समाप्त करना है**: गुब्बारा फोड़ने पर आसन्न संबंध बदल जाता है, इसलिए फोड़ने के क्रम के अनुसार प्राप्त सिक्के बदलते हैं। सभी क्रमों की खोज करने पर `n!` संभावनाएँ बनती हैं जो व्यावहारिक नहीं है। इस निर्भरता को तोड़ने के लिए एक नए दृष्टिकोण की आवश्यकता है
2. **"सबसे अंत में फोड़ना" सोचने पर अंतराल स्वतंत्र हो जाते हैं**: यदि अंतराल `[left, right]` में गुब्बारा `k` को सबसे अंत में फोड़ने का निर्णय लें, तो `k` को फोड़ते समय `[left, k-1]` और `[k+1, right]` के सभी गुब्बारे पहले ही समाप्त हो चुके होते हैं। अर्थात `k` के आसन्न गुब्बारे अंतराल के बाहर स्थित `arr[left-1]` और `arr[right+1]` पर निश्चित हो जाते हैं। बाएँ और दाएँ उप-समस्याएँ स्वतंत्र हो जाती हैं, इसलिए DP से संयोजन संभव है
3. **सीमा प्रसंस्करण को सरल बनाना**: मूल सरणी के दोनों छोरों पर मान `1` के काल्पनिक गुब्बारे जोड़कर नई सरणी `arr` बनाएँ। `arr[0] = 1`, `arr[n+1] = 1` रखने से, सीमा शर्तों को विशेष रूप से संभालने की आवश्यकता नहीं रहती और `arr[left-1] * arr[k] * arr[right+1]` सूत्र को एकीकृत रूप से उपयोग किया जा सकता है
4. **DP तालिका की परिभाषा**: `dp[left][right]` को "अंतराल `[left, right]` के सभी गुब्बारे फोड़कर प्राप्त सिक्कों का अधिकतम मान" के रूप में परिभाषित करें। अंतिम उत्तर `dp[1][n]` (मूल सरणी की पूरी अंतराल के अनुरूप) होगा
5. **छोटी लंबाई के अंतराल से पहले भरें**: लंबाई 1 के अंतराल (एक गुब्बारा) से शुरू करके, लंबाई `n` के अंतराल तक क्रमशः DP तालिका भरें। लंबे अंतराल का मान छोटे अंतराल के मान पर निर्भर करता है, इसलिए छोटे से गणना करने पर संदर्भित मान हमेशा पहले से गणना किया हुआ होता है
6. **प्रत्येक अंतराल में अंत में फोड़ने वाले गुब्बारे की पूर्ण खोज करें**: अंतराल `[left, right]` के लिए, अंत में फोड़ने वाले गुब्बारे `k` को `left` से `right` तक आज़माएँ। `k` को अंत में फोड़ने पर प्राप्त सिक्के `arr[left-1] * arr[k] * arr[right+1] + dp[left][k-1] + dp[k+1][right]` हैं, और इसके अधिकतम मान को `dp[left][right]` में दर्ज करें

## पूर्वापेक्षित ज्ञान

### अंतराल DP (Interval DP) क्या है

अंतराल `[left, right]` को इकाई मानकर DP तालिका का निर्माण करने की विधि है। अंतराल को विभाजित करके, उप-अंतराल के इष्टतम हल को संयोजित करके संपूर्ण इष्टतम हल प्राप्त किया जाता है। छोटे अंतराल से लंबे अंतराल की ओर बॉटम-अप गणना की जाती है।

```java
// अंतराल DP की मूल संरचना: छोटी लंबाई के अंतराल से क्रमशः गणना करें
for (int len = 1; len <= n; len++) {        // अंतराल की लंबाई
    for (int left = 1; left <= n - len + 1; left++) {  // अंतराल का बायाँ छोर
        int right = left + len - 1;          // अंतराल का दायाँ छोर
        // dp[left][right] की गणना करें
    }
}
```

### प्रहरी (Sentinel) क्या है

सरणी के दोनों छोरों पर काल्पनिक तत्व जोड़कर, सीमा शर्तों के विशेष प्रसंस्करण को अनावश्यक बनाने की तकनीक है। इस समस्या में दोनों छोरों पर मान `1` के गुब्बारे रखे जाते हैं।

```java
int[] arr = new int[n + 2];   // मूल सरणी से 2 बड़ी सरणी बनाएँ
arr[0] = 1;                   // बाएँ छोर का प्रहरी (मान 1)
arr[n + 1] = 1;               // दाएँ छोर का प्रहरी (मान 1)
for (int i = 0; i < n; i++)
    arr[i + 1] = nums[i];     // मूल तत्वों को इंडेक्स 1 से n तक कॉपी करें
```

### 2-आयामी सरणी का DP तालिका

`dp[i][j]` में अंतराल `[i, j]` का इष्टतम हल दर्ज किया जाता है। Java में `new int[n+2][n+2]` से बनाने पर सभी तत्व `0` से आरंभ होते हैं। रिक्त अंतराल (`left > right`) का मान `0` ही रहता है, इसलिए अतिरिक्त आरंभीकरण प्रसंस्करण की आवश्यकता नहीं है।

```java
int[][] dp = new int[n + 2][n + 2];  // सभी तत्व 0 से आरंभ होते हैं
dp[left][right];                      // अंतराल [left, right] का अधिकतम सिक्का संग्रहीत करें
```

## गणनात्मक जटिलता

| | मान |
|---|---|
| Time | O(n³) — अंतराल के बाएँ छोर, दाएँ छोर, और अंत में फोड़ने की स्थिति का 3-स्तरीय लूप |
| Space | O(n²) — DP तालिका `dp[n+2][n+2]` का उपयोग किया जाता है |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums (प्रत्येक गुब्बारे का मान)
// आउटपुट: सभी गुब्बारे फोड़कर प्राप्त सिक्कों का अधिकतम मान int में लौटाएँ
public int maxCoins(int[] nums) {
    int n = nums.length;

    // दोनों छोरों पर प्रहरी (मान 1) जोड़कर सरणी बनाएँ
    // इन प्रहरियों से, अंतराल के बाहर संदर्भ करते समय सीमा शर्तों को विशेष रूप से संभालने की आवश्यकता नहीं रहती
    int[] arr = new int[n + 2];
    arr[0] = arr[n + 1] = 1;
    for (int i = 0; i < n; i++)
        arr[i + 1] = nums[i];

    // dp[left][right] = अंतराल [left, right] के सभी गुब्बारे फोड़कर प्राप्त सिक्कों का अधिकतम मान
    // आकार n+2 रखने का कारण प्रहरी के इंडेक्स (0 और n+1) को शामिल करना है
    // रिक्त अंतराल (left > right) का मान 0 ही रहता है
    int[][] dp = new int[n + 2][n + 2];

    // छोटी लंबाई के अंतराल से क्रमशः गणना करें
    // छोटे अंतराल से गणना करने से, लंबे अंतराल की गणना करते समय आवश्यक उप-अंतराल का मान हमेशा पहले से गणना किया हुआ होता है
    for (int len = 1; len <= n; len++) {
        // लंबाई len के सभी अंतरालों को स्कैन करें
        for (int left = 1; left <= n - len + 1; left++) {
            int right = left + len - 1;

            // अंतराल [left, right] में अंत में फोड़ने वाले गुब्बारे k की पूर्ण खोज करें
            for (int k = left; k <= right; k++) {
                // k को अंत में फोड़ने का निर्णय लेने पर, k के आसन्न गुब्बारे अंतराल के बाहर arr[left-1] और arr[right+1] पर निश्चित हो जाते हैं
                int coins = arr[left - 1] * arr[k] * arr[right + 1];
                // बाएँ और दाएँ उप-अंतराल के सिक्के जोड़कर कुल योग प्राप्त करें
                int total = coins + dp[left][k - 1] + dp[k + 1][right];
                // dp[left][right] को अधिकतम मान से अपडेट करें
                dp[left][right] = Math.max(dp[left][right], total);
            }
        }
    }

    // मूल सरणी की पूरी अंतराल (इंडेक्स 1 से n) के अनुरूप अधिकतम सिक्के लौटाएँ
    return dp[1][n];
}
```
