# Checking if a String is an Interleaving of Two Others — यह जाँचना कि तीसरी स्ट्रिंग दो अन्य स्ट्रिंग्स को बारी-बारी मिलाकर बनाई जा सकती है या नहीं

## समस्या का सार

तीन स्ट्रिंग्स `s1`, `s2`, `s3` दी गई हैं। यह निर्धारित करना है कि `s3`, `s1` और `s2` के **इंटरलीविंग** (बारी-बारी मिश्रण) से बनी है या नहीं। इंटरलीविंग का अर्थ है कि `s1` और `s2` के सभी अक्षरों का उपयोग करते हुए, प्रत्येक स्ट्रिंग के भीतर अक्षरों के सापेक्ष क्रम को बनाए रखते हुए उन्हें मिलाना।

## मूल विचार

इस समस्या को उप-समस्या में विभाजित किया जा सकता है: क्या `s1` के पहले `i` अक्षर और `s2` के पहले `j` अक्षर मिलकर `s3` के पहले `i+j` अक्षर बना सकते हैं। प्रत्येक स्थिति पर "अगला 1 अक्षर `s1` से लें या `s2` से लें" इन दो विकल्पों को DP टेबल द्वारा कुशलतापूर्वक निर्धारित किया जाता है।

## विचार प्रक्रिया

1. **लंबाई की पूर्व शर्त की जाँच करें**: यदि `s3`, `s1` और `s2` का इंटरलीविंग है, तो `s3` की लंबाई `s1` की लंबाई + `s2` की लंबाई के बराबर होनी चाहिए। यदि बराबर नहीं है तो तुरंत `false` लौटाया जा सकता है
2. **उप-समस्या को परिभाषित करें**: `dp[i][j]` को "क्या `s1` के पहले `i` अक्षर और `s2` के पहले `j` अक्षर मिलकर `s3` के पहले `i+j` अक्षर बना सकते हैं" के रूप में परिभाषित करें। इस परिभाषा से, `dp[m][n]` (`m` = `s1` की लंबाई, `n` = `s2` की लंबाई) अंतिम उत्तर होता है
3. **संक्रमण सूत्र निकालें**: `dp[i][j]` दो में से किसी एक स्थिति में `true` होता है। स्थिति 1: `dp[i-1][j]` `true` है और `s1` का `i`-वाँ अक्षर `s3` के `i+j`-वें अक्षर से मेल खाता है (`s1` से 1 अक्षर लेना)। स्थिति 2: `dp[i][j-1]` `true` है और `s2` का `j`-वाँ अक्षर `s3` के `i+j`-वें अक्षर से मेल खाता है (`s2` से 1 अक्षर लेना)
4. **बेस केस को परिभाषित करें**: जब `i=0` और `j=0` हो, तो किसी भी स्ट्रिंग से कोई अक्षर नहीं लिया गया है, यह प्रारंभिक अवस्था है और यह `s3` के पहले 0 अक्षरों (खाली स्ट्रिंग) से मेल खाती है, इसलिए `dp[0][0] = true` रखा जाता है
5. **स्थान जटिलता को अनुकूलित करें**: 2-आयामी `dp[i][j]` में `i`-वीं पंक्ति की गणना केवल `i-1`-वीं पंक्ति के मानों का उपयोग करती है। इसलिए 1-आयामी ऐरे `dp[j]` पर्याप्त है, जहाँ `dp[j]` का अपडेट से पहले का मान पिछली पंक्ति (`dp[i-1][j]`) के बराबर होता है, और `dp[j-1]` का अपडेट के बाद का मान वर्तमान पंक्ति के बाएँ पड़ोसी (`dp[i][j-1]`) के बराबर होता है
6. **अंतिम परिणाम**: बाहरी लूप `i = 0` से `m` तक और आंतरिक लूप `j = 0` से `n` तक चलने के बाद, `dp[n]` इस बात का उत्तर है कि `s3` को पूर्ण रूप से इंटरलीविंग से बनाया जा सकता है या नहीं

## पूर्व-ज्ञान

### DP (डायनामिक प्रोग्रामिंग) में 1-आयामी ऐरे द्वारा स्थान अनुकूलन क्या है

2-आयामी DP टेबल `dp[i][j]` में, जब प्रत्येक पंक्ति की गणना केवल पिछली पंक्ति पर निर्भर करती है, तो 1-आयामी ऐरे `dp[j]` से प्रतिस्थापित किया जा सकता है। ऐरे को पंक्ति दर पंक्ति ओवरराइट करके अपडेट करने से, स्थान जटिलता O(m×n) से O(n) तक कम हो जाती है।

```java
// 2-आयामी स्थिति: dp[i][j], dp[i-1][j] और dp[i][j-1] को संदर्भित करता है
boolean[][] dp = new boolean[m + 1][n + 1];

// 1-आयामी में अनुकूलन: dp[j] को पंक्ति दर पंक्ति ओवरराइट किया जाता है
boolean[] dp = new boolean[n + 1];
// dp[j] का अपडेट से पहले का मान → पिछली पंक्ति के dp[i-1][j] के बराबर
// dp[j-1] का अपडेट के बाद का मान → वर्तमान पंक्ति के dp[i][j-1] के बराबर
```

### String.charAt(index) क्या है

यह स्ट्रिंग में निर्दिष्ट स्थिति पर मौजूद अक्षर लौटाने वाला मेथड है। इंडेक्स 0 से शुरू होता है।

```java
String s = "abc";
s.charAt(0);  // 'a' लौटाता है
s.charAt(2);  // 'c' लौटाता है
```

### इंटरलीविंग (Interleaving) क्या है

दो स्ट्रिंग्स के अक्षरों को उनके सापेक्ष क्रम को बनाए रखते हुए मिलाकर एक स्ट्रिंग बनाना।
उदाहरण: `s1 = "aab"`, `s2 = "axy"` होने पर, `"aaxaby"` एक इंटरलीविंग है (`s1` से a,a,b और `s2` से a,x,y का क्रम क्रमशः संरक्षित है)। `"abaaxy"`, `s1` के अक्षरों का क्रम बिगड़ने के कारण इंटरलीविंग नहीं है।

## जटिलता

| | मान |
|---|---|
| Time | O(m×n) — `s1` की लंबाई `m` और `s2` की लंबाई `n` के दोहरे लूप को एक बार निष्पादित किया जाता है |
| Space | O(n) — केवल `s2` की लंबाई+1 आकार की 1-आयामी DP ऐरे का उपयोग किया जाता है |

## कोड

```java
// इनपुट: स्ट्रिंग s1 (लंबाई m), स्ट्रिंग s2 (लंबाई n), स्ट्रिंग s3
// आउटपुट: s3, s1 और s2 के इंटरलीविंग से बन सकती है या नहीं, boolean के रूप में लौटाना
public boolean isInterleave(String s1, String s2, String s3) {
    int m = s1.length();
    int n = s2.length();

    // यदि m + n, s3 की लंबाई के बराबर नहीं है, तो इंटरलीविंग संभव नहीं है
    if (m + n != s3.length())
        return false;

    // dp[j] = s1 के पहले i अक्षर और s2 के पहले j अक्षर मिलकर s3 के पहले i+j अक्षर बना सकते हैं या नहीं
    // 1-आयामी ऐरे को पंक्ति दर पंक्ति ओवरराइट करके, 2-आयामी टेबल की स्थान जटिलता O(n) तक संकुचित की जाती है
    boolean[] dp = new boolean[n + 1];

    // बाहरी लूप: i, s1 से लिए जाने वाले अक्षरों की संख्या दर्शाता है (0〜m)
    for (int i = 0; i <= m; i++) {
        // आंतरिक लूप: j, s2 से लिए जाने वाले अक्षरों की संख्या दर्शाता है (0〜n)
        for (int j = 0; j <= n; j++) {
            if (i == 0 && j == 0) {
                // बेस केस: किसी भी स्ट्रिंग से कोई अक्षर नहीं लिया गया है, और यह s3 की खाली स्ट्रिंग से मेल खाता है
                dp[j] = true;
            } else {
                // शर्त 1 (s1 से लेना): dp[j] का अपडेट से पहले का मान (पिछली पंक्ति = dp[i-1][j] के बराबर) true है
                //   और s1 का i-वाँ अक्षर s3 के i+j-वें अक्षर से मेल खाता है
                // शर्त 2 (s2 से लेना): dp[j-1] का अपडेट के बाद का मान (वर्तमान पंक्ति का बायाँ पड़ोसी = dp[i][j-1] के बराबर) true है
                //   और s2 का j-वाँ अक्षर s3 के i+j-वें अक्षर से मेल खाता है
                // नोट: आंतरिक लूप j को बाएँ से दाएँ चलाता है, इसलिए dp[j] अभी तक ओवरराइट नहीं हुआ है और पिछली पंक्ति का मान रखता है,
                //   जबकि dp[j-1] पहले से ओवरराइट हो चुका है इसलिए वर्तमान पंक्ति का मान रखता है
                dp[j] =
                    (dp[j] && i > 0
                    && s1.charAt(i - 1)
                    == s3.charAt(i + j - 1))
                    || (j > 0
                    && dp[j - 1]
                    && s2.charAt(j - 1)
                    == s3.charAt(i + j - 1));
            }
        }
    }

    // dp[n], s1 के सभी m अक्षर और s2 के सभी n अक्षर मिलकर s3 के सभी m+n अक्षर बना सकते हैं या नहीं, इसका परिणाम है
    return dp[n];
}
```
