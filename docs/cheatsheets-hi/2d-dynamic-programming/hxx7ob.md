# Counting Unique Paths in a Grid — ग्रिड में ऊपर-बाएँ से नीचे-दाएँ तक अद्वितीय पथों की संख्या गिनना

## समस्या का सार

`m × n` का एक ग्रिड दिया गया है। ऊपर-बाएँ सेल `(0, 0)` से नीचे-दाएँ सेल `(m-1, n-1)` तक, प्रत्येक कदम पर **केवल दाएँ या नीचे** जा सकते हैं, ऐसी स्थिति में अद्वितीय पथों की कुल संख्या लौटानी है।

## मूल विचार

किसी सेल तक पहुँचने के पथों की संख्या "ऊपर वाले सेल तक के पथों की संख्या" और "बाएँ वाले सेल तक के पथों की संख्या" का योग होती है। इस पुनरावृत्ति संबंध को बॉटम-अप भरने पर उत्तर प्राप्त होता है, और प्रत्येक पंक्ति की गणना केवल पिछली पंक्ति और वर्तमान पंक्ति पर निर्भर करती है, इसलिए केवल एक पंक्ति की सरणी से स्थान की बचत की जा सकती है।

## विचार प्रक्रिया

1. **प्रत्येक सेल तक के पथों की संख्या को उप-समस्याओं में विभाजित किया जा सकता है**: सेल `(i, j)` तक पहुँचने के लिए, अनिवार्य रूप से ऊपर `(i-1, j)` या बाएँ `(i, j-1)` से आना होता है। इसलिए `dp[i][j] = dp[i-1][j] + dp[i][j-1]` यह पुनरावृत्ति संबंध बनता है
2. **आधार स्थिति निर्धारित करना**: सबसे ऊपरी पंक्ति के सेलों तक केवल बाएँ से पहुँचा जा सकता है, और सबसे बाईं स्तंभ के सेलों तक केवल ऊपर से पहुँचा जा सकता है। दोनों में पथों की संख्या 1 होती है, इसलिए `dp[0][j] = 1`, `dp[i][0] = 1` से आरंभ किया जाता है
3. **प्रत्येक पंक्ति को बाएँ से दाएँ भरना**: पुनरावृत्ति संबंध "एक ऊपर के सेल" और "एक बाएँ के सेल" पर निर्भर करता है, इसलिए पंक्तियों को ऊपर से नीचे और प्रत्येक पंक्ति के भीतर बाएँ से दाएँ स्कैन करने पर, आवश्यक मान सदैव पहले से गणना किए हुए होते हैं
4. **स्थान को एक पंक्ति तक संकुचित किया जा सकता है**: `dp[i][j]` केवल उसी पंक्ति के बाएँ पड़ोसी `dp[i][j-1]` और पिछली पंक्ति के उसी स्तंभ `dp[i-1][j]` पर निर्भर करता है। एक-आयामी सरणी `dp[j]` का उपयोग करने पर, अद्यतन से पहले का `dp[j]` "ऊपर के सेल का मान" होता है, और अद्यतन हो चुका `dp[j-1]` "बाएँ के सेल का मान" होता है, इसलिए `dp[j] += dp[j-1]` से पुनरावृत्ति संबंध व्यक्त किया जा सकता है
5. **आरंभ में सभी तत्व 1 होते हैं**: एक-आयामी सरणी को सभी 1 से आरंभ करने पर, यह सबसे ऊपरी पंक्ति (सभी सेलों की पथ संख्या 1) की स्थिति को दर्शाता है। सबसे बाएँ स्तंभ के अनुरूप `dp[0]` आंतरिक लूप में अद्यतन नहीं होता, इसलिए यह सदैव 1 बना रहता है, और सबसे बाएँ स्तंभ की आधार स्थिति स्वाभाविक रूप से बनी रहती है
6. **अंतिम रूप से लौटाया जाने वाला मान**: सभी पंक्तियों की प्रक्रिया पूरी होने के बाद, `dp[n-1]` नीचे-दाएँ सेल तक के पथों की संख्या को धारण करता है, इसलिए इसे लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### Arrays.fill क्या है

यह एक उपयोगिता विधि है जो सरणी के सभी तत्वों को निर्दिष्ट मान से एक साथ आरंभ करती है। लूप लिखे बिना सरणी को एक समान मान से भरा जा सकता है।

```java
int[] dp = new int[5];       // लंबाई 5 की सरणी बनाना (प्रारंभिक मान सभी 0 हैं)
Arrays.fill(dp, 1);          // सभी तत्वों को 1 पर सेट करना → [1, 1, 1, 1, 1]
```

### एक-आयामी DP द्वारा स्थान संकुचन क्या है

द्वि-आयामी DP तालिका में, जब प्रत्येक सेल की गणना केवल "वर्तमान पंक्ति" और "एक पिछली पंक्ति" पर निर्भर करती है, तब द्वि-आयामी सरणी को एक-आयामी सरणी से प्रतिस्थापित किया जा सकता है। सरणी को प्रत्येक पंक्ति पर ओवरराइट करके अद्यतन करने से, Space O(m×n) को O(n) तक घटाया जा सकता है।

```java
// द्वि-आयामी की स्थिति में: dp[i][j] = dp[i-1][j] + dp[i][j-1]
// एक-आयामी में संकुचन: dp[j] += dp[j-1]
//   dp[j] (अद्यतन से पहले) = पिछली पंक्ति के उसी स्तंभ का मान (= dp[i-1][j] के समतुल्य)
//   dp[j-1] (अद्यतन हो चुका) = वर्तमान पंक्ति के बाएँ पड़ोसी का मान (= dp[i][j-1] के समतुल्य)
```

## जटिलता

| | मान |
|---|---|
| Time | O(m × n) — ग्रिड के सभी सेलों को एक-एक बार स्कैन किया जाता है |
| Space | O(n) — केवल एक पंक्ति की सरणी रखी जाती है |

## कोड

```java
// इनपुट: पूर्णांक m (पंक्तियों की संख्या) और पूर्णांक n (स्तंभों की संख्या)
// आउटपुट: ऊपर-बाएँ से नीचे-दाएँ तक अद्वितीय पथों की संख्या पूर्णांक के रूप में लौटाना
public int uniquePaths(int m, int n) {
    // लंबाई n की एक-पंक्ति DP सरणी बनाना और सभी तत्वों को 1 से आरंभ करना
    // सभी को 1 करने से, सबसे ऊपरी पंक्ति की आधार स्थिति (प्रत्येक सेल तक पथ संख्या 1) सेट होती है
    int[] dp = new int[n];
    Arrays.fill(dp, 1);

    // i=0 (सबसे ऊपरी पंक्ति) आरंभ में सेट हो चुकी है, इसलिए i=1 से शुरू करना
    for (int i = 1; i < m; i++) {
        // j=0 (सबसे बाएँ स्तंभ) सदैव 1 बना रहना चाहिए, इसलिए j=1 से शुरू करना
        for (int j = 1; j < n; j++) {
            // dp[j] (अद्यतन से पहले) = पिछली पंक्ति के उसी स्तंभ का मान (ऊपर से आने वाले पथों की संख्या)
            // dp[j-1] (अद्यतन हो चुका) = वर्तमान पंक्ति के बाएँ पड़ोसी का मान (बाएँ से आने वाले पथों की संख्या)
            // यह जोड़ पुनरावृत्ति संबंध dp[i][j] = dp[i-1][j] + dp[i][j-1] को एक-आयामी सरणी पर लागू करता है
            dp[j] += dp[j - 1];
        }
    }

    // dp[n-1] ग्रिड के नीचे-दाएँ सेल (m-1, n-1) तक अद्वितीय पथों की संख्या धारण करता है
    return dp[n - 1];
}
```
