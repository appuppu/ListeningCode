# Designing a Stack That Tracks the Minimum — सभी ऑपरेशन O(1) में न्यूनतम मान प्राप्त करने वाला स्टैक डिज़ाइन करना

## समस्या का सार

`push`, `pop`, `top`, `getMin` (वर्तमान न्यूनतम मान प्राप्त करना) — इन चारों ऑपरेशनों को O(1) में निष्पादित करने वाला स्टैक डिज़ाइन करना है। सामान्य स्टैक में न्यूनतम मान प्राप्त करने में O(n) समय लगता है, इसलिए एक विशेष तकनीक की आवश्यकता होती है।

## मूल विचार

स्टैक के प्रत्येक तत्व के साथ "उस समय का न्यूनतम मान" भी संग्रहित करने पर, तत्व pop होने के बाद भी न्यूनतम मान की जानकारी नष्ट नहीं होती। `getMin()` हमेशा स्टैक के शीर्ष को देखकर O(1) में उत्तर देता है।

## विचार प्रक्रिया

1. **getMin को O(1) बनाने के लिए, न्यूनतम मान को हमेशा ट्रैक करना आवश्यक है**: एक वेरिएबल से न्यूनतम मान प्रबंधित करने पर विचार करते हैं, लेकिन pop से न्यूनतम मान हटने पर अगला न्यूनतम मान अज्ञात हो जाता है। अर्थात, न्यूनतम मान का "इतिहास" बनाए रखने की व्यवस्था आवश्यक है
2. **न्यूनतम मान का इतिहास स्टैक की स्थिति से जुड़ा होता है**: स्टैक में जब भी तत्व जोड़ा जाता है, न्यूनतम मान बदल सकता है। इसके विपरीत pop होने पर, push से पहले के न्यूनतम मान पर वापस आता है। यह "push से पहले की स्थिति पर लौटना" स्टैक की स्वयं की विशेषता के समान है
3. **प्रत्येक तत्व के साथ उस समय का न्यूनतम मान जोड़ी में संग्रहित करना**: push करते समय, नए मान और वर्तमान न्यूनतम मान की तुलना करके, छोटे मान को "उस समय का न्यूनतम मान" के रूप में नए मान के साथ संग्रहित करना है। इससे pop द्वारा तत्व हटने पर भी, अगला शीर्ष तत्व सही न्यूनतम मान रखता है
4. **जोड़ी की संरचना निर्धारित करना**: `int[]` array का उपयोग करते हुए, `[0]` में मान और `[1]` में उस समय का न्यूनतम मान संग्रहित करना है। स्टैक का प्रकार `Stack<int[]>` होगा
5. **push में न्यूनतम मान की गणना विधि**: यदि स्टैक खाली है तो नया मान ही न्यूनतम मान बनता है। खाली नहीं है तो नए मान और स्टैक के शीर्ष में संग्रहित न्यूनतम मान (`stack.peek()[1]`) की तुलना करके छोटा मान अपनाना है
6. **top, getMin, pop का कार्यान्वयन**: `top()` शीर्ष जोड़ी का `[0]`, `getMin()` शीर्ष जोड़ी का `[1]` लौटाता है — दोनों O(1) हैं। `pop()` सामान्य स्टैक की तरह शीर्ष तत्व को हटाता है

## पूर्वापेक्षित ज्ञान

### Stack क्या है

लास्ट-इन-फर्स्ट-आउट (LIFO) डेटा संरचना। अंतिम जोड़ा गया तत्व सबसे पहले निकाला जाता है। Java में Generics का उपयोग करके संग्रहित प्रकार निर्दिष्ट किया जाता है।

```java
Stack<int[]> stack = new Stack<>();  // int array संग्रहित करने वाला स्टैक बनाना
stack.push(new int[]{1, 1});         // शीर्ष पर तत्व जोड़ना
stack.peek();                         // शीर्ष तत्व को हटाए बिना देखना → [1, 1]
stack.pop();                          // शीर्ष तत्व को हटाकर लौटाना → [1, 1]
stack.isEmpty();                      // स्टैक खाली है या नहीं boolean में लौटाना → true
```

### Math.min क्या है

दो पूर्णांक लेकर छोटा मान लौटाने वाला मेथड। हर push पर नए मान और वर्तमान न्यूनतम मान की तुलना के लिए उपयोग किया जाता है।

```java
Math.min(3, 5);   // → 3
Math.min(-1, 0);  // → -1
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(1) — push, pop, top, getMin सभी ऑपरेशन स्थिर समय में पूर्ण होते हैं |
| Space | O(n) — स्टैक में अधिकतम n जोड़ियाँ संग्रहित होती हैं |

## कोड

```java
// इनपुट: push(val), pop(), top(), getMin() ऑपरेशनों की श्रृंखला
// आउटपुट: top() शीर्ष मान लौटाता है। getMin() स्टैक में वर्तमान न्यूनतम मान लौटाता है
class MinStack {

    // Stack<int[]> प्रकार का फ़ील्ड। प्रत्येक तत्व लंबाई 2 का array है, [0] में मान और [1] में उस समय पूरे स्टैक का न्यूनतम मान संग्रहित होता है
    private Stack<int[]> stack;

    public MinStack() {
        stack = new Stack<>();
    }

    public void push(int val) {
        // स्टैक खाली है तो val स्वयं न्यूनतम मान है। खाली नहीं है तो शीर्ष में दर्ज न्यूनतम मान से तुलना करके छोटा मान अपनाना है
        int min = stack.isEmpty() ? val : Math.min(val, stack.peek()[1]);
        // मान और न्यूनतम मान की जोड़ी new int[]{val, min} को push करना है। यह तत्व शीर्ष पर रहने तक min सही न्यूनतम मान रहता है
        stack.push(new int[]{val, min});
    }

    public void pop() {
        // शीर्ष जोड़ी को हटाना है। हटने के बाद नए शीर्ष जोड़ी के [1] में उस तत्व के push समय का सही न्यूनतम मान संग्रहित होता है, इसलिए न्यूनतम मान की संगतता स्वतः बनी रहती है
        stack.pop();
    }

    public int top() {
        // जोड़ी के [0] में मान स्वयं संग्रहित होता है
        return stack.peek()[0];
    }

    public int getMin() {
        // जोड़ी के [1] में उस समय का न्यूनतम मान संग्रहित होता है, इसलिए पूरे स्टैक को देखने की आवश्यकता नहीं है
        return stack.peek()[1];
    }
}
```
