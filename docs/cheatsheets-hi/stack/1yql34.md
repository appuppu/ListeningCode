# Finding the Largest Rectangle in a Histogram — हिस्टोग्राम में बनाई जा सकने वाली सबसे बड़ी आयत का क्षेत्रफल ज्ञात करना

## समस्या का सार

गैर-ऋणात्मक पूर्णांकों की एक सरणी `heights` दी गई है। प्रत्येक तत्व हिस्टोग्राम की एक पट्टी की ऊँचाई को दर्शाता है, और प्रत्येक पट्टी की चौड़ाई 1 है। इस हिस्टोग्राम में बनाई जा सकने वाली **सबसे बड़ी आयत का क्षेत्रफल** ज्ञात करके लौटाना है।

## मूल विचार

प्रत्येक पट्टी को "आयत की ऊँचाई" के रूप में अपनाने पर, यदि यह ज्ञात हो जाए कि वह पट्टी सबसे नीची पट्टी के रूप में बाएँ और दाएँ कहाँ तक विस्तारित हो सकती है, तो क्षेत्रफल की गणना की जा सकती है। एकदिशीय वृद्धिशील स्टैक का उपयोग करने पर, जिस क्षण पट्टी की ऊँचाई घटती है, उसी क्षण स्टैक में मौजूद पट्टी की विस्तार योग्य चौड़ाई O(1) में निर्धारित की जा सकती है।

## विचार प्रक्रिया

1. **प्रत्येक पट्टी को ऊँचाई मानकर आयत पर विचार करना**: किसी भी आयत को "एक निश्चित पट्टी की ऊँचाई को ऊपरी सीमा मानकर, बाएँ और दाएँ की लगातार पट्टियों से बनी हुई" माना जा सकता है। अर्थात्, प्रत्येक पट्टी `heights[i]` के लिए "यह पट्टी सबसे नीची पट्टी बनने वाले अंतराल की चौड़ाई" ज्ञात हो जाए, तो `heights[i] × चौड़ाई` से क्षेत्रफल की गणना की जा सकती है
2. **बाएँ और दाएँ की सीमाओं को कुशलतापूर्वक ज्ञात करना**: प्रत्येक पट्टी के लिए "बाईं ओर पहली बार स्वयं से नीची पट्टी की स्थिति" और "दाईं ओर पहली बार स्वयं से नीची पट्टी की स्थिति" ज्ञात हो जाए, तो विस्तार योग्य चौड़ाई निर्धारित हो जाती है। सभी पट्टियों के लिए इन दोनों सीमाओं को सरलता से खोजने पर O(n²) समय लगेगा, इसलिए स्टैक का उपयोग करके कुशलता प्राप्त की जाती है
3. **एकदिशीय वृद्धिशील स्टैक का उपयोग करना**: स्टैक में पट्टियों के इंडेक्स को ऊँचाई के एकदिशीय वृद्धिशील क्रम में रखा जाता है। जब वर्तमान पट्टी की ऊँचाई स्टैक के शीर्ष से कम होती है, तो स्टैक के शीर्ष की पट्टी के लिए "दाईं सीमा" वर्तमान स्थिति `i` के रूप में निर्धारित हो जाती है
4. **पॉप के समय चौड़ाई की गणना करना**: स्टैक से पट्टी `top` को पॉप करने पर, दाईं सीमा वर्तमान स्थिति `i` होती है, और बाईं सीमा पॉप के बाद स्टैक के शीर्ष की अगली स्थिति होती है। यदि स्टैक खाली है, तो पट्टी बाएँ छोर (इंडेक्स 0) तक विस्तारित हो सकती है, इसलिए चौड़ाई `i` होती है। यदि स्टैक खाली नहीं है, तो चौड़ाई `i - stack.peek() - 1` होती है
5. **संतरी के रूप में अंत में ऊँचाई 0 जोड़ना**: जब सरणी के अंत तक पहुँच जाएँ, तब भी स्टैक में शेष पट्टियों के क्षेत्रफल की गणना करनी होती है। लूप की सीमा `i <= heights.length` रखकर, `i == heights.length` के समय काल्पनिक रूप से ऊँचाई 0 रखने से, स्टैक की सभी पट्टियाँ निश्चित रूप से पॉप हो जाती हैं
6. **अधिकतम क्षेत्रफल को ट्रैक करना**: प्रत्येक पॉप पर `heights[top] × चौड़ाई` की गणना करके, अब तक के अधिकतम मान से तुलना करके अद्यतन किया जाता है। सभी पॉप पूर्ण होने के बाद का अधिकतम मान ही उत्तर है

## पूर्वापेक्षित ज्ञान

### Stack (स्टैक) क्या है

यह एक अंतिम-प्रवेश-प्रथम-निकास (LIFO) डेटा संरचना है। अंतिम में जोड़ा गया तत्व सबसे पहले निकाला जाता है। हिस्टोग्राम की समस्या में, पट्टियों के इंडेक्स को स्टैक में रखकर ऊँचाई की एकदिशीय वृद्धिशीलता बनाए रखने के लिए इसका उपयोग किया जाता है।

```java
Stack<Integer> stack = new Stack<>();  // एक खाली स्टैक बनाना
stack.push(0);       // स्टैक के शीर्ष पर मान 0 जोड़ना
stack.peek();        // स्टैक के शीर्ष के मान को बिना निकाले देखना → 0
stack.pop();         // स्टैक के शीर्ष के मान को निकालकर लौटाना → 0
stack.isEmpty();     // स्टैक खाली है या नहीं, boolean में लौटाना → true
```

### एकदिशीय वृद्धिशील स्टैक (Monotonic Stack) क्या है

यह एक ऐसा स्टैक है जिसमें तत्व हमेशा नीचे से ऊपर की ओर बढ़ते (या बराबर रहते) हुए क्रम में बनाए रखे जाते हैं। नया तत्व जोड़ते समय, यदि स्टैक के शीर्ष से छोटा मान आता है, तो शीर्ष का मान नए मान से अधिक या बराबर होने तक पॉप किया जाता है। पॉप के क्षण में "उस पॉप किए गए तत्व की दाईं सीमा निर्धारित हो गई" ऐसा माना जा सकता है।

```java
// सरणी [2, 1, 5, 6, 2, 3] के लिए एकदिशीय वृद्धिशील स्टैक की कार्यप्रणाली
// i=0: push(0)         → स्टैक: [0]       (ऊँचाई: [2])
// i=1: 1 < 2 इसलिए pop → स्टैक: []        (ऊँचाई 2 की पट्टी की दाईं सीमा i=1 निर्धारित)
//       push(1)         → स्टैक: [1]       (ऊँचाई: [1])
// i=2: push(2)         → स्टैक: [1,2]     (ऊँचाई: [1,5])
// i=3: push(3)         → स्टैक: [1,2,3]   (ऊँचाई: [1,5,6])
// i=4: 2 < 6 इसलिए pop → स्टैक: [1,2]     (ऊँचाई 6 की पट्टी की दाईं सीमा i=4 निर्धारित)
//       2 < 5 इसलिए pop → स्टैक: [1]       (ऊँचाई 5 की पट्टी की दाईं सीमा i=4 निर्धारित)
//       push(4)         → स्टैक: [1,4]     (ऊँचाई: [1,2])
```

### संतरी (Sentinel) क्या है

लूप की अंतिम प्रक्रिया को सरल बनाने के लिए काल्पनिक रूप से जोड़ा गया मान। इस समस्या में सरणी के अंत में ऊँचाई 0 की एक काल्पनिक पट्टी रखी जाती है, जिससे लूप समाप्ति पर स्टैक में शेष सभी पट्टियाँ स्वाभाविक रूप से पॉप हो जाती हैं।

```java
// जब i == heights.length हो, तब वास्तविक सरणी से बाहर होने पर काल्पनिक रूप से ऊँचाई 0 का उपयोग किया जाता है
int h = (i == heights.length) ? 0 : heights[i];
// ऊँचाई 0 किसी भी पट्टी से कम है, इसलिए स्टैक की सभी पट्टियाँ पॉप हो जाती हैं
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — प्रत्येक पट्टी को स्टैक में एक बार पुश और एक बार पॉप किया जाता है, इसलिए कुल मिलाकर O(n) संक्रियाएँ लगती हैं |
| Space | O(n) — स्टैक में अधिकतम n इंडेक्स संग्रहीत किए जाते हैं |

## कोड

```java
// इनपुट: गैर-ऋणात्मक पूर्णांकों की सरणी heights (प्रत्येक तत्व हिस्टोग्राम की पट्टी की ऊँचाई है)
// आउटपुट: हिस्टोग्राम में बनाई जा सकने वाली सबसे बड़ी आयत का क्षेत्रफल int में लौटाना
public int largestRectangleArea(int[] heights) {
    // पट्टियों के इंडेक्स को एकदिशीय वृद्धिशील क्रम में रखने वाला स्टैक
    Stack<Integer> stack = new Stack<>();
    // अब तक मिला सबसे बड़ा क्षेत्रफल दर्ज करने वाला चर
    int maxArea = 0;

    // i <= heights.length रखने से संतरी की प्रक्रिया भी शामिल हो जाती है
    // जब i == heights.length हो, तो संतरी (ऊँचाई 0) के रूप में स्टैक की सभी पट्टियों को पॉप करवाया जाता है
    for (int i = 0; i <= heights.length; i++) {
        // संतरी: सरणी के अंत से आगे जाने पर ऊँचाई 0 का उपयोग किया जाता है। ऊँचाई 0 किसी भी पट्टी से कम है, इसलिए स्टैक की सभी पट्टियों का पॉप होना सुनिश्चित है
        int h = (i == heights.length) ? 0 : heights[i];

        // जब तक वर्तमान ऊँचाई स्टैक के शीर्ष की पट्टी से कम है, तब तक क्षेत्रफल की गणना की जाती है
        // इस शर्त से स्टैक की एकदिशीय वृद्धिशीलता बनी रहती है
        while (!stack.isEmpty() && h < heights[stack.peek()]) {
            // पॉप की गई पट्टी को आयत की ऊँचाई के रूप में अपनाया जाता है। इस पट्टी की दाईं सीमा वर्तमान स्थिति i है
            int top = stack.pop();

            // चौड़ाई की गणना:
            // स्टैक खाली है → top की पट्टी बाएँ छोर (इंडेक्स 0) तक विस्तारित हो सकती है, इसलिए चौड़ाई i है
            // स्टैक खाली नहीं है → stack.peek() वह इंडेक्स है जो top से बाईं ओर और top से नीचा है (बाईं सीमा), इसलिए चौड़ाई i - stack.peek() - 1 है
            int w = stack.isEmpty() ? i : i - stack.peek() - 1;

            // क्षेत्रफल की गणना करके अधिकतम मान को अद्यतन किया जाता है
            maxArea = Math.max(maxArea, heights[top] * w);
        }

        // वर्तमान इंडेक्स को स्टैक में पुश करके एकदिशीय वृद्धिशीलता बनाए रखी जाती है
        stack.push(i);
    }
    // सभी पॉप पूर्ण होने के बाद का अधिकतम मान ही उत्तर है
    return maxArea;
}
```
