# Counting Car Fleets Arriving at a Destination — गंतव्य पर पहुँचने वाली कारों के काफिलों की संख्या ज्ञात करना

## समस्या का सार

एक पूर्णांक `target` (गंतव्य की स्थिति), एक पूर्णांक सरणी `position` (प्रत्येक कार की वर्तमान स्थिति), और एक पूर्णांक सरणी `speed` (प्रत्येक कार की गति) दी गई है। सभी कारें एक ही गंतव्य की ओर चल रही हैं। जब कोई तेज़ कार आगे चल रही धीमी कार तक पहुँच जाती है, तो वह धीमी कार की गति के अनुसार एक काफिले (fleet) के रूप में चलती है। अंत में गंतव्य पर पहुँचने वाले **काफिलों की संख्या** को पूर्णांक के रूप में लौटाना है।

## मूल विचार

गंतव्य के निकट वाली कार से क्रम में प्रसंस्करण करते हुए, प्रत्येक कार के "गंतव्य पर पहुँचने का समय" को Stack से प्रबंधित करें। यदि पीछे की कार का आगमन समय आगे की कार के आगमन समय से कम या बराबर है तो वह विलय कर जाती है, और यदि अधिक है तो एक नया काफिला बनता है — इस प्रकार Stack का अंतिम आकार काफिलों की संख्या होती है।

## विचार प्रक्रिया

1. **काफिला बनने की शर्त को आगमन समय से निर्धारित करना**: पीछे की कार आगे की कार तक पहुँचती है या नहीं, यह गंतव्य पर आगमन समय से तय होता है। यदि पीछे की कार का आगमन समय आगे की कार के आगमन समय से कम या बराबर है, तो वह रास्ते में पकड़ लेती है और एक ही काफिले में शामिल हो जाती है। आगमन समय की गणना `(target - position[i]) / speed[i]` से की जा सकती है
2. **गंतव्य के निकट वाली कार से क्रम में प्रसंस्करण करना**: काफिले के विलय का निर्णय "आगे की कार (गंतव्य के निकट वाली कार) अवरोध बनती है या नहीं" से तय होता है, इसलिए गंतव्य से निकटता के क्रम में सॉर्ट करके प्रसंस्करण करने पर, आगे की कार के आगमन समय को आधार बनाकर पीछे की कारों का क्रमिक मूल्यांकन किया जा सकता है
3. **सॉर्ट का विषय इंडेक्स सरणी है**: position और speed अलग-अलग सरणियाँ हैं, इसलिए एक इंडेक्स सरणी बनाकर उसे `position` के अवरोही क्रम (गंतव्य के निकट क्रम) में सॉर्ट करते हैं। इस प्रकार मूल सरणियों को बिना बदले, संबंधित position और speed को संदर्भित किया जा सकता है
4. **Stack से काफिलों का प्रबंधन करना**: Stack के शीर्ष पर पिछले काफिले का आगमन समय (= उस काफिले की अग्रणी कार का आगमन समय) रहता है। नई कार का आगमन समय Stack के शीर्ष से कम या बराबर होने पर, वह कार पिछले काफिले में विलय हो जाती है इसलिए Stack में नहीं जोड़ी जाती। आगमन समय शीर्ष से अधिक होने पर, एक नया काफिला बनता है इसलिए Stack में push किया जाता है
5. **Stack का आकार उत्तर होता है**: विलय हुई कारें Stack में नहीं जोड़ी जातीं, और केवल नया काफिला बनाने वाली कारें push की जाती हैं, इसलिए अंतिम Stack के तत्वों की संख्या ही काफिलों की संख्या होती है

## पूर्वापेक्षित ज्ञान

### आगमन समय की गणना

जब कार की वर्तमान स्थिति `pos`, गति `speed`, और गंतव्य `target` है, तो आगमन समय `(target - pos) / speed` से प्राप्त होता है। यह मान जितना छोटा होगा, कार उतनी जल्दी पहुँचेगी।

```
उदाहरण: target=12, pos=10, speed=2 के लिए
आगमन समय = (12 - 10) / 2 = 1.0
```

### Integer[] का कस्टम सॉर्ट

प्रिमिटिव प्रकार `int[]` को lambda अभिव्यक्ति से सॉर्ट नहीं किया जा सकता, इसलिए `Integer[]` की इंडेक्स सरणी बनाकर `Arrays.sort` में Comparator पास करके सॉर्ट करते हैं।

```java
Integer[] idx = new Integer[n];
for (int i = 0; i < n; i++) idx[i] = i;
// pos के अवरोही क्रम (गंतव्य के निकट क्रम) में इंडेक्स को सॉर्ट करना
Arrays.sort(idx, (a, b) -> pos[b] - pos[a]);
```

### Stack क्या है

यह अंतिम-प्रवेश-प्रथम-निकास (LIFO) डेटा संरचना है। `push` से तत्व रखा जाता है, `peek` से सबसे ऊपर के तत्व को देखा जाता है, और `pop` से निकाला जाता है। यहाँ Stack के शीर्ष पर "पिछले काफिले का आगमन समय" रखा जाता है और विलय निर्णय के आधार के रूप में उपयोग किया जाता है।

```java
Stack<Double> stack = new Stack<>();  // एक खाली Stack बनाना
stack.push(3.0);    // तत्व 3.0 को Stack के सबसे ऊपर रखना
stack.peek();        // सबसे ऊपर के तत्व को बिना निकाले देखना → 3.0
stack.isEmpty();     // Stack खाली है या नहीं यह जाँचना → false
stack.size();        // Stack में तत्वों की संख्या लौटाना → 1
```

## जटिलता

| | मान |
|---|---|
| Time | O(n log n) — इंडेक्स सरणी को सॉर्ट करने में O(n log n) और उसके बाद के स्कैन में O(n) लगता है |
| Space | O(n) — इंडेक्स सरणी और Stack में प्रत्येक में अधिकतम n तत्व संग्रहीत होते हैं |

## कोड

```java
// इनपुट: पूर्णांक target (गंतव्य की स्थिति), पूर्णांक सरणी pos (प्रत्येक कार की स्थिति), पूर्णांक सरणी speed (प्रत्येक कार की गति)
// आउटपुट: गंतव्य पर पहुँचने वाले काफिलों की संख्या पूर्णांक के रूप में लौटाना
public int carFleet(int target, int[] pos, int[] speed) {
    // कारों की संख्या प्राप्त करना
    int n = pos.length;

    // Integer[] प्रकार की इंडेक्स सरणी बनाना और 0 से n-1 तक के मानों से आरंभ करना
    // इंडेक्स सरणी को सॉर्ट करने से मूल सरणी को बनाए रखते हुए क्रम बदला जा सकता है
    Integer[] idx = new Integer[n];
    for (int i = 0; i < n; i++) {
        idx[i] = i;
    }

    // इंडेक्स सरणी को position के अवरोही क्रम (गंतव्य के निकट क्रम) में सॉर्ट करना
    // गंतव्य के निकट वाली कार से प्रसंस्करण करने पर, आगे की कार को आधार बनाकर विलय निर्णय संभव होता है
    Arrays.sort(idx, (a, b) -> pos[b] - pos[a]);

    // प्रत्येक काफिले का आगमन समय संग्रहीत करने के लिए Stack
    // Stack का शीर्ष "पिछले निर्धारित काफिले का आगमन समय" दर्शाता है
    Stack<Double> stack = new Stack<>();

    for (int i : idx) {
        // इस कार का गंतव्य पर आगमन समय गणना करना
        // double में कास्ट न करने पर पूर्णांक विभाजन होगा और दशमलव भाग खो जाएगा
        double time = (double) (target - pos[i]) / speed[i];

        // यदि आगमन समय Stack के शीर्ष से कम या बराबर है, तो यह कार आगे के काफिले तक पहुँच जाती है इसलिए विलय होता है
        // continue से Stack में जोड़ना छोड़कर, अगली कार के प्रसंस्करण पर जाना
        if (!stack.isEmpty() && time <= stack.peek()) {
            continue;
        }

        // यदि Stack खाली है, या time शीर्ष से अधिक है, तो आगे के काफिले तक नहीं पहुँच सकती
        // नया काफिला बनता है इसलिए Stack में आगमन समय push करना
        stack.push(time);
    }

    // Stack में प्रत्येक काफिले का आगमन समय एक-एक करके संग्रहीत है, इसलिए आकार काफिलों की संख्या के बराबर होता है
    return stack.size();
}
```
