# Checking if Parentheses Are Balanced — यह जाँचना कि कोष्ठक सही ढंग से संतुलित हैं या नहीं

## समस्या का सार

`(`、`)`、`{`、`}`、`[`、`]` इन 6 प्रकार के कोष्ठकों से बनी एक स्ट्रिंग दी गई है। यह निर्धारित करना है कि सभी खुलने वाले कोष्ठकों के लिए उनके संगत बंद होने वाले कोष्ठक **सही क्रम** में मौजूद हैं या नहीं, और `true` या `false` लौटाना है।

## मूल विचार

कोष्ठकों का मिलान "जो अंत में खुला उसे सबसे पहले बंद करो" अर्थात Last In, First Out (LIFO) की संरचना रखता है। यह गुण स्टैक के समान है, इसलिए खुलने वाले कोष्ठकों को स्टैक में डालकर और बंद होने वाला कोष्ठक आने पर स्टैक के शीर्ष से मिलान करके सही संगतता की जाँच की जा सकती है।

## विचार प्रक्रिया

1. **कोष्ठकों के मिलान में क्रम महत्वपूर्ण है**: `([)]` में प्रत्येक कोष्ठक की संख्या सही है लेकिन क्रम गलत है। अर्थात "सबसे भीतरी कोष्ठक को पहले बंद करो" यह नियम है। यह Last In, First Out (LIFO) संरचना है और इसे स्टैक से स्वाभाविक रूप से व्यक्त किया जा सकता है
2. **खुलने वाले कोष्ठकों को स्टैक में डालें**: स्ट्रिंग को आरंभ से एक-एक अक्षर स्कैन करें, और खुलने वाला कोष्ठक (`(`、`{`、`[`) मिलने पर उसे स्टैक में push करें। स्टैक के शीर्ष पर हमेशा "सबसे हाल में खोला गया, अभी तक बंद न हुआ कोष्ठक" होता है
3. **बंद होने वाला कोष्ठक आने पर स्टैक के शीर्ष से मिलान करें**: बंद होने वाला कोष्ठक मिलने पर, स्टैक से pop किया गया खुलने वाला कोष्ठक संगत प्रकार का है या नहीं यह जाँचें। यदि संगत नहीं है तो स्ट्रिंग अमान्य है
4. **स्टैक खाली होने पर बंद कोष्ठक आए तो अमान्य है**: pop करने से पहले यदि स्टैक खाली है, तो इसका अर्थ है कि संगत खुलने वाला कोष्ठक मौजूद नहीं है, इसलिए `false` लौटाएँ
5. **स्कैन पूरा होने के बाद यदि स्टैक खाली है तो स्ट्रिंग वैध है**: सभी अक्षरों को प्रोसेस करने के बाद, यदि स्टैक में खुलने वाले कोष्ठक शेष हैं तो बंद न हुए कोष्ठक मौजूद हैं। यदि स्टैक खाली है तो सभी कोष्ठक सही ढंग से संगत हैं

## पूर्वापेक्षित ज्ञान

### Stack क्या है

Last In, First Out (LIFO) डेटा संरचना है। अंत में जोड़ा गया तत्व सबसे पहले निकाला जाता है। कोष्ठकों के मिलान की जाँच जैसी स्थितियों में, जहाँ "सबसे हाल के" तत्व से क्रमशः प्रोसेस करना होता है, वहाँ इसका उपयोग किया जाता है।

```java
Stack<Character> stack = new Stack<>();  // खाली स्टैक बनाएँ
stack.push('(');      // स्टैक के शीर्ष पर '(' जोड़ें
stack.peek();         // स्टैक के शीर्ष के तत्व को निकाले बिना देखें → '('
stack.pop();          // स्टैक के शीर्ष के तत्व को निकालकर लौटाएँ → '('
stack.isEmpty();      // स्टैक खाली है या नहीं boolean में लौटाएँ → true
```

### कोष्ठकों की संगतता

3 प्रकार के कोष्ठकों में प्रत्येक के खुलने और बंद होने का जोड़ा होता है। बंद होने वाला कोष्ठक आने पर, स्टैक के शीर्ष पर संगत खुलने वाला कोष्ठक है या नहीं यह जाँचना आवश्यक है।

```
')' का संगत खुलने वाला कोष्ठक '(' है
'}' का संगत खुलने वाला कोष्ठक '{' है
']' का संगत खुलने वाला कोष्ठक '[' है
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n) — स्ट्रिंग को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(n) — स्टैक में अधिकतम n खुलने वाले कोष्ठक संग्रहीत होते हैं |

## कोड

```java
// इनपुट: केवल कोष्ठकों से बनी स्ट्रिंग s
// आउटपुट: सभी कोष्ठक सही ढंग से संगत हैं तो true, अन्यथा false
public boolean isValid(String s) {
    // "अभी तक बंद न हुए खुलने वाले कोष्ठकों" को रखने वाला स्टैक
    // स्टैक के शीर्ष पर सबसे हाल में खोला गया कोष्ठक होता है
    Stack<Character> stack = new Stack<>();

    // स्ट्रिंग को आरंभ से एक-एक अक्षर स्कैन करें। toCharArray() स्ट्रिंग को char ऐरे में बदलता है
    for (char c : s.toCharArray()) {
        // खुलने वाला कोष्ठक है तो स्टैक में डालें। संगत बंद कोष्ठक आने तक यह स्टैक में रहेगा
        if (c == '(' || c == '{' || c == '[') {
            stack.push(c);
        } else {
            // बंद कोष्ठक है लेकिन स्टैक खाली है, तो संगत खुलने वाला कोष्ठक मौजूद नहीं है इसलिए अमान्य है
            if (stack.isEmpty()) return false;

            // स्टैक के शीर्ष से "सबसे हाल में खोला गया, अभी तक बंद न हुआ कोष्ठक" निकालें
            char top = stack.pop();

            // बंद कोष्ठक और खुले कोष्ठक का प्रकार संगत नहीं है तो अमान्य है
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
            if (c == ')' && top != '(') return false;
        }
    }

    // स्टैक खाली है तो सभी कोष्ठक सही ढंग से संगत हैं
    // स्टैक में तत्व शेष हैं तो बंद न हुए खुले कोष्ठक हैं इसलिए false
    return stack.isEmpty();
}
```
