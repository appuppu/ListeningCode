# Finding How Many Days Until a Warmer Temperature — प्रत्येक दिन से अगले गर्म दिन तक के दिनों की संख्या ज्ञात करना

## समस्या का सार

एक पूर्णांक सरणी `temperatures` दी गई है। प्रत्येक दिन के लिए, उस दिन से अधिक तापमान वाला **भविष्य का दिन** कितने दिन बाद आता है, इसकी गणना करें और परिणाम को सरणी के रूप में लौटाएं। यदि भविष्य में अधिक तापमान वाला कोई दिन मौजूद नहीं है, तो उस दिन का उत्तर `0` होगा।

## मूल विचार

एक monotonic decreasing stack में इंडेक्स को push करते जाएं, तो स्टैक में केवल वे दिन बचे रहते हैं "जिनका अभी तक कोई गर्म दिन नहीं मिला है"। जब नए दिन का तापमान स्टैक के शीर्ष पर मौजूद दिन के तापमान से अधिक होता है, तो उन इंडेक्स का अंतर सीधे "प्रतीक्षा दिनों की संख्या" बन जाता है।

## विचार प्रक्रिया

1. **प्रत्येक दिन के लिए "अगले गर्म दिन" को खोजना आवश्यक है**: सरल तरीके से सोचें तो प्रत्येक दिन से दाईं ओर रैखिक खोज करनी होगी, लेकिन इससे O(n²) हो जाएगा। प्रत्येक दिन की "अनसुलझी स्थिति" को कुशलतापूर्वक प्रबंधित करने की व्यवस्था आवश्यक है
2. **"जिन दिनों का उत्तर अभी तय नहीं हुआ" उन्हें ट्रैक करना है**: सरणी को बाएं से स्कैन करते समय, वर्तमान दिन से अधिक तापमान वाला भविष्य का दिन अभी तक नहीं मिला है ऐसे दिनों को "अनसुलझे दिन" के रूप में रखें, तो नया दिन आने पर उन्हें एक साथ हल किया जा सकता है
3. **अनसुलझे दिनों को स्टैक से प्रबंधित करना**: स्टैक में इंडेक्स push करते जाएं। जब नए दिन का तापमान स्टैक के शीर्ष पर मौजूद दिन के तापमान से अधिक हो, तो उस अनसुलझे दिन का उत्तर निश्चित हो जाता है। स्टैक हमेशा ऊपर से नीचे की ओर monotonic decreasing रहता है (कम तापमान ऊपर रहता है)
4. **उत्तर इंडेक्स के अंतर से प्राप्त होता है**: जब अनसुलझा दिन `j` वर्तमान दिन `i` द्वारा हल होता है, तो प्रतीक्षा दिनों की संख्या `i - j` होती है। इस अंतर को परिणाम सरणी के `j`वें स्थान पर संग्रहित किया जाता है
5. **प्रत्येक तत्व अधिकतम एक बार push और pop होता है**: स्टैक में push प्रत्येक तत्व के लिए एक बार होता है, और pop भी अधिकतम एक बार होता है, इसलिए while लूप सहित कुल प्रसंस्करण O(n) में पूर्ण होता है

## पूर्वापेक्षित ज्ञान

### Stack (स्टैक) क्या है

यह Last-In-First-Out (LIFO) डेटा संरचना है। सबसे अंत में जोड़ा गया तत्व सबसे पहले निकाला जाता है। Java में `Stack<Integer>` क्लास का उपयोग किया जाता है।

```java
Stack<Integer> stack = new Stack<>();  // एक खाली स्टैक बनाएं
stack.push(5);          // स्टैक के शीर्ष पर 5 जोड़ें
stack.peek();           // स्टैक के शीर्ष तत्व को निकाले बिना लौटाएं → 5
stack.pop();            // स्टैक के शीर्ष तत्व को निकालकर लौटाएं → 5
stack.isEmpty();        // स्टैक खाली है या नहीं boolean में लौटाएं → true
```

### Monotonic Stack (एकदिशीय स्टैक) क्या है

यह एक ऐसा स्टैक है जिसमें तत्व हमेशा monotonic increasing या monotonic decreasing क्रम में बने रहें। इस समस्या में **monotonic decreasing stack** का उपयोग किया जाता है। नया तत्व जोड़ने से पहले, स्टैक के क्रम को तोड़ने वाले सभी तत्वों को pop करके monotonicity बनाए रखी जाती है। "अगला बड़ा (या छोटा) तत्व खोजने" के पैटर्न में इसका उपयोग किया जा सकता है।

```java
// Monotonic decreasing stack का मूल पैटर्न
// स्टैक के अंदर तापमान नीचे से ऊपर की ओर घटता रहता है
// उदाहरण: स्टैक तल[75, 71, 69]शीर्ष ← तापमान घट रहा है
// यहां 72 आने पर, 69 और 71 को pop करके हल किया जाता है, और [75, 72] बचता है
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — प्रत्येक तत्व स्टैक में अधिकतम एक बार push और एक बार pop होता है, इसलिए कुल O(n) है |
| Space | O(n) — स्टैक में अधिकतम n इंडेक्स संग्रहित होते हैं |

## कोड

```java
// इनपुट: पूर्णांक सरणी temperatures (प्रत्येक दिन का तापमान)
// आउटपुट: प्रत्येक दिन से अगले गर्म दिन तक के दिनों की संख्या संग्रहित int[] लौटाएं
public int[] dailyTemperatures(int[] temperatures) {
    // परिणाम सरणी बनाएं (Java में int[] का प्रारंभिक मान 0 होता है, इसलिए भविष्य में गर्म दिन न होने पर उत्तर 0 डिफ़ॉल्ट रूप से सेट होता है)
    int[] result = new int[temperatures.length];
    // अभी तक गर्म दिन न मिले दिनों के इंडेक्स संग्रहित करने वाला स्टैक
    // तापमान के मान के बजाय इंडेक्स संग्रहित करने का कारण: प्रतीक्षा दिनों की गणना के लिए इंडेक्स का अंतर आवश्यक है, और इंडेक्स से तापमान temperatures[index] द्वारा प्राप्त किया जा सकता है
    Stack<Integer> indexStack = new Stack<>();

    // सरणी को इंडेक्स i = 0 से अंत तक एक-एक करके स्कैन करें
    for (int i = 0; i < temperatures.length; i++) {
        // जब तक वर्तमान तापमान स्टैक के शीर्ष दिन के तापमान से अधिक है, अनसुलझे दिनों को हल करें
        // शर्त: स्टैक खाली नहीं है और वर्तमान तापमान > स्टैक शीर्ष के इंडेक्स का तापमान
        while (!indexStack.isEmpty() && temperatures[i] > temperatures[indexStack.peek()]) {
            // स्टैक के शीर्ष इंडेक्स को निकालें
            int stackTopIndex = indexStack.pop();
            // प्रतीक्षा दिनों की संख्या = वर्तमान इंडेक्स - प्रतीक्षारत दिन का इंडेक्स
            result[stackTopIndex] = i - stackTopIndex;
        }
        // while लूप समाप्त होने के बाद (स्टैक खाली है, या स्टैक शीर्ष का तापमान वर्तमान तापमान के बराबर या अधिक है), वर्तमान इंडेक्स को स्टैक में जोड़ें
        // इस बिंदु पर स्टैक में monotonic decreasing क्रम बना रहता है
        indexStack.push(i);
    }

    // स्टैक में शेष इंडेक्स वे दिन हैं "जिनके भविष्य में कोई गर्म दिन नहीं था"
    // इन दिनों का परिणाम प्रारंभिक मान 0 ही रहता है, इसलिए अतिरिक्त प्रसंस्करण आवश्यक नहीं है
    return result;
}
```
