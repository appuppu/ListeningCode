# Evaluating an Expression in Reverse Polish Notation — रिवर्स पोलिश नोटेशन में अंकगणितीय व्यंजक का मूल्यांकन करना

## समस्या का सार

स्ट्रिंग की एक सरणी `tokens` रिवर्स पोलिश नोटेशन (RPN) में एक अंकगणितीय व्यंजक के रूप में दी गई है। इस व्यंजक का मूल्यांकन करें और परिणाम को पूर्णांक के रूप में लौटाएँ। मान्य ऑपरेटर `+`, `-`, `*`, `/` ये 4 हैं, और प्रत्येक ऑपरैंड एक पूर्णांक या कोई अन्य उप-व्यंजक है। भाग को शून्य की दिशा में छोटा किया जाता है। उदाहरण: `["2","1","+","3","*"]` → `((2+1)*3)` → `9`।

## मूल विचार

रिवर्स पोलिश नोटेशन में ऑपरेटर की प्राथमिकता या कोष्ठकों की हैंडलिंग की आवश्यकता नहीं होती। टोकनों को बाएँ से दाएँ स्कैन करते हुए स्टैक में संख्याएँ डालें, और जब कोई ऑपरेटर आए तो शीर्ष के 2 मान निकालकर गणना का परिणाम वापस डाल दें — बस इतने से पूरे व्यंजक का सही मूल्यांकन हो जाता है।

## विचार प्रक्रिया

1. **RPN की विशेषता को समझना**: रिवर्स पोलिश नोटेशन में ऑपरेटर अपने ठीक पहले के दो ऑपरैंड पर कार्य करता है। अर्थात्, जब ऑपरेटर प्रकट होता है, तब उसके लिए लक्षित दोनों ऑपरैंड पहले से ही निर्धारित होते हैं। इस विशेषता से, "अंत में जोड़ा गया तत्व सबसे पहले निकालना" — LIFO डेटा संरचना अर्थात् स्टैक उपयुक्त है
2. **टोकन संख्या है या ऑपरेटर, इसके अनुसार प्रसंस्करण को विभाजित करना**: प्रत्येक टोकन को क्रम से देखें — यदि संख्या है तो स्टैक में डालें, यदि ऑपरेटर है तो गणना करें। केवल इन दो संक्रियाओं से पूरे व्यंजक का मूल्यांकन किया जा सकता है
3. **ऑपरेटर प्रसंस्करण में ऑपरैंड के क्रम पर ध्यान देना**: स्टैक से पहले pop किया गया मान दायाँ ऑपरैंड (`a`) होता है, और अगला pop किया गया मान बायाँ ऑपरैंड (`b`) होता है। गणना `b ऑपरेटर a` के क्रम में की जाती है। यदि यह क्रम गलत हो जाए, तो घटाव और भाग में गलत परिणाम आता है
4. **गणना के परिणाम को स्टैक में वापस डालना**: गणना का परिणाम स्टैक में push करने से वह परिणाम बाद की गणनाओं के ऑपरैंड के रूप में उपयोग होता है। इससे नेस्टेड उप-व्यंजक भी स्वाभाविक रूप से संसाधित होते हैं
5. **अंतिम परिणाम स्टैक में केवल एक ही शेष रहता है**: यदि RPN व्यंजक मान्य है, तो सभी टोकनों के प्रसंस्करण के बाद स्टैक में गणना का केवल एक ही परिणाम शेष रहता है। इस मान को pop करके लौटाएँ

## पूर्वापेक्षित ज्ञान

### Stack क्या है

लास्ट-इन-फर्स्ट-आउट (LIFO) डेटा संरचना। अंत में जोड़ा गया तत्व सबसे पहले निकाला जा सकता है। तत्व जोड़ना (push) और निकालना (pop) दोनों O(1) में किए जा सकते हैं।

```java
Stack<Integer> stack = new Stack<>();  // खाली स्टैक बनाना
stack.push(5);     // स्टैक के शीर्ष पर 5 डालना → [5]
stack.push(3);     // स्टैक के शीर्ष पर 3 डालना → [5, 3]
stack.pop();       // शीर्ष के तत्व को निकालकर लौटाना → 3, स्टैक है [5]
stack.pop();       // शीर्ष के तत्व को निकालकर लौटाना → 5, स्टैक है []
```

### रिवर्स पोलिश नोटेशन (RPN) क्या है

ऑपरेटर को ऑपरैंड के बाद रखने वाली संकेतन पद्धति। सामान्य इन्फ़िक्स नोटेशन `(2 + 1) * 3` को RPN में `2 1 + 3 *` लिखा जाता है। कोष्ठक की आवश्यकता नहीं होती, और बाएँ से दाएँ क्रम में प्रसंस्करण करने मात्र से सही मूल्यांकन हो जाता है।

```
इन्फ़िक्स नोटेशन:  (2 + 1) * 3
RPN:                2 1 + 3 *
मूल्यांकन प्रक्रिया:  2 1 + → 3, फिर 3 3 * → 9
```

### Integer.parseInt क्या है

स्ट्रिंग को पूर्णांक में बदलने वाला Java का स्टैटिक मेथड। ऋणात्मक संख्या वाली स्ट्रिंग (उदा: `"-3"`) को भी सही ढंग से बदला जा सकता है।

```java
Integer.parseInt("42");    // → 42
Integer.parseInt("-3");    // → -3
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी के टोकनों को केवल एक बार स्कैन करना पर्याप्त है |
| Space | O(n) — स्टैक में अधिकतम n तत्व संग्रहीत होते हैं |

## कोड

```java
// इनपुट: रिवर्स पोलिश नोटेशन में अंकगणितीय व्यंजक को दर्शाने वाली स्ट्रिंग सरणी tokens
// आउटपुट: व्यंजक के मूल्यांकन का परिणाम पूर्णांक के रूप में लौटाना
public int evalRPN(String[] tokens) {
    // संख्यात्मक ऑपरैंड और मध्यवर्ती गणना परिणामों को अस्थायी रूप से रखने के लिए स्टैक
    Stack<Integer> stack = new Stack<>();

    // सरणी tokens को आरंभ से अंत तक एक-एक करके स्कैन करना
    for (String token : tokens) {
        // वर्तमान टोकन ऑपरेटर (+, -, *, / में से कोई) है या नहीं, यह निर्धारित करना
        switch (token) {
            case "+": {
                int a = stack.pop();  // पहला pop → दायाँ ऑपरैंड
                int b = stack.pop();  // दूसरा pop → बायाँ ऑपरैंड
                // परिणाम को push करने से वह बाद की गणनाओं के ऑपरैंड के रूप में उपयोग होता है
                stack.push(b + a);
                break;
            }
            case "-": {
                int a = stack.pop();
                int b = stack.pop();
                // ध्यान दें: pop का क्रम उलटा है इसलिए अवश्य b - a के क्रम में करें। a - b करने से परिणाम उलट जाता है
                stack.push(b - a);
                break;
            }
            case "*": {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(b * a);
                break;
            }
            case "/": {
                int a = stack.pop();
                int b = stack.pop();
                // Java का पूर्णांक भाग स्वचालित रूप से शून्य की दिशा में छोटा करता है, इसलिए विशेष हैंडलिंग की आवश्यकता नहीं है
                // ध्यान दें: pop का क्रम उलटा है इसलिए अवश्य b / a के क्रम में करें। a / b करने से परिणाम उलट जाता है
                stack.push(b / a);
                break;
            }
            default: {
                // संख्यात्मक टोकन को पूर्णांक में बदलकर स्टैक में डालना
                // ऋणात्मक संख्या (उदा: "-3") को भी parseInt सही ढंग से संसाधित करता है
                stack.push(Integer.parseInt(token));
            }
        }
    }

    // यदि RPN व्यंजक मान्य है, तो सभी टोकनों के प्रसंस्करण के बाद स्टैक में केवल एक ही परिणाम शेष रहता है
    return stack.pop();
}
```
