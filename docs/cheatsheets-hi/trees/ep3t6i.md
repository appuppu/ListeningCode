# Viewing a Binary Tree From the Right Side — बाइनरी ट्री को दाईं ओर से देखने पर दिखाई देने वाले नोड्स के मान लौटाना

## समस्या का सार

एक बाइनरी ट्री का `root` दिया गया है। जब आप पेड़ को दाईं ओर से देखते हैं, तो प्रत्येक गहराई पर केवल सबसे दाईं ओर का नोड दिखाई देता है। उन नोड्स के मानों को ऊपर (root) से नीचे तक क्रम में एक `List<Integer>` में लौटाना है।

## मूल विचार

DFS में दाएँ बच्चे को पहले विज़िट करने पर, प्रत्येक गहराई पर सबसे पहले पहुँचने वाला नोड हमेशा "दाईं ओर से दिखाई देने वाला नोड" होता है। गहराई और परिणाम सूची के आकार की तुलना करके यह निर्धारित किया जा सकता है कि वह नोड उस गहराई पर पहली बार विज़िट किया गया है या नहीं।

## विचार प्रक्रिया

1. **दाईं ओर से दिखाई देने वाला नोड क्या है**: प्रत्येक गहराई पर सबसे दाईं ओर स्थित नोड "दाईं ओर से दिखाई देने वाला नोड" होता है। अर्थात, यह समस्या प्रत्येक गहराई से एक-एक नोड चुनने की समस्या में बदल जाती है
2. **दाएँ बच्चे को पहले विज़िट करने वाले DFS पर विचार करना**: DFS से पेड़ को ट्रैवर्स करते समय, यदि दाएँ बच्चे को बाएँ बच्चे से पहले रिकर्सिव कॉल किया जाए, तो प्रत्येक गहराई पर सबसे दाएँ नोड पर सबसे पहले पहुँचा जाता है। इस गुण का उपयोग करके, प्रत्येक गहराई पर पहली बार विज़िट किए गए नोड को ही रिकॉर्ड करना पर्याप्त है
3. **"प्रत्येक गहराई पर पहली विज़िट" कैसे निर्धारित करें**: परिणाम सूची `result` का आकार "अब तक रिकॉर्ड की गई गहराइयों की संख्या" को दर्शाता है। यदि वर्तमान `depth` का मान `result.size()` के बराबर है, तो इसका अर्थ है कि उस गहराई का नोड अभी तक रिकॉर्ड नहीं किया गया है। केवल इस शर्त के पूरा होने पर `result.add(node.val)` किया जाता है
4. **रिकर्शन की संरचना**: प्रत्येक नोड पर "यदि गहराई नई है तो मान रिकॉर्ड करना" → "दाएँ बच्चे पर रिकर्शन" → "बाएँ बच्चे पर रिकर्शन" के क्रम में प्रोसेसिंग की जाती है। दाएँ बच्चे को पहले विज़िट करने के कारण, दाईं ओर के नोड प्रत्येक गहराई पर प्राथमिकता से रिकॉर्ड होते हैं
5. **बेस केस**: जब नोड `null` हो, तो बिना कुछ किए `return` किया जाता है। इससे लीफ नोड से आगे की रिकर्शन स्वाभाविक रूप से समाप्त हो जाती है
6. **अंतिम रिटर्न वैल्यू**: DFS पूरा होने के बाद, `result` सूची में गहराई 0 से क्रम में दाईं ओर से दिखाई देने वाले नोड्स के मान संग्रहीत होते हैं। इस सूची को वैसे ही लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### DFS (डेप्थ-फर्स्ट सर्च) क्या है

यह पेड़ या ग्राफ को ट्रैवर्स करने वाला एक एल्गोरिदम है। किसी नोड से शुरू करके, जितना गहरा जा सकते हैं उतना आगे बढ़ते हैं, फिर वापस लौटते हैं (बैकट्रैक करते हैं)। रिकर्शन का उपयोग करके इसे स्वाभाविक रूप से लागू किया जा सकता है।

```java
void dfs(TreeNode node) {
    if (node == null) return;  // बेस केस: null हो तो कुछ न करें
    // node पर प्रोसेसिंग यहाँ की जाती है
    dfs(node.left);   // बाएँ बच्चे को रिकर्सिव रूप से ट्रैवर्स करना
    dfs(node.right);  // दाएँ बच्चे को रिकर्सिव रूप से ट्रैवर्स करना
}
```

### List का size() और add()

`List` एक परिवर्तनीय लंबाई की सरणी है। `size()` वर्तमान तत्वों की संख्या लौटाता है, और `add()` अंत में एक तत्व जोड़ता है। तत्व जोड़े जाने के क्रम में इंडेक्स 0, 1, 2... पर क्रमबद्ध होते हैं।

```java
List<Integer> list = new ArrayList<>();  // खाली सूची बनाना
list.size();      // वर्तमान तत्वों की संख्या लौटाता है → 0
list.add(5);      // अंत में 5 जोड़ना → [5]
list.add(3);      // अंत में 3 जोड़ना → [5, 3]
list.size();      // → 2
```

### depth (गहराई) क्या है

पेड़ के रूट से उस नोड तक की कोरों (edges) की संख्या को गहराई कहते हैं। रूट की गहराई 0 होती है, रूट के बच्चों की गहराई 1 होती है, और पोतों की गहराई 2 होती है। रिकर्सिव कॉल में `depth + 1` पास करके प्रत्येक नोड की गहराई को ट्रैक किया जा सकता है।

## जटिलता

| | मान |
|---|---|
| Time | O(n) — सभी नोड्स को एक-एक बार विज़िट किया जाता है |
| Space | O(h) — रिकर्शन के कॉल स्टैक के लिए पेड़ की ऊँचाई जितनी जगह आवश्यक है (h पेड़ की ऊँचाई है) |

## कोड

```java
// इनपुट: बाइनरी ट्री का रूट नोड root
// आउटपुट: दाईं ओर से दिखाई देने वाले नोड्स के मान ऊपर से नीचे क्रम में संग्रहीत List<Integer>
List<Integer> rightSideView(TreeNode root) {
    // प्रत्येक गहराई के सबसे दाएँ नोड के मान को संग्रहीत करने वाली सूची
    // सूची का इंडेक्स गहराई से मेल खाता है (index 0 = depth 0)
    List<Integer> result = new ArrayList<>();
    dfs(root, 0, result);
    // DFS पूरा होने के बाद, result में गहराई 0 से क्रम में दाईं ओर से दिखाई देने वाले नोड्स के मान संग्रहीत हैं
    return result;
}

void dfs(TreeNode node, int depth,
         List<Integer> result) {
    // बेस केस: null हो तो कुछ न करें (लीफ नोड के आगे अस्तित्वहीन बच्चे के लिए रिकर्शन समाप्त होती है)
    if (node == null) return;

    // depth == result.size() हो तो, इस गहराई का नोड अभी तक रिकॉर्ड नहीं हुआ है
    // result.size() "अब तक रिकॉर्ड की गई गहराइयों की संख्या" को दर्शाता है
    if (depth == result.size()) {
        // दाएँ बच्चे को पहले विज़िट करने वाले DFS में, प्रत्येक गहराई पर सबसे पहले पहुँचने वाला नोड हमेशा सबसे दाईं ओर का नोड होता है
        result.add(node.val);
    }

    // दाएँ बच्चे को पहले विज़िट करने से, प्रत्येक गहराई का सबसे दाएँ नोड पहले रिकॉर्ड होता है
    // यही इस एल्गोरिदम का मूल है: दाएँ → बाएँ के क्रम में विज़िट करना
    dfs(node.right, depth + 1, result);
    // जिस गहराई पर दाएँ बच्चा मौजूद नहीं है, वहाँ बाएँ बच्चा "उस गहराई पर पहली बार विज़िट किया गया नोड" बनता है और सही ढंग से रिकॉर्ड होता है
    dfs(node.left, depth + 1, result);
}
```
