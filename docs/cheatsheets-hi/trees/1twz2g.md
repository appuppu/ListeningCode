# Serializing and Deserializing a Binary Tree — बाइनरी ट्री को स्ट्रिंग में बदलना और मूल ट्री संरचना को पुनर्स्थापित करना

## समस्या का सार

बाइनरी ट्री को स्ट्रिंग में सीरियलाइज़ करने और उस स्ट्रिंग से मूल बाइनरी ट्री को डीसीरियलाइज़ करने के लिए एक एल्गोरिदम डिज़ाइन करना है। राउंड-ट्रिप लॉसलेस होना चाहिए — पुनर्स्थापित ट्री मूल ट्री के साथ पूर्णतः समान होना चाहिए।

## मूल विचार

Preorder (पूर्व-क्रम) ट्रैवर्सल से ट्री को सीरियलाइज़ करने पर, प्रत्येक नोड की "बायाँ चाइल्ड → दायाँ चाइल्ड" संरचना पुनरावर्ती रूप से रिकॉर्ड होती है। null को सेंटिनल मान के रूप में स्पष्ट रूप से रिकॉर्ड कर देने पर, डीसीरियलाइज़ेशन के समय टोकन को आरंभ से क्रमशः उपभोग करने मात्र से, पुनरावर्ती रूप से मूल ट्री संरचना को अद्वितीय रूप से पुनर्स्थापित किया जा सकता है।

## विचार प्रक्रिया

1. **ट्री संरचना को अद्वितीय रूप से पुनर्स्थापित करने के लिए क्या आवश्यक है**: बाइनरी ट्री की संरचना को अद्वितीय रूप से निर्धारित करने के लिए, प्रत्येक नोड के चाइल्ड मौजूद हैं या नहीं इसकी जानकारी आवश्यक है। null की स्थिति को स्पष्ट रूप से रिकॉर्ड करने पर, केवल एक ट्रैवर्सल क्रम से ट्री संरचना को अद्वितीय रूप से पुनर्निर्मित किया जा सकता है
2. **Preorder ट्रैवर्सल उपयुक्त क्यों है**: Preorder "रूट → बायाँ सबट्री → दायाँ सबट्री" के क्रम में विज़िट करता है। रूट सबसे पहले आता है, इसलिए डीसीरियलाइज़ेशन के समय टोकन को आरंभ से उपभोग करते हुए पुनरावर्ती रूप से नोड उत्पन्न किए जा सकते हैं। ट्रैवर्सल क्रम और नोड उत्पादन क्रम मेल खाते हैं, इसलिए कार्यान्वयन स्वाभाविक हो जाता है
3. **null को सेंटिनल मान के रूप में रिकॉर्ड करना**: जब नोड null होता है तब `"null"` स्ट्रिंग रिकॉर्ड की जाती है। इससे डीसीरियलाइज़ेशन के समय "यहाँ सबट्री समाप्त होता है" इस सीमा का निर्धारण किया जा सकता है। सेंटिनल के बिना सबट्री के अंत को पहचानना संभव नहीं है
4. **सीरियलाइज़ेशन का प्रारूप**: प्रत्येक नोड के मान को कॉमा से अलग करके जोड़ा जाता है। प्रारूप `"1,2,null,null,3,4,null,null,5,null,null"` जैसा होता है। कॉमा से split करने पर टोकन की ऐरे प्राप्त होती है
5. **डीसीरियलाइज़ेशन पुनरावृत्ति द्वारा टोकन उपभोग करता है**: टोकन की सूची के आरंभ से एक-एक करके poll (निकालना) किया जाता है। निकाला गया मान `"null"` होने पर null लौटाया जाता है, अन्यथा नोड उत्पन्न करके बाएँ चाइल्ड और दाएँ चाइल्ड को पुनरावर्ती रूप से निर्मित किया जाता है। LinkedList का उपयोग करने पर आरंभ से poll O(1) में होता है
6. **पुनरावृत्ति का क्रम Preorder से मेल खाता है**: सीरियलाइज़ेशन के समय Preorder क्रम (रूट → बायाँ → दायाँ) और डीसीरियलाइज़ेशन के समय पुनरावर्ती कॉल क्रम (नोड उत्पादन → बायाँ चाइल्ड → दायाँ चाइल्ड) पूर्णतः मेल खाते हैं, इसलिए टोकन को क्रम से उपभोग करने मात्र से सही ट्री पुनर्स्थापित होता है

## पूर्वापेक्षित ज्ञान

### Preorder (पूर्व-क्रम) ट्रैवर्सल क्या है

बाइनरी ट्री को "रूट → बायाँ सबट्री → दायाँ सबट्री" के क्रम में पुनरावर्ती रूप से विज़िट करने की ट्रैवर्सल विधि है। रूट सबसे पहले प्रोसेस होता है, इसलिए सीरियलाइज़ किए गए डेटा का पहला तत्व हमेशा रूट नोड होता है।

```java
void preorder(TreeNode node) {
    if (node == null) return;
    visit(node);           // पहले रूट को प्रोसेस करें
    preorder(node.left);   // फिर बाएँ सबट्री को पुनरावर्ती रूप से प्रोसेस करें
    preorder(node.right);  // अंत में दाएँ सबट्री को पुनरावर्ती रूप से प्रोसेस करें
}
```

### StringBuilder क्या है

स्ट्रिंग को कुशलतापूर्वक जोड़ने के लिए उपयोग किया जाने वाला क्लास है। `+` ऑपरेटर द्वारा स्ट्रिंग जोड़ने पर हर बार नया String ऑब्जेक्ट बनता है जिससे O(n²) लगता है, लेकिन StringBuilder आंतरिक बफर में जोड़ता है इसलिए O(n) में पूरा होता है।

```java
StringBuilder sb = new StringBuilder();  // खाली StringBuilder बनाएँ
sb.append("hello");                      // अंत में स्ट्रिंग जोड़ें
sb.append(",");                          // कॉमा जोड़ें
sb.deleteCharAt(sb.length() - 1);        // अंतिम 1 अक्षर हटाएँ
sb.toString();                           // String में रूपांतरित करें → "hello"
```

### LinkedList और poll मेथड

LinkedList एक डेटा संरचना है जो सूची के आरंभ और अंत में O(1) में जोड़ने और हटाने की अनुमति देती है। `poll()` मेथड सूची के पहले तत्व को निकालकर लौटाता है (सूची से हटा दिया जाता है)। खाली होने पर null लौटाता है।

```java
LinkedList<String> tokens = new LinkedList<>(Arrays.asList("1", "2", "null"));
tokens.poll();  // "1" लौटाता है और सूची से हटाता है। शेष: ["2", "null"]
tokens.poll();  // "2" लौटाता है और सूची से हटाता है। शेष: ["null"]
```

### सेंटिनल मान क्या है

डेटा के अंत या विशेष स्थिति को दर्शाने के लिए उपयोग किया जाने वाला एक विशेष मान है। इस समस्या में स्ट्रिंग `"null"` को सेंटिनल के रूप में उपयोग किया जाता है, जो "इस स्थान पर कोई चाइल्ड नोड मौजूद नहीं है" को व्यक्त करता है। सेंटिनल होने से डीसीरियलाइज़ेशन के समय सबट्री की सीमा का सटीक निर्धारण किया जा सकता है।

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n) — सभी n नोड्स को एक-एक बार विज़िट किया जाता है |
| Space | O(n) — सीरियलाइज़ स्ट्रिंग और टोकन सूची में n तत्वों का स्थान उपयोग होता है। पुनरावर्ती कॉल स्टैक अधिकतम O(n) होता है (असंतुलित ट्री की स्थिति में) |

## कोड

```java
// इनपुट: सीरियलाइज़ — बाइनरी ट्री का रूट नोड root। डीसीरियलाइज़ — कॉमा से अलग की गई स्ट्रिंग data
// आउटपुट: सीरियलाइज़ — ट्री को दर्शाने वाली कॉमा से अलग की गई स्ट्रिंग। डीसीरियलाइज़ — मूल बाइनरी ट्री का रूट नोड

// बाइनरी ट्री को स्ट्रिंग में सीरियलाइज़ करें
public String serialize(TreeNode root) {
    // ट्री के सभी नोड्स के मानों को कॉमा से अलग करके संचित करने वाला बफर
    StringBuilder sb = new StringBuilder();
    // Preorder क्रम में ट्री का ट्रैवर्सल करें और StringBuilder में मान जोड़ें
    serHelper(root, sb);
    // अंत के अतिरिक्त कॉमा को हटाएँ
    if (sb.length() > 0)
        sb.deleteCharAt(sb.length() - 1);
    return sb.toString();
}

// Preorder क्रम में ट्री का ट्रैवर्सल करें और प्रत्येक नोड के मान को StringBuilder में जोड़ें
void serHelper(TreeNode node, StringBuilder sb) {
    // null नोड को सेंटिनल मान "null" के रूप में रिकॉर्ड करें (डीसीरियलाइज़ेशन के समय सबट्री के अंत का निर्धारण करने के लिए)
    if (node == null) {
        sb.append("null,");
        return;
    }
    // वर्तमान नोड के मान को रिकॉर्ड करें (Preorder होने के कारण रूट को सबसे पहले प्रोसेस करें)
    // प्रत्येक मान कॉमा से अलग किए गए प्रारूप में होता है
    sb.append(node.val).append(",");
    // बाएँ सबट्री को पुनरावर्ती रूप से प्रोसेस करें
    serHelper(node.left, sb);
    // दाएँ सबट्री को पुनरावर्ती रूप से प्रोसेस करें (रूट → बायाँ → दायाँ का क्रम Preorder को साकार करता है)
    serHelper(node.right, sb);
}

// स्ट्रिंग से बाइनरी ट्री को डीसीरियलाइज़ करें
public TreeNode deserialize(String data) {
    // खाली स्ट्रिंग खाली ट्री को दर्शाती है
    if (data.isEmpty()) return null;
    // कॉमा से विभाजित करके LinkedList में रूपांतरित करें (आरंभ से O(1) में निकालने वाले poll() की आवश्यकता के कारण)
    LinkedList<String> tokens =
        new LinkedList<>(Arrays.asList(data.split(",")));
    // टोकन को आरंभ से क्रमशः उपभोग करते हुए पुनरावर्ती रूप से नोड उत्पन्न करें
    return desHelper(tokens);
}

// टोकन को आरंभ से क्रमशः उपभोग करते हुए पुनरावर्ती रूप से नोड उत्पन्न करें
TreeNode desHelper(LinkedList<String> tokens) {
    // पहले टोकन को निकालें (poll सूची से तत्व हटाता है, इसलिए अगली पुनरावृत्ति में अगला टोकन पहला बन जाता है)
    String val = tokens.poll();
    // सेंटिनल मान होने पर null लौटाएँ और पुनरावृत्ति समाप्त करें (पैरेंट नोड का चाइल्ड null पर सेट होता है)
    if (val.equals("null")) return null;
    // टोकन के मान को पूर्णांक में रूपांतरित करें और नया नोड उत्पन्न करें
    TreeNode node = new TreeNode(Integer.parseInt(val));
    // Preorder क्रम के अनुसार पहले बाएँ चाइल्ड का निर्माण करें (सीरियलाइज़ेशन के समय के क्रम से मेल खाने के कारण सही टोकन संगत होता है)
    node.left = desHelper(tokens);
    // फिर दाएँ चाइल्ड का निर्माण करें
    node.right = desHelper(tokens);
    // निर्मित नोड को लौटाएँ (पहली कॉल का रिटर्न मान रूट नोड = पुनर्स्थापित संपूर्ण ट्री होता है)
    return node;
}
```
