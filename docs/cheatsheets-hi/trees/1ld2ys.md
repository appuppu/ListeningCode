# Finding the Lowest Common Ancestor in a BST — BST में 2 नोड्स का सबसे गहरा साझा पूर्वज खोजना

## समस्या का सार

एक बाइनरी सर्च ट्री (BST) और उस ट्री में मौजूद दो नोड्स `p`, `q` दिए गए हैं। दोनों नोड्स को वंशज के रूप में रखने वाला सबसे गहरा नोड (न्यूनतम साझा पूर्वज: LCA) लौटाना है। किसी नोड को स्वयं का भी वंशज माना जाता है।

## मूल विचार

BST में बाईं ओर के सभी वंशज वर्तमान नोड से छोटे होते हैं, और दाईं ओर के सभी वंशज बड़े होते हैं। जिस क्षण `p` और `q` वर्तमान नोड के बाएँ और दाएँ अलग-अलग हो जाते हैं, वही नोड LCA होता है।

## विचार प्रक्रिया

1. **BST के गुण का उपयोग किया जा सकता है**: BST में किसी भी नोड के लिए, बाएँ सबट्री के सभी मान < नोड का मान < दाएँ सबट्री के सभी मान, यह क्रम सुनिश्चित होता है। इस गुण के कारण, `p` और `q` किस सबट्री में हैं यह केवल नोड के मानों की तुलना से निर्धारित किया जा सकता है
2. **दोनों बाईं ओर हैं तो बाईं ओर बढ़ें**: यदि `p.val` और `q.val` दोनों वर्तमान नोड के मान से छोटे हैं, तो `p` और `q` दोनों बाएँ सबट्री में मौजूद हैं। LCA भी उसी बाएँ सबट्री में होता है, इसलिए बाएँ चाइल्ड की ओर बढ़ें
3. **दोनों दाईं ओर हैं तो दाईं ओर बढ़ें**: यदि `p.val` और `q.val` दोनों वर्तमान नोड के मान से बड़े हैं, तो `p` और `q` दोनों दाएँ सबट्री में मौजूद हैं। LCA भी उसी दाएँ सबट्री में होता है, इसलिए दाएँ चाइल्ड की ओर बढ़ें
4. **बाएँ-दाएँ अलग हो जाएँ तो वही नोड LCA है**: यदि `p` और `q` वर्तमान नोड के बाएँ और दाएँ अलग-अलग हो गए हैं (एक छोटा है और दूसरा बड़ा है), तो इससे गहरे किसी एक सबट्री में दोनों को समाहित करना संभव नहीं है। इसलिए वर्तमान नोड ही LCA है। यदि `p` या `q` वर्तमान नोड के बराबर है, तो भी स्वयं को वंशज मानने के कारण वह LCA होता है
5. **रिकर्शन के बिना इटरेशन से हल किया जा सकता है**: प्रत्येक चरण में केवल बाएँ या दाएँ एक ही दिशा में आगे बढ़ा जाता है, इसलिए रिकर्शन के कॉल स्टैक की आवश्यकता नहीं है। while लूप से वर्तमान नोड को अपडेट करते रहना पर्याप्त है, और स्पेस कॉम्प्लेक्सिटी O(1) रखी जा सकती है

## पूर्वापेक्षित ज्ञान

### बाइनरी सर्च ट्री (BST) क्या है

प्रत्येक नोड "बाएँ वंशज < स्वयं < दाएँ वंशज" के क्रम को संतुष्ट करने वाला बाइनरी ट्री। इस गुण के कारण, केवल मानों की तुलना से यह निर्धारित किया जा सकता है कि कोई नोड किस सबट्री में है।

```
        6
       / \
      2    8
     / \  / \
    0   4 7   9
```

इस ट्री में नोड 2 और नोड 8 का LCA 6 है। नोड 2 और नोड 4 का LCA 2 है (नोड 2 स्वयं का भी वंशज माना जाता है)।

### न्यूनतम साझा पूर्वज (LCA) क्या है

दो नोड्स `p`, `q` के साझा पूर्वजों में से सबसे गहरा (जड़ से सबसे दूर) नोड। यदि `p` या `q` स्वयं दूसरे का पूर्वज है, तो वह नोड स्वयं ही LCA होता है।

### TreeNode की संरचना

BST के प्रत्येक नोड को दर्शाने वाली क्लास। इसमें मान `val`, बायाँ चाइल्ड `left`, और दायाँ चाइल्ड `right` होता है।

```java
TreeNode node = new TreeNode(6);   // मान 6 वाला नोड बनाएँ
node.val;                           // नोड का मान प्राप्त करें → 6
node.left;                          // बायाँ चाइल्ड नोड प्राप्त करें
node.right;                         // दायाँ चाइल्ड नोड प्राप्त करें
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(h) — ट्री की ऊँचाई जितनी खोज करता है। संतुलित BST में O(log n) होता है |
| Space | O(1) — इटरेटिव प्रोसेसिंग के कारण अतिरिक्त मेमोरी का उपयोग नहीं होता |

## कोड

```java
// इनपुट: BST का रूट नोड root, ट्री में मौजूद दो नोड्स p और q
// आउटपुट: p और q के न्यूनतम साझा पूर्वज (LCA) वाला TreeNode लौटाता है
TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    // वर्तमान खोज स्थिति को रूट से आरंभ करें। while लूप से अपडेट करते रहें
    TreeNode node = root;

    // जब तक node null नहीं है, खोज जारी रखें
    while (node != null) {
        // p और q दोनों वर्तमान नोड से छोटे हैं या नहीं इसकी जाँच करें
        if (p.val < node.val && q.val < node.val) {
            // दोनों बाएँ सबट्री में मौजूद हैं, इसलिए LCA भी बाएँ सबट्री में है
            node = node.left;
        // p और q दोनों वर्तमान नोड से बड़े हैं या नहीं इसकी जाँच करें
        } else if (p.val > node.val && q.val > node.val) {
            // दोनों दाएँ सबट्री में मौजूद हैं, इसलिए LCA भी दाएँ सबट्री में है
            node = node.right;
        } else {
            // p और q बाएँ-दाएँ अलग हो गए (या एक वर्तमान नोड के बराबर है)
            // इससे गहरे किसी एक सबट्री में दोनों नोड्स नहीं समा सकते इसलिए LCA निश्चित है
            return node;
        }
    }
    // समस्या की शर्तों के अनुसार p और q ट्री में मौजूद हैं इसलिए ऊपर के return से अवश्य लौटता है और यहाँ नहीं पहुँचता
    return null;
}
```
