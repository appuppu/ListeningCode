# Finding the Kth Smallest Element in a BST — BST में k-वाँ सबसे छोटा तत्व खोजना

## समस्या का सार

बाइनरी सर्च ट्री (BST) का रूट नोड `root` और एक पूर्णांक `k` दिया गया है। BST के सभी नोड्स के मानों में से **k-वाँ सबसे छोटा मान** लौटाना है। यह गारंटी दी गई है कि ट्री में कम से कम k नोड्स मौजूद हैं।

## मूल विचार

BST पर इन-ऑर्डर ट्रैवर्सल (in-order traversal) करने पर नोड्स के मान आरोही क्रम में प्राप्त होते हैं। इसलिए, इन-ऑर्डर ट्रैवर्सल में k-वें क्रम पर विज़िट किए गए नोड का मान सीधे उत्तर होता है। सभी नोड्स को ट्रैवर्स करने की आवश्यकता नहीं है, k-वें नोड पर पहुँचते ही तुरंत समाप्त किया जा सकता है।

## विचार प्रक्रिया

1. **BST के गुण का उपयोग करना**: BST में किसी भी नोड के लिए "बाएँ सबट्री के सभी नोड < स्वयं < दाएँ सबट्री के सभी नोड" यह शर्त सत्य होती है। इस गुण के कारण, इन-ऑर्डर ट्रैवर्सल (बायाँ→स्वयं→दायाँ) करने पर नोड्स के मान आरोही क्रम में प्राप्त होते हैं
2. **k-वाँ सबसे छोटा मान इन-ऑर्डर ट्रैवर्सल का k-वाँ तत्व है**: इन-ऑर्डर ट्रैवर्सल से प्राप्त आरोही अनुक्रम का k-वाँ तत्व उत्तर है, इसलिए ट्रैवर्सल के दौरान गिनती करना पर्याप्त है
3. **रिकर्शन के बजाय स्टैक द्वारा इटरेटिव ट्रैवर्सल चुनना**: रिकर्शन में k-वें नोड पर पहुँचने पर भी तुरंत return नहीं किया जा सकता (कॉल स्टैक को अनवाइंड करना आवश्यक होता है)। स्टैक का उपयोग करके इटरेटिव ट्रैवर्सल में k-वाँ तत्व मिलते ही return से बाहर निकला जा सकता है
4. **स्टैक से इन-ऑर्डर ट्रैवर्सल कैसे करें**: वर्तमान नोड से बाएँ चाइल्ड को लगातार फॉलो करते हुए स्टैक में पुश करना है। सबसे बाईं ओर पहुँचने पर स्टैक से pop करना है और उस नोड को "विज़िट" करना है। फिर दाएँ चाइल्ड पर जाकर वही प्रक्रिया दोहरानी है
5. **काउंटर से k-वें तत्व का पता लगाना**: नोड को pop करके विज़िट करने पर हर बार k को डिक्रीमेंट करना है। जब k शून्य हो जाए, उस नोड का मान उत्तर है
6. **अंतिम रूप से क्या लौटाना है**: जिस समय k शून्य हो, उस नोड का मान `curr.val` लौटाना है

## पूर्वापेक्षित ज्ञान

### BST (बाइनरी सर्च ट्री) का इन-ऑर्डर ट्रैवर्सल क्या है

बाइनरी सर्च ट्री को "बायाँ सबट्री→स्वयं→दायाँ सबट्री" के क्रम में विज़िट करने की ट्रैवर्सल विधि है। BST पर इन-ऑर्डर ट्रैवर्सल करने पर नोड्स के मान आरोही क्रम (छोटे से बड़े) में प्राप्त होते हैं।

```
उदाहरण:     5
           / \
          3   7
         / \
        2   4

इन-ऑर्डर ट्रैवर्सल का परिणाम: 2, 3, 4, 5, 7 (आरोही क्रम)
```

### Stack क्या है

लास्ट-इन-फर्स्ट-आउट (LIFO) डेटा स्ट्रक्चर है। सबसे अंत में जोड़ा गया तत्व सबसे पहले निकाला जाता है। इन-ऑर्डर ट्रैवर्सल में, बाएँ चाइल्ड को फॉलो करते समय गुज़रे हुए पैरेंट नोड्स को याद रखने के लिए Stack का उपयोग किया जाता है।

```java
Stack<TreeNode> stack = new Stack<>();  // खाली स्टैक बनाना
stack.push(node);      // node को स्टैक के सबसे ऊपर जोड़ना
stack.pop();           // स्टैक के सबसे ऊपर के तत्व को निकालकर लौटाना
stack.isEmpty();       // स्टैक खाली है या नहीं, boolean में लौटाना
```

### इटरेटिव इन-ऑर्डर ट्रैवर्सल का पैटर्न

स्टैक का उपयोग करके इन-ऑर्डर ट्रैवर्सल "सबसे बाईं ओर तक जाना→pop करके विज़िट करना→दाएँ चाइल्ड पर जाना" को दोहराता है। लूप की निरंतरता की शर्त यह है कि "वर्तमान नोड null नहीं है, या स्टैक खाली नहीं है" — इनमें से कोई भी सत्य होने तक लूप जारी रहता है।

```java
TreeNode curr = root;
while (curr != null || !stack.isEmpty()) {
    while (curr != null) {       // सबसे बाईं ओर तक जाना
        stack.push(curr);
        curr = curr.left;
    }
    curr = stack.pop();          // विज़िट करना (यहाँ आरोही क्रम में नोड्स प्राप्त होते हैं)
    curr = curr.right;           // दाएँ चाइल्ड पर जाना
}
```

## जटिलता

| | मान |
|---|---|
| Time | O(h + k) — सबसे बाईं ओर तक h बार नीचे जाना और k नोड्स को pop करना |
| Space | O(h) — स्टैक में अधिकतम ट्री की ऊँचाई h जितने नोड्स पुश होते हैं |

## कोड

```java
// इनपुट: बाइनरी सर्च ट्री का रूट नोड root और पूर्णांक k
// आउटपुट: BST में k-वाँ सबसे छोटा नोड का मान int में लौटाना
public int kthSmallest(TreeNode root, int k) {
    // बाएँ चाइल्ड को फॉलो करते समय गुज़रे हुए पैरेंट नोड्स को अस्थायी रूप से सहेजने और बाद में वापस आने के लिए स्टैक
    Stack<TreeNode> stack = new Stack<>();
    // वर्तमान में देखे जा रहे नोड को इंगित करने वाला पॉइंटर
    TreeNode curr = root;

    // curr null होने पर भी यदि स्टैक में नोड्स शेष हैं तो अभी अनविज़िटेड नोड्स हैं, इसलिए जारी रखना है
    while (curr != null || !stack.isEmpty()) {
        // सबसे बाईं ओर तक जाना और गुज़रे हुए नोड्स को स्टैक में पुश करना (वर्तमान सबट्री के न्यूनतम मान तक पहुँचना)
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }

        // pop किया गया नोड इन-ऑर्डर ट्रैवर्सल में अगला विज़िट होने वाला नोड है (अनविज़िटेड में सबसे छोटा मान रखने वाला)
        curr = stack.pop();
        // pop करना इन-ऑर्डर ट्रैवर्सल में एक नोड विज़िट करने के बराबर है, इसलिए शेष विज़िट की संख्या 1 कम करना
        k--;

        // जिस नोड पर k शून्य हो जाए वह k-वाँ सबसे छोटा तत्व है, इसलिए तुरंत मान लौटाकर समाप्त करना
        if (k == 0)
            return curr.val;

        // यदि दायाँ सबट्री मौजूद है तो अगले इटरेशन में उसके सबसे बाईं ओर तक जाना है। नहीं है तो curr null हो जाएगा और स्टैक से पैरेंट को pop करेंगे
        curr = curr.right;
    }
    // समस्या की शर्त के अनुसार ट्री में कम से कम k नोड्स मौजूद हैं, इसलिए यहाँ कभी नहीं पहुँचेंगे
    return -1;
}
```
