# Checking if a Binary Tree is Height-Balanced — यह जाँचना कि बाइनरी ट्री ऊँचाई-संतुलित है या नहीं

## समस्या का सार

बाइनरी ट्री का रूट नोड `root` दिया गया है। यह निर्धारित करना है कि वह ट्री **ऊँचाई-संतुलित (height-balanced)** है या नहीं। ऊँचाई-संतुलित का अर्थ है कि प्रत्येक नोड पर बाएँ सबट्री की ऊँचाई और दाएँ सबट्री की ऊँचाई का अंतर 1 से अधिक नहीं है। परिणाम `boolean` के रूप में लौटाना है।

## मुख्य विचार

प्रत्येक नोड की ऊँचाई ज्ञात करने वाली पुनरावर्ती प्रक्रिया में, असंतुलन का पता चलते ही `-1` लौटाकर उसे ऊपर तक प्रसारित करना है। ऊँचाई की गणना और संतुलन की जाँच को एक ही पोस्ट-ऑर्डर ट्रैवर्सल (post-order traversal) में एक साथ करने से, सभी नोड्स को केवल एक बार विज़िट करके उत्तर मिल जाता है।

## विचार प्रक्रिया

1. **संतुलन की परिभाषा को पुनरावर्ती रूप में समझना**: ट्री संतुलित है इसका अर्थ है कि प्रत्येक नोड पर बाएँ और दाएँ सबट्री की ऊँचाई का अंतर 1 से अधिक नहीं है। अर्थात्, किसी नोड के संतुलन की जाँच के लिए बाएँ और दाएँ सबट्री की "ऊँचाई" आवश्यक है
2. **ऊँचाई की गणना स्वयं पुनरावर्ती है**: किसी नोड की ऊँचाई `1 + max(बाएँ की ऊँचाई, दाएँ की ऊँचाई)` से प्राप्त होती है। इस पुनरावर्ती विधि से ट्री को नीचे से ऊपर (post-order में) ट्रैवर्स करने पर प्रत्येक नोड की ऊँचाई स्वाभाविक रूप से प्राप्त होती है
3. **ऊँचाई की गणना और संतुलन जाँच को एकीकृत करना**: ऊँचाई लौटाने वाले पुनरावर्ती फ़ंक्शन में, जब बाएँ और दाएँ की ऊँचाई का अंतर 1 से अधिक हो जाए, तो "असंतुलन" दर्शाने वाला विशेष मान `-1` लौटाना है। इस प्रकार ऊँचाई गणना और संतुलन जाँच एक ही फ़ंक्शन में एक साथ की जा सकती है
4. **शीघ्र समाप्ति से अनावश्यक अन्वेषण बचाना**: यदि बाएँ सबट्री का परिणाम `-1` है, तो दाएँ सबट्री की जाँच किए बिना ही पूरा ट्री असंतुलित है। पुनरावर्ती रिटर्न वैल्यू `-1` है या नहीं, इसकी हर बार जाँच करके, असंतुलन मिलते ही तुरंत `-1` लौटाकर पुनरावर्तन रोकना है
5. **रिटर्न वैल्यू के दोहरे अर्थ का उपयोग**: यदि रिटर्न वैल्यू `0 या अधिक` है तो यह सामान्य ऊँचाई है, `-1` है तो असंतुलन को दर्शाती है। कॉल करने वाला `isBalanced` मेथड केवल यह जाँचता है कि अंतिम रिटर्न वैल्यू `-1` नहीं है, और उत्तर प्राप्त हो जाता है

## पूर्वापेक्षित ज्ञान

### बाइनरी ट्री की ऊँचाई (height) क्या है

किसी नोड से सबसे दूर के पत्ती नोड तक की किनारों (edges) की संख्या। पत्ती नोड की ऊँचाई 1 है (नोड्स की संख्या से गिनने पर), `null` की ऊँचाई 0 है। पुनरावर्ती रूप में `height(node) = 1 + max(height(node.left), height(node.right))` से प्राप्त होती है।

```
        1           नोड 1 की ऊँचाई: 3
       / \          नोड 2 की ऊँचाई: 2
      2   3         नोड 4 की ऊँचाई: 1
     /              नोड 3 की ऊँचाई: 1
    4
```

### पोस्ट-ऑर्डर ट्रैवर्सल (Post-Order Traversal) क्या है

बायाँ सबट्री → दायाँ सबट्री → स्वयं नोड, इस क्रम में नोड्स को प्रोसेस करने की ट्रैवर्सल विधि। चाइल्ड की जानकारी पहले निश्चित करके फिर पैरेंट को प्रोसेस करने के कारण, "चाइल्ड की ऊँचाई से पैरेंट की ऊँचाई की गणना करना" जैसी नीचे से ऊपर की एकत्रीकरण प्रक्रिया के लिए उपयुक्त है।

```java
void postOrder(TreeNode node) {
    if (node == null) return;
    postOrder(node.left);   // बाएँ सबट्री को पहले प्रोसेस करना
    postOrder(node.right);  // दाएँ सबट्री को उसके बाद प्रोसेस करना
    // यहाँ node स्वयं का प्रोसेसिंग करना (बाएँ और दाएँ के परिणाम पहले से निश्चित हैं)
}
```

### Math.abs क्या है

पूर्णांक का निरपेक्ष मान (absolute value) लौटाने वाला Java का मानक मेथड। बाएँ और दाएँ की ऊँचाई का अंतर धनात्मक हो या ऋणात्मक, 1 से अधिक नहीं है, यह जाँचने के लिए उपयोग किया जाता है।

```java
Math.abs(3 - 1);    // → 2
Math.abs(1 - 3);    // → 2
Math.abs(2 - 3);    // → 1
```

## जटिलता विश्लेषण

| | मान |
|---|---|
| Time | O(n) — प्रत्येक नोड को एक बार विज़िट किया जाता है |
| Space | O(n) — पुनरावर्ती कॉल स्टैक अधिकतम n स्तर तक जाता है (जब ट्री एक तरफ झुका हो) |

## कोड

```java
// इनपुट: बाइनरी ट्री का रूट नोड root
// आउटपुट: यदि ट्री ऊँचाई-संतुलित है तो true, अन्यथा false लौटाना

// नोड की ऊँचाई लौटाने वाला पुनरावर्ती फ़ंक्शन। असंतुलन का पता चलने पर प्रहरी मान -1 लौटाता है
// यदि रिटर्न वैल्यू 0 या अधिक है तो सामान्य ऊँचाई, -1 है तो "कहीं कोई सबट्री असंतुलित है" का अर्थ है
private int checkHeight(TreeNode node) {
    // बेस केस: null खाली सबट्री को दर्शाता है, ऊँचाई 0 है
    if (node == null) return 0;

    // बाएँ सबट्री की ऊँचाई पुनरावर्ती रूप से ज्ञात करना (पोस्ट-ऑर्डर ट्रैवर्सल का "बाएँ को पहले" भाग)
    int left = checkHeight(node.left);
    // यदि बायाँ सबट्री असंतुलित है, तो दाएँ सबट्री की जाँच किए बिना तुरंत -1 प्रसारित करना (शीघ्र समाप्ति)
    if (left == -1) return -1;

    // दाएँ सबट्री की ऊँचाई पुनरावर्ती रूप से ज्ञात करना (पोस्ट-ऑर्डर ट्रैवर्सल का "दाएँ को बाद में" भाग)
    int right = checkHeight(node.right);
    // यदि दायाँ सबट्री असंतुलित है तो तुरंत -1 प्रसारित करना
    if (right == -1) return -1;

    // वर्तमान नोड पर बाएँ और दाएँ की ऊँचाई का अंतर 1 से अधिक है तो असंतुलित है (पोस्ट-ऑर्डर ट्रैवर्सल का "स्वयं का प्रोसेसिंग" भाग)
    // Math.abs का उपयोग करके, बायाँ या दायाँ कोई भी ऊँचा हो, अंतर को सही ढंग से जाँचना
    if (Math.abs(left - right) > 1)
        return -1;

    // यदि संतुलित है, तो वर्तमान नोड की ऊँचाई लौटाना। पैरेंट नोड की गणना में इसका उपयोग होता है
    return 1 + Math.max(left, right);
}

public boolean isBalanced(TreeNode root) {
    // यदि checkHeight का परिणाम -1 नहीं है तो पूरा ट्री संतुलित है
    // -1 "कहीं कोई सबट्री असंतुलित है" दर्शाने वाला प्रहरी मान है
    return checkHeight(root) != -1;
}
```
