# Finding the Diameter of a Binary Tree — बाइनरी ट्री में सबसे लंबे पथ (edges की संख्या) को ज्ञात करना

## समस्या का सार

बाइनरी ट्री का `root` दिया गया है। ट्री में किन्हीं दो नोड्स के बीच के सभी पथों में से सबसे लंबे पथ की लंबाई (edges की संख्या) को लौटाना है। यह पथ root से होकर गुजरना आवश्यक नहीं है।

## मूल विचार

किसी भी नोड पर "बाएं सबट्री की ऊंचाई + दाएं सबट्री की ऊंचाई + 2" उस नोड से होकर गुजरने वाले सबसे लंबे पथ की edges की संख्या होती है। DFS से प्रत्येक नोड की ऊंचाई ज्ञात करते हुए इस मान के अधिकतम को ट्रैक करने पर, एक ही traversal में diameter प्राप्त हो जाता है।

## विचार प्रक्रिया

1. **diameter किसी एक नोड को "शीर्ष" के रूप में पार करता है**: सबसे लंबा पथ अवश्य किसी एक नोड को सबसे ऊंचे बिंदु (मोड़ बिंदु) के रूप में उपयोग करता है, और उस नोड के बाएं सबट्री में कहीं से दाएं सबट्री में कहीं तक जाता है। इसलिए, प्रत्येक नोड के लिए "उस नोड को शीर्ष मानते हुए पथ की लंबाई" ज्ञात करके, उसका अधिकतम मान diameter बनता है
2. **शीर्ष से गुजरने वाले पथ की लंबाई बाएं और दाएं की ऊंचाई से निर्धारित होती है**: किसी नोड को शीर्ष मानते हुए पथ की edges की संख्या "बाएं सबट्री की ऊंचाई + दाएं सबट्री की ऊंचाई + 2" से गणना की जा सकती है। बाईं ऊंचाई सबसे गहरे बाएं नोड तक की edges की संख्या है, दाईं ऊंचाई सबसे गहरे दाएं नोड तक की edges की संख्या है, और शीर्ष से बाएं-दाएं प्रत्येक ओर 1 edge जुड़ती है इसलिए +2 होता है
3. **ऊंचाई की परिभाषा को "edges की संख्या" के अनुसार रखना**: नोड की ऊंचाई को "उस नोड से सबसे दूर की leaf तक की edges की संख्या" के रूप में परिभाषित करने पर, leaf नोड की ऊंचाई 0 और null नोड की ऊंचाई -1 होती है। null को -1 रखने से, leaf नोड की ऊंचाई `1 + max(-1, -1) = 0` के रूप में स्वाभाविक रूप से गणना हो जाती है
4. **DFS से ऊंचाई लौटाते हुए diameter को अपडेट करना**: पोस्ट-ऑर्डर DFS का उपयोग करके, प्रत्येक नोड पर बाएं और दाएं children की ऊंचाई को recursively प्राप्त करना है। प्राप्त बाएं-दाएं ऊंचाइयों से "उस नोड को शीर्ष मानते हुए पथ की लंबाई" की गणना करके global variable `maxDiameter` को अपडेट करना है, और return value के रूप में उस नोड की अपनी ऊंचाई `1 + max(left, right)` लौटानी है
5. **global variable से अधिकतम मान को ट्रैक करना**: DFS का return value "ऊंचाई" है, "diameter" नहीं, इसलिए diameter का अधिकतम मान global variable `maxDiameter` में रिकॉर्ड किया जाता है। प्रत्येक नोड पर `left + right + 2` और वर्तमान `maxDiameter` की तुलना करके, बड़े मान को रखा जाता है
6. **अंत में लौटाया जाने वाला मान**: DFS द्वारा सभी नोड्स का traversal पूरा होने के बाद, `maxDiameter` में संग्रहीत मान पूरे ट्री का diameter होता है

## पूर्वापेक्षित ज्ञान

### बाइनरी ट्री की ऊंचाई (height) क्या है

किसी नोड से सबसे दूर की leaf नोड तक के पथ में शामिल edges की संख्या। leaf नोड की ऊंचाई 0 और null नोड की ऊंचाई -1 के रूप में परिभाषित की जाती है। parent नोड की ऊंचाई `1 + max(बाएं child की ऊंचाई, दाएं child की ऊंचाई)` से ज्ञात होती है।

```
      1          नोड 1 की ऊंचाई: 2 (1→2→4 की edges की संख्या)
     / \         नोड 2 की ऊंचाई: 1 (2→4 की edges की संख्या)
    2   3        नोड 3 की ऊंचाई: 0 (leaf नोड)
   /             नोड 4 की ऊंचाई: 0 (leaf नोड)
  4
```

### recursion द्वारा DFS (Depth First Search) क्या है

ट्री के प्रत्येक नोड को recursively visit करने की विधि। पोस्ट-ऑर्डर में, बाएं child → दाएं child → स्वयं के क्रम में प्रोसेसिंग होती है। children के परिणामों का उपयोग करके parent का मान गणना करने के लिए यह उपयुक्त है।

```java
int dfs(TreeNode node) {
    if (node == null) return -1;   // बेस केस: null नोड की ऊंचाई -1 है
    int left = dfs(node.left);     // बाएं सबट्री को recursively प्रोसेस करना
    int right = dfs(node.right);   // दाएं सबट्री को recursively प्रोसेस करना
    return 1 + Math.max(left, right);  // अपनी ऊंचाई की गणना करके लौटाना
}
```

### Math.max क्या है

दो मानों में से बड़े मान को लौटाने वाला Java का standard method।

```java
Math.max(3, 5);    // → 5
Math.max(-1, -1);  // → -1
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n) — सभी नोड्स को एक-एक बार visit करने वाला DFS केवल एक बार चलाना पर्याप्त है |
| Space | O(n) — recursive calls का call stack अधिकतम n स्तर (skewed ट्री के मामले में) तक हो सकता है |

## कोड

```java
// इनपुट: बाइनरी ट्री का root नोड root
// आउटपुट: ट्री का diameter (किन्हीं दो नोड्स के बीच सबसे लंबे पथ की edges की संख्या) int के रूप में लौटाना

// DFS traversal के दौरान खोजे गए अधिकतम diameter को रखने वाला global variable
// प्रारंभिक मान 0 है क्योंकि केवल एक नोड वाले ट्री का diameter 0 होता है
int maxDiameter = 0;

// प्रत्येक नोड की ऊंचाई लौटाते हुए, side effect के रूप में maxDiameter को अपडेट करने वाला recursive function
int dfs(TreeNode node) {
    // null नोड की ऊंचाई -1 है (कोई edge मौजूद नहीं होने को दर्शाता है)
    // -1 लौटाने से, parent (leaf नोड) की ऊंचाई 1 + max(-1, -1) = 0 के रूप में सही ढंग से ज्ञात होती है
    if (node == null) return -1;

    // बाएं सबट्री की ऊंचाई को recursively प्राप्त करना
    int left = dfs(node.left);
    // दाएं सबट्री की ऊंचाई को recursively प्राप्त करना
    int right = dfs(node.right);

    // वर्तमान नोड को शीर्ष मानते हुए पथ की edges की संख्या (left + right + 2) से diameter के अधिकतम मान को अपडेट करना
    // +2 वर्तमान नोड से बाएं और दाएं children तक की 2 edges जोड़ने के लिए है
    maxDiameter = Math.max(
        maxDiameter,
        left + right + 2);

    // वर्तमान नोड की ऊंचाई को parent को लौटाना (ध्यान दें कि यह diameter नहीं बल्कि ऊंचाई है)
    // parent नोड अपने पथ की लंबाई गणना करने के लिए इस मान का उपयोग करता है
    return 1 + Math.max(left, right);
}

public int diameterOfBinaryTree(TreeNode root) {
    // DFS से सभी नोड्स का traversal करके, प्रत्येक नोड को शीर्ष मानते हुए पथ की लंबाई से maxDiameter को अपडेट करना
    dfs(root);
    // traversal पूरा होने के बाद maxDiameter पूरे ट्री का diameter होता है
    return maxDiameter;
}
```
