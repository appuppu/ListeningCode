# Finding the Maximum Path Sum in a Binary Tree — बाइनरी ट्री में किसी भी पथ का अधिकतम योग ज्ञात करना

## समस्या का सार

एक बाइनरी ट्री दिया गया है। प्रत्येक नोड एक पूर्णांक मान रखता है (ऋणात्मक मान भी हो सकते हैं)। एज से जुड़े नोड्स से बने किसी भी पथ (प्रत्येक नोड अधिकतम 1 बार ही उपयोग किया जा सकता है) में से, नोड मानों का योग अधिकतम हो ऐसा पथ खोजकर उसका **योग मान** लौटाना है। पथ का रूट से गुजरना आवश्यक नहीं है, यह किसी भी नोड से किसी भी नोड तक का मार्ग हो सकता है।

## मूल विचार

प्रत्येक नोड पर "बाएँ संतानों से प्राप्त अधिकतम लाभ" और "दाएँ संतानों से प्राप्त अधिकतम लाभ" की गणना करें, और उस नोड को शीर्ष मानकर बाएँ-दाएँ को जोड़ने वाले पथ के योग को वैश्विक अधिकतम मान का उम्मीदवार बनाएँ। दूसरी ओर, पैरेंट को लौटाने वाला मान बाएँ या दाएँ में से केवल एक शाखा का चयन करता है (क्योंकि पथ विभाजित नहीं हो सकता)।

## विचार प्रक्रिया

1. **पथ की संरचना पर विचार करें**: किसी भी पथ में अवश्य एक "सबसे ऊँची स्थिति वाला नोड (शीर्ष)" होता है। उस नोड के दृष्टिकोण से, पथ "बाएँ संतानों की ओर उतरने वाला भाग", "स्वयं", और "दाएँ संतानों की ओर उतरने वाला भाग" — इन 3 भागों से बना होता है। सभी नोड्स को शीर्ष के रूप में आज़माकर अधिकतम पथ योग ज्ञात करना है
2. **प्रत्येक नोड पर लाभ (gain) को परिभाषित करें**: किसी नोड को रूट मानकर उसके सबट्री से पैरेंट की दिशा में ले जा सकने वाले अधिकतम योग को "लाभ" कहते हैं। लाभ की गणना "अपना मान + बाएँ-दाएँ में से जो बड़ा हो उस संतान का लाभ" से होती है। पथ विभाजित नहीं हो सकता, इसलिए बाएँ-दाएँ दोनों को एक साथ पैरेंट को नहीं लौटा सकते
3. **ऋणात्मक लाभ को 0 मानें**: यदि संतान का लाभ ऋणात्मक है, तो उस शाखा को शामिल करने से पथ का योग घटता है। इसलिए `Math.max(0, gain)` का उपयोग करके ऋणात्मक लाभ को 0 (उस शाखा का उपयोग न करना) पर समायोजित करते हैं। इससे केवल एक नोड का पथ या केवल एक शाखा वाला पथ भी स्वाभाविक रूप से व्यक्त होता है
4. **वैश्विक अधिकतम मान को अलग से प्रबंधित करें**: प्रत्येक नोड को शीर्ष मानकर "बायाँ लाभ + अपना मान + दायाँ लाभ" उस नोड से गुजरने वाले अधिकतम पथ का योग है। इस मान की तुलना वैश्विक चर `maxSum` से करके उसे अपडेट करते हैं। पैरेंट को लौटाए जाने वाले लाभ से यह अलग गणना है, इसलिए इसे स्वतंत्र रूप से प्रबंधित करना आवश्यक है
5. **पोस्टऑर्डर DFS (postorder DFS) से गणना करें**: संतानों का लाभ ज्ञात होने के बाद ही अपनी गणना करनी होती है, इसलिए बायाँ→दायाँ→स्वयं के क्रम में प्रोसेस करने वाला पोस्टऑर्डर DFS उपयुक्त है। इससे एक ही ट्रैवर्सल में सभी नोड्स को शीर्ष के रूप में आज़माया जा सकता है
6. **अंत में क्या लौटाना है**: DFS पूर्ण होने के बाद, `maxSum` में सभी नोड्स को शीर्ष के रूप में आज़माने से प्राप्त अधिकतम पथ योग संग्रहित होता है। इसी मान को लौटाना है

## पूर्वापेक्षित ज्ञान

### बाइनरी ट्री का पोस्टऑर्डर DFS (Postorder DFS) क्या है

बाइनरी ट्री को "बायाँ संतान → दायाँ संतान → स्वयं" के क्रम में पुनरावर्ती रूप से विज़िट करने की ट्रैवर्सल विधि है। संतानों की गणना के परिणाम का उपयोग करके पैरेंट की गणना करने के लिए यह उपयुक्त है।

```java
void postorder(TreeNode node) {
    if (node == null) return;     // आधार स्थिति: null हो तो कुछ न करें
    postorder(node.left);         // पहले बाएँ सबट्री को प्रोसेस करें
    postorder(node.right);        // फिर दाएँ सबट्री को प्रोसेस करें
    // यहाँ node स्वयं की प्रोसेसिंग करें (संतानों के परिणाम पहले से निर्धारित हैं)
}
```

### Math.max क्या है

दो मानों में से बड़ा मान लौटाने वाला Java का मानक मेथड है। ऋणात्मक लाभ को 0 पर समायोजित करने और बाएँ-दाएँ लाभ की तुलना करने में इसका उपयोग होता है।

```java
Math.max(0, -5);    // → 0 (ऋणात्मक मान को 0 पर समायोजित करता है)
Math.max(3, 7);     // → 7 (बड़ा मान लौटाता है)
Math.max(0, gain(node.left));  // बाएँ संतान का लाभ ऋणात्मक हो तो 0 करता है
```

### Integer.MIN_VALUE क्या है

Java के `int` प्रकार का न्यूनतम संभव मान (-2,147,483,648) है। अधिकतम मान ज्ञात करने वाले एल्गोरिदम में प्रारंभिक मान के रूप में इसका उपयोग होता है। किसी भी मान से तुलना करने पर यह अपडेट हो जाने की गारंटी है।

```java
int maxSum = Integer.MIN_VALUE;  // किसी भी पथ योग से छोटा प्रारंभिक मान
maxSum = Math.max(maxSum, 10);   // → 10 (पहली तुलना में अवश्य अपडेट होता है)
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n) — DFS द्वारा प्रत्येक नोड को एक बार विज़िट किया जाता है |
| Space | O(n) — पुनरावर्ती कॉल का कॉल स्टैक सबसे खराब स्थिति (असंतुलित ट्री) में n स्तरों तक पहुँचता है |

## कोड

```java
// इनपुट: बाइनरी ट्री का रूट नोड root (प्रत्येक नोड में पूर्णांक मान val, बायाँ संतान left, दायाँ संतान right होता है)
// आउटपुट: बाइनरी ट्री में किसी भी पथ का अधिकतम योग मान int के रूप में लौटाता है
class Solution {
    // सभी नोड्स को शीर्ष के रूप में आज़माने से प्राप्त अधिकतम पथ योग को रिकॉर्ड करता है
    // Integer.MIN_VALUE से आरंभ करने पर किसी भी ऋणात्मक पथ मान से भी छोटा होता है, जिससे पहली तुलना में अवश्य अपडेट होता है
    int maxSum = Integer.MIN_VALUE;

    // नोड से पैरेंट की दिशा में ले जा सकने वाला अधिकतम लाभ लौटाने वाला पुनरावर्ती फंक्शन (पोस्टऑर्डर DFS से संतान→पैरेंट के क्रम में गणना करता है)
    int gain(TreeNode node) {
        // आधार स्थिति: null नोड का लाभ 0 है (अस्तित्वहीन संतान से कुछ प्राप्त नहीं होता)
        if (node == null) return 0;

        // बाएँ संतान का लाभ प्राप्त करें, ऋणात्मक हो तो 0 पर समायोजित करें (ऋणात्मक शाखा का उपयोग करने से पथ योग घटता है इसलिए उसे न चुनें)
        int leftGain = Math.max(0, gain(node.left));
        // दाएँ संतान का लाभ प्राप्त करें, उसी प्रकार ऋणात्मक हो तो 0 पर समायोजित करें
        int rightGain = Math.max(0, gain(node.right));

        // वर्तमान नोड को शीर्ष मानकर बाएँ-दाएँ को जोड़ने वाले पथ के योग से वैश्विक अधिकतम मान को अपडेट करें
        // यह मान "बायाँ संतान → वर्तमान नोड → दायाँ संतान" पथ के योग को दर्शाता है
        // leftGain या rightGain 0 होने पर केवल एक शाखा का, या केवल नोड स्वयं का पथ व्यक्त होता है
        maxSum = Math.max(maxSum, node.val + leftGain + rightGain);

        // पैरेंट को लौटाने वाला लाभ बाएँ-दाएँ में से केवल बड़ी शाखा का होता है
        // पथ एक सतत रेखा की तरह जुड़ा होना चाहिए और एक नोड पर विभाजित नहीं हो सकता, इसलिए दोनों को नहीं लौटा सकते
        return node.val + Math.max(leftGain, rightGain);
    }

    int maxPathSum(TreeNode root) {
        // रूट से पुनरावर्ती DFS आरंभ करें और सभी नोड्स को शीर्ष के रूप में आज़माएँ
        gain(root);
        // DFS पूर्ण होने के बाद, maxSum में सभी नोड्स को शीर्ष के रूप में आज़माने से प्राप्त अधिकतम पथ योग संग्रहित है
        return maxSum;
    }
}
```
