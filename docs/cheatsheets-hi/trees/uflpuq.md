# Checking if a Tree is a Subtree of Another — यह जाँचना कि एक वृक्ष दूसरे वृक्ष का उपवृक्ष है या नहीं

## समस्या का सार

दो बाइनरी ट्री `root` और `subRoot` दिए गए हैं। यह `boolean` में लौटाना है कि `root` के अंदर कोई ऐसा उपवृक्ष मौजूद है या नहीं जो संरचना और मानों दोनों में `subRoot` से पूर्णतः मेल खाता हो। उपवृक्ष का अर्थ है कि `root` के किसी नोड को जड़ मानने पर, उसके नीचे का संपूर्ण वृक्ष `subRoot` के साथ समान हो।

## मूल विचार

यदि वृक्ष को null मार्कर सहित प्रीऑर्डर ट्रैवर्सल द्वारा स्ट्रिंग में सीरियलाइज़ किया जाए, तो उपवृक्ष की जाँच "एक स्ट्रिंग दूसरी स्ट्रिंग में शामिल है या नहीं" — इस स्ट्रिंग खोज की समस्या में बदल जाती है।

## विचार प्रक्रिया

1. **उपवृक्ष की मिलान जाँच "संपूर्ण वृक्ष की आकृति और मानों की तुलना" है**: उपवृक्ष होने के लिए, किसी नोड के नीचे की संरचना और सभी नोड्स के मान पूर्णतः मेल खाने चाहिए। अर्थात वृक्ष की आकृति की जानकारी को सुरक्षित रखते हुए तुलना करने की विधि आवश्यक है
2. **यदि वृक्ष को अद्वितीय रूप से व्यक्त किया जा सके तो तुलना सरल हो जाती है**: वृक्ष संरचना के रूप में तुलना करने के लिए प्रत्येक नोड पर रिकर्सिव ट्रैवर्सल आवश्यक होता है। वृक्ष को स्ट्रिंग में सीरियलाइज़ करने से, संरचना और मानों की तुलना स्ट्रिंग तुलना में बदल जाती है, जिससे कुशलतापूर्वक प्रसंस्करण किया जा सकता है
3. **प्रीऑर्डर ट्रैवर्सल में null मार्कर जोड़कर अद्वितीयता सुनिश्चित करना**: केवल प्रीऑर्डर ट्रैवर्सल से भिन्न वृक्ष एक ही स्ट्रिंग बन सकते हैं। जहाँ चाइल्ड null है वहाँ `#` जैसा मार्कर डालने से, वृक्ष की संरचना को अद्वितीय रूप से एनकोड किया जा सकता है
4. **प्रत्येक नोड के मान के पहले कॉमा विभाजक लगाना**: मानों की सीमा स्पष्ट करने के लिए, प्रत्येक नोड के मान के पहले कॉमा `,` जोड़ा जाता है। इससे, उदाहरण के लिए मान `2` और `12` में भ्रम होने से रोका जा सकता है
5. **उपवृक्ष की जाँच स्ट्रिंग समावेशन जाँच में बदल जाती है**: यदि `root` को सीरियलाइज़ की गई स्ट्रिंग में `subRoot` को सीरियलाइज़ की गई स्ट्रिंग सबस्ट्रिंग के रूप में शामिल है, तो `subRoot` `root` का उपवृक्ष है। Java की `String.contains()` से O(m+n) में जाँच की जा सकती है

## पूर्वापेक्षित ज्ञान

### बाइनरी ट्री का प्रीऑर्डर ट्रैवर्सल क्या है

वृक्ष के नोड्स को "जड़ → बायाँ चाइल्ड → दायाँ चाइल्ड" के क्रम में विज़िट करने की ट्रैवर्सल विधि। रिकर्शन से कार्यान्वित करने पर, पहले वर्तमान नोड को प्रसंस्कृत किया जाता है, फिर बाएँ उपवृक्ष को, और अंत में दाएँ उपवृक्ष को रिकर्सिव रूप से प्रसंस्कृत किया जाता है।

```java
void preorder(TreeNode node) {
    if (node == null) return;
    System.out.println(node.val);  // जड़ को प्रसंस्कृत करना
    preorder(node.left);           // बाएँ उपवृक्ष को रिकर्सिव रूप से ट्रैवर्स करना
    preorder(node.right);          // दाएँ उपवृक्ष को रिकर्सिव रूप से ट्रैवर्स करना
}
```

### StringBuilder क्या है

स्ट्रिंग को कुशलतापूर्वक जोड़ने के लिए एक क्लास। `String` का `+` ऑपरेटर प्रत्येक जोड़ पर नया ऑब्जेक्ट बनाता है, लेकिन `StringBuilder` आंतरिक बफ़र में जोड़ता है इसलिए O(1) में जोड़ा जा सकता है।

```java
StringBuilder sb = new StringBuilder();  // खाली StringBuilder बनाना
sb.append(",5");                         // स्ट्रिंग ",5" को बफ़र के अंत में जोड़ना
sb.append(",#");                         // स्ट्रिंग ",#" को बफ़र के अंत में जोड़ना
sb.toString();                           // बफ़र की सामग्री को String प्रकार में बदलना → ",5,#"
```

### String.contains() क्या है

यह विधि `boolean` में लौटाती है कि एक स्ट्रिंग दूसरी स्ट्रिंग को सबस्ट्रिंग के रूप में शामिल करती है या नहीं।

```java
String s = ",1,2,#,#,3,#,#";
s.contains(",2,#,#");    // s में ",2,#,#" शामिल है या नहीं यह जाँचना → true
s.contains(",4,#,#");    // s में ",4,#,#" शामिल है या नहीं यह जाँचना → false
```

### null मार्कर क्या है

वृक्ष के सीरियलाइज़ेशन में, जहाँ चाइल्ड नोड मौजूद नहीं है (null) उस स्थान पर डाला जाने वाला एक विशेष चिह्न। अधिकतर `#` का उपयोग किया जाता है। null मार्कर के बिना, भिन्न संरचना वाले वृक्ष एक ही ट्रैवर्सल परिणाम दे सकते हैं। उदाहरण के लिए, केवल बायाँ चाइल्ड रखने वाले वृक्ष और केवल दायाँ चाइल्ड रखने वाले वृक्ष को अलग करने के लिए null मार्कर आवश्यक है।

## गणना जटिलता

| | मान |
|---|---|
| Time | O(m + n) — root (नोड संख्या m) और subRoot (नोड संख्या n) को प्रत्येक को एक बार ट्रैवर्स करके सीरियलाइज़ किया जाता है, और स्ट्रिंग समावेशन जाँच की जाती है |
| Space | O(m + n) — दोनों वृक्षों के सीरियलाइज़ेशन परिणामों को StringBuilder में संग्रहीत किया जाता है |

## कोड

```java
// इनपुट: बाइनरी ट्री का रूट नोड root और subRoot
// आउटपुट: यदि subRoot root का उपवृक्ष है तो true, अन्यथा false लौटाना

// वृक्ष को प्रीऑर्डर ट्रैवर्सल द्वारा स्ट्रिंग में सीरियलाइज़ करने वाली सहायक विधि
void serialize(TreeNode node, StringBuilder sb) {
    if (node == null) {
        // null मार्कर ",#" जोड़कर चाइल्ड नोड के अस्तित्व में न होने को स्पष्ट करना
        // इससे केवल बायाँ चाइल्ड रखने वाले वृक्ष और केवल दायाँ चाइल्ड रखने वाले वृक्ष को अलग किया जा सकता है
        sb.append(",#");
        return;
    }
    // मान के पहले कॉमा लगाकर, मान 2 और 12 जैसी संख्याओं की सीमा अस्पष्ट न होने देना
    sb.append("," + node.val);
    // बाएँ उपवृक्ष को रिकर्सिव रूप से सीरियलाइज़ करना
    serialize(node.left, sb);
    // दाएँ उपवृक्ष को रिकर्सिव रूप से सीरियलाइज़ करना
    serialize(node.right, sb);
}

boolean isSubtree(TreeNode root, TreeNode subRoot) {
    // sb1 root के सीरियलाइज़ेशन परिणाम को, sb2 subRoot के सीरियलाइज़ेशन परिणाम को संग्रहीत करता है
    StringBuilder sb1 = new StringBuilder();
    StringBuilder sb2 = new StringBuilder();

    // दोनों वृक्षों को प्रीऑर्डर ट्रैवर्सल द्वारा स्ट्रिंग में सीरियलाइज़ करना
    serialize(root, sb1);
    serialize(subRoot, sb2);

    // यदि root की स्ट्रिंग में subRoot की स्ट्रिंग सबस्ट्रिंग के रूप में शामिल है तो वह उपवृक्ष है
    return sb1.toString().contains(sb2.toString());
}
```
