# Constructing a Binary Tree From Traversal Orders — प्रीऑर्डर और इनऑर्डर ट्रैवर्सल से मूल बाइनरी ट्री को पुनर्निर्मित करना

## समस्या का सार

पूर्णांक सरणी `preorder` (प्रीऑर्डर ट्रैवर्सल) और `inorder` (इनऑर्डर ट्रैवर्सल) दी गई है। इन दो ट्रैवर्सल परिणामों से मूल बाइनरी ट्री का निर्माण करके उसे लौटाना है। प्रीऑर्डर ट्रैवर्सल में तत्व "रूट→बायाँ→दायाँ" के क्रम में होते हैं, और इनऑर्डर ट्रैवर्सल में तत्व "बायाँ→रूट→दायाँ" के क्रम में होते हैं।

## मूल विचार

प्रीऑर्डर ट्रैवर्सल का पहला तत्व हमेशा वर्तमान सबट्री का रूट होता है, और उस रूट का मान इनऑर्डर ट्रैवर्सल में कहाँ स्थित है यह देखकर, इनऑर्डर ट्रैवर्सल को "बायीं सबट्री के तत्व" और "दायीं सबट्री के तत्व" में विभाजित किया जा सकता है। इस विभाजन को पुनरावर्ती रूप से दोहराकर पूरे ट्री को पुनर्निर्मित किया जा सकता है।

## विचार प्रक्रिया

1. **प्रीऑर्डर ट्रैवर्सल का पहला तत्व रूट होता है**: प्रीऑर्डर ट्रैवर्सल तत्वों को "रूट→बायाँ→दायाँ" के क्रम में व्यवस्थित करता है, इसलिए सरणी का पहला तत्व हमेशा पूरे ट्री का रूट नोड होता है। यह गुण सबट्री पर भी पुनरावर्ती रूप से लागू होता है
2. **इनऑर्डर ट्रैवर्सल में रूट की स्थिति पता चलने पर बायें और दायें को विभाजित किया जा सकता है**: इनऑर्डर ट्रैवर्सल "बायाँ→रूट→दायाँ" के क्रम में होता है, इसलिए जब रूट का मान इनऑर्डर ट्रैवर्सल में स्थिति `mid` पर होता है, तो `mid` से बायें के सभी तत्व बायीं सबट्री से संबंधित होते हैं, और `mid` से दायें के सभी तत्व दायीं सबट्री से संबंधित होते हैं
3. **रूट की स्थिति तेज़ी से प्राप्त करना आवश्यक है**: हर बार इनऑर्डर ट्रैवर्सल में रैखिक खोज करने पर कुल O(n²) का समय लगता है। पहले से HashMap में "मान→इनऑर्डर ट्रैवर्सल में इंडेक्स" दर्ज करके रखने पर, रूट की स्थिति O(1) में प्राप्त की जा सकती है
4. **सरणी की प्रतिलिपि के बजाय इंडेक्स सीमाओं से सबट्री की सीमा को व्यक्त करना**: हर पुनरावर्तन पर सरणी की प्रतिलिपि बनाने से O(n²) स्थान की आवश्यकता होती है। इनऑर्डर ट्रैवर्सल की सीमा को `inLeft` और `inRight` दो इंडेक्स से व्यक्त करने पर, सरणी की प्रतिलिपि के बिना सबट्री की सीमा निर्दिष्ट की जा सकती है
5. **प्रीऑर्डर ट्रैवर्सल के पॉइंटर को ग्लोबल रूप से आगे बढ़ाना**: प्रीऑर्डर ट्रैवर्सल "रूट→पूरी बायीं सबट्री→पूरी दायीं सबट्री" के क्रम में व्यवस्थित होता है, इसलिए एक ग्लोबल पॉइंटर `preIdx` रखकर हर बार रूट निकालने पर उसे इंक्रीमेंट करने से, बायीं सबट्री की पुनरावृत्ति समाप्त होने पर पॉइंटर स्वाभाविक रूप से दायीं सबट्री के रूट को इंगित करता है
6. **बायीं सबट्री का निर्माण पहले करना**: प्रीऑर्डर ट्रैवर्सल का क्रम "रूट→बायाँ→दायाँ" है, इसलिए रूट निकालने के बाद हमेशा पहले बायीं सबट्री का पुनरावर्ती निर्माण करना होता है, उसके बाद दायीं सबट्री का निर्माण करना होता है। इस क्रम का पालन करने से `preIdx` सही ढंग से आगे बढ़ता है

## पूर्वापेक्षित ज्ञान

### प्रीऑर्डर ट्रैवर्सल (Preorder Traversal) क्या है

बाइनरी ट्री को "रूट→बायीं सबट्री→दायीं सबट्री" के क्रम में विज़िट करने की ट्रैवर्सल विधि है। सरणी का पहला तत्व हमेशा रूट नोड का मान होता है।

```
        3
       / \
      9   20
         / \
        15   7

प्रीऑर्डर ट्रैवर्सल: [3, 9, 20, 15, 7]  ← पहला तत्व 3 रूट है
```

### इनऑर्डर ट्रैवर्सल (Inorder Traversal) क्या है

बाइनरी ट्री को "बायीं सबट्री→रूट→दायीं सबट्री" के क्रम में विज़िट करने की ट्रैवर्सल विधि है। रूट के मान को आधार मानकर, बायीं ओर के तत्व बायीं सबट्री से और दायीं ओर के तत्व दायीं सबट्री से संबंधित होते हैं।

```
इनऑर्डर ट्रैवर्सल: [9, 3, 15, 20, 7]  ← 3 के बायें [9] बायीं सबट्री है, दायें [15,20,7] दायीं सबट्री है
```

### HashMap क्या है

की और वैल्यू के जोड़े को संग्रहीत करने वाली डेटा संरचना है। की निर्दिष्ट करके वैल्यू की खोज और प्राप्ति O(1) में की जा सकती है।

```java
HashMap<Integer, Integer> map = new HashMap<>();  // खाली HashMap बनाना
map.put(3, 1);           // की 3 में वैल्यू 1 संग्रहीत करना
map.get(3);              // की 3 से संबंधित वैल्यू लौटाना → 1
```

### TreeNode क्या है

बाइनरी ट्री के एक नोड को दर्शाने वाला क्लास है। इसमें मान `val`, बायाँ चाइल्ड `left`, और दायाँ चाइल्ड `right` होता है।

```java
TreeNode root = new TreeNode(3);    // मान 3 वाला नोड बनाना
root.left = new TreeNode(9);        // बायें चाइल्ड को मान 9 वाला नोड सेट करना
root.right = new TreeNode(20);      // दायें चाइल्ड को मान 20 वाला नोड सेट करना
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — प्रत्येक नोड को एक बार प्रोसेस किया जाता है, और HashMap द्वारा खोज O(1) में होती है |
| Space | O(n) — HashMap में n तत्व संग्रहीत होते हैं, और पुनरावर्ती स्टैक सबसे खराब स्थिति में O(n) होता है (असंतुलित ट्री के मामले में) |

## कोड

```java
// इनपुट: पूर्णांक सरणी preorder (प्रीऑर्डर ट्रैवर्सल) और पूर्णांक सरणी inorder (इनऑर्डर ट्रैवर्सल)
// आउटपुट: पुनर्निर्मित बाइनरी ट्री का रूट नोड TreeNode लौटाना

// की=इनऑर्डर ट्रैवर्सल का मान, वैल्यू=उस मान का इनऑर्डर ट्रैवर्सल में इंडेक्स संग्रहीत करने वाला HashMap
// रूट के मान से इनऑर्डर ट्रैवर्सल में स्थिति O(1) में प्राप्त करने के लिए उपयोग किया जाता है
Map<Integer, Integer> map = new HashMap<>();
// प्रीऑर्डर ट्रैवर्सल सरणी में "अगला निकालने योग्य रूट की स्थिति" को इंगित करने वाला ग्लोबल पॉइंटर
// हर पुनरावर्ती कॉल पर इंक्रीमेंट करके आगे बढ़ाया जाता है
int preIdx = 0;

public TreeNode buildTree(int[] preorder, int[] inorder) {
    // इनऑर्डर ट्रैवर्सल के प्रत्येक मान और इंडेक्स को HashMap में दर्ज करना
    // इससे किसी भी मान की इनऑर्डर ट्रैवर्सल में स्थिति तुरंत प्राप्त की जा सकती है
    for (int i = 0; i < inorder.length; i++)
        map.put(inorder[i], i);

    // पूरी सरणी की सीमा (inLeft=0, inRight=अंतिम) निर्दिष्ट करके पुनरावर्तन प्रारंभ करना
    return helper(preorder, 0, inorder.length - 1);
}

// inLeft, inRight इनऑर्डर ट्रैवर्सल सरणी पर वर्तमान सबट्री की सीमा को दर्शाते हैं
TreeNode helper(int[] preorder, int inLeft, int inRight) {
    // सबट्री की सीमा खाली होने पर (inLeft > inRight) चाइल्ड नोड मौजूद नहीं है
    if (inLeft > inRight) return null;

    // प्रीऑर्डर ट्रैवर्सल की वर्तमान स्थिति से रूट का मान निकालना और पॉइंटर आगे बढ़ाना
    int rootVal = preorder[preIdx++];
    TreeNode root = new TreeNode(rootVal);

    // रूट का मान इनऑर्डर ट्रैवर्सल में कहाँ है यह HashMap से प्राप्त करना
    // mid इनऑर्डर ट्रैवर्सल में बायीं सबट्री और दायीं सबट्री की सीमा को दर्शाता है
    int mid = map.get(rootVal);

    // ध्यान दें: प्रीऑर्डर ट्रैवर्सल "रूट→बायाँ→दायाँ" के क्रम में होता है, इसलिए बायीं सबट्री का निर्माण पहले करना आवश्यक है
    // इस क्रम से preIdx सही ढंग से दायीं सबट्री के रूट को इंगित करता है
    // इनऑर्डर ट्रैवर्सल में inLeft से mid-1 तक बायीं सबट्री की सीमा है
    root.left = helper(preorder, inLeft, mid - 1);
    // इनऑर्डर ट्रैवर्सल में mid+1 से inRight तक दायीं सबट्री की सीमा है
    root.right = helper(preorder, mid + 1, inRight);

    // निर्मित root नोड को लौटाना। सभी पुनरावर्तन पूरे होने पर पूरे ट्री का रूट नोड लौटता है
    return root;
}
```
