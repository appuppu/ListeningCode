# Finding the Maximum Depth of a Binary Tree — बाइनरी ट्री की अधिकतम गहराई में नोड्स की संख्या ज्ञात करना

## समस्या का सार

बाइनरी ट्री का `root` नोड दिया गया है। रूट नोड से सबसे दूर के लीफ नोड तक के पथ में शामिल **नोड्स की संख्या** (अधिकतम गहराई) को एक पूर्णांक के रूप में लौटाना है। यदि ट्री खाली है (root null है) तो 0 लौटाना है।

## मूल विचार

ट्री की अधिकतम गहराई "बाएं सबट्री की अधिकतम गहराई" और "दाएं सबट्री की अधिकतम गहराई" में से बड़े मान में 1 (वर्तमान नोड के लिए) जोड़कर प्राप्त होती है। यह पुनरावर्ती परिभाषा ही सीधे समाधान बन जाती है।

## विचार प्रक्रिया

1. **ट्री की गहराई को पुनरावर्ती रूप से परिभाषित किया जा सकता है**: किसी नोड की गहराई उसके बाएं और दाएं चाइल्ड को रूट मानने वाले सबट्री की गहराई पर निर्भर करती है। अर्थात, समस्या को समान संरचना वाली छोटी उपसमस्याओं में विभाजित किया जा सकता है
2. **बेस केस निर्धारित करना**: जब नोड null होता है, तो वहां कुछ भी नहीं है इसलिए गहराई 0 होती है। यह पुनरावर्तन की समाप्ति शर्त बन जाती है
3. **बाएं और दाएं सबट्री की गहराई अलग-अलग ज्ञात करना**: वर्तमान नोड से बाएं चाइल्ड पर पुनरावर्तन करके बाएं सबट्री की अधिकतम गहराई प्राप्त करना है। इसी प्रकार दाएं चाइल्ड पर भी पुनरावर्तन करके दाएं सबट्री की अधिकतम गहराई प्राप्त करना है
4. **बाएं और दाएं के परिणामों को संयोजित करना**: अधिकतम गहराई का अर्थ सबसे लंबा पथ है, इसलिए बाएं और दाएं की गहराई में से बड़े मान को चुनना है। इसे `Math.max(left, right)` से प्राप्त किया जाता है
5. **वर्तमान नोड को जोड़कर लौटाना**: बाएं और दाएं की गहराई के अधिकतम मान में 1 जोड़कर, वर्तमान नोड को शामिल करते हुए गहराई पैरेंट को लौटाई जाती है। यह 1 "वर्तमान नोड स्वयं" की गिनती है

## पूर्वापेक्षित ज्ञान

### TreeNode (बाइनरी ट्री का नोड) क्या है

बाइनरी ट्री के प्रत्येक नोड को दर्शाने वाला क्लास है। इसमें मान `val`, बायां चाइल्ड `left`, और दायां चाइल्ड `right` — ये तीन फ़ील्ड होते हैं। यदि कोई चाइल्ड मौजूद नहीं है तो उसमें null होता है।

```java
public class TreeNode {
    int val;              // नोड में संग्रहीत मान
    TreeNode left;        // बायां चाइल्ड नोड (नहीं है तो null)
    TreeNode right;       // दायां चाइल्ड नोड (नहीं है तो null)
}
```

### पुनरावर्तन (Recursion) क्या है

फ़ंक्शन द्वारा स्वयं को कॉल करने की तकनीक है। ट्री संरचना में, प्रत्येक नोड पर सबट्री के लिए समान प्रक्रिया लागू करने के लिए इसका उपयोग किया जाता है। अनंत लूप को रोकने के लिए बेस केस (पुनरावर्तन रोकने की शर्त) को अवश्य परिभाषित करना होता है।

```java
// पुनरावर्तन की मूल संरचना
public int recursive(TreeNode node) {
    if (node == null) return 0;           // बेस केस: पुनरावर्तन की समाप्ति शर्त
    return recursive(node.left);          // पुनरावर्ती कॉल: उपसमस्या को हल करना
}
```

### Math.max क्या है

दो पूर्णांकों में से बड़ा मान लौटाने वाला Java का मानक मेथड है।

```java
Math.max(3, 5);    // → 5
Math.max(0, 0);    // → 0
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — सभी नोड्स को एक-एक बार विज़िट किया जाता है |
| Space | O(h) — पुनरावर्तन का कॉल स्टैक ट्री की ऊंचाई जितना बनता है। सबसे खराब स्थिति (असंतुलित ट्री) में O(n) होता है |

## कोड

```java
// इनपुट: बाइनरी ट्री का रूट नोड root (TreeNode प्रकार, null भी हो सकता है)
// आउटपुट: ट्री की अधिकतम गहराई को दर्शाने वाला पूर्णांक लौटाता है
public int maxDepth(TreeNode root) {
    // बेस केस: यदि नोड नहीं है तो गहराई 0 है
    // लीफ नोड के चाइल्ड (null) तक पहुंचने पर पुनरावर्तन रुक जाता है
    if (root == null) return 0;

    // बाएं सबट्री की अधिकतम गहराई को पुनरावर्ती रूप से ज्ञात करना
    // बाएं चाइल्ड को रूट मानकर सबट्री पर समान प्रक्रिया दोहराई जाती है, अंततः बेस केस तक पहुंचकर मान लौटता है
    int left = maxDepth(root.left);

    // दाएं सबट्री की अधिकतम गहराई को पुनरावर्ती रूप से ज्ञात करना
    // बाएं के समान, दाएं चाइल्ड को रूट मानकर सबट्री की गहराई ज्ञात की जाती है
    int right = maxDepth(root.right);

    // बाएं और दाएं में से गहरे वाले में वर्तमान नोड के लिए 1 जोड़कर लौटाना
    // Math.max(left, right) सबसे लंबे पथ के नोड्स की संख्या वाले गहरे सबट्री को चुनता है
    // +1 वर्तमान नोड root स्वयं की गिनती है। पैरेंट नोड इस लौटाए गए मान को प्राप्त करके अपनी गणना में उपयोग करता है
    return 1 + Math.max(left, right);
}
```
