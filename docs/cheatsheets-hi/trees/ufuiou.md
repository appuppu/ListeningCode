# Checking if Two Binary Trees Are Identical — दो बाइनरी ट्री संरचना और मान दोनों में समान हैं या नहीं इसका निर्णय करना

## समस्या का सार

दो बाइनरी ट्री `p` और `q` दिए गए हैं। दो ट्री "समान" होने का अर्थ है कि उनकी संरचना पूरी तरह मेल खाती है और सभी संबंधित नोड्स के मान बराबर हैं। यदि समान हैं तो `true` लौटाएँ, अन्यथा `false` लौटाएँ।

## मूल विचार

दो ट्री के संबंधित नोड्स को "जोड़ी" के रूप में कतार में डालें और लेवल क्रम में एक-एक जोड़ी निकालकर तुलना करें। यदि सभी जोड़ियों में संरचना और मान मेल खाते हैं तो ट्री समान हैं, और यदि एक भी जोड़ी में बेमेल पाया जाए तो तुरंत असमान निर्णय दिया जा सकता है।

## विचार प्रक्रिया

1. **संबंधित नोड्स की आपस में तुलना करनी होगी**: दो ट्री समान हैं या नहीं यह निर्णय करने के लिए, ट्री में समान स्थिति पर स्थित नोड्स की एक-एक जोड़ी बनाकर तुलना करनी होगी। यदि सभी जोड़ियों में मान मेल खाते हैं और संरचना (चाइल्ड की उपस्थिति या अनुपस्थिति) भी मेल खाती है, तो दो ट्री समान हैं
2. **जोड़ियों का प्रबंधन कैसे करें**: तुलना करने योग्य नोड्स की जोड़ियों को क्रम में प्रबंधित करना आवश्यक है। कतार (FIFO) का उपयोग करने से, चौड़ाई-पहले (breadth-first) तरीके से लेवल के अनुसार जोड़ियाँ निकालकर तुलना की जा सकती है। कतार में `TreeNode[]` ऐरे (2 तत्व) संग्रहित किया जाता है, जहाँ `pair[0]` ट्री p का नोड और `pair[1]` ट्री q का नोड दर्शाता है
3. **जोड़ी निकालने पर क्या निर्णय करना है**: निकाली गई जोड़ी पर तीन स्थितियों का क्रमशः निर्णय करना होगा। (a) यदि दोनों null हैं तो संरचना मेल खाती है इसलिए अगली जोड़ी पर जाएँ, (b) यदि केवल एक null है तो संरचना भिन्न है इसलिए `false` लौटाएँ, (c) यदि दोनों non-null हैं लेकिन मान भिन्न हैं तो `false` लौटाएँ
4. **निर्णय पास होने पर चाइल्ड नोड्स की जोड़ियाँ कतार में जोड़ें**: यदि वर्तमान जोड़ी मेल खाती है, तो अगली तुलना बाएँ चाइल्ड की आपसी जोड़ी और दाएँ चाइल्ड की आपसी जोड़ी की करनी होगी। `{n1.left, n2.left}` और `{n1.right, n2.right}` की 2 जोड़ियाँ कतार में जोड़ें। चाइल्ड null होने पर भी जोड़ सकते हैं (चरण 3 की null जाँच सही ढंग से संभालती है)
5. **कतार खाली होने पर सभी जोड़ियाँ मेल खा गई हैं**: सभी जोड़ियों की तुलना पूरी होने पर यदि कोई बेमेल नहीं मिला, तो दो ट्री समान हैं इसलिए `true` लौटाएँ

## पूर्वापेक्षित ज्ञान

### Queue (कतार) क्या है

यह फर्स्ट-इन फर्स्ट-आउट (FIFO) डेटा संरचना है। सबसे पहले जोड़ा गया तत्व सबसे पहले निकाला जाता है। चौड़ाई-पहले खोज में नोड्स को लेवल क्रम में संसाधित करने के लिए इसका उपयोग किया जाता है। Java में `Queue` इंटरफ़ेस को `LinkedList` द्वारा कार्यान्वित किया जाता है।

```java
Queue<TreeNode[]> queue = new LinkedList<>();  // TreeNode ऐरे संग्रहित करने के लिए कतार बनाएँ
queue.add(new TreeNode[]{p, q});               // जोड़ी (2 तत्वों का ऐरे) को कतार के अंत में जोड़ें
TreeNode[] pair = queue.poll();                 // कतार के आरंभ से जोड़ी निकालकर लौटाएँ (कतार खाली हो तो null लौटाता है)
queue.isEmpty();                               // कतार खाली है या नहीं boolean में लौटाता है → true/false
```

### TreeNode (बाइनरी ट्री का नोड) क्या है

यह बाइनरी ट्री के प्रत्येक नोड को दर्शाने वाला क्लास है। `val` फ़ील्ड में नोड का मान, `left` और `right` फ़ील्ड में क्रमशः बाएँ चाइल्ड नोड और दाएँ चाइल्ड नोड का संदर्भ होता है। यदि चाइल्ड मौजूद नहीं है तो `null` होता है।

```java
TreeNode node = new TreeNode(5);   // मान 5 का नोड बनाएँ
node.val;                          // नोड का मान प्राप्त करें → 5
node.left;                         // बाएँ चाइल्ड नोड प्राप्त करें (नहीं है तो null)
node.right;                        // दाएँ चाइल्ड नोड प्राप्त करें (नहीं है तो null)
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n) — दो ट्री के अधिकतम n नोड्स की एक-एक बार तुलना करता है |
| Space | O(n) — कतार में अधिकतम नोड संख्या के अनुपात में जोड़ियाँ रखता है |

## कोड

```java
// इनपुट: दो बाइनरी ट्री के रूट नोड p और q
// आउटपुट: यदि दो ट्री संरचना और मान दोनों में समान हैं तो true, अन्यथा false लौटाता है
public boolean isSameTree(TreeNode p, TreeNode q) {
    // तुलना करने योग्य नोड्स की जोड़ियों को प्रबंधित करने के लिए कतार बनाएँ
    // जोड़ी को 2 तत्वों के TreeNode[] ऐरे के रूप में संग्रहित किया जाता है, जहाँ pair[0] ट्री p का नोड और pair[1] ट्री q का नोड दर्शाता है
    Queue<TreeNode[]> queue = new LinkedList<>();
    // प्रारंभिक अवस्था के रूप में, दो ट्री के रूट नोड्स की जोड़ी कतार में जोड़ें (सबसे पहले तुलना करने योग्य जोड़ी)
    queue.add(new TreeNode[]{p, q});

    // जब तक कतार खाली नहीं है, एक-एक जोड़ी निकालकर तुलना करें
    while (!queue.isEmpty()) {
        // कतार के आरंभ से जोड़ी निकालें
        TreeNode[] pair = queue.poll();
        TreeNode n1 = pair[0];
        TreeNode n2 = pair[1];

        // यदि दोनों null हैं, तो इस स्थिति पर दोनों ट्री में चाइल्ड मौजूद नहीं है इसलिए संरचना मेल खाती है। अगली जोड़ी पर जाएँ
        if (n1 == null && n2 == null)
            continue;
        // यदि केवल एक null है, तो एक ट्री में नोड मौजूद है और दूसरे में नहीं है इसलिए संरचना भिन्न है
        if (n1 == null || n2 == null)
            return false;
        // यदि मान भिन्न हैं तो संबंधित नोड्स के मान मेल नहीं खाते इसलिए false लौटाएँ
        if (n1.val != n2.val)
            return false;

        // वर्तमान जोड़ी मेल खा गई है, इसलिए अगली तुलना के लिए चाइल्ड नोड्स की जोड़ियाँ कतार में जोड़ें
        // चाइल्ड null होने पर भी वैसे ही जोड़ें (ऊपर की null जाँच सही ढंग से संभालती है)
        queue.add(new TreeNode[]{n1.left, n2.left});
        queue.add(new TreeNode[]{n1.right, n2.right});
    }
    // सभी जोड़ियों में संरचना और मान मेल खा गए इसलिए true लौटाएँ
    return true;
}
```
