# Inverting a Binary Tree — बाइनरी ट्री के सभी नोड्स में बाएँ और दाएँ चाइल्ड को स्वैप करना

## समस्या का सार

बाइनरी ट्री का रूट नोड `root` दिया गया है। ट्री के **सभी नोड्स** में बाएँ चाइल्ड और दाएँ चाइल्ड को स्वैप (इनवर्ट) करें, और इनवर्ट किए गए ट्री का रूट नोड लौटाएँ।

## मूल विचार

बाइनरी ट्री को इनवर्ट करने का अर्थ है सभी नोड्स में बाएँ और दाएँ चाइल्ड को स्वैप करना। BFS से लेवल क्रम में सभी नोड्स को विज़िट करें और प्रत्येक नोड में बाएँ-दाएँ चाइल्ड को स्वैप करें, तो पूरा ट्री इनवर्ट हो जाएगा।

## विचार प्रक्रिया

1. **इनवर्शन की परिभाषा को समझें**: बाइनरी ट्री का इनवर्शन केवल रूट नोड पर नहीं, बल्कि सभी नोड्स पर बाएँ चाइल्ड और दाएँ चाइल्ड को स्वैप करने की क्रिया है। अर्थात्, ट्री के सभी नोड्स को एक-एक बार विज़िट करके प्रत्येक नोड पर स्वैप करना होगा
2. **सभी नोड्स को विज़िट करने की विधि चुनें**: ट्री के सभी नोड्स को विज़िट करने के लिए BFS (ब्रेड्थ-फर्स्ट सर्च) का उपयोग करें। BFS क्यू का उपयोग करके लेवल क्रम में नोड्स को प्रोसेस करता है, इसलिए इसका कार्यान्वयन सहज और समझने में आसान है
3. **प्रत्येक नोड पर की जाने वाली क्रिया निर्धारित करें**: क्यू से निकाले गए प्रत्येक नोड के लिए, एक अस्थायी वेरिएबल का उपयोग करके `left` और `right` को स्वैप करें। स्वैप का क्रम कोई भी हो सकता है, और चाइल्ड null होने पर भी स्वैप में कोई समस्या नहीं होती
4. **चाइल्ड नोड्स को क्यू में जोड़ें**: स्वैप के बाद बाएँ और दाएँ चाइल्ड null नहीं हैं तो उन्हें क्यू में जोड़ें। इससे ट्री की निचली परतों के नोड्स भी क्रमशः विज़िट होंगे और सभी नोड्स पर स्वैप निष्पादित होगा
5. **अंत में क्या लौटाना है**: सभी नोड्स का स्वैप पूरा होने के बाद, मूल रूट नोड `root` को वैसे ही लौटाएँ। ट्री की संरचना बदल जाती है, लेकिन रूट नोड स्वयं वही ऑब्जेक्ट रहता है

## पूर्वापेक्षित ज्ञान

### बाइनरी ट्री (Binary Tree) क्या है

एक ट्री संरचना जिसमें प्रत्येक नोड अधिकतम 2 चाइल्ड (बायाँ चाइल्ड `left` और दायाँ चाइल्ड `right`) रखता है। नोड को `TreeNode` क्लास से दर्शाया जाता है, जिसमें `val` (मान), `left` (बायाँ चाइल्ड), और `right` (दायाँ चाइल्ड) फ़ील्ड होते हैं।

```java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

### Queue (क्यू) क्या है

फर्स्ट-इन फर्स्ट-आउट (FIFO) डेटा संरचना। जो तत्व पहले जोड़ा जाता है वह पहले निकाला जाता है। BFS में क्यू का उपयोग करके विज़िट किए जाने वाले नोड्स को प्रबंधित किया जाता है।

```java
Queue<TreeNode> queue = new LinkedList<>();  // खाली क्यू बनाएँ
queue.add(node);     // क्यू के अंत में node जोड़ें
queue.poll();        // क्यू के सामने से तत्व निकालकर लौटाएँ
queue.isEmpty();     // क्यू खाली है या नहीं boolean में लौटाएँ → true/false
```

### BFS (ब्रेड्थ-फर्स्ट सर्च) क्या है

ट्री या ग्राफ को "लेवल क्रम" में एक्सप्लोर करने वाला एल्गोरिदम। क्यू का उपयोग करके, वर्तमान नोड को प्रोसेस करने के बाद उसके चाइल्ड नोड्स को क्यू में जोड़ता है, जिससे उथली परतों से लेकर क्रमशः सभी नोड्स को विज़िट किया जाता है।

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n) — ट्री के सभी नोड्स को एक-एक बार विज़िट करता है |
| Space | O(n) — क्यू में अधिकतम n नोड्स संग्रहीत होते हैं |

## कोड

```java
// इनपुट: बाइनरी ट्री का रूट नोड root
// आउटपुट: सभी नोड्स के बाएँ-दाएँ चाइल्ड स्वैप करने के बाद रूट नोड root लौटाएँ
public TreeNode invertTree(TreeNode root) {
    // यदि ट्री खाली है तो null लौटाएँ। ट्री मौजूद नहीं है इसलिए वैसे ही समाप्त करें
    if (root == null) return null;

    // BFS के लिए क्यू बनाएँ और रूट नोड जोड़ें
    // यह क्यू उन नोड्स को प्रबंधित करता है जिन पर बाएँ-दाएँ स्वैप करना है
    Queue<TreeNode> queue = new LinkedList<>();
    queue.add(root);

    // जब तक क्यू खाली न हो (= सभी नोड्स प्रोसेस न हो जाएँ) तब तक दोहराएँ
    while (!queue.isEmpty()) {
        // क्यू के सामने से स्वैप करने वाला नोड निकालें
        TreeNode curr = queue.poll();

        // अस्थायी वेरिएबल का उपयोग करके बाएँ और दाएँ चाइल्ड को स्वैप करें
        // ध्यान दें: अस्थायी वेरिएबल के बिना सीधे असाइन करने पर एक संदर्भ ओवरराइट होकर खो जाएगा
        TreeNode temp = curr.left;
        curr.left = curr.right;
        curr.right = temp;

        // स्वैप के बाद चाइल्ड null नहीं हैं तो उन्हें क्यू में जोड़ें
        // null नोड्स के आगे कोई चाइल्ड नहीं होता इसलिए उन्हें जोड़ने की आवश्यकता नहीं है
        if (curr.left != null) queue.add(curr.left);
        if (curr.right != null) queue.add(curr.right);
    }

    // सभी नोड्स का स्वैप पूरा होने के बाद रूट नोड लौटाएँ
    // ट्री की संरचना बदल जाती है, लेकिन रूट नोड स्वयं वही ऑब्जेक्ट है
    return root;
}
```
