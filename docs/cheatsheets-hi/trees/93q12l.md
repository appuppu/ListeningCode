# Validating a Binary Search Tree — बाइनरी ट्री वैध बाइनरी सर्च ट्री है या नहीं, इसकी जाँच करना

## समस्या का सार

बाइनरी ट्री का `root` दिया गया है। यह निर्धारित करना है कि वह ट्री एक वैध बाइनरी सर्च ट्री (BST) है या नहीं। वैध BST का अर्थ है कि हर नोड में, बाएँ सबट्री के सभी मान उस नोड के मान से **सख्ती से छोटे** हों, और दाएँ सबट्री के सभी मान उस नोड के मान से **सख्ती से बड़े** हों।

## मूल विचार

हर नोड के पास "मान की वैध सीमा" होती है। रूट से रिकर्सिव रूप से नीचे जाते समय, बाएँ चाइल्ड के लिए ऊपरी सीमा और दाएँ चाइल्ड के लिए निचली सीमा को संकुचित करते जाएँ, तो एक ही ट्रैवर्सल में यह जाँचा जा सकता है कि सभी नोड BST की शर्तें पूरी करते हैं या नहीं।

## विचार प्रक्रिया

1. **केवल सीधे पैरेंट-चाइल्ड संबंध पर्याप्त नहीं हैं**: यदि हर नोड केवल अपने सीधे बाएँ चाइल्ड से बड़ा और दाएँ चाइल्ड से छोटा हो, तो यह BST की शर्त पूरी नहीं करता। बाएँ सबट्री के "सभी" नोड उस नोड से छोटे होने चाहिए। अर्थात, हर नोड पर पूर्वजों से विरासत में मिली बाध्यता लागू होती है
2. **हर नोड की वैध सीमा परिभाषित करना**: रूट कोई भी मान ले सकता है, इसलिए सीमा `(-∞, +∞)` से शुरू होती है। बाएँ चाइल्ड पर जाने पर ऊपरी सीमा पैरेंट के मान तक संकुचित होती है, और दाएँ चाइल्ड पर जाने पर निचली सीमा पैरेंट के मान तक संकुचित होती है। इस सीमा को रिकर्शन के आर्गुमेंट के रूप में पास करना होता है
3. **निर्णय शर्त तय करना**: हर नोड पर `node.val` `(lo, hi)` सीमा के अंदर है या नहीं, इसकी जाँच करनी होती है। BST में सख्त असमिका लागू होती है, इसलिए यदि `node.val <= lo` या `node.val >= hi` हो, तो उसे अमान्य माना जाता है
4. **रिकर्शन की संरचना तय करना**: बेस केस में `node == null` पर `true` लौटाया जाता है (खाली ट्री वैध BST है)। हर नोड पर अपने मान की जाँच करके, बाएँ और दाएँ चाइल्ड के लिए सीमा संकुचित करके रिकर्सिव कॉल की जाती है। केवल तभी `true` लौटाया जाता है जब बाएँ और दाएँ दोनों `true` लौटाएँ
5. **सीमा का प्रकार long रखना**: जब नोड का मान `Integer.MIN_VALUE` या `Integer.MAX_VALUE` हो, तो int प्रकार की सीमा से प्रारंभिक मान को व्यक्त नहीं किया जा सकता। `Long.MIN_VALUE` और `Long.MAX_VALUE` को प्रारंभिक सीमा के रूप में उपयोग करने से सभी int मानों की सही जाँच की जा सकती है
6. **अंतिम रूप से लौटाया जाने वाला मान**: रूट से रिकर्शन शुरू करके, यदि सभी नोड वैध सीमा के अंदर हों तो `true` लौटाया जाता है, और यदि एक भी उल्लंघन हो तो `false` लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### बाइनरी सर्च ट्री (BST) क्या है

बाइनरी सर्च ट्री ऐसा बाइनरी ट्री है जिसमें हर नोड के लिए, बाएँ सबट्री के सभी मान उस नोड के मान से छोटे होते हैं और दाएँ सबट्री के सभी मान उस नोड के मान से बड़े होते हैं। यह गुण केवल सीधे चाइल्ड पर ही नहीं, बल्कि पूरे सबट्री पर लागू होता है।

```
      5
     / \
    3   7     ← वैध BST: 3<5, 7>5, 1<3, 4>3 और 4<5, 6>5 और 6<7
   / \   \
  1   4   8
```

### रिकर्शन द्वारा सीमा का संकुचन

पैरेंट से चाइल्ड पर जाने पर वैध मान की सीमा संकुचित होने की प्रक्रिया:

```
नोड 5: सीमा (-∞, +∞)
├─ बायाँ चाइल्ड 3: सीमा (-∞, 5)  ← ऊपरी सीमा पैरेंट के मान 5 तक संकुचित होती है
│  ├─ बायाँ चाइल्ड 1: सीमा (-∞, 3)
│  └─ दायाँ चाइल्ड 4: सीमा (3, 5)  ← निचली सीमा 3 और ऊपरी सीमा 5
└─ दायाँ चाइल्ड 7: सीमा (5, +∞)  ← निचली सीमा पैरेंट के मान 5 तक संकुचित होती है
```

### long प्रकार का उपयोग करने का कारण

Java में `int` की सीमा `-2147483648` से `2147483647` तक है। प्रारंभिक सीमा के रूप में "int प्रकार का कोई भी मान स्वीकार्य हो" यह व्यक्त करने के लिए, int की सीमा से बाहर के मान की आवश्यकता होती है। `long` प्रकार का उपयोग करने पर `Long.MIN_VALUE` और `Long.MAX_VALUE` से पर्याप्त विस्तृत प्रारंभिक सीमा सेट की जा सकती है।

```java
long lo = Long.MIN_VALUE;  // int के किसी भी मान से छोटा
long hi = Long.MAX_VALUE;  // int के किसी भी मान से बड़ा
node.val <= lo;            // node.val int प्रकार है, इसलिए यह Long.MIN_VALUE से बड़ा होने की गारंटी है
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — हर नोड को एक बार विज़िट किया जाता है |
| Space | O(h) — रिकर्शन कॉल स्टैक की गहराई ट्री की ऊँचाई h के अनुपात में होती है (सबसे खराब स्थिति O(n), संतुलित ट्री में O(log n)) |

## कोड

```java
// इनपुट: बाइनरी ट्री का रूट नोड root
// आउटपुट: ट्री वैध BST हो तो true, अन्यथा false
public boolean isValidBST(TreeNode root) {
    // प्रारंभिक सीमा को Long.MIN_VALUE/MAX_VALUE पर सेट करना ताकि रूट नोड int प्रकार का कोई भी मान ले सके
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

// lo, hi long प्रकार के हैं। int प्रकार से Integer.MIN_VALUE/MAX_VALUE को प्रारंभिक मान के रूप में उपयोग नहीं किया जा सकता
boolean validate(TreeNode node, long lo, long hi) {
    // बेस केस: खाली नोड BST की शर्त का उल्लंघन नहीं करता
    if (node == null) return true;

    // यदि वर्तमान नोड का मान वैध सीमा (lo, hi) से बाहर हो तो अमान्य है
    // BST में समान मान भी स्वीकार्य नहीं हैं, इसलिए <= और >= से सख्ती से जाँच की जाती है
    if (node.val <= lo || node.val >= hi) return false;

    // बायाँ सबट्री: ऊपरी सीमा को node.val तक संकुचित करना (बाएँ के सभी मान node.val से छोटे होने चाहिए)। निचली सीमा lo पूर्वज की बाध्यता बनाए रखती है
    // दायाँ सबट्री: निचली सीमा को node.val तक संकुचित करना (दाएँ के सभी मान node.val से बड़े होने चाहिए)। ऊपरी सीमा hi पूर्वज की बाध्यता बनाए रखती है
    // केवल तभी जब बायाँ और दायाँ दोनों true हों, यह पूरा सबट्री वैध BST होता है
    return validate(node.left, lo, node.val)
        && validate(node.right, node.val, hi);
}
```
