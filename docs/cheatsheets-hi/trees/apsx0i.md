# Traversing a Binary Tree Level by Level — बाइनरी ट्री के नोड्स को लेवल के अनुसार अलग करके सूची बनाना

## समस्या का सार

बाइनरी ट्री का `root` दिया गया है। ट्री के नोड्स को **लेवल (गहराई) के अनुसार** समूहित करें, और प्रत्येक लेवल के नोड मानों को बाएं से दाएं क्रम में संग्रहित `List<Integer>` को, ऊपरी लेवल से क्रम में सजाकर `List<List<Integer>>` के रूप में लौटाएं।

## मूल विचार

Queue का उपयोग करने से नोड्स को "चौड़ाई-पहले" क्रम में बाएं से दाएं प्रोसेस किया जा सकता है। प्रत्येक लेवल की शुरुआत में Queue का आकार रिकॉर्ड करके, उतनी ही संख्या में नोड्स निकालने से लेवल की सीमा को सटीक रूप से प्रबंधित किया जा सकता है।

## विचार प्रक्रिया

1. **लेवल के अनुसार प्रोसेस करने के लिए चौड़ाई-पहले खोज (BFS) उपयुक्त है**: गहराई-पहले खोज (DFS) एक शाखा को गहराई तक पार करती है, इसलिए लेवल-आधारित समूहीकरण कठिन होता है। BFS नोड्स को उथले क्रम में प्रोसेस करता है, इसलिए यह लेवल-दर-लेवल ट्रैवर्सल के लिए स्वाभाविक रूप से उपयुक्त है
2. **BFS को लागू करने के लिए Queue का उपयोग करें**: Queue एक FIFO (पहले आया पहले गया) डेटा संरचना है, और "पहले जोड़े गए (उथले) नोड से क्रम में प्रोसेस करना" — BFS की इस क्रिया को Queue द्वारा साकार किया जा सकता है
3. **लेवल की सीमा कैसे निर्धारित करें**: प्रत्येक लेवल की प्रोसेसिंग शुरू करने के समय, Queue में मौजूद सभी नोड एक ही लेवल से संबंधित होते हैं। इस समय `queue.size()` को `size` वेरिएबल में रिकॉर्ड करके, `size` बार नोड निकालने से ठीक एक लेवल के नोड्स प्रोसेस किए जा सकते हैं
4. **निकाले गए नोड के बच्चों को अगले लेवल के रूप में Queue में जोड़ें**: प्रत्येक नोड निकालते समय, उसके बाएं और दाएं बच्चे नोड्स को Queue में जोड़ें। ये बच्चे नोड वर्तमान लेवल की प्रोसेसिंग के दौरान नहीं निकाले जाते (`size` द्वारा संख्या सीमित होने के कारण)। अगले while लूप इटरेशन में इन्हें अगले लेवल के रूप में प्रोसेस किया जाता है
5. **प्रत्येक लेवल के परिणाम को सूची में एकत्र करके लौटाएं**: प्रत्येक लेवल के लिए `List<Integer>` बनाएं और उस लेवल के नोड मान संग्रहित करें। एक लेवल की प्रोसेसिंग पूरी होने पर, इस सूची को अंतिम परिणाम `List<List<Integer>>` में जोड़ें
6. **Queue खाली होने पर सभी लेवलों की प्रोसेसिंग पूर्ण होती है**: सभी नोड्स निकाल लेने पर Queue खाली हो जाती है और while लूप समाप्त होता है। इस समय परिणाम सूची में ऊपरी लेवल से क्रम में सभी लेवलों के नोड मान संग्रहित होते हैं

## पूर्व ज्ञान

### Queue (क्यू) क्या है

पहले आया पहले गया (FIFO) डेटा संरचना। सबसे पहले जोड़ा गया तत्व सबसे पहले निकाला जाता है। Java में Queue इंटरफेस के कार्यान्वयन के रूप में LinkedList का उपयोग किया जाता है।

```java
Queue<TreeNode> queue = new LinkedList<>();  // खाली Queue बनाएं
queue.offer(node);   // Queue के अंत में node जोड़ें
queue.poll();        // Queue के आरंभ से तत्व निकालकर लौटाएं (Queue से हटाया जाता है)
queue.size();        // Queue में मौजूद तत्वों की संख्या लौटाता है → int
queue.isEmpty();     // Queue खाली है या नहीं boolean के रूप में लौटाता है
```

### BFS (चौड़ाई-पहले खोज) क्या है

ग्राफ या ट्री को "चौड़ाई" दिशा में खोजने का एल्गोरिदम। शुरुआती बिंदु के निकट नोड्स से क्रम में प्रोसेस करता है। Queue का उपयोग करके लागू किया जाता है। ट्री पर लागू करने पर, लेवल 0→लेवल 1→लेवल 2… के क्रम में नोड्स को विज़िट किया जाता है।

### TreeNode की संरचना

बाइनरी ट्री के प्रत्येक नोड को दर्शाने वाला क्लास। इसमें मान `val`, बायां बच्चा `left`, और दायां बच्चा `right` — ये तीन फील्ड होते हैं।

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — ट्री के सभी नोड्स को एक-एक बार प्रोसेस किया जाता है |
| Space | O(n) — Queue में अधिकतम ट्री के सबसे चौड़े लेवल के नोड्स की संख्या तक संग्रहित होता है (सबसे खराब स्थिति में n/2) |

## कोड

```java
// इनपुट: बाइनरी ट्री का रूट नोड root
// आउटपुट: प्रत्येक लेवल के नोड मानों को सूची में संग्रहित List<List<Integer>> लौटाता है
List<List<Integer>> levelOrder(TreeNode root) {
    // प्रत्येक लेवल की नोड मान सूची को संग्रहित करने वाला अंतिम परिणाम
    List<List<Integer>> result = new ArrayList<>();

    // यदि root null है तो ट्री खाली है, इसलिए खाली result को वैसे ही लौटाएं
    if (root == null) return result;

    // BFS के लिए Queue बनाएं और रूट नोड जोड़ें
    // इस समय Queue में लेवल 0 का केवल एक नोड है
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    // Queue खाली होने तक लेवल के अनुसार प्रोसेसिंग दोहराएं
    // Queue खाली होने पर सभी नोड्स की प्रोसेसिंग पूर्ण हो चुकी होती है
    while (!queue.isEmpty()) {
        // ध्यान दें: इस मान को लूप से पहले वेरिएबल में सहेजना आवश्यक है
        // for लूप के अंदर Queue में बच्चे नोड जोड़ने से Queue का आकार बदल जाता है,
        // इसलिए queue.size() को सीधे for लूप की शर्त में उपयोग करने पर सही लेवल सीमा नहीं बनती
        int size = queue.size();
        // वर्तमान लेवल के नोड मानों को संग्रहित करने वाली सूची
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < size; i++) {
            // Queue के आरंभ से नोड निकालें
            TreeNode node = queue.poll();
            // नोड का मान वर्तमान लेवल की सूची में जोड़ें
            level.add(node.val);

            // यदि बायां बच्चा मौजूद है तो Queue में जोड़ें (अगले लेवल में प्रोसेस होगा)
            if (node.left != null)
                queue.offer(node.left);
            // यदि दायां बच्चा मौजूद है तो Queue में जोड़ें
            // बच्चे नोड्स को बाएं→दाएं क्रम में जोड़ने से, अगले लेवल में भी नोड्स बाएं से दाएं क्रम में प्रोसेस होते हैं
            if (node.right != null)
                queue.offer(node.right);
        }

        // एक लेवल की प्रोसेसिंग पूर्ण हुई इसलिए परिणाम में जोड़ें
        result.add(level);
    }
    // सभी लेवलों के नोड मान ऊपर से क्रम में संग्रहित result को लौटाएं
    return result;
}
```
