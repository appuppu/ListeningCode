# Counting Good Nodes in a Binary Tree — बाइनरी ट्री में "अच्छे नोड" की संख्या गिनना

## समस्या का सार

एक बाइनरी ट्री दिया गया है। रूट से किसी नोड तक के पथ पर मौजूद सभी मानों में, यदि उस नोड का मान अधिकतम मान के बराबर या उससे अधिक है, तो उसे "अच्छा नोड (good node)" माना जाता है। पूरे ट्री में अच्छे नोड्स की कुल संख्या लौटानी है।

## मूल विचार

रूट से प्रत्येक नोड की ओर जाते समय "अब तक का अधिकतम मान" साथ ले जाएं, तो प्रत्येक नोड अच्छा नोड है या नहीं यह O(1) में निर्धारित किया जा सकता है। DFS से ट्री को ट्रैवर्स करते हुए अधिकतम मान को चाइल्ड नोड्स तक प्रसारित करें, तो सभी नोड्स को केवल एक बार विज़िट करके उत्तर प्राप्त हो जाता है।

## विचार प्रक्रिया

1. **निर्धारण शर्त को समझना**: कोई नोड अच्छा नोड है या नहीं, यह केवल रूट से उस नोड तक के पथ पर अधिकतम मान से तुलना करके तय होता है। अर्थात, पथ पर का अधिकतम मान पता हो तो निर्धारण संभव है
2. **पथ पर के अधिकतम मान का प्रबंधन कैसे करें**: DFS से ट्री को ट्रैवर्स करने पर, रिकर्शन का कॉल स्टैक रूट से वर्तमान नोड तक के पथ के संगत होता है। रिकर्शन के आर्ग्युमेंट के रूप में "अब तक का अधिकतम मान" पास करें, तो प्रत्येक नोड पर निर्धारण के लिए आवश्यक जानकारी उपलब्ध हो जाती है
3. **प्रत्येक नोड पर प्रोसेसिंग तय करना**: यदि वर्तमान नोड का मान अधिकतम मान के बराबर या अधिक है तो अच्छा नोड है इसलिए 1 जोड़ें, अन्यथा 0 जोड़ें। इससे निर्धारण और गिनती एक साथ हो जाती है
4. **चाइल्ड नोड को पास करने वाले अधिकतम मान को अपडेट करना**: चाइल्ड नोड को पास करने वाला अधिकतम मान, वर्तमान अधिकतम मान और वर्तमान नोड के मान में से जो बड़ा हो वह होगा। इससे पथ बढ़ने के साथ अधिकतम मान मोनोटोनिक नॉन-डिक्रीसिंग रूप से अपडेट होता है
5. **बाएं और दाएं सबट्री को रिकर्सिव रूप से प्रोसेस करना**: बाएं सबट्री के अच्छे नोड्स की संख्या और दाएं सबट्री के अच्छे नोड्स की संख्या रिकर्शन से प्राप्त करें, और वर्तमान नोड के परिणाम के साथ जोड़कर लौटाएं
6. **प्रारंभिक कॉल का अधिकतम मान**: रूट नोड हमेशा अच्छा नोड होता है (पथ पर केवल स्वयं ही होता है)। प्रारंभिक मान को `Integer.MIN_VALUE` रखने से, रूट का मान निश्चित रूप से उससे अधिक या बराबर होता है, इसलिए सही निर्धारण होता है

## पूर्वापेक्षित ज्ञान

### रिकर्सिव DFS (डेप्थ फर्स्ट सर्च) क्या है

ट्री या ग्राफ को गहराई की दिशा में प्राथमिकता देकर ट्रैवर्स करने वाला एल्गोरिदम। बाइनरी ट्री में, रिकर्सिव फंक्शन स्वयं को बाएं चाइल्ड और दाएं चाइल्ड के लिए कॉल करके इसे क्रियान्वित करता है। रिकर्शन का कॉल स्टैक रूट से वर्तमान नोड तक के पथ को अंतर्निहित रूप से बनाए रखता है।

```java
void dfs(TreeNode node) {
    if (node == null) return;  // बेस केस: null नोड पर पहुंचने पर वापस लौटें
    // वर्तमान नोड पर प्रोसेसिंग करें
    dfs(node.left);            // बाएं सबट्री को रिकर्सिव रूप से ट्रैवर्स करें
    dfs(node.right);           // दाएं सबट्री को रिकर्सिव रूप से ट्रैवर्स करें
}
```

### Math.max क्या है

दो मानों में से बड़ा मान लौटाने वाला मेथड। पथ पर के अधिकतम मान को अपडेट करते समय इसका उपयोग किया जाता है।

```java
Math.max(5, 3);    // → 5（5 और 3 में से बड़ा मान लौटाता है）
Math.max(-1, 4);   // → 4
```

### Integer.MIN_VALUE क्या है

Java के `int` प्रकार का न्यूनतम संभव मान (-2,147,483,648)। किसी भी नोड का मान इससे अधिक या बराबर होता है, इसलिए इसे प्रारंभिक अधिकतम मान के रूप में उपयोग करने पर रूट नोड निश्चित रूप से अच्छा नोड निर्धारित होता है।

```java
Integer.MIN_VALUE;  // → -2147483648（int प्रकार का न्यूनतम मान）
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n) — सभी नोड्स को एक बार विज़िट किया जाता है |
| Space | O(h) — रिकर्शन का कॉल स्टैक ट्री की ऊंचाई के बराबर उपयोग होता है |

## कोड

```java
// इनपुट: बाइनरी ट्री का रूट नोड root
// आउटपुट: अच्छे नोड्स की कुल संख्या int के रूप में लौटाएं

// हेल्पर फंक्शन: node को रूट मानकर उस सबट्री में अच्छे नोड्स की संख्या लौटाता है
// maxSoFar रूट से वर्तमान नोड तक के पथ पर अधिकतम मान को दर्शाता है
private int dfs(TreeNode node, int maxSoFar) {
    // बेस केस: null पर पहुंचने पर अच्छे नोड 0 हैं (लीफ नोड के आगे कोई गिनने योग्य नोड नहीं है)
    if (node == null) return 0;

    // वर्तमान नोड अच्छा नोड है या नहीं यह निर्धारित करें (पथ पर के अधिकतम मान के बराबर या अधिक हो तो अच्छा नोड है)
    int result = node.val >= maxSoFar ? 1 : 0;

    // चाइल्ड नोड को पास करने वाले अधिकतम मान को अपडेट करें (वर्तमान नोड का मान बड़ा हो तो अपडेट करें, अन्यथा पुराना अधिकतम मान यथावत रखें)
    int newMax = Math.max(maxSoFar, node.val);

    // बाएं सबट्री के अच्छे नोड्स की संख्या रिकर्सिव रूप से प्राप्त करके जोड़ें
    result += dfs(node.left, newMax);
    // दाएं सबट्री के अच्छे नोड्स की संख्या रिकर्सिव रूप से प्राप्त करके जोड़ें
    result += dfs(node.right, newMax);

    // वर्तमान नोड को रूट मानकर पूरे सबट्री के अच्छे नोड्स की संख्या लौटाएं
    return result;
}

public int goodNodes(TreeNode root) {
    // प्रारंभिक अधिकतम मान को int का न्यूनतम मान रखने से, रूट नोड निश्चित रूप से अच्छा नोड निर्धारित होता है
    return dfs(root, Integer.MIN_VALUE);
}
```
