# Calculating Network Signal Propagation Time — पूरे नेटवर्क में सिग्नल पहुँचने का न्यूनतम समय ज्ञात करना

## समस्या का सार

`n` नोड (1 से n) और भारित दिशात्मक किनारों की सूची `times` (प्रत्येक किनारा `[स्रोत, गंतव्य, लगने वाला समय]`) दी गई है। निर्दिष्ट स्रोत नोड `k` से सिग्नल भेजने पर, सभी नोड तक सिग्नल पहुँचने का न्यूनतम समय लौटाना है। यदि एक भी नोड तक पहुँचना संभव न हो तो `-1` लौटाना है।

## मूल विचार

"सभी नोड तक पहुँचने का न्यूनतम समय" "प्रत्येक नोड तक की न्यूनतम दूरी में से अधिकतम दूरी" के बराबर है। डिज्क्स्ट्रा एल्गोरिदम से सभी नोड तक की न्यूनतम दूरी ज्ञात करके, उनमें से अधिकतम मान लेना है।

## विचार प्रक्रिया

1. **समस्या को न्यूनतम पथ समस्या के रूप में समझना**: सिग्नल स्रोत नोड से प्रत्येक किनारे के माध्यम से प्रसारित होता है। प्रत्येक नोड तक सिग्नल पहुँचने का समय, स्रोत से उस नोड तक की न्यूनतम दूरी के बराबर है। इसलिए, एकल स्रोत न्यूनतम पथ समस्या को हल करना है
2. **सभी नोड तक की न्यूनतम दूरी कुशलतापूर्वक ज्ञात करना**: किनारों का भार अऋणात्मक है, इसलिए डिज्क्स्ट्रा एल्गोरिदम लागू किया जा सकता है। डिज्क्स्ट्रा एल्गोरिदम प्राथमिकता कतार (min-heap) का उपयोग करता है और न्यूनतम दूरी वाले नोड से लालची (greedy) तरीके से निर्धारित करता है
3. **ग्राफ का प्रतिनिधित्व तय करना**: आसन्नता सूची (adjacency list) का उपयोग करना है। प्रत्येक नोड के लिए "आसन्न नोड और उस किनारे का भार" की जोड़ी को सूची में रखना है। इससे किसी नोड से निकलने वाले किनारों को कुशलतापूर्वक सूचीबद्ध किया जा सकता है
4. **दूरी सरणी को प्रारंभ करना**: सभी नोड की दूरी को अनंत (`Integer.MAX_VALUE`) से प्रारंभ करना है और स्रोत नोड `k` की दूरी को 0 रखना है। क्योंकि स्रोत से स्वयं तक की दूरी 0 है
5. **प्राथमिकता कतार से न्यूनतम दूरी वाले नोड को संसाधित करना**: कतार से न्यूनतम दूरी वाले नोड को निकालना है और उस नोड के आसन्न नोड की दूरी को अद्यतन (शिथिलन/relaxation) करना है। यदि अद्यतन हो तो कतार में जोड़ना है
6. **पुनरावृत्त संसाधन को छोड़ना**: कतार से निकाले गए नोड की दूरी यदि वर्तमान न्यूनतम दूरी से अधिक हो, तो वह पहले से बेहतर पथ से संसाधित हो चुका है इसलिए उसे छोड़ना है। इससे अनावश्यक गणना से बचा जा सकता है
7. **सभी नोड की न्यूनतम दूरी से उत्तर ज्ञात करना**: सभी नोड की दूरी सरणी को जाँचना है। यदि कोई नोड अनंत रहा हो तो वह पहुँच योग्य नहीं है इसलिए `-1` लौटाना है। अन्यथा दूरी का अधिकतम मान उत्तर है

## पूर्वापेक्षित ज्ञान

### आसन्नता सूची (Adjacency List) क्या है

ग्राफ को प्रदर्शित करने की एक डेटा संरचना है। प्रत्येक नोड के लिए "उस नोड से निकलने वाले किनारों की सूची" को एक सूची में रखा जाता है। नोड संख्या `n` के लिए `List<List<int[]>>` से प्रदर्शित किया जाता है और `graph.get(u)` से नोड `u` से निकलने वाले किनारे प्राप्त किए जाते हैं।

```java
List<List<int[]>> graph = new ArrayList<>();
for (int i = 0; i <= n; i++) {
    graph.add(new ArrayList<>());       // प्रत्येक नोड के लिए खाली सूची बनाना
}
graph.get(1).add(new int[]{2, 5});      // नोड1→नोड2, भार 5 का किनारा जोड़ना
graph.get(1).add(new int[]{3, 2});      // नोड1→नोड3, भार 2 का किनारा जोड़ना
```

### PriorityQueue (प्राथमिकता कतार) क्या है

तत्वों को जोड़ने के क्रम से स्वतंत्र, हमेशा न्यूनतम (या अधिकतम) तत्व को शीर्ष पर रखने वाली डेटा संरचना है। डिज्क्स्ट्रा एल्गोरिदम में "न्यूनतम दूरी वाले नोड" को कुशलतापूर्वक निकालने के लिए इसका उपयोग किया जाता है।

```java
// int[] के पहले तत्व (दूरी) के आरोही क्रम में व्यवस्थित min-heap
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{0, 1});   // {दूरी 0, नोड 1} को कतार में जोड़ना
pq.offer(new int[]{5, 2});   // {दूरी 5, नोड 2} को कतार में जोड़ना
int[] curr = pq.poll();       // न्यूनतम दूरी वाला तत्व {0, 1} को निकालना
pq.isEmpty();                 // कतार खाली है या नहीं, boolean में लौटाना
```

### डिज्क्स्ट्रा एल्गोरिदम का शिथिलन (Relaxation) क्या है

किसी नोड `u` से होकर नोड `v` तक पहुँचने की दूरी `dist[u] + w` यदि वर्तमान `dist[v]` से कम हो, तो `dist[v]` को छोटे मान से अद्यतन करने की प्रक्रिया है। इस अद्यतन को बार-बार दोहराने से अंततः सभी नोड तक की न्यूनतम दूरी निर्धारित हो जाती है।

```java
int newDist = dist[u] + w;      // u से होकर v तक जाने की दूरी की गणना करना
if (newDist < dist[v]) {        // यदि वर्तमान न्यूनतम दूरी से कम हो
    dist[v] = newDist;          // न्यूनतम दूरी को अद्यतन करना
    pq.offer(new int[]{newDist, v});  // अद्यतन किए गए v को कतार में जोड़ना
}
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O((V + E) log V) — प्रत्येक नोड और प्रत्येक किनारे के लिए प्राथमिकता कतार की संक्रिया (log V) की जाती है |
| Space | O(V + E) — आसन्नता सूची में सभी किनारे संग्रहीत किए जाते हैं, और दूरी सरणी तथा कतार में नोड संख्या जितनी स्थान का उपयोग होता है |

## कोड

```java
// इनपुट: दिशात्मक किनारा सूची int[][] times (प्रत्येक तत्व [आरंभ बिंदु, अंत बिंदु, भार]), नोड संख्या int n, स्रोत नोड int k
// आउटपुट: स्रोत से सभी नोड तक सिग्नल पहुँचने का न्यूनतम समय int में लौटाना। यदि कोई नोड पहुँच योग्य न हो तो -1 लौटाना
public int networkDelayTime(int[][] times, int n, int k) {
    // आसन्नता सूची बनाना (नोड संख्या 1 से शुरू होती है, इसलिए आकार n+1 रखना और इंडेक्स 0 अप्रयुक्त रखना)
    List<List<int[]>> graph = new ArrayList<>();
    for (int i = 0; i <= n; i++) {
        graph.add(new ArrayList<>());
    }
    // प्रत्येक किनारे [u, v, w] को आसन्नता सूची में पंजीकृत करके, दिशात्मक ग्राफ की आसन्नता सूची प्रतिनिधित्व पूरा करना
    for (int[] t : times) {
        graph.get(t[0]).add(new int[]{t[1], t[2]});
    }

    // दूरी सरणी को अनंत से प्रारंभ करना। dist[i] "स्रोत से नोड i तक की वर्तमान न्यूनतम दूरी" को दर्शाता है
    int[] dist = new int[n + 1];
    Arrays.fill(dist, Integer.MAX_VALUE);
    // स्रोत नोड से स्वयं तक की दूरी 0 है
    dist[k] = 0;

    // दूरी (पहला तत्व) के आरोही क्रम में निकालने वाला min-heap बनाना और स्रोत नोड {दूरी 0, नोड k} को जोड़ना
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, k});

    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int d = curr[0];  // स्रोत से नोड u तक की दूरी
        int u = curr[1];  // वर्तमान में संसाधित किया जा रहा नोड

        // यदि d > dist[u] हो, तो पहले से छोटी दूरी से संसाधित हो चुका है। कतार में पुराना (अधिक दूरी वाला) प्रविष्टि शेष रहने पर यह स्थिति उत्पन्न होती है
        if (d > dist[u]) continue;

        // आसन्न नोड के लिए शिथिलन का प्रयास करना
        for (int[] nei : graph.get(u)) {
            int v = nei[0];  // आसन्न नोड
            int w = nei[1];  // किनारे का भार
            // u से होकर जाने की दूरी d + w यदि वर्तमान dist[v] से कम हो, तो दूरी को अद्यतन करके कतार में जोड़ना
            if (d + w < dist[v]) {
                dist[v] = d + w;
                pq.offer(new int[]{d + w, v});
            }
        }
    }

    // सभी नोड की न्यूनतम दूरी में से अधिकतम मान ज्ञात करना। यह अधिकतम मान "सभी नोड तक सिग्नल पहुँचने का न्यूनतम समय" है
    int max = 0;
    for (int i = 1; i <= n; i++) {
        // यदि Integer.MAX_VALUE बना रहे तो पहुँच योग्य नहीं नोड मौजूद है, इसलिए -1 लौटाना
        if (dist[i] == Integer.MAX_VALUE) return -1;
        max = Math.max(max, dist[i]);
    }
    return max;
}
```
