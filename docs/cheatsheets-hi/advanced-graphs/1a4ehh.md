# Finding the Cheapest Flight With Limited Stops — अधिकतम k बार ट्रांसफर के साथ सबसे सस्ती उड़ान खोजना

## समस्या का सार

`n` शहर, उड़ानों की सूची `[from, to, price]`, प्रस्थान स्थान `src`, गंतव्य `dst`, और अधिकतम ट्रांसफर संख्या `k` दिए गए हैं। प्रस्थान स्थान से गंतव्य तक **अधिकतम k बार ट्रांसफर** (मध्यवर्ती शहर k या उससे कम) के साथ पहुँचने योग्य सबसे सस्ता कुल किराया लौटाएँ। यदि पहुँचना संभव नहीं है तो `-1` लौटाएँ।

## मूल विचार

सामान्य Dijkstra केवल न्यूनतम लागत वाले पथ को ट्रैक करता है, लेकिन इस समस्या में "लागत अधिक होने पर भी कम ट्रांसफर वाला पथ" अंततः सबसे सस्ता मार्ग बन सकता है। इसलिए, प्रत्येक शहर तक पहुँचने की "न्यूनतम ट्रांसफर संख्या" को रिकॉर्ड किया जाता है, और केवल कम ट्रांसफर से पहुँचने वाले पथों को खोज के दायरे में रखा जाता है, जिससे लागत और ट्रांसफर संख्या दोनों को ध्यान में रखते हुए इष्टतम समाधान प्राप्त होता है।

## विचार प्रक्रिया

1. **सबसे सस्ते मार्ग की खोज के लिए Dijkstra आधारभूत है**: यह भारित ग्राफ की सबसे छोटे पथ की समस्या है, इसलिए प्राथमिकता कतार (priority queue) का उपयोग करने वाला Dijkstra मूल दृष्टिकोण है। लागत के बढ़ते क्रम में नोड निकालने से, गंतव्य तक पहली बार पहुँचने पर वही सबसे सस्ता होता है
2. **ट्रांसफर संख्या की बाधा को कैसे संभालें**: सामान्य Dijkstra में "न्यूनतम लागत से पहुँचे हुए शहर को दोबारा नहीं जाते", लेकिन इस समस्या में ट्रांसफर संख्या की बाधा है। न्यूनतम लागत से पहुँचा पथ यदि k बार से अधिक ट्रांसफर करता है तो वह अमान्य है, और थोड़ी अधिक लागत वाला लेकिन कम ट्रांसफर वाला पथ मान्य हो सकता है
3. **प्रत्येक शहर तक "न्यूनतम ट्रांसफर संख्या" रिकॉर्ड करें**: `stops[]` सरणी तैयार करें और प्रत्येक शहर तक पहुँचने की न्यूनतम ट्रांसफर संख्या रिकॉर्ड करें। यदि किसी शहर तक पहले से अधिक ट्रांसफर संख्या से पहुँचते हैं, तो वह पथ लागत और ट्रांसफर संख्या दोनों में सुधार नहीं करता, इसलिए उसे छाँटा (prune) जा सकता है
4. **प्राथमिकता कतार में क्या संग्रहित करें**: प्रत्येक स्थिति को `[लागत, शहर, ट्रांसफर संख्या]` के त्रिक के रूप में प्रबंधित करें। लागत के बढ़ते क्रम में निकालने से, गंतव्य तक पहली बार पहुँचने पर वह समाधान सबसे सस्ता होता है
5. **छँटाई (pruning) की शर्तें व्यवस्थित करें**: (a) यदि वर्तमान ट्रांसफर संख्या उस शहर की रिकॉर्ड की गई न्यूनतम ट्रांसफर संख्या के बराबर या अधिक है, तो खोज रोक दें। (b) यदि ट्रांसफर संख्या k से अधिक है, तो आगे के पड़ोसी शहरों में विस्तार न करें
6. **पड़ोसी शहरों में विस्तार**: केवल छँटाई को पास करने पर, प्रत्येक पड़ोसी शहर के लिए `[वर्तमान लागत + किराया, पड़ोसी शहर, ट्रांसफर संख्या + 1]` को कतार में जोड़ें

## पूर्वापेक्षित ज्ञान

### आसन्नता सूची (Adjacency List) क्या है

यह एक डेटा संरचना है जो ग्राफ के प्रत्येक शीर्ष के लिए, वहाँ से सीधे जा सकने वाले शीर्षों और किनारों के भार को सूची में रखती है। इसे `HashMap<Integer, List<int[]>>` से व्यक्त किया जाता है, जहाँ कुंजी प्रस्थान शहर है और मान `[आगमन शहर, किराया]` की सूची है।

```java
Map<Integer, List<int[]>> adj = new HashMap<>();
// शहर 0 से शहर 1 तक किराया 100 की उड़ान जोड़ें
adj.computeIfAbsent(0, x -> new ArrayList<>()).add(new int[]{1, 100});
// शहर 0 की आसन्नता सूची प्राप्त करें
List<int[]> neighbors = adj.get(0);  // → [[1, 100]]
```

### PriorityQueue (प्राथमिकता कतार) क्या है

यह एक डेटा संरचना है जो तत्व जोड़ने पर आंतरिक रूप से स्वचालित क्रमबद्ध करती है और हमेशा सबसे छोटे (या सबसे बड़े) तत्व को सामने से निकालने की अनुमति देती है। Dijkstra में "न्यूनतम लागत वाली स्थिति" को कुशलतापूर्वक निकालने के लिए इसका उपयोग किया जाता है।

```java
// int[] के पहले तत्व (लागत) के बढ़ते क्रम में क्रमबद्ध प्राथमिकता कतार
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{100, 1, 0});   // [लागत=100, शहर=1, ट्रांसफर=0] जोड़ें
pq.offer(new int[]{50, 2, 1});    // [लागत=50, शहर=2, ट्रांसफर=1] जोड़ें
int[] min = pq.poll();            // न्यूनतम लागत वाला [50, 2, 1] निकालें
pq.isEmpty();                      // कतार खाली है या नहीं जाँचें → false
```

### stops सरणी द्वारा छँटाई (pruning) क्या है

सामान्य Dijkstra में `visited` सरणी से विज़िट किए गए शहरों को प्रबंधित किया जाता है, लेकिन इस समस्या में एक ही शहर तक "भिन्न ट्रांसफर संख्या" से पहुँचने वाले पथों को अलग करना आवश्यक है। `stops[]` सरणी में प्रत्येक शहर तक की न्यूनतम ट्रांसफर संख्या रिकॉर्ड की जाती है, और उससे अधिक ट्रांसफर संख्या से पहुँचने वाले पथों को रोककर अनावश्यक खोज को समाप्त किया जाता है।

```java
int[] stops = new int[n];
Arrays.fill(stops, k + 2);  // k+2 "अभी तक नहीं पहुँचा" दर्शाने वाला पर्याप्त बड़ा प्रारंभिक मान है
// शहर 2 तक 1 बार ट्रांसफर से पहुँचने पर
stops[2] = 1;
// बाद में शहर 2 तक 2 बार ट्रांसफर से पहुँचने पर → 2 >= stops[2] इसलिए छँटाई (स्किप)
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(E · log n) — प्रत्येक उड़ान (किनारे) के लिए प्राथमिकता कतार में जोड़ने और निकालने में log n लगता है |
| Space | O(n + E) — आसन्नता सूची में O(E), stops सरणी में O(n), और कतार में अधिकतम O(E) स्थितियाँ रखी जाती हैं |

## कोड

```java
// इनपुट: शहरों की संख्या n, उड़ान सरणी flights (प्रत्येक तत्व [from, to, price] है), प्रस्थान स्थान src, गंतव्य dst, अधिकतम ट्रांसफर संख्या k
// आउटपुट: अधिकतम k बार ट्रांसफर के साथ प्रस्थान स्थान से गंतव्य तक पहुँचने का सबसे सस्ता किराया int में लौटाएँ। पहुँचना संभव न हो तो -1 लौटाएँ
public int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
    // आसन्नता सूची बनाएँ। कुंजी=प्रस्थान शहर, मान=[आगमन शहर, किराया] की सूची
    // प्रत्येक उड़ान f के लिए, adj की कुंजी f[0] में [f[1], f[2]] जोड़ें
    Map<Integer, List<int[]>> adj = new HashMap<>();
    for (int[] f : flights)
        adj.computeIfAbsent(f[0], x -> new ArrayList<>())
            .add(new int[]{f[1], f[2]});

    // लागत के बढ़ते क्रम की प्राथमिकता कतार। प्रत्येक स्थिति [लागत, शहर, ट्रांसफर संख्या] है
    // कम लागत वाली स्थिति को प्राथमिकता से निकालने पर, गंतव्य तक पहली बार पहुँचना ही सबसे सस्ता होता है
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    // प्रारंभिक स्थिति: प्रस्थान स्थान तक लागत 0 और 0 बार ट्रांसफर से पहुँचा हुआ है
    pq.offer(new int[]{0, src, 0});

    // प्रत्येक शहर तक न्यूनतम ट्रांसफर संख्या रिकॉर्ड करने वाली सरणी
    // k+2 ट्रांसफर सीमा k से पर्याप्त बड़ा मान है जो "अभी तक नहीं पहुँचा" दर्शाता है
    int[] stops = new int[n];
    Arrays.fill(stops, k + 2);

    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int cost = curr[0];
        int city = curr[1];
        int stop = curr[2];

        // गंतव्य तक पहुँच गए तो, लागत के बढ़ते क्रम में निकाल रहे हैं इसलिए यह सबसे सस्ता है
        if (city == dst) return cost;

        // इस शहर तक पहले से अधिक (या समान) ट्रांसफर से पहुँचे हैं तो छँटाई करें
        // लागत के बढ़ते क्रम में निकाल रहे हैं, इसलिए पिछली बार की पहुँच की लागत भी कम है → खोज का अर्थ नहीं है
        if (stop >= stops[city]) continue;
        // इस शहर तक पहुँचने की न्यूनतम ट्रांसफर संख्या अपडेट करें
        stops[city] = stop;

        // ट्रांसफर संख्या सीमा k से अधिक है तो, इस शहर से आगे पड़ोसी शहरों में विस्तार नहीं कर सकते
        if (stop > k) continue;

        // इस शहर से प्रस्थान करने वाली कोई उड़ान नहीं है तो स्किप करें
        if (!adj.containsKey(city)) continue;

        // प्रत्येक पड़ोसी शहर के लिए [संचित लागत, पड़ोसी शहर, ट्रांसफर संख्या+1] कतार में जोड़ें
        for (int[] next : adj.get(city)) {
            pq.offer(new int[]{cost + next[1], next[0], stop + 1});
        }
    }

    // लूप समाप्त होने पर भी गंतव्य तक नहीं पहुँच सके तो -1 लौटाएँ
    return -1;
}
```
