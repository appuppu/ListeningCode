# Reconstructing a Flight Itinerary — एयर टिकटों से शब्दकोश क्रम में सबसे छोटा यात्रा मार्ग पुनर्निर्माण करना

## समस्या का सार

प्रस्थान हवाई अड्डे और आगमन हवाई अड्डे के जोड़ों के रूप में दर्शाए गए एयर टिकटों की एक सूची दी गई है। JFK से प्रस्थान करके सभी टिकटों को ठीक एक-एक बार उपयोग करते हुए यात्रा मार्ग का पुनर्निर्माण करना है। यदि एक से अधिक वैध यात्रा मार्ग मौजूद हों, तो शब्दकोश क्रम में सबसे छोटा मार्ग लौटाना है।

## मूल विचार

सभी किनारों (टिकटों) को ठीक एक-एक बार पार करने वाले ऑयलर पथ की समस्या है। प्रत्येक हवाई अड्डे के गंतव्यों को PriorityQueue से प्रबंधित करने पर शब्दकोश क्रम में सबसे छोटा मार्ग स्वचालित रूप से सुनिश्चित होता है, और Hierholzer के एल्गोरिद्म से पीछे से यात्रा मार्ग का निर्माण करने पर डेड-एंड को सही ढंग से संभाला जा सकता है।

## विचार प्रक्रिया

1. **सभी टिकटों को एक-एक बार उपयोग करना = ऑयलर पथ**: प्रत्येक टिकट निर्देशित ग्राफ का एक किनारा है, और सभी किनारों को ठीक एक बार पार करने वाला पथ ज्ञात करने की समस्या ऑयलर पथ (Eulerian Path) की समस्या में परिवर्तित होती है
2. **शब्दकोश क्रम में सबसे छोटा सुनिश्चित करने के लिए सॉर्टिंग आवश्यक है**: जब किसी हवाई अड्डे से कई गंतव्य हों, तो शब्दकोश क्रम में छोटे वाले को पहले चुनना है। प्रत्येक हवाई अड्डे के गंतव्यों को PriorityQueue (मिन-हीप) में संग्रहीत करने पर, केवल `poll()` करने से हमेशा शब्दकोश क्रम में सबसे छोटा गंतव्य प्राप्त होता है
3. **साधारण लालची विधि से डेड-एंड को संभालना संभव नहीं है**: यदि हमेशा शब्दकोश क्रम में सबसे छोटा चुना जाए, तो अप्रयुक्त किनारे शेष रहते हुए भी पहले डेड-एंड पर पहुँच सकते हैं। उदाहरण के लिए, JFK→A→JFK→B के टिकट होने पर, JFK से A को पहले चुनने पर A→JFK→B तक आगे बढ़ सकते हैं, लेकिन B को पहले चुनने पर B पर डेड-एंड हो जाता है
4. **Hierholzer के एल्गोरिद्म से पीछे से निर्माण करना**: DFS में जब किसी नोड से आगे कोई गंतव्य न बचे (डेड-एंड पर पहुँचे), तो उस नोड को परिणाम सूची के **आरंभ** में जोड़ना है। इससे डेड-एंड यात्रा मार्ग के अंत में स्थित होता है, और शेष किनारे रिकर्शन के वापस लौटते समय सही क्रम में आरंभ में जुड़ते जाते हैं
5. **रिकर्सिव DFS की कार्यप्रणाली**: वर्तमान नोड से PriorityQueue द्वारा शब्दकोश क्रम में सबसे छोटा गंतव्य निकालकर रिकर्सिव रूप से DFS करना है। जब कोई गंतव्य शेष न रहे, तो परिणाम सूची के आरंभ में वर्तमान नोड को जोड़ना है। LinkedList की `addFirst` विधि से O(1) में आरंभ में जोड़ा जा सकता है
6. **अंतिम रूप से लौटाने योग्य परिणाम**: सभी DFS पूर्ण होने के बाद, परिणाम सूची (LinkedList) को उसी रूप में लौटाना है। इस सूची में JFK से आरंभ होने वाला शब्दकोश क्रम में सबसे छोटा यात्रा मार्ग संग्रहीत होता है

## पूर्वापेक्षित ज्ञान

### PriorityQueue (प्राथमिकता कतार) क्या है

यह एक ऐसी डेटा संरचना है जिसमें तत्व जोड़ने पर वे स्वचालित रूप से सॉर्ट हो जाते हैं, और निकालते समय हमेशा सबसे छोटा तत्व प्राप्त होता है। आंतरिक रूप से यह हीप द्वारा कार्यान्वित होती है, और जोड़ने तथा निकालने दोनों में O(log n) का समय लगता है।

```java
PriorityQueue<String> pq = new PriorityQueue<>();  // स्ट्रिंग के प्राकृतिक क्रम (शब्दकोश क्रम) से मिन-हीप बनाना
pq.offer("SFO");       // "SFO" को जोड़ना
pq.offer("ATL");       // "ATL" को जोड़ना
pq.poll();             // सबसे छोटे तत्व "ATL" को निकालकर हटाना → "ATL"
pq.isEmpty();          // कतार खाली है या नहीं boolean में लौटाना → false ("SFO" शेष है)
```

### computeIfAbsent क्या है

HashMap में कुंजी मौजूद न होने पर ही, निर्दिष्ट फ़ंक्शन से मान उत्पन्न करके पंजीकृत करने और उस मान को लौटाने वाली विधि है। यदि कुंजी पहले से मौजूद है, तो मौजूदा मान को उसी रूप में लौटाती है। `get` करके `null` जाँच करके `put` करने के तीन चरणों को एक पंक्ति में लिखा जा सकता है।

```java
Map<String, PriorityQueue<String>> graph = new HashMap<>();
// "JFK" कुंजी मौजूद नहीं है तो नई PriorityQueue बनाकर पंजीकृत करना, और उस PriorityQueue को लौटाना
graph.computeIfAbsent("JFK", k -> new PriorityQueue<>()).offer("SFO");
// "JFK" कुंजी पहले से मौजूद है, इसलिए मौजूदा PriorityQueue को लौटाना (नई नहीं बनाना)
graph.computeIfAbsent("JFK", k -> new PriorityQueue<>()).offer("ATL");
```

### LinkedList की addFirst क्या है

सूची के आरंभ में O(1) में तत्व जोड़ने वाली विधि है। सामान्य `add` (अंत में जोड़ने) के विपरीत, मौजूदा तत्वों को पीछे सरकाए बिना आरंभ में सम्मिलित किया जा सकता है। Hierholzer के एल्गोरिद्म में उल्टे क्रम में परिणाम का निर्माण करते समय इसका उपयोग किया जाता है।

```java
LinkedList<String> result = new LinkedList<>();
result.addFirst("JFK");   // result: ["JFK"]
result.addFirst("ATL");   // result: ["ATL", "JFK"]
result.addFirst("SFO");   // result: ["SFO", "ATL", "JFK"]
```

### Hierholzer का एल्गोरिद्म क्या है

ऑयलर पथ (सभी किनारों को ठीक एक बार पार करने वाला पथ) ज्ञात करने का एल्गोरिद्म है। DFS द्वारा किनारों का उपभोग करते हुए आगे बढ़ना है, और डेड-एंड पर पहुँचे नोड को परिणाम के आरंभ में जोड़ना है। सभी किनारों का उपयोग पूर्ण होने के बाद, परिणाम सूची में ऑयलर पथ सही क्रम में संग्रहीत होता है। डेड-एंड को यात्रा मार्ग के अंत में स्वाभाविक रूप से स्थित करने की क्षमता इस समस्या के लिए उपयुक्त है।

## गणना जटिलता

| | मान |
|---|---|
| Time | O(E log E) — प्रत्येक टिकट (किनारे) को PriorityQueue में जोड़ने और निकालने में log E की लागत लगती है |
| Space | O(V + E) — ग्राफ की आसन्नता सूची में सभी किनारे संग्रहीत होते हैं, और रिकर्शन स्टैक अधिकतम किनारों की संख्या तक गहरा हो सकता है |

## कोड

```java
// इनपुट: एयर टिकटों की सूची tickets (प्रत्येक टिकट [प्रस्थान हवाई अड्डा, आगमन हवाई अड्डा] का स्ट्रिंग जोड़ा है)
// आउटपुट: JFK से आरंभ होने वाला शब्दकोश क्रम में सबसे छोटा यात्रा मार्ग List<String> में लौटाना
public List<String> findItinerary(List<List<String>> tickets) {
    // कुंजी=प्रस्थान हवाई अड्डा, मान=आगमन हवाई अड्डों को शब्दकोश क्रम में प्रबंधित करने वाली PriorityQueue
    // PriorityQueue का उपयोग करने से, निकालते समय हमेशा शब्दकोश क्रम में सबसे छोटा गंतव्य प्राप्त होता है
    Map<String, PriorityQueue<String>> graph = new HashMap<>();

    // सभी टिकटों से ग्राफ का निर्माण करना
    // computeIfAbsent द्वारा, src कुंजी पहली बार आने पर नई PriorityQueue बनाना, मौजूद होने पर उसी को प्राप्त करना
    for (List<String> t : tickets) {
        graph.computeIfAbsent(t.get(0), k -> new PriorityQueue<>())
             .offer(t.get(1));
    }

    // परिणाम संग्रहीत करने के लिए LinkedList (addFirst से O(1) में आरंभ में जोड़ने के लिए)
    LinkedList<String> result = new LinkedList<>();

    // JFK से DFS आरंभ करना
    dfs("JFK", graph, result);
    return result;
}

void dfs(String curr,
          Map<String, PriorityQueue<String>> graph,
          LinkedList<String> result) {
    // वर्तमान हवाई अड्डे से जाने योग्य गंतव्यों की PriorityQueue प्राप्त करना
    PriorityQueue<String> dests = graph.get(curr);

    // जब तक गंतव्य मौजूद हैं, शब्दकोश क्रम में सबसे छोटा गंतव्य निकालकर DFS करना
    // ध्यान दें: poll() तत्व को हटा देता है, इसलिए एक ही किनारे (टिकट) को दो बार पार नहीं किया जाता
    while (dests != null && !dests.isEmpty()) {
        dfs(dests.poll(), graph, result);
    }

    // डेड-एंड पर पहुँचने पर, परिणाम सूची के आरंभ में वर्तमान हवाई अड्डे को जोड़ना
    // आरंभ में जोड़ने से, डेड-एंड नोड यात्रा मार्ग के अंत की ओर स्थित होता है,
    // और बाद में जोड़े जाने वाले नोड यात्रा मार्ग के आरंभ में सही स्थान पर आते हैं
    result.addFirst(curr);
}
```
