# Deriving the Order of an Alien Alphabet — एलियन भाषा के अक्षर क्रम को पुनर्स्थापित करना

## समस्या का सार

एलियन भाषा के शब्दकोश क्रम में सॉर्ट किया गया शब्द सूची `words` दिया गया है। इस क्रम से उस भाषा में वर्णमाला का क्रम अनुमान करें और एक स्ट्रिंग के रूप में लौटाएं। यदि क्रम में विरोधाभास हो (साइकल मौजूद हो, या छोटा शब्द लंबे शब्द के बाद आ रहा हो आदि) तो खाली स्ट्रिंग `""` लौटाएं।

## मूल विचार

दो आसन्न शब्दों की तुलना करने पर "पहले भिन्न अक्षर" से एक क्रम संबंध (दिशात्मक किनारा) प्राप्त होता है। सभी जोड़ियों से प्राप्त क्रम संबंधों को दिशात्मक ग्राफ के रूप में बनाएं और DFS टोपोलॉजिकल सॉर्ट से संपूर्ण क्रम निर्धारित करें। यदि साइकल हो तो क्रम विरोधाभासी है।

## विचार प्रक्रिया

1. **आसन्न शब्दों की तुलना से क्रम संबंध निकालना**: सॉर्ट की गई सूची में आसन्न दो शब्दों `words[i]` और `words[i+1]` को शुरू से तुलना करके, पहले भिन्न अक्षरों का जोड़ा `(a, b)` मिलने पर "a, b से पहले आता है" यह क्रम संबंध एक निश्चित होता है। इस संबंध को दिशात्मक ग्राफ के किनारे `a → b` के रूप में व्यक्त किया जा सकता है
2. **अमान्य इनपुट का पता लगाना**: यदि `words[i]`, `words[i+1]` का प्रीफिक्स है और `words[i]` अधिक लंबा है (उदाहरण: `"abc"` जो `"ab"` से पहले हो), तो यह शब्दकोश क्रम के रूप में विरोधाभासी है इसलिए तुरंत खाली स्ट्रिंग लौटाएं
3. **सभी अक्षरों को नोड के रूप में पंजीकृत करना**: क्रम संबंध प्राप्त न होने वाले अक्षर भी मौजूद हो सकते हैं, इसलिए सभी शब्दों के सभी अक्षरों को ग्राफ के नोड के रूप में पंजीकृत करें। इससे बिना किनारे वाले अक्षर भी परिणाम में शामिल होंगे
4. **DFS टोपोलॉजिकल सॉर्ट से संपूर्ण क्रम निर्धारित करना**: दिशात्मक ग्राफ पर DFS चलाएं और प्रत्येक नोड की खोज पूर्ण होने पर उसे सूची में जोड़ें। DFS के पोस्ट-ऑर्डर को उलटने पर टोपोलॉजिकल क्रम (निर्भरता स्रोत पहले आने वाला क्रम) प्राप्त होता है
5. **3-रंग मार्किंग से साइकल का पता लगाना**: DFS के दौरान प्रत्येक नोड को "अभ्यागत नहीं(0)", "खोज जारी(1)", "खोज पूर्ण(2)" इन 3 अवस्थाओं में प्रबंधित करें। खोज जारी वाले नोड पर दोबारा पहुंचने पर साइकल मौजूद है इसलिए क्रम निर्धारित करना असंभव है, और खाली स्ट्रिंग लौटाएं
6. **उलटकर स्ट्रिंग बनाना**: DFS के पोस्ट-ऑर्डर सूची को उलटकर टोपोलॉजिकल क्रम प्राप्त करें। सूची के सभी अक्षरों को जोड़कर परिणाम स्ट्रिंग लौटाएं

## पूर्व-ज्ञान

### टोपोलॉजिकल सॉर्ट क्या है

दिशात्मक अचक्रीय ग्राफ (DAG) के सभी नोड्स को, किनारों की दिशा के अनुरूप क्रम में एक पंक्ति में व्यवस्थित करने की क्रिया। यदि किनारा `a → b` मौजूद है, तो परिणाम में `a` अवश्य `b` से पहले आएगा। साइकल वाले ग्राफ में टोपोलॉजिकल क्रम संभव नहीं है।

### DFS की 3-रंग मार्किंग क्या है

DFS में प्रत्येक नोड की अवस्था को 3 रंगों से प्रबंधित करने की विधि। सफेद(0) अभ्यागत नहीं है, धूसर(1) वर्तमान खोज पथ पर है (रिकर्सन स्टैक में मौजूद), काला(2) खोज पूर्ण को दर्शाता है। धूसर नोड पर दोबारा पहुंचने पर साइकल निश्चित होता है।

```java
Map<Character, Integer> color = new HashMap<>();
color.put('a', 0);  // सफेद: अभ्यागत नहीं
color.put('a', 1);  // धूसर: खोज जारी (रिकर्सन स्टैक पर मौजूद)
color.put('a', 2);  // काला: खोज पूर्ण (सभी वंशज संसाधित)
```

### HashMap और HashSet की मूल संक्रियाएं

```java
// HashMap: कुंजी और मान के जोड़े संग्रहीत करता है। खोज और प्राप्ति O(1) में होती है
Map<Character, Set<Character>> adj = new HashMap<>();
adj.putIfAbsent('a', new HashSet<>());  // कुंजी अपंजीकृत होने पर ही खाली Set पंजीकृत करता है
adj.get('a').add('b');                  // कुंजी 'a' की आसन्न सूची में 'b' जोड़ता है

// HashSet: बिना दोहराव का समुच्चय। जोड़ना और खोजना O(1) में होता है
Set<Character> set = new HashSet<>();
set.add('b');        // तत्व जोड़ता है
set.contains('b');   // तत्व की उपस्थिति जांचता है → true
```

### startsWith विधि

स्ट्रिंग निर्दिष्ट प्रीफिक्स से शुरू होती है या नहीं इसकी जांच करती है।

```java
"abc".startsWith("ab");  // true — "abc", "ab" से शुरू होता है
"ab".startsWith("abc");  // false — "ab", "abc" से शुरू नहीं होता
```

## गणनात्मक जटिलता

| | मान |
|---|---|
| Time | O(C) — C सभी शब्दों की कुल अक्षर संख्या है। ग्राफ निर्माण में सभी अक्षरों को स्कैन किया जाता है, और DFS नोड संख्या + किनारा संख्या के अनुपात में चलता है, लेकिन दोनों C से अधिक नहीं होते |
| Space | O(1) — नोड संख्या अधिकतम 26 अक्षर (अंग्रेजी लोअरकेस) तक सीमित है जो स्थिरांक है। किनारों की संख्या भी अधिकतम 26² तक स्थिरांक है। यह इनपुट आकार पर निर्भर नहीं करता |

## कोड

```java
// इनपुट: एलियन भाषा के शब्दकोश क्रम में सॉर्ट किया गया स्ट्रिंग सरणी words
// आउटपुट: वर्णमाला के क्रम को दर्शाने वाली स्ट्रिंग। विरोधाभास होने पर खाली स्ट्रिंग "" लौटाता है

// DFS: 3-रंग मार्किंग से साइकल का पता लगाते हुए पोस्ट-ऑर्डर रिकॉर्ड करता है
boolean dfs(char c, Map<Character, Set<Character>> adj,
            Map<Character, Integer> color, List<Character> result) {
    // धूसर (खोज जारी) पर दोबारा पहुंचना → साइकल पाया गया
    if (color.get(c) == 1) return false;
    // काला (खोज पूर्ण) → पहले से संसाधित है इसलिए छोड़ें
    if (color.get(c) == 2) return true;

    // वर्तमान नोड को धूसर (खोज जारी) के रूप में चिह्नित करता है
    color.put(c, 1);

    // सभी आसन्न नोड्स (इस अक्षर के बाद आने वाले अक्षर) पर पुनरावर्ती DFS चलाता है
    for (char n : adj.get(c))
        if (!dfs(n, adj, color, result))
            return false;  // वंशज में साइकल पाया → तुरंत प्रसारित करता है

    // सभी वंशजों की खोज पूर्ण होने पर काले रंग से चिह्नित करता है
    color.put(c, 2);
    // पोस्ट-ऑर्डर में सूची में जोड़ता है (DFS में निर्भरता लक्ष्य पहले जुड़ता है, इसलिए उलटने पर टोपोलॉजिकल क्रम बनता है)
    result.add(c);
    return true;
}

public String alienOrder(String[] words) {
    // आसन्न सूची: कुंजी=अक्षर, मान=उस अक्षर के बाद आने वाले अक्षरों का समुच्चय
    Map<Character, Set<Character>> adj = new HashMap<>();

    // सभी शब्दों के सभी अक्षरों को ग्राफ के नोड के रूप में पंजीकृत करता है
    // क्रम संबंध (किनारा) रहित अक्षरों को भी परिणाम में शामिल करना आवश्यक है, इसलिए इस बिंदु पर सभी अक्षरों को पंजीकृत करता है
    for (String w : words)
        for (char c : w.toCharArray())
            adj.putIfAbsent(c, new HashSet<>());

    // आसन्न दो शब्दों की तुलना करके क्रम संबंध (दिशात्मक किनारा) निकालता है
    for (int i = 0; i < words.length - 1; i++) {
        String w1 = words[i];
        String w2 = words[i + 1];

        // अमान्य इनपुट का पता लगाना: लंबा शब्द छोटे प्रीफिक्स से पहले होने पर (उदाहरण: ["abc","ab"] विरोधाभासी है)
        if (w1.length() > w2.length() && w1.startsWith(w2))
            return "";

        int len = Math.min(w1.length(), w2.length());
        for (int j = 0; j < len; j++) {
            if (w1.charAt(j) != w2.charAt(j)) {
                // पहले भिन्न अक्षर से एक क्रम संबंध प्राप्त करके तुरंत लूप से बाहर निकलता है
                // दूसरे अक्षर के बाद का अंतर तभी अर्थपूर्ण है जब पहले के अक्षर समान हों, इसलिए केवल एक ही निकालता है
                adj.get(w1.charAt(j)).add(w2.charAt(j));
                break;
            }
        }
    }

    // 3-रंग प्रबंधन मैप बनाता है और सभी नोड्स को सफेद(0: अभ्यागत नहीं) से आरंभ करता है
    Map<Character, Integer> color = new HashMap<>();
    for (char c : adj.keySet())
        color.put(c, 0);

    // DFS का पोस्ट-ऑर्डर रिकॉर्ड करने वाली सूची
    List<Character> result = new ArrayList<>();

    // सभी नोड्स पर DFS चलाता है (असंबद्ध ग्राफ के लिए भी सभी नोड्स को प्रारंभ बिंदु बनाता है)
    for (char c : adj.keySet())
        if (!dfs(c, adj, color, result))
            return "";  // साइकल पाया → क्रम निर्धारित करना असंभव

    // पोस्ट-ऑर्डर को उलटकर टोपोलॉजिकल क्रम प्राप्त करता है
    Collections.reverse(result);

    // सभी अक्षरों को जोड़कर परिणाम स्ट्रिंग बनाता है
    StringBuilder sb = new StringBuilder();
    for (char c : result) sb.append(c);
    return sb.toString();
}
```
