# Finding the Minimum Time to Swim Across a Grid — ग्रिड को तैरकर पार करने का न्यूनतम समय ज्ञात करना

## समस्या का सार

n×n का एक ग्रिड दिया गया है, जिसमें प्रत्येक सेल में 0 से n²-1 तक का एक अद्वितीय ऊँचाई मान होता है। किसी सेल से आसन्न सेल (ऊपर, नीचे, बाएँ, दाएँ) में तैरकर जाना तभी संभव है जब वर्तमान समय **दोनों सेलों की ऊँचाई के बराबर या उससे अधिक** हो। ऊपर-बाएँ (0,0) से नीचे-दाएँ (n-1,n-1) तक पहुँचने के लिए आवश्यक **न्यूनतम समय** ज्ञात करना है। प्रारंभ समय grid[0][0] का मान होता है।

## मूल विचार

मार्ग पर पड़ने वाले सेलों की ऊँचाई का **अधिकतम मान** ही उस मार्ग के लिए आवश्यक समय होता है। न्यूनतम हीप का उपयोग करके "वर्तमान में पहुँच योग्य सेलों में से सबसे कम आवश्यक समय वाले सेल" से क्रमशः अन्वेषण करने पर, लक्ष्य तक पहली बार पहुँचने का समय ही इष्टतम उत्तर होता है।

## चिंतन प्रक्रिया

1. **गति की शर्त को पुनः परिभाषित करना**: सेल A से सेल B में जाने के लिए "समय ≥ max(A, B)" आवश्यक है। अर्थात, प्रारंभ से लक्ष्य तक के पूरे मार्ग के लिए आवश्यक समय "मार्ग पर सभी सेलों की ऊँचाई के अधिकतम मान" के बराबर होता है। इसलिए समस्या "ऐसा मार्ग खोजना जिसमें अधिकतम ऊँचाई न्यूनतम हो" में परिवर्तित हो जाती है
2. **सबसे छोटे मार्ग की समस्या से समानता पहचानना**: सामान्य Dijkstra "मार्ग पर किनारों के भारों का योग" न्यूनतम करता है, लेकिन इस समस्या में "मार्ग पर सेलों की ऊँचाई का अधिकतम मान" न्यूनतम करना है। योग के स्थान पर अधिकतम मान का उपयोग करके Dijkstra का ढाँचा यथावत लागू किया जा सकता है
3. **प्राथमिकता कतार से न्यूनतम समय वाले सेल का विस्तार करना**: न्यूनतम हीप (PriorityQueue) में सेलों को "वहाँ पहुँचने के लिए आवश्यक समय" के अनुसार संग्रहीत किया जाता है। सदैव सबसे कम आवश्यक समय वाले सेल से विस्तार करने पर, प्रत्येक सेल तक पहली बार पहुँचने का समय इष्टतम होने की गारंटी मिलती है
4. **आसन्न सेलों के लिए आवश्यक समय की गणना करना**: वर्तमान सेल (r,c) का आवश्यक समय `time` होने पर, आसन्न सेल (nr,nc) के लिए आवश्यक समय `Math.max(time, grid[nr][nc])` से गणना होता है। इसका कारण यह है कि "यहाँ तक के मार्ग पर अधिकतम ऊँचाई" और "अगले सेल की ऊँचाई" में से जो बड़ा हो, वही नए मार्ग का आवश्यक समय बनता है
5. **विज़िट प्रबंधन से दोहराव रोकना**: न्यूनतम हीप से निकाले गए सेल का उस बिंदु पर इष्टतम समय निश्चित हो जाता है। विज़िट किए गए सरणी `vis` से चिह्नित करके उसी सेल को पुनः संसाधित होने से रोका जाता है। यह Dijkstra के निश्चित नोड के समान अवधारणा है
6. **लक्ष्य तक पहुँचने पर तुरंत उत्तर लौटाना**: हीप से निकाला गया सेल यदि (n-1, n-1) है, तो उस समय का `time` ही न्यूनतम समय होता है। न्यूनतम हीप के कारण सबसे कम समय से क्रमशः संसाधित हो रहा है, इसलिए लक्ष्य तक पहली पहुँच ही इष्टतम उत्तर होती है

## पूर्वापेक्षित ज्ञान

### PriorityQueue (न्यूनतम हीप) क्या है

यह एक डेटा संरचना है जो तत्वों को प्राथमिकता क्रम में निकालने की अनुमति देती है। डिफ़ॉल्ट रूप से सबसे छोटा मान सर्वोच्च प्राथमिकता से निकाला जाता है। सम्मिलन और निकालना दोनों O(log n) की गणन जटिलता में कार्य करते हैं। Dijkstra विधि में "अनिश्चित नोडों में से न्यूनतम लागत वाले को चुनने" की कार्यवाही को कुशलतापूर्वक करने के लिए इसका उपयोग किया जाता है।

```java
// int[] के पहले तत्व के अनुसार आरोही क्रम में न्यूनतम हीप बनाना
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{5, 0, 0});   // तत्व जोड़ना (O(log n))
pq.offer(new int[]{3, 1, 0});   // तत्व जोड़ना
int[] min = pq.poll();          // सबसे छोटा तत्व निकालकर हटाना → {3, 1, 0}
boolean empty = pq.isEmpty();   // कतार खाली है या नहीं जाँचना → false
```

### Dijkstra विधि का रूपांतर क्या है

सामान्य Dijkstra विधि किनारों के भारों के **योग** को न्यूनतम करती है, लेकिन इस समस्या में मार्ग पर ऊँचाई के **अधिकतम मान** को न्यूनतम करना है। दूरी की अद्यतन सूत्र को `dist[next] = dist[cur] + weight` से `dist[next] = max(dist[cur], grid[next])` में बदलने मात्र से, Dijkstra की वैधता (न्यूनतम हीप से निकालने के समय इष्टतम निश्चित होने का गुण) यथावत बनी रहती है।

### 4 दिशाओं में आसन्न सेलों का अन्वेषण

ग्रिड पर सेल (r,c) के ऊपर, नीचे, बाएँ, दाएँ के आसन्न सेलों को दिशा वेक्टर `{{0,1},{0,-1},{1,0},{-1,0}}` जोड़कर सूचीबद्ध किया जाता है। सीमा-बाह्य जाँच (0 ≤ nr < n तथा 0 ≤ nc < n) करके केवल मान्य सेलों को संसाधित किया जाता है।

```java
int[][] dir = {{0,1},{0,-1},{1,0},{-1,0}};  // दाएँ, बाएँ, नीचे, ऊपर की 4 दिशाएँ
for (int[] d : dir) {
    int nr = r + d[0];  // आसन्न सेल की पंक्ति
    int nc = c + d[1];  // आसन्न सेल का स्तंभ
    if (nr >= 0 && nr < n && nc >= 0 && nc < n) {
        // (nr, nc) एक मान्य आसन्न सेल है
    }
}
```

## गणन जटिलता

| | मान |
|---|---|
| Time | O(n² log n) — n² सेलों में से प्रत्येक को अधिकतम 1 बार हीप में डाला और निकाला जाता है। प्रति हीप संक्रिया O(log n²) = O(log n) |
| Space | O(n²) — विज़िट किए गए सरणी और हीप में प्रत्येक अधिकतम n² सेल रखे जाते हैं |

## कोड

```java
// इनपुट: n×n का पूर्णांक सरणी grid (प्रत्येक सेल में 0 से n²-1 तक का अद्वितीय ऊँचाई मान होता है)
// आउटपुट: ऊपर-बाएँ (0,0) से नीचे-दाएँ (n-1,n-1) तक पहुँचने के लिए आवश्यक न्यूनतम समय int के रूप में लौटाना
int swimInWater(int[][] grid) {
    int n = grid.length;
    // प्रत्येक सेल का इष्टतम समय निश्चित हुआ है या नहीं, यह प्रबंधित करने वाला विज़िट सरणी (vis[r][c] = true तो निश्चित)
    boolean[][] vis = new boolean[n][n];
    // आवश्यक समय के आरोही क्रम में निकालने वाला न्यूनतम हीप (तत्व: {समय, पंक्ति, स्तंभ})
    // तुलना फ़ंक्शन (a,b)->a[0]-b[0] द्वारा पहले तत्व (आवश्यक समय) के आरोही क्रम में निकाला जाता है
    PriorityQueue<int[]> pq =
        new PriorityQueue<>(
            (a, b) -> a[0] - b[0]);
    // प्रारंभ बिंदु को हीप में जोड़ना और विज़िट किया हुआ चिह्नित करना
    // पहला तत्व आवश्यक समय, दूसरा तत्व पंक्ति, तीसरा तत्व स्तंभ है
    pq.offer(new int[]
        {grid[0][0], 0, 0});
    vis[0][0] = true;
    // ऊपर, नीचे, बाएँ, दाएँ के 4 दिशा वेक्टर
    int[][] dir =
        {{0,1},{0,-1},{1,0},{-1,0}};
    while (!pq.isEmpty()) {
        // सबसे कम आवश्यक समय वाले सेल को निकालना (न्यूनतम हीप के गुण से इस बिंदु पर इष्टतम समय निश्चित होता है)
        int[] cur = pq.poll();
        int time = cur[0];
        int r = cur[1], c = cur[2];
        // लक्ष्य तक पहुँचने पर वह समय इष्टतम उत्तर है (न्यूनतम समय से क्रमशः संसाधित होने के कारण पहली पहुँच ही इष्टतम है)
        if (r == n-1 && c == n-1)
            return time;
        // 4 दिशाओं के आसन्न सेलों का अन्वेषण करना
        for (int[] d : dir) {
            int nr = r+d[0];
            int nc = c+d[1];
            // सीमा के अंदर और अभी तक विज़िट न किए गए सेलों को ही संसाधित करना
            if (nr >= 0 && nr < n
                && nc >= 0 && nc < n
                && !vis[nr][nc]) {
                // ध्यान दें: हीप में जोड़ते समय विज़िट किया हुआ चिह्नित करने से उसी सेल के बार-बार हीप में जुड़ने से रोका जाता है
                vis[nr][nc] = true;
                // मार्ग पर अधिकतम ऊँचाई ही आवश्यक समय बनती है ("यहाँ तक की अधिकतम ऊँचाई" और "अगले सेल की ऊँचाई" में से बड़ा मान)
                int nt = Math.max(
                    time,grid[nr][nc]);
                pq.offer(new int[]
                    {nt, nr, nc});
            }
        }
    }
    // समस्या की शर्तों के अनुसार ग्रिड संबद्ध है इसलिए यहाँ कभी नहीं पहुँचा जाता
    return -1;
}
```
