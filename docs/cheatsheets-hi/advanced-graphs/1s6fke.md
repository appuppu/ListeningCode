# Finding the Minimum Cost to Connect All Points — सभी बिंदुओं को न्यूनतम लागत से जोड़ना

## समस्या का सार

2D समतल पर बिंदुओं की एक सरणी `points` दी गई है। किन्हीं दो बिंदुओं के बीच की लागत मैनहट्टन दूरी `|xi - xj| + |yi - yj|` से परिभाषित होती है। सभी बिंदुओं को जोड़ने के लिए **न्यूनतम कुल लागत** लौटानी है। यह न्यूनतम फैलाव वृक्ष (MST: Minimum Spanning Tree) ज्ञात करने की समस्या है।

## मुख्य विचार

सभी बिंदुओं को न्यूनतम लागत से जोड़ने के लिए, Prim के एल्गोरिदम से "वर्तमान MST के सबसे निकट अभेंट बिंदु" को लालची तरीके से चुनते रहना है। प्राथमिकता कतार का उपयोग करने से न्यूनतम लागत वाली भुजा को कुशलतापूर्वक निकाला जा सकता है।

## विचार प्रक्रिया

1. **यह एक MST समस्या है**: सभी बिंदुओं को जोड़ना है और लागत को न्यूनतम करना है। यह न्यूनतम फैलाव वृक्ष की परिभाषा ही है। ग्राफ की भुजाओं के भार की गणना मैनहट्टन दूरी से की जा सकती है
2. **पूर्ण ग्राफ होने के कारण Prim उपयुक्त है**: n बिंदुओं के लिए भुजाओं की संख्या n(n-1)/2 होती है। Kruskal में सभी भुजाओं को पहले से उत्पन्न और क्रमबद्ध करना आवश्यक है, लेकिन Prim में केवल वर्तमान MST से सटी भुजाओं को क्रमिक रूप से संसाधित किया जा सकता है
3. **न्यूनतम लागत वाली भुजा को तेज़ी से निकालना है**: Prim के एल्गोरिदम में हर बार "अभेंट बिंदुओं तक की न्यूनतम लागत वाली भुजा" चुनना आवश्यक है। प्राथमिकता कतार (न्यूनतम हीप) का उपयोग करने से यह निकासी O(log n) में की जा सकती है
4. **किसी भी बिंदु से आरंभ किया जा सकता है**: MST की कुल लागत किसी भी बिंदु से शुरू करने पर समान रहती है, इसलिए बिंदु 0 से आरंभ करते हैं। प्रारंभिक अवस्था में बिंदु 0 तक की लागत 0 को कतार में डालते हैं
5. **भेंट-चिह्न से दोहराव रोकना है**: कतार से निकाला गया बिंदु यदि पहले से MST में शामिल है तो उसे छोड़ देते हैं। इससे एक ही बिंदु को दोबारा संसाधित करने से रोका जाता है
6. **नया बिंदु MST में जोड़ने पर सटी भुजाएँ जोड़ना है**: MST में बिंदु u जोड़ने पर, u से सभी अभेंट बिंदुओं v तक की मैनहट्टन दूरी की गणना करके कतार में जोड़ते हैं। कतार स्वचालित रूप से न्यूनतम लागत वाली भुजा को अगले उम्मीदवार के रूप में प्रबंधित करती है

## पूर्वापेक्षित ज्ञान

### न्यूनतम फैलाव वृक्ष (MST) क्या है

ग्राफ के सभी शीर्षों को जोड़ने वाले उपग्राफ में से वह जिसमें भुजाओं के भार का योग न्यूनतम हो। n शीर्षों के लिए यह ठीक n-1 भुजाएँ रखता है और इसमें कोई चक्र नहीं होता।

### Prim का एल्गोरिदम क्या है

MST बनाने का एक लालची एल्गोरिदम। किसी भी शीर्ष से आरंभ करके, "वर्तमान MST और अभेंट शीर्षों को जोड़ने वाली भुजाओं में से न्यूनतम भार वाली भुजा" को बार-बार चुनकर MST का विस्तार किया जाता है। सभी शीर्ष MST में शामिल हो जाने पर समाप्त होता है।

### मैनहट्टन दूरी क्या है

दो बिंदुओं के बीच प्रत्येक निर्देशांक के अंतर के निरपेक्ष मानों का योग। 2D समतल पर बिंदु `(x1, y1)` और `(x2, y2)` की दूरी `|x1 - x2| + |y1 - y2|` से गणना की जाती है। यह ग्रिड जैसे मार्ग पर चलने की न्यूनतम दूरी के बराबर है।

```java
int dist = Math.abs(pts[u][0] - pts[v][0]) + Math.abs(pts[u][1] - pts[v][1]);
```

### PriorityQueue (प्राथमिकता कतार) क्या है

एक डेटा संरचना जो तत्वों को प्राथमिकता क्रम में निकालती है। डिफ़ॉल्ट रूप से न्यूनतम मान सबसे पहले निकाला जाता है (न्यूनतम हीप)। `offer` से जोड़ा जाता है, `poll` से न्यूनतम तत्व निकाला जाता है, और दोनों O(log n) में कार्य करते हैं।

```java
// int[] के पहले तत्व के अनुसार आरोही क्रम वाली प्राथमिकता कतार बनाना
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{5, 0});   // [लागत=5, बिंदु अनुक्रमणिका=0] जोड़ना
pq.offer(new int[]{2, 1});   // [लागत=2, बिंदु अनुक्रमणिका=1] जोड़ना
int[] min = pq.poll();       // न्यूनतम लागत वाला तत्व [2, 1] निकालना
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n² log n) — प्रत्येक बिंदु को MST में जोड़ते समय अधिकतम n भुजाएँ कतार में जोड़ी जाती हैं, और कतार संचालन में log n लगता है |
| Space | O(n²) — कतार में अधिकतम n² भुजाएँ संग्रहीत होती हैं। inMST सरणी O(n) है |

## कोड

```java
// इनपुट: 2D निर्देशांकों की सरणी pts (प्रत्येक तत्व [x, y] है)
// आउटपुट: सभी बिंदुओं को जोड़ने की न्यूनतम लागत int के रूप में लौटाना
int minCostConnectPoints(int[][] pts) {
    // बिंदुओं की संख्या प्राप्त करना
    int n = pts.length;
    // प्रत्येक बिंदु MST में शामिल है या नहीं, यह प्रबंधित करने वाली फ्लैग सरणी (सभी false से आरंभ होती है)
    boolean[] inMST = new boolean[n];
    // {लागत, बिंदु अनुक्रमणिका} संग्रहीत करने वाली, लागत आरोही क्रम में निकालने वाली प्राथमिकता कतार
    PriorityQueue<int[]> pq =
        new PriorityQueue<>((a, b) -> a[0] - b[0]);
    // आरंभिक बिंदु (अनुक्रमणिका 0) को लागत 0 के साथ कतार में जोड़ना
    // लागत 0 का अर्थ है कि पहले बिंदु को MST में जोड़ने की लागत 0 है
    // MST की कुल लागत किसी भी बिंदु से शुरू करने पर समान रहती है, इसलिए यहाँ बिंदु 0 चुना गया है
    pq.offer(new int[]{0, 0});
    // cost: MST की कुल लागत, visited: MST में जोड़े गए बिंदुओं की संख्या
    int cost = 0, visited = 0;

    // सभी बिंदु MST में शामिल होने तक दोहराना
    while (visited < n) {
        // न्यूनतम लागत वाली भुजा निकालना (d: जोड़ने की लागत, u: बिंदु अनुक्रमणिका)
        int[] curr = pq.poll();
        int d = curr[0], u = curr[1];

        // पहले से MST में शामिल बिंदु को छोड़ना
        // एक ही बिंदु भिन्न लागतों के साथ कतार में कई बार जुड़ सकता है, इसलिए यह जाँच आवश्यक है
        if (inMST[u]) continue;

        // बिंदु u को MST में जोड़ना और लागत जोड़ना
        inMST[u] = true;
        cost += d;
        visited++;

        // बिंदु u से सभी अभेंट बिंदुओं तक की भुजाएँ कतार में जोड़ना
        // अगली उम्मीदवार भुजाएँ कतार में पंजीकृत होती हैं, और कतार स्वचालित रूप से न्यूनतम लागत वाली भुजा का प्रबंधन करती है
        for (int v = 0; v < n; v++) {
            if (!inMST[v]) {
                // मैनहट्टन दूरी की गणना करना: |xu - xv| + |yu - yv|
                int nd =
                    Math.abs(pts[u][0] - pts[v][0])
                    + Math.abs(pts[u][1] - pts[v][1]);
                pq.offer(new int[]{nd, v});
            }
        }
    }
    // while लूप समाप्त होने के बाद, cost में MST की कुल लागत संग्रहीत है
    return cost;
}
```
