# Adding One to a Number Represented as an Array — सरणी में दर्शाई गई संख्या में 1 जोड़ना

## समस्या का सार

एक गैर-ऋणात्मक पूर्णांक को एक-एक अंक करके संग्रहीत करने वाली सरणी `digits` दी गई है। सरणी का पहला तत्व सबसे बड़ा अंक (most significant digit) है और अंतिम तत्व सबसे छोटा अंक (least significant digit) है। इस संख्या में 1 जोड़कर परिणाम को उसी प्रारूप की सरणी में लौटाना है। प्रत्येक तत्व 0 से 9 तक का एक अंक है।

## मूल विचार

अंतिम अंक से 1 जोड़ना शुरू करें और जैसे ही हासिल (carry) उत्पन्न होना बंद हो, तुरंत परिणाम लौटा दें। हासिल केवल तभी उत्पन्न होता है जब वह अंक 9 हो, और केवल सभी अंक 9 होने की स्थिति में ही सरणी की लंबाई 1 बढ़ती है।

## विचार प्रक्रिया

1. **जोड़ सबसे छोटे अंक से शुरू करें**: संख्याओं का जोड़ इकाई के स्थान से शुरू करना स्वाभाविक है, इसलिए सरणी को अंत से शुरुआत की ओर उल्टे क्रम में स्कैन करें
2. **हासिल रुकने की शर्त पर विचार करें**: यदि वर्तमान अंक 9 से कम है, तो 1 जोड़ने पर हासिल उत्पन्न नहीं होता। उस बिंदु पर जोड़ पूरा हो जाता है, इसलिए तुरंत सरणी लौटाई जा सकती है
3. **अंक 9 होने पर प्रक्रिया पर विचार करें**: जब वर्तमान अंक 9 हो, तो 1 जोड़ने पर 10 बनता है और हासिल उत्पन्न होता है। इस अंक को 0 करके हासिल को अगले ऊपरी अंक तक प्रसारित करें। लूप के अगले पुनरावृत्ति में ऊपरी अंक में 1 जोड़ने की प्रक्रिया स्वाभाविक रूप से हो जाती है
4. **सभी अंक 9 होने की स्थिति पर विचार करें**: 999 जैसे सभी अंक 9 होने पर, लूप अंत तक चलने पर भी हासिल नहीं रुकता। परिणाम 1000 की तरह अंकों की संख्या 1 बढ़ जाती है। केवल इस स्थिति में एक नई सरणी बनाकर पहले स्थान पर 1 सेट करें। Java में `new int[]` सभी तत्वों को 0 से आरंभ करता है, इसलिए शेष अंकों में 0 डालने की आवश्यकता नहीं है
5. **हासिल को चर में प्रबंधित करने की आवश्यकता नहीं है**: हासिल का मान हमेशा 1 होता है, और लूप के जारी रहने का अर्थ ही यह है कि हासिल मौजूद है, इसलिए carry चर बनाए बिना लूप के जारी रहने को ही हासिल की उपस्थिति का संकेत मानने वाली संरचना बनाई जा सकती है

## पूर्वापेक्षित ज्ञान

### सरणी का उल्टा क्रम स्कैन

सरणी को अंत से शुरुआत की ओर लूप करें। `i = n - 1` से शुरू करके `i >= 0` तक `i--` से घटाएं।

```java
int[] digits = {1, 2, 3};
int n = digits.length;                  // सरणी की लंबाई प्राप्त करें → 3
for (int i = n - 1; i >= 0; i--) {      // i=2, 1, 0 के क्रम में लूप चलता है
    System.out.println(digits[i]);      // 3, 2, 1 के क्रम में आउटपुट होता है
}
```

### Java की सरणी आरंभीकरण

`new int[n]` से लंबाई n की पूर्णांक सरणी बनाने पर सभी तत्व स्वचालित रूप से 0 से आरंभ हो जाते हैं। स्पष्ट रूप से 0 डालने की आवश्यकता नहीं है।

```java
int[] result = new int[4];   // {0, 0, 0, 0} से आरंभ होती है
result[0] = 1;               // {1, 0, 0, 0} बन जाती है
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n) — सरणी को अंत से शुरुआत तक अधिकतम एक बार स्कैन करता है |
| Space | O(1) — सभी अंक 9 होने की स्थिति को छोड़कर, इनपुट सरणी को यथास्थान संशोधित करता है इसलिए अतिरिक्त मेमोरी की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: गैर-ऋणात्मक पूर्णांक के प्रत्येक अंक को संग्रहीत करने वाली पूर्णांक सरणी digits
// आउटपुट: digits द्वारा दर्शाई गई संख्या में 1 जोड़ने के परिणाम को संग्रहीत करने वाली int[] लौटाता है
public int[] plusOne(int[] digits) {
    // सरणी की लंबाई सहेजें। उल्टे क्रम स्कैन की लूप सीमा और सभी अंक 9 होने पर नई सरणी की लंबाई के लिए उपयोग होती है
    int n = digits.length;

    // अंत से शुरुआत की ओर स्कैन करें। लूप का जारी रहना स्वयं "हासिल मौजूद है" का अर्थ रखता है
    for (int i = n - 1; i >= 0; i--) {
        // यदि वर्तमान अंक 9 से कम है तो हासिल उत्पन्न नहीं होता। जोड़कर तुरंत लौटाएं
        if (digits[i] < 9) {
            digits[i]++;
            return digits;  // हासिल नहीं है। संशोधित सरणी को यथावत लौटाकर समाप्त करें
        }
        // वर्तमान अंक 9 है इसलिए 0 करके हासिल को ऊपरी अंक तक प्रसारित करें
        digits[i] = 0;
    }

    // सभी अंक 9 थे (उदा: [9,9,9] → [0,0,0]), अंकों की संख्या 1 बढ़ती है
    // new int[] सभी तत्वों को 0 से आरंभ करता है, इसलिए शेष अंकों में 0 डालने की आवश्यकता नहीं है
    int[] result = new int[n + 1];
    result[0] = 1;  // पहले स्थान पर 1 सेट करें (उदा: 999 + 1 = 1000 → [1, 0, 0, 0])
    return result;
}
```
