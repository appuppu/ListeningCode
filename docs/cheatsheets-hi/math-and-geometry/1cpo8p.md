# Rotating a Matrix 90 Degrees — n×n मैट्रिक्स को अतिरिक्त मेमोरी के बिना 90 डिग्री दक्षिणावर्त घुमाना

## समस्या का सार

n×n का एक वर्ग मैट्रिक्स दिया गया है। इस मैट्रिक्स को दक्षिणावर्त (clockwise) 90 डिग्री घुमाना है। नया मैट्रिक्स आवंटित किए बिना, **in-place（उसी स्थान पर）** रूपांतरण करना है। घुमाने के बाद, मूल मैट्रिक्स का प्रत्येक तत्व `matrix[i][j]` स्थिति `matrix[j][n-1-i]` पर चला जाता है।

## मूल विचार

90 डिग्री घुमाव को "ट्रांसपोज़ (पंक्तियों और स्तंभों को आपस में बदलना)" + "प्रत्येक पंक्ति को बाएँ-दाएँ उलटना" — इन दो सरल संक्रियाओं में विभाजित किया जा सकता है। इस विभाजन के कारण, अतिरिक्त मेमोरी के बिना प्रत्येक तत्व को सही स्थिति पर ले जाया जा सकता है।

## विचार प्रक्रिया

1. **घुमाव के गंतव्य का अवलोकन करना**: तत्व `matrix[i][j]` 90 डिग्री दक्षिणावर्त घुमाव में `matrix[j][n-1-i]` पर चला जाता है। इस रूपांतरण को सीधे एक-एक तत्व पर करने से 4 तत्वों का चक्रीय विस्थापन आवश्यक हो जाता है, जो जटिल हो जाता है
2. **क्या घुमाव को ज्ञात संक्रियाओं में विभाजित किया जा सकता है**: ट्रांसपोज़ संक्रिया `matrix[i][j]` को `matrix[j][i]` पर ले जाती है। ट्रांसपोज़ के बाद प्रत्येक पंक्ति को बाएँ-दाएँ उलटने पर, `matrix[j][i]` स्थिति `matrix[j][n-1-i]` पर चला जाता है। यह मूल `matrix[i][j]` → `matrix[j][n-1-i]` अर्थात 90 डिग्री घुमाव से मेल खाता है
3. **ट्रांसपोज़ को in-place में कैसे करें**: विकर्ण (`i == j`) को सीमा मानकर, ऊपरी त्रिभुज और निचले त्रिभुज के तत्वों को आपस में बदलना है। `j > i` की सीमा में `matrix[i][j]` और `matrix[j][i]` को swap करने से, प्रत्येक जोड़ी का केवल एक बार आदान-प्रदान होता है
4. **प्रत्येक पंक्ति के उलटाव को in-place में कैसे करें**: प्रत्येक पंक्ति के लिए, बाएँ छोर और दाएँ छोर पर पॉइंटर रखकर, केंद्र की ओर बढ़ते हुए तत्वों को आपस में बदलना है। इस संक्रिया में अतिरिक्त मेमोरी की आवश्यकता नहीं होती
5. **दोनों संक्रियाओं को क्रम से लागू करना**: पहले पूरे मैट्रिक्स का ट्रांसपोज़ करना है, फिर प्रत्येक पंक्ति को उलटना है। दोनों in-place में की जा सकती हैं, इसलिए कुल मिलाकर O(1) अतिरिक्त मेमोरी में 90 डिग्री घुमाव पूरा हो जाता है

## पूर्वापेक्षित ज्ञान

### ट्रांसपोज़ (Transpose) क्या है

मैट्रिक्स की पंक्तियों और स्तंभों को आपस में बदलने की संक्रिया। तत्व `matrix[i][j]` और `matrix[j][i]` की स्थितियों को आपस में बदला जाता है। वर्ग मैट्रिक्स के मामले में, विकर्ण पर स्थित तत्व नहीं हिलते, और विकर्ण के दोनों ओर सममित स्थिति के तत्वों को आपस में बदला जाता है।

```java
// 3×3 मैट्रिक्स के ट्रांसपोज़ का उदाहरण
// ट्रांसपोज़ से पहले:   ट्रांसपोज़ के बाद:
// [1, 2, 3]            [1, 4, 7]
// [4, 5, 6]  →         [2, 5, 8]
// [7, 8, 9]            [3, 6, 9]

// matrix[0][1]=2 और matrix[1][0]=4 आपस में बदले जाते हैं
int temp = matrix[i][j];
matrix[i][j] = matrix[j][i];
matrix[j][i] = temp;
```

### सरणी का उलटाव (Reverse) क्या है

सरणी के तत्वों को बाएँ-दाएँ सममित रूप से आपस में बदलने की संक्रिया। बाएँ छोर और दाएँ छोर से केंद्र की ओर पॉइंटर बढ़ाते हुए आदान-प्रदान किया जाता है।

```java
// [1, 4, 7] → [7, 4, 1]
int left = 0, right = n - 1;
while (left < right) {
    int temp = array[left];
    array[left] = array[right];
    array[right] = temp;
    left++;
    right--;
}
```

### in-place (उसी स्थान पर) संक्रिया क्या है

नई डेटा संरचना आवंटित किए बिना, इनपुट डेटा को सीधे संशोधित करने वाली संक्रिया। अस्थायी चर (`temp`) का उपयोग O(1) होता है इसलिए यह स्वीकार्य है। समस्या में "नया मैट्रिक्स आवंटित न करें" का निर्देश दिया गया है, इसलिए in-place में हल करना आवश्यक है।

## गणनात्मक जटिलता

| | मान |
|---|---|
| Time | O(n²) — ट्रांसपोज़ में n²/2 बार और उलटाव में n²/2 बार आदान-प्रदान किया जाता है |
| Space | O(1) — केवल अस्थायी चर का उपयोग होता है, नया मैट्रिक्स आवंटित नहीं किया जाता |

## कोड

```java
// इनपुट: n×n का पूर्णांक मैट्रिक्स matrix (2-आयामी सरणी int[][])। वर्ग मैट्रिक्स होने के कारण पंक्तियों और स्तंभों की संख्या समान है
// आउटपुट: कुछ नहीं (void)। तर्क के रूप में दिए गए matrix को ही 90 डिग्री दक्षिणावर्त घुमाई हुई स्थिति में बदला जाता है
public void rotate(int[][] matrix) {
    // matrix.length से मैट्रिक्स का आकार n प्राप्त करना
    int n = matrix.length;

    // चरण 1: ट्रांसपोज़ (विकर्ण के आर-पार तत्वों को बदलकर, पंक्तियों और स्तंभों को आपस में बदलना)
    for (int i = 0; i < n; i++) {
        // j को i+1 से शुरू करने का कारण: विकर्ण पर (i==j) आदान-प्रदान अनावश्यक है, j<i की सीमा पहले से बदली जा चुकी है
        for (int j = i + 1; j < n; j++) {
            // matrix[i][j] और matrix[j][i] को अस्थायी चर का उपयोग करके बदलना, जिससे पंक्ति और स्तंभ आपस में बदल जाते हैं
            int temp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = temp;
        }
    }

    // चरण 2: प्रत्येक पंक्ति को बाएँ-दाएँ उलटना
    for (int i = 0; i < n; i++) {
        // बाएँ छोर और दाएँ छोर पर दो पॉइंटर रखकर, केंद्र की ओर बढ़ते हुए आदान-प्रदान करना
        int left = 0, right = n - 1;
        while (left < right) {
            // matrix[i][left] और matrix[i][right] को बदलकर पंक्ति को बाएँ-दाएँ उलटना
            int temp = matrix[i][left];
            matrix[i][left] = matrix[i][right];
            matrix[i][right] = temp;
            left++;
            right--;
        }
    }
    // सभी पंक्तियों का उलटाव पूरा होने पर, पूरा मैट्रिक्स 90 डिग्री दक्षिणावर्त घुमाई हुई स्थिति में आ जाता है
}
```
