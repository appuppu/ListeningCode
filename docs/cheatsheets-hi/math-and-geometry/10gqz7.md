# Detecting Axis-Aligned Squares From Points — संग्रहीत बिंदुओं से अक्ष-समानांतर वर्गों की गिनती करना

## समस्या का सार

2D समतल पर बिंदु जोड़ने वाली `add` संक्रिया और दिए गए बिंदु को एक शीर्ष के रूप में शामिल करने वाले **अक्ष-समानांतर वर्गों** (जिनकी चारों भुजाएँ x-अक्ष या y-अक्ष के समानांतर हों) की संख्या लौटाने वाली `count` संक्रिया वाली एक डेटा संरचना को डिज़ाइन करना है। एक ही निर्देशांक पर कई बार जोड़े गए बिंदुओं को अलग-अलग बिंदुओं के रूप में माना जाता है।

## मूल विचार

अक्ष-समानांतर वर्ग में विकर्ण पर 2 बिंदु निर्धारित हो जाएँ तो शेष 2 बिंदु स्वतः निश्चित हो जाते हैं। क्वेरी बिंदु के समान x-निर्देशांक वाले बिंदुओं को विकर्ण के साथी उम्मीदवार के रूप में सूचीबद्ध करना है, और शेष 2 कोनों की उपस्थिति को HashMap से O(1) में सत्यापित करने पर वर्गों की गिनती कुशलतापूर्वक की जा सकती है।

## विचार प्रक्रिया

1. **अक्ष-समानांतर वर्ग के गुणों को समझना**: चारों भुजाएँ x-अक्ष और y-अक्ष के समानांतर होने के कारण, 4 शीर्ष `(x1,y1)`, `(x1,y2)`, `(x2,y1)`, `(x2,y2)` के रूप में होते हैं। अर्थात, समान x-निर्देशांक वाले 2 बिंदुओं और समान y-निर्देशांक वाले 2 बिंदुओं के संयोजन से वर्ग बनता है
2. **विकर्ण के 2 बिंदुओं से शेष 2 बिंदुओं को निर्धारित करना**: क्वेरी बिंदु `(px, py)` और उसी x-निर्देशांक पर भिन्न y-निर्देशांक वाले बिंदु `(px, pt_y)` को चुनने पर, भुजा की लंबाई `|py - pt_y|` होती है। शेष 2 शीर्ष `(px ± side, py)` और `(px ± side, pt_y)` की स्थिति पर होने चाहिए
3. **वर्ग बाएँ और दाएँ दोनों दिशाओं में बन सकता है**: भुजा की लंबाई `side` निर्धारित होने पर, दूसरा x-निर्देशांक `px - side` या `px + side` दो प्रकार से हो सकता है। दोनों दिशाओं की जाँच करना आवश्यक है
4. **प्रत्येक निर्देशांक पर बिंदुओं की संख्या रिकॉर्ड करना**: एक ही निर्देशांक पर कई बिंदु जोड़े जा सकते हैं, इसलिए HashMap में प्रत्येक निर्देशांक की बिंदु उपस्थिति संख्या का प्रबंधन करना है। शेष 2 शीर्षों की उपस्थिति संख्याओं का गुणनफल उस संयोजन से बनने वाले वर्गों की संख्या होती है
5. **समान x-निर्देशांक वाले बिंदुओं को तेज़ी से प्राप्त करना**: x-निर्देशांक को कुंजी बनाकर, उस निर्देशांक वाले सभी बिंदुओं की सूची को अलग HashMap में प्रबंधित करना है। इससे `count` के समय केवल समान x-निर्देशांक वाले बिंदुओं को कुशलतापूर्वक सूचीबद्ध किया जा सकता है
6. **परिणाम को संचित करके लौटाना**: प्रत्येक साथी उम्मीदवार और प्रत्येक दिशा के लिए, शेष 2 शीर्षों की उपस्थिति संख्याओं के गुणनफल को परिणाम में जोड़ते जाना है

## पूर्वापेक्षित ज्ञान

### HashMap की कुंजी के रूप में निर्देशांक का उपयोग करने की विधि

2D निर्देशांक `(x, y)` को HashMap की कुंजी बनाने के लिए, इसे स्ट्रिंग `"x,y"` में बदलने की विधि है। इससे किसी भी निर्देशांक के लिए O(1) में मान संग्रहीत और प्राप्त किया जा सकता है।

```java
Map<String, Integer> cnt = new HashMap<>();
String key = x + "," + y;               // निर्देशांक (3,5) → "3,5"
cnt.put(key, cnt.getOrDefault(key, 0) + 1);  // उस निर्देशांक की उपस्थिति संख्या 1 बढ़ाना
cnt.getOrDefault(key, 0);               // यदि अस्तित्व में नहीं है तो 0 लौटाना
```

### computeIfAbsent क्या है

यह एक विधि है जो निर्दिष्ट कुंजी Map में मौजूद न होने पर ही नया मान बनाकर पंजीकृत करती है। यदि कुंजी पहले से मौजूद है तो वह मौजूदा मान को वैसे ही लौटाती है। सूचियों का Map बनाते समय यह सुविधाजनक है।

```java
Map<Integer, List<int[]>> xMap = new HashMap<>();
// यदि कुंजी 5 मौजूद नहीं है तो नई ArrayList बनाना, मौजूद होने पर उस सूची को लौटाना
xMap.computeIfAbsent(5, k -> new ArrayList<>()).add(new int[]{5, 3});
```

### संयोजनों की गिनती (गुणन का नियम)

जब 2 स्वतंत्र विकल्पों में क्रमशः `c1` तरीके और `c2` तरीके हों, तो संयोजनों की कुल संख्या `c1 * c2` होती है। इस समस्या में, शेष 2 शीर्षों के निर्देशांकों पर क्रमशः `c1` और `c2` बिंदु मौजूद होने पर, उन 2 शीर्षों को चुनने के तरीके `c1 * c2` होते हैं।

## जटिलता

| | मान |
|---|---|
| Time | add: O(1) — केवल HashMap में पंजीकरण। count: O(n) — समान x-निर्देशांक वाले सभी बिंदुओं का अवलोकन |
| Space | O(n) — सभी बिंदुओं के निर्देशांक और उपस्थिति संख्या को HashMap में संग्रहीत करना |

## कोड

```java
// add(int[] p): 2D समतल पर बिंदु p = [x, y] को जोड़ना
// count(int[] p): बिंदु p = [x, y] को एक शीर्ष के रूप में शामिल करने वाले अक्ष-समानांतर वर्गों की संख्या int में लौटाना
class DetectSquares {
    // प्रत्येक निर्देशांक की उपस्थिति संख्या प्रबंधित करने वाला HashMap (कुंजी: "x,y")
    // count के समय किसी भी निर्देशांक पर कितने बिंदु हैं यह O(1) में प्राप्त करने के लिए उपयोग
    Map<String, Integer> cnt;
    // समान x-निर्देशांक वाले बिंदुओं की सूची प्रबंधित करने वाला HashMap (कुंजी: x-निर्देशांक)
    // count के समय केवल समान x-निर्देशांक वाले बिंदुओं को कुशलतापूर्वक सूचीबद्ध करने के लिए उपयोग
    Map<Integer, List<int[]>> xMap;

    DetectSquares() {
        cnt = new HashMap<>();
        xMap = new HashMap<>();
    }

    void add(int[] p) {
        // निर्देशांक को स्ट्रिंग "x,y" में बदलकर उपस्थिति संख्या 1 बढ़ाना
        String key = p[0] + "," + p[1];
        cnt.put(key, cnt.getOrDefault(key, 0) + 1);

        // x-निर्देशांक के अनुसार सूची में बिंदु जोड़ना (पहली बार का x-निर्देशांक हो तो नई सूची बनाना)
        xMap.computeIfAbsent(p[0],
            k -> new ArrayList<>()).add(p);
    }

    int count(int[] p) {
        int res = 0;
        int px = p[0], py = p[1];

        // क्वेरी बिंदु के समान x-निर्देशांक वाले बिंदुओं की सूची प्राप्त करना
        // सूची मौजूद न होने पर वर्ग नहीं बन सकता इसलिए 0 लौटाना
        List<int[]> same = xMap.get(px);
        if (same == null) return 0;

        // समान x-निर्देशांक के प्रत्येक बिंदु को साथी उम्मीदवार के रूप में जाँचना
        for (int[] pt : same) {
            // भुजा की लंबाई की गणना करना (क्वेरी बिंदु और साथी बिंदु के y-निर्देशांक के अंतर का निरपेक्ष मान)
            int side = Math.abs(py - pt[1]);
            // समान y-निर्देशांक वाले बिंदु की भुजा लंबाई 0 होती है और वर्ग नहीं बन सकता इसलिए छोड़ना
            if (side == 0) continue;

            // वर्ग बाएँ और दाएँ 2 दिशाओं में बन सकता है, इसलिए दोनों x-निर्देशांक आज़माना
            int[] dirs = {px - side, px + side};
            for (int nx : dirs) {
                // शेष 2 शीर्षों के निर्देशांक (nx, py) और (nx, pt[1]) की उपस्थिति संख्या प्राप्त करना
                // अस्तित्व में न होने वाले निर्देशांक 0 होते हैं, और गुणनफल भी 0 होता है इसलिए स्वतः जुड़ता नहीं
                String k1 = nx + "," + py;
                String k2 = nx + "," + pt[1];
                int c1 = cnt.getOrDefault(k1, 0);
                int c2 = cnt.getOrDefault(k2, 0);

                // 2 शीर्षों की उपस्थिति संख्याओं का गुणनफल इस संयोजन से बनने वाले वर्गों की संख्या है (गुणन का नियम)
                res += c1 * c2;
            }
        }
        return res;
    }
}
```
