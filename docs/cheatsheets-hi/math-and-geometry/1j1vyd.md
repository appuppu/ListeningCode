# Multiplying Two Numbers Represented as Strings — स्ट्रिंग के रूप में दर्शाई गई दो संख्याओं का गुणन

## समस्या का सार

दो स्ट्रिंग `num1` और `num2` दी गई हैं जो गैर-ऋणात्मक पूर्णांकों को दर्शाती हैं। दोनों संख्याओं के **गुणनफल** को स्ट्रिंग के रूप में लौटाना है। बिल्ट-इन बड़ी संख्या लाइब्रेरी का उपयोग या इनपुट को सीधे पूर्णांक में बदलना प्रतिबंधित है।

## मूल विचार

प्राथमिक विद्यालय में सीखी गई लंबी गुणन विधि (हस्तलिखित गुणन) का वैसा ही अनुकरण करना है। `num1` के i-वें अंक और `num2` के j-वें अंक का गुणनफल, परिणाम के `i + j` वें अंक और `i + j + 1` वें अंक में जोड़ा जाता है — यह स्थिति संबंध कुंजी है।

## विचार प्रक्रिया

1. **लंबी गुणन विधि को पुनः निर्मित करना**: चूंकि पूर्णांक में परिवर्तित नहीं कर सकते, इसलिए एक-एक अंक का गुणन करके परिणाम संचित करने वाली लंबी गुणन विधि को सीधे लागू करना है
2. **गुणनफल की अधिकतम अंक संख्या का अनुमान लगाना**: n अंकों और m अंकों की संख्याओं का गुणनफल अधिकतम `n + m` अंकों का होता है (उदाहरण: 99 × 99 = 9801, 2 अंक × 2 अंक = 4 अंक)। इसलिए, आकार `n + m` की एक सरणी `pos` तैयार करते हैं और प्रत्येक अंक का मान उसमें संग्रहित करते हैं
3. **प्रत्येक अंक के गुणनफल की परिणाम में स्थिति निर्धारित करना**: `num1` के दाएं से i-वें अंक और `num2` के दाएं से j-वें अंक का गुणनफल, परिणाम के दाएं से `i + j` वें और `i + j + 1` वें स्थान को प्रभावित करता है। स्ट्रिंग इंडेक्स में, `num1[i] * num2[j]` का गुणनफल `pos[i + j + 1]` (निचला अंक) और `pos[i + j]` (ऊपरी अंक) में जोड़ा जाता है
4. **कैरी (हासिल) को तुरंत संसाधित करना**: प्रत्येक अंक जोड़ी का गुणनफल गणना करने के बाद, `pos[p2]` में पहले से संचित मान में जोड़ते हैं, 10 से भाग देने पर शेष को उस अंक में रखते हैं, और 10 से भाग देने पर भागफल को ऊपरी अंक `pos[p1]` में जोड़ते हैं। इससे कैरी तुरंत संसाधित हो जाती है
5. **अग्रणी शून्यों को हटाकर स्ट्रिंग बनाना**: सरणी `pos` के आरंभ में शून्य हो सकते हैं (उदाहरण: 3 अंक × 2 अंक का गुणनफल 4 अंकों का होने पर, 5 अंकों की सरणी का पहला स्थान 0 होता है)। अग्रणी शून्यों को छोड़ते हुए `StringBuilder` से स्ट्रिंग बनाते हैं
6. **शून्य का विशेष उपचार**: यदि किसी भी इनपुट का मान `"0"` है, तो गुणनफल निश्चित रूप से `"0"` होता है, इसलिए शीघ्र ही `"0"` लौटाते हैं

## पूर्वापेक्षित ज्ञान

### charAt और वर्ण से संख्या में रूपांतरण

`String.charAt(i)` स्ट्रिंग के i-वें वर्ण को `char` प्रकार में लौटाता है। `char` प्रकार के `'0'`〜`'9'` को पूर्णांक 0〜9 में बदलने के लिए, `'0'` का वर्ण कोड घटाते हैं।

```java
String s = "123";
char c = s.charAt(0);       // '1'（char प्रकार）
int digit = c - '0';        // 1（int प्रकार）। '1' का कोड 49 में से '0' का कोड 48 घटाते हैं
```

### लंबी गुणन विधि में स्थिति संबंध

n अंक × m अंक की लंबी गुणन विधि में, `num1[i]` और `num2[j]` का गुणनफल (अधिकतम 81) 2 अंकों का हो सकता है। ये 2 अंक परिणाम के `pos[i + j]` (ऊपरी अंक) और `pos[i + j + 1]` (निचला अंक) के अनुरूप होते हैं।

```
उदाहरण: "12" × "34"
  num1[0]=1, num2[0]=3 → गुणनफल 3  → pos[0], pos[1] में जोड़ते हैं
  num1[0]=1, num2[1]=4 → गुणनफल 4  → pos[1], pos[2] में जोड़ते हैं
  num1[1]=2, num2[0]=3 → गुणनफल 6  → pos[1], pos[2] में जोड़ते हैं
  num1[1]=2, num2[1]=4 → गुणनफल 8  → pos[2], pos[3] में जोड़ते हैं
```

### StringBuilder

परिवर्तनशील लंबाई की स्ट्रिंग को कुशलतापूर्वक बनाने वाला क्लास। `append` से अंत में वर्ण जोड़ते हैं और अंत में `toString` से `String` में बदलते हैं।

```java
StringBuilder sb = new StringBuilder();  // रिक्त StringBuilder बनाते हैं
sb.append(4);                            // अंत में "4" जोड़ते हैं
sb.append(0);                            // "40" बन जाता है
sb.append(8);                            // "408" बन जाता है
sb.toString();                           // String प्रकार "408" लौटाता है
sb.length();                             // वर्तमान वर्ण संख्या लौटाता है → 3
```

## जटिलता

| | मान |
|---|---|
| Time | O(n × m) — num1 के प्रत्येक अंक और num2 के प्रत्येक अंक के सभी जोड़ों का एक-एक बार गुणन करते हैं |
| Space | O(n + m) — गुणनफल के प्रत्येक अंक को संग्रहित करने वाली सरणी का आकार n + m है |

## कोड

```java
// इनपुट: गैर-ऋणात्मक पूर्णांकों को दर्शाने वाली स्ट्रिंग num1 और num2
// आउटपुट: दोनों संख्याओं के गुणनफल को दर्शाने वाली स्ट्रिंग लौटाता है
String multiply(String num1, String num2) {
    // यदि कोई भी "0" है तो गुणनफल निश्चित रूप से 0 होता है, इसलिए शीघ्र "0" लौटाकर समाप्त करते हैं
    if (num1.equals("0") || num2.equals("0"))
        return "0";

    int n = num1.length();
    int m = num2.length();
    // गुणनफल के प्रत्येक अंक को संग्रहित करने वाली सरणी। n अंक×m अंक का गुणनफल अधिकतम n+m अंकों का होता है, इसलिए यह आकार पर्याप्त है
    int[] pos = new int[n + m];

    // लंबी गुणन विधि की तरह निचले अंक (अंत) से आरंभ की ओर क्रमशः गुणन करते हैं
    for (int i = n - 1; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // charAt से प्राप्त वर्ण में से '0' घटाकर, वर्ण को संगत पूर्णांक में बदलकर गुणन करते हैं
            int mul = (num1.charAt(i) - '0')
                * (num2.charAt(j) - '0');
            // गुणनफल जोड़ने की स्थिति: p1 ऊपरी अंक है, p2 निचला अंक है। यह स्थिति संबंध लंबी गुणन विधि में अंकों के संगत स्थान पर आधारित है
            int p1 = i + j;
            int p2 = i + j + 1;
            // पिछले लूप में उसी स्थान पर जोड़े गए मान को ध्यान में रखते हुए, पहले से संचित मान में जोड़ते हैं
            int sum = mul + pos[p2];
            // निचले अंक में केवल एक अंक रखते हैं (10 से भाग का शेष), और कैरी को ऊपरी अंक में जोड़ते हैं (10 से भाग का भागफल)
            pos[p2] = sum % 10;
            pos[p1] += sum / 10;
        }
    }

    // अग्रणी शून्यों को छोड़ते हुए स्ट्रिंग बनाते हैं (उदाहरण: 5 अंकों की सरणी के आरंभ में 0 होने का मामला)
    StringBuilder sb = new StringBuilder();
    for (int p : pos) {
        // यदि StringBuilder अभी रिक्त है और वर्तमान मान 0 है तो यह अग्रणी शून्य है इसलिए छोड़ते हैं
        if (sb.length() == 0 && p == 0)
            continue;
        sb.append(p);
    }
    // StringBuilder को String प्रकार में बदलकर लौटाते हैं
    return sb.toString();
}
```
