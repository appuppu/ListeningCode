# Computing Power of a Number Efficiently — फ़्लोटिंग-पॉइंट संख्या की घात को कुशलतापूर्वक परिकलित करना

## समस्या का सार

एक फ़्लोटिंग-पॉइंट संख्या `x` और एक पूर्णांक `n` दिया गया है। हमें `x` की `n` वीं घात की गणना करके लौटानी है। `n` ऋणात्मक हो सकता है इसलिए ऋणात्मक घातांक को भी संभालना आवश्यक है, और `n` का निरपेक्ष मान बहुत बड़ा होने पर भी गणना कुशलतापूर्वक करनी होगी।

## मूल विचार

यदि हम घातांक `n` को बाइनरी में व्यक्त करें, तो घात की गणना को "x का बार-बार वर्ग करते हुए, n के प्रत्येक बिट के 1 होने पर ही परिणाम में गुणा करना" इस संक्रिया में विभाजित किया जा सकता है। इससे n बार गुणा करने की संख्या घटकर log(n) बार रह जाती है।

## विचार प्रक्रिया

1. **ऋणात्मक घातांक को धनात्मक घातांक में बदलना**: `x^(-n)` का मान `(1/x)^n` के बराबर होता है, इसलिए यदि `n` ऋणात्मक है तो `x` को `1/x` से बदलकर और `n` का चिह्न उलटकर, समस्या को धनात्मक घातांक की समस्या में एकीकृत किया जा सकता है
2. **n बार गुणा करना बहुत धीमा है**: सीधे `x` को `n` बार गुणा करने पर O(n) समय लगता है। जब `n` अरबों में हो, तो यह पर्याप्त नहीं है। घातांक को आधा-आधा कम करने की विधि आवश्यक है
3. **घात को बार-बार वर्ग करके विभाजित किया जा सकता है**: `x^10 = x^8 × x^2` की तरह, किसी भी घात को 2 की घातों के गुणनफल में विभाजित किया जा सकता है। यह घातांक `n` के बाइनरी प्रतिनिधित्व से मेल खाता है। `10` बाइनरी में `1010` है, इसलिए केवल उन स्थानों पर जहाँ बिट 1 है, अर्थात `x^8` और `x^2` को गुणा करना पर्याप्त है
4. **बिट संक्रिया से प्रत्येक अंक की जाँच करना**: `n` का सबसे निचला बिट 1 है या नहीं, यह `(n & 1) == 1` से जाँचा जा सकता है। यदि 1 है, तो उस समय का `x` (वर्तमान अंक के अनुरूप 2 की घात तक घातित मान) परिणाम में गुणा किया जाता है
5. **x का बार-बार वर्ग करके अंक बढ़ाना**: प्रत्येक लूप में `x` को `x * x` से अपडेट करने पर, `x` मूल मान का वर्ग, चतुर्थ घात, अष्टम घात… इस प्रकार 2 की घात के अनुरूप घातित होता जाता है। साथ ही `n` को 1 बिट दाएँ शिफ़्ट करके अगले अंक पर आगे बढ़ते हैं
6. **लूप की समाप्ति शर्त**: `n` को दाएँ शिफ़्ट करते रहने पर अंततः यह 0 हो जाता है। जब तक `n > 0` है, लूप चलाने से सभी बिट्स संसाधित हो जाते हैं

## पूर्वापेक्षित ज्ञान

### बिट संक्रियाएँ (& और >>) क्या हैं

पूर्णांक को बाइनरी के रूप में मानकर, बिट स्तर पर संचालित करने वाली संक्रियाएँ। `&` (AND) केवल तभी 1 देता है जब दोनों बिट 1 हों। `>>` (दायाँ शिफ़्ट) बिट श्रृंखला को दाईं ओर सरकाता है और सबसे निचले बिट को हटाता है (यह 2 से भाग देने के समान है)।

```java
int n = 10;           // बाइनरी: 1010
n & 1;                // सबसे निचला बिट प्राप्त करना → 0 (सम संख्या)
n >>= 1;              // 1 बिट दायाँ शिफ़्ट → n 5 हो जाता है (बाइनरी: 101)
n & 1;                // सबसे निचला बिट प्राप्त करना → 1 (विषम संख्या)
```

### बार-बार वर्ग करने की विधि (Fast Exponentiation) क्या है

घातांक के बाइनरी प्रतिनिधित्व का उपयोग करके, घात की गणना को O(log n) बार गुणा में करने की तकनीक। `x^13` को उदाहरण के रूप में लें, तो `13` बाइनरी में `1101` है, इसलिए `x^13 = x^8 × x^4 × x^1` के रूप में विभाजित किया जा सकता है। लूप में `x` का बार-बार वर्ग करते हुए (`x → x^2 → x^4 → x^8`), जिस बिट का मान 1 है उसे ही परिणाम में गुणा किया जाता है।

```java
// x^13 की गणना प्रक्रिया (13 = 1101 बाइनरी में)
// बिट 0: 1 → result *= x    (result = x^1),  x = x^2
// बिट 1: 0 → छोड़ना,                          x = x^4
// बिट 2: 1 → result *= x^4  (result = x^5),  x = x^8
// बिट 3: 1 → result *= x^8  (result = x^13), x = x^16
```

### long टाइप में कास्ट करना क्यों आवश्यक है

Java में `int` टाइप की सीमा `-2^31` से `2^31 - 1` तक है। जब `n = -2^31` हो, तो `-n` का मान `2^31` हो जाता है जो `int` की सीमा से बाहर है और ओवरफ़्लो हो जाता है। `long` टाइप में कास्ट करने के बाद चिह्न उलटने से इस समस्या से बचा जा सकता है।

```java
int n = Integer.MIN_VALUE;   // -2147483648
long power = (long) n;       // -2147483648L (long टाइप में रूपांतरित)
power = -power;              // 2147483648L (int टाइप में यह व्यक्त नहीं हो सकता लेकिन long टाइप में सुरक्षित है)
```

## परिकलन जटिलता

| | मान |
|---|---|
| Time | O(log n) — घातांक n के बिट्स की संख्या जितनी बार लूप चलता है |
| Space | O(1) — केवल result, x, power ये 3 चर उपयोग होते हैं और पुनरावर्तन स्टैक भी अनावश्यक है |

## कोड

```java
// इनपुट: फ़्लोटिंग-पॉइंट संख्या x और पूर्णांक n
// आउटपुट: x की n वीं घात का मान double में लौटाना
double myPow(double x, int n) {
    // int टाइप में n = -2^31 होने पर चिह्न उलटने से ओवरफ़्लो होता है इसलिए long टाइप में बदलना
    long power = (long) n;

    // ऋणात्मक घातांक को धनात्मक में बदलना: x^(-n) = (1/x)^n
    // इस रूपांतरण से आगे की सभी प्रक्रिया केवल धनात्मक घातांक के लिए एकीकृत हो जाती है
    if (power < 0) {
        x = 1 / x;
        power = -power;
    }

    // परिणाम संचित करने वाले चर को 1.0 से आरंभ करना
    // जिन अंकों का बिट 1 है उनके अनुरूप x की घात को गुणा करके अंतिम परिणाम संचित किया जाता है
    double result = 1.0;

    // power के सभी बिट्स को निचले क्रम से एक-एक करके संसाधित करना
    // power को दाएँ शिफ़्ट करते रहने पर अंततः 0 हो जाता है और सभी अंकों का संसाधन पूर्ण हो जाता है
    while (power > 0) {
        // power & 1 से सबसे निचला बिट (वर्तमान में संसाधित हो रहा अंक) 1 है या नहीं यह जाँचना
        if ((power & 1) == 1) {
            // बिट 1 होने पर: इस समय x मूल x को संसाधित अंकों की संख्या जितनी बार वर्ग किया हुआ मान है (मूल x की 2^k वीं घात)
            // इस अंक के योगदान को result में गुणा करके परिलक्षित करना
            result *= x;
        }
        // x का वर्ग करके अगले अंक के अनुरूप घात मान (दोगुने घातांक की घात) में अपडेट करना
        x *= x;
        // power को 1 बिट दाएँ शिफ़्ट करके अगले अंक पर आगे बढ़ना (सबसे निचला बिट हट जाता है)
        power >>= 1;
    }
    // सभी बिट्स के योगदान का गुणनफल अर्थात अंतिम परिणाम लौटाना
    return result;
}
```
