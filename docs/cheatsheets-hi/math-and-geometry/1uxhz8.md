# Determining if a Number is a Happy Number — प्रत्येक अंक के वर्गों का योग दोहराकर 1 तक पहुँचता है या नहीं यह निर्धारित करना

## समस्या का सार

एक धनात्मक पूर्णांक `n` दिया गया है। `n` के प्रत्येक अंक का वर्ग करके उनका योग निकालने की प्रक्रिया को दोहराया जाता है, और यदि परिणाम **1** तक पहुँचता है तो इसे "हैप्पी नंबर" मानकर `true` लौटाया जाता है। यदि 1 तक नहीं पहुँचता और अनंत लूप में फँस जाता है तो `false` लौटाया जाता है।

## मूल विचार

प्रत्येक अंक के वर्गों का योग दोहराने की प्रक्रिया अनिवार्य रूप से सीमित संख्या के मानों में चक्कर लगाती है। यह Linked List के साइकल डिटेक्शन के समान संरचना है, और Floyd के स्लो पॉइंटर और फास्ट पॉइंटर का उपयोग करके अतिरिक्त मेमोरी के बिना साइकल की उपस्थिति और गंतव्य का निर्धारण किया जा सकता है।

## विचार प्रक्रिया

1. **प्रक्रिया को दोहराने पर अनिवार्य रूप से लूप बनता है**: प्रत्येक अंक के वर्गों का योग निकालने की प्रक्रिया को दोहराने पर मान एक सीमित सीमा में रहते हैं, इसलिए अंततः पहले आया हुआ कोई मान फिर से प्राप्त होता है। अर्थात, अनुक्रम अनिवार्य रूप से "1 पर रुकने वाला लूप" या "1 को न शामिल करने वाला लूप" — इन दोनों में से किसी एक में प्रवेश करता है
2. **लूप डिटेक्शन को साइकल डिटेक्शन समस्या में बदला जा सकता है**: प्रत्येक मान से अगले मान तक के संक्रमण को "नोड से नोड तक का लिंक" मानने पर यह समस्या Linked List में साइकल है या नहीं इसका पता लगाने की समस्या के समान संरचना बन जाती है
3. **Floyd की दो-पॉइंटर विधि से O(1) स्थान में पता लगाना**: स्लो पॉइंटर 1 स्टेप ずつ और फास्ट पॉइंटर 2 स्टेप ずつ आगे बढ़ता है। यदि साइकल मौजूद है तो दोनों पॉइंटर अनिवार्य रूप से साइकल के किसी बिंदु पर मिलते हैं
4. **मिलन बिंदु के मान से परिणाम निर्धारित करना**: जब दोनों पॉइंटर मिलते हैं, यदि वह मान 1 है तो यह हैप्पी नंबर है (1 के प्रत्येक अंक के वर्गों का योग 1 होता है, इसलिए 1 स्वयं एक साइकल बनाता है)। यदि 1 के अलावा किसी अन्य मान पर मिलते हैं, तो 1 को शामिल न करने वाले साइकल में प्रवेश हो चुका है, इसलिए यह हैप्पी नंबर नहीं है
5. **प्रारंभिक मानों की सेटिंग**: स्लो पॉइंटर को `n` पर और फास्ट पॉइंटर को `getNext(n)` पर सेट करके शुरू किया जाता है। ऐसा करने से `while (slow != fast)` लूप में स्वाभाविक रूप से प्रवेश होता है

## पूर्वापेक्षित ज्ञान

### प्रत्येक अंक के वर्गों के योग की गणना

पूर्णांक `n` के प्रत्येक अंक को निकालने के लिए, `n % 10` से सबसे निचले अंक को प्राप्त किया जाता है और `n /= 10` से सबसे निचले अंक को हटाया जाता है — यह प्रक्रिया `n` के 0 होने तक दोहराई जाती है।

```java
int n = 19;
int digit = n % 10;   // सबसे निचला अंक प्राप्त करना → 9
n /= 10;              // सबसे निचला अंक हटाना → n 1 हो जाता है
digit = n % 10;       // अगला अंक प्राप्त करना → 1
// 19 → 1² + 9² = 1 + 81 = 82
```

### Floyd की साइकल डिटेक्शन विधि (दो-पॉइंटर विधि) क्या है

यह Linked List या अनुक्रम में साइकल (लूप) है या नहीं इसका पता लगाने वाला एल्गोरिदम है। स्लो पॉइंटर 1 स्टेप ずつ और फास्ट पॉइंटर 2 स्टेप ずつ आगे बढ़ता है। यदि साइकल मौजूद है तो फास्ट पॉइंटर स्लो पॉइंटर तक पहुँच जाता है और दोनों अनिवार्य रूप से मिलते हैं। अतिरिक्त डेटा संरचना का उपयोग नहीं होने के कारण स्थान जटिलता O(1) है।

```java
int slow = start;                // स्लो पॉइंटर 1 स्टेप ずつ आगे बढ़ता है
int fast = getNext(start);       // फास्ट पॉइंटर की प्रारंभिक स्थिति 1 आगे रखी जाती है
while (slow != fast) {
    slow = getNext(slow);        // 1 स्टेप आगे बढ़ना
    fast = getNext(getNext(fast)); // 2 स्टेप आगे बढ़ना
}
// लूप समाप्त होने पर, slow == fast मिलन बिंदु का मान होता है
```

## जटिलता

| | मान |
|---|---|
| Time | O(log n) — प्रत्येक अंक के वर्गों के योग की गणना में O(log n) लगता है, और साइकल तक पहुँचने के लिए पुनरावृत्तियों की संख्या स्थिरांक में सीमित रहती है |
| Space | O(1) — केवल स्लो पॉइंटर और फास्ट पॉइंटर की दो वेरिएबल्स का उपयोग होता है |

## कोड

```java
// इनपुट: धनात्मक पूर्णांक n
// आउटपुट: यदि n हैप्पी नंबर है तो true, अन्यथा false लौटाता है

// पूर्णांक n के प्रत्येक अंक के वर्गों का योग गणना करके लौटाने वाला सहायक फंक्शन
// n % 10 से सबसे निचला अंक निकाला जाता है, वर्ग को संचित किया जाता है, और n /= 10 से अंक हटाया जाता है — यह प्रक्रिया दोहराई जाती है
private int getNext(int n) {
    int sum = 0;
    while (n > 0) {
        int digit = n % 10;   // सबसे निचला अंक निकालना
        sum += digit * digit;  // अंक के वर्ग को sum में जोड़ना
        n /= 10;               // सबसे निचला अंक हटाना
    }
    return sum;
}

public boolean isHappy(int n) {
    // स्लो पॉइंटर n से और फास्ट पॉइंटर 1 स्टेप आगे getNext(n) से शुरू होता है
    // fast को 1 आगे रखने से while (slow != fast) लूप में स्वाभाविक रूप से प्रवेश होता है
    int slow = n;
    int fast = getNext(n);

    // दोनों पॉइंटर मिलने तक लूप चलता है
    // स्लो और फास्ट की गति के अंतर के कारण, साइकल मौजूद होने पर दोनों अनिवार्य रूप से मिलते हैं
    while (slow != fast) {
        slow = getNext(slow);           // स्लो पॉइंटर 1 स्टेप आगे बढ़ता है
        fast = getNext(getNext(fast));   // फास्ट पॉइंटर 2 स्टेप आगे बढ़ता है
    }

    // यदि मिलन बिंदु 1 है तो यह हैप्पी नंबर है (1 के प्रत्येक अंक के वर्गों का योग 1 होता है, इसलिए 1 स्वयं साइकल बनाता है)
    // यदि 1 के अलावा किसी अन्य मान पर मिलते हैं, तो 1 को शामिल न करने वाले साइकल में प्रवेश हो चुका है इसलिए यह हैप्पी नंबर नहीं है
    return fast == 1;
}
```
