# Traversing a Matrix in Spiral Order — मैट्रिक्स के सभी तत्वों को सर्पिल क्रम में प्राप्त करना

## समस्या का सार

m पंक्तियों और n स्तंभों वाली एक मैट्रिक्स `matrix` दी गई है। ऊपरी-बाएँ कोने से शुरू करके, दाएँ→नीचे→बाएँ→ऊपर के क्रम में बाहरी परिधि को ट्रेस करें और अंदर की ओर दोहराते हुए, सभी तत्वों को **सर्पिल (स्पाइरल) क्रम** में व्यवस्थित एक सरणी लौटाएँ।

## मूल विचार

मैट्रिक्स की बाहरी परिधि को एक "परत" मानें और ऊपरी भुजा, दाईं भुजा, निचली भुजा, बाईं भुजा — इन 4 भुजाओं को क्रमशः स्कैन करें। एक परत की स्कैनिंग पूरी होने पर 4 सीमा पॉइंटरों को अंदर की ओर सिकोड़ने से अगली परत पर स्वाभाविक रूप से संक्रमण होता है।

## विचार प्रक्रिया

1. **सर्पिल स्कैनिंग 4 दिशाओं की पुनरावृत्ति है**: दाएँ→नीचे→बाएँ→ऊपर की 4 दिशाओं को बाहर से अंदर की ओर दोहराने वाली संरचना होने के कारण, वर्तमान स्कैन रेंज की "ऊपरी सीमा, निचली सीमा, बाईं सीमा, दाईं सीमा" को प्रबंधित करने से प्रत्येक दिशा की स्कैन रेंज अद्वितीय रूप से निर्धारित हो जाती है
2. **4 सीमा पॉइंटरों से स्कैन रेंज व्यक्त करना**: `top` (ऊपरी सीमा की पंक्ति), `bottom` (निचली सीमा की पंक्ति), `left` (बाईं सीमा का स्तंभ), `right` (दाईं सीमा का स्तंभ) — ये 4 चर तैयार करें। ये वर्तमान परत की चार भुजाओं की स्थिति दर्शाते हैं
3. **प्रत्येक भुजा का स्कैन क्रम निर्धारित करना**: ऊपरी भुजा बाएँ से दाएँ (स्तंभ बढ़ाना), दाईं भुजा ऊपर से नीचे (पंक्ति बढ़ाना), निचली भुजा दाएँ से बाएँ (स्तंभ घटाना), बाईं भुजा नीचे से ऊपर (पंक्ति घटाना)। इन 4 for लूपों से एक परत की स्कैनिंग पूरी होती है
4. **एक भुजा की स्कैनिंग के बाद सीमा सिकोड़ना**: ऊपरी भुजा स्कैन करने के बाद `top++` (ऊपरी सीमा को 1 पंक्ति नीचे करना), दाईं भुजा स्कैन करने के बाद `right--` (दाईं सीमा को 1 स्तंभ बाएँ करना), निचली भुजा स्कैन करने के बाद `bottom--`, बाईं भुजा स्कैन करने के बाद `left++`। इससे अगले लूप में एक अंदर की परत स्कैन होती है
5. **निचली भुजा और बाईं भुजा की स्कैनिंग के लिए अतिरिक्त शर्त आवश्यक है**: ऊपरी भुजा की स्कैनिंग के बाद `top` बढ़ाने और दाईं भुजा की स्कैनिंग के बाद `right` घटाने के कारण, निचली भुजा की स्कैनिंग के समय `top <= bottom` की शर्त टूट सकती है। इसी प्रकार बाईं भुजा की स्कैनिंग के समय `left <= right` की शर्त टूट सकती है। यदि ये शर्तें पूरी नहीं होतीं, तो पहले से स्कैन की गई पंक्तियों या स्तंभों को दोहराकर पढ़ लिया जाएगा, इसलिए शर्त जाँच आवश्यक है
6. **समाप्ति शर्त सीमाओं का प्रतिच्छेदन है**: `top > bottom` या `left > right` होने पर सभी परतों की स्कैनिंग पूर्ण हो चुकी है। while लूप की शर्त में `top <= bottom && left <= right` निर्दिष्ट करने से लूप स्वाभाविक रूप से समाप्त होता है

## पूर्वापेक्षित ज्ञान

### ArrayList क्या है

एक परिवर्तनीय-लंबाई वाली सरणी है। अंत में तत्व जोड़ने वाला `add` O(1) में कार्य करता है। परिणाम की सर्पिल क्रम सरणी बनाने के लिए इसका उपयोग किया जाता है।

```java
List<Integer> res = new ArrayList<>();  // खाली ArrayList बनाना
res.add(5);                             // अंत में 5 जोड़ना → [5]
res.add(3);                             // अंत में 3 जोड़ना → [5, 3]
res.size();                             // तत्वों की संख्या लौटाना → 2
```

### सीमा पॉइंटर (Boundary Pointers) क्या हैं

मैट्रिक्स की स्कैन रेंज दर्शाने वाले 4 पूर्णांक चर हैं। `top` और `bottom` पंक्तियों की सीमा दर्शाते हैं, `left` और `right` स्तंभों की सीमा दर्शाते हैं। प्रत्येक स्कैन के बाद मान बदलकर रेंज को अंदर की ओर सिकोड़ा जाता है।

```java
int top = 0;                    // ऊपरी सीमा का पंक्ति इंडेक्स (प्रारंभिक मान: 0)
int bottom = matrix.length - 1; // निचली सीमा का पंक्ति इंडेक्स (प्रारंभिक मान: अंतिम पंक्ति)
int left = 0;                   // बाईं सीमा का स्तंभ इंडेक्स (प्रारंभिक मान: 0)
int right = matrix[0].length - 1; // दाईं सीमा का स्तंभ इंडेक्स (प्रारंभिक मान: अंतिम स्तंभ)
top++;    // ऊपरी सीमा को 1 पंक्ति नीचे सिकोड़ना
right--;  // दाईं सीमा को 1 स्तंभ बाएँ सिकोड़ना
```

## जटिलता

| | मान |
|---|---|
| Time | O(m × n) — मैट्रिक्स के सभी तत्वों को ठीक 1 बार स्कैन किया जाता है |
| Space | O(1) — आउटपुट सूची को छोड़कर, केवल 4 सीमा पॉइंटरों का उपयोग किया जाता है |

## कोड

```java
// इनपुट: m पंक्तियों और n स्तंभों वाली पूर्णांक मैट्रिक्स matrix
// आउटपुट: सभी तत्वों को सर्पिल क्रम में संग्रहीत List<Integer> लौटाना
List<Integer> spiralOrder(int[][] matrix) {
    // परिणाम संग्रहीत करने के लिए परिवर्तनीय-लंबाई सूची बनाना
    List<Integer> res = new ArrayList<>();
    // यदि मैट्रिक्स खाली है (पंक्ति संख्या 0 है) तो खाली सूची लौटाना
    if (matrix.length == 0) return res;

    // 4 सीमा पॉइंटरों को प्रारंभ करना। ये वर्तमान में स्कैन की जाने वाली परत की चार भुजाओं की स्थिति दर्शाते हैं
    int top = 0;                      // ऊपरी सीमा की पंक्ति (सबसे ऊपरी पंक्ति)
    int bottom = matrix.length - 1;   // निचली सीमा की पंक्ति (सबसे निचली पंक्ति)
    int left = 0;                     // बाईं सीमा का स्तंभ (सबसे बायाँ स्तंभ)
    int right = matrix[0].length - 1; // दाईं सीमा का स्तंभ (सबसे दायाँ स्तंभ)

    // जब तक स्कैन रेंज मौजूद है, प्रत्येक परत के लिए दोहराना। सीमाओं के प्रतिच्छेदन पर सभी तत्वों की स्कैनिंग पूर्ण होती है
    while (top <= bottom && left <= right) {
        // ऊपरी भुजा: बाएँ से दाएँ स्कैन करना
        for (int c = left; c <= right; c++)
            res.add(matrix[top][c]);
        // ऊपरी भुजा की स्कैनिंग पूर्ण। ऊपरी सीमा को 1 पंक्ति नीचे सिकोड़ना ताकि अगली दाईं भुजा स्कैनिंग में कोने के तत्व दोहराए न जाएँ
        top++;

        // दाईं भुजा: ऊपर से नीचे स्कैन करना (top अपडेट हो चुका है इसलिए कोने का दोहराव नहीं)
        for (int r = top; r <= bottom; r++)
            res.add(matrix[r][right]);
        // दाईं भुजा की स्कैनिंग पूर्ण। दाईं सीमा को 1 स्तंभ बाएँ सिकोड़ना
        right--;

        // निचली भुजा: दाएँ से बाएँ स्कैन करना
        // शर्त जाँच: top++ के परिणामस्वरूप top > bottom होने पर (केवल 1 पंक्ति शेष होने पर),
        // निचली भुजा ऊपरी भुजा के समान पंक्ति है और पहले ही स्कैन हो चुकी है इसलिए छोड़ना
        if (top <= bottom) {
            for (int c = right; c >= left; c--)
                res.add(matrix[bottom][c]);
            // निचली सीमा को 1 पंक्ति ऊपर सिकोड़ना
            bottom--;
        }

        // बाईं भुजा: नीचे से ऊपर स्कैन करना
        // शर्त जाँच: right-- के परिणामस्वरूप left > right होने पर (केवल 1 स्तंभ शेष होने पर),
        // बाईं भुजा दाईं भुजा के समान स्तंभ है और पहले ही स्कैन हो चुकी है इसलिए छोड़ना
        if (left <= right) {
            for (int r = bottom; r >= top; r--)
                res.add(matrix[r][left]);
            // बाईं सीमा को 1 स्तंभ दाएँ सिकोड़ना
            left++;
        }
    }
    // सभी m×n तत्व सर्पिल क्रम में संग्रहीत सूची को लौटाना
    return res;
}
```
