# Setting Entire Rows and Columns to Zero — शून्य वाली पंक्तियों और स्तंभों को पूरी तरह शून्य करना

## समस्या का सार

m×n का एक मैट्रिक्स दिया गया है। जहाँ भी कोई तत्व 0 है, उस तत्व की **पूरी पंक्ति** और **पूरा स्तंभ** 0 से भर दें। यह रूपांतरण in-place (बिना अतिरिक्त मैट्रिक्स का उपयोग किए) करना है।

## मूल विचार

मैट्रिक्स की पंक्ति 0 और स्तंभ 0 को "किस पंक्ति और किस स्तंभ को शून्य करना है" यह दर्ज करने के लिए फ्लैग क्षेत्र के रूप में पुन: उपयोग करें, तो अतिरिक्त स्पेस O(1) में शून्य करने योग्य पंक्तियों और स्तंभों का प्रबंधन किया जा सकता है।

## विचार प्रक्रिया

1. **शून्य करने योग्य पंक्तियों और स्तंभों को दर्ज करना आवश्यक है**: स्कैन के दौरान शून्य मिलते ही उस पंक्ति या स्तंभ को बदल दें, तो बाद के स्कैन में यह भेद नहीं कर पाएँगे कि मूल मान शून्य था या बदलाव के कारण शून्य हुआ। इसलिए पहले "किस पंक्ति और स्तंभ को शून्य करना है" दर्ज करें, फिर एक साथ बदलें — यह 2-पास विधि आवश्यक है
2. **दर्ज करने के लिए अलग सरणी का उपयोग करने पर O(m+n) स्पेस लगता है**: पंक्तियों के लिए आकार m की सरणी और स्तंभों के लिए आकार n की सरणी से दर्ज किया जा सकता है, लेकिन O(1) स्पेस का लक्ष्य रखना है
3. **मैट्रिक्स की अपनी पंक्ति 0 और स्तंभ 0 को फ्लैग के रूप में उपयोग करें**: `matrix[i][0]` यदि 0 है तो इसका अर्थ है "पंक्ति i को शून्य करना है", `matrix[0][j]` यदि 0 है तो इसका अर्थ है "स्तंभ j को शून्य करना है"। इस प्रकार अतिरिक्त सरणी की आवश्यकता नहीं रहती
4. **केवल स्तंभ 0 के फ्लैग के लिए एक स्वतंत्र चर आवश्यक है**: `matrix[i][0]` में "पंक्ति i का फ्लैग" और "स्तंभ 0 का मूल मान" दोनों अर्थ समा जाते हैं। स्तंभ 0 को स्वयं शून्य करना है या नहीं, यह एक अलग चर `firstCol` से प्रबंधित करें
5. **फ्लैग की मार्किंग**: मैट्रिक्स को स्कैन करें, `matrix[i][j] == 0` मिलने पर `matrix[i][0] = 0` और `matrix[0][j] = 0` सेट करके फ्लैग लगाएँ
6. **उल्टे क्रम में शून्य करें**: फ्लैग के आधार पर शून्य लिखते समय, यदि पंक्ति 0 और स्तंभ 0 को पहले बदल दें तो फ्लैग नष्ट हो जाएँगे। इसलिए अंत से उल्टे क्रम में प्रोसेस करें, और पंक्ति 0 तथा स्तंभ 0 को सबसे अंत में प्रोसेस करें

## पूर्वापेक्षित ज्ञान

### in-place ऑपरेशन क्या है

अतिरिक्त डेटा संरचना (अलग मैट्रिक्स या बड़ी सरणी) का उपयोग किए बिना, इनपुट डेटा को स्वयं बदलकर परिणाम प्राप्त करने की क्रिया। केवल स्थिरांक संख्या में अतिरिक्त चर का उपयोग अनुमत है।

```java
// in-place ऑपरेशन का उदाहरण: सरणी के तत्व को सीधे बदलना
matrix[i][j] = 0;  // अलग सरणी में कॉपी किए बिना, मूल मैट्रिक्स को सीधे बदलना
```

### boolean फ्लैग क्या है

true/false के 2 मानों से "कोई शर्त पूरी हुई या नहीं" दर्ज करने वाला चर। लूप में शर्त एक बार भी पूरी होने पर true कर दें, और बाद की प्रोसेसिंग में संदर्भित करें।

```java
boolean firstCol = false;       // प्रारंभिक मान false (शर्त अभी तक पूरी नहीं हुई)
if (matrix[i][0] == 0)
    firstCol = true;            // शर्त पूरी होने को दर्ज करना
// बाद में संदर्भित करना
if (firstCol)
    matrix[i][0] = 0;          // यदि फ्लैग true है तो प्रोसेसिंग निष्पादित करना
```

### उल्टा लूप क्या है

सरणी या मैट्रिक्स को अंत से शुरुआत की ओर स्कैन करने वाला लूप। जब शुरुआत के तत्व बाद की प्रोसेसिंग में फ्लैग का कार्य भी करते हैं, तो शुरुआत को सबसे अंत में प्रोसेस करने के लिए उल्टे क्रम का उपयोग किया जाता है।

```java
for (int i = m - 1; i >= 0; i--)    // i को अंत (m-1) से 0 तक 1 घटाते हुए चलाना
    for (int j = n - 1; j >= 1; j--)  // j को अंत (n-1) से 1 तक 1 घटाते हुए चलाना
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(m × n) — पूरे मैट्रिक्स को 2 बार स्कैन करना (फ्लैग सेट करने में 1 बार, शून्य करने में 1 बार) |
| Space | O(1) — अतिरिक्त चर केवल `firstCol` है। मैट्रिक्स को स्वयं फ्लैग क्षेत्र के रूप में पुन: उपयोग किया जाता है |

## कोड

```java
// इनपुट: m×n का पूर्णांक मैट्रिक्स matrix (2-आयामी सरणी)
// आउटपुट: कुछ नहीं (matrix को सीधे बदलना है। रिटर्न प्रकार void है)
public void setZeroes(int[][] matrix) {
    // पंक्ति संख्या m और स्तंभ संख्या n प्राप्त करना
    int m = matrix.length;
    int n = matrix[0].length;
    // स्तंभ 0 को शून्य करना है या नहीं यह दर्ज करने वाला फ्लैग
    // matrix[i][0] पंक्ति फ्लैग के साथ साझा होता है, इसलिए केवल स्तंभ 0 के फ्लैग को स्वतंत्र चर से प्रबंधित करना
    boolean firstCol = false;

    // पहला पास: फ्लैग की मार्किंग
    for (int i = 0; i < m; i++) {
        // स्तंभ 0 में मूल रूप से शून्य है या नहीं जाँचना, यदि है तो firstCol को true करना
        if (matrix[i][0] == 0)
            firstCol = true;
        // j=1 से स्कैन करना (j=0 पंक्ति फ्लैग के रूप में साझा है इसलिए केवल स्तंभ 1 के बाद देखना)
        for (int j = 1; j < n; j++)
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;  // पंक्ति i को शून्य करने का फ्लैग
                matrix[0][j] = 0;  // स्तंभ j को शून्य करने का फ्लैग
            }
    }

    // दूसरा पास: उल्टे क्रम में शून्य लिखना
    // उल्टे क्रम का कारण: पंक्ति 0 के फ्लैग (matrix[0][j]) को अन्य पंक्तियों की प्रोसेसिंग में उपयोग करने के लिए, पंक्ति 0 को सबसे अंत में प्रोसेस करना
    for (int i = m - 1; i >= 0; i--) {
        // j=1 से उल्टे क्रम में स्कैन करना, पंक्ति फ्लैग या स्तंभ फ्लैग सेट है तो शून्य करना
        for (int j = n - 1; j >= 1; j--)
            if (matrix[i][0] == 0 || matrix[0][j] == 0)
                matrix[i][j] = 0;
        // स्तंभ 0 को शून्य करना आंतरिक लूप के बाद करना
        // सावधानी: यदि पहले matrix[i][0] बदल दें, तो ऊपर के पंक्ति फ्लैग की जाँच गलत हो जाएगी
        if (firstCol)
            matrix[i][0] = 0;
    }
}
```
