# Finding the Median From a Data Stream — डेटा स्ट्रीम से वास्तविक समय में मध्यिका ज्ञात करना

## समस्या का सार

डेटा स्ट्रीम से पूर्णांक लगातार जोड़े जाने की स्थिति में, दो ऑपरेशन को सपोर्ट करने वाली डेटा संरचना डिज़ाइन करनी है। `addNum(int num)` एक पूर्णांक जोड़ता है, और `findMedian()` अब तक जोड़े गए सभी पूर्णांकों की **मध्यिका** लौटाता है। यदि तत्वों की संख्या विषम है तो बीच का मान, और सम है तो बीच के दो मानों का औसत लौटाता है।

## मूल विचार

सभी तत्वों को "छोटे वाले आधे हिस्से" और "बड़े वाले आधे हिस्से" में विभाजित करके, प्रत्येक को max-heap और min-heap से प्रबंधित करने पर, मध्यिका हमेशा दोनों heap के शीर्ष से O(1) में प्राप्त की जा सकती है।

## विचार प्रक्रिया

1. **मध्यिका "बीच" में होती है**: मध्यिका ज्ञात करने के लिए सभी तत्वों को सॉर्ट की हुई अवस्था में रखना और बीच के तत्व तक पहुँचना आवश्यक है। परंतु, हर बार तत्व जोड़ने पर सॉर्ट करने में O(n log n) लगता है
2. **सभी तत्वों का सॉर्ट क्रम अनावश्यक है, केवल बीच का पता होना चाहिए**: सभी तत्वों को "छोटे वाले आधे हिस्से (lower half)" और "बड़े वाले आधे हिस्से (upper half)" में दो भागों में विभाजित करने पर, lower half का अधिकतम मान और upper half का न्यूनतम मान मध्यिका के उम्मीदवार बनते हैं
3. **प्रत्येक आधे हिस्से का चरम मान तेज़ी से प्राप्त करना है**: lower half का अधिकतम मान O(1) में प्राप्त करने के लिए max-heap, और upper half का न्यूनतम मान O(1) में प्राप्त करने के लिए min-heap उपयुक्त है। heap में जोड़ने की लागत O(log n) है
4. **दोनों heap के आकार का संतुलन बनाए रखना है**: मध्यिका सही ढंग से ज्ञात करने के लिए, दोनों heap के आकार का अंतर अधिकतम 1 रखना आवश्यक है। lo (max-heap) का आकार hi (min-heap) के आकार के बराबर या अधिक रहे, ऐसा संतुलन बनाया जाता है
5. **तत्व जोड़ते समय संतुलन समायोजन की प्रक्रिया**: नए तत्व को पहले lo में जोड़ा जाता है, फिर lo का अधिकतम मान hi में स्थानांतरित किया जाता है। इससे lo का अधिकतम मान ≤ hi का न्यूनतम मान सदैव सुनिश्चित रहता है। उसके बाद, यदि hi का आकार lo से बड़ा हो जाए तो hi का न्यूनतम मान lo में वापस किया जाता है
6. **मध्यिका प्राप्त करना**: यदि lo का आकार hi से बड़ा है तो तत्वों की संख्या विषम है, अतः lo का शीर्ष (अधिकतम मान) मध्यिका है। यदि आकार बराबर है तो तत्वों की संख्या सम है, अतः lo के शीर्ष और hi के शीर्ष का औसत मध्यिका है

## पूर्वापेक्षित ज्ञान

### PriorityQueue (heap) क्या है

तत्वों को प्राथमिकता क्रम में प्रबंधित करने वाली डेटा संरचना। डिफ़ॉल्ट रूप से min-heap (न्यूनतम मान शीर्ष पर) के रूप में कार्य करती है। शीर्ष तत्व प्राप्त करना O(1) में, और तत्व जोड़ना व हटाना O(log n) में होता है।

```java
// min-heap (डिफ़ॉल्ट): न्यूनतम मान शीर्ष पर आता है
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
minHeap.offer(5);       // तत्व 5 को जोड़ता है
minHeap.offer(3);       // तत्व 3 को जोड़ता है
minHeap.peek();          // शीर्ष का न्यूनतम मान प्राप्त करता है → 3 (हटाता नहीं)
minHeap.poll();          // शीर्ष का न्यूनतम मान निकालता है → 3 (हटाता है)

// max-heap: अधिकतम मान शीर्ष पर आता है (Collections.reverseOrder() निर्दिष्ट करता है)
PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Collections.reverseOrder());
maxHeap.offer(5);       // तत्व 5 को जोड़ता है
maxHeap.offer(3);       // तत्व 3 को जोड़ता है
maxHeap.peek();          // शीर्ष का अधिकतम मान प्राप्त करता है → 5
```

### offer / poll / peek में अंतर

| विधि | क्रिया | लौटाया गया मान |
|---|---|---|
| `offer(e)` | तत्व `e` को heap में जोड़ता है | `boolean` (सफल होने पर true) |
| `poll()` | शीर्ष तत्व को निकालकर **हटाता है** | निकाला गया तत्व (खाली होने पर `null`) |
| `peek()` | शीर्ष तत्व को **बिना हटाए** देखता है | शीर्ष का तत्व (खाली होने पर `null`) |

### मध्यिका (median) क्या है

सॉर्ट की गई सूची के बीच का मान। यदि तत्वों की संख्या विषम है तो बीच का एक मान, सम है तो बीच के दो मानों का औसत।
उदाहरण: `[1, 2, 3]` → मध्यिका `2` है। `[1, 2, 3, 4]` → मध्यिका `(2 + 3) / 2.0 = 2.5` है।

## गणना जटिलता

| | मान |
|---|---|
| Time | O(log n) — `addNum` में heap में जोड़ने और निकालने की क्रिया अधिकतम 3 बार होती है, और प्रत्येक क्रिया O(log n) है। `findMedian` O(1) है |
| Space | O(n) — दोनों heap में सभी तत्व संग्रहीत होते हैं |

## कोड

```java
// इनपुट: addNum(int num) द्वारा पूर्णांक एक-एक करके स्ट्रीम के रूप में दिए जाते हैं
// आउटपुट: findMedian() अब तक जोड़े गए सभी पूर्णांकों की मध्यिका double के रूप में लौटाता है
class MedianFinder {
    // छोटे वाले आधे हिस्से को प्रबंधित करने वाला max-heap (शीर्ष अधिकतम मान है)
    PriorityQueue<Integer> lo;
    // बड़े वाले आधे हिस्से को प्रबंधित करने वाला min-heap (शीर्ष न्यूनतम मान है)
    PriorityQueue<Integer> hi;

    MedianFinder() {
        // max-heap को Collections.reverseOrder() से अवरोही क्रम में करता है
        lo = new PriorityQueue<>(Collections.reverseOrder());
        // min-heap डिफ़ॉल्ट के रूप में रहता है (आरोही क्रम)
        hi = new PriorityQueue<>();
    }

    void addNum(int num) {
        // प्रत्येक तत्व को पहले छोटे वाले आधे हिस्से (lo) में डालता है
        lo.offer(num);
        // lo का अधिकतम मान hi में स्थानांतरित करके, lo के सभी तत्व ≤ hi के सभी तत्व यह क्रम सदैव बनाए रखता है
        hi.offer(lo.poll());

        // यदि hi का आकार lo से बड़ा हो जाए, तो hi का न्यूनतम मान lo में वापस करके संतुलन बनाता है
        // इस क्रिया से lo का आकार सदैव hi के आकार के बराबर या अधिक रहता है (अंतर अधिकतम 1)
        if (hi.size() > lo.size())
            lo.offer(hi.poll());
    }

    double findMedian() {
        // lo का आकार बड़ा है = कुल तत्वों की संख्या विषम है → lo का शीर्ष (छोटे आधे का अधिकतम मान) मध्यिका है
        if (lo.size() > hi.size())
            return lo.peek();

        // आकार बराबर है = कुल तत्वों की संख्या सम है → बीच के दो मानों का औसत लौटाता है
        // 2.0 से भाग देकर पूर्णांक भाग के बजाय दशमलव भाग करता है
        return (lo.peek() + hi.peek()) / 2.0;
    }
}
```
