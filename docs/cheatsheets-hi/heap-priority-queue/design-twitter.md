# Designing a Simplified Twitter Feed — कई उपयोगकर्ताओं के ट्वीट्स में से नवीनतम 10 को कुशलतापूर्वक प्राप्त करने वाली प्रणाली डिज़ाइन करना

## समस्या का सार

एक सरलीकृत Twitter सिस्टम के रूप में 4 ऑपरेशन लागू करना है। `postTweet` से ट्वीट पोस्ट करना, `getNewsFeed` से उस उपयोगकर्ता और उसके फॉलो किए गए उपयोगकर्ताओं के ट्वीट्स में से **नवीनतम 10** प्राप्त करना, `follow` से फॉलो करना, और `unfollow` से अनफॉलो करना है। मुख्य चुनौती यह है कि कई उपयोगकर्ताओं की ट्वीट सूचियों को **समय क्रम में मर्ज करके केवल शीर्ष 10 को कुशलतापूर्वक निकालना** है।

## मूल विचार

प्रत्येक उपयोगकर्ता की ट्वीट सूची पहले से पोस्ट क्रम (समय क्रम) में सॉर्ट होती है। कई सॉर्ट की गई सूचियों में से शीर्ष K आइटम निकालने की समस्या को सभी सूचियों को दोबारा सॉर्ट करने के बजाय, **Heap का उपयोग करके K-way मर्ज** द्वारा प्रत्येक सूची के शीर्ष की तुलना करते हुए एक-एक करके निकालकर, न्यूनतम तुलनाओं में हल किया जा सकता है।

## विचार प्रक्रिया

1. **डेटा संग्रहण विधि तय करना**: प्रत्येक उपयोगकर्ता द्वारा पोस्ट किए गए ट्वीट्स को समय क्रम में प्रबंधित करना आवश्यक है। उपयोगकर्ता ID को key और ट्वीट सूची को value रखने वाले HashMap का उपयोग करने से किसी भी उपयोगकर्ता की ट्वीट सूची O(1) में प्राप्त की जा सकती है। प्रत्येक ट्वीट को एक global timestamp देकर पोस्ट क्रम रिकॉर्ड करना है
2. **फॉलो संबंध प्रबंधन विधि तय करना**: फॉलो और अनफॉलो, उपयोगकर्ता ID के सेट में जोड़ने और हटाने के अनुरूप है। उपयोगकर्ता ID को key और फॉलो किए गए ID का Set को value रखने वाले HashMap का उपयोग करने से फॉलो जोड़ना, हटाना, और सूची प्राप्त करना सभी O(1) में किया जा सकता है
3. **न्यूज़ फीड प्राप्ति का सार समझना**: `getNewsFeed` स्वयं और फॉलो किए गए सभी उपयोगकर्ताओं के ट्वीट्स में से नवीनतम 10 लौटाने का ऑपरेशन है। चूँकि प्रत्येक उपयोगकर्ता की ट्वीट सूची पोस्ट क्रम में सॉर्ट होती है, यह **कई सॉर्ट की गई सूचियों से शीर्ष K आइटम निकालने की समस्या (K-way मर्ज)** में परिवर्तित होती है
4. **K-way मर्ज के लिए Heap का उपयोग करना**: प्रत्येक उपयोगकर्ता की ट्वीट सूची के अंत (नवीनतम ट्वीट) को Max-Heap में डालना है। Heap से सबसे बड़े timestamp वाला तत्व निकालना है और उस उपयोगकर्ता का अगला नवीन ट्वीट Heap में जोड़ना है। इसे 10 बार दोहराने से नवीनतम 10 प्राप्त होते हैं
5. **Heap के प्रत्येक तत्व में रखी जाने वाली जानकारी तय करना**: Heap से निकालने के बाद उसी उपयोगकर्ता का अगला ट्वीट जोड़ने के लिए, प्रत्येक entry में "timestamp", "tweet ID", "user ID", और "सूची में index" — ये 4 जानकारी रखनी है। Index को 1 घटाने से उस उपयोगकर्ता के अगले नवीन ट्वीट तक पहुँचा जा सकता है
6. **10 आइटम प्राप्त होने पर शीघ्र समाप्ति**: Heap खाली होने पर या परिणाम सूची में 10 आइटम पहुँचने पर लूप समाप्त करना है। सभी ट्वीट्स को संसाधित करने की आवश्यकता नहीं है

## पूर्वापेक्षित ज्ञान

### PriorityQueue (प्राथमिकता कतार / Heap) क्या है

यह एक ऐसी डेटा संरचना है जो तत्व जोड़ने पर स्वचालित रूप से प्राथमिकता क्रम में व्यवस्थित करती है। सबसे उच्च प्राथमिकता वाले तत्व को O(log N) में निकाला जा सकता है। Java का PriorityQueue डिफ़ॉल्ट रूप से Min-Heap (न्यूनतम मान शीर्ष पर) होता है, लेकिन Comparator निर्दिष्ट करके Max-Heap (अधिकतम मान शीर्ष पर) में बदला जा सकता है।

```java
// Max-Heap (बड़ा timestamp = नया आइटम शीर्ष पर) बनाना
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[0] - a[0]);
pq.offer(new int[]{5, 101});   // [timestamp, tweet ID] जोड़ना
pq.offer(new int[]{3, 102});   // जोड़ने के बाद, आंतरिक रूप से timestamp अवरोही क्रम में व्यवस्थित होता है
int[] top = pq.poll();         // सबसे बड़े timestamp वाला तत्व निकालना → [5, 101]
pq.isEmpty();                  // Heap खाली है या नहीं boolean में लौटाना → false
```

### computeIfAbsent क्या है

यह एक ऐसा मेथड है जो HashMap में key मौजूद न होने पर ही निर्दिष्ट फ़ंक्शन से value बनाकर रजिस्टर करता है और वह value लौटाता है। key मौजूद होने पर मौजूदा value को वैसे ही लौटाता है। `get` करके `null` जाँच करके `put` करने के 3 चरणों को 1 पंक्ति में समेटा जा सकता है।

```java
Map<Integer, List<int[]>> tweets = new HashMap<>();
// key 1 मौजूद नहीं है तो नई ArrayList बनाकर रजिस्टर करना और वह सूची लौटाना
tweets.computeIfAbsent(1, k -> new ArrayList<>()).add(new int[]{0, 101});
// key 1 पहले से मौजूद है, इसलिए मौजूदा सूची लौटाना और उसमें जोड़ना
tweets.computeIfAbsent(1, k -> new ArrayList<>()).add(new int[]{1, 102});
```

### K-way मर्ज क्या है

K सॉर्ट की गई सूचियों को एक सॉर्ट किए गए अनुक्रम में एकीकृत करने की विधि है। प्रत्येक सूची के शीर्ष तत्व को Heap में डालना है, और न्यूनतम (या अधिकतम) निकालने पर, निकाले गए तत्व की सूची का अगला तत्व Heap में जोड़ना है। सभी तत्वों को एक साथ सॉर्ट करने वाले O(N log N) से अधिक कुशलता से, O(N log K) में एकीकरण किया जा सकता है।

## गणनात्मक जटिलता

| | मान |
|---|---|
| Time | O(K log K) — K फॉलो किए गए उपयोगकर्ताओं की संख्या है। Heap में प्रारंभिक insertion में O(K log K) और अधिकतम 10 बार poll/offer में O(10 log K) लगता है |
| Space | O(K) — Heap में एक समय में अधिकतम K तत्व संग्रहित होते हैं |

## कोड

```java
// इनपुट: postTweet(userId, tweetId), follow(followerId, followeeId), unfollow(followerId, followeeId), getNewsFeed(userId) के प्रत्येक ऑपरेशन कॉल
// आउटपुट: getNewsFeed उपयोगकर्ता और उसके फॉलो किए गए उपयोगकर्ताओं के ट्वीट्स से नवीनतम 10 tweet ID को List<Integer> में लौटाता है
class Twitter {
    // Global timestamp। सभी उपयोगकर्ताओं के ट्वीट्स के बीच पोस्ट क्रम को विशिष्ट रूप से पहचानता है
    // एकदिशीय बढ़ता है, इसलिए विभिन्न उपयोगकर्ताओं के ट्वीट्स के बीच भी सही समय क्रम तुलना की जा सकती है
    int time = 0;
    // key=उपयोगकर्ता ID, value=उस उपयोगकर्ता की ट्वीट सूची (प्रत्येक तत्व [timestamp, tweet ID] है)
    // सूची में पोस्ट क्रम में अंत में जोड़ा जाता है, इसलिए अंतिम तत्व नवीनतम होता है
    Map<Integer, List<int[]>> tweets;
    // key=फॉलो करने वाले का उपयोगकर्ता ID, value=फॉलो किए गए उपयोगकर्ता ID का Set
    // Set का उपयोग करने से फॉलो जोड़ना, हटाना, और डुप्लिकेट निवारण सभी O(1) में होता है
    Map<Integer, Set<Integer>> follows;

    Twitter() {
        tweets = new HashMap<>();
        follows = new HashMap<>();
    }

    void postTweet(int userId, int tweetId) {
        // उपयोगकर्ता की ट्वीट सूची प्राप्त करना (नहीं है तो बनाना) और अंत में [timestamp, tweet ID] जोड़ना
        // time++ से global timestamp देकर पोस्ट क्रम रिकॉर्ड करना
        tweets.computeIfAbsent(userId, k -> new ArrayList<>())
            .add(new int[]{time++, tweetId});
    }

    void follow(int followerId, int followeeId) {
        // फॉलो Set में followeeId जोड़ना (Set होने से एक ही उपयोगकर्ता को दोबारा फॉलो करने पर डुप्लिकेट नहीं होता)
        follows.computeIfAbsent(followerId, k -> new HashSet<>())
            .add(followeeId);
    }

    void unfollow(int followerId, int followeeId) {
        // फॉलो संबंध मौजूद होने पर ही followeeId को Set से हटाना
        // मौजूद न होने वाले key पर get करने से NullPointerException आता है इसलिए पहले containsKey से जाँच करना
        if (follows.containsKey(followerId))
            follows.get(followerId).remove(followeeId);
    }

    List<Integer> getNewsFeed(int userId) {
        // Max-Heap: बड़ा (नया) timestamp शीर्ष पर आए इसके लिए Comparator निर्दिष्ट करना
        PriorityQueue<int[]> pq =
            new PriorityQueue<>((a, b) -> b[0] - a[0]);

        // फीड लक्ष्य उपयोगकर्ता = स्वयं + फॉलो किए गए सभी उपयोगकर्ता
        // स्वयं के ट्वीट्स भी फीड में शामिल करने हैं इसलिए स्वयं को जोड़ना न भूलना
        Set<Integer> users = new HashSet<>();
        users.add(userId);
        if (follows.containsKey(userId))
            users.addAll(follows.get(userId));

        // प्रत्येक उपयोगकर्ता का नवीनतम ट्वीट (सूची का अंतिम तत्व) Heap में जोड़ना (K-way मर्ज का आरंभीकरण)
        for (int uid : users) {
            // जिस उपयोगकर्ता के ट्वीट्स नहीं हैं उसे छोड़ना
            if (!tweets.containsKey(uid)) continue;
            List<int[]> t = tweets.get(uid);
            int idx = t.size() - 1;
            int[] tw = t.get(idx);
            // [timestamp, tweet ID, उपयोगकर्ता ID, सूची में index]
            // उपयोगकर्ता ID और index शामिल करने का कारण: निकालने के बाद उस उपयोगकर्ता के अगले ट्वीट तक पहुँचने के लिए
            pq.offer(new int[]{tw[0], tw[1], uid, idx});
        }

        // Heap से अधिकतम 10 आइटम निकालना (K-way मर्ज का निष्पादन)
        List<Integer> res = new ArrayList<>();
        while (!pq.isEmpty() && res.size() < 10) {
            // सबसे बड़े timestamp वाला तत्व निकालना
            int[] top = pq.poll();
            // निकाले गए tweet ID को परिणाम में जोड़ना
            res.add(top[1]);
            int uid = top[2];
            // index को 1 घटाकर उस उपयोगकर्ता के अगले नवीन ट्वीट को इंगित करना
            int idx = top[3] - 1;
            // उस उपयोगकर्ता के पास अभी पुराने ट्वीट्स हैं तो Heap में जोड़ना (index ऋणात्मक है तो सभी संसाधित हो चुके)
            if (idx >= 0) {
                int[] tw = tweets.get(uid).get(idx);
                pq.offer(new int[]{tw[0], tw[1], uid, idx});
            }
        }
        // नवीनतम 10 (या कुल ट्वीट्स 10 से कम होने पर सभी) tweet ID timestamp अवरोही क्रम में संग्रहित हैं
        return res;
    }
}
```
