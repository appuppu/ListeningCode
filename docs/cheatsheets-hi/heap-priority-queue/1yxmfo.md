# Finding the K Closest Points to the Origin — मूल बिंदु के सबसे निकट K बिंदुओं को खोजना

## समस्या का सार

द्विविमीय समतल पर बिंदुओं की एक सरणी `points` और एक पूर्णांक `k` दिया गया है। मूल बिंदु (0, 0) से यूक्लिडियन दूरी के अनुसार सबसे निकट `k` बिंदुओं को लौटाना है। दूरी को यूक्लिडियन दूरी से मापा जाता है। उत्तर किसी भी क्रम में लौटाया जा सकता है।

## मूल विचार

"k निकटतम बिंदु" खोजने के लिए पूर्ण सॉर्टिंग आवश्यक नहीं है। Quickselect एल्गोरिदम का उपयोग करके, सरणी को पिवट से विभाजित करके केवल k-वें स्थान की सीमा खोजने से, बाईं ओर k निकटतम बिंदु एकत्रित हो जाते हैं।

## विचार प्रक्रिया

1. **पूर्ण सॉर्टिंग अत्यधिक है**: केवल k निकटतम बिंदुओं को लौटाना है, और क्रम मायने नहीं रखता। अर्थात, "सबसे निकट k बिंदु" और "शेष बिंदु" में विभाजित कर सकें तो पर्याप्त है। पूर्ण सॉर्ट O(n log n) लगता है, लेकिन केवल विभाजन करना तेज़ हो सकता है
2. **Quickselect से विभाजन स्थान खोजना**: Quicksort की पार्टीशन संक्रिया का उपयोग करने से, पिवट से छोटे तत्व बाईं ओर और बड़े तत्व दाईं ओर एकत्रित होते हैं। यदि पिवट की अंतिम स्थिति ठीक k-1 हो, तो बाईं ओर के k तत्व उत्तर हैं
3. **दूरी की गणना को सरल बनाना**: यूक्लिडियन दूरी `√(x² + y²)` है, लेकिन केवल तुलना करनी हो तो वर्गमूल अनावश्यक है, `x² + y²` की तुलना पर्याप्त है। इससे फ़्लोटिंग-पॉइंट संक्रियाओं से बचा जा सकता है
4. **पार्टीशन संक्रिया की कार्यप्रणाली**: दाएँ छोर के तत्व को पिवट के रूप में चुनकर, `storeIdx` से "पिवट से कम या बराबर तत्वों को रखने की अगली स्थिति" का प्रबंधन किया जाता है। स्कैन के दौरान पिवट से कम या बराबर तत्व मिलने पर उसे `storeIdx` की स्थिति से अदला-बदली कर `storeIdx` को आगे बढ़ाया जाता है
5. **पिवट की अंतिम स्थिति से खोज सीमा को संकुचित करना**: पार्टीशन के बाद, पिवट `storeIdx` की स्थिति पर होता है। यदि यह स्थिति `k-1` से छोटी है तो बाईं ओर के तत्व पर्याप्त नहीं हैं इसलिए दाएँ आधे भाग में खोजा जाता है, और `k-1` से बड़ी या बराबर हो तो बाएँ आधे भाग में खोजा जाता है। इस पुनरावृत्ति से औसतन O(n) में विभाजन पूर्ण होता है
6. **अंत में पहले k तत्वों को लौटाना**: लूप समाप्त होने पर सरणी के पहले k तत्व निकटतम बिंदु बन जाते हैं, इसलिए `Arrays.copyOfRange(points, 0, k)` से निकालकर लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### Quickselect क्या है

सरणी में से k-वें सबसे छोटे तत्व को औसतन O(n) में खोजने वाला एल्गोरिदम है। Quicksort की पार्टीशन संक्रिया को केवल एक ओर पुनरावर्ती रूप से लागू करके, पूर्ण सॉर्ट किए बिना लक्षित स्थिति को निश्चित किया जाता है।

```java
// पार्टीशन की मूल संरचना
int pivotValue = arr[right];       // दाएँ छोर को पिवट के रूप में चुनना
int storeIdx = left;               // पिवट से कम या बराबर तत्वों को रखने की स्थिति
for (int i = left; i < right; i++) {
    if (arr[i] <= pivotValue) {    // पिवट से कम या बराबर हो तो बाईं ओर एकत्रित करना
        swap(arr, i, storeIdx);
        storeIdx++;
    }
}
swap(arr, storeIdx, right);        // पिवट को सही स्थिति पर रखना
// storeIdx पिवट की अंतिम स्थिति है
```

### यूक्लिडियन दूरी का वर्ग

मूल बिंदु से दूरी `√(x² + y²)` है, लेकिन केवल तुलना करनी हो तो वर्गमूल को छोड़कर `x² + y²` से तुलना की जा सकती है। वर्गमूल फ़ंक्शन एकदिष्ट वर्धमान है, इसलिए दूरी का बड़ा-छोटा संबंध दूरी के वर्ग में भी संरक्षित रहता है।

```java
private int dist(int[] point) {
    return point[0] * point[0] + point[1] * point[1];  // x² + y²
}
```

### Arrays.copyOfRange क्या है

सरणी की निर्दिष्ट सीमा को कॉपी करके नई सरणी के रूप में लौटाने वाला Java का उपयोगिता मेथड है।

```java
int[][] result = Arrays.copyOfRange(points, 0, k);  // इंडेक्स 0 से k-1 तक के k तत्वों को कॉपी करना
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) औसत — पार्टीशन को केवल एक ओर लागू करने के कारण, औसतन n + n/2 + n/4 + ... = 2n तुलनाओं में अभिसरण होता है |
| Space | O(1) — इनपुट सरणी को इन-प्लेस पुनर्व्यवस्थित करने के कारण, अतिरिक्त मेमोरी का उपयोग नहीं होता है |

## कोड

```java
// इनपुट: द्विविमीय निर्देशांकों की सरणी points (प्रत्येक तत्व [x, y] है) और पूर्णांक k
// आउटपुट: मूल बिंदु के सबसे निकट k बिंदुओं को संग्रहित करके int[][] लौटाना है

// बिंदु की मूल बिंदु से यूक्लिडियन दूरी का वर्ग लौटाता है (तुलना के लिए वर्गमूल अनावश्यक होने के कारण छोड़ा गया है)
private int dist(int[] p) {
    return p[0] * p[0] + p[1] * p[1];
}

public int[][] kClosest(int[][] points, int k) {
    // खोज सीमा के बाएँ और दाएँ छोर को प्रारंभ करना। इस सीमा में पार्टीशन दोहराकर पहले k तत्वों को निकटतम बिंदुओं के रूप में पुनर्व्यवस्थित करना है
    int left = 0;
    int right = points.length - 1;

    // पहले k तत्व निकटतम बिंदु बनने तक पार्टीशन दोहराना
    while (left < right) {
        // दाएँ छोर के बिंदु को पिवट के रूप में चुनकर उसकी यूक्लिडियन दूरी का वर्ग गणना करना (x² + y²)
        int pivotDist = dist(points[right]);
        // storeIdx "पिवट से कम या बराबर दूरी वाले बिंदुओं को रखने की अगली स्थिति" का प्रबंधन करता है
        int storeIdx = left;

        // प्रत्येक बिंदु की दूरी को पिवट से तुलना करके, पिवट से कम या बराबर दूरी वाले बिंदुओं को बाईं ओर एकत्रित करना
        for (int i = left; i < right; i++) {
            if (dist(points[i]) <= pivotDist) {
                // पिवट से कम या बराबर है इसलिए storeIdx की स्थिति पर अदला-बदली करके बाईं ओर एकत्रित करना
                int[] temp = points[i];
                points[i] = points[storeIdx];
                points[storeIdx] = temp;
                storeIdx++;
            }
        }

        // पिवट को उसकी सही अंतिम स्थिति storeIdx पर रखना। बाईं ओर पिवट से कम या बराबर, और दाईं ओर पिवट से अधिक दूरी वाले बिंदु होते हैं
        int[] temp = points[storeIdx];
        points[storeIdx] = points[right];
        points[right] = temp;

        // पिवट की अंतिम स्थिति को k-1 से तुलना करके खोज सीमा को आधा संकुचित करना
        if (storeIdx < k - 1) {
            // बाईं ओर के तत्व k से कम हैं, इसलिए दाईं ओर खोजना है
            left = storeIdx + 1;
        } else {
            // ध्यान दें: storeIdx ठीक k-1 होने पर भी right को घटाने से, लूप शर्त left < right असत्य हो जाती है और लूप समाप्त होता है
            right = storeIdx - 1;
        }
    }

    // लूप समाप्त होने के बाद, सरणी के पहले k तत्व मूल बिंदु के सबसे निकट k बिंदु होते हैं
    return Arrays.copyOfRange(points, 0, k);
}
```
