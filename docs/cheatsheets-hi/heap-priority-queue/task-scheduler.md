# Scheduling Tasks With Cooldown Intervals — कूलडाउन अंतराल के साथ कार्यों का न्यूनतम निष्पादन समय ज्ञात करना

## समस्या का सार

कार्यों की एक सरणी (अक्षरों द्वारा दर्शाई गई) और एक अऋणात्मक पूर्णांक `n` (कूलडाउन अंतराल) दिया गया है। एक ही कार्य को पुनः निष्पादित करने के लिए कम से कम `n` अंतराल का अंतर होना आवश्यक है। कूलडाउन के दौरान CPU निष्क्रिय अवस्था में रहता है। सभी कार्यों को पूरा करने के लिए आवश्यक **न्यूनतम समय इकाइयों की संख्या** लौटानी है।

## मूल विचार

सबसे अधिक आवृत्ति वाला कार्य संपूर्ण शेड्यूल की संरचना निर्धारित करता है। सबसे अधिक बारंबार कार्य के बीच उत्पन्न कूलडाउन रिक्तियों को अन्य कार्यों से भरा जा सकता है या नहीं, इसी से कुल समय "सूत्र द्वारा गणना परिणाम" या "कार्यों की कुल संख्या" में से बड़े वाले से निर्धारित होता है।

## विचार प्रक्रिया

1. **सबसे अधिक बारंबार कार्य अड़चन बनता है**: कूलडाउन प्रतिबंध सबसे कठोर उस कार्य पर होता है जिसकी उपस्थिति संख्या सबसे अधिक है। यह कार्य संपूर्ण शेड्यूल की लंबाई को नियंत्रित करता है
2. **सबसे अधिक बारंबार कार्य को सजाने पर रिक्तियाँ उत्पन्न होती हैं**: सबसे अधिक बारंबार कार्य की उपस्थिति संख्या को `maxFreq` मानें, तो इस कार्य को `n` अंतराल रखकर सजाने पर, कार्यों के बीच `(maxFreq - 1)` ब्लॉक उत्पन्न होते हैं। प्रत्येक ब्लॉक की लंबाई `(n + 1)` होती है (1 कार्य + कूलडाउन के `n` स्लॉट)
3. **रिक्तियों को अन्य कार्यों से भरना**: प्रत्येक ब्लॉक के भीतर कूलडाउन स्लॉट में अन्य कार्यों को रखकर निष्क्रिय समय को कम करते हैं। यदि सभी रिक्तियाँ भर जाएँ तो कोई निष्क्रिय समय उत्पन्न नहीं होता
4. **अंतिम ब्लॉक को विशेष रूप से संभालना**: अंतिम निष्पादन के बाद कूलडाउन की आवश्यकता नहीं होती, इसलिए अंतिम ब्लॉक में केवल सबसे अधिक बारंबार कार्य (और समान आवृत्ति वाले कार्य) ही आते हैं। सबसे अधिक आवृत्ति के बराबर संख्या रखने वाले कार्यों की गिनती को `maxCount` मानें, तो अंतिम ब्लॉक की लंबाई `maxCount` होती है
5. **सूत्र से कुल लंबाई की गणना करना**: `(maxFreq - 1) * (n + 1) + maxCount` से, सबसे अधिक बारंबार कार्य को अक्ष मानकर शेड्यूल की लंबाई प्राप्त होती है
6. **कार्यों की कुल संख्या से तुलना आवश्यक है**: यदि सभी रिक्तियाँ भर जाएँ और फिर भी कार्य शेष रहें, तो कोई निष्क्रिय समय नहीं लगता और कार्यों की कुल संख्या ही सीधे उत्तर बन जाती है। इसलिए अंतिम उत्तर `Math.max(formulaResult, tasks.length)` होता है

## पूर्वापेक्षित ज्ञान

### आवृत्ति सरणी क्या है

निश्चित आकार की सरणी का उपयोग करके प्रत्येक अक्षर की उपस्थिति संख्या गिनने की तकनीक। केवल अंग्रेज़ी बड़े अक्षरों के मामले में, आकार 26 की सरणी सभी अक्षरों को कवर कर सकती है। यह HashMap से तेज़ और कम मेमोरी वाली होती है।

```java
int[] freq = new int[26];            // A〜Z के लिए 26 काउंटरों को 0 से आरंभ करना
freq['B' - 'A']++;                   // 'B' की उपस्थिति संख्या को 1 बढ़ाना (इंडेक्स 1)
freq['B' - 'A'];                     // 'B' की उपस्थिति संख्या प्राप्त करना → 1
```

### Math.max क्या है

दो मानों में से बड़ा मान लौटाने वाली विधि। दो उम्मीदवारों में से उत्तर चुनने के लिए इसका उपयोग किया जाता है।

```java
Math.max(10, 7);    // → 10 (बड़ा मान लौटाता है)
Math.max(5, 12);    // → 12
```

### इस समस्या में ब्लॉक संरचना क्या है

सबसे अधिक बारंबार कार्य को `A` (उपस्थिति संख्या 3), `n = 2` मानें, तो शेड्यूल निम्नलिखित ब्लॉक संरचना में बनता है：

```
[A _ _] [A _ _] [A]
 ब्लॉक1  ब्लॉक2  अंतिम
```

`_` कूलडाउन स्लॉट है, जिसमें अन्य कार्य या निष्क्रिय समय आता है। अंतिम ब्लॉक में कूलडाउन की आवश्यकता नहीं होती, इसलिए केवल `A` ही आता है।

## जटिलता

| | मान |
|---|---|
| Time | O(k) — कार्य सरणी को एक बार स्कैन करता है और निश्चित लंबाई 26 की सरणी को स्थिर बार स्कैन करता है (k कार्यों की संख्या है) |
| Space | O(1) — केवल आकार 26 की निश्चित लंबाई सरणी का उपयोग करता है |

## कोड

```java
// इनपुट: अक्षर सरणी tasks (प्रत्येक अक्षर एक कार्य को दर्शाता है) और अऋणात्मक पूर्णांक n (कूलडाउन अंतराल)
// आउटपुट: सभी कार्यों को पूरा करने के लिए आवश्यक न्यूनतम समय इकाइयों की संख्या int के रूप में लौटाना
public int leastInterval(char[] tasks, int n) {
    // प्रत्येक कार्य (A〜Z) की उपस्थिति संख्या गिनने के लिए आवृत्ति सरणी। freq[0] 'A' से और freq[1] 'B' से संबंधित है
    int[] freq = new int[26];
    // tasks सरणी को स्कैन करना, t - 'A' से अक्षर को 0〜25 के इंडेक्स में बदलकर गिनती करना
    for (char t : tasks)
        freq[t - 'A']++;

    // अधिकतम उपस्थिति संख्या ज्ञात करना। यह मान शेड्यूल में ब्लॉकों की संख्या निर्धारित करता है
    int maxFreq = 0;
    for (int f : freq)
        maxFreq = Math.max(maxFreq, f);

    // अधिकतम उपस्थिति संख्या के बराबर संख्या रखने वाले कार्यों की गिनती करना। यह मान अंतिम ब्लॉक में आने वाले कार्यों की संख्या बनता है
    int maxCount = 0;
    for (int f : freq)
        if (f == maxFreq) maxCount++;

    // ब्लॉक संरचना पर आधारित सूत्र से गणना करना
    // (maxFreq - 1): कूलडाउन आवश्यक ब्लॉकों की संख्या
    // (n + 1): प्रत्येक ब्लॉक की लंबाई (1 कार्य + कूलडाउन के n स्लॉट)
    // maxCount: अंतिम ब्लॉक की लंबाई (केवल सबसे अधिक बारंबार और समान आवृत्ति वाले कार्य आते हैं)
    int formulaResult =
        (maxFreq - 1) * (n + 1)
        + maxCount;

    // formulaResult: कूलडाउन के कारण निष्क्रिय समय उत्पन्न होने की स्थिति में लंबाई
    // tasks.length: कोई निष्क्रिय समय न लगने की स्थिति में लंबाई (सभी रिक्तियाँ भरकर कार्य शेष रहने पर)
    // दोनों में से बड़ा मान सही उत्तर होता है
    return Math.max(formulaResult,
        tasks.length);
}
```
