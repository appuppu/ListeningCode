# Finding the Kth Largest Element in an Array — अनसॉर्टेड ऐरे से K-वां सबसे बड़ा तत्व खोजना

## समस्या का सार

पूर्णांकों की एक ऐरे `nums` और एक पूर्णांक `k` दिया गया है। ऐरे को सॉर्ट करने पर बड़े से छोटे की ओर गिनते हुए `k`-वें स्थान पर आने वाले तत्व का मान लौटाना है। डुप्लिकेट मानों को भी स्वतंत्र रूप से गिना जाता है (k-वां सबसे बड़ा "भिन्न मान" नहीं)।

## मूल विचार

पूरी ऐरे को सॉर्ट किए बिना, पिवट के आधार पर ऐरे को विभाजित करने से "पिवट कितने नंबर पर सबसे बड़ा है" तुरंत पता चल जाता है। पिवट की स्थिति `k-1` होने तक खोज सीमा को एक तरफ सीमित करते रहने से, औसतन O(n) में लक्ष्य तत्व तक पहुँचा जा सकता है।

## विचार प्रक्रिया

1. **K-वां सबसे बड़ा तत्व सॉर्ट के बाद इंडेक्स से निर्धारित होता है**: ऐरे को अवरोही क्रम में सॉर्ट करने पर, इंडेक्स `k-1` का तत्व उत्तर होता है। लेकिन पूर्ण सॉर्ट में O(n log n) लगता है, इसलिए अधिक कुशल विधि पर विचार करते हैं
2. **केवल K-वें स्थान की आवश्यकता है**: पूरे क्रम की जरूरत नहीं है, बस "K-वां सबसे बड़ा तत्व कौन सा है" यह जानना काफी है। पिवट का उपयोग करके ऐरे को "पिवट से बड़े समूह" और "पिवट के बराबर या छोटे समूह" में विभाजित करने पर, पिवट कितने नंबर पर सबसे बड़ा है यह उसकी स्थिति (इंडेक्स) से पता चलता है
3. **पिवट की स्थिति से खोज सीमा को सीमित करना**: partition के परिणामस्वरूप, पिवट इंडेक्स `p` पर रखा गया है। यदि `p == k-1` तो उत्तर मिल गया। यदि `p < k-1` तो लक्ष्य तत्व पिवट के दाईं ओर (छोटी तरफ) है, इसलिए खोज सीमा को `p+1` के बाद तक सीमित करते हैं। यदि `p > k-1` तो बाईं ओर सीमित करते हैं
4. **अवरोही क्रम में partition करना**: सामान्य QuickSort का partition आरोही क्रम में होता है, लेकिन "K-वां सबसे बड़ा" खोजने के लिए अवरोही क्रम में partition करते हैं। अर्थात, पिवट से बड़े तत्वों को बाईं ओर इकट्ठा करते हैं। ऐसा करने से, इंडेक्स `k-1` उत्तर की स्थिति के अनुरूप होता है
5. **लूप से केवल एक तरफ की बार-बार प्रोसेसिंग करना**: QuickSort दोनों तरफ को पुनरावर्ती रूप से प्रोसेस करता है, लेकिन Quickselect में केवल उस तरफ को प्रोसेस करना होता है जिसमें उत्तर है। while लूप में `l <= r` के दौरान partition दोहराते रहते हैं, और `p == k-1` होने पर उस तत्व को लौटाते हैं

## पूर्वापेक्षित ज्ञान

### Quickselect क्या है

QuickSort के समान partition ऑपरेशन का उपयोग करके, ऐरे में से K-वां सबसे छोटा (या सबसे बड़ा) तत्व औसतन O(n) में खोजने वाला एल्गोरिदम है। QuickSort दोनों तरफ को पुनरावर्ती रूप से प्रोसेस करता है, जबकि Quickselect केवल एक तरफ को प्रोसेस करता है, इसलिए औसत जटिलता O(n) होती है।

### partition (विभाजन) क्या है

ऐरे में से एक पिवट चुनकर, पिवट से बड़े तत्वों को बाईं ओर और पिवट के बराबर या छोटे तत्वों को दाईं ओर स्थानांतरित करने का ऑपरेशन है। ऑपरेशन के बाद, पिवट अपनी अंतिम सही स्थिति पर रखा जाता है। यह स्थिति (इंडेक्स) पिवट की "रैंक" को दर्शाती है।

```java
// अवरोही partition: पिवट से बड़े तत्वों को बाईं ओर इकट्ठा करना
// रिटर्न वैल्यू: पिवट जिस इंडेक्स पर रखा गया है
int pivot = nums[r];       // दाएँ छोर के तत्व को पिवट के रूप में चुनना
int store = l;             // अगली स्वैप स्थिति को इंगित करने वाला पॉइंटर
// nums[i] > pivot तो, nums[i] को store स्थिति पर स्वैप करके store को आगे बढ़ाना
// अंत में pivot को store स्थिति पर रखना → store पिवट की अंतिम स्थिति है
```

### swap (तत्वों का आदान-प्रदान) क्या है

ऐरे में दो तत्वों की स्थिति को बदलने का ऑपरेशन है। अस्थायी चर `temp` का उपयोग करके मान को सुरक्षित रखा जाता है, जिससे ओवरराइट को रोका जा सके।

```java
int temp = nums[i];    // nums[i] के मान को अस्थायी चर में सुरक्षित रखना
nums[i] = nums[store]; // nums[store] के मान को nums[i] में ओवरराइट करना
nums[store] = temp;    // सुरक्षित रखे गए मूल nums[i] के मान को nums[store] में लिखना
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) औसत — हर बार खोज सीमा औसतन आधी हो जाती है, इसलिए n + n/2 + n/4 + ... ≈ 2n = O(n) |
| Space | O(1) — ऐरे को in-place ऑपरेट किया जाता है और कोई अतिरिक्त डेटा संरचना उपयोग नहीं होती |

## कोड

```java
// इनपुट: पूर्णांक ऐरे nums और पूर्णांक k
// आउटपुट: ऐरे में K-वां सबसे बड़ा तत्व का मान int के रूप में लौटाना

// अवरोही partition: पिवट से बड़े तत्वों को बाईं ओर इकट्ठा करके, पिवट की अंतिम स्थिति लौटाना
private int partition(int[] nums, int l, int r) {
    // खोज सीमा के दाएँ छोर के तत्व को पिवट के रूप में चुनना
    int pivot = nums[r];
    // store "अगले पिवट से बड़े तत्व को रखने की स्थिति" को इंगित करता है
    int store = l;

    // l से r-1 तक स्कैन करके, पिवट से बड़े तत्वों को बाईं ओर इकट्ठा करना
    for (int i = l; i < r; i++) {
        // यदि वर्तमान तत्व पिवट से बड़ा है, तो store स्थिति पर स्वैप करके बाईं ओर इकट्ठा करना
        if (nums[i] > pivot) {
            int temp = nums[i];
            nums[i] = nums[store];
            nums[store] = temp;
            // store को आगे बढ़ाकर, अगले बड़े तत्व की प्लेसमेंट स्थिति अपडेट करना
            store++;
        }
    }

    // पिवट को store स्थिति पर रखना (पिवट की अंतिम सही स्थिति)
    // इस बिंदु पर, store के बाईं ओर पिवट से बड़े तत्व हैं, और दाईं ओर पिवट के बराबर या छोटे तत्व हैं
    int temp = nums[store];
    nums[store] = nums[r];
    nums[r] = temp;
    // store पिवट की अंतिम स्थिति = पिवट की "अवरोही क्रम में रैंक" को दर्शाता है
    return store;
}

public int findKthLargest(int[] nums, int k) {
    // खोज सीमा को पूरी ऐरे से आरंभ करना
    int l = 0, r = nums.length - 1;

    // खोज सीमा वैध रहने तक partition दोहराना। हर लूप में खोज सीमा सिकुड़ती जाती है
    while (l <= r) {
        // वर्तमान खोज सीमा में partition निष्पादित करके, पिवट की स्थिति प्राप्त करना
        int p = partition(nums, l, r);

        if (p == k - 1) {
            // पिवट K-वें सबसे बड़े स्थान पर है इसलिए उत्तर लौटाना
            // अवरोही क्रम में बाईं ओर से गिनकर इंडेक्स k-1 K-वें सबसे बड़े तत्व की स्थिति है
            return nums[p];
        } else if (p < k - 1) {
            // K-वां तत्व पिवट के दाईं ओर (छोटी तरफ) है, इसलिए खोज सीमा की बाईं सीमा को सिकोड़ना
            l = p + 1;
        } else {
            // K-वां तत्व पिवट के बाईं ओर (बड़ी तरफ) है, इसलिए खोज सीमा की दाईं सीमा को सिकोड़ना
            r = p - 1;
        }
    }
    // समस्या की शर्तों के अनुसार, वैध k दिया जाता है इसलिए यहाँ नहीं पहुँचा जाता
    return -1;
}
```
