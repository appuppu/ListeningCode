# Tracking the Kth Largest Element in a Stream — स्ट्रीम से K-वाँ सबसे बड़ा तत्व हमेशा प्राप्त करना

## समस्या का सार

एक पूर्णांक `k` और एक प्रारंभिक संख्या सूची दी गई क्लास को डिज़ाइन करना है। जब भी `add` मेथड को कॉल किया जाता है, तो एक नई संख्या स्ट्रीम में जोड़ी जाती है और उस समय संपूर्ण स्ट्रीम में **K-वाँ सबसे बड़ा तत्व** लौटाया जाता है।

## मूल विचार

चूँकि केवल K-वाँ सबसे बड़ा तत्व आवश्यक है, इसलिए यदि केवल शीर्ष K तत्वों को Min-Heap में रखा जाए, तो हीप की जड़ (न्यूनतम मान) हमेशा K-वाँ सबसे बड़ा तत्व होगी।

## विचार प्रक्रिया

1. **केवल K-वाँ सबसे बड़ा तत्व आवश्यक है**: संपूर्ण स्ट्रीम को सॉर्ट करने की आवश्यकता नहीं है, केवल शीर्ष K तत्वों को जानने से K-वाँ सबसे बड़ा तत्व निर्धारित हो जाता है
2. **शीर्ष K तत्वों को कुशलतापूर्वक प्रबंधित करना है**: तत्व जोड़ना और न्यूनतम मान निकालना O(log n) में करने वाला Min-Heap (न्यूनतम हीप) उपयुक्त है। Min-Heap की जड़ हमेशा हीप के भीतर न्यूनतम मान रखती है, इसलिए आकार को K पर बनाए रखने से जड़ K-वाँ सबसे बड़ा तत्व बन जाती है
3. **हीप का आकार K तक सीमित करने की विधि**: नया तत्व जोड़ने के बाद, यदि हीप का आकार K से अधिक हो जाता है तो `poll()` से जड़ (न्यूनतम मान) को हटाया जाता है। इससे K-वें सबसे बड़े तत्व से छोटे मान स्वचालित रूप से हट जाते हैं और हमेशा केवल शीर्ष K तत्व बचे रहते हैं
4. **K-वाँ सबसे बड़ा तत्व प्राप्त करने की विधि**: जब हीप का आकार ठीक K होता है, तो जड़ का मान K-वाँ सबसे बड़ा तत्व होता है। `peek()` से O(1) में प्राप्त किया जा सकता है
5. **प्रारंभीकरण में भी add का पुनः उपयोग करना**: कंस्ट्रक्टर में प्रारंभिक सूची के प्रत्येक तत्व के लिए `add` को कॉल करने से, समान लॉजिक से हीप का निर्माण हो जाता है। प्रारंभीकरण और जोड़ने के लिए कोड साझा किया जा सकता है

## पूर्वापेक्षित ज्ञान

### Min-Heap (न्यूनतम हीप) क्या है

हीप एक पूर्ण बाइनरी ट्री संरचना वाला डेटा स्ट्रक्चर है। Min-Heap में, पैरेंट नोड का मान हमेशा चाइल्ड नोड के मान से कम या बराबर बनाए रखा जाता है। इसलिए, जड़ (रूट) पर हमेशा हीप के भीतर का न्यूनतम मान स्थित होता है। तत्व जोड़ना और न्यूनतम मान निकालना O(log n) में किया जा सकता है।

### PriorityQueue क्या है

Java में Min-Heap का कार्यान्वयन क्लास है। डिफ़ॉल्ट रूप से तत्वों को आरोही क्रम (छोटे से बड़े) में प्राथमिकता दी जाती है।

```java
PriorityQueue<Integer> heap = new PriorityQueue<>();  // खाली Min-Heap बनाता है
heap.offer(5);        // तत्व 5 को हीप में जोड़ता है
heap.offer(3);        // तत्व 3 को हीप में जोड़ता है
heap.offer(8);        // तत्व 8 को हीप में जोड़ता है
heap.peek();          // हीप की जड़ (न्यूनतम मान) को हटाए बिना लौटाता है → 3
heap.poll();          // हीप की जड़ (न्यूनतम मान) को हटाकर लौटाता है → 3
heap.size();          // हीप में तत्वों की संख्या लौटाता है → 2
```

### Min-Heap से K-वाँ सबसे बड़ा तत्व कैसे पता चलता है

आकार K के Min-Heap में शीर्ष K सबसे बड़े तत्व होते हैं। हीप की जड़ उनमें सबसे छोटा मान है, अर्थात "शीर्ष K में न्यूनतम मान" = "संपूर्ण में K-वाँ सबसे बड़ा तत्व" होता है।
उदाहरण: k=3, हीप की सामग्री [4, 5, 8] होने पर, जड़ 4 है। यह संपूर्ण में 3-वाँ सबसे बड़ा तत्व है।

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(log k) — प्रति add मेथड कॉल, आकार K के हीप में प्रविष्टि और विलोपन प्रत्येक O(log k) में होता है |
| Space | O(k) — हीप में हमेशा अधिकतम K तत्व ही रखे जाते हैं |

## कोड

```java
// इनपुट: पूर्णांक k, प्रारंभिक पूर्णांक सरणी nums, और add मेथड को दिया जाने वाला पूर्णांक val
// आउटपुट: add मेथड संपूर्ण स्ट्रीम में K-वाँ सबसे बड़ा तत्व int के रूप में लौटाता है
class KthLargest {
    // K को हीप के आकार सीमा के रूप में उपयोग करते रहने के लिए फ़ील्ड में रखा जाता है
    int k;
    // PriorityQueue डिफ़ॉल्ट रूप से Min-Heap (न्यूनतम मान जड़ पर) के रूप में कार्य करता है
    PriorityQueue<Integer> heap;

    // कंस्ट्रक्टर: k और प्रारंभिक सरणी प्राप्त करके हीप का निर्माण करता है
    KthLargest(int k, int[] nums) {
        this.k = k;
        heap = new PriorityQueue<>();
        // add मेथड के भीतर हीप का आकार सीमित होता है, इसलिए प्रारंभीकरण के लिए अलग लॉजिक अनावश्यक है
        for (int n : nums) {
            add(n);
        }
    }

    // नया मान जोड़ता है और K-वाँ सबसे बड़ा तत्व लौटाता है
    int add(int val) {
        // हीप के अंत में तत्व डालता है और हीप गुण बनाए रखने के लिए पैरेंट की दिशा में ले जाता है (O(log k))
        heap.offer(val);

        // यदि आकार K से अधिक हो जाता है, तो K-वें से छोटा एक अतिरिक्त तत्व मौजूद है
        if (heap.size() > k) {
            // Min-Heap की जड़ हमेशा न्यूनतम मान होती है, इसलिए हटाया जाने वाला K-वें से छोटा मान होता है
            heap.poll();
        }

        // जब हीप का आकार ठीक K होता है, तो जड़ हीप का न्यूनतम मान = संपूर्ण में K-वाँ सबसे बड़ा तत्व होता है
        return heap.peek();
    }
}
```
