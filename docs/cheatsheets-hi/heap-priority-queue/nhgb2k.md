# Simulating a Last Stone Weight Game — दो-दो पत्थर टकराकर अंत में बचे पत्थर का वज़न ज्ञात करना

## समस्या का सार

एक पूर्णांक सरणी `stones` दी गई है। हर बार **सबसे भारी 2 पत्थरों** को निकालकर टकराया जाता है। यदि दोनों पत्थरों का वज़न बराबर है तो दोनों नष्ट हो जाते हैं, और यदि भिन्न है तो हल्का पत्थर नष्ट हो जाता है और भारे पत्थर का वज़न अंतर के बराबर हो जाता है। यह प्रक्रिया तब तक दोहराई जाती है जब तक 1 या उससे कम पत्थर शेष रहें, और अंत में बचे पत्थर का वज़न लौटाया जाता है। यदि कोई पत्थर शेष नहीं बचता तो 0 लौटाया जाता है।

## मूल विचार

हर बार "सबसे भारी 2 पत्थरों" को कुशलतापूर्वक निकालने की आवश्यकता है। Max-Heap का उपयोग करने पर अधिकतम मान O(log n) में निकाला जा सकता है, इसलिए हर बार पुनः सॉर्ट करने की आवश्यकता नहीं होती और सदैव सबसे भारी 2 पत्थर प्राप्त किए जा सकते हैं।

## विचार प्रक्रिया

1. **हर बार की प्रक्रिया में 2 अधिकतम मान चाहिए**: पत्थर टकराने के नियम में सदैव सबसे भारी 2 पत्थर चुने जाते हैं। अर्थात् यह "वर्तमान समुच्चय से अधिकतम मान 2 बार निकालने" की प्रक्रिया को दोहराने की समस्या है
2. **अधिकतम मान का निष्कर्षण तेज़ी से करना है**: सरणी को हर बार सॉर्ट करने पर प्रत्येक राउंड में O(n log n) लगता है। Max-Heap का उपयोग करने पर अधिकतम मान का निष्कर्षण O(log n) में होता है, और तत्व का सम्मिलन भी O(log n) में होता है
3. **Java की PriorityQueue को Max-Heap के रूप में उपयोग करना**: Java की PriorityQueue डिफ़ॉल्ट रूप से Min-Heap (न्यूनतम मान शीर्ष पर) होती है। `Collections.reverseOrder()` को comparator के रूप में देने पर यह Max-Heap के रूप में कार्य करती है जहाँ अधिकतम मान शीर्ष पर आता है
4. **सभी पत्थरों को Heap में डालना**: सरणी `stones` के सभी तत्वों को PriorityQueue में जोड़ा जाता है। इससे Heap अधिकतम मान प्रबंधन के लिए तैयार हो जाता है
5. **जब तक 2 या अधिक पत्थर हैं, टकराने की प्रक्रिया दोहराना**: Heap से `poll()` द्वारा 2 बार अधिकतम मान निकाला जाता है, और यदि अंतर 0 नहीं है तो अंतर को `add()` से Heap में वापस डाला जाता है। यदि अंतर 0 है तो कुछ नहीं डाला जाता (दोनों नष्ट हो जाते हैं)
6. **अंतिम स्थिति की जाँच करके लौटाना**: लूप समाप्त होने के बाद, यदि Heap खाली है तो सभी पत्थर नष्ट हो गए हैं इसलिए 0 लौटाया जाता है। यदि Heap में 1 पत्थर शेष है तो उसका वज़न `poll()` से निकालकर लौटाया जाता है

## पूर्व-ज्ञान

### PriorityQueue (प्राथमिकता कतार) क्या है

यह एक ऐसी डेटा संरचना है जिसमें तत्व जोड़ने पर आंतरिक रूप से स्वचालित क्रम प्रबंधित होता है, और `poll()` सदैव सबसे उच्च प्राथमिकता वाला तत्व लौटाता है। आंतरिक कार्यान्वयन Heap (बाइनरी Heap) है, और सम्मिलन तथा निष्कर्षण दोनों O(log n) में कार्य करते हैं।

```java
// डिफ़ॉल्ट Min-Heap है (न्यूनतम मान शीर्ष पर)
PriorityQueue<Integer> minHeap = new PriorityQueue<>();
minHeap.add(5);       // तत्व 5 जोड़ता है
minHeap.add(2);       // तत्व 2 जोड़ता है
minHeap.poll();       // न्यूनतम मान 2 को निकालकर लौटाता है
minHeap.size();       // वर्तमान तत्वों की संख्या लौटाता है → 1
minHeap.isEmpty();    // कतार खाली है या नहीं boolean में लौटाता है → false
```

### Collections.reverseOrder() क्या है

यह PriorityQueue के constructor में दिया जाने वाला comparator है, जो डिफ़ॉल्ट आरोही क्रम (Min-Heap) को अवरोही क्रम (Max-Heap) में उलट देता है। इससे `poll()` अधिकतम मान लौटाने लगता है।

```java
// Max-Heap (अधिकतम मान शीर्ष पर) बनाता है
PriorityQueue<Integer> maxHeap =
    new PriorityQueue<>(Collections.reverseOrder());
maxHeap.add(3);       // तत्व 3 जोड़ता है
maxHeap.add(7);       // तत्व 7 जोड़ता है
maxHeap.add(1);       // तत्व 1 जोड़ता है
maxHeap.poll();       // अधिकतम मान 7 को निकालकर लौटाता है
maxHeap.poll();       // अगला अधिकतम मान 3 को निकालकर लौटाता है
```

### Max-Heap की कार्यप्रणाली का चित्रण

stones = [2, 7, 4, 1, 8, 1] के मामले में：
- Heap में सभी तत्व जोड़ने पर आंतरिक रूप से `[8, 7, 4, 1, 2, 1]` के रूप में प्रबंधित होता है
- `poll()` → 8 निकाला जाता है। Heap `[7, 4, 2, 1, 1]` के रूप में पुनर्गठित होता है
- `poll()` → 7 निकाला जाता है। 8 - 7 = 1 को `add()` से Heap में वापस डाला जाता है

## जटिलता

| | मान |
|---|---|
| Time | O(n log n) — अधिकतम n बार टकराने की प्रक्रिया होती है, और प्रत्येक प्रक्रिया में Heap के निष्कर्षण और सम्मिलन में O(log n) लगता है |
| Space | O(n) — Heap में अधिकतम n पत्थर संग्रहीत होते हैं |

## कोड

```java
// इनपुट: पूर्णांक सरणी stones (प्रत्येक तत्व पत्थर का वज़न है)
// आउटपुट: अंत में बचे पत्थर का वज़न int के रूप में लौटाता है। यदि कोई पत्थर शेष नहीं तो 0 लौटाता है
public int lastStoneWeight(int[] stones) {
    // Collections.reverseOrder() से Max-Heap (अधिकतम मान शीर्ष पर) बनाता है
    // डिफ़ॉल्ट PriorityQueue Min-Heap है, इसलिए comparator से अवरोही क्रम में उलटा जाता है
    PriorityQueue<Integer> pq =
        new PriorityQueue<>(Collections.reverseOrder());

    // सभी पत्थरों को Heap में जोड़ता है। सभी तत्व जोड़ने के बाद Heap अधिकतम मान को शीर्ष पर प्रबंधित करता है
    for (int s : stones) pq.add(s);

    // जब तक 2 या अधिक पत्थर हैं, सबसे भारी 2 पत्थरों को टकराने की प्रक्रिया दोहराता है
    while (pq.size() >= 2) {
        // poll() को 2 बार कॉल करके सबसे भारी पत्थर और अगला भारी पत्थर निकालता है
        // Max-Heap होने के कारण a >= b सदैव सत्य रहता है
        int a = pq.poll();  // सबसे भारी पत्थर निकालता है
        int b = pq.poll();  // अगला भारी पत्थर निकालता है

        // यदि वज़न भिन्न है तो अंतर का पत्थर Heap में वापस डालता है। यदि बराबर है तो दोनों नष्ट होते हैं इसलिए कुछ नहीं डालता
        if (a != b) pq.add(a - b);
    }

    // यदि Heap खाली है तो सभी पत्थर नष्ट हो गए इसलिए 0 लौटाता है, अन्यथा शेष पत्थर का वज़न लौटाता है
    return pq.isEmpty() ? 0 : pq.poll();
}
```
