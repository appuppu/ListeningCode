# Finding the Kth Largest Element in an Array — अनसॉर्टेड ऐरे में K-वाँ सबसे बड़ा तत्व खोजना

## समस्या का सार

पूर्णांकों की एक ऐरे `nums` और एक पूर्णांक `k` दिया गया है। यदि ऐरे को सॉर्ट किया जाए, तो बड़े क्रम से गिनने पर `k`-वाँ तत्व लौटाना है। डुप्लिकेट मानों को भी अलग-अलग गिना जाता है (k-वाँ सबसे बड़ा "भिन्न मान" नहीं)।

## मूल विचार

पूरी ऐरे को सॉर्ट किए बिना भी, पिवट के आधार पर ऐरे को विभाजित करने पर "पिवट कौन-से क्रम पर है" यह तुरंत पता चल जाता है। जब तक पिवट की स्थिति `k-1` नहीं हो जाती, तब तक खोज सीमा को एक तरफ सीमित करते रहने से, औसतन O(n) में लक्ष्य तत्व तक पहुँचा जा सकता है।

## विचार प्रक्रिया

1. **K-वाँ सबसे बड़ा तत्व सॉर्ट के बाद इंडेक्स से निर्धारित होता है**: यदि ऐरे को अवरोही क्रम में सॉर्ट किया जाए, तो इंडेक्स `k-1` का तत्व उत्तर होगा। लेकिन पूर्ण सॉर्ट में O(n log n) लगता है, इसलिए अधिक कुशल तरीका सोचते हैं
2. **केवल K-वीं स्थिति जानना आवश्यक है**: पूरे क्रम की जरूरत नहीं है, बस "K-वाँ सबसे बड़ा तत्व कौन-सा है" यह पता चले। पिवट का उपयोग करके ऐरे को "पिवट से बड़े समूह" और "पिवट या उससे छोटे समूह" में विभाजित करने पर, पिवट कौन-से क्रम पर है यह उसकी स्थिति (इंडेक्स) से पता चल जाता है
3. **पिवट की स्थिति से खोज सीमा को सीमित करना**: partition के परिणामस्वरूप पिवट इंडेक्स `p` पर रखा गया। यदि `p == k-1` है तो उत्तर मिल गया। यदि `p < k-1` है तो लक्ष्य तत्व पिवट के दाईं ओर (छोटे मानों की ओर) है, इसलिए खोज सीमा को `p+1` से आगे सीमित करते हैं। यदि `p > k-1` है तो बाईं ओर सीमित करते हैं
4. **अवरोही क्रम में partition करना**: सामान्य QuickSort का partition आरोही क्रम में होता है, लेकिन "K-वाँ सबसे बड़ा" खोजने के लिए अवरोही क्रम में partition करते हैं। अर्थात, पिवट से बड़े तत्वों को बाईं ओर एकत्र करते हैं। ऐसा करने से इंडेक्स `k-1` उत्तर की स्थिति के अनुरूप होता है
5. **लूप में केवल एक तरफ बार-बार प्रोसेस करना**: QuickSort दोनों तरफ पुनरावर्ती रूप से प्रोसेस करता है, लेकिन Quickselect में केवल उत्तर वाली तरफ प्रोसेस करना पर्याप्त है। while लूप में `l <= r` तक partition दोहराते रहते हैं, और `p == k-1` होने पर उस तत्व को लौटाते हैं

## पूर्वापेक्षित ज्ञान

### Quickselect क्या है

QuickSort के समान partition ऑपरेशन का उपयोग करके, ऐरे में से K-वाँ सबसे छोटा (या सबसे बड़ा) तत्व औसतन O(n) में खोजने वाला एल्गोरिदम है। QuickSort दोनों तरफ पुनरावर्ती प्रोसेसिंग करता है, जबकि Quickselect केवल एक तरफ प्रोसेस करता है, इसलिए इसकी औसत जटिलता O(n) होती है।

### partition (विभाजन) क्या है

ऐरे में से एक पिवट चुनकर, पिवट से बड़े तत्वों को बाईं ओर और पिवट या उससे छोटे तत्वों को दाईं ओर ले जाने की क्रिया है। इस क्रिया के बाद, पिवट अपनी अंतिम सही स्थिति पर रखा जाता है। यह स्थिति (इंडेक्स) पिवट का "क्रम" दर्शाती है।

```java
// अवरोही partition: पिवट से बड़े तत्वों को बाईं ओर एकत्र करना
// रिटर्न वैल्यू: पिवट जिस इंडेक्स पर रखा गया वह इंडेक्स
int pivot = nums[r];       // दाएँ छोर के तत्व को पिवट के रूप में चुनना
int store = l;             // अगली स्वैप स्थिति को इंगित करने वाला पॉइंटर
// यदि nums[i] > pivot है, तो nums[i] को store स्थिति पर स्वैप करके store को आगे बढ़ाना
// अंत में pivot को store स्थिति पर रखना → store पिवट की अंतिम स्थिति है
```

### swap (तत्वों की अदला-बदली) क्या है

ऐरे के दो तत्वों की स्थिति को आपस में बदलने की क्रिया है। एक अस्थायी चर `temp` का उपयोग करके मान को सुरक्षित रखा जाता है, जिससे ओवरराइट होने से बचा जा सके।

```java
int temp = nums[i];    // nums[i] के मान को अस्थायी चर में सुरक्षित रखना
nums[i] = nums[store]; // nums[store] के मान को nums[i] में ओवरराइट करना
nums[store] = temp;    // सुरक्षित रखे गए मूल nums[i] के मान को nums[store] में लिखना
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) औसत — प्रत्येक बार खोज सीमा औसतन आधी होती जाती है, इसलिए n + n/2 + n/4 + ... ≈ 2n = O(n) |
| Space | O(1) — ऐरे को in-place में संचालित किया जाता है और कोई अतिरिक्त डेटा संरचना उपयोग नहीं होती |

## कोड

```java
// इनपुट: पूर्णांक ऐरे nums और पूर्णांक k
// आउटपुट: ऐरे में K-वाँ सबसे बड़ा तत्व int के रूप में लौटाना

// अवरोही partition: पिवट से बड़े तत्वों को बाईं ओर एकत्र करना और पिवट की अंतिम स्थिति लौटाना
private int partition(int[] nums, int l, int r) {
    // खोज सीमा के दाएँ छोर के तत्व को पिवट के रूप में चुनना
    int pivot = nums[r];
    // store "अगले पिवट से बड़े तत्व को रखने की स्थिति" को इंगित करता है
    int store = l;

    // l से r-1 तक स्कैन करना और पिवट से बड़े तत्वों को बाईं ओर एकत्र करना
    for (int i = l; i < r; i++) {
        // यदि वर्तमान तत्व पिवट से बड़ा है, तो उसे store स्थिति पर स्वैप करके बाईं ओर एकत्र करना
        if (nums[i] > pivot) {
            int temp = nums[i];
            nums[i] = nums[store];
            nums[store] = temp;
            // store को एक आगे बढ़ाकर अगली स्वैप स्थिति अपडेट करना
            store++;
        }
    }

    // पिवट को store स्थिति पर रखना (पिवट की अंतिम सही स्थिति)
    // इस बिंदु पर, store के बाईं ओर पिवट से बड़े तत्व हैं और दाईं ओर पिवट या उससे छोटे तत्व हैं
    int temp = nums[store];
    nums[store] = nums[r];
    nums[r] = temp;
    // store पिवट की अंतिम स्थिति है और अवरोही क्रम में "क्रम" को दर्शाता है
    return store;
}

public int findKthLargest(int[] nums, int k) {
    // खोज सीमा के बाएँ और दाएँ छोर को आरंभ करना। शुरू में पूरी ऐरे खोज सीमा है
    int l = 0, r = nums.length - 1;

    // प्रत्येक लूप पुनरावृत्ति में खोज सीमा सिकुड़ती जाती है
    while (l <= r) {
        // वर्तमान खोज सीमा [l, r] में partition निष्पादित करना और पिवट की स्थिति प्राप्त करना
        int p = partition(nums, l, r);

        if (p == k - 1) {
            // पिवट K-वें सबसे बड़े स्थान पर है। अवरोही क्रम में इंडेक्स k-1 K-वें सबसे बड़े तत्व की स्थिति है
            return nums[p];
        } else if (p < k - 1) {
            // K-वाँ सबसे बड़ा तत्व पिवट के दाईं ओर (छोटे मानों की ओर) है
            l = p + 1;
        } else {
            // K-वाँ सबसे बड़ा तत्व पिवट के बाईं ओर (बड़े मानों की ओर) है
            r = p - 1;
        }
    }
    // समस्या की शर्तों के अनुसार, एक वैध k दिया जाता है इसलिए यहाँ कभी नहीं पहुँचेंगे
    return -1;
}
```
