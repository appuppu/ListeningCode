# Designing a Simplified Twitter Feed — कई उपयोगकर्ताओं के ट्वीट्स से नवीनतम 10 ट्वीट्स को कुशलतापूर्वक प्राप्त करने वाली प्रणाली डिज़ाइन करना

## समस्या का सार

एक सरलीकृत Twitter प्रणाली के रूप में 4 ऑपरेशन लागू करना है। `postTweet` से ट्वीट पोस्ट करना, `getNewsFeed` से उस उपयोगकर्ता और उसके फ़ॉलो किए गए उपयोगकर्ताओं के ट्वीट्स से **नवीनतम 10 ट्वीट्स** प्राप्त करना, `follow` से फ़ॉलो करना, और `unfollow` से अनफ़ॉलो करना है। मुख्य चुनौती यह है कि कई उपयोगकर्ताओं की ट्वीट सूचियों को **समय क्रम में मर्ज करके केवल शीर्ष 10 ट्वीट्स को कुशलतापूर्वक निकालना** है।

## मूल विचार

प्रत्येक उपयोगकर्ता की ट्वीट सूची पहले से ही पोस्ट क्रम (समय क्रम) में सॉर्ट होती है। कई सॉर्ट की हुई सूचियों से शीर्ष K आइटम निकालने की समस्या को सभी सूचियों को दोबारा सॉर्ट करने के बजाय, **Heap का उपयोग करके K-way मर्ज** से हल किया जा सकता है, जिसमें प्रत्येक सूची के केवल पहले तत्व की तुलना करते हुए एक-एक करके निकाला जाता है, जिससे न्यूनतम तुलनाओं में समाधान मिलता है।

## विचार प्रक्रिया

1. **डेटा संग्रहण विधि तय करना**: प्रत्येक उपयोगकर्ता द्वारा पोस्ट किए गए ट्वीट्स को समय क्रम में प्रबंधित करने की आवश्यकता है। उपयोगकर्ता ID को कुंजी और ट्वीट सूची को मान के रूप में HashMap का उपयोग करने से किसी भी उपयोगकर्ता की ट्वीट सूची O(1) में प्राप्त की जा सकती है। प्रत्येक ट्वीट को एक ग्लोबल टाइमस्टैम्प दिया जाता है जिससे पोस्ट क्रम रिकॉर्ड होता है
2. **फ़ॉलो संबंध प्रबंधन विधि तय करना**: फ़ॉलो और अनफ़ॉलो ऑपरेशन उपयोगकर्ता ID के सेट में जोड़ने और हटाने के अनुरूप हैं। उपयोगकर्ता ID को कुंजी और फ़ॉलो किए गए ID के Set को मान के रूप में HashMap का उपयोग करने से फ़ॉलो जोड़ना, हटाना और सूची प्राप्त करना सभी O(1) में किया जा सकता है
3. **न्यूज़ फ़ीड प्राप्ति का सार पहचानना**: `getNewsFeed` स्वयं और फ़ॉलो किए गए सभी उपयोगकर्ताओं के ट्वीट्स से नवीनतम 10 ट्वीट्स लौटाने का ऑपरेशन है। प्रत्येक उपयोगकर्ता की ट्वीट सूची पहले से पोस्ट क्रम में सॉर्ट है, इसलिए यह **कई सॉर्ट की हुई सूचियों से शीर्ष K आइटम निकालने की समस्या (K-way मर्ज)** में परिवर्तित हो जाती है
4. **K-way मर्ज के लिए Heap का उपयोग करना**: प्रत्येक उपयोगकर्ता की ट्वीट सूची के अंत (नवीनतम ट्वीट) को Max-Heap में डालना है। Heap से सबसे बड़े टाइमस्टैम्प वाले तत्व को निकालना है, और उस उपयोगकर्ता के अगले नए ट्वीट को Heap में जोड़ना है। यह प्रक्रिया 10 बार दोहराने से नवीनतम 10 ट्वीट्स प्राप्त होते हैं
5. **Heap के प्रत्येक तत्व में रखी जाने वाली जानकारी तय करना**: Heap से निकालने के बाद उसी उपयोगकर्ता के अगले ट्वीट को जोड़ने के लिए, प्रत्येक एंट्री में "टाइमस्टैम्प", "ट्वीट ID", "उपयोगकर्ता ID" और "सूची में इंडेक्स" ये 4 जानकारियाँ रखी जाती हैं। इंडेक्स को 1 घटाकर उस उपयोगकर्ता के अगले नए ट्वीट तक पहुँचा जा सकता है
6. **10 ट्वीट्स प्राप्त होने पर जल्दी समाप्त करना**: Heap खाली होने या परिणाम सूची में 10 ट्वीट्स पहुँचने पर लूप समाप्त किया जाता है। सभी ट्वीट्स को प्रोसेस करने की आवश्यकता नहीं है

## पूर्व ज्ञान

### PriorityQueue (प्राथमिकता कतार / Heap) क्या है

यह एक डेटा संरचना है जो तत्व जोड़ने पर उन्हें स्वचालित रूप से प्राथमिकता क्रम में व्यवस्थित करती है। सबसे उच्च प्राथमिकता वाले तत्व को O(log N) में निकाला जा सकता है। Java का PriorityQueue डिफ़ॉल्ट रूप से Min-Heap (न्यूनतम मान सबसे पहले) होता है, लेकिन Comparator निर्दिष्ट करके इसे Max-Heap (अधिकतम मान सबसे पहले) में बदला जा सकता है।

```java
// Max-Heap बनाना (बड़ा टाइमस्टैम्प = नया ट्वीट सबसे पहले आता है)
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> b[0] - a[0]);
pq.offer(new int[]{5, 101});   // [टाइमस्टैम्प, ट्वीट ID] जोड़ना
pq.offer(new int[]{3, 102});   // जोड़ने के बाद, आंतरिक रूप से टाइमस्टैम्प अवरोही क्रम में व्यवस्थित होता है
int[] top = pq.poll();         // सबसे बड़े टाइमस्टैम्प वाला तत्व निकालना → [5, 101]
pq.isEmpty();                  // Heap खाली है या नहीं boolean में लौटाना → false
```

### computeIfAbsent क्या है

यह एक मेथड है जो HashMap में कुंजी मौजूद न होने पर ही निर्दिष्ट फ़ंक्शन से मान उत्पन्न करके उसे पंजीकृत करता है और वह मान लौटाता है। कुंजी मौजूद होने पर यह मौजूदा मान को वैसे ही लौटाता है। `get` करके `null` जाँच करके `put` करने के 3 चरणों को 1 पंक्ति में संक्षिप्त किया जा सकता है।

```java
Map<Integer, List<int[]>> tweets = new HashMap<>();
// यदि कुंजी 1 मौजूद नहीं है तो नई ArrayList बनाकर पंजीकृत करना और वह सूची लौटाना
tweets.computeIfAbsent(1, k -> new ArrayList<>()).add(new int[]{0, 101});
// कुंजी 1 पहले से मौजूद है, इसलिए मौजूदा सूची लौटाना और उसमें जोड़ना
tweets.computeIfAbsent(1, k -> new ArrayList<>()).add(new int[]{1, 102});
```

### K-way मर्ज क्या है

K सॉर्ट की हुई सूचियों को एक सॉर्ट की हुई अनुक्रम में एकीकृत करने की तकनीक है। प्रत्येक सूची के पहले तत्व को Heap में डाला जाता है, और न्यूनतम (या अधिकतम) निकालने पर, निकाले गए तत्व की सूची के अगले तत्व को Heap में जोड़ा जाता है। सभी तत्वों को एक साथ सॉर्ट करने वाले O(N log N) से अधिक कुशलता से, O(N log K) में एकीकरण किया जा सकता है।

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(K log K) — K फ़ॉलो किए गए उपयोगकर्ताओं की संख्या है। Heap में प्रारंभिक सम्मिलन में O(K log K) और अधिकतम 10 बार poll/offer में O(10 log K) लगता है |
| Space | O(K) — Heap में एक समय में अधिकतम K तत्व संग्रहीत होते हैं |

## कोड

```java
// इनपुट: postTweet(userId, tweetId), follow(followerId, followeeId), unfollow(followerId, followeeId), getNewsFeed(userId) के प्रत्येक ऑपरेशन कॉल
// आउटपुट: getNewsFeed उपयोगकर्ता और उसके फ़ॉलो किए गए उपयोगकर्ताओं के ट्वीट्स से नवीनतम 10 ट्वीट ID को List<Integer> में लौटाता है
class Twitter {
    // ग्लोबल टाइमस्टैम्प। सभी उपयोगकर्ताओं के ट्वीट्स के बीच पोस्ट क्रम को विशिष्ट रूप से पहचानता है (एकदिशीय वृद्धि)
    int time = 0;
    // कुंजी=उपयोगकर्ता ID, मान=उस उपयोगकर्ता की ट्वीट सूची (प्रत्येक तत्व [टाइमस्टैम्प, ट्वीट ID] है)
    // सूची में पोस्ट क्रम में अंत में जोड़ा जाता है, इसलिए अंतिम तत्व नवीनतम होता है
    Map<Integer, List<int[]>> tweets;
    // कुंजी=फ़ॉलो करने वाले का उपयोगकर्ता ID, मान=फ़ॉलो किए गए उपयोगकर्ता ID का Set
    // Set का उपयोग करने से फ़ॉलो जोड़ना, हटाना और डुप्लिकेट रोकना सभी O(1) में होता है
    Map<Integer, Set<Integer>> follows;

    Twitter() {
        tweets = new HashMap<>();
        follows = new HashMap<>();
    }

    void postTweet(int userId, int tweetId) {
        // उपयोगकर्ता की ट्वीट सूची प्राप्त करना (नहीं है तो बनाना) और अंत में [टाइमस्टैम्प, ट्वीट ID] जोड़ना
        // time++ ग्लोबल रूप से एकदिशीय वृद्धि करता है, इसलिए सभी उपयोगकर्ताओं के बीच पोस्ट क्रम की सही तुलना की जा सकती है
        tweets.computeIfAbsent(userId, k -> new ArrayList<>())
            .add(new int[]{time++, tweetId});
    }

    void follow(int followerId, int followeeId) {
        // फ़ॉलो Set में followeeId जोड़ना (Set होने के कारण एक ही उपयोगकर्ता को दोबारा फ़ॉलो करने पर भी डुप्लिकेट नहीं होता)
        follows.computeIfAbsent(followerId, k -> new HashSet<>())
            .add(followeeId);
    }

    void unfollow(int followerId, int followeeId) {
        // फ़ॉलो संबंध मौजूद होने पर ही followeeId को Set से हटाना। मौजूद न होने पर कुछ नहीं करना
        if (follows.containsKey(followerId))
            follows.get(followerId).remove(followeeId);
    }

    List<Integer> getNewsFeed(int userId) {
        // Max-Heap: बड़े (नए) टाइमस्टैम्प वाला तत्व सबसे पहले आए, इसके लिए Comparator निर्दिष्ट करना
        PriorityQueue<int[]> pq =
            new PriorityQueue<>((a, b) -> b[0] - a[0]);

        // फ़ीड लक्षित उपयोगकर्ता = स्वयं + फ़ॉलो किए गए सभी उपयोगकर्ता
        // अपने ट्वीट्स भी फ़ीड में शामिल करने की आवश्यकता है, इसलिए स्वयं को जोड़ना न भूलें
        Set<Integer> users = new HashSet<>();
        users.add(userId);
        if (follows.containsKey(userId))
            users.addAll(follows.get(userId));

        // प्रत्येक उपयोगकर्ता के नवीनतम ट्वीट (सूची के अंतिम तत्व) को Heap में जोड़ना
        // उपयोगकर्ता ID और इंडेक्स शामिल करने का कारण है कि निकालने के बाद उस उपयोगकर्ता के अगले ट्वीट तक पहुँचा जा सके
        for (int uid : users) {
            if (!tweets.containsKey(uid)) continue;
            List<int[]> t = tweets.get(uid);
            int idx = t.size() - 1;
            int[] tw = t.get(idx);
            // [टाइमस्टैम्प, ट्वीट ID, उपयोगकर्ता ID, सूची में इंडेक्स] के 4 तत्वों वाला ऐरे
            pq.offer(new int[]{tw[0], tw[1], uid, idx});
        }

        // Heap से अधिकतम 10 ट्वीट्स निकालना (Heap खाली होने या 10 पहुँचने पर जल्दी समाप्त करना)
        List<Integer> res = new ArrayList<>();
        while (!pq.isEmpty() && res.size() < 10) {
            // सबसे बड़े टाइमस्टैम्प वाला तत्व निकालना
            int[] top = pq.poll();
            // निकाले गए ट्वीट ID को परिणाम में जोड़ना
            res.add(top[1]);
            int uid = top[2];
            // इंडेक्स को 1 घटाकर उस उपयोगकर्ता के अगले नए ट्वीट की ओर इंगित करना
            int idx = top[3] - 1;
            // उस उपयोगकर्ता के और ट्वीट्स होने पर Heap में जोड़ना (इंडेक्स ऋणात्मक होने पर सभी प्रोसेस हो चुके हैं)
            if (idx >= 0) {
                int[] tw = tweets.get(uid).get(idx);
                pq.offer(new int[]{tw[0], tw[1], uid, idx});
            }
        }
        // नवीनतम 10 (या कुल ट्वीट्स 10 से कम होने पर सभी) ट्वीट ID टाइमस्टैम्प अवरोही क्रम में संग्रहीत हैं
        return res;
    }
}
```
