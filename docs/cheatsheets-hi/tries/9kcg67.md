# Designing a Word Dictionary With Wildcard Search — वाइल्डकार्ड के साथ शब्दकोश में शब्द खोज

## समस्या का सार

शब्द जोड़ने और खोजने की दो क्रियाओं का समर्थन करने वाली डेटा संरचना डिज़ाइन करनी है। खोज के समय डॉट `.` किसी भी एक अक्षर से मेल खाने वाले वाइल्डकार्ड के रूप में कार्य करता है। उदाहरण के लिए, यदि शब्दकोश में "bad" पंजीकृत है, तो `search("b.d")` `true` लौटाता है, और `search("b.e")` `false` लौटाता है।

## मूल विचार

Trie में शब्दों को संग्रहीत करना है, सामान्य अक्षरों के लिए उसके एक चाइल्ड नोड को अनुसरण करना पर्याप्त है, लेकिन डॉट मिलने पर "सभी चाइल्ड नोड्स" में शाखा बनाकर गहराई-पहले खोज (DFS) करने से किसी भी एक अक्षर से मेल खाने वाली खोज को साकार किया जा सकता है।

## विचार प्रक्रिया

1. **शब्द जोड़ना और प्रीफ़िक्स खोज कुशलतापूर्वक करनी है**: स्ट्रिंग को एक-एक अक्षर साझा करते हुए संग्रहीत करने वाली डेटा संरचना के रूप में Trie उपयुक्त है। Trie का उपयोग करने से समान प्रीफ़िक्स वाले शब्द नोड्स साझा कर सकते हैं, जिससे मेमोरी दक्षता और खोज दक्षता दोनों प्राप्त होती हैं
2. **सामान्य अक्षरों की खोज Trie की मूल क्रिया से की जा सकती है**: अक्षर `c` के लिए, वर्तमान नोड के `children[c - 'a']` को अनुसरण करना पर्याप्त है। यदि चाइल्ड नोड `null` है तो मेल नहीं खाता, यदि मौजूद है तो अगले अक्षर पर बढ़ना है
3. **डॉट सभी चाइल्ड नोड्स में शाखा बनाने का अर्थ रखता है**: डॉट किसी भी एक अक्षर से मेल खाता है, इसलिए वर्तमान नोड के 26 चाइल्ड नोड्स में से `null` न होने वाले सभी को आज़माना आवश्यक है। यदि किसी एक से भी शेष स्ट्रिंग मेल खाती है तो `true` लौटाना पर्याप्त है
4. **शाखाओं की खोज के लिए गहराई-पहले खोज (DFS) का उपयोग करना है**: डॉट पर शाखा बनी प्रत्येक पथ को पुनरावर्ती रूप से अनुसरण करना है, और शब्द के अंत तक पहुँचने पर यदि `isEnd` फ़्लैग `true` है तो खोज सफल मानी जाती है। DFS का उपयोग करने से शाखा प्रसंस्करण और सामान्य अक्षर प्रसंस्करण को एकीकृत रूप से संभाला जा सकता है
5. **पुनरावर्तन की समाप्ति शर्त निर्धारित करनी है**: स्ट्रिंग के सभी अक्षरों का प्रसंस्करण पूर्ण होने के समय (`idx == word.length()`), यदि वर्तमान नोड का `isEnd` `true` है तो शब्द मौजूद है। यदि बीच में चाइल्ड नोड `null` हो जाता है तो उस पथ पर मेल नहीं खाता
6. **अंतिम रूप से लौटाने वाला मान**: `search` मेथड रूट नोड से पुनरावर्ती रूप से DFS प्रारंभ करता है, यदि कोई एक भी मेल खाने वाला पथ मिलता है तो `true`, अन्यथा `false` लौटाता है

## पूर्वापेक्षित ज्ञान

### Trie (ट्राई ट्री) क्या है

स्ट्रिंग को एक-एक अक्षर में विभाजित करके नोड्स में संग्रहीत करने वाली ट्री संरचना है। प्रत्येक नोड अधिकतम 26 चाइल्ड नोड्स (a से z) रखता है, और रूट से पत्ती की ओर अनुसरण करने पर एक शब्द बनता है। समान प्रीफ़िक्स वाले शब्द नोड्स साझा करते हैं, इसलिए यह शब्दकोश के संग्रहण के लिए उपयुक्त है।

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a से z के लिए 26 चाइल्ड नोड्स
    boolean isEnd = false;                    // क्या इस बिंदु पर समाप्त होने वाला कोई शब्द मौजूद है
}
```

### गहराई-पहले खोज (DFS) क्या है

ट्री या ग्राफ की खोज विधियों में से एक है। एक पथ को अंत तक अनुसरण करती है, और डेड-एंड पर पहुँचने पर एक कदम पीछे जाकर दूसरे पथ को आज़माती है। पुनरावर्तन से कार्यान्वयन स्वाभाविक है, और Trie की शाखा खोज के लिए उपयुक्त है।

```java
boolean dfs(TrieNode node, String word, int idx) {
    // idx वर्तमान में प्रसंस्करण हो रही अक्षर स्थिति है
    // पुनरावर्ती रूप से चाइल्ड नोड्स का अनुसरण करके शर्त पूरी करने वाले पथ को खोजना है
}
```

### char का पूर्णांक रूपांतरण

Java में `char` प्रकार एक पूर्णांक मान रखता है। `c - 'a'` से अक्षर `c` की वर्णमाला में स्थिति (0 से 25) प्राप्त की जा सकती है। इस मान का उपयोग Trie के `children` ऐरे के इंडेक्स के रूप में किया जाता है।

```java
char c = 'd';
int idx = c - 'a';  // idx = 3 ('a'=0, 'b'=1, 'c'=2, 'd'=3)
```

## गणना जटिलता

| | मान |
|---|---|
| Time (addWord) | O(m) — शब्द की लंबाई m के अनुपात में Trie नोड्स का अनुसरण करता है |
| Time (search) | O(26^d × m) — d डॉट्स की संख्या है, m शब्द की लंबाई है। यदि डॉट नहीं है तो O(m) |
| Space | O(n × m) — n शब्दों (औसत लंबाई m) को Trie में संग्रहीत करता है |

## कोड

```java
// इनपुट: addWord(word) स्ट्रिंग word को प्राप्त करके शब्दकोश में जोड़ता है। search(word) स्ट्रिंग word ("." सहित संभव) को प्राप्त करता है
// आउटपुट: search शब्दकोश में मेल खाने वाला शब्द मौजूद होने पर true, मौजूद न होने पर false लौटाता है

class TrieNode {
    TrieNode[] children;  // a से z के लिए 26 चाइल्ड नोड्स
    boolean isEnd;        // क्या इस बिंदु पर समाप्त होने वाला कोई शब्द मौजूद है

    TrieNode() {
        children = new TrieNode[26];
        isEnd = false;
    }
}

class WordDictionary {
    TrieNode root;  // Trie का रूट नोड

    WordDictionary() {
        root = new TrieNode();
    }

    // शब्द को Trie में जोड़ता है
    void addWord(String word) {
        // वर्तमान नोड को रूट से आरंभ करता है
        TrieNode node = root;
        // शब्द के प्रत्येक अक्षर को आरंभ से क्रम में प्रसंस्कृत करता है
        for (char c : word.toCharArray()) {
            // c - 'a' से children ऐरे में अक्षर c की संगत स्थिति ज्ञात करता है
            int idx = c - 'a';
            // यदि चाइल्ड नोड मौजूद नहीं है तो नया बनाता है
            if (node.children[idx] == null)
                node.children[idx] = new TrieNode();
            // चाइल्ड नोड पर जाता है
            node = node.children[idx];
        }
        // शब्द के अंत को दर्ज करता है। यह दर्शाता है कि इस बिंदु पर समाप्त होने वाला शब्द शब्दकोश में मौजूद है
        node.isEnd = true;
    }

    // वाइल्डकार्ड सहित खोज को रूट से प्रारंभ करता है
    boolean search(String word) {
        // रूट नोड से स्थिति 0 पर DFS प्रारंभ करता है
        return dfs(root, word, 0);
    }

    // DFS से पुनरावर्ती रूप से Trie की खोज करता है
    boolean dfs(TrieNode node, String word, int idx) {
        // समाप्ति शर्त: सभी अक्षरों का प्रसंस्करण पूर्ण होने पर, वर्तमान नोड शब्द का अंत है या नहीं यह लौटाता है
        // true होने पर शब्द मौजूद है, false होने पर केवल आंशिक रूप से मेल खाने वाला शब्द है
        if (idx == word.length())
            return node.isEnd;

        char c = word.charAt(idx);

        if (c == '.') {
            // डॉट की स्थिति में: सभी 26 चाइल्ड नोड्स को आज़माता है (किसी भी एक अक्षर से मेल)
            for (TrieNode child : node.children) {
                // null न होने वाले चाइल्ड नोड पर पुनरावर्ती रूप से खोज करता है
                if (child != null && dfs(child, word, idx + 1))
                    return true;  // किसी भी पथ पर मेल मिलने पर तुरंत true लौटाता है
            }
            // सभी चाइल्ड नोड्स आज़माने के बाद भी true न मिलने पर मेल नहीं खाता
            return false;
        } else {
            // सामान्य अक्षर की स्थिति में: c - 'a' से इंडेक्स ज्ञात करके संगत चाइल्ड नोड का अनुसरण करता है
            int i = c - 'a';
            // यदि चाइल्ड नोड मौजूद नहीं है तो संगत अक्षर नहीं है, इसलिए मेल नहीं खाता
            if (node.children[i] == null)
                return false;
            // यदि चाइल्ड नोड मौजूद है तो अगली अक्षर स्थिति idx + 1 पर पुनरावर्तन करता है
            return dfs(node.children[i], word, idx + 1);
        }
    }
}
```
