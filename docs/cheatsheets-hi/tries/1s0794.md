# Finding All Words From a Dictionary in a Grid — ग्रिड पर शब्दकोश के सभी शब्दों को एक साथ खोजना

## समस्या का सार

अक्षरों का एक 2D ग्रिड `board` और एक शब्द सूची `words` दी गई है। ग्रिड पर आसन्न सेल (ऊपर, नीचे, बाएँ, दाएँ) को क्रम से जोड़कर बनाए जा सकने वाले सभी शब्दों को `words` में से खोजकर लौटाना है। प्रत्येक सेल को एक शब्द की रचना में केवल एक बार उपयोग किया जा सकता है।

## मूल विचार

शब्द सूची के सभी शब्दों को Trie में संग्रहित करके, ग्रिड के प्रत्येक सेल से DFS करते समय Trie नोड को अनुसरण करने से, सभी शब्दों को एक साथ खोजा जा सकता है। Trie की शाखा जिस दिशा में मौजूद नहीं है, उस दिशा में DFS को तुरंत समाप्त किया जा सकता है, जिससे अनावश्यक खोज में बड़ी कमी आती है।

## विचार प्रक्रिया

1. **एक साथ कई शब्द खोजने हैं**: यदि प्रत्येक शब्द के लिए अलग-अलग DFS किया जाए, तो गणना जटिलता शब्दों की संख्या × ग्रिड के सभी सेल × अधिकतम शब्द लंबाई हो जाती है। यदि कई शब्द एक ही उपसर्ग (prefix) साझा करते हैं, तो एक ही DFS में कई शब्दों को एक साथ खोजना कुशल है
2. **साझा उपसर्ग प्रबंधन के लिए Trie उपयुक्त है**: Trie को उपसर्ग वृक्ष भी कहते हैं, जो स्ट्रिंग के साझा उपसर्ग को एक ही पथ के रूप में साझा करता है। सभी शब्दों को Trie में डालने पर, DFS के दौरान वर्तमान पथ किस शब्द के उपसर्ग से मेल खाता है, यह O(1) में निर्धारित किया जा सकता है
3. **Trie नोड में शब्द स्वयं संग्रहित करना**: शब्द के अंतिम नोड में पूर्ण शब्द स्ट्रिंग संग्रहित करने पर, DFS उस नोड पर पहुँचते ही "कौन सा शब्द मिला" तुरंत प्राप्त किया जा सकता है
4. **ग्रिड के प्रत्येक सेल से Trie के रूट को प्रारंभ बिंदु के रूप में DFS करना**: प्रत्येक सेल को प्रारंभ बिंदु के रूप में, Trie के रूट से अक्षरों को अनुसरण करते हुए DFS करना है। यदि वर्तमान अक्षर के लिए संगत चाइल्ड नोड Trie में मौजूद नहीं है, तो उस दिशा की खोज तुरंत समाप्त की जाती है (प्रूनिंग)
5. **विज़िटेड सेल की मार्किंग**: DFS के दौरान एक ही सेल पर दोबारा न जाने के लिए, वर्तमान में विज़िट किए जा रहे सेल के अक्षर को अस्थायी रूप से विशेष अक्षर `'#'` से बदला जाता है। DFS समाप्त होने के बाद मूल अक्षर पुनर्स्थापित किया जाता है (बैकट्रैकिंग)
6. **डुप्लिकेट रोकथाम**: एक ही शब्द कई पथों से मिल सकता है। शब्द को परिणाम सूची में जोड़ते समय, उस Trie नोड के `word` को `null` सेट करने से, उसी शब्द का दोहराव रोका जा सकता है

## पूर्वापेक्षित ज्ञान

### Trie (ट्राई वृक्ष) क्या है

स्ट्रिंग के समूह को कुशलतापूर्वक संग्रहित और खोजने के लिए एक वृक्ष संरचना है। प्रत्येक नोड में अधिकतम 26 चाइल्ड नोड (a〜z) होते हैं, और रूट से पत्ती तक का पथ एक स्ट्रिंग को दर्शाता है। साझा उपसर्ग वाली स्ट्रिंग पथ साझा करती हैं, इसलिए उपसर्ग का निर्धारण O(स्ट्रिंग की लंबाई) में किया जा सकता है।

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a〜z के 26 अक्षरों के लिए चाइल्ड नोड सरणी
    String word = null;                       // इस नोड पर पूर्ण होने वाला शब्द (अंतिम नोड न हो तो null)
}

// Trie में शब्द सम्मिलन
TrieNode root = new TrieNode();
TrieNode node = root;
for (char c : "cat".toCharArray()) {
    int i = c - 'a';                          // अक्षर को इंडेक्स में बदलना ('a'→0, 'b'→1, ...)
    if (node.children[i] == null)
        node.children[i] = new TrieNode();    // चाइल्ड नोड न हो तो नया बनाना
    node = node.children[i];                  // चाइल्ड नोड पर जाना
}
node.word = "cat";                            // अंतिम नोड में शब्द संग्रहित करना
```

### बैकट्रैकिंग क्या है

DFS (गहराई-पहली खोज) का एक प्रकार है जिसमें खोज के दौरान स्थिति बदली जाती है, और खोज समाप्त होने के बाद स्थिति को पूर्ववत किया जाता है। इससे यह सुनिश्चित होता है कि एक खोज पथ में किया गया स्थिति परिवर्तन अन्य पथों को प्रभावित नहीं करता।

```java
board[r][c] = '#';    // विज़िट मार्क लगाना (अन्य पथ इस सेल पर दोबारा नहीं जाएँगे)
// ... DFS से ऊपर, नीचे, बाएँ, दाएँ खोजना ...
board[r][c] = ch;     // मूल अक्षर पुनर्स्थापित करना (अन्य प्रारंभ बिंदुओं से खोज में पुन: उपयोग योग्य बनाना)
```

### char और int के बीच रूपांतरण

Java में `char` प्रकार एक पूर्णांक मान रखता है, इसलिए अक्षरों का अंतर गणना करके इंडेक्स में बदला जा सकता है।

```java
char ch = 'c';
int index = ch - 'a';   // 'c' - 'a' = 2 (सरणी के इंडेक्स के रूप में उपयोग)
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(M × N × 4^L) — M×N ग्रिड के सेलों की संख्या है, L सबसे लंबे शब्द की लंबाई है। प्रत्येक सेल से अधिकतम 4 दिशाओं में L बार पुनरावृत्ति होती है |
| Space | O(सभी शब्दों के अक्षरों की कुल संख्या) — Trie में सभी शब्दों को संग्रहित करने का स्थान |

## कोड

```java
// इनपुट: अक्षरों की 2D सरणी board और स्ट्रिंग सरणी words
// आउटपुट: board पर बनाए जा सकने वाले सभी शब्दों को संग्रहित करने वाली List<String> लौटाना

class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a〜z के चाइल्ड नोड
    String word = null;                       // इस नोड पर पूर्ण होने वाला शब्द
}

// सभी शब्दों को Trie में सम्मिलित करके रूट नोड लौटाना
TrieNode buildTrie(String[] words) {
    // खाली Trie बनाने के लिए एक रूट नोड बनाना (सभी शब्दों की खोज का प्रारंभ बिंदु)
    TrieNode root = new TrieNode();
    // words के प्रत्येक शब्द को Trie में सम्मिलित करना
    for (String w : words) {
        TrieNode node = root;
        // रूट से एक-एक अक्षर करके चाइल्ड नोड अनुसरण करना
        for (char c : w.toCharArray()) {
            int i = c - 'a';
            // चाइल्ड नोड मौजूद न हो तो नया बनाना
            if (node.children[i] == null)
                node.children[i] = new TrieNode();
            node = node.children[i];
        }
        // शब्द के अंतिम नोड में शब्द स्ट्रिंग संग्रहित करना (DFS में नोड पहुँचने पर पूर्ण शब्द तुरंत प्राप्त किया जा सकता है)
        node.word = w;
    }
    return root;
}

// Trie नोड को अनुसरण करते हुए ग्रिड पर DFS करना
void dfs(char[][] board, int r, int c,
    TrieNode node, List<String> res) {
    // सीमा जाँच: पंक्ति r या स्तंभ c ग्रिड की सीमा से बाहर हो तो तुरंत लौटना
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length)
        return;
    char ch = board[r][c];
    // विज़िट मार्क '#' वाले सेल पर तुरंत लौटना (एक ही पथ में दोबारा विज़िट रोकना)
    if (ch == '#') return;
    // वर्तमान अक्षर के संगत Trie चाइल्ड नोड प्राप्त करना
    TrieNode next = node.children[ch - 'a'];
    // चाइल्ड नोड न हो तो इस दिशा में कोई शब्द Trie में मौजूद नहीं है (प्रूनिंग)
    if (next == null) return;
    // शब्द पूर्ण हो गया हो तो परिणाम में जोड़ना और डुप्लिकेट रोकथाम के लिए null सेट करना
    // (एक ही शब्द कई पथों से मिल सकता है)
    if (next.word != null) {
        res.add(next.word);
        next.word = null;
    }
    // वर्तमान सेल को '#' से बदलकर विज़िट मार्क लगाना
    board[r][c] = '#';
    // ऊपर, नीचे, बाएँ, दाएँ 4 दिशाओं में next नोड पास करके पुनरावर्ती DFS करना
    dfs(board, r + 1, c, next, res);
    dfs(board, r - 1, c, next, res);
    dfs(board, r, c + 1, next, res);
    dfs(board, r, c - 1, next, res);
    // सेल के अक्षर को मूल ch में पुनर्स्थापित करना (बैकट्रैकिंग: अन्य प्रारंभ बिंदुओं से खोज में पुन: उपयोग योग्य बनाना)
    board[r][c] = ch;
}

// मुख्य फ़ंक्शन: ग्रिड पर शब्दकोश के सभी शब्दों को खोजना
List<String> findWords(char[][] board, String[] words) {
    // सभी शब्दों को Trie में सम्मिलित करना
    TrieNode root = buildTrie(words);
    // परिणाम संग्रहित करने के लिए खाली सूची बनाना
    List<String> res = new ArrayList<>();
    // दोहरे for लूप से सभी सेल (i, j) का अनुसरण करके, प्रत्येक सेल को प्रारंभ बिंदु के रूप में DFS चलाना
    // DFS में Trie का रूट नोड पास करना
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            dfs(board, i, j, root, res);
        }
    }
    // सभी सेलों से DFS पूर्ण होने के बाद परिणाम लौटाना
    return res;
}
```
