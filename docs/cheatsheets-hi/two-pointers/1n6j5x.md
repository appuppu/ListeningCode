# Finding Two Numbers in a Sorted Array That Add Up to a Target — क्रमबद्ध सरणी से योग लक्ष्य के बराबर होने वाली दो संख्याएँ खोजना

## समस्या का सार

क्रमबद्ध पूर्णांक सरणी `nums` और एक पूर्णांक `target` दिया गया है। `nums` में से ऐसे दो तत्व खोजने हैं जिनका योग `target` के बराबर हो, और उनकी **1-indexed स्थिति** को सरणी के रूप में लौटाना है। हल हमेशा केवल एक ही होता है, और एक ही तत्व को दो बार उपयोग नहीं किया जा सकता।

## मूल विचार

सरणी क्रमबद्ध होने के कारण, बाएँ छोर और दाएँ छोर पर दो पॉइंटर रखकर दोनों ओर से संकुचित किया जा सकता है। यदि दोनों का योग बहुत बड़ा है तो दाएँ पॉइंटर को सिकोड़ते हैं, और यदि बहुत छोटा है तो बाएँ पॉइंटर को आगे बढ़ाते हैं, जिससे एक ही बार की स्कैनिंग में O(n) समय और O(1) स्थान में उत्तर मिल जाता है।

## विचार प्रक्रिया

1. **क्रमबद्ध होने की शर्त का लाभ उठाना**: सरणी क्रमबद्ध है इसलिए बायाँ छोर न्यूनतम मान और दायाँ छोर अधिकतम मान को इंगित करता है। इन दोनों छोरों के योग से खोज शुरू करने पर, योग के बड़े या छोटे होने के अनुसार खोज सीमा को निश्चित रूप से संकुचित किया जा सकता है
2. **यदि योग बहुत बड़ा है तो दाएँ पॉइंटर को बाईं ओर ले जाना**: दायाँ पॉइंटर वर्तमान खोज सीमा में सबसे बड़े मान को इंगित करता है। यदि योग `target` से बड़ा है, तो योग को छोटा करने के लिए दाएँ पॉइंटर को एक स्थान बाईं ओर खिसकाकर छोटे मान पर स्विच करते हैं
3. **यदि योग बहुत छोटा है तो बाएँ पॉइंटर को दाईं ओर ले जाना**: बायाँ पॉइंटर वर्तमान खोज सीमा में सबसे छोटे मान को इंगित करता है। यदि योग `target` से छोटा है, तो योग को बड़ा करने के लिए बाएँ पॉइंटर को एक स्थान दाईं ओर खिसकाकर बड़े मान पर स्विच करते हैं
4. **यदि योग ठीक `target` के बराबर है तो उत्तर मिल जाता है**: जब दोनों पॉइंटर द्वारा इंगित मानों का योग `target` से मेल खाता है, तो वही अभीष्ट जोड़ी है। समस्या 1-indexed माँगती है, इसलिए प्रत्येक पॉइंटर की स्थिति में 1 जोड़कर लौटाते हैं
5. **लूप की समाप्ति शर्त**: बायाँ पॉइंटर दाएँ पॉइंटर तक पहुँचने तक लूप दोहराया जाता है। समस्या की बाधाओं के अनुसार हल अवश्य मौजूद होता है, इसलिए पॉइंटर क्रॉस करने से पहले उत्तर अवश्य मिल जाता है
6. **अंत में क्या लौटाना है**: योग `target` से मेल खाने पर, `left + 1` (बाएँ तत्व की 1-indexed स्थिति) और `right + 1` (दाएँ तत्व की 1-indexed स्थिति) दोनों को `int[]` के रूप में लौटाते हैं

## पूर्वापेक्षित ज्ञान

### Two Pointers (दो पॉइंटर) क्या है

सरणी में विभिन्न स्थानों को इंगित करने वाले दो इंडेक्स चर का उपयोग करके, शर्त के अनुसार प्रत्येक को आगे-पीछे ले जाने की तकनीक है। क्रमबद्ध सरणियों में, दोनों छोरों से केंद्र की ओर खोज सीमा को संकुचित करने का पैटर्न सबसे सामान्य है।

```java
int left = 0;                    // बाएँ पॉइंटर को सरणी की शुरुआत पर रखना
int right = nums.length - 1;     // दाएँ पॉइंटर को सरणी के अंत पर रखना
while (left < right) {           // दोनों पॉइंटर क्रॉस करने तक लूप चलाना
    // left और right को शर्त के अनुसार आगे-पीछे ले जाना
    left++;   // बाएँ पॉइंटर को एक स्थान दाईं ओर बढ़ाना
    right--;  // दाएँ पॉइंटर को एक स्थान बाईं ओर घटाना
}
```

### क्रमबद्ध सरणी के गुण

यदि सरणी आरोही क्रम में क्रमबद्ध है, तो `nums[left] <= nums[right]` हमेशा सत्य रहता है। बाएँ पॉइंटर को दाईं ओर ले जाने पर योग बढ़ता है, और दाएँ पॉइंटर को बाईं ओर ले जाने पर योग घटता है। यह एकदिशीय विशेषता होने के कारण ही दोनों पॉइंटर की गति दिशा को योग के बड़े-छोटे होने के आधार पर निर्धारित किया जा सकता है।

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(n) — दोनों पॉइंटर कुल मिलाकर अधिकतम n बार ही आगे-पीछे होते हैं |
| Space | O(1) — केवल पॉइंटर के लिए चर उपयोग होते हैं, किसी अतिरिक्त डेटा संरचना की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: क्रमबद्ध पूर्णांक सरणी nums और पूर्णांक target
// आउटपुट: योग target के बराबर होने वाले दो तत्वों की 1-indexed स्थिति को int[] में लौटाना
public int[] twoSum(int[] nums, int target) {
    // बाएँ पॉइंटर को सरणी की शुरुआत पर रखना। यह खोज सीमा का बायाँ छोर है और सरणी के न्यूनतम मान की ओर की जिम्मेदारी लेता है
    int left = 0;
    // दाएँ पॉइंटर को सरणी के अंत पर रखना। यह खोज सीमा का दायाँ छोर है और सरणी के अधिकतम मान की ओर की जिम्मेदारी लेता है
    int right = nums.length - 1;

    // दोनों पॉइंटर क्रॉस करने तक लूप चलाना
    while (left < right) {
        // वर्तमान दो तत्वों का योग गणना करना और प्रत्येक शाखा में पुन: उपयोग के लिए चर में संग्रहित करना
        int cursum = nums[left] + nums[right];

        if (cursum == target) {
            // योग लक्ष्य से मेल खाता है इसलिए जोड़ी मिल गई। समस्या 1-indexed माँगती है इसलिए प्रत्येक इंडेक्स में 1 जोड़कर लौटाना
            return new int[]{left + 1, right + 1};
        } else if (cursum > target) {
            // योग बहुत बड़ा है इसलिए दाएँ पॉइंटर को बाईं ओर ले जाना। दाएँ पॉइंटर द्वारा इंगित मान छोटा हो जाएगा और अगले पुनरावर्तन में योग घटेगा
            right--;
        } else {
            // योग बहुत छोटा है इसलिए बाएँ पॉइंटर को दाईं ओर ले जाना। बाएँ पॉइंटर द्वारा इंगित मान बड़ा हो जाएगा और अगले पुनरावर्तन में योग बढ़ेगा
            left++;
        }
    }
    // समस्या की बाधाओं के अनुसार हल अवश्य मौजूद होता है इसलिए यहाँ कभी नहीं पहुँचा जाएगा
    return new int[]{};
}
```
