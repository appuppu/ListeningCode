# Three Sum — योग शून्य होने वाले सभी ट्रिपलेट खोजना

## समस्या का सार

पूर्णांकों की एक सरणी `nums` दी गई है। `nums` में से ऐसे तीन तत्वों के सभी संयोजन (ट्रिपलेट) खोजने हैं जिनका योग `0` हो, और उन्हें `List<List<Integer>>` के रूप में लौटाना है। प्रत्येक ट्रिपलेट अलग-अलग इंडेक्स के तत्वों से बना होना चाहिए, और परिणाम में कोई डुप्लिकेट ट्रिपलेट शामिल नहीं होना चाहिए।

## मूल विचार

सरणी को सॉर्ट करने पर, एक तत्व को स्थिर रखकर शेष दो तत्वों को Two Pointers से कुशलतापूर्वक खोजा जा सकता है, और सॉर्ट किए गए क्रम का उपयोग करके डुप्लिकेट मानों को स्किप करने से डुप्लिकेट ट्रिपलेट को स्वाभाविक रूप से हटाया जा सकता है।

## विचार प्रक्रिया

1. **3 तत्वों की समस्या को 2 तत्वों की समस्या में बदलना**: तीन संख्याएँ `a + b + c = 0` में, एक तत्व `a = nums[i]` को स्थिर करने पर `b + c = -a` की दो-तत्व खोज समस्या बन जाती है। बाहरी for लूप में `a` को स्थिर करके, अंदर `b` और `c` को खोजने की संरचना बनाने पर, ज्ञात Two Sum की अवधारणा को लागू किया जा सकता है
2. **Two Pointers का उपयोग करने के लिए सॉर्ट करना**: दो तत्वों की खोज को कुशलतापूर्वक करने के लिए, सरणी को सॉर्ट करके बाएँ और दाएँ से पॉइंटर को सँकुचित करने वाली Two Pointers तकनीक प्रभावी है। योग बहुत छोटा होने पर बाएँ पॉइंटर को दाएँ, और बहुत बड़ा होने पर दाएँ पॉइंटर को बाएँ खिसकाने से सभी जोड़ों को कुशलतापूर्वक खोजा जा सकता है
3. **सॉर्ट के माध्यम से डुप्लिकेट ट्रिपलेट को हटाना**: सॉर्ट की गई सरणी में समान मान एक-दूसरे के बगल में होते हैं। बाहरी लूप में `nums[i]` का मान पिछले तत्व के समान होने पर उसे स्किप करके, और अंदरी लूप में भी जोड़ा मिलने के बाद `left` और `right` को समान मान जारी रहने तक स्किप करके, डुप्लिकेट ट्रिपलेट को परिणाम से बाहर रखा जा सकता है
4. **बाहरी लूप की सीमा तय करना**: तीन तत्वों की आवश्यकता होने के कारण, `i` को `0` से `nums.length - 3` तक चलाया जाता है। `left` को `i + 1` से और `right` को `nums.length - 1` से शुरू किया जाता है, और केवल `left < right` होने तक खोज जारी रखी जाती है
5. **योग के अनुसार पॉइंटर को खिसकाना**: `sum == 0` होने पर ट्रिपलेट को परिणाम में जोड़ा जाता है, डुप्लिकेट स्किप के बाद दोनों पॉइंटर को अंदर की ओर बढ़ाया जाता है। `sum < 0` होने पर योग बढ़ाने के लिए `left` को दाएँ, और `sum > 0` होने पर योग घटाने के लिए `right` को बाएँ खिसकाया जाता है
6. **अंतिम रूप से लौटाना**: सभी स्थिर तत्वों और पॉइंटर के संयोजनों की खोज पूरी होने पर, संचित `result` सूची को वैसे ही लौटाया जाता है

## पूर्वापेक्षित ज्ञान

### Two Pointers क्या है

सॉर्ट की गई सरणी के दोनों छोरों पर दो पॉइंटर (`left` और `right`) रखकर, शर्त के अनुसार किसी एक को खिसकाकर, सभी जोड़ों की खोज O(n) में करने की तकनीक है। योग लक्ष्य से छोटा होने पर `left` को दाएँ (मान बड़ा करने के लिए), और बड़ा होने पर `right` को बाएँ (मान छोटा करने के लिए) खिसकाया जाता है।

```java
int left = 0;
int right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) {
        // जोड़ा मिला
    } else if (sum < target) {
        left++;    // योग बढ़ाने के लिए बाएँ पॉइंटर को दाएँ खिसकाना
    } else {
        right--;   // योग घटाने के लिए दाएँ पॉइंटर को बाएँ खिसकाना
    }
}
```

### Arrays.sort() क्या है

सरणी को आरोही क्रम में सॉर्ट करने वाला Java का मानक मेथड है। सॉर्ट के बाद समान मान एक-दूसरे के बगल में आ जाते हैं, जिससे डुप्लिकेट का पता लगाना आसान हो जाता है।

```java
int[] nums = {4, -1, 2, -1, 0};
Arrays.sort(nums);    // nums {-4, -1, -1, 0, 2} बन जाता है (आरोही क्रम)
```

### Arrays.asList() क्या है

वेरिएबल-लेंथ आर्गुमेंट से निश्चित आकार की `List` बनाने वाला मेथड है। ट्रिपलेट को `List<Integer>` के रूप में परिणाम सूची में जोड़ने के लिए इसका उपयोग किया जाता है।

```java
List<Integer> triplet = Arrays.asList(-1, 0, 1);  // [-1, 0, 1] की सूची बनाना
```

## गणनात्मक जटिलता

| | मान |
|---|---|
| Time | O(n²) — बाहरी लूप O(n) है, अंदरी Two Pointers O(n) है, कुल O(n²) है |
| Space | O(1) — सॉर्ट को छोड़कर, केवल पॉइंटर चर का उपयोग होता है और अतिरिक्त स्थान नहीं लगता |

## कोड

```java
// इनपुट: पूर्णांक सरणी nums
// आउटपुट: योग 0 होने वाले सभी अद्वितीय ट्रिपलेट संग्रहित List<List<Integer>>
public List<List<Integer>> threeSum(int[] nums) {
    // खोजे गए सभी ट्रिपलेट को संचित करने वाली परिणाम सूची
    List<List<Integer>> result = new ArrayList<>();
    // सरणी को आरोही क्रम में सॉर्ट करना (Two Pointers की पूर्वशर्त + डुप्लिकेट स्किप के लिए)
    Arrays.sort(nums);

    // i को 0 से nums.length - 3 तक चलाना। nums[i] ट्रिपलेट का स्थिर तत्व बनता है
    for (int i = 0; i < nums.length - 2; i++) {
        // स्थिर तत्व का मान पिछले तत्व के समान होने पर, वही ट्रिपलेट दोबारा बनेगा इसलिए स्किप करना
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }
        // स्थिर तत्व के ठीक बाद और सरणी के अंत में बाएँ-दाएँ पॉइंटर रखकर, इस सीमा में जोड़ा खोजना
        int left = i + 1;
        int right = nums.length - 1;

        while (left < right) {
            // तीन तत्वों का योग गणना करना
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0) {
                // योग शून्य वाले ट्रिपलेट को परिणाम में जोड़ना
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // बाएँ पॉइंटर की ओर डुप्लिकेट मान स्किप करना (समान मान जारी रहने तक दाएँ बढ़ाना)
                while (left < right && nums[left] == nums[left + 1]) {
                    left++;
                }
                // दाएँ पॉइंटर की ओर डुप्लिकेट मान स्किप करना (समान मान जारी रहने तक बाएँ बढ़ाना)
                while (left < right && nums[right] == nums[right - 1]) {
                    right--;
                }
                // डुप्लिकेट स्किप के बाद, दोनों पॉइंटर को अंदर की ओर 1 बढ़ाकर अगले जोड़े की खोज में आगे बढ़ना
                left++;
                right--;
            } else if (sum < 0) {
                // योग ऋणात्मक है, इसलिए बाएँ पॉइंटर को दाएँ खिसकाकर योग बढ़ाना
                left++;
            } else {
                // योग धनात्मक है, इसलिए दाएँ पॉइंटर को बाएँ खिसकाकर योग घटाना
                right--;
            }
        }
    }

    // सभी स्थिर तत्वों के लिए खोज समाप्त। डुप्लिकेट-रहित सभी ट्रिपलेट संग्रहित हैं
    return result;
}
```
