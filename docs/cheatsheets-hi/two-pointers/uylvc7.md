# Maximizing Water Held Between Two Lines — दो ऊर्ध्वाधर रेखाओं के बीच बनने वाले कंटेनर में अधिकतम जल मात्रा ज्ञात करना

## समस्या का सार

एक गैर-ऋणात्मक पूर्णांकों की सरणी `height` दी गई है। प्रत्येक तत्व `height[i]` x-अक्ष पर स्थिति `i` पर खड़ी ऊर्ध्वाधर रेखा की ऊँचाई को दर्शाता है। इनमें से 2 रेखाएँ चुनकर, x-अक्ष के साथ मिलकर बनने वाले कंटेनर में संग्रहित की जा सकने वाली **अधिकतम जल मात्रा** लौटानी है। कंटेनर की जल मात्रा "2 रेखाओं के बीच की दूरी × दोनों में से छोटी रेखा की ऊँचाई" से निर्धारित होती है।

## मूल विचार

कंटेनर की चौड़ाई को अधिकतम (दोनों सिरों) से शुरू करके, छोटी वाली रेखा के पॉइंटर को अंदर की ओर खिसकाने से, ऊँचाई बढ़ने द्वारा क्षेत्रफल सुधार की संभावना बनाए रखते हुए, सभी जोड़ों को कुशलतापूर्वक खोजा जा सकता है। छोटी वाली रेखा को खिसकाने का कारण यह है कि चौड़ाई घटने पर, ऊँचाई न बढ़े तो क्षेत्रफल में सुधार नहीं हो सकता।

## विचार प्रक्रिया

1. **क्षेत्रफल के सूत्र को समझना**: 2 रेखाएँ `i` और `j` (i < j) द्वारा बनने वाले कंटेनर का क्षेत्रफल `(j - i) × min(height[i], height[j])` है। क्षेत्रफल को अधिकतम करने के लिए "चौड़ाई" और "ऊँचाई के न्यूनतम मान" के गुणनफल को अधिकतम करना आवश्यक है
2. **अधिकतम चौड़ाई की स्थिति से शुरू करना**: चौड़ाई को अधिकतम करने के लिए, बाएँ सिरे (इंडेक्स 0) और दाएँ सिरे (इंडेक्स n-1) की 2 रेखाएँ चुनें। इस स्थिति से खोज शुरू करने पर, चौड़ाई अधिकतम अवस्था से प्रारंभ होती है
3. **कौन सा पॉइंटर खिसकाना है यह तय करना**: चौड़ाई अंदर की ओर खिसकाने पर हमेशा 1 घटती है। क्षेत्रफल में सुधार के लिए ऊँचाई बढ़ाना ही एकमात्र उपाय है। कंटेनर की ऊँचाई दोनों में से छोटी रेखा से निर्धारित होती है, इसलिए छोटी वाली के पॉइंटर को अंदर खिसकाने से अधिक ऊँची रेखा मिलने की संभावना रहती है। इसके विपरीत, बड़ी वाली को खिसकाने पर भी छोटी वाली बाधा बनी रहती है, अतः क्षेत्रफल में सुधार नहीं होता
4. **प्रत्येक चरण में क्षेत्रफल दर्ज करना**: पॉइंटर खिसकाने पर हर बार नया क्षेत्रफल गणना करके, अब तक के अधिकतम मान से तुलना करके अपडेट करना है। इस प्रकार संपूर्ण खोज के समान परिणाम प्राप्त होता है
5. **समाप्ति शर्त निर्धारित करना**: बायाँ पॉइंटर और दायाँ पॉइंटर जब मिलते हैं, उस समय तक सभी संभावित जोड़ों की जाँच पूरी हो चुकी होती है, अतः खोज समाप्त होती है
6. **अंतिम रूप से लौटाया जाने वाला मान**: खोज के दौरान दर्ज किए गए क्षेत्रफल का अधिकतम मान `maxarea` लौटाना है

## पूर्व-आवश्यक ज्ञान

### Two Pointers (2 पॉइंटर) क्या है

सरणी के दोनों सिरों या अलग-अलग स्थानों पर 2 पॉइंटर (इंडेक्स) रखकर, शर्त के अनुसार एक या दोनों को खिसकाते हुए खोज करने की तकनीक है। सभी जोड़ों की O(n²) खोज को, शर्त का उपयोग करके O(n) में कम किया जा सकता है।

```java
int left = 0;                      // बाएँ पॉइंटर को सरणी के आरंभ में रखना
int right = height.length - 1;     // दाएँ पॉइंटर को सरणी के अंत में रखना
while (left < right) {             // 2 पॉइंटर मिलने तक लूप चलाना
    // left या right को खिसकाना
    left++;   // बाएँ पॉइंटर को दाईं ओर 1 स्थान आगे बढ़ाना
    right--;  // दाएँ पॉइंटर को बाईं ओर 1 स्थान पीछे करना
}
```

### Math.min / Math.max क्या है

`Math.min(a, b)` दो मानों में से छोटा मान लौटाता है, और `Math.max(a, b)` बड़ा मान लौटाता है। इनका उपयोग कंटेनर की ऊँचाई (छोटी रेखा) और क्षेत्रफल के अधिकतम मान को अपडेट करने में किया जाता है।

```java
Math.min(3, 7);          // दोनों में से छोटा मान लौटाता है → 3
Math.max(10, 25);        // दोनों में से बड़ा मान लौटाता है → 25
```

### कंटेनर के क्षेत्रफल की गणना

2 रेखाओं `left` और `right` द्वारा बनने वाले कंटेनर का क्षेत्रफल, चौड़ाई × ऊँचाई से प्राप्त होता है। ऊँचाई दोनों रेखाओं में से छोटी वाली से निर्धारित होती है।

```java
int width = right - left;                              // चौड़ाई = 2 रेखाओं के बीच की दूरी
int minHeight = Math.min(height[left], height[right]);  // ऊँचाई = छोटी रेखा की ऊँचाई
int area = width * minHeight;                           // क्षेत्रफल = चौड़ाई × ऊँचाई
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n) — बाएँ और दाएँ पॉइंटर केवल एक बार अंदर की ओर बढ़ते हैं, सरणी को एक बार स्कैन करते हैं |
| Space | O(1) — केवल पॉइंटर और अधिकतम मान रखने वाले चर का उपयोग होता है |

## कोड

```java
// इनपुट: गैर-ऋणात्मक पूर्णांकों की सरणी height (प्रत्येक तत्व ऊर्ध्वाधर रेखा की ऊँचाई है)
// आउटपुट: 2 रेखाओं और x-अक्ष द्वारा बनने वाले कंटेनर में संग्रहित अधिकतम जल मात्रा int के रूप में लौटाना
public int maxArea(int[] height) {
    // खोज के दौरान मिले क्षेत्रफल का अधिकतम मान दर्ज करने वाला चर। 0 से आरंभ करना
    int maxarea = 0;
    // बाएँ पॉइंटर को सरणी के आरंभ में रखना। अधिकतम चौड़ाई की स्थिति से खोज शुरू करना
    int left = 0;
    // दाएँ पॉइंटर को सरणी के अंत में रखना
    int right = height.length - 1;

    // 2 पॉइंटर मिलने तक लूप चलाना। मिलने के समय तक सभी संभावित जोड़ों की जाँच पूरी हो चुकी होती है
    while (left < right) {
        // चौड़ाई = 2 रेखाओं के बीच की दूरी
        int width = right - left;
        // ऊँचाई = छोटी रेखा की ऊँचाई। कंटेनर की जल मात्रा छोटी रेखा से निर्धारित होती है
        int minHeight = Math.min(height[left], height[right]);
        // क्षेत्रफल = चौड़ाई × ऊँचाई
        int area = width * minHeight;

        // अब तक के अधिकतम मान से तुलना करके अपडेट करना
        maxarea = Math.max(area, maxarea);

        // छोटी वाली रेखा के पॉइंटर को अंदर खिसकाना। चौड़ाई घटने पर, ऊँचाई न बढ़े तो क्षेत्रफल में सुधार नहीं होता
        // बड़ी वाली को खिसकाने पर भी छोटी वाली बाधा बनी रहती है, अतः क्षेत्रफल में सुधार नहीं होता
        if (height[left] <= height[right]) {
            // बाईं रेखा छोटी है (या बराबर है), इसलिए बाएँ पॉइंटर को दाईं ओर 1 स्थान आगे बढ़ाकर ऊँचाई सुधार का प्रयास करना
            left++;
        } else {
            // दाईं रेखा छोटी है, इसलिए दाएँ पॉइंटर को बाईं ओर 1 स्थान पीछे करके ऊँचाई सुधार का प्रयास करना
            right--;
        }
    }
    // खोज के दौरान दर्ज किए गए क्षेत्रफल का अधिकतम मान लौटाना
    return maxarea;
}
```
