# Calculating Trapped Rainwater Between Bars — छड़ों के बीच जमा होने वाले वर्षा जल की मात्रा की गणना करना

## समस्या का सार

गैर-ऋणात्मक पूर्णांकों की एक सरणी `height` दी गई है। प्रत्येक तत्व चौड़ाई 1 वाली छड़ की ऊँचाई को दर्शाने वाला एक ऊँचाई-नीचाई मानचित्र है। वर्षा के बाद छड़ों के बीच जमा होने वाले **पानी की कुल मात्रा** की गणना करके लौटानी है।

## मूल विचार

किसी स्थान पर जमा होने वाले पानी की मात्रा "बाईं ओर की अधिकतम ऊँचाई और दाईं ओर की अधिकतम ऊँचाई में से छोटी वाली" में से "उस स्थान की छड़ की ऊँचाई" घटाने से निर्धारित होती है। बाएँ और दाएँ से पॉइंटर को अंदर की ओर चलाते हुए, प्रत्येक ओर की अधिकतम ऊँचाई को अपडेट करते रहने पर, अतिरिक्त सरणी के बिना प्रत्येक स्थान पर पानी की मात्रा की गणना की जा सकती है।

## विचार प्रक्रिया

1. **प्रत्येक स्थान पर पानी की मात्रा बाएँ-दाएँ की अधिकतम ऊँचाई से निर्धारित होती है**: किसी स्थान `i` पर जमा होने वाले पानी की मात्रा `min(बाईं ओर की अधिकतम ऊँचाई, दाईं ओर की अधिकतम ऊँचाई) - height[i]` है। पानी बाएँ-दाएँ की दीवारों में से नीची वाली की ऊँचाई तक ही जमा हो सकता है
2. **बाएँ-दाएँ की अधिकतम ऊँचाई को कुशलतापूर्वक ज्ञात करना है**: प्रत्येक स्थान पर बाएँ-दाएँ की अधिकतम ऊँचाई को हर बार स्कैन करने पर O(n²) लगता है। दो सरणियाँ तैयार करके पूर्व-गणना करने पर O(n) हो जाता है, लेकिन Space O(n) आवश्यक होता है। Space O(1) में प्राप्त करने की विधि पर विचार करते हैं
3. **बाएँ और दाएँ से पॉइंटर को अंदर की ओर चलाना**: बाएँ छोर पर पॉइंटर `left`, दाएँ छोर पर पॉइंटर `right` रखकर, अंदर की ओर चलाते हैं। प्रत्येक पॉइंटर की ओर अब तक देखी गई अधिकतम ऊँचाई को `maxLeftHeight` और `maxRightHeight` चरों में ट्रैक करते हैं
4. **छोटी ओर के पॉइंटर को चलाना**: `height[left] <= height[right]` होने पर, बाईं ओर की अधिकतम ऊँचाई दाईं ओर की अधिकतम ऊँचाई से कम या बराबर होने की गारंटी मिलती है। क्योंकि दाईं ओर कम से कम `height[right]` या उससे अधिक ऊँचाई की दीवार मौजूद है। इसलिए, बाएँ पॉइंटर की स्थिति पर केवल `maxLeftHeight` से ही पानी की मात्रा निश्चित की जा सकती है
5. **पॉइंटर चलाने के बाद पानी की मात्रा जोड़ना**: पॉइंटर को एक आगे बढ़ाकर, उस नई स्थिति पर अधिकतम ऊँचाई को अपडेट करके, `maxLeftHeight - height[left]` (या `maxRightHeight - height[right]`) को पानी की मात्रा में जोड़ते हैं। अधिकतम ऊँचाई सदैव वर्तमान छड़ की ऊँचाई से अधिक या बराबर होती है, इसलिए यह अंतर हमेशा 0 या उससे अधिक होता है
6. **दोनों पॉइंटर मिलने पर समाप्ति**: `left < right` तक लूप जारी रखते हैं और सभी स्थानों की पानी की मात्रा का योग `totalwater` लौटाते हैं

## पूर्वापेक्षित ज्ञान

### Two Pointers (2 पॉइंटर) क्या है

सरणी के दोनों छोरों या भिन्न स्थानों पर 2 पॉइंटर रखकर, शर्त के अनुसार किसी एक को चलाते हुए स्कैन करने की तकनीक है। संपूर्ण सरणी को एक बार के स्कैन में संसाधित किया जा सकता है, और यह क्रमबद्ध सरणी या दोनों छोरों से खोज के लिए प्रभावी है।

```java
int left = 0;                    // बाएँ छोर का पॉइंटर
int right = height.length - 1;   // दाएँ छोर का पॉइंटर
while (left < right) {           // 2 पॉइंटर मिलने तक लूप चलाना
    // शर्त के अनुसार left++ या right-- से पॉइंटर को अंदर की ओर चलाना
}
```

### Math.max क्या है

दो मानों में से बड़ा वाला लौटाने वाली Java की स्थैतिक विधि है। यहाँ, पॉइंटर आगे बढ़ने पर अब तक की अधिकतम ऊँचाई को अपडेट करने के लिए इसका उपयोग किया जाता है।

```java
int maxHeight = 3;
maxHeight = Math.max(maxHeight, 5);  // maxHeight 5 में अपडेट होता है
maxHeight = Math.max(maxHeight, 2);  // maxHeight 5 ही रहता है (2 < 5 होने के कारण)
```

### पानी जमा होने की शर्त

किसी स्थान पर पानी जमा होने के लिए, उस स्थान के बाएँ और दाएँ दोनों ओर वर्तमान छड़ से ऊँची दीवार होनी आवश्यक है। जमा होने वाले पानी की मात्रा "बाएँ-दाएँ की दीवारों में से नीची वाली की ऊँचाई" में से "वर्तमान छड़ की ऊँचाई" घटाने पर प्राप्त होती है।

```
// height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]
// स्थान 2 (ऊँचाई 0): बाएँ का अधिकतम=1, दाएँ का अधिकतम=3 → min(1,3) - 0 = 1 पानी जमा होता है
// स्थान 5 (ऊँचाई 0): बाएँ का अधिकतम=2, दाएँ का अधिकतम=3 → min(2,3) - 0 = 2 पानी जमा होता है
```

## जटिलता

| | मान |
|---|---|
| Time | O(n) — बाएँ-दाएँ के पॉइंटर कुल मिलाकर n बार चलकर सरणी को एक बार स्कैन करते हैं |
| Space | O(1) — केवल पॉइंटर और अधिकतम ऊँचाई के चरों का उपयोग होता है, अतिरिक्त सरणी की आवश्यकता नहीं है |

## कोड

```java
// इनपुट: गैर-ऋणात्मक पूर्णांकों की सरणी height (प्रत्येक तत्व छड़ की ऊँचाई है)
// आउटपुट: छड़ों के बीच जमा होने वाले पानी की कुल मात्रा int के रूप में लौटाना
public int trap(int[] height) {
    // जमा होने वाले पानी की कुल मात्रा को रखने वाले चर को 0 से आरंभ करना
    int totalwater = 0;

    // बाएँ पॉइंटर को सरणी के आरंभ में, दाएँ पॉइंटर को सरणी के अंत में सेट करना
    int left = 0;
    int right = height.length - 1;

    // बाएँ-दाएँ प्रत्येक ओर की अब तक की अधिकतम ऊँचाई को आरंभ करना
    // दोनों छोरों की छड़ों पर स्वयं पानी जमा नहीं होता, इसलिए इन्हें प्रारंभिक मान के रूप में उपयोग करना
    int maxLeftHeight = height[left];
    int maxRightHeight = height[right];

    // 2 पॉइंटर मिलने तक लूप चलाना
    while (left < right) {
        // height[left] <= height[right] होने पर, दाईं ओर कम से कम height[right] की दीवार मौजूद है
        // इसलिए केवल बाईं ओर की अधिकतम ऊँचाई से ही पानी की मात्रा निश्चित की जा सकती है
        if (height[left] <= height[right]) {
            // पॉइंटर को एक दाएँ आगे बढ़ाकर पानी की मात्रा की गणना करना
            left++;
            // अब तक की बाईं ओर की अधिकतम ऊँचाई को अपडेट करना
            maxLeftHeight = Math.max(maxLeftHeight, height[left]);
            // maxLeftHeight सदैव height[left] से अधिक या बराबर होता है, इसलिए जोड़ा जाने वाला मान हमेशा 0 या उससे अधिक होता है
            totalwater += maxLeftHeight - height[left];
        } else {
            // height[left] > height[right] होने पर, बाईं ओर कम से कम height[left] की दीवार मौजूद है
            // इसलिए केवल दाईं ओर की अधिकतम ऊँचाई से ही पानी की मात्रा निश्चित की जा सकती है
            right--;
            // अब तक की दाईं ओर की अधिकतम ऊँचाई को अपडेट करना
            maxRightHeight = Math.max(maxRightHeight, height[right]);
            // maxRightHeight सदैव height[right] से अधिक या बराबर होता है, इसलिए जोड़ा जाने वाला मान हमेशा 0 या उससे अधिक होता है
            totalwater += maxRightHeight - height[right];
        }
    }
    // लूप समाप्त होने पर, सभी स्थानों की पानी की मात्रा का योग totalwater लौटाना
    return totalwater;
}
```
