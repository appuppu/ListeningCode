# Checking if a String is a Palindrome — जाँचना कि कोई स्ट्रिंग पैलिंड्रोम है या नहीं

## समस्या का सार

एक स्ट्रिंग `s` दी गई है। केवल अंग्रेज़ी अक्षरों और अंकों को ध्यान में रखते हुए, तथा बड़े और छोटे अक्षरों के अंतर को अनदेखा करते हुए, यह निर्धारित करना है कि वह स्ट्रिंग पैलिंड्रोम (आगे से पढ़ें या पीछे से पढ़ें, दोनों समान) है या नहीं। यदि पैलिंड्रोम है तो `true` लौटाना है, अन्यथा `false` लौटाना है।

## मूल विचार

स्ट्रिंग के दोनों सिरों से दो पॉइंटर अंदर की ओर बढ़ाएँ, अंग्रेज़ी अक्षरों और अंकों के अलावा अन्य वर्णों को छोड़ते हुए एक-एक अक्षर की तुलना करें, तो बिना कोई अतिरिक्त स्ट्रिंग बनाए O(1) स्थान में पैलिंड्रोम की जाँच की जा सकती है।

## विचार प्रक्रिया

1. **पैलिंड्रोम की परिभाषा को समझना**: पैलिंड्रोम वह स्ट्रिंग है जो आगे से पढ़ने पर और पीछे से पढ़ने पर समान हो। अर्थात, शुरू और अंत के अक्षर मेल खाएँ, और उनके अंदर के अक्षर भी उसी प्रकार मेल खाएँ, तो वह स्ट्रिंग पैलिंड्रोम है
2. **दोनों सिरों से तुलना करने पर एक ही बार में जाँच पूरी हो जाती है**: शुरू में पॉइंटर `left` और अंत में पॉइंटर `right` रखकर, दोनों के मिलने तक अंदर की ओर बढ़ाते हुए तुलना करें, तो सभी अक्षरों को केवल एक बार देखकर जाँच पूरी हो जाती है
3. **अंग्रेज़ी अक्षरों और अंकों के अलावा अन्य वर्णों को छोड़ना आवश्यक है**: समस्या में केवल अंग्रेज़ी अक्षरों और अंकों को ध्यान में रखना है, इसलिए यदि कोई पॉइंटर ऐसे वर्ण पर हो जो अंग्रेज़ी अक्षर या अंक नहीं है, तो उसे छोड़कर आगे बढ़ना है। `Character.isLetterOrDigit` से यह जाँचा जा सकता है कि वर्ण अंग्रेज़ी अक्षर या अंक है या नहीं
4. **तुलना से पहले बड़े और छोटे अक्षरों को एक समान करना**: समस्या में बड़े-छोटे अक्षरों में भेद नहीं करना है, इसलिए तुलना से पहले `Character.toLowerCase` से दोनों अक्षरों को छोटे अक्षर में बदलकर मिलान की जाँच करनी है
5. **असमानता मिलते ही तुरंत `false` लौटाना**: यदि एक भी स्थान पर अक्षर भिन्न हों तो वह स्ट्रिंग पैलिंड्रोम नहीं है, इसलिए शीघ्र लौटाया जा सकता है
6. **यदि पॉइंटर एक-दूसरे को पार करने तक कोई असमानता न मिले तो वह स्ट्रिंग पैलिंड्रोम है**: यदि लूप सामान्य रूप से समाप्त हो जाए, तो इसका अर्थ है कि सभी संगत अक्षर मेल खाते हैं, इसलिए `true` लौटाना है

## पूर्व ज्ञान

### Two Pointers (2 पॉइंटर विधि) क्या है

यह एक ऐसी तकनीक है जिसमें ऐरे या स्ट्रिंग के दोनों सिरों पर पॉइंटर रखे जाते हैं और शर्त के अनुसार उन्हें अंदर की ओर बढ़ाया जाता है। सममिति का उपयोग करने वाली समस्याओं (पैलिंड्रोम जाँच, जोड़ी खोज आदि) में यह प्रभावी है। एक ही बार की स्कैनिंग में समस्या हल हो जाती है, इसलिए समय O(n) और स्थान O(1) प्राप्त होता है।

```java
int left = 0;                    // शुरू की ओर इंगित करने वाला पॉइंटर
int right = s.length() - 1;     // अंत की ओर इंगित करने वाला पॉइंटर
// left और right के एक-दूसरे को पार करने तक लूप जारी रखना
while (left < right) {
    // तुलना या प्रसंस्करण करना
    left++;    // बाएँ पॉइंटर को दाईं ओर बढ़ाना
    right--;   // दाएँ पॉइंटर को बाईं ओर बढ़ाना
}
```

### Character.isLetterOrDigit क्या है

यह एक मेथड है जो जाँचता है कि कोई वर्ण अंग्रेज़ी अक्षर (a-z, A-Z) है या अंक (0-9) है। जब रिक्त स्थान या चिह्न जैसे गैर-अंग्रेज़ी-अंकीय वर्णों को बाहर करना हो, तब इसका उपयोग किया जाता है।

```java
Character.isLetterOrDigit('A');   // true (अंग्रेज़ी अक्षर)
Character.isLetterOrDigit('3');   // true (अंक)
Character.isLetterOrDigit(' ');   // false (रिक्त स्थान)
Character.isLetterOrDigit(',');   // false (चिह्न)
```

### Character.toLowerCase क्या है

यह एक मेथड है जो अंग्रेज़ी अक्षर को छोटे अक्षर में बदलता है। जब बड़े और छोटे अक्षरों में भेद किए बिना तुलना करनी हो, तब इसका उपयोग किया जाता है। यदि वर्ण पहले से छोटा अक्षर या अंक हो, तो वह वैसा ही लौटाया जाता है।

```java
Character.toLowerCase('A');   // 'a'
Character.toLowerCase('a');   // 'a' (कोई परिवर्तन नहीं)
Character.toLowerCase('3');   // '3' (अंक वैसा ही रहता है)
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n) — प्रत्येक पॉइंटर स्ट्रिंग को अधिकतम एक बार स्कैन करता है |
| Space | O(1) — केवल दो पॉइंटर का उपयोग होता है, कोई अतिरिक्त स्ट्रिंग या डेटा संरचना नहीं बनती |

## कोड

```java
// इनपुट: स्ट्रिंग s
// आउटपुट: यदि s पैलिंड्रोम है तो true, अन्यथा false लौटाना
public boolean isPalindrome(String s) {
    // शुरू और अंत में पॉइंटर रखना। ये दोनों स्ट्रिंग के दोनों सिरों से अंदर की ओर बढ़ेंगे
    int left = 0;
    int right = s.length() - 1;

    // दोनों पॉइंटर एक-दूसरे को पार करने तक दोहराना। पार होने का अर्थ है कि सभी तुलनाएँ पूरी हो गई हैं
    while (left < right) {
        // यदि left अंग्रेज़ी अक्षर या अंक नहीं है तो उसे दाईं ओर छोड़ना
        // ध्यान दें: छोड़ते समय भी left < right की शर्त बनाए रखना, ताकि पॉइंटर एक-दूसरे को पार न करें
        while (left < right && !Character.isLetterOrDigit(s.charAt(left))) {
            left++;
        }
        // यदि right अंग्रेज़ी अक्षर या अंक नहीं है तो उसे बाईं ओर छोड़ना। उसी प्रकार left < right की शर्त बनाए रखना
        while (left < right && !Character.isLetterOrDigit(s.charAt(right))) {
            right--;
        }
        // दोनों अक्षरों को छोटे अक्षर में बदलकर तुलना करना, जिससे बड़े-छोटे अक्षरों का अंतर अनदेखा हो
        // यदि असमानता हो तो वह स्ट्रिंग पैलिंड्रोम नहीं है। एक भी स्थान पर अंतर होने पर पैलिंड्रोम की शर्त पूरी नहीं होती, इसलिए तुरंत लौटाना
        if (Character.toLowerCase(s.charAt(left)) != Character.toLowerCase(s.charAt(right))) {
            return false;
        }
        // दोनों अक्षर मेल खाते हैं, इसलिए दोनों पॉइंटर को अंदर की ओर बढ़ाकर अगली अक्षर जोड़ी की तुलना करना
        left++;
        right--;
    }
    // लूप सामान्य रूप से समाप्त हुआ (सभी संगत अक्षर जोड़ियाँ मेल खाती हैं), इसलिए यह स्ट्रिंग पैलिंड्रोम है
    return true;
}
```
