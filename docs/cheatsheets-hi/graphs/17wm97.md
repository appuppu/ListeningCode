# Checking if a Graph Forms a Valid Tree — जाँचना कि ग्राफ एक वैध ट्री बनाता है या नहीं

## समस्या का सार

`0` से `n-1` तक लेबल किए गए `n` नोड्स और अनिर्देशित (undirected) एज की एक सूची `edges` दी गई है। यह निर्धारित करना है कि यह ग्राफ **एक वैध ट्री (valid tree)** बनाता है या नहीं, और परिणाम `boolean` के रूप में लौटाना है। वैध ट्री वह ग्राफ है जिसमें सभी नोड्स जुड़े हुए (connected) हों और कोई भी साइकिल (cycle) मौजूद न हो।

## मूल विचार

ट्री में नोड्स की संख्या `n` के लिए एज की संख्या ठीक `n-1` होती है, और कोई साइकिल नहीं होता। पहले यह जाँच करें कि एज की संख्या `n-1` है, फिर Union-Find का उपयोग करके प्रत्येक एज को जोड़ते हुए साइकिल की उपस्थिति का पता लगाएँ — इससे यह निर्धारित किया जा सकता है कि ग्राफ ट्री है या नहीं।

## विचार प्रक्रिया

1. **ट्री की आवश्यक शर्त का उपयोग करना**: एक वैध ट्री में हमेशा `n-1` एज होती हैं। यदि एज की संख्या `n-1` नहीं है, तो उसी समय यह निर्धारित किया जा सकता है कि यह ट्री नहीं है। इस पूर्व-जाँच से, एज बहुत अधिक होने की स्थिति (साइकिल निश्चित रूप से मौजूद है) और एज बहुत कम होने की स्थिति (ग्राफ connected नहीं है) दोनों को बाहर किया जा सकता है
2. **साइकिल का पता लगाने की विधि पर विचार करना**: एज की संख्या `n-1` होने पर भी साइकिल मौजूद हो सकता है (उस स्थिति में ग्राफ non-connected होगा)। प्रत्येक एज जोड़ते समय, यदि दोनों सिरों के नोड्स पहले से एक ही connected component में हैं, तो साइकिल का पता लगाया जा सकता है
3. **Union-Find से connected components को प्रबंधित करना**: Union-Find (disjoint set data structure) का उपयोग करके, दो नोड्स एक ही connected component में हैं या नहीं इसकी जाँच (find) और दो connected components का विलय (union) लगभग O(1) में किया जा सकता है। प्रत्येक नोड के parent को स्वयं से initialize करें और प्रत्येक एज के लिए union करें
4. **साइकिल का पता लगाने की शर्त निर्धारित करना**: union ऑपरेशन के दौरान, यदि दो नोड्स का root (मूल) समान है, तो वे पहले से connected हैं। वहाँ एक और एज जोड़ने से साइकिल बन जाएगा, इसलिए `false` लौटाएँ
5. **सभी एज संसाधित करने के बाद परिणाम लौटाना**: सभी एज संसाधित करने के बाद भी यदि कोई साइकिल नहीं पाया गया, तो एज की संख्या `n-1` होने (चरण 1 में पहले से सत्यापित) के साथ मिलाकर, ग्राफ एक वैध ट्री है और `true` लौटाएँ

## पूर्वापेक्षित ज्ञान

### Union-Find (disjoint set data structure) क्या है

यह एक डेटा संरचना है जो कई तत्वों को समूहों (sets) में विभाजित करके प्रबंधित करती है। यह दो ऑपरेशन प्रदान करती है। `find` किसी तत्व के समूह का प्रतिनिधि (root) लौटाता है। `union` दो तत्वों के समूहों को एक में मिला देता है। पथ संपीड़न (path compression) और रैंक द्वारा अनुकूलन करने पर, प्रत्येक ऑपरेशन लगभग O(1) में निष्पादित होता है।

```java
int[] parent = {0, 1, 2, 3, 4};  // प्रारंभिक स्थिति: प्रत्येक नोड का parent स्वयं है
int[] rank = new int[5];          // प्रत्येक नोड के रैंक (ट्री की ऊँचाई की ऊपरी सीमा) को 0 से initialize करें

// find: नोड x का root लौटाता है (पथ संपीड़न सहित)
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // पथ संपीड़न: parent को सीधे root से जोड़ देता है
    return parent[x];
}
```

### पथ संपीड़न (Path Compression) क्या है

`find` को कॉल करने पर हर बार, खोज पथ पर सभी नोड्स के parent को सीधे root से जोड़ देने वाली अनुकूलन तकनीक। इससे अगली बार `find` कॉल करना O(1) के करीब हो जाता है। `parent[x] = find(parent[x])` की पुनरावर्ती (recursive) assignment से इसे लागू किया जाता है।

### रैंक द्वारा विलय (Union by Rank) क्या है

दो ट्री को मिलाते समय, कम रैंक (ट्री की ऊँचाई की ऊपरी सीमा) वाले को अधिक रैंक वाले के नीचे जोड़ने की तकनीक। यह ट्री की ऊँचाई में वृद्धि को रोकती है और `find` की खोज दूरी को कम रखती है। केवल जब रैंक समान हो, तभी विलय के बाद रैंक को 1 बढ़ाया जाता है।

```java
// union: नोड a और नोड b के समूहों को मिलाता है। यदि वे पहले से एक ही समूह में हैं तो false लौटाता है
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // प्रत्येक नोड का root प्राप्त करें
    if (ra == rb) return false;       // समान root → पहले से एक ही समूह → साइकिल
    if (rank[ra] < rank[rb])
        parent[ra] = rb;             // कम रैंक वाले को अधिक रैंक वाले के नीचे जोड़ें
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;             // रैंक समान होने पर rb को ra के नीचे जोड़ें
        rank[ra]++;                   // रैंक को 1 बढ़ाएँ
    }
    return true;
}
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(n × α(n)) — प्रत्येक एज के लिए find और union निष्पादित किया जाता है। α(n) Ackermann फ़ंक्शन का प्रतिलोम (inverse) है और व्यावहारिक रूप से इसे स्थिरांक माना जा सकता है |
| Space | O(n) — parent सरणी और rank सरणी में प्रत्येक n तत्वों को संग्रहीत किया जाता है |

## कोड

```java
// इनपुट: पूर्णांक n (नोड्स की संख्या) और द्वि-आयामी पूर्णांक सरणी edges (प्रत्येक तत्व [u, v] अनिर्देशित एज है)
// आउटपुट: यदि ग्राफ एक वैध ट्री है तो true, अन्यथा false लौटाएँ

// parent सरणी: प्रत्येक नोड के parent को प्रबंधित करती है
int[] parent, rank;

// नोड x जिस connected component में है उसका root लौटाता है (पथ संपीड़न सहित)
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // पथ संपीड़न: parent को सीधे root से जोड़ देता है
    return parent[x];
}

// नोड a और नोड b के connected components को मिलाता है। यदि साइकिल बनता है तो false लौटाता है
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // दोनों सिरों के नोड्स का root प्राप्त करें
    if (ra == rb) return false;       // समान root होने पर साइकिल बनेगा → यह एज जोड़ने से साइकिल बनता है
    // कम रैंक वाले को अधिक रैंक वाले के नीचे जोड़कर ट्री की ऊँचाई को नियंत्रित रखें
    if (rank[ra] < rank[rb])
        parent[ra] = rb;
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;
        rank[ra]++;
    }
    return true;
}

public boolean validTree(int n, int[][] edges) {
    // ट्री में एज की संख्या नोड्स की संख्या - 1 होनी चाहिए (अधिक होने पर साइकिल निश्चित, कम होने पर non-connected)
    if (edges.length != n - 1)
        return false;

    // प्रत्येक नोड के parent को स्वयं से initialize करें (प्रत्येक नोड एक स्वतंत्र connected component बनाता है)
    parent = new int[n];
    rank = new int[n];
    for (int i = 0; i < n; i++)
        parent[i] = i;

    // प्रत्येक एज को संसाधित करें; यदि दोनों सिरे पहले से एक ही connected component में हैं तो साइकिल बनेगा इसलिए false लौटाएँ
    for (int[] e : edges)
        if (!union(e[0], e[1]))
            return false;

    // सभी एज संसाधित करने के बाद भी कोई साइकिल नहीं मिला और एज की संख्या n-1 है, इसलिए यह एक वैध ट्री है
    return true;
}
```
