# Finding the Redundant Edge in a Graph — पेड़ में एक अतिरिक्त किनारा जोड़े गए ग्राफ से अनावश्यक किनारे को खोजना

## समस्या का सार

n नोड और n-1 किनारों से बना एक पेड़ दिया गया है जिसमें एक किनारा जोड़ने से ठीक एक चक्र (cycle) बन गया है। उस अतिरिक्त अनावश्यक किनारे को खोजकर लौटाना है। उस किनारे को हटाने पर ग्राफ फिर से एक वैध पेड़ बन जाएगा।

## मूल विचार

जब किनारों को एक-एक करके संसाधित किया जाता है, तो यदि कोई किनारा "पहले से एक ही संयुक्त घटक में मौजूद दो नोड" को जोड़ता है, तो वही किनारा चक्र बनाने वाला अनावश्यक किनारा है। इस निर्णय के लिए Union-Find सबसे उपयुक्त है।

## विचार प्रक्रिया

1. **पेड़ के गुण का उपयोग करना**: पेड़ एक ऐसी संरचना है जो n नोड को n-1 किनारों से जोड़ती है और इसमें कोई चक्र नहीं होता। इसमें एक किनारा जोड़ने पर ठीक एक चक्र बनता है। अर्थात, किनारों को क्रम से जोड़ते समय "चक्र बनाने वाले किनारे" का पता लगाना है
2. **चक्र की पहचान की शर्त पर विचार करना**: जब किनारा (u, v) जोड़ा जाता है, यदि u और v पहले से एक ही संयुक्त घटक में हैं, तो वह किनारा चक्र बनाता है। इसके विपरीत, यदि u और v अलग-अलग संयुक्त घटकों में हैं, तो वह किनारा केवल दो घटकों को मिलाता है और कोई चक्र नहीं बनता
3. **संयुक्त घटकों के प्रबंधन के लिए Union-Find उपयुक्त है**: "दो नोड एक ही संयुक्त घटक में हैं या नहीं" का निर्णय और "दो संयुक्त घटकों को मिलाना" — इन दोनों कार्यों को तेज़ी से करने वाली डेटा संरचना Union-Find है। find ऑपरेशन से मूल (root) की तुलना करके समान घटक की पहचान की जा सकती है, और union ऑपरेशन से घटकों को मिलाया जा सकता है
4. **Union-Find की दक्षता बढ़ाना**: पथ संपीड़न (path compression) द्वारा, प्रत्येक find ऑपरेशन के समय नोड को सीधे मूल से जोड़ दिया जाता है। रैंक (rank) आधारित विलय द्वारा, पेड़ की ऊँचाई को नियंत्रित रखा जाता है। इन दो अनुकूलनों से प्रत्येक ऑपरेशन की समय जटिलता α(n) (व्युत्क्रम Ackermann फलन, व्यावहारिक रूप से स्थिरांक) हो जाती है
5. **किनारों को क्रम से संसाधित करना**: दिए गए किनारों की सरणी को आरंभ से क्रम में संसाधित किया जाता है और प्रत्येक किनारे पर union ऑपरेशन का प्रयास किया जाता है। जिस किनारे पर union विफल हुआ (= पहले से एक ही घटक में थे), वही अनावश्यक किनारा है, और उसे लौटाया जाता है
6. **अंतिम परिणाम**: union ऑपरेशन विफल होने वाले किनारे को `int[]` के रूप में लौटाया जाता है। समस्या की बाधाओं के अनुसार, एक अनावश्यक किनारा अवश्य मौजूद होता है, इसलिए उत्तर न मिलने की स्थिति नहीं आती

## पूर्वापेक्षित ज्ञान

### Union-Find (विसंयुक्त समुच्चय डेटा संरचना) क्या है

अनेक तत्वों को समूहों (संयुक्त घटकों) में विभाजित करके, "दो तत्व एक ही समूह में हैं या नहीं" का निर्णय और "दो समूहों को मिलाना" — इन कार्यों को तेज़ी से करने वाली डेटा संरचना। `parent` सरणी द्वारा समूह की पेड़ संरचना को दर्शाया जाता है, और प्रत्येक तत्व का मूल (प्रतिनिधि) समान हो तो वे एक ही समूह में माने जाते हैं।

```java
int[] parent = new int[n + 1];  // parent[i] नोड i के पैरेंट को संग्रहीत करता है
int[] rank = new int[n + 1];    // rank[i] नोड i को मूल मानने वाले पेड़ की ऊँचाई की ऊपरी सीमा है
for (int i = 1; i <= n; i++)
    parent[i] = i;              // प्रारंभिक स्थिति में प्रत्येक नोड स्वयं अपना पैरेंट होता है (सभी स्वतंत्र समूह हैं)
```

### find ऑपरेशन (पथ संपीड़न सहित)

नोड x जिस समूह में है उसका मूल (प्रतिनिधि) लौटाता है। पुनरावर्ती रूप से पैरेंट का अनुसरण करता है और पथ पर सभी नोड को सीधे मूल से जोड़ देता है (पथ संपीड़न)। इससे अगली बार find तेज़ हो जाता है।

```java
int find(int[] parent, int x) {
    if (parent[x] != x)                    // यदि x मूल नहीं है
        parent[x] = find(parent, parent[x]); // पैरेंट को पुनरावर्ती रूप से खोजकर सीधे मूल से जोड़ना
    return parent[x];                       // x का मूल लौटाना
}
```

### union ऑपरेशन (रैंक आधारित विलय)

दो नोड के समूहों को मिलाता है। जिसका रैंक (पेड़ की ऊँचाई की ऊपरी सीमा) छोटा है उसे बड़े वाले के नीचे जोड़ता है, जिससे पेड़ की ऊँचाई का बढ़ना नियंत्रित रहता है। यदि दो नोड पहले से एक ही समूह में हैं तो विलय नहीं करता और `false` लौटाता है।

```java
boolean union(int[] parent, int[] rank, int x, int y) {
    int rx = find(parent, x);  // x का मूल प्राप्त करना
    int ry = find(parent, y);  // y का मूल प्राप्त करना
    if (rx == ry) return false; // एक ही समूह में हैं तो विलय अनावश्यक → false लौटाना
    // छोटे रैंक वाले को बड़े रैंक वाले के नीचे जोड़ना
    if (rank[rx] < rank[ry]) parent[rx] = ry;
    else if (rank[rx] > rank[ry]) parent[ry] = rx;
    else { parent[ry] = rx; rank[rx]++; }  // रैंक समान हो तो एक को दूसरे के नीचे जोड़ना और रैंक 1 बढ़ाना
    return true;  // विलय सफल → true लौटाना
}
```

### व्युत्क्रम Ackermann फलन α(n) क्या है

Union-Find की प्रत्येक ऑपरेशन की समय जटिलता को व्यक्त करने वाला फलन। α(n) बहुत धीरे बढ़ता है और व्यावहारिक इनपुट आकार (n < 2^65536) में α(n) ≤ 4 रहता है, इसलिए इसे व्यावहारिक रूप से स्थिरांक माना जा सकता है।

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n × α(n)) ≈ O(n) — n किनारों में से प्रत्येक पर find और union एक-एक बार किया जाता है। α(n) व्यावहारिक रूप से स्थिरांक है इसलिए O(n) माना जा सकता है |
| Space | O(n) — parent सरणी और rank सरणी में क्रमशः n+1 तत्व संग्रहीत किए जाते हैं |

## कोड

```java
// इनपुट: किनारों की सरणी edges (प्रत्येक तत्व int[]{u, v} है, जो नोड u और नोड v को जोड़ने वाले किनारे को दर्शाता है)
// आउटपुट: चक्र बनाने वाले अनावश्यक किनारे को int[] के रूप में लौटाना

// नोड x जिस समूह में है उसका मूल लौटाना (पथ संपीड़न सहित)
int find(int[] parent, int x) {
    if (parent[x] != x)
        // पैरेंट को पुनरावर्ती रूप से खोजकर सीधे मूल से जोड़ना (पथ संपीड़न)
        parent[x] = find(parent,
            parent[x]);
    return parent[x];
}

// दो नोड के समूहों को मिलाना। पहले से एक ही समूह में हों तो false लौटाना
boolean union(int[] parent,
        int[] rank, int x, int y) {
    int rx = find(parent, x); // x का मूल प्राप्त करना
    int ry = find(parent, y); // y का मूल प्राप्त करना
    if (rx == ry) return false; // पहले से एक ही संयुक्त घटक में हैं → चक्र बनेगा इसलिए false लौटाना
    // छोटे रैंक वाले को बड़े रैंक वाले के नीचे जोड़कर पेड़ की ऊँचाई का बढ़ना नियंत्रित करना
    if (rank[rx] < rank[ry])
        parent[rx] = ry;
    else if (rank[rx] > rank[ry])
        parent[ry] = rx;
    else {
        // रैंक समान हो तो एक को दूसरे के नीचे जोड़ना और रैंक 1 बढ़ाना
        parent[ry] = rx;
        rank[rx]++;
    }
    return true; // विलय सफल → कोई चक्र नहीं बना
}

public int[] findRedundantConnection(
        int[][] edges) {
    // किनारों की संख्या = नोड की संख्या (पेड़ के n-1 + अतिरिक्त 1 = n)। नोड संख्या 1 से n तक है
    int n = edges.length;
    // प्रत्येक नोड को स्वतंत्र समूह के रूप में प्रारंभ करना (parent[i] = i अर्थात स्वयं मूल है)
    int[] parent = new int[n + 1];
    int[] rank = new int[n + 1]; // rank सरणी डिफ़ॉल्ट 0 के साथ ठीक है
    for (int i = 1; i <= n; i++)
        parent[i] = i;

    // किनारों को आरंभ से क्रम में एक-एक करके संसाधित करना और चक्र बनाने वाले किनारे का पता लगाना
    for (int[] e : edges) {
        // यदि union ने false लौटाया, तो e[0] और e[1] पहले से एक ही संयुक्त घटक में हैं
        // → यह किनारा चक्र बनाने वाला अनावश्यक किनारा है, इसलिए इसे सीधे लौटाना
        if (!union(parent, rank,
                e[0], e[1]))
            return e;
    }
    // समस्या की बाधाओं के अनुसार एक अनावश्यक किनारा अवश्य मौजूद है इसलिए यहाँ नहीं पहुँचा जाएगा
    return new int[0];
}
```
