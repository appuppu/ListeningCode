# Finding the Largest Island by Area — 2D ग्रिड पर सबसे बड़े क्षेत्रफल वाला द्वीप खोजना

## समस्या का सार

`1` (भूमि) और `0` (पानी) से बना एक 2D बाइनरी ग्रिड दिया गया है। द्वीप उन `1` वाले सेलों का समूह है जो ऊपर, नीचे, बाएँ, दाएँ एक-दूसरे से जुड़े हुए हैं। ग्रिड में सभी द्वीपों में से **सबसे बड़ा क्षेत्रफल** (सेलों की संख्या) ज्ञात करके लौटाना है। यदि कोई द्वीप मौजूद नहीं है तो `0` लौटाना है।

## मूल विचार

प्रत्येक भूमि सेल से DFS द्वारा जुड़ी हुई भूमि को गिनने पर द्वीप का क्षेत्रफल प्राप्त होता है। विज़िट किए गए सेलों को अलग सरणी में प्रबंधित करने के बजाय, विज़िट किए गए सेल के मान को `0` में बदल देने से, बिना अतिरिक्त मेमोरी के दोहरी विज़िट को रोका जा सकता है।

## विचार प्रक्रिया

1. **द्वीप का क्षेत्रफल संयुक्त घटक का आकार है**: ग्रिड पर `1` जो ऊपर, नीचे, बाएँ, दाएँ जुड़े हुए हैं, वे एक द्वीप बनाते हैं। द्वीप का क्षेत्रफल उस समूह में शामिल सेलों की संख्या है। इसलिए, प्रत्येक संयुक्त घटक का आकार ज्ञात करके उसका अधिकतम मान लौटाना है
2. **संयुक्त घटकों की खोज के लिए DFS उपयुक्त है**: यदि कोई सेल `(r, c)` का मान `1` है, तो उसे प्रारंभ बिंदु बनाकर DFS से ऊपर, नीचे, बाएँ, दाएँ के निकटवर्ती सेलों की पुनरावर्ती खोज करके, सभी जुड़े हुए `1` को गिनकर उस द्वीप का क्षेत्रफल प्राप्त किया जा सकता है
3. **एक ही सेल को कई बार गिनने से रोकने की व्यवस्था आवश्यक है**: DFS में विज़िट किए गए सेल को दोबारा विज़िट करने पर क्षेत्रफल दोहरा गिना जाएगा। सामान्यतः `boolean[][] visited` सरणी बनाकर विज़िट की गई स्थिति दर्ज की जाती है, लेकिन इसके लिए O(m × n) की अतिरिक्त मेमोरी आवश्यक होती है
4. **विज़िट किए गए सेल को `0` में बदलने से अतिरिक्त मेमोरी अनावश्यक हो जाती है**: DFS में विज़िट किए गए सेल का मान `1` से `0` में बदल देने पर वह सेल पानी के रूप में माना जाता है और आगे की खोज में पुनः विज़िट नहीं होता। `visited` सरणी के बिना दोहराव रोका जा सकता है और सहायक मेमोरी O(1) हो जाती है
5. **DFS के रिटर्न मान से क्षेत्रफल एकत्रित किया जाता है**: DFS विज़िट किए गए सेल की अपनी `1` (गिनती) में ऊपर, नीचे, बाएँ, दाएँ चारों दिशाओं की पुनरावर्ती कॉल के रिटर्न मान जोड़कर लौटाता है। आधार स्थिति के रूप में, ग्रिड सीमा से बाहर या मान `0` वाले सेल `0` लौटाते हैं। इससे एक ही DFS कॉल में पूरे द्वीप का क्षेत्रफल पुनरावर्ती रूप से एकत्रित होता है
6. **पूरे ग्रिड को स्कैन करके अधिकतम मान ज्ञात किया जाता है**: दोहरे for लूप से ग्रिड के सभी सेलों को स्कैन करके प्रत्येक सेल पर DFS कॉल किया जाता है। DFS के रिटर्न मान (द्वीप का क्षेत्रफल) और वर्तमान अधिकतम मान की तुलना करके बड़ा मान रखा जाता है। मान `0` वाले सेलों पर DFS की आधार स्थिति द्वारा तुरंत `0` लौट आता है, इसलिए विशेष शाखा की आवश्यकता नहीं है

## पूर्वापेक्षित ज्ञान

### DFS (गहराई-प्रथम खोज) क्या है

ग्राफ या ग्रिड का खोज एल्गोरिदम। एक नोड से शुरू करके, जहाँ तक जा सकते हैं वहाँ तक गहराई में जाकर फिर वापस आता है। 2D ग्रिड में, किसी सेल से ऊपर, नीचे, बाएँ, दाएँ के निकटवर्ती सेलों में पुनरावर्ती रूप से जाकर सभी जुड़े हुए सेलों को विज़िट किया जा सकता है।

```java
// 2D ग्रिड में DFS की मूल संरचना
void dfs(int[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length)
        return;                    // ग्रिड सीमा से बाहर हो तो समाप्त
    dfs(grid, r - 1, c);          // ऊपर की ओर पुनरावर्तन
    dfs(grid, r + 1, c);          // नीचे की ओर पुनरावर्तन
    dfs(grid, r, c - 1);          // बाएँ की ओर पुनरावर्तन
    dfs(grid, r, c + 1);          // दाएँ की ओर पुनरावर्तन
}
```

### In-place Modification (स्थान पर ही संशोधन) क्या है

इनपुट डेटा को स्वयं बदलकर, अतिरिक्त डेटा संरचना (सरणी या सेट आदि) का उपयोग किए बिना स्थिति दर्ज करने की तकनीक। इस समस्या में, विज़िट की गई भूमि सेल को `0` में बदलकर `visited` सरणी का विकल्प बनाया जाता है।

```java
grid[r][c] = 0;  // विज़िट की गई भूमि(1) को पानी(0) में बदलना
```

### Math.max क्या है

दो मानों की तुलना करके बड़ा मान लौटाने वाला Java का मानक मेथड। लूप में अधिकतम मान को लगातार अपडेट करने के लिए उपयोग किया जाता है।

```java
Math.max(3, 7);   // → 7 (बड़ा मान लौटाता है)
Math.max(10, 2);  // → 10
```

## जटिलता

| | मान |
|---|---|
| Time | O(m × n) — ग्रिड के सभी सेलों को अधिकतम 2 बार (लूप में 1 बार, DFS में 1 बार) विज़िट किया जाता है |
| Space | O(1) सहायक मेमोरी — visited सरणी का उपयोग किए बिना ग्रिड को सीधे बदला जाता है। हालाँकि पुनरावर्तन स्टैक अधिकतम O(m × n) का उपयोग करता है |

## कोड

```java
// इनपुट: 1 (भूमि) और 0 (पानी) से बनी 2D पूर्णांक सरणी grid
// आउटपुट: ग्रिड में सबसे बड़े द्वीप का क्षेत्रफल int में लौटाना है। कोई द्वीप न हो तो 0 लौटाना है

// DFS: जुड़ी हुई भूमि सेलों को गिनता है और विज़िट किए गए सेलों को 0 में बदलता है
int dfs(int[][] grid, int r, int c) {
    // आधार स्थिति: सीमा से बाहर या पानी(0)/विज़िट किया हुआ हो तो नहीं गिनना है
    if (r < 0 || r >= grid.length
        || c < 0 || c >= grid[0].length
        || grid[r][c] == 0)
        return 0;

    // विज़िट किया हुआ चिह्नित करने के लिए भूमि(1) को पानी(0) में बदलना (in-place modification से visited सरणी अनावश्यक हो जाती है)
    grid[r][c] = 0;

    // स्वयं की 1 + ऊपर, नीचे, बाएँ, दाएँ की जुड़ी सेलों की संख्या का योग लौटाना है
    // चारों दिशाओं की पुनरावर्ती कॉल के रिटर्न मान जोड़कर पूरे द्वीप का क्षेत्रफल पुनरावर्ती रूप से एकत्रित होता है
    return 1 + dfs(grid, r - 1, c)   // ऊपर
             + dfs(grid, r + 1, c)   // नीचे
             + dfs(grid, r, c - 1)   // बाएँ
             + dfs(grid, r, c + 1);  // दाएँ
}

int maxAreaOfIsland(int[][] grid) {
    // ग्रिड की पंक्तियों और स्तंभों की संख्या प्राप्त करना
    int m = grid.length;
    int n = grid[0].length;
    // अधिकतम क्षेत्रफल दर्ज करने वाले चर को 0 से आरंभ करना (कोई द्वीप न हो तो यही मान लौटता है)
    int maxArea = 0;

    // दोहरे for लूप से सभी सेलों को स्कैन करके प्रत्येक द्वीप के क्षेत्रफल का अधिकतम मान ज्ञात करना
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // मान 0 वाले सेलों पर DFS की आधार स्थिति द्वारा तुरंत 0 लौट आता है, इसलिए विशेष शाखा अनावश्यक है
            maxArea = Math.max(maxArea,
                dfs(grid, i, j));

    return maxArea;
}
```
