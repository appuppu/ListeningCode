# Finding Cells That Drain to Both Oceans — दोनों महासागरों में पानी बहने वाले सभी सेल खोजना

## समस्या का सार

m×n की ऊँचाई मैट्रिक्स दी गई है। प्रशांत महासागर ऊपरी किनारे और बाएँ किनारे से लगा हुआ है, और अटलांटिक महासागर निचले किनारे और दाएँ किनारे से लगा हुआ है। पानी वर्तमान सेल से आसपास के सेल में तभी बहता है जब आसपास के सेल की ऊँचाई वर्तमान सेल की ऊँचाई के बराबर या उससे कम हो। उन सभी सेलों को खोजना है जिनसे पानी प्रशांत महासागर और अटलांटिक महासागर **दोनों** तक पहुँच सकता है।

## मूल विचार

प्रत्येक सेल से महासागर तक पहुँच की जाँच सीधी दिशा में करने पर गणना दोहराई जाती है। इसके विपरीत, महासागर के सीमा सेलों से अंदर की ओर "पानी जिस दिशा में चढ़ सकता है (ऊँचाई बराबर या अधिक वाले आसपास के सेल)" में BFS करने पर, प्रत्येक महासागर तक पहुँचने योग्य सेलों का समूह O(m*n) में प्राप्त होता है, और दोनों समूहों का प्रतिच्छेदन उत्तर होता है।

## विचार प्रक्रिया

1. **सीधी दिशा की खोज अकुशल है**: प्रत्येक सेल (i,j) से महासागर तक के पथ की खोज करने पर O(m*n) सेलों में से प्रत्येक के लिए BFS/DFS की आवश्यकता होती है, और कुल मिलाकर O((m*n)²) हो जाता है। प्रत्येक सेल की स्वतंत्र खोज में बहुत अधिक दोहराव होता है, इसलिए उलटी दिशा की खोज पर विचार करते हैं
2. **उलटी दिशा में सोच बदलना**: "सेल से महासागर की ओर पानी बहता है" यह "महासागर से सेल तक ऊँचाई में गैर-घटते पथ का अस्तित्व है" के समतुल्य है। महासागर की सीमा से उलटी दिशा में BFS करने पर, पहुँचने योग्य सेलों का समूह एक ही बार में प्राप्त किया जा सकता है
3. **दोनों महासागरों को स्वतंत्र रूप से संसाधित करना**: प्रशांत महासागर के सीमा सेलों (ऊपरी किनारा + बायाँ किनारा) को सभी कतार में डालकर BFS करते हैं, और पहुँचने योग्य सेलों को दर्ज करते हैं। अटलांटिक महासागर के सीमा सेलों (निचला किनारा + दायाँ किनारा) के लिए भी इसी प्रकार BFS करते हैं। दोनों खोजें एक-दूसरे से स्वतंत्र हैं, इसलिए एक ही तर्क का पुन: उपयोग किया जा सकता है
4. **BFS की संक्रमण शर्त निर्धारित करना**: चूँकि यह उलटी दिशा है, आसपास के सेल की ऊँचाई वर्तमान सेल **के बराबर या अधिक** होने पर संक्रमण होता है। यह "पानी ऊँचे स्थान से नीचे स्थान की ओर बहता है" का उलटा है
5. **प्रतिच्छेदन लेना**: दोनों BFS में पहुँच-चिह्नित सेल वे सेल हैं जिनसे दोनों महासागरों में पानी बहता है। सभी सेलों को स्कैन करके दोनों में true वाले सेलों को परिणाम सूची में जोड़ते हैं

## पूर्व ज्ञान

### Multi-source BFS (बहु-स्रोत BFS) क्या है

सामान्य BFS एक प्रारंभ बिंदु से शुरू होता है, लेकिन इस तकनीक में कई प्रारंभ बिंदुओं को पहले से कतार में डालकर BFS शुरू किया जाता है। इससे सभी प्रारंभ बिंदुओं से एक साथ खोज फैलने जैसा प्रभाव मिलता है, और सभी प्रारंभ बिंदुओं से पहुँचने योग्य सेलों को एक ही BFS में प्राप्त किया जा सकता है।

```java
Queue<int[]> queue = new LinkedList<>();
// सभी प्रारंभ बिंदुओं को कतार में जोड़ना
queue.offer(new int[]{0, 0});
queue.offer(new int[]{0, 1});
queue.offer(new int[]{0, 2});
// एक ही while लूप में सभी प्रारंभ बिंदुओं से एक साथ खोज करना
while (!queue.isEmpty()) {
    int[] cell = queue.poll();
    // शर्त के आधार पर आसपास के सेलों की खोज करना
}
```

### boolean[][] द्वारा विज़िट प्रबंधन

2-आयामी boolean सरणी का उपयोग करके, प्रत्येक सेल पहुँचा गया है या नहीं यह दर्ज किया जाता है। प्रारंभिक मान false होता है, और पहुँचे हुए सेल को true किया जाता है। यह एक ही सेल को दोबारा संसाधित करने से रोकता है।

```java
boolean[][] reach = new boolean[m][n];  // m×n की false से आरंभित सरणी
reach[r][c] = true;   // सेल (r,c) को पहुँचा हुआ चिह्नित करना
if (!reach[nr][nc])   // सेल (nr,nc) अभी तक नहीं पहुँचा है यह जाँचना
```

### 4-दिशा गति वेक्टर

ग्रिड पर ऊपर, नीचे, बाएँ, दाएँ की गति को सरणी द्वारा व्यक्त किया जाता है। लूप में 4 दिशाओं को क्रमशः आज़माने से, प्रत्येक दिशा की शाखा को कोड दोहराव के बिना लिखा जा सकता है।

```java
int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};  // दाएँ, बाएँ, नीचे, ऊपर
for (int[] d : dirs) {
    int nr = r + d[0];  // नया पंक्ति इंडेक्स
    int nc = c + d[1];  // नया स्तंभ इंडेक्स
}
```

## जटिलता

| | मान |
|---|---|
| Time | O(m×n) — प्रत्येक BFS सभी सेलों को अधिकतम एक बार विज़िट करता है, और BFS को 2 बार चलाया जाता है |
| Space | O(m×n) — 2 boolean सरणियाँ और BFS कतार प्रत्येक अधिकतम m×n सेल रखती हैं |

## कोड

```java
// इनपुट: m×n की पूर्णांक मैट्रिक्स heights (प्रत्येक सेल की ऊँचाई)
// आउटपुट: दोनों महासागरों तक पानी पहुँच सकने वाले सेलों के निर्देशांक List<List<Integer>> में लौटाना

// ऊपर, नीचे, बाएँ, दाएँ 4 दिशाओं का गति वेक्टर
int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};

// बहु-स्रोत BFS चलाकर पहुँचने योग्य सेलों को boolean सरणी में लौटाना
boolean[][] bfs(int[][] h, Queue<int[]> q) {
    int m = h.length, n = h[0].length;
    // प्रत्येक सेल महासागर से उलटी दिशा में पहुँचने योग्य है या नहीं यह दर्ज करने वाली सरणी
    boolean[][] reach = new boolean[m][n];

    // कतार में सभी प्रारंभ बिंदुओं को पहुँचा हुआ चिह्नित करना (सीमा सेल सीधे महासागर से लगे होते हैं)
    for (int[] c : q)
        reach[c[0]][c[1]] = true;

    while (!q.isEmpty()) {
        int[] cell = q.poll();
        int r = cell[0], c = cell[1];

        // 4 दिशाओं में आसपास के सेलों की जाँच करना
        for (int[] d : dirs) {
            int nr = r + d[0];
            int nc = c + d[1];

            // सीमा के अंदर और अभी तक नहीं पहुँचा और ऊँचाई वर्तमान के बराबर या अधिक (उलटी दिशा में जा सकता है) हो तो खोज बढ़ाना
            // ऊँचाई वर्तमान के बराबर या अधिक की शर्त "पानी ऊँचे स्थान से नीचे स्थान की ओर बहता है" के उलटे को व्यक्त करती है
            if (nr >= 0 && nr < m
                && nc >= 0 && nc < n
                && !reach[nr][nc]
                && h[nr][nc] >= h[r][c]) {
                reach[nr][nc] = true;
                q.offer(new int[]{nr, nc});
            }
        }
    }
    return reach;
}

List<List<Integer>> pacificAtlantic(int[][] heights) {
    int m = heights.length;
    int n = heights[0].length;

    // प्रशांत महासागर और अटलांटिक महासागर के लिए कतार बनाना (Multi-source BFS का प्रारंभ बिंदु समूह)
    Queue<int[]> pQ = new LinkedList<>();
    Queue<int[]> aQ = new LinkedList<>();

    // ऊपरी किनारा प्रशांत महासागर से सीधे लगा है इसलिए प्रशांत का प्रारंभ बिंदु, निचला किनारा अटलांटिक से सीधे लगा है इसलिए अटलांटिक का प्रारंभ बिंदु
    for (int j = 0; j < n; j++) {
        pQ.offer(new int[]{0, j});
        aQ.offer(new int[]{m - 1, j});
    }

    // बायाँ किनारा प्रशांत महासागर से सीधे लगा है इसलिए प्रशांत का प्रारंभ बिंदु, दायाँ किनारा अटलांटिक से सीधे लगा है इसलिए अटलांटिक का प्रारंभ बिंदु
    for (int i = 0; i < m; i++) {
        pQ.offer(new int[]{i, 0});
        aQ.offer(new int[]{i, n - 1});
    }

    // प्रत्येक महासागर से उलटी दिशा में BFS चलाकर पहुँचने योग्य सेलों का समूह प्राप्त करना
    boolean[][] pacReach = bfs(heights, pQ);
    boolean[][] atlReach = bfs(heights, aQ);

    // दोनों महासागरों तक पहुँचने योग्य सेलों को परिणाम सूची में जोड़ना
    // दोनों में true होने का अर्थ है कि उस सेल से प्रशांत महासागर और अटलांटिक महासागर दोनों में पानी बहता है
    List<List<Integer>> res = new ArrayList<>();
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (pacReach[i][j] && atlReach[i][j])
                res.add(Arrays.asList(i, j));

    return res;
}
```
