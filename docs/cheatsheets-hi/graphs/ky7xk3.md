# Counting Connected Components in an Undirected Graph — अनिर्देशित ग्राफ में संयुक्त घटकों की संख्या गिनना

## समस्या का सार

`0` से `n-1` तक लेबल किए गए `n` नोड और अनिर्देशित किनारों (edges) की एक सूची `edges` दी गई है। ग्राफ में **संयुक्त घटकों (connected components) की संख्या** को पूर्णांक के रूप में लौटाना है। संयुक्त घटक उन नोड्स का समूह है जो किनारों के माध्यम से एक-दूसरे तक पहुँच सकते हैं।

## मूल विचार

शुरू में प्रत्येक नोड को एक स्वतंत्र संयुक्त घटक मानें, फिर किनारों को एक-एक करके संसाधित करते हुए दोनों सिरों के नोड्स के समूहों को मिलाते जाएँ। सभी किनारों को संसाधित करने के बाद शेष बचे समूहों की संख्या ही संयुक्त घटकों की संख्या है।

## विचार प्रक्रिया

1. **किनारे से जुड़े नोड एक ही समूह में होते हैं**: संयुक्त घटक "किनारों के माध्यम से पहुँचने योग्य नोड्स का समूह" है, इसलिए किनारे से जुड़े दो नोड अनिवार्य रूप से एक ही संयुक्त घटक में होते हैं। सभी किनारों के लिए "दोनों सिरों के नोड्स को एक ही समूह में मिलाने" की प्रक्रिया दोहराने पर अंततः संयुक्त घटक प्राप्त होते हैं
2. **समूह प्रबंधन के लिए Union-Find उपयुक्त है**: "दो तत्वों को एक ही समूह में मिलाना (union)" और "किसी तत्व का समूह ज्ञात करना (find)" — इन दोनों कार्यों को तेज़ी से करने वाली डेटा संरचना Union-Find है। प्रत्येक नोड को एक "parent नोड" दिया जाता है, और समान root वाले नोड्स को एक ही समूह माना जाता है
3. **प्रारंभिक अवस्था में प्रत्येक नोड स्वयं अपना parent होता है**: `parent[i] = i` से आरंभ करने पर, शुरू में n नोड्स में से प्रत्येक एक स्वतंत्र समूह (संयुक्त घटक) बनता है। प्रारंभिक संयुक्त घटकों की संख्या `n` होती है
4. **प्रत्येक किनारे को संसाधित करते समय union करें, और यदि मिलान हो तो घटक संख्या घटाएँ**: प्रत्येक किनारे `[a, b]` के लिए, `a` का root और `b` का root ज्ञात करें। यदि root भिन्न हैं तो वे अलग-अलग समूह हैं, इसलिए एक root को दूसरे root का child बनाकर मिलाएँ और संयुक्त घटकों की संख्या 1 घटाएँ। यदि root समान है तो वे पहले से एक ही समूह में हैं, इसलिए कुछ नहीं करें
5. **पथ संपीड़न और रैंक से गति बढ़ाएँ**: find के दौरान पथ संपीड़न (path compression) करें — विज़िट किए गए नोड्स के parent को सीधे root से जोड़ दें। union के दौरान रैंक (पेड़ की ऊँचाई की ऊपरी सीमा) की तुलना करें, और छोटे पेड़ को बड़े पेड़ के नीचे जोड़ें (union by rank)। इससे find की जटिलता लगभग O(1) (सटीक रूप से O(α(V))) हो जाती है
6. **सभी किनारों को संसाधित करने के बाद `components` उत्तर है**: प्रारंभिक मान `n` से, प्रत्येक सफल union पर 1 घटाने का परिणाम अंतिम संयुक्त घटकों की संख्या होती है

## पूर्व ज्ञान

### Union-Find (विसंयुक्त समुच्चय डेटा संरचना) क्या है

तत्वों को समूहों में विभाजित करके प्रबंधित करने वाली डेटा संरचना है। यह "दो तत्वों को एक ही समूह में मिलाना (union)" और "किसी तत्व के समूह का प्रतिनिधि (root) ज्ञात करना (find)" — ये दो संक्रियाएँ प्रदान करती है। `parent` ऐरे में प्रत्येक तत्व का parent दर्ज किया जाता है, और root तक parent को ट्रेस करके समूह का प्रतिनिधि निर्धारित किया जाता है।

```java
int[] parent = new int[n];   // parent[i] नोड i के parent नोड को संग्रहीत करता है
for (int i = 0; i < n; i++)
    parent[i] = i;            // प्रारंभिक अवस्था: प्रत्येक नोड स्वयं अपना parent है (स्वतंत्र समूह)
```

### पथ संपीड़न (Path Compression) क्या है

find की पुनरावर्ती प्रक्रिया में, विज़िट किए गए सभी नोड्स के parent को सीधे root से जोड़ने की अनुकूलन तकनीक है। इसके बाद find तुरंत root लौटाता है, और पेड़ सपाट हो जाने से जटिलता लगभग O(1) हो जाती है।

```java
int find(int[] parent, int x) {
    if (parent[x] != x)
        parent[x] = find(parent, parent[x]);  // पुनरावर्ती रूप से root खोजकर, parent को root से जोड़ देता है
    return parent[x];                          // root लौटाता है
}
```

### रैंक (Rank) द्वारा union क्या है

union के समय पेड़ की ऊँचाई की ऊपरी सीमा (रैंक) की तुलना करके, कम रैंक वाले पेड़ को अधिक रैंक वाले पेड़ के नीचे जोड़ने की तकनीक है। पेड़ की ऊँचाई की वृद्धि को रोककर find की दक्षता बनाए रखी जाती है। केवल जब रैंक बराबर हों, तभी मिलान स्थल के रैंक को 1 बढ़ाया जाता है।

```java
int[] rank = new int[n];     // rank[i] नोड i को root मानने वाले पेड़ की ऊँचाई की ऊपरी सीमा है (प्रारंभिक मान 0)
// अधिक रैंक वाले को parent बनाएँ → पेड़ गहरा होने से बचता है
if (rank[r1] > rank[r2])
    parent[r2] = r1;         // r2 के पेड़ को r1 के नीचे जोड़ता है
```

### α (एकरमन फ़ंक्शन का प्रतिलोम) क्या है

Union-Find की जटिलता में प्रकट होने वाला फ़ंक्शन है। व्यावहारिक इनपुट आकारों के लिए α(V) सदैव 5 या उससे कम होता है, इसलिए इसे वास्तविक रूप से स्थिरांक माना जा सकता है। इसी कारण Union-Find की प्रत्येक संक्रिया लगभग O(1) में कार्य करती है।

## जटिलता

| | मान |
|---|---|
| Time | O(V + E · α(V)) — आरंभीकरण में O(V), प्रत्येक किनारे के लिए find और union किया जाता है लेकिन α(V) लगभग स्थिरांक है इसलिए वास्तव में O(V + E) |
| Space | O(V) — parent ऐरे और rank ऐरे में प्रत्येक V तत्व संग्रहीत होते हैं |

## कोड

```java
// इनपुट: नोड्स की संख्या n और किनारों की सूची edges (प्रत्येक किनारा 2 तत्वों का ऐरे [a, b])
// आउटपुट: संयुक्त घटकों की संख्या को पूर्णांक में लौटाता है

// पथ संपीड़न सहित find फ़ंक्शन: नोड x के समूह का root लौटाता है
int find(int[] parent, int x) {
    if (parent[x] != x)
        // पुनरावर्ती रूप से root खोजकर, parent को सीधे root से जोड़ता है (पथ संपीड़न)
        // इससे अगली बार find तुरंत root लौटाता है
        parent[x] = find(parent, parent[x]);
    return parent[x];
}

int countComponents(int n, int[][] edges) {
    // प्रत्येक नोड के parent को संग्रहीत करने वाला ऐरे। parent[i] = i से आरंभ करके प्रत्येक नोड को स्वतंत्र समूह बनाता है
    int[] parent = new int[n];
    // प्रत्येक नोड को root मानने वाले पेड़ की ऊँचाई की ऊपरी सीमा संग्रहीत करने वाला ऐरे (union में किसके नीचे जोड़ना है यह निर्धारित करने के लिए)
    int[] rank = new int[n];
    for (int i = 0; i < n; i++)
        parent[i] = i;

    // प्रारंभिक अवस्था में प्रत्येक नोड एक स्वतंत्र संयुक्त घटक है, इसलिए घटक संख्या n है
    int components = n;

    // किनारों को एक-एक करके स्कैन करते हुए, दोनों सिरों के नोड्स के समूहों को मिलाते जाएँ
    for (int[] e : edges) {
        // किनारे के दोनों सिरों के नोड्स के समूह का root ज्ञात करें (पथ संपीड़न से विज़िट किए गए नोड्स के parent भी root से जुड़ जाते हैं)
        int r1 = find(parent, e[0]);
        int r2 = find(parent, e[1]);

        // यदि root भिन्न हैं तो अलग-अलग समूह हैं इसलिए मिलाएँ (यदि root समान है तो पहले से एक ही समूह है इसलिए कुछ नहीं करें)
        if (r1 != r2) {
            // रैंक की तुलना करके, कम रैंक वाले को अधिक रैंक वाले के नीचे जोड़ें (पेड़ की ऊँचाई बढ़ने से रोकें)
            if (rank[r1] > rank[r2])
                parent[r2] = r1;
            else if (rank[r1] < rank[r2])
                parent[r1] = r2;
            else {
                // रैंक बराबर होने पर, r2 को r1 के नीचे जोड़कर r1 का रैंक 1 बढ़ाएँ
                parent[r2] = r1;
                rank[r1]++;
            }
            // दो समूह एक में मिल गए इसलिए घटक संख्या 1 घटाएँ
            components--;
        }
    }
    // सभी किनारों को संसाधित करने के बाद components संयुक्त घटकों की संख्या है
    return components;
}
```
