# Finding the Shortest Word Transformation Sequence — सबसे छोटी शब्द रूपांतरण श्रृंखला की लंबाई ज्ञात करना

## समस्या का सार

आरंभिक शब्द `beginWord`, लक्ष्य शब्द `endWord`, और मान्य शब्दों का शब्दकोश `wordList` दिया गया है। आरंभिक शब्द से लक्ष्य शब्द तक, **प्रत्येक चरण में केवल 1 अक्षर बदलते हुए**, और सभी मध्यवर्ती शब्द शब्दकोश में मौजूद हों — ऐसी रूपांतरण श्रृंखला में से **सबसे छोटी श्रृंखला की लंबाई** लौटानी है। यदि कोई रूपांतरण श्रृंखला मौजूद नहीं है तो 0 लौटाना है।

## मूल विचार

शब्दों के बीच 1 अक्षर के रूपांतरण को ग्राफ के किनारे (edge) के रूप में देखें, तो सबसे छोटी रूपांतरण श्रृंखला एक सबसे छोटे पथ की समस्या बन जाती है। BFS को आरंभ बिंदु और अंत बिंदु दोनों से एक साथ चलाकर, हमेशा छोटे वाले फ्रंटियर को विस्तारित करने से, खोज स्थान को नाटकीय रूप से कम किया जा सकता है।

## विचार प्रक्रिया

1. **ग्राफ के रूप में समझना**: प्रत्येक शब्द को नोड मानें, और 1 अक्षर के अंतर वाले शब्दों को किनारे से जोड़ें — ऐसा ग्राफ बनाएं। सबसे छोटी रूपांतरण श्रृंखला की लंबाई इस ग्राफ पर beginWord से endWord तक के सबसे छोटे पथ की लंबाई के बराबर होती है
2. **सबसे छोटे पथ के लिए BFS का उपयोग करना**: यह भारहीन ग्राफ की सबसे छोटे पथ की समस्या है, इसलिए BFS (चौड़ाई-पहले खोज) उपयुक्त है। प्रत्येक स्तर एक रूपांतरण चरण के अनुरूप होता है
3. **एकदिशीय BFS की अक्षमता**: यदि केवल आरंभ बिंदु से BFS चलाएं, तो प्रत्येक स्तर पर उम्मीदवार घातांकीय रूप से बढ़ते हैं। गहराई बढ़ने के साथ खोज स्थान विस्फोटक रूप से बढ़ता है
4. **द्विदिशीय BFS से खोज स्थान को कम करना**: आरंभ बिंदु और अंत बिंदु दोनों से एक साथ BFS चलाने पर, दोनों जब मिलते हैं उसी बिंदु पर सबसे छोटा पथ मिल जाता है। एक तरफ की खोज गहराई d/2 तक ही जाती है, इसलिए खोज स्थान काफी कम हो जाता है
5. **छोटे फ्रंटियर को प्राथमिकता से विस्तारित करना**: प्रत्येक चरण में, आरंभ पक्ष और अंत पक्ष के फ्रंटियर (वर्तमान स्तर के शब्दों का समूह) के आकार की तुलना करें, और छोटे वाले को विस्तारित करें। इससे फ्रंटियर के फैलाव को हमेशा नियंत्रित रखा जा सकता है
6. **आसन्न शब्दों की उत्पत्ति विधि**: शब्दकोश के सभी शब्दों से तुलना करने के बजाय, शब्द की प्रत्येक स्थिति पर a से z तक 26 अक्षर आज़माकर आसन्न शब्द उत्पन्न करें। जब शब्द की लंबाई m शब्दकोश के आकार n से पर्याप्त रूप से छोटी हो, तो यह विधि अधिक कुशल होती है
7. **सामने वाले फ्रंटियर से मिलन की जांच**: यदि उत्पन्न किया गया आसन्न शब्द दूसरे पक्ष के फ्रंटियर में मौजूद है, तो इसका अर्थ है कि दोनों खोजें मिल गई हैं, और उस बिंदु पर स्तर+1 लौटाना है

## पूर्वापेक्षित ज्ञान

### BFS (चौड़ाई-पहले खोज) क्या है

ग्राफ के आरंभ बिंदु से निकट क्रम में नोड्स की खोज करने वाला एल्गोरिदम है। प्रत्येक स्तर पर दूरी 1 बढ़ती है, इसलिए पहली बार पहुंचने पर की दूरी ही सबसे छोटी दूरी होती है। भारहीन ग्राफ की सबसे छोटे पथ की समस्या में इसका उपयोग किया जाता है।

### HashSet क्या है

तत्वों के समूह को रखने वाली डेटा संरचना है। तत्व जोड़ना, खोजना और हटाना O(1) में किया जा सकता है। यह स्वचालित रूप से दोहराव को हटा देता है।

```java
Set<String> set = new HashSet<>();   // खाली HashSet बनाता है
set.add("hot");                      // तत्व जोड़ता है
set.contains("hot");                 // तत्व मौजूद है या नहीं boolean में लौटाता है → true
set.size();                          // तत्वों की संख्या लौटाता है → 1
```

### द्विदिशीय BFS क्या है

सामान्य BFS केवल आरंभ बिंदु से खोज करता है, जबकि द्विदिशीय BFS आरंभ बिंदु और अंत बिंदु दोनों से एक साथ खोज को आगे बढ़ाता है। दोनों के फ्रंटियर जब ओवरलैप करते हैं उसी बिंदु पर सबसे छोटा पथ मिल जाता है। खोज स्थान O(b^d) से O(b^(d/2)) तक कम हो जाता है (b शाखा कारक है, d सबसे छोटी दूरी है)।

### toCharArray / String.valueOf क्या है

String को वर्ण सरणी में बदलने और एक-एक अक्षर को संचालित करने के लिए मेथड समूह है।

```java
char[] ch = "hot".toCharArray();     // String → char[] में बदलता है → ['h','o','t']
ch[0] = 'b';                        // एक अक्षर को सीधे बदलता है → ['b','o','t']
String next = String.valueOf(ch);    // char[] → String में वापस बदलता है → "bot"
```

## समय और स्थान जटिलता

| | मान |
|---|---|
| Time | O(n × m) — n शब्दकोश में शब्दों की संख्या है, m शब्द की लंबाई है। प्रत्येक शब्द की प्रत्येक स्थिति पर 26 अक्षर आज़माए जाते हैं |
| Space | O(n × m) — विज़िट किए गए सेट और फ्रंटियर में अधिकतम n शब्द (प्रत्येक लंबाई m) संग्रहीत किए जाते हैं |

## कोड

```java
// इनपुट: आरंभिक शब्द beginWord, लक्ष्य शब्द endWord, मान्य शब्दों का शब्दकोश wordList
// आउटपुट: सबसे छोटी रूपांतरण श्रृंखला की लंबाई int में लौटाता है। यदि रूपांतरण श्रृंखला मौजूद नहीं है तो 0 लौटाता है
int ladderLength(String beginWord, String endWord, List<String> wordList) {
    // शब्दकोश को HashSet में बदलकर शब्द की मौजूदगी जांच को O(1) बनाता है
    Set<String> wordSet = new HashSet<>(wordList);
    // यदि endWord शब्दकोश में नहीं है, तो रूपांतरण श्रृंखला नहीं बन सकती इसलिए 0 लौटाता है
    if (!wordSet.contains(endWord)) return 0;

    // आरंभ पक्ष फ्रंटियर, अंत पक्ष फ्रंटियर, और विज़िट किए गए सेट — ये 3 HashSet बनाता है
    Set<String> start = new HashSet<>();
    Set<String> end = new HashSet<>();
    Set<String> visited = new HashSet<>();
    start.add(beginWord);
    end.add(endWord);
    // दोनों फ्रंटियर के शब्दों को विज़िट किए गए में पंजीकृत करता है
    visited.add(beginWord);
    visited.add(endWord);
    // level रूपांतरण श्रृंखला की लंबाई है (आरंभ शब्द स्वयं को 1 गिना जाता है)
    int level = 1;

    // यदि किसी एक फ्रंटियर में कोई शब्द नहीं बचा तो पहुंचना असंभव है, इसलिए लूप से बाहर निकलता है
    while (!start.isEmpty() && !end.isEmpty()) {
        // हमेशा छोटे फ्रंटियर को विस्तारित करके खोज स्थान के फैलाव को रोकता है
        if (start.size() > end.size()) {
            Set<String> temp = start;
            start = end;
            end = temp;
        }

        // अगले स्तर के उम्मीदवारों को रखने वाला सेट
        Set<String> nextLevel = new HashSet<>();

        for (String word : start) {
            // शब्द को char[] में बदलकर, प्रत्येक स्थिति पर 1 अक्षर बदलकर आसन्न शब्द उत्पन्न करता है
            char[] ch = word.toCharArray();
            for (int j = 0; j < ch.length; j++) {
                // मूल अक्षर को सुरक्षित रखता है ताकि खोज के बाद वापस रख सके
                char orig = ch[j];
                // प्रत्येक स्थिति पर a से z तक 26 अक्षर आज़माकर आसन्न शब्द उत्पन्न करता है
                for (char c = 'a'; c <= 'z'; c++) {
                    ch[j] = c;
                    String next = String.valueOf(ch);
                    // यदि सामने वाले फ्रंटियर में मौजूद है तो दोनों खोजें मिल गई हैं
                    if (end.contains(next)) return level + 1;
                    // यदि शब्दकोश में है और अभी तक विज़िट नहीं किया तो अगले फ्रंटियर में जोड़ता है
                    // visited में जोड़कर उसी शब्द की पुनः विज़िट को रोकता है
                    if (wordSet.contains(next) && !visited.contains(next)) {
                        nextLevel.add(next);
                        visited.add(next);
                    }
                }
                // मूल अक्षर को वापस रखकर अगली स्थिति की खोज के लिए तैयार करता है
                ch[j] = orig;
            }
        }
        // फ्रंटियर को अगले स्तर से बदलता है, level को 1 बढ़ाकर अगले इटरेशन में जाता है
        start = nextLevel;
        level++;
    }
    // यदि किसी एक फ्रंटियर में कोई शब्द नहीं बचा तो रूपांतरण श्रृंखला मौजूद नहीं है
    return 0;
}
```
