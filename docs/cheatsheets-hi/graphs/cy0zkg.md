# Simulating Rotting Oranges Spreading — सड़े हुए संतरों का फैलाव पूरा होने तक की न्यूनतम समय ज्ञात करना

## समस्या का सार

m×n का एक ग्रिड दिया गया है, जिसमें प्रत्येक सेल 0 (खाली), 1 (ताज़ा संतरा), या 2 (सड़ा हुआ संतरा) में से कोई एक है। हर मिनट, सड़ा हुआ संतरा अपने ऊपर, नीचे, बाएँ और दाएँ के आसन्न ताज़े संतरों को सड़ा देता है। सभी ताज़े संतरों को सड़ने में लगने वाला **न्यूनतम मिनट** लौटाएँ। यदि सभी को सड़ाना असंभव हो तो -1 लौटाएँ।

## मूल विचार

सड़े हुए संतरे "एक साथ" आसन्न सेलों में फैलते हैं। यह कई प्रारंभ बिंदुओं से एक साथ BFS शुरू करने वाला "Multi-Source BFS" ही है, और BFS का प्रत्येक स्तर (लेयर) 1 मिनट के अनुरूप होता है।

## विचार प्रक्रिया

1. **फैलाव एक साथ होता है**: जब कई सड़े हुए संतरे हों, तो प्रत्येक एक साथ आसन्न सेलों को सड़ाता है। किसी एक प्रारंभ बिंदु से खोज करने के बजाय, सभी सड़े हुए संतरों को एक साथ प्रारंभ बिंदु बनाना आवश्यक है
2. **एक साथ प्रारंभ के लिए Multi-Source BFS का उपयोग करें**: पहले सभी सड़े हुए संतरों को कतार में डाल दें, तो BFS का 1 स्तर (कतार के वर्तमान आकार जितने तत्वों को प्रोसेस करने का 1 राउंड) 1 मिनट के फैलाव के अनुरूप होता है। DFS "न्यूनतम समय" की गारंटी नहीं दे सकता, इसलिए BFS उपयुक्त है
3. **ताज़े संतरों की संख्या को ट्रैक करें**: फैलाव समाप्त होने के बाद यदि ताज़े संतरे शेष हैं तो यह असंभव केस है। इसलिए, प्रारंभिक अवस्था में ताज़े संतरों की संख्या गिनें और हर बार सड़ाने पर उसे घटाएँ
4. **बीता हुआ समय मापने की विधि**: BFS के प्रत्येक स्तर पर कतार के सभी तत्वों को प्रोसेस करें, और 1 स्तर पूरा होने पर बीते हुए समय में 1 मिनट जोड़ें। ताज़े संतरों की संख्या 0 होने के समय का स्तर संख्या ही उत्तर है
5. **समाप्ति शर्त और असंभवता निर्णय**: BFS समाप्त होने के बाद यदि `fresh > 0` है, तो पहुँच से बाहर ताज़े संतरे मौजूद हैं इसलिए -1 लौटाएँ। यदि `fresh == 0` है तो बीता हुआ समय लौटाएँ

## पूर्व ज्ञान

### BFS (चौड़ाई-पहले खोज) क्या है

ग्राफ या ग्रिड को "प्रारंभ बिंदु से निकटतम दूरी के क्रम में" खोजने वाला एल्गोरिदम है। कतार (FIFO) का उपयोग करके, वर्तमान स्तर के सभी नोड्स को प्रोसेस करने के बाद अगले स्तर पर बढ़ता है। न्यूनतम दूरी और न्यूनतम समय ज्ञात करने की समस्याओं के लिए उपयुक्त है।

### Multi-Source BFS क्या है

सामान्य BFS में प्रारंभ बिंदु 1 होता है, लेकिन Multi-Source BFS में कई प्रारंभ बिंदुओं को कतार में डालकर BFS शुरू किया जाता है। सभी प्रारंभ बिंदुओं से एक साथ फैलाव के सिमुलेशन में इसका उपयोग होता है। कतार की प्रारंभिक अवस्था में कई तत्व होने के अलावा यह सामान्य BFS के समान ही है।

### Queue (कतार) क्या है

पहले-आया-पहले-गया (FIFO) डेटा संरचना है। BFS में खोज के लिए नोड्स को क्रम से प्रोसेस करने के लिए इसका उपयोग होता है।

```java
Queue<int[]> queue = new LinkedList<>();  // int सरणी को तत्व के रूप में रखने वाली कतार बनाएँ
queue.offer(new int[]{0, 1});  // कतार के अंत में तत्व जोड़ें
int[] pos = queue.poll();       // कतार के आरंभ से तत्व निकालें और हटाएँ → {0, 1}
queue.size();                   // कतार में तत्वों की संख्या लौटाएँ
queue.isEmpty();                // कतार खाली है या नहीं boolean में लौटाएँ
```

### दिशा सरणी क्या है

ग्रिड खोज में ऊपर, नीचे, बाएँ, दाएँ के आसन्न सेलों को सूचीबद्ध करने की तकनीक है। पंक्ति और स्तंभ के विस्थापन को सरणी में परिभाषित करके लूप में उपयोग किया जाता है।

```java
int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};  // दाएँ, बाएँ, नीचे, ऊपर की 4 दिशाएँ
for (int[] d : dirs) {
    int nr = row + d[0];  // आसन्न सेल का पंक्ति इंडेक्स
    int nc = col + d[1];  // आसन्न सेल का स्तंभ इंडेक्स
}
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(m × n) — ग्रिड के सभी सेलों को प्रारंभिक स्कैन में 1 बार और BFS में अधिकतम 1 बार प्रोसेस किया जाता है |
| Space | O(m × n) — कतार में अधिकतम m×n सेल संग्रहीत होते हैं |

## कोड

```java
// इनपुट: m×n का पूर्णांक ग्रिड grid (प्रत्येक सेल 0=खाली, 1=ताज़ा संतरा, 2=सड़ा हुआ संतरा)
// आउटपुट: सभी ताज़े संतरों को सड़ने में लगने वाला न्यूनतम मिनट int में लौटाएँ। असंभव होने पर -1 लौटाएँ
public int orangesRotting(int[][] grid) {
    int rows = grid.length;
    int cols = grid[0].length;
    // BFS के लिए कतार। खोज के लक्ष्य सेलों के निर्देशांक रखती है
    Queue<int[]> queue = new LinkedList<>();
    // शेष ताज़े संतरों की संख्या ट्रैक करने वाला चर
    int fresh = 0;

    // संपूर्ण ग्रिड को स्कैन करके BFS के कई प्रारंभ बिंदु और लक्ष्य तक की शेष संख्या एक साथ तैयार करें
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (grid[i][j] == 2) {
                // सड़े हुए संतरे को कतार में जोड़ें (Multi-Source BFS का प्रारंभ बिंदु)
                queue.offer(new int[]{i, j});
            } else if (grid[i][j] == 1) {
                // ताज़े संतरों की संख्या गिनें
                fresh++;
            }
        }
    }

    // ऊपर, नीचे, बाएँ, दाएँ की 4 दिशाओं को दर्शाने वाली दिशा सरणी। आसन्न सेलों को सूचीबद्ध करने में उपयोग होती है
    int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
    int minutes = 0;

    // कतार खाली न होने के साथ-साथ ताज़े संतरे शेष होने की शर्त भी शामिल करें, ताकि सब सड़ने के बाद अनावश्यक लूप से बचा जा सके
    while (!queue.isEmpty() && fresh > 0) {
        // इस स्तर (1 मिनट) में प्रोसेस करने वाले सेलों की संख्या पहले सहेजें। लूप में जुड़ने वाले अगले स्तर के तत्वों से अलग करने के लिए
        int size = queue.size();
        // 1 स्तर की प्रोसेसिंग शुरू हो रही है इसलिए बीते हुए समय में 1 मिनट जोड़ें
        minutes++;

        // size बार कतार से तत्व निकालकर इस स्तर के सभी सेलों को प्रोसेस करें
        for (int k = 0; k < size; k++) {
            int[] pos = queue.poll();

            // दिशा सरणी का उपयोग करके ऊपर, नीचे, बाएँ, दाएँ के 4 आसन्न सेलों की जाँच करें
            for (int[] d : dirs) {
                int nr = pos[0] + d[0];
                int nc = pos[1] + d[1];

                // सीमा के अंदर हो और ताज़ा संतरा हो तो उसे सड़ाएँ
                if (nr >= 0 && nr < rows
                    && nc >= 0 && nc < cols
                    && grid[nr][nc] == 1) {
                    // सेल को 2 में अपडेट करके विज़िटेड चिह्नित करें (visited सरणी के स्थान पर काम करता है। एक ही सेल की दोहरी प्रोसेसिंग रोकता है)
                    grid[nr][nc] = 2;
                    fresh--;
                    queue.offer(new int[]{nr, nc});
                }
            }
        }
    }

    // यदि ताज़े संतरे शेष हैं तो वे पहुँच से बाहर हैं इसलिए -1 लौटाएँ। अन्यथा बीता हुआ समय लौटाएँ
    return fresh > 0 ? -1 : minutes;
}
```
