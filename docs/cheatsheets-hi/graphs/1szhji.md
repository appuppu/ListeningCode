# Deep Copying a Graph — संयुक्त अनिर्देशित ग्राफ के सभी नोड्स को डीप कॉपी द्वारा प्रतिलिपि बनाना

## समस्या का सार

एक संयुक्त अनिर्देशित ग्राफ के एक नोड का संदर्भ दिया गया है। पूरे ग्राफ की **डीप कॉपी (क्लोन)** बनानी है और क्लोन किए गए ग्राफ में इनपुट नोड के संगत नोड को लौटाना है। प्रत्येक नोड में एक पूर्णांक मान `val` और पड़ोसी नोड्स की सूची `neighbors` होती है। मूल ग्राफ के किसी भी नोड को संदर्भित किए बिना, पूरी तरह से स्वतंत्र नया ग्राफ बनाना आवश्यक है।

## मूल विचार

ग्राफ में साइकल होते हैं, इसलिए एक ही नोड को दो बार क्लोन न करने के लिए HashMap में "मूल नोड → क्लोन नोड" की मैपिंग दर्ज करते हैं। यदि नोड अभी तक विज़िट नहीं हुआ है तो क्लोन बनाकर HashMap में पंजीकृत करते हैं, और यदि पहले से विज़िट हो चुका है तो HashMap से क्लोन लौटाते हैं। इससे अनंत लूप को रोकते हुए सभी नोड्स की सटीक प्रतिलिपि बनाई जा सकती है।

## विचार प्रक्रिया

1. **ग्राफ का ट्रैवर्सल आवश्यक है**: पूरे ग्राफ की कॉपी बनाने के लिए, प्रारंभिक नोड से पहुँच योग्य सभी नोड्स को विज़िट करना आवश्यक है। ट्रैवर्सल के लिए DFS (डेप्थ फर्स्ट सर्च) को रिकर्शन से लागू करना स्वाभाविक है
2. **साइकल को संभालना अनिवार्य है**: अनिर्देशित ग्राफ में A→B→A जैसे साइकल अवश्य होते हैं। पहले से विज़िट किए गए नोड को दोबारा क्लोन करने का प्रयास करने पर अनंत लूप हो जाएगा, इसलिए "यह नोड पहले से क्लोन हो चुका है या नहीं" की जाँच करने की व्यवस्था आवश्यक है
3. **HashMap से मूल नोड और क्लोन की मैपिंग प्रबंधित करना**: `HashMap<Node, Node>` तैयार करके, कुंजी में "मूल नोड" और मान में "उसका क्लोन" सहेजते हैं। इससे किसी नोड का क्लोन पहले से बना है या नहीं, यह O(1) में जाँचा जा सकता है, और यदि क्लोन बना हुआ है तो उसे O(1) में प्राप्त किया जा सकता है
4. **रिकर्शन के प्रत्येक चरण में किया जाने वाला कार्य**: यदि वर्तमान नोड HashMap में मौजूद है, तो उसका क्लोन लौटाते हैं (पहले से विज़िट किया हुआ)। यदि मौजूद नहीं है, तो नया Node बनाकर HashMap में पंजीकृत करते हैं, मूल नोड के सभी पड़ोसी नोड्स पर रिकर्सिव रूप से क्लोन कॉल करते हैं, और लौटाए गए क्लोन को अपने neighbors में जोड़ते हैं
5. **पंजीकरण रिकर्शन से पहले करना होता है**: HashMap में पंजीकरण पड़ोसी नोड्स के रिकर्सिव कॉल से **पहले** करना आवश्यक है। पहले पंजीकरण न करने पर, साइकल से वापस अपने पास आने पर HashMap में क्लोन नहीं मिलेगा और अनंत लूप हो जाएगा
6. **अंतिम रूप से लौटाया जाने वाला मान**: प्रारंभिक नोड का क्लोन लौटाते हैं। इस क्लोन से सभी क्लोन नोड्स पड़ोसी सूची द्वारा जुड़े होते हैं

## पूर्वापेक्षित ज्ञान

### Node क्लास क्या है

ग्राफ के प्रत्येक शीर्ष को दर्शाने वाला क्लास। इसमें पूर्णांक मान `val` और पड़ोसी नोड्स की सूची `neighbors` होती है।

```java
class Node {
    public int val;
    public List<Node> neighbors;

    public Node(int val) {        // val निर्दिष्ट करके नोड बनाता है
        this.val = val;
        this.neighbors = new ArrayList<>();  // पड़ोसी सूची खाली स्थिति में आरंभ होती है
    }
}
```

### HashMap क्या है

कुंजी और मान के जोड़े सहेजने वाली डेटा संरचना। कुंजी निर्दिष्ट करके मान की खोज और प्राप्ति O(1) में की जा सकती है। इस समस्या में, कुंजी में "मूल नोड" और मान में "उसका क्लोन नोड" सहेजकर, विज़िट जाँच और क्लोन प्राप्ति दोनों कार्य एक साथ किए जाते हैं।

```java
HashMap<Node, Node> map = new HashMap<>();  // खाली HashMap बनाता है
map.put(original, clone);     // मूल नोड को कुंजी और क्लोन को मान के रूप में संग्रहीत करता है
map.containsKey(original);    // मूल नोड पंजीकृत है या नहीं boolean में लौटाता है → true
map.get(original);            // मूल नोड के संगत क्लोन को लौटाता है → clone
```

### DFS (डेप्थ फर्स्ट सर्च) क्या है

ग्राफ ट्रैवर्सल एल्गोरिदम में से एक। एक दिशा में यथासंभव गहराई तक जाता है, और जब आगे का रास्ता बंद हो जाता है तो वापस लौटकर दूसरी दिशा में आगे बढ़ता है। रिकर्सिव कॉल से स्वाभाविक रूप से लागू किया जा सकता है। यदि विज़िट प्रबंधन नहीं किया जाए तो साइकल के कारण अनंत लूप हो जाता है।

## गणनात्मक जटिलता

| | मान |
|---|---|
| Time | O(V + E) — प्रत्येक नोड को एक बार विज़िट करता है (V), और प्रत्येक किनारे को एक बार प्रोसेस करता है (E) |
| Space | O(V) — HashMap में V नोड्स की मैपिंग सहेजी जाती है, और रिकर्शन स्टैक भी अधिकतम V स्तर तक जाता है |

## कोड

```java
// इनपुट: संयुक्त अनिर्देशित ग्राफ का एक नोड node (Node प्रकार)। यदि ग्राफ खाली है तो null
// आउटपुट: पूरे ग्राफ की डीप कॉपी में इनपुट नोड के संगत क्लोन नोड (Node प्रकार) लौटाता है

// कुंजी=मूल नोड, मान=क्लोन नोड सहेजने वाला HashMap
// सभी रिकर्सिव कॉल में साझा करने के लिए क्लास के फ़ील्ड में रखा गया है
Map<Node, Node> map = new HashMap<>();

public Node cloneGraph(Node node) {
    // यदि ग्राफ खाली (null) है तो null लौटाकर समाप्त करता है
    if (node == null) return null;

    // यदि वर्तमान नोड पहले से क्लोन हो चुका है तो उसका क्लोन लौटाता है
    // यह साइकल के कारण होने वाले अनंत लूप को रोकने की व्यवस्था है
    if (map.containsKey(node))
        return map.get(node);

    // वर्तमान नोड का क्लोन बनाता है (इस समय neighbors खाली है)
    Node clone = new Node(node.val);

    // ध्यान दें: पंजीकरण अगले for लूप के रिकर्सिव कॉल से पहले किया जाता है
    // पहले पंजीकरण न करने पर, साइकल से वापस आने पर containsKey पहचान नहीं कर पाएगा और अनंत लूप हो जाएगा
    map.put(node, clone);

    // मूल नोड के सभी पड़ोसी नोड्स को रिकर्सिव रूप से क्लोन करके, क्लोन की पड़ोसी सूची में जोड़ता है
    // इससे मूल ग्राफ जैसी ही पड़ोसी संबंध क्लोन पक्ष में भी निर्मित होती है
    for (Node nbr : node.neighbors) {
        clone.neighbors
            .add(cloneGraph(nbr));
    }

    // पहली कॉल के लिए लौटाया गया clone, क्लोन किए गए पूरे ग्राफ का प्रारंभिक नोड बनता है
    return clone;
}
```
