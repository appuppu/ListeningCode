# Filling Distances to the Nearest Gate — ग्रिड में प्रत्येक खाली कमरे से निकटतम गेट तक की दूरी ज्ञात करना

## समस्या का सार

m×n का एक ग्रिड दिया गया है। प्रत्येक सेल "दीवार (-1)", "गेट (0)", या "खाली कमरा (Integer.MAX_VALUE)" में से कोई एक है। प्रत्येक खाली कमरे के सेल में निकटतम गेट तक की दूरी लिखनी है। जो कमरा किसी भी गेट तक नहीं पहुँच सकता, उसे Integer.MAX_VALUE ही रहने देना है।

## मूल विचार

प्रत्येक खाली कमरे से निकटतम गेट खोजने के बजाय, सभी गेटों से एक साथ BFS शुरू करना है। BFS के प्रत्येक चरण में दूरी 1, 2, 3… के अनुरूप आगे बढ़ा जाता है, इसलिए किसी सेल तक पहली बार पहुँचते ही उसकी न्यूनतम दूरी निश्चित हो जाती है।

## विचार प्रक्रिया

1. **प्रत्येक कमरे से गेट खोजना अकुशल है**: प्रत्येक खाली कमरे के लिए अलग-अलग BFS चलाने पर, कमरों की संख्या के बराबर BFS चलते हैं और गणना भार बढ़ जाता है। दृष्टिकोण को उलटकर गेट की ओर से कमरों की दिशा में खोज करने पर, सभी गेटों को प्रारंभ बिंदु बनाकर एक ही BFS में सभी कमरों की न्यूनतम दूरी ज्ञात हो जाती है
2. **कई गेटों से एक साथ शुरू करना (Multi-source BFS)**: सभी गेटों को कतार (queue) में डालकर BFS शुरू करना है। इससे पहले दूरी 1 वाले सभी कमरे संसाधित होते हैं, फिर दूरी 2 वाले कमरे संसाधित होते हैं। BFS की स्तर-क्रम (level-order) खोज के गुण के कारण, प्रत्येक कमरे तक पहली बार पहुँचने पर प्राप्त दूरी ही न्यूनतम दूरी होती है
3. **विज़िट की जाँच मान (value) से की जा सकती है**: खाली कमरे Integer.MAX_VALUE से आरंभ किए गए हैं। BFS द्वारा पहुँचे गए सेल में दूरी लिख दी जाती है, इसलिए केवल Integer.MAX_VALUE वाले सेल ही अभी तक नहीं देखे गए हैं। अलग से visited सरणी बनाने की आवश्यकता नहीं है
4. **दूरी की गणना: मूल सेल का मान + 1**: कतार से निकाले गए सेल (मूल) के मान में 1 जोड़ने पर आसन्न सेल (संतान) की दूरी प्राप्त होती है। गेट का मान 0 है, इसलिए आसन्न कमरे की दूरी 1, उसके आगे की दूरी 2 — इस प्रकार सही ढंग से प्रसारित होती है
5. **दीवारों और सीमा से बाहर के सेलों को छोड़ देना**: दीवार (-1) और गेट (0) का मान Integer.MAX_VALUE नहीं है, इसलिए अनदेखे सेल की जाँच में वे स्वतः बाहर हो जाते हैं। सीमा से बाहर के इंडेक्स को सीमा जाँच द्वारा अस्वीकार किया जाता है

## पूर्वापेक्षित ज्ञान

### BFS (चौड़ाई-पहले खोज) क्या है

ग्राफ या ग्रिड को "निकट से दूर" के क्रम में खोजने वाला एल्गोरिदम है। कतार (पहले आया, पहले गया) का उपयोग करके, प्रारंभ बिंदु से दूरी 1 वाले सभी नोड्स को पहले संसाधित किया जाता है, उसके बाद दूरी 2 वाले नोड्स को संसाधित किया जाता है। इस गुण के कारण प्रत्येक नोड तक की न्यूनतम दूरी सुनिश्चित होती है।

```java
Queue<int[]> queue = new LinkedList<>();  // BFS के लिए कतार बनाना
queue.offer(new int[]{0, 0});             // प्रारंभ बिंदु के निर्देशांक को कतार में जोड़ना
int[] cell = queue.poll();                // कतार के आगे से तत्व निकालना
queue.isEmpty();                          // कतार खाली है या नहीं जाँचना → true/false
```

### Multi-source BFS क्या है

सामान्य BFS में प्रारंभ बिंदु एक होता है, लेकिन Multi-source BFS में कई प्रारंभ बिंदुओं को कतार में डालकर शुरू किया जाता है। सभी प्रारंभ बिंदुओं से एक साथ लहर की तरह खोज फैलती है, और प्रत्येक सेल में निकटतम प्रारंभ बिंदु से दूरी दर्ज की जाती है।

```java
// सभी गेट (मान 0 वाले सेल) को प्रारंभ बिंदु के रूप में कतार में जोड़ना
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        if (rooms[i][j] == 0)
            queue.offer(new int[]{i, j});
// इस स्थिति में BFS शुरू करने पर सभी गेटों से एक साथ खोज शुरू होती है
```

### 4-दिशाओं में आसन्न सेल खोज

ग्रिड पर ऊपर, नीचे, बाएँ, दाएँ — 4 दिशाओं में जाने के लिए दिशा सदिश (direction vector) की सरणी का उपयोग करने से कोड सरल हो जाता है। प्रत्येक दिशा सदिश को वर्तमान निर्देशांक में जोड़कर आसन्न सेल का निर्देशांक प्राप्त किया जाता है।

```java
int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};  // ऊपर・नीचे・बाएँ・दाएँ के दिशा सदिश
for (int[] d : dirs) {
    int r = cell[0] + d[0];  // आसन्न सेल की पंक्ति संख्या
    int c = cell[1] + d[1];  // आसन्न सेल की स्तंभ संख्या
}
```

## गणना जटिलता

| | मान |
|---|---|
| Time | O(m × n) — प्रत्येक सेल को कतार में अधिकतम 1 बार जोड़ा जाता है, इसलिए सभी सेलों को 1-1 बार संसाधित किया जाता है |
| Space | O(m × n) — कतार में अधिकतम m×n सेल हो सकते हैं |

## कोड

```java
// इनपुट: m×n का पूर्णांक ग्रिड rooms (-1=दीवार, 0=गेट, Integer.MAX_VALUE=खाली कमरा)
// आउटपुट: कोई रिटर्न मान नहीं (void)। rooms को सीधे संशोधित करके, प्रत्येक खाली कमरे के सेल में निकटतम गेट तक की दूरी संग्रहीत करना
public void wallsAndGates(int[][] rooms) {
    // ग्रिड की पंक्तियों की संख्या प्राप्त करना
    int m = rooms.length;
    // यदि ग्रिड खाली है तो प्रक्रिया समाप्त करना
    if (m == 0) return;
    // ग्रिड की स्तंभों की संख्या प्राप्त करना
    int n = rooms[0].length;

    // BFS के लिए कतार बनाना। सेल के निर्देशांक {पंक्ति, स्तंभ} को संग्रहीत करना
    Queue<int[]> q = new LinkedList<>();

    // पूरे ग्रिड को स्कैन करके सभी गेट (मान 0 वाले सेल) को कतार में जोड़ना
    // इससे सभी गेट एक साथ BFS के प्रारंभ बिंदु के रूप में पंजीकृत हो जाते हैं (Multi-source BFS)
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (rooms[i][j] == 0)
                q.offer(new int[]{i, j});

    // ऊपर・नीचे・बाएँ・दाएँ — 4 दिशाओं को दर्शाने वाले दिशा सदिश। लूप में आसन्न सेलों की गणना के लिए उपयोग होते हैं
    int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

    // कतार खाली होने तक BFS जारी रखना। BFS के गुण के कारण कम दूरी वाले सेल पहले संसाधित होते हैं
    while (!q.isEmpty()) {
        // कतार के आगे से सेल निकालना। cell[0] पंक्ति संख्या है, cell[1] स्तंभ संख्या है
        int[] cell = q.poll();

        // 4 दिशाओं के आसन्न सेलों की जाँच करना
        for (int[] d : dirs) {
            // दिशा सदिश जोड़कर आसन्न सेल के निर्देशांक की गणना करना
            int r = cell[0] + d[0];
            int c = cell[1] + d[1];

            // सीमा से बाहर हो तो छोड़ देना
            if (r < 0 || r >= m || c < 0 || c >= n) continue;

            // यदि मान Integer.MAX_VALUE नहीं है तो छोड़ देना (दीवार・गेट・दूरी निश्चित कमरा)
            // इस जाँच से अलग visited सरणी के बिना भी पुनर्भ्रमण रोका जा सकता है
            if (rooms[r][c] != Integer.MAX_VALUE) continue;

            // मूल सेल की दूरी + 1 लिखना। गेट 0 है इसलिए आसन्न कमरा 1, उसके आगे 2 — इस प्रकार सही प्रसारण होता है
            // BFS दूरी के क्रम में सेलों को संसाधित करता है, इसलिए पहली बार पहुँची दूरी ही न्यूनतम दूरी होती है
            rooms[r][c] = rooms[cell[0]][cell[1]] + 1;
            // दूरी लिखे गए सेल को कतार में जोड़ना, ताकि आगे के कमरों की खोज जारी रहे
            q.offer(new int[]{r, c});
        }
    }
}
```
