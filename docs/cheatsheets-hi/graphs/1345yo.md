# Finding a Valid Order to Complete All Courses — सभी कोर्स पूरे करने के लिए एक वैध क्रम ज्ञात करना

## समस्या का सार

0 से `numCourses - 1` तक लेबल किए गए कोर्स और पूर्वापेक्षा शर्तों के जोड़े `[a, b]` (कोर्स `b` को कोर्स `a` से पहले पूरा करना आवश्यक है) की एक सरणी दी गई है। सभी कोर्स पूरे करने का एक **वैध क्रम** सरणी के रूप में लौटाएँ। यदि कोई वैध क्रम मौजूद नहीं है (चक्रीय निर्भरता होने पर) तो खाली सरणी लौटाएँ।

## मूल विचार

पूर्वापेक्षा शर्तों की निर्भरताओं को एक दिशात्मक ग्राफ से दर्शाया जा सकता है, और वैध क्रम उस ग्राफ के टोपोलॉजिकल सॉर्ट के अनुरूप होता है। इन-डिग्री 0 वाले नोड (बिना पूर्वापेक्षा वाले कोर्स) से क्रमशः प्रसंस्करण करते हुए, प्रसंस्कृत नोड की निर्भरताओं को हटाते जाएँ, तो चक्र न होने पर सभी नोड को सही क्रम में व्यवस्थित किया जा सकता है।

## विचार प्रक्रिया

1. **निर्भरताओं को ग्राफ के रूप में समझना**: पूर्वापेक्षा `[a, b]` का अर्थ है "`b` → `a`" दिशात्मक किनारा। सभी पूर्वापेक्षाओं को दिशात्मक ग्राफ के किनारों के रूप में व्यक्त करने पर, वैध क्रम इस ग्राफ का टोपोलॉजिकल सॉर्ट बन जाता है
2. **कौन से कोर्स से शुरू किया जा सकता है, यह निर्धारित करना**: जिन कोर्स की कोई पूर्वापेक्षा नहीं है, अर्थात जिनकी इन-डिग्री (उस नोड में आने वाले किनारों की संख्या) 0 है, उन्हें तुरंत लिया जा सकता है। प्रत्येक नोड की इन-डिग्री पहले से गणना कर लेने पर, प्रारंभ योग्य कोर्स को O(1) में पहचाना जा सकता है
3. **प्रारंभ योग्य कोर्स के प्रसंस्करण के बाद प्रभाव को प्रतिबिंबित करना**: किसी कोर्स को पूर्ण करने पर, उस कोर्स को पूर्वापेक्षा मानने वाले अन्य कोर्स की "शेष पूर्वापेक्षा संख्या" 1 कम हो जाती है। इसे इन-डिग्री के डिक्रीमेंट के रूप में व्यक्त किया जा सकता है। डिक्रीमेंट के परिणामस्वरूप जिस कोर्स की इन-डिग्री 0 हो जाती है, वह नया लेने योग्य कोर्स बन जाता है
4. **BFS से प्रसंस्करण क्रम का प्रबंधन करना**: इन-डिग्री 0 वाले कोर्स को कतार में डालें, कतार से निकालते समय उस कोर्स को परिणाम सरणी में जोड़ें, और आसन्न नोड की इन-डिग्री को डिक्रीमेंट करें। डिक्रीमेंट के बाद जो नोड 0 हो जाए उसे कतार में जोड़ें। यह दोहराव Kahn's एल्गोरिथ्म है
5. **चक्रीय निर्भरता का पता लगाना**: चक्र होने पर, चक्र के अंदर के सभी नोड की इन-डिग्री कभी 0 नहीं होती। इसलिए, प्रसंस्कृत कोर्स की संख्या `numCourses` से कम हो तो चक्र मौजूद है
6. **अंतिम रूप से क्या लौटाना है**: प्रसंस्कृत कोर्स की संख्या `numCourses` के बराबर हो तो परिणाम सरणी लौटाएँ, अन्यथा खाली सरणी लौटाएँ

## पूर्व ज्ञान

### टोपोलॉजिकल सॉर्ट क्या है

दिशात्मक अचक्रीय ग्राफ (DAG) के सभी नोड को इस प्रकार एक पंक्ति में व्यवस्थित करना कि सभी किनारे बाएँ से दाएँ की ओर हों। यदि किनारा `u → v` मौजूद है, तो क्रम में `u` अवश्य `v` से पहले आता है। चक्र होने पर टोपोलॉजिकल सॉर्ट संभव नहीं है।

### इन-डिग्री क्या है

किसी नोड में आने वाले किनारों की संख्या। इन-डिग्री 0 वाला नोड किसी अन्य नोड पर निर्भर नहीं होता, इसलिए उसे सबसे पहले प्रसंस्कृत किया जा सकता है।

```java
int[] indegree = new int[numCourses];  // प्रत्येक नोड की इन-डिग्री को 0 से आरंभ करना
indegree[a]++;  // नोड a में एक किनारा आता है इसलिए इन-डिग्री 1 बढ़ाना
--indegree[next];  // नोड next की इन-डिग्री 1 घटाना (एक पूर्वापेक्षा पूरी हुई)
```

### आसन्नता सूची (Adjacency List) क्या है

ग्राफ के प्रत्येक नोड के लिए, उस नोड से किनारे जाने वाले गंतव्य नोड को सूची में प्रबंधित करने वाली डेटा संरचना। `graph.get(u)` से नोड `u` से पहुँच योग्य सभी नोड प्राप्त किए जा सकते हैं।

```java
List<List<Integer>> graph = new ArrayList<>();       // संपूर्ण ग्राफ रखने वाली सूची
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());  // प्रत्येक नोड को खाली सूची आवंटित करना
graph.get(u).add(v);   // नोड u से नोड v तक का किनारा जोड़ना
graph.get(u);           // नोड u के सभी आसन्न नोड प्राप्त करना → [v, ...]
```

### Queue (कतार) क्या है

पहले अंदर, पहले बाहर (FIFO) डेटा संरचना। BFS में प्रसंस्करण की प्रतीक्षा कर रहे नोड को कतार से प्रबंधित किया जाता है।

```java
Queue<Integer> queue = new LinkedList<>();  // खाली कतार बनाना
queue.offer(0);   // कतार के अंत में तत्व 0 जोड़ना
queue.poll();      // कतार के आरंभ से तत्व निकालकर लौटाना → 0
queue.isEmpty();   // कतार खाली है या नहीं boolean में लौटाना → true
```

## कम्प्यूटेशनल जटिलता

| | मान |
|---|---|
| Time | O(V + E) — सभी नोड (कोर्स) और सभी किनारों (पूर्वापेक्षाओं) को एक-एक बार प्रसंस्कृत किया जाता है |
| Space | O(V + E) — आसन्नता सूची में सभी किनारे, इन-डिग्री सरणी, कतार और परिणाम सरणी में सभी नोड संग्रहीत होते हैं |

## कोड

```java
// इनपुट: पूर्णांक numCourses (कोर्स की कुल संख्या) और द्विविमीय पूर्णांक सरणी prerequisites (पूर्वापेक्षा शर्तों के जोड़ों की सरणी)
// आउटपुट: सभी कोर्स का वैध क्रम संग्रहीत int[] लौटाना। वैध क्रम न होने पर खाली int[] लौटाना
public int[] findOrder(int numCourses, int[][] prerequisites) {
    // आसन्नता सूची बनाना और प्रत्येक कोर्स को खाली सूची आवंटित करना
    // प्रत्येक इंडेक्स कोर्स नंबर से मेल खाता है, और उस कोर्स के पूरा होने पर लेने योग्य कोर्स की सूची रखता है
    List<List<Integer>> graph = new ArrayList<>();
    // इन-डिग्री सरणी: प्रत्येक कोर्स की अपूर्ण पूर्वापेक्षाओं की संख्या दर्शाती है
    int[] indegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++)
        graph.add(new ArrayList<>());

    // पूर्वापेक्षाओं से किनारे बनाना और इन-डिग्री की गणना करना
    // प्रत्येक जोड़े [a, b] के लिए किनारा b → a बनाना, कोर्स a कोर्स b पर निर्भर है यह दर्ज करना
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);  // किनारा pre[1] → pre[0] जोड़ना
        indegree[pre[0]]++;  // कोर्स pre[0] की इन-डिग्री 1 बढ़ाना
    }

    // इन-डिग्री 0 वाले कोर्स (बिना पूर्वापेक्षा) को कतार में जोड़ना
    // ये वे कोर्स हैं जिन्हें सबसे पहले लिया जा सकता है
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    // परिणाम सरणी और लिखने की स्थिति को आरंभ करना
    int[] result = new int[numCourses];
    int idx = 0;

    while (!queue.isEmpty()) {
        // कतार से कोर्स निकालना और क्रम में निश्चित करना
        int course = queue.poll();
        result[idx++] = course;

        // course के सभी आसन्न नोड next की इन-डिग्री 1 घटाना
        // यह दर्शाता है कि next की पूर्वापेक्षाओं में से एक course पूर्ण हो चुका है
        for (int next : graph.get(course))
            // डिक्रीमेंट के बाद 0 होने पर, next की सभी पूर्वापेक्षाएँ पूरी हुईं इसलिए कतार में जोड़ना
            if (--indegree[next] == 0)
                queue.offer(next);
    }

    // सभी कोर्स प्रसंस्कृत हुए या नहीं यह जाँचना
    // idx numCourses से कम हो तो चक्रीय निर्भरता मौजूद है इसलिए खाली सरणी लौटाना
    return idx == numCourses ? result : new int[0];
}
```
