# Counting the Number of Islands in a Grid — ग्रिड में द्वीपों की संख्या गिनना

## समस्या का सार

`'1'`（भूमि）और `'0'`（पानी）से बना एक 2D ग्रिड दिया गया है। क्षैतिज या ऊर्ध्वाधर दिशा में आसन्न भूमि सेलों के समूह को एक "द्वीप" माना जाता है, और ग्रिड में द्वीपों की **कुल संख्या** लौटानी है।

## मूल विचार

प्रत्येक भूमि सेल को एक नोड मानकर, आसन्न भूमि सेलों को Union-Find से जोड़ते जाएँ, तो अंत में शेष स्वतंत्र समूहों（मूल）की संख्या ही द्वीपों की संख्या होती है।

## विचार प्रक्रिया

1. **द्वीप "संबद्ध घटक" है**: आसन्न भूमि सेलों का समूह एक द्वीप होता है, इसलिए यह समस्या ग्रिड पर संबद्ध घटकों की संख्या ज्ञात करने की समस्या में बदल जाती है
2. **संबद्ध घटकों के प्रबंधन के लिए Union-Find उपयुक्त है**: Union-Find "दो तत्वों को एक ही समूह में मिलाने" और "दो तत्व एक ही समूह में हैं या नहीं यह जाँचने" की क्रियाएँ लगभग O(1) में कर सकता है। ग्रिड के प्रत्येक भूमि सेल को एक तत्व मानकर, आसन्न सेलों को क्रमशः मिलाने से संबद्ध घटक प्राप्त होते हैं
3. **2D ग्रिड के सेल को 1D इंडेक्स में बदलना**: Union-Find की सरणी एक-आयामी होती है, इसलिए सेल `(i, j)` को `i * n + j`（n स्तंभों की संख्या है）से एक पूर्णांक में बदला जाता है। इससे 2D ग्रिड के सेलों को Union-Find के तत्वों के रूप में उपयोग किया जा सकता है
4. **आरंभीकरण में भूमि सेलों की संख्या गिनना**: प्रत्येक भूमि सेल का `parent` स्वयं को सेट किया जाता है, और `count`（द्वीपों की संख्या）को भूमि सेलों की कुल संख्या से आरंभ किया जाता है। इस बिंदु पर प्रत्येक भूमि सेल एक स्वतंत्र द्वीप है
5. **आसन्न सेलों के साथ जोड़कर द्वीपों की संख्या घटाना**: ग्रिड को स्कैन करते हुए, प्रत्येक भूमि सेल के दाईं ओर और नीचे की ओर का आसन्न सेल भूमि होने पर `union` निष्पादित किया जाता है। जब `union` दो भिन्न समूहों को मिलाता है तब `count` 1 कम होता है। केवल दाईं और नीचे देखने से, बाईं और ऊपर की दिशाएँ पिछले सेल के स्कैन में पहले ही संसाधित हो चुकी होती हैं, इसलिए सभी आसन्न संबंधों को कवर किया जा सकता है
6. **अंत में शेष count ही उत्तर है**: सभी जोड़ पूर्ण होने के बाद का `count` स्वतंत्र संबद्ध घटकों की संख्या, अर्थात द्वीपों की संख्या है

## पूर्वापेक्षित ज्ञान

### Union-Find（विसंयुक्त समुच्चय डेटा संरचना）क्या है

अनेक तत्वों को समूहों में विभाजित करके प्रबंधित करने वाली डेटा संरचना। यह "दो तत्वों को एक ही समूह में मिलाना（union）" और "कोई तत्व किस समूह में है यह ज्ञात करना（find）" — ये दो क्रियाएँ प्रदान करती है। `parent` सरणी से प्रत्येक तत्व के पैरेंट को प्रबंधित किया जाता है, और वृक्ष संरचना से समूह को दर्शाया जाता है।

```java
int[] parent = new int[n];   // parent[i] = तत्व i का पैरेंट
int[] rank = new int[n];     // rank[i] = तत्व i को मूल मानने वाले वृक्ष की ऊँचाई की ऊपरी सीमा

// आरंभीकरण: प्रत्येक तत्व के पैरेंट को स्वयं सेट करना（प्रत्येक तत्व एक स्वतंत्र समूह है）
for (int i = 0; i < n; i++)
    parent[i] = i;
```

### पथ संपीड़न（Path Compression）क्या है

`find` क्रिया के दौरान, खोज पथ पर सभी नोड्स के पैरेंट को सीधे मूल से जोड़ने की अनुकूलन विधि। पुनरावर्ती रूप से मूल खोजने के बाद, `parent[x] = find(parent[x])` से पैरेंट को मूल में अपडेट किया जाता है। इससे अगली बार के `find` की जटिलता O(1) के करीब हो जाती है।

```java
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // पैरेंट को मूल से जोड़ना
    return parent[x];
}
```

### रैंक द्वारा मिलान（Union by Rank）क्या है

`union` क्रिया के दौरान, वृक्ष की ऊँचाई（rank）जो कम है उसे अधिक ऊँचाई वाले के नीचे जोड़ने की विधि। यह वृक्ष की ऊँचाई की वृद्धि को रोकती है और `find` की खोज दक्षता बनाए रखती है। केवल जब दोनों rank बराबर हों, तब मिलान के बाद rank 1 बढ़ाया जाता है।

```java
void union(int x, int y) {
    int rx = find(x), ry = find(y);  // प्रत्येक का मूल खोजना
    if (rx == ry) return;            // पहले से एक ही समूह में हैं तो कुछ नहीं करना
    if (rank[rx] < rank[ry])         // कम rank वाले को अधिक rank वाले के नीचे जोड़ना
        parent[rx] = ry;
    else if (rank[rx] > rank[ry])
        parent[ry] = rx;
    else {
        parent[ry] = rx;
        rank[rx]++;                  // rank बराबर होने पर ही rank बढ़ाना
    }
}
```

### 2D इंडेक्स से 1D इंडेक्स में रूपांतरण

2D ग्रिड के सेल `(i, j)` को एक-आयामी सरणी के इंडेक्स में बदलने का सूत्र। स्तंभों की संख्या को `n` मानें तो `id = i * n + j` से एक अद्वितीय पूर्णांक में बदला जा सकता है।

```java
int m = 3, n = 4;          // 3 पंक्तियाँ 4 स्तंभों वाला ग्रिड
int id = i * n + j;        // सेल(1, 2) → 1 * 4 + 2 = 6
```

## जटिलता

| | मान |
|---|---|
| Time | O(m × n × α(m × n)) — सभी सेलों को स्कैन किया जाता है और प्रत्येक सेल पर अधिकतम 2 बार union/find क्रिया की जाती है। α एकरमन फ़ंक्शन का प्रतिलोम है, जिसे व्यावहारिक रूप से स्थिरांक माना जा सकता है |
| Space | O(m × n) — parent सरणी और rank सरणी में प्रत्येक m × n तत्व संग्रहीत होते हैं |

## कोड

```java
// इनपुट: '1'（भूमि）और '0'（पानी）से बना char[][] grid
// आउटपुट: ग्रिड में द्वीपों की संख्या int के रूप में लौटाना

int[] parent;
int[] rank;
int count;

// पथ संपीड़न सहित find: तत्व x का मूल लौटाता है और पथ पर सभी नोड्स के पैरेंट को मूल से जोड़ता है
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);
    return parent[x];
}

// रैंक द्वारा मिलान: दो तत्वों को एक ही समूह में मिलाता है, सफल होने पर count 1 कम करता है
void union(int x, int y) {
    int rx = find(x), ry = find(y);
    if (rx == ry) return;       // पहले से एक ही समूह में हैं तो कुछ नहीं करना
    if (rank[rx] < rank[ry])
        parent[rx] = ry;       // कम rank वाले को अधिक rank वाले के नीचे जोड़ना
    else if (rank[rx] > rank[ry])
        parent[ry] = rx;
    else {
        parent[ry] = rx;
        rank[rx]++;             // rank बराबर होने पर ही rank बढ़ाना
    }
    count--;                    // दो समूह एक में मिल गए इसलिए द्वीपों की संख्या 1 कम करना
}

public int numIslandsUF(char[][] grid) {
    // ग्रिड की पंक्ति संख्या m और स्तंभ संख्या n प्राप्त करना
    int m = grid.length;
    int n = grid[0].length;
    // parent सरणी और rank सरणी को m * n आकार से बनाना
    parent = new int[m * n];
    rank = new int[m * n];
    // द्वीपों की संख्या को 0 से आरंभ करना（इसके बाद के स्कैन में भूमि सेलों की संख्या गिनी जाएगी）
    count = 0;

    // आरंभीकरण: प्रत्येक भूमि सेल के पैरेंट को स्वयं（i * n + j）सेट करना और count को भूमि सेलों की कुल संख्या बनाना
    // इस बिंदु पर प्रत्येक भूमि सेल एक स्वतंत्र द्वीप है
    for (int i = 0; i < m; i++)
      for (int j = 0; j < n; j++)
        if (grid[i][j] == '1') {
            parent[i * n + j] = i * n + j;  // 2D इंडेक्स को 1D में बदलकर पैरेंट को स्वयं सेट करना
            count++;                          // प्रत्येक भूमि सेल के लिए count 1 बढ़ाना
        }

    // प्रत्येक भूमि सेल के लिए, दाएँ और नीचे का आसन्न सेल भूमि होने पर मिलान करना
    // केवल दाईं और नीचे की 2 दिशाएँ जाँचने का कारण: बाईं और ऊपर की दिशाएँ पिछले सेल के स्कैन में पहले ही संसाधित हो चुकी हैं
    for (int i = 0; i < m; i++)
      for (int j = 0; j < n; j++)
        if (grid[i][j] == '1') {
            int id = i * n + j;              // वर्तमान सेल का 1D इंडेक्स गणना करना
            if (j + 1 < n && grid[i][j + 1] == '1')
                union(id, id + 1);           // दाएँ आसन्न भूमि सेल के साथ मिलान करना（id + 1 दाएँ आसन्न का 1D इंडेक्स है）
            if (i + 1 < m && grid[i + 1][j] == '1')
                union(id, id + n);           // नीचे आसन्न भूमि सेल के साथ मिलान करना（id + n नीचे आसन्न का 1D इंडेक्स है）
        }

    // count का प्रारंभिक मान（भूमि सेलों की कुल संख्या）union द्वारा सफल मिलान होने पर हर बार 1 कम होता गया है, और अंतिम मान ही द्वीपों की संख्या है
    return count;
}
```
