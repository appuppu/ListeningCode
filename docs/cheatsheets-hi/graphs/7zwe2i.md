# Capturing Surrounded Regions on a Board — बोर्ड पर घिरे हुए क्षेत्रों को कैप्चर करना

## समस्या का सार

`'X'` और `'O'` से बना m×n का बोर्ड दिया गया है। `'X'` से **पूरी तरह घिरे हुए** `'O'` के सभी क्षेत्रों को `'X'` में बदलना है। हालांकि, बोर्ड की **सीमा (बॉर्डर)** से जुड़े हुए `'O'` और उनसे संबद्ध `'O'` घिरे हुए नहीं हैं, इसलिए उन्हें बदलना नहीं है।

## मूल विचार

"घिरे हुए O को खोजने" के बजाय, "जो O घिरे हुए नहीं हैं (= सीमा से पहुँच योग्य O) उन्हें पहले चिह्नित करें, और शेष सभी O घिरे हुए हैं" — यह उलटी सोच अपनाएँ। सीमा के O से DFS द्वारा संबद्ध सेलों को सुरक्षित चिह्नित करें, और अंत में बोर्ड को एक बार स्कैन करें, तो निर्णय और परिवर्तन को अलग-अलग किया जा सकता है।

## विचार प्रक्रिया

1. **घिरे हुए नहीं O की विशेषता पर विचार करें**: `'O'` के कैप्चर न होने की शर्त यह है कि वह `'O'` बोर्ड की सीमा पर हो, या सीमा के `'O'` से ऊपर-नीचे-बाएँ-दाएँ की संबद्धता से जुड़ा हो। दूसरे शब्दों में, सीमा के `'O'` से पहुँच न सकने वाले सभी `'O'` घिरे हुए हैं
2. **सीमा से खोज शुरू करें**: बोर्ड की 4 भुजाओं (ऊपरी भुजा, निचली भुजा, बाईं भुजा, दाईं भुजा) को स्कैन करें, और जहाँ भी `'O'` मिले वहाँ से DFS शुरू करें। DFS से पहुँच योग्य सभी `'O'` "सुरक्षित (कैप्चर अयोग्य)" हैं
3. **सुरक्षित सेलों को मार्कर से अलग करें**: DFS में विज़िट किए गए `'O'` को अस्थायी मार्कर `'S'` (Safe) में बदलें। ऐसा करने से, DFS समाप्त होने के बाद बोर्ड पर जो `'O'` बचे हैं वे केवल "अभी तक चिह्नित नहीं = घिरे हुए" सेल हैं
4. **बोर्ड को एक बार स्कैन करके परिवर्तन और पुनर्स्थापन करें**: सभी सेलों को स्कैन करें, जो `'O'` वैसे ही बचे हैं वे घिरे हुए हैं इसलिए उन्हें `'X'` में बदलें। `'S'` वाले सेल सुरक्षित `'O'` हैं इसलिए उन्हें मूल `'O'` में पुनर्स्थापित करें। `'X'` वाले सेल वैसे ही रहने दें
5. **DFS की पुनरावर्ती संरचना**: प्रत्येक सेल से ऊपर-नीचे-बाएँ-दाएँ 4 दिशाओं में पुनरावर्ती रूप से खोज करें। सीमा से बाहर की जाँच और `'O'` के अलावा अन्य सेल पर रुकना, विज़िट-चेक का काम भी करता है (`'S'` में बदले गए सेल `'O'` नहीं हैं इसलिए दोबारा विज़िट नहीं होते)

## पूर्वापेक्षित ज्ञान

### DFS (गहराई-पहले खोज) क्या है

ग्राफ या ग्रिड की खोज करने वाला एल्गोरिदम है। किसी बिंदु से शुरू करके, एक दिशा में जहाँ तक जा सकते हैं वहाँ तक गहराई में जाएँ, रुक जाने पर वापस आकर दूसरी दिशा आज़माएँ। पुनरावर्ती कॉल से स्वाभाविक रूप से कार्यान्वित किया जा सकता है। ग्रिड पर ऊपर-नीचे-बाएँ-दाएँ 4 दिशाओं में पुनरावर्ती रूप से विज़िट करते हैं।

```java
// ग्रिड पर DFS का मूल पैटर्न
void dfs(char[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length          // सीमा से बाहर की जाँच
        || c < 0 || c >= grid[0].length
        || grid[r][c] != 'O')              // लक्ष्य-बाह्य सेल पर रुकें
        return;
    grid[r][c] = 'S';                      // विज़िट-चिह्न (पुनः विज़िट रोकथाम भी)
    dfs(grid, r + 1, c);                   // नीचे
    dfs(grid, r - 1, c);                   // ऊपर
    dfs(grid, r, c + 1);                   // दाएँ
    dfs(grid, r, c - 1);                   // बाएँ
}
```

### सीमा (बॉर्डर) सेलों को स्कैन करने की विधि

m×n के बोर्ड में, 4 भुजाओं के सेलों को सूचीबद्ध करने के लिए निम्नलिखित तरीका अपनाएँ। ऊपरी और निचली भुजा के लिए कॉलम को, बाईं और दाईं भुजा के लिए पंक्तियों को लूप करें।

```java
int m = board.length;    // पंक्तियों की संख्या
int n = board[0].length; // कॉलम की संख्या

// ऊपरी भुजा (पंक्ति 0) और निचली भुजा (पंक्ति m-1) के सभी कॉलम स्कैन करें
for (int j = 0; j < n; j++) {
    process(board[0][j]);      // ऊपरी भुजा
    process(board[m - 1][j]);  // निचली भुजा
}
// बाईं भुजा (कॉलम 0) और दाईं भुजा (कॉलम n-1) की सभी पंक्तियाँ स्कैन करें
for (int i = 0; i < m; i++) {
    process(board[i][0]);      // बाईं भुजा
    process(board[i][n - 1]);  // दाईं भुजा
}
```

### मार्कर तकनीक क्या है

बोर्ड के सेल को अस्थायी रूप से एक अलग अक्षर (यहाँ `'S'`) में बदलकर, "विज़िट किया गया" और "विज़िट नहीं किया गया" को अलग करने की विधि है। अलग से `boolean[][]` विज़िट ऐरे बनाने के बजाय, बोर्ड को ही स्थिति प्रबंधन के लिए उपयोग करते हैं। प्रोसेसिंग के अंत में मार्कर को मूल मान में पुनर्स्थापित करते हैं।

## गणनात्मक जटिलता

| | मान |
|---|---|
| Time | O(m × n) — सीमा से DFS प्रत्येक सेल को अधिकतम 1 बार विज़िट करता है, और अंतिम स्कैन भी सभी सेलों को 1 बार स्कैन करता है |
| Space | O(m × n) — DFS की पुनरावर्ती कॉल स्टैक सबसे खराब स्थिति में सभी सेलों जितनी गहराई तक पहुँच सकती है |

## कोड

```java
// इनपुट: 'X' और 'O' से बना m×n का 2D कैरेक्टर ऐरे board
// आउटपुट: board को इन-प्लेस संशोधित करता है। घिरे हुए 'O' को 'X' में बदलता है, कोई रिटर्न वैल्यू नहीं (void)

// सीमा से पहुँच योग्य O को मार्कर S में बदलने वाला DFS
void dfs(char[][] board, int r, int c, int m, int n) {
    // सीमा से बाहर या O के अलावा अन्य सेल हो तो कुछ न करें (विज़िट किया गया S भी अस्वीकृत होता है)
    // 'S' में बदले गए सेल 'O' नहीं हैं इसलिए दोबारा विज़िट नहीं होते
    if (r < 0 || r >= m
        || c < 0 || c >= n
        || board[r][c] != 'O')
        return;

    // सुरक्षित मार्कर S में बदलें (विज़िट-चिह्न का काम भी करता है)
    // अलग से boolean[][] बनाए बिना, बोर्ड को ही स्थिति प्रबंधन के लिए उपयोग करते हैं
    board[r][c] = 'S';

    // ऊपर-नीचे-बाएँ-दाएँ 4 दिशाओं में पुनरावर्ती खोज करें
    dfs(board, r + 1, c, m, n);
    dfs(board, r - 1, c, m, n);
    dfs(board, r, c + 1, m, n);
    dfs(board, r, c - 1, m, n);
}

public void solve(char[][] board) {
    // पंक्तियों और कॉलम की संख्या प्राप्त करें। इसके बाद सीमा जाँच और सीमा स्कैन में उपयोग करें
    int m = board.length;     // पंक्तियों की संख्या
    int n = board[0].length;  // कॉलम की संख्या

    // ऊपरी और निचली भुजा के प्रत्येक कॉलम से सीमा DFS शुरू करें
    // dfs केवल तभी प्रोसेस करता है जब लक्ष्य सेल 'O' हो, 'X' सेल पर कुछ किए बिना लौटता है
    for (int j = 0; j < n; j++) {
        dfs(board, 0, j, m, n);       // ऊपरी भुजा
        dfs(board, m - 1, j, m, n);   // निचली भुजा
    }

    // बाईं और दाईं भुजा की प्रत्येक पंक्ति से सीमा DFS शुरू करें
    // ऊपर के लूप के साथ मिलकर, बोर्ड की सभी 4 भुजाओं को प्रारंभ बिंदु के रूप में कवर करें
    for (int i = 0; i < m; i++) {
        dfs(board, i, 0, m, n);       // बाईं भुजा
        dfs(board, i, n - 1, m, n);   // दाईं भुजा
    }

    // बोर्ड को एक बार स्कैन करके परिवर्तन और पुनर्स्थापन करें
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (board[i][j] == 'O')
                board[i][j] = 'X';        // सीमा से पहुँच न सकने वाले = घिरे हुए O को X में बदलें
            else if (board[i][j] == 'S')
                board[i][j] = 'O';        // सीमा से पहुँच योग्य = सुरक्षित मार्कर को मूल O में पुनर्स्थापित करें
            // 'X' सेल में कोई परिवर्तन नहीं करें
        }
    }
}
```
