# Finding the Maximum Depth of a Binary Tree — 二分木の最も深い経路のノード数を求める

## 問題の本質

二分木の `root` ノードが与えられる。ルートノードから最も遠いリーフノードまでの経路に含まれる**ノードの数**（最大深さ）を整数で返す。空の木（root が null）の場合は 0 を返す。

## 核心のアイデア

木の最大深さは「左部分木の最大深さ」と「右部分木の最大深さ」のうち大きい方に1（現在のノード分）を足したものである。この再帰的な定義がそのまま解法になる。

## 思考プロセス

1. **木の深さは再帰的に定義できる**: あるノードの深さは、その左右の子を根とする部分木の深さに依存する。つまり、問題を小さな同じ構造の部分問題に分解できる
2. **ベースケースを決める**: ノードが null のとき、そこには何もないので深さは 0 である。これが再帰の終了条件になる
3. **左右の部分木それぞれの深さを求める**: 現在のノードから左の子に再帰し、左部分木の最大深さを得る。同様に右の子にも再帰し、右部分木の最大深さを得る
4. **左右の結果を統合する**: 最大深さとは最も長い経路なので、左右の深さのうち大きい方を選ぶ。`Math.max(left, right)` で取得する
5. **現在のノードを加算して返す**: 左右の深さの最大値に 1 を足すことで、現在のノードを含めた深さを親に返す。この 1 は「現在のノード自身」を数えている

## 前提知識

### TreeNode（二分木のノード）とは

二分木の各ノードを表すクラス。値 `val`、左の子 `left`、右の子 `right` の3つのフィールドを持つ。子が存在しない場合は null が入る。

```java
public class TreeNode {
    int val;              // ノードが保持する値
    TreeNode left;        // 左の子ノード（なければnull）
    TreeNode right;       // 右の子ノード（なければnull）
}
```

### 再帰（Recursion）とは

関数が自分自身を呼び出す手法。木構造では、各ノードに対して同じ処理を部分木に適用する際に使う。必ずベースケース（再帰を止める条件）を定義し、無限ループを防ぐ。

```java
// 再帰の基本構造
public int recursive(TreeNode node) {
    if (node == null) return 0;           // ベースケース: 再帰の終了条件
    return recursive(node.left);          // 再帰呼び出し: 部分問題を解く
}
```

### Math.max とは

2つの整数のうち大きい方を返す Java の標準メソッド。

```java
Math.max(3, 5);    // → 5
Math.max(0, 0);    // → 0
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 全ノードを1回ずつ訪問する |
| Space | O(h) — 再帰のコールスタックが木の高さ分だけ積まれる。最悪ケース（偏った木）ではO(n) |

## コード

```java
// 入力: 二分木のルートノード root（TreeNode 型、null の場合もある）
// 出力: 木の最大深さを表す整数を返す
public int maxDepth(TreeNode root) {
    // ベースケース: ノードがなければ深さは0
    // リーフノードの子（null）に到達したときに再帰が止まる
    if (root == null) return 0;

    // 左部分木の最大深さを再帰的に求める
    // 左の子をルートとする部分木に対して同じ処理を繰り返し、最終的にベースケースに到達して値が返ってくる
    int left = maxDepth(root.left);

    // 右部分木の最大深さを再帰的に求める
    // 左と同様に、右の子をルートとする部分木の深さを求める
    int right = maxDepth(root.right);

    // 左右の深い方に現在のノード分の1を足して返す
    // Math.max(left, right) で最も長い経路のノード数となる深い方の部分木を選択する
    // +1 は現在のノード root 自身を数えている。親ノードはこの戻り値を受け取り、自身の計算に使う
    return 1 + Math.max(left, right);
}
```
