# Traversing a Binary Tree Level by Level — 二分木のノードをレベルごとに分けてリストにする

## 問題の本質

二分木の `root` が与えられる。木のノードを**レベル（深さ）ごと**にグループ化し、各レベルのノード値を左から右の順に格納した `List<Integer>` を、上のレベルから順に並べた `List<List<Integer>>` として返す。

## 核心のアイデア

キュー（Queue）を使えば、ノードを「幅優先」で左から右へ処理できる。各レベルの開始時にキューのサイズを記録し、そのサイズ分だけノードを取り出せば、レベルの区切りを正確に管理できる。

## 思考プロセス

1. **レベルごとに処理するには幅優先探索（BFS）が適している**: 深さ優先探索（DFS）は1つの枝を深く辿るため、レベル単位のグループ化が難しい。BFSはノードを浅い順に処理するので、レベルごとの走査に自然に対応する
2. **BFSの実現にはキューを使う**: キューはFIFO（先入れ先出し）のデータ構造であり、「先に追加した（浅い）ノードから順に処理する」というBFSの動作を実現できる
3. **レベルの区切りをどう判定するか**: 各レベルの処理を開始する時点で、キューに入っているノードはすべて同じレベルに属している。このタイミングで `queue.size()` を変数 `size` に記録し、`size` 回だけノードを取り出せば、ちょうど1レベル分のノードを処理できる
4. **取り出したノードの子を次のレベルとしてキューに追加する**: 各ノードを取り出す際に、その左右の子ノードをキューに追加する。これらの子ノードは現在のレベルの処理中には取り出されない（`size` で回数を制限しているため）。次のwhileループのイテレーションで次のレベルとして処理される
5. **各レベルの結果をリストに集めて返す**: レベルごとに `List<Integer>` を作成し、そのレベルのノード値を格納する。1レベル分の処理が終わったら、このリストを最終結果の `List<List<Integer>>` に追加する
6. **キューが空になったら全レベルの処理が完了**: すべてのノードを取り出し終えるとキューが空になり、whileループが終了する。この時点で結果リストには上のレベルから順にすべてのレベルのノード値が格納されている

## 前提知識

### Queue（キュー）とは

先入れ先出し（FIFO）のデータ構造。最初に追加した要素が最初に取り出される。JavaではインターフェースQueueの実装としてLinkedListを使う。

```java
Queue<TreeNode> queue = new LinkedList<>();  // 空のキューを作成
queue.offer(node);   // キューの末尾にnodeを追加する
queue.poll();        // キューの先頭から要素を取り出して返す（キューから削除される）
queue.size();        // キューに入っている要素の数を返す → int
queue.isEmpty();     // キューが空かどうかをbooleanで返す
```

### BFS（幅優先探索）とは

グラフや木を「幅」方向に探索するアルゴリズム。始点に近いノードから順に処理する。キューを使って実装する。木に適用すると、レベル0→レベル1→レベル2…の順にノードを訪問する。

### TreeNode の構造

二分木の各ノードを表すクラス。値 `val`、左の子 `left`、右の子 `right` の3つのフィールドを持つ。

```java
class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 木のすべてのノードを1回ずつ処理する |
| Space | O(n) — キューに最大で木の最も幅が広いレベルのノード数だけ格納される（最悪ケースでn/2） |

## コード

```java
// 入力: 二分木のルートノード root
// 出力: 各レベルのノード値をリストにまとめた List<List<Integer>> を返す
List<List<Integer>> levelOrder(TreeNode root) {
    // 各レベルのノード値リストを格納する最終結果
    List<List<Integer>> result = new ArrayList<>();

    // rootがnullの場合は木が空なので、空のresultをそのまま返す
    if (root == null) return result;

    // BFS用のキューを作成し、ルートノードを追加する
    // この時点でキューにはレベル0のノードが1つだけ入っている
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);

    // キューが空になるまでレベルごとに処理を繰り返す
    // キューが空になったとき、すべてのノードの処理が完了している
    while (!queue.isEmpty()) {
        // 注意: この値をループの前に変数に保存しておく必要がある
        // forループ内でキューに子ノードを追加するとキューのサイズが変わるため、
        // queue.size() を直接forループの条件に使うと正しいレベルの区切りにならない
        int size = queue.size();
        // 現在のレベルのノード値を格納するリスト
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < size; i++) {
            // キューの先頭からノードを取り出す
            TreeNode node = queue.poll();
            // ノードの値を現在のレベルのリストに追加する
            level.add(node.val);

            // 左の子が存在すればキューに追加する（次のレベルで処理される）
            if (node.left != null)
                queue.offer(node.left);
            // 右の子が存在すればキューに追加する
            // 子ノードの追加順序を左→右にすることで、次のレベルでもノードが左から右の順に処理される
            if (node.right != null)
                queue.offer(node.right);
        }

        // 1レベル分の処理が完了したので結果に追加する
        result.add(level);
    }
    // すべてのレベルのノード値が上から順に格納されたresultを返す
    return result;
}
```
