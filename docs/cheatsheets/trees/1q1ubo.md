# Constructing a Binary Tree From Traversal Orders — 前順走査と中順走査から元の二分木を復元する

## 問題の本質

整数配列 `preorder`（前順走査）と `inorder`（中順走査）が与えられる。この2つの走査結果から、元の二分木を構築して返す。前順走査は「根→左→右」の順、中順走査は「左→根→右」の順で要素が並んでいる。

## 核心のアイデア

前順走査の先頭は必ず現在の部分木の根であり、その根の値が中順走査のどこに位置するかを見れば、中順走査を「左部分木の要素」と「右部分木の要素」に分割できる。この分割を再帰的に繰り返せば木全体を復元できる。

## 思考プロセス

1. **前順走査の先頭は根である**: 前順走査は「根→左→右」の順に要素を並べるので、配列の先頭要素は必ず木全体の根ノードである。この性質は部分木にも再帰的に成り立つ
2. **中順走査で根の位置がわかれば左右を分割できる**: 中順走査は「左→根→右」の順なので、根の値が中順走査の位置 `mid` にあるとき、`mid` より左の要素はすべて左部分木に属し、`mid` より右の要素はすべて右部分木に属する
3. **根の位置を高速に求めたい**: 毎回中順走査を線形探索すると全体でO(n²)かかる。事前にHashMapで「値→中順走査でのインデックス」を記録しておけば、根の位置をO(1)で取得できる
4. **配列コピーではなくインデックス境界で部分木の範囲を表現する**: 再帰のたびに配列をコピーするとO(n²)の空間が必要になる。中順走査の範囲を `inLeft` と `inRight` の2つのインデックスで表現すれば、配列コピーなしで部分木の範囲を指定できる
5. **前順走査のポインタをグローバルに進める**: 前順走査は「根→左部分木全体→右部分木全体」の順に並んでいるので、グローバルなポインタ `preIdx` を用意して根を1つ取り出すたびにインクリメントすれば、左部分木の再帰が終わった時点でポインタは自然に右部分木の根を指す
6. **左部分木を先に構築する**: 前順走査の順序は「根→左→右」なので、根を取り出した後は必ず左部分木を先に再帰構築し、その後に右部分木を構築する。この順序を守ることで `preIdx` が正しく進む

## 前提知識

### 前順走査（Preorder Traversal）とは

二分木を「根→左部分木→右部分木」の順に訪問する走査方法。配列の先頭が必ず根ノードの値になる。

```
        3
       / \
      9   20
         / \
        15   7

前順走査: [3, 9, 20, 15, 7]  ← 先頭の3が根
```

### 中順走査（Inorder Traversal）とは

二分木を「左部分木→根→右部分木」の順に訪問する走査方法。根の値を基準に、左側の要素が左部分木、右側の要素が右部分木に属する。

```
中順走査: [9, 3, 15, 20, 7]  ← 3の左にある[9]が左部分木、右にある[15,20,7]が右部分木
```

### HashMap とは

キーと値のペアを保存するデータ構造。キーを指定して値の検索・取得がO(1)でできる。

```java
HashMap<Integer, Integer> map = new HashMap<>();  // 空のHashMapを作成
map.put(3, 1);           // キー3に値1を格納する
map.get(3);              // キー3に対応する値を返す → 1
```

### TreeNode とは

二分木の1つのノードを表すクラス。値 `val`、左の子 `left`、右の子 `right` を持つ。

```java
TreeNode root = new TreeNode(3);    // 値3のノードを作成する
root.left = new TreeNode(9);        // 左の子に値9のノードを設定する
root.right = new TreeNode(20);      // 右の子に値20のノードを設定する
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 各ノードを1回ずつ処理し、HashMapによる検索はO(1)で済む |
| Space | O(n) — HashMapにn個の要素を保存し、再帰スタックは最悪O(n)（偏った木の場合） |

## コード

```java
// 入力: 整数配列 preorder（前順走査）と整数配列 inorder（中順走査）
// 出力: 復元した二分木の根ノード TreeNode を返す

// キー=中順走査の値、バリュー=その値の中順走査でのインデックス を保存するHashMap
// 根の値から中順走査での位置をO(1)で取得するために使う
Map<Integer, Integer> map = new HashMap<>();
// 前順走査配列の中で「次に取り出すべき根の位置」を指すグローバルポインタ
// 再帰呼び出しのたびにインクリメントして進めていく
int preIdx = 0;

public TreeNode buildTree(int[] preorder, int[] inorder) {
    // 中順走査の各値とインデックスをHashMapに登録する
    // これにより、任意の値が中順走査のどの位置にあるかを即座に引けるようになる
    for (int i = 0; i < inorder.length; i++)
        map.put(inorder[i], i);

    // 配列全体の範囲（inLeft=0, inRight=末尾）を指定して再帰を開始する
    return helper(preorder, 0, inorder.length - 1);
}

// inLeft, inRight は中順走査配列上での現在の部分木の範囲を表す
TreeNode helper(int[] preorder, int inLeft, int inRight) {
    // 部分木の範囲が空（inLeft > inRight）なら子ノードは存在しない
    if (inLeft > inRight) return null;

    // 前順走査の現在位置から根の値を取り出し、ポインタを進める
    int rootVal = preorder[preIdx++];
    TreeNode root = new TreeNode(rootVal);

    // 根の値が中順走査のどこにあるかをHashMapで取得する
    // mid は中順走査において左部分木と右部分木の境界を示す
    int mid = map.get(rootVal);

    // 注意: 前順走査は「根→左→右」の順に並んでいるので、左部分木を必ず先に構築する
    // この順序により preIdx が正しく右部分木の根を指すようになる
    // 中順走査の inLeft から mid-1 までが左部分木の範囲
    root.left = helper(preorder, inLeft, mid - 1);
    // 中順走査の mid+1 から inRight までが右部分木の範囲
    root.right = helper(preorder, mid + 1, inRight);

    // 構築した root ノードを返す。再帰が全て完了すると木全体の根ノードが返る
    return root;
}
```
