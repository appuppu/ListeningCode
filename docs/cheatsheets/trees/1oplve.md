# Finding the Diameter of a Binary Tree — 二分木の中で最も長いパス（辺の数）を求める

## 問題の本質

二分木の `root` が与えられる。木の中の任意の2ノード間のパスのうち、最も長いものの長さ（辺の数）を返す。このパスは根を通る必要はない。

## 核心のアイデア

任意のノードにおける「左部分木の高さ＋右部分木の高さ＋2」がそのノードを経由する最長パスの辺数になる。DFSで各ノードの高さを求めながら、この値の最大値を追跡すれば、1回の走査で直径が求まる。

## 思考プロセス

1. **直径はどこかのノードを「頂点」として通過する**: 最長パスは必ずある1つのノードを最も高い位置（折り返し地点）として、そのノードの左部分木のどこかから右部分木のどこかへ向かう形になる。したがって、各ノードについて「そのノードを頂点とするパスの長さ」を求め、その最大値が直径になる
2. **頂点を通るパスの長さは左右の高さで決まる**: あるノードを頂点とするパスの辺数は「左部分木の高さ＋右部分木の高さ＋2」で計算できる。左の高さが最も深い左側ノードまでの辺数、右の高さが最も深い右側ノードまでの辺数であり、頂点から左右にそれぞれ1辺ずつ加わるため＋2になる
3. **高さの定義を「辺の数」に合わせる**: ノードの高さを「そのノードから最も遠い葉までの辺数」と定義すると、葉ノードの高さは0、nullノードの高さは-1になる。nullを-1とすることで、葉ノードの高さが `1 + max(-1, -1) = 0` と自然に計算できる
4. **DFSで高さを返しながら直径を更新する**: 後行順（ポストオーダー）のDFSを使い、各ノードで左右の子の高さを再帰的に取得する。取得した左右の高さから「そのノードを頂点とするパスの長さ」を計算してグローバル変数 `maxDiameter` を更新し、戻り値としてはそのノード自身の高さ `1 + max(left, right)` を返す
5. **グローバル変数で最大値を追跡する**: DFSの戻り値は「高さ」であり「直径」ではないので、直径の最大値はグローバル変数 `maxDiameter` に記録する。各ノードで `left + right + 2` と現在の `maxDiameter` を比較し、大きい方を保持する
6. **最終的に返すもの**: DFSが全ノードを走査し終えた後、`maxDiameter` に格納された値が木全体の直径である

## 前提知識

### 二分木の高さ（height）とは

あるノードから最も遠い葉ノードまでのパスに含まれる辺の数。葉ノードの高さは0、nullノードの高さは-1と定義する。親ノードの高さは `1 + max(左の子の高さ, 右の子の高さ)` で求まる。

```
      1          ノード1の高さ: 2（1→2→4 の辺数）
     / \         ノード2の高さ: 1（2→4 の辺数）
    2   3        ノード3の高さ: 0（葉ノード）
   /             ノード4の高さ: 0（葉ノード）
  4
```

### 再帰によるDFS（深さ優先探索）とは

木の各ノードを再帰的に訪問する手法。後行順（ポストオーダー）では、左の子→右の子→自分の順に処理する。子の結果を使って親の値を計算する場合に適している。

```java
int dfs(TreeNode node) {
    if (node == null) return -1;   // ベースケース: nullノードは高さ-1
    int left = dfs(node.left);     // 左部分木を再帰的に処理する
    int right = dfs(node.right);   // 右部分木を再帰的に処理する
    return 1 + Math.max(left, right);  // 自分の高さを計算して返す
}
```

### Math.max とは

2つの値のうち大きい方を返すJavaの標準メソッド。

```java
Math.max(3, 5);    // → 5
Math.max(-1, -1);  // → -1
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 全ノードを1回ずつ訪問するDFSを1回行うだけで済む |
| Space | O(n) — 再帰呼び出しのコールスタックが最大でn段（偏った木の場合）になる |

## コード

```java
// 入力: 二分木のルートノード root
// 出力: 木の直径（任意の2ノード間の最長パスの辺数）を int で返す

// DFSの走査中に発見された最大の直径を保持するグローバル変数
// 初期値が0なのは、ノードが1つだけの木の直径が0だからである
int maxDiameter = 0;

// 各ノードの高さを返しつつ、副作用として maxDiameter を更新する再帰関数
int dfs(TreeNode node) {
    // nullノードの高さは-1（辺が存在しないことを表す）
    // -1を返すことで、親（葉ノード）の高さが 1 + max(-1, -1) = 0 と正しく求まる
    if (node == null) return -1;

    // 左部分木の高さを再帰的に取得する
    int left = dfs(node.left);
    // 右部分木の高さを再帰的に取得する
    int right = dfs(node.right);

    // 現在のノードを頂点とするパスの辺数（left + right + 2）で直径の最大値を更新する
    // +2 は現在のノードから左右の子への2辺を加えるため
    maxDiameter = Math.max(
        maxDiameter,
        left + right + 2);

    // 現在のノードの高さを親に返す（これは直径ではなく高さであることに注意）
    // 親ノードが自身のパス長を計算するために使う値である
    return 1 + Math.max(left, right);
}

public int diameterOfBinaryTree(TreeNode root) {
    // DFSで全ノードを走査し、各ノードを頂点とするパスの長さから maxDiameter を更新する
    dfs(root);
    // 走査完了後の maxDiameter が木全体の直径である
    return maxDiameter;
}
```
