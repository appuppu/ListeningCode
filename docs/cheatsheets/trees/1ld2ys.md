# Finding the Lowest Common Ancestor in a BST — BST内の2ノードの最も深い共通祖先を見つける

## 問題の本質

二分探索木（BST）と、木に存在する2つのノード `p`, `q` が与えられる。両方のノードを子孫として持つ最も深いノード（最小共通祖先: LCA）を返す。ノード自身も自分の子孫とみなす。

## 核心のアイデア

BSTでは左の子孫はすべて現在のノードより小さく、右の子孫はすべて大きい。`p` と `q` が現在のノードに対して左右に分かれた瞬間、そのノードがLCAである。

## 思考プロセス

1. **BSTの性質を活用できる**: BSTでは任意のノードに対して、左部分木の全値 < ノードの値 < 右部分木の全値という順序が保証されている。この性質により、`p` と `q` がどちらの部分木にいるかをノードの値の比較だけで判定できる
2. **両方が左にいるなら左へ進む**: `p.val` と `q.val` の両方が現在のノードの値より小さい場合、`p` と `q` はどちらも左部分木に存在する。LCAもその左部分木の中にあるので、左の子に移動する
3. **両方が右にいるなら右へ進む**: `p.val` と `q.val` の両方が現在のノードの値より大きい場合、`p` と `q` はどちらも右部分木に存在する。LCAもその右部分木の中にあるので、右の子に移動する
4. **左右に分かれたらそのノードがLCA**: `p` と `q` が現在のノードの左右に分かれた場合（一方が小さく他方が大きい）、これより深い単一の部分木に両方が含まれることはない。したがって現在のノードがLCAである。`p` または `q` が現在のノードと等しい場合も、自身が子孫とみなせるのでLCAとなる
5. **再帰を使わずに反復で実現できる**: 各ステップで左か右の一方向にしか進まないため、再帰のコールスタックは不要である。whileループで現在のノードを更新していくだけでよく、空間計算量をO(1)にできる

## 前提知識

### 二分探索木（BST）とは

各ノードが「左の子孫 < 自分 < 右の子孫」という順序を満たす二分木。この性質により、値の大小比較だけでノードがどの部分木に属するかを判定できる。

```
        6
       / \
      2    8
     / \  / \
    0   4 7   9
```

この木でノード2とノード8のLCAは6。ノード2とノード4のLCAは2（ノード2は自身の子孫でもある）。

### 最小共通祖先（LCA）とは

2つのノード `p`, `q` の共通の祖先のうち、最も深い（根から最も遠い）ノード。`p` または `q` 自身がもう一方の祖先である場合、そのノード自身がLCAとなる。

### TreeNode の構造

BSTの各ノードを表すクラス。値 `val`、左の子 `left`、右の子 `right` を持つ。

```java
TreeNode node = new TreeNode(6);   // 値6のノードを作成
node.val;                           // ノードの値を取得 → 6
node.left;                          // 左の子ノードを取得
node.right;                         // 右の子ノードを取得
```

## 計算量

| | 値 |
|---|---|
| Time | O(h) — 木の高さ分だけ探索する。平衡BSTならO(log n) |
| Space | O(1) — 反復処理のため追加のメモリを使用しない |

## コード

```java
// 入力: BSTのルートノード root、木に存在する2つのノード p と q
// 出力: p と q の最小共通祖先（LCA）にあたる TreeNode を返す
TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
    // 現在の探索位置をルートに初期化する。whileループで更新していく
    TreeNode node = root;

    // nodeがnullでない間、探索を繰り返す
    while (node != null) {
        // pとqの両方が現在のノードより小さいか判定する
        if (p.val < node.val && q.val < node.val) {
            // 両方とも左部分木に存在するので、LCAも左部分木の中にある
            node = node.left;
        // pとqの両方が現在のノードより大きいか判定する
        } else if (p.val > node.val && q.val > node.val) {
            // 両方とも右部分木に存在するので、LCAも右部分木の中にある
            node = node.right;
        } else {
            // pとqが左右に分かれた（または一方が現在のノードと等しい）
            // これより深い単一の部分木には両方のノードが収まらないのでLCA確定
            return node;
        }
    }
    // 問題の制約上、pとqは木に存在するため必ず上のreturnで終了しここには到達しない
    return null;
}
```
