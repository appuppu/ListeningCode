# Finding the Kth Smallest Element in a BST — BSTからk番目に小さい要素を見つける

## 問題の本質

二分探索木（BST）の根ノード `root` と整数 `k` が与えられる。BST内の全ノードの値のうち、**k番目に小さい値**を返す。木には少なくともk個のノードが存在することが保証されている。

## 核心のアイデア

BSTを中順走査（in-order traversal）すると、ノードの値が昇順に並ぶ。したがって、中順走査でk番目に訪問したノードの値がそのまま答えになる。全ノードを走査する必要はなく、k番目に到達した時点で即座に終了できる。

## 思考プロセス

1. **BSTの性質を活用する**: BSTでは任意のノードについて「左部分木の全ノード < 自身 < 右部分木の全ノード」が成り立つ。この性質から、中順走査（左→自身→右）を行うとノードの値が昇順に得られる
2. **k番目に小さい値は中順走査のk番目**: 中順走査で得られる昇順列のk番目の要素が答えなので、走査しながらカウントすればよい
3. **再帰ではなくスタックによる反復的走査を選ぶ**: 再帰だとk番目に到達しても即座にreturnできない（コールスタックの巻き戻しが必要）。スタックを使った反復的走査なら、k番目を見つけた瞬間にreturnで抜けられる
4. **スタックで中順走査を実現する方法**: 現在のノードから左の子を辿り続けてスタックに積む。左端に到達したらスタックからpopし、そのノードを「訪問」する。次に右の子に移動して同じ処理を繰り返す
5. **カウンタでk番目を検出する**: ノードをpopして訪問するたびにkをデクリメントする。kが0になった時点でそのノードの値が答えである
6. **最終的に返すもの**: kが0になった時点のノードの値 `curr.val` を返す

## 前提知識

### BST（二分探索木）の中順走査とは

二分探索木を「左部分木→自身→右部分木」の順番で訪問する走査方法。BSTに対して中順走査を行うと、ノードの値が昇順（小さい順）に得られる。

```
例:     5
       / \
      3   7
     / \
    2   4

中順走査の結果: 2, 3, 4, 5, 7（昇順）
```

### Stack とは

後入れ先出し（LIFO）のデータ構造。最後に追加した要素が最初に取り出される。中順走査では、左の子を辿る過程で通過した親ノードを記憶しておくために使う。

```java
Stack<TreeNode> stack = new Stack<>();  // 空のスタックを作成
stack.push(node);      // nodeをスタックの一番上に追加する
stack.pop();           // スタックの一番上の要素を取り出して返す
stack.isEmpty();       // スタックが空かどうかをbooleanで返す
```

### 反復的中順走査のパターン

スタックを使った中順走査は「左端まで潜る→popして訪問→右の子に移動」を繰り返す。ループの継続条件は「現在のノードがnullでない、またはスタックが空でない」のいずれかが真である限り続ける。

```java
TreeNode curr = root;
while (curr != null || !stack.isEmpty()) {
    while (curr != null) {       // 左端まで潜る
        stack.push(curr);
        curr = curr.left;
    }
    curr = stack.pop();          // 訪問（ここで昇順にノードが得られる）
    curr = curr.right;           // 右の子に移動
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(h + k) — 左端までh回下降し、k個のノードをpopする |
| Space | O(h) — スタックに最大で木の高さh個のノードが積まれる |

## コード

```java
// 入力: 二分探索木の根ノード root と整数 k
// 出力: BST内でk番目に小さいノードの値を int で返す
public int kthSmallest(TreeNode root, int k) {
    // 左の子を辿る過程で通過した親ノードを一時的に保存し、後で戻ってくるためのスタック
    Stack<TreeNode> stack = new Stack<>();
    // 現在注目しているノードを指すポインタ
    TreeNode curr = root;

    // currがnullでもスタックにノードが残っていれば未訪問ノードがあるので続ける
    while (curr != null || !stack.isEmpty()) {
        // 左端まで潜り、通過するノードをスタックに積む（現在の部分木の最小値に到達する）
        while (curr != null) {
            stack.push(curr);
            curr = curr.left;
        }

        // popしたノードが中順走査で次に訪問すべきノード（未訪問のうち最小の値を持つ）
        curr = stack.pop();
        // popは中順走査で1つ訪問したことに相当するので、残り訪問回数を1減らす
        k--;

        // kが0になったノードがk番目に小さい要素なので、即座に値を返して終了する
        if (k == 0)
            return curr.val;

        // 右部分木があれば次のイテレーションでその左端まで潜る。なければcurrがnullになりスタックから親をpopする
        curr = curr.right;
    }
    // 問題の制約上、木には少なくともk個のノードが存在するのでここには到達しない
    return -1;
}
```
