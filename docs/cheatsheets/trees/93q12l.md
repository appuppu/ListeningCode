# Validating a Binary Search Tree — 二分木が有効な二分探索木かを判定する

## 問題の本質

二分木の `root` が与えられる。その木が有効な二分探索木（BST）であるかを判定する。有効なBSTとは、すべてのノードにおいて、左部分木のすべての値がそのノードの値より**厳密に小さく**、右部分木のすべての値がそのノードの値より**厳密に大きい**ことを意味する。

## 核心のアイデア

各ノードは「取りうる値の有効範囲」を持つ。ルートから再帰的に下りながら、左の子には上限を、右の子には下限を狭めていけば、すべてのノードがBSTの条件を満たすかを1回の走査で判定できる。

## 思考プロセス

1. **直接の親子だけでは不十分**: 各ノードが直接の左子より大きく右子より小さいだけではBSTの条件を満たさない。左部分木の「すべての」ノードがそのノードより小さくなければならない。つまり、各ノードには祖先から受け継いだ制約がある
2. **各ノードの有効範囲を定義する**: ルートは任意の値を取れるので、範囲は `(-∞, +∞)` から始まる。左の子に進むとき上限がその親の値に狭まり、右の子に進むとき下限がその親の値に狭まる。この範囲を再帰の引数として渡せばよい
3. **判定条件を決める**: 各ノードで `node.val` が `(lo, hi)` の範囲内にあるかを確認する。BSTは厳密不等号なので、`node.val <= lo` または `node.val >= hi` であれば無効と判定する
4. **再帰の構造を決める**: ベースケースは `node == null` で `true` を返す（空の木は有効なBST）。各ノードで自身の値を判定し、左右の子に対して範囲を狭めて再帰呼び出しする。左右の両方が `true` を返した場合のみ `true` とする
5. **範囲の型をlongにする**: ノードの値が `Integer.MIN_VALUE` や `Integer.MAX_VALUE` のとき、int型の範囲では初期値を表現できない。`Long.MIN_VALUE` と `Long.MAX_VALUE` を初期範囲として使うことで、すべてのint値を正しく判定できる
6. **最終的に返すもの**: ルートから再帰を開始し、すべてのノードが有効範囲内にあれば `true`、1つでも違反があれば `false` を返す

## 前提知識

### 二分探索木（BST）とは

各ノードに対して、左部分木のすべての値がそのノードの値より小さく、右部分木のすべての値がそのノードの値より大きいという性質を持つ二分木。この性質は直接の子だけでなく、部分木全体に適用される。

```
      5
     / \
    3   7     ← 有効なBST: 3<5, 7>5, 1<3, 4>3かつ4<5, 6>5かつ6<7
   / \   \
  1   4   8
```

### 再帰による範囲の絞り込み

親から子へ進むとき、有効な値の範囲が狭まる仕組み:

```
ノード5: 範囲(-∞, +∞)
├─ 左子3: 範囲(-∞, 5)  ← 上限が親の値5に狭まる
│  ├─ 左子1: 範囲(-∞, 3)
│  └─ 右子4: 範囲(3, 5)  ← 下限3かつ上限5
└─ 右子7: 範囲(5, +∞)  ← 下限が親の値5に狭まる
```

### long型を使う理由

Javaの `int` の範囲は `-2147483648` ～ `2147483647`。初期範囲として「int型のどんな値でも許容する」を表現するには、int型の範囲を超える値が必要になる。`long` 型を使えば `Long.MIN_VALUE` と `Long.MAX_VALUE` で十分広い初期範囲を設定できる。

```java
long lo = Long.MIN_VALUE;  // intのどんな値よりも小さい
long hi = Long.MAX_VALUE;  // intのどんな値よりも大きい
node.val <= lo;            // node.valはint型なので、Long.MIN_VALUEより大きいことが保証される
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 各ノードを1回ずつ訪問する |
| Space | O(h) — 再帰のコールスタックの深さは木の高さhに比例する（最悪O(n)、平衡時O(log n)） |

## コード

```java
// 入力: 二分木のルートノード root
// 出力: 木が有効なBSTであれば true、そうでなければ false
public boolean isValidBST(TreeNode root) {
    // 初期範囲をLong.MIN_VALUE/MAX_VALUEに設定し、ルートノードがint型のどんな値でも許容されるようにする
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

// lo, hi はlong型。int型だとInteger.MIN_VALUE/MAX_VALUEを初期値に使えないため
boolean validate(TreeNode node, long lo, long hi) {
    // ベースケース: 空のノードはBSTの条件に違反しない
    if (node == null) return true;

    // 現在のノードの値が有効範囲(lo, hi)の外にあれば無効
    // BSTでは等しい値も許容されないため、<= と >= で厳密に判定する
    if (node.val <= lo || node.val >= hi) return false;

    // 左部分木: 上限をnode.valに狭める（左の値はすべてnode.valより小さい必要がある）。下限loは祖先の制約を維持
    // 右部分木: 下限をnode.valに狭める（右の値はすべてnode.valより大きい必要がある）。上限hiは祖先の制約を維持
    // 左右の両方がtrueの場合のみ、この部分木全体が有効なBST
    return validate(node.left, lo, node.val)
        && validate(node.right, node.val, hi);
}
```
