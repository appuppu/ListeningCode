# Viewing a Binary Tree From the Right Side — 二分木を右側から見たときに見えるノードの値を返す

## 問題の本質

二分木の `root` が与えられる。木を右側から眺めたとき、各深さで最も右にあるノードだけが見える。そのノードの値を、上（root）から下へ順に並べた `List<Integer>` を返す。

## 核心のアイデア

DFSで右の子を先に訪問すれば、各深さで最初に到達するノードが必ず「右側から見えるノード」になる。深さと結果リストのサイズを比較するだけで、そのノードが各深さの最初の訪問かどうかを判定できる。

## 思考プロセス

1. **右側から見えるノードとは何か**: 各深さにおいて最も右に位置するノードが「右側から見えるノード」である。つまり、深さごとに1つずつノードを選ぶ問題に帰着できる
2. **右の子を先に訪問するDFSを考える**: DFSで木を走査するとき、右の子を左の子より先に再帰呼び出しすれば、各深さで最も右のノードに最初に到達する。この性質を利用すれば、各深さで最初に訪問したノードだけを記録すればよい
3. **「各深さで最初の訪問」をどう判定するか**: 結果リスト `result` のサイズは「これまでに記録した深さの数」を表す。現在の `depth` が `result.size()` と等しければ、その深さのノードはまだ記録されていないことを意味する。この条件が成り立つときだけ `result.add(node.val)` を行う
4. **再帰の構造**: 各ノードで「深さが新しければ値を記録」→「右の子を再帰」→「左の子を再帰」の順に処理する。右の子を先に訪問するため、右側のノードが各深さで優先的に記録される
5. **ベースケース**: ノードが `null` のとき、何もせずに `return` する。これにより葉ノードを超えた再帰が自然に終了する
6. **最終的に返すもの**: DFSの完了後、`result` リストには深さ0から順に右側から見えるノードの値が格納されている。このリストをそのまま返す

## 前提知識

### DFS（深さ優先探索）とは

木やグラフを走査するアルゴリズムの一つ。あるノードから出発し、行けるところまで深く進んでから戻る（バックトラックする）。再帰を使うと自然に実装できる。

```java
void dfs(TreeNode node) {
    if (node == null) return;  // ベースケース：nullなら何もしない
    // node に対する処理をここで行う
    dfs(node.left);   // 左の子を再帰的に走査する
    dfs(node.right);  // 右の子を再帰的に走査する
}
```

### List の size() と add()

`List` は可変長の配列。`size()` は現在の要素数を返し、`add()` は末尾に要素を追加する。要素は追加された順にインデックス0, 1, 2...と並ぶ。

```java
List<Integer> list = new ArrayList<>();  // 空のリストを作成
list.size();      // 現在の要素数を返す → 0
list.add(5);      // 末尾に5を追加する → [5]
list.add(3);      // 末尾に3を追加する → [5, 3]
list.size();      // → 2
```

### depth（深さ）とは

木のルートからそのノードまでの辺の数。ルートの深さは0、ルートの子の深さは1、孫の深さは2である。再帰呼び出し時に `depth + 1` を渡すことで、各ノードの深さを追跡できる。

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 全ノードを1回ずつ訪問する |
| Space | O(h) — 再帰のコールスタックが木の高さ分だけ必要（hは木の高さ） |

## コード

```java
// 入力: 二分木のルートノード root
// 出力: 右側から見えるノードの値を上から下へ順に格納した List<Integer>
List<Integer> rightSideView(TreeNode root) {
    // 各深さの右端ノードの値を格納するリスト
    // リストのインデックスが深さに対応する（index 0 = depth 0）
    List<Integer> result = new ArrayList<>();
    dfs(root, 0, result);
    // DFS完了後、resultには深さ0から順に右側から見えるノードの値が格納されている
    return result;
}

void dfs(TreeNode node, int depth,
         List<Integer> result) {
    // ベースケース：nullなら何もしない（葉ノードの先の存在しない子に対する再帰が終了する）
    if (node == null) return;

    // depth == result.size() なら、この深さのノードはまだ未記録
    // result.size() は「これまでに記録済みの深さの数」を表す
    if (depth == result.size()) {
        // 右の子を先に訪問するDFSなので、各深さで最初に到達するノードは必ず最も右のノード
        result.add(node.val);
    }

    // 右の子を先に訪問することで、各深さの右端ノードが最初に記録される
    // これがこのアルゴリズムの核心：右→左の順に訪問する
    dfs(node.right, depth + 1, result);
    // 右の子が存在しない深さでは、左の子が「その深さで最初に訪問されるノード」となり正しく記録される
    dfs(node.left, depth + 1, result);
}
```
