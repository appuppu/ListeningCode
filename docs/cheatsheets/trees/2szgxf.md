# Counting Good Nodes in a Binary Tree — 二分木の中で「良いノード」の数を数える

## 問題の本質

二分木が与えられる。ルートからそのノードまでのパス上にある全ての値の中で、そのノードの値が最大値以上であれば「良いノード（good node）」とみなす。木全体の中で良いノードがいくつあるかを返す。

## 核心のアイデア

ルートから各ノードへ向かう途中で「これまでの最大値」を持ち回れば、各ノードが良いノードかどうかはO(1)で判定できる。DFSで木を走査しながら最大値を子ノードに伝播させれば、全ノードを1回ずつ訪問するだけで答えが求まる。

## 思考プロセス

1. **判定条件を整理する**: あるノードが良いノードかどうかは、ルートからそのノードまでのパス上の最大値と比較するだけで決まる。つまり、パス上の最大値さえ分かれば判定できる
2. **パス上の最大値をどう管理するか**: DFSで木を走査すると、再帰の呼び出しスタックがルートから現在のノードまでのパスに対応する。再帰の引数として「これまでの最大値」を渡せば、各ノードで判定に必要な情報が手に入る
3. **各ノードでの処理を決める**: 現在のノードの値が最大値以上なら良いノードなので1を、そうでなければ0を結果に加算する。これで判定と計数が同時にできる
4. **子ノードに渡す最大値を更新する**: 子ノードに渡す最大値は、現在の最大値と現在のノードの値のうち大きい方にする。これにより、パスが伸びるにつれて最大値が単調非減少で更新される
5. **左右の部分木を再帰的に処理する**: 左の部分木の良いノード数と右の部分木の良いノード数を再帰で求め、現在のノードの結果と合算して返す
6. **初期呼び出しの最大値**: ルートノードは常に良いノードである（パス上に自分しかいない）。初期値を `Integer.MIN_VALUE` にすれば、ルートの値は必ずそれ以上になるので正しく判定される

## 前提知識

### 再帰的DFS（深さ優先探索）とは

木やグラフを深い方向に優先して走査するアルゴリズム。二分木では、再帰関数が自分自身を左の子と右の子に対して呼び出すことで実現する。再帰の呼び出しスタックがルートから現在のノードまでのパスを暗黙的に保持する。

```java
void dfs(TreeNode node) {
    if (node == null) return;  // ベースケース: nullノードに到達したら戻る
    // 現在のノードに対する処理
    dfs(node.left);            // 左の部分木を再帰的に走査する
    dfs(node.right);           // 右の部分木を再帰的に走査する
}
```

### Math.max とは

2つの値のうち大きい方を返すメソッド。パス上の最大値を更新する際に使う。

```java
Math.max(5, 3);    // → 5（5と3のうち大きい方を返す）
Math.max(-1, 4);   // → 4
```

### Integer.MIN_VALUE とは

Javaの `int` 型が取りうる最小値（-2,147,483,648）。どんなノードの値もこれ以上になるため、初期の最大値として使うとルートノードが必ず良いノードと判定される。

```java
Integer.MIN_VALUE;  // → -2147483648（int型の最小値）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 全てのノードを1回ずつ訪問する |
| Space | O(h) — 再帰の呼び出しスタックが木の高さ分だけ使われる |

## コード

```java
// 入力: 二分木のルートノード root
// 出力: 良いノードの総数を int で返す

// ヘルパー関数: nodeを根とする部分木の良いノード数を返す
// maxSoFar はルートから現在のノードまでのパス上の最大値を表す
private int dfs(TreeNode node, int maxSoFar) {
    // ベースケース: nullに到達したら良いノードは0個（葉ノードの先なので数えるノードがない）
    if (node == null) return 0;

    // 現在のノードが良いノードかどうかを判定する（パス上の最大値以上なら良いノード）
    int result = node.val >= maxSoFar ? 1 : 0;

    // 子ノードに渡す最大値を更新する（現在のノードの値が大きければ更新、そうでなければ従来の最大値をそのまま使う）
    int newMax = Math.max(maxSoFar, node.val);

    // 左の部分木の良いノード数を再帰的に求めて加算する
    result += dfs(node.left, newMax);
    // 右の部分木の良いノード数を再帰的に求めて加算する
    result += dfs(node.right, newMax);

    // 現在のノードを根とする部分木全体の良いノード数を返す
    return result;
}

public int goodNodes(TreeNode root) {
    // 初期最大値をint最小値にすることで、ルートノードが必ず良いノードと判定される
    return dfs(root, Integer.MIN_VALUE);
}
```
