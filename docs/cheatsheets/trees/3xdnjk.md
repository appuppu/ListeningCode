# Checking if a Binary Tree is Height-Balanced — 二分木が高さで平衡かどうかを判定する

## 問題の本質

二分木の根ノード `root` が与えられる。その木が**高さ平衡（height-balanced）**かどうかを判定する。高さ平衡とは、すべてのノードにおいて、左部分木の高さと右部分木の高さの差が1以下であることを意味する。結果を `boolean` で返す。

## 核心のアイデア

各ノードの高さを求める再帰処理の中で、不均衡を検出した瞬間に `-1` を返して伝播させる。高さの計算と均衡判定を1回の後行順走査（post-order traversal）で同時に行うことで、すべてのノードを1度だけ訪問すれば答えが出る。

## 思考プロセス

1. **平衡の定義を再帰的に捉える**: 木が平衡であるとは、すべてのノードで左右の部分木の高さの差が1以下であること。つまり、あるノードの平衡判定には、左右の部分木の「高さ」が必要になる
2. **高さの計算自体が再帰的である**: あるノードの高さは `1 + max(左の高さ, 右の高さ)` で求まる。この再帰で木を下から上へ（post-order で）辿れば、各ノードの高さが自然に求まる
3. **高さの計算と均衡判定を統合する**: 高さを返す再帰関数の中で、左右の高さの差が1を超えた時点で「不均衡」を示す特別な値 `-1` を返す。こうすれば、高さ計算と均衡判定を1つの関数で同時に行える
4. **早期終了で無駄な探索を省く**: 左部分木の結果が `-1` なら、右部分木を調べるまでもなく木全体が不均衡である。再帰の戻り値が `-1` かどうかを毎回チェックし、不均衡が見つかった時点で即座に `-1` を返して再帰を打ち切る
5. **戻り値の二重の意味を使い分ける**: 戻り値が `0以上` なら正常な高さ、`-1` なら不均衡を意味する。呼び出し元の `isBalanced` メソッドは、最終的な戻り値が `-1` でないかを確認するだけで答えが得られる

## 前提知識

### 二分木の高さ（height）とは

あるノードから最も遠い葉ノードまでの辺の数。葉ノードの高さは1（ノード数で数える場合）、`null` の高さは0とする。再帰的には `height(node) = 1 + max(height(node.left), height(node.right))` で求まる。

```
        1           ノード1の高さ: 3
       / \          ノード2の高さ: 2
      2   3         ノード4の高さ: 1
     /              ノード3の高さ: 1
    4
```

### 後行順走査（Post-Order Traversal）とは

左部分木 → 右部分木 → 自分自身 の順にノードを処理する走査方法。子の情報を先に確定させてから親の処理を行うため、「子の高さを使って親の高さを計算する」ような下から上への集約処理に適している。

```java
void postOrder(TreeNode node) {
    if (node == null) return;
    postOrder(node.left);   // 左部分木を先に処理する
    postOrder(node.right);  // 右部分木を次に処理する
    // ここで node 自身の処理を行う（左右の結果が既に確定している）
}
```

### Math.abs とは

整数の絶対値を返すJavaの標準メソッド。左右の高さの差が正負どちらでも1以下かどうかを判定するために使用する。

```java
Math.abs(3 - 1);    // → 2
Math.abs(1 - 3);    // → 2
Math.abs(2 - 3);    // → 1
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 各ノードを1回ずつ訪問する |
| Space | O(n) — 再帰呼び出しのコールスタックが最大でn段（木が偏っている場合） |

## コード

```java
// 入力: 二分木の根ノード root
// 出力: 木が高さ平衡であれば true、そうでなければ false を返す

// ノードの高さを返す再帰関数。不均衡を検出したら番兵値 -1 を返す
// 戻り値が 0以上 なら正常な高さ、-1 なら「どこかの部分木が不均衡」を意味する
private int checkHeight(TreeNode node) {
    // ベースケース: nullは空の部分木を表し、高さは0
    if (node == null) return 0;

    // 左部分木の高さを再帰的に求める（後行順走査の「左を先に」の部分）
    int left = checkHeight(node.left);
    // 左部分木が不均衡なら、右部分木を調べずに即座に -1 を伝播する（早期終了）
    if (left == -1) return -1;

    // 右部分木の高さを再帰的に求める（後行順走査の「右を次に」の部分）
    int right = checkHeight(node.right);
    // 右部分木が不均衡なら即座に -1 を伝播する
    if (right == -1) return -1;

    // 現在のノードで左右の高さの差が1を超えるなら不均衡（後行順走査の「自分自身の処理」）
    // Math.abs を使い、左右どちらが高くても正しく差を判定する
    if (Math.abs(left - right) > 1)
        return -1;

    // 平衡であれば、現在のノードの高さを返す。親ノードの計算に使われる
    return 1 + Math.max(left, right);
}

public boolean isBalanced(TreeNode root) {
    // checkHeight が -1 でなければ木全体が平衡である
    // -1 は「どこかの部分木が不均衡」を示す番兵値
    return checkHeight(root) != -1;
}
```
