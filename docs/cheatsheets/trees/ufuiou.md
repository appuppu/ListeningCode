# Checking if Two Binary Trees Are Identical — 2つの二分木が構造・値ともに同一かを判定する

## 問題の本質

2つの二分木 `p` と `q` が与えられる。2つの木が「同一」であるとは、構造が完全に一致し、かつ対応するすべてのノードの値が等しいことを意味する。同一であれば `true`、そうでなければ `false` を返す。

## 核心のアイデア

2つの木の対応するノードを「ペア」としてキューに入れ、レベル順に1組ずつ取り出して比較する。どのペアでも構造と値が一致すれば同一、1つでも不一致があれば非同一と即座に判定できる。

## 思考プロセス

1. **対応するノード同士を比較すればよい**: 2つの木が同一かを判定するには、木の同じ位置にあるノード同士を1組ずつ比較すればよい。すべてのペアで値が一致し、構造（子の有無）も一致すれば、2つの木は同一である
2. **ペアをどう管理するか**: 比較すべきノードのペアを順序どおりに管理する必要がある。キュー（FIFO）を使えば、幅優先でレベルごとにペアを取り出して比較できる。キューには `TreeNode[]` 配列（要素数2）を格納し、`pair[0]` が木pのノード、`pair[1]` が木qのノードを表す
3. **ペアを取り出したとき何を判定するか**: 取り出したペアに対して3つのケースを順に判定する。（a）両方nullなら構造が一致しているので次のペアへ進む、（b）片方だけnullなら構造が異なるので `false` を返す、（c）両方非nullだが値が異なれば `false` を返す
4. **判定を通過したら子ノードのペアをキューに追加する**: 現在のペアが一致した場合、次に比較すべきは左の子同士と右の子同士である。`{n1.left, n2.left}` と `{n1.right, n2.right}` の2組をキューに追加する。子がnullであっても追加してよい（ステップ3のnull判定で正しく処理される）
5. **キューが空になれば全ペアが一致した**: すべてのペアを比較し終えて不一致が見つからなかった場合、2つの木は同一であるため `true` を返す

## 前提知識

### Queue（キュー）とは

先入れ先出し（FIFO）のデータ構造。最初に追加した要素が最初に取り出される。幅優先探索でノードをレベル順に処理するために使う。Javaでは `Queue` インターフェースを `LinkedList` で実装する。

```java
Queue<TreeNode[]> queue = new LinkedList<>();  // TreeNode配列を格納するキューを作成
queue.add(new TreeNode[]{p, q});               // ペア（2要素の配列）をキューの末尾に追加する
TreeNode[] pair = queue.poll();                 // キューの先頭からペアを取り出して返す（キューが空ならnullを返す）
queue.isEmpty();                               // キューが空かをbooleanで返す → true/false
```

### TreeNode（二分木のノード）とは

二分木の各ノードを表すクラス。`val` フィールドにノードの値、`left` と `right` フィールドにそれぞれ左の子ノードと右の子ノードへの参照を持つ。子が存在しない場合は `null` になる。

```java
TreeNode node = new TreeNode(5);   // 値5のノードを作成する
node.val;                          // ノードの値を取得する → 5
node.left;                         // 左の子ノードを取得する（なければnull）
node.right;                        // 右の子ノードを取得する（なければnull）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 2つの木のノードを最大n個ずつ1回比較する |
| Space | O(n) — キューに最大でノード数に比例するペアを保持する |

## コード

```java
// 入力: 2つの二分木のルートノード p と q
// 出力: 2つの木が構造・値ともに同一であれば true、そうでなければ false を返す
public boolean isSameTree(TreeNode p, TreeNode q) {
    // 比較すべきノードのペアを管理するキューを作成する
    // ペアは要素数2の TreeNode[] 配列として格納し、pair[0] が木pのノード、pair[1] が木qのノードを表す
    Queue<TreeNode[]> queue = new LinkedList<>();
    // 初期状態として、2つの木のルートノードのペアをキューに追加する（最初に比較すべきペア）
    queue.add(new TreeNode[]{p, q});

    // キューが空でない間、ペアを1組ずつ取り出して比較する
    while (!queue.isEmpty()) {
        // キューの先頭からペアを取り出す
        TreeNode[] pair = queue.poll();
        TreeNode n1 = pair[0];
        TreeNode n2 = pair[1];

        // 両方nullなら、この位置では両方の木に子が存在しないので構造が一致している。次のペアへ進む
        if (n1 == null && n2 == null)
            continue;
        // 片方だけnullなら、一方の木にはノードが存在し他方には存在しないので構造が異なる
        if (n1 == null || n2 == null)
            return false;
        // 値が異なれば対応するノードの値が一致しないのでfalseを返す
        if (n1.val != n2.val)
            return false;

        // 現在のペアが一致したので、次に比較すべき子ノードのペアをキューに追加する
        // 子がnullであってもそのまま追加する（上のnull判定で正しく処理される）
        queue.add(new TreeNode[]{n1.left, n2.left});
        queue.add(new TreeNode[]{n1.right, n2.right});
    }
    // すべてのペアで構造と値が一致したのでtrueを返す
    return true;
}
```
