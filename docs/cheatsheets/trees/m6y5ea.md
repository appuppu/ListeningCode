# Finding the Maximum Path Sum in a Binary Tree — 二分木における任意のパスの最大合計値を求める

## 問題の本質

二分木が与えられる。各ノードは整数値（負の値もあり得る）を持つ。ノード同士がエッジで接続された任意のパス（各ノードは最大1回のみ使用可能）の中から、ノード値の合計が最大となるパスを見つけ、その**合計値**を返す。パスは根を通る必要はなく、任意のノードから任意のノードへの経路でよい。

## 核心のアイデア

各ノードで「左の子孫から得られる最大利得」と「右の子孫から得られる最大利得」を計算し、そのノードを頂点として左右を結ぶパスの合計をグローバル最大値の候補とする。一方、親に返す値は左右どちらか一方の枝のみを選ぶ（パスは分岐できないため）。

## 思考プロセス

1. **パスの構造を考える**: 任意のパスには必ず「最も高い位置にあるノード（頂点）」が1つ存在する。そのノードから見ると、パスは「左の子孫へ下る部分」「自分自身」「右の子孫へ下る部分」の3つで構成される。すべてのノードを頂点として試し、最大のパス合計を求めればよい
2. **各ノードでの利得（gain）を定義する**: あるノードを根とする部分木から、親方向へ持ち帰れる最大の合計値を「利得」と呼ぶ。利得は「自分の値 + 左右どちらか大きい方の子の利得」で計算する。パスは分岐できないため、左右両方を同時に親に返すことはできない
3. **負の利得は0として扱う**: 子の利得が負の場合、その枝を含めるとパスの合計が減る。そこで `Math.max(0, gain)` を使い、負の利得を0（その枝を使わない）に切り上げる。これにより、ノード単体のパスや片方の枝だけを使うパスも自然に表現できる
4. **グローバル最大値を別途管理する**: 各ノードを頂点とした「左利得 + 自分の値 + 右利得」がそのノードを通る最大パスの合計である。この値をグローバル変数 `maxSum` と比較して更新する。親に返す利得とは別の計算であるため、独立して管理する必要がある
5. **後行順DFS（postorder DFS）で計算する**: 子の利得が分かってから自分の計算を行う必要があるため、左→右→自分の順に処理する後行順DFSが適している。これにより、1回の走査ですべてのノードを頂点として試せる
6. **最終的に返すもの**: DFS完了後、`maxSum` にはすべてのノードを頂点として試した中での最大パス合計が格納されている。この値を返す

## 前提知識

### 二分木の後行順DFS（Postorder DFS）とは

二分木を「左の子→右の子→自分」の順に再帰的に訪問する走査方法。子の計算結果を使って親の計算を行う場合に適している。

```java
void postorder(TreeNode node) {
    if (node == null) return;     // ベースケース: nullなら何もしない
    postorder(node.left);         // 左の部分木を先に処理する
    postorder(node.right);        // 右の部分木を次に処理する
    // ここで node 自身の処理を行う（子の結果が既に確定している）
}
```

### Math.max とは

2つの値のうち大きい方を返すJavaの標準メソッド。負の利得を0に切り上げる処理や、左右の利得の比較に使用する。

```java
Math.max(0, -5);    // → 0（負の値を0に切り上げる）
Math.max(3, 7);     // → 7（大きい方を返す）
Math.max(0, gain(node.left));  // 左の子の利得が負なら0にする
```

### Integer.MIN_VALUE とは

Javaの `int` 型が取りうる最小値（-2,147,483,648）。最大値を求めるアルゴリズムで初期値として使う。どんな値と比較しても更新されることが保証される。

```java
int maxSum = Integer.MIN_VALUE;  // どんなパス合計よりも小さい初期値
maxSum = Math.max(maxSum, 10);   // → 10（初回の比較で必ず更新される）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 各ノードを1回ずつ訪問するDFSを行う |
| Space | O(n) — 再帰呼び出しのコールスタックが最悪の場合（偏った木）n段になる |

## コード

```java
// 入力: 二分木のルートノード root（各ノードは整数値 val、左の子 left、右の子 right を持つ）
// 出力: 二分木内の任意のパスにおける最大合計値を int で返す
class Solution {
    // すべてのノードを頂点として試した中での最大パス合計を記録する
    // Integer.MIN_VALUE で初期化し、どんな負の値のパスよりも小さくすることで初回比較で必ず更新される
    int maxSum = Integer.MIN_VALUE;

    // ノードから親方向へ持ち帰れる最大利得を返す再帰関数（後行順DFSで子→親の順に計算する）
    int gain(TreeNode node) {
        // ベースケース: nullノードの利得は0（存在しない子からは何も得られない）
        if (node == null) return 0;

        // 左の子の利得を取得し、負なら0に切り上げる（負の枝を使うとパス合計が減るため使わない選択をする）
        int leftGain = Math.max(0, gain(node.left));
        // 右の子の利得を取得し、同様に負なら0に切り上げる
        int rightGain = Math.max(0, gain(node.right));

        // 現在のノードを頂点として左右を結ぶパスの合計でグローバル最大値を更新する
        // この値は「左の子孫→現在のノード→右の子孫」のパス合計を表す
        // leftGain や rightGain が0の場合は片方の枝だけ、またはノード単体のパスを意味する
        maxSum = Math.max(maxSum, node.val + leftGain + rightGain);

        // 親に返す利得は左右どちらか大きい方の枝のみ
        // パスは一筆書きのように連続していなければならず、1つのノードで分岐できないため両方は返せない
        return node.val + Math.max(leftGain, rightGain);
    }

    int maxPathSum(TreeNode root) {
        // ルートから再帰的にDFSを開始し、全ノードを頂点として試す
        gain(root);
        // DFS完了後、maxSum にはすべてのノードを頂点として試したパスの中で最大の合計値が格納されている
        return maxSum;
    }
}
```
