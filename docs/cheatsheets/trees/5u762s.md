# Inverting a Binary Tree — 二分木の全ノードで左右の子を入れ替える

## 問題の本質

二分木の根ノード `root` が与えられる。木の**すべてのノード**において左の子と右の子を入れ替え（反転し）、反転後の木の根ノードを返す。

## 核心のアイデア

二分木の反転とは、すべてのノードで左右の子を入れ替える操作である。BFSでレベル順にすべてのノードを訪問し、各ノードで左右の子をswapすれば、木全体が反転する。

## 思考プロセス

1. **反転の定義を理解する**: 二分木の反転とは、根ノードだけでなく、すべてのノードにおいて左の子と右の子を入れ替える操作である。つまり、木のすべてのノードを1回ずつ訪問して、各ノードでswap処理を行えばよい
2. **すべてのノードを訪問する方法を選ぶ**: 木のすべてのノードを訪問する方法としてBFS（幅優先探索）を使う。BFSはキューを使ってレベル順にノードを処理するため、実装が直感的でわかりやすい
3. **各ノードでの操作を決める**: キューから取り出した各ノードに対して、`left` と `right` を一時変数を使ってswapする。swapの順序は問わず、子がnullであってもswap自体は問題なく行える
4. **子ノードをキューに追加する**: swapした後の左右の子がnullでなければキューに追加する。こうすることで、木の下層のノードも順次訪問され、すべてのノードでswapが実行される
5. **最終的に返すもの**: すべてのノードのswapが完了した後、元の根ノード `root` をそのまま返す。木の構造は変わるが、根ノード自体は同じオブジェクトである

## 前提知識

### 二分木（Binary Tree）とは

各ノードが最大2つの子（左の子 `left` と右の子 `right`）を持つ木構造。ノードは `TreeNode` クラスで表現され、`val`（値）、`left`（左の子）、`right`（右の子）のフィールドを持つ。

```java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

### Queue（キュー）とは

先入れ先出し（FIFO）のデータ構造。最初に追加した要素が最初に取り出される。BFSではキューを使って、訪問すべきノードを管理する。

```java
Queue<TreeNode> queue = new LinkedList<>();  // 空のキューを作成
queue.add(node);     // キューの末尾にnodeを追加する
queue.poll();        // キューの先頭の要素を取り出して返す
queue.isEmpty();     // キューが空かどうかをbooleanで返す → true/false
```

### BFS（幅優先探索）とは

木やグラフを「レベル順」に探索するアルゴリズム。キューを使い、現在のノードを処理した後にその子ノードをキューに追加することで、浅い階層から順にすべてのノードを訪問する。

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 木のすべてのノードを1回ずつ訪問する |
| Space | O(n) — キューに最大でn個のノードが格納される |

## コード

```java
// 入力: 二分木の根ノード root
// 出力: 全ノードの左右の子を入れ替えた後の根ノード root を返す
public TreeNode invertTree(TreeNode root) {
    // 木が空ならnullを返す。木が存在しないのでそのまま終了する
    if (root == null) return null;

    // BFS用のキューを作成し、根ノードを追加する
    // このキューは、これから左右のswapを行うべきノードを管理する
    Queue<TreeNode> queue = new LinkedList<>();
    queue.add(root);

    // キューが空になるまで（＝すべてのノードを処理するまで）繰り返す
    while (!queue.isEmpty()) {
        // キューの先頭からswap対象のノードを取り出す
        TreeNode curr = queue.poll();

        // 一時変数を使って左右の子を入れ替える
        // 注意: 一時変数を使わずに直接代入すると、片方の参照が上書きされて失われる
        TreeNode temp = curr.left;
        curr.left = curr.right;
        curr.right = temp;

        // swapした後の子がnullでなければキューに追加する
        // nullのノードはこれ以上処理する子を持たないので追加不要
        if (curr.left != null) queue.add(curr.left);
        if (curr.right != null) queue.add(curr.right);
    }

    // すべてのノードのswapが完了した根ノードを返す
    // 木の構造は変わるが、根ノード自体は同じオブジェクトである
    return root;
}
```
