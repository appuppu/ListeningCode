# Finding Combinations That Sum to a Target — 合計がターゲットになる数の組み合わせを全て見つける

## 問題の本質

正の整数の配列 `candidates`（要素は全て異なる）と正の整数 `target` が与えられる。`candidates` の中から合計が `target` になる組み合わせを全て見つけて返す。同じ数を**何度でも繰り返し使える**。組み合わせの順序が異なるだけのものは重複とみなす。

## 核心のアイデア

候補をソートしておけば、再帰の各段階で「現在の候補が残りのターゲットを超えたら、それ以降の候補も全て超える」と判断でき、不要な探索を丸ごと打ち切れる。この枝刈りにより、全組み合わせを効率的に列挙できる。

## 思考プロセス

1. **組み合わせの全列挙にはバックトラッキングが適している**: 「条件を満たす全てのパターンを見つけよ」という問題は、候補を1つずつ選んで試し、ダメなら戻る再帰的探索（バックトラッキング）で解ける
2. **重複を避けるにはインデックスの開始位置を制御する**: 同じ数を何度でも使えるが、`[2,3]` と `[3,2]` を別の組み合わせとして数えてはいけない。再帰の各段階で「自分と同じ位置以降の候補のみ選ぶ」とすれば、常に昇順の組み合わせだけが生成され、重複を防げる
3. **残りのターゲット（remain）で進捗を管理する**: `target` から選んだ数を引いていき、`remain` が0になれば合計が `target` に一致したことを意味する。`remain` が負になれば合計が超過したことを意味する
4. **ソートすれば枝刈りができる**: 候補を昇順にソートしておくと、ある候補 `cands[i]` が `remain` を超えた時点で、`cands[i+1]` 以降は全てさらに大きいので試す必要がない。forループをその場で打ち切れる
5. **現在の組み合わせをリストで管理し、選択と取り消しを繰り返す**: 要素を末尾に追加して再帰し、戻ってきたら末尾を削除する。この「追加→再帰→削除」のパターンがバックトラッキングの基本操作である
6. **remain が 0 になったら現在の組み合わせのコピーを結果に追加する**: 参照ではなくコピーを保存しないと、後続の操作で中身が変わってしまう

## 前提知識

### バックトラッキングとは

解の候補を段階的に構築し、条件を満たさないと分かった時点で直前の状態に戻って別の候補を試す探索手法。再帰関数で実装し、「選択→再帰→選択の取り消し」を繰り返すことで全パターンを列挙する。

### Arrays.sort とは

配列を昇順にソートするメソッド。ソート済みの配列では「現在の値が条件を超えたら、以降の値も全て超える」という性質を利用して枝刈りができる。

```java
int[] cands = {3, 1, 2};
Arrays.sort(cands);       // cands は {1, 2, 3} になる
```

### ArrayList の操作

可変長のリスト。要素の追加・削除・コピーを行う。バックトラッキングでは現在の組み合わせを管理するために使う。

```java
List<Integer> curr = new ArrayList<>();
curr.add(2);                          // 末尾に2を追加 → [2]
curr.add(3);                          // 末尾に3を追加 → [2, 3]
curr.remove(curr.size() - 1);         // 末尾を削除 → [2]（バックトラック）
new ArrayList<>(curr);                // currのコピーを作成する（結果保存用）
```

### List\<List\<Integer\>\> とは

「整数リストのリスト」を表す型。複数の組み合わせを格納するために使う。各組み合わせが1つの `List<Integer>` であり、それらを束ねたものが `List<List<Integer>>` である。

```java
List<List<Integer>> res = new ArrayList<>();  // 空の結果リストを作成
res.add(new ArrayList<>(curr));               // 組み合わせのコピーを結果に追加
```

## 計算量

| | 値 |
|---|---|
| Time | O(n^(target/min)) — nは候補数、minは最小の候補値。最悪の場合、最小値をtarget/min回選ぶ分岐が各候補について発生する |
| Space | O(target/min) — 再帰の深さは最大でtarget/min。1つの組み合わせに含まれる要素数も最大でtarget/min個である |

## コード

```java
// 入力: 正の整数の配列 candidates（要素は全て異なる）と正の整数 target
// 出力: 合計が target になる全ての組み合わせを List<List<Integer>> で返す
public List<List<Integer>> combinationSum(int[] cands, int target) {
    // 昇順ソートにより「cands[i] > remain なら以降も全て超える」という枝刈り条件が使える
    Arrays.sort(cands);
    // 結果を格納するリスト
    List<List<Integer>> res = new ArrayList<>();
    // バックトラッキングを開始する（残り=target、開始位置=0、現在の組み合わせ=空）
    backtrack(cands, target, 0, new ArrayList<>(), res);
    return res;
}

// remain: targetからこれまで選んだ数を引いた残り。0になれば合計がtargetに一致
// start: 探索開始位置。自分と同じ位置以降のみ選ぶことで重複（順序違い）を防ぐ
// curr: 現在構築中の組み合わせ。選択と取り消しを繰り返して全パターンを探索する
void backtrack(int[] cands, int remain, int start,
               List<Integer> curr, List<List<Integer>> res) {
    // remain が 0 なら合計が target に一致 → 現在の組み合わせを結果に追加
    if (remain == 0) {
        // コピーを作成して保存する。参照のまま保存すると後続の操作で中身が変わる
        res.add(new ArrayList<>(curr));
        return;
    }
    // startから走査し、cands[i] > remain ならソート済みなので以降も全て超える → ループ打ち切り（枝刈り）
    for (int i = start; i < cands.length && cands[i] <= remain; i++) {
        // 現在の候補を組み合わせの末尾に追加する
        curr.add(cands[i]);
        // 第3引数に i（i+1 ではなく i）を渡すことで、同じ数を繰り返し選ぶことを許可する
        backtrack(cands, remain - cands[i], i, curr, res);
        // 再帰から戻ったら追加した要素を取り消す（バックトラック）。次の候補を試す準備
        curr.remove(curr.size() - 1);
    }
}
```
