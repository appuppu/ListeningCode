# Generating All Subsets of a Set — 集合のすべての部分集合を生成する

## 問題の本質

異なる整数の配列 `nums` が与えられる。`nums` のすべての部分集合（べき集合）をリストで返す。部分集合に重複があってはならず、返す順番は問わない。

## 核心のアイデア

要素数 `n` の集合には `2^n` 個の部分集合がある。`n` ビットの整数を `0` から `2^n - 1` まで列挙すれば、各ビットが「対応する要素を含むか含まないか」を表すので、すべての部分集合を漏れなく重複なく生成できる。

## 思考プロセス

1. **部分集合の数は2^nで決まる**: 各要素について「含む」か「含まない」の2択があるので、要素数 `n` の集合には `2^n` 個の部分集合が存在する。すべてを列挙するには、この `2^n` 通りの選択パターンをすべて表現する仕組みが必要になる
2. **2択の列挙はビットで表現できる**: 「含む=1、含まない=0」と対応させると、`n` 個の要素の選択パターンは `n` ビットの整数で表現できる。例えば `nums = [a, b, c]` のとき、ビット列 `101` は「a を含む、b を含まない、c を含む」つまり部分集合 `[a, c]` を意味する
3. **0から2^n-1までの整数がすべてのパターンを網羅する**: `n` ビットで表現できる整数は `0`（全ビット0 = 空集合）から `2^n - 1`（全ビット1 = 全要素を含む集合）までの `2^n` 個である。これらを順に列挙すれば、すべての部分集合を漏れなく重複なく生成できる
4. **各整数から部分集合を構築する方法**: 整数 `mask` の第 `i` ビットが `1` かどうかを `(mask & (1 << i)) != 0` で判定できる。`1` であれば `nums[i]` を部分集合に追加する。`i` を `0` から `n-1` まで走査すれば、`mask` に対応する部分集合が完成する
5. **1 << n で2^nを計算する**: Javaではビットシフト演算子 `<<` を使い、`1 << n` で `2^n` を計算できる。ループの上限値として `mask < (1 << n)` を条件にすれば、`0` から `2^n - 1` まで漏れなく列挙できる
6. **最終的に返すもの**: 各 `mask` に対応する部分集合をリストに追加していき、すべての `mask` を処理した後に、部分集合のリスト `result` を返す

## 前提知識

### ビットマスクとは

整数の各ビット（0 または 1）を「フラグ」として利用するテクニック。`n` 個の要素に対する「含む/含まない」の組み合わせを、1つの整数で表現できる。

```java
int mask = 5;            // 2進数で 101
// 第0ビット: 1（含む）、第1ビット: 0（含まない）、第2ビット: 1（含む）
```

### ビット演算子

`&`（AND）と `<<`（左シフト）を組み合わせて、特定のビットが立っているかを判定する。

```java
1 << 0;                  // 1（2進数: 001）— 第0ビットだけが1のマスクを作る
1 << 1;                  // 2（2進数: 010）— 第1ビットだけが1のマスクを作る
1 << 2;                  // 4（2進数: 100）— 第2ビットだけが1のマスクを作る

int mask = 5;            // 2進数: 101
(mask & (1 << 0)) != 0;  // true  — 第0ビットは1である
(mask & (1 << 1)) != 0;  // false — 第1ビットは0である
(mask & (1 << 2)) != 0;  // true  — 第2ビットは1である
```

### 1 << n で2^nを計算する

ビットシフト `1 << n` は `1` を左に `n` ビットずらす操作で、結果は `2^n` になる。部分集合の総数を求めるのに使う。

```java
1 << 3;                  // 8（= 2^3）— 要素3個なら部分集合は8個
```

## 計算量

| | 値 |
|---|---|
| Time | O(n × 2^n) — 2^n 個のマスクそれぞれについて n ビットを走査する |
| Space | O(n × 2^n) — 2^n 個の部分集合を保存し、各部分集合の平均要素数は n/2 である |

## コード

```java
// 入力: 異なる整数の配列 nums
// 出力: すべての部分集合を格納した List<List<Integer>> を返す
List<List<Integer>> subsets(int[] nums) {
    // nums の要素数。ビットマスクのビット数と配列の走査範囲の両方で使用する
    int n = nums.length;
    // すべての部分集合を格納するリスト。各 mask から生成した部分集合をここに追加していく
    List<List<Integer>> result = new ArrayList<>();

    // mask を 0 から 2^n-1 まで列挙し、各値が1つの部分集合に対応する
    // 1 << n で 2^n を計算し、ループ条件とすることで 2^n 個のパターンをすべて列挙する
    for (int mask = 0; mask < (1 << n); mask++) {
        // 現在の mask に対応する要素を追加していく空の部分集合を作成する
        List<Integer> subset = new ArrayList<>();

        // i は nums のインデックスであり、同時に mask の第何ビットを見るかを決める
        for (int i = 0; i < n; i++) {
            // 1 << i で第 i ビットだけが 1 のマスクを作り、mask との AND で第 i ビットの値を取り出す
            // ビットが 1 なら「この要素を含む」、0 なら「含まない」ので次の i に進む
            if ((mask & (1 << i)) != 0) {
                subset.add(nums[i]);
            }
        }

        // 内側のループ終了後、完成した部分集合を結果リストに追加する
        result.add(subset);
    }
    // すべての mask を処理し終えたら、2^n 個の部分集合が格納された result を返す
    return result;
}
```
