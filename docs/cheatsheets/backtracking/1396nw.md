# Partitioning a String Into Palindrome Substrings — 文字列を回文部分文字列に分割する全パターンを求める

## 問題の本質

文字列 `s` が与えられる。`s` を分割して、すべての部分文字列が回文（前から読んでも後ろから読んでも同じ文字列）になるような分割方法を**すべて**列挙し、リストのリストとして返す。

## 核心のアイデア

任意の部分文字列が回文かどうかをDPテーブルで事前に O(1) 判定できるようにしておき、バックトラッキングで先頭から順に「回文である部分」を切り出しては再帰することで、全分割パターンを効率的に列挙できる。

## 思考プロセス

1. **分割問題は先頭から順に切り出す再帰で表現できる**: 文字列の先頭位置 `start` から末尾までの範囲で、`start` から `end` までの部分文字列を1つ切り出し、残りの部分を再帰的に処理する。`start` が文字列の末尾に到達したら、1つの有効な分割が完成する
2. **切り出す条件は「その部分が回文であること」**: すべての部分文字列が回文である必要があるので、`s[start..end]` が回文のときだけ切り出してパスに追加し、再帰を進める。回文でなければその切り出し方はスキップする
3. **回文判定を毎回 O(n) で行うと無駄が多い**: バックトラッキングの各ステップで部分文字列の回文判定を行うが、同じ部分文字列を何度も判定する可能性がある。DPテーブルで事前計算すれば、任意の `s[l..r]` の回文判定を O(1) に短縮できる
4. **DPテーブルの構築方法**: `dp[l][r]` は「`s` のインデックス `l` から `r` までの部分文字列が回文かどうか」を表すboolean。回文の条件は「両端の文字が同じ」かつ「内側の部分文字列も回文」である。長さ1（`l == r`）は常に回文、長さ2（`r - l == 1`）は両端が同じなら回文、長さ3以上は `s[l] == s[r]` かつ `dp[l+1][r-1]` が true なら回文である
5. **バックトラッキングの構造**: 現在位置 `start` から `end` を `start` から `s.length()-1` まで1つずつ伸ばし、`dp[start][end]` が true なら部分文字列をパスに追加して `end+1` から再帰する。再帰から戻ったらパスの末尾を削除して別の切り出し方を試す
6. **最終的に返すもの**: `start` が `s.length()` に到達するたびに、現在のパスのコピーを結果リストに追加する。すべての再帰が終了したら、結果リストを返す

## 前提知識

### 回文（Palindrome）とは

前から読んでも後ろから読んでも同じ文字列のこと。例えば `"aba"`, `"aa"`, `"a"` は回文。`"ab"` は回文ではない。

### 2次元boolean配列による回文DPテーブル

`dp[l][r]` で「インデックス `l` から `r` までの部分文字列が回文か」を O(1) で判定できるテーブル。外側のループで右端 `r` を固定し、内側のループで左端 `l` を `0` から `r` まで動かして構築する。

```java
boolean[][] dp = new boolean[n][n];
for (int r = 0; r < n; r++) {
    for (int l = 0; l <= r; l++) {
        // 両端が同じ文字で、かつ内側が回文（または長さ2以下）なら回文
        if (s.charAt(l) == s.charAt(r) && (r - l < 2 || dp[l + 1][r - 1])) {
            dp[l][r] = true;
        }
    }
}
dp[0][2];  // s[0]からs[2]までが回文かどうか → true or false
```

### バックトラッキングとは

選択肢を1つ選んで再帰的に進み、条件を満たさなくなったら直前の選択を取り消して別の選択肢を試す探索手法。パスへの追加（選択）→ 再帰 → パスからの削除（取り消し）の3ステップで構成される。

```java
path.add(choice);                    // 選択する
backtrack(nextState, path, result);  // 再帰で先に進む
path.remove(path.size() - 1);       // 選択を取り消して別の道を試す
```

### substring メソッド

`String.substring(start, end)` は、インデックス `start` から `end - 1` までの部分文字列を返す。`end` は含まれない点に注意する。

```java
String s = "aab";
s.substring(0, 1);  // "a"
s.substring(0, 2);  // "aa"
s.substring(0, 3);  // "aab"
```

## 計算量

| | 値 |
|---|---|
| Time | O(n × 2^n) — DPテーブルの構築に O(n^2)、バックトラッキングで最大 2^(n-1) 通りの分割を列挙し各分割で部分文字列のコピーに O(n) かかる |
| Space | O(n^2) — DPテーブルに n×n のboolean配列を使用する。再帰スタックの深さは最大 O(n) |

## コード

```java
// 入力: 文字列 s
// 出力: s のすべての回文分割パターンを格納した List<List<String>>
List<List<String>> partition(String s) {
    int n = s.length();

    // dp[l][r] = s[l]からs[r]までの部分文字列が回文かどうかを表すDPテーブル
    boolean[][] dp = new boolean[n][n];
    // 外側ループで右端 r を固定し、内側ループで左端 l を 0 から r まで走査して構築する
    for (int r = 0; r < n; r++) {
        for (int l = 0; l <= r; l++) {
            // 両端の文字が同じで、内側が回文（または長さ2以下）なら回文
            // r - l < 2 の条件: 長さ1は常に回文、長さ2は両端が同じなら回文
            if (s.charAt(l) == s.charAt(r)
                && (r - l < 2
                || dp[l + 1][r - 1])) {
                dp[l][r] = true;
            }
        }
    }

    // 全分割パターンを格納する結果リスト
    List<List<String>> res = new ArrayList<>();
    // 開始位置 0、空のパスでバックトラッキングを開始する
    bt(s, 0, new ArrayList<>(), res, dp);
    return res;
}

void bt(String s, int start,
    List<String> path,
    List<List<String>> res,
    boolean[][] dp) {
    // 文字列の末尾に到達 → 文字列全体を回文部分文字列で分割しきった
    if (start == s.length()) {
        // path はこの後変更されるため、コピーを追加する
        res.add(new ArrayList<>(path));
        return;
    }

    // start から end までの部分文字列を順に試す
    for (int end = start; end < s.length();
        end++) {
        // DPテーブルで回文判定を O(1) で行う
        if (dp[start][end]) {
            // 回文部分をパスに追加して再帰する
            // substring の第2引数は排他的なので end + 1 を指定する
            path.add(
                s.substring(start, end + 1));
            // 次の開始位置は end + 1（切り出した部分の直後）
            bt(s, end + 1, path, res, dp);
            // 選択を取り消して別の切り出し方を試す（バックトラック）
            path.remove(path.size() - 1);
        }
    }
}
```
