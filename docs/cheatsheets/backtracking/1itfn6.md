# Generating All Unique Subsets With Duplicates — 重複要素を含む配列から全てのユニークな部分集合を生成する

## 問題の本質

重複する値を含む可能性のある整数配列 `nums` が与えられる。全ての可能なユニークな部分集合を返す。結果に重複する部分集合を含めてはならず、各部分集合の要素の順序は任意でよい。

## 核心のアイデア

配列をソートしておけば、同じ再帰レベルで前の要素と同じ値を選ぼうとしたときにスキップするだけで、重複する部分集合の生成を根本から防げる。

## 思考プロセス

1. **部分集合の生成はバックトラッキングの典型問題**: 各要素について「選ぶか選ばないか」を再帰的に決定していけば全部分集合を列挙できる。再帰の各段階で現在の部分集合をそのまま結果に追加すれば、全ての部分集合が得られる
2. **重複の原因を特定する**: 配列に同じ値が複数あると、例えば `[1,2,2]` で1番目の2を選ぶ場合と2番目の2を選ぶ場合で同じ部分集合が生成される。重複は「同じ再帰レベルで同じ値を複数回選ぶ」ときに発生する
3. **ソートで重複要素を隣接させる**: 配列をソートすれば、同じ値の要素が隣り合う。これにより「前の要素と同じ値か」を単純な比較で判定できるようになる
4. **同じ再帰レベルでの重複をスキップする**: forループ内で `i > start && nums[i] == nums[i-1]` の条件を満たすとき、その要素をスキップする。`i > start` の条件は「同じ再帰レベルの2番目以降の選択肢」を意味し、これにより異なる再帰レベルでは同じ値を選べる（部分集合に同じ値を複数含めることは許可される）
5. **再帰の各段階で結果に追加する**: 再帰関数の先頭で現在の部分集合 `curr` を結果リストに追加する。これにより空集合から全要素を含む集合まで、全ての部分集合が結果に含まれる
6. **バックトラッキングで元の状態に戻す**: 再帰呼び出しの後に `curr` の末尾を削除して元に戻すことで、次の選択肢を正しく探索できる

## 前提知識

### バックトラッキングとは

解の候補を再帰的に構築し、条件を満たさない場合は直前の選択を取り消して別の選択を試す探索手法。部分集合・順列・組み合わせの列挙に使われる。

```java
// バックトラッキングの基本構造
void backtrack(状態, 選択肢リスト) {
    結果に現在の状態を追加;
    for (各選択肢) {
        選択を適用;
        backtrack(次の状態, 残りの選択肢);
        選択を取り消し;  // ← バックトラック
    }
}
```

### Arrays.sort とは

配列を昇順にソートするメソッド。重複要素を隣接させることで、重複判定を容易にする。

```java
int[] nums = {4, 1, 4, 2};
Arrays.sort(nums);  // nums = {1, 2, 4, 4} になる
```

### ArrayList のコピーについて

`new ArrayList<>(list)` は既存のリストの浅いコピーを作成する。結果に部分集合を追加するとき、参照ではなくコピーを追加しないと、後のバックトラッキングで内容が書き換わってしまう。

```java
List<Integer> curr = new ArrayList<>();
curr.add(1);
curr.add(2);
List<Integer> copy = new ArrayList<>(curr);  // [1, 2] のコピーを作成
curr.remove(curr.size() - 1);               // curr は [1] に戻るが、copy は [1, 2] のまま
```

### List の末尾削除

`list.remove(list.size() - 1)` はリストの末尾要素を削除する。バックトラッキングで直前に追加した要素を取り消すために使う。

```java
List<Integer> curr = new ArrayList<>();
curr.add(5);        // curr = [5]
curr.add(3);        // curr = [5, 3]
curr.remove(curr.size() - 1);  // curr = [5] に戻る
```

## 計算量

| | 値 |
|---|---|
| Time | O(n × 2^n) — 最大2^n個の部分集合が存在し、各部分集合のコピーに最大O(n)かかる |
| Space | O(n) — 再帰の深さが最大nであり、作業リスト `curr` の長さも最大n（結果リストを除く） |

## コード

```java
// 入力: 重複を含む可能性のある整数配列 nums
// 出力: 全てのユニークな部分集合を格納した List<List<Integer>> を返す
void backtrack(int[] nums, int start, List<Integer> curr, List<List<Integer>> result) {
    // 現在の部分集合のコピーを結果に追加する
    // new ArrayList<>(curr) でコピーを作る理由: curr は後続の再帰で内容が変化するため、参照ではなくその時点の状態を保存する必要がある
    result.add(new ArrayList<>(curr));

    // start から走査することで、自分より前の要素を選ばず部分集合の要素順を保つ
    for (int i = start; i < nums.length; i++) {
        // 同じ再帰レベルで前の要素と同じ値ならスキップして重複を防ぐ
        // i > start: このレベルの最初の選択肢ではない（異なるレベルでは同じ値を選んでよい）
        // nums[i] == nums[i-1]: 前の要素と同じ値である
        // この2条件が同時に成り立つと、同じレベルで同じ値を2回選ぶことになり重複部分集合が生まれる
        if (i > start && nums[i] == nums[i - 1]) continue;

        // 現在の要素を部分集合に追加して次のレベルへ進む
        curr.add(nums[i]);
        // i + 1 を渡すことで、次の再帰レベルでは現在の要素より後ろの要素のみを選択対象とする
        backtrack(nums, i + 1, curr, result);

        // バックトラック: 末尾を削除して元の状態に戻し、次のイテレーションで別の要素を選択できるようにする
        curr.remove(curr.size() - 1);
    }
}

public List<List<Integer>> subsetsWithDup(int[] nums) {
    // ソートして同じ値の要素を隣接させる。これにより nums[i] == nums[i-1] の単純比較で重複判定が可能になる
    Arrays.sort(nums);
    List<List<Integer>> result = new ArrayList<>();
    // 0 は「配列の先頭から探索を開始する」ことを意味する
    backtrack(nums, 0, new ArrayList<>(), result);
    // 全ての再帰が完了し、result には全てのユニークな部分集合が格納されている
    return result;
}
```
