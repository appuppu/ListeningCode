# Generating All Valid Parentheses Combinations — n組の括弧から有効な組み合わせを全て生成する

## 問題の本質

整数 `n` が与えられる。`n` 個の開き括弧 `(` と `n` 個の閉じ括弧 `)` を使って、正しくネストされた括弧文字列を**全て**生成し、リストで返す。各文字列の長さは `2 * n` であり、どの位置でも閉じ括弧の累計が開き括弧の累計を超えてはならない。

## 核心のアイデア

文字列を1文字ずつ構築するとき、「開き括弧の残り数」と「閉じ括弧の残り数」の2つの状態だけで、次に置ける文字が決まる。開き括弧は `n` 個未満なら追加でき、閉じ括弧は開き括弧より少ないときだけ追加できる。この条件で分岐を枝刈りすれば、無効な文字列を一度も生成せずに全ての有効な組み合わせを列挙できる。

## 思考プロセス

1. **全ての組み合わせを列挙する必要がある**: 問題は「全て生成せよ」と求めているので、探索的に全パターンを列挙する手法が必要になる。文字列を1文字ずつ構築しながら分岐するバックトラッキングが適している
2. **各ステップで選択肢は2つしかない**: 文字列の各位置に置ける文字は `(` か `)` の2つだけである。この2択を再帰的に繰り返すことで、全ての候補を探索できる
3. **無効な分岐を早期に打ち切りたい**: 全ての2択を試すと `2^(2n)` 通りになるが、大半は無効である。有効性の条件は2つある。開き括弧を `n` 個より多く使えないこと、閉じ括弧の数がその時点の開き括弧の数を超えてはならないこと。この2条件で分岐を枝刈りする
4. **状態は2つの変数で管理できる**: `open`（使用済みの開き括弧の数）と `close`（使用済みの閉じ括弧の数）を再帰関数に渡す。`open < n` なら `(` を追加でき、`close < open` なら `)` を追加できる
5. **文字列の長さが `2 * n` に達したら完成**: `open` と `close` の条件を守りながら構築した文字列が `2 * n` 文字に達した時点で、その文字列は必ず有効である。結果リストに追加する
6. **バックトラッキングで状態を復元する**: `StringBuilder` に文字を追加して再帰した後、`deleteCharAt` で末尾の文字を削除して元の状態に戻す。こうすることで1つの `StringBuilder` インスタンスを全ての探索パスで共有できる

## 前提知識

### バックトラッキングとは

選択→再帰→取り消しを繰り返して、全ての有効な組み合わせを列挙する探索手法。各ステップで選択肢の中から1つを選び、再帰的に次のステップへ進む。再帰から戻ったら選択を取り消し（バックトラック）、別の選択肢を試す。枝刈り条件を加えることで、無効な経路を早期に打ち切れる。

```java
// バックトラッキングの基本パターン
void backtrack(状態) {
    if (終了条件) {
        結果に追加;
        return;
    }
    for (各選択肢) {
        選択を適用;        // 例: sb.append('(')
        backtrack(次の状態);
        選択を取り消す;    // 例: sb.deleteCharAt(sb.length() - 1)
    }
}
```

### StringBuilder とは

文字列を効率的に組み立てるためのクラス。`String` は不変（immutable）なので文字を追加するたびに新しいオブジェクトが生成されるが、`StringBuilder` は内部バッファを直接操作するため、追加・削除がO(1)でできる。

```java
StringBuilder sb = new StringBuilder();  // 空のStringBuilderを作成
sb.append('(');          // 末尾に文字を追加 → "("
sb.append(')');          // 末尾に文字を追加 → "()"
sb.length();             // 現在の文字数を返す → 2
sb.deleteCharAt(1);      // インデックス1の文字を削除 → "("
sb.toString();           // String型に変換して返す → "("
```

### 括弧の有効性の条件

括弧文字列が「有効」であるとは、以下の2つの条件を満たすことである。
- **条件1**: 開き括弧と閉じ括弧の数が等しい
- **条件2**: 文字列の任意の位置において、先頭からその位置までの閉じ括弧の数が開き括弧の数を超えない

例: `n=2` のとき、`(())` と `()()` は有効。`)()(` は条件2に違反、`((()` は条件1に違反。

## 計算量

| | 値 |
|---|---|
| Time | O(4^n / √n) — 生成される有効な括弧文字列の数はカタラン数 C(n) = C(2n,n)/(n+1) であり、これは O(4^n / (n√n)) に漸近する。各文字列の構築にO(n)かかるため、全体でO(4^n / √n)となる |
| Space | O(n) — 再帰の深さは最大 2n であり、StringBuilderの長さも最大 2n である。結果リストを除けば使用する空間はO(n)である |

## コード

```java
// 入力: 整数 n（括弧のペア数）
// 出力: 有効な括弧文字列を全て格納した List<String> を返す
private void backtrack(StringBuilder sb, int open, int close, int n, List<String> res) {
    // 文字列の長さが2nに達したら、開き括弧と閉じ括弧をちょうどn個ずつ使い切ったので有効な括弧文字列が完成
    if (sb.length() == 2 * n) {
        res.add(sb.toString());
        return;
    }
    // どちらの条件も満たさない場合、これ以上文字を追加できないため何もせずreturnし、呼び出し元でバックトラッキングが進む

    // 開き括弧がn個未満なら、まだ開き括弧を追加できる
    if (open < n) {
        sb.append('(');
        backtrack(sb, open + 1, close, n, res);
        // バックトラッキングの核心: 末尾の '(' を削除して状態を復元し、次の分岐（閉じ括弧の追加）を正しい状態で試す
        sb.deleteCharAt(sb.length() - 1);
    }

    // 注意: 条件が close < n ではなく close < open である点が重要
    // close < n では閉じ括弧が開き括弧を超えるケース（例: ")(")を許してしまうが、
    // close < open なら常に閉じ括弧の数が開き括弧の数以下に保たれ、無効な文字列の生成を防げる
    if (close < open) {
        sb.append(')');
        backtrack(sb, open, close + 1, n, res);
        sb.deleteCharAt(sb.length() - 1);  // 状態を復元する
    }
}

public List<String> generateParenthesis(int n) {
    // 全ての有効な括弧文字列を格納するリスト
    List<String> res = new ArrayList<>();
    // 空のStringBuilderとopen=0, close=0から探索を開始する
    backtrack(new StringBuilder(), 0, 0, n, res);
    return res;
}
```
