# Placing N Queens on a Board Without Conflicts — N個のクイーンを衝突なく配置する

## 問題の本質

整数 `n` が与えられる。n×nのチェスボード上にn個のクイーンを、どの2つのクイーンも同じ行・同じ列・同じ対角線上に存在しないように配置する。条件を満たす全ての盤面構成を、文字列のリストとして返す。

## 核心のアイデア

行ごとに1つずつクイーンを配置すれば行の衝突は自動的に排除できる。残る列・正対角線・負対角線の衝突判定を、ビットマスクの各ビットで管理すれば、O(1)の定数時間で衝突チェックと状態更新ができる。

## 思考プロセス

1. **行の衝突を構造的に排除する**: n個のクイーンをn行に配置するので、各行に必ず1つだけクイーンを置けば、行の衝突は発生しない。よって問題は「各行でどの列にクイーンを置くか」を決める探索に帰着する
2. **列と対角線の衝突を検出する必要がある**: 列の衝突は「既に使った列の集合」で管理できる。対角線の衝突は、正対角線（右上方向、row + col が同じ）と負対角線（左上方向、row - col が同じ）の2種類がある。これら3つの集合を管理すれば全ての衝突を検出できる
3. **ビットマスクで集合を表現する**: 列・正対角線・負対角線の使用状況を整数のビットで表現する。第cビットが1なら「その列（または対角線）は使用済み」を意味する。ビット演算のANDで衝突判定、ORで登録ができ、HashSetより高速に動作する
4. **対角線のビットマスクを行ごとにシフトする**: 正対角線は行が1つ下がると影響範囲が左に1つずれるため左シフト（`<< 1`）、負対角線は右に1つずれるため右シフト（`>> 1`）で更新する。こうすることで、対角線の衝突判定を列番号のビット位置だけで行える
5. **バックトラッキングで全解を探索する**: 行0から行n-1まで順に、各行で衝突しない列を試す。衝突しない列が見つかればクイーンを配置して次の行へ再帰し、行nに到達したら解を1つ記録する。再帰から戻れば自動的に配置が取り消され、別の列を試せる
6. **解の総数を返す**: 全ての行にクイーンを配置できた（row == n に到達した）回数を合計して返す

## 前提知識

### バックトラッキングとは

選択肢を1つ試し、行き詰まったら直前の選択に戻って別の選択肢を試す探索手法。再帰呼び出しで「試す→進む→戻る」を自然に実現できる。全ての有効な組み合わせを列挙する問題に適している。

```java
void backtrack(int step) {
    if (step == goal) {       // ゴールに到達したら解を記録
        recordSolution();
        return;
    }
    for (int choice : choices) {
        if (isValid(choice)) {    // 選択が有効なら試す
            apply(choice);        // 選択を適用
            backtrack(step + 1);  // 次のステップへ再帰
            undo(choice);         // 選択を取り消して別の選択肢を試す
        }
    }
}
```

### ビットマスクとは

整数の各ビットを「集合の要素があるかないか」のフラグとして使うテクニック。集合操作をビット演算で高速に行える。

```java
int mask = 0;             // 空の集合（全ビットが0）
int bit = 1 << c;         // 第cビットだけが1の値を作る（要素cを表す）
mask |= bit;              // 要素cを集合に追加する（第cビットを1にする）
(mask & bit) != 0;        // 要素cが集合に含まれるかを判定する → true/false
```

### ビットシフトによる対角線の追跡

チェスボードで行が1つ下がると、正対角線（右上↗方向）の影響は列番号が1つ小さい方へずれ、負対角線（左上↖方向）の影響は列番号が1つ大きい方へずれる。ビットマスクをシフトすることでこのずれを表現する。

```java
int posDiag = 0;          // 正対角線の使用状況を管理するビットマスク
posDiag |= (1 << c);      // 列cに置いたクイーンの正対角線を登録
posDiag << 1;              // 次の行では影響が左に1列ずれる（左シフト）

int negDiag = 0;          // 負対角線の使用状況を管理するビットマスク
negDiag |= (1 << c);      // 列cに置いたクイーンの負対角線を登録
negDiag >> 1;              // 次の行では影響が右に1列ずれる（右シフト）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n!) — 各行で選べる列の数が最大でn, n-1, n-2, ...と減少する |
| Space | O(n) — 再帰の深さがn段で、各段のビットマスクは定数個の整数のみ |

## コード

```java
// 入力: 整数 n（チェスボードのサイズ、かつ配置するクイーンの数）
// 出力: n個のクイーンを衝突なく配置できる盤面の総数を int で返す
int totalNQueens(int n) {
    // 行0から探索を開始し、列・正対角線・負対角線のビットマスクを全て空（0）で初期化する
    return backtrack(0, n, 0, 0, 0);
}

int backtrack(int row, int n,
    int cols, int posDiag,
    int negDiag) {
    // 全ての行にクイーンを配置できたので、解が1つ見つかった
    if (row == n) return 1;

    // この行以降で見つかる解の数を累計する変数
    int count = 0;

    // 列0からn-1まで走査し、各列にクイーンを置けるかを判定する
    for (int c = 0; c < n; c++) {
        // 列cに対応するビットを作る。このbitを使って3つのビットマスクとの衝突判定を行う
        int bit = 1 << c;

        // 列・正対角線・負対角線のいずれかと衝突する場合はスキップして次の列を試す
        if ((cols & bit) != 0 ||
            (posDiag & bit) != 0 ||
            (negDiag & bit) != 0)
            continue;

        // 列cにクイーンを配置し、3つのビットマスクを更新して次の行へ再帰する
        // cols | bit: 列cを使用済みに登録
        // (posDiag | bit) << 1: 正対角線を登録し、次の行へのずれを左シフトで反映
        // (negDiag | bit) >> 1: 負対角線を登録し、次の行へのずれを右シフトで反映
        // ビットマスクは値渡しなので、再帰から戻れば自動的に登録前の状態に戻り、明示的な取り消し処理は不要
        count += backtrack(row + 1, n,
            cols | bit,
            (posDiag | bit) << 1,
            (negDiag | bit) >> 1);
    }
    // 全ての列を試した結果の解の総数を返す
    return count;
}
```
