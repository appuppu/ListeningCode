# Finding Combinations That Sum to a Target Without Reuse — 重複要素を含む配列からターゲットに合計する一意な組み合わせを全て見つける

## 問題の本質

整数の配列 `candidates`（重複要素を含む可能性がある）と整数 `target` が与えられる。配列の中から合計が `target` になる数値の組み合わせを全て見つける。各数値は組み合わせの中で**1回だけ**使用でき、結果に**重複する組み合わせを含めてはならない**。

## 核心のアイデア

配列をソートすることで同じ値の要素が隣接し、再帰の同じ階層で重複要素をスキップする条件 `i > start && cands[i] == cands[i-1]` が成立する。これにより、重複した組み合わせの生成を根本から防ぎつつ、全ての一意な組み合わせを漏れなく探索できる。

## 思考プロセス

1. **全ての組み合わせを列挙する必要がある**: 問題は「条件を満たす全ての組み合わせ」を求めるので、1つの最適解ではなく解空間全体を探索する必要がある。このような「全列挙」問題にはバックトラッキングが適している
2. **各要素を「使う/使わない」で分岐する**: 配列の各要素について「現在の組み合わせに含めるか含めないか」を再帰的に選択していく。要素を1回だけ使うために、再帰呼び出しでは開始インデックスを `i + 1` に進める
3. **重複する組み合わせを排除する必要がある**: 配列に重複要素がある場合、異なるインデックスの同じ値を選ぶことで同一の組み合わせが生成されてしまう。例えば `[1,1,2]` で target=3 のとき、1番目の1と2の組み合わせ、2番目の1と2の組み合わせは同じ `[1,2]` になる
4. **ソートして重複をスキップする**: 配列をソートすると同じ値が隣接する。再帰の同じ階層（同じforループ内）で、直前と同じ値の要素をスキップすれば、重複する組み合わせの生成を防げる。スキップ条件は `i > start && cands[i] == cands[i-1]` である。`i > start` の条件により、最初の1つは使用を許可しつつ、2つ目以降の同じ値をスキップする
5. **枝刈りで探索を効率化する**: 配列がソート済みなので、現在の要素が残りの合計 `remain` を超えた時点で、それ以降の要素も全て超える。`if (cands[i] > remain) break` でループを打ち切ることで、不要な探索を省略できる
6. **ベースケースの判定**: `remain` が0になったとき、現在の `path` に含まれる要素の合計がちょうど `target` に等しいことを意味するので、`path` のコピーを結果リストに追加する

## 前提知識

### バックトラッキングとは

解の候補を段階的に構築し、条件を満たさないと判明した時点で直前の状態に戻って（バックトラック）別の候補を試す探索手法。「選択→再帰→選択の取り消し」のパターンで実装する。

```java
path.add(element);          // 選択: 要素を組み合わせに追加する
backtrack(next_state);      // 再帰: 次の要素について探索を続ける
path.remove(path.size()-1); // 取り消し: 要素を組み合わせから除去して元の状態に戻す
```

### Arrays.sort とは

配列を昇順にソートするJavaの標準メソッド。ソートにより同じ値の要素が隣接するため、重複の検出とスキップが容易になる。

```java
int[] arr = {2, 1, 2, 3};
Arrays.sort(arr);           // arr が {1, 2, 2, 3} に変わる
```

### ArrayList のコピーコンストラクタ

`new ArrayList<>(path)` は `path` の中身をコピーした新しいリストを作成する。バックトラッキングでは `path` が再帰中に変化し続けるため、結果に追加する時点でコピーを取る必要がある。

```java
List<Integer> path = new ArrayList<>(Arrays.asList(1, 2));
List<Integer> copy = new ArrayList<>(path);  // [1, 2] のコピーを作成する
path.add(3);        // path は [1, 2, 3] に変わる
// copy は [1, 2] のまま変わらない
```

## 計算量

| | 値 |
|---|---|
| Time | O(2^n) — 各要素について「使う/使わない」の2択があるため、最悪ケースで2^n通りの組み合わせを探索する |
| Space | O(n) — 再帰の深さが最大nであり、pathも最大n個の要素を保持する |

## コード

```java
// 入力: 整数配列 candidates（重複要素を含む可能性がある）と整数 target
// 出力: 合計が target になる一意な組み合わせを全て格納した List<List<Integer>> を返す
private void backtrack(int[] cands, int start, int remain,
        List<Integer> path, List<List<Integer>> result) {
    // remain が0なら path の合計がちょうど target に等しい組み合わせを発見した
    if (remain == 0) {
        // path は以降の再帰で変化し続けるため、コピーを作成して結果に追加する
        result.add(new ArrayList<>(path));
        return;
    }

    // start から開始することで、既に使用した要素（start より前）を再度選択することを防ぐ
    for (int i = start; i < cands.length; i++) {
        // 同じ再帰階層で2番目以降の要素かつ直前と同じ値ならスキップして重複組み合わせを防ぐ
        // i > start は「同じ再帰階層で最初の要素ではない」ことを意味する
        if (i > start && cands[i] == cands[i - 1]) continue;

        // ソート済みなので現在の値が remain を超えたら、以降の要素も全て超える（枝刈り）
        if (cands[i] > remain) break;

        path.add(cands[i]);                  // 選択: 要素を組み合わせに追加する
        backtrack(cands, i + 1,              // 再帰: i+1 にすることで同じ要素を2回使うことを防ぐ
            remain - cands[i], path, result); // remain から現在の要素を差し引いて残り合計を更新する
        path.remove(path.size() - 1);        // 取り消し: 要素を除去して別の要素を試すために状態を復元する
    }
}

public List<List<Integer>> combinationSum2(
        int[] candidates, int target) {
    // ソートにより同じ値の重複要素を隣接させ、スキップ条件の判定を可能にする
    Arrays.sort(candidates);
    // 結果を格納するリストと、現在の組み合わせを記録する path を空で作成する
    List<List<Integer>> result = new ArrayList<>();
    // インデックス0・残り合計 target から再帰探索を開始する
    backtrack(candidates, 0, target, new ArrayList<>(), result);
    // 全ての再帰が完了した後、格納された全ての一意な組み合わせを返す
    return result;
}
```
