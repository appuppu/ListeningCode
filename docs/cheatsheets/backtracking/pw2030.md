# Searching for a Word in a Grid — グリッド内の文字を辿って単語を構成できるか判定する

## 問題の本質

2Dの文字グリッド `board` と文字列 `word` が与えられる。グリッド内の隣接するセル（上下左右）を順にたどって `word` を構成できるかを判定し、`boolean` で返す。各セルは1つのパスにつき1回しか使えない。

## 核心のアイデア

グリッドの各セルを起点としてDFSを行い、単語の文字を1文字ずつマッチさせる。訪問済みセルを別配列で管理する代わりに、盤面のセルを直接特殊文字で上書きし、探索後に元に戻すことで、空間計算量を再帰スタックの深さだけに抑える。

## 思考プロセス

1. **各セルが起点になりうる**: 単語の開始位置はグリッドのどのセルでもよいので、全セルを起点候補として試す必要がある
2. **1文字ずつ順にマッチさせる**: 現在のセルの文字が `word` の現在位置の文字と一致するかを確認し、一致すれば上下左右の隣接セルへ再帰的に探索を進める。この構造はDFS（深さ優先探索）そのものである
3. **同じセルの再利用を防ぐ**: 1つのパスで同じセルを2回使えないため、訪問済みの管理が必要になる。別途 `boolean[][]` の訪問配列を持つ方法もあるが、空間を消費する
4. **盤面を直接書き換えて訪問済みを表現する**: 探索に入るとき、現在のセルの文字を `'#'` など盤面に存在しない特殊文字で上書きすれば、再帰先で同じセルにマッチすることはなくなる。これにより訪問配列が不要になり、空間計算量が再帰スタックの深さ O(L) だけで済む
5. **探索後に元の文字を復元する**: DFSの帰りがけに、上書きした `'#'` を元の文字に戻す（バックトラック）。これにより、他の起点からの探索で同じセルを正しく使える
6. **探索の終了条件を整理する**: インデックス `idx` が `word.length()` に達したら全文字マッチ成功で `true` を返す。範囲外・文字不一致の場合は `false` を返す。4方向のいずれかで `true` が返れば、その時点で `true` を返す

## 前提知識

### DFS（深さ優先探索）とは

グラフやグリッドの探索手法。1つの方向を行けるところまで進み、行き止まりに達したら1つ戻って別の方向を試す。再帰呼び出しで自然に実現できる。

```java
void dfs(int node) {
    // nodeを処理する
    for (int neighbor : getNeighbors(node)) {
        dfs(neighbor);  // 隣接ノードへ再帰的に進む
    }
}
```

### バックトラッキングとは

探索中に行った変更を、探索から戻る際に元に戻す手法。「試す → 進む → 戻す」のサイクルにより、すべての候補を漏れなく探索できる。

```java
board[r][c] = '#';   // 変更する（訪問済みにする）
dfs(...);            // 再帰的に探索を進める
board[r][c] = temp;  // 元に戻す（未訪問に戻す）
```

### charAt とは

`String` の指定位置の文字を `char` 型で返すメソッド。インデックスは0始まりである。

```java
String word = "ABCCED";
word.charAt(0);   // 'A' を返す
word.charAt(3);   // 'C' を返す
word.length();    // 6 を返す（文字数を返す）
```

### 2Dグリッドの4方向探索

2Dグリッドで上下左右の隣接セルを探索するには、行と列それぞれに±1する4パターンを試す。

```java
// 上・下・左・右の順に探索する
dfs(board, word, r-1, c, idx+1);  // 上（行を-1）
dfs(board, word, r+1, c, idx+1);  // 下（行を+1）
dfs(board, word, r, c-1, idx+1);  // 左（列を-1）
dfs(board, word, r, c+1, idx+1);  // 右（列を+1）
```

## 計算量

| | 値 |
|---|---|
| Time | O(m × n × 4^L) — 全セルを起点に、各起点から最大4方向をL文字分探索する（m×nはグリッドサイズ、Lは単語の長さ） |
| Space | O(L) — 再帰スタックの深さが最大L。盤面を直接書き換えるため訪問配列は不要 |

## コード

```java
// 入力: 2Dの文字配列 board と文字列 word
// 出力: word をグリッド内の隣接セルで構成できれば true、できなければ false を返す

// 現在位置(r,c)からword[idx]以降をマッチさせるDFS
boolean dfs(char[][] board, String word, int r, int c, int idx) {
    // idx が word.length() に等しければ、全文字のマッチが完了しているので true を返す
    if (idx == word.length()) return true;

    // r または c がグリッドの範囲外であるか、board[r][c] が word.charAt(idx) と一致しない場合は false を返す
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length
        || board[r][c] != word.charAt(idx))
        return false;

    // 現在のセルの文字を変数 temp に退避し、'#' で上書きして再訪問を防ぐ
    // '#' は英字と一致しないため、再帰先でこのセルが再度マッチすることを防ぐ（訪問配列の代わり）
    char temp = board[r][c];
    board[r][c] = '#';

    // 上下左右の4方向に再帰探索する（いずれかがtrueなら成功）
    // || の短絡評価により、true が見つかった時点で残りの方向の探索は省略される
    boolean found =
        dfs(board, word, r - 1, c, idx + 1)
     || dfs(board, word, r + 1, c, idx + 1)
     || dfs(board, word, r, c - 1, idx + 1)
     || dfs(board, word, r, c + 1, idx + 1);

    // 探索結果にかかわらず元の文字を復元する（バックトラック）
    // これにより、別の起点や別のパスからの探索で同じセルを正しく使える状態に戻す
    board[r][c] = temp;
    return found;
}

boolean exist(char[][] board, String word) {
    int m = board.length;
    int n = board[0].length;

    // グリッドの全セル(i,j)を二重forループで走査し、各セルを起点としてDFSを呼び出す
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // dfs が true を返した時点で true を返す
            if (dfs(board, word, i, j, 0))
                return true;

    // 全セルを試しても見つからなければ false を返す
    return false;
}
```
