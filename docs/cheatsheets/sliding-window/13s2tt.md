# Finding the Longest Substring Without Repeating Characters — 重複文字を含まない最長部分文字列の長さを求める

## 問題の本質

文字列 `s` が与えられる。`s` の中から、同じ文字が2回以上出現しない連続部分文字列（substring）を見つけ、その**最大の長さ**を整数で返す。

## 核心のアイデア

スライディングウィンドウを使えば、すべての有効な部分文字列をO(n)で検査できる。重複が見つかったとき、左端を「重複文字の前回出現位置+1」まで一気にジャンプさせることで、無駄な1つずつの移動を省略できる。

## 思考プロセス

1. **部分文字列の探索をウィンドウで表現する**: 「重複なしの部分文字列」は、左端 `left` と右端 `right` の2つのポインタで囲まれた区間として表現できる。右端を1つずつ進めてウィンドウを広げ、重複が発生したら左端を動かしてウィンドウを縮める
2. **重複の検出にはHashMapを使う**: 各文字の「最後に出現したインデックス」をHashMapに記録しておけば、新しい文字がウィンドウ内に既に存在するかをO(1)で判定できる
3. **左端のジャンプ条件を正確に定める**: `right` の文字がHashMapに存在するだけでは不十分。その文字の前回出現位置が `left` 以上（つまり現在のウィンドウ内）である場合のみ重複とみなす。ウィンドウ外の古い記録は無視する
4. **左端の移動先を決める**: 重複が検出されたら、`left` を「重複文字の前回出現位置 + 1」に更新する。こうすることで、重複文字をウィンドウから排除しつつ、それ以外の有効な文字はウィンドウ内に残せる
5. **HashMapの更新タイミング**: 重複判定の後に、現在の文字のインデックスをHashMapに登録（上書き）する。これにより常に各文字の最新の出現位置が記録される
6. **最大長の更新**: 各ステップで `right - left + 1`（現在のウィンドウ幅）を計算し、これまでの最大値と比較して更新する

## 前提知識

### スライディングウィンドウとは

配列や文字列上で、2つのポインタ（`left`, `right`）が定義する区間を「窓」として動かしながら、条件を満たす部分を探索するテクニック。右端を進めて窓を広げ、条件違反時に左端を進めて窓を縮める。各ポインタは前方にのみ動くため、全体でO(n)の計算量になる。

### HashMap とは

キーと値のペアを保存するデータ構造。キーを指定して値の検索・取得がO(1)でできる。この問題では、キーに「文字」、バリューに「その文字が最後に出現したインデックス」を保存する。

```java
HashMap<Character, Integer> map = new HashMap<>();  // 空のHashMapを作成
map.put('a', 0);            // キー'a'に値0を格納する
map.containsKey('a');       // キー'a'が存在するかをbooleanで返す → true
map.get('a');               // キー'a'に対応する値を返す → 0
```

### charAt とは

文字列の指定位置にある文字を取得するメソッド。`s.charAt(i)` は文字列 `s` のインデックス `i` にある `char` を返す。

```java
String s = "abc";
char c = s.charAt(0);  // 'a' を返す
char d = s.charAt(2);  // 'c' を返す
```

### Math.max とは

2つの値のうち大きい方を返すメソッド。最大値を更新し続ける場面で使う。

```java
int result = Math.max(3, 7);  // 7 を返す
maxLength = Math.max(maxLength, currentLength);  // 現在の最大値を更新する
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — `right` が文字列を1回走査するだけで済む。`left` も前方にのみ動くので全体でO(n) |
| Space | O(n) — HashMapに最大n個の文字とインデックスのペアを保存する |

## コード

```java
// 入力: 文字列 s
// 出力: 重複文字を含まない最長部分文字列の長さを int で返す
public int lengthOfLongestSubstring(String s) {
    // ウィンドウの左端ポインタ。初期位置は文字列の先頭
    int left = 0;
    // 走査中に見つけた最長ウィンドウ幅を記録する変数
    int maxLength = 0;
    // キー=文字、バリュー=その文字が最後に出現したインデックス を保存するHashMap
    // 重複判定と左端のジャンプ先計算の両方に使う
    HashMap<Character, Integer> hashMap = new HashMap<>();

    // right はウィンドウの右端を表すポインタ。1つずつ進めてウィンドウを広げる
    for (int right = 0; right < s.length(); right++) {
        // これからウィンドウに追加しようとしている文字を取得する
        char curChar = s.charAt(right);

        // containsKey: この文字が過去に出現したか判定する
        // get(curChar) >= left: その出現位置が現在のウィンドウ内かを確認する
        // 両方が真のとき、ウィンドウ内に重複が存在する
        if (hashMap.containsKey(curChar) && hashMap.get(curChar) >= left) {
            // 重複文字の前回出現位置+1に左端をジャンプさせ、重複を解消する
            // left は常に前方にのみ動くので、過去に戻ることはない
            left = hashMap.get(curChar) + 1;
        }

        // 現在の文字の出現位置を最新のインデックスで上書き登録する
        // 次回この文字が出現したとき、ここで記録したインデックスで左端のジャンプ先を計算する
        hashMap.put(curChar, right);
        // right - left + 1 は現在のウィンドウ幅（重複なし部分文字列の長さ）
        // 過去の最大値を超えていれば更新する
        maxLength = Math.max(maxLength, right - left + 1);
    }
    // これが重複文字を含まない最長部分文字列の長さである
    return maxLength;
}
```
