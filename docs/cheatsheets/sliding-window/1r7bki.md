# Finding the Best Time to Buy and Sell a Stock — 株価配列から1回の売買で得られる最大利益を求める

## 問題の本質

整数の配列 `prices` が与えられる。各要素 `prices[i]` は `i` 日目の株価を表す。1回だけ「買い→売り」を行える条件で、得られる**最大利益**を返す。利益が出ない場合は `0` を返す。買いは売りより前の日でなければならない。

## 核心のアイデア

配列を左から走査しながら「これまでの最安値」を記録し続ければ、各日の価格から最安値を引くだけで、その日に売った場合の最大利益が O(1) で求まる。全日についてこの利益の最大値を取れば答えになる。

## 思考プロセス

1. **利益は「売値 − 買値」で決まる**: ある日に売るとき、利益を最大化するには買値をできるだけ小さくすればよい。つまり、売る日より前の全日のうち最安値で買えばよい
2. **各日における「それ以前の最安値」を効率的に求めたい**: 配列を左から走査しながら、今まで見た価格の最小値を変数 `minPrice` で追跡する。新しい価格を見るたびに `minPrice` を更新するだけでよいので、追加の配列は不要でO(1)の空間で済む
3. **各日の「売った場合の利益」を計算する**: 走査中の各日 `i` について、`prices[i] - minPrice` がその日に売った場合の最大利益である。この値を変数 `maxProfit` と比較して、より大きければ `maxProfit` を更新する
4. **minPrice の更新と利益計算の関係を整理する**: 現在の価格が `minPrice` より小さい場合は、`minPrice` を更新する。この日に売っても利益は負なので利益計算は不要。現在の価格が `minPrice` 以上の場合は、利益を計算して `maxProfit` を更新する
5. **利益が出ない場合の処理**: 株価が単調減少の場合、`maxProfit` は初期値 `0` のまま更新されない。条件分岐なしで自然に `0` が返る
6. **最終的に返すもの**: 配列を1回走査し終えた時点の `maxProfit` の値を返す。これが1回の売買で得られる最大利益である

## 前提知識

### Integer.MAX_VALUE とは

Javaの `int` 型が取りうる最大の値（2,147,483,647）。最小値を探すアルゴリズムで初期値として使う。どんな株価よりも大きいことが保証されるため、最初の比較で必ず実際の株価に置き換わる。

```java
int minPrice = Integer.MAX_VALUE;  // 最小値の初期値として十分大きな値を設定する
// prices[0] が例えば 7 の場合、7 < Integer.MAX_VALUE なので minPrice は 7 に更新される
```

### Math.max とは

2つの `int` 値を受け取り、大きい方を返す静的メソッド。最大値の更新処理を1行で書ける。

```java
int a = 5;
int b = 3;
Math.max(a, b);  // → 5 を返す

// 最大利益の更新に使う
maxProfit = Math.max(maxProfit, profit);  // profitの方が大きければmaxProfitを更新する
```

### Running Minimum（走査中の最小値追跡）とは

配列を走査しながら、それまでに見た要素の最小値を変数で追跡する手法。各ステップで現在の要素と変数を比較し、小さい方で変数を更新する。これにより、任意の位置で「その位置以前の最小値」がO(1)で得られる。

```java
int minPrice = Integer.MAX_VALUE;
for (int price : prices) {
    if (price < minPrice) {
        minPrice = price;  // これまでの最安値を更新する
    }
    // この時点で minPrice は prices[0]〜prices[現在] の中の最小値を保持している
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 変数2つ（minPrice, maxProfit）のみを使用する |

## コード

```java
// 入力: 整数配列 prices（各要素は日ごとの株価）
// 出力: 1回の売買で得られる最大利益を int で返す。利益が出ない場合は 0 を返す
public int maxProfit(int[] prices) {
    // これまでの最安値を追跡する変数。Integer.MAX_VALUE で初期化することで、最初の価格との比較で必ず実際の株価に更新される
    int minPrice = Integer.MAX_VALUE;
    // これまでの最大利益を追跡する変数。0 で初期化することで、利益が出ないケースでは自然に 0 が返る
    int maxProfit = 0;

    // for-eachループで配列を先頭から末尾まで1つずつ走査する
    for (int price : prices) {
        if (price < minPrice) {
            // 現在の価格が最安値より小さければ最安値を更新する
            // この日は最安値の更新日なので、この日に売っても利益は出ない（利益が負になる）。そのため利益計算はスキップする
            minPrice = price;
        } else {
            // 最安値の日に買って今日売った場合の利益を計算する
            int profit = price - minPrice;
            // 利益がこれまでの最大を上回れば最大利益を更新する
            maxProfit = Math.max(maxProfit, profit);
        }
    }
    // ループ終了時点の maxProfit が配列全体を通じた最大利益である
    return maxProfit;
}
```
