# Longest Substring After Replacing K Characters — K回の文字置換で得られる最長の同一文字部分文字列を求める

## 問題の本質

大文字英字の文字列 `s` と整数 `k` が与えられる。文字列中の最大 `k` 個の文字を任意の文字に置換できるとき、**すべての文字が同一**である部分文字列の最大長を返す。

## 核心のアイデア

ウィンドウ内で「最も多い文字の出現数」を把握すれば、「置換が必要な文字数 = ウィンドウサイズ − 最頻文字の出現数」と計算できる。この置換数が `k` 以下である限りウィンドウを拡大し続ければ、最長の部分文字列が求まる。

## 思考プロセス

1. **部分文字列を全探索するのは非効率**: すべての部分文字列を列挙するとO(n²)かかる。連続する区間を扱うので、Sliding Windowパターンが適している
2. **ウィンドウ内で置換が必要な文字数を求めたい**: ウィンドウ内のすべての文字を同一にするには、最も出現回数が多い文字以外を置換すればよい。したがって、置換が必要な文字数は `ウィンドウサイズ − 最頻文字の出現数` で求まる
3. **各文字の出現回数を追跡する手段**: 大文字英字は26種類しかないので、サイズ26の配列 `count` で各文字の出現回数を管理できる。ウィンドウの拡大・縮小に合わせてインクリメント・デクリメントする
4. **最頻文字の出現数を効率的に管理する**: 右ポインタを進めるたびに、追加した文字の出現数と現在の `maxFreq` を比較し、大きい方を `maxFreq` とする。左ポインタを進めて文字を除外しても `maxFreq` は減らさない。なぜなら、最大長を求める問題では、過去に達成した `maxFreq` より小さい値に更新してもより長い結果は得られないからである
5. **ウィンドウの縮小条件**: `ウィンドウサイズ − maxFreq > k` のとき、置換回数が `k` を超えているので、左ポインタを1つ進めてウィンドウを縮小する。この条件が満たされなくなるまで繰り返す
6. **最大長の更新**: ウィンドウが有効（置換数 ≤ k）になるたびに、`right − left + 1` と現在の `maxLen` を比較し、大きい方を `maxLen` として記録する

## 前提知識

### Sliding Window（スライディングウィンドウ）とは

配列や文字列上の連続する区間を、2つのポインタ（left, right）で管理する手法。rightを進めてウィンドウを拡大し、条件を満たさなくなったらleftを進めてウィンドウを縮小する。各要素を最大2回（追加と削除で1回ずつ）しか処理しないため、O(n)で動作する。

### 文字の出現回数を配列で管理する方法

大文字英字は `'A'`〜`'Z'` の26文字なので、`int[26]` の配列で各文字の出現回数を管理できる。文字からインデックスへの変換は `charAt() - 'A'` で行う。

```java
int[] count = new int[26];           // 26文字分の出現回数を保持する配列
count[s.charAt(i) - 'A']++;         // 文字s.charAt(i)の出現回数を1増やす
count[s.charAt(i) - 'A']--;         // 文字s.charAt(i)の出現回数を1減らす
```

### maxFreq を減らさない理由

`maxFreq` はウィンドウ内の最頻文字の出現数である。左ポインタを進めて文字を除外しても `maxFreq` を再計算して減らす必要はない。最大長を求める問題では、`maxFreq` が過去の最大値より小さくなったとしても、その状態で得られるウィンドウサイズは過去の最大長を超えることがない。そのため、`maxFreq` は単調増加のまま管理しても正しい結果が得られる。

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 右ポインタと左ポインタがそれぞれ最大n回進むだけで済む |
| Space | O(1) — 使用する配列のサイズは26で固定であり、入力サイズに依存しない |

## コード

```java
// 入力: 大文字英字の文字列 s と整数 k（最大置換回数）
// 出力: 最大 k 回の置換で全文字を同一にできる部分文字列の最大長を int で返す
public int characterReplacement(String s, int k) {
    // 各文字（A〜Z）の出現回数を管理する配列。インデックス0が'A'、25が'Z'に対応する
    int[] count = new int[26];
    // left: ウィンドウの左端
    int left = 0;
    // maxFreq: ウィンドウ内で最も多く出現している文字の回数（単調増加で管理する）
    int maxFreq = 0;
    // maxLen: 条件を満たす部分文字列の最大長（最終的にこの値を返す）
    int maxLen = 0;

    // 右ポインタを1つずつ進めてウィンドウの右端を拡大する
    for (int right = 0; right < s.length(); right++) {
        // 右端に追加した文字の出現回数を1増やす
        count[s.charAt(right) - 'A']++;

        // 追加した文字の出現数と現在のmaxFreqを比較し、最頻文字の出現数を更新する
        maxFreq = Math.max(maxFreq, count[s.charAt(right) - 'A']);

        // ウィンドウサイズ - maxFreq = 置換が必要な文字数。これがkを超えている間、左端を縮小する
        // 注意: maxFreqはここで再計算しない。減らしても最大長の更新には寄与しないため
        while (right - left + 1 - maxFreq > k) {
            // 左端の文字の出現回数を1減らしてウィンドウから除外する
            count[s.charAt(left) - 'A']--;
            left++;
        }

        // ウィンドウが有効（置換数 ≤ k）なので、現在のウィンドウサイズで最大長を更新する
        maxLen = Math.max(maxLen, right - left + 1);
    }
    // forループ終了後、最大 k 回の置換で得られる最長の同一文字部分文字列の長さを返す
    return maxLen;
}
```
