# Finding the Maximum in Each Sliding Window — スライディングウィンドウ内の最大値を求める

## 問題の本質

整数の配列 `nums` とウィンドウサイズ `k` が与えられる。サイズ `k` のウィンドウを配列の左端から右端まで1つずつスライドさせ、各位置でのウィンドウ内の**最大値**を求める。すべての最大値を配列で返す。

## 核心のアイデア

Deque（両端キュー）にインデックスを「値が単調減少になるように」保持すれば、Dequeの先頭が常にウィンドウ内の最大値を指す。新しい要素が来たら末尾から自分以下の要素を除去し、先頭がウィンドウ外なら除去することで、各ステップO(1)の償却コストで最大値を取得できる。

## 思考プロセス

1. **各ウィンドウの最大値が必要**: ウィンドウを1つスライドするたびに、追加される要素と除去される要素は1つずつである。毎回ウィンドウ全体を走査してO(k)で最大値を求めると全体でO(nk)になるので、最大値を効率的に管理するデータ構造が必要である
2. **最大値の候補だけを保持すればよい**: ウィンドウ内に要素AとBがあり、AがBより左にあり、かつAの値がB以下なら、Aは今後どのウィンドウでも最大値になれない。Bの方が右にあるので先にウィンドウから出ることもない。したがって、Aは候補から除外してよい
3. **単調減少のDequeで候補を管理する**: 候補を値が大きい順に保持すれば、先頭が常に最大値になる。新しい要素を追加するとき、末尾から自分以下の要素を全て除去すれば、単調減少の性質が維持される。この操作にはDeque（両端キュー）が適している
4. **Dequeにはインデックスを保存する**: 要素がウィンドウ外に出たかどうかを判定するには位置情報が必要なので、Dequeには値ではなくインデックスを保存する。値は `nums[index]` で参照できる
5. **先頭のウィンドウ外チェック**: 各ステップで、Dequeの先頭のインデックスが現在のウィンドウの左端 `i - k + 1` より小さい場合、その要素はウィンドウから出ているので先頭から除去する
6. **結果の記録タイミング**: インデックス `i` が `k - 1` 以上になった時点でウィンドウが完成しているので、Dequeの先頭が指す値を結果配列に記録する

## 前提知識

### ArrayDeque（両端キュー）とは

先頭と末尾の両方から要素の追加・取得・削除がO(1)でできるデータ構造。スタックとキューの両方の機能を兼ね備えている。

```java
ArrayDeque<Integer> deque = new ArrayDeque<>();  // 空のDequeを作成
deque.offerLast(5);       // 末尾に5を追加する
deque.offerLast(3);       // 末尾に3を追加する → Dequeの中身: [5, 3]
deque.peekFirst();        // 先頭の要素を取得する（削除しない） → 5
deque.peekLast();         // 末尾の要素を取得する（削除しない） → 3
deque.pollFirst();        // 先頭の要素を取得して削除する → 5
deque.pollLast();         // 末尾の要素を取得して削除する → 3
deque.isEmpty();          // Dequeが空かをbooleanで返す → true
```

### 単調減少Deque（Monotonic Deque）とは

Deque内の要素が先頭から末尾に向かって常に減少（または等しくない）する状態を保つDeque。新しい要素を追加するとき、末尾から自分以下の要素を全て除去することで単調減少を維持する。
例: Deque=[7, 5, 3] に6を追加 → 5と3を除去 → Deque=[7, 6]。先頭は常に最大値を指す。

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 各要素はDequeに最大1回追加され、最大1回除去されるため、全体でO(n)になる |
| Space | O(k) — Dequeにはウィンドウサイズk以下の要素しか保持されない |

## コード

```java
// 入力: 整数配列 nums と整数 k（ウィンドウサイズ）
// 出力: 各ウィンドウ位置での最大値を格納した int[] を返す。要素数は n - k + 1 個になる
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    // 各ウィンドウの最大値を格納する結果配列。ウィンドウは n - k + 1 個存在する
    int[] result = new int[n - k + 1];
    // 最大値候補のインデックスを単調減少で保持するDeque
    // Dequeには「ウィンドウ内で最大値になる可能性があるインデックス」を、対応する値が単調減少になるよう保持する
    ArrayDeque<Integer> deque = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // 先頭のインデックスがウィンドウの左端 i - k + 1 より小さければウィンドウ外なので除去する
        // ウィンドウは1つずつスライドするので、ウィンドウ外になる要素は各ステップで最大1つ
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }

        // 末尾から現在の要素 nums[i] 以下の候補を全て除去して単調減少を維持する
        // これらの要素は nums[i] が存在する限り最大値になれないため、候補から除外してよい
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }

        // 現在のインデックスをDequeの末尾に追加する
        // 上のwhileで自分以下の要素を除去済みなので、追加後もDequeは単調減少のまま
        deque.offerLast(i);

        // i >= k - 1 のとき、ウィンドウにk個の要素が揃っている
        // Dequeの先頭が現在のウィンドウ内の最大値のインデックスを指している
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    // 全ウィンドウの最大値が記録された result を返す
    return result;
}
```
