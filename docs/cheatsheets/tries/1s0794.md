# Finding All Words From a Dictionary in a Grid — グリッド上で辞書の全単語を同時に探索する

## 問題の本質

文字の2Dグリッド `board` と単語リスト `words` が与えられる。グリッド上で隣接するセル（上下左右）を順にたどって構成できる単語を、`words` の中からすべて見つけて返す。各セルは1つの単語の構成中に1回しか使えない。

## 核心のアイデア

単語リストの全単語をTrieに格納し、グリッドの各セルからDFSを行う際にTrieノードをたどることで、全単語を同時に探索する。Trieの枝が存在しない方向へのDFSを即座に打ち切れるため、無駄な探索を大幅に削減できる。

## 思考プロセス

1. **複数単語を同時に探索したい**: 単語ごとに個別にDFSすると、単語数×グリッド全セル×最大単語長の計算量になる。複数の単語が同じ接頭辞を共有している場合、1回のDFSで複数の単語を同時に探索できれば効率的である
2. **共通接頭辞の管理にはTrieが適している**: Trieは接頭辞木とも呼ばれ、文字列の共通接頭辞を1つのパスとして共有する。全単語をTrieに挿入すれば、DFS中に現在のパスがどの単語の接頭辞に該当するかをO(1)で判定できる
3. **Trieノードに単語そのものを保存する**: 単語の末尾ノードに完成した単語文字列を保存しておけば、DFSがそのノードに到達した時点で「どの単語が見つかったか」を即座に取得できる
4. **グリッドの各セルからTrieのルートを起点にDFSする**: 各セルを開始点として、Trieのルートから文字をたどりながらDFSを行う。現在の文字に対応する子ノードがTrieに存在しなければ、その方向の探索を即座に打ち切る（枝刈り）
5. **訪問済みセルのマーキング**: DFS中に同じセルを再訪問しないよう、現在訪問中のセルの文字を特殊文字 `'#'` に一時的に置き換える。DFS終了後に元の文字に復元する（バックトラッキング）
6. **重複防止**: 同じ単語が複数のパスで見つかる可能性がある。単語を結果リストに追加した時点で、そのTrieノードの `word` を `null` に設定することで、同じ単語の重複追加を防ぐ

## 前提知識

### Trie（トライ木）とは

文字列の集合を効率的に格納・検索するための木構造。各ノードは最大26個の子ノード（a〜z）を持ち、ルートから葉へのパスが1つの文字列を表す。共通の接頭辞を持つ文字列はパスを共有するため、接頭辞の判定がO(文字列長)で行える。

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a〜zの26文字分の子ノード配列
    String word = null;                       // このノードで完成する単語（末尾でなければnull）
}

// Trieへの単語挿入
TrieNode root = new TrieNode();
TrieNode node = root;
for (char c : "cat".toCharArray()) {
    int i = c - 'a';                          // 文字をインデックスに変換（'a'→0, 'b'→1, ...）
    if (node.children[i] == null)
        node.children[i] = new TrieNode();    // 子ノードがなければ新規作成
    node = node.children[i];                  // 子ノードに移動
}
node.word = "cat";                            // 末尾ノードに単語を保存
```

### バックトラッキングとは

DFS（深さ優先探索）の一種で、探索中に状態を変更し、探索終了後に状態を元に戻す手法。これにより、1つの探索パスで使った状態変更が他のパスに影響しないことを保証する。

```java
board[r][c] = '#';    // 訪問中マークを付ける（他のパスがこのセルを再訪問しない）
// ... DFSで上下左右を探索 ...
board[r][c] = ch;     // 元の文字に復元する（他の開始点からの探索で再利用可能にする）
```

### char と int の変換

Javaでは `char` 型は整数値を持つため、文字の差を計算してインデックスに変換できる。

```java
char ch = 'c';
int index = ch - 'a';   // 'c' - 'a' = 2（配列のインデックスとして使用）
```

## 計算量

| | 値 |
|---|---|
| Time | O(M × N × 4^L) — M×Nはグリッドのセル数、Lは最長単語の長さ。各セルから最大4方向にL回再帰する |
| Space | O(全単語の文字数の合計) — Trieに全単語を格納する領域 |

## コード

```java
// 入力: 文字の2D配列 board と文字列配列 words
// 出力: board 上で構成可能な単語をすべて格納した List<String> を返す

class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a〜zの子ノード
    String word = null;                       // このノードで完成する単語
}

// 全単語をTrieに挿入してルートノードを返す
TrieNode buildTrie(String[] words) {
    // 空のTrieを構築するため、ルートノードを1つ作成する（全単語の探索の起点）
    TrieNode root = new TrieNode();
    // words の各単語をTrieに挿入する
    for (String w : words) {
        TrieNode node = root;
        // ルートから1文字ずつ子ノードをたどる
        for (char c : w.toCharArray()) {
            int i = c - 'a';
            // 子ノードが存在しなければ新規作成する
            if (node.children[i] == null)
                node.children[i] = new TrieNode();
            node = node.children[i];
        }
        // 単語の末尾ノードに単語文字列を保存（DFS中にノード到達で完成した単語を即座に取得できる）
        node.word = w;
    }
    return root;
}

// Trieノードをたどりながらグリッド上をDFSする
void dfs(char[][] board, int r, int c,
    TrieNode node, List<String> res) {
    // 境界チェック: 行 r または列 c がグリッドの範囲外なら即座にリターン
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length)
        return;
    char ch = board[r][c];
    // 訪問中マーク '#' のセルなら即座にリターン（同一パス内での再訪問を防ぐ）
    if (ch == '#') return;
    // 現在の文字に対応するTrieの子ノードを取得
    TrieNode next = node.children[ch - 'a'];
    // 子ノードがなければこの方向に続く単語はTrieに存在しない（枝刈り）
    if (next == null) return;
    // 単語が完成していれば結果に追加し、重複防止のためnullに設定する
    // （同じ単語が複数のパスで見つかる可能性があるため）
    if (next.word != null) {
        res.add(next.word);
        next.word = null;
    }
    // 現在のセルを '#' に置き換えて訪問中とマークする
    board[r][c] = '#';
    // 上下左右の4方向に対して、nextノードを渡して再帰的にDFS
    dfs(board, r + 1, c, next, res);
    dfs(board, r - 1, c, next, res);
    dfs(board, r, c + 1, next, res);
    dfs(board, r, c - 1, next, res);
    // セルの文字を元の ch に復元する（バックトラッキング: 他の開始点からの探索で再利用可能にする）
    board[r][c] = ch;
}

// メイン関数: グリッド上で辞書の全単語を探索する
List<String> findWords(char[][] board, String[] words) {
    // 全単語をTrieに挿入
    TrieNode root = buildTrie(words);
    // 結果を格納する空のリストを作成
    List<String> res = new ArrayList<>();
    // 2重forループで全セル (i, j) を走査し、各セルを開始点としてDFSを実行
    // DFSにはTrieのルートノードを渡す
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            dfs(board, i, j, root, res);
        }
    }
    // 全セルからのDFSが完了した後、結果を返す
    return res;
}
```
