# Designing a Word Dictionary With Wildcard Search — ワイルドカード付き辞書の単語検索

## 問題の本質

単語の追加と検索の2つの操作をサポートするデータ構造を設計する。検索時にドット `.` はどの1文字にもマッチするワイルドカードとして機能する。例えば、辞書に "bad" が登録されているとき、`search("b.d")` は `true` を返し、`search("b.e")` は `false` を返す。

## 核心のアイデア

Trieに単語を格納し、通常の文字はその子ノードを1つたどるだけでよいが、ドットに遭遇したら「全ての子ノード」に分岐して深さ優先探索を行えば、任意の1文字にマッチする検索を実現できる。

## 思考プロセス

1. **単語の追加と前方一致検索を効率的に行いたい**: 文字列を1文字ずつ共有しながら格納できるデータ構造としてTrieが適している。Trieを使えば、共通のプレフィックスを持つ単語同士でノードを共有でき、メモリ効率と検索効率が両立する
2. **通常文字の検索はTrieの基本操作で対応できる**: 文字 `c` に対しては、現在のノードの `children[c - 'a']` をたどるだけでよい。子ノードが `null` なら不一致、存在すれば次の文字へ進む
3. **ドットは全ての子ノードへの分岐を意味する**: ドットは任意の1文字にマッチするので、現在のノードの26個の子ノードのうち `null` でないもの全てを試す必要がある。いずれか1つでも残りの文字列とマッチすれば `true` を返せばよい
4. **分岐の探索には深さ優先探索（DFS）を使う**: ドットで分岐した各経路を再帰的にたどり、単語の末尾に到達したときに `isEnd` フラグが `true` であれば検索成功とする。DFSを使えば、分岐の処理と通常文字の処理を統一的に扱える
5. **再帰の終了条件を定める**: 文字列の全文字を処理し終えた時点（`idx == word.length()`）で、現在のノードの `isEnd` が `true` であれば単語が存在する。途中で子ノードが `null` になった場合はその経路では不一致とする
6. **最終的に返すもの**: `search` メソッドはルートノードから再帰的にDFSを開始し、マッチする経路が1つでもあれば `true`、なければ `false` を返す

## 前提知識

### Trie（トライ木）とは

文字列を1文字ずつノードに分解して格納する木構造。各ノードは最大26個の子ノード（a〜z）を持ち、ルートから葉に向かってたどると1つの単語になる。共通のプレフィックスを持つ単語はノードを共有するため、辞書の格納に適している。

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // a〜zに対応する26個の子ノード
    boolean isEnd = false;                    // この地点で終わる単語が存在するか
}
```

### 深さ優先探索（DFS）とは

木やグラフの探索手法の1つ。1つの経路を末端まで進み、行き止まりに到達したら1つ戻って別の経路を試す。再帰で実装するのが自然で、Trieの分岐探索に適している。

```java
boolean dfs(TrieNode node, String word, int idx) {
    // idxは現在処理中の文字位置
    // 再帰的に子ノードをたどり、条件を満たす経路を探す
}
```

### char の整数変換

Javaでは `char` 型は整数値を持つ。`c - 'a'` で文字 `c` のアルファベット上の位置（0〜25）を得られる。この値をTrieの `children` 配列のインデックスとして使う。

```java
char c = 'd';
int idx = c - 'a';  // idx = 3（'a'=0, 'b'=1, 'c'=2, 'd'=3）
```

## 計算量

| | 値 |
|---|---|
| Time (addWord) | O(m) — 単語の長さmに比例してTrieノードをたどる |
| Time (search) | O(26^d × m) — dはドットの個数、mは単語の長さ。ドットがなければO(m) |
| Space | O(n × m) — n個の単語（平均長さm）をTrieに格納する |

## コード

```java
// 入力: addWord(word) は文字列 word を受け取り辞書に追加する。search(word) は文字列 word（"." を含みうる）を受け取る
// 出力: search は辞書に一致する単語が存在すれば true、存在しなければ false を返す

class TrieNode {
    TrieNode[] children;  // a〜zに対応する26個の子ノード
    boolean isEnd;        // この地点で終わる単語が存在するか

    TrieNode() {
        children = new TrieNode[26];
        isEnd = false;
    }
}

class WordDictionary {
    TrieNode root;  // Trieのルートノード

    WordDictionary() {
        root = new TrieNode();
    }

    // 単語をTrieに追加する
    void addWord(String word) {
        // 現在のノードをルートで初期化する
        TrieNode node = root;
        // 単語の各文字を先頭から順に処理する
        for (char c : word.toCharArray()) {
            // c - 'a' で children 配列のどの位置に文字 c が対応するかを求める
            int idx = c - 'a';
            // 子ノードが存在しなければ新規作成する
            if (node.children[idx] == null)
                node.children[idx] = new TrieNode();
            // 子ノードへ移動する
            node = node.children[idx];
        }
        // 単語の終端を記録する。この地点で終わる単語が辞書に存在することを示す
        node.isEnd = true;
    }

    // ワイルドカード付きの検索をルートから開始する
    boolean search(String word) {
        // ルートノードから位置0でDFSを開始する
        return dfs(root, word, 0);
    }

    // DFSで再帰的にTrieを探索する
    boolean dfs(TrieNode node, String word, int idx) {
        // 終了条件: 全文字を処理し終えたら、現在のノードが単語の終端かを返す
        // true なら単語が存在し、false なら途中までしか一致する単語がない
        if (idx == word.length())
            return node.isEnd;

        char c = word.charAt(idx);

        if (c == '.') {
            // ドットの場合：26個の子ノードを全て試す（任意の1文字にマッチ）
            for (TrieNode child : node.children) {
                // null でない子ノードに対して再帰的に探索する
                if (child != null && dfs(child, word, idx + 1))
                    return true;  // いずれかの経路でマッチすれば即座に true を返す
            }
            // 全ての子ノードを試しても true が返らなければ不一致
            return false;
        } else {
            // 通常文字の場合：c - 'a' でインデックスを求め、対応する子ノードをたどる
            int i = c - 'a';
            // 子ノードが存在しなければ対応する文字がないので不一致
            if (node.children[i] == null)
                return false;
            // 子ノードが存在すれば次の文字位置 idx + 1 で再帰する
            return dfs(node.children[i], word, idx + 1);
        }
    }
}
```
