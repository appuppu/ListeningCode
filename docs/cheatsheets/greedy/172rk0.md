# Checking Validity of a Parenthesis String With Wildcards — ワイルドカード付き括弧文字列の妥当性を判定する

## 問題の本質

`(`、`)`、`*` の3種類の文字のみからなる文字列が与えられる。`*` は `(`、`)`、または空文字のいずれかとして扱える。この文字列が**有効な括弧列**になり得るかどうかを判定して `boolean` で返す。

## 核心のアイデア

`*` の扱いが不確定なので、開き括弧の数を1つの値ではなく「取りうる範囲（最小値 low ～ 最大値 high）」として追跡する。この範囲が走査中に常に有効であり、最終的に0を含んでいれば、文字列は有効である。

## 思考プロセス

1. **括弧の妥当性は開き括弧のカウントで判定できる**: 文字列を左から走査し、`(` で+1、`)` で-1する。途中でカウントが負になったら無効、最終的に0なら有効。これが括弧判定の基本原理である
2. **`*` があるとカウントが1つの値に定まらない**: `*` は3通りの解釈ができるので、カウントは単一の値ではなく「範囲」になる。`*` を `(` と解釈すればカウントは+1、`)` と解釈すれば-1、空文字なら±0。つまり `*` に遭遇するたびに範囲が広がる
3. **範囲を2つの変数で追跡する**: `low` は開き括弧カウントの最小値（`*` をできるだけ `)` や空文字として扱った場合）、`high` は最大値（`*` をできるだけ `(` として扱った場合）を表す。この2変数だけで全パターンを網羅できる
4. **走査中に `high` が負になったら即座に無効と判定する**: `high` は開き括弧カウントの最大値なので、これが負になるということは、どの `*` の解釈を選んでも `)` が過剰であり、有効な括弧列にはなり得ない
5. **`low` が負になったら0にクランプする**: `low` が負になるのは「`)` を余らせる解釈」を含んでいるだけで、`*` を空文字として扱えばカウント0以上を維持できる。負の値は現実には選ばない解釈なので、`low` を0に補正する
6. **最終的に `low == 0` かどうかで判定する**: 走査が完了した時点で、`low` が0であれば「開き括弧がすべて閉じられる解釈が存在する」ことを意味するので `true` を返す

## 前提知識

### 括弧列の妥当性判定の基本原理

文字列を左から走査し、開き括弧のカウントを管理する。`(` で+1、`)` で-1し、途中で負にならず最終的に0なら有効な括弧列である。

```java
int count = 0;
for (char c : s.toCharArray()) {
    if (c == '(') count++;
    else count--;
    if (count < 0) return false;  // 閉じ括弧が過剰
}
return count == 0;  // 開き括弧が全て閉じられたか
```

### Math.max とは

2つの値のうち大きい方を返すメソッド。値が特定の下限を下回らないように補正（クランプ）する用途に使える。

```java
Math.max(3, 0);    // → 3（3は0以上なのでそのまま）
Math.max(-1, 0);   // → 0（-1は0未満なので0に補正される）
```

### toCharArray とは

文字列を `char` の配列に変換するメソッド。for-each ループで文字列を1文字ずつ走査するときに使う。

```java
String s = "(*)"；
char[] chars = s.toCharArray();  // → ['(', '*', ')']
for (char c : s.toCharArray()) {
    // c に1文字ずつ代入されてループが回る
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 文字列を1回走査するだけで済む |
| Space | O(1) — 変数 `low` と `high` の2つのみを使用する |

## コード

```java
// 入力: '('、')'、'*' のみからなる文字列 s
// 出力: 文字列が有効な括弧列になり得るかを boolean で返す
public boolean checkValidString(String s) {
    // low: 開き括弧カウントの最小値、high: 最大値
    // この2変数で * の全解釈パターンにおけるカウントの範囲を追跡する
    int low = 0, high = 0;

    // 文字列を先頭から1文字ずつ走査する
    for (char c : s.toCharArray()) {
        if (c == '(') {
            // 開き括弧: どの解釈でもカウントを1増やすので、範囲の両端を+1する
            low++;
            high++;
        } else if (c == ')') {
            // 閉じ括弧: どの解釈でもカウントを1減らすので、範囲の両端を-1する
            low--;
            high--;
        } else {
            // '*': ) と解釈すれば最小値は下がり、( と解釈すれば最大値は上がる
            // 空文字の解釈はこの範囲の中に含まれる
            low--;
            high++;
        }

        // 最大値が負なら、どの * の解釈を選んでも閉じ括弧が過剰なので無効
        if (high < 0) return false;

        // low が負になるのは ) として解釈しすぎた場合であり、
        // 実際にはその解釈を選ばなければよいだけなので、最小値を0に補正する
        low = Math.max(low, 0);
    }

    // low が0なら「全ての開き括弧が閉じられる * の解釈が存在する」ので true
    // low が0より大きければ、どう解釈しても開き括弧が余るので false
    return low == 0;
}
```
