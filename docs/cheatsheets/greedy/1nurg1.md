# Finding the Subarray With Maximum Sum — 最大の合計を持つ連続部分配列を見つける

## 問題の本質

整数の配列 `nums` が与えられる。配列には正の数と負の数の両方が含まれる可能性がある。連続する部分配列（subarray）の中で、要素の合計が最大となるものを見つけ、その**合計値**を返す。

## 核心のアイデア

各要素に到達したとき、「これまでの部分配列を延長する」か「この要素から新しい部分配列を始める」かの2択しかない。これまでの累積和が負なら、それを引きずるよりも捨てて新しく始めた方が必ず得になる。

## 思考プロセス

1. **各要素での選択は2つしかない**: 要素 `nums[i]` に到達したとき、取れる行動は「直前までの部分配列に `nums[i]` を追加して延長する」か「`nums[i]` を先頭として新しい部分配列を始める」の2つだけである。連続部分配列という制約上、途中の要素を飛ばすことはできない
2. **延長するか新規に始めるかの判断基準**: 直前までの累積和 `currentSum` が正であれば、`nums[i]` に足すことで `nums[i]` 単体よりも大きくなるので延長する。`currentSum` が負であれば、足すと `nums[i]` 単体よりも小さくなるので捨てて新しく始める。つまり `currentSum + nums[i]` と `nums[i]` の大きい方を選べばよい
3. **この判断を `Math.max` で表現する**: `currentSum = Math.max(currentSum + nums[i], nums[i])` の1行で、延長と新規開始の判断が完了する。`currentSum + nums[i]` が延長、`nums[i]` が新規開始に対応する
4. **全体の最大値を別途追跡する**: `currentSum` は「現在の部分配列の合計」であり、走査の途中で値が上下する。問題が求めるのは「全体を通じての最大合計」なので、別の変数 `maxSum` で走査中に出現した `currentSum` の最大値を記録し続ける
5. **`maxSum` の初期値は `Integer.MIN_VALUE` にする**: 配列の全要素が負の場合でも正しく動作するように、`maxSum` の初期値は整数の最小値にする。0で初期化すると、全要素が負のとき「空の部分配列（合計0）」が最大と誤判定してしまう
6. **最終的に `maxSum` を返す**: 配列の走査が終了した時点で、`maxSum` には全ての連続部分配列の中での最大合計が記録されている。この値を返す

## 前提知識

### Math.max とは

2つの値を受け取り、大きい方を返すJavaの標準メソッド。条件分岐を1行で表現できる。

```java
Math.max(5, 3);       // 2つの値のうち大きい方を返す → 5
Math.max(-2, -7);     // 負の数同士でも大きい方を返す → -2
Math.max(a + b, b);   // 式の結果同士を比較することもできる
```

### Integer.MIN_VALUE とは

Javaにおける `int` 型の最小値（-2,147,483,648）を表す定数。「まだ何も比較していない」状態の初期値として使う。どんな整数と比較しても `Math.max` で必ず相手側が選ばれる。

```java
int maxSum = Integer.MIN_VALUE;   // int型の最小値で初期化する
maxSum = Math.max(maxSum, -5);    // どんな値でもmaxSumより大きい → -5
```

### 連続部分配列（subarray）とは

配列の中で、隣接する要素を途切れなく取り出した部分のこと。要素を飛ばして選ぶことはできない。
例: `nums = [-2, 1, -3, 4, -1, 2]` のとき、`[4, -1, 2]` は連続部分配列（合計5）。`[1, 4, 2]` は要素が隣接していないので連続部分配列ではない。

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 使用する変数は `maxSum` と `currentSum` の2つだけである |

## コード

```java
// 入力: 正の数と負の数を含みうる整数配列 nums
// 出力: 連続部分配列の合計値の最大値を int で返す
public int maxSubArray(int[] nums) {
    // 走査全体を通じて出現した部分配列の合計の最大値を記録する変数
    // 全要素が負の場合でも正しく最大値を選べるようにInteger.MIN_VALUEで初期化する
    // 注意: 0で初期化すると、全要素が負のとき「空の部分配列（合計0）」が最大と誤判定してしまう
    int maxSum = Integer.MIN_VALUE;
    // 現在構築中の部分配列の合計を保持する変数。走査開始時点ではまだどの要素も含んでいないので0
    int currentSum = 0;

    // 配列を先頭から末尾まで1つずつ走査する
    for (int num : nums) {
        // currentSum + num は「直前までの部分配列を延長した場合の合計」
        // num は「この要素から新しい部分配列を始めた場合の合計」
        // 大きい方を選ぶことで、常に最適な判断ができる
        currentSum = Math.max(currentSum + num, num);
        // 現在の部分配列の合計がこれまでの最大値を超えていれば更新し、超えていなければ維持する
        maxSum = Math.max(maxSum, currentSum);
    }
    // 走査が終了した時点で、maxSum には全ての連続部分配列の中で最大の合計値が記録されている
    return maxSum;
}
```
