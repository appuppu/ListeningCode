# Finding the Starting Gas Station for a Circular Route — 円環ルートを一周できる開始ガソリンスタンドを見つける

## 問題の本質

長さ `n` の整数配列 `gas` と `cost` が与えられる。`gas[i]` はステーション `i` で得られる燃料、`cost[i]` はステーション `i` から次のステーションへ移動するのに必要な燃料である。円環ルートを一周できる開始ステーションのインデックスを返す。一周できるステーションが存在しない場合は `-1` を返す。解は最大1つしか存在しない。

## 核心のアイデア

全ステーションの燃料収支の合計が非負なら必ず解が存在する。現在の燃料残量が負になった地点までのステーションは開始地点になり得ないので、次のステーションを新たな開始候補としてリセットすれば、1回の走査で答えが見つかる。

## 思考プロセス

1. **各ステーションの燃料収支を考える**: ステーション `i` では `gas[i]` の燃料を得て `cost[i]` の燃料を消費するので、正味の燃料変化は `net = gas[i] - cost[i]` で表せる。この `net` が正ならそのステーションは燃料の余剰を生み、負なら燃料の不足を生む
2. **一周できる条件を判定する**: 全ステーションの `net` の合計（`totalBalance`）が非負であれば、ルート全体で得られる燃料が消費する燃料以上なので、必ずどこかの開始地点から一周できる。逆に `totalBalance` が負なら、どこから出発しても燃料が足りないので解は存在しない
3. **開始候補を効率的に絞り込む**: ステーション `start` から出発して走査を進め、ある地点 `i` で累積燃料残量（`currentBalance`）が負になったとする。このとき、`start` から `i` までのどのステーションから出発しても、`i` を越えることはできない。なぜなら、`start` から途中のステーション `j` までの累積は非負だったので、`j` から出発すると燃料がさらに少ない状態で `i` に到達するからである。したがって、`start` から `i` までの全ステーションを一括で除外し、`i + 1` を新たな開始候補とする
4. **currentBalance をリセットして走査を続ける**: 新しい開始候補 `i + 1` から再び燃料残量を追跡するため、`currentBalance` を `0` にリセットし、`start` を `i + 1` に更新する。走査自体は最初から最後まで1回だけ行えばよい
5. **走査終了後に totalBalance で最終判定する**: 走査が終わった時点で、`totalBalance >= 0` なら解が存在するので `start` を返す。`totalBalance < 0` なら一周不可能なので `-1` を返す

## 前提知識

### net（正味の燃料変化）とは

各ステーションにおける燃料の収支。`net = gas[i] - cost[i]` で計算する。正なら燃料が余り、負なら燃料が不足することを意味する。

```java
int net = gas[i] - cost[i];  // ステーションiでの燃料収支を計算する
// 例: gas[i]=3, cost[i]=5 のとき net=-2（燃料が2不足する）
// 例: gas[i]=4, cost[i]=1 のとき net=3（燃料が3余る）
```

### totalBalance と currentBalance の役割

`totalBalance` はルート全体の燃料収支の合計で、一周可能かどうかの判定に使う。`currentBalance` は現在の開始候補から走査中のステーションまでの累積燃料残量で、開始候補の更新判定に使う。

```java
int totalBalance = 0;    // ルート全体の燃料収支合計（一周可能かの判定用）
int currentBalance = 0;  // 現在の開始候補からの累積燃料残量（候補更新の判定用）
totalBalance += net;     // 全ステーションについて常に加算し続ける
currentBalance += net;   // 開始候補をリセットするたびに0に戻す
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 使用する変数は3つだけで、入力サイズに依存しない |

## コード

```java
// 入力: 整数配列 gas（各ステーションで得られる燃料）と整数配列 cost（各ステーションから次へ移動するのに必要な燃料）
// 出力: 円環ルートを一周できる開始ステーションのインデックスを int で返す。一周できない場合は -1 を返す
public int canCompleteCircuit(int[] gas, int[] cost) {
    // ルート全体の燃料収支合計（一周可能かの最終判定に使う）
    int totalBalance = 0;
    // 現在の開始候補からの累積燃料残量（候補リセットの判定に使う）
    int currentBalance = 0;
    // 開始候補のインデックス（0から始め、リセットのたびに更新する）
    int start = 0;

    // 配列をインデックス 0 から末尾まで1つずつ走査する
    for (int i = 0; i < gas.length; i++) {
        // ステーションiでの正味の燃料変化を計算する
        int net = gas[i] - cost[i];
        // ルート全体の燃料収支に常に加算する（最終的に一周可能かの判定に使う）
        totalBalance += net;
        // 現在の開始候補からの累積燃料残量に加算する（ステーションi到着時点での燃料残量に相当する）
        currentBalance += net;

        // 累積燃料残量が負になったら、startからiまでのどのステーションも開始地点になり得ない
        if (currentBalance < 0) {
            // 累積燃料残量をリセットして次のステーションを新たな開始候補とする
            currentBalance = 0;
            start = i + 1;
        }
    }
    // ルート全体の燃料収支が非負なら一周可能なので start を返し、負なら不可能なので -1 を返す
    return totalBalance >= 0 ? start : -1;
}
```
