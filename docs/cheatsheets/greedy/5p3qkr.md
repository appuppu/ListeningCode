# Partitioning a String Into Maximum Parts — 各文字が1つのパートにのみ含まれるように文字列を最大数に分割する

## 問題の本質

小文字英字からなる文字列 `s` が与えられる。各文字がたかだか1つのパートにしか含まれないように、文字列をできるだけ多くのパートに分割する。各パートの**長さ**をリストで返す。

## 核心のアイデア

ある文字が現在のパートに含まれるなら、その文字の最後の出現位置までパートを延長しなければならない。各文字の最終出現位置を事前に計算しておけば、1回の走査で貪欲にパートの境界を確定できる。

## 思考プロセス

1. **分割の制約を理解する**: 同じ文字が2つのパートに跨ってはいけない。つまり、ある文字を含むパートは、その文字の最後の出現位置までを少なくとも含む必要がある
2. **各文字の最終出現位置を事前に求める**: 文字列を1回走査し、各文字が最後に現れるインデックスを配列に記録する。英小文字は26種類しかないので、サイズ26の配列で十分である
3. **パートの終端を貪欲に拡張する**: 文字列を先頭から走査し、現在のパートに含まれる全文字の最終出現位置の最大値を `end` として追跡する。新しい文字に出会うたびに、`end` をその文字の最終出現位置と比較して更新する
4. **パートの確定条件を見極める**: 現在のインデックス `i` が `end` に到達したとき、現在のパート内の全文字がこのパートの範囲内に収まっていることが保証される。このタイミングでパートを確定し、次のパートを開始する
5. **パートの長さを計算する**: パートが確定するたびに、`end - start + 1` でパートの長さを求め、結果リストに追加する。次のパートの開始位置 `start` を `i + 1` に更新する

## 前提知識

### 文字のインデックス変換

Javaでは `char` 型は整数として扱える。`s.charAt(i) - 'a'` により、小文字の `'a'` を `0`、`'b'` を `1`、...、`'z'` を `25` に変換できる。これにより、サイズ26の配列で全小文字を管理できる。

```java
char c = 'c';
int index = c - 'a';    // 2（'c'は'a'から2番目）
int[] arr = new int[26]; // 26文字分の配列
arr[c - 'a'] = 5;       // 'c'に対応する位置に値5を格納
```

### Math.max とは

2つの値のうち大きい方を返すメソッド。パートの終端を拡張する際に、現在の `end` と新しい文字の最終出現位置を比較して、より遠い方を採用するために使う。

```java
Math.max(3, 7);   // 7を返す
Math.max(10, 2);  // 10を返す
```

### ArrayList とは

可変長のリスト。パート数が事前にわからないため、パートの長さを1つずつ追加していくのに適している。

```java
List<Integer> res = new ArrayList<>();  // 空のリストを作成
res.add(9);    // 末尾に9を追加 → [9]
res.add(7);    // 末尾に7を追加 → [9, 7]
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 文字列を2回走査するだけで済む（最終位置の記録に1回、パート分割に1回） |
| Space | O(1) — サイズ26の固定配列のみを使用し、入力サイズに依存しない |

## コード

```java
// 入力: 小文字英字からなる文字列 s
// 出力: 各パートの長さを格納した List<Integer> を返す
List<Integer> partitionLabels(String s) {
    // サイズ26の整数配列で、各文字('a'〜'z')の最終出現インデックスを保存する
    // 英小文字は26種類しかないのでサイズ26で固定
    int[] last = new int[26];

    // 1回目の走査: 各文字の最終出現位置を記録する
    // 同じ文字が複数回出現する場合、後のインデックスで上書きされるため最後の位置が残る
    for (int i = 0; i < s.length(); i++) {
        last[s.charAt(i) - 'a'] = i;
    }

    // パート数が事前にわからないので可変長リストを使う
    List<Integer> res = new ArrayList<>();
    // start: 現在のパートの開始位置、end: 現在のパートの終端位置
    int start = 0, end = 0;

    // 2回目の走査: パートを貪欲に確定していく
    for (int i = 0; i < s.length(); i++) {
        // 現在の文字の最終出現位置が end より遠ければ、パートの終端をそこまで拡張する
        // これにより、パート内の全文字の最終出現位置の最大値が end に常に保持される
        end = Math.max(end,
            last[s.charAt(i) - 'a']);

        // i が end に到達 → パート内の全文字がこの範囲に収まっていることが保証される
        // なぜなら、パート内のどの文字も end より後には出現しないから
        if (i == end) {
            // end - start + 1 でパートの長さを計算し結果リストに追加
            res.add(end - start + 1);
            // 次のパートの開始位置を更新
            start = i + 1;
        }
    }
    // 全パートの長さが格納されたリストを返す
    return res;
}
```
