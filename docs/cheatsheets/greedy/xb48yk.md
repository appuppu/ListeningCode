# Dividing Cards Into Consecutive Groups — カードを指定サイズの連続グループに分割できるか判定する

## 問題の本質

整数配列 `hand`（カードの値）と整数 `groupSize` が与えられる。すべてのカードを、各グループが `groupSize` 枚の**連続した値**で構成されるグループに分割できるかを `boolean` で返す。カードは過不足なくすべて使い切る必要がある。

## 核心のアイデア

カードを小さい値から貪欲に処理すれば、各カードが属すべきグループは一意に決まる。最小のカードから連続グループを作り、使ったカードを取り除くことを繰り返し、すべてのカードを使い切れれば分割可能である。

## 思考プロセス

1. **前提条件を確認する**: カードを `groupSize` 枚ずつのグループに分けるので、カードの総数が `groupSize` で割り切れなければ、分割は不可能である。この判定を最初に行うことで、不要な処理を省ける
2. **最小のカードから処理すべき理由**: 最小のカードは、自分自身を先頭とする連続グループにしか属せない。たとえば最小値が3で `groupSize` が3なら、そのカードは必ず [3, 4, 5] のグループに入る。よって最小値から貪欲に処理する戦略が正しい
3. **各カードの出現回数を管理する必要がある**: 同じ値のカードが複数枚ある場合があるので、各値の出現回数（頻度）を記録するデータ構造が必要である。さらに最小値を効率的に取得したいので、キーがソートされたTreeMapが適している
4. **グループ構築の手順**: TreeMapから最小キー `first` を取得し、`first` から `first + groupSize - 1` までの連続する値がすべてTreeMapに存在するかを確認する。存在すれば各値の頻度を1減らし、頻度が0になった値はTreeMapから削除する
5. **連続する値が不足した場合**: グループ構築中に必要な値がTreeMapに存在しなければ、その時点で分割不可能と判定し `false` を返す
6. **すべてのカードを処理し終えたら成功**: TreeMapが空になるまでグループ構築を繰り返し、すべて成功すれば `true` を返す

## 前提知識

### TreeMap とは

キーが常にソート順で管理されるMapデータ構造。HashMapと同様にキーと値のペアを保存できるが、キーの順序に基づく操作（最小キーの取得など）がO(log n)で可能である。内部は赤黒木（自己平衡二分探索木）で実装されている。

```java
TreeMap<Integer, Integer> tm = new TreeMap<>();  // 空のTreeMapを作成
tm.put(5, 2);           // キー5に値2を格納する
tm.put(3, 1);           // キー3に値1を格納する
tm.firstKey();           // 最小のキーを返す → 3
tm.containsKey(5);       // キー5が存在するかをbooleanで返す → true
tm.get(5);               // キー5に対応する値を返す → 2
tm.remove(3);            // キー3とその値を削除する
```

### getOrDefault とは

Mapから値を取得する際に、キーが存在しなければ指定したデフォルト値を返すメソッド。頻度カウントで `null` チェックを省略できる。

```java
TreeMap<Integer, Integer> tm = new TreeMap<>();
tm.getOrDefault(10, 0);  // キー10が存在しないのでデフォルト値0を返す → 0
tm.put(10, 3);
tm.getOrDefault(10, 0);  // キー10が存在するのでその値を返す → 3
```

### 貪欲法（Greedy）とは

各ステップで局所的に最適な選択を行い、全体の最適解を求める手法。この問題では「最小のカードから順にグループを作る」という貪欲な選択が、全体として正しい分割を導く。最小のカードは他のグループの途中に入れることができないため、貪欲な選択が最適解と一致する。

## 計算量

| | 値 |
|---|---|
| Time | O(n log n) — TreeMapへの挿入・削除が各O(log n)で、全カードn枚を処理する |
| Space | O(n) — TreeMapに最大n個のエントリを保存する |

## コード

```java
// 入力: 整数配列 hand（カードの値）と整数 groupSize（各グループのサイズ）
// 出力: すべてのカードを連続値のグループに分割できれば true、できなければ false を返す
public boolean isNStraightHand(int[] hand, int groupSize) {
    // カードの総数がグループサイズで割り切れなければ均等なグループ分けは不可能
    if (hand.length % groupSize != 0)
        return false;

    // キー=カードの値、バリュー=残り枚数（頻度）を保存するTreeMap
    // TreeMapを使う理由: 最小のカード値をO(log n)で取得できるため
    TreeMap<Integer, Integer> tm = new TreeMap<>();
    // 各カードの出現回数をカウントし、getOrDefaultで既存の頻度に1を加算する
    for (int card : hand) {
        tm.put(card, tm.getOrDefault(card, 0) + 1);
    }

    // TreeMapが空になるまでグループを構築する（空になれば全カードを分割できたことを意味する）
    while (!tm.isEmpty()) {
        // 現在の最小カード値を取得し、グループの先頭とする
        // 最小値は他のグループの途中に入れることができないため、必ず新しいグループの先頭になる
        int first = tm.firstKey();

        // firstからgroupSize個の連続する値でグループを作る
        for (int i = 0; i < groupSize; i++) {
            int cur = first + i;

            // 連続する値が存在しなければグループを構成できないので分割不可能
            if (!tm.containsKey(cur))
                return false;

            // 頻度が1ならそのカードは最後の1枚なので削除、2以上なら頻度を1減らす
            if (tm.get(cur) == 1) {
                tm.remove(cur);
            } else {
                tm.put(cur, tm.get(cur) - 1);
            }
        }
    }

    // すべてのカードを連続グループに分割できた
    return true;
}
```
