# Finding the Minimum Jumps to Reach the End — 配列の末尾に到達するための最小ジャンプ回数を求める

## 問題の本質

整数配列 `nums` が与えられ、各要素 `nums[i]` はその位置から最大何マス先までジャンプできるかを表す。インデックス0からスタートして、最後のインデックスに到達するために必要な**最小ジャンプ回数**を返す。末尾には必ず到達できることが保証されている。

## 核心のアイデア

各ジャンプを「1回のジャンプで到達できる範囲（ウィンドウ）」として捉え、ウィンドウの境界に達するたびにジャンプ回数を1増やす。ウィンドウ内を走査しながら次のウィンドウの最遠到達点を記録することで、BFSのレベル探索と同じ効果をO(1)空間で実現できる。

## 思考プロセス

1. **最小回数を求める問題はBFSで解ける**: 各位置をノード、ジャンプ可能な範囲をエッジと見なすと、インデックス0から末尾への最短経路問題になる。BFSはレベルごとに探索するため、最初に末尾に到達したレベルが最小ジャンプ回数になる
2. **BFSのレベルをウィンドウで表現する**: 通常のBFSはキューを使ってO(n)の空間を消費する。しかし、配列上のジャンプでは各レベルで到達可能な範囲が連続区間になるため、区間の終端 `currentEnd` だけで現在のレベルを表現できる
3. **ウィンドウ内で次の最遠到達点を追跡する**: 現在のウィンドウ内（前回の `currentEnd` から今回の `currentEnd` まで）を走査しながら、各位置 `i` から到達できる最遠点 `i + nums[i]` の最大値を変数 `farthest` に記録する。これが次のウィンドウの終端になる
4. **ウィンドウの境界でジャンプを確定する**: インデックス `i` が `currentEnd` に到達したとき、現在のウィンドウを使い切ったことを意味する。このタイミングでジャンプ回数を1増やし、`currentEnd` を `farthest` に更新して次のウィンドウに移行する
5. **ループ範囲は末尾の1つ手前まで**: ループを `i < nums.length - 1` で回すことで、最後のインデックスに到達した時点で余分なジャンプを数えることを防ぐ。末尾に到達できることは保証されているため、到達判定は不要である
6. **最終的に返すもの**: ループ終了後、変数 `jumps` に蓄積された最小ジャンプ回数を返す

## 前提知識

### Greedy BFS（貪欲幅優先探索）とは

BFS（幅優先探索）は、グラフの始点から各ノードへの最短経路を求めるアルゴリズムである。通常はキューを使うが、配列上のジャンプ問題では到達可能範囲が連続区間になるため、区間の境界だけを管理する貪欲法で同じ結果を得られる。各レベル（ジャンプ1回分）で到達可能な最遠点を貪欲に選ぶことで、最小ジャンプ回数が求まる。

### Math.max とは

2つの整数のうち大きい方を返すJavaの標準メソッド。現在の最遠到達点と新たに計算した到達点を比較し、より遠い方を保持するために使う。

```java
Math.max(3, 7);       // 2つの値のうち大きい方を返す → 7
Math.max(farthest, i + nums[i]);  // 現在の最遠点と新たな到達点を比較する
```

### ウィンドウ（ジャンプ範囲）とは

1回のジャンプで到達できるインデックスの連続区間のこと。変数 `currentEnd` がウィンドウの右端を表す。`i` が `currentEnd` に到達すると、現在のウィンドウを使い切ったことを意味し、次のジャンプが必要になる。
例: `nums = [2,3,1,1,4]` の場合、最初のウィンドウは `[1,2]`（インデックス0から最大2マス先）、次のウィンドウは `[3,4]`（ウィンドウ内の最遠到達点4まで）である。

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 3つの変数のみを使用し、追加のデータ構造を必要としない |

## コード

```java
// 入力: 整数配列 nums（各要素はその位置からの最大ジャンプ長）
// 出力: 最後のインデックスに到達するための最小ジャンプ回数を int で返す
public int jump(int[] nums) {
    // ジャンプ回数を記録する変数。ウィンドウの境界に到達するたびに1増やす
    int jumps = 0;
    // 現在のジャンプウィンドウの右端。最初はインデックス0にいるので0で初期化する
    int currentEnd = 0;
    // ウィンドウ内から到達できる最遠のインデックス。次のウィンドウの右端を決定するために使う
    int farthest = 0;

    // 末尾の1つ手前まで走査する。末尾に到達した時点で目的達成なので、そこからさらにジャンプする必要がない
    for (int i = 0; i < nums.length - 1; i++) {
        // i + nums[i] は現在の位置iから最大ジャンプした場合の到達先インデックス
        // これまでのfarthestより遠ければ更新する
        farthest = Math.max(farthest, i + nums[i]);

        // 現在のウィンドウの右端に到達したら、次のジャンプが必要
        if (i == currentEnd) {
            // ジャンプ回数を1増やす
            jumps++;
            // 次のウィンドウの右端をfarthestに設定する。次のウィンドウの範囲は currentEnd+1 から新しい currentEnd まで
            currentEnd = farthest;
        }
    }
    // 蓄積された最小ジャンプ回数を返す
    return jumps;
}
```
