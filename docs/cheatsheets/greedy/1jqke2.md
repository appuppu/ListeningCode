# Determining if You Can Reach the End of an Array — 配列の末尾に到達できるかを判定する

## 問題の本質

整数の配列 `nums` が与えられる。各要素 `nums[i]` は、そのインデックスから前方にジャンプできる**最大の長さ**を表す。インデックス `0` からスタートして、配列の**最後のインデックス**に到達できるかを `boolean` で返す。

## 核心のアイデア

各位置で「ここから到達できる最遠地点」を更新し続ければ、その最遠地点が現在位置より手前に落ちた瞬間に到達不可能と判定できる。個々のジャンプ経路を追跡する必要はなく、「今までに到達可能な最遠インデックス」という1つの値だけで十分である。

## 思考プロセス

1. **到達可能性は最遠地点で決まる**: インデックス `i` に到達できるかどうかは、それ以前の全要素から計算される「到達可能な最遠インデックス」が `i` 以上であるかで判定できる。途中の経路の詳細は不要で、最遠地点だけが重要である
2. **最遠地点は1つの変数で管理できる**: 各インデックス `i` において `i + nums[i]` がそこからの最遠到達地点である。これまでの最遠地点と比較して大きい方を保持すれば、変数1つで全体の到達可能範囲を追跡できる
3. **到達不可能の判定条件**: 配列を左から順に走査するとき、現在のインデックス `i` が最遠地点 `maxReach` を超えていたら、インデックス `i` にはそもそも到達できない。つまり `i > maxReach` が到達不可能の条件である
4. **早期終了の条件**: `maxReach` が配列の最後のインデックス `nums.length - 1` 以上になった時点で、末尾に到達可能と確定するので、残りの走査をスキップして `true` を返せる
5. **走査が最後まで完了した場合**: 途中で `false` にも `true` にもならずにループが終了した場合、全インデックスが到達可能だったことを意味するので `true` を返す

## 前提知識

### Math.max とは

2つの整数を受け取り、大きい方の値を返す静的メソッド。最遠地点の更新で「現在の最遠地点」と「新しく計算した到達地点」を比較するために使用する。

```java
Math.max(3, 5);    // 5を返す — 2つの引数のうち大きい方
Math.max(7, 2);    // 7を返す
Math.max(4, 4);    // 4を返す — 等しい場合はその値を返す
```

### maxReach（最遠到達インデックス）とは

配列の先頭から現在位置までの全要素を考慮したとき、到達可能な最も遠いインデックスを表す変数。インデックス `i` にいるとき、`i + nums[i]` がその位置から到達できる最遠地点であり、`maxReach = Math.max(maxReach, i + nums[i])` で常に最大値を保持する。
例: `nums = [2, 3, 1, 1, 4]` のとき、`i=0` で `maxReach = 0 + 2 = 2`、`i=1` で `maxReach = max(2, 1 + 3) = 4` となり、末尾インデックス `4` に到達可能と判定できる。

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 追加の変数は `maxReach` の1つだけである |

## コード

```java
// 入力: 整数配列 nums（各要素はそのインデックスからの最大ジャンプ長）
// 出力: 最後のインデックスに到達できるなら true、できないなら false を返す
boolean canJump(int[] nums) {
    // これまでに到達可能な最遠インデックスを追跡する変数
    // 開始地点はインデックス 0 なので、初期値は 0
    int maxReach = 0;

    // 配列を先頭から末尾まで1つずつ走査する
    for (int i = 0; i < nums.length; i++) {
        // 現在のインデックスが最遠到達地点を超えていたら、ここには到達できない
        if (i > maxReach) return false;

        // i + nums[i] は現在位置から到達できる最遠インデックス
        // これまでの maxReach と比較して大きい方を保持する
        maxReach = Math.max(maxReach,
            i + nums[i]);

        // 最遠到達地点が配列の最後のインデックス以上なら、末尾に到達可能と確定
        if (maxReach >= nums.length - 1)
            return true;
    }
    // ループが最後まで完了した場合、全インデックスが到達可能だったので true
    return true;
}
```
