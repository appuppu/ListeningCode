# Merging Triplets to Form a Target Triplet — トリプレットの要素ごとの最大値でターゲットを構成できるか判定する

## 問題の本質

三つの整数からなるトリプレットの二次元配列 `triplets` とターゲットトリプレット `target` が与えられる。`triplets` から任意の部分集合を選び、要素ごとの最大値（element-wise maximum）を取った結果が `target` と完全に一致するかどうかを判定し、**boolean**で返す。

## 核心のアイデア

ターゲットのいずれかの要素を超える値を持つトリプレットは、マージに使うとその位置がターゲットを超えてしまうため絶対に使えない。逆に、全要素がターゲット以下のトリプレットだけをマージすれば、ターゲットを超える心配なく最大値を蓄積でき、最終的にターゲットと一致するかを確認するだけでよい。

## 思考プロセス

1. **使えないトリプレットを特定する**: トリプレット `t` のいずれかの要素が `target` の対応する要素を超えている場合、`t` をマージに含めると最大値がターゲットを超えてしまう。最大値は一度上がると下げられないので、そのようなトリプレットは絶対に選べない
2. **使えるトリプレットは全て使ってよい**: 全要素が `target` 以下のトリプレットは、マージしてもターゲットを超えることがない。使っても害がないので、貪欲に全て採用してよい
3. **マージ結果をどう蓄積するか**: 結果を格納する配列 `result` を `[0, 0, 0]` で初期化し、使えるトリプレットの各要素と `result` の各要素の最大値を取って更新していく。`Math.max` で要素ごとに更新すれば、選んだ全トリプレットのelement-wise maximumが得られる
4. **最終判定**: 全てのトリプレットを処理した後、`result` が `target` と完全に一致すれば `true`、一致しなければ `false` を返す。`Arrays.equals` で配列の全要素を比較できる

## 前提知識

### element-wise maximum（要素ごとの最大値）とは

2つ以上の配列の同じ位置の要素を比較し、それぞれの位置で最大の値を取る操作。例えば `[2, 5, 3]` と `[5, 1, 6]` のelement-wise maximumは `[5, 5, 6]` になる。

```java
int[] a = {2, 5, 3};
int[] b = {5, 1, 6};
int[] merged = new int[3];
merged[0] = Math.max(a[0], b[0]);  // max(2, 5) → 5
merged[1] = Math.max(a[1], b[1]);  // max(5, 1) → 5
merged[2] = Math.max(a[2], b[2]);  // max(3, 6) → 6
// merged = [5, 5, 6]
```

### Math.max とは

2つの値のうち大きい方を返すメソッド。マージ結果の蓄積に使用する。

```java
Math.max(3, 7);   // → 7
Math.max(5, 5);   // → 5
Math.max(0, 4);   // → 4（初期値0と比較して更新する用途）
```

### Arrays.equals とは

2つの配列の長さと全要素が一致するかを判定し、booleanで返すメソッド。`==` 演算子は参照の比較になるため、配列の中身を比較するにはこのメソッドを使う。

```java
int[] a = {2, 5, 3};
int[] b = {2, 5, 3};
a == b;              // → false（参照が異なるため）
Arrays.equals(a, b); // → true（全要素が一致するため）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — トリプレット配列を1回走査するだけで済む（各トリプレットの処理はO(1)） |
| Space | O(1) — 長さ3の固定サイズ配列 `result` のみを使用する |

## コード

```java
// 入力: 二次元整数配列 triplets（各要素は長さ3のトリプレット）と、長さ3の整数配列 target
// 出力: トリプレットの部分集合のelement-wise maximumで target を構成できるなら true、できないなら false
public boolean mergeTriplets(int[][] triplets, int[] target) {
    // 使えるトリプレットのelement-wise maximumを蓄積する配列を [0, 0, 0] で初期化する
    int[] result = new int[3];

    // triplets の各トリプレット t を先頭から末尾まで1つずつ走査する
    for (int[] t : triplets) {
        // いずれかの要素がターゲットを超えるトリプレットは、マージに含めると最大値がターゲットを超えてしまい修正できないためスキップする
        if (t[0] > target[0] ||
            t[1] > target[1] ||
            t[2] > target[2])
            continue;

        // 全要素がターゲット以下なので、この更新によって result がターゲットを超えることはない
        // 各要素の最大値で結果を更新する
        result[0] = Math.max(result[0], t[0]);
        result[1] = Math.max(result[1], t[1]);
        result[2] = Math.max(result[2], t[2]);
    }

    // 蓄積した結果がターゲットと完全に一致するかを判定して返す
    return Arrays.equals(result, target);
}
```
