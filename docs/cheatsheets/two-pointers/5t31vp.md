# Three Sum — 3つの数の合計がゼロになるトリプレットを全て見つける

## 問題の本質

整数の配列 `nums` が与えられる。`nums` の中から合計が `0` になる3つの要素の組み合わせ（トリプレット）を全て見つけ、`List<List<Integer>>` で返す。各トリプレットは異なるインデックスの要素で構成され、結果に重複するトリプレットを含めてはならない。

## 核心のアイデア

配列をソートすれば、1つの要素を固定した上で残りの2要素を Two Pointers で効率的に探索でき、さらにソート済みの並びを利用して重複する値をスキップすることで、重複トリプレットの除去も自然に実現できる。

## 思考プロセス

1. **3要素の問題を2要素の問題に帰着させる**: 3つの数 `a + b + c = 0` は、1つの要素 `a = nums[i]` を固定すれば `b + c = -a` という2要素の探索問題になる。外側のforループで `a` を固定し、内側で `b` と `c` を探す構造にすれば、既知の Two Sum の考え方を応用できる
2. **Two Pointers を使うためにソートする**: 2要素の探索を効率的に行うには、配列をソートして左右からポインタを狭めていく Two Pointers が有効である。合計が小さすぎれば左ポインタを右に、大きすぎれば右ポインタを左に動かすことで、全ペアを効率的に探索できる
3. **重複トリプレットの除去をソートで実現する**: ソート済みの配列では、同じ値が隣接する。外側ループの `nums[i]` が前の要素と同じ値であればスキップし、内側ループでもペアが見つかった後に `left` と `right` を同じ値が続く限りスキップすることで、重複トリプレットを結果に含めずに済む
4. **外側ループの範囲を決める**: 3つの要素が必要なので、`i` は `0` から `nums.length - 3` まで走査する。`left` は `i + 1`、`right` は `nums.length - 1` から開始し、`left < right` の間だけ探索を続ける
5. **合計値に応じてポインタを動かす**: `sum == 0` ならトリプレットを結果に追加し、重複スキップ後に両ポインタを内側に進める。`sum < 0` なら合計を大きくするために `left` を右に、`sum > 0` なら合計を小さくするために `right` を左に動かす
6. **最終的に返すもの**: 全ての固定要素とポインタの組み合わせを探索し終えたら、蓄積した `result` リストをそのまま返す

## 前提知識

### Two Pointers とは

ソート済み配列の両端に2つのポインタ（`left` と `right`）を置き、条件に応じてどちらかを動かすことで、全ペアの探索をO(n)で行う手法。合計が目標より小さければ `left` を右へ（値を大きく）、大きければ `right` を左へ（値を小さく）動かす。

```java
int left = 0;
int right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) {
        // ペア発見
    } else if (sum < target) {
        left++;    // 合計を大きくしたいので左ポインタを右に動かす
    } else {
        right--;   // 合計を小さくしたいので右ポインタを左に動かす
    }
}
```

### Arrays.sort() とは

配列を昇順にソートするJavaの標準メソッド。ソート後は同じ値が隣接するため、重複の検出が容易になる。

```java
int[] nums = {4, -1, 2, -1, 0};
Arrays.sort(nums);    // nums は {-4, -1, -1, 0, 2} になる（昇順）
```

### Arrays.asList() とは

可変長引数から固定サイズの `List` を生成するメソッド。トリプレットを `List<Integer>` として結果リストに追加する際に使用する。

```java
List<Integer> triplet = Arrays.asList(-1, 0, 1);  // [-1, 0, 1] のリストを生成
```

## 計算量

| | 値 |
|---|---|
| Time | O(n²) — 外側ループがO(n)、内側の Two Pointers がO(n)で、合計O(n²) |
| Space | O(1) — ソートを除けば、ポインタ変数のみで追加の空間を使用しない |

## コード

```java
// 入力: 整数配列 nums
// 出力: 合計が 0 になる全てのユニークなトリプレットを格納した List<List<Integer>>
public List<List<Integer>> threeSum(int[] nums) {
    // 発見した全てのトリプレットを蓄積する結果リスト
    List<List<Integer>> result = new ArrayList<>();
    // 配列を昇順にソートする（Two Pointersの前提条件 + 重複スキップのため）
    Arrays.sort(nums);

    // i は 0 から nums.length - 3 まで走査する。nums[i] がトリプレットの固定要素となる
    for (int i = 0; i < nums.length - 2; i++) {
        // 固定要素が前の要素と同じ値なら、同じトリプレットが再度生成されるためスキップする
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }
        // 固定要素の直後と配列末尾に左右のポインタを配置し、この範囲からペアを探索する
        int left = i + 1;
        int right = nums.length - 1;

        while (left < right) {
            // 3つの要素の合計を計算する
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0) {
                // 合計がゼロのトリプレットを結果に追加する
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // 左ポインタ側の重複する値をスキップする（同じ値が続く限り右に進める）
                while (left < right && nums[left] == nums[left + 1]) {
                    left++;
                }
                // 右ポインタ側の重複する値をスキップする（同じ値が続く限り左に進める）
                while (left < right && nums[right] == nums[right - 1]) {
                    right--;
                }
                // 重複スキップ後、両ポインタを内側に1つ進めて次のペアの探索に進む
                left++;
                right--;
            } else if (sum < 0) {
                // 合計が負なので、左ポインタを右に動かして合計を大きくする
                left++;
            } else {
                // 合計が正なので、右ポインタを左に動かして合計を小さくする
                right--;
            }
        }
    }

    // 全ての固定要素について探索が終了。重複のない全トリプレットが格納されている
    return result;
}
```
