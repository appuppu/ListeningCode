# Finding Two Numbers in a Sorted Array That Add Up to a Target — ソート済み配列から合計がターゲットになる2つの数を見つける

## 問題の本質

ソート済みの整数配列 `nums` と整数 `target` が与えられる。`nums` の中から合計が `target` になる2つの要素を見つけ、その**1-indexed の位置**を配列で返す。解は必ず1つだけ存在し、同じ要素を2回使うことはできない。

## 核心のアイデア

配列がソート済みであるため、左端と右端の2つのポインタから挟み撃ちにできる。2つの合計が大きすぎれば右を縮め、小さすぎれば左を広げることで、1回の走査でO(n)時間・O(1)空間で答えが見つかる。

## 思考プロセス

1. **ソート済みという条件を活かす**: 配列がソート済みなので、左端は最小値、右端は最大値を指す。この両端の合計から探索を始めれば、合計値の大小に応じて探索範囲を確実に狭められる
2. **合計が大きすぎるなら右ポインタを左へ移動する**: 右ポインタは現在の探索範囲で最大の値を指している。合計が `target` より大きい場合、合計を小さくするには右ポインタを左に1つ動かして、より小さい値に切り替える
3. **合計が小さすぎるなら左ポインタを右へ移動する**: 左ポインタは現在の探索範囲で最小の値を指している。合計が `target` より小さい場合、合計を大きくするには左ポインタを右に1つ動かして、より大きい値に切り替える
4. **合計がちょうど `target` なら答えが見つかる**: 2つのポインタが指す値の合計が `target` と一致したとき、それが求めるペアである。問題は1-indexedを要求するので、各ポインタの位置に1を加えて返す
5. **ループの終了条件**: 左ポインタが右ポインタに到達するまで繰り返す。問題の制約上、解は必ず存在するので、ポインタが交差する前に必ず答えが見つかる
6. **最終的に返すもの**: 合計が `target` と一致した時点で、`left + 1`（左の要素の1-indexed位置）と `right + 1`（右の要素の1-indexed位置）の2つを `int[]` で返す

## 前提知識

### Two Pointers（2つのポインタ）とは

配列の異なる位置を指す2つのインデックス変数を使い、条件に応じてそれぞれを移動させる手法。ソート済み配列では、両端から中央に向かって探索範囲を狭めるパターンが典型的である。

```java
int left = 0;                    // 左ポインタを配列の先頭に置く
int right = nums.length - 1;     // 右ポインタを配列の末尾に置く
while (left < right) {           // 2つのポインタが交差するまでループする
    // left と right を条件に応じて移動させる
    left++;   // 左ポインタを右に1つ進める
    right--;  // 右ポインタを左に1つ戻す
}
```

### ソート済み配列の性質

配列が昇順にソートされている場合、`nums[left] <= nums[right]` が常に成り立つ。左ポインタを右に動かすと合計は増加し、右ポインタを左に動かすと合計は減少する。この単調性があるからこそ、2つのポインタの移動方向を合計の大小で決定できる。

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 2つのポインタが合計で最大n回移動するだけで済む |
| Space | O(1) — ポインタ用の変数のみを使用し、追加のデータ構造は不要 |

## コード

```java
// 入力: ソート済みの整数配列 nums と整数 target
// 出力: 合計が target になる2要素の1-indexed位置を格納した int[] を返す
public int[] twoSum(int[] nums, int target) {
    // 左ポインタを配列の先頭に置く。探索範囲の左端であり、配列の最小値側を担当する
    int left = 0;
    // 右ポインタを配列の末尾に置く。探索範囲の右端であり、配列の最大値側を担当する
    int right = nums.length - 1;

    // 2つのポインタが交差するまでループする
    while (left < right) {
        // 現在の2要素の合計を計算し、変数に入れて各分岐で再利用する
        int cursum = nums[left] + nums[right];

        if (cursum == target) {
            // 合計がターゲットと一致したのでペア発見。問題が1-indexedを要求するため各インデックスに1を加えて返す
            return new int[]{left + 1, right + 1};
        } else if (cursum > target) {
            // 合計が大きすぎるので右ポインタを左に移動する。右ポインタが指す値がより小さくなり、次のイテレーションで合計が減少する
            right--;
        } else {
            // 合計が小さすぎるので左ポインタを右に移動する。左ポインタが指す値がより大きくなり、次のイテレーションで合計が増加する
            left++;
        }
    }
    // 問題の制約上、解は必ず存在するのでここには到達しない
    return new int[]{};
}
```
