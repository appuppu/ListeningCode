# Maximizing Water Held Between Two Lines — 2本の垂直線で挟む容器の最大水量を求める

## 問題の本質

非負整数の配列 `height` が与えられる。各要素 `height[i]` はx軸上の位置 `i` に立つ垂直線の高さを表す。この中から2本の線を選び、x軸と合わせて形成される容器に溜められる**水の最大量**を返す。容器の水量は「2本の線の間の距離 × 2本のうち短い方の高さ」で決まる。

## 核心のアイデア

容器の幅を最大（両端）から始め、短い方のポインタを内側に動かすことで、高さの増加による面積改善の可能性を残しつつ、全ペアを効率的に探索できる。短い方を動かす理由は、幅が縮む以上、高さが増えなければ面積は改善しないからである。

## 思考プロセス

1. **面積の計算式を整理する**: 2本の線 `i` と `j`（i < j）が作る容器の面積は `(j - i) × min(height[i], height[j])` である。面積を最大化するには「幅」と「高さの最小値」の積を最大にする必要がある
2. **幅が最大の状態から始める**: 幅を最大にするには、左端（インデックス0）と右端（インデックス n-1）の2本を選べばよい。この状態から探索を開始すれば、幅は最大の状態から出発できる
3. **どちらのポインタを動かすかを決める**: 幅は内側に動かすと必ず1減る。面積を改善するには高さを増やすしかない。容器の高さは2本のうち短い方で決まるので、短い方のポインタを内側に動かすことで、より高い線に出会う可能性がある。逆に、長い方を動かしても、短い方がボトルネックのままなので面積は改善しない
4. **各ステップで面積を記録する**: ポインタを動かすたびに新しい面積を計算し、これまでの最大値と比較して更新する。こうすれば全探索と同じ結果を得られる
5. **終了条件を決める**: 左ポインタと右ポインタが出会った時点で、全ての有望なペアを調べ終えているので、探索を終了する
6. **最終的に返すもの**: 探索中に記録した面積の最大値 `maxarea` を返す

## 前提知識

### Two Pointers（2ポインタ）とは

配列の両端または異なる位置に2つのポインタ（インデックス）を置き、条件に応じて一方または両方を動かしながら探索する手法。全ペアを調べるO(n²)の探索を、条件を利用してO(n)に削減できる場合に有効である。

```java
int left = 0;                      // 左ポインタを配列の先頭に置く
int right = height.length - 1;     // 右ポインタを配列の末尾に置く
while (left < right) {             // 2つのポインタが出会うまでループする
    // left または right を動かす
    left++;   // 左ポインタを右に1つ進める
    right--;  // 右ポインタを左に1つ進める
}
```

### Math.min / Math.max とは

`Math.min(a, b)` は2つの値のうち小さい方を、`Math.max(a, b)` は大きい方を返す。容器の高さ（短い方の線）と面積の最大値の更新に使用する。

```java
Math.min(3, 7);          // 2つのうち小さい方を返す → 3
Math.max(10, 25);        // 2つのうち大きい方を返す → 25
```

### 容器の面積の計算

2本の線 `left` と `right` が作る容器の面積は、幅 × 高さで求まる。高さは2本の線のうち短い方で決まる。

```java
int width = right - left;                              // 幅 = 2本の線の間の距離
int minHeight = Math.min(height[left], height[right]);  // 高さ = 短い方の線の高さ
int area = width * minHeight;                           // 面積 = 幅 × 高さ
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 左右のポインタが1回ずつ内側に進むだけで、配列を1回走査する |
| Space | O(1) — ポインタと最大値を保持する変数のみを使用する |

## コード

```java
// 入力: 非負整数の配列 height（各要素は垂直線の高さ）
// 出力: 2本の線とx軸で形成される容器が溜められる水の最大量を int で返す
public int maxArea(int[] height) {
    // 探索中に見つけた面積の最大値を記録する変数。0で初期化する
    int maxarea = 0;
    // 左ポインタを配列の先頭に置く。幅が最大の状態から探索を開始する
    int left = 0;
    // 右ポインタを配列の末尾に置く
    int right = height.length - 1;

    // 2つのポインタが出会うまでループする。出会った時点で全ての有望なペアを調べ終えている
    while (left < right) {
        // 幅 = 2本の線の間の距離
        int width = right - left;
        // 高さ = 短い方の線の高さ。容器の水量は短い方の線で決まる
        int minHeight = Math.min(height[left], height[right]);
        // 面積 = 幅 × 高さ
        int area = width * minHeight;

        // これまでの最大値と比較して更新する
        maxarea = Math.max(area, maxarea);

        // 短い方のポインタを内側に動かす。幅が縮む以上、高さが増えなければ面積は改善しない
        // 長い方を動かしても短い方がボトルネックのままなので面積は改善しない
        if (height[left] <= height[right]) {
            // 左の線が短い（または同じ）ので、左ポインタを右に1つ進めて高さの改善を狙う
            left++;
        } else {
            // 右の線が短いので、右ポインタを左に1つ進めて高さの改善を狙う
            right--;
        }
    }
    // 探索中に記録した面積の最大値を返す
    return maxarea;
}
```
