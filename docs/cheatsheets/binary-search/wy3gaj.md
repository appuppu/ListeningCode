# Searching for a Target in a Sorted Array — ソート済み配列からターゲットの位置を見つける

## 問題の本質

ソート済みの整数配列 `nums` と整数 `target` が与えられる。配列の中から `target` と一致する要素を見つけ、その**インデックス**を返す。`target` が配列に存在しない場合は `-1` を返す。

## 核心のアイデア

配列がソート済みであるため、中央の要素とターゲットを比較するだけで、探索範囲を毎回半分に絞り込める。これにより、全要素を確認するO(n)ではなく、O(log n)で探索が完了する。

## 思考プロセス

1. **ソート済みという条件を活かす**: 配列がソートされているので、任意の位置の要素を見れば、ターゲットがその左側にあるか右側にあるかを判定できる。この性質を使えば、探索範囲を毎回半分に絞り込める
2. **探索範囲を2つのポインタで管理する**: 配列の左端を `left`、右端を `right` とする2つのポインタで探索範囲を表現する。初期状態では配列全体が探索範囲である
3. **中央の要素とターゲットを比較する**: 探索範囲の中央インデックス `mid` を計算し、`nums[mid]` と `target` を比較する。一致すれば `mid` が答えである
4. **比較結果に応じて探索範囲を半分に絞る**: `nums[mid] < target` なら、ターゲットは中央より右側にあるので `left = mid + 1` で左端を縮める。`nums[mid] > target` なら、ターゲットは中央より左側にあるので `right = mid - 1` で右端を縮める
5. **探索範囲がなくなるまで繰り返す**: `left <= right` である限り探索を続ける。`left > right` になったら探索範囲が空になったことを意味し、ターゲットは配列に存在しないので `-1` を返す
6. **中央インデックスの計算でオーバーフローを防ぐ**: `mid = (left + right) / 2` だと `left + right` が整数の最大値を超える可能性がある。`mid = left + (right - left) / 2` と書くことでオーバーフローを回避する

## 前提知識

### Binary Search（二分探索）とは

ソート済みの配列に対して、探索範囲を毎回半分に絞り込むことで、目的の要素を効率的に見つけるアルゴリズム。探索範囲の中央要素とターゲットを比較し、一致しなければ左半分か右半分のどちらかを捨てる。これを繰り返すことで、探索回数がO(log n)になる。

```java
// 配列の長さが8の場合の探索回数
// 1回目: 8 → 4（半分に絞る）
// 2回目: 4 → 2（半分に絞る）
// 3回目: 2 → 1（半分に絞る）
// 最大3回 = log₂(8) = 3
```

### 中央インデックスの計算

2つのポインタ `left` と `right` の中間位置を求める。`(left + right) / 2` ではなく `left + (right - left) / 2` を使うことで、`left + right` の加算による整数オーバーフローを防ぐ。

```java
int left = 0;
int right = 10;
int mid = left + (right - left) / 2;  // mid = 0 + (10 - 0) / 2 = 5
```

### while ループの条件 `left <= right`

`left <= right` は探索範囲に要素が1つ以上残っていることを意味する。`left == right` のとき探索範囲に要素が1つだけ残っており、この要素も確認する必要があるため、`<` ではなく `<=` を使う。

```java
// left=3, right=3 のとき、nums[3] がまだ未確認
// left <= right は true なので、nums[3] を確認できる
// left < right だと false になり、nums[3] を確認せずに終了してしまう
```

## 計算量

| | 値 |
|---|---|
| Time | O(log n) — 探索範囲を毎回半分に絞るため、最大log₂(n)回の比較で済む |
| Space | O(1) — ポインタ用の変数のみ使用し、追加のデータ構造は不要 |

## コード

```java
// 入力: ソート済み整数配列 nums と整数 target
// 出力: target と一致する要素のインデックスを int で返す。存在しない場合は -1 を返す
public int binarySearch(int[] nums, int target) {
    // 探索範囲の左端と右端を初期化する。この2つの変数で探索範囲を管理する
    int left = 0;
    int right = nums.length - 1;

    // left <= right: 探索範囲に要素が1つ以上残っている間、繰り返す
    // left > right になったら探索範囲が空なのでループを抜ける
    while (left <= right) {
        // 注意: (left + right) / 2 だと left + right の加算で整数オーバーフローする可能性がある
        // left + (right - left) / 2 と書くことでオーバーフローを防ぐ
        int mid = left
            + (right - left) / 2;

        // 中央の要素がターゲットと一致すればインデックスを返す
        if (nums[mid] == target) {
            return mid;
        }

        // ターゲットが中央より大きければ、探索範囲を右半分に絞る
        // mid 自体は既に確認済みなので mid + 1 とする
        if (nums[mid] < target) {
            left = mid + 1;
        }
        // ターゲットが中央より小さければ、探索範囲を左半分に絞る
        // mid 自体は既に確認済みなので mid - 1 とする
        else {
            right = mid - 1;
        }
    }

    // 探索範囲が空になったので、ターゲットは配列に存在しない
    return -1;
}
```
