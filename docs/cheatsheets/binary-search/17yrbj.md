# Searching for a Target in a Rotated Sorted Array — 回転されたソート済み配列からターゲットを探す

## 問題の本質

昇順にソートされた整数配列が未知のピボットで回転されている。この配列の中から与えられた `target` の値を探し、そのインデックスを返す。`target` が存在しなければ `-1` を返す。全ての要素は一意である。

## 核心のアイデア

回転されたソート済み配列を中央で分割すると、左半分と右半分のうち必ず片方はソート済みである。ソート済みの半分に `target` が含まれるかを範囲チェックで判定し、含まれなければもう片方を探索することで、毎回探索範囲を半分に絞れる。

## 思考プロセス

1. **ソート済み配列なのでBinary Searchを使いたい**: 通常のソート済み配列ならBinary Searchで O(log n) で探索できる。回転があっても、この効率を維持する方法を考える
2. **回転された配列を中央で分割すると、片方は必ずソート済みになる**: 配列 `[4,5,6,7,0,1,2]` を `mid=3`（値7）で分割すると、左半分 `[4,5,6,7]` はソート済み、右半分 `[0,1,2]` もソート済みである。回転のピボットは片方にしか含まれないため、もう片方は必ず昇順が保たれている
3. **どちらがソート済みかを判定する方法**: `nums[left] <= nums[mid]` が成り立てば左半分がソート済みである。成り立たなければ右半分がソート済みである。等号を含めるのは、`left == mid` となるケース（要素が2つ以下のとき）を正しく処理するためである
4. **ソート済みの半分にtargetが含まれるかを判定する**: ソート済みの半分は最小値と最大値がわかるので、`target` がその範囲内にあるかを不等式で判定できる。例えば左半分がソート済みなら、`target >= nums[left] && target < nums[mid]` で判定する
5. **含まれる方を探索する**: `target` がソート済みの半分の範囲内にあれば、その半分に絞る。範囲外であれば、もう片方の半分に `target` が存在するはずなので、そちらを探索する
6. **ループ終了時の処理**: `left > right` になるまで探索しても `target` が見つからなければ、配列に `target` は存在しないので `-1` を返す

## 前提知識

### Binary Search（二分探索）とは

ソート済み配列において、探索範囲の中央要素を調べて探索範囲を半分に絞る操作を繰り返す探索手法。毎回範囲が半分になるため、O(log n) の時間計算量で探索できる。

```java
int left = 0;
int right = nums.length - 1;
while (left <= right) {                    // 探索範囲が有効な間ループする
    int mid = left + (right - left) / 2;   // オーバーフローを防ぐ中央計算
    // nums[mid] と target を比較して left か right を更新する
}
```

### 回転されたソート済み配列とは

昇順ソート済み配列をある位置で切って、後半部分を前に移動させた配列。例えば `[0,1,2,4,5,6,7]` をインデックス4で回転すると `[4,5,6,7,0,1,2]` になる。配列全体はソートされていないが、ピボットの左右それぞれはソート済みである。

```
元の配列:   [0, 1, 2, 4, 5, 6, 7]
回転後:     [4, 5, 6, 7, 0, 1, 2]
             ソート済み↑  ↑ソート済み
```

## 計算量

| | 値 |
|---|---|
| Time | O(log n) — 毎回探索範囲を半分に絞るため、最大 log n 回の比較で済む |
| Space | O(1) — left, right, mid の3変数のみを使用し、追加のデータ構造は不要 |

## コード

```java
// 入力: 回転されたソート済み整数配列 nums と整数 target
// 出力: target のインデックスを int で返す。存在しなければ -1 を返す
public int search(int[] nums, int target) {
    // 探索範囲の両端を初期化する。この2つの変数が探索範囲の両端を表す
    int left = 0;
    int right = nums.length - 1;

    // left > right になったら探索範囲が空になったことを意味する
    while (left <= right) {
        // (left + right) / 2 ではなくこの式を使うのは、left + right の整数オーバーフローを防ぐため
        int mid = left + (right - left) / 2;

        // 中央の要素がtargetと一致すればインデックスを返す
        if (nums[mid] == target) {
            return mid;
        }

        // 左半分がソート済みかを判定する
        // 等号を含めるのは、left == mid（探索範囲が2要素以下）のときに左半分を正しくソート済みと判定するため
        if (nums[left] <= nums[mid]) {
            // targetが左半分の範囲内にあるかを判定する
            if (target >= nums[left] && target < nums[mid]) {
                right = mid - 1;  // targetは左半分の範囲内にあるので左半分に絞る
            } else {
                left = mid + 1;   // targetは左半分の範囲外なので右半分に絞る
            }
        // 右半分がソート済みの場合
        } else {
            // targetが右半分の範囲内にあるかを判定する
            if (target > nums[mid] && target <= nums[right]) {
                left = mid + 1;   // targetは右半分の範囲内にあるので右半分に絞る
            } else {
                right = mid - 1;  // targetは右半分の範囲外なので左半分に絞る
            }
        }
    }

    // 探索範囲が空になったのでtargetは配列に存在しない
    return -1;
}
```
