# Searching for a Value in a Sorted Matrix — ソート済み行列から目標値を探す

## 問題の本質

m×n の行列が与えられる。各行は昇順にソートされており、各行の先頭要素はその前の行の末尾要素より大きい。与えられた `target` がこの行列内に存在するかを判定して `boolean` で返す。

## 核心のアイデア

行列全体が左上から右下に向かって一列に並べると1つのソート済み配列とみなせる。1次元のインデックス `mid` から行列の座標 `[mid / n][mid % n]` への変換を使えば、行列を平坦化せずに1回の二分探索で O(log(m * n)) で探索できる。

## 思考プロセス

1. **行列全体が1つのソート済み配列である**: 各行が昇順かつ次の行の先頭が前の行の末尾より大きいので、行列の要素を左上から右下へ順に読むと、全体が1つの昇順ソート済み配列になっている
2. **ソート済み配列には二分探索が使える**: 全要素数は `m * n` 個なので、0 から `m * n - 1` の範囲で二分探索を行えばよい。探索範囲の下限 `lo = 0`、上限 `hi = m * n - 1` と設定する
3. **1次元インデックスから2次元座標への変換が必要**: 二分探索の中間点 `mid` は1次元のインデックスである。行列から値を取得するには2次元座標が必要なので、行インデックスを `mid / n`（列数で割った商）、列インデックスを `mid % n`（列数で割った余り）として変換する
4. **標準的な二分探索のロジックを適用する**: `matrix[mid / n][mid % n]` で取得した値が `target` と等しければ `true` を返す。小さければ `lo = mid + 1` で探索範囲を右半分に絞り、大きければ `hi = mid - 1` で左半分に絞る
5. **探索範囲がなくなれば target は存在しない**: `lo > hi` になるまでにマッチしなければ、行列内に `target` は存在しないので `false` を返す

## 前提知識

### 二分探索（Binary Search）とは

ソート済みの配列に対して、探索範囲を毎回半分に絞り込むことで目的の値を高速に見つけるアルゴリズム。要素数 n に対して最大 log₂(n) 回の比較で結果が得られる。

```java
int lo = 0, hi = array.length - 1;  // 探索範囲の下限と上限を設定する
while (lo <= hi) {                    // 探索範囲が存在する間ループする
    int mid = lo + (hi - lo) / 2;    // オーバーフローを防ぎつつ中間点を計算する
    if (array[mid] == target)         // 中間点の値がtargetと一致するか判定する
        return true;
    else if (array[mid] < target)
        lo = mid + 1;                // targetは右半分にあるので下限を引き上げる
    else
        hi = mid - 1;                // targetは左半分にあるので上限を引き下げる
}
return false;                         // 見つからなかった場合
```

### 1次元インデックスと2次元座標の変換

列数 `n` の行列において、1次元インデックス `idx` から2次元座標への変換は除算と剰余で行う。この変換により、行列を仮想的な1次元配列として扱える。

```java
int n = matrix[0].length;        // 列数を取得する
int row = idx / n;               // 商が行インデックスになる（例: idx=7, n=4 → row=1）
int col = idx % n;               // 余りが列インデックスになる（例: idx=7, n=4 → col=3）
int val = matrix[row][col];      // 2次元座標で行列の値を取得する
```

## 計算量

| | 値 |
|---|---|
| Time | O(log(m * n)) — 全要素数 m * n に対して二分探索を1回行う |
| Space | O(1) — ポインタ変数のみを使用し、追加のデータ構造は不要 |

## コード

```java
// 入力: m×n の整数行列 matrix と整数 target
// 出力: target が行列内に存在すれば true、存在しなければ false を返す
public boolean searchMatrix(int[][] matrix, int target) {
    // 行列の行数と列数を取得する。全要素数の計算と1次元→2次元変換に使う
    int m = matrix.length;
    int n = matrix[0].length;

    // 二分探索の探索範囲を行列全体に設定する
    // lo=0 は行列の左上、hi=m*n-1 は行列の右下に対応する
    int lo = 0, hi = m * n - 1;

    // lo > hi になった時点で探索範囲がなくなり、targetは存在しないと判定できる
    while (lo <= hi) {
        // (lo + hi) / 2 ではなくこの形式を使い、lo + hi の整数オーバーフローを防ぐ
        int mid = lo + (hi - lo) / 2;

        // 1次元インデックスを2次元座標に変換して値を取得する
        // 行インデックス = mid / n（商）、列インデックス = mid % n（余り）
        int val = matrix[mid / n][mid % n];

        if (val == target)
            return true;           // 目標値が見つかったのでtrueを返す
        else if (val < target)
            lo = mid + 1;          // targetは右半分（大きい側）にあるので下限を引き上げる
        else
            hi = mid - 1;          // targetは左半分（小さい側）にあるので上限を引き下げる
    }

    // ループが終了してもtrueを返していないので、targetは行列内に存在しない
    return false;
}
```
