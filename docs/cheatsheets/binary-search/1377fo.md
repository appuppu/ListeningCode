# Finding the Minimum Eating Speed to Finish Bananas — 制限時間内に全バナナを食べ切る最小速度を求める

## 問題の本質

バナナの山の配列 `piles` と制限時間 `h`（時間）が与えられる。毎時 `k` 本のバナナを食べるとき、`h` 時間以内にすべてのバナナを食べ切れる**最小の整数速度 `k`** を返す。1時間に1つの山しか食べられず、山のバナナが `k` 本未満なら、その山を食べ終えても残りの時間は次の山に進めず待機する。

## 核心のアイデア

「速度 `k` で全部食べ切れるか？」は `k` に対して単調性がある。`k` が大きければ必ず食べ切れ、小さすぎれば食べ切れない。この単調性があるため、答えの候補範囲 `[1, max(piles)]` に対して二分探索を適用し、条件を満たす最小の `k` を効率的に見つけられる。

## 思考プロセス

1. **速度と結果の関係に単調性がある**: 速度 `k` を上げれば必要時間は減り、下げれば増える。ある速度で食べ切れるなら、それ以上の速度でも必ず食べ切れる。この「ある条件を満たす最小値を求める」構造は、二分探索の典型パターンである
2. **探索範囲を決める**: 速度の最小値は `1`（毎時1本は食べる）、最大値は `max(piles)`（最大の山を1時間で食べ切れる速度）である。`max(piles)` より大きい速度にしても1時間に1つの山しか食べられないため、結果は変わらない
3. **判定関数を設計する**: 速度 `mid` が与えられたとき、各山 `piles[i]` を食べるのに `ceil(piles[i] / mid)` 時間かかる。全山の合計時間が `h` 以下なら、その速度で食べ切れると判定できる
4. **天井除算を整数演算で行う**: `ceil(piles[i] / mid)` は `(piles[i] + mid - 1) / mid` で計算できる。これにより浮動小数点演算を避け、整数だけで正確に計算できる
5. **二分探索で範囲を絞る**: 中間値 `mid` で食べ切れるなら、答えは `mid` 以下にあるので `right = mid` とする。食べ切れないなら、答えは `mid + 1` 以上にあるので `left = mid + 1` とする。`left == right` になったとき、その値が求める最小速度である

## 前提知識

### 二分探索（Binary Search）の「条件を満たす最小値」パターン

ソート済みの値や連続する整数の範囲に対して、ある条件を満たす最小値（または最大値）を見つける手法。探索範囲を毎回半分に絞るため、O(log n) で答えが見つかる。

```java
int left = 1;               // 探索範囲の下限
int right = 1000;            // 探索範囲の上限
while (left < right) {       // left == right になったら答え確定
    int mid = left + (right - left) / 2;  // オーバーフローを防ぐ中間値計算
    if (condition(mid))       // midが条件を満たすか判定
        right = mid;          // 条件を満たす → 答えはmid以下にある
    else
        left = mid + 1;       // 条件を満たさない → 答えはmid+1以上にある
}
// left が条件を満たす最小値
```

### 天井除算（Ceiling Division）

`a / b` の結果を切り上げる整数演算。`Math.ceil` を使わずに `(a + b - 1) / b` で計算できる。

```java
int a = 10, b = 3;
int result = (a + b - 1) / b;  // (10 + 2) / 3 = 4  （10÷3=3.33... → 切り上げて4）
```

バナナの問題では、山のサイズ `piles[i]` を速度 `k` で割って切り上げることで、その山を食べ切るのに必要な時間数を求める。

### Math.max とは

2つの値のうち大きい方を返すメソッド。配列の最大値を求めるときにループと組み合わせて使う。

```java
Math.max(5, 3);   // → 5
Math.max(-1, 0);  // → 0
```

## 計算量

| | 値 |
|---|---|
| Time | O(n × log(max(piles))) — 二分探索でO(log(max(piles)))回の反復を行い、各反復で配列全体をO(n)で走査して合計時間を計算する |
| Space | O(1) — 追加のデータ構造を使用せず、変数のみで処理する |

## コード

```java
// 入力: 整数配列 piles（各山のバナナの本数）と整数 h（制限時間）
// 出力: h 時間以内に全バナナを食べ切れる最小の整数速度 k を int で返す
public int minEatingSpeed(int[] piles, int h) {
    // 二分探索の下限を1に設定する。速度は最低でも毎時1本である
    int left = 1;
    // 二分探索の上限を配列の最大値に設定する
    // 最大の山を1時間で食べ切れる速度より大きくしても意味がないため、この値が上限となる
    int right = 0;
    for (int p : piles) {
        right = Math.max(right, p);
    }

    // left == right になるまで探索範囲を半分に絞り続ける
    // left == right になったとき、その値が答えである
    while (left < right) {
        // オーバーフローを防ぐ中間値の計算
        // (left + right) / 2 ではなく left + (right - left) / 2 を使うことで整数オーバーフローを防ぐ
        int mid = left + (right - left) / 2;

        // 速度midで全バナナを食べるのに必要な合計時間を計算する
        int totalHours = 0;
        for (int p : piles) {
            // 天井除算: 各山を食べ切るのに必要な時間数を求める
            totalHours += (p + mid - 1) / mid;
        }

        if (totalHours <= h) {
            // 食べ切れる → もっと遅い速度でも食べ切れる可能性があるので上限を縮める
            // mid自体が答えの可能性があるため、mid - 1 ではなく mid を代入する
            right = mid;
        } else {
            // 食べ切れない → 速度が足りないので下限を引き上げる
            // midは答えになり得ないため、mid + 1 を代入する
            left = mid + 1;
        }
    }

    // ループ終了後、left（= right）が条件を満たす最小の速度である
    return left;
}
```
