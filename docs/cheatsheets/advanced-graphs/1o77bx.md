# Deriving the Order of an Alien Alphabet — エイリアン言語の文字順序を復元する

## 問題の本質

エイリアン言語の辞書順にソートされた単語リスト `words` が与えられる。この並び順から、その言語におけるアルファベットの順序を推定し、文字列として返す。順序に矛盾がある場合（サイクルが存在する、または短い単語が長い単語の後に来ているなど）は空文字列 `""` を返す。

## 核心のアイデア

隣接する2単語を比較すると「最初に異なる文字」から1つの順序関係（有向辺）が得られる。全ペアから得た順序関係を有向グラフとして構築し、DFSトポロジカルソートで全体の順序を決定する。サイクルがあれば順序は矛盾している。

## 思考プロセス

1. **隣接単語の比較で順序関係を抽出する**: ソート済みリストでは、隣接する2単語 `words[i]` と `words[i+1]` を先頭から比較し、最初に異なる文字のペア `(a, b)` が見つかれば「aはbより前」という順序関係が1つ確定する。この関係は有向グラフの辺 `a → b` として表現できる
2. **無効な入力を検出する**: `words[i]` が `words[i+1]` の先頭一致かつ `words[i]` の方が長い場合（例: `"abc"` が `"ab"` の前）、辞書順として矛盾しているので即座に空文字列を返す
3. **全文字をノードとして登録する**: 順序関係が得られない文字も存在するため、全単語の全文字をグラフのノードとして登録する。これにより、辺を持たない文字も結果に含まれる
4. **DFSトポロジカルソートで全体の順序を決定する**: 有向グラフに対してDFSを実行し、各ノードの探索完了時にリストに追加する。DFSの後行順（post-order）を逆転すると、トポロジカル順序（依存元が先に来る順序）が得られる
5. **3色マーキングでサイクルを検出する**: DFS中に各ノードを「未訪問(0)」「探索中(1)」「探索済(2)」の3状態で管理する。探索中のノードに再度到達した場合、サイクルが存在するので順序は決定不可能であり、空文字列を返す
6. **逆順にして文字列を構築する**: DFSの後行順リストを逆転させてトポロジカル順序を得る。リストの全文字を連結して結果の文字列を返す

## 前提知識

### トポロジカルソートとは

有向非巡回グラフ（DAG）の全ノードを、辺の方向に矛盾しない順序で一列に並べる操作。辺 `a → b` があれば、結果では必ず `a` が `b` より前に来る。サイクルがあるグラフにはトポロジカル順序は存在しない。

### DFSの3色マーキングとは

DFSにおける各ノードの状態を3色で管理する手法。白(0)は未訪問、灰(1)は現在の探索パス上（再帰スタックに存在）、黒(2)は探索完了を表す。灰色のノードに再到達するとサイクルが確定する。

```java
Map<Character, Integer> color = new HashMap<>();
color.put('a', 0);  // 白: 未訪問
color.put('a', 1);  // 灰: 探索中（再帰スタック上にある）
color.put('a', 2);  // 黒: 探索完了（全子孫を処理済み）
```

### HashMap と HashSet の基本操作

```java
// HashMap: キーと値のペアを保存。検索・取得がO(1)
Map<Character, Set<Character>> adj = new HashMap<>();
adj.putIfAbsent('a', new HashSet<>());  // キーが未登録の場合のみ空のSetを登録する
adj.get('a').add('b');                  // キー'a'の隣接リストに'b'を追加する

// HashSet: 重複なしの集合。追加・検索がO(1)
Set<Character> set = new HashSet<>();
set.add('b');        // 要素を追加する
set.contains('b');   // 要素の存在を判定する → true
```

### startsWith メソッド

文字列が指定のプレフィックスで始まるかを判定する。

```java
"abc".startsWith("ab");  // true — "abc"は"ab"で始まる
"ab".startsWith("abc");  // false — "ab"は"abc"で始まらない
```

## 計算量

| | 値 |
|---|---|
| Time | O(C) — Cは全単語の総文字数。グラフ構築に全文字を走査し、DFSはノード数＋辺数に比例するが、いずれもCを超えない |
| Space | O(1) — ノード数は最大26文字（英小文字）で定数。辺数も最大26²で定数。入力サイズに依存しない |

## コード

```java
// 入力: エイリアン言語の辞書順にソートされた文字列配列 words
// 出力: アルファベットの順序を表す文字列。矛盾がある場合は空文字列 "" を返す

// DFS: 3色マーキングでサイクル検出しつつ後行順を記録する
boolean dfs(char c, Map<Character, Set<Character>> adj,
            Map<Character, Integer> color, List<Character> result) {
    // 灰色（探索中）に再到達 → サイクル検出
    if (color.get(c) == 1) return false;
    // 黒色（探索済）→ すでに処理完了しているのでスキップする
    if (color.get(c) == 2) return true;

    // 現在のノードを灰色（探索中）にマークする
    color.put(c, 1);

    // 全隣接ノード（この文字より後に来る文字）に対して再帰的にDFSを実行する
    for (char n : adj.get(c))
        if (!dfs(n, adj, color, result))
            return false;  // 子孫でサイクル検出 → 即座に伝播する

    // 全子孫の探索が完了したので黒色にマークする
    color.put(c, 2);
    // 後行順でリストに追加する（DFSでは依存先が先に追加されるため、逆転後にトポロジカル順序になる）
    result.add(c);
    return true;
}

public String alienOrder(String[] words) {
    // 隣接リスト: キー=文字、バリュー=その文字より後に来る文字の集合
    Map<Character, Set<Character>> adj = new HashMap<>();

    // 全単語の全文字をグラフのノードとして登録する
    // 順序関係（辺）がない文字も結果に含める必要があるため、この時点で全文字を登録しておく
    for (String w : words)
        for (char c : w.toCharArray())
            adj.putIfAbsent(c, new HashSet<>());

    // 隣接する2単語を比較して順序関係（有向辺）を抽出する
    for (int i = 0; i < words.length - 1; i++) {
        String w1 = words[i];
        String w2 = words[i + 1];

        // 無効入力の検出: 長い単語が短いプレフィックスの前にある場合（例: ["abc","ab"]は矛盾）
        if (w1.length() > w2.length() && w1.startsWith(w2))
            return "";

        int len = Math.min(w1.length(), w2.length());
        for (int j = 0; j < len; j++) {
            if (w1.charAt(j) != w2.charAt(j)) {
                // 最初に異なる文字から順序関係を1つ得て、即座にループを抜ける
                // 2文字目以降の差異は前の文字が同じ場合にしか意味を持たないため、1つだけ抽出する
                adj.get(w1.charAt(j)).add(w2.charAt(j));
                break;
            }
        }
    }

    // 3色管理マップを作成し、全ノードを白(0: 未訪問)で初期化する
    Map<Character, Integer> color = new HashMap<>();
    for (char c : adj.keySet())
        color.put(c, 0);

    // DFSの後行順を記録するリスト
    List<Character> result = new ArrayList<>();

    // 全ノードに対してDFSを実行する（連結でないグラフにも対応するため全ノードを起点にする）
    for (char c : adj.keySet())
        if (!dfs(c, adj, color, result))
            return "";  // サイクル検出 → 順序は決定不可能

    // 後行順を逆転してトポロジカル順序を得る
    Collections.reverse(result);

    // 全文字を連結して結果の文字列を構築する
    StringBuilder sb = new StringBuilder();
    for (char c : result) sb.append(c);
    return sb.toString();
}
```
