# Finding the Cheapest Flight With Limited Stops — 最大k回の乗り継ぎで最安フライトを見つける

## 問題の本質

`n` 個の都市と、フライトのリスト `[from, to, price]`、出発地 `src`、目的地 `dst`、最大乗り継ぎ回数 `k` が与えられる。出発地から目的地まで、**最大k回の乗り継ぎ**（経由地がk個以下）で到達できる最安の合計運賃を返す。到達不可能な場合は `-1` を返す。

## 核心のアイデア

通常のDijkstraはコスト最小のパスだけを追跡するが、この問題では「コストが高くても乗り継ぎ回数が少ないパス」が最終的に最安ルートになる可能性がある。そのため、各都市に到達した「最少乗り継ぎ回数」を記録し、より少ない乗り継ぎで到達できるパスだけを探索対象に残すことで、コストと乗り継ぎ回数の両方を考慮した最適解を求める。

## 思考プロセス

1. **最安経路の探索にはDijkstraが基本**: 重み付きグラフの最短経路問題なので、優先度付きキューを使ったDijkstraが基本方針となる。コストが小さい順にノードを取り出すことで、目的地に最初に到達した時点でそれが最安となる
2. **乗り継ぎ回数の制約をどう扱うか**: 通常のDijkstraは「最小コストで到達済みの都市は再訪しない」が、この問題では乗り継ぎ回数の制約がある。コスト最小で到達したパスが乗り継ぎ回数をk回超えていれば無効であり、コストが少し高くても乗り継ぎが少ないパスが有効になりうる
3. **各都市への「最少乗り継ぎ回数」を記録する**: 配列 `stops[]` を用意し、各都市に到達した最少の乗り継ぎ回数を記録する。ある都市に以前より多い乗り継ぎ回数で到達した場合、そのパスはコストでも乗り継ぎ数でも改善がないため枝刈りできる
4. **優先度付きキューに何を保存するか**: 各状態を `[コスト, 都市, 乗り継ぎ回数]` の3つ組で管理する。コスト昇順で取り出すことで、目的地に最初に到達した時点の解が最安となる
5. **枝刈りの条件を整理する**: (a) 現在の乗り継ぎ回数がその都市の記録済み最少乗り継ぎ回数以上なら、探索を打ち切る。(b) 乗り継ぎ回数がkを超えていれば、その先の隣接都市への展開を行わない
6. **隣接都市への展開**: 枝刈りを通過した場合のみ、隣接する各都市に対して `[現在のコスト + 運賃, 隣接都市, 乗り継ぎ回数 + 1]` をキューに追加する

## 前提知識

### 隣接リスト（Adjacency List）とは

グラフの各頂点について、そこから直接行ける頂点とエッジの重みをリストで保持するデータ構造。`HashMap<Integer, List<int[]>>` で表現し、キーが出発都市、バリューが `[到着都市, 運賃]` のリストとなる。

```java
Map<Integer, List<int[]>> adj = new HashMap<>();
// 都市0から都市1へ運賃100のフライトを追加
adj.computeIfAbsent(0, x -> new ArrayList<>()).add(new int[]{1, 100});
// 都市0の隣接リストを取得
List<int[]> neighbors = adj.get(0);  // → [[1, 100]]
```

### PriorityQueue（優先度付きキュー）とは

要素を追加すると内部で自動的にソートされ、常に最小（または最大）の要素を先頭から取り出せるデータ構造。Dijkstraでは「コストが最小の状態」を効率的に取り出すために使用する。

```java
// int[]の第0要素（コスト）で昇順にソートする優先度付きキュー
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{100, 1, 0});   // [コスト=100, 都市=1, 乗り継ぎ=0] を追加
pq.offer(new int[]{50, 2, 1});    // [コスト=50, 都市=2, 乗り継ぎ=1] を追加
int[] min = pq.poll();            // コスト最小の [50, 2, 1] を取り出す
pq.isEmpty();                      // キューが空かを判定 → false
```

### stops配列による枝刈りとは

通常のDijkstraでは `visited` 配列で訪問済みの都市を管理するが、この問題では同じ都市に「異なる乗り継ぎ回数」で到達するパスを区別する必要がある。`stops[]` 配列に各都市への最少乗り継ぎ回数を記録し、それ以上の乗り継ぎ回数で到達したパスを打ち切ることで、不要な探索を排除する。

```java
int[] stops = new int[n];
Arrays.fill(stops, k + 2);  // k+2は「まだ未到達」を意味する十分大きな初期値
// 都市2に乗り継ぎ1回で到達した場合
stops[2] = 1;
// 後で都市2に乗り継ぎ2回で到達 → 2 >= stops[2] なので枝刈り（スキップ）
```

## 計算量

| | 値 |
|---|---|
| Time | O(E · log n) — 各フライト（辺）について優先度付きキューへの追加・取り出しにlog nかかる |
| Space | O(n + E) — 隣接リストにO(E)、stops配列にO(n)、キューに最大O(E)の状態を保持する |

## コード

```java
// 入力: 都市数 n、フライト配列 flights（各要素は [from, to, price]）、出発地 src、目的地 dst、最大乗り継ぎ回数 k
// 出力: 最大k回の乗り継ぎで出発地から目的地に到達する最安運賃を int で返す。到達不可能な場合は -1 を返す
public int findCheapestPrice(int n, int[][] flights, int src, int dst, int k) {
    // 隣接リストを構築する。キー=出発都市、バリュー=[到着都市, 運賃]のリスト
    // 各フライト f について、adj のキー f[0] に [f[1], f[2]] を追加する
    Map<Integer, List<int[]>> adj = new HashMap<>();
    for (int[] f : flights)
        adj.computeIfAbsent(f[0], x -> new ArrayList<>())
            .add(new int[]{f[1], f[2]});

    // コスト昇順の優先度付きキュー。各状態は [コスト, 都市, 乗り継ぎ回数]
    // コストが小さい状態を優先的に取り出すことで、目的地に最初に到達した時点が最安となる
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    // 初期状態: 出発地にコスト0、乗り継ぎ0回で到達している
    pq.offer(new int[]{0, src, 0});

    // 各都市への最少乗り継ぎ回数を記録する配列
    // k+2 は乗り継ぎ上限 k より十分大きい値で「まだ未到達」を意味する初期値
    int[] stops = new int[n];
    Arrays.fill(stops, k + 2);

    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int cost = curr[0];
        int city = curr[1];
        int stop = curr[2];

        // 目的地に到達したら、コスト昇順で取り出しているのでこれが最安
        if (city == dst) return cost;

        // この都市に以前より多い（または同じ）乗り継ぎで到達した場合は枝刈り
        // コスト昇順で取り出しているため、以前の到達はコストも小さい → 探索する意味がない
        if (stop >= stops[city]) continue;
        // この都市に到達した最少の乗り継ぎ回数を更新する
        stops[city] = stop;

        // 乗り継ぎ回数が上限kを超えていれば、この都市からさらに隣接都市へ展開できない
        if (stop > k) continue;

        // この都市から出発するフライトがなければスキップ
        if (!adj.containsKey(city)) continue;

        // 隣接する各都市について [累積コスト, 隣接都市, 乗り継ぎ回数+1] をキューに追加する
        for (int[] next : adj.get(city)) {
            pq.offer(new int[]{cost + next[1], next[0], stop + 1});
        }
    }

    // ループが終了しても目的地に到達できなかった場合は -1 を返す
    return -1;
}
```
