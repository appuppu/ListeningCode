# Calculating Network Signal Propagation Time — ネットワーク全体に信号が届くまでの最短時間を求める

## 問題の本質

`n` 個のノード（1〜n）と、重み付き有向辺のリスト `times`（各辺は `[送信元, 送信先, 所要時間]`）が与えられる。指定されたソースノード `k` から信号を送信したとき、全ノードに信号が届くまでの最短時間を返す。到達不可能なノードが1つでもあれば `-1` を返す。

## 核心のアイデア

「全ノードに届く最短時間」は「各ノードへの最短距離のうち最大のもの」に等しい。ダイクストラ法で全ノードへの最短距離を求め、その最大値を取ればよい。

## 思考プロセス

1. **問題を最短経路問題として捉える**: 信号はソースノードから各辺を伝って伝播する。各ノードに信号が届く時刻は、ソースからそのノードへの最短距離に等しい。したがって、単一始点最短経路問題を解けばよい
2. **全ノードへの最短距離を効率的に求めたい**: 辺の重みが非負なので、ダイクストラ法が適用できる。ダイクストラ法は優先度付きキュー（min-heap）を使い、距離が最小のノードから貪欲に確定していく
3. **グラフの表現方法を決める**: 隣接リストを使う。各ノードについて「隣接ノードとその辺の重み」のペアをリストで持つ。これにより、あるノードから伸びる辺を効率的に列挙できる
4. **距離配列を初期化する**: 全ノードの距離を無限大（`Integer.MAX_VALUE`）で初期化し、ソースノード `k` の距離を0にする。ソースから自身への距離は0だからである
5. **優先度付きキューで最短距離のノードを処理する**: キューから距離が最小のノードを取り出し、そのノードの隣接ノードについて距離を更新（緩和）する。更新があればキューに追加する
6. **重複処理をスキップする**: キューから取り出したノードの距離が、現在の最短距離より大きければ、既により良い経路で処理済みなのでスキップする。これにより不要な計算を避ける
7. **全ノードの最短距離から答えを求める**: 全ノードの距離配列を走査し、無限大のままのノードがあれば到達不可能なので `-1` を返す。そうでなければ距離の最大値が答えである

## 前提知識

### 隣接リスト（Adjacency List）とは

グラフを表現するデータ構造。各ノードごとに「そのノードから出る辺の一覧」をリストで保持する。ノード数 `n` に対して `List<List<int[]>>` で表現し、`graph.get(u)` でノード `u` からの辺を取得する。

```java
List<List<int[]>> graph = new ArrayList<>();
for (int i = 0; i <= n; i++) {
    graph.add(new ArrayList<>());       // 各ノードに空のリストを用意する
}
graph.get(1).add(new int[]{2, 5});      // ノード1→ノード2、重み5の辺を追加する
graph.get(1).add(new int[]{3, 2});      // ノード1→ノード3、重み2の辺を追加する
```

### PriorityQueue（優先度付きキュー）とは

要素を追加する順序に関わらず、常に最小（または最大）の要素を先頭に保つデータ構造。ダイクストラ法では「距離が最小のノード」を効率的に取り出すために使う。

```java
// int[]の第0要素（距離）で昇順に並べるmin-heap
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{0, 1});   // {距離0, ノード1} をキューに追加する
pq.offer(new int[]{5, 2});   // {距離5, ノード2} をキューに追加する
int[] curr = pq.poll();       // 距離が最小の要素 {0, 1} を取り出す
pq.isEmpty();                 // キューが空かどうかをbooleanで返す
```

### ダイクストラ法の緩和（Relaxation）とは

あるノード `u` を経由してノード `v` に到達する距離 `dist[u] + w` が、現在の `dist[v]` より小さいとき、`dist[v]` をより短い値に更新する操作。この更新を繰り返すことで、最終的に全ノードへの最短距離が確定する。

```java
int newDist = dist[u] + w;      // uを経由してvに行く距離を計算する
if (newDist < dist[v]) {        // 現在の最短距離より短ければ
    dist[v] = newDist;          // 最短距離を更新する
    pq.offer(new int[]{newDist, v});  // 更新されたvをキューに追加する
}
```

## 計算量

| | 値 |
|---|---|
| Time | O((V + E) log V) — 各ノードと各辺について優先度付きキューの操作（log V）を行う |
| Space | O(V + E) — 隣接リストに全辺を保存し、距離配列とキューにノード数分を使う |

## コード

```java
// 入力: 有向辺リスト int[][] times（各要素は [始点, 終点, 重み]）、ノード数 int n、ソースノード int k
// 出力: ソースから全ノードに信号が届く最短時間を int で返す。到達不可能なノードがあれば -1 を返す
public int networkDelayTime(int[][] times, int n, int k) {
    // 隣接リストを作成する（ノード番号は1始まりなので、サイズn+1でインデックス0は未使用とする）
    List<List<int[]>> graph = new ArrayList<>();
    for (int i = 0; i <= n; i++) {
        graph.add(new ArrayList<>());
    }
    // 各辺 [u, v, w] を隣接リストに登録し、有向グラフの隣接リスト表現を完成させる
    for (int[] t : times) {
        graph.get(t[0]).add(new int[]{t[1], t[2]});
    }

    // 距離配列を無限大で初期化する。dist[i] は「ソースからノード i への現在の最短距離」を表す
    int[] dist = new int[n + 1];
    Arrays.fill(dist, Integer.MAX_VALUE);
    // ソースノードから自身への距離は0
    dist[k] = 0;

    // 距離（第0要素）の昇順で取り出すmin-heapを作成し、ソースノード {距離0, ノードk} を追加する
    PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
    pq.offer(new int[]{0, k});

    while (!pq.isEmpty()) {
        int[] curr = pq.poll();
        int d = curr[0];  // ソースからノードuまでの距離
        int u = curr[1];  // 現在処理するノード

        // d > dist[u] なら、既により短い距離で処理済み。キューに古い（距離が大きい）エントリが残っている場合に発生する
        if (d > dist[u]) continue;

        // 隣接ノードへの緩和を試みる
        for (int[] nei : graph.get(u)) {
            int v = nei[0];  // 隣接ノード
            int w = nei[1];  // 辺の重み
            // uを経由した距離 d + w が現在の dist[v] より短ければ、距離を更新しキューに追加する
            if (d + w < dist[v]) {
                dist[v] = d + w;
                pq.offer(new int[]{d + w, v});
            }
        }
    }

    // 全ノードの最短距離のうち最大値を求める。この最大値が「全ノードに信号が届く最短時間」である
    int max = 0;
    for (int i = 1; i <= n; i++) {
        // Integer.MAX_VALUE のままなら到達不可能なノードが存在するので -1 を返す
        if (dist[i] == Integer.MAX_VALUE) return -1;
        max = Math.max(max, dist[i]);
    }
    return max;
}
```
