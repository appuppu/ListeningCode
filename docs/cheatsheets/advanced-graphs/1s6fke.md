# Finding the Minimum Cost to Connect All Points — 全点を最小コストで接続する

## 問題の本質

2D平面上の点の配列 `points` が与えられる。任意の2点間のコストはマンハッタン距離 `|xi - xj| + |yi - yj|` で定義される。すべての点を接続するための**最小総コスト**を返す。これは最小全域木（MST: Minimum Spanning Tree）を求める問題である。

## 核心のアイデア

すべての点を最小コストで接続するには、Primのアルゴリズムで「現在のMSTに最も近い未訪問の点」を貪欲に選び続ければよい。優先度付きキューを使えば、最小コストの辺を効率的に取り出せる。

## 思考プロセス

1. **これはMST問題である**: すべての点を接続し、かつコストを最小化する。これは最小全域木の定義そのものである。グラフの辺の重みはマンハッタン距離で計算できる
2. **完全グラフなのでPrimが適している**: n個の点があると辺の数はn(n-1)/2本になる。Kruskalではすべての辺を事前に生成・ソートする必要があるが、Primならば現在のMSTに隣接する辺だけを逐次的に処理できる
3. **最小コストの辺を高速に取り出したい**: Primのアルゴリズムでは、毎回「未訪問の点への最小コスト辺」を選ぶ必要がある。優先度付きキュー（最小ヒープ）を使えば、この取り出しをO(log n)で行える
4. **任意の点から開始できる**: MSTの総コストはどの点から始めても同じなので、点0からスタートする。初期状態では点0へのコスト0をキューに入れる
5. **訪問済みフラグで重複を防ぐ**: キューから取り出した点がすでにMSTに含まれている場合はスキップする。これにより同じ点を二重に処理することを防ぐ
6. **新しい点をMSTに追加するたびに隣接辺を追加する**: MSTに点uを追加したら、uからすべての未訪問点vへのマンハッタン距離を計算し、キューに追加する。キューが自動的に最小コストの辺を次の候補として管理する

## 前提知識

### 最小全域木（MST）とは

グラフのすべての頂点を接続する部分グラフのうち、辺の重みの合計が最小のもの。n個の頂点に対して正確にn-1本の辺を持ち、閉路を含まない。

### Primのアルゴリズムとは

MSTを構築する貪欲アルゴリズム。任意の頂点から開始し、「現在のMSTと未訪問の頂点を結ぶ辺のうち、最小重みの辺」を繰り返し選んでMSTを拡大する。すべての頂点がMSTに含まれたら終了する。

### マンハッタン距離とは

2点間の各座標の差の絶対値の合計。2D平面上の点 `(x1, y1)` と `(x2, y2)` の距離は `|x1 - x2| + |y1 - y2|` で計算する。格子状の道を歩く場合の最短距離に相当する。

```java
int dist = Math.abs(pts[u][0] - pts[v][0]) + Math.abs(pts[u][1] - pts[v][1]);
```

### PriorityQueue（優先度付きキュー）とは

要素を優先度順に取り出せるデータ構造。デフォルトでは最小値が最初に取り出される（最小ヒープ）。`offer` で追加、`poll` で最小要素の取り出しを行い、どちらもO(log n)で動作する。

```java
// int[]の第0要素で昇順に並べる優先度付きキューを作成する
PriorityQueue<int[]> pq = new PriorityQueue<>((a, b) -> a[0] - b[0]);
pq.offer(new int[]{5, 0});   // [コスト=5, 点のインデックス=0] を追加する
pq.offer(new int[]{2, 1});   // [コスト=2, 点のインデックス=1] を追加する
int[] min = pq.poll();       // コストが最小の要素 [2, 1] を取り出す
```

## 計算量

| | 値 |
|---|---|
| Time | O(n² log n) — 各点をMSTに追加するたびに最大n個の辺をキューに追加し、キュー操作にlog nかかる |
| Space | O(n²) — キューに最大n²個の辺が格納される。inMST配列はO(n) |

## コード

```java
// 入力: 2D座標の配列 pts（各要素は [x, y]）
// 出力: すべての点を接続する最小コストを int で返す
int minCostConnectPoints(int[][] pts) {
    // 点の数を取得する
    int n = pts.length;
    // 各点がMSTに含まれているかを管理するフラグ配列（すべてfalseで初期化される）
    boolean[] inMST = new boolean[n];
    // {コスト, 点のインデックス} を格納し、コスト昇順で取り出す優先度付きキュー
    PriorityQueue<int[]> pq =
        new PriorityQueue<>((a, b) -> a[0] - b[0]);
    // 開始点（インデックス0）をコスト0でキューに追加する
    // コスト0は、最初の点をMSTに追加するコストが0であることを意味する
    // MSTの総コストはどの点から始めても同じなので、任意に点0を選んでいる
    pq.offer(new int[]{0, 0});
    // cost: MSTの総コスト、visited: MSTに追加済みの点の数
    int cost = 0, visited = 0;

    // すべての点がMSTに含まれるまで繰り返す
    while (visited < n) {
        // コストが最小の辺を取り出す（d: 接続コスト、u: 点のインデックス）
        int[] curr = pq.poll();
        int d = curr[0], u = curr[1];

        // すでにMSTに含まれている点はスキップする
        // 同じ点が異なるコストでキューに複数回追加されている場合があるため、この判定が必要
        if (inMST[u]) continue;

        // 点uをMSTに追加し、コストを加算する
        inMST[u] = true;
        cost += d;
        visited++;

        // 点uからすべての未訪問点への辺をキューに追加する
        // 次の候補辺がキューに登録され、キューが自動的に最小コストの辺を管理する
        for (int v = 0; v < n; v++) {
            if (!inMST[v]) {
                // マンハッタン距離を計算する: |xu - xv| + |yu - yv|
                int nd =
                    Math.abs(pts[u][0] - pts[v][0])
                    + Math.abs(pts[u][1] - pts[v][1]);
                pq.offer(new int[]{nd, v});
            }
        }
    }
    // whileループ終了後、costにMSTの総コストが格納されている
    return cost;
}
```
