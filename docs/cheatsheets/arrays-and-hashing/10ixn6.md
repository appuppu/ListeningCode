# Computing Products Without Self Inclusion — 自分自身を除いた全要素の積を求める

## 問題の本質

整数の配列 `nums` が与えられる。各インデックス `i` について、`nums[i]` **以外**の全要素の積を計算し、その結果を格納した配列 `result` を返す。除算演算子を使ってはならない。

## 核心のアイデア

ある要素を除いた全体の積は、「その要素より左側にある全要素の積」×「その要素より右側にある全要素の積」に分解できる。この左右の累積積を順方向・逆方向の2回の走査で構築すれば、除算なしにO(n)で解ける。

## 思考プロセス

1. **除算が使えないので別の分解方法を考える**: 全体の積を求めて各要素で割る方法は禁止されている。そこで、`result[i]` を「`nums[i]` の左側の積」×「`nums[i]` の右側の積」として分解する。この分解なら除算は不要である
2. **左側の累積積は順方向の走査で構築できる**: 配列を左から右へ走査しながら、各位置における「自分より左にある全要素の積」を計算する。`result[i] = result[i-1] * nums[i-1]` という漸化式が成り立つ。先頭要素の左側には要素がないので、`result[0] = 1`（積の単位元）で初期化する
3. **右側の累積積は逆方向の走査で構築できる**: 配列を右から左へ走査しながら、変数 `record` に「自分より右にある全要素の積」を蓄積する。末尾要素の右側には要素がないので、`record = 1` で初期化する
4. **2つの積を掛け合わせる**: 逆方向の走査中に、`result[i]`（左側の積）に `record`（右側の積）を掛けることで、最終的な答えが得られる。掛け合わせた後に `record = record * nums[i]` で右側の積を更新する
5. **追加の配列を使わずに済む**: 左側の積を `result` 配列に直接書き込み、右側の積を変数1つで管理するため、出力配列以外の追加メモリはO(1)で済む

## 前提知識

### 累積積（Prefix Product / Suffix Product）とは

配列の先頭または末尾から順に要素を掛け合わせていくことで得られる積の列。累積和の掛け算版にあたる。各位置における「それまでの全要素の積」を効率的に求められる。

```java
int[] nums = {1, 2, 3, 4};

// 左からの累積積（prefix product）
// prefix[0] = 1（左に要素がない）
// prefix[1] = 1（nums[0]まで）
// prefix[2] = 1*2 = 2（nums[1]まで）
// prefix[3] = 1*2*3 = 6（nums[2]まで）

// 右からの累積積（suffix product）
// suffix[3] = 1（右に要素がない）
// suffix[2] = 4（nums[3]まで）
// suffix[1] = 4*3 = 12（nums[3]*nums[2]）
// suffix[0] = 4*3*2 = 24（nums[3]*nums[2]*nums[1]）
```

### 積の単位元

任意の数に1を掛けても値は変わらない。累積積の初期値として1を使うことで、最初の要素に対しても同じ漸化式を適用できる。

```java
int record = 1;              // 積の初期値は1（単位元）
record = record * nums[i];   // 最初の掛け算では record = nums[i] となる
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を順方向と逆方向にそれぞれ1回ずつ走査するだけで済む |
| Space | O(1) — 出力配列 `result` を除けば、追加で使用するメモリは変数 `record` のみである |

## コード

```java
// 入力: 整数配列 nums
// 出力: 各インデックスについて自分以外の全要素の積を格納した int[] を返す
public int[] productExceptSelf(int[] nums) {
    // nums と同じ長さの配列を作成する。まず左側の累積積を格納し、後から右側の累積積を掛け合わせる
    int[] result = new int[nums.length];

    // 順方向の走査：各位置の左側にある全要素の積を result に格納する
    result[0] = 1;  // 先頭要素の左側には要素が存在しないため、積の単位元である1で初期化する
    for (int i = 1; i < nums.length; i++) {
        // result[i-1] は位置 i-1 までの左側の積。そこに nums[i-1]（1つ左の要素）を掛けて位置 i の左側の積を得る
        result[i] = result[i - 1] * nums[i - 1];
    }

    // 逆方向の走査：右側の累積積を掛け合わせて最終結果を完成させる
    // record は「現在の位置より右にある全要素の積」を蓄積する変数
    int record = 1;  // 末尾要素の右側には要素が存在しないため、1で初期化する
    for (int i = nums.length - 1; i >= 0; i--) {
        // result[i] には左側の積が入っている。record（右側の積）を掛けて「自分以外の全要素の積」を完成させる
        result[i] = record * result[i];
        // 注意: record の更新は result[i] を確定させた後に行う。先に更新すると nums[i] 自身が積に含まれてしまう
        record = record * nums[i];
    }

    // 各要素に「自分以外の全要素の積」が格納された result を返す
    return result;
}
```
