# Validating a Sudoku Board — 9×9のSudokuボードが有効かを判定する

## 問題の本質

9×9の二次元文字配列で表されたSudokuボードが与えられる。各行・各列・各3×3のサブグリッドに重複する数字が含まれていなければ有効と判定し、`true` を返す。空セルはドット `.` で表される。ボードが完成している必要はなく、現在の配置が規則に違反していないかだけを確認する。

## 核心のアイデア

ボード全体を1回走査しながら、各セルの数字が「その行」「その列」「その3×3ボックス」のいずれかで既に出現していれば無効と判定する。任意のセル `(i, j)` が属するボックスのインデックスは `(i/3) * 3 + j/3` という式で0〜8に一意にマッピングできる。

## 思考プロセス

1. **検証すべき条件を整理する**: Sudokuの有効性は「各行に重複なし」「各列に重複なし」「各3×3ボックスに重複なし」の3つの条件で決まる。これら3つの条件を同時に検証できれば効率的である
2. **重複の検出にはHashSetが適している**: ある数字が既に出現したかをO(1)で判定するにはHashSetが最適。行ごとに9個、列ごとに9個、ボックスごとに9個、合計27個のHashSetを用意すれば、3つの条件を同時にチェックできる
3. **セルからボックスへのマッピングが必要**: セル `(i, j)` がどのボックスに属するかを計算する必要がある。行方向は `i/3`（整数除算）で0,1,2の3グループ、列方向は `j/3` で0,1,2の3グループに分かれる。これを1次元インデックスに変換するには `(i/3) * 3 + j/3` とする。これにより9つのボックスが0〜8の番号に対応する
4. **1回の走査で全条件を検証する**: 二重forループでボード全体を走査し、各セルについて行・列・ボックスの3つのSetに対して重複チェックと登録を行う。ドットは数字ではないのでスキップする
5. **重複が見つかった時点で即座にfalseを返す**: 3つのSetのいずれかに既に同じ数字が含まれていれば、そのボードは無効なので即座に `false` を返す
6. **全セルを走査し終えたらtrueを返す**: 重複が一度も見つからなければ、ボードは有効である

## 前提知識

### HashSet とは

重複しない要素の集合を管理するデータ構造。要素の追加・存在確認がO(1)でできる。今回は「ある数字が既に出現したか」を高速に判定するために使う。

```java
Set<Character> set = new HashSet<>();  // 空のHashSetを作成
set.add('5');            // 要素'5'を追加する
set.contains('5');       // 要素'5'が存在するかをbooleanで返す → true
set.contains('3');       // 要素'3'が存在するかをbooleanで返す → false
```

### HashSetの配列を作成する方法

9つのHashSetを配列としてまとめて管理する。ジェネリクス配列は直接作成できないため、`new HashSet[9]` で生の型の配列を作り、各要素をループで初期化する。

```java
Set<Character>[] sets = new HashSet[9];  // 9個分の配列を確保
for (int i = 0; i < 9; i++) {
    sets[i] = new HashSet<>();           // 各要素を空のHashSetで初期化
}
```

### ボックスインデックスの計算式

`boxIdx = (i/3) * 3 + j/3` は、セル `(i, j)` が属する3×3ボックスの番号（0〜8）を返す。`i/3` は行方向のボックス位置（0,1,2）、`j/3` は列方向のボックス位置（0,1,2）を表す。行方向の位置に3を掛けて列方向の位置を足すことで、9つのボックスに一意の番号を割り当てる。

```
ボックス番号の配置:
0 | 1 | 2
3 | 4 | 5
6 | 7 | 8

例: セル(4, 7) → (4/3)*3 + 7/3 = 1*3 + 2 = 5 → ボックス5に属する
```

## 計算量

| | 値 |
|---|---|
| Time | O(n²) — 9×9のボード全体を1回走査する（n=9で固定なのでO(81)=O(1)とも言える） |
| Space | O(n²) — 27個のHashSetに最大81個の要素を保存する |

## コード

```java
// 入力: 9×9の二次元文字配列 board（数字 '1'〜'9' またはドット '.'）
// 出力: ボードが有効なら true、無効なら false を返す
public boolean isValidSudoku(char[][] board) {
    // 行・列・ボックスごとに出現した数字を記録するHashSetの配列を作成する
    // rowset[i] は i行目、columnset[j] は j列目、boxset[k] は k番目のボックスに出現した数字を記録する
    Set<Character>[] rowset = createSets();
    Set<Character>[] columnset = createSets();
    Set<Character>[] boxset = createSets();

    // 外側ループで行、内側ループで列を走査し、全81セルを1回ずつ訪問する
    for (int i = 0; i < 9; i++) {
        for (int j = 0; j < 9; j++) {
            // 現在のセルの値を取得する
            char c = board[i][j];
            // ドットは空セル（数字ではない）のでスキップする
            if (c == '.') {
                continue;
            }

            // セル(i, j)が属するボックスの番号を計算する（0〜8に一意対応）
            int boxIdx = (i / 3) * 3 + j / 3;

            // 行・列・ボックスのいずれかに既に同じ数字があれば重複なので即座にfalseを返す
            if (rowset[i].contains(c) || columnset[j].contains(c) || boxset[boxIdx].contains(c)) {
                return false;
            }

            // 重複がなければ3つのSetに現在の数字を登録し、以降の重複検出に備える
            rowset[i].add(c);
            columnset[j].add(c);
            boxset[boxIdx].add(c);
        }
    }
    // 全セルを走査して重複が一度も見つからなければ、ボードは有効
    return true;
}

// 9個の空のHashSetを持つ配列を作成するヘルパーメソッド
public Set<Character>[] createSets() {
    Set<Character>[] sets = new HashSet[9];
    for (int i = 0; i < 9; i++) {
        sets[i] = new HashSet<>();
    }
    return sets;
}
```
