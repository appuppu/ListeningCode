# Finding Duplicates in an Array — 配列内に重複する値が存在するかを判定する

## 問題の本質

整数の配列 `nums` が与えられる。配列内に同じ値が2回以上出現する場合は `true` を、すべての要素が異なる場合は `false` を返す。

## 核心のアイデア

配列を走査しながら、これまでに見た要素をHashSetに記録していけば、各要素が既出かどうかをO(1)で判定できる。重複を見つけた時点で即座に `true` を返せる。

## 思考プロセス

1. **重複の判定 = 「以前に同じ値を見たか」の判定**: 配列を先頭から走査するとき、現在の要素が過去に出現済みであれば、それは重複である。つまり「これまでに見た要素の集合」を管理できれば、重複を検出できる
2. **過去に見た要素を高速に検索したい**: 各要素について「この値は既に見たか？」をO(1)で判定するには、HashSetが適している。HashSetは要素の存在確認をO(1)で行えるデータ構造である
3. **HashSetに何を保存するか**: 問題はインデックスではなく真偽値を返すだけなので、値そのものだけをHashSetに保存すれば十分である
4. **走査しながらHashSetを構築する**: 配列を先頭から順に走査し、各要素について「HashSetに既に含まれているか」を判定する。含まれていれば重複発見、含まれていなければ現在の要素をHashSetに追加して次へ進む
5. **早期リターンで効率化する**: 重複を見つけた時点で即座に `true` を返す。配列全体を走査し終えても重複が見つからなければ `false` を返す

## 前提知識

### HashSet とは

重複のない要素の集合を管理するデータ構造。要素の追加・存在確認がO(1)でできる。HashMapと異なり、キーと値のペアではなく値のみを保存する。重複を自動的に排除する性質を持つ。

```java
HashSet<Integer> set = new HashSet<>();  // 空のHashSetを作成
set.add(10);              // 要素10を追加する
set.contains(10);         // 要素10が存在するかをbooleanで返す → true
set.contains(5);          // 要素5が存在するかをbooleanで返す → false
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(n) — HashSetに最大n個の要素を保存する |

## コード

```java
// 入力: 整数配列 nums
// 出力: 重複する値が存在すれば true、すべて異なれば false
public boolean containsDuplicate(int[] nums) {
    // これまでに走査した要素を記録するHashSet
    // 問題が求めるのは真偽値だけなので、値のみを保存すれば十分
    HashSet<Integer> seen = new HashSet<>();

    for (int num : nums) {
        // 現在の要素が既にHashSetに存在すれば、同じ値が2回出現したことになり重複確定
        if (seen.contains(num)) {
            return true;  // 重複を見つけた時点で即座に返す（早期リターン）
        }

        // 現在の要素をHashSetに追加して次へ進む
        // この要素は以降の走査で「過去に見た要素」として参照される
        seen.add(num);
    }
    // ループが終了しても重複が見つからなければ、すべての要素が異なることが確定
    return false;
}
```
