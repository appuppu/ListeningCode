# Finding the Longest Consecutive Number Sequence — 未ソートの配列から最長の連続整数列の長さを求める

## 問題の本質

整数の配列 `nums`（未ソート）が与えられる。配列の中から連続する整数の列（例: 1,2,3,4）を見つけ、その**最長の長さ**を返す。要素の並び順は関係なく、値として連続していればよい。

## 核心のアイデア

連続列の「始点」だけから長さを数えれば、無駄な重複計算を排除できる。ある数 `num` に対して `num - 1` がHashSetに存在しなければ、その数は連続列の始点である。始点からだけカウントを開始することで、全体としてO(n)を達成する。

## 思考プロセス

1. **連続列の始点を特定する**: 連続列の途中の数からカウントを始めると同じ列を何度も数えてしまう。`num - 1` が存在しない数だけが連続列の真の始点である。始点からのみカウントすれば、各要素は最大1回しかカウント対象にならない
2. **存在判定を高速に行いたい**: ある数が配列に含まれるかをO(1)で判定するために、全要素をHashSetに格納する。ソートすればO(n log n)で解けるが、HashSetを使えばO(n)で済む
3. **始点から連続を数え上げる**: 始点 `num` を見つけたら、`num + 1`, `num + 2`, ... とHashSetに存在するか順番に確認し、連続が途切れるまでの長さを数える
4. **最長を追跡する**: 各連続列の長さを変数 `longest` と比較し、より長ければ更新する。全要素を処理した後の `longest` が答えである

## 前提知識

### HashSet とは

重複なしで値を保存するデータ構造。値の追加・存在判定がO(1)でできる。HashMapと異なりキーのみを保存し、ある値が「存在するか否か」を高速に判定したい場面で使う。

```java
HashSet<Integer> set = new HashSet<>();  // 空のHashSetを作成
set.add(4);              // 値4をセットに追加する
set.add(4);              // 重複は無視される（セットの要素数は変わらない）
set.contains(4);         // 値4が存在するかをbooleanで返す → true
set.contains(5);         // 値5が存在するかをbooleanで返す → false
```

### 連続列の始点とは

ある数 `num` について、`num - 1` がセットに存在しないとき、`num` は連続列の最初の数（始点）である。
例: セット={100, 4, 200, 1, 3, 2} のとき、1は始点（0が存在しない）、2は始点ではない（1が存在する）。

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 各要素は始点判定で1回、カウントで最大1回の計2回しかアクセスされない |
| Space | O(n) — HashSetに最大n個の要素を保存する |

## コード

```java
// 入力: 整数配列 nums（未ソート、重複あり得る）
// 出力: 最長の連続整数列の長さを int で返す
public int longestConsecutive(int[] nums) {
    // 全要素をHashSetに格納し、O(1)で存在判定できるようにする
    // 重複要素は自動的に排除される
    Set<Integer> numSet = new HashSet<>();
    for (int num : nums) {
        numSet.add(num);
    }

    // これまでに見つけた連続列の最長の長さを保持する変数
    int longest = 0;

    // HashSetの各要素を走査する
    for (int num : numSet) {
        // num - 1 が存在しなければ、numは連続列の始点である
        // num - 1 が存在する場合、numは連続列の途中の数なのでスキップする
        // （この数は別の始点からのカウント時に数えられる）
        if (!numSet.contains(num - 1)) {
            int currentNum = num;
            int length = 1;

            // 始点から連続する数（num+1, num+2, ...）を順番に数え上げる
            // 連続が途切れるまでループを続ける
            while (numSet.contains(currentNum + 1)) {
                currentNum++;
                length++;
            }

            // 現在の連続列の長さがこれまでの最長を超えていれば更新する
            longest = Math.max(longest, length);
        }
    }
    // 全要素の走査が終了したら、最長の連続整数列の長さを返す
    return longest;
}
```
