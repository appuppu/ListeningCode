# Grouping Words by Anagram Patterns — アナグラム同士の単語をグループにまとめる

## 問題の本質

文字列の配列 `strs` が与えられる。互いにアナグラムである文字列同士をグループにまとめ、グループのリストとして返す。2つの文字列がアナグラムであるとは、同じ文字を同じ回数だけ含み、並び順だけが異なることを意味する。

## 核心のアイデア

アナグラム同士は「各文字の出現回数」がまったく同じである。26文字それぞれの出現回数を数えて文字列化したものをキーにすれば、アナグラム同士は必ず同じキーになるので、HashMapで一括グループ化できる。

## 思考プロセス

1. **アナグラムの共通性質を見つける**: アナグラム同士は文字の並び順だけが異なり、各文字の出現回数は完全に一致する。この「出現回数の一致」をグループ化の判定基準に使える
2. **出現回数をどう表現するか**: 英小文字は26種類なので、サイズ26の整数配列 `count` を用意し、各文字の出現回数をカウントする。この配列の中身が同じなら、その単語同士はアナグラムである
3. **配列をHashMapのキーにする方法**: Javaでは配列をそのままHashMapのキーにできない（参照比較になるため）。そこで、配列の各要素を `#` で区切って連結した文字列（例: `"1#0#0#...#"`）をキーとして使う。こうすれば同じ出現回数の単語は同じ文字列キーを生成する
4. **HashMapでグループ化する**: キーが同じ単語は同じリストに入れればよい。`computeIfAbsent` を使えば、キーが未登録のときは新しいリストを自動生成し、既に登録済みのときはそのリストを返すので、条件分岐なしで単語を追加できる
5. **最終的に返すもの**: HashMapの全バリュー（各グループのリスト）を `ArrayList` に変換して返す

## 前提知識

### HashMap とは

キーと値のペアを保存するデータ構造。キーを指定して値の検索・取得がO(1)でできる。配列のインデックスアクセスと同じ速度で、任意のキーでアクセスできる辞書のようなもの。

```java
HashMap<String, List<String>> map = new HashMap<>();  // 空のHashMapを作成
map.put("key", new ArrayList<>());  // キー"key"に空のリストを格納する
map.containsKey("key");             // キー"key"が存在するかをbooleanで返す → true
map.get("key");                     // キー"key"に対応する値を返す → []
map.values();                       // 全ての値をCollectionとして返す
```

### computeIfAbsent とは

HashMapのメソッド。指定したキーが存在しなければ、第2引数のラムダ式で値を生成して登録し、その値を返す。キーが既に存在すれば、既存の値をそのまま返す。キーの有無による条件分岐を1行で書ける。

```java
// キー"abc"が未登録なら新しいArrayListを作成して登録し、そのリストを返す
// キー"abc"が登録済みなら、既存のリストをそのまま返す
map.computeIfAbsent("abc", k -> new ArrayList<>()).add("cab");
```

### 文字の出現回数カウント

`char` 型の文字から `'a'` を引くと、a=0, b=1, ..., z=25 のインデックスに変換できる。サイズ26の配列を用意し、このインデックスの位置をインクリメントすることで、各文字の出現回数を記録する。

```java
int[] count = new int[26];           // 26文字分のカウント配列を作成（初期値は全て0）
for (char c : "eat".toCharArray())   // 文字列を1文字ずつ走査する
    count[c - 'a']++;                // 該当する文字の位置をインクリメントする
// 結果: count[0]=1(a), count[4]=1(e), count[19]=1(t), 他は0
```

## 計算量

| | 値 |
|---|---|
| Time | O(n × k) — nは文字列の個数、kは文字列の平均長さ。各文字列について文字数分のカウントとサイズ26のキー生成を行う |
| Space | O(n × k) — HashMapに全ての文字列を保存し、各キーは固定長だが文字列自体がk文字分のメモリを占める |

## コード

```java
// 入力: 文字列配列 strs
// 出力: アナグラム同士をグループ化した List<List<String>> を返す
public List<List<String>> groupAnagrams(String[] strs) {
    // キー=出現回数の文字列表現、バリュー=そのキーに属する単語のリスト を保存するHashMap
    // 同じキーを持つ単語同士がアナグラムである
    Map<String, List<String>> map = new HashMap<>();

    // 配列 strs の各文字列 s を先頭から末尾まで1つずつ走査する
    for (String s : strs) {
        // 各文字（a〜z）の出現回数を記録するサイズ26の配列を作成する（初期値は全て0）
        // 文字列ごとに新しい配列を作成するのは、前の文字列のカウント結果が残らないようにするため
        int[] count = new int[26];
        // toCharArray() で文字配列に変換し、各文字 c について出現回数をカウントする
        for (char c : s.toCharArray())
            // c - 'a' により、文字 c をインデックス0〜25に変換してインクリメントする
            count[c - 'a']++;

        // 出現回数の配列を"1#0#0#..."形式の文字列キーに変換する
        // このキーは文字の出現回数を一意に表現し、アナグラム同士は必ず同じキーになる
        // 要素ごとに区切り文字 # を挟むことで、異なるカウントが同じ文字列にならないようにする
        StringBuilder sb = new StringBuilder();
        for (int n : count)
            sb.append(n).append('#');
        String key = sb.toString();

        // キーが未登録なら新しいリストを作成し、現在の文字列をリストに追加する
        // これにより、同じキーを持つ単語が同じリストに蓄積される
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }

    // 全グループのコレクションを取得し、List<List<String>> に変換して返す
    return new ArrayList<>(map.values());
}
```
