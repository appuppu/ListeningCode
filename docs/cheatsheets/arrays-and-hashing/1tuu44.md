# Checking if Two Strings Are Anagrams — 2つの文字列が同じ文字の並び替えかを判定する

## 問題の本質

2つの文字列 `s` と `t` が与えられる。`t` が `s` のアナグラムであるかを判定し、**boolean**で返す。アナグラムとは、2つの文字列が全く同じ文字を同じ出現回数だけ含み、順番だけが異なる関係のことである。

## 核心のアイデア

アナグラムかどうかは「各文字の出現回数が完全に一致するか」に帰着する。小文字アルファベットは26種類しかないので、固定長26の配列で全文字の出現回数を管理すれば、O(1)の空間でO(n)の時間で判定できる。

## 思考プロセス

1. **アナグラムの定義を数学的に捉える**: 2つの文字列がアナグラムであるとは、各文字の出現頻度が完全に一致することを意味する。つまり、文字の順番は無視して、頻度だけを比較すればよい
2. **長さが異なれば即座にfalse**: アナグラムは同じ文字を同じ回数含むので、文字列の長さが異なる時点でアナグラムではありえない。これを最初に判定することで、無駄な処理を省ける
3. **頻度の比較方法を考える**: 小文字アルファベットは'a'から'z'の26種類に限定されている。HashMapではなく、サイズ26の固定長int配列を使えば、各文字の出現回数をインデックスで管理できる
4. **1つの配列で両方の文字列を処理する**: 2つの配列を作って比較する代わりに、1つの配列に対して一方の文字列でインクリメント、もう一方でデクリメントする。最終的に全要素が0であれば、頻度が完全に一致したことを意味する
5. **同じループ内で両方を処理する**: 文字列の長さが等しいことを事前に確認しているので、1つのforループ内で `s` のインクリメントと `t` のデクリメントを同時に行える
6. **最終判定**: ループ終了後、配列の全要素が0であるかを確認する。1つでも0でない要素があれば、ある文字の出現回数が一致していないのでfalseを返す

## 前提知識

### 文字から配列インデックスへの変換

`char - 'a'` という演算により、小文字アルファベットを0〜25の整数に変換できる。これにより、文字をそのまま配列のインデックスとして使える。

```java
char c = 'd';
int index = c - 'a';    // 'd' - 'a' = 3（'a'=0, 'b'=1, 'c'=2, 'd'=3）
int[] count = new int[26];
count[c - 'a']++;       // count[3] が1になる（'d'の出現回数を記録）
```

### 固定長配列による頻度カウント

サイズ26のint配列を用意すると、各インデックスが1文字に対応する頻度テーブルとして機能する。Javaでは `new int[26]` で全要素が0に初期化される。

```java
int[] count = new int[26];  // 全要素0で初期化される
count['b' - 'a']++;        // count[1] = 1（'b'の出現を記録）
count['b' - 'a']--;        // count[1] = 0（'b'の出現を打ち消す）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 文字列を1回走査するだけで済む（nは文字列の長さ） |
| Space | O(1) — 使用する配列のサイズは常に26で、入力の長さに依存しない |

## コード

```java
// 入力: 2つの文字列 s と t
// 出力: t が s のアナグラムであれば true、そうでなければ false を返す
public boolean isAnagram(String s, String t) {
    // アナグラムは同じ文字を同じ回数含むので、長さが異なる時点でアナグラムではない
    if (s.length() != t.length())
        return false;

    // 各アルファベットの出現回数の「差」を記録する配列（インデックス0='a', 25='z'）
    // サイズ26はa〜zの26文字に対応する
    int[] count = new int[26];

    // 1つのループで両方の文字列を同時に処理する（長さが等しいことを事前に確認済み）
    for (int i = 0; i < s.length(); i++) {
        // sの文字でインクリメント：「sにこの文字が1回出現した」ことを記録
        count[s.charAt(i) - 'a']++;
        // tの文字でデクリメント：「tにこの文字が1回出現した」ことを記録
        // インクリメントとデクリメントが打ち消し合えば、その文字の出現回数はsとtで等しい
        count[t.charAt(i) - 'a']--;
    }

    // 全26要素を走査し、0でない要素が1つでもあれば出現回数が不一致
    for (int c : count) {
        if (c != 0) return false;
    }
    // 全要素が0 → 全文字の出現回数が一致 → アナグラムである
    return true;
}
```
