# Counting Ways to Climb Stairs — n段の階段を1段or2段ずつ登る方法の総数を求める

## 問題の本質

整数 `n`（階段の段数）が与えられる。1回に1段または2段ずつ登れるとき、頂上（n段目）に到達する**異なる登り方の総数**を返す。

## 核心のアイデア

n段目に到達するには「n-1段目から1段登る」か「n-2段目から2段登る」しかない。つまり `ways(n) = ways(n-1) + ways(n-2)` というフィボナッチ数列と同じ漸化式が成り立つ。直前2つの値だけを保持すれば、配列を使わずにO(1)の空間で計算できる。

## 思考プロセス

1. **最後の一歩から逆算する**: n段目に到達する直前の状態は「n-1段目にいる」か「n-2段目にいる」のどちらかしかない。したがって、n段目への登り方の総数は `ways(n) = ways(n-1) + ways(n-2)` という漸化式で表せる
2. **基底ケースを定める**: 1段の階段は1通り（1段登る）、2段の階段は2通り（1+1 または 2）。この2つが漸化式の出発点になる
3. **ボトムアップで計算する**: 再帰で上から計算すると同じ部分問題を何度も解くことになる。代わりに、小さい値から順に計算していくボトムアップ方式を採用すれば、各値を1回ずつ計算するだけで済む
4. **必要な変数は2つだけ**: 漸化式 `ways(i) = ways(i-1) + ways(i-2)` は直前2つの値しか参照しない。配列全体を保持する必要はなく、変数2つ（`prev2` と `prev1`）だけで十分である
5. **ループで変数を更新する**: `i = 3` から `n` まで順に、`curr = prev1 + prev2` で現在の値を計算し、`prev2 = prev1`、`prev1 = curr` とスライドさせて次のイテレーションに備える
6. **最終的に返すもの**: ループ終了後、`prev1` にn段目の登り方の総数が格納されているので、`prev1` を返す

## 前提知識

### 動的計画法（Dynamic Programming）とは

大きな問題を小さな部分問題に分割し、各部分問題の結果を記録しながら解く手法。同じ計算を繰り返さないことで効率化する。ボトムアップ方式では、最小の部分問題から順に解いていく。

```java
// ボトムアップDPの基本パターン（配列版）
int[] dp = new int[n + 1];   // 部分問題の結果を保存する配列
dp[1] = 1;                    // 基底ケース1
dp[2] = 2;                    // 基底ケース2
for (int i = 3; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];  // 漸化式で計算する
}
// dp[n] が最終的な答え
```

### スライディング変数とは

配列の代わりに変数2つだけで直前の値を保持するテクニック。漸化式が参照する過去の値が一定個数の場合、配列全体を保持する必要がなくなり、空間計算量をO(n)からO(1)に削減できる。

```java
int prev2 = 1;  // 2つ前の値を保持する変数
int prev1 = 2;  // 1つ前の値を保持する変数
int curr = prev1 + prev2;  // 現在の値を計算する
prev2 = prev1;  // prev2をスライドさせる（prev1の値を引き継ぐ）
prev1 = curr;   // prev1をスライドさせる（currの値を引き継ぐ）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 3からnまで1回ループするだけで済む |
| Space | O(1) — 変数2つ（prev2, prev1）しか使わない |

## コード

```java
// 入力: 整数 n（階段の段数）
// 出力: 頂上に到達する異なる登り方の総数を int で返す
public int climbStairs(int n) {
    // 基底ケース: 1段なら1通りしかない。後続のループが i=3 から始まるため、n=1 を先に処理する
    if (n == 1) return 1;

    // prev2は2つ前の段の登り方の総数。初期値は1段目の登り方（1通り）に対応する
    int prev2 = 1;
    // prev1は1つ前の段の登り方の総数。初期値は2段目の登り方（2通り: 1+1 または 2）に対応する
    int prev1 = 2;

    // i は現在計算している段数。1段目と2段目は初期値として設定済みなので3段目から開始する
    for (int i = 3; i <= n; i++) {
        // 漸化式: i段目の登り方 = (i-1)段目の登り方 + (i-2)段目の登り方
        int curr = prev1 + prev2;
        // 注意: prev2を先に更新しないと prev1 の元の値が失われる
        prev2 = prev1;
        prev1 = curr;
    }

    // ループ終了後、prev1 にn段目の登り方の総数が格納されている
    return prev1;
}
```
