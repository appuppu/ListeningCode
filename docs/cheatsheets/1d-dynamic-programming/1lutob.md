# Determining if a String Can Be Segmented Into Dictionary Words — 文字列を辞書の単語に分割できるか判定する

## 問題の本質

文字列 `s` と辞書の単語リスト `wordDict` が与えられる。`s` を辞書に含まれる単語の連結として分割できるかを判定し、**boolean**で返す。各辞書の単語は何度でも再利用できる。

## 核心のアイデア

文字列の先頭から各位置 `i` までの部分文字列について「分割可能かどうか」を記録していけば、位置 `i` の判定は「ある分割点 `j` までが分割可能」かつ「`j` から `i` までの部分文字列が辞書に存在する」かどうかに帰着できる。

## 思考プロセス

1. **部分問題に分解できる**: 文字列 `s` の先頭 `i` 文字が分割可能かを判定するには、ある位置 `j` で2つに分けて「先頭 `j` 文字が分割可能」かつ「`j` から `i` までが辞書の単語」であればよい。この構造は動的計画法に適している
2. **DPの定義を決める**: `dp[i]` を「文字列 `s` の先頭 `i` 文字が辞書の単語だけで分割可能かどうか」を表すbooleanとする。最終的に `dp[n]`（`n` は文字列の長さ）が答えになる
3. **基底条件を設定する**: 空文字列は常に分割可能なので、`dp[0] = true` とする。この基底条件があることで、文字列の先頭から始まる辞書の単語を検出できる
4. **遷移式を考える**: `dp[i]` が `true` になる条件は、`0 ≤ j < i` のいずれかの `j` について「`dp[j]` が `true`」かつ「`s.substring(j, i)` が辞書に存在する」が成り立つことである。すべての `j` を試せば判定できる
5. **辞書の検索を高速化する**: 単語リストをHashSetに変換しておけば、部分文字列が辞書に含まれるかを `contains` でO(1)で判定できる。リストのまま線形探索するより効率的である
6. **早期終了で無駄を省く**: ある `j` で `dp[i] = true` が確定したら、それ以上の `j` を試す必要はない。`break` で内側のループを抜けて次の `i` に進む

## 前提知識

### HashSet とは

重複のない要素を保存するデータ構造。要素が含まれるかの判定がO(1)でできる。辞書の単語リストを高速に検索するために使う。

```java
Set<String> set = new HashSet<>();       // 空のHashSetを作成
set.add("apple");                        // 要素を追加する
set.contains("apple");                   // 要素が存在するかをbooleanで返す → true
```

### コンストラクタによるListからSetへの変換

`HashSet` のコンストラクタにListを渡すと、Listの全要素をSetに変換できる。1行で辞書をHashSetに変換するために使う。

```java
List<String> list = Arrays.asList("a", "b", "c");
Set<String> set = new HashSet<>(list);   // Listの全要素をSetに変換する
```

### substring とは

文字列の一部を切り出すメソッド。`s.substring(j, i)` はインデックス `j` から `i - 1` までの文字を返す。DPの遷移で「位置 `j` から位置 `i` までの部分文字列」を取得するために使う。

```java
String s = "leetcode";
s.substring(0, 4);                       // "leet" を返す（インデックス0〜3）
s.substring(4, 8);                       // "code" を返す（インデックス4〜7）
```

### DP配列（boolean配列）とは

動的計画法で部分問題の結果を保存する配列。`boolean[] dp = new boolean[n + 1]` で作成すると、全要素が `false` で初期化される。`dp[i]` に `true` を代入することで「先頭 `i` 文字は分割可能」という結果を記録する。

```java
boolean[] dp = new boolean[5];           // [false, false, false, false, false] で初期化
dp[0] = true;                           // 基底条件を設定する
```

## 計算量

| | 値 |
|---|---|
| Time | O(n^2) — 外側ループがn回、内側ループが最大n回で、各ステップでsubstringの生成にO(n)かかる場合は厳密にはO(n^3)だが、平均的にはO(n^2)と扱う |
| Space | O(n) — サイズn+1のDP配列とHashSetに辞書の単語を保存する |

## コード

```java
// 入力: 文字列 s と辞書の単語リスト wordDict
// 出力: s を辞書の単語だけで分割できるなら true、できないなら false を返す
public boolean wordBreak(String s, List<String> wordDict) {
    // 辞書の単語リストをHashSetに変換して検索をO(1)にする
    Set<String> set = new HashSet<>(wordDict);
    // 文字列の長さを変数に保存する
    int n = s.length();

    // dp[i] = 先頭i文字が辞書の単語だけで分割可能かどうか
    // サイズがn+1なのは、dp[n]が文字列全体の分割可能性を表すため
    boolean[] dp = new boolean[n + 1];

    // 空文字列は常に分割可能（基底条件）
    // この設定がないと、文字列の先頭から始まる辞書の単語を検出できない
    dp[0] = true;

    // 外側ループ: iは「先頭何文字までを考えるか」を表す
    for (int i = 1; i <= n; i++) {
        // 内側ループ: jは分割点の候補。「先頭j文字」と「jからiまでの部分文字列」に分ける位置
        for (int j = 0; j < i; j++) {
            // 先頭j文字が分割可能 かつ jからiまでが辞書の単語なら、先頭i文字は分割可能
            // 2つの条件が同時に成り立つ = 「分割可能な部分 + 辞書の単語」に分けられる
            if (dp[j] && set.contains(s.substring(j, i))) {
                dp[i] = true;
                break;  // 分割可能と判明したので他のjを試す必要はない
            }
        }
    }

    // dp[n]は文字列s全体が分割可能かどうかを表している
    return dp[n];
}
```
