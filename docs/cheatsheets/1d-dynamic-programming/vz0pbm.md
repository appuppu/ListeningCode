# Finding the Minimum Cost to Climb Stairs — 階段の頂上に到達する最小コストを求める

## 問題の本質

整数配列 `cost` が与えられ、`cost[i]` は i 番目の段を踏むコストを表す。ステップ0またはステップ1から開始でき、各ステップで1段または2段登れる。階段の**頂上**（配列の末尾の1つ先）に到達するための最小総コストを返す。

## 核心のアイデア

各段に到達する最小コストは、「1段前から来る場合」と「2段前から来る場合」の小さい方で決まる。この計算には直前2つの結果だけが必要なので、配列を持たず2つの変数だけで最小コストを求められる。

## 思考プロセス

1. **頂上への到達方法は2通り**: 頂上（インデックス n）には、1つ前の段（n-1）から1段登るか、2つ前の段（n-2）から2段登るかの2通りで到達できる。それぞれのコストの小さい方が答えになる
2. **各段への最小コストは再帰的に定義できる**: 段 i に到達する最小コストを `dp[i]` とすると、`dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])` という漸化式が成り立つ。「1段前の最小コスト＋その段のコスト」と「2段前の最小コスト＋その段のコスト」の小さい方である
3. **初期条件を決める**: ステップ0またはステップ1から開始できるので、段0と段1に到達するコストはどちらも0である。つまり `dp[0] = 0`, `dp[1] = 0` となる
4. **配列全体は不要で、直前2つだけあればよい**: 漸化式 `dp[i]` は `dp[i-1]` と `dp[i-2]` のみに依存する。したがって、配列の代わりに2つの変数 `prev1`（1つ前）と `prev2`（2つ前）だけを保持すれば計算できる
5. **変数を更新しながら前に進む**: 段2から段nまで順にループし、毎回 `curr` を計算した後、`prev2 = prev1`, `prev1 = curr` とスライドさせる。ループ終了時の `prev1` が頂上への最小コストである

## 前提知識

### 動的計画法（Dynamic Programming）とは

大きな問題を小さな部分問題に分割し、部分問題の結果を再利用して効率的に解を求める手法。この問題では「段 i への最小コスト」を部分問題とし、小さいインデックスから順に解いていく（ボトムアップ方式）。

### Math.min とは

2つの整数のうち小さい方を返すJavaの標準メソッド。2つの選択肢からコストが低い方を選ぶのに使う。

```java
Math.min(5, 3);    // 3を返す — 2つの引数のうち小さい方を返す
Math.min(10, 10);  // 10を返す — 同じ値の場合はその値を返す
```

### 空間最適化の考え方

DP配列の各要素が直前の数個の要素にしか依存しない場合、配列全体を保持する代わりに、必要な数だけの変数で計算を回せる。この問題では `dp[i-1]` と `dp[i-2]` の2つだけが必要なので、変数2つで十分である。

```java
int prev2 = 0;  // dp[i-2] に相当する変数
int prev1 = 0;  // dp[i-1] に相当する変数
int curr;       // dp[i] に相当する変数（毎回計算して更新する）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 変数2つだけを使用し、配列サイズに依存しない |

## コード

```java
// 入力: 整数配列 cost（各段を踏むコスト）
// 出力: 階段の頂上（インデックス n）に到達する最小総コストを int で返す
public int minCostClimbingStairs(int[] cost) {
    // 配列の長さを取得。頂上はインデックス n の位置（配列の末尾の1つ先）
    int n = cost.length;

    // prev2=2つ前の段への最小コスト、prev1=1つ前の段への最小コスト
    // ステップ0と1から開始できるので初期コストは0
    int prev2 = 0, prev1 = 0;

    // 段2から頂上（段n）まで順に最小コストを計算する。i は現在到達しようとしている段
    for (int i = 2; i <= n; i++) {
        // prev1 + cost[i-1]: 1つ前の段から1段登って来る場合の総コスト
        // prev2 + cost[i-2]: 2つ前の段から2段登って来る場合の総コスト
        // 小さい方を選ぶ
        int curr = Math.min(
            prev1 + cost[i - 1],
            prev2 + cost[i - 2]);

        // 変数を1つずつ前にスライドさせる
        // 注意: prev2の更新を先に行わないと、prev1の元の値が失われる
        prev2 = prev1;
        prev1 = curr;
    }

    // prev1にループ最後のイテレーション（i = n）で計算された頂上への最小コストが格納されている
    return prev1;
}
```
