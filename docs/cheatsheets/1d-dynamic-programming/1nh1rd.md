# Finding the Longest Increasing Subsequence — 最長の厳密増加部分列の長さを求める

## 問題の本質

整数の配列 `nums` が与えられる。元の配列から要素を削除して（順序は変えずに）作れる**厳密に増加する部分列**のうち、最も長いものの長さを返す。部分列は連続である必要はないが、元の配列内での相対的な順序は保たなければならない。

## 核心のアイデア

「長さ `k` の増加部分列の末尾要素は、できるだけ小さい方が、後続の要素で伸ばせる可能性が高い」。各長さに対して末尾要素の最小値を配列 `tails` で管理すれば、新しい要素の挿入位置を二分探索でO(log n)で決定でき、全体をO(n log n)で解ける。

## 思考プロセス

1. **増加部分列を伸ばすには末尾が小さいほど有利**: 長さが同じ増加部分列が複数あるとき、末尾要素が最も小さいものが「次に繋げられる値の範囲」が最も広い。したがって、各長さごとに末尾要素の最小値だけを記録すれば十分である
2. **tails配列で末尾の最小値を管理する**: `tails[i]` に「長さ `i+1` の増加部分列が持ちうる末尾要素の最小値」を保存する配列 `tails` を用意する。この配列は常にソート済みの状態が保たれる（長さが長い部分列ほど末尾は大きくなるため）
3. **新しい要素の処理は2パターンに分かれる**: 配列の各要素 `num` について、`tails` の中で `num` 以上の最小の要素を二分探索で見つける。見つかった位置が `tails` の末尾を超えるなら、`num` は既存の最長部分列より大きいので `tails` の末尾に追加する。末尾を超えないなら、その位置の値を `num` で置き換えて末尾の最小値を更新する
4. **二分探索が使える理由**: `tails` 配列は常にソート済みであるため、`num` の挿入位置を `Collections.binarySearch` でO(log n)で特定できる。これにより各要素の処理がO(log n)となり、全体でO(n log n)を達成する
5. **tails配列の長さが答えになる**: 各要素の処理で `tails` は追加か置換のどちらかが行われる。追加は最長部分列の長さが1伸びたことを意味する。全要素の処理が終わった時点での `tails.size()` が、最長増加部分列の長さである

## 前提知識

### ArrayList とは

可変長の配列。要素の追加・取得・更新がO(1)でできる。通常の配列と異なり、サイズを事前に決める必要がない。

```java
List<Integer> list = new ArrayList<>();  // 空のArrayListを作成
list.add(10);          // 末尾に10を追加する → [10]
list.add(20);          // 末尾に20を追加する → [10, 20]
list.get(0);           // インデックス0の要素を取得する → 10
list.set(0, 5);        // インデックス0の要素を5に置き換える → [5, 20]
list.size();           // 要素数を返す → 2
```

### Collections.binarySearch とは

ソート済みリストに対して二分探索を行い、指定した値の位置を返すメソッド。値が見つかればそのインデックスを返す。見つからなければ `-(挿入位置) - 1` という負の値を返す。挿入位置とは、その値をリストに挿入してもソート順が保たれる位置のことである。

```java
List<Integer> list = Arrays.asList(2, 5, 8, 12);
Collections.binarySearch(list, 5);   // 5はインデックス1にある → 1を返す
Collections.binarySearch(list, 6);   // 6は存在しない。挿入位置は2 → -(2)-1 = -3を返す
Collections.binarySearch(list, 1);   // 1は存在しない。挿入位置は0 → -(0)-1 = -1を返す
Collections.binarySearch(list, 15);  // 15は存在しない。挿入位置は4 → -(4)-1 = -5を返す
```

負の戻り値から挿入位置を復元するには `-(戻り値 + 1)` を計算する。例: 戻り値が-3なら、`-(-3 + 1) = 2` が挿入位置である。

### tails配列の概念

`tails` は「長さごとの増加部分列の末尾要素の最小値」を記録する配列である。`tails[i]` は「長さ `i+1` の増加部分列が取りうる末尾の最小値」を意味する。この配列は常に昇順にソートされた状態を維持する。

例: nums = [3, 1, 4, 1, 5] を処理する過程:
- 3を処理 → tails = [3]（長さ1の部分列の末尾最小値は3）
- 1を処理 → tails = [1]（長さ1の末尾最小値を1に更新。3より1の方が小さく有利）
- 4を処理 → tails = [1, 4]（4は1より大きいので末尾に追加。長さ2の部分列ができた）
- 1を処理 → tails = [1, 4]（1の挿入位置はインデックス0で、既に1なので変化なし）
- 5を処理 → tails = [1, 4, 5]（5は4より大きいので末尾に追加。長さ3の部分列ができた）

最終的な `tails.size()` = 3 が答えである。

## 計算量

| | 値 |
|---|---|
| Time | O(n log n) — n個の要素それぞれに対してO(log n)の二分探索を行う |
| Space | O(n) — tails配列に最大n個の要素を保存する |

## コード

```java
// 入力: 整数配列 nums
// 出力: 最長の厳密増加部分列の長さを int で返す
public int lengthOfLIS(int[] nums) {
    // 各長さの増加部分列の末尾要素の最小値を昇順で保持する配列
    // tails[i] は「長さ i+1 の増加部分列が持ちうる末尾要素の最小値」を意味する
    List<Integer> tails = new ArrayList<>();

    // 配列 nums の各要素を先頭から末尾まで1つずつ走査する
    for (int num : nums) {
        // tails配列内でnumが入るべき位置を二分探索で求める
        // tails は常にソート済みなので二分探索が使える
        int pos = Collections.binarySearch(tails, num);

        // 負の値は「見つからなかった」を意味するので、挿入位置に変換する
        // pos が0以上の場合は num と同じ値が tails[pos] に既に存在するので、そのまま使う
        if (pos < 0)
            pos = -(pos + 1);

        if (pos == tails.size()) {
            // numがtailsの全要素より大きいので末尾に追加する
            // これは最長の増加部分列の長さが1伸びたことを意味する
            tails.add(num);
        } else {
            // 該当位置の末尾最小値をnumで置き換えて更新する
            // これにより長さ pos+1 の増加部分列の末尾最小値がより小さくなり、
            // 将来的に部分列を伸ばせる可能性が広がる
            tails.set(pos, num);
        }
    }

    // tails の要素数は処理中に末尾への追加が行われた回数と一致し、
    // これが最長増加部分列の長さである
    return tails.size();
}
```
