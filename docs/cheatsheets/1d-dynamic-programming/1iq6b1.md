# Finding the Subarray With Maximum Product — 最大の積を持つ連続部分配列を見つける

## 問題の本質

整数の配列 `nums` が与えられる。配列の中から**連続する部分配列**を選び、その要素の積が最大になるものを見つけ、その**積**を返す。部分配列は1つ以上の連続した要素で構成される。

## 核心のアイデア

負の数同士の掛け算は正の数になるため、現在の最小値（最も大きな負の数）が次の負の数と掛け合わさることで最大値に変わりうる。そのため、各位置で「現在の最大積」と「現在の最小積」の両方を追跡する必要がある。

## 思考プロセス

1. **部分配列の積の特性を考える**: 連続部分配列の積を求める問題では、要素を1つ追加するたびに「前の部分配列の積 × 現在の要素」で新しい積が計算できる。これはDPの考え方と同じで、前の状態から次の状態を導出できる
2. **負の数が最大積の計算を複雑にする**: 正の数だけなら最大積だけを追跡すればよいが、負の数があると「大きな負の積 × 負の数 = 大きな正の積」が発生する。つまり、現在の最小積（負の方向に最も大きい値）も追跡しなければ、最大積を見逃す可能性がある
3. **各位置での候補は3つに絞られる**: 位置 `i` における最大積の候補は、(a) `nums[i]` 単体（新しい部分配列を開始する場合）、(b) `curMax * nums[i]`（正の最大積を延長する場合）、(c) `curMin * nums[i]`（負の最小積が負の数で反転する場合）の3つである。この3つの最大値が新しい `curMax` になる
4. **最小積も同じ3つの候補から選ぶ**: 最小積の候補も同じ3つの値であり、その最小値が新しい `curMin` になる。最大と最小を同時に更新することで、負の数による反転を正しく捕捉できる
5. **更新時に前の値を退避する**: `curMax` を更新した後に `curMin` を計算すると、`curMin` の計算に更新前の `curMax` が使えなくなる。そのため、`curMax` の更新前にその値を一時変数 `temp` に退避し、`curMin` の計算では `temp` を使う
6. **グローバルな最大値を別変数で管理する**: `curMax` は現在位置での最大積であり、全体の最大積ではない。各位置で `result = Math.max(result, curMax)` として全体の最大積を更新し、最終的に `result` を返す

## 前提知識

### 部分配列の積と DP の関係

部分配列の積は、前の位置までの積に現在の要素を掛けることで延長できる。この性質を利用すると、各位置で「ここで終わる部分配列の最大積」を前の位置の結果から O(1) で計算できる。DP のように前の状態を保持して次の状態を導出する手法である。

### Math.max / Math.min とは

複数の値から最大値・最小値を取得する Java のメソッド。3つ以上の値を比較するには、入れ子にして呼び出す。

```java
Math.max(3, 7);                   // 2つの値の最大値を返す → 7
Math.min(3, 7);                   // 2つの値の最小値を返す → 3
Math.max(a, Math.max(b, c));      // 3つの値の最大値を返す
Math.min(a, Math.min(b, c));      // 3つの値の最小値を返す
```

### なぜ最小値の追跡が必要か

負の数を含む配列では、積の符号が要素ごとに反転する。例: `[-2, 3, -4]` の場合、位置1での最小積は `-2 × 3 = -6` だが、位置2で `-6 × -4 = 24` となり最大積になる。最大積だけを追跡していると、`-6` を捨ててしまい `24` を見逃す。

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 使用する変数は固定個数のみで、入力サイズに依存しない |

## コード

```java
// 入力: 整数配列 nums（長さ1以上）
// 出力: 連続部分配列の積の最大値を int で返す
public int maxProduct(int[] nums) {
    // result=全体の最大積、curMax=現在位置で終わる部分配列の最大積、curMin=同最小積
    // 最初の要素だけからなる部分配列が初期状態となる
    int result = nums[0];
    int curMax = nums[0];
    int curMin = nums[0];

    // i=0 は初期化で処理済みなので i=1 から開始する
    for (int i = 1; i < nums.length; i++) {
        int n = nums[i];
        // curMaxを更新する前に退避する（curMinの計算で更新前の値が必要なため）
        int temp = curMax;

        // 3つの候補から最大値を選ぶ:
        // n単体 → 新しい部分配列を開始する場合
        // temp * n → 前の最大積を延長する場合
        // curMin * n → 前の最小積（負）が負の n で反転して最大になる場合
        curMax = Math.max(n,
            Math.max(temp * n, curMin * n));

        // 同じ3つの候補から最小値を選ぶ（tempで更新前のcurMaxを使うことで、上の更新の影響を受けずに正しく計算できる）
        curMin = Math.min(n,
            Math.min(temp * n, curMin * n));

        // curMaxは現在位置での最大積であり全体の最大積ではないので、別変数 result で全体の最大積を管理する
        result = Math.max(result, curMax);
    }
    // result には配列全体を通じて最大の部分配列積が格納されている
    return result;
}
```
