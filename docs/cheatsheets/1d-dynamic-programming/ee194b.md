# Maximizing Robbery Loot in a Circular Neighborhood — 円形に並んだ家から隣接せずに最大金額を盗む

## 問題の本質

非負整数の配列 `nums` が与えられる。各要素は円形に並んだ家にある金額を表す。隣接する2つの家を連続して盗むことはできない。**最初の家と最後の家も隣接している**という制約のもとで、盗める金額の最大値を返す。

## 核心のアイデア

円形の制約は「最初の家と最後の家を同時に選べない」ことに帰着する。そこで「最初の家を含み最後を除く範囲」と「最後の家を含み最初を除く範囲」の2回に分けて線形版の House Robber を解き、大きい方を取れば円形の制約を満たせる。

## 思考プロセス

1. **円形の制約を分解する**: 円形配列では `nums[0]` と `nums[n-1]` が隣接する。つまり両方を同時に選ぶことはできない。これは「`nums[0]` を選ぶなら `nums[n-1]` は選べない」「`nums[n-1]` を選ぶなら `nums[0]` は選べない」という2つのケースに分解できる
2. **2つの線形問題に帰着させる**: ケース1は `nums[0..n-2]`（最初を含み最後を除く）、ケース2は `nums[1..n-1]`（最初を除き最後を含む）の範囲で、それぞれ線形版の House Robber を解けばよい。2つの結果の大きい方が答えになる
3. **線形版の漸化式を立てる**: 各家 `i` について、「家 `i` を盗む」か「盗まない」かの2択がある。盗む場合は `nums[i] + dp[i-2]`（1つ前は飛ばす）、盗まない場合は `dp[i-1]`（1つ前までの最大値をそのまま引き継ぐ）。よって `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` となる
4. **空間を定数に削減する**: 漸化式が参照するのは `dp[i-1]` と `dp[i-2]` の2つだけである。DP配列全体を保持する必要はなく、2つの変数 `prev1`（1つ前の最大値）と `prev2`（2つ前の最大値）だけで計算できる
5. **エッジケースを処理する**: 配列が空なら0を返す。要素が1つだけなら円形の制約は関係ないのでその値を返す。要素が2つ以上ある場合にのみ2パスの処理を行う
6. **最終的に返すもの**: 2つの範囲それぞれで得られた最大金額のうち、大きい方を `Math.max` で選んで返す

## 前提知識

### House Robber（線形版）とは

一列に並んだ家から、隣接する家を連続して選ばずに最大金額を得る問題。DPの基本問題であり、漸化式 `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` で解ける。この円形版は線形版を2回適用することで解く。

### ローリング変数によるDP空間最適化

DP配列のうち、漸化式が参照する直近の数個だけを変数として保持する手法。配列全体を保持する必要がなくなり、空間計算量をO(n)からO(1)に削減できる。

```java
int prev2 = 0, prev1 = 0;        // dp[i-2]とdp[i-1]に相当する変数を初期化する
int curr = Math.max(prev1, prev2 + nums[i]);  // dp[i]を計算する
prev2 = prev1;                    // prev2を1つ進める（旧prev1が新prev2になる）
prev1 = curr;                     // prev1を1つ進める（currが新prev1になる）
```

### Math.max とは

2つの値のうち大きい方を返すJavaの標準メソッド。DPの遷移で「盗む場合」と「盗まない場合」の最大値を選ぶために使う。

```java
Math.max(5, 3);   // → 5（大きい方を返す）
Math.max(prev1, prev2 + nums[i]);  // 盗まない場合と盗む場合の最大値を選ぶ
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を2回走査するが、各走査はO(n)なので全体でO(n)である |
| Space | O(1) — DP配列を使わず、2つのローリング変数のみで計算する |

## コード

```java
// 入力: 非負整数の配列 nums（円形に並んだ各家の金額）
// 出力: 隣接する家を連続して盗まずに得られる最大金額を int で返す

// 指定範囲（start〜end）に対して線形版House Robberを解くヘルパーメソッド
private int robRange(int[] nums, int start, int end) {
    // 0で初期化するのは、どの家も盗まない状態での金額が0だから
    int prev2 = 0, prev1 = 0;  // 2つ前と1つ前の最大金額を保持するローリング変数
    // 指定された範囲の先頭から末尾まで1つずつ走査する
    for (int i = start; i <= end; i++) {
        // prev1: 家iを盗まず、1つ前までの最大値を引き継ぐ選択肢
        // prev2 + nums[i]: 家iを盗み、2つ前までの最大値に現在の金額を加える選択肢
        int curr = Math.max(prev1,
            prev2 + nums[i]);
        // ローリング変数を1つ進める（次のイテレーションでは curr が prev1、prev1 が prev2 の役割を果たす）
        prev2 = prev1;
        prev1 = curr;
    }
    // prev1 には指定範囲全体を考慮した最大金額が格納されている
    return prev1;
}

public int rob(int[] nums) {
    int n = nums.length;
    if (n == 0) return 0;        // 家がなければ0を返す
    if (n == 1) return nums[0];  // 家が1つなら隣接の制約が発生しないため、その値がそのまま答え

    // 円形の制約を2つの線形問題に分解し、大きい方を返す
    // 最初と最後の家を同時に選ばないことが保証されるため、円形の制約を満たせる
    return Math.max(
        robRange(nums, 0, n - 2),   // 最初の家を含み最後を除く範囲（インデックス 0 から n-2）
        robRange(nums, 1, n - 1));  // 最初の家を除き最後を含む範囲（インデックス 1 から n-1）
}
```
