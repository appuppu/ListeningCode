# Finding the Longest Palindromic Substring — 文字列の中で最も長い回文部分文字列を見つける

## 問題の本質

文字列 `s` が与えられる。`s` の中から、前から読んでも後ろから読んでも同じになる**最長の部分文字列（回文）**を見つけて返す。同じ長さの回文が複数ある場合は、どれか1つを返せばよい。

## 核心のアイデア

回文は必ず「中心」を持つ。文字列の各位置を中心として左右に展開し、文字が一致する限り回文を広げれば、すべての回文を漏れなく発見できる。中心は「1文字（奇数長）」と「隣接する2文字の間（偶数長）」の2種類を試す必要がある。

## 思考プロセス

1. **回文は中心から対称に広がる構造を持つ**: 回文 `"racecar"` は中心の `e` から左右に `c→a→r` と対称に広がっている。この性質を利用すれば、中心を固定して左右に展開することで回文を検出できる
2. **中心の候補は2種類ある**: 奇数長の回文（例: `"aba"`）は1文字が中心になり、偶数長の回文（例: `"abba"`）は隣接する2文字の間が中心になる。すべての回文を漏れなく検出するには、両方の中心を試す必要がある
3. **展開の手順を定める**: 中心から左右にポインタ `left` と `right` を置き、`s.charAt(left) == s.charAt(right)` である限り `left` を左へ、`right` を右へ1つずつ広げる。文字が不一致になるか、文字列の端に到達したら展開を終了する
4. **展開結果から回文の長さを求める**: 展開が終了した時点で `left` と `right` は回文の範囲を1つずつ超えた位置にいる。そのため、回文の長さは `right - left - 1` で計算できる
5. **最長の回文の開始・終了位置を記録する**: 各中心から得られた回文の長さが、これまでの最長を超えた場合に、開始位置 `start` と終了位置 `end` を更新する。中心位置 `i` と回文の長さ `len` から、`start = i - (len - 1) / 2`、`end = i + len / 2` で計算できる
6. **最終的に部分文字列を返す**: すべての中心を試し終えた後、`s.substring(start, end + 1)` で最長回文部分文字列を切り出して返す

## 前提知識

### 回文（Palindrome）とは

前から読んでも後ろから読んでも同じ文字列のこと。`"aba"`、`"abba"`、`"racecar"` は回文である。1文字の文字列も回文である。

### 中心展開法（Expand Around Center）とは

回文の中心を固定し、左右に1文字ずつ広げながら回文かどうかを判定する手法。中心から外側に向かって文字を比較するため、回文の検出を効率的に行える。

```java
// left=right なら奇数長の回文（1文字中心）を検出する
// left=i, right=i+1 なら偶数長の回文（2文字中心）を検出する
expand(s, 2, 2);    // インデックス2を中心とした奇数長の回文を探す
expand(s, 2, 3);    // インデックス2と3の間を中心とした偶数長の回文を探す
```

### String.substring(int, int) とは

文字列から部分文字列を切り出すメソッド。第1引数は開始インデックス（含む）、第2引数は終了インデックス（含まない）。

```java
String s = "babad";
s.substring(0, 3);   // "bab" を返す（インデックス0, 1, 2の文字）
s.substring(1, 4);   // "aba" を返す（インデックス1, 2, 3の文字）
```

### String.charAt(int) とは

文字列の指定したインデックスにある文字を返すメソッド。

```java
String s = "babad";
s.charAt(0);   // 'b' を返す
s.charAt(2);   // 'b' を返す
```

## 計算量

| | 値 |
|---|---|
| Time | O(n²) — 各インデックスを中心として最大O(n)の展開を行い、中心はn個ある |
| Space | O(1) — ポインタと長さを記録する変数のみを使用し、追加のデータ構造は不要 |

## コード

```java
// 入力: 文字列 s
// 出力: s の中で最も長い回文部分文字列を String で返す

// 中心から左右に展開し、回文の長さを返すヘルパーメソッド
private int expand(String s, int left, int right) {
    // 左右の文字が一致し、かつ文字列の範囲内である限り展開を続ける
    while (left >= 0
            && right < s.length()
            && s.charAt(left)
            == s.charAt(right)) {
        left--;  // 左に1つ広げる
        right++; // 右に1つ広げる
    }
    // 展開終了時、leftとrightは回文の範囲を1つずつ超えた位置にいる
    // そのため回文の長さは right - left - 1 で求まる
    return right - left - 1;
}

public String longestPalindrome(String s) {
    // 最長回文の開始・終了インデックスを記録する変数
    // 初期値0は、最低でも1文字目自体が長さ1の回文であることに対応する
    int start = 0, end = 0;

    // 各インデックス i を回文の中心候補として走査する
    for (int i = 0; i < s.length(); i++) {
        // 奇数長の回文（1文字中心）を展開して長さを取得する
        int odd = expand(s, i, i);
        // 偶数長の回文（2文字中心）を展開して長さを取得する
        int even = expand(s, i, i + 1);
        // 奇数長と偶数長の大きい方を採用する
        int len = Math.max(odd, even);

        // 現在の最長回文の長さ (end - start + 1) を超えた場合、開始・終了位置を更新する
        if (len > end - start + 1) {
            // (len - 1) / 2 は中心から左側への距離
            start = i - (len - 1) / 2;
            // len / 2 は中心から右側への距離
            end = i + len / 2;
        }
    }
    // substringの第2引数は「含まない」仕様なので、end + 1 を指定して end の文字まで含める
    return s.substring(start, end + 1);
}
```
