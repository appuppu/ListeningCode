# Maximizing Robbery Loot Without Adjacent Houses — 隣接する家を避けて盗める金額の最大値を求める

## 問題の本質

整数配列 `nums` が与えられ、各要素は通り沿いの各家にある金額を表す。隣接する2つの家を両方盗むことはできないという制約のもとで、一晩に盗める**金額の最大値**を返す。家 `i` を盗んだら、家 `i-1` と家 `i+1` は盗めない。

## 核心のアイデア

各家について「盗む or 盗まない」の2択があり、盗む場合は2つ前までの最大値に現在の金額を加え、盗まない場合は1つ前の最大値をそのまま引き継ぐ。この判断に必要なのは直前2つの値だけなので、配列を持たず変数2つで計算できる。

## 思考プロセス

1. **各家で「盗む/盗まない」の最適判断が必要**: 家 `i` を盗むなら家 `i-1` は盗めないので、家 `i-2` までの最大値に `nums[i]` を加えた値が得られる。盗まないなら家 `i-1` までの最大値がそのまま残る。つまり各家での最大値は `max(家i-1までの最大値, 家i-2までの最大値 + nums[i])` で表せる
2. **漸化式が立つ**: `dp[i] = max(dp[i-1], dp[i-2] + nums[i])` という漸化式で、先頭から順に各家までの最大金額を計算できる。これは典型的な動的計画法の構造である
3. **必要な情報は直前2つだけ**: 漸化式を見ると、`dp[i]` の計算に使うのは `dp[i-1]` と `dp[i-2]` の2つだけである。配列全体を保持する必要はなく、変数2つ（`prev1` と `prev2`）で十分である
4. **変数の更新順序を考える**: `curr` を計算した後、次のイテレーションでは現在の `prev1` が新しい `prev2` になり、`curr` が新しい `prev1` になる。この順序で更新すれば値が上書きされない
5. **初期値の設定**: 走査開始前に `prev1 = 0`（1つ前の最大値）、`prev2 = 0`（2つ前の最大値）とする。家が0軒の場合は0、1軒目では `max(0, 0 + nums[0]) = nums[0]` となり正しく動作する
6. **最終的に返すもの**: 全ての家を走査し終えた後の `prev1` が、全体を通した最大金額である

## 前提知識

### 動的計画法（Dynamic Programming）とは

大きな問題を小さな部分問題に分割し、各部分問題の解を再利用して全体の解を構築する手法。重複する部分問題がある場合に、同じ計算を繰り返さずに済む。この問題では「家 `i` までの最大金額」が部分問題にあたる。

### Math.max とは

2つの値のうち大きい方を返すJavaの標準メソッド。条件分岐を1行で書ける。

```java
Math.max(5, 3);    // → 5（大きい方を返す）
Math.max(prev1, prev2 + num);  // prev1とprev2+numの大きい方を返す
```

### 拡張forループ（for-each）とは

配列の全要素を先頭から順に1つずつ取り出して処理するループ構文。インデックスを使わず要素に直接アクセスする。

```java
int[] nums = {2, 7, 9, 3};
for (int num : nums) {   // numsの各要素を順にnumに代入してループ
    System.out.println(num);  // 2, 7, 9, 3 が順に出力される
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 変数2つのみを使用し、入力サイズに依存しない |

## コード

```java
// 入力: 整数配列 nums（各家の金額）
// 出力: 隣接する家を盗まない制約のもとで盗める金額の最大値を int で返す
public int rob(int[] nums) {
    // prev2: 2つ前の家までの最大金額。走査開始前は家が存在しないので0
    int prev2 = 0;
    // prev1: 1つ前の家までの最大金額。同様に走査開始前は0
    int prev1 = 0;

    // 拡張forループで配列 nums を先頭から末尾まで1要素ずつ走査する
    for (int num : nums) {
        // 「現在の家を盗まない場合(prev1)」と「現在の家を盗む場合(prev2+num)」の大きい方を選ぶ
        // 現在の家を盗む場合に prev2 を使うのは、隣接する prev1 の家は盗めないため
        int curr = Math.max(prev1,
            prev2 + num);
        // 次のイテレーションに向けて変数をスライドさせる
        // 現在の prev1（1つ前の最大値）が、次のイテレーションでは2つ前の最大値になる
        prev2 = prev1;
        // 今計算した curr（現在の家までの最大値）が、次のイテレーションでは1つ前の最大値になる
        // 注意: この更新は prev2 = prev1 の後に行う。先に prev1 を更新すると prev2 に正しい値を代入できなくなる
        prev1 = curr;
    }
    // 全ての家を考慮した最大金額を返す。prev1 には最後の家まで考慮した最大金額が格納されている
    return prev1;
}
```
