# Finding the Fewest Coins to Make a Target Amount — 最小枚数のコインで目標金額を作る

## 問題の本質

コインの額面が入った配列 `coins` と目標金額 `amount` が与えられる。`coins` の中のコインを何枚でも使って合計が `amount` になる組み合わせのうち、**最小枚数**を返す。どう組み合わせても `amount` を作れない場合は `-1` を返す。

## 核心のアイデア

金額0から目標金額まで「各金額を作るのに必要な最小枚数」をボトムアップで計算すれば、金額 `i` の最小枚数は「`i` から各コインの額面を引いた金額の最小枚数 + 1」の中の最小値として求まる。

## 思考プロセス

1. **部分問題に分解できる**: 金額 `i` を作る最後の1枚がコイン `c` だとすると、残りの金額 `i - c` を作る最小枚数がわかっていれば、`dp[i - c] + 1` で金額 `i` の最小枚数が求まる。この構造は動的計画法に適している
2. **どのコインが最後の1枚かは事前にわからない**: 最後の1枚の候補はすべてのコイン額面である。そこで、すべてのコイン `c` について `dp[i - c] + 1` を計算し、その最小値を `dp[i]` とする。これが遷移式 `dp[i] = min(dp[i - c] + 1)` for each coin `c` である
3. **基底ケースを決める**: 金額0を作るのに必要なコインは0枚なので、`dp[0] = 0` とする。これがボトムアップ計算の出発点になる
4. **初期値に「到達不能」を表す値を設定する**: 各金額が作れるかどうかは事前にわからないので、`dp` 配列の全要素を `amount + 1`（ありえない大きな枚数）で初期化する。この値が更新されなかった金額は「作れない」ことを意味する
5. **金額1から順に埋めていく**: `dp[0]` を起点に、金額1, 2, ..., `amount` の順にテーブルを埋める。金額 `i` を計算する時点で、`i` より小さいすべての金額の最小枚数はすでに確定しているため、`dp[i - c]` を安全に参照できる
6. **最終的に返すもの**: `dp[amount]` が `amount + 1` のままなら目標金額は作れないので `-1` を返す。そうでなければ `dp[amount]` が最小枚数である

## 前提知識

### 動的計画法（Dynamic Programming）とは

大きな問題を小さな部分問題に分解し、各部分問題の解をテーブルに記録しながらボトムアップで解を構築する手法。同じ部分問題を重複して解くことを避けるため、計算効率が良い。

```java
// ボトムアップDPの基本パターン
int[] dp = new int[n + 1];     // テーブルを作成する
dp[0] = baseCase;              // 基底ケースを設定する
for (int i = 1; i <= n; i++) { // 小さい部分問題から順に解く
    dp[i] = /* dp[i-1] など過去の結果を使って計算する */;
}
return dp[n];                  // 最終的な答えを返す
```

### Arrays.fill とは

配列のすべての要素を指定した値で埋めるJavaの標準メソッド。DP配列の初期化によく使われる。

```java
int[] dp = new int[5];       // [0, 0, 0, 0, 0] が作られる
Arrays.fill(dp, 100);        // 全要素を100で埋める → [100, 100, 100, 100, 100]
```

### Math.min とは

2つの整数のうち小さい方を返すJavaの標準メソッド。複数の候補から最小値を選ぶときに使う。

```java
Math.min(3, 7);    // → 3
Math.min(dp[i], dp[i - coin] + 1);  // 現在の値と新しい候補のうち小さい方を選ぶ
```

## 計算量

| | 値 |
|---|---|
| Time | O(amount × n) — 金額ごとにn種類のコインを走査する（nはcoins配列の長さ） |
| Space | O(amount) — dp配列にamount+1個の要素を保存する |

## コード

```java
// 入力: コインの額面が入った整数配列 coins と目標金額の整数 amount
// 出力: 合計が amount になるコインの最小枚数を int で返す。作れない場合は -1 を返す
int coinChange(int[] coins, int amount) {
    // dp[i] = 金額iを作るのに必要な最小コイン枚数
    // インデックス0からamountまでの各金額に対応するため、サイズは amount + 1 になる
    int[] dp = new int[amount + 1];

    // 全要素を「到達不能」を表す番兵値で初期化する
    // コインの額面は最小でも1なので amount 枚を超えることはありえず、この値が残っていれば「作れない」と判定できる
    Arrays.fill(dp, amount + 1);

    // 基底ケース: 金額0を作るのに必要なコインは0枚。ボトムアップ計算の出発点
    dp[0] = 0;

    // 金額1からamountまで順にテーブルを埋める
    // 小さい金額から順に計算することで、dp[i - coin] がすでに確定していることを保証する
    for (int i = 1; i <= amount; i++) {
        // 各コインを「金額iを作る最後の1枚」の候補として、すべての額面から最適なものを探す
        for (int coin : coins) {
            // coin > i の場合はそのコインで金額iを作れないのでスキップする
            if (coin <= i)
                // dp[i - coin] + 1 は「金額 i - coin の最小枚数にコイン1枚を追加した枚数」
                // 現在の dp[i] と比較して小さい方を採用する
                dp[i] = Math.min(dp[i],
                    dp[i - coin] + 1);
        }
    }

    // 番兵値のままなら初期値から更新されなかった＝目標金額を作れないので -1 を返す
    return dp[amount] > amount
        ? -1 : dp[amount];
}
```
