# Counting All Palindromic Substrings — 文字列中の回文部分文字列の総数を数える

## 問題の本質

文字列 `s` が与えられる。`s` のすべての部分文字列のうち、回文（前から読んでも後ろから読んでも同じ文字列）であるものの**総数**を返す。1文字の部分文字列もすべて回文として数える。

## 核心のアイデア

すべての回文には「中心」が存在する。中心を固定して左右に拡張すれば、その中心から生まれる回文をすべて列挙できる。中心の候補は各文字（奇数長）と隣接する2文字の間（偶数長）の合計 2n-1 個しかないので、全探索が可能である。

## 思考プロセス

1. **回文の構造的性質に注目する**: すべての回文は中心に対して左右対称である。奇数長の回文は1文字を中心に持ち、偶数長の回文は隣接する2文字を中心に持つ。この性質を利用すれば、中心を起点に回文を効率的に発見できる
2. **中心から外側へ拡張する**: ある中心について、左右のポインタ `left` と `right` を設定し、`s.charAt(left) == s.charAt(right)` である限り外側へ拡張する。拡張が成功するたびに新しい回文が1つ見つかるので、カウントを1増やす
3. **奇数長と偶数長を分けて処理する**: 各インデックス `i` について、`expand(s, i, i)` で奇数長の回文を、`expand(s, i, i+1)` で偶数長の回文を数える。この2つの呼び出しで、`i` を中心とするすべての回文を網羅できる
4. **拡張の停止条件を定める**: `left` が0未満になるか、`right` が文字列長以上になるか、左右の文字が一致しなくなった時点で拡張を停止する。これにより範囲外アクセスを防ぎつつ、最大限の拡張を行う
5. **各中心の結果を合算する**: すべてのインデックスについて奇数長・偶数長の回文数を合計した値が、文字列全体の回文部分文字列の総数になる
6. **最終的に返すもの**: 全中心から得られた回文数の合計を整数 `result` として返す

## 前提知識

### 回文（Palindrome）とは

前から読んでも後ろから読んでも同じ文字列。`"aba"`、`"abba"`、`"a"` はすべて回文である。回文には奇数長（中心が1文字）と偶数長（中心が2文字の間）の2種類がある。

```
奇数長の例: "aba"  → 中心は 'b'
偶数長の例: "abba" → 中心は 'b' と 'b' の間
```

### 中心拡張法（Expand Around Center）とは

回文の中心を固定し、左右に1文字ずつ広げながら回文かどうかを判定する手法。中心から外側へ向かって文字が一致する限り拡張を続け、一致しなくなった時点で停止する。

```
文字列: "abacd"
中心 i=1 ('b') から拡張:
  left=1, right=1 → 'b'=='b' → 回文 "b" 発見、count=1
  left=0, right=2 → 'a'=='a' → 回文 "aba" 発見、count=2
  left=-1 → 範囲外なので停止
```

### String.charAt(int index) とは

文字列の指定されたインデックスにある文字を返すメソッド。インデックスは0から始まる。

```java
String s = "abc";
s.charAt(0);    // 'a' を返す
s.charAt(2);    // 'c' を返す
s.length();     // 文字列の長さを返す → 3
```

## 計算量

| | 値 |
|---|---|
| Time | O(n²) — 各中心（n個）について最大O(n)の拡張を行う |
| Space | O(1) — ポインタとカウンタのみを使用し、追加のデータ構造を使わない |

## コード

```java
// 入力: 文字列 s
// 出力: s の回文部分文字列の総数を整数で返す

// 指定された中心から左右に拡張し、見つかった回文の数を返す
// left と right が同じ値なら奇数長、隣接する値なら偶数長の回文を探索する
int expand(String s, int left, int right) {
    int count = 0;
    // 3条件すべてを満たす間拡張: 左端が範囲内、右端が範囲内、左右の文字が一致
    while (left >= 0 && right < s.length()
            && s.charAt(left) == s.charAt(right)) {
        count++;   // s.substring(left, right+1) が新たな回文なのでカウント
        left--;    // 左に1つ拡張
        right++;   // 右に1つ拡張
    }
    // この中心から見つかった回文の総数を返す
    return count;
}

int countSubstrings(String s) {
    // すべての中心から見つかった回文の数を累積する変数
    int result = 0;

    // 各インデックスを中心候補として走査する
    for (int i = 0; i < s.length(); i++) {
        // 奇数長の回文: left=i, right=i で1文字の中心から拡張を開始
        result += expand(s, i, i);
        // 偶数長の回文: left=i, right=i+1 で隣接する2文字の中心から拡張を開始
        result += expand(s, i, i + 1);
    }
    // 全中心から得られた回文数の合計を返す
    return result;
}
```
