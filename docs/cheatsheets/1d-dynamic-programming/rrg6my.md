# Counting Ways to Decode a Numeric String — 数字の文字列をアルファベットに変換する方法の総数を求める

## 問題の本質

数字のみで構成された文字列 `s` が与えられる。A=1, B=2, ..., Z=26 という対応関係に基づいて、文字列をアルファベット列にデコードする方法が何通りあるかを返す。例えば "226" は "BZ"(2,26)、"VF"(22,6)、"BBF"(2,2,6) の3通りにデコードできる。

## 核心のアイデア

各位置でのデコード方法数は「1文字デコード（1桁）した場合の残りの方法数」と「2文字デコード（2桁）した場合の残りの方法数」の合計で求まる。この依存関係は直前2つの結果だけに限られるため、変数2つで十分である。

## 思考プロセス

1. **各位置での選択肢は最大2つ**: 位置 `i` の数字を見るとき、1桁（1〜9）として1文字にデコードするか、2桁（10〜26）として1文字にデコードするかの最大2択がある。この選択が再帰的に発生するため、各位置でのデコード方法数を体系的に求める必要がある
2. **'0' は単独でデコードできない**: '0' に対応するアルファベットは存在しない。位置 `i` の数字が '0' の場合、その位置から始まる1桁デコードは不可能なので、方法数は0になる。'0' は前の数字と組み合わせて10または20としてのみデコードできる
3. **DPの漸化式を立てる**: `dp[i]` を「位置 `i` から末尾までのデコード方法数」と定義する。位置 `i` の数字が '0' でなければ、1桁デコードした場合の残り `dp[i+1]` を加算する。さらに位置 `i` と `i+1` の2桁が10〜26の範囲なら、2桁デコードした場合の残り `dp[i+2]` も加算する。つまり `dp[i] = dp[i+1] + dp[i+2]`（条件付き）
4. **依存先は直後の2つだけ**: `dp[i]` は `dp[i+1]` と `dp[i+2]` にのみ依存する。そのため配列全体を保持する必要はなく、変数2つ（`next1` = `dp[i+1]`、`next2` = `dp[i+2]`）だけで計算できる。これによりSpace O(1)を実現する
5. **末尾から先頭へ走査する**: `dp[i]` は `dp[i+1]` と `dp[i+2]` に依存するため、末尾側が先に確定している必要がある。そこで文字列の末尾から先頭へ向かってループし、各位置の方法数を計算する
6. **最終的に返すもの**: ループ完了後、`next1` には `dp[0]`（文字列全体のデコード方法数）が格納されている。この値を返す

## 前提知識

### 動的計画法（DP）とは

大きな問題を小さな部分問題に分割し、部分問題の結果を再利用して全体の答えを求める手法。同じ部分問題を何度も再計算することを避けるため、一度計算した結果を保存（メモ化）または順番に計算（ボトムアップ）する。

```java
// ボトムアップDPの典型パターン：フィボナッチ数列
int prev2 = 0, prev1 = 1;
for (int i = 2; i <= n; i++) {
    int current = prev1 + prev2;  // 直前2つの結果だけで現在の値を計算する
    prev2 = prev1;                // 変数をスライドさせて次のイテレーションに備える
    prev1 = current;
}
// prev1 に最終結果が入っている
```

### Integer.parseInt とは

文字列を整数に変換するメソッド。部分文字列を数値として評価するために使用する。

```java
Integer.parseInt("26");          // 文字列"26"を整数26に変換する → 26
Integer.parseInt("09");          // 文字列"09"を整数9に変換する → 9
```

### String.substring とは

文字列から指定範囲の部分文字列を取得するメソッド。引数は開始インデックス（含む）と終了インデックス（含まない）。

```java
String s = "226";
s.substring(0, 2);   // インデックス0から1までの部分文字列を返す → "22"
s.substring(1, 3);   // インデックス1から2までの部分文字列を返す → "26"
```

### String.charAt とは

文字列の指定位置にある1文字を返すメソッド。char型を返すため、文字 '0' との比較で数字の判定ができる。

```java
String s = "206";
s.charAt(0);          // インデックス0の文字を返す → '2'
s.charAt(1);          // インデックス1の文字を返す → '0'
s.charAt(1) == '0';   // 文字が'0'であるかを判定する → true
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 文字列を末尾から先頭へ1回走査するだけで済む |
| Space | O(1) — 変数2つ（next1, next2）のみで計算でき、配列を使用しない |

## コード

```java
// 入力: 数字のみで構成された文字列 s
// 出力: 文字列 s をアルファベット列にデコードする方法の総数を int で返す
public int numDecodings(String s) {
    // next1 = 1つ右の位置からの方法数（dp[i+1]）、next2 = 2つ右の位置からの方法数（dp[i+2]）
    // 文字列の末尾より右は「空文字列をデコードする方法 = 1通り」と定義するため、初期値は1
    int next1 = 1, next2 = 1;

    // dp[i]はdp[i+1]とdp[i+2]に依存するため、右側を先に確定させるよう末尾から先頭へ走査する
    for (int i = s.length() - 1; i >= 0; i--) {
        int current;

        if (s.charAt(i) == '0') {
            // '0'は単独でどのアルファベットにも対応しないため、この位置から始まるデコード方法は0通り
            // '0'は前の数字と組み合わせて10または20としてのみデコードできる
            current = 0;
        } else {
            // 1桁デコード: 位置iの数字（1〜9）を1文字として、残りi+1以降はnext1通り
            current = next1;

            // 2桁デコードが可能か判定する（i+1が文字列の範囲内であれば2桁を取得できる）
            if (i + 1 < s.length()) {
                // s.substring(i, i+2)で2桁の部分文字列を取得し、整数に変換する
                int two = Integer.parseInt(
                    s.substring(i, i + 2));
                // 2桁が10〜26の範囲なら、2桁を1文字としてデコードし残りi+2以降をnext2通りで加算
                if (two >= 10 && two <= 26)
                    current += next2;
            }
        }

        // 変数を1つ左にスライド: 現在のcurrentが次のイテレーションではnext1（1つ右）になる
        next2 = next1;
        next1 = current;
    }

    // ループ完了後、next1には最後に計算したcurrent（= dp[0]）が格納されている
    // これが文字列全体のデコード方法の総数
    return next1;
}
```
