# Partitioning an Array Into Two Equal Sum Subsets — 配列を合計が等しい2つの部分集合に分割できるか判定する

## 問題の本質

整数の配列 `nums` が与えられる。この配列を2つの部分集合に分割し、それぞれの部分集合の要素の合計が等しくなるようにできるかを `boolean` で返す。要素は必ずどちらか一方の部分集合に属し、重複して使うことはできない。

## 核心のアイデア

配列の合計が奇数なら即座にfalseと判定できる。合計が偶数なら、合計の半分 `target` をちょうど作れる部分集合が存在するかという「部分和問題」に帰着できる。1次元のboolean型DP配列を使い、各要素を順に処理しながら到達可能な合計値を記録していけば、`target` に到達できるかをO(n × target)で判定できる。

## 思考プロセス

1. **2等分の条件を考える**: 配列全体の合計が `sum` のとき、2つの部分集合の合計がそれぞれ等しくなるためには、各部分集合の合計が `sum / 2` でなければならない。`sum` が奇数なら整数で2等分できないので、即座にfalseを返せる
2. **問題を「部分和問題」に変換する**: 片方の部分集合の合計が `target = sum / 2` になれば、もう片方も自動的に `target` になる。つまり「配列の要素から合計が `target` になる部分集合が存在するか」という部分和問題に帰着できる
3. **DPで到達可能な合計値を管理する**: boolean型の配列 `dp` を用意し、`dp[j]` は「これまでに処理した要素から合計 `j` を作れるか」を表す。初期状態として `dp[0] = true`（何も選ばなければ合計0）とする
4. **各要素で到達可能な合計値を更新する**: 配列の各要素 `num` について、既に到達可能な合計値 `j` に `num` を加えた `j + num` も到達可能になる。これは `dp[j]` がtrueなら `dp[j + num]` もtrueにする操作である
5. **逆順に走査して重複使用を防ぐ**: 内側のループを `target` から `num` まで逆順に走査する。順方向に走査すると、同じ要素を複数回使った結果で `dp` が更新されてしまう。逆順なら各要素は高々1回しか使われない
6. **最終的に `dp[target]` を返す**: すべての要素を処理した後、`dp[target]` がtrueなら合計 `target` の部分集合が存在するのでtrueを返し、falseならそのような部分集合は存在しない

## 前提知識

### 部分和問題（Subset Sum Problem）とは

与えられた整数の集合から、いくつかの要素を選んで合計がちょうど目標値になるかを判定する問題。DP（動的計画法）で効率的に解ける代表的な問題である。

### boolean型の1次元DP配列とは

`dp[j]` が「合計 `j` を作ることが可能か」をtrue/falseで表す配列。要素を1つずつ処理するたびに、到達可能な合計値の集合が広がっていく。

```java
boolean[] dp = new boolean[target + 1];  // サイズ target+1 の配列を作成（初期値は全てfalse）
dp[0] = true;                            // 何も選ばない場合、合計0は常に到達可能
dp[j - num] == true                      // 合計 j-num が作れるなら、numを加えて合計 j も作れる
```

### DP配列を逆順に更新する理由

順方向（小さい `j` から大きい `j`）に更新すると、同じ要素 `num` を複数回使った結果が伝播する。逆方向（大きい `j` から小さい `j`）に更新すれば、各要素は1回だけ使われることが保証される。

```java
// 逆順ループ: j = target から num まで1ずつ減少
for (int j = target; j >= num; j--) {
    if (dp[j - num]) dp[j] = true;
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n × target) — n個の要素それぞれについて、最大targetまでのDP配列を走査する |
| Space | O(target) — サイズ target+1 のboolean型DP配列を1つ使用する |

## コード

```java
// 入力: 整数配列 nums
// 出力: 配列を合計が等しい2つの部分集合に分割できるかを boolean で返す
boolean canPartition(int[] nums) {
    // 配列の全要素の合計を計算し、2等分が可能かを判断するための基準値を求める
    int sum = 0;
    for (int n : nums) sum += n;

    // 合計が奇数なら整数で2等分できないのでfalseを返す
    if (sum % 2 != 0) return false;

    // 片方の部分集合が達成すべき目標合計値。もう片方も自動的にtargetになる
    int target = sum / 2;

    // dp[j] = これまでに処理した要素から合計jを作れるか（部分和問題のDP配列）
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;  // 何も選ばなければ合計0は常に到達可能

    // 配列の各要素を先頭から末尾まで1つずつ処理し、到達可能な合計値の集合を更新する
    for (int num : nums) {
        // 逆順に走査して同じ要素の重複使用を防ぐ（順方向だとnumを複数回加算した結果が伝播する）
        for (int j = target; j >= num; j--) {
            // 合計 j-num が作れるなら、numを加えて合計 j も作れるのでtrueに更新する
            if (dp[j - num]) dp[j] = true;
        }
    }

    // dp[target]がtrueなら合計targetの部分集合が存在するので2等分可能
    return dp[target];
}
```
