# Finding the Duplicate in an Array of N Plus One Integers — N+1個の整数配列から重複する1つの数を見つける

## 問題の本質

長さ n+1 の整数配列 `nums` が与えられる。各要素は 1 から n の範囲内であり、必ず1つだけ重複する数が存在する。配列を変更せず、かつ定数の追加空間のみを使って、その重複する数を見つけて返す。

## 核心のアイデア

配列の各インデックス `i` から `nums[i]` へ移動する関係を「リンクリスト」と見なすと、重複する数が存在する箇所でリンクが合流し、サイクル（循環）が発生する。Floyd's Cycle Detection（亀とウサギのアルゴリズム）を使えば、そのサイクルの入口＝重複する数をO(1)空間で特定できる。

## 思考プロセス

1. **配列を暗黙的なリンクリストとして捉える**: インデックス `i` にある値 `nums[i]` を「次のノードへのポインタ」と見なす。インデックス0から出発して `nums[0]` → `nums[nums[0]]` → … と辿ると、リンクリストの走査と同じ動きになる。値の範囲が1〜nなのでインデックス0に戻ることはなく、常に有効なインデックスを指す
2. **重複がサイクルを生む理由を理解する**: 2つの異なるインデックスが同じ値を持つとき、その値のインデックスに向かう矢印が2本存在する。これはリンクリストにおいて2つのノードが同じノードを指す状態であり、合流点からサイクルが始まる。サイクルの入口がまさに重複する数である
3. **サイクルの存在を検出する**: slow ポインタは1ステップずつ（`slow = nums[slow]`）、fast ポインタは2ステップずつ（`fast = nums[nums[fast]]`）進める。サイクルが存在すれば、slow と fast は必ずサイクル内のどこかで出会う
4. **サイクルの入口を特定する**: 出会った後、slow をスタート地点（`nums[0]`）に戻し、fast はそのままの位置に留める。両方を1ステップずつ進めると、両者はサイクルの入口で再び出会う。この入口のインデックスに対応する値が重複する数である
5. **なぜ入口で出会うのか**: スタートからサイクル入口までの距離と、出会い地点からサイクル入口までの距離が等しいことが数学的に証明されている。そのため、両者を同じ速度で進めれば入口で一致する

## 前提知識

### 暗黙的リンクリスト（Implicit Linked List）とは

実際にノードオブジェクトを作らなくても、配列の値を「次のインデックスへのポインタ」と解釈することで、リンクリストと同じ構造を表現できる。インデックス `i` のノードの「次のノード」は、インデックス `nums[i]` のノードである。

```java
// 配列 nums = [1, 3, 4, 2, 2] の場合のリンクリスト走査
int current = nums[0];       // インデックス0の値 → 1（次はインデックス1へ）
current = nums[current];     // インデックス1の値 → 3（次はインデックス3へ）
current = nums[current];     // インデックス3の値 → 2（次はインデックス2へ）
current = nums[current];     // インデックス2の値 → 4（次はインデックス4へ）
current = nums[current];     // インデックス4の値 → 2（インデックス2に戻る → サイクル）
```

### Floyd's Cycle Detection（フロイドのサイクル検出）とは

リンクリスト内のサイクルを検出し、その入口を特定するアルゴリズム。2つのポインタ（slow: 1歩ずつ、fast: 2歩ずつ）を使う。サイクルがあれば両者は必ず出会い、その後の手順でサイクルの入口を特定できる。

```java
// フェーズ1: サイクル内での出会い
slow = nums[slow];           // slowは1ステップ進む
fast = nums[nums[fast]];     // fastは2ステップ進む

// フェーズ2: サイクル入口の特定
slow = nums[slow];           // 両方とも1ステップずつ進む
fast = nums[fast];           // 出会った地点がサイクルの入口
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 各ポインタはリンクリストの走査を最大2周分行うだけで済む |
| Space | O(1) — slow と fast の2つの変数のみを使用する |

## コード

```java
// 入力: 長さ n+1 の整数配列 nums（各要素は 1 以上 n 以下、重複は1つだけ）
// 出力: 重複する数を int で返す
public int findDuplicate(int[] nums) {
    // slowとfastの両方をリンクリストの先頭（nums[0]）で初期化する
    // インデックス0自体は値の範囲（1〜n）に含まれないため、サイクルの一部にはならず安全なスタート地点
    int slow = nums[0];
    int fast = nums[0];

    // フェーズ1: slowは1歩、fastは2歩ずつ進め、サイクル内で出会うまで繰り返す
    // do-whileを使う理由: 初期値が同じなので、最初の比較をスキップする必要がある
    do {
        slow = nums[slow];           // slowを1ステップ進める
        fast = nums[nums[fast]];     // fastを2ステップ進める（サイクルがあれば必ず追いつく）
    } while (slow != fast);

    // フェーズ2: slowをスタート地点に戻し、両方1歩ずつ進める
    // スタートから入口までの距離 = 出会い地点から入口までの距離 という性質を利用する
    slow = nums[0];
    while (slow != fast) {
        slow = nums[slow];           // 両方とも1ステップずつ進める
        fast = nums[fast];           // サイクルの入口で必ず一致する
    }

    // サイクルの入口 = 2つの異なるインデックスから指されている数 = 重複する数を返す
    return slow;
}
```
