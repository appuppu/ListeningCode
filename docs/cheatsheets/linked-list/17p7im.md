# Detecting a Cycle in a Linked List — 連結リストにサイクルが存在するかを判定する

## 問題の本質

単方向連結リストの先頭ノード `head` が与えられる。リスト内のいずれかのノードの `next` ポインタが、以前に訪問済みのノードを指している（サイクルが存在する）場合は `true` を返し、サイクルが存在しない場合は `false` を返す。

## 核心のアイデア

速度の異なる2つのポインタを同時に走らせると、サイクルがあれば必ず追いつき合流する。サイクルがなければ速いポインタが先に終端に到達する。この性質により、追加のデータ構造なしでサイクルを検出できる。

## 思考プロセス

1. **サイクルの本質を考える**: サイクルがあるリストを走査すると、終端（null）に到達せず永遠にループし続ける。逆にサイクルがなければ、必ずnullに到達して走査が終了する
2. **速度差のあるポインタを使う**: 1ステップずつ進むポインタ（slow）と2ステップずつ進むポインタ（fast）を用意する。サイクル内では、fastがslowに対して毎ステップ1ノードずつ距離を縮めるため、必ず合流する
3. **合流がサイクルの証拠になる理由**: サイクルがなければfastは先にnullに到達するので、slowとfastが同じノードを指すことは起こりえない。合流が起きた＝サイクルが存在する
4. **終了条件を定める**: fastまたはfast.nextがnullになったら、リストに終端が存在するのでサイクルはない。slowとfastが同じノードを指したら、サイクルが存在する
5. **初期位置を設定する**: slowをhead、fastをhead.nextに配置する。こうすることで、whileループの条件 `slow != fast` が最初から成立し、ループ内で走査を開始できる
6. **最終的に返すもの**: slowとfastが合流したら `true`、fastがnullに到達したら `false` を返す

## 前提知識

### ListNode（連結リストのノード）とは

連結リストを構成する個々の要素。各ノードは「値」と「次のノードへのポインタ」を持つ。最後のノードのnextはnullを指す（サイクルがない場合）。

```java
class ListNode {
    int val;            // ノードが保持する値
    ListNode next;      // 次のノードへの参照（なければnull）
}

ListNode node = head;       // 先頭ノードを取得する
node.next;                  // 次のノードを取得する
node.next.next;             // 2つ先のノードを取得する
```

### Floyd's Tortoise and Hare（フロイドの循環検出法）とは

速度の異なる2つのポインタを使ってサイクルを検出するアルゴリズム。slowポインタは1ステップずつ、fastポインタは2ステップずつ進む。サイクル内でfastはslowに毎ステップ1ノードずつ近づくため、サイクルが存在すれば有限ステップで必ず合流する。

```java
ListNode slow = head;       // 1ステップずつ進むポインタ
ListNode fast = head.next;  // 2ステップずつ進むポインタ
slow = slow.next;           // slowを1つ進める
fast = fast.next.next;      // fastを2つ進める
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — サイクルがない場合はfastがn/2ステップで終端に到達し、サイクルがある場合もサイクル長以内で合流する |
| Space | O(1) — 2つのポインタ変数のみを使用し、追加のデータ構造を必要としない |

## コード

```java
// 入力: 単方向連結リストの先頭ノード head
// 出力: サイクルが存在すれば true、存在しなければ false を返す
public boolean hasCycle(ListNode head) {
    // ノードが0個または1個ならサイクルは存在しえない。falseを返して終了する
    if (head == null || head.next == null) {
        return false;
    }

    // slowをheadに、fastをhead.nextに配置する
    // fastを1つ先に置くことで、whileの条件 slow != fast が初回から成立しループに入れる
    ListNode slow = head;
    ListNode fast = head.next;

    // slowとfastが合流するまでループを繰り返す（合流したら終了）
    while (slow != fast) {
        // fastがnull、またはfast.nextがnullならリストに終端が存在するのでサイクルなし
        if (fast == null || fast.next == null) {
            return false;
        }
        // slowを1ステップ、fastを2ステップ進める
        // 速度差により、サイクル内でfastはslowに毎ステップ1ノードずつ近づく
        slow = slow.next;
        fast = fast.next.next;
    }

    // whileの条件 slow != fast が偽になった＝slowとfastが合流したのでサイクルが存在する
    return true;
}
```
