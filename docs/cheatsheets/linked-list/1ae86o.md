# Reordering a Linked List by Interleaving Ends — 連結リストの両端を交互に組み替える

## 問題の本質

単方向連結リスト L0 → L1 → … → Ln-1 → Ln が与えられる。このリストを L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → … の順に**その場で（in-place）**並べ替える。ノードの値を変更せず、ノードのリンク（next ポインタ）のみを操作して実現する。

## 核心のアイデア

リストの後半を逆順にすれば、「前半の先頭から」と「後半の先頭（元の末尾）から」を交互につなぐだけで目的の順序になる。後半を逆順にするために、まずリストの中間点を見つけて前半と後半に分割する。

## 思考プロセス

1. **並べ替え後の構造を観察する**: L0 → Ln → L1 → Ln-1 → … という順序は、リストの「先頭」と「末尾」から交互に要素を取り出した結果である。つまり、先頭側と末尾側の2つの列を交互にマージすればよい
2. **末尾から要素を取り出すには逆順が必要**: 単方向連結リストでは末尾へのアクセスに O(n) かかる。しかし、リストの後半を逆転させれば、後半の先頭が元の末尾になり、先頭から順にたどるだけで末尾側の要素を取得できる
3. **リストの中間点を見つける**: 後半を逆転させるためには、まずリストをどこで分割するか決める必要がある。slow/fast ポインタ（亀とウサギ）を使えば、1回の走査で中間点が見つかる。slow は1歩ずつ、fast は2歩ずつ進み、fast がリスト末尾に到達した時点で slow が中間点を指している
4. **後半を逆転させる**: 中間点の次のノードから始めて、各ノードの next ポインタを前のノードに向け直すことで、後半リストを逆順にする。prev 変数で直前のノードを追跡し、ループ完了後の prev が逆転後の先頭になる
5. **前半と逆転した後半を交互にマージする**: 前半リストと後半リストをそれぞれ先頭から走査し、前半のノードの次に後半のノードを挿入する。各ステップで next ポインタを付け替えるため、元のリンクを一時変数に退避してから書き換える
6. **後半が短いか同じ長さである**: 奇数長のリストでは前半が1つ長くなるため、マージのループ条件は `second != null` とする。後半のノードがなくなった時点でマージは完了する

## 前提知識

### slow/fast ポインタ（亀とウサギ法）とは

連結リストの中間点を1回の走査で見つけるテクニック。slow は1ノードずつ、fast は2ノードずつ進む。fast がリスト末尾に到達した時点で、slow はリストの中間点を指している。

```java
ListNode slow = head, fast = head;
while (fast.next != null && fast.next.next != null) {
    slow = slow.next;        // slowは1歩進む
    fast = fast.next.next;   // fastは2歩進む
}
// ループ終了時、slowがリストの中間ノードを指す
```

### 連結リストの逆転とは

各ノードの next ポインタを、次のノードではなく前のノードに向け直す操作。prev（直前のノード）を追跡しながら1ノードずつ進み、リンクの向きを反転させる。

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode nxt = curr.next;  // 次のノードを退避する
    curr.next = prev;          // リンクを前のノードに向ける
    prev = curr;               // prevを現在のノードに更新する
    curr = nxt;                // 次のノードに進む
}
// ループ終了時、prevが逆転後のリストの先頭を指す
```

### 2つのリストの交互マージとは

2つのリストの要素を交互に1つずつ取り出して、1つのリストにつなげる操作。各ステップで next ポインタを付け替えるため、元のリンクを一時変数に退避してから書き換える。

```java
ListNode a = list1, b = list2;
while (b != null) {
    ListNode tmpA = a.next;   // aの元の次を退避する
    ListNode tmpB = b.next;   // bの元の次を退避する
    a.next = b;               // aの次にbを挿入する
    b.next = tmpA;            // bの次にaの元の次をつなぐ
    a = tmpA;                 // aを次の位置に進める
    b = tmpB;                 // bを次の位置に進める
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 中間点の探索、後半の逆転、マージの各ステップがそれぞれ O(n) |
| Space | O(1) — ポインタ変数のみを使用し、追加のデータ構造を作成しない |

## コード

```java
// 入力: 単方向連結リストの先頭ノード head
// 出力: なし（リストをその場で並べ替える。戻り値は void）
void reorderList(ListNode head) {
    // 空のリストには並べ替えが不要
    if (head == null) return;

    // ステップ1: slow/fastポインタでリストの中間点を見つける
    // fastはslowの2倍の速度で進むため、fastが末尾に到達した時点でslowが中間ノードを指す
    ListNode slow = head, fast = head;
    while (fast.next != null
            && fast.next.next != null) {
        slow = slow.next;          // slowは1歩進む
        fast = fast.next.next;     // fastは2歩進む
    }

    // ステップ2: 後半リストを切り離して逆転させる
    ListNode second = slow.next;   // secondは後半リストの先頭ノード
    slow.next = null;              // 前半リストの末尾を切断し、前半と後半の2つに分割する
    ListNode prev = null;
    while (second != null) {
        ListNode nxt = second.next;  // 次のノードを退避する
        second.next = prev;          // リンクを前のノードに向ける
        prev = second;               // prevを現在のノードに更新する
        second = nxt;                // 次のノードに進む
    }
    // ループ終了時、prevが逆転後の後半リストの先頭（元のリスト末尾）を指す

    // ステップ3: 前半と逆転した後半を交互にマージする
    ListNode first = head;         // 前半リストの先頭
    second = prev;                 // 逆転後の後半リストの先頭
    // 奇数長のリストでは前半が1つ長くなるため、後半(second)がなくなったら終了
    while (second != null) {
        ListNode tmp1 = first.next;   // 前半の次のノードを退避する（退避しないとnext書き換えで元のリンク先が失われる）
        ListNode tmp2 = second.next;  // 後半の次のノードを退避する
        first.next = second;          // 前半の次に後半のノードを挿入する
        second.next = tmp1;           // 後半のノードの次に前半の続きをつなぐ
        first = tmp1;                 // 前半のポインタを次の位置に進める
        second = tmp2;                // 後半のポインタを次の位置に進める
    }
}
```
