# Merging Two Sorted Linked Lists — 2つのソート済み連結リストを1つにマージする

## 問題の本質

2つのソート済み連結リスト `list1` と `list2` が与えられる。これらを1つのソート済み連結リストにマージし、マージ後のリストの**先頭ノード**を返す。

## 核心のアイデア

2つのリストの先頭ノードを比較し、小さい方を選んでマージ結果の先頭とする。残りの部分は「小さい方の次のノード」と「もう一方のリスト」をマージした結果であり、これは元の問題と同じ構造なので再帰で解ける。

## 思考プロセス

1. **マージの各ステップでやることは同じ**: 2つのリストの先頭ノードを比較し、小さい方を選ぶ。この操作はリストが空になるまで繰り返される。毎回同じ判断をするので、再帰で表現できる
2. **ベースケースを考える**: 一方のリストが空（null）なら、もう一方のリストをそのまま返せばよい。両方とも空なら null を返す（片方が null のケースに含まれる）
3. **再帰ステップを考える**: `list1.val <= list2.val` なら `list1` が先頭になる。`list1.next` には「`list1` の残り」と「`list2` 全体」をマージした結果を接続する。逆の場合は `list2` を先頭にして同様に処理する
4. **各再帰呼び出しで問題サイズが1つ減る**: 毎回どちらかのリストから1ノード消費するので、合計 n 回の再帰で全ノードが処理される
5. **最終的に返すもの**: 各再帰呼び出しは選んだノード（`list1` または `list2`）を返す。最初の呼び出しが返すノードがマージ後のリストの先頭になる

## 前提知識

### ListNode（連結リストのノード）とは

連結リストの各要素を表すクラス。`val` フィールドに値を、`next` フィールドに次のノードへの参照を持つ。`next` が null のノードがリストの末尾である。

```java
class ListNode {
    int val;          // ノードが保持する値
    ListNode next;    // 次のノードへの参照（末尾なら null）

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### 再帰（Recursion）とは

関数が自分自身を呼び出すことで問題を解く手法。大きな問題を同じ構造の小さな問題に分解し、ベースケース（これ以上分解できない最小の問題）に到達したら結果を返す。呼び出しのたびにコールスタックにフレームが積まれるため、再帰の深さ分のスペースを消費する。

```java
// 例: 階乗の計算
int factorial(int n) {
    if (n <= 1) return 1;           // ベースケース: これ以上分解しない
    return n * factorial(n - 1);    // 再帰ステップ: 問題サイズを1つ減らして自分自身を呼ぶ
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 2つのリストの合計ノード数 n 回の再帰呼び出しで全ノードを処理する |
| Space | O(n) — 再帰呼び出しのたびにコールスタックにフレームが積まれ、最大 n 段の深さになる |

## コード

```java
// 入力: 2つのソート済み連結リストの先頭ノード list1 と list2
// 出力: マージ後のソート済み連結リストの先頭ノードを ListNode として返す
ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    // ベースケース: list1が空なら、残りのlist2をそのまま返す（list1が空なので list2 がそのままマージ結果になる）
    if (list1 == null) return list2;
    // ベースケース: list2が空なら、残りのlist1をそのまま返す（list2が空なので list1 がそのままマージ結果になる）
    if (list2 == null) return list1;

    // list1の先頭とlist2の先頭を比較し、マージ結果の先頭にどちらのノードを置くかを決定する
    if (list1.val <= list2.val) {
        // list1を先頭に選び、list1の残り(list1.next)とlist2全体をマージした結果をlist1の次に接続する
        list1.next = mergeTwoLists(list1.next, list2);
        return list1; // list1がマージ結果の先頭ノードになる
    } else {
        // list2を先頭に選び、list1全体とlist2の残り(list2.next)をマージした結果をlist2の次に接続する
        list2.next = mergeTwoLists(list1, list2.next);
        return list2; // list2がマージ結果の先頭ノードになる
    }
}
```
