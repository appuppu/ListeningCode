# Reversing a Linked List — 単方向連結リストを逆順にする

## 問題の本質

単方向連結リスト（singly linked list）の先頭ノード `head` が与えられる。リスト内のすべてのリンク（ポインタ）の向きを反転させ、元の末尾ノードが新しい先頭になるようにして、その新しい先頭ノードを返す。

## 核心のアイデア

各ノードの `next` ポインタを「次のノード」から「前のノード」に付け替えれば、リスト全体が逆順になる。3つのポインタ（prev, curr, next）を使って、リンクを1本ずつ安全に付け替えながら1回走査するだけで完了する。

## 思考プロセス

1. **逆順とはリンクの向きを反転させること**: 連結リストの順序はノードの `next` ポインタが決めている。すべてのノードの `next` を「次のノード」から「前のノード」に変更すれば、リスト全体が逆順になる
2. **リンクを付け替えると次のノードへの参照が失われる**: `curr.next = prev` と書き換えた瞬間、元の次のノードへの参照が消える。そのため、書き換える前に `curr.next` を別の変数 `next` に退避しておく必要がある
3. **3つのポインタで状態を管理する**: `prev`（付け替え先となる前のノード）、`curr`（現在処理中のノード）、`next`（元の次のノードの退避先）の3つがあれば、リンクの付け替えと走査を同時に行える
4. **初期状態を決める**: 逆順後の末尾ノード（元の先頭）の `next` は `null` になるべきなので、`prev` の初期値は `null` にする。`curr` の初期値は `head`（先頭ノード）にする
5. **ループの終了条件と戻り値**: `curr` が `null` になったとき、すべてのノードの処理が完了している。このとき `prev` は最後に処理したノード（元の末尾ノード）を指しているので、`prev` を新しい先頭として返す

## 前提知識

### ListNode（連結リストのノード）とは

連結リストを構成する要素。各ノードは「値（val）」と「次のノードへのポインタ（next）」を持つ。最後のノードの `next` は `null` である。

```java
class ListNode {
    int val;          // ノードが保持する値
    ListNode next;    // 次のノードへの参照（末尾なら null）

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### ポインタの付け替えとは

ノードの `next` フィールドに別のノードを代入することで、リンクの向きを変えること。

```java
// 元の状態: A → B → C
// A.next は B を指している

A.next = null;   // A → null（A と B のリンクが切れる）
B.next = A;      // B → A（B から A への逆向きリンクができる）
// 結果: C → null, B → A → null
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — リストを1回走査するだけで済む |
| Space | O(1) — 3つのポインタ変数のみを使用し、追加のデータ構造は不要 |

## コード

```java
// 入力: 単方向連結リストの先頭ノード head
// 出力: 逆順にしたリストの新しい先頭ノード（ListNode）を返す
ListNode reverseList(ListNode head) {
    // prev: リンクの付け替え先（逆順後の「前のノード」）
    // 最初のノード（元の先頭）は逆順後に末尾になるので、その next は null であるべき。よって初期値は null
    ListNode prev = null;
    // curr: これからリンクを付け替えるノード。先頭ノードから処理を開始する
    ListNode curr = head;

    // curr が null になったとき、すべてのノードの処理が完了している
    while (curr != null) {
        // 元の次のノードを退避する（次のステップで curr.next を書き換えるため、参照を失わないように保存）
        ListNode next = curr.next;

        // リンクを反転させる：次のノードではなく前のノードを指すようにする。これが反転操作の本体
        curr.next = prev;

        // prev を現在のノードに進める（次のイテレーションで、次のノードのリンクの付け替え先として使う）
        prev = curr;
        // curr を退避しておいた元の次のノードに進める（これによりリストの走査が続行される）
        curr = next;
    }

    // ループの最後のイテレーションで prev には最後に処理したノード（元の末尾ノード）が代入されている
    // これが逆順リストの新しい先頭ノードである
    return prev;
}
```
