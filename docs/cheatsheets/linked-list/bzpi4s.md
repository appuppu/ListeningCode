# Adding Two Numbers Represented as Linked Lists — 逆順リンクリストで表現された2つの数を加算する

## 問題の本質

2つの非空リンクリストが与えられる。各リンクリストは非負整数を**逆順**（一の位が先頭）で表現しており、各ノードには1桁の数字が格納されている。2つの数を加算し、その合計を同じく**逆順のリンクリスト**として返す。

## 核心のアイデア

リンクリストが逆順（一の位が先頭）で格納されているため、先頭ノードから順に足し算すればそのまま一の位→十の位→百の位…と筆算と同じ順序で加算できる。繰り上がり（carry）を変数で持ち越しながら、各桁の結果を新しいノードとして繋げていけばよい。

## 思考プロセス

1. **逆順であることが利点になる**: 数値の加算は一の位から行う。リンクリストが逆順なので、先頭ノードから順に処理すれば自然と一の位から加算できる。桁の順序を反転する必要がない
2. **各桁の加算と繰り上がりを管理する**: 各桁で `l1の値 + l2の値 + carry` を計算する。合計が10以上なら繰り上がりが発生する。`sum % 10` がその桁の結果、`sum / 10` が次の桁への繰り上がりになる。これは筆算のルールそのものである
3. **2つのリストの長さが異なる場合を扱う**: 片方のリストが先に終わっても、もう片方のリストやcarryが残っている限り処理を続ける必要がある。whileループの条件を `l1 != null || l2 != null || carry != 0` とすれば、すべてのケースを統一的に扱える
4. **ダミーヘッドで結果リストの構築を簡潔にする**: 結果リストの先頭ノードを特別扱いしないために、値0のダミーノードを先頭に置く。すべての桁の結果を `curr.next` に追加していき、最後に `dummy.next` を返せば正しい結果リストが得られる
5. **ループ内の処理を統一する**: 各イテレーションで、`l1` と `l2` がnullでなければそれぞれの値をsumに加算し、ポインタを次に進める。nullの場合は何もしない。この条件分岐により、リストの長さの違いを自然に吸収できる
6. **最終的に返すもの**: ダミーヘッドの次のノード `dummy.next` が結果リストの先頭である。これを返す

## 前提知識

### ListNode とは

単方向リンクリストのノードを表すクラス。各ノードは整数値 `val` と次のノードへの参照 `next` を持つ。`next` が `null` のノードがリストの末尾である。

```java
public class ListNode {
    int val;              // このノードが保持する1桁の数値
    ListNode next;        // 次のノードへの参照（末尾ならnull）
    ListNode(int val) {   // コンストラクタ：値を指定してノードを作成する
        this.val = val;
    }
}
```

### ダミーヘッド（Dummy Head）とは

リストの先頭に置く値を持たないダミーのノード。結果リストを構築する際、最初のノードを特別扱いせずに済むテクニック。すべてのノードを `curr.next = new ListNode(...)` で統一的に追加でき、最後に `dummy.next` を返すことで実際の先頭ノードを取得する。

```java
ListNode dummy = new ListNode(0);  // ダミーヘッドを作成する
ListNode curr = dummy;             // currはリスト末尾を追跡するポインタ
curr.next = new ListNode(5);       // ダミーの次に値5のノードを追加する
curr = curr.next;                  // currを末尾に進める
// dummy.next が実際のリストの先頭（値5のノード）を指す
```

### 繰り上がり（Carry）とは

1桁同士の加算で合計が10以上になったとき、次の桁に持ち越す値。`sum / 10` で計算する（整数除算なので0か1になる）。現在の桁に残る値は `sum % 10` で求める。
例: 7 + 8 = 15 のとき、carry = 15 / 10 = 1、現在の桁の値 = 15 % 10 = 5。

## 計算量

| | 値 |
|---|---|
| Time | O(max(n, m)) — 2つのリストのうち長い方の長さ分だけ走査する |
| Space | O(max(n, m)) — 結果リストのノード数は最大で max(n, m) + 1 個になる |

## コード

```java
// 入力: 逆順リンクリスト l1 と l2（各ノードは1桁の非負整数）
// 出力: 2つの数の合計を逆順リンクリストとして返す
public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
    // ダミーヘッドを作成する。結果リストの先頭ノードを特別扱いせずに済む
    // 最終的な結果には含まれず、dummy.next が実際の先頭になる
    ListNode dummy = new ListNode(0);
    // currは結果リストの末尾を追跡するポインタ
    ListNode curr = dummy;
    // 繰り上がりを保持する変数。各桁の加算結果が10以上のとき、次の桁に持ち越す値（0または1）
    int carry = 0;

    // どちらかのリストが残っているか、繰り上がりがある限りループを続ける
    // carry != 0 の条件により、999 + 1 = 1000 のように桁数が増えるケースにも対応する
    while (l1 != null || l2 != null || carry != 0) {
        // 前の桁からの繰り上がりを初期値としてsumを計算する
        int sum = carry;

        // l1が残っていれば値を加算し、ポインタを次に進める
        // nullの場合は何もしない。これにより l1 が先に終わっても処理が継続する
        if (l1 != null) {
            sum += l1.val;
            l1 = l1.next;
        }

        // l2が残っていれば値を加算し、ポインタを次に進める
        // nullの場合は何もしない。これにより l2 が先に終わっても処理が継続する
        if (l2 != null) {
            sum += l2.val;
            l2 = l2.next;
        }

        // 繰り上がりを計算する。sumが10以上なら1、10未満なら0になる
        carry = sum / 10;
        // 現在の桁の値（sum % 10）で新しいノードを作成し、結果リストの末尾に接続する
        curr.next = new ListNode(sum % 10);
        // currを末尾に進めて、次のイテレーションで新しいノードを追加できるようにする
        curr = curr.next;
    }

    // ダミーヘッドの次が結果リストの先頭である
    return dummy.next;
}
```
