# Removing the Nth Node From the End of a List — 末尾からN番目のノードを削除する

## 問題の本質

単方向連結リストの先頭ノード `head` と整数 `n` が与えられる。リストの**末尾からN番目**のノードを削除し、変更後のリストの先頭ノードを返す。

## 核心のアイデア

2つのポインタにN個分の間隔を空けて同時に進めると、先行ポインタがリスト末尾に到達した時点で、後続ポインタは削除対象ノードの直前に位置する。これにより1回の走査で削除が完了する。

## 思考プロセス

1. **末尾からN番目を特定するにはリストの長さが必要に見える**: 素朴に考えると、まずリスト全体を走査して長さLを求め、次にL-N番目のノードを探す2回走査が必要になる。しかし、2つのポインタを使えば1回の走査で済む
2. **N個分の間隔を空けた2つのポインタを使う**: fastポインタをslowポインタよりN個先に進めておく。この状態で両者を同時に1つずつ進めると、fastがリスト末尾に到達したとき、slowは末尾からちょうどN+1番目の位置にいる。つまりslowは削除対象の**直前**のノードを指している
3. **ダミーノードを先頭に追加する理由**: 削除対象がリストの先頭ノード（head自身）の場合、「削除対象の直前のノード」が存在しない。ダミーノードをheadの前に置くことで、先頭ノードの削除も他のノードの削除と同じロジックで処理できる
4. **fastをN個先に進める**: forループでfastをN回進める。この時点でslowとfastの間にはN個のノードが存在する
5. **両ポインタを同時に進める**: `fast.next != null` の間、slowとfastを同時に1つずつ進める。fastの**次**がnullになった時点でループを抜ける。このとき、fastはリスト最後のノードを指し、slowは末尾からN+1番目（削除対象の直前）を指している
6. **ノードの削除とリストの返却**: slowの次のノードが削除対象なので、`slow.next = slow.next.next` でリンクを付け替えて削除する。最後に `dummy.next` を返す。headを直接返さないのは、headが削除された場合に対応するためである

## 前提知識

### ListNode とは

単方向連結リストの1つのノードを表すクラス。各ノードは値 `val` と次のノードへの参照 `next` を持つ。`next` がnullのノードがリストの末尾である。

```java
ListNode node = new ListNode(5);  // 値5のノードを作成、nextはnull
node.next = new ListNode(10);     // node → 10 → null のリストになる
```

### ダミーノード（Sentinel Node）とは

リストの先頭に追加する値を持たない番兵ノード。先頭ノードを削除するケースでも「削除対象の前のノード」が必ず存在するようになり、先頭の特別扱いが不要になる。

```java
ListNode dummy = new ListNode(0);  // ダミーノードを作成
dummy.next = head;                 // ダミーの次を本来の先頭にする
// 処理後、dummy.nextが新しい先頭ノードになる
```

### Two-Pointer（2ポインタ）テクニックとは

2つのポインタを異なる速度や間隔で動かすことで、リストの特定の位置を効率的に見つける手法。この問題ではN個の間隔を空けた2つのポインタを同速で動かし、末尾からN番目の位置を特定する。

```java
ListNode slow = head;
ListNode fast = head;
// fastをN個先に進めてから、両方を同時に進める
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — リストを1回走査するだけで済む |
| Space | O(1) — ダミーノードと2つのポインタのみ使用する |

## コード

```java
// 入力: 単方向連結リストの先頭ノード head と整数 n
// 出力: 末尾からN番目のノードを削除した後のリストの先頭ノード ListNode を返す
public ListNode removeNthFromEnd(ListNode head, int n) {
    // 値0のダミーノードを先頭に追加する
    // ダミーノードを置くことで、先頭ノードの削除にも「削除対象の直前のノード」が存在するようになる
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // 両方のポインタをダミーノードから開始する
    // ダミーノードから開始することで、最終的にslowが削除対象の直前に正しく位置する
    ListNode slow = dummy;
    ListNode fast = dummy;

    // fastをN個先に進めて、slowとの間にN個分の間隔を作る
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }

    // 両ポインタを同時に進め、fastがリスト末尾に到達したら停止する
    // fast.next != null を条件にしているのは、fastがリスト最後のノードに到達した時点で
    // slowが削除対象の直前に位置するようにするため
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // slow.next が削除対象のノード。slowの次のポインタを1つ先に付け替え、削除対象をリストから切り離す
    slow.next = slow.next.next;

    // head ではなく dummy.next を返すのは、headが削除対象だった場合に新しい先頭ノードを正しく返すため
    return dummy.next;
}
```
