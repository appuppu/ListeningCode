# Reversing Nodes in Groups of K — 連結リストをK個ずつのグループに分けて各グループを反転する

## 問題の本質

単方向連結リストの先頭ノード `head` と整数 `k` が与えられる。リストを先頭から `k` 個ずつのグループに分け、各グループ内のノードの順序を反転する。末尾のグループが `k` 個未満の場合は、そのグループはそのまま残す。変更後のリストの先頭ノードを返す。

## 核心のアイデア

ダミーノードを先頭に置き、「グループの直前ノード」と「グループのk番目のノード」を基準点として、各グループ内のポインタを1つずつ付け替えることで、追加メモリなしにその場で反転できる。

## 思考プロセス

1. **グループ単位で反転する必要がある**: リスト全体ではなく、k個ずつのグループごとに反転する。つまり「現在のグループの範囲を特定する」→「そのグループを反転する」→「次のグループに進む」というループ構造になる
2. **グループの範囲を特定するにはk番目のノードを見つける**: 現在位置からk個先のノードを探す補助関数 `getKth` を用意する。k番目のノードが存在しなければ（`null`）、残りがk個未満なので反転せずに終了する
3. **反転後にグループ同士を正しく接続する必要がある**: グループを反転すると、グループの先頭と末尾が入れ替わる。前のグループの末尾（`groupPrev`）が反転後の新しい先頭（元のk番目のノード）を指すように接続し直す必要がある
4. **ダミーノードで先頭グループの反転を統一的に扱う**: 最初のグループを反転すると、リストの先頭ノード自体が変わる。ダミーノードを先頭に置くことで、「グループの直前ノードが新しい先頭を指す」という操作を、最初のグループでもそれ以降のグループでも同じロジックで処理できる
5. **各グループの反転は標準的なリスト反転と同じ手法で行う**: `prev` と `curr` の2つのポインタを使い、`curr.next` を `prev` に付け替えながら1ノードずつ進む。ただし、`prev` の初期値をグループの次のノード（`groupNext`）にすることで、反転後の末尾が次のグループと自動的に接続される
6. **反転後にgroupPrevを更新して次のグループへ進む**: 反転前のグループ先頭ノード（`groupPrev.next`）は、反転後にはグループの末尾になる。このノードを次のグループの `groupPrev` として使い、次のイテレーションに進む

## 前提知識

### ListNode とは

単方向連結リストの1つのノードを表すクラス。各ノードは「値（val）」と「次のノードへのポインタ（next）」を持つ。`next` が `null` のノードがリストの末尾である。

```java
class ListNode {
    int val;          // ノードが保持する値
    ListNode next;    // 次のノードへの参照（末尾ならnull）

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### ダミーノード（Dummy Node）とは

リストの先頭に仮のノードを追加するテクニック。先頭ノードの変更が起きる場合に、場合分けを不要にする。`dummy.next` が常にリストの実際の先頭を指す。

```java
ListNode dummy = new ListNode(0);  // 値は何でもよい
dummy.next = head;                 // ダミーの次が実際の先頭
// ... リストを操作 ...
return dummy.next;                 // 操作後の実際の先頭を返す
```

### 連結リストの反転の基本操作

`prev` と `curr` の2つのポインタを使い、各ノードの `next` を前のノードに付け替えていく。

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode tmp = curr.next;  // 次のノードを一時保存する
    curr.next = prev;          // 現在のノードの次を前のノードに変更する
    prev = curr;               // prevを現在のノードに進める
    curr = tmp;                // currを次のノードに進める
}
// prevが反転後の先頭ノードになる
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 各ノードを定数回だけ訪問する（k番目の探索で1回、反転で1回） |
| Space | O(1) — ポインタ変数のみを使用し、追加のデータ構造は不要 |

## コード

```java
// 入力: 連結リストの先頭ノード head と整数 k
// 出力: k個ずつのグループを反転した連結リストの先頭ノードを返す
public ListNode reverseKGroup(ListNode head, int k) {
    // ダミーノードを作成し、dummy.next = head で実際のリストの先頭に接続する
    // ダミーノードを使うことで、最初のグループの反転でも「グループの直前ノード」が常に存在する
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // groupPrevは「これから反転するグループの直前のノード」を指す
    // 初期値はダミーノード
    ListNode groupPrev = dummy;

    // 無限ループで各イテレーションごとに1つのグループを反転する
    while (true) {
        // groupPrevの1つ先のノードから出発し、k-1回nextをたどってk番目のノードを探す
        // 途中でnullに到達した場合は残りがk個未満なのでnullを返す
        ListNode kth = getKth(groupPrev, k);

        // k番目が存在しなければ残りはk個未満なのでそのまま終了する
        // k個未満のグループはそのまま残すという問題の要件をこの判定で満たす
        if (kth == null) break;

        // groupNextは「現在のグループの直後のノード」で、反転の終端の目印として使う
        ListNode groupNext = kth.next;

        // prevの初期値をgroupNextに設定する
        // こうすると反転後のグループ末尾ノードのnextが自動的に次のグループの先頭を指す
        ListNode prev = kth.next;
        // currはグループの先頭ノードから開始する（反転後はグループの末尾になるノード）
        ListNode curr = groupPrev.next;

        // currがgroupNextと等しくなるまでグループ内の各ノードのnextポインタを反転する
        // この操作により、各ノードのnextが1つ前のノードを指すように変わる
        while (curr != groupNext) {
            ListNode tmp = curr.next;  // 次のノードを一時保存する
            curr.next = prev;          // 現在のノードの次を前のノードに変更する
            prev = curr;               // prevを現在のノードに進める
            curr = tmp;                // currを次のノードに進める
        }

        // 反転前の先頭ノードを保存する（反転後はグループの末尾になっている）
        ListNode tmp = groupPrev.next;
        // 反転後のグループ先頭はkth（元のk番目のノード）なので、
        // 前のグループの末尾が反転後の新しい先頭を正しく指すように接続する
        groupPrev.next = kth;
        // 反転前にグループの先頭だったノードは反転後にグループの末尾になっている
        // このノードを次のイテレーションのgroupPrevとして使う
        groupPrev = tmp;
    }

    // dummy.nextは操作後のリスト全体の先頭ノードを指している
    return dummy.next;
}

// nodeの次のノードからk番目のノードを返す。k個未満ならnullを返す
private ListNode getKth(ListNode node, int k) {
    // nodeの1つ先から出発する
    node = node.next;
    // k-1回nextをたどってk番目に到達する
    // 途中でnullに到達した場合は残りのノードがk個未満
    while (node != null && k > 1) {
        node = node.next;
        k--;
    }
    // k番目のノードを返す（k個未満だった場合はnull）
    return node;
}
```
