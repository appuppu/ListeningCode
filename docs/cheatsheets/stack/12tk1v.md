# Checking if Parentheses Are Balanced — 括弧の文字列が正しく対応しているか判定する

## 問題の本質

`(`、`)`、`{`、`}`、`[`、`]` の6種類の括弧のみで構成された文字列が与えられる。すべての開き括弧に対応する閉じ括弧が**正しい順序**で存在するかを判定し、`true` または `false` を返す。

## 核心のアイデア

括弧の対応は「最後に開いたものを最初に閉じる」という後入れ先出し（LIFO）の構造を持つ。この性質はスタックそのものであり、開き括弧をスタックに積み、閉じ括弧が来たらスタックの先頭と照合することで正しい対応を検証できる。

## 思考プロセス

1. **括弧の対応には順序がある**: `([)]` は各括弧の数は合っているが順序が不正。つまり「最も内側の括弧から先に閉じる」というルールがある。これは後入れ先出し（LIFO）の構造であり、スタックで自然に表現できる
2. **開き括弧はスタックに積む**: 文字列を先頭から1文字ずつ走査し、開き括弧（`(`、`{`、`[`）に出会ったらスタックにpushする。スタックの先頭には「最も最近に開かれた、まだ閉じられていない括弧」が常に位置する
3. **閉じ括弧が来たらスタックの先頭と照合する**: 閉じ括弧に出会ったら、スタックからpopした開き括弧が対応する種類かを確認する。対応しなければ不正な文字列である
4. **スタックが空のときに閉じ括弧が来たら不正**: popする前にスタックが空であれば、対応する開き括弧が存在しないことを意味するので `false` を返す
5. **走査完了後にスタックが空であれば正当**: すべての文字を処理した後、スタックに開き括弧が残っていれば閉じられていない括弧があることを意味する。スタックが空であればすべての括弧が正しく対応している

## 前提知識

### Stack とは

後入れ先出し（LIFO: Last In, First Out）のデータ構造。最後に追加した要素が最初に取り出される。括弧の対応チェックのように「最も最近のもの」から順に処理する場面で使う。

```java
Stack<Character> stack = new Stack<>();  // 空のスタックを作成
stack.push('(');      // スタックの先頭に '(' を追加する
stack.peek();         // スタックの先頭の要素を取り出さずに参照する → '('
stack.pop();          // スタックの先頭の要素を取り出して返す → '('
stack.isEmpty();      // スタックが空かどうかをbooleanで返す → true
```

### 括弧の対応関係

3種類の括弧にはそれぞれ開きと閉じのペアがある。閉じ括弧が来たとき、スタックの先頭が対応する開き括弧であるかを確認する必要がある。

```
')' の対応する開き括弧は '('
'}' の対応する開き括弧は '{'
']' の対応する開き括弧は '['
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 文字列を1回走査するだけで済む |
| Space | O(n) — スタックに最大n個の開き括弧を保存する |

## コード

```java
// 入力: 括弧のみで構成された文字列 s
// 出力: すべての括弧が正しく対応していれば true、そうでなければ false
public boolean isValid(String s) {
    // 「まだ閉じられていない開き括弧」を保持するスタック
    // スタックの先頭には最も最近に開かれた括弧が位置する
    Stack<Character> stack = new Stack<>();

    // 文字列を先頭から1文字ずつ走査する。toCharArray() で文字列をchar配列に変換する
    for (char c : s.toCharArray()) {
        // 開き括弧ならスタックに積む。対応する閉じ括弧が来るまでスタックに残り続ける
        if (c == '(' || c == '{' || c == '[') {
            stack.push(c);
        } else {
            // 閉じ括弧なのにスタックが空なら、対応する開き括弧が存在しないので不正
            if (stack.isEmpty()) return false;

            // スタックの先頭から「最も最近に開かれた、まだ閉じられていない括弧」を取り出す
            char top = stack.pop();

            // 閉じ括弧と開き括弧の種類が対応しなければ不正
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
            if (c == ')' && top != '(') return false;
        }
    }

    // スタックが空ならすべての括弧が正しく対応している
    // スタックに要素が残っていれば閉じられていない開き括弧があるので false
    return stack.isEmpty();
}
```
