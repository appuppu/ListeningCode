# Finding the Largest Rectangle in a Histogram — ヒストグラム内に形成できる最大の長方形の面積を求める

## 問題の本質

非負整数の配列 `heights` が与えられる。各要素はヒストグラムの棒の高さを表し、棒の幅はすべて1である。このヒストグラム内に形成できる**最大の長方形の面積**を求めて返す。

## 核心のアイデア

各棒を「長方形の高さ」として採用したとき、その棒が最も低い棒として左右にどこまで拡張できるかがわかれば面積が計算できる。単調増加スタックを使えば、棒の高さが下がった瞬間に、スタック内の棒の拡張可能な幅をO(1)で確定できる。

## 思考プロセス

1. **各棒を高さとする長方形を考える**: 任意の長方形は「ある棒の高さを上限とし、左右に連続する棒で構成される」と見なせる。つまり、各棒 `heights[i]` について「この棒が最も低い棒となる区間の幅」がわかれば、`heights[i] × 幅` で面積を計算できる
2. **左右の境界を効率的に求めたい**: 各棒について「左側で初めて自分より低い棒の位置」と「右側で初めて自分より低い棒の位置」がわかれば、拡張可能な幅が確定する。全棒に対してこの2つの境界を愚直に探索するとO(n²)になるため、スタックを使って効率化する
3. **単調増加スタックを使う**: スタックに棒のインデックスを、高さが単調増加になるように積んでいく。現在の棒の高さがスタックの先頭より低いとき、スタックの先頭の棒にとって「右側の境界」が現在の位置 `i` であると確定する
4. **ポップ時に幅を計算する**: スタックから棒 `top` をポップしたとき、右側の境界は現在の位置 `i`、左側の境界はポップ後のスタックの先頭の次の位置である。スタックが空の場合は左端（インデックス0）まで拡張できるので、幅は `i` となる。スタックが空でない場合は、幅は `i - stack.peek() - 1` となる
5. **番兵として高さ0を末尾に追加する**: 配列の末尾に到達したとき、スタックに残っている棒の面積も計算する必要がある。ループの範囲を `i <= heights.length` とし、`i == heights.length` のときに高さ0を仮想的に置くことで、スタック内の全ての棒が必ずポップされる
6. **最大面積を追跡する**: 棒をポップするたびに `heights[top] × 幅` を計算し、これまでの最大値と比較して更新する。全てのポップが完了した時点での最大値が答えである

## 前提知識

### Stack（スタック）とは

後入れ先出し（LIFO）のデータ構造。最後に追加した要素が最初に取り出される。ヒストグラム問題では、棒のインデックスをスタックに積み、高さの単調性を維持するために使う。

```java
Stack<Integer> stack = new Stack<>();  // 空のスタックを作成
stack.push(0);       // スタックの先頭に値0を追加する
stack.peek();        // スタックの先頭の値を取り出さずに参照する → 0
stack.pop();         // スタックの先頭の値を取り出して返す → 0
stack.isEmpty();     // スタックが空かどうかをbooleanで返す → true
```

### 単調増加スタック（Monotonic Stack）とは

スタック内の要素が常に下から上に向かって増加する（または等しい）状態を維持するスタック。新しい要素を追加するとき、スタックの先頭よりも小さい値が来たら、先頭が新しい値以上になるまでポップする。ポップの瞬間に「そのポップされた要素の右側の境界が確定した」と解釈できる。

```java
// 配列 [2, 1, 5, 6, 2, 3] に対する単調増加スタックの動き
// i=0: push(0)         → スタック: [0]       （高さ: [2]）
// i=1: 1 < 2 なのでpop → スタック: []        （高さ2の棒の右境界がi=1と確定）
//       push(1)         → スタック: [1]       （高さ: [1]）
// i=2: push(2)         → スタック: [1,2]     （高さ: [1,5]）
// i=3: push(3)         → スタック: [1,2,3]   （高さ: [1,5,6]）
// i=4: 2 < 6 なのでpop → スタック: [1,2]     （高さ6の棒の右境界がi=4と確定）
//       2 < 5 なのでpop → スタック: [1]       （高さ5の棒の右境界がi=4と確定）
//       push(4)         → スタック: [1,4]     （高さ: [1,2]）
```

### 番兵（Sentinel）とは

ループの終端処理を簡潔にするために仮想的に追加する値。この問題では配列の末尾に高さ0の棒を仮想的に置くことで、ループ終了時にスタック内に残った全ての棒を自然にポップさせる。

```java
// i == heights.length のとき、実際の配列外なので仮想的に高さ0を使う
int h = (i == heights.length) ? 0 : heights[i];
// 高さ0はどの棒よりも低いので、スタック内の全棒がポップされる
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 各棒はスタックに1回プッシュされ1回ポップされるので、全体でO(n)の操作で済む |
| Space | O(n) — スタックに最大n個のインデックスを保存する |

## コード

```java
// 入力: 非負整数の配列 heights（各要素はヒストグラムの棒の高さ）
// 出力: ヒストグラム内に形成できる最大の長方形の面積を int で返す
public int largestRectangleArea(int[] heights) {
    // 棒のインデックスを単調増加で保持するスタック
    Stack<Integer> stack = new Stack<>();
    // これまでに見つかった最大面積を記録する変数
    int maxArea = 0;

    // i <= heights.length とすることで番兵の処理を含める
    // i == heights.length のとき番兵（高さ0）としてスタックを全てポップさせる
    for (int i = 0; i <= heights.length; i++) {
        // 番兵: 配列末尾を超えたら高さ0を使う。高さ0はどの棒よりも低いので、スタック内の全棒がポップされることが保証される
        int h = (i == heights.length) ? 0 : heights[i];

        // 現在の高さがスタック先頭の棒より低い間、面積を計算する
        // この条件により、スタック内の単調増加性が維持される
        while (!stack.isEmpty() && h < heights[stack.peek()]) {
            // ポップした棒を長方形の高さとして採用する。この棒の右側の境界は現在の位置 i
            int top = stack.pop();

            // 幅を計算する:
            // スタックが空 → top の棒は左端（インデックス0）まで拡張できるので幅は i
            // スタックが空でない → stack.peek() は top より左にあって top より低い棒のインデックス（左側の境界）なので、幅は i - stack.peek() - 1
            int w = stack.isEmpty() ? i : i - stack.peek() - 1;

            // 面積を計算し、最大値を更新する
            maxArea = Math.max(maxArea, heights[top] * w);
        }

        // 現在のインデックスをスタックにプッシュして単調増加を維持する
        stack.push(i);
    }
    // 全てのポップが完了した時点での最大値が答え
    return maxArea;
}
```
