# Finding How Many Days Until a Warmer Temperature — 各日から次に気温が上がる日までの日数を求める

## 問題の本質

整数の配列 `temperatures` が与えられる。各日について、その日より気温が高い**未来の日**が何日後にあるかを計算し、結果を配列で返す。未来に気温が高い日が存在しない場合、その日の答えは `0` とする。

## 核心のアイデア

単調減少スタックにインデックスを積んでいくと、スタックには「まだ自分より暖かい日が見つかっていない日」だけが残る。新しい日の気温がスタック上の日の気温より高ければ、そのインデックスの差がそのまま「待ち日数」になる。

## 思考プロセス

1. **各日について「次に気温が上がる日」を探す必要がある**: 素朴に考えると各日から右方向に線形探索するが、それではO(n²)になる。各日の「未解決状態」を効率よく管理する仕組みが必要である
2. **「まだ答えが決まっていない日」を追跡したい**: 配列を左から走査するとき、現在の日より気温が高い未来の日がまだ見つかっていない日を「未解決の日」として保持しておけば、新しい日が来たときに一括で解決できる
3. **未解決の日をスタックで管理する**: スタックにインデックスを積んでいく。新しい日の気温がスタック上の日の気温より高ければ、その未解決の日の答えが確定する。スタックは常に気温が上から下に向かって単調減少になる（低い気温が上に積まれる）
4. **答えはインデックスの差で求まる**: 未解決の日 `j` が現在の日 `i` によって解決されるとき、待ち日数は `i - j` である。この差を結果配列の `j` 番目に格納する
5. **各要素は最大1回ずつpushとpopされる**: スタックへのpushは各要素で1回、popも最大1回であるため、whileループを含めた全体の処理回数はO(n)に収まる

## 前提知識

### Stack（スタック）とは

後入れ先出し（LIFO）のデータ構造。最後に追加した要素を最初に取り出す。Javaでは `Stack<Integer>` クラスを使用する。

```java
Stack<Integer> stack = new Stack<>();  // 空のスタックを作成
stack.push(5);          // スタックの一番上に5を追加する
stack.peek();           // スタックの一番上の要素を取り出さずに返す → 5
stack.pop();            // スタックの一番上の要素を取り出して返す → 5
stack.isEmpty();        // スタックが空かどうかをbooleanで返す → true
```

### 単調スタック（Monotonic Stack）とは

スタック内の要素が常に単調増加または単調減少の順序を保つように管理するスタック。本問題では**単調減少スタック**を使用する。新しい要素を追加する前に、スタックの順序を崩す要素をすべてpopすることで単調性を維持する。「次に大きい（小さい）要素を見つける」パターンに適用できる。

```java
// 単調減少スタックの基本パターン
// スタック内の気温は下から上に向かって減少する
// 例: スタック底[75, 71, 69]上 ← 気温が減少している
// ここに72が来ると、69と71をpopして解決し、[75, 72]になる
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 各要素はスタックにpushとpopをそれぞれ最大1回ずつ行うため、全体でO(n)である |
| Space | O(n) — スタックに最大n個のインデックスを保存する |

## コード

```java
// 入力: 整数配列 temperatures（各日の気温）
// 出力: 各日から次に気温が上がる日までの日数を格納した int[] を返す
public int[] dailyTemperatures(int[] temperatures) {
    // 結果配列を作成する（Javaではint[]の初期値は0なので、未来に暖かい日がない場合の答え0がデフォルトで設定される）
    int[] result = new int[temperatures.length];
    // まだ暖かい日が見つかっていない日のインデックスを保存するスタック
    // 気温の値ではなくインデックスを保存する理由: 待ち日数の計算にインデックスの差が必要であり、かつインデックスから気温は temperatures[index] で参照できるため
    Stack<Integer> indexStack = new Stack<>();

    // 配列をインデックス i = 0 から末尾まで1つずつ走査する
    for (int i = 0; i < temperatures.length; i++) {
        // 現在の気温がスタック上の日の気温より高い間、未解決の日を解決する
        // 条件: スタックが空でない かつ 現在の気温 > スタック上のインデックスが指す気温
        while (!indexStack.isEmpty() && temperatures[i] > temperatures[indexStack.peek()]) {
            // スタックの一番上のインデックスを取り出す
            int stackTopIndex = indexStack.pop();
            // 待ち日数 = 現在のインデックス - 待っていた日のインデックス
            result[stackTopIndex] = i - stackTopIndex;
        }
        // whileループ終了後（スタックが空、またはスタック上の気温が現在の気温以上）、現在のインデックスをスタックに追加する
        // この時点でスタック内は単調減少の順序が保たれている
        indexStack.push(i);
    }

    // スタックに残っているインデックスは「未来に暖かい日が存在しなかった日」
    // これらの日の結果は初期値の0のままなので、追加の処理は不要
    return result;
}
```
