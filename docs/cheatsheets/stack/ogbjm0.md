# Counting Car Fleets Arriving at a Destination — 目的地に到着する車の隊列数を求める

## 問題の本質

整数 `target`（目的地の位置）、整数配列 `position`（各車の現在位置）、整数配列 `speed`（各車の速度）が与えられる。すべての車は同じ目的地に向かって走行している。速い車が前方の遅い車に追いつくと、遅い車の速度に合わせて1つの隊列（fleet）として走行する。最終的に目的地に到着する**隊列の数**を整数で返す。

## 核心のアイデア

目的地に近い車から順に処理し、各車の「目的地への到着時間」をスタックで管理すれば、後ろの車の到着時間が前の車以下なら合流、大きければ新しい隊列と判定でき、最終的なスタックのサイズが隊列数になる。

## 思考プロセス

1. **隊列の成立条件を到着時間で判定する**: 後ろの車が前の車に追いつくかどうかは、目的地への到着時間で決まる。後ろの車の到着時間が前の車の到着時間以下なら、途中で追いつくので同じ隊列になる。到着時間は `(target - position[i]) / speed[i]` で計算できる
2. **目的地に近い車から順に処理したい**: 隊列の合流判定は「前の車（目的地に近い車）が壁になるかどうか」で決まるため、目的地に近い順にソートして処理すれば、前方の車の到着時間を基準に後方の車を順次判定できる
3. **ソート対象はインデックスにする**: positionとspeedは別々の配列なので、インデックス配列を作成し、`position` の降順（目的地に近い順）でソートする。こうすれば元の配列を壊さずに、対応するpositionとspeedを参照できる
4. **スタックで隊列を管理する**: スタックのトップには直前の隊列の到着時間（＝その隊列の先頭車の到着時間）が入っている。新しい車の到着時間がスタックのトップ以下なら、その車は前の隊列に合流するのでスタックに追加しない。到着時間がトップより大きければ、新しい隊列が形成されるのでスタックにpushする
5. **スタックのサイズが答えになる**: 合流した車はスタックに追加されず、新しい隊列を形成する車だけがpushされるため、最終的なスタックの要素数がそのまま隊列の数になる

## 前提知識

### 到着時間の計算

車の現在位置が `pos`、速度が `speed`、目的地が `target` のとき、到着時間は `(target - pos) / speed` で求まる。この値が小さいほど早く到着する。

```
例: target=12, pos=10, speed=2 のとき
到着時間 = (12 - 10) / 2 = 1.0
```

### Integer[] のカスタムソート

プリミティブ型 `int[]` はラムダ式でソートできないため、`Integer[]` のインデックス配列を作成し、`Arrays.sort` にComparatorを渡してソートする。

```java
Integer[] idx = new Integer[n];
for (int i = 0; i < n; i++) idx[i] = i;
// posの降順（目的地に近い順）でインデックスをソートする
Arrays.sort(idx, (a, b) -> pos[b] - pos[a]);
```

### Stack とは

後入れ先出し（LIFO）のデータ構造。`push` で要素を積み、`peek` で一番上の要素を参照し、`pop` で取り出す。ここではスタックのトップに「直前の隊列の到着時間」を保持し、合流判定の基準として使う。

```java
Stack<Double> stack = new Stack<>();  // 空のスタックを作成
stack.push(3.0);    // 要素3.0をスタックの一番上に積む
stack.peek();        // 一番上の要素を取り出さずに参照する → 3.0
stack.isEmpty();     // スタックが空かどうかを判定する → false
stack.size();        // スタック内の要素数を返す → 1
```

## 計算量

| | 値 |
|---|---|
| Time | O(n log n) — インデックス配列のソートにO(n log n)、その後の走査にO(n)がかかる |
| Space | O(n) — インデックス配列とスタックにそれぞれ最大n個の要素を保存する |

## コード

```java
// 入力: 整数 target（目的地の位置）、整数配列 pos（各車の位置）、整数配列 speed（各車の速度）
// 出力: 目的地に到着する隊列の数を整数で返す
public int carFleet(int target, int[] pos, int[] speed) {
    // 車の台数を取得する
    int n = pos.length;

    // Integer[] 型のインデックス配列を作成し、0からn-1までの値で初期化する
    // インデックス配列をソートすることで、元の配列を保持したまま順序を変更できる
    Integer[] idx = new Integer[n];
    for (int i = 0; i < n; i++) {
        idx[i] = i;
    }

    // インデックス配列をpositionの降順（目的地に近い順）でソートする
    // 目的地に近い車から処理することで、前方の車を基準にした合流判定が可能になる
    Arrays.sort(idx, (a, b) -> pos[b] - pos[a]);

    // 各隊列の到着時間を保存するスタック
    // スタックのトップは「直前に確定した隊列の到着時間」を表す
    Stack<Double> stack = new Stack<>();

    for (int i : idx) {
        // この車の目的地への到着時間を計算する
        // double にキャストしないと整数除算になり小数部分が失われる
        double time = (double) (target - pos[i]) / speed[i];

        // 到着時間がスタックのトップ以下なら、この車は前方の隊列に追いつくので合流する
        // continueでスタックへの追加をスキップし、次の車の処理に進む
        if (!stack.isEmpty() && time <= stack.peek()) {
            continue;
        }

        // スタックが空、またはtimeがトップより大きい場合、前方の隊列に追いつけない
        // 新しい隊列を形成するのでスタックに到着時間を積む
        stack.push(time);
    }

    // スタックには各隊列の到着時間が1つずつ入っているため、サイズが隊列の数と一致する
    return stack.size();
}
```
