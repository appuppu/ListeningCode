# Designing a Stack That Tracks the Minimum — 全操作O(1)で最小値を取得できるスタックを設計する

## 問題の本質

`push`、`pop`、`top`、`getMin`（現在の最小値の取得）の4つの操作を全てO(1)で実行できるスタックを設計する。通常のスタックでは最小値の取得にO(n)かかるため、工夫が必要になる。

## 核心のアイデア

スタックの各要素に「その時点での最小値」を一緒に保存すれば、要素がpopされても最小値の情報が失われない。`getMin()`は常にスタックの先頭を見るだけでO(1)で答えが得られる。

## 思考プロセス

1. **getMinをO(1)にするには、最小値を常に把握しておく必要がある**: 変数1つで最小値を管理する方法を考えるが、popで最小値が取り除かれたとき、次の最小値が分からなくなる。つまり、最小値の「履歴」を保持する仕組みが必要である
2. **最小値の履歴はスタックの状態と連動している**: スタックに要素が積まれるたびに最小値が変わりうる。逆にpopされると、pushする前の最小値に戻る。この「pushする前の状態に戻る」という性質はスタック自体の性質と同じである
3. **各要素にその時点の最小値をペアで保存する**: pushするとき、新しい値と現在の最小値を比較し、小さい方を「その時点の最小値」として新しい値と一緒に保存する。こうすれば、popで要素が取り除かれても、次の先頭要素が正しい最小値を持っている
4. **ペアの構造を決める**: `int[]` の配列を使い、`[0]` に値、`[1]` にその時点の最小値を保存する。スタックの型は `Stack<int[]>` となる
5. **pushでの最小値の計算方法**: スタックが空なら新しい値がそのまま最小値になる。空でなければ、新しい値とスタックの先頭にある最小値（`stack.peek()[1]`）を比較し、小さい方を採用する
6. **top・getMin・popの実装**: `top()` は先頭ペアの `[0]`、`getMin()` は先頭ペアの `[1]` を返すだけでO(1)。`pop()` は通常のスタックと同じく先頭を取り除くだけでよい

## 前提知識

### Stack とは

後入れ先出し（LIFO）のデータ構造。最後に追加した要素が最初に取り出される。JavaではGenericsを使って格納する型を指定する。

```java
Stack<int[]> stack = new Stack<>();  // int配列を格納するスタックを作成
stack.push(new int[]{1, 1});         // 要素を先頭に追加する
stack.peek();                         // 先頭の要素を取り出さずに参照する → [1, 1]
stack.pop();                          // 先頭の要素を取り出して返す → [1, 1]
stack.isEmpty();                      // スタックが空かどうかをbooleanで返す → true
```

### Math.min とは

2つの整数を受け取り、小さい方を返すメソッド。pushのたびに新しい値と現在の最小値を比較するために使用する。

```java
Math.min(3, 5);   // → 3
Math.min(-1, 0);  // → -1
```

## 計算量

| | 値 |
|---|---|
| Time | O(1) — push、pop、top、getMinの全操作が定数時間で完了する |
| Space | O(n) — スタックに最大n個のペアを保存する |

## コード

```java
// 入力: push(val)、pop()、top()、getMin() の操作列
// 出力: top() は先頭の値を返す。getMin() は現在のスタック内の最小値を返す
class MinStack {

    // Stack<int[]> 型のフィールド。各要素は長さ2の配列で、[0] に値、[1] にその時点でのスタック全体の最小値を保存する
    private Stack<int[]> stack;

    public MinStack() {
        stack = new Stack<>();
    }

    public void push(int val) {
        // スタックが空なら val 自身が最小値。空でなければ先頭に記録されている最小値と比較し、小さい方を採用する
        int min = stack.isEmpty() ? val : Math.min(val, stack.peek()[1]);
        // 値と最小値のペア new int[]{val, min} をpushする。この要素が先頭にある間は min が正しい最小値となる
        stack.push(new int[]{val, min});
    }

    public void pop() {
        // 先頭のペアを取り除く。取り除かれた後の先頭ペアの [1] には、その要素がpushされた時点の正しい最小値が保存されているため、最小値の整合性は自動的に保たれる
        stack.pop();
    }

    public int top() {
        // ペアの [0] には値そのものが保存されている
        return stack.peek()[0];
    }

    public int getMin() {
        // ペアの [1] にはその時点での最小値が保存されているため、走査は不要
        return stack.peek()[1];
    }
}
```
