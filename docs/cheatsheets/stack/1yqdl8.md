# Evaluating an Expression in Reverse Polish Notation — 逆ポーランド記法の算術式を評価する

## 問題の本質

文字列の配列 `tokens` が逆ポーランド記法（RPN）の算術式として与えられる。この式を評価し、結果を整数で返す。有効な演算子は `+`, `-`, `*`, `/` の4つで、各オペランドは整数または別の部分式である。除算はゼロ方向に切り捨てる。例: `["2","1","+","3","*"]` → `((2+1)*3)` → `9`。

## 核心のアイデア

逆ポーランド記法では演算子の優先順位や括弧の処理が不要であり、トークンを左から右へ走査しながらスタックに数値を積み、演算子が現れたら上位2つを取り出して計算結果を戻すだけで、式全体を正しく評価できる。

## 思考プロセス

1. **RPNの性質を理解する**: 逆ポーランド記法では、演算子はその直前の2つのオペランドに作用する。つまり、演算子が出現した時点で、対象となる2つのオペランドは既に確定している。この性質から、「最後に追加したものを最初に取り出す」LIFOのデータ構造であるスタックが適している
2. **トークンが数値か演算子かで処理を分岐する**: 各トークンを順に見て、数値ならスタックに積み、演算子なら計算を行う。この2つの操作だけで式全体を評価できる
3. **演算子の処理でオペランドの順序に注意する**: スタックから最初にpopした値が右オペランド（`a`）、次にpopした値が左オペランド（`b`）になる。計算は `b 演算子 a` の順で行う。この順序を間違えると、減算と除算で誤った結果になる
4. **計算結果をスタックに戻す**: 演算結果をスタックにpushすることで、その結果が後続の演算のオペランドとして使われる。これにより、ネストした部分式も自然に処理される
5. **最終結果はスタックに1つだけ残る**: 有効なRPN式であれば、全トークンの処理後にスタックには計算結果が1つだけ残る。この値をpopして返す

## 前提知識

### Stack とは

後入れ先出し（LIFO）のデータ構造。最後に追加した要素を最初に取り出せる。要素の追加（push）と取り出し（pop）はいずれもO(1)で行える。

```java
Stack<Integer> stack = new Stack<>();  // 空のスタックを作成
stack.push(5);     // スタックの一番上に5を積む → [5]
stack.push(3);     // スタックの一番上に3を積む → [5, 3]
stack.pop();       // 一番上の要素を取り出して返す → 3、スタックは [5]
stack.pop();       // 一番上の要素を取り出して返す → 5、スタックは []
```

### 逆ポーランド記法（RPN）とは

演算子をオペランドの後に置く記法。通常の中置記法 `(2 + 1) * 3` は、RPNでは `2 1 + 3 *` と表記する。括弧が不要で、左から右へ順に処理するだけで正しく評価できる。

```
中置記法:  (2 + 1) * 3
RPN:       2 1 + 3 *
評価過程:  2 1 + → 3、次に 3 3 * → 9
```

### Integer.parseInt とは

文字列を整数に変換するJavaの静的メソッド。負の数を表す文字列（例: `"-3"`）も正しく変換できる。

```java
Integer.parseInt("42");    // → 42
Integer.parseInt("-3");    // → -3
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列のトークンを1回走査するだけで済む |
| Space | O(n) — スタックに最大n個の要素を保存する |

## コード

```java
// 入力: 逆ポーランド記法の算術式を表す文字列配列 tokens
// 出力: 式の評価結果を整数で返す
public int evalRPN(String[] tokens) {
    // 数値オペランドと中間計算結果を一時的に保持するスタック
    Stack<Integer> stack = new Stack<>();

    // 配列 tokens を先頭から末尾まで1つずつ走査する
    for (String token : tokens) {
        // 現在のトークンが演算子（+, -, *, / のいずれか）であるかを判定する
        switch (token) {
            case "+": {
                int a = stack.pop();  // 1回目のpop → 右オペランド
                int b = stack.pop();  // 2回目のpop → 左オペランド
                // 計算結果をpushすることで、後続の演算のオペランドとして使われる
                stack.push(b + a);
                break;
            }
            case "-": {
                int a = stack.pop();
                int b = stack.pop();
                // 注意: popの順序が逆なので必ず b - a の順。a - b とすると結果が反転する
                stack.push(b - a);
                break;
            }
            case "*": {
                int a = stack.pop();
                int b = stack.pop();
                stack.push(b * a);
                break;
            }
            case "/": {
                int a = stack.pop();
                int b = stack.pop();
                // Javaの整数除算は自動的にゼロ方向に切り捨てられるため特別な処理は不要
                // 注意: popの順序が逆なので必ず b / a の順。a / b とすると結果が反転する
                stack.push(b / a);
                break;
            }
            default: {
                // 数値トークンを整数に変換してスタックに積む
                // 負の数（例: "-3"）も parseInt が正しく処理する
                stack.push(Integer.parseInt(token));
            }
        }
    }

    // 有効なRPN式であれば、全トークン処理後にスタックには結果が1つだけ残る
    return stack.pop();
}
```
