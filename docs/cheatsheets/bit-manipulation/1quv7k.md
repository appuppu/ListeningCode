# Adding Two Numbers Without the Plus Operator — 加算演算子を使わずに2つの整数の和を求める

## 問題の本質

2つの整数 `a` と `b` が与えられる。`+` 演算子や `-` 演算子を**使わずに**、ビット演算だけで2つの整数の合計を計算して返す。

## 核心のアイデア

2進数の加算は「繰り上がりなしの各桁の和（XOR）」と「繰り上がり（AND を左シフト）」の2つに分解できる。繰り上がりがゼロになるまでこの分解を繰り返せば、最終的な和が得られる。

## 思考プロセス

1. **加算の本質をビット単位で考える**: 2進数の各桁の加算は、繰り上がりを無視すれば「どちらか一方だけが1のとき結果が1」になる。これはXOR演算（`a ^ b`）そのものである
2. **繰り上がりを別途計算する**: 繰り上がりは「両方の桁が1のとき」に発生する。これはAND演算（`a & b`）で求まる。繰り上がりは次の桁に影響するので、結果を1ビット左にシフトする（`(a & b) << 1`）
3. **繰り上がりを和に加算する必要がある**: XORの結果と繰り上がりを足し合わせれば最終的な和になるが、`+` は使えない。しかし「2つの数を足す」という同じ問題に帰着するので、再帰的に同じ処理を適用できる
4. **再帰の終了条件を定める**: 繰り上がり `b` がゼロになれば、加算すべき値が残っていないので、そのときの `a` が最終的な和である。これを基底ケースとする
5. **整数のビット幅が有限なので必ず終了する**: 左シフトにより繰り上がりのビットは毎回上位に移動し、32ビット整数の範囲では最大32回の再帰で繰り上がりが必ずゼロになる

## 前提知識

### XOR演算（排他的論理和）とは

2つのビットが異なるとき1、同じとき0を返すビット演算。繰り上がりを無視した加算と同じ結果になる。

```java
int result = 5 ^ 3;   // 0101 ^ 0011 = 0110 → 6
int result2 = 7 ^ 7;  // 0111 ^ 0111 = 0000 → 0（同じ値同士のXORは0）
```

### AND演算とは

2つのビットが両方とも1のときだけ1を返すビット演算。繰り上がりが発生する桁を特定するために使う。

```java
int result = 5 & 3;   // 0101 & 0011 = 0001 → 1
int result2 = 6 & 3;  // 0110 & 0011 = 0010 → 2
```

### 左シフト演算とは

ビット列を指定した数だけ左にずらし、空いた右側のビットを0で埋める演算。1ビット左シフトは値を2倍にする効果がある。繰り上がりは次の桁に影響するため、1ビット左シフトで正しい桁位置に移動させる。

```java
int result = 1 << 1;  // 0001 → 0010 → 2
int result2 = 3 << 1; // 0011 → 0110 → 6
```

### 2進数の加算の仕組み

10進数の筆算と同じように、各桁ごとに加算し、繰り上がりを上の桁に送る。
例: `5 + 3`（`0101 + 0011`）の場合：
- XOR（繰り上がりなしの和）: `0101 ^ 0011 = 0110`（6）
- AND + 左シフト（繰り上がり）: `(0101 & 0011) << 1 = 0001 << 1 = 0010`（2）
- 6と2をさらに同じ方法で足す → `0110 ^ 0010 = 0100`（4）、`(0110 & 0010) << 1 = 0100`（4）
- 4と4をさらに足す → `0100 ^ 0100 = 0000`（0）、`(0100 & 0100) << 1 = 1000`（8）
- 0と8を足す → `0000 ^ 1000 = 1000`（8）、繰り上がりは0 → 終了。結果は **8**

## 計算量

| | 値 |
|---|---|
| Time | O(1) — 32ビット整数では繰り上がりのシフトが最大32回で終了するため、定数回の再帰で完了する |
| Space | O(1) — 再帰の深さも最大32回で定数であり、追加のデータ構造を使用しない |

## コード

```java
// 入力: 2つの整数 a と b
// 出力: a と b の合計値を int で返す
public int getSum(int a, int b) {
    // 基底ケース: 繰り上がり(b)がゼロなら加算すべき値が残っていないので、aが最終的な和である
    if (b == 0) return a;

    // a ^ b: 繰り上がりを無視した各桁の和を求める（XORは「2つのビットが異なるとき1」を返す）
    // (a & b) << 1: 繰り上がりを求める（ANDで「両方1の桁」を特定し、左シフトで次の桁位置に移動）
    // 再帰のたびに繰り上がりのビットは上位に移動し、32ビット整数では最大32回で必ずゼロになる
    return getSum(a ^ b, (a & b) << 1);
}
```
