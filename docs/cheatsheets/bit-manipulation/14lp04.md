# Reversing the Digits of an Integer — 32ビット符号付き整数の各桁を反転する

## 問題の本質

32ビット符号付き整数 `x` が与えられる。`x` の各桁を逆順に並べ替えた整数を返す。反転後の値が32ビット符号付き整数の範囲（-2³¹ ～ 2³¹-1）を超える場合は `0` を返す。

## 核心のアイデア

整数の末尾の桁は `x % 10` で取り出せ、`x / 10` で末尾を除去できる。この「取り出して積み上げる」操作を繰り返すと、自然に桁が逆順になる。積み上げの際に毎回オーバーフローを事前チェックすることで、安全に反転結果を構築できる。

## 思考プロセス

1. **桁を1つずつ取り出す方法**: 整数の末尾の桁は `x % 10`（10で割った余り）で取得できる。取得後に `x / 10` で末尾の桁を除去すれば、次の桁にアクセスできる。この操作を `x` が0になるまで繰り返せば、全ての桁を末尾から順に取り出せる
2. **取り出した桁を逆順に組み立てる方法**: 結果の変数 `result` に対して、`result = result * 10 + digit` を繰り返す。`result * 10` で既存の桁を1つ左にずらし、`+ digit` で新しい桁を1の位に追加する。末尾から取り出した桁を先頭から順に配置することになるため、桁の並びが自然に逆転する
3. **オーバーフローへの対処**: `result * 10 + digit` の計算結果が `Integer.MAX_VALUE`（2147483647）を超えるか、`Integer.MIN_VALUE`（-2147483648）を下回る可能性がある。掛け算を実行した**後**では手遅れなので、掛け算の**前**にチェックする必要がある
4. **オーバーフローの事前チェック方法**: `result * 10` がオーバーフローするかどうかは、`result` を `Integer.MAX_VALUE / 10`（= 214748364）と比較すれば判定できる。`result > 214748364` なら確実にオーバーフローする。`result == 214748364` の場合は、`digit > 7`（MAX_VALUEの1の位）ならオーバーフローする。負の場合も同様に `Integer.MIN_VALUE / 10` と比較する
5. **符号の扱い**: `x % 10` と `x / 10` はJavaでは負の数に対しても正しく動作する（`-123 % 10 == -3`、`-123 / 10 == -12`）。そのため、符号を分離せずにそのまま処理できる
6. **最終的に返すもの**: ループ終了後の `result` が反転された整数である。オーバーフローが検出された場合はループ内で即座に `0` を返す

## 前提知識

### % 演算子（剰余演算子）とは

整数を別の整数で割った余りを返す演算子。`x % 10` は `x` の1の位の数字を取り出す。Javaでは負の数に対しても符号が保持される。

```java
123 % 10;    // → 3（1の位を取得）
-123 % 10;   // → -3（負の数でも符号が保持される）
123 / 10;    // → 12（1の位を除去）
-123 / 10;   // → -12（負の数でも正しく切り捨てられる）
```

### 32ビット符号付き整数の範囲

Javaの `int` 型が表現できる値の範囲。この範囲を超えるとオーバーフローが発生し、不正な値になる。

```java
Integer.MAX_VALUE;   // → 2147483647（2³¹ - 1）
Integer.MIN_VALUE;   // → -2147483648（-2³¹）
Integer.MAX_VALUE / 10;  // → 214748364（オーバーフロー判定の閾値）
Integer.MAX_VALUE % 10;  // → 7（MAX_VALUEの1の位）
Integer.MIN_VALUE / 10;  // → -214748364
Integer.MIN_VALUE % 10;  // → -8（MIN_VALUEの1の位）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — nは `x` の桁数。各桁を1回ずつ処理する |
| Space | O(1) — 変数 `result` と `digit` のみを使用する |

## コード

```java
// 入力: 32ビット符号付き整数 x
// 出力: x の各桁を反転した整数を返す。反転後の値が32ビット範囲を超える場合は 0 を返す
public int reverse(int x) {
    // 反転結果を格納する変数。桁を1つずつ積み上げていく
    int result = 0;

    // xの桁を末尾から1つずつ取り出して処理する。x が 0 になったら全桁処理完了
    while (x != 0) {
        // xの1の位を取り出す。負の数でも % は符号を保持するため特別な処理は不要
        int digit = x % 10;

        // 正のオーバーフローを事前チェックする（掛け算の後では手遅れなので前にチェック）
        // result > 214748364 なら result * 10 は確実に MAX_VALUE(2147483647) を超える
        // result == 214748364 かつ digit > 7 なら result * 10 + digit が MAX_VALUE(末尾が7) を超える
        if (result > Integer.MAX_VALUE / 10
                || (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return 0;
        }

        // 負のオーバーフローを事前チェックする
        // result < -214748364 なら result * 10 は確実に MIN_VALUE(-2147483648) を下回る
        // result == -214748364 かつ digit < -8 なら result * 10 + digit が MIN_VALUE(末尾が-8) を下回る
        if (result < Integer.MIN_VALUE / 10
                || (result == Integer.MIN_VALUE / 10 && digit < -8)) {
            return 0;
        }

        // result * 10 で既存の桁を1つ左にずらし、+ digit で取り出した桁を1の位に追加する
        // これにより元の数の末尾の桁が結果の先頭側に順次配置される
        result = result * 10 + digit;

        // xの1の位を除去し、次の桁を末尾に露出させる
        x = x / 10;
    }

    // 全桁の反転が完了した結果を返す。オーバーフロー時はループ内で既に 0 を返している
    return result;
}
```
