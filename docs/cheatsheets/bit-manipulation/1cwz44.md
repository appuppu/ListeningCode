# Finding the Missing Number in a Sequence — 0〜nの連続した数列から欠けている1つの数を見つける

## 問題の本質

0からnまでの整数のうち、n個の異なる数を含む配列 `nums` が与えられる。この範囲に含まれるが配列には存在しない**1つの欠けた数**を見つけて返す。

## 核心のアイデア

XORは同じ値を2回適用すると打ち消し合ってゼロになる。配列のインデックス（0〜n-1）と値n、そして配列の全要素をすべてXORすれば、ペアになる数は消え、ペアのない「欠けた数」だけが残る。

## 思考プロセス

1. **欠けた数以外はすべてペアになる**: 配列のインデックスは0〜n-1、配列の値も0〜nの範囲から欠けた数を除いたもの。つまりインデックス側に初期値としてnを加えれば、0〜nの全整数がインデックス側に揃う。欠けた数だけが配列の値側に存在しないため、ペアにならない
2. **ペアを打ち消す操作にはXORが最適**: XORには `a ^ a = 0`（同じ値同士で打ち消し合う）と `a ^ 0 = a`（ゼロとのXORは値を保つ）という性質がある。すべてのインデックスと値をXORすれば、ペアになる数はすべて0になり、ペアのない欠けた数だけが残る
3. **初期値をnにする理由**: forループのインデックスは0〜n-1の範囲しかカバーしない。しかし欠けた数はnである可能性もあるので、XORの初期値をnに設定することで、0〜nの全範囲をカバーする
4. **1回のループで完結する**: ループ内で `xor ^= i`（インデックスのXOR）と `xor ^= nums[i]`（値のXOR）を同時に行えば、配列を1回走査するだけで結果が得られる。追加のデータ構造も不要である

## 前提知識

### XOR（排他的論理和）とは

2つのビットが異なるとき1、同じとき0を返すビット演算。Javaでは `^` 演算子で使用する。整数に対してビットごとに適用される。

```java
int a = 5;          // 二進数: 101
int b = 3;          // 二進数: 011
int result = a ^ b; // 二進数: 110 → 6
```

### XOR の重要な性質

アルゴリズムの根幹となる3つの性質がある。

```java
// 性質1: 同じ値のXORは0になる（打ち消し）
5 ^ 5;    // → 0

// 性質2: 0とのXORは元の値を保つ
5 ^ 0;    // → 5

// 性質3: 順序を入れ替えても結果は同じ（交換法則・結合法則）
(2 ^ 5) ^ 2;  // → 5（2同士が打ち消し合い、5が残る）
```

### ^= 演算子とは

XOR演算の結果を左辺の変数に代入する複合代入演算子。`xor ^= i` は `xor = xor ^ i` と同じ意味である。

```java
int xor = 0;
xor ^= 3;   // xor = 0 ^ 3 → 3
xor ^= 3;   // xor = 3 ^ 3 → 0（同じ値で打ち消される）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 追加のデータ構造を使わず、変数1つだけで済む |

## コード

```java
// 入力: 0〜nの範囲からn個の異なる整数を含む配列 nums
// 出力: 範囲内で配列に含まれない1つの整数を返す
public int missingNumber(int[] nums) {
    // 初期値をnにすることで、ループのインデックス0〜n-1と合わせて0〜n全体をカバーする
    // forループのインデックスは0〜n-1しかカバーしないため、nをここで初期値として与える
    int xor = nums.length;

    for (int i = 0; i < nums.length; i++) {
        // インデックスiをXOR累積値に畳み込む
        // ループ終了時にはインデックス0〜n-1のすべてがXORされる（初期値nと合わせて0〜nの全整数がXORされる）
        xor ^= i;
        // 配列の値をXOR累積値に畳み込む
        // 配列に存在する数はインデックス側と値側の両方に現れるため、a ^ a = 0 の性質により打ち消し合う
        xor ^= nums[i];
    }

    // ペアになった数はすべて打ち消されて0になり、配列に存在しなかった欠けた数だけがペアを持たないため残る
    return xor;
}
```
