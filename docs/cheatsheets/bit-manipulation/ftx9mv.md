# Counting the Number of Set Bits — 整数の2進数表現に含まれる1のビット数を数える

## 問題の本質

非負整数 `n` が与えられる。`n` の2進数表現において、値が1であるビットの個数（ハミング重み）を返す。

## 核心のアイデア

`n & (n - 1)` という演算は、`n` の最下位の1ビットを1つだけ消す操作である。この操作を `n` が0になるまで繰り返せば、繰り返し回数がそのまま1のビット数になる。

## 思考プロセス

1. **1のビットだけを効率的に数えたい**: 32ビット全てを走査するのではなく、1のビットが存在する箇所だけを処理できれば、1のビット数 `k` に比例した時間で済む
2. **最下位の1ビットを消す方法を考える**: `n - 1` を計算すると、`n` の最下位の1ビットが0になり、それより下位のビットが全て1に反転する。例えば `n = 1100` のとき `n - 1 = 1011` となる
3. **n AND (n - 1) で最下位の1ビットだけが消える**: `n` と `n - 1` のANDを取ると、最下位の1ビットの位置以下が全て0になり、それより上位のビットはそのまま残る。`1100 & 1011 = 1000` となり、最下位の1ビットが1つ消えた
4. **消す操作を繰り返してカウントする**: `n &= (n - 1)` を繰り返し適用し、`n` が0になるまでの回数をカウントすれば、それが元の `n` に含まれる1のビット数である
5. **ループの終了条件**: 1のビットが全て消えると `n` は0になる。`n != 0` をループ条件にすれば、1のビット数だけループが回って自然に終了する

## 前提知識

### ビットAND演算（&）とは

2つの整数の各ビットを比較し、両方が1のときだけ結果が1になる演算。それ以外の組み合わせでは結果が0になる。

```java
int a = 0b1100;       // 2進数で 1100
int b = 0b1010;       // 2進数で 1010
int result = a & b;   // 結果は 0b1000（両方1の位置だけが1になる）
```

### n & (n - 1) の動作

`n` から1を引くと、最下位の1ビットが0になり、それより下位のビットが全て1に反転する。`n` との ANDを取ると、最下位の1ビット以下が全て0になる。

```java
int n = 0b1100;       // n     = 1100（1のビットが2個）
n &= (n - 1);        // n - 1 = 1011, n = 1100 & 1011 = 1000（1のビットが1個に減った）
n &= (n - 1);        // n - 1 = 0111, n = 1000 & 0111 = 0000（1のビットが0個に減った）
```

### ハミング重み（Hamming Weight）とは

整数の2進数表現に含まれる1のビットの個数のこと。例えば `11` の2進数は `1011` なので、ハミング重みは3である。

## 計算量

| | 値 |
|---|---|
| Time | O(k) — kは `n` に含まれる1のビット数。ループはk回だけ実行される |
| Space | O(1) — カウンター変数1つのみを使用する |

## コード

```java
// 入力: 非負整数 n
// 出力: n の2進数表現に含まれる1のビット数を int で返す
public int hammingWeight(int n) {
    // 1のビットを消した回数を記録するカウンター。消した総回数が最終的な答えになる
    int count = 0;

    // nが0であれば1のビットは残っていないので、ループを終了する
    while (n != 0) {
        // 最下位の1ビットを1つ消す（Brian Kernighan's Trick）
        // n - 1 により最下位の1ビット以下が反転し、n とのANDでその位置以下が全て0になる
        n &= (n - 1);
        // 1のビットを1つ消したので、消した回数を記録する
        count++;
    }
    // countには1のビットを消した総回数、すなわち元のnに含まれていた1のビット数が格納されている
    return count;
}
```
