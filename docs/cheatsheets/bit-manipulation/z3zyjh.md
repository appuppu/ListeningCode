# Finding the Number That Appears Only Once — 配列の中で1つだけ存在する要素を見つける

## 問題の本質

整数の配列 `nums` が与えられる。配列内のすべての要素はちょうど2回ずつ出現するが、1つの要素だけが1回しか出現しない。その**1回だけ出現する要素**を返す。

## 核心のアイデア

XOR演算は「同じ値を2回XORすると0になる」という性質を持つ。配列の全要素をXORすると、2回出現する要素はすべて相殺されて0になり、1回だけ出現する要素だけが残る。

## 思考プロセス

1. **重複ペアを消去できれば答えが残る**: 配列の中で2回出現する要素をすべて取り除ければ、1回だけ出現する要素が得られる。この「ペアの消去」を効率的に行う演算を探す
2. **XORの自己逆元性質を利用する**: XOR演算には `a ^ a = 0` という性質がある。同じ値を2回XORすると結果は0になる。つまり、2回出現する要素は自動的に消去される
3. **XORの単位元と結合法則を利用する**: `a ^ 0 = a`（0とのXORは値を変えない）かつXORは結合法則・交換法則が成り立つ。そのため、要素の出現順序に関係なく、全要素をXORすればペアは消え、ユニークな要素だけが残る
4. **変数1つで累積XORを計算する**: 変数 `result` を0で初期化し、配列を走査しながら各要素をXORしていく。走査が終わった時点で `result` に残っている値が答えである
5. **追加のデータ構造は不要**: HashSetやHashMapを使わずに、整数変数1つだけで解けるため、空間計算量はO(1)になる

## 前提知識

### XOR（排他的論理和）とは

2つのビットが異なるとき1、同じとき0を返すビット演算。Javaでは `^` 演算子で表す。整数に対して使うと、各ビット位置ごとにXORが適用される。

```java
int a = 5;          // 二進数: 101
int b = 3;          // 二進数: 011
int c = a ^ b;      // 二進数: 110 → 6
```

### XOR の重要な性質

XOR演算には以下の3つの性質があり、この問題を解く上ですべてが必要になる。

```java
// 1. 自己逆元: 同じ値を2回XORすると0になる
a ^ a;    // → 0

// 2. 単位元: 0とのXORは元の値を変えない
a ^ 0;    // → a

// 3. 交換法則・結合法則: 順序を入れ替えても結果は同じ
a ^ b ^ a;    // → (a ^ a) ^ b → 0 ^ b → b
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 追加のデータ構造を使わず、整数変数1つだけで済む |

## コード

```java
// 入力: 整数配列 nums（すべての要素が2回出現し、1つの要素だけが1回出現する）
// 出力: 1回だけ出現する要素を int で返す
public int singleNumber(int[] nums) {
    // 累積XORの初期値。0はXORの単位元なので、どの値とXORしても相手の値を変えない
    int result = 0;

    // for-eachループで配列の各要素を先頭から末尾まで1つずつ走査する
    for (int num : nums) {
        // 現在の result と num のXORを計算して result に代入する
        // 2回出現する要素は a ^ a = 0 により相殺され、1回だけ出現する要素のみが蓄積される
        result ^= num;
    }

    // ループ終了後、すべてのペアが相殺された結果として、1回だけ出現する要素の値だけが残っている
    return result;
}
```
