# Reversing the Bits of an Integer — 32ビット符号なし整数のビットを反転する

## 問題の本質

32ビットの符号なし整数が与えられる。そのビット列を左右反転（逆順）にした整数を返す。例えば、入力 `00000000000000000000000000001011` は `11010000000000000000000000000000` になる。

## 核心のアイデア

結果を左に1ビットずつシフトしながら、入力の最下位ビットを1つずつ取り出して結果に追加する。これを32回繰り返せば、入力のビット列が逆順に結果に積み上がる。

## 思考プロセス

1. **ビットの反転は「末尾から取り出して先頭に積む」操作である**: 入力の最下位ビット（右端）を取り出し、結果の最下位ビット（右端）に追加してから結果を左にシフトすれば、最初に取り出したビットが最終的に最上位に移動する。これはビット列の逆順構築にあたる
2. **最下位ビットの取り出し方**: `n & 1` を計算すれば、`n` の最下位ビットだけを取得できる。AND演算で最下位ビット以外をすべて0にマスクする仕組みである
3. **取り出したビットを結果に追加する方法**: `result |= (n & 1)` でOR演算を使えば、resultの最下位ビットに取り出したビットをセットできる。resultの最下位ビットは直前の左シフトで0になっているので、OR演算で正しくセットされる
4. **次のビットに進む方法**: 入力 `n` を `n >>>= 1` で右に1ビットシフトすれば、次のビットが最下位に来る。`>>>` は符号なし右シフトで、最上位に常に0を補填する
5. **結果にスペースを作る方法**: 新しいビットを追加する前に `result <<= 1` で結果を左に1ビットシフトすれば、最下位ビットが0になり、新しいビットを受け入れるスペースができる
6. **32回繰り返せば完成する**: 32ビット整数なので、上記の「左シフト→ビット追加→右シフト」を32回繰り返せば、入力のすべてのビットが逆順で結果に格納される

## 前提知識

### ビットAND演算（&）とは

2つの整数の各ビットを比較し、両方が1のビットだけ1になる演算。特定のビットを取り出す「マスク」として使う。

```java
int n = 0b1011;       // 2進数で1011（10進数で11）
int bit = n & 1;      // 最下位ビットだけを取得 → 1
int bit2 = 0b1010 & 1; // 最下位ビットが0の場合 → 0
```

### ビットOR演算（|=）とは

2つの整数の各ビットを比較し、どちらかが1ならそのビットが1になる演算。特定のビットをセット（1にする）するために使う。

```java
int result = 0b0000;
result |= 1;          // 最下位ビットを1にセット → 0b0001
result |= 0;          // 0とのORは変化なし → 0b0001
```

### 左シフト演算（<<=）とは

ビット列を左に指定した数だけずらす演算。右端には0が補填される。1ビット左シフトは値を2倍にする効果がある。

```java
int result = 0b0011;   // 2進数で11（10進数で3）
result <<= 1;          // 左に1ビットシフト → 0b0110（10進数で6）
```

### 符号なし右シフト演算（>>>=）とは

ビット列を右に指定した数だけずらす演算。左端には常に0が補填される。`>>` と異なり、符号ビットに関係なく0を補填するため、符号なし整数の操作に適している。

```java
int n = 0b1011;        // 2進数で1011
n >>>= 1;              // 右に1ビットシフト → 0b0101（最下位の1が消え、右端に次のビットが来る）
```

## 計算量

| | 値 |
|---|---|
| Time | O(1) — ループは常に32回で固定であり、入力の値に依存しない |
| Space | O(1) — 追加の変数 `result` のみを使用し、入力サイズに依存しない |

## コード

```java
// 入力: 32ビット符号なし整数 n
// 出力: ビット列を逆順にした整数を int で返す
public int reverseBits(int n) {
    // 反転後のビット列を格納する変数。初期値0はすべてのビットが0の状態を意味する
    int result = 0;

    // 32ビット整数のすべてのビットを処理するために32回ループする
    for (int i = 0; i < 32; i++) {
        // resultを左に1ビットシフトして、最下位ビットを0にし新しいビットを受け入れるスペースを作る
        // 注意: 左シフトはビット追加の前に行う。後に行うと最後のビット追加の後に余分なシフトが発生し結果が2倍になってしまう
        result <<= 1;
        // nの最下位ビットを n & 1 で取り出し、OR演算でresultの最下位ビットにセットする
        // 直前の左シフトで最下位ビットは0になっているので、OR演算で正しくセットされる
        result |= (n & 1);
        // nを符号なし右シフトして、次のビットを最下位に移動させる
        // >>> を使うのは、符号ビットに関係なく0を補填する必要があるため
        n >>>= 1;
    }
    // 32回のループ完了後、入力のビット0がresultのビット31に、ビット1がビット30に、と全ビットが逆順で格納されている
    return result;
}
```
