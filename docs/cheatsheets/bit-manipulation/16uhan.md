# Counting Bits for Every Number Up to N — 0からNまでの各整数に含まれる1のビット数を配列で返す

## 問題の本質

非負整数 `n` が与えられる。長さ `n + 1` の配列を返す。配列のインデックス `i` の要素には、`i` を2進数で表したときの **1のビットの個数** を格納する。例: n=5 のとき、0→0, 1→1, 2→1, 3→2, 4→1, 5→2 なので `[0,1,1,2,1,2]` を返す。

## 核心のアイデア

任意の整数 `i` の1のビット数は、`i` を1ビット右にシフトした値 `i >> 1` の1のビット数に、`i` の最下位ビット（`i & 1`）を足したものに等しい。この再帰的関係により、小さい値の結果を再利用して全ての値を O(1) ずつ求められる。

## 思考プロセス

1. **2進数の構造に注目する**: 整数 `i` の2進表現を右に1ビットシフトすると、最下位ビットが消えて残りのビット列は `i / 2`（切り捨て）と同じになる。つまり `i` のビット列は「`i >> 1` のビット列」＋「最下位の1ビット」という構造を持つ
2. **1のビット数を分解できる**: 上記の構造から、`i` に含まれる1の個数は「`i >> 1` に含まれる1の個数」＋「最下位ビットが1かどうか（0か1）」に分解できる。これを式にすると `countBits(i) = countBits(i >> 1) + (i & 1)` となる
3. **小さい値から順に計算すれば再利用できる**: `i >> 1` は常に `i` より小さい値なので、`i = 0` から順に計算していけば、`result[i >> 1]` は必ず計算済みである。この性質により再帰ではなくループで前から順に埋められる
4. **結果配列自体がDPテーブルになる**: 返却する配列 `result` をそのままDPテーブルとして使う。`result[0] = 0` を基底ケースとし、`i = 1` から `n` まで `result[i] = result[i >> 1] + (i & 1)` で埋めていく。追加のデータ構造は不要である

## 前提知識

### 右シフト演算（`>>` ）とは

整数の2進表現を右に指定ビット数だけずらす演算。右に1ビットシフトすると、最下位ビットが消え、値は2で割った商（切り捨て）になる。

```java
int a = 6;      // 2進数: 110
int b = a >> 1;  // 2進数: 011 → 値は3（6 ÷ 2 = 3）

int c = 7;      // 2進数: 111
int d = c >> 1;  // 2進数: 011 → 値は3（7 ÷ 2 = 3、端数切り捨て）
```

### ビットAND演算（`&`）とは

2つの整数の各ビットを比較し、両方が1のビットだけ1にする演算。`i & 1` は `i` の最下位ビットだけを取り出す操作であり、`i` が奇数なら1、偶数なら0を返す。

```java
int a = 5;       // 2進数: 101
int b = a & 1;   // 2進数: 001 → 値は1（奇数なので最下位ビットは1）

int c = 4;       // 2進数: 100
int d = c & 1;   // 2進数: 000 → 値は0（偶数なので最下位ビットは0）
```

### 動的計画法（DP）とは

大きな問題を小さな部分問題に分割し、部分問題の結果を配列に記録して再利用する手法。この問題では、`result[i >> 1]`（すでに計算済みの小さい値の結果）を利用して `result[i]` を O(1) で求める。

```java
int[] result = new int[n + 1];  // DPテーブル兼結果配列を作成
result[0] = 0;                  // 基底ケース: 0の1のビット数は0
result[i] = result[i >> 1] + (i & 1);  // 遷移式: 既知の結果を再利用
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 1からnまでの各値に対してビットシフトとAND演算をそれぞれ1回ずつ行うだけで済む |
| Space | O(n) — 結果を格納する長さn+1の配列を使用する（出力そのものなので追加空間はO(1)とも解釈できる） |

## コード

```java
// 入力: 非負整数 n
// 出力: 長さ n+1 の int[]。各 result[i] には i の2進表現に含まれる1のビット数を格納する
public int[] countBits(int n) {
    // DPテーブル兼結果配列を作成。new int[n+1] で全要素が0に初期化されるため、
    // result[0] = 0（0の1のビット数は0）は自動的に満たされる
    int[] result = new int[n + 1];

    // i=0 は既に0で正しいので、i=1 から走査を開始する
    for (int i = 1; i <= n; i++) {
        // result[i >> 1]: i を1ビット右シフトした値の1のビット数（i >> 1 は常に i より小さいため計算済み）
        // i & 1: i の最下位ビット（奇数なら1、偶数なら0）
        // この2つを足すと、i の2進表現に含まれる1の総数が求まる
        result[i] = result[i >> 1] + (i & 1);
    }
    // 配列の各要素 result[i] にインデックス i の1のビット数が格納された状態で返す
    return result;
}
```
