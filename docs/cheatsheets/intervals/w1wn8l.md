# Finding the Minimum Removals for Non-Overlapping Intervals — 重複しない区間にするために取り除く区間の最小数を求める

## 問題の本質

区間の配列 `intervals`（各区間は `[start, end]` のペア）が与えられる。残った区間同士が重複しないようにするために、**取り除く区間の最小数**を返す。

## 核心のアイデア

区間を終了時刻でソートし、終了が早い区間を優先的に残せば、後続の区間と重複する可能性が最小になる。重複が発生したら、終了が遅い方（＝現在の区間）を取り除くことで、取り除く数を最小化できる。

## 思考プロセス

1. **重複を減らすには「場所を取らない」区間を優先して残す**: 終了時刻が早い区間ほど、後ろに空きスペースが多く残り、後続の区間と重複しにくい。したがって、区間を終了時刻の昇順でソートし、終了が早い順に貪欲に選ぶのが最適である
2. **ソート後、直前に残した区間の終了時刻だけを追跡すればよい**: 終了時刻でソートしているため、残した区間のうち最後の1つの終了時刻 `lastEnd` だけを記憶しておけば、次の区間が重複するかを判定できる。次の区間の開始時刻が `lastEnd` より小さければ重複している
3. **重複した場合は現在の区間を取り除く**: 重複が発生したとき、直前に残した区間と現在の区間のどちらを取り除くべきか。終了時刻でソート済みなので、現在の区間の終了時刻は直前の区間の終了時刻以上である。終了が遅い現在の区間を取り除く方が、後続への影響が小さい。そのため `removals` をインクリメントし、`lastEnd` は更新しない
4. **重複しない場合は現在の区間を残す**: 現在の区間の開始時刻が `lastEnd` 以上であれば重複しないので、この区間を残す。`lastEnd` を現在の区間の終了時刻に更新する
5. **最終的に返すもの**: ループ終了後、`removals`（取り除いた区間の数）を返す

## 前提知識

### Arrays.sort のカスタムコンパレータ

`Arrays.sort` の第2引数にラムダ式を渡すことで、ソート基準をカスタマイズできる。`(a, b) -> a[1] - b[1]` は、各区間の終了時刻（インデックス1の要素）を基準に昇順ソートする。

```java
int[][] intervals = {{1,3}, {2,4}, {0,2}};
Arrays.sort(intervals, (a, b) -> a[1] - b[1]);
// 結果: {{0,2}, {1,3}, {2,4}} — 終了時刻が早い順に並ぶ
```

### 貪欲法（Greedy）とは

各ステップで「その時点で最も良い選択」を行い、全体の最適解を導く手法。この問題では「終了時刻が最も早い区間を優先的に残す」という局所的な選択が、全体として取り除く数の最小化につながる。

```java
// 貪欲法の典型パターン: ソートしてから先頭から順に最適な選択を行う
Arrays.sort(data, comparator);  // 基準でソート
for (int i = 0; i < data.length; i++) {
    // 条件を満たすなら選択、満たさないならスキップ
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n log n) — ソートにO(n log n)、走査にO(n)がかかり、ソートが支配的である |
| Space | O(1) — ソートの内部領域を除き、追加のデータ構造を使用しない |

## コード

```java
// 入力: 区間の配列 int[][] intervals（各要素は [start, end]）
// 出力: 重複をなくすために取り除く区間の最小数を int で返す
int eraseOverlapIntervals(int[][] intervals) {
    // 区間が0個なら取り除く必要なし
    if (intervals.length == 0)
        return 0;

    // 終了時刻の昇順でソートする（終了が早い区間を優先的に残すため）
    // 貪欲法: 終了が早い区間ほど後続と重複しにくいので、先に残す方が最適
    Arrays.sort(intervals, (a, b) -> a[1] - b[1]);

    // 取り除いた区間の数を記録する変数
    int removals = 0;
    // ソート後の最初の区間は常に残す（終了が最も早いため）。その終了時刻を記録する
    int lastEnd = intervals[0][1];

    // インデックス1から走査する（0番目は既に残す区間として確定済み）
    for (int i = 1; i < intervals.length; i++) {
        // 現在の区間の開始時刻が lastEnd より小さければ、直前に残した区間と重複している
        if (intervals[i][0] < lastEnd) {
            // 現在の区間を取り除く。終了時刻でソート済みなので現在の区間の終了は lastEnd 以上であり、
            // 終了が遅い現在の区間を取り除く方が後続との重複を減らせる。lastEnd は更新しない
            removals++;
        } else {
            // 重複しないので現在の区間を残し、lastEnd を現在の区間の終了時刻に更新する
            // 次の区間との重複判定はこの新しい lastEnd を基準に行う
            lastEnd = intervals[i][1];
        }
    }
    // removals が重複をなくすために取り除く必要がある区間の最小数
    return removals;
}
```
