# Finding the Smallest Interval Containing Each Query — 各クエリを含む最小の区間を見つける

## 問題の本質

2D整数配列 `intervals`（各要素は `[left, right]`）と整数配列 `queries` が与えられる。各クエリの値を含む区間のうち、**サイズが最小のもの**を見つける。区間のサイズは `right - left + 1` で定義される。クエリを含む区間が存在しない場合は `-1` を返す。

## 核心のアイデア

クエリと区間を両方ソートし、クエリ値の小さい順に処理することで、各クエリに対して「左端がクエリ以下の区間」を順次Min-Heapに追加できる。Min-Heapからサイズが最小かつ右端がクエリ以上の区間を取り出せば、それが答えになる。

## 思考プロセス

1. **各クエリに対して全区間を調べるのは非効率**: 各クエリについて全区間を走査するとO(n×q)かかる。クエリと区間の両方をソートすれば、区間の追加処理を全クエリで共有でき、重複する走査を排除できる
2. **クエリを昇順に処理すると区間の追加が単調になる**: 区間を左端でソートし、クエリを値の昇順でソートすると、クエリ値が増えるたびに「左端がクエリ以下」の条件を満たす区間が増えるだけで減ることはない。つまり区間の追加はポインタを進めるだけの単調操作になる
3. **追加した区間の中から最小サイズを高速に取得したい**: 候補区間の中からサイズが最小のものを取り出す操作には、Min-Heap（最小ヒープ）が適している。ヒープのキーを区間サイズにすれば、peek操作でO(1)で最小サイズの区間を取得できる
4. **右端がクエリ値より小さい区間は無効**: ヒープに残っている区間の中で、右端がクエリ値より小さいものはそのクエリを含まない。これらの区間はヒープの先頭から順にpollして除去する。一度除去した区間は以降のクエリでも無効（クエリ値は増加するため）なので、再追加の必要はない
5. **クエリの元の順序を保持する必要がある**: クエリをソートして処理するが、結果は元の順序で返す必要がある。そのためソート前に各クエリの元のインデックスをペアとして保持し、結果配列の対応する位置に答えを書き込む
6. **ヒープが空ならそのクエリを含む区間は存在しない**: 無効な区間を除去した後にヒープが空であれば、そのクエリを含む区間は存在しないので `-1` を結果に格納する

## 前提知識

### PriorityQueue（Min-Heap）とは

要素を優先度順に管理するデータ構造。デフォルトでは最小値が先頭に来る（Min-Heap）。要素の追加と取り出しがO(log n)、先頭の参照がO(1)でできる。

```java
// int[]を格納し、配列の0番目の要素（サイズ）で昇順に並べるMin-Heap
PriorityQueue<int[]> heap = new PriorityQueue<>((a, b) -> a[0] - b[0]);
heap.offer(new int[]{5, 10});  // 要素を追加する
heap.peek();                    // 先頭要素を取り出さずに参照する → {5, 10}
heap.poll();                    // 先頭要素を取り出して削除する → {5, 10}
heap.isEmpty();                 // ヒープが空かを判定する → true
```

### オフラインクエリとは

クエリを到着順ではなく、処理に都合の良い順番に並べ替えてから処理する手法。結果は元のインデックスを使って正しい位置に書き戻す。クエリ間に依存関係がない場合に有効。

```java
int q = queries.length;
int[][] sortedQ = new int[q][2];
for (int i = 0; i < q; i++) {
    sortedQ[i] = new int[]{queries[i], i};  // {クエリ値, 元のインデックス} のペアを作る
}
Arrays.sort(sortedQ, (a, b) -> a[0] - b[0]);  // クエリ値の昇順でソートする
```

### Arrays.sort のカスタムコンパレータ

2D配列やオブジェクト配列を任意の基準でソートする。ラムダ式 `(a, b) -> a[0] - b[0]` は、各要素の0番目の値で昇順にソートすることを意味する。

```java
int[][] intervals = {{3, 6}, {1, 4}, {2, 8}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 左端の昇順でソートする → {{1,4}, {2,8}, {3,6}}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n log n + q log q) — 区間のソートにO(n log n)、クエリのソートにO(q log q)、ヒープ操作は各区間が最大1回追加・1回削除されるのでO(n log n) |
| Space | O(n + q) — ヒープに最大n個の区間、ソート済みクエリ配列にq個の要素を保存する |

## コード

```java
// 入力: 2D整数配列 intervals（各要素は [left, right]）と整数配列 queries
// 出力: 各クエリを含む最小サイズの区間のサイズを格納した int[] を返す。含む区間がなければ -1 を格納する
public int[] minInterval(int[][] intervals, int[] queries) {
    // 区間を左端の昇順でソートする。こうすることでポインタ j を前に進めるだけで「左端がクエリ値以下の区間」を漏れなく追加できる
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    int q = queries.length;
    // 各クエリに元のインデックスを付与してペアにする。ソート後も結果を正しい位置に書き戻すために必要
    int[][] sortedQ = new int[q][2];
    for (int i = 0; i < q; i++) {
        sortedQ[i] = new int[]{queries[i], i};
    }
    // クエリ値の昇順でソートする。昇順に処理することで区間追加が単調操作になる
    Arrays.sort(sortedQ, (a, b) -> a[0] - b[0]);

    // {区間サイズ, 右端} を保持し、サイズの昇順で取り出すMin-Heap。サイズをキーにすることで最小サイズの区間をO(1)で参照できる
    PriorityQueue<int[]> heap =
        new PriorityQueue<>((a, b) -> a[0] - b[0]);

    int[] res = new int[q];
    int j = 0;  // 区間配列を走査するポインタ。全クエリを通じて前にしか進まないので、区間追加の合計はO(n)

    for (int[] sq : sortedQ) {
        int val = sq[0], idx = sq[1];  // val=クエリ値、idx=元のインデックス

        // 左端がクエリ値以下の区間をすべてヒープに追加する。j は戻らないので全体でO(n)
        while (j < intervals.length && intervals[j][0] <= val) {
            int sz = intervals[j][1] - intervals[j][0] + 1;  // 区間サイズ = right - left + 1
            heap.offer(new int[]{sz, intervals[j][1]});  // {サイズ, 右端} をヒープに追加
            j++;
        }

        // 右端がクエリ値より小さい（クエリを含まない）区間を除去する。クエリ値は昇順に増加するため、一度除去した区間は以降も無効
        while (!heap.isEmpty() && heap.peek()[1] < val) {
            heap.poll();
        }

        // ヒープが空なら含む区間なし、そうでなければ先頭の区間サイズが答え（無効な区間は除去済みなので先頭が最小かつ有効）
        res[idx] = heap.isEmpty() ? -1 : heap.peek()[0];
    }
    return res;
}
```
