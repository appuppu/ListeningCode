# Finding the Minimum Meeting Rooms Required — 全会議を衝突なく開催するために必要な最小の会議室数を求める

## 問題の本質

会議の時間帯（開始時刻と終了時刻）の配列が与えられる。すべての会議を衝突なく開催するために必要な**最小の会議室数**を返す。同じ時間帯に重なっている会議はそれぞれ別の会議室を使う必要がある。

## 核心のアイデア

会議の開始と終了を別々のイベントとして時系列順に処理すれば、ある瞬間に同時に行われている会議の最大数が求まる。その最大数が必要な会議室数である。

## 思考プロセス

1. **同時進行の会議数が答えになる**: ある瞬間に同時に進行している会議の最大数 = 必要な会議室数である。問題は「同時進行数の最大値」を効率的に求めることに帰着する
2. **開始と終了を別々のイベントとして扱う**: 会議の開始時に部屋が1つ必要になり、終了時に部屋が1つ空く。開始と終了を分離してそれぞれソートすれば、時系列順にイベントを処理できる
3. **2つのソート済み配列をスイープする**: starts配列とends配列をそれぞれソートし、startsを先頭から走査する。各開始時刻について「最も早い終了時刻より前か」を判定すれば、部屋が必要か空くかがわかる
4. **2ポインタで同時進行数を追跡する**: starts配列のポインタ `i` とends配列のポインタ `endPtr` を用意する。`starts[i] < ends[endPtr]` なら新しい会議が既存の会議と重なるので部屋を追加する。そうでなければ1つの会議が終了して部屋が空くので `endPtr` を進める
5. **最大値を記録する**: 走査の過程で `rooms` の最大値を `maxRooms` に記録し続ける。走査完了後に `maxRooms` を返す

## 前提知識

### Arrays.sort とは

配列を昇順にソートするJavaの標準メソッド。プリミティブ型配列に対してはデュアルピボットクイックソート（O(n log n)）を使用する。

```java
int[] arr = {5, 2, 8, 1};
Arrays.sort(arr);        // arr は {1, 2, 5, 8} になる
```

### 2ポインタ（Two Pointer）とは

2つのインデックス変数を使い、それぞれ独立に配列を走査するテクニック。ソート済み配列に対して使うことで、2つの配列の要素を効率的に比較・マージできる。

```java
int i = 0;          // 1つ目の配列用ポインタ
int endPtr = 0;     // 2つ目の配列用ポインタ
// 条件に応じてどちらのポインタを進めるかを決める
```

### イベントスイープ（Event Sweep）とは

時間軸上のイベント（開始・終了）を時系列順に処理し、ある時点での状態（同時進行数など）を追跡する手法。開始イベントでカウンタを増やし、終了イベントでカウンタを減らすことで、任意の瞬間の同時進行数がわかる。

## 計算量

| | 値 |
|---|---|
| Time | O(n log n) — 2つの配列のソートが支配的 |
| Space | O(n) — 開始時刻と終了時刻を格納する2つの配列を作成する |

## コード

```java
// 入力: 会議の時間帯を表す2次元整数配列 intervals（各要素は [start, end]）
// 出力: すべての会議を衝突なく開催するために必要な最小の会議室数を int で返す
public int minMeetingRooms(int[][] intervals) {
    // 入力が null または空の場合、会議が存在しないので 0 を返す
    if (intervals == null || intervals.length == 0)
        return 0;

    int n = intervals.length;
    // 開始と終了を分離することで、それぞれ独立にソートできるようになる
    int[] starts = new int[n];  // 開始時刻を格納する配列
    int[] ends = new int[n];    // 終了時刻を格納する配列

    // intervals を走査し、開始時刻と終了時刻を別々の配列に格納する
    for (int i = 0; i < n; i++) {
        starts[i] = intervals[i][0];
        ends[i] = intervals[i][1];
    }

    // 両配列を昇順にソートし、時系列順にイベントを処理する準備を整える
    Arrays.sort(starts);
    Arrays.sort(ends);

    int rooms = 0, maxRooms = 0;
    // ends配列のポインタ。最も早く終わる会議を指す
    int endPtr = 0;

    // starts 配列を先頭から走査する。各イテレーションは「新しい会議が始まる」イベントを表す
    for (int i = 0; i < n; i++) {
        if (starts[i] < ends[endPtr]) {
            // 現在始まる会議の開始時刻が、最も早く終わる会議の終了時刻より前 → 重なりが発生するので新しい部屋を割り当てる
            rooms++;
        } else {
            // 最も早く終わる会議が既に終了しているので、その部屋を再利用できる。部屋数は増やさず endPtr を進めて次に早く終わる会議を指す
            endPtr++;
        }
        // 同時使用の最大部屋数を更新する
        maxRooms = Math.max(maxRooms, rooms);
    }
    // maxRooms が同時に使用された部屋数の最大値であり、必要な最小会議室数である
    return maxRooms;
}
```
