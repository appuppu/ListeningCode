# Determining if All Meetings Can Be Attended — 全ての会議に出席できるかを判定する

## 問題の本質

会議の時間帯を表す区間（開始時刻と終了時刻のペア）の配列 `intervals` が与えられる。1人の人が**全ての会議に出席できるか**を判定し、`boolean` で返す。ある会議が別の会議の終了前に始まる場合、2つの会議は競合（重複）しており、全てには出席できない。

## 核心のアイデア

区間を開始時刻でソートすれば、重複が起こりうるのは隣接する区間同士だけになる。隣接ペアを順に比較し、次の区間の開始時刻が前の区間の終了時刻より前かを確認するだけで、全体の重複判定ができる。

## 思考プロセス

1. **重複の条件を整理する**: 2つの区間が重複するとは、一方の開始時刻が他方の終了時刻より前であることを意味する。しかし、区間がバラバラの順番だと、全ペアを比較する必要がありO(n²)になる
2. **ソートで比較対象を限定する**: 区間を開始時刻の昇順でソートすると、重複が発生するのは隣接する区間同士に限られる。なぜなら、`intervals[i]` と `intervals[i+2]` が重複するなら、必ず `intervals[i]` と `intervals[i+1]` も重複するからである
3. **隣接ペアの重複判定**: ソート後、`intervals[i]` の開始時刻が `intervals[i-1]` の終了時刻より前であれば、2つの会議は重複している。この条件は `intervals[i][0] < intervals[i-1][1]` で表現できる
4. **1つでも重複があれば即座に結果が決まる**: 重複が1組でも見つかれば、全ての会議には出席できないので `false` を返す。全ての隣接ペアを確認して重複がなければ `true` を返す

## 前提知識

### Arrays.sort とカスタムComparator

`Arrays.sort` は配列をソートするメソッド。2次元配列の場合、ラムダ式でComparator（比較関数）を指定して、どの要素を基準にソートするかを制御できる。

```java
int[][] intervals = {{7, 10}, {2, 4}, {5, 8}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 各区間の開始時刻（[0]）で昇順ソート
// 結果: {{2, 4}, {5, 8}, {7, 10}}
```

`(a, b) -> a[0] - b[0]` は2つの区間 `a` と `b` を受け取り、開始時刻の差を返す。差が負なら `a` が先、正なら `b` が先に並ぶ。

### 区間の重複判定

2つの区間が開始時刻でソート済みのとき、後の区間の開始が前の区間の終了より前なら重複している。

```java
int[] prev = {2, 4};   // 2時〜4時の会議
int[] curr = {3, 6};   // 3時〜6時の会議
curr[0] < prev[1];     // 3 < 4 → true → 重複している
```

## 計算量

| | 値 |
|---|---|
| Time | O(n log n) — ソートがO(n log n)、隣接ペアの走査がO(n)で、ソートが支配的 |
| Space | O(1) — ソートは入力配列を直接並び替えるため、追加の配列を使わない |

## コード

```java
// 入力: 会議の時間帯を表す2次元整数配列 intervals（各要素は [開始時刻, 終了時刻]）
// 出力: 全ての会議に出席できるなら true、重複する会議があるなら false
public boolean canAttendMeetings(int[][] intervals) {
    // 開始時刻の昇順で区間をソートする
    // ラムダ式 (a, b) -> a[0] - b[0] をComparatorとして渡す
    // これにより、時間順に並んだ区間に対して隣接ペアだけを比較すれば十分になる
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // i = 0 ではなく i = 1 から始める。各ステップで intervals[i] と intervals[i-1] の隣接ペアを比較するため
    for (int i = 1; i < intervals.length; i++) {
        // 現在の会議の開始時刻が、直前の会議の終了時刻より前なら重複
        if (intervals[i][0] < intervals[i - 1][1]) {
            // 1組でも重複があれば全会議には出席できないので、即座に false を返す
            return false;
        }
        // 重複がなければ次の隣接ペアへ進む
    }
    // ループが最後まで完了した場合、どの隣接ペアにも重複がなかったので true を返す
    return true;
}
```
