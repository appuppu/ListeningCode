# Merging Overlapping Intervals — 重なり合う区間をすべて統合する

## 問題の本質

区間（開始値と終了値のペア）の配列 `intervals` が与えられる。重なり合う区間をすべて統合（マージ）し、重なりのない区間のリストを返す。

## 核心のアイデア

区間を開始値でソートすれば、重なる可能性があるのは隣り合う区間だけになる。ソート後に前から順に走査し、現在の区間が直前の区間と重なっていれば終了値を更新し、重なっていなければ新しい区間として追加する。

## 思考プロセス

1. **重なりの判定を単純化したい**: 区間がソートされていなければ、すべてのペアを比較する必要がある。開始値で昇順にソートすれば、重なりの判定は「直前の区間の終了値 ≥ 現在の区間の開始値」だけで済む
2. **ソート後は1回の走査で統合できる**: ソート済みの区間を先頭から順に見ていく。結果リストの末尾の区間と現在の区間を比較し、重なっていれば終了値を大きい方に更新する。重なっていなければ現在の区間をそのまま結果リストに追加する
3. **結果リストの末尾へのアクセスが必要**: 統合の判定では常に結果リストの「最後に追加した区間」の終了値を参照する。LinkedListを使えば `getLast()` でO(1)で末尾にアクセスできる
4. **重なりの条件を正確に定義する**: 直前の区間の終了値が現在の区間の開始値より小さい（`res.getLast()[1] < interval[0]`）とき、2つの区間は重なっていない。それ以外のとき（終了値 ≥ 開始値）は重なっているので統合する
5. **統合時は終了値だけを更新する**: 開始値はソート済みなので直前の区間の方が必ず小さいか等しい。終了値は2つの区間のうち大きい方を採用する。`Math.max()` で直前の終了値と現在の終了値を比較する
6. **最終的に返すもの**: 結果リストに蓄積された非重複区間をすべて `int[][]` の二次元配列に変換して返す

## 前提知識

### Arrays.sort とカスタムComparator

`Arrays.sort` は配列をソートするメソッド。二次元配列の場合、ラムダ式でComparatorを指定して、どの要素を基準にソートするかを定義する。

```java
int[][] intervals = {{3, 6}, {1, 3}, {2, 5}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // 各区間の開始値（index 0）で昇順ソート
// 結果: {{1, 3}, {2, 5}, {3, 6}}
```

### LinkedList とは

先頭・末尾への追加や末尾の取得がO(1)でできるリスト。ArrayListと異なり、`getLast()` メソッドで末尾要素に直接アクセスできる。

```java
LinkedList<int[]> res = new LinkedList<>();  // 空のLinkedListを作成
res.add(new int[]{1, 3});   // 末尾に要素を追加する
res.getLast();               // 末尾の要素を取得する → {1, 3}
res.getLast()[1] = 5;        // 末尾の要素の終了値を直接書き換える → {1, 5}
res.isEmpty();               // リストが空かどうかをbooleanで返す → false
res.size();                  // リストの要素数を返す → 1
```

### Math.max とは

2つの値のうち大きい方を返すメソッド。区間の統合では、2つの終了値のうち大きい方を採用するために使用する。

```java
Math.max(5, 8);   // → 8
Math.max(10, 3);  // → 10
```

## 計算量

| | 値 |
|---|---|
| Time | O(n log n) — ソートがO(n log n)、走査がO(n)なので、全体はO(n log n) |
| Space | O(n) — 結果リストに最大n個の区間を保存する |

## コード

```java
// 入力: 区間の二次元配列 int[][] intervals（各要素は [開始値, 終了値]）
// 出力: 重なり合う区間を統合した後の二次元配列 int[][] を返す
public int[][] merge(int[][] intervals) {
    // ソートすることで、重なりの判定を隣り合う区間の比較だけに限定できる
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // 統合済みの区間を蓄積する結果リスト
    // LinkedListを使う理由は、末尾要素への参照と更新をO(1)で行うため
    LinkedList<int[]> res = new LinkedList<>();

    for (int[] interval : intervals) {
        // resが空なら最初の区間なので無条件に追加する
        // res.getLast()[1] < interval[0] なら直前の区間と重なっていないのでそのまま追加する
        if (res.isEmpty() || res.getLast()[1] < interval[0]) {
            res.add(interval);
        } else {
            // 重なっている場合、終了値を大きい方に更新して統合する
            // 開始値はソート済みのため直前の区間の方が小さいか等しいので変更不要
            res.getLast()[1] = Math.max(res.getLast()[1], interval[1]);
        }
    }

    // 結果リストを二次元配列に変換して返す
    return res.toArray(new int[res.size()][]);
}
```
