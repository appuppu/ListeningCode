# Counting Combinations to Make a Target Amount — コインの組み合わせでターゲット金額を作る方法の数を数える

## 問題の本質

コインの額面が入った配列 `coins` と整数 `amount` が与えられる。`coins` の中のコインを何枚でも繰り返し使って、合計がちょうど `amount` になる**組み合わせの数**を返す。組み合わせが異なるとは、少なくとも1つの額面の使用枚数が異なることを意味する。順序が異なるだけのものは同じ組み合わせとして扱う。

## 核心のアイデア

コインを1種類ずつ順番に処理し、各コインについて「そのコインを0枚以上使う場合の組み合わせ数」をDP配列に累積していく。コインの種類ごとに外側ループを回すことで、同じコインの集合を異なる順序で数える重複（順列）を自然に排除できる。

## 思考プロセス

1. **組み合わせと順列の違いを意識する**: この問題は「組み合わせの数」を求めるので、[1,2] と [2,1] は同じものとして数える必要がある。金額を外側ループにしてコインを内側で選ぶと順列を数えてしまうため、コインの種類を外側ループにして処理順序を固定する必要がある
2. **DPの状態を定義する**: `dp[a]` を「金額 `a` をちょうど作る組み合わせの数」と定義する。最終的に `dp[amount]` が答えになる
3. **基底条件を決める**: 金額0を作る方法は「どのコインも使わない」という1通りなので、`dp[0] = 1` とする。この基底がないと、どのコインを使っても組み合わせ数が0のまま加算されず、答えが常に0になってしまう
4. **遷移式を導く**: あるコイン `coin` を少なくとも1枚使って金額 `a` を作るには、残りの金額 `a - coin` の組み合わせ数を加算すればよい。つまり `dp[a] += dp[a - coin]` が遷移式になる。`dp[a - coin]` には既に同じコインを0枚以上使った組み合わせ数が含まれているため、この加算で「coinを1枚、2枚、…」と使うケースが自動的に網羅される
5. **ループの順序を決める**: 外側ループでコインの種類を1つずつ処理し、内側ループで金額 `a` を `coin` から `amount` まで昇順に走査する。こうすると、各コインは「前のコイン種類までの組み合わせ数」に自分の寄与を加算する形になり、順列の重複カウントが起きない
6. **最終的に返すもの**: すべてのコインを処理し終えた後の `dp[amount]` が、ターゲット金額を作る組み合わせの総数である

## 前提知識

### DP配列（動的計画法の1次元配列）とは

部分問題の答えを配列に保存し、それを再利用して大きな問題の答えを効率的に求める手法。この問題では `dp[a]` が「金額 `a` を作る組み合わせの数」を表す。

```java
int[] dp = new int[amount + 1];  // インデックス0〜amountの配列を作成（初期値はすべて0）
dp[0] = 1;                       // 基底条件: 金額0を作る方法は1通り
dp[a] += dp[a - coin];           // 遷移: 金額aの組み合わせ数に、coinを1枚使った残りの組み合わせ数を加算
```

### 外側ループをコインにする理由

金額を外側・コインを内側にすると、金額5を作るとき [1,2,2] と [2,1,2] と [2,2,1] を別々に数えてしまう（順列）。コインを外側にすると、コイン1の処理が完了してからコイン2を処理するため、「コイン1→コイン2」の順序が固定され、組み合わせのみを数えられる。

```java
// 組み合わせを数える（正しい順序）
for (int coin : coins) {          // 外側: コインの種類ごとに処理
    for (int a = coin; a <= amount; a++) {  // 内側: 金額を走査
        dp[a] += dp[a - coin];
    }
}

// 順列を数えてしまう（誤った順序）
for (int a = 1; a <= amount; a++) {         // 外側: 金額ごとに処理
    for (int coin : coins) {                // 内側: 全コインを試す
        if (a >= coin) dp[a] += dp[a - coin];
    }
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n × amount) — n種類のコインそれぞれについて、金額0〜amountを走査する |
| Space | O(amount) — サイズ amount+1 のDP配列を1つだけ使用する |

## コード

```java
// 入力: コインの額面を格納した整数配列 coins と、ターゲット金額の整数 amount
// 出力: 合計がちょうど amount になるコインの組み合わせの数を int で返す
public int change(int amount, int[] coins) {
    // dp[a] = 金額aをちょうど作る組み合わせの数
    // サイズは amount + 1（インデックス0からamountまでの各金額に対応するため）
    int[] dp = new int[amount + 1];

    // 基底条件: 金額0を作る方法は「何も選ばない」の1通り
    // この基底がないと遷移で加算する元の値が常に0になり、すべての結果が0になる
    dp[0] = 1;

    // コインの種類ごとに処理（外側ループで順序を固定し、組み合わせのみを数える）
    // コインの種類を外側ループにすることで、同じコインの集合を異なる順番で数える重複（順列）を防ぐ
    for (int coin : coins) {
        // 金額coinからamountまで昇順に走査する
        // coinから開始するのは a - coin が0以上である必要があるため
        // 昇順に走査することで、同じコインを複数枚使うケースが自然に反映される
        for (int a = coin; a <= amount; a++) {
            // coinを1枚使い、残りa-coinの組み合わせ数を加算する
            // dp[a - coin] には同じコインを0枚以上使った組み合わせ数が既に含まれているため、
            // この1行で「coinを1枚、2枚、3枚…使う」すべてのケースが網羅される
            dp[a] += dp[a - coin];
        }
    }

    // ターゲット金額を作る組み合わせの総数を返す
    return dp[amount];
}
```
