# Finding the Minimum Edits to Transform One String Into Another — 2つの文字列間の最小編集距離を求める

## 問題の本質

2つの文字列 `word1` と `word2` が与えられる。`word1` を `word2` に変換するために必要な**最小の操作回数**を返す。使える操作は「挿入」「削除」「置換」の3つで、それぞれ1回の操作としてカウントする。

## 核心のアイデア

2つの文字列の末尾から比較するとき、現在の文字が一致すれば操作不要で両方進め、不一致なら「挿入・削除・置換」の3操作のうち最小コストのものを選ぶ。この部分問題の重複をDPテーブルで解消し、さらに各セルは現在行と前の行にしか依存しないため、1行分の配列だけで空間を最適化できる。

## 思考プロセス

1. **各位置での選択肢は3つに限られる**: `word1[i]` と `word2[j]` を比較するとき、文字が一致すれば操作なしで `(i+1, j+1)` に進む。不一致なら「挿入（jを進める）」「削除（iを進める）」「置換（両方進める）」の3つから最小コストを選ぶ。この再帰的な構造がDPの適用を示唆する
2. **DPテーブルの定義**: `dp[i][j]` を「`word1[i:]` を `word2[j:]` に変換するための最小操作回数」と定義する。最終的な答えは `dp[0][0]` になる
3. **ベースケースを決める**: `word1` の残りが空（`i == m`）なら `word2[j:]` の残り文字数分の挿入が必要なので `dp[m][j] = n - j`。`word2` の残りが空（`j == n`）なら `word1[i:]` の残り文字数分の削除が必要なので `dp[i][n] = m - i`
4. **ボトムアップで埋める方向を決める**: `dp[i][j]` は `dp[i+1][j+1]`、`dp[i][j+1]`、`dp[i+1][j]` に依存するため、`i` を `m-1` から `0` へ、`j` を `n-1` から `0` へ逆順に埋める
5. **空間を最適化する**: 各行 `i` の計算に必要なのは「前の行（`i+1`）」と「現在の行（`i`）」の2行だけである。そのため2次元配列を持つ必要はなく、1次元配列 `prev`（前の行）と `curr`（現在の行）の2本で十分である。各行の計算が終わったら `prev = curr` で入れ替える
6. **最終的に返すもの**: すべての行を処理した後、`prev[0]` が `dp[0][0]` に相当する値であり、これが `word1` 全体を `word2` 全体に変換する最小操作回数である

## 前提知識

### Edit Distance（編集距離）とは

2つの文字列間の「類似度」を表す指標で、一方を他方に変換するために必要な最小操作回数のこと。Levenshtein距離とも呼ばれる。許可される操作は以下の3つで、それぞれコスト1である。

- **挿入（Insert）**: 文字列に1文字を追加する
- **削除（Delete）**: 文字列から1文字を取り除く
- **置換（Replace）**: 文字列の1文字を別の文字に変更する

### ボトムアップDP（動的計画法）とは

再帰的な部分問題を、小さい問題から順にテーブルに記録しながら解く手法。メモ化再帰（トップダウン）と異なり、再帰呼び出しのオーバーヘッドがなく、空間最適化も適用しやすい。

```java
// 1次元DPの例: フィボナッチ数列を2変数で計算する
int a = 0, b = 1;
for (int i = 2; i <= n; i++) {
    int temp = a + b;  // 現在の値は前の2つだけに依存する
    a = b;             // 古い値を捨てて更新する
    b = temp;
}
```

### Math.min() とは

2つの整数のうち小さい方を返すJavaの標準メソッド。3つ以上の値を比較する場合はネストして使う。

```java
Math.min(3, 5);                    // → 3
Math.min(3, Math.min(5, 1));       // → 1（3つの値の最小値）
```

### String.charAt(int index) とは

文字列の指定位置にある文字を返すメソッド。インデックスは0から始まる。

```java
String s = "abc";
s.charAt(0);  // → 'a'
s.charAt(2);  // → 'c'
```

## 計算量

| | 値 |
|---|---|
| Time | O(m × n) — `word1` の各位置に対して `word2` の全位置を走査する |
| Space | O(n) — 2次元テーブルの代わりに1行分の配列だけを保持する |

## コード

```java
// 入力: 2つの文字列 word1（長さ m）と word2（長さ n）
// 出力: word1 を word2 に変換するための最小操作回数を int で返す
public int minDistance(String w1, String w2) {
    int m = w1.length();  // word1 の長さを取得する
    int n = w2.length();  // word2 の長さを取得する

    // prev配列: DPテーブルの1つ下の行（i+1）に相当する
    // prev[j] = n - j で初期化: word1が空のとき、word2[j:]の残り n-j 文字をすべて挿入する操作回数
    int[] prev = new int[n + 1];
    for (int j = 0; j <= n; j++)
        prev[j] = n - j;

    // word1の末尾から先頭へ逆順に走査する（i は word1 の現在の位置）
    for (int i = m - 1; i >= 0; i--) {
        // curr配列: DPテーブルの現在の行（i）に相当する
        int[] curr = new int[n + 1];
        // word2が空のとき、word1[i:]の残り m-i 文字をすべて削除する操作回数
        curr[n] = m - i;

        // word2の末尾から先頭へ逆順に走査する（j は word2 の現在の位置）
        for (int j = n - 1; j >= 0; j--) {
            if (w1.charAt(i) == w2.charAt(j)) {
                // 文字が一致すれば操作不要。prev[j+1] は両方1文字進めた部分問題 dp[i+1][j+1] の答え
                curr[j] = prev[j + 1];
            } else {
                // 不一致なら3つの操作のうち最小コストを選び、今回の操作1回分（+1）を加える
                curr[j] = 1 + Math.min(
                    curr[j + 1],           // 挿入: word2側で1文字進める（dp[i][j+1]）
                    Math.min(prev[j],      // 削除: word1側で1文字進める（dp[i+1][j]）
                        prev[j + 1]));     // 置換: 両方で1文字進める（dp[i+1][j+1]）
            }
        }
        // 現在の行を前の行として保存し、次のイテレーション（i-1）に備える
        prev = curr;
    }

    // prev[0] が dp[0][0] に相当し、word1全体をword2全体に変換する最小操作回数
    return prev[0];
}
```
