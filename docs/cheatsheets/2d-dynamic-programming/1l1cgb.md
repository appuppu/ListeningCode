# Finding the Longest Common Subsequence — 2つの文字列に共通する最長部分列の長さを求める

## 問題の本質

2つの文字列 `text1` と `text2` が与えられる。両方の文字列に共通する**部分列（subsequence）**のうち、最も長いものの**長さ**を返す。部分列とは、元の文字列から文字を選んで相対的な順序を保ったまま取り出した列であり、連続している必要はない。

## 核心のアイデア

2つの文字列の末尾の文字が一致するなら、その文字はLCSに含まれ、残りの部分問題は両方の文字列を1文字縮めたものになる。一致しないなら、どちらか一方を1文字縮めた2つの部分問題のうち、より長い方を採用する。この再帰構造を2次元テーブルでボトムアップに埋めることで、重複計算なしに最適解が求まる。

## 思考プロセス

1. **部分問題の定義**: `text1` の先頭 `i` 文字と `text2` の先頭 `j` 文字に対するLCSの長さを `dp[i][j]` と定義する。最終的に求めたい答えは `dp[m][n]`（`m` = text1の長さ、`n` = text2の長さ）である
2. **末尾の文字が一致する場合の遷移**: `text1[i-1] == text2[j-1]` のとき、この文字はLCSの一部になる。よって `dp[i][j] = dp[i-1][j-1] + 1` となる。両方の文字列を1文字ずつ縮めた部分問題の答えに1を加える
3. **末尾の文字が一致しない場合の遷移**: `text1[i-1] != text2[j-1]` のとき、少なくとも一方の末尾文字はLCSに含まれない。`text1` を1文字縮めた場合（`dp[i-1][j]`）と `text2` を1文字縮めた場合（`dp[i][j-1]`）の大きい方を採用する。つまり `dp[i][j] = max(dp[i-1][j], dp[i][j-1])` となる
4. **基底条件**: どちらかの文字列が空（長さ0）のとき、共通部分列は存在しないので `dp[0][j] = 0` および `dp[i][0] = 0` となる。Javaで `int[][]` を生成すると全要素が0で初期化されるため、明示的な設定は不要である
5. **テーブルの埋め方**: `dp[i][j]` は `dp[i-1][j-1]`、`dp[i-1][j]`、`dp[i][j-1]` に依存する。したがって `i` を1からm、`j` を1からnへと昇順に埋めれば、参照先は常に計算済みである
6. **最終的に返すもの**: テーブルを全て埋めた後、`dp[m][n]` が2つの文字列全体のLCSの長さであり、これを返す

## 前提知識

### 部分列（Subsequence）とは

文字列から0個以上の文字を削除し、残った文字の相対的な順序を変えずに取り出した列。部分文字列（substring）と異なり、連続している必要はない。

```
文字列: "abcde"
部分列の例: "ace" (a, c, e を選択。b, d を削除)
部分列でない例: "aec" (元の文字列での順序 a→c→e に反している)
```

### 2次元配列の生成と初期化

Javaで `new int[m+1][n+1]` を宣言すると、サイズ `(m+1) × (n+1)` の2次元配列が作られ、全要素が0で初期化される。

```java
int[][] dp = new int[m + 1][n + 1];  // (m+1)行×(n+1)列の配列を作成、全要素0
dp[i][j] = 5;                         // i行j列に値5を代入する
int val = dp[i][j];                    // i行j列の値を取得する → 5
```

### Math.max とは

2つの整数のうち大きい方を返すメソッド。2つの部分問題の解を比較して、より良い方を選択するために使用する。

```java
Math.max(3, 7);    // 2つの値のうち大きい方を返す → 7
Math.max(dp[i-1][j], dp[i][j-1]);  // 2つのセルの値を比較して大きい方を返す
```

### charAt とは

文字列の指定した位置の文字を返すメソッド。インデックスは0始まりである。

```java
String s = "abc";
s.charAt(0);    // インデックス0の文字を返す → 'a'
s.charAt(2);    // インデックス2の文字を返す → 'c'
```

## 計算量

| | 値 |
|---|---|
| Time | O(m × n) — m×nのテーブルの各セルを1回ずつ埋める |
| Space | O(m × n) — サイズ(m+1)×(n+1)の2次元配列を使用する |

## コード

```java
// 入力: 2つの文字列 text1 と text2
// 出力: 2つの文字列の最長共通部分列の長さを int で返す
public int longestCommonSubsequence(String text1, String text2) {
    // text1の長さをm、text2の長さをnに代入する。テーブルサイズとループ上限に使用する
    int m = text1.length();
    int n = text2.length();

    // dp[i][j] = text1の先頭i文字とtext2の先頭j文字のLCSの長さ
    // サイズ(m+1)×(n+1)にするのは、どちらかが空文字列の場合（基底条件）を表現するため
    // Javaではint[][]の全要素が0で初期化されるため、基底条件 dp[0][j]=0, dp[i][0]=0 は自動的に満たされる
    int[][] dp = new int[m + 1][n + 1];

    // iはtext1の先頭何文字を考慮しているかを表す
    for (int i = 1; i <= m; i++) {
        // jはtext2の先頭何文字を考慮しているかを表す
        for (int j = 1; j <= n; j++) {
            // dpのインデックスは1始まりだが、文字列のインデックスは0始まりなので i-1, j-1 でアクセスする
            if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                // 文字が一致する場合、一致した文字がLCSに加わるので、両方を1文字縮めた部分問題の答えに1を加える
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                // 文字が一致しない場合、text1側を1文字縮めた場合とtext2側を1文字縮めた場合のうち、LCSが長い方を採用する
                dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    // テーブル右下が text1 全体と text2 全体のLCSの長さである
    return dp[m][n];
}
```
