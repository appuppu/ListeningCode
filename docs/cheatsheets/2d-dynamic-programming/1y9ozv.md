# Maximizing Coins From Bursting Balloons — 風船を割る順序を最適化してコインを最大化する

## 問題の本質

整数の配列 `nums`（各風船の値）が与えられる。風船 `i` を割ると、`nums[left] * nums[i] * nums[right]`（left と right は隣接する残りの風船）のコインを獲得する。すべての風船を割ったときに得られるコインの最大値を返す。配列の境界外は値 `1` として扱う。

## 核心のアイデア

風船を「どの順番で割るか」ではなく、区間 `[left, right]` の中で「どの風船を**最後に**割るか」と逆転して考える。最後に割る風船 `k` を固定すれば、左右の部分区間は互いに独立になり、区間DPで最適解を合成できる。

## 思考プロセス

1. **割る順番の依存関係を解消したい**: 風船を割ると隣接関係が変わるため、割る順番によって得られるコインが変わる。順番を全探索すると `n!` 通りになり現実的でない。この依存関係を断ち切る視点が必要である
2. **「最後に割る」と考えると区間が独立になる**: 区間 `[left, right]` の中で風船 `k` を最後に割ると決めると、`k` を割る時点では `[left, k-1]` と `[k+1, right]` の風船はすべて消えている。つまり `k` の隣接は区間の外側にある `arr[left-1]` と `arr[right+1]` に固定される。左右の部分問題が独立になるので、DPで合成できる
3. **境界処理を簡潔にする**: 元の配列の両端に値 `1` の仮想風船を追加した新しい配列 `arr` を作る。`arr[0] = 1`, `arr[n+1] = 1` とすることで、境界条件を特別扱いせずに `arr[left-1] * arr[k] * arr[right+1]` の式を統一的に使える
4. **DPテーブルの定義**: `dp[left][right]` を「区間 `[left, right]` のすべての風船を割って得られるコインの最大値」と定義する。最終的な答えは `dp[1][n]`（元の配列全体に対応する区間）である
5. **区間の長さが短い方から埋める**: 長さ1の区間（風船1つ）から始めて、長さ `n` の区間まで順にDPテーブルを埋める。長い区間の値は短い区間の値に依存するため、短い方から計算すれば参照先は常に計算済みである
6. **各区間で最後に割る風船を全探索する**: 区間 `[left, right]` に対して、最後に割る風船 `k` を `left` から `right` まで試す。`k` を最後に割ったときのコインは `arr[left-1] * arr[k] * arr[right+1] + dp[left][k-1] + dp[k+1][right]` であり、この最大値を `dp[left][right]` に記録する

## 前提知識

### 区間DP（Interval DP）とは

区間 `[left, right]` を単位としてDPテーブルを構築する手法。区間を分割し、部分区間の最適解を組み合わせて全体の最適解を求める。短い区間から長い区間へとボトムアップに計算する。

```java
// 区間DPの基本構造: 区間の長さが短い方から順に計算する
for (int len = 1; len <= n; len++) {        // 区間の長さ
    for (int left = 1; left <= n - len + 1; left++) {  // 区間の左端
        int right = left + len - 1;          // 区間の右端
        // dp[left][right] を計算する
    }
}
```

### 番兵（Sentinel）とは

配列の両端に仮想的な要素を追加して、境界条件の特別処理を不要にするテクニック。この問題では値 `1` の風船を両端に置く。

```java
int[] arr = new int[n + 2];   // 元の配列より2つ大きい配列を作成する
arr[0] = 1;                   // 左端の番兵（値1）
arr[n + 1] = 1;               // 右端の番兵（値1）
for (int i = 0; i < n; i++)
    arr[i + 1] = nums[i];     // 元の要素をインデックス1〜nにコピーする
```

### 2次元配列のDP テーブル

`dp[i][j]` で区間 `[i, j]` の最適解を記録する。Javaでは `new int[n+2][n+2]` で生成すると全要素が `0` で初期化される。空区間（`left > right`）は `0` のままでよいため、初期化の追加処理は不要である。

```java
int[][] dp = new int[n + 2][n + 2];  // 全要素が0で初期化される
dp[left][right];                      // 区間[left, right]の最大コインを格納する
```

## 計算量

| | 値 |
|---|---|
| Time | O(n³) — 区間の左端・右端・最後に割る位置の3重ループ |
| Space | O(n²) — DPテーブル `dp[n+2][n+2]` を使用する |

## コード

```java
// 入力: 整数配列 nums（各風船の値）
// 出力: すべての風船を割って得られるコインの最大値を int で返す
public int maxCoins(int[] nums) {
    int n = nums.length;

    // 両端に番兵（値1）を追加した配列を作成する
    // この番兵により、区間の外側を参照する際に境界条件を特別扱いする必要がなくなる
    int[] arr = new int[n + 2];
    arr[0] = arr[n + 1] = 1;
    for (int i = 0; i < n; i++)
        arr[i + 1] = nums[i];

    // dp[left][right] = 区間[left, right]の風船を全て割って得られるコインの最大値
    // サイズをn+2にするのは、番兵のインデックス（0とn+1）を含めるため
    // 空区間（left > right）の値は0のままでよい
    int[][] dp = new int[n + 2][n + 2];

    // 区間の長さが短い方から順に計算する
    // 短い区間から計算することで、長い区間を計算する際に必要な部分区間の値が常に計算済みであることを保証する
    for (int len = 1; len <= n; len++) {
        // 長さlenの全区間を走査する
        for (int left = 1; left <= n - len + 1; left++) {
            int right = left + len - 1;

            // 区間[left, right]で最後に割る風船kを全探索する
            for (int k = left; k <= right; k++) {
                // kを最後に割ると決めたとき、kの隣接風船は区間外のarr[left-1]とarr[right+1]に固定される
                int coins = arr[left - 1] * arr[k] * arr[right + 1];
                // 左右の部分区間のコインを加算して合計を求める
                int total = coins + dp[left][k - 1] + dp[k + 1][right];
                // dp[left][right]を最大値で更新する
                dp[left][right] = Math.max(dp[left][right], total);
            }
        }
    }

    // 元の配列全体（インデックス1〜n）に対応する最大コインを返す
    return dp[1][n];
}
```
