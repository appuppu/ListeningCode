# Finding the Longest Increasing Path in a Matrix — 行列内で値が厳密に増加する最長パスの長さを求める

## 問題の本質

m×n の整数行列 `matrix` が与えられる。上下左右の4方向に移動でき、移動先のセルの値が現在のセルの値より**厳密に大きい**場合のみ移動できる。この条件を満たす**最長パスの長さ**（セル数）を返す。

## 核心のアイデア

行列を「小さい値から大きい値へ辺が向かうDAG（有向非巡回グラフ）」として捉える。入次数0のセル（周囲に自分より小さい値がないセル）からBFSを層ごとに進め、層の数がそのまま最長パスの長さになる。

## 思考プロセス

1. **移動条件はDAGの辺になる**: 値が厳密に増加する方向にしか移動できないため、サイクルが存在しない。つまり行列の隣接関係をグラフとして見ると、小→大の方向に辺を持つDAG（有向非巡回グラフ）になる
2. **DAGの最長パスはトポロジカルソートで求まる**: DAGの最長パス問題は、トポロジカル順序に沿って処理すれば効率的に解ける。BFS（カーンのアルゴリズム）を使えば、層ごとに処理でき、層の数が最長パスの長さに対応する
3. **入次数の意味を定義する**: 各セルの入次数は「隣接する4方向のうち、自分より値が小さいセルの数」である。入次数0のセルはパスの始点候補であり、周囲に自分より小さい値を持つ隣接セルが存在しない
4. **BFSを層ごとに処理する**: 入次数0のセルをすべてキューに入れてBFSを開始する。1層分のセルをまとめて処理し、各セルから「自分より大きい隣接セル」の入次数を1減らす。入次数が0になったセルを次の層としてキューに追加する
5. **層の数が答えになる理由**: BFSの各層は、DAG上で同じ距離にあるセルの集合である。最後の層が処理されるまでの層数が、始点から最も遠いセルまでの距離、すなわち最長パスの長さになる

## 前提知識

### DAG（有向非巡回グラフ）とは

頂点と有向辺からなるグラフで、サイクル（循環）が存在しないもの。値が厳密に増加する方向にのみ辺を張ると、同じ値に戻ることがないためサイクルが生じず、DAGが構成される。

### 入次数（in-degree）とは

ある頂点に**入ってくる辺の数**。本問題では、セル `(i, j)` の入次数は「上下左右の隣接セルのうち、`matrix[i][j]` より小さい値を持つセルの数」である。入次数0のセルは、どのセルからも到達されないパスの始点を意味する。

```java
// セル(i,j)の入次数を計算する例
int indegree = 0;
for (int[] d : dirs) {
    int ni = i + d[0], nj = j + d[1];
    if (ni >= 0 && ni < m && nj >= 0 && nj < n
        && matrix[ni][nj] < matrix[i][j])  // 隣が自分より小さければ辺が入ってくる
        indegree++;
}
```

### トポロジカルソート（BFS / カーンのアルゴリズム）とは

DAGの頂点を、すべての辺が「先→後」の順番になるように並べる手法。カーンのアルゴリズムでは、入次数0の頂点をキューに入れ、取り出すたびに隣接頂点の入次数を1減らし、入次数が0になった頂点をキューに追加する。これを繰り返すとトポロジカル順序が得られる。

```java
Queue<int[]> q = new LinkedList<>();   // BFS用のキューを作成
q.offer(new int[]{0, 1});             // セル座標をキューに追加する
q.isEmpty();                           // キューが空かをbooleanで返す → false
q.size();                              // キュー内の要素数を返す → 1
int[] cell = q.poll();                 // キューの先頭要素を取り出して返す → {0, 1}
```

### 4方向の移動を配列で表現する

上下左右の4方向を `{行の変化量, 列の変化量}` の2次元配列で定義し、ループで各方向を処理する。

```java
int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};  // 右、左、下、上
for (int[] d : dirs) {
    int ni = i + d[0];  // 移動先の行
    int nj = j + d[1];  // 移動先の列
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(m\*n) — 各セルの入次数計算にO(m\*n)、BFSで各セルをちょうど1回処理するのにO(m\*n) |
| Space | O(m\*n) — 入次数を保存する2次元配列とBFSキューにそれぞれ最大m\*n個のセルを保存する |

## コード

```java
// 入力: m×n の整数行列 matrix
// 出力: 値が厳密に増加する最長パスの長さ（セル数）を int で返す
int longestIncreasingPath(int[][] matrix) {
    // 行数mと列数nを取得する
    int m = matrix.length;
    int n = matrix[0].length;
    // 上下左右の4方向の移動量を定義する（右、左、下、上）
    int[][] dirs = {{0,1}, {0,-1}, {1,0}, {-1,0}};

    // 各セルの入次数を計算する（隣接セルのうち自分より小さい値の数）
    // 入次数 = そのセルに入ってくる辺の数 = 隣接する自分より小さい値のセル数
    int[][] indeg = new int[m][n];
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            for (int[] d : dirs) {
                int ni = i + d[0];
                int nj = j + d[1];
                // 隣接セルが範囲内かつ自分より小さければ、そこから辺が入ってくる
                if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && matrix[ni][nj] < matrix[i][j])
                    indeg[i][j]++;
            }
        }
    }

    // 入次数0のセル（パスの始点）をすべてキューに追加する
    // 入次数0 = 周囲に自分より小さい値がない = DAG上でどのセルからも到達されない始点
    Queue<int[]> q = new LinkedList<>();
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (indeg[i][j] == 0)
                q.offer(new int[]{i, j});

    // BFSを層ごとに処理し、層の数をカウントする
    // 各層はDAG上で始点から同じ距離にあるセルの集合
    int pathLen = 0;
    while (!q.isEmpty()) {
        // 現在の層に属するセルの数を取得する
        int size = q.size();
        // 新しい層に進むたびにパス長を1増やす（層の総数 = 最長パスの長さ）
        pathLen++;
        for (int k = 0; k < size; k++) {
            int[] cell = q.poll();
            // 取り出したセルの4方向の隣接セルを調べる
            for (int[] d : dirs) {
                int ni = cell[0] + d[0];
                int nj = cell[1] + d[1];
                // 隣接セルが範囲内かつ自分より大きい場合、その辺を処理する
                if (ni >= 0 && ni < m && nj >= 0 && nj < n
                    && matrix[ni][nj] > matrix[cell[0]][cell[1]]) {
                    // 入次数を1減らす（このセルからの入力辺を処理済みにする）
                    indeg[ni][nj]--;
                    // 入次数が0になった = すべての入力辺が処理済み → 次の層としてキューに追加
                    if (indeg[ni][nj] == 0)
                        q.offer(new int[]{ni, nj});
                }
            }
        }
    }
    // BFSの層数が最長増加パスの長さである
    // 問題の制約上、行列は空でないので pathLen >= 1 が保証される
    return pathLen;
}
```
