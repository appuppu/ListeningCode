# Implementing Regular Expression Matching — 文字列がパターンに完全一致するか判定する

## 問題の本質

入力文字列 `s` とパターン `p` が与えられる。パターン中の `.` は任意の1文字にマッチし、`*` は直前の文字の0回以上の繰り返しを意味する。パターンが文字列**全体**に一致するかを `boolean` で返す。

## 核心のアイデア

文字列とパターンの末尾から先頭に向かって2次元DPテーブルを埋めていく。`dp[i][j]` は「`s[i:]` が `p[j:]` にマッチするか」を表し、`*` がある場合は「直前の文字を0回使う（スキップ）」か「1回使って文字列を1つ進める」かの2択に帰着する。

## 思考プロセス

1. **部分問題に分解できる**: 文字列の位置 `i` とパターンの位置 `j` を決めれば、「`s[i:]` が `p[j:]` にマッチするか」という部分問題になる。この部分問題の答えを `dp[i][j]` に保存すれば、重複計算を避けられる
2. **現在位置の文字マッチを判定する**: `s[i]` と `p[j]` が同じ文字であるか、または `p[j]` が `.` であれば、現在位置の1文字はマッチする。この判定結果を変数 `match` に保存しておく
3. **`*` がある場合の2つの選択肢を考える**: `p[j+1]` が `*` のとき、「`x*`」というパターンは2通りの解釈ができる。1つ目は「0回マッチ（スキップ）」で、`x*` を丸ごと飛ばして `dp[i][j+2]` を参照する。2つ目は「1回以上マッチ」で、現在の文字がマッチしていれば文字列を1つ進めて `dp[i+1][j]` を参照する（パターン側は進めない。次の位置でも `*` による繰り返しが続く可能性があるため）
4. **`*` がない場合は単純に1文字ずつ進む**: 現在の文字がマッチしていれば、文字列もパターンも1つ進めた `dp[i+1][j+1]` がそのまま答えになる
5. **ベースケースを設定する**: 文字列もパターンも末尾に到達した状態 `dp[n][m]` は `true` である。文字列が残っているがパターンが末尾の場合は `false`、パターンが残っているが文字列が末尾の場合は `*` によるスキップでのみ `true` になりうる
6. **末尾から先頭に向かってテーブルを埋める**: `dp[i][j]` の計算は `dp[i][j+2]`、`dp[i+1][j]`、`dp[i+1][j+1]` に依存する。これらはすべて `i` または `j` が大きい方向の値なので、`i` を `n` から `0` へ、`j` を `m-1` から `0` へ逆順に走査すれば、参照先は常に計算済みである
7. **最終的に返すもの**: テーブルの `dp[0][0]` が「文字列全体がパターン全体にマッチするか」の答えである

## 前提知識

### 2次元DPテーブルとは

2つの変数（ここでは文字列の位置 `i` とパターンの位置 `j`）の組み合わせごとに部分問題の答えを保存する二次元配列。`boolean[][] dp = new boolean[n+1][m+1]` で作成し、`dp[i][j]` に `s[i:]` と `p[j:]` のマッチ結果を格納する。

```java
boolean[][] dp = new boolean[n + 1][m + 1];  // (n+1)×(m+1)のfalseで初期化された表を作成
dp[n][m] = true;                              // ベースケース: 両方末尾なら一致
dp[i][j] = dp[i][j + 2];                     // 別のセルの値を参照して現在のセルを埋める
```

### String.length() と String.charAt()

`length()` は文字列の長さを返す。`charAt(i)` はインデックス `i` の文字を返す。インデックスは0始まりで、範囲外アクセスは例外を投げる。

```java
String s = "abc";
s.length();     // → 3
s.charAt(0);    // → 'a'
s.charAt(2);    // → 'c'
```

### `*`（スター）の意味

正規表現における `*` は「直前の1文字の0回以上の繰り返し」を表す。`a*` は `""`, `"a"`, `"aa"`, `"aaa"`, ... のいずれにもマッチする。`.*` は「任意の文字の0回以上の繰り返し」なので、あらゆる文字列にマッチする。`*` は単独では使われず、必ず直前の文字とセットで `x*` の形をとる。

## 計算量

| | 値 |
|---|---|
| Time | O(n×m) — n×mのDPテーブルの各セルを1回ずつ計算する |
| Space | O(n×m) — n×mのDPテーブルを保存する |

## コード

```java
// 入力: 文字列 s とパターン p
// 出力: s 全体が p にマッチするかを boolean で返す
public boolean isMatch(String s, String p) {
    int n = s.length();  // 文字列の長さ
    int m = p.length();  // パターンの長さ

    // dp[i][j] = 「s[i:]がp[j:]にマッチするか」を保存する二次元テーブル
    // インデックス n と m は空文字列を表すため、サイズは +1 する
    boolean[][] dp = new boolean[n + 1][m + 1];

    // ベースケース: 両方の文字列が末尾に到達していればマッチ成功
    dp[n][m] = true;

    // 末尾から先頭に向かってテーブルを埋める
    // この走査順により、参照先の dp[i][j+2], dp[i+1][j], dp[i+1][j+1] はすべて計算済みである
    for (int i = n; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // 現在位置の1文字がマッチするかを判定する
            // i < n を先に判定することで、文字列が末尾のときに charAt で範囲外アクセスするのを防ぐ
            boolean match = i < n
                && (s.charAt(i) == p.charAt(j)
                    || p.charAt(j) == '.');

            // j+1 < m で範囲チェックし、パターンの現在位置が x* の形かを判定する
            if (j + 1 < m && p.charAt(j + 1) == '*') {
                // x*パターンの2つの選択肢のOR（論理和）をとる:
                // dp[i][j+2]: 0回マッチ（x* を丸ごと飛ばす）
                // match && dp[i+1][j]: 1回マッチして文字列を進める（パターン側は進めない。*による繰り返しが続く可能性があるため j は据え置く）
                dp[i][j] = dp[i][j + 2]
                    || (match && dp[i + 1][j]);
            } else {
                // 通常の文字: 1文字マッチなら文字列とパターンの両方を1つ進める
                dp[i][j] = match
                    && dp[i + 1][j + 1];
            }
        }
    }

    // dp[0][0] が「文字列 s 全体がパターン p 全体にマッチするか」の最終的な答え
    return dp[0][0];
}
```
