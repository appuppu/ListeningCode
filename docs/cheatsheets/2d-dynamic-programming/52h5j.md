# Checking if a String is an Interleaving of Two Others — 2つの文字列を交互に混ぜ合わせて3つ目の文字列が作れるか判定する

## 問題の本質

3つの文字列 `s1`、`s2`、`s3` が与えられる。`s3` が `s1` と `s2` の**インターリーブ**（交互混合）で構成されているかを判定する。インターリーブとは、`s1` と `s2` の全文字を使い切り、かつそれぞれの文字列内での相対的な出現順序を保ったまま混ぜ合わせることである。

## 核心のアイデア

`s1` の先頭 `i` 文字と `s2` の先頭 `j` 文字で `s3` の先頭 `i+j` 文字を構成できるかという部分問題に分解できる。各位置で「次の1文字を `s1` から取るか `s2` から取るか」の2択を、DPテーブルで効率的に判定する。

## 思考プロセス

1. **長さの前提条件を確認する**: `s3` が `s1` と `s2` のインターリーブであるなら、`s3` の長さは `s1` の長さ + `s2` の長さと一致しなければならない。一致しなければ即座に `false` を返せる
2. **部分問題を定義する**: `dp[i][j]` を「`s1` の先頭 `i` 文字と `s2` の先頭 `j` 文字で、`s3` の先頭 `i+j` 文字を構成できるか」と定義する。この定義により、`dp[m][n]`（`m` は `s1` の長さ、`n` は `s2` の長さ）が最終的な答えになる
3. **遷移式を導出する**: `dp[i][j]` が `true` になるのは2つのケースのいずれかである。ケース1: `dp[i-1][j]` が `true` かつ `s1` の `i` 番目の文字が `s3` の `i+j` 番目の文字と一致する（`s1` から1文字取る）。ケース2: `dp[i][j-1]` が `true` かつ `s2` の `j` 番目の文字が `s3` の `i+j` 番目の文字と一致する（`s2` から1文字取る）
4. **ベースケースを定義する**: `i=0` かつ `j=0` のとき、どちらの文字列からも文字を取っていない初期状態であり、`s3` の先頭0文字（空文字列）と一致するので `dp[0][0] = true` とする
5. **空間計算量を最適化する**: 2次元の `dp[i][j]` は `i` 行目の計算に `i-1` 行目の値しか使わない。そのため1次元配列 `dp[j]` で十分であり、`dp[j]` の更新前の値が前の行（`dp[i-1][j]`）に相当し、`dp[j-1]` の更新後の値が現在の行の左隣（`dp[i][j-1]`）に相当する
6. **最終的に返すもの**: 外側ループが `i = 0` から `m` まで、内側ループが `j = 0` から `n` まで回った後、`dp[n]` が `s3` 全体をインターリーブで構成できるかの答えである

## 前提知識

### DP（動的計画法）の1次元配列による空間最適化とは

2次元DPテーブル `dp[i][j]` において、各行の計算が直前の行のみに依存する場合、1次元配列 `dp[j]` で代用できる手法。配列を行ごとに上書き更新することで、空間計算量を O(m×n) から O(n) に削減する。

```java
// 2次元の場合: dp[i][j] は dp[i-1][j] と dp[i][j-1] を参照する
boolean[][] dp = new boolean[m + 1][n + 1];

// 1次元に最適化: dp[j] を行ごとに上書きする
boolean[] dp = new boolean[n + 1];
// dp[j] の更新前の値 → 前の行の dp[i-1][j] に相当
// dp[j-1] の更新後の値 → 現在の行の dp[i][j-1] に相当
```

### String.charAt(index) とは

文字列の指定位置の文字を返すメソッド。インデックスは0始まりである。

```java
String s = "abc";
s.charAt(0);  // 'a' を返す
s.charAt(2);  // 'c' を返す
```

### インターリーブ（Interleaving）とは

2つの文字列の文字を、それぞれの相対順序を保ちながら混ぜ合わせて1つの文字列を作ること。
例: `s1 = "aab"`, `s2 = "axy"` のとき、`"aaxaby"` はインターリーブである（`s1` から a,a,b、`s2` から a,x,y の順序がそれぞれ保たれている）。`"abaaxy"` は `s1` の文字順序が崩れるのでインターリーブではない。

## 計算量

| | 値 |
|---|---|
| Time | O(m×n) — `s1` の長さ `m` と `s2` の長さ `n` の二重ループを1回実行する |
| Space | O(n) — `s2` の長さ+1のサイズの1次元DP配列のみを使用する |

## コード

```java
// 入力: 文字列 s1（長さ m）、文字列 s2（長さ n）、文字列 s3
// 出力: s3 が s1 と s2 のインターリーブで構成できるかを boolean で返す
public boolean isInterleave(String s1, String s2, String s3) {
    int m = s1.length();
    int n = s2.length();

    // m + n が s3 の長さと一致しない場合、インターリーブは不可能
    if (m + n != s3.length())
        return false;

    // dp[j] = s1の先頭i文字とs2の先頭j文字でs3の先頭i+j文字を構成できるか
    // 1次元配列を行ごとに上書きすることで、2次元テーブルの空間を O(n) に圧縮する
    boolean[] dp = new boolean[n + 1];

    // 外側ループ: i は s1 から取る文字数を表す（0〜m）
    for (int i = 0; i <= m; i++) {
        // 内側ループ: j は s2 から取る文字数を表す（0〜n）
        for (int j = 0; j <= n; j++) {
            if (i == 0 && j == 0) {
                // ベースケース: どちらからも文字を取っていない状態で、s3の空文字列と一致する
                dp[j] = true;
            } else {
                // 条件1（s1から取る）: dp[j] の更新前の値（前の行 = dp[i-1][j] に相当）が true
                //   かつ s1 の i 番目の文字が s3 の i+j 番目の文字と一致する
                // 条件2（s2から取る）: dp[j-1] の更新後の値（現在の行の左隣 = dp[i][j-1] に相当）が true
                //   かつ s2 の j 番目の文字が s3 の i+j 番目の文字と一致する
                // 注意: 内側ループが j を左から右へ走査するため、dp[j] はまだ上書きされておらず前の行の値を保持し、
                //   dp[j-1] は既に上書き済みなので現在の行の値を保持している
                dp[j] =
                    (dp[j] && i > 0
                    && s1.charAt(i - 1)
                    == s3.charAt(i + j - 1))
                    || (j > 0
                    && dp[j - 1]
                    && s2.charAt(j - 1)
                    == s3.charAt(i + j - 1));
            }
        }
    }

    // dp[n] は s1 の全 m 文字と s2 の全 n 文字で s3 の全 m+n 文字を構成できるかの結果
    return dp[n];
}
```
