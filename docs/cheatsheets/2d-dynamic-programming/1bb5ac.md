# Maximizing Stock Profit With a Cooldown Period — クールダウン付き株取引で最大利益を求める

## 問題の本質

株価の配列 `prices` が与えられる。各インデックスは日付を表す。株を複数回売買できるが、売却した翌日は**クールダウン**として取引できない。この制約のもとで得られる**最大利益**を返す。

## 核心のアイデア

各日の状態を「株を保有中（hold）」「売却直後（sold）」「休息中（rest）」の3つに分類し、前日の3状態から当日の3状態への遷移を定義する。各日は前日のみに依存するため、配列ではなく3つの変数だけで状態を管理できる。

## 思考プロセス

1. **各日には3つの状態がある**: ある日の終了時点で、自分は「株を保有している（hold）」「その日に売った（sold）」「何もしていない（rest）」のいずれかである。この3状態で全てのケースを網羅できる
2. **状態間の遷移を定義する**: hold は「前日も hold で何もしない」か「前日が rest で今日買う」の大きい方。sold は「前日が hold で今日売る」。rest は「前日も rest で何もしない」か「前日が sold でクールダウンが終わる」の大きい方。クールダウンの制約は「sold の翌日は hold に遷移できない」というルールで自然に表現される
3. **初期状態を設定する**: 0日目に買うなら hold = -prices[0]（利益がマイナスになる）。0日目に売ることも休むこともまだできないので、sold = Integer.MIN_VALUE（この状態は未到達を意味する）、rest = 0（何もしなければ利益は0）とする
4. **各日は前日の状態のみに依存する**: 遷移式を見ると、当日の各状態は前日の3状態だけから計算できる。つまり全日分の配列を持つ必要はなく、3つの変数を毎日更新するだけで済む
5. **同時更新が必要である**: 当日の hold, sold, rest は全て前日の値から計算するため、新しい値を一時変数に格納してから、まとめて前日の変数を上書きする。逐次上書きすると、まだ計算に使うべき前日の値が失われる
6. **最終的に返すもの**: 最終日に株を持ったまま終わるのは最適ではないため、prevSold と prevRest の大きい方が最大利益である

## 前提知識

### 状態機械（State Machine）とは

有限個の状態と、状態間の遷移規則で構成されるモデル。各時点で必ず1つの状態にあり、入力に応じて別の状態に遷移する。この問題では hold / sold / rest の3状態を持つ状態機械として取引をモデル化する。

```
rest ---(買う)---> hold
hold ---(売る)---> sold
sold ---(待つ)---> rest（クールダウン）
hold ---(持続)---> hold
rest ---(持続)---> rest
```

### Math.max とは

2つの整数のうち大きい方を返すメソッド。状態遷移で複数の選択肢がある場合に、利益が大きい方を選ぶために使う。

```java
Math.max(3, 7);    // → 7（大きい方を返す）
Math.max(-5, -2);  // → -2（負の数でも大きい方を返す）
```

### Integer.MIN_VALUE とは

Java の int 型が取れる最小値（-2,147,483,648）。「この状態にはまだ到達していない」ことを表すために使う。どの値と比較しても Math.max で選ばれないため、未到達の状態を安全に無視できる。

```java
int x = Integer.MIN_VALUE;  // まだ到達していない状態を表す
Math.max(x, 0);             // → 0（未到達の状態は選ばれない）
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を1回走査するだけで済む |
| Space | O(1) — 3つの変数のみで状態を管理する |

## コード

```java
// 入力: 整数配列 prices（各要素はその日の株価）
// 出力: クールダウン制約つきで得られる最大利益を int で返す
public int maxProfit(int[] prices) {
    int n = prices.length;
    // 株を売買するには最低2日必要。n < 2 なら売買が成立しないので 0 を返す
    if (n < 2) return 0;

    // 0日目の各状態を初期化する
    int prevHold = -prices[0];          // 0日目に買った場合の利益（支出なのでマイナス）
    int prevSold = Integer.MIN_VALUE;   // 0日目に売ることは不可能（未到達を表す）
    int prevRest = 0;                   // 何もしなければ利益は0

    for (int i = 1; i < n; i++) {
        // 前日の3状態から当日の3状態を計算する
        // newHold: 「前日も保有（prevHold）」か「前日は休息で今日買う（prevRest - prices[i]）」の大きい方
        // 注意: 「前日が sold で今日買う」は選択肢にない。これがクールダウンの制約を表現している
        int newHold = Math.max(prevHold,
            prevRest - prices[i]);

        // newSold: 保有していた株を今日売る。sell は hold からのみ遷移できるため Math.max は不要
        int newSold = prevHold + prices[i];

        // newRest: 「前日も休息（prevRest）」か「前日に売却してクールダウン明け（prevSold）」の大きい方
        int newRest = Math.max(prevRest,
            prevSold);

        // 全て計算した後にまとめて更新する
        // 計算途中で前日の値を上書きしないために、3つの新しい値を全て求めてから代入する
        prevHold = newHold;
        prevSold = newSold;
        prevRest = newRest;
    }
    // 最終日に株を保有したまま終わる（prevHold）のは利益を確定できないため最適ではない
    // sold と rest の大きい方が最大利益
    return Math.max(prevSold, prevRest);
}
```
