# Counting Unique Paths in a Grid — グリッドの左上から右下への一意な経路数を数える

## 問題の本質

`m × n` のグリッドが与えられる。左上のマス `(0, 0)` から右下のマス `(m-1, n-1)` まで、各ステップで**右か下にのみ**移動できるとき、一意な経路の総数を返す。

## 核心のアイデア

あるマスへの経路数は「上のマスへの経路数」と「左のマスへの経路数」の合計である。この漸化式をボトムアップで埋めていけば答えが求まり、各行の計算は直前の行と現在の行だけに依存するため、1行分の配列だけで空間を節約できる。

## 思考プロセス

1. **各マスへの経路数は部分問題に分解できる**: マス `(i, j)` に到達するには、必ず上 `(i-1, j)` か左 `(i, j-1)` から来る。したがって `dp[i][j] = dp[i-1][j] + dp[i][j-1]` という漸化式が成り立つ
2. **基底ケースを決める**: 最上行のマスには左からしか到達できず、最左列のマスには上からしか到達できない。どちらも経路数は1なので、`dp[0][j] = 1`、`dp[i][0] = 1` で初期化する
3. **行ごとに左から右へ埋めていく**: 漸化式が依存するのは「1つ上のマス」と「1つ左のマス」なので、行を上から下へ、各行内を左から右へ走査すれば、必要な値は常に計算済みである
4. **空間を1行分に圧縮できる**: `dp[i][j]` が依存するのは同じ行の左隣 `dp[i][j-1]` と前の行の同じ列 `dp[i-1][j]` だけである。1次元配列 `dp[j]` を使うと、更新前の `dp[j]` が「上のマスの値」、更新済みの `dp[j-1]` が「左のマスの値」にあたるため、`dp[j] += dp[j-1]` で漸化式を表現できる
5. **初期化は全要素1**: 1次元配列を全て1で初期化すると、最上行（全マス経路数1）の状態を表す。最左列にあたる `dp[0]` は内側ループで更新されないため常に1のままとなり、最左列の基底ケースも自然に保たれる
6. **最終的に返すもの**: 全行の処理が終わった後、`dp[n-1]` が右下マスへの経路数を保持しているので、これを返す

## 前提知識

### Arrays.fill とは

配列の全要素を指定した値で一括初期化するユーティリティメソッド。ループを書かずに配列を均一な値で埋められる。

```java
int[] dp = new int[5];       // 長さ5の配列を作成（初期値は全て0）
Arrays.fill(dp, 1);          // 全要素を1に設定 → [1, 1, 1, 1, 1]
```

### 1次元DPによる空間圧縮とは

2次元DPテーブルにおいて、各セルの計算が「現在の行」と「1つ前の行」にしか依存しない場合、2次元配列を1次元配列に置き換えられるテクニック。配列を行ごとに上書き更新することで、Space O(m×n) を O(n) に削減する。

```java
// 2次元の場合: dp[i][j] = dp[i-1][j] + dp[i][j-1]
// 1次元に圧縮: dp[j] += dp[j-1]
//   dp[j]（更新前）= 前の行の同じ列の値（= dp[i-1][j] に相当）
//   dp[j-1]（更新済み）= 現在の行の左隣の値（= dp[i][j-1] に相当）
```

## 計算量

| | 値 |
|---|---|
| Time | O(m × n) — グリッドの全マスを1回ずつ走査する |
| Space | O(n) — 1行分の配列のみを保持する |

## コード

```java
// 入力: 整数 m（行数）と整数 n（列数）
// 出力: 左上から右下までの一意な経路数を整数で返す
public int uniquePaths(int m, int n) {
    // 長さ n の1行分DP配列を作成し、全要素を1に初期化する
    // 全て1にすることで、最上行の基底ケース（各マスへの経路数が1）を設定する
    int[] dp = new int[n];
    Arrays.fill(dp, 1);

    // i=0（最上行）は初期化で設定済みなので i=1 から開始する
    for (int i = 1; i < m; i++) {
        // j=0（最左列）は常に1のままであるべきなので j=1 から開始する
        for (int j = 1; j < n; j++) {
            // dp[j]（更新前）= 前の行の同じ列の値（上からの経路数）
            // dp[j-1]（更新済み）= 現在の行の左隣の値（左からの経路数）
            // この加算で漸化式 dp[i][j] = dp[i-1][j] + dp[i][j-1] を1次元配列上で実現する
            dp[j] += dp[j - 1];
        }
    }

    // dp[n-1] はグリッドの右下マス (m-1, n-1) への一意な経路数を保持している
    return dp[n - 1];
}
```
