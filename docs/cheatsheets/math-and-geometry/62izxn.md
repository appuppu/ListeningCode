# Computing Power of a Number Efficiently — 浮動小数点数のべき乗を効率的に計算する

## 問題の本質

浮動小数点数 `x` と整数 `n` が与えられる。`x` の `n` 乗を計算して返す。`n` は負の値を取りうるため負の指数にも対応する必要があり、`n` の絶対値が非常に大きい場合でも効率的に計算しなければならない。

## 核心のアイデア

指数 `n` を2進数で表現すると、べき乗の計算は「xを繰り返し2乗しながら、nの各ビットが1のときだけ結果に掛ける」という操作に分解できる。これにより、n回の掛け算がlog(n)回に削減される。

## 思考プロセス

1. **負の指数を正の指数に変換する**: `x^(-n)` は `(1/x)^n` と等しいので、`n` が負の場合は `x` を `1/x` に置き換え、`n` の符号を反転させれば、正の指数の問題に統一できる
2. **n回の掛け算は遅すぎる**: 素朴に `x` を `n` 回掛けるとO(n)かかる。`n` が数十億の場合、これでは間に合わない。指数を半分ずつ減らす方法が必要である
3. **べき乗は2乗の繰り返しで分解できる**: `x^10 = x^8 × x^2` のように、任意のべき乗は2のべき乗の積に分解できる。これは指数 `n` の2進数表現に対応する。`10` は2進数で `1010` なので、ビットが1の桁に対応する `x^8` と `x^2` だけを掛ければよい
4. **ビット演算で各桁を判定する**: `n` の最下位ビットが1かどうかは `(n & 1) == 1` で判定できる。1であれば、そのときの `x`（現在の桁に対応する2のべき乗分だけ累乗された値）を結果に掛ける
5. **xの2乗を繰り返して桁を上げる**: 各ループで `x` を `x * x` に更新すると、`x` は元の値の2乗、4乗、8乗…と2のべき乗分の累乗になる。同時に `n` を1ビット右シフトして次の桁に進む
6. **ループの終了条件**: `n` を右シフトし続けると最終的に0になる。`n > 0` の間ループを回せば、すべてのビットを処理できる

## 前提知識

### ビット演算（& と >>）とは

整数を2進数として扱い、ビット単位で操作する演算。`&`（AND）は両方のビットが1のときだけ1になる。`>>`（右シフト）はビット列を右にずらし、最下位ビットを捨てる（2で割る操作に相当する）。

```java
int n = 10;           // 2進数: 1010
n & 1;                // 最下位ビットを取得 → 0（偶数）
n >>= 1;              // 1ビット右シフト → n は 5（2進数: 101）
n & 1;                // 最下位ビットを取得 → 1（奇数）
```

### 繰り返し2乗法（Fast Exponentiation）とは

指数の2進数表現を利用して、べき乗をO(log n)回の掛け算で計算する手法。`x^13` を例にすると、`13` は2進数で `1101` なので、`x^13 = x^8 × x^4 × x^1` と分解できる。ループで `x` を繰り返し2乗しながら（`x → x^2 → x^4 → x^8`）、対応するビットが1のときだけ結果に掛ける。

```java
// x^13 の計算過程（13 = 1101 in binary）
// ビット0: 1 → result *= x    (result = x^1)、  x = x^2
// ビット1: 0 → スキップ、                         x = x^4
// ビット2: 1 → result *= x^4  (result = x^5)、  x = x^8
// ビット3: 1 → result *= x^8  (result = x^13)、 x = x^16
```

### long型へのキャストが必要な理由

Javaの `int` 型の範囲は `-2^31` から `2^31 - 1` である。`n = -2^31` のとき、`-n` は `2^31` となり `int` の範囲を超えてオーバーフローする。`long` 型にキャストしてから符号を反転すれば、この問題を回避できる。

```java
int n = Integer.MIN_VALUE;   // -2147483648
long power = (long) n;       // -2147483648L（long型に変換）
power = -power;              // 2147483648L（int型では表現不可だがlong型なら安全）
```

## 計算量

| | 値 |
|---|---|
| Time | O(log n) — 指数nのビット数分だけループするため |
| Space | O(1) — 使用する変数はresult, x, powerの3つだけで再帰スタックも不要 |

## コード

```java
// 入力: 浮動小数点数 x と整数 n
// 出力: x の n 乗の値を double で返す
double myPow(double x, int n) {
    // int型のままだとn = -2^31のとき符号反転でオーバーフローするのでlong型に変換する
    long power = (long) n;

    // 負の指数を正に変換する: x^(-n) = (1/x)^n
    // この変換により以降の処理を正の指数のみで統一できる
    if (power < 0) {
        x = 1 / x;
        power = -power;
    }

    // 結果を蓄積する変数を1.0で初期化する
    // ビットが1の桁に対応するxの累乗を掛けて最終結果を蓄積していく
    double result = 1.0;

    // powerのすべてのビットを下位から順に処理する
    // powerを右シフトし続けると最終的に0になり、すべての桁の処理が完了する
    while (power > 0) {
        // power & 1 で最下位ビット（現在処理中の桁）が1かどうかを判定する
        if ((power & 1) == 1) {
            // ビットが1の場合: この時点のxは元のxを処理済みの桁数分だけ2乗した値（元のxの2^k乗）
            // この桁の寄与分をresultに掛けて反映させる
            result *= x;
        }
        // xを2乗して次の桁に対応する累乗値（2倍の指数の累乗）に更新する
        x *= x;
        // powerを1ビット右シフトして次の桁に進む（最下位ビットが捨てられる）
        power >>= 1;
    }
    // すべてのビットの寄与が掛け合わされた最終結果を返す
    return result;
}
```
