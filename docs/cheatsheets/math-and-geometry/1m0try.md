# Setting Entire Rows and Columns to Zero — ゼロを含む行と列を丸ごとゼロにする

## 問題の本質

m×n の行列が与えられる。要素が0である箇所を見つけたら、その要素が属する**行全体**と**列全体**をすべて0に設定する。この変換をin-place（追加の行列を使わず）で行う。

## 核心のアイデア

行列の第0行と第0列を「どの行・列をゼロにすべきか」を記録するフラグ領域として再利用すれば、追加スペースO(1)でゼロ化すべき行・列を管理できる。

## 思考プロセス

1. **ゼロ化すべき行・列を記録する必要がある**: 走査中にゼロを見つけた瞬間にその行・列を書き換えると、後続の走査で元の値がゼロだったのか書き換えによるゼロなのか区別できなくなる。そのため、まず「どの行・列をゼロにするか」を記録してから、一括で書き換える2パス方式が必要になる
2. **記録用に別配列を使うとO(m+n)のスペースがかかる**: 行用にサイズmの配列、列用にサイズnの配列を使えば記録できるが、O(1)スペースを目指したい
3. **行列自身の第0行・第0列をフラグとして使う**: `matrix[i][0]` が0なら「i行目をゼロにする」、`matrix[0][j]` が0なら「j列目をゼロにする」という意味を持たせる。こうすれば追加配列が不要になる
4. **第0列のフラグだけは独立した変数が必要**: `matrix[i][0]` は「i行目のフラグ」と「第0列の元の値」という2つの意味を持ってしまう。第0列自体をゼロにすべきかどうかは別の変数 `firstCol` で管理する
5. **フラグのマーキング**: 行列を走査し、`matrix[i][j] == 0` を見つけたら `matrix[i][0] = 0` と `matrix[0][j] = 0` を設定してフラグを立てる
6. **逆順にゼロ化する**: フラグに基づいてゼロを書き込む際、第0行・第0列を先に書き換えるとフラグが壊れる。そのため、末尾から逆順に処理し、第0行・第0列は最後に処理する

## 前提知識

### in-place 操作とは

追加のデータ構造（別の行列や大きな配列）を使わず、入力データ自体を書き換えて結果を得る操作。定数個の変数のみ追加で使用することが許される。

```java
// in-place操作の例: 配列の要素を直接書き換える
matrix[i][j] = 0;  // 別の配列にコピーせず、元の行列を直接変更する
```

### boolean型フラグとは

true/false の2値で「ある条件が成立したか」を記録する変数。ループ中に条件が一度でも成立したらtrueにし、後続の処理で参照する。

```java
boolean firstCol = false;       // 初期値はfalse（条件未成立）
if (matrix[i][0] == 0)
    firstCol = true;            // 条件成立を記録
// 後で参照する
if (firstCol)
    matrix[i][0] = 0;          // フラグがtrueなら処理を実行
```

### 逆順ループとは

配列や行列を末尾から先頭に向かって走査するループ。先頭の要素が後続の処理に使われるフラグを兼ねている場合、先頭を最後に処理するために逆順を用いる。

```java
for (int i = m - 1; i >= 0; i--)    // i を末尾(m-1)から0まで1ずつ減らす
    for (int j = n - 1; j >= 1; j--)  // j を末尾(n-1)から1まで1ずつ減らす
```

## 計算量

| | 値 |
|---|---|
| Time | O(m × n) — 行列全体を2回走査する（フラグ設定で1回、ゼロ化で1回） |
| Space | O(1) — 追加変数は `firstCol` のみ。行列自身をフラグ領域として再利用する |

## コード

```java
// 入力: m×n の整数行列 matrix（2次元配列）
// 出力: なし（matrix を直接書き換える。戻り値は void）
public void setZeroes(int[][] matrix) {
    // 行数mと列数nを取得する
    int m = matrix.length;
    int n = matrix[0].length;
    // 第0列をゼロにすべきかを記録するフラグ
    // matrix[i][0] は行フラグと兼用されるため、第0列のフラグだけは独立した変数で管理する
    boolean firstCol = false;

    // 第1パス: フラグのマーキング
    for (int i = 0; i < m; i++) {
        // 第0列に元々ゼロがあるか確認し、あれば firstCol を true にする
        if (matrix[i][0] == 0)
            firstCol = true;
        // j=1から走査する（j=0 は行フラグ兼用なので列1以降だけを見る）
        for (int j = 1; j < n; j++)
            if (matrix[i][j] == 0) {
                matrix[i][0] = 0;  // i行目をゼロにするフラグ
                matrix[0][j] = 0;  // j列目をゼロにするフラグ
            }
    }

    // 第2パス: 逆順にゼロを書き込む
    // 逆順にする理由: 第0行のフラグ（matrix[0][j]）を他の行の処理に使うため、第0行を最後に処理する
    for (int i = m - 1; i >= 0; i--) {
        // j=1から逆順に走査し、行フラグまたは列フラグが立っていればゼロにする
        for (int j = n - 1; j >= 1; j--)
            if (matrix[i][0] == 0 || matrix[0][j] == 0)
                matrix[i][j] = 0;
        // 第0列のゼロ化は内側ループの後に行う
        // 注意: 先に matrix[i][0] を書き換えると、上の行フラグ判定が壊れる
        if (firstCol)
            matrix[i][0] = 0;
    }
}
```
