# Multiplying Two Numbers Represented as Strings — 文字列で表された2つの数を掛け算する

## 問題の本質

非負整数を表す2つの文字列 `num1` と `num2` が与えられる。2つの数の**積**を文字列として返す。組み込みの大整数ライブラリや、入力を直接整数に変換することは禁止されている。

## 核心のアイデア

小学校で習う筆算の掛け算をそのままシミュレーションする。`num1` の i 桁目と `num2` の j 桁目の積は、結果の `i + j` 桁目と `i + j + 1` 桁目に加算される、という位置関係が鍵である。

## 思考プロセス

1. **筆算の掛け算を再現する**: 整数に変換できないので、1桁ずつ掛け算して結果を蓄積する筆算のアルゴリズムをそのまま実装する
2. **積の最大桁数を見積もる**: n桁の数とm桁の数の積は最大で `n + m` 桁になる（例: 99 × 99 = 9801、2桁 × 2桁 = 4桁）。そこで、サイズ `n + m` の配列 `pos` を用意し、各桁の値を格納する
3. **各桁の積が結果のどの位置に対応するかを特定する**: `num1` の右から数えて i 番目の桁と `num2` の右から数えて j 番目の桁の積は、結果の右から `i + j` 番目と `i + j + 1` 番目の位置に影響する。文字列のインデックスでは、`num1[i] * num2[j]` の積は `pos[i + j + 1]`（下の桁）と `pos[i + j]`（上の桁）に加算される
4. **繰り上がりをその場で処理する**: 各桁ペアの積を計算したら、`pos[p2]` に既に蓄積されている値と足し合わせ、10で割った余りをその桁に残し、10で割った商を上の桁 `pos[p1]` に加算する。これにより繰り上がりが即座に処理される
5. **先頭のゼロを除去して文字列を構築する**: 配列 `pos` の先頭にはゼロが含まれる場合がある（例: 3桁 × 2桁の積が4桁のとき、5桁分の配列の先頭が0になる）。先頭のゼロをスキップしながら `StringBuilder` で文字列を構築する
6. **ゼロの特別処理**: 入力のどちらかが `"0"` の場合、積は必ず `"0"` なので、早期に `"0"` を返す

## 前提知識

### charAt と文字から数値への変換

`String.charAt(i)` は文字列の i 番目の文字を `char` 型で返す。`char` 型の `'0'`〜`'9'` を整数 0〜9 に変換するには、`'0'` の文字コードを引く。

```java
String s = "123";
char c = s.charAt(0);       // '1'（char型）
int digit = c - '0';        // 1（int型）。'1'のコード49から'0'のコード48を引く
```

### 筆算の位置関係

n桁 × m桁の筆算では、`num1[i]` と `num2[j]` の積（最大81）は2桁になりうる。この2桁は結果の `pos[i + j]`（上の桁）と `pos[i + j + 1]`（下の桁）に対応する。

```
例: "12" × "34"
  num1[0]=1, num2[0]=3 → 積3  → pos[0], pos[1] に加算
  num1[0]=1, num2[1]=4 → 積4  → pos[1], pos[2] に加算
  num1[1]=2, num2[0]=3 → 積6  → pos[1], pos[2] に加算
  num1[1]=2, num2[1]=4 → 積8  → pos[2], pos[3] に加算
```

### StringBuilder

可変長の文字列を効率的に構築するクラス。`append` で末尾に文字を追加し、最後に `toString` で `String` に変換する。

```java
StringBuilder sb = new StringBuilder();  // 空のStringBuilderを作成
sb.append(4);                            // "4" を末尾に追加
sb.append(0);                            // "40" になる
sb.append(8);                            // "408" になる
sb.toString();                           // String型 "408" を返す
sb.length();                             // 現在の文字数を返す → 3
```

## 計算量

| | 値 |
|---|---|
| Time | O(n × m) — num1の各桁とnum2の各桁の全ペアを1回ずつ掛け算する |
| Space | O(n + m) — 積の各桁を格納する配列のサイズが n + m である |

## コード

```java
// 入力: 非負整数を表す文字列 num1 と num2
// 出力: 2つの数の積を表す文字列を返す
String multiply(String num1, String num2) {
    // どちらかが"0"なら積は必ず0なので、早期に"0"を返して終了する
    if (num1.equals("0") || num2.equals("0"))
        return "0";

    int n = num1.length();
    int m = num2.length();
    // 積の各桁を格納する配列。n桁×m桁の積は最大n+m桁なので、このサイズで十分
    int[] pos = new int[n + m];

    // 筆算と同じく下の桁（末尾）から先頭に向かって順に掛け算する
    for (int i = n - 1; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // charAtで取得した文字から'0'を引くことで、文字を対応する整数に変換して掛け算する
            int mul = (num1.charAt(i) - '0')
                * (num2.charAt(j) - '0');
            // 積が加算される位置: p1が上の桁、p2が下の桁。この位置関係は筆算における桁の対応に基づく
            int p1 = i + j;
            int p2 = i + j + 1;
            // 過去のループで同じ位置に加算された値を考慮し、既に蓄積されている値と足し合わせる
            int sum = mul + pos[p2];
            // 下の桁に1桁分だけ残し（10で割った余り）、繰り上がりを上の桁に加算する（10で割った商）
            pos[p2] = sum % 10;
            pos[p1] += sum / 10;
        }
    }

    // 先頭のゼロをスキップしながら文字列を構築する（例: 5桁分の配列の先頭が0のケース）
    StringBuilder sb = new StringBuilder();
    for (int p : pos) {
        // StringBuilderがまだ空で、かつ現在の値が0の場合は先頭のゼロなのでスキップする
        if (sb.length() == 0 && p == 0)
            continue;
        sb.append(p);
    }
    // StringBuilderをString型に変換して返す
    return sb.toString();
}
```
