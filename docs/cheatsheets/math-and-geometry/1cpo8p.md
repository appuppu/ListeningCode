# Rotating a Matrix 90 Degrees — n×n行列を追加メモリなしで時計回りに90度回転させる

## 問題の本質

n×n の正方行列が与えられる。この行列を時計回りに90度回転させる。新しい行列を割り当てずに、**in-place（その場で）** 変換を行う。回転後、元の行列の各要素 `matrix[i][j]` は `matrix[j][n-1-i]` の位置に移動する。

## 核心のアイデア

90度回転は「転置（行と列を入れ替え）」+「各行を左右反転」の2つの単純な操作に分解できる。この分解により、追加メモリなしで各要素を正しい位置に移動できる。

## 思考プロセス

1. **回転の移動先を観察する**: 要素 `matrix[i][j]` は90度時計回り回転で `matrix[j][n-1-i]` に移動する。この変換を直接1要素ずつ行うと4要素の循環置換が必要になり複雑になる
2. **回転を既知の操作に分解できないか考える**: 転置操作は `matrix[i][j]` を `matrix[j][i]` に移動する。転置後に各行を左右反転すると、`matrix[j][i]` が `matrix[j][n-1-i]` に移動する。これは元の `matrix[i][j]` → `matrix[j][n-1-i]` という90度回転と一致する
3. **転置をin-placeで実現する方法**: 対角線（`i == j`）を境に上三角と下三角の要素を交換する。`j > i` の範囲で `matrix[i][j]` と `matrix[j][i]` をswapすれば、各ペアを1回だけ交換できる
4. **各行の反転をin-placeで実現する方法**: 各行に対して、左端と右端のポインタを用意し、中央に向かって要素を交換していく。この操作は追加メモリを必要としない
5. **2つの操作を順番に適用する**: まず行列全体を転置し、次に各行を反転する。どちらもin-placeで行えるため、全体としてO(1)の追加メモリで90度回転が完成する

## 前提知識

### 転置（Transpose）とは

行列の行と列を入れ替える操作。要素 `matrix[i][j]` と `matrix[j][i]` の位置を交換する。正方行列の場合、対角線上の要素は動かず、対角線を挟んで対称な位置の要素同士を交換する。

```java
// 3×3行列の転置の例
// 転置前:        転置後:
// [1, 2, 3]     [1, 4, 7]
// [4, 5, 6]  →  [2, 5, 8]
// [7, 8, 9]     [3, 6, 9]

// matrix[0][1]=2 と matrix[1][0]=4 が交換される
int temp = matrix[i][j];
matrix[i][j] = matrix[j][i];
matrix[j][i] = temp;
```

### 配列の反転（Reverse）とは

配列の要素を左右対称に入れ替える操作。左端と右端から中央に向かってポインタを進めながら交換する。

```java
// [1, 4, 7] → [7, 4, 1]
int left = 0, right = n - 1;
while (left < right) {
    int temp = array[left];
    array[left] = array[right];
    array[right] = temp;
    left++;
    right--;
}
```

### in-place（その場で）操作とは

新しいデータ構造を割り当てずに、入力データ自身を直接変更する操作。一時変数（`temp`）の使用はO(1)なので許容される。問題が「新しい行列を割り当てるな」と指示しているため、in-placeで解く必要がある。

## 計算量

| | 値 |
|---|---|
| Time | O(n²) — 転置でn²/2回、反転でn²/2回の交換を行う |
| Space | O(1) — 一時変数のみ使用し、新しい行列は割り当てない |

## コード

```java
// 入力: n×n の整数行列 matrix（2次元配列 int[][]）。正方行列なので行数と列数は同じ
// 出力: なし（void）。引数の matrix 自体を90度時計回りに回転させた状態に変更する
public void rotate(int[][] matrix) {
    // matrix.length で行列のサイズ n を取得する
    int n = matrix.length;

    // ステップ1: 転置（対角線を挟んで要素を交換し、行と列を入れ替える）
    for (int i = 0; i < n; i++) {
        // j を i+1 から開始する理由: 対角線上(i==j)は交換不要、j<i の範囲は既に交換済み
        for (int j = i + 1; j < n; j++) {
            // matrix[i][j] と matrix[j][i] を一時変数を使って交換し、行と列を入れ替える
            int temp = matrix[i][j];
            matrix[i][j] = matrix[j][i];
            matrix[j][i] = temp;
        }
    }

    // ステップ2: 各行を左右反転する
    for (int i = 0; i < n; i++) {
        // 左端と右端の2つのポインタを用意し、中央に向かって交換していく
        int left = 0, right = n - 1;
        while (left < right) {
            // matrix[i][left] と matrix[i][right] を交換して行を左右反転する
            int temp = matrix[i][left];
            matrix[i][left] = matrix[i][right];
            matrix[i][right] = temp;
            left++;
            right--;
        }
    }
    // すべての行の反転が完了した時点で、行列全体が90度時計回りに回転した状態になっている
}
```
