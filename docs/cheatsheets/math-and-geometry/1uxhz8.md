# Determining if a Number is a Happy Number — 各桁の二乗和を繰り返して1に到達するか判定する

## 問題の本質

正の整数 `n` が与えられる。`n` の各桁の数字を二乗して合計する操作を繰り返し、結果が **1** に到達すれば「ハッピー数」として `true` を返す。1に到達せず無限ループに陥る場合は `false` を返す。

## 核心のアイデア

各桁の二乗和を繰り返す操作は、必ず有限個の値の中を巡回する。これはリンクリストのサイクル検出と同じ構造であり、Floyd のスローポインタとファストポインタを使えば、追加メモリなしでサイクルの有無と到達先を判定できる。

## 思考プロセス

1. **操作を繰り返すと必ずループする**: 各桁の二乗和を計算する操作を繰り返すと、値は有限の範囲に収まるため、いずれ過去に出た値に再び到達する。つまり、数列は必ず「1で止まるループ」か「1を含まないループ」のどちらかに入る
2. **ループ検出はサイクル検出問題に帰着できる**: 各値から次の値への遷移を「ノードからノードへのリンク」と見なせば、この問題はリンクリストにサイクルがあるかを検出する問題と同じ構造になる
3. **Floyd の二ポインタ法でO(1)空間で検出する**: スローポインタは1ステップずつ、ファストポインタは2ステップずつ進める。サイクルが存在すれば、2つのポインタは必ずサイクル内のどこかで合流する
4. **合流地点の値で結果を判定する**: 2つのポインタが合流したとき、その値が1であればハッピー数である（1の各桁の二乗和は1なので、1自身がサイクルを形成する）。1以外で合流した場合は、1を含まないサイクルに入っているので、ハッピー数ではない
5. **初期値の設定**: スローポインタを `n` に、ファストポインタを `getNext(n)` に設定して開始する。こうすることで、`while (slow != fast)` のループに自然に入れる

## 前提知識

### 各桁の二乗和の計算

整数 `n` の各桁を取り出すには、`n % 10` で最下位の桁を得て、`n /= 10` で最下位の桁を除去する操作を `n` が0になるまで繰り返す。

```java
int n = 19;
int digit = n % 10;   // 最下位の桁を取得 → 9
n /= 10;              // 最下位の桁を除去 → nは1になる
digit = n % 10;       // 次の桁を取得 → 1
// 19 → 1² + 9² = 1 + 81 = 82
```

### Floyd のサイクル検出法（二ポインタ法）とは

リンクリストや数列にサイクル（ループ）があるかを検出するアルゴリズム。スローポインタは1ステップずつ、ファストポインタは2ステップずつ進める。サイクルが存在する場合、ファストポインタはスローポインタに追いつき、必ず合流する。追加のデータ構造を使わないため、空間計算量はO(1)である。

```java
int slow = start;                // スローポインタは1ステップずつ進む
int fast = getNext(start);       // ファストポインタは初期位置を1つ先にする
while (slow != fast) {
    slow = getNext(slow);        // 1ステップ進む
    fast = getNext(getNext(fast)); // 2ステップ進む
}
// ループ終了時、slow == fast が合流地点の値
```

## 計算量

| | 値 |
|---|---|
| Time | O(log n) — 各桁の二乗和の計算にO(log n)かかり、サイクルに到達するまでの反復回数は定数に収まる |
| Space | O(1) — スローポインタとファストポインタの2つの変数のみを使用する |

## コード

```java
// 入力: 正の整数 n
// 出力: n がハッピー数であれば true、そうでなければ false を返す

// 整数nの各桁の二乗和を計算して返すヘルパー関数
// n % 10 で最下位の桁を取り出し、二乗を累積し、n /= 10 で桁を除去する操作を繰り返す
private int getNext(int n) {
    int sum = 0;
    while (n > 0) {
        int digit = n % 10;   // 最下位の桁を取り出す
        sum += digit * digit;  // 桁の二乗をsumに加算する
        n /= 10;               // 最下位の桁を除去する
    }
    return sum;
}

public boolean isHappy(int n) {
    // スローポインタはnから、ファストポインタは1ステップ先のgetNext(n)から開始する
    // fastを1つ先にすることで、while (slow != fast) のループに自然に入れる
    int slow = n;
    int fast = getNext(n);

    // 2つのポインタが合流するまでループする
    // スローとファストの速度差により、サイクルが存在すれば必ず合流する
    while (slow != fast) {
        slow = getNext(slow);           // スローポインタは1ステップ進む
        fast = getNext(getNext(fast));   // ファストポインタは2ステップ進む
    }

    // 合流地点が1であればハッピー数（1の各桁の二乗和は1なので、1自身がサイクルを形成する）
    // 1以外で合流した場合は、1を含まないサイクルに入っているのでハッピー数ではない
    return fast == 1;
}
```
