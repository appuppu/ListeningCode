# Detecting Axis-Aligned Squares From Points — 格納された点から軸に平行な正方形を数える

## 問題の本質

2D平面上に点を追加する `add` 操作と、与えられた点を1つの頂点として含む**軸に平行な正方形**（4辺がすべてx軸またはy軸に平行）の個数を返す `count` 操作を持つデータ構造を設計する。同じ座標に複数回追加された点は、それぞれ別の点として扱う。

## 核心のアイデア

軸に平行な正方形は、対角線上の2点が決まれば残り2点が一意に決まる。クエリ点と同じx座標を持つ点を対角線のパートナー候補として列挙し、残り2つの角の存在をHashMapでO(1)で確認すれば、効率的に正方形を数えられる。

## 思考プロセス

1. **軸に平行な正方形の性質を理解する**: 4辺がx軸・y軸に平行なので、4頂点は `(x1,y1)`, `(x1,y2)`, `(x2,y1)`, `(x2,y2)` の形になる。つまり、x座標が同じ2点とy座標が同じ2点の組み合わせで構成される
2. **対角線上の2点から残り2点を特定する**: クエリ点 `(px, py)` と、同じx座標で異なるy座標の点 `(px, pt_y)` を選ぶと、辺の長さは `|py - pt_y|` になる。残り2つの頂点は `(px ± side, py)` と `(px ± side, pt_y)` の位置に存在しなければならない
3. **正方形は左右2方向にできる**: 辺の長さ `side` が決まると、もう一方のx座標は `px - side` または `px + side` の2通りがある。両方の方向を確認する必要がある
4. **各座標の点の個数を記録する**: 同じ座標に複数の点が追加されることがあるため、HashMapで各座標の点の出現回数を管理する。残り2頂点の出現回数の積が、その組み合わせで作れる正方形の数になる
5. **同じx座標の点を高速に取得する**: x座標をキーとして、その座標を持つ全ての点のリストを別のHashMapで管理する。こうすることで `count` 時に同じx座標の点だけを効率的に列挙できる
6. **結果を積算して返す**: 各パートナー候補と各方向について、残り2頂点の出現回数の積を結果に加算していく

## 前提知識

### HashMap のキーに座標を使う方法

2次元座標 `(x, y)` をHashMapのキーにするには、文字列 `"x,y"` に変換する方法がある。これにより任意の座標に対してO(1)で値を格納・取得できる。

```java
Map<String, Integer> cnt = new HashMap<>();
String key = x + "," + y;               // 座標(3,5) → "3,5"
cnt.put(key, cnt.getOrDefault(key, 0) + 1);  // その座標の出現回数を1増やす
cnt.getOrDefault(key, 0);               // 存在しなければ0を返す
```

### computeIfAbsent とは

指定したキーがMapに存在しない場合のみ、新しい値を生成して登録するメソッド。キーが既に存在する場合はそのまま既存の値を返す。リストのMapを構築するときに便利である。

```java
Map<Integer, List<int[]>> xMap = new HashMap<>();
// キー5が存在しなければ新しいArrayListを作成し、存在すればそのリストを返す
xMap.computeIfAbsent(5, k -> new ArrayList<>()).add(new int[]{5, 3});
```

### 組み合わせの数え方（積の法則）

2つの独立した選択肢がそれぞれ `c1` 通りと `c2` 通りある場合、組み合わせの総数は `c1 * c2` になる。本問題では、残り2頂点の座標にそれぞれ `c1` 個と `c2` 個の点が存在するとき、その2頂点の選び方は `c1 * c2` 通りになる。

## 計算量

| | 値 |
|---|---|
| Time | add: O(1) — HashMapへの登録のみ。count: O(n) — 同じx座標の点を全て走査する |
| Space | O(n) — 全ての点の座標と出現回数をHashMapに保存する |

## コード

```java
// add(int[] p): 2D平面上に点 p = [x, y] を追加する
// count(int[] p): 点 p = [x, y] を1つの頂点として含む軸に平行な正方形の個数を int で返す
class DetectSquares {
    // 各座標の出現回数を管理するHashMap（キー: "x,y"）
    // count時に任意の座標に何個の点があるかをO(1)で取得するために使う
    Map<String, Integer> cnt;
    // 同じx座標を持つ点のリストを管理するHashMap（キー: x座標）
    // count時に同じx座標の点だけを効率的に列挙するために使う
    Map<Integer, List<int[]>> xMap;

    DetectSquares() {
        cnt = new HashMap<>();
        xMap = new HashMap<>();
    }

    void add(int[] p) {
        // 座標を文字列 "x,y" に変換して出現回数を1増やす
        String key = p[0] + "," + p[1];
        cnt.put(key, cnt.getOrDefault(key, 0) + 1);

        // x座標ごとのリストに点を追加する（初めてのx座標なら新しいリストを作成）
        xMap.computeIfAbsent(p[0],
            k -> new ArrayList<>()).add(p);
    }

    int count(int[] p) {
        int res = 0;
        int px = p[0], py = p[1];

        // クエリ点と同じx座標を持つ点のリストを取得する
        // リストが存在しない場合は正方形を構成できないため0を返す
        List<int[]> same = xMap.get(px);
        if (same == null) return 0;

        // 同じx座標の各点をパートナー候補として走査する
        for (int[] pt : same) {
            // 辺の長さを計算する（クエリ点とパートナー点のy座標の差の絶対値）
            int side = Math.abs(py - pt[1]);
            // 同じy座標の点は辺の長さが0になり正方形を構成できないのでスキップする
            if (side == 0) continue;

            // 正方形は左右2方向にできるので、両方のx座標を試す
            int[] dirs = {px - side, px + side};
            for (int nx : dirs) {
                // 残り2頂点の座標 (nx, py) と (nx, pt[1]) の出現回数を取得する
                // 存在しない座標は0になり、積も0になるため自動的に加算されない
                String k1 = nx + "," + py;
                String k2 = nx + "," + pt[1];
                int c1 = cnt.getOrDefault(k1, 0);
                int c2 = cnt.getOrDefault(k2, 0);

                // 2頂点の出現回数の積が、この組み合わせで作れる正方形の数（積の法則）
                res += c1 * c2;
            }
        }
        return res;
    }
}
```
