# Traversing a Matrix in Spiral Order — 行列の全要素を渦巻き順に取得する

## 問題の本質

m行n列の行列 `matrix` が与えられる。左上隅から開始し、右→下→左→上の順に外周をなぞり、内側へ向かって繰り返すことで、全要素を**渦巻き（スパイラル）順**に並べた配列を返す。

## 核心のアイデア

行列の外周を1つの「層」とみなし、上辺・右辺・下辺・左辺の4辺を順に走査する。1層分の走査が終わったら4つの境界ポインタを内側に縮めることで、次の層へ自然に移行できる。

## 思考プロセス

1. **スパイラル走査は4方向の繰り返しである**: 右→下→左→上の4方向を外周から内側へ繰り返す構造なので、現在の走査範囲の「上端・下端・左端・右端」を管理すれば、各方向の走査範囲が一意に決まる
2. **4つの境界ポインタで走査範囲を表現する**: `top`（上端の行）、`bottom`（下端の行）、`left`（左端の列）、`right`（右端の列）の4変数を用意する。これらが現在の層の四辺の位置を示す
3. **各辺の走査順序を決める**: 上辺は左から右へ（列を増やす）、右辺は上から下へ（行を増やす）、下辺は右から左へ（列を減らす）、左辺は下から上へ（行を減らす）。この4つのforループで1層分の走査が完了する
4. **1辺の走査後に境界を縮める**: 上辺を走査したら `top++`（上端を1行下げる）、右辺を走査したら `right--`（右端を1列左へ）、下辺を走査したら `bottom--`、左辺を走査したら `left++`。これにより次のループでは1つ内側の層を走査する
5. **下辺と左辺の走査には追加条件が必要である**: 上辺の走査後に `top` を増やし、右辺の走査後に `right` を減らすため、下辺の走査時点で `top <= bottom` が崩れている可能性がある。同様に左辺の走査時点で `left <= right` が崩れている可能性がある。これらの条件を満たさない場合、既に走査済みの行や列を重複して読んでしまうため、条件チェックが必要である
6. **終了条件は境界の交差である**: `top > bottom` または `left > right` になった時点で、全ての層の走査が完了している。whileループの条件に `top <= bottom && left <= right` を指定すれば自然に終了する

## 前提知識

### ArrayList とは

可変長の配列。要素を末尾に追加する `add` がO(1)で行える。結果のスパイラル順配列を構築するために使用する。

```java
List<Integer> res = new ArrayList<>();  // 空のArrayListを作成
res.add(5);                             // 末尾に5を追加する → [5]
res.add(3);                             // 末尾に3を追加する → [5, 3]
res.size();                             // 要素数を返す → 2
```

### 境界ポインタ（Boundary Pointers）とは

行列の走査範囲を示す4つの整数変数。`top` と `bottom` が行の範囲、`left` と `right` が列の範囲を表す。走査のたびに値を変更することで、範囲を内側へ縮小する。

```java
int top = 0;                    // 上端の行インデックス（初期値: 0）
int bottom = matrix.length - 1; // 下端の行インデックス（初期値: 最終行）
int left = 0;                   // 左端の列インデックス（初期値: 0）
int right = matrix[0].length - 1; // 右端の列インデックス（初期値: 最終列）
top++;    // 上端を1行下に縮める
right--;  // 右端を1列左に縮める
```

## 計算量

| | 値 |
|---|---|
| Time | O(m × n) — 行列の全要素をちょうど1回ずつ走査する |
| Space | O(1) — 出力用リストを除き、境界ポインタ4つのみを使用する |

## コード

```java
// 入力: m行n列の整数行列 matrix
// 出力: 全要素をスパイラル順に格納した List<Integer> を返す
List<Integer> spiralOrder(int[][] matrix) {
    // 結果を格納する可変長リストを作成する
    List<Integer> res = new ArrayList<>();
    // 行列が空（行数が0）の場合は空リストをそのまま返す
    if (matrix.length == 0) return res;

    // 4つの境界ポインタを初期化する。これらが現在走査すべき層の四辺の位置を表す
    int top = 0;                      // 上端の行（最上行）
    int bottom = matrix.length - 1;   // 下端の行（最下行）
    int left = 0;                     // 左端の列（最左列）
    int right = matrix[0].length - 1; // 右端の列（最右列）

    // 走査範囲が存在する間、層ごとに繰り返す。境界が交差したら全要素の走査が完了している
    while (top <= bottom && left <= right) {
        // 上辺: 左から右へ走査する
        for (int c = left; c <= right; c++)
            res.add(matrix[top][c]);
        // 上辺の走査完了。上端を1行下に縮め、次の右辺走査で角の要素を重複して読まないようにする
        top++;

        // 右辺: 上から下へ走査する（topは更新済みなので角の重複なし）
        for (int r = top; r <= bottom; r++)
            res.add(matrix[r][right]);
        // 右辺の走査完了。右端を1列左に縮める
        right--;

        // 下辺: 右から左へ走査する
        // 条件チェック: top++の結果 top > bottom になる場合（残り1行だった場合）、
        // 下辺は上辺と同じ行であり既に走査済みなのでスキップする
        if (top <= bottom) {
            for (int c = right; c >= left; c--)
                res.add(matrix[bottom][c]);
            // 下端を1行上に縮める
            bottom--;
        }

        // 左辺: 下から上へ走査する
        // 条件チェック: right--の結果 left > right になる場合（残り1列だった場合）、
        // 左辺は右辺と同じ列であり既に走査済みなのでスキップする
        if (left <= right) {
            for (int r = bottom; r >= top; r--)
                res.add(matrix[r][left]);
            // 左端を1列右に縮める
            left++;
        }
    }
    // 全 m×n 個の要素がスパイラル順に格納されたリストを返す
    return res;
}
```
