# Adding One to a Number Represented as an Array — 配列で表現された数値に1を加算する

## 問題の本質

非負整数を1桁ずつ格納した配列 `digits` が与えられる。配列の先頭が最上位桁、末尾が最下位桁である。この数値に1を加算し、結果を同じ形式の配列で返す。各要素は0から9の1桁の数字である。

## 核心のアイデア

末尾の桁から1を加算し、繰り上がりが発生しなくなった時点で即座に返せる。繰り上がりが発生するのはその桁が9のときだけであり、全桁が9の場合のみ配列の長さが1つ増える。

## 思考プロセス

1. **加算は最下位桁から行う**: 数値の加算は一の位から始めるのが自然であるため、配列の末尾から先頭に向かって逆順に走査する
2. **繰り上がりが止まる条件を考える**: 現在の桁が9未満であれば、1を加算しても繰り上がりは発生しない。その時点で加算は完了するので、即座に配列を返せる
3. **桁が9の場合の処理を考える**: 現在の桁が9のとき、1を加算すると10になり繰り上がりが発生する。この桁を0にして、次の上位桁に繰り上がりを伝播させる。ループの次のイテレーションで上位桁に1を加算する処理が自然に行われる
4. **全桁が9だった場合を考える**: 999のように全桁が9の場合、ループが最後まで回っても繰り上がりが止まらない。結果は1000のように桁数が1つ増える。この場合だけ新しい配列を作成し、先頭に1を設定する。Javaの `new int[]` は全要素が0で初期化されるため、残りの桁に0を代入する必要はない
5. **繰り上がりを変数で管理する必要はない**: 繰り上がりの値は常に1であり、ループが継続している時点で繰り上がりが存在することが確定しているため、carry変数を用意せずにループの継続自体が繰り上がりの存在を意味する構造にできる

## 前提知識

### 配列の逆順走査

配列の末尾から先頭に向かってループする。`i = n - 1` から始めて `i >= 0` の間 `i--` でデクリメントする。

```java
int[] digits = {1, 2, 3};
int n = digits.length;                  // 配列の長さを取得 → 3
for (int i = n - 1; i >= 0; i--) {      // i=2, 1, 0 の順にループ
    System.out.println(digits[i]);      // 3, 2, 1 の順に出力される
}
```

### Javaの配列初期化

`new int[n]` で長さnの整数配列を作成すると、全要素が自動的に0で初期化される。明示的に0を代入する必要はない。

```java
int[] result = new int[4];   // {0, 0, 0, 0} で初期化される
result[0] = 1;               // {1, 0, 0, 0} になる
```

## 計算量

| | 値 |
|---|---|
| Time | O(n) — 配列を末尾から先頭まで最大1回走査する |
| Space | O(1) — 全桁が9の場合を除き、入力配列をその場で変更するため追加メモリは不要 |

## コード

```java
// 入力: 非負整数の各桁を格納した整数配列 digits
// 出力: digits が表す数値に1を加算した結果を格納した int[] を返す
public int[] plusOne(int[] digits) {
    // 配列の長さを保存。逆順走査のループ上限と、全桁9の場合の新配列の長さに使用する
    int n = digits.length;

    // 末尾から先頭に向かって走査する。ループが継続していること自体が「繰り上がりが存在する」ことを意味する
    for (int i = n - 1; i >= 0; i--) {
        // 現在の桁が9未満なら繰り上がりは発生しない。加算して即座に返せる
        if (digits[i] < 9) {
            digits[i]++;
            return digits;  // 繰り上がりなし。変更済みの配列をそのまま返して終了
        }
        // 現在の桁が9なので0にして繰り上がりを上位桁に伝播する
        digits[i] = 0;
    }

    // 全桁が9だった場合（例: [9,9,9] → [0,0,0]）、桁数が1つ増える
    // new int[] は全要素0で初期化されるため、残りの桁に0を代入する必要はない
    int[] result = new int[n + 1];
    result[0] = 1;  // 先頭に1を設定（例: 999 + 1 = 1000 → [1, 0, 0, 0]）
    return result;
}
```
