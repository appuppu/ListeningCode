# Finding the Largest Island by Area — 2Dグリッド上で最大面積の島を見つける

## 問題の本質

`1`（陸地）と `0`（水）で構成される2Dバイナリグリッドが与えられる。島とは、上下左右に隣接する `1` のセルが連結したグループである。グリッド内のすべての島の中から**最大の面積**（セル数）を求めて返す。島が存在しない場合は `0` を返す。

## 核心のアイデア

各陸地セルからDFSで連結する陸地を数えれば島の面積が求まる。訪問済みのセルを別配列で管理する代わりに、訪問したセルの値を `0` に書き換えることで、追加メモリなしに重複訪問を防げる。

## 思考プロセス

1. **島の面積は連結成分のサイズである**: グリッド上の `1` が上下左右に連結したグループが1つの島を構成する。島の面積とは、そのグループに含まれるセルの個数である。したがって、各連結成分のサイズを求め、その最大値を返せばよい
2. **連結成分の探索にはDFSが適している**: あるセル `(r, c)` が `1` であれば、そこを起点にDFSで上下左右の隣接セルを再帰的に探索し、連結しているすべての `1` を数え上げることで、その島の面積が求まる
3. **同じセルを複数回カウントしない仕組みが必要**: DFSで訪問したセルを再度訪問すると面積を二重にカウントしてしまう。通常は `boolean[][] visited` 配列を用意して訪問済みを記録するが、これにはO(m × n)の追加メモリが必要になる
4. **訪問済みセルを `0` に書き換えれば追加メモリが不要になる**: DFSで訪問したセルの値を `1` から `0` に変更すれば、そのセルは水として扱われ、以降の探索で再訪問されない。`visited` 配列を使わずに重複防止ができ、補助メモリがO(1)になる
5. **DFSの戻り値で面積を集計する**: DFSは訪問したセル自身の `1`（カウント）に、上下左右4方向の再帰呼び出しの戻り値を加算して返す。基底条件として、グリッド範囲外または値が `0` のセルは `0` を返す。これにより、1回のDFS呼び出しで島全体の面積が再帰的に集計される
6. **グリッド全体を走査して最大値を求める**: 二重forループでグリッドの全セルを走査し、各セルについてDFSを呼び出す。DFSの戻り値（島の面積）と現在の最大値を比較し、大きい方を保持する。値が `0` のセルではDFSの基底条件で即座に `0` が返るため、特別な分岐は不要である

## 前提知識

### DFS（深さ優先探索）とは

グラフやグリッドの探索アルゴリズム。1つのノードから出発し、行けるところまで深く進んでから戻る。2Dグリッドでは、あるセルから上下左右の隣接セルへ再帰的に移動することで、連結したセルをすべて訪問できる。

```java
// 2Dグリッドにおける基本的なDFSの構造
void dfs(int[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length || c < 0 || c >= grid[0].length)
        return;                    // グリッド範囲外なら終了
    dfs(grid, r - 1, c);          // 上方向へ再帰
    dfs(grid, r + 1, c);          // 下方向へ再帰
    dfs(grid, r, c - 1);          // 左方向へ再帰
    dfs(grid, r, c + 1);          // 右方向へ再帰
}
```

### In-place Modification（その場での書き換え）とは

入力データ自体を変更することで、追加のデータ構造（配列やセットなど）を使わずに状態を記録する手法。この問題では、訪問済みの陸地セルを `0` に書き換えることで、`visited` 配列の代わりとする。

```java
grid[r][c] = 0;  // 訪問済みの陸地(1)を水(0)に書き換える
```

### Math.max とは

2つの値を比較して大きい方を返すJavaの標準メソッド。ループ内で最大値を更新し続ける場面で使う。

```java
Math.max(3, 7);   // → 7（大きい方を返す）
Math.max(10, 2);  // → 10
```

## 計算量

| | 値 |
|---|---|
| Time | O(m × n) — グリッドの全セルを最大2回（ループで1回、DFSで1回）訪問する |
| Space | O(1) 補助メモリ — visited配列を使わずグリッドを直接書き換える。ただし再帰スタックに最大O(m × n)を使用する |

## コード

```java
// 入力: 1（陸地）と 0（水）で構成される2D整数配列 grid
// 出力: グリッド内の最大の島の面積を int で返す。島がなければ 0 を返す

// DFS: 連結した陸地セルを数え、訪問済みセルを0に書き換える
int dfs(int[][] grid, int r, int c) {
    // 基底条件: 範囲外または水(0)/訪問済みならカウントしない
    if (r < 0 || r >= grid.length
        || c < 0 || c >= grid[0].length
        || grid[r][c] == 0)
        return 0;

    // 訪問済みとして陸地(1)を水(0)に書き換える（in-place modification で visited 配列を不要にする）
    grid[r][c] = 0;

    // 自身の1 + 上下左右の連結セル数を合計して返す
    // 4方向の再帰の戻り値を加算することで、島全体の面積が再帰的に集計される
    return 1 + dfs(grid, r - 1, c)   // 上
             + dfs(grid, r + 1, c)   // 下
             + dfs(grid, r, c - 1)   // 左
             + dfs(grid, r, c + 1);  // 右
}

int maxAreaOfIsland(int[][] grid) {
    // グリッドの行数と列数を取得
    int m = grid.length;
    int n = grid[0].length;
    // 最大面積を記録する変数を 0 で初期化（島がなければこの値がそのまま返る）
    int maxArea = 0;

    // 二重forループで全セルを走査し、各島の面積の最大値を求める
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // 値が 0 のセルでは DFS の基底条件で即座に 0 が返るため、特別な分岐は不要
            maxArea = Math.max(maxArea,
                dfs(grid, i, j));

    return maxArea;
}
```
