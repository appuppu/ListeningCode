# Checking if a Graph Forms a Valid Tree — グラフが有効な木を形成するか判定する

## 問題の本質

`0` から `n-1` までのラベルが付いた `n` 個のノードと、無向辺のリスト `edges` が与えられる。このグラフが**有効な木（valid tree）**を形成するかを判定して `boolean` で返す。有効な木とは、すべてのノードが連結しており、かつサイクル（閉路）が存在しないグラフである。

## 核心のアイデア

木はノード数 `n` に対して辺の数がちょうど `n-1` 本であり、かつサイクルがない。辺の数が `n-1` 本であることを先に確認し、Union-Findで各辺を結合していく過程でサイクルの有無を検出すれば、木かどうかを判定できる。

## 思考プロセス

1. **木の必要条件を利用する**: 有効な木は必ず `n-1` 本の辺を持つ。辺の数が `n-1` でなければ、その時点で木ではないと即座に判定できる。この前提チェックにより、辺が多すぎる場合（サイクルが確実に存在）も辺が少なすぎる場合（連結でない）も除外できる
2. **サイクルの検出方法を考える**: 辺の数が `n-1` 本であっても、サイクルが存在する可能性がある（その場合は非連結になる）。各辺を追加するたびに、両端のノードが既に同じ連結成分に属しているかを判定すれば、サイクルを検出できる
3. **Union-Findで連結成分を管理する**: Union-Find（素集合データ構造）を使えば、2つのノードが同じ連結成分に属するかの判定（find）と、2つの連結成分の統合（union）をほぼO(1)で実行できる。各ノードの親を自分自身に初期化し、辺ごとにunionを行う
4. **サイクルの検出条件を定める**: union操作の際に、2つのノードのルート（根）が同じであれば、それらは既に連結されている。そこにさらに辺を追加するとサイクルが生じるため、`false` を返す
5. **全辺の処理後に結果を返す**: すべての辺を処理してもサイクルが検出されなければ、辺の数が `n-1` 本であること（ステップ1で確認済み）と合わせて、グラフは有効な木であると判定し `true` を返す

## 前提知識

### Union-Find（素集合データ構造）とは

複数の要素をグループ（集合）に分けて管理するデータ構造。2つの操作を提供する。`find` はある要素が属するグループの代表元（ルート）を返す。`union` は2つの要素が属するグループを1つに統合する。経路圧縮とランクによる最適化を行うと、各操作がほぼO(1)で実行できる。

```java
int[] parent = {0, 1, 2, 3, 4};  // 初期状態：各ノードの親は自分自身
int[] rank = new int[5];          // 各ノードのランク（木の高さの上限）を0で初期化

// find: ノードxのルートを返す（経路圧縮付き）
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 経路圧縮：親を直接ルートに付け替える
    return parent[x];
}
```

### 経路圧縮（Path Compression）とは

`find` を呼ぶたびに、探索経路上のすべてのノードの親を直接ルートに付け替える最適化手法。これにより次回以降の `find` がO(1)に近づく。`parent[x] = find(parent[x])` の再帰代入で実現する。

### ランクによる統合（Union by Rank）とは

2つの木を統合するとき、ランク（木の高さの上限）が低い方を高い方の下に付ける手法。木の高さの増加を抑え、`find` の探索距離を短く保つ。ランクが等しい場合のみ、統合後にランクを1増やす。

```java
// union: ノードaとノードbのグループを統合する。既に同じグループならfalseを返す
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // 各ノードのルートを取得する
    if (ra == rb) return false;       // 同じルート → 既に同じグループ → サイクル
    if (rank[ra] < rank[rb])
        parent[ra] = rb;             // ランクが低い方を高い方の下に付ける
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;             // ランクが等しい場合はraの下にrbを付ける
        rank[ra]++;                   // ランクを1増やす
    }
    return true;
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(n × α(n)) — 各辺に対してfindとunionを実行する。α(n)はアッカーマン関数の逆関数であり、実用上は定数とみなせる |
| Space | O(n) — parent配列とrank配列にそれぞれn個の要素を保存する |

## コード

```java
// 入力: 整数 n（ノード数）と二次元整数配列 edges（各要素は [u, v] の無向辺）
// 出力: グラフが有効な木であれば true、そうでなければ false を返す

// parent配列：各ノードの親を管理する
int[] parent, rank;

// ノードxが属する連結成分のルートを返す（経路圧縮付き）
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 経路圧縮：親を直接ルートに付け替える
    return parent[x];
}

// ノードaとノードbの連結成分を統合する。サイクルが生じる場合はfalseを返す
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // 両端ノードのルートを取得する
    if (ra == rb) return false;       // 同じルートならサイクルが生じる → この辺を追加するとサイクルになる
    // ランクが低い方を高い方の下に付けて木の高さを抑える
    if (rank[ra] < rank[rb])
        parent[ra] = rb;
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;
        rank[ra]++;
    }
    return true;
}

public boolean validTree(int n, int[][] edges) {
    // 木の辺の数はノード数-1でなければならない（多すぎればサイクル確定、少なすぎれば非連結）
    if (edges.length != n - 1)
        return false;

    // 各ノードの親を自分自身に初期化する（各ノードが独立した連結成分を形成する）
    parent = new int[n];
    rank = new int[n];
    for (int i = 0; i < n; i++)
        parent[i] = i;

    // 各辺を処理し、両端が既に同じ連結成分ならサイクルが生じるのでfalseを返す
    for (int[] e : edges)
        if (!union(e[0], e[1]))
            return false;

    // すべての辺を処理してもサイクルがなく、辺の数がn-1本なので有効な木である
    return true;
}
```
