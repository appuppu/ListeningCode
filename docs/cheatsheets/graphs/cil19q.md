# Determining if All Courses Can Be Completed — 全コースを完了できるかを判定する

## 問題の本質

`0` から `n-1` までのラベルが付いた `numCourses` 個のコースと、前提条件のペアのリスト `prerequisites` が与えられる。各ペア `[a, b]` は「コース `b` を先に履修しないとコース `a` を履修できない」ことを意味する。すべてのコースを履修できるかどうかを `boolean` で返す。これは有向グラフにサイクル（循環依存）が存在するかを検出する問題である。

## 核心のアイデア

コースの依存関係を有向グラフとして捉えると、すべてのコースを履修できるかは「グラフにサイクルがないか」と同義である。入次数（そのノードに入ってくる辺の数）が0のノードから順に処理していくトポロジカルソートを行い、すべてのノードを処理できればサイクルは存在しない。

## 思考プロセス

1. **問題をグラフに変換する**: 各コースをノード、各前提条件 `[a, b]` を「`b` → `a`」の有向辺として隣接リストを構築する。こうすれば依存関係がグラフ構造で表現できる
2. **サイクルがあると全履修は不可能**: コースAがBに依存し、BがAに依存するような循環があると、どちらも先に履修できない。よって問題は「有向グラフにサイクルがあるか」の判定に帰着する
3. **入次数に着目する**: 各ノードの入次数（前提条件の数）を数える。入次数が0のノードは前提条件がないのですぐに履修できる。これらを起点にすればよい
4. **入次数0のノードをキューに入れて処理を開始する**: BFSのようにキューを使い、入次数0のノードを順に処理する。処理済みのノードから出る辺の先のノードの入次数を1減らし、入次数が0になったノードを新たにキューに追加する
5. **処理済みノード数で判定する**: すべてのノードを処理できれば（処理済みカウント == `numCourses`）サイクルは存在せず、全コース履修可能である。サイクル内のノードは入次数が永遠に0にならないため、処理されずに残る

## 前提知識

### 隣接リスト（Adjacency List）とは

グラフを表現するデータ構造。各ノードについて、そのノードから辺が出ている先のノードのリストを保持する。`List<List<Integer>>` で実装し、`graph.get(i)` でノード `i` の隣接ノード一覧を取得できる。

```java
List<List<Integer>> graph = new ArrayList<>();
for (int i = 0; i < n; i++)
    graph.add(new ArrayList<>());  // 各ノードに空のリストを作成
graph.get(0).add(1);               // ノード0からノード1への辺を追加
graph.get(0);                       // ノード0の隣接ノード一覧 → [1]
```

### 入次数（In-degree）とは

有向グラフにおいて、あるノードに入ってくる辺の数。入次数が0のノードはどのノードにも依存していない。配列 `inDegree[i]` でノード `i` の入次数を管理する。

```java
int[] inDegree = new int[n];   // 全ノードの入次数を0で初期化
inDegree[0]++;                  // ノード0の入次数を1増やす
```

### Queue（キュー）とは

先入れ先出し（FIFO）のデータ構造。BFSで処理待ちのノードを管理するために使う。`offer` で末尾に追加し、`poll` で先頭から取り出す。

```java
Queue<Integer> queue = new LinkedList<>();
queue.offer(0);       // キューに0を追加する
queue.poll();          // キューの先頭を取り出して返す → 0
queue.isEmpty();       // キューが空かをbooleanで返す → true
```

## 計算量

| | 値 |
|---|---|
| Time | O(V + E) — 全ノード（V個）と全辺（E個）をそれぞれ1回ずつ処理する |
| Space | O(V + E) — 隣接リストに全辺を、入次数配列とキューに全ノードを保存する |

## コード

```java
// 入力: コース数 numCourses と前提条件の配列 prerequisites（各要素は [a, b] で「b → a」の依存を表す）
// 出力: すべてのコースを履修できるなら true、サイクルがあり履修不可能なら false
boolean canFinish(int numCourses, int[][] prerequisites) {
    // 各ノードの入次数（前提条件の数）を保存する配列。入次数は「そのコースの前提条件がいくつあるか」を表す
    int[] inDegree = new int[numCourses];

    // 隣接リストでグラフを構築する。graph.get(i) はノード i から辺が出ている先のノードのリスト
    List<List<Integer>> graph = new ArrayList<>();
    for (int i = 0; i < numCourses; i++)
        graph.add(new ArrayList<>());

    // 各前提条件から辺を追加し、入次数を更新する。これにより依存関係のグラフと各ノードの入次数が完成する
    for (int[] p : prerequisites) {
        graph.get(p[1]).add(p[0]);  // p[1] → p[0] の辺を追加
        inDegree[p[0]]++;           // p[0] の入次数を1増やす
    }

    // 入次数0のノード（前提条件なし）をキューに追加する。これらが最初に履修できるコースである
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (inDegree[i] == 0)
            queue.offer(i);

    // BFSで入次数0のノードから順に処理する
    int count = 0;  // 処理済みコース数を追跡する変数
    while (!queue.isEmpty()) {
        int course = queue.poll();
        count++;  // このノードは履修完了として扱う

        // 隣接ノードの入次数を1減らす（前提条件を1つ消化した意味）。0になったら全前提条件が満たされたのでキューに追加する
        for (int nei : graph.get(course))
            if (--inDegree[nei] == 0)
                queue.offer(nei);
    }

    // 全ノードを処理できればサイクルなし（全コース履修可能）。サイクル内のノードは入次数が0にならず処理されずに残る
    return count == numCourses;
}
```
