# Filling Distances to the Nearest Gate — グリッド内の各空き部屋から最寄りのゲートまでの距離を求める

## 問題の本質

m×n のグリッドが与えられる。各セルは「壁（-1）」「ゲート（0）」「空き部屋（Integer.MAX_VALUE）」のいずれかである。各空き部屋のセルに、最も近いゲートまでの距離を書き込む。どのゲートにも到達できない部屋は Integer.MAX_VALUE のままにする。

## 核心のアイデア

各空き部屋から最寄りのゲートを探すのではなく、すべてのゲートから同時にBFSを開始する。BFSの各ステップが距離1, 2, 3…に対応するため、最初に到達した時点でそのセルの最短距離が確定する。

## 思考プロセス

1. **各部屋からゲートを探すと非効率**: 空き部屋ごとにBFSを行うと、部屋の数だけBFSが走り計算量が膨らむ。発想を逆転し、ゲート側から部屋に向かって探索すれば、すべてのゲートを起点として1回のBFSで全部屋の最短距離が求まる
2. **複数のゲートから同時に出発する（Multi-source BFS）**: すべてのゲートをキューに入れた状態でBFSを開始する。こうすると、距離1の部屋がすべて先に処理され、次に距離2の部屋が処理される。BFSのレベル順探索の性質により、各部屋に最初に到達したときの距離が最短距離になる
3. **訪問済みの判定は値で行える**: 空き部屋は Integer.MAX_VALUE で初期化されている。BFSで到達したセルには距離を書き込むため、値が Integer.MAX_VALUE のセルだけが未訪問である。別途 visited 配列を用意する必要がない
4. **距離の計算は親セルの値+1**: キューから取り出したセル（親）の値に1を加えた値が、隣接セル（子）の距離になる。ゲートの値が0なので、隣接する部屋は1、その隣は2と正しく伝播する
5. **壁と範囲外は単にスキップする**: 壁（-1）やゲート（0）は Integer.MAX_VALUE ではないので、未訪問判定で自然に除外される。範囲外のインデックスは境界チェックで弾く

## 前提知識

### BFS（幅優先探索）とは

グラフやグリッドを「近い順」に探索するアルゴリズム。キュー（先入れ先出し）を使い、起点から距離1のノードをすべて処理してから距離2のノードに進む。この性質により、各ノードへの最短距離が保証される。

```java
Queue<int[]> queue = new LinkedList<>();  // BFS用のキューを作成
queue.offer(new int[]{0, 0});             // 起点の座標をキューに追加
int[] cell = queue.poll();                // キューの先頭から要素を取り出す
queue.isEmpty();                          // キューが空かどうかを判定する → true/false
```

### Multi-source BFS とは

通常のBFSは起点が1つだが、Multi-source BFSは複数の起点をキューに入れた状態で開始する。すべての起点から同時に波が広がるように探索が進み、各セルには最も近い起点からの距離が記録される。

```java
// すべてのゲート（値が0のセル）を起点としてキューに追加する
for (int i = 0; i < m; i++)
    for (int j = 0; j < n; j++)
        if (rooms[i][j] == 0)
            queue.offer(new int[]{i, j});
// この状態でBFSを開始すると、全ゲートから同時に探索が始まる
```

### 4方向の隣接セル探索

グリッド上で上下左右の4方向に移動するとき、方向ベクトルの配列を使うとコードが簡潔になる。各方向ベクトルを現在の座標に加算して隣接セルの座標を求める。

```java
int[][] dirs = {{-1,0},{1,0},{0,-1},{0,1}};  // 上・下・左・右の方向ベクトル
for (int[] d : dirs) {
    int r = cell[0] + d[0];  // 隣接セルの行番号
    int c = cell[1] + d[1];  // 隣接セルの列番号
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(m × n) — 各セルはキューに最大1回しか追加されないため、全セルを1回ずつ処理する |
| Space | O(m × n) — キューに最大m×n個のセルが入る可能性がある |

## コード

```java
// 入力: m×n の整数グリッド rooms（-1=壁、0=ゲート、Integer.MAX_VALUE=空き部屋）
// 出力: 戻り値なし（void）。rooms を直接書き換え、各空き部屋のセルに最寄りのゲートまでの距離を格納する
public void wallsAndGates(int[][] rooms) {
    // グリッドの行数を取得する
    int m = rooms.length;
    // グリッドが空なら処理を終了する
    if (m == 0) return;
    // グリッドの列数を取得する
    int n = rooms[0].length;

    // BFS用のキューを作成する。セルの座標 {行, 列} を格納する
    Queue<int[]> q = new LinkedList<>();

    // グリッド全体を走査し、すべてのゲート（値が0のセル）をキューに追加する
    // これにより、すべてのゲートがBFSの起点として同時に登録される（Multi-source BFS）
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (rooms[i][j] == 0)
                q.offer(new int[]{i, j});

    // 上・下・左・右の4方向を表す方向ベクトル。ループで隣接セルを列挙するために使う
    int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

    // キューが空になるまでBFSを続ける。BFSの性質により、距離が小さいセルから順に処理される
    while (!q.isEmpty()) {
        // キューの先頭からセルを取り出す。cell[0]が行番号、cell[1]が列番号
        int[] cell = q.poll();

        // 4方向の隣接セルを調べる
        for (int[] d : dirs) {
            // 方向ベクトルを加算して隣接セルの座標を計算する
            int r = cell[0] + d[0];
            int c = cell[1] + d[1];

            // 範囲外ならスキップする
            if (r < 0 || r >= m || c < 0 || c >= n) continue;

            // 値がInteger.MAX_VALUEでなければスキップする（壁・ゲート・距離確定済みの部屋）
            // この判定により、別途visited配列を用意しなくても再訪問を防げる
            if (rooms[r][c] != Integer.MAX_VALUE) continue;

            // 親セルの距離+1を書き込む。ゲートが0なので隣接は1、その隣は2と正しく伝播する
            // BFSが距離順にセルを処理するため、最初に到達した距離が最短距離になる
            rooms[r][c] = rooms[cell[0]][cell[1]] + 1;
            // 距離を書き込んだセルをキューに追加し、さらにその先の部屋を探索する
            q.offer(new int[]{r, c});
        }
    }
}
```
