# Capturing Surrounded Regions on a Board — 盤面上の囲まれた領域を捕獲する

## 問題の本質

`'X'` と `'O'` で構成される m×n の盤面が与えられる。`'X'` に**完全に囲まれた** `'O'` の領域をすべて `'X'` に反転する。ただし、盤面の**境界（ボーダー）**に接している `'O'` およびそこから連結している `'O'` は囲まれていないため、反転してはならない。

## 核心のアイデア

「囲まれた O を探す」のではなく、「囲まれていない O（＝境界から到達可能な O）を先にマークし、残った O がすべて囲まれている」と逆転の発想で考える。境界の O から DFS で連結セルを安全マークし、最後に盤面を一括スキャンすれば、判定と反転を分離できる。

## 思考プロセス

1. **囲まれていない O の特徴を考える**: `'O'` が捕獲されない条件は、その `'O'` が盤面の境界にあるか、境界の `'O'` と上下左右の連結で繋がっていることである。逆に言えば、境界の `'O'` から到達できない `'O'` はすべて囲まれている
2. **境界から探索を開始する**: 盤面の4辺（上辺・下辺・左辺・右辺）を走査し、`'O'` が見つかるたびにそこを起点として DFS を実行する。DFS で到達できるすべての `'O'` は「安全（捕獲不可）」である
3. **安全なセルをマーカーで区別する**: DFS で訪問した `'O'` を一時的なマーカー `'S'`（Safe）に書き換える。こうすれば、DFS 終了後に盤面上の `'O'` は「まだマークされていない＝囲まれている」セルだけになる
4. **盤面を一括スキャンして反転と復元を行う**: 全セルを走査し、`'O'` のままのセルは囲まれているので `'X'` に反転する。`'S'` のセルは安全な `'O'` なので元の `'O'` に復元する。`'X'` のセルはそのまま残す
5. **DFS の再帰構造**: 各セルから上下左右の4方向に再帰的に探索する。範囲外チェックと `'O'` 以外のセルでの打ち切りが、訪問済み判定も兼ねる（`'S'` に書き換え済みのセルは `'O'` ではないので再訪しない）

## 前提知識

### DFS（深さ優先探索）とは

グラフやグリッドを探索するアルゴリズム。ある地点から出発し、行けるところまで一方向に深く進み、行き止まりになったら戻って別の方向を試す。再帰呼び出しで自然に実装できる。グリッド上では上下左右の4方向を再帰的に訪問する。

```java
// グリッド上のDFSの基本パターン
void dfs(char[][] grid, int r, int c) {
    if (r < 0 || r >= grid.length          // 範囲外チェック
        || c < 0 || c >= grid[0].length
        || grid[r][c] != 'O')              // 対象外セルで打ち切り
        return;
    grid[r][c] = 'S';                      // 訪問済みマーク（再訪防止を兼ねる）
    dfs(grid, r + 1, c);                   // 下
    dfs(grid, r - 1, c);                   // 上
    dfs(grid, r, c + 1);                   // 右
    dfs(grid, r, c - 1);                   // 左
}
```

### 境界（ボーダー）セルの走査方法

m×n の盤面で、4辺のセルを列挙するには以下のようにする。上辺と下辺は列を、左辺と右辺は行をループする。

```java
int m = board.length;    // 行数
int n = board[0].length; // 列数

// 上辺（行0）と下辺（行m-1）の全列を走査
for (int j = 0; j < n; j++) {
    process(board[0][j]);      // 上辺
    process(board[m - 1][j]);  // 下辺
}
// 左辺（列0）と右辺（列n-1）の全行を走査
for (int i = 0; i < m; i++) {
    process(board[i][0]);      // 左辺
    process(board[i][n - 1]);  // 右辺
}
```

### マーカー技法とは

盤面のセルを一時的に別の文字（ここでは `'S'`）に書き換えることで、「訪問済み」と「未訪問」を区別する手法。別途 `boolean[][]` の訪問配列を用意する代わりに、盤面そのものを状態管理に使う。処理の最後にマーカーを元の値に復元する。

## 計算量

| | 値 |
|---|---|
| Time | O(m × n) — 境界からのDFSが各セルを最大1回訪問し、最終スキャンも全セルを1回走査する |
| Space | O(m × n) — DFSの再帰呼び出しスタックが最悪ケースで全セル分の深さに達する |

## コード

```java
// 入力: 'X' と 'O' で構成される m×n の2次元文字配列 board
// 出力: board をその場で（in-place）変更する。囲まれた 'O' を 'X' に反転し、戻り値はない（void）

// 境界から到達可能なOをマーカーSに書き換えるDFS
void dfs(char[][] board, int r, int c, int m, int n) {
    // 範囲外またはO以外のセルなら何もしない（訪問済みSも弾かれる）
    // 'S'に書き換え済みのセルは'O'ではないため再訪されない
    if (r < 0 || r >= m
        || c < 0 || c >= n
        || board[r][c] != 'O')
        return;

    // 安全マーカーSに書き換える（訪問済みを兼ねる）
    // 別途boolean[][]を用意せず、盤面そのものを状態管理に使う
    board[r][c] = 'S';

    // 上下左右の4方向に再帰探索する
    dfs(board, r + 1, c, m, n);
    dfs(board, r - 1, c, m, n);
    dfs(board, r, c + 1, m, n);
    dfs(board, r, c - 1, m, n);
}

public void solve(char[][] board) {
    // 行数と列数を取得する。以降の範囲チェックと境界走査に使用する
    int m = board.length;     // 行数
    int n = board[0].length;  // 列数

    // 上辺と下辺の各列から境界DFSを開始する
    // dfsは対象セルが'O'の場合のみ処理を行うため、'X'のセルでは何もせずに返る
    for (int j = 0; j < n; j++) {
        dfs(board, 0, j, m, n);       // 上辺
        dfs(board, m - 1, j, m, n);   // 下辺
    }

    // 左辺と右辺の各行から境界DFSを開始する
    // 上のループと合わせて、盤面の4辺すべてを起点としてカバーする
    for (int i = 0; i < m; i++) {
        dfs(board, i, 0, m, n);       // 左辺
        dfs(board, i, n - 1, m, n);   // 右辺
    }

    // 盤面を一括スキャンして反転と復元を行う
    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (board[i][j] == 'O')
                board[i][j] = 'X';        // 境界から到達できなかった＝囲まれたOをXに反転する
            else if (board[i][j] == 'S')
                board[i][j] = 'O';        // 境界から到達できた＝安全マーカーを元のOに復元する
            // 'X'のセルは変更しない
        }
    }
}
```
