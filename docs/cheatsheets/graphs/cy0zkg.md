# Simulating Rotting Oranges Spreading — 腐ったオレンジの拡散が完了するまでの最短時間を求める

## 問題の本質

m×nのグリッドが与えられ、各セルは0（空）、1（新鮮なオレンジ）、2（腐ったオレンジ）のいずれかである。毎分、腐ったオレンジは上下左右に隣接する新鮮なオレンジを腐らせる。すべての新鮮なオレンジが腐るまでの**最小の分数**を返す。すべてを腐らせることが不可能な場合は-1を返す。

## 核心のアイデア

腐ったオレンジは「同時に」隣接セルへ拡散する。これは複数の始点から同時にBFSを開始する「Multi-Source BFS」そのものであり、BFSの各レベル（階層）が1分に対応する。

## 思考プロセス

1. **拡散は同時に起こる**: 腐ったオレンジが複数あるとき、それぞれが同時に隣接セルを腐らせる。1つの始点からの探索ではなく、すべての腐ったオレンジを同時に出発点とする必要がある
2. **同時出発にはMulti-Source BFSを使う**: 最初にすべての腐ったオレンジをキューに入れておけば、BFSの1レベル（キューの現在のサイズ分だけ処理する1ラウンド）が1分間の拡散に対応する。DFSでは「最短時間」を保証できないため、BFSが適している
3. **新鮮なオレンジの数を追跡する**: 拡散が終了した後に新鮮なオレンジが残っていれば不可能なケースである。そのため、初期状態で新鮮なオレンジの数を数えておき、腐らせるたびにデクリメントする
4. **経過時間の計測方法**: BFSのレベルごとにキューの全要素を処理し、1レベル完了するごとに経過時間を1分加算する。新鮮なオレンジが0になった時点のレベル数が答えである
5. **終了条件と不可能判定**: BFSが終了した後に `fresh > 0` であれば、到達不可能な新鮮なオレンジが存在するので-1を返す。`fresh == 0` であれば経過時間を返す

## 前提知識

### BFS（幅優先探索）とは

グラフやグリッドを「始点からの距離が近い順」に探索するアルゴリズム。キュー（FIFO）を使い、現在のレベルの全ノードを処理してから次のレベルに進む。最短距離・最短時間を求める問題に適している。

### Multi-Source BFS とは

通常のBFSは始点が1つだが、Multi-Source BFSは複数の始点をキューに入れた状態でBFSを開始する。すべての始点から同時に拡散するシミュレーションに使う。キューの初期状態が複数要素になる以外は通常のBFSと同じである。

### Queue（キュー）とは

先入れ先出し（FIFO）のデータ構造。BFSでは探索対象のノードを順番に処理するために使う。

```java
Queue<int[]> queue = new LinkedList<>();  // int配列を要素とするキューを作成
queue.offer(new int[]{0, 1});  // キューの末尾に要素を追加する
int[] pos = queue.poll();       // キューの先頭から要素を取り出して削除する → {0, 1}
queue.size();                   // キュー内の要素数を返す
queue.isEmpty();                // キューが空かどうかをbooleanで返す
```

### 方向配列とは

グリッド探索で上下左右の隣接セルを列挙するためのテクニック。行と列の変位を配列で定義し、ループで回す。

```java
int[][] dirs = {{0,1},{0,-1},{1,0},{-1,0}};  // 右、左、下、上の4方向
for (int[] d : dirs) {
    int nr = row + d[0];  // 隣接セルの行インデックス
    int nc = col + d[1];  // 隣接セルの列インデックス
}
```

## 計算量

| | 値 |
|---|---|
| Time | O(m × n) — グリッドの全セルを初期走査で1回、BFSで最大1回ずつ処理する |
| Space | O(m × n) — キューに最大m×n個のセルが格納される |

## コード

```java
// 入力: m×nの整数グリッド grid（各セルは0=空、1=新鮮なオレンジ、2=腐ったオレンジ）
// 出力: すべての新鮮なオレンジが腐るまでの最小分数を int で返す。不可能な場合は-1を返す
public int orangesRotting(int[][] grid) {
    int rows = grid.length;
    int cols = grid[0].length;
    // BFS用のキュー。探索対象となるセルの座標を保持する
    Queue<int[]> queue = new LinkedList<>();
    // 残っている新鮮なオレンジの数を追跡する変数
    int fresh = 0;

    // グリッド全体を走査し、BFSの複数の始点とゴールまでの残数を同時に準備する
    for (int i = 0; i < rows; i++) {
        for (int j = 0; j < cols; j++) {
            if (grid[i][j] == 2) {
                // 腐ったオレンジをキューに追加（Multi-Source BFSの始点）
                queue.offer(new int[]{i, j});
            } else if (grid[i][j] == 1) {
                // 新鮮なオレンジの数をカウント
                fresh++;
            }
        }
    }

    // 上下左右の4方向を表す方向配列。隣接セル列挙に使う
    int[][] dirs = {{0, 1}, {0, -1}, {1, 0}, {-1, 0}};
    int minutes = 0;

    // キューが空でないだけでなく新鮮なオレンジが残っていることも条件に含め、全て腐った後の無駄なループを防ぐ
    while (!queue.isEmpty() && fresh > 0) {
        // このレベル（1分間）で処理するセル数を先に保存。ループ中に追加される次レベルの要素と区別するため
        int size = queue.size();
        // 1レベル分の処理を開始するので経過時間を1分加算する
        minutes++;

        // size回だけキューから要素を取り出し、このレベルの全セルを処理する
        for (int k = 0; k < size; k++) {
            int[] pos = queue.poll();

            // 方向配列を使って上下左右の4つの隣接セルを確認する
            for (int[] d : dirs) {
                int nr = pos[0] + d[0];
                int nc = pos[1] + d[1];

                // 範囲内かつ新鮮なオレンジであれば腐らせる
                if (nr >= 0 && nr < rows
                    && nc >= 0 && nc < cols
                    && grid[nr][nc] == 1) {
                    // セルを2に更新して訪問済みとする（visited配列の代わりになる。同じセルの重複処理を防ぐ）
                    grid[nr][nc] = 2;
                    fresh--;
                    queue.offer(new int[]{nr, nc});
                }
            }
        }
    }

    // 新鮮なオレンジが残っていれば到達不可能なので-1を返す。そうでなければ経過時間を返す
    return fresh > 0 ? -1 : minutes;
}
```
