# Finding the Redundant Edge in a Graph — 木にもう1本辺を加えたグラフから、余分な辺を見つける

## 問題の本質

n個のノードとn-1本の辺からなる木に、1本の辺が追加されてちょうど1つの閉路（サイクル）ができたグラフが与えられる。追加された余分な辺を見つけて返す。その辺を取り除けばグラフが再び有効な木に戻る。

## 核心のアイデア

辺を1本ずつ処理していくとき、「既に同じ連結成分に属している2つのノード」を結ぶ辺が現れたら、その辺こそがサイクルを作り出す余分な辺である。この判定にはUnion-Findが最適である。

## 思考プロセス

1. **木の性質を利用する**: 木はn個のノードをn-1本の辺で連結する構造であり、サイクルは存在しない。ここに1本辺を追加するとちょうど1つのサイクルが生まれる。つまり、辺を順番に追加していく過程で「サイクルを生む辺」を検出すればよい
2. **サイクルの検出条件を考える**: 辺(u, v)を追加するとき、uとvが既に同じ連結成分に属していれば、その辺はサイクルを形成する。逆に、uとvが異なる連結成分に属していれば、その辺は2つの成分を統合するだけでサイクルは生まれない
3. **連結成分の管理にはUnion-Findが適している**: 「2つのノードが同じ連結成分に属するか」の判定と「2つの連結成分を統合する」操作を高速に行うデータ構造がUnion-Findである。find操作で根を比較すれば同一成分かを判定でき、union操作で成分を統合できる
4. **Union-Findの効率化**: 経路圧縮（path compression）により、find操作のたびにノードを根に直接つなぎ替える。ランク（rank）による統合により、木の高さを抑える。これら2つの最適化により、各操作の計算量はα(n)（逆アッカーマン関数、実質的に定数）になる
5. **辺を順番に処理する**: 与えられた辺の配列を先頭から順に処理し、各辺に対してunion操作を試みる。unionが失敗した（= 既に同じ成分に属していた）辺が余分な辺であり、それを返す
6. **最終的に返すもの**: union操作が失敗した辺を `int[]` として返す。問題の制約上、必ず1本の余分な辺が存在するので、答えが見つからないケースはない

## 前提知識

### Union-Find（素集合データ構造）とは

複数の要素をグループ（連結成分）に分け、「2つの要素が同じグループに属するか」の判定と「2つのグループを統合する」操作を高速に行うデータ構造。`parent` 配列でグループの木構造を表現し、各要素の根（代表元）が同じならば同一グループと判定する。

```java
int[] parent = new int[n + 1];  // parent[i]はノードiの親を保持する
int[] rank = new int[n + 1];    // rank[i]はノードiを根とする木の高さの上限
for (int i = 1; i <= n; i++)
    parent[i] = i;              // 初期状態では各ノードが自分自身を親とする（全員が独立したグループ）
```

### find 操作（経路圧縮付き）

ノードxが属するグループの根（代表元）を返す。再帰的に親をたどり、経路上の全ノードを根に直接つなぎ替える（経路圧縮）。これにより次回以降のfindが高速になる。

```java
int find(int[] parent, int x) {
    if (parent[x] != x)                    // xが根でなければ
        parent[x] = find(parent, parent[x]); // 親を再帰的にたどり、根に直接つなぎ替える
    return parent[x];                       // xの根を返す
}
```

### union 操作（ランクによる統合）

2つのノードが属するグループを統合する。ランク（木の高さの上限）が小さい方を大きい方の下に接続することで、木の高さの増加を抑える。2つのノードが既に同じグループに属する場合は統合せずに `false` を返す。

```java
boolean union(int[] parent, int[] rank, int x, int y) {
    int rx = find(parent, x);  // xの根を取得する
    int ry = find(parent, y);  // yの根を取得する
    if (rx == ry) return false; // 同じグループなら統合不要 → falseを返す
    // ランクが小さい方を大きい方の下に接続する
    if (rank[rx] < rank[ry]) parent[rx] = ry;
    else if (rank[rx] > rank[ry]) parent[ry] = rx;
    else { parent[ry] = rx; rank[rx]++; }  // ランクが同じなら片方をもう片方の下に接続し、ランクを1増やす
    return true;  // 統合成功 → trueを返す
}
```

### 逆アッカーマン関数 α(n) とは

Union-Findの操作1回あたりの計算量を表す関数。α(n) は非常にゆっくり成長し、現実的な入力サイズ（n < 2^65536）ではα(n) ≤ 4 となるため、実質的に定数とみなせる。

## 計算量

| | 値 |
|---|---|
| Time | O(n × α(n)) ≈ O(n) — n本の辺それぞれに対してfindとunionを1回ずつ行う。α(n)は実質定数なのでO(n)とみなせる |
| Space | O(n) — parent配列とrank配列にそれぞれn+1個の要素を保存する |

## コード

```java
// 入力: 辺の配列 edges（各要素は int[]{u, v} で、ノードuとノードvを結ぶ辺を表す）
// 出力: サイクルを形成している余分な辺を int[] で返す

// ノードxが属するグループの根を返す（経路圧縮付き）
int find(int[] parent, int x) {
    if (parent[x] != x)
        // 親を再帰的にたどり、根に直接つなぎ替える（経路圧縮）
        parent[x] = find(parent,
            parent[x]);
    return parent[x];
}

// 2つのノードが属するグループを統合する。既に同じグループならfalseを返す
boolean union(int[] parent,
        int[] rank, int x, int y) {
    int rx = find(parent, x); // xの根を取得する
    int ry = find(parent, y); // yの根を取得する
    if (rx == ry) return false; // 既に同じ連結成分 → サイクルが生まれるのでfalseを返す
    // ランクが小さい方を大きい方の下に接続し、木の高さの増加を抑える
    if (rank[rx] < rank[ry])
        parent[rx] = ry;
    else if (rank[rx] > rank[ry])
        parent[ry] = rx;
    else {
        // ランクが同じなら片方をもう片方の下に接続し、ランクを1増やす
        parent[ry] = rx;
        rank[rx]++;
    }
    return true; // 統合成功 → サイクルは生まれていない
}

public int[] findRedundantConnection(
        int[][] edges) {
    // 辺の数 = ノードの数（木のn-1本 + 余分な1本 = n本）。ノード番号は1からn
    int n = edges.length;
    // 各ノードを独立したグループとして初期化する（parent[i] = i で自分自身が根）
    int[] parent = new int[n + 1];
    int[] rank = new int[n + 1]; // rank配列はデフォルトの0のままでよい
    for (int i = 1; i <= n; i++)
        parent[i] = i;

    // 辺を先頭から順に1本ずつ処理し、サイクルを形成する辺を検出する
    for (int[] e : edges) {
        // unionがfalseを返した場合、e[0]とe[1]は既に同じ連結成分に属している
        // → この辺がサイクルを形成する余分な辺なので、そのまま返す
        if (!union(parent, rank,
                e[0], e[1]))
            return e;
    }
    // 問題の制約上、必ず余分な辺が1本存在するのでここには到達しない
    return new int[0];
}
```
