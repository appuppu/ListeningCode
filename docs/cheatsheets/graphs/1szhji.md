# Deep Copying a Graph — 連結無向グラフの全ノードを深いコピーで複製する

## 問題の本質

連結無向グラフの1つのノードへの参照が与えられる。グラフ全体の**ディープコピー（クローン）**を作成し、クローンされたグラフの対応するノードを返す。各ノードは整数値 `val` と隣接ノードのリスト `neighbors` を持つ。元のグラフのノードを一切参照せず、完全に独立した新しいグラフを構築する必要がある。

## 核心のアイデア

グラフにはサイクルがあるため、同じノードを2回クローンしないようにHashMapで「元ノード→クローンノード」の対応を記録する。未訪問ならクローンを作成してHashMapに登録し、訪問済みならHashMapからクローンを返すことで、無限ループを防ぎつつ全ノードを正確に複製できる。

## 思考プロセス

1. **グラフの走査が必要**: グラフ全体をコピーするには、起点ノードから到達可能な全ノードを訪問する必要がある。走査にはDFS（深さ優先探索）を再帰で行うのが自然である
2. **サイクルへの対処が必須**: 無向グラフでは A→B→A のようなサイクルが必ず存在する。訪問済みのノードを再度クローンしようとすると無限ループに陥るため、「このノードは既にクローン済みか」を判定する仕組みが必要になる
3. **HashMapで元ノードとクローンの対応を管理する**: `HashMap<Node, Node>` を用意し、キーに「元のノード」、バリューに「そのクローン」を保存する。こうすれば、あるノードが既にクローン済みかをO(1)で判定でき、クローン済みならそのクローンをO(1)で取得できる
4. **再帰の各ステップでやること**: 現在のノードがHashMapに存在すれば、そのクローンを返す（訪問済み）。存在しなければ、新しいNodeを作成してHashMapに登録し、元ノードの全隣接ノードに対して再帰的にクローンを呼び出し、返ってきたクローンを自身のneighborsに追加する
5. **登録は再帰の前に行う**: HashMapへの登録を隣接ノードの再帰呼び出しより**前**に行う。先に登録しないと、サイクルで自分に戻ってきたときにHashMapにクローンが見つからず、無限ループになる
6. **最終的に返すもの**: 起点ノードのクローンを返す。このクローンから全てのクローンノードが隣接リストで繋がっている

## 前提知識

### Node クラスとは

グラフの各頂点を表すクラス。整数値 `val` と隣接ノードのリスト `neighbors` を持つ。

```java
class Node {
    public int val;
    public List<Node> neighbors;

    public Node(int val) {        // valを指定してノードを作成する
        this.val = val;
        this.neighbors = new ArrayList<>();  // 隣接リストは空で初期化される
    }
}
```

### HashMap とは

キーと値のペアを保存するデータ構造。キーを指定して値の検索・取得がO(1)でできる。この問題では、キーに「元のノード」、バリューに「そのクローンノード」を保存し、訪問済み判定とクローン取得を兼ねる。

```java
HashMap<Node, Node> map = new HashMap<>();  // 空のHashMapを作成
map.put(original, clone);     // 元ノードをキー、クローンをバリューとして格納する
map.containsKey(original);    // 元ノードが登録済みかをbooleanで返す → true
map.get(original);            // 元ノードに対応するクローンを返す → clone
```

### DFS（深さ優先探索）とは

グラフの走査アルゴリズムの一つ。1つの方向にできるだけ深く進み、行き止まりになったら戻って別の方向に進む。再帰呼び出しで自然に実装できる。訪問済み管理を行わないとサイクルで無限ループになる。

## 計算量

| | 値 |
|---|---|
| Time | O(V + E) — 各ノードを1回ずつ訪問し（V）、各辺を1回ずつ処理する（E） |
| Space | O(V) — HashMapにV個のノード対応を保存し、再帰スタックも最大V段になる |

## コード

```java
// 入力: 連結無向グラフの1つのノード node（Node 型）。グラフが空の場合は null
// 出力: グラフ全体のディープコピーにおける、入力ノードに対応するクローンノード（Node 型）を返す

// キー=元ノード、バリュー=クローンノード を保存するHashMap
// 全再帰呼び出しで共有するためにクラスのフィールドに置く
Map<Node, Node> map = new HashMap<>();

public Node cloneGraph(Node node) {
    // グラフが空（null）なら null を返して終了する
    if (node == null) return null;

    // 現在のノードが既にクローン済みならそのクローンを返す
    // これがサイクルによる無限ループを防ぐ仕組みである
    if (map.containsKey(node))
        return map.get(node);

    // 現在のノードのクローンを作成する（この時点では neighbors は空）
    Node clone = new Node(node.val);

    // 注意: 登録は次のforループの再帰呼び出しより前に行う
    // 先に登録しないと、サイクルで自分に戻ってきたときに containsKey で検出できず無限ループになる
    map.put(node, clone);

    // 元ノードの全隣接ノードを再帰的にクローンし、クローンの隣接リストに追加する
    // これにより元のグラフと同じ隣接関係がクローン側にも構築される
    for (Node nbr : node.neighbors) {
        clone.neighbors
            .add(cloneGraph(nbr));
    }

    // 最初の呼び出しに対して返される clone が、クローンされたグラフ全体の起点ノードとなる
    return clone;
}
```
