# Encontrando o Maior Retângulo em um Histograma — Encontrar a área do maior retângulo que pode ser formado dentro de um histograma

## Essência do Problema

É dado um array de inteiros não negativos `heights`. Cada elemento representa a altura de uma barra do histograma, e a largura de todas as barras é 1. O objetivo é encontrar e retornar a **área do maior retângulo** que pode ser formado dentro deste histograma.

## Ideia Central

Se, ao adotar cada barra como "altura do retângulo", soubermos até onde essa barra pode se expandir para a esquerda e para a direita como a barra mais baixa, podemos calcular a área. Usando uma stack monotonicamente crescente, no momento em que a altura de uma barra diminui, podemos determinar a largura expansível das barras na stack em O(1).

## Processo de Raciocínio

1. **Considerar o retângulo cuja altura é cada barra**: Qualquer retângulo pode ser visto como "composto por barras consecutivas à esquerda e à direita, tendo a altura de uma determinada barra como limite superior". Ou seja, se para cada barra `heights[i]` soubermos "a largura do intervalo no qual essa barra é a mais baixa", podemos calcular a área como `heights[i] × largura`
2. **Encontrar os limites esquerdo e direito de forma eficiente**: Se para cada barra soubermos "a posição da primeira barra mais baixa à esquerda" e "a posição da primeira barra mais baixa à direita", a largura expansível fica determinada. Buscar esses dois limites de forma ingênua para todas as barras resulta em O(n²), por isso usamos uma stack para otimizar
3. **Usar uma stack monotonicamente crescente**: Empilhamos os índices das barras na stack de forma que as alturas sejam monotonicamente crescentes. Quando a altura da barra atual é menor que a do topo da stack, determinamos que o "limite direito" da barra no topo é a posição atual `i`
4. **Calcular a largura ao desempilhar**: Quando desempilhamos a barra `top`, o limite direito é a posição atual `i`, e o limite esquerdo é a posição seguinte ao novo topo da stack. Se a stack estiver vazia, a barra pode se expandir até a extremidade esquerda (índice 0), então a largura é `i`. Se a stack não estiver vazia, a largura é `i - stack.peek() - 1`
5. **Adicionar uma sentinela de altura 0 ao final**: Quando chegamos ao final do array, ainda precisamos calcular a área das barras restantes na stack. Definimos o intervalo do loop como `i <= heights.length` e, quando `i == heights.length`, colocamos virtualmente uma barra de altura 0, garantindo que todas as barras na stack sejam desempilhadas
6. **Rastrear a área máxima**: Cada vez que desempilhamos uma barra, calculamos `heights[top] × largura` e comparamos com o valor máximo até o momento para atualizá-lo. O valor máximo no momento em que todos os desempilhamentos forem concluídos é a resposta

## Conhecimentos Prévios

### O que é uma Stack

Uma estrutura de dados do tipo último a entrar, primeiro a sair (LIFO). O último elemento adicionado é o primeiro a ser retirado. No problema do histograma, a stack é usada para empilhar os índices das barras e manter a monotonicidade das alturas.

```java
Stack<Integer> stack = new Stack<>();  // Criar uma stack vazia
stack.push(0);       // Adicionar o valor 0 ao topo da stack
stack.peek();        // Consultar o valor do topo da stack sem removê-lo → 0
stack.pop();         // Remover e retornar o valor do topo da stack → 0
stack.isEmpty();     // Retornar um boolean indicando se a stack está vazia → true
```

### O que é uma Stack Monotonicamente Crescente (Monotonic Stack)

Uma stack que mantém os elementos sempre em ordem crescente (ou igual) de baixo para cima. Ao adicionar um novo elemento, se o valor for menor que o topo da stack, desempilhamos até que o topo seja maior ou igual ao novo valor. No momento do desempilhamento, podemos interpretar que "o limite direito do elemento desempilhado foi determinado".

```java
// Comportamento da stack monotonicamente crescente para o array [2, 1, 5, 6, 2, 3]
// i=0: push(0)         → stack: [0]       (altura: [2])
// i=1: 1 < 2, então pop → stack: []        (o limite direito da barra de altura 2 é determinado como i=1)
//       push(1)         → stack: [1]       (altura: [1])
// i=2: push(2)         → stack: [1,2]     (altura: [1,5])
// i=3: push(3)         → stack: [1,2,3]   (altura: [1,5,6])
// i=4: 2 < 6, então pop → stack: [1,2]     (o limite direito da barra de altura 6 é determinado como i=4)
//       2 < 5, então pop → stack: [1]       (o limite direito da barra de altura 5 é determinado como i=4)
//       push(4)         → stack: [1,4]     (altura: [1,2])
```

### O que é uma Sentinela (Sentinel)

Um valor adicionado virtualmente para simplificar o tratamento do final do loop. Neste problema, ao colocar virtualmente uma barra de altura 0 no final do array, todas as barras restantes na stack são desempilhadas naturalmente quando o loop termina.

```java
// Quando i == heights.length, estamos fora do array real, então usamos virtualmente a altura 0
int h = (i == heights.length) ? 0 : heights[i];
// Como a altura 0 é menor que qualquer barra, todas as barras na stack são desempilhadas
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Cada barra é empilhada uma vez e desempilhada uma vez, então o total de operações é O(n) |
| Space | O(n) — A stack armazena no máximo n índices |

## Código

```java
// Entrada: array de inteiros não negativos heights (cada elemento é a altura de uma barra do histograma)
// Saída: retornar a área do maior retângulo que pode ser formado dentro do histograma como int
public int largestRectangleArea(int[] heights) {
    // Stack que mantém os índices das barras em ordem monotonicamente crescente
    Stack<Integer> stack = new Stack<>();
    // Variável que registra a maior área encontrada até o momento
    int maxArea = 0;

    // Usar i <= heights.length para incluir o processamento da sentinela
    // Quando i == heights.length, a sentinela (altura 0) faz com que toda a stack seja desempilhada
    for (int i = 0; i <= heights.length; i++) {
        // Sentinela: quando ultrapassar o final do array, usar altura 0. Como a altura 0 é menor que qualquer barra, é garantido que todas as barras na stack serão desempilhadas
        int h = (i == heights.length) ? 0 : heights[i];

        // Enquanto a altura atual for menor que a barra no topo da stack, calcular a área
        // Esta condição mantém a propriedade monotonicamente crescente dentro da stack
        while (!stack.isEmpty() && h < heights[stack.peek()]) {
            // Adotar a barra desempilhada como a altura do retângulo. O limite direito desta barra é a posição atual i
            int top = stack.pop();

            // Calcular a largura:
            // Stack vazia → a barra top pode se expandir até a extremidade esquerda (índice 0), então a largura é i
            // Stack não vazia → stack.peek() é o índice de uma barra à esquerda de top e mais baixa que top (limite esquerdo), então a largura é i - stack.peek() - 1
            int w = stack.isEmpty() ? i : i - stack.peek() - 1;

            // Calcular a área e atualizar o valor máximo
            maxArea = Math.max(maxArea, heights[top] * w);
        }

        // Empilhar o índice atual na stack para manter a ordem monotonicamente crescente
        stack.push(i);
    }
    // O valor máximo no momento em que todos os desempilhamentos forem concluídos é a resposta
    return maxArea;
}
```
