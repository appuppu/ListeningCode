# Checking if Parentheses Are Balanced — Determinar se uma string de parênteses está corretamente balanceada

## Essência do problema

Uma string composta apenas por 6 tipos de parênteses: `(`, `)`, `{`, `}`, `[`, `]` é fornecida. O objetivo é determinar se todos os parênteses de abertura possuem parênteses de fechamento correspondentes na **ordem correta**, retornando `true` ou `false`.

## Ideia central

A correspondência de parênteses possui uma estrutura de último a entrar, primeiro a sair (LIFO): "o último parêntese aberto deve ser o primeiro a ser fechado". Essa propriedade é exatamente a de uma pilha. Ao empilhar os parênteses de abertura e comparar cada parêntese de fechamento com o topo da pilha, é possível verificar se a correspondência está correta.

## Processo de raciocínio

1. **A correspondência de parênteses depende da ordem**: Em `([)]`, a quantidade de cada tipo de parêntese está correta, mas a ordem é inválida. Ou seja, existe a regra de que "os parênteses mais internos devem ser fechados primeiro". Essa é uma estrutura de último a entrar, primeiro a sair (LIFO), que pode ser representada naturalmente por uma pilha
2. **Os parênteses de abertura são empilhados**: A string é percorrida caractere por caractere desde o início. Ao encontrar um parêntese de abertura (`(`, `{`, `[`), ele é adicionado à pilha com push. O topo da pilha sempre contém "o parêntese aberto mais recentemente que ainda não foi fechado"
3. **Ao encontrar um parêntese de fechamento, ele é comparado com o topo da pilha**: Ao encontrar um parêntese de fechamento, o parêntese de abertura removido da pilha com pop é verificado para confirmar se corresponde ao tipo correto. Se não corresponder, a string é inválida
4. **Se a pilha estiver vazia quando um parêntese de fechamento aparecer, a string é inválida**: Se a pilha estiver vazia antes do pop, isso significa que não existe um parêntese de abertura correspondente, portanto retorna-se `false`
5. **Se a pilha estiver vazia após a varredura completa, a string é válida**: Após processar todos os caracteres, se houver parênteses de abertura restantes na pilha, isso significa que existem parênteses não fechados. Se a pilha estiver vazia, todos os parênteses estão corretamente correspondidos

## Conhecimentos prévios

### O que é uma Stack

Uma estrutura de dados de último a entrar, primeiro a sair (LIFO: Last In, First Out). O último elemento adicionado é o primeiro a ser removido. É utilizada em situações onde é necessário processar elementos na ordem do "mais recente primeiro", como na verificação de correspondência de parênteses.

```java
Stack<Character> stack = new Stack<>();  // Cria uma pilha vazia
stack.push('(');      // Adiciona '(' ao topo da pilha
stack.peek();         // Consulta o elemento do topo da pilha sem removê-lo → '('
stack.pop();          // Remove e retorna o elemento do topo da pilha → '('
stack.isEmpty();      // Retorna um boolean indicando se a pilha está vazia → true
```

### Correspondência de parênteses

Os 3 tipos de parênteses possuem, cada um, um par de abertura e fechamento. Quando um parêntese de fechamento aparece, é necessário verificar se o topo da pilha contém o parêntese de abertura correspondente.

```
O parêntese de abertura correspondente a ')' é '('
O parêntese de abertura correspondente a '}' é '{'
O parêntese de abertura correspondente a ']' é '['
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Basta percorrer a string uma única vez |
| Space | O(n) — A pilha armazena no máximo n parênteses de abertura |

## Código

```java
// Entrada: string s composta apenas por parênteses
// Saída: true se todos os parênteses estiverem corretamente correspondidos, false caso contrário
public boolean isValid(String s) {
    // Pilha que mantém os "parênteses de abertura que ainda não foram fechados"
    // O topo da pilha contém o parêntese aberto mais recentemente
    Stack<Character> stack = new Stack<>();

    // Percorre a string caractere por caractere desde o início. toCharArray() converte a string em um array de char
    for (char c : s.toCharArray()) {
        // Se for um parêntese de abertura, empilha. Ele permanece na pilha até que o parêntese de fechamento correspondente apareça
        if (c == '(' || c == '{' || c == '[') {
            stack.push(c);
        } else {
            // Se for um parêntese de fechamento mas a pilha estiver vazia, não existe um parêntese de abertura correspondente, portanto é inválido
            if (stack.isEmpty()) return false;

            // Remove do topo da pilha "o parêntese aberto mais recentemente que ainda não foi fechado"
            char top = stack.pop();

            // Se o tipo do parêntese de fechamento não corresponder ao parêntese de abertura, é inválido
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
            if (c == ')' && top != '(') return false;
        }
    }

    // Se a pilha estiver vazia, todos os parênteses estão corretamente correspondidos
    // Se houver elementos restantes na pilha, existem parênteses de abertura não fechados, portanto retorna false
    return stack.isEmpty();
}
```
