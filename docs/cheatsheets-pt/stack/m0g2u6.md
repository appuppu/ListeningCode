# Designing a Stack That Tracks the Minimum — Projetar uma pilha que obtém o valor mínimo em O(1) para todas as operações

## Essência do problema

O objetivo é projetar uma pilha que execute as quatro operações `push`, `pop`, `top` e `getMin` (obter o valor mínimo atual) em O(1). Em uma pilha convencional, obter o valor mínimo custa O(n), portanto é necessário um mecanismo especial.

## Ideia central

Se armazenarmos junto com cada elemento da pilha "o valor mínimo naquele momento", a informação do mínimo não se perde mesmo quando um elemento é removido com pop. O método `getMin()` sempre obtém a resposta em O(1) apenas consultando o topo da pilha.

## Processo de raciocínio

1. **Para que getMin seja O(1), é necessário manter o valor mínimo sempre disponível**: Considerar gerenciar o mínimo com uma única variável, mas quando o valor mínimo é removido pelo pop, o próximo mínimo se torna desconhecido. Ou seja, é necessário um mecanismo para manter o "histórico" dos valores mínimos
2. **O histórico dos mínimos está vinculado ao estado da pilha**: Cada vez que um elemento é empilhado, o valor mínimo pode mudar. Inversamente, quando um elemento é removido, o mínimo retorna ao valor anterior ao push. Essa propriedade de "retornar ao estado anterior ao push" é a mesma propriedade da própria pilha
3. **Armazenar o valor mínimo naquele momento em par com cada elemento**: Ao executar push, comparar o novo valor com o mínimo atual e armazenar o menor como "mínimo naquele momento" junto com o novo valor. Dessa forma, mesmo que um elemento seja removido pelo pop, o próximo elemento do topo contém o valor mínimo correto
4. **Definir a estrutura do par**: Utilizar um array `int[]`, armazenando o valor em `[0]` e o mínimo naquele momento em `[1]`. O tipo da pilha será `Stack<int[]>`
5. **Método de cálculo do mínimo no push**: Se a pilha estiver vazia, o novo valor se torna diretamente o mínimo. Caso contrário, comparar o novo valor com o mínimo armazenado no topo da pilha (`stack.peek()[1]`) e adotar o menor
6. **Implementação de top, getMin e pop**: `top()` retorna `[0]` do par no topo, `getMin()` retorna `[1]` do par no topo, ambos em O(1). `pop()` apenas remove o elemento do topo, como em uma pilha convencional

## Conhecimentos prévios

### O que é uma Stack

Uma estrutura de dados LIFO (Last In, First Out — último a entrar, primeiro a sair). O último elemento adicionado é o primeiro a ser removido. Em Java, utiliza-se Generics para especificar o tipo dos elementos armazenados.

```java
Stack<int[]> stack = new Stack<>();  // Criar uma pilha que armazena arrays de int
stack.push(new int[]{1, 1});         // Adicionar um elemento ao topo
stack.peek();                         // Consultar o elemento do topo sem removê-lo → [1, 1]
stack.pop();                          // Remover e retornar o elemento do topo → [1, 1]
stack.isEmpty();                      // Retornar um boolean indicando se a pilha está vazia → true
```

### O que é Math.min

Um método que recebe dois inteiros e retorna o menor deles. É utilizado para comparar o novo valor com o mínimo atual a cada push.

```java
Math.min(3, 5);   // → 3
Math.min(-1, 0);  // → -1
```

## Complexidade

| | Valor |
|---|---|
| Time | O(1) — Todas as operações push, pop, top e getMin são concluídas em tempo constante |
| Space | O(n) — A pilha armazena no máximo n pares |

## Código

```java
// Entrada: sequência de operações push(val), pop(), top(), getMin()
// Saída: top() retorna o valor do topo. getMin() retorna o valor mínimo atual na pilha
class MinStack {

    // Campo do tipo Stack<int[]>. Cada elemento é um array de tamanho 2, onde [0] armazena o valor e [1] armazena o valor mínimo de toda a pilha naquele momento
    private Stack<int[]> stack;

    public MinStack() {
        stack = new Stack<>();
    }

    public void push(int val) {
        // Se a pilha estiver vazia, val é o próprio mínimo. Caso contrário, comparar com o mínimo registrado no topo e adotar o menor
        int min = stack.isEmpty() ? val : Math.min(val, stack.peek()[1]);
        // Empilhar o par de valor e mínimo new int[]{val, min}. Enquanto este elemento estiver no topo, min será o valor mínimo correto
        stack.push(new int[]{val, min});
    }

    public void pop() {
        // Remover o par do topo. O [1] do par que se torna o novo topo armazena o valor mínimo correto do momento em que aquele elemento foi empilhado, portanto a consistência do mínimo é mantida automaticamente
        stack.pop();
    }

    public int top() {
        // O [0] do par armazena o valor em si
        return stack.peek()[0];
    }

    public int getMin() {
        // O [1] do par armazena o valor mínimo naquele momento, portanto não é necessário percorrer a pilha
        return stack.peek()[1];
    }
}
```
