# Inverting a Binary Tree — Trocar os filhos esquerdo e direito de todos os nós de uma árvore binária

## Essência do Problema

Um nó raiz `root` de uma árvore binária é fornecido. O programa troca (inverte) o filho esquerdo e o filho direito em **todos os nós** da árvore e retorna o nó raiz da árvore invertida.

## Ideia Central

A inversão de uma árvore binária é a operação de trocar os filhos esquerdo e direito em todos os nós. O algoritmo visita todos os nós em ordem de nível usando BFS e realiza o swap dos filhos esquerdo e direito em cada nó, invertendo assim a árvore inteira.

## Processo de Raciocínio

1. **Compreender a definição de inversão**: A inversão de uma árvore binária é a operação de trocar o filho esquerdo e o filho direito não apenas no nó raiz, mas em todos os nós. Ou seja, basta visitar todos os nós da árvore uma vez cada e realizar o processo de swap em cada nó
2. **Escolher o método para visitar todos os nós**: O algoritmo usa BFS (busca em largura) como método para visitar todos os nós da árvore. O BFS processa os nós em ordem de nível usando uma fila, tornando a implementação intuitiva e fácil de entender
3. **Definir a operação em cada nó**: Para cada nó retirado da fila, o algoritmo troca `left` e `right` usando uma variável temporária. A ordem do swap não importa, e o swap pode ser realizado sem problemas mesmo quando um filho é null
4. **Adicionar os nós filhos à fila**: Após o swap, se os filhos esquerdo e direito não forem null, o algoritmo os adiciona à fila. Dessa forma, os nós das camadas inferiores da árvore também são visitados sequencialmente, e o swap é executado em todos os nós
5. **O que retornar ao final**: Após a conclusão do swap de todos os nós, o algoritmo retorna o nó raiz original `root` como está. A estrutura da árvore muda, mas o nó raiz em si é o mesmo objeto

## Conhecimentos Prévios

### O que é uma Árvore Binária (Binary Tree)

Uma estrutura de árvore em que cada nó possui no máximo dois filhos (filho esquerdo `left` e filho direito `right`). Os nós são representados pela classe `TreeNode`, que possui os campos `val` (valor), `left` (filho esquerdo) e `right` (filho direito).

```java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;
}
```

### O que é uma Queue (Fila)

Uma estrutura de dados do tipo primeiro a entrar, primeiro a sair (FIFO). O primeiro elemento adicionado é o primeiro a ser retirado. No BFS, a fila é usada para gerenciar os nós que devem ser visitados.

```java
Queue<TreeNode> queue = new LinkedList<>();  // Cria uma fila vazia
queue.add(node);     // Adiciona node ao final da fila
queue.poll();        // Retira e retorna o elemento do início da fila
queue.isEmpty();     // Retorna um boolean indicando se a fila está vazia → true/false
```

### O que é BFS (Busca em Largura)

Um algoritmo que explora árvores e grafos em "ordem de nível". Usando uma fila, após processar o nó atual, o algoritmo adiciona seus nós filhos à fila, visitando assim todos os nós sequencialmente das camadas mais rasas para as mais profundas.

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — O algoritmo visita todos os nós da árvore uma vez cada |
| Space | O(n) — A fila armazena no máximo n nós |

## Código

```java
// Entrada: nó raiz root de uma árvore binária
// Saída: retorna o nó raiz root após trocar os filhos esquerdo e direito de todos os nós
public TreeNode invertTree(TreeNode root) {
    // Se a árvore estiver vazia, retorna null. Como a árvore não existe, o algoritmo encerra diretamente
    if (root == null) return null;

    // Cria uma fila para BFS e adiciona o nó raiz
    // Esta fila gerencia os nós nos quais o swap esquerdo/direito deve ser realizado
    Queue<TreeNode> queue = new LinkedList<>();
    queue.add(root);

    // Repete até que a fila esteja vazia (= até que todos os nós sejam processados)
    while (!queue.isEmpty()) {
        // Retira o nó alvo do swap do início da fila
        TreeNode curr = queue.poll();

        // Troca os filhos esquerdo e direito usando uma variável temporária
        // Nota: sem usar uma variável temporária, a atribuição direta sobrescreve uma das referências e a perde
        TreeNode temp = curr.left;
        curr.left = curr.right;
        curr.right = temp;

        // Se os filhos após o swap não forem null, adiciona-os à fila
        // Nós null não possuem mais filhos para processar, portanto não precisam ser adicionados
        if (curr.left != null) queue.add(curr.left);
        if (curr.right != null) queue.add(curr.right);
    }

    // Retorna o nó raiz após a conclusão do swap de todos os nós
    // A estrutura da árvore muda, mas o nó raiz em si é o mesmo objeto
    return root;
}
```
