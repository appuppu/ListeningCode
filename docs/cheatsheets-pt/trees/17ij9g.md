# Encontrando a Profundidade Máxima de uma Árvore Binária — Determinar o número de nós no caminho mais profundo de uma árvore binária

## Essência do Problema

Um nó `root` de uma árvore binária é fornecido. O programa deve retornar como inteiro o **número de nós** (profundidade máxima) contidos no caminho do nó raiz até o nó folha mais distante. Se a árvore estiver vazia (root é null), o programa deve retornar 0.

## Ideia Central

A profundidade máxima de uma árvore é igual ao maior valor entre "a profundidade máxima da subárvore esquerda" e "a profundidade máxima da subárvore direita", mais 1 (referente ao nó atual). Essa definição recursiva se torna diretamente a solução.

## Processo de Raciocínio

1. **A profundidade da árvore pode ser definida recursivamente**: A profundidade de um nó depende da profundidade das subárvores que têm seus filhos esquerdo e direito como raiz. Ou seja, o problema pode ser decomposto em subproblemas menores com a mesma estrutura
2. **Definir o caso base**: Quando o nó é null, não há nada ali, portanto a profundidade é 0. Esta é a condição de término da recursão
3. **Calcular a profundidade de cada subárvore esquerda e direita**: A partir do nó atual, o programa faz a recursão para o filho esquerdo e obtém a profundidade máxima da subárvore esquerda. Da mesma forma, faz a recursão para o filho direito e obtém a profundidade máxima da subárvore direita
4. **Combinar os resultados esquerdo e direito**: Como a profundidade máxima é o caminho mais longo, o programa seleciona o maior valor entre as profundidades esquerda e direita. O programa obtém esse valor com `Math.max(left, right)`
5. **Somar o nó atual e retornar**: Ao adicionar 1 ao valor máximo das profundidades esquerda e direita, o programa retorna ao pai a profundidade incluindo o nó atual. Esse 1 representa a contagem do "próprio nó atual"

## Conhecimentos Prévios

### O que é TreeNode (Nó de Árvore Binária)

TreeNode é uma classe que representa cada nó de uma árvore binária. Ela possui três campos: o valor `val`, o filho esquerdo `left` e o filho direito `right`. Quando um filho não existe, o campo contém null.

```java
public class TreeNode {
    int val;              // Valor armazenado no nó
    TreeNode left;        // Nó filho esquerdo (null se não existir)
    TreeNode right;       // Nó filho direito (null se não existir)
}
```

### O que é Recursão (Recursion)

Recursão é uma técnica em que uma função chama a si mesma. Em estruturas de árvore, ela é utilizada para aplicar o mesmo processamento às subárvores de cada nó. É obrigatório definir um caso base (condição que interrompe a recursão) para evitar loops infinitos.

```java
// Estrutura básica da recursão
public int recursive(TreeNode node) {
    if (node == null) return 0;           // Caso base: condição de término da recursão
    return recursive(node.left);          // Chamada recursiva: resolver o subproblema
}
```

### O que é Math.max

Math.max é um método padrão do Java que retorna o maior entre dois inteiros.

```java
Math.max(3, 5);    // → 5
Math.max(0, 0);    // → 0
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — O programa visita todos os nós exatamente uma vez |
| Space | O(h) — A pilha de chamadas da recursão acumula até a altura da árvore. No pior caso (árvore desbalanceada), a complexidade é O(n) |

## Código

```java
// Entrada: nó raiz root da árvore binária (tipo TreeNode, pode ser null)
// Saída: o programa retorna um inteiro representando a profundidade máxima da árvore
public int maxDepth(TreeNode root) {
    // Caso base: se o nó não existe, a profundidade é 0
    // A recursão para quando atinge o filho de um nó folha (null)
    if (root == null) return 0;

    // Calcular recursivamente a profundidade máxima da subárvore esquerda
    // O programa repete o mesmo processamento para a subárvore com o filho esquerdo como raiz, até atingir o caso base e retornar o valor
    int left = maxDepth(root.left);

    // Calcular recursivamente a profundidade máxima da subárvore direita
    // Da mesma forma que à esquerda, o programa calcula a profundidade da subárvore com o filho direito como raiz
    int right = maxDepth(root.right);

    // Somar 1 (referente ao nó atual) ao maior valor entre esquerda e direita e retornar
    // Math.max(left, right) seleciona a subárvore mais profunda, que corresponde ao número de nós no caminho mais longo
    // O +1 conta o próprio nó atual root. O nó pai recebe este valor de retorno e o utiliza em seu próprio cálculo
    return 1 + Math.max(left, right);
}
```
