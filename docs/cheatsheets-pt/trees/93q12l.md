# Validating a Binary Search Tree — Determinar se uma árvore binária é uma árvore binária de busca válida

## Essência do Problema

Uma árvore binária `root` é fornecida. O objetivo é determinar se essa árvore é uma árvore binária de busca (BST) válida. Uma BST válida significa que, para todos os nós, todos os valores na subárvore esquerda são **estritamente menores** que o valor do nó, e todos os valores na subárvore direita são **estritamente maiores** que o valor do nó.

## Ideia Central

Cada nó possui um "intervalo válido de valores possíveis". Ao descer recursivamente a partir da raiz, estreitando o limite superior para o filho esquerdo e o limite inferior para o filho direito, é possível determinar em uma única travessia se todos os nós satisfazem as condições da BST.

## Processo de Raciocínio

1. **Verificar apenas pai e filho direto não é suficiente**: Apenas verificar que cada nó é maior que seu filho esquerdo direto e menor que seu filho direito direto não satisfaz as condições da BST. "Todos" os nós na subárvore esquerda devem ser menores que esse nó. Ou seja, cada nó possui restrições herdadas dos seus ancestrais
2. **Definir o intervalo válido de cada nó**: A raiz pode assumir qualquer valor, então o intervalo começa com `(-∞, +∞)`. Ao avançar para o filho esquerdo, o limite superior se estreita para o valor do pai, e ao avançar para o filho direito, o limite inferior se estreita para o valor do pai. Basta passar esse intervalo como argumento da recursão
3. **Determinar a condição de validação**: Em cada nó, verificar se `node.val` está dentro do intervalo `(lo, hi)`. Como a BST usa desigualdade estrita, se `node.val <= lo` ou `node.val >= hi`, o nó é considerado inválido
4. **Determinar a estrutura da recursão**: O caso base é `node == null`, que retorna `true` (uma árvore vazia é uma BST válida). Em cada nó, valida-se o próprio valor e faz-se chamadas recursivas para os filhos esquerdo e direito com o intervalo estreitado. Retorna `true` somente se ambos os filhos retornarem `true`
5. **Usar o tipo long para o intervalo**: Quando o valor do nó é `Integer.MIN_VALUE` ou `Integer.MAX_VALUE`, não é possível representar o valor inicial com o tipo int. Ao usar `Long.MIN_VALUE` e `Long.MAX_VALUE` como intervalo inicial, todos os valores int podem ser validados corretamente
6. **O que retornar no final**: A recursão começa a partir da raiz, retornando `true` se todos os nós estiverem dentro do intervalo válido, ou `false` se houver pelo menos uma violação

## Conhecimentos Prévios

### O que é uma Árvore Binária de Busca (BST)

Uma árvore binária com a propriedade de que, para cada nó, todos os valores na subárvore esquerda são menores que o valor do nó, e todos os valores na subárvore direita são maiores que o valor do nó. Esta propriedade se aplica não apenas aos filhos diretos, mas a toda a subárvore.

```
      5
     / \
    3   7     ← BST válida: 3<5, 7>5, 1<3, 4>3 e 4<5, 6>5 e 6<7
   / \   \
  1   4   8
```

### Estreitamento do intervalo por recursão

O mecanismo pelo qual o intervalo válido de valores se estreita ao avançar do pai para o filho:

```
Nó 5: intervalo(-∞, +∞)
├─ Filho esquerdo 3: intervalo(-∞, 5)  ← limite superior se estreita para o valor 5 do pai
│  ├─ Filho esquerdo 1: intervalo(-∞, 3)
│  └─ Filho direito 4: intervalo(3, 5)  ← limite inferior 3 e limite superior 5
└─ Filho direito 7: intervalo(5, +∞)  ← limite inferior se estreita para o valor 5 do pai
```

### Razão para usar o tipo long

O intervalo do `int` em Java é de `-2147483648` a `2147483647`. Para expressar "qualquer valor do tipo int é permitido" como intervalo inicial, é necessário um valor que exceda o intervalo do tipo int. Usando o tipo `long`, é possível definir um intervalo inicial suficientemente amplo com `Long.MIN_VALUE` e `Long.MAX_VALUE`.

```java
long lo = Long.MIN_VALUE;  // menor que qualquer valor int
long hi = Long.MAX_VALUE;  // maior que qualquer valor int
node.val <= lo;            // como node.val é do tipo int, é garantido ser maior que Long.MIN_VALUE
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — cada nó é visitado exatamente uma vez |
| Space | O(h) — a profundidade da pilha de chamadas recursivas é proporcional à altura h da árvore (pior caso O(n), caso balanceado O(log n)) |

## Código

```java
// Entrada: nó raiz da árvore binária root
// Saída: true se a árvore for uma BST válida, false caso contrário
public boolean isValidBST(TreeNode root) {
    // Define o intervalo inicial como Long.MIN_VALUE/MAX_VALUE para que o nó raiz aceite qualquer valor do tipo int
    return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
}

// lo e hi são do tipo long. Isso porque não é possível usar Integer.MIN_VALUE/MAX_VALUE como valores iniciais com o tipo int
boolean validate(TreeNode node, long lo, long hi) {
    // Caso base: um nó vazio não viola as condições da BST
    if (node == null) return true;

    // Se o valor do nó atual estiver fora do intervalo válido (lo, hi), é inválido
    // Na BST, valores iguais também não são permitidos, então a validação é estrita com <= e >=
    if (node.val <= lo || node.val >= hi) return false;

    // Subárvore esquerda: estreita o limite superior para node.val (todos os valores à esquerda devem ser menores que node.val). O limite inferior lo mantém a restrição dos ancestrais
    // Subárvore direita: estreita o limite inferior para node.val (todos os valores à direita devem ser maiores que node.val). O limite superior hi mantém a restrição dos ancestrais
    // Somente se ambos esquerdo e direito retornarem true, toda esta subárvore é uma BST válida
    return validate(node.left, lo, node.val)
        && validate(node.right, node.val, hi);
}
```
