# Detecting Axis-Aligned Squares From Points — Contar quadrados com lados paralelos aos eixos a partir de pontos armazenados

## Essência do problema

Projetar uma estrutura de dados que possui uma operação `add` para adicionar pontos em um plano 2D e uma operação `count` que retorna o número de **quadrados com lados paralelos aos eixos** (todos os 4 lados paralelos ao eixo x ou ao eixo y) que contêm o ponto fornecido como um dos vértices. Pontos adicionados múltiplas vezes na mesma coordenada são tratados como pontos distintos.

## Ideia central

Em um quadrado com lados paralelos aos eixos, uma vez que dois pontos na diagonal são determinados, os dois pontos restantes são determinados de forma única. Ao enumerar pontos com a mesma coordenada x que o ponto de consulta como candidatos a parceiros na diagonal, e verificar a existência dos dois vértices restantes em O(1) usando um HashMap, é possível contar os quadrados de forma eficiente.

## Processo de raciocínio

1. **Compreender as propriedades de um quadrado com lados paralelos aos eixos**: Como os 4 lados são paralelos aos eixos x e y, os 4 vértices têm a forma `(x1,y1)`, `(x1,y2)`, `(x2,y1)`, `(x2,y2)`. Ou seja, o quadrado é composto por combinações de 2 pontos com a mesma coordenada x e 2 pontos com a mesma coordenada y
2. **Identificar os 2 pontos restantes a partir de 2 pontos na diagonal**: Ao escolher o ponto de consulta `(px, py)` e um ponto com a mesma coordenada x mas coordenada y diferente `(px, pt_y)`, o comprimento do lado é `|py - pt_y|`. Os 2 vértices restantes devem existir nas posições `(px ± side, py)` e `(px ± side, pt_y)`
3. **O quadrado pode ser formado em 2 direções, esquerda e direita**: Uma vez que o comprimento do lado `side` é determinado, a outra coordenada x pode ser `px - side` ou `px + side`. É necessário verificar ambas as direções
4. **Registrar a quantidade de pontos em cada coordenada**: Como múltiplos pontos podem ser adicionados na mesma coordenada, o número de ocorrências de cada coordenada é gerenciado com um HashMap. O produto dos números de ocorrências dos 2 vértices restantes é o número de quadrados que podem ser formados com essa combinação
5. **Obter rapidamente pontos com a mesma coordenada x**: Gerenciar uma lista de todos os pontos com uma determinada coordenada x em um HashMap separado, usando a coordenada x como chave. Isso permite enumerar eficientemente apenas os pontos com a mesma coordenada x durante o `count`
6. **Acumular e retornar o resultado**: Para cada candidato a parceiro e cada direção, adicionar o produto dos números de ocorrências dos 2 vértices restantes ao resultado

## Conhecimentos prévios

### Método para usar coordenadas como chave de HashMap

Para usar uma coordenada 2D `(x, y)` como chave de um HashMap, existe o método de convertê-la para a string `"x,y"`. Isso permite armazenar e recuperar valores em O(1) para qualquer coordenada.

```java
Map<String, Integer> cnt = new HashMap<>();
String key = x + "," + y;               // coordenada(3,5) → "3,5"
cnt.put(key, cnt.getOrDefault(key, 0) + 1);  // incrementa em 1 o número de ocorrências dessa coordenada
cnt.getOrDefault(key, 0);               // retorna 0 se não existir
```

### O que é computeIfAbsent

É um método que gera e registra um novo valor somente quando a chave especificada não existe no Map. Se a chave já existir, retorna o valor existente sem alteração. É conveniente ao construir Maps de listas.

```java
Map<Integer, List<int[]>> xMap = new HashMap<>();
// Se a chave 5 não existir, cria um novo ArrayList; se existir, retorna a lista existente
xMap.computeIfAbsent(5, k -> new ArrayList<>()).add(new int[]{5, 3});
```

### Como contar combinações (regra do produto)

Quando duas escolhas independentes possuem `c1` e `c2` possibilidades respectivamente, o número total de combinações é `c1 * c2`. Neste problema, quando existem `c1` pontos e `c2` pontos nas coordenadas dos 2 vértices restantes, o número de formas de escolher esses 2 vértices é `c1 * c2`.

## Complexidade

| | Valor |
|---|---|
| Time | add: O(1) — apenas registro no HashMap. count: O(n) — percorre todos os pontos com a mesma coordenada x |
| Space | O(n) — armazena as coordenadas e o número de ocorrências de todos os pontos no HashMap |

## Código

```java
// add(int[] p): adiciona o ponto p = [x, y] no plano 2D
// count(int[] p): retorna como int o número de quadrados com lados paralelos aos eixos que contêm o ponto p = [x, y] como um dos vértices
class DetectSquares {
    // HashMap que gerencia o número de ocorrências de cada coordenada (chave: "x,y")
    // Usado para obter em O(1) quantos pontos existem em qualquer coordenada durante o count
    Map<String, Integer> cnt;
    // HashMap que gerencia a lista de pontos com a mesma coordenada x (chave: coordenada x)
    // Usado para enumerar eficientemente apenas os pontos com a mesma coordenada x durante o count
    Map<Integer, List<int[]>> xMap;

    DetectSquares() {
        cnt = new HashMap<>();
        xMap = new HashMap<>();
    }

    void add(int[] p) {
        // Converte a coordenada para a string "x,y" e incrementa o número de ocorrências em 1
        String key = p[0] + "," + p[1];
        cnt.put(key, cnt.getOrDefault(key, 0) + 1);

        // Adiciona o ponto à lista por coordenada x (cria uma nova lista se for a primeira vez para essa coordenada x)
        xMap.computeIfAbsent(p[0],
            k -> new ArrayList<>()).add(p);
    }

    int count(int[] p) {
        int res = 0;
        int px = p[0], py = p[1];

        // Obtém a lista de pontos com a mesma coordenada x que o ponto de consulta
        // Se a lista não existir, não é possível formar um quadrado, então retorna 0
        List<int[]> same = xMap.get(px);
        if (same == null) return 0;

        // Percorre cada ponto com a mesma coordenada x como candidato a parceiro
        for (int[] pt : same) {
            // Calcula o comprimento do lado (valor absoluto da diferença entre as coordenadas y do ponto de consulta e do ponto parceiro)
            int side = Math.abs(py - pt[1]);
            // Pontos com a mesma coordenada y resultam em comprimento de lado 0 e não podem formar um quadrado, então são ignorados
            if (side == 0) continue;

            // Como o quadrado pode ser formado em 2 direções (esquerda e direita), tenta ambas as coordenadas x
            int[] dirs = {px - side, px + side};
            for (int nx : dirs) {
                // Obtém o número de ocorrências das coordenadas dos 2 vértices restantes (nx, py) e (nx, pt[1])
                // Coordenadas inexistentes retornam 0, e o produto também será 0, então não são adicionadas automaticamente
                String k1 = nx + "," + py;
                String k2 = nx + "," + pt[1];
                int c1 = cnt.getOrDefault(k1, 0);
                int c2 = cnt.getOrDefault(k2, 0);

                // O produto dos números de ocorrências dos 2 vértices é o número de quadrados que podem ser formados com esta combinação (regra do produto)
                res += c1 * c2;
            }
        }
        return res;
    }
}
```
