# Designing a Word Dictionary With Wildcard Search — Busca de Palavras em Dicionário com Curinga

## Essência do Problema

O objetivo é projetar uma estrutura de dados que suporte duas operações: adicionar palavras e buscar palavras. Durante a busca, o ponto `.` funciona como um curinga que corresponde a qualquer caractere único. Por exemplo, se a palavra "bad" estiver registrada no dicionário, `search("b.d")` retorna `true` e `search("b.e")` retorna `false`.

## Ideia Central

As palavras são armazenadas em uma Trie. Para caracteres comuns, basta seguir um único nó filho correspondente. Porém, ao encontrar um ponto, o algoritmo ramifica para "todos os nós filhos" e realiza uma busca em profundidade (DFS), permitindo assim a correspondência com qualquer caractere único.

## Processo de Raciocínio

1. **Realizar adição de palavras e busca por prefixo de forma eficiente**: A Trie é a estrutura de dados adequada, pois armazena strings compartilhando caracteres um a um. Com a Trie, palavras com prefixos em comum compartilham nós, garantindo eficiência tanto em memória quanto em busca
2. **A busca de caracteres comuns é uma operação básica da Trie**: Para um caractere `c`, basta seguir `children[c - 'a']` do nó atual. Se o nó filho for `null`, não há correspondência; se existir, o algoritmo avança para o próximo caractere
3. **O ponto significa ramificação para todos os nós filhos**: Como o ponto corresponde a qualquer caractere único, é necessário testar todos os nós filhos não nulos entre os 26 filhos do nó atual. Se qualquer um deles corresponder ao restante da string, o algoritmo retorna `true`
4. **A busca em profundidade (DFS) é usada para explorar as ramificações**: O algoritmo percorre recursivamente cada caminho ramificado pelo ponto. Quando atinge o final da palavra, verifica se o flag `isEnd` é `true` para confirmar o sucesso da busca. A DFS permite tratar de forma unificada tanto o processamento de ramificações quanto o de caracteres comuns
5. **Definir a condição de término da recursão**: Quando todos os caracteres da string foram processados (`idx == word.length()`), se o `isEnd` do nó atual for `true`, a palavra existe no dicionário. Se um nó filho for `null` durante o percurso, esse caminho é considerado sem correspondência
6. **O que retornar no final**: O método `search` inicia a DFS recursiva a partir do nó raiz e retorna `true` se pelo menos um caminho corresponder, ou `false` caso contrário

## Conhecimentos Prévios

### O que é uma Trie (Árvore de Prefixos)

A Trie é uma estrutura de dados em árvore que armazena strings decompondo-as caractere por caractere em nós. Cada nó possui no máximo 26 nós filhos (a–z), e ao percorrer da raiz até uma folha, obtém-se uma palavra. Palavras com prefixos em comum compartilham nós, tornando a Trie adequada para armazenar dicionários.

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // 26 nós filhos correspondentes a a–z
    boolean isEnd = false;                    // Indica se existe uma palavra que termina neste ponto
}
```

### O que é Busca em Profundidade (DFS)

A DFS é um método de exploração de árvores e grafos. O algoritmo avança por um caminho até o final e, ao chegar a um beco sem saída, retrocede um passo e tenta outro caminho. A implementação recursiva é natural e adequada para a exploração de ramificações em uma Trie.

```java

    // idx é a posição do caractere sendo processado atualmente
    // Percorre os nós filhos recursivamente em busca de um caminho que satisfaça a condição
}
```

### Conversão de char para inteiro

Em Java, o tipo `char` possui um valor inteiro. A expressão `c - 'a'` obtém a posição alfabética (0–25) do caractere `c`. Esse valor é usado como índice no array `children` da Trie.

```java
char c = 'd';
int idx = c - 'a';  // idx = 3 ('a'=0, 'b'=1, 'c'=2, 'd'=3)
```

## Complexidade

| | Valor |
|---|---|
| Tempo (addWord) | O(m) — Proporcional ao comprimento m da palavra, percorrendo os nós da Trie |
| Tempo (search) | O(26^d × m) — d é o número de pontos e m é o comprimento da palavra. Sem pontos, é O(m) |
| Espaço | O(n × m) — Armazena n palavras (comprimento médio m) na Trie |

## Código

```java
// Entrada: addWord(word) recebe a string word e a adiciona ao dicionário. search(word) recebe a string word (que pode conter ".")
// Saída: search retorna true se existir uma palavra correspondente no dicionário, ou false caso contrário

class TrieNode {
    TrieNode[] children;  // 26 nós filhos correspondentes a a–z
    boolean isEnd;        // Indica se existe uma palavra que termina neste ponto

    TrieNode() {
        children = new TrieNode[26];
        isEnd = false;
    }
}

class WordDictionary {
    TrieNode root;  // Nó raiz da Trie

    WordDictionary() {
        root = new TrieNode();
    }

    // Adiciona uma palavra à Trie
    void addWord(String word) {
        // Inicializa o nó atual como a raiz
        TrieNode node = root;
        // Processa cada caractere da palavra do início ao fim
        for (char c : word.toCharArray()) {
            // c - 'a' determina a posição no array children correspondente ao caractere c
            int idx = c - 'a';
            // Cria um novo nó filho se ele não existir
            if (node.children[idx] == null)
                node.children[idx] = new TrieNode();
            // Move para o nó filho
            node = node.children[idx];
        }
        // Registra o final da palavra. Indica que existe uma palavra no dicionário que termina neste ponto
        node.isEnd = true;
    }

    // Inicia a busca com curinga a partir da raiz
    boolean search(String word) {
        // Inicia a DFS a partir do nó raiz na posição 0
        return dfs(root, word, 0);
    }

    // Explora a Trie recursivamente usando DFS
    boolean dfs(TrieNode node, String word, int idx) {
        // Condição de término: quando todos os caracteres foram processados, retorna se o nó atual é o final de uma palavra
        // Se true, a palavra existe; se false, existe apenas uma correspondência parcial
        if (idx == word.length())
            return node.isEnd;

        char c = word.charAt(idx);

        if (c == '.') {
            // Caso do ponto: testa todos os 26 nós filhos (corresponde a qualquer caractere único)
            for (TrieNode child : node.children) {
                // Explora recursivamente cada nó filho que não seja null
                if (child != null && dfs(child, word, idx + 1))
                    return true;  // Retorna true imediatamente se qualquer caminho corresponder
            }
            // Retorna false se nenhum nó filho resultou em correspondência
            return false;
        } else {
            // Caso de caractere comum: calcula o índice com c - 'a' e segue o nó filho correspondente
            int i = c - 'a';
            // Se o nó filho não existir, o caractere correspondente não está presente, portanto não há correspondência
            if (node.children[i] == null)
                return false;
            // Se o nó filho existir, continua a recursão na próxima posição idx + 1
            return dfs(node.children[i], word, idx + 1);
        }
    }
}
```
