# Finding All Words From a Dictionary in a Grid — Buscar todas as palavras do dicionário simultaneamente em um grid

## Essência do Problema

Um grid 2D de caracteres `board` e uma lista de palavras `words` são fornecidos. O objetivo é encontrar e retornar todas as palavras de `words` que podem ser formadas percorrendo células adjacentes (cima, baixo, esquerda, direita) no grid. Cada célula pode ser usada apenas uma vez durante a formação de uma palavra.

## Ideia Central

Todas as palavras da lista são armazenadas em uma Trie. Ao realizar DFS a partir de cada célula do grid, os nós da Trie são percorridos simultaneamente, permitindo buscar todas as palavras ao mesmo tempo. Como a DFS é interrompida imediatamente nas direções onde não existem ramificações na Trie, a exploração desnecessária é drasticamente reduzida.

## Processo de Raciocínio

1. **Buscar múltiplas palavras simultaneamente**: Se a DFS for executada individualmente para cada palavra, a complexidade computacional será número de palavras × total de células do grid × comprimento máximo da palavra. Quando múltiplas palavras compartilham o mesmo prefixo, é eficiente buscar várias palavras simultaneamente em uma única DFS
2. **A Trie é adequada para gerenciar prefixos comuns**: A Trie, também chamada de árvore de prefixos, compartilha prefixos comuns de strings como um único caminho. Ao inserir todas as palavras na Trie, é possível determinar em O(1) durante a DFS se o caminho atual corresponde a um prefixo de alguma palavra
3. **Armazenar a própria palavra no nó da Trie**: Ao armazenar a string completa da palavra no nó final, quando a DFS alcança esse nó, é possível obter imediatamente qual palavra foi encontrada
4. **Executar DFS a partir de cada célula do grid usando a raiz da Trie como ponto de partida**: A DFS é realizada a partir de cada célula como ponto inicial, percorrendo os caracteres desde a raiz da Trie. Se não existir um nó filho correspondente ao caractere atual na Trie, a exploração nessa direção é interrompida imediatamente (poda)
5. **Marcação de células visitadas**: Para evitar revisitar a mesma célula durante a DFS, o caractere da célula atualmente visitada é temporariamente substituído pelo caractere especial `'#'`. Após a conclusão da DFS, o caractere original é restaurado (backtracking)
6. **Prevenção de duplicatas**: A mesma palavra pode ser encontrada por múltiplos caminhos. Ao definir `word` como `null` no nó da Trie no momento em que a palavra é adicionada à lista de resultados, a adição duplicada da mesma palavra é evitada

## Conhecimentos Prévios

### O que é uma Trie (Árvore de Prefixos)

Uma estrutura de árvore para armazenar e buscar conjuntos de strings de forma eficiente. Cada nó possui até 26 nós filhos (a–z), e o caminho da raiz até a folha representa uma string. Strings com prefixos comuns compartilham caminhos, permitindo a verificação de prefixos em O(comprimento da string).

```java
class TrieNode {
    TrieNode[] children = new TrieNode[26];  // Array de nós filhos para os 26 caracteres de a a z
    String word = null;                       // Palavra completa neste nó (null se não for um nó final)
}

// Inserção de uma palavra na Trie
TrieNode root = new TrieNode();
TrieNode node = root;
for (char c : "cat".toCharArray()) {
    int i = c - 'a';                          // Converter caractere em índice ('a'→0, 'b'→1, ...)
    if (node.children[i] == null)
        node.children[i] = new TrieNode();    // Criar novo nó filho se não existir
    node = node.children[i];                  // Avançar para o nó filho
}
node.word = "cat";                            // Armazenar a palavra no nó final
```

### O que é Backtracking

Uma variação da DFS (busca em profundidade) que modifica o estado durante a exploração e restaura o estado após a conclusão. Isso garante que as modificações de estado feitas em um caminho de exploração não afetem outros caminhos.

```java
board[r][c] = '#';    // Marcar como em visita (impedir que outros caminhos revisitem esta célula)
// ... Explorar as 4 direções (cima, baixo, esquerda, direita) com DFS ...
board[r][c] = ch;     // Restaurar o caractere original (permitir reutilização em explorações a partir de outros pontos de início)
```

### Conversão entre char e int

Em Java, o tipo `char` possui um valor inteiro, permitindo calcular a diferença entre caracteres para converter em índice.

```java
char ch = 'c';
int index = ch - 'a';   // 'c' - 'a' = 2 (usado como índice do array)
```

## Complexidade

| | Valor |
|---|---|
| Time | O(M × N × 4^L) — M×N é o número de células do grid e L é o comprimento da palavra mais longa. A partir de cada célula, a recursão ocorre no máximo em 4 direções, L vezes |
| Space | O(soma do número de caracteres de todas as palavras) — Espaço para armazenar todas as palavras na Trie |

## Código

```java
// Entrada: array 2D de caracteres board e array de strings words
// Saída: retorna uma List<String> contendo todas as palavras que podem ser formadas no board

class TrieNode {
    TrieNode[] children = new TrieNode[26];  // Nós filhos de a a z
    String word = null;                       // Palavra completa neste nó
}

// Inserir todas as palavras na Trie e retornar o nó raiz
TrieNode buildTrie(String[] words) {
    // Criar um nó raiz para construir uma Trie vazia (ponto de partida para a busca de todas as palavras)
    TrieNode root = new TrieNode();
    // Inserir cada palavra de words na Trie
    for (String w : words) {
        TrieNode node = root;
        // Percorrer os nós filhos um caractere por vez a partir da raiz
        for (char c : w.toCharArray()) {
            int i = c - 'a';
            // Criar um novo nó filho se não existir
            if (node.children[i] == null)
                node.children[i] = new TrieNode();
            node = node.children[i];
        }
        // Armazenar a string da palavra no nó final (permite obter a palavra completa imediatamente ao alcançar o nó durante a DFS)
        node.word = w;
    }
    return root;
}

// Realizar DFS no grid enquanto percorre os nós da Trie
void dfs(char[][] board, int r, int c,
    TrieNode node, List<String> res) {
    // Verificação de limites: retornar imediatamente se a linha r ou coluna c estiver fora do grid
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length)
        return;
    char ch = board[r][c];
    // Retornar imediatamente se a célula tiver a marca de visita '#' (evitar revisita no mesmo caminho)
    if (ch == '#') return;
    // Obter o nó filho da Trie correspondente ao caractere atual
    TrieNode next = node.children[ch - 'a'];
    // Se não houver nó filho, não existe palavra na Trie que continue nesta direção (poda)
    if (next == null) return;
    // Se uma palavra estiver completa, adicioná-la ao resultado e definir como null para evitar duplicatas
    // (a mesma palavra pode ser encontrada por múltiplos caminhos)
    if (next.word != null) {
        res.add(next.word);
        next.word = null;
    }
    // Substituir a célula atual por '#' para marcá-la como em visita
    board[r][c] = '#';
    // Realizar DFS recursivamente nas 4 direções (cima, baixo, esquerda, direita), passando o nó next
    dfs(board, r + 1, c, next, res);
    dfs(board, r - 1, c, next, res);
    dfs(board, r, c + 1, next, res);
    dfs(board, r, c - 1, next, res);
    // Restaurar o caractere original ch na célula (backtracking: permitir reutilização em explorações a partir de outros pontos de início)
    board[r][c] = ch;
}

// Função principal: buscar todas as palavras do dicionário no grid
List<String> findWords(char[][] board, String[] words) {
    // Inserir todas as palavras na Trie
    TrieNode root = buildTrie(words);
    // Criar uma lista vazia para armazenar os resultados
    List<String> res = new ArrayList<>();
    // Percorrer todas as células (i, j) com dois loops for e executar DFS a partir de cada célula como ponto de início
    // Passar o nó raiz da Trie para a DFS
    for (int i = 0; i < board.length; i++) {
        for (int j = 0; j < board[0].length; j++) {
            dfs(board, i, j, root, res);
        }
    }
    // Retornar os resultados após a conclusão da DFS a partir de todas as células
    return res;
}
```
