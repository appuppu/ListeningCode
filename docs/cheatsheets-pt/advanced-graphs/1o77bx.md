# Deriving the Order of an Alien Alphabet — Restaurar a ordem dos caracteres de um idioma alienígena

## Essência do problema

É fornecida uma lista de palavras `words` ordenada lexicograficamente em um idioma alienígena. A partir dessa ordenação, é necessário estimar a ordem do alfabeto nesse idioma e retorná-la como uma string. Se houver contradição na ordem (por exemplo, existência de ciclo ou uma palavra mais curta vir após uma palavra mais longa), retorna-se a string vazia `""`.

## Ideia central

Ao comparar duas palavras adjacentes, obtém-se uma relação de ordem (aresta direcionada) a partir do "primeiro caractere diferente". Constrói-se um grafo direcionado com todas as relações de ordem obtidas de todos os pares e determina-se a ordem total por meio de uma ordenação topológica com DFS. Se houver ciclo, a ordem é contraditória.

## Processo de raciocínio

1. **Extrair relações de ordem comparando palavras adjacentes**: Na lista ordenada, compara-se as duas palavras adjacentes `words[i]` e `words[i+1]` a partir do início. Quando se encontra o primeiro par de caracteres diferentes `(a, b)`, confirma-se uma relação de ordem "a vem antes de b". Essa relação pode ser representada como a aresta `a → b` em um grafo direcionado
2. **Detectar entrada inválida**: Se `words[i]` for um prefixo de `words[i+1]` e `words[i]` for mais longa (exemplo: `"abc"` antes de `"ab"`), há contradição na ordem lexicográfica, e retorna-se imediatamente a string vazia
3. **Registrar todos os caracteres como nós**: Como existem caracteres para os quais nenhuma relação de ordem é obtida, todos os caracteres de todas as palavras são registrados como nós do grafo. Isso garante que caracteres sem arestas também sejam incluídos no resultado
4. **Determinar a ordem total por ordenação topológica com DFS**: Executa-se DFS no grafo direcionado e adiciona-se cada nó a uma lista no momento da conclusão da exploração. Ao inverter a ordem pós-visita (post-order) do DFS, obtém-se a ordem topológica (na qual as dependências vêm primeiro)
5. **Detectar ciclos com marcação de 3 cores**: Durante o DFS, cada nó é gerenciado em 3 estados: "não visitado(0)", "em exploração(1)" e "explorado(2)". Se um nó em exploração for alcançado novamente, existe um ciclo, e a ordem não pode ser determinada, retornando-se a string vazia
6. **Inverter e construir a string**: Inverte-se a lista de ordem pós-visita do DFS para obter a ordem topológica. Concatenam-se todos os caracteres da lista para retornar a string resultado

## Conhecimentos prévios

### O que é ordenação topológica

É a operação de dispor todos os nós de um grafo acíclico direcionado (DAG) em uma sequência linear sem contradizer a direção das arestas. Se existir uma aresta `a → b`, no resultado `a` sempre virá antes de `b`. Grafos com ciclos não possuem ordem topológica.

### O que é a marcação de 3 cores no DFS

É uma técnica que gerencia o estado de cada nó no DFS usando 3 cores. Branco(0) indica não visitado, cinza(1) indica que o nó está no caminho de exploração atual (presente na pilha de recursão) e preto(2) indica exploração concluída. Quando se alcança novamente um nó cinza, confirma-se a existência de um ciclo.

```java
Map<Character, Integer> color = new HashMap<>();
color.put('a', 0);  // Branco: não visitado
color.put('a', 1);  // Cinza: em exploração (presente na pilha de recursão)
color.put('a', 2);  // Preto: exploração concluída (todos os descendentes já processados)
```

### Operações básicas de HashMap e HashSet

```java
// HashMap: armazena pares de chave e valor. Busca e obtenção são O(1)
Map<Character, Set<Character>> adj = new HashMap<>();
adj.putIfAbsent('a', new HashSet<>());  // Registra um Set vazio apenas se a chave não estiver registrada
adj.get('a').add('b');                  // Adiciona 'b' à lista de adjacência da chave 'a'

// HashSet: conjunto sem duplicatas. Adição e busca são O(1)
Set<Character> set = new HashSet<>();
set.add('b');        // Adiciona um elemento
set.contains('b');   // Verifica a existência do elemento → true
```

### Método startsWith

Verifica se uma string começa com o prefixo especificado.

```java
"abc".startsWith("ab");  // true — "abc" começa com "ab"
"ab".startsWith("abc");  // false — "ab" não começa com "abc"
```

## Complexidade

| | Valor |
|---|---|
| Time | O(C) — C é o número total de caracteres de todas as palavras. A construção do grafo percorre todos os caracteres, e o DFS é proporcional ao número de nós + arestas, mas nenhum excede C |
| Space | O(1) — O número de nós é no máximo 26 caracteres (letras minúsculas) e é constante. O número de arestas também é no máximo 26² e é constante. Não depende do tamanho da entrada |

## Código

```java
// Entrada: array de strings words ordenado lexicograficamente no idioma alienígena
// Saída: string representando a ordem do alfabeto. Se houver contradição, retorna a string vazia ""

// DFS: registra a ordem pós-visita enquanto detecta ciclos com marcação de 3 cores
boolean dfs(char c, Map<Character, Set<Character>> adj,
            Map<Character, Integer> color, List<Character> result) {
    // Alcançou novamente um nó cinza (em exploração) → ciclo detectado
    if (color.get(c) == 1) return false;
    // Nó preto (já explorado) → já foi processado, portanto pula-se
    if (color.get(c) == 2) return true;

    // Marca o nó atual como cinza (em exploração)
    color.put(c, 1);

    // Executa DFS recursivamente para todos os nós adjacentes (caracteres que vêm depois deste caractere)
    for (char n : adj.get(c))
        if (!dfs(n, adj, color, result))
            return false;  // Ciclo detectado em um descendente → propaga imediatamente

    // A exploração de todos os descendentes foi concluída, portanto marca-se como preto
    color.put(c, 2);
    // Adiciona à lista em ordem pós-visita (no DFS, as dependências são adicionadas primeiro, portanto após a inversão obtém-se a ordem topológica)
    result.add(c);
    return true;
}

public String alienOrder(String[] words) {
    // Lista de adjacência: chave=caractere, valor=conjunto de caracteres que vêm depois desse caractere
    Map<Character, Set<Character>> adj = new HashMap<>();

    // Registra todos os caracteres de todas as palavras como nós do grafo
    // Registram-se todos os caracteres neste ponto porque caracteres sem relações de ordem (arestas) também precisam ser incluídos no resultado
    for (String w : words)
        for (char c : w.toCharArray())
            adj.putIfAbsent(c, new HashSet<>());

    // Compara duas palavras adjacentes e extrai relações de ordem (arestas direcionadas)
    for (int i = 0; i < words.length - 1; i++) {
        String w1 = words[i];
        String w2 = words[i + 1];

        // Detecção de entrada inválida: palavra mais longa está antes de um prefixo mais curto (exemplo: ["abc","ab"] é contraditório)
        if (w1.length() > w2.length() && w1.startsWith(w2))
            return "";

        int len = Math.min(w1.length(), w2.length());
        for (int j = 0; j < len; j++) {
            if (w1.charAt(j) != w2.charAt(j)) {
                // Obtém uma relação de ordem a partir do primeiro caractere diferente e sai imediatamente do loop
                // Diferenças a partir do segundo caractere só têm significado se os caracteres anteriores forem iguais, portanto extrai-se apenas uma relação
                adj.get(w1.charAt(j)).add(w2.charAt(j));
                break;
            }
        }
    }

    // Cria o mapa de gerenciamento de 3 cores e inicializa todos os nós como branco (0: não visitado)
    Map<Character, Integer> color = new HashMap<>();
    for (char c : adj.keySet())
        color.put(c, 0);

    // Lista para registrar a ordem pós-visita do DFS
    List<Character> result = new ArrayList<>();

    // Executa DFS para todos os nós (inicia a partir de todos os nós para tratar grafos não conexos)
    for (char c : adj.keySet())
        if (!dfs(c, adj, color, result))
            return "";  // Ciclo detectado → a ordem não pode ser determinada

    // Inverte a ordem pós-visita para obter a ordem topológica
    Collections.reverse(result);

    // Concatena todos os caracteres para construir a string resultado
    StringBuilder sb = new StringBuilder();
    for (char c : result) sb.append(c);
    return sb.toString();
}
```
