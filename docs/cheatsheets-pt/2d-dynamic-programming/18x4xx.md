# Implementing Regular Expression Matching — Determinar se uma string corresponde completamente a um padrão

## Essência do problema

Recebemos uma string de entrada `s` e um padrão `p`. No padrão, `.` corresponde a qualquer caractere único, e `*` significa zero ou mais repetições do caractere imediatamente anterior. O método retorna um `boolean` indicando se o padrão corresponde à string **inteira**.

## Ideia central

Preenchemos uma tabela de DP bidimensional do final para o início da string e do padrão. `dp[i][j]` representa "se `s[i:]` corresponde a `p[j:]`". Quando há um `*`, o problema se reduz a duas escolhas: "usar o caractere anterior zero vezes (pular)" ou "usar uma vez e avançar uma posição na string".

## Processo de raciocínio

1. **O problema pode ser decomposto em subproblemas**: Ao fixar a posição `i` na string e a posição `j` no padrão, obtemos o subproblema "se `s[i:]` corresponde a `p[j:]`". Armazenando a resposta desse subproblema em `dp[i][j]`, evitamos cálculos redundantes
2. **Verificar a correspondência do caractere na posição atual**: Se `s[i]` e `p[j]` são o mesmo caractere, ou se `p[j]` é `.`, então o caractere na posição atual corresponde. Armazenamos esse resultado na variável `match`
3. **Considerar as duas opções quando há `*`**: Quando `p[j+1]` é `*`, o padrão `x*` pode ser interpretado de duas formas. A primeira é "zero correspondências (pular)", pulando `x*` inteiramente e consultando `dp[i][j+2]`. A segunda é "uma ou mais correspondências": se o caractere atual corresponde, avançamos uma posição na string e consultamos `dp[i+1][j]` (não avançamos o padrão, pois a repetição pelo `*` pode continuar na próxima posição)
4. **Sem `*`, simplesmente avançamos um caractere por vez**: Se o caractere atual corresponde, a resposta é diretamente `dp[i+1][j+1]`, avançando tanto a string quanto o padrão em uma posição
5. **Definir o caso base**: O estado `dp[n][m]`, onde tanto a string quanto o padrão chegaram ao final, é `true`. Se a string ainda tem caracteres restantes mas o padrão chegou ao final, o resultado é `false`. Se o padrão ainda tem caracteres restantes mas a string chegou ao final, o resultado só pode ser `true` por meio de pulos com `*`
6. **Preencher a tabela do final para o início**: O cálculo de `dp[i][j]` depende de `dp[i][j+2]`, `dp[i+1][j]` e `dp[i+1][j+1]`. Todos esses valores estão na direção em que `i` ou `j` são maiores. Portanto, ao percorrer `i` de `n` até `0` e `j` de `m-1` até `0` em ordem reversa, os valores referenciados já estarão calculados
7. **O que retornar no final**: `dp[0][0]` na tabela é a resposta para "se a string inteira corresponde ao padrão inteiro"

## Conhecimentos prévios

### O que é uma tabela de DP bidimensional

É um array bidimensional que armazena a resposta de um subproblema para cada combinação de duas variáveis (neste caso, a posição `i` na string e a posição `j` no padrão). Criamos com `boolean[][] dp = new boolean[n+1][m+1]` e armazenamos em `dp[i][j]` o resultado da correspondência entre `s[i:]` e `p[j:]`.

```java
boolean[][] dp = new boolean[n + 1][m + 1];  // Cria uma tabela (n+1)×(m+1) inicializada com false
dp[n][m] = true;                              // Caso base: se ambos chegaram ao final, há correspondência
dp[i][j] = dp[i][j + 2];                     // Referencia o valor de outra célula para preencher a célula atual
```

### String.length() e String.charAt()

`length()` retorna o comprimento da string. `charAt(i)` retorna o caractere no índice `i`. Os índices começam em 0, e acessar um índice fora do intervalo lança uma exceção.

```java
String s = "abc";
s.length();     // → 3
s.charAt(0);    // → 'a'
s.charAt(2);    // → 'c'
```

### Significado do `*` (estrela)

Em expressões regulares, `*` representa "zero ou mais repetições do caractere imediatamente anterior". `a*` corresponde a `""`, `"a"`, `"aa"`, `"aaa"`, ... `.*` significa "zero ou mais repetições de qualquer caractere", correspondendo a qualquer string. O `*` nunca é usado sozinho; ele sempre aparece junto com o caractere anterior na forma `x*`.

## Complexidade

| | Valor |
|---|---|
| Time | O(n×m) — Cada célula da tabela de DP n×m é calculada uma única vez |
| Space | O(n×m) — A tabela de DP n×m é armazenada |

## Código

```java
// Entrada: string s e padrão p
// Saída: retorna um boolean indicando se s inteira corresponde a p
public boolean isMatch(String s, String p) {
    int n = s.length();  // Comprimento da string
    int m = p.length();  // Comprimento do padrão

    // dp[i][j] = tabela bidimensional que armazena "se s[i:] corresponde a p[j:]"
    // Os índices n e m representam a string vazia, por isso o tamanho é +1
    boolean[][] dp = new boolean[n + 1][m + 1];

    // Caso base: se ambas as strings chegaram ao final, a correspondência é bem-sucedida
    dp[n][m] = true;

    // Preenche a tabela do final para o início
    // Essa ordem de percurso garante que dp[i][j+2], dp[i+1][j] e dp[i+1][j+1] já estejam calculados
    for (int i = n; i >= 0; i--) {
        for (int j = m - 1; j >= 0; j--) {
            // Verifica se o caractere na posição atual corresponde
            // Verificar i < n primeiro evita acesso fora do intervalo com charAt quando a string chegou ao final
            boolean match = i < n
                && (s.charAt(i) == p.charAt(j)
                    || p.charAt(j) == '.');

            // Verifica o intervalo com j+1 < m e determina se a posição atual do padrão tem a forma x*
            if (j + 1 < m && p.charAt(j + 1) == '*') {
                // Calcula o OR (disjunção lógica) das duas opções do padrão x*:
                // dp[i][j+2]: zero correspondências (pula x* inteiramente)
                // match && dp[i+1][j]: uma correspondência e avança a string (não avança o padrão, pois a repetição pelo * pode continuar, então j permanece inalterado)
                dp[i][j] = dp[i][j + 2]
                    || (match && dp[i + 1][j]);
            } else {
                // Caractere normal: se um caractere corresponde, avança tanto a string quanto o padrão em uma posição
                dp[i][j] = match
                    && dp[i + 1][j + 1];
            }
        }
    }

    // dp[0][0] é a resposta final para "se a string s inteira corresponde ao padrão p inteiro"
    return dp[0][0];
}
```
