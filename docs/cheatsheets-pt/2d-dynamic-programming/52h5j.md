# Checking if a String is an Interleaving of Two Others — Verificar se uma terceira string pode ser formada intercalando duas outras strings

## Essência do problema

São dadas três strings `s1`, `s2` e `s3`. O objetivo é verificar se `s3` é composta por um **interleaving** (intercalação) de `s1` e `s2`. Interleaving significa usar todos os caracteres de `s1` e `s2`, misturando-os de forma que a ordem relativa de aparição dentro de cada string original seja preservada.

## Ideia central

O problema pode ser decomposto em subproblemas: verificar se os primeiros `i` caracteres de `s1` e os primeiros `j` caracteres de `s2` podem formar os primeiros `i+j` caracteres de `s3`. Em cada posição, a decisão de "tomar o próximo caractere de `s1` ou de `s2`" é avaliada eficientemente por meio de uma tabela de DP.

## Processo de raciocínio

1. **Verificar a pré-condição de comprimento**: Se `s3` for um interleaving de `s1` e `s2`, o comprimento de `s3` deve ser igual à soma dos comprimentos de `s1` e `s2`. Caso contrário, retorna-se `false` imediatamente
2. **Definir o subproblema**: Define-se `dp[i][j]` como "é possível formar os primeiros `i+j` caracteres de `s3` usando os primeiros `i` caracteres de `s1` e os primeiros `j` caracteres de `s2`". Com essa definição, `dp[m][n]` (onde `m` é o comprimento de `s1` e `n` é o comprimento de `s2`) é a resposta final
3. **Derivar a recorrência**: `dp[i][j]` é `true` em um dos dois casos. Caso 1: `dp[i-1][j]` é `true` e o `i`-ésimo caractere de `s1` coincide com o `(i+j)`-ésimo caractere de `s3` (toma-se um caractere de `s1`). Caso 2: `dp[i][j-1]` é `true` e o `j`-ésimo caractere de `s2` coincide com o `(i+j)`-ésimo caractere de `s3` (toma-se um caractere de `s2`)
4. **Definir o caso base**: Quando `i=0` e `j=0`, nenhum caractere foi tomado de nenhuma das strings, o que corresponde aos primeiros 0 caracteres de `s3` (string vazia), portanto `dp[0][0] = true`
5. **Otimizar a complexidade espacial**: A tabela bidimensional `dp[i][j]` usa apenas os valores da linha `i-1` para calcular a linha `i`. Por isso, um array unidimensional `dp[j]` é suficiente: o valor de `dp[j]` antes da atualização corresponde à linha anterior (`dp[i-1][j]`), e o valor de `dp[j-1]` após a atualização corresponde à célula à esquerda na linha atual (`dp[i][j-1]`)
6. **Valor a retornar**: Após o loop externo percorrer `i` de 0 a `m` e o loop interno percorrer `j` de 0 a `n`, `dp[n]` contém a resposta sobre se `s3` inteira pode ser formada por interleaving

## Conhecimentos prévios

### O que é a otimização espacial de DP com array unidimensional

Quando cada linha da tabela bidimensional `dp[i][j]` depende apenas da linha imediatamente anterior, é possível substituí-la por um array unidimensional `dp[j]`. Ao sobrescrever o array a cada linha, a complexidade espacial é reduzida de O(m×n) para O(n).

```java
// Caso bidimensional: dp[i][j] referencia dp[i-1][j] e dp[i][j-1]
boolean[][] dp = new boolean[m + 1][n + 1];

// Otimização para unidimensional: dp[j] é sobrescrito a cada linha
boolean[] dp = new boolean[n + 1];
// Valor de dp[j] antes da atualização → corresponde a dp[i-1][j] da linha anterior
// Valor de dp[j-1] após a atualização → corresponde a dp[i][j-1] da linha atual
```

### O que é String.charAt(index)

É um método que retorna o caractere na posição especificada da string. O índice começa em 0.

```java
String s = "abc";
s.charAt(0);  // retorna 'a'
s.charAt(2);  // retorna 'c'
```

### O que é Interleaving (Intercalação)

É o processo de misturar os caracteres de duas strings para formar uma única string, preservando a ordem relativa de cada string original.
Exemplo: para `s1 = "aab"` e `s2 = "axy"`, `"aaxaby"` é um interleaving (a ordem de a,a,b de `s1` e a,x,y de `s2` é preservada). `"abaaxy"` não é um interleaving porque a ordem dos caracteres de `s1` é quebrada.

## Complexidade

| | Valor |
|---|---|
| Time | O(m×n) — executa-se um único loop duplo com o comprimento `m` de `s1` e o comprimento `n` de `s2` |
| Space | O(n) — utiliza-se apenas um array de DP unidimensional de tamanho `n+1`, correspondente ao comprimento de `s2` |

## Código

```java
// Entrada: string s1 (comprimento m), string s2 (comprimento n), string s3
// Saída: retorna um boolean indicando se s3 pode ser formada pelo interleaving de s1 e s2
public boolean isInterleave(String s1, String s2, String s3) {
    int m = s1.length();
    int n = s2.length();

    // Se m + n não for igual ao comprimento de s3, o interleaving é impossível
    if (m + n != s3.length())
        return false;

    // dp[j] = é possível formar os primeiros i+j caracteres de s3 com os primeiros i caracteres de s1 e os primeiros j caracteres de s2
    // Ao sobrescrever o array unidimensional a cada linha, a complexidade espacial da tabela bidimensional é reduzida para O(n)
    boolean[] dp = new boolean[n + 1];

    // Loop externo: i representa o número de caracteres tomados de s1 (0 a m)
    for (int i = 0; i <= m; i++) {
        // Loop interno: j representa o número de caracteres tomados de s2 (0 a n)
        for (int j = 0; j <= n; j++) {
            if (i == 0 && j == 0) {
                // Caso base: nenhum caractere foi tomado de nenhuma das strings, correspondendo à string vazia de s3
                dp[j] = true;
            } else {
                // Condição 1 (tomar de s1): o valor de dp[j] antes da atualização (linha anterior = corresponde a dp[i-1][j]) é true
                //   e o i-ésimo caractere de s1 coincide com o (i+j)-ésimo caractere de s3
                // Condição 2 (tomar de s2): o valor de dp[j-1] após a atualização (célula à esquerda na linha atual = corresponde a dp[i][j-1]) é true
                //   e o j-ésimo caractere de s2 coincide com o (i+j)-ésimo caractere de s3
                // Nota: como o loop interno percorre j da esquerda para a direita, dp[j] ainda não foi sobrescrito e mantém o valor da linha anterior,
                //   enquanto dp[j-1] já foi sobrescrito e contém o valor da linha atual
                dp[j] =
                    (dp[j] && i > 0
                    && s1.charAt(i - 1)
                    == s3.charAt(i + j - 1))
                    || (j > 0
                    && dp[j - 1]
                    && s2.charAt(j - 1)
                    == s3.charAt(i + j - 1));
            }
        }
    }

    // dp[n] contém o resultado de se todos os m caracteres de s1 e todos os n caracteres de s2 podem formar todos os m+n caracteres de s3
    return dp[n];
}
```
