# Counting Distinct Subsequences — Contar quantas subsequências da string s coincidem com t

## Essência do problema

Duas strings `s` e `t` são fornecidas. O objetivo é contar de quantas maneiras é possível deletar zero ou mais caracteres de `s` (mantendo a ordem relativa dos caracteres restantes) para formar uma subsequência que coincida com `t`.

## Ideia central

Para cada caractere de `s`, existe uma escolha binária: "usar ou não usar para o casamento com `t`". A acumulação dessas escolhas é gerenciada em um array unidimensional, e ao atualizá-lo de trás para frente, a soma dos casos "usar" e "não usar" é calculada corretamente.

## Processo de raciocínio

1. **O casamento de subsequências é uma acumulação de escolhas**: Quando o i-ésimo caractere de `s` coincide com o j-ésimo caractere de `t`, existem duas opções: "usar esse caractere para o casamento com `t[j]`" ou "ignorá-lo e pular". A soma das contagens de ambos os casos fornece o total de padrões
2. **Definir o estado do DP**: Define-se `dp[j]` como "o número de subsequências de `s` que coincidem com os primeiros j caracteres de `t`". No final, `dp[n]` (onde n é o comprimento de `t`) será a resposta
3. **Considerar o caso base**: A subsequência que coincide com os primeiros 0 caracteres de `t` (string vazia) existe exatamente de uma maneira para qualquer `s`: "não selecionar nenhum caractere". Portanto, `dp[0] = 1`
4. **Derivar a fórmula de transição**: Quando `s[i-1] == t[j-1]`, `dp[j]` recebe duas contribuições. O caso "não usar `s[i-1]`" mantém o valor existente de `dp[j]`, e o caso "usar `s[i-1]`" adiciona `dp[j-1]` (a contagem de casamentos até o caractere anterior). Portanto, `dp[j] += dp[j-1]`. Quando os caracteres não coincidem, `dp[j]` permanece inalterado (a única opção é pular)
5. **Razão para atualizar na ordem inversa**: Na expressão `dp[j] += dp[j-1]`, o valor de `dp[j-1]` antes da atualização é necessário. Se j for atualizado do menor para o maior, `dp[j-1]` será sobrescrito antes de ser usado e o valor antigo será perdido. Atualizando j do maior para o menor (ordem inversa), `dp[j-1]` ainda mantém o valor da iteração anterior, permitindo o cálculo correto
6. **Valor final a retornar**: Após percorrer todos os caracteres de `s`, `dp[n]` contém a resposta de quantas subsequências de `s` coincidem com `t`

## Conhecimentos prévios

### O que é uma Subsequência (Subsequence)

Uma string formada pela exclusão de zero ou mais caracteres da string original, mantendo a ordem relativa dos caracteres restantes. Diferente de uma substring, os caracteres não precisam ser contíguos.

```
s = "rabbbit", t = "rabbit"
Exemplo de subsequência: selecionar os caracteres 1,2,3,5,6,7 de s → "rabbit" ✓
Exemplo de subsequência: selecionar os caracteres 1,2,4,5,6,7 de s → "rabbit" ✓
Exemplo de subsequência: selecionar os caracteres 1,3,4,5,6,7 de s → "rabbit" ✓
→ Total de 3 maneiras
```

### O que é a atualização em ordem inversa no DP unidimensional

Uma técnica que comprime a tabela de DP bidimensional `dp[i][j]` em um array unidimensional `dp[j]`. Quando o cálculo da linha atual requer apenas os valores da linha anterior, é possível reutilizar um array unidimensional para reduzir a complexidade espacial. Porém, quando a atualização de `dp[j]` requer `dp[j-1]` (valor da linha anterior), atualizar j em ordem crescente faz com que `dp[j-1]` seja sobrescrito com o valor da linha atual. Atualizando j em ordem decrescente (do maior para o menor), o valor de `dp[j-1]` da linha anterior ainda não foi sobrescrito e pode ser referenciado corretamente.

```java
// DP bidimensional (forma original)
dp[i][j] = dp[i-1][j] + dp[i-1][j-1];

// Compressão para DP unidimensional (atualização em ordem inversa)
for (int j = n; j >= 1; j--) {   // Atualizar do maior para o menor
    dp[j] += dp[j - 1];          // dp[j-1] ainda mantém o valor da linha anterior
}
```

## Complexidade

| | Valor |
|---|---|
| Time | O(m × n) — Para cada caractere de s (m caracteres), percorre-se cada caractere de t (n caracteres) |
| Space | O(n) — Utiliza-se apenas um array unidimensional de comprimento n+1 |

## Código

```java
// Entrada: string s (comprimento m) e string t (comprimento n)
// Saída: retorna como int a quantidade de subsequências de s que coincidem com t
public int numDistinct(String s, String t) {
    int m = s.length();
    int n = t.length();

    // dp[j] = número de subsequências de s que coincidem com os primeiros j caracteres de t
    // Gerencia n+1 estados com índices de 0 a n, por isso o tamanho é n+1
    int[] dp = new int[n + 1];

    // A subsequência que coincide com a string vazia é sempre 1 (não selecionar nenhum caractere)
    // Este caso base é válido independentemente de qual posição de s se inicia
    dp[0] = 1;

    // Considerar cada caractere de s em ordem (i representa quantos caracteres de s foram considerados)
    for (int i = 1; i <= m; i++) {
        // Percorrer j na ordem inversa (do maior para o menor)
        // Razão: no cálculo dp[j] += dp[j-1], é necessário referenciar dp[j-1] antes da atualização
        // Se atualizado em ordem crescente, dp[j-1] seria sobrescrito primeiro e o valor da linha anterior seria perdido
        for (int j = n; j >= 1; j--) {
            // i e j começam em 1, mas os índices da string começam em 0, então acessa-se com i-1 e j-1
            if (s.charAt(i - 1) == t.charAt(j - 1))
                // Caso coincidam: soma dp[j-1] (contagem do caso "usar") a dp[j] (contagem do caso "não usar")
                // Esta soma acumula em dp[j] o total de ambas as opções: "usar" e "não usar"
                dp[j] += dp[j - 1];
            // Caso não coincidam: nada é feito (s[i-1] não pode ser usado para casar com t[j-1], então a única opção é pular)
        }
    }

    // dp[n] armazena a quantidade de subsequências em todo s que coincidem com todo t
    return dp[n];
}
```
