# Partitioning a String Into Palindrome Substrings — Encontrar todos os padrões de partição de uma string em substrings palíndromos

## Essência do Problema

Uma string `s` é fornecida. O objetivo é particionar `s` de modo que todas as substrings resultantes sejam palíndromos (strings que são iguais lidas da esquerda para a direita e da direita para a esquerda), enumerar **todos** os padrões de partição possíveis e retorná-los como uma lista de listas.

## Ideia Central

Preparamos uma tabela DP que permite verificar em O(1) se qualquer substring é um palíndromo, e então utilizamos backtracking para extrair sequencialmente desde o início as "partes que são palíndromos" e recursar, enumerando eficientemente todos os padrões de partição.

## Processo de Raciocínio

1. **O problema de partição pode ser expresso como recursão que extrai sequencialmente desde o início**: A partir da posição inicial `start` até o final da string, extraímos uma substring de `start` até `end` e processamos recursivamente o restante. Quando `start` atinge o final da string, uma partição válida está completa
2. **A condição para extração é "essa parte ser um palíndromo"**: Como todas as substrings precisam ser palíndromos, só extraímos e adicionamos ao caminho quando `s[start..end]` é um palíndromo, e então avançamos a recursão. Se não for palíndromo, ignoramos essa forma de extração
3. **Verificar palíndromos em O(n) a cada vez é desperdício**: Em cada passo do backtracking verificamos se uma substring é palíndromo, mas a mesma substring pode ser verificada múltiplas vezes. Com pré-computação em uma tabela DP, podemos reduzir a verificação de palíndromo de qualquer `s[l..r]` para O(1)
4. **Método de construção da tabela DP**: `dp[l][r]` representa um boolean indicando "se a substring do índice `l` até `r` de `s` é um palíndromo". A condição de palíndromo é "os caracteres nas extremidades são iguais" e "a substring interna também é um palíndromo". Comprimento 1 (`l == r`) é sempre palíndromo, comprimento 2 (`r - l == 1`) é palíndromo se as extremidades forem iguais, comprimento 3 ou mais é palíndromo se `s[l] == s[r]` e `dp[l+1][r-1]` for true
5. **Estrutura do backtracking**: A partir da posição atual `start`, estendemos `end` de `start` até `s.length()-1` uma posição por vez, e se `dp[start][end]` for true, adicionamos a substring ao caminho e recursamos a partir de `end+1`. Ao retornar da recursão, removemos o último elemento do caminho para tentar outra forma de extração
6. **O que retornamos no final**: Cada vez que `start` atinge `s.length()`, adicionamos uma cópia do caminho atual à lista de resultados. Quando toda a recursão termina, retornamos a lista de resultados

## Conhecimentos Prévios

### O que é um Palíndromo (Palindrome)

É uma string que é igual lida da esquerda para a direita e da direita para a esquerda. Por exemplo, `"aba"`, `"aa"`, `"a"` são palíndromos. `"ab"` não é um palíndromo.

### Tabela DP de Palíndromos com Array Booleano Bidimensional

Uma tabela que permite verificar em O(1) "se a substring do índice `l` até `r` é um palíndromo" usando `dp[l][r]`. É construída fixando a extremidade direita `r` no loop externo e movendo a extremidade esquerda `l` de `0` até `r` no loop interno.

```java
boolean[][] dp = new boolean[n][n];
for (int r = 0; r < n; r++) {
    for (int l = 0; l <= r; l++) {
        // Se as extremidades são o mesmo caractere e o interior é palíndromo (ou comprimento ≤ 2), é palíndromo
        if (s.charAt(l) == s.charAt(r) && (r - l < 2 || dp[l + 1][r - 1])) {
            dp[l][r] = true;
        }
    }
}
dp[0][2];  // Se s[0] até s[2] é palíndromo → true ou false
```

### O que é Backtracking

É uma técnica de busca que escolhe uma opção e avança recursivamente, e quando a condição não é mais satisfeita, desfaz a escolha anterior e tenta outra opção. É composta por 3 passos: adição ao caminho (escolha) → recursão → remoção do caminho (desfazer).

```java
path.add(choice);                    // Faz a escolha
backtrack(nextState, path, result);  // Avança recursivamente
path.remove(path.size() - 1);       // Desfaz a escolha para tentar outro caminho
```

### Método substring

`String.substring(start, end)` retorna a substring do índice `start` até `end - 1`. Note que `end` não está incluído.

```java
String s = "aab";
s.substring(0, 1);  // "a"
s.substring(0, 2);  // "aa"
s.substring(0, 3);  // "aab"
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n × 2^n) — A construção da tabela DP custa O(n^2), o backtracking enumera no máximo 2^(n-1) partições e cada partição custa O(n) para copiar as substrings |
| Space | O(n^2) — A tabela DP utiliza um array booleano n×n. A profundidade máxima da pilha de recursão é O(n) |

## Código

```java
// Entrada: string s
// Saída: List<List<String>> contendo todos os padrões de partição em palíndromos de s
List<List<String>> partition(String s) {
    int n = s.length();

    // dp[l][r] = tabela DP que indica se a substring de s[l] até s[r] é um palíndromo
    boolean[][] dp = new boolean[n][n];
    // O loop externo fixa a extremidade direita r, e o loop interno percorre a extremidade esquerda l de 0 até r
    for (int r = 0; r < n; r++) {
        for (int l = 0; l <= r; l++) {
            // Se as extremidades são o mesmo caractere e o interior é palíndromo (ou comprimento ≤ 2), é palíndromo
            // Condição r - l < 2: comprimento 1 é sempre palíndromo, comprimento 2 é palíndromo se as extremidades forem iguais
            if (s.charAt(l) == s.charAt(r)
                && (r - l < 2
                || dp[l + 1][r - 1])) {
                dp[l][r] = true;
            }
        }
    }

    // Lista de resultados que armazena todos os padrões de partição
    List<List<String>> res = new ArrayList<>();
    // Inicia o backtracking com posição inicial 0 e caminho vazio
    bt(s, 0, new ArrayList<>(), res, dp);
    return res;
}

void bt(String s, int start,
    List<String> path,
    List<List<String>> res,
    boolean[][] dp) {
    // Atingiu o final da string → a string inteira foi particionada em substrings palíndromos
    if (start == s.length()) {
        // Como path será modificado depois, adicionamos uma cópia
        res.add(new ArrayList<>(path));
        return;
    }

    // Tenta substrings de start até end sequencialmente
    for (int end = start; end < s.length();
        end++) {
        // Verifica se é palíndromo em O(1) usando a tabela DP
        if (dp[start][end]) {
            // Adiciona a parte palíndroma ao caminho e recursa
            // O segundo argumento de substring é exclusivo, então especificamos end + 1
            path.add(
                s.substring(start, end + 1));
            // A próxima posição inicial é end + 1 (logo após a parte extraída)
            bt(s, end + 1, path, res, dp);
            // Desfaz a escolha para tentar outra forma de extração (backtrack)
            path.remove(path.size() - 1);
        }
    }
}
```
