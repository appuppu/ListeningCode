# Searching for a Word in a Grid — Determinar se é possível formar uma palavra percorrendo caracteres em um grid

## Essência do Problema

Um grid 2D de caracteres `board` e uma string `word` são fornecidos. O objetivo é determinar se é possível formar `word` percorrendo células adjacentes (cima, baixo, esquerda, direita) sequencialmente no grid, retornando um `boolean`. Cada célula pode ser usada apenas uma vez por caminho.

## Ideia Central

O algoritmo executa DFS a partir de cada célula do grid, verificando caractere por caractere da palavra. Em vez de gerenciar células visitadas com um array separado, o algoritmo sobrescreve diretamente a célula do grid com um caractere especial e restaura o valor original após a exploração, reduzindo a complexidade de espaço apenas à profundidade da pilha de recursão.

## Processo de Raciocínio

1. **Qualquer célula pode ser o ponto de partida**: Como a posição inicial da palavra pode ser qualquer célula do grid, é necessário testar todas as células como candidatas a ponto de partida
2. **Verificar caractere por caractere sequencialmente**: O algoritmo verifica se o caractere da célula atual corresponde ao caractere na posição atual de `word`, e se corresponder, explora recursivamente as células adjacentes nas quatro direções. Essa estrutura é exatamente uma DFS (busca em profundidade)
3. **Prevenir a reutilização da mesma célula**: Como a mesma célula não pode ser usada duas vezes em um único caminho, é necessário gerenciar as células visitadas. Uma abordagem seria manter um array de visitação `boolean[][]`, mas isso consome espaço adicional
4. **Modificar diretamente o grid para representar células visitadas**: Ao entrar na exploração, sobrescrever o caractere da célula atual com `'#'` ou outro caractere especial que não existe no grid impede que a mesma célula seja correspondida nas chamadas recursivas. Isso elimina a necessidade de um array de visitação, reduzindo a complexidade de espaço para apenas O(L), a profundidade da pilha de recursão
5. **Restaurar o caractere original após a exploração**: No retorno da DFS, o algoritmo restaura o `'#'` sobrescrito para o caractere original (backtracking). Isso permite que outras explorações a partir de diferentes pontos de partida utilizem a mesma célula corretamente
6. **Organizar as condições de término da exploração**: Quando o índice `idx` atinge `word.length()`, todos os caracteres foram correspondidos com sucesso e o algoritmo retorna `true`. Se estiver fora dos limites ou se o caractere não corresponder, retorna `false`. Se qualquer uma das quatro direções retornar `true`, o algoritmo retorna `true` naquele ponto

## Conhecimentos Prévios

### O que é DFS (Busca em Profundidade)

É uma técnica de exploração de grafos ou grids. O algoritmo avança em uma direção o máximo possível e, ao atingir um beco sem saída, retrocede uma posição e tenta outra direção. Pode ser implementado naturalmente com chamadas recursivas.

```java
void dfs(int node) {
    // Processar o nó
    for (int neighbor : getNeighbors(node)) {
        dfs(neighbor);  // Avançar recursivamente para o nó adjacente
    }
}
```

### O que é Backtracking

É uma técnica que desfaz as alterações realizadas durante a exploração ao retornar dela. O ciclo "tentar → avançar → desfazer" permite explorar todos os candidatos sem omissões.

```java
board[r][c] = '#';   // Modificar (marcar como visitado)
dfs(...);            // Avançar a exploração recursivamente
board[r][c] = temp;  // Restaurar (marcar como não visitado)
```

### O que é charAt

É um método que retorna o caractere na posição especificada de uma `String` como tipo `char`. O índice começa em 0.

```java
String word = "ABCCED";
word.charAt(0);   // Retorna 'A'
word.charAt(3);   // Retorna 'C'
word.length();    // Retorna 6 (retorna o número de caracteres)
```

### Exploração em 4 direções em um grid 2D

Para explorar células adjacentes nas direções cima, baixo, esquerda e direita em um grid 2D, o algoritmo tenta 4 combinações de ±1 na linha e na coluna.

```java
// Explorar na ordem: cima, baixo, esquerda, direita
dfs(board, word, r-1, c, idx+1);  // Cima (linha -1)
dfs(board, word, r+1, c, idx+1);  // Baixo (linha +1)
dfs(board, word, r, c-1, idx+1);  // Esquerda (coluna -1)
dfs(board, word, r, c+1, idx+1);  // Direita (coluna +1)
```

## Complexidade

| | Valor |
|---|---|
| Time | O(m × n × 4^L) — Explora a partir de todas as células, com no máximo 4 direções para L caracteres a partir de cada ponto de partida (m×n é o tamanho do grid, L é o comprimento da palavra) |
| Space | O(L) — A profundidade máxima da pilha de recursão é L. Não é necessário um array de visitação pois o grid é modificado diretamente |

## Código

```java
// Entrada: array 2D de caracteres board e string word
// Saída: retorna true se word puder ser formada por células adjacentes no grid, false caso contrário

// DFS que tenta corresponder word[idx] em diante a partir da posição (r,c)
boolean dfs(char[][] board, String word, int r, int c, int idx) {
    // Se idx for igual a word.length(), todos os caracteres foram correspondidos, então retorna true
    if (idx == word.length()) return true;

    // Se r ou c estiver fora dos limites do grid, ou se board[r][c] não corresponder a word.charAt(idx), retorna false
    if (r < 0 || r >= board.length
        || c < 0 || c >= board[0].length
        || board[r][c] != word.charAt(idx))
        return false;

    // Salvar o caractere da célula atual na variável temp e sobrescrever com '#' para prevenir revisitação
    // Como '#' não corresponde a nenhuma letra, isso impede que esta célula seja correspondida novamente nas chamadas recursivas (substitui o array de visitação)
    char temp = board[r][c];
    board[r][c] = '#';

    // Explorar recursivamente nas 4 direções (cima, baixo, esquerda, direita) — sucesso se qualquer uma retornar true
    // Devido à avaliação de curto-circuito do ||, a exploração das direções restantes é omitida assim que true é encontrado
    boolean found =
        dfs(board, word, r - 1, c, idx + 1)
     || dfs(board, word, r + 1, c, idx + 1)
     || dfs(board, word, r, c - 1, idx + 1)
     || dfs(board, word, r, c + 1, idx + 1);

    // Restaurar o caractere original independentemente do resultado da exploração (backtracking)
    // Isso retorna a célula ao estado correto para que explorações a partir de outros pontos de partida ou caminhos possam utilizá-la
    board[r][c] = temp;
    return found;
}

boolean exist(char[][] board, String word) {
    int m = board.length;
    int n = board[0].length;

    // Percorrer todas as células (i,j) do grid com um laço duplo e chamar DFS a partir de cada célula como ponto de partida
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            // Retornar true assim que dfs retornar true
            if (dfs(board, word, i, j, 0))
                return true;

    // Retornar false se nenhuma célula produzir um resultado positivo
    return false;
}
```
