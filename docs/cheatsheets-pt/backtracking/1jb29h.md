# Generating All Valid Parentheses Combinations — Gerar todas as combinações válidas de n pares de parênteses

## Essência do problema

Um inteiro `n` é fornecido. Utilizando `n` parênteses de abertura `(` e `n` parênteses de fechamento `)`, o objetivo é gerar **todas** as strings de parênteses corretamente aninhadas e retorná-las em uma lista. Cada string tem comprimento `2 * n`, e em qualquer posição, o total acumulado de parênteses de fechamento não deve exceder o total acumulado de parênteses de abertura.

## Ideia central

Ao construir a string caractere por caractere, apenas dois estados — "número restante de parênteses de abertura" e "número restante de parênteses de fechamento" — determinam qual caractere pode ser colocado a seguir. Um parêntese de abertura pode ser adicionado se menos de `n` foram utilizados, e um parêntese de fechamento pode ser adicionado somente quando a sua quantidade é menor que a de parênteses de abertura. Ao podar as ramificações com essas condições, é possível enumerar todas as combinações válidas sem gerar nenhuma string inválida.

## Processo de raciocínio

1. **É necessário enumerar todas as combinações**: O problema pede "gerar todas", portanto é necessária uma abordagem de busca que enumere todos os padrões. O backtracking, que constrói a string caractere por caractere ramificando em cada passo, é adequado para isso
2. **Em cada passo, existem apenas duas opções**: Os únicos caracteres que podem ser colocados em cada posição da string são `(` ou `)`. Repetindo essa escolha binária recursivamente, é possível explorar todos os candidatos
3. **Deseja-se interromper ramificações inválidas antecipadamente**: Testar todas as escolhas binárias resultaria em `2^(2n)` combinações, mas a maioria é inválida. As condições de validade são duas: não é possível usar mais de `n` parênteses de abertura, e o número de parênteses de fechamento não pode exceder o número de parênteses de abertura naquele momento. Essas duas condições são usadas para podar as ramificações
4. **O estado pode ser gerenciado com duas variáveis**: `open` (número de parênteses de abertura utilizados) e `close` (número de parênteses de fechamento utilizados) são passados à função recursiva. Se `open < n`, é possível adicionar `(`; se `close < open`, é possível adicionar `)`
5. **A string está completa quando seu comprimento atinge `2 * n`**: Uma string construída respeitando as condições de `open` e `close` que atinge `2 * n` caracteres é necessariamente válida. Ela é adicionada à lista de resultados
6. **O backtracking restaura o estado**: Após adicionar um caractere ao `StringBuilder` e fazer a chamada recursiva, o caractere final é removido com `deleteCharAt` para restaurar o estado original. Dessa forma, uma única instância de `StringBuilder` é compartilhada entre todos os caminhos de busca

## Conhecimentos prévios

### O que é backtracking

O backtracking é uma técnica de busca que repete o ciclo de escolher → recursão → desfazer para enumerar todas as combinações válidas. Em cada passo, uma opção é selecionada dentre as alternativas disponíveis e a recursão avança para o próximo passo. Ao retornar da recursão, a escolha é desfeita (backtrack) e outra alternativa é testada. Adicionando condições de poda, caminhos inválidos podem ser interrompidos antecipadamente.

```java
// Padrão básico de backtracking
void backtrack(estado) {
    if (condição de término) {
        adicionar ao resultado;
        return;
    }
    for (cada alternativa) {
        aplicar a escolha;        // Ex: sb.append('(')
        backtrack(próximo estado);
        desfazer a escolha;       // Ex: sb.deleteCharAt(sb.length() - 1)
    }
}
```

### O que é StringBuilder

StringBuilder é uma classe para construir strings de forma eficiente. Como `String` é imutável (immutable), um novo objeto é criado cada vez que um caractere é adicionado. O `StringBuilder`, por outro lado, opera diretamente sobre um buffer interno, permitindo adições e remoções em O(1).

```java
StringBuilder sb = new StringBuilder();  // Cria um StringBuilder vazio
sb.append('(');          // Adiciona um caractere ao final → "("
sb.append(')');          // Adiciona um caractere ao final → "()"
sb.length();             // Retorna o número atual de caracteres → 2
sb.deleteCharAt(1);      // Remove o caractere no índice 1 → "("
sb.toString();           // Converte para o tipo String e retorna → "("
```

### Condições de validade dos parênteses

Uma string de parênteses é considerada "válida" quando satisfaz as duas condições a seguir:
- **Condição 1**: O número de parênteses de abertura e de fechamento é igual
- **Condição 2**: Em qualquer posição da string, o número de parênteses de fechamento do início até essa posição não excede o número de parênteses de abertura

Exemplo: quando `n=2`, `(())` e `()()` são válidas. `)()(` viola a condição 2, e `((()` viola a condição 1.

## Complexidade

| | Valor |
|---|---|
| Time | O(4^n / √n) — O número de strings de parênteses válidas geradas é o número de Catalan C(n) = C(2n,n)/(n+1), que é assintoticamente O(4^n / (n√n)). Como a construção de cada string custa O(n), o total é O(4^n / √n) |
| Space | O(n) — A profundidade máxima da recursão é 2n, e o comprimento máximo do StringBuilder também é 2n. Excluindo a lista de resultados, o espaço utilizado é O(n) |

## Código

```java
// Entrada: inteiro n (número de pares de parênteses)
// Saída: retorna uma List<String> contendo todas as strings de parênteses válidas
private void backtrack(StringBuilder sb, int open, int close, int n, List<String> res) {
    // Quando o comprimento da string atinge 2n, exatamente n parênteses de abertura e n de fechamento foram utilizados, completando uma string de parênteses válida
    if (sb.length() == 2 * n) {
        res.add(sb.toString());
        return;
    }
    // Se nenhuma das condições abaixo for satisfeita, não é possível adicionar mais caracteres, então retorna sem fazer nada e o backtracking prossegue no chamador

    // Se o número de parênteses de abertura é menor que n, ainda é possível adicionar um parêntese de abertura
    if (open < n) {
        sb.append('(');
        backtrack(sb, open + 1, close, n, res);
        // Essência do backtracking: remove o '(' do final para restaurar o estado e testar a próxima ramificação (adição de parêntese de fechamento) no estado correto
        sb.deleteCharAt(sb.length() - 1);
    }

    // Atenção: o ponto importante é que a condição é close < open, e não close < n
    // Com close < n, casos em que parênteses de fechamento excedem os de abertura (ex: ")(") seriam permitidos,
    // mas com close < open, o número de parênteses de fechamento é sempre mantido menor ou igual ao de abertura, evitando a geração de strings inválidas
    if (close < open) {
        sb.append(')');
        backtrack(sb, open, close + 1, n, res);
        sb.deleteCharAt(sb.length() - 1);  // Restaura o estado
    }
}

public List<String> generateParenthesis(int n) {
    // Lista para armazenar todas as strings de parênteses válidas
    List<String> res = new ArrayList<>();
    // Inicia a busca com um StringBuilder vazio e open=0, close=0
    backtrack(new StringBuilder(), 0, 0, n, res);
    return res;
}
```
