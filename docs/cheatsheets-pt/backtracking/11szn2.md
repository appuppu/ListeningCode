# Finding Combinations That Sum to a Target — Encontrar todas as combinações de números cuja soma é igual ao alvo

## Essência do problema

Dado um array de inteiros positivos `candidates` (todos os elementos são distintos) e um inteiro positivo `target`, encontre e retorne todas as combinações de elementos de `candidates` cuja soma é igual a `target`. O mesmo número pode ser **reutilizado quantas vezes quiser**. Combinações que diferem apenas na ordem são consideradas duplicatas.

## Ideia central

Se os candidatos forem ordenados previamente, em cada etapa da recursão é possível determinar que "se o candidato atual excede o alvo restante, todos os candidatos seguintes também o excedem", permitindo cortar ramos inteiros de exploração desnecessária. Essa poda permite enumerar todas as combinações de forma eficiente.

## Processo de raciocínio

1. **Backtracking é adequado para enumerar todas as combinações**: Problemas do tipo "encontre todos os padrões que satisfazem uma condição" podem ser resolvidos com exploração recursiva (backtracking), onde se escolhe um candidato por vez, e se retrocede caso não funcione
2. **Controlar a posição inicial do índice evita duplicatas**: O mesmo número pode ser usado várias vezes, mas `[2,3]` e `[3,2]` não devem ser contados como combinações diferentes. Se em cada etapa da recursão apenas candidatos na posição atual ou posterior forem escolhidos, somente combinações em ordem crescente serão geradas, evitando duplicatas
3. **Gerenciar o progresso pelo alvo restante (remain)**: Subtraindo os números escolhidos de `target`, quando `remain` chega a 0 significa que a soma é igual a `target`. Quando `remain` fica negativo significa que a soma excedeu o alvo
4. **A ordenação permite a poda**: Se os candidatos estiverem ordenados em ordem crescente, quando um candidato `cands[i]` excede `remain`, todos os `cands[i+1]` em diante são ainda maiores e não precisam ser testados. O loop pode ser interrompido nesse ponto
5. **Gerenciar a combinação atual com uma lista, repetindo seleção e cancelamento**: Adiciona-se um elemento ao final, faz-se a recursão, e ao retornar remove-se o último elemento. Esse padrão "adicionar → recursar → remover" é a operação básica do backtracking
6. **Quando remain chega a 0, adicionar uma cópia da combinação atual ao resultado**: Se a referência for salva em vez de uma cópia, operações subsequentes alterarão o conteúdo

## Conhecimentos prévios

### O que é backtracking

É uma técnica de busca que constrói candidatos a solução de forma incremental e, ao perceber que uma condição não é satisfeita, retorna ao estado anterior para tentar outro candidato. É implementado com funções recursivas, repetindo "selecionar → recursar → cancelar a seleção" para enumerar todos os padrões.

### O que é Arrays.sort

É um método que ordena um array em ordem crescente. Em arrays ordenados, é possível realizar poda aproveitando a propriedade de que "se o valor atual excede a condição, todos os valores seguintes também a excedem".

```java
int[] cands = {3, 1, 2};
Arrays.sort(cands);       // cands se torna {1, 2, 3}
```

### Operações de ArrayList

Lista de tamanho variável. Permite adição, remoção e cópia de elementos. No backtracking, é usada para gerenciar a combinação atual.

```java
List<Integer> curr = new ArrayList<>();
curr.add(2);                          // Adiciona 2 ao final → [2]
curr.add(3);                          // Adiciona 3 ao final → [2, 3]
curr.remove(curr.size() - 1);         // Remove o último → [2] (backtrack)
new ArrayList<>(curr);                // Cria uma cópia de curr (para salvar no resultado)
```

### O que é List\<List\<Integer\>\>

É um tipo que representa "uma lista de listas de inteiros". É usado para armazenar múltiplas combinações. Cada combinação é um `List<Integer>`, e o conjunto dessas combinações é um `List<List<Integer>>`.

```java
List<List<Integer>> res = new ArrayList<>();  // Cria uma lista de resultados vazia
res.add(new ArrayList<>(curr));               // Adiciona uma cópia da combinação ao resultado
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n^(target/min)) — n é o número de candidatos, min é o menor valor entre os candidatos. No pior caso, a ramificação de escolher o menor valor target/min vezes ocorre para cada candidato |
| Space | O(target/min) — A profundidade da recursão é no máximo target/min. O número de elementos em uma combinação também é no máximo target/min |

## Código

```java
// Entrada: array de inteiros positivos candidates (todos os elementos são distintos) e um inteiro positivo target
// Saída: retorna todas as combinações cuja soma é igual a target como List<List<Integer>>
public List<List<Integer>> combinationSum(int[] cands, int target) {
    // A ordenação crescente permite a condição de poda "se cands[i] > remain, todos os seguintes também excedem"
    Arrays.sort(cands);
    // Lista para armazenar os resultados
    List<List<Integer>> res = new ArrayList<>();
    // Inicia o backtracking (restante=target, posição inicial=0, combinação atual=vazia)
    backtrack(cands, target, 0, new ArrayList<>(), res);
    return res;
}

// remain: o restante após subtrair os números escolhidos até agora de target. Quando chega a 0, a soma é igual a target
// start: posição inicial da busca. Escolher apenas candidatos na posição atual ou posterior evita duplicatas (diferença de ordem)
// curr: combinação em construção. Repete seleção e cancelamento para explorar todos os padrões
void backtrack(int[] cands, int remain, int start,
               List<Integer> curr, List<List<Integer>> res) {
    // Se remain é 0, a soma é igual a target → adiciona a combinação atual ao resultado
    if (remain == 0) {
        // Cria e salva uma cópia. Se salvar a referência diretamente, operações subsequentes alterarão o conteúdo
        res.add(new ArrayList<>(curr));
        return;
    }
    // Percorre a partir de start; se cands[i] > remain, como está ordenado, todos os seguintes também excedem → interrompe o loop (poda)
    for (int i = start; i < cands.length && cands[i] <= remain; i++) {
        // Adiciona o candidato atual ao final da combinação
        curr.add(cands[i]);
        // Passa i (não i+1) como terceiro argumento, permitindo escolher o mesmo número repetidamente
        backtrack(cands, remain - cands[i], i, curr, res);
        // Ao retornar da recursão, cancela o elemento adicionado (backtrack). Prepara para tentar o próximo candidato
        curr.remove(curr.size() - 1);
    }
}
```
