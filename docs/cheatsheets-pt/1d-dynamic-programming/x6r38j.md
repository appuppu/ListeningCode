# Counting Ways to Climb Stairs — Encontrar o número total de maneiras de subir uma escada de n degraus, subindo 1 ou 2 degraus por vez

## Essência do Problema

Um inteiro `n` (número de degraus da escada) é fornecido. Quando é possível subir 1 ou 2 degraus por vez, o programa deve retornar o **número total de maneiras distintas** de alcançar o topo (degrau n).

## Ideia Central

Para alcançar o degrau n, existem apenas duas possibilidades: "subir 1 degrau a partir do degrau n-1" ou "subir 2 degraus a partir do degrau n-2". Ou seja, a relação de recorrência `ways(n) = ways(n-1) + ways(n-2)` é equivalente à sequência de Fibonacci. Mantendo apenas os dois valores anteriores, é possível calcular com espaço O(1) sem utilizar um array.

## Processo de Raciocínio

1. **Raciocinar de trás para frente a partir do último passo**: O estado imediatamente antes de alcançar o degrau n é apenas "estar no degrau n-1" ou "estar no degrau n-2". Portanto, o número total de maneiras de alcançar o degrau n pode ser expresso pela relação de recorrência `ways(n) = ways(n-1) + ways(n-2)`
2. **Definir os casos base**: Uma escada de 1 degrau tem 1 maneira (subir 1 degrau), e uma escada de 2 degraus tem 2 maneiras (1+1 ou 2). Esses dois valores são o ponto de partida da relação de recorrência
3. **Calcular de baixo para cima (bottom-up)**: Se o cálculo for feito de cima para baixo com recursão, os mesmos subproblemas serão resolvidos repetidamente. Em vez disso, adotando a abordagem bottom-up, que calcula sequencialmente a partir dos valores menores, cada valor precisa ser calculado apenas uma vez
4. **Apenas 2 variáveis são necessárias**: A relação de recorrência `ways(i) = ways(i-1) + ways(i-2)` referencia apenas os dois valores anteriores. Não é necessário manter o array inteiro; duas variáveis (`prev2` e `prev1`) são suficientes
5. **Atualizar as variáveis no loop**: De `i = 3` até `n`, o valor atual é calculado com `curr = prev1 + prev2`, e as variáveis são deslizadas com `prev2 = prev1` e `prev1 = curr` para preparar a próxima iteração
6. **O que retornar no final**: Após o término do loop, `prev1` contém o número total de maneiras de subir até o degrau n, então `prev1` é retornado

## Conhecimentos Prévios

### O que é Programação Dinâmica (Dynamic Programming)

A programação dinâmica é uma técnica que divide um problema grande em subproblemas menores e os resolve registrando o resultado de cada subproblema. A eficiência é obtida ao não repetir os mesmos cálculos. Na abordagem bottom-up, os subproblemas são resolvidos sequencialmente a partir do menor.

```java
// Padrão básico de DP bottom-up (versão com array)
int[] dp = new int[n + 1];   // Array para armazenar os resultados dos subproblemas
dp[1] = 1;                    // Caso base 1
dp[2] = 2;                    // Caso base 2
for (int i = 3; i <= n; i++) {
    dp[i] = dp[i - 1] + dp[i - 2];  // Calcular usando a relação de recorrência
}
// dp[n] é a resposta final
```

### O que são Variáveis Deslizantes

É uma técnica que mantém os valores anteriores usando apenas 2 variáveis em vez de um array. Quando a relação de recorrência referencia um número fixo de valores passados, não é necessário manter o array inteiro, e a complexidade de espaço pode ser reduzida de O(n) para O(1).

```java
int prev2 = 1;  // Variável que mantém o valor de 2 posições anteriores
int prev1 = 2;  // Variável que mantém o valor de 1 posição anterior
int curr = prev1 + prev2;  // Calcular o valor atual
prev2 = prev1;  // Deslizar prev2 (herdar o valor de prev1)
prev1 = curr;   // Deslizar prev1 (herdar o valor de curr)
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Basta executar um único loop de 3 até n |
| Space | O(1) — Utiliza apenas 2 variáveis (prev2, prev1) |

## Código

```java
// Entrada: inteiro n (número de degraus da escada)
// Saída: retorna o número total de maneiras distintas de alcançar o topo como int
public int climbStairs(int n) {
    // Caso base: se há 1 degrau, existe apenas 1 maneira. Como o loop subsequente começa em i=3, o caso n=1 é tratado primeiro
    if (n == 1) return 1;

    // prev2 é o número total de maneiras para o degrau 2 posições antes. O valor inicial corresponde às maneiras para o degrau 1 (1 maneira)
    int prev2 = 1;
    // prev1 é o número total de maneiras para o degrau 1 posição antes. O valor inicial corresponde às maneiras para o degrau 2 (2 maneiras: 1+1 ou 2)
    int prev1 = 2;

    // i é o degrau sendo calculado atualmente. Como os degraus 1 e 2 já foram definidos como valores iniciais, o cálculo começa a partir do degrau 3
    for (int i = 3; i <= n; i++) {
        // Relação de recorrência: maneiras para o degrau i = maneiras para o degrau (i-1) + maneiras para o degrau (i-2)
        int curr = prev1 + prev2;
        // Atenção: prev2 deve ser atualizado primeiro, caso contrário o valor original de prev1 será perdido
        prev2 = prev1;
        prev1 = curr;
    }

    // Após o término do loop, prev1 contém o número total de maneiras de subir até o degrau n
    return prev1;
}
```
