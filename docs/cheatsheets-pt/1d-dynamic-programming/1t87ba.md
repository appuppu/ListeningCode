# Maximizing Robbery Loot Without Adjacent Houses — Encontrar o valor máximo que pode ser roubado evitando casas adjacentes

## Essência do problema

Dado um array de inteiros `nums`, onde cada elemento representa a quantia de dinheiro em cada casa ao longo de uma rua. Sob a restrição de que não é possível roubar duas casas adjacentes, retorne o **valor máximo** que pode ser roubado em uma noite. Se a casa `i` for roubada, as casas `i-1` e `i+1` não podem ser roubadas.

## Ideia central

Para cada casa, existem duas opções: "roubar ou não roubar". No caso de roubar, soma-se a quantia atual ao valor máximo até duas casas antes. No caso de não roubar, herda-se diretamente o valor máximo até a casa anterior. Como apenas os dois valores anteriores são necessários para essa decisão, é possível calcular usando apenas duas variáveis, sem manter um array.

## Processo de raciocínio

1. **É necessário tomar a decisão ótima de "roubar/não roubar" em cada casa**: Se a casa `i` for roubada, a casa `i-1` não pode ser roubada, então obtém-se o valor máximo até a casa `i-2` somado a `nums[i]`. Se não for roubada, o valor máximo até a casa `i-1` permanece inalterado. Ou seja, o valor máximo em cada casa pode ser expresso como `max(valor máximo até a casa i-1, valor máximo até a casa i-2 + nums[i])`
2. **A relação de recorrência é estabelecida**: Com a relação de recorrência `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`, é possível calcular o valor máximo até cada casa sequencialmente desde o início. Esta é uma estrutura típica de programação dinâmica
3. **Apenas os dois valores anteriores são necessários**: Observando a relação de recorrência, o cálculo de `dp[i]` utiliza apenas `dp[i-1]` e `dp[i-2]`. Não é necessário manter o array inteiro; duas variáveis (`prev1` e `prev2`) são suficientes
4. **Considerar a ordem de atualização das variáveis**: Após calcular `curr`, na próxima iteração o `prev1` atual se torna o novo `prev2`, e `curr` se torna o novo `prev1`. Atualizando nesta ordem, os valores não são sobrescritos incorretamente
5. **Definição dos valores iniciais**: Antes de iniciar a varredura, define-se `prev1 = 0` (valor máximo da casa anterior) e `prev2 = 0` (valor máximo de duas casas antes). No caso de 0 casas o resultado é 0, e para a primeira casa `max(0, 0 + nums[0]) = nums[0]`, funcionando corretamente
6. **O que retornar no final**: O `prev1` após percorrer todas as casas é o valor máximo considerando todas as casas

## Conhecimentos prévios

### O que é Programação Dinâmica (Dynamic Programming)

É uma técnica que divide um problema grande em subproblemas menores e reutiliza as soluções de cada subproblema para construir a solução geral. Quando há subproblemas sobrepostos, evita-se repetir os mesmos cálculos. Neste problema, "o valor máximo até a casa `i`" corresponde ao subproblema.

### O que é Math.max

É um método padrão do Java que retorna o maior entre dois valores. Permite escrever uma ramificação condicional em uma única linha.

```java
Math.max(5, 3);    // → 5 (retorna o maior valor)
Math.max(prev1, prev2 + num);  // retorna o maior entre prev1 e prev2+num
```

### O que é o loop for aprimorado (for-each)

É uma estrutura de loop que extrai e processa cada elemento do array sequencialmente desde o início. Acessa os elementos diretamente sem usar índices.

```java
int[] nums = {2, 7, 9, 3};
for (int num : nums) {   // atribui cada elemento de nums a num e itera
    System.out.println(num);  // 2, 7, 9, 3 são exibidos sequencialmente
}
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — basta percorrer o array uma única vez |
| Space | O(1) — utiliza apenas duas variáveis, não depende do tamanho da entrada |

## Código

```java
// Entrada: array de inteiros nums (quantia de cada casa)
// Saída: retorna como int o valor máximo que pode ser roubado sob a restrição de não roubar casas adjacentes
public int rob(int[] nums) {
    // prev2: valor máximo até duas casas antes. Antes de iniciar a varredura, é 0 pois não há casas
    int prev2 = 0;
    // prev1: valor máximo até a casa anterior. Da mesma forma, é 0 antes de iniciar a varredura
    int prev1 = 0;

    // Percorre o array nums do início ao fim, um elemento por vez, usando o loop for aprimorado
    for (int num : nums) {
        // Escolhe o maior entre "não roubar a casa atual (prev1)" e "roubar a casa atual (prev2+num)"
        // Ao roubar a casa atual, usa-se prev2 porque a casa adjacente prev1 não pode ser roubada
        int curr = Math.max(prev1,
            prev2 + num);
        // Desliza as variáveis para a próxima iteração
        // O prev1 atual (valor máximo da casa anterior) se torna o valor máximo de duas casas antes na próxima iteração
        prev2 = prev1;
        // O curr calculado agora (valor máximo até a casa atual) se torna o valor máximo da casa anterior na próxima iteração
        // Atenção: esta atualização deve ser feita após prev2 = prev1. Se prev1 for atualizado primeiro, não será possível atribuir o valor correto a prev2
        prev1 = curr;
    }
    // Retorna o valor máximo considerando todas as casas. prev1 armazena o valor máximo considerando até a última casa
    return prev1;
}
```
