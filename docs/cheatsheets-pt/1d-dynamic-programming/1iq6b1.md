# Finding the Subarray With Maximum Product — Encontrar o subarray contíguo com o maior produto

## Essência do problema

Dado um array de inteiros `nums`, selecione um **subarray contíguo** dentro do array cujo produto dos elementos seja máximo e retorne esse **produto**. O subarray é composto por um ou mais elementos consecutivos.

## Ideia central

Como a multiplicação de dois números negativos resulta em um número positivo, o valor mínimo atual (o número negativo de maior magnitude) pode se transformar no valor máximo ao ser multiplicado por um próximo número negativo. Por isso, é necessário rastrear tanto o "produto máximo atual" quanto o "produto mínimo atual" em cada posição.

## Processo de raciocínio

1. **Considerar as propriedades do produto de subarrays**: Em problemas que exigem o produto de um subarray contíguo, a cada elemento adicionado, o novo produto pode ser calculado como "produto do subarray anterior × elemento atual". Isso é equivalente à abordagem de DP, onde o próximo estado é derivado do estado anterior
2. **Números negativos complicam o cálculo do produto máximo**: Se houvesse apenas números positivos, bastaria rastrear o produto máximo. Porém, com números negativos, ocorre "grande produto negativo × número negativo = grande produto positivo". Ou seja, se não rastrearmos o produto mínimo atual (o valor mais negativo), podemos perder o produto máximo
3. **As candidatas em cada posição se reduzem a três**: As candidatas ao produto máximo na posição `i` são: (a) `nums[i]` sozinho (caso de iniciar um novo subarray), (b) `curMax * nums[i]` (caso de estender o produto máximo positivo), (c) `curMin * nums[i]` (caso em que o produto mínimo negativo se inverte com um número negativo). O máximo entre essas três candidatas se torna o novo `curMax`
4. **O produto mínimo também é escolhido entre as mesmas três candidatas**: As candidatas ao produto mínimo são os mesmos três valores, e o mínimo entre eles se torna o novo `curMin`. Atualizando o máximo e o mínimo simultaneamente, capturamos corretamente as inversões causadas por números negativos
5. **Salvar o valor anterior antes da atualização**: Se calcularmos `curMin` depois de atualizar `curMax`, não teremos acesso ao valor de `curMax` antes da atualização para o cálculo de `curMin`. Por isso, antes de atualizar `curMax`, salvamos seu valor em uma variável temporária `temp` e usamos `temp` no cálculo de `curMin`
6. **Gerenciar o máximo global em uma variável separada**: `curMax` é o produto máximo na posição atual, não o produto máximo global. Em cada posição, atualizamos o máximo global com `result = Math.max(result, curMax)` e, ao final, retornamos `result`

## Conhecimentos prévios

### Relação entre produto de subarrays e DP

O produto de um subarray pode ser estendido multiplicando o produto até a posição anterior pelo elemento atual. Usando essa propriedade, é possível calcular em O(1) o "produto máximo do subarray que termina aqui" a partir do resultado da posição anterior. É uma técnica que mantém o estado anterior e deriva o próximo estado, assim como em DP.

### O que são Math.max / Math.min

São métodos Java que obtêm o valor máximo e mínimo entre múltiplos valores. Para comparar três ou mais valores, as chamadas são aninhadas.

```java
Math.max(3, 7);                   // Retorna o máximo entre dois valores → 7
Math.min(3, 7);                   // Retorna o mínimo entre dois valores → 3
Math.max(a, Math.max(b, c));      // Retorna o máximo entre três valores
Math.min(a, Math.min(b, c));      // Retorna o mínimo entre três valores
```

### Por que é necessário rastrear o valor mínimo

Em arrays que contêm números negativos, o sinal do produto se inverte a cada elemento. Exemplo: para `[-2, 3, -4]`, o produto mínimo na posição 1 é `-2 × 3 = -6`, mas na posição 2, `-6 × -4 = 24` se torna o produto máximo. Se rastrearmos apenas o produto máximo, descartamos `-6` e perdemos `24`.

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Basta percorrer o array uma única vez |
| Space | O(1) — Utiliza apenas um número fixo de variáveis, independente do tamanho da entrada |

## Código

```java
// Entrada: array de inteiros nums (comprimento ≥ 1)
// Saída: retorna o produto máximo de um subarray contíguo como int
public int maxProduct(int[] nums) {
    // result=produto máximo global, curMax=produto máximo do subarray que termina na posição atual, curMin=produto mínimo correspondente
    // O estado inicial é o subarray composto apenas pelo primeiro elemento
    int result = nums[0];
    int curMax = nums[0];
    int curMin = nums[0];

    // i=0 já foi processado na inicialização, então começamos em i=1
    for (int i = 1; i < nums.length; i++) {
        int n = nums[i];
        // Salvar curMax antes da atualização (o valor anterior é necessário para o cálculo de curMin)
        int temp = curMax;

        // Escolher o máximo entre três candidatas:
        // n sozinho → caso de iniciar um novo subarray
        // temp * n → caso de estender o produto máximo anterior
        // curMin * n → caso em que o produto mínimo anterior (negativo) se inverte com n negativo e se torna o máximo
        curMax = Math.max(n,
            Math.max(temp * n, curMin * n));

        // Escolher o mínimo entre as mesmas três candidatas (usando temp com o curMax anterior à atualização, o cálculo não é afetado pela atualização acima)
        curMin = Math.min(n,
            Math.min(temp * n, curMin * n));

        // curMax é o produto máximo na posição atual, não o máximo global, então gerenciamos o máximo global na variável separada result
        result = Math.max(result, curMax);
    }
    // result contém o maior produto de subarray ao longo de todo o array
    return result;
}
```
