# Maximizing Robbery Loot in a Circular Neighborhood — Roubar o valor máximo de casas dispostas em círculo sem escolher casas adjacentes

## Essência do problema

Um array de inteiros não negativos `nums` é fornecido. Cada elemento representa o valor disponível em uma casa disposta em círculo. Não é permitido roubar duas casas adjacentes consecutivamente. Sob a restrição de que **a primeira e a última casa também são adjacentes**, retorne o valor máximo que pode ser roubado.

## Ideia central

A restrição circular se reduz a "não é possível escolher a primeira e a última casa simultaneamente". Portanto, divide-se o problema em dois casos — "intervalo que inclui a primeira casa e exclui a última" e "intervalo que inclui a última casa e exclui a primeira" — resolvendo a versão linear do House Robber para cada caso e tomando o maior dos dois resultados, satisfazendo assim a restrição circular.

## Processo de raciocínio

1. **Decompor a restrição circular**: Em um array circular, `nums[0]` e `nums[n-1]` são adjacentes. Ou seja, não é possível escolher ambos simultaneamente. Isso pode ser decomposto em dois casos: "se `nums[0]` for escolhido, `nums[n-1]` não pode ser escolhido" e "se `nums[n-1]` for escolhido, `nums[0]` não pode ser escolhido"
2. **Reduzir a dois problemas lineares**: O caso 1 resolve o House Robber linear no intervalo `nums[0..n-2]` (inclui o primeiro, exclui o último). O caso 2 resolve no intervalo `nums[1..n-1]` (exclui o primeiro, inclui o último). O maior dos dois resultados é a resposta
3. **Formular a recorrência da versão linear**: Para cada casa `i`, há duas opções: "roubar a casa `i`" ou "não roubar". Se roubar, o valor é `nums[i] + dp[i-2]` (pula a casa anterior). Se não roubar, o valor é `dp[i-1]` (herda o valor máximo até a casa anterior). Portanto, `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`
4. **Reduzir o espaço para constante**: A recorrência referencia apenas `dp[i-1]` e `dp[i-2]`. Não é necessário manter o array DP inteiro — basta duas variáveis: `prev1` (valor máximo da posição anterior) e `prev2` (valor máximo de duas posições atrás)
5. **Tratar casos especiais**: Se o array estiver vazio, retorna 0. Se houver apenas um elemento, a restrição circular não se aplica, então retorna esse valor. O processamento em dois passos é executado apenas quando há dois ou mais elementos
6. **Valor final retornado**: Entre os valores máximos obtidos em cada um dos dois intervalos, o maior é selecionado com `Math.max` e retornado

## Conhecimentos prévios

### O que é o House Robber (versão linear)

É o problema de obter o valor máximo de casas dispostas em linha, sem escolher casas adjacentes consecutivamente. É um problema básico de DP e pode ser resolvido com a recorrência `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`. A versão circular resolve o problema aplicando a versão linear duas vezes.

### Otimização de espaço do DP com variáveis rolantes

É a técnica de manter como variáveis apenas os poucos valores recentes que a recorrência referencia no array DP. Elimina a necessidade de manter o array inteiro e reduz a complexidade de espaço de O(n) para O(1).

```java
int prev2 = 0, prev1 = 0;        // Inicializa as variáveis correspondentes a dp[i-2] e dp[i-1]
int curr = Math.max(prev1, prev2 + nums[i]);  // Calcula dp[i]
prev2 = prev1;                    // Avança prev2 em uma posição (o antigo prev1 se torna o novo prev2)
prev1 = curr;                     // Avança prev1 em uma posição (curr se torna o novo prev1)
```

### O que é Math.max

É um método padrão do Java que retorna o maior entre dois valores. É usado para selecionar o valor máximo entre "roubar" e "não roubar" na transição do DP.

```java
Math.max(5, 3);   // → 5 (retorna o maior dos dois)
Math.max(prev1, prev2 + nums[i]);  // Seleciona o valor máximo entre não roubar e roubar
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — O array é percorrido duas vezes, mas cada percurso é O(n), portanto o total é O(n) |
| Space | O(1) — Não utiliza array DP; o cálculo é feito apenas com duas variáveis rolantes |

## Código

```java
// Entrada: array de inteiros não negativos nums (valor de cada casa disposta em círculo)
// Saída: retorna como int o valor máximo que pode ser obtido sem roubar casas adjacentes consecutivamente

// Método auxiliar que resolve a versão linear do House Robber para o intervalo especificado (start a end)
private int robRange(int[] nums, int start, int end) {
    // Inicializa com 0 porque o valor quando nenhuma casa é roubada é 0
    int prev2 = 0, prev1 = 0;  // Variáveis rolantes que mantêm o valor máximo de duas posições atrás e da posição anterior
    // Percorre do início ao fim do intervalo especificado, uma posição por vez
    for (int i = start; i <= end; i++) {
        // prev1: opção de não roubar a casa i e herdar o valor máximo até a posição anterior
        // prev2 + nums[i]: opção de roubar a casa i e somar o valor atual ao valor máximo de duas posições atrás
        int curr = Math.max(prev1,
            prev2 + nums[i]);
        // Avança as variáveis rolantes em uma posição (na próxima iteração, curr assumirá o papel de prev1 e prev1 assumirá o papel de prev2)
        prev2 = prev1;
        prev1 = curr;
    }
    // prev1 contém o valor máximo considerando todo o intervalo especificado
    return prev1;
}

public int rob(int[] nums) {
    int n = nums.length;
    if (n == 0) return 0;        // Se não houver casas, retorna 0
    if (n == 1) return nums[0];  // Se houver apenas uma casa, a restrição de adjacência não se aplica, então o valor é a resposta direta

    // Decompõe a restrição circular em dois problemas lineares e retorna o maior dos dois
    // Como é garantido que a primeira e a última casa não são escolhidas simultaneamente, a restrição circular é satisfeita
    return Math.max(
        robRange(nums, 0, n - 2),   // Intervalo que inclui a primeira casa e exclui a última (índice 0 a n-2)
        robRange(nums, 1, n - 1));  // Intervalo que exclui a primeira casa e inclui a última (índice 1 a n-1)
}
```
