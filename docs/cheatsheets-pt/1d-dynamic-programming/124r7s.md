# Partitioning an Array Into Two Equal Sum Subsets — Determinar se um array pode ser dividido em dois subconjuntos com somas iguais

## Essência do problema

É dado um array de inteiros `nums`. O objetivo é retornar um `boolean` indicando se é possível dividir o array em dois subconjuntos cujas somas dos elementos sejam iguais. Cada elemento deve pertencer a exatamente um dos subconjuntos e não pode ser usado mais de uma vez.

## Ideia central

Se a soma total do array for ímpar, é possível retornar false imediatamente. Se a soma for par, o problema se reduz ao "problema da soma de subconjunto": verificar se existe um subconjunto cuja soma seja exatamente `target`, que é a metade da soma total. Utilizando um array DP unidimensional do tipo boolean e processando cada elemento sequencialmente para registrar as somas alcançáveis, é possível determinar se `target` é alcançável em O(n × target).

## Processo de raciocínio

1. **Considerar a condição de divisão em duas partes iguais**: Quando a soma total do array é `sum`, para que os dois subconjuntos tenham somas iguais, cada subconjunto deve ter soma igual a `sum / 2`. Se `sum` for ímpar, não é possível dividi-lo em dois inteiros iguais, portanto retorna-se false imediatamente
2. **Converter o problema no "problema da soma de subconjunto"**: Se a soma de um subconjunto for `target = sum / 2`, a soma do outro subconjunto também será automaticamente `target`. Ou seja, o problema se reduz a "verificar se existe um subconjunto dos elementos do array cuja soma seja `target`"
3. **Gerenciar as somas alcançáveis com DP**: Prepara-se um array boolean `dp`, onde `dp[j]` representa "se é possível formar a soma `j` a partir dos elementos processados até o momento". Como estado inicial, define-se `dp[0] = true` (se nenhum elemento for selecionado, a soma é 0)
4. **Atualizar as somas alcançáveis para cada elemento**: Para cada elemento `num` do array, se a soma `j` já for alcançável, então `j + num` também se torna alcançável. Essa operação consiste em definir `dp[j + num]` como true quando `dp[j]` for true
5. **Percorrer em ordem reversa para evitar o uso duplicado**: O laço interno percorre de `target` até `num` em ordem decrescente. Se o percurso fosse em ordem crescente, o array `dp` seria atualizado com resultados que usam o mesmo elemento múltiplas vezes. Em ordem reversa, cada elemento é usado no máximo uma vez
6. **Retornar `dp[target]` como resultado final**: Após processar todos os elementos, se `dp[target]` for true, existe um subconjunto com soma `target`, portanto retorna-se true; caso contrário, tal subconjunto não existe

## Conhecimentos prévios

### O que é o problema da soma de subconjunto (Subset Sum Problem)

É um problema que consiste em determinar se é possível selecionar alguns elementos de um conjunto de inteiros de forma que a soma seja exatamente igual a um valor alvo. É um problema clássico que pode ser resolvido eficientemente com DP (programação dinâmica).

### O que é um array DP unidimensional do tipo boolean

É um array onde `dp[j]` indica com true/false "se é possível formar a soma `j`". A cada elemento processado, o conjunto de somas alcançáveis se expande progressivamente.

```java
boolean[] dp = new boolean[target + 1];  // Cria um array de tamanho target+1 (valor inicial é false para todos)
dp[0] = true;                            // Se nenhum elemento for selecionado, a soma 0 é sempre alcançável
dp[j - num] == true                      // Se a soma j-num é alcançável, adicionando num, a soma j também é alcançável
```

### Razão para atualizar o array DP em ordem reversa

Se a atualização for feita em ordem crescente (de `j` menor para `j` maior), o resultado do uso do mesmo elemento `num` múltiplas vezes se propaga. Atualizando em ordem decrescente (de `j` maior para `j` menor), garante-se que cada elemento é usado apenas uma vez.

```java
// Laço em ordem reversa: j decresce de target até num, diminuindo 1 a cada iteração
for (int j = target; j >= num; j--) {
    if (dp[j - num]) dp[j] = true;
}
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n × target) — Para cada um dos n elementos, o array DP é percorrido até no máximo target |
| Space | O(target) — Utiliza-se um único array DP do tipo boolean com tamanho target+1 |

## Código

```java
// Entrada: array de inteiros nums
// Saída: retorna um boolean indicando se o array pode ser dividido em dois subconjuntos com somas iguais
boolean canPartition(int[] nums) {
    // Calcula a soma total de todos os elementos do array para obter o valor de referência que determina se a divisão em duas partes iguais é possível
    int sum = 0;
    for (int n : nums) sum += n;

    // Se a soma for ímpar, não é possível dividi-la em dois inteiros iguais, portanto retorna false
    if (sum % 2 != 0) return false;

    // Valor alvo da soma que um subconjunto deve atingir. O outro subconjunto também terá automaticamente a soma igual a target
    int target = sum / 2;

    // dp[j] = se é possível formar a soma j a partir dos elementos processados até o momento (array DP do problema da soma de subconjunto)
    boolean[] dp = new boolean[target + 1];
    dp[0] = true;  // Se nenhum elemento for selecionado, a soma 0 é sempre alcançável

    // Processa cada elemento do array do início ao fim, um por um, atualizando o conjunto de somas alcançáveis
    for (int num : nums) {
        // Percorre em ordem reversa para evitar o uso duplicado do mesmo elemento (em ordem crescente, o resultado de somar num múltiplas vezes se propagaria)
        for (int j = target; j >= num; j--) {
            // Se a soma j-num é alcançável, adicionando num, a soma j também se torna alcançável, portanto atualiza para true
            if (dp[j - num]) dp[j] = true;
        }
    }

    // Se dp[target] for true, existe um subconjunto com soma igual a target, portanto a divisão em duas partes iguais é possível
    return dp[target];
}
```
