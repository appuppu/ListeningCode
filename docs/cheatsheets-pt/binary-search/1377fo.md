# Finding the Minimum Eating Speed to Finish Bananas — Encontrar a velocidade mínima para comer todas as bananas dentro do tempo limite

## Essência do problema

É fornecido um array de pilhas de bananas `piles` e um tempo limite `h` (horas). Ao comer `k` bananas por hora, o objetivo é retornar a **menor velocidade inteira `k`** que permite comer todas as bananas dentro de `h` horas. Só é possível comer de uma pilha por hora, e se a pilha tiver menos de `k` bananas, mesmo após terminar essa pilha, o tempo restante é gasto aguardando sem avançar para a próxima pilha.

## Ideia central

A pergunta "É possível comer tudo na velocidade `k`?" possui monotonicidade em relação a `k`. Se `k` for grande o suficiente, é sempre possível comer tudo; se for pequeno demais, não é possível. Graças a essa monotonicidade, pode-se aplicar busca binária no intervalo de candidatos `[1, max(piles)]` para encontrar eficientemente o menor `k` que satisfaz a condição.

## Processo de raciocínio

1. **A relação entre velocidade e resultado é monótona**: Ao aumentar a velocidade `k`, o tempo necessário diminui; ao diminuí-la, o tempo aumenta. Se é possível comer tudo em uma determinada velocidade, qualquer velocidade maior também permite terminar. Essa estrutura de "encontrar o menor valor que satisfaz uma condição" é um padrão clássico de busca binária
2. **Definir o intervalo de busca**: O valor mínimo da velocidade é `1` (come-se pelo menos 1 banana por hora) e o valor máximo é `max(piles)` (velocidade suficiente para comer a maior pilha em 1 hora). Velocidades maiores que `max(piles)` não alteram o resultado, pois só é possível comer de uma pilha por hora
3. **Projetar a função de verificação**: Dada a velocidade `mid`, cada pilha `piles[i]` leva `ceil(piles[i] / mid)` horas para ser consumida. Se o tempo total de todas as pilhas for menor ou igual a `h`, é possível comer tudo nessa velocidade
4. **Realizar a divisão com teto usando aritmética inteira**: `ceil(piles[i] / mid)` pode ser calculado como `(piles[i] + mid - 1) / mid`. Isso evita operações de ponto flutuante e permite um cálculo exato apenas com inteiros
5. **Reduzir o intervalo com busca binária**: Se é possível comer tudo com o valor intermediário `mid`, a resposta está em `mid` ou abaixo, então atribui-se `right = mid`. Se não for possível, a resposta está em `mid + 1` ou acima, então atribui-se `left = mid + 1`. Quando `left == right`, esse valor é a velocidade mínima procurada

## Conhecimentos prévios

### Padrão de busca binária (Binary Search) para "menor valor que satisfaz a condição"

Técnica para encontrar o menor valor (ou o maior valor) que satisfaz uma condição em um intervalo de valores ordenados ou inteiros contínuos. Como o intervalo de busca é reduzido pela metade a cada iteração, a resposta é encontrada em O(log n).

```java
int left = 1;               // Limite inferior do intervalo de busca
int right = 1000;            // Limite superior do intervalo de busca
while (left < right) {       // Quando left == right, a resposta está definida
    int mid = left + (right - left) / 2;  // Cálculo do valor intermediário para evitar overflow
    if (condition(mid))       // Verifica se mid satisfaz a condição
        right = mid;          // Satisfaz a condição → a resposta está em mid ou abaixo
    else
        left = mid + 1;       // Não satisfaz a condição → a resposta está em mid+1 ou acima
}
// left é o menor valor que satisfaz a condição
```

### Divisão com teto (Ceiling Division)

Operação inteira que arredonda para cima o resultado de `a / b`. Em vez de usar `Math.ceil`, pode-se calcular como `(a + b - 1) / b`.

```java
int a = 10, b = 3;
int result = (a + b - 1) / b;  // (10 + 2) / 3 = 4  (10÷3=3,33... → arredondado para cima resulta em 4)
```

No problema das bananas, divide-se o tamanho da pilha `piles[i]` pela velocidade `k` e arredonda-se para cima para obter o número de horas necessárias para consumir essa pilha.

### O que é Math.max

Método que retorna o maior entre dois valores. É utilizado em combinação com um loop para encontrar o valor máximo de um array.

```java
Math.max(5, 3);   // → 5
Math.max(-1, 0);  // → 0
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n × log(max(piles))) — A busca binária realiza O(log(max(piles))) iterações, e em cada iteração o array inteiro é percorrido em O(n) para calcular o tempo total |
| Space | O(1) — Nenhuma estrutura de dados adicional é utilizada; o processamento é feito apenas com variáveis |

## Código

```java
// Entrada: array de inteiros piles (número de bananas em cada pilha) e inteiro h (tempo limite)
// Saída: retorna como int a menor velocidade inteira k que permite comer todas as bananas dentro de h horas
public int minEatingSpeed(int[] piles, int h) {
    // Define o limite inferior da busca binária como 1. A velocidade é no mínimo 1 banana por hora
    int left = 1;
    // Define o limite superior da busca binária como o valor máximo do array
    // Velocidades maiores que a necessária para comer a maior pilha em 1 hora não fazem sentido, portanto este valor é o limite superior
    int right = 0;
    for (int p : piles) {
        right = Math.max(right, p);
    }

    // Continua reduzindo o intervalo de busca pela metade até que left == right
    // Quando left == right, esse valor é a resposta
    while (left < right) {
        // Cálculo do valor intermediário para evitar overflow
        // Usa-se left + (right - left) / 2 em vez de (left + right) / 2 para evitar overflow de inteiros
        int mid = left + (right - left) / 2;

        // Calcula o tempo total necessário para comer todas as bananas na velocidade mid
        int totalHours = 0;
        for (int p : piles) {
            // Divisão com teto: obtém o número de horas necessárias para consumir cada pilha
            totalHours += (p + mid - 1) / mid;
        }

        if (totalHours <= h) {
            // É possível comer tudo → pode haver uma velocidade menor que também funcione, então reduz o limite superior
            // Como o próprio mid pode ser a resposta, atribui-se mid em vez de mid - 1
            right = mid;
        } else {
            // Não é possível comer tudo → a velocidade é insuficiente, então eleva o limite inferior
            // Como mid não pode ser a resposta, atribui-se mid + 1
            left = mid + 1;
        }
    }

    // Após o término do loop, left (= right) é a menor velocidade que satisfaz a condição
    return left;
}
```
