# Reordering a Linked List by Interleaving Ends — Reordenar uma lista ligada intercalando as extremidades

## Essência do problema

Uma lista ligada simples L0 → L1 → … → Ln-1 → Ln é fornecida. O objetivo é reordenar essa lista **no local (in-place)** na seguinte ordem: L0 → Ln → L1 → Ln-1 → L2 → Ln-2 → …. A reordenação deve ser realizada manipulando apenas os links (ponteiros next) dos nós, sem alterar os valores dos nós.

## Ideia central

Se a segunda metade da lista for invertida, basta conectar alternadamente "a partir do início da primeira metade" e "a partir do início da segunda metade (que era o final original)" para obter a ordem desejada. Para inverter a segunda metade, primeiro é necessário encontrar o ponto médio da lista e dividi-la em duas partes.

## Processo de raciocínio

1. **Observar a estrutura após a reordenação**: A ordem L0 → Ln → L1 → Ln-1 → … é o resultado de extrair elementos alternadamente do "início" e do "final" da lista. Ou seja, basta mesclar alternadamente duas sequências: a do lado do início e a do lado do final
2. **Para extrair elementos do final, é necessário inverter**: Em uma lista ligada simples, o acesso ao final custa O(n). No entanto, se a segunda metade da lista for invertida, o início da segunda metade se torna o final original, e é possível obter os elementos do lado do final simplesmente percorrendo a partir do início
3. **Encontrar o ponto médio da lista**: Para inverter a segunda metade, primeiro é necessário decidir onde dividir a lista. Usando ponteiros slow/fast (tartaruga e lebre), o ponto médio pode ser encontrado em uma única passagem. O slow avança 1 passo por vez e o fast avança 2 passos por vez; quando o fast chega ao final da lista, o slow está apontando para o ponto médio
4. **Inverter a segunda metade**: A partir do nó seguinte ao ponto médio, o ponteiro next de cada nó é redirecionado para o nó anterior, invertendo a segunda metade da lista. A variável prev rastreia o nó anterior, e após a conclusão do loop, prev aponta para o início da lista invertida
5. **Mesclar alternadamente a primeira metade e a segunda metade invertida**: Percorrer ambas as listas a partir do início e inserir um nó da segunda metade após cada nó da primeira metade. Como os ponteiros next são reatribuídos a cada passo, é necessário salvar os links originais em variáveis temporárias antes de sobrescrevê-los
6. **A segunda metade é menor ou do mesmo tamanho**: Em listas de comprimento ímpar, a primeira metade tem um nó a mais, portanto a condição do loop de mesclagem é `second != null`. A mesclagem termina quando não há mais nós na segunda metade

## Conhecimentos prévios

### O que é o ponteiro slow/fast (método da tartaruga e lebre)

Uma técnica para encontrar o ponto médio de uma lista ligada em uma única passagem. O slow avança 1 nó por vez e o fast avança 2 nós por vez. Quando o fast chega ao final da lista, o slow está apontando para o ponto médio da lista.

```java
ListNode slow = head, fast = head;
while (fast.next != null && fast.next.next != null) {
    slow = slow.next;        // slow avança 1 passo
    fast = fast.next.next;   // fast avança 2 passos
}
// Ao final do loop, slow aponta para o nó do meio da lista
```

### O que é a inversão de uma lista ligada

Uma operação que redireciona o ponteiro next de cada nó para o nó anterior em vez do próximo nó. Avança-se um nó por vez rastreando prev (o nó anterior) e invertendo a direção dos links.

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode nxt = curr.next;  // Salvar o próximo nó
    curr.next = prev;          // Redirecionar o link para o nó anterior
    prev = curr;               // Atualizar prev para o nó atual
    curr = nxt;                // Avançar para o próximo nó
}
// Ao final do loop, prev aponta para o início da lista invertida
```

### O que é a mesclagem alternada de duas listas

Uma operação que extrai elementos alternadamente, um por um, de duas listas e os conecta em uma única lista. Como os ponteiros next são reatribuídos a cada passo, é necessário salvar os links originais em variáveis temporárias antes de sobrescrevê-los.

```java
ListNode a = list1, b = list2;
while (b != null) {
    ListNode tmpA = a.next;   // Salvar o próximo original de a
    ListNode tmpB = b.next;   // Salvar o próximo original de b
    a.next = b;               // Inserir b após a
    b.next = tmpA;            // Conectar o próximo original de a após b
    a = tmpA;                 // Avançar a para a próxima posição
    b = tmpB;                 // Avançar b para a próxima posição
}
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Cada etapa de busca do ponto médio, inversão da segunda metade e mesclagem é O(n) |
| Space | O(1) — Utiliza apenas variáveis de ponteiro, sem criar estruturas de dados adicionais |

## Código

```java
// Entrada: nó inicial head de uma lista ligada simples
// Saída: nenhuma (a lista é reordenada no local. O tipo de retorno é void)
void reorderList(ListNode head) {
    // Uma lista vazia não precisa de reordenação
    if (head == null) return;

    // Passo 1: Encontrar o ponto médio da lista usando ponteiros slow/fast
    // O fast avança ao dobro da velocidade do slow, portanto quando o fast chega ao final, o slow aponta para o nó do meio
    ListNode slow = head, fast = head;
    while (fast.next != null
            && fast.next.next != null) {
        slow = slow.next;          // slow avança 1 passo
        fast = fast.next.next;     // fast avança 2 passos
    }

    // Passo 2: Separar a segunda metade da lista e invertê-la
    ListNode second = slow.next;   // second é o nó inicial da segunda metade da lista
    slow.next = null;              // Cortar o final da primeira metade, dividindo em duas partes
    ListNode prev = null;
    while (second != null) {
        ListNode nxt = second.next;  // Salvar o próximo nó
        second.next = prev;          // Redirecionar o link para o nó anterior
        prev = second;               // Atualizar prev para o nó atual
        second = nxt;                // Avançar para o próximo nó
    }
    // Ao final do loop, prev aponta para o início da segunda metade invertida (final original da lista)

    // Passo 3: Mesclar alternadamente a primeira metade e a segunda metade invertida
    ListNode first = head;         // Início da primeira metade da lista
    second = prev;                 // Início da segunda metade invertida da lista
    // Em listas de comprimento ímpar, a primeira metade tem um nó a mais, portanto termina quando a segunda metade (second) se esgota
    while (second != null) {
        ListNode tmp1 = first.next;   // Salvar o próximo nó da primeira metade (sem salvar, o link original seria perdido ao sobrescrever next)
        ListNode tmp2 = second.next;  // Salvar o próximo nó da segunda metade
        first.next = second;          // Inserir o nó da segunda metade após o nó da primeira metade
        second.next = tmp1;           // Conectar a continuação da primeira metade após o nó da segunda metade
        first = tmp1;                 // Avançar o ponteiro da primeira metade para a próxima posição
        second = tmp2;                // Avançar o ponteiro da segunda metade para a próxima posição
    }
}
```
