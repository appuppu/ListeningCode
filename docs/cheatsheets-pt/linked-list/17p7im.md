# Detecting a Cycle in a Linked List — Determinar se existe um ciclo em uma lista encadeada

## Essência do problema

Um nó inicial `head` de uma lista encadeada unidirecional é fornecido. Se o ponteiro `next` de algum nó na lista apontar para um nó já visitado anteriormente (ou seja, existe um ciclo), retornar `true`; caso contrário, retornar `false`.

## Ideia central

Ao executar simultaneamente dois ponteiros com velocidades diferentes, se houver um ciclo, o ponteiro mais rápido inevitavelmente alcançará o mais lento e ambos se encontrarão. Se não houver ciclo, o ponteiro mais rápido alcançará o final da lista primeiro. Essa propriedade permite detectar ciclos sem utilizar estruturas de dados adicionais.

## Processo de raciocínio

1. **Considerar a essência de um ciclo**: Ao percorrer uma lista que contém um ciclo, o percurso nunca alcança o final (null) e continua em loop infinitamente. Por outro lado, se não houver ciclo, o percurso sempre alcança null e termina
2. **Usar ponteiros com diferença de velocidade**: Preparar um ponteiro que avança 1 passo por vez (slow) e outro que avança 2 passos por vez (fast). Dentro do ciclo, fast reduz a distância até slow em 1 nó a cada passo, então os dois inevitavelmente se encontram
3. **Por que o encontro é prova de um ciclo**: Se não houver ciclo, fast alcança null antes de slow, então é impossível que slow e fast apontem para o mesmo nó. Se o encontro ocorreu, então existe um ciclo
4. **Definir as condições de término**: Se fast ou fast.next for null, o final da lista existe, portanto não há ciclo. Se slow e fast apontarem para o mesmo nó, existe um ciclo
5. **Definir as posições iniciais**: Posicionar slow em head e fast em head.next. Dessa forma, a condição do while `slow != fast` é satisfeita desde o início, permitindo que o percurso comece dentro do loop
6. **O que retornar no final**: Retornar `true` se slow e fast se encontrarem; retornar `false` se fast alcançar null

## Conhecimento prévio

### O que é um ListNode (nó de uma lista encadeada)

É um elemento individual que compõe uma lista encadeada. Cada nó possui um "valor" e um "ponteiro para o próximo nó". O next do último nó aponta para null (quando não há ciclo).

```java
class ListNode {
    int val;            // Valor armazenado no nó
    ListNode next;      // Referência ao próximo nó (null se não existir)
}

ListNode node = head;       // Obter o nó inicial
node.next;                  // Obter o próximo nó
node.next.next;             // Obter o nó dois posições à frente
```

### O que é o Floyd's Tortoise and Hare (algoritmo de detecção de ciclo de Floyd)

É um algoritmo que detecta ciclos utilizando dois ponteiros com velocidades diferentes. O ponteiro slow avança 1 passo por vez e o ponteiro fast avança 2 passos por vez. Dentro do ciclo, fast se aproxima de slow em 1 nó a cada passo, portanto, se existir um ciclo, os dois inevitavelmente se encontram em um número finito de passos.

```java
ListNode slow = head;       // Ponteiro que avança 1 passo por vez
ListNode fast = head.next;  // Ponteiro que avança 2 passos por vez
slow = slow.next;           // Avançar slow em 1 posição
fast = fast.next.next;      // Avançar fast em 2 posições
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Se não houver ciclo, fast alcança o final em n/2 passos; se houver ciclo, os ponteiros se encontram dentro do comprimento do ciclo |
| Space | O(1) — Utiliza apenas duas variáveis de ponteiro, sem necessidade de estruturas de dados adicionais |

## Código

```java
// Entrada: nó inicial head de uma lista encadeada unidirecional
// Saída: retornar true se existir um ciclo, false caso contrário
public boolean hasCycle(ListNode head) {
    // Se houver 0 ou 1 nó, não é possível existir um ciclo. Retornar false e encerrar
    if (head == null || head.next == null) {
        return false;
    }

    // Posicionar slow em head e fast em head.next
    // Ao colocar fast uma posição à frente, a condição do while slow != fast é satisfeita desde o início, permitindo entrar no loop
    ListNode slow = head;
    ListNode fast = head.next;

    // Repetir o loop até slow e fast se encontrarem (encerrar quando se encontrarem)
    while (slow != fast) {
        // Se fast for null ou fast.next for null, o final da lista existe, portanto não há ciclo
        if (fast == null || fast.next == null) {
            return false;
        }
        // Avançar slow em 1 passo e fast em 2 passos
        // Devido à diferença de velocidade, dentro do ciclo fast se aproxima de slow em 1 nó a cada passo
        slow = slow.next;
        fast = fast.next.next;
    }

    // A condição do while slow != fast se tornou falsa = slow e fast se encontraram, portanto existe um ciclo
    return true;
}
```
