# Merging Two Sorted Linked Lists — Mesclar duas listas ligadas ordenadas em uma única lista

## Essência do problema

Duas listas ligadas ordenadas `list1` e `list2` são fornecidas. O objetivo é mesclá-las em uma única lista ligada ordenada e retornar o **nó inicial** da lista mesclada.

## Ideia central

Comparamos os nós iniciais das duas listas e escolhemos o menor como o início do resultado da mesclagem. A parte restante é o resultado da mesclagem entre "o próximo nó do menor" e "a outra lista", que possui a mesma estrutura do problema original, portanto pode ser resolvido com recursão.

## Processo de raciocínio

1. **Cada etapa da mesclagem executa a mesma operação**: Comparamos os nós iniciais das duas listas e escolhemos o menor. Essa operação se repete até que uma lista fique vazia. Como a mesma decisão é tomada a cada vez, podemos expressá-la com recursão
2. **Considerar o caso base**: Se uma das listas estiver vazia (null), basta retornar a outra lista. Se ambas estiverem vazias, retornamos null (isso está incluído no caso em que uma delas é null)
3. **Considerar o passo recursivo**: Se `list1.val <= list2.val`, então `list1` se torna o início. Conectamos a `list1.next` o resultado da mesclagem entre "o restante de `list1`" e "`list2` inteira". No caso contrário, colocamos `list2` no início e processamos de forma análoga
4. **O tamanho do problema diminui em 1 a cada chamada recursiva**: A cada vez, consumimos 1 nó de uma das listas, portanto todos os nós são processados em um total de n chamadas recursivas
5. **O que é retornado ao final**: Cada chamada recursiva retorna o nó escolhido (`list1` ou `list2`). O nó retornado pela primeira chamada se torna o início da lista mesclada

## Conhecimentos prévios

### O que é ListNode (nó de lista ligada)

Uma classe que representa cada elemento de uma lista ligada. O campo `val` armazena o valor, e o campo `next` armazena a referência para o próximo nó. O nó cujo `next` é null é o final da lista.

```java
class ListNode {
    int val;          // Valor armazenado no nó
    ListNode next;    // Referência para o próximo nó (null se for o final)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### O que é Recursão (Recursion)

Uma técnica em que uma função resolve um problema chamando a si mesma. O problema grande é decomposto em problemas menores com a mesma estrutura, e quando o caso base (o menor problema que não pode ser mais decomposto) é alcançado, o resultado é retornado. A cada chamada, um frame é empilhado na call stack, portanto consome espaço proporcional à profundidade da recursão.

```java
// Exemplo: cálculo do fatorial
int factorial(int n) {
    if (n <= 1) return 1;           // Caso base: não decompõe mais
    return n * factorial(n - 1);    // Passo recursivo: reduz o tamanho do problema em 1 e chama a si mesma
}
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Processa todos os nós em n chamadas recursivas, onde n é o número total de nós das duas listas |
| Space | O(n) — A cada chamada recursiva um frame é empilhado na call stack, atingindo uma profundidade máxima de n |

## Código

```java
// Entrada: nós iniciais list1 e list2 de duas listas ligadas ordenadas
// Saída: retorna o nó inicial da lista ligada ordenada mesclada como ListNode
ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    // Caso base: se list1 estiver vazia, retorna list2 diretamente (como list1 está vazia, list2 é o resultado da mesclagem)
    if (list1 == null) return list2;
    // Caso base: se list2 estiver vazia, retorna list1 diretamente (como list2 está vazia, list1 é o resultado da mesclagem)
    if (list2 == null) return list1;

    // Compara o início de list1 com o início de list2 e decide qual nó colocar no início do resultado da mesclagem
    if (list1.val <= list2.val) {
        // Escolhe list1 como início e conecta ao próximo de list1 o resultado da mesclagem entre o restante de list1 (list1.next) e list2 inteira
        list1.next = mergeTwoLists(list1.next, list2);
        return list1; // list1 se torna o nó inicial do resultado da mesclagem
    } else {
        // Escolhe list2 como início e conecta ao próximo de list2 o resultado da mesclagem entre list1 inteira e o restante de list2 (list2.next)
        list2.next = mergeTwoLists(list1, list2.next);
        return list2; // list2 se torna o nó inicial do resultado da mesclagem
    }
}
```
