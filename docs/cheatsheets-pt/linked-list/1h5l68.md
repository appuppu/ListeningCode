# Reversing Nodes in Groups of K — Reverter os nós de uma lista ligada em grupos de K

## Essência do problema

São dados o nó inicial `head` de uma lista ligada unidirecional e um inteiro `k`. O objetivo é dividir a lista em grupos de `k` nós a partir do início e reverter a ordem dos nós dentro de cada grupo. Se o último grupo tiver menos de `k` nós, esse grupo permanece inalterado. A função deve retornar o nó inicial da lista modificada.

## Ideia central

Colocando um nó dummy no início e usando como pontos de referência o "nó imediatamente antes do grupo" e o "k-ésimo nó do grupo", é possível redirecionar os ponteiros um a um dentro de cada grupo, realizando a reversão in-place sem memória adicional.

## Processo de raciocínio

1. **É necessário reverter em unidades de grupo**: Não se reverte a lista inteira, mas sim grupos de k nós por vez. Ou seja, a estrutura de loop é: "identificar o intervalo do grupo atual" → "reverter esse grupo" → "avançar para o próximo grupo"
2. **Para identificar o intervalo do grupo, é preciso encontrar o k-ésimo nó**: Prepara-se uma função auxiliar `getKth` que busca o nó k posições à frente da posição atual. Se o k-ésimo nó não existir (`null`), significa que restam menos de k nós, portanto a reversão não é realizada e o processo termina
3. **Após a reversão, é necessário reconectar os grupos corretamente**: Ao reverter um grupo, o início e o fim do grupo se invertem. É necessário reconectar para que o final do grupo anterior (`groupPrev`) aponte para o novo início após a reversão (o k-ésimo nó original)
4. **O nó dummy permite tratar a reversão do primeiro grupo de forma uniforme**: Ao reverter o primeiro grupo, o próprio nó inicial da lista muda. Colocando um nó dummy no início, a operação "o nó anterior ao grupo aponta para o novo início" pode ser processada com a mesma lógica tanto para o primeiro grupo quanto para os grupos subsequentes
5. **A reversão de cada grupo utiliza a mesma técnica padrão de reversão de lista**: Usando dois ponteiros `prev` e `curr`, redireciona-se `curr.next` para `prev` enquanto se avança nó a nó. Porém, ao definir o valor inicial de `prev` como o nó seguinte ao grupo (`groupNext`), o final do grupo revertido se conecta automaticamente ao próximo grupo
6. **Após a reversão, atualiza-se groupPrev e avança-se para o próximo grupo**: O nó que era o início do grupo antes da reversão (`groupPrev.next`) torna-se o final do grupo após a reversão. Esse nó é usado como `groupPrev` do próximo grupo para prosseguir na próxima iteração

## Conhecimentos prévios

### O que é um ListNode

É uma classe que representa um nó de uma lista ligada unidirecional. Cada nó possui um "valor (val)" e um "ponteiro para o próximo nó (next)". O nó cujo `next` é `null` é o final da lista.

```java
class ListNode {
    int val;          // Valor armazenado no nó
    ListNode next;    // Referência para o próximo nó (null se for o último)

    ListNode(int val) {
        this.val = val;
        this.next = null;
    }
}
```

### O que é um Nó Dummy (Dummy Node)

É uma técnica que adiciona um nó fictício no início da lista. Quando o nó inicial pode ser alterado, essa técnica elimina a necessidade de tratamento condicional. `dummy.next` sempre aponta para o início real da lista.

```java
ListNode dummy = new ListNode(0);  // O valor pode ser qualquer um
dummy.next = head;                 // O próximo do dummy é o início real
// ... manipular a lista ...
return dummy.next;                 // Retorna o início real após a manipulação
```

### Operação básica de reversão de lista ligada

Usando dois ponteiros `prev` e `curr`, redireciona-se o `next` de cada nó para o nó anterior.

```java
ListNode prev = null;
ListNode curr = head;
while (curr != null) {
    ListNode tmp = curr.next;  // Salva temporariamente o próximo nó
    curr.next = prev;          // Altera o próximo do nó atual para o nó anterior
    prev = curr;               // Avança prev para o nó atual
    curr = tmp;                // Avança curr para o próximo nó
}
// prev se torna o nó inicial da lista revertida
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Cada nó é visitado um número constante de vezes (uma vez na busca do k-ésimo e uma vez na reversão) |
| Space | O(1) — Utiliza apenas variáveis de ponteiro, sem necessidade de estruturas de dados adicionais |

## Código

```java
// Entrada: nó inicial da lista ligada head e inteiro k
// Saída: retorna o nó inicial da lista ligada com os grupos de k nós revertidos
public ListNode reverseKGroup(ListNode head, int k) {
    // Cria um nó dummy e conecta ao início real da lista com dummy.next = head
    // Usando o nó dummy, o "nó imediatamente antes do grupo" sempre existe, mesmo na reversão do primeiro grupo
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // groupPrev aponta para o "nó imediatamente antes do grupo que será revertido"
    // O valor inicial é o nó dummy
    ListNode groupPrev = dummy;

    // Loop infinito que reverte um grupo em cada iteração
    while (true) {
        // Partindo do nó seguinte a groupPrev, percorre next k-1 vezes para encontrar o k-ésimo nó
        // Se null for alcançado no caminho, significa que restam menos de k nós, então retorna null
        ListNode kth = getKth(groupPrev, k);

        // Se o k-ésimo nó não existir, restam menos de k nós, então termina sem alterar
        // Esta verificação satisfaz o requisito do problema de manter inalterados os grupos com menos de k nós
        if (kth == null) break;

        // groupNext é o "nó imediatamente após o grupo atual", usado como marcador de fim da reversão
        ListNode groupNext = kth.next;

        // Define o valor inicial de prev como groupNext
        // Assim, o next do último nó do grupo revertido aponta automaticamente para o início do próximo grupo
        ListNode prev = kth.next;
        // curr começa no nó inicial do grupo (que após a reversão se tornará o último nó do grupo)
        ListNode curr = groupPrev.next;

        // Reverte o ponteiro next de cada nó dentro do grupo até que curr seja igual a groupNext
        // Esta operação faz com que o next de cada nó passe a apontar para o nó anterior
        while (curr != groupNext) {
            ListNode tmp = curr.next;  // Salva temporariamente o próximo nó
            curr.next = prev;          // Altera o próximo do nó atual para o nó anterior
            prev = curr;               // Avança prev para o nó atual
            curr = tmp;                // Avança curr para o próximo nó
        }

        // Salva o nó que era o início antes da reversão (após a reversão, tornou-se o final do grupo)
        ListNode tmp = groupPrev.next;
        // O novo início do grupo revertido é kth (o k-ésimo nó original),
        // então reconecta para que o final do grupo anterior aponte corretamente para o novo início
        groupPrev.next = kth;
        // O nó que era o início do grupo antes da reversão agora é o final do grupo
        // Este nó é usado como groupPrev na próxima iteração
        groupPrev = tmp;
    }

    // dummy.next aponta para o nó inicial de toda a lista após as operações
    return dummy.next;
}

// Retorna o k-ésimo nó a partir do nó seguinte a node. Retorna null se houver menos de k nós
private ListNode getKth(ListNode node, int k) {
    // Parte do nó seguinte a node
    node = node.next;
    // Percorre next k-1 vezes para alcançar o k-ésimo nó
    // Se null for alcançado no caminho, significa que há menos de k nós restantes
    while (node != null && k > 1) {
        node = node.next;
        k--;
    }
    // Retorna o k-ésimo nó (null se havia menos de k nós)
    return node;
}
```
