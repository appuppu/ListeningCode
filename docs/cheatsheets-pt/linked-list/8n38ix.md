# Removing the Nth Node From the End of a List — Remover o N-ésimo nó a partir do final de uma lista

## Essência do problema

São dados o nó inicial `head` de uma lista encadeada simples e um inteiro `n`. O objetivo é remover o **N-ésimo nó a partir do final** da lista e retornar o nó inicial da lista modificada.

## Ideia central

Ao avançar dois ponteiros simultaneamente com um intervalo de N nós entre eles, no momento em que o ponteiro da frente alcança o final da lista, o ponteiro de trás estará posicionado imediatamente antes do nó a ser removido. Isso permite concluir a remoção com apenas uma travessia.

## Processo de raciocínio

1. **Parece necessário saber o comprimento da lista para identificar o N-ésimo nó a partir do final**: De forma ingênua, seria preciso percorrer toda a lista para obter o comprimento L e depois buscar o nó na posição L-N, exigindo duas travessias. No entanto, usando dois ponteiros, é possível resolver com apenas uma travessia
2. **Usar dois ponteiros com um intervalo de N nós**: O ponteiro fast é avançado N posições à frente do ponteiro slow. Nesse estado, ao avançar ambos simultaneamente um nó por vez, quando fast alcança o final da lista, slow estará exatamente na posição N+1 a partir do final. Ou seja, slow aponta para o nó **imediatamente antes** do nó a ser removido
3. **Motivo para adicionar um nó dummy no início**: Quando o nó a ser removido é o primeiro nó da lista (o próprio head), não existe um "nó imediatamente antes do nó a ser removido". Ao colocar um nó dummy antes do head, a remoção do primeiro nó pode ser tratada com a mesma lógica da remoção de qualquer outro nó
4. **Avançar fast N posições à frente**: Um laço for avança fast N vezes. Nesse ponto, existem N nós entre slow e fast
5. **Avançar ambos os ponteiros simultaneamente**: Enquanto `fast.next != null`, slow e fast avançam um nó por vez ao mesmo tempo. Quando o **próximo** de fast se torna null, o laço é encerrado. Nesse momento, fast aponta para o último nó da lista e slow aponta para o nó N+1 a partir do final (imediatamente antes do nó a ser removido)
6. **Remoção do nó e retorno da lista**: Como o próximo nó de slow é o nó a ser removido, a remoção é feita reassociando o ponteiro com `slow.next = slow.next.next`. Por fim, retorna-se `dummy.next`. O motivo de não retornar head diretamente é para lidar com o caso em que o próprio head foi removido

## Conhecimentos prévios

### O que é ListNode

É uma classe que representa um nó de uma lista encadeada simples. Cada nó possui um valor `val` e uma referência `next` para o próximo nó. O nó cujo `next` é null é o final da lista.

```java
ListNode node = new ListNode(5);  // Cria um nó com valor 5, next é null
node.next = new ListNode(10);     // A lista se torna node → 10 → null
```

### O que é um nó dummy (Sentinel Node)

É um nó sentinela sem valor significativo adicionado no início da lista. Mesmo no caso de remoção do primeiro nó, sempre existirá um "nó antes do nó a ser removido", eliminando a necessidade de tratamento especial para o início da lista.

```java
ListNode dummy = new ListNode(0);  // Cria o nó dummy
dummy.next = head;                 // Define o próximo do dummy como o início original
// Após o processamento, dummy.next será o novo nó inicial
```

### O que é a técnica Two-Pointer (dois ponteiros)

É uma técnica que move dois ponteiros em velocidades ou intervalos diferentes para encontrar eficientemente uma posição específica na lista. Neste problema, dois ponteiros com um intervalo de N nós são movidos na mesma velocidade para identificar a posição do N-ésimo nó a partir do final.

```java
ListNode slow = head;
ListNode fast = head;
// Após avançar fast N posições à frente, ambos avançam simultaneamente
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Basta percorrer a lista uma única vez |
| Space | O(1) — Utiliza apenas o nó dummy e dois ponteiros |

## Código

```java
// Entrada: nó inicial head de uma lista encadeada simples e um inteiro n
// Saída: retorna o nó inicial ListNode da lista após remover o N-ésimo nó a partir do final
public ListNode removeNthFromEnd(ListNode head, int n) {
    // Adiciona um nó dummy com valor 0 no início
    // Ao colocar o nó dummy, mesmo a remoção do primeiro nó terá um "nó imediatamente antes do nó a ser removido"
    ListNode dummy = new ListNode(0);
    dummy.next = head;

    // Ambos os ponteiros iniciam a partir do nó dummy
    // Ao iniciar a partir do nó dummy, slow ficará corretamente posicionado imediatamente antes do nó a ser removido
    ListNode slow = dummy;
    ListNode fast = dummy;

    // Avança fast N posições à frente para criar um intervalo de N nós entre slow e fast
    for (int i = 0; i < n; i++) {
        fast = fast.next;
    }

    // Avança ambos os ponteiros simultaneamente e para quando fast alcança o final da lista
    // A condição fast.next != null é usada para que, quando fast alcança o último nó da lista,
    // slow esteja posicionado imediatamente antes do nó a ser removido
    while (fast.next != null) {
        slow = slow.next;
        fast = fast.next;
    }

    // slow.next é o nó a ser removido. Reassocia o ponteiro next de slow para um nó à frente, desvinculando o nó a ser removido da lista
    slow.next = slow.next.next;

    // Retorna dummy.next em vez de head porque, caso head tenha sido o nó removido, isso garante o retorno correto do novo nó inicial
    return dummy.next;
}
```
