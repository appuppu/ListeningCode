# Finding the Longest Consecutive Number Sequence — Encontrar o comprimento da maior sequência consecutiva de inteiros em um array não ordenado

## Essência do Problema

Um array de inteiros `nums` (não ordenado) é fornecido. O objetivo é encontrar uma sequência de inteiros consecutivos (exemplo: 1, 2, 3, 4) dentro do array e retornar o **comprimento máximo** dessa sequência. A ordem dos elementos no array não importa; basta que os valores sejam consecutivos.

## Ideia Central

Ao contar o comprimento apenas a partir do "ponto de início" de cada sequência consecutiva, é possível eliminar cálculos redundantes. Se `num - 1` não existir no HashSet para um determinado número `num`, esse número é o ponto de início de uma sequência consecutiva. Iniciando a contagem apenas a partir dos pontos de início, o algoritmo atinge O(n) no total.

## Processo de Raciocínio

1. **Identificar o ponto de início da sequência consecutiva**: Se a contagem começar a partir de um número no meio da sequência, a mesma sequência será contada várias vezes. Apenas os números para os quais `num - 1` não existe são verdadeiros pontos de início de uma sequência consecutiva. Ao contar apenas a partir dos pontos de início, cada elemento é contado no máximo uma vez
2. **Realizar a verificação de existência de forma rápida**: Para verificar se um número está contido no array em O(1), todos os elementos são armazenados em um HashSet. Ordenar o array resolveria o problema em O(n log n), mas usar um HashSet permite resolver em O(n)
3. **Contar a sequência a partir do ponto de início**: Ao encontrar um ponto de início `num`, o algoritmo verifica sequencialmente se `num + 1`, `num + 2`, ... existem no HashSet, contando o comprimento até que a sequência seja interrompida
4. **Rastrear o comprimento máximo**: O comprimento de cada sequência consecutiva é comparado com a variável `longest`, e o valor é atualizado se for maior. O valor de `longest` após o processamento de todos os elementos é a resposta

## Conhecimentos Prévios

### O que é um HashSet

É uma estrutura de dados que armazena valores sem duplicatas. A adição de valores e a verificação de existência são realizadas em O(1). Diferente do HashMap, o HashSet armazena apenas chaves e é utilizado em situações em que se deseja verificar rapidamente se um valor "existe ou não".

```java
HashSet<Integer> set = new HashSet<>();  // Criar um HashSet vazio
set.add(4);              // Adicionar o valor 4 ao conjunto
set.add(4);              // Duplicatas são ignoradas (o número de elementos do conjunto não muda)
set.contains(4);         // Retorna um boolean indicando se o valor 4 existe → true
set.contains(5);         // Retorna um boolean indicando se o valor 5 existe → false
```

### O que é o ponto de início de uma sequência consecutiva

Para um determinado número `num`, quando `num - 1` não existe no conjunto, `num` é o primeiro número (ponto de início) da sequência consecutiva.
Exemplo: No conjunto {100, 4, 200, 1, 3, 2}, 1 é um ponto de início (0 não existe), e 2 não é um ponto de início (1 existe).

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Cada elemento é acessado no máximo 2 vezes: uma vez na verificação de ponto de início e no máximo uma vez na contagem |
| Space | O(n) — O HashSet armazena no máximo n elementos |

## Código

```java
// Entrada: array de inteiros nums (não ordenado, pode conter duplicatas)
// Saída: retorna o comprimento da maior sequência consecutiva de inteiros como int
public int longestConsecutive(int[] nums) {
    // Armazenar todos os elementos em um HashSet para permitir verificação de existência em O(1)
    // Elementos duplicados são automaticamente eliminados
    Set<Integer> numSet = new HashSet<>();
    for (int num : nums) {
        numSet.add(num);
    }

    // Variável que mantém o comprimento máximo da sequência consecutiva encontrada até o momento
    int longest = 0;

    // Percorrer cada elemento do HashSet
    for (int num : numSet) {
        // Se num - 1 não existir, num é o ponto de início de uma sequência consecutiva
        // Se num - 1 existir, num está no meio de uma sequência consecutiva e é ignorado
        // (Este número será contado quando a contagem começar a partir de outro ponto de início)
        if (!numSet.contains(num - 1)) {
            int currentNum = num;
            int length = 1;

            // Contar sequencialmente os números consecutivos a partir do ponto de início (num+1, num+2, ...)
            // O loop continua até que a sequência seja interrompida
            while (numSet.contains(currentNum + 1)) {
                currentNum++;
                length++;
            }

            // Atualizar se o comprimento da sequência consecutiva atual exceder o máximo encontrado até o momento
            longest = Math.max(longest, length);
        }
    }
    // Após percorrer todos os elementos, retornar o comprimento da maior sequência consecutiva de inteiros
    return longest;
}
```
