# Checking if Two Strings Are Anagrams — Verificar se duas strings são anagramas uma da outra

## Essência do problema

Duas strings `s` e `t` são fornecidas. O objetivo é verificar se `t` é um anagrama de `s` e retornar um **boolean**. Um anagrama é uma relação em que duas strings contêm exatamente os mesmos caracteres com a mesma frequência de ocorrência, diferindo apenas na ordem.

## Ideia central

A verificação de anagramas se reduz a "verificar se a frequência de ocorrência de cada caractere coincide perfeitamente". Como o alfabeto minúsculo possui apenas 26 tipos de caracteres, é possível gerenciar a frequência de todos os caracteres com um array de tamanho fixo 26, realizando a verificação em tempo O(n) com espaço O(1).

## Processo de raciocínio

1. **Interpretar a definição de anagrama matematicamente**: Duas strings serem anagramas significa que a frequência de ocorrência de cada caractere coincide perfeitamente. Ou seja, basta ignorar a ordem dos caracteres e comparar apenas as frequências
2. **Retornar false imediatamente se os comprimentos forem diferentes**: Como um anagrama contém os mesmos caracteres o mesmo número de vezes, strings com comprimentos diferentes não podem ser anagramas. Verificar isso primeiro evita processamento desnecessário
3. **Considerar o método de comparação de frequências**: O alfabeto minúsculo é limitado a 26 tipos, de 'a' a 'z'. Em vez de um HashMap, é possível usar um array de inteiros de tamanho fixo 26, gerenciando a frequência de cada caractere pelo índice
4. **Processar ambas as strings com um único array**: Em vez de criar dois arrays e compará-los, o sistema incrementa o array para uma string e decrementa para a outra. Se todos os elementos forem 0 no final, isso significa que as frequências coincidem perfeitamente
5. **Processar ambas no mesmo loop**: Como a igualdade dos comprimentos das strings já foi verificada previamente, é possível realizar o incremento de `s` e o decremento de `t` simultaneamente em um único loop for
6. **Verificação final**: Após o término do loop, o sistema verifica se todos os elementos do array são 0. Se houver pelo menos um elemento diferente de 0, a frequência de algum caractere não coincide, e o sistema retorna false

## Conhecimento prévio

### Conversão de caractere para índice de array

A operação `char - 'a'` converte uma letra minúscula em um inteiro de 0 a 25. Isso permite usar o caractere diretamente como índice do array.

```java
char c = 'd';
int index = c - 'a';    // 'd' - 'a' = 3 ('a'=0, 'b'=1, 'c'=2, 'd'=3)
int[] count = new int[26];
count[c - 'a']++;       // count[3] se torna 1 (registra a ocorrência de 'd')
```

### Contagem de frequência com array de tamanho fixo

Ao preparar um array de inteiros de tamanho 26, cada índice funciona como uma tabela de frequência correspondente a um caractere. Em Java, `new int[26]` inicializa todos os elementos com 0.

```java
int[] count = new int[26];  // Todos os elementos são inicializados com 0
count['b' - 'a']++;        // count[1] = 1 (registra a ocorrência de 'b')
count['b' - 'a']--;        // count[1] = 0 (cancela a ocorrência de 'b')
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Basta percorrer a string uma única vez (n é o comprimento da string) |
| Space | O(1) — O tamanho do array utilizado é sempre 26, independente do comprimento da entrada |

## Código

```java
// Entrada: duas strings s e t
// Saída: retorna true se t for um anagrama de s, caso contrário retorna false
public boolean isAnagram(String s, String t) {
    // Como um anagrama contém os mesmos caracteres o mesmo número de vezes, comprimentos diferentes significam que não é anagrama
    if (s.length() != t.length())
        return false;

    // Array que registra a "diferença" na frequência de cada letra (índice 0='a', 25='z')
    // O tamanho 26 corresponde às 26 letras de a a z
    int[] count = new int[26];

    // Processa ambas as strings simultaneamente em um único loop (a igualdade dos comprimentos já foi verificada)
    for (int i = 0; i < s.length(); i++) {
        // Incrementa para o caractere de s: registra que "este caractere apareceu 1 vez em s"
        count[s.charAt(i) - 'a']++;
        // Decrementa para o caractere de t: registra que "este caractere apareceu 1 vez em t"
        // Se o incremento e o decremento se cancelarem, a frequência desse caractere é igual em s e t
        count[t.charAt(i) - 'a']--;
    }

    // Percorre todos os 26 elementos; se houver pelo menos um diferente de 0, as frequências não coincidem
    for (int c : count) {
        if (c != 0) return false;
    }
    // Todos os elementos são 0 → as frequências de todos os caracteres coincidem → é um anagrama
    return true;
}
```
