# Computing Products Without Self Inclusion — Calcular o produto de todos os elementos excluindo o próprio

## Essência do problema

Um array de inteiros `nums` é fornecido. Para cada índice `i`, você deve calcular o produto de todos os elementos **exceto** `nums[i]` e retornar um array `result` contendo os resultados. O operador de divisão não pode ser utilizado.

## Ideia central

O produto de todos os elementos excluindo um determinado elemento pode ser decomposto em "produto de todos os elementos à esquerda desse elemento" × "produto de todos os elementos à direita desse elemento". Construindo os produtos acumulados à esquerda e à direita por meio de duas varreduras — uma para frente e outra para trás — é possível resolver o problema em O(n) sem utilizar divisão.

## Processo de raciocínio

1. **Pensar em uma decomposição alternativa, já que a divisão não é permitida**: O método de calcular o produto total e dividir por cada elemento está proibido. Portanto, decompomos `result[i]` como "produto à esquerda de `nums[i]`" × "produto à direita de `nums[i]`". Essa decomposição não requer divisão
2. **O produto acumulado à esquerda pode ser construído com uma varredura para frente**: Varrendo o array da esquerda para a direita, calculamos o "produto de todos os elementos à esquerda" para cada posição. A relação de recorrência `result[i] = result[i-1] * nums[i-1]` é válida. Como não existem elementos à esquerda do primeiro elemento, inicializamos com `result[0] = 1` (elemento neutro da multiplicação)
3. **O produto acumulado à direita pode ser construído com uma varredura para trás**: Varrendo o array da direita para a esquerda, acumulamos na variável `record` o "produto de todos os elementos à direita". Como não existem elementos à direita do último elemento, inicializamos com `record = 1`
4. **Multiplicar os dois produtos**: Durante a varredura para trás, multiplicamos `result[i]` (produto à esquerda) por `record` (produto à direita) para obter a resposta final. Após a multiplicação, atualizamos o produto à direita com `record = record * nums[i]`
5. **Não é necessário utilizar arrays adicionais**: Como o produto à esquerda é escrito diretamente no array `result` e o produto à direita é gerenciado com apenas uma variável, a memória adicional além do array de saída é O(1)

## Conhecimentos prévios

### O que é Produto Acumulado (Prefix Product / Suffix Product)

É a sequência de produtos obtida multiplicando os elementos sequencialmente a partir do início ou do final do array. Corresponde à versão multiplicativa da soma acumulada. Permite calcular eficientemente o "produto de todos os elementos até determinada posição".

```java
int[] nums = {1, 2, 3, 4};

// Produto acumulado da esquerda (prefix product)
// prefix[0] = 1 (não há elementos à esquerda)
// prefix[1] = 1 (até nums[0])
// prefix[2] = 1*2 = 2 (até nums[1])
// prefix[3] = 1*2*3 = 6 (até nums[2])

// Produto acumulado da direita (suffix product)
// suffix[3] = 1 (não há elementos à direita)
// suffix[2] = 4 (até nums[3])
// suffix[1] = 4*3 = 12 (nums[3]*nums[2])
// suffix[0] = 4*3*2 = 24 (nums[3]*nums[2]*nums[1])
```

### Elemento neutro da multiplicação

Multiplicar qualquer número por 1 não altera o seu valor. Ao utilizar 1 como valor inicial do produto acumulado, é possível aplicar a mesma relação de recorrência inclusive ao primeiro elemento.

```java
int record = 1;              // O valor inicial do produto é 1 (elemento neutro)
record = record * nums[i];   // Na primeira multiplicação, record passa a ser nums[i]
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Basta varrer o array uma vez para frente e uma vez para trás |
| Space | O(1) — Excluindo o array de saída `result`, a única memória adicional utilizada é a variável `record` |

## Código

```java
// Entrada: array de inteiros nums
// Saída: retorna um int[] contendo o produto de todos os elementos exceto o próprio para cada índice
public int[] productExceptSelf(int[] nums) {
    // Cria um array com o mesmo comprimento de nums. Primeiro armazena o produto acumulado à esquerda e depois multiplica pelo produto acumulado à direita
    int[] result = new int[nums.length];

    // Varredura para frente: armazena em result o produto de todos os elementos à esquerda de cada posição
    result[0] = 1;  // Não existem elementos à esquerda do primeiro elemento, então inicializa com 1 (elemento neutro da multiplicação)
    for (int i = 1; i < nums.length; i++) {
        // result[i-1] é o produto à esquerda até a posição i-1. Multiplicando por nums[i-1] (o elemento imediatamente à esquerda), obtemos o produto à esquerda da posição i
        result[i] = result[i - 1] * nums[i - 1];
    }

    // Varredura para trás: multiplica pelo produto acumulado à direita para completar o resultado final
    // record é a variável que acumula o "produto de todos os elementos à direita da posição atual"
    int record = 1;  // Não existem elementos à direita do último elemento, então inicializa com 1
    for (int i = nums.length - 1; i >= 0; i--) {
        // result[i] contém o produto à esquerda. Multiplicando por record (produto à direita), completamos o "produto de todos os elementos exceto o próprio"
        result[i] = record * result[i];
        // Atenção: a atualização de record deve ser feita após a finalização de result[i]. Se atualizar antes, nums[i] será incluído no produto
        record = record * nums[i];
    }

    // Retorna result, onde cada elemento contém o "produto de todos os elementos exceto o próprio"
    return result;
}
```
