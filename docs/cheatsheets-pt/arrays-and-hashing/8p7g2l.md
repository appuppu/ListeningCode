# Grouping Words by Anagram Patterns — Agrupar palavras que são anagramas entre si

## Essência do problema

Um array de strings `strs` é fornecido. O objetivo é agrupar as strings que são anagramas entre si e retornar o resultado como uma lista de grupos. Duas strings são anagramas quando contêm as mesmas letras com a mesma frequência, diferindo apenas na ordem dos caracteres.

## Ideia central

Anagramas possuem exatamente a mesma frequência de ocorrência de cada caractere. Se contarmos a frequência de cada uma das 26 letras e convertermos o resultado em uma string para usar como chave, anagramas sempre gerarão a mesma chave, permitindo agrupá-los de uma só vez com um HashMap.

## Processo de raciocínio

1. **Encontrar a propriedade comum dos anagramas**: Anagramas diferem apenas na ordem dos caracteres, e a frequência de ocorrência de cada caractere é exatamente igual. Essa "igualdade de frequências" pode ser usada como critério de agrupamento
2. **Como representar a frequência de ocorrência**: Como existem 26 tipos de letras minúsculas, preparamos um array de inteiros `count` de tamanho 26 e contamos a frequência de cada caractere. Se o conteúdo desse array for igual entre duas palavras, elas são anagramas
3. **Como usar o array como chave do HashMap**: Em Java, não é possível usar um array diretamente como chave de um HashMap (pois a comparação seria por referência). Por isso, concatenamos cada elemento do array separado por `#` em uma string (exemplo: `"1#0#0#...#"`) e usamos essa string como chave. Dessa forma, palavras com a mesma frequência geram a mesma chave
4. **Agrupar com o HashMap**: Basta inserir palavras com a mesma chave na mesma lista. Usando `computeIfAbsent`, quando a chave ainda não está registrada, uma nova lista é criada automaticamente; quando já está registrada, a lista existente é retornada, permitindo adicionar palavras sem necessidade de condicionais
5. **O que retornar no final**: Converter todos os valores do HashMap (a lista de cada grupo) em um `ArrayList` e retornar

## Conhecimentos prévios

### O que é um HashMap

Uma estrutura de dados que armazena pares de chave e valor. A busca e a obtenção de valores por chave são realizadas em O(1). Funciona como um dicionário que permite acesso por qualquer chave com a mesma velocidade do acesso por índice em um array.

```java
HashMap<String, List<String>> map = new HashMap<>();  // Cria um HashMap vazio
map.put("key", new ArrayList<>());  // Armazena uma lista vazia na chave "key"
map.containsKey("key");             // Retorna um boolean indicando se a chave "key" existe → true
map.get("key");                     // Retorna o valor correspondente à chave "key" → []
map.values();                       // Retorna todos os valores como uma Collection
```

### O que é computeIfAbsent

Um método do HashMap. Se a chave especificada não existir, o método gera um valor usando a expressão lambda do segundo argumento, registra esse valor e o retorna. Se a chave já existir, retorna o valor existente diretamente. Permite escrever em uma única linha a lógica condicional baseada na existência da chave.

```java
// Se a chave "abc" não estiver registrada, cria um novo ArrayList, registra e retorna essa lista
// Se a chave "abc" já estiver registrada, retorna a lista existente diretamente
map.computeIfAbsent("abc", k -> new ArrayList<>()).add("cab");
```

### Contagem da frequência de caracteres

Ao subtrair `'a'` de um caractere do tipo `char`, é possível convertê-lo em um índice onde a=0, b=1, ..., z=25. Preparando um array de tamanho 26 e incrementando a posição correspondente ao índice, registramos a frequência de ocorrência de cada caractere.

```java
int[] count = new int[26];           // Cria um array de contagem para 26 letras (todos os valores iniciais são 0)
for (char c : "eat".toCharArray())   // Percorre a string caractere por caractere
    count[c - 'a']++;                // Incrementa a posição correspondente ao caractere
// Resultado: count[0]=1(a), count[4]=1(e), count[19]=1(t), os demais são 0
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n × k) — n é o número de strings e k é o comprimento médio das strings. Para cada string, realiza-se a contagem de caracteres e a geração de uma chave de tamanho 26 |
| Space | O(n × k) — Todas as strings são armazenadas no HashMap; cada chave tem tamanho fixo, mas as próprias strings ocupam memória proporcional a k caracteres |

## Código

```java
// Entrada: array de strings strs
// Saída: retorna uma List<List<String>> com as strings agrupadas por anagramas
public List<List<String>> groupAnagrams(String[] strs) {
    // HashMap que armazena chave=representação em string da frequência, valor=lista de palavras pertencentes a essa chave
    // Palavras com a mesma chave são anagramas entre si
    Map<String, List<String>> map = new HashMap<>();

    // Percorre cada string s do array strs do início ao fim, uma por uma
    for (String s : strs) {
        // Cria um array de tamanho 26 para registrar a frequência de cada caractere (a–z) (todos os valores iniciais são 0)
        // Um novo array é criado para cada string para evitar que o resultado da contagem anterior permaneça
        int[] count = new int[26];
        // Converte a string em um array de caracteres com toCharArray() e conta a frequência de cada caractere c
        for (char c : s.toCharArray())
            // c - 'a' converte o caractere c em um índice de 0 a 25 e o incrementa
            count[c - 'a']++;

        // Converte o array de frequências em uma chave no formato "1#0#0#..."
        // Essa chave representa de forma única a frequência dos caracteres, e anagramas sempre geram a mesma chave
        // O separador # entre os elementos garante que contagens diferentes não resultem na mesma string
        StringBuilder sb = new StringBuilder();
        for (int n : count)
            sb.append(n).append('#');
        String key = sb.toString();

        // Se a chave não estiver registrada, cria uma nova lista e adiciona a string atual à lista
        // Dessa forma, palavras com a mesma chave são acumuladas na mesma lista
        map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
    }

    // Obtém a coleção de todos os grupos e a converte em uma List<List<String>> para retornar
    return new ArrayList<>(map.values());
}
```
