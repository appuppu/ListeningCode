# Three Sum — Encontrar todos os tripletos cuja soma é zero

## Essência do Problema

Um array de inteiros `nums` é fornecido. O objetivo é encontrar todas as combinações de 3 elementos (tripletos) em `nums` cuja soma seja `0` e retorná-las como `List<List<Integer>>`. Cada tripleto deve ser composto por elementos de índices diferentes, e o resultado não deve conter tripletos duplicados.

## Ideia Central

Ao ordenar o array, é possível fixar um elemento e buscar os outros dois de forma eficiente usando Two Pointers. Além disso, a ordenação permite pular valores duplicados, eliminando naturalmente os tripletos repetidos.

## Processo de Raciocínio

1. **Reduzir o problema de 3 elementos para 2 elementos**: A equação `a + b + c = 0` com três números pode ser transformada em `b + c = -a` ao fixar um elemento `a = nums[i]`. Ao fixar `a` no laço externo e buscar `b` e `c` no laço interno, é possível aplicar a mesma abordagem do Two Sum
2. **Ordenar o array para usar Two Pointers**: Para buscar os dois elementos de forma eficiente, o método Two Pointers é eficaz: ordena-se o array e aproximam-se os ponteiros das extremidades esquerda e direita. Se a soma for pequena demais, move-se o ponteiro esquerdo para a direita; se for grande demais, move-se o ponteiro direito para a esquerda, explorando todos os pares de forma eficiente
3. **Eliminar tripletos duplicados utilizando a ordenação**: Em um array ordenado, valores iguais ficam adjacentes. Se `nums[i]` no laço externo tiver o mesmo valor que o elemento anterior, ele é pulado. No laço interno, após encontrar um par, `left` e `right` também são avançados enquanto houver valores iguais consecutivos, evitando a inclusão de tripletos duplicados no resultado
4. **Definir o intervalo do laço externo**: Como são necessários 3 elementos, `i` percorre de `0` até `nums.length - 3`. `left` inicia em `i + 1` e `right` em `nums.length - 1`, e a busca continua enquanto `left < right`
5. **Mover os ponteiros de acordo com o valor da soma**: Se `sum == 0`, o tripleto é adicionado ao resultado e, após pular duplicatas, ambos os ponteiros avançam para dentro. Se `sum < 0`, move-se `left` para a direita para aumentar a soma. Se `sum > 0`, move-se `right` para a esquerda para diminuir a soma
6. **Retorno final**: Após explorar todas as combinações de elementos fixos e ponteiros, a lista `result` acumulada é retornada diretamente

## Conhecimentos Prévios

### O que é Two Pointers

É uma técnica que posiciona dois ponteiros (`left` e `right`) nas extremidades de um array ordenado e move um deles de acordo com a condição, permitindo explorar todos os pares em O(n). Se a soma for menor que o alvo, move-se `left` para a direita (aumentando o valor); se for maior, move-se `right` para a esquerda (diminuindo o valor).

```java
int left = 0;
int right = nums.length - 1;
while (left < right) {
    int sum = nums[left] + nums[right];
    if (sum == target) {
        // Par encontrado
    } else if (sum < target) {
        left++;    // Move o ponteiro esquerdo para a direita para aumentar a soma
    } else {
        right--;   // Move o ponteiro direito para a esquerda para diminuir a soma
    }
}
```

### O que é Arrays.sort()

É um método padrão do Java que ordena um array em ordem crescente. Após a ordenação, valores iguais ficam adjacentes, facilitando a detecção de duplicatas.

```java
int[] nums = {4, -1, 2, -1, 0};
Arrays.sort(nums);    // nums se torna {-4, -1, -1, 0, 2} (ordem crescente)
```

### O que é Arrays.asList()

É um método que gera uma `List` de tamanho fixo a partir de argumentos variáveis. É utilizado para adicionar tripletos como `List<Integer>` à lista de resultados.

```java
List<Integer> triplet = Arrays.asList(-1, 0, 1);  // Gera a lista [-1, 0, 1]
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n²) — O laço externo é O(n) e o Two Pointers interno é O(n), totalizando O(n²) |
| Space | O(1) — Excluindo a ordenação, utiliza-se apenas variáveis de ponteiros, sem espaço adicional |

## Código

```java
// Entrada: array de inteiros nums
// Saída: List<List<Integer>> contendo todos os tripletos únicos cuja soma é 0
public List<List<Integer>> threeSum(int[] nums) {
    // Lista de resultados para acumular todos os tripletos encontrados
    List<List<Integer>> result = new ArrayList<>();
    // Ordena o array em ordem crescente (pré-requisito para Two Pointers + pular duplicatas)
    Arrays.sort(nums);

    // i percorre de 0 até nums.length - 3. nums[i] é o elemento fixo do tripleto
    for (int i = 0; i < nums.length - 2; i++) {
        // Se o elemento fixo tiver o mesmo valor que o anterior, pula para evitar tripletos duplicados
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue;
        }
        // Posiciona os ponteiros esquerdo e direito logo após o elemento fixo e no final do array, buscando pares nesse intervalo
        int left = i + 1;
        int right = nums.length - 1;

        while (left < right) {
            // Calcula a soma dos três elementos
            int sum = nums[i] + nums[left] + nums[right];

            if (sum == 0) {
                // Adiciona o tripleto com soma zero ao resultado
                result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                // Pula valores duplicados no lado do ponteiro esquerdo (avança para a direita enquanto o valor for igual)
                while (left < right && nums[left] == nums[left + 1]) {
                    left++;
                }
                // Pula valores duplicados no lado do ponteiro direito (avança para a esquerda enquanto o valor for igual)
                while (left < right && nums[right] == nums[right - 1]) {
                    right--;
                }
                // Após pular duplicatas, avança ambos os ponteiros uma posição para dentro para buscar o próximo par
                left++;
                right--;
            } else if (sum < 0) {
                // A soma é negativa, então move o ponteiro esquerdo para a direita para aumentar a soma
                left++;
            } else {
                // A soma é positiva, então move o ponteiro direito para a esquerda para diminuir a soma
                right--;
            }
        }
    }

    // A exploração de todos os elementos fixos foi concluída. Todos os tripletos sem duplicatas estão armazenados
    return result;
}
```
