# Finding Two Numbers in a Sorted Array That Add Up to a Target — Encontrar dois números em um array ordenado cuja soma é igual ao alvo

## Essência do problema

Um array de inteiros ordenado `nums` e um inteiro `target` são fornecidos. O objetivo é encontrar dois elementos em `nums` cuja soma seja igual a `target` e retornar suas **posições em 1-indexed** em um array. A solução é sempre única, e o mesmo elemento não pode ser usado duas vezes.

## Ideia central

Como o array está ordenado, é possível usar dois ponteiros nas extremidades para convergir ao centro. Se a soma dos dois elementos for grande demais, o ponteiro direito recua; se for pequena demais, o ponteiro esquerdo avança. Assim, a resposta é encontrada em uma única varredura com tempo O(n) e espaço O(1).

## Processo de raciocínio

1. **Aproveitar a condição de array ordenado**: Como o array está ordenado, a extremidade esquerda aponta para o menor valor e a extremidade direita aponta para o maior valor. Ao iniciar a busca pela soma dessas duas extremidades, é possível estreitar o intervalo de busca de forma confiável conforme a soma seja maior ou menor que o alvo
2. **Se a soma for grande demais, mover o ponteiro direito para a esquerda**: O ponteiro direito aponta para o maior valor no intervalo de busca atual. Se a soma for maior que `target`, o ponteiro direito é movido uma posição para a esquerda para trocar por um valor menor e reduzir a soma
3. **Se a soma for pequena demais, mover o ponteiro esquerdo para a direita**: O ponteiro esquerdo aponta para o menor valor no intervalo de busca atual. Se a soma for menor que `target`, o ponteiro esquerdo é movido uma posição para a direita para trocar por um valor maior e aumentar a soma
4. **Se a soma for exatamente igual a `target`, a resposta foi encontrada**: Quando a soma dos valores apontados pelos dois ponteiros é igual a `target`, esse é o par procurado. Como o problema exige 1-indexed, adiciona-se 1 à posição de cada ponteiro antes de retornar
5. **Condição de término do loop**: O loop se repete até que o ponteiro esquerdo alcance o ponteiro direito. Pelas restrições do problema, a solução sempre existe, portanto a resposta é encontrada antes que os ponteiros se cruzem
6. **O que retornar ao final**: No momento em que a soma é igual a `target`, retorna-se um `int[]` contendo `left + 1` (posição 1-indexed do elemento esquerdo) e `right + 1` (posição 1-indexed do elemento direito)

## Conhecimentos prévios

### O que é Two Pointers (dois ponteiros)

É uma técnica que utiliza duas variáveis de índice apontando para posições diferentes do array, movendo cada uma conforme a condição. Em arrays ordenados, o padrão típico é estreitar o intervalo de busca convergindo das extremidades para o centro.

```java
int left = 0;                    // Posiciona o ponteiro esquerdo no início do array
int right = nums.length - 1;     // Posiciona o ponteiro direito no final do array
while (left < right) {           // Repete o loop até que os dois ponteiros se cruzem
    // Move left e right conforme a condição
    left++;   // Avança o ponteiro esquerdo uma posição para a direita
    right--;  // Recua o ponteiro direito uma posição para a esquerda
}
```

### Propriedades de um array ordenado

Quando o array está ordenado em ordem crescente, `nums[left] <= nums[right]` sempre é verdadeiro. Mover o ponteiro esquerdo para a direita aumenta a soma, e mover o ponteiro direito para a esquerda diminui a soma. É justamente essa monotonicidade que permite determinar a direção de movimento dos dois ponteiros com base na comparação da soma com o alvo.

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Os dois ponteiros percorrem no máximo n movimentos no total |
| Space | O(1) — Utiliza apenas variáveis para os ponteiros, sem estruturas de dados adicionais |

## Código

```java
// Entrada: array de inteiros ordenado nums e inteiro target
// Saída: retorna um int[] contendo as posições 1-indexed dos dois elementos cuja soma é igual a target
public int[] twoSum(int[] nums, int target) {
    // Posiciona o ponteiro esquerdo no início do array. É a extremidade esquerda do intervalo de busca e representa o lado dos menores valores
    int left = 0;
    // Posiciona o ponteiro direito no final do array. É a extremidade direita do intervalo de busca e representa o lado dos maiores valores
    int right = nums.length - 1;

    // Repete o loop até que os dois ponteiros se cruzem
    while (left < right) {
        // Calcula a soma dos dois elementos atuais e armazena em uma variável para reutilizar em cada ramificação
        int cursum = nums[left] + nums[right];

        if (cursum == target) {
            // A soma é igual ao alvo, portanto o par foi encontrado. Como o problema exige 1-indexed, adiciona 1 a cada índice antes de retornar
            return new int[]{left + 1, right + 1};
        } else if (cursum > target) {
            // A soma é grande demais, então o ponteiro direito é movido para a esquerda. O valor apontado pelo ponteiro direito se torna menor, e a soma diminui na próxima iteração
            right--;
        } else {
            // A soma é pequena demais, então o ponteiro esquerdo é movido para a direita. O valor apontado pelo ponteiro esquerdo se torna maior, e a soma aumenta na próxima iteração
            left++;
        }
    }
    // Pelas restrições do problema, a solução sempre existe, portanto este ponto nunca é alcançado
    return new int[]{};
}
```
