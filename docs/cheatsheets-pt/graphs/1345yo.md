# Finding a Valid Order to Complete All Courses — Encontrar uma ordem válida para concluir todos os cursos

## Essência do Problema

São dados cursos rotulados de 0 a `numCourses - 1` e um array de pares de pré-requisitos `[a, b]` (o curso `b` deve ser cursado antes do curso `a`). Retorne um array com uma **ordem válida de conclusão** de todos os cursos. Se não existir uma ordem válida (quando há dependência circular), retorne um array vazio.

## Ideia Central

As dependências de pré-requisitos podem ser representadas como um grafo direcionado, e a ordem válida de conclusão corresponde a uma ordenação topológica desse grafo. Processando os nós com grau de entrada 0 (cursos sem pré-requisitos) em sequência e removendo as dependências dos nós já processados, é possível ordenar todos os nós corretamente, desde que não haja ciclos.

## Processo de Raciocínio

1. **Modelar as dependências como um grafo**: O pré-requisito `[a, b]` significa uma aresta direcionada "`b` → `a`". Representando todos os pré-requisitos como arestas de um grafo direcionado, a ordem válida de conclusão corresponde à ordenação topológica desse grafo.
2. **Determinar quais cursos podem ser iniciados**: Cursos sem nenhum pré-requisito, ou seja, com grau de entrada (número de arestas que chegam ao nó) igual a 0, podem ser cursados imediatamente. Calculando o grau de entrada para cada nó, é possível identificar os cursos iniciais em O(1).
3. **Refletir o impacto após processar os cursos disponíveis**: Quando um curso é marcado como concluído, o "número de pré-requisitos restantes" dos outros cursos que dependiam dele diminui em 1. Isso é representado como um decremento do grau de entrada. Se o grau de entrada de um curso chegar a 0 após o decremento, esse curso se torna disponível para ser cursado.
4. **Gerenciar a ordem de processamento com BFS**: Insira os cursos com grau de entrada 0 na fila, e a cada extração da fila, adicione o curso ao array de resultados e decremente o grau de entrada dos nós adjacentes. Se o grau de entrada de um nó chegar a 0 após o decremento, adicione-o à fila. Essa repetição é o algoritmo de Kahn.
5. **Detecção de dependência circular**: Se houver um ciclo, o grau de entrada de todos os nós no ciclo nunca chegará a 0. Portanto, se o número de cursos processados for menor que `numCourses`, pode-se determinar que existe um ciclo.
6. **O que retornar ao final**: Se o número de cursos processados for igual a `numCourses`, retorne o array de resultados; caso contrário, retorne um array vazio.

## Conhecimentos Prévios

### O que é Ordenação Topológica

É o processo de alinhar todos os nós de um grafo acíclico direcionado (DAG) em uma sequência de modo que todas as arestas apontem da esquerda para a direita. Se existe uma aresta `u → v`, então `u` sempre aparece antes de `v` na sequência. Se houver um ciclo, a ordenação topológica é impossível.

### O que é Grau de Entrada (in-degree)

É o número de arestas que chegam a um determinado nó. Nós com grau de entrada 0 não dependem de nenhum outro nó, portanto podem ser processados primeiro.

```java
int[] indegree = new int[numCourses];  // Inicializa o grau de entrada de cada nó com 0
indegree[a]++;  // Incrementa o grau de entrada do nó a em 1, pois uma aresta chega até ele
--indegree[next];  // Decrementa o grau de entrada do nó next em 1 (um pré-requisito foi satisfeito)
```

### O que é Lista de Adjacência (Adjacency List)

É uma estrutura de dados que, para cada nó do grafo, gerencia em uma lista os nós de destino das arestas que partem desse nó. Com `graph.get(u)` é possível obter todos os nós alcançáveis a partir do nó `u`.

```java
List<List<Integer>> graph = new ArrayList<>();       // Lista que armazena o grafo inteiro
for (int i = 0; i < n; i++) graph.add(new ArrayList<>());  // Atribui uma lista vazia a cada nó
graph.get(u).add(v);   // Adiciona uma aresta do nó u para o nó v
graph.get(u);           // Obtém todos os nós adjacentes ao nó u → [v, ...]
```

### O que é uma Queue (Fila)

É uma estrutura de dados do tipo primeiro a entrar, primeiro a sair (FIFO). No BFS, os nós aguardando processamento são gerenciados em uma fila.

```java
Queue<Integer> queue = new LinkedList<>();  // Cria uma fila vazia
queue.offer(0);   // Adiciona o elemento 0 ao final da fila
queue.poll();      // Remove e retorna o elemento do início da fila → 0
queue.isEmpty();   // Retorna um boolean indicando se a fila está vazia → true
```

## Complexidade

| | Valor |
|---|---|
| Time | O(V + E) — Processa cada nó (curso) e cada aresta (pré-requisito) exatamente uma vez |
| Space | O(V + E) — A lista de adjacência armazena todas as arestas; o array de grau de entrada, a fila e o array de resultados armazenam todos os nós |

## Código

```java
// Entrada: inteiro numCourses (número total de cursos) e array bidimensional de inteiros prerequisites (array de pares de pré-requisitos)
// Saída: retorna um int[] contendo a ordem válida de conclusão de todos os cursos. Se não existir uma ordem válida, retorna um int[] vazio
public int[] findOrder(int numCourses, int[][] prerequisites) {
    // Cria a lista de adjacência e atribui uma lista vazia a cada curso
    // Cada índice corresponde a um número de curso e armazena a lista de cursos que se tornam disponíveis após a conclusão desse curso
    List<List<Integer>> graph = new ArrayList<>();
    // Array de grau de entrada: representa o número de pré-requisitos não concluídos de cada curso
    int[] indegree = new int[numCourses];
    for (int i = 0; i < numCourses; i++)
        graph.add(new ArrayList<>());

    // Cria as arestas a partir dos pré-requisitos e calcula o grau de entrada
    // Para cada par [a, b], cria a aresta b → a, registrando que o curso a depende do curso b
    for (int[] pre : prerequisites) {
        graph.get(pre[1]).add(pre[0]);  // Adiciona a aresta pre[1] → pre[0]
        indegree[pre[0]]++;  // Incrementa o grau de entrada do curso pre[0] em 1
    }

    // Adiciona à fila os cursos com grau de entrada 0 (sem pré-requisitos)
    // Esses são os cursos que podem ser cursados primeiro
    Queue<Integer> queue = new LinkedList<>();
    for (int i = 0; i < numCourses; i++)
        if (indegree[i] == 0) queue.offer(i);

    // Inicializa o array de resultados e a posição de escrita
    int[] result = new int[numCourses];
    int idx = 0;

    while (!queue.isEmpty()) {
        // Remove um curso da fila e o confirma na ordem de conclusão
        int course = queue.poll();
        result[idx++] = course;

        // Decrementa o grau de entrada de todos os nós adjacentes next de course em 1
        // Isso reflete o fato de que course, um dos pré-requisitos de next, foi concluído
        for (int next : graph.get(course))
            // Se o grau de entrada chegar a 0 após o decremento, todos os pré-requisitos de next foram concluídos, então adiciona-o à fila
            if (--indegree[next] == 0)
                queue.offer(next);
    }

    // Verifica se todos os cursos foram processados
    // Se idx for menor que numCourses, existe uma dependência circular, portanto retorna um array vazio
    return idx == numCourses ? result : new int[0];
}
```
