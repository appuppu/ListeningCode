# Checking if a Graph Forms a Valid Tree — Verificar se um grafo forma uma árvore válida

## Essência do problema

São dados `n` nós rotulados de `0` a `n-1` e uma lista de arestas não direcionadas `edges`. O objetivo é determinar se esse grafo forma uma **árvore válida (valid tree)** e retornar um `boolean`. Uma árvore válida é um grafo em que todos os nós estão conectados e não existe nenhum ciclo.

## Ideia central

Uma árvore com `n` nós possui exatamente `n-1` arestas e não contém ciclos. Ao verificar primeiro se o número de arestas é `n-1` e depois usar Union-Find para unir cada aresta detectando a presença de ciclos, é possível determinar se o grafo é uma árvore.

## Processo de raciocínio

1. **Utilizar a condição necessária de uma árvore**: Uma árvore válida possui obrigatoriamente `n-1` arestas. Se o número de arestas não for `n-1`, é possível determinar imediatamente que não é uma árvore. Essa verificação prévia elimina tanto o caso de arestas em excesso (ciclo garantido) quanto o caso de arestas insuficientes (grafo desconexo)
2. **Considerar o método de detecção de ciclos**: Mesmo que o número de arestas seja `n-1`, pode existir um ciclo (nesse caso o grafo seria desconexo). Ao verificar, a cada aresta adicionada, se ambos os nós já pertencem ao mesmo componente conexo, é possível detectar ciclos
3. **Gerenciar componentes conexos com Union-Find**: Usando Union-Find (estrutura de conjuntos disjuntos), é possível executar tanto a verificação se dois nós pertencem ao mesmo componente conexo (find) quanto a fusão de dois componentes (union) em tempo praticamente O(1). Cada nó é inicializado com o pai apontando para si mesmo, e a operação union é executada para cada aresta
4. **Definir a condição de detecção de ciclo**: Durante a operação union, se a raiz dos dois nós for a mesma, eles já estão conectados. Adicionar mais uma aresta entre eles criaria um ciclo, portanto retorna-se `false`
5. **Retornar o resultado após processar todas as arestas**: Se nenhum ciclo for detectado após processar todas as arestas, combinado com o fato de que o número de arestas é `n-1` (verificado no passo 1), o grafo é determinado como uma árvore válida e retorna-se `true`

## Conhecimentos prévios

### O que é Union-Find (estrutura de conjuntos disjuntos)

É uma estrutura de dados que gerencia múltiplos elementos divididos em grupos (conjuntos). Fornece duas operações: `find` retorna o representante (raiz) do grupo ao qual um elemento pertence. `union` funde os grupos de dois elementos em um só. Com otimizações de compressão de caminho e union por rank, cada operação é executada em tempo praticamente O(1).

```java
int[] parent = {0, 1, 2, 3, 4};  // Estado inicial: o pai de cada nó é ele mesmo
int[] rank = new int[5];          // Inicializa o rank (limite superior da altura da árvore) de cada nó com 0

// find: retorna a raiz do nó x (com compressão de caminho)
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // Compressão de caminho: redireciona o pai diretamente para a raiz
    return parent[x];
}
```

### O que é compressão de caminho (Path Compression)

É uma técnica de otimização que, a cada chamada de `find`, redireciona o pai de todos os nós no caminho de busca diretamente para a raiz. Isso faz com que chamadas subsequentes de `find` se aproximem de O(1). É implementada pela atribuição recursiva `parent[x] = find(parent[x])`.

### O que é union por rank (Union by Rank)

É uma técnica que, ao fundir duas árvores, coloca a de menor rank (limite superior da altura) abaixo da de maior rank. Isso suprime o aumento da altura da árvore e mantém curta a distância de busca do `find`. O rank só é incrementado em 1 quando ambos os ranks são iguais.

```java
// union: funde os grupos dos nós a e b. Retorna false se já pertencerem ao mesmo grupo
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // Obtém a raiz de cada nó
    if (ra == rb) return false;       // Mesma raiz → mesmo grupo → ciclo
    if (rank[ra] < rank[rb])
        parent[ra] = rb;             // Coloca o de menor rank abaixo do de maior rank
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;             // Se os ranks são iguais, coloca rb abaixo de ra
        rank[ra]++;                   // Incrementa o rank em 1
    }
    return true;
}
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n × α(n)) — Executa find e union para cada aresta. α(n) é a função inversa de Ackermann, que na prática pode ser considerada constante |
| Space | O(n) — Armazena n elementos no array parent e n elementos no array rank |

## Código

```java
// Entrada: inteiro n (número de nós) e array bidimensional de inteiros edges (cada elemento é uma aresta não direcionada [u, v])
// Saída: retorna true se o grafo for uma árvore válida, caso contrário retorna false

// Array parent: gerencia o pai de cada nó
int[] parent, rank;

// Retorna a raiz do componente conexo ao qual o nó x pertence (com compressão de caminho)
int find(int x) {
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // Compressão de caminho: redireciona o pai diretamente para a raiz
    return parent[x];
}

// Funde os componentes conexos dos nós a e b. Retorna false se criar um ciclo
boolean union(int a, int b) {
    int ra = find(a), rb = find(b);  // Obtém a raiz de ambos os nós
    if (ra == rb) return false;       // Mesma raiz significa que um ciclo seria criado → adicionar esta aresta criaria um ciclo
    // Coloca o de menor rank abaixo do de maior rank para suprimir a altura da árvore
    if (rank[ra] < rank[rb])
        parent[ra] = rb;
    else if (rank[ra] > rank[rb])
        parent[rb] = ra;
    else {
        parent[rb] = ra;
        rank[ra]++;
    }
    return true;
}

public boolean validTree(int n, int[][] edges) {
    // O número de arestas de uma árvore deve ser número de nós - 1 (se houver mais, há ciclo; se houver menos, o grafo é desconexo)
    if (edges.length != n - 1)
        return false;

    // Inicializa o pai de cada nó como ele mesmo (cada nó forma um componente conexo independente)
    parent = new int[n];
    rank = new int[n];
    for (int i = 0; i < n; i++)
        parent[i] = i;

    // Processa cada aresta; se ambos os extremos já pertencerem ao mesmo componente conexo, há ciclo, então retorna false
    for (int[] e : edges)
        if (!union(e[0], e[1]))
            return false;

    // Todas as arestas foram processadas sem detectar ciclo e o número de arestas é n-1, portanto é uma árvore válida
    return true;
}
```
