# Merging Overlapping Intervals — Unificar todos os intervalos sobrepostos

## Essência do Problema

Um array de intervalos `intervals` (pares de valor inicial e valor final) é fornecido. O objetivo é unificar (merge) todos os intervalos sobrepostos e retornar uma lista de intervalos sem sobreposição.

## Ideia Central

Se os intervalos forem ordenados pelo valor inicial, apenas intervalos adjacentes podem se sobrepor. Após a ordenação, percorra sequencialmente desde o início: se o intervalo atual se sobrepõe ao intervalo anterior, atualize o valor final; caso contrário, adicione-o como um novo intervalo.

## Processo de Raciocínio

1. **Simplificar a verificação de sobreposição**: Se os intervalos não estiverem ordenados, é necessário comparar todos os pares. Ao ordenar em ordem crescente pelo valor inicial, a verificação de sobreposição se resume a "o valor final do intervalo anterior ≥ o valor inicial do intervalo atual"
2. **Após a ordenação, a unificação pode ser feita em uma única varredura**: Percorra os intervalos ordenados desde o início. Compare o último intervalo da lista de resultados com o intervalo atual; se houver sobreposição, atualize o valor final para o maior dos dois. Se não houver sobreposição, adicione o intervalo atual diretamente à lista de resultados
3. **É necessário acessar o final da lista de resultados**: Na verificação de unificação, sempre se faz referência ao valor final do "último intervalo adicionado" na lista de resultados. Usando LinkedList, é possível acessar o final em O(1) com `getLast()`
4. **Definir a condição de sobreposição com precisão**: Quando o valor final do intervalo anterior é menor que o valor inicial do intervalo atual (`res.getLast()[1] < interval[0]`), os dois intervalos não se sobrepõem. Nos demais casos (valor final ≥ valor inicial), há sobreposição e os intervalos devem ser unificados
5. **Na unificação, apenas o valor final é atualizado**: Como os valores iniciais já estão ordenados, o intervalo anterior sempre possui um valor inicial menor ou igual. Para o valor final, adota-se o maior entre os dois intervalos. Usa-se `Math.max()` para comparar o valor final anterior com o valor final atual
6. **O que retornar ao final**: Converte-se todos os intervalos não sobrepostos acumulados na lista de resultados em um array bidimensional `int[][]` e o retorna

## Conhecimentos Prévios

### Arrays.sort e Comparator personalizado

`Arrays.sort` é um método que ordena arrays. No caso de arrays bidimensionais, define-se um Comparator com expressão lambda para especificar qual elemento será usado como critério de ordenação.

```java
int[][] intervals = {{3, 6}, {1, 3}, {2, 5}};
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);  // Ordena em ordem crescente pelo valor inicial (índice 0) de cada intervalo
// Resultado: {{1, 3}, {2, 5}, {3, 6}}
```

### O que é LinkedList

É uma lista que permite adição no início/final e obtenção do final em O(1). Diferentemente de ArrayList, é possível acessar diretamente o último elemento com o método `getLast()`.

```java
LinkedList<int[]> res = new LinkedList<>();  // Cria uma LinkedList vazia
res.add(new int[]{1, 3});   // Adiciona um elemento ao final
res.getLast();               // Obtém o último elemento → {1, 3}
res.getLast()[1] = 5;        // Modifica diretamente o valor final do último elemento → {1, 5}
res.isEmpty();               // Retorna um boolean indicando se a lista está vazia → false
res.size();                  // Retorna o número de elementos da lista → 1
```

### O que é Math.max

É um método que retorna o maior entre dois valores. Na unificação de intervalos, é utilizado para adotar o maior entre os dois valores finais.

```java
Math.max(5, 8);   // → 8
Math.max(10, 3);  // → 10
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n log n) — A ordenação é O(n log n) e a varredura é O(n), portanto o total é O(n log n) |
| Space | O(n) — A lista de resultados armazena no máximo n intervalos |

## Código

```java
// Entrada: array bidimensional de intervalos int[][] intervals (cada elemento é [valor inicial, valor final])
// Saída: retorna um array bidimensional int[][] após unificar os intervalos sobrepostos
public int[][] merge(int[][] intervals) {
    // Ao ordenar, a verificação de sobreposição se limita apenas à comparação de intervalos adjacentes
    Arrays.sort(intervals, (a, b) -> a[0] - b[0]);

    // Lista de resultados que acumula os intervalos já unificados
    // Usa-se LinkedList porque permite referência e atualização do último elemento em O(1)
    LinkedList<int[]> res = new LinkedList<>();

    for (int[] interval : intervals) {
        // Se res estiver vazio, é o primeiro intervalo, então adiciona incondicionalmente
        // Se res.getLast()[1] < interval[0], não há sobreposição com o intervalo anterior, então adiciona diretamente
        if (res.isEmpty() || res.getLast()[1] < interval[0]) {
            res.add(interval);
        } else {
            // Se houver sobreposição, atualiza o valor final para o maior dos dois, realizando a unificação
            // O valor inicial não precisa ser alterado, pois está ordenado e o do intervalo anterior é menor ou igual
            res.getLast()[1] = Math.max(res.getLast()[1], interval[1]);
        }
    }

    // Converte a lista de resultados em um array bidimensional e o retorna
    return res.toArray(new int[res.size()][]);
}
```
