# Checking Validity of a Parenthesis String With Wildcards — Determinar a validade de uma string de parênteses com curingas

## Essência do problema

É fornecida uma string composta apenas por três tipos de caracteres: `(`, `)` e `*`. O caractere `*` pode ser tratado como `(`, `)` ou uma string vazia. O objetivo é determinar se essa string pode se tornar uma **sequência válida de parênteses** e retornar um `boolean`.

## Ideia central

Como o tratamento de `*` é indeterminado, rastreamos a contagem de parênteses de abertura não como um único valor, mas como um "intervalo possível (mínimo low ~ máximo high)". Se esse intervalo permanecer válido durante toda a varredura e contiver 0 no final, a string é válida.

## Processo de raciocínio

1. **A validade dos parênteses pode ser determinada pela contagem de parênteses de abertura**: Varremos a string da esquerda para a direita, incrementando +1 para `(` e decrementando -1 para `)`. Se a contagem ficar negativa durante a varredura, a string é inválida; se for 0 no final, é válida. Este é o princípio básico da validação de parênteses
2. **Com `*`, a contagem não se define em um único valor**: Como `*` pode ser interpretado de 3 formas, a contagem não é um valor único, mas um "intervalo". Se interpretarmos `*` como `(`, a contagem aumenta +1; como `)`, diminui -1; como string vazia, ±0. Ou seja, a cada `*` encontrado, o intervalo se expande
3. **Rastreamos o intervalo com duas variáveis**: `low` representa o valor mínimo da contagem de parênteses de abertura (quando tratamos `*` o máximo possível como `)` ou string vazia), e `high` representa o valor máximo (quando tratamos `*` o máximo possível como `(`). Apenas essas 2 variáveis cobrem todos os padrões
4. **Se `high` ficar negativo durante a varredura, determinamos imediatamente que é inválido**: Como `high` é o valor máximo da contagem de parênteses de abertura, se ele ficar negativo, isso significa que, independentemente da interpretação escolhida para `*`, há excesso de `)`, e não é possível formar uma sequência válida de parênteses
5. **Se `low` ficar negativo, fazemos o clamping para 0**: O `low` ficar negativo apenas indica que estamos incluindo uma "interpretação que deixa `)` sobrando", mas podemos manter a contagem em 0 ou mais tratando `*` como string vazia. Valores negativos representam interpretações que na prática não escolheríamos, então corrigimos `low` para 0
6. **No final, determinamos pelo resultado de `low == 0`**: Quando a varredura é concluída, se `low` for 0, isso significa que "existe uma interpretação em que todos os parênteses de abertura são fechados", então retornamos `true`

## Conhecimentos prévios

### Princípio básico da validação de sequência de parênteses

Varremos a string da esquerda para a direita, gerenciando a contagem de parênteses de abertura. Incrementamos +1 para `(` e decrementamos -1 para `)`. Se a contagem nunca ficar negativa durante a varredura e for 0 no final, a sequência de parênteses é válida.

```java
int count = 0;
for (char c : s.toCharArray()) {
    if (c == '(') count++;
    else count--;
    if (count < 0) return false;  // Excesso de parênteses de fechamento
}
return count == 0;  // Todos os parênteses de abertura foram fechados
```

### O que é Math.max

É um método que retorna o maior entre dois valores. Pode ser usado para corrigir (clamping) um valor de modo que ele não fique abaixo de um determinado limite inferior.

```java
Math.max(3, 0);    // → 3 (3 é maior ou igual a 0, então permanece como está)
Math.max(-1, 0);   // → 0 (-1 é menor que 0, então é corrigido para 0)
```

### O que é toCharArray

É um método que converte uma string em um array de `char`. É usado para varrer uma string caractere por caractere em um loop for-each.

```java
String s = "(*)"；
char[] chars = s.toCharArray();  // → ['(', '*', ')']
for (char c : s.toCharArray()) {
    // c recebe um caractere por vez a cada iteração do loop
}
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Basta uma única varredura da string |
| Space | O(1) — Utiliza apenas as duas variáveis `low` e `high` |

## Código

```java
// Entrada: string s composta apenas por '(', ')' e '*'
// Saída: retorna boolean indicando se a string pode se tornar uma sequência válida de parênteses
public boolean checkValidString(String s) {
    // low: valor mínimo da contagem de parênteses de abertura, high: valor máximo
    // Essas 2 variáveis rastreiam o intervalo da contagem em todos os padrões de interpretação de *
    int low = 0, high = 0;

    // Varre a string caractere por caractere desde o início
    for (char c : s.toCharArray()) {
        if (c == '(') {
            // Parêntese de abertura: em qualquer interpretação a contagem aumenta 1, então incrementamos ambos os extremos do intervalo em +1
            low++;
            high++;
        } else if (c == ')') {
            // Parêntese de fechamento: em qualquer interpretação a contagem diminui 1, então decrementamos ambos os extremos do intervalo em -1
            low--;
            high--;
        } else {
            // '*': se interpretado como ), o mínimo diminui; se interpretado como (, o máximo aumenta
            // A interpretação como string vazia está incluída dentro deste intervalo
            low--;
            high++;
        }

        // Se o máximo for negativo, há excesso de parênteses de fechamento independentemente da interpretação de *, então é inválido
        if (high < 0) return false;

        // Se low ficar negativo, isso indica excesso de interpretação como ),
        // e na prática basta não escolher essa interpretação, então corrigimos o mínimo para 0
        low = Math.max(low, 0);
    }

    // Se low for 0, "existe uma interpretação de * em que todos os parênteses de abertura são fechados", então retorna true
    // Se low for maior que 0, independentemente da interpretação, sobram parênteses de abertura, então retorna false
    return low == 0;
}
```
