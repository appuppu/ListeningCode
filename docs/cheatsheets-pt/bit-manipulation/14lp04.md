# Reversing the Digits of an Integer — Inverter os dígitos de um inteiro com sinal de 32 bits

## Essência do Problema

Um inteiro com sinal de 32 bits `x` é fornecido. O programa deve retornar um inteiro com os dígitos de `x` reorganizados em ordem inversa. Se o valor após a inversão exceder o intervalo de um inteiro com sinal de 32 bits (-2³¹ a 2³¹-1), o programa deve retornar `0`.

## Ideia Central

O último dígito de um inteiro pode ser extraído com `x % 10`, e o último dígito pode ser removido com `x / 10`. Ao repetir essa operação de "extrair e empilhar", os dígitos ficam naturalmente em ordem inversa. Verificando o overflow antecipadamente a cada iteração durante o empilhamento, é possível construir o resultado invertido de forma segura.

## Processo de Raciocínio

1. **Como extrair os dígitos um a um**: O último dígito de um inteiro pode ser obtido com `x % 10` (o resto da divisão por 10). Após a extração, removendo o último dígito com `x / 10`, é possível acessar o próximo dígito. Repetindo essa operação até que `x` se torne 0, todos os dígitos podem ser extraídos sequencialmente a partir do final
2. **Como montar os dígitos extraídos em ordem inversa**: Para a variável de resultado `result`, repete-se `result = result * 10 + digit`. `result * 10` desloca os dígitos existentes uma posição para a esquerda, e `+ digit` adiciona o novo dígito na casa das unidades. Como os dígitos extraídos do final são posicionados sequencialmente a partir do início, a ordem dos dígitos se inverte naturalmente
3. **Como lidar com o overflow**: O resultado do cálculo `result * 10 + digit` pode exceder `Integer.MAX_VALUE` (2147483647) ou ficar abaixo de `Integer.MIN_VALUE` (-2147483648). Como é tarde demais verificar **depois** de executar a multiplicação, a verificação precisa ser feita **antes** da multiplicação
4. **Como verificar o overflow antecipadamente**: Para determinar se `result * 10` causará overflow, basta comparar `result` com `Integer.MAX_VALUE / 10` (= 214748364). Se `result > 214748364`, o overflow ocorrerá com certeza. Se `result == 214748364`, ocorrerá overflow quando `digit > 7` (o dígito das unidades de MAX_VALUE). Para valores negativos, a comparação é feita de forma análoga com `Integer.MIN_VALUE / 10`
5. **Tratamento do sinal**: Em Java, `x % 10` e `x / 10` funcionam corretamente para números negativos (`-123 % 10 == -3`, `-123 / 10 == -12`). Por isso, é possível processar o número diretamente sem separar o sinal
6. **O que retornar no final**: O `result` após o término do loop é o inteiro invertido. Se um overflow for detectado, o valor `0` é retornado imediatamente dentro do loop

## Conhecimentos Prévios

### O que é o operador % (operador de resto)

Um operador que retorna o resto da divisão de um inteiro por outro inteiro. `x % 10` extrai o dígito da casa das unidades de `x`. Em Java, o sinal é preservado mesmo para números negativos.

```java
123 % 10;    // → 3 (obtém o dígito das unidades)
-123 % 10;   // → -3 (o sinal é preservado mesmo para números negativos)
123 / 10;    // → 12 (remove o dígito das unidades)
-123 / 10;   // → -12 (truncamento correto mesmo para números negativos)
```

### Intervalo de um inteiro com sinal de 32 bits

O intervalo de valores que o tipo `int` do Java pode representar. Se esse intervalo for excedido, ocorre overflow e o valor se torna incorreto.

```java
Integer.MAX_VALUE;   // → 2147483647 (2³¹ - 1)
Integer.MIN_VALUE;   // → -2147483648 (-2³¹)
Integer.MAX_VALUE / 10;  // → 214748364 (limiar para verificação de overflow)
Integer.MAX_VALUE % 10;  // → 7 (dígito das unidades de MAX_VALUE)
Integer.MIN_VALUE / 10;  // → -214748364
Integer.MIN_VALUE % 10;  // → -8 (dígito das unidades de MIN_VALUE)
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — n é o número de dígitos de `x`. Cada dígito é processado uma vez |
| Space | O(1) — Apenas as variáveis `result` e `digit` são utilizadas |

## Código

```java
// Entrada: inteiro com sinal de 32 bits x
// Saída: retorna um inteiro com os dígitos de x invertidos. Retorna 0 se o valor invertido exceder o intervalo de 32 bits
public int reverse(int x) {
    // Variável para armazenar o resultado invertido. Os dígitos são empilhados um a um
    int result = 0;

    // Extrai os dígitos de x um a um a partir do final. Quando x se torna 0, todos os dígitos foram processados
    while (x != 0) {
        // Extrai o dígito das unidades de x. O operador % preserva o sinal para números negativos, então nenhum tratamento especial é necessário
        int digit = x % 10;

        // Verifica antecipadamente o overflow positivo (verificar após a multiplicação seria tarde demais)
        // Se result > 214748364, então result * 10 certamente excederá MAX_VALUE (2147483647)
        // Se result == 214748364 e digit > 7, então result * 10 + digit excederá MAX_VALUE (cujo último dígito é 7)
        if (result > Integer.MAX_VALUE / 10
                || (result == Integer.MAX_VALUE / 10 && digit > 7)) {
            return 0;
        }

        // Verifica antecipadamente o overflow negativo
        // Se result < -214748364, então result * 10 certamente ficará abaixo de MIN_VALUE (-2147483648)
        // Se result == -214748364 e digit < -8, então result * 10 + digit ficará abaixo de MIN_VALUE (cujo último dígito é -8)
        if (result < Integer.MIN_VALUE / 10
                || (result == Integer.MIN_VALUE / 10 && digit < -8)) {
            return 0;
        }

        // result * 10 desloca os dígitos existentes uma posição para a esquerda, e + digit adiciona o dígito extraído na casa das unidades
        // Dessa forma, o último dígito do número original é posicionado sequencialmente no início do resultado
        result = result * 10 + digit;

        // Remove o dígito das unidades de x, expondo o próximo dígito no final
        x = x / 10;
    }

    // Retorna o resultado com todos os dígitos invertidos. Em caso de overflow, o valor 0 já foi retornado dentro do loop
    return result;
}
```
