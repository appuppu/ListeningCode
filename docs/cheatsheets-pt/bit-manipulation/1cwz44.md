# Finding the Missing Number in a Sequence — Encontrar o número ausente em uma sequência contínua de 0 a n

## Essência do Problema

É fornecido um array `nums` contendo n números distintos dentre os inteiros de 0 a n. O objetivo é encontrar e retornar **o único número ausente** que está dentro do intervalo mas não existe no array.

## Ideia Central

O XOR anula-se quando aplicado duas vezes ao mesmo valor, resultando em zero. Ao aplicar XOR a todos os índices do array (0 a n-1), ao valor n e a todos os elementos do array, os números que formam pares se cancelam, restando apenas o "número ausente" que não possui par.

## Processo de Raciocínio

1. **Todos os números exceto o ausente formam pares**: Os índices do array vão de 0 a n-1, e os valores do array também estão no intervalo de 0 a n excluindo o número ausente. Ou seja, ao adicionar n como valor inicial do lado dos índices, todos os inteiros de 0 a n ficam cobertos pelo lado dos índices. Apenas o número ausente não existe do lado dos valores do array, portanto não forma par
2. **XOR é a operação ideal para cancelar pares**: O XOR possui as propriedades `a ^ a = 0` (valores iguais se cancelam) e `a ^ 0 = a` (XOR com zero preserva o valor). Ao aplicar XOR a todos os índices e valores, os números que formam pares tornam-se todos 0, restando apenas o número ausente que não possui par
3. **Motivo de definir o valor inicial como n**: O índice do loop for cobre apenas o intervalo de 0 a n-1. No entanto, o número ausente pode ser n, então ao definir o valor inicial do XOR como n, todo o intervalo de 0 a n fica coberto
4. **Conclusão em um único loop**: Ao realizar `xor ^= i` (XOR do índice) e `xor ^= nums[i]` (XOR do valor) simultaneamente dentro do loop, o resultado é obtido com uma única varredura do array. Nenhuma estrutura de dados adicional é necessária

## Conhecimento Prévio

### O que é XOR (Ou Exclusivo)

É uma operação bit a bit que retorna 1 quando dois bits são diferentes e 0 quando são iguais. Em Java, utiliza-se o operador `^`. A operação é aplicada bit a bit aos inteiros.

```java
int a = 5;          // binário: 101
int b = 3;          // binário: 011
int result = a ^ b; // binário: 110 → 6
```

### Propriedades Importantes do XOR

Existem 3 propriedades fundamentais para o algoritmo.

```java
// Propriedade 1: XOR de valores iguais resulta em 0 (cancelamento)
5 ^ 5;    // → 0

// Propriedade 2: XOR com 0 preserva o valor original
5 ^ 0;    // → 5

// Propriedade 3: O resultado é o mesmo independente da ordem (propriedade comutativa e associativa)
(2 ^ 5) ^ 2;  // → 5 (os dois 2 se cancelam, restando 5)
```

### O que é o operador ^=

É um operador de atribuição composta que atribui o resultado da operação XOR à variável do lado esquerdo. `xor ^= i` tem o mesmo significado que `xor = xor ^ i`.

```java
int xor = 0;
xor ^= 3;   // xor = 0 ^ 3 → 3
xor ^= 3;   // xor = 3 ^ 3 → 0 (cancelado pelo mesmo valor)
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Basta uma única varredura do array |
| Space | O(1) — Não utiliza estruturas de dados adicionais, apenas uma variável |

## Código

```java
// Entrada: array nums contendo n inteiros distintos no intervalo de 0 a n
// Saída: retorna o único inteiro do intervalo que não está contido no array
public int missingNumber(int[] nums) {
    // Ao definir o valor inicial como n, junto com os índices do loop de 0 a n-1, cobre-se todo o intervalo de 0 a n
    // Como os índices do loop for cobrem apenas de 0 a n-1, n é fornecido aqui como valor inicial
    int xor = nums.length;

    for (int i = 0; i < nums.length; i++) {
        // Acumula o índice i no valor XOR
        // Ao final do loop, todos os índices de 0 a n-1 terão sido aplicados ao XOR (junto com o valor inicial n, todos os inteiros de 0 a n são cobertos)
        xor ^= i;
        // Acumula o valor do array no valor XOR
        // Os números presentes no array aparecem tanto do lado dos índices quanto do lado dos valores, portanto se cancelam pela propriedade a ^ a = 0
        xor ^= nums[i];
    }

    // Todos os números que formaram pares foram cancelados resultando em 0, e apenas o número ausente que não possui par permanece
    return xor;
}
```
