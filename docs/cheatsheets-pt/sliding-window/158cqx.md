# Checking if a String Contains a Permutation of Another — Verificar se uma string contém uma permutação de outra

## Essência do problema

Duas strings `s1` e `s2` são fornecidas. O objetivo é determinar se existe um anagrama (rearranjo de caracteres) de `s1` como uma **substring contígua** dentro de `s2`, retornando `true` se existir e `false` caso contrário.

## Ideia central

Que uma permutação de `s1` esteja contida em `s2` significa que existe uma substring em `s2` com o mesmo comprimento e a mesma frequência de caracteres que `s1`. Ao percorrer `s2` com uma janela deslizante de tamanho fixo e atualizar incrementalmente a contagem de caracteres coincidentes entre as 26 letras, é possível avaliar cada deslocamento em O(1).

## Processo de raciocínio

1. **Reformular a condição de permutação**: Que uma permutação de `s1` exista como substring de `s2` significa que existe uma substring de comprimento `m` (= comprimento de `s1`) em `s2` cuja contagem de ocorrências de cada caractere coincide exatamente com a de `s1`
2. **Percorrer com uma janela de tamanho fixo**: Como o comprimento da substring é sempre `m`, basta posicionar uma janela de tamanho fixo `m` sobre `s2` e deslizá-la um caractere por vez, comparando as frequências de caracteres
3. **Gerenciar as contagens de ocorrências com arrays de frequência**: Como existem 26 tipos de letras minúsculas, dois arrays de inteiros de tamanho 26 (`s1F` e `winF`) gerenciam as frequências de caracteres de `s1` e da janela, respectivamente. Cada índice do array corresponde a uma letra
4. **Comparar 26 elementos a cada passo é desnecessário**: Ao deslizar a janela, no máximo 2 caracteres mudam: o que entra e o que sai. Em vez de comparar 26 elementos a cada vez, um contador `matches` rastreia quantas das 26 letras possuem frequências coincidentes, atualizando apenas a diferença
5. **Regra de atualização do contador matches**: Ao alterar a frequência de um caractere, se as frequências coincidiam antes da alteração, `matches` é decrementado em 1; se coincidem após a alteração, `matches` é incrementado em 1. Seguir a ordem "verificação antes da alteração → alteração do valor → verificação após a alteração" garante a consistência do contador
6. **Condição de avaliação**: Quando `matches` atinge 26, as frequências de todas as 26 letras coincidem e o método retorna `true`. Se o deslizamento até o final de `s2` não resultar em 26, o método retorna `false`

## Conhecimentos prévios

### O que é uma janela deslizante

É uma técnica que percorre subintervalos contíguos de um array ou string movendo as extremidades esquerda e direita. No caso de uma janela de tamanho fixo, ao avançar a extremidade direita em uma posição, a extremidade esquerda também avança em uma posição, mantendo o tamanho da janela constante.

```java
// Forma básica de deslizar uma janela de tamanho fixo m sobre s2
for (int i = m; i < n; i++) {
    char entering = s2.charAt(i);       // Caractere que entra na janela (extremidade direita)
    char leaving = s2.charAt(i - m);    // Caractere que sai da janela (extremidade esquerda)
}
```

### O que é um array de frequência

É um array de inteiros de tamanho 26 que armazena a contagem de ocorrências de cada caractere. `'a'` corresponde ao índice 0 e `'z'` ao índice 25. A expressão `charAt(i) - 'a'` converte um caractere em seu índice correspondente.

```java
int[] freq = new int[26];              // Inicializado com todos os elementos em 0
freq[s.charAt(i) - 'a']++;            // Incrementa a contagem de ocorrências do caractere em 1
freq[s.charAt(i) - 'a']--;            // Decrementa a contagem de ocorrências do caractere em 1
```

### O que é o contador matches

É um contador que rastreia quantos índices possuem o mesmo valor entre dois arrays de frequência. Se todos os 26 coincidirem, `matches == 26`, o que significa que a composição de caracteres das duas strings é idêntica.

```java
int matches = 0;
for (int i = 0; i < 26; i++) {
    if (s1F[i] == winF[i]) matches++;  // Conta o número de caracteres com frequências coincidentes
}
// Se matches == 26, todas as frequências de caracteres coincidem
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Basta percorrer `s2` uma única vez (cada deslocamento é O(1)) |
| Space | O(1) — O tamanho do array de frequência é sempre 26 e não depende do tamanho da entrada |

## Código

```java
// Entrada: string s1 (permutação a ser buscada) e string s2 (string onde buscar)
// Saída: true se s2 contém uma permutação de s1 como substring, false caso contrário
boolean checkInclusion(String s1, String s2) {
    int m = s1.length();
    int n = s2.length();

    // Se s1 é mais longa que s2, a permutação não pode estar contida, então retorna false imediatamente
    if (m > n) return false;

    // Arrays de tamanho 26 para armazenar as frequências de caracteres de s1 e da janela
    int[] s1F = new int[26];
    int[] winF = new int[26];

    // Calcula as frequências da primeira janela (primeiros m caracteres). Conta s1 e os primeiros m caracteres de s2 simultaneamente
    for (int i = 0; i < m; i++) {
        s1F[s1.charAt(i) - 'a']++;
        winF[s2.charAt(i) - 'a']++;
    }

    // Conta quantas das 26 letras possuem frequências coincidentes (cálculo inicial de matches)
    int matches = 0;
    for (int i = 0; i < 26; i++) {
        if (s1F[i] == winF[i]) matches++;
    }

    // Se todas as 26 frequências coincidem na primeira janela, retorna true
    if (matches == 26) return true;

    // Desliza a janela um caractere por vez para a direita (i é a posição seguinte à extremidade direita da janela)
    for (int i = m; i < n; i++) {
        // --- Processamento do caractere que entra na janela (extremidade direita) ---
        int idx = s2.charAt(i) - 'a';
        // Atenção: a ordem "verificação antes da alteração → alteração do valor → verificação após a alteração" deve ser sempre respeitada
        if (winF[idx] == s1F[idx]) matches--;   // Se coincidia antes da alteração, decrementa matches
        winF[idx]++;                              // Incrementa a frequência pois o caractere entra na janela
        if (winF[idx] == s1F[idx]) matches++;   // Se coincide após a alteração, incrementa matches

        // --- Processamento do caractere que sai da janela (extremidade esquerda) ---
        idx = s2.charAt(i - m) - 'a';
        // Mesmo procedimento do caractere que entra: verificação antes da alteração → alteração do valor → verificação após a alteração
        if (winF[idx] == s1F[idx]) matches--;   // Se coincidia antes da alteração, decrementa matches
        winF[idx]--;                              // Decrementa a frequência pois o caractere sai da janela
        if (winF[idx] == s1F[idx]) matches++;   // Se coincide após a alteração, incrementa matches

        // Se todas as 26 frequências coincidem, a permutação foi encontrada e retorna true
        if (matches == 26) return true;
    }

    // O deslizamento até o final de s2 não resultou em matches==26, então retorna false
    return false;
}
```
