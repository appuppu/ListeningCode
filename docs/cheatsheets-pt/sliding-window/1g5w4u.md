# Longest Substring After Replacing K Characters — Encontrar a maior substring de caracteres idênticos obtida com no máximo K substituições

## Essência do problema

São dados uma string `s` composta por letras maiúsculas e um inteiro `k`. É possível substituir no máximo `k` caracteres da string por qualquer caractere. O objetivo é retornar o comprimento máximo de uma substring em que **todos os caracteres sejam idênticos**.

## Ideia central

Se soubermos a "frequência do caractere mais comum" dentro da janela, podemos calcular o "número de caracteres que precisam ser substituídos = tamanho da janela − frequência do caractere mais comum". Enquanto esse número de substituições for menor ou igual a `k`, continuamos expandindo a janela, e assim obtemos a maior substring.

## Processo de raciocínio

1. **Explorar todas as substrings é ineficiente**: Enumerar todas as substrings custa O(n²). Como estamos lidando com intervalos contíguos, o padrão Sliding Window é adequado
2. **Queremos saber quantos caracteres precisam ser substituídos dentro da janela**: Para tornar todos os caracteres da janela idênticos, basta substituir todos exceto o caractere com maior frequência. Portanto, o número de caracteres a substituir é `tamanho da janela − frequência do caractere mais comum`
3. **Meio de rastrear a frequência de cada caractere**: Como existem apenas 26 tipos de letras maiúsculas, podemos gerenciar a frequência de cada caractere com um array `count` de tamanho 26. Incrementamos e decrementamos conforme a janela se expande e se contrai
4. **Gerenciar a frequência máxima de forma eficiente**: Cada vez que o ponteiro direito avança, comparamos a frequência do caractere adicionado com o `maxFreq` atual e tomamos o maior valor como novo `maxFreq`. Mesmo quando o ponteiro esquerdo avança e um caractere é removido, não reduzimos `maxFreq`. Isso ocorre porque, em um problema de busca pelo comprimento máximo, atualizar `maxFreq` para um valor inferior ao máximo já alcançado não produz um resultado mais longo
5. **Condição de contração da janela**: Quando `tamanho da janela − maxFreq > k`, o número de substituições excede `k`, então avançamos o ponteiro esquerdo em uma posição para contrair a janela. Repetimos até que essa condição deixe de ser satisfeita
6. **Atualização do comprimento máximo**: Sempre que a janela é válida (número de substituições ≤ k), comparamos `right − left + 1` com o `maxLen` atual e registramos o maior valor como `maxLen`

## Conhecimentos prévios

### O que é Sliding Window (Janela Deslizante)

É uma técnica que gerencia um intervalo contíguo em um array ou string usando dois ponteiros (left, right). Avançamos right para expandir a janela e, quando a condição deixa de ser satisfeita, avançamos left para contrair a janela. Como cada elemento é processado no máximo duas vezes (uma na adição e outra na remoção), a técnica opera em O(n).

### Método de gerenciar a frequência de caracteres com um array

Como as letras maiúsculas vão de `'A'` a `'Z'` (26 caracteres), podemos gerenciar a frequência de cada caractere com um array `int[26]`. A conversão de caractere para índice é feita com `charAt() - 'A'`.

```java
int[] count = new int[26];           // Array que armazena a frequência de cada um dos 26 caracteres
count[s.charAt(i) - 'A']++;         // Incrementa em 1 a frequência do caractere s.charAt(i)
count[s.charAt(i) - 'A']--;         // Decrementa em 1 a frequência do caractere s.charAt(i)
```

### Por que não reduzimos maxFreq

`maxFreq` representa a frequência do caractere mais comum dentro da janela. Mesmo quando avançamos o ponteiro esquerdo e removemos um caractere, não é necessário recalcular e reduzir `maxFreq`. Em um problema de busca pelo comprimento máximo, mesmo que `maxFreq` se torne menor que o valor máximo anterior, o tamanho da janela obtido nesse estado não superará o comprimento máximo anterior. Por isso, gerenciar `maxFreq` de forma monotonicamente crescente ainda produz o resultado correto.

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Os ponteiros direito e esquerdo avançam no máximo n vezes cada |
| Space | O(1) — O tamanho do array utilizado é fixo em 26 e não depende do tamanho da entrada |

## Código

```java
// Entrada: string s composta por letras maiúsculas e inteiro k (número máximo de substituições)
// Saída: retorna como int o comprimento máximo de uma substring cujos caracteres podem ser todos igualados com no máximo k substituições
public int characterReplacement(String s, int k) {
    // Array que gerencia a frequência de cada caractere (A–Z). O índice 0 corresponde a 'A' e o 25 a 'Z'
    int[] count = new int[26];
    // left: extremidade esquerda da janela
    int left = 0;
    // maxFreq: frequência do caractere mais comum dentro da janela (gerenciada de forma monotonicamente crescente)
    int maxFreq = 0;
    // maxLen: comprimento máximo da substring que satisfaz a condição (este valor será retornado ao final)
    int maxLen = 0;

    // Avança o ponteiro direito uma posição por vez para expandir a extremidade direita da janela
    for (int right = 0; right < s.length(); right++) {
        // Incrementa em 1 a frequência do caractere adicionado na extremidade direita
        count[s.charAt(right) - 'A']++;

        // Compara a frequência do caractere adicionado com o maxFreq atual e atualiza a frequência do caractere mais comum
        maxFreq = Math.max(maxFreq, count[s.charAt(right) - 'A']);

        // Tamanho da janela - maxFreq = número de caracteres que precisam ser substituídos. Enquanto esse valor exceder k, contrai a extremidade esquerda
        // Nota: maxFreq não é recalculado aqui. Reduzi-lo não contribui para a atualização do comprimento máximo
        while (right - left + 1 - maxFreq > k) {
            // Decrementa em 1 a frequência do caractere na extremidade esquerda e o remove da janela
            count[s.charAt(left) - 'A']--;
            left++;
        }

        // A janela é válida (número de substituições ≤ k), então atualiza o comprimento máximo com o tamanho atual da janela
        maxLen = Math.max(maxLen, right - left + 1);
    }
    // Após o término do loop for, retorna o comprimento da maior substring de caracteres idênticos obtida com no máximo k substituições
    return maxLen;
}
```
