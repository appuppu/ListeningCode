# Finding the Longest Substring Without Repeating Characters — Encontrar o comprimento da maior substring sem caracteres repetidos

## Essência do problema

Uma string `s` é fornecida. O objetivo é encontrar uma substring contígua em `s` que não contenha nenhum caractere repetido e retornar o **comprimento máximo** dessa substring como um número inteiro.

## Ideia central

Utilizando uma janela deslizante, é possível verificar todas as substrings válidas em O(n). Quando uma duplicata é encontrada, o ponteiro esquerdo salta diretamente para "a posição da ocorrência anterior do caractere duplicado + 1", eliminando movimentos desnecessários de uma posição por vez.

## Processo de raciocínio

1. **Representar a busca de substrings como uma janela**: Uma "substring sem duplicatas" pode ser representada como um intervalo delimitado por dois ponteiros, o esquerdo `left` e o direito `right`. O ponteiro direito avança uma posição por vez para expandir a janela, e quando uma duplicata ocorre, o ponteiro esquerdo avança para encolher a janela
2. **Usar um HashMap para detectar duplicatas**: Registrando o "último índice de ocorrência" de cada caractere em um HashMap, é possível determinar em O(1) se um novo caractere já existe dentro da janela
3. **Definir com precisão a condição de salto do ponteiro esquerdo**: Apenas verificar se o caractere de `right` existe no HashMap não é suficiente. O caractere só é considerado duplicado quando a posição da sua ocorrência anterior é maior ou igual a `left` (ou seja, está dentro da janela atual). Registros antigos fora da janela são ignorados
4. **Determinar o destino do ponteiro esquerdo**: Quando uma duplicata é detectada, `left` é atualizado para "a posição da ocorrência anterior do caractere duplicado + 1". Dessa forma, o caractere duplicado é removido da janela, enquanto os demais caracteres válidos permanecem dentro dela
5. **Momento de atualização do HashMap**: Após a verificação de duplicatas, o índice do caractere atual é registrado (sobrescrito) no HashMap. Isso garante que a posição mais recente de cada caractere esteja sempre registrada
6. **Atualização do comprimento máximo**: Em cada passo, o valor `right - left + 1` (largura atual da janela) é calculado e comparado com o valor máximo anterior para atualização

## Conhecimentos prévios

### O que é uma janela deslizante

É uma técnica que percorre um array ou uma string movendo uma "janela" definida por dois ponteiros (`left`, `right`), buscando trechos que satisfaçam uma condição. O ponteiro direito avança para expandir a janela, e quando a condição é violada, o ponteiro esquerdo avança para encolher a janela. Como cada ponteiro se move apenas para frente, a complexidade total é O(n).

### O que é um HashMap

É uma estrutura de dados que armazena pares de chave e valor. A busca e a obtenção de valores por chave são feitas em O(1). Neste problema, a chave é um "caractere" e o valor é "o último índice em que esse caractere apareceu".

```java
HashMap<Character, Integer> map = new HashMap<>();  // Cria um HashMap vazio
map.put('a', 0);            // Armazena o valor 0 com a chave 'a'
map.containsKey('a');       // Retorna um boolean indicando se a chave 'a' existe → true
map.get('a');               // Retorna o valor correspondente à chave 'a' → 0
```

### O que é charAt

É um método que obtém o caractere em uma posição específica de uma string. `s.charAt(i)` retorna o `char` no índice `i` da string `s`.

```java
String s = "abc";
char c = s.charAt(0);  // Retorna 'a'
char d = s.charAt(2);  // Retorna 'c'
```

### O que é Math.max

É um método que retorna o maior entre dois valores. É utilizado em situações onde o valor máximo precisa ser atualizado continuamente.

```java
int result = Math.max(3, 7);  // Retorna 7
maxLength = Math.max(maxLength, currentLength);  // Atualiza o valor máximo atual
```

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — `right` percorre a string apenas uma vez. `left` também se move apenas para frente, portanto a complexidade total é O(n) |
| Space | O(n) — O HashMap armazena no máximo n pares de caractere e índice |

## Código

```java
// Entrada: string s
// Saída: retorna como int o comprimento da maior substring sem caracteres repetidos
public int lengthOfLongestSubstring(String s) {
    // Ponteiro esquerdo da janela. A posição inicial é o início da string
    int left = 0;
    // Variável que registra a maior largura de janela encontrada durante a varredura
    int maxLength = 0;
    // HashMap que armazena chave=caractere, valor=último índice em que esse caractere apareceu
    // É utilizado tanto para verificação de duplicatas quanto para calcular o destino do salto do ponteiro esquerdo
    HashMap<Character, Integer> hashMap = new HashMap<>();

    // right é o ponteiro que representa a extremidade direita da janela. Avança uma posição por vez para expandir a janela
    for (int right = 0; right < s.length(); right++) {
        // Obtém o caractere que será adicionado à janela
        char curChar = s.charAt(right);

        // containsKey: verifica se este caractere já apareceu anteriormente
        // get(curChar) >= left: confirma se essa ocorrência está dentro da janela atual
        // Quando ambas as condições são verdadeiras, existe uma duplicata dentro da janela
        if (hashMap.containsKey(curChar) && hashMap.get(curChar) >= left) {
            // Faz o ponteiro esquerdo saltar para a posição da ocorrência anterior do caractere duplicado + 1, eliminando a duplicata
            // left sempre se move apenas para frente, nunca retrocede
            left = hashMap.get(curChar) + 1;
        }

        // Registra (sobrescreve) a posição de ocorrência do caractere atual com o índice mais recente
        // Na próxima vez que este caractere aparecer, o índice registrado aqui será usado para calcular o destino do salto do ponteiro esquerdo
        hashMap.put(curChar, right);
        // right - left + 1 é a largura atual da janela (comprimento da substring sem duplicatas)
        // Atualiza se o valor superar o máximo anterior
        maxLength = Math.max(maxLength, right - left + 1);
    }
    // Este é o comprimento da maior substring sem caracteres repetidos
    return maxLength;
}
```
