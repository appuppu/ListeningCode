# Finding the Maximum in Each Sliding Window — Encontrar o valor máximo em cada janela deslizante

## Essência do problema

São dados um array de inteiros `nums` e um tamanho de janela `k`. Uma janela de tamanho `k` desliza uma posição por vez, da extremidade esquerda até a extremidade direita do array, e o programa deve encontrar o **valor máximo** dentro da janela em cada posição. O programa retorna todos os valores máximos em um array.

## Ideia central

Se o Deque (fila de duas pontas) mantiver índices de forma que os valores correspondentes estejam em ordem monotonicamente decrescente, o início do Deque sempre apontará para o valor máximo dentro da janela. Quando um novo elemento chega, o algoritmo remove do final todos os elementos menores ou iguais a ele; quando o elemento do início está fora da janela, o algoritmo o remove. Dessa forma, o algoritmo obtém o valor máximo em cada passo com custo amortizado O(1).

## Processo de raciocínio

1. **O valor máximo de cada janela é necessário**: A cada deslizamento da janela, apenas um elemento é adicionado e um elemento é removido. Se o algoritmo percorrer toda a janela e calcular o máximo em O(k) a cada vez, o custo total será O(nk). Portanto, é necessária uma estrutura de dados que gerencie o valor máximo de forma eficiente
2. **Basta manter apenas os candidatos a valor máximo**: Se dentro da janela existem os elementos A e B, A está à esquerda de B e o valor de A é menor ou igual ao de B, então A nunca poderá ser o valor máximo em nenhuma janela futura. Como B está mais à direita, B não sairá da janela antes de A. Portanto, A pode ser excluído dos candidatos
3. **Gerenciar os candidatos com um Deque monotonicamente decrescente**: Se os candidatos forem mantidos em ordem decrescente de valor, o início sempre será o valor máximo. Ao adicionar um novo elemento, o algoritmo remove do final todos os elementos menores ou iguais a ele, mantendo assim a propriedade de decrescimento monotônico. O Deque (fila de duas pontas) é adequado para essa operação
4. **Armazenar índices no Deque**: Para determinar se um elemento saiu da janela, é necessária a informação de posição. Por isso, o Deque armazena índices em vez de valores. Os valores podem ser acessados via `nums[index]`
5. **Verificação de saída da janela no início do Deque**: Em cada passo, se o índice no início do Deque for menor que a extremidade esquerda da janela atual `i - k + 1`, esse elemento já saiu da janela e deve ser removido do início
6. **Momento de registrar o resultado**: Quando o índice `i` é maior ou igual a `k - 1`, a janela está completa. Nesse momento, o algoritmo registra no array de resultados o valor apontado pelo início do Deque

## Conhecimentos prévios

### O que é ArrayDeque (fila de duas pontas)

É uma estrutura de dados que permite adicionar, consultar e remover elementos tanto no início quanto no final em O(1). O ArrayDeque combina as funcionalidades de pilha e fila.

```java
ArrayDeque<Integer> deque = new ArrayDeque<>();  // Criar um Deque vazio
deque.offerLast(5);       // Adicionar 5 ao final
deque.offerLast(3);       // Adicionar 3 ao final → conteúdo do Deque: [5, 3]
deque.peekFirst();        // Consultar o elemento do início (sem remover) → 5
deque.peekLast();         // Consultar o elemento do final (sem remover) → 3
deque.pollFirst();        // Consultar e remover o elemento do início → 5
deque.pollLast();         // Consultar e remover o elemento do final → 3
deque.isEmpty();          // Retornar boolean indicando se o Deque está vazio → true
```

### O que é um Deque monotonicamente decrescente (Monotonic Deque)

É um Deque que mantém os elementos sempre em ordem decrescente (sem valores iguais) do início ao final. Ao adicionar um novo elemento, o algoritmo remove do final todos os elementos menores ou iguais a ele para manter o decrescimento monotônico.
Exemplo: Deque=[7, 5, 3], ao adicionar 6 → remover 5 e 3 → Deque=[7, 6]. O início sempre aponta para o valor máximo.

## Complexidade

| | Valor |
|---|---|
| Time | O(n) — Cada elemento é adicionado ao Deque no máximo uma vez e removido no máximo uma vez, resultando em O(n) no total |
| Space | O(k) — O Deque mantém no máximo k elementos, correspondentes ao tamanho da janela |

## Código

```java
// Entrada: array de inteiros nums e inteiro k (tamanho da janela)
// Saída: retorna um int[] contendo o valor máximo em cada posição da janela. O número de elementos é n - k + 1
public int[] maxSlidingWindow(int[] nums, int k) {
    int n = nums.length;
    // Array de resultados para armazenar o valor máximo de cada janela. Existem n - k + 1 janelas
    int[] result = new int[n - k + 1];
    // Deque que mantém os índices dos candidatos a valor máximo em ordem monotonicamente decrescente
    // O Deque armazena "índices que podem ser o valor máximo dentro da janela", mantendo os valores correspondentes em ordem monotonicamente decrescente
    ArrayDeque<Integer> deque = new ArrayDeque<>();

    for (int i = 0; i < n; i++) {
        // Se o índice do início for menor que a extremidade esquerda da janela i - k + 1, ele está fora da janela e deve ser removido
        // Como a janela desliza uma posição por vez, no máximo um elemento sai da janela em cada passo
        if (!deque.isEmpty() && deque.peekFirst() < i - k + 1) {
            deque.pollFirst();
        }

        // Remover do final todos os candidatos menores ou iguais ao elemento atual nums[i] para manter o decrescimento monotônico
        // Esses elementos nunca poderão ser o valor máximo enquanto nums[i] existir, portanto podem ser excluídos dos candidatos
        while (!deque.isEmpty() && nums[deque.peekLast()] <= nums[i]) {
            deque.pollLast();
        }

        // Adicionar o índice atual ao final do Deque
        // Como o while acima já removeu todos os elementos menores ou iguais, o Deque permanece monotonicamente decrescente após a adição
        deque.offerLast(i);

        // Quando i >= k - 1, a janela contém k elementos completos
        // O início do Deque aponta para o índice do valor máximo na janela atual
        if (i >= k - 1) {
            result[i - k + 1] = nums[deque.peekFirst()];
        }
    }
    // Retornar result, que contém os valores máximos de todas as janelas
    return result;
}
```
